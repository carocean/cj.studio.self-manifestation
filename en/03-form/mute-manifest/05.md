# The Mute-Manifest Reachability Form

Introduction

This chapter succeeds the Mute-Manifest General Form, the Mute-Manifest Mathematical Form, the Mute-Manifest Phase-Transition Form, and the Mute-Manifest Source Form, and treats one task only:

given a deeply mute initial state and its sedimentary configuration, and permitting only declared boundary inputs, the system's legitimate dynamics, and legitimate configurational generation, to adjudicate whether there exists a complete path by which one and the same r-bound generative lineage reaches, from a B-invariant stable trace-formation organization, a maintainable B-conditioned stable trace-formation organization.

This chapter does not prove why D → L belongs to phase transition; the Phase-Transition Form has already treated the two phases, the criticality, and the organizational reconstruction. Nor does this chapter prove that satisfying certain conditions makes L necessarily reached; "there exists a legitimate path" and "all or almost all trajectories finally arrive" are not the same task.

The core question of this chapter is:

O\_D^r ↝ O\_L^r ?

I. Upstream inputs and the entry condition of construction

This chapter is a Reachability Form. By the strength requirement of that form-kind, the target construction must hold before the proof of reachability; this chapter does not also serve as a Construction Form.

The object of target construction this chapter requires is written:

𝔠\_L^r

It must give at least the LFamily stable organization, the stable carrying basin, the formation-load-bearing structure, the legitimate formation relation, together with an explicit witness of construction and an item-by-item verification.

The Mute-Manifest Phase-Transition Form delivers DBranch, LFamily, PhaseSuppᵣ, CurPhaseᵣ, Σ\_land^r, S\_D ⪯\_gen^r S\_L, and the established sub-types of phase transition. The ⪯\_gen^r received is that chapter's relation of generative reachability on the state space (a preorder, admitting cycles); this chapter takes it up only as an upstream witness and does not use its order properties in derivation.

The Mute-Manifest Source Form delivers the valid / invalid / unknown source classes, Supp\_{L,form}^r(\[H\]), ClosureLevel\_src^r, and the source constraints.

But these results do not automatically yield:

Constructed(𝔠\_L^r) = 1

Hence the public registration:

Mute-Manifest Reachability Form-H1:

Constructed(𝔠\_L^r) = 1

that is, the L stable-organization construction class has already reached construction strength by an independent proof, with an explicit witness of construction and item-by-item verification.

The responsibility for verifying H1 does not fall within this chapter; it must be closed by an independent Construction Form, by an existing text that has attained construction strength, or by a subsequent explicit proof of construction.

H1 is a form-level admission dependence:

Admission\_reach^r = 1  
⇔  
Constructed(𝔠\_L^r) = 1

H1 answers whether the target L organization class has attained construction strength; Reach answers whether the present X₀ can reach at least one instance within that construction class.

Hence:

Constructibility of target class  
≠  
Reachability from this initial state

Only within the admission domain where Admission\_reach = 1 does this chapter's theorem of reachability without additional constructional conditions formally take effect.

While H1 is unclosed:

Status(ReachForm) = conditional/open

Γ₁—Γ₄ do not substitute for H1 by re-proving that the target class is constructible; they prove only that the present X₀ can reach an instance of the target class as delimited by H1.

While H1 is unclosed, this chapter establishes only the regime of conditional reachability and the conditional theorem of reachability, and may not claim that the construction of L has been completed.

II. The initial state, the state target, and the path target

Define the complete reachability state:

X^r = (S^r, 𝔥^r)

Given an initial state:

X₀^r = (S₀^r, 𝔥₀^r)

it is required that:

CurPhaseᵣ(S₀^r) = D

and that S₀ be carried by some stable D branch with:

DBranch\_r(\[O\_D\], 𝔥₀^r) = 1

Define the criterion of construction instance:

Inst\_{𝔠\_L}^r(X)  
∈  
{1, 0, ⊥}

Inst\_{𝔠\_L}^r(X) = 1

if and only if the L stable organization, the carrying structure, and the formation-load-bearing organization of X satisfy the constructional specification and the item-by-item conditions of verification already given by 𝔠\_L^r.

If H1 being unclosed leaves the constructional specification insufficient to complete the determination of instance, then:

Inst\_{𝔠\_L}^r(X) = ⊥

Define the three-valued criterion of the state target:

Target\_L^r(X)  
∈  
{1, 0, ⊥}

Target\_L^r(X) = 1

if and only if all of the following hold:

Inst\_{𝔠\_L}^r(X) = 1;

L ∈ PhaseSuppᵣ(𝔥);

CurPhaseᵣ(S) = L;

S lies in the stable carrying basin of some LFamily\_r(𝔉\_L, 𝔥) = 1;

that L carriage is maintainable within the declared maintenance window Δ\_ord^r.

If at least one necessary condition of the target has definitely failed, then:

Target\_L^r(X) = 0

If there is no proven failure but at least one load-bearing criterion is ⊥, then:

Target\_L^r(X) = ⊥

Only when all necessary conditions of the target are 1 is:

Target\_L^r(X) = 1

The three-valued conjunction therefore takes:

0 ∧ ⊥ = 0

1 ∧ ⊥ = ⊥

Hence:

Inst = ⊥  
≠  
X does not belong to the target

but rather:

membership in the target is at present undecidable.

If set notation is required, only states already adjudged 1 compose:

𝒯\_{L,state}^r  
\=  
{X : Target\_L^r(X) = 1}

For a history Γ and a moment t, define the criterion of the path target:

Goal\_L^r(Γ, t)  
∈  
{1, 0, ⊥}

Goal\_L^r(Γ, t) = 1

if and only if:

Target\_L^r(X\_Γ(t)) = 1

and:

Lineage\_r(Γ\[0, t\]) = 1

If Target\_L^r(X\_Γ(t)) = ⊥ or Lineage\_r(Γ\[0, t\]) = ⊥, and there is no other proven failure, then:

Goal\_L^r(Γ, t) = ⊥

Only when the criterion of the target state or the criterion of lineage has definitely failed is:

Goal\_L^r(Γ, t) = 0

where Lineage\_r denotes that from X₀ to the present moment one and the same r-bound legitimate generative lineage has been preserved throughout.

Hence one and the same terminal state may be reached by a legitimate lineage, or by an illegitimate lineage such as copying, re-initialization, or replacement; only the former satisfies Goal\_L.

Define the working context of reachability:

𝒞\_reach^r

fixing at least:

the model instance;

the initial state X₀;

the regime of permitted inputs;

the legitimate system successor;

the set of forbidden operations;

𝒯\_{L,state};

Lineage\_r;

the time domain;

and, for a stochastic model, the environment/policy regime, the probability kernel, and the path space.

Should any of these load-bearing conditions change, reachability must be adjudicated afresh.

III. The regime of permitted inputs and the legitimate system successor

At the universal level this chapter restricts π to a state-feedback policy:

π : Obs\_r(X) → A\_allow^r

that is, the policy depends only on the presently observable state declared permissible, and not on unencoded prior history.

If a particular model uses a history-dependent policy, it must prove separately:

Compat\_π(Γ₁, …, Γ\_n) = 1

proving that the whole concatenated history still obeys the same policy.

Three regimes of input are distinguished:

Π\_allow^r: the set of permitted control policies;

Env\_det^r: the regime of deterministic fixed environmental input;

Env\_prob^r: the regime of probabilistic environment.

Hence:

reachability under some permitted policy ≠ deterministic fixed-environment reachability ≠ stochastic reachability under a probabilistic environment.

Define the unified legitimate system successor:

X' ∈ F\_reach^r(X, a)

where a must be legitimately produced by π ∈ Π\_allow, by Env\_det, or by the stochastic regime.

F\_reach at the same time obeys the normal boundary input, the internal state dynamics, the configurational updating, and the legitimate order of updating of the Mute-Manifest Mathematical Form; it does not permit local transitions to be freely concatenated into a pseudo-path.

The set of forbidden operations 𝒰\_forbid^r includes directly setting the phase label, M, or internal load-bearing variables, direct insertion into the L basin, overwriting by copy, re-initialization exchanging the object, hidden controllers, and rootless external structural inscription.

IV. Permitted histories and path sets

Given π ∈ Π\_allow^r, a history:

Γ = (X₀, a₀, X₁, a₁, …)

requires:

X\_{k+1} ∈ F\_reach^r(X\_k, a\_k)

with a\_k legitimately produced by π.

Define Paths\_π^r(X₀).

Under the deterministic fixed environment Env\_det, define Paths\_{env,det}^r(X₀).

The union of paths over all control policies:

Paths\_allow^r(X₀)  
\=  
⋃\_{π ∈ Π\_allow^r} Paths\_π^r(X₀)

No path may exhibit 𝒰\_forbid; and if a load-bearing structure from a source class is used, that structure must be legitimately generated from the present X₀ along this same Γ.

V. The definition of reachability

Deterministic controllable finite reachability is defined as a three-valued aggregation:

Reach\_L^{ctrl}(X₀^r)  
∈  
{1, 0, ⊥}

Reach\_L^{ctrl}(X₀^r) = 1

if and only if:

∃π ∈ Π\_allow^r  
∃Γ ∈ Paths\_π^r(X₀)  
∃t\_f \< ∞

such that:

Goal\_L^r(Γ, t\_f) = 1

Reach\_L^{ctrl}(X₀^r) = 0

if and only if it has been proven that:

∀π ∈ Π\_allow^r  
∀Γ ∈ Paths\_π^r(X₀)  
∀t \< ∞

one has:

Goal\_L^r(Γ, t) = 0

All other cases are uniformly adjudged:

Reach\_L^{ctrl}(X₀^r) = ⊥

that is:

there is neither a path with a proven Goal = 1,

nor a proof that all permitted paths at all finite moments have Goal = 0,

and "not yet proven reachable" may not be exchanged for "unreachable."

Deterministic fixed-environment reachability is likewise defined as:

Reach\_L^{env}(X₀^r)  
∈  
{1, 0, ⊥}

Reach\_L^{env}(X₀^r) = 1

if and only if:

∃Γ ∈ Paths\_{env,det}^r(X₀)  
∃t\_f \< ∞

such that:

Goal\_L^r(Γ, t\_f) = 1

Reach\_L^{env}(X₀^r) = 0

if and only if it has been proven that:

∀Γ ∈ Paths\_{env,det}^r(X₀)  
∀t \< ∞

one has:

Goal\_L^r(Γ, t) = 0

All other cases:

Reach\_L^{env}(X₀^r) = ⊥

The three-valued transduction is therefore fixed as:

Inst\_{𝔠\_L}  
→  
Target\_L  
→  
Goal\_L  
→  
Reach\_L^{ctrl/env}

wherein a ⊥ at any load-bearing link may not automatically collapse into 0 downstream.

VI. The state-feedback path-concatenation lemma and the conditional theorem of reachability

The state-feedback path-concatenation lemma:

If π : Obs\_r(X) → A\_allow^r, and finite historical segments Γ₁, …, Γ\_n share endpoints head to tail, and each segment is legitimately produced by the same π and F\_reach, then:

Γ = Γ₁ ∘ … ∘ Γ\_n

still obeys the same π, that is:

PolicyCompat\_r(π, Γ) = 1

A history-dependent policy does not automatically fall under this lemma; Compat\_π = 1 must be proven separately.

Declaration of relational properties. The ↝ of this chapter is a path notation: Γ : X\_a ↝ X\_b denotes that there exists a finite legitimate history generated by permitted dynamics, with X\_a as its starting point and X\_b as its terminus. From it a binary relation between states may be defined:

X\_a ↝\_π^r X\_b

if and only if under the permitted policy π there exists such a finite legitimate history. The properties of that relation are as follows:

Reflexivity is determined by convention: whether a zero-length history counts is not prescribed by this chapter; since every usage in this chapter requires actual generation through permitted dynamics, and the duration condition T \< ∞ degenerates at zero length, this chapter does not rely on reflexivity, and a particular model may convention it as it sees fit.

Transitivity holds within one and the same permitted policy, but it is not identical with the concatenation lemma above. What the lemma proves is policy compatibility — the concatenated history still obeys the same π, that is PolicyCompat\_r(π, Γ) = 1; whereas what transitivity requires is that the concatenated history still be a legitimate history, policy compatibility being only one of the conditions of legitimacy. Transitivity further requires three things: that every segment be legitimately produced by F\_reach^r, which is preserved since concatenation introduces no new manner of production; that every segment be of finite duration and the segments be finite in number, so that the sum of t\_f remains finite; and that no segment use 𝒰\_forbid^r, which is preserved since concatenation introduces no new input. These three together with the concatenation lemma give: if X\_a ↝\_π^r X\_b and X\_b ↝\_π^r X\_c, then X\_a ↝\_π^r X\_c.

This must be read together with the sentence in Section III, "F\_reach does not permit local transitions to be freely concatenated into a pseudo-path": that sentence forbids concatenating illegitimate local transitions and passing them off as a path; what is discussed here is that two already legitimate histories, concatenated, remain legitimate. The two do not conflict — the former governs the materials of concatenation, the latter the result.

The concatenation of four path segments in Section VI of this chapter is precisely what, after checking these conditions item by item, yields t\_f = T₁ + T₂ + T₃ + T₄ \< ∞ and PolicyCompat\_r(π, Γ) = 1; here that procedure is merely abstracted into a general property of the relation.

Across policies it does not hold automatically: for two segments under different π, compatibility must be proven separately as Compat\_π = 1. A history-dependent policy does not fall under this lemma, as above. Infinitely many concatenations do not preserve finiteness, so transitivity holds only for finitely many concatenations.

Antisymmetry does not hold and is not required to hold: if there is a legitimate path from X\_a to X\_b and also a legitimate path back from X\_b to X\_a, the two are mutually reachable without being equal. The regime of permitted inputs of this chapter does not forbid cycles, and reversible processes and cyclic orbits both belong to this case. Hence ↝\_π^r is a preorder, not a partial order.

This property is of a kind with the ⪯\_gen^r of the Mute-Manifest Phase-Transition Form — both being relations of generative reachability, both admitting cycles — and unlike the within-history-graph ancestor relation ⪯\_H^r of the Mute-Manifest Source Form, whose definition explicitly contains a temporal partial order and admits no cycle. None of the three may be inferred from another on the ground of similar notation or name.

This chapter does not take a quotient by ↝\_π^r: mutually reachable states may have different values of Inst\_{𝔠\_L}^r and different CurPhase, and taking a quotient would erase the determination of reachability itself.

The following theorem holds within the admission domain where:

Admission\_reach^r = 1

It is required that there exist one and the same permitted state-feedback policy π, shared endpoints X₁, X₂, X₃, X₄, and four finite legitimate historical segments:

Γ₁ : X₀ ↝ X₁  
Γ₂ : X₁ ↝ X₂  
Γ₃ : X₂ ↝ X₃  
Γ₄ : X₃ ↝ X₄

with T₁, T₂, T₃, T₄ \< ∞.

First, the segment of source formation:

SourceWitnessValid\_r(Γ₁, \[H\]) = 1.

That witness may be supported by an existing legitimate proof of source from the Mute-Manifest Source Form; or this chapter may prove directly, for the source subgraph actually used by Γ₁, that BaseSrc, SourceTransform, the formation-load-bearing structure, and the lineage are all legitimate.

If such a local re-proof produces new knowledge of source, then there must be generated:

ΔSrcProof\_{Γ₁}

to be returned to the Mute-Manifest Source Form or to the interface of source-gap management of the Master Map of the Mute-Manifest Group.

ΔSrcProof closes or narrows only the unknown of that particular source subgraph; it does not automatically yield AdmClass = 1 or HistClosureClass = 1 for the whole \[H\].

Second, the segment of configurational chaining:

Γ₂ legitimately enters from X₁ into the configurational domain 𝓗\_req satisfying the requirements of L formation.

Third, the segment of critical entry:

Γ₃ enters from X₂ into the corresponding organizational domain of landscape criticality.

Fourth, the segment of carriage completion:

Γ₄ legitimately enters from X₃ into stable LFamily carriage and satisfies:

Inst\_{𝔠\_L}^r(X₄) = 1

and:

X₄ ∈ 𝒯\_{L,state}^r

By the state-feedback path-concatenation lemma:

PolicyCompat\_r(π, Γ) = 1

where:

Γ = Γ₁ ∘ Γ₂ ∘ Γ₃ ∘ Γ₄

and it is required that:

Lineage\_r(Γ) = 1

so that:

t\_f = T₁ + T₂ + T₃ + T₄ \< ∞

Define the conjunction of the above path conditions as:

C\_reach^r(X₀, π)

Then within the admission domain where Admission\_reach = 1:

C\_reach^r(X₀, π)  
⇒  
Reach\_L^{ctrl}(X₀^r) = 1

Proof: the four finite legitimate historical segments may be concatenated at their shared endpoints; the terminus X₄ is a legitimate instance of 𝔠\_L and satisfies the remaining L state targets; the whole segment has Lineage = 1; hence Goal\_L(Γ, t\_f) = 1.

While H1 is unclosed, the above theorem is preserved only under an open dependency condition, and may not be passed off as a closed conclusion already satisfying all the admission conditions of a Reachability Form.

VII. A path is not an order of proof

The following argument is invalid:

O\_D is established; O\_L is established; therefore O\_D can reach O\_L.

That both endpoints exist proves only that two kinds of organization may exist.

A Reachability Form must give the intermediate path and prove step by step that each transition belongs to:

Φᵣ, Ξ, or another permitted relation already declared upstream.

Hence:

Exist(O\_D) ∧ Exist(O\_L) ⇏ Reach\_L^{ctrl}(X₀)

VIII. Landscape reachability and actual reachability

If under some configuration:

L ∈ PhaseSuppᵣ(𝔥)

this shows only that a stable L organization exists in that landscape.

It does not yield:

Reach\_L^{ctrl}(X₀^r) = 1

There may be: the L basin wholly isolated from X₀; the required configuration ungeneratable by permitted dynamics; an uncrossable boundary between D and L; entry into L possible only by privileged inscription; the actual lineage terminating before the criticality is reached.

Hence:

StableExistence\_L ≠ Reachability\_L

IX. Establishment of source and configurational reachability

The Mute-Manifest Source Form may prove that some L formation-load-bearing structure has a legitimate source history, but closure of source is not reachability from the present X₀.

If a path uses the Supp\_{L,form}^r(\[H\]) of a source class \[H\], it must be checked afresh: that its BaseSrc is available within the present 𝒞\_reach; that its SourceTransform belongs to the presently permitted dynamics; that its load-bearing structure can actually be generated from the present X₀ along the same Γ.

If reaching L requires the configurational domain 𝓗\_req^r, it must be proven that 𝔥₀^r ↝ 𝓗\_req^r holds along legitimate configurational transitions.

Hence:

SourceClosed ≠ ReachableFrom(X₀)

X. Reachability of the continuous-destabilization type

For the continuous-destabilization type, if there exists a permitted configurational orbit:

𝔥₀^r ↝ Σ\_land^r ↝ 𝔥\_L^r

and along that orbit one and the same r-bound D branch persists until the criticality, thereafter destabilizes and enters a stable L organization by legitimate dynamics, then that continuous-destabilization path constitutes a legitimate witness of Reach\_L^{ctrl} = 1.

The minimal path structure:

X₀^D → continuous configurational evolution → Σ\_land → DBranch destabilizes under the conditions of the continuous-destabilization type → legitimate B-side actual load-bearing → O\_L → StableOrg

If the configuration can reach the criticality but the system must necessarily exit the r-bound working domain before that, then that path does not hold.

XI. Reachability of the discontinuous-nucleation type

For the discontinuous-nucleation type, the existence of an L branch is still not enough.

There must exist a permitted path forming a B-conditioned local organization able to cross the model-level condition of discontinuous nucleation or basin-change.

If the model uses a critical nucleus N\_c, then it is required that there exist:

N₀ ↝ N

with:

N ≥ N\_c

and that this growth, combination, or generation be completed by permitted dynamics.

If all permitted paths satisfy:

N \< N\_c

then even if:

L ∈ PhaseSuppᵣ(𝔥)

L cannot be reached from the present initial state.

XII. Paths of pre-shaped, first-inscribed, and mixed source

If a witness of reachability uses a type of source from the Mute-Manifest Source Form, it must be read back from the particular class of source history.

A Pre path requires that the formation duties associated with the criticality were already legitimately formed beforehand, and that the present X₀ can preserve, release, or take up anew those structures along a permitted path.

An Onset path requires that the key formation duty be first acquired by permitted internal dynamics during the process associated with the criticality.

A Mixed path requires that both the pre-critical source contribution and the subsequent rewriting associated with the criticality actually enter the same legitimate source graph.

No type of source may become a witness of reachability for the present X₀ merely on the ground that "such a history exists in theory."

XIII. Consistency of the source class with the present path

If a source class \[H\] is used in a proof of reachability, then it must not already have been adjudged invalid by the Mute-Manifest Source Form; its key source nodes must not depend on boundaries or operations forbidden in the present 𝒞\_reach; its formation-load-bearing structure must be embeddable in the present Γ; and its r-bound lineage must be consistent with the present X₀.

GenerativeExplanationClosed likewise does not automatically yield reachability from the present X₀.

XIV. Normal external induction

An external input may belong to a path of reachability.

For example:

A\_ext → normal Gate/Pass → change of automatic antecedents → legitimate action of internal B/Y/T → change of configuration and landscape → D → L

So long as A\_ext has not crossed the declared interface to complete the B-side uptake on the system's behalf, that path still belongs to self-manifesting reachability.

Hence:

ExternalTrigger ≠ PrivilegedCompletion

XV. Preservation of lineage

A candidate path Γ must satisfy:

Lineage\_r(Γ) = 1.

If along the way: the old system is destroyed and re-initialized; r is replaced by s; L is copied from another duplicate; a core load-bearing structure is added by rootless external inscription;

then even if the terminus satisfies some of the L state conditions, so long as Lineage\_r(Γ) ≠ 1 it is not a mute-manifest path of reachability for the present X₀^r.

XVI. Event-level reachability is not phase-level reachability

That there exists a path making some event:

M\_ε = 1

does not yield:

Reach\_L^{ctrl}(X₀^r) = 1

for that event may fail to nucleate and thereafter return to D.

The target of phase-level reachability must be:

𝒯\_{L,state}^r

that is, the domain of stable B-conditioned organizational carriage, and not a set of events with M = 1 on one occasion.

XVII. Finite paths and asymptotic paths

If there exists a permitted trajectory entering 𝒯\_{L,state}^r in finite time, that is finite reachability.

If the system does not enter 𝒯\_{L,state}^r for any finite t and only approaches the L boundary as:

t → ∞

then this may not be written directly as finite reachability.

If the definition of the target permits asymptotic arrival, it must be declared separately as:

Reach\_L^∞

with the sense of the limit given.

The Reach\_L^{ctrl} and Reach\_L^{env} of this chapter both refer by default to actual entry within finite time, and do not pass off infinite approach as arrival.

XVIII. Reachability in stochastic dynamics

A stochastic model must declare its probability space.

For the case of policy control:

(Ω\_Γ^r, 𝔽\_Γ^r, ℙ\_{X₀}^{π})

For a fixed probabilistic environment:

(Ω\_Γ^r, 𝔽\_Γ^r, ℙ\_{X₀}^{env})

First define the path-level state of finite hitting:

PathHit\_L^r(Γ)  
∈  
{1, 0, ⊥}

PathHit\_L^r(Γ) = 1

∃t \< ∞,

PathHit\_L^r(Γ) = 0

∀t \< ∞,  
Goal\_L^r(Γ, t) = 0

PathHit\_L^r(Γ) = ⊥

PathHit\_L^r(Γ) = 1

ResolvedGoal\_r^π = 1

ResolvedGoal\_r^{env} = 1

XX. Bypasses and alternative paths

That one candidate path has been breached does not mean unreachability.

If there exists another wholly legitimate path:

Γ₂ ≠ Γ₁

which can still form from X₀ some Γ, t with Goal\_L(Γ, t) = 1, then reachability still holds.

A proof of unreachability must therefore cover the whole class of permitted paths; it cannot merely breach the one mechanism the investigator first had in mind.

Conversely, a proof of reachability need give only at least one complete legitimate witnessing path.

XXI. The minimal witness of reachability

A witness of reachability contains at least:

Admission\_reach^r = 1;

the initial state X₀^r;

the target construction class 𝔠\_L^r;

the criterion of terminal instance:

Inst\_{𝔠\_L}^r(X\_f) = 1;

the three-valued state target:

Target\_L^r(X\_f) = 1;

the set of permitted policies Π\_allow^r or the corresponding environmental regime;

the actual path Γ;

the legitimacy of every key source and configurational change along the path;

the place where Σ\_land, or the particular model's condition of basin-change or nucleation, is crossed;

the place of actual LFamily load-bearing;

the terminus:

X\_f ∈ 𝒯\_{L,state}^r;

and:

Lineage\_r(Γ) = 1.

If H1 is unclosed, the witness report must at the same time record:

Status(ReachForm) = conditional/open

and may not render a "closed Reachability Form" adjudication.

Where any load-bearing link is missing, reachability may not be adjudged merely from the final output of a simulation.

XXII. The witness of unreachability

Unreachability may not be inferred from "no path has been found so far."

Deterministic controllable unreachability:

Reach\_L^{ctrl}(X₀^r) = 0

requires proof that:

∀π ∈ Π\_allow^r  
∀Γ ∈ Paths\_π^r(X₀)  
∀t \< ∞

one has:

Goal\_L^r(Γ, t) = 0

or the giving of an unbypassable invariant or barrier covering all permitted policies and histories.

For instance, if there exists an invariant I such that:

I(X₀) ∈ D\_I

and every permitted unified successor preserves:

I(X') ∈ D\_I

while every target state satisfying Goal\_L requires:

I(X\_L) ∉ D\_I

then L is unreachable.

For infinite histories, no undefined End(Γ) is used.

XXIII. The boundary with the Necessity Form

Reachability proves only:

∃ Γ : D ↝ L

The Necessity Form must prove:

C ⇒ D → L

or, in a probabilistic model, the corresponding necessary consequence at the distributional level.

Hence:

Reach\_L^{ctrl} = 1 ⇏ NecessaryTransition\_L

That a legitimate path exists does not mean the system must take that path.

XXIV. The boundary with the Realization Form

That a formal system proves:

Reach\_L^{ctrl}(X₀) = 1

is not that an actual engineering has already realized that path.

Whether an actual device has the declared states, interfaces, and configurational dynamics, and whether it has really traversed Γ, belongs to the task of realization.

This chapter proves only permitted reachability within a theoretical system.

XXV. Breach conditions

Should any of the following occur, the claim of reachability fails:

1\. only the two ends D and L, with no legitimate intermediate path;  
2\. the path uses an undeclared internal write port, debugging port, or hidden controller;  
3\. the required configuration has an explanation of source but cannot be legitimately generated from the present initial state;  
4\. only one occurrence of M = 1 is reached, without entering StableOrg;  
5\. the path changes midway to another content, another duplicate, or a re-initialized system;  
6\. the stable existence of L is taken directly as reachability from the present D;  
7\. in the nucleation type all permitted nuclei are below the criticality, yet reachability is still claimed;  
8\. in the continuous type the r-bound working domain has already terminated before the criticality;  
9\. a stochastic model has only a mathematical trajectory of measure zero, yet physical reachability is claimed;  
10\. positive-probability reachability is written as almost-sure or deterministic necessity;  
11\. infinite approach to the target is written as finite arrival;  
12\. after breaching one path, total unreachability is claimed without covering other permitted bypasses;  
13\. ↝\_π^r is used as a partial order — for instance inferring X\_a = X\_b from X\_a ↝ X\_b and X\_b ↝ X\_a, or adjudicating reachability after taking a quotient by that relation.
