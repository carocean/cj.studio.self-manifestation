# The Reachability Form of Law

Section One

Purpose, Form-Kind, and the Single Task

### 1.1 The Single Task

For an already standing Law, once a definite initial state, running specification, protocol, set of permitted inputs and operations, and a Law-dynamics target declared in advance have been fixed, this text answers one question:

&nbsp;&nbsp;&nbsp;&nbsp;whether there exists a finite legal path along which the Law really hits the target within a legal working segment.

What is proved is supported reachability:

&nbsp;&nbsp;&nbsp;&nbsp;SuppReach^LD

Its sense is one only: among the legal successors the system permits, there exists at least one finite path that reaches the target.

### 1.2 Form-Kind

The reachability form, an auxiliary form, set up as an independent text.

By Canon Chapter 1, Part Four, Chapter Nine, the purpose of the reachability form is to prove that the constructed object can be reached from a given initial state by permitted operations or by the system's dynamics; its entry conditions are that the construction is already given and that the initial state and the set of permitted operations are clearly delimited. The construction of this text is given upstream, see Section Three; the initial state, the permitted set, and the target are all frozen in Section Three.

By Canon Chapter 1, Part Two, Chapter Five, the order of the completion strengths of establishment proof is compatibility ≺ construction ≺ reachability ≺ realization, and a higher strength must cover the requirements of the lower. This text reaches the strength of reachability: the construction it relies on is already given upstream and is not redone here; the strength of realization is not borne by this text.

### 1.3 The Upper Bound of Strength

What this text proves goes only as far as the existence of a path. The following three are not proved here, and nothing in the main text may upgrade to them:

&nbsp;&nbsp;&nbsp;&nbsp;not upgraded to CtrlReach — it is not claimed that an operator can guarantee arriving;  
&nbsp;&nbsp;&nbsp;&nbsp;not upgraded to universality — it is not claimed that every permitted path hits;  
&nbsp;&nbsp;&nbsp;&nbsp;not upgraded to probability one — it is not claimed that arrival is necessary.

The difference between these three and supported reachability lies in quantifier and modality, not in wording. Whoever substitutes "can be brought about," "necessarily arrives," or "always reaches" for "there exists a path" has already overstepped the grade.

2.4 Four Lines against Neighbouring Tasks

First

&nbsp;&nbsp;&nbsp;&nbsp;CompatSol ≠ Reachability

The CompatSol of Chapter 5 is the completion of formal information within one and the same η already given. Reachability in this text is the search for, or construction of, a future permitted path from an initial state, with η not yet given. The former completes without changing the segment; the latter is exactly the making of that segment.

Second

&nbsp;&nbsp;&nbsp;&nbsp;GenReach ≠ Reachability

The GenReach of Chapter 5 is the after-the-fact attribution, by generating chain, of the source of contribution within a dynamical event that has already occurred. What this text asks is whether there is a legal path in the future that reaches the target. One looks backward, the other forward.

Third

&nbsp;&nbsp;&nbsp;&nbsp;DynReach ≠ LawSource

This text does not ask how a Law first came into being. Source belongs to Chapter 9, The Source Form of Law.

Fourth

&nbsp;&nbsp;&nbsp;&nbsp;DynReach ≠ LawIdentity

As soon as a path involves wholesale migration, copying, replacement, or recovery across carriers, so that it must be adjudicated "whether it is still the same Law," it is handed down at once to the Law-identity texts. The paths of this text do not cross this line; wherever one does, its conclusion of reachability may be stated only after the Law-identity texts have given a criterion.

### 2.5 What Is Not Asked

How a Law comes to stand; where a Law comes from; whether it is the same after its carriers have been replaced; the complete theory of interaction by which another Law brings about a change in the dynamics of this Law; long-term persistence and return in an environment of several Laws. These belong, respectively, to The General Form of Law and The Necessity Form of Law, The Source Form of Law, the Law-identity texts, the Law Interaction texts, and The Stability Form of Law Ecology.

Section Four

Reachability Nodes, Target Sets, and Legal Supported Successors

4.1 A Target Is Not an Isolated Terminal State

Of the six classes of upstream Law-dynamics event

&nbsp;&nbsp;&nbsp;&nbsp;Θ\_LD = { Start, Continue, Stop, Rise, Fall, Migration }

most are relations between adjacent evaluation points, not properties of a single state. A Start requires the read-outs at the two ends to go from zero to one, a Continue requires both ends to be one, a Rise requires the profiles at the two ends to be ordered. Writing any of them as an isolated terminal state loses one of its ends.

So a purely auxiliary object of proof is introduced:

&nbsp;&nbsp;&nbsp;&nbsp;Z\_k = ( X\_{a(k)}, E^eval\_k, X\_{a(k+1)} )

that is, one evaluation step together with the underlying states anchored at its two ends.

Z is not a field state, not a new state component, and does not enter the laws of running. It only packs "one evaluation step and its two ends" into an object on which a target criterion can take a value.

The target set is

&nbsp;&nbsp;&nbsp;&nbsp;G\_Θ = { Z : Z satisfies the declared target criterion }

The criteria are listed class by class in 4.2; no abstract predicate Θ(·) is set up.

### 4.2 The Six Target Sets

The criteria are all taken from upstream; no second set is set up:

&nbsp;&nbsp;&nbsp;&nbsp;G\_Start = { Z : ( A\_k, A\_{k+1} ) = ( 0, 1 ) }  
&nbsp;&nbsp;&nbsp;&nbsp;G\_Continue = { Z : ( A\_k, A\_{k+1} ) = ( 1, 1 ) }  
&nbsp;&nbsp;&nbsp;&nbsp;G\_Stop = { Z : ( A\_k, A\_{k+1} ) = ( 1, 0 ) }  
&nbsp;&nbsp;&nbsp;&nbsp;G\_Rise = { Z : G\_{k+1} ≻\_D G\_k }  
&nbsp;&nbsp;&nbsp;&nbsp;G\_Fall = { Z : G\_k ≻\_D G\_{k+1} }  
&nbsp;&nbsp;&nbsp;&nbsp;G\_Migration = { Z : G\_k ∥\_D G\_{k+1} }

where A is the reading of current action of 3.10 of Chapter 5, G its Degree profile reading of 3.11, and ≻\_D and ∥\_D the comparison relations of Chapter 3.

The criteria refer to current action and profile relations at the object layer. Where a hit is verified by the machine read-outs of Chapter 5, by 3.12 of Chapter 5 v1.1 the read-outs must be reliable and the readings determinate; an evaluation step whose reading is ⊥ does not count as a hit, nor is it taken as a miss — it is recorded only as an undecided reading. G\_Rise, G\_Fall, and G\_Migration are targets on the profile domain J\_D: hitting G\_Rise is not becoming more familiar, and hitting G\_Fall is not growing shallower.

### 4.3 Legal Prefixes

The legal qualification of a segment is a property of the whole segment, not a local label step by step. By Definition 2 of Chapter 4, LegalLawSegment is the conjunction of five items: one and the same legal trajectory segment, the target reference fixed, qualification preserved within the segment, updates following the protocol, the evaluation protocol frozen in advance. Several of these span the whole segment and cannot be inferred automatically from "each step is locally legal" — two successors each legal on its own, joined together, need not form a segment that still satisfies the five items.

So the object is not an isolated node but a legal finite prefix starting from the frozen initial state. Write

&nbsp;&nbsp;&nbsp;&nbsp;π = ( X\_0 ; Z\_1, …, Z\_j ),　j ≥ 0

that is, a sequence beginning with the initial state X\_0 followed by j evaluation nodes. j can be zero:

&nbsp;&nbsp;&nbsp;&nbsp;π\_0 = ( X\_0 )

is the empty evaluation prefix, containing no evaluation step yet — the initial state itself is not an evaluation node; a lone X\_0, with no E^eval and no state at the far end, does not make up a Z. This must be fixed definitively, or the types in the zero-step case do not close.

The Z follow on one another: the front end of Z\_1 is anchored at X\_0, and the front end of Z\_{i+1} is the far end of Z\_i.

π is called legal if and only if the working segment η(π) it covers satisfies

&nbsp;&nbsp;&nbsp;&nbsp;LegalLawSegment^{η(π)}( L ) = 1

The legality of the empty evaluation prefix π\_0 is that the initial state itself lies within the working domain, which is given by the declaration of Section Three.

### 4.4 Legal Supported Successors

Define the auxiliary relation of proof

&nbsp;&nbsp;&nbsp;&nbsp;Next^adm\_LD( π )

Its sense is: the set of next evaluation nodes Z′ produced from the legal prefix π, under the frozen Adm\_LD and Prot, by legal transitions already existing upstream — the front end of Z′ anchored at the terminal state of π (at X\_0 when π = π\_0) — which must further satisfy

&nbsp;&nbsp;&nbsp;&nbsp;π ⌢ Z′　is still a legal prefix, that is, LegalLawSegment^{η(π ⌢ Z′)}( L ) = 1

None of the three requirements may be lacking: Z′ is produced by a legal transition upstream; the inputs and modes used lie within Adm\_LD; after the extension, the whole segment is still legal.

The third requirement is why this section takes prefixes as its object. Were only the local successor required to be legal, the preservation of the five items over the whole segment would merely be inherited in passing, not checked at every step; written now into the definition of Next, every extension must obtain the certificate of the whole segment anew, and the loophole of joining is closed.

Its standing must be stated. Next^adm\_LD is not a dynamical law and produces no transition; it only filters among the legal successors already existing upstream — filtering out those whose inputs or modes are not in Adm\_LD, and those after whose extension the whole segment is no longer legal. Every member must come from Step^M\_Prot.

No duplicate object of qualification such as a LawTube is created: the legal qualification of a segment is already given by the five items of Definition 2 of Chapter 4, and this text only invokes their criteria without setting up its own.

Section Five

The Definition of Supported Reachability and the Path Certificate

### 5.1 Definition

&nbsp;&nbsp;&nbsp;&nbsp;SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 1

L is already within Ξ\_LD and is not listed separately as a parameter; the target is always written as the target set G\_Θ, not as an abstract label. This signature is unchanged throughout; Section Six and Sections Seven through Ten all use it, Sections Seven through Ten only taking Ξ and the initial state as those of this instance, without changing the signature.

Its value is one if and only if there exists a finite path

&nbsp;&nbsp;&nbsp;&nbsp;γ = ( X\_0, ζ\_0, X\_1, …, ζ\_{H−1}, X\_H ),　H \< ∞

Here H is the number of underlying execution steps of the path. Throughout the text, every "H = 1" means the number of underlying execution steps; the rank bound of Theorem One is written separately as the number of evaluation steps N and is not a bound on H (6.1); it shares the letter with the H of conditional items (such as C0, C2, H1–H3) and has nothing to do with it.

satisfying four items:

&nbsp;&nbsp;&nbsp;&nbsp;PathLegal( γ ) = 1　　　every ζ\_r ∈ Step^M\_Prot  
&nbsp;&nbsp;&nbsp;&nbsp;InputAdmissible( γ ) = 1　every u\_r ∈ Adm\_LD ∩ 𝒰, every m\_r ∈ Adm\_LD ∩ 𝓜\_Prot  
&nbsp;&nbsp;&nbsp;&nbsp;LegalLawSegment^η( L ) = 1　the working segment covered by the path is legally qualified  
&nbsp;&nbsp;&nbsp;&nbsp;TargetHit\_{G\_Θ}( π ) = 1　　on that prefix there exists some Z\_i ∈ G\_Θ

The correspondence between the two notations must be written out, or the fourth item hangs on an undefined object.

γ is a sequence of underlying single steps; π is a sequence of evaluation nodes. They are linked by the anchoring map a inherited from Chapter 5: given γ and the set of evaluation points frozen by Γ\_reach, take

&nbsp;&nbsp;&nbsp;&nbsp;a(0) = 0,　X\_{a(0)} = X\_0

with the subsequent a(k) increasing and not exceeding H; then the prefix corresponding to γ is

&nbsp;&nbsp;&nbsp;&nbsp;π( γ ) = ( X\_0 ; Z\_1, …, Z\_j ),　Z\_i = ( X\_{a(i−1)}, E^eval\_{i−1}, X\_{a(i)} )

where j is the number of evaluation points on γ less one. If γ has no evaluation point other than the initial state, then j = 0 and π(γ) = π\_0.

Below, wherever π is said without further specification, it means π(γ).

The empty evaluation prefix contains no Z, so TargetHit\_{G\_Θ}( π\_0 ) = 0 always holds — the six classes of target are all evaluation events, and none can be hit where there is not yet an evaluation step.

From this also follows the agreement of the third item with 4.3: "the working segment covered by the path" in the third item of 5.1 is η(π(γ)); its legality and π(γ) being a legal prefix are one and the same thing.

### 5.2 The Path Certificate

&nbsp;&nbsp;&nbsp;&nbsp;CertReach( γ, G\_Θ ) = PathLegal ∧ InputAdmissible ∧ SegmentQualified ∧ TargetHit

where SegmentQualified is the third item.

Its standing must be declared: CertReach is a certificate of proof of reachability, not an ontological structure of LawDyn. It may not be added to the general formula of The General Form of Law-Dynamics, nor read downstream as a third conjunct of LawDyn. The general formula of Chapter 4 is sealed as two items, and this text does not change it.

5.3 The Difference between Support and Control

The quantifier in the definition is "there exists a path." What it asserts is that there is such a path among the system's permitted successors; it does not assert that an operator can pick it, nor that at a branching the system will take this branch.

Whoever infers from the conclusions of this text that "an operator can make it happen" passes support off as control; see K-R5 in Section Fourteen.

Section Six

The Theorem of Supported Reachability by Finite Rank

### 6.1 Theorem One

Fix Ξ\_LD. Write D^π\_Θ for the domain of legal prefixes from X\_0.

The rank function is defined on legal prefixes, not on isolated nodes:

&nbsp;&nbsp;&nbsp;&nbsp;ρ\_Θ : D^π\_Θ → ℕ

satisfying two conditions:

&nbsp;&nbsp;&nbsp;&nbsp;Condition one　ρ\_Θ( π ) = 0　⇒　TargetHit\_{G\_Θ}( π ) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;Condition two　for any π ∈ D^π\_Θ, if ρ\_Θ( π ) \> 0, then there exists at least one  
&nbsp;&nbsp;&nbsp;&nbsp;　　　　　　Z′ ∈ Next^adm\_LD( π )　with π′ = π ⌢ Z′ ∈ D^π\_Θ and ρ\_Θ( π′ ) \< ρ\_Θ( π )

Taking prefixes rather than nodes as the domain settles three matters at once. First, the initial state X\_0 need not be disguised as an evaluation node — it cannot make up a Z to begin with. Second, the types of the zero-step case hold: what ρ\_Θ(π) = 0 yields is that there is already a hit on that prefix, not that some isolated state itself possesses some evaluation relation; since the empty evaluation prefix contains no Z, its TargetHit is always zero, so ρ\_Θ(π\_0) = 0 can be taken only where the target has already been hit on an existing prefix. Third, Next^adm\_LD is itself defined on prefixes, and the rank is also defined on prefixes; the two are of the same type.

Then

&nbsp;&nbsp;&nbsp;&nbsp;SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 1

and there exists a finite legal supported path; writing N for the number of evaluation steps it needs to reach a hitting prefix,

&nbsp;&nbsp;&nbsp;&nbsp;N ≤ ρ\_Θ( π\_0 )

where π\_0 = ( X\_0 ) is the empty evaluation prefix. For the path chosen, its number of underlying execution steps is

&nbsp;&nbsp;&nbsp;&nbsp;H = Σ\_{i=0}^{N−1} \[ a(i+1) − a(i) \]

each term finite, so H is finite. Each decrease of the rank corresponds to one evaluation step, and by the anchoring institution inherited, one evaluation step may contain several underlying execution steps; so this theorem gives no bound on H. Only under a further condition that each evaluation step contains at most M underlying execution steps could one obtain H ≤ M·ρ\_Θ(π\_0); this text introduces no M.

v1.0 wrote H ≤ ρ\_Θ(π\_0) here, mistaking a bound on evaluation steps for a bound on underlying execution steps; this version withdraws it. Counterexample: freeze the evaluation protocol so that the first evaluation point falls after the 10th underlying execution step and hits the target at once; let ρ\_Θ(π\_0) = 1 and the rank after the hit 0; both conditions hold, while H = 10.

### 6.2 Proof

Take the empty evaluation prefix π\_0 = ( X\_0 ). By the declaration of Section Three, X\_0 lies within the working domain, so π\_0 ∈ D^π\_Θ.

If ρ\_Θ(π\_0) = 0, then by condition one TargetHit\_{G\_Θ}(π\_0) = 1, the path has length zero, and the conclusion holds. Note that the empty evaluation prefix contains no evaluation node and its TargetHit is always zero, so when starting from the empty evaluation prefix ρ\_Θ(π\_0) \> 0 necessarily holds and the zero-step case does not occur; this case is provided only for non-empty prefixes already containing a hit.

If ρ\_Θ(π\_0) \> 0, then by condition two take some Z′ ∈ Next^adm\_LD(π\_0) with π\_1 = π\_0 ⌢ Z′ ∈ D^π\_Θ and ρ\_Θ(π\_1) \< ρ\_Θ(π\_0).

The legality of this step is given directly by the three requirements of Next^adm\_LD: Z′ comes from Step^M\_Prot; the inputs and modes used lie within Adm\_LD; and π\_1 is still a legal prefix, that is, LegalLawSegment^{η(π\_1)} = 1. So the legality of the whole segment is not inherited in passing but obtained anew with every extension.

Repeat on π\_1. With each repetition, the value of ρ\_Θ on the prefix falls strictly by at least one. Since ρ\_Θ takes values in the natural numbers, a strict decrease cannot go on indefinitely, so after at most ρ\_Θ(π\_0) evaluation steps some legal prefix π\_N with ρ\_Θ(π\_N) = 0 must be obtained; by condition one, TargetHit\_{G\_Θ}(π\_N) = 1. Each extension adds one evaluation node, so the number of decreases is the number of evaluation steps N ≤ ρ\_Θ(π\_0).

π\_N is a legal prefix, so the working segment it covers satisfies LegalLawSegment = 1; every step comes from Step^M\_Prot, and the inputs and modes all lie within Adm\_LD; on it there is some Z\_i ∈ G\_Θ. The four items of the certificate are complete, that is, CertReach = 1. The number of evaluation steps N ≤ ρ\_Θ(π\_0); the number of underlying execution steps H = Σ\_{i=0}^{N−1} \[ a(i+1) − a(i) \], a sum of finitely many finite positive integers, is finite. ∎

### 6.3 The Position of the Quantifiers

The quantifiers of condition two are

&nbsp;&nbsp;&nbsp;&nbsp;∀ π \[ ρ\_Θ(π) \> 0 \]　∃ Z′ ∈ Next^adm\_LD( π )

not

&nbsp;&nbsp;&nbsp;&nbsp;∀ π　∀ Z′

So what follows is only

&nbsp;&nbsp;&nbsp;&nbsp;∃ path

It does not follow that every path hits, nor necessity, nor probability one, nor operator control. Were condition two written with a universal Z′ — requiring every legal extension of the prefix to lower the rank — what would be obtained is a different, stronger theorem, whose proof differs from this section's; this text does not make it.

### 6.4 The Standing of ρ\_Θ

ρ\_Θ is a tool of proof, set up for the task and discarded once the proof is done.

It is not a field potential, not a dynamical potential, not a control variable, not a property of the Law, and not a new Degree coordinate. It does not enter 𝓡 and Φ, takes part in no read-out, and is not cited downstream as an object.

The same target may have several legitimate ρ\_Θ; which one is taken does not affect the conclusion, only the tightness of the bound on the number of evaluation steps obtained. It is defined on legal prefixes, not on field states, so it cannot be read as a property of some state either.

6.5 The Relation of Theorem One to Sections Seven through Nine

By Part Four, Chapter Nine of the Canon Chapter, the standard composition of the reachability form admits two routes: path construction or reachability argument. Either one suffices.

Theorem One belongs to the latter: it gives a sufficient condition — whoever can construct a rank function satisfying the two conditions may conclude reachability without writing out a path explicitly, together with an upper bound on the number of evaluation steps.

Sections Seven, Eight, and Nine take the former: all three paths are given explicitly, and their certificates verified item by item, without going through Theorem One.

So Theorem One is not invoked by any instance in this text. That is not an oversight — direct construction already suffices to support Theorem Two, with no need to go round by way of a rank function; Theorem One is kept here as a general tool, for use where the target is further off and an explicit path is not easily written.

Both give the same strength, reaching only the existence of a path. Where reachability is obtained by Theorem One, the bound on the number of evaluation steps is ρ\_Θ(π\_0), and the number of underlying execution steps is known only to be finite; where it is obtained by direct construction, the number of underlying execution steps is the length of the path constructed.
