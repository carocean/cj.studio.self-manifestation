# The Construction Form of the Minimal Sedimentation Field

## Section I　Purpose

This text treats a single problem of construction:

On the basis of the structure and dynamics of the Sedimentation-Field already given in the Field Chapters of *On Self-Manifestation*, can one explicitly construct an instance of a Sedimentation-Field which closes the minimal set of offices, can actually be run, and is able to have its subsequent flux altered by its own history?

This text does not redefine the Sedimentation-Field, does not undertake the proof of necessity for a general form of the Sedimentation-Field, and does not take neural networks as a source of definition.

This text and *The Construction Form of the Law Operating Substrate* are strictly divided in office:

*The Construction Form of the Minimal Sedimentation Field* is responsible only for constructing the "Sedimentation-Field" and proving that it can run;

*The Construction Form of the Law Operating Substrate* then extends it, on that basis, with the thresholds, intensities, stable recurrence, Freeze-run, pseudo-law counterexamples and other structures required for law-side testing.

Accordingly, this text no longer undertakes any adjudication of law-standing; it does not certify R ∈ 𝒮, sets up no FormalLawSolutionCandidate, and does not interpret A ⇒ C or B ⇒ D as a law. Where a conditional mapping is used, it is taken only as a running probe for testing whether "an organization of history can alter what comes after."

The word "minimal" in the title of this text means:

upon a given structural substrate Ξ, forming the minimal closure of Sedimentation-Field offices with as few persistent states and core dynamical operators as possible.

This text does not prove that the node count \|Ξ\| is minimal, and does not prove that every Sedimentation-Field must use variables of the same names as those here.

## Section IV　The Group of Constructive Conditions

\**C1　Entry of action*\*

There exists an actual external event π\_t received by the in-field Trace, rather than merely recorded outside the field.

\**C2　Formation of Trace-Response*\*

Trace(π\_t) produces a non-zero Trace-Response τ\_t, so that the present field acquires a detectable response to the event.

\**C3　Cross-temporal sedimentation*\*

After passing through Sediment, the Trace-Response is able to enter the persistent field state of the next moment, and does not wholly vanish at the end of that step.

\**C4　Relational organization*\*

History not only alters local sedimentation but is able to form relational organization between Structural Positions.

\**C5　History taking part in what follows*\*

The sedimentary structure already formed must really enter subsequent generation; if a load-bearing sediment is deleted or severed while the present re-entry conditions are held unchanged, a detectable change should occur in the subsequent flux.

\**C6　Shallowing*\*

In the absence of further action, existing sediment is able to weaken, realizing "Little used — trace fades."

\**C7　Present flux*\*

There exist actual state transitions q\_t → q\_{t+1} within the field.

Following the minimal semantics of "condition migrates and turns within" in *On the Sedimentation-Field* v1.2, this text requires only that at least one actual in-field state transition exist; it does not extend C7 into "every state must continue autonomously without limit" or "a closed orbit without limit must be formed."

The construction of this text succeeds if and only if one and the same Canonical F\* satisfies C1—C7 simultaneously.

Compatibility(C1,…,C7) is closed in parallel with this construction: one and the same Canonical F\* acquiring C1—C7 simultaneously constitutes a constructive witness of compatibility.

## Section IX　The Two Modes of Running

\**I. Exogenous-experience mode Mode\_exo*\*

An actual permitted event i→j occurs in the external environment.

Define:

π\_t := ExternalTransition\_t(i,j).

That event enters Trace:

τ\_t = Trace(π\_t).

Sediment then writes the Trace-Response into d and g.

The office of Mode\_exo is only to let external history enter the field.

\**II. Endogenous-continuation mode Mode\_endo*\*

No dangling external π\_t is posited.

Given the present q\_t together with d\_t, g\_t:

κ\_t = K(q\_t,d\_t,g\_t).

Then:

q\_{t+1} = Continuation(q\_t,κ\_t).

After the actual transition q\_t → q\_{t+1} occurs, a Trace-Response is formed and sedimentation continues.

Hence:

Mode\_exo: external history enters;

Mode\_endo: the existing sedimentary structure takes part autonomously in what comes after.

## Section X　Unified Temporal Update

Canonical F\* uniformly adopts, at every actual event, the order "Shallow first, then handle the present event"; the Mode\_endo of the final source code v1.2 already agrees with this completely: Decay → Continuation → Trace → Sediment.

First define the present sediment after Shallowing:

d̃\_i(t)=max{0,d\_i(t)−λ\_d};

g̃\_ij(t)=max{0,g\_ij(t)−λ\_g}.

If in Mode\_endo, then:

κ\_t(q\_t→j)=κ₀+w\_g·g̃\_{q\_t j}(t)+w\_d·d̃\_j(t).

q\_{t+1}=Continuation(q\_t,κ\_t).

After the actual event i→j occurs:

τ\_ij(t)=1 if and only if i→j actually occurred at that step, and 0 otherwise.

The local Trace-Response τ\_i(t) takes the value 1 at the Structural Positions reached by the event, and 0 elsewhere.

Then:

d\_i(t+1)=d̃\_i(t)+α·τ\_i(t).

g\_ij(t+1)=g̃\_ij(t)+β·(1−g̃\_ij(t)/g\_max)·τ\_ij(t).

So the endogenous chain is:

(q\_t,d\_t,g\_t) → (d̃\_t,g̃\_t) → κ\_t → q\_{t+1} → τ\_t → (d\_{t+1},g\_{t+1}).

And the exogenous chain is:

ExternalTransition\_t(i,j) → (d̃\_t,g̃\_t) → τ\_t → (d\_{t+1},g\_{t+1}).

There is no cycle in which a future state takes part in generating itself.

## Section XV　Orthogonality Test for the Offices of d and g

This section still uses one and the same Canonical F\*.

\**I. Relational organization*\*

Construct two histories with the same final local sedimentation d but different relational pairings. Both first undergo the same common prefix — one A→C and one B→D, bringing every local sediment into the positive region — and then 180 rounds each:

H1: repeated experience of A→C and B→D;

H2: repeated experience of A→D and B→C.

The final d of the two groups agree component by component: max\|d^{H1} − d^{H2}\| ≈ 4.44×10⁻¹⁶, within the declared tolerance 10⁻¹² (asserted by the script). v1.2 controlled only the visitation counts, without a common prefix; the final d of the two groups then differed through initial truncation at zero, and after erasing g, P(C\|A) was 0.4999 in one and 0.5001 in the other, still different — not enough to prove that d cannot distinguish the two histories. This version adds the control.

Full F\*:

H1: P(C\|A)≈0.9499, P(D\|B)≈0.9502;

H2: P(C\|A)≈0.0501, P(D\|B)≈0.0499.

H1: P(C\|A)≈0.4999, P(D\|B)≈0.5001;

\**II. Local depth-accumulation*\*

A controlled state-intervention test of local sedimentation. import numpy as np
import copy

class CanonicalSedField:
    def __init__(self, alpha=0.015, beta=0.030, g_max=1.20,
                 lam_d=0.0015, lam_g=0.0015, kappa0=0.10,
                 w_g=0.55, w_d=0.05, temperature=0.20, seed=0):
        self.rng = np.random.default_rng(seed)
        self.nodes = ["A","B","C","D"]
        self.idx = {n:i for i,n in enumerate(self.nodes)}
        self.allowed = {
            self.idx["A"]:[self.idx["C"], self.idx["D"]],
            self.idx["B"]:[self.idx["C"], self.idx["D"]],
        }
        self.d = np.zeros(4)
        self.g = np.zeros((4,4))
        self.alpha=alpha; self.beta=beta; self.g_max=g_max
        self.lam_d=lam_d; self.lam_g=lam_g
        self.kappa0=kappa0; self.w_g=w_g; self.w_d=w_d
        self.temperature=temperature

    def Decay(self):
        self.d = np.maximum(0.0, self.d - self.lam_d)
        self.g = np.maximum(0.0, self.g - self.lam_g)

    def Trace(self, i, j):
        tau_d = np.zeros(4)
        tau_g = np.zeros((4,4))
        tau_d[i] = 1.0
        tau_d[j] = 1.0
        tau_g[i,j] = 1.0
        return {"tau_d": tau_d, "tau_g": tau_g, "event": (i,j)}

    def Sediment(self, tau):
        tau_d, tau_g = tau["tau_d"], tau["tau_g"]
        self.d = self.d + self.alpha * tau_d
        hits = np.argwhere(tau_g > 0)
        for i,j in hits:
            old = self.g[i,j]
            self.g[i,j] = min(
                self.g_max,
                old + self.beta*(1 - old/self.g_max)*tau_g[i,j]
            )

    def kappa(self, q):
        outs = self.allowed[q]
        return np.array([
            self.kappa0 + self.w_g*self.g[q,j] + self.w_d*self.d[j]
            for j in outs
        ])

    def Continuation(self, q, rng=None):
        rng = rng or self.rng
        outs = self.allowed[q]
        scores = self.kappa(q)
        z = (scores - scores.max())/self.temperature
        p = np.exp(z); p /= p.sum()
        j = int(rng.choice(outs, p=p))
        return j,p

    def exo_experience(self, i, j, trace_on=True, sediment_on=True, decay_on=True):
        assert j in self.allowed[i]
        if decay_on:
            self.Decay()
        tau = self.Trace(i,j) if trace_on else None
        if sediment_on and tau is not None:
            self.Sediment(tau)
        return tau

    def endo_episode(self, i, rng=None, learn=True, decay_on=True,
                     trace_on=True, sediment_on=True):
        # Canonical order: Decay -> Continuation -> Trace -> Sediment
        if decay_on:
            self.Decay()
        j,p = self.Continuation(i,rng=rng)
        tau = self.Trace(i,j) if trace_on else None
        if learn and sediment_on and tau is not None:
            self.Sediment(tau)
        return j,p,tau

    def idle(self, steps=1):
        for _ in range(steps):
            self.Decay()

def exact_prob(field, src, target):
    outs=field.allowed[src]
    scores=field.kappa(src)
    z=(scores-scores.max())/field.temperature
    p=np.exp(z); p/=p.sum()
    return float(p[outs.index(target)])

def train_map(field, cycles=350):
    A,B,C,D=[field.idx[x] for x in ["A","B","C","D"]]
    for _ in range(cycles):
        field.exo_experience(A,C)
        field.exo_experience(B,D)
    return field

def local_deposit_intervention(field, x, n):
    """Controlled state intervention (test interface, not Mode_exo / Mode_endo):
    each step applies the same Decay, then adds an equal local deposit at x;
    it does not call Trace or Sediment and forms no event in E."""
    for _ in range(n):
        field.Decay()
        tau_d=np.zeros(4); tau_d[x]=1.0
        field.d += field.alpha*tau_d

D_TOL = 1e-12   # tolerance for "same final d" (floating-point)

def test_relation_organization():
    def make(h1=True):
        f=CanonicalSedField(seed=2)
        A,B,C,D=[f.idx[x] for x in ["A","B","C","D"]]
        # common prefix: bring local sediment into the positive region,
        # so that equal visit counts no longer yield unequal final d via truncation at 0
        f.exo_experience(A,C); f.exo_experience(B,D)
        for _ in range(180):
            if h1:
                f.exo_experience(A,C); f.exo_experience(B,D)
            else:
                f.exo_experience(A,D); f.exo_experience(B,C)
        return f
    h1=make(True); h2=make(False)
    A,B,C,D=[h1.idx[x] for x in ["A","B","C","D"]]
    d_gap=float(np.max(np.abs(h1.d-h2.d)))
    assert d_gap <= D_TOL, d_gap
    h1d=copy.deepcopy(h1); h1d.g[:]=0
    h2d=copy.deepcopy(h2); h2d.g[:]=0
    return {
        "max|d_H1-d_H2|":d_gap,
        "H1_P(C|A)":exact_prob(h1,A,C),
        "H1_P(D|B)":exact_prob(h1,B,D),
        "H2_P(C|A)":exact_prob(h2,A,C),

        "H2_d_only_P(C|A)":exact_prob(h2d,A,C),
