# The Construction Form of the Probability Operating Substrate

## Section One　Purpose and the Single Task

In a really runnable Sedimentation-Field dynamical system, to construct explicitly an operating substrate in which the probability qualification, current action and cross-time dynamics used earlier by the Probability Group-Form can all be formed, maintained, changed and read out endogenously from actual running history, thereby showing item by item that these objects are not dangling symbols.

The overall construction is written:

Spec\_ProbB = Augment(Spec\_LDB, A\_Prob)

Spec\_LDB is the running layer prescribed by the sealed Law-Dynamics operating substrate: actual running, trace, sedimentation and decay, formation of Law. A\_Prob is the probability-side increment added here, in two sub-layers:

A\_Prob = A\_Prob^run ∪ A\_Prob^read

A\_Prob^run is the conservative running increment: the per-dimension sedimentation of common binding BindSed, and the wiring of the probability organization to the continuation kernel (org / external). They operate by the same rules as the running layer, sedimenting only through traces left by actual traversal, or acting on the field as legal operations.

A\_Prob^read is the read-only increment: formal dimensions, D, B, R, minimal sufficient groups, the rate-bearing organization, decision-time witnesses, read-outs of action and dynamics, and layered coverage certificates.

The increment layer does not rewrite, replace or bypass the causal chain of the running layer.

Probability is not redefined here, The General Form of Probability and The Necessity Form of Probability are not proven anew, nor are the objects of the texts on Probability-Action and Probability-Dynamics established anew; the meanings of D, B, R, ProbabilityAct and ProbabilityDyn are all taken over from the sealed upstream.

Two levels are distinguished here, and no one symbol is allowed to denote both:

Formal inheritance target: Spec\_ProbB = Augment(Spec\_LDB, A\_Prob). Its byte-level inheritance from the sealed source fldb\_v1\_12.py is at present PENDING RAW SOURCE (Section Eleven); this is an integration matter of external implementation.

Reference construction: Spec\_ProbB^ref = Augment(F\_ref, A\_Prob^run, A\_Prob^read), abbreviated below as Augment(F\_ref, A\_Prob). F\_ref is the minimal Sedimentation-Field of Appendix A. Section 3.0 lists the minimum running-layer interface I\_LDB^Prob actually invoked here and proves F\_ref ⊨ I\_LDB^Prob. Theorems One and Two are borne by Spec\_ProbB^ref, with the strength of construction.

So the temporary absence of the source is not a gap of the theoretical objects or of the reference construction here; what is to be done after obtaining the source is to redo the same increment on the sealed Spec\_LDB and check that it likewise satisfies I\_LDB^Prob.

### 2.2 Causal direction

The construction fixes the following causal direction:

actual running → trace → sedimentation / decay → formation of Law (Law-bearing) → probability organization → Rel\_ρ → continuation → read-out

Any reverse structure is prohibited: Probability → continuation; RateDyn → field update; D, B, R → sedimentation; reader → trace or sedimentation. Direct writing into Probability, ProbabilityAct, Rel\_ρ, RateDyn, QualStructDyn, D, B, R is prohibited. Readers only read the real history that has already occurred in the system.

With another set of legal parameters or representations, the construction must still satisfy the item-by-item verification of Section Five.

## Section Three　Construction Procedure

3.0 The minimum running-layer interface I\_LDB^Prob and semantic conformance

The running-layer interface actually invoked here has only the following seven items:

L1　Actual running record: every tick has a unique actual route, and records the run, branch, protocol and moment.

L2　Trace is the actual route: what leaves a trace is exactly the path actually walked; there is no other source of sedimentation.

L3　Sedimentation and decay: the amount of sedimentation accumulates monotonically with actual traversal and decays with time.

L4　Formation of Law obtained only from history: whether a path has formed a Law is judged only by its own sedimentary state, not by any read-out or label.

L5　The generation kernel reads sedimentation: the generation weights at continuation are computed from the sedimentary state and actually enter branch selection.

L6　Legal operations act on the field: there exists a set of legal operations (availability, masking, freezing, channel and kernel wiring) that change only the field and write into no derived predicate.

L7　Conservative extension: the attached read-out layer changes no subsequent state of the running layer.

Proof of F\_ref ⊨ I\_LDB^Prob (corresponding item by item to Appendix A): L1 is given by the event log of execute(), one entry per tick, containing run, branch, protocol and moment, its completeness verified by C1; L2 is given by execute() invoking sedimentation only for the paths in actual; L3 is given by \_sediment\_edge() and decay\_step(); L4 is given by law\_bearing\_edge() reading only (g, rep); L5 is given by kappa\_edge(), carrier\_raw() and the continuation kernel select\_from\_relation(), the relation in group 2 of the fork changing with actual continuation and deciding the next selection; L6 is given by the legal operation set of execute(), none of which writes into Probability, ProbabilityAct, Rel\_ρ, D, B, R or dynamics readings; L7 is given by T7 and group 6 of the fork: a copy that repeatedly invokes all readers (including the coverage certificates) and a copy that does not have the same state after the same events.

Note: binding sedimentation BindSed and the continuation-kernel wiring (org / external) belong to the running sub-layer A\_Prob^run, not to the read-only sub-layer A\_Prob^read. The former is the same rule of L2, L3 acting on "the carrier–coordinator pairs jointly traversed by one and the same event"; the latter is one legal operation of L6. Both are conservative: they write into no probability-side reading. When redone on the sealed Spec\_LDB, these two items must be realized by its own structures and likewise satisfy I\_LDB^Prob; this belongs to the pending source integration.

3.1 The running layer (F\_ref and A\_Prob^run)

The field consists of a number of directed paths, each with a sedimentary state (g, d, rep, avail, mask):

carrier paths: each candidate dimension v has a set of carriers v1, v2, …; they bear the continuation dimensions;

coordination paths: G0, G1, bearing the common generation schema;

out-of-domain paths: O1, …, ON, other successors at the same Continuation-Position, not belonging to the candidate probability organization;

binding sedimentation BindSed(g, v): the binding trace between coordinator g and dimension v.

At every tick: first all sedimentation decays (g, d multiplied by 1 − decay rate); then a trace is left according to this tick's actual route: for every path on the route, g ← g + α\_g(1 − g), d ← d + α\_d(1 − d), rep ← rep + 1; if one and the same event traverses at once a carrier of some dimension v and the coordinator g, BindSed(g, v) likewise leaves a trace and sediments. The trace is exactly the route actually walked; there is no other source of sedimentation.

A path forms a Law if and only if g ≥ 0.55 and rep ≥ 3.

The legal operations are only: setting the avail or mask of some carrier; freezing or unfreezing sedimentation; switching on or cutting off the channel from the organization to the generation kernel (Coupling); setting the continuation-kernel wiring (Selector: org or external). These operations all act on the field; none writes into any probability-side reading.

### 3.2 The continuation kernel

Each tick can be: an externally specified route (exo-carrier, exo-outside, one running of the field driven from outside); endogenous continuation (endo); an idle tick (idle, decay only).

Endogenous continuation: take the relation object of the tick, Rel\_decision (normalized from the generation weights of the current formal dimensions); if the wiring is org, select the formal dimension with the greatest weight in Rel\_decision; if the wiring is external, an external mechanism specifies the branch among the same formal dimensions in its own order. Then, among the available formal carriers of the selected dimension, take the one with the greatest generation kernel, which together with the current formal common schema makes up the actual route.

Execution can be wholly deterministic. Whether probability holds is not conditioned on ontological randomness.

3.3 The probability-side read-only increment A\_Prob^read

Formal dimensions: V\_P = { v: v has at least one carrier that has formed a Law }. A current rate of zero does not make a dimension exit V\_P.

Formal common schema: the coordinator g has itself formed a Law, and for each dimension v in the current V\_P, BindSed(g, v) has formed a Law. A coordinator that has only itself formed a Law is not a common schema.

Relation object: in weight mode, Rel\_ρ is taken as the positive-scaling class \[w\]\_ρ of the raw generation-weight vector: w⁺ ∼\_ρ w⁻ if and only if there exists a \> 0 with w⁺ = a·w⁻. The decimals displayed are only for display and bear no object identity.

Minimal sufficient groups MinSuff\_ρ: enumerate subsets of all formal generation factors of the organization; if, on a copy, keeping only the contribution of subset S and ablating the other organization factors yields a relation of the same class as the relation of the whole organization, then S is sufficient; if S is sufficient and has no sufficient proper subset, S belongs to MinSuff\_ρ.

Rate-bearing certificate: RateBearCert = RateDomainQual ∧ RelForm ∧ ActualOrgContribution ∧ SameWitnessBind. ActualOrgContribution: there exists G ∈ MinSuff\_ρ each of whose factors is a formal carrier of some dimension of V\_P (SourceReal), and the continuation kernel reads exactly the relation formed by this organization (EvalRateBind, that is, the wiring is org). It is not required that every dimension have a positive contribution.

Read-outs: D = \[ \|V\_P\| ≥ 2 \]; B = D ∧ \[ there exists a formal common schema \]; R = D ∧ B ∧ RateBearCert; Probability = D ∧ B ∧ R.

Decision-time witness: each endogenous continuation records Rel\_decision, the selected dimension, the selected carrier, the coordinator and the generation contributions, together with the witness key made up of run, branch, protocol and moment. This is a log and does not enter the causal layer.

Action read-out (four gates): an event signs ProbabilityAct = 1 if and only if

G\_dim: the carrier walked is, at decision time, a formal carrier of some dimension of V\_P;

G\_bind: the coordinator walked is the formal common schema at decision time;

G\_gen: the branch selected is exactly the output of the organization selector applied to the decision-time relation object Rel\_decision, the wiring being org;

G\_same: the relation, the selected dimension, the carrier, the coordinator and the actual event belong to one and the same witness.

G\_gen is an implementation gate used by this reference implementation to exclude external selectors sufficiently, not the general ontological definition of ProbabilityAct: what upstream prohibits is an external mechanism deciding the relative generation among the dimensions in place of the organization; an external trigger of an input is not thereby prohibited.

Rate-bearing organization: the frozen identity projection π\_role: carrier → Law role, given before the instance enters running; during running no legal operation can rewrite it. For each G ∈ MinSuff\_ρ take π\_role(G), remove duplicates to obtain the family of hyperedges ℋ\_ρ, the role set RoleSet\_ρ being its union:

RateBearOrg = ( RoleSet\_ρ, ℋ\_ρ )

Which carriers have formed Laws is shown only as implementation information of the carrier organization (CarrierOrganization) and takes no part in the determination of dynamics.

Layered coverage certificates and three-valued read-outs: following The Mathematical Form of Probability-Dynamics, every negative reading can be signed 0 only when the coverage it depends on is 1; otherwise it is ⊥. The reference implementation gives the layered certificate coverage\_certificate, item by item: records of run and branch (traj), update records (upd), protocol (prot), evaluation index (idx), action records at both ends (act\_t0, act\_t1), action records of every unit within the sub-segment (act\_units, that is, Cov^Act(u)), relation readings (rel), snapshots of the dimension organization, common schema and bearing organization (dim, bind, bear), and same-witness keys (bindkey, that is, SamePDynBind\_k). If another run or branch appears in the records, traj = 0 (definite failure); if the records have a gap, traj = ⊥ (insufficient material), not 0.

The same-witness key is implemented as the step-level key of The Mathematical Form of Probability-Dynamics: K\_k = (anchor, RunID, η, t\_k, t\_{k+1}, I\_k, Γ\_PDyn), the anchor being (candidate 𝒫, C, 𝔯\_P). Every evaluation snapshot carries a frozen identity (anchor, run, branch, η, Γ\_PDyn, moment); the load-bearing snapshots of Rel, formal dimensions, common schema and bearing organization are all obtained from endpoints carrying identity. SamePDynBind\_k = 1 if and only if the identities of the snapshots at both ends belong to K\_k, and every event within I\_k carries the same run, branch and protocol, its moment falling within I\_k; any definite inconsistency of identity gives 0, any missing identity material gives ⊥. So snapshots with exactly the same values, if taken from another run or another candidate, cannot be stitched to the records of this segment either. Three-valued read-outs act3, step\_act3, classify3: a positive reading takes 1; a negative reading takes 0 only when the corresponding coverage is 1, otherwise ⊥; if one item of the basic coverage of running-layer records is 0, the dynamics readings of that step are 0 (the legal dynamics segment does not hold); if one is ⊥, all are ⊥.

Dynamics read-out (adjacent evaluation points k → k+1):

Contact = Probability\_k ∨ Probability\_{k+1};

ActDyn: read only when Probability is 1 at both ends, endpoint signatures not standing in. The action evaluation granularity takes one tick as one unit, dividing the adjacent sub-segment I\_k into units u; the unit reading a\_u is the action read-out of that tick's event (0 for externally driven or idle ticks, by the four gates for endogenous continuation, ⊥ when the record is incomplete); the endpoint reading A\_k is the unit reading of the tick at the evaluation point. The step state follows The Mathematical Form of Probability-Dynamics:

Start: A\_k = 0, A\_{k+1} = 1, and OnsetBind\_k = 1 (the unit entering 1 from 0 is an endogenous continuation, joined to a legal update carrying the same witness key);

Continue: A\_k = A\_{k+1} = 1, and a\_u = 1 for every unit within I\_k;

Stop: A\_k = 1, A\_{k+1} = 0, and CessationBind\_k = 1 (the unit entering 0 from 1 is a legal update carrying the same witness key);

Idle: A\_k = A\_{k+1} = 0, and a\_u = 0 for every unit within I\_k;

other cases are ⊥. Endpoints 1 → 1 are only an endpoint signature, not a sufficient condition of Continue; endpoints 0 → 0 with action in between do not sign Idle, and are ⊥ under the current frozen granularity.

SameRel: the raw weights at both ends belong to one positive-scaling class; RateDyn = Contact ∧ ¬SameRel;

DimStructDyn = Contact ∧ \[ V\_P changes \]; BindStructDyn = Contact ∧ \[ the set of formal common schemas changes \];

RateBearingStructDyn = Contact ∧ SameRel ∧ \[ RateBearOrg changes \];

No double signing: once the relation changes, RateBearingStructDyn = 0, and the step belongs only to RateDyn.

Coverage: Coverage = Σ\_{v∈V\_P} w\_v / M\_C, M\_C being the sum of the generation masses of the probability dimensions and of the out-of-domain successors that have formed Laws at the same Continuation-Position; out-of-domain successors do not automatically enter V\_P.

3.4 Order of execution of the construction procedure

One, establish the field: candidate dimensions and their carriers, coordinators, binding sedimentation, (when needed) out-of-domain paths; freeze π\_role.

Two, form qualification by actual running: let the carriers and coordinators of the dimensions be walked repeatedly in one and the same event, until the carriers, the coordinators and every pair of bindings cross the threshold of Law formation.

Three, read out D, B, R and Probability.

Four, continue actual running in the same field: idle ticks, endogenous continuation, externally driven new paths and new coordinators, new carriers.

Five, read out at every evaluation point, and read out dynamics for adjacent evaluation points.

Every step is code in Appendix A executable line by line; no step is an existential assumption.

## Section Four　Step-by-Step Execution: the Sediment-Fork Instance

This instance is the actual running witness of the construction theorems; the path names used are only names within the instance, not new ontological objects. The Continuation-Position is Fork, the candidate dimensions Left and Right, and later a third new path NewRoute appears. The following values are all taken from the actual run records of Appendix B.

### 4.1 How probability really forms

Initial state: V\_P = ∅, D = B = R = 0, Probability = 0.

Actual history: Left via G0 walked 8 times, Right via G0 walked 6 times. Each time is actually walked → trace left → sedimentation. After the two carriers, the coordinator G0 and the bindings of G0 to Left and Right all cross the threshold of Law formation (t = 14):

V\_P = {Left, Right}, D = B = R = 1, Probability = 1

The relation reading is Left 0.5407825821, Right 0.4592174179. This is not a preset probability table, but the reading after the sedimentary state has entered the generation relation. The process of formation is wholly completed by externally driven routes, so no step in this segment signs ProbabilityAct: an externally specified route is not action of the probability organization.

### 4.2 Shifts of action and rate relation

t = 15, idle tick: Probability = 1, ProbabilityAct = 0; the relation is 0.5407622813 / 0.4592377187 (changed slightly by decay).

t = 16, endogenous continuation: the field selects Left by the decision-time relation and actually continues through Left1 and G0. All four action gates pass; ProbabilityAct goes from 0 to 1, ActDyn = Start. Since Left really occurred and again left a trace and sedimented, the relation becomes 0.5553193534 / 0.4446806466, RateDyn = 1.

t = 17, another endogenous continuation, still taking Left: ActDyn = Continue; the relation becomes 0.5669598887 / 0.4330401113.

t = 18, idle tick: ProbabilityAct goes from 1 to 0, ActDyn = Stop; the relation becomes 0.5669268102 / 0.4330731898 through decay, RateDyn = 1.

This segment shows: probability is not a value given in advance; the value is a read-out of the actual sedimentary structure on the subsequent generation relation. The causal direction is Left actually occurs → Left leaves a trace → the sedimentation of Left changes → the generation relation changes → the next continuation changes; it is not modifying p(Left) and then drawing lots by probability. Actual execution lands on only one path, and this does not make the other formal probability dimensions vanish.

### 4.3 How a new path enters probability

NewRoute is at first a runnable path, but without formal Law-bearing, not belonging to V\_P. NewRoute1 is walked continuously (via G0) driven from outside; at the 4th repetition (t = 21 → 22), NewRoute1 and the binding G0—NewRoute both cross the threshold of Law formation:

V\_P changes from {Left, Right} to {Left, Right, NewRoute}, DimStructDyn = 1

The new relation reading is Left 0.4234235569, NewRoute 0.2529506890, Right 0.3236257541, with RateDyn = 1 at the same step. G0 is already bound to NewRoute when NewRoute enters the dimensions, so the formal common schema is still G0, and B stays 1. These four steps are all externally driven routes, and the action readings are all 0, the reason being externally specified routes.

It is not the program that adds NewRoute to V\_P; it is NewRoute that obtained formal Law-bearing through actual occurrence, trace, sedimentation and re-walking.

### 4.4 Reorganization of common binding

In the same field, let Left1, Right1, NewRoute1 actually run in turn through a second coordinator G1, each walked once per cycle. G1 has itself formed a Law by the 2nd cycle (which is why the 2nd cycle was earlier mistaken for the point of common binding), but the formal common schema requires that the bindings of G1 to each of the three dimensions have formed Laws: each dimension passes through G1 only once per cycle, and after the 3rd time the binding sedimentation is about 0.525, still below the threshold 0.55; only at the 4th cycle (t = 31 → 34) do they all cross:

the formal common schema changes from {G0} to {G0, G1}, BindStructDyn = 1

The relation at this step changes from Left 0.3788293960, NewRoute 0.2911703876, Right 0.3300002164 to 0.3696708777, 0.2994064137, 0.3309227086, with RateDyn = 1 at the same time; upstream does not prohibit RateDyn and BindStructDyn from holding at once. G1 holds not by switching a schema label, but by the three dimensions all actually running through G1 and leaving binding sedimentation.

4.5 Reorganization of the rate-bearing organization

Take another instance of the same fork specification, with decay rate 0 (a choice made by the reference implementation to construct exact SameRel, not a requirement of probability theory that there be no decay). Left1, Right1, NewRoute1 each walked 6 times via G0; then:

RateBearOrg⁻ = ({Left1, NewRoute1, Right1}, {{Left1, NewRoute1, Right1}})

Then Left2, Right2, NewRoute2 each walked 6 times via G0, becoming a second set of formal Law-bearing carriers; π\_role projects each of them as a separately qualified Law role. Taking any one carrier per dimension suffices to maintain the same relation, so there are 2³ = 8 minimal sufficient groups:

RateBearOrg⁺ = ({Left1, Left2, NewRoute1, NewRoute2, Right1, Right2}, eight hyperedges)

The raw weights satisfy w⁺ = 2·w⁻; the relation is 1/3, 1/3, 1/3 before and after, SameRel = 1. Hence RateBearingStructDyn = 1, RateDyn = 0 (5a).

Contrast 5d: walk exactly the same physical history, but π\_role is frozen as Left2 ↦ Left1, Right2 ↦ Right1, NewRoute2 ↦ NewRoute1, that is, the second set of carriers are only implementation copies of the roles of the first set. Then the carrier organization changes and the relation does not, while the projected family of hyperedges is {{Left1, NewRoute1, Right1}} before and after: RateBearingStructDyn = 0, RateDyn = 0. "One more implementation copy" is not "a change of the rate-bearing organization".

Contrast 5b: add only Left2, and the relation becomes 0.5 / 0.25 / 0.25. The bearing organization also changes, but SameRel = 0, so only RateDyn = 1 is signed, RateBearingStructDyn = 0, no double signing.

Re-reading 5c: a construction from early in research (adding a second set of carriers under asymmetric history and non-zero decay) changes the carrier organization, but the relation also changes from 0.3697456302 / 0.3161228943 / 0.3141314755 to 0.3516650279 / 0.3247243002 / 0.3236106719, so it belongs to RateDyn, not to RateBearingStructDyn. The judgment is changed here truthfully; the old signature is not kept for the sake of the old interpretation.

### 4.6 Two controls

Read-outs are non-causal: two instances are copied from the same state; one invokes the qualification read-out, the rate-bearing certificate and the minimal sufficient group read-out 100 times each in succession, the other does not; then the same 5 endogenous continuations are given. The underlying sedimentary states of the two are wholly the same. The basic regression T7 additionally invokes the action read-out and the layered coverage certificate as well, with the same conclusion (V18).

Ablation of the organization channel: on the state of 4.1, cut off only the channel from the organization to the generation kernel: D = 1, B = 1, but R = 0, Probability = 0, and Rel is no longer formed. The dimensions and common binding are still there; what is lost is rate bearing. Probability is not a hard-coded label.

def proportional(w0, w1, tol=1e-12):
    """True iff the raw weight vectors (dicts over the same keys) satisfy ∃a>0: w1=a·w0."""
    if w0 is None or w1 is None or set(w0)!=set(w1): return False
    s0=sum(w0.values()); s1=sum(w1.values())
    if s0<=0 or s1<=0: return False

    Writes none of: Probability, ProbabilityAct, Rel_rho, D, B, R, Law, Degree,
    g, d, rep, Om, pathdyn, or any FLDB target label."""
    def __init__(self,m,F,*,candidate_id,C,rate_domain,dimensions,coordinators,
                 protocol_id="ProbDyn-P0"):
        self.m=m; self.F=F; self.candidate_id=candidate_id; self.C=C
        self.rate_domain=rate_domain; self.dimensions=copy.deepcopy(dimensions)
        self.coordinators=copy.deepcopy(tuple(coordinators)); self.protocol_id=protocol_id
        self.run_id=f"fldb-object-{id(F)}"; self.branch_id="actual"; self.events=[]

    # ---------- pure readers ----------
    def _edge_formal(self,e,F=None):
        F=F or self.F; vals={}
        for name in ("Deposited","Groove"):
            fn=getattr(F,name,None); vals[name]=(bool(fn(e)) if callable(fn) else None)
        vals["Avail"]=F.Avail[e] if hasattr(F,"Avail") and e in F.Avail else None
        return vals
    def dim_law_ok(self,dim,F=None): return bool(self.dimensions[dim]["law_cert"](F or self.F))
    def V(self,F=None): return tuple(d for d in self.dimensions if self.dim_law_ok(d,F))
    def active_schema_set(self,F=None):
        out=[]
        for s in self.coordinators:
            ok=all(self._edge_formal(e,F)["Deposited"] is True and self._edge_formal(e,F)["Groove"] is True
                   and self._edge_formal(e,F)["Avail"]!=0 for e in s["required_edges"])
            if ok: out.append(s["id"])
        return tuple(out)
    def D(self,F=None): return len(self.V(F))>=2
    def B(self,F=None): return self.D(F) and len(self.active_schema_set(F))>0
    def _dim_kappa(self,dim,F=None):
        F=F or self.F; vals=[]
        for e in self.dimensions[dim]["carrier_edges"]:
            if e not in F.E: return None
            k=F.kappa(e)
            if not math.isfinite(k) or k<=-1e8: return None
            vals.append(k)
        return min(vals) if vals else None
    def weight_vector(self,F=None):
        ans=[]
        for d in self.V(F):
            w=self._dim_kappa(d,F)
            if w is None: return None
            ans.append((d,max(0.0,w)))
        return tuple(ans)
    def rel_rho_weight(self,F=None):
        w=self.weight_vector(F)
        if w is None: return None
        tot=sum(v for _,v in w)
        if tot==0: return tuple((d,0.0) for d,_ in w)
        return tuple((d,round(v/tot,12)) for d,v in w)
    def bear_org(self,F=None):
        F=F or self.F
        return tuple((d,tuple(e for e in self.dimensions[d]["carrier_edges"]
                              if self._edge_formal(e,F)["Avail"]!=0))
                     for d in sorted(self.V(F)))
    external_selector=False   # set True only if the caller declares an outside mechanism deciding branches

    def _proportional(self,r0,r1):
        if r0 is None or r1 is None: return False
        d0=dict(r0); d1=dict(r1)
        if set(d0)!=set(d1): return False
        return all(abs(d0[k]-d1[k])<=1e-12 for k in d0)

    def rate_bearing_certificate(self):
        if not self.B(): return False,{"reason":"no organization"}
        w=self.weight_vector(); rel0=self.rel_rho_weight()
        rel_form = w is not None and sum(v for _,v in w)>0
        if not rel_form: return False,{"reason":"RelForm fails"}
        if not hasattr(self.F,"Avail"): return False,{"reason":"no Avail channel to ablate"}
        from itertools import combinations
        dims_pos=[d for d,val in w]
        def suff(S):
            X=copy.deepcopy(self.F)
            for d in dims_pos:
                if d in S: continue
                for e in self.dimensions[d]["carrier_edges"]:
                    if e in X.Avail: X.Avail[e]=0
            return self._proportional(rel0,self.rel_rho_weight(X))
        MS=[]
        for k in range(1,len(dims_pos)+1):
            for S in combinations(dims_pos,k):
                if any(set(T)<=set(S) for T in MS): continue
                if suff(set(S)): MS.append(S)
        G=MS[0] if MS else ()
        eval_bind = not self.external_selector
        cert = bool(G) and eval_bind
        return cert,{"RateDomainQual":True,"RelForm":True,"MinSuff":tuple(MS),"witness_group":tuple(G),
                     "SourceReal":bool(G),"EvalRateBind":eval_bind,"SameWitness":True}
    def R(self):
        if not self.B(): return False
        return self.rate_bearing_certificate()[0]
    def Probability(self): return self.D() and self.B() and self.R()
    def snapshot(self):
        return {"t_run":getattr(self.F,"t_run",None),"candidate":self.candidate_id,"C":self.C,
                "rate_domain":self.rate_domain,"protocol":self.protocol_id,"V":self.V(),
                "D":self.D(),"B":self.B(),"R":self.R(),"Probability":self.Probability(),
                "schema_set":self.active_schema_set(),"Rel":self.rel_rho_weight(),
                "W":dict(self.weight_vector() or ()) or None,
                "rate_bear_org":(self.rate_bearing_certificate()[1].get("MinSuff") if self.B() else None),
                "bear_org":self.bear_org()}

    # ---------- actual occurrence binding ----------
    def pulse(self,*args,prescribed_route=False,**kwargs):
        """prescribed_route=True must be passed whenever the caller dictates the
        branch; such events are recorded but can never be ProbabilityAct."""
        before=self.snapshot()
        route,inst=self.F.pulse(*args,**kwargs)
        after=self.snapshot()
        ev={"run_id":self.run_id,"branch_id":self.branch_id,"protocol":self.protocol_id,
            "t_run":getattr(self.F,"t_run",None),"route":tuple(route),"inst":tuple(inst),
            "prescribed_route":bool(prescribed_route),"pre":before}
        self.events.append(ev); return before,after,ev
    def probability_act(self,ev):
        pre=ev["pre"]
        if ev["prescribed_route"]: return False,"G_gen: externally prescribed route"
        if not pre["Probability"]: return False,"pre-event Probability not established"
        es=set(zip(ev["route"],ev["route"][1:]))
        hits=[d for d in pre["V"] if set(self.dimensions[d]["carrier_edges"])<=es]
        if len(hits)!=1: return False,"G_dim: route does not traverse exactly one formal dimension"
        stand=[s for s in self.coordinators if s["id"] in pre["schema_set"]
               and set(s["required_edges"])&es]
        if not stand: return False,"G_bind: no standing common schema on the route"
        if self.external_selector: return False,"G_gen: branch decided by an external selector"
        if pre["Rel"] is None or hits[0] not in dict(pre["Rel"]):
            return False,"G_gen: branch not produced from the organization's relation"
        if ev["run_id"]!=self.run_id or ev["protocol"]!=self.protocol_id:
            return False,"G_same: witness key mismatch"
        return True,"ok"

    @staticmethod
    def dyn_compare(s0,s1,act0,act1):
        contact=s0["Probability"] or s1["Probability"]
        actdyn=None
        if s0["Probability"] and s1["Probability"]:
            if (not act0) and act1: actdyn="Start"
            elif act0 and act1: actdyn="Continue"
            elif act0 and (not act1): actdyn="Stop"
        def prop(w0,w1):
            if not w0 or not w1 or set(w0)!=set(w1): return False
            a0=sum(w0.values()); a1=sum(w1.values())
            if a0<=0 or a1<=0: return False
            return all(abs(w1[k]*a0-w0[k]*a1)<=1e-12*max(a0,a1)*max(1.0,max(w0.values()),max(w1.values())) for k in w0)
        rel_known=s0["W"] is not None and s1["W"] is not None
        same_rel=rel_known and prop(s0["W"],s1["W"])
        rate=bool(contact and rel_known and not same_rel)
        bear_diff=(s0["rate_bear_org"] is not None and s1["rate_bear_org"] is not None
                   and s0["rate_bear_org"]!=s1["rate_bear_org"])
        rbs=bool(contact and same_rel and bear_diff)
        assert not (rate and rbs), "double-sign forbidden"
        return {"ActDyn":actdyn,"RateDyn":rate,"DimStructDyn":bool(contact and s0["V"]!=s1["V"]),
                "BindStructDyn":bool(contact and s0["schema_set"]!=s1["schema_set"]),
                "BearOrgDiff":bear_diff,"SameRel":same_rel,"RateBearingStructDyn":rbs}
