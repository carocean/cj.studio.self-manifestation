# The Stability Form of Probability

## Section One　Purpose

To prove: for an already holding Probability (initial state Probability = 1), under a stability instance Ξ\_PSt frozen in advance (domain of permitted variation, qualification protocol, stability protocol, recovery deadline and continued verification), the preservation, failure and recovery of its qualification satisfy the following conclusions, and to obtain construction witnesses on the reference construction Spec\_ProbB^ref of the fourteenth text:

One, stability is not invariance. There exist legal trajectories with ProbabilityDyn = 1 and Stable^set\_Prob = 1; the occurrence of any of RateDyn, DimStructDyn, BindStructDyn, RateBearingStructDyn does not imply that qualification loses stability.

Two, grading of the fixed-realization layer and the existence layer. Q^fix\_P(k) = 1 ⇒ Q^set\_P(k) = 1, the converse not holding; when both layers are decidable and the first actual failures of both exist, k\_f^fix ≤ k\_f^set; the recoveries of the two layers cannot be inferred from each other.

Three, the conditions of recovery. Recover^x = 1 if and only if: a first actual failure has occurred; after it, and within the recovery deadline, there exists a point of return; the same stability instance has not been rewritten; after return, the minimum confirmation window is passed, and the qualification is kept to the end of the observation domain.

Four, the determination formula of stability. Stable^x = Keep^x ∨₃ Recover^x, x ∈ { fix, set }; dynamic-type states have separately a stability determination carrying only trajectory quantifiers. When material is incomplete, ⊥ is taken, not 0.

Five, quantifier levels. The determinations above are given separately under three quantifiers — a single trajectory, a declared trajectory family and all legal trajectories — none implying another.

Form-kind: Stability Form, auxiliary form. What it proves is the preservation and return of an established qualification under variation, not first existence, first reachability or first occurrence; SuppReach = 1 of the fifteenth text does not imply stability.

## Section Three　Stability Objects and the Original Qualification

### 3.1 Two classes of stability object

Θ\_PSt = Θ^state\_PSt ∪ Θ^step\_PSt.

State-qualification layer: Θ^state\_PSt = { Probability }.

Dynamic-type layer: Θ^step\_PSt = { Start, Continue, Stop, RateDyn, DimStructDyn, BindStructDyn, RateBearingStructDyn }.

Probability is a state qualification; the rest are all event-level or evaluation-step-level objects, not written as static state variables. The main line is the stability of Probability qualification; dynamic-type stability is a subordinate section (Section Nine).

### 3.2 Qualification realization

The object of stability review E\_k^P is one complete realization of Probability qualification at the k-th stability evaluation point:

E\_k^P = (E\_D, E\_B, E\_R)\_k

E\_R: one minimal sufficient group projected through the frozen π\_role, that is, one hyperedge h of the current RateBearOrg;

E\_B: one formal common schema g;

E\_D: for each dimension in V\_P, the non-empty set of formal Law-bearing roles of that dimension used by h; for a dimension not used by h (a zero-rate dimension), one of its own formal Law-bearing roles is taken.

E^P only unfolds the sealed positive qualification structure of D, B, R into one combination that can be pointed out item by item: the formal probability dimensions, Law-bearing roles, formal common binding, RateBearOrg and rate-bearing certificate it cites all come from upstream; it is not a new ontology of probability.

Qualification certificate ProbCert(E^P; X\_k, Γ\_qual) = 1 if and only if on the state X\_k Probability = 1, and E\_D, E\_B, E\_R all hold on X\_k in the manner above. The set of current legal realizations:

𝓔^P\_k = { E^P: ProbCert(E^P; X\_k, Γ\_qual) = 1 }

When completeness is insufficient, "not found" is not read as the empty set (Section Six). In the reference implementation the field is closed and the enumeration complete.

The initial realization E\_0^P is chosen in advance in the realization set 𝓔^P\_0 of the initial state and belongs to the stability instance; the reference implementation takes the lexicographically smallest one among them.

### 3.3 Four layers of identity

Event witness (the record of one continuation), physical realization (carrier), qualification realization (E^P), Probability qualification: the four layers are separated:

ImplementationReplacement ⇏ RealizationReplacement; RealizationReplacement ⇏ ProbabilityLoss.

So the identity of the fixed-object layer is not "exactly the same set of physical carriers". If a second set of carriers is, through π\_role, only implementation copies of the roles of the first set, using them instead does not change E^P (S6); if they are separately qualified roles, using them instead is a substitution of qualification realization, but Probability is not thereby lost (S7).

## Section Four　Stability Instance and Domain of Permitted Variation

### 4.1 Stability instance

Ξ\_PSt = (Spec, Prot, X\_0, χ̄\_P, E\_0^P, Δ\_PSt, Γ\_qual, Γ\_stab, 𝓗\_PSt)

Δ\_PSt: the domain of permitted variation; Γ\_qual: the qualification read-out protocol (the read-outs and certificates of the fourteenth text); Γ\_stab: the stability observation and evaluation protocol (evaluation points, observable range, interval certificates); 𝓗\_PSt: stability parameters such as the recovery deadline T\_rec, the minimum confirmation length h^x of the qualification layer, the minimum confirmation length h\_θ of the dynamic type, the observation domain and trajectory quantifiers. Γ\_qual and Γ\_stab are separated; one Γ is not used for both.

Modifying any of χ̄\_P, Δ\_PSt, Γ\_qual, Γ\_stab or 𝓗\_PSt during running is changing the stability task, not a legal disturbance within the original instance (S17).

### 4.2 Domain of permitted variation

What can be declared in advance: sedimentation and decay; formal carriers entering or exiting; the start, continuation and stop of action; RateDyn, DimStructDyn, BindStructDyn, RateBearingStructDyn; implementation substitution; substitution of qualification realization; the existing legal field operations (availability, masking, freezing, unfreezing, channel, kernel wiring); changes of out-of-domain successors.

Prohibited: directly writing g, d, rep, BindSed; directly writing Probability, D, B, R, Rel\_ρ; directly writing dynamics readings; modifying CandidateID, C or the rate domain; modifying π\_role during running; rewriting logs to manufacture evidence; modifying the stability protocol after the fact.

4.3 Recomputing qualification after variation

After each step of variation, the qualification and the realization set are recomputed on the new state according to the read-outs of the fourteenth text and the definition of 3.2; the recomputation rule itself does not change with the trajectory.

## Section Five　Levels of Instantaneous Preservation

Object axis x ∈ { fix, set }:

Q^fix\_P(k) = 1 if and only if E\_0^P ∈ 𝓔^P\_k;

Q^set\_P(k) = 1 if and only if 𝓔^P\_k ≠ ∅.

Quantifier discipline: ∃E\_0 ∀k (the same realization is present at every evaluation point) differs from ∀k ∃E\_k (at every evaluation point there is some realization); only the former is fix, the latter supports only set. In the reference implementation, Q^set\_P(k) = 1 agrees with Probability = 1 at that point.

## Section Six　Dynamic Trajectories, Observation Windows and Decidable Domains

### 6.1 Decidable domains

DynDom^fix\_PSt(γ) and DynDom^set\_PSt(γ) are defined separately, and the two are not equivalent: determining whether the original realization is still present is easier than proving that no substitute realization exists at all, so one can have DynDom^fix = 1 while DynDom^set = ⊥. set = 0 must rest on the complete candidate domain already being decidable and all candidates failing; without searching completely, only ⊥.

Three-valued discipline: DynDom ≠ 1 ⇒ Keep = Recover = Stable = ⊥; only when DynDom = 1 do Keep, Recover, Stable take 0 or 1.

The distinction of the decidable domains of the fix and set layers belongs to the general regime of stability. In the current closed reference field, the enumeration of qualification realizations is complete, and the material needed by the two layers happens to be complete at the same time, so in the instances of Appendix A the decidable domains of the two layers are always 1 together or ⊥ together, constituting no instance of their separation.

### 6.2 Stability coverage

Stability is an interval property and cannot be judged by comparing only first and last: if Probability(t\_0) = 1 and Probability(t\_2) = 1 while in between Probability(t\_1) = 0, Keep = 1 cannot be signed. So stability coverage is stronger than ordinary evaluation coverage:

StableCoverage(γ, Γ\_stab) = 1 if and only if every running step that may change qualification is directly evaluated; or every sparse evaluation interval has a verified interval certificate. Otherwise StableCoverage = ⊥, DynDom = ⊥.

An interval certificate is an external object: CertInterval = { (t, Q^fix(t), Q^set(t), task anchor) }, given by an independent issuer. It is accepted only when the following five items all hold: one, it covers every running step within the interval, without gaps; two, every entry carries the anchor of the same stability task; three, the qualification reading of every entry is decidable (0 or 1); four, it covers the whole sparse interval; five, every entry agrees with the result of read-only recomputation. Lacking any item, StableCoverage = ⊥. A certificate is verified, not believed: declaring "there is a certificate" does not itself raise coverage.

In the reference implementation: evaluation at every running step gives StableCoverage = 1; sparse evaluation without an interval certificate gives ⊥ (S11: first and last both 1, failure at tick 16 in between, the sparse read-out ⊥, the tick-by-tick read-out Keep = 0); sparse evaluation with a verified interval certificate is decidable, Keep^set = 0, the failure at tick 16 (S11b); forging tick 16 of the certificate as 1, or deleting the entry for tick 16, fails verification, giving ⊥ (S11c); containing running steps unobservable by the protocol also gives ⊥ (S16).

The endpoint-type evaluation of G\_Bear of the fifteenth text is not reused here to prove the preservation of qualification: there 18 running steps make up one evaluation step, and what is judged is a cross-step dynamic target, not continued qualification over an interval.

## Section Seven　Preservation, Failure Set and First Actual Failure

When DynDom^x\_PSt(γ) = 1: Keep^x = 1 if and only if Q^x\_P(k) = 1 for all review points k in the stability coverage domain (including evaluation points, and internal running steps covered by interval certificates); Keep^x = 0 if and only if there exists such a k with Q^x\_P(k) = 0. Otherwise Keep^x = ⊥. The failure set, first failure and recovery below are all taken on the same set of review points.

Failure set Fail^x\_γ = { k: Q^x\_P(k) = 0 }; ⊥ does not enter the failure set. On a discrete time domain, the first actual failure k\_f^x = min Fail^x\_γ. If the time domain is continuous, b\_f^x = inf Fail^x gives only a boundary, and b\_f^x ∈ Fail^x must be proven separately before it can be called a point of actual failure. The time domain of the reference implementation is discrete.

## Section Eight　Recovery and Stability

### 8.1 Recovery

Recover^x = 1 if and only if all of the following are satisfied:

One, a first actual failure k\_f^x has occurred;

Two, posterior return: there exists k\_r \> k\_f^x with Q^x\_P(k\_r) = 1; k\_r need not be the moment of first becoming 1 again after the failure, as long as the following items are satisfied;

Three, deadline: Dur(k\_f^x, k\_r) ≤ T^x\_rec, timing beginning at the first actual failure, a later failure not resetting the deadline; in the reference implementation Dur is counted in underlying running ticks, not in evaluation steps, the measure to be changed when continuous time is used in future;

Four, the same Ξ\_PSt has not been rewritten;

Five, continued verification after return: from k\_r on, Q^x\_P is 1 for at least h^x evaluation steps (the minimum confirmation window), and is kept by the protocol to the end of the observation domain, that is, Q^x\_P = 1 for all review points after k\_r up to the end of the observation domain. h^x is only the minimum confirmation length; passing h^x and then exiting again within the observation domain does not constitute stable recovery.

The reference implementation takes as k\_r the earliest candidate satisfying all the conditions (including being kept to the end of the observation domain) (first\_valid\_recovery). That the first reappearance does not pass continued verification does not exclude another legal return later within the original deadline; but the deadline is always timed from the first actual failure, and a later failure does not reset it. The qualification layer and the dynamic-type layer share this determination.

Returning only after the deadline: Reappear^x = 1, Recover^x = 0. Never having failed: Recover^x = 0; a system that has always been normal does not sign Recover = 1.

### 8.2 Stability

Stable^x\_PSt,γ = Keep^x\_PSt,γ ∨₃ Recover^x\_PSt,γ

Persistent^x ≡ Keep^x = 1; Resilient^x ≡ Fail^x ≠ ∅ ∧ Recover^x = 1. No separate "ontology of resilience" is set up.

## Section Nine　Dynamic-Type Stability

For θ ∈ { Start, Continue, Stop, RateDyn, DimStructDyn, BindStructDyn, RateBearingStructDyn }, read Q^θ\_γ(k) = Read\_θ(Z\_k) ∈ {1, 0, ⊥} on adjacent evaluation steps, and then define Keep^θ, Fail^θ, Recover^θ, Stable^θ in the same way as in Sections Seven and Eight.

fix / set are not used here: one RateDyn is not a realization persisting across windows. Dynamic-type stability has only the trajectory axis Λ ∈ { single, family, guaranteed }. The minimum confirmation length of dynamic-type recovery is declared separately as h\_θ, distinct from h^x of the qualification layer; the requirement of being kept to the end of the observation domain applies likewise.

Dynamic-type stability has its own decidable domain DynDom^θ\_PSt(γ): in the reference implementation it is 1 when the dynamic-type readings within the observation domain are all 0 or 1, otherwise ⊥. If within the observation domain the dynamic-type reading has a load-bearing ⊥ (for example the endpoint of some evaluation step being unobservable by the protocol), the trajectory is undecidable for this dynamic-type stability task, and Keep^θ, Recover^θ, Stable^θ all take ⊥; undecidable evaluation steps may not be deleted before judging recovery, otherwise the undecidable hole would be stepped over and recovery signed prematurely.

Example (S19): from the state in which action is under way (t = 16): endogenous continuation, endogenous continuation, idle tick, endogenous continuation, endogenous continuation. The readings of θ = Continue are in turn 1, 1, 0 (Stop), 0 (Start), 1. Keep^θ = 0; the first failure is at t = 19, return at t = 21, within the deadline 3. When h\_θ = 0 is declared, Recover^θ = 1, Stable^θ = 1. Contrast: if the same trajectory declares h\_θ = 2, there are not enough evaluation steps after return for verification, Recover^θ = 0; extending the trajectory by two more endogenous continuations, the continued verification of h\_θ = 2 passes, Recover^θ = 1.

## Section Ten　Levels of Trajectory Quantifiers

The main layer of Probability forms six combinations { fix, set } × { single, family, guaranteed }. "Probability is stable" is not written bare; the object layer and the trajectory-quantifier layer must be specified.

single: Stable^x\_γ on one trajectory γ.

family: FamilyStable^x(𝒢) = 1 if and only if Stable^x\_γ = 1 for all γ ∈ 𝒢; 0 when there exists γ ∈ 𝒢 with Stable^x\_γ = 0; ⊥ when the family is empty, membership in the family cannot be confirmed, or undecidable trajectories are mixed in without complete determination.

guaranteed: takes the status of a guarantee certificate. The full set of legal trajectories TrajLegal and its decidable subset TrajDec^x must both be delimited; only when TrajLegal ≠ ∅ and TrajLegal = TrajDec^x is the 1 / 0 determination entered: 1 when all Stable^x = 1, otherwise 0. Legal but undecidable trajectories may not be deleted; when there are such trajectories, ⊥.

Reference instances (Appendix B):

S13: a declared family of four dynamic trajectories (action and rate relation, new dimension, common binding, rate-bearing organization), FamilyStable^set = 1.

S14: from X\_P, with the permitted alphabet {endogenous continuation, idle tick}, all 16 trajectories of length 4 are decidable and all Stable^set = 1, Guaranteed^set = 1.

S15: with "cut off the organization channel" added to the alphabet, length 3, all 27 are decidable, among them trajectories that do not return after being cut off, Guaranteed^set = 0.

S16: with the alphabet {endogenous continuation, idle tick, unobservable idle tick}, length 3, only 8 of the 27 legal trajectories are decidable, Guaranteed^set = ⊥.

guaranteed here holds only for the declared finite trajectory space and is not extended to an infinitely long future.

## Section Eleven　Stability Boundary

The stability boundary is not conflated with the qualification limit boundary of the ninth text, The Limit Form of Probability. What is studied here are the actual exit points q^fix\_out, q^set\_out on the same disturbance axis of the same stability instance, and the reverse recovery points q^fix\_in, q^set\_in. Only after a boundary has actually been attained can an event-level statement be made; hysteresis is discussed only when q\_out and q\_in belong to the same frozen axis and the same protocol, both actually attained and unequal. No "hysteresis width" is constructed from two infima or suprema.

No specific stability boundary value is declared here for any disturbance axis; the above is only the discipline of boundary statements.

## Section Twelve　Stability Theorems

Theorem One　fix implies set

Q^fix\_P(k) = 1 ⇒ Q^set\_P(k) = 1; the converse does not hold.

Proof: E\_0^P ∈ 𝓔^P\_k implies 𝓔^P\_k ≠ ∅. Counterexample to the converse: S7, at tick 37 only the availability of Left1 is set to 0, the hyperedge of the original realization fails, Q^fix = 0, while a substitute realization borne by Left2 is present, Q^set = 1. □

Theorem Two　Order of first failures

If both layers are decidable, and the first actual failures of both layers exist, then k\_f^fix ≤ k\_f^set.

Proof: by the contrapositive of Theorem One, Q^set\_P(k) = 0 ⇒ Q^fix\_P(k) = 0, so Fail^set ⊆ Fail^fix, hence min Fail^fix ≤ min Fail^set. □ Checked point by point in actual runs (S20); example: in the second case of S12, k\_f^fix = 37, k\_f^set = 38.

Theorem Three　The recoveries of the two layers cannot be inferred from each other

Recover^fix = 1 ⇏ Recover^set = 1: the first case of S12, Left1 blocked at tick 37, the original realization fails, Left1 restored at tick 38, the original realization returns and is kept; the set layer never failed, Recover^set = 0.

Recover^set = 1 ⇏ Recover^fix = 1: the second case of S12, Left1 blocked at tick 37 (fix fails), the organization channel cut off at tick 38 (set fails), switched on at tick 39 (set returns within the deadline and is kept); Left1 stays blocked throughout, the original realization does not return, Recover^fix = 0. □

Theorem Four　Probability-Dynamics and qualification stability can coexist

There exist legal trajectories with ProbabilityDyn = 1 and Stable^set\_Prob = 1.

Proof: S2, from X\_P an idle tick, endogenous continuation, endogenous continuation, idle tick, with Start, Continue, Stop and RateDyn appearing, Keep^set = 1. Item by item: S3, a new dimension enters the dimensions (DimStructDyn), Keep^set = 1; S4, G1 becomes a common schema (BindStructDyn), Keep^set = 1; S5, a second set of carriers forms: on the same actual trajectory walking from t = 18 to t = 36, RateBearingStructDyn = 1 is read on one evaluation step of the same 18-step path of the fifteenth text; the snapshots at both ends are taken from the same instance and the same run, not stitched across instances; reading qualification tick by tick on the same history, Keep^set = 1. □

Theorem Five　Stability is not stillness

Stable^set\_Prob = 1 ⇏ NoProbabilityDyn. Follows directly from Theorem Four. □

Note: dynamics and the fixed-object layer. In S3, after a new dimension enters, the qualification realization must cover the new V\_P, the original realization is no longer in the realization set, Keep^fix = 0; in S5, midway as the second set of carriers form Laws one by one, the original hyperedge is no longer a minimal sufficient group, Keep^fix = 0 (at the end of the 18 steps the original hyperedge is again among the eight hyperedges). This shows that some dynamics cause substitution of the qualification realization, while the set layer is unaffected. In S4 the original realization is present throughout, Keep^fix = 1.

## Section Fourteen　Strength Declaration and Breach Methods

### 14.1 Strength

Reference substrate layer: for Spec\_ProbB^ref, the stability determinations and construction witnesses above have all been checked by actual runs, Status = Established, confined to the declared initial states, domains of permitted variation, protocols and finite trajectory spaces.

Formal inheritance layer: byte-level inheritance of Spec\_ProbB = Augment(Spec\_LDB, A\_Prob) from the sealed source fldb\_v1\_12.py is still PENDING RAW SOURCE and is not upgraded.

One recovery path does not pass as guaranteed stability; guaranteed over a finite trajectory space is not extended to a guarantee over an infinite future.

### 14.2 Breach methods

While the declared original qualification, domain of permitted variation, protocols and condition group are kept, exhibit any of the following cases:

stability of the fixed object is claimed, while E\_0^P exits at some decidable evaluation point;

stability of the existence layer is claimed, while at some decidable evaluation point all candidate realizations exit;

recovery is claimed, while the return occurs before the actual failure, there is no preceding actual failure, the declared deadline is exceeded, the declared minimum confirmation window is not satisfied, or after return it exits again within the observation domain;

family stability is claimed, while the family contains a legal decidable trajectory losing stability;

guaranteed stability is claimed, while there exists a legal trajectory losing stability, or there exist legal undecidable trajectories that were deleted in advance from the domain of the quantifier;

failure occurring at a boundary point is claimed, while that infimum or supremum has not been attained;

persistence of the same realization is claimed, while in fact different realizations bore it separately at different moments;

after changing χ̄\_P, Δ\_PSt, Γ\_qual, Γ\_stab, 𝓗\_PSt, the original stability conclusion is still claimed to hold;

Keep = 1 is signed by sparse first-and-last comparison without a verified interval certificate, or an unverified, forged or gapped interval certificate is accepted, or set = 0 is signed without complete search, or recovery is judged after deleting undecidable evaluation steps.

# ---------- qualification realizations E^P = (E_D, E_B, E_R) ----------
def realizations(F):
    """All complete Probability-qualification realizations at the current state.
    E_R: one role-projected MinSuff hyperedge h (via the frozen pi_role);
    E_B: one formal common schema g;
    E_D: for every dimension of V_P, the non-empty set of its formal Law-bearing roles
         used by h; a dimension that h does not use (a zero-rate dimension) contributes
         one of its own formal Law-bearing roles.
    The toy field is closed, so the enumeration is complete (returns (True, set))."""
    q=F.probability_reader()
    if not q["Probability"]: return True,frozenset()
    V=F.V(); bear=F.dimension_bearers()
    roles={d:sorted({F.law_role(c) for c in bear[d]}) for d in V}
    schemas=F.eligible_coords()
    H=[frozenset(h) for h in F.rate_bearing_org()[1]]
    out=set()
    for h in H:
        used={d:tuple(sorted(r for r in roles[d] if r in h)) for d in V}
        if not set(h)<=set(r for d in V for r in used[d]): continue
        free=[d for d in V if not used[d]]
        for pick in itertools.product(*[roles[d] for d in free]):
            ED=dict(used); ED.update({d:(r,) for d,r in zip(free,pick)})
            for g in schemas:
                out.add((tuple((d,ED[d]) for d in V),g,tuple(sorted(h))))
    return True,frozenset(out)

def anchor(F):
    return (F.candidate_id,F.C,F.rate_domain,tuple(sorted(F.role_map.items())),F.run_id,F.branch_id,F.protocol,F.eta)

def snap(F):
    q=F.probability_reader(); last=F.log[-1] if F.log else None
    cov_act=coverage_certificate(F,0,F.t)["act_t1"] if F.t>0 else 1
    return {"t":F.t,"id":snapshot_identity(F),"Probability":q["Probability"],"V":q["V"],"Rel":q["Rel"],"W":q["W"],
            "eligible_schemas":q["eligible_schemas"],"rate_bear_org":q["rate_bear_org"],
            "ProbabilityAct3":act3(F,last,cov_act)}

# ---------- admissible change domain Δ ----------
DELTA_MODES={"endo","idle","exo-carrier","exo-outside"}
DELTA_OPS={"AvailCarrier","MaskCarrier","Freeze","Thaw","Coupling","Selector"}
def apply(F,a):
    k=a[0]
    if k in ("endo","idle"): F.execute(k)
    elif k=="exo-carrier": F.execute("exo-carrier",carrier=a[1],coord=a[2])
    elif k=="op": F.execute("idle",op=a[1])
    elif k=="opaque-idle": F.execute("idle")          # legal step whose record Γ_stab cannot observe
    elif k=="ILLEGAL-set-role": F.role_map[a[1]]=a[2]  # outside Δ: rewrites the frozen pi_role
    elif k=="ILLEGAL-set-protocol": F.protocol=a[1]    # outside Δ: rewrites the protocol
    else: raise ValueError(a)
def in_delta(a):
    return a[0] in DELTA_MODES or (a[0]=="op" and a[1][0] in DELTA_OPS) or a[0]=="opaque-idle"

# ---------- one stability run ----------
def issue_interval_certificate(X0, actions):
    """An interval certificate issued by a separate certifier: for every run step t
    of the trajectory, (Q_fix(t), Q_set(t), task anchor).  It is an external object;
    run() verifies it instead of trusting it."""
    F=X0(); a0=anchor(F); _,E0s=realizations(F); E0=min(E0s) if E0s else None
    cert={}
    for a in actions:
        apply(F,a); _,Es=realizations(F)
        cert[F.t]=(1 if E0 in Es else 0, 1 if Es else 0, anchor(F))
    return cert

def verify_interval_certificate(cert, t_lo, t_hi, a0, truth):
    """1 iff the certificate covers every run step of (t_lo, t_hi] without gap, every
    entry carries the task anchor, every entry is decidable, and every entry agrees
    with the read-only recomputation `truth`; otherwise ⊥."""
    if not isinstance(cert,dict): return BOT
    for t in range(t_lo+1,t_hi+1):
        e=cert.get(t)
        if e is None or len(e)!=3: return BOT
        qf,qs,an=e
        if an!=a0 or qf not in (0,1) or qs not in (0,1): return BOT
        if (qf,qs)!=truth.get(t): return BOT
    return 1

def first_valid_recovery(Q, kf, T_rec, h):
    """The earliest k_r > k_f that satisfies the WHOLE recovery condition:
    Q(k_r)=1, Dur(k_f,k_r) <= T_rec (clock fixed at the first actual failure k_f,
    never reset by later failures), a minimum confirmation window of h steps
    (Q = 1 on k_r..k_r+h), AND Q stays 1 from k_r to the end of the observation
    domain.  A first reappearance that fails these checks does not exclude a later one."""
    for kr in [t for t,v in Q if t>kf and v==1]:
        if kr-kf>T_rec: continue
        hold=[v for t,v in Q if kr<=t<=kr+h]
        if len(hold)!=h+1 or not all(v==1 for v in hold): continue
        if not all(v==1 for t,v in Q if t>=kr): continue
        return kr
    return None

def theta_stability(Qt, T_rec, h_theta):
    """Dynamic-type stability on adjacent evaluation steps with its own DynDom^theta.
    If any reading in the observation domain is ⊥, the trajectory is undecidable for
    this dynamic-type task: Keep = Recover = Stable = ⊥.  ⊥ readings are never
    filtered out before the recovery check."""
    dom=1 if all(v in (0,1) for _,v in Qt) else BOT
    if dom!=1: return {"DynDom":BOT,"Keep":BOT,"Recover":BOT,"Stable":BOT}
    fail=[t for t,v in Qt if v==0]
    keep=0 if fail else 1
    rec=1 if (fail and first_valid_recovery(Qt,fail[0],T_rec,h_theta) is not None) else 0
    return {"DynDom":1,"Keep":keep,"Recover":rec,"Stable":1 if (keep==1 or rec==1) else 0}

def run(X0, actions, *, T_rec=3, h=2, h_theta=None, eval_every=1, interval_cert=None, theta=None):
    """Γ_stab: evaluation points every `eval_every` run steps.  For sparse evaluation an
    interval certificate object may be supplied; it is verified step by step against the
    read-only recomputation, never trusted as a flag.  Dur is measured in run ticks.
    Returns three-valued Keep / Fail / Recover / Stable for x in {fix, set}."""
    F=X0(); a0=anchor(F)
    _,E0set=realizations(F); E0=min(E0set) if E0set else None
    per_step=[]; observable=[]; task_changed=False; outside=False
    rec0=(F.t,True,E0 in E0set,len(E0set)>0)
    per_step.append(rec0); observable.append(True)
    snaps=[snap(F)]
    for j,a in enumerate(actions,1):
        if not in_delta(a): outside=True
        apply(F,a)
        if anchor(F)!=a0: task_changed=True
        _,Es=realizations(F)
        per_step.append((F.t,a[0]!="opaque-idle",E0 in Es,len(Es)>0)); observable.append(a[0]!="opaque-idle")
        snaps.append(snap(F))
    if task_changed or outside:
        return {"status":"TASK_CHANGED_OR_OUTSIDE_DELTA","Recover_fix":BOT,"Recover_set":BOT,"Stable_fix":BOT,"Stable_set":BOT}
    n=len(actions)
    eval_idx=[i for i in range(0,n+1) if i%eval_every==0]
    dense=eval_every==1
    truth={per_step[i][0]:(1 if per_step[i][2] else 0, 1 if per_step[i][3] else 0) for i in range(n+1)}
    cert_ok=None
    if not dense and interval_cert is not None:
        cert_ok=all(verify_interval_certificate(interval_cert,per_step[i][0],per_step[j][0],a0,truth)==1
                    for i,j in zip(eval_idx,eval_idx[1:]))
        if eval_idx[-1]!=n: cert_ok=False
    if not all(observable): stable_cov=BOT
    elif dense: stable_cov=1
    elif cert_ok: stable_cov=1
    else: stable_cov=BOT
    out={"E0":E0,"eval_points":[per_step[i][0] for i in eval_idx],"StableCoverage":stable_cov,
         "interval_certificate_verified":cert_ok}
    idx=range(0,n+1)
    for x,col in (("fix",2),("set",3)):
        if stable_cov!=1:
            out.update({f"DynDom_{x}":BOT,f"Keep_{x}":BOT,f"Recover_{x}":BOT,f"Stable_{x}":BOT}); continue
        Q=[(per_step[i][0],1 if per_step[i][col] else 0) for i in idx]
        fail=[t for t,v in Q if v==0]
        keep=1 if not fail else 0
        rec=0; reapp=0; kr=None
        if fail:
            kf=fail[0]
            reapp=1 if any(t>kf and v==1 for t,v in Q) else 0
            kr=first_valid_recovery(Q,kf,T_rec,h)
            rec=1 if kr is not None else 0
        out.update({f"DynDom_{x}":1,f"Q_{x}":Q,f"Fail_{x}":fail,f"k_f_{x}":(fail[0] if fail else None),
                    f"Keep_{x}":keep,f"Reappear_{x}":reapp,f"Recover_{x}":rec,f"k_r_{x}":kr,
                    f"Stable_{x}":1 if (keep==1 or rec==1) else 0})
    # dynamic-type readings Q^theta(k) on adjacent evaluation steps (dense)
    if dense:
        dyn=[]
        for i,(a,b) in enumerate(zip(snaps,snaps[1:])):
            d=classify3(F,a,b,coverage_certificate(F,a["t"],b["t"],a,b))
            if not (observable[i] and observable[i+1]): d={k:BOT for k in d}   # unobservable endpoint
            dyn.append(((a["t"],b["t"]),d))
        out["dyn"]=dyn
        out["ProbabilityDyn_any"]=any(any(v not in (0,BOT) for v in d.values()) for _,d in dyn)
        if theta:
            key,val=theta
            Qt=[(st[1],1 if d[key]==val else (BOT if d[key]==BOT else 0)) for st,d in dyn]
            ht=h if h_theta is None else h_theta
            ts=theta_stability(Qt,T_rec,ht)
            out["theta"]={"key":key,"val":val,"h_theta":ht,"Q":Qt,**ts}
    return out
