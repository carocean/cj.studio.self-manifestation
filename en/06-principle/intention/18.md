# The Source Form of Intention

A frozen candidate first obtains Intention qualification within a declared history window. Which stretch of actual history bears the formation of this first holding? If several stretches of history can each legally bear it, how far at most can it be determined? And to what degree is the history that bears the formation the field's own formation, rather than something already given at the boundary?

The conclusion is: the source of Intention qualification is not the four-item structure holding simultaneously at the endpoint, not the item closing last, not an event earlier in time, nor any counterfactual necessary condition; it is a stretch of actual history that bore the real formation of the first qualification closure of this frozen candidate, and that passes at once the certification of the actual generation chain and that of legal counterfactual minimal sufficiency. The source may be non-unique; not having found a source is not the same as having no source. Once the source is certified, its provenance must still be asked about separately: whether the formation of the four items was obtained within the field through sedimentation, whether an Intention-specific duty designation was already preset at the boundary, and whether the inputs used in the formation already named the bearers. Only when all three questions are cleared may one say, within that boundary, “Intention qualification is formed within the field”; the initial state having no Intention qualification does not mean that no Intention is pre-installed in it.

## Section One　Declaration of the Object

### 1.1 Form-kind and the single task

Source Form, auxiliary form, a standalone text. By the Source Form specification of the Canon Chapter, Part Four, Chapter Four: to prove by what actual process an already established structure is generated, rather than by what it is given.

Only the source of the first holding of Intention qualification is studied here, and the provenance and the boundary of the source are distinguished. Tracing how the current organization was formed when the initial state already has qualification is not set up as a separate class of problem: the first point of the set of evaluation points is no later than the registration point of the candidate (1.4), so this tracing is simply asking about the same first holding over a longer window; when earlier history is unavailable and the first point already reads 1, Genesis\_I is ⊥ by 1.5, and the source is accordingly ⊥. Re-formation after exit from qualification must, by The Limit Form of Intention, be frozen and declared anew for a new declared segment; the source problem of this re-formation is handed by The Limit Form of Intention to this chapter: for a re-declared candidate, the first holding and the source are asked about on its own set of evaluation points (1.5). Not studied: whether there is currently Intention qualification; how Intention acts, switches and has dynamics at this moment; the persistence, failure and return of qualification afterwards; whether qualification can be reached from a given initial state; how to construct an executable system that generates Intention for the first time in a base Sedimentation-Field; whether the re-formed organization is the same as the original organization; identity continuity across hosts through migration or copying.

Five closures are separated here:

&nbsp;&nbsp;&nbsp;&nbsp;Qualification closure         the four-item structure holds at the evaluation point                   may sign Intention qualification (The General Form of Intention, The Necessity Form of Intention)  
&nbsp;&nbsp;&nbsp;&nbsp;Running closure               existing structures actually operate in the field                       may sign the running of existing Intention (The Construction Form of the Intention Operating Substrate)  
&nbsp;&nbsp;&nbsp;&nbsp;Path closure                  a legal path reaches it from the given initial state                    may sign reachability under the specified task (The Reachability Form of Intention)  
&nbsp;&nbsp;&nbsp;&nbsp;Source closure                the first holding is borne by certified actual history                 may sign the source under the given protocol (Section Four of this chapter)  
&nbsp;&nbsp;&nbsp;&nbsp;In-field formation closure    the source is certified, the boundary has no Intention-specific pre-installation, and all four items are formed within the field and not named by inputs    may sign formation within the field inside the given boundary (Section Six of this chapter)

A closure of an earlier kind does not imply one of a later kind.

1.3 Cross-time candidate and bearer designation

The Source Form cannot freeze some single moment as the identity of the candidate. A cross-time frozen declaration is written:

&nbsp;&nbsp;&nbsp;&nbsp;χ̄\_I = (F, 𝒫\_I, C\_I, 𝔯\_I, V\_I, Anc\_I, Duty\_I, Rec\_I)

F is the field; 𝒫\_I, C\_I, 𝔯\_I and V\_I are the probability organization, the Continuation-Position, the rate domain and the formal dimensions, and the carrier-candidate registration of the probability layer belongs to the frozen declaration of 𝒫\_I; Anc\_I is the qualification anchor; Duty\_I is the kinds and identities of the duties: the source-drive duty, the set of identities of the Desire-Gate duties, the set of identities of the tuning duties, and the Intention-Domain duty. Duty\_I gives only the identities of the duties; it does not name the bearers, nor does it give the pairing of dimensions with gate duties. Rec\_I is the declaration record: the registration point and the declaration sequence number. The candidate instance at evaluation point t is χ\_I(t) = (χ̄\_I, t).

Which edge bears the source drive, which dimension corresponds to which gate duty (the pairing of dimensions with gate duties), which gate node bears a gate duty, which post-gate edge bears the tuning behind which gate duty, and which probability organization is declared to lie in the Intention-Domain: these bearer designations are written Des\_I. The pairing of dimensions with gate duties is the bearing content of GC and belongs only to Des\_I. The Intention-Domain duty is an identity and belongs to Duty\_I; declaring some probability organization to be its bearer is a designation and belongs to Des\_I. Des\_I belongs to the system state, not to the candidate declaration: it is either already given in the initial state or obtained through historical events within the window. A designation obtained within the window is a historical event and, like other events, is subject to reduction, replay and the review of formation (3.6).

In one source protocol, χ̄\_I is entirely frozen in advance. After history is deleted, V\_I may not be added to or deleted from; the anchor, the Continuation-Position and the rate domain may not be changed; the identities of the duties may not be altered; and another candidate may not be re-declared.

X\_0 and Bg^Π together are called the boundary B\_S. What lies within the boundary does not belong to the source candidates and can only be reviewed separately (Section Six).

### 1.5 First qualification event

&nbsp;&nbsp;&nbsp;&nbsp;Genesis\_I^Π(χ̄\_I, τ) ∈ {1, 0, ⊥}

1: τ is not the first point of T\_Π, Judge\_I^Π(τ) = 1, and Judge\_I^Π(t) = 0 for every t \< τ in T\_Π.  
0: Judge\_I^Π(τ) = 0; or there exists t \< τ with Judge\_I^Π(t) = 1. An earlier definite 1 suffices to deny “first”, even if other earlier points are ⊥.  
⊥: all other cases, for example: the point τ is non-adjudicable; the point τ is 1 while some earlier evaluation point is ⊥ and there is no earlier definite 1; or τ is the first point of T\_Π and is already 1 (there is no earlier 0 to compare with).

The first point of T\_Π is no later than the registration point of the candidate, so for the original candidate a renewed holding after exit from qualification has Genesis\_I = 0 when the earlier 1 has been definitely obtained (at the formal layer; or at the object layer when structural facts serve as the verdict, or when the H\_LawRead of the witness used has been closed); when the object layer uses Det\_I and the earlier 1 is ⊥ (LawReadOpen), Genesis\_I = ⊥. By “Re-formation is not re-entry into the original segment” in The Limit Form of Intention (see also V52 of The Construction Form of the Intention Operating Substrate), once the original segment has crossed the qualification boundary, the re-forming segment must be frozen and declared anew as a new candidate χ̄\_I′: its declaration record Rec\_I′ differs from Rec\_I, and its registration point lies after the exit of the original segment and before the re-formation; for χ̄\_I′, on its own set of evaluation points, the re-formation can be a first qualification event, and its source is certified by Section Four. Whether χ̄\_I′ and χ̄\_I are the same is not concluded here (as in The Limit Form of Intention). Such re-formation occurs on structures already placed and designated; by Section Six it falls at most into Boundary, and it is not first generation from a base Sedimentation-Field.

### 1.6 Two layers of the first event

Genesis\_I is obtained from the verdict; for the case where structural facts at the object layer serve as the verdict, see 1.7. At the object layer Det\_I is used: the 1 at the point τ requires that the H\_LawRead of the witness used has been closed, otherwise it is ⊥ (LawReadOpen); the 0 at each earlier point must be obtained along the negative-reading path of The Determination Form of Intention, the probability side carrying H2 ∧ H3^red and H^-\_M or H\_ρRep^-, and a formal zero of an atom newly added in this group form being ⊥ (IntentAtomRepOpen). At the formal layer IntentCoreCert^M is used, written Genesis\_I^{Π,M}. The two layers are registered separately and not mixed; the instance of Section Seven signs Genesis\_I^{Π,M} = 1 only at the formal layer, while at the object layer Genesis\_I = ⊥.

The principle of routing: when Genesis\_I is undefined or 0, OutDom is recorded; when Genesis\_I is 1 or ⊥ and the source-determination domain is not closed, ⊥ is recorded. So when the candidate is not frozen, the set of evaluation points is not frozen, or τ is not in T\_Π, the source verdict is recorded as OutDom and routed off before the evidence is adjudicated; when Genesis\_I(τ) = 0, τ is not a first qualification event and asking about its source has no object, so OutDom is likewise recorded; when Genesis\_I(τ) = ⊥, the source is recorded as ⊥; when Genesis\_I is 1 or ⊥ but the granularity is not frozen, the reduction domain is infinite, or the reduction relation does not constitute a finite partial order, the source-determination domain is not closed and the source is recorded as ⊥.

### 1.7 First nucleation

If structural facts at the object layer serve as the verdict (Judge\_I(t) = Intent\_t), τ is not the first point of T\_Π, N\_{I,t} = 0 for every t \< τ in T\_Π, and N\_{I,τ} = 1, then Genesis\_I^Π(χ̄\_I, τ) = 1, and τ is the evaluation point at which this candidate first obtains Intention qualification on the set of points.

Proof. By The Necessity Form of Intention, N\_{I,τ} = 1 ⇒ Intent\_τ = 1; taking the contrapositive of the necessary direction of The General Form of Intention, N\_{I,t} = 0 ⇒ Intent\_t = 0. Neither direction carries H; substituting into the 1 branch of 1.5 gives the result. □

Status = Established. It states only the time point of the first holding, not what formed it this time; the source is certified separately by Section Four. In the instance, the structural facts of the four items are obtained from formal readings, and reading back to the object layer must follow the conditions of 1.2, under which a formal zero of a newly added atom does not read back; so the instance of Section Seven can only stop at the formal layer.

## Section Two　Exclusion of the Presumed Source

The following are objects that are easily taken for sources but cannot serve as sources. Each item is a non-implication at the definition layer: the source is certified by IGenesisSource of Section Four, whose second and third items take history as their argument, and the final state, temporal order, correlation and counterfactual necessity cannot satisfy it on their own.

W-I1　Inferring backwards from the final-state qualification: Intent\_τ = 1 ⇏ 𝔖^Π\_{I,src} ≠ ∅.  
W-I2　Inferring backwards from the final-state qualification core: N\_{I,τ} = 1 ⇏ the source has been certified. A qualification certificate is not a source certificate (Theorem Two).  
W-I3　The item closing last passing as the whole source: the item that last changes from 0 to 1 at τ is X ⇏ the source forms only X (Theorem Three).  
W-I4　Formation of a single item passing as the source of Intention: some item is formed within the window ⇏ the source of Intention qualification has been certified. The first event requires that all four items of the same candidate hold at τ (Theorems Three and Five).  
W-I5　Temporal precedence, synchrony, correlation, prediction: h precedes τ ⇏ h bears the source; Corr(h, Genesis\_I) ⇏ h bears the source.  
W-I6　Environmental reward and punishment passing as source (u41): reward and punishment occurred ⇏ source. Reward and punishment must really enter the actual generation chain and bear load in minimal sufficiency (5.4).  
W-I7　Triggering passing as formation (u42): a musing, recollection or thinking circuit launching one activity of already formed Intention is the starting source of that activity, not the formation source of qualification. Within a window in which qualification has already been determined as 1, Genesis\_I = 0 (Section Seven, 7.7).  
W-I8　Break-holding passing as source (u40): break-holding occurred ⇏ Intention qualification is formed. Break-holding may produce only another arrangement of the Law Ecology (5.4).  
W-I9　Background enabling: counterfactual necessity ⇏ source. A condition not in H\_obs, without which the system cannot attain qualification, does not thereby become a source (Section Seven, 7.8).  
W-I10　Illegal deletion: after h is deleted the history cannot be legally replayed (Replayable = 0) ⇏ h is a necessary source.  
W-I11　External installation passing as formation within the field: ExternalInstall\_I = 1 ⇏ FieldBorn\_I = 1. External installation can be a source, but is not thereby formation within the field.  
W-I12　No qualification in the initial state passing as not pre-installed: Intent(X\_0) = 0 ⇏ NoPreinstalledIntent(B\_S) (Theorem Eight).  
W-I13　Running passing as source: placed structures actually run in the field ⇏ these structures were first formed after the boundary.  
W-I14　Recovery passing as first formation: for the original candidate, a renewed holding after exit from qualification is not a first holding (Genesis\_I = 0 when the earlier 1 is definite, otherwise ⊥, 1.5); re-formation must ask separately about the first holding and the source for the re-declared candidate, and on placed structures it is at most Boundary (1.5; Section Seven, 7.7).  
W-I15　Reachability passing as source: R\_Ξ(X\_0, G\_I) = 1 ⇏ the source has been certified; the source has been certified ⇏ reachable under another frozen task (Theorem Ten).  
W-I16　External input passing as external completion: external input exists in the formation ⇏ not formation within the field; legal external induction with the formation completed within the field does not exclude formation within the field (6.2; for a formal-layer instance on general structures, see P\_I in Section Seven, 7.5).  
W-I17　Probability passing as Intention: Probability = 1 ⇏ Intent; an ordinary probability organization without source-drive driving, Desire-Gate correspondence and tuning interface is not Intention (Section Seven, 7.9).  
W-I18　Lower-layer structure passing as upper-layer qualification: repeated sedimentation ⇏ Law; several coexisting Laws ⇏ Probability; a probability organization driven by source drive ⇏ Intention (lacking Desire-Gate correspondence or tuning interface); directions connected to gates ⇏ complete Intention (lacking the interface of post-gate commanding tuning). The grounds are given in 5.5.

This yields four distinctions:

&nbsp;&nbsp;&nbsp;&nbsp;last closure ≠ source, structural necessity ≠ source, final-state qualification ≠ source, counterfactual necessity ≠ source

The grounds are, respectively, Theorem Three, Theorem Four, Theorem Two, and the requirement of the actual generation chain in 3.6.

## Section Three　Characterization of the Generative Process

### 3.1 Representation of history

Actual history is written as an ordered finite object:

&nbsp;&nbsp;&nbsp;&nbsp;H\_obs = (e\_1, e\_2, …, e\_n), n \< ∞

It may not be written as an unordered set. Every occurrence keeps at least its temporal order, its actual content of occurrence, the object it acts on and its route. What belongs to the process of formation within the field keeps in addition execution, trace, sedimentation and formation, and the connection with the bearing of the four items at the endpoint; what belongs to the process of external installation keeps the external editing events, the objects edited and the states before and after editing. Fields that do not exist may not be fabricated merely to complete the format.

### 3.2 Reduction domain

A protocol-relative reduction is written H′ ⪯\_Π H: there exists a finite sequence of operations permitted by Ops^Π that reduces H to H′. Each operation can only delete an existing event or weaken the effect of an existing event; it does not change the event's original temporal position; its execution and result can be reviewed. When an event is deleted, the temporal position it occupied is kept as an empty slot of the same duration.

Reduction may not change X\_0 (including the bearer designations in it), χ̄\_I, Bg^Π, Dyn^Π, or the definitions of the verdict or the qualification core; may not add new events; may not change the order of the remaining events; may not covertly supply the final state; and may not re-cut Gran^Π after the fact. Strict reduction is written H′ ≺\_Π H. It is required that ⪯\_Π constitute a frozen finite partial order on the declared reduction domain; when this is not met, the source-determination domain is not closed (1.6). The minimality below is relative to this partial order.

3.3 Finiteness and the domain of source candidates

Here it is required that \|H\_obs\| \< ∞ and that the reduction domain ℛ\_Π(H\_obs) = { H′ \| H′ ⪯\_Π H\_obs } be finite. For continuous weakening strengths, infinitely fine granularity or infinite descending chains without a frozen discretization, ReductionDomainFinite or GranFrozen does not hold, SrcDetDom is not closed, and the source is recorded as ⊥ (4.4, 4.5). The domain of candidate source histories:

&nbsp;&nbsp;&nbsp;&nbsp;𝓗^Π\_src := ℛ\_Π(H\_obs) ∖ { H\_∅ }

H\_obs is taken only up to τ; events after τ do not enter the source candidates. Source candidates can be obtained only from actual history by permitted reductions; a substitute process that did not occur in actual history, or another possible history, may not be taken as a source candidate of this first holding. H\_∅ serves only as the empty-history control of 4.3.

### 3.4 Legal replay

&nbsp;&nbsp;&nbsp;&nbsp;Replayable\_I^Π(H) ∈ {1, 0, ⊥}

1: there exists a legal replay complying with the complete frozen protocol: the same X\_0, the same χ̄\_I, the same background, the same legal dynamics, the same verdict and evaluation protocol; only the events not kept undergo permitted deletion or weakening, and the system is then left to evolve lawfully.  
0: the so-called replay can be completed only by changing the candidate, altering X\_0 or the background (including the bearer designations at the boundary), changing the dynamics, altering the verdict, adding undeclared events or covertly supplying the final state.  
⊥: whether the replay is legal cannot currently be determined.

&nbsp;&nbsp;&nbsp;&nbsp;Replayable = 0 ≠ counterfactual failure; cannot delete ≠ deleted and fails

### 3.5 Sufficiency of a source

Evaluated only after Replayable\_I^Π(H) = 1:

&nbsp;&nbsp;&nbsp;&nbsp;Suff\_I^Π(H; χ̄\_I, τ) ∈ {1, 0, ⊥}

1: legally replayed to τ, N\_{I,τ}^{Replay(H)} = 1, that is, all four items of the same candidate hold at τ; by The Necessity Form of Intention, Intent\_τ = 1.  
0: the legal replay is completed, and N\_{I,τ} = 0 definitely holds at τ.  
⊥: the legal replay holds, but the reading at τ is insufficient to judge N\_I.

In a counterfactual replay it is not required that qualification first hold exactly at τ; it may hold earlier: what is studied here is the source, not exact timing. At the formal layer Suff\_I^M is taken with IntentCoreCert^M; its 1 reads back to the object layer according to H\_LawRead, and its 0 reads back to the object layer according to the negative-reading conditions of 1.2.

### 3.6 Actual Intention generation chain

A source cannot have only counterfactual sufficiency; it must also have actual formation; what is formed must be one and the same as what the endpoint qualification uses; and this formation itself must bear the sufficiency of this history, rather than being merely a by-product that happens alongside and is read by the endpoint.

Order-preserving sub-history H\_g ⊑\_ord H\_s: obtained by extracting some events of H\_s in their original order. Formation witness g = (H\_g, s\_g), where s\_g is a structure formed by these events, or the union of several structures (a composite witness; see (iv)).

H\_g takes the exact write-in events of the transition in which s\_g last changed from 0 to 1 within the window, that is, those events of actual history, up to this transition, whose route passes through the bearing edges of s\_g, listed event by event and not enlarged by atom; the write-in events of one structure may belong to several atoms (for example, the rate relation of two dimensions depends at once on the carriers of both dimensions), in which case H\_g takes their union. Atoms are used only to judge whether a witness falls within some candidate, and to report event-level bearing. Below, “before” means before the first write-in event of H\_g (in the reference instance, no other event in the window writes these variables before then, so their values are the same as at X\_0).

(i) Kinds of state change. That s\_g changes from 0 to 1 within the window can be several different facts; classified by the state variables on which it depends, they have different standing in the determination of formation:

Structure generation: the sedimentary variables bearing s\_g (the sediment and repetition records of the bearing edges, and the binding sediment; not including node sediment and path dynamics) were empty before and are established by the traces of the events of H\_g; the transition occurs on a write-in event of H\_g, and this event neither alters the switches or topology of the bearing edges nor rewrites a bearer designation. Node sediment is shared by several structures, and the path dynamics of carrier paths have non-empty initial values; neither takes part in this discrimination. It can bear the present formation and is also the first source of the structure.  
Threshold crossing: the above sedimentary variables bearing s\_g already existed before but did not suffice for s\_g to hold; the transition occurs on a write-in event of H\_g that alters no switch, topology or designation, and its trace makes these variables cross the condition of holding (for example, the repetition records needed for groove formation fall within the window again). It can bear the present formation, that is, the obtaining of the structural state on which qualification depends; the earlier source of the structure lies in the preceding history, must be registered separately, and is not borne by this occasion.  
Re-enabling: s\_g holds only because a switch such as availability, masking or threshold has been altered; the sedimentary variables have not changed because of H\_g. It does not bear formation and can serve only as evidence of triggering or recovery.  
Designation change: s\_g holds only because a bearer designation has been rewritten. It is not formation within the field; if the rewriting is a declared external editing event, it can be the formation connection of an external installation, otherwise it is an undeclared write-in.  
Read-out change: the verdict, the read-out definition or the protocol has been altered. This is protocol invalidity, not formation of any kind.  
Other or mixed: transitions belonging to none of the above, for example a transition that occurs on no write-in event and is not due to a switch alteration or a designation rewrite (it changes only because of a competing edge or some other structural change), a transition whose write-in event at the same time alters switches, topology or designations, or a single transition accompanied both by a switch alteration and by a designation rewrite. The kind is recorded as ⊥, and it does not bear formation.  
The discrimination looks only at the alterations relevant to this transition: before and after the event at which the transition occurs, whether the availability, masking, threshold and topology of the bearing edges were altered, and whether a bearer designation was rewritten.

Only structure generation and threshold crossing can bear formation. Formation is determined on the actual history H\_obs, not on replays of reduced histories: the event at which s\_g last changed from 0 to 1 within the window belongs to H\_g, s\_g stays 1 from then until τ, this change is one of the two kinds above, and the events of H\_g actually pass through the edges bearing s\_g. A structure that already exists and is merely maintained does not count as formed by this history.

Counterexample: a single event merely reopens an edge that had already formed a groove and been masked; s\_g changes from 0 to 1, the event also passes through this edge, and the endpoint reads it; by the classification above, this is re-enabling, not formation.

(ii) Two paths of formation, taking values in {1, 0, ⊥} for each g:

FieldFormationLink\_I(g): 1, the events in H\_g are all declared legal inputs and, through execution, trace, sedimentation and formation under Dyn^Π, formed s\_g within the field by structure generation or threshold crossing, with no undeclared write-in altering s\_g or a bearer designation within the window, and the whole process is reviewable; 0, the interfaces needed are completely readable, and there is definitely no such connection of formation; ⊥, some part is unreadable or unreviewable, or the kind of change cannot be discriminated.

ExternalInstallLink\_I(g): 1, H\_g contains declared, reviewable external editing events that really generated s\_g; 0, the interfaces needed are completely readable, and there is definitely no such connection of installation; ⊥, some part is unreadable or unreviewable.

&nbsp;&nbsp;&nbsp;&nbsp;ActualFormation(g) := FieldFormationLink\_I(g) ∨₃ ExternalInstallLink\_I(g)

This disjunction exhausts the paths of formation only within the formal definitions here; it does not claim that all modes of the formation of Intention are ontologically exhausted. Correlation, synchrony, prediction, onlooking, purely background enabling, re-enabling and final-state proxies satisfy neither path.

(iii) End binding, taking values in {1, 0, ⊥} for each g and each X ∈ {P\_I, SD, GC, TI}:

EndBind\_X(g): 1, s\_g formally enters the bearing of item X of this frozen candidate at τ, that is, the read-out of X is 1 at τ and s\_g is among the bearers read; 0, the binding interfaces are completely readable, and it definitely does not enter; ⊥, the binding relation is non-adjudicable.

&nbsp;&nbsp;&nbsp;&nbsp;EndBind\_I(g) := EndBind\_P\_I(g) ∨₃ EndBind\_SD(g) ∨₃ EndBind\_GC(g) ∨₃ EndBind\_TI(g)

End binding is relative to the frozen χ̄\_I: s\_g must enter the bearing of some item under the same candidate and the same qualification anchor. For a structure formed on another organization, another run or another qualification anchor, EndBind\_I = 0.

(iv) Formative load-bearing. Withdrawal operation Wd^Π(g, s\_g): when H\_s is legally replayed, only after each event of H\_g has been executed (event by event, not including events of the same atom outside H\_g), withdraw that event's sediment increment and repetition records on the bearing edges of s\_g, its binding increment, and (when s\_g is a Law-bearing or a rate relation) the corresponding alterations of the path dynamics of each dimension, keeping one decay step of the event itself; the other effects of the event and its temporal position are all kept. Node sediment is shared by all structures passing through the node and is not withdrawn. If a withdrawn variable also bears other structures, the withdrawal cancels those structures at the same time, and what is actually judged is their union, which must be registered as a composite witness. The legality of Wd^Π is declared in advance in the protocol; when it cannot be legally executed, FormBear is recorded as ⊥.

&nbsp;&nbsp;&nbsp;&nbsp;FormBear(g; H\_s) ∈ {1, 0, ⊥}

First look at the candidate itself: when Replayable(H\_s) ≠ 1 or Suff(H\_s) = ⊥, FormBear = ⊥; when Replayable(H\_s) = 1 and Suff(H\_s) = 0, FormBear = 0. Only when Replayable(H\_s) = 1 and Suff(H\_s) = 1 does one continue:  
0: in the legal replay of H\_s, s\_g is not formed by the events of H\_g, or does not hold at τ.  
Otherwise, a legal replay with Wd^Π(g, s\_g) is performed:  
⊥: the withdrawal cannot be legally executed; or in the withdrawal replay s\_g is still formed by the events of H\_g (the withdrawal did not cancel this formation); or the reading of the withdrawal replay is non-adjudicable.  
1: the withdrawal has cancelled the formation of s\_g by H\_g, and N\_I = 0 definitely holds at τ.  
0: the withdrawal has cancelled the formation of s\_g by H\_g (s\_g does not hold, or is instead formed by events outside H\_g), while N\_I = 1 definitely holds at τ, that is, this formation does not bear the sufficiency of this history.

FormBear binds actual formation and counterfactual load-bearing to one and the same structure: it does not ask “whether deleting some event makes the history no longer sufficient”, but “whether the history is no longer sufficient when only the formation of this structure is cancelled and all other effects of the event are kept”. So when an event is counterfactually necessary because of other effects and only incidentally forms a redundant structure, that structure has FormBear = 0. When several structures are mutually redundant and withdrawing each alone does not destroy sufficiency, the witnesses of single structures are all 0, and their union must be reviewed further. A composite witness is used only when it is minimal: withdrawing its union destroys sufficiency, while withdrawing any proper sub-union does not; so a union containing a member that bears load on its own is not a composite witness, and a by-product cannot obtain load-bearing by being merged into a load-bearing structure. Minimality is judged by the sets of variables that can be withdrawn separately: when several structures share withdrawal variables and cannot be withdrawn separately, they count as one member unit as a whole; when the reading of some proper sub-union is ⊥, minimality cannot be determined, and the composite witness is recorded as ⊥. The ActualFormation of a composite witness is the ∧₃ of the ActualFormation of its members; EndBind\_X(g) = 1 requires that some member enter the bearing of X. On the axis of provenance, FieldBorn requires that all members be formed within the field and ExternalInstall requires that all members be externally installed; when the members differ in provenance, neither signs 1, and the source core is not affected. “Enumerated completely” includes the minimal composite witnesses.

Actual Intention generation chain:

&nbsp;&nbsp;&nbsp;&nbsp;ActualIGenesisLink^Π(H\_s; χ̄\_I, τ) := ∃₃ g, H\_g ⊑\_ord H\_s: \[ ActualFormation(g) ∧₃ EndBind\_I(g) ∧₃ FormBear(g; H\_s) \]

Formation, binding and load-bearing must fall on one and the same witness g: one may not take the formation of event A on one side and the end binding of another event or of a pre-existing structure B on the other, nor substitute the counterfactual necessity of C for the formative load-bearing of A. For a candidate with Suff(H\_s) = 0, FormBear = 0, ActualIGenesisLink = 0, and MinSuff is also 0; for a candidate with Replayable(H\_s) ≠ 1 or Suff(H\_s) = ⊥, the FormBear of every witness is ⊥; in that case, as long as some witness has neither ActualFormation nor EndBind equal to 0, its three-term conjunction is ⊥ and ActualIGenesisLink does not sign 0; MinSuff is ⊥ by 3.7.

Three-valued rules: ∨₃ is 1 if any term is 1, ⊥ if none is 1 but some is ⊥, and 0 only if all are 0; ∧₃ is 0 if any term is 0, ⊥ if none is 0 but some is ⊥, and 1 only if all are 1; ∃₃ is 1 if any is 1, ⊥ if none is 1 but some is ⊥, and 0 only if all are 0, and “all 0” requires that the formation witnesses in H\_s have been enumerated completely, otherwise ⊥.

### 3.7 Minimal sufficient source history

&nbsp;&nbsp;&nbsp;&nbsp;MinSuff\_I^Π(H\_s; χ̄\_I, τ) ∈ {1, 0, ⊥}

First judge the candidate itself: when Replayable(H\_s) ∈ {0, ⊥}, it is ⊥; when Replayable(H\_s) = 1 and Suff(H\_s) = 0, it is 0; when Suff(H\_s) = ⊥, it is ⊥. Only when Replayable(H\_s) = 1 and Suff(H\_s) = 1 are all H′ ≺\_Π H\_s examined:

0: there exists H′ ≺\_Π H\_s with Replayable(H′) = 1 and Suff(H′) = 1. A definite counterexample takes precedence.  
1: there is no such counterexample, and every strict reduction has Replayable(H′) = 1 and Suff(H′) = 0.  
⊥: there is no definite sufficient strict reduction, but at least one strict reduction has Replayable = 0 or ⊥, or Suff = ⊥ after legal replay.

Not: cannot be legally deleted ⇒ necessary source.

What MinSuff = 1 proves is that H\_s is minimal in a reduction domain in which every strict reduction can be legally replayed and obtains a definite reading. As soon as one strict reduction cannot be legally replayed or has a non-adjudicable reading, MinSuff is recorded only as ⊥, even if all the other legal reductions have been proven insufficient. This is a conservative determination: it is not minimality in the general counterfactual sense. The admission of reductions and the legality of replay are two separate matters: Ops^Π is frozen in advance and can exclude in advance operations known to break the protocol; a reduction already admitted that has Replayable ≠ 1 keeps MinSuff at ⊥ and may not be removed after the fact.

### 6.2 Reading dependence and input naming

Dep\_X: all the state items on which the read-out of X depends at τ, listed variable by variable according to the read-out definition of X, including the state variables of the bearing structures, the bearer designations and the coverage switches of the reader. A state inventory is declared that contains all the state variables of the system: the topology of the graph; the sediment and repetition records, availability, masking and threshold of each edge; the sediment of each node; the path dynamics of the carrier paths; bindings, generation gates and carrier links; bearer designations (including the source registration and the binding relation of the probability organization, and the bearer attributes used in event assembly; in cross-run comparison the run identity is normalized to “whether it is bound to the frozen probability organization”, without deleting this relation); the coverage switches of the reader; the random sources of each layer; the clock; the field log, the degree records and the event and operation records of each layer; the gate-bearing state and the source-drive session state. This probe has two limits, which are registered together with the conclusion: dependences that act only under joint perturbation cannot be detected; and each variable is disturbed only to one fixed value (for example, sediment set to zero, availability switched off), so when a variable already has that value the probe is empty for it (for example, a competing edge without sediment, a dependence that shows only when sediment is added). So the strength of DepComplete\_X = 1 is “the listing of the read-out definition, plus this single-variable probe having found no omission”.

Each item d of Dep\_X falls into one of five classes:  
Frozen declaration item: a component of χ̄\_I and of the protocol (the qualification anchor, the duty identities, the formal dimensions, the probability carrier candidates and so on), unchanged within the window by definition;  
General boundary item: not a frozen declaration item; its value is unchanged at every evaluation point from X\_0 to τ, and it belongs to the general medium or remains ungiven throughout (for example, a designation that remains empty throughout, a structure that never has sediment);  
Specific boundary item: not a frozen declaration item; its value is unchanged at every evaluation point from X\_0 to τ, it does not belong to the general medium, and it is already given at X\_0, for example bearer designations and placements outside the general medium that already bear;  
In-window formation item: its value changes within the window, it is a bearing variable of some structure s, s holds at τ, and the last change of s from 0 to 1 has a formation witness in the sense of 3.6 (structure generation or threshold crossing);  
Unexplained item: everything else, including items whose value changes but that do not hold at τ, that have no formation witness, or that are unreadable.  
The frozen declaration items are separated first; the rest are split into two branches by “whether the value changes within the window”: the unchanged branch is divided into specific and general items by “whether it does not belong to the general medium and is already given at X\_0”, and the changed branch is divided into formation items and unexplained items by whether the conditions of an in-window formation item are met. So this classification is exhaustive and mutually exclusive.

NoPrivWrite: every change of state within the window comes from the execution of events of H\_obs under Dyn^Π, with no undeclared write-in.

Source determining the route: who determines the stretch of route along which a formation event passes through the bearing structure. There are four kinds:  
Input specification: the input itself gives this stretch of route (for example, a pulse with a given route), or the route is uniquely determined from the input by a mapping that is fixed in advance and can be reviewed;  
Designation-determined: the system constructs the route according to bearer designations (for example, events assemble their routes from the registered source-drive bearer and the gate and tuning bearers), and the distinction of the bearers comes from the designation;  
Route selection within the field: the route is selected in competition by the field's own continuation, and the declared reviewable records show that no input or designation determines this stretch of route;  
Insufficient material: the mechanism determining this stretch of route cannot be reviewed, for example when an undeclared table lookup or indirect mapping may exist.  
For a formation witness g, SelfRouted(g) ∈ {1, 0, ⊥}: 1, route selection within the field; 0, input specification or designation-determined; ⊥, insufficient material. The scope of review of SelfRouted is set by the bearing at the endpoint: every structure that enters the bearing of SD, GC or TI at τ, as well as every structure bearing the Intention-Domain position, must be reviewed, because the question is who obtains the distinction of the Intention bearers; the one exception is the route along which the general Law and Probability structures in P\_I are formed, which is a question of the source of the probability organization itself and is handed to The Source Form of Probability. The scope of review is not set by boundary identity: on a boundary without pre-installation, the bearers of SD, GC and TI are precisely undesignated structures on the general medium, and they are reviewed all the same. That a route passes through a bearing edge does not by itself show that the bearer was named externally; that no route is given does not by itself show that the bearer was selected by the field; in both cases the actual source of determination must be reviewed. Legal external induction is not the same as an external party completing the formation on the system's behalf: inputs may exist; the question is who obtains the distinction of the bearers.

def minsuff(S, R):
    r = R[S]
    if r['replayable'] is not True: return None
    if r['suff'] is False: return False
    if r['suff'] is None: return None
    subs = [S - frozenset(x) for k in range(1, len(S) + 1) for x in itertools.combinations(sorted(S), k)]
    if any(R[T]['replayable'] is True and R[T]['suff'] is True for T in subs): return False
    if all(R[T]['replayable'] is True and R[T]['suff'] is False for T in subs): return True
    return None

                full_history_sufficient=t3(R[frozenset(ATOMS)]['suff']), full_history_minimal=t3(ms[frozenset(ATOMS)]))

def probe(I):

    base = qual(I); hits = {it: [] for it in ITEMS}

def struct_edges(s):
    if s.startswith('law_') or s.startswith('bind_'): return list(DIMS_R[s[-1]])
    if s == 'rate_R': return [e for r in DIMS_R.values() for e in r]

def carrier_vars(s):
    """All state variables that carry a structure (used to classify Dep_X): sediment of its carrier edges, deposits of
    their end nodes, binding, and the path dynamics of a dimension's carrier path."""
    es = struct_edges(s); v = [('sed',) + e for e in es] + [('d', n) for n in sorted({n for e in es for n in e})]
    if s.startswith('bind_'): v = [('bind', s[-1])]
    if s.startswith('law_'): v += [('pathdyn', s[-1])]
    if s == 'rate_R': v += [('pathdyn', k) for k in sorted(DIMS_R)]
    return v

def withdraw_vars(s):
    """Wd withdraws the variables on the structure's carrier edges (sediment and repetition records), binding and the
    dimension's path dynamics; node deposits, shared by every structure through a node, are not withdrawn."""
    return [v for v in carrier_vars(s) if v[0] != 'd']

def generation_vars(s):
    """Variables that decide generation versus threshold crossing: carrier-edge sediment and repetition records,
    binding.  Node deposits (shared) and path dynamics (initialised non-empty) do not take part."""
    return [v for v in carrier_vars(s) if v[0] in ('sed', 'bind')]

def _sed_empty(x): return x[0] == 0.0 and not x[1]

def formation_events():
    """Last 0 -> 1 transition of each structure in the actual history; writers (atoms whose events traced its carrier
    edges up to the transition); the kind of change at the transition (section 3.6 (一))."""
    w = window(); evs = w['evs']; st_tau = evs[-1]['st']; st0 = w['X0']['structures']; v0 = w['X0']['vars']; out = {}
    for s in st_tau:
        if st_tau[s] is not True: out[s] = None; continue
        seq = [st0[s]] + [e['st'][s] for e in evs]
        ups = [i for i in range(1, len(seq)) if seq[i] is True and seq[i - 1] is not True]
        if not ups: out[s] = None; continue
        j = ups[-1] - 1; e = dict(evs[j]); es = struct_edges(s)
        wev = [x for x in evs[:j + 1] if x['route'] and set(es) & set(zip(x['route'], x['route'][1:]))]
        writers = sorted({x['atom'] for x in wev}); writer_events = tuple(x['idx'] for x in wev)
        pre = v0 if j == 0 else evs[j - 1]['vars']; post = evs[j]['vars']
        switch = any(pre[(k,) + x] != post[(k,) + x] for x in es for k in ('Avail', 'mask', 'th', 'topo'))
        desig = not evs[j]['designations_unchanged']
        writer_at = e['atom'] in writers and bool(e['route']) and bool(set(es) & set(zip(e['route'], e['route'][1:])))
        # "before": before the first writer event (in this window no other event writes these variables, so X0)
        first_w = min(i for i, x in enumerate(evs[:j + 1]) if x['idx'] in writer_events) if writers else j
        before = v0 if first_w == 0 else evs[first_w - 1]['vars']
        empty0 = all(_sed_empty(before[v]) for v in generation_vars(s))
        if writer_at and (switch or desig): ctype = 'mixed'
        elif switch and desig: ctype = 'mixed'
        elif switch: ctype = 'enabling'
        elif desig: ctype = 'designation'
        elif not writer_at: ctype = 'other'
        else: ctype = 'generation' if empty0 else 'threshold_crossing'
        e['change_type'] = ctype; e['writers'] = writers; e['writer_events'] = writer_events
        out[s] = e
    return out

FORMATION_TYPES = ('generation', 'threshold_crossing')   # change types that can carry a formation (section 3.6)

def external_edit_events(H):

    return sum(1 for ev in H if EVENT_KINDS.get(ev[0][0]) not in ('formation pulse', 'field pulse'))

def no_priv_write():
    """NoPrivWrite holds by construction (the window only calls the model's pulses and decay steps); checked per event:
    the designations and the generic probability-layer items are never changed."""
    w = window()
    return all(e['designations_unchanged'] and e['prob_generic'] == w['X0']['prob_generic'] for e in w['evs'])

def _snap(I, vs):
    b = {}
    for v in vs:
        if v[0] == 'sed': e = v[1:]; b[v] = (I.F.g[e], copy.copy(I.F.rep[e]))
        elif v[0] == 'bind': b[v] = (I.P.bind[v[1]], list(I.P.bind_rep[v[1]]))
        elif v[0] == 'pathdyn': b[v] = list(I.F.pathdyn[v[1]])
    return b

def _withdraw(I, b):
    """Wd for the reference instance: withdraw the event's traces on the listed variables, keep its own decay step."""
    for v, x in b.items():
        if v[0] == 'sed':
            e = v[1:]; I.F.g[e] = max(0.0, x[0] - I.F.lam_g); I.F.rep[e] = x[1]
            while I.F.rep[e] and I.F.t_sed - I.F.rep[e][0] > I.F.W: I.F.rep[e].popleft()
            I.F.Om[e] = I.F._omega(e)
        elif v[0] == 'bind': I.P.bind[v[1]] = max(0.0, x[0] - I.P.bind_decay); I.P.bind_rep[v[1]] = x[1]
        elif v[0] == 'pathdyn': I.F.pathdyn[v[1]] = x

def replay_wd(H, keep, wev, sset):
    """Replay the kept events; after each event whose index is in `wev` (the witness's exact events H_g), apply Wd to
    the structures in `sset`.  Returns the three-valued reading of N_I at tau and, for each structure of sset, its
    reading at tau and the index of the event of its last 0 -> 1 transition in this replay."""
    I = blank(); vs = sorted({v for s in sset for v in withdraw_vars(s)}); wev = set(wev)
    prev = {x: structures(I)[x] for x in sset}; last = {x: None for x in sset}
    for i, ev in enumerate(H):
        k = ev[0] in keep
        if k and i in wev:
            b = _snap(I, vs); do_event(I, ev, True); _withdraw(I, b)
        else:
            do_event(I, ev, k)
        if k:
            st = structures(I)
            for x in sset:
                if st[x] is True and prev[x] is not True: last[x] = i
                prev[x] = st[x]
    return qual(I)['Intent'], {x: dict(at_tau=prev[x], last_up_event=last[x]) for x in sset}

def replay_formed(S):
    """In the plain replay of S: for each structure, the index of the event of its last 0 -> 1 transition and its reading at tau."""
    key = ('rf', S)
    if key in _C: return _C[key]
    _, _, evs = run_points(window()['H'], keep=set(S), record_events=True)
    st0 = window()['X0']['structures']; out = {}
    for s in st0:
        seq = [st0[s]] + [e['st'][s] for e in evs]
        ups = [i for i in range(1, len(seq)) if seq[i] is True and seq[i - 1] is not True]
        out[s] = dict(at_tau=seq[-1], last_up_event=(evs[ups[-1] - 1]['idx'] if ups else None))
    _C[key] = out; return out

def form_bear(S, wev, sset):
    """FormBear(g; H_s), three-valued (section 3.6 (四)); g is given by its exact events wev (indices into H_obs) and
    its structures sset.  The withdrawal must actually cancel g's formation: if a structure of g is still formed by an
    event of g in the withdrawal replay, the reading is ⊥."""
    key = ('fb', S, tuple(sorted(wev)), tuple(sorted(sset)))
    if key in _C: return _C[key]
    R = reduction()
    if R[S]['replayable'] is not True or R[S]['suff'] is None: v = None
    elif R[S]['suff'] is False: v = False
    else:
        rf = replay_formed(S)
        same = all(rf[s]['at_tau'] is True and rf[s]['last_up_event'] in set(wev) for s in sset)
        if not same: v = False
        else:
            r, wst = replay_wd(window()['H'], set(S), wev, sset)
            if any(x['at_tau'] is True and x['last_up_event'] in set(wev) for x in wst.values()): v = None
            elif r is None: v = None
            else: v = (r is False)
    _C[key] = v; return v

def witnesses_of(S):
    """Formation witnesses available in S: one per structure; H_g is the exact writer events up to the transition (all
    of whose atoms must lie in S); the atom set is used only for candidate membership and carrier reports."""
    w = window(); fe = formation_events(); q_tau = w['pts'][w['tau']]; dep = w['X0']['dep']; out = []
    for s, e in fe.items():

        if not set(e['writers']) <= set(S): continue

        if any(eb.values()): out.append(dict(atoms=tuple(e['writers']), events=tuple(e['writer_events']), structures=(s,), EndBind=eb))
    return out

def bearing_witnesses(S):
    """Single-structure witnesses with FormBear, and minimal composite witnesses (unions of the exact events and
    structures of non-bearing single witnesses) whose withdrawal breaks sufficiency while that of every proper sub-union
    does not (section 3.6 (四)).  A union with a proper sub-union read ⊥ cannot be shown minimal and is recorded as ⊥."""
    key = ('bw', S)
    if key in _C: return _C[key]
    ws = witnesses_of(S)
    for x in ws: x['bear'] = form_bear(S, x['events'], x['structures'])
    tested = []
    if reduction()[S]['suff'] is True:
        nb = [i for i, x in enumerate(ws) if x['bear'] is False]
        found = []; bot = []; base = list(ws)
        for k in range(2, len(nb) + 1):
            for comb in itertools.combinations(nb, k):
                if any(f < set(comb) for f in found): continue
                xs = [base[i] for i in comb]
                atoms = tuple(sorted({a for x in xs for a in x['atoms']})); evx = tuple(sorted({i for x in xs for i in x['events']}))
                ss = tuple(sorted({t for x in xs for t in x['structures']}))
                b = form_bear(S, evx, ss)
                if b is True and any(f < set(comb) for f in bot): b = None
                tested.append(dict(structures=ss, events=len(evx), bear=t3(b)))
                if b is True: found.append(set(comb))
                if b is None: bot.append(set(comb))
                if b is not False:
                    ws.append(dict(atoms=atoms, events=evx, structures=ss, EndBind={it: any(x['EndBind'][it] for x in xs) for it in ITEMS},
                                   bear=b, composite=True))
    _C[key] = ws; _C[('ct', S)] = tested; return ws

def numeric_horizon(max_rounds=400, seed=0):
    """Round at which the reference program first fails numerically (OverflowError) under the same input class."""
    I = blank(); rng = random.Random(seed)

            for _ in range(2): I.P.formation_pulse(rng.choice(['A', 'X']))

        except OverflowError:
            return r
    return None

def abstract_eval(atoms, suff, witnesses, genesis=True, spec=None):
    """atoms: H_obs; suff: frozenset -> bool; witnesses: list of (atom set, field 0/1, endbind {item:0/1});
    genesis: the three-valued first-qualification event at tau; spec: {item: 0/1} at the boundary.
    Every history is replayable.  With genesis not 1 the core is not 1 for any candidate."""
    dom = [frozenset(S) for k in range(len(atoms) + 1) for S in itertools.combinations(atoms, k)]
    R = {S: dict(replayable=True, suff=suff(S)) for S in dom}
    W = [(x + (1,)) if len(x) == 3 else x for x in witnesses]     # (atoms, field, endbind, bear)
    def link(S, bearing=True):
        # bear is the declared FormBear in a sufficient candidate; in an insufficient candidate FormBear = 0 (section 3.6)
        ws = [bool(f) and any(eb.values()) and ((bool(b) and R[S]['suff'] is True) or not bearing) for g, f, eb, b in W if set(g) <= S]
        return or3(*ws) if ws else False
    cands = [S for S in dom if S]
    fam = [S for S in cands if and3(genesis, link(S), minsuff(S, R)) is True]
    sdd = genesis and R[frozenset()]['suff'] is False and all(minsuff(S, R) is not None for S in cands if link(S))
    out = dict(family=[sorted(S) for S in fam], Genesis=t3(genesis),
               Source='OutDom' if genesis is False else 1 if (sdd and fam) else 0 if sdd else '⊥',
               empty_sufficient=t3(R[frozenset()]['suff']),
               spectrum={'+'.join(sorted(S)): ''.join(str(int(any(set(g) <= S and f and b and eb.get(it) for g, f, eb, b in W))) for it in ITEMS) for S in fam})
    fam_nb = [S for S in cands if and3(genesis, link(S, False), minsuff(S, R)) is True]
    if fam_nb != fam or any(len(x) == 4 for x in witnesses):
        out['without_bearing_rule'] = dict(family=[sorted(S) for S in fam_nb],
            spectrum={'+'.join(sorted(S)): ''.join(str(int(any(set(g) <= S and f and eb.get(it) for g, f, eb, b in W))) for it in ITEMS) for S in fam_nb})
    if spec is not None:
        # FormInternal_X from the witnesses: X is 0 at X0 (Spec_X = 0 and not held), so it needs a window formation
        fi = {it: (1 if any(f and eb.get(it) for g, f, eb, b in W) else '⊥') for it in ITEMS}
        no_pre = all(spec[it] == 0 for it in ITEMS)
        fb = any(f and b and any(eb.values()) for S in fam for g, f, eb, b in W if set(g) <= S)
        out.update(FieldBorn=int(fb), NoPreinstalledIntent=int(no_pre), FormInternal=fi,
                   InternalSource=int(bool(fam) and no_pre and all(fi[it] == 1 for it in ITEMS)))
    return out

                                             (('b',), 1, {it: int(it == 'TuneInterface') for it in ITEMS}, 1)])
    # one item formed, the other three never: N_I never 1, no first event, no source
    out['single_item'] = abstract_eval(['hS'], lambda S: False, [(('hS',), 1, {it: int(it == 'SourceDrive') for it in ITEMS})],
                                       genesis=False)
    # four items formed in four runs, each run's candidate has only its own item: no candidate has a first event
    out['four_runs'] = {it: abstract_eval(['h'], lambda S: False, [(('h',), 1, {x: int(x == it) for x in ITEMS})], genesis=False)['family']
                        for it in ITEMS}
    return out
