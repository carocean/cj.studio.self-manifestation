# The Reachability Form of Principle Generation

## Section One　Purpose and Entry Conditions

### 1.1　Purpose

The Construction Form of the Principle Running Base has already constructed a runnable Principle base: within legal instances of the same specification, several Laws form from a weak state; one Law acquires Principle qualification relative to another by the same duty through which it became a Law, and currently acts; the field dynamics themselves reroute, leave a trace, and sediment; and a candidate Law that did not stand at the outset finally acquires qualification by one and the same general Law criterion. The construction has been given.

What remains is the problem of reachability: starting from a declared initial state, using only the permitted inputs frozen in advance and the system's own legal dynamics, does there exist a finite legal path along which the formal solution set of the candidate Law turns from empty to non-empty; and does that path contain an actual counter-holding generative history possessing the source qualification of Principle and Principle-action?

What follows answers only that question: it does not reconstruct the Principle base, does not redefine Law, Principle, or Act, and does not reopen what a Principle must have in order to stand.

### 1.2　Entry conditions

　　(i) The construction has been given: The Construction Form of the Principle Running Base v1.0 and its official construction model v4.12.  
　　(ii) The initial state is clearly delimited: declared in Section Two.  
　　(iii) The permitted input set is clearly delimited: declared in Section Three, and frozen before the path is constructed.

1.3　Division of labour with neighbouring form-texts

The seventh text answers "what a satisfier looks like"; here the answer is "whether one can get there from a given initial state." The qualification criteria at the Law layer are borne by the Law Group-Form, and the criteria of Principle and Principle-action by the first six texts of the Principle Group-Form; what follows argues about paths upon those existing criteria alone. The stability, boundary, and grading of Principle, and the probabilistic structure of generation, each belong to their own form-texts and are not touched here.

## Section Two　Task Specification, Initial State, and Target

### 2.1　The frozen task specification

　　Ξ\_GR = (Spec, P, A, d\*, N, I\_N, U^adm),

where Spec is the legal running specification already constructed, P the bearing Law already standing as a Principle, A the target Law against which P is a Principle, d\* the same duty that makes P a Principle, N the candidate Law identity frozen in advance, I\_N its entry domain, and U^adm the permitted input set.

Ξ\_GR does not change along the whole path. It is a frozen task specification, not a dynamic state; the dynamic state is represented by F\_t, the current field state, alone, and no composite state structure is erected.

### 2.2　The target set

　　G\_N = { F \| 𝒮(F, N, I\_N) ≠ ∅ }.

This is the identity-level target at which the candidate Law N has acquired at least one legal formal witness. The fixed-witness version

　　G\_{N,R} = { F \| R ∈ 𝒮(F, N, I\_N) }

appears only as a stronger subtask: the instance path of Section Six in fact hits G\_{N,R\_N}, and G\_{N,R\_N} ⊆ G\_N, so it hits G\_N as well. The general theorem requires only that the solution set be non-empty, and fixes no preselected R; that the instance happens to give one R is a fact of the instance, not a requirement of the theorem.

### 2.3　Declaration of the initial state

The formal-layer initial condition:

　　𝒮(F₀, N, I\_N) = ∅, that is, F₀ ∉ G\_N.

This is the starting point of the crossing to be made. "Law(N)=0" is not taken as the sole initial condition — the non-emptiness of the solution set and the read-back at the Law layer are two layers, and to mix them is to drift between them.

The initial conditions on the Principle-source side:

　　Law(P) = 1, Law(A) = 1, Principle(P; A, J) = 1, with d\* the same fixed duty through which these stand.

The Principle here carries its relation domain J as upstream; the relational context at issue is j ∈ J, and neither j nor J is changed anywhere along the path.

Act = 1 is not required in the initial state. Acting is a current fact within the running of the path, not an item declared of the initial state.

## Section Three　Permitted Inputs and Legal Supported Successors

### 3.1　Permitted inputs

　　u\_k ∈ U^adm.

U^adm is frozen once by Ξ\_GR before the path is constructed; its content is declared with the task specification and is not prescribed generally by this form-text. Wherever U^adm appears in a theorem, it means that one set frozen by that declaration. To enlarge it is to declare afresh and to run the reachability argument again.

In the running instance used, U^adm contains one input only:

　　u\* = ( {s, hR}, {dR} ),

that is, the normal inflow together with the activation of the frozen same duty.

Two things must be kept apart: activating d\* is an input; Act(d\*)=1 is a fact obtaining after the system has run according to Spec. Acting is not a button that can be pressed from outside, and no path may treat it as an operation.

### 3.2　System dynamics

The following occur automatically by Spec, are not external operations, and do not count within U^adm: field pressure and flow, accumulated depth, fullness, impedance, blocking, tuning, branch competition, actual execution, trace, sedimentation, re-walk, Ω, and decay.

### 3.3　Legal supported successors

Define the set-valued map

　　F\_GR(F, u)

as the set of legal one-step successors that can be produced, under the frozen task specification and the input u, by the normal system dynamics already declared in Spec and by nothing else.

It must be set-valued: the branch competition of the reference implementation contains a random selection, and after one step the state may land on any of several legal states. A random branch belongs to the system's support and not to externally controllable action; it must not be written as an assignable operation.

F\_GR is determined by Spec's dynamics and the given input alone: the forbidden operations listed in 3.4 lie outside Spec's normal dynamics, so successors obtained through them do not belong to any F\_GR(F, u) to begin with, and need not be excluded separately — the list of prohibitions binds whoever constructs the path; it does not pare down the successor set.

### 3.4　Forbidden operations

The positive path forbids the use of: branch forcing; external gating; external editing; writing depth directly; writing re-walk directly; setting Law qualification directly; altering the topology midway; changing the duty midway; changing the binding of Principle qualification midway; changing the candidate Law midway; modifying the Law criterion or its thresholds during running; enlarging the permitted input set midway.

Gating, editing, and branch forcing may appear only in control experiments, and must not enter the positive reachability argument.

## Section Four　Finite Legal Paths and Principle-Source Supported Reachability

### 4.1　Paths

　　Γ = ( F₀, u₀, F₁, …, u\_{H−1}, F\_H ).

Γ is legal if and only if, for every k \< H:

　　u\_k ∈ U^adm, and F\_{k+1} ∈ F\_GR(F\_k, u\_k).

4.2　Principle-source supported reachability

First define supported reachability with no restriction of source:

　　SuppReach\_GR(F₀, N) = 1　⟺　there exists a finite legal path Γ: F₀ ⇝ F\_H with F\_H ∈ G\_N.

Then define its source-restricted subclass:

　　SuppReach^PrinAct\_GR(F₀, N) = 1

means: there exists a finite legal path Γ: F₀ ⇝ F\_H with F\_H ∈ G\_N, and within the path there is an actual counter-holding generative history possessing the source qualification of Principle and Principle-action — that is, at least one Act(P; A, d*) = 1, and, within the same experiment, the counter-hold discharged by d* enters, by way of the normal field dynamics, the actual execution, trace, and sedimentation history of some legal witness of the terminal state.

"PrinAct" marks the source class of this path only; it is not a new ontological predicate. All its constituents — the same d\*, Principle, Act, actual execution, trace, sedimentation — are taken from upstream and none is made anew here.

Restriction of source type: the PrinAct signed here is of the direct type — at least one actual execution, trace, and sedimentation event entering a legal witness of the terminal state occurs within the same experiment as a legal Act. Another type is conceivable, the indirect: acting first alters the field state, the bearing Law then falls at rest, and the already altered field state goes on, in later experiments without acting, to reroute, sediment, and finally make N stand. That cross-experiment initiation-and-completion type does not lie within what this version signs, and is not thereby excluded either; no general adjudication of it has been established.

## Section Five　Restriction on the Principle Source

Source qualification and physical dynamics must be kept apart.

Source qualification means: the duty producing that counter-hold is the same duty bound to the bearing Law when it acquired Law qualification, and that duty has acquired Principle qualification in the current experiment and has actually been registered as acting. It is given by the upstream criteria, and is a fact of identity.

Generative dynamics means: the field changes produced, after that counter-hold enters the degree of freedom the target holds, by blocking, tuning, competition, execution, trace, and sedimentation. It is given by Spec's dynamics, and is a fact of dynamics.

The two are not the same, and must be kept in three layers. First, Principle qualification does not entail acting: where Principle stands while nothing is currently triggered, or where the target is not in bearing on this beat, no acting is registered. Second, once acting stands, the current counter-hold of that same duty has in fact been discharged — that is the content of the upstream Act itself, not an empty mark — but it still does not entail that some designated successor must be selected, leave a trace, sediment, and finally make N stand: branch competition is the field's affair, and is not settled by the identity of the acting. Third, conversely, a counter-hold of the same shape and its subsequent field dynamics do not entail the source identity of Principle and Principle-action either; the non-bound-duty control of Section Ten is the counterexample.

Nothing below claims that the identity of Principle supplies any force of its own. Act is not a second qualification, nor a mark that could alter the physics independently of the counter-hold it discharges.

## Section Six　Construction of the Path: An Explicit Legal Path

### 6.1　Protocol

Take the specification constructed by the seventh text together with its frozen initial state. At each step only u\* is applied, that is, each experiment invokes the normal inflow and the activation of the same duty, everything else being left to the system dynamics; none of the forbidden operations of 3.4 is used.

### 6.2　The explicit path (seed 0)

Initial state: A, P\_R, P\_D, Q, B are each Laws, N is not a Law, and 𝒮(F₀, N, I\_N) = ∅ — the Law criterion fails on the read item, with no witness.

From F₀, apply u\* step by step:

　　Experiments 1–4: the Principle qualification of dR, the same duty of P\_R, stands from the initial state onward and is retained; each experiment registers acting; its counter-hold enters the impedance of the degree of freedom A holds, the result quantity falls, blocking accumulates, the openness of the old path is lowered and that of the bypass raised; the branch still takes the old path.  
　　Experiment 5: branch competition takes the bypass m→x actually for the first time; that edge leaves a trace, sediments, and registers a re-walk, and its successor path is executed accordingly.  
　　Experiments 6–14: the bypass is actually executed again and again, and depth and re-walk accumulate.  
　　Experiment 15: the re-walk count reaches 11, Ω is 1, the depth exceeds the threshold, every edge of N's path has depth, re-walk, and Ω, and one and the same general Law criterion adjudicates

　　　　𝒮(F₁₅, N, I\_N) ∋ R\_N = { s→m, m→x, x→n, n→d },

so F₁₅ ∈ G\_N and H = 15.

Throughout, Law(A)=1, Law(P\_R)=1, Principle(dR)=1, and every experiment has Act(dR)=1 (15/15). Every edge in the terminal witness has its own history of actual execution and sedimentation; the key bearing that this generative path from F₀ newly adds and closes lies in the bypass m→x — the other edges of the witness were already mature structures on F₀. The bypass m→x is not of zero depth on F₀: its depth is 0.02167 and its re-walk zero, far from enough to acquire qualification. From F₀ onward, all the newly added actual execution, re-walk, and sedimentation needed to carry it from that shallow state to terminal qualification (re-walk 0→11, depth 0.02167→1.04569) occur within the generative path after dR currently discharges its counter-hold.

Every step of this path uses u\* alone, and every successor belongs to F\_GR(F\_k, u\*), so Γ is legal; the terminal state hits G\_N; and the path contains a counter-holding generative history with legal source qualification. Hence

　　SuppReach^PrinAct\_GR(F₀, N) = 1

stands on this instance.

6.3　The range of reproduction of the path

The same protocol reaches G\_N on all 200 seeds. Checking experiment by experiment before arrival: Law(A) does not lapse 200/200, Law(P\_R) does not lapse 200/200, Principle(dR) does not lapse 200/200, and every experiment registers acting 200/200. The step counts of arrival are in Section Eight.

## Section Seven　The Finite-Rank Reachability Argument

Section Six gives one explicit path, and that already suffices to support the theorem of Section Nine. What follows gives, in addition, a general sufficient condition of reachability, for use in cases other than the instance constructed here; it is not the ground of the proof in Section Nine, and this form-text has constructed no rank function for the instance of Section Six.

Theorem 7.1　Finite-rank supported reachability theorem

Let D be a declared state domain, D ⊆ the legal states and closed under the successors taken in (ii), and let there be a function ρ: D → ℕ satisfying:

　　(i) ρ(F) = 0 ⇒ F ∈ G\_N;  
　　(ii) for every F ∈ D with ρ(F) \> 0, there exist a u ∈ U^adm and at least one F′ ∈ F\_GR(F, u) with F′ ∈ D and ρ(F′) \< ρ(F).

Then for every F ∈ D there exists a finite legal supported path from F reaching G\_N, that is, SuppReach\_GR(F, N) = 1.

Proof. From F, take successors repeatedly by (ii): each one taken remains within D, so (ii) may continue to be applied; ρ takes values in the natural numbers and strictly decreases each time, so after at most ρ(F) steps it can decrease no further, at which point that state's ρ can only be 0, and by (i) it falls within G\_N. Every step of the sequence so obtained uses a permitted input and lies within the legal successor set, so it is a legal path. □

A strict decrease on the natural numbers falls by at least one each step, so the length of that descending path satisfies H ≤ ρ(F).

The quantifier of this theorem is "for each F there exists a descending successor," and what it yields is accordingly only "there exists a path." It does not yield "every legal path arrives," nor any probabilistic conclusion.

ρ is a tool of proof only, and is no new ontology of Principle or of Law; it enters no read-back.

To obtain SuppReach^PrinAct requires one step more: the descending path constructed must be independently verified to satisfy the source condition of Section Four — the path must really contain Act(P;A,d\*)=1, and the counter-hold it discharges must enter the actual execution and sedimentation history of the terminal witness. The descent of the rank does not of itself guarantee source qualification.

## Section Eight　Cost and Bounds on the Number of Steps

Three layers, not to be mixed.

Instance length. The explicit path of seed 0 has H = 15. This is a strict fact of the instance.

Empirical bound. The distribution of arrival steps for the same protocol over 200 seeds is {12:1, 13:13, 14:72, 15:98, 16:16}, so 12 ≤ H ≤ 16 holds over that set of 200 seeds. This is an empirical bound, not a theoretical upper bound.

Theoretical bound. Where the conditions of Theorem 7.1 hold, a descending path satisfies H ≤ ρ(F₀). But this form-text has constructed no concrete ρ and D for the running instance of Section Six, nor verified its two conditions; the H = 15 of Section Six is given directly by the actual path and is not derived from Theorem 7.1. For general Sedimentation-Fields, general candidate Laws, and general initial states, no uniform rank function is given, and no uniform upper bound on the number of experiments is given either.

　　The rank function of the instance: not constructed.  
　　A general uniform bound on the number of steps: not established.

The other quantities of the instance are likewise facts of the instance and must not be raised into theoretical constants: the first actual rerouting occurs at experiment 5; the re-walk count of the bypass in the terminal witness is 11; the depth is 1.0457; Ω is 1.

## Section Nine　The Reachability Theorem

Theorem 9.1　Principle-source finite supported reachability theorem

Let the task specification Ξ\_GR be frozen, and let:

　　(i) 𝒮(F₀, N, I\_N) = ∅;  
　　(ii) there exists a finite path Γ = (F₀, u₀, …, u\_{H−1}, F\_H) with u\_k ∈ U^adm and F\_{k+1} ∈ F\_GR(F\_k, u\_k) for every k \< H;  
　　(iii) the path contains at least one Act(P; A, d\*) = 1;  
　　(iv) within that same experiment, the counter-hold discharged by d\* enters, by way of the normal field dynamics, the actual execution, trace, and sedimentation history of some legal witness of the terminal state;  
　　(v) 𝒮(F\_H, N, I\_N) ≠ ∅.

Then

　　(a) SuppReach^PrinAct\_GR(F₀, N) = 1;  
　　(b) where the positive-end read-back condition bundle H⁺\_M of The Mathematical Form of Law holds, further, Law\_{F\_H}(N, I\_N) = 1.

Proof. (a): (ii) and (v) give a finite legal supported path hitting G\_N; (iii) and (iv) give the restriction of source for that path — within it there is an actual counter-holding generative history possessing the source qualification of Principle and Principle-action, and that history enters the terminal witness. By the definition of 4.2, therefore, SuppReach^PrinAct\_GR(F₀, N) = 1. (i) further guarantees that the initial state is not within G\_N, so what is obtained here is not a Continuation inside the target but a real generative crossing 𝒮: ∅ → ≠∅.

(b): (v) gives 𝒮(F\_H, N, I\_N) ≠ ∅; where H⁺\_M holds, the positive-end read-back of The Mathematical Form of Law gives ∃R\[ Established\_{F\_H}(R) ∧ Govern\_{F\_H}(N; R, I\_N) \]; and then, by the sufficient direction of The Necessity Form of Law, where its working domain and inherited antecedents hold, Law\_{F\_H}(N, I\_N) = 1. That conclusion is conditional upon H⁺\_M and upon the antecedents of that sufficient direction; it is not unconditional merely because (a) is. □

The explicit path of Section Six satisfies (i) through (v) item by item, so the antecedent of the theorem is non-empty on that instance.

9.2　Conditional read-back to the Law layer

What Theorem 9.1 proves directly is a crossing of the formal solution set from empty to non-empty alone:

　　𝒮: ∅ → ≠∅.

Conclusions at the Law layer must pass through the upstream read-back and must not be equated directly:

　　where the positive-end read-back condition bundle H⁺\_M of The Mathematical Form of Law holds, 𝒮(F\_H, N, I\_N) ≠ ∅ gives ∃R\[ Established\_{F\_H}(R) ∧ Govern\_{F\_H}(N; R, I\_N) \];  
　　and then, by the sufficient direction of The Necessity Form of Law, Law\_{F\_H}(N, I\_N) = 1.

The conditions of these two steps are inherited under their original attributions and are not upgraded here. Whoever cites the conclusions of this form-text and needs the Law layer must inherit H⁺\_M and the antecedents of the sufficient direction along with them. The converse has its discipline too: 𝒮(F, N, I\_N) = ∅ must not be read directly as Law(N) = 0; the negative end has its own condition bundle, and belongs to The Boundary Form of Law.

9.3　The probability of a path under a random kernel

The branch competition of the reference implementation is given by a random kernel. If every step of a finite path satisfies K(F\_{k+1} \| F\_k, u\_k) \> 0, then

　　P\_K(Γ) = ∏\_{k\<H} K(F\_{k+1} \| F\_k, u\_k) \> 0.

The path of Section Six was in fact generated by that kernel, so the transition probability of each of its steps is positive, and the probability of that path is therefore strictly positive. The branch probability at experiment 5 has been measured as 0.889660228101722 (Appendix A); the values at the other steps are not recorded one by one, and are guaranteed positive only by this: that the path was generated by actual sampling from that kernel.

This must not be written as probability one, nor as almost sure arrival, nor as every trajectory arriving; and no probabilistic equality whatever may be inferred from the total success over 200 seeds.

## Section Ten　Source and Boundary

The experiments of this section serve to draw boundaries only, and take no part in the proof of Section Nine.

10.1　The local same-randomness counterfactual

Take one experiment before the first arrival at G\_N, with the same prior state, the same normal inflow, and the same random state fixed, the sole intervening difference being whether the same duty is activated: all 30 seeds satisfy it — the positive branch registers acting, actually takes the bypass, and that edge sediments positively; the negative branch does not take the bypass and that edge sediments zero. Seed 0 at experiment 5: the positive branch's selection probability for that branch is 0.889660228101722 with sedimentation 0.08731367897583661; the negative branch's probability is 2.770821959531943e-29 with sedimentation 0. One and the same random draw therefore yields different actual Continuations on the two branches.

This shows that the counter-hold currently discharged by d\* actually altered the branch competition and produced the sedimentation history used by the terminal witness. It does not show that the identity "acting" of itself supplied any additional force.

### 10.2　Whole-path same-randomness pairing

From the same initial state, the positive track applies u\* at each experiment while the negative track applies the same normal inflow and activates no duty. The shared random stream is enforced by an external master random source: before each experiment, the master source injects the same experimental random stream into both tracks. The model samples only at branch competition, so injection experiment by experiment makes the random streams within that experiment the same on both tracks; it does not rely on the unproved assumption that "the same seed at the start means the same stream throughout." Sampling counts are compared experiment by experiment by a counter, and the number of experiments on which the two tracks' counts differ is 0. All 30 seeds satisfy it: at the very moment the positive track first reaches G\_N, the negative track has not arrived; the cumulative count of actual executions of the bypass on the negative track is 0, its re-walk zero, and its Ω zero.

This shows that, under the same initial state, the same normal inflow, and the same experiment-by-experiment random realization — the sole intervening difference being whether d\* is activated — the counter-hold discharged by d\* is dynamically load-bearing for that finite generative path. It does not show that, without that duty, N is forever unreachable in every future.

### 10.3　The same-effect non-identical duty

There is another duty that shares d*'s bearer, target, restricted edge, gain, and terminal, and whose physical effect is the same; the sole difference is that it is not the duty bound to the bearing Law when that Law acquired its Law qualification. Its Principle qualification and acting are accordingly both zero, while d*'s are both one.

The long-range control follows the same shared-randomness discipline as 10.2: the same initial state, the same normal inflow, the same random stream injected by the master source experiment by experiment, the same duty parameters, the sole difference being duty identity; 60 experiments are run for each, and the number of experiments on which the two tracks' sampling counts differ is 0. The arrival moments of the two agree seed by seed (30/30 the same, with the same distribution {13:1, 14:9, 15:17, 16:3}), and that non-bound duty likewise reaches G\_N 30/30.

Hence it is stated expressly here:

　　equivalence of dynamics ⇏ equivalence of source qualification.

One must not write "only a Principle can generate N," must not write "the identity of Principle supplies a force of its own," must not write "a non-bound duty cannot generate N," and must not write "acting itself alters the physics independently of the counter-hold it discharges." The controls above have excluded each of these four in turn.

### 10.4　Controls with external mechanisms

Gating, external editing, and a non-bound duty can all reach the target set G\_N of the same candidate N: 30/30 arrival each, with a history of acting of zero.

Hence the terminal

　　𝒮(F, N, I\_N) ≠ ∅

does not of itself prove that N was generated by Principle; and even where, with H⁺\_M and the antecedents of the Law-side sufficient direction holding, it is read back further to Law(N) = 1, the Law identity itself still carries no proof of its source of generation. A result of qualification cannot be used to infer a genealogy of generation backwards. The source must be obtained from the complete history of the path: Law(P) → Principle(P; A) → Act(P; A) → actual execution → trace → sedimentation → the terminal witness.

10.5　What does not enter the general theorem

In the instance, the latter stretch of the candidate Law is supported by another already standing Law providing mature support. That role belongs to the instance alone, and must not be written as a general necessary condition of a Principle generating a new Law; the general theorem requires only that the terminal solution set be non-empty, and does not fix where the existing support of the terminal witness comes from.

### 10.6　Negative adjudication

Only positive reachability is formally proved here. To sign

　　Reach = 0,

one must prove that no permitted path whatever, at any finite number of steps, hits G\_N. Several ablations carried in the seventh text did not arrive within 60 experiments, which shows only that they did not arrive under that declared protocol within that time domain, and does not suffice to be raised into global unreachability. Wherever the path space has not been exhausted, the verdict is recorded as undecided.

## Section Eleven　Declaration of Strength

Reachability strength is attained: the initial state has been declared; the permitted input set was frozen before the path was constructed; the regime of legal successors is explicit; a complete finite legal path has been given; the bounds that can be given have been given, and those that cannot have been declared.

What is signed:

　　SuppReach^PrinAct\_GR(F₀, N) = 1, holding on the initial state declared in Section Two, the permitted inputs frozen in Section Three, and the path given in Section Six;  
　　the path given has strictly positive probability under the declared random kernel.

What is not signed: any controllable reachability; any conclusion of probability one or of almost sure arrival; "once a Principle acts it must generate a new Law"; "Principle is the sole generative mechanism of a new Law"; "the identity of acting is an additional field force"; a general uniform bound on the number of steps; the general reachability qualification of the cross-experiment indirect source type (acting first alters the field state, and experiments without acting then complete the generation).

By the covering relations among the four strengths, reachability strength covers the logical requirement of construction — the construction used is given by the seventh text and is here actually walked through; the higher strength of realization is not attained, and real resources, materials, and engineering constraints are not touched.

Declaration by layer of status:

　　The formal supported-reachability layer (Theorem 9.1 (a), 𝒮 from empty to non-empty): Established, confined to the initial state of Section Two, the permitted inputs of Section Three, and the path of Section Six.  
　　The Law read-back layer (Theorem 9.1 (b)): Conditional on H⁺\_M and on the antecedents of the sufficient direction of The Necessity Form of Law.  
　　Generation reachability under general initial states and general Principle relations: not established.  
　　The running-instance layer: Established within the specification constructed by the seventh text and the model v4.12, and the declared protocols, seed set, and parameters.

New H: none. No upstream criterion is rewritten; conclusions at the Law layer are read back conditionally as in 9.2, with their antecedents inherited under their original attributions.

## Section Twelve　Breakdown

By the reachability-form specification, breakdown is of two kinds.

First, proving that no permitted path arrives: for the initial state declared in Section Two and the permitted inputs frozen in Section Three, prove that for every legal path and every finite number of steps F\_H ∉ G\_N.

Second, exhibiting that the path given contains an operation that is not permitted: point out that the path of Section Six uses, at some step, one of the forbidden operations listed in 3.4, or an input outside U^adm, or that some successor does not belong to F\_GR(F\_k, u\_k).

There are three further kinds of breakdown aimed at the statements above: exhibit that the path of Section Six cannot be reproduced under the declared model version, seeds, and parameters; exhibit that the read-back of Section Nine passes over H⁺\_M and asserts a Law-layer conclusion directly; or exhibit, against Theorem 7.1, one of the following: that the ρ claimed does not take values in the natural numbers; that some state with ρ\>0 has no successor satisfying condition (ii); that the successor taken does not strictly lower the rank; that the descending successor leaves the declared domain D; or that ρ=0 while that state is not within G\_N. That a strict descent on the natural numbers must terminate in finitely many steps is itself unbreakable.

The following do not constitute breakdown: that no general uniform bound on the number of steps has been established (already declared); that certain ablation protocols did not arrive within 60 experiments (that is undecided, not unreachable); that a non-bound duty, gating, and editing likewise reach G\_N (already written down as a boundary); differences in biological realization.

"""Reachability-side verification protocols for the reach form (rebuilt from the engine's public API).
Commands: path0 | dist200 | gr1 | gr2 | dx | nolaw"""
import json,sys,copy,random
from collections import Counter,defaultdict
import full_dynamics_sediment_field_v4_12 as M

U_ADM=({"s","hR"},{"dR"})   # the only admissible input used on the positive path

class CountingRandom(random.Random):
    """random.Random that counts how many draws an episode consumes, so that a
    'same random stream' claim can be verified rather than assumed."""
    def __init__(self,seed=None):
        super().__init__(seed); self.draws=0
    def random(self):
        self.draws+=1
        return super().random()

def _inject(engines,episode_seed):
    """Give every engine the identical random stream for the coming episode.
    The engine draws at exactly one place (the junction softmax), so re-seeding
    per episode makes the streams identical regardless of how many draws each
    trajectory happens to consume."""
    out=[]
    for f in engines:
        f.rng=CountingRandom(episode_seed); out.append(f.rng)
    return out

def path0(seed=0):
    f=M.build_model(seed); M.train_initial(f)
    out={"S_F0_empty":not f.law_check("N")[0],"fail_at_F0":f.law_check_detail("N")[1]}
    H=None; firstmx=None; acts=0
    for k in range(60):
        l=f.run_episode(*U_ADM)
        if firstmx is None and ("m","x") in l.executed: firstmx=k+1
        acts+=int("dR" in l.act_duties)
        if H is None and f.law_check("N")[0]:
            st=f.edges[("m","x")]
            out.update(H=k+1,first_mx=firstmx,acts_before_H=acts,rep=len(st.rep),omega=st.omega,g=st.g,
                       witness=[list(e) for e in f.law_check_detail("N")[2]])
            break
    return out

def dist200(n=200):
    """Arrival distribution, plus per-episode (not just terminal) checks that
    A, P_R and Principle(dR) never lapse before arrival, and that dR acts every episode."""
    c=Counter(); keep=Counter()
    for seed in range(n):
        f=M.build_model(seed); M.train_initial(f)
        allA=allP=allPr=allAct=True
        for k in range(60):
            l=f.run_episode(*U_ADM)
            allA&=f.law_check("A")[0]; allP&=f.law_check("P_R")[0]
            allPr&=f.principle_check("dR"); allAct&=("dR" in l.act_duties)
            if f.law_check("N")[0]: c[k+1]+=1; break
        keep["A_all_episodes"]+=int(allA); keep["P_R_all_episodes"]+=int(allP)
        keep["principle_all_episodes"]+=int(allPr); keep["act_every_episode"]+=int(allAct)
    return {"firstN":dict(sorted(c.items())),"kept":dict(keep)}

def gr1(n=30):
    """Local counterfactual: identical prior state, identical ordinary inflow, identical
    random state; the sole intervention difference is whether the bound duty is activated.
    Checks execution AND sediment on both branches."""
    ok=0; ex=None
    for seed in range(n):
        f=M.build_model(seed); M.train_initial(f)
        for k in range(60):
            st=f.rng.getstate(); snap=copy.deepcopy(f)
            lp=f.run_episode(*U_ADM)
            g=copy.deepcopy(snap); g.rng.setstate(st)
            ln=g.run_episode({"s","hR"},set())
            e=("m","x")
            plus_sed=lp.sedimented.get(e,0.0); minus_sed=ln.sedimented.get(e,0.0)
            if (e in lp.executed and e not in ln.executed and "dR" in lp.act_duties
                    and plus_sed>0 and minus_sed==0):
                ok+=1
                if seed==0:
                    ex={"episode":k+1,
                        "p_with":dict(lp.candidates.get("m",[])).get(e),
                        "p_without":dict(ln.candidates.get("m",[])).get(e),
                        "sed_with":plus_sed,"sed_without":minus_sed}
                break
            if f.law_check("N")[0]: break
    return {"gr1_ok":ok,"seed0":ex}

def gr2(n=30):
    """Whole-path pairing under a common random stream: before every episode both
    trajectories are injected with the identical episode stream from one master source,
    so the claim of a shared stream is enforced rather than assumed. Draw counts of the
    two trajectories are recorded so that any divergence would be visible."""
    r=defaultdict(int); mismatched=0
    for seed in range(n):
        base=M.build_model(seed); M.train_initial(base)
        pos=copy.deepcopy(base); neg=copy.deepcopy(base)
        master=random.Random(seed+555)
        neg_exec=0
        for k in range(60):
            rp,rn=_inject([pos,neg],master.random())
            pos.run_episode(*U_ADM)
            ln=neg.run_episode({"s","hR"},set())
            neg_exec+=int(("m","x") in ln.executed)
            if rp.draws!=rn.draws: mismatched+=1
            if pos.law_check("N")[0]:
                r["pos_N"]+=1; r["neg_N"]+=int(neg.law_check("N")[0])
                r["neg_mx_exec_total"]+=neg_exec
                r["neg_rep_zero"]+=int(len(neg.edges[("m","x")].rep)==0)
                r["neg_omega_zero"]+=int(neg.edges[("m","x")].omega==0)
                break
    r["episodes_with_unequal_draw_counts"]=mismatched
    return dict(r)

def dx(n=30):
    """Long-run contrast between the bound duty and a physically identical non-bound duty,
    under the same common-random-stream discipline as gr2: identical initial state,
    identical ordinary inflow, identical per-episode random stream, identical duty
    parameters; the sole difference is duty identity."""
    a=Counter(); b=Counter(); same=0; mismatched=0
    for seed in range(n):
        base=M.build_model(seed); M.train_initial(base)
        f1=copy.deepcopy(base); f2=copy.deepcopy(base)
        master=random.Random(seed+999)
        t1=t2=None
        for k in range(60):
            r1,r2=_inject([f1,f2],master.random())
            f1.run_episode({"s","hR"},{"dR"}); f2.run_episode({"s","hR"},{"dX"})
            if r1.draws!=r2.draws: mismatched+=1
            if t1 is None and f1.law_check("N")[0]: t1=k+1
            if t2 is None and f2.law_check("N")[0]: t2=k+1
        a[t1]+=1; b[t2]+=1; same+=int(t1==t2)
    return {"dR_T":dict(sorted(a.items())),"dX_T":dict(sorted(b.items())),"same_T":same,
            "episodes_with_unequal_draw_counts":mismatched}

def nolaw(n=30):
    """Gate / Edit / non-bound duty: no Principle, no Act, yet N still forms."""
    r=defaultdict(int)
    for seed in range(n):
        base=M.build_model(seed); M.train_initial(base)
        for nm,args in (("gate",(set(),{"external_gate":{"A":1.0}})),
                        ("edit",(set(),{"external_edit":{"A":0.8}})),
                        ("dX",({"dX"},{}))):
            f=copy.deepcopy(base); acts=0
            for _ in range(60):
                l=f.run_episode({"s","hR"} if nm=="dX" else {"s"},args[0],**args[1]); acts+=len(l.act_duties)
            r[nm+"_N"]+=int(f.law_check("N")[0]); r[nm+"_acts"]+=acts
    return dict(r)

if __name__=="__main__":
    print(json.dumps({"path0":path0,"dist200":dist200,"gr1":gr1,"gr2":gr2,"dx":dx,"nolaw":nolaw}[sys.argv[1]]()))
