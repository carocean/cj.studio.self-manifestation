# The Necessity Form of Generative Computation

One. Purpose

*The General Form of Computational Layering* has already shown that if a stretch of computation makes history become dynamics (the duty Φ(∅)), it must have two kinds of bearing — the execution S of a fixed transformation relation on the host, and the historical condition D, which satisfies Sedimentability Nature, is updated within the segment as driven by execution, and is read in by execution; D is a level above S. That is the necessary direction: history is first assumed to have become dynamics, and then one asks what the computation must minimally have. *The General Form of Generative Computation* and *The General Form of Computational Layering* both list the other direction as unanswered: under what conditions history cannot fail to become dynamics.

This group form's initial stipulation on computation gives precisely an account in this direction: generative computation writes the rules in the host, and by these rules the host can automatically generate the dynamics layer (initial stipulation, item 6); the host need only write down the Trace-Response relation between signal and medium and give an initial network of the Sedimentation-Field, which the signal flow thereafter keeps changing in history (initial stipulation, item 6). This chapter proves: when the host rules satisfy a group of properties readable from the rules themselves, together with conditions such as the initial state, permission of re-entry, legitimate taking-over and no intrusion, there must be a legitimate run in which the dynamics layer is generated in the host; in any run segment that actually contains one passage at the branch position and a subsequent actual re-entry, with the trace difference retained until reading-in and the read-in set not otherwise altered, the dynamics layer cannot fail to be generated — history becomes, within this stretch of computation, a condition of subsequent transformations, and completes one reaction round trip by the channel fixing the flow and the flow reshaping the channel; and no object rule need be written into the rules.

Degree of Answer. First edition. The conclusions obtained and their standing are as follows: "proved" means that a complete proof is given within the declared model of Section Three. The necessity of generation is stated at two levels: that there exists a legitimate run in which generation occurs (Theorem One-A), and that generation necessarily occurs within every run segment that actually contains the witness configuration (Theorem One-B).  
First, the existence of the witness of generation (Theorem One-A) and the necessity of generation within run segments (Theorem One-B): proved, carrying Computational Execution General Form-H3.  
Second, the witness configuration in autonomous Continuation (Theorem Two): proved, additionally requiring a source entry and either relational reading-in or isolation; every passage satisfying retention becoming a condition (Theorem Three): proved, holding only under case (a) of Theorem Two, relational reading-in (together with the source entry), and not extending to the case of isolation; both carry Computational Execution General Form-H3; with relational reading-in and isolation removed, there is a cancellation countermodel.  
Third, no object rules are needed (Theorem Four): proved.  
Fourth, the initial potential does not fix destiny (Theorem Five): proved, the conclusion being that there is a legitimate exogenous history that rewrites the initial bias; with no shallowing and a saturated initial state there is lock-in, given as a boundary.  
Fifth, rerouting under deterministic reading-in (Theorem Six): proved, the rule class being set up separately as 𝔗\_det, additionally requiring Fgt\*, RT₁(o), NL(x) and the group of conditions C\_pre (with the 𝔗 of C₂ replaced by 𝔗\_det, and C₆ replaced by RT₁(o)); carrying Computational Execution General Form-H3.

Seventh, correspondence with the seven items of *The General Form of Generative Computation* (Theorem Eight): conditional, with the boundary drawn between a difference being non-zero and a difference being discernible.  
Unanswered: corresponding conclusions on continuous vector media; the existence of witnesses of autonomous Continuation on general media; the degree of complexity of dynamical transformation; the formation of the object layer within dynamics; a lower bound on total variation under general Luce-type kernels.

Initial stipulation. This form takes the following stipulations about computation as premises: they are the initial stipulation adopted by this form, are not proved in this form, and do not become proved theorems by being cited. Item numbers are marked when cited:  
　Initial stipulation, item 1: each execution node of rule transformation is a logical rule: it is the rule, at this node, of the law the program expresses, prescribing how the next step goes in order to form this law.  
　Initial stipulation, item 2: in dynamical transformation, history becomes dynamics; applying external intervention to dynamics from outside history is another case, namely intrusion.  
　Initial stipulation, item 3: taking the digging of channels as an example, after the water has flowed it erodes the network of channels in turn, and subsequent flows go on interacting with the network of channels in this way; this is the generation of the dynamics layer.  
　Initial stipulation, item 4: above the dynamics layer, part of the holding-tendency is judged to be law; objects act back on dynamics through their holding, selecting, biasing, breaking and other actions; these motions all really come from the host, and if the host is a computing device, from computation.  
　Initial stipulation, item 5: the computation of the host can only fix the computational rules of the dynamics layer, as in neural plasticity: places through which pulses often flow deepen and become easier to pass, and places through which they seldom flow become shallow and harder to pass.  
　Initial stipulation, item 6: generative computation writes the rules in the host, and by these rules the host can automatically generate the dynamics layer; the kinds of dynamics include back-erosion, rerouting, shallowing and so on. The host rules need only judge the count, within a time window, of signal flow passing through some sedimentary structure (such as a certain Groove-Line and Terminal Hollow): when the count grows, passage becomes easier; when it shrinks, harder; the host gives an initial network of the Sedimentation-Field, which the signal flow thereafter keeps changing in history. The host only prescribes and captures changes of the basic rules, letting the signal flow keep acting on the field and producing the complex transformations of the dynamics layer.  
　Initial stipulation, item 7: the rule of adjusting weights by error in training is not a basic rule of the Sedimentation-Field but a rule of training; such training is called field-induction; field-induction does not change the host rules.  
　Initial stipulation, item 8: directly changing channels or rewriting weights from outside history, not through the signal flow, is intrusion.  
　Initial stipulation, item 9: in a computing host, dynamics occurs when the signal flow passes and a computational transformation is really carried out through the rules; host rules are the Trace-Response relation between signal and host medium, and the dynamical conditions are the current conditions at each occurrence of Trace-Response that produces a transformation.  
　Initial stipulation, item 10: generative computation contains rule computation; rule computation takes place in the host layer of generative computation.  
　Initial stipulation, item 11: the initial Sedimentation-Field is not without the action of potential; it is non-uniform.

Working domain 𝒲₇: a single host P; the medium consists of finitely many structural positions and the local transitions permitted between them (a finite simple directed graph: between the same pair of structural positions there is at most one transition in the same direction); signals enter as pulses, one pulse being one execution by P of the one-step task τ\_Φ; random Continuation is always stated at the level of distributions or under a shared random source. Continuous vector media, multiple hosts and the formation of the object layer (law, Principle, Probability, Intention) lie outside 𝒲₇. All conclusions of this chapter are restricted to 𝒲₇.

Two. Core Propositions

If the host rules prescribe only the Trace-Response relation between signal and medium — what is actually passed through leaves a trace, repeated passage deepens the trace, little use makes it fade, a deeper trace is easier to pass — and these prescriptions are uniform over all structural positions, then:

First, as long as the host bears and executes this rule, holds an initial field obtained by legitimate taking-over, the signal is permitted to enter some branch position again, sedimentation is switched on without intrusion, and the trace difference left by one passage on the initial field survives one sedimentation clock step, there exists a legitimate run in which history becomes a condition of subsequent transformations, the trace formed is read in through execution, and it changes where the flow subsequently goes and where it subsequently writes.

Second, in any run segment, as long as it actually contains one passage at a branch position followed by one actual reading-in at that position, with the trace left in between not smoothed away and the read-in set of that position not otherwise altered, history cannot fail, within this run segment, to become a condition of subsequent transformations, and the trace formed cannot fail to change where the flow subsequently goes and where it subsequently writes.

The rules need not, and do not, contain any clause taking objects as arguments. The non-uniformity of the initial field gives the initial potential, but under shallowing does not determine the dynamical conditions thereafter.

Formally: C\_pre ⇒ ∃σ ∈ Run\_legal: C₃(σ) ∧ C\_run(σ) ∧ Γ(σ) ∧ R₁(σ) ∧ R₂(σ); C₁ ∧ C₂ ∧ C₄ ∧ C₈ ∧ C\_run(σ) ∧ Γ(σ) ⇒ R₁(σ) ∧ R₂(σ); τ\_Φ ∈ 𝔗 ⇒ R₃ (Section Four gives the items; Section Five proves them one by one). Propositions One and Two, together with the first two formulas, are restricted to 𝒲₇, carrying Computational Execution General Form-H3 (attribution of E3(ii) and W to execution).

### 3.3　The Trace-Response rule class 𝔗

One pulse (one execution of τ\_Φ): when SED = 1, first apply Idle once to all trace states; then continue hop by hop — at position q, take an available outgoing edge according to K\_q (in exogenous experience, the edge given by route), and, when SED = 1, apply Pass\_p once to that edge and its two end positions, q moving to the head of the edge; stop when there is no available outgoing edge or the hop limit H is reached. This order follows "first shallow, then deal with the current event" of Section Ten of F\_min (Decay → Continuation → Trace → Sediment) and the pulse program of F\_LB.

τ\_Φ ∈ 𝔗 if and only if the following five conditions hold:  
　TR1 (sedimentation gate)　With sedimentation switched on, the only changes of D in one pulse are: each trace state first undergoes Idle once; thereafter, for each actual passage e, m\_e and n\_{tail(e)}, n\_{head(e)} each undergo Pass\_p once. With sedimentation switched off, D does not change. Basis: initial stipulation, item 6 (judging the count of signal flow passing through sedimentary structures); the sedimentation gate (4.3) of *The Mathematical Form of Law-Dynamics* v1.0 (only what is actually passed through enters sedimentation).  
　TR2 (trace deepening)　Write the read-out dominance order m ⪰ m′ :⇔ for all k ≥ 0, ρ(Idle^k m) ≥ ρ(Idle^k m′). Idle and Pass\_p preserve ⪰; Pass\_p(m) ⪰ m; the zero trace o is the least element of ⪯, and Idle(o) = o; on the set of unsaturated states 𝕄°, ρ(Pass\_p m) \> ρ(m). Likewise for position traces. Basis: initial stipulation, item 5 (places often flowed through deepen), item 6 (the count grows).  
　TR3 (shallowing)　ρ(Idle m) ≤ ρ(m). Basis: initial stipulation, item 5 (places seldom flowed through become shallow), item 6 (the count shrinks).  
　TR4 (local uniformity)　Idle, Pass, S and φ are the same function for all edges and all positions, not taking the names of structural positions, relations or entries as arguments; τ\_Φ is deterministic, randomness lying only in the sampling of Continuation, given by the declared random source. Basis: initial stipulation, item 6 (the host only prescribes and captures changes of the basic rules), item 9 (host rules are the Trace-Response relation between signal and host medium).  
　TR5 (read-in coupling)　S is strictly increasing in its first argument and non-decreasing in its second; φ is strictly increasing and positive (a Luce-type Continuation kernel; softmax, power normalization and linear normalization all fall within this class). Basis: initial stipulation, item 5 (what is deeper is easier to pass, what is shallower harder), item 6 (when the count grows passage becomes easier, when it shrinks harder), item 9 (dynamical conditions).

The other persistent quantities in D that do not enter the score (such as the re-walk window records and Ω of F\_LB) also change only through Idle and Pass; TR2 and TR3 are stated only for the trace components that enter the score.  
The five conditions are all properties of the rules themselves, readable from the declaration of τ\_Φ before any run. Instances: F\_min satisfies TR1–TR5; F\_LB satisfies TR1–TR5 for strengths p ≤ g\_max/β (its score κ\_e = κ₀ + w\_g·Mask\_e·g\_e·(1 or s\_weak) + w\_d·d\_{head(e)} is piecewise linear and strictly increasing in g\_e, jumping up at the threshold; for p ≤ g\_max/β its Pass preserves the order in g, while for larger p it does not, and TR2 fails; the F\_LB instances cited in this chapter all lie within this range); rules taking the number of passages within a time window as their read-out (initial stipulation, item 6) satisfy TR1–TR5.

Item-by-item correspondence between Sedimentability Nature and 𝔗. *Sedimentation-Field Theory* v1.2 defines Sedimentability Nature as "that through interaction, it may respond through traces. Repeated — trace deepens. Little used — trace fades. Same source — same trace. Different source — different trace" (quoted as in Section Three of *The Construction Form of the Minimal Sedimentation Field* v1.2). Item by item:  
　\| Sedimentability Nature \| Counterpart in 𝔗 \|  
　\| Through interaction, it may respond through traces \| TR1: what is actually passed through undergoes Pass; TR2: Pass\_p(m) ⪰ m, the read-out strictly increasing when unsaturated \|  
　\| Repeated — trace deepens \| TR2: Pass preserves the order and is strictly increasing; n + 1 passages dominate n passages, strictly where unsaturated \|  
　\| Little used — trace fades \| TR3: Idle does not increase the read-out; what is not passed through undergoes only Idle \|  
　\| Same source — same trace \| TR4: the same sequence of passages gives the same trace \|  
　\| Different source — different trace \| TR1: whichever edge is passed through, Pass is applied to the edge trace of that edge, and edges not passed through undergo only Idle \|  
Hence, when τ\_Φ ∈ 𝔗, every trace component whose historical dependence is given by Idle and Pass has a historical dependence satisfying Sedimentability Nature.  
The reading of "Same source — same trace. Different source — different trace": the same action (passage) leaves the same trace at the same place, and different actions leave their own traces where they reach; this is a property that holds action by action and component by component. It is not the global injectivity "any two different histories must leave different complete field states": the latter is incompatible with "Little used — trace fades" in the same definition — two different old histories, after shallowing to the zero trace, leave the same field state. The main book's original wording "Select that which can be determined to keep currents of the same source the same, currents of different sources different" (*On Self-Manifestation* v0.7.1, Outer Chapter 6, *Electromagnetism*, the passage on the selection of materials) also speaks of the current of each source. The witness of this chapter uses only the difference, in the read-in components, between the two chosen histories, proved by Γ5 and Lemma 1, and does not depend on global injectivity.

### 3.4　Retention and forgetting

Retention　Two time bases are distinguished. Taking the state m̂ just before the passage as the base: RT^pre\_k(m̂) :⇔ ρ(Idle^k Pass\_p m̂) \> ρ(Idle^k m̂) — between passing once on m̂ and not passing, the read-outs still differ strictly after a further k sedimentation clock steps. Taking the state m before the start of the pulse as the base (the first hop of the pulse, preceded only by the one Idle at the start of this pulse): RT\_k(m) :⇔ RT^pre\_k(Idle m), that is, ρ(Idle^k Pass\_p Idle m) \> ρ(Idle^{k+1} m). Each excludes both saturation (Pass no longer increasing) and smoothing away (shallowing to the zero trace); wherever the passage is not at the first hop of the pulse, or the state before it has already undergone this pulse's Idle, only RT^pre can be used.  
The read-out dominance order ⪰ is reflexive and transitive (following from the ≥ in its definition holding for each k).  
Forgetting　Fgt: for all m, ρ(Idle^n m) reaches ρ(o) within finitely many steps or tends to ρ(o); likewise for position traces. Theorems Five and Six use the score forgetting Fgt\* (5.6), a strengthening of this.

### 4.1　Dynamical law

Under the group of conditions, the system evolves by the pulse of 3.3: first shallowing, then hop-by-hop Continuation and sedimentation. The Continuation kernel K\_v reads the current edge traces and head-position traces; the traces of what is passed through are deepened by Pass, and those of what is not passed through are made shallower by Idle. 4.3　The witness configuration Γ(σ) (events within the run segment)

For a run segment σ, Γ(σ) means that the following five items obtain:  
　Γ1 (actual passage)　σ actually passes through e₁ = (x, y₁) at x at some hop of some pulse t₁; write h⁻ for the history before this, and h₁ for the actual history.  
　Γ2 (legitimate substitute)　The history h₂ that, after h⁻, replaces that hop of t₁ by e₂ = (x, y₂) belongs to the declared family of legitimate histories: when e₁ comes from exogenous experience, h₂ replaces it by the permitted exogenous experience (x, p, (x, y₂)); when e₁ comes from Continuation sampling, the Continuation probability of e₂ at that place is positive. Thereafter h₂ shares the deliveries, exogenous control operations and random numbers of h₁.  
　Γ3 (actual re-entry)　σ actually carries out a Continuation reading-in at x in a subsequent pulse t₂; write k for the number of sedimentation clock steps between the Pass at that hop of t₁ and the reading-in of t₂. Comparison isomorphism: h₁ and h₂ have, at the comparison point of t₂, the same τ\_Φ, input of the present step u, exogenous control configuration c = (SED, Mask, Avail), current position q = x, set of available outgoing edges A(x) and its declared order; their c keeps the open-reading configuration of C₄ on A(x). The field states D of the two histories are not required to be the same.  
　Γ4 (isolation of the read-in set)　From after that hop of t₁ until before the reading-in of t₂: (i) the edge traces of each edge of A(x) undergo only Idle in both h₁ and h₂; (ii) when S reads position traces, at comparison, n\_{y₁} in h₁ ⪰ n\_{y₁} in h₂ and n\_{y₂} in h₁ ⪯ n\_{y₂} in h₂, and the position traces at the heads of the other edges of A(x) are the same in the two histories.  
　Γ5 (retention until reading-in)　RT^pre\_k(m̂\_{e₁}) or RT^pre\_k(m̂\_{e₂}) holds, where m̂ denotes the edge traces of A(x) at the moment just before the passage at that hop of t₁ (after the Idle at the start of this pulse and all the preceding hops have acted), the same in both histories at that moment; k is the number fixed by Γ3.  
No item of Γ(σ) states that the historical difference has already entered what follows, nor that sedimentation has been read in: Γ1 and Γ3 are the occurrences of two execution events, Γ2 is the legitimacy of a counterfactual, and Γ4 and Γ5 are the evolution and retention of the read-in set between the two events. TR5 is the functional dependence of the rules on the field state; the reading-in of sedimentation by execution (Rd) is the actual occurrence of this dependence on the witness chain given by Γ, as proved below.

### 4.4　Results R

For a run segment σ:  
　R₁(σ) (generation within the segment)　Φ(∅)(σ) holds, and there is a witness chain χ such that the historical condition on which χ depends is formed within σ: the set of sedimentary update events on χ within σ is non-empty, and each of these events satisfies ImplDecl and is driven by execution (W(χ) holding non-trivially).  
　R₂(σ) (reaction round trip)　The trace formed on χ within σ is read in by a subsequent execution within σ, changing the Continuation kernel at the place of reading-in, and changing the actual outgoing edge on a sampling set of positive measure under the shared random source, and hence changing the position of subsequent writing: the flow reshapes the channel, the channel fixes the flow, and the channel is reshaped again (what item 3 of the initial stipulation speaks of as the water, after it has flowed, eroding the network of channels in turn).  
　R₃ (no object rules)　τ\_Φ contains no object rule (definition in 5.5).  
Φ(∅), E1–E4, W, Rd and the common witness χ are used in their original sense from *The General Form of Computational Layering*, the fourth item of Section One, Sections Four and Five, and Parts Two and Three of "Appendix: The General Form of Computational Layering · Formalization."

### 5.1　Two lemmas

Lemma 1 (retention of the trace difference)　Assume C₂ and C₇(σ), and that two histories h₁, h₂ satisfy Γ1–Γ5. Then at comparison:  
　ρ(m\_{e₁}) in h₁ is no less than in h₂, and ρ(m\_{e₂}) in h₁ is no greater than in h₂, at least one of them strictly;  
　when S reads position traces, ρ\_d(n\_{y₁}) in h₁ is no less than in h₂, and ρ\_d(n\_{y₂}) in h₁ is no greater than in h₂;  
　for the other edges of A(x) and their heads, the read-outs entering the score are the same in the two histories.  
Proof　The two histories are the same before that hop of t₁ (Γ2), and the edge traces at the moment just before the passage at that hop are m̂. By TR1, that hop applies Pass once to m\_{e₁} in h₁ and once to m\_{e₂} in h₂. By Γ4(i), from then until comparison, the edge traces of A(x) undergo only Idle in both histories, k times in all. So in h₁, m\_{e₁} becomes Idle^k Pass\_p m̂\_{e₁}, and in h₂ it becomes Idle^k m̂\_{e₁}; by TR2, Pass\_p m̂ ⪰ m̂ and Idle preserves ⪰, so the read-out of the former is no less than that of the latter, strictly when RT^pre\_k(m̂\_{e₁}). The case of m\_{e₂} is symmetric. The other edges of A(x) undergo the same operators in the two histories, and by the determinism of TR4 take the same values. The clauses on position traces follow directly from Γ4(ii) and the definition of ⪰ (taking k = 0). By Γ5, at least one is strict. ∎

Lemma 2 (ratio of kernels)　Assume TR5. If, from h₂ to h₁, s\_{e₁} does not decrease and s\_{e₂} does not increase, at least one strictly, and the scores of the other edges of A(x) are unchanged, then K\_x(e₁)/K\_x(e₂) strictly increases; hence K\_x changes, and under inverse-transform sampling with a fixed order of outgoing edges, the set of random numbers for which the two distributions give different actual outgoing edges has positive measure.  
Proof　K\_x(e₁)/K\_x(e₂) = φ(s\_{e₁})/φ(s\_{e₂}); φ is strictly increasing and positive, so this ratio strictly increases, and the two distributions differ. If the two distributions differ, their cumulative distributions differ somewhere, and inverse-transform sampling gives different outgoing edges in between, on an interval of positive length. ∎

5.2　Theorem One (the theorem of the necessity of generation)

Theorem One-B (necessity of generation within the run segment)　Assume C₁, C₂, C₄, C₈ and C\_run(σ), and that σ satisfies Γ(σ). Then R₁(σ) and R₂(σ) hold. Carrying Computational Execution General Form-H3.

Proof　E1: by C₁ and C₁(σ).  
　E2: by the comparison isomorphism of Γ3, the two comparison states have the same τ\_Φ, input of the present step, c and q, and the same A(x) and its order; π\_cmp is declared before the run (C₈); so π\_cmp is the same at both places, and the Continuation kernels at the two places are compared on the same set of outgoing edges. By Lemma 1, ρ(m\_{e₁}) in h₁ is not smaller and ρ(m\_{e₂}) not greater, at least one strictly, the head-position traces are ordered in the same direction, and the other read-ins are unchanged. By TR5 and Γ3 (c keeping the open-reading configuration of C₄, Mask\_{e₁} = Mask\_{e₂} = 1), s\_{e₁} does not decrease and s\_{e₂} does not increase, at least one strictly. By Lemma 2, K\_x differs; under the shared random source, the actual successors at t₂ differ on a sampling set of positive measure.  
　E3: (i) the difference is borne by the edge traces of A(x) and the head-position traces, which belong to the D held by P and enter what follows through the execution of the Continuation kernel; there is no proxy evaluation outside the boundary (C₇(σ)). (ii) The historical condition on which the witness depends — the Pass at that hop of t₁ — is formed within σ, is a legitimately declared implementation (C₂), and the initiation of the pulse t₁ is one of the actual causes of the present evolution of that update (the Ex of *The General Form of Computational Execution*, carrying that form's H3); within σ the read-in set of A(x) undergoes no change other than Idle and Pass (C₇(σ)).  
　E4: the historical dependence of the components bearing the difference is given by Idle and Pass, and by the item-by-item correspondence of 3.3 satisfies Sedimentability Nature. Here there are sedimentary updates within the segment, so E4 is certified by the updates themselves, without depending on the field qualification of the field state at the head of the segment.  
　W(χ): the sedimentary update events on χ within σ are the Pass at that hop of t₁, the subsequent applications of Idle, and the head writes involved in Γ4(ii), all of them declared implementations driven by execution (C₂, C₇(σ)); the Pass event exists, so W is non-trivial.  
　Rd(χ): at t₂, ρ(m\_{e\_i}) enters K\_x as an argument of S (TR5), and this reading-in is an execution actually occurring within σ (Γ3).  
　E2, E3, E4, W and Rd are all certified on the same witness chain given by Γ. So Φ(∅)(σ) holds, and R₁(σ) holds.  
　R₂(σ): by Lemma 2, taking the random number in the interval where the two distributions differ, h₁ and h₂ pass through different outgoing edges at t₂; by TR1, the subsequent Pass is written on different edges. The trace formed on χ is read in within σ, changes what is actually passed through, and in turn changes the next write. ∎  
How to read the conclusion: that K\_x differs is determinate; "changing the actual outgoing edge" is a path difference under the shared random source — the sampling set on which the two histories give different outgoing edges has positive measure — not a claim that the one sample actually realized in σ must fall within it. That a single observation does not see a difference of outgoing edge does not negate R₂(σ).

Theorem One-A (existence of the witness of generation)　Assume C\_pre. Then there is σ ∈ Run\_legal satisfying C₃(σ), C\_run(σ) and Γ(σ), and hence R₁(σ) and R₂(σ) hold. Carrying Computational Execution General Form-H3.

Proof　Construct σ from D₀: the first pulse is the exogenous experience (x, p, (x, y₁)), and the second pulse delivers (x, p) to x. The joint realization of this sequence within one and the same legitimate run is permitted by C₅; σ is executed by P (C₁, C₂), SED = 1 and no other protocol operation is performed (permitted by C₇), and the whole segment is one and the same run — so σ ∈ Run\_legal, and C₃(σ) and C\_run(σ) hold. Checking Γ item by item: Γ1 is the single hop of the first pulse; the substitute of Γ2 is the permitted exogenous experience (x, p, (x, y₂)), with subsequent deliveries shared; Γ3 is the Continuation reading-in at x in the second pulse, k = 1; both histories are at x with (x, p), neither changes c, c keeps the open-reading configuration of C₄, and A(x) and its order are given by the declaration of the medium, so the comparison isomorphism holds; Γ4(i): between the two pulses the edge traces of A(x) undergo only the one Idle at the start of the second pulse; Γ4(ii): the single-hop exogenous experience writes only n\_x and the head of the edge passed through, so n\_{y₁} undergoes one more Pass in h₁ and n\_{y₂} one more Pass in h₂, the other heads being the same in the two histories, and TR2 gives the required ⪰; Γ5: that hop is the first hop of the first pulse, the edge trace at the moment just before the passage is Idle m⁰, and RT^pre\_1(Idle m⁰) is RT₁(m⁰), that is, C₆. The result follows from Theorem One-B. ∎

Strength　Theorem One-A asserts the existence of a witness of generation: under the group of conditions, a legitimate run in which generation occurs can be constructed; it does not assert that every legitimate run makes generation occur. Theorem One-B asserts necessity within the run segment: in any run segment actually containing the witness configuration, generation cannot fail to occur. The differences given by both are non-zero; neither theorem asserts that they exceed a given resolution (see 5.9). Instances: TV = 0.312 on a new field of F\_LB, TV = 0.041 on a new field of F\_min; among 4000 random instances of TR1–TR5, the change of score difference is positive in all 3517 instances in which C₆ holds, and the reaction round trip holds in all 3262 instances in which it can be checked (Appendix B, items B-1 and B-2, both being constructed runs of Theorem One-A).

5.3　Theorem Two (the witness configuration in autonomous Continuation)

Assume C₁, C₂, C₄, C₈ and C\_run(σ); x is a source entry (having no incoming edges); σ has, at t₁, a delivery to x whose first hop takes e₁ by Continuation sampling, and, at a subsequent t₂, the next delivery to x; RT\_k(m\_{e₁}) or RT\_k(m\_{e₂}) holds (m being the edge trace before the start of the pulse t₁, and k the number of sedimentation clock steps between the Pass at that hop and the reading-in at t₂; x is a source and that hop is the first hop of t₁, so RT\_k(m) is RT^pre\_k(Idle m)); and one of the following is satisfied:  
　(a) relational reading-in: S does not depend on its second argument;  
　(b) isolation Iso(x): within the hop limit H, no route starting from any head of A(x) reaches x or any other head of A(x), and t₂ is the pulse immediately following t₁.  
Then Γ(σ) holds, and hence R₁(σ) and R₂(σ) hold, the witness being formed by P's own Continuation sampling. Carrying Computational Execution General Form-H3.

Proof　Γ1 and Γ3 are the two assumed deliveries; comparison isomorphism: h₂ shares the deliveries and exogenous control operations of h₁, under C₇(σ) the c of A(x) is unchanged within σ, at t₂ both histories are at x with the same delivery, and A(x) and its order are given by the declaration of the medium; Γ2: the Continuation probability of e₂ is positive (φ \> 0), and the subsequent hops and deliveries are shared. Γ4(i): x is a source, so the edges of A(x) are passed through only at the first hop of pulses to x, and there is no pulse to x between t₁ and t₂, so in both histories the edge traces of A(x) undergo only Idle. Γ4(ii): under (a), head-position traces do not enter the score, and this clause is not needed; under (b), write out the sequences of operators applied by the two histories to each head-position trace. Write n̂ for the position traces at the moment just before the passage at that hop of t₁ (the same in both histories). After that hop of t₁ and before the reading-in at t₂, there are only the remaining hops of the pulse t₁ and the one Idle at the start of the pulse t₂ (t₂ immediately following t₁). In h₁: n\_{y₁} first undergoes one Pass as the head of e₁, and thereafter the route of t₁ proceeds from y₁, so that n\_{y₁} may undergo Pass again several times with y₁ as starting point or head, but these are all applications of Pass, with no Idle in between; by Iso(x), this route reaches neither y₂ nor the other heads of A(x). So in h₁, n\_{y₁} = Idle Pass^j n̂\_{y₁} (j ≥ 1), n\_{y₂} = Idle n̂\_{y₂}, and the other heads = Idle n̂. h₂ is symmetric: n\_{y₂} = Idle Pass^{j′} n̂\_{y₂} (j′ ≥ 1), n\_{y₁} = Idle n̂\_{y₁}, and the other heads = Idle n̂. By TR2, Pass(n) ⪰ n and ⪰ is transitive, so Pass^j n̂ ⪰ n̂; Idle preserves ⪰. Therefore n\_{y₁} in h₁ ⪰ in h₂, n\_{y₂} in h₁ ⪯ in h₂, and the other heads are the same in the two histories, which is Γ4(ii). Γ5: the edge trace at the moment just before the passage at that hop is Idle m, and RT\_k(m) is RT^pre\_k(Idle m). The result follows from Theorem One-B. ∎  
Existence form: assume C\_pre, that x is a source entry, and (a) or (b). From D₀, by C₅, deliver to x twice in succession; the first hop of the first takes e₁ with positive probability, SED = 1, and no other protocol operation is performed (C₇); take k = 1, so that Γ5 is RT₁(m⁰), which holds by C₆. So there is σ ∈ Run\_legal satisfying C₃(σ), C\_run(σ) and Γ(σ), the witness being given by P's own Continuation.

Cancellation countermodel　Conditions (a) and (b) are load-bearing in this proof. Take the medium x→y₁, x→y₂, y₂→y₁, y₁→w, w→y₁, y₁→z (z having no outgoing edges), with hop limit H = 6; the route of h₁ is x, y₁, z (stopping at z), and the route of h₂ is x, y₂, y₁, w, y₁, w, y₁ (stopping at the hop limit); both are complete trajectories of positive probability under any positive Continuation kernel; edge traces increase by 0.25 at each passage and position traces by 1, with no shallowing, and S = κ₀ + g + w\_d·d. At comparison, n\_{y₁} is 2 and 5 in h₁ and h₂ respectively, and n\_{y₂} is 0 and 2, so Γ4(ii) fails; s\_{e₁} − s\_{e₂} is 0.25 + 2w\_d in h₁ and −0.25 + 3w\_d in h₂; for w\_d = 0.5 the two are equal, the Continuation distributions of the two histories at x are exactly the same, and this pair of histories does not witness E2; for w\_d = 0.02, TV = 0.654 (Appendix B, item B-6). In the same system a witness can still be obtained from exogenous experience by Theorem One-A.

5.4　Theorem Three (every passage satisfying retention becomes a condition)

Under the conditions of Theorem Two (a), for every actual passage e at x within σ such that there is subsequently, within σ, an actual next re-entry at x, and RT\_k(m\_e) or RT\_k(m\_{e′}) holds (m being the edge trace before the start of that pulse, e′ another outgoing edge in A(x), Mask\_e = Mask\_{e′} = 1 under the declared configuration, and k the number of sedimentation clock steps between that passage and the reading-in at the next re-entry), K\_x at the next re-entry differs from that under its legitimate counterfactual e′. Carrying Computational Execution General Form-H3.

Proof　For each such passage, take t₁ to be that pulse and t₂ the next re-entry at x; by the proof of Theorem Two (a), Γ(σ) holds with (e, e′); the result follows by Lemmas 1 and 2. ∎

Under these conditions the dynamics layer is not generated just once: every passage that satisfies retention and is followed by a re-entry becomes a condition of the subsequent Continuation. Instances: all 8799 determinable checks in random runs hold; on F\_LB (which satisfies neither (a) nor (b)) all 199 checks also give non-zero differences (Appendix B, item B-4).

5.5　Theorem Four (no object rules are needed)

Definition (object rule)　A clause in τ\_Φ whose expression of action takes as argument the name — not the field state — of some structural position, relation or entry, prescribing or biasing Continuation or sedimentation at that place. The execution nodes of rule transformation of which item 1 of the initial stipulation speaks, which prescribe how the next step goes in order to form this law, are exactly such clauses. Examples: always taking m1 at a1 (the τ\_C of Section Seven of *The General Form of Computational Layering*); adding a constant to the score of some edge; writing only to some edge.

Theorem Four　When τ\_Φ ∈ 𝔗, τ\_Φ contains no object rule; Theorems One-A, One-B, Two and Three hold for every member of 𝔗. So the generation of the dynamics layer needs no object rule to be written.

Proof　TR4 prescribes that Idle, Pass, S and φ are the same function for all positions, not taking the names of positions as arguments; an object rule, by definition, takes the name of a position as an argument, contrary to TR4. The proofs of Theorems One-A to Three use only TR1–TR5, the group of conditions and the witness configuration. ∎

Corollary 4.1 (equivariance)　τ\_Φ ∈ 𝔗 commutes with any renaming of the medium: the renamed medium, initial state and history give the renamed field state and Continuation distribution. Instances: uniform rules show 0 mismatches in 500 random instances; rules containing object clauses show 480 mismatches in 500 instances (Appendix B, item B-5).  
Corollary 4.2 (direction is given by history)　Suppose the medium has an automorphism ψ that fixes x and exchanges e₁ and e₂, and that D₀, the deliveries and the control configuration are invariant under ψ or transform with it. Then by Corollary 4.1, under the same rules, a history h and its image ψ(h) give exchanged Continuation probabilities: K\_x^{ψ(h)}(e₁) = K\_x^{h}(e₂), K\_x^{ψ(h)}(e₂) = K\_x^{h}(e₁); if h forms a strict bias (K\_x^h(e₁) ≠ K\_x^h(e₂)), ψ(h) forms the strict bias in the opposite direction; if h has no bias, neither has ψ(h). Instance: the medium of F\_LB has (m1 m2)(c x) as an automorphism (c and x here being names of structural positions in the medium of F\_LB, the branch position being a1); after 20 passages a1→m1→c a new field has P(m1 \| a1) ≈ 1.000, and after the image history P(m1 \| a1) ≈ 3.2×10⁻¹³ (Appendix B, item B-5). To which side the dynamical condition is biased is given by history; the rules give only how bias forms with history.  
Corollary 4.3 (writing the object into the medium)　If the medium leaves only one available outgoing edge at x, K\_x at x is a point distribution, no history changes it, and E2 cannot be witnessed at x. The same holds at the restricted positions when the exogenous control configuration leaves only the object's route available: at these positions there is no Continuation that history can change.  
Corollary 4.4 (an object rule that wholly determines Continuation replaces dynamics where it lies)　If τ\_Φ contains an object rule at x, and this rule wholly determines Continuation at x — for all legitimately comparable field states D, D′, K\_x(D) = K\_x(D′) (such as "always take e₁ at x") — then no history changes K\_x, and E2 cannot be witnessed at x. This and the conclusion of Section Seven of *The General Form of Computational Layering* (DynamicRole failing at that place under τ\_C) are two sides of the same fact: where an object rule that wholly determines Continuation lies, the bearing of law and the generation of dynamics both give way to the rule. An object rule that only biases (such as adding a constant to the score of some edge, the rest still reading edge traces) does not cancel the dynamical reading-in at that place: history still changes Continuation, only part of the bias being written in advance by the rule; such a τ\_Φ does not belong to 𝔗, the antecedents of Theorems One-A to Three do not hold for it, and whether their conclusions hold must be proved separately.

5.6　Theorem Five (the initial potential does not fix destiny)

Score forgetting Fgt\*: for any edge trace m and position trace n, S(ρ(Idle^j m), ρ\_d(Idle^j n)) tends to S(ρ(o), ρ\_d(o)) as j → ∞ (derivable from the Fgt of 3.4 together with the joint continuity of S; satisfied as a matter of course by traces that reach the zero trace in finitely many steps).

No self-loop at the branch position, NL(x): the head of no outgoing edge of A(x) is x. Theorems Five and Six use it to guarantee that, when one outgoing edge is passed through repeatedly, the edge traces and head-position traces of the other outgoing edges undergo only Idle — when e₂ is passed through, x undergoes Pass as the starting point, and if the head of some outgoing edge were x itself, its score would still be continually deepened through n\_x.

Theorem Five　Assume τ\_Φ ∈ 𝔗, Fgt\*, RT₁(o) (one sedimentation on the zero trace survives one sedimentation clock step), NL(x), and C₁, C₂, C₄, C₅, C₇; e₁, e₂ are the two open-reading outgoing edges given by C₄. Then for any initial state D₀ satisfying C₃ for which C₅ holds (possibly arbitrarily non-uniform), there is a legitimate exogenous history starting from D₀ and satisfying C\_run — repeatedly delivering the exogenous experience (x, p, (x, y₂)) to x — such that after finitely many repetitions K\_x(e₂) \> K\_x(e₁).

Proof　Each pulse of this history has only the single hop x→y₂, and by TR1 writes only m\_{e₂}, n\_x and n\_{y₂}; by NL(x), y₁ ≠ x, and y₁ ≠ y₂ (simple graph), so e₁ and y₁ undergo only Idle, and by Fgt\*, s\_{e₁} tends to S(ρ(o), ρ\_d(o)). Each time, e₂ undergoes Idle and then Pass: by TR2 (o least, the operators order-preserving), after each pulse m\_{e₂} ⪰ Pass\_p Idle o, and at comparison ρ(m\_{e₂}) ≥ ρ(Idle Pass\_p Idle o). Write δ := ρ(Idle Pass\_p Idle o) − ρ(o); by RT₁(o) and Idle(o) = o, δ \> 0. The position trace of y₂ ⪰ the zero trace. By Mask\_{e₂} = 1 and TR5, s\_{e₂} ≥ S(ρ(o) + δ, ρ\_d(o)) \> S(ρ(o), ρ\_d(o)). So after finitely many repetitions s\_{e₂} \> s\_{e₁}, and by TR5, K\_x(e₂)/K\_x(e₁) = φ(s\_{e₂})/φ(s\_{e₁}) \> 1. ∎

What Theorem Five asserts is the existence of a legitimate exogenous history that rewrites the initial bias; it does not assert that autonomous running must rewrite it.

Proposition 5.1 (lock-in)　When Idle is the identity, the initial read-out of e₁ has reached the reachable supremum while Pass can only approach and never reach it, and S does not read position traces, no history can make K\_x(e₂) \> K\_x(e₁): the initial state is locked in. Proof: the read-out of e₁ is always the supremum and that of e₂ always no greater, S is increasing in its first argument and does not read position traces, so s\_{e₂} ≤ s\_{e₁}, and hence K\_x(e₂) ≤ K\_x(e₁). ∎  
Instances: for the three families of shallowing — linear with floor, exponential and time window — a strongly biased initial state is rewritten at the 104th, 47th and 26th repetition respectively; with no shallowing and a saturated initial state, it is not rewritten within 5000 repetitions; with no shallowing and no capacity bound, it is rewritten at the 61st repetition — lock-in requires both "no shallowing" and "saturation" (Appendix B, item B-7).

The non-uniformity of the initial field gives the initial potential (initial stipulation, item 11). Under "Little used — trace fades," it does not determine the dynamical conditions thereafter; when shallowing is absent and the initial state already saturated, the initial state becomes a prescription that history cannot rewrite. What the clause "Little used — trace fades" of Sedimentability Nature bears in the sufficient direction is exactly this.  
Corollary 5.2　Under the conditions of Theorem Five, the dynamical condition at the time of comparison varies with both the initial state and history.

5.7　Theorem Six (rerouting under deterministic reading-in)

The rule class 𝔗\_det: TR1–TR4 unchanged; TR5 is replaced by TR5′ — S is strictly increasing in its first argument and non-decreasing in its second, and Continuation takes the available outgoing edge of greatest score, ties being broken by taking the first in the fixed order of A(v) in the declaration of the medium. This order is part of the declaration of the medium, carried along when structural positions are renamed; under this convention Corollary 4.1 holds equally for 𝔗\_det, and the order itself, not prescribing Continuation by names, does not constitute an object rule.

Theorem Six　Assume τ\_Φ ∈ 𝔗\_det, Fgt\*, RT₁(o), NL(x) and C\_pre (with the 𝔗 of C₂ replaced by 𝔗\_det, and C₆ replaced by RT₁(o)). Then there is n such that the two legitimate histories "deliver to x the exogenous experience (x, p, (x, y₁)) n times, then deliver (x, p) to x" and "replace the first n times by (x, p, (x, y₂))" have different actual outgoing edges at x at the last delivery; E2 is thereby witnessed, both runs can be taken as legitimate runs satisfying C₃(σ) and C\_run(σ), and the former satisfies R₁, carrying Computational Execution General Form-H3.

Proof　For sufficiently large n, in the first history: each pulse writes only m\_{e₁}, n\_x and n\_{y₁}; by NL(x) and the simple graph, the heads of the other edges of A(x) are neither x nor y₁, so these edges and their heads undergo only Idle, and by Fgt\* their scores tend to S(ρ(o), ρ\_d(o)); s\_{e₁} ≥ S(ρ(o) + δ, ρ\_d(o)) (δ as in the proof of Theorem Five, positive by RT₁(o)), strictly greater than that limit. So after finitely many repetitions s\_{e₁} is strictly greater than the scores of the other edges of A(x), so e₁ has the greatest score; likewise in the second history e₂ does. Neither history changes c (C₇); at the last delivery τ\_Φ, the input of the present step, c, q, and A(x) and its order are the same, π\_cmp is the same, and the actual outgoing edges differ, so E2 holds; E3, E4, W and Rd as in Theorem One-B. ∎

Under random reading-in, the difference of one passage at once becomes a condition; under deterministic reading-in, the difference of one passage does not necessarily change the direction, and must accumulate until rerouting. The back-erosion and rerouting listed in item 6 of the initial stipulation are of the latter kind. Instances: among 600 random instances with deterministic reading-in, only 137 reroute at once; of the 490 in which retention holds, 489 reroute within 600 repetitions, the remaining one being a case of slow shallowing (shallowing rate 0.001, the third outgoing edge deep in the initial state), which reroutes at the latest at the 750th repetition (not yet rerouted at the 700th; Appendix B, item B-8).

5.8　Theorem Seven (the dynamics layer holds)

For every run segment σ satisfying R₁ (those given by Theorems One-B, One-A and Two, and the run segments of Theorem Six), Φ(∅)(σ) holds; by part (1) of the general theorem of *The General Form of Computational Layering*, S and D (S and D here being the host layer and dynamics layer of *The General Form of Computational Layering*, S not being the score function of 3.2) hold on P, and D is a level above S: Layer(S, D). Carried: Computational Execution General Form-H3, Generative Computation General Form-H1, H2, Computational Layering General Form-H1. Of these, Computational Layering General Form-H1 bears here only the inclusion of the witnessing components in the persistent field state of P's Sedimentation-Field (D\_E2 ⊆ D\_P), E4 having already been certified by updates within the segment.

What item 6 of the initial stipulation says — that the host can automatically generate the dynamics layer by the rules — becomes within 𝒲₇ a conditional conclusion, composed from the necessary direction of *The General Form of Computational Layering* and the sufficient direction of this chapter: the duty Φ(∅) must have a host layer and a dynamics layer; the Trace-Response rule class together with the group of conditions must have legitimate runs in which Φ(∅) holds, and every run segment containing the witness configuration must make Φ(∅) hold. 5.9　Theorem Eight (correspondence with the seven items of *The General Form of Generative Computation*)

"""rulelib.py — 迹应规则类 𝔗 的参照实现（第八《生成计算必然式》参考实现）。

规则只由三类算子给出，全部对一切边（位）一致，不以结构位的名字为自变量（TR3）：
  Idle  ：每个沉积钟步对一切迹状态作用一次（退浅，TR2）；
  Pass  ：被实际经过的边（及其两端位）作用一次（写入闸门与迹深，TR1）；
  score ：位置 x 的每一可用出边 e 的得分 s_e = k0 + w_g*h(ρ(m_e)) + w_d*ρ_d(m_head(e))，
          h 严格增；续行核把得分变成出边上的分布（TR4）。
迹状态族（trace family）：
  'linfloor'  g ← max(0, g−λ)；经过 g ← min(G, g+β p (1−g/G))          （F_LB / F_min 形式）
  'exp'       g ← γ g；        经过 g ← g + β p                         （指数退浅、无容量）
  'window'    状态为时间戳表；退浅＝时钟前进并丢弃窗口外记录；经过＝追加；ρ＝窗口内计数（以时间窗口内的经过次数为读数）
  'clamp'     g ← max(0, g−λ)；经过 g ← min(G, g+B)                      （可达容量的硬截断；崩坏条件 K3 用）
续行核（kernel）：'softmax'（温度 T）、'luce'（s^a 归一，s>0）、'linnorm'（s/Σs，s>0）。
共用随机源：续行按出边的固定次序做逆分布抽样，ξ ~ U[0,1)；两条历史用同一 ξ 序列即为共用随机源下的比较。
本文件只是参照实现；它不承担任何定理的证明。
"""
import math, random, copy
from collections import defaultdict

class Trace:
    def __init__(self, fam, **kw):
        self.fam = fam; self.kw = kw
    def init(self, v=0.0):
        if self.fam == 'window':
            return {'t': 0, 'ts': [0] * int(round(v))}      # v 次"段首之前"的经过（合法承接的初值）
        return float(v)
    def idle(self, m):
        k = self.kw
        if self.fam in ('linfloor', 'clamp'): return max(0.0, m - k['lam'])
        if self.fam == 'exp': return k['gam'] * m
        if self.fam == 'window':
            t = m['t'] + 1; return {'t': t, 'ts': [s for s in m['ts'] if t - s < k['W']]}
        if self.fam in ('none', 'schedule', 'overwrite'): return m
        raise ValueError(self.fam)
    def passed(self, m, p):
        k = self.kw
        if self.fam == 'linfloor':
            G = k['G']; return min(G, m + k['beta'] * p * (1 - m / G))
        if self.fam == 'clamp': return min(k['G'], m + k['B'] * p)
        if self.fam == 'exp': return m + k['beta'] * p
        if self.fam == 'window': return {'t': m['t'], 'ts': m['ts'] + [m['t']]}
        if self.fam == 'none': return m
        if self.fam == 'schedule': return m                  # 崩坏条件 K1：经过不写
        if self.fam == 'overwrite': return 1.0               # 崩坏条件 K11：规则状态（不随反复而深）
        raise ValueError(self.fam)
    def rho(self, m):
        if self.fam == 'window': return float(len(m['ts']))
        return float(m)

class Rule:
    """τ_Φ 的一个实例：迹族（边、位）＋得分＋续行核。全部参数对一切位置一致。"""
    def __init__(self, tr_g, tr_d, k0=0.05, w_g=1.0, w_d=0.0, h='id', theta=None, s_weak=0.4,
                 kernel='softmax', T=0.15, a=2.0, sched_delta=0.0, obj_clause=None):
        self.tr_g, self.tr_d = tr_g, tr_d
        self.k0, self.w_g, self.w_d, self.h, self.theta, self.s_weak = k0, w_g, w_d, h, theta, s_weak
        self.kernel, self.T, self.a = kernel, T, a
        self.sched_delta = sched_delta           # K1：按时间表给一切边加同量（与经过无关）
        self.obj_clause = obj_clause             # K10：对象规则条款 {位置名: 规定的出边}（违反 TR3）
    def hfun(self, r):
        if self.h == 'id': return r
        if self.h == 'thr':                       # F_LB 式：阈下以 s_weak 计，阈上全计；严格增（含阈处上跳）
            return r * (1.0 if r >= self.theta else self.s_weak)
        raise ValueError(self.h)
    def score(self, F, e):
        if not F.avail[e]: return None
        return self.k0 + self.w_g * F.mask[e] * self.hfun(self.tr_g.rho(F.g[e])) + self.w_d * self.tr_d.rho(F.d[e[1]])
    def probs(self, F, x):
        cand = [e for e in F.out[x] if F.avail[e]]
        if not cand: return []
        if self.obj_clause and x in self.obj_clause:          # 对象规则：不读场态
            return [(e, 1.0 if e == self.obj_clause[x] else 0.0) for e in cand]
        s = [self.score(F, e) for e in cand]
        if self.kernel == 'softmax':
            m = max(s); w = [math.exp((v - m) / self.T) for v in s]
        elif self.kernel == 'luce':
            w = [max(v, 1e-12) ** self.a for v in s]
        elif self.kernel == 'linnorm':
            w = [max(v, 1e-12) for v in s]
        else: raise ValueError(self.kernel)
        z = sum(w); return [(e, wi / z) for e, wi in zip(cand, w)]

class Field:
    """宿载上的介质与持久场态 D = (g, d)；外生控制构型 c = (SED, mask, avail)。"""
    def __init__(self, nodes, edges, rule, g0=None, d0=None):
        self.nodes = list(nodes); self.E = list(edges); self.rule = rule
        self.out = defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        self.g = {e: rule.tr_g.init((g0 or {}).get(e, 0.0)) for e in self.E}
        self.d = {n: rule.tr_d.init((d0 or {}).get(n, 0.0)) for n in self.nodes}
        self.mask = {e: 1 for e in self.E}; self.avail = {e: 1 for e in self.E}
        self.SED = True; self.t_sed = 0; self.writes = []   # writes：D 的写入记录（来源标注，供 E3/W 的核对）
    def decay(self):
        self.t_sed += 1
        for e in self.E: self.g[e] = self.rule.tr_g.idle(self.g[e])
        for n in self.nodes: self.d[n] = self.rule.tr_d.idle(self.d[n])
        if self.rule.sched_delta:
            for e in self.E: self.g[e] = self.g[e] + self.rule.sched_delta if not isinstance(self.g[e], dict) else self.g[e]
    def deposit(self, e, p, src='exec'):
        self.g[e] = self.rule.tr_g.passed(self.g[e], p)
        self.d[e[0]] = self.rule.tr_d.passed(self.d[e[0]], p)
        self.d[e[1]] = self.rule.tr_d.passed(self.d[e[1]], p)
        self.writes.append((self.t_sed, e, src))
    def choose(self, x, xi):
        pr = self.rule.probs(self, x)
        if not pr: return None
        c = 0.0
        for e, w in pr:
            c += w
            if xi < c: return e
        return pr[-1][0]
    def pulse(self, entry, p=1.0, route=None, xis=None, maxhop=6, first=None):
        """一次脉冲＝τ_Φ 的一次执行：先退浅（开启沉积时），再逐跳续行并沉积。
        route：外生经历（Mode_exo），给定所经结构位序列；xis：本脉冲各跳的共用随机数；
        first：自主续行中第一跳的合法反事实取值（须为正概率出边）。"""
        if self.SED: self.decay()
        q = entry; path = [q]; xis = list(xis or [])
        for h in range(maxhop):
            if route is not None:
                if h >= len(route) - 1: break
                e = (route[h], route[h + 1])
            else:
                if h == 0 and first is not None:
                    pr = dict(self.rule.probs(self, q)); assert pr.get(first, 0) > 0, 'counterfactual must be a legal draw'
                    e = first
                else:
                    xi = xis[h] if h < len(xis) else 0.5
                    e = self.choose(q, xi)
                    if e is None: break
            if self.SED: self.deposit(e, p)
            q = e[1]; path.append(q)
            if not self.out[q]: break
        return path

def tv(p1, p2):
    a = dict(p1); b = dict(p2); keys = set(a) | set(b)
    return 0.5 * sum(abs(a.get(k, 0) - b.get(k, 0)) for k in keys)

def diff_measure(p1, p2):
    """共用随机源（固定次序的逆分布抽样）下两分布给出不同实际出边的 ξ 测度。"""
    def cuts(pr):
        out = []; c = 0.0
        for e, w in pr: out.append((c, c + w, e)); c += w
        return out
    A, B = cuts(p1), cuts(p2); m = 0.0
    for a0, a1, ea in A:
        for b0, b1, eb in B:
            if ea != eb: m += max(0.0, min(a1, b1) - max(a0, b0))
    return m

def gap_change(rule, A, B, x, e1, e2):
    """比值核（softmax、luce、linnorm）下，P(e1)/P(e2) 是得分的严格单调函数；分布不同的充分判据：
    softmax 用得分差的变化，luce、linnorm 用对数得分差的变化。返回该变化量（> 0 即两分布不同，与浮点下溢无关）。"""
    sA1, sA2, sB1, sB2 = rule.score(A, e1), rule.score(A, e2), rule.score(B, e1), rule.score(B, e2)
    if rule.kernel == 'softmax': return (sA1 - sA2) - (sB1 - sB2)
    return (math.log(sA1) - math.log(sA2)) - (math.log(sB1) - math.log(sB2))

def find_xi(p1, p2):
    """取共用随机源下两分布给出不同实际出边的一个 ξ（差异区间的中点）；无差异区间时返回 None。"""
    def cuts(pr):
        out = []; c = 0.0
        for e, w in pr: out.append((c, c + w, e)); c += w
        return out
    best = None
    for a0, a1, ea in cuts(p1):
        for b0, b1, eb in cuts(p2):
            lo, hi = max(a0, b0), min(a1, b1)
            if ea != eb and hi - lo > 1e-12 and (best is None or hi - lo > best[1] - best[0]): best = (lo, hi)
    return None if best is None else (best[0] + best[1]) / 2   # 取最宽的差异区间，避开浮点相接处

def rt_pred(rule, m, k):
    """迹差留存（RT_k 连同未饱和）：从同一迹状态 m 起，本步退浅后经过一次 vs 不经过，再退浅 k 次，读数严格较大。"""
    T = rule.tr_g
    a = T.idle(m); w = T.passed(a, 1.0); n = a
    for _ in range(k): w = T.idle(w); n = T.idle(n)
    return T.rho(w) - T.rho(n) > 1e-12          # 浮点舍入容差：差为舍入噪声（如 0.25 − 5×0.05）者按 0 计
