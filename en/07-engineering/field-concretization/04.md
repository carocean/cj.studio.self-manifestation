# The Indistinguishability Form of Field Concretization

1\. Purpose  
*The Adjudication Form of the Sedimentation-Field* gives criteria that adjudicate the duties of a Sedimentation-Field from observations, and its Theorems 4 and 5 declare the adjudication limits of the first-layer criteria: under a jointly frozen operational configuration, instances with the same profile cannot be separated by the first-layer verdicts. There it gives only a few witness pairs and instance-by-instance twins, which serve as bounds of Misjudgment. The indistinguishability problem that follows is this: for a family of observation sets with closed declarations, and for the duty components q, r, Part, Act, HistCond, HDyn, together with Q(T) of a declared T and Fld = ∃T Q(T), prove which items can be determined under all observations in the observation set and for which items there exist candidates of different qualification that are indistinguishable under all observations; and give the extensions of the observation set that make them distinguishable, or the range beyond which such an extension must go.  
The conclusions of each theorem hold for all observations within the declared observation set; the finite verifications of the appendices serve to search for counterexamples and to check constructions, and do not constitute proofs.  
Form kind: Indistinguishability Form (Canon Chapters, Group Four, inversion-discernment auxiliary forms, Chapter Thirteen).

3\. Declaration of Candidates and Observation Sets

### 3.1  Candidate Families

Deterministic family 𝔉: an F-class candidate M consists of the following.  
　(1) A finite position set I, divided into the in-boundary part I\_B and the out-of-boundary part I\_out; an initial state s\_{t₀−1}: I → ℚ\_{≥0}; the declared T, a nonempty subset of I\_B; a resolution ε ≥ 0; a window W = {t₀, …, t₁}, with entry beat t₀ − 1.  
　(2) An alphabet U containing rest; a set 𝓗 of legitimate histories, given by a finite monitor automaton; the actual history h\_act ∈ 𝓗, which is recorded.  
　(3) Pulses: beat, letter, target position, amplitude a ≥ 0, and a source mark, out-of-boundary or in-field.  
　(4) Processes: beat, gating (ungated, or running only under one particular letter), target position, carrier (inside B or out-of-boundary), numeric law (constant law, linear law in the sum of the read positions, bilinear law in the product of two read positions), read positions, coefficient k and bias b.  
　(5) Every certification takes the value 1; Ident and HistEv take 1 (POS and REC are declared); the evidence edges are the canonical edges, i.e., the read positions of each process point to that process.  
The net transition Φ\_t(s, u) follows 4.2 of the Mathematical Form: only effective terms are booked (pulse amplitude greater than ε, process component of absolute value greater than ε); components read the pre-beat state; a negative updated value takes the step out of the domain of definition. The duties are evaluated on the actual history according to D16–D19 of the Mathematical Form.  
Stochastic family 𝔉^ω: on top of 𝔉, pulse amplitudes and process parameters may depend on the current beat's innovation ω\_t; the ω\_t are independent and identically distributed beat by beat. There is no hidden memory beyond the declared state; correlations across beats must be declared as augmented state, after which the candidate belongs to this family (Adjudication Form 3.3). The actual record consists of h\_act and the in-boundary trajectory under the actual realization; the actual innovation sequence ω\* is not readable.  
R-layer joint events: the indecomposable joint events of D9 of the Mathematical Form, whose action evidence is recorded by their formal evidence variable φ.  
3.2  Interface, Complete Protocol State and Comparison Rules  
The interface 𝔦(M) of a candidate M comprises: the in-boundary reading coordinates and act; U and the monitor automaton 𝓜; t₀, t₁, ε, T, h\_act; whether a supply cut-off is declared; the settable positions and their value domains; in the MOD branch, the set of module labels.  
Complete protocol state: the beat index; the monitor state of each copy; the complete state of each copy, including out-of-boundary components and the mixed states produced by clamping; a legality flag, so that after leaving the domain the protocol enters an explicit absorbing state and reads out “illegal”. All decidability conclusions are stated in terms of the complete protocol state.  
Comparison rules:  
　(1) Two candidates are compared only when they have the same 𝔦, and every operational configuration C\_op is applied to both sides with the same parameters.  
　(2) Candidates with different 𝔦 are called declaration-distinguishable and lie outside the scope of the theorems below.  
　(3) When the interfaces are the same but an operation is legitimate on one side and illegitimate on the other, the experiment reads out “illegal”; a difference in the domain of legitimate operations is a reading.  
　(4) Out-of-boundary components, process decompositions, carrier and source marks, and the numeric laws inside modules are not readings.

### 3.3  Experiments and Observation Sets

Experiment: a finite, possibly adaptive sequence of operations acting on k coupled copies; at each beat one operation is chosen for each copy; exogenous disturbances are shared within a beat; at every step copies 1 to k − 1 have their out-of-boundary components overwritten with the values of copy 0 (twin clamping); the readings are the in-boundary components and act of each copy, including the initial reading before any common operation; the output of an experiment is the joint distribution of the reading sequence.  
Observation sets:  
　𝒴₁: k ≤ 2; the operations are the letters of U (including rest and probes), the declared supply cut-off, and the settings declared for Dep. These are all the observations used by the first layer of the Adjudication Form, and every verdict of that first layer is a functional of their readings.  
　𝒴₁^(k): as 𝒴₁, with k copies.  
　𝒴₁+LOC: in addition, local settings (to legitimate values) at any beat and any position.  
　𝒴₁+MOD: in addition, knockouts of any subset of modules at any beat, with labels common to both sides.  
　𝒴₂\_obs: 𝒴₁+LOC+MOD, plus the outputs of the read-out processes declared under OUT-f.  
　𝒴\_L: on R-layer models, all experiments whose readings are all state components of the L layer and whose interventions are inputs, local settings, and knockouts by process (a joint event being an indecomposable unit).  
𝒴₁+LOC and 𝒴₁+MOD do not contain each other: LOC can reach states that are otherwise unreachable, while MOD cannot, and MOD can read out the booked term of a single module while LOC cannot.  
Closure and the antecedent FIN: the closure R\_t of an observation set 𝒴 at beat t is the set of complete states of all copies at beat t over all experiments in 𝒴, including arbitrary legitimate baseline and control histories, clamped mixed states and declared settings. FIN means that R\_t is finite. FIN holds under a finite alphabet, a finite window, finite setting domains and a finite set of disturbance values.  
Scope of the decidability conclusions: finite, explicit, rational domains, i.e., finite U, a finite window or finitely many complete protocol states, a finite set of disturbance values, and rational parameters. Arbitrary local settings give an infinite operation alphabet; for these only mathematical statements are made, with no algorithm attached.

### 3.4  Observations and Declarations

𝒴₂\_obs does not read carrier or source marks. In its second layer the Adjudication Form additionally uses the declarations of instance protocols (INV-a, INV-c, PE and others), denoted 𝒴\_decl. Restricting the candidate family by declarations, i.e., intersecting an observation class with a declared family C, acts differently from adding observations; 𝒴₂\_obs is not the same as the complete adjudication input 𝒴₂\_obs + 𝒴\_decl of the Adjudication Form.  
3.5  Relations on the Stochastic Family, Stochastic Classes and Quantifier Forms  
Observational equivalence ≈obs: the interfaces are the same, and the joint distributions of readings of all experiments in the observation set are the same. All classes and all determinacy conclusions of this paper are relative to ≈obs.  
Path equivalence ≈path: under the same state representation and the same disturbance coupling, the complete trajectories are the same for every ω. ≈path implies ≈obs; the converse fails (the parity candidates of Theorem 1(2) are observationally equivalent under two copies, yet their trajectories differ under the same ω). ≈path serves only as a tool for constructing twins.  
Stochastic qualification reading: the duties are evaluated on the actual realization (h\_act, ω\*) according to the single-trajectory reading of F in the Mathematical Form.  
Stochastic class: C(M, record) = {(M′, ω′) : M′ ≈obs M, and ω′ is a realization of M′ that gives the recorded in-boundary trajectory along h\_act}; the duties are evaluated on (M′, ω′). Matching the unreadable ω is not treated as an observation.  
Two quantifier forms:  
　Anchored form “∀ω\* ∃M′”: the actual realization is fixed first, and the twin is then constructed and frozen; once frozen, the twin preserves all reading distributions for every experiment.  
　Uniform form “∃M′ ∀ω\*”: one and the same twin changes the duty on every realization satisfying the conditions.  
The anchored form is an existence result, not an identification algorithm that could be executed from the unreadable ω\*.  
Determined, two-valued: for an observation set 𝒴 and a duty item X, if all members of a class have the same X, X is said to be determined in that class; if the class has members with X = 1 and members with X = 0, the class is said to be two-valued. Two-valuedness is witnessed by a pair of candidates of different qualification that are indistinguishable under all observations (twins).

4\. Identity of Outputs  
Lemma 1 (Structural Identity)  
Suppose two candidates have the same interface and, on the states reachable by the operations of the observation set, satisfy the following: the same structural map for every t, u, ω; the same cut-off, setting and knockout maps and the same readings; the same legality; the same disturbance distribution; the same initial state (or initial distribution). Then for any number of copies k, the joint distributions of readings of all experiments in that observation set are the same.  
Proof: by induction on the history read so far. Suppose that for every reading history of length n the two sides give that history the same probability, and that, conditioned on that history, the joint state of the copies has the same distribution on both sides. The next operation is a function of the history read so far, so both sides take the same operation; the joint state is transferred by the same kernel with shared disturbances; hence the probabilities of the histories of length n + 1 and the conditional distributions of the joint state are again the same. ∎  
Lemma 1 is a sufficient condition under the same state representation; observationally equivalent candidates can have different hidden representations, and Lemma 1 is not a necessary condition for their equivalence.  
Theorem 1 (Observation Framework)  
(1) Deterministic finite candidates, k ≥ 2: a k-copy experiment distinguishes two candidates if and only if some two-copy experiment with a baseline and one control distinguishes them. Indistinguishability can be decided by a product search on complete protocol states: with a finite window the search runs on a graph layered by beat, and a distinguishing experiment counted from the entry beat has length at most \|W\| + 1 (counted from after entry, at most \|W\|); with homogeneous dynamics over an infinite horizon, the shortest distinguishing length is less than \|𝓜\|²·\|S\|²·\|S′\|², where S and S′ are the complete state sets including out-of-boundary components.  
Proof: the readings of a control copy j depend only on the baseline trajectory and on j's own operations; so if the k-copy readings differ, then the baseline readings or the readings of some control differ, and the corresponding two-copy experiment distinguishes the candidates. A product state is (beat index, the monitor states of the two sides, the baseline state and control state of each candidate); the reachable ones are finite in number, and breadth-first search within finitely many steps either finds a state with differing readings or exhausts them. ∎  
(2) Stochastic candidates: for every k ≥ 1 there exist two candidates whose joint distributions of readings are the same on all experiments with at most k copies, yet some (k + 1)-copy experiment distinguishes them.  
Proof: let the single-beat disturbance consist of k + 1 independent fair bits. Letters a₁…a\_k read out the first k bits; letter c reads out the parity of the first k bits in candidate A, and the (k + 1)-th bit in candidate B. The parity together with any k − 1 of the first k bits is uniformly distributed in k dimensions, so the joint distribution of at most k readings (with repeated coordinates when the same letter is chosen more than once) is the same on both sides; the joint distribution of all k + 1 readings satisfies the parity constraint in A but not in B. Over several beats the state has no memory, so the joint distributions multiply beat by beat; the adaptive case follows by induction as in Lemma 1. ∎  
Hence in the stochastic case 𝒴₁^(k) is strictly weaker than 𝒴₁^(k+1). This paper takes k ≤ 2 as 𝒴₁, in agreement with the twin protocol of the Adjudication Form; every indistinguishability proved via Lemma 1 holds for every k.  
Lemma 2 (Dead-Zone Decomposition)  
Let Z ⊂ ℚ be finite, z\* ∈ Z, ε \> 0, and F: Z → ℚ with F(z*) = 0. Then F is a sum of finitely many terms θ(z) = (b + k z)·\[\|b + k z\| \> ε\], each of which satisfies \|b + k z*\| ≤ ε, i.e., is ineffective at z\*.  
Proof: let z\_min and z\_max be the least and greatest elements of Z.  
　Right-hand single terms: take U \> z\* and 0 \< κ \< 2ε/(U − z\_min). On Z, P⁺ = κ(z − U) + ε and P⁻ = −κ(z − U) − ε are effective exactly at z \> U (the reactivation point U − 2ε/κ on the other side lies below z\_min), and their values at z\* lie in \[−ε, ε\].  
　The sum of P⁺(κ₁) and P⁻(κ₂) with the same threshold is (κ₁ − κ₂)(z − U)·\[z \> U\]: the ±ε steps cancel and a ramp remains; its slope is bounded above, and any rational slope is obtained by taking several copies.  
　For two thresholds U \< U′ in the same gap, the difference of the ramps is the constant U′ − U at every point to the right of the gap and 0 to the left, i.e., a pure step. The thresholds are taken between adjacent rational points.  
　Taking one step per gap, with height equal to the adjacent difference of F, yields F to the right of z\*; to the left, F is obtained in the same way from mirror-image single terms effective at z \< L.  
　When Z is a single point or F is identically 0, take the empty sum; when only one side is present, carry out the construction on that side only. ∎

5\. Indistinguishability Theorems  
5.1  The 𝒴₁ Equivalence Classes of the Deterministic Family  
Notation: s\_t is the candidate's complete pre-beat state at beat t on the actual history, and π\_B s\_t is its in-boundary reading; A(T) means that there exist t ∈ W and y ∈ T with s\_t(y) \> ε; crossing(x) means that s(x) ≤ ε at some beat in the record while s(x) \> ε at window end; D\_t(y) is the observed net increment on y at beat t. Write Y\_t(T) = { y ∈ T : s\_t(y) \> ε, and Form(y) has a record earlier than t }, abbreviated Y\_t. Y\_t is the set of available positions of a given candidate; under the antecedent of Theorem 5(1), its formation part can be recovered from observations. Y\_t^det denotes the subset of available positions whose formation is certified by an observable threshold crossing. Numeric laws are evaluated on the complete state s\_t; only the in-boundary components are directly readable.  
Theorem 2 (Family 𝔉: Determinacy of the Duties within 𝒴₁ Equivalence Classes)  
　q(x): determined as 0 when s(x) ≤ ε at window end; determined as 1 when crossing(x); two-valued when s(x) \> ε throughout the record.  
　r (T nonempty): always two-valued.  
　Part: determined as 0 when ¬A(T); otherwise two-valued.  
　HDyn: determined as 0 when ¬A(T); otherwise two-valued (FIN is required when ε \> 0).  
　Act (acting on T within W): determined as 1 when D\_t(y) \< 0 or 0 \< D\_t(y) ≤ ε at some beat for some y; otherwise two-valued (FIN is required when ε \> 0).  
　Q(T): determined as 0 when s(x) ≤ ε at window end for some x ∈ T, or when ¬A(T); otherwise two-valued; never determined as 1.  
　Fld: determined as 0 when no position x satisfies both “s(x) \> ε at window end” and “s(x) \> ε at some beat within W”; otherwise two-valued; never determined as 1.  
Proofs of the determined directions:  
　q: if Ret fails, q = 0. At the beat of the threshold crossing the net increment is positive; only effective terms are booked, so some term has c \> ε, and s ≥ 0, so that term enters Form (Adjudication Form, Theorem 5(3)).  
　Part, HDyn: when ¬A(T) there is no available position within W, Avail is empty, and Cond and HistCond are both 0.  
　Act: pulse amplitudes are nonnegative, so a net decrease must come from some effective negative component; effective pulse amplitudes all exceed ε, so their sum is either 0 or greater than ε, and hence 0 \< D ≤ ε must also involve an effective process component. In both cases there is an effective process acting on T.  
　Q, Fld: Q(T) = 1 requires every position of T to exceed ε at window end and some position to be available within W, so some single position must have both properties.  
Twin constructions for the two-valued directions: each construction below keeps Φ pointwise the same on the stated state set (including the raw values at out-of-domain points, so that legality is also the same), and so, by Lemma 1, the twins are indistinguishable under all observations of 𝒴₁.  
　r → 0: make every pulse in-field and move every process carrier inside B.  
　r → 1: at the same beat, add an out-of-boundary constant law +a and an in-boundary constant law −a (a \> ε) acting on one position of T.  
　Formation registration: at the entry beat, add an in-field pulse +a under the actual letter and an in-boundary constant law −a gated by the same letter, both acting on y.  
　q → 1: apply formation registration.  
　q → 0 (s(x) \> ε throughout the record): replace the effective pulses on x by in-boundary constant laws of the same amplitude gated by the same letter; x stays above ε throughout, so no process forms it by threshold crossing.  
　Part → 1: apply formation registration, then add, at an available beat, a pure-read process that reads y (k = b = 0).  
　Part → 0: move all process carriers within W out of the boundary.  
　HDyn → 1: apply formation registration, then add +k·y and −k·y (\|k·s\_t(y)\| \> ε); the two terms have the same absolute value everywhere, so they become effective and ineffective together.  
　Q, Fld → 0: r → 0 makes Src = 0 for every T at once.  
　Fld → 1: take T = {x} and superpose formation registration, r → 1, the pure read and ±k·x; the constructions do not interfere with one another.  
　All the constructions above are identities on every state, for any ε.  
　HDyn → 0:  
　　ε = 0: centering. Replace each in-window process τ acting on T by the constant law τ(s\_t) together with the law of the same type τ − τ(s\_t). The latter is 0 at the actual state and hence ineffective; the constant law has no functional support, so HistCond is 0. When ε = 0, zero terms do not change the sum, and Φ is a polynomial identity; every term keeps its value at the actual state, so formation, causes and action are unchanged.  
　　ε \> 0 (FIN): replace only those in-window processes τ = b + k·m(s) acting on T that are effective at the actual state, where m is the sum or the product of the read positions. At beat t write Z = m(R\_t), z\* = m(s\_t), F(z) = τ(z)·\[\|τ(z)\| \> ε\] − τ(z\*). Replace τ by the constant law τ(s\_t) gated by the actual letter, and add the dead-zone terms given by Lemma 2, of the same law type, with the same read positions and gated by the actual letter; when the original process is ungated, add one gated copy of it under each of the other letters. Then Φ is the same on R\_t letter by letter and point by point.  
　Act → 0 (each beat has D = 0 or D \> ε):  
　　ε = 0: turn every term into a shifted term; the constant of the ungated part is supplied instead by constant laws gated by the other letters; the net increment D under the actual letter is supplied instead by an in-field pulse. Pulses do not count as action.  
　　ε \> 0 (FIN): replace the effective terms by dead-zone terms as above, and merge the constant part with the effective pulses under the actual letter into a single in-field pulse D; since D \> ε, this pulse is effective; when D = 0 no pulse is set. ∎

### 5.2  The Stochastic Family

Theorem 3 (Family 𝔉^ω)  
(1) Uniform form: there exists a single frozen twin whose structural map is an identity for every ω and which changes the duty on every realization satisfying the corresponding condition.  
　r → 0/1, Part → 0, q → 0/1, Q and Fld → 0: the constructions of Theorem 2 do not depend on the realization in the first place; parameters that depend on ω are transformed along with them.  
　Part → 1, HDyn → 1 (all-T, all-beat construction): register formation for every position y of T; for every window beat t and every y, add the in-boundary terms +1·y and −1·y. The parameters do not depend on the realization; the two terms have the same absolute value everywhere, so the net transition is an identity for every ω and every state. In any realization satisfying A(T), some y exceeds ε at some window beat; there that pair of terms is effective, reads the available position y and has its carrier inside B, so Part = HDyn = 1.  
　Q(T) → 1: on top of the construction above, add for every position of T an out-of-boundary +a and an in-boundary −a at t₀. In every realization in which every position of T exceeds ε at window end and A(T) holds, Q(T) = 1.  
　Fld → 1: apply the same construction to all in-boundary positions (including the r pair). In each realization, take any position x that exceeds ε at window end and at some beat within the window, and let T = {x}; then Q(T) = 1. T is chosen according to the realization; the twin is one and the same.  
　These constructions add processes, and are used only for observation sets that do not read the module decomposition, not for the MOD branch.  
(2) Anchored form:  
　HDyn → 0: for each actual realization ω\* there exists a twin, frozen before the experiment, that preserves all experiment distributions and has HDyn = 0 on (h\_act, ω*). ε = 0: for each module to be replaced, the constant is the module's law value C = τ\_{ω*\_t}(s\_t) at the actual complete pre-beat state under the actual innovation, and the parameters of the shifted term are taken per ω as b\_ω − C, giving a polynomial identity for every ω. ε \> 0: FIN and a finite set Ω of disturbance values are required; the parameters are piecewise in the current beat's innovation: when ω\_t = ω\*\_t, the dead-zone decomposition anchored at the actual pre-beat state is used, and under every other ω the original law is kept; the closure is taken over the states under all ω sequences and all baseline and control histories.  
　Act → 0: the permitted realization domain is that the actual net increment at every beat within the window and at every position of T is D = 0 or D \> ε (for ε = 0, simply D ≥ 0).  
　　Within this domain, centering is used for ε = 0, and no further antecedent is needed; for ε \> 0, FIN and a finite Ω are additionally required (the closure including all permitted experiments, declared settings, shared disturbances and clamped states). Under these antecedents, for each actual realization ω\* there exists a twin, frozen before the experiment, that preserves all experiment distributions and has Act = 0 on (h\_act, ω*). Construction: under ω*\_t, each effective T term is replaced by terms ineffective at the actual state (shifted terms for ε = 0, dead-zone terms for ε \> 0), and its value at the actual state is merged with the original total of effective pulses into a single in-field pulse D; under every other ω the original law and the original total of effective pulses are kept; when the original process is ungated, a full copy is kept under the other letters.  
　　FIN and a finite Ω are working-domain conditions of this construction; they are not asserted to be necessary for the existence of every zero-direction twin. When ε \> 0 and FIN fails (e.g., when the declared setting domain contains infinitely many legitimate values), this construction does not cover the case: the jump toward the actual state described in Theorem 4 may then occur and make Act determined as 1 (Instance B6), or some other zero-direction twin may exist; absent any other criterion, the case is recorded as not covered by this construction.  
　　Outside this domain (D \< 0 at some beat at some position of T, or 0 \< D ≤ ε): Act is determined as 1 in the record class, and no zero-direction twin exists; this conclusion does not depend on FIN.  
　The anchored construction is not uniform: on non-anchored realizations the same anchored twin may still have HDyn = 1. This shows only that the construction is not uniform; it does not prove that no uniform twin exists.  
(3) The determined directions use only the actual record. The in-boundary trajectory in the record is the same on every member of the stochastic class C(M, record), so the determinacy conditions of Theorem 2 hold for every (M′, ω′) in the class; the two-valued conclusions are given by ≈path twins, and these twins belong to the ≈obs class. ∎

### 5.3  The LOC Branch

Corollary 1 (LOC Adds No Determinacy When ε = 0)  
When ε = 0, within 𝒴₁+LOC, the determinacy conditions and the two-valued cases of Theorem 2 are unchanged item by item; the anchored form of Theorem 3 likewise holds.  
Proof: when ε = 0, all the twins of Theorems 2 and 3 are identities of Φ on all states, so local settings cannot separate them; the determined directions still hold on the finer equivalence classes. ∎  
When ε \> 0, the twins in the rows for q, r, Part, Q and Fld are still identities on all states, and the conclusions are unchanged; the zero-direction twins of HDyn and Act are equal only on the closure, and LOC can make these items determined (Theorem 4). The zero direction of Act is stated, in every case, only within its permitted realization domain.  
Theorem 4 (The Gain of LOC When ε \> 0; Family 𝔉)  
Antecedents: the LOC setting domain contains all legitimate values in some open neighborhood on the slice in question; every step within that neighborhood is legitimate; y′ belongs to Y\_t^det, i.e., s\_t(y′) \> ε and there is an observable threshold-crossing formation before beat t; every model has finitely many processes.  
Statement: take t ∈ W, the actual letter u, and y ∈ T. Along the y′ slice (setting y′ to v in s\_t), let g(v) be the increment on y. If there exists p ≠ s\_t(y′) such that g(p) equals the limit from the side facing away from s\_t(y′), while the limit from the side facing s\_t(y′) differs from g(p), then every member of the class has HDyn = 1 and Act = 1.  
Proof: in any member, g is the sum of the effective terms acting on y at beat t under letter u. Terms and pulses that do not read y′ are constant along the slice; the partner of a bilinear law is fixed on the slice. A term that reads y′ is θ\_j = w\_j·\[\|w\_j\| \> ε\], where w\_j is affine in v or of the form b + k v². On v ≥ 0, the ineffective set of w\_j is a closed interval and the effective set is its complement, each branch extending to the end of the domain in the direction away from that interval. Discontinuities of g occur only on the boundaries of the effective sets of the terms; at a boundary point p the term takes 0, and its limit from the effective side has modulus ε. The difference between the facing-side limit and g(p) equals the sum of the limits of those terms that have p as a boundary point and their effective side facing s\_t(y′); this difference is nonzero, so at least one term θ\_j has p as a boundary point and is effective on the side facing s\_t(y′). That effective branch extends to the end of the domain and so contains s\_t(y′). Hence θ\_j is effective at the actual state, its target is y ∈ T, and it depends on y′ along the slice: for a linear law, k ≠ 0 and y′ is among the read positions; for a bilinear law, the partner is nonzero at s\_t; for the y′·y′ law, s\_t(y′) \> ε ≥ 0. In all three cases y′ lies in the action support; y′ is available, the threshold crossing gives a formation record in every member, and the canonical evidence edge exists. Hence HistCond = 1, HDyn = 1 and Act = 1. ∎  
This theorem is only a sufficient condition. Instance: Appendix B.6. Hence when ε \> 0, LOC strictly increases determinacy.

### 5.4  The MOD Branch

The closure R\_t^MOD: the set of complete states of the two sides at beat t over all experiments of 𝒴₁+MOD, the experiments including arbitrary legitimate baseline and control histories, arbitrary knockout subsets on each side at each beat, and clamped mixed states. Fitting only on the slice whose baseline is the actual history is not enough to support equivalence under all observations (Instance B1).  
Lemma 3 (Reduction to Pulse Totals)  
Let P\_t(u, y) be the total of effective pulses on the target position y at beat t under letter u (each term thresholded first, then summed).  
(1) Let π\_B be the in-boundary reading projection. In the same experiment, the actual state and the control state differ only on Y\_t in every member, while the difference of the readable bookings is fixed by the observations; so in every member the law takes different values at the two states and therefore reads some y′ ∈ Y\_t. For a linear law, k ≠ 0 and the support is the set of read positions. For a bilinear law k·j₁·j₂: if j₂ were 0 at s\_t, then j₂ ∉ Y\_t, so j₂(s) = 0 and the law would take the same value at both states, a contradiction; hence the partner is nonzero at s\_t, and j₁ lies in the support and is available. ### 5.6  Indecomposable Joint Net Zero

Proposition 5 (Formal Evidence Variables Cannot Be Recovered from 𝒴\_L)  
Objects: pairs of R-layer models with the same transition relation and the same successor sets for all joint events, differing only in the formal evidence variable φ (Mathematical Form D9) of some joint event j, which is 1 on one side and 0 on the other. Permitted interventions: inputs, local settings, and knockouts with j as an indecomposable unit. Permitted readings: all state components of the L layer.  
Conclusion: the joint distributions of readings of all experiments in 𝒴\_L are the same, so the declared formal evidence variable φ cannot be recovered from 𝒴\_L.  
Proof: φ enters no transition, intervention map or reading; apply Lemma 1. ∎  
This proposition is a statement about formal evidence variables, not about the facts of physical action at the object level. To claim that two legitimate hosts, one with “actual action true” and one with “actual action false”, are indistinguishable within 𝒴\_L, one must give two mechanism witnesses satisfying the upstream semantics, together with all intervention maps, and prove that both are legitimate candidates; this claim is unproven (U4). Distinguishing requires going beyond the defined 𝒴\_L; it does not follow that it requires going beyond the L layer. “No distinguishing observation exists” and “no implementable additional reading has yet been defined” are two different states.

### 5.7  Reference Histories for Hist

Let Hist\_ρ be the Hist given by the reference history that replaces the examined segment with ρ (rest reading, twin clamping). In this section q ∈ ℕ₀ is the number of delay beats and r ∈ \[0,1) is the TV discrimination threshold, distinct from the duty notation q(x) and the source notation r(T).  
Theorem 7 (Equivalence Classes of Reference Histories)  
(1) Once the actual history and the compared block are fixed, the reference acts on Hist only through the TV distances under each q; hence ρ and ρ′ give the same verdict for all r ∈ \[0, 1) and all q if and only if their TV distance vectors are the same. This is a quotient by the distance function: different marginal distributions can have the same distance (Appendix B.11(4), Example 1). Deterministic case: when the compared block consists of all in-boundary positions, clamping is applied at every beat and the tail segment has the same dynamics, the beats at which the states on the compared block coincide after clamping form an upward-closed set; when the compared block is shrunk, this conclusion must not be carried over.  
(2) In the PE family, the net transition of a letter without pulses is the same as that of rest, so every reference without effective pulses lies in the same class as the rest reference.  
(3) When PE fails (in-boundary processes with input gating being allowed), rest is not a privileged reference: there exist pulse-free references that give the opposite Hist from rest.  
(4) A reference containing effective pulses can give Hist = 1 while the examined segment has no signal. Hence Lemma 12 of the Adjudication Form certifies r only for the rest reference or for references in the same class as it.  
(5) With a finite window and a finite set of q, exact computation is possible: propagate the two-copy joint distribution (shared disturbances, clamping), take the marginal on the compared block, compute the rational TV for each q, and take the quotient of references by distance vector.  
(6) The Hist quotient loses the source of formation: two references that reach the same state, one through a signal pulse and the other through an in-field gated process, have the same distance vector but different formation events (Appendix B.11(4), Example 2). Hence equality of Hist does not imply that the sources of events are the same, in agreement with the redundant formation of Lemma 7 of the Adjudication Form.  
Proof: (1) Let d\_ρ(q) be the marginal TV distance on the compared block between the fixed actual history and the reference history at delay q. Hist\_ρ(r,q) = 1 if and only if d\_ρ(q) \> r. If the distance vectors are the same, the verdicts agree threshold by threshold; if the two distances at some q satisfy d \< d′, take d ≤ r \< d′ (r \< 1 can be chosen), and the two values differ; so the converse also holds. Different marginals can have the same distance: for example, relative to δ₀, both δ₁ and δ₂ are at TV 1. In the deterministic case, once all in-boundary states have merged and the out-of-boundary components have been clamped equal, the two complete states are the same; the common tail dynamics keeps identical states identical, so the set of merged beats is upward closed.  
(2) Under PE, processes other than pulses are not input-gated, so a letter without effective pulses gives the same update as rest; by induction on beats, the reference reading distributions and their distances are the same.  
(3) Take an in-boundary position x with initial state 0; at the examined beat, the actual letter a gives a signal pulse 1, letter b gives an in-field gated constant law 1, and rest makes no change. With b as reference both sides reach 1, and Hist = 0 at q=0; with rest as reference the two sides are at 1 and 0, and Hist = 1 (for any r\<1). This model does not satisfy the no-gating condition of PE.  
(4) Take a PE model in which only a carries a signal pulse 1 and rest makes no change; the actual examined beat is rest and the reference uses a. The actual segment has no signal, but the TV between the final states 0 and 1 is 1, so Hist = 1 at q=0, r\<1.  
(5) A finite explicit rational kernel is pushed forward on the complete two-copy states, joint probabilities are computed under shared disturbances, and marginals are taken after clamping is completed; all probabilities and TV distances are rational and can be compared exactly for each q.  
(6) In the model of (3), the actual history is a, and the two references are a and b; both references reach 1, and the common rest tail keeps the states the same, so all distances are the same. The former has a signal formation event, the latter only an in-field formation event: the sources differ while the Hist quotient is the same. ∎

5.8  Decision of Stochastic Two-Copy Equivalence  
Theorem 8 (Decision of ≈obs on Finite Rational Domains)  
Antecedents: a finite set of disturbance values with rational probabilities; a finite alphabet; a finite window, or finitely many complete protocol states; a frozen structural kernel.  
Statement: whether two candidates are observationally equivalent within 𝒴₁ (two copies, shared disturbances, clamping) is decidable. This theorem decides only ≈obs, not ≈path.  
Complete protocol: the initial readings are compared first; the operations comprise letters and declared settings, the supply cut-off being a declared operation letter; legitimate histories are given by the monitor automaton, and when it is not prefix-closed, legitimate complete histories are delimited by accepting states and experiments take only prefixes that can be extended to accepted histories within the remaining beats; copies running in the same beat must be jointly acceptable at one common remaining length; it is not enough to check that each copy separately has some accepting length; leaving the domain enters an absorbing state that reads out “illegal”.  
Proof: (1) The two-copy process of each candidate is a finite controlled probabilistic machine whose states are complete protocol states; each common operation a and joint reading o give a rational matrix K\_(a,o). (2) For the two candidates, take block-diagonal matrices, the initial row vector α = (α\_M, α\_M′) and the functional f(v) = v·(1, −1)ᵀ. (3) The probability difference of an operation word w with readings is f(α K\_w). (4) Starting from α and multiplying on the right by the K\_(a,o) generates a rational linear span whose dimension does not exceed the sum of the numbers of states of the two candidates, so the closure is completed in finitely many steps. (5) The candidates are observationally equivalent if and only if every basis vector v of the span satisfies f(v) = 0; if some vector has f ≠ 0, the word that generates it is a distinguishing witness. (6) Identical distributions of all readings on fixed operation words extend to adaptive strategies by induction on the history read so far (Lemma 1). ∎  
This does not apply to infinite-state kernels or to arbitrary real-valued black-box kernels.

~~~python
"""Decision procedure for Theorem 5(C) and Proposition 3: determinacy of module-level HistCond and of organizational-conditioning support in the MOD branch.
Given a module's booked term ĉ(s) on the closure R_t at beat t, the actual state s_t and the set of available positions Y_t,

import itertools

def shapes(sites):
    yield ('constant', ())
    for r in range(1, len(sites) + 1):
        for J in itertools.combinations(sites, r): yield ('linear', J)
    for i, j in itertools.combinations_with_replacement(sites, 2): yield ('bilinear', (i, j))
def gval(shape, s):

    if law == 'linear': return sum(s[j] for j in rd)
    return s[rd[0]] * s[rd[1]]
def _interval_ok(lo, hi, sign):
    """Whether k ∈ [lo, hi] (None means unbounded) with the sign of k equal to sign (+1 strictly positive, −1 strictly negative, 0 zero) is feasible; returns a feasible k or None."""
    if sign == 0:
        return Fr(0) if (lo is None or lo <= 0) and (hi is None or hi >= 0) else None
    if sign > 0:
        l = lo if lo is not None and lo > 0 else None
        if hi is not None and hi <= 0: return None
        if l is None: return (hi / 2) if hi is not None else Fr(1)
        if hi is not None and l > hi: return None
        return l
    l = hi if hi is not None and hi < 0 else None
    if lo is not None and lo >= 0: return None
    if l is None: return (lo / 2) if lo is not None else Fr(-1)
    if lo is not None and l < lo: return None
    return l
def fit(pts, eps, sign):

    def check(b, k):

    gs = sorted({g for g, _ in E})
    if sign == 0:

        b = E[0][1] if E else Fr(0)
        return (b, Fr(0)) if check(b, Fr(0)) else None

        (g1, c1), (g2, c2) = [next((g, c) for g, c in E if g == gs[0]), next((g, c) for g, c in E if g == gs[1])]

        return (b, k) if (k > 0 if sign > 0 else k < 0) and check(b, k) else None

            if d == 0:
                if abs(c0) > eps: return None
                continue

            l, h = min(a, bnd), max(a, bnd)

        if lo is not None and hi is not None and lo > hi: return None

    return yes, no
~~~

A.6  deadzone.py  Dead-zone decomposition: an arbitrary target function on a finite set decomposed into a sum of effective terms, each ineffective at the anchor (Lemma 2)

~~~python
"""Lemma 2 (dead-zone decomposition): for a finite set Z ⊂ ℚ, z* ∈ Z and ε > 0, every F: Z → ℚ with F(z*) = 0
can be written as a finite sum of terms θ(z) = (b + k z)·[|b + k z| > ε], each with |b + k z*| ≤ ε (ineffective at z*).
Construction: in each gap to the right of z*, a pure step is the difference of the ramps at two thresholds; each ramp is given by a pair of single terms with the same threshold (their ±ε steps cancel); the left side is the mirror image.
"""
from fractions import Fraction as Fr
def _theta(b, k, z, eps):
    v = b + k * z
    return v if abs(v) > eps else Fr(0)
def _ramp_right(U, lam, zmin, eps):
    """λ·(z − U)·[z > U]; every term is ineffective at the points of the finite set with z ≤ U (keeping the left tail from reactivating requires slope < 2ε/(U − zmin))."""
    if lam == 0: return []
    B = 2 * eps / (U - zmin)
    N = int(abs(lam) / (B / 2)) + 1
    k2 = B / 2; k1 = k2 + lam / N
    assert 0 < k1 < B and 0 < k2 < B
    return [(eps - k1 * U, k1), (k2 * U - eps, -k2)] * N     # P+(U,k1): k1(z−U)+ε; P−(U,k2): −k2(z−U)−ε
def _ramp_left(L, lam, zmax, eps):
    """λ·(L − z)·[z < L]."""
    if lam == 0: return []
    B = 2 * eps / (zmax - L)
    N = int(abs(lam) / (B / 2)) + 1
    k2 = B / 2; k1 = k2 + lam / N
    assert 0 < k1 < B and 0 < k2 < B
    return [(k1 * L + eps, -k1), (-k2 * L - eps, k2)] * N    # Q+: k1(L−z)+ε; Q−: −k2(L−z)−ε
def decompose(Z, zs, F, eps):
    Z = sorted(set(Z)); assert zs in Z and F[zs] == 0 and eps > 0
    zmin, zmax = Z[0], Z[-1]; terms = []
    right = [z for z in Z if z > zs]; left = [z for z in Z if z < zs][::-1]
    prev, fprev = zs, Fr(0)
    for z in right:
        H = F[z] - fprev
        if H:
            U, U2 = prev + (z - prev) / 3, prev + 2 * (z - prev) / 3
            lam = H / (U2 - U)
            terms += _ramp_right(U, lam, zmin, eps) + _ramp_right(U2, -lam, zmin, eps)
        prev, fprev = z, F[z]
    prev, fprev = zs, Fr(0)
    for z in left:
        G = F[z] - fprev
        if G:
            L, L2 = prev - (prev - z) / 3, prev - 2 * (prev - z) / 3
            lam = G / (L - L2)
            terms += _ramp_left(L, lam, zmax, eps) + _ramp_left(L2, -lam, zmax, eps)
        prev, fprev = z, F[z]
    for b, k in terms: assert abs(b + k * zs) <= eps
    for z in Z: assert sum((_theta(b, k, z, eps) for b, k in terms), Fr(0)) == F[z], z
    return terms
if __name__ == '__main__':
    import random
    rng = random.Random(5); n = 0
    for _ in range(400):
~~~

~~~python
class DModel:

def run_k(m, seqs):
    """k copies; copy 0 is the baseline, and the remaining controls are clamped step by step to the baseline's out-of-boundary value. Returns the beat-by-beat readings (the in-boundary component of each copy)."""
    xs = [m.s0] * len(seqs); out = [tuple(x[0] for x in xs)]

        xs = [nb] + [clamp(m.step(x, u), nb) for x, u in zip(xs[1:], step[1:])]

def product_search(m1, m2):

    while dq:
~~~

~~~python
    return sm_with(sm, procs=tuple(procs))

def act_domain_ok(sm, h, w):
    """Permitted realization domain of Act → 0: at every window beat and every T position, the actual net increment is D = 0 or D > ε. Otherwise Act is determined as 1 in the record class."""
    dm = sm.inst(w); tr = dm.traj(h); eps = sm.base.eps
    for i, t in enumerate(dm.beats):
        if t in dm.W:
            for y in dm.T:
                D = tr[i + 1][y] - tr[i][y]
                if D < 0 or (0 < D <= eps): return False
    return True
def a_act0(sm, h, w, letters=LET):
    """Act → 0 in anchored form (called only inside the permitted realization domain). At beat t, with actual innovation ω*_t and actual letter u:
    each in-window process acting on T is replaced under ω*_t by terms ineffective at the actual state (ε = 0: shifted terms; ε > 0: dead-zone terms), and its value at the actual state is merged into one in-field pulse;
    under the other ω the original law is kept; if the original process is ungated, a full copy is kept under the other letters. Under ω*_t the original pulses are merged into D; under the other ω they keep their original amounts."""
    assert act_domain_ok(sm, h, w)
    dm = sm.inst(w); st = dict(zip(dm.beats, dm.traj(h))); au = dict(zip(dm.beats, h)); wb = dict(zip(dm.beats, w)); eps = sm.base.eps
    procs = list(sm.base.procs); pulses = list(sm.base.pulses)
    zero_at = lambda spec, ws, val: {o: (val if o == ws else pick(spec, o)) for o in sm.Omega}
    for t in dm.W:
        u, ws = au[t], wb[t]; R = reach_s(sm, t, letters) + [st[t]]
        K = defaultdict(Fr)
        for q in sm.base.procs:
            if not (q.beat == t and q.target in dm.T and (q.gate is None or q.gate == u)): continue
            qi = replace(q, b=pick(q.b, ws), k=pick(q.k, ws)); c = value(qi, st[t])
            if abs(c) <= eps: continue                       # a term ineffective at the actual state does not count as action anyway; keep it
            procs.remove(q)
            if q.gate is None: procs += [replace(q, name=f'{q.name}@{v}', gate=v) for v in letters if v != u]
            procs.append(replace(q, name=q.name + '·o', gate=u, b=zero_at(q.b, ws, Fr(0)), k=zero_at(q.k, ws, Fr(0))))
            K[q.target] += c
            if q.law != 'constant' and qi.k != 0:
                fun = lambda s_, q=q: sum(s_[j] for j in q.reads) if q.law == 'linear' else s_[q.reads[0]] * s_[q.reads[1]]
                if eps == 0:
                    procs.append(replace(q, name=q.name + '·δ', gate=u, b={o: (qi.b - c if o == ws else Fr(0)) for o in sm.Omega},
                                         k={o: (qi.k if o == ws else Fr(0)) for o in sm.Omega}))
                else:
                    Z = {fun(s_) for s_ in R}; zs = fun(st[t])
                    F = {z: ((qi.b + qi.k * z) if abs(qi.b + qi.k * z) > eps else Fr(0)) - c for z in Z}
                    for j, (bb, kk) in enumerate(decompose(Z, zs, F, eps)):
                        procs.append(replace(q, name=f'{q.name}#{j}', gate=u, b={o: (bb if o == ws else Fr(0)) for o in sm.Omega},
                                             k={o: (kk if o == ws else Fr(0)) for o in sm.Omega}))
        for y in dm.T:
            old = [p for p in sm.base.pulses if p.beat == t and p.letter == u and p.target == y]
            A = sum((pick(p.amount, ws) for p in old if pick(p.amount, ws) > eps), Fr(0))
            D = A + K[y]
            assert D == st[t + 1][y] - st[t][y] if (t + 1) in st else True
            pulses = [p for p in pulses if p not in old]
            amt = {o: (D if o == ws else sum((pick(p.amount, o) for p in old if pick(p.amount, o) > eps), Fr(0))) for o in sm.Omega}
            if any(amt.values()): pulses.append(P(f'D{t}{y}', t, u, y, amt, False))
    return sm_with(sm, procs=tuple(procs), pulses=tuple(pulses))

def inst_beat(sm, t, o):
    return sm.inst(tuple(o if tt == t else sm.Omega[0] for tt in sm.base.beats))
def push(sm, state, op):
    """state = (beat index, baseline state, control state) or 'END'. Returns {reading: {new state: probability}}."""
    out = defaultdict(lambda: defaultdict(Fr))
    if state == 'END' or state[0] > sm.base.t1:
        out['—']['END'] += 1; return out
    t, b, c = state; b, c = dict(b), dict(c); pr = Fr(1, len(sm.Omega))
    for o in sm.Omega:
        dm = inst_beat(sm, t, o)
        try: nb = dm.step(t, b, op[0]); nc = dm.step(t, c, op[1])
        except Illegal: out['illegal']['END'] += pr; continue
        for x in sm.out: nc[x] = nb[x]
        rd = (tuple(nb[x] for x in dm.sites if x not in sm.out), tuple(nc[x] for x in dm.sites if x not in sm.out))
        out[rd][(t + 1, tuple(sorted(nb.items())), tuple(sorted(nc.items())))] += pr
    return out
def equivalent(sm1, sm2, letters):
    ops = list(itertools.product(letters, repeat=2))
    s0 = lambda sm: (sm.base.t0 - 1, tuple(sorted(sm.base.init.items())), tuple(sorted(sm.base.init.items())))
    start = {(0, s0(sm1)): Fr(1), (1, s0(sm2)): Fr(1)}
    basis = []                                        # reduced basis: [(pivot, vector)]
    def reduce(v):
        v = dict(v)
        for piv, bv in basis:
            if piv in v and v[piv] != 0:
                f = v[piv] / bv[piv]
                for k, x in bv.items(): v[k] = v.get(k, Fr(0)) - f * x
                v = {k: x for k, x in v.items() if x != 0}
        return v
    def func(v): return sum(x for (side, _), x in v.items() if side == 0) - sum(x for (side, _), x in v.items() if side == 1)
    queue = [(start, ())]
    while queue:
        v, word = queue.pop()
        r = reduce(v)
        if not r: continue
        piv = next(iter(r)); basis.append((piv, r))
        if func(v) != 0: return False, word
        for op in ops:
            grouped = defaultdict(dict)
            for (side, st), x in v.items():
                smx = sm1 if side == 0 else sm2
                for rd, nxt in push(smx, st, op).items():
                    for ns, p in nxt.items(): grouped[rd][(side, ns)] = grouped[rd].get((side, ns), Fr(0)) + x * p
            for rd, nv in grouped.items(): queue.append((nv, word + ((op, rd),)))
    return True, len(basis)

def can_finish(mon, q, steps):
    states, delta, start, acc = mon; cur = {q}
    for _ in range(steps): cur = cur | {delta[(x, o)] for x in cur for o in OPS_G[0] if delta.get((x, o)) is not None}
    return bool(cur & acc) if steps >= 0 else False
def joint_can_finish(mon, qb, qc, steps):
    """The two same-beat copies must be able to accept jointly at one and the same remaining length; being able to finish separately does not guarantee that the joint experiment is legal."""
    def lengths(q):
        cur = {q}; out = set()
        for n in range(steps + 1):
            if cur & mon[3]: out.add(n)
            cur = {mon[1][(x, op)] for x in cur for op in OPS_G[0] if (x, op) in mon[1]}
        return out
    return bool(lengths(qb) & lengths(qc)) if steps >= 0 else False

def brute_full(sm1, sm2, ops, mon):
    rd0 = lambda sm: tuple(sm.base.init[x] for x in sm.base.sites if x not in sm.out)
    if rd0(sm1) != rd0(sm2): return False
    B = len(sm1.base.beats)
    def accepted(seq):
        q = mon[2]
        for o in seq:
            q = mon[1].get((q, o))
            if q is None: return False
        return q in mon[3]
    seqs = [x for n in range(B + 1) for x in itertools.product(ops, repeat=n) if accepted(x)]
    def law(sm, hb, hc):
        ws = list(itertools.product(sm.Omega, repeat=len(hb))); pr = Fr(1, len(ws)); out = Counter()
        for w in ws:
            dm = sm.inst(w); b = dict(dm.init); c = dict(dm.init); rd = []
            for t, ob, oc in zip(dm.beats, hb, hc):
                try: nb = apply_op(dm, t, b, ob); nc = apply_op(dm, t, c, oc)
                except Illegal: rd.append('illegal'); break

                b, c = nb, nc
                rd.append((tuple(b[z] for z in dm.sites if z not in sm.out), tuple(c[z] for z in dm.sites if z not in sm.out)))
            out[tuple(rd)] += pr
        return out

def tv_vector(sm, h_act, h_ref, Q, block):
~~~
