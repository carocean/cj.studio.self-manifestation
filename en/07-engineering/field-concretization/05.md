# The Reachability Form of Field Concretization

1\. Declaration of Form Kind  
This paper is a Reachability Form (an auxiliary form of establishment proof). Its sole task is to determine, in a fixed reachability working context, whether a Sedimentation-Field target that has attained construction strength can be reached from the declared initial state using only the declared permitted operations and passing only through legitimate successors of the same lineage. For a reachable target it gives a path and a bound on the number of steps or on the budget; for an unreachable one it gives a witness of unreachability.  
The conclusions of this paper fall into four groups.  
　1\. Information structure of qualification targets: Sedimentation-Field qualification is not a function of raw state (Theorem 1); within the declared model class, qualification is determined by the window's starting state, the formation and mark records, and the in-window input (Lemma 1).  
　2\. Finite decision and path bounds: when the physically reachable set is finite, qualification reachability is decidable and the shortest path length does not exceed (2\|I\| + 1)N − 1 + w (Theorem 2); counterfactual-level targets have a corresponding node bound when the clamped closure is finite (Corollary 1).  
　3\. Formation paths: a qualification path must contain an effective out-of-boundary change (Lemma 2); the formation paths, minimal beat counts and unreachability witnesses for the witness χ₀ of *The General Form of Field Concretization* and for Instance A of *The Adjudication Form of the Sedimentation-Field* (Theorem 3, Proposition 2); the entry stage of the representative examples of tendency types (Proposition 3).  
　4\. Controlled ordering: in a restricted family of the locally exchangeable families, reversal reachability and locking obstructions under two regimes: a per-beat amplitude bound and a cumulative budget bound (Theorem 4).  
In addition: declaration rules for extending the permitted set (Proposition 4), reachable but unprovable (Corollary 2), trace-erasure bounds (Lemma 3), and the declaration of the stochastic branch (Section 11).  
Strength position: in the strength order of the Canon Chapters, Part Two, Chapter Five, reachability lies after construction and before realization. A reachability conclusion does not include a construction conclusion; “there exists a permitted path” is neither maintenance in the sense of the Stability Form nor universal arrival in the sense of the Necessity Form; reachability is not material realization.  
Theoretical increment and resistance: qualification targets depend on formation and mark records and on counterfactual history pairs, and cannot be written as reachability on sets of raw states. The “system × record” product construction is itself an existing formal method; the increment of this paper lies in the specific records that Sedimentation-Field qualification requires, their sufficiency and quantifier preservation, and the linear path bound that monotonicity of the records yields. The controlled-ordering part gives explicit invariant sets and budget bounds under the specified model and operation regimes; it is not a general theory of optimal control. Elementary conclusions are stated as lemmas, corollaries or declaration rules, not as main theorems.

### 2.2  Construction Entry Condition

The entry condition of a Reachability Form is that the target has attained construction strength (Canon Chapters, Part Four, Chapter Nine). The target objects of this paper are only the following existing constructions:  
　(1) χ₀ (Section 6 of *The General Form of Field Concretization*), given explicitly and checked item by item;  
　(2) Instance A of the Adjudication Form (χ\_ext, χ\_in, χ\_frz), with an explicit model and verdicts evaluated item by item;  
　(3) the representative examples of local families in 6.3–6.4 of *The Grading Form of Tendency Types*, with states, net laws and Tr^rest witnesses given explicitly;  
　(4) the finite models used by Theorem 1, Theorem 2, Corollary 1, Proposition 4 and Corollary 2, given explicitly in the main text or in Appendix A of this paper and evaluated item by item.  
Anyone who takes another object as a target must first register “the target has attained construction strength” as an open antecedent and may make only conditional reachability statements; the reachability regime does not work backwards to certify construction strength. The continuation of Canonical F\* is stochastic; it is listed in Section 11 and does not enter the main theorems.

### 2.3  Delimitation of Scope

　(1) Construction of the target belongs to the Construction Form;  
　(2) maintenance, exit and return after arrival belong to the Stability Form;  
　(3) necessary arrival of all or almost all trajectories belongs to the Necessity Form;  
　(4) completion under real resources and materials belongs to the Realization Form;  
　(5) reachability conclusions do not constitute qualification certification of any material host; simulated reachability does not mean that a material host has acquired qualification.

3\. Reachability Working Context and Declaration of Permitted Operations  
Definition 1 (reachability working context 𝒞\_reach). A reachability judgment must fix the following:  
　the model instance and representation layer (the F layer, the R layer, or the beat-wise reading into which a continuous model enters through the one-beat flow map);  
　the initial state and the initial record (empty by default; a nonempty one must be declared as the record of a legitimate prehistory);  
　the permitted set Π;  
　the regime of legitimate histories (all finite words, or the language recognized by a declared monitor automaton);  
　prohibited operations;  
　the lineage (the same declared host instance);  
　the time domain (finite, eventual, asymptotic);  
　controller information (open-loop input words, full state feedback, policies based only on the observation history).  
Changing any one of these requires reachability to be judged anew.  
Definition 2 (ladder of permitted sets).  
　Π₀: the declared alphabet, i.e. signal pulses and rest;  
　Π₁ = Π₀ ∪ {supply cut-off};  
　Π₂ = Π₁ ∪ {LOC (declared setting domain)};  
　Π₃ = Π₂ ∪ {MOD}.  
The engineering permitted sets are Π₀ and Π₁; Π₂ and Π₃ are used only to discuss the effects of extension. Changing the upper bound of the input amplitude is a separately declared control regime, not the original permitted set. Permission and prohibition are distinguished by route of action: what is permitted is change formed by the host's own response to signals applied through the declared entry; what is prohibited is bypassing that mechanism to overwrite internal state directly, including directly writing or overwriting Trace-Responses and sedimentation states, directly setting qualification variables or labels, copy-overwriting, reinitializing or replacing the host, and hidden controllers. Each concrete model must state its declared entry positions and the route of action of its entry.  
Definition 3 (alphabet-gated F model class 𝔐\_GF). The finite deterministic subclass of the mechanism transition models of the Adjudication Form: each letter determines the pulse table and the process table of the current beat. Validity antecedents:  
　position names nonempty and pairwise distinct; ε, the initial state and the pulse amplitudes nonnegative rationals;  
　the alphabet finite and containing rest; process labels pairwise distinct within each letter;  
　process laws of the three classes of D12 of the Mathematical Form, with nonempty read positions for linear laws, exactly two positions for bilinear laws and no read positions for constant laws; read positions and action targets in the position set;  
　cert\_eff = 1; cert\_read and direct path-edge certification take values in {1, 0, ⊥}; Γ\_closed = closed; Ident and HistEv declared 1;  
　window length w ≥ 1.  
Invalid models are rejected and do not enter evaluation; a post-state with a negative value leaves the domain of definition. Formation and marking are registered strictly per D16 of the Mathematical Form: every certified effective pulse is counted into Form; an effective positive component makes a position whose pre-beat depth is not greater than ε a trace-retaining element; effective components of out-of-boundary pulses and of processes with out-of-boundary carriers are counted into Mark. Within the directly comparable range, this paper's evaluator agrees item by item with the upstream evaluator of Appendix A.1 of *The Mathematical Form of Field Concretization* (Appendix B.1).  
Definition 4 (window reading RD). For an input history h of 𝔐\_GF and a window length w, take the following F run: W is the last w beats of h; the beats before W form the formative history, whose Form and Mark records registered per D16 are represented in F by entry-beat records (D2 of the Mathematical Form); the starting state of W is the final state of the formative history. For each nonempty T ⊆ I this gives a three-valued reading Q\_F(h, T); define the qualification reading  
　　Fld\_RD(h) = ⋁^K\_{∅ ≠ T ⊆ I} Q\_F(h, T),  
where ⋁^K is strong Kleene disjunction (D1 of the Mathematical Form): 1 if some term is 1, 0 only if all terms are 0, ⊥ otherwise. The positive-determination qualification target is Fld\_RD(h) = 1, and reachability of a positive determination means ∃h ∈ 𝓗 \[Fld\_RD(h) = 1\]. The positive-determination target is equivalent to ∃T \[Q\_F(h, T) = 1\], but this equivalence does not redefine the three-valued reading Fld\_RD: a history with no Q\_F = 1 may have Fld\_RD = ⊥ (not yet certified), which is not read as 0. Hereafter Fld always abbreviates Fld\_RD; material-layer read-back still carries the upstream certification antecedents. The in-boundary self-feedback type further requires a process inside B such that \[tgt ∈ T\] ∧ Act ∧ HistCond, with the route of HistCond lying inside B (Section 7 of the General Form); under the direct evidence edges of 𝔐\_GF the route runs straight from the read positions in T to that process inside B, so this clause follows. RD is used only for actual formative histories of 𝔐\_GF; it does not compress the source paths of general R-layer histories into position-set summaries.  
Definition 5 (ladder of targets).  
　State targets: reaching a declared state, ordering, share region or state tendency direction. The tendency type of a host is a structural property of a fixed net law and declared domain, not a state that a trajectory reaches, and is not a state target; studying a change of tendency type requires separately declaring a change of parameters or of the dynamical law.  
　Qualification targets: under RD, the qualification reading Fld\_RD = 1 (positive determination), or the three-valued reading of the in-boundary self-feedback type equal to 1.  
　Provable qualification targets: the qualification target can be determined as 1 from certifying readings within the declared observation set.

4\. Information Structure of Qualification Targets  
Theorem 1 (insufficiency of raw state). There exist a model M\_B1 in 𝔐\_GF, an initial state and two permitted histories, of the same lineage, with identical beat-by-beat state trajectories and identical final states, such that under RD Fld is 1 for one and 0 for the other. Hence qualification targets cannot be expressed as reachability on sets of raw states or sets of raw trajectories.  
Proof. M\_B1: positions x, o, ε = 0; letter w is an out-of-boundary pulse +1 → x; letter b is a gated constant-law process inside B, +1 → x; letter c runs the linear-law process opt inside B (reads x, component 1 − x/2, acts on x) and the pure-read process rd inside B (reads x, acts on o, component 0); the initial state is (0, 0) and the initial record is empty. Take the histories (w, c) and (b, c), with W the last 1 beat. After the first beat both histories have x = 1 and Form(x) ≠ ∅; in the second beat opt reads the already formed x, the component 1/2 is effective, and both histories end the window in (3/2, 0). In the former, Mark(x) ≠ ∅; for T = {x}, Src = Ret = 1, rd bears Part, opt bears HDyn, and Q\_F = 1. In the latter, Mark = ∅, Src = 0 for every T, and Fld = 0 (Appendix B.2). ∎  
Relation to Theorem 1 of *The Mathematical Form of Field Concretization*: that theorem obtains the same trajectory with different qualification on one declared instance through different mechanism events; here the mechanisms are gated by letters, the model and initial state are fixed, and the two histories differ only in the input word, which gives a direct witness between two permitted histories in the reachability setting. The conclusion of this theorem is limited to the insufficiency of “raw” states and trajectories; once records are added, qualification targets reduce to targets on an extended state (Lemma 1).  
Proposition 1 (information levels). Under a fixed model, parameters and operational configuration, verdicts on qualification fall into three levels by the information they require:  
　(1) State level: Wr is a function of the current state together with the given model and operational configuration C\_op. In the reachability setting, the Tr^rest asked with the reached state as a new declared starting point is the Wr at that point.  
　(2) Record level: Q\_F, Fld and the in-boundary self-feedback type under RD; the information required is the window's starting state, the formation and mark position sets registered per D16, the in-window event atoms, and the declared atoms (cert\_read, path edges, Ident, HistEv).  
　(3) Counterfactual level: Hist^rest, Hist^cut and the historical form Act\_𝓟^h; the information required is the paired states of the actual side and the reference side (the examined segment replaced by rest), together with the value clamping of 3.3 of the Adjudication Form. The reference side is a computational branch used for certification and is not executed on the host.  
This proposition is a classification, not a general irreducibility theorem about “minimal information”.  
Lemma 1 (sufficiency of RD). In 𝔐\_GF (the subclass with direct evidence edges), Q\_F for each T, Fld and the in-boundary self-feedback type under RD are all functions of (s\_{n−w}, Form\_\<, Mark\_\<, window word), where Form\_\< and Mark\_\< are the formation and mark position sets registered per D16 over the formative history.  
Proof. Beat by beat, the solver of 5.1 of the Mathematical Form reads only the pre-beat state; the formation records earlier than the current beat (which determine the available positions, D17); the mark records (which determine Src); and the declared atoms. Entry records act in only three places: they make the corresponding positions “already formed”, they give Src its value, and they make Form ≠ ∅ in Ret hold. By D16, Form and Mark only grow. By induction on the number of beats in the window, the event atoms of every beat coincide, so Q\_F for each T at the end of the window coincides. Fld\_RD takes the strong Kleene disjunction over finitely many nonempty T (Definition 4), with the same three-valued semantics as upstream; the positive determination Fld\_RD = 1 holds if and only if Q\_F = 1 for some T, so the quantifier ∃T is not lost. ∎

5\. Finite Decision and Path Bounds  
Theorem 2 (qualification reachability on finite deterministic models). Let M ∈ 𝔐\_GF, with all finite words as legitimate histories and an empty initial record, and let the physical states reachable from s₀ by declared letters be finite, N in all.  
　(1) The set of augmented nodes (s, Form, Mark) reachable from (s₀, ∅, ∅) is finite, with at most N·4^{\|I\|} nodes. The number of augmented nodes may exceed N.  
　(2) Under RD, “there exists a permitted history with Fld = 1 (or with the in-boundary self-feedback type = 1)” is decidable.  
　(3) If such a history exists, the shortest satisfying history has length at most (2\|I\| + 1)N − 1 + w.  
　(4) Count: at most N·4^{\|I\|} augmented nodes; \|U\|^w window words enumerated per node; evaluation of each window takes O(2^{\|I\|}·w·\|events\|) unit-cost rational operations. This is an operation count, not a bit-complexity bound.  
Proof. (1) Physical successors depend only on the physical state and the letter, and each record position set takes one of 2^{\|I\|} values. (2) By Lemma 1, qualification is a function of the augmented node and the window word; breadth-first search on the finite augmented graph, followed by enumeration of the finitely many window words at each node, is complete and sound. (3) Form and Mark only grow, so along a shortest path (Form, Mark) changes at most 2\|I\| times. Within a segment on which the records are constant, a repeated physical state means a repeated augmented node, and cutting out the cycle gives a shorter path; so each segment has at most N − 1 steps, and the formative part has length at most (2\|I\| + 1)(N − 1) + 2\|I\| = (2\|I\| + 1)N − 1, to which the window length w is added. ∎  
This bound does not cover models with general history-monitor languages; a nonempty initial record must be brought in separately as the initial search node, and the programs of this paper implement only the empty initial record.  
Finite verification (Appendix B.1, B.2): on histories of the form “1 entry beat + W” (where RD and the upstream F run coincide in meaning), this paper's evaluator and the upstream evaluator compare Q for every nonempty T: over 400 random models, 29979 histories and 64107 (history, T) pairs agree item by item, covering effective pulses at positions with positive initial state, positive and negative effective components, formation earlier than reading, pure reads, zero coefficients, certification 0 or ⊥, and histories leaving the domain of definition (3630 of them). Compression of general formative histories is borne by the proof of Lemma 1 and is not replaced by finite comparison. Comparison of the augmented search: among 300 bounded random models, the shortest lengths of the 109 positive cases agree with brute-force enumeration in increasing length (maximum shortest length 4); the 191 negative cases are judged unreachable by (2), and brute force checks them only up to length 5; the largest ratio of the longest formative-part distance to N is 2.00, which shows that the node bound cannot be replaced by N. This comparison shares the evaluator with the search and checks only the search logic.  
Corollary 1 (node and path bounds for counterfactual-level targets). Applicable subclass: deterministic models; the set reachable from s₀ under the original dynamics is finite (N states), and the clamped closure of the reference side is finite (the in-boundary value set I′ is finite); transitions are computable; the legitimate histories are all finite words; the examined segment is a single position; q is fixed. Then the paired nodes (stage, actual state, reference state) of a Hist^rest target number at most N before the examined position; after it they are determined by (actual state, in-boundary value of the reference side) and number at most N·\|I′\|, where I′ is the in-boundary value set of the reference side after clamping, not a projection of the set reachable under the original dynamics. The shortest satisfying history has length at most N + N·\|I′\| − 1, plus a rest tail of q beats. If regular legitimate histories are declared, the monitor states of both sides and the stage must be merged into the nodes, multiplying by the corresponding factors; this case is not covered by this corollary (U3).  
Proof. Before the examined position the two sides have the same input and the same state; after it, the out-of-boundary components of the reference side are overwritten at every step with the values of the actual side, so the reference state is determined by the actual state and the in-boundary value of the reference side. A shortest path repeats no node. ∎  
Limit witnesses (Appendix B.3): M5 has only N = 2 states reachable under the original dynamics, yet under the actual history w·a^j the reference side runs through (0, 1), (2, 1), (4, 1), …, so the clamped closure is infinite; hence finiteness of N cannot replace finiteness of the closure. M1 (the witness model of Theorem 1 (a2) of the Adjudication Form) has 5 paired nodes under the “actual letter vs. rest” protocol, and its reference side enters the mixed state (0, 1), which is unreachable under the original dynamics; this count belongs to the restricted protocol of this corollary and is not the same algorithmic quantity as the node count of the upstream Tr history-pair search of the Adjudication Form. The shortest Hist^rest = 1 engineering history of M\_H is (a), in agreement with brute-force enumeration. In engineering only the actual history is executed; the reference side is a computational branch in model mode, and in measurement mode it must be realized with a replica or a resettable host (3.2 of the Adjudication Form).

6\. Formation Paths  
Lemma 2 (necessary passage of a signal). Under RD with an empty initial record, every permitted history with Fld = 1 contains an effective out-of-boundary change acting on some position of T (an out-of-boundary pulse, or an effective component of a process with an out-of-boundary carrier).  
Proof. Fld = 1 ⇒ there exists T with Src = 1 ⇒ Mark(i) ≠ ∅ for some i ∈ T (D19, D16 of the Mathematical Form). ∎  
If the initial record is declared as a legitimate prehistory carrying Mark, this lemma does not apply.  
Theorem 3 (entry of χ₀). χ₀ takes the original model δ' = min{δ\_max, δ + αu + βδ − λδ} with ε = 0 (upstream: every nonzero component is an effective change). Within the original parameter domain (α \> 0, 0 \< β \< λ \< 1, α/(λ − β) \< δ\_max) take the parameters α = 1/2, β = 1/10, λ = 3/10, δ\_max = 3, so that δ\* = α/(λ − β) = 5/2 \< δ\_max and ρ = 1 + β − λ = 4/5; inputs are rational; the initial state is δ = 0 and the initial record is empty.  
　(1) Qualification target: take a signal entry of amplitude 0 \< u ≤ δ\_max/α = 6 (if the context separately declares an input upper bound ū, also u ≤ ū) followed by rest within the window, two beats in all; this reaches Fld = 1 and in-boundary self-feedback type = 1. The shortest history length is 2 (W being 1 beat).  
　(2) State target “net-zero window” δ = δ*: u ∈ \[0, ū\] at each beat. This is a variant of χ₀ under a separately declared input-upper-bound regime; the original χ₀ declares ū ≥ 1/(λ − β) = 5, in which case n* = 1. δ\* is reachable at beat n if and only if ū(1 − ρⁿ) ≥ 1. Hence for ū \> 1 the minimal number of beats n\* is the least n satisfying this inequality; for ū = 1, δ\* is not reachable in finite time but is reachable asymptotically; for ū \< 1 it is unreachable.  
Proof. (1) At the entry beat δ = αu ≤ δ\_max, and at the rest beat ρδ \< δ; neither beat hits the cap, so the original model and the F encoding of its three terms (signal entry, read-out write-back βδ, shallowing −λδ) agree beat by beat. Upstream writes signal entry as an out-of-boundary process with component αu, whereas this paper encodes it as an out-of-boundary pulse of amplitude αu; the two have the same numerical update, both make the position formed at δ = 0, and both enter Mark (D16), so the registration of Form and Mark is the same. The entry pulse is effective and out-of-boundary, so x is formed and enters Mark; within the window the read-out write-back is conditioned on the already formed δ and has a nonzero component, so it bears Part, Act and HistCond, with its route inside B. With window length 1 and an empty initial record, a read within the window requires a prior formation, so at least two beats are needed. For u \> 6 the entry beat hits the cap (e.g. u = 7: the original model gives 3, the F encoding 7/2), the uncapped encoding does not apply, and the qualification conclusion of this theorem does not extend to that case. (2) f(δ, u) = min(δ\_max, ρδ + αu) is nondecreasing in δ and in u; the maximum after n beats is M\_n^c = min(δ\_max, M\_n), with M\_n = δ*·ū·(1 − ρⁿ). Since δ* \< δ\_max, δ\* is reachable at beat n if and only if M\_n ≥ δ*; the reachable set is an interval (continuous in u, and u = 0 keeps 0). For ū = 1, M\_n \< δ* while M\_n → δ\*. ∎  
The minimal number of beats is found by doubling and bisection in fully rational arithmetic, without floating point: for 0 \< ρ \< 1 and ū \> 1, doubling finds a satisfying point in finitely many steps, the criterion is monotone in n, and bisection returns the first satisfying point. The path takes ū for the first n\* − 1 beats and the exact value at the last beat. Verification (Appendix B.4, original model with the cap): for ū = 5, 2, 3/2, 11/10, n\* is 1, 4, 5, 11 respectively; at the exact critical value ū = 3125/2101 it is 5, 10⁻¹⁵ below it 6, and 10⁻¹⁵ above it 5; for ū = 1 + 10⁻²⁰ it is 207, and for ū = 10⁴⁰⁰ it is 1. In each case it is checked that n\* satisfies the criterion, that n\* − 1 does not, and that the last-beat input lies in \[0, ū\]. The entry u₀ = 1/(λ − β) declared by the original χ₀ is the one-beat path with ū = 5.  
Proposition 2 (Instance A). Following the original model of 7.5 and Appendix A.7 of the Adjudication Form: position w, ε = 1/100; fwd is a pure read inside B, acting on w, with coefficient 0 and bias 0, run at every beat; opt runs only under the training input a, with Δw = (2 − w)/4; init is an entry initialization pulse +1. Regime of legitimate histories 𝓗\_A (declared in this paper): init may occur only at beat 0.  
　(1) The originally declared history (init, a, a, a) (W being beats 1–3) reproduces the upstream trajectory 0, 1, 5/4, 23/16, 101/64; for χ\_ext, Fld = 1 and in-boundary self-feedback type = 0; for χ\_in, Fld = 1 and in-boundary self-feedback type = 1.  
　(2) With W the last 1 beat: the shortest history for Fld of χ\_ext has length 2, e.g. (init, a) and (a, a), the latter reaching it because opt is outside the boundary and its effective component enters Mark; for χ\_in the shortest history for both Fld and the in-boundary self-feedback type is (init, a), and (a, a) does not reach them (Lemma 2).  
　(3) For χ\_ext the in-boundary self-feedback type is 0 on every permitted path.  
　(4) For χ\_frz (only rest permitted within W), Fld = 0 on every permitted path.  
Proof. (3) The only process inside B, fwd, always has component 0, so Act\_F is always 0. (4) Within W only fwd runs, so HDyn\_F = 0 for every T. Neither depends on the length of the formative history. (1)(2): see Appendix B.4. The appendix also runs a long-history regression: for χ\_ext, the history init^12·rest is not in 𝓗\_A; even without the restriction on legitimate histories, its Fld under the original model is also 0, which shows that (3)(4) do not depend on that restriction. ∎  
Proposition 3 (entry stage of the representative examples of tendency types). The zero state is not in the state domain X of *The Grading Form of Tendency Types*; it belongs to a separately declared entry state space. The entry beat applies P\_w(0) = η: when η ∈ (0, ∞)ⁿ, P\_w(0) ∈ X, and thereafter the rest flow stays in X (domain lemma (i) of that paper); when η has a zero component, this entry beat does not enter X and this proposition does not apply. The subsequent motion of a zero component requires in addition a regime of boundary transition or solution selection: for α \< 1 the boundary lacks local Lipschitz uniqueness. Example: α = 1/2, I = λ = 1; from (1, 0) there is both a solution with x₂ ≡ 0 and a solution with x₂(t) = t²/4 + o(t²) (in general, for 0 \< α \< 1 and boundary initial value x₁(0) \> 0, the leading term of the latter solution is ((1 − α)(I/x₁(0))^α t)^{1/(1−α)}: setting p = 1/(1 − α) and x₂ = z^p gives z′ = (1 − α)\[(I/(x₁ + z^p))^α − λz\], whose value at z = 0 is positive). The subsequent motion of a zero component is undetermined (U6). The formation length is 1 beat; the qualification verdict is given by the relation-layer mechanism witness of *The Grading Form of Tendency Types*.  
The three quantities kept apart. The actual formation length, the certification-experiment length, and whether the two are serial are stated separately and are not added in advance.  
　χ₀ and Instance A: actual formation takes 1 beat, plus a window of w beats; certification in model mode is evaluation of the declared model; certification under Y₂ (algorithmic level) of the Adjudication Form is a one-beat intervention on each window state, which can be carried out afterwards on a replica and need not be serial with formation.  
　Representative examples of tendency types: the Tr^rest witness pair ((w), (rest)) runs 1 + q beats from s₀; it is a counterfactual comparison and belongs to certification, while the actual formative history has only 1 entry beat. The two are similar in form but belong respectively to the actual path and to the counterfactual test.  
Whether the segments must be serial is judged by the specific protocol; no uniform lower bound has been established.

7\. Extension of the Permitted Set  
Proposition 4 (declaration rules for extending the permitted set).  
　(1) For a fixed model and a common target space, Reach(Π₀) ⊆ Reach(Π₁) ⊆ Reach(Π₂) ⊆ Reach(Π₃).  
　(2) Added operations do not guarantee added reachable states. Proof. (1) The permitted sets are monotone, so a Πᵢ path is also a Πᵢ₊₁ path. (2) Complete enumeration on the finite models. ∎

8\. Controlled Ordering  
Restricted family: the locally exchangeable family of *The Grading Form of Tendency Types* with β = 1, n = 2, ẋᵢ = (I·sᵢ)^α − λxᵢ; entry pulses are applied only to the lower-ranked position x₂; one beat is a pulse followed by a rest flow of duration Δ. Write M₁ = max(x₁(0), I^α/λ) and ρ₀ = x₂/x₁ \< 1. The target is the strict reversal x₂ \> x₁. T4 and T5 constrain only the rest-flow segments; for controlled paths containing pulse jumps, the jump segments are treated separately. Each conclusion is a sufficient bound or an obstruction, not an exact critical value or an optimal control.  
Theorem 4 (ordering reachability and locking obstructions in the restricted family).  
　(a) Per-beat amplitude bound, α ≤ 1: for any η \> 0 the strict reversal is reachable, in at most ⌊(1 − ρ₀)M₁/η⌋ + 1 beats.  
　(b) Per-beat amplitude bound, α \> 1: take A, b satisfying (L1) I^α b^{α−1}/A^α ≤ λ/2, (L2) A ≤ (I^α/λ)(A/(A + b))^α, b \< A, and let η ≤ b(1 − e^{−λΔ/2}). Then V = {x₁ ≥ A, x₂ ≤ b·e^{−λΔ/2}} is invariant under the beat map, and no reversal is possible from V. For A = I^α/(2λ), every condition is met by taking b small enough.  
　(c) General sufficient condition: if η \> M(1 − e^{−λΔ}), M = max(x₁(0), I^α/λ), then reversal is reachable from any initial state in X.  
　(d) Cumulative budget bound, α \< 1: for any B \> 0 reversal is reachable.  
　(e) Cumulative budget bound, α = 1: if B \< (1 − ρ₀)s₁(0)S\_min/(1 + (1 − ρ₀)s₁(0)), reversal is unreachable, where S\_min = min(S₀, I/λ).  
　(f) Cumulative budget bound, α \> 1: write r for the remaining budget; the set {x₁ ≥ A, x₂ + r ≤ b} (with A, b satisfying (L1)(L2) and b \< A) is invariant under both rest and pulses, and no reversal is possible from it.  
Proof.  
(a) Each pulse increases ρ = x₂/x₁ by η/x₁ ≥ η/M₁: a pulse does not change x₁, and under the rest flow x₁ ≤ M₁ (domain lemma (i)). For ρ \< 1 a flow segment does not decrease ρ: the share-difference equation ṡ₁ = s₁s₂I^α(s₁^{α−1} − s₂^{α−1})/S shows that for α = 1 the shares are constant and for α \< 1, s₁ decreases. After n pulses ρ ≥ ρ₀ + nη/M₁, which is strictly greater than 1 for n = ⌊(1 − ρ₀)M₁/η⌋ + 1. For α \< 1 the flow does not cross the tie line (by symmetry and uniqueness), so the reversal occurs in a jump segment, consistently with T4; once the tie has been crossed, uniqueness of the flow in the positive domain preserves the strict ordering.  
(b) (L2) gives ẋ₁ ≥ 0 at x₁ = A, so {x₁ ≥ A} is forward invariant. With S ≥ x₁ ≥ A and x₂ ≤ b, ẋ₂ ≤ x₂(I^α x₂^{α−1}/A^α − λ) ≤ −(λ/2)x₂, so during a rest segment x₂ decreases and its final value does not exceed its entering value times e^{−λΔ/2}; after a pulse, x₂ ≤ b·e^{−λΔ/2} + η ≤ b. Throughout, x₂ ≤ b \< A ≤ x₁.  
(c) Let y\_k be x₂ just after the k-th pulse has been applied. During rest segments the write is nonnegative, so x₂ decays at most by the factor e^{−λΔ}; hence y\_{k+1} ≥ e^{−λΔ}y\_k + η and y\_k ≥ η(1 − e^{−kλΔ})/(1 − e^{−λΔ}), whose limit is η/(1 − e^{−λΔ}) \> M ≥ x₁. Hence reversal occurs at beat k at the latest, where k is the least positive integer with η(1 − e^{−kλΔ})/(1 − e^{−λΔ}) \> M, i.e. k \> −ln(1 − M(1 − e^{−λΔ})/η)/(λΔ). Reversal is checked after the pulse.  
(d) Under rest, s₁ is monotone; the state has positive lower and upper bounds, and compactness rules out limits other than the tie, so s₁ → 1/2 and ρ → 1. Once 1 − ρ \< B/M₁, apply a single pulse of amplitude B: ρ increases by B/x₁ ≥ B/M₁, and the order is reversed. The number of waiting beats depends on the rate at which s₁ tends to 1/2; a bound on it remains open (Section 15, U1).  
(e) For α = 1 the flow does not change the shares and Ṡ = I − λS; pulses only increase S, so S ≥ S\_min. A pulse multiplies s₁ by S/(S + η) ≥ 1 − η/S\_min, so s₁ ≥ s₁(0)(1 − B/S\_min) and x₁ ≥ s₁(0)(S\_min − B). The flow does not change ρ, and the k-th pulse increases ρ by ηₖ/x₁ ≤ ηₖ/(s₁(0)(S\_min − B)), so throughout ρ ≤ ρ₀ + B/(s₁(0)(S\_min − B)). The given bound on B is equivalent to B \< (1 − ρ₀)s₁(0)(S\_min − B), which makes the right-hand side less than 1; so ρ stays below 1 throughout, and reversal is impossible.  
(f) Rest decreases x₂ and leaves r unchanged; a pulse of amplitude η increases x₂ by η and decreases r by η. Hence x₂ + r ≤ b is preserved, so x₂ ≤ b, the estimates from (L1)(L2) hold, and x₁ ≥ A \> b ≥ x₂. This proof covers every application policy. ∎  
Numerical comparison (Appendix B.6, I = λ = 1, Δ = 1/2): (a) the reversal beat counts of all 12 cases lie within the bound; (b) for 40 initial states in V, 60 beats each, V is preserved; (c)–(f) all agree. The numerics serve only as a comparison.  
This theorem shows that the flat type (α = 1) and the falling type (α \< 1) are alike in being reachable with arbitrarily small amplitudes under a per-beat amplitude bound, but differ under a cumulative budget; the rising type (α \> 1) has obstructions under both kinds of budget. The tendency type does not by itself determine ordering reachability: the budget type, the position acted on, the beat length and the current state all enter the conclusion. The conclusions are limited to the restricted family of this section; nothing is proved for general Φ or the two-tube slime-mould model. The qualitative content of rising-type locking is already present in the increasing-returns literature (Arthur 1989); the content of this theorem is the explicit invariant sets and budget bounds under the model and operation regimes of this section.

10\. Trace-Erasure Bounds  
Lemma 3 (finite-time bounds on trace erasure).  
　(1) Continuous time, λ \> 0, write w ≥ 0: x(t) ≥ x(0)e^{−λt}, so a positive trace does not return to zero in finite time.  
　(2) w ≡ 0, ε \> 0, x₀ \> ε: t\* = ln(x₀/ε)/λ. The number of beats for the non-strict target x ≤ ε is ⌈t*/Δ⌉; for the strict target x \< ε it is ⌊t*/Δ⌋ + 1, one beat more than for the non-strict target when t\*/Δ is an integer (with per-beat factor 1/2, x₀ = 1 and ε = 1/8: 3 beats and 4 beats respectively). Remark (outside the antecedents): for x₀ ≤ ε the non-strict target takes 0 beats; for x₀ = ε and w ≡ 0 the strict target takes exactly one beat.  
　(3) Common antecedents λ \> 0, Δ \> 0, ε \> 0, 0 ≤ w ≤ w̄; by initial state there are three mutually exclusive branches:  
　　Already subthreshold — for x₀ ≤ ε, the shortest time and number of beats for the non-strict target are 0; this sentence does not assert that x stays subthreshold afterwards.  
　　Guaranteed reachability — for x₀ \> ε and w̄/λ \< ε, t\* = ln((x₀ − w̄/λ)/(ε − w̄/λ))/λ \> 0 (numerator and denominator both positive, the numerator larger than the denominator); for every such w, x(t) ≤ ε for t ≥ t*, and the number of beats can be taken as ⌈t*/Δ⌉.  
　　A bad write exists — for x₀ \> ε and w̄/λ ≥ ε, take w ≡ w̄: for x₀ \> w̄/λ, x(t) \> w̄/λ ≥ ε; for ε \< x₀ ≤ w̄/λ, x(t) ≥ x₀ \> ε; in both cases x ≤ ε is not reachable in finite time, and finite arrival cannot be guaranteed.  
　(4) F-layer linear shallowing c = −κs (effective if and only if κs \> ε): under ε \> 0, 0 \< κ \< 1, s₀ \> ε/κ, s stalls in ((1 − κ)ε/κ, ε/κ\]; for 0 \< κ ≤ 1/2 the stall value is greater than ε, and this shallowing alone cannot erase the Trace-Response below ε. Degenerate cases: for ε = 0, 0 \< κ \< 1, s₀ \> 0 there is no finite stall and s\_n = (1 − κ)ⁿs₀; for κ = 1, s₀ \> ε goes to 0 in one step and s₀ ≤ ε keeps its value; for κ = 0 there is no shallowing and the interval formula does not apply.  
　(5) Fixed-amount shallowing truncated at zero, max{0, d − λ\_d} (used by Canonical F\*; not the proportional shallowing of the F layer): with no write it reaches 0 within ⌈d/λ\_d⌉ beats.  
Proof. (1) Comparison principle. (2)(3) From the explicit solution of ẋ = w − λx and the comparison principle; the rounding for the strict target is split according to whether t\*/Δ is an integer. (4) Before the last effective step s \> ε/κ, and afterwards s' = (1 − κ)s \> (1 − κ)ε/κ; for κ ≤ 1/2, (1 − κ)/κ ≥ 1. (5) Direct computation. ∎  
This lemma serves only as an interface to the Stability Form and bears no guarantee of return. Numerical examples are in Appendix B.6.

11\. Stochastic Branch (Declared; No Conclusion Issued)  
The decidability of qualification targets in stochastic families remains open; the limits of external methods are as follows:  
　Open-loop input words: the strict-threshold emptiness problem for probabilistic automata is undecidable (Paz 1971; Rote, Probabilistic Finite Automaton Emptiness is Undecidable, 2024).  
　Policies based only on the observation history: the related problems of infinite-horizon planning and partial observability are undecidable (Madani, Hanks, Condon, AAAI 1999, 541–548).  
　Full state feedback: the maximal reachability probability of a finite Markov decision process can be computed by linear programming and is attained by a memoryless deterministic policy (Kwiatkowska, Parker, Automated Verification and Strategy Synthesis for Probabilistic Systems, 2013, 3.1); this holds for the fully observable augmented process, and once projected back to the original physical states the policy may need memory.  
　Finite horizon: open-loop words are enumerated word by word, at cost \|U\|^H times the cost of probability propagation; state feedback is handled by dynamic programming over states that include the remaining horizon; observation policies are computed over policy trees.  
These external results can be applied to the qualification targets here only after the qualification target has been embedded into the corresponding problem with the alphabet, information, termination and probability quantifiers preserved; this reduction has not yet been given (U4). The deterministic Lemma 1 and Corollary 1 do not automatically yield a finite sufficient record representation for stochastic families. The continuation of Canonical F\* is softmax-stochastic; its qualification must be evaluated branch by branch in the R layer, and its probabilistic conclusions remain open.

13\. Final Statement  
Given that the reachability working context 𝒞\_reach is fixed, the permitted sets are declared by level, and the lineage is preserved:  
　Sedimentation-Field qualification targets are not functions of raw state; in the alphabet-gated F model class they are determined by the window's starting state, the formation and mark records, and the in-window input.  
　When the legitimate histories are all finite words, the initial record is empty and the physically reachable set is finite, qualification reachability is decidable, and shortest paths do not exceed (2\|I\| + 1)N − 1 + w; in deterministic models, counterfactual-level targets with a single examined position have a node bound of N + N·\|I′\| when the clamped closure is finite.  
　With an empty initial record, a qualification path must contain an effective out-of-boundary change; χ₀ reaches the qualification target in two beats; under a separately declared input upper bound ū, its net-zero window is reachable in finite time if and only if ū \> 1, and the minimal number of beats is the least n satisfying ū(1 − ρⁿ) ≥ 1; the formation paths of Instance A and its two universal unreachability results have been given explicitly.  
　Whether experimental interventions outside the engineering permitted sets enlarge the reachable set must be declared case by case, and is not read as engineering reachability.  
　In the restricted family of local families, ordering reachability is not determined by the tendency direction alone; the budget type, the position acted on, the beat length and the current state all enter the conclusion.  
　A qualification already reached may be unprovable within the declared observation sets.

~~~python
from fractions import Fraction as Fr
from itertools import combinations, product
from collections import deque
ONE, ZERO, BOT = 1, 0, None

def k_and(*xs):
    if any(x == 0 for x in xs):
        return 0
    if any(x is None for x in xs):
        return None
    return 1

def k_or(*xs):
    if any(x == 1 for x in xs):
        return 1
    if any(x is None for x in xs):
        return None
    return 0

class Proc:
    def __init__(self, pid, tgt, car, law, R=(), k=0, b=0, cert_read=1, cert_path=1):
        self.pid, self.tgt, self.car, self.law = pid, tgt, car, law
        self.R, self.k, self.b = tuple(R), Fr(k), Fr(b)
        self.cert_read, self.cert_path = cert_read, cert_path
    def value(self, s):
        if self.law == 'const':
            return self.b
        if self.law == 'lin':
            return self.b + self.k * sum(s[j] for j in self.R)
        j1, j2 = self.R
        return self.b + self.k * s[j1] * s[j2]
    def supp_act(self, s):
        if self.law == 'const' or self.k == 0:
            return set()
        if self.law == 'lin':
            return set(self.R)
        j1, j2 = self.R
        out = set()
        if s[j2] != 0:
            out.add(j1)
        if s[j1] != 0:
            out.add(j2)
        return out
    def supp_cond(self, s, eps):
        sa = self.supp_act(s)
        if self.law == 'lin' and abs(self.value(s)) <= eps:
            sa |= set(self.R)
        return sa

        return self.I.index(i)
    def step(self, s, u):
        """One beat (4.2 and 5.1 of the Mathematical Form): returns (post-state, set of newly formed positions, set of newly marked positions, process event table); returns None when the step leaves the domain."""
        eps = self.eps
        pulses, procs = self.letters[u]
        d = {i: Fr(0) for i in self.I}
        sd = dict(zip(self.I, s))
        formed, marked, events = set(), set(), []
        for (tgt, a, ext) in pulses:
            a = Fr(a)
            if a > eps:                      # effective pulse: always counted in Form (D16; as in upstream field_final.py lines 123–126), whatever the pre-beat depth
                formed.add(tgt)
                if ext == 'out':
                    marked.add(tgt)
                d[tgt] += a
        for p in procs:
            c = p.value(sd)
            act = 1 if abs(c) > eps else 0
            events.append((p, c, act))
            if act:
                if c > eps and sd[p.tgt] <= eps:   # an effective positive component makes an empty position a trace-retaining element (D16; upstream line 162)
                    formed.add(p.tgt)
                if p.car == 'out':
                    marked.add(p.tgt)        # an effective change by a mechanism with an out-of-boundary carrier enters Mark
                d[p.tgt] += c
        s2 = tuple(sd[i] + d[i] for i in self.I)
        if any(x < 0 for x in s2):
            return None
        return s2, formed, marked, events

def window_eval(M, s_start, F_rec, M_rec, word):
    """Window reading: entry records F_rec, M_rec (position sets), W = word. Returns a dict with Q for every nonempty T, Fld and the in-boundary self-feedback type."""
    eps = M.eps
    s = s_start
    Form = set(F_rec)           # formation records “earlier than t” (the entry-beat records precede every beat in W)
    Mark = set(M_rec)
    ev_log = []                 # (full avail_cond, full avail_act, p, act); the part relevant to each T is extracted afterwards
    for u in word:
        r = M.step(s, u)
        if r is None:
            return None
        s2, formed, marked, events = r
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev_log.append((ac, aa, p, act))
        Form |= formed
        Mark |= marked
        s = s2
    end = dict(zip(M.I, s))
    out = {}
    fld, selfref = 0, 0
    for n in range(1, len(M.I) + 1):
        for T in combinations(M.I, n):
            T = set(T)
            src = 1 if any(i in Mark for i in T) else 0
            ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
            trace = k_and(src, ret, 1, 1)   # Ident and HistEv declared as 1
            part = k_or(*[k_and(1 if (ac & T) else 0, p.cert_read)
                          for (ac, aa, p, act) in ev_log if p.car == 'B']) if ev_log else 0
            hd_terms, sr_terms = [], []
            for (ac, aa, p, act) in ev_log:
                hc = k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0)
                hd_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
                if p.car == 'B':
                    sr_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
            hdyn = k_or(*hd_terms) if hd_terms else 0
            q = k_and(trace, part, hdyn)
            out[frozenset(T)] = q
            fld = k_or(fld, q)
            sr = k_and(q, k_or(*sr_terms) if sr_terms else 0)
            selfref = k_or(selfref, sr)
    return {'Q': out, 'Fld': fld, 'self': selfref, 'end': s}

def run_prefix(M, h):
    """Formative history: apply h from s0 and return (final state, Form position set, Mark position set)."""
    s, F, Mk = M.s0, set(), set()
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F |= fo
        Mk |= ma
    return s, frozenset(F), frozenset(Mk)

def fld_of_history(M, h, w):
    """Window-reading qualification of the input history h (W = last w beats, w ≥ 1)."""
    if w < 1:
        raise ValueError('w ≥ 1')
    if len(h) < w:
        return None
    pre = run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    return window_eval(M, s, F, Mk, h[len(h) - w:])

def physical_reach(M, letters=None):
    letters = letters or list(M.letters)
    seen, dq = {M.s0}, deque([M.s0])
    while dq:
        s = dq.popleft()
        for u in letters:
            r = M.step(s, u)
            if r and r[0] not in seen:
                seen.add(r[0])
                dq.append(r[0])
    return seen

def augmented_search(M, w, target='Fld', letters=None):
    """Augmented search: nodes (s, Form, Mark); for each node, enumerate the window words of length w. Returns the shortest satisfying history and node statistics."""
    letters = letters or list(M.letters)
    start = (M.s0, frozenset(), frozenset())
    dist, par = {start: 0}, {start: None}
    dq = deque([start])
    while dq:
        node = dq.popleft()
        s, F, Mk = node
        for u in letters:
            r = M.step(s, u)
            if r is None:
                continue
            s2, fo, ma, _ = r
            nxt = (s2, F | fo, Mk | ma)
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                par[nxt] = (node, u)
                dq.append(nxt)
    best = None
    for node in sorted(dist, key=lambda n: dist[n]):
        if best is not None and dist[node] + w >= best[0]:
            break
        s, F, Mk = node
        for word in product(letters, repeat=w):
            e = window_eval(M, s, F, Mk, word)
            if e is not None and e[target] == 1:
                path, n = [], node
                while par[n] is not None:
                    n, u = par[n]
                    path.append(u)
                h = tuple(reversed(path)) + word
                if best is None or len(h) < best[0]:
                    best = (len(h), h)
                break
    N = len(physical_reach(M, letters))
    return {'best': best, 'nodes': len(dist), 'N': N,
            'max_prefix_dist': max(dist.values()), 'bound_prefix': (2 * len(M.I) + 1) * N - 1}

def brute_min(M, w, Lmax, target='Fld', letters=None):
    letters = letters or list(M.letters)
    for L in range(w, Lmax + 1):
        for h in product(letters, repeat=L):
            e = fld_of_history(M, h, w)
            if e is not None and e[target] == 1:
                return L, h
    return None
~~~

~~~python
Formal simulation, not certification of material causation.

def exact(v):
    """Each input number is taken as the exact rational given by its decimal representation; all F-layer arithmetic is carried out exactly over the rationals."""
    return Fraction(repr(v)) if isinstance(v, float) else Fraction(v)
def tri_and(*xs):
    if False in xs:return False
    if None in xs:return None
    return True
def tri_or(xs):
    xs=list(xs)
    if True in xs:return True
    if None in xs:return None
    return False
@dataclass(frozen=True)
class Pulse:
    name:str; step:int; target:str; amount:float; external:bool=True; certified:Tri=True
@dataclass(frozen=True)
class Process:
    name:str; step:int; target:str; carrier_inside:bool; law:str
    reads:tuple[str,...]=(); coefficient:float=0.; bias:float=0.
    certified_effect:Tri=True; certified_read:Tri=True
    # rule: constant, linear (sum of read sites), bilinear (two sites)
@dataclass(frozen=True)
class Link:

def _num(v, nonneg=False):
    # Legal numbers: integers, rationals (Fraction), or finite decimal floats
    if isinstance(v, bool) or not isinstance(v, (int, float, Fraction)): return False
    if isinstance(v, float) and not isfinite(v): return False
    return (not nonneg) or v >= 0
def check(x):
    if not x.sites or len(set(x.sites))!=len(x.sites):raise ValueError('sites')
    if x.declared_T is None or not x.declared_T or len(set(x.declared_T))!=len(x.declared_T) or any(s not in x.sites for s in x.declared_T):raise ValueError('declared T')
    if not x.window or tuple(range(x.window[0],x.window[-1]+1))!=x.window:raise ValueError('window')
    if len(x.initial)!=len(x.sites) or not all(_num(z,True) for z in x.initial):raise ValueError('initial')
    if not _num(x.epsilon,True):raise ValueError('epsilon')
    if x.identity not in (True,False,None) or x.trace_history not in (True,False,None):raise ValueError('identity')
    names=set()
    for e in (*x.pulses,*x.processes):
        if not e.name or e.name in names:raise ValueError('event id')
        names.add(e.name)
        if e.step<x.window[0]-1 or e.step>x.window[-1]:raise ValueError('event time')
        if e.target not in x.sites:raise ValueError('target')
        if isinstance(e,Pulse):
            if not _num(e.amount,True):raise ValueError('pulse amount')
            # In F, certified is the certification of “whether the pulse actually occurs”: 1 = occurs, 0 = does not occur; ⊥ is outside the single-trajectory domain of F and must be enumerated by branch in R
            if e.certified is None:raise ValueError('F_UNDECIDED_PULSE: enumerate occurrence branches in R')
            if e.certified not in (True,False):raise ValueError('pulse evidence')
        else:
            if e.law not in ('constant','linear','bilinear'):raise ValueError('law')
            if any(s not in x.sites for s in e.reads):raise ValueError('read sites')
            if e.law=='bilinear' and len(e.reads)!=2:raise ValueError('bilinear arity')
            if e.law=='linear' and not e.reads:raise ValueError('linear reads')
            if e.law=='constant' and e.reads:raise ValueError('constant reads')
            if not _num(e.coefficient) or not _num(e.bias):raise ValueError('params')
            # D20: the action certification must be decided; a mechanism with undetermined action is outside the F domain (even when its component is zero)
            if e.certified_effect not in (True,False):raise ValueError('undecided mechanism effect')
            if e.certified_read not in (True,False,None):raise ValueError('evidence')
    # All trace nodes are snapshots at integer t; process nodes at integer t+0.5.
    # Strict temporal order prevents fabricated same-step read-after-write.
    times={f'state:{s}:{t}':float(t) for s in x.sites for t in range(x.window[0],x.window[-1]+2)}
    times.update({e.name:float(e.step)+0.5 for e in (*x.pulses,*x.processes)})
    for link in x.links:
        if link.source not in times or link.target not in times:raise ValueError('link endpoint')
        if times[link.source]>=times[link.target]:raise ValueError('noncausal link')
        if link.certified not in (True,False,None):raise ValueError('link evidence')
    return times
def path_status(links,starts,target,closed=True):
    adjacency=defaultdict(list)
    for l in links:adjacency[l.source].append(l)
    def reachable(allow):
        seen=set(starts);queue=list(starts)
        while queue:
            u=queue.pop()
            for l in adjacency[u]:
                if allow(l.certified) and l.target not in seen:
                    seen.add(l.target);queue.append(l.target)
        return target in seen
    if reachable(lambda w:w is True):return True
    if reachable(lambda w:w is not False):return None
    return False if closed else None
def run(x):
    check(x)
    eps=exact(x.epsilon)
    state={s:exact(v) for s,v in zip(x.sites,x.initial)}
    # For each site, certified external history must be identified as event, not inferred from nonzero state.
    formation=defaultdict(list); history_snapshots=defaultdict(list)
    signal_marks=defaultdict(list)  # out-of-boundary cause: changes left at this position by certified, effective out-of-boundary action components (pulses, or processes whose carrier is outside the boundary)
    part=[];hdyn=[];reports=[]
    for t in range(x.window[0]-1,x.window[-1]+1):
        before=dict(state); contributions=defaultdict(list);events=[]
        # Pulse first as an event, but processes read the prior snapshot, not pulse-modified value.
        for p in x.pulses:
            if p.step!=t:continue
            # Count only pulses certified as occurring and effective; a pulse confirmed not to occur contributes nothing and registers no formation or cause
            a=exact(p.amount)
            if p.certified is True and a>eps:
                contributions[p.target].append((p.name,a))
                formation[p.target].append((p.name,t,p.external))
                if p.external:signal_marks[p.target].append((p.name,t))
        for m in x.processes:
            if m.step!=t:continue
            k=exact(m.coefficient); b=exact(m.bias)
            if m.law=='constant':value=b
            elif m.law=='linear':value=b+k*sum(before[s] for s in m.reads)
            else:value=b+k*before[m.reads[0]]*before[m.reads[1]]
            is_action=tri_and(abs(value)>eps,m.certified_effect)
            # Declared reads do not establish a genuine dependence: compute the law's support.
            support=()
            # Support for the organizational condition: the numerical law depends on the read positions, or the process is a pure read (component not an effective change, |c| ≤ ε); read certification enters as a separate conjunct, and an undetermined value is not truncated to false in advance
            # Functional support is decided by a mathematically nonzero partial derivative (coefficient and partner reading exactly nonzero), not conflated with the effective-change threshold ε
            if m.law=='linear' and (k!=0 or abs(value)<=eps): support=m.reads
            elif m.law=='bilinear' and k!=0:
                support=tuple(s for i,s in enumerate(m.reads) if before[m.reads[1-i]]!=0)
            # For every element in the declared T, historical formation must precede the read.
            active_T=set(x.declared_T)
            available=[s for s in support if s in active_T and before[s]>eps and any(a[1]<t for a in formation[s])]
            is_cond=tri_and(bool(available),m.certified_read)
            # No automatic path from a read-site to an act. Explicit event links are required.
            old_nodes=[f'state:{s}:{t}' for s in available]
            route=path_status(x.links,old_nodes,m.name,x.closed_graph) if old_nodes else False
            # Action provenance must be supported by a nonzero functional dependence,
            # not merely a certified read that has no effect on the action.
            action_support=()
            if m.law=='linear' and k!=0:action_support=m.reads
            elif m.law=='bilinear' and k!=0:
                action_support=tuple(s for i,s in enumerate(m.reads) if before[m.reads[1-i]]!=0)
            action_available=[s for s in action_support if s in active_T and before[s]>eps and any(a[1]<t for a in formation[s])]
            action_nodes=[f'state:{s}:{t}' for s in action_available]
            action_route=path_status(x.links,action_nodes,m.name,x.closed_graph) if action_nodes else False
            is_hist=tri_and(bool(action_available),m.certified_read,action_route)
            if is_action is True:
                contributions[m.target].append((m.name,value))
                # Formation of a new element: with its carrier inside B it is formation by in-field continuation; with its carrier outside the boundary it is formation by signal
                if value>eps and before[m.target]<=eps:
                    formation[m.target].append((m.name,t,not m.carrier_inside))
                # An effective component of a process whose carrier is outside the boundary is a change left by a signal, whether the element is new or old and whether the component is positive or negative
                if not m.carrier_inside:
                    signal_marks[m.target].append((m.name,t))
            elif is_action is None: # defensive check: an undetermined action certification is already excluded from the domain by check()
                raise ValueError('unresolved effect cannot determine numeric trajectory')
            if t in x.window:
                if m.carrier_inside:part.append(is_cond)
                hdyn.append(tri_and(m.target in active_T,is_action,is_hist))
            events.append({'id':m.name,'delta':value,'act':is_action,'cond':is_cond,'histcond':is_hist,'route':route})
        for s in x.sites:
            new=before[s]+sum(v for _,v in contributions[s])
            # Depth must not be negative: an exact updated value below zero leaves the domain; no truncation to zero, no tolerance
            if new < 0:raise ValueError('negative trace depth')
            state[s]=new
            if state[s]>eps and formation[s]:history_snapshots[s].append(t+1)
        if t in x.window:reports.append({'step':t,'before':before,'after':dict(state),'contributions':dict(contributions),'events':events})
    ts=x.declared_T
    eligible=all(state[s]>eps and formation[s] for s in ts)
    sources={origin for site in ts for origin,t in signal_marks[site]}
    trace=tri_and(bool(sources),eligible,x.identity,x.trace_history)
    pw=tri_or(part); hw=tri_or(hdyn)
    return {'trace':trace,'part':pw,'hdyn':hw,'Q':tri_and(trace,pw,hw),'reports':reports,'physical_certificate':False}
~~~

~~~python
def nstar_exact(ub):
    """Least n with ū(1 − ρⁿ) ≥ 1 (exact rational doubling plus bisection, no floating point); returns None for ū ≤ 1.
    For 0 < ρ < 1 and ū > 1 the doubling finds a satisfying point in finitely many steps; reached is monotone in n, so the bisection returns the first satisfying point."""
    if ub <= 1:
        return None
    def reached(n):
        return ub * (1 - rho ** n) >= 1
    lo, hi = 0, 1
    while not reached(hi):
        lo, hi = hi, 2 * hi
    while hi - lo > 1:
        mid = (lo + hi) // 2
        if reached(mid):
            hi = mid
        else:
            lo = mid
    return hi

    assert m < dstar
    return un
~~~

~~~python
"""Proposition 4 (R-layer transition/operation model with an upper limit, truncation at zero and an absorbing state; not in the linear F subclass): reachable sets of the ladder of permitted sets Π₀ ⊆ Π₁ ⊆ Π₂ ⊆ Π₃: weak inclusion (in general), one model that witnesses all three strict inclusions at once, and two equality witnesses;
Corollary 2: a witness pair that is reachable yet unprovable within Y₁ (and within the MOD and LOC readings of Y₂); distinguishing the pair requires a carrier/source declaration."""
from collections import deque
from fractions import Fraction as Fr
from reach_core import GF, Proc, fld_of_history

def reach(s0, ops):
    seen, dq = {s0}, deque([s0])
    while dq:
        s = dq.popleft()
        for f in ops:
            n = f(s)
            if n is not None and n not in seen:
                seen.add(n); dq.append(n)
    return seen

# ---------- M4: state (x, z, y). x is a Trace-Response position (upper limit 2; x = 3 is an absorbing value); z follows x through the process pz; y is a supply position (always 1 while supply is on)
def w(s, ko=False):          # letter w: out-of-boundary pulse +1 on x (when x < 2); the same-beat process pz adds 1 to z (upper limit 2); supply keeps y = 1
    x, z, y = s
    if x >= 2:
        return (x, z, 1) if x != 3 else s
    return (x + 1, z if ko else min(2, z + 1), 1)
def rest(s, ko=False):       # rest: the shallowing process pd lowers x and z by 1 each (not below 0); x = 3 is unchanged
    x, z, y = s
    if x == 3:
        return s
    return (max(0, x - 1), z if ko else max(0, z - 1), 1)
def cut(s):                  # supply cut-off: y ← 0, everything else unchanged (the declared cut-off transition law)
    x, z, y = s
    return (x, z, 0)
def loc3(s):                 # LOC: sets only x; declared setting domain {3}
    x, z, y = s
    return (3, z, y)
def ko_w(s):                 # MOD: knocks out process pz within a beat of letter w
    return w(s, ko=True)
def ko_rest(s):              # MOD: knocks out the shallowing component on z within a rest beat
    return rest(s, ko=True)
S0 = (0, 0, 1)
P0 = [w, rest]; P1 = P0 + [cut]; P2 = P1 + [loc3]; P3 = P2 + [ko_w, ko_rest]
R = [reach(S0, P) for P in (P0, P1, P2, P3)]
print('M4: Reach sizes Π₀..Π₃ =', [len(r) for r in R])
for i in range(3):
    assert R[i] <= R[i + 1] and R[i] != R[i + 1]
    new = sorted(R[i + 1] - R[i])[:3]
    print(f'  Π{i} ⊊ Π{i + 1}: new cases {new}')
assert all(s[1] == s[0] for s in R[2] if s[0] != 3)            # under Π₂, z = x whenever x ≠ 3
assert any(s[0] != 3 and s[1] != s[0] for s in R[3])           # MOD makes z ≠ x
print('  one model witnesses all three strict inclusions at once: supply cut-off gives y = 0; LOC gives x = 3, unreachable by the dynamics; MOD gives x ≤ 2 with z ≠ x')
# Equality witness M4′: no supply position (the declared cut-off is the identity) and no process that can be knocked out → Reach(Π₀) = Reach(Π₁), Reach(Π₂) = Reach(Π₃)
def w2(s): return (min(2, s[0] + 1),)
def rest2(s): return (max(0, s[0] - 1),)
def cut2(s): return s
def loc2(s): return (2,)        # setting domain {2}, already reachable
def ko2(s): return w2(s)        # w2 has only a pulse and no process: knocking out processes has no effect
R2 = [reach((0,), P) for P in ([w2, rest2], [w2, rest2, cut2], [w2, rest2, cut2, loc2], [w2, rest2, cut2, loc2, ko2])]
print('M4′: Reach sizes Π₀..Π₃ =', [len(r) for r in R2], '(supply cut-off is equivalent to rest, the LOC setting value is already reachable, MOD has no process to knock out: equality at all three steps)')
assert R2[0] == R2[1] == R2[2] == R2[3]
# ---------- Corollary 2: the witness pair (M_A, M_B) shares one interface: the same position set, the same alphabet, the same pulse labels and amplitudes,
# the same process labels, laws, read positions and parameters; the only difference is that the pulse pa of letter a is out-of-boundary in M_A (ext = out) and in-field in M_B (ext = in).
def pair(ext):
    opt = Proc('opt', 'x', 'B', 'lin', R=('x',), k=Fr(-1, 2), b=1)
    rd = Proc('rd', 'o', 'B', 'lin', R=('x',), k=0, b=0)
    return GF(I=('x', 'o'), eps=0, letters={'rest': ([], []), 'a': ([('x', 1, ext)], []), 'c': ([], [opt, rd])}, s0=(0, 0))
MA, MB = pair('out'), pair('in')

def ko_step(M, s, u, ko_pulses, ko_procs):
    """Same-label subset knockout: remove from this beat the pulses whose labels are in ko_pulses and the processes whose labels are in ko_procs (the same label subset is applied on both sides)."""
    pulses, procs = M.letters[u]
    pl = [p for k, p in enumerate(pulses) if f'p{k}' not in ko_pulses]
    pr = [p for p in procs if p.pid not in ko_procs]
    tmp = GF(I=M.I, eps=M.eps, letters={'rest': ([], []), u: (pl, pr)}, s0=M.s0)
    r = tmp.step(s, u)
    return None if r is None else r[0]

# any same-label knockout subset K and any LOC setting value, the two models have the same post-state, and the same validity (nonnegative post-state). From the same initial state, every finite experiment

        for Kp in subsets(labels_p):
            for Km in subsets(labels_m):          # includes full-module knockout
                assert ko_step(MA, s, u, set(Kp), set(Km)) == ko_step(MB, s, u, set(Kp), set(Km))
                n_cases += 1
ea, eb = fld_of_history(MA, ('a', 'c'), 1), fld_of_history(MB, ('a', 'c'), 1)
print(f'Corollary 2 (common interface): M_A and M_B differ only in the ext flag of pulse pa; on {len(grid)} states × 3 letters × all same-label knockout subsets (including full knockout), {n_cases} cases in all, the post-states agree item by item'
      f' (the general case is proved by induction); for the same engineering history (a, c): Fld of M_A = {ea["Fld"]}, Fld of M_B = {eb["Fld"]}')
assert ea['Fld'] == 1 and eb['Fld'] == 0
print('  hence within Y₁, Y₁+LOC and Y₁+MOD (same-label subset knockout), this path of M_A has reached the qualification target yet cannot be certified as 1; '
      'this is a corollary of Theorem 6 of the Indistinguishability Form in the reachability setting. Distinguishing the pair requires a source declaration (the signal entry positions of Y_decl); distinguishing this one pair is not a certification of the whole candidate family')
~~~

A.8  order\_erase.py  Numerical comparison for ordering reachability in the restricted family and numerical examples of the erasure bounds (Theorem 4, Lemma 3)

~~~python
"""Theorem 4 (restricted family): local family β = 1, n = 2; entry pulses act only on the lower-ranked position (x₂); one beat = a pulse followed by a rest flow of duration Δ;
checks: (a) for α ≤ 1, order reversal is possible for every per-beat amplitude η > 0, in at most ⌊(1 − ρ₀)M₁/η⌋ + 1 beats; (b) for α > 1 the locking set V is invariant; (c) a general sufficient condition;
(d)(e)(f) the three cases under a cumulative budget. The numerical results are for comparison only; the proofs are in Section 8 of the main text.
Lemma 3: trace-erasure bounds: pure decay in continuous time, bounded write, and stalling of linear shallowing under F-layer resolution truncation."""
import math
from fractions import Fraction as Fr
I, LAM = 1.0, 1.0

def F(x, al):
    S = x[0] + x[1]
    return [(I * x[0] / S) ** al - LAM * x[0], (I * x[1] / S) ** al - LAM * x[1]]

def flow(x, al, T, h=1e-3):
    n = max(1, round(T / h)); h = T / n
    for _ in range(n):
        k1 = F(x, al)
        k2 = F([x[i] + h / 2 * k1[i] for i in range(2)], al)
        k3 = F([x[i] + h / 2 * k2[i] for i in range(2)], al)
        k4 = F([x[i] + h * k3[i] for i in range(2)], al)
        x = [x[i] + h / 6 * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]) for i in range(2)]
    return x

def beats_to_reverse(x, al, eta, D, nmax):
    for n in range(1, nmax + 1):
        x = [x[0], x[1] + eta]
        if x[1] > x[0]:
            return n
        x = flow(x, al, D)
        if x[1] > x[0]:
            return n
    return None

D = 0.5
print('Theorem 4: numerical comparison (local family β = 1, I = λ = 1, Δ = 0.5, pulses only on x₂)')
for al in (0.5, 1.0):
    for x0 in ([1.0, 0.2], [0.9, 0.05], [3.0, 0.5]):
        for eta in (0.05, 0.01):
            M1 = max(x0[0], I ** al / LAM); rho0 = x0[1] / x0[0]
            bound = math.floor((1 - rho0) * M1 / eta) + 1
            n = beats_to_reverse(list(x0), al, eta, D, bound + 1)
            assert n is not None and n <= bound, (al, x0, eta, n, bound)
            print(f'  (a) α = {al}, x₀ = {x0}, η = {eta}: order reversed at beat {n}; bound ⌊(1 − ρ₀)M₁/η⌋ + 1 = {bound}')
al = 1.5
A = I ** al / (2 * LAM)
b = min(A * (2 ** (1 / al) - 1), (LAM * A ** al / (2 * I ** al)) ** (1 / (al - 1))) * 0.999
eta_lock = b * (1 - math.exp(-LAM * D / 2))
assert I ** al * b ** (al - 1) / A ** al <= LAM / 2 + 1e-12 and A <= (I ** al / LAM) * (A / (A + b)) ** al + 1e-12
print(f'  (b) α = 1.5: A = {A:.4f}, b = {b:.4f}, η_lock = b(1 − e^(−λΔ/2)) = {eta_lock:.4f}; '
      f'V = {{x₁ ≥ A, x₂ ≤ b·e^(−λΔ/2)}}')
import random
rng = random.Random(1)
worst = 0
for trial in range(40):
    x = [A + rng.random() * 0.8, rng.random() * b * math.exp(-LAM * D / 2)]
    for n in range(60):
        x = [x[0], x[1] + eta_lock]
        assert x[1] <= b + 1e-9 and x[0] >= A - 1e-9
        x = flow(x, al, D)
        assert x[0] >= A - 1e-6 and x[1] <= b * math.exp(-LAM * D / 2) + 1e-6
        worst = max(worst, x[1] / x[0])
print(f'  (b) 40 initial states in V, 60 beats each: V is preserved, maximum x₂/x₁ {worst:.4f} < 1 (no order reversal)')
for al in (0.5, 1.0, 1.5):
    x0 = [1.2, 0.01]; M = max(x0[0], I ** al / LAM)
    eta = 1.05 * M * (1 - math.exp(-LAM * D))
    n = beats_to_reverse(list(x0), al, eta, D, 400)
    assert n is not None
    print(f'  (c) α = {al}: with η = 1.05·M(1 − e^(−λΔ)) = {eta:.4f}, order reversed at beat {n} (general sufficient condition)')
# (d) α < 1, cumulative budget B: wait until 1 − ρ < B/M₁, then apply a single pulse B
for B in (0.05, 0.01):
    al = 0.5; x = [1.0, 0.2]; M1 = max(x[0], I ** al / LAM); waits = 0
    while 1 - x[1] / x[0] >= B / M1:
        x = flow(x, al, D); waits += 1
    x = [x[0], x[1] + B]
    assert x[1] > x[0]
    print(f'  (d) α = 0.5, cumulative budget B = {B}: after {waits} rest beats, a single pulse B reverses the order')
# (e) α = 1, cumulative-budget threshold: for B < (1 − ρ₀)s₁(0)S_min/(1 + (1 − ρ₀)s₁(0)) the order cannot be reversed (a check of the necessary condition: even the greedy strategy does not reverse the order)

for B in (0.9 * Bth, 0.5 * Bth):

    for k in (1, 2, 5, 10):        # split B evenly into k pulses, applied after various waits
        for wait in (0, 2, 10):

    print(f'  (e) α = 1, B = {B / Bth:.1f}·B_th (B_th = {Bth:.4f}): over the strategies tried, maximum x₂/x₁ {best:.4f} < 1')

    x = flow(x, al, D); ok &= x[1] < x[0]
assert ok
print(f'  (f) α = 1.5, B = b/2: from V_B the budget is spent at once; x₂ < x₁ throughout 80 beats')
print('Lemma 3: trace-erasure bounds')
# continuous time: w ≡ 0; number of beats for x ≤ ε and for x < ε
x0, eps, Dl = 1.0, Fr(1, 8), 0.25
tstar = math.log(x0 / float(eps)) / LAM
n_le = math.ceil(tstar / Dl - 1e-12); n_lt = math.floor(tstar / Dl) + 1
print(f'  w ≡ 0: x₀ = 1, ε = 1/8, λ = 1, Δ = 1/4: t* = ln(x₀/ε)/λ = {tstar:.4f}; x ≤ ε takes {n_le} beats, x < ε takes {n_lt} beats')
# exact beat-wise example: the per-beat decay factor e^(−λΔ) is declared to be 1/2, x₀ = 1, ε = 1/8: x_n = 2^(−n); the required time is exactly a whole number of beats (n = 3)
xs = [Fr(1, 2 ** n) for n in range(6)]
n_le_ex = min(n for n, v in enumerate(xs) if v <= Fr(1, 8)); n_lt_ex = min(n for n, v in enumerate(xs) if v < Fr(1, 8))
assert (n_le_ex, n_lt_ex) == (3, 4)
print(f'  exact beat-wise example (per-beat factor 1/2, x₀ = 1, ε = 1/8): x ≤ ε takes {n_le_ex} beats, x < ε takes {n_lt_ex} beats; when the required time is exactly a whole number of beats, the strict target needs one beat more')
# bounded write: for w̄/λ < ε a time is given; for w̄/λ ≥ ε, w ≡ w̄ witnesses unreachability
for wb in (0.05, 0.125, 0.2):
    if wb / LAM < float(eps):
        t = math.log((x0 - wb / LAM) / (float(eps) - wb / LAM)) / LAM
        print(f'  0 ≤ w ≤ w̄ = {wb}: w̄/λ < ε; x(t) ≤ x₀e^(−λt) + (w̄/λ)(1 − e^(−λt)) is ≤ ε for t ≥ {t:.4f}')
    else:
        xinf = wb / LAM
        print(f'  0 ≤ w ≤ w̄ = {wb}: w̄/λ = {xinf} ≥ ε; with w ≡ w̄, x(t) > w̄/λ ≥ ε (x₀ > w̄/λ), so x ≤ ε is unreachable in finite time')
# F layer: linear shallowing c = −κ·s is effective if and only if κs > ε; the stall value falls in ((1 − κ)ε/κ, ε/κ]
for kap, s0 in ((Fr(1, 2), Fr(10)), (Fr(1, 4), Fr(10)), (Fr(3, 4), Fr(10)), (Fr(1, 10), Fr(1))):
    e = Fr(1, 10); s = s0; n = 0
    while abs(kap * s) > e:
        s = s - kap * s; n += 1
    assert (1 - kap) * e / kap < s <= e / kap or s0 <= e / kap
    print(f'  F layer κ = {kap}, ε = {e}, s₀ = {s0}: after {n} beats, stalls at s = {s} ({float(s):.4f}); '
          f'{"already ≤ ε" if s <= e else "still > ε; this shallowing alone cannot erase below ε"}')

    for _ in range(nmax):
        if not abs(kap * s) > e:
            return seq, True          # stalled (no longer effective)
        s = s - kap * s; seq.append(s)
    return seq, False
~~~
