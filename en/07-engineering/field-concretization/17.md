# The Adjudication Form for Identifying Concretized Fields

1\. Purpose

### 1.1  Use and Central Question

This paper is an Adjudication Form (an auxiliary form of the inversion-discernment group; the chapter on Adjudication Forms in the Canon Chapters of the main book *On Self-Manifestation* v0.7.8). Its use: faced with a concrete host, and starting from its mechanism evidence (molecular mechanisms, electrophysiology, imaging, morphometry, connectomes, population experiments and published models), to adjudicate (1) which changes are Trace-Responses and which are the activity of the moment, activity residues and background structure; (2) what quantity bears the depth of the Trace-Responses, detecting any “pre-selected number”; (3) under the declared setting family and time frame, which bearers make up one and the same organization; (4) whether what identification yields can enter \[S3\], \[S11\] and \[S13\], bridging the places these three papers do not cover with proved supplementary criteria; (5) to report, by the master formula of \[S1\], whether the instance constitutes a Sedimentation-Field, with the optional ledgers reported separately.  
The central question: Chapters 3, 11 and 13 start from declared Structural Positions, state variables, process inventories and observation protocols; this paper deals with how these declarations are grounded in the concrete object—why these changes are chosen as Trace-Responses, why these bearers make up one set, how the existing set takes part in activity and how activity in turn acts back on this set—and tests whether what identification yields can enter the existing criteria.  
Duty determinations follow the upstream verdicts; the conclusions of adjudication contain no material certification. Where no existing experiment is available, the conclusions are limited to mechanisms, conditional conclusions and breachable predictions; predictions are not registered as certification in reality, no candidate is presumed to pass necessarily, and the undetermined is not treated as a negative determination.

2.3  The Research Procedure for Concretized Fields (Seven Steps)  
The research procedure for concretized fields is required content of *The Master Map of the Field Concretization Group Form*: given a concretized field, first find its Trace-Responses, then study how the Trace-Response set transforms. Step 1, find the Trace-Responses (what signal acts on what medium of the field, what change it leaves, what bears the change and how it is retained, and keep the retained change apart from the activity occurring at the time); Step 2, study the single Trace-Response (how it deepens, how it shallows, when it does not change, and what quantity in the host bears its depth); Step 3, study the organization of the set (boundary and subsets); Steps 4 to 6, study tendency, activity and re-action; Step 7, assemble the evidence, conditional derivations and breachable predictions, and then call on existing criteria to adjudicate.  
This paper takes the adjudication side of Step 1, of “what quantity bears the depth” in Step 2, of “the boundary and subsets of the set” in Step 3, and of “pinning down the actual process by which existing Trace-Responses take part in determining action and action further changes the set” in Step 6, together with Step 7. The expression, running and solution of Steps 4 to 6 belong to Chapter 18, *The Mathematical Form of Trace-Response Set Transformation*; the correspondence between the two is given in the interfaces (Section 11).

### 3.3  Sequence of Definitions

Definition 1 (trace-free ground state, reference history and oriented depth) \[Representational choice\]  
The trace-free ground state w⁰\_k of carrier k: the state of that carrier when the medium has no signal history at all (a constant for a static medium; for a drifting medium, the reference trajectory w\_k(h\_ref; t) under the same non-signal driving, where h\_ref is the reference history obtained by replacing the signal segments of the actual history with rest, following the reference history of Hist in \[S3\]). Oriented depth δ\_x := o\_x·(w\_x − w⁰\_x), where o\_x is the declared element orientation (depression type, thickening type, etc.). δ\_x \> ε makes x a Trace-Response candidate in that orientation; δ\_x \< −ε makes it a candidate of the other type, beyond the ground state, listed separately and not counted in the original orientation. Signal-formed positions: the positions at which the carrier difference between the actual and the reference history at window end exceeds ε; they give the identification-side witness for r of \[S1\]. The depth of an element formed by in-field continuation and not through a signal is counted from w⁰.  
Definition 2′ (self-retention and three-way classification; complete and lower bound)  
For carrier k, apply a legitimate write with the other carriers clamped, and let u\_k(t) be the subsequent deviation sequence at rest; the self-retention length τ\_k := one plus the last t with \|u\_k(t)\| \> ε (taken over the entire rest domain; 0 if there is no threshold crossing).  
Observed lower bound: on a finite record u\_k(0), …, u\_k(t\_end), τ\_k^obs := one plus the last t in the record with \|u\_k(t)\| \> ε. Always τ\_k ≥ τ\_k^obs; an end point of the record that does not cross the threshold gives no upper bound, because threshold crossing can be interrupted and then recur (counterexample X11). When threshold crossing is interrupted and recurs, the last threshold crossing and continuous retention are reported separately.  
Complete self-retention: τ\_k = τ\_k^obs requires tail evidence, of one of three kinds: (A) the record already covers all of the remaining rest domain; (B) the end state of the record has entered a forward-invariant subthreshold set—the rest map maps the set into itself, and \|u\| ≤ ε within the set; (C) a proved envelope—\|u\_k(t\_end + s)\| ≤ C·λ^s holds for all s ≥ 0, with 0 ≤ λ \< 1 and C ≤ ε. Without tail evidence only a “lower bound” is recorded, whether or not the end point crosses the threshold.  
Three-way classification: declare τ\_act \< τ\_W. Background—not written under any legitimate history in 𝓗\_R; Trace-Response carrier—can be written and τ\_k ≥ τ\_W, where a lower bound τ\_k^obs ≥ τ\_W already suffices for a positive determination; activity—can be written and τ\_k ≤ τ\_act; activity residue—τ\_act \< τ\_k \< τ\_W. The latter two classes require complete self-retention (an upper bound); when there is only a lower bound and τ\_k^obs \< τ\_W, the verdict is ⊥\_Tail, and neither activity, nor residue, nor non-Trace-Response is issued. Relative to the declared τ\_act and τ\_W the four classes are mutually exclusive and exhaustive; at worst the verdict stops at ⊥\_Tail. The key point is “clamp the other carriers”: an activity reading that varies with the Trace-Responses (Part) is not that reading's own retention (Lemma 17-1′).  
Definition 3′ (bearable depth; relative to the declared probe and write condition)  
Let k be a Trace-Response carrier (its identity may be given by a self-retention lower bound ≥ τ\_W; K1–K3 do not use complete self-retention), Ω\_k the set of reachable carrier values of k (with the other carriers at the trace-free ground state), p a declared probe, j a declared read-out component, and the participation effect e\_{p,j}(w) := \|Φ\_j(w; p) − Φ\_j(w⁰; p)\|. δ: Ω\_k → ℚ≥0 is a bearable depth if and only if:  
　K1 (retention bearing): δ is a function of the retained carrier value of k only; δ(w⁰) = 0, and δ(w) \> 0 for w ≠ w⁰;  
　K2 (participation grading, relative to fixed p, j): δ(w) \< δ(w′) ⇔ e(w) \< e(w′), and δ(w) = δ(w′) ⇔ e(w) = e(w′);  
　K3 (repetition does not erase; only for the declared write condition 𝒲): δ(W\_s(w)) ≥ δ(w) for all w ∈ Ω\_k.  
Participation depth δ\* := e\_{p,j}. If some non-ground state w has e(w) = 0, the element is hidden from probe p, and the probe must be changed or a probe class declared. A failure of a (K1, K3) pair breaches only the declaration for that carrier under 𝒲. Basis: the ontological explanatory note “A single Trace-Response has only deepening and shallowing… the limit of shallowing is that the Trace-Response phenomenon does not occur”; Definition 9 of *The Mathematical Form of the Field*, “Sedimentation-Degree is borne by the hosting mechanism”; *The Definition of the Sedimentation-Field* v1.1, “deepen through repeated exposure” \[Representational choice\].  
Definition 4′ (Trace-Response candidates and element certificates)  
Candidate screening: positions with oriented depth \> ε at window end (positive) and \< −ε (reverse) are listed separately. Element certificate: a candidate further requires (1) self-retention reaching τ\_W (a lower bound τ\_k^obs ≥ τ\_W suffices; ⊥\_Tail when the lower bound falls short of τ\_W and there is no tail evidence); (2) K1–K3 passed under the declared p, j, 𝒲; (3) when the probe class has an order conflict, splitting already carried out per Lemma 17-3′. Screening is not certification.  
Definition 5′ (organization hypergraph; exact enumeration and bounded sampling)  
On the element set E construct the hypergraph H\_org. Co-participation hyperedges: the minimal setting subsets that effectively change activity component j (the positions on which j depends singly are merged into one hyperedge; a dependence that appears only under a joint setting takes that joint subset). History-condition hyperedges: a minimal setting subset U that effectively changes the total component (recomputed under the unclamped mechanism) of a process acting on x, together with x. Exact verdict: enumerate over the whole declared setting family 𝔖 (joint settings included); the connected components are read off from it. Bounded sampling: computed only on the subsets actually applied; it outputs witness hyperedges and coverage gaps (pairs of positions not jointly covered by any tested subset; being covered does not mean that the relation of the pair has been identified), and does not output connected components. Each hyperedge notes its probe and time; chains linked across times or across settings that cannot be applied simultaneously must be noted. Object set: a connected component under 𝔖 and the time frame; a sub-organization is another adjudication instance, obtained by declaring boundary conditions (the other positions clamped at declared values) and then taking a subset of the component. Connectedness is an equivalence relation; the uniqueness of components holds only for a given hypergraph.  
Definition 6′ (effective-difference certificate: one sufficient certificate for HistCond of \[S1\])  
The definition of HistCond(ρ, T) in \[S1\] is unchanged: the action of ρ on Org(T) within W (occurrence, timing, position, strength or direction) is determined in part, through an actual material route, by Trace-Responses T has already left. This definition gives only one sufficient evidence rule for its “strength” clause; it is an entry point for positive determination, not an equivalent definition.  
Effective-difference witness: the action of process ρ on x ∈ T at beat t within W in state σ\_t, together with a legitimate control σ′, such that  
　(A) same beat, same process: Act and the difference are taken at the same beat t, for the same process ρ and the same target x;  
　(B) bearing positions: σ′ changes only U ⊆ T, and every position in U has oriented depth \> ε in the pre-beat state of beat t, with evidence of formation and retention earlier than beat t (window-end membership of T does not by itself give this evidence);  
　(C) effective difference: recomputed under the unclamped mechanism (activity recomputed with the setting), the total-component difference Δ\_tot := c\_{ρ,x}(σ′) − c\_{ρ,x}(σ\_t) satisfies \|Δ\_tot\| \> ε;  
　(D) route and certification: the dependence between σ\_t and σ′ runs through the declared actual mechanism route (in model mode given by the model structure; in measurement mode requiring IMP of \[S3\] or its counterpart), and the action certification of ρ holds (same-beat component \|c\_{ρ,x}(σ\_t)\| \> ε, under the semantics of the declared resolution).  
Three-way value (for each beat, process, target and declared setting family):  
　effective difference certified—some legitimate control satisfies (A) to (D);  
　functional support established—some legitimate control gives Δ\_tot ≠ 0 but none exceeds ε, or there is nonzero functional support on a certified path per D15–D18 of \[S2\];  
　effective difference not certified—otherwise.  
The latter two values are not negations of HistCond. The two branches are reported separately: along the declared order “first swap the activity, then change the direct read”, A := c(direct read of σ\_t, y(σ′)) − c(direct read of σ\_t, y(σ\_t)) and D := c(direct read of σ′, y(σ′)) − c(direct read of σ\_t, y(σ′)), with A + D = Δ\_tot. This is a telescoping identity along that order; when the direct read and the activity interact, the components under the other order differ (counterexample X8), and the components are not a unique attribution of responsibility. When the applicability of the mixed state (the direct read of σ\_t with the activity of σ′) is not established, A and D belong only to the model ledger. That each branch is effective does not imply (C) (counterexample X1); a verifiable cancellation margin: (C) holds when \|A\| \> \|D\| + ε or \|D\| \> \|A\| + ε; when the two branches have the same sign, \|Δ\_tot\| = \|A\| + \|D\|.  
Note 6′-1 (normative note on the history condition)  
The effective-difference certificate of Definition 6′ proves only one kind of history condition, under the declared control. D15–D18 of Chapter 2 express strength dependence through certified paths and nonzero functional support; failure to obtain an effective-difference certificate cannot be used to negate that dependence, nor does it rule on other modes of participation. The F-layer conclusions of Chapter 2 may be read back under their original antecedents.  
Definition 7′ (main verdict and optional ledgers)  
Main verdict: the original definition of the formal master formula Fld(χ) of \[S1\], with HDyn and HistCond in their original meaning in \[S1\]. In the target instance χ\*: T, a write process ρ acting on x ∈ T, and an intermediate activity variable y outside T. ### 5.1  Three-Way Classification

Theorem 17-1 (self-retention classification and robust window)  
Hypotheses: with the other carriers clamped, the self-decay of each carrier satisfies \|u\_k(t)\| = \|u\_k(0)\|·λ\_k^t, λ\_k ∈ \[0, 1); the legitimate write amplitude \|u\_k(0)\| ∈ \[a, A\], 0 \< ε \< a ≤ A. Call k “surely retained” at window length t if a·λ\_k^t \> ε, and “surely not retained” if A·λ\_k^t ≤ ε.  
(1) For each k, the t at which k is surely retained form {0, …, t\_s(k)}, and the t at which it is surely not retained form {t\_f(k), t\_f(k)+1, …}, with t\_s(k) \< t\_f(k).  
(2) Suppose the carriers split into a fast group F (λ\_k ≤ λ\_f) and a slow group S (λ\_k ≥ λ\_s), with λ\_f \< λ\_s. Let t\_lo := min{t : A·λ\_f^t ≤ ε} and t\_hi := max{t : a·λ\_s^t \> ε}. If t\_lo ≤ t\_hi, then for every τ\_W ∈ \[t\_lo, t\_hi\] every carrier in S is surely retained and every carrier in F is surely not retained: within this interval the classification does not change with window length (robust window).  
(3) The classification changes with window length: when the carrier set is nonempty, the surely retained set at t = 0 is the whole set, and at t ≥ max\_k t\_f(k) it is empty; hence over the whole domain of window lengths the surely retained set must change. When the robust window of (2) is empty (no spectral gap), the verdict must carry the declared τ\_W; without a declaration the verdict is ⊥\_Sep.  
(4) Distinguishing two carriers k, k′ within a given candidate window domain: if the actual critical beats satisfy t\_s(k) \< t\_s(k′) (t\_s(k) = max{t : a·λ\_k^t \> ε}, computed directly), then for every t ∈ (t\_s(k), t\_s(k′)\], k′ is surely retained and k is not surely retained; when the candidate window domain intersects this interval, the two can be distinguished within it. λ\_k \< λ\_k′ alone does not imply t\_s(k) \< t\_s(k′): with a = 1 and ε = 1/2, λ = 2/5 and λ = 49/100 both give t\_s = 0 (Appendix B.2 R1f).  
Proof: λ^t is monotonically nonincreasing in t. (1) The t with a·λ^t \> ε form an initial segment, and the t with A·λ^t ≤ ε form a final segment; since a ≤ A, the last point of the initial segment is less than the first point of the final segment. (2) λ\_k ≤ λ\_f ⇒ A·λ\_k^t ≤ A·λ\_f^t ≤ ε (t ≥ t\_lo); λ\_k ≥ λ\_s ⇒ a·λ\_k^t ≥ a·λ\_s^t \> ε (t ≤ t\_hi). (3) Since a \> ε, a·λ\_k^0 = a \> ε, so at t = 0 every carrier is surely retained; since λ\_k \< 1, A·λ\_k^t → 0 and t\_f(k) is finite, so for t ≥ max\_k t\_f(k) (finitely many carriers) every carrier is surely not retained; the surely retained sets at these two window lengths are the whole set and the empty set. (4) By (1), k′ is surely retained for t ≤ t\_s(k′), and k is not surely retained for t \> t\_s(k); the interval (t\_s(k), t\_s(k′)\] is nonempty if and only if t\_s(k) \< t\_s(k′). ∎  
Generalization: the self-decay need not be geometric; as long as the fast group has a monotone upper envelope and the slow group a monotone lower envelope, the proof is unchanged.  
Tail evidence: the hypothesis of this theorem (geometric self-decay) is itself an envelope of type (C) of Definition 2′; a “surely not retained” adjudicated from it is a complete verdict. Where an instance has only a finite record, the tail evidence of Definition 2′ must be given separately before the record is read as complete; otherwise only the lower bound is used.  
Two-way character: with exact clamped records and tail evidence, J1 is two-way (the definition is the computation); with a reading error r, judge surely retained by a·λ^t − r \> ε and surely not retained by A·λ^t + r ≤ ε, and ⊥ otherwise; a verdict of 1 is sound in one direction (the same margin structure as 13-A of \[S13\]).  
Verification: Appendix B.2 R1c (λ = 1/2 and 31/32, amplitude \[1/10, 1\], ε = 1/100, robust window \[7, 72\]); R1d (λ = 1/10 … 9/10, no spectral gap; the classifications at t = 2, 4, 8, 16 are pairwise different); R1d′ (for the same family, 9 surely retained at t = 0 and 0 at t = 44); R1a (*E. coli* proxy model: methylation observed lower bound 39 beats; the tail evidence is that the subthreshold set \|u\| ≤ 40/4096 is forward-invariant under the rest map, verified cell by cell, so complete 39 beats; activity 0 beats); R1b (*Drosophila* model: the γ1 position is complete at 29 beats, with tail evidence of the same type; the α3 position has only a lower bound ≥ 300 beats—for τ\_W ≤ 29, γ1 is a Trace-Response, for τ\_W \> 29 an activity residue, so the regime depends on the time window; for τ\_W ≤ 300, α3 is positively determined as a Trace-Response carrier by its lower bound).  
Lemma 17-1′ (an activity that varies with the Trace-Responses does not thereby become a Trace-Response)  
Let the activity component y\_j = Φ\_j(d, s) be a quantity determined within the beat by Trace-Response carrier d and current signal s. Then with d clamped the self-retention of y\_j is 0; without clamping, the deviation of y\_j after supply cut-off relative to the trace-free history equals Φ\_j(d, rest) − Φ\_j(d⁰, rest), that is, the participation effect of d, which can stay nonzero for a long time.  
Proof: with d clamped, at the beat of supply cut-off y\_j = Φ\_j(d, rest), which is independent of history; without clamping, substitute directly into the deviation formula. ∎  
Significance: judging Trace-Responses only by “whether a deviation remains after supply cut-off” would misjudge activities that vary with the Trace-Responses, such as CheA activity and MBON firing, as Trace-Responses; the clamping of Definition 2′ is necessary. Clamping in physical systems: strains with a fixed modification state (*E. coli* cheR cheB background, Sourjik and Berg 2002), optogenetic or pharmacological clamping, flow clamping. A finite record without tail evidence yields only a lower bound, whether or not the end point crosses the threshold (Definition 2′, counterexample X11; Appendix B.2 R1b: the γ1 position has tail evidence, complete 29 beats; the α3 position has only a lower bound ≥ 300 beats).  
Verification: Appendix B.2 R8a (*E. coli* proxy model adapted to an attractant that is then removed: A rises from the ground state 1/2 to 0.638—this is the read-out of retained methylation; the self-retention of A itself is 0).

### 5.2  Depth

Theorem 17-2 (uniqueness of the depth order; relative to a fixed probe)  
Suppose δ₁, δ₂ both satisfy K1 and K2 on Ω\_k for the same probe p and read-out j. Then there is a unique strictly increasing φ with φ(0) = 0 such that δ₂ = φ∘δ₁.  
Proof: define φ(δ₁(w)) := δ₂(w). Well-defined: δ₁(w) = δ₁(w′) ⇒ e(w) = e(w′) ⇒ δ₂(w) = δ₂(w′); strictly increasing: δ₁(w) \< δ₁(w′) ⇒ e(w) \< e(w′) ⇒ δ₂(w) \< δ₂(w′); φ(0) = 0 by K1; uniqueness by the defining equation. ∎ When the probe is changed, the two depths may be ordered differently (Lemma 17-3′).  
Corollary 17-2a (detecting a pre-selected number): suppose a candidate number q already satisfies K1, and satisfies K3 under 𝒲. Then q is a bearable depth relative to (p, j) if and only if q and e\_{p,j} have the same order relation everywhere—none of the three conflicts (strict reversal; q equal while e differs; q different while e is equal) is allowed. If there is a single conflicting pair, q is not a depth under that probe. When K1 or K3 has not passed, this corollary is not used. Verification: Appendix B.2 R2a (the methylation excess and the participation effect have identical order relations); R2b (the candidate \|M − 6\| has 256 strictly reversed pairs and 16 equality-mismatched pairs).  
Corollary 17-2b: statements invariant under φ (whether each step deepens, shallows or is zero change; which of two states of the same element is deeper; whether the element is extinguished) are facts about the object; the size of increments, ratios and linear growth laws are facts only about the chosen measure, and the measure must be noted.  
Theorem 17-3 (periodic writes and the declared K1/K3)  
If the formative write W\_s under 𝒲 has in Ω\_k a periodic orbit through the ground state, w⁰ → W\_s(w⁰) → … → W\_s^n(w⁰) = w⁰ (n ≥ 2, W\_s(w⁰) ≠ w⁰), then there is no depth satisfying both K1 and K3 (relative to 𝒲).  
Proof: along the orbit K3 gives 0 = δ(w⁰) ≤ δ(W\_s(w⁰)) ≤ … ≤ δ(W\_s^n(w⁰)) = 0, so δ(W\_s(w⁰)) = 0, contradicting K1. ∎  
Restriction: this breaches only the K1/K3 combination “for that carrier, under 𝒲”; a periodic host with retention may have a bearable depth on another carrier (wear, oscillator parameters) or under another write condition. An odometer digit wheel cannot serve as an element of that orientation under the 𝒲 “advance by one step only” (Appendix B.2 R2c); a counter register satisfies K3 below full scale and fails it at the return to zero (R2d).  
Lemma 17-3′ (probe-order conflict and splitting)  
If under probes p, p′ there are w, w′ ∈ Ω\_k with e\_p(w) \< e\_p(w′) but e\_{p′}(w) \> e\_{p′}(w′), then there is no depth satisfying K2 for both probes. Proof: for p, K2 requires δ(w) \< δ(w′), and for p′ the reverse. ∎ This gives only a necessary condition for splitting, and only relative to the two probes listed (Appendix B.2 R2e).

### 5.3  Organization

Theorem 17-4′ (organization hypergraph: uniqueness of components, necessity of exact enumeration, anti-splicing, reduction with antecedents)  
(1) The connected components of the H\_org obtained under 𝔖 and the time frame partition E uniquely. This is a property of the given hypergraph; changing the setting family, the probe or the time frame can give a different hypergraph, and the physical boundary is not thereby unique.  
(2) A graph built only from single-position settings can misclassify: in counterexample X3 the single-position-setting graph gives three isolated points, while exact enumeration over the whole of 𝔖 gives the hyperedge {a, b, x} and one component (Appendix B.2 R0, X3); when bounded sampling tests only {a} and {b}, there is no witness, and all three pairs are coverage gaps (R0, X3′).  
(3) Anti-splicing: construct Gerry—s is a scratch engraved by a signal, the scan read-out is scan = s, and no process acts on s; b is a Trace-Response left by an in-field pulse at the entry beat (not a signal), with activity y\_b = b, and the process self acts on b by h·y\_b/2. For T = {s, b}: TraceSet (both positions cross the threshold, and s is a signal-formed position), Part (scan depends on s) and HDyn (self changes b at beat 0 with an effective total difference) hold, hence Fld; for T = {s}: there is no acting process, HDyn = 0; for T = {b}: b is not a signal-formed position, and r does not hold. Between s and b there is neither a co-participation hyperedge nor a history-condition hyperedge (Appendix B.2 R3e, exact enumeration including joint settings). Condition of entry: when an adjudication procedure evaluates by “∃T” and allows T to span components (Lemma 9 of \[S3\], Theorem TM of \[S11\]), this construction enters its verdict; the identification output reports component by component.  
(4) Reduction (with antecedents): suppose Fld is witnessed by T, and the witness of HDyn is an effective-difference witness of Definition 6′ (process ρ, beat t, target x, the control changing only U). Lemma 17-4′ (identity under refinement)  
When carriers split and merge within W, the union (finite) of the segment boundaries at all times determines the coarsest common refinement P*, which exists and is unique, and every segment is a union of cells of P*. ### 5.5  Cycle Map

Theorem 17-6′ (cycle map: well-definedness, monotone convergence, basins of attraction)  
Hypotheses: F\_P is well-defined (Definition 8′) and monotonically nondecreasing; its domain is a finite totally ordered chain, or a closed interval with F\_P continuous.  
(1) When F(δ₀) \> δ₀, the iterates are monotonically nondecreasing and converge to the least fixed point ≥ δ₀ (when it exists; on a finite chain it always exists).  
(2) When F(δ₀) \< δ₀, the iterates are monotonically nonincreasing and converge to the greatest fixed point ≤ δ₀.  
(3) The basin B(p) is a convex set containing p; its endpoints are determined point by point by (1) and (2); when F is the identity, every point is a single-point basin of its own.  
Proof: (1) F(δ₀) ≥ δ₀ and monotonicity give F^{n+1}(δ₀) ≥ F^n(δ₀); when p is a fixed point ≥ δ₀, F^n(δ₀) ≤ p ⇒ F^{n+1}(δ₀) ≤ F(p) = p; on a finite chain the sequence ends at a constant q, F(q) = q, δ₀ ≤ q ≤ p, and taking p least gives q = p; on a closed interval the limit L exists, continuity gives F(L) = L, and likewise L = p. (2) Symmetric. (3) When δ₁ \< δ \< δ₂ and δ₁, δ₂ ∈ B(p), F^n(δ₁) ≤ F^n(δ) ≤ F^n(δ₂), and the limit is squeezed to p. ∎ Verification: Appendix B.2 R0, X6.  
(4) Necessity of well-definedness: when the *E. coli* proxy model takes only the mTar depth as its state, states with the same depth but different mTsr give different depths after one cycle (Appendix B.2 R5f: 9 depth values), so the state must be augmented to (mTar, mTsr); the dent-cell model has depth as its only state and is well-defined (R5e).  
Application (Appendix B.2 R5, the mixed regime of the dent-cell model): per-beat ungridded zero δ = 1/3 (analytic); gridded (1/4096) cycle threshold 171/512 ≈ 0.333984; saturation point 4; on the test chain, the upper end of B(0) is 5/16 and the lower end of B(4) is 11/32. The three are not used in place of one another.

### 5.6  Continuous Class

Theorem 17-7′ (short-beat knockout certificate for the continuous class)  
Hypotheses: ẋ = F(x) = Σ\_m F\_m(x), with F and F − F\_m Lipschitz on a convex set K containing the relevant trajectory segments, with constants (max norm) L, L′ and suprema M, M′. Beat length h; full flow φ\_h, flow with m removed φ\_h^{−m}; knockout difference Δ\_m^h(s) := (φ\_h(s) − φ\_h^{−m}(s))\_t; setting s′ = s + δe\_i, response R := Δ\_m^h(s′) − Δ\_m^h(s).  
(1) First-order bound: \|R − h(f\_m(s′) − f\_m(s))\| ≤ h²(LM + L′M′). Proof: for a Lipschitz field G (constant L\_G, supremum M\_G) and its flow ψ, ψ\_h(s) − s − hG(s) = ∫\_0^h (G(ψ\_τ(s)) − G(s))dτ; the integrand is ≤ L\_G·\|ψ\_τ(s) − s\| ≤ L\_G M\_G τ, and integration gives ≤ L\_G M\_G h²/2; hence Δ\_m^h(s) = h f\_m(s) + E₁(s) − E₂(s) with \|E₁\| ≤ LMh²/2 and \|E₂\| ≤ L′M′h²/2, and subtraction gives the bound. ∎  
(2) The exact formula does not hold in general (counterexample X5: Appendix B.2 R0 checks with rational upper and lower bounds that R ≈ 0.648721 \> 1/2, and that \|R − h\| ≤ 5/4 = the first-order bound). A sufficient antecedent for the exact formula: on the target coordinate, the rates of the other processes depend neither on the target coordinate nor on the coordinates affected by m (triangular structure), and the integral of the difference of the other target rates in the paired flows is zero; when f\_m is constant along a non-drifting Trace-Response, R = h(f\_m(s′) − f\_m(s)) (R6b).  
(3) Separate error budgets: each of the four raw flow readings ≤ r\_φ; each of the two knockout differences ≤ 2r\_φ; the error of the final response reading ≤ 4r\_φ; model error ≤ h²(LM + L′M′). Rule for a verdict of 1: \|R\_obs\| \> h²(LM + L′M′) + 4r\_φ ⇒ f\_m(s′) ≠ f\_m(s) (finite-difference support, sound; Appendix B.2 R6a: in 3000 random cases the model error exceeds the bound 0 times, and among the cases judged 1 none has a finite difference of 0).  
(4) Differential support: differentiable on the open segment (s, s′) ⇒ some interior point has a nonzero partial derivative; with SD\_i in addition on an Ω\_i containing s ⇒ nonzero partial derivative at s. Lipschitz continuity does not give differentiability.  
(5) Completeness in the limit: write K := LM + L′M′. When f\_m(s′) ≠ f\_m(s): if K = 0 and the reading error is zero, the verdict is 1 for every h; if K \> 0, then for a sufficiently small reading error there is an h for which the verdict is 1. When the finite difference is 0, no threshold is sought (R6c; no division is performed).  
(6) Read-back: even when a partial derivative is read off, an effective component within the window, i being an available position, and the route (IMP-c) are still required; HC^c remains a candidate reading; when reading back to HistCond, an effective difference must be obtained separately per Definition 6′, or only functional support is recorded per Note 6′-1.

### 5.7  Cross-Record Chains

Theorem 17-8′ (cross-record chain: nonzero, threshold-crossing difference and actual action proved separately)  
Assume Definition 10′.

6\. Bounds of Misjudgment  
E17-1  Three-way classification: incomplete clamping (other carriers drift during the clamp) overestimates the self-retention of activity. Bound: with drift amplitude η, the self-retention criterion is reliable for “surely retained” only with a·λ^t − η \> ε; if η is not reported, the verdict is ⊥\_Clamp.  
E17-2  Three-way classification: with the window length outside the robust window, the same carrier falls into different classes in two reports. Bound: the window endpoints of Theorem 17-1(2); verdicts outside the window must carry τ\_W.  
E17-3  Depth: the probe class is too narrow, and a hidden position is judged to be the ground state (an undetected K2 failure). Bound: valid only for the declared probe class; what a change of probe reveals is adjudicated separately.

E17-5  Set: insufficient edge certification causes one organization to be judged as two (a wrong split). Measurement gives no separation verdict, so this misjudgment arises only in model mode and is borne by incompleteness of the process and activity inventory (what is breached is the inventory declaration).

E17-9  Continuous class: the Lipschitz constant or supremum is under-reported. Bound: Theorem 17-7′ is reliable only when the reported constants are true; an untrue constant declaration breaches the declaration.  
E17-10  Cross-record chain: the C1–C5 declarations are untrue (optogenetic drive is not physiological firing; the range is not covered). Bound: the verdict goes only as far as a Column B conditional conclusion, carrying C1–C5.  
E17-11  Regime: a fixed point on a finite grid is produced by the gridding (a numerical spurious fixed point). Bound: the grid in the program is part of the declared model and the conclusions are exact for that model; for the continuous model the analytic threshold governs (e.g. δ\_c = 1/3).

E17-13  A wrong split from building the organization graph from single-position settings alone (X3). Bound: component verdicts are issued only under exact enumeration over all of 𝔖; sampling reports only witnesses and coverage gaps.  
E17-14  A single-branch change is used in place of the total difference (X1), or the components of one decomposition order are read as an attribution of responsibility (X8). Bound: Definition 6′ adjudicates by Δ\_tot alone; the two branches state their order.  
E17-15  The failure of an effective-difference certificate is read as a negation of HistCond or Fld (X7); or the ⊥\_HC of one candidate witness overrides values already obtained elsewhere. E17-16  SED is used to infer net deepening, or the reverse (X2, the sun-warmed stone). Bound: each ledger keeps its own account.  
E17-17  The cycle map is not well-defined but is iterated on a single depth. Bound: ⊥\_WD, or augment.  
E17-18  A first-order approximation is taken as the exact formula (X5). Bound: use the exact formula only under the antecedents of Theorem 17-7′(2).  
E17-19  Chain nonzero is used in place of threshold crossing (X9); the chain difference or the lower bound on G is used in place of actual action (X10); the monotonicity observed in record 2 is used in place of the target write law (C2 co-intervention); the early return of the chain certificate is read as the absence of actual action. 8.1  *E. coli* Chemotaxis (Non-Neural; Methylation Is the Trace-Response, CheA Activity Is the Activity, the Receptor Cluster Is the Organization)  
(1) Identification  
Signal: a change in extracellular ligand concentration (MeAsp or aspartate for Tar, serine for Tsr), acting on the ligand-binding domain of the receptors from outside B (the cell) (Sourjik and Berg 2002).  
Medium and carriers: the chemoreceptor array (Tar and Tsr clustered with CheA and CheW); the carriers are the methylatable glutamate sites on each receptor molecule.  
Change left behind: site methylation. \[Fact\] After attractant is added, methylation rises to a new level within minutes, by more for larger stimuli, stays there while the attractant is present, and falls back rapidly when it is removed (Goy, Springer and Adler 1977, abstract); in fixed-modification-state strains the dose–response shifts monotonically with the modification state, the Tar K\_D going from 38 µM (EEEE) to 440 µM (QEQQ) (Sourjik and Berg 2002).  
Three-way classification (J1): CheA activity is activity — with the modification state clamped (cheR cheB background), activity responds to a ligand step within the solution-exchange time (90% exchange \< 4 s, CheY-P half-life a few tenths of a second, Sourjik and Berg 2002, \[Fact\]); methylation is the Trace-Response carrier — self-relaxation τ\_a about 29 s (22 °C) and 11 s (32 °C) (Shimizu, Tu and Berg 2010, inferred from FRET kinetics via a model, \[Published model\]); the phosphorylation state of CheB is activity residue (Clausznitzer et al. 2010); receptor and enzyme expression levels and cluster geometry are background. Maintenance of methylation while attractant persists is “maintenance” (the CheR and CheB components cancel, with action borne; \[S1\] Section 3), not activity. Proxy model: methylation self-retention complete at 39 beats (tail evidence: a forward-invariant subthreshold set), activity 0 beats (Appendix B.2 R1a); removal response A = 0.638 \> 1/2 (R8a), which is the read-out of retained methylation.  
Depth (J2): issued relative to the probe “activity shift under a ligand step” and the write condition “repetition of the same attractant step”. Under the site-weight differences of the published MWC model (Shimizu, Tu and Berg 2010: the E modification has about 2.5 times the effect of Q, \[Published model\]), what has the same order as the free-energy shift is methylation weighted by site weights; the unweighted site count can have equality mismatches with it (the case Corollary 17-2a addresses). The proxy model has the same order (Appendix B.2 R2a). Shallowing: demethylation returns to the adapted baseline and the removal response vanishes, i.e. the Trace-Response phenomenon does not occur. Physical identity of elements: the same site on the same receptor molecule, with negligible turnover within W (\[Insufficient: insufficient observation\]; persistence not directly labeled).

8.3  *Physarum polycephalum* Tube Network (Non-Neural)  
(1) Identification  
Signal: a local nutrient stimulus beside the network (Kramar and Alim 2021). Medium and carriers: the plasmodial tube network; the carriers are the tube segments (the gel-like ectoplasm of the tube wall and its actomyosin cortex).  
Change left behind: \[Fact\] within about 15 min after the stimulus a new tube-diameter distribution forms and persists until the end of the 45 min analysis window; nearby tubes grow in diameter (up to about twofold) and thinner distant tubes shrink; after the nutrient is exhausted, a ring of thick tubes around it remains (qualitative) (Kramar and Alim 2021). The Trace-Response is the change in tube-segment conductance (∝ a⁴/ℓ) relative to the reference.  
Three-way classification (J1): activity and Trace-Response are superposed on the same carrier (tube diameter): the periodic contractions of about 1–2 min (Marbach et al. 2023) are the activity component, and the diameter averaged over the contraction cycle is the Trace-Response component; they are distinguished by spectral decomposition under Theorem 17-1 (the fast mode is the peristaltic oscillation, the slow mode the adaptation time t\_adapt of about 10–100 min, Marbach et al. 2023), with the window length chosen between the two. Cytoplasmic flow, pressure and shear are activity; the delay in sensing shear (1–3 min) is activity residue; the softening agent (a mechanistic hypothesis of Kramar and Alim 2021) is activity or residue transported by advection. The baseline drifts with contraction, so depth must be computed against a reference trajectory (the same network without stimulus, or a sham-stimulation control); otherwise ⊥\_Ref (Definition 1).  
Depth (J2): the participation effect is the change, relative to the reference, in the flow carried by a tube segment under probe pumping; with the rest of the network fixed, the flow in a single tube can be written Q\_x = V\_eq/(1/g\_x + R\_net) (V\_eq and R\_net are the equivalent drive and equivalent resistance of the rest of the network across the two ends of the tube), which for finite R\_net is strictly increasing in the tube's own conductance g\_x, so K2 holds. K3: repeated nearby stimuli enlarge the tube diameter up to an upper limit (radius 5–70 µm, Marbach et al. 2023). Shallowing limit: the tube segment disappears (Marbach et al. 2023) — extinction is accompanied by the disappearance of the carrier and a change of topology, unlike synaptic efficacy returning to baseline while the synapse remains.  
Set (J4): Kirchhoff conservation makes the flow in every tube segment of a connected network depend jointly on the conductances of all tubes, so the tube network of one plasmodium is one organization component (Appendix B.2 R3d: the positive candidates 02, 13, 23 form one component; thinning tube 01 is a reverse candidate, listed on its own). Element identity: tube segments merge into longer tubes when neighboring tubes disappear (Marbach et al. 2023); under Lemma 17-4′ the common refinement over the whole window gives the representational units, and merging is a change of organization (of paths); identity of tube-segment material requires separate grounding in continuous imaging.  
Activity and re-action: the tendency is the network's distribution of flow under pumping and stimulus, and the tendency acting on a single tube is borne by the equivalent resistance R\_net of the rest of the network and the local pressure (Marbach et al. 2023, \[Published model\]); the re-action is shear-driven diameter adaptation with a 1–3 min delay; the disappearance of one tube changes R\_net and destabilizes its neighbors (an avalanche).

  hc_total          difference reading: some legitimate setting makes the total component difference > ε (not restricted to available positions; for contrast only).

  sed               activity-mediated positive component (optional strengthening ledger); with plus, SED⁺.
  net_deep          actual net deepening (a separate ledger).
  trace_candidates  screening of Trace-Response candidates (oriented depth > ε and < −ε listed separately; not an element certificate).
  retention         self-retention: observed lower bound and complete verdict kept apart; a complete verdict requires explicit tail evidence (Definition 2′).
  triage            three-way verdict from the lower bound, completeness and the declared τ_act, τ_W; ⊥_Tail only when there is just a lower bound and it falls short of τ_W.
  org_graph_exact   exact enumeration over all declared joint settings (hyperedges included).
  org_graph_sample  bounded sampling: reports only witness edges and coverage gaps.

from fractions import Fraction as Fr
from itertools import combinations
import math
ZERO = Fr(0)
FRACS = (Fr(0), Fr(1, 2), Fr(2))

def floor_grid(x, G):
    return Fr(math.floor(x * G), G)

class Host:
    name = 'host'
    grid = None
    def step(self, w, s):
        y = self.act(w, s)
        new = dict(w)
        for (_p, x, c) in self.comps(w, y, s):
            new[x] = new[x] + c
        for x in self.X:
            v = min(self.hi[x], max(self.lo[x], new[x]))
            if self.grid is not None:
                v = floor_grid(v, self.grid)
            new[x] = v
        return new

def run(host, w0, hist):
    out, w = [dict(w0)], dict(w0)
    for s in hist:
        w = host.step(w, s)
        out.append(w)
    return out

def ref_hist(host, hist):
    return ['rest' for _ in hist]

def depth(host, w, x):
    """Oriented depth (signed): a positive value is a Trace-Response in the declared orientation; a negative value is the other type, beyond the ground state."""
    return host.orient[x] * (w[x] - host.ground[x])

def trace_candidates(host, hist, eps):
    """Candidate screening (not an element certificate). Returns (trajectory, reference trajectory, positive candidates, reverse candidates, signal-formed positions)."""
    S = run(host, host.init, hist)
    R = run(host, host.init, ref_hist(host, hist))
    w, wr = S[-1], R[-1]
    pos = [x for x in host.X if depth(host, w, x) > eps]
    neg = [x for x in host.X if depth(host, w, x) < -eps]
    sig = [x for x in host.X if abs(w[x] - wr[x]) > eps]
    return S, R, pos, neg, sig

def retention(seq, eps, tail=None):
    """Self-retention (Definition 2′). Returns (lower bound, verdict); lower bound = 1 + the last t in the record with |u| > eps (0 if no point crosses the threshold).
    The verdict is 'complete' if and only if tail evidence is given and checked, and 'lower bound' otherwise, regardless of whether the last record point is above threshold:
    a last point below threshold does not rule out a later crossing during the ensuing rest. tail is one of:
      ('coverage',)                    the record already covers the whole remaining rest domain (declared; the function does not certify it);
      ('invariant set', step, band)    band lists all points of the subthreshold set (|u| ≤ eps), step is the one-step rest map;
                                       requires the last record point to lie in band and step(band) ⊆ band (checked exactly, point by point);
      ('envelope', C, lam)             |u(t_end + s)| ≤ C·lam^s (s ≥ 0) is proved, 0 ≤ lam < 1; requires C ≤ eps."""
    last = 0
    for t, v in enumerate(seq):
        if abs(v) > eps:
            last = t + 1
    if tail is None or not seq:
        return last, 'lower bound'
    kind = tail[0]
    ok = False
    if kind == 'coverage':
        ok = True
    elif kind == 'invariant set':
        step, band = tail[1], set(tail[2])
        ok = (seq[-1] in band and all(abs(u) <= eps for u in band)
              and all(step(u) in band for u in band))
    elif kind == 'envelope':
        C, lam = tail[1], tail[2]
        ok = 0 <= lam < 1 and C <= eps and abs(seq[-1]) <= C
    return last, ('complete' if ok else 'lower bound')

def triage(lb, status, tau_act, tau_W):
    """Three-way verdict for a carrier that can be written (Definition 2′): lower bound ≥ τ_W gives a Trace-Response carrier; activity and activity residue require complete self-retention;
    when there is only a lower bound and it is < τ_W, the verdict is ⊥_Tail (no verdict of activity, residue or non-Trace-Response is issued)."""
    if lb >= tau_W:
        return 'Trace-Response carrier'
    if status != 'complete':
        return '⊥_Tail'
    return 'activity' if lb <= tau_act else 'activity residue'

def setv(host, w, vals):
    v = dict(w)
    for x, val in vals.items():
        v[x] = min(host.hi[x], max(host.lo[x], val))
    return v

def setT(host, w, T, frac=Fr(0)):
    return setv(host, w, {x: host.ground[x] + frac * (w[x] - host.ground[x]) for x in T})

def comp_of(host, w, y, s, proc, x):
    tot = ZERO
    for (p, xx, c) in host.comps(w, y, s):
        if p == proc and xx == x:
            tot += c
    return tot

def total_comp(host, w, s, proc, x):
    return comp_of(host, w, host.act(w, s), s, proc, x)

def branches(host, w, w2, s, proc, x):
    """Two-branch report (the control w2 is the state after a legitimate setting). A = c(direct read of w, y(w2)) − c(direct read of w, y(w));
    D = c(direct read of w2, y(w2)) − c(direct read of w, y(w2)); A + D = total difference = c(w2) − c(w) (recomputed under the unclamped mechanism)."""
    y, y2 = host.act(w, s), host.act(w2, s)
    c0 = comp_of(host, w, y, s, proc, x)
    cA = comp_of(host, w, y2, s, proc, x)
    c2 = comp_of(host, w2, y2, s, proc, x)
    return cA - c0, c2 - cA, c2 - c0

def settings(host, w, T, fracs=FRACS, joint=True):
    """Declared family of legitimate settings: every nonempty subset of T (joint=True), or each single position and the whole of T (joint=False), times the depth multiples."""
    T = list(T)
    subs = []
    if joint:
        for k in range(1, len(T) + 1):
            subs += [list(c) for c in combinations(T, k)]
    else:
        subs = [[x] for x in T] + ([T] if len(T) > 1 else [])
    out = []
    for U in subs:
        for f in fracs:
            w2 = setT(host, w, U, f)
            if w2 != w:
                out.append((tuple(U), f, w2))
    return out

def hc_total(host, w, s, proc, x, T, eps, fracs=FRACS, joint=True):
    """Difference reading of the history condition: some legitimate setting makes the total component difference > eps. Returns (U, f, A, D, total difference) or None."""
    for (U, f, w2) in settings(host, w, T, fracs, joint):
        A, D, tot = branches(host, w, w2, s, proc, x)
        if abs(tot) > eps:
            return (U, f, A, D, tot)
    return None

def part(host, w, T, probes, eps, fracs=FRACS):
    for s in probes:
        y0 = host.act(w, s)
        for (U, f, w2) in settings(host, w, T, fracs, joint=False):
            y1 = host.act(w2, s)
            for j in y0:
                if abs(y0[j] - y1[j]) > eps:
                    return (s, j, y0[j], y1[j])
    return None

def hdyn(host, states, sigs, T, eps, fracs=FRACS):
    """For contrast: at some beat in the window, the component of process p on x ∈ T is effective, and the total component difference is effective under some legitimate setting of T (not restricted to available positions)."""
    for k, s in enumerate(sigs):
        w = states[k]
        y = host.act(w, s)
        seen = set()
        for (p, x, c) in host.comps(w, y, s):
            if x not in T or (p, x) in seen:
                continue
            seen.add((p, x))
            c = comp_of(host, w, y, s, p, x)
            if abs(c) <= eps:
                continue
            h = hc_total(host, w, s, p, x, T, eps, fracs)
            if h:
                return (k, s, p, x, c) + h
    return None

def sed(host, reach, T, eps, plus=False, fracs=FRACS):
    """Activity-mediated positive component (optional strengthening ledger): (A) the oriented component is > eps; (B) under the same setting, the total difference is effective and the A branch is effective.
    plus: additionally requires that setting the whole of T shallower by each frac < 1 makes the oriented component strictly smaller (self-reinforcement ledger; not a universal claim over all subsets)."""
    for (w, s) in reach:
        y = host.act(w, s)
        for (p, x, c) in host.comps(w, y, s):
            if x not in T:
                continue
            c = comp_of(host, w, y, s, p, x)
            if host.orient[x] * c <= eps:
                continue
            ok = False
            for (U, f, w2) in settings(host, w, T, fracs):
                A, D, tot = branches(host, w, w2, s, p, x)
                if abs(tot) > eps and abs(A) > eps:
                    ok = True
                    break
            if not ok:
                continue
            if not plus:
                return (s, p, x, c)
            good = True
            for f_ in [f_ for f_ in fracs if f_ < 1]:
                w2 = setT(host, w, T, f_)
                if not host.orient[x] * total_comp(host, w2, s, p, x) < host.orient[x] * c:
                    good = False
                    break
            if good:
                return (s, p, x, c)
    return None

def net_deep(host, w, protocol, T, eps):
    """Actual net deepening: applying the protocol increases the oriented depth of some position in T by > eps. Returns [(x, before, after)]."""
    w2 = dict(w)
    for s in protocol:
        w2 = host.step(w2, s)
    return [(x, depth(host, w, x), depth(host, w2, x)) for x in T if depth(host, w2, x) - depth(host, w, x) > eps]

def reach_pairs(host, hists):
    out = []
    for h in hists:
        S = run(host, host.init, h)
        for k, s in enumerate(h):
            out.append((S[k], s))
    return out

class UF:
    def __init__(self, items):
        self.p = {i: i for i in items}
    def f(self, i):
        while self.p[i] != i:
            self.p[i] = self.p[self.p[i]]
            i = self.p[i]
        return i
    def u(self, a, b):
        ra, rb = self.f(a), self.f(b)
        if ra != rb:
            self.p[rb] = ra

def _act_dep(host, w, w2, s, eps):
    y0, y1 = host.act(w, s), host.act(w2, s)
    return [j for j in y0 if abs(y0[j] - y1[j]) > eps]

def org_graph_exact(host, w, E, probes, eps, fracs=FRACS):
    """Exact enumeration: finds dependences over all nonempty subsets of E × depth multiples (the declared family of joint settings).
    Co-participation hyperedge: a minimal subset U that changes activity component j (a hyperedge when |U| ≥ 2; when |U| = 1, merged into the single-position dependence group of the same j).
    History-condition hyperedge: a minimal subset U that changes the total component acting on x, together with x. Returns (list of hyperedges, connected components)."""
    E = list(E)
    hyper = set()
    for s in probes:
        y0 = host.act(w, s)
        changed = {}
        for (U, f, w2) in settings(host, w, E, fracs, joint=True):
            for j in _act_dep(host, w, w2, s, eps):
                changed.setdefault(('act', j), set()).add(U)
            for (p, x, c) in host.comps(w, y0, s):
                if x not in E:
                    continue
                tot = total_comp(host, w2, s, p, x) - comp_of(host, w, y0, s, p, x)
                if abs(tot) > eps:
                    changed.setdefault(('w', p, x), set()).add(U)
        for key, Us in changed.items():
            mins = [U for U in Us if not any(set(V) < set(U) for V in Us)]
            if key[0] == 'act':
                singles = sorted({U[0] for U in mins if len(U) == 1})
                if len(singles) >= 2:
                    hyper.add(('co-participation', key[1], tuple(singles)))
                for U in mins:
                    if len(U) >= 2:
                        hyper.add(('co-participation', key[1], tuple(sorted(U))))
            else:
                x = key[2]
                for U in mins:
                    nodes = tuple(sorted(set(U) | {x}))
                    if len(nodes) >= 2:
                        hyper.add(('history condition', key[1] + '@' + x, nodes))
    uf = UF(E)
    for (_k, _n, nodes) in hyper:
        for a in nodes[1:]:
            uf.u(nodes[0], a)
    comps = {}
    for i in E:
        comps.setdefault(uf.f(i), []).append(i)
    return sorted(hyper), sorted([sorted(v) for v in comps.values()])

def org_graph_sample(host, w, E, probes, eps, tested, fracs=FRACS):
    """Bounded sampling: settings are made only on tested (a list of subsets). Returns (witness hyperedges, coverage gaps: position pairs not jointly covered by any tested subset; being covered does not mean being identified)."""
    hyper = set()
    for s in probes:
        y0 = host.act(w, s)
        for U in tested:
            for f in fracs:
                w2 = setT(host, w, U, f)
                if w2 == w:
                    continue
                for j in _act_dep(host, w, w2, s, eps):
                    hyper.add(('co-participation', j, tuple(sorted(U))))
                for (p, x, c) in host.comps(w, y0, s):
                    if x in E and abs(total_comp(host, w2, s, p, x) - comp_of(host, w, y0, s, p, x)) > eps:
                        hyper.add(('history condition', p + '@' + x, tuple(sorted(set(U) | {x}))))
    covered = set()
    for U in tested:
        for a in U:
            for b in U:
                covered.add((a, b))
    unknown = [(a, b) for a, b in combinations(sorted(E), 2) if (a, b) not in covered]
    return sorted(hyper), unknown

def basins(F, chain):
    """F (a dict) is a map on chain, a finite totally ordered chain. Returns {fixed point: [its basin of attraction (the points whose limit is that point)]}."""
    out = {}
    for d in chain:
        x, seen = d, set()
        while F[x] != x:
            if x in seen:
                x = None
                break
            seen.add(x)
            x = F[x]
        out.setdefault(x, []).append(d)
    return out

def order_rel(a1, a2):
    return (a1 > a2) - (a1 < a2)

def order_conflicts(pairs):
    """Returns the point pairs whose order relations under q and e disagree (including equality mismatches in both directions)."""
    bad = []
    for i in range(len(pairs)):
        for j in range(i + 1, len(pairs)):
            (q1, e1), (q2, e2) = pairs[i], pairs[j]
            if order_rel(q1, q2) != order_rel(e1, e2):
                bad.append((pairs[i], pairs[j]))
    return bad

def fstr(x):
    if isinstance(x, Fr):
        return str(x.numerator) if x.denominator == 1 else '%d/%d' % (x.numerator, x.denominator)
    return str(x)

def avail_at(host, states, k, T, eps, k_form=None):
    """Available bearing positions at beat k: the positions in T whose oriented depth is > eps in the pre-beat state states[k] of beat k.
    states[k] results from the writes of the earlier beats, so its threshold crossing means the trace was left before beat k; if the crossing dates from states[0] (above threshold at the start),
    its formation needs a separate record (the counterpart of ENT in [S3]), which this function does not certify; here the program verifies only that the trace was numerically “already left”.
    Window-end membership in T is not used for this judgment."""
    return [x for x in T if depth(host, states[k], x) > eps]

def hc_status(host, w, s, proc, x, U_av, eps, fracs=FRACS):
    """Three values of the history condition on one beat and one process (over the family of legitimate settings that change only the available positions U_av, joint settings included):
    'effective difference certified': some setting makes the total component difference > eps; 'functional support established': some setting makes the total component difference ≠ 0 but none makes it > eps;
    'effective difference not certified': the total component difference is identically 0 over the tested setting family (this is only a reading within a finite setting family, not a complete negation)."""
    best = None
    nonzero = False
    for (U, f, w2) in settings(host, w, U_av, fracs, joint=True):
        A, D, tot = branches(host, w, w2, s, proc, x)
        if abs(tot) > eps:
            return 'effective difference certified', (U, f, A, D, tot)
        if tot != 0:
            nonzero = True
            best = (U, f, A, D, tot)
    if nonzero:
        return 'functional support established', best
    return 'effective difference not certified', None

def hdyn_cert(host, states, sigs, T, eps, fracs=FRACS):
    """Act and history difference on the same beat and the same process: Act = the total component c of that process on x ∈ T at that beat has |c| > eps;

def solve(A, b):
    """Gaussian elimination over the rationals."""
    n = len(A)
    M = [list(A[i]) + [b[i]] for i in range(n)]
    for c in range(n):
        piv = next(r for r in range(c, n) if M[r][c] != 0)
        M[c], M[piv] = M[piv], M[c]
        pv = M[c][c]
        M[c] = [v / pv for v in M[c]]
        for r in range(n):
            if r != c and M[r][c] != 0:
                fct = M[r][c]
                M[r] = [M[r][k] - fct * M[c][k] for k in range(n + 1)]
    return [M[i][n] for i in range(n)]

# ---------- Theorem 17-1: robust window of geometric self-decay ----------
def first_below(A, lam, eps):
    """Smallest t ≥ 0 with A·lam^t ≤ eps."""
    t, v = 0, A
    while v > eps:
        t += 1
        v = v * lam
    return t

def last_above(a, lam, eps, cap=100000):
    """Largest t ≥ 0 with a·lam^t > eps (when a > eps); returns -1 if a ≤ eps."""
    if a <= eps:
        return -1
    t, v = 0, a
    while v * lam > eps and t < cap:
        t += 1
        v = v * lam
    return t

def window_geo(lams, a, A, eps):
    """Self-decay rates lams of the modes, write amplitudes ∈ [a, A]. For each mode, find the endpoints that fix, at every window length t, whether it is “surely retained” or “surely not retained”;
    returns a dict mapping each mode k to (t_f(k), t_s(k)): the first t from which k is surely not retained, and the last t at which k is surely retained (−1 if none); the robust window [t_lo, t_hi] is read off as the largest t_f in the fast group and the smallest t_s in the slow group.
    Surely retained: a·lam^t > eps; surely not retained: A·lam^t ≤ eps; all others are “amplitude-dependent”."""
    return {k: (first_below(A, l, eps), last_above(a, l, eps)) for k, l in lams.items()}

# ---------- Theorem 17-3: digit wheel ----------
def digit_wheel(n=10):
    """Digit wheel: carrier states 0..n−1, formation write (advance by one step) w(k) = (k + 1) mod n. Returns the orbit starting from the ground state 0."""
    orb, k = [0], 0
    while True:
        k = (k + 1) % n
        if k == 0:
            break
        orb.append(k)
    return orb

def k3_possible_on_orbit(orb, n):
    """Whether the orbit admits a depth function satisfying K1 (depth 0 at the ground state, > 0 elsewhere) and K3 (formation writes do not decrease depth).
    The write at the last point of the orbit returns to the ground state: K3 requires δ(0) ≥ δ(last point) > 0, contradicting K1. Returns (possible?, point of contradiction)."""
    last = orb[-1]
    if (last + 1) % n == orb[0]:
        return False, (last, orb[0])
    return True, None

# ---------- Lemma 17-3′: order conflict between two probes ----------
def probe_orders(states, e1, e2):
    """Returns a pair of states on which the orders induced by e1 and e2 conflict (None if there is no conflict)."""
    for u in states:
        for v in states:
            if e1(u) < e1(v) and e2(u) > e2(v):
                return (u, v)
    return None

# ---------- Theorem 17-7′: short-beat certificate for the continuous class (polynomial systems, exact integration of the knockout difference) ----------
def pint(coefs, y0, c, h):
    """∫_0^h P(y0 + c s) ds, P a polynomial (coefficients from low to high degree). Exact."""
    # Expand P(y0 + c s) as a polynomial in s
    from math import comb
    deg = len(coefs) - 1
    sc = [F(0)] * (deg + 1)
    for k, a in enumerate(coefs):
        for j in range(k + 1):
            sc[j] += a * comb(k, j) * (y0 ** (k - j)) * (c ** j)
    return sum((sc[j] * h ** (j + 1) / (j + 1) for j in range(deg + 1)), F(0))

def pval(coefs, y):
    return sum((a * y ** k for k, a in enumerate(coefs)), F(0))

def pder(coefs):
    return [k * coefs[k] for k in range(1, len(coefs))]

def sup_abs_quad(coefs, lo, hi):
    """Supremum of |P| on [lo, hi] for a polynomial of degree at most two (endpoints and vertex)."""
    cands = [lo, hi]
    if len(coefs) == 3 and coefs[2] != 0:
        v = -coefs[1] / (2 * coefs[2])
        if lo <= v <= hi:
            cands.append(v)
    return max(abs(pval(coefs, t)) for t in cands)

def cert_continuous(fm, g, c, y0, delta, h):
    """System y' = c, x' = f_m(y) + g(y); f_m and g are polynomials of degree at most two. Process m reads the Trace-Response y and acts on x.
    Knockout difference Δ_m^h(y0) = x_full(h) − x_{−m}(h) = ∫_0^h f_m(y0 + c s) ds (exact).
    Setting response R = Δ_m^h(y0 + δ) − Δ_m^h(y0).
    Error bound B = h²·(L·M + L'·M'): L and M are the Lipschitz constant (max norm) and the supremum of the full-system field on the convex-hull box,
    L' and M' are those of the knockout system. Returns a dict."""
    lo = min(y0, y0 + delta, y0 + c * h, y0 + delta + c * h)
    hi = max(y0, y0 + delta, y0 + c * h, y0 + delta + c * h)
    full = [a + b for a, b in zip(fm + [F(0)] * (3 - len(fm)), g + [F(0)] * (3 - len(g)))]
    gg = g + [F(0)] * (3 - len(g))
    L = sup_abs_quad(pder(full) + [F(0)], lo, hi)
    M = max(abs(c), sup_abs_quad(full, lo, hi))
    L2 = sup_abs_quad(pder(gg) + [F(0)], lo, hi)
    M2 = max(abs(c), sup_abs_quad(gg, lo, hi))
    B = h * h * (L * M + L2 * M2)
    D0 = pint(fm, y0, c, h)
    D1 = pint(fm, y0 + delta, c, h)
    R = D1 - D0
    lin = h * (pval(fm, y0 + delta) - pval(fm, y0))
    return {'R': R, 'lin': lin, 'B': B, 'err': abs(R - lin), 'fires': abs(R) > B,
            'fdiff': pval(fm, y0 + delta) - pval(fm, y0)}

# ---------- Theorem 17-8′: counterexample evaluation for cross-record chain joining ----------
def chain_eval(h_link, g_link, bypass, T1, T2):
    """Write component on the target instance: c(T) = g(h(T)) + bypass(T). Returns (c(T1), c(T2))."""
    return g_link(h_link(T1)) + bypass(T1), g_link(h_link(T2)) + bypass(T2)

# ---------- Theorem 17-6′: cycle map ----------
def cycle_map(host, d, cycle):
    w = {'d': d}
    for s in cycle:
        w = host.step(w, s)
    return w['d']

def cert_short(fm, g, c, y0, delta, h, r_phi=F(0)):
    """Theorem 17-7′: errors reported separately.
    Model error (first-order expansion of the flow): E_mod = h²(LM + L′M′); reading error: each of the four raw flow readings ≤ r_phi,
    each of the two knockout differences ≤ 2 r_phi, the final response ≤ 4 r_phi. Rule for a verdict of 1: |R_obs| > E_mod + 4 r_phi (the finite-difference verdict f(s′) ≠ f(s) is issued first).
    Completeness threshold: K = LM + L′M′, the coefficient of E_mod; when K = 0 the certificate is complete for all h (no division is performed)."""
    r = cert_continuous(fm, g, c, y0, delta, h)
    K = r['B'] / (h * h)
    r['K'] = K
    r['bud_read'] = 4 * r_phi
    r['fires_read'] = abs(r['R']) > r['B'] + 4 * r_phi
    if r['fdiff'] == 0:
        r['h_complete'] = None
    elif K == 0:
        r['h_complete'] = 'all'
    else:
        r['h_complete'] = abs(r['fdiff']) / (2 * K)
    return r

def exp_bracket(h, N=12):
    """Rational lower and upper bounds for e^h − 1 (0 < h ≤ 1/2): the partial sum, with remainder ≤ 2·h^{N+1}/(N+1)!."""
    from math import factorial
    s = sum((h ** k / factorial(k) for k in range(1, N + 1)), F(0))
    return s, s + 2 * h ** (N + 1) / factorial(N + 1)

def cyclemap_welldef(host, states_by_depth, cycle, key):
    """Well-definedness check for the cycle map: whether several reachable states with the same depth key(w) have the same depth after one cycle."""
    outs = {}
    for w in states_by_depth:
        w2 = dict(w)
        for s in cycle:
            w2 = host.step(w2, s)
        outs.setdefault(key(w), set()).add(key(w2))
    return {k: v for k, v in outs.items() if len(v) > 1}

# ---------- Theorem 17-8′: chain nonzeroness, threshold crossing and actual action proven separately ----------
def chain_certificate(y1m, y2m, r1, grid_meas, r2, zeta, eps, full_component=False, bypass=None):
    """Certificate for the monotone-law class (write monotonically nondecreasing in the mediator), with the three items issued separately.
    Nonzero: there exist grid points a < b with y2m + r1 ≤ a and b ≤ y1m − r1 such that (ĝ(b) − r2 − ζ) − (ĝ(a) + r2 + ζ) > 0;
    threshold crossing: the same lower bound > eps (effective difference certified);
    actual action: the certified interval of the target's actual total component c(T1). G(y1) ∈ [ĝ(b) − r2 − ζ, ĝ(b′) + r2 + ζ], where b′ is the smallest grid point ≥ y1m + r1;
      full_component=True declares “G is the complete component” (to be proven separately: no other component at that beat and position, no clipping in effect);
      with bypass = (lower bound, upper bound), the interval of the total component is the G interval plus the bypass interval; when neither is given, actual action gets the verdict ⊥_Act.
      Act is certified when the lower end of the interval is > eps or the upper end is < −eps (a negative sign is effective shallowing, which is likewise action).
    Returns early when the two state intervals of record 1 overlap or there are too few grid points between them, recording ⊥ for both the difference and actual action: this is conservative for a sufficient procedure;
    this function does not exhaust all inputs under which actual action can be certified independently; an independently obtained Act certificate is declared separately."""
    lo1, hi1, hi2 = y1m - r1, y1m + r1, y2m + r1
    out = {'nonzero': False, 'over_eps': False, 'margin': None, 'act': '⊥', 'act_ok': False, 'interval': None}
    if hi2 >= lo1:
        out['v'], out['why'] = '⊥', '⊥_Chain(C3′): the two state intervals of record 1 overlap'
        return out
    pts = sorted(u for u in grid_meas if hi2 <= u <= lo1)
    if len(pts) < 2:
        out['v'], out['why'] = '⊥', '⊥_Chain(C3′): not enough grid points between the two state intervals'
        return out
    a, b = pts[0], pts[-1]
    margin = (grid_meas[b] - r2 - zeta) - (grid_meas[a] + r2 + zeta)
    out.update({'a': a, 'b': b, 'margin': margin})
    if margin > 0:
        out['nonzero'] = True
    if margin > eps:
        out['over_eps'] = True
        out['v'], out['why'] = '1', 'effective difference certified'
    elif margin > 0:
        out['v'], out['why'] = '⊥', 'nonzero proven, threshold crossing unproven'
    else:
        out['v'], out['why'] = '⊥', '⊥_Chain(C3′): insufficient cancellation margin'
    g_lo = grid_meas[b] - r2 - zeta
    ups = sorted(u for u in grid_meas if u >= hi1)
    g_hi = (grid_meas[ups[0]] + r2 + zeta) if ups else None
    if full_component:
        lo_t, hi_t = g_lo, g_hi
    elif bypass is not None:
        lo_t = g_lo + bypass[0]
        hi_t = (g_hi + bypass[1]) if g_hi is not None else None
    else:
        out['act'] = '⊥_Act: bypass base value not declared, and G not proven to be the complete component'
        return out
    out['interval'] = (lo_t, hi_t)
    if lo_t > eps:
        out['act'], out['act_ok'] = 'certified (positive)', True
    elif hi_t is not None and hi_t < -eps:
        out['act'], out['act_ok'] = 'certified (negative, effective shallowing)', True
    else:
        out['act'] = '⊥_Act: certified interval intersects [−ε, ε]'
    return out
