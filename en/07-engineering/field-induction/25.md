# The Possibility Form of Field Induction in Memristive Material Networks

## Section 1  Question and Strength

### 1.1  Question

The conductance of a memristive device is changed by the applied voltage and is retained, so the device is often regarded as a material synapse that can be “written.” Take the declared memristive crossbar model as the regulated field: can a goal-directed direct transformation of the host be given on it that satisfies the necessary structures listed in *The General Form of Host Adjustment*? Does it admit tuning?

### 1.2  Sole Task and Form Kind

Within the principal instance of the model 𝔐\_R declared in Section 2 and the frozen permitted class, we answer two questions: (1) it admits host adjustment — we give an explicit construction satisfying condition group C^R (Section 5); (2) whether it admits tuning — within the permitted class we give a negative answer (Section 6). The Form kind is Possibility Form: a principal form; (1) is a constructive proof of an existence assertion, and (2) is the refutation of an existence assertion.

### 1.3  Upper Bound of Strength

In this paper, “admits host adjustment” in (1) is limited to condition group C^R declared in Section 4: a goal-directed direct transformation of the host that satisfies the necessary structures listed in *The General Form of Host Adjustment* (the six duty groups of Field Induction, Rewrite, Bear\_R). *The General Form of Host Adjustment* proves only the necessary direction; the converse is unproved. This paper does not use the converse as a proxy proof and does not sign host-adjustment event qualification in the general sense.  
The conclusions reach only the principal instance χ\_R of 𝔐\_R (algorithmic level, model mode) and the frozen permitted class. They do not extend to: the other members of the declared parameter family; device models beyond the family conditions whose mapping has not been verified separately; arrays with external gating (such as row select transistors); any real memristive material. The qualification of real materials is kept as ⊥ (3.5).

## Section 2  Declared Model 𝔐\_R

### 2.1  Host and Running

A memristive crossbar array with n\_in rows × n\_out columns; the device conductances G\_ij ∈ \[lo, hi\] = \[0, 2\] are Structural Positions, with baseline b; the column nodes are integrate-and-fire comparator circuits. Algorithmic level, discrete beats, exact rational values (every nonzero component is an effective change). Each beat consists of, in order:  
　(1) row read pulses s\_i ∈ {0, 1} (determined by the letters A = (1, 0), B = (0, 1), AB = (1, 1), rest = (0, 0)); a teaching current I\_j is injected into the column (out-of-boundary);  
　(2) column capacitor integration ṽ\_j = λ·v\_j + Σ\_i G\_ij·s\_i + I\_j (with the pre-beat G);  
　(3) firing g\_j = \[ṽ\_j ≥ θ\]; (4) reset v\_j := 0 if g\_j = 1, and ṽ\_j otherwise;  
　(5) device voltage V\_ij = V\_pre·s\_i + bp·V\_post·g\_j;  
　(6) threshold-type state equation ΔG\_ij = α·\[V\_ij ≥ V\_set\] − β·\[V\_ij ≤ −V\_rst\] − ρ·(G\_ij − b), where ρ is volatile relaxation (with the pre-beat G), clipped to \[lo, hi\].  
bp ∈ {0, 1} is the column back-propagation pulse switch: a beat-wise or piecewise binary protocol frozen in advance (e.g., on during the formative part and off in a given qualification window); it is not a permitted port.  
Declared parameter family: V\_pre = V\_post = 1/2, V\_set = V\_rst = 1 (pulses are nonnegative, so the reset branch is never triggered); λ ∈ {0, 1/2, 3/4}, θ ∈ {1, 3/2}, α ∈ {1/8, 1/4, 3/8}, ρ ∈ {0, 1/16, 1/8}, b ∈ {1/4, 1/2}; bp ∈ {0, 1}.

### 2.2  Principal Instance χ\_R

n\_in = 2, n\_out = 1; λ = 1/2, θ = 1, α = β = 1/4, ρ = 1/8, b = 1/4; entry G = (G00, G10) = (1/4, 1/4), v = 0. Object domain B: 2 input rows, 1 column node, 2 devices; outside B lie the input stimulus sequence, the teaching current, and the actor's programming pulses.

2.3  Permitted Class and Event Protocol (Frozen)

The ports available to an act are exhausted by two:  
　Input port In: row pulse letters (one of the four) and the column teaching current I ∈ {0, 1};  
　Direct-write port Rw: the actor uses a programming pulse to write the conductance of a device directly to a declared value, landing on the Structural Position G\_ij.  
A direct write is an actual state transition between two beats: the dynamics step of the following beat (both the actual branch and the diagnostic branch) reads the post-write state. A direct write is not a component of the within-beat rules of 2.1 and is not merged into the potentiation component.  
Field Induction event protocol: bp = 1; the goal declaration is the goal conductance gol (out-of-boundary, written by a goal-setting event), with goal value 5/4; actor P; goal holder Xg; reading Φ := G00 (the host drive of the A pathway); the input class is the four declared letters with I ∈ {0, 1}. The direct-write port is the actor's landing point and does not change B, the field rules, or the levels.

## Section 3  Field-Concretization Qualification

### 3.1  Adjudication Path

𝔐\_R is a member of the event-gated class 𝒦\_g of *The Adjudication Form of Field Concretization for Candidate Hosts*. Mapping: eligibility-trace decay d\_x = d\_y = 0 (so x′ = s, y′ = g), A₊ = α, A₋ = 0, relaxation ρ, λ, and θ as given, v\_reset = 0, plastic = 1, bap = bp, baseline and interval as given.  
Sufficient conditions for the mapping (hereafter the family conditions): V\_pre \< V\_set and V\_post \< V\_set; when bp = 1, V\_pre + V\_post ≥ V\_set (the threshold is reached when a row pulse and the column back-propagation coincide); when bp = 0, the device voltage does not exceed V\_pre \< V\_set, and the potentiation component is identically zero. Under the family conditions, \[V\_ij ≥ V\_set\] = s\_i·g\_j·bp, and the state equation equals, term by term, the potentiation component, the relaxation component, and the clipping of Definition 2 of that paper.  
Finite check: within the declared family (including both values of bp, with teaching currents sampled from {0, 1/2, 1}), 400 random histories, 3840 beats in all, were compared beat by beat between a general form implemented independently from Definition 2 and 𝔐\_R, for G, v, and firing (with x′, y′ the mapped eligibility traces); there was not a single disagreement. Clipping took effect at 125 places, and the integral exactly equaled the threshold at 680 places. The sampled domain is wider than the event protocol of 2.3; the mapping holds for both.  
Beyond the sufficient conditions above, whether the mapping of this subsection holds must be verified separately; whatever lies beyond the range proved here is not covered by the adjudication path. For example, when V\_pre ≥ V\_set, a row pulse alone, without firing, can potentiate, which does not satisfy the firing-gated mapping given in this subsection; we sign only “not covered by the adjudication path” and do not assert that such a model lies outside 𝒦\_g. Conversely, a model beyond the sufficient conditions may still fit the mapping: when bp = 0, V\_pre = 1/2, and V\_post = V\_set = 1, the back-propagation term is identically zero, the device voltage V\_pre·s\_i \< V\_set, and the potentiation component is identically zero, the same as with bap = 0 in Definition 2.  
Intervention landing point: diagnostic settings follow LOC of 3.3 and Definition D-1 of that paper — a single-beat setting puts the conductances at available positions to rational values in \[b, hi\]; the legitimate witnesses used in this paper are taken on the 1/4 grid (starting from b = 1/4). A positive determination needs only one legitimate witness. On the program hosts of 𝒦\_g, what is set is a variable that the process actually reads (Lemma IMP-g of that paper). A diagnostic setting is not a permitted act and does not serve as a Field Induction witness.  
On the formation side, certification follows criterion PS of that paper: the potentiation component (PLUS) acting on the Structural Position at beat k is nonzero; with the field-entry components removed at the same beat, that PLUS is zero, and no firing is added. The net increment of the device (the sum of potentiation and relaxation) is reported separately as a comparison; it is not the certifying quantity of PS.

Replayed on the teaching protocol (A + teaching current 1) × 4: the Trace-Response version is G00\|1 (the device write at beat 1, whose source contains the input event); the integration at beat 2 reads in this version and actually changes ṽ; the successor version is G00\|2; path G00\|1 —value-write→ ṽ\|2 —value-write→ g —value-write→ G00\|2. With the mechanism undeclared, the verdict is ⊥.

3.4  Negative Cases and Boundaries (Analytic Adjudication)

No formation (no teaching current; A × 4 followed by the same window): the history contains only the letters A and rest, with I = 0. Suppose that before a beat G = (b, b) and 0 ≤ v \< 1/2. Then ṽ ≤ v/2 + 1/4 \< 1/2 \< θ: there is no firing, PLUS is zero, relaxation is zero since G = b, after the beat G is still (b, b), and v = ṽ ∈ \[0, 1/2). The entry satisfies the premise; induct on the number of beats. Throughout, no Structural Position departs from baseline, the maximal Trace-Response set is empty, and the Trace-Response set duty fails for every T: Fld = 0 (carrying the three antecedents of a declared intervention domain, an exhaustive mechanism inventory, and a faithful record).  
Nonvolatile (ρ = 0), with bp = 0 within the window: within the window the device voltage does not exceed 1/2 \< V\_set, so PLUS is identically zero; since ρ = 0, relaxation is zero; the reset branch is not triggered. No Structural Position has an effective event within the window, and the historical dynamics duty fails for every T: Fld = 0 (carrying the same antecedents as above).  
Volatile (ρ = 1/8), with bp = 0 within the window: within the window the only action on T is the device's own relaxation. Whether relaxation that reads the Trace-Response at its own position bears “action arising from the Trace-Response” has no reading fixed upstream; the verdict is ⊥, and it is not read as 0.  
The negative determinations above rest on analytic arguments; the absence of witnesses on a finite grid does not yield a negative determination on the continuous domain.

### 3.5  Real Materials

The verdict is ⊥. The model verdict adjudicates only 𝔐\_R; read-back to a material host requires the counterparts of implementation fidelity and model faithfulness (*The Adjudication Form of Field Concretization for Candidate Hosts*, 5.5), which are not given. The premise registered in *The Adjudication Form of Material Field Concretization*, “the reset network is the same as the original network,” is listed as a gap in physical verification. The threshold-type state equation is a declared idealization and does not correspond to measurements of any specific device.

## Section 4  Condition Group

Taken over from *The General Form of Field Induction* v1.0, *The General Form of Host Adjustment* v1.0, and *The General Form of Tuning* v1.0, numbered item by item, each item checkable on its own. The arguments are fixed as the same regulated field F := B′, goal holder Xg, actor P, act a, window W, input class, and reading Φ.

C^R-0 (Qualification)  B′ acquires Field-Concretization Qualification on the same history in which W lies and on the same T (the adjudication path of Section 3).  
C^R-1 (Six duty groups)  Org₀: at the entry of W, an established host organization bears Φ; GoalRep/Target: the goal declaration agrees with the target-pointing registry and points to B′; ΔΦ\_W ≠ 0: the net tendency difference within W is nonzero; Eff: P's act actually changes the state of B′ within W; Bear: the bearing of the tendency passes through P's actual act; GoalCond: the goal actually takes part, through a value-write chain, in determining P's act.  
C^R-2 (Rewrite)  At least part of P's act actually changes G\_ij at the host level through the direct-write port, listed separately from formation by signals.  
C^R-3 (Bear\_R)  The bearing of the tendency starts from this direct write: starting from the change the direct write leaves on B′, it takes part, through an actual route, in determining the organization that bears Φ within W.  
C^G-1 (Gate)  At least part of the act opens and closes existing pathways of V by suppression and disinhibition, adjusting their current permeability.  
C^G-2 (Bear\_G)  The bearing of the tendency originates in this gating change.  
Classification criterion: an action that only enters as signals and is processed by the field's own rules is input, and the subsequent change in the physical layer caused by the field rules is sedimentation; what directly transforms the physical layer is direct write. Parts are reported separately by actual landing point and route, not classified by source.

5.5  Existence Theorem (Admitting Host Adjustment)

Theorem 1  Under χ\_R, the frozen permitted class, and the event protocol of 2.3, there exists a goal-directed direct transformation of the host satisfying C^R-0–C^R-3: the history H\_R of 5.1.  
Proof: H\_R is a legitimate history within the permitted class of 2.3 (the inputs take the declared letters and I ∈ {0, 1}, and the actor's only direct write lands on G00). C^R-0: the three duties on the same W and the same T are given by the actual witnesses and legitimate settings of 5.2; the formation certification precedes the direct write, and retention spans it. C^R-3: the direct-write version enters the device write of beat 5 through the integration and firing of beat 5, and the organization bearing Φ within W (the successor versions of G00) all have this direct-write version as a source. Every item takes the same F, Xg, P, a, W, input class, and Φ as arguments. ∎  
Theorem 1 gives a witness that the listed necessary structures hold together on one concrete model history; it is not inferred backward from the necessary direction of *The General Form of Host Adjustment*, nor does it sign host-adjustment event qualification in the general sense.

## Section 6  Whether It Admits Tuning: Negation

### 6.1  Exhaustive Check of Gating Objects

Levels: G00 and G10 belong to the host level; v, ṽ, g, s, and I belong to the run level; gol is out-of-boundary. Variables of a dynamic permeability layer: none.  
Ports: the input port writes s and I; the direct-write port writes G. Gating port: none. bp is a protocol switch declared in advance, not an act port.  
Quantities read by transmission (integration): G00, G10 (host level); v, s0, s1, I (run level). The only permeability quantity of an existing connection ij is G\_ij; the read-out passes connection by connection only through G\_ij·s\_i, with no per-connection dynamic factor.  
Changing the input amplitude or removing a row signal is input control; the teaching current I is applied at the column node and processed by the node's own integration rule, so it is input as well. None of these lies on any connection, and none constitutes the patency of a connection.

### 6.2  Impossibility Theorem

Theorem 2  Under χ\_R and the frozen permitted class (input port, direct-write port), there is no act satisfying C^G-1; hence the principal instance of 𝔐\_R cannot serve as the regulated field of a tuning.  
Proof: Suppose the act a has a gating part a\_G. By 2.3, the landing point of a\_G on V can only be the input port or the direct-write port. If it is the direct-write port, it rewrites G\_ij at the host level; by the classification criterion this is direct write, not gating. If it is the input port, it is a signal that enters as input and is processed by the field rules; by 6.1, this route sets the current patency of no existing connection — the patency of connection ij is borne only by G\_ij, and G\_ij changes only through direct write or sedimentation. Hence a has no gating part, contradicting C^G-1. The result follows by the contrapositive of the necessary direction Tune ⇒ Gate of *The General Form of Tuning*. ∎  
Adding external gating, such as row select transistors, changes the declared boundary and the form of transmission (transmission then reads m·G, which is multiplicative); the result is another model. Its qualification and tunability must be proved separately and are not decided by Theorem 2.
