# 着色

酸甜苦辣咸，意象也；  
泔膻腥馊臭，亦意象也，而好恶出之。

朋亲侣子敬，关系之意象也；  
敌仇寇贼逆，亦关系之意象也，而亲疏出之。

人有好恶，以分亲疏；  
兽有好恶，以决趋避。

好恶附于意象，成之偏好；  
偏好者，好此而恶彼也；  
由是个性出焉。

情感者，观之加也；  
或加于此，或加于彼；  
见景生情，睹物思人，是之谓也。  
其间好恶生焉，偏好作焉，个性成焉。

故情感生，而好恶出；  
附于意象，胶着其上，若匹之着色，故曰着色。

好恶者，倾向也，偏也；  
由偏而行，或趋或避，是谓趋避，此着色之用也。

既谓情感，既谓情之可感也，既可感则可现，故为意象，故其必有专属自显回路，称之谓着色回路。

着色回路，其不独用，而与其它回路并作。  
其生成着色意象于意象场，着色于其它回路之意象。  
有喜欢 / 厌恶 / 亲近 / 回避 / 紧张 / 安全等，此情感之线也，倾向之度也，好恶分立两端，为着色经验场所差分焉。  
其出，生偏流，达于经验靶，入界门，此常开之门，为观界之守司，令现实着以情色，增益倾向于其所欲决，调其意向之所欲去也。

故常有非理性之言行，此之谓也。

生物之思考经验也有限，因是善用其着色之能，加诸倾向于其所行。  
故兔见狼则逃，惧也；蜂见花则近，好也。故得以趋避。

婴儿见屎而不知其臭，把玩而不避，及长而掩其鼻，吾于是知着色意象，乃为后渐生。其或有生之具来之好恶，则承之于父。

音乐，电影，故事，百感随其演义而转于其间，情感以模式沉积于着色场之内，复用渐深，疏朋渐淡，此音乐家之所以易感动也。

是故，cj曰：着色回路，乃倾向状态之系统也，底智之生物而欲存，则不可失之者也。人若失之，虽知万策，而不能择其一也。
