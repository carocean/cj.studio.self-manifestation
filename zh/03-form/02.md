自显论·式篇第二 v1.1

# 物化极限式

〔v1.1 说明：本版相对 v1.0 不改动任何数学论证（压缩必然性、等价类、截断、复用的鸽巢式证明全部保留且本就成立），只做三处精度对齐，起因是式篇第一升级到 v2.0 后产生的术语落差。三处为：(一) 第五节”稳定性出现”中的”稳定”正名——本篇的”稳定”是集合论意义（无限重访的等价类），与式篇第一 v2.0 的动力学稳定（δ\* 不动点涌现）是两个层级，本版明确切开，防止读者拿本篇去填式篇第一的缺口二；(二) 第五节量词精确化为实际状态序列上的无限鸽巢；(三) 打通与式篇第一 v2.0 附 1 的互引——两者是同一个鸽巢，本篇是其原始出处。〕

一、基本设定

设系统 S 满足：

1\. 输入为跨时间序列 F(1), F(2), …, F(t)  
1\. 输入历史记为 hₜ = (F(1), …, F(t))  
1\. 所有可能历史构成集合 𝓗ₜ  
1\. 状态空间为 R，且 \|R\| \< ∞  
1\. 状态由映射给出：Mₜ : 𝓗ₜ → R

当输入持续产生新信息时，随 t 增长，\|𝓗ₜ\| 严格增长，且对充分大的 t，有：

\|𝓗ₜ\| \> \|R\|

二、压缩必然性

由于 Mₜ : 𝓗ₜ → R，且 \|𝓗ₜ\| \> \|R\|，映射不可能为单射，故必有：

∃ h₁ ≠ h₂，使得 Mₜ(h₁) = Mₜ(h₂)

因此：系统必然对历史发生多对一映射，即压缩不可避免。

三、压缩定义

若存在 h₁ ≠ h₂ 使 Mₜ(h₁) = Mₜ(h₂)，则称映射 Mₜ 对历史发生压缩；不发生压缩 ⟺ Mₜ 为单射。

四、等价类结构

对任意 r ∈ R，定义：

O(r) = { h ∈ 𝓗ₜ ∣ Mₜ(h) = r }

即：系统将历史划分为若干等价类，每一状态 r 对应一类历史集合 O(r)。

五、重复命中结构的出现（v1.1 正名：原”稳定性出现”）

【术语声明（v1.1 新增，关键）】本节及全篇所称”稳定”，是集合论意义的稳定：某状态 r\* 在系统实际运行中被无限次重复命中，对应的等价类持续重现。这与式篇第一 v2.0 所证的动力学稳定不是同一概念——后者指沉积度 δ 收敛到吸引不动点 δ\*，需要条件组 H（积深退散竞争的不动点存在与收敛）。本篇的”重复命中”处于式篇第一 v2.0 链条中的缺口一层面（连续流→重复命中），不触及缺口二（重复命中→δ\* 涌现）。换言之：本篇证明某状态被无限次重访，但”该状态对应的沉积结构是否动力学稳定”不在本篇范围。为避免混淆，本版将原文的”稳定结构”改称”重复命中结构 / 重复命中等价类”。

论证（v1.1 量词精确化）：考察系统实际经历的状态序列 r₁, r₂, r₃, …，其中 rₜ = Mₜ(hₜ)，hₜ 为系统在时刻 t 实际经历的历史（不是任意可能历史）。该序列是无限序列（由第一节设定：输入持续产生新信息、t 无限增长，系统持续响应，故状态序列无限），每一项取值于有限集合 R（第一节设定 \|R\| \< ∞）。由无限鸽巢原理（无限序列取值于有限集合，必有某值被取到无限多次），存在 r\* ∈ R，使得在无限多个 t 上 rₜ = r\*。

因此：存在 r\*，在无限多个 t 上 Mₜ(hₜ) = r\*——该等价类即形成重复命中结构。

（注：此处只断言”无限次重复命中”，这是纯组合事实，无条件成立。它不断言该重复命中所对应的沉积结构是动力学稳定的——那是式篇第一 v2.0 缺口二的内容，需条件组 H。）

六、截断性质

若系统当前决策显式依赖完整历史 hₜ，则其处理对象规模随 t 增长。若系统需在有限时间内完成更新与响应，此种依赖不可能无限扩张。因此系统当前决策只能依赖：

rₜ = Mₜ(hₜ)

即：历史进入当前时，必经映射而被截断为有限状态。

七、复用必然性

由于 \|R\| \< ∞ 且 \|𝓗ₜ\| 随时间增长，不可能为每一不同历史分配独立状态，故必有：

∃ h₁ ≠ h₂，使 Mₜ(h₁) = Mₜ(h₂) = r

即：状态必然被重复使用，结构复用不可避免。

八、主结论

在以下条件同时成立：

1\. 输入历史持续增长  
1\. 状态空间有限  
1\. 系统需在有限时间内持续响应

则必然有：历史被压缩、历史被截断、状态被复用、等价类结构形成、重复命中结构出现（集合论意义，见第五节术语声明）。

九、唯一性结论

若设存在映射 Nₜ : 𝓗ₜ → R，使 h₁ ≠ h₂ ⇒ Nₜ(h₁) ≠ Nₜ(h₂)，则 Nₜ 为单射。但当 \|𝓗ₜ\| \> \|R\| 时，单射不可能存在，故该设不成立。

因此：不存在无需压缩（即保持单射）的系统。

（说明：本节证的是”压缩不可避免”——即无单射映射，这是第二节结论的等价重述。重复命中结构的形成是另一回事，由第五节的无限鸽巢另行证出，不由本节给出。v1.0 原文此处结论写作”不存在无需压缩而形成稳定结构的系统”，把第二节所证的压缩与第五节所证的重复命中混在一句里；v1.1 将本节结论收回到它实际所证的范围——压缩必然，不越界到重复命中的形成。）

十、最简表达

O(r) = { h ∈ 𝓗ₜ ∣ Mₜ(h) = r }

十一、解释（降级说明，不入结构）

O(r) 对应”原有”；对象为对 O(r) 的认知指认。

十二、最终结论

系统在有限状态约束下，必然通过对历史的压缩与截断，形成重复命中的等价类结构。

十三、与式篇第一 v2.0 的衔接（v1.1 新增）

本篇与式篇第一 v2.0 附 1（重复命中定理）是同一个鸽巢论证的两次出现，此前互不引用，构成体系内失联。现打通：

其一，本篇是该鸽巢论证的原始出处。式篇第一 v2.0 附 1 用”有限结构位承接持续输入流，必有位被重复命中且无界”闭合其缺口一，所用的正是本篇第二、五、七节的压缩—重复命中论证。附 1 应引本篇为出处，本篇在此声明这一关系。

其二，本篇在式篇第一 v2.0 链条中的精确位置：完整链条是「连续流 →〔缺口一：重复命中〕→ 重复结构 → 迹应累积 → 积深 →〔缺口二：δ\* 涌现〕→ 动力学稳定」。本篇覆盖的是缺口一层面——它证明重复命中（等价类被无限重访）无条件成立。本篇不触及缺口二：从”被无限次命中”到”该位沉积度收敛到 δ\* 而动力学稳定”，需要式篇第一 v2.0 附 2 的条件组 H，不在本篇。

其三，由此明确两个”稳定”的分工：本篇的稳定 = 状态层的重复命中（无条件，组合事实）；式篇第一 v2.0 的稳定 = 沉积层的 δ\* 不动点（条件式，需 H）。前者是后者的必要前置（无重复命中则无持续积深），但不是充分——重复命中之上还需积深退散竞争收敛，才有动力学稳定。本篇到此为止，不越界。

版本说明（v1.0 → v1.1）  
一、数学论证零改动：压缩必然性（第二节）、等价类（第四节）、截断（第六节）、复用（第七节）、唯一性（第九节）全部保留，本就由鸽巢/单射不可能性严格成立。  
二、第五节”稳定”正名为”重复命中结构”，新增术语声明，明确本篇”稳定”为集合论意义（无限重访），与式篇第一 v2.0 动力学稳定（δ\* 不动点）切开；第八、九、十二节”稳定结构”相应改为”重复命中结构/等价类”。  
三、第五节量词精确化：由含糊的”∃ hₜ 使 Mₜ(hₜ)=r\*“改为实际状态序列上的无限鸽巢（无限序列取值于有限集必有值被无限次取到）。  
四、新增第十三节，打通与式篇第一 v2.0 附 1 的互引，标定本篇在缺口一层面、不触及缺口二。  
五、终审修订：第九节结论原 v1.0 作”不存在无需压缩而形成稳定结构的系统”，v1.1 改词时机械替换为”无需压缩而形成重复命中等价类”，使结论与该节实际所证错位——第九节用单射不可能性证的是”压缩必然”（第二节结论的重述），不证”重复命中等价类的形成”（那是第五节无限鸽巢另证）。现将第九节结论收回到”不存在无需压缩（保持单射）的系统”，并加说明区分两节所证。  
六、定位：本版为精度对齐版（v1.1），非奠基升级——本篇主体数学本就成立，升级仅在术语精度与体系衔接。
