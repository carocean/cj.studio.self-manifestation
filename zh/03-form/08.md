自显论·式篇第八v2.1

# 误外化极限式

本篇试论一个总命题:

“在外”这一归属结果的生成机制不可还原——任何能够形成并维持”s 为外来”的机制,必然实现误外化结构的全部功能项;直接读取、确定映射、随机过程、并列归属、结构自带与静态集合六类最常见的替代方案,各因缺失至少一项功能或与前提冲突而不能实现它。

本篇与误外化一般式(式篇第七 v2.1)的分工:

式篇第七给出两件东西:构造(形成”s 为外来”的六元结构 Externalization(s) = (E, X, Δₛ, Ʃₛ, Λₛ, Kₛ))与全称必要性(任何能形成并维持来源归属的系统必含该极小完备集,其总定理)。本篇承接后者,把全称必要性落到六类最常见的替代方案上逐一检验:每一类的失败方式,正是某项必要功能的缺失方式,或是与自显结构的前提直接冲突。完备性由全称定理承担,本篇的排除提供其实例验证。

需要预先说明结论的逻辑来源,以免误读:”‘在外’只能由误外化结构生成”这一全称结论(见第十六节),不是由排除六类机制推出的——机制空间不可枚举,非穷举排除推不出全称结论。它的来源是式篇第七总定理的功能必要性:对任何能形成并维持来源归属的系统的全称量化。本篇的六类排除是该全称定理的诊断性实例。

一句话

观者极限式证明当前的生成别无他途;本篇证明”在外”别无来源——它不是被读到的,不是被算出的,不是被抽中的,不是自带的,而是被构造的。

一、基本设定

设系统在时刻 t 的当前结构为 sₜ ∈ S。

锚定:sₜ 为该时刻被维持为占据态的收束意象;其成分共同为一由观者一般式义务 I 无条件给出,其存在与唯一性则依池级当前单值原则(构成性承诺,未证,允许经验击穿)。本篇所实需者为前者(sₜ 是单一收束形态),后者只在需断言存在性处引用。来源归属仅在显现层上定义(式篇第二十二下游衔接节)。本篇工作域为恰一区(”恰一”依上述承诺)且归属需求成立的系统(归属需求的条件与边界见式篇第七第三节、反例四)。

设其来源解释集合为 Ʃₜ ⊆ P,满足:

\|Ʃₜ\| ≥ 2,且来源缺口成立:Δₜ(Ʃₜ) ≠ ∅(式篇第七定义一——存在不同路径在系统全部可用判定函数下不可区分)。

且:Ʃₜ 由 E(sₜ) 所生成或限定,不作为外部输入变量。

设来源归属结果为:

lₜ ∈ L = {l内, l外}

该结果不预设为已有函数输出,而视为待生成结果。

归属的唯一性与稳定性不作为公理设定:由式篇第七 v2.1 第三节,被维持的归属恰一份(载体层:被维持的当前是单一收束形态,其成分非并列的独立占据者,故载体为这一个形态——观者一般式义务 I 与观者数理式整合运行;形态层:标签维是收束形态的组成维度,单一平衡对二值维度至多一个被维持赋值;逻辑层:l内 ≔ ¬l外,二值互否),其稳定区间落在 sₜ 的占据维持区间之内。本篇直接引用该继承,记被维持的归属为 l\*ₜ。

二、问题定义

在来源解释集合 Ʃₜ 中,多个来源路径均可与当前结构 sₜ 相容。

系统在该时刻对 sₜ 形成来源归属,且被维持的归属恰一份(由第一节继承)。

因此存在一个对 sₜ 生成 l\*ₜ 的过程(其完整依赖见第十节函数形)。

该过程不涉及结构 sₜ 是否存在,而涉及:在多个可相容来源中,何者被归属为 sₜ 的来源性质。

本篇要确定的是:实现这一生成过程的机制,属于哪一类;不属于哪一类。

三、排除路径一:直接读取外部

设系统可直接读取真实外部域 Ω,即存在 f : Ω → L,使 l\*ₜ = f(Ω)。

此路径与自显结构的前提双重冲突。

其一,通道不存在。在自显结构中,系统所直接可得者仅为当前结构 sₜ 及其内部条件,而非独立于结构之外的真实外部域 Ω。

其二,类型层的不可能。系统可实现的判定函数定义于系统可得对象之上:f ∈ Fₛ,f : P × Cₛ → D(式篇第七附录第二节)——定义域为路径表征与当前条件。而 Ω 按定义为独立于一切结构的真实外部域,非系统可得对象;f(Ω) 在类型上即无定义。直接读取不是失败的尝试,而是无法写下的函数。

其三,转译层的辅证。Ω 的任何影响要进入系统,必先经候选化转译为池内结构;转译所得已是与 sₜ 同级的内部结构——它本身又成为来源归属的对象,而非”外部本身”。注意观界定理在此的正确适用范围:式篇第二十二定理二的后承作用于池内结构集(界外结构不能以内容身份越界,只能经由变界);Ω 不在池内结构集中,故该定理不直接施加于 Ω,而是施加于其转译物的准入——“读取到的”永远只能是已入界的转译物,不可能是 Ω 本身。

因此:¬∃ f : Ω → L 使 l\*ₜ = f(Ω)。

直接读取类被排除。其定位:非功能缺失,而是类型层的不可能(主依据)与转译必经性(辅依据)的合取——这一类不是失败的机制,而是不存在的通道。

四、排除路径二:确定映射

设当前显式条件为 Γₜ,若存在 f : Γₜ → L 使 l\*ₜ = f(Γₜ),则来源归属完全由 Γₜ 决定。

但由第一节,来源缺口成立:存在不同路径在系统全部可用判定函数下不可区分。故不存在在 Γₜ 下单值可定义的区分函数:

¬∃ f : Γₜ → L 使 l\*ₜ = f(Γₜ)

确定映射类被排除。其缺失项定位:X 不具独立性——若归属可由 Γₜ 单值给出,则任何偏置均可还原为当前显式条件的展开项,而归属偏置的定义恰恰要求其在来源缺口下提供 Γₜ 之外的压缩依据(式篇第七定义四、附录第四节非退化性)。故 X 功能性缺席,且与来源缺口前提直接冲突(对应式篇第七总定理 X 项)。

五、排除路径三:随机或不稳定过程

设 l\*ₜ \~ P(L),即来源归属由随机抽取给出。

随机过程不具归属稳定性:不存在 Δt \> 0,使 ∀ τ ∈ \[t, t+Δt\],l\_τ = l\*ₜ。每一时刻的重新抽取都可能更换标签,所谓”在外”退化为标签波动,不构成被维持的归属。

进一步,凡标签随时间在两值间切换而无稳定区间者——无论其切换由抽取、噪声还是竞争振荡造成——均归入本类:无稳定 τ 即无被维持的归属。

随机或不稳定过程类被排除。其缺失项定位:无归属收束 Kₛ——抽取与振荡均不含把标签固化并维持于占据区间内的结构(对应式篇第七总定理 Kₛ 项;Kₛ 的动力学奠基见式篇第七第三节其二)。

六、排除路径四:并列归属

设同一结构 sₜ 同时持有 lₜ = l内 且 lₜ = l外。

此情形被两层独立地排除,任何一层单独成立即足够;两层均不引用任何”唯一归属约束”——在本版中不存在这样一条约束可供引用,唯一性是继承的后承,不是设定。

其一,形态层(动力排除)。由式篇第七第三节:标签维是收束形态的组成维度,被维持的形态是单一平衡。两份相互否定的被维持赋值,意味着标签维未完成收束、形态未达平衡——与 sₜ 为被维持的占据直接矛盾(占据即被维持的完成态;候选完成须于完成窗持续,见观者数理式定义四十五)。

其二,逻辑层。由二值互否结构 l内 ≔ ¬l外(误外化消解式第四节),lₜ = l内 ∧ lₜ = l外 即 lₜ = ¬lₜ,为逻辑矛盾,无需引用任何结构条件即被排除。

至于标签在两值间交替的情形,不属并列而属振荡,已由排除路径三处理。

并列归属类被排除。其定位:非机制缺失,而是动力不可能与逻辑矛盾的合取——这一类不是失败的机制,而是不存在的状态。

七、排除路径五:结构自带外在性

设”在外”为结构 sₜ 的固有属性,即存在 g : S → L 使 g(sₜ) = l\*ₜ。

但结构仅包含其存在内容,而不包含来源指派信息;来源归属属于对结构的附加判定,而非结构自性(式篇第七第二节)。

进一步,从顺序约束看:若标签先于判定而在,则归属被预设,Kₛ 先于 Λₛ——这违反式篇第七第七节(附录第七节)的必要顺序:归属映射先于归属收束;不存在先于 Λₛ 的 Kₛ 使某 l\* 对结构合法成立。

因此:¬∃ g : S → L 使 g(sₜ) = l\*ₜ。

结构自带类被排除。其缺失项定位:无归属映射 Λₛ 与判定过程——标签若为自性则无判定,无判定则极小完备集中 Λₛ 缺位,且顺序约束 Λₛ ≺ Kₛ 被违反(对应式篇第七总定理 Λₛ 项与顺序约束)。

八、排除路径六:来源集合的静态存在性

设仅依赖来源解释集合 Ʃₜ 的静态存在,即 Ʃₜ 中存在多个可相容来源路径。

但静态存在性仅保证”可解释”,不提供”归属压缩”:多个解释并存本身不产出任何标签,更不产出被维持的标签。

因此:Ʃₜ 的存在性 ⊬ 被维持的来源归属。

静态集合类被排除。其缺失项定位:无 Λₛ(无压缩)与无 X(无偏置)——解释集是判定的材料,不是判定本身(对应式篇第七总定理 Λₛ、X 两项)。

九、归属机制的必要存在

先给出严格可得的部分。由三至八,来源归属的生成不属于六类已排除机制;同时在本篇工作域内,归属确实形成(恰一区有被维持的占据者——”恰一”依池级当前单值原则之承诺;归属需求成立,且由式篇第七的构造,归属可被形成并维持)。因此:

必须存在一类实现来源归属的机制 Ψₜ,其输出满足:

Ψₜ(sₜ) = l\*ₜ

且 Ψₜ 不属于上述任一已排除类型。(此处签名为示意:Ψₜ 的完整依赖——Ʃₜ、X 及 E、Δₜ 的约束——见第十节函数形。)

到此为止,排除论证给出的只是”存在另一类机制”,不是”只能是误外化结构”——六类不穷尽机制空间,这一步不能越过。

全称结论由另一条路给出。式篇第七总定理对全体机制量化:任何能够形成并维持”s 为外来”的系统,必然同时具有 E, X, Δₛ, Ʃₛ, Λₛ, Kₛ,且满足 Λₛ ≺ Kₛ。而”误外化结构”的定义恰是这一功能组。因此,Ψₜ 的任何实现都是误外化结构——不是因为别的类都被点名排除了,而是因为该功能组对任务本身必要。

两条路在此汇合并互相检验:全称定理断言任何实现必含六元极小完备集;六类排除则逐一展示,每一被排除类恰好缺失其中至少一项,或与前提直接冲突(各路径末尾的定位)。排除不承担完备性,它为全称定理提供六个独立的实例验证。

十、结构定义与形式

定义该类映射为误外化机制。其实现所需结构,必包括:

E:生成并限定 Ʃₜ  
Δ:保证 Ʃₜ 上不存在可定义的区分函数  
X:提供归属偏置  
Λ:将多来源解释压缩为单一来源标签  
K:将该标签稳定为持续归属

Ψₜ 不应理解为 E、Δ、X、Λ、K 的函数复合——X 为在位偏置取值,Δₜ 为条件对象,均非映射,写入复合链即类型不通。其运作关系为:E 限定来源解释集,Δₜ 给出来源不可判定条件,X 参与归属压缩,Λ 生成来源标签,K 维持该标签。Ψₜ 的输出由此可形式写为:

Ψₜ(sₜ) = Kₛ(sₜ, Λₛ(Ʃₜ, X)),其中 Ʃₜ ⊆ E(sₜ),且 Δₜ(Ʃₜ) ≠ ∅

并满足:存在 Δt \> 0,使 ∀ τ ∈ \[t, t+Δt\],l\_τ = l\*ₜ。

该条件不是新增公理,而是被维持归属的显式形式(第一节继承),作为 Ψₜ 的输出性质成立,而非单一子结构属性;其实现基础为 Kₛ 与占据维持机制的共用(式篇第七第三节其二)。

十一、与一般式的一致性及可构造性

在误外化一般式中,单一结构 s 的最小完备结构已定义为:

Externalization(s) = (E, X, Δₛ, Ʃₛ, Λₛ, Kₛ)

其中:Ʃₛ ⊆ P 且由 E(s) 内生生成;Λₛ : (Ʃₛ, X) → L;若 l\* = Λₛ(Ʃₛ, X),则 Kₛ(s, l\*) = l\*。

现于极限式中,取 s = sₜ、Ʃₛ = Ʃₜ、l\* = l\*ₜ,则 Ψₜ 所要求之结构,与 Externalization(sₜ) 的六元结构一一对应。

并且,由于 Externalization(sₜ) 在一般式中已构造性给出,且各子结构均定义于 S 内,故 Ψₜ 在系统中可构造存在。

因此:Ψₜ ≅ Externalization(sₜ),且 Externalization(sₜ) 为 Ψₜ 的充要结构形式。

此节即第九节两条路的汇合点:全称必要性给出”任何实现必含六元结构”,本节给出”该结构已被构造且充要”。

十二、结构必要性(完备击穿)

本节逐项给出六元结构的必要性。注意它与第三至八节的关系:本节是全称论证(任一项缺失即破坏归属任务的成立条件),第三至八节是其实例(每一被排除机制类对应本节至少一项的缺失或与前提的冲突,见各路径末尾的定位)。

若缺失 E,则 Ʃₜ 无法生成,来源判定域不存在。

若缺失 Δ,则存在可定义区分函数,系统退化为确定映射(路径二)。

若缺失 X,则归属压缩失去来源缺口下的独立压缩依据,Λₛ 不再满足非退化性要求(式篇第七附录第四节),从而不构成误外化结构;确定映射(偏置全数还原为 Γₜ,路径二)与随机过程(无任何稳定偏置来源,路径三)仅为其典型退化实例,非穷尽形态。

若缺失 Λ,则多来源解释无法压缩为唯一标签,不构成误外化结构;静态集合(路径六)与结构自带之预设(路径五)为其典型表现,非穷尽形态。

若缺失 K,则归属结果无法维持,不能形成稳定”在外”(路径三)。

因此任一结构缺失,均破坏以下至少一项:多来源并存、被维持的来源归属(继承形式)、时间一致性、非读取式”在外”生成。

十三、极限约束

若系统不能直接读取真实外部域 Ω(第三节:类型层不可能为主依据,转译必经性为辅),且:

\|Ʃₜ\| ≥ 2 ∧ Δₜ(Ʃₜ) ≠ ∅  
被维持的归属恰一份(第一节继承:载体层、形态层、逻辑层三层之合取;非仅系于承诺)  
¬∃ f : Γₜ → L

则”在外”这一结果不能来自:外部读取、当前条件决定、随机或不稳定过程、并列成立、结构自带、静态解释集合。

因此在上述极限条件下,“在外”只能由误外化结构生成(全称依据:式篇第七总定理;实例验证:第三至八节),并且该结构只能实现为 Externalization(sₜ)(第十一节充要性)。

十四、主定理

在以下条件成立时:

sₜ 为被维持的占据(其为单一收束形态由观者一般式义务 I 给出;存在性依池级当前单值原则之承诺),归属需求成立(式篇第七第三节)  
\|Ʃₜ\| ≥ 2 ∧ Δₜ(Ʃₜ) ≠ ∅  
¬∃ f : Γₜ → L,¬∃ f : Ω → L(后者由第三节给出:判定函数的类型定义域不含 Ω;转译必经性为辅)

则:

(a)存在性:必存在实现来源归属的机制 Ψₜ,使 Ψₜ(sₜ) = l\*ₜ(完整函数形见第十节;归属确实被形成并维持,构造见式篇第七)。

(b)全称必要性(承重项):Ψₜ 的任何实现必同时具有 (E, X, Δₛ, Ʃₛ, Λₛ, Kₛ) 并满足 Λₛ ≺ Kₛ——即任何实现都是误外化结构,且 Ψₜ ≅ Externalization(sₜ)(式篇第七总定理,对全体机制量化,不依赖枚举)。

(c)实例排除(推论):特别地,Ψₜ 不属于直接读取类、确定映射类、随机或不稳定过程类、并列归属类、结构自带类、静态集合类——六类各缺失(b)中至少一项,或与前提直接冲突(第三至八节定位)。

十五、最简表达

sₜ —Ψₜ→ l\*ₜ(Ψₜ 内含 Ʃₜ、X 与 E、Δₜ 之约束)

且 Ψₜ ≅ Externalization(sₜ)。

若 l\*ₜ = l外,则结构 sₜ 被判为”在外”。

十六、结论

在来源缺口、归属需求与归属继承共同成立,且排除直接读取与确定映射的条件下:

“在外”并非预设关系,而是由误外化结构生成的结果——其依据是功能必要性的全称定理,而非机制类型的枚举;六类替代方案的失败,是该定理的六个实例。

若系统不能直接得到外部,却仍形成”现实在外”的结果,则该结果必为误外化,且其唯一结构形式为 Externalization(s)。

式篇第七证明”在外”能够被构造;本篇证明”在外”不能被读取——它别无来源,只能被构造。
