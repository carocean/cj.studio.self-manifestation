自显论·式篇第九v2.1

# 误外化消解式

本篇试论一个总命题:

“内 / 外”这对来源标签不具有现实的本体地位——它们不是现实的先验划分,而是归属机制的输出。被消解的是划分的实在性,不是世界的实在性。

本篇与误外化诸式的分工:

式篇第七证明”在外”能够被构造;式篇第八证明”在外”不能被读取;本篇证明”在外”与”在内”作为一组划分,不具有先验地位——三篇合为误外化的完整刻画:构造、不可读取、地位消解。

需要预先划定消解的范围,以免越界。本篇消解一件事,保留一件事,不裁定一件事:

消解:l内 / l外 这对标签的本体地位——它们不是先于归属机制而在的现实分区。

保留:生成路径的事实。结构 sₜ 确由某条真实路径生成,该事实存在;系统无从取得它(来源缺口是认识层的不可判定,不是本体层的无事实,式篇第七反例一)。消解不触及此。

不裁定:外部域 Ω 的存在与否。式篇第八的类型层论证只断言 Ω 非系统可得对象;其存在与否,本体系不作裁定。本篇的消解与该论证完全相容:被消解的是”外标签对应某个可得真实域”的主张,不是 Ω 本身。

一句话

“外”不是被发现的方位,而是被生成的标签;“内”不是基础,而是同一二值标签结构中的另一取值。

※ ※ ※

一、基本设定

设系统在时刻 t 的当前结构为 sₜ ∈ S。

锚定:sₜ 为该时刻被维持为占据态的收束意象(其为单一收束形态由观者一般式义务 I 给出;占据之形式定义见观者数理式定义四十五);本篇对”内 / 外”标签的消解,作用范围为显现层上的归属(式篇第二十二)。

其来源解释集合为 Ʃₜ ⊆ P,满足:

\|Ʃₜ\| ≥ 2,且来源缺口成立(式篇第七定义一)

且:Ʃₜ 完全由 E(sₜ) 内生生成或限定,不允许存在独立于结构之外的解释来源集合。

设存在归属机制 Ψₜ,其输出满足 Ψₜ(sₜ) = lₜ,完整函数形为 Ψₜ(sₜ) = Kₛ(sₜ, Λₛ(Ʃₜ, X)),其中 Ʃₜ ⊆ E(sₜ) 且 Δₜ(Ʃₜ) ≠ ∅(式篇第八第十节)。

其中 lₜ ∈ L = {l内, l外}。

Ψₜ 在本篇中仍作为标签生成结构成立。其输出是否代表现实的真实划分,正是本篇的论题——本篇将论证:它仅代表结构内生成的标记结果(结论见第十三节,论证完成之前不作预设)。

二、问题重述

在 \|Ʃₜ\| ≥ 2 且来源缺口成立的条件下,来源存在不可判定性。

一般式与极限式已证明:“在外”不是被读取的,而是由误外化结构生成并维持的归属结果(式篇第七总定理;式篇第八主定理)。

现在的问题是:既然”外”只是生成标签,那么与之对立的”内”,是否仍然是一个真实划分?进一步:这对标签所构成的划分本身,是否具有先验的本体地位?

三、标签的生成性

由定义:lₜ = Ψₜ(sₜ)。

可知:“内 / 外”不是结构本身自带的属性,而是结构运行后的输出。

因此:lₜ 不属于 sₜ 本身,不属于 Ʃₜ 的预设内容,而只属于 Ψₜ 的输出。

即:“内”和”外”都是生成出来的标签,而不是先在那里等着被发现的东西。

四、二值结构的锁定

定义:外 = 1,内 = 0,并规定:

l内 ≔ ¬l外

因此:内和外不是两个独立存在的项,而是同一二值结构的两个取值。

即:L = {0, 1} 只是 Ψₜ 的输出空间,而不是现实的分区。

本节即式篇第七第三节(唯一性继承的逻辑层)与式篇第八排除路径四(逻辑层排除)所引用的二值锁定:一旦 l内 ≔ ¬l外 成立,同一结构同持两标签即 l = ¬l,逻辑矛盾——并列归属在此即被排除,无需任何附加约束。

五、对立关系的依赖

由于 lₜ 由 Ψₜ 生成,Ʃₜ 完全内生,所以:“内 / 外”这对对立,是在 Ψₜ 运行之后才出现的。

因此:不是先有”内 / 外”,再去判断结构属于哪一边,而是先有 Ψₜ,才有”内 / 外”这两个标签。

即:内外依赖 Ψₜ,而不是 Ψₜ 依赖内外。

六、排除路径一:先验的内外划分

如果假设:现实本来就分成”内”和”外”,每个结构天然属于其中一边,且系统的归属据此作出——那就不需要 Ψₜ 这种生成机制。

此假设被排除,但须精确陈述排除的是什么,以免认识层与本体层相混。

被排除的是先验划分的功能存在:若存在先验划分且系统能依之归属,则归属可由结构或条件直接读出——这与来源缺口矛盾(式篇第八排除路径二),也与读取不可能矛盾(式篇第八排除路径一)。故无论现实”本身”如何,先验划分不可能是系统归属的依据;系统的内外标签不来自它。

进一步,在体系内部,“内外划分”这一概念的全部可指认内容,就是标签的生成与使用——除标签操作之外,该划分在体系内没有剩余的本体内容可供指认。因此,体系内的”内外划分”被完全收归标签层。

须预先封堵一个自然的反驳:体系内确有真实的结构边界——池界(个体化,观者个体化数理式第六节之池轨分层与预识别协议)、观界(准入与可达,式篇第二十二)、识界(分辨闭包)——它们是实在的,“外”是否就是对越过这些边界之事件的追踪?不是,三条理由:其一,这些边界划分的是结构的资格与身份(谁是一个观者、什么能显、能分成什么),不是内容的来源——它们的判据(Sep 条件、三道门、不可区分闭包)与来源标签的生成条件(缺口加偏置)互不重合;其二,若来源标签可由某条真实边界的越界检测直接读出,归属即为确定映射,已被式篇第八排除路径二排除——缺口的存在恰恰意味着没有任何在系统中可用的边界检测能单值地给出归属;其三,标签可以与任何边界事实相背(完全内生的结构被标为外,经界门入界的转译物被标为内),这一可背离性本身证明标签不是对任何实在边界的读数。真实边界存在,但来源标签不还原为其中任何一条——它是在边界检测失效处被构造出来的。

至于体系之外”现实自身是否分内外”——该问题超出一切可得结构,本体系不作裁定,也无需裁定:无论其答案为何,均不改变上两段的结论。

七、排除路径二:“外”对应可得的真实外部

如果假设:“外”这一标签对应某个系统可以访问或验证的真实外部域——那么归属就是对该域的读取。

但系统所能得到的只有 sₜ 与 Ʃₜ,而 Ʃₜ 完全内生;对真实外部域的直接读取在类型上不可能(式篇第八排除路径一:f(Ω) 无定义),经转译入界者已是内部结构而非外部本身。

因此:不存在一个可被调用或验证的外部来源域;“外”这一标签不对应任何可得的真实域。

注意结论的精确边界:被否定的是标签与可得真实域的对应关系,不是 Ω 的存在。Ω 是否存在,系统无从知晓,本体系不作裁定——这正是与式篇第八类型层论证的相容之处:那里以”Ω 非可得对象”立论,从未以”Ω 不存在”立论。

八、排除路径三:“内”作为真实基底

如果假设:“内”是一个独立真实的基础区域——那它必须在逻辑上独立于”外”。

但 l内 ≔ ¬l外,而”外”是 Ψₜ 的输出标签。

因此:“内”同样只是标签;在本式的二值结构中,它由对”外”的否定来确定,并不具有独立于该标签结构之外的基础地位。把”内”立为基底,等于把一个标签取值立为基底——而标签取值的全部内容都在标签结构之内。

九、结构的封闭性

由前述:Ʃₜ 内生,lₜ 由 Ψₜ 生成。因此存在闭合链:

sₜ → Ʃₜ → lₜ

须精确陈述闭合的是什么:这是来源判定链的闭合——在从 sₜ 到 lₜ 的判定过程中,不存在来自 Ω 的直接输入;判定所用的一切材料(解释集、偏置、判定函数)均为内部结构。

这不是因果链的封闭:系统照常接受输入,输入经候选化转译入界(式篇第二十二),转译物参与后续的生成与归属——但转译物是内部结构,它进入判定链时已不携带”来自外部”的自证标记(否则归属可被读取,与式篇第八矛盾)。

因此:“内 / 外”完全是在结构内部生成的——判定层面如此;而这并不意味着系统与环境无因果交换。

十、误外化的重新界定

在一般式中,误外化被描述为”把结构当作在外”。在本式中可进一步明确”误”字的两种读法,一被消解,一被保留:

其一,相对先验划分之”误”——被消解。“错判”预设标签有先验的真值条件(现实本有内外,判断可对可错)。由第六节,无此先验划分可作依据;在这一读法下,根本无所谓判对判错,“误”字落空。

其二,相对路径事实之”误”——被保留,但限定为认识层描述。结构 sₜ 的真实生成路径存在(式篇第七反例一);当归属标签与该路径事实不符(内生路径而标签为外),这一不符作为关系事实成立;但系统自身无从核对它,因为核对恰恰需要读取被缺口遮蔽的路径。

因此,误外化的准确刻画是:系统在无从核对处生成标签,并将标签再解释为来源属性。所谓”误”,不是偏离某个先验真值,而是:归属与不可得的路径事实之间的关系,永久地无从在系统内部结清。

实际发生的是:标签生成 + 对标签的再解释——而非对真实来源的(错误)读取。

十一、对立的消解

由以上各点,“内 / 外”:

不是先验的(第六节);  
不对应可得的真实域(第七节);  
不构成独立的基础划分(第八节);  
其生成全程封闭于判定链内部(第九节)。

而只是:Ψₜ 输出的一组标签取值。

因此,内外这组对立,可以被消解:它们不再作为现实结构存在,而仅作为标记结构存在。

十二、现实地位的限定

这里的结论是:“内 / 外”不具有现实的本体地位。

这并不否认:在经验中,内外区分照常发生,清晰、稳定、不可随意取消——因为归属是续行所需的功能结构(式篇第七第三节:归属需求),标签由收束维持(Kₛ),其稳固正是误外化结构正常运转的表现。

本式的结论仅指出:这种区分来自结构生成,而不是现实本身的预设划分。消解取消的是划分的本体读法,不是划分的功能存在——读法消解之后,内外区分照常用,只是不再被当作现实的接缝。

十三、主定理

在以下条件成立时:

sₜ 为被维持的占据(其为单一收束形态由观者一般式义务 I 给出;存在性依池级当前单值原则之承诺),归属需求成立(式篇第七第三节)  
\|Ʃₜ\| ≥ 2 ∧ Δₜ(Ʃₜ) ≠ ∅,且 Ʃₜ 完全内生  
Ψₜ 为归属机制(式篇第八主定理:Ψₜ ≅ Externalization(sₜ))  
不存在可得的外部来源域(式篇第八排除路径一)

则:

(i)“内 / 外”不构成现实的先验划分,仅为 Ψₜ 的输出标签空间(第三至八节);

(ii)消解不及于生成路径的事实(路径事实在本体层存在,其不可得在认识层成立),亦不裁定 Ω 的存在(总命题范围限定);

(iii)因此,误外化所依赖的”外在性”不具有终极地位——但作为功能结构,它照常成立、照常必要(式篇第七、第八)。

十四、最简表达

sₜ —Ψₜ→ lₜ(Ψₜ 内含 Ʃₜ、X 与 E、Δₜ 之约束)

其中:lₜ ∈ Output(Ψₜ),而非 lₜ ∈ 现实结构本身。

十五、结语

“外”这一标签,不指向任何可得的彼岸;“内”不是基础,而是同一二值标签结构中的另一取值。

没有先验的内,没有先验的外。

所谓”误”,不是偏离真实,而是在无从核对处对已生成标签的再解释。

当生成机制被看清:内外之分被收回标签层,误外之名随之消解——而世界的实在、路径的事实、归属的功能,一概无损。

式篇第七证明”在外”能够被构造;式篇第八证明”在外”不能被读取;本篇证明”在外”不必被相信——它从来只是一个标签。
