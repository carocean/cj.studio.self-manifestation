# 识界极限式

一、基本设定

设结构空间为 S，生成域为 G。

定义：

A ⊆ G 为可接触域  
M : A → S 为入构映射

记：

S’ = M(A)

假设：

\|S’\| \< ∞

定义结构保持映射族：

𝔽 = { f ∣ f : S’ → S’，且 f 保持结构关系不变 }

定义不可区分关系：

Π ⊆ S’ × S’

满足：

(s₁, s₂) ∈ Π ⇔ ∀ f ∈ 𝔽，f(s₁) = f(s₂)

二、划分结构

由 Π 为等价关系，定义等价类：

\[s\] = { x ∈ S’ ∣ (x, s) ∈ Π }

则：

S’/Π = { \[s\] ∣ s ∈ S’ }

三、问题定义

系统面对生成域 G，但仅通过 A 与之发生关系，并经 M 映入 S’。

问题在于：

系统是否可以在 S’ 上无限细分结构，而不形成稳定划分？

四、无限细分假设

假设系统可以在 S’ 上无限细分结构，而不形成稳定划分。

即存在划分序列 {𝒫ₙ}，满足：

𝒫₀ ⪰ 𝒫₁ ⪰ 𝒫₂ ⪰ …

且：

∀ n，有 𝒫ₙ₊₁ ≺ 𝒫ₙ

同时该序列不收敛，即：

∀ n，𝒫ₙ ≠ 𝒫ₙ₊₁

五、与不可区分关系的冲突

由 Π 的定义：

(s₁, s₂) ∈ Π ⇔ ∀ f ∈ 𝔽，f(s₁) = f(s₂)

即：

若两元素在所有结构保持映射下不可区分，则必须归于同一结构类。

因此，对任意划分 𝒫ₙ，若存在：

(s₁, s₂) ∈ Π

则在任何满足结构保持约束的细分中，必有：

s₁, s₂ 属于同一块

因此：

Π 对划分的细分施加下界约束。

六、与结构保持约束的冲突

由 𝔽 的定义：

任意 f ∈ 𝔽 保持结构关系不变。

因此，对任意划分 𝒫ₙ，若 s₁, s₂ 属于同一块 B ∈ 𝒫ₙ，则必须满足：

∀ f ∈ 𝔽，f(s₁), f(s₂) 仍落入 𝒫ₙ 中同一块

否则：

划分将破坏结构保持性。

因此：

划分不仅受 Π 限制，还受 𝔽 的结构一致性约束。

并且：

对任意 B ∈ 𝒫ₙ，∀ f ∈ 𝔽，存在 B’ ∈ 𝒫ₙ，使：

f(B) ⊆ B’

七、无限细分不可持续

由第五、六节：

任何划分必须同时满足：

Π 一致性  
结构保持性

而这两类约束共同作用，使得划分无法任意细化。

若继续细分，则必然出现：

违反 Π 的强制合并条件  
或违反结构保持映射的不变性

因此：

严格下降的无限划分序列不可能存在。

八、有限性约束下的终止性

由于：

\|S’\| \< ∞

则：

Part(S’) 为有限集合

因此任何划分下降序列：

𝒫₀ ⪰ 𝒫₁ ⪰ 𝒫₂ ⪰ …

不可能无限严格下降

必存在 N，使：

𝒫ₙ = 𝒫ₙ₊₁（n ≥ N）

即：

划分过程必然终止。

九、划分空间与偏序

记：

Part(S’) 为 S’ 上所有划分的集合。

定义偏序：

𝒫₁ ⪯ 𝒫₂ ⇔ ∀ B ∈ 𝒫₁，∃ B’ ∈ 𝒫₂，使 B ⊆ B’

即：

𝒫₁ 比 𝒫₂ 更细

由于 \|S’\| \< ∞，故：

Part(S’) 为有限格

十、闭包算子（构造定义）

定义算子：

C : Part(S’) → Part(S’)

对任意划分 𝒫，定义关系 \~𝒫 于 S’ 上：

s₁ \~𝒫 s₂ ⇔ (s₁, s₂) ∈ Π ∧ ∀ f ∈ 𝔽，有 f(s₁), f(s₂) 落入 𝒫 中同一块

记 \~𝒫\* 为 \~𝒫 的最小等价闭包

定义：

C(𝒫) = 由 \~𝒫\* 所诱导的等价类划分

十一、单调性与收敛性

对任意划分 𝒫，有：

C(𝒫) ⪯ 𝒫

且：

若 𝒫₁ ⪯ 𝒫₂，则 C(𝒫₁) ⪯ C(𝒫₂)

因此：

C 为单调收缩算子

定义序列：

𝒫₀ = { S’ }  
𝒫ₙ₊₁ = C(𝒫ₙ)

由于 Part(S’) 有限，

该单调下降序列必在有限步内收敛：

∃ N，使 𝒫ₙ = 𝒫ₙ₊₁（n ≥ N）

十二、极限划分

定义：

𝒫\* = 𝒫ₙ（n ≥ N）

则：

C(𝒫\*) = 𝒫\*

十三、不变性与最细性

𝒫\* 满足：

(1) 不变性  
∀ B ∈ 𝒫\*，∀ f ∈ 𝔽，∃ B’ ∈ 𝒫\*，使 f(B) ⊆ B’

(2) Π 一致性  
∀ s₁, s₂ ∈ S’，若 (s₁, s₂) ∈ Π，则 s₁, s₂ 属于同一块

(3) 最细性  
若划分 𝒬 满足上述两条件，则 𝒬 ⪯ 𝒫\*

十四、唯一性结论

设 𝒫₁, 𝒫₂ 均满足上述条件，

则：

𝒫₁ ⪯ 𝒫₂ ∧ 𝒫₂ ⪯ 𝒫₁ ⇒ 𝒫₁ = 𝒫₂

故：

𝒫\* 唯一存在

十五、识界定义

定义：

Boundary = 𝒫\*

即：

识界为在 Π 与结构保持约束共同作用下的最细不变划分

十六、主定理

在以下条件成立：

\|S’\| \< ∞  
存在入构映射 M : A → S  
存在结构保持映射族 𝔽

则：

闭包序列 𝒫₀ → C(𝒫₀) → C²(𝒫₀) → … 必在有限步内收敛至唯一划分 𝒫\*

该划分满足 Π 一致性、结构不变性与最细性，并定义识界

十七、最简表达

𝒫₀ → C → C² → … → Boundary

十八、最终结论

在有限结构空间中，

只要存在不可区分关系与结构保持约束，

则任意划分在闭包作用下必收敛为最细不变划分

该划分即为识界

终式

Boundary = limₙ→∞ Cⁿ(𝒫₀)

终极句

识界 = 不可区分关系与结构保持约束下的划分极限
