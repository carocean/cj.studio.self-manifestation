自显论·式篇第二十 v1.2

# 沉积动力一般式

本篇试论一个总命题：

承认”历史会影响未来”这一事实，并要求此影响在有限场中形成稳定续行，则意味着：系统内部不只是存在变化，而且存在一套结构，使过去留下的差异能够压偏后续路径。

也就是说：

若一个场中可以发生多次作用、留下不同痕迹、并继续接受后续脉冲，为什么它不会永远均匀、永远散乱、永远无结构，而会形成深浅、熟径、闭包、主导续行结构与跨时稳定续接？

我们要在该篇，在不断的追问下找到证明，并推导沉积动力的一般式。

我们的目标是：

得到沉积动力结构的范式模型（其最小性尚未完成证明），并给出正反证明、所列概念间的区分（不可压缩性）、最小完备性的条件性说明、击穿路径与最终总压缩式。

那么，我们先给出结果。

沉积动力一般式

Sedimentation-Dynamics = (I, T, H, D, B, F, C, U, K, S)

在重复作用、历史留存、有限竞争、退散存在与后续受偏同时成立的情况下，任何能够形成并维持沉积型主导续行结构的系统，必然同时具有：

入场作用、  
迹应生成、  
历史留存、  
差分积深、  
续行偏置、  
熟径锁定、  
闭包回返、  
统流压缩、  
抗散保持、  
续行绑定。

因此：

沉积结构不是外加规则，

而是历史对未来路径不断压偏之后，在有限竞争与退散压力下形成的稳定结果。

一句话

历史压偏未来，  
有限竞争压缩未来。

摘要

《场数理式》已经说明，迹应如何形成沟线、熟径、共核与闭包。《域数学》已经说明，局部稳定续行如何形成域、Lock 与 Sync。《共核数学》已经说明，多域长期交叠之后，共核如何形成概念层与泛化结构。

但问题仍未结束，而是进一步推进：

沉积结构若要形成并维持，必须具备什么？

本文提出：

若一个场满足：

\- 作用能够留下迹应；  
\- 历史不会完全逆消；  
\- 后续续行会受历史压偏；  
\- 场不能无限均流；  
\- 一切结构都会退散；

并且在其中形成并维持由沉积差承担的主导续行结构（下称沉积型主导续行结构），则此结构必具：

深浅、  
熟径、  
闭包、  
主导续行结构、  
跨时稳定续接。

本文不断言满足五项条件的场必然生成此种结构（第十二节注）。

本文的核心结论是：

无历史，则无沉积；  
无沉积度差，则无续行偏置；  
无续行偏置，则无熟径锁定；  
无熟径锁定，则闭包回返不可定义；  
无有限竞争，则主导续行结构不可定义；  
无抗散保持，则主导续行结构不可维持；  
无续行绑定，则跨时稳定续接不可成立。

因此：

沉积动力一般式不是经验描述，

而是：

在本篇界定之下，沉积型主导续行结构的必要结构。

引言

我们通常看到的是已经形成的结构。

沟线已经在，  
熟径已经在，  
域已经在，  
共核已经在，  
规律也好像已经在。

但真正的问题不是：

结构在哪里？

而是：

结构为什么会出现？

如果一个场每次受作用之后都完全复原，则无历史可言；

若历史虽有留存，却不改变后续路径，则历史没有动力意义；

若后续路径虽受影响，但所有路径永远等势，则深浅不能形成；

若深浅虽形成，其差却不参与后续续行，则熟径不能锁定；

若熟径虽存在，却不能形成互返结构，则闭包不能成立；

若闭包能够无限并流，则主导续行结构在结构上不可定义；

若主导续行结构无法抵抗退散，则稳定续接不可维持；

若主导续行结构不能优先续接自身，则跨时稳定续接不可成立。

所以，本篇不从”结构已经存在”开始，而从：

场为什么不再无差别。

开始。

论证流

一，

先问最浅的一层：

沉积动力是不是所有变化系统都有？

不是。

如果一个系统每次受作用之后都会完全复原，那么其中虽有变化，却没有沉积。

因此：

作用必须进入场中。

定义一：入场作用

I：入场作用

所谓入场作用，就是某一作用进入场中，并参与场态变化。

I 只要求：作用进入场。但：不保证留下稳定差异。

二，

既然存在入场作用，再问：

作用进入场之后，是否一定留下有效差异？

不一定。

若作用只是穿场而过，而不留下任何局部改变，则场仍不形成沉积。

因此：迹应生成成为必要。

定义二：迹应生成

T：迹应生成

所谓迹应，就是作用在场中留下的有效改变。

T 不只要求作用进入场，还要求：作用留下可持续局部差异。

若无迹应，则历史在结构上不可成立。

三，

既然存在迹应，再问：

迹应是否一定构成历史？

不一定。

若迹应形成之后立即完全逆消，则过去不能参与未来。

因此：历史留存成为必要。

定义三：历史留存

H：历史留存

所谓历史留存，不是完整保存过去，而是：场不能完全恢复至未受迹应之前。

只要过去留下不可完全逆消的差异，历史便成立。

四，

既然存在历史，再问：

历史是否一定形成结构差异？

不一定。

若所有历史在全场以完全相同方式留存，则：历史虽在，却不形成不同续行倾向。

因此：差分积深成为必要。

定义四：差分积深

D：差分积深

所谓差分积深，就是历史在不同结构位、沟线或路径之间留下不等的沉积度。

沉积度是沉积深浅之程度，由宿载机制承担（场篇第一定义9）。

H 只要求历史存在。D 则要求：历史形成不均。

差分积深不是记忆名称，也不是作用强度；它是沉积状态之差。沉积度的通行作用不写入本定义，另有方向关系：同类可比结构中，沉积度愈深，其阈愈小（场篇第一方程3a）；比较条件相同时，深者不后于浅者得流，另满足严格条件时深者先得其流（场篇第一定律5、定理17；外三「深者先得其流」）。

D 只断言差在，不断言差已改变后续续行；后者是 B。

五，

既然存在沉积度差，再问：

沉积度差是否一定参与后续续行？

不一定。

外三言「深者先得其流」，此律有其比较条件：同一入口、共享入口流压、通道无阻、无择偏与调谐差别、同类可比（场篇第一方程4 之 C₌）。条件不具时，沉积度差可以不改变后续行进。例如较深之路受阻（内十五「遇塞则绕」），流只走较浅之路：差虽在，后续行进与差被抹平时无异。就此比较而言，沉积差在动力上未起作用。

因此：沉积差要参与未来生成，须另立一项：续行偏置。

定义五：续行偏置

B：续行偏置

所谓续行偏置，就是后续续行依赖于沉积度之差：在申报的比较任务中，把比较对象的沉积度抹平到申报的共同水平、其余不变，后续的相对行进随之改变。

也就是说：沉积差改变了未来路径。外三「深者先得其流」是其典型情形。

B 不强求概率表达：读数可以是首批开放者、先后次序或份额。

B 不是一切偏流。偏流在内外篇有多种语境用法（前迹引导后流、经验场差分输出、意向择取或改变流向、着色改变经验偏流，见内十五、内七、内四、外九），择偏、调谐、着色也可改变流向。B 只取其中由沉积差承担的一种。形式定义见附件一第五节。

六，

既然存在续行偏置，再问：

偏置是否一定形成稳定路径？

不一定。

若沉积差只在一次比较中改变行进，此后不再复现，则系统只存在瞬时倾向，不形成常走之径。

因此：熟径锁定成为必要。

定义六：熟径锁定

F：熟径锁定

所谓熟径锁定，就是一条熟径在申报窗口内持续承受续行偏置：它是熟径；在窗口的各申报子段中，后流独先归于此径，且此独先依赖其沉积差：抹平沉积差后，此径不再独先。

熟径是常熟之径（外三「因深者先得其流，故信号好走常熟，此所谓常熟之径，常熟之域也」），判定依场篇第一定义13：既有深积，且在申报窗口内有常走记录。熟是对深者的称谓（外三「可称深者为熟」）。先得其流是熟径的表现，不是其定义。

复走产生加深作用；加深压过退浅且未达底限时，此径愈深，其阈愈小（场篇第一方程2、3a；在路径处，以附件一第一节的路径阈规则为前提，平台处阈可不变）。

熟径锁定与场篇第一的 Bias（定义22）相近而不同：Bias 不要求熟径，以差分门槛与长窗上的实际偏续界定；F 要求熟径，以此径自身的偏置（附件一第五节 B\_m^q）在各子段持续成立界定。

七，

既然存在熟径，再问：

熟径是否自动构成稳定结构？

不一定。

若熟径之间不能形成互返关系，则结构只能单向滑落，而不能复用。

因此：闭包回返成为必要。

定义七：闭包回返

C：闭包回返

所谓闭包回返，就是多段已锁定的熟径之间形成可重复返回的续行结构。

闭包不是规则。闭包是：熟径之间形成的稳定互返关系。

注：场篇第一方程16 的闭包一般不要求熟径（「熟径可参与闭包，熟径不要求闭包，闭包亦不要求熟径」）。本篇的 C 专指由锁定熟径构成的闭包，是场篇第一闭包的一个子类；依赖链中的 F ≺ C 只对此子类成立。

八，

既然存在多个闭包，再问：

多个闭包是否能够无限同时维持？

不能。

若所有闭包无限并流，则：不存在唯一优先续行。若不存在唯一优先续行，则：主导续行结构不可定义。

因此：统流压缩成为必要。

定义八：统流压缩

U：统流压缩

所谓统流压缩，不是空间有限，而是：系统在同一时刻能够稳定维持的有效续行总量有限。

因此：部分闭包必须压制部分闭包。部分路径被强化，部分路径被压低，部分路径被舍弃。于是：局部唯一优先续行形成。

注（v1.2）：本篇所称主导续行结构，是在闭包回返（C，即锁定熟径之闭包）之间经统流压缩形成者，称为沉积型主导续行结构。凡本篇说「主导续行结构」，均指此种。

九，

既然存在主导续行结构，再问：

主导续行结构是否一定稳定？

不一定。

若不存在抗散保持，则：任何沉积结构都会持续退浅。若持续退浅，则：主导续行结构无法维持其结构差分。若结构差分无法维持，则：主导续行结构不能稳定续接自身。

因此：抗散保持成为必要。

定义九：抗散保持

K：抗散保持

所谓抗散保持，不是绝对不变，而是：在退浅、扰动、竞争与冲刷之下，结构仍能维持其可复用性。

K 不是形成结构，而是：抵抗结构散失。

本篇的 K 作用于闭包回返（C）：闭包在窗口内保持其互返，且其不可替代的承载路径不退至可复用下限之下（形式判据见附件一第九节）。

注：K（抗散保持）与 U（统流压缩）均依赖 C（闭包回返）成立，两者之间是并列关系而非依赖关系——统流压缩的形成不是抗散保持的前提，抗散保持的形成也不是统流压缩的前提。两者共同支撑 S（续行绑定）的成立。详见第十一节依赖链说明。

十，

既然存在稳定主导续行结构，再问：

稳定主导续行结构是否自动形成跨时稳定续接？

不一定。

若主导续行结构不能优先续接自身，则：系统虽存在局部主导，却仍可能在每一时刻重新散开。

因此：续行绑定成为必要。

定义十：续行绑定

S：续行绑定

所谓续行绑定，不是主导续行结构本身，而是：使主导续行结构优先续接自身，而不在每一时刻重新散开的结构。

因此：跨时稳定续接，不是静态存在，而是：主导续行结构不断续接自身后的结果。

注：S（续行绑定）在功能上与场篇第二的 Lock（历史层积对当前聚流的持续偏置）高度对应。Lock 是域层面上历史结构对当前聚流的约束延续，使域优先复走旧熟径；S 是一般式层面上主导续行结构优先续接自身的结构条件。两者是同一动力原则在不同层次上的表达：S 是 Lock 在一般式层次的抽象，Lock 是 S 在沉积场域层次的具体实现。

十一，

到这里，沉积动力一般式已经被一步一步逼出来了。

无入场作用，则场不受改变；  
无迹应生成，则变化不留有效差异；  
无历史留存，则过去不能影响未来；  
无差分积深，则历史不形成深浅；  
无续行偏置，则沉积差不参与未来生成；  
无熟径锁定，则偏置不在窗口内持续成径；  
无闭包回返，则熟径不能形成复用结构；  
无统流压缩，则闭包无限并流，主导续行结构不可定义；  
无抗散保持，则结构差分无法长期维持；  
无续行绑定，则主导续行结构不能稳定续接自身。

因此：沉积动力一般式正式写为：

Sedimentation-Dynamics = (I, T, H, D, B, F, C, U, K, S)

其中：  
I：入场作用  
T：迹应生成  
H：历史留存  
D：差分积深  
B：续行偏置  
F：熟径锁定  
C：闭包回返  
U：统流压缩  
K：抗散保持  
S：续行绑定

并满足以下依赖关系：

I ≺ T  
T ≺ H  
H ≺ D  
D ≺ B  
B ≺ F  
F ≺ C  
C ≺ U  
C ≺ K  
(U ∧ K) ≺ S

其中：  
“≺”表示严格单向结构必要依赖：A ≺ B 表示”B 成立时，A 必须已经成立”，且反方向不成立（A 成立时 B 可以不成立）。“≺”不表示时间先后，只表示结构必要依赖。

注：原 v1.0 写 U ≺ K（统流压缩依赖先于抗散保持），但这一方向有误——抗散保持的成立不以统流压缩为前提。两者均以闭包回返（C）为前提，并列支撑续行绑定（S）。本版修订为：C ≺ U，C ≺ K，(U ∧ K) ≺ S。

注（v1.2）：D ≺ B、B ≺ F、F ≺ C 三环的必要方向，分别由附件一命题1（B ⇒ D）、定义六（熟径锁定含续行偏置）、定义七（C 由锁定熟径构成）给出；反方向不成立的见证，见第十三节。

十二，

现在可以给出总定理：

在重复作用、历史留存、有限竞争、退散存在与后续受偏同时成立的情况下，任何能够形成并维持沉积型主导续行结构的系统，必然同时具有：I, T, H, D, B, F, C, U, K, S。

注：此定理的结论成立依赖”能够形成并维持主导续行结构”这一前提。满足五项基本条件是必要条件而非充分条件——若系统虽满足五项条件，但因某种内部原因始终无法形成稳定主导续行结构，则结论不适用。

注（v1.2）：本定理所论为沉积型主导续行结构（定义八注）：它在闭包回返上界定（U、K 均以 C 为前提），C 由锁定熟径构成，F 含 B，B 蕴含 D。故本定理是该类结构的条件性结构结论：D、B、F、C 四项的必要性由定义与命题给出，其余各项的必要性按本篇对各项的界定理解。本篇不证明一般的稳定主导结构都需要 F、C；择偏、调谐、着色等非沉积差来源也可造成主导，不在本定理范围内。

任意子集或替代结构，只要不能同时实现：作用入场、迹应生成、历史留存、差分积深、续行偏置、熟径锁定、闭包回返、统流压缩、抗散保持、续行绑定，则不足以构成沉积动力结构。

证明如下：

无 I，则无有效作用进入场。  
无 T，则变化不留迹应。  
无 H，则过去不影响未来。  
无 D，则历史不形成深浅。  
无 B，则沉积差不参与未来生成。  
无 F，则偏置不在窗口内持续成径。  
无 C，则熟径不能形成互返复用。  
无 U，则闭包无限并流，主导续行结构不可定义。  
无 K，则结构差分不能长期维持。  
无 S，则主导续行结构不能稳定续接自身。

又若依赖关系如第十一节所示，则后项必预设前项。

故：I ≺ T ≺ H ≺ D ≺ B ≺ F ≺ C ≺ (U ∧ K) ≺ S 为必要。

证毕。

十三，

不可压缩性证明

I 不可并入 T。因为：入场作用只要求作用进入场中，而迹应生成要求作用留下有效差异。存在作用穿场而过而不留迹应。故：I ≠ T。

T 不可并入 H。因为：迹应生成只要求留下有效改变，而历史留存要求改变不可完全逆消。存在迹应形成后立即完全逆消而不留历史。故：T ≠ H。

H 不可并入 D。因为：历史留存只要求过去未完全逆消，而差分积深要求不同结构位之间形成不均差异。存在全场等量历史留存而无结构差分。故：H ≠ D。

D 不可并入 B。因为：差分积深只要求沉积度差存在，而续行偏置要求此差改变后续的相对行进。存在沉积度差已形成、而差不改变后续行进的情形：较深之路受阻（内十五「遇塞则绕」），流只走较浅之路；把两路沉积度抹平到任一合法共同水平，较深之路仍受阻，后续行进不变（附件一第五节受阻实例）。此情形由「深者先得其流」的比较条件不具（通道受阻）所致，不与此律相冲突。故：D ≠ B。

B 不可并入 F。因为：续行偏置只要求沉积差在一次比较中改变后续行进，而熟径锁定要求此径为熟径，且偏置在窗口各子段持续成立。存在一次输入中较深者先得流（B 成立）、此后输入中断、窗口内无常走记录的情形：B 成立而熟径锁定不成立（附件一第六节）。故：B ≠ F。

F 不可并入 C。因为：熟径锁定只要求一条熟径持续承受偏置，而闭包要求锁定熟径之间互返。存在单向的锁定熟径而无闭包结构。故：F ≠ C。

C 不可并入 U。因为：闭包只要求形成稳定互返，而统流压缩要求多个闭包之间形成唯一优先续行。存在多个稳定闭包并流而无主导续行结构。故：C ≠ U。

C 不可并入 K。因为：闭包只要求形成稳定互返，而抗散保持要求主导结构抵抗退浅。存在形成闭包但结构快速退散的情况。故：C ≠ K。

U 不可并入 K。因为：统流压缩只要求形成局部唯一优先续行，而抗散保持要求主导结构抵抗退浅。存在瞬时主导续行结构而无长期稳定结构。故：U ≠ K。

K 不可并入 S。因为：抗散保持只要求结构不快速退散，而续行绑定要求主导续行结构优先续接自身。存在稳定但不断跳流的结构。故：K ≠ S。

十四，

最小完备性（条件性说明）

本节不证明「除此之外不存在新的独立结构项」，只给出条件命题：

任意新增结构 X，若：X 的作用只能：进入已有历史结构、改变已有差分结构、调整已有偏置结构、参与已有主导续行结构、强化已有续接结构，则：X 的功能必可归约至 (I, T, H, D, B, F, C, U, K, S) 之一或其组合。

故：满足此条件的 X 不构成新的独立结构项。是否一切相关的新增项都满足此条件，本篇未证。

注（v1.2）：择偏、调谐、着色等非沉积差的偏流来源，若参与主导续行，按上条归入「参与已有主导续行结构」，不并入 B。

因此：(I, T, H, D, B, F, C, U, K, S) 是本篇为沉积型主导续行结构所立的必要结构集；第十三节给出所列概念间的区分（相邻或相关各项不等同、不反向蕴含），第十一节给出条件性必要依赖；整套结构的最小性（十项中每一项都不能由其余各项实现、替代或导出）尚未完成证明，完备性亦未证。

十五，

击穿论证

反例一：完全复原场。若每次受作用后都完全复原，则无历史留存。不成沉积动力。

反例二：无迹应场。若作用不留下有效改变，则无迹应生成。不成沉积动力。

反例三：均匀历史场。若历史虽留存，却不形成差分，则无差分积深。不成沉积结构。

反例四：无偏置场。若沉积度差存在，却因比较条件不具（如较深之路受阻）而不改变后续行进，则沉积差在动力上失效，不成续行偏置。

反例五：随机偏置场。若偏置只偶然成立，不在窗口各子段持续，则不成熟径锁定。

反例六：单向熟径场。若路径虽熟，却不能互返复用，则闭包不可定义。

反例七：无限均流场。若所有闭包能够无限并流，则主导续行结构不可定义。

反例八：绝对积深场。若所有结构只积不退，则系统失去有效差分。

反例九：不可维持场。若结构无法抵抗退散，则主导续行结构不可维持。

反例十：瞬时主导场。若主导续行结构不能优先续接自身，则跨时稳定续接不可成立。

十六，

最终总压缩式

History-Bias under Finite-Competition ⇒ Structure

即：结构，乃历史压偏在有限竞争下形成的稳定结果。

注：上式是哲学性压缩，表达本篇的总体见解，不是形式命题；其中「⇒」不作充分条件使用。

本篇的形式结论写为：

Structure\_sed ⇒ B ⇒ ∂Future/∂History ≠ 0

其中 Structure\_sed 表示沉积型主导续行结构成立。∂Future/∂History ≠ 0 在本篇是依赖记号，表示反事实依赖：改变历史所留的沉积状态，未来读数随之改变。它不断言通常微积分意义上的偏导存在，不得据此作微分运算。

即：沉积型主导续行结构成立，则续行偏置 B 必已成立（依赖链）；B 成立，则抹平沉积差会改变未来读数，即未来随沉积状态（历史留存）改变，在此意义下 ∂Future/∂History ≠ 0。

两步均不可逆：∂Future/∂History ≠ 0 不推出 B，因为它也可经共同水平变化、择偏、调谐、着色而成立；B 不推出 Structure\_sed（第十三节 B ≠ F 等见证）。

二、入场作用与迹应表达

定义入场作用：I : ℐ(t) → 𝒮(t)，表示：作用进入场。

定义迹应生成算子：T : (𝒮(t),iₖ) → 𝒮′(t)，满足：δ(𝒮(t),𝒮′(t)) \> 0，则：迹应成立。

若：δ(𝒮(t),𝒮′(t)) = 0，则：作用穿场而过而不留迹应。

故：I ≠ T

三、历史留存表达

定义历史留存条件：∃Δt \> 0，使：δ(𝒮(t),𝒮(t+Δt)) \> 0，则：历史成立。

若：∀Δt \> 0，δ(𝒮(t),𝒮(t+Δt)) = 0，则：场完全复原。故：无历史留存。

定义历史留存算子：H : 𝒮(t) → 𝒮(t+Δ)，满足：H(𝒮(t)) ≠ 𝒮(t)

四、差分积深表达

定义沉积度差：D(qᵢ,qⱼ,t) = \|Depth(qᵢ,t) − Depth(qⱼ,t)\|

若：∀qᵢ,qⱼ ∈ 𝒬(t)，D(qᵢ,qⱼ,t) = 0，则：历史虽存在，但不形成结构差分。故：无差分积深。

定义差分积深成立条件：∃qᵢ,qⱼ ∈ 𝒬(t)，使：D(qᵢ,qⱼ,t) \> 0

五、续行偏置表达

定义比较任务 T：申报工作域 M、比较对象 K ⊆ 𝒬(t)（至少两路）、输入协议 P、时间窗 W、相对读数 Y（如首批开放者、先后次序、份额）与共同水平函数 m。

m 的合法条件：（1）事先申报，不得在读取结果后挑选；（2）幂等：m(c,…,c) = c；（3）居间：min\_K Depth ≤ m(Depth\_K) ≤ max\_K Depth；（4）对称：与 K 中成员的排列次序无关。常用者有最小值、算术平均、最大值。

定义抹平干预 I\_m：把 K 中各成员的沉积度都设为 c\* = m(Depth\_K)。凡 M 申报为由沉积度决定之量（如阈），按 M 的规则重算；独立于沉积度的状态（通道阻断、调谐、择偏、着色、输入协议 P）保持不变。Y 只读 K 内的相对行进，不读绝对时刻或绝对流量。

干预的可实现性：路径层模型（甲）中，直接把各成员的 Depth 设为 c\*。聚合模型（乙）中，M 须申报回写规则：给出结构位层的沉积度设置，使 K 中各成员的聚合值都等于 c\*，不属于 K 中各路的结构位保持不变，且结果唯一；并且当各成员的 Depth 已都等于 c\* 时，回写为恒等。K 中各路共享结构位时，此要求可能无解（例：Depth(q₁) = x，Depth(q₂) = y，Depth(q₃) = x + y，x = 1、y = 2，算术平均为 2，须 x = y = x + y = 2，无解）。无可实现且唯一的回写时，I\_m 未定义。

定义续行偏置条件：B\_m(T) 为真，当且仅当 I\_m 有定义，且 Y(I\_m(M),P,W) ≠ Y(M,P,W)，则：续行偏置成立。I\_m 未定义时，B\_m(T) 记为「未定义」，不判为假。

报告 B 须写明所用的 m；结论要求不依赖 m 时，须报告在申报的 m 族中逐一检验的结果。各路阈机制不同时，B\_m 的真值可随 m 而变。

定义成员居先读数：按申报规则由 Y 得出 q 的居先地位 Lead\_q(Y) ∈ {独先, 同先, 不先}。如以首批开放者为 Y：q 为唯一首批开放者为独先，与他路同批开放为同先，不在首批为不先；以份额为 Y 时，按份额最大者定。

定义成员偏置：B\_m^q(T) 为真，当且仅当 I\_m 有定义，且 Lead\_q(Y(I\_m(M),P,W)) ≠ Lead\_q(Y(M,P,W))。即：抹平沉积差后，q 的居先地位改变。

Lead\_q 是 Y 的函数，故 B\_m^q(T) 为真推出 B\_m(T) 为真。反之不然：B\_m 可以只来自其他路径之间的次序改变，而 q 的居先地位不变。例：三路沉积度 q = 2、r = 3、s = 1，阈机制分别为 θ\_q = 0.01/Depth(q)、θ\_r = 1/Depth(r)、θ\_s = 1/Depth(s)；以开放次序为 Y，原次序为 q、r、s，抹平到平均值 2 后为 q、{r, s}；B\_m 为真，q 仍独先，B\_m^q 为假。

命题1（B ⇒ D）：设在比较任务 T 中 I\_m 有定义，且各成员沉积度相等时 I\_m 为恒等干预（路径层模型自动满足；聚合模型由回写规则的恒等要求保证）。对任一合法的 m，若 B\_m(T) 为真，则 K 上差分积深成立。  
证明：设 K 上差分积深不成立，即各成员沉积度同为 c₀。由幂等，c\* = c₀；由恒等要求，干预不改变任何量，Y 不变，B\_m(T) 为假。取逆否即得。∎

受阻实例（D 成立而 B 不成立）：取路径层模型。入口端壑 e 下两路 a、b，无共享片段、汇流与跨路回写；路径阈规则 θ = g(Depth)，g 严格递减，两路机制相同；入口流压 p 自 p₀ 起每步增 u \> 0，首次有路开放即停；a 完全受阻，b 无阻。取 K = {a, b}，Depth(a) \> Depth(b)，Y 为首批开放者，W 不短于 (g(Depth(b)) − p₀)/u 步。则 D 成立。对任一合法 m，c\* 居于 Depth(b) 与 Depth(a) 之间；干预后 a 仍受阻，b 之阈 g(c\*) ≤ g(Depth(b))，于窗内开放，Y = {b} 不变，B\_m 为假。  
对照：a 不受阻、其余相同，且 p₀ \< g(Depth(a))、每步增量小于阈差 g(Depth(b)) − g(Depth(a))、W 足够长时，原读数 Y = {a}（场篇第一定理17）；干预后两路同阈、同步开放，Y = {a, b}，B\_m 为真；a 由独先变为同先，B\_m^a 亦为真。

若：K 内沉积度差存在，而 B\_m(T) 为假，则：就此比较任务而言，沉积差未改变后续行进。于是：沉积差在动力上未起作用。读数取份额或概率时，即「差存在而份额不随差改变」。

注：B 检测对沉积差的依赖，不检测共同水平变化造成的依赖，亦不检测择偏、调谐、着色造成的偏流。v1.0 的 β(q,t) ∝ ∇Depth(q,t) 与 v1.1 的 β(q,t) ∝ Depth(q,t) − avg{Depth(q′,t)} 本版删去：二者把方向关系写成比例式，且未申报其类别。

六、熟径锁定表达

定义复走加深作用：R(q,t) ≥ 0，表示沿 q 的复走在 t 步造成的加深（对应场篇第一方程2 的 Dτ）。R 的函数形式由具体场决定；本附件不立 R 与 Pr 的比例关系。

定义熟径：q 为熟径，当且仅当 Depth(q,t) \> 0，且 q 在申报窗口 W 内有常走记录（通过次数或频率达到申报判据）（场篇第一定义13）。

定义熟径锁定：F(q;T,W) 成立，当且仅当 q 为 W 内的熟径，且 W 按申报划分为子段 W₁,…,Wₙ，在每一子段上，比较任务 T\_k（K 含 q）满足：原读数中 q 独先（Lead\_q = 独先），且 B\_m^q(T\_k) 为真（抹平后 q 不再独先）。则：熟径锁定成立。

由定义，F ⇒ B\_m^q ⇒ B\_m，此即 B ≺ F 的必要方向。F 所要求的偏置绑定于 q 自身：q 在各子段的独先，依赖其沉积差。

B 成立而 F 不成立之见证：W 内只有一次输入，此次较深之 q 先得流，B 成立（第五节对照）；此后输入中断，q 在 W 内无常走记录，不为熟径，F 不成立。

注：v1.1 以 R ∝ Pr、∂Pr/∂t \> 0 与 ∂Cost/∂t \< 0、F(q) = lim R 界定熟径，本版删去：前二者以先出、代价下降等表现或结果量定义熟径，后者以强化之极限定义熟径，均与「熟是对深者的称谓，熟径是常熟之径」不合。

七、闭包回返表达

定义路径回返关系：qᵢ ↔ qⱼ，表示：路径之间存在稳定互返。

定义闭包：C ⊆ 𝒬(t)，满足：∀qᵢ,qⱼ ∈ C，存在：qᵢ ↝ qⱼ 且 qⱼ ↝ qᵢ，且 C 中各路径均满足熟径锁定 F（第六节），则：C 为闭包（本篇所论之子类，见定义七注）。

若不存在互返，则：结构仅单向滑落。故：闭包不可成立。

八、统流压缩表达

定义闭包统流强度：Φ(Cᵢ,t) = ∑Pr(q,t)，其中：q ∈ Cᵢ

定义有限竞争条件：∑\_{q ∈ ∪ᵢCᵢ} Pr(q,t) ≤ Λ(t)，按路径并集计，闭包重叠时共享路径只计一次（逐闭包相加 ∑Φ(Cᵢ,t) 会重复计数）。

定义资源计量：Occ(C,t) ≥ 0 为闭包 C 的资源占用；闭包族 𝒞 的总占用 Occ(𝒞,t) 按申报的重叠计量规则计算，规则须满足：互不相交部分的占用可加，共享部分只计一次，总占用不小于其任一部分的占用。资源容量约束：Occ(𝒞,t) ≤ V(t)。V(t) 与场篇第一 Cap(F) 的对应须另行申报换算，本附件不直接立此对应。份额约束与资源约束各自的用途，见极限附件第四节。

定义主导续行结构：C\*，满足：Φ(C\*,t) = max{Φ(Cᵢ,t)}

若：∀Cᵢ，Φ(Cᵢ,t) 相等，则：不存在唯一优先续行。故：主导续行结构不可定义。

定义统流压缩：U : {C₁,C₂,…} → C\*

九、抗散保持表达

定义自然退散函数：Ξ₀(q,t) ≥ 0，满足：在无复走加深条件下：Depth(q,t+1) \< Depth(q,t)（Depth \> 0 时），表示：结构存在自然退浅趋势。

抗散保持是资格，每步补偿量是复走加深作用 R(q,t)（第六节），二者分立。资格分两级：路径级保持资格 k\_W(q)，与依赖链中的闭包抗散保持 K\_W(C)。

定义路径级保持资格：k\_W(q) = 1，当且仅当在申报窗口 W = \[t₀, t₁\] 内，对一切 t ∈ W，Depth(q,t) ≥ δ\_K(q)，其中 δ\_K(q) \> 0 为申报的可复用下限；否则 k\_W(q) = 0。

接口（由总动力式，已证）：Depth(q,t) = Depth(q,t₀) + Σ\_{s=t₀}^{t−1}(R(q,s) − Ξ₀(q,s))。故 k\_W(q) = 1，当且仅当对一切 t ∈ W，Σ\_{s=t₀}^{t−1}(R(q,s) − Ξ₀(q,s)) ≥ δ\_K(q) − Depth(q,t₀)。

推论：若 Depth(q,t₀) ≥ δ\_K(q)，且 W 内每步 R(q,s) ≥ Ξ₀(q,s)，则 k\_W(q) = 1。等量补偿（R = Ξ₀）即可维持；严格大于对应净增长。补偿可逐步不等，只要累积亏损不超过初始余量 Depth(q,t₀) − δ\_K(q)。

k\_W 是一般的路径级资格，不预设闭包：一条无闭包回返的单向路径，沉积度恒为 2、下限为 1、每步 R = Ξ₀ = 0.1，亦有 k\_W = 1。故 k\_W 不是依赖链中预设 C 的那个 K。

定义承载路径：闭包 C 中的路径 q 为不可替代的承载路径，当且仅当从 C 中去掉 q 后，余下路径不再满足闭包条件（第七节）。其余路径为可替代路径。

定义闭包抗散保持：K\_W(C) = 1，当且仅当（1）C 在 W 内每一时刻满足闭包条件（第七节）；（2）C 的每一条不可替代承载路径 q 满足 k\_W(q) = 1。否则 K\_W(C) = 0。

由定义，K\_W(C) = 1 推出 C 在 W 内为闭包，此即 C ≺ K 的必要方向。依赖链中的 K 指 K\_W(C)。

若：C 的某一条不可替代承载路径 q 在 W 内累积亏损超过初始余量（k\_W(q) = 0），则：K\_W(C) = 0。可替代路径低于下限，不必使 C 失去保持资格。故：以 C 为基础的主导续行结构，在其闭包失去保持资格时，不能在 W 内维持。

注：v1.1 写 K \> Ξ₀ 方能维持、K ≤ Ξ₀ 则最终退散，未说明 K 与补偿量的关系，且排除了等量补偿；本版改为资格与补偿量分立，并把依赖链中的 K 定于闭包层。

十、续行绑定表达

定义续接函数：Bind : 𝒬(t) → 𝒬(t+Δ)，满足：Pr(Bind(q),t+Δ) \> Pr(q′,t+Δ)，其中 q′ 为其他候选路径。即：路径优先续接自身。

定义续行绑定：S(q) = Bind(q→q)

若：不存在优先自续接，则：系统每时刻重新散开。故：跨时稳定续接不可成立。

十一、总动力式

定义沉积动力变化（离散，对应场篇第一方程2）：

Depth(q,t+1) = Depth(q,t) + R(q,t) − Ξ₀(q,t)

其中：  
R(q,t)：复走加深作用；  
Ξ₀(q,t)：自然退散趋势。

此式是方程2 在路径层的申报写法；聚合方式非线性时，R、Ξ₀ 为聚合后的等效项。

量纲注：R、Ξ₀ 与 Depth 同量纲，为每步的沉积度变化量。R 为增加项，Ξ₀ 为减少项。各项的具体函数形式由具体场实现决定，本式给出结构性约束，不预设精确函数形式。

因此：沉积度净增，来自：复走加深压过退散（R \> Ξ₀），且未达底限。

偏置不另立增长项：沉积差不直接增加沉积度。其作用的路径是：较深者在比较条件下先得流（场篇第一定律5、定理17；在路径处，以严格阈序与 P₁₇ 成立为前提），得流而复走，复走产生加深作用 R。

又：沉积度变化对后续行进的作用，取方向而不取比例：同类可比结构中，沉积度愈深，其阈愈小（场篇第一方程3a）。在路径处，按第一节的路径阈规则分两级：同一机制且弱单调时，深者阈不高于浅者，在 C₌ 下深者不后得流（场篇第一定理17(a) 的论证对 θ(a) ≤ θ(b) 同样成立）；严格阈序成立（同一机制严格递减，或申报并核验 θ(a) \< θ(b)）且满足 C₌ 与 P₁₇ 时，深者先得流（定理17(b)）。平台或机制不同时，不由深度差单独推出严格先后。v1.1 的 ∂Pr(q,t)/∂t ∝ ∂Depth(q,t)/∂t 本版删去。

十二、稳定条件表达

定义稳定结构条件：Depth(q,t+1) = Depth(q,t)，即：结构进入稳定平衡。

于是：R(q,t) = Ξ₀(q,t)，即：复走加深刚好抵消自然退散。

定义稳定主导续行结构 q\*，满足：Depth(q\*,t+1) = Depth(q\*,t)，且：Depth(q\*,t) \> Depth(q,t)，其中 ∀q ≠ q\*（q 属于申报的比较对象）

即：该路径在稳定状态下，仍保持高于全部竞争路径的沉积度优势。

十三、依赖链表达

I ≺ T  
T ≺ H  
H ≺ D  
D ≺ B  
B ≺ F  
F ≺ C  
C ≺ U  
C ≺ K  
(U ∧ K) ≺ S

其中：A ≺ B 表示：B 成立时，A 必已成立（严格单向）。

十四、总动力表达式

Sedimentation-Dynamics = (I,T,H,D,B,F,C,U,K,S)

哲学性压缩：Structure = History-Bias under Finite-Competition（不是形式命题，见第十六节）

形式结论：Structure\_sed ⇒ B ⇒ ∂Future/∂History ≠ 0

即：沉积型主导续行结构成立，则续行偏置 B 必已成立；B 成立，则未来对历史存在非零依赖。两步均不可逆，见第十六节。

附件：沉积动力极限式

一、极限问题

沉积动力一般式已经说明：系统若形成并维持沉积型主导续行结构，则必具沉积度差、熟径锁定、闭包回返、统流压缩、抗散保持与续行绑定。

但问题仍未结束。因为：一般式说明的是：结构如何形成。而极限式进一步追问：结构形成之后，会不会无限增长？如果不会，它为何停止？如果会，它为何不吞没全场？

因此：极限式不再讨论：“结构能否形成”，而讨论：“结构能增长到哪里”。

二、极限约束

本附件各条标明类别：定义、额外假设、已证命题、定义性要求、概括表述。

先问：沉积度是否能够无限增长？

场篇第一定义9 给出内沉底限 δmax，即当前场状态下可继续稳定内沉之最大沉积深；δmax 可随场状态、束界、分辨条件与结构变化而变化。当前底限不等于跨时统一上界，不能据此推出路径沉积度终生有界。方向关系「愈深阈愈小」也不能推出：严格递减的阈可以趋向正下界，方向关系本身不足以推出单路径统治。

故本附件立额外假设：

假设 L1（一致上界）：对所论路径 q，存在不随时间变化的 Depth̄(q) \< ∞，使对一切 t，Depth(q,t) ≤ Depth̄(q)。

定义一：沉积度极限

L1 成立时，称 Depth̄(q) 为路径 q 的沉积度极限。（类别：定义，以 L1 为前提。）

三、退散极限

再问：沉积度在什么条件下趋稳？

由总动力式 Depth(q,t+1) = Depth(q,t) + R(q,t) − Ξ₀(q,t)，得累积式：Depth(q,t) = Depth(q,t₀) + Σ\_{s=t₀}^{t−1}(R(q,s) − Ξ₀(q,s))。

注：退散存在本身，不阻止沉积度逼近上界。例：Ξ₀ ≡ 0.1，R(t) = 0.1 + 2^{−(t+2)}，Depth(0) = 1/2，则 Depth(t) = 1 − 2^{−(t+1)}：始终有退散，沉积度仍趋近 1。本附件不作「退散阻止逼近上界」之断言。

定义二：极限稳定态

若 t → ∞ 时 Depth(q,t) 收敛于有限值 Depth^∞(q)，称路径 q 进入极限稳定态。（类别：定义。）

极限命题一（已证）：若路径 q 进入极限稳定态，则 R(q,t) − Ξ₀(q,t) → 0。  
证明：收敛则 Depth(q,t+1) − Depth(q,t) → 0，由总动力式即得。∎

逆不成立：步间变化趋零不推出收敛（例：Depth(t) = 1 + ½·sin√t，有界，步间变化趋零而不收敛）。故 R − Ξ₀ → 0 只表示「步间变化渐小」，不得自动称为最终平衡。

极限命题二（已证，充分条件）：若 L1 成立，且自某步 t₂ 起恒有 R(q,t) ≥ Ξ₀(q,t)，则 q 进入极限稳定态。  
证明：t ≥ t₂ 时 Depth(q,t) 单调不减，且以 Depth̄(q) 为上界，故收敛。∎

四、竞争极限

再问：闭包数量是否能够无限增长？

仅凭份额约束 ∑Pr ≤ Λ 不能推出闭包数量有限：份额之和受限时，仍可有无限多个正份额（例：Pr(qₙ) = 2^{−n}）。闭包重叠时，逐闭包相加还会重复计数。故数量问题以资源计量处理（附件一第八节：Occ、V(t)、重叠计量规则）。

假设 L2（正下界成本）：每个合格的稳定闭包，其独占部分（不与其他闭包共享的部分）的资源占用不小于 c\_min \> 0。

极限命题三（已证）：若资源容量约束与 L2 成立，则同时维持的合格稳定闭包数 N 满足 N ≤ V(t)/c\_min。  
证明：各闭包的独占部分互不相交。由重叠计量规则，总占用不小于各独占部分之并的占用，即不小于各独占部分占用之和 ≥ N·c\_min；又总占用 ≤ V(t)。∎

三种状态分立：  
接近容量：V(t) − Occ(𝒞,t) \< c\_min。此时在 L2 下，不压缩既有结构即不能再增一个合格闭包。  
达到容量：Occ(𝒞,t) = V(t)。  
超容：Occ(𝒞,t) \> V(t)，违反容量约束。只有超容可对应场篇第一方程15 的 Use(F) \> 1，且以 Occ、V 与 Cap(F) 的对应另行申报为前提。

定义三：竞争饱和

在 L2 下，场达到接近容量时，称进入竞争饱和。此时新增合格闭包必须压缩既有结构（由极限命题三的计数得出）。（类别：定义，所附结论以 L2 为前提。）

五、主导极限

再问：是否可能存在绝对主导续行结构？

本节讨论主导闭包之外的续行份额。闭包内部各路径之间的比较，以及嵌套于 C\* 的闭包之间按 Φ 的比较，不在本节读数之内；本附件不对其是否构成竞争作判定。

区分三种量：  
未用容量：Λ(t) − Σ\_{q∈∪ᵢCᵢ} Pr(q,t)；  
容量保留余量：Γ(t) = Λ(t) − Φ(C\*,t)（第七节）；  
主导闭包外的非共享续行份额：Φ\_out(t) = Σ\_{q∈∪ᵢCᵢ∖C\*} Pr(q,t)，即不与 C\* 共享的各闭包路径的份额（按路径并集计）。Φ\_out 不是闭包间竞争的完整读数：闭包可以重叠，他闭包可完全含于 C\*。例：C\* = {a, b, c}，份额 0.6、0.3、0.1，Φ(C\*) = 1；C₂ = {a, b}，Φ(C₂) = 0.9；此时 Φ\_out = 0，而 C\* 与 C₂ 仍可按附件一第八节的 Φ 比较。

Φ\_out(t) = 0 时，该时刻主导闭包之外没有非共享的续行份额。这不断言闭包之间无竞争（嵌套闭包仍可比较），不等于单路径（C\* 内部可有多条路径），也不等于沉积过程停止（C\* 仍可复走、加深，并以 R = Ξ₀ 抵消退散）。

又须分三种情形：  
（甲）有限时刻为零：某时刻 Φ\_out(t) = 0；  
（乙）渐近趋零：对一切 t 有 Φ\_out(t) \> 0，但 Φ\_out(t) → 0。在任一有限离散窗口内，取窗口内的最小值即得正下界；在无限时间上没有统一的正下界（例：Φ\_out(t) = 1/(t+1)，在 t = 0,…,10 内恒有 Φ\_out(t) ≥ 1/11，在 t ≥ 0 上无统一正下界）；  
（丙）候选通道仍存在：有份额为零、而结构上仍在且未受阻的闭包或通道，外部份额可在其重新得份额后恢复。  
Φ(C\*,t) → Λ(t) 是极限关系，不表示有限时刻已无其他正份额路径。

下称「持续沉积动力」：在申报的时间范围内，主导闭包外的非共享续行份额有正下界。时间范围须申报为以下二者之一：  
有限窗口持续性：对申报的有限窗口 W，存在 ε\_W \> 0（可依赖 W），使 t ∈ W 时恒有 Φ\_out(t) ≥ ε\_W；在离散有限窗口中，此即窗口内每一时刻 Φ\_out(t) \> 0。  
无限时间持续性：存在同一个 ε \> 0，使对一切 t ≥ t₀ 恒有 Φ\_out(t) ≥ ε。

定义四：主导极限

持续沉积动力要求：在申报的时间范围内，Φ\_out(t) 有正下界（有限窗口时为 ε\_W，无限时间时为统一的 ε）。（类别：持续沉积动力的定义性要求，不是已证结论。）

即：在持续沉积动力之下，主导闭包之外始终有不小于该下界的非共享续行份额。情形（乙）满足任一有限窗口持续性，不满足无限时间持续性；情形（丙）中候选通道的存在本身，不满足任一种持续性。此要求只关乎主导闭包外的非共享份额，不是闭包间竞争的完整刻画。

六、闭包极限

再问：闭包是否能够无限扩张？

定义闭包复杂度：Cx(C,t)，满足：Cx(C,t) ↑ with \|C\|，其中 \|C\| 表示闭包内部路径数量。Cx 取值于申报的定义域 𝒳 ⊆ ℝ≥0。（v1.1 记作 Ω(C,t)，与场篇第一的 Ω（稳定复走能力）同名异义，本版改记 Cx。）

复杂度与退散成本增长，不直接推出有限复杂度上限，须另立桥接：

假设 L3（退散随复杂度无界增长）：Ξ₀(C,t) ≥ h(Cx(C,t))，h 在 𝒳 上单调不减且无上界。  
假设 L4（维持资源有界）：闭包可得的复走加深 R(C,t) ≤ R̄ \< ∞。

记 S\_R = {x ∈ 𝒳 : h(x) ≤ R̄}。

极限命题四（已证）：在 L3、L4 下：（1）若 S\_R 为空，则不存在可不退的复杂度取值：每一闭包每步净退（R − Ξ₀ \< 0）；（2）若 S\_R 非空，记 Cxₘₐₓ = sup S\_R（有限）；闭包 C 在某步不退（R(C,t) ≥ Ξ₀(C,t)）时，该步 Cx(C,t) ≤ Cxₘₐₓ；复杂度超过 Cxₘₐₓ 的闭包，每步净退。  
证明：不退之步 h(Cx(C,t)) ≤ Ξ₀(C,t) ≤ R(C,t) ≤ R̄，故 Cx(C,t) ∈ S\_R。S\_R 为空时无不退之步，即（1）。S\_R 非空时，h 单调不减且无上界，故 S\_R 有上界，Cxₘₐₓ 有限，Cx(C,t) ≤ Cxₘₐₓ；后半为其逆否。∎

定义五：闭包极限

在 L3、L4 下且 S\_R 非空时，称 Cxₘₐₓ 为闭包极限；S\_R 为空时，报告「不存在可不退的复杂度取值」。（类别：定义，以 L3、L4 为前提。）

即：在所列假设下，不退之闭包的复杂度存在上限。

七、统流极限

再问：统流压缩是否能够无限增强？

若统流压缩使 C\* 占尽全部已用份额，则 Φ\_out(t) = 0：该时刻主导闭包之外没有非共享续行份额（第五节情形（甲））。嵌套于 C\* 的闭包仍可按 Φ 比较，C\* 内部仍可有可比较的路径，沉积过程本身也不必停止。

定义六：容量保留余量

定义：Γ(t) = Λ(t) − Φ(C\*,t)，其中 C\* 为当前主导续行结构。

则：Γ(t) 表示：份额上限中未被主导闭包占用的部分，包括未用容量与他闭包的份额。

Γ 是容量余量，不是外部续行份额。例一：只有一条实际路径，份额 0.5，Λ = 1，则 Γ = 0.5，但没有另一条有份额的路径。例二：C\* 含两路，份额 0.6、0.4，Λ = 1，则 Γ = 0，但闭包内部仍有两条可比较路径。若需要，可把 Γ(t) ≥ ε\_Γ \> 0 作为人为设定的容量保留条件申报；它与持续沉积动力不等价。

极限命题五（已证）：Φ\_out(t) ≤ Γ(t)。  
证明：Φ\_out(t) = Σ\_{q∈∪ᵢCᵢ} Pr(q,t) − Φ(C\*,t) ≤ Λ(t) − Φ(C\*,t) = Γ(t)。∎

故持续沉积动力推出：在同一时间范围内，Γ(t) 不小于同一下界；反之不然（例一）。

八、总极限式

本附件的极限分为三类：  
（一）已证命题：极限稳定态 ⇒ R − Ξ₀ → 0（极限命题一）；L1 且终有 R ≥ Ξ₀ ⇒ 极限稳定态（极限命题二）；L2 下合格闭包数有界（极限命题三）；L3、L4 下不退之闭包的复杂度有界，或不存在可不退的复杂度取值（极限命题四）；Φ\_out ≤ Γ（极限命题五）。  
（二）额外假设：L1 至 L4。  
（三）持续沉积动力的定义性要求：在申报的时间范围内 Φ\_out(t) 有正下界（有限窗口持续性或无限时间持续性）；Γ 不小于同一下界为其推论。

于是：沉积动力极限式写为：

R − Ξ₀ → 0（极限稳定态的必要条件）

under

∑Pr(q,t) ≤ Λ(t)，Occ(𝒞,t) ≤ V(t)，且：在申报的时间范围内 Φ\_out(t) ≥ ε（有限窗口时 ε = ε\_W）

即：稳定结构不是无限强化后的结果；在所列假设与要求下，稳定态以加深与退散相抵为必要条件。

九、极限定理

若系统满足：

1\. 沉积度一致有界（L1）；  
1\. 份额约束 ∑Pr ≤ Λ 与资源容量约束 Occ ≤ V 成立；  
1\. 合格闭包的独占成本有正下界（L2）；  
1\. 闭包退散随复杂度无界增长，且维持资源有界（L3、L4）；  
1\. 持续沉积动力在申报的时间范围内成立（有限窗口持续性或无限时间持续性，须申报其一）；

则：  
（一）每条所论路径的沉积度有极限 Depth̄(q)（定义一）；  
（二）路径若进入极限稳定态，则 R − Ξ₀ → 0；若终有 R ≥ Ξ₀，则必进入极限稳定态（极限命题一、二）；  
（三）同时维持的合格稳定闭包数不超过 V(t)/c\_min（极限命题三）；  
（四）S\_R 非空时，不退之闭包的复杂度不超过 Cxₘₐₓ；S\_R 为空时，无闭包可不退（极限命题四）；  
（五）在所申报的时间范围内，主导闭包外的非共享续行份额不小于其下界（条件 5），Γ(t) 亦不小于同一下界（极限命题五）。

上述条件不成立时，本定理不作断言。

十、最终压缩式

以下为本附件的概括表述，不是另立的形式命题：

主导闭包占尽全部已用份额（Φ\_out = 0）⇒ 主导闭包之外没有非共享续行份额（嵌套闭包仍可比较，闭包内部仍可有可比较的路径，份额为零的候选通道仍可存在）  
主导闭包外的非共享份额长期为零 ⇒ 不再有在主导闭包之外得份额而生成的新结构（沉积过程本身可继续）

因此：持续沉积动力，不是无限统治，而是有限竞争下的动态平衡。

再压缩为（哲学性压缩）：Structure = Finite-History-Balance

进一步，稳定结构的数学表达为：

Depth(q,t) → Depth^∞(q)（t → ∞，在极限稳定态下），此时 Depth(q,t+1) − Depth(q,t) → 0

即：稳定结构趋向沉积度收敛的动态平衡，而非无限增长；步间变化趋零是其必要条件，不是充分条件。
