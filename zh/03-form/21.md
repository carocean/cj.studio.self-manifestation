自显论·式篇第二十一 v1.0

# 非社一般式

本篇总命题：

承认系统中存在个体场与社会场的耦合，并承认耦合来源于个体功能缺口——那么，社会耦合的维持结构是什么？它在什么最小条件下成立？又在什么最小条件下必然趋向瓦解？

也就是说：

在个体场已存在、社会场已形成耦合之后，系统必须对这种耦合的来源给出结构性解释。

本文证明：社群依赖不是自显体的本质属性，而是在功能缺口条件下由系统内部结构维持的耦合结果。只要功能缺口的维持结构不稳定，社群依赖就必然趋向极限瓦解。

我们的目标是：

得到社会依赖的最小维持结构，并证明该维持结构在自显体演化路径上结构性不稳定，从而证明：在功能性社群依赖的缺口消解路径中，非社终态是唯一结构性稳定极限。

那么，我们先给出结果。

最小非社一般式

NST(f) ⇐ ∀j ∈ KeyFunctions：NeedBound\_j \< ∞ ∧ PathSufficient\_j ∧ T\_j（极小充分结构，非充要）

注：本篇所给为充分结构而非充要一般式——三条件联立足以推出 NST(f)，但不排除存在其他路径（如边界吸收式，见附件五）同样可达非社终态。

一句话

社群存在，因为缺口存在；  
缺口的维持结构不稳定；  
在功能性社群依赖的缺口消解路径中，缺口趋零是唯一结构性稳定极限。

1\. 引言

社篇已经说明：社会场不是个体的简单集合，而是多个个体场长期耦合后形成的跨场共核结构。社会依赖也不是一个先天事实，而是在个体能力不足以覆盖关键功能时，由群体支持补足缺口所形成的维持关系。

因此，本篇不再讨论社会场如何生成，而是进一步追问：

社会依赖靠什么维持？  
这个维持结构是否能够永久成立？  
若不能永久成立，非社终态如何从一般式中被逼出？

本篇的核心转折在于：不再把”人是社会动物”作为起点，而是把社群依赖还原为功能缺口的函数。只要社群依赖成立，就必然存在至少一个关键维度上的 CapacityGap；只要 CapacityGap 不能永久维持，SocialDependency 就必然趋零。

由此，本篇要证明的不是”个体选择离开社会”，而是：在自显体可持续扩展、工具化不断推进、外接能力路径充分打开的条件下，功能性社群依赖会被结构性消解。非社终态不是心理选择，也不是伦理主张，而是功能缺口趋零之后出现的结构性极限。

1\. 论证流

我们采用不断追问的方式，从上往下，一步一步逼出最小结构。

一，

先问最浅的一层：

社群依赖是不是自显体的本质属性？

若是，则它无条件存在，不需要维持结构，也无法趋向瓦解。

但只要承认以下事实——社会中存在无社群依赖的个体，存在历史上社群解体后个体继续存活的案例——就已经说明：社群依赖不是无条件的。

因此，社群依赖必然有其成立条件。

这里要把”社群依赖”锁定下来。

定义一：社群依赖

SocialDependency(f) \> 0 当且仅当：

∃ j ∈ KeyFunctions：CapacityGap\_j(f) \> 0

即：在至少一个关键功能维度上，存在个体能力尚未覆盖的功能缺口。

若对所有 j，CapacityGap\_j(f) = 0，则 SocialDependency(f) = 0。

注：CapacityGap\_j 是功能性缺口，不等同于实际社交行为。个体可以不使用群体支持，但只要 GroupSupport\_j \> IndividualCapacity\_j，功能性缺口仍成立；此时 SocialDependency 描述的是潜在功能依赖，而非现实互动频率。

二，

既然社群依赖有成立条件，那么再问：

社群依赖的成立条件是什么？

由定义一，成立条件是：

CapacityGap\_j(f) := max(0, GroupSupport\_j(f) − IndividualCapacity\_j(f)) \> 0

对至少一个 j 成立。

这就把问题转移了：

社群依赖的成立，等价于功能缺口的成立。

这里要把”功能缺口”锁定下来。

定义二：功能缺口

CapacityGap\_j(f) := max(0, GroupSupport\_j(f) − IndividualCapacity\_j(f))

CapacityGap\_j(f) = 0 表示第 j 维度的缺口已被个体能力覆盖。

SocialDependency(f) = 0 当且仅当 ∀ j：CapacityGap\_j(f) = 0。

三，

那么功能缺口能否永久维持？

只有两种情形可以使 CapacityGap\_j 永久非零（完备性：CapacityGap\_j \> 0 等价于 GroupSupport\_j \> IndividualCapacity\_j，后者永久成立当且仅当以下两种情形之一成立）：

情形一：GroupSupport\_j 永久高于 IndividualCapacity\_j（且差距不缩小）→ 对应条件（一）不成立：GroupSupport\_j 没有有限上界，或其上界持续高于 IndividualCapacity\_j 的可达上界  
情形二：IndividualCapacity\_j 的增长被永久封顶于 GroupSupport\_j 之下 → 对应条件（二）不成立：IndividualCapacity\_j 的增长被单一场容积或外部垄断永久封顶

若这两种情形都不成立（即两个对应条件都成立），功能缺口就无法永久维持。

四，

现在问：GroupSupport\_j 是否有有限上界？

GroupSupport\_j 的内容是：在第 j 个关键功能维度上，群体为个体提供的最大功能增益。

但 GroupSupport\_j 的上界取决于个体的实际功能需求——群体无法为个体提供超过其实际需求的功能支持（超出需求的支持不进入 CapacityGap 的计算）。

因此：

只要个体实际功能需求存在有限上界 NeedBound\_j \< ∞，GroupSupport\_j 就存在有限上界。

这里要把”群体功能有限上界”锁定下来。

定义三：有限需求上界

对任意个体场 f，∃ NeedBound\_j \< ∞，使个体在第 j 维度的实际功能需求不超过 NeedBound\_j。

由此推出群体功能有限上界：GroupSupport\_j(f) ≤ NeedBound\_j，因为群体无法为个体提供超过其实际需求上界的功能支持（超出上界的支持不进入 CapacityGap 的计算）。

条件一正式表述为：∃ NeedBound\_j \< ∞，GroupSupport\_j(f) ≤ NeedBound\_j（有限需求蕴含有限群体支持上界）。

此条件不预设 NeedBound\_j 的具体值，只要求个体实际功能需求有限——这是自显体有限性的基本前提。

五，

既然 GroupSupport\_j 有有限上界，那么 CapacityGap\_j 的消解取决于：

IndividualCapacity\_j(f) 能否达到 NeedBound\_j。

这里要把”个体有效能力的增长”锁定下来。

定义四：个体有效能力

IndividualCapacity\_j(f) = NativeCapacity\_j(f) + ExtendedCapacity\_j(f)

其中 NativeCapacity\_j 为个体场自身原生能力；ExtendedCapacity\_j 为通过工具、宿体、外接、并联等扩展机制获得的有效能力增量。

关键问题：ExtendedCapacity\_j 的增长是否被单一场容积（Cap\_f）封顶？

这里要把”扩展能力不被场封顶”锁定下来。

定义五：外接能力路径存在且充分

条件二的正式表述：记 PathSufficient\_j := ExternalExtensionPath\_j ≠ ∅ ∧ sup(ExtendedCapacity\_j) \> NeedBound\_j——即存在至少一条通过外部资源（工具、宿体、外接系统、并联结构）扩展第 j 维度能力的路径，该路径不依赖单一场 f 的内部容积（Cap\_f），且该路径的能力上界超过个体实际需求上界 NeedBound\_j。

注：路径存在（ExternalExtensionPath\_j ≠ ∅）不自动蕴含路径充分（sup(ExtendedCapacity\_j) \> NeedBound\_j）——若外部资源本身有限上界低于 NeedBound\_j，则即使路径存在，CapacityGap\_j 仍无法趋零。因此条件二须同时满足路径存在与路径充分两项。

条件二与条件三独立：条件二说明”能力扩展的结构性路径存在且充分”，条件三说明”群体功能向个体能力的转化过程持续发生”；两者相互支撑——条件三的进行使条件二的路径被实际激活，但两者的成立条件不互相预设。

六，

那么，既然 IndividualCapacity\_j 可以原则上超过 NeedBound\_j，CapacityGap\_j 是否必然趋零？

还差一步。

IndividualCapacity\_j 超过 GroupSupport\_j 需要一个过程——群体原本提供的功能需要被工具化并归入个体有效能力。若这个过程被永久阻断，CapacityGap\_j 的消解就永久不发生。

这里要把”工具化进程”锁定下来。

定义六：工具化进程

ToolizationRate\_j(f,t) 表示第 j 维度上，群体功能被工具替代并归入 ExtendedCapacity\_j 的速率。

工具化进程不永久归零，并具有长期累积有效量，在本篇中取强形式：

T\_j := ∫₀^∞ ToolizationRate\_j(f,t) dt = ∞

即：工具化进程在无限时间尺度上具有累积有效量，不在有限时间后永久归零。

七，

现在问：工具化进程能否被永久阻断？

历史上，所有尝试永久阻断技术扩散的机制均已失败——文字、印刷术、互联网的扩散均未被永久阻断。这不是经验归纳，而是结构性原因：

工具化的动力来源于 CapacityGap 本身——只要缺口存在，就有填补缺口的结构性压力；这个压力使工具化进程在长期内不会永久停止。永久阻断工具化，需要永久维持阻断机制，而阻断机制本身消耗资源、积深有限、无法无限维持。

因此：在缺口压力仍存在的路径上，工具化进程不能被结构性永久阻断。

这里要把”永久阻断不可持续”锁定下来。

定义七：阻断不可持续

任何阻断 ToolizationRate\_j 的机制，本身作为社会场结构，受场篇压缩动力约束——其积深有限、维持成本随规模超线性增长，无法在无限时间上维持有效阻断。

故在充分长时间内，工具化进程不会永久归零，并具有累积有效量。

八，

到这里，三个最小条件已经被逐步逼出：

条件一：NeedBound\_j \< ∞，GroupSupport\_j ≤ NeedBound\_j（有限需求蕴含有限群体支持上界）  
条件二：PathSufficient\_j 成立，即外接能力路径存在且充分（ExternalExtensionPath\_j ≠ ∅ ∧ sup(ExtendedCapacity\_j) \> NeedBound\_j）  
条件三 T\_j：∫₀^∞ ToolizationRate\_j(f,t) dt = ∞（工具化进程不永久归零，长期具有累积有效量）

这三条构成在本篇缺口消解路径下推出 CapacityGap\_j → 0 的极小充分结构。

缺少任意一条：

无条件一：GroupSupport\_j 可以无限增长，CapacityGap\_j 永久维持（需求同步扩展情形）  
无条件二：ExternalExtensionPath\_j = ∅ 或 sup(ExtendedCapacity\_j) ≤ NeedBound\_j，IndividualCapacity\_j 无法超过 NeedBound\_j，CapacityGap\_j 永久维持  
无条件三：工具化被永久阻断，IndividualCapacity\_j 无法超过 GroupSupport\_j，CapacityGap\_j 永久维持

三条同时成立，才能推出：

lim(t→∞) CapacityGap\_j(f,t) = 0（∀ j ∈ KeyFunctions）

⇒ lim(t→∞) SocialDependency(f,t) = 0

⇒ NST(f)（非社终态）

九，

现在问：三条件能否同时永久不成立？

条件一的对立面（GroupSupport\_j 无有限上界）要求个体实际功能需求无限——这与自显体有限性矛盾。在自显体有限性前提下，条件一结构性成立。

条件二的对立面（ExtendedCapacity\_j 被永久封顶）要求外接路径不存在或路径能力上界不足。条件二须由 PathSufficient\_j 独立保证：即外接路径存在（ExternalExtensionPath\_j ≠ ∅）且路径能力上界超过 NeedBound\_j（sup(ExtendedCapacity\_j) \> NeedBound\_j）。条件三（T\_j 成立）只能说明工具化进程不会永久停止，不能单独推出条件二——工具化持续发生不等于外接路径充分。两者分别独立成立：条件二保证路径充分，条件三保证路径被持续激活，共同推出 ExtendedCapacity\_j 实际持续增长并最终超过 NeedBound\_j。

条件三的对立面（工具化被永久阻断）已由定义七证明结构性不可持续。

在自显体可持续扩展路径上，三条件若同时成立，则 CapacityGap → 0 是结构性极限，在功能性社群依赖的缺口消解路径中，非社终态是唯一结构性稳定极限。

1\. 最小非社结构一般式

由上述追问链，可以正式写出：

最小非社结构（MinNonSocial(f)）：

MinNonSocial(f) = (Δ\_j, NeedBound\_j, PathSufficient\_j, T\_j)

其中：

Δ\_j：功能缺口，= max(0, GroupSupport\_j − IndividualCapacity\_j)，为社群依赖的直接来源

NeedBound\_j：有限需求上界，∈ (0, ∞)，使 GroupSupport\_j(f) ≤ NeedBound\_j

PathSufficient\_j：外接能力路径存在且充分，即 ExternalExtensionPath\_j ≠ ∅ ∧ sup(ExtendedCapacity\_j) \> NeedBound\_j

T\_j：= ∫₀^∞ ToolizationRate\_j(f,t) dt = ∞（工具化长期累积有效量，不永久归零）

三条件成立等价于：

NeedBound\_j \< ∞（有限需求上界成立）  
ExternalExtensionPath\_j ≠ ∅ 且 sup(ExtendedCapacity\_j) \> NeedBound\_j（外接路径存在且充分）  
T\_j：∫₀^∞ ToolizationRate\_j(f,t) dt = ∞（长期累积有效工具化量）

三条件同时成立，则：

lim(t→∞) Δ\_j(f,t) = 0（∀ j）

⇒ lim(t→∞) SocialDependency(f,t) = 0

⇒ NST(f)

1\. 总定理

非社必然性定理（极小版）：

在自显体有限性前提下，若同时成立：

（一）NeedBound\_j \< ∞，GroupSupport\_j(f) ≤ NeedBound\_j  
（二）PathSufficient\_j 成立，即 ExternalExtensionPath\_j ≠ ∅ 且 sup(ExtendedCapacity\_j) \> NeedBound\_j  
（三）T\_j 成立，即 ∫₀^∞ ToolizationRate\_j(f,t) dt = ∞

则：

lim(t→∞) CapacityGap\_j(f,t) = 0（∀ j ∈ KeyFunctions）

⇒ lim(t→∞) SocialDependency(f,t) = 0

⇒ NST(f)

证明：

由条件（一），GroupSupport\_j ≤ NeedBound\_j \< ∞，故 CapacityGap\_j = max(0, GroupSupport\_j − IndividualCapacity\_j) 的正值部分被 NeedBound\_j 上界约束；

由条件（三）T\_j 成立（∫₀^∞ ToolizationRate\_j dt = ∞），在 ToolizationRate\_j 有效映射到 ExtendedCapacity\_j 的前提下，工具化进程长期具有累积有效量，使群体功能持续被工具化并归入 ExtendedCapacity\_j；

由条件（二）PathSufficient\_j 成立（ExternalExtensionPath\_j ≠ ∅ 且 sup(ExtendedCapacity\_j) \> NeedBound\_j），外接路径上界超过 NeedBound\_j，工具化积分发散意味着路径被持续有效激活，累积增量最终超过 NeedBound\_j；故 ∃ T₁，∀ t \> T₁：IndividualCapacity\_j(t) \> NeedBound\_j ≥ GroupSupport\_j(t)；

三条件联立：Δ\_j(f,t) = max(0, GroupSupport\_j − IndividualCapacity\_j) → 0（∀ j）；

由 SocialDependency 定义（社篇第十九），SocialDependency = Σ\_j w\_j · Δ\_j / Σ\_j w\_j · GroupSupport\_j；GroupSupport\_j 保持正值（Δ\_j → 0 通过 IndividualCapacity\_j 上升实现，非 GroupSupport\_j 退化，故分母非零）；

故 SocialDependency → 0，NST(f) 成立。∎

极小充分性：

无条件（一）：GroupSupport\_j 可以同步增长，CapacityGap\_j 不趋零，NST(f) 不成立。  
无条件（二）：IndividualCapacity\_j 被永久封顶，无法超过 NeedBound\_j，CapacityGap\_j 不趋零，NST(f) 不成立。  
无条件（三）：工具化被永久阻断，IndividualCapacity\_j 无法吸收 GroupSupport\_j，CapacityGap\_j 不趋零，NST(f) 不成立。

故三条件构成 NST(f) 的极小充分结构。∎

1\. 击穿论证

反例一（需求同步扩展）：若 GroupSupport\_j 与 IndividualCapacity\_j 同步无限增长（个体需求无限），则 CapacityGap\_j 可以永久非零——但此时条件（一）不成立（GroupSupport\_j 无有限上界）。这说明非社终态依赖个体实际需求有限性，而非绝对能力比较。此为条件（一）的边界，不推翻定理。

反例二（永久技术封锁）：若极端技术垄断使 ExtendedCapacity\_j 永久无法增长，则条件（二）不成立，CapacityGap\_j 无法趋零。但由定义七，永久封锁本身作为社会场结构，维持成本超线性增长，结构性不可持续——在充分长时间内封锁必然松动，条件（二）在长期成立。此为时间尺度上的边界，不推翻定理。

反例三（群体同步升级）：若群体持续升级使 GroupSupport\_j 的增速持续超过 IndividualCapacity\_j，则条件（一）虽成立（NeedBound\_j 有限），但缺口可能先扩大后才趋零。这说明趋零的速度取决于增速比较，但只要三条件成立，极限仍为零。此为速度上的边界，不推翻定理。

定义域边界四（情感维度未纳入）：即使功能性社群依赖趋零，情感性耦合仍可能长期存在。由于本篇只讨论 CapacityGap 所定义的功能依赖，而不讨论情感依赖的一般式，故 NST(f) 仅表示功能非社终态，不表示情感依赖必然消失。情感依赖的一般式留待后续篇章。此为本定理的定义域边界，而非反例。

定义域边界五（能力退化）：若 IndividualCapacity\_j 发生持续结构性退化（老龄失能、宿体损坏、外接系统断开等），则已消解的 CapacityGap\_j 可以重新出现，NST(f) 不再保持。因此本篇讨论的是能力扩展路径上的极限结构，不讨论能力衰减路径——附件三消解不可逆条件已明确”IndividualCapacity\_j 不发生结构性退化”为前提。此为成立条件的显式边界，补强本定理的适用范围。

1\. 总式

最小非社一般式：

SocialDependency(f) \> 0 ⟺ ∃ j：CapacityGap\_j(f) \> 0（社群依赖的充要条件是功能缺口的存在）

NST(f) ⟺ lim(t→∞) SocialDependency(f,t) = 0 ⟺ ∀ j：lim(t→∞) CapacityGap\_j(f,t) = 0

三条件（NeedBound\_j \< ∞ ∧ PathSufficient\_j ∧ T\_j）构成 NST(f) 的极小充分结构

其中 PathSufficient\_j := ExternalExtensionPath\_j ≠ ∅ ∧ sup(ExtendedCapacity\_j) \> NeedBound\_j

社群不是自显体的本质属性，而是缺口的函数——社群存在因为缺口存在，缺口趋零则社群依赖趋零，非社终态是功能性社群依赖缺口消解路径中的唯一结构性稳定极限。

附注：边界吸收式路径详见附件五。

最后压成最简三句：

社会场由耦合形成；  
社群依赖由缺口维持；  
缺口趋零，则非社终态成立。

T\_j：= ∫₀^∞ ToolizationRate\_j(f,t) dt = ∞，工具化长期累积有效量；τ\_j 已升级为 T\_j；  
NST(f)：非社终态，= lim(t→∞) SocialDependency(f,t) = 0；引自社篇第二十。

附件一：非社表达式

一、基本域与记号

设个体场为 f，关键功能维度集合为 J = {j₁, j₂, …, jₙ}。  
设 GroupSupport\_j(f) ∈ ℝ⁺ 为第 j 维度群体功能支持。  
设 IndividualCapacity\_j(f) ∈ ℝ⁺ 为第 j 维度个体有效能力。  
设权重函数 w\_j \> 0，∑\_j w\_j = 1。

二、功能缺口表达式

CapacityGap\_j(f) := max(0, GroupSupport\_j(f) − IndividualCapacity\_j(f))

即：

CapacityGap\_j(f) = 0 ⟺ IndividualCapacity\_j(f) ≥ GroupSupport\_j(f)  
CapacityGap\_j(f) \> 0 ⟺ IndividualCapacity\_j(f) \< GroupSupport\_j(f)

三、社群依赖表达式

SocialDependency(f) := (∑\_j w\_j · CapacityGap\_j(f)) / (∑\_j w\_j · GroupSupport\_j(f))

前提：∑\_j w\_j · GroupSupport\_j(f) \> 0

满足：

SocialDependency(f) ∈ \[0, 1\]  
SocialDependency(f) = 0 ⟺ ∀ j：CapacityGap\_j(f) = 0  
SocialDependency(f) = 1 ⟺ 在所有 GroupSupport\_j(f) \> 0 的维度上，IndividualCapacity\_j(f) = 0

四、非社条件表达式

NonSocialCondition(f) ⟺ SocialDependency(f) = 0 ⟺ ∀ j ∈ J：CapacityGap\_j(f) = 0

五、有效能力分解式

IndividualCapacity\_j(f) = NativeCapacity\_j(f) + ExtendedCapacity\_j(f)

其中：

NativeCapacity\_j(f) ≥ 0（原生能力，受 Cap\_f 约束）  
ExtendedCapacity\_j(f) ≥ 0（扩展能力，不受单一 Cap\_f 封顶）

附件二：非社极限式

一、时间域

设时间域 𝕋 = \[0, +∞)，CapacityGap\_j(f,t) 为时刻 t 的功能缺口。

二、非社终态极限式

NST(f) ⟺ lim\_{t→∞} SocialDependency(f,t) = 0

等价表达：

在 ∑\_j w\_j · GroupSupport\_j(f,t) \> 0 且不趋于 0 的前提下：

NST(f) ⟺ ∀ j ∈ J：lim\_{t→∞} CapacityGap\_j(f,t) = 0

三、极限成立条件

定义三个结构条件：

N\_j：NeedBound\_j \< ∞，即 ∃ M\_j \< ∞，GroupSupport\_j(f) ≤ M\_j

P\_j：PathSufficient\_j，即 ExternalExtensionPath\_j ≠ ∅ ∧ sup(ExtendedCapacity\_j) \> NeedBound\_j

T\_j：∫₀^∞ ToolizationRate\_j(f,t) dt = ∞，即工具化进程不永久归零且长期具有累积有效量

四、极限定理

若 N\_j ∧ P\_j ∧ T\_j 对所有 j ∈ J 成立，则 NST(f) 成立。

即：

(∀j：N\_j ∧ P\_j ∧ T\_j) ⇒ NST(f)

五、极限速率界

设 CapacityGap\_j(f,t) 在三条件下单调趋降，则：

∀ ε \> 0，∃ T\* \< ∞：∀ t \> T\*，CapacityGap\_j(f,t) \< ε（∀ j）

即缺口在极限意义下趋零，不要求在有限时刻精确归零。

附件三：非社消解式

一、消解路径

CapacityGap\_j(f,t) 的消解由三个算子的复合实现：

Toolization\_j：GroupSupport\_j → ExtendedCapacity\_j（工具化算子；速率 ToolizationRate\_j \> 0）  
Expansion\_j：ExtendedCapacity\_j → ExtendedCapacity\_j + Δ（外接扩展算子；PathSufficient\_j 成立时激活）  
Bound\_j：GroupSupport\_j ≤ M\_j（有限上界约束；NeedBound\_j \< ∞ 时成立）

二、消解动力方程

∂CapacityGap\_j(f,t)/∂t ≤ −κ\_j · ToolizationRate\_j(f,t) · ExtensionActive\_j(t)，其中 κ\_j \> 0

其中 ExtensionActive\_j(t) = 1 若 PathSufficient\_j 成立，否则为 0。

三、消解充分条件

CapacityGap\_j(f,t) → 0 的充分条件：

∫₀^∞ ToolizationRate\_j(f,t) dt = ∞（即 ToolizationRate\_j 不在有限时间后永久归零，且反复有效激活）  
∧ ExtensionActive\_j(t) = 1（外接路径激活）  
∧ GroupSupport\_j(f) ≤ M\_j \< ∞（有限上界）

四、消解不可逆条件

若 CapacityGap\_j(f,t₀) = 0 且 dGroupSupport\_j/dt = 0 且 IndividualCapacity\_j 不发生结构性退化，则：

CapacityGap\_j(f,t) = 0（∀ t \> t₀）

即：缺口一旦消解，在群体功能不增长且个体能力不退化的条件下，消解不可逆。

三者不构成时间先后关系，而是结构联立关系：

N\_j 为边界约束（GroupSupport\_j 有有限上界，为缺口消解的终止条件）  
P\_j 为通道条件（外接路径存在且充分，为能力扩展的结构前提）  
T\_j 为激活动力（工具化进程不永久停止，使路径被实际激活）

N\_j ∧ P\_j ∧ T\_j ⇒ CapacityGap\_j → 0

附件四：非社相图式

一、相图设定

SocialDependency(f) 不是单一数值，而是多维功能缺口向量：

Δ(f) = (CapacityGap\_j₁, CapacityGap\_j₂, …, CapacityGap\_jₙ)

不同维度的缺口组合构成不同的社会态，单一数值无法区分其结构差异。

为此定义二维相图，以两个独立轴描述社会依赖的基本结构：

横轴：FD（功能依赖度）= (∑\_{j∈FuncDims} w\_j · CapacityGap\_j(f)) / (∑\_{j∈FuncDims} w\_j · GroupSupport\_j(f))  
纵轴：PD（情感依赖度）= (∑\_{j∈PsychDims} w\_j · CapacityGap\_j(f)) / (∑\_{j∈PsychDims} w\_j · GroupSupport\_j(f))

其中 FuncDims = {感知扩展、行动执行、构造制造、沟通信息获取、认知运算、存续修复}  
PsychDims = {情感认同、文化归属、意义生成、精神体验}（留待后续篇章形式化）

二、四象限相态

S1（完全社会态）：FD 高 ∧ PD 高

功能与情感均高度依赖群体。  
对应：蚂蚁、蜜蜂、白蚁等真社会性昆虫；裸鼹鼠、狼群、虎鲸群等高度协作型动物；早期氏族/部落共同体。社群在多数关键维度上构成存续、繁殖与学习优势；在真社会性昆虫中接近”离群即结构崩解”，在哺乳动物与人类共同体中则表现为高度功能增益与协作依赖。越靠近灵长类与人类共同体，PD 与文化依赖权重越高。

S2（工具化社会态）：FD 低 ∧ PD 高

功能依赖已通过工具化消解，情感依赖仍然强烈。  
对应：当代高度工业化人类——技术使物质功能独立，但情感归属仍依赖他者。  
SocialDependency 的功能分量趋零，但情感分量维持。

S3（功能非社态）：FD 低 ∧ PD 低（中）

功能依赖消解，情感依赖减弱但仍存在。  
对应：本篇主定理的 NST(f)——功能性非社终态。  
此态下社群关系变为可选，而非结构性强制。

S4（完全非社态）：FD → 0 ∧ PD → 0

功能与情感依赖均趋零，或边界吸收使两者定义失效。  
对应：NST\_A（附件五边界吸收式）——总场直接生成精神体验，他者不再是精神需求的前提。  
此态为非社的更完备形式。

在三条件成立时（附件三），演化轨迹为：

S1 → S2 → S3（→ S4）

即：

功能依赖先行消解（工具化进程）  
情感依赖后续消解（精神需求内生化，或边界吸收）

两轴不同步：FD 消解速度通常快于 PD，故 S2 为历史过渡态。

附件五：边界吸收式

一、基本设定

设总场为 F，个体场集合为 {f\_i}，i ∈ I。

定义场包含关系：f\_i ⊂ F（个体场 f\_i 被吸收入总场 F，成为其子结构）。

二、边界消解条件

若 f\_i ⊂ F，则：

Boundary(f\_i, F) → 0（f\_i 与 F 的边界趋零）

⇒ GroupSupport\_j(f\_i) 与 IndividualCapacity\_j(f\_i) 不再可分

⇒ CapacityGap\_j(f\_i) 定义失效

即：非社不表现为 CapacityGap → 0，而表现为 CapacityGap 不再可定义。

三、边界吸收式定义

BoundaryAbsorption(f\_i, F) ⟺

f\_i ⊂ F  
∧ ∀ j：GroupSupport\_j(f\_i) − IndividualCapacity\_j(f\_i) 无定义

⇒ NST\_A(f\_i)（吸收型非社终态）

NST\_A(f\_i) ≠ NST(f\_i)：

NST(f\_i)：缺口消解型非社——CapacityGap\_j → 0，定义仍成立，数值趋零  
NST\_A(f\_i)：边界吸收型非社——CapacityGap\_j 定义失效，区分本身瓦解

四、精神需求内生化与着色回路

在边界吸收式下，精神需求可由总场直接内生生成：

PsychologicalNeed(f\_i) ← F（总场直接供给）

不依赖外部他者，情感非社条件在此路径下成立。

真梦结构为其典型实现：总场生成的精神体验真实如现实感知，完备精神世界由总场而非他者提供。

注：情感依赖的消解不等于情感本身的消失。依据内篇第十七《着色》：情感（着色）是附着于意象之上的偏流——着色回路与其他回路并作，生成着色意象，附着于意象场中的对象之上，产生好恶、亲疏、偏好与个性。情感的存在依赖的是意象对象，而非意象对象必须来自外部他者。

故 NST\_A 下的非社不是情感枯竭，而是情感的意象来源从外部他者转移到总场内生结构——着色回路的对象由总场供给，好恶偏好完整保留。

五、两式关系与统一

NST(f)：缺口消解路径，本篇主定理
