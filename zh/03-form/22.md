自显论·式篇第二十二 v1.2

# 观界一般式

本篇试论一个总命题:

承认”并非一切皆可显现”这一事实,一定意味着:系统内部存在一套结构,使可显与不可显之间形成稳定且可变的划分。观界不是感受器的物理极限,而是候选化、限域与收束可达性共同压出的结构边界;在界外存在条件 H\_excl 下,它是池内结构集的真限制,并随容量、退散、熟径与取向而变形。

编次与推导链位置的说明:本篇按成稿次序编为式篇第二十二;其逻辑位置居观者诸式(式篇第四、第五)之后、误外化诸式(式篇第七至九)之前——观者给出”谁在占据”,观界给出”什么能进入占据的竞争”,误外化给出”占据者如何被归属来源”。

本篇与相邻各篇的分工:

式篇第四、第五处理占据的生成与机制:在已进入竞争的候选中,为何恰有一个被维持为当前。本篇处理更早的一道划分:池内的全部结构中,哪些能够进入这场竞争、并在原则上可被收束——哪些永远不能。前者是竞争之内的唯一性问题,本篇是竞争资格与可显性的边界问题。

与识界诸式(式篇第十三至十七)的分工:观界是显现边界——某结构能否被点亮(其前置两门给出竞争资格);识界是分辨边界——已显现者能够被分成什么样。某物可分而不可入,某物可入而难分,二者正交。观界随容量与取向实时伸缩;识界是不可区分关系经闭包稳定后的结构极限,只有关系本身改变才能突破。

与池界(观者组式:池轨之分层定义与预识别协议,见观者个体化数理式第六节)的分工:池界是个体化边界,划定谁构成一个观者、一个系统里有几个观者;观界在一个已成立的观者之内起作用,划定该观者能点亮什么。池界逻辑上在先:先有”恰是一个观者”,才谈得上它的观界。

我们的目标是:

得到观界结构的最小范式模型,给出其存在性与非平凡性成立的条件,给出界形的决定项与变界动力,并给出可检验推论与击穿路径。

先给出结果。

最小观界一般式

E(t) = Cand(t) ∩ Adm(t)(资格域:已具竞争资格者,而非已在竞争者)  
W(t) = E(t) ∩ Reach(t)(可显域,即观界:在当前结构与参数下原则上可被点亮者)  
M(t) = E(t) ∖ W(t)(界缘:已具竞争资格、但在当前参数下不可达显现的滞留带)

在池已成立、物化前提(连续输入、有限资源)与收束动力(观者数理式候选运行诸定义;其系数为条件构造,见观者构造式 H6)同时成立的情况下,池内结构集上形成可显域 W(t) ⊆ E(t) ⊆ Ξ(P):在界外存在条件 H\_excl 下,W(t) 为真子集;在恰一区(已存在被维持占据的时段)内,W(t) 非空;在显现空缺区内,W(t) = ∅,而 E 与 M 仍保持观界结构。W 由三道门的交集给出:候选化之门、限域之门、收束可达之门。任一结构不过其中一道门,即在当前结构与参数下位于观界之外,无论其物理上离感受器多近、强度多大;若强刺激改变了候选化通道或系统参数,那属于变界(W 本身被改写),而非界外内容的直接显现。

一句话

显现有界(其为真界依 H\_excl);界不是射程,而是结构;界形不固定,随参数而变。

摘要

观者诸式已经说明:在多候选并存与确定性缺口下,恰有一个候选被维持为当前。于是问题向前推进一步:候选从何而来?为什么有些结构永远成不了候选?为什么同一结构在此刻可显、在彼刻不可显?

本篇提出:可显与不可显的划分,既不是感受器的物理射程,也不是注意的同义词,而是三个独立条件的合取——结构须可被展开为候选(候选化),须通过候选限域(准入),且在当前参数下存在可实现的资源分配使其收束可达(可达性)。前两门给出资格域 E(t)(已具竞争资格者),三门合取给出可显域 W(t),即观界——在当前结构与参数下原则上可被点亮者;两者之差 M(t) = E ∖ W 为界缘——已具资格而不可达显现的滞留带。

三道门给出 W ⊆ E ⊆ Ξ(P);在界外存在条件 H\_excl(池内存在不能通过候选化或限域之门的结构)下,E 与 W 均为池内结构全集的真子集——有限资源与有限分辨本身不足以推出此条件,因可显性是逐一可达,不要求同时;非空性分区成立(恰一区内 W 非空;显现空缺区内 W 为空,观界结构以 E 与 M 的形式存续)。资格域、可显域与界缘共同诱导池内结构的四带划分——界外、界缘(具资格而不可达)、界内未显(可显而此刻未显)、显现(被维持占据)——且显现只能沿候选化、收束的链条到达,不可跳层。界缘与界内未显的区分本身可检验:参数不变下,界缘内容无论曝露多久均不可显,界内未显内容延长曝露或减轻竞争即可显。注意界缘的准确含义:其内容可被系统处理、可受竞争机制作用、可进入预显动力并产生偏置,但在当前参数下不可达占据——是”具资格而不可达”,不是”已上场而必败”。

W 的界形由四类项决定:结构项(感受野配置与熟径分布)、容量项(Φ\_cap)、退散项(η)、取向项(R 经 P 的偏置)。由此得到变界动力:容量下降使观界不扩张(在定理三(i)的比较条件下;在 H\_ord 与熟—阈值桥接 H\_fam 下,并在弱次序上偏向更熟的内容:负荷下的隧道效应);收束可达条件被渐进压低时,观界可能先缩后空(条件解释,待检验:须完整路径的退散单调性;麻醉的渐进版;显现空缺之判据见观者数理式定理七、定理十一——空缺判据非 r ≤ η,而是不存在任何可实现的候选—整合—维持路径;r ≤ η 在单候选、无交叠、常系数线性模型中只排除自阈下的新完成,不单独判定空缺);工具与训练扩界而不增观者;取向偏置实时重塑界形而不取消边界。

本篇的可检验推论包括:偏侧忽视为半侧界缘化的判据性病例(池界完好、识界完好、资格域保留而半侧可达性归零),忽视内容应保留预显层效应,且线索与动机干预应可暂时复显;盲视为界缘的慢性病例(资格保留、收束通路受损);双任务负荷下(在 H\_ord 与 H\_fam 下)边缘内容的丢失应呈弱次序:更熟的内容不早于较浅的内容丢失(严格的不均匀性另需条件)。

本篇的核心结论是:观者解决”现在是哪一个在”,观界解决”什么能够被点亮”,界缘划出”具资格而不可达显现”;此边界之为真界依 H\_excl;有限容量限制同一时刻可共同承载的结构族,能否共同承载全部 Ξ(P),须结合联合分配约束与总资源需求判定,不能仅由容量有限推出其不可能。

引言

一个事实长期被两种方式错误地解释。

事实是:并非一切皆可显现。站在同一处,有人看见的东西另一人看不见;同一刺激,此刻入眼,彼刻视而不见;有些内容无论如何努力都进不了某个观者的现实。

第一种错误解释把它归于感受器:看不见,是因为射程不够、分辨不够。但非注意盲否定了它——刺激在射程之内、强度充分,仍可不显;工具的存在也否定了它——望远镜没有改变眼睛,却改变了可显域。

第二种错误解释把它等同于注意:可显域就是注意的光圈。但注意只是变界诸项之一——无主动注意时观界仍有其默认形;且观界含界内未显的层次,而注意的光圈不含。

本篇给出第三种解释:可显与不可显的划分是结构边界,由候选化、限域与收束可达性三道门共同压出。内篇第十六已经给出这一边界的哲学陈述——不是所有输入都进入现实,观界决定什么能够被点亮;场篇第二十给出了其沉积场动力条件(该引称之实际承载,待场篇第二十升级时回核,见待形式化 (f);本篇不以此引称补足自身证明)。本篇给出它的最小范式:它在何条件下存在,由什么决定,如何变形,缺了什么必然失败。

论证流

我们采用不断追问的方式,一步一步来,因此会形成论证流,需要大家从上往下看。

一、边界的存在不是偶然

先问最浅的一层:并非一切皆可显——这是经验偶然,还是结构必然?

设其反面成立:池内一切结构皆可显现。有限容量限制同一时刻可共同承载的结构族;能否共同承载全部 Ξ(P),须结合联合分配约束与总资源需求判定,不能仅由容量有限推出其不可能。何况可显性是逐一可达,不要求同时:设池内只有两个可分辨结构,均可候选化、均通过准入,有限资源每次足以支持其中任意一个,则二者分别可达,一切皆可显,而无须无限容量。

物化一般式的第一前提是有限资源,场篇给出有限分辨(Res)与有限容积(φ\_f),观者数理式给出有限调谐容量(Φ\_cap)。这些前提限制同一时刻可共同承载的结构族,是否排除全部同时显现依联合分配约束与总资源需求而定;有限分辨也只在所申报的 Ξ(P) 含低于分辨阈的结构差异时,才排除其候选化。

因此,单凭有限资源与有限分辨,推不出必有结构位于可显域之外。本篇把界外之存在申报为条件 H\_excl:所申报的池内结构集 Ξ(P) 中,存在不能通过候选化或限域之门的结构。H\_excl 是否由有限资源与有限分辨必然给出,须结合 Ξ(P) 的范围及候选化机制另证(待形式化 (d))。

由此,边界之为真界在 H\_excl 下成立;本篇所论是它的构成、形状与动力,H\_excl 本身列为待证。

二、边界划在什么上

边界以池为前提。由观者个体化数理式第六节,池由 Sep 判据(Sep 对 Coact + Infilt + Reentry)划定其候选轨与稳定轨,给出一个观者的个体化范围;该协议现为框架级,标定未闭(观者判定式 H5 半闭);本篇的全部讨论在单一池内进行。池界与观界不同层:池界划定观者之间,观界划定一个观者之内的可显与不可显。

记池内结构集为 Ξ(P)。观界是 Ξ(P) 上的划分。

三、三道门

一个结构要显现,须依次满足三个独立条件。三者均可从观者式的既有结构读出,但在观者式中它们是占据生成的环节,在本篇中它们被重述为边界条件。

定义一:候选化之门  
结构 x 在时刻 t 可被候选展开 C 展开为候选,记 Cand(x, t) = 1。不可被展开者——展开能力不覆盖、转译通道不存在——无论物理上多么临近,均不可能进入竞争。

定义二:限域之门  
候选 x 通过候选限域 B 进入有限竞争集合,记 Adm(x, t) = 1。限域的功能是防止候选无界并流(观者数理式统一容量式);其反面是:被限域排除者不入竞争。

定义三:收束可达之门  
在时刻 t 的参数(r、η、χ、Ovl、Φ\_cap)与可实现分配集 𝒳(t) 之下,存在可实现的分配 x⃗ ∈ 𝒳(t) 及一条完整的候选—整合—维持路径,使 x 于有限时间内达到(或已处于)占据水平(z = 1)并被维持(维持依观者数理式完成保持条件,定义四十七),记 Reach(x, t) = 1。  
两点必须明确。其一,Reach 是反事实的可达性判断,不要求 x 实际显现——“未曾显现”不蕴含”不可显”,否则观界将循环地等于显现史。其二,“可达”指于有限时间内达到并可维持,不指渐近趋向。平衡值判据另列为平衡容许条件 Eq(定义三′);Eq 不自动等同实际收束、整合与维持路径存在。某一分配下趋而不达者,仅当不存在其他合法完整可达路径时,才据此判入界缘;某一分配下渐近不达,不足以否定其他分配下的可达性。

定义三′:平衡容许条件  
Eq(x, t) = 1 ⟺ ∃ x⃗ ∈ 𝒳(t),使该分配下 z\_x 的平衡值 z\*\_x = r·x\_x/d\_x ≥ 1,其中 d\_x = η + χ·Σ Ovl(x, ·)·ẑ(对手项取该分配下的有效压制),r \> 0,d\_x \> 0。在常系数线性模型 ż\_x = r·x\_x − d\_x·z\_x 中,自 z₀ \< 1 于有限时间首次到达 1,当且仅当 r·x\_x \> d\_x;等号时 z 只渐近趋近 1 而不达(例:单候选、无压制,r = η = 1,分配份额为 1,z₀ = 0,则 z(t) = 1 − e^{−t},平衡值为 1 而任意有限时刻均未达 1)。故在该模型内 Reach ⇒ Eq,反之不成立:Eq 不含严格不等,也不含整合与维持职责。

定义四:可实现分配集  
𝒳(t) 为系统在时刻 t 实际能够实现的资源分配方案集,由取向来源 R、取向生成与入域 P、驱动 D 与调谐机构的具体能力共同决定。

精确性说明:此处的模态量词必须绑定于 𝒳(t),不可取全体数学上可能的分配——否则 Reach 将系统性偏大,观界沦为空泛。绑定之后,Reach 依赖于 R、P、D 的实际实现,这不是缺陷,而正是命题本身:观界是结构边界,同一物理基底上,取向与调谐机构不同,观界即不同。

定义五:资格域、观界与界缘  
资格域:E(t) = { x ∈ Ξ(P) : Cand(x, t) = 1 ∧ Adm(x, t) = 1 }——已具竞争资格者(注意:具资格不等于已在竞争;入域参赛与否由分配动力决定)。  
观界(可显域):W(t) = E(t) ∩ { x : Reach(x, t) = 1 }——在当前结构与参数下原则上可被点亮者。内篇第十六”观界决定什么能够被点亮”对应此集。  
界缘:M(t) = E(t) ∖ W(t)——已具竞争资格、但在当前参数与可实现分配下不存在完整可达路径者。界缘以 E ∖ W 判定:其内容可能停留于阈下(含平衡值 z\* \< 1 者,及 z\* = 1 之渐近情形),也可能标量进度已完成而整合或维持职责不满足;z 达到 1 本身不足以判定 Occ。界缘内容可受竞争机制作用、可获得资源、可形成部分进度、可产生功能效应,但无论曝露多久均不可显(参数不变下)。

三道门对 W 是合取关系:缺任一道,x ∉ W(t);缺第三道而前两道在,x ∈ M(t)。

四、存在性与非平凡性

定理一(观界存在定理)  
在池已成立、物化前提与收束动力同时成立的条件下:  
(i)真子集性(条件):三道门给出 W(t) ⊆ E(t) ⊆ Ξ(P);在 H\_excl 下,E(t) ⊊ Ξ(P),从而 W(t) ⊊ Ξ(P);  
(ii)非空性(分区):恰一区内 W(t) ≠ ∅;显现空缺区内 W(t) = ∅,而观界结构以 E(t) 与 M(t) 的形式存续。

证明:  
真子集性。W ⊆ E ⊆ Ξ(P) 由定义五直接给出。三道门未必各自都是真子集——某一时刻 Adm 可能不排除任何已候选化结构;Reach 是逐一可达(存在某个分配即可,不要求同时),不被容量有限性自动限制。故有限资源不单独推出界外结构:两个可分辨结构皆可候选化、皆可准入、有限资源每次足以支持其一,即有 E = W = Ξ(P)。有限分辨也不保证 Ξ(P) 必含低于分辨能力的元素,这取决于 Ξ(P) 如何申报。在 H\_excl 下,存在 x ∈ Ξ(P) 使 Cand(x, t) = 0 或 Adm(x, t) = 0,故 x ∉ E(t),E(t) ⊊ Ξ(P),合取更有 W(t) ⊊ Ξ(P)。H\_excl 是否由有限资源与有限分辨必然给出,须结合 Ξ(P) 的范围及候选化机制另证(待形式化 (d))。证毕。  
说明:v1.1 以三点论证真子集性无条件成立——有限分辨(场篇第十二:Res 有限)使低于可分阈的结构差异不可候选化;取向机构不能指向它不能表征的目标;三道门同时全开须无限容量。前两点给出 H\_excl 的可期理由而非证明:前者只在 Ξ(P) 含低于分辨阈之结构差异时成立,后者只限 𝒳(t) 而不排除逐一可达;第三点亦不成立为证明:对有限的 Ξ(P),全部结构的联合资源需求可以仍是有限量,能否同时全显须结合联合分配约束与总资源需求判定。  
非空性。恰一区指已存在被维持占据的时段;池级当前单值原则(构成性承诺)只给至多一,不提供存在性,“恰一”为该原则下之工作域记法,非已证定理。占据者必已通过三道门,且已处于占据水平并被维持(定义三),故 c\*ₜ ∈ W(t),W(t) ≠ ∅。在显现空缺区(一般判据:不存在任何可实现的候选—整合—维持路径;r ≤ η 在单候选、无交叠、常系数线性模型中只排除自阈下的新完成,不单独判定空缺,见定理三(ii)),Reach 全域为 0——依定义三,Reach(x, t) = 1 须由一条完整的可实现候选—整合—维持路径见证,与空缺判据不相容——故 W(t) = ∅,可显域整体消失;但资格域 E(t) 可存续,候选、部分进度态以及标量进度已完成而整合或维持职责不满足者,滞留于界缘 M(t)。显现中断时系统并非空无内容,而是全部内容退入界缘。该极限情形由变界定理(定理三)统一处理,见第七节。证毕。

五、四带划分与不可跳层

定义六:四带  
资格域、可显域与界缘在池内结构集上诱导四带划分:  
界外:x ∉ E(t)。在当前结构与参数不变的条件下不可成为竞争者;若刺激或干预改变了候选化通道、限域配置或收束参数,则属于变界——边界被改写后 x 可入域,而非界外内容以原界形直接显现(与定理二的后承一致:界外结构对显现的影响只能经由改变界形,不能以内容身份越界)。  
界缘:x ∈ M(t),以 E ∖ W 判定,不以 z 判定。可受竞争机制作用、可获部分进度、可产生功能效应,其标量进度或停留于阈下,或已完成而整合或维持职责不满足,但在当前参数与可实现分配下不存在完整可达路径;延长曝露与加强刺激均不改变其不可显(改变的只能是边界本身)。  
界内未显:x ∈ W(t) ∖ Cur(t)。它包括阈下推进态——候选(z = 0 起点)与预显态(0 \< z \< 1,结构实在、功能有效、未达候选完成,故不入显现层;候选完成之定义见观者数理式定义四十五)——也可包括尚未取得实际占据资格、但存在后续完整可达路径的完成候选;不能仅以 z \< 1 定义。与界缘之别:界内未显者在竞争减轻或曝露延长时可显。  
显现层:x 被维持为占据(Occ = 1);在占据与当前事实之桥接(观者一般式 H3、观者实现式 H4、观者构造式 H10)闭合前,此读回为工作约定。该层每池至多一元——此非定理,而是池级当前单值原则:一项公开承担、允许经验击穿的构成性承诺(观者组式 v1.0 总图第三节;观者个体化一般式明文不证一池一我)。本篇凡用此至多一者,皆在该承诺成立的模型内。  
界缘与界内未显的预显态在功能效应上同型(均可启动、偏置、沉积),其区分判据是可显性而非功能性——这一区分本身可由曝露操作检验。

定理二(不可跳层定理)  
显现只能沿”入资格域(若发生变界)→ 候选 → 预显 → 占据”的链条到达,且预显须在可显域内方可续进至占据;不存在不经候选化与收束的显现,也不存在自界缘直达占据的路径(界缘者须先经变界迁入 W)。

证明:占据的定义是被维持的完成态(z = 1 且持续;候选完成见观者数理式定义四十五);z 是收束进度,收束的对象按定义是候选(观者数理式定义六、九)。故占据者必曾为候选、必经收束推进。不经候选化的”直接显现”在定义层即不成立;不经收束推进的”瞬时显现”被占据的持续性定义排除。证毕。

此定理的直接后承:界外结构对显现的影响只能是间接的——通过改变场参数、改变界形,而不能以内容身份出现在显现中。

六、界形的决定项

W(t) 不是固定集合。其形状由四类项决定:

结构项:感受野配置决定候选化之门的默认覆盖;熟径分布(场篇第十一 v1.2:熟是对深者的称谓,更熟依沉积度 δ̄ 比较)是界形的慢变历史条件。它是否使平衡分配阈值降低,本篇不从场篇第十一推出——该篇未立续行代价下降之条件(式篇第十 v2.2 待形式化 (a) 同此)——故以桥接假设 H\_fam 申报(附 1 第二节)。结构项给出观界的慢变默认形。

容量项:Φ\_cap 决定可同时维持的竞争规模与可实现分配集的丰度。若容量降低时 𝒳(t) 按包含关系缩小,则在其余条件固定下 Reach 通过集不扩张。

退散项:η 影响收束可达的底线。在单候选、无交叠、常系数线性模型中,自阈下的新完成须 r·u \> η(u 为分配份额,0 ≤ u ≤ 1),故 r \> η 是该模型内新完成的必要条件;已有完成态的维持另论(见定理三(ii));一般情形依完整路径判定。η 升时 Reach 是否收缩,依完整路径的退散单调性(未证,见定理三(ii)之条件解释)。

取向项:R 经 P 入域的偏置实时改写分配,从而实时重塑 Reach 的局部形状;经 L 的聚焦改写 Adm 的局部通过性。取向项给出观界的快变形。

七、变界动力

定理三(变界定理)  
(i)容量单调性:固定候选化、准入及其他动力条件;若容量降低(或被占用)时可实现分配集 𝒳(t) 按包含关系缩小,则 Reach 通过集不扩张,从而 W 不扩张。若资格域也变化,则另需 E\_低容量 ⊆ E\_高容量;单凭容量数值下降,不能排除准入重排后出现新成员。排序:在共同资格域、固定比较条件及 H\_ord 下,平衡分配阈值较低者不会比较高者更早失去可达资格;H\_fam 将此弱次序承接到熟的比较(较浅者不晚于更熟者失去可达资格),允许并列。严格先后另需严格的阈值差,且容量上限实际穿越两者之间的区间(附 1 第二节)。  
(ii)退散临界性(限定模型):在单候选、无交叠、常系数线性模型中,固定分配份额 0 ≤ u ≤ 1、η \> 0,并从 z₀ \< 1 出发,若 r ≤ η,则不能在有限时间首次达到 1。此结论只排除该模型内从阈下的新完成,不自动排除已有完成态的维持(例:r = η = 1、u = 1、无压制,若 z₀ = 1,则 ż = 1 − z,z(t) ≡ 1),也不单独推出一般 W 或 Cur 为空。一般空缺仍依完整候选—整合—维持路径不存在判定(观者数理式定理七、十一)。  
条件解释(待检验预测):若退散沿完整路径单调削弱可达性,则 η 相对 r 渐升时,内容自 W 向 M 迁移,可显域变薄、界缘增厚;显现中断之前,应先观察到可显域的收缩与界缘功能效应的相对存续(麻醉渐深时,外显报告先于内隐启动消失)。标量方程尚未证明完整路径的退散单调性,也不保证严格逐步收缩。  
(iii)取向重塑性:取向偏置可局部扩张或压缩 W(扩张受 𝒳(t) 与容量项约束);在改写后的配置上 H\_excl 仍成立时,不能取消 W 的真子集性。

证明要点:(i)Reach 要求 ∃ x⃗ ∈ 𝒳(t),𝒳(t) 按包含缩小则其通过集不扩张;E 固定或按包含缩小,故 W 不扩张;排序由 H\_ord 下 Reach ⟺ c \< a(Φ\_cap),a 随容量单调不减;熟的次序另由 H\_fam 承接(弱次序),不由场篇第十一推出;(ii)该模型中 ż = r·u − η·z,自 z₀ \< 1 于有限时间首次到达 1 须 r·u \> η(定义三′),与 r ≤ η、u ≤ 1 矛盾;z₀ = 1 且 r·u = η 时 z ≡ 1,故不排除维持;(iii)取向项改写分配与 Adm 的局部通过性;在改写后的配置上 H\_excl 仍成立时,由定理一得 W ⊊ Ξ(P)。证毕。

变界的两个扩张通道:  
工具扩界:工具把原本不可候选化的结构转译为可候选化的结构(望远镜、显微镜、仪表),扩张 Cand 的通过集。注意工具扩界不改池界、不增观者数——它移动的是 W,不是 N\_obs。  
训练扩界:训练加深相关路径时,在 H\_fam 下,平衡分配阈值不增;只有阈值实际下降并跨过当前分配上限,且实际可达与维持条件同时成立,才能据此推出新增入界。

八、推论

推论一(观界独损判据,可检验)  
三个边界可独立受损:池界损伤改变个体化单位候选数(观者个体化数理式:池数、轨数皆非观者计数器,故此处只记单位候选数之变);识界损伤改变分辨结构;观界损伤改变可显域而不动前两者。偏侧忽视为半侧界缘化的判据性病例:患者为单一观者(池界完好),对进入显现的内容分辨正常(识界完好),一侧空间的内容系统性不入显现——其结构定位不是候选化或限域的缺损,而是取向项对该侧的分配结构性归零,使该侧内容的 Reach 趋于 0:资格保留,可达性废止,内容滞留界缘。本式由此给出两个强预测:其一,忽视内容应保留界缘的功能效应——可测的启动、偏好与回避偏置——尽管无显现;其二,凡能暂时重建该侧分配的干预(外源线索、动机操控、对侧适应),应可暂时复显该侧内容。两个预测共同把忽视症从待解释现象转为四带结构的判据性证据。

推论二(工具与观者数解耦,可检验)  
任何工具扩界都不改变观者计数:扩界作用于 Cand,池界判据(Sep 对 Coact + Infilt + Reentry)不涉及候选化通道。其外推接外篇·入世:在彼世构建代身,在结构上即为在异质基底上重立候选化通道与收束机构——重立观界,而非迁移池。

推论三(负荷隧道,可检验)  
认知负荷占用容量项时,在定理三(i)的比较条件下 W 不扩张;在 H\_ord 与 H\_fam 下,并在弱次序上偏向更熟的内容(定理三(i))。可测形态:双任务下,更熟的刺激不早于较浅的刺激丢失检出;严格的检出率差异另需严格的阈值差、容量上限实际穿越其间,以及检出读数与实际显现之间的桥接;该次序应随负荷量梯度变化。此预测检验 H\_ord、H\_fam、比较条件及检出读数与实际显现之间的桥接。仅在其余条件已独立确认时,逆序结果才可用于反驳 H\_fam;未出现严格不均匀性,不足以反驳允许成本相等的弱 H\_fam。

推论四(供给源切换)  
资格域与可显域的定义均不含”输入须来自感受器”。由物化一般式,候选的来源有三:输入压缩、历史回灌、内部展开。睡梦中感受器门控关闭,候选化的供给源切换为内部展开与历史回灌,E 与 W 仍然成立——梦境有其观界与界缘(梦中同样并非一切皆可显)。此推论同时说明:观界不等于感受器射程,二者在梦境中完全解耦。

九、击穿论证

下面检验几个最可能的反例与混同。

反例一:观界即感受器物理极限。  
不成立,三个独立的反证:非注意盲——刺激在射程内、强度充分,因取向项与限域不入显现;工具扩界——感受器未变而 W 变;梦境——感受器门控关闭而 W 仍在(推论四)。射程是候选化之门的物理条件之一,不是观界本身。

反例二:观界即识界。  
不成立。可分而不可入:忽视患者对被转入好侧的同一内容分辨正常,说明分辨结构完好而该侧可达性废止(半侧界缘化,推论一)——内容在原侧不可显,移入好侧即可显且分辨如常。可入而难分:低分辨条件下的内容可显现而难辨细节(模糊知觉;观者组式反例族之低分辨情形)。两个边界正交,损伤可分离。

反例三:观界即注意。  
不成立。注意对应取向项,是变界四项之一:无主动注意时 W 仍有由结构项给出的默认形;W 含界内未显层、E 更含界缘,而注意光圈两者皆不含;注意重塑 W 与 M 的分界(经分配改写 Reach 的局部)而不创造边界——边界之为真界依 H\_excl(定理一),与注意之有无无关。观界范畴严格大于注意焦点。

反例四:全显系统。  
设某系统 W = Ξ(P)。这不与有限资源直接矛盾——可显性是逐一可达,不要求同时显现;能否同时全显,须结合联合分配约束与总资源需求判定,不能仅由容量有限推出其不可能。本篇以 H\_excl 排除全显:在 H\_excl 下 E ⊊ Ξ(P),故 W = Ξ(P) 不成立。任何声称的全显系统,须检查其 Ξ(P) 是否被偷换为已在界内的结构集。

反例五:阈下知觉与盲视。  
这两类现象常被用来质疑”显现有明确边界”。在四带结构下它们不是反例,而是两条不同带的直接实例,且二者的实验区别恰好对应带的区别。阈下启动:内容在可显域之内、形成预显态、产生功能效应而未达占据——界内未显;故延长曝露或减轻竞争即可显,这正是阈下范式的标准操作。盲视:资格保留(候选化与限域通道部分完好)而收束通路受损,Reach 长期为 0——界缘的慢性病例;故无论曝露多久均不可显,而强迫选择优势存续。同为”有效应而无显现”,一个可经曝露转显、一个不可——四带结构不仅安放了两类现象,还预言了它们的分离判据。

十、三界定位

至此可以把三个边界并列陈述,以固定各自的层位:

池界(观者个体化数理式第六节):个体化边界。回答”谁在看”。判据:Sep 对 Coact + Infilt + Reentry。输出:个体化单位候选数 N\_cand;观者数 N\_obs 为 NoShare 与最终性两条款下之条件量。  
观界(本篇):显现边界。回答”能看见什么”。判据:三道门的合取(前两门给出资格域 E,第三门给出可显域 W,差集为界缘 M)。输出:四带划分(界外、界缘、界内未显、显现)。  
识界(式篇第十三至十七):分辨边界。回答”能分辨成什么样”。判据:不可区分关系的闭包。输出:结构极限划分。

三者互为前提而不可互换:池界在先,观界居中,识界作用于已显者之上。三者可独立受损、独立变动、独立测量。

十一、下游衔接

误外化接口:误外化的对象是收束完成的意象(观者组式下游衔接:观者数理式与观者实现式之接口节),即本篇显现层的元素。显现层之外——界内未显与界缘——均不被归属来源:预显态无”内外”标签。这给误外化诸式补上一个边界条件:来源归属仅在显现层上定义。

识界接口:识界的不可区分关系作用于已显内容之上;观界变动(扩界、缩界)改变识界的作用域而不直接改变其闭包结构——这解释了为何单纯获得新输入通道(扩界)不自动带来认知跃迁(识界跃迁式,式篇第十六):入界不等于可分。

入世接口:见推论二。

非社接口:能力的持续提升在本篇的形式下即 Cand 与 Reach 通过集的持续扩张;观界扩张降低对群体补足的依赖,接式篇第二十一。

十二、实现对应(微核论)

候选化之门:感受野与信号流展开;限域之门:界门;取向项:意向域经欲门;收束可达:调谐场在容量内的可达性。界门是资格域的机构落点;可显域在此之上还需调谐可达,其机构落点为调谐场。与观者构造式实现读回一节的分层说明一致:界门所司为观者之内的资格准入(本篇资格域),池界另由串扰连通性给出(观者个体化数理式第六节)。

十三、结语

本篇结论压成两句话:

观者解决”现在是哪一个在”,  
观界解决”什么能够被点亮”,  
界缘划出”具资格而不可达显现”。

再压成最简一句:

没有收束,就没有东西在此显现;  
没有观界,显现便无从划定其可达者——而界之为真界,依界外存在条件 H\_excl。

附 1:观界一般式之符号化表达

一、基本域与记号

设池 P 已由观者个体化数理式第六节之池轨判据成立,池内结构集为 Ξ(P)。沿用观者组式的全部记号:z(收束进度)、r(推进率)、η(退散率)、χ(串扰系数)、Ovl(交叠度)、Φ\_cap(容量)、Occ(占据,含持续性)。

二、三道门

Cand(x, t) ∈ {0,1}:x 可被候选展开 C 展开。  
Adm(x, t) ∈ {0,1}:x 通过候选限域 B。  
𝒳(t):可实现分配集,由 R、P、D 与调谐机构的实际能力决定。  
Reach(x, t) = 1 ⟺ ∃ x⃗ ∈ 𝒳(t) 及一条完整的可实现候选—整合—维持路径,使 x 于有限时间内达到(或已处于)占据水平(z = 1)并被维持(反事实判断,不要求实际显现;维持依观者数理式定义四十七)。  
Eq(x, t) = 1 ⟺ ∃ x⃗ ∈ 𝒳(t),使 z\*\_x = r·x\_x/d\_x ≥ 1,d\_x = η + χ·Σ Ovl(x, ·)·ẑ(对手项取该分配下的有效压制),r \> 0,d\_x \> 0。常系数线性模型 ż\_x = r·x\_x − d\_x·z\_x 中,自 z₀ \< 1 有限时间首次到达 1 ⟺ r·x\_x \> d\_x;等号时只渐近趋近。故该模型内 Reach ⇒ Eq,反之不成立。  
平衡分配阈值:c(x, t) ≔ d\_x/r,在对手压制项固定的比较条件下;Eq(x, t) = 1 ⟺ 存在可实现分配使 x\_x ≥ c(x, t)。c 不是一般的实际可达成本。  
H\_ord(容量—可达排序桥接,另加):在共同资格域与固定比较条件下,存在对 Φ\_cap 单调不减的单目标可分配上限 a(Φ\_cap),使 Reach(x, t) = 1 ⟺ c(x, t) \< a(Φ\_cap(t))。此为另加的实际可达桥接条件(含整合与维持职责之满足),不由平衡公式或定义四推出。  
H\_fam(熟—阈值桥接,待立):其他条件相同时,承载路径更熟者(δ̄ 更深,依场篇第十一 v1.2 之固定共同聚合协议)c 不更高;允许相等。熟的比较依 δ̄;H\_fam 不由场篇第十一推出(该篇未立续行代价 𝒵 下降之条件),也不是熟的定义。  
H\_excl(界外存在条件):所申报的池内结构集 Ξ(P) 中,存在 x 使 Cand(x, t) = 0 或 Adm(x, t) = 0。

三、资格域、观界、界缘与四带

E(t) = { x ∈ Ξ(P) : Cand ∧ Adm }  
W(t) = E(t) ∩ { x : Reach(x, t) = 1 }  
M(t) = E(t) ∖ W(t)  
Out(t) = Ξ(P) ∖ E(t)  
Pre(t) = { x ∈ E(t) : 0 ≤ z\_x(t) \< 1 }(阈下推进态之集,按 x ∈ W 或 x ∈ M 分属界内未显或界缘;Pre 不是带的定义——四带依集合资格划分,界内未显为 W ∖ Cur,界缘为 M,二者均可含 z = 1 而无实际占据者)  
Cur(t) = { x : Occₜ(x) = 1 },\|Cur(t)\| ≤ 1(依池级当前单值原则,构成性承诺;观者组式 v1.0)  
四带:Out ∪ M ∪ (W ∖ Cur) ∪ Cur,两两不交,并为 Ξ(P)。

四、定理(统一表达)

定理一(恰一区之”恰一”依池级当前单值原则,见第四节显现层条款之申明):池成立 ∧ 有限资源 ∧ 收束动力 ⇒ W(t) ⊆ E(t) ⊆ Ξ(P);H\_excl ⇒ E(t) ⊊ Ξ(P) 且 W(t) ⊊ Ξ(P);恰一区内 W(t) ≠ ∅;显现空缺区内 W(t) = ∅ ∧ E(t) 存续。

定理二:Occₜ(x) = 1 ⇒ 存在 τ′ \< t 使 Cand(x, τ′) = Adm(x, τ′) = 1 且 z\_x 经连续推进达 1;显现不可跳层。

定理三:  
(i)E 固定(或 E\_低 ⊆ E\_高)且 𝒳(t) 随 Φ\_cap 按包含单调时,∂W/∂Φ\_cap ≥ 0;共同资格域、固定比较条件与 H\_ord 下,c 较低者不早于 c 较高者失去可达资格;H\_ord ∧ H\_fam 下,较浅者不晚于更熟者失去可达资格(弱次序,允许并列);严格先后另需严格阈值差与容量上限穿越其间。记号说明:本附录中集合对参数的 ∂ 记号(如 ∂W/∂·、∂Cand/∂·)一律指包含关系意义下的单调性(参数增则集合不缩、参数减则集合不增),非集合对标量的数值微分;数值量(如 N\_obs)的 ∂ 取通常含义;涉及集合规模比较时以待形式化事项(a)的测度为准;  
(ii)单候选、无交叠、常系数线性模型,0 ≤ u ≤ 1,η \> 0,z₀ \< 1:r ≤ η ⇒ 不能于有限时间首次达到 1;不排除已有完成态之维持(r·u = η、z₀ = 1 时 z ≡ 1),不单独推出 W = ∅ 或 Cur = ∅。一般空缺(完整候选—整合—维持路径不存在;观者数理式定理七、十一)⇒ W = ∅ ∧ Cur = ∅,E 存续、内容退入 M;  
(iii)取向项重塑 W 的局部形状;在改写后的配置上 H\_excl 仍成立时,W ⊊ Ξ(P) 不变。

五、推论的形式位置

推论一:∃ 损伤配置使 N\_obs 不变 ∧ 识界闭包不变 ∧ 半侧 Reach → 0(取向项分配归零,Cand、Adm 保留);该侧 x ∈ M,其功能效应可测,且重建分配的干预可使其暂时迁回 W。  
推论二:∂Cand/∂工具 \> 0 ∧ ∂N\_obs/∂工具 = 0。  
推论三:负荷 L↑ 且定理三(i)之比较条件成立 ⇒ W 不扩张(包含意义);H\_ord ∧ H\_fam 下,较浅者不晚于更熟者出界(弱次序,允许并列)。Familiarity 已于场篇第十一 v1.2 撤销为熟的定义,本式不用。  
推论四:候选供给源 ∈ {输入压缩, 历史回灌, 内部展开};感受器门控 → 0 不蕴含 W = ∅。

六、待形式化事项

(a)\|W\| 的度量:需在 Ξ(P) 上引入测度(可由场篇的 Res 与 Λ 导出),本篇定理只用包含关系与单调性,未依赖具体测度;  
(b)𝒳(t) 的显式刻画:可实现分配集目前由 R、P、D 的功能定义给出,其参数化表达(策略集的容量与拓扑)留待工篇的实现层处理;
