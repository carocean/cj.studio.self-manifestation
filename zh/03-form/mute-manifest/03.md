自显论·式篇第二十三·喑显组式第三 v1.3.1

# 喑显相变式

导言

本篇承《喑显一般式》与《喑显数理式》，只处理一个任务：

证明在强喑工作域内，同一 r-bound 生成谱系怎样由 B-invariant 稳定成迹组织，经沉积构形所控制的稳定组织景观重构，转入可维持的 B-conditioned 稳定成迹组织。

本篇所称“相变”，不是任一状态改变，不是 B 强度越过某一数值阈值，不是一次 M\_ε = 1，也不是外部把系统直接写入后相。

相变要求同时成立：

前相与后相具有不同的组织判据；  
控制基质经过相变相关临界；  
实际状态发生同一生成谱系内的组织归属改变；  
后相能够在声明扰动域中维持；  
这一相身份不是形成协议的偶然产物。

本篇不证明系统迟早必然转相，不追溯后相全部历史来源，不证明从任意初态都可达后相，也不处理 1→100 的显化分级。

二、相变工作上下文

为避免把正常边界输入、普通扰动制度、组织等价规则与形成协议的变化误算成“构形导致的相变”，本篇先固定相变工作上下文：

𝒞\_phase^r  
\=  
(U\_class^r,  
&nbsp;Δ\_ord^r,  
&nbsp;∼\_r^org,  
&nbsp;𝔓\_form^r)

其中：

U\_class^r：声明的正常边界输入类；

Δ\_ord^r：不改变当前有效 B 条件职责的普通扰动制度；

∼\_r^org：稳定组织等价关系；

𝔓\_form^r：同一物理形成问题下的合法协议族。

合法协议族只允许按不涉及待证 D/L 相身份的条件定义。

各 Prot ∈ 𝔓\_form^r 必须保持：

同一系统物理边界；

同一正常动力与 r-bound 同迹职责；

同一合法 B 条件域物理含义；

同一 ∼\_r^org；

同一 Δ\_ord^r；

同一形成任务。

协议之间只允许改变已经由数理层证明不改变上述对象的表示坐标、数值求解器、停止算法实现或其它非承重形式细节。

不得因为某协议导致 D/L 分类翻转，就事后把它踢出 𝔓\_form^r。

全文在固定 𝒞\_phase^r 后，简写：

四、D 稳定分支与 L 稳定分支族

本篇不再用一个统一 DBranch/LFamily 同时承载 D 与 L，因为 D 可以由单一 B-invariant 稳定分支表达，而 L 的非退化性本质上是多个 B-indexed 稳定组织之间的关系性质。

\[O\] ∈ 𝒪\_r^stable / ∼\_r^org

Resp\_r(\[O\], 𝔥ᵣ, Prot)  
\=  
{b ∈ 𝓑\_stab^r :  
𝒦\_{r,Prot}^form(b; 𝔥ᵣ) = \[O\]}

B\_D(\[O\], 𝔥ᵣ, Prot)  
⊆

DBranch\_r(\[O\], 𝔥ᵣ) ∈ {1,0,⊥}

LFamily\_r(𝔉\_L,𝔥ᵣ) = 1

\=  
{(b,\[O\_b\]) :

𝒦\_{r,Prot}^form(b;𝔥ᵣ) = \[O\_b\]

LFamily\_r(𝔉\_L, 𝔥ᵣ) ∈ {1,0,⊥}

若：

第一，B\_L 至少包含两个可比较合法 B 条件；

LFamily\_r(𝔉\_L, 𝔥ᵣ) = 0

LFamily\_r(𝔉\_L, 𝔥ᵣ) = ⊥

八、景观临界

本篇不再用“相已经变了”直接定义临界。

景观临界必须由独立组织事实的不可约变化逼出。

定义景观结构读数：

J\_land^r(𝔥)  
\=  
(𝒜ᵣ,  
&nbsp;Stab,  
&nbsp;Basin,  
&nbsp;Reach,  
&nbsp;𝐊\_r^form)

定义相景观等价：

𝔏₁ ∼\_land^r 𝔏₂

当且仅当两景观在下列 D/L 承重结构上保持同一类型：

DBranch 的局部分支结构与 LFamily 的 B-conditioned 稳定分支族结构；

各分支的局部稳定身份；

Basin 的连接与 D/L 承载归属；

D/L Reach 可达结构；

𝐊\_r^form 的稳定形成退化/非退化身份。

普通连续数值漂移若不改变上述结构，不构成相景观不等价。

性质申明：∼\_land^r 是等价关系。自反、对称、传递三性均成立——该关系由五项承重结构「保持同一类型」给出，同类型关系自反、对称、传递。反对称性不成立，也不要求成立：不同的景观可以在这五项上同类型，这正是本关系要商掉的东西（普通数值漂移即属此类）。

与《喑显数理式》中 ∼\_ε、∼\_r^org 同例，三性在本篇是对实例化的要求而非本篇所证：五项承重结构的「同一类型」如何判定，由具体模型声明。具体模型给出判定规则时，须同时保证三性；不满足者不是本篇所称的相景观等价，Σ\_land^r 的定义随之不成立。

定义景观临界集合：

Σ\_land^r

为覆盖相关 D/L 景观等价类改变所必需的最小闭合临界集合：移除其中任何承重子集后，均不能完整分隔或覆盖相关的相景观等价类改变。

其成员所在任意允许邻域中，应能找到景观在 ∼\_land^r 下不等价的合法构形，且差异至少涉及下列一项：

D 稳定组织的局部稳定性发生临界改变；

L 稳定组织由不可承载转为可承载，或反之；

Basin 的 D/L 承载结构发生改变；

Reach 的 D/L 合法可达结构发生改变；

𝐊\_r^form 的稳定组织像结构发生退化/非退化改变。

因此：

𝔥 ∈ Σ\_land^r

不能仅由 PhaseSupp 标签变化宣告，而必须回读到 J\_land^r 的实际组织重构。

连续失稳型中，Σ\_land 可以对应：

{D} → {L}

的单一临界。

非连续成核型中，可以存在：

{D} → {D,L}

和：

{D,L} → {L}

两类不同景观边界。

九、实际转相与当前承载改变

实际转相不是景观支持改变本身，而是当前承载相改变。

确定性模型中，定义 D 与 L 的实际稳定承载域：

𝔅\_D^r  
\=  
{S ∈ 𝒮ᵣ : CurPhaseᵣ(S)=D}

𝔅\_L^r  
\=  
{S ∈ 𝒮ᵣ : CurPhaseᵣ(S)=L}

确定性实际转相边界：

Σ\_trans^{r,det}  
⊂  
∂𝔅\_D^r ∩ ∂𝔅\_L^r

或在离散/非拓扑模型中，为 D/L 实际承载改变的最小状态分界。

随机模型中，不把“概率等值面”直接叫实际转相边界。

可以定义模型级 L 命中函数：

q\_L(S)  
\=  
Pr\_S(τ\_L \< τ\_D^\*)

其中 τ\_L 为进入 L 稳定承载域的首次时刻，τ\_D^\* 为声明的竞争 D 承载/终止事件。

q\_L 只描述转相倾向。

随机模型中的实际相变，由真实样本轨迹第一次进入 L 稳定承载域并取得 CurPhase=L 判定来裁定。

但单一 realization 的跨盆只证明该次实际承载改变；随机动力本身是否发生景观相变，仍必须由 J\_land^r 随 𝔥ᵣ 的组织结构重构独立证明。固定双稳景观中的噪声换盆不自动构成景观相变。

因此：

PostCritical ≠ Transition

PhaseSupp = {D,L}

也不等于：

CurPhase = L

十、生成谱系连续性

定义统一生成谱系关系：

S\_a ⪯\_gen^r S\_b

当且仅当存在一条由当前合法：

Φᵣ

及其结构分解：

F、G、Ξ

与正常边界输入 Uᵣ

生成的有限或声明允许的连续/离散后继链，从 S\_a 到 S\_b，并满足：

不更换系统实例身份；

不更换当前 r-bound 生成身份；

不通过特权内部写入替换承重结构；

所有新结构均由前态合法生成。

“同载体谱系、同迹属谱系、同生成谱系”均作为：

⪯\_gen^r

的检查条件。

性质申明：⪯\_gen^r 是预序，不是偏序。

自反性成立：任一 S 到自身有零步后继链。

传递性成立：若从 S\_a 到 S\_b 有合法链、从 S\_b 到 S\_c 有合法链，则二链相接仍是从 S\_a 到 S\_c 的合法链，且四项检查条件逐段成立即整体成立。

反对称性不成立，也不要求成立：只要系统从 S\_a 演化到 S\_b 之后还能沿合法后继回到 S\_a，就同时有 S\_a ⪯\_gen^r S\_b 与 S\_b ⪯\_gen^r S\_a 而 S\_a ≠ S\_b。本篇的合法后继链不禁止回路——四项检查条件（不换系统实例身份、不换 r-bound 生成身份、不用特权写入、新结构由前态合法生成）皆不含单向性要求，故振荡、循环与可逆复调所生成的状态对，都落在这一情形里。故本关系不在状态空间上给出偏序，其记号 ⪯ 只表示生成可达方向，不表示状态之间有高下或先后的唯一排序。

由此二事须明：

其一，本篇不对 ⪯\_gen^r 取商。互相可达的状态在生成谱系上等价，但它们的 CurPhase 可以不同（一个在 D，一个在 L），取商会把相变本身抹掉。

其二，相变要求 S\_D ⪯\_gen^r S\_L，这是方向要求而非序数要求。它要求的是存在一条从 S\_D 到 S\_L 的合法生成链，不排除同时存在从 S\_L 回到 S\_D 的链——后者若存在，只说明该相变可逆，不说明它没有发生。

相变要求：

S\_D ⪯\_gen^r S\_L

而不是只要求前后结构相似。

十一、相变总命题

给定合法模型实例 𝔐ᵣ 与固定相变工作上下文 𝒞\_phase^r。

若存在合法实际轨迹：

γᵣ : t ↦ Sᵣ(t)

使某 t₀ 时：

CurPhaseᵣ(Sᵣ(t₀)) = D

并且在后续构形演化中：

𝔥ᵣ(t)

经过一个由独立组织结构读数 J\_land^r 证明成立的景观临界 Σ\_land^r，

同时存在 t₁ \> t₀，使：

CurPhaseᵣ(Sᵣ(t₁)) = L

且：

L ∈ PhaseSuppᵣ(𝔥ᵣ(t₁))

后相属于 StableOrg，

并且：

Sᵣ(t₀) ⪯\_gen^r Sᵣ(t₁)

则称同一 r-bound 生成谱系发生局部 D→L 承载转相。

若上述普遍条件成立，则该轨迹已经构成局部喑显相变：

𝔓\_D^r  
⟶  
𝔓\_L^r

若进一步满足连续失稳型条件，则归入连续失稳型；

若进一步满足非连续成核型条件，则归入非连续成核型。

这两个子型不是喑显相变机制的穷尽分类；其它合法机制只要满足本篇普遍相变条件，不因未归入这两个子型而被否定。

十二、B-side 形成责任强化判据

LFamily=1 已经证明稳定组织形成关系对合法 B 条件非退化。

本节进一步提供一个更强的、非普遍必要的形成责任诊断。

定义职责族删除：

Abl\_{B-family}^r

它只将当前 r-bound B-side 对成迹的整个合法因果职责族：

𝓘\_r^{B-family→trace}

置零，同时保留：

B 的状态空间；

合法 B 条件域；

自动前件；

Prot\_form；

正常边界输入；

其它非 B-side 承重结构。

比较：

𝐊\_{r,base}^form

与：

𝐊\_{r,Abl}^form

若基线存在 LFamily=1，而删除整个 B-side 成迹职责族后该 L family 退化为常映射、⊥\_form 或不再形成同一 B-conditioned 稳定组织关系，则：

Dep\_{B-family}^form = 1

此时可以进一步裁定：

B-side 职责族对该 L 相形成具有不可约形成责任。

若：

Dep\_{B-family}^form = 0

不得因此否定喑显相变；它只表示系统可能存在冗余或等效形成路径。

因此 Dep\_{B-family}^form 不进入普遍相变定义，也不作为条件相变定理的必要前件。

十三、连续失稳型

连续失稳型要求具体模型提供一个合法的组织连续结构。

可采用：

组织度量 d\_org；

连续序参量 ψ；

稳定谱；

Lyapunov 指标；

恢复率；

或其它已经证明能够回读 D/L 组织变化的连续结构。

若没有任何合法组织连续结构，则可以判 D→L 相变，但不得进一步宣称“连续失稳型”。

普遍连续失稳条件为：

存在连续构形路径 𝔥ᵣ(λ)

以及一个合法稳定性边界判据，使：

λ \< λ\_c 时，存在 DBranch=1 的稳定分支，且其局部稳定性为正；

当 λ → λ\_c^- 时，D 在至少一个 B-sensitive 有效方向上的局部稳定性逼近失稳边界；

λ \> λ\_c 的相邻域中，存在 LFamily=1 的稳定分支；

并且新相的组织非退化程度在临界处无有限跃差地从零出现。

若模型使用序参量 ψ\_L，则可写：

lim\_{λ→λ\_c^+} ψ\_L(λ) = 0

同时 λ \> λ\_c 时：

ψ\_L(λ) \> 0

若模型使用稳定裕度 κ\_D，则可写：

κ\_D(λ) \> 0，λ \< λ\_c

κ\_D(λ\_c) = 0

这些标量只是具体实例，不是普遍必要物理量。

连续失稳型不要求：

有限临界核；

构形瞬时跳变；

临界前已有 B-specific 熟路；

域满或边沁。

十四、非连续成核型

非连续成核型允许：

PhaseSuppᵣ(𝔥ᵣ) = {D,L}

而：

CurPhaseᵣ(Sᵣ) = D

长期成立。

若在同一共存景观中，D 与 L 均为局部稳定组织，实际状态位于 D 承载盆；只有当某个 B-conditioned 局部组织跨过 D/L 承载边界，实际轨迹才进入 L 承载域，则为非连续成核型。

具体模型可定义模型级核支持量 N 与临界值 N\_c：

N \< N\_c ⇒ 返回 D 承载域

N = N\_c ⇒ 位于承载临界

N \> N\_c ⇒ 进入 L 承载域

N、N\_c 不要求表示节点数、物理尺寸或统一强度。

非连续成核型允许实际转相时 D 仍局部稳定。

因此非连续成核型的核心不是“旧相必失稳”，而是：

共存；

有限承载边界；

成核或换盆；

L 后相可维持。

十五、r-bound 成核组织模板

对适用的成核模型，可以使用一个充分组织模板：

迹属闭合；

差异穿透；

稳定承接。

迹属闭合：

候选局部组织属于当前 r 的合法生成关系。

差异穿透：

至少一个合法 B-side 差异经过完整自动复调后，仍形成不同稳定组织商类。

稳定承接：

该 B-conditioned 局部组织能够进入 L 稳定承载，而不是一次瞬时 M\_ε = 1。

这一“自动—主动共调闭环”只作为适用模型中的充分成核模板，不是所有非连续相变的普遍最小微观拓扑。

本篇普遍要求只到：

B-conditioned 局部稳定组织跨越实际承载边界。

十六、模型级沉积实现

域满—边沁—新结构生成可以作为非连续成核型的一种沉积场实现：

旧 B-invariant 组织长期吸收新增差异  
→ 新增差异吸收余量下降  
→ 旧结构达到局部压缩/分辨限制  
→ 新增 r-bound B-side 差异不能继续内沉  
→ 边沁、分辨重组或新结构位生成  
→ B-conditioned 局部组织取得独立结构承接  
→ 超过维持条件后形成 L 核

这一链只属于模型级实现例。

本篇不把域满、边沁、预塑、新结构位、迟滞中的任何一项写成全部喑显相变的普遍必要条件。

这些机制的历史来源交《喑显源式》。

十七、预塑与首写边界

本篇只允许两类来源形态进入相变描述：

临界前已有承重预塑；

转相窗口内首次合法写入。

允许：

预塑—释出；

首写—连续生长；

首写—超临界成核。

但本篇不证明其来源史，也不证明哪一种普遍发生。

详细来源闭合交《喑显源式》。

十八、景观临界与实际转相时刻

区分：

t\_land：

𝔥ᵣ(t) 首次进入 Σ\_land^r 的时刻；

t\_trans：

实际轨迹第一次取得：

CurPhaseᵣ(Sᵣ(t)) = L

并进入 L 稳定承载的时刻。

连续失稳型可以有：

t\_land = t\_trans

非连续失稳型可以有：

t\_land \< t\_trans

因此景观已经允许 L，不等于实际已经进入 L。

本篇也不要求：

Δ𝔥ᵣ(t\_trans) ≠ 0

构形可以在临界前完成足以改变景观的积累，实际状态随后才跨盆。

十九、前后相维持规则改变

D 相的稳定组织事实是：

合法 B 条件变化仍不能形成不同稳定组织商类。

L 相的稳定组织事实是：

固定同一合法 B 条件 b 时，普通扰动只检验类内恢复；

改变合法 B 条件时，可以形成不同稳定组织商类。

因此喑显相变改变的不是“系统从稳定变得不稳定”。

它改变的是：

B-side 差异在稳定成迹组织生成中的身份。

前相：

B-side 差异不承担稳定组织分化。

后相：

至少一个合法 B-side 方向成为稳定组织生成条件。

二十、序参量与连续性回读

本篇不规定全模型统一标量序参量。

有限离散模型可以采用：

ψ\_card  
\=  
\|Im(𝒦\_{r,Prot}^form(·;𝔥ᵣ)\|\_{𝓑\_stab^r})\| - 1

ψ\_diam

diam(Im(𝒦\_{r,Prot}^form(·;𝔥ᵣ)))

若局部可微：

ψ\_rank

二十一、事件越界与相变分离

M\_ε = 1

只说明一次事件满足同迹后命判据。

即使：

P\_ε = 1 ∧ M\_ε = 1

已经齐备，也不推出：

L ∈ PhaseSuppᵣ(𝔥ᵣ)

更不推出：

CurPhaseᵣ(Sᵣ) = L

若 B-sensitive 事件不能形成可维持 B-conditioned 稳定组织，只能判为瞬时越界、失败成核或未闭合候选。

因此：

M\_ε = 1 ⇏ 𝔓\_L^r

二十二、迟滞、残留与不可逆

若具体模型的 D→L 与 L→D 转相边界不同，则可申报迟滞。

例如有效控制坐标存在：

η\_D→L ≠ η\_L→D

则上行与下行条件不同。

若 L 形成后继续改变 𝔥ᵣ，使回退条件进一步移动，可申报历史残留。

只有在声明工作域内证明不存在合法逆过程恢复 D，才可申报不可逆。

迟滞、残留与不可逆均不是普遍必要性质。

二十三、普通跃迁排除

若：

J\_land^r(𝔥ᵣ)

在相关过程中保持 D/L 承重结构不变，而只有状态：

S\_a → S\_b

发生变化，则最多证明普通状态跃迁。

若在固定景观中外力直接把状态从 D 承载盆推入 L 承载盆，而没有相变相关景观重构，则最多证明外制换盆。

喑显相变必须同时具有：

独立组织事实支持的景观临界；

D/L 相支持身份成立；

当前承载相实际改变；

同一生成谱系；

可维持 L 后相。

同相解释排除

上节所排除的是「景观未变而状态变了」。此外还须排除另一路：景观变了、状态也变了，而整个过程仍可在同一相之内连续完成。

设从 S\_D 到 S\_L 的过程中，CurPhaseᵣ 自始至终取同一值。此时无论 J\_land^r 如何变化、无论 B-side 差异多大，都不构成相变——它是同一相内部的演化，其程度变化归《喑显分级式》，其极限性质归极限式。

故本篇主张 D→L 相变时，须证：不存在一条保持 CurPhaseᵣ 取值不变的合法生成链，能够实现所主张的全部目标变化。

此证不可由「D 与 L 互斥」得出。第四节已明：DBranch 只检验该 D 分支自身的局部 B-invariant 身份，同一景观中完全允许 DBranch=1 与 LFamily=1 同时成立，二者的判据分别落在单个分支的性质与分支族的关系性质上，并不互斥。

可行的证法落在 CurPhaseᵣ 上，而不落在相支持上。CurPhaseᵣ 判的是当前承载组织属于哪一侧：属于某个 DBranch=1 的稳定 D 分支，则取 D；属于某个 LFamily=1 的 B-conditioned 稳定分支族，则取 L。故须证的是：不存在一条合法生成链，使当前承载组织自始至终留在同一侧，而所主张的目标变化仍然完成。

具体证法依目标变化的内容而定：

若所主张的目标变化，其内容就是「当前承载组织由 D 侧转到 L 侧」，则同相解释自动排除——保持 CurPhaseᵣ 不变即等于该变化未发生。此时本项无额外负担，只须申明。

若所主张的目标变化另有内容（如某读数由小变大、某结构由简变繁），则须逐项检查该内容能否在 CurPhaseᵣ 取值不变的前提下完成。凡能完成者，该项不属于本篇的相变主张，应从相变主张中剔出，交《喑显分级式》（可分级者）或极限式（问极限性质者）。

故本项的实际效果是划界：把「承载侧的改变」留给本篇，把「同侧内部的程度变化」交出去。若剔出之后所剩为空，则本篇的相变主张不成立。

此项与第十二节 B-side 职责族删除判据不同：删除判据问的是「后相是否依赖 B 侧职责」，本项问的是「目标变化能否在同一相内完成」。前者是后相的性质，后者是过程的性质。

二十四、条件相变定理

主张类型申报

依《法篇第一》相变式规范，相变主张分两类：只证相结构在某条件处发生质变者，为相结构主张；另证某系统或轨迹确已离开前相并进入后相者，为转相事件主张。

本篇同时承担两类，分列如下。

相结构主张：第八节所立的景观临界 Σ\_land^r。它由独立组织结构读数 J\_land^r 的等价类改变逼出，只断言 D/L 相支持结构在该临界处发生改变，不断言任何系统此刻已经转相。

转相事件主张：第九节所立的实际转相边界 Σ\_trans^{r,det} 与当前承载相改变。它断言某条实际轨迹确已离开 D 承载域并进入 L 承载域。

二者的关系已由篇内两节处理。第九节立其分别：PostCritical ≠ Transition，PhaseSupp = {D,L} 不等于 CurPhase = L。第十八节立其时刻：t\_land 为构形首次进入 Σ\_land^r 的时刻，t\_trans 为实际轨迹第一次取得 CurPhaseᵣ = L 并进入 L 稳定承载的时刻；连续失稳型可以 t\_land = t\_trans，非连续型可以 t\_land \< t\_trans。

下列条件相变定理的七条件跨两类主张：第二、第三条属相结构主张（景观临界与临界后相支持）；第四、第五、第六条属转相事件主张（生成谱系、当前承载相、后相可维持）；第一条为初态前件，第七条为排除条件，两类共用。

引用本定理者，须申明所引的是哪一类主张，或两类兼取。只引相结构主张者，不得据以断言任何系统已经转相。

本篇建立的是条件化相变充分判定，不主张在任意沉积场条件下 D→L 必然发生。

在合法 𝔐ᵣ 与固定 𝒞\_phase^r 中，若条件组 C\_phase 同时满足：

第一，存在 CurPhase=D 的稳定初态 S\_D；

第二，构形轨迹 𝔥ᵣ(t) 使 J\_land^r 跨越一个由 ∼\_land^r 判定成立的景观临界 Σ\_land^r；

第三，临界后的景观满足：

L ∈ PhaseSuppᵣ(𝔥ᵣ)

第四，存在合法实际轨迹从 S\_D 生成到某 S\_L：

S\_D ⪯\_gen^r S\_L

第五：

CurPhaseᵣ(S\_L)=L

第六：

S\_L 所属 LFamily=1 的稳定组织在 Δ\_ord^r 下可维持；

第七，不存在特权内部写入代办相变；

则：

C\_phase  
⇒  
该轨迹构成局部喑显 D→L 相变：

𝔓\_D^r  
⟶  
𝔓\_L^r

若另满足第十三节连续性条件，则裁为连续失稳型；

若另满足第十四节共存—成核—换盆条件，则裁为非连续成核型。

本定理只给出充分判定。

哪些动力条件必使 C\_phase 成立，不由本篇证明，交《喑显必然式》。

二十五、击穿条件

出现以下任一情形，本篇相变主张失败：

1\. 合法协议族内出现不能由非承重表示差异解释的 D/L 支持冲突；

在同一景观中存在 LFamily 时，仅因整个形成系统对 B 非退化而错误否定一个在自身 B\_D 工作域内保持不变的 DBranch；  
2\. 前后只有数值变化，没有 J\_land^r 的 D/L 承重组织结构改变；  
3\. 宣称跨过 Σ\_land^r，但稳定组织景观没有 D/L 相关重构；  
4\. 宣称发生 D→L，而实际轨迹没有发生 CurPhaseᵣ : D → L 的承载改变；  
5\. 后相不能在声明 Δ\_ord^r 下维持；  
6\. 后相来自另一内容、另一副本或无根外写，谱系不连续；  
7\. 只有一次 M\_ε = 1，没有稳定 L 后相；  
8\. 固定景观中外力直接换盆，却称为自显相变；  
9\. 用序参量跳变代替组织相证明；  
10\. 把域满、边沁、临界核、预沉积、迟滞或构形跳变中的任一具体机制写成普遍必要条件；  
11\. 把 PostCritical 直接写成 Transition；  
12\. 把相变可能、可达或高概率偷换成相变必然；  
13\. 所主张的目标变化可以由一条保持 CurPhaseᵣ 取值不变的合法生成链完全实现，即同相解释未被排除；  
14\. 引用条件相变定理时不申明所引为相结构主张还是转相事件主张，或只引相结构主张而断言某系统已经转相；  
15\. ⪯\_gen^r、∼\_land^r 或具体模型引入的 ∼\_B^r，其实际性质与本篇所申明的不符。

结语

喑显相变不是 B 变强，不是反馈出现，不是某个量越阈，也不是自动系统失稳以后变乱。

其普遍逻辑链为：

固定相变工作上下文 𝒞\_phase^r  
→  
沉积构形 𝔥ᵣ  
→  
稳定组织景观 𝔏ᵣ(𝔥ᵣ)  
→  
相支持 PhaseSuppᵣ(𝔥ᵣ)  
→  
景观临界 Σ\_land^r  
→  
当前承载相 CurPhaseᵣ(Sᵣ) 实际由 D 转为 L

其中：

景观支持哪些相，与当前状态实际由哪一相承载，必须分开；

D/L 相支持必须从独立组织事实回读，不能由协议标签直接宣布；

景观临界必须由 Stab、Basin、Reach、𝐊\_r^form 等承重组织结构的不可约重构推出，不能用“相已经变了”反向定义临界；

实际相变必须保持同一 r-bound 生成谱系，并形成可维持 L 后相；

连续失稳型还必须具有合法组织连续结构；

非连续成核型允许 D/L 共存、成核与换盆。

至此，本篇完成“喑如何转为显”的相变制度，不进入后相承重构形的来源闭合、不证明相变必然发生、不证明任意初态可达，也不处理显相内部 1→100 的分级。

新增：

一、第十节加 ⪯\_gen^r 的性质申明。核其三性：自反成立（零步后继链）；传递成立（二链相接仍合法）；反对称不成立且不要求成立——本篇的四项检查条件皆不含单向性要求，故若系统从 S\_a 演化到 S\_b 后还能沿合法后继回到 S\_a（振荡、循环、可逆复调即属此类），则二者互相可达而不相等。故本关系是预序不是偏序，其记号 ⪯ 只表示生成可达方向，不表示状态之间有唯一排序。并申明二事：本篇不对该关系取商（互相可达的状态可以 CurPhase 不同，取商会把相变本身抹掉）；相变要求 S\_D ⪯\_gen^r S\_L 是方向要求非序数要求，不排除同时存在回路，回路若存在只说明该相变可逆。

二、第八节加 ∼\_land^r 的性质申明：等价关系，三性成立，反对称不成立且不要求成立；三性为对实例化的要求而非本篇所证，体例同《喑显数理式》v1.3。

三、第二节 ∼\_B^r 加一句：具体模型若引入该关系，须为等价关系，否则 \[b\]ᵣ 记号不成立。

四、第二十三节加「同相解释排除」。上节所排除者为「景观未变而状态变了」；本项排除另一路——景观变了、状态也变了，而整个过程仍可在同一相内连续完成。证法落在 CurPhaseᵣ 上而非相支持上——第四节已明 DBranch 与 LFamily 可同时成立、二者不互斥，故不可由「D 与 L 互斥」立论。须证者为：不存在一条合法生成链使当前承载组织自始至终留在同一侧而目标变化仍然完成。依目标变化的内容分两种情形：其内容即为承载侧改变者，同相解释自动排除，只须申明；另有内容者，须逐项检查能否在同侧内完成，凡能完成者从相变主张中剔出，交分级式或极限式。本项的实际效果是划界。并申明本项与第十二节 B-side 职责族删除判据的分别：删除判据问后相是否依赖 B 侧职责，本项问过程能否在同一相内完成；前者是后相的性质，后者是过程的性质。

五、第二十四节加「主张类型申报」。本篇同时承担两类主张：相结构主张为第八节的景观临界，只断言相支持结构改变；转相事件主张为第九节的实际转相边界，断言某轨迹确已转相。二者关系由第十八节处理（可分离，连续失稳型可重合，非连续成核型分离）。条件相变定理七条件跨两类，逐条归属已列。引用者须申明所引为哪一类，只引相结构主张者不得据以断言任何系统已经转相。

六、第二十五节击穿条件增三项：同相解释未被排除；引用条件相变定理不申明主张类型或以相结构主张断言已转相；三个关系的实际性质与所申明不符。第二十六节回答程度「已完成」清单补三项，与上列新增内容对应。
