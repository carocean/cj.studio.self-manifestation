自显论·式篇第二十三·喑显组式第五 v1.3.1

# 喑显可达式

导言

本篇承《喑显一般式》《喑显数理式》《喑显相变式》《喑显源式》，只处理一个任务：

给定一个强喑初态及其沉积构形，在只允许声明边界输入、系统合法动力和合法构形生成的条件下，判定是否存在一条完整路径，使同一  
r-bound 生成谱系从 B-invariant 稳定成迹组织到达可维持的 B-conditioned  
稳定成迹组织。

本篇不证明 D → L  
为什么属于相变；相变式已经处理前后两相、临界和组织重构。本篇也不证明只要满足某些条件就必然到达  
L；“存在一条合法路径”和“所有或几乎所有轨迹最终到达”不是同一任务。

本篇的核心问题是：

O\_D^r ↝ O\_L^r ？

一、上游输入与构造进入条件

本篇是可达式。按可达式强度要求，目标构造必须先于可达证明成立；本篇不兼任构造式。

本篇所需目标构造对象记：

𝔠\_L^r

它必须至少给出 LFamily 稳定组织、稳定承载盆、形成承重结构、合法形成关系，以及显式构造见证与逐项验证。

《喑显相变式》交付 DBranch、LFamily、PhaseSuppᵣ、CurPhaseᵣ、Σ\_land^r、S\_D ⪯\_gen^r S\_L 及已建立相变子型。所承接的 ⪯\_gen^r 是该篇状态空间上的生成可达关系（预序，容许回路）；本篇只承接它作为上游见证，不在推导中使用其序性质。

《喑显源式》交付 valid / invalid / unknown 来源类、Supp\_{L,form}^r(\[H\])、ClosureLevel\_src^r 及来源约束。

但这些结果不自动推出：

Constructed(𝔠\_L^r)=1

因此公开登记：

喑显可达式-H1：

Constructed(𝔠\_L^r)=1

即 L 稳定组织构造类已经由独立证明达到构造强度，并有显式构造见证与逐项验证。

H1 的验证责任不归本篇内部完成；必须由独立构造式、已有达到构造强度的式文或后续明确构造证明关闭。

H1 是式级准入依赖：

Admission\_reach^r=1  
⇔  
Constructed(𝔠\_L^r)=1

H1 回答目标 L 组织类是否已经达到构造强度；Reach 回答当前 X₀ 是否能到达该构造类中的至少一个实例。

因此：

Constructibility of target class  
≠  
Reachability from this initial state

只有在 Admission\_reach=1 的准入域中，本篇的无附加构造条件可达定理才正式生效。

H1 未关闭时：

Status(ReachForm)=conditional/open

Γ₁—Γ₄ 不替代 H1 重新证明目标类可构造，只证明当前 X₀ 能到达一个由 H1 界定的目标类实例。

H1 未关闭时，本篇只建立条件可达制度与条件可达定理，不得宣称 L 构造已经完成。

二、初态、状态目标与路径目标

定义完整可达状态：

X^r=(S^r,𝔥^r)

给定初态：

X₀^r=(S₀^r,𝔥₀^r)

要求：

CurPhaseᵣ(S₀^r)=D

且 S₀ 由某个：

DBranch\_r(\[O\_D\],𝔥₀^r)=1

的稳定 D 分支承载。

定义构造实例判据：

Inst\_{𝔠\_L}^r(X)  
∈  
{1,0,⊥}

Inst\_{𝔠\_L}^r(X)=1

当且仅当 X 的 L 稳定组织、承载结构与形成承重组织满足 𝔠\_L^r 已给出的构造规范与逐项验证条件。

若 H1 未关闭而使构造规范不足以完成实例判定，则：

Inst\_{𝔠\_L}^r(X)=⊥

定义三值状态目标判据：

Target\_L^r(X)  
∈  
{1,0,⊥}

Target\_L^r(X)=1

当且仅当以下各项均已成立：

Inst\_{𝔠\_L}^r(X)=1；

L ∈ PhaseSuppᵣ(𝔥)；

CurPhaseᵣ(S)=L；

S 位于某个 LFamily\_r(𝔉\_L,𝔥)=1 的稳定承载盆；

该 L 承载在声明维持窗 Δ\_ord^r 内可维持。

若至少一个目标必要条件已经明确失败，则：

Target\_L^r(X)=0

若没有已证失败项，但至少一个承重判据为 ⊥，则：

Target\_L^r(X)=⊥

只有全部目标必要条件均为 1 时，才：

Target\_L^r(X)=1

因此三值合取采用：

0 ∧ ⊥ = 0

1 ∧ ⊥ = ⊥

因此：

Inst=⊥  
≠  
X 不属于目标

而是：

目标成员关系当前不可判。

若需要集合记号，只把已经判定为 1 的状态组成：

𝒯\_{L,state}^r  
\=  
{X : Target\_L^r(X)=1}

对一条历史 Γ 与时刻 t，定义路径目标判据：

Goal\_L^r(Γ,t)  
∈  
{1,0,⊥}

Goal\_L^r(Γ,t)=1

当且仅当：

Target\_L^r(X\_Γ(t))=1

且：

Lineage\_r(Γ\[0,t\])=1

若 Target\_L^r(X\_Γ(t))=⊥ 或 Lineage\_r(Γ\[0,t\])=⊥，且没有其它已证失败项，则：

Goal\_L^r(Γ,t)=⊥

只有目标状态判据或谱系判据已经明确失败时，才：

Goal\_L^r(Γ,t)=0

其中 Lineage\_r 表示从 X₀ 到当前时刻始终保持同一 r-bound 合法生成谱系。

因此同一个终点状态可以由合法谱系到达，也可以由复制、重初始化或替换等非法谱系到达；只有前者满足 Goal\_L。

定义可达工作上下文：

𝒞\_reach^r

至少固定：

模型实例；

初态 X₀；

许可输入制度；

合法系统后继；

禁止操作集；

𝒯\_{L,state}；

Lineage\_r；

时间域；

若为随机模型，还必须固定环境/策略制度、概率核与路径空间。

改变上述任一承重条件，必须重新判可达。

三、许可输入制度与合法系统后继

本篇普遍层将 π 限定为状态反馈策略：

π : Obs\_r(X) → A\_allow^r

即策略只依赖声明允许的当前可观测状态，不依赖未编码的先前历史。

若具体模型使用历史依赖策略，则必须另证：

Compat\_π(Γ₁,…,Γ\_n)=1

证明拼接后的整条历史仍服从同一策略。

区分三种输入制度：

Π\_allow^r：许可控制策略集；

Env\_det^r：确定性固定环境输入制度；

Env\_prob^r：概率环境制度。

因此：

存在许可策略可达 ≠ 确定性固定环境可达 ≠ 概率环境随机可达。

定义统一合法系统后继：

X' ∈ F\_reach^r(X,a)

其中 a 必须由 π∈Π\_allow、Env\_det 或随机制度合法产生。

F\_reach 同时服从正常边界输入、内部状态动力、构形更新及《喑显数理式》的合法更新次序，不允许把局部转移自由拼接成伪路径。

禁止操作集 𝒰\_forbid^r 包括直接设置相标签、M、内部承重变量、直接送入 L 盆、复制覆盖、重初始化换对象、隐藏控制器与无根结构外写。

四、许可历史与路径集合

给定 π∈Π\_allow^r，一条历史：

Γ=(X₀,a₀,X₁,a₁,…)

要求：

X\_{k+1} ∈ F\_reach^r(X\_k,a\_k)

且 a\_k 由 π 合法产生。

定义 Paths\_π^r(X₀)。

确定性固定环境 Env\_det 下定义 Paths\_{env,det}^r(X₀)。

所有控制策略的路径并集：

Paths\_allow^r(X₀)  
\=  
⋃\_{π∈Π\_allow^r} Paths\_π^r(X₀)

任何路径都不得出现 𝒰\_forbid；若使用来源类承重结构，该结构必须从当前 X₀ 沿本 Γ 合法生成。

五、可达定义

确定性可控有限可达定义为三值聚合：

Reach\_L^{ctrl}(X₀^r)  
∈  
{1,0,⊥}

Reach\_L^{ctrl}(X₀^r)=1

当且仅当：

∃π∈Π\_allow^r  
∃Γ∈Paths\_π^r(X₀)  
∃t\_f\<∞

使：

Goal\_L^r(Γ,t\_f)=1

Reach\_L^{ctrl}(X₀^r)=0

当且仅当已经证明：

∀π∈Π\_allow^r  
∀Γ∈Paths\_π^r(X₀)  
∀t\<∞

都有：

Goal\_L^r(Γ,t)=0

其余情形统一判：

Reach\_L^{ctrl}(X₀^r)=⊥

即：

既没有已证 Goal=1 的路径，

又不能证明全部许可路径、全部有限时刻均 Goal=0，

则不能把“尚未证明可达”偷换成“不可达”。

确定性固定环境可达同样定义为：

Reach\_L^{env}(X₀^r)  
∈  
{1,0,⊥}

Reach\_L^{env}(X₀^r)=1

当且仅当：

∃Γ∈Paths\_{env,det}^r(X₀)  
∃t\_f\<∞

使：

Goal\_L^r(Γ,t\_f)=1

Reach\_L^{env}(X₀^r)=0

当且仅当已经证明：

∀Γ∈Paths\_{env,det}^r(X₀)  
∀t\<∞

都有：

Goal\_L^r(Γ,t)=0

其余情形：

Reach\_L^{env}(X₀^r)=⊥

因此三值传导固定为：

Inst\_{𝔠\_L}  
→  
Target\_L  
→  
Goal\_L  
→  
Reach\_L^{ctrl/env}

其中任一承重环节的 ⊥ 都不得在后续自动坍缩成 0。

六、状态反馈路径拼接引理与条件可达定理

状态反馈路径拼接引理：

若 π:Obs\_r(X)→A\_allow^r，且有限历史段 Γ₁,…,Γ\_n 首尾共享端点，并且每段均由同一 π 与 F\_reach 合法产生，则：

Γ=Γ₁∘…∘Γ\_n

仍服从同一 π，即：

PolicyCompat\_r(π,Γ)=1

历史依赖策略不自动适用本引理，必须另证 Compat\_π=1。

关系性质申明。本篇的 ↝ 是路径记号：Γ:X\_a↝X\_b 表示存在一段由许可动力生成的有限合法历史，其起点为 X\_a、终点为 X\_b。由它可以定义状态之间的二元关系：

X\_a ↝\_π^r X\_b

当且仅当在许可策略 π 下存在这样一段有限合法历史。该关系的性质如下：

自反性依约定而定：零长历史是否计入，本篇未规定；由于本篇一切用法都要求实际经过许可动力生成，且 T\<∞ 的时长条件在零长时退化，故本篇不依赖自反性，具体模型可自行约定。

传递性在同一许可策略内成立，但它不等同于上述拼接引理。拼接引理所证者为策略相容——相接后的历史仍服从同一 π，即 PolicyCompat\_r(π,Γ)=1；而传递性所需者为相接后的历史仍是合法历史，策略相容只是合法性的条件之一。传递性还需三条：各段皆由 F\_reach^r 合法产生，相接不引入新的产生方式故保持；各段时长有限而段数有限，故 t\_f 之和仍有限；各段不使用 𝒰\_forbid^r，相接不引入新输入故保持。三条与拼接引理合起来，得：若 X\_a ↝\_π^r X\_b 且 X\_b ↝\_π^r X\_c，则 X\_a ↝\_π^r X\_c。

此处须与第三节「F\_reach 不允许把局部转移自由拼接成伪路径」一句对读：该句禁的是把不合法的局部转移拼起来冒充路径；本处所论的是两段本已合法的历史相接后仍合法。二者不冲突——前者管拼接的材料，后者管拼接的结果。

本篇第六节四段路径的拼接，正是逐条检查了这些条件后才得出 t\_f=T₁+T₂+T₃+T₄\<∞ 与 PolicyCompat\_r(π,Γ)=1；此处只是把该处的做法抽为关系的一般性质。

跨策略不自动成立：不同 π 下的两段历史相接，其相容性须另证 Compat\_π=1。历史依赖策略不适用本引理，同上。无限段相接不保持有限性，故传递性只对有限次相接成立。

反对称性不成立，也不要求成立：若从 X\_a 有合法路径到 X\_b，且从 X\_b 也有合法路径回到 X\_a，二者互相可达而不相等。本篇的许可输入制度不禁止回路，可逆过程与循环轨道皆属此类。故 ↝\_π^r 是预序，不是偏序。

此性质与《喑显相变式》的 ⪯\_gen^r 同类——二者都是生成可达关系，都容许回路——而与《喑显源式》的历史图内祖先关系 ⪯\_H^r 不同，后者定义显含时间偏序，无回路。三者不得因记号或名称相近而互推。

本篇不对 ↝\_π^r 取商：互相可达的状态可以有不同的 Inst\_{𝔠\_L}^r 取值与不同的 CurPhase，取商会把可达判定本身抹掉。

以下定理在：

Admission\_reach^r=1

的准入域内成立。

要求存在同一许可状态反馈策略 π、共享端点 X₁,X₂,X₃,X₄，以及四段有限合法历史：

Γ₁:X₀↝X₁  
Γ₂:X₁↝X₂  
Γ₃:X₂↝X₃  
Γ₄:X₃↝X₄

且 T₁,T₂,T₃,T₄\<∞。

第一，来源形成段：

SourceWitnessValid\_r(Γ₁,\[H\])=1。

该见证可以由《喑显源式》的已有合法来源证明支持；也可以由本篇直接对 Γ₁ 实际使用的来源子图证明 BaseSrc、SourceTransform、形成承重结构与谱系均合法。

若后一种局部重新证明产生新的来源知识，则必须生成：

ΔSrcProof\_{Γ₁}

回传《喑显源式》或《喑显组式总图》的来源缺口管理接口。

ΔSrcProof 只关闭或缩小该具体来源子图的 unknown，不自动推出整个 \[H\] 的 AdmClass=1 或 HistClosureClass=1。

第二，构形串联段：

Γ₂ 从 X₁ 合法进入满足 L 形成要求的构形域 𝓗\_req。

第三，临界进入段：

Γ₃ 从 X₂ 进入相应景观临界组织域。

第四，承载完成段：

Γ₄ 从 X₃ 合法进入稳定 LFamily 承载，并满足：

Inst\_{𝔠\_L}^r(X₄)=1

以及：

X₄∈𝒯\_{L,state}^r

由状态反馈路径拼接引理：

PolicyCompat\_r(π,Γ)=1

其中：

Γ=Γ₁∘Γ₂∘Γ₃∘Γ₄

并要求：

Lineage\_r(Γ)=1

故：

t\_f=T₁+T₂+T₃+T₄\<∞

定义上述路径条件合取为：

C\_reach^r(X₀,π)

则在 Admission\_reach=1 的准入域内：

C\_reach^r(X₀,π)  
⇒  
Reach\_L^{ctrl}(X₀^r)=1

证明：四段有限合法历史可按共享端点拼接；终点 X₄ 是 𝔠\_L 的合法实例并满足其余 L 状态目标，整段 Lineage=1，故 Goal\_L(Γ,t\_f)=1。

H1 未关闭时，上述定理只以开放依赖条件保存，不得冒充已经满足可达式全部准入条件的封闭结论。

七、路径不是证明次序

下列论证无效：

O\_D 已成立； O\_L 已成立； 所以 O\_D 可达 O\_L。

两个端点都存在，只证明两种组织可能存在。

可达式必须给出中间路径，并逐步证明每一转移属于：

Φᵣ Ξ 或其它上游已声明许可关系。

故：

Exist(O\_D) ∧ Exist(O\_L) ⇏ Reach\_L^{ctrl}(X₀)

八、景观可达与实际可达

若某构形下：

L ∈ PhaseSuppᵣ(𝔥)

只说明 L 稳定组织在该景观中存在。

它不推出：

Reach\_L^{ctrl}(X₀^r) = 1

可能存在：

L 盆与 X₀ 完全隔离； 所需构形无法由许可动力生成； D/L  
之间存在不可跨越边界； 只有特权写入才能进入 L；  
实际谱系在到达临界前已经终止。

因此：

StableExistence\_L ≠ Reachability\_L

九、来源成立与构形可达

《喑显源式》可以证明某个 L  
形成承重结构具有合法来源历史，但来源闭合不等于从当前 X₀ 可达。

若路径使用来源类 \[H\] 中的 Supp\_{L,form}^r(\[H\])，必须重新检查：其 BaseSrc  
在当前 𝒞\_reach 中可用；其 SourceTransform  
属于当前许可动力；其承重结构能从当前 X₀ 沿同一 Γ 实际生成。

若到达 L 需要构形域 𝓗\_req^r，则必须证明 𝔥₀^r ↝ 𝓗\_req^r  
沿合法构形转移成立。

因此：

SourceClosed ≠ ReachableFrom(X₀)

十、连续失稳型可达

对连续失稳型，若存在许可构形轨道：

𝔥₀^r ↝ Σ\_land^r ↝ 𝔥\_L^r

且在该轨道上同一 r-bound D 分支持续存在至临界，随后失稳并由合法动力进入  
L 稳定组织，则该连续失稳型路径构成 Reach\_L^{ctrl}=1 的合法见证。

最低路径结构：

X₀^D → 构形连续演化 → Σ\_land → DBranch 按连续失稳型条件失稳 → 合法 B-side 实际承重  
→ O\_L → StableOrg

若构形虽可到临界，但系统在此前必然退出 r-bound 工作域，则该路径不成立。

十一、非连续成核型可达

对非连续成核型，L 分支存在仍不足够。

必须存在许可路径形成一个能够跨越 模型级非连续成核/换盆条件 的  
B-conditioned 局部组织。

若模型使用临界核 N\_c，则要求存在：

N₀ ↝ N

且：

N ≥ N\_c

该增长、组合或生成过程必须由许可动力完成。

若所有许可路径均满足：

N \< N\_c

则即使：

L ∈ PhaseSuppᵣ(𝔥)

也不可从当前初态到达 L。

十二、预塑、首写与混合来源路径

若可达见证使用《喑显源式》的来源类型，必须从具体来源历史类回读。

Pre 路径要求临界相关形成职责此前已合法形成，并且当前 X₀  
能沿许可路径保存、释放或重新承接这些结构。

Onset 路径要求关键形成职责在临界相关过程中首次由许可内部动力取得。

Mixed 路径要求临界前来源贡献与临界相关后续改写都实际进入同一合法来源图。

任何一种来源类型都不能仅凭“这种历史理论上存在”直接变成当前 X₀  
的可达见证。

十三、来源类与当前路径一致性

若来源类 \[H\] 被用于可达证明，则它不得已被《喑显源式》判为  
invalid；其关键来源节点不得依赖当前 𝒞\_reach  
禁止的边界或操作；其形成承重结构必须能嵌入当前 Γ；其 r-bound  
谱系必须与当前 X₀ 一致。

GenerativeExplanationClosed 也不自动推出从当前 X₀ 可达。

十四、正常外诱

外部输入可以属于可达路径。

例如：

A\_ext → 正常 Gate/Pass → 自动前件改变 → 内部 B/Y/T 合法作用 →  
构形与景观变化 → D → L

只要 A\_ext 没有越过声明接口替系统完成 B-side  
接权，该路径仍属于自显可达。

因此：

ExternalTrigger ≠ PrivilegedCompletion

十五、谱系保持

候选路径 Γ 必须满足：

Lineage\_r(Γ)=1。

若中途：

旧系统被销毁后重新初始化； r 被 s 替换； L 由另一个副本复制而来；  
核心承重结构通过无根外写加入；

则即使终点满足部分 L 状态条件，只要 Lineage\_r(Γ)≠1，也不是当前 X₀^r 的喑显可达路径。

十六、事件级可达不等于相级可达

存在路径使某次事件：

M\_ε = 1

不推出：

Reach\_L^{ctrl}(X₀^r) = 1

因为该事件可能失败成核，随后返回 D。

相级可达的目标必须是：

𝒯\_{L,state}^r

即稳定 B-conditioned 组织承载域，而不是一次 M = 1 的事件集合。

十七、有限路径与渐近路径

若存在有限时间进入 𝒯\_{L,state}^r 的许可轨迹，则为有限可达。

若系统对所有有限 t 均未进入 𝒯\_{L,state}^r，只在：

t → ∞

时趋近 L 边界，则不能把它直接写成有限可达。

若目标定义允许渐近到达，必须另行声明：

Reach\_L^∞

并给出极限意义。

本篇的 Reach\_L^{ctrl} 与 Reach\_L^{env} 均默认指有限时间实际进入，不以无限趋近冒充到达。

二十、旁路与替代路径

发现一条候选路径被击穿，不等于不可达。

若存在另一条完全合法路径：

Γ₂ ≠ Γ₁

仍可从 X₀ 形成某 Γ,t 使 Goal\_L(Γ,t)=1，则可达仍成立。

因此不可达证明必须覆盖全部许可路径类，不能只击穿研究者最初设想的一条机制。

反之，可达证明只需给出至少一条完整合法见证路径。

二十一、最小可达见证

可达见证至少包含：

Admission\_reach^r=1；

初态 X₀^r；

目标构造类 𝔠\_L^r；

终点实例判据：

Inst\_{𝔠\_L}^r(X\_f)=1；

三值状态目标：

Target\_L^r(X\_f)=1；

许可策略集 Π\_allow^r 或对应环境制度；

实际路径 Γ；

路径中每一关键来源与构形变化的合法性；

跨越 Σ\_land 或具体模型换盆/成核条件的位置；

LFamily 实际承重位置；

终点：

X\_f∈𝒯\_{L,state}^r；

以及：

Lineage\_r(Γ)=1。

若 H1 未关闭，则见证报告必须同时注明：

Status(ReachForm)=conditional/open

不能给出“封闭可达式”裁定。

缺少任一承重环节，不得仅凭模拟最终输出判可达。

二十二、不可达见证

不可达不能由“目前没有找到路径”推出。

确定性可控不可达：

Reach\_L^{ctrl}(X₀^r)=0

要求证明：

∀π∈Π\_allow^r  
∀Γ∈Paths\_π^r(X₀)  
∀t\<∞

都有：

Goal\_L^r(Γ,t)=0

或给出一个覆盖全部许可策略与历史的不可绕过不变量/障碍。

例如若存在不变量 I，使：

I(X₀)∈D\_I

且所有许可统一后继都保持：

I(X')∈D\_I

而所有满足 Goal\_L 的目标状态都要求：

I(X\_L)∉D\_I

则 L 不可达。

对于无限历史不使用未定义的 End(Γ)。

二十三、与必然式的边界

可达只证明：

∃ Γ : D ↝ L

必然式要证明：

C ⇒ D → L

或者在概率模型中证明相应分布层必然后果。

因此：

Reach\_L^{ctrl} = 1 ⇏ NecessaryTransition\_L

一条合法路存在，不意味着系统一定走那条路。

二十四、与实现式的边界

形式系统证明：

Reach\_L^{ctrl}(X₀) = 1

不等于现实工程已经实现该路径。

实际装置是否具有声明的状态、接口、构形动力，并是否真实走过  
Γ，属于实现任务。

本篇只证明理论系统中的许可可达性。

二十五、击穿条件

出现以下任一情形，可达主张失败：

1\.  只有 D、L 两端，没有中间合法路径；  
2\.  路径使用未申报内部写口、调试口或隐藏控制器；  
3\.  所需构形有来源解释，却不能从当前初态合法生成；  
4\.  只到达一次 M = 1，没有进入 StableOrg；  
5\.  路径中途换成另一内容、另一副本或重新初始化系统；  
6\.  把 L 稳定存在直接当成从当前 D 可达；  
7\.  成核型中所有许可核均低于临界，却仍宣称可达；  
8\.  连续型中到临界前 r-bound 工作域已经终止；  
9\.  随机模型只有零测度数学轨迹，却宣称物理可达；  
10\. 把正概率可达写成几乎必然或确定性必然；  
11\. 把无限趋近目标写成有限到达；  
12\. 击穿一条路径后即宣称全部不可达，而未覆盖其它许可旁路；  
13\. 把 ↝\_π^r 当作偏序使用——例如据 X\_a ↝ X\_b 与 X\_b ↝ X\_a 推出 X\_a = X\_b，或对该关系取商后再判可达。

结语

喑显可达式只问：从给定强喑初态出发，在声明输入制度与系统合法后继下，是否存在同一 r-bound 谱系的有限路径进入已经构造成立的 L 目标类实例。

构造与可达的对象链为：

Constructed(𝔠\_L^r)  
→  
Inst\_{𝔠\_L}^r(X)  
→  
Target\_L^r(X)  
→  
Goal\_L^r(Γ,t)  
→  
PathHit\_L^r(Γ)  
→  
Reach\_L^{ctrl/env}(X₀)

其中三值逻辑逐层保持：

目标必要条件任一明确失败，即 Target=0；

无失败但仍有未决，即 Target=⊥；

路径有限时间内一旦出现 Goal=1，即 PathHit=1；

只有已经证明所有有限时刻 Goal=0，才 PathHit=0；

其余路径命中状态为 ⊥。

确定性 Reach：

存在 PathHit=1 的许可路径时为 1；

全部量词域 PathHit=0 时为 0；

其余情形为 ⊥。

随机 Reach：

只有在 UnresolvedHit\_L 具有零测度、即 ResolvedGoal=1 时，才允许把命中概率转换成 0/1 层级；

若未决命中路径仍有正测度，则概率 Reach 保持 ⊥。

H1 仍是式级准入依赖：

Admission\_reach^r=1  
⇔  
Constructed(𝔠\_L^r)=1

在该准入域内：

C\_reach^r(X₀,π)  
⇒  
Reach\_L^{ctrl}(X₀)=1

来源历史空间不必全部 HistoricalSourceClosed=1 才能证明一条具体可达路径；但实际使用的来源子图必须由 SourceWitnessValid 证明合法。若本篇产生新的局部来源证明，则以 ΔSrcProof 回传来源缺口管理，不擅自关闭整个来源历史类。

因此：

目标类可构造 ≠ 当前初态可达；  
存在 L 相 ≠ 当前初态可达；  
来源空间全局闭合 ≠ 一条具体来源路径合法；  
unknown 来源本身 ≠ 合法可达前件；  
存在策略可达 ≠ 固定环境可达；  
可达 ≠ 必然；  
可达 ≠ 实现。
