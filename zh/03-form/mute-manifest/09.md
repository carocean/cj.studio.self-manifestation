自显论·式篇第二十三·喑显组式第九 v1.0

# 喑显构造式

导言

本篇承《喑显数理式》与《喑显相变式》，只处理一个任务：给出一个显式构造，使 L 稳定组织构造类 𝔠\_L^r 达到构造强度。

《喑显可达式》公开登记了一项式级准入依赖：

喑显可达式-H1：Constructed(𝔠\_L^r)=1

该篇明写此项不由其内部完成，须由独立构造式关闭。本篇即承担此任务。

本篇不证明 L 必然形成，不证明从任意初态可达 L，不证明 D→L 属于相变，也不证明所构造者是唯一的 L 组织类。本篇只回答一件事：满足 LFamily 判据的那个东西，长什么样，怎样一步一步造出来，以及为什么造出来的东西确实满足每一条。

本篇是构造式，不兼任可能式。凡以存在性论证代替显式构造者，本篇视为未完成。

一句话：能被判为 L 的东西不是只能被指认，它可以被造出来；本篇给出造法与逐项验收。

⸻

一、上游进入条件

本篇承继：

《喑显数理式》v1.3：合法模型实例 𝔐ᵣ 的结构、成迹等价 ∼\_ε、稳定组织等价 ∼\_r^org、StableOrg 与 Stab、Basin、Reach 的回读规则、形成协议 Prot\_form^r、合法 B 条件域 𝓑\_adm^r、扩展形成映射 𝒦\_r^form、普通扰动类 Δ\_ord^r。

《喑显相变式》v1.3：LFamily 判据四条、DBranch 判据、PhaseSuppᵣ 与 CurPhaseᵣ、合法协议族 𝔓\_form^r。

本篇不引用 Oᵣ ⇒ Pᵣ ∧ Mᵣ，故不传导 \[喑显一般式-H1\]。本篇所构造者为形式对象，其成立不依赖首显是否非自动。

进入条件三项：

其一，合法模型实例 𝔐ᵣ 已按《喑显数理式》完成实例化，其中 ∼\_r^org 满足三性、Δ\_ord^r 已声明、Prot\_form^r 已固定。

其二，条件组闭合。本篇所要满足的条件组即 LFamily\_r(𝔉\_L, 𝔥ᵣ)=1 的四条，加《喑显可达式》另要求的稳定承载盆、形成承重结构与合法形成关系。该条件组逐项可查，无待定项。

其三，相容性。本篇不另证相容——四条判据的相容性由本篇的构造本身给出：造得出来即相容。若构造在某一步不可执行，则该条件组在本模型内不相容，此为本篇的击穿之一。

⸻

二、条件组申报

本篇所要构造的对象记 𝔠\_L^r。它须同时满足以下各项。

甲组·来自 LFamily 判据（《喑显相变式》第四节）

甲一，存在 B-indexed 稳定分支族 𝔉\_L = {(b,\[O\_b\]) : b ∈ B\_L ⊆ 𝓑\_stab^r}，且对每个 b 有 𝒦\_{r,Prot}^form(b;𝔥ᵣ) = \[O\_b\]。

甲二，B\_L 至少包含两个可比较合法 B 条件。

甲三，存在 b₀、b₁ ∈ B\_L，使 \[O\_{b₀}\] ≠ \[O\_{b₁}\]。

甲四，各 \[O\_b\] 均属于 StableOrg。

甲五，该 B-conditioned 非退化关系在合法协议族 𝔓\_form^r 中保持同一物理组织意义。

乙组·来自《喑显可达式》第一节的目标构造要求

乙一，稳定承载盆：对每个 \[O\_b\]，Basin(\[O\_b\]) 已给出且非空。

乙二，形成承重结构：造出各 \[O\_b\] 所实际依赖的构形成分已显式列出。

乙三，合法形成关系：从 Prot\_form^r 的共同初始构形到各 \[O\_b\] 的形成路径由合法动力 Φᵣ 给出，不含特权写入。

丙组·本篇自加的两项，用于封住构造的两个常见漏洞

丙一，非平凡性：所造 𝔉\_L 不得由把同一个组织重复登记两次而成。即 b₀ ≠ b₁ 且 \[O\_{b₀}\] ≠ \[O\_{b₁}\] 须由动力实际生成，不由记号区分制造。

丙二，非特权性：B\_L 中每个 b 都属于 𝓑\_adm^r，即满足 Src\_B、同迹许可与形成协议的正常输入要求；不得因「最终形成了稳定组织」而事后把某个 b 纳入。

条件组至此闭合，共十项。

⸻

三、构造程序

本节给出逐步显式的构造。每一步只使用 𝔐ᵣ 已有的对象与动力，不引入新结构。

第一步·固定形成协议

取 Prot\_form^r = (F\_form^auto, 𝔥\_init, U\_form, Stop\_form)，其中：

F\_form^auto 为共同自动前件；  
𝔥\_init 为共同初始构形；  
U\_form 为合法边界输入类；  
Stop\_form 为形成过程的停止与定局规则。

此四项由 𝔐ᵣ 的实例化给出，本步只是固定它们，使后续各 b 在同一协议下比较。

固定之后，形成映射 𝒦\_{r,Prot}^form : 𝓑\_adm^r → (𝒪\_r^stable / ∼\_r^org) ∪ {⊥\_form} 即被确定。

第二步·取两个合法 B 条件

本步须先说明一件事，否则以下诸步不是构造而是搜索。

若只写「在 𝓑\_adm^r 中取 b₀ 与 b₁，使其满足某某条件」，而不说取法，则本篇所给的不是构造程序，是存在性论证的分步改写——法篇构造式禁止写法首条正禁此事。且若 𝓑\_adm^r 无穷，「所有合法对皆失败」这一判据不可执行。

故本步要求具体模型先声明两件：

其一，𝓑\_adm^r 上的一个可枚举序 σ。即给出一个映射 σ : ℕ → 𝓑\_adm^r，使 𝓑\_adm^r 的每个成员至少被枚举一次。若 𝓑\_adm^r 有限，取任一排列即可；若无穷，须给出显式的枚举规则。

其二，一个终止界 N。即声明本次构造只检验 σ 的前 N 项所生成的条件对。

二者由具体模型声明，不由本篇规定——本篇不知道任何具体的 𝓑\_adm^r 长什么样。二者未声明时，本篇输出 ⊥ 而非 0。

声明之后，本步为：按 σ 依次取 (σ(i), σ(j))，1 ≤ i \< j ≤ N，得候选条件对的有序列表 L\_cand。对每一对检验：

其一，二者皆满足 Src\_B、同迹许可与 U\_form 的正常输入要求（此即丙二）；  
其二，二者不属于同一 \[b\]\_r。

不满足者从 L\_cand 中划去。所余者按序进入第三步。

若 L\_cand 为空，则在前 N 项内不存在合法条件对。此时本篇输出 Constructed(𝔠\_L^r)=⊥，并申明：在所声明的枚举序与终止界内未找到，非已证不可构造。

只有当具体模型另证 𝓑\_adm^r 有限且 N 已覆盖其全部成员时，L\_cand 为空方得输出 Constructed=0。此二者的分别贯穿以下各步，不再重复说明。

第三步·分别运行形成过程

自 𝔥\_init 出发，以 F\_form^auto 为自动前件、U\_form 为边界输入，分别令 B 取 b₀ 与 b₁，按 Φᵣ 运行至 Stop\_form 所定的形成定局。

得两个形成结果：

𝒦\_{r,Prot}^form(b₀; 𝔥ᵣ) = \[O\_{b₀}\]  
𝒦\_{r,Prot}^form(b₁; 𝔥ᵣ) = \[O\_{b₁}\]

若某一支输出 ⊥\_form，即该 b 在本协议下未形成可判稳定组织，则该对不合用，从 L\_cand 中划去，取 L\_cand 中下一对重复本步。

若 L\_cand 中所有对皆有一支输出 ⊥\_form，则在所声明的枚举序与终止界内不存在可用对，输出 ⊥（或在 𝓑\_adm^r 有限且 N 已覆盖全部成员时输出 0）。

第四步·检验二者不同

比较 \[O\_{b₀}\] 与 \[O\_{b₁}\]，比较在稳定组织商空间 𝒪\_r^stable / ∼\_r^org 中进行。

若 \[O\_{b₀}\] = \[O\_{b₁}\]，则该对不合用，从 L\_cand 中划去，取下一对重复第三、四步。

若 L\_cand 中所有对皆得同一商类，则在所检验的范围内形成映射为常映射，输出 ⊥；只有在 𝓑\_adm^r 有限且 N 已覆盖全部成员时，方得输出 Constructed=0，此时该结论与《喑显相变式》LFamily=0 的判定一致。

若 \[O\_{b₀}\] ≠ \[O\_{b₁}\]，进入第五步。此时甲三与丙一同时得到满足：二者之异在商空间中成立，即由动力实际生成，非由记号区分制造。

第五步·检验各支稳定

对每个 \[O\_b\]（b ∈ {b₀, b₁}），在固定该 b 所属的有效 B 条件类 \[b\]\_r 的前提下，取普通扰动类 Δ\_ord^r(\[b\]) 中的扰动逐一施加，运行合法动力 Φᵣ，检验扰动后是否仍保持或恢复到同一稳定组织商类 \[O\_b\]。

若是，则 \[O\_b\] ∈ StableOrg，且 Stab(\[O\_b\] \| \[b\]\_r, Δ\_ord) 成立。

若某一支不稳定，则该对不合用，从 L\_cand 中划去，取下一对重复第三至第五步。

若 L\_cand 中所有对总有一支不稳定，输出 ⊥；只有在 𝓑\_adm^r 有限且 N 已覆盖全部成员时，方得输出 Constructed=0。

第六步·给出承载盆

对每个 \[O\_b\]，定义：

Basin(\[O\_b\]) = {X ∈ 𝒮ᵣ × ℋᵣ : 自 X 出发、在 \[b\]\_r 固定下运行 Φᵣ，最终保持或恢复到 \[O\_b\]}

由第五步，Δ\_ord^r(\[b\]) 所生成的扰动态皆在 Basin(\[O\_b\]) 内，故 Basin(\[O\_b\]) 非空。此即乙一。

第七步·列出形成承重结构

对每个 \[O\_b\]，追溯第三步的形成过程，列出其中实际参与形成 \[O\_b\] 的构形成分。此列表即该支的形成承重结构。

追溯之法依《喑显源式》的来源解析 ρ\_src^r：凡在形成过程中承担 FormRole=1 者入列，只作背景而不承担者不入列。

本步只列出，不判其反事实必要——后者归《喑显源式》的 NecessarySource，非本篇任务。此即乙二。

第八步·扩充为族

至此已得二元族 𝔉\_L^{min} = {(b₀,\[O\_{b₀}\]), (b₁,\[O\_{b₁}\])}。

若 𝓑\_adm^r 中另有 b 满足第二、三、五步的要求，可一并纳入，得 𝔉\_L = {(b,\[O\_b\]) : b ∈ B\_L}，其中 B\_L ⊇ {b₀, b₁}。

扩充不是必需的：LFamily 判据只要求 B\_L 至少含两个合法 B 条件，故 𝔉\_L^{min} 已足以满足甲二。扩充只使构造更丰满，不改变构造是否成立。

第九步·跨协议检验

取合法协议族 𝔓\_form^r 中另一协议 Prot'，重复第一至第五步。

若在 Prot' 下所得的 B-conditioned 非退化关系与在 Prot 下所得者保持同一物理组织意义——即两协议下的 \[O\_{b₀}\] 与 \[O\_{b₁}\] 分别对应同一物理组织，且二者相异这一事实在两协议下皆成立——则甲五得到满足。

若某协议下二者不再相异，则该「相异」是协议之产物而非系统之性质，构造不成立，输出 Constructed=0。此步是本篇最要紧的一道关：它挡住的是「用协议造出一个 L」。

第十步·输出

至此得：

𝔠\_L^r = (𝔉\_L, {Basin(\[O\_b\])}\_{b ∈ B\_L}, {形成承重结构}\_{b ∈ B\_L}, {形成路径}\_{b ∈ B\_L}, Prot\_form^r, 𝔓\_form^r 中的检验记录)

构造完成。

与《喑显可达式》第一节所要者对读：该节要求「必须至少给出 LFamily 稳定组织、稳定承载盆、形成承重结构、合法形成关系，以及显式构造见证与逐项验证」。逐项对应如下——LFamily 稳定组织即 𝔉\_L（第八步）；稳定承载盆即 {Basin(\[O\_b\])}（第六步）；形成承重结构即 {形成承重结构}（第七步）；合法形成关系即 {形成路径} 与 Prot\_form^r（第三步与第一步）；显式构造见证即第三节全部十步的运行记录与第九步的跨协议检验记录；逐项验证即第四节。六者齐备，无缺项。

⸻

四、构造物满足条件的逐项验证

甲一。由第一步固定 Prot、第三步运行形成过程得。每个 (b,\[O\_b\]) 皆有 𝒦\_{r,Prot}^form(b;𝔥ᵣ) = \[O\_b\]，此即第三步的输出。

甲二。B\_L ⊇ {b₀, b₁}，二者由第二步在 𝓑\_adm^r 中取得，且不属于同一 \[b\]\_r，故为两个可比较的合法 B 条件。

甲三。由第四步的检验直接得：\[O\_{b₀}\] ≠ \[O\_{b₁}\] 在商空间中成立。

甲四。由第五步的检验直接得：各 \[O\_b\] 在 Δ\_ord^r(\[b\]) 下保持或恢复同一商类，故属 StableOrg。

甲五。由第九步的跨协议检验得。

乙一。由第六步得，且已证非空。

乙二。由第七步得。

乙三。形成路径即第三步所运行者，其动力为 Φᵣ，输入为 U\_form，皆合法；Stop\_form 为定局规则，非特权写入。故形成关系合法。

丙一。第四步的比较在商空间 𝒪\_r^stable / ∼\_r^org 中进行，商掉了记号与非承重表示差异，故 \[O\_{b₀}\] ≠ \[O\_{b₁}\] 意味着二者在稳定组织回读量上确实不同，非记号所造。

丙二。第二步取 b 时已要求 b ∈ 𝓑\_adm^r，即已满足 Src\_B、同迹许可与正常输入要求；且取 b 在运行形成过程之前，非事后纳入。

十项逐一验毕。

⸻

五、构造定理

喑显 L 组织类构造定理

设合法模型实例 𝔐ᵣ 已按《喑显数理式》完成实例化，形成协议 Prot\_form^r 与合法协议族 𝔓\_form^r 已固定，合法 B 条件域 𝓑\_adm^r 与普通扰动类 Δ\_ord^r 已声明，且具体模型已声明 𝓑\_adm^r 上的可枚举序 σ 与终止界 N。

若第三节的构造程序十步皆可执行，即：

在 σ 的前 N 项内存在两个不同有效 B 条件类的合法条件 b₀、b₁；  
二者在 Prot 下皆形成可判稳定组织，非 ⊥\_form；  
所形成的两个组织商类相异；  
各支在其 B 条件类固定下于 Δ\_ord^r 内稳定；  
该相异在 𝔓\_form^r 的其余协议下保持；

则第三节所输出的 𝔠\_L^r 满足第二节所申报的全部十项条件，故：

Constructed(𝔠\_L^r) = 1

证明即第四节的逐项验证。证毕。

三值申明。本定理只给出 Constructed=1 的充分条件。其余二值须分辨：

Constructed(𝔠\_L^r)=0 只在 𝓑\_adm^r 已证有限、且 N 已覆盖其全部成员、而检验全数失败时输出。此为已证不可构造。

Constructed(𝔠\_L^r)=⊥ 在以下情形输出：σ 或 N 未声明；在 σ 的前 N 项内未找到可用对而 𝓑\_adm^r 未证有限或 N 未覆盖全部成员；第八节所列须实例化的项目有缺。此为未找到，非已证不可构造。

不得把 ⊥ 读作 0。在无穷或未知大小的 𝓑\_adm^r 上，本篇的程序只能给出正判，不能给出负判——此即本篇的能力边界。

推论。《喑显可达式》的式级准入依赖

Admission\_reach^r = 1 ⇔ Constructed(𝔠\_L^r) = 1

于本定理的前提下关闭。该篇的条件可达定理自此在准入域内正式生效，其 Status 由 conditional/open 转为在本定理前提下成立。

⸻

六、强度申报

本篇达到构造强度，不达到实现强度。

按《法篇第一》第二编第五章的四级（相容 ≺ 构造 ≺ 可达 ≺ 实现）：

相容——由本篇的构造给出：造得出即相容。  
构造——本篇所达到者。构造程序显式，逐项验证完成。  
可达——不由本篇给出。从某个初态能否到达所构造的类中某一实例，归《喑显可达式》。  
实现——不由本篇给出。在真实资源、材料、精度与时间约束下能否落成，归实现式，本组尚无该篇。

另须申明三项本篇不承担者：

其一，本篇不证明所构造的 𝔠\_L^r 是唯一的 L 组织类。同一模型中可以有多个满足十项条件的构造，本篇只给出一个。

其二，本篇不证明 L 必然形成。构造回答「满足者长什么样」，不回答「它会不会出现」。后者归《喑显必然式》。

其三，本篇不证明所构造者对应任何现实系统。本篇的构造在 𝔐ᵣ 内进行，𝔐ᵣ 是否有现实对应，归《喑显判定式》与具体模型。

其四，本篇的构造程序在无穷或未知大小的 𝓑\_adm^r 上只能给出正判，不能给出负判。找到一对即得 Constructed=1；未找到只得 ⊥。负判须另有 𝓑\_adm^r 有限性的独立证明，该证明不由本篇给出。

⸻

七、击穿条件

出现以下任一情形，本篇构造主张失败：

其一，构造物不满足条件组的某一项。展示所输出的 𝔠\_L^r 中，甲一至甲五、乙一至乙三、丙一或丙二中某一项不成立。

其二，构造程序的某一步无法执行，而本篇未申明该情形。第二、三、四、五、九步各有不可执行时的处置（输出 Constructed=0 并申明原因）；若某步在某模型中不可执行而本篇未给出处置，则本篇的程序不完整。

其三，所构造的相异由协议制造。展示存在 𝔓\_form^r 中的合法协议，在其下 \[O\_{b₀}\] 与 \[O\_{b₁}\] 不再相异，而第九步的检验未能查出。此击穿甲五，亦击穿整个构造。

其六，B\_L 中某个 b 实为事后纳入。展示某 b 不满足 Src\_B、同迹许可或正常输入要求，而是因其形成了稳定组织才被纳入 𝓑\_adm^r。此击穿丙二。
