# 喑显玩具模型实测记录

体例说明

本件非式文。它不承担独立待证命题、独立证明目标、独立完成条件与独立击穿方式，故按《法篇第一》第一编第四章不构成正式式，不占式篇编号，不进入组式成员表，不受第九编审稿规范约束，但受全书术语规范与编号规范约束。

本件为实验记录，登记一次玩具模型的构建与检验，供组内各篇引用。凡引用本件数据者，须注明其为模型内结果，不得读作现实系统的判定。

一、目的

本组自立以来，一个反复出现的问题是：诸式所立的判据能否真被计算。《喑显数理式》列有一长串「必须实例化但不属于本篇 H 的参数」，这些不落地，《喑显判定式》的 Dec\_SM 无从算起。故本组现阶段只能排除，不能认证。

本次实测取一最小可实现模型，把 Gate、成迹等价 ∼\_ε、定局判据、普通扰动类与合法 B 条件域具体化，检验三件：

其一，M\_ε 能否真算出 1、0、⊥ 三值。  
其二，《喑显一般式》第五至第九节所排除的五类伪替代物，在该模型内是否确实判 M\_ε = 0。  
其三，《喑显构造式》第三节的构造程序，在该模型上是否可执行。

二、模型

状态空间。状态记 s = (x, z, a)：

x ∈ {0,1,2}：内容 r 的成迹强度。0 为未实入，1 为已实入而未定局，2 为已定局。  
z ∈ {0,1,2}：当前成迹组织标识。0 为无组织，1 与 2 为两个不同的组织。  
a ∈ {0,1}：自动复调计数。0 为复调未完成，1 为已完成。

状态空间大小 \|S\| = 18。

合法 B 条件域。𝓑\_adm = {0, 1, 2}，其中 0 为无内源作用，1 与 2 为两个不同的合法内源条件。\|𝓑\_adm\| = 3，条件对总数 3。

Gate。P\_ε = 1 当且仅当 x ≥ 1。

动力 Φ。x = 0 时不发生任何转移。x ≥ 1 且 a = 0 时为成迹进行中，此刻 b 决定 z，随后 a 置 1 进入定局。a = 1 后 z 不再改变。

成迹等价 ∼\_ε。实例化为读数映射取值相同：Γ₁ ∼\_ε Γ₂ 当且仅当二者定局态的 z 相同。此为《喑显数理式》第八节所称「最常见的合法实例化方式」。

定局判据。轨迹定局当且仅当末态满足 x = 2 且 a = 1。

M\_ε 判定。P\_ε = 0 时输出 ⊥（M 的定义域未成立）；\|𝓑\_adm\| \< 2 时输出 ⊥；事件未定局时输出 ⊥；否则比较各 b 下的读数，取值有异则输出 1，全同则输出 0。

转移全定义：18 状态 × 3 条件共 54 次调用，无未定义处。

模型二·多步复调。上述模型一步定局，成迹进行中与复调之间无时间跨度，不足以检验涉及复调过程的条款。故另设模型二：状态记 (x, z, k)，k 为复调轮次，须满 K = 3 轮方定局。首轮由 b 决定 z，其后各轮为复调，定局判据为 k = K 且 x = 2。模型三·诸量皆活。审稿中查出模型一之伪二、伪三、伪四所用的辅助量（记忆位 m、行为 act、旁路量 w）皆为只写不读的死变量——它们不参与任何转移，故判 0 是必然的，与「不落在成迹上」无关。此如证明一个不在电路里的灯泡不发光。故另设模型三：m 被复调读取（w 之演化依赖它）、w 影响 act、act 在定局后发生，三者皆真参与转移，而 z 不受其影响。模型三用于伪二、伪三、伪四之重验。

模型四·真反馈环。同理，模型一之「反馈环」实不成环——a 由 0 置 1 后不回授影响 z。故另设模型四：z 累加入经验量 e，e 达阈值后回授翻转 z，构成真闭环。模型四用于伪一之重验，并由此挖出第六节第五项所记之发现。

模型二用于伪五之检验与定局时机敏感性；其余各项皆在模型一内进行。

三、检验一：三值机制

结果如下。

真后命，b 参与成迹：M\_ε = 1。  
常映射，b 不参与成迹：M\_ε = 0。  
r 未实入，P\_ε = 0：M\_ε = ⊥。  
𝓑\_adm 只含一个条件：M\_ε = ⊥。  
事件未定局（运行步数不足）：M\_ε = ⊥。

三值皆真算得出，无一情形落入未定义。

定局时机的敏感性另在模型二内检验。取 T 为运行步数，K = 3 为复调轮数：T = 1、2、3 时皆判 ⊥（复调未跑完），T = 4 方判 1。《喑显数理式》第二十一节击穿条件第五项「只比较 B 作用后的第一次 E 微扰，不运行完整自动复调到事件定局」，于此有了可见的形式——首轮即比较者得 1 而实应为 ⊥，或在伪五模型中首轮即比较者得 1 而实应为 0。

四、检验二：五类伪替代物

《喑显一般式》第五至第九节逐层排除五类。本次在模型内逐一构造，结果如下。

伪一·有反馈。在模型四内检验。z 累加入经验量 e，e 达阈值后回授翻转 z，构成真闭环；b 不参与成迹时，三个 b 的轨迹完全相同，读数皆为 2。M\_ε = 0。环确实在跑——z 值在轨迹中确有变化（1→1→1→2），只是不因 b 而异。

伪二、伪三、伪四·合并在模型三内检验。该模型中记忆位 m 由 b 写入且被复调读取（w 之演化依赖它），旁路量 w 影响行为 act，act 在定局后由 m 与 w 决定。三个 b 下末态分别为 m = 0/1/2、w = 0/2/2、act = 0/102/202——三量皆因 b 而异，且皆真参与转移，非死变量。而成迹组织 z 皆为 1。M\_ε = 0。

此三类原在模型一内检验，审稿中查出该模型的 m、act、w 皆只写不读，不参与任何转移，故判 0 与「不落在成迹上」无关，检验为虚。已改在模型三内重验。

伪五·瞬时差异被吸收。此项在模型一内不足以检验——该模型一步定局，「瞬时」与「定局后」之间无时间跨度，所谓吸收是硬写的，看不见过程。故改在模型二（K = 3 多步复调）内检验。

b = 2 之轨迹为：(1,0,0) → (1,2,1) → (1,1,2) → (1,1,3) → (2,1,3)。即首轮 b 确实造成 z = 2，第二轮被复调拉回 1，至定局时读数与 b = 0、b = 1 无异。M\_ε = 0。

差异确曾出现，而未扛过复调——此即该类之实义。在模型一内此过程不可见，本次改在模型二内检验，方为实检。

对照·真后命：M\_ε = 1。

五类全判 0，对照判 1。

此结果的分量在于旁证一栏。伪二、伪三、伪四中，内部状态 m、行为 action、旁路量 w 在不同 b 下取值确实不同——差异实实在在存在，只是不落在成迹上。「控制权不等于成迹权」在此取得了机器可判的形式：不是「看起来不像」，而是读数相同。

五、检验三：构造程序

《喑显构造式》第三节要求具体模型先声明 𝓑\_adm 上的可枚举序 σ 与终止界 N，据以生成有序候选对列表 L\_cand，其后按序推进。本次取 σ(i) = \[0,1,2\]\[i mod 3\]。

用例一，N = 3，覆盖全域，正常模型。程序先取 (0,1)，因二者读数皆为 1 而划去；再取 (0,2)，读数分别为 1 与 2，相异，且各支在普通扰动下稳定，通过。输出 Constructed = 1，构造对为 (0,2)。

用例二，N = 2，只覆盖 {0,1}。L\_cand 只含 (0,1)，因读数相同划去。输出 Constructed = ⊥。

用例三，N = 3，常映射模型。三对皆因读数相同划去。输出 Constructed = ⊥；须另证 𝓑\_adm 有限且 N 覆盖其全部成员，方得改判 Constructed = 0。

程序可执行，按序推进而不回溯。

用例二尤须记。若按该篇初稿的写法——失败时「回到第二步另取」，判据为「若 𝓑\_adm 中所有合法对皆失败则输出 0」——此格将输出 0，而模型内实际存在构造对 (0,2)。这是一个错判。该篇改稿时是从「程序不可执行」的角度改的，未料它同时挡住了一个实际的误判。此为构造式 v1.0 撰写中所改一项的实证支持。

六、挖掘所得：一处现行条款挡不住的假阳性

前三项检验皆为正面结果。本节所记为反面结果，是本次实测最要紧的所得。

其一，M\_ε 完全悬于 ∼\_ε 的实例化。

换用不同读数映射，同一系统的判定结果如下：读组织标识 z（承重读数）得 M\_ε = 1；读成迹强度 x 得 0；读复调计数 a 得 0；读轨迹长度得 0；读常值（把一切读作同一）得 0；读全状态得 1。

也就是说，M\_ε 不是系统的性质，是系统与所声明的 ∼\_ε 二者的性质。理论对此并不隐瞒——《喑显数理式》把 ∼\_ε 列在「必须实例化但不属于本篇 H」之中——但实测使这一依赖的程度显了出来。

其二，假阴性已被现行条款挡住。

构造粗读数：把 z 读作 z mod 1（全归零）或 z \> 0（只问有无），则真后命被抹掉，M\_ε 由 1 变 0。但此类实例化违犯《喑显数理式》第八节「∼\_ε 必须商掉不改变成迹结构的微观噪声、非承重数值差和表示差」——粗到不分辨承重量者，商掉的已不止非承重量。故此类已被挡住。

其三，假阳性未被挡住。

构造如下模型：z 恒为 1，即 b 确实不参与成迹；另设状态分量 q = b × 10，即 b 确实影响 q，而 q 与成迹无关。

以 z 为读数，M\_ε = 0，此为正判。以 q 为读数，M\_ε = 1，此为假阳性。

关键在于，「∼\_ε 读 q」这一实例化不触犯现行任何一句：

满足三性——它由取值相同定义，自反、对称、传递皆成立。  
商掉了噪声——q 是确定量，无噪声可言。  
商掉了表示差——q 是状态的真实分量，非表示。  
非以待证结果定义——q 不是「是否有意识」「是否显」之类，故不触犯《喑显数理式》第二十一节击穿条件第六项。

现行条款只说了 ∼\_ε 必须商掉什么，未说不得读进什么。第六项只挡「以待证结果定义」，挡不住「以非承重量定义」。

其四，假阳性一路传导，无一环能独立发现。

在同一模型内，以 q 为读数时：M\_ε = 1；据同一读数判组织商类相异，故 LFamily = 1；据同一读数找构造对，得 (0,1)，故 Constructed = 1。三者连锁成立。

以 z 为读数时，三者分别为 0、0、⊥。

此即要害所在：M\_ε、LFamily、Constructed 三处用的是同一个 ∼\_ε。它们不是三次独立检验，是同一个读数的三次使用。故一处误实例化，会一路传到相变式的相支持判定、构造式的构造成立、可达式的准入开启，而中间没有任何一环能独立发现它。

其五，判定亦悬于定局时刻，此为比 ∼\_ε 更隐蔽的一处依赖。

在模型四内，b 确实参与首轮成迹（b = 2 使 z 首轮取 2），此非伪替代物。然闭环之后续演化，或保留该差异、或抹去之。改变 Stop\_form 所定的复调轮数 K，同一系统、同一 b，判定如下：K = 1 判 1、K = 2 判 1、K = 3 判 0、K = 4 判 0、K = 5 判 0、K = 6 判 0。

也就是说，一个真实的后命，可以因定局定得晚而被判为 0。这不是伪替代物被正确排除，是真后命被闭环吸收。

《喑显数理式》第二十一节击穿条件第五项禁「只比较 B 作用后的第一次 E 微扰，不运行完整自动复调到事件定局」——该条防的是定局定得太早。本项所示为反向的风险：定局定得晚，真后命亦可被抹去。而 Stop\_form 与 ∼\_ε 同列于「必须实例化而不属本篇 H」，理论对其取值亦无约束。

故 M\_ε 之判定悬于两处实例化，非一处：∼\_ε 读什么，Stop\_form 停在哪。

七、由此提出的修订建议

本件不改任何式文。以下三项为建议，须走各篇的升版程序。

建议一，《喑显数理式》第八节增一句正向约束：∼\_ε 只得读取成迹承重量，即在本模型声明中承担成迹组织身份的那些量；状态中不承担成迹组织身份的分量，无论其是否确定、是否为真实分量，皆不得进入 ∼\_ε 的判定。

此句与现行「必须商掉……」一句为一正一反：现行句说不得留下什么，新句说不得读进什么。二者缺一，则本节第三项所构造的假阳性无法被条款判违。

建议二，《喑显数理式》第二十一节击穿条件第六项扩充。现作「∼\_ε 以『是否有意识』『是否显』或其它待证结果定义」，宜增一款：或以不承担成迹组织身份的状态分量定义。

建议三，《喑显判定式》第二十八节不可判条款增一项，或于误判控制一节增一款：当 M\_ε = 1 的判定所依的 ∼\_ε 未能证明其只读承重量时，输出 ⊥ 而非 1。

此建议之要在于：现行制度把「∼\_ε 未定义充分」列为 ⊥ 的情形，但「已定义而定义得不对」不在其列。前者是缺，后者是错，错比缺更难发现——因为它给得出一个确定的答案。

建议四，《喑显数理式》第九节事件定局一节，宜加一款约束 Stop\_form 之实例化：定局规则须由结构事实定，不得由「此时比较得出何种结论」定；且若同一模型在不同合法定局规则下 M\_ε 取值不同，须报告该敏感性，不得只报其一。

此建议对应第六节第五项。现行击穿条件第五项只防定局过早，未防定局过晚，亦未防定局规则之择取本身受结论牵引。

八、本次实测的限度

其一，模型极小。18 状态、3 个 B 条件、单 r、单通道、确定性动力。它足以检验判据是否可算、伪替代物是否被排除，不足以检验任何涉及随机、连续、多内容或大规模的条款。《喑显必然式》的随机层级、《喑显可达式》的随机三值聚合、《喑显分级式》的五维画像，本次皆未触及。

其二，五类伪替代物的构造是本件作者所为。它们符合《喑显一般式》各节的描述，但一个模型内的构造不等于该类的全部。判 0 说明这五个具体构造被排除，不说明该类的一切成员皆被排除。

其三，本次未检验 Prot\_form 的跨协议不变性。《喑显构造式》第九步要求在协议族中另取协议重跑，本模型只声明了一个协议，故该步未实检。此为构造式最要紧的一道关，未验。

其四，本模型不对应任何现实系统。它是形式对象，用以检验判据的可算性，不用以判定任何实际系统是否显化。

其五，代码由本件作者一人所写并自检，未经外部复核。

其六之前，另记一事：本次审稿共查出模型结构不足三处——模型一无多步复调（伪五检验为虚）、模型一之辅助量皆死变量（伪二三四检验为虚）、模型一之「反馈环」实不成环（伪一检验为虚）。五类之中四类的初次检验皆不成立，皆经另设模型二、三、四方得实检。此事之提示见下条。

其六，模型一步定局，故涉及复调过程的条款在其内不可检验。本次为此另设模型二。审稿中查出此事：初稿以模型一检验伪五，而该模型内的「吸收」是硬写的，不是复调所致，检验为虚。已改在模型二内重验。此事提示：模型之最小化有其代价，某些条款须待模型具备相应结构方能检验；不可因模型跑通而以为条款皆已受检。

十、一句话

判据可以算，五类伪替代物确实被排除，构造程序确实可执行；但判定的分量不在判据本身，而在 ∼\_ε 读什么——而这一处，现行条款只管住了一半。
