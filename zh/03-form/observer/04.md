# 观者构造式

本篇试论一个总命题：检验《观者数理式》的原始对象、组织关系与运行规则中，哪些已能由自显场经明示构造程序建成，哪些仅有条件构造、候选实现或待桥接，并据此划定其来源边界。逐项如实分级（已构造／条件构造／候选定义或候选实现／待桥接／有意收缩／外来），不以降格保全升级、不以升格掩盖降级；全称立行住判词依分级结果定，不预设。

我们要在本篇，在不断追问下找到证明应当走向何处，并给出观者数理式诸原始项在自显场中的构造程序与来源分级。

那么，我们先给出结果。（以下为全文完成后据实回置篇首的阅读组织，只预告结果，不作为后续推导的前提。）

构造总表（预告）：数理式原始项十六类——已构造五、条件构造三、候选定义与候选实现七、待桥接一；有意收缩零；现阶段无已确认外来项（已申报假设之外来性依 H6、H7、H8、H13 裁）。二类附增益。正式裁定表于末节。

一句话：观者数理式的原始对象在场里多数有来源——五件无条件建成，三件带前件建成，七件在候选层，一件待桥；已确认外来件，现无。

摘要

本篇执行生长验证：自下而上，从场基底词汇（续延势、协调压缩、续行代价、沁叠、调谐负载、可分阈、界门、过门、显现回路、对齐、成一、重续）出发，逐项构造《观者数理式》的原始对象（候选与进度、动力方程、交叠、容量、复合分辨率、有效耦合、许可关系域、三义务承担判据、构形链、承接族、载体、当前事实对应），并对每项作三重交付：场词汇定义、性质证明、与数理式原定义的一致性核对；交付分级依层级传导表六类制（已构造／条件构造／候选实现／待桥接／有意收缩／外来），条件与前件显式随行。四判据先立为击穿结构。方向纪律：不采自上而下的解释映射。

引言

《观者一般式》证明了当前事实之下三项义务必然（F、I、M）；《观者数理式》把义务写成了闭合形式系统。但形式系统可以有两种身世：由对象自身的结构生长而出，或作为外来形式罩在对象上仅在输入输出层拟合——后者即功能模拟，无论拟合多好，其原始项在理论内部无根。判别两种身世只有一法：逐项索要构造程序。本篇即做此事。材料纪律：只取自《自显场结构与动力总卡》v0.2 所录、经直读或注明转引的场篇、内篇、外篇文本。

一、生长判据（击穿结构，先于构造立定）

判据一·原始项对账：数理式任一原始项无场基底构造程序，该项判外来。  
判据二·组织关系对账：数理式对象间组织须与场篇组织同构或由之派生；强加分划判失败。  
判据三·动力对账：数理式运转规则须为场动力方程的限制、粗化或复合，逐规则给出导出关系；仅输入输出拟合者判功能模拟。  
判据四·无剩余反向检验：场侧关键结构凡在数理式系统性无对应者，须申明有意收缩并给理由，否则记不完备。  
四判据即本式的击穿方式：任一判据被击穿，相应裁定改判，总判随动。

三、构造程序

每项三重交付：〔构〕场词汇定义；〔证〕性质证明；〔核〕与数理式原定义的一致性。构造顺序即依赖顺序，不可调序。

构造一·时间域与维持窗  
〔构〕T := 场动力时间参数域；I\_t := \[t−Δ\_maint, t\]，Δ\_maint 取任一满足 ReCont 判定前件的正持续窗（场二十条件四）。〔证〕T 全序继承实数序；持续判定非瞬时判定，故窗须正长度——最小正窗之存在不由“持续”推出，若须最小窗，其存在性为宿体正则性前件（联判定-H1甲类）。〔核〕数理式定义1–3 只要求 T 全序、维持窗非零——满足。

构造二·有限容量工作域  
〔构〕Φ\_cap 工作域 := 场配置集 {L(t) ≤ Cap}；Cap\_Φ(τ) := Cap(τ)。〔证〕Cap 为场九所立之调谐容积上限，L 为维持活跃边界之调谐资源量（场九 v1.2），故工作域以 L ≤ Cap 界定。原引「场九定理六路径」撤回：该定理现为示范模型内之边界密度有界定理，不给出 L 超出 Cap 时之崩散结论。〔核〕数理式定义5、定义80 之容量函数——同一量，注源即闭。

构造三·候选与进度  
〔构〕候选 c := 一股已进入调谐的续延势 V\_c 连同其收束进程（内篇“已进入调谐、朝完成推进的结构进程”之场对应）；完成基准改立为成立域：𝒞\_c := V\_c 稳定复走之成立域，稳定复走依场篇第一 v2.7 定义12 判定，为申报窗口 W 内之历史资格 Ω\_W（由 Pass\_W、各子段复走事件与 Brk\_W 判定）；协调压缩 Ω\_c、续行代价 𝒵、历史沉积、持续时间与调谐配置为其相关条件，不替代 Ω\_W 之判定；熟径不由 Ω\_c 判定（场篇第一定义13；场四 v1.2）；Comp\_t(c) := 运行状态入 𝒞\_c。条件化压缩（前件 H8）：在固定工作域内若 𝒞\_c 可压缩为单一压缩水平 Ω\*\_c，则进度 z\_c(τ) := min(Ω\_c(q\_c,τ)/Ω\*\_c, 1) 为条件化近似；压缩性未证之域不用阈值式。资源份额 x\_c := L\_c(τ)/Cap(τ)——H 条件量（前件 H7）：其成立须负载归属分摊算子，处理共享负载 L\_overlap、多义务重叠与剩余 L\_res 之记账；场九只给总量 L(τ)，逐候选可分离之 L\_c 非其直接产物。无重叠无剩余之特殊域内方退化为简单分解 L=Σ\_c L\_c+Σ\_q L\_q。Act\_t(c) := 窗内 V\_c 续行流非零；Comp\_t(c) 之阈值读法（条件化）：压缩前件下 Comp\_t(c) ⟺ z\_c=1。  
〔证〕z\_c∈\[0,1\] 由定义；单阈值双向等价（z=1⟺Ω≥Ω\*⟺稳定复走）撤销——现立为：Comp 由成立域 𝒞\_c 陈述，阈值读法仅在压缩前件下成立。“候选达到自身完成条件”仍由场量陈述，不引显现词汇。〔核〕数理式候选层四谓词逐项对应；且“完成不等于当前”在场侧自动成立：Comp（入 𝒞\_c）只说路径稳定复走成立，不说过门、不说结于观界——分层是场结构自带的，不是数理式外加的。

构造四·候选动力方程（动力对账第一格）  
〔构〕下列候选动力式作为待验证的闭合模型提出，不称为已由场四示范方程导出。场四方程（场四 v1.2：二式为示范模型 M1–M3，非定理；μ𝒵/Ω\_c 不承担 Eλ）支持协调压缩与续行代价之间的示范动力关系，但尚未给出资源份额耦合、负自身反馈及目标系数的完整导出：在正参数工作域内，f(Ω,𝒵) = α·Ω/𝒵 − μ·𝒵/Ω 对本候选自身 Ω 之偏导为 α/𝒵 + μ·𝒵/Ω² \> 0（下列 𝒵\_c 分解不含本候选自身之 Ω），故其自身偏差之一阶项为正，不能展开为 −η\_c·z\_c；负的函数项不等于负的线性化系数；原式亦无资源份额 x\_c，不能导出 r\_c·x\_c。候选竞争代价分解（申明为假设，非导出）：𝒵\_c = 𝒵\_0 + κ·Σ\_{c′≠c} Itr(V\_c,V\_c′)·z\_{c′}。场义依据（场四 v1.2「续行代价……是多续行竞争下的协调成本」；“沁叠成续延压”）只支持竞争与沁叠影响续行代价，不给出加法形、线性性、可求和性与 κ 恒定——此四者为假设之条件组（H6）：竞争贡献可加、Itr·z 局部线性、高阶与饱和项在工作域内可忽略、κ 在工作域内稳定。提出候选式：  
ż\_c ≈ r\_c·x\_c − χ·Σ\_{c′≠c} Itr(V\_c,V\_c′)·z\_{c′} − η\_c·z\_c + ξ\_c  
其中 r\_c 为资源份额增益系数，η\_c 为候选退散系数，χ 为串扰系数，ξ\_c 为边沁涨落与外入扰动项；各系数之场义来源与推导未给（H6）；区间投影 Π\_\[0,1\] 由 z 之定义域强制。  
〔证〕地位：候选动力模型——待验证之闭合模型，不称限制，亦不称条件粗化；其与场四示范方程之映射缺口（负自身反馈、资源份额耦合、目标系数之推导）登记于 H6。〔核〕与数理式候选动力形在形式上一致；Eλ、场四示范模型的 μ𝒵/Ω\_c 项与耗散量 Ξ₀ 分属不同定义及模型位置，本篇未建立三者的实现对应或等价关系；候选动力式中的退散项须独立申报其来源与适用条件。附：双完成对称轨道（r=4、η=1、χ=1、Ovl=1、x=1/2）为候选模型内之核对——在该模型内可读为两股等强续延势均分调谐份额而各自达到完成；此核对只在候选模型内成立，不能反过来证明场侧构造成立。

构造五·交叠（附生长增益一）  
〔构〕Ovl(c,c′) := Itr(V\_c,V\_c′,t)，即二者沉积结构交叠匹配度 M(x,t) 的域层积分（场十四第4节）。〔证〕对称、非负、受 Λ 约束——数理式对 Ovl 的全部使用性质成立。〔核〕一致。增益：Itr 自有动力 dItr\_f/dt ∝ Coact+Infilt+Reentry−Sep——构造所得的 Ovl 是动态量，数理式取其为常参数只是冻结近似；构造版给出交叠的时间演化与裂解恢复，为原式所未含。

构造六·复合分辨率（附生长增益二）  
〔构〕Composite(H) := ∃ s\_i,s\_j∈成分(H)，d(s\_i,s\_j) \> θ\_sep(t)。〔证〕θ\_sep 有下限 θ\_min、有漂移动力（场九）——谓词良定义且随场状态演化。〔核〕数理式“工作分辨率下可再分”由声明制升为场判据制；单成分之“不可再分”即一切成分对 d≤θ\_sep。增益：θ\_sep 升至超过成分间差异度时，Composite 可由 1 变 0（判据层；分辨塌缩依场九 v1.2 以长期可分集界定，并入共核另依结构认证）——复合性之动态化为原式所无。

构造七·有效耦合  
〔构〕三谓词分立（现实／模态／反事实各归其位，不混于一谓词）：ActualCircuit(c,R,I\_t) := R 为窗内实际成立之回路关系且对 V\_c 双向 Cpl∧Press 实际非零——归 R₀(I\_t)；PossibleCircuit(c,R,I\_t) := 上述条件在当前参数与可实现分配集 𝒜(I\_t) 下可成立（模态）——归 Eligible 之可满足性；InterventionSensitive(c,R,I\_t) := 经 Press 通路之许可干预（干预域 𝒟 待判定式测量层定义）能改变 c 之 Gate／Pass 结果（反事实）——归操作层。数理式 EffectiveCouple 之场构造 := ActualCircuit ∧ InterventionSensitive，其中 InterventionSensitive 在本篇为级一理论谓词，其操作判定归判定式。〔证〕“两个自动控制器互馈”被 Press 条款排除（场二十定理二）。〔核〕数理式定义50 三款分别由三谓词承接；混合谓词撤销。

五、主任务二：三义务承担判据的非循环化

禁行申明：下列判据全部以 Gate、Pass、Align、成一、ReCont、复用流贡献等独立场谓词写成；“能承担 X 者”不出现在 X 判据的定义位。

结语

数理式的多数原始对象已有场层构造或候选来源：交叠生于沁叠，容量总层生于调谐负载，构定条件生于界门，动力以候选模型提出，与场式之映射待闭（H6）；其余依条件定义与桥接开放。未申报外来项，零。

再压成一句：数理式的骨多数长自场中——余下的，条件在案，桥在路上。
