# 域数学

第1节 目的

《场数理式》（场篇第一 v2.7）已经说明：

迹应如何在沉积场中形成沟线、熟径、共核与闭包。

具体而言，场篇第一建立了以下生成链：  
π → τ → Γ → H → ℬ → 𝒟（沟线、端壑起即有深浅 δ 与阈 θ）

注：场篇第一 v2.7 中，Ω\_W 与 κ 不在此链末端顺次生成，而是导出量：Ω\_W 由申报窗口 W 内的复走记录与沟连接完整性记录导出，是取 0 或 1 的历史资格谓词（定义12）；κ 由 δ、θ 与续行结构 S 导出（定义11、方程3a）。本篇凡引 Ω、κ 处，均按此理解。

本篇在此生成链已成立的前提下，进一步讨论域的动力学。本篇不重复场篇第一的底层生成过程，而直接从域出发，追问域为何能够长期稳定、退散与重组。

但仅有场篇第一的内容，仍不足以解释：

为何场不会始终散乱流动。

为何会出现：

• 稳定记忆  
• 概念结构  
• 情绪稳定态  
• 长期人格  
• 联想网络  
• Recognition-Realm

因此：

本篇不再讨论单条迹应。

而开始讨论：

局部稳定续行结构。

即：

域。

域不是集合。不是区域划分。不是观察者命名。

域是：沉积场中长期聚流后形成的稳定续行结构。其形成须满足场篇第一定义8所列五项条件（见下）。

域：局部稳定续行。

本篇进一步讨论：

• 域如何形成  
• 域如何维持  
• 域如何锁定  
• 域如何同步  
• 域如何碎裂  
• Recognition-Realm 如何形成

并尝试将：

记忆、人格、情绪、现实连续感，

统一为：

沉积场中的域动力学。

注：本篇把记忆、人格、情绪、联想、现实连续感等对应到域动力学，是释义性对应（现实适用主张），须经验验证，不由本篇各式推出。

注：Recognition-Realm（识界）指沉积场经息化后形成的大型同步稳定结构，是观察者得以在其中生成识出的域网络结构。其生成机制在本篇第12节展开，完整定义见主书息化相关篇章。

第2节 核心动力

域数学中的高层结构，最终可约化为：

• InFlow  
• MaintainFlow  
• CohereFlow  
• Lock  
• Sync  
• DecayRate  
• FragmentRate

之间的稳定组合。

定义1：InFlow  
记：InFlow(𝒟)  
表示外部脉冲持续趋入某域的输入流。  
InFlow 决定：  
• 域是否形成  
• 域是否积深  
• 域是否扩张

定义2：MaintainFlow  
记：MaintainFlow(𝒟)  
表示维持域内部稳定续行所需的持续流。  
MaintainFlow 决定：  
• 域是否维持  
• 域能否抵偿退浅与域漏（见第3节域形成条件）  
• 域界是否稳定

定义3：CohereFlow  
记：CohereFlow(𝒟)  
表示维持跨域同步所需的凝聚流。  
CohereFlow 决定：  
• 跨域同步规模  
• 联想稳定性  
• Recognition-Realm 连续性

定义4：Lock  
记：Lock(𝒟)  
表示历史层积对当前聚流的持续偏置。  
Lock 不是记忆保存。而是：历史结构对当前聚流的约束延续。  
注：Lock 与场篇第一的 Ω\_W（稳定复走能力）不同。Ω\_W 是某路径在申报窗口 W 内已表现出稳定复走的历史资格谓词（取 0 或 1，由复走记录、各子段复走事件与沟连接完整性导出，场篇第一定义12），属路径层；Lock 是历史层积对域内当前聚流方向的整体偏置，是域层的程度量。Lock 的基础是沉积差（δ 的历史层积，见第4节），不以 Ω\_W=1 为前提；本篇亦不断言 Ω\_W=1 推出 Lock\>0。复走产生加深作用（Dτ\>0），可经沉积度参与 Lock 的形成。

注：Lock 与偏置。Lock 的成立面依式篇第二十 v1.2 续行偏置 B（对沉积差的依赖）：以域内申报的比较任务 T\_𝒟 判定 B\_m(T\_𝒟)；B 不成立则 Lock = 0，B 未定义则 Lock 未定义（见 Lock 形成方程）。其强度面由示范式给出（历史层积 × 维持流），不是 B 的效应量，故 Lock 不称 B 的程度化。逻辑方向：B\_m(T\_𝒟) 为假 ⇒ Lock = 0；故 Lock \> 0 ⇒ B\_m(T\_𝒟) 为真。反之不成立：B 为真而 HistLayer 或 MaintainFlow 为 0 时 Lock = 0，因此 Lock = 0 不推出 B 为假。见证（式篇第二十）：深路受阻时，沉积差存在，HistLayer 与 MaintainFlow 都可为正，但 B 不成立，此时 Lock = 0。Lock \> 0 亦不推出 Bias：Bias 须在长时间窗上满足场篇第一方程11 的 (4a)(4b)。式篇第二十 v1.2 定义十注所称 Lock 与续行绑定 S 的功能对应，按本版 Lock 的界定尚未重新核验，本篇不承接，登记为待证。

定义5：Sync  
记：Sync(𝒟₁,𝒟₂)  
表示多个域之间：续行节律能够长期稳定互返的程度。

定义6：DecayRate  
记：DecayRate(𝒟)  
表示域内部历史续行结构的自然退散趋势。  
DecayRate 不是历史消失。它是域内历史层积的退浅速率；Lock 对当前聚流的束定因之下降，是其作用，不写入其定义。  
注：DecayRate 对应场篇第一中场质（λ）对沉积度（δ）的退浅效应。场质 λ 决定退浅之速，DecayRate 是 λ 在域层面的表现。

定义7：FragmentRate  
记：FragmentRate(𝒟)  
表示域同步结构中的碎裂率。  
FragmentRate 越高：跨域同步越难维持。

元说明：动力约化关系  
高层认知结构，最终都可视为 InFlow、MaintainFlow、CohereFlow、Lock、Sync、DecayRate、FragmentRate 之间的稳定组合。这不是可验证的场行为定律，而是本篇展开域数学的元结构原则。

注（各式与定律的类别）：本篇各式——域形成条件、历史层积方程、Lock 形成方程、主核形成方程、域桥方程、同步方程、FragmentRate 来源方程、时间尺度方程、冲突方程、相变条件、情绪方程、资源方程、失败条件方程、连续性方程——均为示范模型（模型假设）：给出方向与组合形式，内外篇原文不足以推出其精确形式；比例常数、量纲、取值范围与测定协议须由具体场申报。相位差方程是记法定义。依这些式所作的极限讨论（如「有限饱和」）只在示范式内成立。定律1–21是域层的方向性陈述，除定律3 的先后内容承接场篇第一定律5 外，均为本篇模型层的申报，不是由场篇第一推出的定理。命题一、命题二在示范式内严格成立。

注（量纲约定 U）：本篇示范式取固定步长 Δt = 1。HistLayer、τ 计层积量；Leak、MaintainFlow、CohereFlow、LockMaintenance 计每步流量，并约定一单位流量在一步内对应一单位层积量（换算系数 c\_H = 1）。据此，DecayRate × HistLayer（一步内退散的层积量）可换为流量当量，与 Leak、MaintainFlow 相加比较。具体场的步长或换算不同时，须申报 c\_H，先换算再比较。Lock、Sync、BridgeStr、FragmentRate、RhythmFlow 及各归一读数为无量纲量（Lock 的量纲由比例常数 c\_L 吸收）。CohereFlow 有两种读数：原始流量 CohereFlow，用于资源方程；归一读数 CohereFlow\_N = CohereFlow / Rcap(F)（须 Rcap(F) \> 0），用于域桥方程。二者不可混用。

动力底层约化注：  
上述七项高层动力，与场篇第一的底层变量存在以下对应关系：  
InFlow 对应脉冲（π）持续趋入，与续行势（κ，导出量）和流压（φ）相关——κ 决定能否趋入，φ 决定趋入后如何续出（场篇第一定义17）。  
MaintainFlow 对应维持稳定续行，与沉积度（δ）和稳定复走能力（Ω\_W）相关——δ 提供趋入基础；Ω\_W 记录 W 内是否已表现出稳定复走，是历史资格谓词，不是维持流的来源。  
DecayRate 对应场质（λ）对 δ 的退浅效应，见场篇第一方程2 的 Eλ 项。  
Lock 对应沉积差对后流的偏置作用：比较条件 C₌ 下，深者不后于浅者满足出流条件；在 C₌ 与 P₁₇ 下严格先（场篇第一定律5、定理17）；在长时间窗上稳定成立者为 Bias（方程11）。κ 为导出量，不另作中介。  
CohereFlow 对应跨域续行结构（域桥）的维持流，与扩展续行（Extend）相关，见场篇第一运算25。  
Sync 对应多域之间续行节律的稳定互返，与共核（Core）形成机制相关，见场篇第一方程7。  
FragmentRate 对应续行结构断裂率，与 S(x) 断裂条件相关，见场篇第一定义14。

第3节 域形成

脉冲长期 InFlow 后：局部续势提高。

局部续势长期高于外围后：后续聚流更容易重复趋入。

于是：稳定续行形成。

注：续势即续行势 κ，为导出量（场篇第一定义11、方程3a）：比较条件相同时 κ 不逆 δ 序。「更容易重复趋入」的先后内容承接场篇第一定律5（C₌ 下不后于，C₌ 与 P₁₇ 下严格先）；聚流量或份额更多，须另证。

定义8：域核  
记：DCore(𝒟)  
表示域中的主聚流中心。  
域核不是单点。而是：局部续势最高的稳定聚流结构。  
注：DCore(𝒟) 与场篇第一中的共核 Core(x₁,x₂,…) 不同。Core 是多个结构长期共同迹应形成的跨结构共同稳定聚流中心；DCore 是单个域内部续势最高的聚流核心。两者均为”核”，但层次不同：Core 是跨域/跨结构层次，DCore 是单域内部层次。

定义9：域界  
记：∂𝒟  
表示域内部与外部续势发生明显衰减的位置。  
域界不是几何边界。而是：续势断层。

定义10：域压  
记：Pr(𝒟)  
表示域内部聚流对域界的持续冲积强度。

注：Pr(𝒟) 与式篇第二十的 Pr(q,t)（续行份额读数）同字异义，以自变量区分。

定义10a：域漏  
记：Leak(𝒟)  
表示域内聚流因域界渗漏而损失的流量。  
域漏不是退浅，不是 DecayRate。退浅是沉积度因场质下降；域漏是域界未能完全束住流量时的外溢损耗。  
Leak(𝒟) 越大，域界越不稳定，域越难维持。Bind(∂𝒟) 增强时，Leak(𝒟) 减小。

域形成条件（示范模型）：  
若：Leak(𝒟) + DecayRate(𝒟) × HistLayer(𝒟) \< MaintainFlow(𝒟)  
长期成立，则：稳定续行得以维持（示范模型的动力条件）。𝒟 是否成立，仍依下述五项条件（场篇第一定义8）认证。

注：DecayRate(𝒟) 为无量纲退散率，DecayRate × HistLayer 为一步内退散的层积量；按量纲约定 U（第2节注）换为流量当量后，与 Leak、MaintainFlow 同单位比较。

域定义（与场篇第一对齐）：  
域是线束中能够稳定维持以下五项条件的局部稳定续行结构：  
容与（Cnv(𝒟)\>0）、分辨、差分积深、续行、束界。  
上述聚流动力学条件（InFlow、MaintainFlow、DecayRate）是域五项条件得以成立的动力来源，而非域定义的替代。  
注：外篇第三（数论）原表述”任取线束之一段即为域”已在场篇第一定义8中作严谨性修订（v2.7 仍为定义8）。本篇采用场篇第一的精确版本。

注：域满（Full(𝒟)=1）表示域内稳定继续形成新差分之条件达到限制（场篇第一方程9）。此时上述形成条件只说明已有结构能否维持，不再说明新差分能否在域内形成。若新增迹应继续进入且不可继续内沉，则边沁成立（场篇第一方程10、定义21），沿域边界生成新结构位。

定律1：聚流成域定律  
长期 InFlow 后：局部稳定续行可以形成；满足场篇第一定义8五项条件者，域成立（并见定律2）。

定律2：高流无 Lock 失败定律  
即使存在持续 InFlow，若历史层积无法形成 Lock，则：稳定域仍无法成立。

注：定律2 限定定律1——InFlow 是稳定成域的必要动力来源，但不充分。Lock 是共同所需的条件：历史层积若未形成对当前聚流的偏置，即使输入持续，聚流也不能稳定为持久的域。

记忆：历史层积后的 Lock 稳定态。

第4节 历史层积与 Lock

沉积场中的历史，不会彻底消失。

新迹应不会覆盖旧迹应。而会：层积其上。

定义11：历史层积  
记：HistLayer(𝒟)（域层；全场记 HistLayer(F)）  
表示沉积场中的历史叠层结构。

历史层积方程（示范模型）：  
HistLayerₜ₊₁ ＝ max(0, HistLayerₜ + τₜ − DecayRate(𝒟)ₜ × HistLayerₜ)  
注：DecayRate(𝒟) 是退散速率（无量纲比率），乘以当前历史层积量后得到当前时刻的实际退散量。max(0,…) 保证历史层积不为负——极端退散条件下历史层积趋向零而非负值，符合沉积场的物理约束。

注：此式与场篇第一方程2（δₜ₊₁=δₜ+Dτₜ−Eλₜ）同为加减记账：τₜ 在此记本拍迹应造成的域层积深量（方程2 中 Dτ 在域内的汇总），DecayRate×HistLayer 对应 Eλ；退浅与当前层积量成比例，是示范模型的假设。HistLayer 由各结构位 δ 汇总的方法，本篇未给，具体场须申报。

命题一（历史层积的界）：设 HistLayer₀ ≥ 0，且对一切 t 有 τₜ ≥ 0。(a) 若对一切 t 有 r ≤ DecayRateₜ ≤ 1（r \> 0）且 τₜ ≤ τ\_max，则对一切 t，HistLayerₜ ≤ M，M = max(HistLayer₀, τ\_max/r)。(b) 若对一切 t 有 DecayRateₜ ≤ d \< 1，则 HistLayerₜ \> 0 推出 HistLayerₜ₊₁ \> 0：历史层积不在有限步内退尽。(c) 若对一切 t 有 DecayRateₜ = 0 且 τₜ ≥ τ\_min \> 0，则 HistLayerₜ ≥ HistLayer₀ + t·τ\_min，无界。(d) 若对一切 t 有 τₜ = 0 且 0 ≤ DecayRateₜ \< 1，则 HistLayerₜ = HistLayer₀ · Πₛ₌₀^{t−1}(1 − DecayRateₛ)；HistLayer₀ \> 0 时，HistLayerₜ → 0 当且仅当 Σₛ DecayRateₛ = ∞。特例：DecayRate 恒为 d ∈ (0,1) 时 HistLayerₜ = (1 − d)^t · HistLayer₀，几何趋零；DecayRate 恒为 0 时 HistLayer 保持不变。

证明：(a) 对 t 归纳。HistLayer₀ ≤ M。设 0 ≤ HistLayerₜ ≤ M。因 r ≤ DecayRateₜ ≤ 1，0 ≤ (1 − DecayRateₜ)·HistLayerₜ ≤ (1 − r)·M，故 HistLayerₜ₊₁ ≤ (1 − r)·M + τ\_max ≤ (1 − r)·M + r·M = M（末步用 τ\_max ≤ r·M）。(b) (1 − DecayRateₜ)·HistLayerₜ ≥ (1 − d)·HistLayerₜ \> 0，又 τₜ ≥ 0，故截断不起作用，HistLayerₜ₊₁ \> 0。(c) 截断不起作用，每拍至少增 τ\_min。(d) τₜ = 0、DecayRateₜ \< 1 时截断不起作用，乘积式由递推得出。若 Σ DecayRateₛ = ∞，由 1 − x ≤ e^{−x}，乘积 ≤ exp(−Σ DecayRateₛ) → 0。若 Σ DecayRateₛ \< ∞，则 DecayRateₛ → 0，只有有限个 s 使 DecayRateₛ \> 1/2；其余各项满足 0 ≤ x ≤ 1/2，有 1 − x ≥ e^{−2x}，其积 ≥ exp(−2Σ DecayRateₛ) \> 0；那有限个因子各自 \> 0，故乘积有正下界，不趋零。∎

注：本节首句「沉积场中的历史，不会彻底消失」，在本示范式中只对应命题一(b)：DecayRate ≤ d \< 1 时，有限步内不退尽。它不表示 HistLayer 不趋于零。无输入时：DecayRate 恒为 d ∈ (0,1)，几何趋零；一般变退散率下，趋零当且仅当累计退散发散（命题一(d)）；DecayRate 恒为 0，保持不变。完全回复之不可能，另见场篇第一定理15。

Lock 形成方程（示范模型）：  
Lock(𝒟) ＝ χ\_B(𝒟) × c\_L × HistLayer(𝒟) × MaintainFlow(𝒟) / (1 + DecayRate(𝒟))

其中：B\_m(T\_𝒟) 为真时 χ\_B(𝒟) = 1，为假时 χ\_B(𝒟) = 0；B\_m(T\_𝒟) 未定义时，Lock(𝒟) 未定义（记 ⊥）。T\_𝒟 为域内申报的比较任务（比较对象、抹平水平 m、读数判据与窗口，依式篇第二十 v1.2 第五节）。c\_L \> 0 为申报的固定比例常数。  
注：分母取 1+DecayRate(𝒟) 而非 DecayRate(𝒟)，只消除 DecayRate→0 处的奇点，不单独推出有界。推论：在命题一(a) 的条件下，若 MaintainFlow ≤ MF\_max，则 Lock ≤ c\_L · M · MF\_max（因 χ\_B ≤ 1、1 + DecayRate ≥ 1）。若 DecayRate = 0 而输入持续（命题一(c)），HistLayer 无界增长；χ\_B = 1 且 MaintainFlow 有正下界时，Lock 亦无界。

命题二（Lock 的下降条件）：设 χ\_B 在 t、t+1 两拍均为 1，Lockₜ \> 0，且 τₜ \< DecayRateₜ × HistLayerₜ，MaintainFlowₜ₊₁ ≤ MaintainFlowₜ，DecayRateₜ₊₁ ≥ DecayRateₜ。则 Lockₜ₊₁ \< Lockₜ。

证明：Lockₜ \> 0 推出 HistLayerₜ \> 0，且 aₜ = MaintainFlowₜ / (1 + DecayRateₜ) \> 0。由 τₜ \< DecayRateₜ · HistLayerₜ，HistLayerₜ + τₜ − DecayRateₜ · HistLayerₜ \< HistLayerₜ；又 HistLayerₜ \> 0，截断后仍有 HistLayerₜ₊₁ \< HistLayerₜ。由所设，aₜ₊₁ ≤ aₜ。于是 Lockₜ₊₁ = c\_L · HistLayerₜ₊₁ · aₜ₊₁ ≤ c\_L · HistLayerₜ₊₁ · aₜ \< c\_L · HistLayerₜ · aₜ = Lockₜ。∎

注：χ\_B 由 1 变 0 时，Lock 直接降为 0。历史输入足以抵偿退散（τₜ ≥ DecayRateₜ × HistLayerₜ）时，即使 MaintainFlow 很低，Lock 也可不降。例：c\_L = 1，HistLayer = 20，DecayRate = 0.5，τ = 10，MaintainFlow = 1，历史层积每拍保持 20，Lock 不变，而 MaintainFlow \< DecayRate × HistLayer 始终成立。

定律3：历史 Lock 定律  
历史层积越深：当前聚流越倾向复走旧熟径。  
注：此定律是外三（数论）「深者先得其流」在域动力学层次的展开，原文只给方向。其可证内容取先后判据：「历史层积越深」在此指所比较旧熟径的沉积度较深；比较条件 C₌ 下，较深者不后于较浅者满足出流条件，在 C₌ 与 P₁₇ 下严格先（场篇第一定律5、定理17）。熟径依场篇第一定义13（既有深积，且在申报窗口内常走）。聚流量或份额更多，不由此推出，须另证。κ 为导出量，不另作中介。

定律4：深 Lock 惯性定律  
Lock 越强：域越难重新改变。

注：外十六「深积而难改，积浅则易移」把难改归于深积（沉积度）；本定律在域层以 Lock 表述，是模型层的申报。

定律5：补给不足退 Lock 定律  
若：χ\_B 在相邻两拍均为 1，当拍 Lock \> 0，历史输入不足以抵偿退散（τ \< DecayRate × HistLayer），且 MaintainFlow 不升、DecayRate 不降，则：Lock 下降（命题二）。χ\_B 由 0 变为 1 时，Lock 可由 0 上升，不在本定律范围。

记忆偏向：长期 Lock 后的稳定复走倾向。

第5节 主核与统域

域形成初期：可能存在多个聚流中心。

长期聚流后：部分聚流中心会持续增强。于是：主核形成。

定义12：主核  
记：MainCore(𝒟)  
表示长期统摄域聚流的核心结构。  
主核不是主体。而是：长期统流中心。

主核形成方程（示范模型）：  
MainCoreᵢ(𝒟) ＝ MaintainFlowᵢ(𝒟) × Lockᵢ(𝒟) / Σⱼ(MaintainFlowⱼ(𝒟) × Lockⱼ(𝒟))  
注：Lockᵢ(𝒟)、MaintainFlowᵢ(𝒟) 记第 i 个聚流中心所承担的部分（示范记法）。定义域：分母 Σⱼ(MaintainFlowⱼ(𝒟) × Lockⱼ(𝒟)) 有限且严格为正，否则 MainCore 未定义（⊥）。归一化形式体现多核竞争——域内各聚流中心的主核强度，由其相对于全部聚流中心的比重决定。只有一个聚流中心且其权重为正时，MainCore = 1，统摄完全；若多核并立且均衡，则各核权重相近，主核统摄减弱。

定律6：主核统域定律  
主核越稳定：域内部聚流越统一。

定律7：多核层级定律  
长期稳定多核，不会总是导致域裂。  
若：主核能够统摄副核，则：层级域形成。

定律8：主核失统定律  
若：Sync ↓ 且 Lock ↓，则：MainCore 开始失统。

人格：MainCore 统摄下，由高 Lock、高跨域 Sync 长期形成的稳定统流结构。

第6节 域桥与同步

域之间，并非完全隔绝。

长期跨域续行后：域桥形成。

域桥形成后：多个域开始同步。

定义13：域桥  
记：Bridge(𝒟₁⇝𝒟₂)  
表示稳定跨域续行结构。

域桥方程（示范模型）：  
BridgeStr(𝒟₁⇝𝒟₂) ∝ CohereFlow\_N(𝒟₁) × √(Lock(𝒟₁) × Lock(𝒟₂))  
注：两侧 Lock 取几何平均，使域桥强度受两域历史稳定性共同约束：任一侧 Lock 为 0，则 BridgeStr = 0；𝒟₁ 若无历史层积，即使 CohereFlow 强，也无法形成稳定桥接。CohereFlow\_N(𝒟₁) = CohereFlow(𝒟₁) / Rcap(F)（须 Rcap(F) \> 0）为无量纲读数（量纲约定 U）；BridgeStr 因而无量纲，与同步方程中无量纲的 FragmentRate 相容。

同步方程（示范模型）：  
Sync(𝒟₁,𝒟₂) ∝ BridgeStr(𝒟₁⇝𝒟₂) / (1 + FragmentRate(𝒟₁,𝒟₂))  
注：分母取 1+FragmentRate，只消除 FragmentRate→0 处的奇点。BridgeStr 有界时，Sync 有界；若 BridgeStr 另趋于有限值 N，且 FragmentRate 趋于 0，则 Sync 趋于比例常数乘 N（其他输入固定、只令 FragmentRate 趋零时亦然）。分子有界而振荡时，Sync 可不收敛。分母加 1 不单独推出全局有界。

FragmentRate 来源方程（示范模型）：  
FragmentRate(𝒟) ∝ PhaseConflict + SyncCollapse + LockDecay

其中：PhaseConflict 记域间相位差引起的失稳；SyncCollapse 记已有跨域同步的崩解；LockDecay 记低 MaintainFlow 或高 DecayRate 下 Lock 的减弱。FragmentRate(𝒟) 为域层量，同步方程中的 FragmentRate(𝒟₁,𝒟₂) 为域对层量，各自申报。

定律9：强桥同步定律  
域桥越稳定：跨域同步越容易长期维持。

联想：稳定跨域同步续行。

第7节 时间尺度与相位

不同域，并不以相同速度续行。因此：域具有不同时间尺度。

定义14：时间尺度  
记：TimeScale(𝒟)  
表示域完成一次稳定聚流周期所需时间。

时间尺度方程（示范模型）：  
TimeScale(𝒟) ∝ Lock(𝒟) / MaintainFlow(𝒟)  
注：MaintainFlow = 0 时本式未定义（⊥）。单看本式：Lock 固定时，MaintainFlow 越强，时间尺度越小；MaintainFlow 固定时，Lock 越强，时间尺度越大。与 Lock 形成方程联立（MaintainFlow \> 0）则得 TimeScale ∝ χ\_B × c\_L × HistLayer / (1 + DecayRate)，MaintainFlow 消去：经 Lock 传入的维持作用与分母中的维持作用相抵。故本篇不以本式断言「MaintainFlow 越强，域更新越快」。联立式中（χ\_B = 1），时间尺度随 HistLayer 增大而增大，随 DecayRate 增大而减小。

定义15：Phase  
记：Phase(𝒟)  
表示聚流的时间位置结构。

相位差方程：  
ΔPhase(𝒟₁,𝒟₂) ＝ \|Phase₁ − Phase₂\|

定律10：深域慢变定律  
Lock 越强：域变化越慢。

注：与 Lock 形成方程联立时（见时间尺度方程注），此定律只在 MaintainFlow 固定时成立。

定律11：大相差碎同步定律  
长期大相位差：会提高 FragmentRate。于是：跨域 Sync 下降。

第8节 冲突与相变

不同历史层积之间，可能存在互斥聚流。于是：历史冲突形成。

定义16：历史冲突  
记：Conflict(Hist₁,Hist₂)  
表示不同历史层积之间存在互斥聚流。

冲突方程（示范模型）：  
ConflictStr ∝ ΔDir × Lock(Hist₁) × Lock(Hist₂)

注：Hist₁、Hist₂ 记两种历史层积（不记 H，以免与场篇第一的端壑 H 同字）。ΔDir 记二者所压偏方向的差异程度（不取 Bias 之差：场篇第一的 Bias 是成立与否的判定）。Lock(Histᵢ) 记 Histᵢ 所承担的那部分 Lock。三者均为示范量，测定须由具体场申报。

定义17：域相变  
记：PhaseShift(𝒟)  
表示域结构在短时间内发生整体重组。

相变条件（示范模型）：  
若：Conflict ↑↑ 或 SyncCollapse ↑↑，则：PhaseShift(𝒟) ↑

定律12：强冲突相变定律  
长期冲突积压后：域更容易发生整体重组。

顿悟、精神崩塌、价值骤变，皆为：域相变。

第9节 情绪节律态

情绪不是对象。

情绪是：大规模同步后的节律偏态。

定义18：EmotionState  
记：EmotionState(R)  
表示 Recognition-Realm 中的大规模同步节律结构。

定义18a：RhythmFlow

记：RhythmFlow(R)

表示 Recognition-Realm 中聚流的周期结构——聚流呈现稳定周期复现的程度。示范式取 RhythmFlow ∈ \[0,1\]：0 表示完全无周期的聚流，1 表示最稳定的周期聚流。Sync 亦高时，高 RhythmFlow 放大 EmotionState；RhythmFlow 低时，无论 Sync 高低，情绪幅度都受抑制。

情绪方程（示范模型）：  
EmotionState(R) ∝ Sync(R) × RhythmFlow(R) × Conflict(R) / (1 + FragmentRate(R))  
注：分母取 1+FragmentRate，只消除 FragmentRate→0 处的奇点。Sync(R)、RhythmFlow(R)、Conflict(R) 有界时，EmotionState 有界；若三者之积另趋于有限值 N，且 FragmentRate 趋于 0，则 EmotionState 趋于比例常数乘 N（其他输入固定、只令 FragmentRate 趋零时亦然）。分子有界而振荡时，EmotionState 可不收敛。分母加 1 不单独推出全局有界。Conflict(R) 记 R 内历史冲突强度的汇总（示范记法）。

恐惧：高 Conflict 同步态。  
狂热：高 Sync 扩张态。  
平静：低 Conflict 稳同步态。  
麻木：低 Sync 低 Rhythm 态。

定律13：高同步放大量律  
Sync 越强：情绪越容易整体扩散。

定律14：高冲突震荡定律  
历史冲突越强：情绪节律越不稳定。

定律15：失同步冷却定律  
跨域 Sync 下降后：情绪节律逐渐衰减。

第10节 资源与能耗

稳定同步，需要持续资源支持。

定义19：资源容量  
记：Rcap(F)  
（不记 Res(F)，以免与场篇第一中分辨率符号 Res(F) 冲突）  
表示沉积场当前可维持的有效聚流总量。  
注：Rcap(F) 与场篇第一的场容积 Cap(F)=Vol(F)×Res(F) 不同。Cap(F) 是稳定差分域的数量上限（物理层），Rcap(F) 是可维持有效聚流的总量上限（动力层）。两者量纲不同（一计域数，一计聚流量），本篇不立二者之间的数量关系；Cap(F) 超限时的释放条件见场篇第一约束20。

资源方程（示范模型）：  
ΣMaintainFlow + ΣCohereFlow + ΣLockMaintenance ≤ Rcap(F)  
注：ΣCohereFlow 可理解为各域维持稳定同步的聚流消耗总和，即同步成本（SyncCost）的总量。大规模 Sync 越强，ΣCohereFlow 越高，资源消耗越大。ΣLockMaintenance 记维持各域 Lock 所需的聚流（示范项，须申报）。

定律16：高同步高耗定律  
大规模 Sync：会持续消耗 CohereFlow。

定律17：同步资源竞争定律  
当：ΣCohereFlow 逼近 Rcap(F) 时：部分域同步开始下降。于是：FragmentRate 上升。

长期疲劳、注意力耗尽、认知迟钝，皆为：资源竞争失衡。

第11节 域失败条件

并非所有聚流，都能形成稳定域。即使形成域，也未必能够长期维持。

定义20：失败域  
记：Fail(𝒟)  
表示无法维持稳定聚流的域。

失败条件方程（示范模型）：  
若：MaintainFlow ↓ 且 Lock ↓ 且 Sync ↓，则：Fail(𝒟) ＝ 1

定律18：低 Lock 崩域定律  
Lock 长期不足：域容易崩散。

定律19：高 FragmentRate 碎界定律  
FragmentRate 长期升高：Recognition-Realm 稳定性下降。

认知碎裂、长期失焦、现实感退化，皆为：域失败现象。

第12节 Recognition-Realm 连续性

Recognition-Realm 的连续感，并不是世界天然赋予，而是域网络同步稳定后的生成结果：大规模 Sync 压过 FragmentRate 的结果。

连续性方程（示范模型）：  
Continuity(R) = Sync\_N(R) × Lock\_N(R) / (1 + FragmentRate(R))  
注：Sync\_N = Sync / S\_ref、Lock\_N = Lock / L\_ref 为归一读数，原始量 Sync、Lock 不直接代入本式。S\_ref、L\_ref \> 0 为申报的共同尺度，须不小于所论范围内 Sync、Lock 的上确界（Lock 的上界见 Lock 形成方程注之推论；无界时不能归一，Continuity 未定义）。FragmentRate ≥ 0。于是 Continuity(R) ∈ \[0,1\]，且 Continuity(R) = 1 当且仅当 Sync\_N = Lock\_N = 1 且 FragmentRate = 0；此理想能否实现，本篇不断言。

定律20：高 Sync 稳现实定律  
Sync 长期稳定：Recognition-Realm 越连续。

定律21：高 FragmentRate 碎现实定律  
FragmentRate 长期升高：Recognition-Realm 开始碎裂。

梦境、幻觉、现实断裂感，皆为：跨域同步失稳。

第13节 最终压缩

域：局部稳定续行。

历史：不可逆层积（不删除历史迹应则不能完全回复，场篇第一定理15）。

Lock：历史层积对当前聚流的持续偏置。

Sync：多个域之间的稳定互返续行。

记忆：Lock 稳定态。

人格：MainCore 统摄下，由高 Lock、高跨域 Sync 长期形成的稳定统流结构。

情绪：大规模 Sync 后的节律偏态。

现实连续感：Sync 与 Lock 共同压过 FragmentRate 的结果。

Recognition-Realm：沉积场中的大型同步稳定结构，是观察者得以在其中生成识出的域网络结构。其连续性由 Sync、Lock 对 FragmentRate 的相对压过程度决定。

认知：历史层积在 InFlow、MaintainFlow、CohereFlow、Lock、Sync、DecayRate、FragmentRate 之间形成的稳定偏流结构。

以上各条：式为示范模型，定律为模型层的申报，记忆、人格、情绪等对应为释义（现实适用主张），见第1节注与第2节注。
