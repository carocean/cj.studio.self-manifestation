自显论·场篇第七 v1.2

# 场动力纵深方程

1\. 目的

前六篇已经建立：

\- 场篇第一：沉积结构（沟线、域、熟径、共核、闭包）如何生成；  
\- 场篇第二：域网络如何同步，识界如何形成；  
\- 场篇第三：共核如何稳定；  
\- 场篇第四：路径层的协调压缩动力（Ω\_c 演化方程）；  
\- 场篇第五：历史为何不可逆；  
\- 场篇第六：分化为何从未分中出现。

但场篇第四在路径层描述单条路径的协调压缩演化，尚未建立以下问题的域层动力方程：

为什么沉积不会无限累积。

为什么结构既会稳定，又会裂解。

为什么边沁之后会形成新域。

为什么熟径能够长期维持。

为什么结构既会聚流，又会弥散。

若沉积没有退化（这不同于沉积度净值不下降：增长抵消退化时，净值也可不下降），则：

\- 已留下的旧迹不会因退化而退出；  
\- 局部分辨容量不能由退化释放，只能由迁移与扩散重新分配；  
\- 新差异能否进入，只取决于剩余容量与迁移，不再有退化腾出的容量；  
\- 新结构能否形成，同样失去退化腾出容量这一来源。

（没有退化也不等于无界增长：门控使有效输入在剩余容量趋零时趋于零。）

因此：退化不是附属现象。退化是有限分辨场释放局部分辨容量的过程。

本篇与场篇第四的关系：场篇第四 v1.2 在路径层建立协调压缩 Ω\_c 的示范模型，Ω\_c 是同一参考条件下的协调压缩作用；本篇在域-空间层建立局部域沉积度 δ(x,t) 的偏微分方程组（示范模型），引入空间偏微分算子（∇、∇²）和核函数。二者对象不同：Ω\_c 不是沉积度，本篇不立二者的对应。

本篇将：把输入门控、竞争退化、流动、扩散、邻域转移纳入同一示范动力系统，并给出熟径所在路径维持于主分辨区的条件、总沉积量有界的条件，以及成域候选与核稳定的沉积度条件。新域、闭合与核是否存在，须另依结构条件认证，不在本篇模型之内（第13、14节）。各项结论的地位，见第18节之末的「结论地位表」。

1\. 基础变量

设：

δ(x,t) 为局部域 x 在时刻 t 的沉积度。

符号说明：本篇使用 δ(x,t) 引用场篇第一的沉积度 δ(x)（定义9：结构位、沟线、端壑、线束或域的沉积深浅程度，由宿载机制承担），并将其推广为连续时间、连续空间的函数。

本篇主方程（第9节）是场篇第一方程2（δₜ₊₁ = δₜ + Dτ − Eλ）在连续时空下的扩展模型：有效输入 I\_eff 与邻域转移项 B\_out 对应迹应造成的加深 Dτ；退化项 q₀δ + β·φ(ρ/Λ)·δ 对应场质导致的退浅 Eλ（外三：「场质，所以决遗忘之速也」），其中 β·φ 项把场质退浅在局部占压下的加速写成模型，是本篇的模型假设，原文未给；分辨流 −∇·J 与扩散 f·∇²δ 是本模型新增的迁移与弥散机制。主方程是示范模型，不是由方程2 推出的定理。

x 表示：场中能够形成交叠、竞争、熟径、边沁与核稳定的局部域位置（对应场篇第一的结构位 x 在连续空间中的推广）。

与场篇第四的关系：场篇第四 v1.2 的 Ω\_c 是同一参考条件下的协调压缩作用，不是沉积度；本篇不立「Ω\_c 上升对应 δ 趋向增深」（场篇第四 v1.2 第2节符号说明）。

设：

S(x,t) 为当前输入结构。

I(x,t) 为进入局部域 x 的脉冲输入。

M(x,t) 为输入结构与已有沉积结构的交叠匹配率。

A(x,t) 为门控前输入。

I\_eff(x,t) 为有效输入（被局部域吸收的输入）。

R(x,t) 为未吸收输入（被容量门控挡下的输入）。

B\_out(x,t) 为邻域转移项（邻域未吸收输入转入 x 而被吸收者）。

ρ(x,t) 为局部域 x 附近的分辨占压（Resolution Occupancy Pressure）。

注：ρ 不是沉积度本身，而是邻域沉积对局部 x 形成的竞争压力——ρ = K∗δ 表示以核函数 K 对邻域 δ 加权积分后得到的占压值。ρ 与 δ 是不同层次的量：δ(x,t) 是局部域 x 的沉积度；ρ(x,t) 是由邻域沉积共同形成的、作用于 x 的竞争压力。两者不可混同，否则”沉积因为沉积而退化”将变成无信息的自环定义。

Λ(x) 为局部域 x 的局部分辨容量（注：原版 v1.0 使用 Ω(x)，但 Ω 已在场篇第一中定义为稳定复走能力 Ω(x→y)，故本篇改用 Λ(x) 表示局部分辨容量）。

G(x,t) 为局部域 x 的剩余分辨容量。

C(x,t) 为局部容量负载。

O(x,t) 为局部源项剩余。

J(x,t) 为局部分辨流。

q₀(x) 为基础退化系数。

β(x) 为局部竞争退化系数（注：原版 v1.0 使用 λ(x)，但 λ 已在场篇第一中定义为场质，故本篇改用 β(x)）。

p 为匹配增强系数（注：原版 v1.0 使用 α，但 α 已在场篇第四中定义为低代价复走增益系数，故本篇改用 p）。

γ 为匹配梯度流系数。

r 为占用梯度流系数（注：原版 v1.0 使用 κ，但 κ 已在场篇第一中定义为趋入能力 κ(x)，故本篇改用 r）。

f 为局部扩散系数（注：原版 v1.0 使用 ν，但 ν 已在场篇第四中定义为协调压缩降代价系数，故本篇改用 f）。

χ 为匹配尺度系数。

C₀ 为局部容量尺度。

η 为容量平滑系数（σ(G) = max(G,0)/(max(G,0)+η) 中的平滑参数，η \> 0）。

T(x,y,t) 为邻域转移核。

τc 为成域候选的最小增长持续时间。

τs 为核稳定判定时间窗口。

ε 为核稳定误差阈值。

K(x−y) 为邻域影响核。

W(x−y) 为局部容量影响核。

模型申报（定义域与前提）：

（1）空间域：Ω\_s ⊂ ℝⁿ 为有界区域，边界 ∂Ω\_s 光滑；时间 t ∈ \[0, T\_end)。

（2）边界条件：无通量，即在 ∂Ω\_s 上 (J − f·∇δ)·n = 0，n 为外法向。

（3）初始条件：δ(x,0) = δ₀(x) ≥ 0。

（4）解的存在：假设在 Ω\_s × \[0, T\_end) 上存在充分光滑的解（本篇不证存在性）。

（5）非负性：本篇的 J 不随 δ 成比例，零沉积处仍可有外流，故非负性一般不由方程保持。本篇以假设 N₊ 申报：所论解在 Ω\_s × \[0, T\_end) 上保持 δ ≥ 0。凡用到 δ ≥ 0 的结论，均以 N₊ 为前提。若要由方程保证非负，可改用随 δ 成比例的流 J = δ·v（v = −r·∇ρ + γχ·∇M），此为可选的替代形式，本篇不采用。

（6）参数与核：Λ(x) ≥ Λ\_min \> 0；C₀ \> 0；η \> 0；q₀(x) ≥ q\_min \> 0；β(x) ≥ 0；p ≥ 0 为固定有限常数；γ、r、f \> 0 为常数；χ \> 0 为常数；K ≥ 0 且 ∫K(x−y)dy = 1；W ≥ 0 且可积；输入有界：0 ≤ I(x,t) ≤ Ī，S ≥ 0。

（7）量纲：取 δ、ρ、C、M、Λ 为无量纲相对量，x 的量纲为 \[L\]，t 的量纲为 \[T\]。

1\. 局部分辨占用方程

局部分辨占用方程（Local Resolution Occupancy Equation）：

ρ(x,t) = ∫K(x−y)δ(y,t)dy

这表示：局部域 x 的分辨压力，由邻近相关域中的沉积共同决定，不是由全场统一决定。因此：只有邻近、交叠、相关结构，才会显著竞争同一局部分辨容量。

1\. 剩余分辨容量方程

剩余分辨容量方程（Residual Resolution Capacity Equation）：

G(x,t) = Λ(x) − ρ(x,t)

其中 Λ(x) 为局部域 x 的稳定分辨容量。本篇不展开 Λ 的演化，仅承认不同局部域的局部分辨容量可以不同。

当 G \> 0：该局部域仍能吸收新差异。  
当 G → 0：该局部域接近域满。  
当 G ≤ 0：该局部域的分辨容量已被占尽，本篇称为容量满（场篇第一定义20 的域满另要求不可再深、不可再分、不可再入分辨三者同时成立）。

1\. 局部容量负载方程

局部容量负载方程（Local Capacity Load Equation）：

C(x,t) = ∫W(x−y)δ(y,t)dy

在 N₊ 与 W ≥ 0 下，C ≥ 0。这表示：局部域的输入衰减，由邻域沉积负载共同决定，不是由全场统一共享一个总容量。因此：场负载具有局部性。

1\. 结构交叠匹配方程

结构交叠匹配方程（Structural Overlap Matching Equation）：

沉积加深之由，在本篇模型中分两层。其一，先后：深者先得其流（外三；场篇第一定律5：在比较条件 C₌ 下，深者不后于浅者满足出流条件；在 C₌ 与 P₁₇ 下严格先满足，定理17）。其二，进入后的有效输入量：本篇以当前输入结构与已有沉积结构之间的交叠程度 M 来模型化。二者不相替代：M 不决定先后，先后由场篇第一判定。

定义匹配率：

M(x,t) = ∫\_Nx min(S(y,t), δ(y,t))dy / ∫\_Nx max(S(y,t), δ(y,t))dy

其中 Nx 表示局部域 x 的邻域范围（即积分在 x 的局部邻域内进行，而非全场）。S(y,t) 和 δ(y,t) 均定义在同一连续空间中，因此积分域统一。若分母为 0（即 Nx 上 S 与 δ 几乎处处为 0），规定 M(x,t) = 0。

非负约束：本篇要求 S(y,t) ≥ 0，并以 N₊ 保证 δ(y,t) ≥ 0。此约束保证 min/max 运算有意义（若允许负值，min/max 将失去交叠度量的语义）。

在上述规定下，0 ≤ M ≤ 1。

当 M → 0：输入与已有域几乎无交叠。  
当 M → 1：输入与已有域高度交叠。

此处之 M，仅为最低可算交叠近似。更高结构匹配，可进一步引入时序、拓扑与方向结构。

注：M 关于 δ 不必单调：在 δ 已超过 S 之处，δ 再增，M 反而下降。故本模型不推出「愈深则有效输入愈多」；这与深者先得其流不相冲突，后者论先后，由场篇第一判定。

因此：在本篇模型中，交叠是有效输入的增强因素：M 越大，门控前输入按因子 1 + p·M 越大；M = 0 时，有效输入仍可为正。熟径本身依场篇第一定义13 判定：既有深积，且在申报窗口内有常走记录（外三「因深者先得其流，故信号好走常熟，此所谓常熟之径」）。

1\. 有限场输入衰减方程

有限场输入衰减方程（Finite-Field Input Attenuation Equation）：

A = I·(1 + p·M)·exp(−C(x,t)/C₀)

I\_eff = A·σ(G(x,t))

R = A·(1 − σ(G(x,t)))

其中 σ(G) = max(G,0)/(max(G,0)+η)（η \> 0 为容量平滑系数）为剩余容量门控函数。A 是经交叠增强与负载衰减后的门控前输入；I\_eff 是被局部域吸收的部分；R 是被容量门控挡下、未被吸收的部分。负载衰减 exp(−C/C₀) 所减去的部分，本篇视为衰减损失，不再计入。

σ(G) 的作用：当 G 充裕（G \>\> η）时，σ(G) ≈ 1，容量约束不显著；当 G → 0（域接近满）时，σ(G) → 0，有效输入趋于零，未吸收输入趋于 A；当 G ≤ 0 时，σ(G) = 0，I\_eff = 0，R = A。此门控在全域有定义且有界。p 为固定有限常数；若令 p → ∞，在 G \> 0、M \> 0、I \> 0 处 I\_eff 仍随 p 无界增长，σ(G) 不能阻止。

这表示：输入与已有域交叠越高，门控前输入越大。但当局部容量负载升高或剩余容量趋零时，有效输入整体衰减至零，未被吸收的部分成为 R。

邻域转移项（新增模型内容）：

B\_out(x,t) = σ(G(x,t))·∫T(x,y,t)·R(y,t)dy

其中 T(x,y,t) ≥ 0 为邻域转移核，须申报，并满足：（i）T(x,y,t) 只在 y 的邻域内非零；（ii）对每个 y，∫T(x,y,t)dx ≤ 1，即转出的量不超过 y 处的未吸收输入；（iii）方向申报：T 对 x 的权重关于 G(x) 与 M(x) 不减（例如 T(x,y) ∝ K\_T(x−y)·σ(G(x))·(1 + p\_T·M(x)) 再归一化）。

即：未吸收的输入 R(y) 按申报的转移核分配；实际被邻域 x 吸收的转入量由 B\_out(x) 给出（经 x 自身的容量门控 σ(G(x))），也可能为零；余者离场，不再计入。

此即未吸收输入的邻域转移模型，是本篇新增的模型内容；T = 0 时退回不含邻域转移的模型。由于 η \> 0，凡 A \> 0 处恒有 R = A·η/(max(G,0)+η) \> 0：剩余容量充裕时 R 很小，转移可忽略；只在 G → 0 或 G ≤ 0 时，R 接近或等于 A，转移才显著。G ≤ 0 且 A \> 0 也不保证实际转入非零：T 可为 0，邻域也可全部容量满（σ(G(x)) = 0）。

与边沁的关系：此模型是场篇第一定义21 边沁的候选实现机制，不是边沁的认证。定义21 的边沁——「域满之后，新增迹应因不可继续内沉，沿域边界外溢，并生成新结构位」——要求：域满（定义20，不只是 G ≤ 0 的容量满）；新增迹应不能继续内沉；沿域边界外溢；生成新结构位。本模型只表达其中「输入继续进入而此处不能吸收，于是按转移核分配给邻域」这一部分。容量满不等于域满；R 在容量未满时也为正；邻域吸收不等于生成新结构位。故存在转移不等于发生边沁。只有上述结构条件另行满足时，才讨论此转移是否承担边沁。

1\. 分辨流方程

分辨流方程（Resolution-Flow Equation）：

J(x,t) = −r·∇ρ(x,t) + γχ·∇M(x,t)

其中 χ 为正常数，故 γ·∇(χ·M) = γχ·∇M。本篇暂不展开流之惯性与延迟，仅取瞬时局部分辨流近似。

−r·∇ρ：分辨流趋向低占用区域。  
γχ·∇M：分辨流趋向高匹配区域。

因此：分辨流的方向，由降占用方向与增匹配方向加权合成（定理四）。二者同向处，流向低占用且高匹配的邻域；二者相悖处，方向由加权和决定。

1\. 沉积场动力主方程

沉积场动力主方程（Sedimentation-Field Dynamics Equation）：

∂δ/∂t = I\_eff + B\_out − q₀δ − β·φ(ρ/Λ)·δ − ∇·J + f·∇²δ

（类别：示范模型。各项的函数形式，连同第3至8节的 ρ、G、C、M、A、I\_eff、R、J、B\_out，都是本篇的模型选择，不由内外篇或场篇第一推出。）

其中 φ(u) 为局部分辨竞争函数，规定：

φ(u) = u + c\_φ·max(u−1, 0)²

其中 c\_φ ≥ 0 为非线性竞争增强系数。

当 c\_φ = 0 时：φ(u) = u，全程线性，即最低可算近似。  
当 c\_φ \> 0 时：u ≤ 1 时 φ(u) = u（与线性一致）；u \> 1 时 φ(u) = u + c\_φ(u−1)²（超饱和后非线性增强）。

平滑性说明：在 u = 1 处，φ(1) = 1（连续），φ’(1) = 1（一阶导连续），φ’’(1⁺) = 2c\_φ（二阶导在 u=1 处右导数存在）。函数在 u=1 处 C¹ 连续，避免导数跳跃，适合 PDE 稳定性分析。精确函数形式（包括更高阶平滑版本）留待后续篇章根据具体场类型确定。u ≥ 0 时 φ(u) ≥ 0。

各项含义：

I\_eff：本地被吸收的输入。

B\_out：邻域未吸收输入经邻域转移转入、在本地被吸收者。

−q₀δ：基础退化。即使局部分辨竞争很弱，沉积也会自然退化。

−β·φ(ρ/Λ)·δ：局部分辨竞争导致的额外退化。局部分辨占用越高，维持旧沉积的代价越高，旧迹越容易退化。（本模型把场质退浅在局部占压下的加速写成此项，原文未给，见第2节。）

−∇·J：局部分辨流导致的沉积迁移。∇·J \> 0 表示该局部域的沉积向外流出；∇·J \< 0 表示邻域沉积向该局部域流入。因此沉积不仅局部增减，还会在场中迁移与聚流。

f·∇²δ：无方向局部扩散。沉积具有局部弥散趋势，扩散会削弱局部差异梯度。

因此：J 表示有方向聚流；f·∇²δ 表示无方向局部弥散；B\_out 表示邻域转入。

左侧 ∂δ/∂t：\[T⁻¹\]  
I\_eff、B\_out：\[T⁻¹\]（吸收速率）；A、R、I：\[T⁻¹\]  
q₀δ：q₀ 量纲为 \[T⁻¹\]，项量纲 \[T⁻¹\]

J：\[L·T⁻¹\]；∇·J：\[T⁻¹\]。由 J = −r·∇ρ + γχ·∇M，∇ρ 与 ∇M 的量纲为 \[L⁻¹\]，故 r 与 γχ 的量纲为 \[L²·T⁻¹\]  
f·∇²δ：f 量纲为 \[L²·T⁻¹\]，∇² 量纲为 \[L⁻²\]，项量纲 \[T⁻¹\]  
T(x,y,t)：\[L⁻ⁿ\]（使 ∫T dx 无量纲）

各项量纲一致，均为 \[T⁻¹\]。

系数说明：

q₀ \> 0（基础退化系数）：决定基础退化半衰期，t₁/₂ = ln2/q₀。  
β ≥ 0（局部竞争退化系数）：β 越大，高分辨占用对沉积的退化加速越剧烈。  
p ≥ 0（匹配增强系数，固定有限）：p 越大，输入与已有结构交叠对门控前输入的增强越强。  
γ \> 0（匹配梯度流系数）：γ 越大，分辨流向高匹配区域的趋向越强。  
r \> 0（占用梯度流系数）：r 越大，分辨流向低占用区域的趋向越强。  
f \> 0（局部扩散系数）：f 越大，沉积的局部弥散趋势越强。

1\. 基础退化

在 I\_eff = B\_out = 0（例如 I 在 Ω\_s 上于所论时段恒为 0，则 A、I\_eff、R、B\_out 处处为 0；仅该处 I = 0 不能推出 B\_out = 0）、β·φ(ρ/Λ) = 0、∇·J = 0 且 ∇²δ = 0 时：

∂δ/∂t = −q₀δ

解为：δ(t) = δ₀·e^(−q₀t)

因此：q₀ 决定基础退化半衰期：t₁/₂ = ln2/q₀（定理二）。若只是 I\_eff = B\_out = 0、ρ ≈ 0、流与扩散可忽略，则 ∂δ/∂t ≈ −q₀δ，半衰期近似为 ln2/q₀。

这说明：场质具有可测量部分。不同场的基础退化速度不同。

1\. 增长、稳定与退化

若 I\_eff + B\_out \> q₀δ + β·φ(ρ/Λ)·δ + ∇·J − f·∇²δ，则沉积增加。

若 I\_eff + B\_out = q₀δ + β·φ(ρ/Λ)·δ + ∇·J − f·∇²δ，则沉积稳定。

若 I\_eff + B\_out \< q₀δ + β·φ(ρ/Λ)·δ + ∇·J − f·∇²δ，则沉积退化。

注：此处将主方程移项，∇·J 出现在右侧退化一侧。∇·J \> 0 表示净流出（沉积向外迁移，对 δ 形成减少贡献），∇·J \< 0 表示净流入（沉积从邻域流入，对 δ 形成增加贡献）。

因此：熟径所在路径能否在所论时段内留在主分辨区，取决于它在持续输入、结构交叠、竞争、流动、扩散与退化之间，能否不使沉积度持续下降（定理三）。熟径的判定仍依场篇第一定义13。

1\. 主分辨区阈值

设 δᵣ 为申报的主分辨区阈值。其操作用途是：判定路径是否处于主分辨区。它不替代熟的一般含义（场篇第一定义13：「具体场若以阈值 δᵣ 等另立门槛，须申报其操作用途，不替代熟的一般含义」）。

若 δ ≥ δᵣ，则称路径处于主分辨区；若此路径同时为熟径（既有深积，且在申报窗口内有常走记录），称为主分辨区熟径。它是否对后续输入形成稳定续行偏置，依场篇第一方程11（Bias）判定，不由 δ ≥ δᵣ 单独推出。

若 δ \< δᵣ，则路径逐渐退出主分辨区。

因此：历史是否能够留下，不仅取决于是否发生过，更取决于该路径是否能长期维持足够沉积度。

1\. 局部源项剩余

局部源项剩余（Local Source Surplus）：

O(x,t) = max(I\_eff + B\_out − q₀δ − β·φ(ρ/Λ)·δ, 0)

由主方程，I\_eff + B\_out − q₀δ − β·φ(ρ/Λ)·δ = ∂δ/∂t + ∇·J − f·∇²δ，故两式恒等，无须稳态或流项为零。O 是扣除退化、尚未扣除净迁移与扩散的局部源项剩余，不是实际净增长：例如有效输入为 3、退化量为 1、净流出为 2、扩散为 0，则 ∂δ/∂t = 0，而 O = 2。

O 不用作转移判据：在容量满处（G ≤ 0），I\_eff = 0，且在 N₊ 下退化项非负，若此处 B\_out 亦为 0，则 O = 0。转移显著的条件看未吸收输入 R（第7节）：G → 0 或 G ≤ 0，且 A \> 0（此时 R → A 或 R = A）；实际转入是否非零，还取决于 T 与邻域的容量门控。

容量满转移态：当 G(x,t) → 0 或 G(x,t) ≤ 0，且 A(x,t) \> 0 时，本篇称为容量满转移态。这只是候选状态：此处的未吸收输入 R 接近或等于 A，按转移核分配；实际转入由 B\_out 给出，也可能为零。若要断言某时刻确有非零转入，须另有 ∫\_{Ω\_s} B\_out(x,t)dx \> 0。在有转入的邻域 x 处，B\_out 进入主方程，使该处沉积增加的源项增大。

但：转入并不一定形成稳定新域。若转入仅短暂存在，则其会退化消散。邻域沉积度的持续增长，只是成域的候选条件（判据五）；新域、新闭合是否形成，须另依结构条件认证：场篇第一定义8 的域须稳定维持容与、分辨、差分积深、续行、束界五项；方程16 的闭包须长期互返续行且能重复返回。本篇模型不推出这些结构条件。

因此：在本模型中，邻域转移不是随机的：未吸收输入按申报的转移核分配，其方向由 T 的方向申报给出（在其他因素相同的比较下，见定理四）；实际转入量由 B\_out 给出，也可能为零。此转移是否承担边沁，须另依场篇第一定义21 的结构条件认证（第7节）。

1\. 核稳定

新域形成之后，并不一定长期稳定。\|∂δ/∂t\| \< ε 持续超过时间 τs，是已有核的沉积度稳定条件（判据六）。

此条件只表示在有限窗口内该处沉积度变化较小；它允许静态平衡（各项皆为零，例如无输入且 δ = 0），也允许各项非零而相互抵消（动态平衡）。窗口本身也不保证窗口结束后的长期稳定。故它不能单独证明核存在。核的存在须另依结构条件认证（例如场篇第一定义15 的共核，或定义8 的域的五项稳定条件），本篇模型不推出。

因此：在核已存在的前提下，判据六刻画有限窗口内沉积度变化较小；它允许静态平衡，也允许输入、竞争、退化、流动、扩散各项非零而相互抵消。

1\. 极端情况

以下为带条件的模型趋势，分两层：固定状态下的瞬时速率变化；整个解随参数变化的行为。

（一）q₀ → 0 且 β → 0。固定状态下：退化速率 q₀δ + β·φ(ρ/Λ)·δ 随系数趋于 0。小而正的退化仍释放容量：持续输入、没有迁移疏散时，输入与退化仍可能在容量满之前平衡。例如取空间均匀状态，Λ = η = I = 1，p = β = 0，W = 0，T = 0，迁移与扩散为 0，则 dδ/dt = (1 − δ)/(2 − δ) − q₀δ（0 ≤ δ \< 1）；q₀ = 0.1 时有稳定平衡 δ\* ≈ 0.90098，G\* ≈ 0.09902 \> 0；对任意小的正 q₀，右端在 δ = 0 处为 1/2、在 δ → 1 时趋于 −q₀，同样存在小于 1 的平衡。零退化（q₀ = β = 0）另作极限模型讨论：此时容量不能由退化释放，只能由迁移与扩散重新分配；但是否到达容量满，仍须另证，不能仅凭持续输入推出（门控使有效输入在 G → 0 时趋零）。零退化超出模型申报（6）的 q\_min \> 0，定理一′ 不适用；其上界在 q\_min → 0 时趋于无穷，总量估计不再给出有限上界（这不表示总量必然无界）。

（二）q\_min → ∞。参数极限申明：考虑一族参数，其 q\_min → ∞，而初始总量 m(0) 与 Ī(1+p) 统一有界，\|Ω\_s\| 固定，各解存在于共同讨论区间 \[0, T\_c)，其余申报不变。一般的逐点 q₀(x) → ∞ 不等同于 q\_min → ∞。固定状态下：退化速率随 q₀ 无界增大。整个解：由定理一′ 证明中的 dm/dt ≤ Ī(1+p)\|Ω\_s\| − q\_min·m，得 m(t) ≤ m(0)·e^(−q\_min·t) + (Ī(1+p)\|Ω\_s\|/q\_min)·(1 − e^(−q\_min·t))；在 (0, T\_c) 中任一固定 t 处，右端随 q\_min → ∞ 趋于 0。即在 N₊ 与上述统一条件下，总沉积量在任一固定正时刻趋于零。

（三）β → ∞。固定状态下：只在 φ(ρ/Λ) \> 0 且 δ \> 0 处，竞争退化速率随 β 无界增大；φ(ρ/Λ) = 0 处（ρ = 0），增大 β 不产生作用。整个解随 β 的行为，本篇不推出。

（四）熟径能否形成、历史能否保留、现实能否更新，属结构层与观者层的判断；以上只是沉积度层面的趋势，本篇模型不推出这些结论。

1\. 核心结论

第一：退化不是缺陷。退化是有限分辨场释放局部分辨容量的过程。

第二：遗忘不是删除。原义中，遗忘是迹淡、退浅（内六「少用则迹淡」；外三「场质，所以决遗忘之速也」）；本模型中，遗忘的操作判定是沉积度退出主分辨区（δ \< δᵣ）。

第三：熟径是常熟之径（场篇第一定义13）；在本篇模型中，交叠是其有效输入的增强因素，不是必要条件。

第四：场满不是全场总量过高。在本模型中，容量满是局部分辨占用达到局部分辨容量（G ≤ 0）。

第五：在本模型中，未吸收输入按申报的转移核分配，不是随机的（新增模型内容）；实际被邻域吸收的转入量由 B\_out 给出，也可能为零。这是边沁的候选实现机制；是否承担边沁、新闭合是否形成，须另依场篇第一定义21 与结构条件认证。

第六：分辨流与扩散决定沉积如何迁移与弥散；成域须另依结构条件。

第七：在核已存在的前提下，判据六刻画有限窗口内沉积度变化较小；它允许静态平衡，也允许各项非零而相互抵消。窗口不保证其后的长期稳定。核的存在须另依结构条件认证。

1\. 关于模型层级

本篇所给方程，为沉积场动力的示范性最小闭合模型，各函数形式是本篇的模型选择。其目的，在于描述：输入门控、竞争退化、流动、扩散与邻域转移之间的最小动力关系，并给出成域候选与核稳定的沉积度条件。

方程结构定位：本篇主方程

∂δ/∂t = I\_eff + B\_out − q₀δ − β·φ(ρ/Λ)·δ − ∇·J + f·∇²δ

属于竞争–流动–扩散–退化闭合系统（Competition–Flow–Diffusion–Decay closed system），加上非局部的邻域转移项。其结构与反应–扩散方程（Reaction-Diffusion Equation）同族，但增加了有方向性的分辨流项 −∇·J、非线性竞争退化项 −β·φ(ρ/Λ)·δ 与转移项 B\_out。

因此：本篇中的结构交叠匹配、局部分辨竞争、容量影响核、分辨流与转移核，仍采用最低可算近似。后续场数学中，可进一步引入：时序结构、拓扑结构、方向结构、流惯性、时滞动力、多尺度域与更高阶结构匹配。

1\. 定理与判据

定理一：输入门控定理（示范模型内）

在模型申报（6）下，0 ≤ I\_eff ≤ Ī(1 + p)·σ(G)，0 ≤ A ≤ Ī(1 + p)。当 G(x,t) → 0⁺ 时，I\_eff(x,t) → 0；当 G(x,t) ≤ 0 时，I\_eff(x,t) = 0，R(x,t) = A(x,t)。

证明要点：0 ≤ M ≤ 1，故 1 ≤ 1 + p·M ≤ 1 + p；在 N₊ 与 W ≥ 0 下 C ≥ 0，故 0 \< exp(−C/C₀) ≤ 1。所以 0 ≤ A ≤ Ī(1 + p)，I\_eff = A·σ(G)。由 σ 的定义，G → 0⁺ 时 σ(G) → 0，G ≤ 0 时 σ(G) = 0。∎

本定理只证明输入门控：有效输入有界，且在容量耗尽时趋零。它不控制迁移补入、局部集中与解的长期行为，不推出局部沉积度有界。

定理一′：总沉积量有界定理（示范模型内）

在模型申报（1）至（6）与 N₊ 下，记总沉积量 m(t) = ∫\_{Ω\_s} δ(x,t)dx，\|Ω\_s\| 为 Ω\_s 的体积。则对一切 t ∈ \[0, T\_end)：

m(t) ≤ max( m(0), Ī(1 + p)\|Ω\_s\| / q\_min )

证明要点：对主方程在 Ω\_s 上积分。由无通量边界条件与 f 为常数，∫(−∇·J + f·∇²δ)dx = −∫\_{∂Ω\_s}(J − f·∇δ)·n dS = 0。由 T 的条件（ii），∫B\_out dx ≤ ∫∫T(x,y)R(y)dydx ≤ ∫R dy。故 ∫(I\_eff + B\_out)dx ≤ ∫(A·σ + A·(1 − σ))dx = ∫A dx ≤ Ī(1 + p)\|Ω\_s\|。在 N₊ 下 ρ ≥ 0，φ(ρ/Λ) ≥ 0，β ≥ 0，故 ∫β·φ·δ dx ≥ 0；又 ∫q₀δ dx ≥ q\_min·m。于是 dm/dt ≤ Ī(1 + p)\|Ω\_s\| − q\_min·m，由比较原理即得。∎

局部沉积度 δ(x,t) 是否有界（是否会因迁移补入而局部集中），本篇未证，登记为待证问题。

定理二：基础退化半衰期定理（示范模型内）

在该处无吸收输入（I\_eff = B\_out = 0；例如 I 在 Ω\_s 上于所论时段恒为 0）、局部竞争退化项为零（β·φ(ρ/Λ) = 0）、无净分辨流（∇·J = 0）且沉积度空间均匀（∇²δ = 0）的条件下，沉积按指数衰减，半衰期为 t₁/₂ = ln2/q₀。若只是 I\_eff = B\_out = 0、ρ ≈ 0、流与扩散可忽略，则此式为近似。

证明要点：在所列条件下，主方程化为 ∂δ/∂t = −q₀δ，解为 δ(t) = δ₀·e^(−q₀t)；令 δ(t₁/₂) = δ₀/2，解得 t₁/₂ = ln2/q₀。∎

定理三：主分辨区维持定理（示范模型内）

设 δᵣ \> 0 为固定操作门槛，有效区间 \[t₀, t₁\] ⊂ \[0, T\_end)，在其上解存在。

（a）必要条件：设 δ(x,t₀) ≥ δᵣ，且在 \[t₀, t₁\] 上恒有 ∂δ(x,t)/∂t ≤ −c \< 0。记 T\_r = t₀ + (δ(x,t₀) − δᵣ)/c。若 T\_r ≤ t₁，则至迟于 T\_r，δ(x,·) 达到门槛（δ ≤ δᵣ）；对 (T\_r, t₁\] 中任一 t，δ(x,t) \< δᵣ，路径严格退出主分辨区。故若 t₁ \> T\_r，要在 \[t₀, t₁\] 上维持 δ ≥ δᵣ，净变化率不能在整个 \[t₀, t₁\] 上恒不大于 −c。在 N₊ 下，此负速率条件不能无限期成立（否则 δ 变负），故只在有效区间上陈述。

（b）充分条件：若 δ(x,t₀) ≥ δᵣ，δ(x,·) 在 \[t₀, t₁\] 上关于 t 连续可微，且在 \[t₀, t₁\] 内每当 δ(x,t) = δᵣ 时 ∂δ(x,t)/∂t \> 0，则对一切 t ∈ \[t₀, t₁\]，δ(x,t) ≥ δᵣ。

证明要点：（a）对 t ∈ \[t₀, t₁\]，δ(x,t) ≤ δ(x,t₀) − c(t − t₀)；t = T\_r 时右端等于 δᵣ，t \> T\_r 时右端小于 δᵣ。（b）若有 t ∈ (t₀, t₁\] 使 δ(x,t) \< δᵣ，取 s\* = sup{s ∈ \[t₀,t\] : δ(x,s) ≥ δᵣ}，则 δ(x,s\*) = δᵣ，且 s\* 之后紧邻处 δ \< δᵣ，故 ∂δ(x,s\*)/∂t ≤ 0，与假设矛盾。∎

本定理只保证主分辨区（δ ≥ δᵣ）的维持，不替代熟径维持的全部资格：熟径另须既有深积且在窗口内有常走记录（场篇第一定义13）。

定理四：分辨流与邻域转移的方向性定理（示范模型内）

（a）分辨流 J = −r·∇ρ + γχ·∇M 的方向，由降占用方向 −∇ρ 与增匹配方向 ∇M 加权合成（权重 r 与 γχ）。二者同向处，J 指向低分辨占用且高结构匹配的邻域；二者相悖处，J 的方向由加权和决定。

（b）邻域转移的去向，由转移核 T 的方向申报给出：在申报（iii）下，在其他因素相同（同一来源 y、同一 R(y)、相同距离核与其他权重）的比较中，转入量向 G 较大、M 较高的邻域倾斜；转入后再经邻域自身的容量门控吸收。不同来源、不同距离或不同权重的邻域之间，实际转入量的排序不由此推出。

证明要点：（a）由分辨流方程与 χ 为正常数直接读出。（b）由第7节 T 的申报与 B\_out 的定义直接读出。∎

故在本模型中，沉积流与邻域转移都由申报的梯度或转移核定向，不是随机的。此定理不认证边沁（第7节）。

判据五：成域候选的增长条件

本篇以「邻域 y 中 ∂δ(y,t)/∂t \> 0 持续超过时间 τc」作为成域候选的增长条件。

说明：此为本篇申报的条件，不是由主方程推出的定理。持续正增长包含有效输入、邻域转入、净迁移与扩散的共同贡献，不必是「有效输入超过退化量」。它可以发生在空间均匀、没有新边界的结构中，故不能单独认证新域或新闭合。新域、新闭合是否形成，须另依结构条件认证：场篇第一定义8 的域的五项稳定条件；方程16 的闭包条件；稳定边（协调不可继续统一的边界，见场篇第六定理四）的闭合。

判据六：已有核的沉积度稳定条件

本篇以「\|∂δ/∂t\| \< ε 持续超过时间 τs」作为已有核的沉积度稳定条件。

说明：此条件表示主方程右侧各项之和的绝对值小于 ε；它不要求各项为零。空场、缓慢衰减、空间均匀结构都可满足此条件，故它不能单独证明核存在。核的存在须另依结构条件认证；在核已存在的前提下，此条件刻画其沉积度的稳定。

1\. 最终方程组

沉积场动力方程组（Sedimentation-Field Dynamics Equations）

局部分辨占用方程：ρ(x,t) = ∫K(x−y)δ(y,t)dy

剩余分辨容量方程：G(x,t) = Λ(x) − ρ(x,t)

局部容量负载方程：C(x,t) = ∫W(x−y)δ(y,t)dy

结构交叠匹配方程：M(x,t) = ∫\_Nx min(S,δ)dy / ∫\_Nx max(S,δ)dy（分母为 0 时 M = 0）

有限场输入衰减方程：A = I·(1+p·M)·exp(−C(x,t)/C₀)；I\_eff = A·σ(G(x,t))；R = A·(1 − σ(G(x,t)))，其中 σ(G) = max(G,0)/(max(G,0)+η)

邻域转移项：B\_out(x,t) = σ(G(x,t))·∫T(x,y,t)R(y,t)dy

分辨流方程：J(x,t) = −r·∇ρ(x,t) + γχ·∇M(x,t)

沉积场动力主方程：∂δ/∂t = I\_eff + B\_out − q₀δ − β·φ(ρ/Λ)·δ − ∇·J + f·∇²δ

局部源项剩余：O(x,t) = max(I\_eff + B\_out − q₀δ − β·φ(ρ/Λ)·δ, 0)

边界与初始条件：在 ∂Ω\_s 上 (J − f·∇δ)·n = 0；δ(x,0) = δ₀(x) ≥ 0

（以上方程组为示范模型；N₊ 与解的存在为申报假设。）

最终压缩式

有限分辨场中的结构，

在竞争中保留，

在流动中迁移，

在扩散中弥散，

在退化中释放容量，

并在容量满时，按申报的核分配未吸收的输入；邻域实际吸收多少，由 B\_out 给出。
