自显论·场篇第九 v1.2

# 可分动力方程

1\. 目的

前篇已经指出：现实之所以能够成立，并不因为场天然分明，而是因为场能够在有限条件下维持稳定裂分。

因此：差异是否成立，并不只取决于冲击是否不同，更取决于场是否还有能力维持其成为两个。

然而此前仍未说明：为什么场的可分能力会不断变化。

为什么：

\- 有时现实越来越清晰；  
\- 有时现实开始模糊；  
\- 有时细类不断生成；  
\- 有时细类重新塌回共类；  
\- 有时新现实能够形成；  
\- 有时旧结构吞没大量新差异。

前篇仅论其存在条件，尚未论其动力。

因此本篇讨论：可分能力如何演化。以及：在本篇示范模型中，场为何不能同时维持全部持续生成的裂分，而会压缩与重构。各项结论的地位，见第12节之末的「结论地位表」。

1\. 核心命题

现实无法长期维持无限裂分。因为：裂分本身，会不断提高场的维持成本。

边界越多，则：

\- 调谐负载越高；  
\- 域间隔越小；  
\- 噪声互扰越强；  
\- 结构维持越困难。

于是：场越来越难继续维持新的细边。原本能够稳定成立的细类，便开始重新并回共类。

以上是本篇的出发观点。其中「边界越多 → 可分阈趋升」在本篇以模型假设表达（第3节假设 A1），不是推出的定理；本篇模型中可证的部分是：持续输入下，同时维持的边界密度有界，持续生成的裂分绝大部分不能同时维持（定理六）。

因此：现实并不会无限细化，而会不断：分化、聚流、回压、重构。

1\. 阈漂移

设：

θ\_sep(t) 为场 f 于时刻 t 的可分阈（直接引用场篇第八符号；场篇第八的基础假设为 θ\_sep \> 0）。

符号说明：θ\_sep 是场篇第八的可分阈，判定两冲击能否在场中分开（d(s₁,s₂) \> θ\_sep 则可分）；它不是场篇第一方程3a 的路径出流阈 θ(x)。后者「愈深阈愈小」，指深者更易出流；本篇所论深核密度使 θ\_sep 趋升，指新差异更难分开。二者对象不同，不相冲突。

B\_d(t) 为边界密度：场中活跃边界的密度。其计法须申报（例如单位场测度内的活跃边界数）。

N(t) 为噪声强度。

L(t) 为场 f 于时刻 t 的调谐负载（Tuning Load），表示场当前为维持所有活跃边界的调谐稳定所消耗的总资源量。L 越高，场维持新边界的剩余能力越低。L 随活跃边界数量正向增加，随容积上限 Cap 增大而相对降低。

Cap 为场的调谐容积上限；Cap − L 为剩余容积（注：v1.1 以 C 记容积，但 C 已在场篇第七中定义为局部容量负载 C(x,t)，故本篇改用 Cap）。

Dn(t) 为深核密度：场中深核的密度。其计法须申报（例如沉积度不低于申报门槛 δ\_D 的稳定局部域在场中的测度占比）；本篇不定其唯一计法。

则：θ\_sep(t) 并非常量，其随场状态持续演化。

阈漂移假设（假设 A1，模型假设）：

θ\_sep(t) 趋向升高的条件：

1\. 边界密度 B\_d 升高：域间隔减小，边际相扰增强，调谐负载 L 上升，θ\_sep ↑。  
1\. 噪声强度 N 升高：细分边界更不稳定，θ\_sep ↑。  
1\. 剩余容积 (Cap − L) 下降：场维持新边界的可用资源减少，θ\_sep ↑。

以上三条综合表达为：

B\_d ↑ 或 N ↑ 或 (Cap − L) ↓ ⟹ θ\_sep(t) 趋升

此为本篇申报的方向假设，不是由场篇第八推出的定理。其读法统一为：其他因素相同时，相应量的上述变化使可分阈的变化率增大；阈值是否实际升高，仍由总驱动项的符号决定。其在示范动力方程中的写法见第9节（定理一）。

注：历史本身并不直接提高阈值。历史通过形成深核，深核通过占流与熟径锁定（熟径锁定依式篇第二十 v1.2），进一步提高现实对新差异的维持难度（见第5节、假设 A2）。

1\. 边界互扰

边界并不是彼此独立的。边界越密，则：

\- 域间隔越小；  
\- 边际相扰越强；  
\- 调谐越难稳定；  
\- 噪声越容易渗透。

于是：原本能够稳定存在的边，开始出现弥散、重叠、回压、合并。

因此：边界的增加，并不会无限提升现实精度。在本篇模型中，其他因素相同时，边界密度增大使阈变化率增大（假设 A1），故边界增至某一阶段后，可能开始削弱整体分辨能力。

1\. 深核占流

设 x\_i 为场中局部域位置（直接引用场篇第七的 x：能够形成交叠、竞争、熟径、边沁与核稳定的局部域）。δ(x\_i, t) 为 x\_i 的沉积度（场篇第一定义9；场篇第七 δ(x,t)）。

深核占流分两层：

其一，先后：深者先得其流（外三；场篇第一定律5：在比较条件 C₌ 下，深者不后于浅者满足出流条件；在 C₌ 与 P₁₇ 下严格先满足，定理17）。

其二，进入后的有效输入量：依场篇第七 v1.2，I\_eff = A·σ(G)，其中门控前输入 A 由交叠 M 增强（M 不决定先后，且关于 δ 不必单调），σ(G) = max(G,0)/(max(G,0)+η) 为剩余容量门控。场篇第七定理一：G → 0⁺ 时 I\_eff → 0，G ≤ 0 时 I\_eff = 0。

Flow(x\_i) 表示流向局部域 x\_i 的后续续行流量。本篇采用以下示范形式：

示范假设 H\_F：Flow(x\_i, t) = k\_F·δ(x\_i, t)·σ(G(x\_i, t))，其中 k\_F \> 0 为申报的常系数。

（类别：本篇的示范假设。它不是场篇第七的方程，场篇第七中也无此式；其中「随 δ 增」的部分是对先得流的量化模型，比定律5 的先后结论更强，只在本篇内使用。）

此关系表明：在 k\_F 与 G 相同的比较中，Flow 关于 δ 不减；共同 G \> 0 时，δ 较大者 Flow 严格较大；G ≤ 0 时，Flow 均为 0。G 随沉积状态改变，仅有 G \> 0 不足以推出深者流量较大：例如取 k\_F = Λ = η = 1、ρ = δ（故 G = 1 − δ），则 δ = 0.8 时 G = 0.2、Flow ≈ 0.13333；δ = 0.9 时 G = 0.1、Flow ≈ 0.08182；两者均未饱和，深者流量反而较小。截断：若另申报 δ ≤ δ\_max（δ 有界），则 G → 0 时 Flow ≤ k\_F·δ\_max·σ(G) → 0；没有此有界前提，不能只凭 σ(G) → 0 推出 Flow → 0。场篇第七定理一的门控结论针对有界的门控前输入 A，不能自动移给 k\_F·δ。

因此：先后与流量分开。先后：在比较条件 C₌ 下，深者不后于浅者满足出流条件（定律5）；另满足 P₁₇ 时，才严格先满足（定理17）。先后不推出占有更多流量。流量：在 H\_F 下，k\_F 与 G 相同时关于 δ 不减，共同 G \> 0 时随 δ 严格增大。

故：现实并不会平均维持所有输入；在先后意义上，C₌ 下深核不后于浅者获得续行，另满足 P₁₇ 时严格优先（定律5、定理17）。

1\. 共性扩张

若大量新冲击持续被压入同一深核，则：越来越多细边，开始难以继续维持稳定。因为（依假设 A1、A2，其他因素相同时）：

\- 阈的变化率增大（阈是否实际升高，由总驱动项的符号决定）；  
\- 调谐资源不断消耗；  
\- 边界互扰不断增强。

于是：若可分阈沿实际历史升高（此为额外前提），原本可分的细域不再可分，归为同类（定理三）。它们是否实际合并、细边是否消失、是否并入共核（场篇第一定义15），须另依结构条件认证。

故：在共核结构条件另行成立时，共核覆盖范围扩大。

因此（释义）：现实中稳定呈现的「类」，是场长期压缩后的稳定结果。

1\. 新差异为何困难

若一个新冲击落于旧核附近，则旧核在先后意义上不后于新冲击所在处得流（C₌ 下，定律5；另满足 P₁₇ 时严格先得，定理17；第5节）。于是新差异很难维持自身边界。

新边成立至少须：

d(s\_new, s\_old) \> θ\_sep(t)

（场篇第八可分条件）。近旧核处，因旧核优先占流，新边稳定所需的差异量可能大于 θ\_sep(t)；其裕量多大，本篇未定，登记为待证。否则其差异会被压回旧类。

因此：深核愈多（Dn 愈高），在假设 A2 下，其他因素相同时阈的变化率增大；若阈实际升高（额外前提），新现实愈难形成，因为旧结构会不断扩大自身解释范围。

1\. 分辨塌缩

若 θ\_sep(t) 沿实际历史持续升高（此为额外前提），则越来越多细类开始不高于可分阈。

于是：细类不可分而归为同类。小域是否实际合并、细边是否消失，须另依结构条件认证。

称此为：分辨塌缩。本篇的操作界定是：可分对集合随 θ\_sep 升高而收缩（定理四）。

分辨塌缩之后（释义），现实会越来越趋向：熟径、共核、大类压缩、低分辨结构。

在假设 A2 下，且阈实际升高时，现实越依赖深核，则越难继续维持新裂分。

因此：现实并非总在增加复杂度，现实也会不断回压自身。

1\. 现实震荡

若场持续裂分，则边界不断增加。调谐负载升高，阈的变化率增大；若阈因此实际升高，场开始回压，现实重新压缩。

但压缩之后，新的冲击仍会持续进入场中，新的边界又会生成。

在本篇最低模型中（定理五；常输入、常 c）：若 c ≥ 0，可分阈单向升高，进入单向塌缩；若 c \< 0 且内部平衡存在，平衡附近的轨道可呈阻尼往复（局部结论）；也可能停在下界平衡。这些是列明条件的结果，不是穷尽分类。持续周期振荡不由最低模型给出（只对常输入、完全位于内部区域的轨道证明了无闭轨道）。故「现实始终处于分化、聚流、回压、再裂分之间的动态震荡」不是本篇模型的结论；本篇只给出往复与平衡的条件。

可分动力方程（示范模型，最低可算近似）：

∂θ\_sep/∂t = α\_B·B\_d + α\_N·N − α\_C·(Cap−L) + α\_Dn·Dn

其中 α\_B, α\_N, α\_Dn \> 0（正向驱动θ\_sep 升高），α\_C \> 0（剩余容积正向压低 θ\_sep）。α\_Dn·Dn 项即假设 A2：深核密度对阈变化率的作用为正。

下界约束：θ\_sep(t) ≥ θ\_min \> 0。θ\_min 为本篇申报的统一下界（场篇第八只给 θ\_sep \> 0，不给统一下界）。当 θ\_sep = θ\_min 且右侧之和为负时，取 ∂θ\_sep/∂t = 0，即 θ\_sep 停在 θ\_min，不降至零或负值。

∂B\_d/∂t = μ\_B·I\_in − ν\_B·ψ(θ\_sep)·B\_d

其中 I\_in ≥ 0 为外部冲击输入速率，μ\_B \> 0（输入驱动边界生成），ν\_B \> 0；ψ 连续可微、不减，且 ψ(θ\_min) = ψ\_min \> 0（θ\_sep 升高加速边界退化/合并）（注：v1.1 用 μ、φ，但 μ 已在场篇第四中使用，φ 已在场篇第七中定义为局部分辨竞争函数，故本篇改用 μ\_B、ψ）。

记 c = α\_N·N − α\_C·(Cap−L) + α\_Dn·Dn。在本篇最低模型中，N、L、Dn、Cap 视为给定（其耦合方程留待后续篇章），c 为常数。

两式耦合构成最低动力闭合：裂分（B\_d ↑）→ θ\_sep ↑ → B\_d 加速退化 → 当 B\_d \< −c/α\_B（只在 c \< 0 时可能）时 θ\_sep 趋降 → 新边界重新生成。在列明条件下，可得单向升高、内部平衡附近的局部阻尼往复或下界平衡（定理五）；这不是穷尽分类。精确耦合形式（含 L、Dn 的耦合方程）留待后续篇章建立。

注：本式仅为最低阶近似，不断言所有场必然呈周期振荡。常输入、常 c 下，最低模型没有完全位于内部区域的闭轨道（定理五（c））；时变输入（例如周期输入）驱动的振荡、触及下界的轨道，不在此结论内。在强外扰、强饱和或深核锁死条件下，系统也可能进入单向塌缩或长期低分辨稳态。

1\. 可维持现实

现实并不趋向完整维持。在本篇模型中：持续输入下，累计生成的边界无界增长，而同时维持的边界密度有界（定理六）；故持续生成的裂分，只有趋于零的份额能被同时维持。

因此：现实真正趋向的，并不是最大裂分，而是最大可维持（释义。本篇模型未定义、也未求解最大化问题，故此说未证成）。

于是：现实并非场中全部持续生成差异的完全展开。现实只是：场在有限资源下，所能长期维持的稳定裂分。

1\. 总式

可分动力一般式：

θ\_sep(t) = Θ\[B\_d, N, L, Dn, Cap\](t)

表示 θ\_sep 依赖这些量至时刻 t 为止的历程（依赖记号，不是状态函数）。下列方向标记，依第9节示范方程读作对 ∂θ\_sep/∂t 的作用方向：

其中：

B\_d：边界密度（Boundary Density）。B\_d ↑ → θ\_sep 趋升。  
N：噪声强度（Noise Intensity）。N ↑ → θ\_sep 趋升。  
L：调谐负载（Tuning Load）。L ↑ → θ\_sep 趋升。  
Dn：深核密度（Deep Nucleus Density）。Dn ↑ → θ\_sep 趋升（假设 A2：深核占流增强，新差异更难维持）。注：原版 v1.0 使用 D，但 D 已在场篇第六中定义为稳定差异度 D(s,t)，故本篇改用 Dn。  
Cap：容积上限（Capacity）。Cap ↑ → θ\_sep 趋降（容积越大，越能支撑更多边界）。

以及：

示范假设 H\_F：Flow(x\_i, t) = k\_F·δ(x\_i, t)·σ(G(x\_i, t))；k\_F 与 G 相同时，Flow 关于 δ 不减，共同 G \> 0 时严格增，G ≤ 0 时均为 0；δ 有界时，G → 0 使 Flow 趋于截断。先后另依场篇第一定律5。

因此：在先后意义上，C₌ 下后续流沿深径不后于浅径续行，另满足 P₁₇ 时严格先行（定律5、定理17）；旧结构在此意义上优先承接后续输入。

于是：现实并不是被动呈现的。现实是：场在有限可分能力下，不断压缩、重构与续持中的动态稳定结构。

1\. 定理

以下定理在第9节示范模型与本节所列前提下成立；对 B\_d 与 θ\_sep，假设解存在于所论时段。

定理一：阈漂移速率定理（示范模型内）

在可分动力方程下，当 θ\_sep \> θ\_min 时，∂θ\_sep/∂t 关于 B\_d、N、L、Dn 严格增，关于 Cap 严格减。即 B\_d 升高、N 升高、剩余容积 (Cap−L) 下降或 Dn 升高时，θ\_sep 的变化率增大。

证明要点：由可分动力方程，∂(∂θ\_sep/∂t)/∂B\_d = α\_B \> 0，对 N 为 α\_N \> 0，对 L 为 α\_C \> 0，对 Dn 为 α\_Dn \> 0，对 Cap 为 −α\_C \< 0。∎

本定理只读出变化率的方向；θ\_sep 本身是否升高，取决于右侧之和的正负。A1 规定的是其他因素相同时对阈变化率的作用方向；它与本定理均不保证阈沿实际历史升高。

假设二：深核密度假设（原定理二，本篇模型假设 A2）

深核密度 Dn 对可分阈变化率的作用为正：在示范方程中为 α\_Dn \> 0。它不保证阈沿实际历史升高。

说明（释义链，非证明）：Dn ↑（场中深核增多）→ 深核不后于浅者得流（场篇第一定律5，C₌ 下；另满足 P₁₇ 时严格先得，定理17），先后不推出流量更多；流量多少依 H\_F：k\_F、G 相同时关于 δ 不减，共同 G \> 0 时严格增 → 新冲击的迹应更易被旧核吸收 → 新差异 d(s\_new, s\_old) 更难超过 θ\_sep(t) 而成立。此链中「旧核吸收」与「可分阈升高」之间的环节没有被推出，故以假设申报。

定理三：可分对收缩定理（示范模型内；原共性扩张定理）

设冲击对集合 P 中各对的差异量 d(s₁,s₂) 在 \[t₀, t₁\] 上固定，且 θ\_sep 在 \[t₀, t₁\] 上不减。记可分对集合 S(t) = {(s₁,s₂) ∈ P : d(s₁,s₂) \> θ\_sep(t)}。则 S(t₁) ⊆ S(t₀)；满足 θ\_sep(t₀) \< d(s₁,s₂) ≤ θ\_sep(t₁) 的对，在 t₀ 可分，在 t₁ 不可分而归为同类。

证明要点：若 d \> θ\_sep(t₁)，则 d \> θ\_sep(t₁) ≥ θ\_sep(t₀)；其余由场篇第八可分条件（d \> θ\_sep ⟺ 可分）直接读出。∎

本定理只给出细边不可分而归为同类；「大量新冲击压入同一深核 → θ\_sep 升高」除假设 A1、A2 外，还须总驱动项为正、阈沿实际历史升高这一额外条件；细域是否并入共核、共核覆盖是否扩大，须另依场篇第一定义15 的结构条件认证。

定理四：分辨塌缩定理（示范模型内）

在定理三的前提下，设解存在于 \[t₀, ∞)，θ\_sep(t) 在 \[t₀, ∞) 上不减。记长期可分集 S\_∞ = ∩\_{t ≥ t₀} S(t)。（a）若 θ\_sep(t) → θ\_∞ \< ∞：d \> θ\_∞ 的对一直可分，属于 S\_∞；d \< θ\_∞ 的对最终不可分；d = θ\_∞ 的对，若对一切 t 有 θ\_sep(t) \< θ\_∞（阈从下方逼近），则在每个有限时刻可分，属于 S\_∞，若有 T 使 θ\_sep(T) = θ\_∞，则自 T 起不可分。故 S\_∞ ⊇ {d \> θ\_∞}，二者只在 d = θ\_∞ 的对上可能不同：长期可分集未必等于把极限阈值代入判定所得的集合。（b）若 θ\_sep(t) → ∞，则对任一有限 P，存在 T 使 t ≥ T 时 S(t) 为空，即 P 中细类全部不可分。

证明要点：（a）d \> θ\_∞ 时，d \> θ\_∞ ≥ θ\_sep(t) 对一切 t 成立；d \< θ\_∞ 时，由收敛存在 T 使 θ\_sep(T) \> d，此后由单调性 θ\_sep(t) ≥ θ\_sep(T) \> d；d = θ\_∞ 的两种情形由场篇第八可分条件直接读出。例：θ\_sep(t) = 2 − e^(−t)，d = 2，则此对在每个有限时刻可分，却不属于 {d \> 2}。（b）P 有限，取 d\_max = max d；θ\_sep → ∞ 时存在 T 使 θ\_sep(T) ≥ d\_max。∎

本定理以长期可分集的收缩界定分辨塌缩；它只给出不可分而归为同类，小域实际合并、细边物理消失另依结构条件认证。v1.1 证明中「场篇第七退化项主导、细边 δ 持续下降」不由本篇模型推出，已删去。

定理五：最低模型的平衡与往复定理（示范模型内；原现实震荡定理）

在第9节最低模型中，设 c 为常数，I\_in \> 0 为常数；涉及 t → ∞ 的结论，设解存在于 \[0, ∞)。

（a）若 c ≥ 0：对 B\_d \> 0，∂θ\_sep/∂t \> 0，θ\_sep 严格单调升高，无内部平衡；若 c \> 0，θ\_sep(t) ≥ θ\_sep(0) + c·t → ∞（单向塌缩，结合定理四）。

（b）若 c \< 0：记 B\* = −c/α\_B \> 0。若存在 θ\* \> θ\_min 使 ψ(θ\*) = μ\_B·I\_in/(ν\_B·B\*)，且 ψ′(θ\*) \> 0，则 (θ\*, B\*) 是内部平衡，且局部渐近稳定（局部结论，不是任意初态的全局收敛）；当 (ν\_B·ψ(θ\*))² \< 4·α\_B·ν\_B·ψ′(θ\*)·B\* 时，平衡为稳定焦点，邻近轨道呈阻尼往复（裂分与回压交替而振幅衰减）。c \< 0 本身不保证内部平衡存在，也不保证一切轨道阻尼往复。

（c）在区域 {θ\_sep \> θ\_min, B\_d \> 0} 内，最低模型（常输入、常 c）没有闭轨道，即不存在完全落于该区域的持续周期振荡。此结论不覆盖时变输入（例如周期输入）驱动的振荡，也不覆盖触及下界的轨道。

（d）下界平衡：记 B\_m = μ\_B·I\_in/(ν\_B·ψ\_min)。若 α\_B·B\_m + c ≤ 0，则 (θ\_min, B\_m) 是下界上的平衡：θ\_sep 停在 θ\_min（依下界取法），B\_d = B\_m。例：θ\_min = 0.1，ψ(θ) = θ，α\_B = μ\_B = ν\_B = I\_in = 1，c = −20，则 B\_m = 10，α\_B·B\_m + c = −10 ≤ 0，(0.1, 10) 是下界平衡，既非阻尼往复，也非单向升高。

证明要点：（a）∂θ\_sep/∂t = α\_B·B\_d + c \> 0；c \> 0 时积分即得。（b）平衡条件为 α\_B·B\* + c = 0 与 μ\_B·I\_in = ν\_B·ψ(θ\*)·B\*。雅可比矩阵为 \[\[0, α\_B\], \[−ν\_B·ψ′(θ\*)·B\*, −ν\_B·ψ(θ\*)\]\]，迹为 −ν\_B·ψ(θ\*) \< 0，行列式为 α\_B·ν\_B·ψ′(θ\*)·B\* \> 0，故局部渐近稳定；特征值为复数的条件即迹² \< 4·行列式。（c）向量场的散度为 ∂/∂θ\_sep(α\_B·B\_d + c) + ∂/∂B\_d(μ\_B·I\_in − ν\_B·ψ(θ\_sep)·B\_d) = −ν\_B·ψ(θ\_sep) \< 0；该区域单连通，由 Bendixson 判据，区域内无闭轨道。∎

故「场不会停留于绝对统一或无限裂分，而始终处于动态震荡」不由最低模型推出。最低模型在所列条件下给出：单向升高（a）；内部平衡附近的局部阻尼往复（b）；下界平衡（d）。这不是对全部轨道的穷尽分类：c \< 0 时内部平衡可不存在，全局收敛未证，时变输入下的行为未论。持续震荡须另立耦合（L、Dn 的方程等），登记为待证。

定理六：边界密度有界定理（示范模型内；原可维持现实定理）

设 0 ≤ I\_in(t) ≤ Ī\_in，B\_d(0) ≥ 0，θ\_sep ≥ θ\_min，ψ 不减且 ψ(θ\_min) = ψ\_min \> 0。则：

（a）在解存在的范围内，对一切 t ≥ 0，0 ≤ B\_d(t) ≤ max( B\_d(0), μ\_B·Ī\_in/(ν\_B·ψ\_min) )。

（b）记累计生成量 Γ(t) = ∫₀ᵗ μ\_B·I\_in(s)ds。若解存在于 \[0, ∞)，且另有 I\_in(t) ≥ I\_low \> 0，则 Γ(t) → ∞，而 B\_d(t)/(B\_d(0) + Γ(t)) → 0：累计生成的边界中，同时维持的份额趋于零。

证明要点：（a）B\_d = 0 时 ∂B\_d/∂t = μ\_B·I\_in ≥ 0，故 B\_d 保持非负；由 ψ(θ\_sep) ≥ ψ\_min 得 ∂B\_d/∂t ≤ μ\_B·Ī\_in − ν\_B·ψ\_min·B\_d，由比较原理即得。（b）Γ(t) ≥ μ\_B·I\_low·t → ∞，分子由（a）有界。∎

本定理在模型内给出「场不能同时维持全部持续生成的裂分」；「现实趋向最大可维持裂分」是解释性观点，本篇模型未定义、也未求解最大化问题，故未证成。v1.1 证明中「B\_d → ∞ → L → C → θ\_sep 持续升高」与本模型不合（模型中 B\_d 有界），已删去。
