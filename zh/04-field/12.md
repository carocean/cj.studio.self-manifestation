自显论·场篇第十二 v1.2

# 场分辨率方程

1\. 目的

前篇已经建立：

\- 熟径如何形成；  
\- 熟径如何竞争；  
\- 偏流如何稳定；  
\- 历史如何形成路径依赖。

但此前仍未真正说明：为什么场不能无限分化。

为什么：

\- 有些差异能够继续形成细分；  
\- 有些差异最终只能并入旧域；  
\- 有些域能够不断生成新结构；  
\- 有些域最终无法继续分化。

因为：差异存在，并不意味着场仍能够继续稳定维持这些差异。

因此本篇讨论：场如何形成分辨率。以及：域为什么会达到分辨率极限。

《数论》中说：「其冲不绝，而场有物理之限，域须有相错之隙，至再无相错之隙，则达分辨之上限，故称此上限曰：场之容积。」此为全场层面的分辨上限（场篇第一定义30 Cap(F)）；本篇讨论其在域层的表现。

1\. 核心命题

本篇所论的分辨率余量，并不表示信息多少，也不表示观察是否细腻。

场篇第一定义29 的分辨率 Res(F) 表示单位体积中可差分辨之域数，依《数论》：「单位体积所可差分分辨之域数，曰分辨率。」本篇不改此定义，而在域层另立分辨率余量。

分辨率余量表示的是：一个域在既有沉积、交叠与调谐条件下，还能继续稳定维持多少新增差分。

因此（本篇拟议的读法）：若新差异进入之后，场仍能够稳定维持其独立差分，则该差异能够继续形成新的细分。反之，若场已经无法继续稳定维持新的独立差分，则新增差异不能作为新增细分维持，其主要去向是被压缩并域（其他去向见定理一）。

因此：本篇所论的分辨率余量，是域对新增差分的稳定维持余量；它不替代 Res(F)，其下降也不等于场篇第一定义34 的 LossRes。

1\. 分辨率余量

设：

SDC\_f(t) 为域 f 在时刻 t 的稳定差分维持能力（Stable Differentiation Capacity）。注：原版 v1.0 使用 C\_f(t)，但 C 已在场篇第七中定义为局部容量负载 C(x,t) = ∫W(x−y)δ(y,t)dy，故本篇改用 SDC\_f(t)。SDC\_f 按申报单位计量（例如以稳定差分关系的数目计），读作：在保持域内既有稳定差分不变的条件下，域 f 所能稳定维持的差分上限。

S\_f(t) 为域 f 在时刻 t 的压缩饱和度（Compression Saturation），表示域内已被熟径压缩、共核固化、闭包锁定的结构所占据的差分维持量。S\_f 与 SDC\_f 采用同一申报单位（若以比例表示，SDC\_f 须作同一归一化）；每增一项稳定差分，S\_f 增加一个正量 u。v1.1 称 S\_f 为「分辨率比例」而与 SDC\_f 相减，二者单位未统一，本版补此申报。

与场篇第七 ρ(x,t) 的关系：ρ(x,t) 是场篇第七局部分辨占用方程 ρ(x,t) = ∫K(x−y)δ(y,t)dy 所定义的局部分辨占压。S\_f 不由 ρ 定义；本篇只取方向读法（假设）：在申报的聚合下，域内 ρ 越高（邻域沉积占压越强），S\_f 趋向越高。两者层次不同：ρ 在空间点层，S\_f 在域层；其定量关系本篇未立。

则：

R\_f(t) = SDC\_f(t) − S\_f(t)

称 R\_f(t) 为该域的分辨率余量。

与场篇第七 G(x,t) 的层次关系：场篇第七的剩余分辨容量 G(x,t) = Λ(x) − ρ(x,t) 是空间层的剩余容量（即局部域位置 x 还能吸收多少新差异的空间度量）；G ≤ 0 在场篇第七称为容量满，不是场篇第一定义20 的域满。本篇的 R\_f(t) = SDC\_f(t) − S\_f(t) 是差分层的分辨率余量（即域 f 还能稳定维持多少新增差分关系的结构度量）。两者方向读法一致（G 充裕、R\_f \> 0 皆表示尚有余量），但层次不同：G 在空间点层，R\_f 在域层。v1.1 称「G 是 R\_f 的空间层前提——G → 0 时 R\_f 也趋向 ≤ 0」；本篇未建立 G 与 R\_f 的定量关系，此句撤回，若需要须另立聚合关系后再证。

与场篇第八 θ\_sep 的对接：场篇第八的可分阈 θ\_sep 是场当前的可分阈（d(s₁,s₂) \> θ\_sep 则可分）。本篇拟议域内有效可分阈 θ\_sep,f，作域 f 内部差异成立的局部条件；它不是场篇第八已定义的量，不等同于全场 θ\_sep，单域 SDC\_f 也不直接决定全场 θ\_sep。本篇的方向假设 H\_θ：其他条件相同时，SDC\_f 越高，θ\_sep,f 趋向越低（域内差异更容易成立）；SDC\_f 下降时，θ\_sep,f 趋向升高。此为假设，不由场篇第八推出；可分性下降亦不等于阈值升高（场篇第八 v1.2 定理五）。

因此（读法，见定理一）：

若 R\_f(t) \> 0，则域 f 尚有差分维持余量；新增差分能否形成新的稳定细分，还须另满足可分条件与维持条件。

若 R\_f(t) ≤ 0，则在固定预算比较下（见定理一），该域不能在保持既有差分全部不变的同时继续稳定维持新的差分，本篇称此为：余量耗尽。

与场篇第一定义20 域满的关系：《数论》中说：「若有交叠之域而不可再深，则其域不可再分，其不可再入分辨，谓之域满。」定义20 要求不可再深、不可再分、不可再入分辨三者共同成立。余量耗尽只表示：在本篇申报的预算与比较条件下，不能在保持既有差分全部不变的同时继续新增稳定差分；它仍允许置换、重组等其他去向。它不替代定义20 中「不可再分、不可再入分辨」的结构判定；这两项与「不可再深」均须另验（不可再深可参场篇第一定义19 之沁，而沁亦不等于域满）。即使另有不可再深，也不能仅凭 R\_f ≤ 0 认证域满。v1.1 将 R\_f ≤ 0 径称为域满，本版改称余量耗尽。

1\. 差分形成

设域 f 内已经存在 fa₁、fa₂、fa₃。此时新差异 fa₄ 进入。

若 R\_f(t) \> 0，且 fa₄ 与各既有差分满足场篇第八可分条件 d(fa₄, fa\_i) \> θ\_sep，则 fa₄ 可能形成新的细分；其能否长期维持，另依维持条件判定（定理一）。

若 R\_f(t) ≤ 0，则在固定预算比较下、保持既有差分不变时，场已经无法继续稳定维持新的差分关系；本篇讨论的主要情形是 fa₄ 逐渐被压缩进入既有差分结构（其他去向见定理一）。

因此：差分并不是天然存在的。差分是：场长期稳定维持之后，所形成的持续差分结构。

1\. 分辨率之满

若 R\_f(t) ≤ 0，则在固定预算比较下，新增差分已经无法在保持既有差分不变的同时于域内形成新的稳定细分。本篇拟议：此时新增差异不断被压缩，未被吸收的部分逐渐积聚于边界附近（积聚须另申报存留与释放机制）。在场篇第七示范模型中，与此对应的是容量门控挡下的未吸收输入 R（G → 0 或 G ≤ 0 时 R 接近或等于 A），而不是局部源项剩余 O。

因此：分辨率之满（余量耗尽），并不是信息太多，也不是结构太多，而是场已经无法继续稳定维持新的差分。

1\. 边沁形成

R\_f(t) ≤ 0 且新增差分持续进入，不单独推出 P\_Δ 随时间增加。压力如何变化，依其定义（见下）及输入、门控、边界权重的变化判断：例如边界上的 A、G、ω 保持不变时，P\_Δ 可以恒定。边界积聚须另申报存留与释放机制。

设：

P\_Δ(f,t) 为域 f 在时刻 t 的边界差分压力，表示域内无法被吸收的新增差分在边界附近的强度。本篇以场篇第七的未吸收输入 R(x,t) = A·(1 − σ(G(x,t))) 在域 f 边界上的加权积分定义：

P\_Δ(f,t) = ∫\_{∂f} ω(x)·R(x,t) dS

其中 ω(x) ≥ 0 为边界位置 x 处的申报权重函数（反映局部边界的调谐稳定性与导流方向），dS 为边界面元；ω 与边界读取范围须预先申报。P\_Δ(f,t) ≥ 0，其单位由 R 与 ω 的申报单位决定，B\_f 须采用同一单位。若要表示积聚，可另申报窗口积分 ∫\_{t−W}^{t} P\_Δ(f,s) ds，比较时取同一口径。v1.1 以场篇第七 O(x,t)（v1.1 称「结构剩余」，场篇第七 v1.2 定名局部源项剩余）定义 P\_Δ，并以 ∝ 处理量纲；依场篇第七 v1.2，容量满处 I\_eff = 0，若 B\_out 亦为 0 则 O = 0，O 不用作转移判据，未被吸收的是 R。本版改以 R 定义，以等号代替比例。

B\_f(t) 为域 f 在时刻 t 的边界可稳定压缩承载限，表示边界结构在当前调谐状态下能够稳定压缩吸收的最大边界差分压力（与 P\_Δ 同一单位）。B\_f(t) \> 0，其依赖记为：

B\_f(t) = Ψ(L\_f(t), B\_d(f,t), R\_f(t))

其中 L\_f(t) 为域 f 的调谐负载，B\_d(f,t) 为域 f 的边界密度：场篇第九 v1.2 的 L(t)、B\_d(t) 是场层量，本篇的域层读数须另申报其聚合或计法。R\_f(t) 为分辨率余量。方向假设 H\_Ψ：L\_f 越高 → B\_f 越低；B\_d 越高 → B\_f 越低（边界间相扰增强）；R\_f 越低 → B\_f 越低。此为本篇假设，不由场篇第九推出。精确函数形式 Ψ 留待后续篇章建立。

则（判据二，边沁候选条件）：

R\_f(t) ≤ 0 ∧ P\_Δ(f,t) \> B\_f(t) ⇒ 边沁候选

《数论》中说：「故边沁不过某域之边界线束之阈，则不生某之边沁。」本篇以 P\_Δ \> B\_f 作越过边界线束之阈的操作读法：P\_Δ ≤ B\_f 时不立边沁候选；P\_Δ \> B\_f 只给出候选。边沁（场篇第一定义21，B(𝒟)=1）的认证另须：域满已经成立（定义20，不只是余量耗尽）；新增迹应继续进入且不可继续内沉；沿域边界外溢；生成新结构位。

因此：边沁并不是随机溢出（场篇第一定义21：边沁不是随机扩散）。本篇拟议：边沁是域内余量耗尽之后，差分压力越过边界承载限、向边界外裂的结果；其认证依定义21。

1\. 边沁与新结构

本篇拟议：边沁发生之后，原本无法在旧域内部稳定维持的新差异，开始沿边界之外形成新的稳定差分。《数论》中说：「故边沁作，则细类生。」

于是（拟议）：新细类开始形成；新域、新熟径、新结构可能相继出现。新域须依场篇第一定义8 之五项稳定条件认证；新结构位依定义21；新熟径依定义13；场篇第七判据五（邻域沉积度持续增长）只是成域候选条件。

因此（释义，依场篇第一「边沁连属相继，则新结构位生成」）：新结构并不是凭空生成。新结构是：旧域无法继续稳定维持新增差分之后，差分向外裂开的结果。

1\. 分辨率与熟径

若某熟径长期占据大量后续流（此为前提；场篇第十一 v1.2 定理一熟径先出只给出比较条件下出流的先后，不给出长期流量份额），则本篇拟议：既有差分结构会越来越稳定，与此同时新增差分越来越难被稳定维持。

本篇以假设 H\_S 表达：其他驱动不变时，熟径加深（路径沉积度统计 δ̄ 升高，场篇第十一 v1.2）使 S\_f(t) 增加。在 H\_S 与 SDC\_f 不变的比较下，δ̄ 升高时 R\_f(t) 下降（命题三）。v1.1「熟径越强，压缩稳定性越强，于是 S\_f(t) 上升越快，R\_f(t) 下降越快」改为此条件陈述；上升「越快」的速率比较，本篇未证。

于是（释义）：场越倾向于维持旧压缩结构，而难以继续形成新细分。

1\. 分辨率塌缩

若：熟径长期稳定；新差异长期被压缩；边界长期无法继续外裂；调谐不断粗化；则本篇拟议：场能够稳定维持的新差分开始逐渐减少，与此同时旧压缩结构不断增强。

于是（拟议）：SDC\_f(t) 下降，S\_f(t) 上升；二者若在申报窗口内成立，则 R\_f(t) 在该窗口内持续下降（定理四）。

称 R\_f(t) 在申报窗口内持续下降为：分辨率塌缩（本篇的操作界定）。

说明：分辨率塌缩与场篇第九 v1.2 的分辨塌缩（以长期可分集 S\_∞ 的收缩界定）不同，也不是场篇第一定义34 的 LossRes。持续下降不推出余量耗尽，也不推出场篇第九意义的分辨塌缩或 LossRes。

1\. 分辨率恢复

若：旧熟径开始裂解；旧压缩关系开始松动；边界重新活化；调谐重新细化；则本篇拟议：场重新获得稳定维持新增差分的能力。

于是（拟议）：原本会被压缩并域的差异，在 R\_f 回升且满足可分条件与维持条件时，开始能够稳定形成新的细分。

因此（拟议）：SDC\_f(t) 上升，S\_f(t) 下降，R\_f(t) 回升（定理五）。

称 R\_f(t) 在申报窗口内回升为：分辨率恢复（本篇的操作界定）。依场篇第一定义34，场释放负载并不必然恢复稳定分辨；R\_f 回升不等于稳定分辨已经恢复。

1\. 动力方程

场分辨率动力式：

dR\_f/dt = dSDC\_f/dt − dS\_f/dt

并且（由上式直接读出）：

dS\_f/dt \> dSDC\_f/dt ⇒ 分辨率余量下降

dSDC\_f/dt \> dS\_f/dt ⇒ 分辨率余量上升

其中（拟议的定性对应，各方向为本篇假设）：

dSDC\_f/dt 上升来自：调谐细化（对应场篇第九 L↓，域层读数另申报）；边界重组（对应场篇第九 B\_d↓，域层读数另申报）；熟径裂解（对应场篇第十一 v1.2 熟径资格丧失或 δ̄ 下降，定理二）；旧压缩关系松动（对应场篇第十 LoopCoupling↓）。

dS\_f/dt 上升来自：熟径固化（对应场篇第十一 v1.2 δ̄ 加深；续行竞争的综合占优另由 CI 度量，CI 不是熟度）；共核压缩加深（共核依场篇第一方程7，积深对应场篇第七 δ）；闭包锁定（对应场篇第十 InternalReentry 增强，依其假设 H\_IR）；差分交叠加重（对应场篇第七 M(x,t) 升高）。

最低可算近似说明：本篇动力方程描述 R\_f(t) 的演化方向，各项驱动力均为定性对应，方向为假设。精确耦合函数（将场篇第七 δ、M、σ(G)，场篇第八 θ\_sep 与本篇 θ\_sep,f，场篇第九 L、B\_d，场篇第十 LoopCoupling，场篇第十一 δ̄、CI 等量代入 dSDC\_f/dt 和 dS\_f/dt）留待后续篇章建立。

压缩—余量耗尽—边沁闭环（拟议）：

S\_f ↑ ⇒ R\_f ↓（限 SDC\_f 不变的比较）

R\_f ↓ ⇒ P\_Δ ↑（另立假设）

R\_f ≤ 0 ∧ P\_Δ \> B\_f ⇒ 边沁候选（判据二）⇒ 边沁、新结构（须另认证）

此闭环为拟议链：第一环在 SDC\_f 不变的比较下由定义读出；第二环（R\_f 下降是否使 P\_Δ 增加）为另立假设，本篇未立 R\_f 与边界未吸收输入 R 的定量关系；第三环只在 R\_f ≤ 0 且 P\_Δ \> B\_f 两条件同时成立时依判据二成立候选——P\_Δ 增加而仍不超过 B\_f，或 R\_f 尚未耗尽，均不成立候选；实际边沁依场篇第一定义21 与方程10、新结构依定义8 另行认证。新结构再生成新熟径与新压缩、使链首尾相接，是本篇依《数论》「边沁连属相继，核与边相交替」所作的释义。v1.1 的「边沁概率」未定义，撤去；「统一了第8节（熟径）、第9节（塌缩）、第6-7节（边沁与新结构）的动力关联」改为：此链把第6至9节的拟议串联起来。

1\. 总式

场分辨率一般式：

R\_f(t) = SDC\_f(t) − S\_f(t)

其中 R\_f 为分辨率余量，SDC\_f 为稳定差分维持能力，S\_f 为压缩饱和度。

并且（读法与条件陈述）：

R\_f 下降，只表示余量减少，不保证趋于零或达到余量耗尽；满足定理四的统一下降速率下界及有效区间条件时，才有其所列耗尽时限

R\_f ≤ 0 ∧ P\_Δ \> B\_f ⇒ 边沁候选（判据二；边沁之认证依场篇第一定义21，域满依定义20）

熟径↑（δ̄↑）⇒ S\_f ↑ ⇒ R\_f ↓（依 H\_S，SDC\_f 不变的比较）

调谐细化↑ ⇒ SDC\_f ↑ ⇒ R\_f ↑（方向假设，S\_f 不变的比较）

因此（读法）：分辨率余量越大，域就越能够继续稳定维持新增差分；分辨率余量越小，新增差异就越容易被压缩并域。

因此（释义）：现实中的类、边界与新结构，并不是天然存在的，而是场在有限分辨率下，长期稳定维持与压缩差分之后形成的结果。

1\. 定理

定理一：分辨率余量的必要条件定理（固定预算比较下）

设 SDC\_f 与 S\_f 采用同一申报单位，SDC\_f 读作在保持域内既有稳定差分不变的条件下域 f 所能稳定维持的差分上限。本定理采用固定预算比较：固定域 f、计量单位及其他条件；新增前后 SDC\_f 不变，既有占用不释放、不重估，新增差分使占用由 S\_f 变为 S\_f + u（u \> 0）；申报的合法维持条件为 S\_f + u ≤ SDC\_f。（a）若在此比较下新差异 fa₄ 在既有差分全部保持不变的同时作为新增稳定差分在域 f 内成立，则新增前 R\_f(t) ≥ u \> 0；故新增前 R\_f(t) ≤ 0 时，在此比较下不能如此成立。（b）R\_f(t) ≥ u 不是充分条件：fa₄ 形成新细分，另须与各既有差分满足场篇第八可分条件 d(fa₄, fa\_i) \> θ\_sep，且其维持另验。

证明要点：在固定预算比较下，若 fa₄ 在既有差分保持不变的同时作为新增稳定差分成立，则占用由 S\_f 变为 S\_f + u，而 SDC\_f 不变；由申报的合法维持条件 S\_f + u ≤ SDC\_f，得新增前 R\_f = SDC\_f − S\_f ≥ u \> 0；其逆否即（a）后半。不充分：若 R\_f ≥ u 而 d(fa₄, fa\_i) ≤ θ\_sep，则二者不满足该判据下的两两可分条件，fa₄ 不成为新细分；反之，若 d \> θ\_sep 而 R\_f ≤ 0，则二者两两可分，而在此比较下不能在既有差分保持时作为新增差分维持。故 R\_f 与可分条件互不蕴含。∎

说明：（a）只排除「既有差分全部保持不变」下的新增。R\_f ≤ 0 时 fa₄ 的去向——并入既有结构、置换既有差分、外溢为边沁候选或退化消散——须另判，本篇讨论的主要情形是并入。新增过程中容量变化或既有占用重组，不在本比较之内，另判：例如新增前 SDC\_f = S\_f = 2，新增过程中容量升至 3，新增占用为 1，旧差分全部保留——此时新增成立，而新增前 R\_f = 0，与本定理不冲突，因其不满足固定预算比较。场篇第八的两两不可分关系，未经额外分类规则，不当作完整的同类关系。v1.1 定理一「R\_f(t) ≤ 0 时新增差分被压缩并域，域满发生」与「对应场篇第八 d(fa₄, fa\_i) \> θ\_sep 成立」撤回：前者把一种去向写成唯一结局，并把余量耗尽当作域满；后者把两个独立条件写成对应。

判据二：边沁候选判据

本篇以「R\_f(t) ≤ 0 且 P\_Δ(f,t) \> B\_f(t)」作为域 f 发生边沁的候选条件，为《数论》「故边沁不过某域之边界线束之阈，则不生某之边沁」的操作读法：P\_Δ ≤ B\_f 时不立候选。

说明：此为申报条件，不是由上游推出的定理。边沁的认证依场篇第一定义21（B(𝒟)=1）与方程10（边沁生成方程）：域满已经成立（定义20，不只是余量耗尽）；新增迹应继续进入且不可继续内沉；沿域边界外溢；生成新结构位。场篇第七 v1.2 第7节的邻域转移只是边沁的候选实现机制，不是认证。v1.1 定理二的证明（「新增差分对应场篇第七 O(x,t) \> 0（结构剩余）在边界积累」「与场篇第七第13节边沁机制一致」）撤回：依场篇第七 v1.2，容量满处若 B\_out 为 0 则 O = 0，未被吸收的是 R；场篇第七并无已证的边沁机制。

命题三：熟径压制分辨率余量（依 H\_S）

设假设 H\_S 成立：其他驱动不变时，熟径的路径沉积度统计 δ̄（场篇第十一 v1.2）升高使 S\_f(t) 增加。则在 SDC\_f 不变的比较下，δ̄ 升高时 R\_f(t) 下降，场越难维持新增差分。

证明要点：由 H\_S，S\_f 增加；SDC\_f 不变，由 R\_f = SDC\_f − S\_f 即得。∎

说明：本命题的实质内容全在 H\_S。v1.1 证明链撤回：（i）场篇第十一 v1.2 定理一为熟径先出定理（依桥接假设 H\_δ），只给比较条件下出流的先后，不给持续占流；（ii）「新增差分难以获得足够 I\_eff」依场篇第七 v1.2 不成立：I\_eff = A·σ(G) 由交叠与剩余容量门控决定，交叠不定先后（场篇第八 v1.2 定理五已撤回同类推论）；（iii）「新增差分无法超过 θ\_sep」：可分性下降不等于阈值升高，旧核压制为场篇第八之假设 H\_occ，其机制未证。Familiarity 依场篇第十一 v1.2 改记：熟的比较依 δ̄，续行竞争的综合占优另由续行竞争指数族 CI 度量，CI 不是熟度。

定理四：余量下降定理（分辨率塌缩的条件）

设 SDC\_f、S\_f 在 \[t₀, t₁\] 上可微。（a）若在 \[t₀, t₁\] 上 dS\_f/dt \> dSDC\_f/dt，则 R\_f 在 \[t₀, t₁\] 上严格下降，即该窗口内发生本篇意义的分辨率塌缩。（b）若进而在 \[t₀, t₁\] 上 dS\_f/dt − dSDC\_f/dt ≥ c \> 0，则 R\_f(t) ≤ R\_f(t₀) − c(t − t₀)；当 R\_f(t₀) \> 0 且 t₁ ≥ t₀ + R\_f(t₀)/c 时，R\_f 至迟于 t₀ + R\_f(t₀)/c 达到余量耗尽（R\_f ≤ 0）。

证明要点：dR\_f/dt = dSDC\_f/dt − dS\_f/dt。（a）dR\_f/dt \< 0 于 \[t₀, t₁\]，由中值定理 R\_f 严格下降。（b）令 g(t) = R\_f(t) + ct，则在 \[t₀, t₁\] 上 g′(t) = dSDC\_f/dt − dS\_f/dt + c ≤ 0；由中值定理 g 不增，故 R\_f(t) ≤ R\_f(t₀) − c(t − t₀)，令 t = t₀ + R\_f(t₀)/c 即得。∎

说明：只有逐点 dS\_f/dt \> dSDC\_f/dt 时，R\_f 严格下降但不必达到余量耗尽：例如 R\_f(t) = 1 + e^{−t}（t ≥ 0），严格下降而恒大于 1。严格下降不推出趋于零，有下界也不保证达到下界。本定理不推出场篇第九的分辨塌缩（长期可分集收缩）或场篇第一的 LossRes；「场趋向低分辨结构」为释义。

定理五：余量回升定理（分辨率恢复的条件）

设 SDC\_f、S\_f 在 \[t₀, t₁\] 上可微。（a）若在 \[t₀, t₁\] 上 dSDC\_f/dt \> dS\_f/dt，则 R\_f 在 \[t₀, t₁\] 上严格上升，即该窗口内发生本篇意义的分辨率恢复。（b）若进而在 \[t₀, t₁\] 上 dSDC\_f/dt − dS\_f/dt ≥ c \> 0，且 R\_f(t₀) \< u，则当 t₁ ≥ t₀ + (u − R\_f(t₀))/c 时，R\_f 至迟于 t₀ + (u − R\_f(t₀))/c 达到 u（定理一之必要条件）。

证明要点：与定理四同理，符号相反；（b）对 h(t) = R\_f(t) − ct 应用中值定理，h′ ≥ 0，h 不减。∎

说明：R\_f 回升至 u 以上只满足定理一的必要条件；原本被压缩的差异能否重新成为新细分，另依可分条件与维持条件。逐点条件同样不保证达到 u（反例同定理四，符号相反）。v1.1 证明中「旧熟径裂解（场篇第十定理六）→ LoopCoupling↓ → S\_f↓」撤回：场篇第十 v1.2 已将原定理六改为命题六（闭包裂解，拟议诱因），LoopCoupling↓ 使 S\_f↓ 是本篇第11节的方向假设。依场篇第一定义34，R\_f 回升不等于稳定分辨已经恢复。

命题六：边沁生成新结构（拟议）

边沁发生后，溢出差分可能在域外形成新的稳定差分结构，新细类、新域、新熟径可能相继出现。

说明：此为拟议，依《数论》「故边沁作，则细类生」。v1.1 证明链改订如下：（i）溢出差分的去向，在场篇第七示范模型中对应未吸收输入 R 经转移核 T 的邻域转移 B\_out（场篇第七第7节，候选实现机制），不是分辨流 J；J 是既有沉积的迁移流，不承载未吸收输入。（ii）邻域 R\_{f′} \> 0 与可分条件只给出定理一的必要条件。（iii）邻域 ∂δ/∂t \> 0 持续超过 τc 是场篇第七判据五（成域候选的增长条件），v1.1 引作「场篇第七定理五」，不能单独认证新域；新域依场篇第一定义8 之五项稳定条件，新结构位依定义21。（iv）新熟径依场篇第一定义13 与场篇第十一 v1.2 定理二判定；v1.1 所引「熟径优先机制」在场篇第十一 v1.2 中为定理一（熟径先出，依 H\_δ），只给出流先后，不推出新熟径必然增长。
