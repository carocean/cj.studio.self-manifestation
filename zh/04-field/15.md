自显论·场篇第十五 v1.2

# 场容积方程

1\. 目的

前篇已经建立：

\- 分辨率为何下降；  
\- 沁叠为何增长；  
\- 压缩候选在何种条件下成立（场篇第十三 v1.2）；  
\- 边沁候选在何种条件下成立（场篇第十二 v1.2）。

但此前仍未真正说明：为什么有些场更容易压缩、更容易失稳、更容易边沁，而有些场能长期维持高分辨率、多重共核、复杂续延。

本篇以场篇第一定律20 的容积有限为前提（场容积有限，稳定差分域不可无限安置），研究有效续延域的开放程度及其变化，不由该前提反推无限开放情形下各机制必然消失。v1.1「若场只是无限开放，则分辨率不会下降，压缩不会增强，边沁不会发生，稳定现实不会形成」为未证的反事实判断，撤回。

因此：场内部存在可被续延、分辨、调谐、压缩与维续的有效域限。称此为：场容积。《数论》中说：「其冲不绝，而场有物理之限，域须有相错之隙，至再无相错之隙，则达分辨之上限，故称此上限曰：场之容积。」场篇第一定义30 记全场容积为 Cap(F)；本篇讨论其在域层的读法（第3节）。

并且：场真正决定性的，不是总容积，而是可继续维持新续延的有效容积率。

因此本篇讨论：场容积率为何会下降。以及（拟议）：容积率下降与压缩、固化、熟径锁定、分辨率下降、边沁之间的关系。

1\. 核心命题

场并不是无限可续延的空域。

本篇拟议：场中的熟径、共核、压缩、沁叠、深积，都会持续占据有效续延域。

因此（拟议）：场虽然仍存在总域，但真正可供新续延稳定形成的域量会不断下降。

因此：场真正的问题不是”存在多少东西”，而是还剩多少可继续续延的新域。

本篇拟议：有效续延域的开放程度会影响场的稳定与失稳；本篇不以对象数量或容积率单独给出稳定判定。

1\. 场容积

设：

Cap\_f 为域 f 的可维续场容积（Field Capacity），表示该场中可同时稳定维持多个独立续延结构的有效域总量。注：原版 v1.0 使用 V\_f(t)，但 V 已在场篇第十四中定义为续延势 V\_i（Vitality），故本篇改用 Cap\_f。与场篇第一定义30 的关系：本篇取 Cap\_f 为 Cap(F) 在域 f 上的局部读法，Cap\_f = ∫\_f Res(x)dVol（场篇第一定义30 之非均匀形式），以域数计。依场篇第一定义33，Cap 可随 Res、Vol 变化；本篇申报 H\_Cap：在所论比较窗口内 Cap\_f 视为常数（v1.1 径写「常数」，今改为申报），且 0 \< Cap\_f \< ∞；Cap\_f = 0 时不使用 φ\_f、Use\_f 等比值。

A\_f(t) 为域 f 在时刻 t 仍可继续开放新续延的有效续延容积，定义为：仍可支持新续延稳定生成，且不会立即被既有熟径、共核或压缩结构吸收的开放场域，与 Cap\_f 同一单位（以域数计）。

则：A\_f(t) ≤ Cap\_f（有效续延容积不超过总场容积，A\_f(t) ≥ 0）。

与场篇第七 G(x,t) 的层次关系：场篇第七的剩余分辨容量 G(x,t) = Λ(x) − ρ(x,t) 是空间点层的剩余容量，G ≤ 0 称为容量满；本篇的 A\_f(t) 是域层的有效续延容积。两者方向读法一致（G 充裕、A\_f 较大皆表示尚有余量），但层次不同。v1.1 称 A\_f 是「对 G(x,t) 在域 f 范围内的聚合度量」，二者的定量关系本篇未立，此句改为方向读法。

与场篇第十二 R\_f(t) 的层次关系：场篇第十二 v1.2 的分辨率余量 R\_f(t) = SDC\_f − S\_f 是差分层的度量；本篇的 A\_f(t) 是续延域层的容积度量。本篇的方向假设 H\_φR：其他条件相同时，A\_f 较高对应 R\_f 较高。v1.1「A\_f 是空间层前提，R\_f 是差分层结果」未证，撤回（场篇第十二 v1.2 已撤回同类的「G 是 R\_f 的空间层前提」）。

1\. 沁叠占域

设：

OccItr\_f(t) 为域 f 在时刻 t 的沁叠占域（Occupied Interpenetration），表示由沁叠过程产生并在场中稳定占据有效续延域的结构性残留。注：原版 v1.0 使用 I\_f(t)，但 I 已在场篇第七中定义为脉冲输入 I(x,t)，故本篇改用 OccItr\_f(t)。OccItr\_f(t) ≥ 0，对应场篇第十四 Itr\_f(t) 在域层形成的稳定占域成分；其计法须申报。沁叠不同于场篇第一定义19 之沁（结构位内沉到底）。

1\. 容积率

φ\_f(t) = A\_f(t) / Cap\_f

称为剩余容积率（Residual Capacity Ratio）。注：原版 v1.0 使用 ρ\_f(t)，但 ρ 已在场篇第七中定义为局部分辨占压 ρ(x,t) = ∫K(x−y)δ(y,t)dy，故本篇改用 φ\_f(t)。φ\_f 与场篇第七的局部分辨竞争函数 φ(·) 不同，以下标 f 与时间变量区分。φ\_f(t) ∈ \[0,1\]。

与外篇第三《数论》「容积用量」的关系：《数论》中说：「场之己用之域数与其容积之比为容积用量。」场篇第一定义33 记为 Use(F) = UsedDomains(F)/Cap(F)，且 Use 可大于 1（超容积）。本篇若申报 H\_A：A\_f = max(0, Cap\_f − UsedDomains\_f)（UsedDomains\_f 为域 f 内的已用域数），则 φ\_f(t) = max(0, 1 − Use\_f(t))：Use\_f ≤ 1 时二者加总为 1，Use\_f \> 1 时 φ\_f = 0。不申报 H\_A 时，本篇未建立容积用量与剩余容积率的必然联动：UsedDomains\_f 与 A\_f 的定义并不保证二者反向变化，相关方向须另行申报比较条件与假设。v1.1 径写「φ\_f(t) = 1 − 容积用量(f,t)」，未计 Use \> 1 的情形，且 A\_f 的定义（不会立即被既有结构吸收的开放域）不自动等于未用之域，本版改为上述条件式。《数论》又说：「超出其容积，则不可加事物之旁系，不可探于新奇，因固于其所执」——本篇以之对应 φ\_f → 0 时第9节固执机制与第10节创造力下降（释义）。

容积率表示：场中仍可生成新续延的比例。

φ\_f(t) 高时（拟议）：场中仍存在大量未被深积锁定的开放续延域，新续延更容易分辨、稳定、延展、调谐、共核化。

φ\_f(t) 低时（拟议）：场越来越倾向复用旧续延，而不是形成新续延。

1\. 容积率下降

容积率下降来源于（拟议）：熟径加深；沁叠增长；压缩增强；深积累积；调谐固化。

其本质为（拟议）：既有续延结构持续优先占据有效续延域。

动力关系（示范模型，本篇的模型选择）：

dφ\_f(t)/dt = F\_f(t)，F\_f(t) = −b\_S·S\_f(t) − b\_O·OccItr\_f(t) − b\_K·K\_f(t) + α\_f(t)（0 \< φ\_f \< 1 时）

边界规则：φ\_f = 0 时 dφ\_f/dt = max(F\_f, 0)；φ\_f = 1 时 dφ\_f/dt = min(F\_f, 0)，使 φ\_f 保持于 \[0,1\]。

解的意义（申报）：驱动项可测、局部可积；解为绝对连续函数，几乎处处满足上式及边界规则；下文定理中的符号条件按几乎处处读取。

与 H\_A 并用的相容条件：H\_A 与本动力式同时采用时，须另检验同一历史中的相容性。UsedDomains\_f 持续超过 Cap\_f 时，H\_A 要求 φ\_f 保持为 0，不能仅凭正向恢复项便判定开放容积已经出现：例如 Cap\_f = 10、UsedDomains\_f = 12 持续不变，H\_A 要求 φ\_f 始终为 0，而若 F\_f = 1，边界规则却令 φ\_f 立即上升。在 0 \< φ\_f \< 1 且 H\_Cap 成立的区间，同时采用 H\_A 须有 dUsedDomains\_f/dt = −Cap\_f·F\_f。本篇未独立建立已用域数的动力学，不将两套关系视为自动相容。

符号说明：b\_S、b\_O、b\_K ≥ 0 为申报的换算系数，使 S\_f（差分维持量，场篇第十二 v1.2）、OccItr\_f（占域计法）与 K\_f（∈ \[0,1\]，场篇第十三 v1.2）换算为容积率的变化速率；v1.1 写作 dφ\_f/dt ∝ −S\_f − OccItr\_f − K\_f + α\_f，三项单位各异而直接相加，本版补此申报。方向（本篇假设）：其他驱动及换算系数固定时，S\_f、OccItr\_f 或 K\_f 增大使 F\_f 不增（对应旧结构占域、沁叠残留、压缩固化增多）；这不保证净变化已经为负，也不保证在边界处继续下降；系数为零时，该项没有影响。α\_f(t) ≥ 0 为正向恢复项，对应调谐细化、熟径裂解、沁叠裂解或边沁后新域开放等使有效续延域重新增加的过程（拟议对应；场篇第十二 v1.2 定理五为余量回升，场篇第十四沁叠裂解依其现版）。本式以占域诸量的水平驱动 φ\_f 的变化率；若要以占用直接扣减 A\_f，须另立静态式。F\_f \< 0 时，φ\_f 在尚未达到 0 的区间严格下降，达到 0 后在该符号条件持续成立时停留于 0；F\_f \> 0 的情形对称：在尚未达到 1 的区间严格上升，达到 1 后停留于 1。逐点严格符号不保证有限时间到达边界（定理一、五）。v1.1「在正常深积累积过程中，α\_f 通常不足以抵消三项负向驱动，故 φ\_f 长期趋向下降」为未证的经验判断，改为拟议：F\_f 的符号依各项实际取值。

1\. 分辨率关系

R\_f(t) 表示域在场篇第十二 v1.2 所申报的预算条件下，继续维持新增稳定差分的余量；它不是分辨细度，也不替代 Res(F)（场篇第一定义29）或可分阈 θ\_sep。

φ\_f(t) 与 R\_f(t) 相关但不等价（φ\_f 在续延域层，R\_f 在差分层）。

φ\_f(t) ↓ ⇒ R\_f(t) ↓（依假设 H\_φR，H\_Cap 下、其他条件固定的比较；命题二）。余量下降不得直接读成实际分辨率下降。

1\. 容积率与压缩

φ\_f(t) ↓ ∧ S\_f(t) \> 0 ⇒ K\_f(t) ↑（拟议；须经场篇第十三 v1.2 的条件：P\_eff \> SDC\_f 且 K\_f \< 1；命题三）

即（拟议）：当有效续延域减少且旧结构压缩饱和度不为零时，压缩强度可能增强；实际增长依场篇第十三 v1.2 第4节示范模型判定，压缩须另经场篇第一定义35 认证。

1\. 固执机制

本篇拟议：φ\_f(t) 长期下降后，场倾向使用旧续延解释新输入：旧熟径吸收新输入；旧共核改写新结构；旧压缩覆盖新续延；旧现实重释新进入。熟径锁定的判定依式篇第二十 v1.2 定义六（熟径、各子段后流独先、依赖沉积差）。

1\. 创造力条件

本篇拟议：高创造状态对应场仍允许大量新续延长期独立存在（φ\_f(t) 较高）。新调谐、新分辨、新共核、新压缩路径更容易形成。

1\. 边沁机制

本篇拟议：φ\_f(t) 持续下降时，新续延难以稳定进入场内，沁叠持续积深并强化边界收束；当旧压缩结构无法继续吸收新增续延时，边界压力可能积累。后续流一部分可能被既有熟径吸收；边沁候选依场篇第十二 v1.2 判据二（R\_f ≤ 0 且 P\_Δ \> B\_f 同时成立），认证依场篇第一定义21 与方程10。依场篇第一定律21，超载释放可表现为压缩、边沁、失分辨或组合，本节只讨论其中的边沁路径。

1\. 动力方程

场容积动力式（示范模型）：

dφ\_f(t)/dt = −b\_S·S\_f(t) − b\_O·OccItr\_f(t) − b\_K·K\_f(t) + α\_f(t)（0 \< φ\_f \< 1；边界规则见第6节）

并且（拟议）：

φ\_f(t) ↓ ⇒ 新续延生成失败率 ↑

φ\_f(t) ↓ ⇒ R\_f(t) ↓（依 H\_φR）

φ\_f(t) ↓ ∧ S\_f(t) \> 0 ⇒ K\_f(t) ↑（须 P\_eff \> SDC\_f 且 K\_f \< 1）

φ\_f(t) ↓ ⇒ 熟径锁定增强（熟径锁定依式篇第二十 v1.2 定义六判定）

1\. 总式

场容积动力一般式（拟议链）：

深积增长 ⇒ A\_f(t) ↓

A\_f(t) ↓ ⇒ φ\_f(t) ↓

φ\_f(t) ↓ ⇒ 新续延生成困难

新续延生成困难 ⇒ 后续流被既有熟径吸收

后续流被吸收 ⇒ 现实锁定增强

现实锁定增强 ⇒ 熟径加深与沁叠增强

沁叠与压缩增强 ⇒ φ\_f(t) 继续下降（拟议的正反馈：旧结构增强进一步压低容积率；本篇未证此链加速）

φ\_f(t) 持续下降 ∧ R\_f(t) ≤ 0 ∧ P\_Δ \> B\_f ⇒ 边沁候选（场篇第十二 v1.2 判据二；认证依场篇第一定义21、方程10）

场真正的限制不在对象数量，而在可持续开放新续延的有效域容量（释义，依场篇第一定律20）。

所谓固执、僵化、现实锁定与创造力下降，本篇释义为场容积率长期下降后的结构结果（依《数论》「超出其容积……因固于其所执」）；本篇不证明其为唯一成因。

1\. 定理

定理一：容积率下降定理（示范模型内）

设第6节示范模型成立，φ\_f(t₀) ∈ \[0,1\]，解在 \[t₀, t₁\] 上存在。（a）若在 \[t₀, t₁\] 上 F\_f ≤ 0，则 φ\_f 在 \[t₀, t₁\] 上单调不增；若 F\_f ≤ 0 对一切 t ≥ t₀ 成立且解全局存在，则 φ\_f 收敛。（b）若进而在 \[t₀, t₁\] 上 b\_S·S\_f + b\_O·OccItr\_f + b\_K·K\_f − α\_f ≥ c \> 0，则 φ\_f(t) ≤ max(0, φ\_f(t₀) − c(t − t₀))；当 t₁ ≥ t₀ + φ\_f(t₀)/c 时，φ\_f 至迟于 t₀ + φ\_f(t₀)/c 降至 0。

证明要点：（a）由解的意义，φ\_f(t) − φ\_f(s) = ∫\_s^t φ\_f′ dτ；内部 φ\_f′ = F\_f ≤ 0，在 φ\_f = 0 处 φ\_f′ = max(F\_f, 0) = 0，在 φ\_f = 1 处 φ\_f′ = min(F\_f, 0) ≤ 0，几乎处处 φ\_f′ ≤ 0，故 φ\_f 不增；单调有界即收敛。（b）在尚未达到 0 的区间上，φ\_f′ = F\_f ≤ −c 几乎处处，积分比较得 φ\_f(t) ≤ φ\_f(t₀) − c(t − t₀)；φ\_f 一旦为 0，由边界规则（max(F\_f, 0) = 0）停留于 0。∎

说明：只有逐点 F\_f \< 0 时，φ\_f 在尚未达到 0 的区间严格下降，但不保证有限时间降至 0（例如 φ\_f(t) = (1 + e^{−t})/4，t ≥ 0）；φ\_f 已为 0 时，边界规则令其停留，并不严格下降；F\_f ≤ 0 时 φ\_f 虽收敛，其极限也不必为 0。v1.1 定理一（场容积率下降必然性定理）撤回：（i）「α\_f 通常不足以抵消三项负向驱动」是未证判断，F\_f 的符号依实际取值；（ii）所引「场篇第十二熟径压制分辨率定理」今为场篇第十二 v1.2 命题三（依 H\_S）；「场篇第十三压缩必然性定理」今为场篇第十三 v1.2 判据一（压缩候选，非必然）；「场篇第十四沁叠必然性定理」依场篇第十四现版，本篇不据以推出 OccItr\_f 必然上升；（iii）「φ\_f 单调下降至稳定点（当三项负向驱动与 α\_f 趋向均衡时）」改为（a）：F\_f ≤ 0 时单调有界而收敛，极限是否为 F\_f = 0 的平衡另证。

命题二：容积率与分辨率联动（依 H\_φR）

在假设 H\_φR 下，于 H\_Cap 成立、其他条件固定的比较中，φ\_f(t) 下降对应 R\_f(t) 趋向下降。余量下降不得直接读成实际分辨率下降。

说明：本命题的实质内容全在 H\_φR。v1.1 证明链撤回：「A\_f ↓（有效续延域减少）→ G(x,t) 在域 f 内整体趋降（场篇第七空间层前提）」——A\_f 与 G 的定量关系未立，「空间层前提」已由场篇第十二 v1.2 撤回；「SDC\_f 相对 S\_f 余量收缩」须另立 A\_f 与 SDC\_f、S\_f 的关系；所引「场篇第十二分辨率余量定理」在场篇第十二 v1.2 中为定理一（余量的必要条件，固定预算比较下），不给出与 φ\_f 的联动。

命题三：容积率与压缩联动（拟议）

φ\_f(t) 下降且 S\_f \> 0 时，K\_f 可能上升。

说明：此为拟议。依场篇第十三 v1.2，K\_f 在其示范模型中增长须 P\_eff \> SDC\_f 且 K\_f \< 1；P\_s \> SDC\_f 只给压缩候选（判据一），压缩须另经场篇第一定义35 认证。本篇另须假设：A\_f 减少使差分交叠上升、从而 P\_s 升高（H\_AP），本篇未证。v1.1 所引「场篇第十三压缩必然性定理」今为判据一，不是必然；「S\_f \> 0 保证……使压缩进一步加速」未证，撤回。

命题四：熟径锁定（拟议）

φ\_f(t) 长期下降时，新输入可能更多被既有熟径吸收，场趋向熟径锁定，新续延越来越难稳定形成。

说明：此为拟议；熟径锁定的判定依式篇第二十 v1.2 定义六（熟径、各子段后流独先、依赖沉积差），本篇不由 φ\_f 下降单独推出。v1.1 证明链撤回：（i）「高 Familiarity 的熟径」依场篇第十一 v1.2 改记：熟的比较依路径沉积度统计 δ̄，续行竞争的综合占优另由 CI 度量，CI 不是熟度；（ii）所引「场篇第十一熟径优先定理」在场篇第十一 v1.2 中为定理一（熟径先出，依桥接假设 H\_δ），只给比较条件下出流的先后，不给吸收份额；（iii）「场篇第十一现实保守定理」在场篇第十一 v1.2 中为释义（熟径与现实保守），不是定理。

定理五：容积率回升定理（示范模型内）

设第6节示范模型成立，φ\_f(t₀) ∈ \[0,1\]，解在 \[t₀, t₁\] 上存在。（a）若在 \[t₀, t₁\] 上 F\_f ≥ 0，则 φ\_f 单调不减。（b）若进而在 \[t₀, t₁\] 上 α\_f − (b\_S·S\_f + b\_O·OccItr\_f + b\_K·K\_f) ≥ c \> 0，则 φ\_f(t) ≥ min(1, φ\_f(t₀) + c(t − t₀))。

证明要点：与定理一同理，符号相反；（b）在尚未达到 1 的区间上，φ\_f′ = F\_f ≥ c 几乎处处，积分比较得 φ\_f(t) ≥ φ\_f(t₀) + c(t − t₀)；φ\_f 一旦为 1，由边界规则（min(F\_f, 0) = 0）停留于 1。∎

说明：v1.1 的条件「S\_f + OccItr\_f + K\_f \< α\_f」三项单位各异，今改为加权条件。「新续延重新可稳定形成」「R\_f 趋升（场篇第十二分辨率恢复定理）」为拟议：后者今为场篇第十二 v1.2 定理五（余量回升），与 φ\_f 的联动依 H\_φR；R\_f 回升也不等于稳定分辨已经恢复（场篇第一定义34）。只有逐点 F\_f \> 0 时，φ\_f 在尚未达到 1 的区间严格上升，但不保证有限时间升至 1；φ\_f 已为 1 时，边界规则令其停留，并不严格上升。

命题六：场容积与边沁（拟议）

φ\_f(t) 持续下降，若伴随 R\_f(t) ≤ 0 且 P\_Δ \> B\_f，则依场篇第十二 v1.2 判据二成立边沁候选；本篇拟议场容积率下降是边沁的一种前因。

说明：边沁候选须 R\_f ≤ 0 与 P\_Δ \> B\_f 同时成立，认证依场篇第一定义21 与方程10（域满已经成立、新增迹应不可继续内沉、沿域边界外溢、生成新结构位）；依场篇第一定律21，超载释放亦可为压缩、失分辨或组合。v1.1 证明链改订：「P\_Δ ↑（场篇第十二边界差分压力随 R\_f 下降而上升）」在场篇第十二 v1.2 中为另立假设，R\_f 下降不单独推出 P\_Δ 增加；所引「场篇第十二边沁触发定理」今为判据二；「场篇第十四沁叠驱动压缩定理」依场篇第十四现版；「K\_f ↑ → S\_f ↑」依场篇第十三 v1.2 第3节之方向读法（假设）；「边沁后邻域开放新域，φ\_{f’}(t) 升高」为拟议，新域依场篇第一定义8 认证。
