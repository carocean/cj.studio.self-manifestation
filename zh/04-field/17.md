自显论·场篇第十七 v1.1

# 场间耦合

1\. 目的

前十六篇建立的是单一场（域 f）的内部动力：

\- 沉积如何形成；  
\- 熟径如何加深；  
\- 压缩候选在何种条件下成立（场篇第十三 v1.2）；  
\- 容积率如何下降（场篇第十五 v1.2）；  
\- 势动力如何生成。

但前十六篇有一个隐含假设：所有动力发生在同一场内部。

现实中的场从不孤立。

神经沉积场与意象场之间存在持续的续流传递；意向场与语言场之间存在结构映射；个体场与社会场之间存在长期的共核对齐与张力。

本篇的出发观点（释义）：以下现象都涉及场与场之间的动力关联：

\- 个体之间形成共识；  
\- 语言携带意义；  
\- 技能跨场迁移；  
\- 文化沉积与传承。

本篇研究这种关联，不由此断言缺少耦合时上述现象必然不能发生。

因此本篇讨论：场与场之间如何形成耦合，耦合的条件是什么，耦合的方向为何不对称，以及耦合失败与强耦合各自导向什么结果。

1\. 核心命题

场间耦合不是信号简单地从一个场流入另一个场。

本篇拟议：耦合成立，需要接收场能够识别、容纳并稳定维持来自发送场的续流结构；若接收场的分辨率、调谐状态、熟径结构与输入信号不兼容，则续流进入接收场后难以稳定沉积，耦合难以成立。

因此（本篇的界定）：

耦合不是传输，而是结构兼容后的稳定续流传递。

并且：

场间耦合按方向分别定义：Cpl(f\_A → f\_B) 与 Cpl(f\_B → f\_A) 是两个量。

f\_A → f\_B 成立，不意味着 f\_B → f\_A 成立。

本篇拟议：两场之间的耦合方向与强度，取决于各自的 θ\_sep、K\_f、φ\_f 与熟径结构，而非对称的物理连接。第6节示范模型的兼容度只含 φ、MatchTheta 与熟径重合度，K\_f 的作用为拟议。

1\. 耦合算子

设 f\_A 与 f\_B 为两个不同的域。

定义：

Cpl(f\_A → f\_B, t)

为从域 f\_A 到域 f\_B 在时刻 t 的场间耦合强度（Field Coupling Intensity）。

Cpl(f\_A → f\_B, t) ≥ 0。

Cpl = 0 表示 f\_A 对 f\_B 无有效耦合；Cpl 越高，f\_A 的续流结构在 f\_B 中越能稳定沉积并形成持续影响（读法）。Cpl 的单位与读取方式须申报。

注：Cpl(f\_A → f\_B, t) 与 Cpl(f\_B → f\_A, t) 一般不相等（有向不对称，见第5节）。

1\. 耦合成立条件

本篇以下列四项刻画耦合的条件；在第6节示范模型中，由零开始的耦合成立的精确条件见定理一：

条件一：续流输出条件

f\_A 存在向外的续流输出。OutFlow(f\_A, t) 的示范拆解（本篇的模型选择）：

OutFlow(f\_A, t) = α·P\_Δ(f\_A, t) + β·Press(f\_A→f\_B, t) + γ·Rc(f\_A, t)

其中：  
α·P\_Δ(f\_A, t)：f\_A 的边界差分压力所对应的被动输出（场篇第十二 v1.2：P\_Δ 为未吸收输入 R 的边界加权积分）；它不是边沁本身，边沁候选依场篇第十二判据二，认证依场篇第一定义21 与方程10；α ≥ 0；  
β·Press(f\_A→f\_B, t)：f\_A 对 f\_B 的主动续流压入；场篇第十六 v1.2 的 Press(f,p,t) 是续流 f 压入续行位 p 的二值判定，本篇的 Press(f\_A→f\_B, t) 是其在场间的聚合读数，计法须申报；β ≥ 0；  
γ·Rc(f\_A, t)：f\_A 重续稳定后的持续输出；场篇第十六 v1.2 的 Rc 是重续结构，本篇的 Rc(f\_A, t) 是其输出强度读数，计法须申报；γ ≥ 0。

α、β、γ 为申报的换算系数，使三项换算为同一输出单位。三项之和 OutFlow ≥ 0。若 f\_A 三项均为零（无边界差分压力输出、无主动压入、无重续输出），则 OutFlow = 0。

注：此拆解为第十九篇场的层级结构中 Transfer(f^n-1→f^n) 算子提供输入来源的明确定义。

条件二：分辨率兼容条件

本篇以 f\_B 的剩余容积率 φ\_{f\_B}(t) \> 0（场篇第十五 v1.2）表示接收场尚有开放续延域，并要求 f\_A 输出的续流结构在 f\_B 的可分辨范围内。场篇第十二 v1.2 的分辨率余量 R\_{f\_B} 不进入第6节的兼容度；R\_{f\_B} 与 φ\_{f\_B} 的联动依场篇第十五 v1.2 的假设 H\_φR，二者不互推。

本篇拟议：若 f\_B 余量耗尽（R\_{f\_B} ≤ 0，场篇第十二 v1.2；余量耗尽不等于场篇第一定义20 之域满），普通输入时 f\_B 难以容纳新结构，输入多被旧熟径吸收，Cpl 趋降；此读法不在示范模型内，模型中只有 φ\_{f\_B} 下降才降低兼容度。例外（拟议）：当 OutFlow(f\_A, t) \> T\_replace（申报的旧熟径裂解阈值）时，强输入可能触发 f\_B 的旧熟径裂解（场篇第十四沁叠裂解机制，依其现版），R\_{f\_B} 局部回升，耦合可重新成立；边沁候选与认证另依场篇第十二判据二、场篇第一定义21 与方程10。示例（释义）：强烈的教育冲击、认知范式革命、心理创伤后的结构重组。

条件三：调谐兼容条件

f\_A 输出信号的结构特征与 f\_B 的可分阈 θ\_sep(f\_B, t) 兼容（场篇第八 v1.2：d \> θ\_sep 则可分）。

可分性须针对申报的比较对象，依场篇第八 v1.2 的差异量 d 与 θ\_sep 判断（d \> θ\_sep 则可分），不能直接以未说明比较对象的信号幅度替代。MatchTheta 的读取规则须另行申报。若本模型进一步规定不满足该可分条件时 MatchTheta = 0，则相应时段 Compat = 0，不产生新增耦合驱动；已有 Cpl 仍依动力式演化，不立即归零。若整段历史驱动均为零且初值为零，才可据定理一判定未建立耦合。

本篇拟议：若 f\_A 的输出信号差分结构与 f\_B 的调谐焦点完全不重叠，信号进入 f\_B 后可能迅速消退，新增耦合驱动难以产生。

条件四：熟径重合条件

f\_A 输出的续流结构与 f\_B 既有熟径存在部分匹配。熟径依场篇第一定义13；熟的比较依场篇第十一 v1.2 的路径沉积度统计 δ̄，续行竞争的综合占优另由 CI 度量，CI 不是熟度。FamOverlap(f\_A, f\_B, t) ∈ \[0,1\] 为申报的熟径重合度，其计法须申报。v1.0 写作「既有熟径 Familiarity(q\_i, t)」，依场篇第十一 v1.2 改记。

本篇拟议：完全无熟径重合的输入，在 f\_B 中难以找到既有沉积锚点；但当 φ\_{f\_B} 较高且 MatchTheta 兼容时，f\_B 可以自发形成新锚点（新沉积核）接纳陌生输入，耦合以较低强度成立。

因此本节定义有效熟径重合度：

FamOverlap\_eff(f\_A, f\_B, t) = max(FamOverlap(f\_A, f\_B, t), ε · φ\_{f\_B}(t) · MatchTheta(f\_A, f\_B, t))

其中 ε ∈ (0,1) 为新锚形成系数（申报的示范系数），表示在既有熟径完全陌生时，f\_B 凭借剩余容积率和调谐兼容度自发形成新锚的能力。ε 小表示新锚形成困难，ε 大表示 f\_B 对陌生输入的开放性高。ε 项是陌生输入获得正兼容读数的示范模型选择；其正值不认证实际新锚、沉积核或熟径已经形成，这些结构是否生成并稳定维持，须另依相应结构条件检验（熟径依场篇第一定义13，域依定义8）。

Compat 定义更新为：Compat(f\_A, f\_B, t) = φ\_{f\_B}(t) · MatchTheta(f\_A, f\_B, t) · FamOverlap\_eff(f\_A, f\_B, t)

注（释义）：此条件解释了为何学习新知识需要旧知识的锚点（FamOverlap 主导项），以及为何完全陌生的领域仍可以缓慢进入（ε 项）——后者对应场篇第十八中场的生成初期无熟径时的最低耦合路径。

四个条件的关系（示范模型内，见定理一）：由零开始，耦合成立须在正测度时段内 OutFlow \> 0、φ\_{f\_B} \> 0、MatchTheta \> 0 同时成立；此时 FamOverlap\_eff ≥ ε·φ\_{f\_B}·MatchTheta \> 0 自动成立。已有耦合在输入中断后不立即为零，而按 Decay\_C 衰减（定理四；Decay\_C = 0 时不衰减）。v1.0「条件一为必要前提，条件二至四共同决定耦合强度。缺少任一条件，Cpl(f\_A → f\_B, t) 趋向零」改为此式。

1\. 有向不对称

Cpl(f\_A → f\_B, t) 与 Cpl(f\_B → f\_A, t) 一般不相等（命题二）

原因：两个方向的兼容度使用不同的接收场参数（φ\_{f\_B} 与 φ\_{f\_A} 等），两向输出也各不相同；两场的 θ\_sep、R\_f、K\_f、φ\_f 与熟径结构一般不对称。

具体分析：

本篇拟议（示范模型的兼容度不含 K\_f）：若 f\_A 的 K\_{f\_A} 高（高度压缩，结构抽象），而 f\_B 的 K\_{f\_B} 低（结构具体），则 f\_A → f\_B 的耦合强度可能低（抽象结构在具体场中难以找到熟径锚点），而 f\_B → f\_A 的耦合强度可能较高（具体细节进入高压缩场可能被迅速归入既有共核）。

本篇拟议：K\_{f\_A} ≫ K\_{f\_B} 时，f\_A → f\_B 方向可能存在显著的层间传递损耗（TransferLoss(f\_A→f\_B) ↑），即高压缩场向低压缩场的输出在接收场中难以展开为可分辨的独立差分。此规律为第十九篇场的层级结构中层间损耗算子 Λ(f^n-1, f^n) 的来源之一。

由兼容度读出：若 f\_B 的 φ\_{f\_B} 低（容积接近耗尽），则 f\_A → f\_B 的兼容度低；而 φ\_{f\_A} 高时，f\_B → f\_A 的兼容度可能仍然较高。

本篇拟议：若 f\_A 的熟径结构与 f\_B 的调谐焦点不重叠，则 f\_A → f\_B 耦合极弱；但若 f\_B 存在专门的界门焦点（续行位依场篇第十六 v1.2 定义四），接收 f\_A 类型的输入，则方向差异会更显著。

因此（拟议）：单向耦合强、反向耦合弱的情形常见；本篇不证明其为场间耦合的常态。

示例（释义）：语言场 → 意向场的耦合（语言影响意图）与意向场 → 语言场的耦合（意图驱动语言），方向和强度均不对等。情感场 → 认知场的影响往往强于认知场 → 情感场的影响，原因可能在于两场的 θ\_sep 与 K\_f 的不对称。

1\. 耦合动力方程

示范动力式（本篇的模型选择）：

dCpl(f\_A → f\_B, t)/dt = a·OutFlow(f\_A, t)·Compat(f\_A, f\_B, t) − Decay\_C·Cpl(f\_A → f\_B, t)

其中 a \> 0 为申报常数；OutFlow、Compat 非负、可测、局部可积；解为绝对连续函数，几乎处处满足上式。v1.0 的「∝」改为常数 a。

其中：

OutFlow(f\_A, t)（输出流强度）：f\_A 向 f\_B 的续流输出强度，对应条件一。OutFlow ≥ 0。

Compat(f\_A, f\_B, t)（结构兼容度）：f\_A 输出结构与 f\_B 接收结构的综合兼容程度，对应条件二至四的综合量。

Compat(f\_A, f\_B, t) = φ\_{f\_B}(t) · MatchTheta(f\_A, f\_B, t) · FamOverlap\_eff(f\_A, f\_B, t)

其中：  
φ\_{f\_B}(t)：f\_B 的剩余容积率（直接引用场篇第十五 v1.2 φ\_f = A\_f/Cap\_f），∈ \[0,1\]。注：此处不以 R\_{f\_B}/Cap\_{f\_B} 代替，因二者层次与单位不同；φ\_{f\_B} 与 R\_{f\_B} 的联动依场篇第十五 v1.2 的假设 H\_φR，φ\_{f\_B} 不是二者关系的综合量。v1.0「φ\_{f\_B} 是两者关系在域层已综合后的正确量」撤回；  
MatchTheta(f\_A, f\_B, t)：f\_A 输出与 f\_B 的 θ\_sep 匹配度（场篇第八），∈ \[0,1\]，计法须申报；  
FamOverlap\_eff(f\_A, f\_B, t)：有效熟径重合度（条件四），∈ \[0,1\]；φ\_{f\_B} \> 0 且 MatchTheta \> 0 时由新锚形成项 ε·φ\_{f\_B}·MatchTheta 保底，大于 0；φ\_{f\_B} = 0 或 MatchTheta = 0 时可为 0。保底项的正值是模型评分，不是结构生成的证明；定理一证明的是该模型中 Cpl 由零转正，不兼作新锚生成定理。v1.0 写作 ∈ (0,1\]、「不为零」，与第8节情形四不合，本版改正。

Decay\_C ≥ 0 为耦合衰减率（申报常数）。本篇拟议其对应场质（场篇第一定义28）：《数论》中说：「场质，所以决遗忘之速也。非有之则场易满；满则速失于可分辨。」Decay\_C \> 0 时，输入停止后耦合强度衰减（定理四）；Decay\_C = 0 时不衰减。

因此（读法）：耦合不是静态的连接；Decay\_C \> 0 时，它是需要持续续流维持的动力关系；本模型允许 Decay\_C = 0，此时已有耦合在无输入时自行保持。

1\. 耦合失败

Cpl(f\_A → f\_B, t) → 0 的条件。以下区分兼容度下降、驱动消失与耦合趋零：兼容度趋零本身不保证 OutFlow·Compat 趋零（OutFlow 只要求局部可积，可随时间增大）；已有耦合是否衰减，还须检查驱动乘积及 Decay\_C。例如 φ\_{f\_B} = 1、FamOverlap = 1、MatchTheta = 1/(1 + t)、OutFlow = 1 + t，则 Compat 趋零而 OutFlow·Compat 恒为 1；取 a = Decay\_C = 1、零初值，Cpl = 1 − e^{−t} 趋于 1。

情形一（输出中断）：OutFlow(f\_A, t) = 0。f\_A 停止向 f\_B 输出，Decay\_C \> 0 时耦合按指数衰减趋于零（定理四）。示例（释义）：长期不使用的跨场技能退化；语言不用则失；社会联系中断。

情形二（余量耗尽阻断，拟议）：R\_{f\_B} ≤ 0。本篇拟议 f\_B 难以容纳新输入，f\_A 的输出多被旧熟径吸收，不形成新的耦合结构；此情形不在示范模型内，模型中由 φ\_{f\_B} → 0 表示（见情形四及定理一）。示例（释义）：固执状态下他人的新信息无法真正进入；过度压缩的认知场对新输入不可渗透。

情形三（调谐不兼容）：MatchTheta(f\_A, f\_B, t) → 0。f\_A 与 f\_B 的调谐焦点完全不重叠，兼容度趋零（由兼容度读出）；输入与申报比较对象不满足 d \> θ\_sep 的可分条件，或进入 f\_B 后迅速消退（拟议）。若另有 OutFlow 有界，则兼容度趋零可推出驱动乘积趋零；进一步在 Decay\_C \> 0 时，Cpl → 0（定理四（c））；Decay\_C = 0 时不作此结论。示例（释义）：语言无法表达感觉（意向场与语言场调谐不兼容）；儿童无法理解高度抽象概念（调谐发育未到位）。

情形四（无熟径锚点且新锚不可成）：FamOverlap(f\_A, f\_B, t) → 0 且 ε·φ\_{f\_B}·MatchTheta → 0（例如 φ\_{f\_B} → 0 或 MatchTheta → 0；乘积趋零不要求某一因子自身趋零，二者可交替为零），使 FamOverlap\_eff → 0。若另有 OutFlow 有界，则驱动乘积趋零；进一步在 Decay\_C \> 0 时，Cpl → 0（定理四（c））；Decay\_C = 0 时不作此结论。示例（释义）：完全陌生的知识领域在 f\_B 容积耗尽或调谐完全不兼容时无法进入；跨文化交流中既无熟径重合、又无开放容积的根本性障碍。

1\. 强耦合

称 Cpl(f\_A → f\_B, t) \> T\_cpl（申报阈值）的状态为强耦合（本篇的操作界定）。

强耦合的结构后果（拟议）：

f\_A 的续流结构在 f\_B 中可能形成深度沉积，f\_B 的熟径可能向 f\_A 的结构靠拢（FamOverlap 上升；假设 H\_T，见命题三）。

本篇拟议：f\_A 与 f\_B 的共核可能开始对齐，两场共享的稳定维持结构增加，称此为跨场共核形成（Cross-Field Co-Nucleus Formation）。其是否构成共核，依场篇第一定义15、方程7（长期共同迹应且后续共同稳定复走）判定；两场 K\_f 是否上升，依场篇第十三 v1.2 的增长条件，压缩须经场篇第一定义35 认证。

跨场共核形成后（拟议）：Cpl(f\_A → f\_B) 可能进一步上升；耦合是否趋于稳定另证。

同时（拟议）：f\_B 的独立结构空间可能收缩，φ\_{f\_B} 下降，f\_B 越来越难以维持与 f\_A 不同的独立差分。

因此（释义）：强耦合是双刃的——它使两场之间能够稳定传递复杂结构，但也使 f\_B 的独立性下降，新差分的生成越来越困难。

强耦合的排异动力（拟议）：

本篇拟议：并非所有强耦合都趋向稳定。当 FamOverlap(f\_A, f\_B) 持续下降（两场结构差异增大）而 Cpl 仍在上升时，f\_B 内无法吸收的结构张力可能积累，最终可能触发耦合崩溃（CouplingCollapse）——两场之间的强制续流传递激活 f\_B 的排异，使 f\_B 的可分阈升高以阻断输入（θ\_sep 的变化方向依场篇第八 v1.2 的方向假设；可分性下降不等于阈值升高）。

条件（拟议）：FamOverlap ↓ ∧ Cpl ↑ ∧ P\_Δ(f\_B) \> B\_{f\_B} ⇒ CouplingCollapse 风险上升。P\_Δ(f\_B) \> B\_{f\_B} 单独不构成边沁候选（场篇第十二 v1.2 判据二另须 R\_{f\_B} ≤ 0）。

示例（释义）：文化冲突中的认知排异；强制同化引发的结构性抵抗；认知失调持续累积后的系统性断裂。

示例（释义）：技能自动化（运动场与认知场强耦合后，运动执行不再需要认知场的显式参与）；社会共识形成（个体场与社会场长期强耦合后，个体场的熟径与社会场对齐，异见难以维持）；条件反射（刺激场与反应场的强耦合使两场之间的续流传递变为自动）。

1\. 耦合稳定与失稳

瞬时收支平衡条件：

dCpl/dt = 0，即 a·OutFlow·Compat = Decay\_C·Cpl。单一时刻满足该等式，不证明耦合稳定。驱动乘积为常数 Sc 且 Decay\_C \> 0 时，定理四（b）证明 Cpl 向 a·Sc/Decay\_C 指数收敛；输入随时间变化时，平衡另证。v1.0 的「耦合稳定条件：dCpl/dt ≈ 0」改为此式。

耦合失稳条件：

情形一（过度强耦合，拟议）：Cpl 持续增强，f\_B 的 φ\_{f\_B} → 0，f\_B 失去独立续延能力，开始完全依赖 f\_A 的输入驱动。若 f\_A 的输出中断，f\_B 可能因缺乏独立续流而迅速失稳（耦合依赖性崩溃，命题六）。

情形二（耦合震荡，拟议）：若 f\_A 与 f\_B 的 θ\_sep 周期性变化（如调谐状态交替），MatchTheta 与兼容度随之周期性变化，耦合强度可能周期性升降。示例（释义）：双方认知焦点交替契合与错位的持续张力状态。

1\. 动力方程

场间耦合动力式（示范模型）：

dCpl(f\_A → f\_B, t)/dt = a·OutFlow(f\_A, t)·Compat(f\_A, f\_B, t) − Decay\_C·Cpl(f\_A → f\_B, t)

并且：

Cpl(t₀) = 0 时：Cpl(t) \> 0 ⇔ 在 \[t₀, t\] 的某正测度子集上 OutFlow \> 0 ∧ φ\_{f\_B} \> 0 ∧ MatchTheta \> 0（定理一；此时 FamOverlap\_eff \> 0 自动成立）

Cpl(f\_A → f\_B, t) 与 Cpl(f\_B → f\_A, t) 一般不相等（命题二）

Cpl \> T\_cpl ⇒ 跨场共核形成 ∧ φ\_{f\_B} ↓（拟议；共核依场篇第一定义15、方程7 另验）

Cpl → 0 对应耦合失败的各情形（第8节；情形二不在示范模型内）

OutFlow = 0 ∧ Decay\_C \> 0 ∧ t → ∞ ⇒ Cpl → 0（耦合衰减，定理四）

1\. 总式

场间耦合动力一般式（地位分列）：

f\_A 有输出 ∧ φ\_{f\_B} \> 0 ∧ 调谐兼容（于正测度时段同时成立）⇒ Cpl(f\_A → f\_B) 由零转正（定理一；有效重合度的正值由模型保底项给出，不认证实际新锚形成）

Cpl 持续增长 ⇒ 跨场共核形成 ⇒ f\_B 熟径向 f\_A 靠拢（拟议的正反馈；命题三依 H\_T）

Cpl 过高 ⇒ φ\_{f\_B} ↓ ⇒ f\_B 独立性下降（拟议；强耦合代价）

Cpl → 0 ⇒ 跨场结构传递中断 ⇒ 沉积依场质衰减（拟议；Decay\_C \> 0 时 Cpl 衰减依定理四）

本篇释义：场间耦合是多场系统存在的动力基础。单场的分辨率、压缩、容积极限，可通过耦合向其他场传递、分担或转化。多场系统的层级结构、共识、技能迁移与文明积累，都涉及耦合；本篇不证明耦合是其唯一或充分的条件。

1\. 定理

定理一：耦合成立定理（示范模型内）

设第6节示范模型成立：a \> 0，Decay\_C ≥ 0，OutFlow、Compat 非负、可测、局部可积，Cpl 为绝对连续解。则对 t ≥ t₀：Cpl(t) = e^{−Decay\_C·(t−t₀)}·Cpl(t₀) + a·∫\_{t₀}^{t} e^{−Decay\_C·(t−s)}·OutFlow(s)·Compat(s) ds。故：（a）Cpl(t₀) ≥ 0 时 Cpl(t) ≥ 0；（b）若 Cpl(t₀) = 0，则 Cpl(t) \> 0 当且仅当 OutFlow·Compat 在 \[t₀, t\] 的某正测度子集上大于 0；（c）Compat \> 0 当且仅当 φ\_{f\_B} \> 0 且 MatchTheta \> 0（此时 FamOverlap\_eff ≥ ε·φ\_{f\_B}·MatchTheta \> 0）。合之：由零开始，Cpl(t) \> 0 当且仅当在 \[t₀, t\] 的某正测度子集上 OutFlow \> 0、φ\_{f\_B} \> 0、MatchTheta \> 0 同时成立。

证明要点：常数变易法，(e^{Decay\_C·t}·Cpl)′ = a·e^{Decay\_C·t}·OutFlow·Compat 几乎处处成立，积分即得表示式。（a）两项皆非负。（b）e^{−Decay\_C(t−s)} \> 0，被积函数非负，积分为正当且仅当被积函数在某正测度集上为正。（c）Compat = φ\_{f\_B}·MatchTheta·FamOverlap\_eff；φ\_{f\_B}、MatchTheta 皆正时 FamOverlap\_eff ≥ ε·φ\_{f\_B}·MatchTheta \> 0，三项皆正；其一为 0 时 Compat = 0。∎

说明：v1.0 定理一「Cpl(f\_A → f\_B, t) \> 0 当且仅当……四个条件缺一，耦合不成立」以同一时刻的条件判定 Cpl(t) 的正负，不成立：已有耦合在输入中断后仍为正，例如 OutFlow 于 \[t₁, t\] 为 0 时 Cpl(t) = e^{−Decay\_C·(t−t₁)}·Cpl(t₁) \> 0；Decay\_C = 0 时缺少条件也不使 Cpl 趋零。本版改为（b）。条件二中的 R\_{f\_B} \> 0 不在示范模型内，模型以 φ\_{f\_B} 表示接收容量；FamOverlap\_eff \> 0 在 φ\_{f\_B}、MatchTheta 皆正时自动成立，不是独立条件。

命题二：有向不对称（由模型读出）

Cpl(f\_A → f\_B, t) 与 Cpl(f\_B → f\_A, t) 由各自的输出与兼容度驱动，二者一般不相等；本篇不由模型推出二者相等。

说明：Compat(f\_A, f\_B) 用 φ\_{f\_B}、MatchTheta(f\_A→f\_B)、FamOverlap\_eff(f\_A→f\_B)，Compat(f\_B, f\_A) 用 φ\_{f\_A}、MatchTheta(f\_B→f\_A)、FamOverlap\_eff(f\_B→f\_A)，输出也各为 OutFlow(f\_A)、OutFlow(f\_B)。例如：两向初值为 0，Decay\_C \> 0，两向的 OutFlow、MatchTheta 相同且为常数，FamOverlap\_eff 取相同的既有重合项，而 φ\_{f\_B} = 0.2、φ\_{f\_A} = 0.8，则两向平衡值之比为 1 : 4（定理四）。v1.0 定理二证明称「对称耦合仅在两场结构完全对称时成立，为零测集」，撤回：两向相等不需要两场完全对称（不同参数组合可使两向的输出与兼容度之积相等），本篇也未申报可据以谈测度的参数空间。「单向耦合成立、双向耦合不成立，是场间耦合的常态」改为拟议（第5节）。

命题三：强耦合正反馈（依 H\_T）

设假设 H\_T：Cpl \> T\_cpl 时 FamOverlap(f\_A, f\_B) 不减。则在 OutFlow、φ\_{f\_B}、MatchTheta 不变的比较下，Compat 不减，驱动项 a·OutFlow·Compat 不减。

证明要点：FamOverlap\_eff = max(FamOverlap, ε·φ\_{f\_B}·MatchTheta) 关于 FamOverlap 不减，Compat 为其与非负因子之积；由 H\_T 即得。∎

说明：驱动项不减不推出 dCpl/dt \> 0（衰减项 Decay\_C·Cpl 随 Cpl 增大）；强耦合是否「自我强化」另证。v1.0 证明链撤回：（i）「f\_B 中 f\_A 结构的沉积深度超过 θ\_sep(f\_B)」混同了沉积度与可分阈：θ\_sep 比较的是差异量 d（场篇第八），不是沉积深度；（ii）「φ\_{f\_B} ↓（场篇第十五容积率下降机制）」：场篇第十五 v1.2 定理一为示范模型内的条件定理，须其驱动条件；（iii）「最终 dCpl/dt → 0，耦合稳定于新均衡点」未证。

定理四：耦合衰减与平衡定理（示范模型内）

在定理一的条件下：（a）若在 \[t₀, ∞) 上 OutFlow ≡ 0 且 Decay\_C \> 0，则 Cpl(t) = Cpl(t₀)·e^{−Decay\_C·(t−t₀)} → 0；Decay\_C = 0 时 Cpl 保持为 Cpl(t₀)。（b）若在 \[t₀, ∞) 上 OutFlow·Compat ≡ Sc（常数，Sc ≥ 0）且 Decay\_C \> 0，则 \|Cpl(t) − a·Sc/Decay\_C\| = e^{−Decay\_C·(t−t₀)}·\|Cpl(t₀) − a·Sc/Decay\_C\| → 0。（c）若驱动乘积 g = OutFlow·Compat 满足 g(t) → 0（t → ∞）且 Decay\_C \> 0，则 Cpl(t) → 0。

证明要点：（a）（b）代入定理一的表示式直接计算。（c）任给 η \> 0，取 T ≥ t₀ 使 t ≥ T 时 g(t) \< η；对 t ≥ T 将历史积分拆为 \[t₀, T\] 与 \[T, t\] 两段：前段连同初值项不超过 e^{−Decay\_C·(t−T)}·(Cpl(t₀) + a·∫\_{t₀}^{T} g ds)，随 t → ∞ 趋于 0；后段不超过 a·η/Decay\_C。故 limsup Cpl ≤ a·η/Decay\_C，η 任意，得 Cpl → 0。∎

说明：本篇拟议 Decay\_C 对应场质（第6节）；v1.0「对应场篇第七遗忘项 −q₀δ 的跨场推广」改为类比：场篇第七主方程为示范模型，其对象是局部沉积度，不由之推出本式。输入随时间变化时，Cpl 是否收敛另证。

命题五：余量耗尽阻断（拟议）

当 R\_{f\_B}(t) ≤ 0（余量耗尽，场篇第十二 v1.2）时，普通输入下 f\_A 的输出可能多被 f\_B 的旧熟径吸收，不形成新的跨场结构；强输入（OutFlow \> T\_replace）可能触发旧熟径裂解，R\_{f\_B} 局部回升，耦合重新成立。

说明：此为拟议，不在示范模型内。v1.0 证明链改订：（i）「R\_{f\_B} ≤ 0 → φ\_{f\_B} → 0」不成立：场篇第十五 v1.2 的 H\_φR 只给 φ\_f 下降对应 R\_f 下降的方向假设，不给反向，也不给 R\_f ≤ 0 时 φ\_f 趋零；（ii）「场篇第十一熟径优先定理保证其被最高 Familiarity 的旧熟径吸收」：场篇第十一 v1.2 定理一为熟径先出（依 H\_δ），只给出流先后，不给吸收份额，Familiarity 改记为 δ̄ 与 CI；（iii）例外路径中「场篇第十四沁叠裂解机制」依其现版，「场篇第十五场容积恢复定理」今为场篇第十五 v1.2 定理五（示范模型内的容积率回升），R\_{f\_B} 回升依 H\_φR；（iv）「域满」改称余量耗尽，域满依场篇第一定义20 另验。

命题六：耦合崩溃（拟议）

若 f\_B 因强耦合使 φ\_{f\_B} 趋近 0 后 f\_A 输出中断，f\_B 可能因失去外部续流来源且自身独立续流不足而失稳。

说明：此为拟议。v1.0 证明链撤回：（i）「场篇第十五熟径锁定定理」今为场篇第十五 v1.2 命题四（拟议）；（ii）「场篇第十三压缩必然性定理」今为场篇第十三 v1.2 判据一（压缩候选，非必然），K\_f 增长须 P\_eff \> SDC\_f 且 K\_f \< 1，压缩须经场篇第一定义35 认证；（iii）「R\_{f\_B} 持续下降，K\_{f\_B} 趋向 1，分辨率趋零」未证，撤回；Cpl → 0 依定理四，须 Decay\_C \> 0。
