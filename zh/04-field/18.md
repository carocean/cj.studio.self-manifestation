自显论·场篇第十八 v1.1

# 场的生成与消亡

1\. 目的

前十七篇建立了场的内部动力与场间耦合。但始终存在一个隐含假设：场已经存在。

这一假设遮蔽了两个根本问题：

第一，场是怎么来的？

在没有任何熟径、没有任何共核、没有任何沉积结构的情况下，一个新场如何从前场状态生成？

第二，场会怎么消亡？

一个曾经存在的场，在什么条件下走向终结？消亡之后留下什么，不留下什么？

这两个问题对整个体系很重要（出发观点，释义）：生成条件关系到现实结构从何而来，消亡条件关系到旧结构如何被取代、新场如何在旧场的残留上生成。

因此本篇讨论：场的生成最低条件是什么；场消亡的两种路径及其不同后果；以及死亡残留如何成为新场生成的初始条件。

1\. 核心命题

场不是被给定的。

本篇拟议：场是在持续续流冲入有限空间、沉积度持续积累、差分结构开始稳定维持之后，才逐渐成立的结构。

场也不是永恒的。

本篇拟议：场在续流停止或压缩饱和之后，会经由两种不同路径走向终结：压缩性死亡与遗忘性死亡。另行认证共核后，压缩性死亡可能留下深核残留；在定理三的持续条件下，遗忘性死亡的残留随时间趋零。

注：此处「消亡」泛指场的终结。压缩性死亡是终极固化，而非真正消失——场还在，但已失去分辨新差分的能力（拟议读法）；遗忘性死亡的判据只给出沉积度全部低于 δᵣ 且不增长，结构回归零点是另加持续条件（定理三）下的情形。

本篇拟议：这两种死亡路径留下不同的初始条件，影响下一个场生成时面对的结构环境。

因此（释义）：场的生灭不是外部施加的，而是沉积动力的内在结果。

1\. 场生成条件

设域 f 尚未成立（∅ → f 待逼出）。

本篇以下列三个最低条件刻画域 f 的成场候选（成场的认证见本节末）：

条件一：最低续流密度条件

在有限空间 Ω 中，存在持续的脉冲输入 I(x,t)（场篇第七），使得存在子区域 Ω\_f ⊆ Ω，其中局部沉积度 δ(x,t) 持续正增长：

∃Ω\_f ⊆ Ω，使 x ∈ Ω\_f 时 ∂δ(x,t)/∂t \> 0，持续时长 ≥ τ\_stable

此即场篇第七 v1.2 判据五（成域候选的增长条件，τ\_stable 对应其 τc）：持续正增长包含有效输入、邻域转入、净迁移与扩散的共同贡献，可以发生在无新边界的结构中，故只是候选条件，不能单独认证新域。

本篇拟议：若续流过于稀疏或时间过短，沉积度在退化项（场篇第七 −q₀δ 等）的作用下难以积累。

条件二：最低差分密度条件

在区域 Ω 内，沉积结构中可分辨的差分实体数量超过最低阈值：

N\_diff(Ω, t) ≥ N\_min

N\_min 为本篇成场候选筛选所申报的数量门槛。N\_diff \< N\_min 表示未满足本篇条件二，不据此判定差分不存在或域不成立；域的成立依场篇第一定义8 另验。

注：条件二只负责「差分实体是否足够存在」，不要求差分之间的关系已经稳定——后者由条件三负责。差分关系的稳定维持是独立的额外条件。N\_min 为申报阈值，N\_diff 的计法须申报。《数论》中说：「能指则已分，能比则已类，故数生之于已分已类」——可数的前提是已有足够多的分辨实体（释义对应）。

条件三：最低稳定闭包条件（本篇所称「稳定闭包」指差分间的稳定互锁，不是场篇第一定义24、方程16 的闭包）

本篇以至少一对差分 (q\_i, q\_j) 的沉积度同时达到申报的主分辨区阈值 δᵣ（场篇第七 v1.2 第12节；δᵣ 的操作用途为判定是否处于主分辨区，不替代场篇第一定义13 熟的一般含义），并在申报窗口内持续满足 d(q\_i, q\_j) \> θ\_sep，作为条件三的操作判据：

∃(q\_i, q\_j)：δ(q\_i, t) ≥ δᵣ ∧ δ(q\_j, t) ≥ δᵣ

且在申报窗口内持续满足场篇第八 v1.2 的可分条件 d(q\_i, q\_j) \> θ\_sep。该判据不单独认证结构互锁、自我维持边界或场篇第一的闭包。v1.0 写作「两者之间的分辨关系 M(q\_i, q\_j, t)（引用场篇第七）稳定维持」：场篇第七的 M(x,t) 是输入结构与已有沉积结构的交叠匹配率，不是两差分之间的分辨关系，本版改依场篇第八的可分条件。

注：条件三不是条件一的自然结果。条件一给出沉积度在某区域持续增长，但并不保证特定差分对 (q\_i, q\_j) 持续满足可分条件；二者须分别检验。

本篇拟议：若无稳定互锁，区域内的沉积结构难以自我维持，会在调谐波动下迅速散失。

场生成算子（本篇的操作界定）：

Genesis(f, t) = 1

当且仅当：第3节三个操作条件在同一申报窗口内共同持续不少于 τ\_stable（定义）。

Genesis(f, t) = 0 表示域 f 尚未满足成场候选条件。

认证：Genesis = 1 是本篇的成场候选读法；域 f 是否成立，依场篇第一定义8 判定（线束中能够稳定容与、分辨、差分积深、续行与束界的一段）。三条件不单独推出定义8 的五项。

1\. 场生成动力

本篇拟议：场的生成不是瞬间完成的，而是渐进的沉积积累过程。

阶段一（前场阶段，拟议）：区域 Ω 中存在零散脉冲输入，沉积度低且不稳定，退化持续消退沉积，尚未形成稳定结构。此时 Genesis(f, t) = 0。

阶段二（成域临界，拟议）：脉冲输入密度升高，局部沉积度开始达到主分辨区阈值 δᵣ，差分数量接近 N\_min，但稳定互锁尚未形成。轻微的输入减少可能使沉积重新散失，输入持续则可能趋向成场。

阶段三（成场候选成立）：三个条件同时满足，Genesis(f, t) = 1；域 f 是否成立依场篇第一定义8 另验；场的内部动力（分辨率、调谐、熟径、压缩）可能开始逐渐建立（拟议）。v1.0「场篇第七的主方程开始在域 f 上有效运行」撤回：场篇第七 v1.2 主方程为示范模型，不以域是否成立为运行条件。

与场篇第十七 v1.1 的关系：新生场在生成初期无熟径结构，FamOverlap ≈ 0，若 φ\_f \> 0 且 MatchTheta \> 0，则 ε·φ\_f·MatchTheta \> 0，因而在场篇第十七的示范模型中取得正兼容读数（条件四新锚项）；MatchTheta = 0 时，该项为零。该保底项是模型评分，不认证实际新锚、沉积核或熟径已经形成（场篇第十七 v1.1）。

1\. 场消亡条件

本篇拟议：域 f 的消亡不是单一路径，而是两种不同的动力过程。两种死亡可以并发：当 K\_f ≥ K\_dead 的同时续流中断，Death\_C 与 Death\_F 的条件可以先后满足。并发时，若另已认证 Core(f)，残留可能以核部残留 δ\_res^C 为主；在定理三的条件下若输入中断持续足够长，核部沉积度最终降至主分辨区阈值以下，转为遗忘性死亡状态。

### 5.1 压缩性死亡

条件：K\_f(t) ≥ K\_dead（K\_dead 为本篇申报的死亡压缩阈；K\_f 依场篇第十三 v1.2 读取，K\_f 只计经场篇第一定义35 认证的压缩共享），同时独立维持差分数量 Ind\_f(t) 趋零（场篇第十三 v1.2，按实际独立成员计数），分辨率余量 R\_f(t) 不超过 ε\_R（场篇第十二 v1.2，预算条件下的余量）。

过程（拟议）：场内差分不断被压缩共享，独立结构空间收缩至极限。场没有崩散，而是被压缩为极少数深核结构——最极端情形下可能趋向单一深核。被压入者是否构成共核，依场篇第一定义15、方程7 判定；压缩不是失分辨（场篇第一定义35）。

死亡算子（本篇的操作界定）：

Death\_C(f, t) = 1

当且仅当：K\_f(t) ≥ K\_dead ∧ R\_f(t) ≤ ε\_R ∧ Ind\_f(t) ≤ ε\_N（定义）

其中 K\_dead ∈ (0,1) 为申报的死亡压缩阈（不要求 K\_f 精确趋于 1）；ε\_R、ε\_N 为申报的非负阈值。「压缩强度超过此阈值时场失去独立分辨能力」为本篇拟议的读法。Death\_C 只记录所申报的压缩、预算余量与独立维持数量条件，不单独推出共核存在、少核或高沉积度。

压缩性死亡的核部残留（另行认证 Core(f) 后）：

δ\_res^C(x, f, t) = δ(x, t)\|\_{x ∈ Core(f)}（Core 依场篇第一定义15 判定；其沉积深浅另验；「少数高深核残留」作为附加情形讨论）

δ\_res^C 的特点（拟议，附加情形：核部沉积度高）：依场篇第十一 v1.2，深者为熟（熟的比较依路径沉积度统计 δ̄），在比较条件下先出（定理一，依 H\_δ）。新输入进入此残留区域后，可能多被既有熟径吸收，难以形成独立差分；先出只给出流先后，不给吸收份额，后者为本篇拟议。v1.0「Familiarity 极高」「被既有熟径以最高优先级吸入」及所引「场篇第十一熟径优先定理」依场篇第十一 v1.2 改记。

示例（释义）：记忆中无法忘却的执念；语言中无法绕过的核心词汇；文明中沉淀千年的核心范畴。

### 5.2 遗忘性死亡

条件：f 的全部外部流入中断——依场篇第七 v1.2，有效输入与邻域转入为零（I\_eff = B\_out = 0）；所有外部场对 f 的耦合 Cpl(f\_ext → f, t) 接近零（场篇第十七 v1.1；Cpl 是耦合强度，不等同于流入量，二者关系本篇未立）；同时内部重续 Rc(f, t) ≈ 0（场篇第十六；若内部重续仍在，场未真正死亡）；且基础退化系数 q₀ \> 0（场篇第七）。v1.0 中文条件含「OutFlow(f, t) ≈ 0（场篇第十七，f 不再有外部输出）」，f 自身的输出与其沉积是否消退无关，本版删去，与英文 v1.0 的写法一致。

过程：场不再接收任何续流输入，沉积度在退化项作用下变化。在场篇第七 v1.2 定理二所列精确条件下（I\_eff = B\_out = 0、β·φ(ρ/Λ) = 0、∇·J = 0、∇²δ = 0），衰减为指数形式，定理三成立：

δ(x,t) = δ(x,t₀)·e^{−q₀(t−t₀)} → 0（t → ∞）

条件仅近似满足时，须另给遗漏项的误差界与有效时段；尚不能据此保证趋零或有限时间满足 Death\_F。例如遗漏项为正源 r 时 δ′ = r − q₀δ，极限为 r/q₀，可能高于 δᵣ。

本篇拟议：在上述精确条件下，所有沉积结构逐渐消退，熟径、共核、差分关系一一散失，最终域 f 的沉积度全面低于主分辨区阈值 δᵣ。场质与遗忘：《数论》中说：「若冲而不复来，则迹应渐逝，谓之遗忘。此决于场之质性也。」q₀ 为场篇第七的基础退化系数，本篇读作场质（场篇第一定义28）的退浅分量（拟议对应）。

死亡算子（本篇的操作界定）：

Death\_F(f, t) = 1

当且仅当：∀x ∈ f，δ(x,t) \< δᵣ ∧ ∂δ(x,t)/∂t ≤ 0（沉积度低于主分辨区阈值且不再增长；定义）。v1.0 写作 ∂δ/∂t \< 0：δ = 0 处 ∂δ/∂t = 0，若照写则空域永不满足，本版改为 ≤ 0。

遗忘性死亡的残留：

Death\_F = 1 时，残留满足 0 ≤ δ\_res^F \< δᵣ，且在判定时不增长。在定理三的持续条件下，残留随时间指数趋零。v1.0「δ\_res^F ≈ 0（几乎无残留）」改为此式：判据本身不给出 δ ≈ 0，例如 δ = 0.9δᵣ 恒定也满足判据而不趋零。

示例（释义）：不再使用的技能完全消失；被彻底遗忘的语言；消亡文明的知识体系从传承链完全断开后的最终结果。

1\. 两种死亡的根本区别

本篇拟议：压缩性死亡与遗忘性死亡，留下不同的初始条件（下表残留一行为附加情形：压缩性死亡一列假定另已认证 Core 且核部沉积度高，遗忘性死亡一列假定在定理三的持续条件下残留已很小）：

\|比较维度  \|压缩性死亡                         \|遗忘性死亡          \|  
\|------\|------------------------------\|---------------\|  
\|触发条件  \|K\_f ≥ K\_dead，R\_f ≤ ε\_R，Ind\_f ≤ ε\_N\|外部流入中断，Rc → 0，q₀ \> 0\|  
\|残留结构  \|核部 δ\_res^C 高（附加情形）           \|δ\_res^F 小（附加情形）\|  
\|对新场的影响\|强熟径吸引子，约束新场（拟议）            \|无约束，新场可自由生成（拟议）\|  
\|新差分可能性\|极低（被深核吸收，拟议）                 \|高（无旧结构干扰，拟议）  \|  
\|对应现象  \|固执、意识形态锁死（释义）               \|遗忘、文明断层（释义）    \|

因此（释义）：压缩性死亡不是真正的消亡，而是场的极端固化——场还在，但已经失去分辨新差分的能力。遗忘性死亡判据表示全域沉积度低于主分辨区阈值且不增长；在定理三的持续条件下，沉积度进一步指数趋零。结构逐渐散失是该持续退浅过程的拟议解释。

1\. 死亡残留与新场生成

本篇拟议：死亡残留 δ\_res 是新场生成的初始沉积条件。

情形一（压缩性死亡后的新场生成）：

本篇拟议：在附加情形（另已认证 Core 且核部沉积度高）下，新场在 δ\_res^C 的基础上生成时，面对深核吸引结构。新续流输入可能多被旧深核吸收，难以形成独立差分（FamOverlap 高，φ\_f 低）。

因此（拟议）：在压缩性死亡残留上生成的新场，倾向于沿旧深核方向压缩，难以突破旧范式。示例（释义）：文明的路径依赖、认知的先入之见、语言的核心词汇对新概念的吸附。

突破条件（拟议）：OutFlow 足够强（场篇第十七 v1.1 命题五之 T\_replace 例外路径，拟议），可能触发旧深核的裂解，旧核沉积度局部下降，新差分才能获得独立沉积空间。

情形二（遗忘性死亡后的新场生成）：

本篇拟议：在另加小残留条件下（δ\_res^F ≈ 0，例如定理三的持续条件下经足够时间），新场在近乎空场上生成，无旧结构约束，也无任何熟径锚点。

新续流输入从近乎为零的沉积度开始积累，满足三个条件后成场候选成立（定义8 另验）。本篇拟议：此时新场的生成方向主要由当前输入结构决定，不受旧结构影响。

但代价是（拟议）：生成速度较慢（无熟径加速），且易在输入中断时重新散失（初期沉积度低，退化压力相对大）。

示例（释义）：文明断层后的新文明重建；遗忘后的重新学习；认知重置后的新结构生成。

1\. 场的生命周期

综合前七节，本篇拟议的场生命周期如下：

阶段一（前场）：区域 Ω 存在零散输入，δ \< δᵣ，Genesis = 0；

阶段二（生成临界）：输入持续，δ 局部达到 δᵣ，差分数量接近 N\_min，稳定互锁尚未形成；

阶段三（成场候选）：Genesis = 1，域依场篇第一定义8 另验，场篇第七至第十六的内部动力可能开始建立；

阶段四（场发展）：熟径加深，共核形成，K\_f↑，φ\_f↓，场可能趋向稳定也趋向压缩；

阶段五（场极限）：K\_f → 1 或 φ\_f → 0，场进入场篇第十二、十三、十五所论的极限状态（其到达须各篇示范模型之条件）；

阶段六（死亡路径）：

\- 路径 A（压缩性死亡）：K\_f ≥ K\_dead、R\_f ≤ ε\_R、Ind\_f ≤ ε\_N，故 Death\_C = 1；另行认证 Core(f) 后读取核部残留，其沉积深浅另验；  
\- 路径 B（遗忘性死亡）：外部流入中断，Death\_F = 1，残留低于 δᵣ 且不增长；在定理三的持续条件下 δ → 0；

阶段七（新场生成）：在 δ\_res 基础上，新续流冲入，新场生成条件重新积累。

1\. 动力方程

场生成算子（定义；域依场篇第一定义8 另验）：

Genesis(f, t) = 1 ⟺ 第3节三个操作条件在同一申报窗口内共同持续不少于 τ\_stable（条件一：∃Ω\_f，∂δ/∂t \> 0；条件二：N\_diff ≥ N\_min；条件三：δ(q\_i), δ(q\_j) ≥ δᵣ 且 d(q\_i, q\_j) \> θ\_sep）

压缩性死亡算子（定义）：

Death\_C(f, t) = 1 ⟺ K\_f ≥ K\_dead ∧ R\_f ≤ ε\_R ∧ Ind\_f ≤ ε\_N

遗忘性死亡算子（定义）：

Death\_F(f, t) = 1 ⟺ ∀x，δ(x,t) \< δᵣ ∧ ∂δ/∂t ≤ 0

死亡残留（读法）：

Death\_C = 1 且另已认证 Core(f) ⇒ δ\_res^C(x) = δ(x,t)\|\_{x ∈ Core(f)}（核部残留；其深浅另验）  
Death\_F = 1 ⇒ 0 ≤ δ\_res^F(x) \< δᵣ 且在判定时不增长；定理三的持续条件下 δ\_res^F → 0

生灭闭环（拟议）：

Death\_C ∨ Death\_F ⇒ δ\_res 成为新 Genesis 的初始沉积条件

Genesis → 场内动力建立（场篇第七至第十六）→ Death\_C ∨ Death\_F → δ\_res → 新 Genesis

1\. 总式

场的生灭动力一般式（地位分列）：

第3节三个操作条件在同一申报窗口内共同持续不少于 τ\_stable ⇔ Genesis = 1（成场候选，定义；域依场篇第一定义8 另验）

Genesis = 1 ⇒ 场内动力建立，K\_f ↑，φ\_f ↓（拟议；场发展→场极限）

K\_f ≥ K\_dead ∧ R\_f ≤ ε\_R ∧ Ind\_f ≤ ε\_N ⇒ Death\_C = 1（定义）；另认证 Core(f) 后读取核部残留 δ\_res^C（深浅另验）

外部流入中断 ∧ Rc(f,t) ≈ 0 ∧ q₀ \> 0 ⇒ Death\_F = 1 且 0 ≤ δ\_res^F \< δᵣ（定理三：在场篇第七定理二所列精确条件下于有限时刻后成立，残留指数趋零；条件仅近似满足时，须另给误差界与有效时段，不据此保证）

Death\_C 且附加情形（Core 已认证、核部沉积度高）⇒ 深核残留约束新场，新场难以突破旧范式（拟议）

Death\_F 且另加小残留条件 ⇒ 近乎空场，新场自由但缓慢（拟议）

δ\_res + 新续流 ⇒ 新 Genesis（拟议的生灭闭环）

本篇释义：场不是永恒存在的给定结构，而是沉积动力在续流、压缩、遗忘之间不断生成、发展、死亡、残留、重生的过程。

本篇释义：场的生灭是整个沉积场动力体系的时间尺度底层——场内的分辨率、压缩、容积方程描述的是场存在期间的演化，而场的生灭方程描述的是场本身的存在条件与终结路径。

1\. 定理

判据一：成场候选判据

本篇以「三个操作条件在同一申报窗口内共同持续不少于 τ\_stable」作为域 f 的成场候选条件，即 Genesis(f, t) = 1（第3节定义）。

说明：此为申报的操作界定，不是由上游推出的定理；因 Genesis 由三条件定义，「Genesis = 1 当且仅当三条件成立」是定义的复述。域 f 是否成立，依场篇第一定义8 另验；条件一即场篇第七 v1.2 判据五，只是成域候选条件。v1.0 定理一（场生成必要条件定理）的证明撤回：（i）「条件一缺失（续流不足）→ ∂δ/∂t ≤ −q₀δ \< 0」不成立：持续正增长不成立，不等于沉积度只受基础退化（场篇第七 v1.2 主方程另有竞争退化、迁移、扩散与邻域转入诸项）；（ii）「无场篇第十二 R\_f 可建立」「场篇第八 θ\_sep 无稳定对象」只是读法；（iii）「三条件同时满足 → δ 持续超过 δᵣ，N\_diff ≥ N\_min，闭包稳定 → Genesis = 1」是定义，不是推出。

命题二：压缩性死亡的难逆（拟议）

若 Death\_C(f, t) = 1，则 f 内部可能难以自发恢复分辨；外部强输入超过 T\_replace 触发旧核裂解，是一条可能的恢复路径（场篇第十七 v1.1 命题五，拟议）。

说明：此为拟议。v1.0 定理二（压缩性死亡不可逆定理）的证明链撤回：（i）「任何新差分进入场后立即被既有共核吸收（场篇第十三共核形成定理）」：场篇第十三 v1.2 已改为命题三（拟议），共享维持结构不等于共核；（ii）「R\_f = SDC\_f − S\_f ≤ 0」：Death\_C 只要求 R\_f ≤ ε\_R，且场篇第十二 v1.2 定理一只给固定预算比较下的必要条件；「场篇第七主方程中新差分无法稳定积累」未证；（iii）「唯一恢复路径」未证，撤回「唯一」；（iv）场篇第十三示范模型中 dK\_f/dt ≥ 0、K\_f 不下降，只说明该模型不含恢复，不证明场不能恢复。依场篇第一定义34，场释放负载不必然恢复稳定分辨，恢复须重新形成稳定差分等条件。

定理三：遗忘性死亡定理（依场篇第七 v1.2 定理二的条件）

设在 \[t₀, ∞) 上域 f 内各点满足场篇第七 v1.2 定理二的条件：I\_eff = B\_out = 0、β·φ(ρ/Λ) = 0、∇·J = 0、∇²δ = 0，且 q₀ \> 0 为常数、δ ≥ 0，δᵣ \> 0 为固定门槛；记 δ\_max = sup\_{x∈f} δ(x, t₀) \< ∞，并设内部重续不提供输入。则 δ(x,t) = δ(x,t₀)·e^{−q₀(t−t₀)}；令 t\* = t₀（当 0 ≤ δ\_max ≤ δᵣ），t\* = t₀ + ln(δ\_max/δᵣ)/q₀（当 δ\_max \> δᵣ）；则对一切 t \> t\*，Death\_F(f, t) = 1。

证明要点：在所列条件下主方程化为 ∂δ/∂t = −q₀δ（场篇第七 v1.2 定理二），解为所示指数式，故 ∂δ/∂t = −q₀δ ≤ 0；t \> t\* 时 δ(x,t) ≤ δ\_max·e^{−q₀(t−t₀)} \< δᵣ 对一切 x ∈ f 成立（δ\_max = 0 时解恒为零，从 t₀ 起即满足；0 \< δ\_max ≤ δᵣ 时 t \> t₀ 即有 δ \< δᵣ）；由 Death\_F 的定义即得。∎

说明：v1.0 定理三以「所有外部耦合 Cpl(f\_ext→f) ≈ 0」为条件：Cpl 是耦合强度，不等同于流入为零（场篇第十七 v1.1），且「≈ 0」只给近似结论；本版以场篇第七 v1.2 定理二的精确条件表述。条件仅近似满足时，须另给遗漏项的误差界与有效时段，尚不能据此保证趋零或有限时间满足 Death\_F（正源 r 之例见5.2）。《数论》「若冲而不复来，则迹应渐逝，谓之遗忘」为本定理的原义对应。

命题四：两种死亡残留不等价（拟议）

Death\_C 与 Death\_F 的判据不同，残留读法也不同：Death\_C 只限定压缩、预算余量与独立维持数量，另认证 Core(f) 后才读取核部残留，其深浅另验；Death\_F 给出残留低于 δᵣ 且不增长，在定理三的持续条件下趋零。在附加情形（核部沉积度高；遗忘残留已很小）下，在 Death\_C 残留上生成的新场可能倾向于路径依赖，在 Death\_F 残留上生成的新场可能自由发展但初期易散失。

说明：此为拟议。残留读法依二者的定义、Core 的另行认证与定理三；「深核高、遗忘残留小」为附加情形，其后果为拟议。v1.0「残留的高低由定义读出」不成立：Death\_C 不限定 δ，Death\_F 只给 δ \< δᵣ。v1.0 证明链改订：（i）「Familiarity(新输入方向) 极高」依场篇第十一 v1.2 改记为 δ̄ 较深，先出只给先后；（ii）「场篇第十七耦合方程使新场输入被旧核吸入」：场篇第十七 v1.1 的兼容度只决定耦合驱动，不给吸收去向；（iii）Death\_F 残留上「仅 ε·φ\_f·MatchTheta 项 \> 0」是场篇第十七的模型评分，不认证新锚形成。

命题五：生灭闭环（拟议）

场的生灭可能构成动力闭环：Death\_C ∨ Death\_F → δ\_res → 新 Genesis 初始条件 → 新场发展 → 新场极限 → 新 Death；每一次死亡为下一次生成提供初始结构。

说明：此为拟议。在附加情形（另已认证 Core 且核部 δ ≥ δᵣ）下，δ\_res^C 保留的位置可能为新输入重新满足条件三提供位点，但稳定可分须由新输入重新建立，不是自动保持；Death\_F 之后重新取得成场候选资格，须重新检验三条件在同一窗口内共同持续成立；初始沉积度取实际残留，不预设为零。v1.0 的「闭环成立」改为拟议；示例（释义）：文明兴衰、记忆形成与消退、认知范式的更迭。

命题六：场生成速度（依 H\_res）

设在相同起点、申报协议与 τ\_stable 下比较两种残留情形，并设假设 H\_res：条件一、二在两种情形中的窗口资格相同；凡条件三在遗忘残留情形中合格的窗口，在压缩残留情形中也合格。记两种情形中三条件共同持续不少于 τ\_stable 的合格窗口终点集合为 𝒯\_C、𝒯\_F，定义 τ\_gen^C = inf 𝒯\_C − t₀、τ\_gen^F = inf 𝒯\_F − t₀（空集的下确界约定为 ∞）。则 τ\_gen^C ≤ τ\_gen^F；但前者的独立性可能更低（命题四）。

证明要点：由 H\_res，凡在遗忘残留情形中三条件共同合格的窗口，在压缩残留情形中三条件亦共同合格，故 𝒯\_F ⊆ 𝒯\_C，从而 inf 𝒯\_C ≤ inf 𝒯\_F；起点同为 t₀，故 τ\_gen^C ≤ τ\_gen^F。∎

说明：本命题的实质内容全在 H\_res（窗口资格的包含关系）；条件三首次满足得更早，不保证三条件共同持续成立得更早（条件三在压缩残留上可能更早满足，却在条件一、二成立之前已经失效）；本命题依赖窗口资格包含假设，不能只由保留深积位点推出。v1.0 定理六称「δ\_res^C 已满足条件三」，与条件三须差分对稳定可分不合（残留只保留沉积度，不自动保留可分关系），撤回；「速度与独立性之间存在结构性权衡」为释义。
