自显论·场篇第二十一 v1.0

# 场尺度律

1\. 目的

前二十篇建立了单场动力、场间耦合、场的生灭、层级结构与观界条件。

场篇第十九引入了尺度（Scale）的初步区分：

层级（Depth）是纵向堆叠——下层场的输出驱动上层场；  
尺度（Scale）是横向扩展——同层场的 Cap\_f 大小。  
两者独立。

但场篇第十九未正式推导尺度如何影响场的内部动力。

本篇回答：场的尺度大小，如何系统性地改变 K\_f、R\_f、P\_s、φ\_f 等核心参数的有效范围与动力趋势？

1\. 核心命题

尺度不只是”场更大或更小”。

尺度改变动力参数的有效边界——同样的续流输入，在大尺度场中产生的压缩效果、分辨率余量、熟径锁定程度，系统性地与小尺度场不同。

因此：

Scale ↑ ⇒ K\_f 趋增、φ\_f 趋降、R\_f 趋降、保守性趋强（在持续输入 + 长时间运行条件下）

Scale ↓ ⇒ K\_f 趋降、φ\_f 趋升、R\_f 趋升、创新性趋强

这不是偶然的，而是由沉积场的基本约束——有限容积中的差分维持压力——在不同尺度下的系统性结果。

1\. 场尺度的正式定义

Scale(f) = Cap\_f

即场尺度等于场篇第十五所定义的可维续场容积（Field Capacity）。

说明：

Cap\_f 是域 f 中可同时稳定维持多个独立续延结构的有效域总量（场篇第十五）。它衡量的是场在空间/结构意义上的”大小”——能容纳多少独立差分关系。

Scale(f) 直接使用 Cap\_f，不引入新量。场篇第十五已确立 Cap\_f 为常数（对给定场，容积上限不随时间改变）。尺度是结构性属性，不是动力变量。

尺度与层级的区分（引用场篇第十九）：

Depth(f)：纵向，fⁿ⁻¹ → fⁿ 的堆叠层数；  
Scale(f) = Cap\_f：横向，f 能容纳多少独立差分结构；  
两者独立——高层级场不一定大尺度；大尺度场不一定高层级。

1\. 尺度与压缩强度

大尺度场（Cap\_f 大）的压缩强度 K\_f 为何趋高？

前提条件：以下推导成立的条件是”持续输入 + 长时间运行”——即场已接收足够多的历史续流输入，S\_f 有充分时间积累。一个刚建立的大尺度空场（Cap\_f 大但 S\_f 极低）不会自动有高 K\_f；尺度律描述的是长期统计趋势，不是瞬时必然。

推导（在持续输入 + 长时间前提下）：

Cap\_f 大 → 场的容积上限高，S\_f 可以持续积累而场不会提前边沁；在同等续流输入强度下，大尺度场的 S\_f 积累上限远高于小尺度场，长期均衡中 S\_f 系统性偏高；

S\_f 高 → P\_s(f,t)（差分维持压力，场篇第十三）∝ N\_f·O\_f 趋高（更多差分之间的交叠关系；O\_f 随 S\_f 增长而系统性增大——场篇第十三，大尺度场中 N\_f 基数大，N\_f·O\_f 的增长效应比小尺度场更显著）；

P\_s 高 → K\_f 增速 dK\_f/dt ∝ (1−K\_f)·max(0, P\_s−SDC\_f) 趋大（场篇第十三压缩动力方程）；

因此：大尺度场在其他条件相同时，K\_f 的均衡值系统性高于小尺度场。

直觉：大社会比小社会有更高的分类压缩倾向；大语言系统比小方言有更高的词汇共核化压力；大机构比小团队有更强的规则固化趋势。

形式化：

dK\_f/dt\|\*{Scale=L} \> dK\_f/dt\|\*{Scale=S}，当 L \> S，其他条件相同时。

注：K\_f 与 Scale(f) 的关系是统计性规律，非硬性单调。高尺度场在特定时段（如初创期、边沁后重组期）可能有较低 K\_f。但长期稳定均衡中，大尺度场的 K\_f 系统性偏高。

1\. 尺度与分辨率余量

大尺度场（Cap\_f 大）的分辨率余量 R\_f 为何趋低？

推导：

R\_f = SDC\_f − S\_f（场篇第十二，分辨率余量 = 稳定差分维持能力 − 当前差分数量）；

Cap\_f 大 → S\_f 可以积累至更高水平而场不会立即边沁；

S\_f 高且持续增长 → SDC\_f 上限在长期压缩中被消耗（K\_f 上升，场篇第十三 SDC\_f 的有效容量随 K\_f 压缩而下降）；

因此：大尺度场在长期演化中，R\_f 趋向较低水平——不是因为 SDC\_f 小，而是因为 S\_f 的积累量在大尺度场中系统性偏高。

注意：R\_f 的绝对值在大尺度场可能仍比小尺度场高（因为 Cap\_f 大，SDC\_f 基数也大），但 R\_f/Cap\_f（相对分辨率余量）在大尺度场中更低。场篇第十五的剩余容积率 φ\_f = A\_f/Cap\_f 才是反映相对开放程度的正确量——大尺度场的 φ\_f 趋低。

1\. 尺度与容积率

大尺度场的剩余容积率 φ\_f 为何趋低？

注：场篇第十五定义 A\_f(t) 为”仍可开放新续延的有效续延容积”（剩余量），φ\_f = A\_f/Cap\_f 为剩余容积率。φ\_f 趋低意味着 A\_f 相对 Cap\_f 减小，即开放余量下降，场趋向饱和。

推导路径（引用场篇第十五动力方程）：

dφ\_f/dt ∝ −S\_f − OccItr\_f − K\_f + α\_f（场篇第十五第6节）

大尺度场在持续输入 + 长时间运行条件下：

S\_f（压缩饱和度）↑（由定理一，Scale↑ → K\_f↑ → S\_f↑，旧结构占据更多有效续延域）；

OccItr\_f（沁叠占域）↑（Scale↑ → 差分交叠积累更多，场篇第十四，沁叠残留增大）；

K\_f（压缩强度）↑（由定理一）；

三项负向驱动均系统性偏高，而恢复项 α\_f 在大尺度场中由于 K\_f 高、T\_replace 门槛高（场篇第十七）而系统性偏低——熟径裂解和边沁后新域开放更困难；

因此：大尺度场的 dφ\_f/dt 长期偏负，φ\_f 在长期均衡中系统性偏低，对应开放余量减少、独立新差分形成能力下降、新差分难以稳定。

1\. 尺度与保守性

综合前三节，尺度对保守性的影响：

Scale ↑ ⇒ K\_f ↑ ∧ φ\_f ↓ ∧ R\_f（相对）↓ ⇒ 保守性 ↑

保守性的机构定义：场倾向于用旧熟径吸收新输入，而不是形成独立新差分。保守性高 = K\_f 高（共核覆盖广）+ φ\_f 低（开放余量少）+ R\_f 相对低（分辨新差分的能力受限）。

尺度律的核心结论：

大尺度场不是”能力更强”，而是”历史更重”——历史沉积占据了更多结构空间，使新结构的生成越来越困难。

这解释了：

为什么大型机构难以创新（大尺度认知场/社会场的 K\_f 高、φ\_f 低）；  
为什么古老语言词汇固化（历史悠久 = 高尺度 × 长时间，K\_f 极高）；  
为什么大脑随年龄增长趋向保守（神经场尺度不变，但历史沉积持续积累，φ\_f 系统性下降）。

1\. 尺度律与场篇第十八的相互关系

尺度律与场的生灭（场篇第十八）有重要交叉：

大尺度场的 Death\_C（压缩性死亡）阈值 K\_dead 虽相同，但大尺度场更快趋近 K\_dead——因为 Scale 大导致 P\_s 高，K\_f 增速快；

大尺度场一旦达到 Death\_C，留下的深核残留（δ\_res^C）也更强——因为 Cap\_f 大，深核沉积度更高；

大尺度场发生 Death\_F（遗忘性死亡）的条件更苛刻——需要更长时间的续流中断才能使大容积场的沉积度全面衰减至 δᵣ 以下。

因此：大尺度场有更强的路径依赖性——既难以死亡（遗忘性死亡门槛高），又难以新生（压缩性死亡的深核残留强）。

1\. 尺度律与场篇第十七的相互关系

尺度改变场间耦合的动力条件（场篇第十七）：

大尺度场（B场）的 AnchorCapacity 绝对值高（既有熟径多），但 φ\_{f\_B} 低（相对开放度低）→ Gate(f\_B) 的 AnchorCapacity 条件容易满足，但 φ\_{f\_B} 项在 Compat 中贡献低（注：此处 Compat 引用场篇第十七耦合算子 Compat = φ\_{f\_B}·MatchTheta·FamOverlap\_eff，非场篇第二十的 Gate/Pass 分层表述）→ 大尺度观者场接受新输入时，虽然锚点多，但过门的新内容大多被旧熟径吸收（场篇第十七域满路径），实质性新结构难以形成；

小尺度场（B场）φ\_{f\_B} 高，新内容更容易形成独立新差分，但 AnchorCapacity 绝对值低，耦合成立的锚点条件要求更高。

1\. 动力方程

尺度定义方程：

Scale(f) = Cap\_f（直接等于场篇第十五可维续场容积）

尺度对压缩动力的影响：

Scale(f) ↑ ⇒ S\_f↑（平均）⇒ P\_s↑ ⇒ dK\_f/dt↑（K\_f 增速系统性偏高）

尺度对容积率的影响：

Scale(f) ↑ ⇒ K\_f↑、S\_f↑、OccItr\_f↑ ⇒ dφ\_f/dt 长期偏负 ⇒ φ\_f 均衡值系统性偏低

尺度对分辨率的影响：

Scale(f) ↑ ⇒ R\_f/Cap\_f（相对分辨率余量）系统性偏低

尺度律总关系：

Scale ↑ ⇒ K\_f↑，φ\_f↓，R\_f（相对）↓ ⇒ 保守性↑，独立新差分形成能力↓

Scale ↓ ⇒ K\_f↓，φ\_f↑，R\_f（相对）↑ ⇒ 保守性↓，独立新差分形成能力↑

1\. 总式

场尺度律一般式：

Scale(f) = Cap\_f（尺度 = 场容积，横向扩展量）

Scale ≠ Depth（尺度不等于层级，两者独立，引用场篇第十九）

Scale ↑ ⇒ K\_f 均衡值↑（大系统压缩强）

Scale ↑ ⇒ φ\_f 均衡值↓（大系统开放度低）

Scale ↑ ⇒ 保守性↑，路径依赖↑，独立新差分形成能力↓

Scale ↓ ⇒ 开放性↑，新差分易形成，但稳定性低（小尺度场 K\_f 低，结构不稳定）

尺度律的核心意义：现实系统中的保守性、固化、创新困难，并非偶然，而是大尺度场在有限容积中历史沉积持续累积的结构性后果。这一规律适用于认知场、语言场、社会场、文明场的一切层次。

1\. 定理

定理一：尺度与压缩正相关定理

在其他条件相同的情况下，Scale(f) 越大，K\_f 的长期均衡值越高；大尺度场系统性偏向高压缩。

证明要点：在持续输入 + 长时间运行前提下，Scale(f) = Cap\_f ↑ → S\_f 积累上限↑，长期均衡中 S\_f 系统性偏高（大空场 S\_f 极低时此链不适用）→ P\_s ∝ N\_f·O\_f↑（更多差分间交叠，场篇第十三）→ dK\_f/dt ∝ (1−K\_f)·max(0, P\_s−SDC\_f) 均衡值偏高 → K\_f 长期均衡 K̄\_f 随 Scale↑ 而系统性偏高；此为长期统计性规律，允许短期例外。∎

定理二：尺度与容积率负相关定理

在其他条件相同的情况下，Scale(f) 越大，φ\_f 的长期均衡值越低；大尺度场系统性偏向低开放度。

证明要点：由场篇第十五动力方程 dφ\_f/dt ∝ −S\_f − OccItr\_f − K\_f + α\_f；在持续输入 + 长时间运行条件下，Scale↑ → 长期 S\_f↑（大尺度场差分积累上限高，饱和度系统性偏高）；S\_f↑ → OccItr\_f↑（差分交叠积累更多，场篇第十四）；Scale↑ → K\_f↑（定理一）；三项负向驱动系统性偏高；同时 K\_f 高使 T\_replace 门槛高（场篇第十七），α\_f（恢复项）系统性偏低 → dφ\_f/dt 长期偏负 → φ\_f 长期均衡值偏低；对应：大型系统历史负担重，开放余量少，独立新差分形成能力系统性低于小尺度场。∎

定理三：尺度不等于层级定理

Scale(f) 与 Depth(f) 相互独立；大尺度场不一定是高层级场，高层级场不一定是大尺度场。

证明要点：Scale(f) = Cap\_f 由横向容积决定；Depth(f) 由纵向堆叠层数决定（场篇第十九层级关系定义）；两者定义完全独立——可构造高 Cap\_f 低层级场（如大型低层神经场），亦可构造低 Cap\_f 高层级场（如高度压缩的小规模概念场）；故两者无必然相关。∎

定理四：大尺度保守性定理

大尺度场（Scale(f) 大）的保守性高于小尺度场——即大尺度场倾向用旧熟径吸收新输入，形成独立新差分的能力系统性低于小尺度场。

证明要点：由定理一，Scale↑ → K\_f↑ → 共核覆盖广（场篇第十三），新输入被旧核吸收；由定理二，Scale↑ → φ\_f↓ → 开放续延域少（场篇第十五），新差分难以稳定；两者共同导致：大尺度场对新输入的处理方式以归入旧类为主，独立新差分的生成越来越困难 → 保守性↑；此与外篇第三·数论”分而有限则必压入一”一致：容积有限且历史积累重，压缩为必然。∎

定理五：大尺度路径依赖定理

大尺度场对自身历史结构的依赖程度高于小尺度场；大尺度场的结构一旦形成，改变成本随 Scale 增大而系统性增加。

证明要点：由场篇第十八，Death\_C 后的深核残留 δ\_res^C 强度与沉积深度正相关 → Scale↑ 使历史沉积积累更深 → δ\_res^C 更强 → 旧核残留增强，新输入被旧核吸附的概率↑ → 新场生成时路径依赖更强（场篇第十八定理四）；同时，Scale↑ → φ\_f↓ → FamOverlap\_eff 中旧熟径主导（场篇第十七）→ 耦合输入被旧核吸收 → 结构变化需要更强的 OutFlow 超过 T\_replace（场篇第十七定理五）才能触发裂解 → 改变成本随 Scale 增大而增加。∎

定理六：尺度-开放性权衡定理

Scale(f) 与 φ\_f 之间存在结构性权衡：大尺度场容积大但开放度低，小尺度场开放度高但绝对容量小；在长期稳定条件下，大尺度与高开放度难以长期同时维持。

证明要点：φ\_f = A\_f/Cap\_f，其中 A\_f 为剩余开放容积（场篇第十五）；随着持续续流输入、沁叠占域（OccItr\_f↑）、熟径锁定（K\_f↑）与压缩增强，A\_f 系统性下降（dφ\_f/dt 长期偏负，由定理二）；Cap\_f 为固定上限 → A\_f 在长期中系统性趋低 → φ\_f 长期趋低；若强行维持高 φ\_f，必须通过遗忘、边沁裂解或熟径重组释放 A\_f；但大尺度场 K\_f 高、T\_replace 门槛高（场篇第十七），释放成本随 Scale 增大而系统性升高；故大尺度高开放度的稳定均衡不可持续；系统必须在尺度与开放度之间权衡。
