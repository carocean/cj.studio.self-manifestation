# 总图

第一节

用途、性质与非新增声明

### 1.1 用途

律动力组式十三篇已分别封版。它们各自回答一个问题，彼此以接口相连；但十三篇共同把什么闭合成了一个理论对象、各篇之间哪些是硬逻辑依赖、哪些只是语义承继或运行依赖、哪些问题看似相近而实不可互代——这些只靠各篇的交叉引用已看不清楚。

本总图把这些关系一次画清，并给出律动力组式在当前申报工作域内的组级闭合边界。

### 1.2 性质

本总图是统摄形式，按《法篇第一》第五编第二章写作。它不是第十四篇，不是主式，不是证明式。

据此，本总图：

　　不新增待证命题  
　　不新增本体谓词  
　　不新增 H 条件  
　　不修改十三篇的任何封版结论

凡是本总图所载的承重结论，都逐条标注来源篇与版本，见第十二节的定理来源表与术语对应表。

本总图自身没有独立的可击穿命题。击穿本总图，就是击穿它所引的某一篇；若某篇升版而其结论改动，本总图随之核改，不得以统摄的地位压住局部式的修订。

### 1.4 工作域

本总图所述的闭合，限于各篇各自申报的工作域之内：

　　当前作用与程度　　一条已成的律，于一个时刻  
　　律动力　　　　　　一条已成的律，于一段合法轨迹

第二节

十三篇的五区结构

十三篇不是线性的十三步，而是五个功能区。

### 2.1 第一区　当前资格区（第一、二、三篇）

回答：一条已成的律，此刻是否真的在行；若在行，其程度剖面如何。熟的比较另依熟序域，见下。

第一篇证必要向

　　LawAct\_{F,t}( L ; ξ\_t )　⇒　CurLawBear

其中 CurLawBear = CurrentLawOccurrence ∧ DutyConformance，两层受同一份当前 realization 的绑定约束。

第二篇补充分向

　　CurLawBear　⇒　LawAct

两篇合成当前作用的双向闭合。

第三篇（v1.1）另问程度，分立两个分级域：

　　熟序域　J\_δ = { δ̄ }  
　　Degree 剖面域　J\_D = { δ̄, Reentry, 𝒵, FlowShare }

熟序域依原义比较更熟——熟的比较依沉积度（外三「可称深者为熟」、内九「其深积而在顶，称之谓熟」；场篇第一定义13、运算11），δ̄ 为路径沉积度统计。剖面域的四项是《熟径度量方程·场篇第十一》v1.2 续行竞争指数族 CI = Φ( δ̄, Reentry, 𝒵, FlowShare ) 的四个输入；𝒵 名续行代价。剖面中 𝒵 减小、其余三项增大被规定为有利方向，这不是已证的实际竞争优势，也不是「更熟」；不得以剖面序称更熟。为使四维同向，该篇统一记

　　D̂( q ) = ( δ( q ), Reentry( q ), −𝒵( q ), FlowShare( q ) )

其中 δ 指路径沉积度统计 δ̄；并于其第十节以同一第三分量取比较向量 D( q )；分量条件写作 𝒵\_A ≤ 𝒵\_B。第七篇承继此四坐标，记作 D( q, t ) = ( δ, Reentry, 𝒵, FlowShare ) 并标 𝒵↓（第七篇 v1.1 注明其对应 J\_D，δ 即 δ̄）。二者所指相同，记法不一，见 12.3 表 B（v1.0 误指 11.3）。

所得是偏序而非总分，分辨严格占优、等阶与不可比；非总分在合法 Law 域上以存在剖面交叉对为前提，四维不可删与非退化依 G\_{D-Sep}（第三篇 v1.1）。Degree 与当前作用资格分流，不回灌为 LawAct 的条件。

此区所立的是一个时刻上的资格与程度，尚未跨入轨迹。因此称当前资格区，不称动力区。

### 2.2 第二区　律动力区（第四、五、六、七篇）

回答：一条已成的律沿一段合法轨迹有无动力、怎样精确读出、能否到达、能否在真实基底上运行。这是整组的主干。

第四篇从时刻跨到轨迹段：

　　LawDyn　⟺　LegalLawSegment ∧ DynActual，　DynActual = ActDyn ∨₃ DegDyn

作用侧读起、续、止，程度侧读升、降、迁移；第十篇据此记六类事件为 Θ\_LD = { Start, Continue, Stop, Rise, Fall, Migration }。依第四篇 v1.1，程度侧的升、降、等阶、迁移是 Degree 剖面域 J\_D 上的关系：剖面降不等于退浅，更熟、退浅另依 δ̄ 于 J\_δ 判定，不在两投影之列。该篇的必要向与充分向都 Established，其穷尽限于所申报的作用侧与程度侧两个投影之内；进入条件 Law = 1 经充分向取得者携 SC\_Hold，经形式解传导者另携回读前件与 Ω\_e 补检，只经进入条件传导，不入主式（第四篇 v1.1）。

第五篇把第四篇的结构建成可执行的形式系统：

　　S\_LawDyn　⟼　M\_LawDyn

第六篇换了问题：给定初态、协议与目标，是否存在一条合法有限路径命中某一 LawDyn 目标。

　　SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 1

其义只有「存在一条路径」，不推出一切路径都命中，不推出必然，不推出概率一，不推出操作者可控。

第七篇回答前六篇的对象是否只是纸面定义：

　　∃ Spec\_LDB \[ Spec\_LDB = Augment\_cons( Spec\_LB, A\_LDB ) ∧ LawDynBaseCapable( Spec\_LDB ) \]

使 Law、LawAct、Degree、LawDyn 在以真实沉积场为基底的显式运行构造上取得可执行见证。依第七篇 v1.1：其程序层所证为判定核签出 R1 ∈ 𝒮；R1 ∈ 𝒮 经《律数理式》回读得 Established ∧ Govern，再由《律必然式》充分向得 Law，故读作 Law 时携 Ω\_e 补检（《律运行基底构造式》v1.3 K13）、回读前件与 SC\_Hold，读作 R1 ∈ 𝒮 时不携。

第六与第七并列，互不包含：前者回答可达的量词，后者回答显式构造与真实运行。

### 2.3 第三区　跨 occurrence 与历史归属审查区（第八、九篇）

此区不称身份区，因 SameLaw 未闭合。

第八篇只证两种配对规则可被合法观测区分：

　　OccPair\_LS^can　≠　OccPair\_B^can，　OccPair\_LS^can　⇏　OccPair\_B^can

二者都是配对规则，都不是 SameLaw。

第九篇问另一件事：一个事前冻结的 Law 候选，首次由正式 Law = 0 跨到 Law = 1，这一次首次成律由哪段实际历史承担。

　　LawGenesisSource^Π( H\_s ; χ\_L, τ ) = 1　⟺　Genesis^Π\_τ = 1 ∧ ActualGenesisLink^Π = 1 ∧ MinSuff^Π = 1

第八与第九并列为两条审查支，不是先后生成：配对的区分不产生来源，来源的认证也不产生身份。

### 2.4 第四区　直接交互闭合区（第十、十一、十二篇）

回答：一条已成的律对另一条已成的律的某一次动力事件，是否发生了直接的律际交互。

这是一组标准的三篇闭合。第十篇证必要向：

　　LawInteraction　⇒　LawInteractionBear

　　LawInteractionBear = 1　⟺　SourceLawContribution = 1 ∧ TargetDynGeneration = 1 ∧ SameInteractionBind = 1

右式有三个成立条件，而只有两个本体层；SameInteractionBind 只规定两层见证的同一。

第十一篇建其形式系统 S\_IntBear ⟼ M\_IntBear，读出 Read^M\_INT ∈ { 1, 0, ⊥ }，回读止于 Bear。

第十二篇证充分向：

　　C\_INT-S = 1 ∧ LawInteractionBear　⇒　LawInteraction

与第十篇合成

　　LawInteraction　⟺　LawInteractionBear

此双向成立于两篇共同冻结的工作域与 H 条件之下。其工作域为成对、事件级、直接；多级因果、交互图、反馈环与多律网络都不在内。因此称直接交互闭合区，不泛称多律动力区。

### 2.5 第五区　多律组织保持区（第十三篇）

回答：由多条正式 Law 与反复发生的正式 LawInteraction occurrences 共同实现的一份组织，在合法后继轨迹中如何保持、退出、替代、复归，以及在何种量词强度之下可签稳定。

第十三篇不新增生态本体：所稳定的是由已成立的上游事实所构成的组织资格证书，可展开回 Law、LawInteraction 与事前冻结的角色模板与评价协议。

其稳定审查有两条轴：

　　对象轴　　　x ∈ { fix, set }　原来那一份 realization 是否仍在；同类之中是否尚有其一  
　　轨迹量词轴　Λ ∈ { single, family, guaranteed }

合为一个二乘三的审查矩阵。∀k∃E\_k 只支持 set 层，∃E\_0∀k 才是 fix 层，二者不等价。

此区不称生态动力区：第十三篇未新增生态的力、生态的场或持久之交互。

### 3.1 三类依赖

篇与篇之间的依赖分三类：

　　H　硬逻辑依赖——下游的证明以上游的结论为前提，上游撤销则下游的结论随之失效或转为待定  
　　S　语义或协议承继——下游沿用上游的术语、分层、边界或协议，而其证明不以上游结论为前提  
　　R　运行实现依赖——下游的对象必须在上游所给的运行基底上方能取得见证

依赖箭头不是因果箭头，也不是时间生成箭头。一条 H 箭头说的是「此篇的证明用到彼篇的结论」，不说「彼篇的对象产生了此篇的对象」。

第五节

LawDyn 的六类事件与运行实现

### 5.1 六类事件

作用侧为起、续、止，程度侧为升、降、迁移（第四篇）。第十篇记为

　　Θ\_LD = { Start, Continue, Stop, Rise, Fall, Migration }

Rise 与 Fall 用 Degree 的偏序判定；Migration 是 Degree profile 的确定不可比，无增减的区分（第三、七篇）。三者都是 Degree 剖面域 J\_D 上的事件，不是熟序；不得以 Rise 称更熟或竞争更占优，不得以 Fall 称退浅（第三、四、七篇 v1.1）。

### 5.2 LawDyn 是读出，不是原因

第七篇明言：LawDyn、DynActual、ActDyn、DegDyn 都是对已有场状态与轨迹的读取与判定，不是新的动力原因。

因此正确的方向是

　　场的动力　→　轨迹　→　LawDyn 的读出

不得画作

　　LawDyn　→　场的变化

### 5.3 三层

同一个 LawDyn 在三层各有其位：第四篇给其对象资格，第五篇给其形式系统，第七篇给其在真实沉积场上的运行见证。三者不相代：形式系统可求，不即对象成立；对象成立，不即已在真实基底上运行。

### 11.1 未闭合的

以下各问不在本组闭合之列，本总图主动列出，以防误用。

身份。SameLaw 的定义与判定未闭合。第八篇只证两种配对规则可区分，二者都非身份判据；其 13.3 明言：尚未产生一个闭合的 Law identity 性质。十三篇凡是涉身份之处都不越线，故此问未闭，不构成律动力本体的缺口。

可控。第六篇只证存在一条路径，不证可控，不证全称，不证概率一。

多级交互网络。第十至十二篇只处理成对、事件级、直接的交互；长级联、因果祖先图、全局交互网络及其可控性，都不在内，也非第十三篇所补。

概率。六类事件可判其发生、变化、可达；某事件以多大概率发生、多律竞争之下未来事件如何分布，不是本组的内容。各篇于此有明示：第六篇不升为概率一，第七篇所证不是概率定理，第九篇不主张概率的来源分布。

意向选择。本组回答一条律如何在行、如何动、如何与另一律交互；不回答哪条律为何被当前的意图选中，意图场如何配置、驱动、竞争与改路。

计算。本组已有运行基底与形式系统，不等于已回答何为计算、何种结构只是合法运行而非计算。十三篇中「计算」一词只作寻常的含义用——求 profile、求解的有限步骤等——无一篇立其定义；第五篇并明言不断言各子程序在一切场规格上都可计算终止。
