# 律动力数理式

第一节

目的

结构输入 S = 《律动力一般式》v1.1（封版）及其所承继的前三篇（第三篇《律分级式》现行 v1.1，第一、二篇现行 v1.0）。形式输出 M = 本篇律动力形式系统。本篇为映射

　　S\_LawDyn ⟼ M\_LawDyn

S 所给出的结构为

　　LawDyn^η\_F(L; I, Γ\_dyn) = 1  
　　⟺　LegalLawSegment^η\_F(L; I, Γ\_dyn) = 1　∧　DynActual^η\_F(L; Γ\_dyn) = 1

其中 DynActual = ActDyn ∨₃ DegDyn。

其分量为：合法 Law 动力段及其五项——同一合法轨迹段、目标引用固定、段内资格保持、更新循协议、评价协议事前冻结；动力实际性；作用动力与程度动力两投影；三值析取合成；三值传导与资格层界线。

本篇在既有《律数理式》的形式基底与场篇的沉积场之上，为上述分量建立精确表示、状态空间、双时钟、运行与后继算子、求解程序、耦合与回读规则，并承担第四篇下交的贡献归属、失承切集、优势得失各项的形式化。

本篇不重证第四篇的最低必要结构。那一篇以失败世界逐项逼出两项，其必要向与充分向的 Status 都是 Established；本篇不重走那条路，也不以任何方式重新追问"一条律有动力最少必须有什么"。本篇所证的是形式实现：M 对 S 已经成立的各分量给出可运行、可求解的实现，其确定输出可逐项可靠回读（未决输出不赋值对象层，见 7.2），且其形式辅助对象不新增本体条件，不新增场量，不改变第四篇的定理方向与状态。

本篇不承担独立判定式任务。作为数理系统，它必须能够在给定合法输入时执行求解并返回形式读数——第五节的 SolveLawDyn 即此。但判定协议的完备性、PASS 与 FAIL 的分类、识别职责与判定域资格，都不在本篇另立，归判定层。

第二节

核心论题

S 的结构分两层：资格层与读出层。

资格层即 LegalLawSegment，五项的合取，决定一个候选段是否进入评价，对象层取值二元。

读出层即 DynActual 及其两投影：沿已冻结的 T\_η 逐对相邻评价点，一侧读当前作用的静置、起、续、止，一侧比 Degree profile 的升、降、等阶、迁移，各自三值聚合，再以三值析取合成。程度侧所比的是《律分级式》v1.1 的 Degree 剖面域 J\_D，不是熟序：剖面升不称更熟，剖面降不称退浅；更熟、退浅另依 δ̄ 于熟序域 J\_δ 判定，不在两投影之列（《律动力一般式》v1.1）。

本篇必须精确表达七件。

其一，两套索引的分离。底层执行有其自身的步序，评价协议另有其点集；二者不可共用一个索引，否则第四篇专门划开的"评价尺度不等于底层执行尺度"在符号层被合回去。

其二，状态空间的分层，以及读出量不入状态。运行、沉积、结构三类状态承担不同时相角色；Law-side 的读出量不得作为持久状态分量。

其三，双时钟。运行时间与沉积时间不可压为一个 t，且其增量不得被预签为运行模式的单值函数。

其四，运行算子的地位。𝓡 与 Φ 不是本篇凭空假定的新动力律，而是上游已有合法转移的形式因子化。

其五，资格层的机器读出。五项必须分别有可执行的读出，再以零吸收型三值合取合成；机器不可读与资格失败必须严格分开。

其六，三值的两套制度。动力事件的存在采一吸收型析取，贡献证书与资格合取采零吸收型合取，二者不得混用。

其七，固定 η 之下的多解。本篇为给定一段求其动力，不生成新的 η；多解只指同一 η 之下形式完成的不唯一，不涉可达性。

形式方向分正向求解与反向回读两路，都必须完备，无悬空符号。

第三节

基础对象与定义序列

本节逐条给出定义，编号冻结。每一条或对应 S 的一个分量，或申明为纯形式辅助对象。

### 3.0 对象来源三分

凡是本篇出现的符号，属以下三类之一，逐条标明。

上游本体对象：已有定义，只调用，不重定义。含 Law、Established、Govern、DynamicRole、ΩSupport、Rel(L)、Type、Read、Cov、Ante、Trig、LawAct、CurLawBear、CurrentLawOccurrence、DutyConformance、Binding、ξ\_t、Degree 四坐标（剖面域 J\_D）、⪰\_D、Front、G^Γ\_D、Γ\_D、∥\_D、⊥\_D、LegalLawSegment、ActDyn、DegDyn、DynActual、LawDyn、Traj、Spec\_F、Init、Prot。

既有形式对象：出自《律数理式》、场数理式与封版第三篇，复用不另造。含 EstWitness^M、DynamicRole^M、ΩSupport^M、Bind^M、Govern^M、形式解集 𝒮(F\_t, L, I)、Existing\_t、ActArg、ActArg^μ、RolePath、RoleReal、RoleCtx、Hosts、Comp、Scheme；沉积侧的 Decay、Trace、Sediment；Degree 侧的比较系统 Cmp\_D 与整律 profile 空间 𝒢\_D；以及运行协议中的 Mode\_exo、Mode\_endo、Freeze、Thaw、IdleStep、do(Mask)、do(Avail)。

纯形式辅助对象：为表示、索引、求解与回读而设，不新增场量，不新增本体谓词，不承担独立真值，不作动力原因。含 r、k、a、χ、R\_η；状态空间 𝒳 及其三分量 𝒳\_run、𝒳\_sed、𝒳\_str，输入空间 𝒰，模式空间 𝓜，见证包空间 𝒴 与其 Trace 可读子空间 𝒴\_trace；X\_r、Y\_r、u\_r、m\_r、ζ\_r、σ(r)、Step^M\_Prot、Trans\_Prot、WitTrans、π\_tr、π\_F；沉积门 ς 及其值域常量 WRITE、DECAY、HOLD；E^eval\_k、Exec(E\_k)；五项资格读出与 Lift\_{hold→Seg}、ReadLegalSeg、ReadLawHold、Dom\_Legal、𝓛\_Γdyn；相邻步读数 StepAct\_k 与 StepDeg\_k 及其值域常量 Idle、Start、Continue、Stop 与 Rise、Fall、Equal、Migration；𝓔\_η、𝓤\_η、CompatSol、Agg\_Sol、SolveLawDyn 及其 solver 状态；历史支持读出 𝒪\_Ω；以及第八节贡献模块的实际子段、源点索引、事件见证对象、全部证书、见证集合与切集族。

必须特别申明：Law、LawAct、Degree、ActDyn、DegDyn、DynActual、LawDyn、DynContrib 都不是新增动力状态变量。它们是读出与判定，不进入运行律，不参与流的分配，不对任何量施加作用。这是第四篇先行的辨所锁，本篇承继。

### 3.1 两套索引

底层执行索引

　　r = 0, 1, 2, …

用于底层状态与单步记录：X\_r、Y\_r、u\_r、m\_r、σ(r)、ζ\_r。

评价点索引

　　k = 0, 1, …, n

只用于第四篇所冻结的 T\_η = ( t₀ \< t₁ \< ⋯ \< t\_n )，n ≥ 1。

二者不共用。凡是涉底层执行者一律用 r，凡是涉评价点的一律用 k。

### 3.2 锚定映射

　　a : { 0, 1, …, n } → ℕ，　a(0) \< a(1) \< ⋯ \< a(n)

a(k) 为第 k 个评价点 t\_k 所对应的底层执行索引，即该评价点上所读的底层状态为 X\_{a(k)}。

a 严格增，保证评价点在底层序上不倒置、不重合。

### 3.3 状态空间

　　X\_r = ( X^run\_r, X^sed\_r, X^str\_r )　∈　𝒳 = 𝒳\_run × 𝒳\_sed × 𝒳\_str

X^run　当前运行所需的快状态：场运行状态、当前流、续行代价 𝒵（旧名续行阻抗，依场篇第四 v1.2 改名）、当前可用性、调谐等，都是上游已有对象。

X^sed　沉积侧的慢状态：沉积度 δ、复走历史与历史支持等。此处不以「积深」名状态：依《场数理式》v2.7，沉积深浅的状态量名沉积度 δ（定义9），加深是其过程（方程2 之 Dτ）；复走历史须保留在 X^sed 之中，因 Ω\_W 所查的复走事实不能由当前 δ 唯一恢复（见 6.4）。

X^str　结构事实：关系组织、RolePath、carrier、合法承载结构的当前状态。

不设第四分量 X^read。Law-side 的读出量不得作为持久动力状态分量——若设它，则读出可经 Φ 进入后继状态，读出便成了原因，违 3.0 末段的申明，触 K-MD7。

### 3.4 双时钟

　　σ(r) = ( t\_run(r), t\_sed(r) )

增量记

　　σ(r+1) − σ(r) = ( Δt^run\_r, Δt^sed\_r )，　Δt^run\_r ≥ 0，　Δt^sed\_r ≥ 0

要求该对增量与 Prot、m\_r、ζ\_r 相容——即在该协议与该模式之下，这一对增量是被允许的。

不要求 t\_run = t\_sed，不要求 Δt^run\_r = Δt^sed\_r，也不预签增量为运行模式的单值函数。具体规格若规定由模式唯一确定，则在该规格之内退化为函数；此退化是规格的性质，不是本篇的假设。

三种情形必须都可表示：运行推进而沉积冻结（Δt^run \> 0，Δt^sed = 0）；沉积老化而无实际当前作用（Δt^sed \> 0 而该段无起无续）；二者同时推进。

强令 t\_run = t\_sed，或强令两增量相等的，触 K-MD9。

### 3.5 合法单步与 𝓡、Φ 的因子化

上游《律数理式》与场数理式已给出合法轨迹

　　τ ∈ Traj( Spec\_F, Init, Prot )

其中的合法一步为四元组 ( X\_r, u\_r, m\_r, X\_{r+1} )，m\_r ∈ 𝓜 为运行模式。

先记上游的一步转移关系

　　Trans\_Prot ⊆ 𝒳 × 𝒰 × 𝓜 × 𝒳

其成员即 Prot 所许可的合法一步。

本篇不另立动力律，只把这一步作形式因子化：在中间插入形式转移见证 Y\_r，把一步分解为两段

　　X\_r　──𝓡──▶　Y\_r　──Φ──▶　X\_{r+1}

据此定义

　　𝓡 : 𝒳 × 𝒰 × 𝓜 ⇉ 𝒴，　Y\_r ∈ 𝓡( X\_r, u\_r, m\_r )  
　　Φ : 𝒳 × 𝒴 × 𝓜 ⇉ 𝒳，　X\_{r+1} ∈ Φ( X\_r, Y\_r, m\_r )

并以下式定其为因子化，非仅插入一个中间符号：

　　Trans\_Prot( X, u, m, X′ )　⟺　∃Y \[ Y ∈ 𝓡( X, u, m ) ∧ X′ ∈ Φ( X, Y, m ) \]

记满足该式的 Y 的全体为 WitTrans( X, u, m, X′ )，即该合法转移的形式分解见证集。

分量写作 Φ = ( Φ\_run, Φ\_sed, Φ\_str )。

必须说清 Y 的地位，并把其型别的最低要求一并定死——否则 3.7 取 Y 去写沉积时无所依据。

本篇不声称场中天然长着一个当前产出对象。Y 是对既有合法转移的形式分解见证；但它不是任取的一个中间符号，其最低要求为：

　　Y ∈ 𝒴　必须携带该合法单步之中，足以供后继更新取用、并足以供上游 Trace 读取的实际执行信息。

即 Y 是执行见证包，而非空占位。凡是不携带这些信息的不入 𝒴，其所参与的分解不是本篇所认的因子化。

Trace 所能读取的那一部分另设投影：

　　π\_tr : 𝒴 → 𝒴\_trace

其中 𝒴\_trace 为上游 Trace 所许可的实际执行记录空间。π\_tr 只作取出，不添内容；3.7 的写入分支取 π\_tr(Y\_r)，不取整个 Y\_r。

Y 的更具体内容仍待具体场规格给定——若某规格把它具体化为当前流、产出包或别的对象，那是该规格的事；但无论如何具体化，上述最低要求与 π\_tr 的存在都不可少。

单值性不签：取集合值映射，不预设底层动力普遍确定；若具体规格满足 \|𝓡(X, u, m)\| = 1 与 \|Φ(X, Y, m)\| = 1，则退化为单值函数。

不预签 Φ = 𝒢 ∘ 𝒰 或 Φ = 𝒰 ∘ 𝒢。沉积更新与结构更新各有其位置，其串行次序不作普遍假定。

### 3.6 单步记录

上游 Prot 所许可的是四元转移，不含形式见证 Y。因此必须另立本篇的见证化单步集：

　　Step^M\_Prot = { ( X, u, m, Y, X′ ) : Trans\_Prot( X, u, m, X′ ) ∧ Y ∈ WitTrans( X, u, m, X′ ) }

于是

　　ζ\_r = ( X\_r, u\_r, m\_r, Y\_r, X\_{r+1} )　∈　Step^M\_Prot

二者必须分清，不得以一名兼两义：

　　Trans\_Prot　　上游合法转移，四元，不含 Y  
　　Step^M\_Prot　 本篇加入形式见证后的单步记录，五元

ζ\_r 是纯形式记录，不新增场量；其五个分量都已在 3.3 与 3.5 中定义。

### 3.7 沉积更新协议

协议读出定义在整个合法单步空间上：

　　ς : Step^M\_Prot → { WRITE, DECAY, HOLD }

即 ς(ζ\_r) 读取整个合法单步记录及其协议语义，不只凭模式的名称决定。模式空间尚含 Mode\_exo、Mode\_endo、Thaw、do(Mask)、do(Avail) 各项，其沉积后果必须由该步的协议语义定，若只写作 m\_r 的函数，则这些模式的落点无处安放。

据此

　　X^sed\_{r+1} =  
　　　　Sediment( Trace( Decay(X^sed\_r), π\_tr(Y\_r) ) )　　若 ς(ζ\_r) = WRITE  
　　　　Decay( X^sed\_r )　　　　　　　　　　　　　若 ς(ζ\_r) = DECAY  
　　　　X^sed\_r　　　　　　　　　　　　　　　　　若 ς(ζ\_r) = HOLD

此处写作状态式而非 Φ\_sed 的等式：Φ 为集合值映射，其沉积分量在给定 ζ\_r 之后取定一个后继状态，二者型别不同，不能混淆写。

用法：按协议必须写入沉积的合法实际执行取 WRITE；IdleStep 取 DECAY；Freeze 取 HOLD，或按上游冻结协议保持相应分量。

"合法实际执行"不等于"取 WRITE"：Freeze 本身也可以是一次实际执行，却按协议明确不写沉积。判据在协议，不在是否实际。

以下一律不得自动进入 Trace 与 Sediment：候选评价；假想分支；复走探测；非实际执行；未许可的手工改写。违反的，即触犯 K-MD8。

### 3.8 评价步与底层执行段

评价步

　　E^eval\_k = ( t\_k, t\_{k+1} )，　k = 0, …, n−1

其底层执行段

　　Exec( E\_k ) = ( ζ\_{a(k)}, ζ\_{a(k)+1}, …, ζ\_{a(k+1)−1} )

长度为 a(k+1) − a(k) ≥ 1。

由 a 严格增，该长度恒为正，故每一评价步之内至少有一个合法单步。

不假定评价步与底层单步一一对应。第四篇的续为评价协议相对的结论，其两端相同不保证其间只走了一步，也不保证其间无中断于更细尺度；贡献归属必须能下钻到 Exec(E\_k) 之内，见第八节。

### 3.9 Law 资格回读算子

　　𝒬 : 𝒳 × L × I → { 1, 0, ⊥\_Q }

只作上游 Law 的形式回读，不重判资格。⊥\_Q 表示机器无法完成该回读，非资格失败。

注（Law 读出所携条件，对应《律必然式》v1.4、《律一般式》v2.6 与《律动力运行基底构造式》v1.1）　𝒬 的内容为《律数理式》的形式判据（6.1），程序上所判者为形式解 R ∈ 𝒮。由此读作对象层 Law = 1，经《律数理式》回读得 Established ∧ Govern，携其回读前件；再经《律必然式》充分向得 Law，携承接条件 SC\_Hold；判据所读之 Ω 若为工程资格 Ω\_e，另携 Ω\_W 事实二、三之补检（《律运行基底构造式》v1.3 K13）。故 𝒬 = 1 读作「R ∈ 𝒮」时不携上列条件，读作「Law 成立」时携之。正负两向的读出依据不同。𝒬 = 1：有符合判据的形式见证 R ∈ 𝒮，并满足上列读作 Law 所需条件。𝒬 = 0：须有足以否定对象层 Law 的可靠依据；某个候选 R 不属 𝒮，或未找到见证，本身不足以判 Law = 0，此时回读未闭合，返回 ⊥\_Q。SC\_Hold 等条件只说明正向承接，不替代负向判定依据。下文定理零所设「读出可靠」之前件（3.12），对 R\_hold 一项即含此两向依据。

### 3.10 当前作用回读算子

　　𝒜 : 𝒳 × L × ξ → { 1, 0, ⊥\_A }

回读 LawAct ⟺ CurLawBear，即由封版第一、二篇的双向闭合取值。不重定义 LawAct，不另造第二套。⊥\_A 承自第二篇所定的形式回读三值边界。

### 3.11 Degree 回读算子

　　𝒟\_{Γ\_D} : 𝒳 × L → 𝒢\_D ∪ { ⊥\_D }

其中 𝒢\_D 为第三篇所定的整律 Degree profile 空间，即该篇 v1.1 之 Degree 剖面域 J\_D = { δ̄, Reentry, 𝒵, FlowShare } 上的 profile；四项是《熟径度量方程·场篇第十一》v1.2 续行竞争指数族 CI 的输入，剖面方向（𝒵 减小、其余三项增大）为该篇规定的有利方向，不是实际竞争优势，也不是更熟。输出为 profile，不输出单标量总分；profile 也不是熟度——熟的比较依沉积度（外三「可称深者为熟」），在该篇另立的熟序域 J\_δ = { δ̄ } 上进行，不在本篇读出之列。输出 Grade(L) 或 LawStrength(L) 的，触 K-MD6。

　　⊥\_C　　贡献证书未决（第八节）  
　　⊥\_branch　同一 η 之下多个形式完成解未能一致（5.6，solver 层，见 5.7）

本篇正为防止不同层面的不可判互相污染而设此分层，故不得一符多用。

读出可靠与完整可读。二者须分开：

　　读出可靠　机器返回确定值（1、0，或确定的步类、比较值）时，该值即对象层相应对象的值  
　　完整可读　机器在所论范围内不返回任何 ⊥

本篇各回读定理只以读出可靠为前件，完整可读不作一般假设。读出可靠之下，机器返回 ⊥ 只表示本次读取未决，不推定对象层亦不可判——对象层可以确定成立而机器读不出。若要把机器 ⊥ 与对象层不可判逐值对应，须另设并论证前件 H\_Exact（机器各层的不可判与对象层相应不可判准确对应）；本篇不主张 H\_Exact。

### 3.13 段内资格保持的对象层与机器层

对象层

　　LawHold^η ∈ { 1, 0 }

即第四篇定义二其三所要求的段内资格保持，二值，承自第四篇，本篇不改。

机器层另设读出，见 3.14。二者不得混写：机器读不出，不等于资格不保持。

### 3.14 段内资格保持的机器读出

量化范围必须先钉死。工作段所覆盖的底层执行索引为

　　R\_η = { r ∈ ℕ : a(0) ≤ r ≤ a(n) }

即自首个评价点所锚定的底层状态起，至末个评价点所锚定的止。

若底层合法轨迹为离散执行序列，则

　　ReadLawHold^η =  
　　　　0　　　　若 ∃r ∈ R\_η：𝒬( X\_r, L, I ) = 0  
　　　　1　　　　若 ∀r ∈ R\_η：𝒬( X\_r, L, I ) = 1  
　　　　⊥\_hold　 无 0 而至少有一 r ∈ R\_η 使 𝒬 = ⊥\_Q

若底层规格为连续时间，则调用上游的连续保持制度在 \[t₀, t\_n\] 上取得相应三值读数，本篇不另造。此区间即工作段 η 的全域，与离散情形的 R\_η 对称；写作 \[t₀, t₁\] 的只覆盖首个评价步，n \> 1 时漏检。

量化不得跑到 R\_η 之外。第四篇所要求的是该动力段之内的资格保持，不是整条系统历史上的永久成立：一条律可以在 X\_0 尚未成立、其后某处成立、而本段自始至终保持——此段的资格保持无瑕，若因段外某点的 𝒬 = 0 而判本段不保持，则把别处的事算到本段头上。

分辨率则必须跑满 R\_η：T\_η 负责动力评价，底层轨迹制度负责段内资格保持。以 T\_η 的有限评价点代段内保持，是把评价分辨率当作资格分辨率。因此本条的量化跑在 r 上，不跑在 k 上，而其范围恰为 R\_η。

### 3.15 合法段的机器读出

对象层 LegalLawSegment^η ∈ { 1, 0 }，二值，承自第四篇，本篇不改。

机器层为五项分别读出：

　　R\_traj　　同一合法轨迹段：η 是否确为某 τ ∈ Traj(Spec\_F, Init, Prot) 的区间限制  
　　R\_target　目标引用固定：L 与 I 在段内是否未经更换  
　　R\_hold　　段内资格保持：取 ReadLawHold^η（3.14）  
　　R\_prot　　更新循协议：段内每一 ζ\_r 是否属 Step^M\_Prot，有无段外改写  
　　R\_freeze　评价协议事前冻结：T\_η 是否满足良构条件，且段开始之前已冻结、其后未经增删改

型别必须写死，不另立新的不可判记号。

　　R\_traj, R\_target, R\_prot, R\_freeze ∈ { 1, 0, ⊥\_Seg }

四项直接取合法段层的不可判值。

R\_hold 则由 3.14 的读数提升而来：

其中

提升只改所标的层，不改真值。

合成取零吸收型三值合取：

其值严格落在 { 1, 0, ⊥\_Seg } 之内：任一项确定为 0 则整段确定非法；五项都是 1 则确定合法；无 0 而至少一项为 ⊥\_Seg 则为 ⊥\_Seg。

本篇不设 ⊥\_traj、⊥\_target、⊥\_prot、⊥\_freeze 四种记号——3.12 的分层若可随处添项，分层本身即失效。

三值只在机器层，不上溯改写对象层。

### 3.16 LawDyn 读出偏函数

　　𝓛\_{Γ\_dyn} : Dom\_Legal ⇀ { 1, 0, ⊥\_Dyn }

其中

　　Dom\_Legal = { (η, L, I, Γ\_dyn) : LegalLawSegment^η = 1 }

在定义域之内，其取值即由 DynActual 给出：

　　𝓛\_{Γ\_dyn}( η, L, I ) = DynActual^η

依据为第四篇的三值传导——LegalLawSegment^η = 1 时，LawDyn 的三档取值逐档由 DynActual 传出，不另作判断。因此本偏函数即整段 LawDyn 的回读算子，非装饰记号；5.5 第九步径用它。

非法评价对象不进入定义域，不返回 LawDyn = 0。这就是第四篇资格层与读出层界线的机器侧实现。违反的，即触犯 K-MD3。

### 3.17 三值联结

一吸收型析取，承自第四篇，原样复用：

　　1 ∨₃ x = 1；　0 ∨₃ 0 = 0；　0 ∨₃ ⊥ = ⊥；　⊥ ∨₃ ⊥ = ⊥

真值表：

　　　　　　1　　0　　⊥  
　　1　　　1　　1　　1  
　　0　　　1　　0　　⊥  
　　⊥　　　1　　⊥　　⊥

零吸收型合取，用于资格合成（3.15）与贡献证书（第八节）：

　　0 ∧₃ x = 0；　1 ∧₃ 1 = 1；　1 ∧₃ ⊥ = ⊥；　⊥ ∧₃ ⊥ = ⊥

真值表：

　　　　　　1　　0　　⊥  
　　1　　　1　　0　　⊥  
　　0　　　0　　0　　0  
　　⊥　　　⊥　　0　　⊥

两套不得混用。析取问"有没有发生"，一处确定即确定；合取问"是不是全都成立"，一项不成立即不成立。

按法篇数理式规范，凡定义序列中含关系者，须逐项申明其性质，不得默认。

a　严格增的单射，自 { 0, …, n } 入 ℕ。不主张满射。

𝓡、Φ　集合值映射，非函数。其表示的存在性由上游合法转移承继（3.5）；不主张单值性，不主张任何序性质。

𝓛\_{Γ\_dyn}　偏函数。定义域为 Dom\_Legal，域外无定义——非"取值为零"。

⪰\_D　偏序：自反、反对称、传递。三性质由第三篇在 Degree 向量集上证得，本篇承继，不重证。

∼\_D　等价关系，由向量相等诱导，承自第三篇。

∥\_D　对称，反自反；不保证传递。第三篇确立其为双方都确定不能覆盖对方时的确定不可比，本篇承继该义；至于是否存在非传递实例，第三篇未作一般证明，本篇也不加强主张。

WitTrans　集合值映射，𝒳 × 𝒰 × 𝓜 × 𝒳 ⇉ 𝒴。其值可为空——空当且仅当该四元组不属 Trans\_Prot；非空时不主张单元素。

第四节

方程与运行

### 4.1 运行方程

　　Y\_r ∈ 𝓡( X\_r, u\_r, m\_r )  
　　X\_{r+1} ∈ Φ( X\_r, Y\_r, m\_r )  
　　σ(r+1) − σ(r) = ( Δt^run\_r, Δt^sed\_r )，与 Prot、m\_r、ζ\_r 相容

三式构成本篇的运行系统，都跑在底层索引 r 上。第一式给当前产出，第二式给后继状态，第三式给双时钟推进。

沉积门由合法单步依其协议语义决定，即 ς(ζ\_r)；模式 m\_r 是该语义的组成之一，但不单独决定沉积门。模式的取值由既有运行协议给出：Mode\_exo、Mode\_endo、Freeze、Thaw、IdleStep、do(Mask)、do(Avail)；其中 Freeze 明为沉积关闭，而它同样可以是一次实际执行，故门的判据在协议语义，不在模式的名称。

m\_r 另约束两个时钟增量的可取范围。

三式的存在性不另证：由 3.5，它们是上游合法转移的形式因子化，凡是上游给出合法轨迹，三式即可逐步写出。

### 4.2 读出不入运行

三式之中，𝓡 与 Φ 的自变量只有 X、u、m、Y 四者。

Law-side 的读出量——𝒬、𝒜、𝒟 的输出，以及由其聚合所得的 ActDyn、DegDyn、DynActual、LawDyn、DynContrib——一律不出现在 𝓡 与 Φ 的自变量之中。

这是本篇最要紧的一条形式纪律。读出若入运行，则与第四篇的申明相违——那里已把五个对象锁为读取与判定，非新增场量；更实际的后果是重复计账：四项 Degree 坐标与作用侧读数本已由场篇与前三篇的制度决定，若令其聚合读数反驱其输入，同一份动力被计入两次。

若日后确需在运行律中安置某个与本篇结论相关的量，必须先证明它携带其余运行输入无法恢复的独立信息，再走升版程序；在此之前不得径入。违反的，即触犯 K-MD7。

### 4.3 沉积写入的闸门

X^sed 的后继更新按 3.7 的协议门分三支——Φ 的沉积分量在给定 ζ\_r 之后由该三支状态式约束，此处不写作 Φ\_sed 的等式。闸门的设置，为的是把"实际发生过"与"只是被评价过"分开。

候选评价、假想分支、复走探测都必须运行系统给出读数，但它们不是这一回实际走过的路；若令其进入 Trace 与 Sediment，则沉积量被评价行为本身改写，其后所读的 Degree 便含有评价的痕迹。这正是第四篇论证流第二节所排除的手工改写的形式变体。

### 4.4 求解输入

　　𝕀\_η = ( Spec\_F, Init, Prot, τ, η, T\_η, a, L, I, Γ\_dyn, Γ\_D )

其中 η 必须为 τ 的区间限制，T\_η 必须满足第四篇的良构条件，a 必须严格增。

输入之中已含 η。本篇是给定一段求其动力，不从 Spec\_F 与 Init 生成新的 η——生成与搜索属第六《律可达式》，见 5.6 与第十节。

第五节

求解

### 5.1 作用侧

令

　　A\_k = 𝒜( X\_{a(k)}, L, ξ\_{t\_k} )，　k = 0, …, n

相邻步

　　StepAct\_k =  
　　　　Idle　　　若 (A\_k, A\_{k+1}) = (0, 0)  
　　　　Start　　 若 (0, 1)  
　　　　Continue　若 (1, 1)  
　　　　Stop　　　若 (1, 0)  
　　　　⊥\_A　　　其余，即 A\_k 或 A\_{k+1} 为 ⊥\_A

聚合

　　ActDyn^η =  
　　　　1　　若 ∃k：StepAct\_k ∈ { Start, Continue, Stop }  
　　　　0　　若 ∀k：StepAct\_k = Idle  
　　　　⊥\_A　其余

三档次序即存在极性居先：任一相邻步已确定为起、续、止，则未知步不得洗掉已确认的动力。

不可读的点不得删出 T\_η。删点以制造二值的，触 K-MD5；跳过 T\_η 内点而只比两端的，触 K-MD4。

### 5.2 程度侧

令

　　G\_k = 𝒟\_{Γ\_D}( X\_{a(k)}, L )

相邻步调用第三篇既有比较系统

　　StepDeg\_k = Cmp\_D( G\_k, G\_{k+1} ) ∈ { Rise, Fall, Equal, Migration, ⊥\_D }

其中 Rise 为 G\_{k+1} ≻\_D G\_k，Fall 为 G\_k ≻\_D G\_{k+1}，Equal 为 G\_k ∼\_D G\_{k+1}，Migration 为 G\_k ∥\_D G\_{k+1}；若 G\_k 或 G\_{k+1} 为 ⊥\_D，或比较本身不可判，则该步为 ⊥\_D。

四值都是 Degree 剖面域 J\_D 上的关系：Rise 是剖面升，不称更熟，也不称竞争更占优；Fall 是剖面降，不称退浅——退浅指沉积度下降（《场数理式》v2.7 方程2 之 Eλ 压过 Dτ），只读 δ̄（《律动力一般式》v1.1）。

聚合

　　DegDyn^η =  
　　　　1　　若 ∃k：StepDeg\_k ∈ { Rise, Fall, Migration }  
　　　　0　　若 ∀k：StepDeg\_k = Equal  
　　　　⊥\_D　其余

Migration 一项必须保持 profile 层：它是 G\_k ∥\_D G\_{k+1}，即两侧都确定不能覆盖对方，其来源可为单份记录内部的坐标交叉，也可为不同评价单元之间或同一单元前沿成员之间的交叉优势。压成单一四维向量"有升有降"的，触 K-MD6。

### 5.3 合成

　　DynActual^η = ActDyn^η ∨₃ DegDyn^η

按 3.17 的析取真值表。

### 5.4 动力事件编码

为贡献模块之用，定义纯形式事件集

　　𝓔\_η(L) = { (k, χ) : χ ∈ { Start, Continue, Stop, Rise, Fall, Migration }，且第 k 步确定为 χ }

事件类型记 χ，不用 τ——后者已在 3.5 冻结为合法轨迹的名称，同名即冲突。此后事件写作 e = (k, χ)。

与未决步集

　　𝓤\_η(L) = { k : StepAct\_k = ⊥\_A 或 StepDeg\_k = ⊥\_D }

二者只是 DynActual 的形式编码，不是新的本体定义，不改变任何取值。

命题一（编码表示）

　　𝓔\_η ≠ ∅　⟺　DynActual^η = 1  
　　𝓔\_η = ∅ 且 𝓤\_η = ∅　⟺　DynActual^η = 0  
　　𝓔\_η = ∅ 且 𝓤\_η ≠ ∅　⟺　DynActual^η = ⊥

证明。由 5.1 与 5.2，两投影取一当且仅当存在确定的动力步，即 𝓔\_η 非空；两投影都取零当且仅当各步都是 Idle 与 Equal，即无确定动力步也无未决步；其余的即 𝓔\_η 空而 𝓤\_η 非空，按 3.17 的析取表恰为 ⊥。∎

### 5.5 主求解程序

　　SolveLawDyn( 𝕀\_η )

一　按 3.15 求 R\_traj、R\_target、R\_hold、R\_prot、R\_freeze，合取得 ReadLegalSeg^η。

二　若 ReadLegalSeg^η = 0，返回 solver 状态 OutOfDomain，终止。

三　若 ReadLegalSeg^η = ⊥\_Seg，返回 solver 状态 EligibilityUnresolved，终止。

四　若 ReadLegalSeg^η = 1，求 𝐀\_η = ( A\_0, …, A\_n )。

五　求 𝐆\_η = ( G\_0, …, G\_n )。

六　按 5.1 得 ActDyn^η。

七　按 5.2 得 DegDyn^η。

八　按 5.3 得 DynActual^η。

九　若 DynActual^η ∈ { 1, 0 }，按 3.16 读回

　　LawDyn^η = 𝓛\_{Γ\_dyn}( η, L, I ) = DynActual^η

其依据为第四篇的三值传导，本步不另作判断；回读的适用条件见定理四（资格已读出为 1、读出可靠）。若 DynActual^η = ⊥\_Dyn，程序返回 ⊥\_Dyn，只报告本次读取未决，不据以确定对象层 LawDyn 的值（3.12）。

在各上游读出与比较子程序——𝒬、𝒜、𝒟、Cmp\_D 及 3.15 五项读出——均可执行并终止的工作域之内，SolveLawDyn 由上列九个显式步骤组成，每步的判据都是已写定的条文。

此处所称可求解，指外层程序在该工作域内由有限显式步骤构成，不断言各子程序在一切场规格上都可计算终止。

OutOfDomain 与 EligibilityUnresolved 是 solver 状态，不是 LawDyn 的新本体值，不得写作 LawDyn = 0 或 LawDyn = ⊥\_Dyn。

### 5.6 同一段之下的形式完成解

固定输入包 𝕀\_η 之后，其中仍可能有未被唯一化的形式分量：部分信息在该形式层不可识别，或底层实现未被唯一化。由此得

　　CompatSol( 𝕀\_η ) = { ρ\_1, …, ρ\_m }

其中每个 ρ\_i 是对 𝕀\_η 中未唯一化形式分量的一份合法完成。记由 ρ\_i 补全后的输入实例为

　　𝕀\_η\[ ρ\_i \]

补全只填未定分量，不改已定的：η 不换，T\_η 不换，a 不换，L、I、Γ\_dyn、Γ\_D 都不换。因此各 𝕀\_η\[ρ\_i\] 是同一段的不同补全，不是不同的段。

必须说清其界。CompatSol 只补全同一个已给定的 𝕀\_η，不产生新的 η，不从 Spec\_F 与 Init 搜索未来轨迹。生成与搜索属第六《律可达式》；本篇的输入已含 η，其任务是求这一段发生了什么。因此此处不用"运行解"的名称，以免与可达性混读。

分别计算

　　v\_i = SolveLawDyn( 𝕀\_η\[ ρ\_i \] )

结果记 v，不记 r——后者已冻结为底层执行索引，同名即破两套索引不得混用的纪律。

### 5.7 聚合

　　Agg\_Sol( { v\_1, …, v\_m } )

规则：

　　Agg\_Sol( {1} ) = 1  
　　Agg\_Sol( {0} ) = 0  
　　Agg\_Sol( {⊥\_Dyn} ) = ⊥\_Dyn  
　　含相异值的 = ⊥\_branch

聚合表：

　　分支值集合　　　　　聚合结果  
　　{1}　　　　　　　　 1  
　　{0}　　　　　　　　 0  
　　{⊥\_Dyn}　　　　　　 ⊥\_Dyn  
　　{1, 0}　　　　　　　⊥\_branch  
　　{1, ⊥\_Dyn}　　　　　⊥\_branch  
　　{0, ⊥\_Dyn}　　　　　⊥\_branch  
　　{1, 0, ⊥\_Dyn}　　　 ⊥\_branch

⊥\_branch 的型别必须写死：

　　⊥\_branch 是 solver 层的未决子类，不是 LawDyn 的第四个值。

形式地，solver 状态集含 BranchUnresolved 一项；聚合得 ⊥\_branch 时，solver 返回该状态。只有在形式完成解已经唯一或各解一致、且读出完成之后，才可以回读

　　LawDyn ∈ { 1, 0 }

共同值为 ⊥\_Dyn 时，solver 返回 ⊥\_Dyn 作读取未决，不回读对象层 LawDyn（定理五）。

必须明：第四篇三值析取中的"一吸收未知"，只适用于同一实际段内部两个投影之间。两个投影读的是同一段上同一件事的两面，故一侧确定即整体确定；而不同的形式完成解是同一段的不同补全，一解为一不使另一解也为一。照搬的，触 K-MD10。

多解不得直接等同于未决：若各解值一致，聚合即取该值。任选其一的也触 K-MD10。

### 7.2 回读定理群

以下各定理不另设带上标的形式量。所谓回读，即断言求解程序在其定义域内所得的确定值，与第四篇同名对象的取值相等；程序所得 ⊥ 只报告读取未决，不回读为对象层的值（3.12）。各定理以读出可靠为前件，不以完整可读为前件。

定理零（合法段机器回读的可靠性）

设 3.15 的五项机器读出均可靠（3.12），即各项返回确定值时，该值与第四篇定义二相应合取项的真值相符；R\_hold 一项的可靠性含 3.9 注所列 𝒬 正负两向的读出依据。则

　　ReadLegalSeg^η = 1　⇒　LegalLawSegment^η = 1  
　　ReadLegalSeg^η = 0　⇒　LegalLawSegment^η = 0

ReadLegalSeg^η = ⊥\_Seg 时，不推定对象层真值。

若另设五项在本段上完整可读（3.12），则第一式可加强为 ReadLegalSeg^η = 1 ⟺ LegalLawSegment^η = 1。

证明。第四篇定义二为五项的合取：同一合法轨迹段、目标引用固定、段内资格保持、更新循协议、评价协议事前冻结。3.15 的 R\_traj、R\_target、R\_hold、R\_prot、R\_freeze 与它一一对应，各读其一。

取 1 一路：ReadLegalSeg = 1 当且仅当五项都返回 1（零吸收合取的唯一取一情形）；由可靠性，五个合取项都成立，故 LegalLawSegment = 1。

取 0 一路：ReadLegalSeg = 0 当且仅当至少一项返回 0；由可靠性，相应合取项不成立，故 LegalLawSegment = 0。

⊥ 一路：无 0 而有 ⊥\_Seg 时，至少一项未读出确定值。可靠性只约束确定值，不约束 ⊥，故机器层不据以推定对象层真值：对象层五项可以都成立而某项机器读不出，这就是 3.13 所立的资格失败与机器不可读的区分。

加强一路：另设完整可读，则五项都返回确定值，ReadLegalSeg ∈ { 1, 0 }。若 LegalLawSegment = 1，则 ReadLegalSeg ≠ 0（否则由取 0 一路得 LegalLawSegment = 0），故 ReadLegalSeg = 1；与取 1 一路合为双向。∎

v1.0 本定理以「各 R 取 1 当且仅当相应合取项成立」为前件，并据以写双向式；该前件实含完整可读，而本篇允许对象层成立而机器不可读，故本版改为单向，双向只在另设完整可读时成立。

本定理是资格层与读出层之间的桥。定理四以 ReadLegalSeg^η = 1 为显式前件，由本定理得 LegalLawSegment^η = 1；对象层合法本身不推出机器资格读出为 1。

定理一（作用侧确定输出的可靠回读）

在 ReadLegalSeg^η = 1、各 A\_k 已求得且 𝒜 读出可靠（3.12）之下：若 5.1 所得 ActDyn^η ∈ { 1, 0 }，则它等于第四篇定义四的 ActDyn^η；若 5.1 所得为 ⊥\_A，则只报告作用侧读取未决，不据以确定对象层 ActDyn。

证明。第四篇定义四以 T\_η 内各相邻步的四种走法按三档聚合，存在极性居先。5.1 的 StepAct 与其四种走法逐一对应；二者都以同一冻结的 T\_η 为参数，都不删点。

取 1 一路：存在 k 使 StepAct\_k ∈ { Start, Continue, Stop }，即 A\_k、A\_{k+1} 都是确定值；由可靠性，二者即对象层该两点的当前作用值，故对象层第 k 步为同一走法，由存在极性居先，对象层 ActDyn = 1。此路只需该一步两端可读，其余读数可读与否不影响。

取 0 一路：各步都是 Idle，即各 A\_k 都确定为 0；由可靠性，对象层各点当前作用都为 0，各步都是静置，故对象层 ActDyn = 0。

⊥ 一路：机器读数有 ⊥\_A 而无确定动力步时，对象层未读出的点可为 0，也可为 1，故不推定。∎

定理二（程度侧确定输出的可靠回读）

在同样条件下，且 𝒟 与 Cmp\_D 读出可靠：若 5.2 所得 DegDyn^η ∈ { 1, 0 }，则它等于第四篇定义五的 DegDyn^η；若为 ⊥\_D，只报告程度侧读取未决。

证明。第四篇定义五以 T\_η 内各相邻步在同一 Γ\_D 下的五种关系按三档聚合。5.2 的 Cmp\_D 即第三篇的比较系统，其五值与该五种关系逐一对应；Migration 两处都取 profile 层的 ∥\_D。

取 1 一路：存在 k 使 StepDeg\_k 确定为 Rise、Fall 或 Migration；由可靠性，即对象层该步的关系，故对象层 DegDyn = 1。取 0 一路：各步都确定为 Equal；由可靠性，对象层各步等阶，故 DegDyn = 0。⊥ 一路同定理一，不推定。∎

定理三（合成确定输出的可靠回读）

在定理一、定理二的前件下：若机器侧 ActDyn^η ∨₃ DegDyn^η ∈ { 1, 0 }，则它等于第四篇定义六的 DynActual^η；若为 ⊥\_Dyn，只报告读取未决。

证明。3.17 的析取真值表即第四篇定义六的三值规则，未作改动。机器侧取 1：至少一侧取 1，由定理一或定理二，对象层该投影为 1，故对象层 DynActual = 1。机器侧取 0：两侧都取 0，由定理一、定理二，对象层两投影都为 0，故 DynActual = 0。机器侧取 ⊥：不推定。∎

注（三值逐值相等）　若另设并论证 H\_Exact（3.12），则定理一至三的 ⊥ 一路也逐值相等，回到 v1.0「逐值相等」的表述；本篇不主张 H\_Exact。

定理四（整段确定输出的可靠回读）

设对每个 ρ ∈ CompatSol( 𝕀\_η )，SolveLawDyn( 𝕀\_η\[ρ\] ) 的第一步都得 ReadLegalSeg^η = 1，3.15 五项、𝒜、𝒟、Cmp\_D 的读出都可靠（3.12），必要形式读取可执行。若各结果一致，记其共同值为 v，则

　　v ∈ { 1, 0 }　⇒　v = LawDyn^η  
　　v = ⊥\_Dyn　⇒　只报告本次读取未决，不确定对象层 LawDyn^η 的值

证明。

由前件与定理零取 1 一路，LegalLawSegment^η = 1，(η, L, I, Γ\_dyn) ∈ Dom\_Legal，程序在每个 𝕀\_η\[ρ\] 上进入第四步。

各 ρ 是同一段的不同形式补全，其读数可以不同；但由可靠性，任一 𝕀\_η\[ρ\] 上的确定读数都是对象层的值，故各 ρ 的差异只能是何处可读、何处不可读的差异，不能是同一处两个相异确定值的差异。

设 v ∈ { 1, 0 }。取任一 ρ，其 DynActual 输出为 v；由定理三，v 等于对象层 DynActual^η。确定结论只需充分的已读见证支持——取 1 时一个确定的动力步即足——不要求该补全上所有读数都确定。再由 3.16，LegalLawSegment^η = 1 时 LawDyn^η = DynActual^η，故 v = LawDyn^η。

设 v = ⊥\_Dyn。各补全都未读出足以定值的见证，而对象层仍可确定：例如对象层某相邻步作用值实为 ( 0, 1 )，构成起，各补全都未读出这两点，程度侧又各步等阶，则各补全共同返回 ⊥\_Dyn，对象层 DynActual 却为 1。故不推定对象层的值。∎

CompatSol( 𝕀\_η ) 为单元素时，本定理即：SolveLawDyn( 𝕀\_η\[ρ\] ) ∈ { 1, 0 } 时等于 LawDyn^η。

非法候选不进入本定理的定义域：按 3.16，Dom\_Legal 只含 LegalLawSegment^η = 1 的。对象层合法而机器资格读出为 ⊥\_Seg 者，程序返回 EligibilityUnresolved，亦不在本定理之内。

v1.0 本定理有两处推断不成立，本版撤回：其一，「v ≠ ⊥ 则至少一个补全上各读数都可判」——存在极性居先之下，一个确定的起即使作用侧取 1，其余读数仍可不可读；其二，「各补全都为 ⊥ 则对象层也不可判」——反例见上。

定理五（多解保守）

若 CompatSol( 𝕀\_η ) 的各解经 SolveLawDyn( 𝕀\_η\[ρ\_i\] ) 给出同一值 v，则 Agg\_Sol 取 v：v ∈ { 1, 0 } 时，在定理四的前件下可回读为 LawDyn^η = v；v = ⊥\_Dyn 时，solver 返回 ⊥\_Dyn，只报告读取未决，不回读对象层 LawDyn。若各解值不一致，则 solver 返回 BranchUnresolved，此时不回读 LawDyn，也不得任选一解。

证明。一致一路：由 5.7 的聚合规则，单值集合取该值；v ∈ { 1, 0 } 时由定理四即 LawDyn^η；v = ⊥\_Dyn 时由定理四不推定。

不一致一路：由 5.7，含相异值的取 ⊥\_branch；由其型别申明，⊥\_branch 为 solver 层未决子类，非 LawDyn 的值，故此时不回读。任选一解则违 5.7 末段，也触 K-MD10。∎

注　在定理四的可靠性前件下，各解不可能一给 1、一给 0（二者都须等于对象层同一值）；分支值集合含 { 1, 0 } 即示某项读出不可靠，属 K-MD1 或 K-MD2 的线索。含 { 1, ⊥\_Dyn } 或 { 0, ⊥\_Dyn } 者，本篇仍按 5.7 保守返回 BranchUnresolved，不径取确定值。

第八节

附属模块：动力贡献

### 8.0 模块地位

　　M\_Contrib 是本篇的附属归因模块，不是主求解的必要前件。

删去整个第八节，第三至第七节的 LawDyn 主求解与回读仍然闭合——SolveLawDyn 的九步无一调用本节对象。此裁定写死。

本模块所回答的是：某次已经发生的动力事件，其源头该记在谁账上。第四篇已证 DynContrib = 0 不推出 LawDyn = 0；本模块不改此判，也不以贡献为动力的资格。违反的，即触犯 K-MD11。

### 8.1 型别

　　DynContrib : 𝓑 × 𝓔\_η → { 1, 0, ⊥\_C }

其中 𝓑 为候选源全体，𝓔\_η 为 5.4 所编码的动力事件集。取三值读出映射，不写作子集关系。

### 8.2 统一证书

　　CertDyn( B, e ) = SourceQual( B, e ; L, I ) ∧₃ ActualMechanism( B, e ) ∧₃ GenReach( B, e ) ∧₃ SameDynBind( B, e )

四项都以事件 e 为参数，签名一致。

合取取 3.17 的零吸收型规则。

　　DynContrib( B, e ) = CertDyn( B, e )

两套三值制度不得混用：动力事件的存在采一吸收型析取（5.1、5.2、5.3），资格合成与贡献证书采零吸收型合取（3.15、8.2）。前者问"有没有发生"，一处确定即确定；后者问"是不是全都成立"，一项不成立即不成立。

### 8.3 事件的实际子段

在给出四项证书之前，先固定各项见证所需落在的那一段。

对事件 e，其所属评价步为 E\_k。定实际子段

　　Z\_e = ( ζ\_p, ζ\_{p+1}, …, ζ\_q )　⊆　Exec( E\_k )

要求连续，且 a(k) ≤ p ≤ q ≤ a(k+1) − 1。

Z\_e 为 e 在底层的实际发生所占的那一段执行记录。下文 SourceQual、ActualMechanism、GenReach 三项的实际见证，一律必须落在同一个 Z\_e 之内——此三项为 SameDynBind 所绑定的前件，与 8.2 的四项证书不同指，不简称"三项证书"。

### 8.4 SourceQual

　　SourceQual\_r( B, L, I ) ∈ { 1, 0, ⊥\_C }

带底层索引 r，取一当且仅当

　　B ∈ 𝒮( F\_r, L, I )

其中 F\_r 为 X\_r 所对应的当前沉积场状态的记号，不新增状态对象：底层完整状态 X\_r = ( X^run\_r, X^sed\_r, X^str\_r ) 已由 3.3 给出，F\_r 即其在场侧的读取，形式上记为 F\_r ≔ π\_F( X\_r )，π\_F 为自底层完整状态取其当前沉积场状态的投影。此约定只为衔接上游解集的记法，不另开对象。

其中 𝒮 为《律数理式》定义 3.47 与式 (4.7) 所给的形式解集

　　𝒮( F\_t, L, I ) = { R ⊆ Existing\_t \| EstWitness^M = 1 ∧ Govern^M = 1 }

即直接复用上游解集，不另拼见证，也不另造第二套承重体系。若该判据的读出不可完成，则取 ⊥\_C。

索引不能省略。起、续、降各事件的贡献可发生在不同的 r 上；不带索引则"当前状态"无着落。

事件级的 SourceQual 由此定义：

　　SourceQual( B, e ; L, I )　≔　SourceQual\_{r\_s}( B, L, I )

其中 r\_s 为 8.5 所记的那条实际生成链的起点索引。

r\_s 的取法不可放宽。不得写作

　　∃ r ∈ Z\_e：SourceQual\_r( B, L, I ) = 1

否则可以拿子段后段某一时刻的资格，来给前段的生成源补证——那是以彼时的资格证此时的来源。因此 r\_s 必须与 GenReach 所用的是同一条实际生成链的起点，二者不得各取各的。

### 8.5 ActualMechanism 与 GenReach

　　ActualMechanism( B, e ) ∈ { 1, 0, ⊥\_C }

按 e 的类型取值，见 8.7 的类型表。

　　GenReach( B, e ) ∈ { 1, 0, ⊥\_C }

终点必须先说准。起与续尚可直观地说"链达于事件"，而升、降、迁移三者本身是两个 profile 之间的比较关系，不是底层的一个状态节点；说链的终点是它，型别上不成立。

因此于事件与链之间另设见证对象。取一当且仅当：在 e 的实际子段 Z\_e 之内，存在一条实际执行链，其起点成分属 B，其终点为某个事件见证对象 w\_e，且该见证经相应的事件读出规则产生 e。记作

　　B ⤳ w\_e ⤳ e

而非 B ⤳ e。

见证对象按事件类型取：

　　Start、Continue　w\_e 为该步的实际发生见证或续行见证  
　　Stop　　　　　　 w\_e = C\_e，其中 C\_e ∈ CutActual⁻\_k( L, e )  
　　Rise　　　　　　 w\_e ∈ GainAdv^Γ\_k(L)  
　　Fall　　　　　　 w\_e ∈ LostAdv^Γ\_k(L)  
　　Migration　　　　w\_e ∈ Cross⁺\_k ∪ Cross⁻\_k

止一项的见证取整个实际生效切集 C\_e，非其中某个退出成分。理由在事实本身：止所要求的是全部合法当前承担方案都被实际切断，单个成分的退出不足以见证它——冗余承担之下，去一而余的仍承担，止并未发生。因此见证必须是那个足以切断全部候选的集合。

至于某个 B 对止的撤出贡献，则由 ActualMechanism 判 B 的退出是否实际进入该 C\_e，见 8.8 与类型表。

此处的实际执行链，指由 Z\_e 内各 ζ\_r 的产出与后继关系所连成的链，非结构层的可走链，也非复走链。

记该链的起点所在的底层索引为 r\_s ∈ Z\_e，下文 8.4 使用它。

必须划一线：GenReach 不是第六篇的可达性。

　　本篇：给定 η，问其内已经发生的事的生成链。  
　　第六篇：给定初态与目标，问是否存在某 η 到达。

严禁把 GenReach 写成对 η 的存在量化去搜索未来目标状态。

### 8.6 SameDynBind

　　SameDynBind( B, e ) ∈ { 1, 0, ⊥\_C }

取一当且仅当 SourceQual( · , e ; L, I )、ActualMechanism、GenReach 三项的实际见证，与被归属的事件 e，绑定在同一组键上：

　　( L, E\_k, e, B, Z\_e )

即：同一条律、同一评价步、同一事件、同一候选源、同一实际子段。三项见证若分属不同评价步，或落在不同的 Z\_e 之内，则本项为零。

Z\_e 由 8.3 定义为 Exec(E\_k) 的连续子段，非自然语言所称的"同一族"。

它是贡献证书的良构条件，不是新的 LawDyn 本体项，不入总式。

### 8.7 类型分派

事件类型表：

　　事件　　　　事实层来源　　　　　　 ActualMechanism 所需  
　　Start　　　 StepAct\_k = Start　　 ActArg^μ；源取合法 Established Law bearer  
　　Continue　　StepAct\_k = Continue　Exec(E\_k) 之内的实际 execution continuation  
　　Stop　　　　StepAct\_k = Stop　　　B 的退出是否实际进入某 C\_e ∈ CutActual⁻\_k（8.8）  
　　Rise　　　　StepDeg\_k = Rise　　　GainAdv^Γ\_k（8.9）  
　　Fall　　　　StepDeg\_k = Fall　　　LostAdv^Γ\_k（8.9）  
　　Migration　 StepDeg\_k = Migration Cross⁺\_k 与 Cross⁻\_k（8.10）

Start。贡献源采合法的 Established Law bearer，不要求事前已有 CurLawBear。起发生时该律尚在静置，若要求源已在当前承担，则静置的律永不能取得起贡献——而一条静置而已成立的律，仍有合法的 Established 与 Govern 承重结构。此承第四篇附录第四项。

Continue。事实层为 A\_k = A\_{k+1} = 1。贡献层必须下钻 Exec(E\_k)，寻本评价步之内的实际 execution continuation。不得只凭两端读数为一认定贡献——第四篇已申明续为协议相对的结论，其两端相同不保证其间的执行由谁承担。

### 8.8 失承切集

记与评价步 E\_k 的后继端 t\_{k+1} 相对应的合法当前承担候选为

　　𝓑\_{k+1}(L) = { B : B 为 L 在 t\_{k+1} 上的合法当前承担候选 }

下标取 k+1 而非 k：所问的是这一步之后还有没有候选能承担，其对象在后继端，与下式的 CurLawBear\_{k+1} 同端。k 为评价索引，非底层执行步。

结构切集族定义为：

　　C ∈ CutStruct⁻\_k(L)  
　　⟺　∀ B ∈ 𝓑\_{k+1}(L)：CurLawBear^{do(C)}\_{k+1}( B ) = 0

即：合法地删除或使失效 C 之后，下一拍没有任何候选仍能共同满足 CurrentLawOccurrence 与 DutyConformance。

最小切集另加：

　　C 最小　⟺　C ∈ CutStruct⁻\_k(L) 且 ∀ C' ⊊ C：∃ B ∈ 𝓑\_{k+1}(L)：CurLawBear^{do(C')}\_{k+1}( B ) = 1

其中 CurLawBear 即封版第一篇的对象，上标 do(C) 表示合法删除或使失效 C 之后的取值。本篇不另设 CurBear 的名称。

必须说明为何是"足以切断全部候选"而非"各候选必要承重点之并"。后者只给出一个庞大的删除集合，既不能表达冗余承担方案，也不能回答哪一个集合真正足以切断全部合法承担解；在冗余实现的世界里，取并会把并不必要的成分算进来，而真正的最小切集可能远小于它。因此以"删除之后全部候选皆不成立"为判据。

实际切集为这一次实际停止中真正发生并生效的。型别必须与切集族分清：CutStruct⁻\_k(L) 是切集的族，其元素才是某个切集 C。

因此对停止事件 e 定实际生效切集族

　　CutActual⁻\_k( L, e ) ⊆ CutStruct⁻\_k(L)

其成员 C 必须满足：C 的全部成分在 Z\_e 之内确已退出或失效。

若一次停止只对应一个实际切集，则该族为单元素，记其成员为 C^actual\_{k,e} ∈ CutStruct⁻\_k(L)；若存在多个等价的实际生效切集，则该族含多个成员。二者都是族的情形，不再一边称"一份切集"一边用子集于族的型别。

WithdrawContrib 只能绑定 CutActual⁻，不得绑定 CutStruct⁻——"理论上足以使它停"与"这一次真正使它停"是两件事。此承第四篇附录第一项。

### 8.9 优势得失

本节与 8.10 所称「优势」，都指 Degree 剖面域 J\_D 上按规定有利方向的覆盖见证，不是实际竞争优势，也不是更熟（《律分级式》v1.1）。

Rise。事实层先由第三篇得 G\_{k+1} ≻\_D G\_k。定纯形式比较见证集

　　GainAdv^Γ\_k(L) = 新 profile 中旧 profile 所不能覆盖的优势见证的全体

只有源经实际生成链进入这些新增优势见证，才成立 RiseContrib。

　　RiseFact ≠ RiseContrib

Fall。事实层先由第三篇得 G\_k ≻\_D G\_{k+1}。定

　　LostAdv^Γ\_k(L) = 旧 profile 中新 profile 所不能覆盖的优势见证的全体

只有源的实际变化经生成链绑定到 LostAdv，才成立 RetreatContrib。

　　FallFact ≠ RetreatContrib

此承第四篇附录第二项：竞争径流增加可使占流比例下降而该律自身承载未变，剖面降的事实不等于剖面降的贡献（DegreeFallFact ≠ RetreatContribution）。Fall 是剖面降，不是退浅；RetreatContrib 沿用第四篇的名称，所指为剖面降的贡献（《律动力一般式》v1.1）。

### 8.10 迁移两侧

事实层由 G\_k ∥\_D G\_{k+1} 取得 profile 层迁移。定两个纯形式见证集：

　　Cross⁺\_k　新 profile 中旧 profile 无法覆盖的优势  
　　Cross⁻\_k　旧 profile 中新 profile 无法覆盖的优势

贡献必须允许源只贡献得势侧、只贡献失势侧、两侧都贡献，或两侧都无可归属贡献。

不得压成正负标量——迁移本非一个方向上的量，压成标量即回到第三篇所禁的总分。

证书架构的形式良构性与型别闭合：由 8.1 至 8.10 给出，此层 Established。

定理六（形式实现）

在上游封版对象及其原条件成立（含 3.9 注所列 Law 读出所携之回读前件、SC\_Hold 与 Ω\_e 补检）、评价协议与运行规格良构、必要形式读取可执行且读出可靠（3.12）之下，M\_LawDyn 对第四篇已经成立的 LegalLawSegment、ActDyn、DegDyn、DynActual 与 LawDyn 给出可运行、可求解的形式实现，其确定输出可逐项可靠回读（7.2 所证范围：确定输出与对象层同值，未决输出不赋值对象层）；其形式辅助对象不新增律动力的本体条件，不新增场量，也不改变第四篇的定理方向与状态。

证明。

第十一节

击穿

本篇为数理式，其击穿按法篇所定：展示形式系统内部的矛盾；或展示形式结果与已证结构命题在回读处冲突；或展示对应表遗漏了承重符号；或展示定义序列中某个关系的实际性质与所申明的不符。

据此列十六条。前十二条落在前两种方式，后四条分落四种：K-MD13 与 K-MD14 属内部矛盾的具体形态，K-MD15 属对应表遗漏，K-MD16 属关系性质不符。

K-MD1　内部矛盾。同一固定输入与同一形式完成解推出 LawDyn = 1 与 LawDyn = 0。

K-MD2　上游回读冲突。形式输出与第四篇的定义不一致，即定理一至五之一被反例。

K-MD3　非法段误写为零动力。LegalLawSegment = 0 而返回 LawDyn = 0，违 3.16 的偏函数定义域。

K-MD4　首尾压缩。冻结的 T\_η 有内点，而求解跳过内点评价只比两端。

K-MD5　删除未知点。评价点不可读时直接删点再计算，以制造二值。

K-MD6　Degree 标量化。以总分或单标量替代 profile 偏序；或把 Migration 压成单向量的坐标交叉；或以剖面序称更熟、以剖面降称退浅。

K-MD7　读出反灌动力。LawDyn、ActDyn、DegDyn 或 DynContrib 未经独立证明而直接进入 𝓡 或 Φ 的自变量。

K-MD8　沉积误写。Freeze、候选评价或非实际执行被写入 Trace 与 Sediment。

K-MD9　双时钟偷同一。强令 t\_run = t\_sed，或强令两增量相等，或把增量预签为运行模式的单值函数。

K-MD10　多解偷选。各形式完成解输出不一致而任选其一；或把一解的一吸收另一解的未知。

K-MD11　贡献反灌资格。以 DynContrib = 0 推出 LawDyn = 0。

K-MD12　Degree 同拍循环。建立占流比例与 Degree 之间的同拍闭环。

K-MD13　索引混用。以同一索引兼表底层执行步与评价点，或以 Exec(E\_k) 的长度恒为一代替锚定映射。

K-MD14　切集错定。以各候选必要承重点的并代 CutStruct⁻，致冗余承担世界被判错；或以 CutStruct⁻ 代 CutActual⁻ 绑定撤出贡献。

K-MD15　对应表遗漏。展示一个正文承重使用而 3.0 三类与 7.1 清单都未列的记号；或展示 S 的某一分量在 7.3 的对应表中无回读路径。前者即 7.1 末句所设的反例，后者即回读完备性失败。

K-MD16　关系性质不符。展示 3.18 所申明的某一性质与该对象的实际性质不符——例如所称全函数在其所标定义域上有无定义的点，所称保值的不保值，所称不交的两集合有交，所称连续子段实际上是任意子集；或展示定义序列中新立一对象而 3.18 未申明其性质，这就是 3.18 末句所设的遗漏。

任一成立，本篇相应主张失败或必须升版。

不是击穿的：ReadLegalSeg 返回 ⊥\_Seg——属机器层不可读，非形式矛盾；SolveLawDyn 返回 ⊥\_Dyn——属读取未决，不是对象层不可判的断言；Agg\_Sol 返回 ⊥\_branch——属保守聚合的正常结果，且已声明为 solver 层子类；贡献模块的某实例取 ⊥\_C——属执行结果；上游被击穿——那将使本篇工作域失效，属条件传导。

第十二节

接口

向上

《律动力一般式》v1.1（封版）——S 的全部结构分量。本篇为其形式实现，不改其定义、方向与状态。该篇若升版而改动两投影、三值规则或资格层界线，本篇第五、七节随之复审。

《律作用一般式》《律作用必然式》（都封版，现行 v1.0）——𝒜 的取值来源。二者若升版而改动 LawAct 或 CurLawBear，3.10 与 5.1 随之复审。二者原文所记 Law 条件，引用时另携 SC\_Hold（律动力组式《总图》v1.1 11.3 登记），待其升版核改。

《律分级式》v1.1（封版）——𝒟 的输出空间（剖面域 J\_D）与 Cmp\_D 的比较系统；熟序域 J\_δ 不入本篇读出。该篇若升版而改动四坐标、序方向或三值方向判定，3.11 与 5.2 随之复审；其 G\_{D-Sep} 与 G\_{D-Read} 按该篇原分挂传导，不成为本篇主定理的统一前件。

《律数理式》《场数理式》v2.7 与运行基底（《律运行基底构造式》v1.3、《律动力运行基底构造式》v1.1）——既有形式对象、合法转移与运行协议。本篇复用不另造；其转移制度若改动，则 3.5 至 3.8 与第四节随之复审。

《律必然式》v1.4、《律一般式》v2.6——经充分向读作 Law 所携之 SC\_Hold（3.9 注）。SC\_Hold 被击穿，或回读前件、Ω\_e 补检未闭，则本篇读作对象层 Law、LawDyn 之结论随之待定，读作形式解 R ∈ 𝒮 之程序结论不受影响。

向下

M\_LawDyn 及其求解程序——下游可用作 LawDyn 的形式实现。引用时必须连同 Γ\_dyn、T\_η、锚定映射 a 与第四篇的域限定一并承继。回读定理以读出可靠为前件，引用时一并承继；程序输出 ⊥\_Dyn、⊥\_Seg 只表示读取未决，下游不得读作对象层 LawDyn 不可判或资格不成立。

两套三值真值表与多解聚合表——析取与合取两制度不得混用；聚合不得任选分支。

3.12 的不可判分层——八个 ⊥ 记号各归其层，下游不得互代，尤其不得以机器不可读充资格失败。

7.1 的纯形式辅助量清单——下游不得把其中任一项当作本体对象引用，不得据以新立谓词。

8.0 的模块地位——贡献模块可删，删去它，主求解仍闭合。下游不得以贡献模块的实例取值否定主形式实现定理。
