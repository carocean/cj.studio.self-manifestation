自显论 · 律篇 · 律动力组式第六 v1.1

# 律可达式

第一节

目的、式种与唯一任务

### 1.1 唯一任务

对一条已经成立的律，固定明确初态、运行规格、协议、许可输入与操作集，以及预先声明的律动力目标之后，本篇回答一件事：

　　是否存在一条有限的合法路径，使该律在合法工作段之内真正命中该目标。

所证的是支持可达：

　　SuppReach^LD

其义只有一条：系统所许可的合法后继之中，存在至少一条有限路径到达目标。

### 1.2 式种

可达式，附式，独立成篇。

按法篇第一第四编第九章，可达式的用途为证明构造物可以由许可的操作或系统动力从给定初态到达；其进入条件为构造已经给出、初态与许可操作集界定清晰。本篇的构造由上游给出，见第三节；初态、许可集与目标都在第三节冻结。

按法篇第一第二编第五章，成立证明的完成强度序为相容、构造、可达、实现，高阶须覆盖低阶。本篇达到可达强度：所依的构造由上游已经给出，本篇不重作；实现强度不在本篇承担。

### 1.3 强度的上限

本篇所证只到存在一条路径。以下三者都非本篇所证，正文任何一处不得升级：

　　不升为 CtrlReach——不主张操作者能够保证走到；  
　　不升为全称——不主张一切许可路径都命中；  
　　不升为概率一——不主张必然到达。

三者与支持可达的差别在量词与模态，不在措辞。凡是以"可以做到""必然走到""总能到达"代替"存在一条路径"的，即已越级。

### 2.2 承继第五篇的运行系统

调用而不重建：

　　X\_{r+1} ∈ Φ( X\_r, Y\_r, m\_r )

以及第五篇已立的合法工作段、三个读出算子与求解程序。

评价步与底层执行段的分层也一并承继，其两个记号本篇径用不另定义：锚定映射

与评价步

　　E^eval\_k = ( t\_k, t\_{k+1} )

前者把第 k 个评价点系于底层状态 X\_{a(k)}，后者为相邻两评价点所夹的一步。二者都出自第五篇，本篇不改其义。

### 2.3 承继运行基底

调用现成的

　　Spec\_LB

与协议集

　　Prot\_LB = { Mode\_exo, Mode\_endo, Freeze, Thaw, IdleStep, do(Mask), do(Avail) }

不自行增加协议操作。运行基底已明确：Freeze 可关闭沉积而保留运行；IdleStep 只退浅与过期，不产生当前 pulse；Mask 与 Avail 各有正式协议位置；直接裸改 g、d、rep、Ω 不是合法路径操作。

### 2.4 与相邻任务的四组分界

其一

　　CompatSol ≠ Reachability

第五篇的 CompatSol 是在同一条已经给定的 η 之内，对形式信息的补全。本篇的可达是 η 尚未给定，自初态搜索或构造未来的许可路径。前者不换段只补全，后者正是要造出那一段。

其二

　　GenReach ≠ Reachability

第五篇的 GenReach 是在已经发生的动力事件之内，对贡献来源作事后的生成链归属。本篇问的是未来有没有一条合法路径到达目标。一个朝后看，一个朝前看。

其三

　　DynReach ≠ LawSource

本篇不问律最初如何产生。来源归第九《律源式》。

其四

　　DynReach ≠ LawIdentity

一旦路径涉及整体迁移、复制、替换或跨载体恢复，而必须判断"还是不是同一条律"，即刻下交第七至九篇《律身份》。本篇的路径不跨越这一线；凡是跨越的，其可达结论必须待身份各篇给出判据之后方可陈述。

### 2.5 不问的

律如何成立；律从何而来；经过承载更替之后是否同一；另一条律如何导致本律动力改变的完整交互理论；多律环境中的长期保持与复归。各项分归《律一般式》《律必然式》《律源式》《律身份》各篇、《律交互》各篇与《律生态稳定式》。

第三节

初态、目标与许可操作申报

### 3.1 任务输入

　　Ξ\_LD = ( Spec\_F, Prot, X\_0, L, I, G\_Θ, Adm\_LD, Γ\_reach )

其中 Spec\_F 为运行规格；Prot 为合法协议；X\_0 为明确初态；L 为固定目标律；I 为其适用域；G\_Θ 为预先声明的目标集；Adm\_LD 为事前冻结的许可输入、模式与操作集；Γ\_reach 为评价协议。

证明开始之后，X\_0、L、I、G\_Θ、Adm\_LD 五者不得更动。改其一即更换任务，先前所得的可达结论不随之转移。

这是法篇所定禁止写法的反面：不申报初态，或扩大许可集而不申报，都属违规。凡是本篇中途若必须调整许可集，则作为新的 Ξ 另行申报，不在原结论名下。

### 3.2 初态

本篇不以共同弱初态 Init\_LB 为主证明初态。理由在任务：所研究的是已成的律的动力可达，而弱初态之下律尚未成立，其上所论者是成律的可达，属别的问题。

基准实例取运行基底 LB1 正式成律之后的状态。固定

　　L\_{0.9} : a1 ⇒ c

及其承载

　　R\_1 = { a1 → m1, m1 → c }

记该已成律的共同结构基底为

　　X^LB1\_base

它只保证

　　Law( L\_{0.9} ) = 1

以及承载 R\_1 的结构完好，不规定当前作用读数 A 取何值。

结构基底不是任务初态。六类目标各有其进入条件——起必须自静置出发，续与止必须自在行出发——同一个读数不能兼两者。因此必须在同一基底之上分立三个任务初态：

　　X\_0^Start　　　Law = 1，A\_0 = 0  
　　X\_0^Continue　 Law = 1，A\_0 = 1  
　　X\_0^Stop　　　 Law = 1，A\_0 = 1

三者共享同一个 LB1 已成律结构，其别只在当前运行状态。相应的任务输入分记

　　Ξ^Start\_LB1，　Ξ^Continue\_LB1，　Ξ^Stop\_LB1

三者的 Spec\_F、Prot、L、I、Γ\_reach 与 Adm\_LD 同，X\_0 与 G\_Θ 各异。按 3.1，三者是三个任务，其结论各自成立，不互相转移。

其 Law 资格来自上游的正式律判与充分向，本篇不重证。

注（Law 资格所携条件，对应《律必然式》v1.4、《律一般式》v2.6、《律运行基底构造式》v1.3 与《律动力运行基底构造式》v1.1）　正式律判在程序上签出的是形式解 R\_1 ∈ 𝒮；经《律数理式》回读得 Established ∧ Govern，携其回读前件；再经《律必然式》充分向得 Law，携承接条件 SC\_Hold；Spec\_LB 所给 Ω 为工程资格 Ω\_e，与《场数理式》v2.7 之 Ω\_W 互不蕴含（K13），读作 Law 时另携 Ω\_W 事实二、三之补检。故本篇凡称 Law( L\_{0.9} ) = 1、段内 Law = 1 保持，读作对象层 Law 时都携此三项条件；读作「R\_1 ∈ 𝒮 保持」时不携。此为上游条件的传导，非本篇新增 H。按法篇第二编第五章，可达强度必须覆盖构造强度——此处所覆盖的即上游已经给出的这一构造，本篇不另作构造。

### 3.3 许可集

第五篇已把输入空间 𝒰、模式空间 𝓜 与合法单步集 Step^M\_Prot 分开：a1 pulse 是输入，属 𝒰；Freeze 与 IdleStep 是模式或操作，属 𝓜 与 Prot\_LB。二者不同类，不可以一个子集记号兼收。

因此不用 U 这一容易被读作只属输入空间的字母，改记

　　Adm\_LD

为事前冻结的许可输入、模式与操作的集合。其两个分量为

　　Adm\_LD ∩ 𝒰 ⊆ 𝒰　　许可输入  
　　Adm\_LD ∩ 𝓜\_Prot ⊆ 𝓜\_Prot　　许可模式与操作，𝓜\_Prot 为 Prot\_LB 所列的

本篇各路径所用者全在其中，逐条列于各路径的核验表。

裸改 g、d、rep、Ω 既不在 Adm\_LD 之内，也不在 Prot\_LB 之内——它不是协议操作，而是绕过协议直接改写状态。

第四节

可达节点、目标集与合法支持后继

### 4.1 目标不是孤立终态

上游的六类律动力事件

　　Θ\_LD = { Start, Continue, Stop, Rise, Fall, Migration }

之中，多数是相邻评价点之间的关系，不是某个状态自身的性质。Start 必须两端读数由零变一，Continue 必须两端都一，Rise 必须两端 profile 有序。以孤立终态写它，即丢掉其一端。

因此引入纯证明辅助对象

　　Z\_k = ( X\_{a(k)}, E^eval\_k, X\_{a(k+1)} )

即一个评价步连同其两端所锚定的底层状态。

Z 不是场状态，不是新增状态分量，不进入运行律。它只是把"一个评价步及其两端"打成一个可供目标判据取值的对象。

目标集

　　G\_Θ = { Z : Z 满足所声明的目标判据 }

判据逐类列于 4.2，不另设一个抽象谓词 Θ(·)。

### 4.2 六个目标集

判据全部取自上游，不另立第二套：

　　G\_Start = { Z : ( A\_k, A\_{k+1} ) = ( 0, 1 ) }  
　　G\_Continue = { Z : ( A\_k, A\_{k+1} ) = ( 1, 1 ) }  
　　G\_Stop = { Z : ( A\_k, A\_{k+1} ) = ( 1, 0 ) }  
　　G\_Rise = { Z : G\_{k+1} ≻\_D G\_k }  
　　G\_Fall = { Z : G\_k ≻\_D G\_{k+1} }  
　　G\_Migration = { Z : G\_k ∥\_D G\_{k+1} }

其中 A 为第五篇 3.10 的当前作用读数，G 为其 3.11 的 Degree profile 读数，≻\_D 与 ∥\_D 为第三篇的比较关系。

判据所指为对象层的当前作用与剖面关系。以第五篇的机器读数核验命中时，依第五篇 v1.1 3.12，须读出可靠且读数为确定值；读数为 ⊥ 的评价步不算命中，也不据以判未命中，只记读取未决。G\_Rise、G\_Fall、G\_Migration 是剖面域 J\_D 上的目标：命中 G\_Rise 不等于更熟，命中 G\_Fall 不等于退浅。

### 4.3 合法前缀

段的合法资格是整段性质，非逐步局部标签。按第四篇定义二，LegalLawSegment 为五项的合取：同一合法轨迹段、目标引用固定、段内资格保持、更新循协议、评价协议事前冻结。其中数项跨越全段，不能由"每一步局部合法"自动推出——两个各自合法的后继拼在一起，其所成的段未必仍满足五项。

因此不以孤立节点为对象，而以自冻结初态起的合法有限前缀为对象。记

　　π = ( X\_0 ; Z\_1, …, Z\_j )，　j ≥ 0

即以初态 X\_0 开头、其后接 j 个评价节点的序列。j 可为零：

　　π\_0 = ( X\_0 )

为空评价前缀，其中尚无任何评价步——初态本身不是评价节点，单给一个 X\_0 尚无 E^eval 与后端状态，凑不成一个 Z。此点必须写死，否则零步情形的型别不闭合。

各 Z 依次相接：Z\_1 的前端锚定于 X\_0，Z\_{i+1} 的前端即 Z\_i 的后端。

称 π 合法，当且仅当其所覆盖的工作段 η(π) 满足

　　LegalLawSegment^{η(π)}( L ) = 1

空评价前缀 π\_0 的合法性即初态本身在工作域之内，由第三节的申报给出。

### 4.4 合法支持后继

定义证明辅助关系

　　Next^adm\_LD( π )

其义为：自合法前缀 π 出发，在冻结的 Adm\_LD 与 Prot 之下，由上游已有合法转移所产生的下一评价节点 Z′ 的集合——Z′ 的前端锚定于 π 的末端状态（π = π\_0 时即 X\_0）——且必须满足

　　π ⌢ Z′　仍为合法前缀，即 LegalLawSegment^{η(π ⌢ Z′)}( L ) = 1

三项要求缺一不可：Z′ 由上游合法转移产生；所用输入与模式在 Adm\_LD 之内；扩展之后整段仍合法。

第三项是本节所以改取前缀为对象的缘故。若只要求局部后继合法，则整段五项的保持只是顺手继承，而非每步被核；今把它写进 Next 的定义，则每一次扩展都必须重新取得整段证书，拼接漏洞由此堵住。

必须写明其地位。Next^adm\_LD 不是动力律，不产生任何转移；它只在上游已有的合法后继之中作过滤——滤去所用输入或模式不在 Adm\_LD 的，并滤去扩展后整段不再合法的。任何成员都必须来自 Step^M\_Prot。

不另造 LawTube 一类重复的资格对象：段的合法资格已由第四篇定义二五项给出，本篇只调用其判据，不另立。

第五节

支持可达定义与路径证书

### 5.1 定义

　　SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 1

L 已在 Ξ\_LD 之内，不另列为参数；目标一律写作目标集 G\_Θ，不写作抽象标签。全篇此签名不变，第六节与第七至十节都使用它；第七至十节只把 Ξ 与初态取为本实例的，签名不改。

其值为一，当且仅当存在有限路径

　　γ = ( X\_0, ζ\_0, X\_1, …, ζ\_{H−1}, X\_H )，　H \< ∞

此处 H 为路径的底层执行步数。全篇凡「H = 1」处皆指底层执行步数；定理一的秩界另以评价步数 N 记，不是 H 的界（6.1）；与条件项之 H（如 C0、C2、H1–H3）同字而无涉。

满足四项：

　　PathLegal( γ ) = 1　　　每一 ζ\_r ∈ Step^M\_Prot  
　　InputAdmissible( γ ) = 1　每一 u\_r ∈ Adm\_LD ∩ 𝒰，每一 m\_r ∈ Adm\_LD ∩ 𝓜\_Prot  
　　LegalLawSegment^η( L ) = 1　路径所覆盖的工作段资格合法  
　　TargetHit\_{G\_Θ}( π ) = 1　　该前缀之上存在某 Z\_i ∈ G\_Θ

两套记号的对应必须写明，否则第四项挂在一个未定义的对象上。

γ 是底层的单步序列，π 是评价节点的序列。二者由承自第五篇的锚定映射 a 联系：给定 γ 与 Γ\_reach 所冻结的评价点集，取

　　a(0) = 0，　X\_{a(0)} = X\_0

其后各 a(k) 依次递增而不超过 H，则 γ 所对应的前缀为

　　π( γ ) = ( X\_0 ; Z\_1, …, Z\_j )，　Z\_i = ( X\_{a(i−1)}, E^eval\_{i−1}, X\_{a(i)} )

其中 j 为该 γ 之上评价点的个数减一。若 γ 之上除初态外无评价点，则 j = 0，π(γ) = π\_0。

下文凡是言 π 而不另指的，都指 π(γ)。

空评价前缀不含任何 Z，故 TargetHit\_{G\_Θ}( π\_0 ) = 0 恒成立——六类目标都是评价事件，无一能在尚无评价步之处命中。

由此也得第三项与 4.3 的一致：5.1 第三项所称"路径所覆盖的工作段"，即 η(π(γ))；其合法性与 π(γ) 之为合法前缀是同一件事。

### 5.2 路径证书

　　CertReach( γ, G\_Θ ) = PathLegal ∧ InputAdmissible ∧ SegmentQualified ∧ TargetHit

其中 SegmentQualified 即第三项。

必须申明其地位：CertReach 是可达的证明证书，不是 LawDyn 的本体结构。它不得被加入《律动力一般式》的总式，也不得被下游读作 LawDyn 的第三合取项。第四篇的总式已封版为两项，本篇不改。

### 5.3 支持与控制的区别

定义之中的量词是"存在一条路径"。它所断言的，是系统的许可后继之中有这样一条；不断言操作者能选中它，不断言在有分支处会走这一支。

凡是由本篇的结论推出"操作者能够使之发生"的，即以支持冒充控制，见第十四节 K-R5。

第六节

有限秩支持可达定理

### 6.1 定理一

固定 Ξ\_LD。记 D^π\_Θ 为自 X\_0 起的合法前缀的域。

秩函数定义在合法前缀之上，不定义在孤立节点之上：

　　ρ\_Θ : D^π\_Θ → ℕ

满足两条：

　　条件一　ρ\_Θ( π ) = 0　⇒　TargetHit\_{G\_Θ}( π ) = 1  
　　条件二　对任何 π ∈ D^π\_Θ，若 ρ\_Θ( π ) \> 0，则至少存在一个  
　　　　　　Z′ ∈ Next^adm\_LD( π )　使 π′ = π ⌢ Z′ ∈ D^π\_Θ 且 ρ\_Θ( π′ ) \< ρ\_Θ( π )

取前缀而非节点为定义域，一举了结三事。其一，初态 X\_0 无须伪装成评价节点——它本来就凑不成一个 Z。其二，零步情形的型别成立：ρ\_Θ(π) = 0 所推出的是该前缀之上已有命中，而非某个孤立状态自身具备某种评价关系；空评价前缀既不含 Z，其 TargetHit 恒为零，故 ρ\_Θ(π\_0) = 0 只在目标已于既有前缀中命中时可取。其三，Next^adm\_LD 本就定义在前缀之上，秩也定义在前缀之上，二者同型。

则

　　SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 1

且存在一条有限的合法支持路径，记其到达命中前缀所需的评价步数为 N，则

　　N ≤ ρ\_Θ( π\_0 )

其中 π\_0 = ( X\_0 ) 为空评价前缀。对所选路径，其底层执行步数为

　　H = Σ\_{i=0}^{N−1} \[ a(i+1) − a(i) \]

各项有限，故 H 有限。秩每下降一次对应一个评价步，而按承继的锚定制度一个评价步可含多个底层执行步，故本定理不给出 H 的界。若另有每个评价步至多含 M 个底层执行步的条件，方可进一步得 H ≤ M·ρ\_Θ(π\_0)；本篇不引入 M。

v1.0 此处写作 H ≤ ρ\_Θ(π\_0)，把评价步数界误作底层执行步数界，本版撤回。反例：冻结评价协议，使首个评价点落在第 10 个底层执行步之后且即命中目标，令 ρ\_Θ(π\_0) = 1、命中后秩为 0，两条件都满足，而 H = 10。

### 6.2 证明

取空评价前缀 π\_0 = ( X\_0 )。由第三节的申报，X\_0 在工作域之内，故 π\_0 ∈ D^π\_Θ。

若 ρ\_Θ(π\_0) = 0，由条件一 TargetHit\_{G\_Θ}(π\_0) = 1，路径长度为零，结论成立。必须注意：空评价前缀不含任何评价节点，其 TargetHit 恒为零，故自空评价前缀起步时 ρ\_Θ(π\_0) \> 0 必然成立，零步不发生；此档只为已含命中的非空前缀而设。

若 ρ\_Θ(π\_0) \> 0，由条件二取一个 Z′ ∈ Next^adm\_LD(π\_0) 使 π\_1 = π\_0 ⌢ Z′ ∈ D^π\_Θ 且 ρ\_Θ(π\_1) \< ρ\_Θ(π\_0)。

这一步的合法性由 Next^adm\_LD 的三项要求直接给出：Z′ 来自 Step^M\_Prot；所用输入与模式在 Adm\_LD 之内；且 π\_1 仍为合法前缀，即 LegalLawSegment^{η(π\_1)} = 1。因此整段合法性不是顺手继承，而是随每次扩展重新取得。

于 π\_1 上重复。每重复一次，该前缀的 ρ\_Θ 值严格下降至少一。而 ρ\_Θ 取值于自然数，严格下降不能无限进行，故至多 ρ\_Θ(π\_0) 个评价步之后必得某合法前缀 π\_N 使 ρ\_Θ(π\_N) = 0；由条件一，TargetHit\_{G\_Θ}(π\_N) = 1。每次扩展增加一个评价节点，故下降次数即评价步数 N ≤ ρ\_Θ(π\_0)。

π\_N 为合法前缀，故其所覆盖的工作段满足 LegalLawSegment = 1；各步都来自 Step^M\_Prot，输入与模式都在 Adm\_LD 之内；其上有某 Z\_i ∈ G\_Θ。四项证书齐备，即 CertReach = 1。评价步数 N ≤ ρ\_Θ(π\_0)；底层执行步数 H = Σ\_{i=0}^{N−1} \[ a(i+1) − a(i) \]，为有限个有限正整数之和，故有限。∎

### 6.3 量词的位置

条件二的量词是

　　∀ π \[ ρ\_Θ(π) \> 0 \]　∃ Z′ ∈ Next^adm\_LD( π )

不是

　　∀ π　∀ Z′

因此所推出的只是

　　∃ path

不推出所有路径都命中，不推出必然，不推出概率一，不推出操作者可控。若把条件二写成全称的 Z′——即要求该前缀的每一个合法扩展都使秩下降——所得的将是另一条更强的定理，其证明与本节不同，本篇不作。

### 6.4 ρ\_Θ 的地位

ρ\_Θ 是一件证明工具，随任务而设，随证毕而弃。

它不是场势，不是动力势，不是控制变量，不是律的属性，不是新的 Degree 坐标。它不进入 𝓡 与 Φ，不参与任何读出，不被下游作为对象引用。

同一目标可有多个合法的 ρ\_Θ；取哪一个不影响结论，只影响所得评价步数界的松紧。它定义在合法前缀之上，不定义在场状态之上，故也不可被读作某个状态的属性。

### 6.5 定理一与第七至九节的关系

按法篇第四编第九章，可达式的标准写法容许两条路：路径构造，或可达性论证。二者择一即足。

定理一属后者：它给出一个充分条件，凡是能构造出满足两条的秩函数的，不必显式写出路径即可断定可达，并附带一个评价步数上界。

第七、八、九三节走前者：三条路径都显式给出，其证书逐项核验，不经定理一。

因此定理一在本篇未被任何实例调用。这不是疏漏——直接构造已足以支撑定理二，无须再绕一道秩函数；定理一在此备为一般工具，供目标较远、显式路径不易写出之处使用。

二者所得强度相同，都只到存在一条路径。若某处以定理一得出可达，其评价步数界为 ρ\_Θ(π\_0)，底层执行步数只知有限；若以直接构造得出，其底层执行步数即所构造路径的长度。三节所得的 H = 1 出自后者。

### 12.3 不可达纪律

本篇主要证正可达。若必须写

　　SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 0

则必须证明

　　∀ H \< ∞，∀ γ ∈ Paths^adm\_H：TargetHit\_{G\_Θ}( π(γ) ) = 0

其中 Paths^adm\_H 为自 X\_0 起、长度为 H、其每一 ζ\_r ∈ Step^M\_Prot 且输入与模式都在 Adm\_LD 之内、并使 π(γ) 全程为合法前缀的路径的全体；π(γ) 依 5.1 的对应取得。

即一切有限长的许可路径都不命中。这正是法篇所定的可达式击穿方式之一，用于否证时其举证责任在否证一方。

该式的量词与定理一的下降条件相反：那里是 ∀π ∃Z′，此处是 ∀H ∀γ。正可达只需一条路径，否可达必须尽一切路径——两向的举证负担不同，不可互援。

有限次实验未找到路径的，只能写

　　Undetermined

不得把"我没找到"写成"不可达"。二者的区别在量词：前者是若干次尝试的结果，后者是对一切许可路径的全称断言。

第十四节

击穿

按法篇第一第四编第九章，可达式的击穿方式为：证明一切许可路径都到达不了；或展示所给路径包含不许可的操作。据此列六条。

K-R1　无许可路径。证明

　　∀ H \< ∞，∀ γ ∈ Paths^adm\_H：TargetHit\_{G\_Θ}( π(γ) ) = 0

则相应的 SuppReach^LD\_Ξ( X\_0 ; G\_Θ ) = 1 被击穿。举证范围见 12.3。

K-R2　路径使用非法操作。所给路径之中出现下列之一：u ∉ Adm\_LD；使用 Prot 之外的操作；裸改 g、d、rep、Ω；强制系统选择原本不可控的随机分支；中途扩大许可集。则路径证书失败。

K-R3　资格断裂。路径途中 LegalLawSegment = 0，而仍被称作"同一已成律的动力可达"。则第三项证书失败。

K-R4　目标误判。终态表面相同，而第五篇的正式事件判据未命中。例如 A\_H = 0 却不是由一变零，则不得称 Stop。以机器读数为 ⊥ 的评价步充作命中，同属此类。

K-R5　支持偷换控制。只有 ∃ Z′ 而声称操作者能够保证走到该后继。则越过 5.3 所立的界。

K-R6　Degree 偷代。以 g、rep、κ、P̂ 等直接替代 δ、Reentry、𝒵、FlowShare，并据以宣称 Rise、Fall 或 Migration；或以剖面事件称更熟、退浅。则违 11.2、11.4。

不是击穿的：某次搜索未找到路径——按 12.3 只得 Undetermined；三个 Degree 目标尚无实例路径——那是 11.3 所登记的待证任务，非结论失败；上游被击穿——那将使本篇工作域失效，属条件传导。

本篇为附式独立立篇（可达式），按法篇第一第四编第九章的可达式规范写作与审稿。

所依附条款被击穿或在升版中撤销时，本篇结论随之失效或转为待定：Law 资格制度被撤销，则第三节的初态失效，全篇待定；六类动力事件的判据被改，则第四节的目标集必须重立；运行系统或协议集被改，则第四、七、八、九节的路径必须重核；LB1 构造被撤销，则定理二失效，而定理一不受影响——后者不依赖任何具体实例；SC\_Hold 被击穿，或回读前件、Ω\_e 补检未闭，则本篇读作对象层 Law 之实例结论随之待定，读作「R\_1 ∈ 𝒮 保持」者不受影响。

附式独立成篇，不等于附式升格为主式。本篇结论仍依赖所依附的主式成立。
