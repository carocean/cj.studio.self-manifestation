# 律动力运行基底构造式

第一节

目的、式种与唯一任务

### 1.1 唯一任务

封版《律组式第五·律运行基底构造式》已在最小沉积场之上构造出律运行基底

　　Spec\_LB = Augment( Spec\_min, A\_LB )

其参考实现 flb.py 实际执行沉积场运行，具备双时钟、Freeze、IdleStep、Avail、Mask、复走窗口与 Ω 各真实结构（此 Ω 即该篇之 Ω\_e，只查《场数理式》v2.7 Ω\_W 三项事实之第一项另加阈资格，与 Ω\_W 互不蕴含，见该篇 K13）。

本组式的前五篇——《律作用一般式》《律作用必然式》《律分级式》《律动力一般式》《律动力数理式》——逐级定出 LawAct、Degree、LawDyn 各对象及其形式实现；第六篇《律可达式》就 LB1 实例证其支持可达。各篇都已封版，本篇不重定义，也不重走其路径。

另有封版《律判定式》给出 R ∈ 𝒮 的正式判定程序。本篇的目标律资格即由其判定核签出，不以较弱判据代签；所承继的判定域与前件见 2.5 与 15.7。

但有一件事尚未做过：这些对象是否只能存在于纸面。

本篇的唯一任务是：在 Spec\_LB 之上构造一个真正由沉积场自身动力运行的 Spec\_LDB，使已封版的 Law、LawAct、Degree、LawDyn 取得真实可执行见证，并使 Start、Continue、Stop、Rise、Fall、Migration 六类律动力事件能够在同一固定规格族之中，由底层合法轨迹实际产生。

一句话：

　　本篇所证不是"我们定义了律动力"——上游已经定义；  
　　本篇所证是"这些律动力对象不是纸上的读数：存在一个真实沉积场运行基底，使它们由场动力自己跑出来"。

### 1.2 式种与方法约束

构造式，附式，独立成篇。

按法篇第一第四编第八章，构造式的用途为给出满足条件组的对象的显式构造；其标准写法为：条件组申报；构造程序（逐步显式）；构造物满足条件的逐项验证；构造定理；强度申报；接口。其完成条件为构造显式、逐项验证完成。其击穿方式为展示构造物不满足条件组的某一项，或展示构造程序的某一步无法执行。其禁止写法为：以存在性证明冒充构造；验证缺项；构造依赖没有申报的前件。

按法篇第一第二编第五章，完成强度序为相容、构造、可达、实现。本篇达到构造强度，所覆盖的相容由上游各篇给出；可达强度已由第六篇就 LB1 实例取得，实现强度归后续。

### 2.3 Degree

《律分级式》已固定四项坐标 δ、Reentry、𝒵、FlowShare 及其序方向。本篇以原始读数记

　　D(q, t) = ( δ(q,t), Reentry(q,t), 𝒵(q,t), FlowShare(q,t) )

有利方向为 δ↑、Reentry↑、𝒵↓、FlowShare↑。

注（对应《律分级式》v1.1）　该篇已把熟的比较与 Degree 剖面分立：熟序域 J\_δ 只依 δ̄ 比较熟；Degree 剖面域 J\_D = { δ̄, Reentry, 𝒵, FlowShare } 是续行竞争指数族 CI 的四项输入，其有利方向是该篇规定的有利方向，不是实际竞争优势。本篇 D(q, t) 即剖面读数，δ 即该篇之 δ̄（路径汇总口径见 5.7，即本篇在 Γ\_D 中事前冻结之汇总协议）。故本篇之 Rise、Fall、Migration 都是剖面域 J\_D 上的事件：Rise 不得称"更熟"或"竞争更占优"，Fall 不得称"更生疏"；是否更熟，只按 δ̄ 在 J\_δ 上判。第九节三例中，Rise 与 Migration 之 δ̄ 都升（J\_δ 上更熟），Fall 之 δ̄ 降；Migration 在 J\_D 上不可比，在 J\_δ 上可比，二者不得互代。

记法对照：《律分级式》为使四维同向，于其方向统一向量 D̂(q)（其 7.4）与比较向量 D(q)（其 10.1）中，第三分量皆取 −𝒵。二者由 −𝒵\_A ≥ −𝒵\_B ⟺ 𝒵\_A ≤ 𝒵\_B 对应，所指相同。故本篇之 D(q, t) 与该篇之 D(q) 同名而第三分量写法不同：本篇写原始的 𝒵 并标其有利方向为减，该篇写 −𝒵 使其有利方向为增。

不得标量化为一个总熟度。Rise 与 Fall 用逐项偏序。Migration 是两个 Degree profile 的确定不可比

　　D\_k ∥\_D D\_{k+1}

《律动力数理式》承继该四坐标与比较系统，G\_{D-Sep} 与 G\_{D-Read} 原样向下传递。本篇不修改四坐标。

### 2.5 Law 资格在本篇的判据

本篇凡是称 Law = 1 处，都取上游的合法链

　　Law　⇐　Established ∧ Govern，　Govern = DynamicRole ∧ ΩSupport

但本篇不以结构层的三项诊断直接签 Law。按封版《律数理式》式 (4.7)

　　𝒮( F\_t, L, I ) = { R ⊆ Existing\_t \| EstWitness^M ∧ Govern^M }  
　　Govern^M = DynamicRole^M ∧ ΩSupport^M ∧ Bind^M

形式资格是 R ∈ 𝒮，其判定归封版《律判定式》。该篇的正式判定序为

　　Y\_LB → CC → CR → CNI → Dyn → ΩSupport → Bind → P

其判定域为冻结快照上的单职责、单入口 I = { Ante(L) }、权重型候选。本篇的对象恰在该域之内：L1 单职责，R1 权重型，I = { a1 } = { Ante }，且评价段本就作冻结规约式的读取。

本篇在论证层区分结构诊断与形式资格，二者不得混名。结构层的 Established、DynamicRole、ΩSupport 只用于解释资格的构成，不另设第二个 Law 签出接口；参考实现之中的正式 Law 资格接口只有一个：

　　LawCertificateG6　调用判定核签出 R1 ∈ 𝒮( F, L1, { a1 } )

LawA 只取这一种：只有判定核签出 R1 ∈ 𝒮 时才是真。其后经封版《律数理式》的正向回读（(7.4)、(7.5)、(7.7)，携其 H\_Read 前件）得 Established ∧ Govern，再由封版《律必然式》的充分向（《律一般式》将充分向下交该篇）

　　∃R \[ Established ∧ Govern \]　⇒　Law

得 Law = 1。整条链为

　　FLDB 状态 → Y\_LB → G6 判定 PASS → R1 ∈ 𝒮 → Established ∧ Govern → Law → LegalLawSegment → LawDyn

注（Law = 1 所携条件，对应《律必然式》v1.4 与《律运行基底构造式》v1.3）　参考实现所签者为判定核之 R1 ∈ 𝒮（LawCertificateG6）。下文凡称 Law = 1、Law 保持、LawHold 为真，程序上均指此签出；由此读作 Law，逐环承继下列条件：其一，判定核之协议与引理前件（PR1、PR2-valid、PR3、PR4，引理 3.1、5.1、5.2、5.3，见 15.7）。其二，判定核 ΩSupport 一环所读之 Ω 为 FLB 之 Ω\_e（参考实现 judge 中 omega\_ok 取 F.Om），只查 Ω\_W 三项事实之第一项另加阈资格；按《律运行基底构造式》K13 与《律必然式》第十节箭头一另注，须补事实二（同时核查沉积连接 g \> 0 与介质可用 Avail = 1）与事实三（各子段复走）之检查，未补时此环另携此条件。其三，R1 ∈ 𝒮 → Established ∧ Govern 经《律数理式》回读，携 (7.4)\[H\_ReadC ∧ H\_ReadR ∧ H\_ReadN ∧ H1\]、(7.5)\[H\_ReadD\]、(7.7)\[H\_ReadΩ\]。其四，Established ∧ Govern → Law 经《律必然式》定理四，携承接条件 SC\_Hold（该篇主定理 Conditional on SC\_Hold）。故本篇各构造定理与证书，读作"R1 ∈ 𝒮 在所列各段保持"时不携其二至其四；读作"Law 在所列各段保持"及由此而来之 LegalLawSegment、LawDyn 时，条件等级不高于上列各环中最弱一环。

不得以 RolePath 代理 DynamicRole，也不得以结构层三项直接顶替 R ∈ 𝒮。前者使不真正承担职责的结构被记为 Law，4.5 所登记的失败世界由此暴露；后者则把 Bind 一环无条件置真，而该环由判定式的坍缩引理给出，非无条件通过。

判定核的实现来源见 15.7。

　　　　　　　　　∧ LawDynBaseCapable( Spec\_LDB ) \]

### 3.2 合取的同主词要求

三个合取项必须为同一个 Spec\_LDB 的三项性质，不得由不同的构造物分别见证。

这一条单列，因其失败形态最隐蔽：两个构造物各自通过全部测试，而合取无主词。见 4.4。

### 3.3 八项构造能力与必要因果证书

　　LawDynBaseCapable( Spec\_LDB )  
　　　≔　C1 ∧ C2 ∧ C3 ∧ C4 ∧ C5 ∧ C6 ∧ C7 ∧ C8 ∧ CausalCouplingNonempty

八项之外另有一项必要因果证书 CausalCouplingNonempty，由第十二节验证。

这一项不能省略，也不可降为额外检查。理由在 4.1：一个旁路空算子能够满足四维可读、四维可变、六类事件与 Reader 非因果各项，而删去它，场如故。若 LawDynBaseCapable 只由 C1 至 C8 合取而成，则定理一在逻辑上仍允许那样的失败世界取得该资格——空算子便只是在文字里被批评，未被定理排除。

C1 至 C8 的既有编号与内容不动；第十二节由额外检查升为构造资格的必要因果证书。

八项分述如下。

C1　LawBaseConservative　新增层关闭之后完整退化回 Spec\_LB。证据为 C1–C7 preserve 与 LB1–LB9 的逐项输出一致。

C2　ActRunCap　Start、Continue、Stop 有合法运行 witness。

C3　DegreeReadCap　δ、Reentry、𝒵、FlowShare 四维都由真实场状态与实际运行记录可读。

C4　DegreeVariationCap　四维不是硬编码常量，能随合法场运行发生实际变化。本项不要求证明四维逐项数学独立。

C5　SixEventCap　六类事件各有同规格合法实例，且各带整段 LegalLawSegment 的程序证书。

　　后一句不是修饰。上游已把 LawDyn = LegalLawSegment ∧ DynActual 写死，第五篇又把 LegalLawSegment 立为资格层。因此一个事件若无合法段，它就不是 LawDyn 的 witness，只是一次读数。段级证书因此是 C5 的必要构成，不是可删的加强项。

C6　SegmentExecCap　第五篇的评价步与底层执行段分层可实际执行。

C7　ClockSepCap　Freeze 与 IdleStep 给出双向时钟分离。

C8　ReadoutNonCausalCap　Reader-off 同轨消融通过。

C1 至 C8 为主构造条件。其中 C5 含整段 LegalLawSegment 的程序证书，记为

　　S1　SegmentLawCertificate（7.4 与 9.8）

S1 并入 C5，不另列为可删项——理由已于 C5 条下写明。

另立两项加强证书，不塞入 C1–C8，以免改动已成形的主构造条件：

S2　DegreeSeparationCertificate　四维逐维分离证书，即 G\_{D-Sep} 在本构造域的闭合（8.4，定理五）。  
S3　LocalParameterRobustnessCertificate　四十点单参扫描与二四三点联合网格扫描（13.3）。

二者都非 LawDynBaseCapable 的合取项：删去其中任一，C1–C8 仍各自成立，定理一不受影响。它们所加强的是本篇的强度申报，不是构造目标本身。

动力耦合非空一项不在此列：它已是 LawDynBaseCapable 的合取项，见上。

第四节

必须排除的错误路线，含失败世界

以下列四个已实际出现的失败世界，并列三条实现禁令。

四个失败世界都能在局部产出貌似正确的输出——"六类事件全部出现"一类的报告照样拿得到——而所构造的并未做到所称的事。三条禁令则是构造中不得走的路。逐条如下。

### 4.1 失败世界一：旁路空算子

有这样一版：(Ω\_c, 𝒵) 在旁路自行变化，而 Continuation、Trace、Sediment 完全不受其影响。

该版的 Reader 照样能读出四维，照样能判出 Rise 与 Fall——因为四维的读数本来就随场运行而变，而 (Ω\_c, 𝒵) 只是在一旁自己演化。

对该版作反向消融：删除该模块之后，旧沉积场的 route 与 d、g、rep、Ω 完全不变。

　　判定：FAIL

失败之所在必须说准。它不是数值错误，不是实现疏漏——它的每一项测试都能通过。失败在于：那个模块不在因果链上。删去它而场如故，则它所"驱动"的东西本来就不由它驱动；所谓律动力运行基底，退化为一块挂在旁边的表盘。

因此本篇把"能改变真实运行轨迹"立为构造成功条件，见第十二节。

### 4.2 禁止四项偷代

不得使用

　　g = δ，　rep = Reentry，　κ⁻¹ = 𝒵，　P̂ = FlowShare

第六篇本就把 Degree 侧的实例化保留在 G\_{D-Read} 条件之下，未允许这些代换。以运行基底的既有量直接顶替 Degree 四坐标，所读出的便不是 Degree，而是四个同名的别物；据此判出的 Rise 也不是 Rise。

### 4.3 禁止手工设置事件结果

不得执行 do(Rise)、do(Fall)、do(Migration)，也不得直接设 do(Degree)、do(Reentry)、do(𝒵)、do(FlowShare)。

必须先让沉积场运行，再由 Reader 判断结果。次序颠倒即是把答案先写好再去读。

### 4.4 失败世界二：两个主词

v1.0 的参考实现把保守回归放在 FLDB 上，闭环动力放在一个独立的类 F 上。二者不继承，节点集不同，参数不同。

两半各自都通过：FLDB 的 C1–C7 与 LB1–LB9 全 PASS，F 的六事件与两组消融全 PASS。

但 3.1 的构造目标是一个合取式，其三项必须为同一个 Spec\_LDB 的三项性质。而在该版中

　　LawBaseConservative 在 FLDB 上证  
　　LawDynBaseCapable 在 F 上证

合取取不到同一个主词，第一节所称的"同一固定规格族"也无所指——Inst(Spec\_LDB) 究竟指哪一个规格，有两个答案。

　　判定：FAIL

v1.1 已把全部职责并入 FLDB(FLB) 一条继承链，删去 class F，关闭该缺口。

### 4.5 失败世界三：新增增益绕过职责干预

第三个失败世界出自本篇的实际构造，判定为失败之后方得修正。

有这样一版：新增的耦合增益直接加在 κ 之上，不受 mask 门控。

其表现如下。遮蔽目标承载 R1 之后，命中率

　　P\_base = 1.0，　P\_Rmask = 1.0

即遮蔽不降命中。DynamicRole 的探测因此失效，Govern = DynamicRole ∧ ΩSupport 不成立，目标律在该构造域中并未取得完整的成立资格。

　　判定：FAIL

失败之所在必须说准。它不是数值问题，也不是探测口径不当——上游的 Mask 本就要求能在不改沉积历史的前提下压掉该职责的运行贡献，而新增增益从旁把被遮蔽的边托了起来。凡是新层所加的续行优势不受职责干预约束的，上游的资格判据即被架空。

修正见 5.4：增益受同一个 mask(e) 门控。修后

　　P\_base = 1.0，　P\_Rmask = 0.554，　P\_base − P\_Rmask = 0.446 \> δ = 0.15

同时 g、rep、Ω 都不变，遮蔽后 RolePath 为假。DynamicRole 恢复成立。

此世界与 4.1 的空算子相对：那里是新层不影响场，此处是新层影响了本不该影响的地方。两者都使构造失其所称。

### 4.6 禁止 Reader 反馈

不得 Degree → Continuation，不得 LawDyn → Sediment。

因果方向必须是

　　场动力 → 轨迹 → Degree / LawDyn

而非反之。第五篇 4.2 已把读出量挡在运行律之外。本篇的实现在源码层做到这一点：六个运行函数的自变量中无任何读出量，见 11.2。消融实验另证其行为侧，见 11.3。

### 4.7 失败世界四：动力增益与承重状态脱钩

第四个失败世界也出自本篇的实际构造。

有这样一版：增益已受 mask 门控，却不随该边自身的承重状态而变。

其表现如下。把 anchor 边的积深反事实地压到零，该边仍从分支耦合取得近乎完整的增益，续行分布几乎不动：

　　g(anchor) = 0 时　分布 = ( 0.999, 0.001 )

于是 anchor 的状态对生成分布不再有作用，按 3.10′ 的口径它被合法地排出极小 μ-充分组，DynamicRole 不成立。

　　判定：FAIL

修正见 5.4：增益随 g\_e / g\_max 缩放。修后同一反事实下

　　g(anchor) = 0 时　分布 = ( 0.580, 0.420 )

极小 μ-充分组恢复为两边的状态联合，anchor 在其中，DynamicRole 恢复。

此世界与 4.5 必须分清。4.5 是职责遮蔽不能切断贡献，此处是承重状态不能控制贡献；前者破 do(Mask)，后者破 ActArg^μ。二者自两端夹住同一条角色判定一致性要求。

第五节

构造程序

本节逐步给出构造，每一步标明其地位。

### 5.1 起点

取封版 Spec\_LB 的参考实现 flb.py 所定的类 FLB 为起点，其节点集

　　NODES = \[ a1, a2, u, m1, m2, c, x, y, z, w \]

与介质边集、参数、算子、协议集 Prot\_LB 全部照旧。

### 5.2 第一步：保守扩展的外壳

定义

　　class FLDB( FLB )

以继承取得 FLB 的全部结构。新增节点

　　EXTRA\_NODES = \[ r, o \]

与新增边

　　EXTRA\_EDGES = \[ (c,r), (r,a1), (c,o) \]

新增节点只有两个：回返节点 r 与出口节点 o。回返边自 r 直接返回入口 a1。

关键在于退化区的设置。新增边的 Avail 初值随 ld\_enabled 而定，默认为零。两个开关的默认值为

　　ld\_enabled = False，　coupling\_enabled = True

退化之所以成立，不在两者都假，而在耦合入口处要求二者的合取：kappa 覆写只在 ld\_enabled ∧ coupling\_enabled 时生效，否则径取基类的值。默认之下前者为假，故合取为假，耦合不生效，新增边也不可用。

于是在默认状态下，FLDB 的一切行为与 FLB 逐字相同——这就是 Π\_LB( Spec\_LDB^off ) = Spec\_LB 的实现侧。

地位：外壳是本篇新增实现。继承而非另起，是 3.2 同主词要求的直接落实。

### 5.3 第二步：(Ω\_c, 𝒵) 的运行实现

Ω\_c 为协调压缩度，𝒵 为续行代价（场篇第四 v1.2 由"续行阻抗"改名为"续行代价"，英文 Continuation Cost）。二者都是场篇已有对象，本篇给出其在运行基底中的实现，不是新增本体量。依场篇第四 v1.2：Ω\_c 是同一参考条件下调谐沉积的效果量，不是 Ω 的程度化，不与沉积度 δ 立对应；Ω\_c 高不等于当前代价 𝒵 低，比较当前代价须直接比较 𝒵。本篇亦不主张 Ω\_c 与 δ、Ω 方向一致，不以 Ω\_c 判熟径。参考实现源码注释中的 impedance 为旧名，代码未改。

必须与四者分清：

　　Ω\_c ≠ Ω\_e ≠ Ω\_W ≠ ΩSupport

其动力关系取场篇第四的协调压缩演化式与续行代价演化式。该篇 v1.2 已把两式标为示范模型，只要求申报之方向假设（M1：低代价复走增益关于 Ω\_c 不减、关于 𝒵 不增；M2：高代价退散损失关于 𝒵 不减、关于 Ω\_c 不增；M3 同该篇），其中 μ·𝒵/Ω\_c 一项不承担方程2 之退浅 Eλ。其连续式为

　　dΩ\_c/dt = α·(Ω\_c / 𝒵) − μ·(𝒵 / Ω\_c)  
　　d𝒵/dt = η·(𝒵 / Ω\_c) − ν·Ω\_c

参考实现所执行者，是其活动门控离散实现：

　　dΩ\_c/dt = α·a·(Ω\_c / 𝒵) − μ·(𝒵 / Ω\_c)  
　　d𝒵/dt = η·(𝒵 / Ω\_c) − ν·a·Ω\_c

其中 a ∈ {0, 1}，由该分支本拍是否为实际活动分支决定。

门控必须单独申明，因它不是离散化误差，而是一项实现结构的增加：该示范模型对两个分支同等演化，而实现只让本拍实际被走的那一支承受驱动项，未被走的只承受衰减项。这是参考实现的构造选择，不是理论唯一规定。

在 FLDB 中，二者按分支逐路径维持，记为 pathdyn，随每一拍的实际运行更新。

### 5.4 第三步：耦合进入 Continuation

为使 𝒵 真正进入续行选择，参考实现在 κ 上作单调低代价增益：

　　κ\_LDB(e) = κ\_LB(e) + mask(e) · ( g\_e / g\_max ) · zscore · ( Ω\_c(q) / max(𝒵(q), zmin) )

增益受两重约束，都不能省略。

其一，同一个 mask(e) 门控。Mask 是上游所定的目标职责干预：它要求在不改沉积历史的前提下压掉该职责的运行贡献。而新增增益若绕过 mask，则遮蔽目标承载之后，该边仍从分支耦合取得续行优势——上游的职责干预被新层架空，DynamicRole 的探测随之失效。4.5 登记的即这一失败世界。

Mask 不是 Avail：前者是职责干预，后者是介质可达性。受 mask 门控的只是该边作为当前职责承担所贡献的续行增益，该边本身仍然可达。二者在 Prot\_LB 中是两类合法操作，不得混用。

其二，随该边自身的承重状态缩放，即因子 g\_e / g\_max。这是承重门控原则：

　　协调—代价增益只能调制一项已由该边自身沉积状态提供的承重贡献，不得独立于该承重状态而产生该边的续行资格。

不设此因子，则 g\_e → 0 而增益不随之退去，该边失去承重状态却仍得近乎完整的续行优势；于是 anchor 的状态对生成分布不再有作用，按 3.10′ 的口径它被合法地排出 ActArg^μ，DynamicRole 随之不成立。4.7 登记的即这一失败世界。

该因子使新增项对 g 仍单调不减，故不破 PR2(a) 的单自由量可证性。

这是参考实现的构造约束，非《自显论》的普遍本体定律。

该式属参考实现中的构造选择，用以实现场篇第四示范模型中申报的方向假设（M1，非已证定律）；以 Ω\_c/𝒵 之比作增益亦属构造选择，不表示 Ω\_c 高即代价低；不宣称这是《自显论》唯一可能的本体公式。

源码中该处自带注释 "Reference implementation coupling only ... It is NOT a theory identity"，正文与代码在这一点上一致。

不得把参考代码的选择反写成理论定义。这是击穿第十条所防的。

### 5.5 第四步：真实回环

Reentry 必须来自实际场内回环，不得靠人工标签。

所构造的回环结构为

　　c → r → a1

即自目标径末端 c 经回返节点 r 直接回到入口 a1，其后重新进入 a1 → m1 → c。两段都实际执行，都真实 Trace，都真实 Sediment。

第九节所列的实际 route 即其证据：Rise witness 的路径为 a1 → m1 → c → r → a1 → m1 → c → o，其中 c → r → a1 一段确为实走。

Reentry 由真实 route history 读出。按《律分级式》的冻结定义，目标径总流 F = N + R，其中 N 为直接新输入、R 为回返流，而

　　Reentry = R / N

参考实现依此计：由 PathMap 取出目标径的入口边，于每一 route 之中，该边的首次被走计入 N，其后各次计入 R；走竞争径的 pulse 于二者都不计。冻结的历史窗之内取

　　Reentry = ΣR ÷ ΣN

若 ΣN = 0，即窗内并无对目标径的直接新入，则该坐标不可读，返回不可读状态，不得静默置零。

此处必须与旧写法划清：分母是目标径的直接新输入 N，不是窗内 pulse 的总数。以窗长为分母的做法会把走竞争径的 pulse 也算进 N，所得便不是上游的 Reentry，而是同名的别物。单位 pulse 只能把流的权重离散化，不能替换分母之所指。

禁止把 origin = return 作为用户输入标签直接送给 Reader。Return 必须由路径历史判出。

### 5.6 第五步：PathMap

固定一项已取得 Law 资格的承载 R，经事前冻结的

　　PathMap( L, R ) = q\_R

映射到物理承重路径。

参考实现中，该映射为一张冻结表，其值含三项：

　　pathmap\[ ('L1','R1') \] = ( branch, depth\_nodes, carrier\_edges )  
　　　　　　　　　　　　　\= ( 'A', ( m1, c ), ( (a1,m1), (m1,c) ) )

Degree Reader 经 PathMap 解析出分支、积深节点与承重边，再据此取读数。

硬编码的范围必须说准：物理路径的内容不再写死在 Degree Reader 之内，而是经该表取得；但目标律与承载的标识，在本单目标参考实现中仍以 L1 与 R1 固定于调用处。因此不得写作"Reader 体内无任何目标标识的硬编码"——所去的是路径内容，非目标标识。

表可扩充为多条律与多份承载，本实现只填一项，因本篇只有一个目标律；届时调用处的标识必须随之参数化。

地位：PathMap 是桥接规则，不是新的动力变量。它不参与任何转移，不进入 𝓡 与 Φ 的自变量，只把 Law 侧的承载对应到场侧的路径。

### 5.7 第六步：四维 Degree Reader

　　DRead^Γ( L, R, t ) = ( Read\_δ, Read\_Reentry, Read\_𝒵, Read\_FlowShare )

四维各自的读取来源：

δ　自场篇的真实历史积深读取。路径汇总方式在 Γ\_D 中事前冻结：由 PathMap 解出承重边序列，取其所涉节点，去掉与竞争分支共享的入口节点，对其余节点的积深求均值——本实现中即 m1 与 c 两节点的均值。去掉入口节点，是为不把竞争分支共享的前缀重复算作目标 Law 的专属积深。这是参考实现的冻结采样协议，不是理论唯一规定。

Reentry　自真实闭环 route history 读出，按 ΣR ÷ ΣN 计，分母为目标径的直接新输入，见 5.5。ΣN = 0 时不可读。

𝒵　直接读取实际运行中的 𝒵 值。

FlowShare　自实际竞争运行读出：

　　FlowShare(q,t) = Flow(q,t) ÷ Σ\_{q\_j ∈ Comp\_Γ} Flow(q\_j,t)

比较集、共享段处理与分母都事前冻结。

### 5.8 第七步：时间纪律

四维统一属于同一时刻的 D(q,t)。不得以未来评价段 \[t\_k, t\_{k+1}) 的数据计算 t\_k 的 Reentry 或 FlowShare。

动力判断的次序只能是

　　D\_k → Exec( E^eval\_k ) → D\_{k+1} → Cmp\_D( D\_k, D\_{k+1} )

若数值实现必须用时间窗，则窗口必须事前冻结且满足因果方向。

### 5.9 第八步：开关与消融协议

实现中的持久开关有二：

　　ld\_enabled　　　控制新增拓扑是否可用，并与下一项合取控制耦合是否生效  
　　coupling\_enabled　控制律动力是否进入 Continuation

第十二节的动力消融即切换后者，属实现的持久状态。

第十一节的 Reader 消融不同：模型中没有、也不应有一个 readers 开关。Reader-on 与 Reader-off 是实验协议——一路调用 Degree 与 Law 资格的读出，另一路不调用；两路的运行因果状态、输入、seed 与协议完全相同。

此处必须分三层，不可并作两层。

　　运行因果状态　进入 κ、Continuation、Trace、Sediment 的自变量的  
　　观测记录状态　由运行结果写入、供回读取用者  
　　Reader 调用　　外部的取值动作

参考实现之中确有观测记录：degree\_trace 由每一拍的实际 route 在运行之后写入，供 Reentry 与 FlowShare 的回读取用。因此不可说"模型内部不存在任何读出记录"——它是运行结果的下游记录，不是续行选择的动力原因。

degree\_trace、PathMap 与 Degree 各读出，都不进入 κ、Continuation、Trace、Sediment 的生成自变量。

因此本篇所称的 Reader 非因果，其确义为：调用或不调用 Reader，不改变运行因果状态与其后继轨迹。非谓模型内不存在与读出相关的任何记录。

若把读出设为模型的持久开关，则读出本身即成为运行状态的一部分，第十一节所要证的便先已被实现结构所否定。

### 5.10 第九步：评价段分层

第五篇已把底层执行索引 r 与评价索引 k 分开，并以锚定映射 a(k) 相联。实现必须使一个评价步能够跨越多个底层单步。

为此设一个读出侧操作

　　exec\_eval\_segment( ops )

其中 ops 为该评价步之内待执行的底层操作序列，每项或为一次 pulse，或为一次 IdleStep。该操作在序列执行之前读出 D\_k，执行之后读出 D\_{k+1}，中间各步只登记不产出 D。

登记索引取起始值：按第五篇，ζ\_r = ( X\_r, u\_r, m\_r, Y\_r, X\_{r+1} ) 以该步的起始底层索引为号，故每一步登记其执行之前的 t\_run，而非执行之后的到达值。差这一位，所得 Exec(E\_k) 便与第五篇的写法错开。

该操作在读出侧，不进入运行律。ops 序列在该段运行之前给定，不得事后调整。

由此得

　　Exec( E\_k ) = ( ζ\_{a(k)}, …, ζ\_{a(k+1)−1} )

其长度可大于一。第十节即这一项的验证。

至此构造程序完毕。

第七节

C2 验证：Start、Continue、Stop

### 7.1 验证方式

三者的本体定义已由《律作用一般式》与《律作用必然式》封版，第六篇又已就 LB1 实例给出支持可达。本篇只作运行基底兼容验证：在 FLDB 之中，三类事件能否由真实 pulse 实际取得。

### 7.2 实际运行结果

　　\[six\_events\_unified\] PASS，其中 Start = True，Continue = True，Stop = True

四段实际 route 为

　　act\_routes = ( \[a1, m2, x\], \[a1, m1, c\], \[a1, m1, c\], \[a1, m2, x\] )

由此读出：第一拍目标径未走而第二拍走通，得 (0,1) 即 Start；第二拍与第三拍都走目标径，得 (1,1) 即 Continue；第三拍走通而第四拍转入竞争径，得 (1,0) 即 Stop。

### 7.3 产生方式必须说准

这三段的 pulse 带指定路径参数。参考实现在该参数给出时绕过 Continuation 的选路，而其余一切照旧：每一边都实际执行，都真实 Trace，都真实 Sediment。

因此正确的说法是：

　　三类作用事件在合法协议输入之下，由真实的底层执行链产生；事件标签由 Reader 事后读出。

不得写作"由实际 Continuation 自主选出"。指定路径是合法的协议输入，不是手工置位——手工置位是直接写事件结果或直接改 Degree，此处并无；但它也不是内生的自主选路。

第九节的 Rise 与 Migration 两组才确实含 Continuation 的自主选路：其 route 未经指定，由续行选择自行走出。二者的分别必须保留，免得把合法外部输入写成全自主内生。

### 7.4 段级合法证书

三类作用事件都由相邻两次作用读数构成，非某个执行单元自带的标签。按第五篇，StepAct\_k 取相邻读数对 (A\_k, A\_{k+1}) 的比较，Start、Continue、Stop 分别为 01、11、10。

四个连续的合法执行单元给出

　　acts = ( 0, 1, 1, 0 )

相邻读数对分别形成三类事件：

　　Start　　pair = (0,1)，ζ = ( (60,), (61,) )

不所证：这不是全参数域鲁棒性定理，不是概率定理，不是普遍统计规律。283 个 case 所证的是所扫网格之上的稳健，不是整个连续参数空间的全称命题；网格之外未验。

按法篇第四编第八章，构造式的击穿方式为：展示构造物不满足条件组的某一项；或展示构造程序的某一步无法执行。据此列十七条，顺序排列。

K-C1　新增结构关闭后，旧 C1–C7 或 LB1–LB9 任一结果改变。则 C1 失效，保守扩展不成立。

K-C7　Degree 评价使用未来数据。则违 5.8 的时间纪律。

        pc=hit_prob(C,duty['ante'],duty['read'],n)
    ok=inv and (base-pm)>delta and (pc is None or abs(base-pc)<=delta)

# ---------- G6 decision core: ljudge.py v1.0 logic, kernel routed through F.kappa ----------
# The judging logic below is the sealed Law-Group-VI reference implementation.
# One and only one thing is changed: every generative distribution is produced by
# the ACTUAL continuation kernel of the object being judged (F.kappa), instead of
# the hand-written LB kappa of the original file.  Routing it otherwise would put
# two different kernels inside one decision (K-J4).  Everything else -- the exact
# path enumeration, PR1 restricted re-normalisation, PR2 endpoint grid, the P
# enumeration, the level order and the failure positions -- is as sealed.

MAXHOP = 6

def kernel(F, q, avail=None, mask=None):
    """K_y at position q: distribution over out-edges, from state only (exact).

    Uses F.kappa so that whatever the subclass actually runs is what gets judged.
    """
    avail = avail or F.Avail
    cand = [e for e in F.out[q] if avail[e]]
    if not cand: return {}
    ks = [F.kappa(e)/F.T for e in cand]
    m = max(ks); ws = [math.exp(k-m) for k in ks]; z = sum(ws)
    return {e: w/z for e, w in zip(cand, ws)}

def eval_paths(F, entry, edges_allowed=None, maxhop=MAXHOP):
    """Exhaustive Eval(Ctx): all routes with exact mu.  No Monte Carlo."""
    out = []
    def rec(q, route, prob, hops):
        K = kernel(F, q)
        if edges_allowed is not None:
            K = {e: p for e, p in K.items() if e in edges_allowed}
            z = sum(K.values())
            if z == 0: out.append((tuple(route), prob, 'dead')); return
            K = {e: p/z for e, p in K.items()}      # PR1: restricted kernel re-normalised inside P
        if not K or hops >= maxhop: out.append((tuple(route), prob, 'end')); return
        for e, p in K.items(): rec(e[1], route+[e[1]], prob*p, hops+1)
    rec(entry, [entry], 1.0, 0)
    return out

def mu_read(F, entry, target, edges_allowed=None):
    return sum(p for r, p, _ in eval_paths(F, entry, edges_allowed) if target in r)

def actargs_at(F, q, eps=0.01):
    """Minimal mu-sufficient groups over per-edge state fixings at position q.

    AdmVar endpoint grid {0, g_max}; the counterfactual distribution is produced
    by F.kappa with the counterfactual g substituted in, not by a second kernel.
    """
    cand = [e for e in F.out[q] if F.Avail[e]]
    if not cand: return set(), []
    base = {e: F.g[e] for e in cand}
    def dist(gvals):
        for e in cand: F.g[e] = gvals[e]
        try:
            ks = [F.kappa(e)/F.T for e in cand]
        finally:
            for e in cand: F.g[e] = base[e]
        m = max(ks); ws = [math.exp(k-m) for k in ks]; z = sum(ws)
        return [w/z for w in ws]
    def tv(p, qq): return 0.5*sum(abs(a-b) for a, b in zip(p, qq))
    def sufficient(C):
        freevars = [e for e in cand if e not in C]
        if not freevars: return True
        grids = [[0.0, F.g_max] for _ in freevars]
        dists = []
        for combo in itertools.product(*grids):
            gv = dict(base); gv.update({e: v for e, v in zip(freevars, combo)})
            for e in C: gv[e] = base[e]
            dists.append(dist(gv))
        return max(tv(a, b) for a in dists for b in dists) <= eps
    minimal = []
    for r in range(len(cand)+1):
        for C in itertools.combinations(cand, r):
            if sufficient(set(C)) and not any(set(M) <= set(C) for M in minimal):
                minimal.append(C)
    return set(u for M in minimal for u in M), minimal

def duty(ante, anchor, read): return dict(ante=ante, anchor=anchor, read=read)

def _judge_P(F, L, P, R, pi0, eps):
    """CR / CNI / Dyn / OmegaSupport on one implementation P subset R.
    Depth order: CR=1, CNI=2, Dyn=3, OmegaSupport=4 (all-pass)."""
    ante, anchor, read = L['ante'], L['anchor'], L['read']; d = {}
    m_res = mu_read(F, ante, read, edges_allowed=set(P))
    d['P'] = [f"{e[0]}->{e[1]}" for e in sorted(P)]
    d['CR'] = dict(anchor_in_P=anchor in P, mu_restricted=round(m_res, 4), pi0=pi0)
    if not (anchor in P and m_res >= pi0): return 0, d
    # CNI by reduction lemma 5.1: frozen => Estab={g>0}; under PR1 the witness has
    # Q(Pi) subset P subset R subset Estab (CC); Bear cap Inst = empty since P has
    # no g=0 edge.  The program asserts the lemma's premises.
    assert all(F.g[e] > 0 for e in P), "CNI reduction premise violated"
    d['CNI'] = dict(by_reduction_lemma=True, Q_subset_Estab=True)
    aa, minimal = actargs_at(F, anchor[0], eps)
    adj = defaultdict(list)
    for (i, j) in P:
        if F.g[(i, j)] > 0 and F.mask[(i, j)]: adj[i].append(j)
    seen = {anchor[1]}; st = [anchor[1]]
    while st:
        x = st.pop()
        for y2 in adj[x]:
            if y2 not in seen: seen.add(y2); st.append(y2)
    rolepath = (anchor in aa) and (read in seen or read == anchor[1])
    d['Dyn'] = dict(ActArg_at_anchor_tail=[f"{e[0]}->{e[1]}" for e in sorted(aa)],
                    minimal_groups=[[f"{e[0]}->{e[1]}" for e in M] for M in minimal],
                    anchor_in_ActArg=anchor in aa, rolepath=rolepath)
    if not rolepath: return 2, d
    seenA = F._closure(ante, [e for e in F.E if F.Avail[e]])
    reach = any(F.Avail[e] and e[0] in seenA for e in P)
    bear = [e for e in P if e == anchor or (anchor[1] == e[0] or e[0] in seen)]
    omega_ok = all(F.Om[e] > 0 for e in bear)
    d['OmegaSupport'] = dict(Reach=reach, Bear=[f"{e[0]}->{e[1]}" for e in bear],
                             Omega={f"{e[0]}->{e[1]}": round(F.Om[e], 2) for e in bear})
    if not reach: return 3, dict(d, fail='Reach')
    if not omega_ok: return 3, dict(d, fail='OmegaOK')
    return 4, d

def judge(F, L, R, I, pi0=0.9, eps=0.01, verbose=False):
    """Decision domain: single-duty, single-entry I={Ante}, measure-type candidate."""
    T = {}
    if list(I) != [L['ante']]:
        T['fail_at'] = 'bot (outside decision domain: single duty, single entry I={Ante})'
        return None, T
    F = copy.deepcopy(F); F.Freeze()
    T['Y'] = {e: (round(F.g[e], 2), int(F.S(e)), round(F.Om[e], 2), F.Avail[e], F.mask[e])
              for e in F.E if F.g[e] > 0 or e in R}
    cc = len(R) > 0 and all(e in F.E for e in R) and all(F.g[e] > 0 for e in R)
    T['CC'] = cc
    if not cc: return _out('CC', T, verbose)
    anchor = L['anchor']; best = (-1, None)
    for r in range(1, len(R)+1):
        for Pt in itertools.combinations(R, r):
            if anchor not in Pt: continue
            depth, detail = _judge_P(F, L, set(Pt), R, pi0, eps)
            if depth > best[0]: best = (depth, detail)
            if depth == 4: break
        if best[0] == 4: break
    depth, detail = best
    for k in ('P', 'CR', 'CNI', 'Dyn', 'OmegaSupport'):
        if detail and k in detail: T[k] = detail[k]
    if depth == 4:
        T['Bind'] = dict(by_collapse_lemma=True, value=True)
        T['verdict'] = 'R in S'
        return _out(None, T, verbose)
    fail = ['CR', 'CNI', 'Dyn',
            ('OmegaSupport(Reach)' if detail and detail.get('fail') == 'Reach' else 'OmegaSupport(OmegaOK)')][depth if depth < 3 else 3]
    return _out(fail, T, verbose)

def _out(fail, T, verbose):
    T['fail_at'] = fail
    if verbose:
        print("PASS  R in S" if fail is None else f"FAIL @ {fail}")
        for k, v in T.items():
            if k != 'fail_at': print(f"  {k} = {v}")
    return (fail is None), T

def judge_G6(F, R, L, I, pi0=0.9, eps=0.01, verbose=False):
    """Adapter alias kept for the call sites in this file."""
    return judge(F, L, R, I, pi0, eps, verbose)

    both=sum(1 for x,y in ev.values() if x and y); either=sum(1 for x,y in ev.values() if x or y)
    return both/either if either else 0.0

class FLDB(FLB):
    """One unified conservative extension of FLB.

    The same d/g/rep/Om/Avail/Mask/t_run/t_sed state carries both the sealed
    FLB regression duties and the law-dynamics witnesses.  No second field
    model is embedded here.
    """
    def __init__(self, nodes, medium, *args, ld_enabled=False,
                 coupling_enabled=True, zscore=0.30,
                 alpha_c=.10, mu_c=.055, eta_c=.085, nu_c=.10,
                 zmin=.08, dt_c=.05, degree_window=12, **kwargs):
        super().__init__(nodes, medium, *args, **kwargs)
        self.ld_enabled=ld_enabled
        self.coupling_enabled=coupling_enabled
        self.zscore=zscore
        self.alpha_c,self.mu_c,self.eta_c,self.nu_c=alpha_c,mu_c,eta_c,nu_c
        self.zmin,self.dt_c=zmin,dt_c
        # Field-Ch.4 implementation states for the two competing continuation paths.
        self.pathdyn={'A':[1.0,.70], 'X':[1.0,.70]}  # [Omega_c, Z]
        self.degree_trace=deque(maxlen=degree_window)
        # extra topology exists in the same Medium, but conservative region disables it.
        for e in EXTRA_EDGES:
            if e in self.Avail:
                self.Avail[e]=1 if ld_enabled else 0

    @staticmethod
    def _branch_for_edge(e):
        if e in (('a1','m1'),('m1','c')): return 'A'
        if e in (('a1','m2'),('m2','x')): return 'X'
        return None

    def kappa(self,e):
        base=super().kappa(e)
        if base < -1e8 or not (self.ld_enabled and self.coupling_enabled):
            return base
        k=self._branch_for_edge(e)
        if k is None:
            return base
        oc,z=self.pathdyn[k]
        # Reference implementation coupling only: higher compression/lower impedance
        # increases continuation tendency.  It is NOT a theory identity.
        #
        # The added gain is gated by the SAME mask[e] as the sealed base term.
        # Mask is the upstream duty-directed intervention: it must suppress every
        # continuation gain this edge contributes as the current bearer of that
        # duty, not merely the groove term.  Mask is not Avail; the edge stays
        # medium-reachable, only its duty contribution is suppressed.
        # Bearing-state gating.  The coordination/impedance gain may only
        # modulate a continuation contribution this edge already supplies out of
        # its OWN sediment state; it must not confer continuation standing on an
        # edge independently of that state.  Hence the factor g_e / g_max:
        # g_e = 0  =>  no law-dynamics gain at all.  Without it the anchor's
        # bearing state stops affecting the generative distribution, ActArg^mu
        # legitimately drops the anchor, and DynamicRole fails (K-J4 territory).
        # The added term stays monotone non-decreasing in g, so PR2(a) is intact.
        # This is a reference-implementation constraint, not a general ontic law.
        bear=self.g[e]/self.g_max if self.g_max>0 else 0.0
        return base + self.mask[e]*bear*self.zscore*(oc/max(z,self.zmin))

    def _update_pathdyn(self,active):
        if not self.ld_enabled:
            return
        for k,(oc,z) in list(self.pathdyn.items()):
            a=1.0 if k==active else 0.0
            oc=max(.05,oc); z=max(self.zmin,z)
            doc=self.alpha_c*a*oc/z - self.mu_c*z/oc
            dz=self.eta_c*z/oc - self.nu_c*a*oc
            self.pathdyn[k]=[
                max(.05,oc+self.dt_c*doc),
                max(self.zmin,z+self.dt_c*dz)
            ]

    def pulse(self,entry,p=1.0,path=None,maxhop=12):
        route,inst=super().pulse(entry,p,path,maxhop)
        active=None
        for e in zip(route,route[1:]):
            if e==('a1','m1'): active='A'; break
            if e==('a1','m2'): active='X'; break
        if active is not None:
            self._update_pathdyn(active)
        # Trace-derived readout support only.  Nothing below feeds Continuation/Sediment.
        # Upstream Reentry is R/N on the TARGET path: N counts direct new entry
        # into the target path; R counts each entry that follows a prior one.
        # Competing-branch pulses contribute to neither.
        entry=self.PathMap('L1','R1')['carrier_edges'][0]
        N_t=0; R_t=0
        for e in zip(route,route[1:]):
            if e==entry:
                if N_t==0: N_t=1
                else: R_t+=1
        a_flow=sum(1 for e in zip(route,route[1:]) if e==('a1','m1'))
        x_flow=sum(1 for e in zip(route,route[1:]) if e==('a1','m2'))
        self.degree_trace.append((N_t,R_t,a_flow,x_flow,tuple(route)))
        return route,inst

    def PathMap(self,law_id='L1',carrier_id='R1'):
        """Frozen Law-side -> physical carrier bridge for this reference construction.

        This is an implementation bridge, not a new dynamical variable and not a
        reverse inference from physical familiarity to Law qualification.
        """
        table={
            ('L1','R1'): dict(branch='A', depth_nodes=('m1','c'),
                              carrier_edges=(('a1','m1'),('m1','c')))
        }
        return table[(law_id,carrier_id)]

    def LawCertificateG6(self):
        """Formal qualification via the sealed G6 decision core.

        Signs R1 in S(F,L1,{a1}) through CC -> CR -> CNI -> Dyn ->
        OmegaSupport -> Bind, with every generative distribution produced by
        this object's own F.kappa.

        NOT cached.  The verdict depends on F.kappa, which in turn depends on
        g, d, mask, Avail, pathdyn, ld_enabled, coupling_enabled, zscore, zmin
        and T.  Under Freeze the sediment state can stay fixed while pathdyn
        keeps advancing, so any cache keyed on sediment quantities alone would
        return a stale verdict computed under a kernel the object no longer
        runs.  Proving a cache key complete is not worth it here: one judgement
        costs under a millisecond on this spec.
        """
        return judge(self, L1, R1, ['a1'])

    def LawA(self):
        """Law = 1 iff the G6 core signs R1 in S, then G7 sufficiency applies."""
        ok,_=self.LawCertificateG6()
        return ok

    def DegreeA(self):
        # Gamma_D reference implementation via the explicit frozen PathMap bridge.
        pm=self.PathMap('L1','R1')
        dn=pm['depth_nodes']
        delta=sum(self.d[n] for n in dn)/len(dn)
        W=list(self.degree_trace)
        # Unit-pulse reference realization of the target-path return ratio.
        # Reentry = sum R / sum N over the frozen window, target path only.
        # No direct new entry recorded => coordinate unreadable, not zero.
        sumN=sum(x[0] for x in W); sumR=sum(x[1] for x in W)
        reentry=(sumR/sumN) if sumN else None
        z=self.pathdyn[pm['branch']][1]
        af=sum(x[2] for x in W); xf=sum(x[3] for x in W)
        share=af/(af+xf) if (af+xf) else None
        return (delta,reentry,z,share)

    def exec_eval_segment(self,ops):
        """Execute one evaluation segment containing >=1 r-level operations.

        Each pulse contributes a distinct t_run index r; IdleStep contributes only
        sediment-clock advancement.  Degree is read only at segment boundaries.
        """
        d0=self.DegreeA(); r0=self.t_run; s0=self.t_sed
        law_trace=[('start',self.t_run,self.t_sed,self.LawA())]
        op_trace=[]
        for op in ops:
            kind=op[0]
            # Fifth-piece convention: zeta_r = (X_r,u_r,m_r,Y_r,X_{r+1}) is indexed by
            # the STARTING underlying index, so record r before the step executes.
            r_before=self.t_run; s_before=self.t_sed
            if kind=='pulse':
                kwargs=op[1] if len(op)>1 else {}
                route,_=self.pulse('a1',**kwargs)
                op_trace.append(('pulse',r_before,s_before,tuple(route)))
            elif kind=='idle':
                n=op[1] if len(op)>1 else 1
                self.IdleStep(n)
                op_trace.append(('idle',r_before,s_before,n))
            else:
                raise ValueError(kind)
            law_trace.append((kind,self.t_run,self.t_sed,self.LawA()))
        zeta=tuple(t[1] for t in op_trace if t[0]=='pulse')
        d1=self.DegreeA()
        return dict(D0=d0,D1=d1,r0=r0,r1=self.t_run,s0=s0,s1=self.t_sed,
                    r_span=self.t_run-r0,zeta=zeta,ops=tuple(op_trace),
                    law_trace=tuple(law_trace),legal=all(x[3] for x in law_trace))

    def ActionA(self,route):
        es=set(zip(route,route[1:]))
        return int(set(R1)<=es)

    def dyn_snapshot(self):
        return dict(
            t_run=self.t_run,t_sed=self.t_sed,SED=self.SED,
            d=tuple((n,round(self.d[n],12)) for n in self.nodes),
            g=tuple((e,round(self.g[e],12)) for e in self.E),
            rep=tuple((e,tuple(self.rep[e])) for e in self.E),
            Om=tuple((e,round(self.Om[e],12)) for e in self.E),
            Avail=tuple((e,self.Avail[e]) for e in self.E),
            mask=tuple((e,self.mask[e]) for e in self.E),
            pdyn=tuple((k,round(v[0],12),round(v[1],12)) for k,v in sorted(self.pathdyn.items())),
            routes=tuple(x[2] for x in self.log),
        )

def cmp_degree(a,b,e=1e-9):
    if None in a or None in b:return 'NA'
    aa=(a[0],a[1],-a[2],a[3]); bb=(b[0],b[1],-b[2],b[3])
    ge=all(bb[i]>=aa[i]-e for i in range(4)); gt=any(bb[i]>aa[i]+e for i in range(4))
    le=all(aa[i]>=bb[i]-e for i in range(4)); lt=any(aa[i]>bb[i]+e for i in range(4))
    if ge and gt:return 'Rise'
    if le and lt:return 'Fall'
    if not ge and not le:return 'Migration'
    return 'Equal'

def new_operational(seed=0,coupling=True):
    return FLDB(NODES+EXTRA_NODES,MED+EXTRA_EDGES,seed=seed,
                ld_enabled=True,coupling_enabled=coupling,zscore=.30)

def _set_loop(F,on=True):
    for e in EXTRA_EDGES:
        F.SetAvail(e,1 if on else 0)

def form_A(F,na=60,nx=0):
    # Legal construction history; loop disabled only during formation.
    _set_loop(F,False)
    for _ in range(na): F.pulse('a1',1.0,path=['a1','m1','c'])
    for _ in range(nx): F.pulse('a1',1.0,path=['a1','m2','x'])
    _set_loop(F,True)
    return F

def test_g6_five_cases():
    """Reproduce the sealed G6 five-case verification, failure positions included.

    Oracle is Appendix B of the sealed piece:
      positive PASS / strong impulse OmegaSupport(OmegaOK) / pure correlation CC
      / abandoned groove CR / weak trace OmegaSupport(OmegaOK).
    Any differing position fails this test.

            F.pulse('a1',1.0,path=['a1','m1','c']); F.pulse('a2',1.0,path=['a2','m2','x'])
        return F

def test_law_state_sensitivity():
    """The formal qualification must track the kernel it is judged under.

    Under Freeze the sediment quantities (g, rep, Om) stay fixed while pathdyn
    keeps advancing, so F.kappa changes while any sediment-keyed cache would
    not.  What this test asserts is that the qualification is recomputed under
    the changed kernel rather than served from a sediment-keyed stale cache.

    It does NOT assert that the verdict flips.  A changed kernel may well still
    judge Law true; the danger of a stale cache is that the judgement is not
    made again, not that it must come out differently.
    """
    F=form_A(new_operational(0),60,10); F.Freeze()
    g0={e:F.g[e] for e in F.E}; rep0={e:len(F.rep[e]) for e in F.E}
    pd0={k:tuple(v) for k,v in F.pathdyn.items()}
    v0,_=F.LawCertificateG6()
    kap0={e:F.kappa(e) for e in F.out['m1'] if F.Avail[e]}
    # advance pathdyn only: Freeze keeps sediment fixed
    for _ in range(40): F.pulse('a1')
    sed_same=(all(abs(F.g[e]-g0[e])<1e-12 for e in F.E)
              and all(len(F.rep[e])==rep0[e] for e in F.E))
    pd_moved=any(tuple(F.pathdyn[k])!=pd0[k] for k in pd0)
    kap1={e:F.kappa(e) for e in F.out['m1'] if F.Avail[e]}
    kappa_moved=any(abs(kap1[e]-kap0[e])>1e-12 for e in kap0)
    v1,_=F.LawCertificateG6()
    # Evidence that the judgement is made again under the new kernel: kappa has
    # moved while the sediment state has not, and no qualification cache exists.
    # verdict_before / verdict_after are reported, not constrained.
    out=dict(sediment_unchanged=sed_same, pathdyn_moved=pd_moved,
             kappa_moved=kappa_moved, verdict_before=v0, verdict_after=v1,
             no_cache=not hasattr(F,'_law_cache'))
    ok=(sed_same and pd_moved and kappa_moved and out['no_cache'])
    return ok,out

def test_dynamics_off_unified():
    """Causally sensitive existential witness for CausalCouplingNonempty.

    Not "run some seeds and hope one diverges".  The witness is frozen and
    declared in advance:
      snapshot   form_A(new_operational(0), 60, 60)
      position   a1, which has two competing out-edges
      seed       43, whose first draw u = 0.038552...
    The two branches differ in exactly one variable: OFF sets
    coupling_enabled = False.  ld_enabled, topology, inputs, protocol and the
    random stream are identical.

    The chain established is:
      kappa^ON != kappa^OFF  =>  P^ON(e|q) != P^OFF(e|q)
      =>  the draw u lies in the separating interval (P_OFF, P_ON)
      =>  the SAME u selects different edges on the two sides
      =>  Continuation differs => Trace differs => Sediment differs.
    The divergence is therefore not a lucky sample: the random variable is held
    fixed and the difference comes from the conditional distribution itself.
    """
    WITNESS_SEED=43
    base=form_A(new_operational(0),60,60)
    ON=copy.deepcopy(base); OFF=copy.deepcopy(base)
    OFF.coupling_enabled=False                      # the single differing variable
    # exact conditional distributions at the competing position, before any draw
    def _pq(F,q):
        cand=[e for e in F.out[q] if F.Avail[e]]
        ks=[F.kappa(e)/F.T for e in cand]
        mx=max(ks); ws=[math.exp(k-mx) for k in ks]; z=sum(ws)
        return cand,[w/z for w in ws]
    cand,p_on=_pq(ON,'a1'); _,p_off=_pq(OFF,'a1')
    lo,hi=sorted([p_on[0],p_off[0]])
    u=random.Random(WITNESS_SEED).random()
    in_interval=(lo<u<hi)
    # same state, same seed, same protocol; only the coupling flag differs
    ON.rng=random.Random(WITNESS_SEED); OFF.rng=random.Random(WITNESS_SEED)
    first=None
    for i in range(80):
        ro,_=ON.pulse('a1'); rf,_=OFF.pulse('a1')
        if first is None and ro!=rf: first=(i,ro,rf)
    gd=sum(abs(ON.g[e]-OFF.g[e]) for e in ON.E)
    dd=sum(abs(ON.d[n]-OFF.d[n]) for n in ON.nodes)
    out=dict(witness_seed=WITNESS_SEED,
             position='a1', edges=[f"{e[0]}->{e[1]}" for e in cand],
             P_on=[round(x,6) for x in p_on], P_off=[round(x,6) for x in p_off],
             separating_interval=(round(lo,6),round(hi,6)), u=round(u,6),
             u_in_interval=in_interval,
             prob_differs=(p_on!=p_off),
             same_initial_state=True, same_seed=True, same_protocol=True,
             only_coupling_differs=True,
             first_divergence=first, sum_abs_g=gd, sum_abs_d=dd)
    ok=(out['prob_differs'] and in_interval and first is not None and gd>0 and dd>0)
    return ok,out

                   others_zero_all=all(r[1] for r in rows),law_all=all(r[2] for r in rows))

def test_legal_segments_unified():
    out={}
    # Rise: retain first rise whose full one-r-step segment is Law-legal at both boundaries.
    R=form_A(new_operational(0),60,10); rise=None
    for i in range(80):
        seg=R.exec_eval_segment([('pulse', {})])
        if cmp_degree(seg['D0'],seg['D1'])=='Rise' and seg['legal']:
            rise=(i,seg); break
    out['RiseLegal']=rise is not None
    # Fall: Law must hold before, after IdleStep, and after competing pulse.
    F=form_A(new_operational(0),60,5)
    fallseg=F.exec_eval_segment([('idle',1),('pulse',{'path':['a1','m2','x']})])
    out['FallLegal']=(cmp_degree(fallseg['D0'],fallseg['D1'])=='Fall' and fallseg['legal'])
    # Migration: check each evaluation beat as a legal segment.
    M=form_A(new_operational(0),60,0); M.degree_trace.clear()
    M.SetAvail(('c','r'),1); M.SetAvail(('r','a1'),1); M.SetAvail(('c','o'),0)

    M.SetAvail(('c','r'),0); M.SetAvail(('c','o'),1)
    seg2=M.exec_eval_segment([('pulse', {})])
    out['MigrationLegal']=(cmp_degree(seg1['D1'],seg2['D1'])=='Migration'
                           and seg1['legal'] and seg2['legal'])
    ok=all(out.values())
    return ok,dict(flags=out,rise=rise,fall=fallseg,migration=(seg1,seg2))

def test_degree_sep_unified():
    """Construction-level G_D-Sep witnesses: each coordinate can vary alone.

    All pairs remain Law-qualified; no Degree coordinate is directly edited.
    Equality of the three non-target coordinates is checked numerically.
    """
    import copy as _copy
    tol=1e-12; out={}

    # delta only: first establish an identical readable Degree window, then vary
    # sediment time only. IdleStep does not update pathdyn or degree_trace.
    B=form_A(new_operational(1),60,0); B.degree_trace.clear(); B.pulse('a1',path=['a1','m1','c'])
    A=_copy.deepcopy(B); C=_copy.deepcopy(B); A.IdleStep(1); C.IdleStep(5)
    out['delta']=(A.DegreeA(),C.DegreeA(),A.LawA() and C.LawA())

    # Reentry only: sediment frozen; same active A update and FlowShare=1, but
    # one route truly re-enters while the other exits.
    B=form_A(new_operational(2),60,0); B.degree_trace.clear(); A=_copy.deepcopy(B); C=_copy.deepcopy(B); A.Freeze(); C.Freeze()
    A.SetAvail(('c','r'),1); A.SetAvail(('r','a1'),1); A.SetAvail(('c','o'),0)
    C.SetAvail(('c','r'),0); C.SetAvail(('c','o'),1)
    A.pulse('a1'); C.pulse('a1'); out['reentry']=(A.DegreeA(),C.DegreeA(),A.LawA() and C.LawA())

    # Z only: same multiset of one A and one X pulse, reversed order, under
    # Freeze. Aggregate reentry/share are identical; nonlinear pathdyn order splits Z.
    B=form_A(new_operational(4),60,0); B.degree_trace.clear(); A=_copy.deepcopy(B); C=_copy.deepcopy(B); A.Freeze(); C.Freeze()
    A.pulse('a1',path=['a1','m1','c']); A.pulse('a1',path=['a1','m2','x'])
    C.pulse('a1',path=['a1','m2','x']); C.pulse('a1',path=['a1','m1','c'])
    out['Z']=(A.DegreeA(),C.DegreeA(),A.LawA() and C.LawA())

    # FlowShare only: both routes enter the target path once and re-enter it
    # once, so R/N is identical on both sides; sediment is frozen and the first
    # active A-branch update is the same.  They differ only in the competing
    # flow taken afterwards, which moves FlowShare alone.
    B=form_A(new_operational(3),60,0); B.degree_trace.clear(); A=_copy.deepcopy(B); C=_copy.deepcopy(B); A.Freeze(); C.Freeze()
    A.pulse('a1',path=['a1','m1','c','r','a1','m1','c','o'])
    C.pulse('a1',path=['a1','m1','c','r','a1','m1','c','r','a1','m2','x'])
    out['FlowShare']=(A.DegreeA(),C.DegreeA(),A.LawA() and C.LawA())

    targets={'delta':0,'reentry':1,'Z':2,'FlowShare':3}; detail={}; allok=True
    for name,(x,y,law) in out.items():
        dif=[abs(x[i]-y[i]) for i in range(4)]
        t=targets[name]; others=[i for i in range(4) if i!=t]
        ok=law and dif[t]>tol and all(dif[i]<=tol for i in others)
        detail[name]=dict(A=x,B=y,diff=dif,law=law,target=t,ok=ok)
        allok &= ok
    return allok,detail

    base=dict(ld_enabled=True,coupling_enabled=True,zscore=.30,
              alpha_c=.10,mu_c=.055,eta_c=.085,nu_c=.10,
              zmin=.08,dt_c=.05)

def form(F,na=60,nx=0):
    m._set_loop(F,False)
    for _ in range(na): F.pulse('a1',1.0,path=['a1','m1','c'])
    for _ in range(nx): F.pulse('a1',1.0,path=['a1','m2','x'])
    m._set_loop(F,True); return F

def validate(p, seeds=range(5)):
    for seed in seeds:
        # Act Start/Continue/Stop + Law
        A=form(newp(seed+1000,**p),60,0)
        routes=[]; acts=[]
        for path in (['a1','m2','x'],['a1','m1','c'],['a1','m1','c'],['a1','m2','x']):
            r,_=A.pulse('a1',path=path); routes.append(r); acts.append(A.ActionA(r))
        if not (acts==[0,1,1,0] and A.LawA()): return False,'act'
        # Rise autonomous
        R=form(newp(seed,**p),60,10); prev=R.DegreeA(); rise=False
        for _ in range(80):
            R.pulse('a1'); cur=R.DegreeA()
            if m.cmp_degree(prev,cur)=='Rise' and R.LawA(): rise=True; break
            prev=cur
        if not rise: return False,'rise'
        # Fall

        if not (m.cmp_degree(b,a)=='Fall' and l0 and F.LawA()): return False,'fall'

        M=form(newp(seed,**p),60,0); M.degree_trace.clear()
