自显论 · 律篇 · 律动力组式第九 v1.0

# 律源式

第一节

目的、式种与唯一任务

### 1.1 唯一任务

固定一个事前冻结的 Law 候选资格对象

　　χ\_L = ( L, I, Rel(L), Γ\_judge )

与来源协议 Π\_src。

若该候选在申报的历史窗之中，首次由正式的 Law = 0 跨到正式的 Law = 1，则问：哪一段实际历史承担了这一次首次成律；而在来源不唯一时，理论最多能够确定到什么程度。

所研究的只是首次成律的来源。

### 1.2 式种

源式，附式，独立成篇。

按法篇第一第四编第四章，源式的用途为证明某个结构或标签的发生来源——它是由什么过程压出来的，而不是由什么给定的；其进入条件为该结构或标签已经成立，而其来源仍被默认为给定的或外在的；其标准写法为对象申报、默认来源的排除、发生过程刻画、来源定理、来源不能唯一确定处的申报、接口；其完成条件为来源定理证明完成、不能唯一确定处显式列出。

据此安排：第三节为对象申报，第四节为默认来源的排除，第五至第八节为发生过程的刻画，第九节立来源核心，第十节为来源定理，第十一节申报不能唯一确定处，第十二与十三节给出生成模式、条件与状态，第十四节为击穿，第十五节为接口。

### 1.3 不在本篇的

复制、迁移、恢复、替换、跨载体重现，都不在本篇。

1 → 0 → 1 之后的再次资格取得也不在本篇。此处必须分两问：若问题表述为「原有的那一条 Law 得以恢复」，则必须先有身份判据，而第八篇已证两个配对基底不可互相冒充、闭合的 Law identity 性质至今未立，故无从下手；若只问同一冻结候选的再次资格取得，则可另立再成律来源的任务，而不得借本篇作答——本篇的 Genesis 只守窗内的首次，再次的不在其义。

### 1.4 四条边界

四句必须先钉住，全篇不得反向使用。

其一

　　SameCandidateQualification　≠　SameLawIdentity

重放之中再次令同一冻结候选取得 Law = 1，不表示证明了「同一条 Law 再次出现」。所同的是候选的资格，不是律的身份。

其二

　　LawQualification　≠　LawGenesisMode

正式的 Law judge 判的是当前是否成律，不判它由何而来。资格的判定程序里没有来源这一项。

其三

　　Law = 1　⇏　FieldBorn

直接的外部编辑之后，只要正式判定成立，仍可取得 Law 资格；而这不表示该资格由场内的沉积生成。

其四

　　CounterfactualNecessity　⇏　SourceBearing

某条件「没有它就不能成律」，不自动说明它是这条 Law 的形成来源。背景、宿主、全局运行条件都可有此性质而不承担形成。

### 1.5 一句话

来源不是从终态倒推出来的，也不是从「删了就不成」倒推出来的。它要求一段实际发生过的历史，既真在形成链上，又在合法反事实下承重。

第二节

上游输入

《律组式》与《律判定式》（封版）——正式的 Law 资格。本篇的 Law = 0 与 Law = 1 都按其判定程序取得，不另造简化版。

《律动力数理式》（封版）——运行段、实际执行与贡献归属的形式纪律。第七节的形成链按其两套索引与评价段制度写。

《律动力运行基底构造式》（封版）——真实沉积场的运行与正式判定接口。Execution、Trace、Sedimentation 三者的实际形态本于此。

《律身份配对区分式》（封版）——候选声明的对应与 root 的对应都不得冒充 SameLaw。1.4 其一本于此。

第三节

对象申报

### 3.1 候选资格对象

　　χ\_L = ( L, I, Rel(L), Γ\_judge )

L 为候选律，I 为其适用域，Rel(L) 为其关系职责，Γ\_judge 为正式的资格判定协议。

四项事前冻结。

### 3.2 来源协议

　　Π\_src = ( χ\_L, X\_0, H\_obs, B^Π, Ops^Π, Dyn^Π, Judge^Π, T\_Π, Gran^Π )

　　X\_0　　　申报初态  
　　H\_obs　　实际观察到的有序历史  
　　B^Π　　　冻结背景  
　　Ops^Π　　许可的删除、屏蔽、Mask、抑制等操作，逐项冻结，其应备三条见 6.1  
　　Dyn^Π　　合法的沉积场动力  
　　Judge^Π　正式的 Law judge  
　　T\_Π　　　评价点集，有限，Judge^Π 只在其上求值  
　　Gran^Π　 历史的切分粒度

以上全部事前冻结。

T\_Π 一项不能省略。首次性系于其上：τ 之为首次，是相对该点集而言。若其未事前冻结，则看到结果之后增一点或删一点，即可移动「首次」之所在——增一个更早的命中点则首次不在 τ，删一个不便的点则原本不是首次的变成了首次。

### 3.3 事后调整的禁止

不得在看见结果之后改历史的切分粒度；不得改来源候选域；不得改可删除项；不得改 Law judge；不得增删评价点集 T\_Π 之中的点；不得把有利的结果重新命名为来源。

凡是有一项在结果之后调整的，所得不入本篇的承认之列。其理与上游冻结评价协议同：看到结果再挑读法，则结论由挑选者给出。

### 3.4 空历史控制与来源域的完整性

　　H\_∅

为空历史控制：不留任何历史事件，而 Π\_src 的其余申报项如故。

　　SourceDomainIncomplete^Π( χ\_L, τ ) ∈ { 1, 0, ⊥ }

其义为：当前协议所声明的历史候选域是否不足以承担本次的首次成律。

　　1　若 SuffGenesis^Π( H\_∅ ) = 1，即不留任何历史事件而仍得首次成律  
　　0　若 SuffGenesis^Π( H\_∅ ) = 0  
　　⊥　若 SuffGenesis^Π( H\_∅ ) = ⊥，或 H\_∅ 不入其求值域

此量是来源协议的一项判定状态，非来源本身。取 1 时所申报者是所划的域有漏，不是来源不存在；二者的区别见定理三。

### 3.5 首次成律事件

　　Genesis^Π\_τ( χ\_L ) ∈ { 1, 0, ⊥ }

评价只在冻结的评价点集 T\_Π 之上进行，不对连续时间作全称量化。

　　Genesis^Π\_τ = 1　　若 Judge\_τ = 1 且 ∀ t ∈ T\_Π, t \< τ : Judge\_t = 0

　　Genesis^Π\_τ = 0　　若 Judge\_τ = 0，或 ∃ t ∈ T\_Π, t \< τ : Judge\_t = 1

　　Genesis^Π\_τ = ⊥　　其余情形

其余的有两项：当前的 Judge\_τ = ⊥；当前为 1 而此前至少有一个 ⊥ 且无更早的 1。

取值的优先也必须说准：更早的 1 足以否定首次，故纵有别的先前点为 ⊥，仍判 0。

第三值不能省略。若某一先前评价点的正式资格不可判，则不能说此前全为 0——不可判与判为零是两件事，压成一值即把前者当作后者。

其中的 Law = 1 必须沿既有封版体系取得。不得以「结构已经很像律」「沟已经很深」「已有 bearer」代替正式资格。

不得把 1 → 0 → 1 称作本篇所研究的首次成律。若只问同一冻结候选的再次资格取得，可另立再成律来源的任务；若进一步称其为「原有 Law 的恢复」，方必须先解决身份判据。见 1.3。

第四节

默认来源的排除

本节列八个失败世界，逐一排除八种默认的来源写法。各世界都在协议冻结之下构造。

### 4.1 W-S1　终态倒推

构造两段不同的历史

　　H\_A ≠ H\_B

而二者都得

　　Law\_τ = 1

因此

　　Law\_τ = 1　⇏　𝔖^Π\_src

即相同的终态资格值不足以决定来源解族。此处不用未经定义的裸 Source，其正式形态见定理一。

### 4.2 W-S2　时间先后

设 h ≺ τ，即 h 发生在首次命中之前。

先后不足以推出承担：

　　h ≺ τ　⇏　PossibleSourceCarrier^Π( h ) = 1

其中 h 为按 Gran^Π 冻结的 occurrence。窗内在 τ 之前发生的事很多，其中多数与本次成律无涉。

### 4.3 W-S3　同步或相关

设 Corr( h, Genesis ) 成立——h 与首次成律在统计上共现、同步变化，或由 h 可准确预测 Genesis。

相关不足以推出承担：

　　Corr( h, Genesis )　⇏　PossibleSourceCarrier^Π( h ) = 1

不得以统计共现、同步变化或预测准确率代替来源。法篇于源式所禁止的情形之一，正是以相关代替原因。

### 4.4 W-S4　终态的形式见证

设 R\_τ ∈ 𝒮( F\_τ, L, I )。

它只承担终态的正式资格见证，不得直接写作历史来源。

R\_τ 是终态资格成立的一份形式见证：它回答终态的资格凭什么取得正式的认证，不回答该资格在历史之中如何形成。

### 4.5 W-S5　终态的物理承载

设 q\_τ = PathMap( L, R\_τ )。

它是终态的承载，不等于其形成的历史。第八篇已把承载与身份分层，此处同理：终态落在哪里，不说明它怎么长出来。

### 4.6 W-S6　非法删除

若删去某事件 e 而得的 H′ 有

　　Replayable^Π( H′ ) = 0

则只说明该反事实本身非法，不能推出

　　NecessarySourceCarrier^Π( e ) = 1

不能执行的删除，不证明来源的必要性。这就是 1.4 其四在操作层的形态，其在最小性一层的形态见 8.1 与 8.3。

### 4.7 W-S7　背景使能

电源、宿主、全局的运行条件，缺了它则整个系统无从工作。

此只说明该条件对本次 Genesis 具有反事实的必要性，而反事实必要本身不足以成为来源。

不得以「是否只作用于这一条律」为二者的区别。一个局部门控、某个特定的传感器、某条输入通道，完全可以只使能某一候选而仍非其形成来源。

其是否为来源，仍必须另证其实际进入生成链，并在协议相对的最小充分历史之中承担。因此背景使能与形成来源的区别，不在作用范围的广狭，而在是否同时取得实际生成链与反事实承担两项资格。此与 1.4 其四一致。

### 4.8 W-S8　外部安装冒充场内生成

直接修改权重、沟槽、沉积值、形式见证或终态结构，使正式的 judge 最终 PASS。

此时确可得 Law = 1，而不得据此写 FieldBorn = 1。

所排除的是这一步冒充，非外部安装本身。外部安装可以是一次首次成律的实际来源——它毕竟是一次真实的资格发生，其发生链可查——但它不是场内生成。正式的资格与发生的模式必须分开：资格由 Judge^Π 判，模式由生成链的分支判。第九节据此把两种链并立。

这八项既已排除，来源必须另有所据。以下四节刻画其发生过程。

第五节

历史的表示

### 5.1 历史是有序的有限对象

实际历史必须表示为有序对象

　　H\_obs = ( e\_1, e\_2, …, e\_n )，　\| H\_obs \| = n \< ∞

不得表示为无序集合。以集合表示的，本篇不承认其为历史。

有限性是协议条件，非技术上的便利。

而 occurrence 的有限不足以尽它。6.1 所许的操作含删除、Mask、抑制各项；若 Mask 或抑制可取连续的强度，则纵使只有一个 occurrence，也可有

　　H\_1 ≻\_Π H\_2 ≻\_Π H\_3 ≻\_Π …

每一项都充分而无一项最小。因此所需的不止历史的有限，而是削减域的有限。

记冻结的削减域

　　ℛ\_Π( H\_obs ) = { H′ \| H′ ⪯\_Π H\_obs }

本篇 v1.0 要求

　　\| H\_obs \| = n \< ∞　且　\| ℛ\_Π( H\_obs ) \| \< ∞

即：历史的 occurrence 有限，且 Π\_src 所许的可判削减方案构成一个有限的离散域。连续强度的 Mask、无限层级的抑制，或其它可产生无限严格下降链的操作，必须先离散冻结才得以进入本篇。

这一项能否查验，系于 6.1 对 Ops^Π 的逐项冻结：各操作既已逐项列定，其作用域限于 H 之中已有的 occurrence，而 occurrence 有限，则有限长的操作序列所生的削减方案也可数而有限。若 Ops^Π 未逐项冻结，或其中有一项取连续的参数，则 ℛ\_Π 的有限性无从核验。

二者既立，则协议本身不生无限的严格下降链。其时解族若空，原因不在无极小元。连续或无界的历史，另必须先按 Gran^Π 切分为有限个事件 occurrence。

### 5.2 至少必须保留的

每个历史 occurrence 至少必须保留其时间次序、次数、持续区间、实际发生的内容，及其所作用的对象。这是共同字段。

其后按所属分支另有所需：

　　属场内形成一支的　　另必须保留 execution、trace、sedimentation 及三者的连接  
　　属外部安装一支的　　另必须保留外部编辑事件、编辑目标、编辑前后的状态及相应的 judge 读数

不存在的字段不得为满足格式而虚造。

两支共用同一个有序的历史框架，而不强令后者伪装成沉积历史。若以场内一支的字段为一切历史的必备，则外部安装事件连合法的历史都进不来，而 7.3 又认其为合法的生成分支——二处即相撞。

### 5.3 两条禁令

不得把一次刺激与百次重复写作同一个元素——次数是沉积的实际变量，抹去次数即抹去形成的分量。

不得把 e\_1 → e\_2 与 e\_2 → e\_1 当作同一个来源候选——顺序改变则实际的执行链改变，所沉积的也随之不同。

### 5.4 切分粒度

历史的切分由 Gran^Π 事前冻结。粒度既定，事件的原子即定；此后不得为求某一结论而改粒度。

第六节

历史的削减与合法重放

### 6.1 协议相对的削减

　　H′ ⪯\_Π H

其成立必须正反两面都具备。

正面：存在一个有限的操作序列

　　ω = ( ω\_1, …, ω\_k )，　ω\_i ∈ Ops^Π

施加于 H 而得 H′。Ops^Π 的每一项必须事前冻结，且必须满足三条：其一，只作用于 H 之中已有的 occurrence，不及其外；其二，其效果为去除该 occurrence，或削弱其作用而不改其时位；其三，其施行与否及其结果可由实现环境读出。

不合此三条的不入 Ops^Π。凡是所许的操作未逐项冻结的，其所生的削减不得据以判最小——最小性系于对一切削减的量化，而量化的域不定则量化无所施。

反面：所得的 H′ 必须满足

　　不改 X\_0  
　　不改 χ\_L  
　　不改合法动力 Dyn^Π  
　　不改 Law judge  
　　不增加新事件  
　　不改变剩余事件的原顺序  
　　不偷补最终状态

正面一款与反面七条，缺一则该削减不合法。

二面缺一不可。只有反面，则七条都不违反的未必是一次削减——既非删也非 Mask 的改动可以一条都不犯；只有正面，则操作虽合法而其所改可溢出历史之外。

严格削减记为

　　H′ ≺\_Π H

### 6.2 最小相对于此偏序

此后一切「最小」都相对 ⪯\_Π 而言。不得以普通的集合包含代替——集合包含不管顺序，而顺序正是 5.3 所立的历史分量。

### 6.3 合法重放

　　Replayable^Π( H ) ∈ { 1, 0, ⊥ }

　　1　重放符合冻结协议  
　　0　只能靠改动力、改 judge、改初态、加入未申报的操作才能进行  
　　⊥　当前无从确定其合法性

### 6.4 与 Genesis 的区别

　　Replayable^Π = 0　　不是　　Genesis = 0

前者说的是这个反事实本身非法，后者说的是合法反事实之中的失败结果。

混此二者，则一切不便执行的删除都可被读作来源必要。4.6 所排除的正是这一点。

第七节

来源充分性与实际形成链

### 7.1 来源充分性

　　SuffGenesis^Π( H\_s ; χ\_L ) ∈ { 1, 0, ⊥ }

只在 Replayable^Π( H\_s ) = 1 时进入求值。

其成立不是「最后 Law = 1」这么弱，而必须再次出现一个合法的首次资格发生：存在 τ\_s，使

　　Judge\_t( χ\_L ) = 0　　对一切 t ∈ T\_Π 且 t \< τ\_s  
　　Judge\_{τ\_s}( χ\_L ) = 1

三值如下：

　　1　合法重放之中确有此首次 0 → 1  
　　0　合法重放已毕而明确无此首次 0 → 1  
　　⊥　合法重放成立而 Law 的读数不足以判其首次性

Replayable = 0 时不令 SuffGenesis = 0，而视为不入求值域。否则非法的反事实会混进失败的反事实——前者是这个反事实做不得，后者是做了而不成。二层的 ⊥ 与 0 不得互代。

### 7.2 措辞的限定

不得写作「重放出同一条 Law」。

只能写：重放使同一冻结候选重新取得正式的 Law 资格。

二者的区别即 1.4 其一。重放所得的是候选资格的再次成立，而两次之间是否同一条律，本篇不判。

### 7.3 实际生成链

来源不能只有反事实的充分性。另必须

　　ActualGenesisLink^Π( H\_s ; χ\_L, τ )

它要求该段历史真沿实际已发生的生成链进入本次的终态资格。此链有两个合法分支：

　　ActualGenesisLink　=　FieldFormationLink　∨₃　ExternalInstallLink

其一，场内形成：

　　FieldFormationLink^Π  
　　　Execution → Trace → Sedimentation → Formation → R ∈ 𝒮 → Law = 1

其二，外部安装：

　　ExternalInstallLink^Π  
　　　一项明确申报的外部编辑事件真实进入资格的改变链，使正式的 judge 自 0 转 1

两分支并立的缘由在 4.8：外部安装是一次真实的资格发生，其发生链可查，故不可因其非场内生成而使它无来源可言。若只认第一支，则凡是由外部编辑而首次成律的，按本篇永无来源——而 1.1 所问的正含此类。

两支各自的取值依同一规则。对任一生成链候选 G：

　　G^Π( H\_s ; χ\_L, τ ) = 1　当该支所需的实际事件及其进入资格改变的连接，都经正式读取而成立

　　G^Π = 0　当该支所需的接口都可读，而至少一项必要的连接明确不成立

　　G^Π = ⊥　当判定该支所必需的接口或连接有不可读、不可审，或证据不足的

两支所需的接口分列如下：

　　FieldFormationLink　　execution、trace、sedimentation、formation、形式见证、Law 资格  
　　ExternalInstallLink　 所申报的编辑 occurrence、目标状态、编辑前后的状态、前后的正式 judge，及该编辑进入资格改变的连接

∨₃ 为三值的析取：两支都是 0 则为 0；有一支为 1 则为 1；无 1 而有 ⊥ 则为 ⊥。

### 7.4 此链所排除的

纯相关；同步伴生；终态的 proxy；旁路的辅助；无实际沉积贡献的事件。

这些都可在反事实上显得要紧，而并未真在链上。

### 7.5 不得以反事实单独代它

不得以「删掉它结果会不同」单独代替实际形成链。

删去它而果异，可以出于多种缘故——它是使能条件，它与真正的来源共变，它的删除连带扰动了别处。这些都不说明它在链上。

第八节

最小充分历史

### 8.1 定义

　　MinSuff^Π( H\_s ; χ\_L ) ∈ { 1, 0, ⊥ }

先处理候选自身：

　　MinSuff = 0　若 Replayable( H\_s ) = 1 且 SuffGenesis( H\_s ) = 0

　　MinSuff = ⊥　若 Replayable( H\_s ) ∈ { 0, ⊥ }，或 Replayable( H\_s ) = 1 且 SuffGenesis( H\_s ) = ⊥

候选自身的 Replayable = 0 入 ⊥ 而不入 0。其不能在协议之下合法重放，并不证明它不是最小充分的来源——它连充分与否都未经合法的检验。

此与削减层同理，也必须同判：

　　不能重放　≠　重放而不充分

同一个 Replayable = 0，不得在削减之上判 ⊥ 而在候选自身之上判 0。一个语义在两处被赋两种认识论的强度，即是不一致。

只有候选自身

　　Replayable( H\_s ) = 1，　SuffGenesis( H\_s ; χ\_L ) = 1

之后，才检其严格削减。此时对一切 H′ ≺\_Π H\_s 量化：

　　MinSuff = 0　若存在 H′ ≺\_Π H\_s 使 Replayable( H′ ) = 1 且 SuffGenesis( H′ ) = 1

　　　　即找到了一个仍然充分的合法真削减。这是确定的反例，优先于一切 ⊥。

　　MinSuff = 1　若无上述反例，且对每一个 H′ ≺\_Π H\_s 都有  
　　　　　　　　Replayable( H′ ) = 1　且　SuffGenesis( H′ ) = 0

　　　　即每一个严格削减都真经合法的检验而失败。

　　MinSuff = ⊥　若无上述反例，而至少存在一个 H′ 使  
　　　　　　　　Replayable( H′ ) = 0，或 Replayable( H′ ) = ⊥，  
　　　　　　　　或 Replayable( H′ ) = 1 且 SuffGenesis( H′ ) = ⊥

其中 Replayable( H′ ) = 0 一项必须入 ⊥ 而不得入 1。此点是本节的承重处：若容其入 1，则「一切削减皆不可合法执行」反倒判该历史为最小，那正是 8.5 所禁的「不能删，所以它必要」。删不得不给最小性；只有真删得而真不成律的，才支持最小性。

### 8.2 量化于一切严格削减，不得先称其承重

上文对一切 H′ ≺\_Π H\_s 量化，不得写作「对承重的严格削减」。

正以削减的结果判谁承重，而先称其为承重的，即循环。承重是量化之后所得，非量化之前所设。

### 8.3 确定的反例优先于不可判

取值的优先必须写死：一经找到一个合法而仍充分的真削减，即知其不最小，判 0；不因别的削减不能执行或不可判而返 ⊥。

反之若无此反例，则但有一处不能执行或不可判，即判 ⊥，不得径判 1。

　　不能删　≠　删了不成

前者是操作的限制，后者是来源的承担。二者在本节分居 ⊥ 与 0，不得互换。

### 8.4 三值不得压成二值

⊥ 一值不能省略。省去它则「删不掉」会被读作「删不得」，而二者迥异：前者是操作的限制，后者是来源的承担。

### 8.5 特禁

禁止写「不能删，所以它必要」。

不可执行的删除不证明来源的必要性。此与 4.6、6.4 同出一理，而在最小性这一层最易犯：凡是遇一处削减不能执行，便记其为最小充分之所系——那是把 ⊥ 当作 1。

第九节

来源核心与双链纪律

### 9.1 核心定义

　　LawGenesisSource^Π( H\_s ; χ\_L, τ ) = 1

当且仅当三项都成立：

　　Genesis^Π\_τ( χ\_L ) = 1  
　　ActualGenesisLink^Π( H\_s ; χ\_L, τ ) = 1  
　　MinSuff^Π( H\_s ; χ\_L ) = 1

三者各守一事：首次由 Genesis 守；本次真实的发生链由 ActualGenesisLink 守；非旁观也非冗余的历史由 MinSuff 守。

各量都是三值，其总表如下：

　　Genesis^Π\_τ( χ\_L ) ∈ { 1, 0, ⊥ }　　　　　3.4  
　　Replayable^Π( H ) ∈ { 1, 0, ⊥ }　　　　　6.3  
　　SuffGenesis^Π( H ; χ\_L ) ∈ { 1, 0, ⊥ }　　7.1  
　　ActualGenesisLink^Π ∈ { 1, 0, ⊥ }　　　　7.3  
　　MinSuff^Π( H ; χ\_L ) ∈ { 1, 0, ⊥ }　　　 8.1

三项之中有一为 0，则 LawGenesisSource 为 0；无 0 而有 ⊥，则为 ⊥。

### 9.2 双链

　　LawGenesisSource　=　ActualGenesis　∩　CounterfactualBearing

实际参加了形成而在反事实上非承重的，不够——它在链上，而删去它无妨，则它不是这一次成律所系。

在反事实上足够而并非本次实际的发生链的，也不够——删去它则不成，而本次成律并未经它，则它至多是另一条可能的路。

二者的交才是来源。这是本篇最要紧的一条纪律。

### 9.3 两侧各自的失败形态

只有实际生成而无反事实承重：见 8.1 的 MinSuff = 0——存在合法的严格削减而仍充分，则该段历史之中有可删的。

只有反事实承重而无实际生成：见 7.4 与 7.5——使能条件、共变的、连带扰动的，都可使删的结果异而并未在链上。

### 9.4 生成模式是链的读数

　　FieldBorn^Π( χ\_L, τ ) = 1　当 ActualGenesisLink 经 FieldFormationLink 一支成立  
　　ExternalInstall^Π( χ\_L, τ ) = 1　当其经 ExternalInstallLink 一支成立

二者不是来源之外的孤立标签，而是该链取了哪一支的读数。因此一次首次成律可以有来源而非场内生成——其来源即那一项申报的外部编辑事件。

二者不预设互斥：两支都成立时，两项都是 1，见 12.1。

第十节

来源定理

定理一　终态来源不足

　　Law\_τ = 1　⇏　𝔖^Π\_src

即：不存在仅由终态的资格值决定来源解族的函数。

证明。取 4.1 的失败世界，并补其至解族一层。

4.1 所给的是两段不同的历史 H\_A ≠ H\_B，二者都得 Law\_τ = 1。今更要求二者于 τ 的冻结终态候选数据也相同——按 3.2，该数据由协议所定的字段读得，两段不同的历史可落到相同的读数。

二者的实际生成链不同。按 7.3，生成链依实际已发生的而定，非依终态而定；因此 ActualGenesisLink 在两世界之上各认其自身的那一段。经 6.1 的合法削减与 6.3 的重放，按 9.1 的三项各自认证，所得为

　　𝔖^Π\_src( W\_A )　≠　𝔖^Π\_src( W\_B )

这一步是 4.1 所未走的：该节只到两段历史的差异，而此处更需要两个解族的差异。

设有一函数仅由 Law\_τ = 1 决定来源解族。它在这两个世界上的输入相同——同为 Law\_τ = 1，且终态候选数据也同——而输出不同，故非函数。因此无此函数。∎

此证不依赖来源的唯一性。第十一节已许解族多元，故不得以「同一终态只应对应一个来源」为据——那正是被许可的多解所否定的。所证只是：终态给出资格，不给出来源。

定理二　来源双链

若 LawGenesisSource^Π( H\_s ; χ\_L, τ ) = 1，则

　　Genesis^Π\_τ( χ\_L ) = 1  
　　ActualGenesisLink^Π( H\_s ) = 1  
　　MinSuff^Π( H\_s ) = 1

三项一项也不能删。

证明。三项由 9.1 直接给出。其不可删，各有失败形态：删 Genesis，则所问的不是一次首次成律，本篇的对象不成立；删 ActualGenesisLink，则 7.4 所列这些都可入选，而它们并未在链上；删 MinSuff，则 H\_s 之中可含任意多的无关历史，而「来源」便无从收束——凡是包含真来源的更长历史都可自称来源。∎

定理三　来源域泄漏

若

　　SuffGenesis^Π( H\_∅ ) = 1

则

　　SourceDomainIncomplete^Π = 1

且当前协议之下不得输出完整的来源结论。

证明。由 3.4，H\_∅ 为空历史控制，而 SuffGenesis^Π( H\_∅ ) = 1 时该量取 1。其原因在于：不留任何历史事件而仍得首次成律，则当前协议所声明的历史候选域不是来源的完整承担域——承担者在该域之外。

其所在不可遽断。遗漏可能位于冻结背景 B^Π；可能在初态 X\_0 之中已藏有足够的结构；可能在 Dyn^Π 的自发演化之中有未被切成历史事件的承重过程；可能 Gran^Π 过粗而把承担者并入了别的原子；也可能来源候选域本身漏列了事件。五者都有可能，本定理不判其一。

此时不得写 Source = ∅。空的来源与「来源不在所划的域内」是两回事：前者说没有东西承担，后者说承担者被划到了考察之外。

也不另造一个总来源变量以承此情形。本篇的正式对象只有 LawGenesisSource 与 𝔖^Π\_src 二者，此处不得突然引入未经定义的量。

因此当前协议的来源判定为未闭合：已有的 𝔖^Π\_src 不得作为完整的来源解族输出。必须重审 X\_0、H^Π、B^Π、Dyn^Π、Gran^Π 五者的划分，另建来源协议。在原协议之下不得继续声称来源已判明。∎

定理四　多解保留

若

　　\| 𝔖^Π\_src \| \> 1

则来源的输出必须保留整个认证解族，不得把其中一项升作唯一来源。

证明。由 11.1 的定义，𝔖^Π\_src 中的每一项都满足 ActualGenesisLink 与 MinSuff 两项认证。若自其中取一项报作唯一来源，则所报者与其余各项在本篇的判据之下无别——取此而不取彼，其据不在判据之内，只在取舍者的意图。

法篇于源式所禁止的情形之一，正是来源有多解而只报告其中一个。∎

第十一节

来源不能唯一确定处

### 11.1 来源解族

　　𝔖^Π\_src( χ\_L, τ ) = { H\_s \| LawGenesisSource^Π( H\_s ; χ\_L, τ ) = 1 }

不在此处另行展开其三项，以免两处定义日后漂移。三项见 9.1，其中 Genesis 一项也在其内——不带该项则单看定义，首次事件不存在时也可出现形式上的来源候选。

不得预设 \| 𝔖^Π\_src \| = 1。

容许 H\_A ≠ H\_B 而二者都属该族。

### 11.2 两种承担

　　PossibleSourceCarrier^Π( e ) = 1　　当　∃ H\_s ∈ 𝔖^Π\_src : e ∈ H\_s

　　NecessarySourceCarrier^Π( e ) = 1　当且仅当  
　　　　　𝔖^Π\_src ≠ ∅　∧　∀ H\_s ∈ 𝔖^Π\_src : e ∈ H\_s

非空一款不能省略。空族之上的全称在经典逻辑下为真，若不加这一款，则一个来源解也未找到时，反倒人人都是必要承担。

而空族时不判 0，判

　　𝔖^Π\_src = ∅　⇒　NecessarySourceCarrier^Π( e ) = ⊥

原因在空族至少有三种来处：当前协议未取得任何认证的来源；来源域漏项；现有候选都未越过 ⊥。三者不可一概压作「不是必要来源」。

不写「确无来源」。既已有 Genesis = 1，而本篇所研究的又是实际的资格改变历史，此语易引出一种无因的 genesis，而本篇并未证明那样的世界合法，也不否定它——所主张的只到现有协议之下未取得认证来源为止。

另有一种来处即无极小元的情形，已由 5.1 所立的冻结削减域的有限性堵住。

其中 e 为按 Gran^Π 冻结的事件 occurrence，非事件的类型。二者必须分：同型的事件重复百次，是百个 occurrence 而非一个类型；以类型计，则「必要承担」会在类型与个例之间混淆——某类型的事件出现于一切解族之中，不等于其中某一次出现为一切解族所需。

### 11.3 两句不得反用

　　SourceExistence　⇏　UniqueSource  
　　PossibleSourceCarrier　⇏　NecessarySourceCarrier

唯一来源只在 \| 𝔖^Π\_src \| = 1 时才得以申报。

### 11.4 不能唯一确定的，显式列出

按源式的完成条件，来源不能唯一确定之处必须显式列出。本篇所列如下。

其一，解族的基数。不主张 \| 𝔖^Π\_src \| = 1，也不给出使其为一的条件。

其二，协议相对性。𝔖^Π\_src 系于 Π\_src 的九项冻结，评价点集 T\_Π 也在其内；换一份协议，所得解族未必相同。不主张来源在任意协议之下一致。

其三，⊥ 的分布。凡是取 ⊥ 的，其是否属解族未定。该值出现的范围由四者共同决定：重放的合法性、正式资格的可判性、实际生成链的可审查性，以及协议的粒度。其边界未给。

其四，背景与历史的界线。定理三所示的，是该界划错时来源无从判明；而何为正确的划法，此处不给判准。

第十二节

生成模式

### 12.1 两种模式

　　FieldBorn^Π( χ\_L, τ ) = 1　　当存在成立的 FieldFormationLink  
　　ExternalInstall^Π( χ\_L, τ ) = 1　当存在成立的 ExternalInstallLink，即一条事前申报且可审查、而不属场内沉积形成动力的外部编辑链

不用「主要由」一类说法。主要与否无判据可依——多少算主要，最大的贡献，必要的作用，抑或充分的作用，都无定。二者的取值即其对应分支的读数，见 9.4。

二者在本篇 v1.0 所定义的 ActualGenesisLink 之内穷尽——该链既由两支的三值析取所定，则其为 1 时至少一支为 1。而本篇不据此主张二者穷尽一切可能的 Law genesis mode：形式定义之内的穷尽，不是本体上的穷尽。

二者不预设互斥。一次 genesis 之中完全可以既有正常的沉积，又有中途对某个承重状态的外部编辑，两条实际链都参与；其时两项都是 1。本篇不另裁「主要是哪一支」——若无另证 FieldBorn ⊕ ExternalInstall，则不得把二者写成二选一的模式。

申报与可审查二者不能省略。未申报的外部编辑不在此列，归 K-SRC2——若二者同用一名，则合法的外部来源与偷进来的外部变量会被一词覆盖。

### 12.2 二者不改资格

正式的 Law 资格不因模式而异。正确的关系为：

　　FieldBorn = 1　⇒　Law = 1　（在目标终点）

而

　　Law = 1　⇏　FieldBorn = 1

ExternalInstall 也可最终正式取得 Law = 1。

### 12.3 措辞的禁止

不得写「安装出来的 Law 不是真 Law」。

本篇只分它如何取得资格，不分它是不是律。资格由 Judge^Π 判，模式由来源协议判，二者不相代。

第十四节

击穿

按法篇第四编第四章，源式的击穿方式为：所申报的源条件全部成立而目标结构仍不生成；或证明生成链依赖未申报的外部条件；或经干预证明所指的过程并不承担所宣称的生成作用。另有一条：只在本式宣称必要来源或唯一来源之时，目标结构在该过程缺席而仍发生，方构成击穿。

据此列五条。

K-SRC1　来源证书与正式判定冲突。若系统输出 LawGenesisSource^Π( H\_s ) = 1 或 MinSuff^Π( H\_s ) = 1，而按同一冻结协议实际重放 H\_s 之后，正式的 Law judge 并未取得合法的首次 0 → 1，则该来源证书失效，本篇的实现或形式映射被击穿。

　　这一条必须如此写才可以执行。若写作「来源条件全备而合法重放不能使之成律」，则不成其为击穿：MinSuff = 1 的定义之中已含 SuffGenesis = 1，故那一情形在定义之内即不可能，所暴露的是证书与判定的不一致，非理论的反例。

K-SRC2　依赖未申报者。所谓的实际形成链依赖一个未申报的外部输入、编辑或背景承担。

K-SRC3　干预证其不承担。经干预证实所申报的 H\_s 并不承担所宣称的形成链。

K-SRC4　必要承担的反例。若正文对某历史原子宣称 NecessarySourceCarrier = 1，则找到一个合法的来源解不含该原子，即击穿该宣称。

K-SRC5　唯一来源的反例。若正文宣称唯一来源，则找到第二个认证的来源解，即击穿该宣称。

不是击穿的：来源有多解——11.3 已申明本篇不主张唯一；某削减不可执行而得 ⊥——8.1 已申报该值，非结论失败；来源域划分不完整而得 SourceDomainIncomplete^Π = 1——定理三即为此而设，其输出正是该情形的正确输出，已有的 𝔖^Π\_src 其时不得作为完整的来源解族输出；三项前件之一不成立——13.2 已申报的条件化，非结论失败。

第十五节

接口

### 15.1 向上

《律组式》与《律判定式》（封版）——正式的 Law 资格。各篇的前件随之传导。

《律动力数理式》（封版）——运行段、实际执行与贡献归属的形式纪律。7.3 的形成链本于此。

《律动力运行基底构造式》（封版）——真实沉积场的运行与正式判定接口。

《律身份配对区分式》（封版）——候选声明的对应与 root 的对应都不得冒充 SameLaw。1.4 其一本于此。

### 15.2 向下

LawGenesisSource 的双链——下游可用作「来源须兼实际形成与反事实承重」的依据。引用时必须连同 13.1 的三项前件与 13.2 的 Conditional 状态一并承继。

多解的保留——定理四随结论传导。下游不得自解族中取一项报作唯一来源。

⊥ 与未闭合的读法——MinSuff = ⊥ 与 SourceDomainIncomplete = 1 都是申报值，非失败值；二者都不得读作来源不存在。下游也不得把 ⊥ 读作 0。

模式与资格的区别——12.2 随结论传导。下游不得据 ExternalInstall 推出资格不成立。

来源与身份的区别——1.4 四句随结论传导。下游不得据本篇取得任何关于两份 occurrence 是否同一的断言。

### 15.3 篇际边界

《律交互一般式》——一条律如何改变另一条律。届时可用本篇区分「当前的作用」与「历史的形成来源」。

《律交互数理式》——承接来源与贡献的绑定。

《律生态稳定式》——承接多律环境中的新生事件，而不得把 source 当作 identity。

身份各篇——复制、迁移、恢复、替换、跨载体重现，以及 1 → 0 → 1 的再次成律。这些必须先有闭合的 Law identity 性质，而该性质至今未立，见 1.3。
