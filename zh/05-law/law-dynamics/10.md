自显论 · 律篇 · 律动力组式第十 v1.0

# 律交互一般式

第一节

总命题、工作域与承继边界

### 1.1 总命题

承认一条已成的律对另一条已成的律的某次动力事件确实发生了直接的律际交互，则必有某种最低结构使这一承认成立。

对象为三者：source-role 的已成 Law 引用 L\_S，target-role 的已成 Law 引用 L\_T，以及目标的 LawDyn 事件 e\_T。

必须解释或维持的成立事实：L\_S 对 L\_T 的这一次动力事件发生了直接的律际交互。

本式主张的逻辑强度只到必要向。

### 1.2 问题驱动

我们要在本篇，在不断追问下找到证明应当走向何处，并推导律际交互的一般式。

证明路径不预先铺设。下一步只能由上一轮的未闭合处生成。

### 1.3 待建立总式的预告

本篇所要建立的，其形状预告如下：

　　LawInteraction^η\_F( L\_S → L\_T ; e\_T )　⇒　LawInteractionBear^η\_F( L\_S, L\_T ; e\_T )

其上下标之所指：F 为所考察的沉积场，η 为其上一条合法的运行轨迹。二者按上游承继，本篇不另定义；所申报的交互即落在该场该轨之上的一次事件级关系。

这是待证的对象，不是已成的对象。预告只为使读者知其去向，不得在后文的任何一轮之中充作前提——凡是某一层未经其失败世界逼出的，在该轮之前不得取用。

### 1.4 式种与版本定位

一般式，主式，独立成篇，首版。

按法篇第一第三编第一章，一般式的用途为证明对象成立的最小结构，形式为 O ⇒ N；其进入条件为对象已有清晰界定、成立可陈述为可审查的事实、最小结构尚未得到已成立的无条件结论。

本篇的进入条件按此核验：两端的 Law 资格与目标的 LawDyn 事件都由上游给出，是可审查的事实；而「这一次交互最低须有什么」，上游各篇都未给出。

### 1.5 工作域

本篇只研究成对的、事件级的、直接的 LawDyn 交互。

目标事件域固定为

　　Θ\_LD = { Start, Continue, Stop, Rise, Fall, Migration }

六者一个不增，一个不减。不得扩为「任意的 Law 侧变化」；Continue 尤不得删，原因见第十节。

不研究：多级的因果祖先；交互图；长期的反馈环;生态稳定；多律网络；SameLaw；律的首次来源；Principle 的充分定义。

### 1.6 四条边界

四句必须先钉住，全篇不得反用。

　　LawInteraction　≠　Coexistence

共存、同步、共位都不构成交互。

　　LawInteraction　≠　Principle

Principle 是一种已成立的律与律之间的关系资格，其成立本身不推出当前发生了一次律际交互。资格与当前之行是两层，理篇已分：已成的理与其当前正在行者不相代。

已成 Principle 的当前的行使，若进一步满足本篇所立的事件级直接交互条件，可成为 LawInteraction 的一种特殊实例；而寻常的 LawInteraction 不要求 CounterHold。

　　LawInteraction　≠　LawSource

来源问的是首次成律，交互问的是另一条已成的律是否进入本律的动力事件。二者所问不同，见第九篇。

　　LawInteraction　≠　LawIdentity

本篇不判两份 occurrence 是否同一。闭合的 Law identity 判据至今未立，见第八篇。

### 1.7 一句话

交互不是两条律都在，也不是两条律挨着；它要求 source 一侧确有一份作为律的职责承担发出，而这一份确实进入了 target 那一次事件的生成。

第二节

上游输入与非退化条件

### 2.1 上游承继

《律组式》与《律判定式》（封版）——正式的 Law 资格。

《律作用一般式》《律作用必然式》（封版）——Rel(L)、职责语义与当前作用的区别。

《律动力一般式》（封版）——LawDyn 六类事件及其合法判定。

《律动力数理式》（封版）——运行段、实际执行与贡献归属的形式纪律，三值不可判的制度。

《律动力运行基底构造式》（封版）——形式见证与物理承载的分层，DynamicRole 与合法 realization 的实际形态。

《律身份配对区分式》（封版）——声明的对应与 root 的对应都不得冒充 SameLaw。

《律源式》（封版）——来源与交互的区别，1.6 其三本于此。

各项按其既有定义承继，本篇不另造第二套。

### 2.2 对象的语义锚

本篇以 LawInteraction 为待析的对象层事实引用，其语义锚有二。

其一，母本已有的关系语义：相扰、相追、使行。这几项在母本之中已有其所指，其语料足证已成持势之间存在可被指称的有向动力关系。

不取「律间的实际进入」为锚。该语已近后文所需逼出的项之一，若入语义锚，则 N 之一项被预埋于 O，而对象的入口复成循环。本篇据母本各义申报 LawInteraction 为待析的对象事实，而不以「实际进入目标事件之生成」界定它。

其二，本组式已冻结的 LawDyn 事件域 Θ\_LD。所申报者是一次落在该域之内的事件之上、由 source-role 指向 target-role 的直接动力交互。

所申报的对象事实只这一句：发生了一次 source-role 对 target-role 的直接动力交互。

此入口不以本篇待逼出的项来界定。凡是后文递推所逼出的项，无论其为本体层抑或绑定纪律，都不得反过来用于界定该入口事实。

　　LawInteraction 是待析的对象，不是 N 的缩写

这一款不能省略。本篇的递推以失败世界推进，而每一轮都必须先能认出该世界之中交互成立与否；若此认取暗用了后文才逼出的两层，则所逼出的不过是先已塞入判据的对象，递推成循环。因此入口必须独立于 N 而先立。

### 2.3 非退化条件

固定两份不同的申报 Law 引用：

　　Ref\_S ≠ Ref\_T

其中 Ref\_S 为 source-role 一侧所申报的 Law 引用，Ref\_T 为 target-role 一侧的。该式只表示二者不用同一份申报引用。

不得写作 SameLaw( L\_S, L\_T ) = 0。闭合的 Law identity 判据尚未建立，此处不得据此断言二者非同一。所据的只是两份引用不同，而引用不同不推出所指不同——第八篇已立这条界线。

全篇凡是简称「另一条律」的，均只指另一份冻结的 Law-role 引用，不附带 SameLaw = 0 的身份断言。此语在自然语言之中易带身份的意味，故在此一并声明。

第三节

两端都是律，是否已够

两端都已成律，是否已足以推出交互？

　　Law( L\_S ) = 1 ∧ Law( L\_T ) = 1　⇒　LawInteraction ？

构造失败世界一：各自独立。

同一场中有 L\_S 与 L\_T 两条律。二者各自在独立的运行链之中成立，各有其承担族，各自通过正式的资格判定。二者甚至同时 Rise——其 Degree 同步上行，读数上共变。

而二者之间没有任何跨端的实际关系：L\_S 的承担未进入 L\_T 的任何运行，L\_T 的事件的生成也未取用 L\_S 的任何贡献。

　　Law( L\_S ) = 1 ∧ Law( L\_T ) = 1，而交互不成立

资格是各端自身的性质：它说这一条确已成律。交互是两端之间的关系：它说这一条进入了那一条的某次事件。前者对每一端各说一次，后者对一对说一次。

同时 Rise 一节尤其要说准：二者的读数共变，可以出于同一个外部条件的推动，而彼此并无往来。共变是两条曲线的形状相似，非一条进入了另一条。

因此所得只有一句：

　　资格共存不足

那么真交互还缺什么？此处尚不得给出任何名目，所得的只是一个缺口：缺的是跨端的实际关系。问题随之推进——纵使真有物理上的进入，是否已够？

第四节

有实际的物理进入，仍然不足

于是加入一项：source 一侧确有一份实际发生，且该发生确实进入了 target 所在的物理机制——不是共存，不是共变，是真有东西过去了。

而该发生只是 L\_S 的承担者的物理副作用：其发热改变了邻近介质的阻抗，其占用挤压了共用通道的带宽，其电流在共地上引起了偏移。

这些都与 Rel(L\_S) 无关，与 L\_S 的 DynamicRole 无关，与其合法的 realization 无关。承担者恰好承担着 L\_S，而这一份发生并不是它作为 L\_S 的职责承担所发。

　　PhysicalContributionFromBearer( L\_S )　⇏　LawInteraction

若此世界之中仍判交互成立，则所交互的已不是律。凡是两条律共用一段介质，其承担者之间必有种种物理上的相互影响；据此都判为律际交互，则交互成了承载之间的事，而上游所立的 Law 恰恰不是承载。

这就是失败世界二：承载的副作用。

至此方可命名第一层：

　　SourceLawContribution

它所回答的是：所考察的这一份实际贡献，是否确属 L\_S 作为律的职责承担。

此层所问的只是「谁发出的」。它不问该贡献是否抵达，不问其是否进入目标的生成——那是后文另一轮的事，此处若预取，则第六节「第一层成立而贡献未达」的世界便构造不出，逼出第二层的那一步自毁。

此层的内部至少必须查什么，下节分说。

第五节

第一层：SourceLawContribution

### 5.1 三道审查

本层内含三道审查，而不得拆成三个本体层——三者共同回答同一个问题，即该贡献是否确属 L\_S 的职责承担。

其一，源点的资格。

于实际贡献的发出源点 r\_s

　　Law\_{F, r\_s}( L\_S, I\_S ) = 1

资格在源点判。

不要求 source 律在整个传播段之中持续保持 Law = 1，原因见第十一节。

其二，实际的贡献 occurrence。

必须存在一份真实的贡献 occurrence

　　c\_S

它是实际发生过的一份事，不是潜在的能力，不是静态的接线，不是统计上的相关。

能力、接线、相关三者都可在无一事实际发生时成立，而本层所求的是已发生的。

其三，Law 侧的归属。

c\_S 必须能沿三者回读：L\_S 的合法 realization；DynamicRole；Rel(L\_S)。

不得因物理 root 相同、承担者共用、空间共位或同一材料结构，便把物理的副作用记在 L\_S 名下。四者都是承载一层的事实，而归属所问的是职责一层。

### 5.2 三道之间

三者在审查的次序上相承，而非三个独立的本体层：先查源点的资格，才谈得上作为律的承担；次查实际的 occurrence，才有可归属的对象；末查 Law 侧的回读，才定其归属于谁。

这是证明与判定的次序，非生成的时序。不谓现实之中必须先取得资格、再有 occurrence、再有归属——三者本是同一件事的三个侧面，此处只是分三道查它。

缺其一则本层不成立，而三者合起来只立一层。

第六节

第一层仍然不足

第一层既立，再问其是否已够。设 SourceLawContribution( L\_S, c\_S ) = 1——源点有资格，贡献实有其事，且确属 L\_S 的职责承担。

而 c\_S 被旁路：它走了另一条通道，未及 L\_T 的运行；或被屏蔽：中途有闸门将其截住；或被耗散：其量在抵达之前已衰减至不入生成；或径直未进入 L\_T 的任何一次合法的 LawDyn 事件。

　　SourceLawContribution　⇏　LawInteraction

一份确属 L\_S 的贡献确实发出，而未进入目标的任何事件，则这一次交互并未发生。发出与抵达是两件事。这就是失败世界三：贡献未达。

至此方可命名第二层：

　　TargetDynGeneration

它所回答的是：同一份 c\_S 是否实际进入了 L\_T 某次合法 LawDyn 事件的生成机制。

第七节

第二层：TargetDynGeneration

### 7.1 所要求的

　　e\_T ∈ Θ\_LD

且 c\_S 真实进入 e\_T 的实际生成链。

### 7.2 所不要求的

本层不是「目标最终有所不同」。因此不得要求：

　　OutcomeSuccess = 1  
　　ButForNecessity = 1  
　　NetDifference ≠ 0

三者都非必要，原因如下。

冗余的贡献是真交互：两份贡献同至，去其一而目标依旧——按 but-for 的准则，两者都非必要，于是两份真实进入生成的贡献都被判为非交互。而它们确实进入了。

被补偿的贡献是真交互，而这一款必须收紧一层：所申报的目标事件 e\_T 必须实际成立。

若 e\_T 仍实际成立，而另有贡献对 c\_S 作部分的或结果一侧的补偿，则不取消这一次交互——c\_S 推得二，另一项抵去一，目标仍 Rise 一，其交互成立；又或目标本即 Continue，两个相反的贡献共同维持一个读数不变的实际继续，其交互也成立。

而若补偿完全，以致所申报的事件根本未发生——申报者为 Rise 而终成持平，持平不在 Θ\_LD 之内——则不得仍称其为对该次 Rise 的交互。那一次 Rise 未曾发生，无从交互于其上。

这条界线不可越。本篇既已把目标锁于 Θ\_LD 六类，则「实际进入某个内部机制」不得绕过所申报的事件是否成立。

Continue 是真交互：一条律实际维持另一条律的 Continue，目标的读数不变而事件确实发生。按结果的准则，不变即无交互——而 Continue 本是六类事件之一。

### 7.3 直接的含义

direct 不等于物理上的一步直连。

中途容许经过：通道；门;介质；非律的转换节点。这些都不改 c\_S 的 Law 侧贡献身份。

只要 c\_S 的 Law 侧贡献身份未被另一条律接管，且实际的生成链连续可追，则仍属同一次直接的律际交互。

### 7.4 接管则拆段

若中途有另一条律 L\_M 取得了新的 Law 侧贡献 c\_M，则必须拆为两段：

　　L\_S → L\_M　　与　　L\_M → L\_T

而不得由此自动推出 L\_S → L\_T。

因此

　　LawInteraction 不预设传递性

两段各自成立，不合成第三段。是否合成，必须另证，而本篇不证。

第八节

两层分别成立，仍然不足

两层既立，再问二者分别成立是否已够。设第一层于某份贡献上成立：

　　SourceLawContribution( L\_S, c\_a ) = 1

设第二层于另一份贡献上成立：

　　TargetDynGeneration( c\_b ; L\_T, e\_T ) = 1

而

　　c\_a ≠ c\_b

c\_a 确属 L\_S 的职责承担而未达 e\_T；c\_b 确实进入了 e\_T 的生成而不属 L\_S——其或来自别的律，或竟是承载的副作用。

两层各自为真，而「一份 L\_S 的 Law 侧贡献进入了 L\_T 的这一次事件」并不成立。

所缺的不是又一层内容，是两层必须落在同一份贡献之上。若容许两层各取所需，则任何一对「某处有合法贡献」与「某处有生成进入」都可凑成一次交互。这就是失败世界四：拼证。

由此逼出绑定纪律：

　　SameInteractionBind

绑定键为

　　β\_int = ( L\_S, r\_s, c\_S, Z\_ST, L\_T, e\_T )

　　L\_S　　source 律  
　　r\_s　　贡献的发出源点  
　　c\_S　　实际的贡献 occurrence  
　　Z\_ST　自源点至目标事件的实际生成子段  
　　L\_T　　target 律  
　　e\_T　　目标的 LawDyn 事件

它所要求的是：第一层所认出的 c\_S，即第二层实际进入 e\_T 的那一个 c\_S；其间的生成子段为同一段；其所进入的事件为同一次。

它不是第三本体层

此点必须写死。

SameInteractionBind 不增加新的内容，只要求既有的两层由同一份实际贡献 occurrence、同一生成子段与同一目标事件共同见证。删去它，则两层可分持二物而各自为真；设立它，所加者是见证的同一，非对象的又一层。

其与《律作用一般式》的 Binding 同类：那一处也不立第三层，只要求各项落在同一次作用之上。

第九节

递推停止

三者既立，必须再问一次：是否还能构造一个保持三者全真，而仍逼出新的独立必要差异的失败世界？

以下各候选都经审查而未逼出第三本体层：

共存；共时；共位；承载的物理副作用；共同的原因；冗余的原因；多源的贡献；结果的补偿；净差为零；source 律其后退出资格；死后的残留；Continue；Migration；多律接管；拼证。

这些或已被前四轮排除，或落在两层之内，或由绑定纪律挡住。

　　递推停止

不得为求「完整」而另加第三层。一般式所立的是最低结构；凡是加一项而无失败世界逼它，则所加者非必要，而最低即失其为最低。

第十节

各项为何不入必要结构

以下各项都不进入本篇的必要结构，各有原因。

　　LawAct\_{t\_T}( L\_S ) = 1　与　WholeSegmentLawAct( L\_S ) = 1

目标事件发生时 source 律仍在行，非必要；整个传播段持续在行，也非必要。c\_S 既已合法发出并进入生成，其后 L\_S 是否仍在行使不改其归属，见 11.1。

而不得无时间索引地宣称 LawAct( L\_S ) = 1 非必要。于源点 r\_s 之上，第一层所求的——实际的贡献 occurrence，且其属 L\_S 的合法 realization、DynamicRole 与 Rel(L\_S)——已近上游 CurLawBear 的两层条件；上游《律作用必然式》既立 LawAct ⟺ CurLawBear 的双向，则 r\_s 上是否由 SourceLawContribution 进一步推出 LawAct\_{r\_s}( L\_S ) = 1，属承继的后果，非本篇所得取消的对象。

因此本篇所取消的是：LawAct 不作为新增的独立必要层，且不要求目标时刻与全传播段的持续在行；源点上的派生关系不在取消之列。

　　LawDyn( L\_S ) = 1

source 一侧自身是否有动力事件，与其贡献是否进入目标的事件无关。本篇所问的是 target 一侧的事件。

所取消的是不把 source 自身发生 LawDyn 事件立为独立的必要层。上游以 LawDyn 为段级读出而非无索引的状态量，故下游若数理化这一项，必须补其段索引，不得沿用此处的无索引写法。

　　OutcomeSuccess = 1

见 7.2。目标最终有无不同，非交互之所系。

所取消的是事件之后的结果成功，非 e\_T 自身是否发生——后者由第二层明确要求，见 7.1 与 7.2 的收紧一款。不得把「结果不要紧」误读作「事件可以不存在」。

　　ButForNecessity = 1

见 7.2。冗余的贡献会被此准则错杀——两份同至，去其一而目标依旧，则两份都判非必要，而两份都实际进入了生成。

　　NetDifference ≠ 0

不作为本篇统一的必要条件。Continue 可在目标读数净差为零时真实成立，而 source 的贡献仍实际进入其继续执行的机制——以净差为统一的条件，则此类事件尽被排除。

而对 Rise、Fall 各事件，其相应方向的差若由事件的定义本身所要求，则属 e\_T 的上游事件资格，非律际交互另加的一道条件。

此处不援「被补偿者净变为零而确曾进入」为据：若净变确为零而所申报者为 Rise，则该次 Rise 多半未曾发生，其时不得仍称交互，见 7.2。

　　UniqueCause = 1

多源的贡献是常态。要求唯一，则凡是有第二份贡献的都不成交互。

　　InteractionSign ∈ { +, − }

不得把交互压成正负二值。Migration 所示的是 Degree 各维互不可比，无从归入增减；压缩它则该类事件无处安放。

　　WholeSegmentLawHold( L\_S ) = 1

资格在源点判，不要求整个传播段持续保持，原因见 11.1。

　　SpatialSeparation( L\_S, L\_T ) = 1

不要求两份 Law-role 引用在空间上分离。同一段介质可同时出现于两份引用的合法实现之中。

共用承载既不足以推出 SameLaw = 1，也不足以取消本篇 source-role 与 target-role 的工作区分。至于两份 occurrence 在闭合的 Law identity 意义之下究竟是一是二，本篇不判——该判据至今未立，见 2.3。

　　DifferentPhysicalRoot = 1

同理。physical root 的同异只是承载一层的事实：既不推出 SameLaw = 1，也不推出 SameLaw = 0。它不能代替尚未建立的 Law identity 判据。

　　Transitivity = 1

见 7.4。两段各自成立不合成第三段。

第十一节

时间归属

### 11.1 源点锚定

SourceLawContribution 的资格在 r\_s 判。

若 c\_S 已在 L\_S 仍为律时合法发出，并沿连续的实际生成链抵达目标，则 L\_S 其后退出资格，不反向抹掉既有的贡献归属。

　　归属锚于源点

其理在于：归属所记者是发出时的事实，而事实既已发生，不因其后的状态变动而不曾发生。

### 11.2 死后的残留不给无限期的归属

而另一面必须一并写死。

L\_S 退出资格之后，由其旧承担者的残留状态新产生的一项独立效应，若不是原 c\_S 连续生成链的后继，不得继续归于 L\_S。

　　死后的残留不给无限期的归属

二者的区别在于：前者是一份已发出的贡献在途，后者是一份新生的效应；前者的源点在资格之内，后者的源点在资格之外。

若无这一款，则一条律一旦成立，其承担者此后的一切动静都可永归其名下，而那已非交互，是追认。

第十二节

总式与最小性

### 12.1 总式

　　LawInteraction^η\_F( L\_S → L\_T ; e\_T )  
　　　⇒　LawInteractionBear^η\_F( L\_S, L\_T ; e\_T )

其中

　　LawInteractionBear　≡　Bind\_INT( SourceLawContribution, TargetDynGeneration )

其中 Bind\_INT 为绑定算子：它取两层为项，而所成的合取必须由同一份见证承担，即 SameInteractionBind = 1。该算子不引入第三个项，只规定其两项必须落在同一见证之上；其所依据的即第八节所立的绑定键 β\_int。

展开为

　　LawInteractionBear = 1  
　　　⟺　SourceLawContribution = 1 ∧ TargetDynGeneration = 1 ∧ SameInteractionBind = 1

右式有三个成立条件，而只有两个本体层：SameInteractionBind 只规定两层见证的同一，不增第三种本体内容，见第八节末。

绑定必须入 N 的定义，不得另置于外。若 N 只由两层合取而成，则纵 Binding 为零而两层分别为一，N 仍成立——如此则总式所承诺的不含总定理所证的绑定义务，而第十四节以 Binding 为零列为击穿也无所附。今入其定义，二处方合。

### 12.2 总定理

　　定理　设 LawInteraction^η\_F( L\_S → L\_T ; e\_T ) = 1，则  
　　　　　SourceLawContribution = 1，TargetDynGeneration = 1，SameInteractionBind = 1

证明。逐轮读回。

其一。设进入目标一侧的实际贡献只是承担者的副作用，而不属 L\_S 的 Law 侧职责承担。则所成立的至多是承担者对目标的物理影响，非所申报的律对律的交互——而前件所申报者正是后者，二者相违。因此

　　SourceLawContribution = 1

此步取第四节的失败世界。

其二。设该同一份贡献并未实际进入 L\_T 所申报的那一次 LawDyn 事件 e\_T 的生成。则 source 一侧只发出了贡献而未形成本次对目标的交互——发出与抵达是两事，见第六节；而前件所申报者是这一次交互已然发生，二者相违。因此

　　TargetDynGeneration = 1

此步取第六节的失败世界。

其三。设两层所引的非同一份贡献 occurrence，或非同一生成子段，或非同一目标事件。则所存在的是两件分别为真的事实，而非「这一份 L\_S 的贡献进入了这一次 e\_T」——与一次直接交互的单次性相违。因此

　　SameInteractionBind = 1

此步取第八节的失败世界。

三步既立，则

　　LawInteraction^η\_F　⇒　LawInteractionBear^η\_F

其中两层受绑定纪律的约束。∎

### 12.3 不得写作等价

本篇不建立 LawInteraction ⟺ LawInteractionBear。12.1 之中的 ⟺ 仅为 LawInteractionBear 内部的定义展开，非 O 与 N 之间的双向。二者层级不同，不相混。

三者齐备是否足以推出交互，是《律交互必然式》的事；若该篇证其不足，则由其逼出新项，不得由本篇预埋。

### 12.4 三项各自不可删

删 SourceLawContribution：则承担者的非律副作用也被记作律际交互。这就是第四节的失败世界。

删 TargetDynGeneration：则 source 律的合法贡献纵未进入目标的任何事件，也被记作交互。这就是第六节的失败世界。

删 SameInteractionBind：则可由不同的贡献 occurrence 拼证。这就是第八节的失败世界。

三种失败互不替代：第一种错在归属，第二种错在未达，第三种错在见证不同一。

### 12.5 停于此

三者全部保留之后未再逼出新的独立必要差异，故按一般式的递推纪律停止加项，见第九节。

第十四节

击穿

按法篇第三编第一章，一般式的击穿方式为：展示 O 成立而 N 中某一项不成立。

本篇的必要向被击穿，当且仅当在保持工作域与 H 条件的合法世界之中，LawInteraction = 1 而出现下列之一。

其前件的认定必须依 2.2 的语义锚：据母本已有的相扰、相追、使行各义，并本组式所冻结的事件域，认定该世界之中确有一次 source-role 对 target-role 的直接动力交互。不得以本篇所逼出的任何一项作此认定——以它认定，则所击的是同义反复，非本篇的结论。

三条各必须指明其所据：

K-INT1　SourceLawContribution = 0。即交互成立，而进入生成的贡献并不属 L\_S 的职责承担——其源点无资格，或无实际的贡献 occurrence，或其不能沿 L\_S 的合法 realization、DynamicRole 与 Rel(L\_S) 回读。三者有一不备即这一条成立，见 5.1。

K-INT2　TargetDynGeneration = 0。即交互成立，而并无 L\_S 的贡献进入 L\_T 的任何一次合法 LawDyn 事件——或其未抵达，或所申报的 e\_T 并未实际成立，见 7.1 与 7.2。

K-INT3　SameInteractionBind = 0。即交互成立，而两层所认出的非同一份贡献 occurrence、非同一生成子段、非同一目标事件——即绑定键 β\_int 的六项不能由一组见证共同满足，见第八节。

不是击穿的：三者齐备而 LawInteraction = 0——那是充分向的问题，归《律交互必然式》，不得写作本篇的击穿；Continue 之中读数不变——7.2 已申明；两律共用承载——第十节已申明；两段不合成第三段——7.4 已申明；H 条件之一不成立——13.3 已申报的条件化，非结论失败。
