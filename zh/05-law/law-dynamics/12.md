# 律交互必然式

第一节

目的

### 1.1 本篇要回答什么

第十篇已经证明：凡是有直接的律际交互，必有 LawInteractionBear。那是必要向。

本篇反过来问：在共同的工作域与前件成立、而 Bear 的三项已经齐备时，是否还存在一个合法的世界，使这一次交互仍然不成立？

若答案是没有，则 Bear 齐备时交互不能不发生，充分向随之成立。

### 1.2 待证命题

　　LawInteractionBear^η\_F( L\_S, L\_T ; e\_T )　⇒　LawInteraction^η\_F( L\_S → L\_T ; e\_T )

### 1.3 展开只是前件，不是证明

第十篇所冻结的展开为

　　LawInteractionBear = SourceLawContribution ∧ TargetDynGeneration ∧ SameInteractionBind

本篇取它作前件，而不取它作论据。

　　LawInteractionBear = 1　⇏（由定义）　LawInteraction = 1

二者是两个不同的谓词：前者是第十篇所逼出的那套结构，后者是以母本关系语义为锚的对象事实。充分向必须另行证明，其所据为两件事——母本所许的当前交互资格已被那套结构完备覆盖，且不存在独立的取消项。

### 1.4 式种与版本定位

必然式，主式，独立成篇，首版。

按法篇第一第三编第三章，必然式的用途是证明在给定的结构、动力与条件之下什么不能不发生，形式为 C ⇒ R；进入条件是条件组各项皆出自已成立的式或显式申报为假设，结果可陈述为可审查的事实，算子映射所依托的形式系统已经成立。

本篇的进入条件按此核验：条件组各项出自第十篇与工作域的冻结；结果 LawInteraction 的成立事实按第十篇 2.2 的语义锚陈述；所依托的形式系统由第十一篇给出。

### 1.5 工作域

全部承继第十篇：只研究成对的、事件级的、直接的 LawDyn 交互。事件域仍为

　　Θ\_LD = { Start, Continue, Stop, Rise, Fall, Migration }

### 1.6 对象入口的承继

第十篇已定：LawInteraction 的对象入口以母本已有的相扰、相追、使行等关系语义为独立的锚，而不以「source 实际进入 target 事件的生成」界定——后者正是该篇所逼出的第二层，若入锚则必要层被反塞进对象定义，成为循环。

此纪律本篇原样承继。下文凡是称母本语义处，都指该独立的锚，不含本篇或第十篇所逼出的任何结构项。

第二节

核心命题

### 2.1 中心命题

在冻结的工作域与前件之下，第十篇所立的三项一旦齐备，这一次直接的律际交互就不能不成立。

其原因在于有二。其一，母本所许的当前交互资格，已被这三项完备覆盖，无第四项资格在其外。其二，在三项都保持时，母本域中不存在任何独立的取消项，能单独令交互不成立。

二者既立，交互的不成立便无处安放——它既不能缺一项资格，也不能被一项取消项挡住。

### 2.2 两件事必须先说准

其一，资格的覆盖不是定义的等同。三项是第十篇自失败世界逼出的结构，母本资格是对象一侧的语义；本篇要证的是后者落在前者之内，而非二者同名。

其二，取消项之为空不是未曾找到。本篇给出判准，逐类检验，并说明为什么每一候选都不是独立的取消项——或它破坏三项之一，或它在三项保持时并不取消交互。

第四节

母本域的冻结与当前资格的压缩

### 4.1 母本承重语句

本篇所据的母本承重语句冻结为三处原文。

　　M1　夫择也，扰也，必有主事，称之为主动因子  
　　M2　顺势系统若使行逆，则主动因子必自于外，两顺势系统相扰而可互逆  
　　M3　律者，持之势也；理者，破持之势也；此欲持，彼破之，彼破之，则不持，二者之相追，致因应相化不息

三处之外不取。三条限定随之：

其一，M3 的「逆」与「破持」属 Principle 的特化，不入寻常交互的资格。

其二，M2 的「可互逆」是交互的一种可能形态，非其成立的资格。

其三，M3 的「因应相化不息」所述的是化的展开，不得升格为这一次交互成立的资格——结果如何展开是后事，交互是否成立是此刻的事。

### 4.2 原文原子

自三句原文逐字析出承担语义的原子。各原子必须能逐字回指母本，不以上游结构的语言改写；且必须拆至不可再分——一个原子若分承两义，它便不是原子。

　　A\_1　扰　　　　　　　　　M1  
　　A\_2　必有主事　　　　　　M1  
　　A\_3　主动因子　　　　　　M1  
　　A\_4　使行　　　　　　　　M2  
　　A\_5　逆　　　　　　　　　M2  
　　A\_6　主动因子必自于外　　M2  
　　A\_7　两顺势系统　　　　　M2  
　　A\_8　相扰　　　　　　　　M2  
　　A\_9　可互逆　　　　　　　M2  
　　A\_10　二者　　　　　　　 M3  
　　A\_11　相追　　　　　　　 M3  
　　A\_12　致因应相化不息　　 M3

十二原子即三句原文中承担交互语义的全部载体。合取候选另由 5.2 按母本授权检查。

M2 的「使行逆」拆为 A\_4 与 A\_5 两项：前者述一端之行作用到另一端之行，后者述其方向之为逆。M3 的「二者之相追」拆为 A\_10 与 A\_11：前者述所论者为两端而同指一桩，后者述其相寻不舍。不拆则一原子分承两义，与下文的互斥三分不能并立。

### 4.3 语义承担解释

原文原子与其所承担的语义，分作两层写：上一层是原文，本层是解释。解释不改写原文，只说该原文在本篇工作域中承担什么。

　　A\_2、A\_3　支持 Q\_S^母：这一次扰动有一个可归属的作用源  
　　A\_4　　　 支持 Q\_T^母：一端之行作用到另一端之行  
　　A\_8　　　 支持关系之实有：确有一桩及于彼此之事  
　　A\_10　　　支持所论者为同一桩两端之事  
　　A\_1　　　 支持确有一桩扰动发生，其义为 A\_8 所含  
　　A\_5　　　 述方向之为逆，属 Principle 之特化  
　　A\_6　　　 述 Principle 语境中作用源相对于被作用一端的关系外部性，属该语境之特化  
　　A\_9　　　 述可能之形态  
　　A\_11　　　述相寻不舍之延续  
　　A\_12　　　述化之展开

此二层的区分必须守住。母本只说「必有主事」，未说「主者以其所司之职而扰」——后者是 Rel(L) 的语言，属第十篇 SourceLawContribution 对母本的强化，不是母本原子。母本只说「使行」，未说「此次目标事件因 source 而生成」——后者是 TargetDynGeneration 的术语，也属强化。

若以强化后的话写作母本原子，再证 Bear 覆盖它，则所覆盖的本就是用 Bear 的话写的，定理二成为同语反复。

### 4.4 三区

　　𝒜\_INT = 𝒜\_Q ⊔ 𝒜\_D ⊔ 𝒜\_O

　　𝒜\_Q　当前交互资格：直接决定这一次交互此刻成立的原子  
　　𝒜\_D　独立取消候选：前件保持而能单独令 LawInteraction = 0 的  
　　𝒜\_O　其它语义：不进入当前交互资格的，含特化、形态、延续、后果，以及归他篇的

⊔ 为互斥的区分：每一原子恰入一区，无一跨区。

𝒜\_D 专任独立取消的域，不得移作他用。特化、形态、延续与后果一律归 𝒜\_O——若以 𝒜\_D 承载它们，则取消语义便无一个有限域可承，定理三失其所据。

### 4.5 两侧判准

归区的依据有二，其方向不同。

正面　该原子是否直接承担「这一次交互此刻成立」。若是，则入 𝒜\_Q。

反面　取该原子的反面，问交互是否即不成立。此向只授权排除，不授权归入：取反而交互仍成立的，可判其非当前资格；取反而交互不成立的，只说明它未被此向排除，不即证它是当前资格。归入 𝒜\_Q 由正面承担。

形似否决者专查　设前件保持，问该原子能否单独令交互不成立。若其发生必致前件失效，则它不独立，归其本类而非 𝒜\_D。

### 4.6 逐项归区

A\_1　扰。述确有一桩扰动发生。它不辨主客，也不辨及于何方，故不单独成一项资格；而它是当前关系成立的被涵盖语义：

　　Q\_T^母 = 1　⇒　A\_8（相扰）　⇒　A\_1（扰）

相扰者必先有扰。因此归 𝒜\_Q，而为 Q\_T^母 所吸收，不形成独立项。

不得归 𝒜\_O：本篇的对象入口正以相扰、相追、使行为语义锚，见 1.6；若以「无扰而交互仍成立」为说，则与该锚自撞。

A\_2　必有主事。所发的必须有其主事者。取其反则此扰无主，无主则无所谓某方加于某方。归 𝒜\_Q，承担 Q\_S^母。

A\_3　主动因子。这是 A\_2 的「主事」的角色命名与主动性标记。本篇不从「主动」二字另推出「自系统内生」「不受外驱」一类新的本体条件——母本于此处所立的是称名，其内容的展开归理篇。归 𝒜\_Q，与 A\_2 同承 Q\_S^母；它不增加独立的条件。

A\_4　使行。述一端之行作用到另一端之行。取其反则另一端之行未受此作用。归 𝒜\_Q，承担 Q\_T^母。

A\_5　逆。述所使之行其方向为逆。此属 Principle 的特化——寻常的交互不要求 CounterHold，见 1.6 与 4.1 其一。归 𝒜\_O / Principle 特化。

A\_6　主动因子必自于外。此处的「外」是相对于被作用的那一端自顺系统而言的关系外部性，不要求离开整个沉积场，也不要求物理承载分离——封版理篇已立：「自于外」由 P ≠ A 承担，是 Law 身份非同一，不是空间外部性。

而 P ≠ A 是 Principle 工作域中的身份性要求。本篇的工作域只冻结 Ref\_S ≠ Ref\_T，而第十篇已明令：引用不同不推出所指不同，不得据此写 SameLaw( L\_S, L\_T ) = 0——闭合的身份判据至今未立。因此不得以 Ref\_S ≠ Ref\_T 承担 A\_6，那是从引用的异跳到所指的差异。

也不得把 Principle 工作域中由 P ≠ A 承担的身份性要求，推广为寻常 LawInteraction 的资格。

归 𝒜\_O / Principle 特化。它与同句中的 A\_5 同出一源，都属特化，不入寻常交互的当前资格。

A\_7　两顺势系统。述所论者为两端。其同一的含义与 A\_10 同承，而这一项本身只述有两端，为工作域之所设——第十篇所研究的即成对的交互。归 𝒜\_O / 工作域的设定。

A\_8　相扰。述确有一桩及于彼此的事。归 𝒜\_Q，其关系实有的含义并入 Q\_T^母。其「相」字所含的同一的含义，另由 A\_10 承担，这一项不兼它。

A\_9　可互逆。述可能的形态——可互逆的未必已互逆。归 𝒜\_O / 形态。

A\_10　二者。述所论的两端同指一桩，即此加与此受是同一桩事。归 𝒜\_Q，承担 B\_INT^母。

A\_11　相追。述两端相寻不舍，是交互的延续形态——一次而止的也是一次交互。归 𝒜\_O / 延续。

A\_12　致因应相化不息。述化的展开与不息，是交互之后事。归 𝒜\_O / 后果。以它为资格，则参与生成被换作决定结果，见 9.1。

三区的区分如下：

　　𝒜\_Q = { A\_1（为 Q\_T^母 所吸收）, A\_2, A\_3, A\_4, A\_8, A\_10 }  
　　𝒜\_D = ∅　　（候选的检验见第七节）  
　　𝒜\_O = { A\_5, A\_6, A\_7, A\_9, A\_11, A\_12 }

每一原子恰入一区，无一跨区。三区合起来穷尽十二原子。

### 4.7 母本资格的三项

𝒜\_Q 各项归为三项母本资格：

第五节

当前资格的穷尽

### 5.1 两层检查

任何被提出的第四项当前资格，其语义若在 𝓜\_INT 中有根据而又承担当前交互资格，则其载体或为单个原子，或为若干原子的不可约合取。二者分别查：5.1 已由 4.6 的逐项归区完成单原子一层，5.2 按母本授权查合取一层。

单原子一层的结论即 4.6：十二原子各有所归，入 𝒜\_Q 的尽为 Q\_S^母、Q\_T^母 与 B\_INT^母 所收，入 𝒜\_O 的不承担成立。无一原子落在三者之外而仍承担当前资格。

### 5.2 合取候选的母本授权检查

所谓不可约合取，指去掉任一成员，该候选即不再是原先所主张的那个条件。

判准为母本授权。合取本身不是新的母本原子——十二原子已是三句母本中承担交互语义的全部载体，把两个已登记的原子写在一起并不多出一句母本。合取要升格为新的资格，必须母本把该组合关系本身也作为一项语义事实明白承担。

按此，合取候选分三类，三类穷尽一切候选。

第一类　候选含 𝒜\_Q 成员。该成员已被 Q\_S^母、Q\_T^母 或 B\_INT^母 所收，其余成员来自 𝒜\_O 而无母本授权赋予新的当前资格；因此该合取所承担者不出三项之外。

　　例：A\_3 ∧ A\_9——主动因子而可互逆。A\_3 已入 Q\_S^母，A\_9 为形态；母本未把「主动因子须可互逆」作为一项事实承担，故此合取不升格。

第二类　候选全来自 𝒜\_O。冻结的母本未授权该合取承担新增的当前交互资格，故不能通过合取升格为第四项。

　　例：A\_9 ∧ A\_12——可互逆而因应相化不息。前者是形态，后者是后事；合起来仍未出形态与后事一层，母本未以此为成立的依据。以它为资格，即以结果的类型判定此刻的成立。

　　例：A\_6 ∧ A\_11——自于外而相追不舍。前者属 Principle 的特化，后者是延续的形态；合起来仍未出特化与形态两层，母本未以此为寻常交互新增的当前资格。

第三类　候选被主张涌现了新语义。该语义既不在十二原子之内，即已出冻结的母本域，不在本篇所许。

### 5.3 跨句合取

另必须查跨句联合有无母本文义的授权。

M1 与 M2 之间有直接联合：M2 的「主动因子必自于外」即承 M1 的「主动因子」而言，其联合所授的是「有主事者而其居外来之位」。居外一义归 𝒜\_O / Principle 特化的关系限制，有主一义已入 Q\_S^母，故不生第四项。

M2 之内，「使行逆」与「相扰」相接。去其「逆」的 Principle 特化后，其联合所授的仍是「一端之行实际作用到另一端之行」，即 A\_4 与 A\_8 所共承的，归 Q\_T^母。

M2 自身不由此新增 B\_INT^母：关系的同一由 M3 的「二者」即 A\_10 承担，不出于此句。因此也不生第四项。

M1 与 M3 之间，母本无直接联合陈述；强以相连的属第三类。

因此跨句联合也不生第四项。

定理一　当前交互资格穷尽

在 C\_scope 已成立的前提下，冻结的母本域 𝓜\_INT 之内，一次直接的律际交互此刻成立所需具备的当前资格，尽在 Q\_S^母、Q\_T^母 与 B\_INT^母 之中，无第四项。即

　　Q\_4 = ∅

其中 Q\_4 指这样一项资格：它不等同于 Q\_S^母、Q\_T^母 与 B\_INT^母 之中的任何一个，而又是一切直接的 LawInteraction 所必须额外具备的当前资格。

证明。

设有 Q\_4 如上所言。其语义若在 𝓜\_INT 中有根据而又承担当前交互资格，则其载体或为单个原子，或为母本授权的不可约合取。

载体为单个原子的：由 4.6，十二原子各有所归。入 𝒜\_Q 的已被 Q\_S^母、Q\_T^母 与 B\_INT^母 收尽，若 Q\_4 即其一，则与「不等同于三者之任一」相违。入 𝒜\_O 的不承担成立，若 Q\_4 出于此，则它非当前资格。二路都不成。

载体为不可约合取的：由 5.2 三类穷尽。第一类，其 𝒜\_Q 成员已被三项吸收，其余成员无母本授权赋予新的当前资格。第二类，全出 𝒜\_O 的，母本未授权其升格。第三类，主张涌现新语义的，该语义已出冻结域。三类都不生 Q\_4。跨句联合由 5.3 另查，也不生。

其语义若不在 𝓜\_INT 中有根据，则已逾 4.1 的冻结，不在本篇所许。

A\_5 另作说明：它属 Principle 的特化，其身份性要求由 P ≠ A 承担，而寻常的 LawInteraction 不要求 CounterHold 也不研究 SameLaw。因此它不进入寻常交互的当前资格，也不由此产生 Q\_4。

因此在 C\_scope 之下、𝓜\_INT 之内，单原子与母本授权的不可约合取都无独立的第四项资格。∎

此结论限于冻结的母本域。该域若增删，本定理必须重证，见 10.1。

第六节

三项对母本资格的实现

定理二　Bear 实现母本资格

　　SourceLawContribution = 1　⇒　Q\_S^母 = 1  
　　TargetDynGeneration = 1　⇒　Q\_T^母 = 1  
　　SameInteractionBind = 1　⇒　B\_INT^母 = 1

证明。

三式所证的都是强结构推出较弱的母本资格，非二者同名。

第一项。Q\_S^母 所要的，止于「这一次扰动有一个可归属的作用源」——母本只说必有主事、称之为主动因子，未及其所发是否出于职责。而第十篇第五节的 SourceLawContribution 含三道审查：源点的资格、实际的贡献 occurrence、Law 侧的归属。三者既立，则这一次所发的不但有其源，且该源即 L\_S，其所发出于其职责。有源一事自在其中。因此

　　SourceLawContribution = 1　⇒　Q\_S^母 = 1

反向不成立：有可归属的作用源的，未必其所发即出于职责——承担者的物理影响正是有源而非职责。因此该式为单向，也见其为强推弱。

第二项。Q\_T^母 所要的，止于「一端之行作用到另一端之行」——母本只说使行、相扰，未及所作用者是否进入某一次已申报事件的生成。而第十篇第七节的 TargetDynGeneration 要求：所申报的事件落在 Θ\_LD 之内，且这一份贡献实际进入其生成。既已实际进入某次事件的生成，则一端之行作用到另一端之行自在其中。因此

　　TargetDynGeneration = 1　⇒　Q\_T^母 = 1

反向不成立：一端之行作用到另一端而未进入任何一次已申报事件的生成的情形是有的。因此该式也为单向。

第三项。B\_INT^母 所要的，止于「所论者为同一桩两端之事」——母本以「两顺势系统」「二者之相追」的「二者」二字承担这一义。而第十篇第八节的 SameInteractionBind 要求各项落在同一组 β\_int 之上：同一份贡献、同一段执行、同一次事件。此较「同一桩」为细，同一桩自在其中。因此

　　SameInteractionBind = 1　⇒　B\_INT^母 = 1

三式都以对象一层的内容相对，不以形式一层的读数相对：第十一篇的读数只证这些结构有精确的形式实现，不定母本的资格，见 3.2。∎

### 7.1 判准

候选 X 为独立的取消项，当且仅当：在

保持时——即

三项全部保持——X 的成立仍使 LawInteraction = 0。

判准直接绑 Bear，而不绑母本资格。本篇所要证的是 Bear 齐备则交互不能不成立，故所需排除的正是「Bear 全真而仍被 X 挡住」这一情形。

由此，若 X 的成立令三项之中某一项退出，则本篇的前件本就不满足，X 不是第四个取消条件——不必另说它对应某个母本原子的取反。

此与 4.5 的形似否决者专查同出一理：其发生若必致前件失效，则它不独立，归其本类而非 𝒜\_D。

两条线于此分明：母本域一线所证的是交互语义已被穷尽，Bear 一线所证的是三项全真时无可取消的 X；二者于定理四汇合。

### 7.2 取消侧的单原子检查

凡是具否定、排除、阻断或令其不成立的潜力的，都必须登记为 𝒜\_D 的候选，逐一检验。冻结母本域内，具此潜力的出自两处。

其一，十二原子的取反。取 𝒜\_Q 各项的反面，其发生必致相应的母本资格失效——取 A\_2、A\_3 的反面即此扰无主，Q\_S^母 随之不成；取 A\_4 的反面即另一端之行未受此作用，取 A\_8 的反面即无一桩及于彼此的事，Q\_T^母 随之不成；取 A\_10 的反面即所论非同一桩事，B\_INT^母 随之不成。

而母本资格既不成，则由定理二取其逆否：Q\_S^母 = 0 推出 SourceLawContribution ≠ 1，Q\_T^母 = 0 推出 TargetDynGeneration ≠ 1，B\_INT^母 = 0 推出 SameInteractionBind ≠ 1。三者有一不成，Bear 即不保持，本篇的前件本就不满足。按 7.1 的判准，此类都不独立。

定理二先于本节，原因正在于此：取消项的判准绑的是 Bear，而由母本资格的反面推出 Bear 某项不保持，必须经该定理的逆否。

取 A\_1 的反面，即无扰。它不是独立取消项，而是先令前件失效：由 4.6，Q\_T^母 = 1 蕴含 A\_8（相扰），A\_8 蕴含 A\_1；因此无扰与 Q\_T^母 = 1 相冲，而由定理二的逆否，Q\_T^母 不成则 TargetDynGeneration 不保持。按 7.1 的判准，此类不独立。

若取 𝒜\_O 各项的反面：非逆、主动因子不自于外、非两端、不可互逆、不相追、不因应相化——六者都不承担成立，其反也不能令一次已具前件的交互不成立。一次而止的仍是一次交互，读数不变的仍是一次交互，此第十篇第十节已立。

其中 A\_5 与 A\_6 两项另必须说准：由 4.6，二者都属 Principle 的特化，不入寻常交互的当前资格；本篇既不要求 CounterHold，也不研究 SameLaw，故其反不在本篇所能判之列，更非独立取消项。

A\_7 的反面即非两端，那与 C\_scope 所设的成对工作域相冲，不在本篇工作域之内。

其二，三句母本之中的否定性语义。三句所述的，是扰、是相及、是相追相化，都是正面的关系陈述，其中无一句授权「虽有主之职责行加于彼而彼因之动，仍不成其为交互」的否决。

因此单原子一层，𝒜\_D 的候选尽数落空：

　　𝒜\_D = ∅

### 7.3 取消侧的合取检查

与资格侧同理，另必须查母本授权的不可约合取是否形成取消项。

判准仍为母本授权：合取本身不是新的母本原子，要作为一项取消条件，必须母本把该组合关系本身作为否决的依据明白承担。

第一类　含 𝒜\_Q 成员取反的候选。其发生已致相应资格失效，按 7.1 不独立，与合取与否无关。

第二类　全由 𝒜\_O 成员取反组成的候选。这些都不承担成立，合起来仍不承担；母本未以「其形态如此、其后果如彼」为否决的依据。

　　例：A\_11 的反面 ∧ A\_12 的反面——一次而止且化未及展。Continue 一类事件正属此列，交互成立。

第三类　主张涌现新的否决语义的候选。该语义不在十二原子之内，已出冻结域。

三类穷尽一切取消侧的合取候选，无一形成独立取消项。

### 7.4 六组压力世界

上两小节由有限域给出结论，本节另以六类具体情形印证，并示其各自落在何处。

其一，极弱的贡献。设 source 所发的量极微。只要它已经进入这一次事件的实际生成机制，第二项即成立——本篇不设幅度的阈值。若其弱至未曾进入该机制，则 TargetDynGeneration = 0，Bear 已不成立，前件不满足。

其二，背景状态的改变。裸的环境改变纵然有其主事者，也不属 L\_S 的职责承担，故 SourceLawContribution = 0，Bear 已不成立——此处所缺的是 Law 侧的归属，不必断言母本的「有主」为假。而若该状态的变化本身即属 source 律的职责所行，且被目标这一次的机制实际读取，则三项都成立，交互不因其为「状态」而不成立。

其三，使能。单纯的使能未被这一次的机制实际取用，故 TargetDynGeneration = 0，Bear 已不成立——此处所缺的是进入这一次生成，不必断言母本的「使行」绝对为假：

　　MereEnable　⇏　TargetDynGeneration

只有当这一份使能被当前的机制实际读取，才有资格入第二层：

　　Enable ∧ ActualMechanismUse　才可以

其四，抑制。Stop 与 Fall 的贡献可经切断、撤除、失承、增阻各途实现。生成不可狭解为正向的注入——第四篇的六类事件本含止与落，其机制见证也含切集与失利。抑制之行若已进入该次事件的实际机制，第二项成立；其可互逆与否属 A\_9，归 𝒜\_O，不承担成立。

其五，远祖。中途的普通介质、门与非律的转换不截断直接性，第十篇 7.3 已许。而若中途另有一条律取得新的 Law 侧源锚，并接管了通往当前这一目标见证的后缀，则原 source 的直接性已断，TargetDynGeneration = 0，Bear 已不成立。

此处只断直接一层：原 source 仍可能是远端的因果祖先，只是不再构成这一次的直接交互。本篇不据此断言母本的「使行」为假。

其六，延迟。时间的长短属 A\_11，归 𝒜\_O，不承担成立。跨越存储与延迟而 provenance 连续的，第二项照旧成立；provenance 断裂的，TargetDynGeneration = 0，Bear 已不成立。

六类的共同形态是：

　　每一候选，要么破坏 Bear 之一项，要么在 Bear 保持时并不取消 Interaction

定理三　独立取消项为空

在 C\_scope = 1 且 LawInteractionBear = 1 保持时——即 SourceLawContribution、TargetDynGeneration 与 SameInteractionBind 三项全部保持——冻结的母本域 𝓜\_INT 之内不存在独立的取消项。即

证明。

设有候选 X 为独立的取消项。按 7.1 的判准，X 必须在 C\_scope 与 Bear 三项都保持时令交互不成立，且其达到这一结果的途径不得是先令三项之一退出。

X 的语义若在 𝓜\_INT 中有根据，则其载体或为单个原子及其取反，或为母本授权的不可约合取。

载体为单原子一层的：由 7.2，𝒜\_Q 各项的取反都致相应的母本资格失效。而判准绑的是 Bear 三项，非母本资格，故必须再经一步——由定理二取其逆否：

　　Q\_S^母 = 0　⇒　SourceLawContribution ≠ 1  
　　Q\_T^母 = 0　⇒　TargetDynGeneration ≠ 1  
　　B\_INT^母 = 0　⇒　SameInteractionBind ≠ 1

三者有一不成，Bear 即不保持，前件已失，按判准不独立。

这一步不能省略：自母本资格之失到 Bear 某项的不保持，必须由定理二承接；定理二先于本节，原因正在于此。

𝒜\_O 各项的取反都不承担成立，不能令前件已具的交互不成立；三句母本之中也无授权否决的语义。因此 𝒜\_D = ∅。

第九节

高危边界

三条必须单列，随结论一并传导。

### 9.1 参与生成不是决定结果

　　ActualGenerationParticipation　≠　OutcomeDetermination

因此不要求 ButForNecessity，不要求 UniqueCause，不要求 NetOutcomeChange。

冗余的贡献两份同至而去其一无妨，部分被补偿的其净变虽减而事件仍成，Continue 之中读数不变——三者都实际进入了生成。以结果类型的准则判定参与，则此三类尽被错杀。第十篇第十节已排除此三项，本篇不复引之为资格。

补偿一款必须依第十篇 7.2 的收紧：以所申报的事件实际成立为限。部分的或结果一侧的补偿不取消交互；而补偿完全，以致所申报的事件根本未发生的——申报者为 Rise 而终成持平——则那一次 Rise 未曾发生，无从交互于其上，此非本条所许的情形。

其时所缺的是事件本身，故 TargetDynGeneration 不成，Bear 已不保持，按 7.1 的判准也不入独立取消项之列。

### 9.2 单纯使能不是参与

　　MereEnable　⇏　TargetDynGeneration

只有

　　Enable ∧ ActualMechanismUse

才有资格入第二层。二者的区别在于：前者使系统得以工作，后者被这一次的机制实际取用。

### 9.3 非律的转换不截断直接性

　　NonLawTransform　⇏　BreakDirect

而

　　NewLawSideSource ∧ SuffixTakeover　⇒　BreakDirect

接管必须就当前这一目标见证而言：中途某律纵然对别的见证有后缀，也不截断此路。第十一篇 D11 已把这一约束绑在同一见证之上，形式一侧有完整支持。

第十节

边界情形与结构崩坏条件

### 10.1 结论失效的条件

本篇的结论在下列情形失效，其各自的归属如下。

工作域越界——所问的非成对、非事件级、非直接，或所申报的事件不在 Θ\_LD 之内。则 C\_scope 不成立，本定理不适用。

H-INT1 撤销——两端的 Law 资格无从合法判定，本篇的前件不进入可判定的状态。此非结论为假。

H-INT2 撤销——目标事件无从合法认定，同上。

母本域变动——4.1 所冻结的 𝓜\_INT 若增删，则定理一与定理三必须重证，二者都是相对该域的穷尽证明；若因此改变 Q\_S^母、Q\_T^母 与 B\_INT^母 的内容，定理二也必须随之复核。

### 10.2 不属本篇失效的

第十一篇的 G 接口未闭合——那使形式一侧读不出，不改对象一侧的充分向。

第十篇的 H 组中本篇未取用者变动——本篇只取 H-INT1 与 H-INT2。

身份、来源、生态各问未决——都归他篇，见 4.3 的 𝒜\_O。

第十一节

击穿

### 11.1 唯一的硬击穿式

　　C\_INT-S = 1 ∧ LawInteractionBear = 1 ∧ LawInteraction = 0

一个有效的击穿世界必须同时保持：

　　SourceLawContribution = 1  
　　TargetDynGeneration = 1  
　　SameInteractionBind = 1

且工作域与两项 H 都合法。

### 11.2 不构成击穿的情形

下列各种都不是本篇的击穿，因其都已使前件不成立，或本不在本篇工作域：

　　source 实为承担者的物理副作用——第一项不成立  
　　provenance 不连续——第二项不成立  
　　source 只是远端的背景而未被取用——第二项不成立  
　　目标见证拼错——第三项不成立  
　　中途已有新的 Law 侧源接管同一见证的后缀——第二项不成立  
　　Law 或 LawDyn 的工作域本身失效——C\_scope 或两项 H 不成立  
　　第十一篇的 G 接口不可读——形式一侧的事，见 10.2

### 11.3 新增第四项之前提

若有人欲为本篇的结构增设第四个本体项，必须先构造一个合法的世界：其中 Bear 三项全真，而 LawInteraction = 0。

未有此世界而增项的，所增非必要——此与第十篇第九节的递推停止同理。

第十二节

总结公式

### 12.1 本篇的主式

　　C\_INT-S = 1 ∧ LawInteractionBear　⇒　LawInteraction

### 12.2 与第十篇合成

第十篇所证为必要向：

　　LawInteraction　⇒　LawInteractionBear

本篇所证为充分向。二者合成

　　LawInteraction　⟺　LawInteractionBear

此双向成立于两篇共同冻结的工作域与 H 条件之下，不是无条件的普遍命题。凡是引用者必须连同 C\_scope、H-INT1 与 H-INT2 一并承继。

### 12.3 与第十一篇合成的推论

推论一

在 C\_INT-S = 1 之下

　　Read^M\_INT = 1　⇒　LawInteractionBear = 1　⇒　LawInteraction = 1

前一步由第十一篇 8.2，后一步由本篇定理四——后者的前件含 C\_INT-S，即 C\_scope 与两项 H，故这一条件不能省略。

推论二

在 C\_INT-S = 1，且第十一篇 G-INT1、G-INT2 与 G-INT3 都闭合的可读域之内

　　Read^M\_INT = 1　⟺　LawInteraction = 1

前向由推论一，反向由第十一篇的完备回读定理与 12.2 的双向合成；而 12.2 的双向本系于 C\_scope 与两项 H，故三项 G 之外另必须 C\_INT-S。

两条推论的成立条件两侧齐全：对象一侧为 C\_INT-S，形式一侧为三项 G。只列其一的，所申报的条件比实际所需为宽。

两条推论都置于主定理之后，不参与本篇的主证明：本篇的充分向由第五至第八节独立证成，与形式一侧的读数无涉。
