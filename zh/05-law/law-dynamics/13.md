自显论 · 律篇 · 律动力组式第十三 v1.0

# 律生态稳定式

第一节

目的、式种与唯一任务

### 1.1 这一篇要解决什么问题

一组律彼此配合而成一份组织：某些律各承其位，某些律之间按事件反复交互。这份组织在场的后续演化中会遇到扰动——成员退出、承担者更换、程度升降、交互中断。

要问的是：这份组织还在不在？若一时不在了，还能不能按规矩回来？而「还在」这句话，说的是原来那一份组织本身，还是同类的组织尚有其一？这两问的答案可以不同，必须分开签。

### 1.2 唯一任务

固定一份已由正式 Law 与正式 LawInteraction 事实联合实现的多律组织模板，固定许可变化域、评价协议与动态稳定协议；问该组织在合法的后继轨迹之中，其固定 realization 与 realization 集分别如何保持、退出、替代、复归，以及在何种量词强度之下可以合法签出稳定。

### 1.3 两条轴，不得裸写稳定

所签的稳定必须同时说明两件事：稳定的是哪一层对象，覆盖的是哪一级轨迹。

　　对象层　x ∈ { fix, set }  
　　轨迹量词层　Λ ∈ { single, family, guaranteed }

裸写「生态稳定」为本篇所禁。凡是言稳定处，必须指明 x 与 Λ。

### 1.4 式种与版本定位

稳定式，附式，独立成篇，首版。

按法篇第一第四编第十五章，稳定式的用途是证明一个已经成立的资格、结构、对象或解，在声明的许可变化域中能否保持，若退出是否能在合法动力下复归，并区分同一承担者保持、存在某承担者保持、声明轨迹族稳定与全部合法轨迹保证稳定等不同的量词层级。稳定式所证者是已立资格在变化中的保持，不是对象的首次存在、首次可达或首次发生。

### 1.5 本篇不是什么

不是一般式：不证「生态成立最少必须有什么」。

不是必然式：不证「生态必然稳定」。

不是可达式：不证「存在一条恢复路径」。存在一条恢复路径与稳定是两件事，与全部合法轨迹保证稳定更是两件事。

不是身份式：不答复归之后的承担者是不是原来那一条 Law。

第二节

上游输入、工作域与非新增声明

### 2.1 上游输入

本篇只调用，不重证。

《律组式》与《律判定式》（封版）——正式的 Law 资格。

第一至七篇（封版）——当前的 LawAct、Degree、六类 LawDyn 事件、运行段与合法轨迹的制度。

第十至十二篇（封版）——事件级的直接交互

　　LawInteraction^η\_F( L\_S → L\_T ; e\_T )

及其与 LawInteractionBear 在共同工作域与 H 条件下的双向。本篇调用已取得正式资格的交互 occurrence，不重新定义它。

第八篇（封版）——身份的界线。本篇不判 SameLaw。

### 2.2 不新增本体

本篇不新增一种叫 Eco 的本体实体。

也不新增：PersistentInteraction、EcoForce、EcoField、EcoTrigger、SameEco。

下文所立的 EcoQual、EcoCert、node-role、interaction-role、JointEcoBind 各项，都是稳定审查一层的组织与证书对象。它们最终都能展开回

　　Law　+　LawInteraction　+　事前冻结的角色模板与评价协议

因此本篇未借附式的权限另作一篇「生态一般式」。

这一款必须置于前部。否则读者会问：生态是什么尚未证成，为什么先稳定它？答曰：本篇不主张一种新的生态本体，所稳定的是一份由已成立的上游事实所构成的多律组织资格证书。

### 2.3 条件化的承继

凡是 Law、LawInteraction、底层合法轨迹或上游读出制度本身为 Conditional 的，本篇的结论只在其条件闭包之内成立。

第三节

生态资格模板与当前资格

### 3.1 模板

冻结

　　Σ\_Eco = ( 𝒩\_Eco, ℰ\_Eco, Γ\_qual )

　　𝒩\_Eco　node-role 的集。每一 ν 是一个生态职责位，必须由正式的 Law-role realization 承担  
　　ℰ\_Eco　interaction-role 的集。每一 ε 规定哪两个 node-role 之间，必须由正式的事件级 LawInteraction occurrences 兑现何种关系职责  
　　Γ\_qual　当前资格如何读取的协议

Γ\_qual 只管当前资格的读取，不管稳定。它冻结节点窗口评价、交互窗口评价、事件的选择与聚合、同证绑定、三值读出的规则。

稳定协议不入 Σ\_Eco。「生态是什么」与「允许它怎么变」「怎样算它稳定」，是三件事。

### 3.2 interaction-role 不是持久之边

这是全篇最高风险的界线。

　　InteractionRole　≠　LawInteractionOccurrence

更不得写

　　InteractionRole　=　PersistentInteraction

上游的 LawInteraction 是某一次 LawDyn 事件之上的正式交互 occurrence。因此生态的长久关系只能由多次正式的 occurrence，在冻结的窗口协议之下反复兑现。

长久之边不是一个新实体，而是

　　自事件历史之中反复读出的角色资格

本篇所以必须窗口评价而非瞬时的静态图，原因在此。

### 3.3 当前窗口资格

　　EcoCert = NodeWindowQual ∧₃ EdgeWindowQual ∧₃ JointEcoBind

∧₃ 为零吸收的三值合取：三项都是 1 则为 1；任一项确定为 0 则为 0；无 0 而至少一项为 ⊥ 则为 ⊥。

三值自资格的入口即立，不待第七节才开始。因此 EcoCert = ⊥ 的不入 ℰ\_k：纳入它则「读不出」被当作「读得而成立」。而 ℰ\_k 是否确为空，另必须 7.2 所要求的候选域完整可判。

　　NodeWindowQual　一切 node-role 于该窗按冻结协议取得正式的 Law 承担  
　　EdgeWindowQual　一切 interaction-role 于该窗按冻结的事件评价协议，由正式的 LawInteraction occurrences 兑现  
　　JointEcoBind　　节点的承担与各 occurrence 属同一份角色 realization

三项一项也不能删。

删 JointEcoBind 的，节点自一套证书取、边自另一套取，可拼出一份实不存在的生态。

### 3.4 两项不入当前资格

Coverage 不另立为第四项：它是 Node 与 Edge 两项得满的结果，非另一项条件。

JointViability 也不立：其若指「当下可共同成立」，已为三项所涵；其若指「将来还能共同成立」，那是稳定一层的事，置入当前资格即成循环。

第四节

结构 realization、事件见证与窗级解集

### 4.1 二者必须分开

一份可跨窗比较的生态结构 realization 记作

　　E^str = μ\_N

即 node-role 的承担结构：每一位由谁来承担。

interaction-role 一侧不另设分量。其两端的 role 由 ℰ\_Eco 的 ε 已定，其两端的承担者由 μ\_N 唯一决定，故其结构配位可自 Σ\_Eco 与 μ\_N 导出，不另记它——记下它则是一个无自由度的空位。

而于某一评价窗 H\_k 之中，实际用以证明各 interaction-role 得以兑现的事件 occurrences，另记作

　　W\_k

因此

　　W\_0 ≠ W\_1

本属寻常。

不得把具体的 interaction occurrence token 放入跨窗的固定身份之中——放入则该固定层几乎必于下一窗自行死亡，所稳定的成了一次不可重现的事件。

### 4.2 静态资格证书

　　EcoCert( E^str, W\_k ; Σ\_Eco, H\_k )

### 4.3 窗级解集

　　ℰ\_k ≔ ℰ( F\|\_{H\_k}, Σ\_Eco ) = { E^str \| ∃ W\_k　EcoCert( E^str, W\_k ; Σ\_Eco, H\_k ) = 1 }

此解集为后文一切稳定读数的基础。

必须说准：ℰ\_k ≠ ∅ 只说当前资格存在，不推出稳定。

### 4.4 事件的时间语义

interaction-role 不得要求「每一微时刻皆有 LawInteraction」。评价落在事前冻结的观察窗

　　H\_0, H\_1, …, H\_n

每一 edge-role 的事件读法由 Γ\_qual 冻结。

某一具体应用可要求某窗之内至少有一次，或要求更严的覆盖；此类都是协议的参数，不写作理论的常数。

核心纪律只两条：评价规则事前冻结；0 ≠ ⊥。材料不足时，不得把「未见交互」径判为 0。

第五节

稳定实例与许可变化域

### 5.1 稳定实例

　　Ξ\_Eco = ( F\|\_{H\_0}, Σ\_Eco, E^str\_0, Δ\_Eco, ℋ\_Eco )

　　E^str\_0 ∈ ℰ\_0　初窗之中已成立的那一份固定 realization  
　　Δ\_Eco　　许可变化域  
　　ℋ\_Eco　　稳定协议，至少冻结观察域、恢复期限、持续验证的时长与动态读出的规则

Σ\_Eco 与 Δ\_Eco 必须分开：生态是什么，与允许它怎么变，不是一件事。

### 5.2 许可变化域

Δ\_Eco 所许的变化包括：场状态的变化；Degree 的升降；LawAct 的起止；成员的退出；合法的替代；新 Law 或额外交互的加入；interaction occurrence 的更新；非律物理路径的变化。

### 5.3 不入许可变化域的改动

Σ\_Eco 的改写、Γ\_qual 的改写、Δ\_Eco 自身的改写、ℋ\_Eco 的改写——四者都不是原稳定实例之中的一次扰动。

一旦改它，则

　　Ξ\_Eco　→　Ξ′\_Eco

其后所稳定的已非原实例。改了模板、许可变化域、身份层或评价协议之后再称原稳定实例复归的，构成击穿，见 13.2。

第六节

固定层与存在层

### 6.1 两层

　　Q^fix\_Eco( k ) = 1　⟺　E^str\_0 ∈ ℰ\_k  
　　Q^set\_Eco( k ) = 1　⟺　ℰ\_k ≠ ∅

前者问原来那一份 realization 是否仍在，后者问同类之中尚有其一否。

### 6.2 单向

　　Q^fix = 1　⇒　Q^set = 1

反向不成立。合法替代即其反例：E^str\_0 ∉ ℰ\_k 而 ℰ\_k ≠ ∅——原来那一份已退出，而另一份合法的顶了上来。

### 6.3 只有两层

轨迹不另立为介于二者之间的第三层资格。它属于另一条轴，见第七节。

第七节

动态判定域与三值制度

### 7.1 轨迹轴

设 γ 为一条合法的底层后继轨迹。则

　　Q^x\_{Eco,γ}( k )，　x ∈ { fix, set }

沿该轨迹逐窗重算。

对象层与轨迹量词层是两条轴：前者问所稳定的是什么，后者问覆盖多少条合法未来。

### 7.2 三值

一切读数取

　　Q^x( k ) ∈ { 1, 0, ⊥ }

set 一层尤其要说准：Q^set = 0 不得由「搜索未得」而来。只有候选域完整可判、且一切候选都确定失败，才取 0；否则取 ⊥。

合法而不可判的未来留在定义域之内，不预先删去。

### 7.3 动态判定域

合法的轨迹不以观察窗的覆盖或当下的可判性筛除。TrajLegal\_Eco 收一切合法的后继轨迹；可判与否另立一层。

对 γ ∈ TrajLegal\_Eco 与给定的原 realization E^str\_0：

　　DynDomFix\_Eco( γ, E^str\_0, ℋ\_Eco ) = 1　当且仅当

　　　一　观察窗于该轨迹之上覆盖完整  
　　　二　观察域之上，固定层任务所需的窗级读数都可求  
　　　三　Fail^fix\_γ 非空时，其首次实际失效可确定；若用连续的域而取下确界，必须可判其是否取得，且于恢复任务所需时，取得一个可合法计时的实际失效点  
　　　四　固定层的动态任务所需的协议条件全部满足

　　DynDomSet\_Eco( γ, ℋ\_Eco ) = 1　当且仅当

　　　一　观察窗于该轨迹之上覆盖完整  
　　　二　观察域之上，存在层任务所需的窗级读数都可求  
　　　三　Fail^set\_γ 非空时，其首次实际失效可确定；若用连续的域而取下确界，必须可判其是否取得，且于恢复任务所需时，取得一个可合法计时的实际失效点  
　　　四　存在层的动态任务所需的协议条件全部满足

若相应的 DynDom 不为 1，则该轨迹于该层的 Keep、Recover 与 Stable 三者的判值都取 ⊥。

DynDom 为总门，不是旁注：8.1、9.2 与 10.1 的判定都以其为 1 为前件。第三款所以写至「可合法计时的实际失效点」的，正为免于 DynDom 已判为 1，而至 9.1 才发现无 k\_f 可用以计时。

DynDom^x\_Eco( γ ) = 1 时，相应的动态任务已进入可判的域，故 Keep^x、Recover^x 与 Stable^x 三者都只取 1 或 0。

相应任务所需的关键事实仍不可判的，不得令 DynDom^x\_Eco( γ ) = 1；其当留在 TrajLegal\_Eco ＼ TrajDec^x\_Eco 之中，而三项动态判值由总门取 ⊥。

三值的位置由此分明：

　　DynDom ≠ 1　⇒　⊥  
　　DynDom = 1　⇒　{ 0, 1 }

⊥ 只由总门给出，不在各项之内另开一处。此制原样承继封版《律稳定式》。

### 7.4 可判轨迹族

　　TrajDecFix\_Eco = { γ ∈ TrajLegal\_Eco \| DynDomFix\_Eco( γ, E^str\_0, ℋ\_Eco ) = 1 }  
　　TrajDecSet\_Eco = { γ ∈ TrajLegal\_Eco \| DynDomSet\_Eco( γ, ℋ\_Eco ) = 1 }

下文凡是书 TrajDec^x\_Eco 的，x = fix 取前者，x = set 取后者。

### 7.5 重算规则

每一窗按 Γ\_qual 重读 EcoCert，得 ℰ\_k，再按 6.1 求两层的值。变化之后的资格如何重算，即此。

第八节

保持、实际失效与边界

### 8.1 保持

DynDom^x\_Eco( γ ) 为总门：其不为 1 的，Keep^x\_{Eco,γ} = ⊥，不入以下的判定。

DynDom^x\_Eco( γ ) = 1 时，Keep^x\_{Eco,γ} ∈ { 0, 1 }：

　　Keep^x\_{Eco,γ} = 1　⟺　观察域之中一切 k 都有 Q^x( k ) = 1  
　　Keep^x\_{Eco,γ} = 0　⟺　存在 k 使 Q^x( k ) = 0

⊥ 只由总门给出。轨迹的覆盖未完而某窗已见 0 的，其 DynDom 不为 1，该轨迹不入 TrajDec^x\_Eco，Keep 由总门取 ⊥ 而非取 0——见得一处失败，不等于这条轨迹上的保持的问题已可判。

### 8.2 量词不得偷换

　　∀k ∃E\_k　只支持 set 一层  
　　∃E\_0 ∀k　才是 fix 一层

二者不等价。以前者充后者，是把「每一窗都有某份 realization」说成「有一份 realization 贯穿诸窗」。这是稳定式审稿的硬点。

### 8.3 失败集与首次实际失效

本节也以 DynDom^x\_Eco( γ ) = 1 为前件。

　　Fail^x\_γ = { k \| Q^x\_γ( k ) = 0 }

只有确定的 0 入该集。⊥ 不是 failure。

此处必须与两层的 ⊥ 相对读。窗级的读数 Q^x( k ) 本是三值，其取 ⊥ 的即该窗读不出；而 7.3 第二款要求观察域之上各窗级读数都可求，故凡是有一窗取 ⊥ 而其为该任务所需的，该轨迹即不满足 DynDom^x\_Eco = 1，于是留在 TrajLegal\_Eco ＼ TrajDec^x\_Eco 之中，其 Keep、Recover 与 Stable 由总门取 ⊥。

所以于 DynDom = 1 的轨迹上，各所需的窗都得确定的值，Fail^x\_γ 之外更无「未定之窗」可虑。「⊥ 不是 failure」一语，所防的是把不可判的窗算作失败，而非许其与 0 并存于一条已判的轨迹。

于离散的评价域

　　k\_f^x = min Fail^x\_γ

若用连续的域而取 inf Fail，则必须另证该下确界确被取得，才可以称其为实际的失效点。这也是 7.3 第三款的要求——其不可判的不得入 TrajDec。

数学之边界不自动给出该点之真值：b = inf A 或 b = sup A 只给边界。自边界读取失效、状态或责任之前，须另证边界取得。

第九节

复现、恢复与持续验证

### 9.1 恢复的五项

对 x ∈ { fix, set }，恢复必须五项都具备：实际失效、后置复归、期限、同一稳定任务的绑定、持续验证。

　　Recover^x\_{Eco,γ} = 1　仅当存在 k\_f^x \< k\_r 使

　　　Q^x( k\_f^x ) = 0  
　　　Q^x( k\_r ) = 1  
　　　Dur( k\_f^x, k\_r ) ≤ T^x\_rec  
　　　绑定未改：Ξ\_Eco、Σ\_Eco、Δ\_Eco、ℋ\_Eco、γ 都仍其旧  
　　　复归之后满足至少 h\_x 的持续验证，并按协议保持至观察域的末尾

### 9.2 取值

DynDom^x\_Eco( γ ) 为本项的总门。

　　DynDom^x\_Eco( γ ) ≠ 1　⇒　Recover^x\_{Eco,γ} = ⊥

只有其为 1 时，进入二值的判定：

　　Recover^x = 1　已有首次实际失效，且 9.1 的五项都成立

　　Recover^x = 0　下列之一成立：  
　　　　其一　观察域之内确未发生实际失效  
　　　　其二　确曾发生实际失效，而恢复期限之内五项至少有一项确定不成立

取 0 的第一款不表其系统的不佳，只表未曾发生恢复一事——其时若 Keep^x = 1，Stable 仍由 Persistent 一支取得，见 10.2。

失效的有无、复归、期限、任务绑定或持续验证之中，若有关键事实不可判，则该轨迹不满足 DynDom^x\_Eco = 1；其 Recover 不在本项之内另取 ⊥，而由总门直接取 ⊥。

本项既已闭合，10.1 的 Stable 才是总函数。

### 9.3 期限自首次实际失效起算

后来再次失效的，不得重置 T^x\_rec。计时始终自首次实际失效起。

### 9.4 复现不是恢复

　　Recover^x　⇒　Reappear^x  
　　Reappear^x　⇏　Recover^x

瞬时的 0 → 1 → 0 只是复现。逾期而后归的，也只是复现。改了模板或稳定协议才重得其 1 的，更非原稳定任务的恢复。

无先行的实际失效而只是重新出现的，不构成恢复。

第十节

单轨迹稳定

### 10.1 主判据

以下的判定也以 DynDom^x\_Eco( γ ) = 1 为前件：其不为 1 的，Keep^x 与 Recover^x 都由总门取 ⊥，Stable^x\_{Eco,γ} 随之为 ⊥。

其为 1 的，Keep^x 与 Recover^x 都已取定 0 或 1，故 Stable^x\_{Eco,γ} ∈ { 0, 1 }：

　　Stable^x\_{Eco,γ} = Keep^x\_{Eco,γ} ∨₃ Recover^x\_{Eco,γ}

其义为：在冻结的协议之下，一份生态资格沿某一条合法轨迹，或始终保持，或实际失效之后按合法的恢复条件复归；得其一方可签稳定。

∨₃ 为三值的析取：有一为 1 则为 1；两者都确定为 0 则为 0；无 1 而有 ⊥ 则为 ⊥。

### 10.2 两种稳定的来源

　　Persistent^x　≡　Keep^x = 1  
　　Resilient^x　≡　Fail^x ≠ ∅ ∧ Recover^x = 1

Stable 可由二者之一取得。本篇标题所含的保持、复归与韧性，尽于此二者。

不另开一套韧性的本体。

第十一节

轨迹族稳定与保证稳定

### 11.1 轨迹族稳定

事前声明

　　∅ ≠ 𝒢^x\_Eco ⊆ TrajDec^x\_Eco

族必须非空，且必须确认其为相应可判轨迹族的子集。

　　FamilyStable^x\_Eco( 𝒢 ) = 1　⟺　∀ γ ∈ 𝒢，Stable^x\_{Eco,γ} = 1  
　　FamilyStable^x\_Eco( 𝒢 ) = 0　⟺　∃ γ ∈ 𝒢，Stable^x\_{Eco,γ} = 0

所声明的族为空，或无从确认其为 TrajDec^x\_Eco 的子集的，FamilyStable^x\_Eco = ⊥。

族内有一条合法而可判的失稳轨迹，即击穿它。

### 11.2 保证稳定

本篇的 GuaranteedStable^x\_Eco，不取作一个脱离审查制度的裸全称命题真值，而取作：

　　对全部合法后继轨迹完成相应层级的判定以后，可以正式签出的保证稳定证书状态。

因此其取 1 与取 0，均以

　　TrajLegal\_Eco ≠ ∅  
　　TrajLegal\_Eco = TrajDec^x\_Eco

为共同的资格门。

此谓：若仍有合法而不可判的后继轨迹，则关于「全部合法轨迹」的保证审查尚未闭合；纵已出现一条确定失稳的轨迹，本篇所定义的证书状态仍不径签 0，而取 ⊥。该制度所表的，是保证审查是否已完整闭合，非寻常三值逻辑之中一个裸全称公式的独立真值。

在此定义之下：

　　GuaranteedStable^x\_Eco = 1　当且仅当三者都成立

　　　TrajLegal\_Eco ≠ ∅  
　　　TrajLegal\_Eco = TrajDec^x\_Eco  
　　　∀ γ ∈ TrajLegal\_Eco，Stable^x\_{Eco,γ} = 1

　　GuaranteedStable^x\_Eco = 0　当且仅当三者都成立

　　　TrajLegal\_Eco ≠ ∅  
　　　TrajLegal\_Eco = TrajDec^x\_Eco  
　　　∃ γ ∈ TrajLegal\_Eco，Stable^x\_{Eco,γ} = 0

　　其余情形　GuaranteedStable^x\_Eco = ⊥

取 0 与取 1 共用完整覆盖的资格门。任何合法而不可判的轨迹，都表保证审查尚未闭合，故相应的证书状态当下取 ⊥。

FamilyStable 只对事前声明且已进入可判域的轨迹族负责；GuaranteedStable 则必须全部合法的后继轨迹都进入可判域之后，才允许正式签出 1 或 0。

### 11.2.1 两事必须分

上制承自封版《律稳定式》，本篇按其原样承继，不自行改它。

其与全篇的零吸收原则不相撞，原因在于所判的本非同一事：

　　其一　全称的真值——∀ γ ∈ TrajLegal\_Eco，Stable^x\_γ = 1 是否为真  
　　其二　签证的资格——是否已把全部合法轨迹判毕，因而有资格签出一份完整的保证证书

一条确定失稳的轨迹足以否定其一，而不足以给出其二。本谓词所签的是其二。

此二者于上游制度之中压作一个谓词。其是否当拆为 GuaranteedStableTruth 与 GuaranteedStableCertifiable 两项，属《律稳定式》的升版问题，非本篇所得单独裁断——本篇若径改为「见一条确定失稳轨迹即取 0」，则与已封版之上游制度不一致。

因此登记为组级待决点：

　　G-PEND1　保证稳定的真值与可签证性是否当分立

该点若经上游升版而裁定分立，本篇 11.2 与 K-ECO11 随之修订，走升版程序。在其裁定之前，本篇按现制运行。

### 11.3 不得预删

不得把合法而不可判的轨迹自「全部合法轨迹」之中删去，而后宣布保证稳定。

轨迹未覆盖观察窗的，也不得以其所缺的部分制造全称的空真。

### 11.4 三级不得互冒

单轨迹的稳定不是族稳定，族稳定不是保证稳定。存在一条恢复路径更非保证稳定。

第十二节

固定层与存在层的关系，及高危边界

### 12.1 两层的蕴含

设 DynDomFix\_Eco( γ ) = DynDomSet\_Eco( γ ) = 1，则由 6.2

　　Keep^fix = 1　⇒　Keep^set = 1

前件必须两层齐全，不得以一层代它：DynDomFix = 1 并不蕴含 DynDomSet = 1。set 层的 0 必须候选域完整可判，见 7.2；fix 层只需判原来那一份是否在内。因此一条轨迹可以 fix 层可判而 set 层不可判——其时 Keep^fix = 1，而 Keep^set 由总门取 ⊥，并非 1。

窗级的蕴含则不受此限：Q^fix( k ) = 1 ⇒ Q^set( k ) = 1 逐窗成立，不待动态的总门。12.2 所用者即此。

### 12.2 恢复不可平移

不得写

　　Recover^fix　⇒　Recover^set

原因在于：fix 可以失效而后复归，而 set 或自始未曾失效——未失效的无所谓恢复。

正确的是

　　Recover^fix = 1　⇒　Q^set( k\_r ) = 1

该式落在窗级读数上：复归的窗 k\_r 有 Q^fix( k\_r ) = 1，由 12.1 末所言之窗级蕴含即得。它不断言 Recover^set 与 Keep^set 取何值——后二者必须 DynDomSet = 1 才有确定的值。

而

　　Recover^set = 1　⇏　Recover^fix = 1

其反例即合法替代：各 realization 尽退而后另有一份顶上，set 复归而原来那一份始终未归。

### 12.3 失效的次序

设同一轨迹 γ 上 DynDomFix\_Eco( γ ) = DynDomSet\_Eco( γ ) = 1，且两层的首次失败都实际取得，则

　　k\_f^fix　≤　k\_f^set

原因在 Q^set( k ) = 0 ⇒ Q^fix( k ) = 0——此蕴含也必须该窗两层都可判才得以成立，故前件不能省略。其义为：原固定的 realization 可以先行失效，而实现的集尚未空；只有其后一切合法的 realization 都退出，set 才坍缩。

这是边界的定理，不升为主稳定的定义。

### 12.4 反馈、竞争、互助的位置

三者尽归 Σ\_Eco 的具体模板内容，都非一般生态稳定的必要条件。

因此禁写

　　EcoStable　⇒　Feedback  
　　Feedback　⇒　EcoStable

竞争与互助同此。某模板需要反馈环的，把相应的 interaction-role 写入该模板即可；不需要的不强加。

### 12.5 替代不是身份

　　RoleReplacement　≠　SameLaw

一份新的正式 Law 可以合法接过同一个 node-role：

　　L\_A ⤳ L\_B

此只证 L\_B 满足同一位的承担资格，不推出 SameLaw( L\_A, L\_B ) = 1。

第八篇已证声明的配对与物理 root 的配对都不得冒充身份，而闭合的 Law identity 判据至今未立。本篇不自后门补它。

### 12.6 见证替代与对象替代不得混写

一份固定的 E^str\_0 之下，某窗所用的 W\_k 更换，是内部见证的替代，E^str\_0 未动，Q^fix 照旧可为 1。

而 E^str\_0 退出、另一份 E^str\_1 顶上，是对象的替代，Q^fix = 0 而 Q^set 或仍为 1。

二者不得混写：以见证的更换称对象失效的错误，以对象的替代称原对象保持者尤误。

第十三节

定理群与击穿

### 13.1 命题与定理

命题一　生态资格重算（定义的展开）

　　E^str ∈ ℰ\_k

当且仅当存在该窗的一组事件见证 W\_k，使

　　EcoCert( E^str, W\_k ; Σ\_Eco, H\_k ) = 1

即

　　E^str ∈ ℰ\_k  
　　⟺  
　　∃ W\_k \[  
　　　　NodeWindowQual( E^str, W\_k )  
　　　　∧₃ EdgeWindowQual( E^str, W\_k )  
　　　　∧₃ JointEcoBind( E^str, W\_k )  
　　　　\= 1  
　　\]

其义为：跨窗比较的对象仍是 E^str；某一评价窗之中，用以证明该结构 realization 当前合格的那些具体 interaction occurrences，只作为该窗的事件见证 W\_k 而存在，不入跨窗的身份。

存在量词不能省略。去掉它则三项成无见证的裸谓词，而 4.1 所立的「结构 realization 与事件见证不得混」于此自坏。

证明。由 4.3，

　　ℰ\_k = { E^str \| ∃ W\_k　EcoCert( E^str, W\_k ; Σ\_Eco, H\_k ) = 1 }

因此 E^str ∈ ℰ\_k 当且仅当存在 W\_k 使 EcoCert = 1。再由 3.3，

　　EcoCert = NodeWindowQual ∧₃ EdgeWindowQual ∧₃ JointEcoBind

因此上式成立。∎

定理一　稳定对象层级

　　Q^fix = 1　⇒　Q^set = 1，而反向不成立。

证明。前向：E^str\_0 ∈ ℰ\_k 则 ℰ\_k 非空。反向的不成立由 6.2 的合法替代反例。∎

命题二　单轨迹稳定判据（定义的展开）

　　DynDom^x\_Eco( γ ) ≠ 1　⇒　Stable^x\_γ = ⊥  
　　DynDom^x\_Eco( γ ) = 1　⇒　Stable^x\_γ = Keep^x\_γ ∨ Recover^x\_γ ∈ { 0, 1 }

证明。前一式由 7.3 的总门。后一式由 10.1 的定义；其时 Keep 与 Recover 已由 8.1 与 9.2 取定 0 或 1，故三值的析取 ∨₃ 于其上退为寻常的析取。∎

Stable 的 ⊥ 只由总门给出，不由两个 ⊥ 的析取而得——总门之后二者本无 ⊥。

命题三　轨迹族的聚合（定义的展开）

对 ∅ ≠ 𝒢^x\_Eco ⊆ TrajDec^x\_Eco

　　FamilyStable^x( 𝒢 ) = 1　⟺　∀ γ ∈ 𝒢，Stable^x\_γ = 1  
　　FamilyStable^x( 𝒢 ) = 0　⟺　∃ γ ∈ 𝒢，Stable^x\_γ = 0  
　　其余取 ⊥

证明。由 11.1 的定义。族为空或无从确认其为可判族的子集的，两款之前提都不成，故取 ⊥。∎

本节四款命题为定义的展开，两条定理为其所推得的：前者示各判据如何合成，后者证两层的蕴含与失效的次序。

命题四　保证稳定的聚合（定义的展开）

　　GuaranteedStable^x = 1　⟺　TrajLegal\_Eco ≠ ∅ ∧ TrajLegal\_Eco = TrajDec^x\_Eco ∧ ∀ γ ∈ TrajLegal\_Eco，Stable^x\_γ = 1  
　　GuaranteedStable^x = 0　⟺　TrajLegal\_Eco ≠ ∅ ∧ TrajLegal\_Eco = TrajDec^x\_Eco ∧ ∃ γ ∈ TrajLegal\_Eco，Stable^x\_γ = 0  
　　其余取 ⊥

证明。由 11.2 的定义。二集不等时，其差即合法而不可判的轨迹；按 11.3 不得预删，故取 0 与取 1 之前提都不成，其值为 ⊥。∎

定理二　失效边界次序

设 DynDomFix\_Eco( γ ) = DynDomSet\_Eco( γ ) = 1，且两层的首次失败都实际取得，则

　　k\_f^fix ≤ k\_f^set

证明。设 DynDomFix\_Eco( γ ) = DynDomSet\_Eco( γ ) = 1。其时每一窗两层都得确定的值，故由 6.2 的逆否，Q^set( k ) = 0 推出 Q^fix( k ) = 0，即

　　Fail^set\_γ　⊆　Fail^fix\_γ

两集的最小元于是有此序。

前件不能省略：若某窗 Q^set 取 ⊥ 而 Q^fix 取 0，二集的包含关系无从确立。∎

### 13.2 击穿

下列各情形，于所声明的原资格、许可变化域与条件组保持时，任一成立即构成相应的击穿。

K-ECO1　宣称 Keep^fix = 1 或 Persistent^fix = 1，而观察域之中存在某窗使 E^str\_0 ∉ ℰ\_k；或固定层已实际失效而未满足 9.1 的恢复五项，却仍宣称 Stable^fix = 1。

　　不得以「曾经退出」径击 Stable^fix：由 10.1，Stable = Keep ∨₃ Recover，而 Resilient 一路本许 1 → 0 → 1。退出只击保持一支，不击稳定本身；欲击稳定，必须并证其恢复不成。

K-ECO2　宣称 Keep^set = 1，而某窗已确定 ℰ\_k = ∅；或存在层已实际坍缩而未满足 9.1 的恢复五项，却仍宣称 Stable^set = 1。

　　同上：坍缩只击保持一支。

K-ECO3　宣称恢复而无先行的实际失效。

K-ECO4　宣称恢复而复归发生于失效之前。

K-ECO5　宣称恢复而逾所报的期限。

K-ECO6　宣称恢复而只是瞬时复现。

K-ECO7　宣称恢复而未满足所报的持续验证。

K-ECO8　以后来的失效重置恢复的期限。

K-ECO9　改了模板、许可变化域、评价协议或稳定协议之后，仍称原稳定实例复归。

K-ECO10　宣称 FamilyStable 而所声明的族内存在合法且可判的失稳轨迹。

K-ECO11a　于 TrajLegal\_Eco = TrajDec^x\_Eco 而存在合法的失稳轨迹时，仍宣称 GuaranteedStable^x = 1。

K-ECO11b　于 TrajLegal\_Eco ≠ TrajDec^x\_Eco 时，宣称 GuaranteedStable^x = 1 或 0，而未取 ⊥。

　　这一款必须与 11.2 及 11.2.1 相对读：纵已见一条失稳的轨迹，若同时另有合法而不可判的，本篇定义之下的保证审查仍未闭合，故 GuaranteedStable 的证书状态仍为 ⊥。

　　此不等于否认该失稳轨迹已构成对裸全称稳定命题的反例——二者所判非同一事，见 11.2.1。

　　这一款系于上游现制，其是否当改见 G-PEND1。

K-ECO11c　把合法而不可判的轨迹预先删出 TrajLegal\_Eco，据以取得 1 或 0。

K-ECO12　宣称边界的点已发生失效，而该 inf 或 sup 未经证明取得。

K-ECO13　不同时刻不同的承担者被拼作同一份固定的 realization。

K-ECO14　节点的承担与各 interaction occurrence 出自不同的角色映射，而被拼作一份 EcoCert。

K-ECO15　无协议授权而把事件的静默径判为边的失效。

### 13.3 不是击穿的

某窗的 W\_k 更换而 E^str\_0 未动——这是内部见证的替代，见 12.6。

某窗取 ⊥ 而非 0——⊥ 不入失败集，见 8.3。

上游的 H 或条件闭包未成——本篇的结论只在其闭包内成立，见 2.3。

模板之中无反馈的环——反馈非一般稳定的必要条件，见 12.4。
