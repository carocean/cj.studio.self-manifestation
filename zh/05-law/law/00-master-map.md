# 总图

## 第一节　目的、职责域与组式定种

### 1.1　目的

本篇是《律组式》八篇已封版式文的总图与组级证明文件。本篇只做整理、统摄和显式化，把已经完成的组级研发写清楚：不新增理论内容，不新增 H，不新增本体谓词和场量，不改动八篇封版的结论、术语、定理方向和状态。

### 1.2　律在《自显论》中的体系位置

《律组式》处理的不是一个孤立的规律分类问题。以下分五层说明律的上游来源、内部位置与下游作用。这五层是不同类型的关系，不能压成一条单线因果链（见本节末的关系类型申明）。

\*\*第一层　物化层\*\*

《自显论》所谓物化，不只生成"物"。物化同时生成两类结果：物承担材料表达，律承担模式表达，即物的运动模式；在沉积场中，这种模式进一步表现为已经形成并能够承担续行的关系组织。

这里要避免一个严重误读：物不是外部世界预先给定的材料。物本身也是系统在物化中生成、压缩、组织出来的材料表达；律则是同一次物化中取得的模式表达。所以不能写成"外部先有物，沉积场后来再学习它的规律"，也不能写成"先有物，之后律才附着其上"。

　　物与其律的共同生成，即为物化。

物化发生于自显场之中；这里先说明物化结果的构成，第三层再说明这些生成在三场中的不同沉积职责。

\*\*第二层　生律层\*\*

第一层说明的是物化结果的构成关系；本层说明的是其中"律"这一模式表达，在沉积场一侧凭什么已经取得当前成立资格，以及这一资格所对应的迹应—沉积—成形—进入当前—承担后来之结构次序。二者描述的是同一生成事实的不同问题层级，不是两次生律。

就这一当前成立资格而言，其结构形成次序表现为：

　　外部作用发生迹应；  
　　迹应进入沉积；  
　　反复迹应塑成关系结构；  
　　已成关系进入当前；  
　　已成关系承担后来续行；  
　　沉积场由此可以用既成模式组织后来因应。

律因此处在"留下过去的作用"与"用既成模式组织后来因应"之间的关键桥位。迹应不是直接变成因应；中间隔着沉积、成形与进入当前这几步。

等到观者生成以后，已经发生在场中的因应关系才进一步能够被识出、区分和表述。

\*\*第三层　三场层\*\*

在自显场中，三场各自沉积不同内容：

　　意象场——沉积物的意象，即材料表达在自显场中的意象组织；  
　　经验场——沉积律，即已经形成的模式、续行关系与经验结构；  
　　意图场——沉积理。

理不是另一种律，而是在已有律的基础上进一步生成的择、偏、破、改之结构。母本关系保持为：律者，持、复；理者，择、偏、破。

\*\*第四层　后续生成与运行层\*\*

生成层面：律先形成，理以律为基础生成。律既是理生成的基础，也是自显性生成的基础。

运行层面：理可以驱动既有之律运行。

例如，感知经验本身是一种律；意图场之理驱动这条律运行，使其调谐意象场中的当前信号、形成阻抗，并由此命出物的意象。此处理不直接命物，也不直接调谐信号；被驱动的是感知经验这条律。

这只是运行关系的一个具体例子，不是律与理关系的总定义：不得据此认为所有律都是感知律，或所有理都以命物为目的。理如何选择某一条律、如何驱动、驱动接口是什么、不同理之间如何竞争、律被驱动后的完整动力机制，本组一律不证明。

\*\*第五层　证明边界\*\*

第四层所说"律是理与自显性生成的基础"，只表示\*\*生成资格上的前置关系\*\*，不是充分因果关系。不能写成"律一旦成立，理和自显性就必然生成"。前述共同生成关系（第一层）、场内职责关系（第三层）与运行关系（第四层之运行面）仍分别按本节末的关系类型申明理解，不得并入此前置关系。本组采用的只是更严格的前置表述：

　　一个还不能生律、还不能用既成模式组织后来因应的场，尚未取得继续生成理与自显性的前置资格。

物化、三场分工、理驱动律与感知经验之例，均来自《自显论》既有理论，本总图只用它们说明《律组式》在全书中的体系位置，不把任何一项扩写成本组新的待证命题，也不因此扩大 Q\_LawSuite。八篇自身所证明的范围，仍然严格限定在 1.4 冻结的 Q\_LawSuite 之内。

\*\*关系类型申明\*\*　上列关系至少分四类，各有不同的逻辑类型，不得互相替代：

　A　共同生成关系：物化 → 物 + 律。  
　B　前置资格关系：律 → 理进一步生成的基础；律 → 自显性进一步生成的基础。  
　C　场内职责关系：意象场 → 物的意象；经验场 → 律；意图场 → 理。  
　D　运行关系：理 → 驱动既有之律运行。感知经验之例属 D 的一个实例。

不得写成"物化 → 物 → 律 → 理 → 自显 → 感知"这样一条链：那会把四种不同逻辑类型错误地压成同一种充分因果箭头。

\*\*工程位置\*\*　这也说明了《律组式》八篇的位置：如果还不能说明什么才算律、怎样把律的资格形式化、怎样构造能够生律的沉积场、怎样判定它是否已经取得律资格，以及这种资格怎样保持、在哪里失去，就还没有得到一个足以继续研究理与自显生成的沉积场基础。所以对《自显论》的工程路线来说，构造一个真正能够生律的沉积场，是继续研究理与自显生成的前置工作之一。

### 1.4　组级职责域

　　Q\_LawSuite：对\*\*预先给定\*\*的候选律 L，建立它的结构资格、形式表示、运行实现、可执行判定、稳定保持和成立边界的完整理论。

### 1.5　组式定种

正式定种：\*\*理论组式\*\*，不是组织组式。

理由有两条。

第一，本组取得了组级理论闭合。Law 的双向刻画（第三节）不是任何单篇的结论：必要向属于 G1，充分向属于 G7，两者合成的双向闭合不能由任一成员独立取得，只在组级取得；成员中转述的合成双向式，仍依赖必要向与充分向的跨篇合成。

第二，最小完备性已经检验。CurrentMinimal 与 CurrentComplete 的逐项检验见第四节，合起来得到 CurrentMinimalComplete(𝒢\_Law \| Q\_LawSuite)。

组织组式的成员之间只有编排关系，组图只起组织作用；理论组式则要求成员共同取得单篇不能独立取得的组级结论，并完成职责最小性和完备性检验。本组两项都具备，所以定为理论组式，本总图是它的组级证明文件，不只是目录。

### 3.4　组级主闭合

　　C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3 ∧ SC\_Hold  
　　⇒ \[ Law\_F,t(L,I) ⇔ ∃R( Established\_F,t(R) ∧ Govern\_F,t(L;R,I) ) \]

　　Law\_F,t(L,I) ⇔ ∃R\[ Established\_F,t(R) ∧ DynamicRole\_F,t(L;R,I) ∧ ΩSupport\_F,t(L;R,I) \]（在上面的前件之下）。

### 3.5　状态分记

　必要向：Conditional，条件 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3。  
　充分向：Conditional，条件 SC\_Hold。  
　组级双向闭合：Conditional，条件 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3 ∧ SC\_Hold。

### 4.4　最小完备

　　CurrentMinimalComplete(𝒢\_Law \| Q\_LawSuite) ⇔ CurrentMinimal ∧ CurrentComplete。

由 4.1 和 4.3 得到。读法是：\*\*在当前已经冻结的 Law 资格系统职责域内，八项职责都不能删，并且没有同层职责遗漏，所以当前八篇构成最小完备组。\*\* 这不是关于绝对篇数最小性的断言（4.2）。

### 6.4　条件路由纪律

　\*\*纪律一（不得逆向回灌）\*\*　下游的形式桥和判定条件，不得反向成为上游结构本体定理的前件。例如：Read / Rep 各桥不得成为 G1 必要向的前件；G6 的协议 PR1–PR4 不得成为 G2 或 G7 的前件；G5 的构造结果不得成为 G7 充分向的前件。  
　\*\*纪律二（分支局部传播）\*\*　条件只沿实际依赖路径传播：

　　　H\_i 传播到 T\_j，当且仅当 T\_j 的证明路径实际使用了 G\_i 中受 H\_i 保护的输出。

　　如果 T\_j 另有一条独立的 Established 路径绕开那个输出，H\_i 就不向 T\_j 传播。G8 的定理 4.1 就是这种情况：它的路径经过 G7 而不经过 G1 的必要向，所以不携带 H\_G；它携带的是 G7 自己的 SC\_Hold。

三栏的区别一句话说清：A 栏是欠证明，B 栏是划范围，C 栏是设靶子。

## 第九节　总图压缩

\*\*体系位置压缩\*\*（非组级定理，只述位置）

在更上游的生成关系中，物化共同生成物与律：物承担材料表达，律承担模式表达。律在沉积场中成为组织后来因应的已成模式，并进一步成为理与自显性生成的基础。物化发生于自显场之中：意象场沉积物的意象，经验场沉积律；意图场则在已有律的基础上沉积理。理还可以在具体运行中驱动既有之律。感知经验是一种律，它被意图场之理驱动而参与命物，只是这种运行关系的一个具体例子。
