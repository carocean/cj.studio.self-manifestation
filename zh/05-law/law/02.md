# 律数理式

## 第一节　目的

结构输入：S = 《律一般式》。形式输出：M = 本篇律形式系统。本篇为映射 S ↦ M。

S 给出的结构为：

　　Law\_F,t(L,I) ⇒ ∃R \[ Established\_F,t(R) ∧ Govern\_F,t(L;R,I) \]，  
　　Govern\_F,t(L;R,I) ⇔ DynamicRole\_F,t(L;R,I) ∧ ΩSupport\_F,t(L;R,I)。

其分量为：Rel(L)、CurrentCarrier、CarrierRealizes、CarrierNonInstant、Established、DynamicRole、StableReplay、ΩSupport、Govern。

本篇在《场数理式》v2.6 的沉积场上为上述分量建立形式判据、静力关系、求解程序、耦合与回读规则，并承担 S 之 H3（冗余动力职责客观真值）的形式化。

本篇不重证 ∃R(Established ∧ Govern) ⇒ Law；该充分向已由《律必然式》 建立（主充分向 Status = Established），本篇只提供形式解至结构层的表示与回读接口（6.3）。本篇亦不重证 S 的必要性，不作实例判定（归《律判定式》）。

## 第二节　核心论题

S 的结构分三层：结构承载层（场中已有完整关系承载结构）、动力承担层（该结构真实进入后来生成）、再入承担层（再入时由已成结构继续承担并由 Ω 支撑）。三层共享职责体系与实现体系，使用不同评价上下文。

本篇须精确表达：

　(1) Established 的形式见证：完整承载在当前场中的存在与非即时性；  
　(2) DynamicRole 的形成态判据：不以当前输入为前提，区分热冗余、结构冷备用、结构截断、时序截断、纯相关与多级参与；  
　(3) StableReplay 的再入判据：承担段须已成且在当前 R 内，接入段可由入流即时重建；  
　(4) ΩSupport 的稳定支撑判据：在再入实现的承担段上评价既有 Ω；  
　(5) Govern 的耦合：DynamicRole 与 ΩSupport 的见证须属于同一 Rel(L) 实现家族，不得跨实现串证。

形式方向分正向回读 M ⇒ S 与反向表示 S ⇒ M，二者强度不同。

### 3.2　生成与评价

定义 3.5〔辅〕（局部生成函数）　对可生成量 y，y = G\_y(a₁,…,a\_m)，Arg(y) = {a₁,…,a\_m}。G\_y 保持局部层级，不作代入消元。

定义 3.5′〔辅〕（局部生成核）　对可生成量 y，实现给出局部生成核 K\_y(· \| A\_y)：A\_y 为该生成步实际读取的输入集，K\_y 为在 A\_y 取值下 y 的生成分布。确定生成为特例 K\_y = δ\_{G\_y(A\_y)}，此时 A\_y = Arg(y)。K\_y 是生成规则的形式接口：softmax 只是某一实现对 K\_y 的具体取法。

例 3.1　Y = A ∨ Z，Z = ¬A ∧ B。Arg(Y) = {A,Z}。代入得 Y = A ∨ B 则 Arg 被错写为 {A,B}，B 在 A = 1 时已被 Z 截断却被判为进入 Y。

定义 3.6〔辅〕（赋值环境）　ν 为覆盖所考察局部生成函数及其上游量的一组相容取值；当前实际赋值 ν\_t，ν\_t(a) = val\_t(a)。

定义 3.7〔辅〕（评价上下文）　Ctx = (B, c, σ, m)：B ⊆ 𝔘\_t 为可使用的结构底本；c 为外部条件（入流到来、职责前件等，不属于 B 的结构变量）；σ 为对 B 内量的部分固定赋值；m ∈ {inject, fixed} 为评价模式。Eval(Ctx) 为满足以下条件的 ν 全体：c 成立；σ 所固定的量取 σ 值；不受 c、σ 影响的 B 中既有量保持其值；受影响的量按局部生成函数重算，B 外结构变量不可用；所有局部生成关系相容；m = inject 且 c 含入流到来时，入场动力按《场数理式》入场规则在 B 之上生成即时结构，其解作为 ν 的一部分；m = fixed 时 c 只作为已成立的外部条件（其真值与已选分支保留），不执行入场生成，B 外的即时结构不得由 c 再生。Eval(Ctx) 可含多个元素。简记 Eval(B,c,σ,m) := Eval((B,c,σ,m))。inject 只用于 3.13 初次生成 ν；此后一切上下文均为 fixed。

背景投影：对赋值 ν 与 (B,c)，BaseFix\_{B,c}(ν) 为 ν 在“不受 c 影响而应保持”的 B 内既有量上的限制；受 c 影响的生成量不在其中。凡 σ 位写入某个完整赋值 ν 处，一律指 BaseFix\_{B,c}(ν)，不得把 ν 整体固定：否则 Eval(Ctx) 退化为单元素集，定义 3.10 之极小充分组对 C = ∅ 亦满足 (i)，ActArg 塌为 ∅。

定义 3.7′〔辅〕（评价测度）　对上下文 Ctx，评价测度为概率空间

　(Eval(Ctx), Σ\_Ctx, μ\_Ctx)，

满足 μ\_Ctx(Eval(Ctx)) = 1。μ\_Ctx 由实现所给局部生成核按时间展开生成次序复合诱导，并与《场数理式》优先续行规则（方程 4）在该实现下一致。

对普通顺序生成节点 y\_j，使用条件核 K\_{y\_j}(· \| A\_{y\_j})。对定义 3.8 的同刻联合节点 Z\_τ，实现必须直接给出联合生成核 K\_Z(· \| A\_Z)；仅在实现已经申报合法条件分解或条件独立结构时，才允许由成员核按该分解复合。成员边际核本身不唯一决定联合核；若某联合节点不能给出唯一合法 K\_Z，则 μ\_Ctx 不唯一，M3 不满足，该实例在 M 中记为不可判（⊥），不得任取一种耦合作为 μ\_Ctx。

Eval(Ctx) 有限或可数离散时，

　μ\_Ctx({ν}) = ∏\_j K\_{y\_j}(ν(y\_j) \| ν(A\_{y\_j}))

其中乘积按时间展开的普通节点与已声明分解的联合节点取相应因子，并有

　Σ\_{ν∈Eval(Ctx)} μ\_Ctx({ν}) = 1。

一般情形不以单点概率和定义 μ，而以概率空间及核复合定义。

μ 自 K 诱导，不由观察数据反推；μ\_Ctx 由实现所给 K 与 Ctx 唯一诱导，为评价上下文的生成测度，不依 Rel(L) 或 Type(d) 而改变。Type(d) 申报 Read 泛函、D、ε\_role、成立阈值及其他职责内部读取条件；EvalMode(d) 的外层 set/measure 解释依定义 3.14、3.16′处理。若 Read/PreRealized 本身要求全支撑、概率阈值或其他更强条件，该要求只属于职责内部成立条件，不改变外层结构量词；(K,Ctx) ↦ μ\_Ctx 与 Type(d) ↦ 读取规则两层分开。EvalMode(L,i)=set 时，合法评价是否为零测不改变普通 ∀/∃ 的集合语义；只有 EvalMode(L,i)=measure 时，μ\_Ctx 才参与外层 a.e./正测度读取。μ\_Ctx 的可求性列入 M3。

定义 3.8〔辅〕（时间展开生成图）　节点 (y,τ)；若 u 进入 y 的生成，记 (u,τ) ↝ (y,τ+Δ)，Δ \> 0。同刻联立互依的量合为联合节点 Z\_τ，其合法取值为联立方程之解；无解者不属于 Eval，多解者各解分别属于 Eval。物理环 A → B → A 的时间展开无环，故不设无环假设。

定义 3.9〔辅〕（宿主支撑）　生成图节点按类型分为四种，每种节点 z 的 Hosts(z) ⊆ 𝔘\_t 为承载该节点的结构成分集：(a) 结构状态节点，即某成分 u 的场量取值（δ(u)、θ(u)、κ(u)、S(u) 等），Hosts = {u}；(b) 有宿主的中间生成量，即《场数理式》局部动力方程中归属于某成分 u 的中间量（如 u 的续行势、门控输出），Hosts = {u}；(c) 联合节点 Z\_τ = (z₁,…,z\_n)，Hosts = ⋃\_k Hosts(z\_k)；(d) 无结构宿主的纯计算量、纯输出读数与 Read(d)，Hosts = ∅。每个生成图节点须在 M3 的生成函数刻画中被归入且仅归入一类；不存在第五类。Hosts 描述节点由哪些成分承载，不是其因果祖先集：(b) 类节点即使由多个上游成分的状态生成，其 Hosts 仍只为宿主 u。对任意生成图节点集 Z，Comp(Z) = ⋃\_{z∈Z} Hosts(z)；路径 π 视为其节点集时，Comp(π) 为此定义的特例。

定义 3.9′〔辅〕（合法反事实变动族）　对上下文 Ctx、可生成量 y 与其局部输入集 U\_y（确定生成取 U\_y = Arg(y)，权重型、分布型生成取 U\_y = A\_y），先定合法反事实族

　AdmVar\_Ctx(U\_y) ⊆ ∏\_{a∈U\_y} Dom(a)。

其元素为在保持该实现的结构方程、《场数理式》的场约束、联立约束、共享资源约束与各量类型约束之条件下，该局部生成关系允许比较的合法反事实联合取值。联合节点按联合取值处理，不拆为互不相容的独立赋值；不得含以直接赋值伪造本应由上游生成才能取得的状态组合。

此处反事实置值只用于形式比较，不要求实例具有物理操纵接口。某量是否进入生成是本体事实；能否直接操作该量是判定能力，二者不得混同。

对结构状态量，AdmVar 可含其合法反事实取值，不限于 Eval(Ctx) 中被 BaseFix 固定的当前值；对生成量，AdmVar 限于结构取定后与生成方程相容的值。类型域仅为外边界：

　AdmVar\_Ctx(U\_y) ⊆ ∏\_{a∈U\_y} Dom(a)，

一般不取等号。

对

　C ⊆ {(a,ν(a)) \| a ∈ U\_y}，

定义

　Var\_C^Ctx(y;U\_y)  
　\= {v ∈ AdmVar\_Ctx(U\_y) \| v 与 C 在 C 所涉各输入上一致}。

实例层可另申报可操作子族

　OperableDo\_Ctx(U\_y) ⊆ AdmVar\_Ctx(U\_y)，

仅供《律判定式》使用。若 OperableDo 不足以覆盖某形式判据所需比较，判定输出为 ⊥，不得据此把 ActArg 或 ActArg^μ 改判为 0。AdmVar 的可刻画性列入 M6。

定义 3.10〔辅〕（承担自变量）　对 Ctx 与 ν ∈ Eval(Ctx)，u ∈ ActArg\_ν^Ctx(y) 当且仅当存在

　C ⊆ {(a,ν(a)) \| a ∈ Arg(y)}

使：

　(i) 凡 ν′ ∈ Var\_C^Ctx(y;Arg(y))，均有 ν′(y) = ν(y)；  
　(ii) (u,ν(u)) ∈ C；  
　(iii) 去掉 (u,ν(u)) 后余下条件不再满足 (i)。

本定义使用 3.9′ 的合法反事实族，不以 Eval(Ctx) 中被 BaseFix 固定的当前结构状态作为反事实全集。

定义 3.10′〔辅〕（μ-充分组与分布承担自变量）　对权重型、分布型职责，Rel(L) 随 Type(d) 申报生成职责分辨度 ε\_role ∈ \[0,1) 与分布差异量 D（默认全变差距离）；ε\_role 与 Read(d) 的成立阈值分层申报。

候选集为 A\_y，即局部生成核 K\_y 实际读取的输入集；与 y 相关而不被 K\_y 读取的量不在候选集内。

对 ν ∈ Eval(Ctx) 与

　C ⊆ {(a,ν(a)) \| a ∈ A\_y}，

C 为 μ-充分，当且仅当对任意两个完整合法联合赋值

　v,v′ ∈ Var\_C^Ctx(y;A\_y)，

均有

　D(K\_y(· \| v), K\_y(· \| v′)) ≤ ε\_role。

Var\_C^Ctx(y;A\_y) 的元素已经是 A\_y 上与 C 一致的完整联合赋值，故本定义不再把它重复拆成 do(C) 与 rest。形式反事实资格完全由定义 3.9′ 的 AdmVar 决定，不要求实例具有相应物理操纵接口。充分性以 K\_y 的生成分布作合法反事实比较，不以观察条件分布判定。

若 A\_y 有限，则 μ-充分性对 C 的扩大单调，极小 μ-充分组存在。一般无限输入情形若极小组存在性或可求性不能保证，则 M6 不满足，该实例记为 ⊥。

定义

　u ∈ ActArg^μ\_ν(y)

当且仅当存在极小 μ-充分组 C 使 (u,ν(u)) ∈ C。

本定义判的是 u 是否属于当前评价下至少一个极小 μ-充分生成组，不要求 u 单独为 but-for 必要条件。热冗余承担者可以分别属于不同极小充分组。

权重型、分布型职责下，3.11 的 Chain 及其后引用 ActArg 的对象一律改引 ActArg^μ；确定型、存在型职责仍用 3.10。

定理 3.10′.1（退化一致性）　若 G\_y 为确定函数，K\_y = δ\_{G\_y(A\_y)}，A\_y = Arg(y)，且 0 ≤ ε\_role \< 1，则

　ActArg^μ\_ν(y) = ActArg\_ν^Ctx(y)。

证明　点测度间的全变差距离只取 0 或 1。故 C 为 μ-充分，当且仅当对同一合法反事实族 Var\_C^Ctx(y;Arg(y)) 中所有剩余输入变化，y 的取值不变；这正是定义 3.10(i)。两定义使用同一候选输入域与同一 Var，极小性条件亦同，故二者相等。□

勘误　v1.1 之 3.10(i) 写作「凡 ν′ ∈ Eval(Ctx)」。因 BaseFix 可把结构状态固定在 Eval(Ctx) 的全部元素上，按该字面结构状态可能永不进入 ActArg，与 DynamicRole 的职责语义相悖。本版将确定型 ActArg 的反事实量化域统一改为定义 3.9′ 的 Var\_C^Ctx(y;Arg(y))。这是对 v1.1 的实质勘误，不宣称 v1.1 字面 ActArg 与 v1.2 ActArg 逐项相等。

本版删去 GenEffect；主链保持

　K\_y → μ\_Ctx → ActArg^μ

以及确定退化

　K\_y = δ\_G → ActArg^μ = ActArg。

若《律判定式》需要额外作用量，另立定义与有效性证明，不在本篇预置。

定理 3.10′.2　确定生成下，以 ActArg^μ 替换 ActArg 后，Chain、FullChain、RolePath、RoleReal、DynamicRole^M 逐一不变。  
证明　各对象只经 ActArg 引用生成职责，由定理 3.10′.1 逐节点相等。□

例 3.2（三情形）　热冗余 y = A ∨ B，ν 中 A = B = 1：{A} 极小 μ-充分，{B} 亦然，故 A、B ∈ ActArg^μ。结构冷备用 Z = ¬A ∧ B，ν 中 A = 1：{A} 极小 μ-充分且 B 不属任何极小 μ-充分组，B ∉ ActArg^μ，虽 B ∈ A\_Z 被读取。时序截断：y\_{t+Δ} 的生成核只读 A\_t，C ∉ A\_{y\_{t+Δ}}，C ∉ ActArg^μ。三者与 v1.1 判定一致；若以 A\_y 本身作 ActArg，冷备用 B 将进入 Chain，冷备用排除须另在 RolePath 或 DynamicRole 处重设，即回到本定义。

定义 3.11〔辅〕（生成链）　Chain\_ν^Ctx(y) 为目标节点 y 及由 ActArg\_ν^Ctx(y)（权重型、分布型职责下为 ActArg^μ）出发沿生成图逐级前溯所得的承担节点全体；遇联合节点以整体前溯。y ∈ Chain\_ν^Ctx(y) 恒成立。HypChains(y \| Ctx) = {Chain\_ν^Ctx(y) \| ν ∈ Eval(Ctx)，Ctx 之 c 在链的有效前件路径上}。

### 3.3　候选律、适用域与职责

定义 3.12〔辅〕　候选承载组织 R ⊆ Existing\_t，可为单一、分布、冗余、协同或组合结构。适用域 I ⊆ 𝒫\_t，I ≠ ∅，判定前给定，不得事后缩小。I 为预声明适用覆盖域（《律一般式》）；其中真正承担覆盖义务者为适用覆盖守卫域 I\_cov(L,I)（3.15′），亦于判定前由 Rel(L) 之职责声明固定，同样不得事后缩小。

定义 3.13〔辅〕（入流评价）　对 i ∈ I（评价族按 I 全域构造，判据量化另限于 I\_cov，见 3.15′）：

　角色评价族　RoleEval(i) = Eval(Existing\_t, i 到来, ∅, inject)；  
　再入评价族　ReplayEval(i) = Eval(Estab\_t, i 到来, ∅, inject)。

对 ν 属于二者之一，Inst(i,ν) 为 ν 中由入场动力在底本之上生成的即时结构成分集，满足：(i) 只来自既有入场动力，不含为使 Rel(L) 成立而补造的结构；(ii) 不含稳定承担结构。多解时不同 ν 可对应不同 Inst(i,ν)。记 RoleBase(i,ν) = Existing\_t ∪ Inst(i,ν)，ReplayBase(i,ν) = Estab\_t ∪ Inst(i,ν)；实现域 X^Role\_{i,ν} = R ∪ Inst(i,ν) ⊆ RoleBase(i,ν)，X^Replay\_{i,ν} = (R ∩ Estab\_t) ∪ Inst(i,ν) ⊆ ReplayBase(i,ν)。R 中未成成分不进入再入实现域。

定义 3.14〔S〕　Rel(L) 为候选律 L 的关系内容索引，给出职责族 𝒪(Rel(L)) = {d\_α}。每个职责 d 带：前件条件域 Ante(d)（职责在何种情形下适用）；关系前项 Anchor(d)（该关系所关联的结构状态量集，即关系由何状态出发）；后继描述类型 Type(d)；读出函数 Read(d)（关系后项）。Anchor(d) 中的量须为结构成分的状态量，不得为入流本身。Val(d) = {ν \| ν ⊨ Ante(d) 且足以评价 Read(d)}。Rel(L) 另给出适用约束 Cov(L)，规定其声称覆盖的场状态情形。

Type(d) 除后继描述类型外，须申报 EvalMode(d)∈{set, measure}。set 表示按合法评价集合读取；measure 表示按定义 3.7′ 的生成测度读取。Read(d) 的概率、期望、阈值等整体泛函仍属于职责内容本身，不改变下列外层量词极性。

对任一 i∈I\_cov(L,I)（I\_cov 见定义 3.15′，依赖链为 Rel → Trig → I\_cov → Adm/ReplayAdm → ModeSet；本款按该链读取），定义其联合职责族在角色与再入评价域上的外层模式集合（I∖I\_cov 之条件不触发职责，不参与模式判定）：

　ModeSet(L,i)  
　\=  
　{ EvalMode(d) \|  
　　ν∈Adm(L,i)∪ReplayAdm(L,i)，  
　　d∈D\_{i,ν} }。

局部诊断量仍可记：

　ModeConsistent(L,i,ν)  
　⇔ ∀d,d′∈D\_{i,ν}：EvalMode(d)=EvalMode(d′)。

但 ModeConsistent 只用于定位单一评价内部的模式冲突，不承担定义 EvalMode(L,i) 的职责。

定义 MixedMode(L,i) 的三值闭包：

　MixedMode(L,i)=0，若 \|ModeSet(L,i)\|=1；  
　MixedMode(L,i)=1，若 \|ModeSet(L,i)\|\>1；  
　MixedMode(L,i)=⊥，若 ModeSet(L,i)=∅。

当 MixedMode(L,i)=0 时，把 ModeSet(L,i) 的唯一元素定义为：

　EvalMode(L,i)=the unique element of ModeSet(L,i)。

当 MixedMode(L,i)=1 时，同一 i 的联合职责族在不同合法评价之间发生 set/measure 漂移，相关 Type-sensitive 量词及其依赖的全局谓词在 M 中记为 ⊥；不得任取一种模式，也不得自行拼接混合量词继续求值。

当 MixedMode(L,i)=⊥ 时，不定义 EvalMode(L,i)，四个 Type-sensitive 量词均记为 ⊥。若调用这些量词的上游定义已经因 Adm、ReplayAdm 或 D\_{i,ν} 的明确非空资格失败而判为 0，则按本篇三值传播规则以该 0 为最终失败；不得利用空域全称的真空真补造 1。

注　Ante 与 Anchor 是不同内容：前者决定职责何时适用，后者决定关系从哪一状态起承担。同一关系的 Ante 可有粗细不同的等价表述，Anchor 不随之改变。

定义 3.15〔辅〕　Trig(i) ⊆ 𝒪(Rel(L)) 为入流 i 可触发的职责子族。若 Rel(L) 对 i 规定“保持不变”，该结果须显式写为职责进入 Trig(i)。

定义 3.15′〔辅〕（适用覆盖守卫域）　I\_cov(L,I) ⊆ I 为 I 中依 Rel(L) 之预声明职责范围属于 L 实际声称适用覆盖的合法条件全体：

　i ∈ I\_cov(L,I) 当且仅当 Rel(L) 对 i 声称职责，即 Trig(i) ≠ ∅。

四条纪律：

　(a) 先验于实现　I\_cov 由 Rel(L) 之预声明职责结构经 Trig 固定，必须在 Real、JointReal、ReplayWit、ΩWit、Bind 等实现判定之前确定；Ante 与 Cov 属评价级约束，不决定 I\_cov 之成员资格（见 (d)）。严禁以实现成败定义之：i ∈ I\_cov ⇔ Adm(L,i)≠∅、⇔ ReplayAdm(L,i)≠∅、⇔ 相应见证存在，皆为非法；否则即成“因该条件失败故宣布其不适用”，违《律一般式》“不得见反例后缩域”。属于 I\_cov 之条件若其 Adm、ReplayAdm 为空、Mass=0 或职责域失败，须照常判该项失败，不得因此把它移出 I\_cov。  
　(b) 空与不可判分离　Trig(i)=∅ 只在“Rel(L) 本来就不对 i 声称职责”时才使 i ∉ I\_cov。若 Trig(i) 因职责编码缺失、不可判或 M4 信息不足而无法确定，则 i 之归属记 ⊥，相应依赖 I\_cov 的形式项按三值传播记 ⊥，不得静默排除。  
　(c) 纯形式辅助　I\_cov 为〔辅〕类对象，不新增 S 层本体谓词，不回读；它只是把《律一般式》 之“适用覆盖守卫”在 M 层显式化。

　(d) 声明级与评价级分层　I\_cov 判定「该入流条件是否被 L 声明承担至少一项职责」，属声明级适用性；Cov(L)、Ante(d) 则在已进入 I\_cov 的条件下限定哪些评价与职责实例合法适用，属评价级适用性。Cov 与 Ante 不重新决定某 i 是否属于 I\_cov；评价级失败不得反向修改声明级守卫域。

　单调性　由本定义直接得：若 I ⊆ J，则 I\_cov(L,I) ⊆ I\_cov(L,J)。因成员资格只由 Trig(i) ≠ ∅ 决定，与 I 的大小及实现成败无关。下游《律边界式》之单 R 域凸性依赖此性质（该篇 K-B5 为其击穿口）。

　I\_cov(L,I) ≠ ∅ 为下列各覆盖型判据之显式前件，见 3.35、3.39。

定义 3.16〔辅〕（评价域）

　Adm(L,i) = {ν ∈ RoleEval(i) \| ν ⊨ Cov(L)}；AdmPair(L,I) = {(i,ν) \| i ∈ I, ν ∈ Adm(L,i)}；  
　ReplayAdm(L,i) = {ν ∈ ReplayEval(i) \| ν ⊨ Cov(L)}；ReplayPair(L,I) = {(i,ν) \| i ∈ I, ν ∈ ReplayAdm(L,i)}。

Adm(L,I) = ⋃\_i Adm(L,i) 仅为记号，不承担判据量化。AdmPair(L,I) 与 ReplayPair(L,I) 按 I 全域构造，为对象集记号；凡结构谓词之判据量化一律以 3.15′ 之 I\_cov(L,I) 为域（同域约定，3.46）。若某判据或定理以 (i,ν) ∈ AdmPair / ReplayPair 作全称，其 i 亦须先限于 I\_cov，写作 (i,ν) ∈ AdmPair 且 i ∈ I\_cov。

定义 3.16′〔辅〕（评价模式、适用测度与 Type-sensitive 量词）　对 i∈I，记（本定义按 I 全域给出量词算子；各结构谓词调用时其 i 限于 I\_cov，见 3.15′、3.46）：

　RoleSeedCtx(i)=(Existing\_t, i 到来, ∅, inject)，  
　ReplaySeedCtx(i)=(Estab\_t, i 到来, ∅, inject)。

若相应普通局部核与联合核按定义 3.7′ 唯一诱导生成测度，则记

　μ\_i^Role=μ\_{RoleSeedCtx(i)}，  
　μ\_i^Replay=μ\_{ReplaySeedCtx(i)}。

在所需集合可测且测度可求时，定义

　RoleMass(L,i)=μ\_i^Role(Adm(L,i))，  
　ReplayMass(L,i)=μ\_i^Replay(ReplayAdm(L,i))。

当 RoleMass(L,i)\>0 时，定义条件适用测度

　μ̄^Role\_{L,i}(A)=μ\_i^Role(A∩Adm(L,i))/RoleMass(L,i)。

当 ReplayMass(L,i)\>0 时，定义条件适用测度

　μ̄^Replay\_{L,i}(A)=μ\_i^Replay(A∩ReplayAdm(L,i))/ReplayMass(L,i)。

若测度本身不能唯一给出、所需集合不可测或相关测度运算不可求，则依赖该测度的形式项记为 ⊥；这不是测度为 0。RoleMass=0 或 ReplayMass=0 是已定义的数学事实，不得与 ⊥ 混同：此时条件测度无定义，约定 measure 模式量词取空域值——∀^{Role}\_{L,i}\[P\]=1（真空）、∃^{Role}\_{L,i}\[P\]=0，Replay 同理。真空全称不得单独成立任何覆盖性判据：凡以 ∀^{Type} 为内容的结构谓词（CarrierRealizes、ReplayReady、StableReplay、ΩSupport、Bind）均须另置相应域的非空前件。

为保留各结构谓词原有的量词极性，定义两类 Type-sensitive 量词算子：

　∀^{Role}\_{L,i}\[P\]，　∃^{Role}\_{L,i}\[P\]，  
　∀^{Replay}\_{L,i}\[P\]，∃^{Replay}\_{L,i}\[P\]。

其极性由调用它的结构谓词决定，Type 只决定该极性在评价空间中的解释：

　(a) set 模式：  
　　　∀^{Role}\_{L,i}\[P\]=1 ⇔ ∀ν∈Adm(L,i)：P(ν)；  
　　　∃^{Role}\_{L,i}\[P\]=1 ⇔ ∃ν∈Adm(L,i)：P(ν)；  
　　　Replay 同理，以 ReplayAdm(L,i) 为域。

　(b) measure 模式：仅当相应 Mass\>0 且条件测度可判时，  
　　　∀^{Role}\_{L,i}\[P\]=1 ⇔ μ̄^Role\_{L,i}({ν∈Adm(L,i)\|P(ν)})=1；  
　　　∃^{Role}\_{L,i}\[P\]=1 ⇔ μ̄^Role\_{L,i}({ν∈Adm(L,i)\|P(ν)})\>0；  
　　　Replay 同理。

因此，measure 模式只把“全称”解释为几乎处处，把“存在”解释为正测度存在；它不把 DynamicRole 的存在极性改成全称，也不把 CarrierRealizes、StableReplay、ΩSupport、Bind 的覆盖极性改成存在。Read(d) 自身若要求概率阈值、期望或其他整体泛函，仍在定义 3.21 的实现资格中评价，不由本定义代替。

四个 Type-sensitive 量词只在 \|ModeSet(L,i)\|=1、即 MixedMode(L,i)=0 时定义，并统一读取唯一的 EvalMode(L,i)：

　若 EvalMode(L,i)=set，则按 (a) 的普通 ∀/∃ 解释；  
　若 EvalMode(L,i)=measure，则按 (b) 的 a.e./正测度解释；  
　若 MixedMode(L,i)=1，则四个量词均记为 ⊥；  
　若 MixedMode(L,i)=⊥，即 ModeSet(L,i)=∅，则四个量词亦记为 ⊥；只有调用它们的上游定义已经由明确的非空资格失败项判为 0 时，才按三值传播得到最终 0。

因此，同一 i 的全部合法角色/再入评价共同要求唯一外层评价模式；不仅禁止同一 ν 内部混合，也禁止不同 ν 之间发生 set/measure 模式漂移。不同 i 之间仍可采用不同模式。

四个量词算子的值域均为 {1,0,⊥}。只有 MixedMode、依赖的测度、可测性或运算不可判时才取 ⊥；已定义而量词条件失败时取 0。

定义 3.17〔辅〕（职责域）　D\_{i,ν} = Trig(i) ∩ {d \| ν ⊨ Ante(d)}。全文职责量化一律用 D\_{i,ν}。

定义 3.18〔辅〕（上下文）　对 (i,ν) ∈ AdmPair：RoleCtx(i,ν) = (RoleBase(i,ν), i 到来, BaseFix(ν), fixed)。对 (i,ν) ∈ ReplayPair：ReplayCtx(i,ν) = (ReplayBase(i,ν), i 到来, BaseFix(ν), fixed)。BaseFix 的 (B,c) 由各自底本与条件给出。Inst(i,ν) 已由 ν 选定并进入底本，fixed 模式下不再由 c 重生。于是 ν ∈ Eval(RoleCtx(i,ν))，且 Eval(RoleCtx(i,ν)) 保留受 i 影响的生成量之全部合法变化，ActArg 在此域上计算。对 P ⊆ B 与上下文 κ = (B,c,σ,fixed)：受限上下文 Restrict(κ,P) = κ\_P = (P, c, σ\|\_P, fixed)；c 的真值与已选分支保留，P 外结构变量（含 Inst(i,ν) ∖ P）不可用且不得由 c 再生。受限评价见证 ResEval(κ,P,ν) = {η ∈ Eval(κ\_P) \| η 与 ν 在 σ\|\_P 所固定的背景量及 c 之已选分支上一致}。全场赋值 ν 一般不属于 Eval(κ\_P)（P 外变量删去后受影响量须重算），故一切 P 受限运算以 η ∈ ResEval(κ,P,ν) 为链见证，不直接使用 ν。

定义 3.19〔辅〕（三层链）　StructChains(d,ν) = HypChains(Read(d) \| (Existing\_t, Ante(d), BaseFix(ν), fixed))；ActChain\_t(d) = Chain\_{ν\_t}^{(Existing\_t, 当前入流, BaseFix(ν\_t), fixed)}(Read(d))（ν\_t ⊨ Ante(d) 且链经 d 的前件路径，否则为 ∅）；ReplayChains(d \| i,ν) = Chain\_ν^{ReplayCtx(i,ν)}(Read(d))。

定义 3.20〔辅〕　StructBear\_R(d,ν) = R ∩ ⋃\_{χ∈StructChains(d,ν)} Comp(χ)；ActBear\_R(d) = R ∩ Comp(ActChain\_t(d))；NonInstBear\_R(d,ν) = StructBear\_R(d,ν) ∩ Estab\_t。Comp 见定义 3.9。

### 3.4　实现

定义 3.21〔辅〕（预实现）　对上下文 κ=(B,c,σ,fixed)、ν∈Eval(κ)、职责 d、P⊆B：

先定单评价合格。为避免与评价测度 μ 混淆，以下用 η 表示受限评价点。η ∈ ResEval(κ,P,ν) 对 d 合格，当且仅当：

　(iii) Read(d) 在 η 下有定义；  
　(iv) Closed^κ(P,d,η)：  
　　　Comp(Chain\_η^{κ\_P}(Read(d))) ⊆ P；  
　(v) Read(d) 在 η 下满足 d 的关系内容。

记

　Good^κ(d,ν;P)  
　⊆ ResEval(κ,P,ν)

为合格评价集。

实现评价见证族 WitEval^κ(d,ν;P) 由 Type(d) 与 Cov(L) 决定：

1\. 确定型职责：  
　W = ResEval(κ,P,ν)，要求 Good = ResEval。

2\. 存在型职责：  
　W 为 Good 中某单元素集 {η}；不同 η 给出不同见证。

3\. 分布型、权重型职责：  
　W = ResEval(κ,P,ν)，不得取有利子族；  
　要求 W ∈ Σ\_{κ\_P} 且 μ\_{κ\_P}(W) \> 0；  
　Read(d) 的整体读出作用于条件测度

　　μ\_{κ\_P}(· \| W)  
　　\= μ\_{κ\_P}(·∩W)/μ\_{κ\_P}(W)。

　定义正则评价集

　　Reg^κ(d,ν;P)  
　　\= {η∈W \| Read(d) 有定义且 Closed^κ(P,d,η)}。

　默认要求

　　μ\_{κ\_P}(Reg^κ(d,ν;P) \| W)=1，

　即 (iii)(iv) μ-a.e. 成立；若该要求由 Type(d) 的 Read/PreRealized 内部条件明确申报，可加强为 Reg=W；该加强只改变职责内部实现资格，不改变定义 3.16′ 的外层量词极性及其 set/measure 解释。关系内容 (v) 则由 Read(d) 对条件测度 μ\_{κ\_P}(·\|W) 的整体泛函值判定。

μ\_{κ\_P}(W)=0 时 (P,W) 不构成权重型或分布型合法见证。

PreRealized^κ(d,ν;P,W)=1 当且仅当：  
　(i) ν∈Val(d)；  
　(ii) ResEval(κ,P,ν)≠∅；  
　(vi) W 为按上述规则合法的 WitEval^κ(d,ν;P)，W≠∅，并满足对应 Type(d) 的 (iii)–(v) 要求。

W 一经取定即随实现见证贯穿 Bear、Realized、Real、ExtReal、JointReal 与 ReqSeg，不得在后续重新挑选评价子族。

定义 3.22〔辅〕（承担段与接入段）　对 PreRealized^κ(d,ν;P,W)=1 的 (P,W)，逐评价计算，不跨评价拼接路径。

对确定型、存在型职责，令 W°=W。  
对权重型、分布型职责，令

　W° = Reg^κ(d,ν;P)，

于是 μ\_{κ\_P}(W°\|W)=1。

对每个 η∈W°：

　χ\_η = Chain\_η^{κ\_P}(Read(d))。

记 State(z) 为生成节点 z 所对应的状态量。定义 AnchorNodes(d) = {z \| State(z) ∈ Anchor(d)}。若 Anchor(d) 中每一状态量都在 χ\_η 上有对应节点，则 BearEntry\_η 为各 Anchor 状态量在 χ\_η 上的承担前沿；否则 BearEntry\_η=∅。

令 ↝\*\_{χ\_η} 为 χ\_η 内的自反传递闭包，并定义

　BearNodes\_η  
　\= {z∈χ\_η \|  
　　 ∃e∈BearEntry\_η：  
　　 e↝\*\_{χ\_η}z ∧ z↝\*\_{χ\_η}Read(d)}。

确定型、存在型职责取

　BearNodes^κ(P,W,d,ν)  
　\= ⋃\_{η∈W°} BearNodes\_η。

权重型、分布型职责不对 W° 作普通全集并，而取本质承担节点。对每个候选节点 z，事件

　E\_z = {η∈W° \| z∈BearNodes\_η}

须属于 Σ\_{κ\_P}。若某所需 E\_z 不可测，则该实现见证的 Bear 在 M 中记为 ⊥，不得判 0 或 1；若可测，则定义

　BearNodes^κ(P,W,d,ν)  
　\= {z \| μ\_{κ\_P}(E\_z \| W) \> 0 }。

即只有在条件生成测度下以正测度参与承担的节点进入 Bear；零测评价中的异常节点不得在本层重新进入承担结构。

然后

　Bear^κ(P,W,d,ν)  
　\= Comp(BearNodes^κ(P,W,d,ν))，

　Acc^κ(P,W,d,ν)  
　\= P ∖ Bear^κ(P,W,d,ν)。

Bear 仍由 Anchor(d)、W 与各评价中的承担链确定，不跨评价拼接路径，不依赖 Ante 的语言表述，不在本定义中评价 Ω。

实现见证仍为 ρ=(P,W)，Supp(ρ)=P。以 ρ 为参数的对象定义为：

　BearNodes^κ(ρ,d,ν) = BearNodes^κ(P,W,d,ν)，  
　Bear^κ(ρ,d,ν) = Bear^κ(P,W,d,ν)，  
　Acc^κ(ρ,d,ν) = Acc^κ(P,W,d,ν)。

当 ρ = ρ\_d 取自联合实现且 κ、ν 由上下文确定时，简写 Bear(ρ\_d)、Acc(ρ\_d)。

命题 3.1（Bear 对 Ante 表述不变）　设 Ante(d)、Ante′(d) 为同一职责前件的两种等价表述，二者诱导相同的 Val(d)、ResEval 与 WitEval 资格。对任一实现见证 ρ = (P,W)，若同一 W 在两种表述下均为合法 WitEval，则 Bear^κ\_{Ante}(ρ,d,ν) = Bear^κ\_{Ante′}(ρ,d,ν)。本命题不断言同一 P 之不同 W 给出相同 Bear。  
证明　固定 ρ 后，Bear^κ(ρ,d,ν) 只依赖 Anchor(d)、W 与各 η ∈ W° 的 Chain\_η^{κ\_P}(Read(d))；三者均不依赖 Ante 的语言表达（c 含前件成立这一事实而非其表述）。□

例 3.2　g → R\_Ω → Read(d)，P = {g} ∪ R\_Ω，Anchor(d) = R\_Ω 入口的状态量。受限链为 g 的门控状态 → R\_Ω 的状态 → Read(d)；BearEntry 在 R\_Ω 入口；Bear = R\_Ω，Acc = {g}。若 Rel(L) 把 Anchor(d) 定为 g 的门控状态，则 Bear ∋ g；此时该关系以即时门控为前项，不由 R 承担，后文判 0 为正确结果。

定义 3.23〔辅〕（完整实现）　Realized^κ(d,ν;P,W) = 1 当且仅当 PreRealized^κ(d,ν;P,W) = 1 且 Bear^κ(P,W,d,ν) ≠ ∅。对 B′ ⊆ B\_κ：Real^κ\_{B′}(d,ν) = {ρ = (P,W) \| P ⊆ B′，Realized^κ(d,ν;P,W) = 1}。同一 P 可对应多个 ρ；各 ρ 独立进入后续判据，其 Bear、Acc、ReqSeg、RolePath 均以自身之 W 计算。简写：PreRealized^κ(d,ν;P) = 1 ⇔ ∃W PreRealized^κ(d,ν;P,W) = 1；故 PreRealized^κ(d,ν;P) = 0 ⇔ ¬∃W \[PreRealized^κ(d,ν;P,W) = 1\]。

定义序列 ResEval → WitEval → PreRealized → Bear → Realized → Real，无循环；受限评价见证 W 自 PreRealized 起携带至 Bear、Realized、Real 及后续 ExtReal、JointReal、ReqSeg。

定义 3.24〔辅〕（扩展实现）　记 X^κ\_{i,ν} 为 κ = RoleCtx(i,ν) 时的 X^Role\_{i,ν}、κ = ReplayCtx(i,ν) 时的 X^Replay\_{i,ν}；均有 X^κ\_{i,ν} ⊆ B\_κ，故 Real^κ\_{X^κ\_{i,ν}} 有定义。ExtReal^κ\_R(d) = {ρ ∈ Real^κ\_{X^κ\_{i,ν}}(d,ν) \| Bear^κ(ρ,d,ν) ⊆ R ∧ Supp(ρ) ∩ Inst(i,ν) ⊆ Acc^κ(ρ,d,ν)}。

定义 3.25〔辅〕（联合实现）　对 κ、职责子族 D 与 ν，JointReal^κ\_{B′}(D,ν) 为 Π = {ρ\_d}\_{d∈D} 之集合：每个 ρ\_d ∈ Real^κ\_{B′}(d,ν)，各职责共享同一完整评价环境 ν；各 Supp(ρ\_d) 的共享结构、门控、状态、权重、资源相容，各 W\_d 在共享量上一致；全部实现在同一 ν 中同时成立。凡函数只需 d 的局部量，在其内部以投影 ν↾d 读取；ν↾d 不是 Eval(κ) 的元素，不得作为评价环境参数。ExtJointReal^κ\_R(D) 为各 ρ\_d ∈ ExtReal^κ\_R(d) 者。D = ∅ 时 JointReal 取空族 {∅}；本篇各判据以 D ≠ ∅ 为前件（见 ReplayReady）。

定义 3.26〔辅〕　Bear^κ(Π) = ⋃\_d Bear^κ(ρ\_d,d,ν)，Acc^κ(Π) = ⋃\_d Acc^κ(ρ\_d,d,ν)，Q(Π) = Acc(Π) ∪ Bear(Π)；Supp(Π) = ⋃\_d Supp(ρ\_d)；κ 由上下文确定时省略上标。Q\_L^∪ = ⋃{Q(Π) \| Π 为 R 中合法联合实现}（与 S 之 Q\_L 不同，后者对应某具体 Π 的 Bear(Π)）。

### 3.5　界面、接达与 Ω

定义 3.27〔辅〕　E\_B(i) ⊆ B 为 i 可直接作用于底本 B 的部位。

定义 3.28〔辅〕（接达）　Reach\_B(E,P) 当且仅当存在 e ∈ E、p ∈ P，e 可沿 B 内既有结构关系（结构位间续行、结构位—沟线隶属、沟线—端壑交会、沟线—线束从属等）到达 p。接达段不要求 Ω \> 0。

定义 3.29〔辅〕（承担续行段与 Ω 见证）　对 ρ=(P,W)：

对确定型、存在型职责，W°=W；  
对权重型、分布型职责，W°=Reg^κ(d,ν;P)。

对每个 η∈W°，定义单评价承担续行段

　ReqSeg^κ\_η(ρ,d,ν)  
　\= {x ⇝\_t y \|  
　　 x,y ∈ ⋃\_{z∈BearNodes\_η} Hosts(z)，  
　　 且存在 BearNodes\_η 内相邻生成边  
　　 z\_x ↝ z\_y，  
　　 Hosts(z\_x)∋x，Hosts(z\_y)∋y，  
　　 x⇝y 属于 Ω 定义域}。

确定型、存在型职责取

　ReqSeg^κ(ρ,d,ν)  
　\= ⋃\_{η∈W°} ReqSeg^κ\_η(ρ,d,ν)。

权重型、分布型职责取本质承担续行段。对每个候选续行段 x⇝y，事件

　E\_{x⇝y}  
　\= {η∈W° \| (x⇝y)∈ReqSeg^κ\_η(ρ,d,ν)}

须属于 Σ\_{κ\_P}。若某所需 E\_{x⇝y} 不可测，则该实现见证的 ReqSeg 在 M 中记为 ⊥，不得判 0 或 1；若可测，则定义

　ReqSeg^κ(ρ,d,ν)  
　\= {x⇝y \| μ\_{κ\_P}(E\_{x⇝y}\|W)\>0 }。

因此零测评价中的异常续行段不进入 Ω 判据。

定义

　ΩOK^κ(ρ,d,ν)=1

当且仅当

　\[ReqSeg^κ(ρ,d,ν)≠∅  
　 ∧ ∀(x⇝y)∈ReqSeg^κ(ρ,d,ν)：Ω\_t(x→y)\>0\]

或

　\[ReqSeg^κ(ρ,d,ν)=∅  
　 ∧ StableType^κ(ρ,d,ν)=1\]。

Acc 段仍不进入 Ω 评价。

### 3.6　角色对象

定义 3.30〔辅〕（承担状态）　对 ρ 与 u ∈ Bear^κ(ρ,d,ν)：RelState^κ\_ρ(u,d,ν) = {State(z) \| z ∈ BearNodes^κ(ρ,d,ν)，u ∈ Hosts(z)，State(z) 有定义}，即该实现见证的承担节点中归属于 u 的状态量。同一 (κ,d,ν) 下不同 ρ₁、ρ₂（含同一 P 不同 W）的 BearNodes 可不同，故 RelState 以 ρ 为参数。

定义 3.31〔辅〕（全场链）　对上下文 κ ∈ {RoleCtx(i,ν), ReplayCtx(i,ν)}：FullChain^κ(d) = Chain\_ν^κ(Read(d))，按全场评价，不作 P 受限。

定义 3.32〔辅〕（角色路径）　RolePath^κ\_ρ(d) 为生成图上满足以下条件的路径 π 之集合：(i) π 起于某 u ∈ Bear^κ(ρ,d,ν) 的 RelState^κ\_ρ(u,d,ν) 中的状态量；(ii) π 止于 Read(d)；(iii) π 的每条边属于 FullChain^κ(d)；(iv) Comp(π) ⊆ Supp(ρ)。

定义 3.33〔辅〕（角色实在实现）　RoleReal^κ\_R(d) = {ρ ∈ ExtReal^κ\_R(d) \| RolePath^κ\_ρ(d) ≠ ∅}，κ 为该 (i,ν) 的 RoleCtx 或 ReplayCtx。

### 3.7　结构分量的形式表示

定义 3.34〔S〕（CurrentCarrier^M）　组织块：B ⊆ Existing\_t 为组织块，当且仅当 B 为单个合法类型成分，或 B 的成分由下列既有关系相连：结构位—沟线隶属；沟线—端壑交会；沟线—线束从属；结构位间续行 ⇝\_t；同一联合生成块成员。共组织关系 Org\_t(B\_j,B\_k)：B\_j、B\_k 同属一线束或一端壑，或存在合法生成节点 z 使 Hosts(z) ∩ B\_j ≠ ∅ ∧ Hosts(z) ∩ B\_k ≠ ∅，或存在生成节点 z 其局部生成链同时接受来自 B\_j 与 B\_k 之状态量（共同后继），或经 ⇝\_t 链相连。CurrentCarrier^M\_F,t(R) = 1 当且仅当 R ≠ ∅，R ⊆ Existing\_t，R 中每一成分为合法类型且其场量有定义，且 R = ⋃\_{k∈K} B\_k，K ≠ ∅，每个 B\_k 为组织块。不同 B\_k 之间不要求任何 Org\_t 关系。本判据不引用 Rel(L)、职责或 StructBear。

注　S 允许 R 为分布结构：物理分离的 R₁、R₂ 可分别承担同一 Rel(L) 的不同职责。CurrentCarrier 不知职责分工，故不得以连通性预先排除；若干块是否共同构成 Rel(L) 的完整承载由 CarrierRealizes^M 判定。Org\_t 保留为组织描述量，供《律判定式》使用，不作本判据必要条件。

三值求值约定（模式资格）　MixedMode(L,i) 只决定相应 Type-sensitive 量词是否可定义，不作为 CarrierRealizes、CarrierNonInstant、DynamicRole、ReplayReady、StableReplay、ΩSupport、Bind 的普通布尔前件参与合取。MixedMode(L,i)=0 时四个量词按唯一 EvalMode(L,i) 求值；MixedMode(L,i)∈{1,⊥} 时相应量词值为 ⊥。若某性质另有独立于该量词的明确失败项已经判为 0，则决定性 0 覆盖 ⊥；否则 ⊥ 继续向该性质传播。特别地，DynamicRole 保持存在极性：若任一 i 的 ∃^{Role}\_{L,i}=1，则 DynamicRole^M=1；若无任何 1 且至少一个必要候选量词为 ⊥，则 DynamicRole^M=⊥；只有全部可判候选均为 0 时才判 0。

定义 3.35〔S〕（CarrierRealizes^M）　CarrierRealizes^M\_F,t(L;R,I)=1 当且仅当 I\_cov(L,I)≠∅，且对每个 i∈I\_cov(L,I)：角色域非空——EvalMode(L,i)=set 时 Adm(L,i)≠∅，EvalMode(L,i)=measure 时 RoleMass(L,i)\>0——且

　∀^{Role}\_{L,i}\[  
　　D\_{i,ν}≠∅  
　　∧ JointReal^{RoleCtx(i,ν)}\_R(D\_{i,ν},ν)≠∅  
　\]=1。

角色域非空为显式前件：不得由空 Adm(L,i) 上的真空全称取得本判据。I\_cov 非空亦为显式前件：不得由空守卫域上的真空全称取得本判据。I∖I\_cov 之条件不进入本判据之全称——依《律一般式》，不属于 L 适用职责的裸条件不承担覆盖义务；但属于 I\_cov 者若角色域为空，照常判 0。

定义 3.36〔S〕（CarrierNonInstant^M）　CarrierNonInstant^M\_F,t(L;R,I)=1 当且仅当 CarrierRealizes^M=1，且对每个 i∈I\_cov(L,I)（与 3.35 同一守卫域），

　∀^{Role}\_{L,i}\[  
　　∃Π∈JointReal^{RoleCtx(i,ν)}\_R(D\_{i,ν},ν)：Q(Π)⊆Estab\_t  
　\]=1。

定义 3.37〔S〕（EstWitness^M）　EstWitness^M\_F,t(L;R,I)=1 当且仅当 CurrentCarrier^M ∧ CarrierRealizes^M ∧ CarrierNonInstant^M。若必要形式项出现 0，则 EstWitness^M=0；无 0 而至少一项为 ⊥，则 EstWitness^M=⊥。S 之结构谓词为 Established\_F,t(R)；其 H1 前件带 (L;R,I)，故本见证亦带此参数。

定义 3.38〔S〕（DynamicRole^M）　DynamicRole^M\_F,t(L;R,I)=1 当且仅当存在 i∈I\_cov(L,I)，使

　∃^{Role}\_{L,i}\[  
　　∃d∈D\_{i,ν}：RoleReal^{RoleCtx(i,ν)}\_R(d)≠∅  
　\]=1。

这里保留 S 所要求的形成态存在极性；Type 只决定该“存在”是合法存在还是正测度存在。存在量词之域改用 I\_cov 只为与覆盖型判据同域、接口整洁：I∖I\_cov 之条件 Trig(i)=∅ 故 D\_{i,ν}=∅，本不能贡献角色见证，改域不改真值。本谓词不得改为全称——它承担“R 是否真实进入 Rel(L) 之生成”的真实性资格，不要求每个适用条件各自取得独立动力见证（《律一般式》 之极性分工）。若所有 i 均明确取 0，则 DynamicRole^M=0；不存在取 1 的 i 而至少一个所需项为 ⊥，则 DynamicRole^M=⊥。

定义 3.39〔辅〕（再入就绪）　ReplayReady(L,I)=1 当且仅当 I\_cov(L,I)≠∅，且对每个 i∈I\_cov(L,I)（与 3.35 同一守卫域）：Trig(i)≠∅（由 I\_cov 之定义自动成立）；再入域非空——EvalMode(L,i)=set 时 ReplayAdm(L,i)≠∅，EvalMode(L,i)=measure 时并须 ReplayMass(L,i)\>0；且

　∀^{Replay}\_{L,i}\[D\_{i,ν}≠∅\]=1。

再入域非空为显式前件：measure 模式下零测 ReplayAdm 不得经真空全称使 ReplayReady 及其下游（StableReplay、ΩSupport、Bind）凭空成立。I\_cov 非空同为显式前件。I∖I\_cov 不参与本全称，不得因其 Trig、ReplayAdm 为空而判 ReplayReady=0；属于 I\_cov 者若 ReplayAdm 为空、ReplayMass=0 或 D\_{i,ν}=∅，照常判 0，不得移出 I\_cov。

定义 3.40〔辅〕（再入见证）　以下 κ = ReplayCtx(i,ν)。ReplayWit\_R(L,i,ν,Π) 当且仅当 (i,ν) ∈ ReplayPair(L,I)，D\_{i,ν} ≠ ∅，Π ∈ ExtJointReal^κ\_R(D\_{i,ν})，且：(i) Bear^κ(Π) ⊆ R ∩ Estab\_t（由 X^Replay 自动成立）；(ii) Acc^κ(Π) ⊆ X^Replay\_{i,ν}；(iii) ∀d ∈ D\_{i,ν}：Realized^κ(d,ν;Supp(ρ\_d),W\_d) = 1，ρ\_d = (Supp(ρ\_d),W\_d)；(iv) ∀d：Bear^κ(ρ\_d) ∩ Inst(i,ν) = ∅。

定义 3.41〔辅〕（Ω 见证）　ΩWit\_R(L,i,ν,Π) 当且仅当 ReplayWit\_R(L,i,ν,Π) 且 ∀d ∈ D\_{i,ν}：Reach\_{X^Replay\_{i,ν}}(E\_{X^Replay\_{i,ν}}(i), Bear^κ(ρ\_d)) ∧ ΩOK^κ(ρ\_d,d,ν)。

定义 3.42〔S〕（StableReplay^M）　StableReplay^M\_F,t(L;R,I)=1 当且仅当 ReplayReady=1，且对每个 i∈I\_cov(L,I)：

　∀^{Replay}\_{L,i}\[∃Π ReplayWit\_R(L,i,ν,Π)\]=1。

定义 3.43〔S〕（ΩSupport^M）　ΩSupport^M\_F,t(L;R,I)=1 当且仅当 ReplayReady=1，且对每个 i∈I\_cov(L,I)：

　∀^{Replay}\_{L,i}\[∃Π ΩWit\_R(L,i,ν,Π)\]=1。

定义 3.44〔辅〕（实现家族）　Scheme\_R(L,i,ν) = {Π ∈ ExtJointReal^{ReplayCtx(i,ν)}\_R(D\_{i,ν}) \| ∀d ∈ D\_{i,ν}：ρ\_d ∈ RoleReal^{ReplayCtx(i,ν)}\_R(d)}。

定义 3.45〔辅〕（Bind^M）　Bind^M\_F,t(L;R,I)=1 当且仅当 ReplayReady=1，且对每个 i∈I\_cov(L,I)：

　∀^{Replay}\_{L,i}\[  
　　∃Π(ΩWit\_R(L,i,ν,Π) ∧ Π∈Scheme\_R(L,i,ν))  
　\]=1。

定义 3.46〔S〕（Govern^M）　Govern^M ⇔ DynamicRole^M ∧ ΩSupport^M ∧ Bind^M。

同域约定　CarrierRealizes^M、CarrierNonInstant^M、ReplayReady、StableReplay^M、ΩSupport^M、Bind^M 与 DynamicRole^M 一律使用同一 I\_cov(L,I)；不得在不同阶段各自重定适用域。此对应《律一般式》 之“覆盖同域”与“H2 两端同域”。

三值传播：任一合取项为 0 则为 0；无 0 而至少一项为 ⊥ 则为 ⊥；全部为 1 才为 1。

定义 3.47〔辅〕（解集）　𝒮(F\_t,L,I) = {R ⊆ Existing\_t \| EstWitness^M = 1 ∧ Govern^M = 1}。

### 3.8　关系性质申明

　⇝\_t：不默认自反、传递；不对称。  
　↝：不自反、不对称；严格时间推进节点上反对称；传递闭包由生成链承担。  
　ActArg\_ν^Ctx、ActArg^μ：左右类型不同；多对一；不随条件集扩大单调；同一 ν 在不同 Ctx 下可不同；ActArg^μ 对 ε\_role 无一般单调性。  
　StructBear、ActBear、NonInstBear：左右类型不同；NonInstBear ⊆ StructBear；ActBear 与 NonInstBear 无一般包含。  
　Reach\_B：元素级自反、传递；一般不对称、一般不反对称。  
　Org\_t：对称；定义在不同块间，不论自反；不传递。  
　RolePath 中的 π：↝ 的有限链。↝\*\_χ：↝ 在 χ 内的自反传递闭包，自反、传递；一般不对称。  
　Hosts：节点到成分集的映射；Comp：节点集到成分集的映射，路径为其特例。  
　⊆：偏序。

### 4.2　定理

定理 4.1　Bind^M=1 ⇒ ΩSupport^M=1 ⇒ StableReplay^M=1。

证明　对任一 i、ν，

　\[∃Π(ΩWit∧Π∈Scheme)\] ⇒ \[∃Π ΩWit\] ⇒ \[∃Π ReplayWit\]。

三者外层均使用同一覆盖极性 ∀^{Replay}\_{L,i}。set 模式下普通全称保持逐点蕴涵；measure 模式下若事件 A⊆B 且 A 几乎处处成立，则 B 亦几乎处处成立。故每个 i 上 Bind 条件推出 ΩSupport 条件，再推出 StableReplay 条件；三者又共用 ReplayReady=1。□

定理 4.2　NonInstBear ⊆ StructBear；ActBear 与 NonInstBear 无一般包含。  
证明　前者由定义 3.20。后者：正在生成的结构可仍由即时输入维持；已成结构可当前闲置。□

定理 4.3　∀d ∈ D ∃ρ\_d ∈ Real^κ\_B(d,ν) 不蕴涵 JointReal^κ\_B(D,ν) ≠ ∅。  
证明　各 ρ\_d 可在互相冲突的门控、资源取值或 W\_d 下分别实现而无公共 ν。□

定理 4.4（CarrierRealizes 不蕴涵 CarrierNonInstant）　CarrierNonInstant^M ⇒ CarrierRealizes^M；反向不成立。  
证明　前者由定义 3.36。反例：R = g ∪ R\_Ω，g 为当前由即时输入维持的必要门控，R\_Ω ⊆ Estab\_t。每个合法 Π 均有 g ∈ Q(Π) 而 g ∉ Estab\_t，故不存在 Q(Π) ⊆ Estab\_t 的 Π，定义 3.36 失败。□

引理 4.5（结构冷备用）　g → A → y，g → \[sel\_B\] → B → y，sel\_B = ¬failure，ν 中 failure = 0，κ 为任一含此结构的上下文。则 ¬∃W PreRealized^κ(d,ν;{g,B},W) = 1。

引理 4.6（结构截断）　y = A ∨ Z，Z = ¬A ∧ C，ν 中 A = 1。则 ¬∃W PreRealized^κ(d,ν;{g,C},W) = 1。  
证明　Z 引用 P 外结构变量 A。□

引理 4.7（时序截断）　A、C 局部生成函数互不引用，A 先到使 y\_{t+Δ} 落定。则存在合法 W 使 ρ\_C = ({g,C},W) ∈ ExtReal^κ\_R(d)，而 ρ\_C ∉ RoleReal^κ\_R(d)，κ 为含 A 的上下文。  
证明　受限评价 η ∈ ResEval(κ,{g,C},ν) 中无变量记录 A 已先到，y 由 C 重算生成，取 W = {η} 得 Realized^κ(d,ν;{g,C},W) = 1，Bear = {C} ⊆ R，g 只在 Acc，故 ρ\_C ∈ ExtReal；这正是全场 ν 与受限 η 不同之处。κ 下 y\_{t+Δ} 的 ActArg 只含 A\_t，C 的状态不在 FullChain^κ，3.32 (iii) 失败。□

引理 4.8（共享段搭便车）　主路 g → B₁ → A₂ → y 先到，备路 g → B₁ → B₂ → y 被时序截断，κ 为含 A₂ 的上下文，ρ\_B = ({g,B₁,B₂},W\_B) 为其合法实现见证。则 ρ\_B ∈ ExtReal^κ\_R(d) 而 ρ\_B ∉ RoleReal^κ\_R(d)。  
证明　路径 B₁ → A₂ → y 有 A₂ ∈ Comp(π)、A₂ ∉ Supp(ρ\_B)，违反 3.32 (iv)；路径 B₁ → B₂ → y 不在 FullChain^κ，违反 (iii)。□

引理 4.9（联合节点搭便车）　设 y 由联合节点 Z = joint(B,A′) 生成，A′ ∉ Supp(ρ)。则任何经 Z 的 π 有 A′ ∈ Comp(π)，违反 3.32 (iv)。

证明　所述路径满足 3.32 (i)–(iv)，故 RolePath 非空；与定义 3.33 直接相接。□

定理 4.11（纯相关）　若对每个 (i,ν) ∈ AdmPair（i ∈ I\_cov）与 d ∈ D\_{i,ν}，R 的状态均不在 Read(d) 在其职责类型下的承担链中——确定型为 Arg/ActArg 链，权重型、分布型为 A\_y/ActArg^μ 链——则 DynamicRole^M = 0。

定理 4.13（一次强冲）　设新沟 A⊆R 已入场，存在 i′∈I\_cov(L,I)，使

且该值不是 ⊥。则 DynamicRole^M=1，ΩSupport^M=0。

证明　前者由定义 3.38；后者因某 i 的覆盖条件明确失败，由定义 3.43 得 ΩSupport^M=0。□

定理 4.14（废弃旧沟）　设 R 已成、Ω \> 0、接得到，且对每个 (i,ν) ∈ AdmPair（i ∈ I\_cov）与 d ∈ D\_{i,ν}，R 的状态均不进入 Read(d) 的生成。则 DynamicRole^M = 0；StableReplay^M、ΩSupport^M 可为 1。

定理 4.15（死端、别处有 Ω）　设 i ∈ I\_cov(L,I)。若

　∀^{Replay}\_{L,i}\[∃Π ΩWit\_R(L,i,ν,Π)\] = 0，

则 ΩSupport^M = 0。以下两类构造足以使该量词取 0，各按模式解释：

　死端　设 ν ∈ ReplayAdm(L,i) 与 d ∈ D\_{i,ν}，对所有 P ⊆ X^Replay\_{i,ν}，在 Restrict(ReplayCtx(i,ν),P) 下均不存在自前件到 Read(d) 的、满足 Closed^κ 的生成链。则对一切 P 均 ¬∃W PreRealized^{ReplayCtx(i,ν)}(d,ν;P,W) = 1，该 (i,ν) 无 ΩWit。  
　别处有 Ω　设 ν ∈ ReplayAdm(L,i)，存在 d ∈ D\_{i,ν}，使 ∀ρ ∈ ExtReal^{ReplayCtx(i,ν)}\_R(d)：¬Reach\_{X^Replay\_{i,ν}}(E\_{X^Replay\_{i,ν}}(i), Bear^{ReplayCtx(i,ν)}(ρ,d,ν))。则该 (i,ν) 无 ΩWit。R 中他处有 Ω 段只是反例背景，不入前件。

模式解释　EvalMode(L,i) = set 时，单个如上之 ν 即使该量词取 0（普通全称之反例）。EvalMode(L,i) = measure 时，单点失败不足：须失败事件

　{ν ∈ ReplayAdm(L,i) \| ¬∃Π ΩWit\_R(L,i,ν,Π)}

具正测度（等价地 μ̄^Replay\_{L,i}(∃Π ΩWit) \< 1），量词方取 0；零测的死端评价不使 ΩSupport^M = 0（3.16′ 之 a.e. 读法）。

两分支之 i 均须属 I\_cov：I∖I\_cov 之条件不承担覆盖义务，其处无 ΩWit 不推出 ΩSupport^M = 0。□

定理 4.16（Bind 与 DynamicRole）　若 Existing\_t=Estab\_t（Drive\_t^inst=∅），且 RoleCtx=ReplayCtx，并且相关 i 满足 \|ModeSet(L,i)\|=1，从而 Role 与 Replay 共用唯一 EvalMode(L,i)，则 Bind^M=1 ⇒ DynamicRole^M=1。

　∀^{Replay}\_{L,i}\[∃Π(ΩWit∧Π∈Scheme)\]=1。

　∃Π(ΩWit∧Π∈Scheme) ⇒ ∃d∈D\_{i,ν}：RoleReal^{ReplayCtx}\_R(d)≠∅。

因此 set 模式下至少存在合法评价具有 RoleReal；measure 模式下覆盖成立的评价集为满测度，因 ReplayAdm 非空且条件测度总质量为 1，故该 RoleReal 事件具有正测度。由 RoleCtx=ReplayCtx 且共用唯一 EvalMode(L,i)，得到某 i 上 ∃^{Role}\_{L,i}\[∃d RoleReal≠∅\]=1，故 DynamicRole^M=1。□

注　有当前即时驱动时两上下文不同，当前即时结构可在 RoleCtx 下截断一条在 ReplayCtx 下成立的角色路径，蕴涵不必成立。定理 4.13、4.14 表明 DynamicRole^M 与 ΩSupport^M 各有独立失败世界；(4.6) 显式保留三项，与 S 之 Govern ⇔ DynamicRole ∧ ΩSupport 对位。

　① 存在 i\_A∈I\_cov(L,I)，使

且该值非 ⊥。

则 DynamicRole^M=1，ΩSupport^M=1，Bind^M=0，Govern^M=0。

## 第五节　运行与求解

### 5.1　运行

给定 F\_t、L、I，系统按下列步骤运行。

　1\. 由 F\_t 取 Existing\_t；枚举候选 R ⊆ Existing\_t。  
　2\. 判 CurrentCarrier^M（3.34）。失败：R 出局。  
　3\. 由 Rel(L) 建 𝒪、Ante、Anchor、Type、Read、Cov、Val、Trig。  
　4\. 由已预声明之 Trig 构造 I\_cov(L,I) = {i ∈ I \| Trig(i) ≠ ∅}（3.15′）。若 I\_cov = ∅，依各覆盖型谓词之非空守卫处理（3.35、3.39）；若某 i 之 Trig 归属不可判，则按 3.15′(b) 将该 i 之 I\_cov 归属及依赖其之形式项记为 ⊥，不得当作普通条件继续构造。此后各结构判据只对 i ∈ I\_cov 构造评价域、ModeSet 与 Type-sensitive 量词。  
　5\. 对各 i ∈ I\_cov 求 RoleEval(i)、ReplayEval(i)，各 ν 的 Inst(i,ν)，得 Adm、ReplayAdm、D\_{i,ν}；由 Type(d) 读取 EvalMode(d)，构造 ModeSet(L,i)。若 ModeSet(L,i)=∅，置 MixedMode(L,i)=⊥，不定义 EvalMode(L,i)，四个 Type-sensitive 量词记为 ⊥；若相应上游非空资格已经明确失败，则按三值传播保留该 0。若 \|ModeSet(L,i)\|\>1，置 MixedMode(L,i)=1，相关 Type-sensitive 量词及依赖谓词为 ⊥。若 \|ModeSet(L,i)\|=1，置 MixedMode(L,i)=0，以唯一元素定义 EvalMode(L,i)，再据结构谓词所需极性构造 ∀^{Role}/∃^{Role}、∀^{Replay}/∃^{Replay}。仅当 EvalMode(L,i)=measure 时构造 μ\_i、Mass 与条件测度；若所需测度、可测性或运算不可求，则相应量词值为 ⊥。  
　6\. 对各 i ∈ I\_cov 建 RoleCtx、Real、JointReal；按 ∀^{Role} 判 CarrierRealizes^M。  
　7\. 由 Freeze\_t 求 Estab\_t；仍按 ∀^{Role} 判 CarrierNonInstant^M；得 EstWitness^M。  
　8\. 对各 i ∈ I\_cov 建 FullChain（权重型、分布型职责用 ActArg^μ）、ExtReal、RolePath；按 ∃^{Role} 判 DynamicRole^M。  
　9\. 判 ReplayReady；对各 i ∈ I\_cov 建 ReplayCtx、ExtJointReal，求 ReplayWit；按 ∀^{Replay} 判 StableReplay^M。  
　10\. 权重型、分布型职责求正则评价、本质 Bear、本质 ReqSeg 与 ΩWit；其他 Type 按其原有 W/评价政策求 ΩWit；按 ∀^{Replay} 判 ΩSupport^M。  
　11\. 求 Scheme；按 ∀^{Replay} 判 Bind^M。  
　12\. 得 Govern^M（3.46）。  
　13\. 收集 EstWitness^M ∧ Govern^M 的 R，得 𝒮（3.47）。

任一步出现 0，按定义判相应性质不成立；出现 ⊥ 而此前无决定性 0，则相应性质为 ⊥。

### 5.2　解

R ∈ 𝒮(F\_t,L,I) 为本篇形式解。𝒮 = ∅ 表示 M 未找到解；在第七节 H\_Rep 各条关闭前，不能由此推出结构侧不存在合格 R。𝒮 ≠ ∅ 时，在 (7.9) 的桥下可读回 ∃R\[Established ∧ Govern\]。

### 5.3　可解性（形式表示条件）

　M1　Freeze\_t 与 Drive\_t^inst 有定义，Estab\_t 由之唯一确定。（对应 S 之 C1，不改变其上游地位。）  
　M2　局部生成函数与生成核可查询或求解。  
　M3　Eval(Ctx) 与所需生成结构可有效刻画；对每个 i，ModeSet(L,i) 可有效构造并判断其基数。\|ModeSet\|=1 时 MixedMode(L,i)=0，并唯一得到 EvalMode(L,i)；\|ModeSet\|\>1 时 MixedMode(L,i)=1 且相关形式项为 ⊥；ModeSet=∅ 时 MixedMode(L,i)=⊥，不定义 EvalMode(L,i)，四个 Type-sensitive 量词为 ⊥，除非相应上游非空资格已经明确判 0。对 EvalMode(L,i)=measure 的联合职责族，σ-代数 Σ\_Ctx、普通局部核与联合节点联合核可求得或可有效描述，并能唯一诱导 μ\_Ctx；所需条件测度、可测集、a.e./正测度及 Read 所需概率阈值等评价可有效判定或有效逼近到 Type(d) 所申报精度。联合核不唯一、所需集合不可测或测度运算不可决定时，相应 Type-sensitive 量词值为 ⊥，不是 0。对 EvalMode(L,i)=set 的联合职责族，不强制因为概率测度接口缺失而不可判。
