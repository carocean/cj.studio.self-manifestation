自显论·律篇·律组式第四 v1.3

# 最小沉积场构造式

## 第一节　目的

本篇处理一个单一构造问题：

依据《自显论》场篇已经给出的沉积场结构与动力，能否显式构造一个最低职责闭合、可以实际运行、能够由历史改变后继流变的沉积场实例。

本篇不重新定义沉积场，不承担沉积场一般式的必要性证明，也不以神经网络作为定义来源。

本篇与《律运行基底构造式》严格分工：

《最小沉积场构造式》只负责把"沉积场"造出来并证明它能够运行；

《律运行基底构造式》再在此基础上扩展阈、强度、稳定复走、Freeze-run、伪律反例等律侧检验所需结构。

因此，本篇不再承担成律判定，不签 R∈𝒮，不设置 FormalLawSolutionCandidate，不把 A⇒C、B⇒D 解释为律。若使用条件映射，只把它当作检验"历史组织能否改变后来"的运行探针。

本篇标题中的"最小"，指：

在既定结构基质 Ξ 上，以尽可能少的持久状态与核心动力算子形成沉积场最低职责闭环。

本篇不证明 \|Ξ\| 的节点数最小，不证明所有沉积场都必须使用本篇同名变量。

## 第二节　式种与输出

本篇为构造式。

结构输入：场篇已经给出的沉积场基本性质与动力结构。

形式输出：一个显式、可执行的 Canonical F\*。

本篇构造目标写为：

∃F\*\[Constructed(F\*) ∧ C1(F\*) ∧ C2(F\*) ∧ C3(F\*) ∧ C4(F\*) ∧ C5(F\*) ∧ C6(F\*) ∧ C7(F\*)\]。

其中 C1—C7 只承担沉积场级职责，不含任何律侧资格。

## 第三节　上游输入

本篇直接依附：

《自显论·内篇第六 v1.2·沉积场论》；

《自显论·场篇·场数理式 v2.7》；

《自显论·式篇·沉积动力一般式 v1.2》。

《沉积场论》v1.2 给出沉积场三项基本性质：可沉积性、可组织性、态之流变性。其中原文明确：

"所谓可沉积性，即与之作用而能应之以迹，反复而迹深，少用则迹淡，同源则同迹，异源则异迹。"

"所谓可组织性，即能结起机构而因应之。"

"所谓态之流变性，其迁转情态于内……"

《场数理式》v2.7 进一步把脉冲、迹应、沟线、沉积度、续行势等结构放入同一生成链：迹应于结构位之间成沟，谓之沟线，一次迹应即可成浅沟（定义5）；沉积度 δ 为沉积深浅之程度（定义9）；续行势 κ 是由沉积度、阈与当前续行结构状态给出的导出量，比较条件相同时不逆 δ 序（定义11、方程3a）；沟线经稳定复走方成路（定义12）。

《沉积动力一般式》v1.2 进一步区分：差分积深 D 只指历史在不同结构位、沟线或路径之间留下的沉积度之差，不含作用义（定义四）；沉积差是否参与后续另立续行偏置 B——在申报的比较任务中，把比较对象的沉积度抹平到申报的共同水平、其余不变，后续的相对行进随之改变（定义五）。B 不强求概率表达，读数可以是首批开放者、先后次序或份额；B 不是一切偏流，只取由沉积差承担的一种；干预须可实现。该篇结论限于沉积型主导续行结构。（v1.2 此处引作「历史差分……还必须能够压偏后来；历史留存而不进入后继生成时，历史在动力上仍为惰性」，系该篇 v1.1 的表述。）

本篇不重新证明这些上游命题，只把它们转成构造接口。

## 第四节　构造条件组

C1　作用进入

存在实际外部事件 πₜ 被场内 Trace 接收，而非只被场外记录。

C2　迹应形成

Trace(πₜ) 产生非零迹应 τₜ，使当前场获得可检测事件响应。

C3　跨时沉积

迹应经 Sediment 后能够进入下一时刻持久场态，不在该步结束时全部消失。

C4　关系组织

历史不仅改变局部沉积，还能够形成结构位之间的关系组织。

C5　历史参与后来

已经形成的沉积结构必须真实进入后继生成；若删除或切断承重沉积而保持当前再入条件不变，后继流变应发生可检测变化。

C6　退浅

缺少后续作用时，既有沉积能够减弱，实现"少用则迹淡"。

C7　当前流变

场内存在实际状态迁转 qₜ→qₜ₊₁。

依据《沉积场论》v1.2"其迁转情态于内"的最低语义，本篇只要求至少存在场内实际迁转，不把 C7 扩张为"任一状态都必须无限自主续行"或"必须形成无限闭合轨道"。

本篇构造成功，当且仅当同一个 Canonical F\* 同时满足 C1—C7。

Compatibility(C1,…,C7) 与本构造并行关闭：同一个 Canonical F\* 同时取得 C1—C7，构成构造性相容见证。

## 第五节　Canonical F\*

本篇冻结唯一正式构造：

Canonical F\* = (Ξ, d, g; Trace, Sediment, Decay, Continuation)。

持久场态只有：

State\_persist(F\*) = (d,g)。

其中：

dᵢ：局部沉积深度；

gᵢⱼ：关系沉积强度。

即时运行量：

qₜ：当前结构状态；

πₜ：实际外部入场事件，只在外生作用模式中出现；

τₜ：当前迹应；

κₜ：由当前沉积结构即时导出的续行倾向。

τ、κ 不跨时独立保存。

最终参考实现中 Trace、Sediment、Decay、Continuation 均具有独立、可定位的执行函数；正文算子与代码算子逐项同构。

## 第六节　场篇结构与实例量对应

Ξ：结构基质。对应场篇中可受作用、可留迹、可参与续行和形成组织的结构位空间。

dᵢ：本实例局部积深实现量。它承担局部历史积深职责，不新增场篇本体术语。对应：dᵢ 实例化结构位 i 的沉积度 δ（场篇第一 v2.7 定义9）；结构位之间 d 的不等，即式篇第二十 v1.2 的差分积深 D。

gᵢⱼ：本实例关系沉积实现量。它承担连续经历形成关系组织的职责，不与《场数理式》中既有 Γ、γ 符号重载。对应（场篇第一 v2.7）：gᵢⱼ \> 0 实例化结构位 i、j 之间的沟线 Gr(i,j) 及其沉积度——一次迹应即可成浅沟，反复则加深（定义5）；本构造不实现成路（Ω\_W，定义12），成路资格的操作化移交《律运行基底构造式》。v1.2 写作「沟线前阶结构」，系依场数理式 v2.6 口径；依 v2.7，沟线不以复走为前提，故改。

πₜ：当前外部入场事件。

τₜ：当前迹应事件。

κₜ：由 d、g 即时导出的续行倾向。它实例化场篇第一 v2.7 的续行势 κ（导出量）；本构造无阈 θ，κ 只由 d、g 给出；因 w\_d、w\_g ≥ 0，κ 关于 d、g 不减，与「κ 不逆 δ 序」相容（定义11）。

本篇实现量与场篇理论量是实例化关系，不是重新定义关系。

## 第七节　显式基质

取四个结构位：

Ξ = {A,B,C,D}。

允许的局部续行关系：

E = {A→C, A→D, B→C, B→D}。

这里只预装介质允许哪些局部迁转，不预装哪条关系应占优。

初态：

d\_A(0)=d\_B(0)=d\_C(0)=d\_D(0)=0；

g\_AC(0)=g\_AD(0)=g\_BC(0)=g\_BD(0)=0。

所以初态没有任何历史差分，也没有任何成熟关系组织。

本篇不证明 \|Ξ\|=4 是最少结构位数。四点基质只是当前低配构造，用来同时容纳两个可再入状态和两个可竞争后继。

取：

α=0.015；

β=0.030；

g\_max=1.20；

λ\_d=0.0015；

λ\_g=0.0015；

κ₀=0.10；

w\_g=0.55；

w\_d=0.05；

这些都是实现参数，不构成沉积场一般定义。

## 第九节　两种运行模式

一、外生经历模式 Mode\_exo

外部环境实际发生一个允许事件 i→j。

定义：

πₜ := ExternalTransitionₜ(i,j)。

该事件进入 Trace：

τₜ = Trace(πₜ)。

随后由 Sediment 把迹应写入 d、g。

Mode\_exo 的职责只是让外部历史进入场。

二、内生续行模式 Mode\_endo

不另设悬空外部 πₜ。

给定当前 qₜ 与 dₜ、gₜ：

κₜ = K(qₜ,dₜ,gₜ)。

随后：

qₜ₊₁ = Continuation(qₜ,κₜ)。

实际迁转 qₜ→qₜ₊₁ 发生后，再形成迹应并继续沉积。

因此：

Mode\_exo：外部历史进入；

Mode\_endo：既有沉积结构自主参与后来。

## 第十节　统一时间更新

Canonical F\* 每一实际事件统一采用"先退浅，再处理当前事件"的顺序；最终源码 v1.2 的 Mode\_endo 已与此完全一致：Decay → Continuation → Trace → Sediment。

先定义退浅后的当前沉积：

d̃ᵢ(t)=max{0,dᵢ(t)−λ\_d}；

g̃ᵢⱼ(t)=max{0,gᵢⱼ(t)−λ\_g}。

若为 Mode\_endo，则：

κₜ(qₜ→j)=κ₀+w\_g·g̃\_qₜj(t)+w\_d·d̃\_j(t)。

qₜ₊₁=Continuation(qₜ,κₜ)。

实际事件 i→j 发生后：

τᵢⱼ(t)=1 当且仅当该步实际发生 i→j，否则为 0。

局部迹应 τᵢ(t) 在事件所及结构位取 1，其余取 0。

然后：

dᵢ(t+1)=d̃ᵢ(t)+α·τᵢ(t)。

gᵢⱼ(t+1)=g̃ᵢⱼ(t)+β·(1−g̃ᵢⱼ(t)/g\_max)·τᵢⱼ(t)。

所以内生链为：

(qₜ,dₜ,gₜ) → (d̃ₜ,g̃ₜ) → κₜ → qₜ₊₁ → τₜ → (dₜ₊₁,gₜ₊₁)。

外生链为：

ExternalTransitionₜ(i,j) → (d̃ₜ,g̃ₜ) → τₜ → (dₜ₊₁,gₜ₊₁)。

不存在未来状态先参与生成自身的循环。

## 第十一节　续行求解器

本实例使用 softmax：

P(qₜ→j)=exp(κₜ(qₜ→j)/T)/Σₖexp(κₜ(qₜ→k)/T)。

softmax 只是数值求解器，不承担沉积场本体资格。

理论承重项只有：

沉积差异能够系统性改变后继生成。

其他承担同一职责的求解方式原则上可以替代。

注（随场篇第一 v2.7、式篇第二十 v1.2）　softmax 给出的是续行概率份额，不同于场篇第一定律5「深者先得其流」的先后判据；份额读数只是式篇第二十 v1.2 续行偏置 B 所许读数之一。

## 第十二节　构造程序

Step 1　若有外部经历，读入 ExternalTransition(i,j)；若为内生模式，读入当前 qₜ。

Step 2　执行 Decay，得到 d̃ₜ、g̃ₜ。

Step 3　Mode\_endo 下由 d̃ₜ、g̃ₜ 计算 κₜ，并由 Continuation 生成 qₜ₊₁。

Step 4　对实际发生的 i→j 调用 Trace，生成 τₜ。

Step 5　调用 Sediment，以 τₜ 更新 d、g。

Step 6　进入下一时刻。

该程序中的 Trace、Sediment、Decay、Continuation 均可独立定位和关闭。

## 第十三节　C1—C7 逐项验证

C1　作用进入

Mode\_exo 中，πₜ=ExternalTransitionₜ(i,j) 进入 Trace 与 Sediment，不是场外记账。

C1 通过。

C2　迹应形成

单次事件后，对应 Trace 产生局部迹应和关系迹应；开启 Sediment 时，对应 d、g 从 0 变为正值。

C2 通过。

C3　跨时沉积

更新后的 d、g 在下一时刻继续存在，并成为 κ 的输入。

C3 通过。

C4　关系组织

gᵢⱼ 保存实际连续事件形成的关系沉积。第十五节证明，最终局部沉积 d 相同（在申报容差内）、关系组织不同的两组历史，不能仅靠 d 区分。

C4 通过。

C5　历史参与后来

已形成的 d、g 被 Continuation 实际读取。切断 Continuation 对 d、g 的读取后，原有历史偏向立即退回无偏。

C5 通过。

C6　退浅

正常 Decay 开启时，未继续作用的 d、g 逐步下降；关闭 Decay 时，idle 前后 g 不再变化。

C6 通过。

C7　当前流变

Mode\_endo 下，A、B 均能依据当前 κ 在场内自主迁转到 C、D。

本篇只据此取得最低"迁转情态于内"资格，不宣称无限自主闭合流。

C7 通过。

故：

C1(F\*)∧C2(F\*)∧C3(F\*)∧C4(F\*)∧C5(F\*)∧C6(F\*)∧C7(F\*)。

## 第十四节　构造定理

定理　最小沉积场构造定理

存在一个显式、可执行的 Canonical F\*，满足本篇沉积场构造条件 C1—C7。

证明。

第五至第十二节给出唯一构造对象、持久状态、即时量、初态、实现参数、两种运行模式与完整更新程序；第十三节逐项验证 C1—C7。故构造成立。

记：

MinimalSedimentationFieldConstruct(Canonical F\*) = Constructed。

本定理只取得构造强度，不证明 d、g 是所有沉积场唯一可能的表示，也不证明四结构位是节点数最小。

## 第十五节　d/g 正交职责检验

本节仍使用同一个 Canonical F\*。

一、关系组织

构造两组最终局部沉积 d 相同、关系配对不同的历史。两组先经历相同的共同前缀——A→C、B→D 各一次，使各局部沉积进入正值区——再各进行 180 轮：

H1：反复经历 A→C 与 B→D；

H2：反复经历 A→D 与 B→C。

两组最终 d 逐分量一致：max\|d^{H1} − d^{H2}\| ≈ 4.44×10⁻¹⁶，在申报容差 10⁻¹² 之内（脚本断言）。v1.2 只控制访问次数而无共同前缀，两组最终 d 因初始截零而不同，擦除 g 后 P(C\|A) 一为 0.4999、一为 0.5001，仍有差别，不足以证明 d 不能区分两组历史；本版补此控制。

完整 F\*：

H1：P(C\|A)≈0.9499，P(D\|B)≈0.9502；

H2：P(C\|A)≈0.0501，P(D\|B)≈0.0499。

擦除 g、只保留 d：

H1：P(C\|A)≈0.4999，P(D\|B)≈0.5001；

H2：P(C\|A)≈0.4999，P(D\|B)≈0.5001。

两组读数相同（d 本身在 C、D 间有约 0.0015 的次序差，两组一致，故份额同偏离 0.5）。

故在最终 d 相同的两组历史中，只保留 d 不能区分关系配对；g 承担独立关系组织职责。

与续行偏置 B 的对应（式篇第二十 v1.2）：擦除 g（全部置 0）即把比较对象的关系沉积抹平到共同水平 0、其余不变；此干预在本构造中可实际执行，后续相对行进随之改变（份额读数），构成 B 的一个实例。下文擦除 d 同理。

二、局部积深

局部沉积的受控状态干预检验。先经历 A→C 与 A→D 各 160 轮，使二者关系沉积近似相等；取两份相同快照，经历相同退浅，并分别对 C 或 D 施加等量局部沉积干预（各 140 步），不增加关系沉积。该操作是检验接口（附录 A 之 local\_deposit\_intervention），不调用 Trace、Sediment，也不形成允许集合 E 中的事件，不是 Mode\_exo 或 Mode\_endo 的自然运行历史。

完整 F\*：

C-deep：P(C\|A)≈0.6273；

D-deep：P(C\|A)≈0.3706。

擦除 d、只保留 g：

两组均 P(C\|A)≈0.4990。

故 g 不能替代 d 的局部积深职责。

本检验说明：在申报的状态干预范围内，保持 g 相同而改变 d，可改变后继份额；它不单独证明这些对照态均由现有事件模式生成。若要以合法经历生成作见证，须另行正式定义局部事件及其 Trace、Sediment 处理规则，再行验证。

因此在当前构造中（关系组织一项依同一最终 d 下的经历检验，局部积深一项依受控状态干预检验）：

LocalDepth(d) ≠ RelationOrganization(g)。

## 第十六节　历史记录与历史治理检验

先形成稳定历史组织，再保持 d、g 不变，只令：

w\_d=0，w\_g=0。

即历史仍被保存，但 Continuation 不再读取历史。

完整 F\* 的运行探针：

P(C\|A)≈0.9514；

P(D\|B)≈0.9516。

切断历史读取后：

P(C\|A)=0.500；

P(D\|B)=0.500。

注　w\_d=w\_g=0 为规格级消融（改动规格参数），用以验证 C5 的场级职责；状态级的角色干预（保持规格、只切断某组织的读取通路）由下游《律运行基底构造式》以 RoleReadMask 形式化。

故：

Record(history) ≠ Govern(current continuation)。

记号注　此处 Govern 是本篇运行探针的记号，指历史实际参与当前续行，不是《律一般式》的 Govern\_F,t(L;R,I)（DynamicRole ∧ ΩSupport）。w\_d = w\_g = 0 改的是读取规格，不是把沉积度抹平到共同水平，故不是式篇第二十 v1.2 续行偏置 B 的实例；它检验的是 C5 所要求的读取职责。

因此，沉积场不是只会保存历史的记录器；历史必须进入后来。

## 第十七节　Trace、Sediment、Decay 消融

一、Trace-off

在相同 350 轮两组外生经历下关闭 Trace：

Σd=0；

Σg=0；

P(C\|A)=0.500；

P(D\|B)=0.500。

作用无法形成可供跨时沉积使用的迹应。

二、Sediment-off

保留 Trace，但关闭 Sediment：

Σd=0；

Σg=0；

import numpy as np
import copy

class CanonicalSedField:
    def __init__(self, alpha=0.015, beta=0.030, g_max=1.20,
                 lam_d=0.0015, lam_g=0.0015, kappa0=0.10,
                 w_g=0.55, w_d=0.05, temperature=0.20, seed=0):
        self.rng = np.random.default_rng(seed)
        self.nodes = ["A","B","C","D"]
        self.idx = {n:i for i,n in enumerate(self.nodes)}
        self.allowed = {
            self.idx["A"]:[self.idx["C"], self.idx["D"]],
            self.idx["B"]:[self.idx["C"], self.idx["D"]],
        }
        self.d = np.zeros(4)
        self.g = np.zeros((4,4))
        self.alpha=alpha; self.beta=beta; self.g_max=g_max
        self.lam_d=lam_d; self.lam_g=lam_g
        self.kappa0=kappa0; self.w_g=w_g; self.w_d=w_d
        self.temperature=temperature

    def Decay(self):
        self.d = np.maximum(0.0, self.d - self.lam_d)
        self.g = np.maximum(0.0, self.g - self.lam_g)

    def Trace(self, i, j):
        tau_d = np.zeros(4)
        tau_g = np.zeros((4,4))
        tau_d[i] = 1.0
        tau_d[j] = 1.0
        tau_g[i,j] = 1.0
        return {"tau_d": tau_d, "tau_g": tau_g, "event": (i,j)}

    def Sediment(self, tau):
        tau_d, tau_g = tau["tau_d"], tau["tau_g"]
        self.d = self.d + self.alpha * tau_d
        hits = np.argwhere(tau_g > 0)
        for i,j in hits:
            old = self.g[i,j]
            self.g[i,j] = min(
                self.g_max,
                old + self.beta*(1 - old/self.g_max)*tau_g[i,j]
            )

    def kappa(self, q):
        outs = self.allowed[q]
        return np.array([
            self.kappa0 + self.w_g*self.g[q,j] + self.w_d*self.d[j]
            for j in outs
        ])

    def Continuation(self, q, rng=None):
        rng = rng or self.rng
        outs = self.allowed[q]
        scores = self.kappa(q)
        z = (scores - scores.max())/self.temperature
        p = np.exp(z); p /= p.sum()
        j = int(rng.choice(outs, p=p))
        return j,p

    def exo_experience(self, i, j, trace_on=True, sediment_on=True, decay_on=True):
        assert j in self.allowed[i]
        if decay_on:
            self.Decay()
        tau = self.Trace(i,j) if trace_on else None
        if sediment_on and tau is not None:
            self.Sediment(tau)
        return tau

    def endo_episode(self, i, rng=None, learn=True, decay_on=True,
                     trace_on=True, sediment_on=True):
        # Canonical order: Decay -> Continuation -> Trace -> Sediment
        if decay_on:
            self.Decay()
        j,p = self.Continuation(i,rng=rng)
        tau = self.Trace(i,j) if trace_on else None
        if learn and sediment_on and tau is not None:
            self.Sediment(tau)
        return j,p,tau

    def idle(self, steps=1):
        for _ in range(steps):
            self.Decay()

def exact_prob(field, src, target):
    outs=field.allowed[src]
    scores=field.kappa(src)
    z=(scores-scores.max())/field.temperature
    p=np.exp(z); p/=p.sum()
    return float(p[outs.index(target)])

def train_map(field, cycles=350):
    A,B,C,D=[field.idx[x] for x in ["A","B","C","D"]]
    for _ in range(cycles):
        field.exo_experience(A,C)
        field.exo_experience(B,D)
    return field

def local_deposit_intervention(field, x, n):
    """Controlled state intervention (test interface, not Mode_exo / Mode_endo):
    each step applies the same Decay, then adds an equal local deposit at x;
    it does not call Trace or Sediment and forms no event in E."""
    for _ in range(n):
        field.Decay()
        tau_d=np.zeros(4); tau_d[x]=1.0
        field.d += field.alpha*tau_d

D_TOL = 1e-12   # tolerance for "same final d" (floating-point)

def test_relation_organization():
    def make(h1=True):
        f=CanonicalSedField(seed=2)
        A,B,C,D=[f.idx[x] for x in ["A","B","C","D"]]
        # common prefix: bring local sediment into the positive region,
        # so that equal visit counts no longer yield unequal final d via truncation at 0
        f.exo_experience(A,C); f.exo_experience(B,D)
        for _ in range(180):
            if h1:
                f.exo_experience(A,C); f.exo_experience(B,D)
            else:
                f.exo_experience(A,D); f.exo_experience(B,C)
        return f
    h1=make(True); h2=make(False)
    A,B,C,D=[h1.idx[x] for x in ["A","B","C","D"]]
    d_gap=float(np.max(np.abs(h1.d-h2.d)))
    assert d_gap <= D_TOL, d_gap
    h1d=copy.deepcopy(h1); h1d.g[:]=0
    h2d=copy.deepcopy(h2); h2d.g[:]=0
    return {
        "max|d_H1-d_H2|":d_gap,
        "H1_P(C|A)":exact_prob(h1,A,C),
        "H1_P(D|B)":exact_prob(h1,B,D),
        "H2_P(C|A)":exact_prob(h2,A,C),
