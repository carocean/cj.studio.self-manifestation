自显论·律篇·律组式第五 v1.3

# 律运行基底构造式

## 第一节　目的

《最小沉积场构造式》已构造出满足 C1–C7 的可运行沉积场 F\_min。本篇处理其后一个构造问题：怎样在 F\_min 之上增加律侧区分所需结构，得到一个足以承载律的生成、运行、判定及伪律反例检验的运行基底 F\_LB。本篇不签新增结构的最少性。

构造目标：

　　∃Spec\_LB \[ Spec\_LB = Augment(Spec\_min, A\_LB) ∧ SedFieldSpec(Spec\_LB) ∧ LawBaseCapable(Spec\_LB) \]

其中 Spec\_LB 为固定运行基底规格。Inst(Spec\_LB) = Traj(Spec\_LB, Init\_LB, Prot\_LB)，为由该规格自共同初态、经许可协议 Prot\_LB 产生的合法实例/状态轨迹集。Prot\_LB = {Mode\_exo, Mode\_endo, Freeze, Thaw, IdleStep, do(Mask), do(Avail)}；直接改写 g、d、rep、Ω 不属于许可协议，如作结构删除干预须另行申报并保持派生量闭包。

LawBaseCapable(Spec\_LB) ⇔ FormationCap ∧ RoleCap ∧ StabilityCap ∧ BoundaryCap：  
　FormationCap　能产生 Deposited、Groove、Ω，且可区分一次强冲与反复复走（LB1、LB2、LB5、LB9）；  
　RoleCap　能对指定 R 作 do(Mask\_R) 并与对照组织比较（LB3）；  
　StabilityCap　能 Freeze^inst 使沉积停止而既有结构继续运行（LB8）；  
　BoundaryCap　能独立操作 Avail，并构造 Corr = 1 ∧ MediumReach = 1 ∧ Dyn = 0 之反例（LB4、LB6、LB7）。  
LB1–LB9 为上述四能力的验证套件；每项由 Inst(Spec\_LB) 中的实例作见证。本篇不要求单一时刻状态同时满足九项；「同一 F」指同一规格的多个合法实例。

　　LawBaseCapable(Spec\_LB) ⇏ Law(L)。

本篇不签 R ∈ 𝒮，不签 Law(L)。最终只签：若干律侧诊断谓词在同一规格的实例上可被分别操纵。

接口申明：上游之下游接口节将 FormalLawSolutionCandidate 与 R ∈ 𝒮 的正式实例判定经本篇转交《律判定式》；本篇不承接（第八节）。

《自显论·律篇·律组式第一·律一般式》：九个结构分量；第十一节边界例。  
《自显论·律篇·律组式第二·律数理式》：Existing、Estab、Inst、Freeze、DynamicRole^M、ΩSupport^M、Reach、RolePath。本篇只按名引用这些对象作诊断谓词的对照，不实例化其判据，故不受数理式 v1.3 起 I\_cov 量化域收窄的影响。

## 第三节　继承层、扩展映射与新增层

### 3.1　继承自 F\_min（最低场核，不改其职责）

　d\_i　结构位局部沉积；g\_e　邻接上的关系沉积（饱和于 g\_max）；  
　Trace、Sediment、Decay、Continuation 四算子；Mode\_exo、Mode\_endo；softmax 求解器。

### 3.2　扩展映射

　Augment(Spec\_min, A\_LB) = Spec\_LB，A\_LB = {p, θ, rep, Ω, Avail, Mask, Freeze^inst, IdleStep, 双时钟, 扩展拓扑, 多跳续行}。

多跳续行：F\_min 的 Mode\_endo 每次只作一次迁转 q\_t → q\_{t+1}；本篇一个脉冲沿 κ 连续续行至无出边或跳数上限（maxhop = 6），每跳各留迹应。单跳为其退化情形，故 C7 保持。

投影 Π\_min：Spec\_LB → Spec\_min，遗忘 A\_LB 全部对象，只保留 (Ξ, d, g; Trace, Sediment, Decay, Continuation)。退化参数区：p = 1，Mask ≡ 1，Avail ≡ 1，此时 θ/S 只作门控，不改变最低职责。保守扩展的定义：Π\_min(F\_LB) ⊨ C1 ∧ … ∧ C7。本实现是职责保持的扩展实现，不是 Canonical F\* 四节点集合的直接扩容：F\_min 的 d、g、四算子在 F\_LB 中逐一有同名实现（附录 C）；Sediment 的写入式改为按 p 计，Continuation 的 κ 式加入 S 与 Mask 门控。保持性由第七节引理证明，并由附录 B 的 test\_preserve\_C1\_C7 在退化参数区一键验证。

### 3.3　本篇新增（律运行基底层）

　p　脉冲强度：Sediment 按 α·p、β·p 写入；  
　θ\_e　阈；S\_e = \[g\_e ≥ θ\_e\]　续行结构状态；

注（θ 与 S 为本篇工程读法）：本篇 θ 是沉积量资格阈，只用于 S\_e = \[g\_e ≥ θ\_e\]；场篇第一的 θ 是出流阈，用于入口流压达到阈后的出流判定（方程4、定理17）。二者未建立同一对应：本构造没有实现流压—出流阈机制，固定 θ 也不实现「愈深阈愈小」（场篇第一方程3a）；本篇 S 只是 g 是否过阈的工程读法，不自动等同于场篇第一由成路状态等条件给出的续行结构 S（定义14）。变量与代码照旧。  
　双时钟　t\_run 运行步，每次脉冲递增；t\_sed 沉积步，只在沉积律执行（Decay）时递增。正常脉冲二者同增；IdleStep 只增 t\_sed；Freeze-run 只增 t\_run。  
　rep\_e　满足 t\_sed − W ≤ r ≤ t\_sed 的复走事件时刻 r（按 t\_sed 计；跨度 W、两端包含，整数时钟下至多含 W + 1 个时刻；代码在 t\_sed − r \> W 时删除记录）；窗口过期与 t\_sed 绑定，不与 t\_run 绑定；  
　Γ\_t　派生沟线集：Groove(e) ⇔ S\_e ∧ \|rep\_e\| ≥ 2；  
　Ω\_e　稳定复走能力：Ω\_e = min(1, \|rep\_e\|/2n\_Ω) 若 \|rep\_e\| ≥ n\_Ω ∧ S\_e，否则 0；

注（沟线与 Groove，对应场篇第一 v2.7）：场篇第一的沟线是迹应所成之沟，自形成起即有深浅 δ 与阈 θ（生成链、定义14）；在本构造中它对应 Deposited(e)（g\_e \> 0）。本篇的 Groove(e) ⇔ S\_e ∧ \|rep\_e\| ≥ 2 是附加了阈与窗口复走的工程资格谓词，不等于场篇第一的沟线，也不等于成路（Route\_W ⇔ Ω\_W = 1）；Γ\_t 是此资格谓词的成立集。下文「成沟」「沟线除名」均指此资格的得失，不指迹应所成之沟本身的生灭：Groove 因窗口过期除名后，Deposited 仍可为 1，沟线仍有深浅（外三「沟线、端壑有深浅」），见 LB9 注。

注（Ω\_e 与 Ω\_W，对应场篇第一 v2.7）：场篇第一的 Ω\_W 是申报窗口 W 内的历史资格谓词（取 0 或 1），检查三项事实：W 内复走记录达到申报判据；所沿沟线连接保持（Brk\_W = 0）；各子段都有复走事件（定义12）。本篇 Ω\_e 是自定的操作化程度量：Ω\_e \> 0 ⇔ \|rep\_e\| ≥ n\_Ω ∧ S\_e，即只检查事实一（窗口为 \[t\_sed − W, t\_sed\]，W = 30、两端包含；判据 n\_Ω = 3），另加阈资格 S\_e；事实二在本构造中没有独立的断裂机制（Avail 为外生控制），不单独检查；事实三不检查。Ω\_e \> 0 时，Ω\_e 随窗口内复走次数单调不减，至 1 饱和。为比较两者，本注取子段约定：把 \[t\_sed − W, t\_sed\] 三等分为 \[lo, lo + W/3\]、(lo + W/3, lo + 2W/3\]、(lo + 2W/3, t\_sed\]（lo = t\_sed − W）；判据取 n\_Ω；连接保持取：窗口内所沿各边的沉积连接持续存在且未受阻；本构造中该见证至少同时核查 g \> 0（Deposited）与 Avail = 1，二者须在窗口内每次 Decay 之后都成立。Avail = 1 只表示介质可用，不保证沉积之沟仍在，不能单独等同于上游 Brk\_W = 0：例如一次 p = 0.05 后闲置 5 步，Avail = 1 而 g = 0，Deposited = 0。按此约定，\[Ω\_e \> 0\] 与 Ω\_W = 1 互不蕴含。其一，Ω\_W = 1 而 Ω\_e = 0：连续 32 次 p = 0.05 沿 a1→m1→c；末态 t\_sed = 32，窗口 \[2, 32\] 保留时刻 2 至 32 共 31 次复走（事实一成立），窗口内每次 Decay 之后 a1→m1、m1→c 均有 Avail = 1，且两边最小 g 约为 0.0025 \> 0（事实二按本约定成立），三子段复走数为 11、10、10（事实三成立）；而 g(m1→c) ≈ 0.08923 \< θ，S = 0，Ω\_e = 0。其二，Ω\_e \> 0 而事实三不成立：三次 p = 2 的脉冲后 IdleStep 20 步，t\_sed = 23，窗口 \[−7, 23\]，rep 时刻为 1、2、3，Ω\_e = 0.5，三子段复走数为 3、0、0。本篇 Ω\_e 不代替 Ω\_W；第八节 ΩSupport^pre ⇝ ΩSupport^M 亦只是候选接口（K13）。

注（反复与加深）：Sediment 每次流经按 β·p·(1 − g/g\_max) 增加 g，这是本实现申明的加深规则：反复流经而深，在 g\_max 处饱和；某次流经造成多少加深，由此规则给出。Ω\_e 计的是复走，g 计的是深，二者分立（场篇第一定义12：Ω 对应复，δ 对应深）。  
　外生控制量　Avail\_t(e), Mask\_t(e) ∈ {0,1}：不由 Sediment 写入，不受 Decay，只经许可干预改变，在再次干预前跨步保持。与即时量（τ、κ）、持久沉积量（d、g、rep、Ω）均不同类。  
　Avail\_t(e)　可用性；Continuation 与 MediumReach 只经 Avail = 1 的边；正常运行恒为 1；  
　RoleReadMask\_t(e)　角色读取掩码；κ 读取 Mask·g；正常恒为 1。do(Mask = 0) 切断该结构进入当前生成的通路而不改 g、S、rep、Ω，是本篇唯一合法的角色干预；裸改 g 属结构删除干预，须同步重算 S、Ω、Γ，本篇不用；  
　Freeze^inst　沉积律开关；IdleStep　只退浅、只过期窗口，不产生 τ、rep、流；  
　Established^inst、RolePath^inst、DynamicRole^inst、ΩSupport^pre、MediumReach^inst　律侧读出（第五节）。

### 3.4　状态层级

　基础沉积状态　d, g　　（持久，Sediment 写、Decay 减；F\_min 之 State\_persist）  
　结构资格量　　S, Γ　　（由 g、θ、rep 派生）  
　历史窗口状态　rep　　（持久，Sediment 追加、按 t\_sed 过期）  
　派生能力量　　Ω　　　（由 rep 与 S 派生；不是新的沉积记忆）  
　外生控制量　　Avail, Mask, SED  
　时钟　　　　　t\_run, t\_sed  
　即时量　　　　τ, κ, q

持久沉积状态仍只有 (d, g, rep)，其中 rep 为窗口记录；F\_min 的 State\_persist = (d, g) 之低配性不被新增层破坏。

κ 在继承式上加入 S 与 Mask：κ\_e = κ₀ + w\_g·Mask\_e·g\_e·(1 若 S\_e 否则 s\_weak) + w\_d·d\_{e 之末端}。

注：本构造以 softmax 份额实现续行选择。比较条件：在其他候选得分不变、该边可用（Avail = 1）、Mask = 1，且末端 d 与阈参数固定时，在本篇参数下（w\_g \> 0，s\_weak \> 0），提高该边 g 不降低其 softmax 选择概率；若该入口另有至少一条可用候选，则严格提高；若该边是唯一可用出边，其选择概率恒为 1。比较两条不同的边，仅有同一入口和深浅之差，不足以确定概率排序：例如深支 g ≈ 4.2306、浅支 g ≈ 1.1804，对深支作 do(Mask = 0) 后，深支选择概率约为 0.000455。这是本实现的操作化选择（份额意义），不同于场篇第一定律5 的先后判据（C₌ 下深者不后于浅者满足出流条件，C₌ 与 P₁₇ 下严格先），二者不互推。场篇第一的 κ 是由 δ、θ、S 导出的趋入条件；本式只由 g、S、d 与外生控制量 Mask、Avail 组成，不另立独立变量。

新增层保持 F\_min 的沉积链 Decay → Continuation → Trace → Sediment 的顺序。

## 第四节　LawBaseCapable 条件组

同一规格的实例须能实际容纳并区分：

　LB1　历史成沟：初态 Γ₀ = ∅，经重复作用派生 Groove 资格（Γ 为资格谓词的成立集，不等于迹应所成之沟，见 3.3 注）。  
　LB2　一次强冲：单次强作用留下完整非即时承载并真实影响后来，但不形成稳定复走能力。  
　LB3　真实动力职责：候选组织 R 的状态实际进入后继生成，效应归属于 R 而非他处（局部角色干预与对照）。记录 ≠ 治理已由上游 C5 证明，本篇不重证。  
　LB4　纯相关：两量在宏事件共现协议下相关为 1、结构可达，但一方状态不进入另一方生成。  
　LB5　稳定复走：Ω 由复走历史与结构资格推出，非规定；阈下弱迹即使复走次数达标，亦不取得 Groove 资格，Ω\_e = 0（θ 的职责见证）。  
　LB6　可达性接口：do(Avail = 0) 使同一 R 上 Reach 由 1 切换为 0，g、Ω、Γ 不变。  
　LB7　闲置旧沟：Established(R) = 1 ∧ ∃e ∈ R：Ω\_e \> 0 ∧ Reach(I,R) = 0。  
　LB8　Freeze-run：沉积关闭，持势动力继续生成。  
　LB9　退浅：无作用时迹淡，沟线可除名。

## 第五节　显式构造 Spec\_LB

### 5.1　基质

结构位（10）：a1 a2 u m1 m2 c x y z w。  
可能邻接 E（13）：a1→m1 a1→m2 a2→m1 a2→m2 m1→c m1→x m2→x m2→c u→y u→z y→w z→w y→z。  
E 为介质；Γ\_t ⊆ E 由历史派生；Γ₀ = ∅。

### 5.2　参数

α 0.05，β 0.25，g\_max 20，λ\_d = λ\_g = 0.01，θ 1.0，W 30，n\_Ω 3，κ₀ 0.05，w\_g 1.0，w\_d 0.02，s\_weak 0.4，T 0.15。

### 5.3　律侧读出

　Deposited(e) ⇔ g\_e \> 0　（有非即时沉积）  
　Groove(e) ⇔ S\_e ∧ \|rep\_e\| ≥ 2　（沟线资格）  
　职责 J = (Ante, Anchor, Read)（符号 J 以避免与结构位沉积 d\_i 冲突；代码中为 duty）：Ante 为入口位；Anchor 为一条边，其首位状态为关系前项；Read 为目标位。  
　　L：a1 ⇒ c　　　J = (a1, m1→c, c)，R1 = {a1→m1, m1→c}，承担段 Q1 = {m1→c}  
　　L\_corr：y ⇒ z　J\_corr = (y, y→z, z)，R\_corr = {y→z}  
　CarrierRealizes^inst(R,J) ⇔ Anchor ∈ R ∧ Deposited(Anchor) ∧ Ante 经 R 内 Deposited 边可达 Anchor 之尾 ∧ 经 Anchor 边本身 ∧ Anchor 之首经 R 内 Deposited 边可达 Read。Anchor 边必须实际位于承担路径上，不得只存在于 R 中。  
　CarrierNonInstant^inst　类型不变量：g 为持久状态，Deposited(e) ⇒ 非仅由当前流维持；不另作运行时检验。  
　Established^inst\_t(R,J) ⇔ R ⊆ E ∧ ∀e ∈ R：Deposited(e) ∧ CarrierRealizes^inst(R,J)  
　RolePath^inst(R,J) ⇔ Anchor ∈ R ∧ Deposited(Anchor) ∧ Mask(Anchor) = 1 ∧ Ante 经 R 内 Deposited ∧ Mask = 1 的边可达 Anchor 之尾 ∧ 经 Anchor ∧ Anchor 之首经同类边可达 Read  
　DynamicRole^inst(R,J) ⇔ RolePath^inst(R,J) = 1 ∧ 在同一冻结快照、相同入口与求解协议下，基线、do(Mask\_R = 0)、对照 do(Mask\_{R′} = 0) 三组均由该快照复制，承重场态 State\_bearing = (d, g, S, rep, Ω, Avail, θ) 保持相同，只改 Mask；do(Mask\_R = 0) 使 P̂(Read\|Ante) 下降 \> δ（本篇 δ = 0.15）而对照不产生同量变化。探测运行只推进不进入生成函数的观测计数（t\_run、log）。  
　MediumReach^inst(I,Q) ⇔ 自入口沿 Avail = 1 的邻接可达 Q 中某条 Avail = 1 的边之首位。只检验介质接入，不赋予 Q 已成结构资格；当 Q 已成（如 Q1）时可作正式 Reach 的前阶。  
　ΩSupport^pre(I,Q) ⇔ MediumReach^inst(I,Q) ∧ ∃e ∈ Q：Ω\_e \> 0  
　Inst(i,ν)　脉冲沿途经过的、进入前 Deposited = 0 的边

以上 ^inst、^pre 为本篇为运行基底诊断构造的前阶接口，不等于律数理式的 Established、DynamicRole^M、ΩSupport^M、Reach。Established 在候选组织 R 对职责 J 判定，不以单边有迹代替；一条孤立弱迹只满足 Deposited。

### 5.4　相关的测量协议

宏事件：每个外部事件 M\_k 由若干同属一标签的外生脉冲组成。Corr\_M(a,b) = #{k \| a,b 均在 M\_k 中出现} / #{k \| a 或 b 在 M\_k 中出现}。不用长窗口 presence。

### 5.5　数值记法

　P\_model　softmax 精确值；round₃(P\_model)　三位显示值，0.000 不表示严格为 0；P̂\_n　n 次冻结探测的经验频率，P̂\_2000 = 1.000 表示 2000/2000，不主张数学概率严格为 1。第六节选边概率为 round₃(P\_model)，命中率为 P̂\_2000。

## 第九节　击穿

K1　沟线不经复走即入 Γ。  
K2　单次强冲使 Ω \> 0。  
K3　在预申报 J\_corr 与宏事件协议下 Corr\_M = 1 ∧ MediumReach^inst = 1，而 DynamicRole^inst(R\_corr,J\_corr) = 1。  
K4　Freeze^inst 后 g、d、rep 或 Ω 改变；或 rep 窗口被绑定到 t\_run。  
K4′　任何以裸改 g 而不重算 S、Ω、Γ 的状态被当作 Inst(Spec\_LB) 合法见证。  
K5　删去 θ 后 LB1–LB9 全部同判（本版 LB5 弱迹对照已排除）。  
K5′　Ω 在本构造中只承担判定职责，不进入运行律。这是否为缺陷待查：律侧要求的是 ΩSupport \> 0 表示稳定复走能力存在，不自动要求 Ω 作为因果变量再入 κ；若再入，δ→κ 与 δ/历史→Ω→κ 可能重复计账。保留为待查项，不预判。  
K6　参数成功仅存在于孤立点（参数扫描未做；T = 0.15 使 LB1 概率饱和，扫描须报告 T 变化下的分布）。  
K7　律侧正式判定否定第八节任一读法，则该项见证降级；构造定理不因此失效。  
K8　律侧要求纯相关例为单脉冲分流的共因结构，本构造只以宏事件承担共因。  
K9　要求闲置旧沟由场机制自然生成，本构造须升版。  
K10　若上游 F\_min 升版改变 d、g 或四算子职责，本篇继承层须同步复核。  
K11　MediumReach^inst 只判到承担段首位；若律侧要求判到 Q\_L 全段可续行，本接口须加强。  
K8′　律侧要求纯相关例为「R 已成而不在生成链上」，本构造不能提供，只提供无承载版本。  
K12　5.3 之 Inst(i,ν) 读出在本篇无实验见证，只作接口申报。

K13　若律侧要求 Ω\_e 满足场篇第一 Ω\_W 的三项事实（含沟连接保持与各子段复走），本构造须补相应检查并升版。

## 第十节　结论与边界

本篇证明：存在运行基底规格 Spec\_LB = Augment(Spec\_min, A\_LB)，Augment 为保守扩展，LawBaseCapable(Spec\_LB) 构造成立；LawBaseDiagnosticSeparability(Spec\_LB) = Passed。两篇合起来所得：沉积场最低职责存在不依赖神经网络特定机制的可执行实现；该实现可被职责保守地扩展为律运行基底；在该基底上，律组式原本只在形式上分离的若干资格获得可区分的运行见证，以及所列干预下的分离结果（定义上的依赖照旧，如 ΩSupport^pre ⇒ MediumReach^inst）。F\_min 证明能形成稳定历史偏流；F\_LB 证明能区分这种偏流是否取得不同律侧诊断资格。

本篇不证明：参数域鲁棒性（K6 为公开缺口）；新增结构的最少性；正式成律资格 R ∈ 𝒮 与 Law(L)；Ω 是否须进入运行律（K5′）。

"""F_LB = Augment(F_min).
Inherited from Canonical F* v1.2 (最小沉积场构造式 v0.9): node depth d, relation sediment g (saturating),
Trace / Sediment / Decay / Continuation, Mode_exo / Mode_endo, softmax solver.
Added (law-base layer): pulse strength p, threshold θ, S, derived groove set Γ, replay window & Ω,
Freeze^inst (SED=OFF), Avail (availability), RoleReadMask (targeted role intervention), dual clock t_run / t_sed, IdleStep (decay only), Established^inst(R)."""
import math, random, copy
from collections import defaultdict, deque

class FLB:
    def __init__(self, nodes, medium, alpha=0.05, beta=0.25, g_max=20.0, lam_d=0.01, lam_g=0.01,
                 theta=1.0, W=30, n_omega=3, kappa0=0.05, w_g=1.0, w_d=0.02, s_weak=0.4, T=0.15, seed=0):
        self.nodes=nodes; self.E=list(medium); self.out=defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        # inherited persistent state
        self.d={n:0.0 for n in nodes}; self.g={e:0.0 for e in self.E}
        # added persistent state
        self.rep={e:deque() for e in self.E}; self.Om={e:0.0 for e in self.E}
        self.th={e:theta for e in self.E}; self.Avail={e:1 for e in self.E}
        self.alpha,self.beta,self.g_max,self.lam_d,self.lam_g=alpha,beta,g_max,lam_d,lam_g
        self.W,self.n_omega,self.k0,self.w_g,self.w_d,self.s_weak,self.T=W,n_omega,kappa0,w_g,w_d,s_weak,T
        self.t_run=0; self.t_sed=0; self.SED=True; self.rng=random.Random(seed); self.log=[]; self.macro=None
        self.mask={e:1 for e in self.E}   # RoleReadMask: exogenous control quantity (not sediment, not decayed, persists until re-intervened)
    # ---------- inherited operators
    def Decay(self):
        """one sediment-clock step: t_sed advances; depths decay; replay windows (on t_sed) expire."""
        self.t_sed+=1
        for n in self.nodes: self.d[n]=max(0.0,self.d[n]-self.lam_d)
        for e in self.E:
            self.g[e]=max(0.0,self.g[e]-self.lam_g)
            while self.rep[e] and self.t_sed-self.rep[e][0]>self.W: self.rep[e].popleft()
            self.Om[e]=self._omega(e)
    def Trace(self,e,p): return {'e':e,'p':p}
    def Sediment(self,tau):
        e,p=tau['e'],tau['p']
        self.d[e[0]]+=self.alpha*p; self.d[e[1]]+=self.alpha*p
        self.g[e]=min(self.g_max,self.g[e]+self.beta*p*(1-self.g[e]/self.g_max))
        self.rep[e].append(self.t_sed); self.Om[e]=self._omega(e)
    def kappa(self,e):
        if not self.Avail[e]: return -1e9
        return self.k0+self.w_g*self.mask[e]*self.g[e]*(1.0 if self.S(e) else self.s_weak)+self.w_d*self.d[e[1]]
    def Continuation(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        if not cand: return None
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]
        r=self.rng.random()*sum(ws)
        for e,w in zip(cand,ws):
            r-=w
            if r<=0: return e
        return cand[-1]
    def probs(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return {e[1]:w/z for e,w in zip(cand,ws)}
    # ---------- added layer
    def S(self,e): return self.g[e]>=self.th[e]
    def Deposited(self,e): return self.g[e]>0
    def Groove(self,e): return self.S(e) and len(self.rep[e])>=2
    def Gamma(self): return {e for e in self.E if self.Groove(e)}
    def _omega(self,e):
        n=len(self.rep[e]); return 0.0 if (n<self.n_omega or not self.S(e)) else min(1.0,n/(2*self.n_omega))
    def Freeze(self): self.SED=False
    def Thaw(self): self.SED=True
    def SetAvail(self,e,v): self.Avail[e]=v
    def IdleStep(self,n=1):
        for _ in range(n): self.Decay()          # t_sed advances only
    def SetMask(self,e,v): self.mask[e]=v          # targeted role intervention (structure untouched)
    # ---------- pulse
    def pulse(self,entry,p=1.0,path=None,maxhop=6):
        self.t_run+=1
        if self.SED: self.Decay()                 # t_sed advances only when sediment law is on
        q=entry; route=[q]; inst=[]
        for h in range(maxhop):
            if path is not None:
                if h>=len(path)-1: break
                e=(path[h],path[h+1])
            else:
                e=self.Continuation(q)
                if e is None: break
            if not self.Deposited(e): inst.append(e)
            if self.SED: self.Sediment(self.Trace(e,p))
            q=e[1]; route.append(q)
            if not self.out[q]: break
        self.log.append((self.t_run,entry,tuple(route),self.macro))
        return route,inst
    # ---------- law-side readouts
    # duty = dict(ante=entry node, anchor=edge whose head state is the relation's antecedent, read=target node)
    def _closure(self,start,edges):
        adj=defaultdict(list)
        for (i,j) in edges: adj[i].append(j)
        seen={start}; st=[start]
        while st:
            x=st.pop()
            for y in adj[x]:
                if y not in seen: seen.add(y); st.append(y)
        return seen
    def CarrierRealizes_inst(self,R,duty):
        """R alone (restricted) carries Ante ⇝ Anchor.tail —Anchor→ Anchor.head ⇝ Read, all on deposited edges of R;
        the anchor edge itself must be traversed (it is deposited and on the path)."""
        a=duty['anchor']
        if a not in R or not self.Deposited(a): return False
        dep=[e for e in R if self.Deposited(e)]
        return a[0] in self._closure(duty['ante'],dep) and duty['read'] in self._closure(a[1],dep)
    def Established_inst(self,R,duty):
        """R ⊆ E ∧ ∀e∈R Deposited ∧ CarrierRealizes_inst. CarrierNonInstant is a type invariant here:
        g is persistent state, so Deposited(e) ⇒ not flow-only."""
        return set(R)<=set(self.E) and all(self.Deposited(e) for e in R) and self.CarrierRealizes_inst(R,duty)
    def MediumReach_inst(self,entry,Q):
        """medium access only: entry reaches the head of some Avail=1 edge in Q via Avail=1 edges. Does not require Q deposited."""
        seen=self._closure(entry,[e for e in self.E if self.Avail[e]])
        return any(self.Avail[e] and e[0] in seen for e in Q)
    def RolePath_inst(self,R,duty):
        """a deposited, mask-open path inside R from the anchor state to Read."""
        a=duty['anchor']
        if a not in R or not (self.Deposited(a) and self.mask[a]): return False
        open_edges=[e for e in R if self.Deposited(e) and self.mask[e]]
        return a[0] in self._closure(duty['ante'],open_edges) and duty['read'] in self._closure(a[1],open_edges)

def OmegaSupport_pre(F,entry,Q):
    """pre-stage interface for this construct only: MediumReach_inst(I,Q) ∧ ∃e∈Q Ω_e>0. Not the formal ΩSupport^M."""
    return F.MediumReach_inst(entry,Q) and any(F.Om[e]>0 for e in Q)

    g,rep,Ω unchanged under both masks."""

    base=hit_prob(F,duty['ante'],duty['read'],n)
    L=copy.deepcopy(F)
    for e in R: L.SetMask(e,0)
    pm=hit_prob(L,duty['ante'],duty['read'],n)
    inv=(L.g==F.g and L.Om==F.Om and {e:len(L.rep[e]) for e in L.E}=={e:len(F.rep[e]) for e in F.E})
    pc=None
    if control_R:
        C=copy.deepcopy(F)
        for e in control_R: C.SetMask(e,0)
        pc=hit_prob(C,duty['ante'],duty['read'],n)
    ok=inv and (base-pm)>delta and (pc is None or abs(base-pc)<=delta)
    return ok,dict(P_hat_base=base,P_hat_Rmask=pm,P_hat_ctrlmask=pc,invariants=inv)
def hit_prob(F,entry,target,n=2000):
    G=copy.deepcopy(F); G.Freeze(); c=0
    for _ in range(n): c+= target in G.pulse(entry)[0]
    return c/n

def corr_M(F,a,b):
    """macro-event co-occurrence: Corr_M = #{k: a,b both in M_k} / #{k: a or b in M_k}."""
    ev=defaultdict(lambda:[False,False])
    for _,_,r,m in F.log:
        if m is None: continue
        if a in r: ev[m][0]=True
        if b in r: ev[m][1]=True
    both=sum(1 for x,y in ev.values() if x and y); either=sum(1 for x,y in ev.values() if x or y)
    return both/either if either else 0.0
