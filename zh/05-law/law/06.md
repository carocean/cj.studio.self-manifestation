# 律判定式

## 第一节　目的

本篇为判定式。用途：给出由观测集 Y 判定性质 P 成立与否的程序与判据，双向有效或显式申报误判界。

　　P := R ∈ 𝒮(F\_LB, L, I)。

𝒮 按《律数理式》(4.7)：R ∈ 𝒮 ⇔ EstWitness^M ∧ Govern^M。本篇不重新定义任何上游谓词，不承担律的本体证明；只把已封版判据变为 F\_LB 上可执行的判定协议，并在正负实例上运行。

判定域申明：本篇判定域为冻结快照上的单职责、单入口（I = {Ante(L)}）、measure 型（权重型）候选。参考实现之接口即按此收窄：候选数据结构（duty）只容纳单职责、measure 型；运行时另检查单入口 I = {Ante}，不满足者输出 ⊥；程序接收可冻结之 F\_LB 状态并先生成 Freeze^inst 快照后判定。多职责、set 型、混合型候选不属本实现之定义域，其判定归本篇后续版本。

I\_cov 核对　《律数理式》 起，各覆盖型判据与 DynamicRole 的量化域为适用覆盖守卫域 I\_cov(L,I) = {i ∈ I \| Trig(i) ≠ ∅}。本篇判定域为单入口 I = {Ante(L)}，而候选 L 对该入口有职责声明（Trig ≠ ∅），故 I\_cov(L,I) = I，本篇五案例之判定不受该守卫域收窄影响。多入口判定域下须逐入口核 Trig，归本篇后续版本。

进入条件核验：P 之定义已闭合（《律数理式》）；Y 已界定（第三节）；P 与 Y 的前向关系已由成立之式给出（数理式第三、四节 + 律组式第五接口实物 + 本篇协议 PR1–PR4，协议失效条件入误判界）。

## 第三节　性质与观测集申报

### 3.1　判定场景

判定在 Freeze^inst 快照上进行，快照中无在途脉冲。  
引理 3.1（底本坍缩）　冻结快照中 Existing\_t = Estab\_t = {e \| g\_e \> 0}。证明：律组式第五 5.3 之接口定义 Existing\_t = {e \| g\_e \> 0} ∪ 当前有流之边，Drive^inst = 仅由流维持之边；快照无在途脉冲，故有流边集为空，Existing\_t = {g \> 0} = Estab\_t。□  
由引理 3.1，RoleBase = ReplayBase，RoleCtx(i,ν) = ReplayCtx(i,ν)（数理式 3.18 两式在同一底本、同一条件下逐项相同），AdmPair = ReplayPair；数理式定理 4.16 之前件在本场景成立。

### 3.2　观测集

　　Y\_LB = (Y\_struct, Y\_path, Y\_int)：  
　Y\_struct　冻结快照结构量：每边 (g\_e, S\_e, Ω\_e, rep\_e, Avail\_e, Mask\_e, θ\_e)，每位 d\_i；  
　Y\_path　　穷举路径族 Eval(Ctx) 及其精确测度 μ\_LB。跳数上限 H = 6 为 F\_LB 规格量，Eval 有限，测度为各跳 softmax 概率之积（数理式 3.7′ 由 K 诱导），无采样；  
　Y\_int　　 Prot\_LB 许可干预（do(Mask)、do(Avail)、Freeze、IdleStep）下对上述二者的重读。

排除项：任何采样频率 P̂\_n；任何非冻结可读量。判据不依赖 Y\_LB 之外的量。

### 3.3　候选律申报

　　L\_{0.9}: a1 ⇒ c。  
　职责 J = (Ante, Anchor, Read)：Ante = 脉冲 p = 1 入 a1；Anchor = 边 m1→c 之状态 (g\_{m1→c}, S\_{m1→c})；Read = μ\_LB(路径含 c \| Ante) ≥ π₀，π₀ = 0.9。  
　Type(J) = 权重型；EvalMode(J) = measure；ε\_role = 0.01；D = 全变差距离。  
　Cov(L) = 全部 p = 1 之 a1 入流；I = {a1} = {Ante(J)}（单入口，属本篇判定域）；候选承载 R1 = {a1→m1, m1→c}。  
　ModeSet(L, a1) = {measure}，MixedMode = 0，EvalMode(L, a1) = measure。

负例候选：  
　L\_corr,{0.9}: y ⇒ z，J\_corr = (y 入流, (g\_{y→z}, S\_{y→z}), μ\_LB(含 z \| y) ≥ 0.9)，R\_corr = {y→z}，I = {y}；  
　闲置旧沟、一次强冲、阈下弱迹均用 L\_{0.9} 原职责，仅场态不同。

π₀ 与 ε\_role 为 Rel(L) 之内容，非本篇自由参数。

## 第四节　实例协议

数理式对象落到 F\_LB 须四条协议。协议为申报项，不改上游定义；各自失效条件入第七节误判界。

　PR1（受限评价核）　κ\_P 之"P 外结构不可用"读作：各选边核 K\_y 限制到 P 内出边并重归一；位置于 P 内无出边者为死端。死端评价不贡献 Read 之满足质量：权重型整体读出将死端质量计为不满足（非 ⊥——死端是已定义之失败，⊥ 只留给不可测、不可求）。死端质量为满测度时 CR 判 0。  
　PR2（变动族网格与其有效性条件）　AdmVar 中结构状态 g 之许可域为 \[0, g\_max\]；程序在端点网格 {0, g\_max} 之积上求全变差之最大。定义有效性条件 PR2-valid(F, q, C) :⇔ sup\_{AdmVar} TV = max\_{端点网格} TV。三点申明：  
　(a) 单自由量情形 PR2-valid 可证：κ 对 g 分段线性且跨阈上跳，处处单调不减；仅一 logit 变动时，softmax 目标坐标单调、其余坐标同向递减，TV(t₁,t₂) = \|p\_j(t₁) − p\_j(t₂)\|，沿单调路径于域端点达最大。□  
　(b) 多自由量情形 PR2-valid 为未证条件，K-J1 承其击穿。  
　(c) 网格之否定方向无条件可靠：网格上找到一对分布 TV \> ε\_role 即证不充分，无论 sup 是否被网格达到。  
本组五案例中，全部"充分"授予点之自由量集为空（平凡精确），全部"不充分"判定由网格反例给出（(c) 无条件可靠），故五案例之判定不依赖 PR2-valid。  
　PR3（承担段与 Ω 域）　F\_LB 之 Ω 定义于边；ReqSeg 读作 Bear 中沟线边本身，ΩOK ⇔ ∀e ∈ Bear: Ω\_e \> 0。  
　PR4（宿主约定与链延续）　当前位置与选边节点为无宿主纯流量（Hosts = ∅）；结构状态节点之 Hosts 为该边。Comp 只收结构边，与律组式第五 5.3 一致。  
链延续论证：F\_LB 各选边核以当前位置为必需输入——固定全部边状态而变动位置，分布整族改变，故位置属该核每个 μ-充分组；位置又是上一选边之确定函数。于是 FullChain 经"选边 → 位置 → 下一选边"自动延续，多跳承担路径上唯一非平凡的 ActArg^μ 检查集中于 Anchor 之尾位。judge 之"Anchor 充分组 + R 内可达"因此对多跳承担段亦完整，非仅对单跳。

## 第五节　判据构造

判定程序（逐级，输出首个失败谓词；全过判 R ∈ 𝒮）：

　　Y\_LB → CC → CR → CNI → Dyn → ΩSupport → Bind → P。

程序之定义域由接口收窄（duty 结构单职责、measure 型）并运行时检查单入口（I ≠ {Ante} 输出 ⊥）；对合域候选，先生成冻结快照，再对实现存在量词作穷举：对每个含 Anchor 之 P ⊆ R，构造正则见证 Π\_P（承载 P，见证族 W = ResEval(κ\_P) 全族，PR1），逐级检验；R 通过当且仅当存在 P 使 Π\_P 四级全过。失败定位取诸 P 中达到之最深级。各级：

　CC　CurrentCarrier^M：R ≠ ∅ ∧ R ⊆ E ∧ ∀e ∈ R: g\_e \> 0。（数理式 3.34）  
　CR　CarrierRealizes^M（权重型）：Anchor ∈ P ∧ μ\_LB^{κ\_P}(Read \| Ante) ≥ π₀，受限测度按 PR1 精确计算。（3.35、3.21）  
　CNI　CarrierNonInstant^M：由归约引理给出，程序断言其前件。  
引理 5.1（CNI 归约）　冻结快照 ∧ CC ∧ CR(Π\_P) ⇒ CarrierNonInstant^M 于该 (L,R,I) 成立。证明链：AdmPair 之每个 (i,ν) 下，Π\_P 之各 ρ\_d 的 Supp ⊆ P（PR1 受限评价只用 P 内结构），故 Q(Π\_P) ⊆ P ⊆ R；CC 给 ∀e ∈ R: g\_e \> 0，引理 3.1 给 Estab = {g \> 0}，故 Q(Π\_P) ⊆ Estab\_t；又 Inst(i,ν) 只含进入前 g = 0 之边；冻结期间沉积律关闭、g 不更新（律组式第五 LB8：Freeze 下 g 逐位不变，K4 承其击穿），且快照无在途脉冲，故评价进入前之 g 即快照之 g，CC 给 P 内各边快照 g \> 0，遂进入前亦 g \> 0，P ∩ Inst(i,ν) = ∅，Bear ∩ Inst = ∅（数理式 3.40 (iv)）自动成立；实现见证为非即时联合实现。诸 ν 共享同一冻结结构，故 ∀^{Role} 逐点成立。□（3.36）  
　Dyn　DynamicRole^M：Anchor 状态属 Anchor 之尾位处某极小 μ-充分组（按 3.10′ 于 PR2 网格穷举全部极小组），且自 Anchor 之首经 P 内 Deposited ∧ Mask = 1 之边可达 Read（RolePath，3.32；多跳之完备性由 PR4 链延续论证给出）。（3.38）  
　ΩSupport　Reach^inst(I, P)（沿 Avail = 1 邻接可达 P 中某非封边之首位；只判至首位，律组式第五 K11）∧ ΩOK 于 Π\_P 之 Bear（PR3）。承担段自身被封之世界由 CR 前级拦截（受限核于该处死端，PR1）。（3.43、3.41）  
　Bind　由坍缩引理给出，不另设无条件通过。  
引理 5.2（Bind 坍缩）　冻结快照下，若 Π\_P 通过 ΩSupport 级且通过 Dyn 级，则 Bind^M 之存在条件 ∃Π(ΩWit ∧ Π ∈ Scheme) 由同一 Π\_P 见证。证明：Scheme\_R(L,i,ν) = {Π ∈ ExtJointReal^{ReplayCtx} \| ∀d: ρ\_d ∈ RoleReal^{ReplayCtx}(d)}（数理式 3.44），其条件全部在 ReplayCtx 内，无跨上下文要求；RoleReal^κ(d) = {ρ ∈ ExtReal^κ(d) \| RolePath^κ\_ρ(d) ≠ ∅}（3.33，κ 取 ReplayCtx）。Π\_P 过 ΩSupport 级即 ΩWit(Π\_P)；Π\_P 过 Dyn 级即 RolePath^{ReplayCtx}\_{ρ\_P}(d) ≠ ∅（引理 3.1 使 RoleCtx = ReplayCtx，Dyn 级之 RolePath 检验即在此上下文），故 ρ\_P ∈ RoleReal^{ReplayCtx}(d)，Π\_P ∈ Scheme。存在量词由 Π\_P 满足。□  
注　引理 5.2 只证 ⇐ 方向（同一见证充分）；程序判 Bind = 1 恒经此见证，故无假正。判 0 之完备性（不存在正则族外之成功 Π）由引理 5.3 给出。

引理 5.3（正则见证完备归约）　冻结、单职责 D = {J}、权重型、PR1 之下，对任意 P ⊆ R：合法实现见证之全体恰为 {Π\_P = {(P, ResEval(κ\_P, ν))} \| Anchor ∈ P}；故对含 Anchor 之 P 穷举即对合法见证穷举。证明：(i) 分量归约——单职责下 Π = {ρ\_J}（3.25），ρ\_J = (P, W)（3.23），Π 之自由分量仅 P 与 W；Bear、Acc、Q、RolePath、ΩWit、Scheme 资格均为 (P, W, ν) 之派生性质，非自由分量（3.23："其 Bear、Acc、ReqSeg、RolePath 均以自身之 W 计算"）。(ii) W 唯一——权重型下 W = ResEval(κ\_P, ν)，不取子族（3.21），故给定 P 时 W 唯一，ρ 唯一，Π 唯一 = Π\_P。(iii) Anchor 必要——Anchor ∉ P 时受限评价无 Anchor 状态，BearNodes 自 RelState(J) 起为空，Bear = ∅，Realized = 0（3.23 要求 Bear ≠ ∅），故此类 P 无合法见证，程序跳过不损完备。□  
于是真则判真所需的"正式系统存在成功 Π ⇒ 程序命中之"由 (i)(ii)(iii) 与穷举给出。

参考实现 ljudge.py（附录 A）：全部为精确计算——有限枚举加闭式 softmax，无蒙特卡洛，无近似环节。

## 第七节　误判界

　7.1　多自由量情形之充分性授予依赖 PR2-valid；本篇未证明其普遍成立。若存在 sup\_{AdmVar} TV \> ε\_role 而端点网格最大值 ≤ ε\_role，程序会错误授予 μ-充分性。五案例不触此界（充分性授予点自由量集均空）。击穿 K-J1。  
　7.2　PR1 之受限核重归一为"P 外不可用"的一种读法，其效应：弱迹在 CR 处放行（P 内唯一路径被迫走）。替代读法为保留原核、竞争质量计入死端，此读法下弱迹之受限测度 = 0.3745 \< π₀（实算），CR 反转为 0，失败位置前移。二读法之裁定归上游。击穿 K-J2。  
　7.3　π₀、ε\_role 为 Rel(L) 内容；μ 为精确值无测量误差，但 μ 落 π₀ 邻域时判定对申报敏感。本组案例 μ ∈ {0, 1}，不触界。  
　7.4　闲置旧沟失败于 CR 而非"Est = 1、仅 Reach 败"：数理式 EstWitness 含 CarrierRealizes(L;R,I)，R 自身之边被封则实现不成立。律组式第五 Est^inst 为 Deposited + 连通，弱于正式 EstWitness；两表之差为定义层级不同，非矛盾。此项为本篇对律组式第五诊断表的正式修订记录。  
　7.5　Bind 之判定经引理 5.2 于冻结快照成立；非冻结判定或存在型/混合型职责下坍缩不适用，须独立 Bind 判据。Bind 之独立失败世界（数理式 4.17）在当前 F\_LB 拓扑中尚未构造；这不影响引理 5.2 之同一见证充分向，正则见证穷举之完备性由引理 5.3 承担。击穿 K-J3。  
　7.6　律组式第五 DynamicRole^inst 之 do(Mask) 干预效应对照未纳入本程序；本程序按 3.10′ 形式定义直接求 ActArg^μ。二者一致性未验。击穿 K-J4。  
　7.7　动态稳定（律稳定式之 T\_obs、T\_rec、轨迹族）不在本篇；本篇只判冻结快照上的静态资格。

## 第八节　判定定理

定理（相对协议与引理前件的双向有效性）　设 M1–M6 于 F\_LB 成立，PR1、PR3、PR4 为所取协议，且 PR2-valid 于程序全部充分性授予点成立（自由量集为空或单量时自动成立）。则对任意满足本篇候选规格的冻结快照 F（无在途脉冲）及单职责、单入口权重型候选 (L, R, I)，I = {Ante(L)}：

　judge(F, L, R, I) 输出 PASS ⇔ 数理式之 CC、CR、CNI、Dyn、ΩSupport、Bind 在该实例协议读法下全部为 1，即 R ∈ 𝒮；  
　judge 输出 FAIL @ X ⇔ X 为诸实现 P 所达最深级之失败判据。

证明　真则判真：诸级判据成立 ⇒ 存在见证；由引理 5.3，合法见证全体 = {Π\_P \| Anchor ∈ P ⊆ R}，程序穷举之，必命中成立见证；CNI 由引理 5.1、Bind 由引理 5.2 随 CR、Dyn、ΩSupport 成立。假则判假：程序判 PASS 只经某 Π\_P 之逐级检验，各级为对应判据在有限对象上的精确求值——CC 有限合取，CR 受限测度为有限路径和（PR1），Dyn 之充分性授予在 PR2-valid 下等于 AdmVar 上确界判定、否定由网格反例无条件可靠，RolePath 有限图可达（PR4 链延续），ΩSupport 有限检查（PR3），Bind 经引理 5.2 之显式见证——故 PASS ⇒ 各判据为 1。□

强度：相对 PR1、PR3、PR4、PR2-valid 与引理 3.1、5.1、5.2、5.3 前件（冻结、无在途脉冲、权重型、单职责、单入口 I = {Ante}）的双向有效。协议与前件之合法性由第七节误判界承担；此为法篇十一章"不能两全处显式列出"之执行。

"""ljudge.py — 《律判定式》参考实现 v1.0
P := R ∈ 𝒮(F_LB, L, I)，按律数理式 v1.2 在 F_LB(flb.py v1.0) 冻结快照上精确判定。
观测集 Y_LB：冻结快照结构量 (g,S,Ω,rep,Avail,Mask,θ) + 穷举路径族 Eval 及其精确测度 μ_LB。
不用蒙特卡洛；所有概率为 softmax 精确值的有限乘积与求和。
候选 L 均为权重型：EvalMode = measure，ε_role = 0.01，Read: μ(路径含 Read 位 | Ante) ≥ π₀ = 0.9。
"""
import math, copy, itertools
from collections import defaultdict
import sys; sys.path.insert(0,'/home/claude')
from flb import FLB, fresh, MED, NODES

MAXHOP=6

# ---------- kernel & exact path measure ----------
def kernel(F,q,avail=None,mask=None):
    """K_y at position q: distribution over out-edges, from state only (exact)."""
    avail=avail or F.Avail; mask=mask or F.mask
    cand=[e for e in F.out[q] if avail[e]]
    if not cand: return {}
    ks=[]
    for e in cand:
        k=F.k0+F.w_g*mask[e]*F.g[e]*(1.0 if F.S(e) else F.s_weak)+F.w_d*F.d[e[1]]
        ks.append(k/F.T)
    m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
    return {e:w/z for e,w in zip(cand,ws)}

def eval_paths(F,entry,edges_allowed=None,maxhop=MAXHOP):
    """Exhaustive Eval(Ctx): all routes with exact μ. edges_allowed=None → all; else restrict (κ_P)."""
    out=[]
    def rec(q,route,prob,hops):
        K=kernel(F,q)
        if edges_allowed is not None:
            K={e:p for e,p in K.items() if e in edges_allowed}
            z=sum(K.values())
            if z==0: out.append((tuple(route),prob,'dead')); return
            K={e:p/z for e,p in K.items()}   # 受限评价：P 外结构不可用，核在 P 内重归一
        if not K or hops>=maxhop: out.append((tuple(route),prob,'end')); return
        for e,p in K.items(): rec(e[1],route+[e[1]],prob*p,hops+1)
    rec(entry,[entry],1.0,0)
    return out

def mu_read(F,entry,target,edges_allowed=None):
    return sum(p for r,p,_ in eval_paths(F,entry,edges_allowed) if target in r)

# ---------- ActArg^μ at a choice node (weighted duty) ----------
def actargs_at(F,q,eps=0.01):
    """minimal μ-sufficient groups over per-edge state fixings at position q.
    AdmVar: each out-edge's g varies over its admissible domain. The implementation evaluates
    endpoint grids {0,g_max} (S recomputed): single-free-variable sufficiency is exact, while
    multi-variable positive sufficiency is conditional on PR2-valid (paper §4 PR2, §7.1);
    negative verdicts from grid counterexamples are unconditionally sound."""
    cand=[e for e in F.out[q] if F.Avail[e]]
    def dist(gvals):
        ks=[]
        for e in cand:
            g=gvals[e]; S=1.0 if g>=F.th[e] else 0.0
            k=F.k0+F.w_g*F.mask[e]*g*(1.0 if S else F.s_weak)+F.w_d*F.d[e[1]]
            ks.append(k/F.T)
        m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return [w/z for w in ws]
    def tv(p,qq): return 0.5*sum(abs(a-b) for a,b in zip(p,qq))
    base={e:F.g[e] for e in cand}
    def sufficient(C):
        freevars=[e for e in cand if e not in C]
        if not freevars: return True
        grids=[[0.0,F.g_max] for _ in freevars]
        dists=[]
        for combo in itertools.product(*grids):
            gv=dict(base); gv.update({e:v for e,v in zip(freevars,combo)})
            for e in C: gv[e]=base[e]
            dists.append(dist(gv))
        return max(tv(a,b) for a in dists for b in dists)<=eps
    minimal=[]
    for r in range(len(cand)+1):
        for C in itertools.combinations(cand,r):
            if sufficient(set(C)) and not any(set(M)<=set(C) for M in minimal):
                minimal.append(C)
    return set(u for M in minimal for u in M), minimal

# ---------- duty / candidate law ----------
def duty(ante,anchor,read): return dict(ante=ante,anchor=anchor,read=read)

# ---------- the judging pipeline ----------
def _judge_P(F,L,P,R,pi0,eps):
    """evaluate CR/CNI/Dyn/ΩSupport on one implementation P ⊆ R (canonical witness Π_P: W=ResEval(κ_P), PR1).
    Returns (depth_reached, detail). Depth order: CR=1, CNI=2, Dyn=3, ΩSupport=4 (all-pass)."""
    ante,anchor,read=L['ante'],L['anchor'],L['read']; d={}
    m_res=mu_read(F,ante,read,edges_allowed=set(P))
    d['P']=[f"{e[0]}→{e[1]}" for e in sorted(P)]
    d['CR']=dict(anchor_in_P=anchor in P,mu_restricted=round(m_res,4),pi0=pi0)
    if not (anchor in P and m_res>=pi0): return 0,d
    # CNI by reduction lemma: frozen ⇒ Estab={g>0}; witnesses under PR1 have Q(Π)⊆P⊆R⊆Estab (CC);
    # Bear∩Inst=∅ automatic since P has no g=0 edge. Assert the lemma's premises:
    assert all(F.g[e]>0 for e in P), "CNI reduction premise violated"
    d['CNI']=dict(by_reduction_lemma=True,Q_subset_Estab=True)
    # Dyn on Π_P
    aa,minimal=actargs_at(F,anchor[0],eps)
    adj=defaultdict(list)
    for (i,j) in P:
        if F.g[(i,j)]>0 and F.mask[(i,j)]: adj[i].append(j)
    seen={anchor[1]}; st=[anchor[1]]
    while st:
        x=st.pop()
        for y2 in adj[x]:
            if y2 not in seen: seen.add(y2); st.append(y2)
    rolepath=(anchor in aa) and (read in seen or read==anchor[1])
    d['Dyn']=dict(ActArg_at_anchor_tail=[f"{e[0]}→{e[1]}" for e in sorted(aa)],minimal_groups=[[f"{e[0]}→{e[1]}" for e in M] for M in minimal],anchor_in_ActArg=anchor in aa,rolepath=rolepath)
    if not rolepath: return 2,d
    # ΩSupport on Π_P
    seenA=F._closure(ante,[e for e in F.E if F.Avail[e]])
    reach=any(F.Avail[e] and e[0] in seenA for e in P)
    bear=[e for e in P if e==anchor or (anchor[1]==e[0] or e[0] in seen)]
    omega_ok=all(F.Om[e]>0 for e in bear)
    d['ΩSupport']=dict(Reach=reach,Bear=[f"{e[0]}→{e[1]}" for e in bear],Omega={f"{e[0]}→{e[1]}":round(F.Om[e],2) for e in bear})
    if not reach: return 3,dict(d,fail='Reach')
    if not omega_ok: return 3,dict(d,fail='ΩOK')
    return 4,d

def judge(F,L,R,I,pi0=0.9,eps=0.01,verbose=True):
    """Decision domain: single-duty, single-entry I={Ante}, measure-type candidate;
    the input F_LB state is converted to a Freeze^inst snapshot before judging.
    Existential over implementations: R passes iff ∃P ⊆ R (anchor ∈ P) whose canonical witness Π_P
    passes CR∧CNI∧Dyn∧ΩSupport; Bind then follows by the collapse lemma (frozen: RoleCtx=ReplayCtx,
    same Π_P bears ΩWit and ρ_P ∈ RoleReal via its Dyn check). fail_at = deepest level reached over all P."""
    T={}
    # interface domain: duty structure admits single-duty measure-type candidates only;
    # runtime guard below checks single entry I={Ante}; F is frozen into a Freeze^inst snapshot before judging
    if list(I)!=[L['ante']]:
        T['fail_at']='⊥(判定域外: 本篇只判单职责、单入口 I={Ante} 之权重型候选)'
        if verbose: print(T['fail_at'])
        return None,T
    F=copy.deepcopy(F); F.Freeze()
    T['Y']={e:(round(F.g[e],2),int(F.S(e)),round(F.Om[e],2),F.Avail[e],F.mask[e]) for e in F.E if F.g[e]>0 or e in R}
    cc = len(R)>0 and all(e in F.E for e in R) and all(F.g[e]>0 for e in R)
    T['CC']=cc
    if not cc: return _out('CC',T,verbose)
    anchor=L['anchor']
    best=(-1,None)
    for r in range(1,len(R)+1):
        for Pt in itertools.combinations(R,r):
            if anchor not in Pt: continue
            depth,detail=_judge_P(F,L,set(Pt),R,pi0,eps)
            if depth>best[0]: best=(depth,detail)
            if depth==4: break
        if best[0]==4: break
    depth,detail=best
    for k in ('P','CR','CNI','Dyn','ΩSupport'):
        if detail and k in detail: T[k]=detail[k]
    if depth==4:
        T['Bind']=dict(by_collapse_lemma=True,value=True)
        T['verdict']='R ∈ 𝒮'
        return _out(None,T,verbose)
    fail=['CR','CNI','Dyn',('ΩSupport(Reach)' if detail and detail.get('fail')=='Reach' else 'ΩSupport(ΩOK)')][depth if depth<3 else 3]
    return _out(fail,T,verbose)

def _out(fail,T,verbose):
    T['fail_at']=fail
    if verbose:
        print(("PASS  R∈𝒮" if fail is None else f"FAIL @ {fail}"))
        for k,v in T.items():
            if k!='fail_at': print(f"  {k} = {v}")
    return (fail is None),T

def _lb1(seed=1):

    for k in range(60): F.pulse('a1',1.0,path=['a1','m1','c']); F.pulse('a2',1.0,path=['a2','m2','x'])

L1=duty('a1',('m1','c'),'c')
