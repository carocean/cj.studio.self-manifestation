自显论·律篇·律组式第八 v1.2

# 律边界式

## 第一节　目的与式种

本篇为极限式（《法篇第一》第二编第四章第一组"边界辨析附式"；第四编第一章极限式规范：在主式已经给出结构之后，辨明该结构成立的边界）。本篇之"极限"即《律一般式》所给结构在预声明比较域中的成立边界，极限方向与极限条件由比较规约 Γ 申报，非趋于无穷之渐近意义。本篇不取分级式（不给层级或比较关系），不取消解式（不消解表观矛盾），不取稳定式：不研究保持、替代与复归作为稳定过程，不求其发生参数、稳定宽度与恢复位置（该三事归《律稳定式》）；但在判定 Law 是否真正越界时，允许读取「右端是否存在替代见证」这一结构事实（定理 4.3、4.4、7.1）——读取一个集合级事实与研究其过程分属两事。

本篇唯一中心问题：

　　同一律在预声明比较中，何时从成立跨到不成立，或反之？

即：固定候选律 L 及其关系内容 Rel(L) 的同一性（否则不成其为"同一律"之边界）；由比较规约 Γ 预声明 F、t、I 及其余比较量中哪些固定、哪些允许变化；研究同一 L 在各合法比较态之间之真值跨越

　　Law\_Γ(X⁻) ≠ Law\_Γ(X⁺)

之发生位置与结构条件。

本篇不研究边界如何形成。律为何生成、为何被替换、为何相互竞争、Ω 如何随时间增长或衰退、律如何迁移分裂合并——皆属未来《律动力》，本篇一律不涉。本篇亦不做参数扫描、阈值求解、稳定宽度与数值算法（归《律稳定式》），不做候选枚举、可操作性测定与 PASS/FAIL/⊥ 执行程序（归《律判定式》）。

本篇不新增本体谓词，不新增场量，不新增待验桥。

## 第二节　核心论题

边界是 \*\*Law 真值的跨越\*\*，不是任何下层量的跨越。

三条负面命题构成本篇的纪律：

　结构失效不自动等于 Law 边界——某个 R 失去资格，只说明该见证退出，Law 可由别的见证继续承担；  
　形式失效不自动等于 Law 边界——形式解集 𝒮 变空须经相应表示条件才转为 Law 假；Bind^M 之失只属形式耦合层；  
　参数临界不自动等于 Law 边界——《律稳定式》所定固定见证边界 q\_fix^∂ 是见证级事件，须另证其恰为最后见证之灭绝方可升级。

正面则有三层判据：结构见证层（第四节）、形式解层（第五节）、适用域层（第六节）。三层各有自己的跨越条件与自己的条件束。

本篇之一项特别成果是：\*\*边界端点非对称\*\*——认证一次具体边界，不必先在整个比较域上建立 Law ⇔ 𝒮 ≠ ∅，正端与负端各自承担不同的证明义务即可（定理 5.2）。

## 第三节　基础对象

标注：〔S〕结构层对象；〔辅〕纯形式辅助对象，无本体对应物，不回读。

### 3.1　比较规约

定义 3.1〔辅〕（比较规约）　Γ 为一次边界研究的预声明比较规约，规定：

　(i) 固定量——比较中保持不变者（至少含 L 与 Rel(L)：同一律为比较之前提）；  
　(ii) 可变量——允许变化者，及其合法变化方式；  
　(iii) 比较分辨率——两个比较态在何种精度下算作可分；  
　(iv) 比较方向——沿何序或何参数比较；  
　(v) 同一性识别——若场结构发生变化，如何识别"同一个承载组织"。

Γ 须在比较开始前完成申报，不得因出现反例而事后修改。记 X 为 Γ 下之一个比较态（其内容含 F、t、I 及 Γ 所许可之其余变化）。

定义 3.2〔辅〕（承载对应）　τ\_Γ 为 Γ 之 (v) 项所给的承载对应（carrier transport）：对 X⁻ 中之组织 R，τ\_Γ(R) 为其在 X⁺ 中之对应组织；若 Γ 判定无对应者，则 τ\_Γ(R) 不存在。τ\_Γ 为〔辅〕对象，只承担同一性记账，不是新本体关系，也不预设保结构性。

### 3.2　边界对象

定义 3.3〔辅〕（真值跨越）　Cross\_Γ(X⁻,X⁺) ⇔ Law\_Γ(X⁻) ≠ Law\_Γ(X⁺)。

定义 3.4〔辅〕（相邻）　Adjacent\_Γ(X⁻,X⁺) ⇔ 在 Γ 所申报之比较分辨率下，X⁻ 与 X⁺ 不可再分——即 Γ 之分辨率不允许在二者之间插入第三个可分比较态。此为\*\*分辨率相对\*\*概念：连续可变量上不要求存在"无中间元素"的覆盖关系，只要求在申报精度下不可再细分。

定义 3.5〔辅〕（边界对）　Boundary\_Γ(X⁻,X⁺) ⇔ Adjacent\_Γ(X⁻,X⁺) ∧ Cross\_Γ(X⁻,X⁺)。

　出界　Boundary⁻\_Γ(X⁻,X⁺) ⇔ Boundary\_Γ ∧ Law(X⁻)=1 ∧ Law(X⁺)=0。  
　入界　Boundary⁺\_Γ(X⁻,X⁺) ⇔ Boundary\_Γ ∧ Law(X⁻)=0 ∧ Law(X⁺)=1。

Cross 与 Boundary 之分：前者只说真值不同，后者另要求已定位到分辨率下不可再分。凡称"已定位边界"者须为后者。

### 3.3　结构见证集

定义 3.6〔S 派生〕（结构见证集）　对比较态 X：

　　𝒲\_S(X) = { R \| Established\_X(R) ∧ Govern\_X(L;R,I) }，  
　　Govern\_X(L;R,I) ⇔ DynamicRole\_X(L;R,I) ∧ ΩSupport\_X(L;R,I)（《律一般式》）。

𝒲\_S 由《律一般式》既有结构分量构成，非新增对象。

### 3.4　失效谱

定义 3.7〔辅〕（见证失效谱）　对 R ∈ 𝒲\_S(X⁻) 且 τ\_Γ(R) 存在：

　　Fail\_S(R) = { A ∈ {E, D, Ω} \| A 在 τ\_Γ(R) 于 X⁺ 上取 0 }，

其中 E = Established、D = DynamicRole、Ω = ΩSupport。若 τ\_Γ(R) 不存在，记 Fail\_S(R) = ⟂τ（对应缺失），单列不入 {E,D,Ω}。

失效谱只记录\*\*哪些资格被清空\*\*，不记录其原因；原因归《律动力》。本篇亦不把 Established 再拆为 CurrentCarrier / CarrierRealizes / CarrierNonInstant 之失——那属上游结构诊断，非 Law 边界之必要职责。

定义 3.8〔辅〕（极小失效覆盖）　设 𝒲\_S(X⁻) ≠ ∅ 而 𝒲\_S(X⁺) = ∅。先分旧见证为两类：

　　𝒲^τ = { R ∈ 𝒲\_S(X⁻) \| τ\_Γ(R) 不存在 }　（承载对应消失）  
　　𝒲^q = 𝒲\_S(X⁻) ∖ 𝒲^τ　　　　　　　　　（对应存在而资格失效）

MinFailCover 只处理资格失效型：称 C ⊆ {E,D,Ω} 为\*\*失效覆盖\*\*，当且仅当对每个 R ∈ 𝒲^q：Fail\_S(R) ∩ C ≠ ∅。MinFailCover\_Γ(X⁻,X⁺) 为诸失效覆盖中之极小者全体；𝒲^q = ∅ 时该式无内容（不定义），此时退出全由承载对应消失承担。

承载对应消失不参与 E、D、Ω 之极小覆盖，亦不得改写为 Established = 0：「无可追踪之同一对应物」与「对应物存在而不 Established」不是同一命题，τ\_Γ 为〔辅〕记账对象（3.2），不是第四个本体资格。

### 3.5　边界前沿

定义 3.9〔辅〕（边界前沿）　设 Γ 之比较方向由序 ≺ 给出。

　　ℬ⁻\_Γ = { (X,Y) \| X ≺ Y ∧ Boundary⁻\_Γ(X,Y) }，  
　　ℬ⁺\_Γ = { (X,Y) \| X ≺ Y ∧ Boundary⁺\_Γ(X,Y) }，  
　　ℬ\_Γ = ℬ⁻\_Γ ∪ ℬ⁺\_Γ。

即前沿之元素一律为\*\*已定位边界对\*\*（含 Adjacent\_Γ，定义 3.5）。未定位之跨越对只属 Cross\_Γ，不入前沿。另记跨越对集合 𝒞\_Γ = { (X,Y) \| X ≺ Y ∧ Cross\_Γ(X,Y) }；ℬ\_Γ ⊆ 𝒞\_Γ，一般不等。

一般 Law 边界为 ℬ\_Γ 这一\*\*边界对之集合\*\*（前沿），非唯一边界点。本篇不做一般拓扑边界理论。

## 第四节　结构边界定理

### 4.1　正向：见证存在即律成立

定理 4.1（见证充分）　𝒲\_S(X) ≠ ∅ ⇒ Law\_Γ(X) = 1。

证明　由《律必然式》 之律必然定理：∃R\[Established ∧ Govern\] ⇒ Law，其主充分向 Status = Established（不携本篇及一般式之 C、H 前件）。𝒲\_S(X) ≠ ∅ 即该存在式成立。□

推论 4.1.1　Law\_Γ(X) = 0 ⇒ 𝒲\_S(X) = ∅。（4.1 之逆否，同强度。）

### 4.2　负向：见证灭绝方可判律不成立

定理 4.2（见证必要，Conditional）　在 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3 下：𝒲\_S(X) = ∅ ⇒ Law\_Γ(X) = 0。

证明　《律一般式》 必要向：在该五项条件下 Law ⇒ ∃R\[Established ∧ Govern\]。逆否即得。□

两向条件不对称：正向（4.1）无条件，负向（4.2）携一般式全部 Conditional 前件。此不对称贯穿全篇，是第五节端点非对称之结构层来源。

### 4.3　单见证失效不足

定理 4.3（承载边界 ⇏ 律边界）　设 R ∈ 𝒲\_S(X⁻)，而 τ\_Γ(R) 不存在或 τ\_Γ(R) ∉ 𝒲\_S(X⁺)。此只说明见证 R 退出。若 ∃R′ ∈ 𝒲\_S(X⁺)，则 Law(X⁺) = 1（定理 4.1），Cross\_Γ 不成立。

证明　4.1 之存在量词只要求某一见证；R 之退出不影响 R′ 之资格。□

　　故：承载边界 ⇏ 律边界。

此为本篇最常被误用之处：某个 R 的 Established、DynamicRole 或 ΩSupport 失败，不得据以直接签 Law 边界。

### 4.4　退出分解

定理 4.4（结构见证退出分解）　设 𝒲\_S(X⁻) ≠ ∅ 且 𝒲\_S(X⁺) = ∅（称结构见证坍缩）。该坍缩之充要分解为下列两项同时成立：

　(甲) 原见证全部退出　∀R ∈ 𝒲\_S(X⁻)：τ\_Γ(R) 不存在 ∨ τ\_Γ(R) ∉ 𝒲\_S(X⁺)；  
　(乙) 无替代见证　不存在 R′ ∈ 𝒲\_S(X⁺) 而 R′ 不在 τ\_Γ(𝒲\_S(X⁻)) 之像中——即右端无新合格见证补位。

证明　⇐：由 (甲) 原见证之像皆不在 𝒲\_S(X⁺)，由 (乙) 亦无像外之新见证，故 𝒲\_S(X⁺) = ∅。⇒：若 (甲) 不成立则某像仍在 𝒲\_S(X⁺) 内，若 (乙) 不成立则有像外见证，二者皆使 𝒲\_S(X⁺) ≠ ∅。□

　　(甲) ∧ (乙) 合称\*\*见证灭绝\*\*（witness extinction）。仅有 (甲) 不足——这正是定理 4.3 之另一面。

　　升级条件　结构见证坍缩本身只是集合论事实，不即 Boundary⁻。欲升为 Boundary⁻\_Γ(X⁻,X⁺)，尚须两事：其一，Law(X⁺) = 0——由 𝒲\_S(X⁺) = ∅ 经定理 4.2 取得，携 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3（左端 Law(X⁻) = 1 由定理 4.1 无条件取得）；其二，Adjacent\_Γ(X⁻,X⁺)——由 Γ 之分辨率给出。二者俱备方得 Boundary⁻。本定理自身不携任何上游条件（8.4）。

### 4.5　边界类型

定义 4.5〔辅〕（结构边界类型）　设见证灭绝发生。先按 3.8 之两类分：

　𝒲^q = ∅ 且 𝒲^τ ≠ ∅　　correspondence-loss——全部旧见证之承载对应在 Γ 下消失，无资格失效可分类；  
　𝒲^q ≠ ∅ 且 𝒲^τ = ∅　　qualification-loss——按下列极小覆盖分型；  
　二者皆非空　　　　　　correspondence-loss + qualification-loss mixed——须同时报告两侧。

于 𝒲^q ≠ ∅ 之情形，取 C ∈ MinFailCover\_Γ(X⁻,X⁺)：

　C = {E}　　Established-critical——最后一批见证皆在承载资格上被清空；  
　C = {D}　　DynamicRole-critical——皆在真实动力承担上被清空；  
　C = {Ω}　　ΩSupport-critical——皆在稳定复走支撑上被清空；  
　\|C\| ≥ 2　　mixed boundary——须多项合击方能覆盖全部旧见证；  
　\|MinFailCover\| ≥ 2　non-unique mechanism——同一次退出可由不同极小机制描述，边界机制不唯一。

类型只描述\*\*清空发生在哪些资格上\*\*，不描述其原因。

### 4.6　Bind 之地位

命题 4.6（Bind^M 不入结构边界类型）　S 层 Govern ⇔ DynamicRole ∧ ΩSupport，无 Bind 分量；Bind^M 为《律数理式》之〔辅〕形式耦合约束。故 Bind^M: 1 → 0 只可称\*\*形式耦合失效\*\*，不得列为一种 Law 本体边界机制。

　　形式耦合失效欲升为 Law 边界，须经：Bind^M 之失使 𝒮 = ∅（形式解层，第五节），且负端条件束 H⁻\_M 成立，方得 Law = 0。

## 第五节　形式边界转移

### 5.1　形式解集

沿用《律数理式》：

　　𝒮(F\_t,L,I) = { R ⊆ Existing\_t \| EstWitness^M = 1 ∧ Govern^M = 1 }。

本节研究 𝒮 ≠ ∅ 与 𝒮 = ∅ 之间的跨越，及其向 Law 层之转移。本节不新造 SolState 之类对象。

### 5.2　两端条件束

定义 5.1〔辅〕（正端条件束）

　　H⁺\_M = H\_ReadC ∧ H\_ReadR ∧ H\_ReadN ∧ H1 ∧ H\_ReadD ∧ H\_ReadΩ。

定义 5.2〔辅〕（负端条件束）

　　H⁻\_M = C0 ∧ C2 ∧ H2 ∧ H3 ∧ H\_RepC ∧ H\_RepN ∧ H\_RepD ∧ H\_RepΩ ∧ H\_RepBind。

定理 5.1（端点转移）

　(i) 在 H⁺\_M 下：𝒮(X) ≠ ∅ ⇒ Law\_Γ(X) = 1。  
　(ii) 在 H⁻\_M 下：𝒮(X) = ∅ ⇒ Law\_Γ(X) = 0。

证明　(i) 取 R ∈ 𝒮(X)，即 EstWitness^M ∧ Govern^M。经数理式正向回读 (7.4)\[H\_ReadC ∧ H\_ReadR ∧ H\_ReadN ∧ H1\]、(7.5)\[H\_ReadD\]、(7.7)\[H\_ReadΩ\] 得 Established ∧ Govern，即 𝒲\_S(X) ≠ ∅；再由定理 4.1 得 Law = 1。

　(ii) 逆否论证，走\*\*前-H1 见证回放\*\*路径：不调用一般式之总必要定理（该定理携 H1），而抽取其证明中调用 H1 之前已经取得之中间结论。该抽取显式立为：

　　引理 5.1.1（PreH1Witness，上游抽取，非新增假设）

　　　C0 ∧ C2 ∧ H3 ∧ Law\_F,t(L,I)  
　　　⇒ ∃R \[ CurrentCarrier\_F,t(R) ∧ CarrierRealizes(L;R,I) ∧ CarrierNonInstant(L;R,I)  
　　　　　　 ∧ DynamicRole(L;R,I) ∧ StableReplay(L;R,I) \]。

　　依据　《律一般式》 必要向证明之三次追问：第一次追问在 C0 下（律不得悬于场外、即时或描述层）取得同一 R 上之 CurrentCarrier ∧ CarrierRealizes ∧ CarrierNonInstant——该处尚未调用 H1，H1 之职责是把此三项落为 Established，本引理不需该落实；第二次追问（废弃旧沟退化）于同一 R 取得 DynamicRole，其冗余、协同与多重承载情形之客观真值依 H3；第三次追问（一次强冲退化，携 C6b 之"复"承继）取得 StableReplay，其中 Ω 作为稳定复走能力之场量身份由 C2 承接。三次追问皆在 H1 之前完成，故本引理不携 H1。

　　地位　本引理不是新假设，亦不是新理论内容，而是《律一般式》 必要向证明在调用 H1 之前已经完成之中间结论的显式抽取；其真值随该证明，不另立 H。若上游改写该证明使三次追问之次序或所用条件改变，本引理须同步复核（击穿 K-B10）。

　　由引理 5.1.1 与

　　　H2：StableReplay ⇒ ΩSupport

得 ΩSupport(L;R,I)，故 Govern(L;R,I)。以上共用 C0 ∧ C2 ∧ H2 ∧ H3，不含 H1。

　转 M 层：由 H\_RepC 得 CurrentCarrier^M；由 H\_RepN 得 CarrierNonInstant^M，而数理式 3.36 以 CarrierRealizes^M = 1 为定义前件，故 CarrierRealizes^M 随之取得，不另需 H\_RepR；三者合为 EstWitness^M。由 H\_RepD 得 DynamicRole^M，由 H\_RepΩ 得 ΩSupport^M，再由 H\_RepBind（Govern ∧ DynamicRole^M ∧ ΩSupport^M ⇒ Bind^M）得 Bind^M；三者合为 Govern^M。

　故 R ∈ 𝒮(X)，𝒮(X) ≠ ∅。所用条件恰为 H⁻\_M，逆否即 (ii)。□

　　H1 ∉ H⁻\_M　由引理 5.1.1：H1 之职责是把 CurrentCarrier ∧ CarrierRealizes ∧ CarrierNonInstant 落为 Established，而 (ii) 之 M 侧只需该三项各自之 Rep 像（H\_RepC、H\_RepN 及 3.36 之定义前件），不需要 Established 这一名目。故证明在 H1 之前截取见证，H1 不入束——此为证明路径之结果，非省略：若改走总必要定理，则必须携 H1（定理 4.2 即如此）。本条之承重点即引理 5.1.1，其可击穿性见 K-B10。  
　　H\_RepR ∉ H⁻\_M　CarrierRealizes^M 由 H\_RepN 之结论经数理式 3.36 之定义前件取得（3.36 明文以 CarrierRealizes^M = 1 为前件），故不需独立之 H\_RepR。

### 5.3　端点非对称定理

定理 5.2（边界端点非对称）　认证一次具体形式退出边界，不必先在整个比较域上建立 Law ⇔ 𝒮 ≠ ∅。若

　　𝒮(X⁻) ≠ ∅ ∧ 𝒮(X⁺) = ∅，

则只需 H⁺\_M 在 X⁻ 处成立、H⁻\_M 在 X⁺ 处成立，即得

　　Law\_Γ(X⁻) = 1 ∧ Law\_Γ(X⁺) = 0，

从而 Cross\_Γ(X⁻,X⁺)；若另有 Adjacent\_Γ(X⁻,X⁺)，则得 Boundary⁻\_Γ(X⁻,X⁺)。

证明　两端各自应用定理 5.1 之一支：左端用 (i)，右端用 (ii)。两支所需条件束不同，且各只在其自身比较态上被要求。□

　　对称地，入界只需 H⁻\_M 在 X⁻ 处、H⁺\_M 在 X⁺ 处成立。

　　此定理之意义：边界认证是\*\*逐端点的局部义务\*\*，不是全域等价的整体义务。全域等价 Law ⇔ 𝒮 ≠ ∅ 须 H⁺\_M ∧ H⁻\_M 于全域成立，代价远高；而一次边界只用两个端点各一束。

### 5.4　⟂ 纪律

　　⟂ ≠ 0。

判定或求解中出现之 ⟂（《律数理式》M1–M6 不满足、《律判定式》OperableDo 不足或协议不可判）不构成 Law 假：

　(i) 判定输出 ⟂ 不得记为该比较态之 Law = 0；  
　(ii) 搜索中若存在未决候选，不得以"未找到 PASS"报为已证 𝒮 = ∅；  
　(iii) 一旦经完整形式证明真正取得 𝒮 = ∅，且 H⁻\_M 成立，则仍可由定理 5.1(ii) 推出 Law = 0。

本篇只作此三条声明。判定能力之刻画、搜索状态之形式化归《律判定式》，本篇不新造。

## 第六节　适用域边界

本节固定 F、t、L 与其余 Γ 量，只令适用域 I 变化。依《律一般式》 与《律数理式》：DynamicRole 为存在极性，CarrierRealizes、CarrierNonInstant、StableReplay、ΩSupport 为覆盖极性，覆盖域为适用覆盖守卫域 I\_cov(L,I)（数理式 3.15′）；I 增大时 I\_cov 是否随之增大，取决于 Rel(L) 对新条件是否预声明职责。

记 𝔍\_Law = { I \| Law\_Γ(F,t,L,I) = 1 }。

### 6.1　双向非单调

定理 6.1（不保证上闭）　存在 I ⊊ J 使 Law(I) = 1 而 Law(J) = 0。

构造　取 J = I ∪ {i\_new}，其中 Rel(L) 对 i\_new 预声明职责（故 i\_new ∈ I\_cov(L,J)），而 R 在 i\_new 处无可接达之承担 Rel(L) 的稳定结构。则 ΩSupport 之覆盖义务在 i\_new 处失败（一般式第五种"不够"），Govern(J) = 0；若无替代见证，𝒲\_S(J) = ∅，在 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3 下 Law(J) = 0。而 I 处覆盖义务不含 i\_new，𝒲\_S(I) ∋ R，Law(I) = 1。□

　　机制：扩域给覆盖极性诸谓词增加新义务。

定理 6.2（不保证下闭）　存在 I ⊊ J 使 Law(I) = 0 而 Law(J) = 1。

构造　设 R 在 J 之全部覆盖义务上皆成立，而其唯一的 DynamicRole 存在见证落在 i\_\* ∈ J ∖ I。取 I = J ∖ {i\_\*}：I 上覆盖义务只减不增，仍成立；但 DynamicRole 之存在量词在 I\_cov(L,I) 上无见证可取，DynamicRole(I) = 0，Govern(I) = 0；若无替代见证则 Law(I) = 0（同上条件）。而 Law(J) = 1 由定理 4.1。□

　　机制：缩域可能删掉唯一的存在见证。

　　两条机制方向相反：覆盖极性使\*\*扩域\*\*危险，存在极性使\*\*缩域\*\*危险。故 𝔍\_Law 一般既不上闭亦不下闭。

### 6.2　适用域可有洞

定理 6.3（域洞）　存在 I₁ ⊊ I₂ ⊊ I₃ 使 Law(I₁) = 1、Law(I₂) = 0、Law(I₃) = 1。

构造（单步链）　取 I₁ = {a}、I₂ = {a,b}、I₃ = {a,b,c}，三者皆在 Γ 所申报之合法域族 𝔄\_I 中；Rel(L) 对 a、b、c 皆预声明职责（故 I\_cov(L,I) = I 于三者）。取两个组织：

　R\_A　覆盖资格只及于 a，于 b 处覆盖失败；其 DynamicRole 存在见证落于 a。故 R\_A ∈ 𝒲\_S(I₁)，而 R\_A ∉ 𝒲\_S(I₂)、∉ 𝒲\_S(I₃)。  
　R\_B　覆盖资格及于 a、b、c 全体；其唯一 DynamicRole 存在见证落于 c。故 R\_B ∈ 𝒲\_S(I₃)；于 I₂ 覆盖虽足而 I\_cov(L,I₂) = {a,b} 中无存在见证，DynamicRole(I₂) = 0，R\_B ∉ 𝒲\_S(I₂)。

别无第三见证。则 Law(I₁) = 1、Law(I₃) = 1（定理 4.1）；𝒲\_S(I₂) = ∅，在 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3 下 Law(I₂) = 0（定理 4.2）。□

　　链之每步为单条件增添（I₁ ≺ I₂ ≺ I₃），故在 6.5 之定位约定下二步皆为已定位边界对，不需另证"最小步细分存在"。

　　故 𝔍\_Law 一般不具区间性。

### 6.3　单见证域凸性

定理 6.4（单 R 域凸性）　固定 R，记 𝔍\_R = { I \| R ∈ 𝒲\_S(I) }。若 I₁ ⊆ I₂ ⊆ I₃ 且 I₁, I₃ ∈ 𝔍\_R，则 I₂ ∈ 𝔍\_R。

证明　本节固定 F、t 与 R；𝒲\_S 之三分量分别为 Established\_F,t(R)、DynamicRole(L;R,I)、ΩSupport(L;R,I)。

　Established\_F,t(R)　该谓词不带 I（《律一般式》：CurrentCarrier 无 I 极性，Established 为 F、t、R 之函数）。F、t、R 已固定，故其值在 I₁、I₂、I₃ 间不变；由 I₁ ∈ 𝔍\_R 知其为 1。  
　DynamicRole　存在极性。由 I₁ ∈ 𝔍\_R，存在见证落于 I\_cov(L,I₁) 中某条件；I₁ ⊆ I₂ 给 I\_cov(L,I₁) ⊆ I\_cov(L,I₂)，该见证仍在域内，故 DynamicRole(I₂) = 1。\*\*存在见证自小域向大域保留。\*\*  
　ΩSupport　覆盖极性。由 I₃ ∈ 𝔍\_R，R 在 I\_cov(L,I₃) 全体上满足覆盖义务；I₂ ⊆ I₃ 给 I\_cov(L,I₂) ⊆ I\_cov(L,I₃)，故 I₂ 之覆盖义务为其子集，仍满足。\*\*覆盖资格自大域向小域保留。\*\*

三者合取即 R ∈ 𝒲\_S(I₂)。□

　注一　CarrierRealizes、CarrierNonInstant 之覆盖义务虽随 I 变，但二者是 Established 之结构前件（经 H1），不是 𝒲\_S 之独立分量；本证明只对 𝒲\_S 之三分量论证，不重复处理其前件。

　　注二　证明只用 I ↦ I\_cov 之单调性（I ⊆ J ⇒ I\_cov(L,I) ⊆ I\_cov(L,J)），此由 I\_cov 之定义 {i ∈ I \| Trig(i) ≠ ∅} 直接得到，与实现成败无关（数理式 3.15′(a)）。

推论 6.4.1（域洞必含见证切换）　定理 6.3 之域洞不可能由同一个 R 造成：若 R 同时是 I₁ 与 I₃ 之见证，则由 6.4 它亦是 I₂ 之见证，与 Law(I₂) = 0 矛盾。故任何 1 → 0 → 1 之域洞，其两端见证必不相同——\*\*Law 域洞必含见证切换\*\*。

　　本篇只记录切换之发生，不解释其原因（归《律动力》）。

### 6.4　多个互不可比极大域

定理 6.5（无最大适用域）　设 U 为预声明顶域（Γ 所申报之比较范围上界）。可在 U 内构造 I\_A, I\_B ∈ 𝔍\_Law，二者互不可比（I\_A ⊄ I\_B ∧ I\_B ⊄ I\_A），且各自在 𝔍\_Law 中\*\*极大\*\*（maximal），而 Law(U) = 0。故 𝔍\_Law 一般无\*\*最大元\*\*（maximum）。

构造（coatom）　取 U = {a,b,c}，Γ 所申报之合法域族 𝔄\_I ⊆ 𝒫(U) 含 U 及其两个余原子

　　I\_A = U ∖ {c} = {a,b}，　I\_B = U ∖ {b} = {a,c}。

设 Rel(L) 对 a、b、c 皆预声明职责（故 I\_cov(L,I) = I 于三者）。取见证 R\_A 使其在 {a,b} 上覆盖与存在俱足而于 c 处覆盖失败；R\_B 对称，在 {a,c} 上俱足而于 b 处覆盖失败；U 上别无第三见证。则

　　Law(I\_A) = 1，Law(I\_B) = 1（定理 4.1）；　Law(U) = 0（𝒲\_S(U) = ∅，在 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3 下由定理 4.2）。

极大性由格结构直接给出：I\_A 与 I\_B 在 𝔄\_I 中之唯一严格超域皆为 U，而 Law(U) = 0，故二者各无合格真扩张，皆为 maximal。二者互不可比（c ∈ I\_B ∖ I\_A，b ∈ I\_A ∖ I\_B）。若有 maximum，则须包含 I\_A ∪ I\_B = U，而 U ∉ 𝔍\_Law，故 maximum 不存在。□

　　此构造不依赖"任何真扩张皆触及失败条件"这类需另证之断言：余原子之上只有顶域一个候选，逐一验之即可。

　　maximal 与 maximum 之别　maximal 指无真扩张仍在 𝔍\_Law 内；maximum 指包含 𝔍\_Law 中一切元素。本定理断言前者可多个且互不可比，故后者一般不存在。二者不得混用。

　　顶域限定　本构造在预声明顶域 U 内进行；离开 U 无从谈论极大性，故 U 之申报为构造之必要部分。

### 6.5　边界前沿（适用域）

依定义 3.9，取 ≺ 为集合包含之相邻关系（在 Γ 分辨率下）：

　　ℬ⁻\_I = { (I,J) \| I ≺ J, Law(I)=1, Law(J)=0 }，  
　　ℬ⁺\_I = { (I,J) \| I ≺ J, Law(I)=0, Law(J)=1 }。

由 6.1–6.3，二者一般皆非空，且不能由单一阈值刻画。

　　定位约定　以下取 Γ 之适用域分辨率为\*\*单条件增删\*\*：I ≺ J 当且仅当 J = I ∪ {i} 且 i 为一个预声明原子条件（或反向删去一个），且二者皆在合法域族 𝔄\_I 中。在此分辨率下 Adjacent\_Γ(I,J) 成立。6.1、6.2、6.3、6.5 之构造皆已取单步（各只增删一个原子条件，且所涉诸域皆申报在 𝔄\_I 内），故其跨越对同时为已定位边界对，不需另证细分之存在。若 Γ 取更粗之分辨率，或 𝔄\_I 不含所需中间域，则相应构造只得 Cross\_Γ，须另行细分方能定位。

定理 6.6（前沿非单点）　在上述单条件增删分辨率下，适用域之一般 Law 边界为边界对之集合 ℬ\_I = ℬ⁻\_I ∪ ℬ⁺\_I，非唯一边界点。

证明　由 6.1（取 J = I ∪ {i\_new}，单步）得 ℬ⁻\_I ≠ ∅；由 6.2（取 I = J ∖ {i\_\*}，单步）得 ℬ⁺\_I ≠ ∅；由 6.3 之单步链 I₁ ≺ I₂ ≺ I₃ 得同一包含链上有两个已定位边界对（I₁,I₂）∈ ℬ⁻\_I 与（I₂,I₃）∈ ℬ⁺\_I；由 6.5 得多个互不可比极大域各自贡献自己的出界对（I\_A ≺ U、I\_B ≺ U 皆为单条件增添）。故 ℬ\_I 一般为多元素集，且不由单一"边界点"给出。□

## 第七节　与《律稳定式》《律判定式》之接口

### 7.1　固定见证边界与律边界

《律稳定式》给出固定见证之边界参数 q\_fix^∂（该 R 失去固定解资格之临界）与解集边界参数（该篇记号，本篇不重做其求法）。记 q\_W^∂ 为见证灭绝之临界，即 𝒲\_S 变空之处。

本节只处理\*\*出界\*\*（1 → 0）之参数接口：q\_W^∂ 之定义为结构见证集灭绝之临界，即 𝒲\_S 由非空变空之处，故其对象天然只是出界候选，不得兼任入界。入界（0 → 1）由结构见证自空变为非空及定理 4.1 认证，其参数求法仍归《律稳定式》；本篇不为之另立记号。

定理 7.1（固定见证边界不晚于见证灭绝边界）　设：在同一预声明 Γ 单向比较路径上，按同一序参数化；被跟踪之见证 R 于起始端为结构见证（R ∈ 𝒲\_S 于路径起点），且沿路径保有 τ\_Γ 之可追踪对应；q\_fix^∂(R)（该 R 失去见证资格之临界）与 q\_W^∂（𝒲\_S 灭绝之临界）均存在且\*\*取得\*\*（非仅有下确界而边界不达）。则

　　q\_fix^∂(R) ≤ q\_W^∂。

证明　R 失格时 𝒲\_S 未必空（定理 4.3）；𝒲\_S 空则其中每个见证皆已失格，特别地该 R 已失格。故沿同一路径，R 之失格不迟于灭绝。□

　(i) 严格不等　若在 R 首次失格\*\*之后、见证灭绝之前\*\*存在一个严格后继比较态 X′（同一路径上，q\_fix^∂(R) ≺ X′ ≺ q\_W^∂）使 𝒲\_S(X′) ≠ ∅，则 q\_fix^∂(R) \< q\_W^∂。此前件强于"失效后仍存在替代见证"：连续情形下若接替只发生于单点而其严格后继处 𝒲\_S 复空，则不得签严格不等。  
　(ii) 相等　若该失效恰逢最后见证灭绝且无替代（定理 4.4 之甲乙俱成立于同一比较态），则 q\_fix^∂(R) = q\_W^∂。  
　(iii) 定义域资格　若 𝒲\_S 沿路径永不灭绝（q\_W^∂ 不存在）、被跟踪之 R 在 Γ 下失去可追踪对应（τ\_Γ(R) 不存在）、边界只有下确界而未取得、或两临界来自不同路径或不同分辨率，则二者无可比较意义，本定理不适用，不得强行比较。

　　升级条件　q\_W^∂ 认证为出界方向之 Law 边界参数 q\_Law^∂，须另经：Law(X⁺) = 0 由定理 4.2（携 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3）或定理 5.1(ii)（携 H⁻\_M）取得；左端 Law = 1 由定理 4.1 无条件取得；另需 Adjacent\_Γ 方为已定位边界（定理 4.4 之升级条件）。

　　本篇只证上列关系，并告诉《律稳定式》：其所算得之固定边界在何种条件下可解释为 Law 边界。参数扫描、阈值求解、稳定区宽度、首失败位置、恢复后置检查、数值算法一律归该篇，本篇不做。

### 7.2　与《律判定式》

本篇只规定 ⟂ 纪律（5.4）。候选枚举、Trig 测定、OperableDo 充分性、Reach 实测、缺数据处理、PASS/FAIL/⟂ 执行程序、𝒮 = ∅ 之算法认证，皆归该篇。

　K-B6　在 H⁺\_M 成立而 𝒮(X) ≠ ∅ 之处得 Law(X) = 0，或在 H⁻\_M 成立而 𝒮(X) = ∅ 之处得 Law(X) = 1——击穿定理 5.1。  
　K-B7　证明 H⁻\_M 尚缺一项（如确须 H\_RepR 或 H1）——击穿 5.2 之条件束划分。  
　K-B8　以某单一 R 之资格失效直接签 Law 边界，或以 Bind^M 之失直接签结构边界类型——非击穿本篇，而是违反本篇纪律（4.3、4.6）；若因此得出与本篇相反之结论，该结论无效。

　K-B9　把「见证灭绝」当作 Law 边界之无条件刻画——见证灭绝 ⇒ Law = 0 携 C0 ∧ C2 ∧ H1 ∧ H2 ∧ H3（定理 4.2），且只覆盖出界方向；入界（0 → 1）不由灭绝刻画。凡以无条件口吻断言此事者，其断言无效。  
　K-B10　证明引理 5.1.1（PreH1Witness）不成立——例如指出《律一般式》 必要向证明在取得 DynamicRole 或 StableReplay 之前已经调用 H1，或其三次追问所用条件多于 C0 ∧ C2 ∧ H3。此击穿 H1 ∉ H⁻\_M，并使 5.1(ii)、5.2 之负端条件束须补 H1。

不构成击穿：上游 H 未闭；本篇未解释边界成因；本篇未给出边界之数值求法；本篇未处理 ⟂ 之判定能力刻画。
