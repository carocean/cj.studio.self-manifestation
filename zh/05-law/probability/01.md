# 概率一般式

本篇试论一个总命题：

通常所谓的概率，一旦在沉积场中成立，就不能只是某一结果被写上一个数值，不能只是观察者对若干可能结果的衡量，也不能只是长期重复以后读出来的一个频率；它必须已经取得由场内已成结构承担相对续行生成的必要资格。

通常把概率定义为：衡量某个随机事件发生可能性大小的度量。

这一定义把三样东西预先放在了前面：一个进行衡量的谁；一个预先摆好的"所有可能结果"的空间；一个挂在各结果上的数值。

《自显论》不从这里出发。

物理执行层上，每一次实际续行都落定为一次实际发生。所谓"可能的若干结果"，可以作为识出、描述或形式表达中的对象；但本篇不把一个预先摆好的可能性空间当作 Probability 的本体起点。

《自显论》的母本已经把续行、迹应、沉积、积深与后来续行联系起来；后续律体系又把能够形成、治理后来并具有合法复走支撑的关系组织闭合为 Law。由此，本篇真正需要追问的是：一份被承认为 Probability 的系统侧续行率组织，其正式续行维最终凭什么取得场内承担资格。

因此，本篇不从"所有可能结果 + 数值测度"倒推 Probability，也不预先规定 Probability 的完整发生史。来源、首次形成与历史归因，留给《概率源式》。本篇只问当前资格的必要构成。

本组式研发起点立有一语：

"概率是律。"

这一句给出的是方向：概率不在沉积场之外，而须落到场内已成律体系的承担上。本篇不把这句话直接形式化为 Probability = Law，而是在连续追问中检验：一份概率既已成立，它和律究竟处在什么关系中，它除了律以外最少还需要什么。

所以本篇要问的是：

如果概率不是对可能性的度量，而是在沉积场中生成的续行率组织，那么一份概率一旦在场中成立，最少必须具有什么？少了什么，它就不能作为已经成立的概率？

我们要在本篇，在不断追问下找到证明应当走向何处，并推导概率的一般式。

我们的目标是：

得到概率在沉积场中成立的当前推导最小必要结构，并给出最小性证明与击穿路径。

本篇只证明必要方向：

Probability ⇒ N\_P

N\_P 的内容不在此预设，由以下追问逐轮逼出。这一必要向所携的上游条件，见下文条件记账。

反向：

N\_P ⇒ Probability

不由本篇证明，也不得由本篇的任何定义、命名或删项测试暗中取得。充分方向属于《概率必然式》。

本篇的条件记账：

H\_new = ∅  
H\_inherit = { H2, H3^red, SC\_Hold }

本篇不新立任何未证形式前件。但本篇必要向的实际证明路径，经过上游《律一般式》尚未关闭的两座桥：H2（Ω 完备表达桥）普遍承重；H3（DynamicRole 冗余因果职责存在桥）只在冗余、协同、备用或多重承载的情形中承重，记为 H3^red。二者在首次承重处（第四节）申明，并在篇末统一收束。另，本篇第四节所调用之《律必然式》充分向，于该篇 v1.4 为 Conditional on SC\_Hold（持势承接条件，待证），亦随"每一维取得正式 Law-bearing"一步承继，记入 H\_inherit；SC\_Hold 是上游申报之语义承接条件，不是本篇新立之 H。其余上游结论均为已封版承继项或母本语义承继。

H3^red 作为逻辑条件定义为：

RedRole\_P :⇔ 该实例涉及冗余、协同、备用或多重承载的 DynamicRole 归属

H3^red :⇔ ( RedRole\_P ⇒ H3 )

非此情形中 RedRole\_P = 0，H3^red 自动成立，不要求 H3；此情形中 H3^red 退化为要求 H3。

所以本篇的必要向是 Conditional：

H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ Probability ⇒ N\_P \]

条件只沿实际证明路径传播：H1 与 C2 不在本篇证明路径上，不进入本篇。

一、工作域

设：

F 为沉积场；

t 为当前时刻；

𝒫 为当前候选概率组织，即被声称在 F 中、于时刻 t 成立的一份概率所指的续行率组织；

C 为 𝒫 所涉的续行位（Continuation-Position），即 𝒫 所回答的那一个续行问题：在这一处当前续行之后，后继如何续行；

𝔯\_P 为 𝒫 所声称成立的率域索引，即这份概率被声称在其上成立的生成/再入域。

记：

Probability\_F,t(𝒫; C, 𝔯\_P)

表示候选概率组织 𝒫 在时刻 t、沉积场 F 中，相对于续行位 C 与率域 𝔯\_P 成立。

记 V\_P 为候选组织 𝒫 所申报的续行维（continuation dimensions）集合。一个续行维，是某一续行位处与其他后继方向可区分的一个后继续行方向。

工作域中的 C，是该候选 Probability 所申报的共同续行位；但在推导开始时，不预设 V\_P 中每一维事实上都已经属于这个 C。这一点正是后文必须由失败世界逼出的资格要求。

因此，在共同续行位的要求被正式逼出以前，各候选维可以暂以自己的续行位 C\_i 表示；只有后文证明：

∀i：C\_i = C

以后，才可说诸维真正同属于这份 Probability 所申报的共同续行位。

这里只登记 V\_P 这一索引，不预设：

V\_P 有几个元素；

V\_P 中的维由什么承担；

V\_P 中的维是否已经各有数值率；

V\_P 中诸维是否同属 C；

V\_P 是否覆盖 C 处全部实际后继。

"一个可区分的结果凭什么算作续行维"，正是本篇要追问的内容之一，工作域不预先回答。

C 与 𝔯\_P 在这里只作候选申报索引：它们说明这份候选概率被申报为"哪一处续行"在"哪一个域中"的概率。它们各自须满足什么纪律、诸维是否真正落在其上，在追问中确定，工作域不预先规定。

若需指称 V\_P 诸维之间的相对生成关系，记为：

Rel\_ρ(𝒫; C, 𝔯\_P)

若在反例世界中需要描述诸维的率，记为：

ρ = (ρ(v\_1), ρ(v\_2), …)

这些数值只用于描述构造出来的世界，不表示本篇预设 Probability 必须有可读数值。

记号注

母本以 𝒫(t) 记续行空间。本篇的 𝒫 不带时间参数，只作为 Probability 及其各分量谓词的首变元出现，专指候选概率组织，与母本续行空间不同。本篇正文不再使用母本 𝒫(t) 这一记号；需要指称时写作"母本续行空间"。

三值纪律

本篇总定理只处理 Probability\_F,t(𝒫; C, 𝔯\_P) = 1 时的必要结构。一份具体候选在实例上取 1、0 或 ⊥ 的判定，属于《概率判定式》。本篇不把"读不出"写成"不成立"，也不把"本篇未判定"写成"为 0"。

二、母本承继与旧量的位置

### 2.1 母本已有的续行率结构

母本《自显论》在沉积动力的一般表达中（式篇第二十《沉积动力一般式》，现行 v1.2）已有：

续行空间；

有效续行路径集合 𝒬(t)；

路径续行概率 Pr(q,t)，q ∈ 𝒬(t)；

路径积深 Depth(q,t)；

续行势 κ；

场有限续行容积 Λ(t)（份额上限，与场篇第一之场容积 Cap(F) 不立对应），并有 ∑Pr(q,t) ≤ Λ(t)；

以及历史留存、积深、续行偏置、熟径等结构。

这些是本组式研发概率的重要母本：它们已经表明，在母本中，续行的"率"不是外部挂上去的数，而与积深、偏置、熟径等沉积结构相连。

### 2.2 旧 Pr(q,t) 不直接升格

旧 Pr(q,t) 是早期的路径续行率表达。它早于本组式所承继的 Law、DynamicRole、ΩSupport 等成熟资格体系，因此本篇不写：

Probability(q) ⇔ Pr(q,t) \> 0

也不写：

Probability = Pr

具体地：

第一，母本旧式：

∑ Pr(q,t) ≤ Λ(t)

表达的是场有限续行容积下的有限竞争约束。它不是现代概率论的归一公理：

∑\_i p\_i = 1

本篇不把前者偷换为后者，更不把后者作为 Probability 的资格条件。

第二，母本旧稿以：

∃q\_i, q\_j：Pr(q\_i,t) ≠ Pr(q\_j,t)

定义续行偏置。式篇第二十 v1.2 已改：续行偏置 B 为对沉积差的依赖——在申报的比较任务中，合法抹平沉积差（干预 I\_m）后，至少两路之间的相对行进读数改变，即 B\_m(T) 成立；干预规则与读数范围依式篇第二十，不读绝对时刻或绝对流量；干预不可实现时记"未定义"；不强求以概率表达，也不是一切偏流。故"Pr 有差"既不是偏置的定义，更不是概率成立的条件。本篇不把任一形式的偏置提升为 Probability 必须非均匀。

第三，母本旧稿曾有：

∂Pr(q,t)/∂t ∝ ∂Depth(q,t)/∂t

式篇第二十 v1.2 已删去此式，总动力式改为离散 Depth(q,t+1) = Depth(q,t) + R(q,t) − Ξ₀(q,t)（R ↔ Dτ，Ξ₀ ↔ Eλ），沉积度对后流之作用改由场篇第一方向关系给出（方程3a 愈深阈愈小、定律5、定理17，带其比较条件）。本篇只承继这一方向含义：沉积度变化能够改变后来续行的率结构；不承继原比例式，也不读作 Pr 由 Depth 唯一决定。

第四，母本在论律的一般表达时已指出：律不等于概率；概率可以描述多次运行后的外显分布，但不能作为生成机制；一次落定由 Θ 的最低化给出。

这一论述中的"概率"，指的是多次运行以后读出的外显分布，即本篇所称经验频率与识出之率的层面。它与本篇篇首所持立场一致：每一次物理执行仍然归一；读出的分布不是当下落定的机制。本篇研究的 Probability，不是那一读出层，而是读出层之前、在沉积场中承担相对续行生成的组织。本篇因此不与该论述冲突，也不把旧读出量反写为本体。

旧 Pr(q,t) 与本组式正式率符号之间的桥接，属于《概率数理式》。

### 2.3 Law 资格承继

本篇在一处需要使用 Law 的充分方向。只调用已封版结论：

《律必然式》充分向：

∃R \[

&nbsp;&nbsp;∧ Govern\_F,t(L; R, I)  
\]  
⇒ Law\_F,t(L, I)

其中：

Govern\_F,t(L; R, I)  
:⇔ DynamicRole\_F,t(L; R, I)  
&nbsp;&nbsp;&nbsp;∧ ΩSupport\_F,t(L; R, I)

承继纪律：

第一，本篇不重新定义 Law，也不重证上式。

第二，该充分向主定理于《律必然式》v1.4 为 Conditional on SC\_Hold（持势承接条件，待证）；其母本语料域限定是证明域限定，不另降级。本篇调用该充分向，随之携 SC\_Hold。

第三，该充分向不使用《律一般式》必要向的 C0、C2、H1—H3。本篇只调用充分方向，因此不把《律一般式》的 Conditional 必要向前件传入本篇。本篇也不调用二者合成所得的条件化双向等价式。

第四，Established 与 Govern 必须落在同一个 R 上。不得从一个 R 取 Established、从另一个 R 取 Govern 拼出 Law。

第五，ΩSupport 按其现行覆盖语义读取。

三、只有一条稳定续行，已经是概率了吗？

先取最强的单路情形。

设 F 中已有一条稳定续行：

L\_1 : C → v\_1

它可以已经沉积，已经成律，能够稳定复走；在 C 处，后继始终是 v\_1。

数学上甚至可以写：

p(v\_1) = 1

现在问：

这是一份概率吗？

如果说它是，那么这个"率"是在什么之间成立的？

数学上，单点分布完全可以给 v\_1 赋值 1。本篇不否认这一写法可以成立；本篇要问的是：这个 1 是否带来了一个独立于 L\_1 的对象。

在上面的世界里，C 处只有 v\_1。没有第二个可区分的续行方向，就没有任何诸维之间的相对生成关系可言。p(v\_1) = 1 这一写法，并不比"C 处稳定续行到 v\_1"多说出任何东西；它说出的内容，已经由 L\_1 作为一条律完全承担了。

所以，单一续行可以被记率为 1，但不足以形成本篇所研究的独立 Probability organization；在资格上，它仍由普通 Law 完全承担。

若仍称之为 Probability，那么这份 Probability 与 L\_1 在内容上没有任何差别：它只是普通 Law 被换了一个名字。本篇所问的 Probability 如果有独立于普通 Law 的对象，这个对象就不能在单一续行维上成立。

所以，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

\|V\_P\| ≥ 2

并且 V\_P 中诸维彼此可区分：

∀v\_i, v\_j ∈ V\_P, i ≠ j：  
&nbsp;&nbsp;Dist(v\_i, v\_j)

这里必须注意本轮取得的边界。

本轮只证明了"多维"。它没有证明这些维由什么承担，也没有证明"两个可区分的东西"就足以成为概率的两维。第二维可以是什么，此时仍然完全开放。

未闭合处因此是：

一个可区分的后继方向，凭什么算作续行维？

四、多出一个可区分的结果，就已经是概率之维了吗？

保持：

\|V\_P\| ≥ 2

保持 v\_1 由已成律 L\_1 承担。

现在令另一个所谓维 u 只是下列之一：

第一，一次偶然发生。C 处曾经有一次实际续行到了 u。这一情形还可以再分三层看：其一，发生以后没有留下任何承担结构；其二，发生留下了痕迹，痕迹甚至被长期保存，但这份留存并不进入后来 C 处续行的生成；其三，留存曾经真实参与过后来一次续行到 u，但此后再次合法到达 C 时，已无稳定支撑。

第二，一个可达分支。从 C 出发，u 在结构上是可以到达的，但场中从未形成承担 C → u 的任何关系组织。

第三，一个外部开关临时开放的结果。某个外部条件临时把 C 接向 u；开关一撤，这一续行就不存在。

第四，一个数学候选标签。分析者在样本空间中写下 u，并给它一个数。

这四种情形都能使"两个可区分的东西"成立。

现在问：

在这些世界里，u 是系统自身续行率的一维吗？

逐一看。

一次偶然发生：

发生而无留存。发生一次，只说明这一回实际续行与 u 相符。它没有留下能够承担后来的结构，下一次到达 C 时，没有任何场内之物为 u 承担任何份额。

留存而不管后来。痕迹在场中，但它只是被记录下来；后来到达 C 时，u 是否生成与这份留存无关。留存与 u 相关，却不参与 u 的生成。

影响过一次而不能复走。留存曾经真实参与过一次后来续行，但这只是某一回的承担；再次合法到达 C 时，已无能够支撑 C → u 的已成结构。

三层都不能使 u 成为系统自身的续行率之维：

Occurrence(u) = 1 ⇏ u 是续行维

可达分支：可达只说明 u 在结构上不被排除。场内并没有形成过承担 C → u 的组织，u 没有进入过后来续行。

Reachable(u) ⇏ u 是续行维

外部开关：C → u 的续行确实发生，但承担它的是场外临时条件；场内没有形成自己的承担结构，开关一撤，u 就不复存在。

数学标签：它存在于分析者的表示中，不存在于 F 的续行中。

在这四个世界里，u 都只是裸候选。说"C 处有 v\_1 与 u 两维，各占某种率"，u 的那一份没有任何场内之物承担；它是分析者或外部条件附加在系统上的，不是系统自身的续行率之维。

那么，要使 u 成为系统自身的续行率之维，最少需要什么？

对照上述失败，可以逐项读出：

其一，承担 C → u 的整体组织，必须已经成为 F 的当前沉积承载组织，而不是只由当前输入或外部条件即时维持的响应状态——发生而无留存、一处可达、一个数学标签，都根本没有这样的组织；外部开关只在开关开放时即时维持这一续行。

其二，这一组织必须真实进入 C 处续行到 u 这一后来关系的生成：它不能只是被记录下来、与 u 相关而不参与 u 的生成——这由"留存而不管后来"一层暴露。

其三，这一后来关系必须由该组织中可从 C 这一入口接达、并实际承担 C → u 的场内已成稳定复走结构支撑：不能只在某一回成立，也不能靠场外条件的反复出现来维持——前者由"影响过一次而不能复走"一层暴露，后者由外部开关世界暴露：即使外部开关每次都恰好开放，C → u 的反复出现也不是场内已成结构的支撑。

这三项要求，分别对应已封版 Law 资格体系中：

Established  
DynamicRole  
ΩSupport

三个结构谓词。三者的既有含义是：Established 即"R 已经成为 F 的当前沉积承载组织，而不是只由当前输入即时维持的响应状态"；DynamicRole 即"R 真实进入 Rel(L) 所涉后来关系生成"；ΩSupport 即"这种后来关系已经由 R 中可从适用入口接达、并实际承担该关系的 Ω 结构支撑"。

对应的方式并不相同：其一直接就是 Established 的既有含义；其二在单一承载时直接就是 DynamicRole 的既有含义；其三则只到"场内已成稳定复走结构支撑"，处在 StableReplay 一层，并未直接到达"Ω 结构支撑"。三者各自如何落到相应谓词，见下文条件路径。

这里须如实申明本步的条件路径。

Established：失败世界逼出的，正是 Established 的既有含义本身——承担组织已经成为 F 的当前沉积承载组织，而不是只由当前输入即时维持的响应状态。《律必然式》形式实现定理亦申明，这一含义即"沉积成形"的全部内容。本篇不经 CurrentCarrier、CarrierRealizes、CarrierNonInstant 等结构分量间接取得 Established，因此不经《律一般式》的 H1。

DynamicRole：失败世界逼出的是"真实进入后来关系生成"。在单一承载的情形中，这就是 DynamicRole 的既有含义。但本篇允许一维由冗余、协同、备用或多重承载结构承担（一维可以在 𝓛\_P 中登记不止一处）；在这些情形中，要断言相应承载者的 DynamicRole = 1，须依赖上游 H3：该动力归属具有客观真值，且不以简单但为删除反事实为必要条件。H3 的形式化已完成，但其本体回读真值仍为 Conditional。所以本步在这些情形中携带 H3，记为 H3^red；非此情形不额外要求 H3。

ΩSupport：失败世界实际逼出的，是"承担须由场内已成的稳定复走能力支撑"这一要求，它处在 StableReplay 一层。由此落到 ΩSupport——即由可从适用入口接达、实际承担该关系的 Ω 结构支撑——需要上游《律一般式》的 H2（Ω 完备表达桥）：

StableReplay\_F,t(L; R, I) ⇒ ΩSupport\_F,t(L; R, I)

H2 在上游仍为待验。改换措辞、或声称"直接按 ΩSupport 的既有含义读取"，都不能取消这一步：上游已把"已成结构能继续承担"与"承担段具 Ω 支撑"区分开，并把二者之间的完备表达关系专门登记为 H2。所以本步普遍携带 H2。

Ω 依《场数理式》v2.7 读作 Ω\_W——申报窗口 W 内已实际表现出的稳定复走之历史资格谓词，不作前瞻保证——与《律必然式》v1.4 处理相同；H2 之后件 ΩSupport 依此读。《律一般式》的 C2 不在本篇证明路径上。

这里不是把 Law 预设为概率维的定义，而是上述失败世界各自暴露出的缺口，恰好落在 Law 资格体系已经形式化的三处职责上。这一对应并非巧合：《律一般式》的必要向追问，正是沿"一次关系发生""关系已经留下而不管后来""已经影响后来一次"三层逐步逼出其承载组织须已形成、须真实进入后来、须有稳定复走支撑。本篇不重新定义这三项，只按其既有含义使用。

于是，在 H2 ∧ H3^red ∧ SC\_Hold 之下，若 u 是 V\_P 中的正式一维，则存在 u 所在的续行位 C\_u、场内承载组织 R\_u 与候选律 L\_u 及其适用域 I\_u，使：

Established\_F,t(R\_u)  
∧ DynamicRole\_F,t(L\_u; R\_u, I\_u)  
∧ ΩSupport\_F,t(L\_u; R\_u, I\_u)

在同一个 R\_u 上成立，且 Rel(L\_u) 所承担的正是 C\_u 处续行到 u 这一后继关系。

上面的世界为便于对照，把 u 放在与 v\_1 相同的续行位上；但本轮论证不依赖各维是否同属一个续行位。无论 u 在哪一处续行位上，裸候选都不能成为系统自身的续行率之维。

依 2.3 所承继的《律必然式》充分向：

∃R\_u \[  
&nbsp;&nbsp;Established\_F,t(R\_u)  
&nbsp;&nbsp;∧ Govern\_F,t(L\_u; R\_u, I\_u)  
\]  
⇒ Law\_F,t(L\_u, I\_u)

所以，在 H2 ∧ H3^red ∧ SC\_Hold 之下：

Law\_F,t(L\_u, I\_u) = 1

对 V\_P 中每一维，同一论证都成立：任何一维若只是偶发、可达、外部开关或数学标签，它都不能作为系统自身的续行率之维。

这里要记下一个关系：

Law\_F,t(L\_i, I\_i) = 1 ∧ BearDim\_F,t(L\_i, v\_i; C\_i)

BearDim\_F,t(L\_i, v\_i; C\_i) 表示：L\_i 所承担的关系内容，正是续行位 C\_i 处续行到 v\_i 这一后继关系。

v\_i 与 L\_i 不是同一个对象：

v\_i ≠ L\_i

v\_i 是续行维，是某一续行位处一个可区分的后继方向；L\_i 是承担该维的正式 Law 引用。一维由律承担，不等于一维就是律。

到这里，前两轮所得可以收束为：

MultiLawDimension\_F,t(𝒫)

其最低职责为：\|V\_P\| ≥ 2，各维彼此可区分；并且对每一个 v\_i ∈ V\_P，存在某个续行位 C\_i、正式 Law 引用 L\_i 及其适用域 I\_i，使 L\_i 取得 Law 资格并承担 C\_i 处的 v\_i。

MultiLawDimension\_F,t(𝒫)  
:⇔  
&nbsp;&nbsp;\|V\_P\| ≥ 2  
&nbsp;&nbsp;∧ ∀v\_i, v\_j ∈ V\_P, i ≠ j：Dist(v\_i, v\_j)  
&nbsp;&nbsp;∧ ∀v\_i ∈ V\_P ∃C\_i ∃L\_i ∃I\_i \[  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Law\_F,t(L\_i, I\_i) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;∧ BearDim\_F,t(L\_i, v\_i; C\_i)  
&nbsp;&nbsp;&nbsp;&nbsp;\]

这里尚未要求：

C\_i = C\_j

否则后文便无法再从跨任务的失败世界逼出共同续行位。

Law 身份限界

本篇不判定承担不同 v\_i 的 Law 引用在跨维意义上是否为同一 Law（SameLaw）或非同一 Law（NotSameLaw）。现行 Law identity 并未由本篇闭合，本篇也不调用它。因此 MultiLawDimension 中的"MultiLaw"，只表示多个可区分维各自取得正式 Law-bearing，是一个多维的 Law-bearing role family，不构成 Law 身份数量的判词。后文所谓"多律组织"，只作这一职责组织的简称；本篇在构造世界时写下的 L\_1、L\_2 等，也只是 Law 引用的记名，不断言其身份彼此不同。

记这一 Law-bearing role family 为：

𝓛\_P = { (L\_i, v\_i, C\_i) \| v\_i ∈ V\_P }

𝓛\_P 是候选组织 𝒫 所申报的承担登记：其中每一项 (L\_i, v\_i, C\_i) 都须满足 ∃I\_i \[Law\_F,t(L\_i, I\_i) = 1 ∧ BearDim\_F,t(L\_i, v\_i; C\_i)\]，V\_P 的每一维在其中至少登记一处；一维可以登记不止一处。

它可以由单一、分布、冗余或协同的承载组织实现；本轮只要求每一维至少取得一处正式 Law-bearing。

于是，在 H2 ∧ H3^red ∧ SC\_Hold 之下，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

MultiLawDimension\_F,t(𝒫) = 1

后续各节所得均以此为已知前项，因而整条必要向随同携带这一条件。

此时留下的未闭合处恰好是：

这些各自已有 Law-bearing 的维，为什么属于同一份 Probability 所申报的共同续行位 C？

五、各维都有律承担，就已经是一份概率了吗？

保持：

MultiLawDimension\_F,t(𝒫) = 1

构造如下世界：

L\_1 : C\_a → v\_1  
L\_2 : C\_b → v\_2

其中：

C\_a ≠ C\_b

C\_a 是一处续行问题，例如某一刺激到来后的趋避；C\_b 是另一处续行问题，例如另一处结构中的沉积迁移。两维各自取得正式 Law-bearing，各自稳定复走，彼此可区分。

上一节所得在这里完整保持：\|V\_P\| ≥ 2，Dist(v\_1, v\_2)，并且各维各有其 C\_i、L\_i、I\_i。

分析者把 v\_1 与 v\_2 并列，统计二者在某一时段内各自的实现次数，并写下一个比例。

现在问：

这两个 Law-bearing 维，凭什么属于同一份概率，而不只是同时存在于 F 中？

它们回答的根本不是同一个续行问题。L\_1 回答"C\_a 之后如何续行"，L\_2 回答"C\_b 之后如何续行"。两者之间不存在"同一处续行的后继在二维之间如何生成"这一关系。写下的比例只是两个无关事件计数之比，不是任何一次续行在 v\_1、v\_2 之间的率。

"率"所需的"相对"，只能在同一个续行问题的不同后继之间成立。

所以本篇在这里第一次逼出：所申报组织中的每一处 Law-bearing，都落在同一个续行位 C 上。简写为：

∀i：C\_i = C

形式上，C\_i 是第四节存在量化出来的见证，一维可能不止一个 (C\_i, L\_i, I\_i)。为使 C\_i 有确定的绑定，定义直接量化已登记的 role family 𝓛\_P，而不引入函数 C(v\_i)，也不强迫见证唯一：

SameContinuationPosition\_F,t(𝒫; C)  
:⇔  
&nbsp;&nbsp;∀(L\_i, v\_i, C\_i) ∈ 𝓛\_P：C\_i = C

由于 V\_P 的每一维在 𝓛\_P 中至少有一处登记，由此可得：V\_P 的每一维，其 Law-bearing 都落在 C 上：

∀v\_i ∈ V\_P ∃L\_i ∃I\_i \[  
&nbsp;&nbsp;Law\_F,t(L\_i, I\_i) = 1  
&nbsp;&nbsp;∧ BearDim\_F,t(L\_i, v\_i; C)  
\]

只有到这里，工作域中预先登记的共同续行位 C，才从候选申报索引升级为 Probability 必要资格的一部分。

于是，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

SameContinuationPosition\_F,t(𝒫; C) = 1

未闭合处：

同一个续行位上各维的 Law-bearing，它们各自承担 C 处续行时所处的条件，是否是同一个？

六、同在一个续行位，就已经属于同一率关系了吗？

保持：

MultiLawDimension\_F,t(𝒫) = 1  
SameContinuationPosition\_F,t(𝒫; C) = 1

构造如下世界。

在同一个续行位 C 上：

L\_1 只在条件 a 中承担 C → v\_1  
L\_2 只在条件 b 中承担 C → v\_2

条件 a 下，C 之后总是 v\_1；条件 b 下，C 之后总是 v\_2。

历史上，F 在条件 a 下到达 C 共 70 次，在条件 b 下到达 C 共 30 次。观察者事后把两个条件下的历史混在一起，得到：

v\_1 : v\_2 = 70 : 30

在这个世界里：

每一维都取得正式 Law-bearing；

二维的 Law-bearing 都落在同一个 C 上。

现在问：

这两个 Law-bearing 维凭什么属于同一个合法率关系，而不是把两个条件下的结果拼在一起？

在条件 a 这一生成情形中，C 之后只有 v\_1；在条件 b 这一生成情形中，C 之后只有 v\_2。每一个生成情形内部，都只有单一续行，回到了第三节的单路情形。70 : 30 这个数，不是任何一个生成情形中 v\_1 与 v\_2 的相对生成关系，而是两个不同条件出现次数之比，被观察者在事后读成了"C 处的率"。

这是跨条件拼证：从条件 a 中取 v\_1 的承担，从条件 b 中取 v\_2 的承担，拼成一份并不存在于任何单一生成情形中的"率"。

所以必须要求：V\_P 各维的承担，处在同一个生成域之中。

SameGenerationDomain\_F,t(𝒫; C, 𝔯\_P)  
:⇔  
&nbsp;&nbsp;∀(L\_i, v\_i, C\_i) ∈ 𝓛\_P：  
&nbsp;&nbsp;&nbsp;&nbsp;L\_i 对 v\_i 的承担在同一个 𝔯\_P 中成立  
&nbsp;&nbsp;∧ NoCrossConditionStitch\_F,t(𝒫; 𝔯\_P)

其中：

NoCrossConditionStitch\_F,t(𝒫; 𝔯\_P)  
:⇔  
&nbsp;&nbsp;𝔯\_P 不是由各维分属的、  
&nbsp;&nbsp;按申报本应分开冻结的不同条件拼接而成

这里量化的是 𝓛\_P 中的一般元素 (L\_i, v\_i, C\_i)，不在定义内部预设 C\_i = C。在本节的推导中，SameContinuationPosition = 1 已由第五节保持，所以此时所有 C\_i = C；但 SameGenerationDomain 本身只承担"同域且不可跨条件拼证"的职责，不重复承担共同续行位。同位、同域、同次生成三项由此各自承担不同的排除任务。

这里还逼出一条域纪律。

如果 𝔯\_P 可以在看到结果以后再选，那么同一段历史可以被切成"条件 a 与条件 b 合为一个域"，也可以被切成"只取条件 a"，还可以被任意缩域、换域、重选样本，直到得到想要的率。那样，"同一个生成域"就失去了约束力：任何拼接都可以在事后被重新命名为"同一个域"。

所以 𝔯\_P 必须事前申报：在检验 V\_P 诸维的承担以前，𝔯\_P 已经确定；不得见结果以后缩域、换域或重选样本。

Frozen(𝔯\_P) ≺ 检验 𝒫

同时必须把"冻结率域"与"冻结一切"分开。

事前冻结的，是资格条件：续行位 C、所申报的生成/再入制度、该制度允许何种扰动与合法变化。它不是把制度内一切合法变量逐一钉死。

如果把一个确定性系统的完整微状态全部固定，它的后继当然只有一个；但那是另一个更细的生成情形，不是原先申报的 𝔯\_P。在所申报的 𝔯\_P 中，环境扰动、合法输入与场内状态可以按申报的制度变化。

因此，"域内允许的合法变化"与"跨条件拼接"的区别，不在于变化是否存在，而在于：这些变化是否属于事前申报的同一生成制度。条件 a、b 若按其自身规定应当被分开冻结，把它们混在一起就是跨条件拼证；某种变化若本就属于申报制度内的合法变化，它就不构成拼接。

若把条件 a、b 在事前重新申报为同一生成制度内的合法变化，并且这一制度确有系统侧实际合法生成/再入根据，那么该实例已不是本节反例。此时 70 : 30 由 a、b 在该制度中的出现给出；它是否由申报组织承担，不再是同域问题，而是后文所要追问的"相对生成由谁承担"的问题。本节只排除：a、b 按申报本属不同生成制度，却被拼成一个域。

于是，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

SameGenerationDomain\_F,t(𝒫; C, 𝔯\_P) = 1

未闭合处：

同位、同域的诸维及其 Law-bearing，是否真正属于同一次续行的生成？

七、同位同域，就已经属于同一次续行生成了吗？

保持：

MultiLawDimension\_F,t(𝒫) = 1  
SameContinuationPosition\_F,t(𝒫; C) = 1  
SameGenerationDomain\_F,t(𝒫; C, 𝔯\_P) = 1

构造如下世界。

在同一个续行位 C、同一个事前申报的 𝔯\_P 中，F 内有两个彼此独立的并行生成过程：

过程一：由 L\_1 承担，C 之后生成 v\_1  
过程二：由 L\_2 承担，C 之后生成 v\_2

每一次合法再入 C，两个过程同时各自运行：v\_1 与 v\_2 都发生。它们在同一位置、同一上下文中出现，但不是同一次续行事件的互斥后继：过程一的发生不排除过程二的发生，过程二的发生也不排除过程一的发生。

在这个世界里：

两维可区分，各自取得正式 Law-bearing；

同属 C；

同在 𝔯\_P 中。

若分析者分别统计二者，也可以写出某个比例。

现在问：

这两个 Law-bearing 维是否真正属于同一次续行生成关系？

不是。

率所需的"相对"，只能存在于同一次续行生成事件的诸后继方向之间。在上面的世界中，v\_1 与 v\_2 不是同一次续行事件的两个不同去向，而是两次续行各自的去向。它们并存，却不互斥。写下的比例，只是两个并行过程各自产出之比，不是任何一次续行事件在两维之间的相对生成。

物理执行层上，每一次续行都归一。概率之"多维"，只能是同一次续行生成关系所面对的多个后继方向；一次实际续行若落入这些维，也只兑现其中之一。两个并行过程各自归一，不构成同一次续行的多维。

所以必须要求：V\_P 诸维是同一次续行生成事件所对应的可区分后继方向。

SameGenerationRelation\_F,t(𝒫; C, 𝔯\_P)  
:⇔  
&nbsp;&nbsp;V\_P 诸维是 𝔯\_P 中 C 处  
&nbsp;&nbsp;同一次续行生成事件所对应的可区分后继方向；  
&nbsp;&nbsp;一次实际续行若兑现 V\_P 中的维，  
&nbsp;&nbsp;则至多兑现其中一维

此处只规定 V\_P 内诸维作为同一次续行后继的互斥兑现，不要求每一次实际续行都落入 V\_P，不要求 V\_P 穷尽 C 处全部实际后继，因此不推出 FullCoverage。

这一谓词也不规定诸维之间的相对生成关系由谁形成或承担。后者是第八节的问题，本节不预先回答。

这里的"同一次续行生成事件"，指 𝔯\_P 中一次合法再入 C 所引起的续行生成；它不是 𝔯\_P 内按条件再细分出来的子情形。所以第六节的世界中，每一次合法再入 C（无论处在条件 a 还是 b）都只兑现 v\_1、v\_2 之一，SameGenerationRelation 在那里可以成立，那个世界失败的是同域，不是同次生成。

上面的并行过程世界违反的正是这一点：每一次合法再入 C，v\_1 与 v\_2 在同一次续行中同时兑现，违反"至多一维"。

于是，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

SameGenerationRelation\_F,t(𝒫; C, 𝔯\_P) = 1

到这里，连续三轮所得的绑定条件，才允许统一命名为：

CommonContinuationBind\_F,t(𝒫; C, 𝔯\_P)  
:⇔  
&nbsp;&nbsp;SameContinuationPosition\_F,t(𝒫; C)  
&nbsp;&nbsp;∧ SameGenerationDomain\_F,t(𝒫; C, 𝔯\_P)  
&nbsp;&nbsp;∧ SameGenerationRelation\_F,t(𝒫; C, 𝔯\_P)

对这一命名，须作四点申明。

第一，CommonContinuationBind 不是一个新的物理实体，不是在诸维及其 Law-bearing 之外另有一个"绑定物"。它是一项组织绑定纪律：诸维及其承担，必须出于同一续行位、同一事前申报的生成域、同一次续行生成关系；不得跨任务、跨域、跨生成关系拼证。这与已封版 Law 资格体系中"同一个 R"的纪律同属一类：同见证，不可拼证。

第二，"异维"已由 MultiLawDimension 之 \|V\_P\| ≥ 2 与 Dist 承担，不再放入 Bind。

第三，CommonContinuationBind 约束的是维角色与生成关系的共同归属，不承担 Law identity。它要求 SameContinuationPosition、SameGenerationDomain、SameGenerationRelation，但不要求、也不推出：

L\_i ≠ L\_j

或：

SameLaw(L\_i, L\_j) = 0

不同维是否可能由同一 Law 身份的不同 role occurrence 承担，属于 Law identity 问题；本篇不越过这一边界。

第四，三项绑定各有自己的失败世界：第五节的世界满足 MultiLawDimension 而 SameContinuationPosition 失败；第六节的世界满足同位与同次生成而 SameGenerationDomain 失败；第七节的世界满足同位同域而 SameGenerationRelation 失败。因此同域不被同位与同次生成吸收，同次生成不被同位与同域吸收。

同位与同次生成之间的关系须如实说明：SameGenerationRelation 以"C 处"为求值位置，诸维若是 C 处同一次续行生成事件的后继方向，其所在续行位即已是 C，因此它可能在内容上蕴含一部分同位要求。本篇仍把 SameContinuationPosition 列为独立分量，理由是：它是递推中第一次把各 C\_i 收束为 C 的责任项，并且直接约束 𝓛\_P 中每一处承担登记的续行位，而 SameGenerationRelation 约束的是诸维作为后继方向的归属。二者之间是否存在可合并的内容重叠，属于《概率数理式》形式化时的分量整理问题；它只涉及 CommonContinuationBind 内部分量的写法，不影响顶层三项的必要性与当前推导最小性。

于是，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

CommonContinuationBind\_F,t(𝒫; C, 𝔯\_P) = 1

未闭合处：

诸维各有 Law-bearing，并同绑于同一次续行生成。但这一次续行的后继在诸维之间如何生成，是谁承担的？

八、诸维同绑，就已经承担率了吗？

保持：

MultiLawDimension\_F,t(𝒫) = 1  
CommonContinuationBind\_F,t(𝒫; C, 𝔯\_P) = 1

构造外部选择器世界。

设候选 Probability 𝒫 所申报的 Law-bearing role family 𝓛\_P，已经承担 v\_1、v\_2 的结果执行：若这一次续行取 v\_1，由 L\_1 执行 C → v\_1；若取 v\_2，由 L\_2 执行 C → v\_2。

另有一个机制 M，位于这份申报组织之外，并由 M 独自决定二维之间的相对生成关系：

M：以 0.7 取 v\_1，以 0.3 取 v\_2

每一次合法再入 C：M 先决定这一次取 v\_1 还是 v\_2；然后由相应的 Law-bearing 执行。

v\_1、v\_2 各自的 Law-bearing 都真实成立：它们已经沉积形成，真实进入后来续行，稳定复走。二维同属 C，同在 𝔯\_P 中，并且是同一次续行生成事件所对应的两个可区分后继方向；在该反例中，每次由这份候选组织申报的实际续行兑现 v\_1、v\_2 中的一维。

按第七节的定义，SameGenerationRelation 在这里成立：该谓词只规定诸维属于同一生成事件，不规定诸维之间的相对生成由谁形成。M 先决定取哪一维，并不使 v\_1、v\_2 离开同一生成事件；它改变的只是"谁形成二者之间的相对生成"。

长期频率可以稳定为：

v\_1 : v\_2 ≈ 70 : 30

在这个世界里，MultiLawDimension 与 CommonContinuationBind 都成立。

现在问：

v\_1 与 v\_2 之间 0.7 : 0.3 的相对生成关系，是谁承担的？

不是申报组织 𝓛\_P。

这一相对生成关系，在任何一次续行中都已经由 M 先行决定。按本反例的构造，0.7 : 0.3 完全由 M 的选择规则给定；L\_1、L\_2 的申报职责，只在相应一维被取以后承担该维的结果执行，不承担二维之间相对生成关系的形成。

这里必须把两种承担分开：

结果承担（OutcomeBearing）：某一维一旦被取，便由相应的 Law-bearing 执行。

率承担（RateBearing）：诸维之间的相对生成关系，由组织承担其形成。

外部选择器世界中，申报组织有结果承担，没有率承担：

OutcomeBearing ⇏ RateBearing

它的成员是支路执行，而不是概率之律。

本节所排除的，是：申报组织只承担结果，而相对生成率完全由别处承担。

若 M 本身后来被证明属于这份 Probability organization 的正式系统侧率承担结构，那么该实例已不是本节反例；候选组织必须把 M 一并重新申报，并按完整组织重新评价。本节不因 M 的存在本身而排除任何组织，只排除"申报组织与率承担者分离"这一情形。

还要注意一个易混处。

在这个世界里，若取消 v\_1 唯一的执行者，v\_1 将无法执行，观察到的频率随之改变。但这一改变来自一维失去了执行者，而不是来自该执行者承担着 v\_1 与 v\_2 之间的相对生成。取消唯一执行者所引起的结果变化，只能说明结果承担，不能说明率承担。

这个世界如果被判为 Probability，那么"概率之维由律承担"就只剩下"每个结果都有律去执行"；而诸维之间的率，却完全落在申报组织以外的 M 上。"概率由律组织构成"这一方向，将被外部选择器整个架空。

所以必须要求：诸维之间的相对生成关系，由这份申报组织本身真实承担。

DomainRelativeRateBearing\_F,t(𝒫; C, 𝔯\_P)  
:⇔  
&nbsp;&nbsp;在事前冻结、非空、非空洞、  
&nbsp;&nbsp;有系统侧实际合法生成/再入根据的 𝔯\_P 中，  
&nbsp;&nbsp;𝓛\_P 作为组织的合法承重状态  
&nbsp;&nbsp;真实进入 V\_P 诸维之间相对生成关系  
&nbsp;&nbsp;Rel\_ρ(𝒫; C, 𝔯\_P) 的形成；  
&nbsp;&nbsp;它不能只有结果执行，  
&nbsp;&nbsp;而把相对生成率完全交给申报组织之外的机制

它不能被写成下列任何一项：

RateExists            ——"存在一个率"只说数值关系存在，不说谁承担它；  
StableFrequency       ——频率稳定在外部选择器世界中同样成立；  
NumericRateRead       ——数值能读出不说明谁生成它；  
OutcomeBearing        ——各维有律执行，已被本节世界证明不足。

于是，若 Probability\_F,t(𝒫; C, 𝔯\_P) = 1，则：

DomainRelativeRateBearing\_F,t(𝒫; C, 𝔯\_P) = 1

未闭合处：

"在 𝔯\_P 中"与"由 𝓛\_P 承担"都还太宽。率域可以是什么样的域？承担者是否必须逐一角色各自承担？

九、率承担须在怎样的域中，由谁承担？

### 9.1 率域必须事前冻结

第六节已从跨条件拼证逼出 𝔯\_P 的事前申报。率承担把这一纪律再用一次：如果 𝔯\_P 可以在看见率以后重切，那么任何一个外部偶然的频率，都可以通过事后选域而被"找到"一个似乎由申报组织承担的域。

所以率承担只在事前冻结的 𝔯\_P 中求值，不得见结果以后重切样本：

Frozen(𝔯\_P)

### 9.2 率域必须是系统侧非空洞的生成域

事前冻结一个符号集合，并不足以使它成为 Probability 的合法生成域。

构造分析者域世界：分析者在 C 处写下一个样本空间，给 v\_1、v\_2 各配一个数；但 F 本身从未在这一"域"所描述的情形中实际合法再入 C，这一"域"只存在于分析者的表示中。

在这样的"域"上说"组织承担相对生成率"，只是把分析者的样本空间反写成系统本身。同样，把观察者不知道的隐藏变量所构成的集合直接称为率域，是把观察者一侧的无知当作系统一侧的生成。

所以 𝔯\_P 至少必须：

非空；

非空洞；

有系统侧实际合法生成/再入根据；

不得仅由观察者无知、事后样本切分或纯反事实集合构成。

这些要求是"率承担在什么域中求值"的内部纪律，属于 DomainRelativeRateBearing 自身的含义，不另立为顶层必要项。

本篇只建立这一结构要求。何谓非零生成质量、何种生成测度可以表示该域、何时由生成核或其他形式对象实例化这些要求，属于《概率数理式》；本篇不建立测度、质量或生成核谓词。

### 9.3 承担主体是组织，不是逐一角色

构造冗余承担世界。

在 C 处，v\_1 在 𝓛\_P 中有两处登记：(L\_a, v\_1, C) 与 (L\_b, v\_1, C)。二者的承重状态冗余地参与 v\_1 与 v\_2 之间相对生成关系的形成：任一在位，都足以维持同一率关系。

单删 L\_a：L\_b 完整补偿，率关系不变。

单删 L\_b：L\_a 完整补偿，率关系不变。

同时删 L\_a 与 L\_b：率关系改变。

如果要求：

∀(L\_i, v\_i, C\_i) ∈ 𝓛\_P：do(L\_i off) ⇒ Rel\_ρ 改变

那么在这个世界里，L\_a 与 L\_b 都将被判为不承担率，申报组织的率承担被判为 0；而事实上，率关系正是由 L\_a 与 L\_b 共同维持的，联合删除即可暴露这一点。

所以不得要求每一成员逐项满足但为（but-for）条件。率承担的主体是 Probability organization：

可以是联合承担：诸角色共同形成率关系，单独任一个都不单独决定它；

可以是分布承担：率关系分布在诸角色的承载组织中；

可以是冗余承担：多个角色各自足以维持同一率关系。

这与已封版 Law 资格体系中 DynamicRole 取存在极性、允许冗余与协同承担的纪律一致。

### 9.4 本节不做的事

本节只确定率承担的求值域纪律与承担主体。率承担的操作判据——何种合法干预、何种比较、何种读出可以判定 Rel\_ρ 是否由 𝓛\_P 承担——属于《概率数理式》与《概率判定式》，本篇不展开。

十、必要构成闭合与反审

### 10.1 连续递推的回看

现在沿同一个 𝒫、同一个 C、同一个 𝔯\_P，已经得到：

MultiLawDimension\_F,t(𝒫) = 1  
CommonContinuationBind\_F,t(𝒫; C, 𝔯\_P) = 1  
DomainRelativeRateBearing\_F,t(𝒫; C, 𝔯\_P) = 1

这三项不是事先摆好的三个格子。

第三节由单路情形逼出多维；第四节由裸候选逼出每一维须取得正式 Law-bearing，二者收束为第一项。这时各维尚可各有其续行位 C\_i。第五节由跨任务世界第一次逼出 ∀i：C\_i = C；第六、七节再由跨条件、并行过程两个世界逼出同域、同次生成关系；三者收束为第二项。第八节在前两项都成立之后，由外部选择器世界逼出第三项；第九节再收紧第三项的求值域与承担主体。

每一步都由上一步留下的未闭合处产生。每一项都有独立的逼出世界：第一项由单路与裸候选世界直接逼出；其后每一新增职责，均在此前所得职责保持的条件下，由其失败世界逼出。

### 10.2 反审纪律

本节的任务不是证明：

N\_P ⇒ Probability

也不负责证明：某一候选属性 X 缺失或改变时，Probability 仍然成立。

后一种主张，无论针对同一时刻的另一世界，还是针对同一实例在合法演化之后的状态，都需要"三项成立则 Probability 成立"或 Probability 的跨时保持；前者属于《概率必然式》，后者属于《概率稳定式》。本篇均无权使用。

所以反审只做一件事：回查第三至第九节实际出现过的每一个失败世界与每一个未闭合缺口，看是否有任何一个缺口必须依赖某一候选属性 X 才能关闭。

若没有任何缺口必须依赖 X 才能关闭，那么本篇没有取得：

Probability ⇒ X

X 因此不进入本篇当前必要结构。

若某一失败世界虽可用 X 描述，但使 Probability 不成立的，实际是三项之一的失败，那么 X 所涉的排除力已由该项承担，不独立。

本节所得的强度到此为止："X 未被本篇逼出为必要职责"。它不是"X 不是必要职责"的证明。若以后另有独立证明得到 Probability ⇒ X，则触发第十四节的当前最小性重开条件，而不能以本节"未逼出"反驳该结果。

### 10.3 逐项反审

本体随机（OntologicalRandomness）

第三至第九节的各个缺口——单路无相对、裸候选无承担、跨任务、跨条件、并行过程、外部选择器、事后切域与空洞域、逐一但为——没有一个是靠"系统本体随机"关闭的；每一处都由多维、Law-bearing、同位、同域、同次生成关系或组织率承担关闭。

与随机性最相近的隐藏确定性选择器情形，其失败也落在已有三项上：若选择变量 s 外置于申报组织，s 的分布由组织以外决定，申报组织只执行被 s 选中的一维，则与第八节外部选择器同构，第三项失败；若 s 按 𝔯\_P 的申报本应被冻结，而观察者把不同 s 下的试次混在一起，则是跨条件拼证，第二项失败。

所以本篇没有取得：

Probability ⇒ OntologicalRandomness

本体随机未被本篇逼出为必要职责。

观察者无知（EpistemicUncertainty）

没有任何缺口的关闭依赖观察者是否知道某一变量。第六节与第九节 9.2 反而表明：观察者的无知不能把跨条件混合变成同一率关系，也不能使一个隐藏变量集合成为率域。无知属于识出层。

本篇没有取得：

Probability ⇒ EpistemicUncertainty

可能性（Possibility）

第四节表明，可达、可能不使一个方向成为续行维；此后各缺口的关闭，也都不需要另设一个"可能结果空间"。

本篇没有取得：

Probability ⇒ Possibility

各向异性（Anisotropy）

各缺口的关闭无一依赖诸维之率不相等。第三节所要求的"相对"，是诸维之间存在相对生成关系，不是这一关系的取值不均。母本以 Pr(q\_i,t) ≠ Pr(q\_j,t) 定义的是续行偏置，不是概率资格；偏置程度属于状态，不属于本篇所问的资格。

本篇没有取得：

Probability ⇒ Anisotropy

各向异性未被本篇逼出为必要职责。

正率（p\_i \> 0）

第四节逼出的一维必要资格，是它须有正式 Law-bearing，而不是它当前的率值；此后各缺口也没有一个要求每一维当前率为正。

本篇没有取得：

Probability ⇒ ∀v\_i ∈ V\_P：ρ(v\_i) \> 0

因此本篇不定义：

ProbDim(v\_i) ⇔ ρ\_i \> 0

同时须把三种情况在概念上分开：一个方向不在 V\_P 中，是不在这份候选概率的维内；一个维当前率为零，是率关系的一个状态值；一个维在某一次续行中没有发生，是这一次执行归一于他处——可以是 V\_P 中的其他维，也可以是 V\_P 以外的后继。

v ∉ V\_P  ≠  ρ(v) = 0  ≠  Actual(v, t) = 0

本篇只作此区分，不据此主张任何具体世界中 Probability 成立或不成立。

数值率可读（RateRead）

各缺口的关闭都是结构性的：谁承担、在哪一续行位、在哪一域、是否同次生成、由谁承担相对生成。没有一个缺口依赖数值读出可得。

本篇没有取得：

Probability ⇒ RateRead ≠ ⊥

读不出不等于读得为零。本篇的本体资格不以数值率可读为前件。

归一（Normalization）

归一是数值表示的一个性质。各缺口的关闭都不依赖数值表示；并且即使可以读出，∑ρ\_i = 1 也可能只是 V\_P 内部条件化以后的归一，而不是完整生成域上的归一。

本篇没有取得：

Probability ⇒ Normalization

完整覆盖（FullCoverage）

各缺口所要求的，是 V\_P 内诸维的承担、绑定与率承担；没有一个缺口要求 V\_P 穷尽 C 处全部实际后继。

本篇没有取得：

Probability ⇒ FullCoverage

同时须申明：V\_P 内部的条件率不得申报为 C 处完整的后继分布；也不得为了使和为一，把"停止""未知"或尚未取得 Law-bearing 的新径自动补成概率维，或删去未解决的部分再重新归一。这些是对数值申报的纪律，不是新增必要职责。

稳定经验频率（Stable Empirical Frequency）

有限次重复得到的：

ρ̂\_N

是后来的观察与估计结果。

它不能定义 Probability，也不能单独证明 Probability：外部选择器世界中频率同样稳定，而第三项失败；跨条件混合世界中频率同样稳定，而第二项失败；依本篇必要向（在 H2 ∧ H3^red ∧ SC\_Hold 之下），这两个世界都不是 Probability。

同时，各缺口的关闭无一依赖重复次数或频率稳定。

本篇没有取得：

Probability ⇒ StableEmpiricalFrequency

熟悉度（Familiarity）

熟是对深者的称谓（场篇第一定义13；外三「故可称深者为熟」）：某一维之承担结构沉积加深，即其较前更熟；熟不是沉积加深的来源。熟也可关联率关系的状态；但没有一个缺口的关闭依赖熟悉度。第八节所要求的是组织承担相对生成，单一熟悉度标量不能替代这一职责。

本篇没有取得：

Probability ⇒ Familiarity

### 10.4 反审结论

回查第三至第九节全部失败世界与未闭合缺口，本篇没有进一步逼出第四个独立必要职责；上列候选均未被逼出为必要职责。

因此当前可收束的是：

H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ Probability ⇒ N\_P \]

以及三个已经逼出职责的不可删除性（第十二节）。

这里的"当前"必须保留：本节是对本篇递推的穷尽回查，不是对一切未来可能结构 X 的绝对穷尽证明；若以后发现新的独立必要职责，第十四节所列当前最小性重开条件即被触发。

这不构成新的 H。H 用于尚未验证而又实际承重当前结论的前件；此处是对当前最小性结论强度的限界。

本节也不说明：

N\_P ⇒ Probability

也不说明任何候选属性缺失或改变后 Probability 仍然成立。充分方向属于《概率必然式》；跨时保持属于《概率稳定式》。

十二、最小结构

### 12.1 方法声明

以下删除测试，删除的是最终资格要求中的一个职责，而不是机械地把一个复合谓词置 0、再强迫另外两个仍取 1。

因为后两项的求值对象都会引用候选维及其承担角色，三个复合谓词并非形式上完全无依赖。

所以最小性审查问的是：

若从最终必要结构中取消某一职责，而保留其余已经逼出的职责边界，是否会重新放入一个本篇已经构造并排除的非概率世界？

删除测试在连续递推完成以后进行。它检验的是所得职责是否各自不可删，不是它们的发生来源；它们的来源是第三至第九节的追问。

### 12.2 删除测试

第一，取消"维须取得正式 Law-bearing"这一职责。

DomainRelativeRateBearing 的承担主体是 𝓛\_P，而 𝓛\_P 正是 Law-bearing role family；取消 Law-bearing 职责以后，该谓词不能原样保留。所以这里考察的是删职后的弱化世界：

取消"每一维须取得正式 Law-bearing"这一职责；共同续行位、共同生成域、同次生成关系的要求，改按承担诸维的系统侧角色求值，而不再按 𝓛\_P 求值；率承担只保留"存在一组系统侧角色承担诸维及其相对生成"这一较弱要求。

那么裸候选、可达分支、外部开关临时开放的结果，即可被某一率装置组织起来：这些"维"放在同一处、同一域、同一次选择之中，由装置的角色承担它们之间的比例。第四节已经排除的裸候选世界重新进入，"概率之维由律承担"这一结论整个丢失。

第二，取消 CommonContinuationBind 职责。

保留各维的 Law-bearing 与率承担职责，但不再要求同位、同域、同次生成关系。

此时第七节的并行过程世界重新进入：两维各自取得 Law-bearing；二维的产出关系由两个过程各自的 Law-bearing 形成；删职以后，率承担不再以同一生成事件为求值对象，在"诸维之间产出关系由申报组织自身形成"这一弱化读法下可以满足；唯独"同一次续行生成事件的互斥后继"这一归属失败。于是，两次续行各自的去向可以被拼成"一次续行的两维"。

第五节的跨任务世界与第六节的跨条件世界，在递推中首先由第二项排除；其比例由到达 C\_a、C\_b 或出现 a、b 的频次给出，它们是否同时被第三项排除，本测试不作判断，也不以它们作为"删去第二项即重新进入"的见证。第二项的不可删性由并行过程世界一例即已成立。

第三，取消 DomainRelativeRateBearing 职责。

保留各维的 Law-bearing 与共同绑定，但不再要求申报组织自身承担相对生成率。那么第八节的外部选择器世界重新进入：外部选择器决定全部率，申报组织只执行被选中的结果。

因此三个职责分别不可删除。

### 12.3 不可合并

三项不能互相吸收，依据是：

Law-bearing 不推出共同绑定：第五、六、七节的世界中，各维 Law-bearing 全真，CommonContinuationBind 失败；

Law-bearing 与共同绑定合起来不推出率承担：第八节的外部选择器世界中，前两项全真，DomainRelativeRateBearing 失败；

弱化的共同绑定与弱化的率承担合起来不推出 Law-bearing：12.2 第一项删职后的弱化世界中，裸候选被同位、同域、同次地组织起来并由系统侧角色承担比例，而各"维"并无正式 Law-bearing；

Law-bearing 与率承担合起来不推出同次生成归属：12.2 第二项所用的第七节并行过程世界。

因此任何一项都不能被另外两项吸收。

十五、语义裁决：怎样读"概率是律"

本组式研发起点立"概率是律"一语。

本篇不把它形式化为：

Probability = Law

在本篇所承继的 H2、H3^red 与 SC\_Hold 成立的条件下，本篇所得更准确地说是：

概率的正式续行维均须取得 Law-bearing；这些 Law-bearing roles 进一步组成同一续行生成关系中的率承担组织。

因此：

Probability ≠ one isolated Law

第三节已示：若只有一条续行，即使可记率为 1，也不形成独立于 Law 的概率组织；第八节已示：在上述条件保持时，即使诸维各有 Law-bearing、并共同绑定，只要率关系不由申报组织承担，依本篇必要向也不是 Probability。

所以"概率是律"在本篇中的正式读法（在上述条件下），不是 Law identity 等式，而是：

概率的维资格落在正式 Law-bearing 上，而其率资格落在这些 Law-bearing roles 所组成的合法组织承担上；本篇不另断言该率承担组织作为整体又构成一个独立 Law 身份。

在 Law identity 尚未闭合的范围内，"多律组织"只作上述职责组织的简称，不作不同 Law 身份数量的判词。

研发起点另有"概率是穿过律生态的律"一语。它所涉及的穿过律生态、生态组织与动力迁移等问题，不在本篇升格为定义，留给后续动力与稳定相关式文。

### 17.3 母本承继

母本续行空间、𝒬(t)、Pr(q,t)、Depth(q,t)、κ、Λ(t) 及其相关表达式：作为研发母本承继。旧 Pr(q,t) 不直接升格为本篇 Probability；∑Pr(q,t) ≤ Λ(t) 不读作归一；Pr(q\_i,t) ≠ Pr(q\_j,t) 不再是续行偏置之定义（式篇第二十 v1.2 改为对沉积差之依赖 B\_m：在申报的比较任务中合法抹平沉积差后相对行进读数改变）；∂Pr/∂t ∝ ∂Depth/∂t 已由该篇删去，只承继沉积度变化能改变率结构之方向含义（场篇第一定理17 等，带条件）。

母本关于"律不等于概率；概率描述多次运行后的外显分布，不作为生成机制"的论述：作为母本语义承继，与本篇"生成率先于经验频率与识率、每次执行归一"的结论一致，不作为形式前件。

"概率是律""概率是穿过律生态的律"：作为本组式研发起点的语义方向。前者经第十五节裁决为准确读法；后者不在本篇展开。

### 17.4 下游接口

条件传播纪律：以下任何下游式文，若仅使用本篇定义出的对象、符号或候选结构，不因此自动承继 H2、H3^red、SC\_Hold；若以本篇已证的 Probability ⇒ N\_P，或以由该必要向取得的任一分量作为承重前件，则必须同时承继 H2、H3^red 与 SC\_Hold，除非相应上游条件已被独立关闭。不得因接口化、形式化或下游命名而截断该条件。

《概率数理式》：承接 N\_P 各分量的形式表示；BearDim、Dist、C\_i 与 C、NoCrossConditionStitch、同一生成事件的形式刻画；Frozen 及率域非空洞、系统侧根据的形式刻画，包括是否及如何以生成测度、非零生成质量、生成核等形式对象表示；条件率与完整率的区分；旧 Pr(q,t) 与正式率符号的桥接。

《概率必然式》：承接充分方向 N\_P ⇒ Probability。

《概率作用一般式》《概率作用数理式》《概率作用必然式》：承接 Probability 的当前作用，与本篇资格层分开。

《概率反演式》：承接由结果、频率、干预读出等可观察材料反推 Probability 资格时的可识别范围与不可辨识边界；不得以经验频率直接反推出 Probability。

《概率判定式》：承接实例判定，包括 1、0、⊥ 三值与 RateRead = ⊥ 的处理，以及率承担的操作判据。

《概率极限式》：承接 Probability 在预声明合法比较方向上的资格边界，包括维资格退出、CommonContinuationBind 失效、DomainRelativeRateBearing 失效等边界；不得把零率、RateRead = ⊥、覆盖不完全自动写成 Probability 边界。

《概率源式》：承接概率的来源、首次形成与历史归因。

《概率动力一般式》《概率动力数理式》：承接概率的动力变化，包括新径经沉积取得 Law-bearing 而进入 V\_P、率关系随沉积与环境而变化等。

《概率运行基底构造式》：承接上述资格结构在真实沉积场运行基底中的构造与可运行见证，并与纯数学率装置、外部选择器及经验频率读出相区分。

《概率可达式》：承接从给定合法初态或运行状态到 Probability 目标组织的可达问题；不得以"存在 Probability 构造"代替"该状态可达 Probability"。

《概率稳定式》：承接 Probability 组织的稳定与失稳，包括率状态变化时 Probability 资格的跨时保持问题。

Law identity 问题：不属于本组式本篇，由律体系相应任务承接；本篇结论不依赖其结果。

十八、最后压缩

概率不以预先摆好的可能性空间为本体起点。

以下凡由本篇必要向所得者，均在 H2 成立、并在涉及冗余、协同、备用或多重承载时 H3 亦成立、且 SC\_Hold 成立的条件下读取。

单一续行即使可记率为 1，也未形成独立的概率组织，其资格仍只是律；多出来的一个结果若没有正式 Law-bearing，就还不能取得本篇所要求的概率维资格，只是裸候选；各有 Law-bearing 的维，若不在同一续行位、同一事前申报的生成域、同一次续行生成关系中，只是同时存在或被拼在一起；即使诸维各有 Law-bearing、并共同绑定，若诸维之间的率由申报组织以外决定，这些 Law-bearing 也只是执行结果。

所以，在 H2 成立、并在涉及冗余、协同、备用或多重承载时 H3 亦成立、且 SC\_Hold 成立的条件下：

一份概率一旦在沉积场中成立，它的每一维取得正式 Law-bearing；它的诸维同绑于同一续行位、同一事前申报的生成域、同一次续行生成；它的诸维之间的相对生成关系，在一个事前冻结、非空洞、有系统侧实际根据的率域中，由这份组织本身承担。

而每一次物理执行仍然归一。
