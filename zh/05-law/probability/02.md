# 概率数理式

## 第一节　目的

为概率的三项必要资格建立形式系统，使任一候选概率组织的这三项资格都可以形式求值，并得到成立（1）、不成立（0）或材料不足（⊥）的确定读数。

三项必要资格即《概率一般式》v1.0 所得：

N\_P  
:⇔  
&nbsp;&nbsp;MultiLawDimension\_F,t(𝒫)  
&nbsp;&nbsp;∧ CommonContinuationBind\_F,t(𝒫; C, 𝔯\_P)  
&nbsp;&nbsp;∧ DomainRelativeRateBearing\_F,t(𝒫; C, 𝔯\_P)

分别判定：各维是否取得正式 Law-bearing；诸维是否同一续行位、同一冻结生成域、同一生成关系；诸维之间的相对生成关系是否由该组织承担。

形式目标为：

S\_P ↦ M\_P

## 第二节　核心论题

给定当前沉积场中的候选概率组织 𝒫、续行位 C、事前冻结的率域 𝔯\_P、申报续行维集合 V\_P 与 Law-bearing 登记族 𝓛\_P，怎样从实际 Law 形式见证、续行生成事件、率域评价、生成结构及其来源链中，求得《概率一般式》三个必要职责的形式真值，并严格区分结构失败 0 与形式材料不足 ⊥？

S\_P 的结构分三层：维资格层（哪些方向有资格成为概率维）、共同绑定层（这些维凭什么属于同一续行率问题）、率承担层（这一共同续行问题中的相对生成由谁承担）。三层依次引用前层已取得的对象。

M\_P 须精确表达：

(1) 维资格：每一申报维须有上游 Law 形式解承担，且诸维在申报分辨协议下互斥可分；

(2) 共同绑定：同一续行位、同一冻结生成制度、同一生成关系的互斥后继；

(3) 率承担：在冻结、非空、非空洞、有系统侧根据的率域中，相对生成关系可形式表示，并由申报组织的实际生成贡献承担。

须在形式上区分下列五组对象：

OutcomeBearing ≠ RateBearing

StableFrequency ≠ Rel\_ρ

RateRead ≠ 资格

ρ(v\_i) = 0 ≠ v\_i ∉ V\_P

V\_P 内归一 ≠ FullCoverage

形式方向分正向回读 M ⇒ S 与反向表示 S ⇒ M，二者强度不同（第七节）。

### 3.1 求解实例

定义 3.1 \[S\]

χ\_P = (F, t, 𝒫, C, 𝔯\_P, V\_P, 𝓛\_P)

F 为当前沉积场；t 为当前时刻；𝒫 为候选概率组织；C 为申报续行位；𝔯\_P 为事前申报率域；V\_P 为申报续行维集合；𝓛\_P 为申报的 Law-bearing 登记族，其元素记为 W\_i = (L\_i, v\_i, C\_i)。

χ\_P 只是已有结构参数的求解登记，不是新本体对象。V\_P、𝓛\_P、C、𝔯\_P 须在求解前给定，不得事后增删。

### 3.2 上游 Law 形式解

定义 3.2 \[承\]

对 L\_i 及其适用域 I\_i，调用《律数理式》的形式解集：

𝒮(F, L\_i, I\_i) = { R ⊆ Existing\_t \| EstWitness^M ∧ Govern^M }

不重建 Established、DynamicRole、ΩSupport 的形式判据，也不修改其量词极性与适用覆盖守卫域。

### 3.3 维兑现

定义 3.3 \[S\]

对续行位 C，记 Y\_C 为后继签名空间：在本次申报分辨协议下，足以判断续行后继身份的签名空间。它不一定等于完整的场状态空间。续行生成事件 e 的实际后继签名为 Succ(e) ∈ Y\_C。因此下文 D\_i ∩ D\_j = ∅ 只表示申报维在所用分辨协议下可区分，不要求两种后继在一切物理坐标上毫无重叠。对每一 v\_i ∈ V\_P，申报运行可判的后继识别域：

D\_i ⊆ Y\_C，D\_i ≠ ∅

定义：

Realize^M(e, v\_i) = 𝟏\_{D\_i}(Succ(e))

要求在申报分辨协议下：

i ≠ j ⇒ D\_i ∩ D\_j = ∅

不要求：

⋃\_i D\_i = Y\_C

后继落在 ⋃\_i D\_i 之外的事件，不属于任何申报维；这不是任何维的失败，也不构成新维。

### 3.4 BearDim

定义 3.4 \[S\]

BearDim^M(L\_i, v\_i; C\_i, R\_i) = 1，当且仅当：

(a) R\_i ∈ 𝒮(F, L\_i, I\_i)；

(b) DimGenBind^M(L\_i, v\_i; C\_i, R\_i) = 1。

DimGenBind^M 为压缩名，展开为：存在同一职责 d ∈ O(Rel(L\_i)) 与该职责在 R\_i 中的合法实现 Π，使

(b1) 按《律数理式》，RoleReal^M(d, R\_i, Π) = 1；

(b2) Π 的实际职责生成链在续行位 C\_i 处进入后继生成；

(b3) Π 所承担的后继方向，由兑现域 D\_i（定义 3.3）识别为 v\_i。

本定义不要求职责的读出 Read(d) 本身落在 D\_i 之内：一个真实生成该维、但其读出描述处在另一层级的 Law 职责，不因此被排除。要求的是同一职责实现的生成链承担了 v\_i 所对应的后继方向。

(a) 或 (b1)—(b3) 任一项完整求值后失败，取 0；上游 Law 形式解、职责实现或生成链不可判，取 ⊥。

### 3.5 Dist

定义 3.5 \[S\]

Dist^M(v\_i, v\_j) = 1，当两个申报维在申报运行分辨率下具有互斥的后继兑现域：D\_i ∩ D\_j = ∅；D\_i ∩ D\_j ≠ ∅ 时取 0；在申报分辨率下交集不可判时取 ⊥。

标签不同、名称不同，不构成 Dist。

### 3.6 维资格

定义 3.6 \[S\]

维见证纤维：

𝒲\_Dim(v\_i) = { (L\_i, C\_i, R\_i) \| R\_i ∈ 𝒮(F, L\_i, I\_i) ∧ BearDim^M(L\_i, v\_i; C\_i, R\_i) = 1 }

DimQual^M(v\_i) =  
&nbsp;&nbsp;1，𝒲\_Dim(v\_i) ≠ ∅；  
&nbsp;&nbsp;0，求解完整且纤维为空；  
&nbsp;&nbsp;⊥，上游 Law 或 BearDim 材料不足。

𝓛\_P 中登记的每一 W\_i，均须在 𝒲\_Dim(v\_i) 中有对应元素；一维可有多个见证，不要求唯一。某一登记 W\_i 经完整求值后无对应元素，则 𝓛\_P 不合《概率一般式》对登记族的定义，DimCover^M 记 0；须重新申报 𝓛\_P，不得在求解中删去该登记。

### 3.7 MultiLawDimension

定义 3.7 \[S\]

Card^M = 1 ⇔ \|V\_P\| ≥ 2；V\_P 不可有效列举时取 ⊥。

DistAll^M = ∧₃\_{i≠j} Dist^M(v\_i, v\_j)

DimCover^M = ∧₃\_{v\_i ∈ V\_P} DimQual^M(v\_i) ∧₃ RegValid^M

RegValid^M = ∧₃\_{W\_i ∈ 𝓛\_P} \[ 𝒲\_Dim(v\_i) 中存在 L 与 C 分别同于 L\_i、C\_i 的元素 \]

MultiLawDimension^M = Card^M ∧₃ DistAll^M ∧₃ DimCover^M

### 3.8 率域登记

定义 3.8 \[S\]

𝔯\_P^M = (Γ\_r, τ\_0, ℰ\_r)

Γ\_r 为事前冻结的率域成员规则；τ\_0 为冻结时点或协议版本；ℰ\_r 为 F 中可作资格评价见证的合法生成/再入实现集，包括当前实际运行实现，以及依冻结协议取得的合法再入或复走实现；不包括纯分析者假设、未落入系统生成机制的反事实赋值。定义 3.27 的评价内实现 e\_ν 均属于 ℰ\_r。AdmVar\_ρ 是诊断变化域，不混入 ℰ\_r。

InRateDomain^M(e) = Γ\_r(e) ∈ {1, 0, ⊥}

一个"同一次续行生成事件"，指 ℰ\_r 中一次合法再入 C 所引起的续行生成，不是 Γ\_r 内按条件再细分出的子情形（承《概率一般式》第七节口径）。每一事件带事件身份 e\_k。下文"续行生成事件"或"事件"均指 ℰ\_r 中的一次合法生成/再入实现，与"实现"同指；测度意义上的可测集合不称"事件"。

### 3.9 Frozen

定义 3.9 \[S\]

Frozen^M = 1，当且仅当 Γ\_r 与共同生成关系身份 g\_C（定义 3.13）有可检查的冻结记录（真实协议版本、冻结记录或等价机制），其冻结点 τ\_0 先于一切用于承重的实现读出与率评价，且在 τ\_0 之后二者均未被修改。冻结记录不可得时取 ⊥；可得而显示事后修改时取 0。

### 3.10 NoCrossConditionStitch

定义 3.10 \[S\]

每一承重记录 x（用于承重的事件读出、维见证或率评价）须带其所属的率域协议标识 DomainProtocol(x) 与证据时点 EvidenceTime(x)。

NoCrossConditionStitch^M = 1，当且仅当所有承重记录 x 均满足：

DomainProtocol(x) = Γ\_r

FreezeTime(Γ\_r) = τ\_0 \< EvidenceTime(x)

若存在两个承重记录 x、y，使 DomainProtocol(x) = Γ\_a、DomainProtocol(y) = Γ\_b、Γ\_a ≠ Γ\_b，而当前申报域只能由二者事后合并形成，则 NoCrossConditionStitch^M = 0。协议标识或证据时点不可取得时取 ⊥。

不同微条件 a、b，若在 τ\_0 时已作为同一 Γ\_r 的合法变化登记，其记录的 DomainProtocol 均为 Γ\_r，不构成拼接。本判据判断的是同一冻结生成制度，不要求底层变量字面相等。

### 3.11 SameContinuationPosition

定义 3.11 \[S\]

SameContinuationPosition^M = 1，当且仅当对 𝓛\_P 中每一登记 W\_i = (L\_i, v\_i, C\_i) 均有 C\_i = C。

不另造位置等价算子；C\_i 与 C 的同一，按场系统对续行位的身份判定读取，不可判时取 ⊥。

### 3.12 SameGenerationDomain

定义 3.12 \[S\]

SameGenerationDomain^M = 1，当且仅当：

(a) 所有用于承重的事件、维见证与率评价，均满足 InRateDomain^M = 1，且属于同一个 Γ\_r；

(b) NoCrossConditionStitch^M = 1。

### 3.13 SameGenerationRelation

定义 3.13 \[S\]

对 C 处合法续行生成事件 e，底层运行系统须提供其生成关系身份：

GenSchema(e)

GenSchema 是场系统或运行基底对实际生成根、生成图式或等价生成关系身份的读取，不是新增的本体对象。申报实例预先登记共同生成关系身份 g\_C，与 Γ\_r 同时冻结。

SameGenSchema^M = 1，当且仅当所有用于申报诸维及率关系求值的合法续行生成实现 e ∈ ℰ\_r 均满足：

GenSchema(e) = g\_C

若明确存在两个实现分别属于 g\_a ≠ g\_b，而只有把二者的后继拼在一起才能形成 V\_P，则 SameGenSchema^M = 0。生成关系身份不可取得时取 ⊥。

MutualSuccessor^M = 1，当且仅当：

(一) 各 D\_i 均为同一 g\_C 在 C 处的合法可区分后继域；

(二) 对每一属于 g\_C、且用于资格评价的合法续行生成实现 e\_k ∈ ℰ\_r：

Σ\_{i=1}^{\|V\_P\|} Realize^M(e\_k, v\_i) ≤ 1

不写成 = 1：不要求每一次实际后继都落入 V\_P，不推出 FullCoverage。同一事件同时兑现两维，则 (二) 为 0；事件身份或后继归属不可判时取 ⊥。

SameGenerationRelation^M = SameGenSchema^M ∧₃ MutualSuccessor^M

SameGenSchema 负责排除不同生成过程的拼接；MutualSuccessor 负责同一生成关系内部的互斥后继归属。二者不得互相替代：两个各自只兑现一维的独立生成过程，满足互斥不等式而 SameGenSchema 失败；同一生成关系中同一事件同时兑现两维，SameGenSchema 成立而 MutualSuccessor 失败。

### 3.14 CommonContinuationBind

定义 3.14 \[S\]

CommonContinuationBind^M = SameContinuationPosition^M ∧₃ SameGenerationDomain^M ∧₃ SameGenerationRelation^M

它不是新的绑定实体，只是《概率一般式》三项绑定纪律的形式合取。

### 3.15 率域评价与外层量词模式

定义 3.15 \[辅\]

Eval(𝔯\_P) 为率域上的合法评价族：每一评价 ν 是 Γ\_r 所许可的一种合法生成配置（输入状态、环境扰动、场内状态等）。

DomainEvalMode(𝔯\_P) ∈ {set, measure}

它只决定整个率域上的量词如何求值：set 模式用普通全称/存在；measure 模式在合法评价测度 μ\_r 下用 a.e. 全称与正测度存在。measure 模式下，零测异常不得自动击穿全称覆盖；单个零测成功点也不得建立存在型结论。

μ\_r 只作用于 Eval(𝔯\_P) 上的外层评价量词；它与 weight 模式中的生成测度 μ\_{C,ν}（定义 3.18）为不同对象，除非底层系统另有合法映射，不得互换或相互推出。

### 3.16 相对生成表示模式

定义 3.16 \[辅\]

对每一评价 ν：

RelRepMode(ν) ∈ {struct, weight}

它只决定单个评价上 Rel\_ρ 如何表示。DomainEvalMode 与 RelRepMode 两轴互不推出。

### 3.17 struct 表示

定义 3.17 \[辅\]

若底层只能结构性地给出相对生成关系，则取 R\_ν^struct，并须至少提供跨评价同关系比较：

EqRel\_ρ^M(R\_ν, R\_ν′) ∈ {1, 0, ⊥}

只有"存在某结构关系"的描述而不能比较不同合法配置下关系是否相同的实例，其 struct 表示不可用于率承担求解，相关项取 ⊥。

### 3.18 weight 表示

定义 3.18 \[辅\]

若底层在评价 ν 下提供合法的非负有限生成权重或生成测度 μ\_{C,ν}（定义在 Y\_C 上），取：

w\_i(ν) = μ\_{C,ν}(D\_i)

w\_V(ν) = (w\_1(ν), …, w\_n(ν))

正比例等价：

w ∼\_ρ w′ ⇔ ∃a \> 0：w′ = a·w

保留零类 \[0\]\_ρ。

不设 Σ\_i w\_i \> 0 为任何资格条件。

### 3.19 Rel\_ρ

定义 3.19 \[S\]

Rel\_ρ^M(ν) =  
&nbsp;&nbsp;R\_ν^struct，RelRepMode(ν) = struct；  
&nbsp;&nbsp;\[w\_V(ν)\]\_∼ρ，RelRepMode(ν) = weight。

Rel\_ρ^M 是生成侧的相对生成关系表示，不以经验频率 ρ̂\_N 替代。

### 3.20 条件率与完整率

定义 3.20 \[辅\]

若 Σ\_j w\_j \> 0，定义 V\_P 内部条件率：

ρ\_i^cond = w\_i / Σ\_j w\_j

若底层完整后继生成质量 M\_C = μ\_{C,ν}(Y\_C) \> 0 可得，才定义完整率：

ρ\_i^full = w\_i / M\_C

此时 Σ\_i ρ\_i^full ≤ 1。

Σ\_i ρ\_i^cond = 1 只是 V\_P 内部条件化的结果，不读作 FullCoverage。M\_C − Σ\_i w\_i 为 V\_P 外残余质量，不得自动补成"未知维""停止维"或其他概率维。

### 3.21 旧 Pr(q,t) 桥

定义 3.21 \[辅\]

只有当母本旧 Pr(q,t) 在当前实现中确属生成侧的率读出，且存在合法投影：

π\_V：q ↦ v\_i

时，才允许：

w\_i = Σ\_{π\_V(q) = v\_i} Pr(q,t)

并由此进入 Rel\_ρ^M。

不得写 Probability = Pr；不得把母本 Σ Pr(q,t) ≤ Λ(t) 改作归一公理。

### 3.22 率生成因子域

定义 3.22 \[辅\]

A\_ρ^gen(ν) 为评价 ν 下，该评价的局部生成机制中有资格进入 Rel\_ρ 承担分析的实际生成因子域。其元素可以是：输入状态、生成节点、门控、掩码、Avail、Law-bearing 实现在该评价中的状态，以及与率形成直接相关的结构参数。

必须排除：只与结果统计相关的变量；生成决定完成后才执行结果的节点；观察者事后频率；没有生成来源链的相关量。

a ∈ A\_ρ^gen(ν) 不推出 a 承担率。冷备用可以进入候选域，但在其未接管的评价中不承担。

### 3.23 Law 见证到生成因子的映射

定义 3.23 \[辅\]

对 W\_i ∈ 𝓛\_P：

GenIn(W\_i, ν) ⊆ A\_ρ^gen(ν)

为 W\_i 所对应的 Law 形式解 R\_i 在评价 ν 下实际实现为的生成因子集。它必须依据真实生成来源链取得，不得依据同宿主、同变量名、同值或统计相关；并须保留同一 R\_i、e、C、𝔯\_P、ν。

### 3.24 合法职责诊断变化族

定义 3.24 \[辅\]

AdmVar\_ρ(ν) 为判断率承担所允许的形式诊断变化族。它不是 𝔯\_P 本身：𝔯\_P 是 Probability 申报成立的真实生成/再入域；AdmVar\_ρ 是为判断率承担而许可的诊断变化。

变化时须冻结：C、Γ\_r、V\_P、{D\_i}、g\_C 以及生成事件的结构图式。

允许合法改变：生成输入、门控、掩码、Avail、合法冗余实现，以及场系统本身许可变化的其他生成因子。不得作任意数学赋值。

### 3.25 相对生成关系比较

定义 3.25 \[辅\]

struct 模式：

d\_ρ(R, R′) = 0，EqRel\_ρ = 1；1，EqRel\_ρ = 0；⊥，EqRel\_ρ = ⊥。

weight 模式：非零类取规范代表 w̄ = w / ‖w‖₁，并取总变差距离：

d\_ρ(\[w\], \[w′\]) = TV(w̄, w̄′)

另定义 d\_ρ(\[0\], \[0\]) = 0；d\_ρ(\[0\], \[w\]) = 1（w ≠ 0）。

ε\_ρ ≥ 0 为申报比较分辨度。struct 与 weight 混合评价须比较时，须有合法投影到共同表示（M8），否则相关比较为 ⊥。

d\_ρ、ε\_ρ、w̄ 均为纯形式辅助量。

### 3.26 极小充分率生成组

定义 3.26 \[辅\]

对 B ⊆ A\_ρ^gen(ν)，若对全部合法 ν′, ν″ ∈ AdmVar\_ρ(ν)，只要 ν′ 与 ν″ 在 B 上一致，就有：

d\_ρ( Rel\_ρ^M(ν′), Rel\_ρ^M(ν″) ) ≤ ε\_ρ

则称 B 为充分率生成组。

MinSuff\_ρ(ν) 为全部包含意义下极小（inclusion-minimal）的充分组之族。不取最小基数，不要求唯一。

由此允许热冗余：MinSuff\_ρ = {{A}, {B}}；冷备用在该评价中的族只应为 {{A}}，不把 B 误收为该评价的承担者。

### 3.27 评价内率生成绑定

定义 3.27 \[辅\]

属于某一极小充分组，只取得率承担的形式资格候选；它本身不说明现实时间 t 当前正在发生 ProbabilityAct。

对合法评价 ν，取该评价内部的合法生成实现 e\_ν。它可以来自当前运行评价，也可以来自符合资格协议的合法再入或复走评价；不要求现实时间 t 正有该事件发生。

对 Law 见证 W\_i、评价内实际生成贡献 c\_i、评价内生成子段 Z\_i^ρ 与实现 e\_ν，取绑定键：

β\_ρ = (W\_i, c\_i, Z\_i^ρ, e\_ν, C, 𝔯\_P, ν)

EvalRateBind^M(W\_i, ν, e\_ν) = 1，当且仅当下列四项同时成立：

B1 来源同一：c\_i 来自同一个 W\_i 所对应的合法 Law 实现；

B2 生成进入：c\_i 在该评价的实现中实际进入 Rel\_ρ^M(ν) 的形成；

B3 同一实现：c\_i、Z\_i^ρ、Rel\_ρ^M(ν) 与相应的后继生成均属于同一个 e\_ν；

B4 同域同评价：以上均属于同一 C、𝔯\_P、ν。

任一项完整求值后失败取 0；评价内合法实现或来源链不可取得取 ⊥。

EvalRateBind^M 只是 B1—B4 的压缩名，可完全展开消除，不是第四个本体层。它只保证资格评价中的同见证闭合，不定义 ProbabilityAct；现实当前事件是否正在兑现 Probability 的作用，由《概率作用数理式》另行判断。

### 3.28 RateBearWitness

定义 3.28 \[S\]

RateBearWitness^M(ν) = 1，当且仅当存在 B ∈ MinSuff\_ρ(ν)、W\_i ∈ 𝓛\_P 与评价内实现 e\_ν，使：

B ∩ GenIn(W\_i, ν) ≠ ∅

且：

EvalRateBind^M(W\_i, ν, e\_ν) = 1

这里取得的是评价 ν 中的率承担资格，不等同于现实当前的 ProbabilityAct。

取存在极性：不要求每一极小充分组都包含申报组织的生成因子。因此允许另一套完全外部的冗余机制存在，只要该评价内的实现确由申报组织承担。反之，若在该评价中申报组织的机制只是备用，实现完全由外部机制承担，则 RateBearWitness^M(ν) = 0。

整个率域上的资格聚合：

RateBearWitness^M\_{𝔯\_P} = ∀^{mode}\_{ν ∈ Eval(𝔯\_P)} RateBearWitness^M(ν)

其中 ∀^{mode} 按 DomainEvalMode 取 set 全称或 measure 下 a.e. 全称。

### 3.29 RateDomainQual

定义 3.29 \[S\]

RateDomainQual^M = Frozen^M ∧₃ NonEmpty^M ∧₃ NonVacuous^M ∧₃ Grounded^M ∧₃ NoCrossConditionStitch^M

NonEmpty^M：率域协议层存在至少一个合法配置，Eval(𝔯\_P) ≠ ∅。

NonVacuous^M：其中至少一个合法配置具有可实现的系统生成/再入实现，而不是纯形式条件描述；measure 模式下，具有系统生成实现的配置集在 μ\_r 下质量为正。

Grounded^M：该实现的生成来源属于 F 的合法生成机制，而不是观察者按结果、频率或未知性切出的样本集合。

三者依次为：域不空、可实现、有系统内生根据。

NoCrossConditionStitch^M 与定义 3.10 共用同一判据，不另造。

RateDomainQual^M 不是新增顶层职责，只是 DomainRelativeRateBearing 域部分的形式化。

### 3.30 RelForm

定义 3.30 \[S\]

RelForm^M = 1，当且仅当：对 Eval(𝔯\_P) 中（按 DomainEvalMode 聚合的）各评价，struct 或 weight 至少一种合法表示可形成；率承担求解所需的跨评价同关系比较可判；且 Rel\_ρ^M 取自生成侧，不以经验频率替代。

### 3.31 DomainRelativeRateBearing

定义 3.31 \[S\]

DomainRelativeRateBearing^M = RateDomainQual^M ∧₃ RelForm^M ∧₃ RateBearWitness^M\_{𝔯\_P}

### 3.32 形式总读数

定义 3.32 \[S\]

M\_1^P := MultiLawDimension^M

M\_2^P := CommonContinuationBind^M

M\_3^P := DomainRelativeRateBearing^M

Read\_{N\_P}^M = M\_1^P ∧₃ M\_2^P ∧₃ M\_3^P

### 3.33 关系性质申明

Dist^M：非自反（D\_i ≠ ∅，故 Dist(v\_i, v\_i) = 0）；对称；一般不传递；不是偏序或全序。

∼\_ρ：等价关系（自反、对称、传递）。

d\_ρ：在 weight 模式的非零正比例等价类上为度量（每一类有唯一的 ℓ₁ 归一代表，总变差在其上为度量）；对零类采用约定扩张。struct 模式下只作三值同异比较，不申报度量性质。

GenIn：W\_i 到生成因子集的映射，多对多；对 ν 不申报单调性。

MinSuff\_ρ：包含意义下的反链；不要求唯一元素。

Realize^M：事件到 {0,1} 的指示；在 MutualSuccessor 成立时，同一事件对不同维的指示和 ≤ 1。

生成关系身份同一关系 GenSchema(e) = GenSchema(e′)：为等价关系（自反、对称、传递）；GenSchema(e) = g\_C 是固定 g\_C 后的一元谓词。

续行位身份同一关系（C\_i = C 为其实例）：按场系统续行位身份判定，为等价关系（自反、对称、传递）。

⊆：偏序。

## 第四节　方程与静力关系

### 4.1 静力关系

这里不是动力问题，不设微分方程。承重关系只有四条：

(P-E1) 维兑现

Realize^M(e, v\_i) = 𝟏\_{D\_i}(Succ(e))

(P-E2) 同次互斥

Σ\_i Realize^M(e, v\_i) ≤ 1

(P-E3) weight 分支投影

w\_i(ν) = μ\_{C,ν}(D\_i)

Rel\_ρ^M(ν) = \[w\_V(ν)\]\_∼ρ

struct 分支不强制写数值方程。

(P-E4) 三值合成

Read\_{N\_P}^M = MultiLawDimension^M ∧₃ CommonContinuationBind^M ∧₃ DomainRelativeRateBearing^M

以下不得写作资格方程：

Σ\_i p\_i = 1

Probability = f(ρ)

Rel\_ρ = ρ̂\_N

RateBearing ⇔ ∂ρ/∂L\_i ≠ 0

最后一式会把冗余承担与固定比例承担错判为不承担。

### 4.2 形式性质

命题 4.1　SameGenerationRelation^M 不推出 FullCoverage。

证：取 V\_P = {v\_1, v\_2}，Y\_C = D\_1 ∪ D\_2 ∪ D\_out，三者两两不交且 D\_out ≠ ∅。令事件 e 满足 Succ(e) ∈ D\_out，则 Σ\_i Realize^M(e, v\_i) = 0 ≤ 1，(P-E2) 成立，而 ⋃\_i D\_i ≠ Y\_C。□

命题 4.2　∼\_ρ 为等价关系，Rel\_ρ^M 在 weight 模式下良定。

证：a = 1 得自反；w′ = a·w 则 w = a⁻¹·w′ 得对称；w′ = a·w、w″ = b·w′ 则 w″ = (ab)·w 得传递。零向量只与自身等价，故 \[0\]\_ρ 为单独一类。□

命题 4.3　Σ\_j w\_j \> 0 时 Σ\_i ρ\_i^cond = 1；M\_C \> 0 时 Σ\_i ρ\_i^full = Σ\_i w\_i / M\_C ≤ 1，等号当且仅当 V\_P 外残余质量为零。

证：由定义 3.20 及 D\_i 两两不交、Σ\_i w\_i = μ\_{C,ν}(⋃\_i D\_i) ≤ μ\_{C,ν}(Y\_C) 直接得出。□

命题 4.4　某维当前权重为零，不改变其维资格读数。

证：DimQual^M(v\_i) 只依赖 𝒲\_Dim(v\_i)（定义 3.6），不含 w\_i。w\_i = 0 只使 Rel\_ρ^M 取相应的类。□

命题 4.5　MinSuff\_ρ 成员资格不推出 RateBearWitness^M。

证：取内部机制 I 与外部机制 M 各自独立足以维持同一 Rel\_ρ，则 MinSuff\_ρ = {{I}, {M}}。若在评价 ν 中实现由 M 承担、I 只备用，则 I 的贡献不进入该评价实现的生成链，B2 失败，EvalRateBind^M = 0；M 不在 GenIn(W\_i, ν) 中，故 RateBearWitness^M(ν) = 0。□

## 第五节　运行与求解

### 5.1 求解顺序

求解顺序固定为：

MultiLawDimension^M → CommonContinuationBind^M → DomainRelativeRateBearing^M

后项引用前项已取得的维与共同生成关系。前项已明确为 0 时，可停止下游求解，后项不求值；按 ∧₃，总读数取 0。

1\. 校验 χ\_P 登记（M1）。

2\. 对每一 v\_i，调用《律数理式》求 𝒮(F, L\_i, I\_i)，判 BearDim^M，得 𝒲\_Dim(v\_i)（M2）。

3\. 求 Card^M、Dist^M、DimQual^M 与 RegValid^M，得 MultiLawDimension^M（M3）。

4\. 核对 𝓛\_P 中所有 C\_i = C，得 SameContinuationPosition^M。

5\. 读取冻结记录，判 Frozen^M（M5）。

6\. 由 Γ\_r 与 ℰ\_r 生成合法 Eval(𝔯\_P)，确定 DomainEvalMode（M6、M15）。

7\. 读取各承重记录的 DomainProtocol 与 EvidenceTime，判 NoCrossConditionStitch^M 与 InRateDomain^M，得 SameGenerationDomain^M。

8\. 按生成关系身份判 SameGenSchema^M，按事件身份判 (P-E2) 得 MutualSuccessor^M，合成 SameGenerationRelation^M（M4）。

9\. 签 CommonContinuationBind^M。

10\. 判 NonEmpty^M、NonVacuous^M、Grounded^M，得 RateDomainQual^M。

11\. 对各评价确定 RelRepMode(ν)。

12\. 形成 Rel\_ρ^M(ν)，判 RelForm^M（M7、M8）。

13\. 取得 A\_ρ^gen(ν)（M9）。

14\. 求 GenIn(W\_i, ν)（M10）。

15\. 构造 AdmVar\_ρ(ν)（M11）。

16\. 核 Sound\_Adm 与 Cover\_Adm（M11）；二者均为 1 时，用 d\_ρ 与 ε\_ρ 求全部 MinSuff\_ρ(ν)（M12、M13）；否则 MinSuff\_ρ(ν) 记 ⊥。

17\. 对各评价的评价内实现 e\_ν 检查 β\_ρ 与 B1—B4（M14）。

18\. 求 RateBearWitness^M(ν)。

19\. 按 DomainEvalMode 聚合整个 𝔯\_P，得 RateBearWitness^M\_{𝔯\_P}。

20\. 签 DomainRelativeRateBearing^M，合成 Read\_{N\_P}^M。

### 5.2 三值与负读出守卫

1：明确成立。

0：完整求值后明确失败。

⊥：当前合法形式输入不足。

合取按 ∧₃；量词按第三节三值量词规则。任何负读出 0 必须带有对应层的求解完整性依据；缺证据不写 0。

### 5.3 可解性条件

以下 M1—M16 是形式表示与求解条件，不是 Probability 的新增必要结构，也不是 H。任一 Mi 缺失，只使依赖该条件的形式项取 ⊥，不自动把 N\_P 或 Probability 判为 0。

M1 申报对象完整可识别：F、t、𝒫、C、𝔯\_P、V\_P、𝓛\_P 均可有效引用。

M2 上游 Law 形式接口可用：各申报维所需的 Law 形式解、职责分解、职责实现 RoleReal 及其生成链可判。

M3 维兑现规则可执行：每一 D\_i 可有效判断后继归属。

M4 生成事件身份可追踪：事件身份及其后继签名、输入、事件归属可判；生成关系身份 GenSchema(e) 可读取。

M5 率域冻结与成员规则可判：Γ\_r、τ\_0、g\_C 及版本一致性可判；承重记录的 DomainProtocol 与 EvidenceTime 可取得。

M6 率域系统侧根据可判：率域实现的生成来源可追踪，NonVacuous^M 与 Grounded^M 可求值。根据不可追踪时二者取 ⊥；可追踪而明确无系统侧根据时，Grounded^M 取 0，属结构失败，不属本条件缺失。

M7 Rel\_ρ 表示接口可用：struct 至少有可执行的同关系比较；weight 至少有合法生成权重或测度。

M8 跨表示模式桥可判：struct 与 weight 混合评价须比较时，能合法投影到共同表示；否则相关比较为 ⊥。

M9 率生成因子域可求：A\_ρ^gen(ν) 能从真实生成结构中取得。

M10 生成来源链可追踪：GenIn(W\_i, ν) 由真实生成链取得。

M11 合法诊断变化族忠实可刻画：AdmVar\_ρ(ν) 对当前冻结的合法职责诊断变化域具有两向忠实性。

Sound\_Adm = 1：其中每一变化均由场系统许可，并保持 C、Γ\_r、V\_P、{D\_i}、g\_C 及已冻结的生成图式；不含违反场系统、冻结协议或生成图式的变化。

Cover\_Adm = 1：在 C、Γ\_r、V\_P、{D\_i}、g\_C 及冻结生成图式保持不变的条件下，场系统所许可、且能够改变 A\_ρ^gen(ν) 中生成因子的取值、可用性、合法实现或 Rel\_ρ 形成结果的诊断变化，均被 AdmVar\_ρ(ν) 收入，或由申报分辨度下等价的代表覆盖。覆盖域由场系统的合法变化域给出，不由最终率承担判定倒推。遗漏这类变化，会使 MinSuff\_ρ 误判充分性：某组 B 被判为充分，仅因能使其不充分的合法变化未被收入。

合法性或覆盖性不可判时，依赖 MinSuff\_ρ 的结果为 ⊥。Sound\_Adm = 0 或 Cover\_Adm = 0 已明确时，该求解是形式协议失真，不获准签 1 或 0，MinSuff\_ρ 及依赖它的各项记 ⊥；不得写成 DomainRelativeRateBearing^M = 0，因为这不是结构事实的失败。

M12 相对生成关系比较可判：d\_ρ 或等价判据可计算到申报分辨度。

M13 极小充分组可求：有限域可枚举；无限域中若极小组的存在性或可求性不能保证，相关量为 ⊥。

M14 评价内同见证绑定可判：各评价的合法实现 e\_ν 可取得，B1—B4 可核。

M15 率域外层量词模式可定：set/measure 可确定；measure 模式下相关集合可测或可有效逼近。

M16 三值与负读出完整性可执行：任何 0 均有完整求解依据。

### 5.4 解

Read\_{N\_P}^M = 1 为 M\_P 的形式解。Read\_{N\_P}^M = 0 表示在完整求值下某一职责的形式判据失败。Read\_{N\_P}^M = ⊥ 表示形式材料不足，不得读作 N\_P 失败，更不得读作 Probability 不成立。

## 第六节　耦合关系

### 6.1 与《概率一般式》

M\_P 只形式化 N\_P，逐分量对应见 3.0。不新增第四必要职责；M1—M16、\[辅\] 对象与 MinSuff\_ρ 均不回读为 Probability 的本体组成。

### 6.2 与《律数理式》

Law 形式解、Established、DynamicRole、ΩSupport、Rel(L) 的职责分解，全部沿用上游。Probability 没有第二套 Law 本体。DynamicRole 的冗余处理以上游为准；MinSuff\_ρ 只用于率承担，不替代 DynamicRole^M。

### 6.3 与场数理系统

后继签名空间、生成节点与路径、掩码、Avail、状态、权重、生成核、合法生成实现，均须来自场系统或合法运行基底。M\_P 不另建物理生成系统，也不设抽象统一生成算子；具体实现提供生成核、确定函数、流分配、门控网络或场内生成结构中的哪一种，就引用哪一种。

### 6.4 与母本旧 Pr(q,t)

只经定义 3.21 的桥进入 Rel\_ρ^M。不写 Probability = Pr；不把 Σ Pr(q,t) ≤ Λ(t) 改作归一公理。

### 6.5 与《概率必然式》

交出 N\_P^M 及其形式证书。N\_P ⇒ Probability 由《概率必然式》负责。

### 6.6 与《概率作用一般式》《概率作用数理式》《概率作用必然式》

交出 V\_P、𝓛\_P、当前 Rel\_ρ^M、率承担见证与生成来源链接口。不交 ProbabilityAct。

### 6.7 与《概率动力一般式》《概率动力数理式》

交出当前快照 M\_P(t)。不研究 M\_P(t\_0) → M\_P(t\_1) 的变化原因。

### 6.8 与《概率运行基底构造式》

最低实现接口须能提供：Law 见证登记、维登记、续行位身份、冻结率域协议（含 domain\_protocol\_id 与冻结时点）、生成事件身份、生成关系身份 GenSchema、后继签名、生成因子域、生成来源链、相对生成表示。若启用 measure 型 DomainEvalMode，须提供合法的评价测度 μ\_r；若启用 weight 型 RelRepMode，须提供生成权重或生成测度 μ\_{C,ν}。缺少任一项，运行基底不能声称完整实现 M\_P。

## 第七节　回读规则

### 7.1 证据三层

第一层，数学形式事实：如 D\_i ∩ D\_j = ∅、w ∼\_ρ w′、B ∈ MinSuff\_ρ。只读回对应的数学事实。

第二层，场内实际生成事实：如 GenIn(W\_i, ν)、EvalRateBind^M。说明某份合法 Law 见证的生成因子实际进入同一相对生成的形成。

第三层，一般式结构回读：见 7.2。

### 7.2 正向回读 M ⇒ S

方括号内为该箭头所携条件。

(7.1) DimQual^M(v\_i) = 1 ⇒ v\_i 取得正式 Law-bearing，即存在 L\_i、I\_i、C\_i，使 Law\_F,t(L\_i, I\_i) = 1 ∧ BearDim\_F,t(L\_i, v\_i; C\_i)  
\[H\_LawRead(W\_i)\]

H\_LawRead(W\_i) 为：该见证（𝓛\_P 中的登记，或 𝒲\_Dim(v\_i) 中用于回读的元素）所引用的上游 Law 资格，按其实际来源与当前引用版本所携带的全部有效成立或回读前件。具体地：

若 W\_i 由当前《律数理式》形式解即时回读而来，承继那条回读箭头实际携带的条件，再经《律必然式》充分向取得 Law，该步不增条件；

若 W\_i 引用的是已经建立的 Law 结构事实，只承继该事实本身的现行条件。

不复制、不冻结上游内部的回读条件名单；上游升版时，H\_LawRead(W\_i) 随其当前引用版本读取。各 W\_i 按其自身来源逐一承继，不跨维机械合并。

其中 BearDim 部分的回读，由下述定理给出，不另立条件。

定理 7.1　维承担回读

若 BearDim^M(L\_i, v\_i; C\_i, R\_i) = 1，则 L\_i 所承担的关系内容，正是续行位 C\_i 处续行到 v\_i 这一后继关系，即结构层 BearDim\_F,t(L\_i, v\_i; C\_i) 成立。

证：由定义 3.4，存在同一职责 d ∈ O(Rel(L\_i)) 与其在 R\_i 中的合法实现 Π，满足 (b1)—(b3)。d 为 Rel(L\_i) 的职责，由定义直接给出；(b1) 给出 d 在 R\_i 中得到实现；(b2) 给出这份实现的职责生成链在 C\_i 处进入后继生成，故 d 所承担的是 C\_i 处的续行；(b3) 给出该续行的后继方向在申报分辨协议下被 D\_i 识别为 v\_i。d 属于 Rel(L\_i)，故 Rel(L\_i) 所承担的关系内容中含 C\_i 处续行到 v\_i 的后继关系，即结构层 BearDim 的含义。L\_i 的 Law 资格部分由 (a) 与 H\_LawRead(W\_i) 取得。□

(7.2) MultiLawDimension^M = 1 ⇒ MultiLawDimension = 1  
\[用于 DimCover 的各见证之 H\_LawRead 的合取\]

Card^M 与 Dist^M 的回读依定义 3.5、3.7 与 S 分量同义，不另携条件。

(7.3) CommonContinuationBind^M = 1 ⇒ CommonContinuationBind = 1  
\[本箭头不新增条件；其所量化的 𝓛\_P 登记之 Law 资格，按 (7.1) 各自携带\]

SameContinuationPosition^M、SameGenerationDomain^M、SameGenerationRelation^M 是对一般式既有结构项的直接身份、协议与事件关系形式化：C\_i = C；同一冻结协议；同一生成关系身份；同一生成关系内部的互斥后继。它们是 S 的精确表示，不经由结构侧没有的形式工具归约，因此不另立回读桥。若以后发现 GenSchema 身份不足以保证结构侧的"同一次续行生成关系"，按 8.5(3) 回读冲突处理。

定理 7.2　率承担归约（关闭 H\_ρB）

设 M9—M14 成立，且 RateBearWitness^M(ν) 所引用的 Law 见证 W\_i 之资格依其 H\_LawRead(W\_i) 有效。若：

RateBearWitness^M(ν) = 1

则在评价 ν 中，申报组织 𝓛\_P 的合法承重状态真实进入 Rel\_ρ(𝒫; C, 𝔯\_P) 的形成。

证：由定义 3.28，存在 B ∈ MinSuff\_ρ(ν)、W\_i ∈ 𝓛\_P 与评价内实现 e\_ν，使 B ∩ GenIn(W\_i, ν) ≠ ∅ 且 EvalRateBind^M(W\_i, ν, e\_ν) = 1。取 a ∈ B ∩ GenIn(W\_i, ν)。

第一步，排除纯相关。a ∈ B ⊆ A\_ρ^gen(ν)。由定义 3.22，A\_ρ^gen 已排除只与结果统计相关的变量、生成决定完成后才执行结果的节点、观察者事后频率与无生成来源链的相关量。故 a 是该评价生成机制中的实际生成因子，不是相关量或结果执行变量。

第二步，排除仅被读取而不承重。B 是包含意义下的极小充分组（定义 3.26）：在 AdmVar\_ρ(ν) 的全部合法诊断变化中，固定 B 即在申报分辨度 ε\_ρ 下固定 Rel\_ρ^M；而 B 的任何真子集都不具此性质。故 a 不是仅被读取而不影响 Rel\_ρ 的量，而是在合法诊断变化族中属于相对生成关系的极小充分形成组。M11 保证 AdmVar\_ρ(ν) 对所申报的合法职责诊断变化域具有忠实性：其中不含违反场系统、冻结协议及生成图式的非法变化（Sound\_Adm），同时不遗漏上述承重相关的合法生成变化，或至少包含其在申报分辨度下的等价代表（Cover\_Adm）。因此 B 的充分性与包含极小性，是相对于真实合法生成变化域成立的，而不是相对于任意数学赋值或事后筛选的变化族成立的。

第三步，排除组织外的承担者。a ∈ GenIn(W\_i, ν)，由定义 3.23 与 M10，a 是 W\_i 所对应的 Law 形式解 R\_i 在 ν 下经真实生成来源链实现的生成因子，故 a 属于申报的 Law-bearing 组织，而不是组织之外的选择机制。

第四步，排除有承担能力而本评价未承担。EvalRateBind^M = 1 的 B2 给出：W\_i 的贡献 c\_i 在该评价的实现 e\_ν 中实际进入 Rel\_ρ^M(ν) 的形成，而非只具备用能力。

第五步，排除拼证。B1—B4 给出：来源同一 W\_i，生成进入同一 Rel\_ρ 形成链，同一实现 e\_ν，同一 C、𝔯\_P、ν。故极小充分性、来源归属与实际进入落在同一份承担上，不是由一份极小充分组、另一份来源链与第三次事件拼成。

合前五步：申报组织的一个 Law-bearing 实现，以其在合法评价中的承重状态，作为相对生成关系极小充分形成组的成员，实际进入了该评价中 Rel\_ρ 的形成。这正是《概率一般式》所称"𝓛\_P 的合法承重状态真实进入诸维之间相对生成关系的形成"；存在极性与一般式允许的联合、分布、冗余承担一致。

由率域量词聚合：RateBearWitness^M\_{𝔯\_P} = 1 时，按 DomainEvalMode 对 Eval(𝔯\_P) 全称（或 a.e.）成立，故组织在 𝔯\_P 上承担 Rel\_ρ。□

定理 7.2 即关闭率承担归约桥 H\_ρB（见 8.3）。

(7.4) DomainRelativeRateBearing^M = 1 ⇒ DomainRelativeRateBearing = 1  
\[调用定理 7.2 关闭的 H\_ρB，不作为未决条件向下游传播；RateBearWitness 所引 W\_i 各自承继 H\_LawRead(W\_i)\]

RateDomainQual^M 与 RelForm^M 分别是一般式率域纪律与 Rel\_ρ 可形成性的直接形式化；与定理 7.2 所得合取，得结构层 DomainRelativeRateBearing。

(7.5) Read\_{N\_P}^M = 1 ⇒ N\_P = 1  
\[(7.2)—(7.4) 各箭头所携条件之合取\]

新立的回读桥只有 H\_ρB，已由定理 7.2 关闭；其余方括号内的条件均自上游承继。

《概率一般式》必要向的条件 H2 ∧ H3^red，只在调用 Probability ⇒ N\_P，或以由该必要向取得的分量作为承重前件时承继。M\_P 的形式定义与求解只使用 V\_P、𝓛\_P、C、𝔯\_P 等对象与符号，不调用该必要向，因此不自动承继 H2、H3^red。

### 8.2 下交

《概率必然式》：N\_P^M、N\_P 及形式证书。

《概率作用一般式》《概率作用数理式》《概率作用必然式》：当前资格结构、Rel\_ρ^M、率承担见证与来源链；不交 ProbabilityAct 结论。

《概率反演式》：可观察量与生成侧不可直接观察量的区分；经验频率不能直接反推 RateBearing。

《概率判定式》：三值形式对象、M1—M16、0 与 ⊥ 的边界及可操作接口。

### 8.3 条件账本

### 8.4 状态

形式定义与求解本身不以 H\_ρB 为外部假设；H\_ρB 是在第七节提出并关闭的 M ⇒ S 归约桥。没有新增的未关闭 H。结构回读仍为 Conditional，条件为各 Law 见证自身的 H\_LawRead(W\_i)。任何后续引用第七节回读结论者，须保留方括号内的条件。

### 8.5 击穿方式

(1) 表示失败：存在满足 S\_P 的合法实例，在 M1—M16 全部满足时仍不能由 M\_P 表示，且不是单纯输入不足。

(2) 内部矛盾：同一 χ\_P 下同一判据按定义同时推出 1 与 0。

(3) 回读冲突：形式读数为 1 而对应的一般式结构为 0。

(4) 资格条件越界：把一般式未要求的归一、完整覆盖、正率、稳定频率等变成资格条件。

(5) 外部选择器误判：把外部选择器判为申报组织的率承担。

(6) 冗余误判：把热冗余中评价内的实际承担者判为不承担，或把冷备用判为该评价中的承担者。

(6′) 资格与作用混同：把 RateBearWitness 的评价内实现要求读成"现实时间 t 须正有事件发生"，从而把 ProbabilityAct 的判断并入资格判据。

(7) 相关量入链：把纯相关量收入 A\_ρ^gen 或生成承担链。

(8) ⊥ 写成 0：把形式材料不足记为失败。

(9) 符号悬空：某一承重符号在未来运行基底中找不到存储、读取、判定、更新的对应。

(10) 对应表遗漏：某对象承担判据、求解或回读职责而未列入 3.0。

(11) 关系性质冲突：正文用法与 3.33 申明不符。

(12) 量词极性改变：把 RateBearWitness 的存在极性改成全称，或把率域聚合的全称改成存在；measure 模式下以零测点建立或击穿结论。

(13) 归约反例：存在 RateBearWitness^M(ν) = 1、M9—M14 成立（含 M11 的 Sound\_Adm 与 Cover\_Adm）、所引 Law 见证资格有效，而结构层申报组织在 ν 中并不承担 Rel\_ρ 的形成。此击穿定理 7.2，须重开 H\_ρB。

不构成击穿：M1—M16 不满足致相关项为 ⊥；上游回读条件未关闭；N\_P^M = 1 而 Probability 未判（充分向另属《概率必然式》）。

### 8.6 回归测试

以下测试只作回归与击穿检验，不作一般证明。

测试 1　正例：两维均有正式 Law 见证；同 C；同冻结率域；同一次生成关系；申报组织实际形成 70:30。要求 MLD^M = 1、CCB^M = 1、DRRB^M = 1，故 Read\_{N\_P}^M = 1。

测试 2　外部选择器：外部 M 决定 70:30，𝓛\_P 只执行被选结果（各评价内均如此）。M 的选择节点不在任何 GenIn(W\_i, ν) 中，执行节点不进入 A\_ρ^gen。要求 MLD^M = 1、CCB^M = 1、DRRB^M = 0；稳定频率不改变第三项的读数。

测试 3　跨条件拼接：70 次条件 a、30 次条件 b，a、b 不属于同一冻结 Γ\_r。要求 NoCrossConditionStitch^M = 0，SameGenerationDomain^M = 0，故 CCB^M = 0。

测试 4　并行过程：v\_1 与 v\_2 分别来自两个不同的生成关系身份（GenSchema 不同）；每一事件都只兑现其所属的一维，互斥不等式全部通过；二者同 C、同 Γ\_r。要求 SameGenSchema^M = 0，故 SameGenerationRelation^M = 0。

测试 4b　同次双兑现：同一 GenSchema 的同一事件同时落入 D\_1 与 D\_2。要求 MutualSuccessor^M = 0，故 SameGenerationRelation^M = 0。

测试 5　热冗余：A、B 任一都足以维持同一相对生成关系。要求 MinSuff\_ρ = {{A}, {B}}，评价内实际承担者所属的申报组织取得 RateBearWitness^M = 1。

测试 6　部分覆盖与零率维：(w\_1, w\_2, w\_out) = (7, 0, 3)。要求 v\_2 不因 w\_2 = 0 退出 V\_P；Σ\_i ρ\_i^full = 0.7 \< 1；不因覆盖不全而失败。

测试 7　来源链不足：有结果频率、Law 见证、同位同域，但无法取得 W\_i → c\_i → Z\_i^ρ。要求 DRRB^M = ⊥，不是 0，也不是 1。

测试 8　冷备用：A 承担，B 只在 A 退出后接管。要求在该评价中 MinSuff\_ρ = {{A}}；A 取得率承担，B 不取得；B 可属于 A\_ρ^gen，但不属于该评价的极小充分组。

测试 9　纯相关量：Z 与率高度相关，但无生成来源链。要求 Z ∉ A\_ρ^gen。

测试 10　内外完全冗余：内部 I 与外部 M 均独立足以维持同一 Rel\_ρ。评价内实现走 I 时 RateBearWitness^M = 1；走 M 而 I 只备用时 RateBearWitness^M = 0（命题 4.5）。此例表明极小充分组资格与评价内绑定必须同时具备。
