# 概率作用必然式

一、目的

证明：一份已经成立的概率，只要在时刻 t 存在一组见证，使当前发生与职责兑现在这同一组见证上都成立，它此刻就必然正在作用；不再需要任何额外的独立作用内容，也不存在能够单独取消这一作用的独立条件。

即：在 Probability\_F,t(𝒫; C, 𝔯\_P) = 1 的工作域内，

N\_PAct = 1 ⇒ ProbabilityAct\_F,t(𝒫; C, 𝔯\_P, ξ\_t) = 1

N\_PAct = ∃(e\_t, R\_t, Z\_t) \[ CurrentProbabilityOccurrence ∧ ProbabilityDutyConformance \]

具体而言：最终结果是否落入某一概率维、这份概率是否为唯一或不可替代的承担者、率值是否与以往相同、系统是否本体随机、这次作用是否被识出或观察、当前是否有环境扰动、这份概率是否有奖惩形成史，都不影响结论。

二、核心命题

在已经成立的概率 𝒫 的工作域内，冻结作用语料所说的概率作用，其当前作用内容恰由两项构成：此刻确有这份概率的一次现实发生；这份概率作为 Law-bearing 组织承担了各维之间的相对生成。两项受同一见证纪律约束，必须落在同一次发生、同一份实现上；这一纪律不是第三项内容。冻结语料中没有第三项作用内容，也没有在两项都成立时仍能单独取消作用的条件。因此，《概率作用一般式》逼出的必要结构 N\_PAct 一旦成立，概率作用不能不发生。

证明不采用"ProbabilityAct ⇒ N\_PAct，所以反过来也成立"的路线。一般式的删职最小性只证明两项缺一不可，不证明两项合起来足以成立作用。一般式的结构在这里只作为前件，充分性由冻结作用语义的独立闭合取得。

三、算子映射

以下把命题涉及的对象逐一映射到已经成立的式与形式系统。

工作域对象

F、t：当前沉积场与当前时刻。来源：《概率一般式》工作域。

𝒫、C、𝔯\_P：候选概率组织、续行位、事前冻结率域。来源：《概率一般式》工作域；在《概率作用数理式》中登记于 χ\_PAct。

ξ\_t：时刻 t 的当前申报情境，不预设存在实际续行。来源：《概率作用一般式》第二节；《概率作用数理式》定义 3.1。

Probability\_F,t(𝒫; C, 𝔯\_P)：概率资格谓词。来源：《概率一般式》《概率必然式》；这里只作进入条件。

D\_PAct：工作域，即 Probability\_F,t(𝒫; C, 𝔯\_P) = 1（第四节）。

V\_P：𝒫 的续行维集合。来源：《概率一般式》；《概率数理式》。

Realize(e, v\_i)：续行 e 是否兑现维 v\_i。来源：《概率数理式》定义 3.3。

Θ：落定代价，一次落定由其最低化给出。来源：母本。

目标谓词

ProbabilityAct\_F,t(𝒫; C, 𝔯\_P, ξ\_t)：已经成立的概率 𝒫 在情境 ξ\_t 中确实发挥了它作为概率的作用。来源：《概率作用一般式》第二节对象入口，语义锚为冻结作用语料 B5.c、B11.a。它在形式系统中没有对应算子；《概率作用数理式》明确不给出它的读数。

结构前件

w^S = (e\_t, R\_t, Z\_t)：结构见证。来源：《概率作用一般式》第五节。

CurrentProbabilityOccurrence(w^S)，记 R\_1：当前确有一次实际续行 e\_t，其实际生成链中有一段 Z\_t 由 𝒫 的合法当前实现 R\_t 实际承担。来源：《概率作用一般式》第五节。形式算子：CurrentProbabilityOccurrence^M(w^M)，w^M ∈ 𝔉(w^S)，《概率作用数理式》定义 3.7。

ProbabilityDutyConformance(w^S)：在同一次续行 e\_t 中，R\_t 作为 𝒫 这一 Law-bearing 组织的实现，以合法的当前承重状态实际进入该次各概率维之间相对生成关系的形成，并使当前承担成立。来源：《概率作用一般式》第五节。形式算子：ProbabilityDutyConformance^M(w^M)，《概率作用数理式》定义 3.11。

R\_2 := R\_1 ∧ ProbabilityDutyConformance，依赖型为线性递进 R\_1 ≺ R\_2，R\_2 ⇒ R\_1。来源：《概率作用一般式》第五节。形式算子：R\_2^M，《概率作用数理式》定义 3.12。

N\_PAct = ∃w^S \[ R\_1(w^S) ∧ ProbabilityDutyConformance(w^S) \]。来源：《概率作用一般式》。形式算子：Read\_{N\_PAct}^M，《概率作用数理式》定义 3.16。

C\_PAct := N\_PAct：充分条件组（第四节）。

语义对象

A\_1、A\_2：冻结作用语料的两项作用内容；B\_same：二者的同见证绑定纪律（第五节定理一）。三者都是元语言名称，不是本体谓词，不是场量，各处可以原地展开为第五节所列的语料分量。B\_same 不是第三项作用内容。

IndependentCancel\_PAct：独立取消条件集合的元语言名称，不是本体谓词。

R\_3^independent：第三项独立作用职责集合的元语言名称，不是本体谓词。

映射表到此完整。以下证明只使用上列对象；没有列入的对象，都不承重。

四、工作域、条件组与静力律

这里研究的是当前作用是否成立，不是作用如何随时间演化，所以不设动力方程。以下逐项列出来源。

工作域

D\_PAct：Probability\_F,t(𝒫; C, 𝔯\_P) = 1。来源：《概率一般式》《概率必然式》封版结果。它是对象的进入条件，不是充分条件组的一项；离开这一工作域，所研究的对象就不是一份概率，问题本身没有进入。这里不调用《概率一般式》条件化的必要向 Probability ⇒ N\_P。

条件组

C\_PAct := N\_PAct，即存在同一组 w^S = (e\_t, R\_t, Z\_t)，使 R\_1(w^S) = 1 且 ProbabilityDutyConformance(w^S) = 1。来源：《概率作用一般式》封版结构。

主定理的形式是：D\_PAct ⊨ ( N\_PAct ⇒ ProbabilityAct )。

证明域

关于当前作用的语义结论，只在冻结语料上取得：《概率必然式》第三节固定语料 A1—A3、B1—B11、C1，其中直接描述作用的是 B5.c 与 B11.a。这是证明域的限定，不是充分性的规则；语料修订或新增作用语句时，按第六节击穿一复审。

静力律

L1　执行归一：每一次物理执行都落定于一处；一次落定由 Θ 的最低化给出。来源：母本 A1.d、研发起点语料 B3.a。

L2　互斥后继：一次续行对各概率维的兑现之和 Σ\_i Realize(e, v\_i) ≤ 1，不要求等于 1。来源：《概率数理式》定义 3.13。

L3　递进与同见证：R\_2 在 R\_1 的同一见证上成立，两项不得拆成各自独立的存在式。来源：《概率作用一般式》第五节。

L4　资格与作用分层：资格可以在静置时保留、在复走中取得；作用只在现实当前取得。来源：《概率作用一般式》第三节、第十节。

五、定理群

### 5.1 定理一　作用语义与绑定闭合定理

冻结作用语料中的每一个语义分量，都属于下列三类之一：当前作用的取得条件；当前作用的取消条件；不决定当前作用真值的分量（执行方式、触发前件、生成过程、关系、动力、功能与例子、程度、表示与观察）。其中取得侧恰好是两项作用内容：

A\_1　当前发生：这份已经成立的概率，此刻确实在现实续行中发生。

A\_2　概率身份下的职责兑现：这份概率的合法当前实现不只是在活动，而是承担概率特有的职责，即各概率维之间相对生成关系的形成。

两项受同见证绑定纪律约束：

B\_same：∃w \[ A\_1(w) ∧ A\_2(w) \]，而不是 (∃w A\_1(w)) ∧ (∃w′ A\_2(w′))。

B\_same 是 A\_1 与 A\_2 的见证绑定纪律，不是第三项作用内容。取得侧没有第三项独立职责：R\_3^independent = ∅。

证明

第一，原子化。B5.c "它使在穿过众多律生态中各方向上，能归一而行，即能行一。这是概率在底等生物中的重要作用。" 拆为：当前的"行"，属于取得侧，给出 A\_1；"各方向上"，属于取得侧，给出 A\_2 的职责背景，即概率面对的是多个方向之间的相对生成；"归一而行""能行一"属于执行方式，由 L1 刻画；"穿过众多律生态"属于关系与动力；"底等生物中的重要作用"属于功能与例子。

B11.a "如果某环境扰动出现，因受过奖惩而已成概率律，则自动去某方向维……而续行，底等生物靠此而行。" 拆为："某环境扰动出现"是本次续行的触发前件；"因受过奖惩"属于生成过程；"已成概率律"是资格，已由 D\_PAct 固定；"自动……而续行"属于取得侧，给出 A\_1；"去某方向维"属于取得侧，给出 A\_2，即按概率的方向生成后继；"底等生物靠此而行"属于功能与例子。

第二，B\_same 的来源。两句都把"行"与"各方向""某方向维"写在同一次续行上：B5.c 说的是"在各方向上……而行"，B11.a 说的是"去某方向维而续行"。语料所说的作用，是同一次续行中方向性的生成，不是一次续行与另一次方向性生成的并列。所以 A\_1 与 A\_2 必须落在同一见证上。这一要求约束的是两项内容的见证，不增加新的作用内容，与《概率作用一般式》把同一见证定为承继纪律而非第三项结构的裁定一致。

第三，分类穷尽，没有第三项取得条件。对 B5.c、B11.a 的每一分量，以及它们与固定语料其余语句之间的同句合取与跨句联合授权，《概率作用一般式》作用语料审查已逐一检验：执行方式、触发前件、生成过程、关系、动力、功能与例子、程度、表示与观察各有归属，没有任何分量或组合被授权承担 A\_1、A\_2 之外的当前作用内容。固定语料中其余语句不直接描述作用；它们与 B5.c、B11.a 之间的跨句关系，也已由该审查检验，都只用于说明作用的例子、前件、形成方式、关系或执行方式，不决定当前作用的真值。这里承继的是该审查对冻结语料的分类结论，不是那一篇的必要向，不构成对必要向的倒置。

综合以上三点，定理一得证。□

### 5.2 定理二　取消条件为空定理

在 D\_PAct 内，当 A\_1、A\_2 在满足 B\_same 的同一见证上全部取得时，冻结作用语料中不存在能够单独使 ProbabilityAct = 0 的条件：

IndependentCancel\_PAct = ∅

证明

逐项检验可能被当作取消条件的候选。每一项都检验：假设 A\_1、A\_2 在同一见证上全部成立，该候选的成立或不成立，能否单独使作用不成立。

最终没有落入 V\_P：由 L2，一次续行的最终后继可以落在各维之外；由 L1，最终落定是执行，不是作用语义。作用完成后另一合法机制改变最终落定，不回溯取消已经发生的作用。不是取消条件。

非唯一承担、非但为必要：A\_2 要求的是这份概率的实现实际承担了相对生成，不要求它是唯一或不可替代的承担者；热冗余中多个实现同时承担，各自都在承担。不是取消条件。

率值不变：持续承担既有的相对生成关系，仍是承担。不是取消条件。

率值发生合法变化：A\_2 所说的职责是承担各维之间的相对生成，不是保持某个率值；变化后的率关系仍由这份概率的合法当前实现形成，职责仍在兑现。不是取消条件。

非本体随机：作用语料只说"行"与"方向"，没有要求执行不可预测；由 L1，每次执行本来就归一。不是取消条件。

当前没有环境扰动：B11.a 中环境扰动是那一句所举作用例的触发前件，没有被规定为一切作用的条件；B5.c 没有提环境扰动。不是普遍取消条件。

没有"穿过众多律生态"：属于关系与动力，不属于当前作用语义。不是取消条件。

没有奖惩形成史：属于生成过程；由 D\_PAct，资格已经固定，这里不能再要求它的形成史。不是取消条件。

没有被识出、读取或观察：属于表示与观察；由 L4 与作用语义，未被读出时的真实承担仍然是承担。不是取消条件。

不独占整次事件：A\_1 只要求存在一段由这份概率的实现实际承担的子段，不要求整次续行都由它生成。不是取消条件。

没有其他候选：《概率作用一般式》已对冻结作用语料 B5.c、B11.a 的单个分量、同句合取与跨句联合授权逐项审查，没有发现当前发生、概率职责兑现及其同见证纪律之外的独立当前作用职责；环境扰动、奖惩形成、最终落定、穿越律生态、程度、表示与观察都已分流。在此基础上，以上又逐项检查了这些分量：在 A\_1、A\_2 于满足 B\_same 的同一见证上成立时，它们都不能单独取消 ProbabilityAct。所以在当前冻结语料域内，没有剩余的独立取消候选。《概率必然式》第五节的取消侧审查针对的是概率资格，不是当前作用，这里不借用它的结论。

所以 IndependentCancel\_PAct = ∅。□

### 5.3 定理三　结构实现定理

C\_PAct 完整实现 A\_1、A\_2，并满足 B\_same：

R\_1(w^S) ⇒ A\_1(w^S)

ProbabilityDutyConformance(w^S) ⇒ A\_2(w^S)

N\_PAct ⇒ ∃w \[ A\_1(w) ∧ A\_2(w) \]，即绑定纪律 B\_same 得到满足

证明

R\_1(w^S) 给出：现实时间 t 存在一次实际续行 e\_t，其中一段 Z\_t 由 𝒫 的合法当前实现 R\_t 实际承担。这正是 A\_1 所说"这份已经成立的概率此刻确实在现实续行中发生"：发生是现实当前的，发生的是这份概率自己的实现，而不是外部旁路、同型结构或事后归属。

ProbabilityDutyConformance(w^S) 给出：在同一 e\_t 中，R\_t 作为 𝒫 这一 Law-bearing 组织的实现，以合法的当前承重状态实际进入各概率维之间相对生成关系的形成，并使当前承担成立。这正是 A\_2 所说"不只是在活动，而是承担概率特有的职责"：它排除了单维律独行、率关系的单纯存在或读出、组织之外的结构与部分执行。

N\_PAct 对 w^S 取同一个存在量词，由 L3，两项在同一 (e\_t, R\_t, Z\_t) 上成立，所以 B\_same 得到满足。

A\_1、A\_2 没有剩余内容。□

### 5.4 定理四　概率作用必然定理

在工作域 D\_PAct（Probability\_F,t(𝒫; C, 𝔯\_P) = 1）内，若存在同一组见证 w^S = (e\_t, R\_t, Z\_t)，使 CurrentProbabilityOccurrence(w^S) = 1 且 ProbabilityDutyConformance(w^S) = 1，则：

ProbabilityAct\_F,t(𝒫; C, 𝔯\_P, ξ\_t) = 1

即：D\_PAct ⊨ ( N\_PAct ⇒ ProbabilityAct )

证明

在 D\_PAct 内，设 N\_PAct = 1 而 ProbabilityAct = 0。

由定理一，冻结作用语料中决定当前作用真值的分量，只有取得条件与取消条件两类；其余分量不决定作用的真值。所以 ProbabilityAct = 0 若成立，只可能有两种原因：某一取得条件没有兑现，或者某一取消条件生效。

第一种不可能。由定理一，取得条件恰为 A\_1、A\_2，并受 B\_same 约束，没有第三项；由定理三，N\_PAct = 1 使 A\_1、A\_2 在同一见证上全部兑现，B\_same 得到满足。

第二种不可能。由定理二，在 A\_1、A\_2 于同一见证上全部取得时，不存在独立的取消条件。

两种原因都被排除，与 ProbabilityAct = 0 矛盾。所以 ProbabilityAct = 1。□

这里得到的不是"与作用相似的结构"。N\_PAct 完整实现了由冻结作用语料独立分析得到的全部作用内容与绑定纪律；证明不依赖把 ProbabilityAct 定义为 N\_PAct，也没有倒置《概率作用一般式》的必要向。

### 5.5 定理五　N\_PAct 的充分结构最小定理

在 D\_PAct 内，并在当前冻结的作用语料与任务域中，N\_PAct 是推导最小的充分结构：去掉其中任一部分，结论不再成立；增加任一候选项，都是过强或没有语料依据。工作域 D\_PAct 不参与这一测试：离开它，对象就不是一份概率，问题没有进入，这不是"充分条件少了一项"。

证明

去掉 R\_1：只剩"有概率职责的结构或能力"，则静置、历史实现、复走中的承担、仅有承担潜能的情形都会混入。R\_1 不可去。

去掉 ProbabilityDutyConformance：只剩 R\_1，可以出现概率中某一维的律单独续行，而组织没有承担相对生成。ProbabilityDutyConformance 不可去。

去掉同见证纪律（把 N\_PAct 拆为两个独立存在式）：一次现实当前发生没有职责兑现、另一次复走或别处有职责兑现，两者可以拼成前件为真而作用不成立。同见证纪律不可去。

增加"最终落维"：过强，见第六节作用后改道情形。

增加"唯一承担"或"但为必要"：过强，见第六节热冗余情形。

增加"固定率值"：过强，见第六节合法变率情形。

增加"环境扰动""本体随机""被识出或读取"：没有语料依据，定理一已说明它们不属于作用的取得条件，定理二已说明它们也不是取消条件。

所以在 D\_PAct 内：

C\_PAct^min = N\_PAct

这里的"最小"指推导最小，不宣称不存在其他逻辑等价的表达，也不宣称语料升版后仍然不变。□

### 5.6 推论

推论一　双向闭合。《概率作用一般式》已证 ProbabilityAct ⇒ N\_PAct（在 D\_PAct 的工作域内，不携 H）；定理四证 N\_PAct ⇒ ProbabilityAct。合得：

在 Probability\_F,t(𝒫; C, 𝔯\_P) = 1 的工作域内：ProbabilityAct ⇔ N\_PAct

这一等价是两篇合成的结果，不改变任一篇的式种，也不另立等价式。

推论二　形式入口。若《概率作用数理式》取得 Read\_{N\_PAct}^M = 1，经其正向回读 (7.1)—(7.3) 得 N\_PAct = 1，再由定理四得 ProbabilityAct = 1：

Read\_{N\_PAct}^M = 1 ⇒ ProbabilityAct = 1　\[所用见证适用的 H\_LawRead(W\_i)\]

这一链条只承继《概率作用数理式》正向回读所携的 H\_LawRead，不承继 H\_PAct-Rep：后者只承担第二层负读出的反向表示，不在这条正向链上。

六、边界情形与结构崩坏条件

### 6.1 边界回测

以下情形都在 D\_PAct 内，只作回测，不作一般证明。判为 ProbabilityAct = 1 的，都满足 N\_PAct，由定理四得出；判为 ProbabilityAct = 0 的，都是 N\_PAct 不成立，由《概率作用一般式》必要向的逆否得出（不携 H）。

T1　作用后改道：N\_PAct 成立，作用子段完成后下游机制使最终结果不落入 V\_P。ProbabilityAct = 1。

T2　热冗余：两个合法实现同时足以承担相对生成，这份概率的实现真实参与，但不是但为必要。N\_PAct 成立，ProbabilityAct = 1。

T3　合法变率：率关系由 7 : 3 变为 1 : 9，仍由这份概率的合法当前实现形成。N\_PAct 成立，ProbabilityAct = 1。

T4　单维独行：R\_1 成立，ProbabilityDutyConformance 在时刻 t 的每一次属于 𝒫 的发生上都不成立。N\_PAct 不成立，ProbabilityAct = 0。

T5　一般物理影响：这份概率的成员改变了热、阻抗、带宽等物理量，但没有承担各维之间的相对生成，时刻 t 也没有其他属于 𝒫 的发生承担了相对生成。ProbabilityDutyConformance 在每一次属于 𝒫 的发生上都不成立，N\_PAct 不成立，ProbabilityAct = 0。

T6　复走冒充：职责兑现只出现在复走或历史中，时刻 t 在 C 处没有任何属于 𝒫 的现实当前发生。R\_1 不成立，ProbabilityAct = 0。

T7　拼证：一次现实事件满足 R\_1 而没有职责兑现，另一次评价（复走，或另一续行位、另一率域实例）满足职责兑现，时刻 t 在 C 处没有其他同时满足两项的见证。两者不在同一见证上，N\_PAct 不成立，ProbabilityAct = 0。

T8　未识出：没有任何读取，但这份概率在当前真实承担相对生成。N\_PAct 成立，ProbabilityAct = 1。

T9　非本体随机：完全确定的系统中满足 N\_PAct。ProbabilityAct = 1。

T10　无奖惩史：某份概率的来源不依赖奖惩，但当前结构与职责都合法。N\_PAct 成立，ProbabilityAct = 1；不能因没有奖惩史取消当前作用。

### 6.2 结构崩坏条件

以下任一出现，即击穿定理四：在工作域与申报条件都保持时，存在合法情形满足 Probability = 1、N\_PAct = 1，而 ProbabilityAct = 0。按发生的层次分为：

击穿一　语义遗漏：冻结作用语料中存在一个未被 A\_1、A\_2 覆盖的当前作用内容，即存在第三项独立的当前职责；或者语料修订、新增了这类语句。击穿定理一。

击穿二　取消条件：存在一个独立条件，使 R\_1 与职责兑现都成立时仍能取消作用。击穿定理二。

击穿三　实现失败：同见证纪律不足以保证 A\_1 与 A\_2 落在同一次发生上，或 R\_1、ProbabilityDutyConformance 未完整实现 A\_1、A\_2。击穿定理三。

击穿四　分流错误：某个被归入生成过程、动力、程度、表示、观察、执行、关系或结果的因素，被冻结作用语料证明其实是当前作用语义。击穿定理一或定理二。

击穿五　误判：热冗余、合法变率、作用后改道、未识出、非本体随机等合法情形，被判为 ProbabilityAct = 0。

击穿六　证明方式违规：证明中把一般式必要向直接倒置；或把 ProbabilityAct 换名为"真正作用""整体作用""有效作用"之类的隐藏谓词，再把它当作新的前件；或以《概率作用数理式》的形式读数或证书代替对象层的充分证明。
