# 概率反演式

在事前冻结的合法观测协议下，给定实际观测 y，确定由 y 最多能够知道一份候选是不是概率：什么时候可以辨明，什么时候已经证明不可辨明，什么时候因为前像没有查全或候选自身资格没有定而只能待定。

观测不把内部系统还原为一个答案，只把可能的内部系统缩成一个前像。概率能否由此被识出，不在于结果有多像概率，而在于这个前像中还能不能同时容纳概率系统与非概率系统。

一、观测集与前向映射申报

### 1.1 上游冻结结论

概率资格核：

N\_P := MultiLawDimension ∧ CommonContinuationBind ∧ DomainRelativeRateBearing

充分向（《概率必然式》）：N\_P ⇒ Probability，Status = Established，不携 H。

必要向（《概率一般式》）：H2 ∧ H3^red ⇒ \[ Probability ⇒ N\_P \]。

所以：

N\_P = 1 ⇒ Probability = 1，不携 H；

N\_P = 0 ⇒ Probability = 0，若经必要向的逆否取得，携 H2 ∧ H3^red。

两者的条件来源不同，以下不洗掉这一差异。

已有禁止回读（《概率数理式》第七节）：StableFrequency ⇏ DomainRelativeRateBearing；RateRead ≠ ⊥ ⇏ RateBearing；ρ(v\_i) = 0 ⇏ v\_i ∉ V\_P。数值率可读、各维率为正、归一、完整覆盖、本体随机、经验频率稳定，都不是概率资格的条件。

### 1.2 观测协议

Π\_obs = (D\_Π, Y\_Π, H\_Π, Prot\_Π)

D\_Π：合法候选内部系统的域。每个成员 X 是一份完整规定的候选内部系统，包括它的 Law 组织、生成结构与环境。

Y\_Π：协议允许取得的观测空间。

H\_Π：D\_Π → Y\_Π，前向映射：给定内部系统 X，协议下会得到的观测 H\_Π(X)。

Prot\_Π：事前冻结的观测协议，规定观测的对象、窗口、方式与记录格式。

实际观测：y ∈ Y\_Π。

### 1.3 前向映射的来源

H\_Π 必须由已经成立的式给出：由场系统、运行基底或已封版的形式系统说明，内部系统 X 在协议 Prot\_Π 下会产生什么观测。H\_Π 的来源须逐项写明。凭空假定一个"由概率到观测"的统一总映射，不构成合法的前向映射。

### 1.4 反演准入

AdmInv(Π) = DomainFrozen ∧ ObsSetFrozen ∧ ForwardMapEstablished ∧ NoInternalQualificationLeak ∧ NoTargetPreselection

DomainFrozen：D\_Π 在观测以前冻结，看见结果以后不重切候选域。

ObsSetFrozen：Y\_Π 与 Prot\_Π 在观测以前冻结，看见结果以后不追加有利的观测。

ForwardMapEstablished：H\_Π 按 1.3 有已成立的来源。

NoInternalQualificationLeak：Y\_Π 中的观测不直接含有待反演的内部资格，包括 Probability、N\_P、DomainRelativeRateBearing、RateBearWitness、Law 资格。这些量不得作为普通外部观测进入 y。

NoTargetPreselection：D\_Π 不是预先只保留 Probability = 1 的候选而得，也不是用与 Probability 等价的内部资格筛选而得。

AdmInv 是反演的工作域准入，不是新的概率本体条件，不计入 H。AdmInv(Π) = 0 时，不进入反演。

### 1.5 候选资格标签

对每个 X ∈ D\_Π：

Class\_P(X) ∈ {1, 0, ⊥}

Class\_P(X) = 1：已有合法的上游结论签出 Probability(X) = 1。当前可用的一条充分来源是 N\_P(X) = 1 ⇒ Probability(X) = 1（《概率必然式》），不携 H。

Class\_P(X) = 0：已有合法的上游结论签出 Probability(X) = 0。当前由 N\_P(X) = 0 经《概率一般式》必要向的逆否取得时，携 H2 ∧ H3^red；这一条件随该候选的标签逐个保留。

Class\_P(X) = ⊥：当前没有合法的上游结论签出该候选的 Probability 真值。

Class\_P 是合法上游签出的状态，不限定只能由 N\_P 取得；以后若有其他已成立的式签出资格，按其来源及所携条件进入。

反演读出本身正负对称；候选资格的来源在当前上游证明状态下不对称。这一不对称来自上游证明的现状，不是概率本体的正负不对称。

Class\_P 描述的是候选内部系统的理论资格，用于刻画前像；它不是观测，不进入 y，与 NoInternalQualificationLeak 不冲突。

二、反演问题陈述

### 2.1 前像

E\_Π(y) := H\_Π^{-1}(y) = { X ∈ D\_Π \| H\_Π(X) = y }

### 2.2 观测等价

X\_a ∼\_Π X\_b ⇔ H\_Π(X\_a) = H\_Π(X\_b)

∼\_Π 是 D\_Π 上的等价关系（自反、对称、传递）。E\_Π(y) 非空时，是实际观测所对应的等价类。

### 2.3 问题

由 y 求前像 E\_Π(y) 的界：由 y 最多能够知道内部系统的什么，以及关于概率资格最多能够知道什么。

前像不是"最可能的解释"。这里不讨论贝叶斯后验，不给前像成员赋可信度，不以统计拟合优度代替结构可识别性。

### 2.4 前像覆盖

实际求解时，前像以枚举候选集 Ê\_Π(y) ⊆ E\_Π(y) 给出。定义前像覆盖证书 InvCover\_Π(y) ∈ {1, 0, ⊥}：

1：已证明 Ê\_Π(y) = E\_Π(y)，即合法候选已经查全；

0：已证明 Ê\_Π(y) ⊊ E\_Π(y)，即已知至少还有一个合法候选没有被当前枚举包含；

⊥：既不能证明覆盖完整，也没有取得明确的遗漏见证。

InvCover\_Π(y) ≠ 1 时，前像覆盖未闭。

### 2.5 概率特化

令 φ\_P(X) = Probability(X)。关于概率资格的反演问题，就是问 φ\_P 在 E\_Π(y) 上是否同值。

Probability 是候选的对象层资格真值，不因反演而变为三值。实际求解时，这里不直接访问该真值，而以 Class\_P(X) ∈ {1, 0, ⊥} 记录当前上游理论是否已经合法签出该候选的 Probability 真值。Class\_P(X) = ⊥ 表示资格真值当前没有被理论链关闭，不表示 Probability 本体有第三个真值。

三、可识别性分析

### 3.1 定理一　性质可识别因子化定理

对内部性质 φ：D\_Π → Z，定义：

Ident\_Π(φ)：存在函数 g\_φ：Im(H\_Π) → Z，使对所有 X ∈ D\_Π，φ(X) = g\_φ(H\_Π(X))。其中 Im(H\_Π) = H\_Π(D\_Π) 是前向映射的像。

则：

Ident\_Π(φ) ⇔ \[ ∀X\_a, X\_b ∈ D\_Π：X\_a ∼\_Π X\_b ⇒ φ(X\_a) = φ(X\_b) \] ⇔ ∃g\_φ：Im(H\_Π) → Z，φ = g\_φ ∘ H\_Π

在单个观测 y 上的局部形式：定义 IdentAt\_Π(φ; y)：存在 z ∈ Z，使对所有 X ∈ E\_Π(y)，φ(X) = z。则

IdentAt\_Π(φ; y) ⇔ φ 在 E\_Π(y) 上恒定

并记 NonIdent\_φ^Π(y) := ¬IdentAt\_Π(φ; y)；对 φ = φ\_P，记作 NonIdent\_P^Π(y)。

证明

由左推中：若 φ = g\_φ ∘ H\_Π，且 H\_Π(X\_a) = H\_Π(X\_b)，则 φ(X\_a) = g\_φ(H\_Π(X\_a)) = g\_φ(H\_Π(X\_b)) = φ(X\_b)。

由中推右：若 φ 在每个等价类上恒定，对 Im(H\_Π) 中的每一个 y′，取 E\_Π(y′) 中任一成员 X，定义 g\_φ(y′) := φ(X)。由恒定性，这一定义与所取成员无关；于是对任意 X，φ(X) = g\_φ(H\_Π(X))。

右即左的定义。局部形式同理，只在 E\_Π(y) 上论证。□

数据量多并不自动意味着可识别。可识别的真正条件是：目标性质不区分任何观测协议无法区分的两个合法内部系统。

### 3.2 概率的可识别性

由定理一，概率资格在 y 上可识别，当且仅当：

∀X\_a, X\_b ∈ E\_Π(y)：Probability(X\_a) = Probability(X\_b)

"看起来像概率"不是可识别。可识别只取决于前像中概率资格是否同值。

### 3.3 三个不可辨识反例模板

以下三例是协议相对的结构反例模板，不申报新的物理实现或运行基底，也不断言某种具体的概率运行体已经存在。模板的形式是：若相应协议 Π\_out、Π\_freq、Π\_rate 已经取得 ForwardMapEstablished、从而 AdmInv(Π) = 1，并且存在一份取得相应观测 y 的概率候选 X\_1，只要能在 D\_Π 中构造一份外部选择器候选 X\_0，使它复制同一观测而 DomainRelativeRateBearing(X\_0) = 0，二者就进入同一前像，该类观测便不能普遍识别概率资格。这里不新建这些前向映射。以下三个结论式都在这一模板条件下成立：除 AdmInv 外，还要求 D\_Π 中确有相应的 X\_1 与 X\_0。

X\_0 的负标签经《概率一般式》必要向的逆否取得，所以各模板中"X\_0 不是概率"的判断携 H2 ∧ H3^red（见 5.2）。

外部选择器候选的构造：给定 X\_1，令 X\_0 保留 X\_1 的各维、Law-bearing 与共同绑定，但各维之间的相对生成改由组织之外的机制 M 决定，𝒫 只执行被选中的结果。《概率一般式》第八节已经说明这类情形中前两项资格可以全真，而 DomainRelativeRateBearing 失败。于是 N\_P(X\_0) = 0，Class\_P(X\_0) = 0。

模板一　结果序列

给定概率候选 X\_1，协议 Π\_out 只记录各次续行的结果序列，H\_{Π\_out}(X\_1) = y。构造 X\_0，安排 M 的选择使 X\_0 产生同一结果序列：H\_{Π\_out}(X\_0) = y。

所以：AdmInv(Π\_out) = 1 ⇒ ( OutcomeSequence ⇏ Probability )。

模板二　稳定经验频率

给定概率候选 X\_1，协议 Π\_freq 记录经验频率，其极限为 H\_{Π\_freq}(X\_1) = ρ\*。构造 X\_0，使 M 的选择在同一极限下产生同一频率：H\_{Π\_freq}(X\_0) = ρ\*。

所以：AdmInv(Π\_freq) = 1 ⇒ ( StableEmpiricalFrequency ⇏ Probability )。

即便频率的极限完全精确，只要外部选择器能够复制它，仍不能识别率由谁承担。无限数据不能弥补前向映射的结构性非单射：数据越多，频率估计越准，但两个候选产生的是同一个频率。

模板三　数值率读出

给定概率候选 X\_1，协议 Π\_rate 能够准确读出各维的率值 (ρ(v\_1), …, ρ(v\_n))。构造 X\_0，使 M 按同一率值选择：两者读出的率值完全相同，H\_{Π\_rate}(X\_1) = H\_{Π\_rate}(X\_0)。

所以：AdmInv(Π\_rate) = 1 ⇒ ( NumericRateRead ⇏ Probability )。

率值不是率承担。读出的是相对生成关系的数值，概率资格要问的是这一关系由谁承担。

### 3.4 不得作的两种推断

不得写 ObservedOutcomeAbsence ⇒ DimensionAbsence。某一维在观测窗中没有兑现，不足以证明该维不存在：ρ(v\_i) = 0 ⇏ v\_i ∉ V\_P，而观测窗内未兑现又比零率更弱。

不得写 FrequencyShift ⇒ ¬Probability。概率资格不要求率值固定，也不要求经验频率稳定；频率的跨时变化属于《概率动力一般式》《概率动力数理式》《概率稳定式》。

### 3.5 干预与分离

干预可以进入观测协议，但只能条件开放。不得写 Intervention ⇒ Identification。

设协议 Π 包含一族合法干预 u，每一干预有前向映射 H\_{Π,u}。定义分离：

Sep\_Π(X\_a, X\_b) = 1，当且仅当 ∃u ∈ Π：H\_{Π,u}(X\_a) ≠ H\_{Π,u}(X\_b)

由定理一，概率资格在 Π 下普遍可识别，至少要求：

Probability(X\_1) ≠ Probability(X\_0) ⇒ ∃u：H\_{Π,u}(X\_1) ≠ H\_{Π,u}(X\_0)

干预本身不是证据。有辨识力的是"合法干预加上已成立的差异前向响应"：干预 u 下两个异资格候选的响应不同，并且这一差异由已成立的式给出。仅凭"干预以后系统变了"，不能推出概率资格。

四、上界与下界

### 4.1 定理二　观测等价上界定理

在 AdmInv(Π) = 1 下，给定 y = H\_Π(X)，只使用 y 的反演，对内部系统的最细合法分辨率是 E\_Π(y)。任何只依赖 y 的合法反演输出，都不能进一步区分同一前像中的成员。

证明

只依赖 y 的反演输出，是 y 的函数 K(y)。设 X\_a, X\_b ∈ E\_Π(y)，而 K 声称能区分二者，即对 X\_a 输出 K\_a、对 X\_b 输出 K\_b，且 K\_a ≠ K\_b。但 H\_Π(X\_a) = H\_Π(X\_b) = y，所以二者给 K 的输入相同，K(y) 只能取一个值，不能同时等于 K\_a 与 K\_b。矛盾。□

记 KnowMax\_Π(y) := E\_Π(y)。KnowMax 只是反演上界的形式名称，不是新的本体谓词。

### 4.2 定理三　概率不可辨识定理

若存在 X\_1, X\_0 ∈ D\_Π，使：

Class\_P(X\_1) = 1，Class\_P(X\_0) = 0，H\_Π(X\_1) = H\_Π(X\_0) = y

则：

NonIdent\_P^Π(y) = 1

任何只使用该协议观测的反演，都不得在这个 y 上签出 Probability = 1 或 Probability = 0。

证明

由标签的含义，Probability(X\_1) = 1、Probability(X\_0) = 0，所以 φ\_P 在 E\_Π(y) 上不恒定，由定理一的局部形式，NonIdent\_P^Π(y) = 1。再由定理二，只依赖 y 的输出 K(y) 对 X\_1 与 X\_0 相同。若 K(y) 签出 Probability = 1，则对 X\_0 为错；若签出 Probability = 0，则对 X\_1 为错。二者都在合法前像中，协议无法排除任何一个。□

这是已经证明的不可辨识，不是当前枚举不足。只要追加的材料仍属于同一个不增加分离能力的观测协议，或者扩展后的协议仍使这一对异标签候选保持观测等价，增加这类数据就不能消除这一不可辨识；若新观测引入了新的合法分离量，那已经是更强协议下的另一次反演。

条件传播：定理三自身不新增、也不继承 H2、H3^red，它以 Class\_P(X\_1) = 1 与 Class\_P(X\_0) = 0 已经成立为前提。若某一具体应用中的 Class\_P(X\_0) = 0 是由 N\_P(X\_0) = 0 经《概率一般式》必要向逆否取得，则该负标签以及依赖它的应用结论携 H2 ∧ H3^red。条件沿标签的来源传播，不进入定理三本身。

### 4.3 下界：必然不可知

由定理三：只要前像中同时存在正标签与负标签的候选，概率资格在该 y 上必然不可知。由 3.3 的三个反例模板：在只记录结果序列、经验频率或数值率的协议下，只要模板条件满足，就存在这样的 y，所以这三类协议不能普遍识别概率资格。

### 4.4 内部反演状态

InvState\_P^Π(y) ∈ { P^+，P^-，Mix，InvOpen，ClassOpen }

P^+：InvCover\_Π(y) = 1，E\_Π(y) 非空，且所有 X ∈ E\_Π(y) 都有 Class\_P(X) = 1。

P^-：InvCover\_Π(y) = 1，E\_Π(y) 非空，且所有 X ∈ E\_Π(y) 都有 Class\_P(X) = 0。

Mix：已知前像中至少有一个 Class\_P = 1 的候选和一个 Class\_P = 0 的候选。由定理三，已证不可辨识。Mix 不以覆盖闭合为前提：只要已找到两个异标签的合法成员即成立。

InvOpen：不属于 Mix，且 InvCover\_Π(y) ≠ 1，即前像没有证明查全。

ClassOpen：不属于 Mix，InvCover\_Π(y) = 1，但至少有一个候选 Class\_P = ⊥，即候选自身的概率资格尚未由上游关闭。

若 InvCover\_Π(y) = 1 而 E\_Π(y) = ∅，则观测 y 不在前向映射的像中，说明前向映射或协议有误，属于 AdmInv 层面的问题，不进入上述五种状态。

五种状态两两不相交，并覆盖 AdmInv(Π) = 1、E\_Π(y) 非空时的全部情形。

### 4.5 对外三值读出

Read^Inv\_{P,Π}(y) ∈ {1, 0, ⊥}

P^+ → 1

P^- → 0

Mix、InvOpen、ClassOpen → ⊥

⊥ 必须附原因：

Reason\_⊥ ∈ { NonIdentifiable，InverseCoverageOpen，CandidateClassificationOpen }

分别对应 Mix、InvOpen、ClassOpen。三类原因不得混写。

读出的条件：

Read = 1：前像中所有候选的正标签按其来源携带条件；当前经 N\_P = 1 取得的正标签不携 H，读出随之不携 H。

Read = 0：前像中所有候选的负标签，凡经必要向逆否取得者携 H2 ∧ H3^red；读出随之携带。

⊥ 且原因为 NonIdentifiable：这一判断依赖其中负标签候选的 Class\_P = 0；若该负标签经必要向逆否取得，则判断携 H2 ∧ H3^red。

另外，全部读出都以 AdmInv(Π) = 1 为准入，其中 ForwardMapEstablished 要求 H\_Π 有已成立的来源；H\_Π 来源所携的条件，随来源承继。

### 4.6 定理四　负读出覆盖定理

NoPositiveWitness ⇏ NegativeIdentification

即"没有找到 Class\_P = 1 的候选"不等于"所有候选 Class\_P = 0"。

Read^Inv = 0 当且仅当 InvCover\_Π(y) = 1、E\_Π(y) 非空、且所有候选都取得 Class\_P = 0。

证明

由 4.4 与 4.5 的定义，Read^Inv = 0 当且仅当状态为 P^-，而 P^- 要求覆盖闭合、前像非空、所有候选负标签。若覆盖未闭，前像中可能有未枚举的 Class\_P = 1 候选，此时签 0 可能为错；故只能签 ⊥，原因为 InverseCoverageOpen。□

同理，签出 1 也须覆盖闭合：未枚举的成员可能是负标签，从而实际状态是 Mix。

五、残余申报

### 5.1 不可知的残余

以下残余必须显式申报，不得默不申报：

NonIdentifiable（Mix）：前像中同时有概率与非概率候选。已证明不可辨识。要消除它，只能换用能够分离它们的协议（3.5），不能靠增加不提高分离能力的同类数据。

InverseCoverageOpen（InvOpen）：前像没有证明查全。这是求解上的残余，补全枚举或证明覆盖后可以消除。

CandidateClassificationOpen（ClassOpen）：前像已查全，但有候选的资格上游尚未关闭。这是上游资格的残余，由《概率判定式》等关闭候选资格后可以消除。

三者性质不同：第一种是结构性的，第二种是枚举上的，第三种是资格上的。Mix 不是普通的资料不足；InvOpen 与 ClassOpen 不合并。

### 5.2 条件账本

H\_new = ∅。

定理一至定理四作为反演定理，都不因其自身证明而继承 H2、H3^red。具体应用若使用由条件化必要向取得的负标签，条件沿该标签传播到该应用的结论：Read = 0、原因为 NonIdentifiable 的 ⊥，以及 3.3 三个反例模板中"X\_0 不是概率"的判断。条件不沿"反演式"这一名称整体传播。

ForwardMapEstablished 是反演协议的准入条件，不是普遍的本体桥，不计入 H；H\_Π 的来源所携条件，随来源承继。

### 5.3 击穿方式

上界击穿：存在同一前像中的两个候选，却有只依赖 y 的合法方法能够区分其内部结构。击穿定理二。

可识别性击穿：宣称某性质在 y 上可辨（包括 4.5 中签出 1 或 0 的读出），但存在同一前像中该性质异值的合法候选。击穿该可辨结论。

局部不可辨识结论击穿：宣称某具体协议不能识别概率资格，但该协议实际存在已成立的合法分离量，能够区分所有异资格候选。击穿 3.3 或 4.3 中相应的结论。

覆盖击穿：在前像覆盖未闭时签出 0 或 1。击穿定理四。

协议失格：所谓外部观测直接泄漏 N\_P、RateBearWitness、Probability 等内部答案。这不是主定理被击穿，而是 AdmInv(Π) = 0，反演没有进入。

不构成击穿：读出为 ⊥；上游负标签所携的 H2、H3^red 尚未关闭；在更强协议下原来的 Mix 被分离（那是另一个协议下的另一次反演）。

六、接口

### 6.1 与《概率判定式》的边界

《概率反演式》：输入既有的合法观测协议、前向映射与观测结果，回答"这些观测最多允许知道什么"。

《概率判定式》：建立或调用概率三项资格的操作检查、证书、覆盖与 1、0、⊥ 判据，回答"怎样检查一个实例是不是概率"。

所以这里不把 Read\_{N\_P}^M、RateBearWitness^M、Law 见证或 N\_P 本身当作普通外部观测；否则就把反演写成了判定，同时违反 NoInternalQualificationLeak。候选资格标签 Class\_P 由上游给出，这里只读取、不判定。

### 6.2 上承

《概率一般式》：概率资格核 N\_P 与必要向（条件化）。

《概率数理式》：禁止回读与形式对象。

《概率必然式》：充分向。

场系统与运行基底：前向映射 H\_Π 的来源。

### 6.3 下交

《概率判定式》：承接关闭 ClassOpen 所需的候选资格判定。反演读出为 ⊥ 时所附的三类原因，交该篇区分哪些残余可由资格判定消除（ClassOpen），哪些不能（Mix）。

《概率极限式》：不可辨识边界可作为观测层的资格边界参考；资格本身的边界不由反演决定。

《概率动力一般式》《概率动力数理式》《概率稳定式》：频率与率的跨时变化；这里不作推断。

### 6.4 不做的事

不回答怎样检查 N\_P 是否成立；不新增概率本体组成或第四项资格；不把经验频率、数值率、随机性、归一、正率、完整覆盖写成资格条件；不作统计估计，不引入贝叶斯先验与后验；不以最可能解释代替合法前像；不把没有找到反例写成可识别；不重新证明前六篇；不研发概率动力、稳定、来源与极限。
