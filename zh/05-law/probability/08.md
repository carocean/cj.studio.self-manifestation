# 概率判定式

对一份事前冻结的现实候选概率组织，在合法可操作的判定协议下，调用《概率数理式》的三值形式系统与上游 Law、场的接口，给出它的概率资格判词 1、0 或 ⊥，并证明：判 1 时它一定是概率；判 0 时它一定不是概率（携带所申报的条件）；不能保证正确时一律判 ⊥，并写明原因。

一、性质与观测集申报

### 1.1 性质

待判定的性质是候选的概率资格 Probability\_F,t(𝒫; C, 𝔯\_P)。它的定义已由上游闭合：

N\_P := MultiLawDimension ∧ CommonContinuationBind ∧ DomainRelativeRateBearing

充分向（《概率必然式》）：N\_P ⇒ Probability，Status = Established，不携 H。

必要向（《概率一般式》）：H2 ∧ H3^red ⇒ \[ Probability ⇒ N\_P \]；其逆否 H2 ∧ H3^red ⇒ \[ ¬N\_P ⇒ ¬Probability \]。

三项资格不增不减，不新增第四项。

### 1.2 候选实例

沿用《概率数理式》定义 3.1：

χ\_P = (F, t, 𝒫, C, 𝔯\_P, V\_P, 𝓛\_P)

这些都是申报对象，不是已取得资格的对象。V\_P、𝓛\_P、C、𝔯\_P 须在判定前冻结，判定过程中不得为通过测试而增删、缩域、换域、换位或重报。

### 1.3 观测集：判定证据分层

判定读取的是合法可操作的接口，按服务的资格项分为四层：

Y\_det = (Y\_D, Y\_C, Y\_R, Y\_cov)

Y\_D，服务于 MultiLawDimension：维登记、兑现域 D\_i、Law 形式解 𝒮(F, L, I)、职责实现 RoleReal、职责生成链、维与 Law-bearing 的绑定。

Y\_C，服务于 CommonContinuationBind：续行位身份、率域冻结协议与版本、DomainProtocol、EvidenceTime、GenSchema、合法生成实现的身份、互斥后继关系。

Y\_R，服务于 DomainRelativeRateBearing：A\_ρ^gen、GenIn、AdmVar\_ρ、Sound\_Adm、Cover\_Adm、MinSuff\_ρ、EvalRateBind^M、RateBearWitness^M，以及 set 与 measure 外层量词接口。

Y\_cov，服务于判定方法本身：各层搜索覆盖、求解完整性、负读出的完整性、外层量词可判性。

Y\_cov 不是概率的第四项资格，只决定判定方法有没有资格签出 1 或 0。

不得读取 Probability 或 N\_P 本身作为输入；不得以结果序列、稳定经验频率或数值率读出作为概率判据（《概率反演式》3.3 已证明这三类观测不能普遍识别概率资格）。

### 1.4 前向关系

性质与观测之间的前向关系由已成立的式给出：Y\_D 的读取来自《律数理式》与《概率数理式》定义 3.3—3.7；Y\_C 来自《概率数理式》定义 3.8—3.14；Y\_R 来自《概率数理式》定义 3.15—3.31；Y\_cov 来自《概率数理式》第五节的可解性条件 M1—M16。

### 1.5 与《概率反演式》的边界

《概率反演式》回答：给定既有观测，最多可以知道什么。这里回答：为判定一份现实候选，应调用哪些合法操作接口，怎样签出正式的概率判词。反演式禁止把内部资格作为外部观测，这里读取的 Law 见证、GenIn、RateBearWitness 等是合法操作接口，不是待判定的资格本身；待判定的 Probability 与 N\_P 仍不作输入。

二、判据构造

### 2.1 三层短路

沿用《概率数理式》的求解顺序：

D\_1 := MultiLawDimension^M

D\_2 := CommonContinuationBind^M

D\_3 := DomainRelativeRateBearing^M

Read\_{N\_P}^M 按三值短路取值：

D\_1 = 0 ⇒ Read = 0

D\_1 = 1，D\_2 = 0 ⇒ Read = 0

D\_1 = D\_2 = 1，D\_3 = 0 ⇒ Read = 0

D\_1 = D\_2 = D\_3 = 1 ⇒ Read = 1

当前必须求解的层为 ⊥，且此前没有合法的决定性 0，则 Read = ⊥。不得越过前层的 ⊥ 去下层寻找 0。

### 2.2 维见证搜索覆盖

对每一维 v\_i，定义：

DimWitnessCover^Π(v\_i) = 1：当前冻结的搜索域覆盖了一切有资格成为该维结构层 Law-bearing 见证的合法候选，或由等价代表覆盖。

它是判定方法层的覆盖条件，不是新的概率本体条件。

### 2.3 路径判定域与完全判定域

PathDom：用于具体候选的实际判定。只要求当前实际走过的判定路径，其输入、搜索覆盖与负读出证书充分。若第一层已经合法判 0，不要求后两层的可解性条件可用。

FullDetDom：用于说明判定器在某个工作域内具有完整决定能力。它要求三层中任何可能访问的接口、搜索域、身份读取、来源链、率承担诊断、极小充分组与外层量词都足够完整：整体引用《概率数理式》M1—M16，并补入各维的 DimWitnessCover。

PathDom 与 FullDetDom 都是判定方法层的条件，不是概率资格条件，不进入 N\_P。

### 2.4 率承担判定域

DetDom\_ρ(ν) 由《概率数理式》的可解性条件按功能组成：

GenFactorCover：真实生成因子域可以取得（M9）；

SourceCover：生成来源链可以追踪（M10）；

Sound\_Adm = 1 ∧ Cover\_Adm = 1：合法诊断变化族忠实且完整（M11）；

MinSuffSolvable = 1：比较可判，极小充分组存在且可求（M12、M13）；

ActualRealizationCover = 1：评价内合法实现与 B1—B4 可核（M14）；

DomainQuantifierDecidable = 1：set 与 measure 外层量词可判（M15）；

以及 M16：所有 0 都有完整负读出依据。

这些都是判定方法层条件，不进入概率本体。

### 2.5 最终判定器

Det\_P^Π(χ\_P) ∈ {1, 0, ⊥}

它是最终的概率判词，不等同于形式读数 Read\_{N\_P}^M：

Det\_P = 1：Read\_{N\_P}^M = 1，且所用各 Law 见证的正向回读条件 H\_LawRead(W\_i) 已关闭。

Det\_P = 0：Read\_{N\_P}^M = 0 且为结构零（StructuralZero，见 3.5），失败所在路径的负向表示已经关闭（第三节），并且 H2 ∧ H3^red 已关闭。

Det\_P = ⊥：其余情形，并附原因。

### 2.6 ⊥ 的原因

InputOpen：现实输入或身份接口不足。

DeclarationInvalid：形式读数 0 只来自冻结申报实例的失格（DeclarationZero），须重新申报。

DimWitnessCoverOpen：维 Law-bearing 的搜索覆盖未闭。

UpstreamLawOpen：上游 Law 资格、正向回读条件 H\_LawRead 或负端条件束 H^-\_M 未关闭。

BindReadOpen：共同续行位、率域或生成关系身份不可判。

RateCoverOpen：生成因子、来源链、诊断变化、极小充分组或评价内实现的覆盖未闭。

RateRepOpen：率承担的负向表示条件 H\_ρRep^- 未关闭（2.7、3.4）。

DomainQuantifierOpen：set 或 measure 外层量词不可判。

OntologyBridgeOpen：已经得到 N\_P = 0，但 H2、H3^red 未关闭，不能正式签 Probability = 0。

这些原因不得合写为笼统的"材料不足"。

### 2.7 两座负向表示桥

负判需要反向表示：结构层某项成立时，形式层在判定域内一定能取得相应的正读数。上游只证明了正向回读。这里需要的两座反向桥是：

H\_DimRep^-：维 Law-bearing 的负向表示。其内容与状态见 3.2。

H\_ρRep^-：率承担的负向表示。其内容与状态见 3.4。

三、判据有效性证明

### 3.1 真则判真，在正向：判 1 则真

定理一　正判有效定理

Det\_P = 1 ⇒ Probability = 1

证明

由 2.5，Det\_P = 1 蕴含 Read\_{N\_P}^M = 1，且所用见证的 H\_LawRead 已关闭。由《概率数理式》(7.5)，Read\_{N\_P}^M = 1 ⇒ N\_P = 1，条件为所用见证的 H\_LawRead，已关闭。由《概率必然式》，N\_P ⇒ Probability，不携 H。故 Probability = 1。□

定理一不携 H2、H3^red。

### 3.2 维资格负向完备

定理二　维见证负向表示定理

设 DetDom\_Dim(v\_i) := DimWitnessCover^Π(v\_i) = 1 ∧《概率数理式》M2 ∧ M3 成立：上游 Law 形式接口可用，并且兑现域 D\_i 的后继归属可以有效判断。候选实例的可识别性 M1 作为全篇判定的统一准入，不在各局部定理中重复。则：

DetDom\_Dim(v\_i) ∧ DimQual(v\_i) = 1 ⇒ DimQual^M(v\_i) = 1　\[H^-\_M，按见证承继\]

逆否：

DetDom\_Dim(v\_i) ∧ DimQual^M(v\_i) = 0 ⇒ DimQual(v\_i) = 0　\[H^-\_M，按见证承继\]

证明

DimQual(v\_i) = 1，即结构层存在 L、I、C\_i，使 Law(L, I) = 1 且 BearDim(L, v\_i; C\_i)。由 DimWitnessCover，这一 Law-bearing 或其等价代表在搜索域中。要使它在形式层得到 R ∈ 𝒮(F, L, I)，须由结构层的 Law 资格推出其形式解集非空：这正是《律边界式》定理 5.1(ii) 的逆否，在该篇定义 5.2 的负端条件束 H^-\_M = C0 ∧ C2 ∧ H2 ∧ H3 ∧ H\_RepC ∧ H\_RepN ∧ H\_RepD ∧ H\_RepΩ ∧ H\_RepBind 下成立，按见证逐一承继。这里直接承继上游现成的负端条件束，不自行枚举：H\_RepR、H\_RepReplay 与 H1 不在其中。BearDim 一项由职责实现与生成链的直接读取给出（《概率数理式》定义 3.4 与 M2）。由此 R 在 𝒲\_Dim(v\_i) 中，DimQual^M(v\_i) = 1。逆否即得第二式。□

H\_DimRep^- 的内容就是定理二。它在 DimWitnessCover 之下已归约到上游《律边界式》的负端条件束 H^-\_M；这里不另立新的未决条件，其状态随 H^-\_M 而定：H^-\_M 关闭，H\_DimRep^- 即关闭。

申报失败不等于结构失败：

DeclarationFail ≠ StructuralFail

𝓛\_P 中某一登记 W\_i 失效，只说明当前冻结申报中的这一登记失效。若 DimWitnessCover 未闭，不得据此断言现实不存在其他合法 Law-bearing；漏登记只能导致覆盖未闭，读数为 ⊥，不能自动导致结构 0。

定理三　MultiLawDimension 负向回读定理

DetDom\_1 按失败所在的分项取用，只要求实际走过的路径（与 2.3 的 PathDom 一致）：由 Card^M = 0 取得的 0，只要求 V\_P 可完整列举；由 DistAll^M = 0 取得的 0，只要求相应兑现域的交集可判；由某一 DimQual^M(v\_i) = 0 取得的 0，只要求该维 DetDom\_Dim(v\_i) = 1。不要求其余各维的 DetDom\_Dim 都成立。则：

DetDom\_1 ∧ MultiLawDimension^M = 0 ⇒ MultiLawDimension = 0

条件：若 0 来自 DimCover^M 中 DimQual^M = 0 的一项，携该维见证的 H^-\_M；若来自 Card^M 或 DistAll^M，不携条件。定理只对下述结构零成立；由 RegValid^M = 0 单独造成的申报零不适用。

证明

MultiLawDimension^M = Card^M ∧₃ DistAll^M ∧₃ DimCover^M（《概率数理式》定义 3.7），为 0 时至少有一项为 0。

Card^M = 0：V\_P 可完整列举而 \|V\_P\| \< 2，结构层 MultiLawDimension 的 \|V\_P\| ≥ 2 不成立。

DistAll^M = 0：某一对维的兑现域交集非空且可判，结构层的可区分性不成立。

DimCover^M = 0：若来自某一 DimQual^M(v\_i) = 0，由定理二，DimQual(v\_i) = 0，该维没有结构层 Law-bearing。若只来自 RegValid^M = 0，按《概率数理式》定义 3.6—3.7，形式读数仍为 0，这里不改动该定义；但这个 0 只说明冻结申报的登记族不合定义，属于申报零（见 3.5），不经本定理回读为结构 0。

前三种结构失败都使 MultiLawDimension = 0。□

### 3.3 共同绑定负向回读

定理四　CommonContinuationBind 负向回读定理

DetDom\_2 由 D\_1 = 1 与下列身份读取组成：续行位身份、DomainProtocol、EvidenceTime、FreezeTime、GenSchema 与事件身份（《概率数理式》M4、M5）。D\_1 = 1 列入前提，因为第二层的三项绑定都对 𝓛\_P 量化，须在第一层已经合法通过、登记族合格之后才能求值。与 2.3 的 PathDom 一致，身份读取按失败分项取用：由 SameContinuationPosition^M = 0 取得的 0，只要求续行位身份可取得；由 SameGenerationDomain^M = 0 取得的 0，只要求协议标识与时点可取得；由 SameGenerationRelation^M = 0 取得的 0，只要求 GenSchema 与事件身份可取得。则：

DetDom\_2 ∧ CommonContinuationBind^M = 0 ⇒ CommonContinuationBind = 0

不携条件。

证明

CommonContinuationBind^M 的三项都是对结构分量的直接身份、协议与事件关系的表示（《概率数理式》定义 3.11—3.13 与 7.3 的说明）。在 DetDom\_2 下，形式层的 0 对应明确的结构反见证：

SameContinuationPosition^M = 0：存在登记使 C\_i ≠ C；

SameGenerationDomain^M = 0：存在不同 DomainProtocol 的证据事后拼接，或冻结记录显示事后修改；

SameGenerationRelation^M = 0：存在 GenSchema 不同的实现，或同一生成事件同时兑现两维。

每一种都是结构层相应分量的失败。□

### 3.4 率承担负向完备

定理五　率承担负向表示定理

设 DetDom\_ρ(ν) 成立。则：

DetDom\_ρ(ν) ∧ RateBearing(ν) = 1 ⇒ RateBearWitness^M(ν) = 1　\[H\_ρRep^-\]

逆否：

DetDom\_ρ(ν) ∧ RateBearWitness^M(ν) = 0 ⇒ RateBearing(ν) = 0　\[H\_ρRep^-\]

其中 H\_ρRep^- 为：在 DetDom\_ρ(ν) 下，申报组织中任一在评价 ν 中实际进入 Rel\_ρ 形成的生成因子，属于某一 B ∈ MinSuff\_ρ(ν)。

证明

设 RateBearing(ν) = 1：申报 Law-bearing 组织的合法承重状态真实进入评价 ν 中 Rel\_ρ 的形成。

第一步，由 GenFactorCover，承重所经的实际生成贡献出自某一生成因子 a ∈ A\_ρ^gen(ν)。

第二步，由 SourceCover，存在 W\_i ∈ 𝓛\_P，a ∈ GenIn(W\_i, ν)。

第三步，由 Sound\_Adm、Cover\_Adm 与 MinSuffSolvable，MinSuff\_ρ(ν) 相对于真实合法变化域存在且可求。要得到 B ∈ MinSuff\_ρ(ν) 使 B ∩ GenIn(W\_i, ν) ≠ ∅，还需要：这一实际进入形成的因子 a 属于某一极小充分组。这正是 H\_ρRep^- 的内容。它不能由前两步或覆盖条件推出：在联合与冗余承担中，一个真实参与生成的因子，可能在任何包含它的充分组中都不是必需的（其作用被组内其他因子完全决定），此时它不在任何极小充分组内。结构层"真实进入形成"与形式层"极小充分组成员"之间的这一对应，上游《概率数理式》只证明了由后者到前者（其定理 7.2），这里需要的是由前者到后者。

第四步，在 H\_ρRep^- 下取 a ∈ B ∈ MinSuff\_ρ(ν)。由于 RateBearing(ν) 是评价 ν 中的真实承担而非备用能力，由 ActualRealizationCover，B1—B4 可核并成立，EvalRateBind^M(W\_i, ν, e\_ν) = 1。

于是 RateBearWitness^M(ν) = 1。□

说明：

不要求所有极小充分组都含申报组织的因子，只要求存在一个与其实际贡献相交；因此允许热冗余。

冷备用在该评价中不实际进入形成，不能取得当前评价的 RateBearWitness。

外部机制独立承担时，申报组织不因"有承担能力"而被判为承担。

H\_ρRep^- 状态：待验。它与《概率作用数理式》的 H\_PAct-Rep 是同一类反向表示命题，只是一个在资格评价 ν 上，一个在现实当前评价 ν\_t^cur 上；二者应一并在《概率数理式》的反向表示中关闭。

无限极小充分组：若无限生成因子域中不能保证极小充分组存在或可求，MinSuffSolvable ≠ 1，相关判定为 ⊥（原因 RateCoverOpen），不得写成 RateBearing = 0。这只是退出完整判定域，不是概率的结构失败。

measure 模式：DomainEvalMode = measure 时，整个率域上的承担用 a.e. 全称。单个零测失败点不能击穿整个率域的承担；单个零测成功点不能建立存在型结论；只有正测度的失败集才能使 measure 型全称失败。μ\_r 只用于率域评价量词，不得与生成权重或测度 μ\_{C,ν} 混用。

定理六　DomainRelativeRateBearing 负向回读定理

DetDom\_3 由 D\_1 = D\_2 = 1 与下列各项组成：率域的冻结、非空、非空洞、系统侧根据可判（《概率数理式》M5、M6）；Rel\_ρ 表示接口可用（M7、M8）；各评价 DetDom\_ρ(ν) 成立、外层量词可判。D\_1 = D\_2 = 1 列入前提，因为率承担是在前两项都保持之后才进入的。与 2.3 的 PathDom 一致，其余前提按失败分项取用：由 RateDomainQual^M 取得的 0，只要求 M5、M6；由 RelForm^M 取得的 0，只要求 M7、M8；由率域聚合取得的 0，要求各相关评价的 DetDom\_ρ(ν) 与外层量词可判。则 DomainRelativeRateBearing^M = 0 时：

若 0 来自 RateDomainQual^M 的明确结构反见证（冻结记录显示事后修改、ℰ\_r 为空、无可实现的系统实现、实现来源不属于 F、跨协议拼接），则 DomainRelativeRateBearing = 0，不携条件；

若 0 来自 RelForm^M 在接口完整时的明确失败（相对生成关系在生成侧不能形成），则 DomainRelativeRateBearing = 0，不携条件；

若 0 来自完整率域聚合后的 RateBearWitness^M\_{𝔯\_P} = 0，即按外层量词有非零测度（set 模式为至少一个）评价 ν 使 RateBearWitness^M(ν) = 0，则由定理五，这些评价中 RateBearing(ν) = 0，结构层率承担在 𝔯\_P 上不成立，DomainRelativeRateBearing = 0，携 H\_ρRep^-。

若只是来源链不可得、AdmVar 覆盖未闭、极小充分组不可求、measure 量词不可判或生成侧表示接口不足，读数为 ⊥，不是 0。

证明：由《概率数理式》定义 3.29—3.31 与定理五，逐项对应。□

### 3.5 形式资格完整表示

结构零与申报零

Read\_{N\_P}^M = 0 按来源分为两类：

StructuralZero：决定性的 0 来自某一层的结构反见证，即定理三中的 Card、DistAll、DimQual 失败，定理四中的三项绑定失败，或定理六中的三种失败。

DeclarationZero：决定性的 0 只来自冻结申报实例的失格，当前即 RegValid^M = 0 单独造成的 0。

形式读数不作改动；两类零的区分只在判定层进行。只有 StructuralZero 可以回读为 N\_P = 0；DeclarationZero 不足以回读结构零，最终判词为 ⊥，原因 DeclarationInvalid，须重新申报。

定理七　形式资格完整表示定理

(a) 正向（已有）：Read\_{N\_P}^M = 1 ⇒ N\_P = 1　\[所用见证的 H\_LawRead\]

(b) 负向：若 Read\_{N\_P}^M = 0 为 StructuralZero，且失败所在层满足相应的判定域（DetDom\_1、DetDom\_2 或 DetDom\_3），则 N\_P = 0。条件随失败路径：第一层来自 DimQual 者携 H^-\_M，第三层来自率承担者携 H\_ρRep^-，其余不携条件。

(c) 在 FullDetDom 下，申报实例合格（不出现 DeclarationZero），并在 H\_LawRead、H^-\_M 与 H\_ρRep^- 关闭时：Read\_{N\_P}^M = N\_P。

证明

(a) 为《概率数理式》(7.5)。

(b) 由 2.1，Read = 0 来自某一层的决定性 0，其前各层都为 1；按前提它是 StructuralZero。失败在第二层时，D\_1 = 1 已满足 DetDom\_2 的前提；失败在第三层时，D\_1 = D\_2 = 1 已满足 DetDom\_3 的前提。由定理三、四、六，该层在相应判定域下对应结构层的失败，按各定理所列条件携带。

(c) 在 FullDetDom 下每一层都可判，不出现 ⊥。若 N\_P = 1，则三项结构都成立：由定理二（经 H^-\_M）第一层形式读数为 1；由定理四的逆否（结构成立则不会出现结构反见证），第二层不为 0，又由 FullDetDom 保证 DetDom\_2 成立、不出现 ⊥，故为 1；由定理五（经 H\_ρRep^-）各评价的 RateBearWitness^M 为 1，并由 RateDomainQual 与 RelForm 的直接表示，第三层为 1；于是 Read = 1。若 N\_P = 0，由 (a) 的逆否 Read ≠ 1，又在 FullDetDom 下 Read ≠ ⊥，故 Read = 0。□

### 3.6 假则判假，在负向：判 0 则假

定理八　负判有效定理

Det\_P = 0 ⇒ Probability = 0　\[H2 ∧ H3^red；并随失败路径携 H^-\_M 或 H\_ρRep^-\]

证明

由 2.5，Det\_P = 0 蕴含 Read = 0 且为 StructuralZero、失败路径的负向表示已关闭、H2 ∧ H3^red 已关闭。由定理七 (b)，N\_P = 0。由《概率一般式》必要向的逆否，在 H2 ∧ H3^red 下，Probability = 0。□

若 N\_P = 0 已经成立而 H2、H3^red 未关闭，最终判词为 ⊥，原因 OntologyBridgeOpen。若失败路径所需的 H^-\_M 或 H\_ρRep^- 未关闭，判词为 ⊥，原因分别为 UpstreamLawOpen 或 RateRepOpen。若 Read = 0 只是 DeclarationZero，判词为 ⊥，原因 DeclarationInvalid。

元层说明：由充分向的逆否，可以不携 H 得到 ¬Probability ⇒ ¬N\_P，即真正的非概率必有结构失败。但这不能代替判定器从 N\_P = 0 走到 Probability = 0 所需的必要向条件。

四、误判界申报

这里不引入统计误判率。判定纪律是：不能保证正确时退到 ⊥。

正判域：由定理一，FalsePositive = 0，条件为所用见证的 H\_LawRead 已关闭（这已写进 Det\_P = 1 的定义）。

负判域：由定理八，在 H2 ∧ H3^red 已关闭，且失败路径所需的 H^-\_M 或 H\_ρRep^- 已关闭时，FalseNegative = 0（这也已写进 Det\_P = 0 的定义）。

不能两全之处：在当前上游状态下，H2、H3^red、H\_ρRep^- 与《律边界式》的负端条件束 H^-\_M 尚未关闭。依赖它们的负判，一律退到 ⊥，并附 OntologyBridgeOpen、RateRepOpen 或 UpstreamLawOpen。所以当前判定器在负方向的覆盖范围小于正方向：它不会误判，但会有较多的 ⊥。这是显式申报的误判界，不是判定器的错误。

真正的判定边界是可判域，不是统计置信区间。

五、判定定理

### 5.1 完全判定定理

定理九　完全判定定理

在 FullDetDom 下，申报实例合格，并在 H\_LawRead、H^-\_M、H\_ρRep^-、H2、H3^red 均关闭时：

Probability = 1 ⇒ Det\_P = 1

Probability = 0 ⇒ Det\_P = 0

结合定理一与定理八：

Det\_P = Probability

在二值资格域上成立；域外保留 ⊥。

证明

Probability = 1：由《概率一般式》必要向（H2 ∧ H3^red），N\_P = 1；由定理七 (c)，Read = 1；所用见证的 H\_LawRead 已关闭，故 Det\_P = 1。

Probability = 0：由充分向的逆否，N\_P = 0；由定理七 (c)，Read = 0；申报实例合格，所以这个 0 是结构零而非申报零；失败路径所需的负向表示条件与 H2 ∧ H3^red 都已关闭，故 Det\_P = 0。□

不宣称所有物理系统都落入 FullDetDom。

### 5.4 击穿方式

正判误杀：存在 Det\_P = 1 而 Probability = 0。

负判误杀：在申报的负判条件全部成立时，存在 Det\_P = 0 而 Probability = 1。

维见证覆盖击穿：声明 DimWitnessCover = 1，现实却存在合法的 BearDim 见证而 DimQual^M = 0，且 H^-\_M 成立。

率承担完备击穿：在 DetDom\_ρ 与 H\_ρRep^- 下，真实 RateBearing = 1 而 RateBearWitness^M = 0。

⊥ 到 0 越界：接口、来源链、极小充分组、measure 量词或搜索覆盖未闭却签 0。

申报替代现实：仅因登记漏失或错误就声称现实不存在结构见证。

量词极性错误：把 RateBearWitness 的存在极性改成全称，或把率域的全称、a.e. 聚合改成存在。

资格越界：把归一、正率、稳定频率、完整后继覆盖写成概率资格条件。

### 5.5 回归测试

以下只作回归检验，不作一般证明。

测试 1　正例：两维 Law-bearing、同位同域同次生成、申报组织实际承担相对生成，各层可判，H\_LawRead 关闭。Det\_P = 1。

测试 2　单维：V\_P 可完整列举，\|V\_P\| = 1。第一层 0，不携条件；H2 ∧ H3^red 未关闭时 Det\_P = ⊥（OntologyBridgeOpen），关闭时 Det\_P = 0。

测试 3　漏登记：𝓛\_P 漏登某维的实际 Law-bearing，DimWitnessCover 未闭。Det\_P = ⊥（DimWitnessCoverOpen），不是 0。

测试 3b　登记失格：𝓛\_P 中某一登记没有对应见证，各维 DimQual^M 都为 1。RegValid^M = 0，形式读数为 0，属申报零。Det\_P = ⊥（DeclarationInvalid），须重新申报。

测试 4　跨协议拼接：证据来自不同 DomainProtocol。第二层 0，不携条件；终判随 H2 ∧ H3^red。

测试 5　外部选择器：外部机制决定全部率，申报组织只执行结果。各评价 RateBearWitness^M = 0；在 H\_ρRep^- 未关闭时 Det\_P = ⊥（RateRepOpen）。

测试 6　热冗余：两个机制都足以承担，申报组织的因子在某一极小充分组中且实际绑定。第三层 1，Det\_P = 1。

测试 7　冷备用：申报组织只是备用。该评价中不取得 RateBearWitness；负判随 H\_ρRep^-。

测试 8　无限因子域：极小充分组不可求。Det\_P = ⊥（RateCoverOpen）。

测试 9　measure 零测失败：零测评价集上 RateBearWitness^M = 0，其余 a.e. 为 1。第三层 1。

测试 10　稳定频率：只有稳定经验频率，没有 Y\_R 接口。Det\_P = ⊥（InputOpen）；不得以频率判定。
