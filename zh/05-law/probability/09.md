# 概率极限式

在已经闭合的概率资格结构上，沿事先声明的合法比较方向作极限审查，确定两件事：通常被当作"概率性"的那些数值、统计、覆盖、随机与表示属性，退到极端时概率资格是否仍然保持；概率资格真正不可越过的边界在哪里，越过以后退化成什么。

结论是：率为零、各向同性、完全确定、数值不可读，这些端点都与概率资格相容；申报维对完整后继的覆盖不完全，不构成资格边界，而整个率域上的零覆盖不能保持 N\_P = 1；覆盖能否在真实实现中任意逼近零，目前开放；在当前条件闭合域内（H2 ∧ H3^red 下），概率资格的硬界落在三项资格结构上，越界只有三种基本退化。概率的极限不变量不是概率值，而是概率资格结构。

一、基本设定

### 1.1 上游冻结结论

N\_P := D ∧ B ∧ R，其中 D := MultiLawDimension，B := CommonContinuationBind，R := DomainRelativeRateBearing。共同绑定记作 B，以免与续行位 C 混淆。

充分向（《概率必然式》）：N\_P ⇒ Probability，Status = Established，不携 H。

必要向（《概率一般式》）：H2 ∧ H3^red ⇒ \[ Probability ⇒ N\_P \]。

合得：H2 ∧ H3^red ⇒ \[ Probability ⇔ N\_P \]。两向的条件不同：进入方向不携 H，退出方向携 H2 ∧ H3^red。以下不洗掉这一不对称。

《概率一般式》已把极限式的任务下交为：在预声明的合法比较方向上确定资格边界，包括维资格退出、共同绑定失效与率承担失效；并禁止把零率、RateRead = ⊥、覆盖不完全自动写成资格边界。

### 1.2 冻结资格语义域

记 Σ\_P^cur 为当前封版的《自显论》与《概率组式》所冻结的概率当前资格语义域。它是证明域的限定，不是本体谓词、场量、第四项资格或 H。

以下所说的"硬界""不可再还原""精确资格边界"，都只相对于 Σ\_P^cur。若以后出现新的独立职责，并满足《概率一般式》的重开条件，上游与这里一并受控升版。

### 1.3 极限比较协议

Π\_Lim = (Σ\_P^cur, A, Ord\_A, E\_A, Fix\_A)

A：本次比较的轴。每一项极限结论都须事先声明比较哪一个轴：率值、单维零率、各向异性、完整覆盖、随机与确定、数值可读性、维规模，或某一资格结构项。不得同时移动多个轴，再把结果归给其中一个。

Ord\_A：该轴的退化方向，例如率值下降到零、各向异性下降到零、覆盖下降到零。

E\_A：所申报的端点或边界（记作 E\_A，以免与共同绑定 B 混淆）。须区分四种：端点可达；端点只能任意逼近；开放软区间；越过资格边界。

Fix\_A：比较中须固定的身份与协议。概率的含义保持在同一 Σ\_P^cur；比较轴不是维数时，不增删 V\_P；在同一候选内比较时，不换续行位 C，不换冻结率域 𝔯\_P；比较族由不同候选组成时，须事先冻结比较族协议，每一成员的续行位与率域各在检验前冻结，不得看见结果以后选取成员或重切域；不跨 DomainProtocol；不改分辨协议；不事后删去不利结果；不把不同条件、不同生成事件拼成一条极限序列。

### 1.4 极限方向与极限条件

极限方向：沿 Ord\_A，把比较轴推向其退化端。

极限条件：比较族 {χ\_α} 中每一成员都满足 Fix\_A，并都处在 Σ\_P^cur 的资格语义下；比较族由合法候选、合法实例或合法表示组成。

### 1.5 比较不是动力

{χ\_α} ≠ χ(t\_0) → χ(t\_1)

比较的是一族合法候选或表示，不是同一个系统怎样从一个状态变到另一个状态。这里不说明率怎样下降、某维怎样出现或消失、资格是否保持或恢复；这些属于《概率动力一般式》《概率动力数理式》《概率源式》《概率稳定式》。

LimitComparison ≠ ProbabilityDyn

### 1.6 可达的含义

这里所说"端点可达"，指该端点与 N\_P = 1 在资格语义上相容：N\_P 的三项结构定义中，没有任何一项排除该端点，所以处在该端点、且 N\_P = 1 的合法候选一定是概率。它不断言某一具体物理实现已经存在；实现的构造属于《概率运行基底构造式》。"端点只能逼近"，指存在任意接近端点、且 N\_P = 1 的合法候选，而端点本身与 N\_P = 1 不相容；这是存在性结论，须有真实的资格见证。"开放软区间"，指某一非端点的退化范围不构成资格边界（其中的值与 N\_P = 1 相容），但尚未证明存在 N\_P = 1 的候选能一直逼近端点。

二、不可避免性论证

为什么极限审查必然落到 D、B、R 三项上，而不是落到率值、频率、覆盖或随机性上？

第一，软极限侧。N\_P 是本组式当前闭合的资格充分核。由充分向，任何比较族只要逐项保持 N\_P = 1，就逐项保持 Probability = 1，无论比较轴走到哪里；这一侧不携 H。

第二，硬界穷尽侧。只有在 H2 ∧ H3^red 下，资格退出才必然落为 N\_P = 0：此时 Probability ⇔ N\_P，所以任何从资格内部走到资格外部的比较，都必然使 D、B、R 中至少一项由 1 变 0，一个外围属性要成为资格边界，只能通过破坏 D、B、R 之一来实现。不携 H 时，只能断言保持 N\_P 就保持资格，不能断言资格退出必经 D、B、R。

第三，因此在 H2 ∧ H3^red 下，任何比较轴只有两种可能：它的退化端与 N\_P = 1 相容，这时它是软极限，资格保持；或者它的退化端迫使 D、B、R 中某一项失败，这时它越过硬界，而越界的原因是那一项结构，不是该轴本身。

这一分叉在 Σ\_P^cur 内、H2 ∧ H3^red 下不可避免。

三、核心定义

### 3.1 软极限

某一不属于 N\_P 的属性，其退化端（或趋近退化端的每一值）与 N\_P = 1 相容。分为：

ReachableEndpoint：端点本身与 N\_P = 1 相容。

ApproachableEndpoint：对任意 ε \> 0，存在距端点 ε 以内、且 N\_P = 1 的合法候选，而端点本身与 N\_P = 1 不相容。这是存在性结论。当前没有已经证明的实例。

OpenSoftRange（开放软区间）：某一非端点的退化范围内的值与 N\_P = 1 相容，不构成资格边界；但是否存在 N\_P = 1 的真实候选一直逼近端点，尚未证明。

### 3.2 硬界

使 Probability 由 1 退出的结构资格边界。在 Σ\_P^cur 内，并在 H2 ∧ H3^red 成立时，当前硬界由 N\_P 三项结构的失效刻画。不携这一条件时，只能使用 N\_P = 1 ⇒ Probability = 1，不得由 N\_P = 0 无条件签出资格退出。

### 3.3 辅助比较量

以下只是比较用的辅助量，不是概率的本体量：

各向异性（两维 weight 模式）：A\_ρ := \|w\_1 − w\_2\| / (w\_1 + w\_2)；

完整覆盖：Coverage := Σ\_i ρ\_i^full，其中 ρ\_i^full = w\_i / M\_C，M\_C 为完整后继生成质量（《概率数理式》定义 3.20）。Coverage 只在 weight 模式、且 M\_C \> 0 时有定义；struct 模式下没有这一量，也不作这一轴的比较。

### 3.4 越界退化类

以下是极限分类标签，不是新的本体谓词：

Deg\_D：D = 0。

Deg\_B：D = 1，B = 0。

Deg\_R：D = B = 1，R = 0。

四、结构刻画

### 4.1 资格区与其边界

在 Σ\_P^cur 内，并在 H2 ∧ H3^red 下，资格区 { Probability = 1 } 与 { N\_P = 1 } 是同一集合。所以资格的进入与退出，都由 N\_P 的三项结构刻画。不携 H 时，只能断言 { N\_P = 1 } ⊆ { Probability = 1 }。

### 4.2 越界区的划分

{ N\_P = 0 } 恰好被划分为 Deg\_D、Deg\_B、Deg\_R 三类，两两不相交，并覆盖全部：

N\_P = 0 当且仅当 D、B、R 至少一项为 0。按第一个失败项分类：D = 0 为 Deg\_D；D = 1 而 B = 0 为 Deg\_B；D = B = 1 而 R = 0 为 Deg\_R。三类的判别条件互斥，且穷尽了至少一项为 0 的一切情形。这与《概率数理式》的三层求解顺序一致：后一项在前一项成立之后才有意义。

### 4.3 软极限轴上的等价类

在 weight 模式中，相对生成关系是正比例等价类 \[w\]\_ρ（《概率数理式》定义 3.17—3.19）。各维权重整体按比例缩放，只是更换同一个相对生成关系的代表，\[w\]\_ρ 不变。所以权重的绝对大小 Σ\_i w\_i 在没有额外冻结标尺时不是表示不变的量，不作为极限轴；有意义的是相对于完整后继生成质量的比值 Coverage = Σ\_i w\_i / M\_C。它是下文完整覆盖一轴的比较量。

五、主结论

### 5.1 定理一　软极限保持定理

在 Π\_Lim 下：

(i) 单维零率、零各向异性、完全确定、数值不可读，四个端点都是 ReachableEndpoint；

(ii) 完整覆盖：0 \< Coverage \< 1 是 OpenSoftRange，部分覆盖不构成资格边界；

(iii) 在整个率域上 Coverage = 0（按 DomainEvalMode 的全称或 a.e.）与 N\_P = 1 不相容。

覆盖能否由 N\_P = 1 的真实候选任意逼近零，这里不作结论，列为开放问题。

所以上述属性都不是当前概率资格的硬界。

证明

(i) 单维零率。设 V\_P = {v\_1, v\_2}，ρ = (1, 0)。D 要求 \|V\_P\| ≥ 2、各维可区分、各维取得正式 Law-bearing（《概率一般式》对 MultiLawDimension 的定义），不要求各维的率为正；B 要求同位、同域、同一生成关系，不涉及率值；R 要求组织承担相对生成关系，零类之外的任何比例都是合法的相对生成关系，(1, 0) 不是零类。三项都不排除 ρ(v\_2) = 0。所以该端点与 N\_P = 1 相容；处于该端点而 N\_P = 1 的候选，由充分向是概率。《概率必然式》9.2 已有同一结论。

零各向异性。取 w = (1, 1)，A\_ρ = 0。D、B、R 都不要求率值不等；《概率一般式》没有得到 Probability ⇒ Anisotropy。所以相容。

完全确定。设 x = a ⇒ v\_1，x = b ⇒ v\_2，单次执行完全确定。D、B 与执行是否确定无关；R 问的是 x 的生成比例及到各维的相对生成由谁承担，不问执行是否可预测。当 x 的比例由组织自身形成时，R 可以成立。所以相容。《概率必然式》9.3 已有同一结论。若 x 的比例完全由组织之外的机制决定，失败的是 R，不是"太确定"。

数值不可读。《概率数理式》允许 RelRepMode = struct：相对生成关系只有结构表示 R\_ν^struct，没有合法数值权重。R 要求的是相对生成关系由组织承担，不要求该关系可以数值读出。所以 NumericRateRead = ⊥ 与 N\_P = 1 相容。

(ii) 部分覆盖。N\_P 的三项结构中，没有任何一项要求申报维覆盖全部后继：D 与 B 不涉及覆盖；R 要求相对生成关系由组织承担，不要求这一关系穷尽全部后继。《概率一般式》没有取得 Probability ⇒ FullCoverage；《概率必然式》明确把"是否覆盖全部后继"排除在第四项资格之外；《概率数理式》已允许 Σ\_i ρ\_i^full \< 1，并规定域外残余不得补成未知维、停止维或其他概率维。所以 0 \< Coverage \< 1 与 N\_P = 1 相容：处在部分覆盖、且 N\_P = 1 的候选一定是概率，Coverage \< 1 不能推出 ¬Probability。

这里只作相容性陈述，与 (i) 的可达端点同一口径，不断言对某一个具体的覆盖值存在真实的 N\_P = 1 候选。

为什么不进一步断言覆盖的下确界为 0：那需要对任意 ε \> 0 给出一份 N\_P = 1、且 0 \< Coverage \< ε 的见证。N\_P 的三项都含现实结构的内容，R 尤其要求率域具有系统侧的实际生成根据；生成权重与合法生成实现须由场系统或运行基底给出（《概率数理式》）。不能在一个尚无物理实现的模式内部直接规定各维已经取得 Law-bearing、率已经被真实承担，再据此签出 N\_P = 1。所以在《概率运行基底构造式》完成以前，逻辑上仍可能存在某个 0 \< c\* \< 1，使一切真实的 N\_P = 1 候选都有 Coverage ≥ c\*；这样的下界即使存在，也不是资格的定义项，只是物理实现空间的事实。它是否存在，交该篇构造：若能对任意 ε \> 0 构造真实合法的实现，使 N\_P = 1 且 0 \< Coverage \< ε，覆盖轴即升级为 ApproachableEndpoint。

(iii) 覆盖为零的端点。设 weight 模式下每一评价有 M\_C(ν) \> 0，并且按 DomainEvalMode（set 模式为一切 ν，measure 模式为 a.e.）都有 Coverage(ν) = 0。由于各项非负，Σ\_i ρ\_i^full(ν) = 0 推出每一 ρ\_i^full(ν) = 0，即每一 w\_i(ν) = 0，所以 Rel\_ρ(ν) = \[0\]\_ρ。这样整个资格评价域上的相对生成都是零类，正是《概率必然式》9.1 的情形：没有任何生成因子参与相对生成的形成，R = 0。所以整个率域上的零覆盖与 N\_P = 1 不相容。

只在某一个评价点上 Coverage = 0，不足以推出 R = 0，不在这一结论之内。□

不携 H：定理一只调用充分向与上游的定义。

### 5.2 定理二　当前资格硬界定理

在 Σ\_P^cur 内：

进入方向：N\_P = 1 ⇒ Probability = 1。Status = Established。

退出方向：H2 ∧ H3^red ∧ N\_P = 0 ⇒ Probability = 0。Status = Conditional。

所以在 H2 ∧ H3^red 下，资格硬界恰由 N\_P 的三项结构 D、B、R 刻画。

证明

进入方向为《概率必然式》的充分向。退出方向为《概率一般式》必要向的逆否。二者合起来，资格区与 N\_P = 1 的区域重合（4.1），资格的进入与退出都由 N\_P 的三项结构刻画。□

这里所说的"恰由"，只在 Σ\_P^cur 内成立（见第六节）。

### 5.3 定理三　越界退化定理

在 H2 ∧ H3^red 下，越过硬界的每一个候选都不是概率，并且恰属于下列三类之一。

Deg\_D　维基塌缩（D = 0）。至少包括三种：

单维塌缩：\|V\_P\| \< 2，退化为单维续行律或单路组织；

可区分性塌缩：某两维在当前分辨协议下不可区分，所谓不同维只是重复或重叠的标签；

Law-bearing 塌缩：某一申报维没有正式 Law-bearing，退化为裸候选方向或外加的率标签。

三者共同失去的是"可区分且 Law-bearing 的多维底座"。

Deg\_B　共同绑定解体（D = 1，B = 0）。包括不同续行位、不同冻结生成域、跨条件拼接、不同生成制度、不同生成事件被拼成一份。退化后，多个 Law-bearing 可以各自存在，但它们不再回答同一个续行问题，不属于同一冻结率域，也不是同一次的互斥后继。结果是 Law-bearing 过程的拼接集合，不是一份统一的概率。《概率一般式》删职审查已表明：取消 B，并行过程与跨条件拼接的情形就会重新进入。

Deg\_R　相对生成承担失效（D = B = 1，R = 0）。各维都取得 Law-bearing，处于同一续行位、同一冻结率域、同一生成关系，但 R 不成立。按 R 的构成（《概率数理式》定义 3.29—3.31，《概率判定式》定理六的三种失败来源），至少有四种典型子型：

率域失格：率域的事前冻结、非空、非空洞或系统侧根据失败；凡这类失败已经使共同绑定 B 失败的（例如跨协议拼接），按第一失败项归入 Deg\_B，这里只收 B 仍成立而 R 的率域资格失败的情形；

关系失成：相对生成关系在生成侧不能形成；

零类退化：整个资格评价域上的相对生成都是零类 \[0\]\_ρ（《概率必然式》9.1）；

承担外置：各维之间的相对生成由组织之外的选择机制决定，申报组织只执行被选中的结果，结果是"外部选择—内部执行"的组织。《概率一般式》删职审查已表明：取消 R，外部选择器的情形就会重新进入。

四种子型共同失去的是"由这份组织自己承担、在合法率域中形成的相对生成关系"。承担外置是 Deg\_R 的一个典型子型，不是它的同义词。

证明

由 4.2，N\_P = 0 的候选恰属三类之一。由定理二的退出方向，在 H2 ∧ H3^red 下它们都不是概率。各类的退化结果，由相应资格项的定义与《概率一般式》对该项删职后重新进入的失败情形给出。□

这三类与 N\_P 的三个结构项一一对应。这里不宣称它们是未来一切可能理论中的绝对穷尽。

### 5.4 附属命题　资源极限

以下两条是资源上的限制，不是资格边界：

ResourceLimit ≠ QualificationBoundary

(a) 条件率模式。若 Σ\_i ρ\_i^cond = 1，对任意 ε \> 0，记 N\_{≥ε} := \|{ i：ρ\_i^cond ≥ ε }\|，则 N\_{≥ε} ≤ ⌊1/ε⌋。否则条件率之和超过 1。

这只说明：具有统一正率下界的维数有资源上界。它不说明 \|V\_P\| 本身不能增长，因为 v\_i ∈ V\_P 不蕴含 ρ(v\_i) \> 0。

(b) 母本续行率兼容的子域。只有当母本 Pr(q,t) 可以经合法投影 π\_V：q ↦ v\_i 进入正式的率表示时，才可以取 w\_i = Σ\_{π\_V(q) = v\_i} Pr(q,t)。若另有 Σ\_q Pr(q,t) ≤ Λ(t)，则 Σ\_i w\_i ≤ Λ(t)，于是 N\_{≥ε} := \|{ i：w\_i ≥ ε }\| ≤ ⌊Λ(t)/ε⌋。

《概率数理式》规定：旧 Pr(q,t) 只能经合法桥进入 Rel\_ρ^M，不得写 Probability = Pr，也不得把 Σ Pr ≤ Λ 当作概率的归一公理。所以 (b) 只在该兼容子域内成立，不是一切概率的边界。

六、当前资格边界的精确性

这里不宣称任何唯一性：候选系统空间上没有定义拓扑，也没有定义边界算子，"硬界"指的是结构资格的退出条件，不是拓扑边界。所以不承担唯一性命题，只陈述精确性。

在 Σ\_P^cur 内，并在 H2 ∧ H3^red 下，由定理二：

N\_P = 1 的候选全部在资格之内；

N\_P = 0 的候选全部在资格之外；

当前的资格退出，恰由 D、B、R 中第一个失效的项刻画（4.2、定理三）。

不携 H 时，只有第一条成立。

这一精确性只在 Σ\_P^cur 内成立。越界退化的三类与 N\_P 的三项结构一一对应，并穷尽 N\_P = 0 的情形（4.2）；这里不宣称它们在未来理论中的绝对穷尽。

七、最简表达

在 Σ\_P^cur 内，并在 H2 ∧ H3^red 下：

Probability ⇔ D ∧ B ∧ R

极限不变量：对合法比较族 {χ\_α}，若族中每一成员都有 N\_P(χ\_α) = 1，则无论所申报的外围比较轴逼近哪一个合法退化端，都有 Probability(χ\_α) = 1（不携 H）。

这只是充分向的极限式读法，不新增本体。

八、解读（不属于形式结构）

以下只是对前述结论的说明，不参与证明，不承重。

通常把概率理解为一个数：一个在 0 与 1 之间、加起来等于 1、在多次重复中表现为稳定频率的数。按这里的结论，这些都可以退到极端而概率仍在：一个方向的率可以为零；各方向可以完全相等；系统可以完全确定；率可以根本读不出数值；申报的方向可以只占整个后继的一部分。概率不因此消失。

在当前条件闭合域内（H2 ∧ H3^red 下），概率消失的地方只有三处：没有可区分的、由律承担的多个方向；这些方向不再回答同一个续行问题；方向之间的相对生成不再由这份组织自己承担。

所以概率的"极限"不在它的数值上，而在它的结构上。

九、最终结论

### 9.1 总式

在 Π\_Lim 与 Σ\_P^cur 下：

软极限：单维零率、零各向异性、完全确定、数值不可读为可达端点；部分覆盖 0 \< Coverage \< 1 为开放软区间，不构成资格边界；整个率域上的零覆盖与 N\_P = 1 不相容。Status = Established，不携 H。覆盖能否由真实资格候选任意逼近零，开放，交《概率运行基底构造式》。

硬界：Probability ⇔ D ∧ B ∧ R，进入方向不携 H，退出方向携 H2 ∧ H3^red。

越界退化：Deg\_D（维基塌缩）、Deg\_B（共同绑定解体）、Deg\_R（相对生成承担失效），随退出结论携 H2 ∧ H3^red。

资源极限：附属命题，不是资格边界。

### 9.2 条件账本

H\_new = ∅。

软极限保持（定理一）：只调用充分向，Status = Established，不继承 H2、H3^red。

资格退出（定理二退出方向、定理三、第六节精确性中的后两条）：调用必要向的逆否，继承 H2 ∧ H3^red，Status = Conditional。

《概率判定式》的 H\_ρRep^- 不进入：这里直接讨论结构层的资格边界，不由形式证据 RateBearWitness^M = 0 推出 R = 0。若以后改以形式证据作结构失效的输入，须重新承继该篇的表示条件。

Σ\_P^cur 是证明域的限定，不是 H。

### 9.3 禁止推论

不得：ρ(v\_i) = 0 ⇒ v\_i ∉ V\_P。

不得：ρ(v\_i) = 0 ⇒ ¬Probability。

不得：Anisotropy = 0 ⇒ ¬Probability。

不得：Determinism ⇒ ¬Probability。

不得：NumericRateRead = ⊥ ⇒ ¬Probability。

不得：Coverage \< 1 ⇒ ¬Probability。

不得：Coverage → 0 ⇒ Probability → 0。

不得：由"可以任意逼近 0"写成"0 可达"。

不得：ResourceLimit ⇒ QualificationBoundary。

不得：把 Σ\_P^cur 内的资格边界写成未来理论永恒唯一的本体边界。

### 9.4 击穿方式

极限式的击穿是：极限条件已经成立，而所断言的极限性质没有出现。

软端误界：宣称某一端点与 N\_P = 1 相容，却能证明 N\_P 的某一项排除该端点。

部分覆盖误界：能证明当前资格语义中某一项推出 Coverage = 1，或推出 Coverage ≥ c\_0（对某个 c\_0 \> 0）。

零覆盖误判：能证明整个率域上 Coverage = 0 时仍可 N\_P = 1，则定理一 (iii) 被击穿。

硬界内反例：在 H2 ∧ H3^red 下，存在 Probability = 1 而 N\_P = 0。

硬界外反例：存在 N\_P = 1 而 Probability = 0。这同时直接击穿《概率必然式》。

退化分类错误：宣称某候选属 Deg\_R 的某一子型，但申报组织事实上仍然在合法率域中承担相对生成；或三类的划分出现重叠或遗漏。

比较协议污染：极限族须经换 C、换 𝔯\_P、改 DomainProtocol、改分辨协议、事后删维或跨条件拼接才取得极限结果。

动力偷渡：把比较族写成同一系统的真实时间演化，并据此断言形成原因、保持或恢复。

绝对唯一性越权：把 Σ\_P^cur 内的精确资格边界写成未来理论永恒唯一的本体边界。

### 9.5 回归测试

以下只作回归检验，不作一般证明。

测试 1　ρ = (1, 0)，N\_P = 1。资格保持。

测试 2　w = (1, 1)，A\_ρ = 0，N\_P = 1。资格保持。

测试 3　完全确定的执行，比例由组织自身形成。资格保持。

测试 4　struct 模式，无数值权重，N\_P = 1。资格保持。

测试 5　权重整体缩放 w → a·w（a \> 0）。只是更换代表，\[w\]\_ρ 不变，不构成极限退化。

测试 6　部分覆盖 Coverage = 1/2，N\_P = 1。资格保持，部分覆盖不是资格边界。整个率域上 Coverage = 0 时落入零类，属 Deg\_R 的零类退化子型。覆盖能否任意逼近零，不作判定。

测试 6b　单个评价点上 Coverage = 0，其余评价正常。不足以推出 R = 0；measure 模式下若该点零测，率域聚合不受影响。

测试 7　\|V\_P\| = 1。Deg\_D，单维塌缩。

测试 8　两维兑现域重叠。Deg\_D，可区分性塌缩。

测试 9　跨冻结协议拼接。Deg\_B。

测试 10　外部选择器决定全部率。Deg\_R 的承担外置子型。

测试 11　比较族靠换续行位才得到极限。协议污染，不是合法极限。

十、接口

上承

《概率一般式》：三项必要结构、条件化必要向、删职后重新进入的失败情形、极限式下交条款。

《概率数理式》：struct 与 weight 两种表示、正比例等价类、ρ^cond 与 ρ^full、完整后继生成质量 M\_C、旧 Pr 的合法桥、零率与部分覆盖不得资格化。

《概率必然式》：N\_P ⇒ Probability；零率、全零关系、确定性分支三个边界例。

《概率判定式》：只承继结构零与表示开放的区别作为边界纪律，不调用其操作判定桥来证明这里的结构结论。

下交

《概率源式》：硬界两侧的结构从何而来，这里不回答。

《概率动力一般式》《概率动力数理式》：这里交出三种越界型，不回答同一系统怎样发生 D、B、R 由 1 到 0 的变化。

《概率稳定式》：这里给出资格在哪里退出；稳定式回答在许可的变化轨迹上是否保持、何时首次失效、能否恢复。

《概率运行基底构造式》：这里给出需要能够实例化与测试的软极限族、硬界与资源极限接口；可达端点的具体实现，以及对任意 ε \> 0 是否存在 N\_P = 1、且 0 \< Coverage \< ε 的真实可运行实现，由该篇构造；若构造成功，覆盖轴由开放软区间升级为 ApproachableEndpoint。

不做的事

不把概率定义为数值；不建立概率归一公理；不要求各维正率、完整后继覆盖、本体随机或稳定经验频率；不把 RateRead = ⊥ 写成结构失效；不证明动力变化、跨时稳定、来源或可达；不重新作实例判定；不宣称 N\_P 是未来理论永恒唯一的本体核；不把兼容子域的资源命题升格为一切概率的边界。
