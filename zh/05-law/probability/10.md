# 概率源式

一份候选概率在申报的历史窗中首次取得正式资格，这一次首次成概率由哪一段实际历史承担？若有多段历史都能合法承担，理论最多能确定到什么程度？

结论是：概率的来源，不是最终的概率值，不是稳定频率，不是最后闭合的那一项资格，也不是任一反事实必要条件；它是一段实际历史，对这份冻结候选的首次资格闭合承担了真实的形成，并且这段历史必须同时通过实际生成链与合法反事实最小充分性的认证。来源可以不唯一；没有找到来源，不等于没有来源。

一、对象申报

### 1.1 式种与唯一任务

源式，附式，独立成篇。按《法篇》第四编第四章源式规范：证明一个已经成立的结构由什么实际过程生成，而不是由什么给定。

这里只研究首次概率成立的来源。不研究：当前是否有概率资格，当前怎样作用，已成概率以后怎样变化，资格的失去与恢复，是否可达，怎样构造第一个可运行的概率，1 → 0 → 1 之后的再次成立，跨宿主迁移或复制的身份连续性。

### 1.2 上游冻结结构

N\_P := D ∧ B ∧ R，D := MultiLawDimension，B := CommonContinuationBind，R := DomainRelativeRateBearing。共同绑定记作 B，以免与续行位 C 混淆。

充分向：N\_P ⇒ Probability，Status = Established，不携 H。

必要向：H2 ∧ H3^red ⇒ \[ Probability ⇒ N\_P \]。只有在 H2 ∧ H3^red 下，Probability ⇔ N\_P。两向的条件不对称，这里不洗掉。

以下主要使用不携 H 的充分向。

### 1.3 跨时候选

上游静态候选为 χ\_P = (F, t, 𝒫, C, 𝔯\_P, V\_P, 𝓛\_P)。源式不能把某一单独时刻冻结为候选身份，所以记跨时冻结声明：

χ̄\_P = (F, 𝒫, C, 𝔯\_P, V\_P, 𝓛\_P)

某一评价点的候选实例为 χ\_P(t) = (χ̄\_P, t)。这只是跨时来源协议的申报方式，不是新的概率本体。

在一次来源协议中，F、𝒫、C、𝔯\_P、V\_P、𝓛\_P 都事前冻结。删除历史以后，不得增删 V\_P，不得换 C、𝔯\_P、Law-bearing 候选集合或生成制度，不得重新申报另一份候选。

### 1.4 来源协议

Π^P\_src = (χ̄\_P, X\_0, H\_obs, Bg^Π, Ops^Π, Dyn^Π, Judge\_P^Π, Judge\_N^Π, T\_Π, Gran^Π)

χ̄\_P：冻结的跨时候选声明。

X\_0：来源窗的申报初态。

H\_obs：实际观察到的有序历史。

Bg^Π：冻结背景（记作 Bg^Π，以免与共同绑定 B 混淆）。

Ops^Π：允许的删除、遮蔽、Mask、抑制等历史削减操作，事前冻结。

Dyn^Π：合法的场系统或运行基底动力。

Judge\_P^Π：正式的概率三值资格判定，Judge\_P^Π(t) ∈ {1, 0, ⊥}。

Judge\_N^Π：资格核的结构读数，Judge\_N^Π(t) = (D\_t, B\_t, R\_t)，N\_{P,t} = D\_t ∧ B\_t ∧ R\_t。

T\_Π：事前冻结的有限评价点集。"首次"只相对于这个点集定义；不得看见结果以后增删评价点。

Gran^Π：历史发生事项的冻结切分粒度；结果出来以后不得改变。

### 1.5 首次成概率事件

Genesis\_P^Π(χ̄\_P, τ) ∈ {1, 0, ⊥}

1：Judge\_P^Π(τ) = 1，且对 T\_Π 中一切 t \< τ，Judge\_P^Π(t) = 0。

0：Judge\_P^Π(τ) = 0；或者存在 t \< τ 使 Judge\_P^Π(t) = 1。更早存在确定的 1，足以否定"首次"，即使其他更早的点为 ⊥。

⊥：其余情形，例如 τ 点不可判，或 τ 点为 1 而此前有关键评价点为 ⊥，且没有更早的确定的 1。

### 1.6 首次事件的条件

这里不从 N\_P = 0 重新推出 Probability = 0。Genesis\_P 是来源研究的入口事实。若某些时间点的 Probability = 0 取自《概率判定式》的 Det\_P，该具体负端证书自行携带 H2 ∧ H3^red，以及其失败路径相应的 H^-\_M 或 H\_ρRep^-。这些是上游判定证书的条件，不是这里新增的 H。

二、默认来源的排除

以下是容易被当作来源、但不能作为来源的对象。各项都是定义层的不推出：来源由第四节的 PGenesisSource 认证，它的第二、三项以历史为自变量，终态、数值、相关与反事实必要性都不能单独满足它。

W-P1　终态概率倒推：Probability\_τ = 1 ⇏ 𝔖^Π\_{P,src} ≠ ∅。

W-P2　终态资格核倒推：D\_τ = B\_τ = R\_τ = 1 ⇏ GenesisSource。资格证书不是来源证书。

W-P3　最后闭合项冒充全部来源：LastClose\_τ = X ⇏ SourceOnly(X)。

W-P4　最终概率值、各向异性、稳定频率：FinalRate、Anisotropy、StableFrequency 都不推出来源。

W-P5　时间先后、同步、相关、预测：h 先于 τ ⇏ SourceCarrier(h)；Corr(h, Genesis\_P) ⇏ SourceCarrier(h)。

W-P6　"受过奖惩"自动冒充来源：RewardPunishmentOccurred ⇏ GenesisSource。奖惩必须真实进入实际生成链，并在最小充分性中承重。

W-P7　背景使能：CounterfactualNecessity ⇏ GenesisSource。

W-P8　非法删除：删去 h 后的历史不能合法重放（Replayable = 0）⇏ NecessarySourceCarrier(h) = 1。

W-P9　外部安装冒充场内形成：ExternalInstall\_P ⇏ FieldBorn\_P。外部安装可以是来源，但不因此是场内形成。

由此形成四条区分：

LastClosure ≠ GenesisSource

StructuralNecessity ≠ GenesisSource

FinalProbabilityValue ≠ GenesisSource

CounterfactualNecessity ≠ GenesisSource

各条的依据：LastClosure ≠ GenesisSource 由定理三；StructuralNecessity ≠ GenesisSource 由定理四，其中"结构必要性"指资格核的组成项，在 H2 ∧ H3^red 下也指概率的必要资格项，两种读法都不推出来源；FinalProbabilityValue ≠ GenesisSource 由定理二的推论：最终率值、稳定频率与各向异性连完整的终态资格核都不构成，而定理二已证明连完整的终态资格核都不推出来源，这些更弱的终态量更不能独立给出来源证书；CounterfactualNecessity ≠ GenesisSource 由 3.6 的实际生成链要求：反事实必要而没有同一见证上的实际形成与终点绑定，ActualPGenesisLink 不为 1。

三、发生过程刻画

### 3.1 历史表示

实际历史写作有序有限对象：

H\_obs = (e\_1, e\_2, …, e\_n)，n \< ∞

不得写成无序集合。每一发生事项至少保留时间次序、次数、持续区间、实际发生内容与所作用的对象。

属于场内形成过程的，按实际存在的结构另保留执行、痕迹、沉积、成形，以及与终点 D、B、R 承担之间的连接。属于外部安装过程的，保留外部编辑事项、编辑对象、编辑前后的状态，以及编辑进入资格结构变化的连接。不存在的字段不得为了格式完整而虚造。

### 3.2 削减域

协议相对的削减记为 H′ ⪯\_Π H：存在一列由 Ops^Π 允许的有限操作，把 H 削减为 H′。每项操作只能删除已有事项，或削弱已有事项的作用；不改变它的原时间位置；执行与结果可以审查。

削减不得改 X\_0、χ̄\_P、Dyn^Π、概率判定或资格核定义，不得加入新事件，不得改变剩余事件的顺序，不得偷补终态，不得事后重切 C、𝔯\_P、V\_P。

严格削减记为 H′ ≺\_Π H。要求 ⪯\_Π 在申报的削减域上构成冻结的有限偏序；这是协议的准入条件，不由上述操作规定自动推出。下文的最小性相对于这一偏序，不相对于普通的集合包含。

### 3.3 削减域有限

v1.0 要求 \|H\_obs\| \< ∞，且 \|ℛ\_Π(H\_obs)\| \< ∞，其中 ℛ\_Π(H\_obs) = { H′ \| H′ ⪯\_Π H\_obs }。连续的 Mask 强度、无限细的粒度或无限下降链，若未冻结离散化，不进入 v1.0 的最小充分来源判定域。这是协议工作域的限定，不是概率本体的限制。

3.3a 来源候选历史域

一切来源候选历史 H\_s 都取自冻结削减域：

𝓗^Π\_src := ℛ\_Π(H\_obs) ∖ { H\_∅ }

所以 H\_s ∈ 𝓗^Π\_src ⇒ H\_s ⪯\_Π H\_obs。来源候选只能由实际历史 H\_obs 经协议允许的削减取得；不得把实际历史中没有发生的替代过程、补造过程或另一条可能历史，作为本次首次成概率的来源候选。H\_∅ 只作为 4.3 的背景控制，不进入来源候选域。由 3.3，\|𝓗^Π\_src\| \< ∞。

### 3.4 合法重放

Replayable\_P^Π(H) ∈ {1, 0, ⊥}

1：存在遵守完整冻结协议的合法重放。保持同一 X\_0、同一 χ̄\_P、同一身份规则、同一合法动力、同一允许输入、同一判定与评价协议；只对未保留的历史事项作协议允许的删除或遮蔽，然后让系统依法自行演化。

0：只有通过换候选、换宿主规则、换动力、改判定、改资格定义、加未申报事件或偷补终态，才能完成所谓重放。

⊥：当前无法确定重放是否合法。

Replayable = 0 ≠ 反事实失败

不能删 ≠ 删了不成

### 3.5 来源充分性

只在 Replayable\_P^Π(H) = 1 以后求：

Suff\_P^Π(H; χ̄\_P, τ) ∈ {1, 0, ⊥}

1：合法重放到实际首次事件的评价终点 τ 时，N^{Replay(H)}\_{P,τ} = 1，即 D\_τ = B\_τ = R\_τ = 1。由充分向，终点 Probability = 1。

0：合法重放已完成，且终点明确 N\_{P,τ} = 0。

⊥：合法重放成立，但终点结构读数不足以判 N\_P。

Replayable = 0 时不进入 Suff 的 0 分支。

反事实重放中不要求概率仍恰好在 τ 首次成立，它可以更早成立。这里研究的是来源原因，不是精确的定时原因：

来源原因 ≠ 精确定时原因

### 3.6 实际概率生成链

来源不能只有反事实充分性，还须有实际的形成链，并且形成的东西与终点资格所用的东西必须是同一个。

保序子历史：H\_g ⊑\_ord H\_s，表示 H\_g 由 H\_s 中若干事项按原次序抽取得到。它只用于标识形成见证实际经过的历史片段，不是削减偏序 ⪯\_Π（形成见证的子历史不一定是完整、可重放的合法削减历史），也不是普通的集合包含。

形成见证：g = (H\_g, s\_g)，其中 H\_g ⊑\_ord H\_s 是一段保序子历史，s\_g 是这些事项所形成的结构。

两条形成路径（对每一 g 取值于 {1, 0, ⊥}）：

FieldFormationLink\_P(g)：1，H\_g 中的事项经执行、痕迹、沉积、成形，在场内真实形成了 s\_g，全过程可以审查；0，所需接口完整可读，而明确没有这样的形成连接；⊥，事项或连接存在不可读、不可审之处。

ExternalInstallLink\_P(g)：1，H\_g 中有申报的、可以审查的外部编辑事项，真实生成了 s\_g；0，所需接口完整可读，而明确没有这样的安装连接；⊥，存在不可读、不可审之处。

实际形成：

ActualFormation(g) := FieldFormationLink\_P(g) ∨₃ ExternalInstallLink\_P(g)

这一析取只在 v1.0 的形式定义内穷尽形成路径，不宣称在本体上一切概率形成方式都被穷尽。相关、同步、预测、旁观、纯背景使能与终态代理，都不满足任一路径。

终点绑定（对每一 g 取值于 {1, 0, ⊥}）：

EndBind\_X(g)，X ∈ {D, B, R}：1，s\_g 正式进入 τ 时这份冻结候选的资格项 X 的承担；0，绑定接口完整可读，而明确没有进入；⊥，绑定关系不可判。

EndBind\_P(g) := EndBind\_D(g) ∨₃ EndBind\_B(g) ∨₃ EndBind\_R(g)

不要求来源同时改变三项，只要求同一形成结果至少进入终点资格核的一项。

实际概率生成链：

ActualPGenesisLink^Π(H\_s; χ̄\_P, τ) := ∃₃ g，H\_g ⊑\_ord H\_s：\[ ActualFormation(g) ∧₃ EndBind\_P(g) \]

形成与绑定必须落在同一个见证 g 上：不能一边拿事项 A 的形成，一边拿另一事项或既存结构 B 的终点绑定。

三值规则：∨₃ 为有 1 即 1、无 1 而有 ⊥ 即 ⊥、全 0 才为 0；∧₃ 为有 0 即 0、无 0 而有 ⊥ 即 ⊥、全 1 才为 1；∃₃ 为有 1 即 1、无 1 而有 ⊥ 即 ⊥、全 0 才为 0，并且"全 0"要求 H\_s 中的形成见证已经枚举完整，否则为 ⊥。

### 3.7 两条实际来源路径

对已认证的来源历史 H\_s：

FieldBorn\_P^Π(H\_s) = 1：存在 g，H\_g ⊑\_ord H\_s，FieldFormationLink\_P(g) = 1 且 EndBind\_P(g) = 1。

ExternalInstall\_P^Π(H\_s) = 1：存在 g，H\_g ⊑\_ord H\_s，ExternalInstallLink\_P(g) = 1 且 EndBind\_P(g) = 1。

二者不预设互斥，可以同时为 1，不写成排他的或。

ExternalInstall ⇏ ¬Source：外部安装可以是真实来源。

ExternalInstall ⇏ FieldBorn。

### 3.8 沉积场纪律

上游语料已把"概率是在沉积场中生成"归入所在层级与生成过程。所以外部安装不解释为概率可以脱离沉积场存在；正确的解释是：当前候选概率的合法沉积结构，可以通过外部安装历史在当前来源窗中首次取得。

ExternalInstallSource ≠ 非沉积场概率

### 3.9 最小充分来源历史

MinSuff\_P^Π(H\_s; χ̄\_P, τ) ∈ {1, 0, ⊥}

对任意申报的 H\_s，先判候选自身：

其一，Replayable\_P(H\_s) ∈ {0, ⊥}：MinSuff\_P(H\_s) = ⊥。候选自身不能合法重放，不能解释为"不是最小"。

其二，Replayable\_P(H\_s) = 1 且 Suff\_P(H\_s) = 0：MinSuff\_P(H\_s) = 0。它已经明确不充分，不可能是最小充分历史。

其三，Replayable\_P(H\_s) = 1 且 Suff\_P(H\_s) = ⊥：MinSuff\_P(H\_s) = ⊥。

其四，只有 Replayable\_P(H\_s) = 1 且 Suff\_P(H\_s) = 1 时，才审查一切 H′ ≺\_Π H\_s：

0：存在 H′ ≺\_Π H\_s，使 Replayable\_P(H′) = 1 且 Suff\_P(H′) = 1。确定反例优先。

1：没有上述反例，并且一切严格削减都有 Replayable\_P(H′) = 1 且 Suff\_P(H′) = 0。

⊥：没有确定的充分严格削减，但至少有一个关键的严格削减 Replayable = 0 或 ⊥，或合法重放后 Suff = ⊥。

不能重放 ≠ 重放后不充分

不得：不能合法删除 ⇒ 必要来源。

四、来源定理

### 4.1 来源核心

PGenesisSource^Π(H\_s; χ̄\_P, τ) = Genesis\_P^Π ∧₃ ActualPGenesisLink^Π ∧₃ MinSuff\_P^Π

三项各守一事：Genesis\_P 守首次概率事件；ActualPGenesisLink 守实际形成链；MinSuff\_P 守合法反事实承重与非冗余。

ProbabilityGenesisSource = ActualGenesis ∩ CounterfactualBearing

只有实际链而没有反事实承重，不够；只有反事实必要而没有实际形成链，也不够。

三值传播：三项全为 1 时为 1；至少一项确定为 0 时为 0；没有确定的 0 而至少一项为 ⊥ 时为 ⊥。材料不足不写成"不是来源"。

### 4.2 来源解族

𝔖^Π\_{P,src} = { H\_s ∈ 𝓗^Π\_src \| PGenesisSource^Π(H\_s) = 1 }

来源解族可以有多个成员，不默认唯一。来源有多解时，报告整个可认证的解族。

### 4.3 空历史控制

H\_∅：不保留任何申报来源事项，其余协议项不变。

SourceDomainIncomplete\_P^Π ∈ {1, 0, ⊥}：

1：Replayable\_P(H\_∅) = 1 且 Suff\_P(H\_∅) = 1。真正承重的过程至少有一部分漏在 X\_0、Bg^Π、Dyn^Π、过粗的历史粒度或未申报的来源候选域中。此时 Source\_P^Π = ⊥，不写成 Source\_P = 0。

0：Replayable\_P(H\_∅) = 1 且 Suff\_P(H\_∅) = 0。空历史不充分。

⊥：空历史不能合法重放，或其 Suff 不可判。

空集不进入 𝔖^Π\_{P,src}。

### 4.4 来源可判域

SrcDetDom\_P^Π := GenesisResolved ∧ DomainExhaustive ∧ ReductionDomainFinite ∧ ReplayCoverage ∧ ActualLinkCoverage ∧ EmptyControlClosed ∧ GranFrozen

GenesisResolved：Genesis\_P 已判为 1。

DomainExhaustive：冻结的来源候选历史域 𝓗^Π\_src 已完整申报并穷尽，不存在域外历史被当作本次实际首次成概率的来源候选。

ReductionDomainFinite：3.3 的有限性成立。

ReplayCoverage：对来源候选域中一切 ActualPGenesisLink = 1 的候选历史 H\_s，其 MinSuff\_P(H\_s) 已按 3.9 完整判为 0 或 1；即为取得该 MinSuff 所必需的候选自身与严格削减，其 Replayable 与 Suff 已取得足以关闭三值传播的读数，不存在仍使 MinSuff\_P(H\_s) = ⊥ 的关键重放缺口。对 ActualPGenesisLink = 0 的候选，来源核心已有确定的 0，不要求无关的 MinSuff 分支另行求值。Replayable = 0 时 Suff 不进入求值域，不要求它另取 0 或 1。

ActualLinkCoverage：一切候选的 ActualPGenesisLink 都已判出 1 或 0。

EmptyControlClosed：SourceDomainIncomplete = 0。（另记 EmptyControlResolved：SourceDomainIncomplete ∈ {0, 1}，表示空历史已判定完毕；可判域中使用的是 EmptyControlClosed。）于是 SourceDomainIncomplete = 1 ⇒ SrcDetDom = 0 ⇒ Source\_P = ⊥。

GranFrozen：粒度已冻结。

它只是来源判定工作的完整域，不是概率本体，不是第四项资格，不是 H。

### 4.5 来源整体状态

区分两件事：是否已经存在至少一个已认证的来源；当前协议是否已经足以给出来源的整体判定。

SourceExistence\_P^Π ∈ {1, 0, ⊥}：1，𝔖^Π\_{P,src} ≠ ∅；0，SrcDetDom = 1 且 𝔖^Π\_{P,src} = ∅；⊥，其余情形。它是解族的存在读数，不是新的本体。

Source\_P^Π(χ̄\_P, τ) ∈ {1, 0, ⊥}：

1：SrcDetDom = 1，且 𝔖^Π\_{P,src} ≠ ∅。

0：SrcDetDom = 1，且 𝔖^Π\_{P,src} = ∅。SrcDetDom = 1 已含 SourceDomainIncomplete = 0、来源候选域完整、全部关键合法重放已经闭合。

⊥：其余情形，包括来源候选域不完整、空历史已充分、关键重放非法或不可判、实际生成链不可审、粒度不足、来源集尚未穷尽。

所以可以同时有 SourceExistence = 1 与 Source = ⊥：已经知道至少有一条真实来源，但冻结背景本身也已充分，或来源域尚未穷尽，还不能说当前解族给出了这次首次成概率的完整来源判定。已有部分来源证书，不等于来源域已经穷尽。

### 4.10 事件级来源承担

对历史原子 h，下列谓词都取值于 {1, 0, ⊥}。记"来源族完整"为：SrcDetDom = 1，且 𝔖^Π\_{P,src} 已完整枚举。

PossibleSourceCarrier\_P^Π(h)：1，已找到至少一个 H\_s ∈ 𝔖 使 h ∈ H\_s（存在性正证，不要求来源族已穷尽）；0，来源族完整，且其中没有任何 H\_s 含 h；⊥，其余情形。

NecessarySourceCarrier\_P^Π(h)：1，来源族完整且非空，所有 H\_s 都含 h；0，已经存在一个 H\_s ∈ 𝔖 不含 h（确定反例优先，不要求来源族完整）；⊥，尚无这种反例，而来源族未完整闭合，或来源族为空。来源族为空时，不借空集的全称把任意 h 判为必要来源。

PossibleSourceCarrier 与 NecessarySourceCarrier 互为镜像：Possible 由一个含 h 的来源判 1，穷尽后判 0；Necessary 由一个不含 h 的来源判 0，穷尽后判 1。

RedundantSourceCarrier\_P^Π(h)：1，已找到 H\_A ∈ 𝔖 含 h，又已找到 H\_B ∈ 𝔖 不含 h，h 是冗余但真实的来源承担（存在性正证）；0，来源族完整，且 h 不属于任何 H\_s，或 h 属于所有 H\_s；⊥，其余情形。

NonSourceCarrier\_P^Π(h)：1，来源族完整，且 h 不属于任何 H\_s；0，已找到某一 H\_s 含 h；⊥，其余情形。

### 5.1 定理五　来源非唯一性定理

证明

MinSuff\_P 是相对于偏序 ⪯\_Π 的极小性，而一个偏序集中的极小元不必唯一；PGenesisSource 的定义中也没有唯一性条款。构造一个有限的抽象协议模型（形式模型，不断言物理实例已经存在）：

因此 Source\_P = 1 而 \|𝔖^Π\_{P,src}\| = 2：Source\_P = 1 ⇏ UniqueSource。更弱的 SourceExistence\_P = 1 ⇏ UniqueSource 随之成立。□

Status = Established。

### 5.2 必须申报的不确定处

以下几处，这里不能唯一确定，须显式申报：

来源解族可以有多个成员；来源有多解时报告整个解族，不只报告其中一个。

来源可判域 SrcDetDom 未闭合时，非来源与来源整体为 0 都不能签出，只能为 ⊥。

空历史已充分时，来源域不完整，来源整体为 ⊥。

削减域无限或粒度未冻结时，不进入 v1.0 的最小充分来源判定域。

### 5.3 来源分类：三条正交轴

不得把环境奖惩、源动、进化、外部安装写成四个同层互斥的来源型。分类沿三条正交轴进行。

轴一　来源出处：FieldBorn\_P、ExternalInstall\_P（3.7），二者不预设互斥。

SourceDriveSource：只有当源动驱动的历史真实形成了终点所用的结构，并进入最小充分来源集时，才能成立。

EvolutionarySource：研发起点语料 B10 只支持进化过程与概率维、意向结构之间的关系；只有当实际演化历史被当前来源协议纳入，并被认证为最小充分来源承担时，才能贴这一标签。不得写 Evolution ⇒ ProbabilityGenesis。

### 6.4 击穿方式

K-SRC1　正来源反例：已签 PGenesisSource(H\_s) = 1，但合法重放 H\_s 到 τ 时 N\_P = 0。

K-SRC5　必要来源反例：已判 NecessarySourceCarrier(h) = 1，却发现另一合法最小充分来源集不含 h。

K-SRC7　来源域误闭合：已判 Source = 0 或 NonSource = 1，后来发现空历史充分或遗漏了合法来源候选。

K-SRC8　源式与动力式偷换：把已成概率之后 D、B、R 的变化、失效、恢复或迁移写成首次来源。

《概率动力一般式》《概率动力数理式》：这里只研究实际已经发生的首次形成史，不建立一般的 Probability(t) → Probability(t′)；已成概率以后 D、B、R 的变化交动力式。

《概率运行基底构造式》：这里不负责制造实际的概率；可运行的 N\_P = 1 实例，以及回归测试中各模式的物理实现，交构造式。

《概率可达式》：源式问实际发生的这一次由什么造成；可达式问从给定初态是否存在合法路径到达概率。可达路径不等于实际来源路径。

《概率稳定式》：源式只守首次的 0 → 1；之后的 1 → 0 与 1 → 0 → 1 不属于首次形成。
