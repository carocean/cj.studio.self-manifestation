# 概率动力一般式

本篇试论一个总命题：

一份申报的概率候选，在一段真实的跨时运行中若确有概率动力，这种动力最低必须具有什么结构？我们要在本篇，在不断追问下找到证明应当走向何处，并推导概率动力的一般式。

那么，我们先给出结果。（以下为全文完成后据实回置篇首的阅读组织，只预告结果，不作为后续推导的前提。）

概率的动力，不是把两个概率状态并排比较。先须有同一份申报概率候选沿真实合法轨迹连续走过的一段路，读法事先冻结；然后在这段路上，这份概率自身须真有事发生：或者它的作用推移，或者它所承担的相对生成关系推移，或者构成它资格的正式组织推移。三者至少其一，不要求同时。这些判断都相对于事前冻结的评价粒度。

H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ ProbabilityDyn^η ⇒ N\_PDyn \]

N\_PDyn 的具体组成由下文逐轮逼出，见第五节。

一句话：

只是时间过去、结果不同、经验频率不同、环境不同，或者底层实现换了，都不因此成为概率动力；概率动力是同一份概率在一段真实合法的路上，自身的作用、率关系或资格组织确有推移。

※※※

摘要

《概率一般式》《概率必然式》已经给出概率的当前资格 N\_P = D ∧ B ∧ R，《概率作用一般式》《概率作用必然式》闭合了概率的当前作用，《概率源式》给出了首次成概率的来源。本式推进一步：研究一份申报概率候选在真实跨时运行中若有动力，最低必须具有什么结构。

所得必要结构由两部分组成：一段合法的概率动力段，要求同一真实轨迹、固定的概率锚、合法的状态更新、事先冻结的评价协议与良构的评价点集；以及在这一段上概率自身的动力实际性，它是三个投影的析取：作用推移、率关系推移、资格组织的正式结构推移。三者至少其一，不要求同时。

只证明必要方向，Status = Conditional，条件为 H2 ∧ H3^red ∧ SC\_Hold；这一条件只在"三投影穷尽了资格侧的动力"一处承重。本篇的动力判断相对于 Γ\_PDyn 所申报的评价粒度。细于该粒度、且在该粒度下完全消隐的子段内往复，不由本篇定理保证检出；真实过程在更细粒度具有动力，不自动推出本协议下的动力判断成立。充分方向、形式化、可达性与稳定性，分别交由后续式文。

一、式种、任务与完成规范

### 1.1 式种

一般式，主式，必要方向。直接输出：ProbabilityDyn 的最小必要构成。

### 1.2 待证命题

H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ ProbabilityDyn^η ⇒ N\_PDyn \]

其中 η 为申报的一段跨时运行，N\_PDyn 由后文连续约束递推取得。

### 1.3 证明目标

通过同一个不可约任务的连续追问，逼出概率动力的最低必要结构，并证明其当前推导最小性。不证明充分方向。

### 1.4 完成条件

本式完成，当且仅当：连续约束递推闭合；N\_PDyn 的每一项都有明确的逼出来源；删除、弱化、替换与不可合并审查完成；对可能的第四个动力投影完成冻结语料审查；正式总式与总定理只含已逼出项、合法承继项或显式条件项；条件账本、击穿方式与接口闭合。

### 1.5 击穿方式

在工作域、进入条件与相关 H 条件都保持时，若存在 ProbabilityDyn^η = 1，而 N\_PDyn 的某一必要项缺失，任务仍然闭合，则本式被击穿。具体条目见第九节。

### 1.6 版本定位与任务边界

首版。

这里只回答：一份申报概率候选在一段真实运行中若确有概率动力，最少有哪些结构事实必须成立。

这里不回答：

一、这些结构是否足以说明确有概率动力；

二、这些对象怎样形式化、怎样三值回读；

三、怎样构造可运行的概率动力；

四、从给定初态能否到达某一动力目标；

五、概率资格能否保持、何时首次失效、能否恢复；

六、概率怎样首次形成。

二、工作域与承继边界

### 2.1 承继

概率当前资格：N\_P = D ∧ B ∧ R，D := MultiLawDimension，B := CommonContinuationBind，R := DomainRelativeRateBearing（共同绑定记作 B，以免与续行位 C 混淆）。充分向 N\_P ⇒ Probability，Status = Established，不携 H；必要向 H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ Probability ⇒ N\_P \]。两向条件不洗平。由充分向 N\_P ⇒ Probability 的逆否，Probability = 0 时，D、B、R 至少一项不成立，此项不携条件。若要由 Probability 的跨时真值改变，推出 D、B、R 至少一项的真值发生改变，则还须保证合格端满足 N\_P；本篇经条件化必要向取得这一保证，因而携 H2 ∧ H3^red ∧ SC\_Hold。（v1.0 此处写作「只有在 H2 ∧ H3^red 下，才能断言资格的退出必经 D、B、R 至少一项的失败」，把失格端的结构失败与跨时结构改变混在一处，本版拆开。）

注（对应《概率一般式》v1.1 与《概率必然式》v1.1）　《概率一般式》v1.1 因调用《律必然式》v1.4 充分向（Conditional on SC\_Hold），其必要向改为 H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ Probability ⇒ N\_P \]；《概率必然式》v1.1 主定理 N\_P ⇒ Probability 仍为 Established，不携 SC\_Hold，其形式层推论回读经《律必然式》充分向者另携 SC\_Hold。本篇所承继的条件随之由 H2 ∧ H3^red 改为 H2 ∧ H3^red ∧ SC\_Hold（下文统一写作此式），承重位置不变：只在第四投影审查的资格真值一项。

概率作用：《概率作用一般式》《概率作用必然式》已经在对象层闭合 ProbabilityAct；《概率作用数理式》提供其形式实现与回读接口。ProbabilityAct 不是结果落入某维，而是在同一次现实当前续行中，这份概率确有合法当前发生，并实际承担各维之间相对生成关系的形成。当前作用与跨时动力分开。

概率源式：研究首次成概率。它把 V\_P、𝓛\_P 冻结进跨时候选，是因为它研究同一份冻结候选的第一次形成。这里不复制这一冻结方式：动力恰恰必须允许 V\_P(t)、𝓛\_P(t) 变化。

动力语料：《概率必然式》第五节已把固定语料中的三处分量归入动力（Dynamics）：A3.c，∂Pr(q,t)/∂t ∝ ∂Depth(q,t)/∂t（v0.7.1 母本旧式，作冻结语料保留；现行式篇第二十 v1.2 已删此比例式，沉积度变化对后续行进的作用只取方向，见《概率必然式》v1.1 3.1 注）；B2，"概率是穿过律生态的律"；B6.a，"源动脉冲-律生态（在变）-环境（在变），所以方向维在增长，可能空间在变大，每个方向上可被续行的概率在变小"。

### 2.2 对象入口

ProbabilityDyn^η 只以上述动力语料作语义锚，先读作：一份申报的概率候选，在一段真实运行 η 中，其作为概率的状态确有推移。语料所举的，有方向维的增长、每个方向上续行率的变化、率关系随沉积度变化而推移（A3.c 只取其方向含义，不取比例）。

评价粒度限定。本篇的动力判断相对于 Γ\_PDyn 所申报的评价粒度。细于该粒度、且在该粒度下完全消隐的子段内往复，不由本篇定理保证检出；真实过程在更细粒度具有动力，不自动推出本协议下的动力判断成立。这是评价粒度的限定，不同于机器材料不足或形式读数为 ⊥；也不由此把 ProbabilityDyn 定义成 N\_PDyn。

这里不预先规定这种推移须有何种结构；那是待逼出的内容。

### 2.3 跨时对象

设动力候选锚：

χ̄\_PDyn = (F, 𝒫, C, 𝔯\_P, Γ\_PDyn)

F 为申报沉积场；𝒫 为申报概率候选组织的引用；C 为这份概率所回答的续行问题；𝔯\_P 为申报率域；Γ\_PDyn 为事前冻结的动力评价协议。

以下都不作跨时身份锚，而作动力状态，允许随时间变化：V\_P(t)、𝓛\_P(t)、Rel\_ρ(t)、ProbabilityAct(t)、D(t)、B(t)、R(t)，以及它们内部的正式结构。特别地，不把 V\_P 固定进动力对象的身份：母本与前篇已把"新径经沉积取得 Law-bearing 而进入 V\_P"下交概率动力（B6.a 的"方向维在增长"）。

### 2.4 工作域

η 为申报的一段跨时运行。Probability 不要求在全段保持为 1。这里也不另设"全段至少有一点 Probability = 1"为独立的工作域条件；概率资格与动力见证的归属关系，由下文的 QualificationContactBind\_PDyn 在实际承担 DynActual 的相邻评价步上约束。需要的是见证步上的局部接触，不是全段的整体接触。

三、先行之辨

动力不等于时间经过。若只要时间经过就算动力，一份完全静置、各项不变的概率也在"动"。

动力不等于结果不同。某一次续行落入 v\_i、另一次落入 v\_j，只是两次执行的结果；每次执行都归一，结果不同不说明概率自身变了。

动力不等于经验频率变化。频率是多次结果的统计，《概率反演式》已证明频率不能普遍识别概率资格，它的变化同样不能代理概率自身的推移。

动力不等于数值率变化。概率的相对生成关系可以只有结构表示而没有合法数值（《概率数理式》struct 模式），数值的改变也可以只是换了代表（正比例等价类）。

此处所说"真实"，指由场系统或运行基底的合法动力实际生成，不是记录、编辑或事后拼接出来的。

※※※

四、论证流

当前只知道：有一份概率资格与作用都已闭合的理论，有动力语料，有上述对象锚。

先问：只凭若干时刻的概率状态按时间排列，是否已经是概率动力？

构造一个时间并置情形。𝒫\_A 在 t\_0、𝒫\_B 在 t\_1、𝒫\_C 在 t\_2 各自具有合法的概率资格，甚至率值、外显行为都完全相同。把它们按时间排成一列。

这一列有时间次序，但说不出"同一份概率从一个状态走到另一个状态"：它们是不同的候选。语料所说的"方向维在增长""概率在变小"，说的都是同一个东西的变化。

所以时间排列不是动力。要有动力，至少须是同一份被申报并持续追踪的概率候选：全段固定 F、𝒫、C、𝔯\_P 与动力协议引用。这一要求暂记为 FixedProbabilityAnchor。这里的"同一"只是同一份申报候选（SameDeclaredCandidate），不是跨越资格失效的同一概率身份：若资格经历 1 → 0 → 1，不据此自动断言后一个 1 是前一个概率实体的恢复。

现在已有固定的概率锚。任务闭合了吗？没有。

构造一个状态置位情形。同一份候选在 t\_0 处于状态 S\_0；到 t\_1，一个记录器、外部编辑器或人工操作直接把它的内部状态改写为 S\_1：直接改写 ProbabilityAct、改写 Rel\_ρ、手工增删概率维，或直接写入 D、B、R 的真值。

两端都是真实存在的状态，对象引用也没有换，但 S\_0 与 S\_1 之间没有真实的场动力或合法运行过程连接。状态编辑不是动力。

再构造一个轨迹拼接情形。同一份候选的 t\_0 状态取自一段真实运行，t\_1 状态取自另一段真实运行；两段各自都是合法的场动力，但彼此不相接。

两种情形都保持固定锚，都不是这份概率的动力：前者状态之间没有合法更新，后者状态不在同一条轨迹上。所以还须有两项，分别回答两个问题。是不是同一路：所有评价点及其相邻子段属于同一条实际连续运行历史，不得跨运行实例、跨分支或跨不同历史拼接，记为 SameActualTrajectory。这条路是不是按规矩走出来的：这一实际历史中的各状态更新，服从 Γ\_PDyn 所许可的场动力或运行操作，不得直接改写被评价对象，记为 AdmissibleUpdate。轨迹拼接情形违反前者，状态置位情形违反后者。

现在已有固定锚、同一真实轨迹与合法更新。任务闭合了吗？没有。

构造一个场动力情形。在同一真实轨迹上，同一份候选的周围发生了真实的变化：其他律改变，无关区域沉积，环境输入改变，其他路径在运行。但这份概率自身全段处于静置（ProbabilityAct 在各评价点都为 0），它所承担的相对生成关系不变，它的资格组织也不变。

整个场都有动力，但这份概率自身没有发生任何事。若这也算概率动力，那么只要场在动，一切概率都在"动"，概率动力与场动力无从区分。

所以，在合法的轨迹之外，还须有属于这份概率自己的动力实际性，暂记为 DynActual\_P。它的内部有几种形式，这时还没有确定。

那么再问：这份概率自身"有事发生"，可以是哪些事？下面三支都保持上面已得的全部内容，各自构造一种情形，分别闭合同一个问题的不同方面，最后合流。

第一支。ProbabilityAct 的工作域是 Probability = 1（《概率作用一般式》的进入条件），所以这一支只在相邻两评价点都取得 Probability = 1 时读取作用；若相邻点跨越概率资格的进入或退出，不以工作域外的"ProbabilityAct = 0"补值；若该资格跨越有正式资格组织变化的对象层见证，则由下面第三支的 QualStructDyn 承担；若仅由 Probability 真值的跨越反推其必伴随 D、B、R 正式组织的变化，则须承继 H2 ∧ H3^red ∧ SC\_Hold。保持资格、率关系与资格组织都不变，只让作用状态推移：ProbabilityAct 由 0 到 1（从静置到行使），或由 1 到 1（持续行使），或由 1 到 0（停止行使）。若这种情形也判为"没有概率动力"，一份概率从静置到行使、持续行使、停止行使，在动力中就无处安放。所以须有作用的跨时推移，暂记为 ActDyn\_P，它读取 ProbabilityAct 在相邻评价点之间的推移。这里不引入尚未建立的作用程度或强弱。1 → 1 所谓"持续"，只表示在冻结评价协议下相邻两端都取得 ProbabilityAct = 1；不断言两个评价点之间任意更细的时间尺度上从未中断。持续行使计入作用推移，是因为这一段中概率确在行使，是正在发生的事；0 → 0（持续静置）不计入，那时概率的作用没有发生任何事。0 → 1、1 → 1、1 → 0 是作用动力在冻结评价点上的端点签名，不以端点组合本身代替相邻真实子段中的实际行使事实：若两端都是 1，而这一子段内在冻结粒度下没有任何实际行使的见证，只是两个静态端点，那不是持续行使。

第二支。保持作用状态与资格组织不变，只让由这份概率组织承担的相对生成关系发生跨时变化（这一步至少一端具有概率资格，见下文的资格接触纪律）：Rel\_ρ(t\_k) 推移到 Rel\_ρ(t\_{k+1})。语料所说"每个方向上可被续行的概率在变小"、率关系随沉积度变化而推移（A3.c，只取方向），正是这一类。即使没有作用的起止，这份概率所承担的相对生成关系已经变了。这里不称"续行偏置变了"：依式篇第二十 v1.2，续行偏置 B 专指后续续行对沉积度之差的依赖（抹平干预判定），与 Rel\_ρ 的推移不是一物。所以须有率关系的跨时推移，暂记为 RateDyn\_P。它读取的是相对生成关系本身，不是它的数值表示：

RateDyn\_P ≠ NumericRateShift

概率的相对生成关系在 struct 模式下没有合法数值权重，仍是正式的率关系；经验频率的变化也不能代理它。

第三支。保持 ActDyn = 0、RateDyn = 0，这一步至少一端具有概率资格（见下文的资格接触纪律）。设 V\_P(t\_0) = {v\_1, v\_2}；随后一条新径经合法沉积取得正式 Law-bearing，成为新的概率维，V\_P(t\_1) = {v\_1, v\_2, v\_3}。语料所说"方向维在增长"（B6.a），正是这一类。此时 MultiLawDimension 在两端都可以为 1，Probability 在两端也都可以为 1；只读资格的真值，会漏掉这一真实的结构推移。所以须有概率维正式结构的推移，暂记为 DimStructDyn\_P。

维的结构之外，资格组织还有两层：这些维怎样构成同一个概率问题，以及谁在正式承担相对生成。它们的推移是否已被维结构或前两支吸收？下面各构造一个情形，都保持此前全部所得。

共同绑定结构变化情形。保持 ActDyn = 0、RateDyn = 0，并保持正式维集合及其 Law-bearing 不变。让共同绑定的正式结构发生合法推移：例如各维共同所属的生成关系，其正式生成图式由 g\_C 合法推移为 g\_C′，各维仍同属一个生成关系、仍是互斥后继；或者同一申报域内共同绑定的正式内部关系重组。B 在两端都可以为 1。这时维结构没有变，作用与率关系也没有变，但"这些维怎样构成同一个概率问题"的正式组织变了。若这不算概率动力，这一层的推移无处安放。所以须有共同绑定正式结构的推移，暂记为 BindStructDyn\_P。

率承担组织变化情形。保持 ActDyn = 0；保持 V\_P、𝓛\_P、各维与正式 Law-bearing 的绑定 BearDim(L\_i, v\_i)、共同绑定 B 与 Rel\_ρ 本身全部不变。只改变：同一批已固定的 Law-bearing 职责中，哪些正式承重状态、以何种联合、分布或冗余的组合，实际承担 Rel\_ρ 的形成。例如在 t\_k 由 {W\_1, W\_2} 共同进入 Rel\_ρ 的形成，在 t\_{k+1} 由 {W\_1, W\_3} 承担同一个 Rel\_ρ；W\_1、W\_2、W\_3 始终都在固定的 𝓛\_P 中，各自对维的正式 Law-bearing 资格没有变化。变的只是率承担组织，即这份相对生成关系由组织内部怎样正式承担。它不是 DimStructDyn，因为维的集合、登记族与维的 Law-bearing 绑定都没有变；不是 RateDyn，因为率关系本身没有变；也不是实现更替，因为实现更替是在同一个正式承担职责下把实现由 r\_a 换为 r\_b，而这里变的是正式承担职责的参与与组织本身（见下文实现更替情形）。若这不算概率动力，"这份相对生成由组织内部怎样正式承担"的推移无处安放。所以须有率承担组织正式结构的推移，暂记为 RateBearingStructDyn\_P。

三种情形各自保持另外两层不变，分别逼出三类结构推移，彼此不相包含。合为资格组织的正式结构推移：

QualStructDyn\_P := DimStructDyn\_P ∨ BindStructDyn\_P ∨ RateBearingStructDyn\_P

QualStructDyn 不得缩为 D(t\_k) ≠ D(t\_{k+1})、B(t\_k) ≠ B(t\_{k+1})、R(t\_k) ≠ R(t\_{k+1}) 或 Probability(t\_k) ≠ Probability(t\_{k+1})：三种情形中两端真值都相同，而内部正式结构确有变化。

第三支还须划清一条界线。构造一个实现更替情形：保持 V\_P、正式 Law-bearing 登记、共同绑定、率承担的资格结构、Rel\_ρ 与 ProbabilityAct 都不变，只让某一正式职责的当前实现由 r\_a 换为 r\_b。这只是运行实现或见证的更替，概率的正式组织没有变。所以：

RealizationReplacement ⇏ QualStructDyn\_P，从而 RealizationReplacement ⇏ ProbabilityDyn

但若变化落在正式概率组织本身——概率维的正式成员改变，某维的正式 Law-bearing 资格绑定改变，共同绑定结构改变，或率承担组织的资格改变——则属于 QualStructDyn。这里不涉及"两个不同 Law 身份"的判定：Law 的统一跨时身份问题尚未由本组式闭合。

三支合流。三支闭合的是同一个问题"这份概率自身有什么事发生"的三个方面，彼此不包含：第一支的作用推移可以在率关系与组织都不变时发生，第二支的率推移可以在作用与组织都不变时发生，第三支的组织推移可以在作用与率关系都不变时发生。一个真实的概率动力事件只须其中至少一支成立，不要求三者同时变化。所以：

DynActual\_P^η = ActDyn\_P^η ∨ RateDyn\_P^η ∨ QualStructDyn\_P^η

它们是并列选择的投影，不是合取。

那么再问：三个投影的推移，是否只要发生在这份申报候选身上就够了？

构造一个失格区情形。在同一真实轨迹、合法更新之下，某一对相邻评价点 (t\_k, t\_{k+1}) 上，候选在两端都不具有概率资格（Probability(t\_k) = Probability(t\_{k+1}) = 0），而候选的率关系或候选的资格组织结构在这一步发生了变化。

这一步里没有概率，只有一个尚未成为、或已经不再是概率的候选。它的结构变化只能算"概率候选的结构变化"，不能算这份概率的动力：对象入口说的是"作为概率的状态"确有推移。

再构造一个跨区拼接情形。同一段运行中，前一段 Probability = 1，但作用、率关系与资格组织都没有推移；后一段 Probability = 0，候选结构在其中发生了变化。若把前一段的概率资格与后一段的候选变化合在一起，签出"这份概率有动力"，就是把一处的资格见证与另一处完全失格区中的结构变化拼接起来。

所以，动力实际性的见证步必须与概率资格局部接触。对相邻评价步 k，记：

Contact\_P(k) := Probability(t\_k) = 1 ∨ Probability(t\_{k+1}) = 1

ActDyn 仍按第一支的要求，两端都满足 Probability = 1；RateDyn 与 QualStructDyn 的见证步必须满足 Contact\_P(k) = 1。并且 DynActual 的签出，必须由至少一个与概率资格局部接触的相邻评价步承担；不得把一处的概率资格与另一处完全失格区中的候选结构变化拼接为概率动力。这一纪律记为 QualificationContactBind\_PDyn。

它是动力实际性的见证良构纪律，与"同段见证一致"同一性质：不是新的动力内容，不是第四个投影，也不改变 N\_PDyn 的两部分结构。资格的进入（0 → 1）或退出（1 → 0）所在的那一步，Contact\_P(k) = 1，所以资格跨越的这一步不被接触纪律排除：若有正式资格组织变化的对象层见证，它由 QualStructDyn 承担；若仅从资格真值的跨越反推组织变化，须承继 H2 ∧ H3^red ∧ SC\_Hold。

那么再问：有了三个投影，任务闭合了吗？

构造一个事后改读情形。在同一真实轨迹、合法更新之下，先看到了结果，再选择评价哪些变量、以什么分辨率、按什么方向比较、读取哪个投影、在哪些时点采样，使某一投影恰好显示变化。

这种读法可以从同一段不变的运行中读出"变化"，也可以把真实的变化读成"不变"。所以动力的读取协议必须事前冻结：评价变量、评价分辨率、比较方向、读取投影与采样点都在运行以前确定，记为 FrozenEvalProtocol。

构造一个首尾比较情形。作用在一段运行中经历 0 → 1 → 0；或率关系经历 R\_0 → R\_1 → R\_0；或资格组织经历 V\_0 → V\_1 → V\_0。首尾相同，中间确有事发生。若只比较首尾，这些真实的动力都被漏掉。

所以三个投影都必须沿相邻评价点 (t\_k, t\_{k+1}) 逐步读取，首尾差不能代理动力。逐相邻评价可以保留评价点所覆盖的中间变化，但不能保证捕获任意细尺度的变化：相邻两点之间仍可发生往复（例如作用在两评价点之间经历 0 → 1 → 0，两端都读 0）。这类往复是否进入判断，取决于 Γ\_PDyn 所申报的评价粒度（2.2）。这要求评价点集 T\_η = (t\_0, t\_1, …, t\_n) 良构：严格有序；至少两个评价点（n ≥ 1）；每一对相邻评价点对应真实轨迹的一个子段；不可判的点不得事后删除。记为 WellFormedEvalSet。

把第一、二轮与最后两轮所得合为一段：

LegalProbabilityDynSegment^η := SameActualTrajectory^η ∧ FixedProbabilityAnchor^η ∧ AdmissibleUpdate^η ∧ FrozenEvalProtocol^η ∧ WellFormedEvalSet^η

同段的见证须一致：三个投影都在这一段的同一轨迹、同一评价协议下读取。这一纪律属于合法动力段内部的良构要求，不另立为第三个并列的本体项。

现在已有合法动力段与动力实际性。任务闭合了吗？

继续检验可能加入的结构。以下都由同一个问题产生：是否还有第四种独立的、属于这份概率自身的动力投影，既不能归入作用、率关系或资格组织的推移，又不是别的问题？

观察。经验频率或结果统计的变化，不是概率自身的推移。

表示。数值率、可读性或识出方式的改变，不是率关系本身的改变。

执行。某一次最终落入 v\_i 或改落 v\_j，只是一次执行的结果，不是概率组织的跨时变化。

来源。问的是怎样形成，不是已经形成以后怎样变化，属于《概率源式》。

位置。跨场、跨宿主首先需要身份连续性的判据，这里不涉及。

关系。概率与律、理、意图等对象的关系（语料 B2 "穿过律生态"的关系一面），不是独立的动力投影；它若使这份概率的作用、率关系或资格组织发生推移，就已归入三投影之一。

实现与见证更替。已由实现更替情形排除。

外部贡献。谁使概率发生变化，与概率身上有没有变化，是两个问题。即使这份概率自身不是造成其变化的原因（DynContrib\_P = 0），也不能推出 ProbabilityDyn = 0。

稳定。研究保持、首次实际失效与恢复，不是单个动力段上发生了什么。

可达。研究从给定初态是否存在一条合法有限路径命中目标，不是给定真实路径上的实际动力。

资格真值的变化。Probability 由 1 到 0 或由 0 到 1，是否另成一个投影？在 H2 ∧ H3^red ∧ SC\_Hold 下，Probability ⇔ N\_P，资格真值的改变必伴随 D、B、R 至少一项的改变，从而落入 QualStructDyn；不携该条件时，不能这样断言。这是全篇唯一使用该条件的地方。

所以，在当前冻结的概率语料域内，并在 H2 ∧ H3^red ∧ SC\_Hold 下，没有第四个独立的概率侧动力投影。这一结论只到当前冻结语料的完整性，不断言未来一切理论扩展都绝不可能新增投影。

原任务已经闭合。约束递推到此停止。

至此，已经逼出两部分必要结构：

缺合法动力段：可以从不同候选、不同轨迹、状态编辑、事后改读或首尾比较拼出伪动力。

缺动力实际性：只剩一段真实、对象固定、协议合法的运行，而这份概率自身没有任何推移，只是时间在过去。

五、必要结构的正式命名

第一部分：

合法概率动力段 LegalProbabilityDynSegment^η，由五项组成：

SameActualTrajectory^η：所有评价点及其相邻子段属于同一条实际连续运行历史，不跨运行实例、分支或不同历史拼接。它只回答"是不是同一路"，不回答更新是否合法。

FixedProbabilityAnchor^η：全段固定 F、𝒫、C、𝔯\_P 与动力协议引用；"同一"指同一申报候选，不是跨越资格失效的同一身份。

AdmissibleUpdate^η：这一实际历史中的各状态更新，服从 Γ\_PDyn 所许可的场动力或运行操作，不得直接改写 ProbabilityAct、Rel\_ρ、概率维或 D、B、R 的真值。它回答"这条路是不是按规矩走出来的"。

FrozenEvalProtocol^η：评价变量、分辨率、比较方向、读取投影与采样点事前冻结。

WellFormedEvalSet^η：T\_η 严格有序，至少两点，相邻点对应真实轨迹子段，不可判点不得事后删除。

第二部分：

概率动力实际性 DynActual\_P^η = ActDyn\_P^η ∨ RateDyn\_P^η ∨ QualStructDyn\_P^η。

ActDyn\_P^η：在某一对相邻评价点 (t\_k, t\_{k+1}) 之间，两端都取得 Probability = 1，并且在对应的真实轨迹子段 I\_k 上，ProbabilityAct 确有实际的起、续或止；其端点签名分别表现为 0 → 1、1 → 1、1 → 0（0 → 0 不计入）。其中 1 → 1 只在 I\_k 内确有持续行使的事实时才签出 ActDyn，两端都为 1 本身不充分；这里不要求任意更细的时间尺度上绝不中断。作用动力的对象事实是子段上的实际行使加上端点签名，不是端点组合本身。相邻点跨越资格的进入或退出时，不读取 ProbabilityAct。由此区分：Probability 的 0 → 1 若由正式资格组织的实际变化承担，则属于 QualStructDyn，其中第一次形成的来源问题另由《概率源式》研究；若只给出 Probability 真值由 0 到 1，而未直接给出资格组织的变化，则须在 H2 ∧ H3^red ∧ SC\_Hold 下才能把这一跨越归入 QualStructDyn；ProbabilityAct 的 0 → 1 是已有资格时从静置进入作用。端点为 0 → 0 而子段内另有在申报粒度下完全消隐的起止者，不在本定义的检出范围之内（2.2 评价粒度限定）。

RateDyn\_P^η：在某一对满足 Contact\_P(k) = 1 的相邻评价点之间，由这份概率组织承担的相对生成关系 Rel\_ρ 发生推移；读取的是关系本身，不是数值表示或频率。

QualStructDyn\_P^η = DimStructDyn\_P^η ∨ BindStructDyn\_P^η ∨ RateBearingStructDyn\_P^η：在某一对满足 Contact\_P(k) = 1 的相邻评价点之间，概率维的正式结构、共同绑定的正式结构或率承担组织的正式结构至少一项发生推移；不是资格真值的比较，也不是实现或见证的更替。RateBearingStructDyn 与 RateDyn 不重叠：前者是承担组织变而关系不变，后者是关系本身变。

这里的三个投影及其内部各类，都是对象层的事实，取普通二值，析取为普通析取：发生了就是发生了，与当前能否读出无关。"材料不足、不可判"属于形式读数层，不进入这里的对象层定义；否则会出现"现实确有动力、只是暂时读不出"时主定理失效的混层。形式读数 Read^M\_{ActDyn}、Read^M\_{RateDyn}、Read^M\_{QualStructDyn} ∈ {1, 0, ⊥} 及其三值析取 ∨₃，交由《概率动力数理式》定义；形式读数为 ⊥，不推出对象层动力成立或不成立。

资格接触纪律 QualificationContactBind\_PDyn：Contact\_P(k) := Probability(t\_k) = 1 ∨ Probability(t\_{k+1}) = 1。ActDyn 的见证步两端都须 Probability = 1；RateDyn 与 QualStructDyn 的见证步须 Contact\_P(k) = 1；DynActual 的签出须由至少一个满足 Contact\_P(k) = 1 的相邻评价步承担，不得把一处的资格见证与另一处完全失格区中的候选结构变化拼接。它是 DynActual 的见证良构纪律，性质与同段见证一致相同，不是新的动力内容，不是第四投影，不是第三个主合取项。纯 0 → 0 区间中的候选率关系或候选资格结构的变化，只算概率候选的结构变化，不单独签出 ProbabilityDyn。

故概率动力必要结构为：

N\_PDyn := LegalProbabilityDynSegment^η ∧ DynActual\_P^η

六、必要性与非冗余审查

删除合法动力段。三个投影失去共同的合法轨迹与冻结的评价域，可以从不同历史或事后采样拼出伪动力（时间并置、状态置位、轨迹拼接、事后改读、首尾比较五种情形重新进入）。不可删。

删除动力实际性。保留一段完全真实、对象固定、协议合法的轨迹，而概率全程静置、率关系与资格组织全程没有推移，只剩时间经过（场动力情形重新进入）。不可删。

删除 ActDyn。从静置进入作用、持续作用或停止作用的情形被漏掉。不可删。

删除 RateDyn。相对生成关系真实改变、而作用与资格组织都不变的情形被漏掉。不可删。

删除 QualStructDyn。新的 Law-bearing 概率维进入或退出、资格组织重组、而作用与既存率关系都不变的情形被漏掉。不可删。其内部三类也各不可删：删 DimStructDyn，新维情形漏掉；删 BindStructDyn，共同绑定结构变化情形漏掉；删 RateBearingStructDyn，率承担组织变化情形漏掉。

合并三个投影。若压成一个笼统的"概率侧有变化"，就失去三者各自的上游判据与各自独立的失败情形。不可合并。

合法动力段内部的五项，各由其情形逼出：删 FixedProbabilityAnchor，时间并置进入；删 SameActualTrajectory，轨迹拼接进入；删 AdmissibleUpdate，状态置位进入；删 FrozenEvalProtocol，事后改读进入；删 WellFormedEvalSet，首尾比较与事后删点进入。

同段绑定是否另立第三主项：不立。它是合法动力段内部的良构纪律。

删除资格接触纪律 QualificationContactBind。失格区情形与跨区拼接情形重新进入：纯 0 → 0 区间中的候选结构变化，或把一处的概率资格与另一处失格区中的候选变化拼在一起，都会被签为概率动力。不可删。它同样不另立主项，而是 DynActual 的见证良构纪律。

弱化与替换：

以首尾差替代逐相邻读取：首尾比较情形使之失败。

以端点状态替代作用动力的实际性：若 1 → 1 只凭两端 ProbabilityAct = 1 就签出 ActDyn，则两端静态、子段内没有实际行使见证的情形会被误签。所以端点签名不能替代实际的作用过程。

以任意系统变化替代概率侧变化：场动力情形使之失败。

以概率值或资格真值的变化替代 QualStructDyn：第三支的新维情形使之失败。

以数值率变化或频率变化替代 RateDyn：先行之辨与第二支使之失败。

以实现更替替代 QualStructDyn：实现更替情形使之失败。

以动力贡献 DynContrib 作为必要条件：第四投影审查中的外部贡献一项使之失败。

承重分类：

LegalProbabilityDynSegment 的五项、DynActual 及其三个投影、QualStructDyn 的三类：逼出项，分别回指第四节的时间并置、状态置位、轨迹拼接、场动力、三支情形（第三支含新维、共同绑定结构变化、率承担组织变化三个情形）、实现更替、事后改读与首尾比较情形；资格接触纪律回指失格区与跨区拼接情形，它是见证良构纪律，不是结构项。

概率资格、作用、源式的结论与动力语料：承继项。

χ̄\_PDyn、η：工作域项。

H2 ∧ H3^red ∧ SC\_Hold：承继的条件项，只在第四投影审查的资格真值一项承重。

当前推导最小：{ LegalProbabilityDynSegment, DynActual } 两部分，DynActual 内三个投影为析取。它只表示在当前冻结任务域内没有少掉逼出的差异、也没有放进多余的差异；不证明充分方向，不主张唯一的物理实现，也不证明语料升版以后绝无新增结构。

※※※

七、必要结构式、符号与读回

设：

χ̄\_PDyn = (F, 𝒫, C, 𝔯\_P, Γ\_PDyn)：动力候选锚。

η：申报的一段跨时运行。T\_η = (t\_0, …, t\_n)，n ≥ 1：事前冻结的评价点集。

V\_P(t)、𝓛\_P(t)、Rel\_ρ(t)、ProbabilityAct(t)、D(t)、B(t)、R(t)：动力状态，允许变化。

ProbabilityDyn^η：任务侧谓词，只登记一件任务事实：申报概率候选在运行 η 中，作为概率的状态确有推移，且这一推移相对于 Γ\_PDyn 所申报的评价粒度判断（2.2）。它的语义锚是动力语料，不含 N\_PDyn 的任何内容。

所得必要结构式：

H2 ∧ H3^red ∧ SC\_Hold ⇒ \[ ProbabilityDyn^η ⇒ LegalProbabilityDynSegment^η ∧ ( ActDyn\_P^η ∨ RateDyn\_P^η ∨ QualStructDyn\_P^η ) \]

读回：若申报概率候选在运行 η 中确有概率动力，那么这段运行是同一候选在同一真实轨迹上、经合法更新、按事前冻结的协议与良构的评价点集读取的一段；并且在某一对相邻评价点之间，这份概率的作用、它所承担的相对生成关系、或它的资格组织的正式结构，至少一项确有推移。

三个投影都沿相邻评价点读取，全部对象都在同一 η 与同一 Γ\_PDyn 之下求值。

只证明上述必要方向，不证明它们足以成立概率动力。

※※※

八、概率动力必要结构定理

设 χ̄\_PDyn 与 η 满足工作域，且 ProbabilityDyn^η 成立。则在 H2 ∧ H3^red ∧ SC\_Hold 下：

一、LegalProbabilityDynSegment^η 成立；

二、DynActual\_P^η = 1，即 ActDyn、RateDyn、QualStructDyn 至少一项为 1。

证明

由第四节的连续递推，FixedProbabilityAnchor、SameActualTrajectory、AdmissibleUpdate、FrozenEvalProtocol、WellFormedEvalSet 分别由时间并置、轨迹拼接、状态置位、事后改读与首尾比较情形留下的未闭合处逼出。每一项若取消，都会在此前其余所得保持的情况下，重新容纳一个与 ProbabilityDyn 任务不相容的合法反例情形。因此 ProbabilityDyn^η 成立时，这五项不可缺，LegalProbabilityDynSegment^η 成立。这里不宣称这五个情形穷尽了一切不合法的动力段。

这里三个投影都按第五节的定义取值，其见证步已经内含资格接触纪律。若三个投影都为 0，则在申报评价粒度下，作用、率关系与资格组织在与概率资格接触的各步上都没有概率侧的推移；这里只排除申报粒度下的动力，不把投影为 0 解释为真实子段绝无动力；第四节的场动力情形已经证明，仅有其余的场变化不能承担 ProbabilityDyn，与 ProbabilityDyn^η 矛盾。若某一推移不属于三投影，由第四投影审查，它或属观察、表示、执行、来源、位置、关系、实现更替、外部贡献、稳定、可达，不是概率自身的推移；或是资格真值的变化，而在 H2 ∧ H3^red ∧ SC\_Hold 下它落入 QualStructDyn。故 DynActual\_P^η = 1。

证毕。

定理强度声明：本定理是必要方向定理。它不断言：

一、合法动力段与动力实际性足以成立概率动力；

二、三个投影须同时发生；

三、Probability 须在全段保持为 1；

四、资格失效后再次取得资格是同一概率身份的恢复；

五、这份概率自身是造成其变化的原因；

六、在语料升版以后不可能出现第四个投影；

七、细于申报评价粒度、在该粒度下完全消隐的子段内往复都被检出。

Status：Conditional，条件为 H2 ∧ H3^red ∧ SC\_Hold；动力判断相对于申报评价粒度（2.2）。

※※※

九、击穿论证

以下都须保持工作域与进入条件。

K-PDyn1：存在 ProbabilityDyn，而没有同一真实合法轨迹段。

K-PDyn2：存在 ProbabilityDyn，而可以任意更换申报概率对象，不影响判定。

K-PDyn3：存在 ProbabilityDyn，而 ActDyn = RateDyn = QualStructDyn = 0。

K-PDyn4：存在第四种独立的概率侧动力，不能归入三个投影，也不是观察、表示、执行、来源、位置、关系、实现更替、外部贡献、稳定或可达问题。

K-PDyn5：删除三个投影中的任意一项，不会遗漏合法的概率动力情形。

K-PDyn6：只比较首尾即可完整判定动力，不存在中间有事而首尾相同的合法轨迹。

K-PDyn7：允许在结果出来以后改变评价点、评价变量或读取规则，而不会制造伪动力。

K-PDyn8（条件化）：在 H2 ∧ H3^red ∧ SC\_Hold 成立时，Probability 资格退出，却不存在任何 D、B、R 及其正式资格组织的变化。

K-PDyn9：存在 ProbabilityDyn，而其全部动力见证步都落在 Probability 两端皆为 0 的失格区中，或只能靠把一处的资格见证与另一处失格区中的候选变化拼接才能签出。

非击穿情形：某一投影的形式读数为 ⊥；Probability 在全段不恒为 1；这份概率不是自身变化的原因；实现更替而组织不变；经验频率或数值率变化而关系不变；细于申报评价粒度、在该粒度下完全消隐的子段内往复未被检出。

十、条件性后承

一、动力与当前作用。ActDyn 读取的是 ProbabilityAct 的跨时推移，只在相邻两点都有概率资格时读取。某一时刻的 ProbabilityAct 对象层取值，承继《概率作用一般式》《概率作用必然式》的双向闭合；需要形式读出时，承继《概率作用数理式》的接口及其条件。

二、动力与来源。首次成概率（0 → 1 的第一次）的来源问题由《概率源式》研究；同一次 0 → 1 若有正式资格组织变化的对象层见证，可由这里的 QualStructDyn 登记；若仅从资格真值的跨越反推该组织变化，则承继 H2 ∧ H3^red ∧ SC\_Hold。已经成概率以后的其他推移同样归这里。同一事件可以有来源面，也可以有动力面，两式问的是不同问题。1 → 0 → 1 中后一个 1 是否为同一概率身份的恢复，不在这里断言。

三、条件闭包。H2 ∧ H3^red ∧ SC\_Hold 只在第四投影审查的资格真值一项承重：把资格真值的改变落到 D、B、R 组织的改变。ActDyn、RateDyn 与直接读取正式资格结构变化的 QualStructDyn，本身的必要性都不携新 H。形式层的 H\_LawRead、H\_PAct-Rep、H\_ρRep^- 不进入本体总式，由后续形式化按实际回读路径承继。

十一、组内接口

与前十篇：承继资格、作用、源式与动力语料，不修改它们的定义与条件传播纪律。

第十二篇《概率动力数理式》：承接本篇的评价粒度范围，并把粒度限定与形式读数的 ⊥ 分开；形式化合法动力段的五项、T\_η、相邻评价、三个投影，定义各投影的三值形式读数与三值析取 ∨₃，给出形式回读，并按实际路径传播各 H。

第十六篇《概率稳定式》：研究许可变化轨迹上的保持、首次实际失效、恢复与韧性。

结语

概率可以在不同时刻各自成立。

但把不同时刻的状态排在一起，不是动力；把状态改写过去，不是动力；把两段运行拼起来，也不是动力。

所以，须有同一份概率沿同一条真实轨迹、经合法更新走过的一段路，读法事先冻结，评价点逐个相接。

路走过了。

但若这份概率自身什么也没变，只是场在动、时间在过，那也不是概率动力。

所以，这份概率自身须真有事发生：它的作用推移，或它承担的相对生成关系推移，或构成它资格的正式组织推移。三者至少其一。

再压成一句：

概率的动力，是同一份概率在一段真实合法的路上，自身的作用、率关系或资格组织确有推移。
