# 概率动力数理式

## 第一节　目的

为概率动力的必要结构建立形式系统，使任一申报概率候选在一段实际运行上的动力结构，都可以从真实运行记录与上游形式接口出发实际求值，并得到成立（1）、完整求值后不成立（0）或合法形式材料不足（⊥）的确定读数。

所形式化的结构出自《概率动力一般式》v1.0：

N\_PDyn = LegalProbabilityDynSegment^η ∧ DynActual\_P^η

LegalProbabilityDynSegment^η = SameActualTrajectory^η ∧ FixedProbabilityAnchor^η ∧ AdmissibleUpdate^η ∧ FrozenEvalProtocol^η ∧ WellFormedEvalSet^η

DynActual\_P^η = ActDyn\_P^η ∨ RateDyn\_P^η ∨ QualStructDyn\_P^η

QualStructDyn\_P^η = DimStructDyn\_P^η ∨ BindStructDyn\_P^η ∨ RateBearingStructDyn\_P^η

并带有其已冻结的见证纪律：ActDyn 要求相邻两端都有概率资格且子段内确有实际行使；RateDyn 与 QualStructDyn 的见证步须与概率资格相接（QualificationContactBind\_PDyn）。

形式目标为：

S\_PDyn ↦ M\_PDyn

即：对每一个承重形式量，说明它从现实哪里取得、怎样计算、材料不足时怎样落为 ⊥、可以回读为什么结构事实；给出求解顺序、各层负读出所需的覆盖，以及回读与条件传播规则。回答不了这四问的符号，不进入这里的系统。

## 第二节　核心论题

给定同一份申报概率候选 χ̄\_PDyn = (F, 𝒫, C, 𝔯\_P, Γ\_PDyn) 与一段申报实际运行 η，怎样从运行基底的真实记录与已有概率形式系统中，判断：

(1) 这是不是同一份候选沿同一条实际运行、经合法更新、按事前冻结的读法与良构评价点走出的一段；

(2) 在这一段中，是否真实发生了至少一种概率侧动力：作用的起、续、止；相对生成关系本身的推移；资格正式组织的推移；

(3) 怎样排除端点伪动力、表示伪变化、经验频率变化、失格区候选变化、纯实现更替与跨历史拼接；

(4) 怎样严格区分 1、0 与 ⊥：1 为明确成立，0 为完整求值后明确不成立，⊥ 为合法形式材料不足。

须在形式上区分下列几组对象：

端点签名 ≠ 子段中的实际行使

数值或表示的变化 ≠ 相对生成关系本身的变化

资格真值的变化 ≠ 资格正式组织的变化

实现更替 ≠ 正式承担组织的变化

单一评价上的承担组合 ≠ 整个率域上的承担组织

没有找到正证据 ≠ 否定

### 3.1 运行数据包

定义 3.1 \[辅\]

Ω^η\_PDyn = (RunID, BranchID, χ̄\_PDyn, Γ\_PDyn, T\_η, {I\_k}, {S\_k}, ℰ\_η, ℋ\_η)

RunID：实际运行实例的标识。BranchID：实际历史分支的标识。T\_η = (t\_0, …, t\_n)，n ≥ 1：事前冻结的评价点。I\_k：真实运行中连接 t\_k 与 t\_{k+1} 的实际子段，k = 0, …, n − 1。S\_k：评价点 t\_k 的正式状态快照。ℰ\_η：实际事件记录。ℋ\_η：状态更新、操作、来源与协议的历史。

这些输入由场系统、运行基底与上游数理式提供；这里不另建物理运行系统。Ω^η\_PDyn 只是求解输入的组织形式，不是新的本体。

### 3.2 三值逻辑

定义 3.2 \[辅\]

𝕋\_3 = {1, 0, ⊥}。

∧₃：有 0 即 0；无 0 而有 ⊥ 即 ⊥；全 1 才为 1。

∨₃：有 1 即 1；无 1 而有 ⊥ 即 ⊥；全 0 才为 0。

¬₃：1 ↦ 0，0 ↦ 1，⊥ ↦ ⊥。

∃₃ k Q\_k（存在型聚合）：存在一步 Q\_k = 1 时为 1；没有 1 而至少一个承重步为 ⊥ 时为 ⊥；只有全部申报承重步都完成求值且都为 0，并有相应覆盖证书（定义 3.17）时，才为 0。

正证据优先：一个明确的 1 不被其他步或其他分支的 ⊥ 洗掉。不得：没有找到正证据 ⇒ 0。

### 3.3 同一实际轨迹

定义 3.3 \[辅/S\]

TrajLink\_k ∈ 𝕋\_3。取 1，当且仅当可以核实：t\_k、t\_{k+1} 的状态与 I\_k 都属于同一 RunID 与同一 BranchID；I\_k 真实存在，Begin(I\_k) = t\_k，End(I\_k) = t\_{k+1}；I\_k 与 I\_{k−1}、I\_{k+1} 在实际历史上连续接合；没有把现实运行、复走、另一历史或另一分支拼接进来。有明确的拼接或分支不一致时取 0；运行或分支记录不可取得时取 ⊥。

Read\_{SameActualTrajectory}^M = ∧₃\_k TrajLink\_k

### 3.4 固定概率锚

定义 3.4 \[S\]

Read\_{FixedProbabilityAnchor}^M = 1，当且仅当在全部评价点上，F、𝒫、C、𝔯\_P、Γ\_PDyn 的引用保持同一。有引用改变时取 0；引用不可取得时取 ⊥。V\_P(t)、𝓛\_P(t)、Rel\_ρ(t)、ProbabilityAct(t) 不列入固定锚：它们正是允许变化的动力状态。

### 3.5 合法更新

定义 3.5 \[辅/S\]

对每一子段 I\_k 取得真实的更新证书：

κ\_k^upd = (Ops(I\_k), Sources(I\_k), ProtRef, TargetWriteLog(I\_k))

ProtocolAllowed\_k ∈ 𝕋\_3：Ops(I\_k) 中每一项操作都属于 Γ\_PDyn 所许可的场动力或运行操作（包括底层已许可的 Mask、Avail、Freeze 等），并有可追踪的来源链。

NoDirectTargetWrite\_k ∈ 𝕋\_3：TargetWriteLog(I\_k) 中没有绕过合法运行结构直接写入以下对象的记录：ProbabilityAct；Rel\_ρ；正式概率维；D、B、R 的真值；QualStructDyn 或其他派生动力标签。

合法的外部干预本身不是非法更新：只要状态变化有可追踪的运行来源链，它就是合法更新。

UpdateOK\_k = ProtocolAllowed\_k ∧₃ NoDirectTargetWrite\_k

Read\_{AdmissibleUpdate}^M = ∧₃\_k UpdateOK\_k

来源链或写入日志不可取得时取 ⊥；不得因"没有发现非法操作"签 1。

### 3.6 冻结评价协议

定义 3.6 \[S\]

Γ\_PDyn = (AnchorRef, VarSet, ProjSet, T\_η, Resolution, CmpRules, RepRules, FreezeStamp, Version)

Read\_{FrozenEvalProtocol}^M = 1，当且仅当：FreezeStamp 早于一切承重评价；全程 Version 一致；没有事后增删评价点；没有事后更改比较规则、读取方向、分辨率或投影集合。有明确的事后修改时取 0；协议的修改历史不可审计时取 ⊥。

### 3.7 良构评价点集

定义 3.7 \[S\]

区分事前申报的评价点 T\_η^decl 与实际求值所用的索引 T\_η^read。

Read\_{WellFormedEvalSet}^M = 1，当且仅当：t\_0 \< t\_1 \< … \< t\_n，n ≥ 1；每一对相邻点都有真实的 I\_k；Index(T\_η^read) = Index(T\_η^decl)，即所有事前申报的点都保留在求值索引中。某一评价点不可判时，它的读数可以为 ⊥，但不得事后删除这个点；删除了申报点取 0；索引记录不可取得时取 ⊥。

### 3.9 同见证绑定键

定义 3.9 \[辅\]

K\_k^PDyn = (𝒫, RunID, η, t\_k, t\_{k+1}, I\_k, Γ\_PDyn)

每一条承重证据（轨迹、更新、端点读数、作用证书、率关系表示、组织快照）都须携带其 K\_k^PDyn。

SamePDynBind\_k^M ∈ 𝕋\_3：1，第 k 步所用的全部承重证据的键一致，并与合法动力段所用的 η、RunID、Γ\_PDyn 一致；0，键明确不一致（例如合法段取自 η\_1、动力证据取自 η\_2）；⊥，键材料不足。

### 3.10 端点资格与资格接触

定义 3.10 \[辅\]

P\_k := Read\_Probability(t\_k) ∈ 𝕋\_3，取自《概率判定式》的判词 Det\_P 在 t\_k 的值，或《概率数理式》在 t\_k 的读数经其回读所得。

Contact\_k^M := P\_k ∨₃ P\_{k+1}：至少一端明确为 1 时为 1；两端都明确为 0 时为 0；无一端为 1、而至少一端为 ⊥ 时为 ⊥。

资格接触不是第四个动力投影，也不是 N\_PDyn 的第三个主项，而是逐步动力见证的归属门。

### 3.11 作用动力

定义 3.11 \[辅/S\]

上游输入：复用《概率作用数理式》的现实当前作用证书，不另定义第二套 ProbabilityAct。对子段 I\_k，收集合法的作用正见证：

𝒲\_k^Act = { w^M：w^M 的实际支撑落在 I\_k 内，且 Read\_{N\_PAct}^M(w^M) = 1，并携带 K\_k^PDyn }

端点作用读数：A\_k := ProbabilityAct 在 t\_k 的读数 ∈ 𝕋\_3。1 取自 Read\_{N\_PAct}^M = 1 经《概率作用数理式》正向回读与《概率作用必然式》；0 取自 Read\_{N\_PAct}^M = 0 经负向回读；否则 ⊥。

作用评价单元：由 Γ\_PDyn 中事前给定的 Resolution\_Act，把 I\_k 分为 𝒰\_k^Act = { u\_{k,1}, …, u\_{k,m\_k} }。不要求任意无限细的时间上每一瞬都有作用。

单元读数 a\_u ∈ 𝕋\_3：1，存在 w ∈ 𝒲\_k^Act，Support(w) ∩ u ≠ ∅；0，单元 u 的作用事件负覆盖完整（Cov^{Act}(u) = 1），且没有这样的 w；⊥，其他情形。

来源绑定：OnsetBind\_k ∈ 𝕋\_3 为 1，当且仅当子段内作用由 0 进入 1 的那一单元与一条合法更新链（定义 3.5）相接，且其证据携带 K\_k^PDyn；CessationBind\_k 同样定义于由 1 进入 0 的那一单元。

逐步状态 StepAct\_k 只在 P\_k = P\_{k+1} = 1 时求值：

Start：A\_k = 0，A\_{k+1} = 1，OnsetBind\_k = 1。

Continue：A\_k = A\_{k+1} = 1，且对一切 u ∈ 𝒰\_k^Act，a\_u = 1（ActCover\_k = 1）。

Stop：A\_k = 1，A\_{k+1} = 0（t\_{k+1} 的负读出完整），CessationBind\_k = 1。

Idle：A\_k = A\_{k+1} = 0，且对一切 u ∈ 𝒰\_k^Act，a\_u = 0。若 A\_k = A\_{k+1} = 0 而某个 a\_u = 1，StepAct\_k = ⊥：这不是"不知道有没有作用"，而是当前冻结评价粒度与已观察到的段内起止事实不相容，不能按现行三个合法端点签名完成这一步的归类；既不签 Idle，也不自行签 ActDyn = 1。

⊥：其余情形，包括只有端点变化而没有来源绑定、端点 1 → 1 而有单元不为 1、负读出不完整等。

逐步状态只有 Start、Continue、Stop、Idle 四种正负类型，承继《概率动力一般式》ActDyn 的端点签名 0 → 1、1 → 1、1 → 0，0 → 0 不计入。若冻结评价粒度粗到把一次"起又止"包进一个相邻段、使端点为 0 → 0，这一对端点不能自行扩展为作用动力；应检查 FrozenEvalProtocol 与 WellFormedEvalSet 的分辨率是否足以把真实的起止暴露为相邻评价的变化。端点 1 → 1 而中间有单元不为 1，不是 Continue；在现行对象口径下这一步记 ⊥，由更细的申报评价点另行暴露其起止。

若 P\_k 或 P\_{k+1} 明确为 0，这一步不在作用的工作域内，记 StepAct\_k = NA（不适用），它对 ActDyn 的聚合按 0 处理；若 P\_k 或 P\_{k+1} 为 ⊥ 而无一为 0，StepAct\_k = ⊥。

步读数：Q\_k^Act = 1 当 StepAct\_k ∈ {Start, Continue, Stop} 且 SamePDynBind\_k^M = 1；Q\_k^Act = 0 当 StepAct\_k ∈ {Idle, NA}；否则 ⊥。

Read\_{ActDyn}^{M,η} = ∃₃ k Q\_k^Act

1 → 1 只是端点签名，不是 Continue 的充分条件；Continue 须全部作用单元都有实际行使见证。不以"后面没有看到作用事件"代理停止。

### 3.12 率关系动力

定义 3.12 \[辅/S\]

上游的相对生成关系按评价定义：Rel\_ρ^M(ν)，ν ∈ Eval(𝔯\_P)。所以时刻 t\_k 的率关系取为整个率域上的关系族：

ℛ\_k := \[ ν ↦ Rel\_ρ^M(ν; t\_k) \]，ν ∈ Eval(𝔯\_P)

逐评价的同一性 SameRel\_k(ν) ∈ 𝕋\_3：

struct → struct：按上游 struct 表示的同一性判据；不能合法比较时取 ⊥。

weight → weight：比较正比例等价类 \[w\_k(ν)\]\_ρ 与 \[w\_{k+1}(ν)\]\_ρ；若 w\_{k+1} = a·w\_k，a \> 0，则是同一关系。所以 (1, 2) → (3, 6) 不是关系变化，(1, 2) → (1, 3) 是关系变化。

struct ↔ weight：只有上游已有合法的共同表示桥时才比较；没有桥时取 ⊥。表示模式的改变本身不推出关系变化。

对象同一性：SameRel\_k^M ∈ 𝕋\_3 回答两端表示的是不是同一个正式的相对生成关系对象。若底层把它展开为关系族 ν ↦ Rel\_ρ(ν)，只有当冻结表示协议能够完整判断这一关系族的身份时，才签 1 或 0：对一切 ν 都 SameRel\_k(ν) = 1 时为 1，存在 ν 使 SameRel\_k(ν) = 0 时为 0，否则为 ⊥。DomainEvalMode 的 a.e. 规则用于率域上的资格与率承担聚合，不用于认定关系对象的身份：若现有 measure 型接口只足以作资格聚合，而不足以判断关系对象的身份，SameRel\_k^M = ⊥，不擅自宣布零测评价上的变化不算变化。

RelChange\_k^M := ¬₃ SameRel\_k^M

不得以上游率承担诊断用的 d\_ρ、ε\_ρ 定义动力阈值：不得写 RateDyn = 1 ⇔ d\_ρ \> ε\_ρ。一个真实但在当前表示分辨率下分辨不出的关系变化，取 ⊥，不取 0。经验频率、数值大小、表示模式、作用状态或承担组织的变化，都不代理 RelChange。

步读数：Q\_k^Rate := Contact\_k^M ∧₃ RelChange\_k^M ∧₃ SamePDynBind\_k^M

Read\_{RateDyn}^{M,η} = ∃₃ k Q\_k^Rate

纯 0 → 0 失格区中候选率关系的变化，因 Contact = 0 而不签出。

### 3.13 正式维组织

定义 3.13 \[辅\]

𝔇\_k = (V\_k, 𝓛\_k, 𝔟\_k^Dim)，𝔟\_k^Dim = { (W\_i, v\_i)：W\_i ∈ 𝓛\_k，BearDim^M(W\_i, v\_i) = 1 }

比较的是正式维成员、正式 Law-bearing 登记与正式 BearDim 绑定，不比较见证数量或当前实现数量。

DimDiff\_k ∈ 𝕋\_3：1，𝔇\_k 与 𝔇\_{k+1} 在正式维成员、登记或绑定上明确不同（例如新维 v\_3 已取得正式 Law-bearing 而进入 V\_P）；0，三者都明确相同；⊥，快照不可取得，或比较依赖跨时 Law 或职责的身份而这一身份不可合法确定。这里不自行建立统一的 Law 跨时身份判据。

### 3.14 共同绑定组织

定义 3.14 \[辅\]

\_k^Bind = (PosBind\_k, DomainBind\_k, GenBind\_k)

其内容至少包括：续行位的正式身份；冻结生成域；正式生成关系身份 g\_C；维与生成关系的绑定；各维的正式后继兑现域；互斥后继结构。不能只保存 SameContinuationPosition、SameGenerationDomain、SameGenerationRelation 三个布尔值。

### 3.15 率域级正式承担组织

定义 3.15 \[辅\]

对每一评价点 t\_k 与合法评价 ν ∈ Eval(𝔯\_P)，令 ℰ^real\_{k,ν} 为该时点、该评价下可合法读取的实际评价实现集合，其成员与来源由上游评价实现接口与运行基底提供。若该集合不能完整取得，依赖它的承担组织比较为 ⊥。

RoleSet\_{k,ν}(G, e) = { W\_i ∈ 𝓛\_P：G ∩ GenIn(W\_i, ν) ≠ ∅ 且 EvalRateBind^M(W\_i, ν, e) = 1 }，G ∈ MinSuff\_ρ(ν)，e ∈ ℰ^real\_{k,ν}

ℋ\_{k,ν}^ρ = { RoleSet\_{k,ν}(G, e)：G ∈ MinSuff\_ρ(ν)，e ∈ ℰ^real\_{k,ν}，RoleSet\_{k,ν}(G, e) ≠ ∅ }

每一个 RoleSet 都在同一个实际实现 e 上取得，不把一个评价下不同实际实现的证书拼在一起；多实现与热冗余各自保留为不同的超边，不压成唯一实现。

空的 RoleSet 不进入：上游允许完全外部的冗余机制作为极小充分组存在，只要申报组织另有实际承担即可；这些纯外部充分组不含申报组织的任何职责，不属于这份概率自身的承担组织。比较的始终是申报组织内部哪些正式 Law-bearing 职责以怎样的组合实际承担。外部机制的出现、消失或重组，不单独签出承担组织的变化。

整个率域上的正式承担组织：

𝔅\_k^ρ = \[ ν ↦ ℋ\_{k,ν}^ρ \]，按冻结协议能够合法识别的正式组织身份逐评价比较。DomainEvalMode 的 a.e. 规则用于 DomainRelativeRateBearing 这一资格的率域聚合，不用于认定正式承担组织的身份：资格在两端都保持 R = 1，内部承担结构仍可以变化。

角色组合保留为超边族，不压成活跃角色的并集：{{W\_1, W\_2}, {W\_3}} 与 {{W\_1}, {W\_2, W\_3}} 的角色并集相同，承担组织不同。

角色投影 RoleProj：上游率承担证书中的实现 r\_i、贡献 c\_i、子段 Z\_i^ρ 与评价内实际实现 e，只用于证明正式职责 W\_i 确实在同一个 e 上承担，并据以把职责分组为超边；跨时比较前一律投影到职责层，每条超边只保留 W\_i。所以只发生 W\_2(r\_a) → W\_2(r\_b) 而正式职责、正式绑定与角色组合都没有变化时，承担组织不变。

BearOrgDiff\_k ∈ 𝕋\_3：1，存在某一评价 ν，其超边族 ℋ\_{k,ν}^ρ 与 ℋ\_{k+1,ν}^ρ 明确不同；0，对一切评价都明确相同；⊥，某些评价的极小充分组或绑定不可求，或底层只能提供 a.e. 的资格聚合而不能确定完整的承担组织。

命题 4.6　超边组合的变化可以签出。若角色并集不变而某一评价上的超边族明确改变，且完整组织身份接口可判，则 BearOrgDiff\_k = 1；两端 DomainRelativeRateBearing 都为 1 不妨碍这一结论。在 Contact\_k = 1、SameRel\_k = 1、SamePDynBind\_k = 1 时，由此得 Q\_k^BearStruct = 1。

命题 4.7　跨段拼证被排除。若合法段与动力证据取自不同的 η、RunID 或 Γ\_PDyn，则 SamePDynBind\_k^M = 0，相应的 Q\_k 为 0。

## 第五节　运行与求解

### 5.1 求解顺序

1\. 校验 χ̄\_PDyn、η、Γ\_PDyn、T\_η 的申报（PD-M1）。

所以不新立统一的 H\_PDyn-Rep。

### 7.3 负向回读与资格接触

(7.2) Read\_{N\_PDyn}^M = 0 ⇒ N\_PDyn = 0，在两种情形下成立：Read\_{LegalSeg}^M = 0 且来自有覆盖的直接失败（不携 H）；或 Read\_{DynActual}^{M,η} = 0，各层覆盖完整，并按实际失败路径承继条件：ActDyn 支中，某步因资格工作域失败（NA）取得 0 时，不携 H\_PAct-Rep，但其所依据的 Probability = 0 按《概率判定式》的实际负判路径承继相应条件；明确不是合法端点签名、或作用第一层当前发生的完整失败而取得 0 的，不携 H\_PAct-Rep；只有该 0 承重于作用职责兑现层的负表示时才携 H\_PAct-Rep；RateBearingStructDyn 支承继 H\_ρRep^-；其余直接表示。

资格接触：一端 P\_k 正判为 1 时，Contact = 1 按该正判路径回读。若要以 Contact = 0 作为结构层的负结论，两端 Probability = 0 的结构负判须按《概率判定式》的实际失败路径分别传播其条件，必要时包括 H2 ∧ H3^red 与相应的负端表示条件。这只影响形式负回读，不进入对象层定义。

未决：Read = ⊥ 既不推出对象层动力成立，也不推出不成立。

### 7.4 禁止回读

不得：Read\_{N\_PDyn}^M = 1 ⇒ ProbabilityDyn。充分方向属于第十三篇《概率动力必然式》，它以对象层 N\_PDyn = 1 为前件。

不得：端点 1 → 1 ⇒ Continue；数值或表示变化 ⇒ RateDyn；实现更替 ⇒ QualStructDyn；资格真值差 ⇒ 组织变化；d\_ρ \> ε\_ρ ⇒ RateDyn；没有找到正证据 ⇒ 0。

### 7.5 纯形式辅助量

以下不回读为概率本体的新组成：Ω^η\_PDyn、TrajLink、κ^upd、UpdateOK、K\_k^PDyn、SamePDynBind、P\_k、Contact、A\_k、a\_u、𝒰\_k^Act、OnsetBind、CessationBind、StepAct、ℛ\_k、SameRel、RelChange、𝔇\_k、\_k^Bind、𝔅\_k^ρ、RoleProj、各差异谓词、各覆盖证书，以及评价单元的划分与编号。

## 第八节　接口

### 8.1 上承

《概率动力一般式》v1.0：N\_PDyn 及其全部分项、见证纪律与对象入口。

《概率数理式》v1.0：率关系、表示、率域、极小充分组、率承担与维资格的形式对象。

《概率作用数理式》v1.0：作用正见证、端点读数与其回读条件。

《概率判定式》v1.0：端点资格判词及其条件。

场系统与运行基底：运行数据包的全部输入。

### 8.2 下交

第十三篇《概率动力必然式》：这里封版后，该篇取得正式进入条件。交付 N\_PDyn 的完整形式映射、合法段五项的可执行判据、三支的求解规则、资格接触的逐步门、三值读数 Read\_{DynActual}^{M,η} 与 Read\_{N\_PDyn}^M，以及回读路径与条件传播表。该篇的主充分向仍以对象层 N\_PDyn = 1 为前件，不得改为 Read\_{N\_PDyn}^M = 1 ⇒ ProbabilityDyn；这里的形式系统只作其算子映射的底座。

第十四篇《概率运行基底构造式》：最低实现契约——运行实例与分支记录、真实相邻子段、操作与来源日志、冻结协议版本、评价点索引、Probability 与 ProbabilityAct 接口、Rel\_ρ 表示接口、三类正式组织快照、同见证键与各层覆盖证书。该篇须真正构造能提供这些数据的可运行沉积场系统。

第十五篇《概率可达式》：可作为目标状态或目标动力结构读取的形式对象；这里不研究从初态能否到达。

第十六篇《概率稳定式》：跨时快照与结构比较接口；这里不研究保持、首次失效、恢复或韧性。

### 8.3 条件账本

新立：H\_new = ∅。

形式回读按实际路径承继既有的上游条件：H\_LawRead(W\_i)；H\_PAct-Rep（作用动力中来自职责兑现层的负端点，以及作用动力的反向表示）；H\_ρRep^-（率承担组织的反向表示）；Probability 负判路径实际需要的既有条件（必要时包括 H2 ∧ H3^red）。这些条件不合并为整篇的一个 Conditional 状态。

PD-M1—PD-M13 是形式可解性条件，不是 H，也不是概率动力的必要结构。

### 8.4 状态

形式系统：Established。

正向回读：Conditional，按实际正读路径承继 H\_LawRead，Start、Stop 中来自职责兑现层的负端点另承继 H\_PAct-Rep。

负向回读：Conditional，按支承继反向表示条件。

主体成立，开放的只是具体的反向表示与负回读路径。

### 8.5 击穿方式

K-PDynM1：在全部相关 PD-M 条件满足时，把真实的 N\_PDyn = 1 实例读成 0，而问题不能归因于已申报的上游反向表示缺口。

K-PDynM2：Read\_{N\_PDyn}^M = 1，而对应的结构层没有同一合法动力段与动力实际性。

K-PDynM3：两个静态的 1 → 1 端点在没有段内实际行使时取得 ActDyn = 1。

K-PDynM4：纯数值变化或表示模式变化取得 RateDyn = 1。

K-PDynM5：实现更替被读成 QualStructDyn = 1。

K-PDynM6：D、B、R 真值不变时，真实的内部正式结构变化被遗漏。

K-PDynM7：率承担组织只比较单一评价，遗漏率域级的分布或冗余结构变化。

K-PDynM8：以资格聚合的 a.e. 规则认定关系对象或正式承担组织的身份，从而漏掉资格真值不变时的真实内部变化，或把不可判的情形签为 0。

K-PDynM9：纯 0 → 0 失格区的变化取得概率动力的正读数。

K-PDynM10：不同运行、不同轨迹、不同协议或不同候选的证据被拼接。

K-PDynM11：材料不足时签出 0。

K-PDynM12：一个已确认的正动力被其他分支的 ⊥ 洗成 ⊥。

K-PDynM13：把 PD-M 条件写成本体必要条件或 H。

K-PDynM14：把 H\_PAct-Rep、H\_ρRep^- 暗中宣布关闭。

K-PDynM15：把 H2 ∧ H3^red 加进 QualStructDyn 的直接结构正读或主体形式定义。

K-PDynM16：承重形式符号未列入对应表，或没有现实输入、计算规则与回读语义。

### 8.6 回归测试

以下只作回归检验，不作一般证明。

测试 1　不同 RunID 或分支拼成轨迹：SameActualTrajectory = 0。

测试 2　直接写入 Rel\_ρ 后出现差异：AdmissibleUpdate = 0，Read\_{N\_PDyn} = 0。

测试 3　删除一个不可判的评价点后作首尾比较：WellFormedEvalSet = 0。

测试 4　合法起动：A 由 0 到 1，有起动来源绑定：ActDyn = 1。

测试 5　静态 1 → 1，段内没有实际行使见证：StepAct ≠ Continue。

测试 6　真实 1 → 1，冻结粒度下全部单元都有行使见证：Continue，ActDyn = 1。

测试 7　1 → 0 但后端负读出不完整：Stop 不成立，StepAct = ⊥。

测试 8　weight 比例缩放 (1, 2) → (3, 6)：RateDyn = 0。

测试 9　真关系变化 (1, 2) → (1, 3)，且 Contact = 1：RateDyn = 1。

测试 10　struct → weight，没有合法桥：该步 RelChange = ⊥。

测试 11　新正式维加入，D 的真值两端都为 1：DimStructDyn = 1。

测试 12　g\_C → g\_C′，B 两端都为 1：BindStructDyn = 1。

测试 13　承担由 {W\_1, W\_2} 转为 {W\_1, W\_3}，且 SameRel = 1：RateBearingStructDyn = 1，RateDyn = 0。

测试 13b　承担组织与 Rel\_ρ 同时改变（BearOrgDiff = 1，RelChange = 1）：这一步 RateDyn = 1，RateBearingStructDyn = 0，不双签。

测试 14　纯实现更替 W\_2(r\_a) → W\_2(r\_b)：QualStructDyn = 0。

测试 15　角色并集相同而超边组合改变，且 SameRel = 1、Contact = 1、SamePDynBind = 1：RateBearingStructDyn = 1。

测试 16　两端 DomainRelativeRateBearing 都为 1，SameRel = 1，而某一正式承担组合明确改变，完整组织身份接口可判：RateBearingStructDyn = 1，不因资格真值仍为 1 而漏掉。

测试 17　底层只能提供 a.e. 资格聚合、不能确定完整承担组织：BearOrgDiff = ⊥。

测试 18　纯 0 → 0 失格区的结构变化：Q\_k^Dim = Q\_k^Bind = Q\_k^BearStruct = 0。

测试 25　经验频率变化而生成关系不变：RateDyn = 0。

### 8.7 不做的事

不发明统一的抽象动力算子来代替真实事件、来源链与结构比较；不定义 ProbabilityDyn = f(Δp)；不以经验频率代理 Rel\_ρ；不以 d\_ρ \> ε\_ρ 定义 RateDyn；不把端点 1 → 1 自动定义为 Continue；不要求任意无限细时间上的连续作用；不以实现身份代理正式职责身份；不只比较 D、B、R 的真值；不把率承担组织压成活跃角色集；不只在单一评价上比较整个率承担组织；不建立新的全局 Law 跨时身份公理；不把 ⊥ 当作 0；不把 PD-M 条件升级为本体条件；不以一般式的最小性证明形式系统的正确；不证明充分方向。
