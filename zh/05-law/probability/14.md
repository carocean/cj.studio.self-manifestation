# 概率运行基底构造式

一、目的与唯一任务

在一个真实可运行的沉积场动力系统中，显式构造一份运行基底，使概率组式此前使用的概率资格、当前作用与跨时动力，都能由实际运行历史内生形成、维持、改变和读出，从而逐项表明这些对象不是悬空的符号。

总构造记为：

Spec\_ProbB = Augment(Spec\_LDB, A\_Prob)

Spec\_LDB 是封版律动力运行基底所规定的运行层：实际运行、痕迹、沉积与衰减、成律。A\_Prob 是这里新增的概率侧增量，分两个子层：

A\_Prob = A\_Prob^run ∪ A\_Prob^read

A\_Prob^run 是保守的运行增量：共同绑定的逐维沉积 BindSed，以及概率组织到续行核的接线（org / external）。它们按运行层的同一规则运作，只由实际经过留迹沉积，或作为合法操作作用于场。

A\_Prob^read 是只读增量：正式维、D、B、R、极小充分组、率承担组织、决策时见证、作用与动力读出、分层覆盖证书。

增量层不重写、不替换、不旁路运行层的因果链。

这里不重新定义概率，不重新证明《概率一般式》《概率必然式》，也不重新建立概率作用与概率动力各篇的对象；D、B、R、ProbabilityAct、ProbabilityDyn 的含义全部沿用已封版的上游。

这里区分两个层次，不让同一个符号同时表示二者：

正式继承目标：Spec\_ProbB = Augment(Spec\_LDB, A\_Prob)。它与封版源码 fldb\_v1\_12.py 的字节级继承，目前处于 PENDING RAW SOURCE（第十一节）；这是外部实现的集成事项。

参考构造：Spec\_ProbB^ref = Augment(F\_ref, A\_Prob^run, A\_Prob^read)，下文简记 Augment(F\_ref, A\_Prob)。F\_ref 是附录 A 的最小沉积场。3.0 节列出这里实际调用的运行层最低接口 I\_LDB^Prob，并证明 F\_ref ⊨ I\_LDB^Prob。定理一、定理二由 Spec\_ProbB^ref 承担，强度为构造。

所以源码暂缺不是这里理论对象或参考构造的缺口；取得源码后要做的，是在封版的 Spec\_LDB 上重做同一增量，并核对它同样满足 I\_LDB^Prob。

二、条件组申报

### 2.1 上游条件

C1　概率资格：N\_P = D ∧ B ∧ R，D := MultiLawDimension，B := CommonContinuationBind，R := DomainRelativeRateBearing（共同绑定记作 B，以免与续行位 C 混淆）；充分向 N\_P ⇒ Probability 不携 H。来源：《概率一般式》《概率必然式》。

C2　当前作用：ProbabilityAct 在 Probability = 1 的工作域内，与 N\_PAct 双向闭合：同一次现实当前发生中，概率组织的合法当前实现实际进入各维之间相对生成关系的形成；外部选择器不构成作用。来源：《概率作用一般式》《概率作用必然式》《概率作用数理式》。

C3　跨时动力：N\_PDyn = LegalProbabilityDynSegment ∧ ( ActDyn ∨ RateDyn ∨ QualStructDyn )，QualStructDyn = DimStructDyn ∨ BindStructDyn ∨ RateBearingStructDyn；资格接触纪律、ActDyn 的实际行使纪律、RateDyn 与 RateBearingStructDyn 不重叠。来源：《概率动力一般式》《概率动力必然式》。

C4　形式接口：同见证键、资格接触门、关系对象同一性（weight 模式为原始权重的正比例类）、率域级承担组织以超边族比较、实现更替不签组织变化、正证据优先与负读出须有覆盖。来源：《概率动力数理式》。

C5　下交事项：对任意 ε \> 0，是否存在真实可运行的实现，使 N\_P = 1 且 0 \< Coverage \< ε；若构造成功，覆盖轴由开放软区间升级为 ApproachableEndpoint。来源：《概率极限式》。

C6　运行层：Spec\_LDB 的因果链（实际运行 → 痕迹 → 沉积与衰减 → 成律）。来源：封版律动力运行基底；参考源码 fldb\_v1\_12.py，SHA-256 = 6964fce8c427a1eefa8d95ec8e99021e37a5a3b99ef5d4bfef3cb56ec794dbdb。

### 2.2 因果方向

构造固定以下因果方向：

实际运行 → 痕迹 → 沉积 / 衰减 → 成律（Law-bearing） → 概率组织 → Rel\_ρ → 续行 → 读出

禁止任何反向结构：Probability → 续行；RateDyn → 场更新；D、B、R → 沉积；读出器 → 痕迹或沉积。禁止直接写入 Probability、ProbabilityAct、Rel\_ρ、RateDyn、QualStructDyn、D、B、R。读出器只读系统已经发生的现实历史。

### 2.3 参考实现的选择

以下都是参考实现的选择，不是概率本体：沉积增量系数 α\_g、α\_d，衰减率，成律门槛（g ≥ 0.55 且重复次数 ≥ 3），生成核 κ = mask·(0.20 + 1.20g + 0.55d) 与生成权重 w = avail·exp(κ)，离散的时间步，协调器与图式的表示，测试脚手架与协议标识。换一组合法的参数或表示，构造仍须满足第五节的逐项验证。

三、构造程序

### 3.0 运行层最低接口 I\_LDB^Prob 与语义符合性

这里实际调用的运行层接口只有以下七项：

L1　实际运行记录：每一拍都有唯一的实际路线，并记录运行、分支、协议与时刻。

L2　痕迹即实际路线：留迹的恰是实际走过的路径，此外没有沉积来源。

L3　沉积与衰减：沉积量随实际经过单调累积，随时间衰减。

L4　成律只由历史取得：一条路径是否成律，只由它自身的沉积状态判定，不由任何读出或标签判定。

L5　生成核读沉积：续行时的生成权重由沉积状态计算，并实际进入分支选择。

L6　合法操作作用于场：存在一组合法操作（可用性、遮蔽、冻结、通道与核接线），它们只改变场，不写入任何派生谓词。

L7　保守扩展：附加的读出层不改变运行层的任何后续状态。

F\_ref ⊨ I\_LDB^Prob 的证明（逐项对应附录 A）：L1 由 execute() 的事件日志给出，每拍一条，含运行、分支、协议与时刻，C1 验证其完整；L2 由 execute() 只对 actual 中的路径调用沉积给出；L3 由 \_sediment\_edge() 与 decay\_step() 给出；L4 由 law\_bearing\_edge() 只读 (g, rep) 给出；L5 由 kappa\_edge()、carrier\_raw() 与续行核 select\_from\_relation() 给出，岔路第 2 组中关系随实际续行改变并决定下一次选择；L6 由 execute() 的合法操作集给出，其中没有一项写入 Probability、ProbabilityAct、Rel\_ρ、D、B、R 或动力读数；L7 由 T7 与岔路第 6 组给出：反复调用全部读出器（包括覆盖证书）的副本与不调用的副本，在相同事件后状态一致。

说明：绑定沉积 BindSed 与续行核接线（org / external）属于 A\_Prob^run 的运行子层，不属于只读子层 A\_Prob^read。前者是 L2、L3 的同一规则作用于"同一事件共同经过的载体—协调器对"；后者是 L6 的一项合法操作。两者都保守：它们不写入任何概率侧读数。在封版 Spec\_LDB 上重做时，这两项须由其自身的结构实现，并同样满足 I\_LDB^Prob；这属于待办的源码集成。

### 3.1 运行层（F\_ref 与 A\_Prob^run）

场由若干有向路径组成，每条路径带沉积状态 (g, d, rep, avail, mask)：

载体路径：每个候选维 v 有一组载体 v1、v2、…；它们承担续行维；

协调路径：G0、G1，承担共同生成图式；

域外路径：O1、…、ON，同一续行位上的其他后继，不属于候选概率组织；

绑定沉积 BindSed(g, v)：协调器 g 与维 v 之间的绑定迹。

每一拍：先对全部沉积作衰减（g、d 乘以 1 − 衰减率）；再按本拍的实际路线留迹：路线上的每条路径 g ← g + α\_g(1 − g)、d ← d + α\_d(1 − d)、rep ← rep + 1；若同一个事件同时走过某维 v 的载体与协调器 g，则 BindSed(g, v) 同样留迹沉积。痕迹恰为实际走过的路线，此外没有任何沉积来源。

一条路径成律，当且仅当 g ≥ 0.55 且 rep ≥ 3。

合法操作只有：设置某载体的 avail 或 mask；冻结或解冻沉积；接通或切断组织到生成核的通道（Coupling）；设置续行核接线（Selector：org 或 external）。这些操作都作用在场上，没有一项写入任何概率侧读数。

### 3.2 续行核

每一拍可以是：外部指定路线（exo-carrier、exo-outside，外部驱动场的一次运行）；内生续行（endo）；空拍（idle，只衰减）。

内生续行：取当拍的关系对象 Rel\_decision（由当前正式维的生成权重归一而得）；若接线为 org，选出 Rel\_decision 中权重最大的正式维；若接线为 external，由外部机制按其自身次序在同样的正式维之间指定分支。然后在所选维的可用正式载体中取生成核最大者，与当前正式共同图式一起构成实际路线。

执行可以完全确定。概率是否成立，不以本体随机为条件。

### 3.3 概率侧只读增量 A\_Prob^read

正式维：V\_P = { v：v 至少有一条已成律的载体 }。当前率为零不使维退出 V\_P。

正式共同图式：协调器 g 自身成律，并且对当前 V\_P 中每一维 v，BindSed(g, v) 都已成律。只有自身成律的协调器，不是共同图式。

关系对象：weight 模式下，Rel\_ρ 取为原始生成权重向量的正比例类 \[w\]\_ρ：w⁺ ∼\_ρ w⁻ 当且仅当存在 a \> 0 使 w⁺ = a·w⁻。显示的小数只用于展示，不承担对象身份。

极小充分组 MinSuff\_ρ：对组织的全部正式生成因子作子集枚举；在副本上只保留子集 S 的贡献、其余组织因子消融，所得关系与全组织关系同类，则 S 充分；S 充分且没有充分的真子集，则 S 属于 MinSuff\_ρ。

率承担证书：RateBearCert = RateDomainQual ∧ RelForm ∧ ActualOrgContribution ∧ SameWitnessBind。ActualOrgContribution：存在 G ∈ MinSuff\_ρ，其每个因子都是 V\_P 某一维的正式载体（SourceReal），且续行核读取的正是由这一组织形成的关系（EvalRateBind，即接线为 org）。不要求每一维都有正贡献。

读出：D = \[ \|V\_P\| ≥ 2 \]；B = D ∧ \[ 存在正式共同图式 \]；R = D ∧ B ∧ RateBearCert；Probability = D ∧ B ∧ R。

决策时见证：每次内生续行记录 Rel\_decision、所选维、所选载体、协调器与生成贡献，以及运行、分支、协议与时刻构成的见证键。这是日志，不进入因果层。

作用读出（四门）：一次事件签 ProbabilityAct = 1，当且仅当

G\_dim：所走载体在决策时是 V\_P 某一维的正式载体；

G\_bind：所走协调器是决策时的正式共同图式；

G\_gen：所选分支正是决策时关系对象 Rel\_decision 经组织选择器的输出，接线为 org；

G\_same：关系、所选维、载体、协调器与实际事件属于同一见证。

G\_gen 是这一参考实现用来充分排除外部选择器的实现门，不是 ProbabilityAct 的一般本体定义：上游所禁止的是外部机制替组织决定各维之间的相对生成，外部触发一次输入并不因此被禁止。

率承担组织：冻结的身份投影 π\_role：载体 → Law 角色，在实例进入运行前给定，运行中没有任何合法操作可以改写它。对每个 G ∈ MinSuff\_ρ 取 π\_role(G)，去重得超边族 ℋ\_ρ，角色集 RoleSet\_ρ 为其并集：

RateBearOrg = ( RoleSet\_ρ, ℋ\_ρ )

哪些载体已经成律，只作为载体组织（CarrierOrganization）的实现信息展示，不参与动力判定。

分层覆盖证书与三值读出：按《概率动力数理式》，每个负读数只有在它所依赖的覆盖为 1 时才能签 0，否则为 ⊥。参考实现给出分层证书 coverage\_certificate，逐项为：运行与分支记录（traj）、更新记录（upd）、协议（prot）、评价索引（idx）、两端作用记录（act\_t0、act\_t1）、子段内每一单元的作用记录（act\_units，即 Cov^Act(u)）、关系读数（rel）、维组织、共同图式与承担组织快照（dim、bind、bear）、同见证键（bindkey，即 SamePDynBind\_k）。记录中出现别的运行或分支，traj = 0（明确失败）；记录有缺口，traj = ⊥（材料不足），不是 0。

同见证键按《概率动力数理式》的步级键实现：K\_k = (锚, RunID, η, t\_k, t\_{k+1}, I\_k, Γ\_PDyn)，锚为 (候选 𝒫, C, 𝔯\_P)。每一个评价快照都携带冻结身份（锚、运行、分支、η、Γ\_PDyn、时刻）；Rel、正式维、共同图式与承担组织这些承重快照，都由带身份的端点取得。SamePDynBind\_k = 1 当且仅当两端快照的身份都属于 K\_k，且 I\_k 内每一个事件都携带同一运行、分支、协议，时刻落在 I\_k 内；任一明确的身份不一致为 0，任一身份材料缺失为 ⊥。所以数值完全相同的快照，只要取自另一运行或另一候选，也不能与本段的记录拼在一起。三值读出 act3、step\_act3、classify3：正读数取 1；负读数只有相应覆盖为 1 时取 0，否则取 ⊥；运行层记录的基本覆盖有一项为 0，该步的动力读数为 0（合法动力段不成立），有一项为 ⊥，则全部为 ⊥。

动力读出（相邻评价点 k → k+1）：

Contact = Probability\_k ∨ Probability\_{k+1}；

ActDyn：只在两端 Probability 都为 1 时读取，不以端点签名代替。作用评价粒度取一拍为一个单元，把相邻子段 I\_k 分为单元 u；单元读数 a\_u 为该拍事件的作用读出（外部驱动或空拍为 0，内生续行按四门，记录不全为 ⊥）；端点读数 A\_k 为评价点那一拍的单元读数。逐步状态按《概率动力数理式》：

Start：A\_k = 0，A\_{k+1} = 1，且 OnsetBind\_k = 1（由 0 进入 1 的那一单元是内生续行，并与携带同一见证键的合法更新相接）；

Continue：A\_k = A\_{k+1} = 1，且 I\_k 内一切单元 a\_u = 1；

Stop：A\_k = 1，A\_{k+1} = 0，且 CessationBind\_k = 1（由 1 进入 0 的那一单元是携带同一见证键的合法更新）；

Idle：A\_k = A\_{k+1} = 0，且 I\_k 内一切单元 a\_u = 0；

其余情形为 ⊥。端点 1 → 1 只是端点签名，不是 Continue 的充分条件；端点 0 → 0 而中间有作用，不签 Idle，按当前冻结粒度为 ⊥。

SameRel：两端原始权重同属一个正比例类；RateDyn = Contact ∧ ¬SameRel；

DimStructDyn = Contact ∧ \[ V\_P 改变 \]；BindStructDyn = Contact ∧ \[ 正式共同图式集改变 \]；

RateBearingStructDyn = Contact ∧ SameRel ∧ \[ RateBearOrg 改变 \]；

非双签：关系一旦改变，RateBearingStructDyn = 0，这一步只归 RateDyn。

覆盖：Coverage = Σ\_{v∈V\_P} w\_v / M\_C，M\_C 为同一续行位上概率维与已成律域外后继的生成质量之和；域外后继不自动进入 V\_P。

### 3.4 构造程序的执行顺序

一、建立场：候选维及其载体、协调器、绑定沉积、（需要时）域外路径；冻结 π\_role。

二、由实际运行形成资格：让各维的载体与协调器在同一事件中反复被走过，直到载体、协调器与每一对绑定都跨过成律门槛。

三、读出 D、B、R 与 Probability。

四、在同一场中继续实际运行：空拍、内生续行、外部驱动的新径与新协调器、新的载体。

五、每一评价点读出，并对相邻评价点读出动力。

每一步都是附录 A 中可以逐行执行的代码，没有一步是存在性的假定。

四、逐步执行：沉积岔路实例

这一实例是构造定理的实际运行见证，所用路径名只是实例中的名称，不是新增的本体对象。续行位为 Fork，候选维 Left、Right，以后出现第三条新径 NewRoute。以下数值全部取自附录 B 的实跑记录。

### 4.1 概率怎样真实形成

初态：V\_P = ∅，D = B = R = 0，Probability = 0。

实际历史：Left 经 G0 走 8 次，Right 经 G0 走 6 次。每一次都是实际走过 → 留迹 → 沉积。两条载体、协调器 G0，以及 G0 与 Left、Right 的绑定都跨过成律门槛后（t = 14）：

V\_P = {Left, Right}，D = B = R = 1，Probability = 1

关系读数为 Left 0.5407825821、Right 0.4592174179。这不是预设的概率表，而是沉积状态进入生成关系后的读数。形成过程全部由外部驱动的路线完成，所以这一段没有任何一步签 ProbabilityAct：外部指定路线不是概率组织的作用。

### 4.2 作用与率关系的推移

t = 15，空拍：Probability = 1，ProbabilityAct = 0；关系为 0.5407622813 / 0.4592377187（衰减使其略变）。

t = 16，内生续行：场按决策时的关系选出 Left，经 Left1 与 G0 实际续行。作用四门全部通过，ProbabilityAct 由 0 到 1，ActDyn = Start。由于 Left 真实发生并再次留迹沉积，关系变为 0.5553193534 / 0.4446806466，RateDyn = 1。

t = 17，再一次内生续行，仍走 Left：ActDyn = Continue；关系变为 0.5669598887 / 0.4330401113。

t = 18，空拍：ProbabilityAct 由 1 到 0，ActDyn = Stop；关系因衰减变为 0.5669268102 / 0.4330731898，RateDyn = 1。

这一段说明：概率不是先给出的数值，数值是实际沉积结构对以后生成关系的一种读出。因果方向是 Left 实际发生 → Left 留迹 → Left 沉积改变 → 生成关系改变 → 下一次续行改变；不是修改 p(Left)，再按概率抽签。实际执行只落一径，并不使其他正式概率维消失。

### 4.3 新径怎样进入概率

NewRoute 起初是可运行的路径，但没有正式 Law-bearing，不属于 V\_P。由外部驱动连续走 NewRoute1（经 G0）；到第 4 次重复（t = 21 → 22）时，NewRoute1 与 G0—NewRoute 的绑定都跨过成律门槛：

V\_P 由 {Left, Right} 变为 {Left, Right, NewRoute}，DimStructDyn = 1

新的关系读数为 Left 0.4234235569、NewRoute 0.2529506890、Right 0.3236257541，同一步 RateDyn = 1。G0 在 NewRoute 入维的同时已与它绑定，所以正式共同图式仍是 G0，B 保持为 1。这四步都是外部驱动的路线，作用读数全部为 0，理由是外部指定路线。

不是程序把 NewRoute 加入 V\_P，而是 NewRoute 经实际发生、留迹、沉积、复走，取得了正式 Law-bearing。

### 4.4 共同绑定的重组

在同一场中，让 Left1、Right1、NewRoute1 依次经第二套协调器 G1 实际运行，每个周期各走一次。G1 自身在第 2 个周期已经成律（早期把第 2 个周期误作共同绑定的时点，原因在此），但正式共同图式要求 G1 与三维各自的绑定都成律：每维每周期只经 G1 一次，第 3 次后绑定沉积约为 0.525，仍低于门槛 0.55；第 4 个周期（t = 31 → 34）才全部跨过：

正式共同图式由 {G0} 变为 {G0, G1}，BindStructDyn = 1

这一步的关系由 Left 0.3788293960、NewRoute 0.2911703876、Right 0.3300002164 变为 0.3696708777、0.2994064137、0.3309227086，RateDyn 同时为 1；上游并不禁止 RateDyn 与 BindStructDyn 同时成立。G1 不是靠切换图式标签成立的，而是由三维都实际经 G1 运行并留下绑定沉积取得的。

### 4.5 率承担组织的重组

另取同一岔路规格的实例，衰减率取 0（参考实现为构造精确的 SameRel 所作的选择，不是概率理论要求无衰减）。Left1、Right1、NewRoute1 各经 G0 走 6 次，此时：

RateBearOrg⁻ = ({Left1, NewRoute1, Right1}, {{Left1, NewRoute1, Right1}})

随后 Left2、Right2、NewRoute2 各经 G0 走 6 次，成为第二组正式 Law-bearing 载体；π\_role 把它们各自投影为独立取得资格的 Law 角色。任取每维一个载体都足以维持同一关系，所以极小充分组有 2³ = 8 个：

RateBearOrg⁺ = ({Left1, Left2, NewRoute1, NewRoute2, Right1, Right2}, 八条超边)

原始权重满足 w⁺ = 2·w⁻，关系前后都是 1/3、1/3、1/3，SameRel = 1。于是 RateBearingStructDyn = 1，RateDyn = 0（5a）。

对照 5d：走完全相同的物理历史，但 π\_role 冻结为 Left2 ↦ Left1、Right2 ↦ Right1、NewRoute2 ↦ NewRoute1，即第二组载体只是第一组角色的实现副本。这时载体组织改变，关系不变，而投影后的超边族前后都是 {{Left1, NewRoute1, Right1}}：RateBearingStructDyn = 0，RateDyn = 0。"多了一个实现副本"不是"率承担组织变化"。

对照 5b：只加 Left2，关系变为 0.5 / 0.25 / 0.25。承担组织也变了，但 SameRel = 0，所以只签 RateDyn = 1，RateBearingStructDyn = 0，不双签。

重读 5c：研发初期的一个构造（非对称历史、非零衰减下加入第二组载体）载体组织改变，但关系也由 0.3697456302 / 0.3161228943 / 0.3141314755 变为 0.3516650279 / 0.3247243002 / 0.3236106719，所以归 RateDyn，不归 RateBearingStructDyn。这里如实改判，不为旧解释保留旧签名。

### 4.6 两个控制

组织通道消融：在 4.1 的状态上只切断组织到生成核的通道：D = 1、B = 1，但 R = 0，Probability = 0，Rel 不再形成。维与共同绑定都还在，失去的是率承担。Probability 不是硬编码的标签。

六、构造定理

### 6.1 定理一　概率运行基底构造定理

存在一族有限、可执行的沉积场运行系统 Spec\_ProbB^ref = Augment(F\_ref, A\_Prob)（附录 A；F\_ref ⊨ I\_LDB^Prob，见 3.0），在不直接写入任何概率资格或动力读数的条件下，由实际运行历史内生形成 D、B、R，并存在实例满足 N\_P = 1；在同一运行基底上，可以实际构造并区分 ProbabilityAct、ActDyn（Start、Continue、Stop）、RateDyn、DimStructDyn、BindStructDyn 与 RateBearingStructDyn，全部读出器不进入场的因果更新，每个负读数都有分层覆盖证书支持，每个动力读数都以同一步级见证键为前提。

证明

构造由第三节给出，每一步都是附录 A 中可执行的代码。

资格：由 4.1，经实际运行，两维的载体、协调器 G0 及其与两维的绑定都成律，于是 D = 1（V\_P 有两维）；G0 是正式共同图式，B = 1；MinSuff\_ρ = {{Left1, Right1}}，其因子都是正式载体，续行核读取由它形成的关系，率承担证书成立，R = 1。所以 N\_P = 1。没有一步写入这些读数：它们都是由沉积状态计算出来的。

作用：由 4.2 与 V9—V12，内生续行在四门下签 ProbabilityAct = 1，外部指定路线、未成律的载体、非正式协调器与外部选择器都不签；决策时关系与实际选择同见证。

动力：ActDyn 的 Start、Continue、Stop 由 4.2 的内生续行取得，并在单元级规则下保持（V12、V12′）；DimStructDyn、BindStructDyn、RateDyn、RateBearingStructDyn 分别由 4.3、4.4、4.2、4.5 的真实运行取得；非双签与实现副本的区分由 5b、5c、5d 保证；各动力读数都以同一步级见证键为前提，跨段拼证不签（V20）。

非因果：由 4.6 与 V18，读出器反复调用不改变随后的实际运行。

覆盖：由 V19，负读数都由分层覆盖证书支持，材料不足时为 ⊥。

各项验证见第五节，全部回归通过（第九节）。□

### 6.2 定理二　覆盖可逼近零端点定理

对任意 ε \> 0，存在有限可运行的成员 F\_ε，使 N\_P(F\_ε) = 1 且 0 \< Coverage(F\_ε) \< ε。

构造与证明

取衰减率 0（参考实现的选择）。场含两条候选维 A、B（各一个载体 A1、B1）、协调器 G0，以及 N 条域外后继 O1、…、ON。运行六个周期；每个周期依次让 A1 经 G0、B1 经 G0、各 Oj 各走一次。

衰减为 0 时，每条路径的 (g, d, rep) 只取决于它被沉积的次数，与先后次序无关。A1、B1 与每一 Oj 都恰被沉积 6 次，所以它们的沉积状态完全相同，生成权重同为某个 w \> 0；六次沉积后 g = 1 − 0.78⁶ ≈ 0.775，已跨过成律门槛，所以每一 Oj 都成律并计入完整生成质量，但它们不是候选组织的载体，不进入 V\_P。于是

M\_P = 2w，M\_C = (N + 2)w，Coverage\_N = 2 / (N + 2)

同时 V\_P = {A, B}；G0 与 A、B 的绑定都成律，B = 1；MinSuff\_ρ = {{A1, B1}}，率承担证书成立，R = 1；与 N 无关。所以每个成员都有 N\_P = 1。

取

N\_ε = max{ 0, ⌊2/ε − 2⌋ + 1 }

则 N\_ε \> 2/ε − 2，即 2/(N\_ε + 2) \< ε；又 Coverage\_N \> 0。ε \> 1 时 N\_ε = 0，Coverage = 1 \< ε，仍然成立。□

实跑核对（附录 B 的 CF）：ε = 0.5、0.1、0.01、0.002 时，N 分别为 3、19、199、999，Coverage 与 2/(N+2) 的差分别不超过 6e-17、0、2e-18、0，各成员 Probability = 1。

非理想参数下的鲁棒性核对（T5）：衰减率 0.00001、N = ⌈3/ε⌉ 时，ε = 0.25、0.10、0.05、0.02、0.01 分别得 Coverage ≈ 0.142846、0.062488、0.032246、0.013145、0.006610，都满足 0 \< Coverage \< ε 且 D = B = R = 1。

推论　回交《概率极限式》：覆盖轴 Coverage → 0⁺ 是 ApproachableEndpoint。整个率域上的 Coverage = 0 仍不与 N\_P = 1 相容，这一构造不签出 Coverage = 0。

七、强度申报

定理一、定理二的强度是构造（Construction）：它们给出至少一族真实可执行的运行系统，使概率组式此前所用的运行对象都有对应的实例。

它们不是可达式：不证明任意目标状态都能从任意初态到达。它们不是实现式：不断言自然界中全部概率系统都按这一具体算法运行。

不得由这里越界声称：所有自然概率系统都由这一算法运行；这一玩具基底是概率唯一的本体实现；任意概率关系都必须数值化；每个正式维必须有正率；概率要求完整覆盖；随机性或稳定经验频率是概率的定义条件；π\_role 可以事后修改；适配器 v0.8 已完成与封版 FLDB 的继承；这里证明了概率的稳定、来源或可达。

参考实现的这些选择，都是实现选择，不是本体：生成核与权重的具体公式、成律门槛、衰减率（包括为构造精确 SameRel 与解析覆盖族所取的 0）、离散步长、图式与协议的表示、G\_gen 这一实现门、玩具极小充分组的枚举方式。

八、击穿方式

以下任一出现，即击穿相应的结论：

构造物不满足条件组：存在第五节某一验证项在附录 A 的代码下不成立；或某一读数（D、B、R、作用、动力）实际上是由直接写入取得的。

构造步骤不可执行：附录 A 的某一步无法按第三节执行。

因果倒置：读出器的调用改变了随后的实际运行；或概率侧的某一读数进入了场的更新。

悬空承重：某一概率侧读数可以在运行历史完全不同、而仅改动读出器或标签时改变。

跨段拼证：取自另一运行、另一候选或另一评价协议的快照，与本段记录拼在一起签出动力。

伪作用：外部指定路线、未成律的载体、非正式协调器或外部选择器下的续行签出 ProbabilityAct = 1；或仅凭端点签名签出 Start、Continue、Stop、Idle。

伪组织动力：纯实现副本签出 RateBearingStructDyn；或关系已变仍签出 RateBearingStructDyn（双签）；或资格真值不变时，真实的内部正式结构变化被漏掉。

伪共同绑定：只与部分维绑定的协调器被当作共同图式。

覆盖定理失效：存在 ε \> 0，使 N\_ε 对应的成员不满足 N\_P = 1 或 0 \< Coverage \< ε。

越权声称：把适配器 v0.8 写成已完成封版继承，或把 H\_PAct-Rep、H\_ρRep^- 写成已被一般关闭。

#   RateBearingOrganization is a formal object built from MinSuff_ρ through a
#   carrier -> LawRole projection:  RateBearOrg = (RoleSet, H), where H is the
#   normalised hyperedge family {role(G) : G ∈ MinSuff_ρ} and RoleSet its union.
#   The carrier organization (which carriers are Law-bearing) is kept only as

#      BindSed(coord,dim), laid down only when one actual event traverses a

#   2. The field has an explicit continuation-kernel wiring `selector`:

from dataclasses import dataclass
import copy, math, json

@dataclass
class SedEdge:
    g: float = 0.0
    d: float = 0.0
    rep: int = 0
    avail: float = 1.0
    mask: float = 1.0

def proportional(w0, w1, tol=1e-12):
    """True iff the raw weight vectors (dicts over the same keys) satisfy ∃a>0: w1=a·w0."""
    if w0 is None or w1 is None or set(w0)!=set(w1): return False
    s0=sum(w0.values()); s1=sum(w1.values())
    if s0<=0 or s1<=0: return False
    scale=max(max(abs(v) for v in w0.values()),max(abs(v) for v in w1.values()),1.0)
    return all(abs(w1[k]*s0-w0[k]*s1)<=tol*scale*max(s0,s1) for k in w0)

class ProbabilityRunningBase:
    def __init__(self, dims=("A","B"), spare_per_dim=1, outside_count=0,
                 alpha_g=.22, alpha_d=.16, decay=.002,
                 theta_g=.55, n_rep=3, beta=1.0, role_map=None):
        self.dims=tuple(dims)
        self.role_map=dict(role_map or {})   # carrier -> LawRole; missing = its own role
        self.alpha_g=alpha_g; self.alpha_d=alpha_d; self.decay=decay
        self.theta_g=theta_g; self.n_rep=n_rep; self.beta=beta
        self.carrier_to_dim={}; self.carriers={}
        for dim in dims:

                name=f"{dim}{j+1}"
                self.carrier_to_dim[name]=dim; self.carriers[name]=SedEdge()
        self.outside={f"O{j+1}":SedEdge() for j in range(outside_count)}
        self.coords={"G0":SedEdge(),"G1":SedEdge()}
        self.bind={(g,d):SedEdge() for g in self.coords for d in self.dims}   # BindSed(coord,dim)
        self.sed_enabled=True
        self.coupling_enabled=True        # organization -> generation channel
        self.selector="org"               # continuation-kernel wiring
        self.external_policy=None         # outside mechanism (dims order) when selector=="external"
        self.C="C0"; self.rate_domain="r0"; self.protocol="P0"
        self.candidate_id="P"; self.eta="eta-0"   # frozen identity of the declared candidate and evaluation segment (not causal)
        self.run_id="run-1"; self.branch_id="main"
        self.t=0; self.log=[]

    def clone(self): return copy.deepcopy(self)

    # ---------- Sedimentation-Field causal layer ----------
    def _decay_edges(self,table):
        for e in table.values(): e.g*=(1-self.decay); e.d*=(1-self.decay)
    def decay_step(self):
        self._decay_edges(self.carriers); self._decay_edges(self.outside); self._decay_edges(self.coords)
        self._decay_edges(self.bind)
    def _sediment_edge(self,e):
        if not self.sed_enabled: return
        e.g+=self.alpha_g*(1-e.g); e.d+=self.alpha_d*(1-e.d); e.rep+=1
    def law_bearing_edge(self,e): return e.g>=self.theta_g and e.rep>=self.n_rep
    def eligible_carriers(self): return tuple(k for k,e in self.carriers.items() if self.law_bearing_edge(e))
    def eligible_outside(self): return tuple(k for k,e in self.outside.items() if self.law_bearing_edge(e))
    def eligible_coords(self):
        """Formal common schemas: coordinator Law-bearing AND bound to every dimension of V_P."""
        V=self.V()
        return tuple(k for k,e in self.coords.items()
                     if self.law_bearing_edge(e) and len(V)>=1
                     and all(self.law_bearing_edge(self.bind[(k,d)]) for d in V))
    def coord_self_law_bearing(self):
        return tuple(k for k,e in self.coords.items() if self.law_bearing_edge(e))
    def active_schema(self):
        ec=self.eligible_coords()
        return None if not ec else max(ec,key=lambda k:(self.kappa_edge(self.coords[k]),k))
    def kappa_edge(self,e): return e.mask*(0.20+1.20*e.g+0.55*e.d)
    def carrier_raw(self,name):
        e=self.carriers[name]; return e.avail*math.exp(self.beta*self.kappa_edge(e))
    def outside_raw(self,name):
        e=self.outside[name]; return e.avail*math.exp(self.beta*self.kappa_edge(e))
    def dimension_bearers(self):
        ans={d:[] for d in self.dims}
        for c in self.eligible_carriers(): ans[self.carrier_to_dim[c]].append(c)
        return {d:tuple(v) for d,v in ans.items()}
    def V(self):

    def dimension_raw(self):

    def raw_weights(self):

        raw=self.dimension_raw()
        if not self.coupling_enabled or len(raw)<2: return None

    def rel_class(self,ndigits=10):

        s=sum(raw.values())
        if s<=0: return tuple((d,0.0) for d in sorted(raw))
        return tuple((d,round(raw[d]/s,ndigits)) for d in sorted(raw))
    def complete_mass(self):

        return p+o
    def coverage(self):

    def select_from_relation(self,rel):

        if not cand: return None

    def select_external(self):

        V=self.V(); pol=[d for d in self.external_policy if d in V]
        if not pol: return None

    def choose_carrier(self,dim):

        return None if not cs else max(cs,key=lambda c:(self.kappa_edge(self.carriers[c]),c))

    def execute(self,mode="endo",carrier=None,coord=None,outside=None,op=None):
        if op:
            kind,args=op[0],op[1:]
            if kind=="AvailCarrier": self.carriers[args[0]].avail=float(args[1])
            elif kind=="MaskCarrier": self.carriers[args[0]].mask=float(args[1])
            elif kind=="Freeze": self.sed_enabled=False
            elif kind=="Thaw": self.sed_enabled=True
            elif kind=="Coupling": self.coupling_enabled=bool(args[0])
            elif kind=="Selector":

            else: raise ValueError("illegal operation")
        pre={"V":self.V(),"bearers":self.dimension_bearers(),"schema":self.active_schema(),
             "coupling":self.coupling_enabled,"selector":self.selector}
        self.t+=1
        self.decay_step()
        actual=[]; decision=None
        if mode=="exo-carrier":
            if carrier not in self.carriers or coord not in self.coords: raise ValueError("bad exo carrier route")
            actual=[("carrier",carrier),("coord",coord)]
        elif mode=="exo-outside":
            if outside not in self.outside: raise ValueError("bad outside route")
            actual=[("outside",outside)]
        elif mode=="endo":
            rel_dec=self.rel_class()                    # the exact object handed to the selector
            schema=self.active_schema()
            if self.selector=="org": dim=self.select_from_relation(rel_dec)
            else: dim=self.select_external()

                          "schema_at_decision":schema}
        elif mode=="idle": pass
        else: raise ValueError("illegal mode")
        for typ,name in actual:
            table={"carrier":self.carriers,"coord":self.coords,"outside":self.outside}[typ]
            self._sediment_edge(table[name])
        # binding trace: one actual event through carrier(dim) + coord
        cs=[n for t_,n in actual if t_=="carrier"]; gs=[n for t_,n in actual if t_=="coord"]
        if cs and gs: self._sediment_edge(self.bind[(gs[0],self.carrier_to_dim[cs[0]])])
        ev={"t":self.t,"mode":mode,"actual":tuple(actual),"op":op,"run_id":self.run_id,
            "branch_id":self.branch_id,"protocol":self.protocol,"pre":pre,"decision":decision,
            "key":(self.run_id,self.branch_id,self.protocol,self.t)}
        self.log.append(ev); return ev

                "outside":tab(self.outside),"coupling":self.coupling_enabled,

    def org_factors(self):

        carriers of dimensions in V_P, with their actual contributions."""

    def _sufficient(self,S,full):

    def min_suff(self):
        """MinSuff_ρ by subset enumeration over the organization's formal factors."""
        from itertools import combinations
        full=self.raw_weights()
        if full is None or sum(full.values())<=0: return ()
        fac=sorted(self.org_factors())
        suff=[]
        for k in range(1,len(fac)+1):
            for S in combinations(fac,k):
                if any(set(T)<=set(S) for T in suff): continue      # a sufficient proper subset exists
                if self._sufficient(set(S),full): suff.append(S)
        return tuple(suff)

    def law_role(self,c): return self.role_map.get(c,c)

    def rate_bearing_org(self):

        H=frozenset(frozenset(self.law_role(c) for c in G) for G in self.min_suff())
        roles=frozenset(r for e in H for r in e)
        return (tuple(sorted(roles)), tuple(sorted(tuple(sorted(e)) for e in H)))

    def rate_bearing_certificate(self):
        V=self.V()
        rate_domain_qual = self.coupling_enabled and self.rate_domain is not None and len(V)>=2
        rel=self.raw_weights()
        rel_form = rel is not None and sum(rel.values())>0

        bear=self.dimension_bearers()
        # ∃G∈MinSuff whose every factor is a formal bearer of some v∈V_P (SourceReal)

        source_real = bool(G)
        eval_bind = self.selector=="org"     # kernel actually reads the relation formed by G
        same_witness = rel_form and bool(G)  # G, rel and kernel read on one state/key
        cert = rate_domain_qual and rel_form and source_real and eval_bind and same_witness
        return cert,{"RateDomainQual":rate_domain_qual,"RelForm":rel_form,"MinSuff":MS,"witness_group":G,
                     "SourceReal":source_real,"EvalRateBind":eval_bind,"SameWitness":same_witness}

    def probability_reader(self):

        B=D and self.active_schema() is not None
        cert,det=self.rate_bearing_certificate() if B else (False,None)
        R=D and B and cert
        bear=self.dimension_bearers()

                "bear_org":tuple((d,bear[d]) for d in sorted(bear) if d in V),   # carrier organization (display)
                "rate_bear_org":self.rate_bearing_org() if R else None,           # formal object
                "Rel":self.rel_class(),"W":self.raw_weights(),"Coverage":self.coverage(),
                "cert":det}

def probability_act(F, ev):
    """Four gates on one decision-time witness.  G_gen is this reference
    implementation's sufficient gate against an external selector; it is not
    the general definition of ProbabilityAct."""
    if ev["mode"]=="idle": return False,"no continuation (idle)"
    if ev["mode"]!="endo": return False,"G_gen: externally prescribed route"
    dec=ev["decision"]; pre=ev["pre"]
    if dec is None: return False,"no endogenous continuation produced"
    if len(pre["V"])<2 or pre["schema"] is None or not pre["coupling"]:
        return False,"pre-event Probability not established"
    if dec["selector"]!="org": return False,"G_gen: branch decided by an external selector"
    if dec["dim"] not in pre["V"] or dec["carrier"] not in dec["bearers_at_decision"].get(dec["dim"],()):
        return False,"G_dim: carrier not a formal bearer of V_P"
    if dec["coord"]!=pre["schema"] or dec["coord"]!=dec["schema_at_decision"]:
        return False,"G_bind: coordinator is not the standing schema"
    if dec["dim"]!=F.select_from_relation(dec["Rel_decision"]):
        return False,"G_gen: chosen branch is not the output of the decision-time relation"
    if ev["actual"]!=(("carrier",dec["carrier"]),("coord",dec["coord"])) or dec["contribution"]<=0:
        return False,"G_same: witness components differ"
    return True,"ok"

def same_rel(s0,s1): return proportional(s0["W"],s1["W"])

# ---------- Layered coverage certificates and three-valued readers (v1.0) ----------
# Values: 1, 0, BOT ("⊥").  A negative reading may be signed 0 only when the

BOT="⊥"

def snapshot_identity(F):
    """Frozen identity carried by every evaluation snapshot."""
    return {"anchor":(F.candidate_id,F.C,F.rate_domain),"run_id":F.run_id,"branch_id":F.branch_id,
            "eta":F.eta,"gamma":F.protocol,"t":F.t}

def step_key(F, t0, t1):
    """K_k = (anchor, RunID, eta, t_k, t_{k+1}, I_k, Gamma) built from the frozen identity of F."""
    return ((F.candidate_id,F.C,F.rate_domain),F.run_id,F.eta,t0,t1,(t0,t1),F.protocol)

def same_pdyn_bind(F, t0, t1, s0, s1, log=None):
    """SamePDynBind_k: both endpoint snapshots and every event of I_k carry the same K_k.
    Any explicit mismatch -> 0; any missing identity material -> ⊥."""
    log=F.log if log is None else log
    K=step_key(F,t0,t1)
    ids=[None if s is None else s.get("id") for s in (s0,s1)]
    if any(i is None for i in ids): return BOT
    for i,t in zip(ids,(t0,t1)):
        need=("anchor","run_id","branch_id","eta","gamma","t")
        if any(k not in i for k in need): return BOT
        if (tuple(i["anchor"]),i["run_id"],i["branch_id"],i["eta"],i["gamma"],i["t"])!=(K[0],F.run_id,F.branch_id,F.eta,F.protocol,t):
            return 0
    seg=[e for e in log if t0 < e.get("t",-1) <= t1]
    if len(seg)!=t1-t0 or any(not e.get("key") for e in seg): return BOT
    for e in seg:
        if tuple(e["key"][:3])!=(F.run_id,F.branch_id,F.protocol) or not (t0 < e["key"][3] <= t1): return 0
    return 1

def coverage_certificate(F, t0, t1, s0=None, s1=None, log=None):
    """Layered coverage for the adjacent evaluation step t0 -> t1 (t0 may be 0)."""
    log=F.log if log is None else log

            ok=_legal_bound_event(F,ev)
            return ok if ok!=1 else (1 if ev["mode"]=="endo" and ev.get("decision") else 0)

    return 0

    return 0

    return BOT
