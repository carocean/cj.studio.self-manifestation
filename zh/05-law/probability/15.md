# 概率可达式

一、目的、式种与唯一任务

给定一个已经构造完成的概率运行基底、一个明确的初态、冻结的概率候选身份、冻结的许可输入与运行模式与操作集，以及一个事前声明的概率侧目标，证明是否存在一条有限的合法路径，从这一初态命中这一目标。

式种：可达式，附式。按《法篇》可达式规范，构造已经给出（第十四篇），这里先冻结初态与许可集，再给出路径构造、步数的界、可达定理与强度。

核心输出是支持可达：

SuppReach\_Ξ^Prob(X\_0; G\_Θ) ∈ {1, 0, ⊥}

它断言的是"存在一条有限合法路径"。它不是可控可达（CtrlReach），不是"一切许可路径都必然到达"，也不是"以概率一到达"。

这里不重新研究概率是什么、怎样作用、怎样变化；概率资格、当前作用与跨时动力的含义全部沿用已封版的第一至第十四篇。这里只问：从一个具体的初态出发，能不能合法地走到那些已经定义好的概率侧目标。

二、上游输入与边界

### 2.1 上游输入

第一至第三篇：概率资格 N\_P = D ∧ B ∧ R（共同绑定记作 B，以免与续行位 C 混淆）。

第四至第六篇：当前作用 ProbabilityAct。

第十一至第十三篇：跨时动力 N\_PDyn、ActDyn 的单元级判据、RateDyn、QualStructDyn 三分、资格接触、同见证键 SamePDynBind、分层覆盖与三值纪律。

第十四篇：参考构造 Spec\_ProbB^ref = Augment(F\_ref, A\_Prob^run, A\_Prob^read)，以及其封版参考实现（probability\_running\_base\_v1\_0.py，SHA-256 = 187a9305db39fdb141502d64a79763427f1d7dda7bc8d8eb2c71bc69683f482a）。这里直接消费它，不修改它。

### 2.2 边界

Constructibility ≠ Reachability：第十四篇说明满足条件的运行系统能构造出来；这里说明从某个 X\_0 能不能合法走到目标。

Reachability ≠ Source：一条路径能到 Probability = 1，不等于现实中观察到的那次首次成概率就是由这条历史产生；实际的首次来源归《概率源式》。

Reachability ≠ Necessity：存在一条路径，不等于一切路径、几乎一切路径或必然到达。

Reachability ≠ Stability：存在一次 0 → 1、1 → 0 或恢复的路径，不等于保持、恢复时限或全部合法轨迹上的稳定；这些归第十六篇《概率稳定式》。

Reachability ≠ Implementation：这里的可达是运行模型中的可达，不是真实材料、资源与工程约束下已经落成。

Probability ≠ Pr(reach)：概率组式所说的"概率"是一份律组织；"到达某目标的概率是多少"是另一回事。这里的可达是存在一条路径，不是一个概率值。

三、任务规格、初态、目标与许可集

### 3.1 任务规格

Ξ\_PR = (Spec, Prot, X\_0, χ̄\_P, G\_Θ, Adm\_PR, Γ\_reach)

Spec：已构造的运行规格。当前正构造的承载者是 Spec\_ProbB^ref。

Prot：运行协议（运行、分支、协议标识在路径中保持不变）。

X\_0：本次任务的明确初态（3.2）。

χ̄\_P：概率候选的跨时身份锚（3.3）。

G\_Θ：事前声明的目标（第四节）。

Adm\_PR：冻结的许可集（3.4）。

Γ\_reach：冻结的评价协议，事前规定评价点的选取规则，由它确定锚定映射 a\_Γ（4.3）。

### 3.2 初态

每个任务的初态都由空基底经一段申报的构造前缀给出（附录 A 的 X\_empty、X\_P、X\_idle、X\_act、X\_new、X\_bind、X\_bear）。这里只把前缀的终态当作初态，不把前缀计入可达路径；前缀本身也全部由合法路线组成。

### 3.3 候选身份锚

χ̄\_P = (𝒫, C, 𝔯\_P, π\_role, CandidateID)

不把当前的 V\_P 冻结进身份：DimStructDyn 本来就允许 V\_P(t) 变化，若把它写进身份，新维进入概率组织这一目标就被预先堵死。同理，当前已成律的载体集合也不冻结。

C、𝔯\_P、π\_role、CandidateID 必须固定。π\_role 在路径中不得为了得到 RateBearingStructDyn 而修改。

### 3.4 许可集

Adm\_PR = (U^adm, M^adm, O^adm)

U^adm：许可的外部输入，即允许外部驱动的具体路线（某载体经某协调器，或某域外路径）；

M^adm：许可的运行模式（外部驱动、内生续行、空拍）；

O^adm：许可的场操作（可用性、遮蔽、冻结、解冻、通道、核接线）。

运行基底具有某项操作，不等于本次任务许可它；每个任务都冻结它真正许可的子集。

明确禁用：直接改写 g、d、rep、BindSed；直接写 D、B、R、Probability、Rel\_ρ、ProbabilityAct、RateDyn、QualStructDyn；运行途中修改 π\_role；改 CandidateID、C 或率域；改写日志以制造见证；改了目标以后沿用原先的可达结论。

读出器不是操作：调用读出器不产生后继（附录 B，reader\_is\_not\_an\_operation）。

四、可达前缀、目标节点与合法后继

### 4.1 目标族

Θ\_Prob = { Prob, Act, Start, Continue, Stop, Rate, Dim, Bind, Bear }

九类只是可达任务可以选择的目标类型，不是九项新的概率本体。

状态级目标：G\_Prob = { X：Probability(X) = 1 }。

事件级目标：G\_Act = { 评价点 X\_k：该点所结束的那一拍事件的作用读数为 1 }。

评价步级目标：其余七类落在相邻评价步上，不写成"X 满足 RateDyn = 1"。以

Z\_k = (S\_k, I\_k, S\_{k+1})，必要时连同该步的事件记录 Z\_k⁺ = (S\_k, I\_k, ℰ\_k, S\_{k+1})

作为目标的承载物：

G\_Start = { Z\_k：ActDyn\_k = Start }；G\_Continue、G\_Stop 同理；

G\_Rate = { Z\_k：RateDyn\_k = 1 }；G\_Dim、G\_Bind、G\_Bear 分别对应 DimStructDyn、BindStructDyn、RateBearingStructDyn 为 1。

Z\_k 只是可达证明的目标承载物，不是概率的新本体对象。

### 4.2 两种步

底层运行步：路径中每一次许可的外部驱动、内生续行、空拍或场操作，记路径的运行步数为 H\_run。

评价步：冻结评价协议 Γ\_reach 所给相邻评价点之间的一步，记路径所含评价步数为 H\_eval。Z\_k、合法后继与第六节的秩，都以评价步计。

每一拍都是评价点时，H\_run = H\_eval；评价点较稀时，一个评价步可以含多个运行步（第十节 G\_Bear：H\_run = 18，H\_eval = 1）。下文说到步数时，都注明是哪一种。

### 4.3 运行路径到评价前缀的映射

底层运行路径 γ = (X\_0, ζ\_0, X\_1, …, ζ\_{H\_run−1}, X\_{H\_run}) 与评价前缀 π 用两套索引，其对应由锚定映射给出：

a\_Γ：{0, …, H\_eval} → {0, …, H\_run}，a\_Γ(0) = 0，0 = a\_Γ(0) \< a\_Γ(1) \< … \< a\_Γ(H\_eval) ≤ H\_run

a\_Γ 完全由事前冻结的 Γ\_reach 决定。据此定义

π\_Γ(γ) = (X\_0; Z\_1, …, Z\_{H\_eval})，Z\_k = ( X\_{a\_Γ(k−1)}, I\_k, X\_{a\_Γ(k)} )，I\_k = { ζ\_r：a\_Γ(k−1) ≤ r \< a\_Γ(k) }

需要事件记录时，扩为 Z\_k⁺ = ( X\_{a\_Γ(k−1)}, I\_k, ℰ\_k, X\_{a\_Γ(k)} )，ℰ\_k 为 I\_k 中各运行步的事件记录。

路径的终点，只有当 Γ\_reach 本来把它列为评价点时才进入 π；不因路径在那里结束而临时把终点加入评价点。若 a\_Γ(H\_eval) \< H\_run，最后一个评价点之后的运行步不构成评价步。

这里用到的 Γ\_reach 都是等距规则：a\_Γ(k) = k·m，m 为冻结的评价间隔。逐拍评价取 m = 1；G\_Bear 取 m = 18，于是 a\_Γ(0) = 0、a\_Γ(1) = 18，得到跨 t = 18 → 36 的一个评价步。附录 A 的 certify 按这一规则取评价点，并在证书中输出 a\_Γ（字段 a\_gamma）；附录 B 的对照 path\_end\_not\_promoted 核验了终点不被提升：一条 10 步路径在 m = 4 下只得到评价点 0、4、8。

### 4.4 合法前缀与合法后继

有限合法前缀 π = (X\_0; Z\_1, …, Z\_j)。

Next^adm\_PR(π) 为：从当前合法前缀的末端出发，经冻结的 Adm\_PR 与运行基底的正常动力产生，并且扩展以后整条前缀仍然合法的下一评价节点的集合。合法性同时检查：同一运行、同一分支、同一候选锚、操作属于许可集、没有直接写入目标读数。评价步级目标还须该步 SamePDynBind = 1，且目标读数所需的各层覆盖为 1（第十二、第十四篇）；由覆盖不足造成的读数不作命中证据。

五、支持可达与路径证书

### 5.1 定义

SuppReach\_Ξ^Prob(X\_0; G\_Θ) = 1，当且仅当存在有限运行路径

γ = (X\_0, ζ\_0, X\_1, …, ζ\_{H−1}, X\_H)，H \< ∞

（H 为运行步数 H\_run），使 PathLegal(γ)、InputAdmissible(γ)、AnchorFixed(γ)、NoDirectTargetWrite(γ) 都为 1，并且 TargetHit\_{G\_Θ}(π\_Γ(γ)) = 1（π\_Γ(γ) 按 4.3 由 Γ\_reach 取得）；评价步级目标还须命中那一步 SamePDynBind = 1、基本覆盖为 1。

路径证书 CertReach^Prob(γ, G\_Θ)：逐步核验许可性与锚不变，分别记录许可失败的位置与锚变化的位置；同时记录初态、申报的运行步数与实际执行的运行步数、评价步数、锚定映射 a\_Γ，以及命中的状态或评价步（连同其评价索引与运行索引）及其三值读数。它是证明证书，不进入 Probability、ProbabilityAct 或 ProbabilityDyn 的本体定义。

### 5.2 三值

1：给出一条完整、合法、有限的命中路径即可。

0：须证明对一切 H \< ∞ 与一切许可路径 γ ∈ Paths\_H^adm，TargetHit\_{G\_Θ}(π\_Γ(γ)) = 0。

⊥：其余情形。有限次尝试没有命中、在某个步数预算内没有命中、运行基底的某项材料不可得，都只能记 ⊥，不能记 0。第十一节单列这一纪律。

六、有限秩支持可达定理

### 6.1 定理一

设 D^π\_Θ 为合法前缀的集合，ρ\_Θ：D^π\_Θ → ℕ。若

(i) ρ\_Θ(π) = 0 ⇒ TargetHit\_{G\_Θ}(π) = 1；

(ii) ρ\_Θ(π) \> 0 ⇒ 存在 Z′ ∈ Next^adm\_PR(π)，使 ρ\_Θ(π ⌢ Z′) \< ρ\_Θ(π)，

则 SuppReach\_Ξ^Prob(X\_0; G\_Θ) = 1，且存在命中路径，其评价步数 H\_eval ≤ ρ\_Θ(π\_0)。

证明

从 π\_0 出发，只要 ρ \> 0，由 (ii) 取一个合法后继使 ρ 严格下降。ρ 取值于自然数，严格下降至多 ρ\_Θ(π\_0) 次就到 0；由 (i) 此时命中目标。每一步都是合法后继，所以整条路径合法、有限，评价步数不超过 ρ\_Θ(π\_0)。□

这里 ρ\_Θ 定义在整个申报的合法前缀域 D^π\_Θ 上，条件 (ii) 对这一域中每一个 ρ \> 0 的前缀都须成立。

### 6.2 强度

定理一只给出存在一条路径，不推出一切路径都到达，也不推出以概率一到达。当运行规格是确定的（第十四篇的参考实现就是确定的），"存在一条路径"是在许可集中选出一列动作；若将来的运行规格本身带随机核，可以另报"以正概率到达"或"以概率一到达"，但那不是这里的可达定义。

### 6.3 与显式路径证明的关系

定理一给出一般的有限秩充分条件。第七至第十节的九项实例不依赖定理一取得可达性，而按《法篇》允许的"路径构造"路线，由完整、有限、合法的路径直接取得 SuppReach = 1；所列路径的步数直接给出步数上界。只沿一条已选路径定义的 ρ(π\_j) = H − j，不是定义在整个合法前缀域上的秩函数，不用来冒充定理一的实例化。若将来能在整个申报前缀域上构造满足 6.1 两条件的秩函数，可以由定理一取得同类或更强的统一界；这一版的九项实例不作这一额外主张。对其中三类目标，另给出与上界相等的下界，得到这一规格、这一许可集下的精确最短步数。

七、概率资格可达实例

任务 G\_Prob

X\_0：空基底（候选维 Left、Right、NewRoute，每维两个载体，协调器 G0、G1，衰减率 0.0005），V\_P = ∅，Probability = 0。

Adm：M = {外部驱动}，U = {Left1 经 G0，Right1 经 G0}，O = ∅。

Γ\_reach：每一拍为评价点。

路径：Left1、Right1 交替 4 轮，共 8 个运行步（H\_run = H\_eval = 8）。

证书：全部 8 步都在许可集内，锚不变；第 8 步时 Probability = 1，此前各评价点都为 0。所以 SuppReach = 1。第 8 步时 G0 与两维的绑定各经 4 次沉积而成律，B = 1；率承担证书成立，R = 1。

第十四篇用 14 步的形成历史（再加 Left1 两轮不对称的走法）建立其后续测试的基准；这里从同一空初态、同一许可集，取其首次命中的前缀作为正式证书。构造历史不等于最短的可达证书。

最短步数：上界 8 由上述路径给出。下界所依赖的，都是第十四篇参考构造的运行事实，限于这里冻结的 Adm 与 Spec\_ProbB^ref，不是新增的动力规则：

(a) 一次外部驱动的路线，只给路线上的那一条载体、那一个协调器，以及它们构成的那一对绑定各增加一次沉积；

(b) 一条路径从 g = 0 起，经 n 次沉积后 g ≤ 1 − 0.78ⁿ；n = 3 时约为 0.525，低于门槛 0.55，所以成律至少要 4 次沉积。

在这里冻结的 Adm 中，每一步只能执行 Left1 经 G0 或 Right1 经 G0 之一，所以每一步至多给两条目标载体之一增加一次沉积；Probability = 1 要求两维各有一条成律载体，两条载体各至少需要 4 次，所以任何许可的命中路径至少 8 个运行步。最短步数恰为 8。

八、作用与起、续、止的可达实例

任务 G\_Act 与 G\_Start

X\_0：概率已成、当前未作用的状态（空基底经 14 步形成历史，再一个空拍，t = 15），Probability = 1，ProbabilityAct = 0。

Adm：M = {内生续行}。

路径：一次内生续行。

证书：第 16 拍的作用读数为 1（四门通过），G\_Act 命中；评价步 (15, 16) 上 ActDyn = Start，OnsetBind = 1，SamePDynBind = 1，G\_Start 命中。H\_run = H\_eval = 1，这是最短的：初态本身不在目标中。

任务 G\_Continue

X\_0：t = 16，ProbabilityAct = 1。Adm：M = {内生续行}。路径：一次内生续行。证书：评价步 (16, 17) 上 ActDyn = Continue，单元读数全为 1，SamePDynBind = 1。H\_run = H\_eval = 1。

任务 G\_Stop

X\_0：t = 16，ProbabilityAct = 1。Adm：M = {空拍}。路径：一个空拍。证书：评价步 (16, 17) 上 ActDyn = Stop，CessationBind = 1，SamePDynBind = 1。H\_run = H\_eval = 1。

这些目标都是评价步级的：命中的是一对相邻评价点连同其间的单元与见证，不是某个孤立的终态。

九、率关系、新维与共同绑定的可达实例

任务 G\_Rate

X\_0：t = 15（同 G\_Start）。Adm：M = {内生续行}。路径：一次内生续行。证书：评价步 (15, 16) 上原始权重不再同属一个正比例类，RateDyn = 1，SamePDynBind = 1。H\_run = H\_eval = 1。

任务 G\_Dim

X\_0：NewRoute 尚未入维的状态（t = 18，V\_P = {Left, Right}）。Adm：M = {外部驱动}，U = {NewRoute1 经 G0}。路径：NewRoute1 经 G0 四次。证书：评价步 (21, 22) 上 V\_P 变为 {Left, Right, NewRoute}，DimStructDyn = 1，SamePDynBind = 1。

最短步数：上界 4（H\_run = H\_eval = 4）。下界：在这里冻结的 Adm 中，每一步只能执行 NewRoute1 经 G0，由第七节的运行事实 (a)，每一步只给 NewRoute1 增加一次沉积；由 (b)，它从 g = 0 起至少要 4 次沉积才能成律；所以任何许可的命中路径至少 4 个运行步。最短步数恰为 4。

任务 G\_Bind

X\_0：三维已入概率、正式共同图式只有 G0 的状态（t = 22）。Adm：M = {外部驱动}，U = {Left1 经 G1，Right1 经 G1，NewRoute1 经 G1}。路径：三条路线轮流 4 周期，共 12 步。证书：第 12 步所在的评价步 (33, 34) 上正式共同图式由 {G0} 变为 {G0, G1}，BindStructDyn = 1，SamePDynBind = 1；此前各步该读数都为 0。

最短步数：上界 12（H\_run = H\_eval = 12）。下界：在这里冻结的 Adm 中，每一步只能执行三条路线之一经 G1；由第七节的运行事实 (a)，一次路线只给它对应的那一对绑定 (G1, 该维) 增加一次沉积；G1 成为共同图式，要求它与三维各自的绑定都成律，由 (b) 每一对至少要 4 次沉积；所以任何许可的命中路径至少 12 个运行步。最短步数恰为 12。

十、率承担组织的可达实例及实现副本对照

任务 G\_Bear

X\_0：衰减率为 0 的岔路基底，Left1、Right1、NewRoute1 各经 G0 走 6 次（t = 18），每维一个正式载体。衰减率取 0 是第十四篇为构造精确的 SameRel 所作的参考实现选择。

Adm：M = {外部驱动}，U = {Left2 经 G0，Right2 经 G0，NewRoute2 经 G0}。

Γ\_reach：以 t = 18 为初始评价点，此后每经过 18 个运行步设置一个评价点。这是事前定义的评价规则，不是看到某条路径成功以后把它的终点指定为评价点。所给证书因此使用相邻评价点 t = 18 与 t = 36。

路径：Left2、Right2、NewRoute2 轮流 6 周期，共 18 个运行步。评价协议只产生一个跨 t = 18 → 36 的评价步：H\_run = 18，H\_eval = 1。18 是底层许可操作的步数，不是 18 个评价步。

证书：评价步 (18, 36) 上原始权重满足 w⁺ = 2·w⁻，SameRel = 1；正式率承担组织由单一超边变为八条超边；RateBearingStructDyn = 1，SamePDynBind = 1。运行步数上界为 18；这里不给出下界。

说明：若把评价点改为每一拍，读数是：前 9 拍第二组载体尚未成律，权重与承担组织都不变，两项都不签；自第 10 拍起，第二组载体先后成律并继续沉积，各步的权重比例都在变，只签 RateDyn；逐拍评价下没有一步签 RateBearingStructDyn。用附录 A 的 certify 把这一任务的 eval\_every 设为 1 重跑同一路径即可复现。那是另一个评价协议下的另一次读取，不影响上述证书，也说明 G\_Bear 的命中依赖所冻结的评价协议；这一依赖在事前申报，不是事后挑选。

实现副本对照

同一初态、同一 18 步路径，但 π\_role 冻结为 Left2 ↦ Left1、Right2 ↦ Right1、NewRoute2 ↦ NewRoute1。这时载体组织改变，而投影后的正式超边族不变，这条路径不命中 G\_Bear（附录 B，bear\_on\_implementation\_copies）。所以"多一套载体"本身不能作为命中证据；是否命中，取决于冻结的角色身份，而不取决于载体数量。这一对照只说明这条路径不构成证书，不构成"G\_Bear 不可达"的负判。

十一、负判、⊥ 与随机路径纪律

### 11.1 负判须覆盖一切许可路径

例：以空基底为初态，许可集只有空拍（M = {空拍}，U = O = ∅），目标 G\_Prob。空拍的实际路线为空，所以任何路径上都没有一次沉积：每条路径的 rep 恒为 0，没有路径成律，V\_P 恒为空，D = 0，Probability 恒为 0。这一论证对一切 H 与一切许可路径成立，所以 SuppReach = 0。这里的 0 由不变量证明取得；附录 B 中 50 个空拍的运行只是演示，不是证明。

### 11.2 有限尝试失败只能记 ⊥

例：以 G\_Bind 的初态为初态，只执行其路径的前 8 步，没有命中（附录 B，bounded\_failure\_is\_bot）。这不能签 0：更长的许可路径确实命中（第九节）。

### 11.3 不许可的操作使路径失格

例：在 G\_Prob 的许可集下，另取一条路径：Left1、Right1 交替 6 轮之后，第 13 步走 NewRoute1 经 G0（这条路径不是第七节的 8 步证书）。证书在该步报出"不在许可集内"，路径失格，不作命中证据；证书同时记录锚没有变化、实际执行了 12 个运行步（附录 B，unadmitted\_route\_rejected）。许可失败与锚变化分开记录。这对应《法篇》的击穿方式"所给路径包含不许可的操作"。

### 11.4 随机路径

参考实现是确定的。若将来的运行规格带随机核，"跑了若干次没有到"同样只能记 ⊥；"以正概率到达""以概率一到达"须另行报告，不替代这里的 SuppReach。

十三、击穿方式

### 13.1 《法篇》规定的两类击穿

A 类：证明在所申报的初态、许可集、目标与冻结评价协议 Γ\_reach 下，一切许可路径都不能命中目标。

B 类：指出所给的证书路径不合法，即包含不许可的操作。

### 13.2 B 类在这里的具体形态

路径中含有不在许可集内的路线、模式或操作；路径中途改变了候选锚、π\_role、运行、分支或协议；命中评价步的 SamePDynBind ≠ 1，或其读数依赖为 ⊥ 的覆盖；目标由直接写入读数、改写日志或事后改变评价协议取得。任一成立，该项证书失效，相应的 SuppReach = 1 退回 ⊥，直到另给合法证书。

### 13.3 附加主张的局部击穿

找到比 8、4、12 更短的许可命中路径：只击穿相应的最短步数命题，不击穿 SuppReach = 1。

把"多一套实现副本"读作 G\_Bear 的命中：击穿的是那一次 G\_Bear 判定及其角色投影的应用，不自动击穿其他八项可达。

把有限尝试的失败签成 0，或把"存在一条路径"写成"一切路径"或"以概率一"：击穿的是相应的强度陈述。
