# 概率稳定式

一、目的

证明：一份已经成立的概率（初态 Probability = 1），在事前冻结的稳定实例 Ξ\_PSt（许可变化域、资格协议、稳定协议、恢复期限与持续验证）之下，其资格的保持、失效与恢复满足以下结论，并在第十四篇的参考构造 Spec\_ProbB^ref 上取得构造见证：

一、稳定不是不变。存在合法轨迹，使 ProbabilityDyn = 1 且 Stable^set\_Prob = 1；RateDyn、DimStructDyn、BindStructDyn、RateBearingStructDyn 任一发生，都不推出资格失稳。

二、固定实现层与存在层分级。Q^fix\_P(k) = 1 ⇒ Q^set\_P(k) = 1，逆不成立；两层都可判且首次实际失效都存在时，k\_f^fix ≤ k\_f^set；两层的恢复不可互推。

三、恢复的成立条件。Recover^x = 1，当且仅当：已发生首次实际失效；在其后、且在恢复期限之内存在复归点；同一稳定实例未被改写；复归后通过最低确认窗，并保持到观察域末尾。

四、稳定的判定式。Stable^x = Keep^x ∨₃ Recover^x，x ∈ { fix, set }；动力型状态另有只带轨迹量词的稳定判定。材料不全时取 ⊥，不签 0。

五、量词层级。上述判定在单条轨迹、声明轨迹族与全部合法轨迹三种量词下分别给出，互不推出。

式种：稳定式，附式。它证明的是已立资格在变化中的保持与复归，不是首次存在、首次可达或首次发生；第十五篇的 SuppReach = 1 不推出稳定。

二、上游输入与边界

### 2.1 上游输入

概率资格 N\_P = D ∧ B ∧ R（共同绑定记作 B，以免与续行位 C 混淆）；当前作用 ProbabilityAct；跨时动力 N\_PDyn = LegalProbabilityDynSegment ∧ ( ActDyn ∨ RateDyn ∨ QualStructDyn )，QualStructDyn = DimStructDyn ∨ BindStructDyn ∨ RateBearingStructDyn。第十三篇已把 ProbabilityDyn 及其三类动力状态下交这里作为稳定分析的对象。

第十四篇的参考构造 Spec\_ProbB^ref 与封版参考实现（probability\_running\_base\_v1\_0.py，SHA-256 = 187a9305db39fdb141502d64a79763427f1d7dda7bc8d8eb2c71bc69683f482a），其中正式维、π\_role、共同图式、率承担组织 RateBearOrg、率承担证书都已给出；Probability 可以在 RateDyn、DimStructDyn、BindStructDyn、RateBearingStructDyn 发生时继续成立。

第十五篇的跨时身份锚 χ̄\_P = (𝒫, C, 𝔯\_P, π\_role, CandidateID)：不冻结当前 V\_P、当前载体集或当前 Rel\_ρ 数值；状态级 Probability 与评价步级动力目标分离，跨步动力落在 Z\_k = (S\_k, I\_k, S\_{k+1}) 或 Z\_k⁺ 上。

### 2.2 动力不是失稳

ProbabilityDyn = 1 ⇏ ProbabilityUnstable。分项地：

RateDyn = 1 ⇏ Stable^set\_Prob = 0；DimStructDyn = 1 ⇏ Stable^set\_Prob = 0；BindStructDyn = 1 ⇏ Stable^set\_Prob = 0；RateBearingStructDyn = 1 ⇏ Stable^set\_Prob = 0。

这四条由第十二节定理四的实例逐一见证（附录 B，S2—S5）。

三、稳定对象与原资格

### 3.1 两类稳定对象

Θ\_PSt = Θ^state\_PSt ∪ Θ^step\_PSt。

状态资格层：Θ^state\_PSt = { Probability }。

动力型层：Θ^step\_PSt = { Start, Continue, Stop, RateDyn, DimStructDyn, BindStructDyn, RateBearingStructDyn }。

Probability 是状态资格；其余都是事件级或评价步级对象，不写成静态的状态变量。主线是 Probability 资格的稳定；动力型稳定是从属的一节（第九节）。

### 3.2 资格实现

稳定审查对象 E\_k^P 是第 k 个稳定评价点上的一份完整 Probability 资格实现：

E\_k^P = (E\_D, E\_B, E\_R)\_k

E\_R：一条经冻结的 π\_role 投影后的极小充分组，即当前 RateBearOrg 的一条超边 h；

E\_B：一个正式共同图式 g；

E\_D：对 V\_P 中的每一维，h 所用到的该维正式 Law-bearing 角色构成的非空集合；h 没有用到的维（零率维），取它自己的一个正式 Law-bearing 角色。

E^P 只把已封版的 D、B、R 正资格结构展开为可以逐一指认的一份组合：它引用的正式概率维、Law-bearing 角色、正式共同绑定、RateBearOrg 与率承担证书都来自上游，不是新的概率本体。

资格证书 ProbCert(E^P; X\_k, Γ\_qual) = 1，当且仅当在状态 X\_k 上 Probability = 1，且 E\_D、E\_B、E\_R 都按上述方式在 X\_k 上成立。当前合法实现集：

𝓔^P\_k = { E^P：ProbCert(E^P; X\_k, Γ\_qual) = 1 }

完整性不足时，不把"没有找到"读成空集（第六节）。参考实现中场是封闭的，枚举完整。

初始实现 E\_0^P 在初态的实现集 𝓔^P\_0 中事前取定，属于稳定实例的一部分；参考实现取其中字典序最小的一份。

### 3.3 四层身份

事件见证（一次续行的记录）、物理实现（载体）、资格实现（E^P）、Probability 资格，四层分开：

ImplementationReplacement ⇏ RealizationReplacement；RealizationReplacement ⇏ ProbabilityLoss。

所以固定对象层的身份不是"完全相同的物理载体集"。第二组载体若经 π\_role 只是第一组角色的实现副本，换用它们不改变 E^P（S6）；若是独立取得资格的角色，换用它们是资格实现的替代，但 Probability 不因此失去（S7）。

四、稳定实例与许可变化域

### 4.1 稳定实例

Ξ\_PSt = (Spec, Prot, X\_0, χ̄\_P, E\_0^P, Δ\_PSt, Γ\_qual, Γ\_stab, 𝓗\_PSt)

Δ\_PSt：许可变化域；Γ\_qual：资格读出协议（第十四篇的读出与证书）；Γ\_stab：稳定观察与评价协议（评价点、可观察范围、区间证书）；𝓗\_PSt：恢复期限 T\_rec、资格层的最低确认长度 h^x、动力型的最低确认长度 h\_θ、观察域与轨迹量词等稳定参数。Γ\_qual 与 Γ\_stab 分开，不混用一个 Γ。

运行中修改 χ̄\_P、Δ\_PSt、Γ\_qual、Γ\_stab 或 𝓗\_PSt 中任何一项，都是换了稳定任务，不是原实例中的合法扰动（S17）。

### 4.2 许可变化域

可以事前申报：沉积与衰减；正式载体进入或退出；作用的起、续、止；RateDyn、DimStructDyn、BindStructDyn、RateBearingStructDyn；实现替代；资格实现替代；已有的合法场操作（可用性、遮蔽、冻结、解冻、通道、核接线）；域外后继的变化。

禁止：直接写 g、d、rep、BindSed；直接写 Probability、D、B、R、Rel\_ρ；直接写动力读数；修改 CandidateID、C 或率域；运行中修改 π\_role；改写日志制造证据；事后修改稳定协议。

### 4.3 变化后的资格重算

每一步变化以后，资格与实现集都按第十四篇的读出与 3.2 的定义在新状态上重算；重算规则本身不随轨迹改变。

五、即时保持层级

对象轴 x ∈ { fix, set }：

Q^fix\_P(k) = 1 当且仅当 E\_0^P ∈ 𝓔^P\_k；

Q^set\_P(k) = 1 当且仅当 𝓔^P\_k ≠ ∅。

量词纪律：∃E\_0 ∀k（同一实现在每个评价点都在）与 ∀k ∃E\_k（每个评价点都有某个实现）不同；前者才是 fix，后者只支持 set。在参考实现中，Q^set\_P(k) = 1 与该点 Probability = 1 一致。

六、动态轨迹、观察窗与可判域

### 6.1 可判域

DynDom^fix\_PSt(γ) 与 DynDom^set\_PSt(γ) 分开定义，二者不等价：判定原实现是否还在，比证明全部替代实现都不存在容易，所以可以有 DynDom^fix = 1 而 DynDom^set = ⊥。set = 0 必须建立在完整候选域已经可判、且全部候选都失败之上；没有搜全只能是 ⊥。

三值纪律：DynDom ≠ 1 ⇒ Keep = Recover = Stable = ⊥；只有 DynDom = 1 时，Keep、Recover、Stable 才取 0 或 1。

fix 与 set 两层可判域的区分属于一般的稳定制度。在当前封闭的参考场中，资格实现的枚举完整，两层所需的材料恰好同时完备，所以附录 A 的实例中两层可判域总是同时为 1 或同时为 ⊥，不构成二者分离的实例。

### 6.2 稳定覆盖

稳定是区间性质，不能只比较首尾：若 Probability(t\_0) = 1、Probability(t\_2) = 1，而中间 Probability(t\_1) = 0，就不能签 Keep = 1。所以稳定覆盖强于普通的评价覆盖：

StableCoverage(γ, Γ\_stab) = 1，当且仅当每个可能改变资格的运行步都被直接评价；或者每个稀疏评价间隔都有一份经核验的区间证书。否则 StableCoverage = ⊥，DynDom = ⊥。

区间证书是一个外部对象：CertInterval = { (t, Q^fix(t), Q^set(t), 任务锚) }，由独立的出证者给出。它只有在以下五项都成立时才被接受：一、覆盖区间内每一个运行步，没有缺口；二、每一项都携带同一稳定任务的锚；三、每一项的资格读数都可判（为 0 或 1）；四、覆盖整个稀疏间隔；五、每一项都与只读重算的结果一致。缺一项，StableCoverage = ⊥。证书是被核验的，不是被相信的：声明"有证书"本身不提升覆盖。

参考实现中：逐运行步评价得 StableCoverage = 1；稀疏评价且无区间证书得 ⊥（S11：首尾都是 1，中间第 16 拍失效，稀疏读出为 ⊥，逐拍读出为 Keep = 0）；稀疏评价并附经核验的区间证书，可判，Keep^set = 0，失效在第 16 拍（S11b）；把证书第 16 拍伪造成 1，或删去第 16 拍那一项，核验都不通过，得 ⊥（S11c）；含有协议观察不到的运行步，也得 ⊥（S16）。

这里不复用第十五篇 G\_Bear 的端点式评价来证明资格保持：那里 18 个运行步构成一个评价步，判断的是跨步动力目标，不是区间上的持续资格。

七、保持、失败集与首次实际失效

在 DynDom^x\_PSt(γ) = 1 时：Keep^x = 1 当且仅当对稳定覆盖域中的全部审查点 k（包括评价点，以及经区间证书覆盖的内部运行步），Q^x\_P(k) = 1；Keep^x = 0 当且仅当存在这样的 k 使 Q^x\_P(k) = 0。否则 Keep^x = ⊥。下文的失败集、首次失效与恢复，都在同一审查点集合上取。

失败集 Fail^x\_γ = { k：Q^x\_P(k) = 0 }；⊥ 不进入失败集。离散时间域上，首次实际失效 k\_f^x = min Fail^x\_γ。若时间域连续，b\_f^x = inf Fail^x 只给边界，须另证 b\_f^x ∈ Fail^x 才能称为实际失效点。参考实现的时间域是离散的。

八、恢复与稳定

### 8.1 恢复

Recover^x = 1，当且仅当同时满足：

一、已发生首次实际失效 k\_f^x；

二、后置复归：存在 k\_r \> k\_f^x，Q^x\_P(k\_r) = 1；k\_r 不必是失效后第一次重新为 1 的时刻，只要满足下面各条即可；

三、期限：Dur(k\_f^x, k\_r) ≤ T^x\_rec，计时从首次实际失效起算，后续再次失效不重置期限；参考实现中 Dur 以底层运行拍计，不以评价步数计，将来换用连续时间时再换度量；

四、同一 Ξ\_PSt 没有被改写；

五、复归后通过持续验证：自 k\_r 起至少 h^x 个评价步内 Q^x\_P 都为 1（最低确认窗），并且按协议保持到观察域的末尾，即对 k\_r 之后直到观察域末尾的一切审查点，Q^x\_P = 1。h^x 只是最低的确认长度；通过了 h^x 而在观察域内再次退出，不构成稳定恢复。

参考实现取满足全部条件（含保持到观察域末尾）的最早候选作为 k\_r（first\_valid\_recovery）。第一次复现没有通过持续验证，并不排除此后在原期限内的另一次合法复归；但期限始终从首次实际失效起算，后续再次失效不重置。资格层与动力型层共用这一判定。

超过期限才回来：Reappear^x = 1，Recover^x = 0。从未失效：Recover^x = 0；系统一直正常，不签 Recover = 1。

### 8.2 稳定

Stable^x\_PSt,γ = Keep^x\_PSt,γ ∨₃ Recover^x\_PSt,γ

Persistent^x ≡ Keep^x = 1；Resilient^x ≡ Fail^x ≠ ∅ ∧ Recover^x = 1。不另立"韧性本体"。

九、动力型稳定

对 θ ∈ { Start, Continue, Stop, RateDyn, DimStructDyn, BindStructDyn, RateBearingStructDyn }，在相邻评价步上读取 Q^θ\_γ(k) = Read\_θ(Z\_k) ∈ {1, 0, ⊥}，然后按第七、八节同样的方式定义 Keep^θ、Fail^θ、Recover^θ、Stable^θ。

这里不用 fix / set：一次 RateDyn 不是跨窗持续的实现。动力型稳定只有轨迹轴 Λ ∈ { single, family, guaranteed }。动力型恢复的最低确认长度单独申报为 h\_θ，与资格层的 h^x 分开；保持到观察域末尾的要求同样适用。

动力型稳定另有可判域 DynDom^θ\_PSt(γ)：参考实现中，观察域内的动力型读数全部为 0 或 1 时为 1，否则为 ⊥。若观察域内该动力型读数存在承重的 ⊥（例如某一评价步的端点协议观察不到），该轨迹在这一动力型稳定任务上不可判，Keep^θ、Recover^θ、Stable^θ 都取 ⊥；不得删除不可判的评价步后再判恢复，否则会跨过不可判的空洞，提前签出恢复。

例（S19）：自作用正在进行的状态（t = 16）起，内生续行、内生续行、空拍、内生续行、内生续行。θ = Continue 的读数依次为 1、1、0（Stop）、0（Start）、1。Keep^θ = 0；首次失效在 t = 19，t = 21 复归，期限 3 之内。申报 h\_θ = 0 时，Recover^θ = 1，Stable^θ = 1。对照：同一轨迹若申报 h\_θ = 2，复归之后没有足够的评价步供验证，Recover^θ = 0；把轨迹再延长两次内生续行，h\_θ = 2 的持续验证通过，Recover^θ = 1。

十、轨迹量词层级

Probability 主层形成 { fix, set } × { single, family, guaranteed } 六种组合。不裸写"概率稳定"，必须指明对象层与轨迹量词层。

single：一条轨迹 γ 上的 Stable^x\_γ。

family：FamilyStable^x(𝒢) = 1 当且仅当对一切 γ ∈ 𝒢，Stable^x\_γ = 1；存在 γ ∈ 𝒢 使 Stable^x\_γ = 0 时为 0；族为空、族成员资格不可确认，或混入不可判轨迹而没有完整判定时为 ⊥。

guaranteed：采用保证证书状态。合法轨迹全集 TrajLegal 与其中可判的子集 TrajDec^x 都须界定；只有 TrajLegal ≠ ∅ 且 TrajLegal = TrajDec^x 时，才进入 1 / 0 判定：全部 Stable^x = 1 为 1，否则为 0。合法但不可判的轨迹不得删去；有这种轨迹时为 ⊥。

参考实例（附录 B）：

S13：四条动力轨迹（作用与率关系、新维、共同绑定、率承担组织）组成的声明族，FamilyStable^set = 1。

S14：自 X\_P 起，许可字母表 {内生续行, 空拍}、长度 4 的全部 16 条轨迹都可判，都 Stable^set = 1，Guaranteed^set = 1。

S15：字母表加入"切断组织通道"、长度 3，全部 27 条可判，其中有切断后不复归的轨迹，Guaranteed^set = 0。

S16：字母表为 {内生续行, 空拍, 观察不到的空拍}、长度 3，27 条合法轨迹中只有 8 条可判，Guaranteed^set = ⊥。

这里的 guaranteed 只对所申报的有限轨迹空间成立，不推广到无限长的未来。

十一、稳定边界

稳定边界不与第九篇《概率极限式》的资格极限边界混同。这里研究的是同一稳定实例、同一扰动轴上的实际退出点 q^fix\_out、q^set\_out，以及反向恢复点 q^fix\_in、q^set\_in。只有实际取得边界以后，才能作事件级的陈述；q\_out 与 q\_in 属于同一冻结轴、同一协议、都实际取得而又不相等时，才讨论迟滞。不由两个下确界或上确界构造"迟滞宽度"。

这里不对任何扰动轴申报具体的稳定边界值；以上只是边界陈述的纪律。

十二、稳定定理

定理一　fix 推出 set

Q^fix\_P(k) = 1 ⇒ Q^set\_P(k) = 1；逆不成立。

证明：E\_0^P ∈ 𝓔^P\_k 推出 𝓔^P\_k ≠ ∅。逆的反例：S7，第 37 拍只把 Left1 的可用性设为 0，原实现的超边失效，Q^fix = 0，而由 Left2 承担的替代实现在，Q^set = 1。□

定理二　首次失效的次序

若两层都可判，且两层的首次实际失效都存在，则 k\_f^fix ≤ k\_f^set。

证明：由定理一的逆否，Q^set\_P(k) = 0 ⇒ Q^fix\_P(k) = 0，所以 Fail^set ⊆ Fail^fix，于是 min Fail^fix ≤ min Fail^set。□ 实跑逐点核对（S20）；例：S12 第二例中 k\_f^fix = 37、k\_f^set = 38。

定理三　两层的恢复不可互推

Recover^fix = 1 ⇏ Recover^set = 1：S12 第一例，第 37 拍阻断 Left1，原实现失效，第 38 拍恢复 Left1，原实现复归并保持；set 层从未失效，Recover^set = 0。

Recover^set = 1 ⇏ Recover^fix = 1：S12 第二例，第 37 拍阻断 Left1（fix 失效），第 38 拍切断组织通道（set 失效），第 39 拍接通（set 在期限内复归并保持）；Left1 始终阻断，原实现没有复归，Recover^fix = 0。□

定理四　概率动力与资格稳定可以共存

存在合法轨迹，使 ProbabilityDyn = 1 且 Stable^set\_Prob = 1。

证明：S2，自 X\_P 起空拍、内生续行、内生续行、空拍，出现 Start、Continue、Stop 与 RateDyn，Keep^set = 1。分项：S3 新维入维（DimStructDyn），Keep^set = 1；S4 G1 成为共同图式（BindStructDyn），Keep^set = 1；S5 第二组载体形成：在同一条实际轨迹上从 t = 18 走到 t = 36，以第十五篇同一 18 步路径的一个评价步读得 RateBearingStructDyn = 1；两端快照取自同一实例、同一运行，不跨实例拼接；同一历史逐拍读资格，Keep^set = 1。□

def issue_interval_certificate(X0, actions):

def first_valid_recovery(Q, kf, T_rec, h):
    """The earliest k_r > k_f that satisfies the WHOLE recovery condition:
    Q(k_r)=1, Dur(k_f,k_r) <= T_rec (clock fixed at the first actual failure k_f,
    never reset by later failures), a minimum confirmation window of h steps
    (Q = 1 on k_r..k_r+h), AND Q stays 1 from k_r to the end of the observation
    domain.  A first reappearance that fails these checks does not exclude a later one."""
    for kr in [t for t,v in Q if t>kf and v==1]:

        hold=[v for t,v in Q if kr<=t<=kr+h]
        if len(hold)!=h+1 or not all(v==1 for v in hold): continue
        if not all(v==1 for t,v in Q if t>=kr): continue
        return kr
    return None

    If any reading in the observation domain is ⊥, the trajectory is undecidable for

    filtered out before the recovery check."""
