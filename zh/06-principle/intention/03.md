# 意向必然式

一、目的

证明：在自显场的意向资格工作域内，意向域中的一个概率组织，只要同时具有以下四项结构，意向就成立，不需要再满足第五项独立的资格条件。

四项结构是：

第一，意向域中有正式的概率组织 𝒫\_I：它位于意向域中，在欲门之前；它的各维由律承担，共同承担续行位 C\_I，各维之间的相对生成由组织自身承担。

第二，𝒫\_I 处在源动驱动关系之中，并由它自身承担源动的续行。

第三，𝒫\_I 的各概率维与欲门一一对应，并通向对应的欲门。

第四，每一个欲门之后都有使役调谐的接口。

用式子表示为：

&nbsp;&nbsp;&nbsp;&nbsp;N\_I ⇒ Intent\_{F,t}

&nbsp;&nbsp;&nbsp;&nbsp;N\_I := P\_I ∧ SourceDrive\_{F,t}(𝒫\_I) ∧ GateCorrespondence\_{F,t}(𝒫\_I; 𝒢\_I) ∧ TuneInterface\_{F,t}(𝒢\_I)  
&nbsp;&nbsp;&nbsp;&nbsp;P\_I := InIntentDomain\_{F,t}(𝒫\_I) ∧ Probability\_{F,t}(𝒫\_I; C\_I, 𝔯\_I)

“不需要再满足第五项独立的资格条件”具体是指：当前有没有显化，有没有清晰的“我想……”体验，有没有外部行为，当前是否正在切换欲门，有没有默想回路或思考回路参与，某一维当前是否兑现、率是否为零，概率值能否读出，意向是否静置，当前是否正在调谐，某次作用是否改变了最终结果，系统是否具有高级的显性体验，都不影响结论。一个低等沉积场，没有清楚的起心动念体验，只要四项结构全部成立，同样取得意向资格。

二、上游输入与证明路线

1\. 上游输入

《意向一般式》：必要方向 Intent ⇒ N\_I，Status 为 Established；四项结构的正式含义；语料域；语义原子全集 u1 至 u52 的拆分。本篇使用该篇登记的语料与原子拆分，不使用该篇关于第五项资格与独立取消条件的结论。

《意向数理式》：N\_I 的形式系统与回读规则，IntentCoreCert^M = 1 ⇒ N\_I = 1；H\_LawRead 只沿 Probability 的回读路径，随实际使用的律见证传播。

《概率必然式》：N\_P ⇒ Probability，Status 为 Established；定理一（概率当前资格闭合定理）：在其固定语料域上，当前 Probability 资格的语义内容正好是维资格、共同续行与率承担三类，取消侧为空。

《律必然式》：∃R\[Established ∧ Govern\] ⇒ Law，Status 为 Established；定理二（律当前资格闭合定理）：当前 Law 资格的语义内容正好是沉积成形与稳定持势。

《式篇第四》：界门关系（Gate、Pass）与统摄关系（理场使役调谐、TunePriority）的分列。

2\. 证明路线

证明不采用“《意向一般式》已经证明没有第五项资格、没有独立取消条件，所以四项齐全就足以成立意向”的路线。那两项结论在该篇中服务于必要方向，本篇不把它们作为前提，只在第八节作一致性回测。本篇在同一语料域上独立地重新执行充分性程序。

证明路线为：

&nbsp;&nbsp;&nbsp;&nbsp;固定语料域 → 原子分类 → 不可约合取审查 → 当前资格闭合 → N\_I 完整实现资格 → Intent

与此对应的三条定理是：先在固定语料上取得意向当前资格的全部职责，并证明不存在独立的取消条件（定理一）；再证明 N\_I 的四项结构完整实现这些职责（定理二）；最后得出意向必然定理（定理三）。

3\. 记号纪律

下文使用的 U\_P、U\_S、U\_G、U\_T 是职责分类的名称。CurrentIntentQualification 是“固定语料中直接决定当前 Intent 真值的语义条件集合”的名称；IndependentDisqualifier\_I 是“独立取消条件集合”的名称。它们都是元语言名称，不是本体谓词，不是场量，也不具有独立真值；出现的地方都可以直接展开为第五节列出的语义原子。证明使用的是展开后的语料条件，不是名称本身。

四、原子化与分类规则

1\. 分类

每一个原子按它的主导职责归入下列一类。

CurrentIntentQualification：当前场中的组织，现在凭什么取得意向资格（取得侧）。按所回答的问题再分为四类：

U\_P　概率组织：意向域中有没有由律承担、共同续行、组织自身承担相对生成的方向组织；  
U\_S　源动驱动：这一组织是否处在源动驱动之中，源动的续行是否由它自身承担；  
U\_G　概率维与欲门的对应：这些方向是否通向欲门，方向与欲门是否一一对应；  
U\_T　调谐接口：欲门之后是否能使役调谐。

Disqualification：在 CurrentIntentQualification 的取得条件全部成立时，能够单独使当前意向资格失效的原子（取消侧）。

其余各类合称 U\_O：

Relation　意向与理、律、概率等的关系；  
Designation　称名；  
Location　意向及其组分所在的场，或类别的来源；  
WorkDomain　工作域约束；  
Act　意向的当前作用或一般作用；  
Dyn　意向怎样变化、怎样维持其状态；  
Source　意向怎样生成、怎样形成；  
Representation　表示、识出、读出；  
Boundary　本体边界，即排除某种东西属于意向；  
Consequence　意向作用的后果，包括显化；  
Implementation　实现方式。

2\. 分类判准

（a）问题判准。看该原子回答的是“有没有正式的方向组织”（U\_P）、“源动是否由这一组织承担”（U\_S）、“方向是否与欲门一一对应”（U\_G）、“欲门之后能否使役调谐”（U\_T），还是其他问题（U\_O）。

（b）时相判准。看该原子说的是“怎样形成”（Source）、“现在是否成立”（CurrentIntentQualification）、“怎样变化”（Dyn）、“正在做什么”（Act），还是“表现为什么”（Representation、Consequence）。

（c）删除判准。假设该原子取反，其余原子不变。如果组织仍然具有四类取得侧内容，并且固定语料中没有语句在该原子取反时否认意向成立，那么该原子不属于 CurrentIntentQualification。本判准只用于复核按（a）已归入 U\_O 的原子，不用来产生取得侧职责；取得侧职责只由（a）从语料中读出。

（d）取消侧审查。如果某个原子在形式上像否定（“出现某种情况就不是意向”），需要专门审查：假设取得条件全部成立，该原子能否单独使 Intent = 0。如果它要生效就必然使某一取得条件失效，那么它不是独立的取消条件，归入原来的类别。

3\. 不可约合取审查

单个原子全部分类以后，仍须检查固定语料所授权的不可约合取。两个单独都不构成资格的原子，合在一起有可能产生新的效力，所以不能由“各部分都不是资格”推出“合取也不是资格”。如果有人主张两个或多个原子的合取

&nbsp;&nbsp;&nbsp;&nbsp;X = u\_{j1} ∧ … ∧ u\_{jn}

承担新的当前意向资格职责或取消职责，就必须在固定语料中找到明确授权这一组合承担该职责的依据。这种联合授权可以出现在同一句内，也可以由跨句的因果、条件、指代、总结或回指关系形成。

合取分三类审查：

（一）含有 U\_P、U\_S、U\_G、U\_T 成员的合取：其中的资格成员由四项结构实现；其余成员只有在语料明确赋予该组合新增的当前资格语义或取消语义时，才能形成第五项职责。

（二）全部由 U\_O 原子构成的合取：没有语料授权，不能仅仅因为合取而上升为资格。

（三）主张合取产生了此前各原子中都不存在的新当前资格语义：如果固定语料中没有这一语义的授权，这一主张已超出冻结语料域，不进入证明。

一个合取 X 如果要成为第五项资格，还必须满足：在四项结构保持成立时，X 取反就使 Intent = 0，而这一取消并不表现为四项中任何一项的退出。否则 X 只是四项之一的展开。

五、原子逐项分类

1\. 取得侧

u1　方向维由律承担（I3；P5“每维都是律”；P1“生成各向的律续行熟路”）。U\_P。回答各方向由什么承担。结合 P5“由各维的律组成的律组织”，指维由正式律承担，不是维与律等同。

七、资格实现

1\. 定理二　意向资格实现定理

&nbsp;&nbsp;&nbsp;&nbsp;N\_I ⇒ U\_P ∧ U\_S ∧ U\_G ∧ U\_T

也就是说，N\_I 作为落在同一个 𝒫\_I、C\_I、𝒢\_I 上的四项结构，联合实现 U\_P、U\_S、U\_G、U\_T 的全部内容。四类职责各有一个主承担项：U\_P 是 P\_I，U\_S 是 SourceDrive，U\_G 是 GateCorrespondence，U\_T 是 TuneInterface。多数原子由主承担项直接给出；有四个原子的完整含义需要两项或三项共同落成：

&nbsp;&nbsp;&nbsp;&nbsp;u8：P\_I ∧ SourceDrive ∧ GateCorrespondence  
&nbsp;&nbsp;&nbsp;&nbsp;u12：P\_I ∧ SourceDrive  
&nbsp;&nbsp;&nbsp;&nbsp;u15：P\_I ∧ GateCorrespondence  
&nbsp;&nbsp;&nbsp;&nbsp;u21：GateCorrespondence ∧ TuneInterface

这不产生第五项，也不改变定理一的分类：分类依据的是原子的主导职责，实现可以是联合实现。四项是可以区分的资格职责，但语义原子并不要求与四项形成四个互相隔离的部分；某些原子的完整含义，要由同锚四项之间的接口共同落成。

证明

第一，N\_I 实现 U\_P，主承担项是 P\_I。

P\_I 给出 InIntentDomain(𝒫\_I) 与 Probability(𝒫\_I; C\_I, 𝔯\_I)。

Probability = 1 的语义内容，由《概率必然式》定理一给出：在其固定语料域上，当前 Probability 资格的语义内容正好是三类，Probability = 1 即这三类内容成立：至少有两个可以区分的方向，各方向是已经沉积的路径、由正式律承担（维资格）；各方向从同一起点出发，处在同一生成制度中，合成一个组织（共同续行）；各方向之间的率由组织自身产生，承担者是各维的律所组成的组织（率承担）。这里使用的是《概率必然式》定理一所闭合的语义内容，没有经由《概率一般式》的必要方向从 Probability 推出 N\_P 的形式谓词，因此不继承 H2 ∧ H3^red。

逐项对照 U\_P 的内容：多个可以区分的去处（u4）由维资格中的“至少两个可以区分的方向”给出；各方向由正式律承担、是以概率形式组织的律生态（u1、u2）由维资格与“各维的律所组成的组织”给出；各方向的差异由已沉积的熟路承担（u9）由维资格中“已经沉积的路径”给出，结合《律必然式》定理二，承担各维的不是即时的结果标签，而是取得了沉积成形与稳定持势的正式律；共同承担一个续行位（u6）由共同续行给出；择与偏、选择性、相对生成由组织自身承担（u3、u5、u7）由率承担给出；从源动到欲门之间有路径、有律，使脉冲走此路而非彼路（u8），是联合实现：路径由律承担，由维资格给出；路径的源动一端由 SourceDrive 给出，即源动的续行进入 𝒫\_I 并经它分向；路径的欲门一端由 GateCorrespondence 给出，即每一维通向其对应的欲门；位于意向域而不在欲门之后（u10）由 InIntentDomain(𝒫\_I) 给出。U\_P 没有剩余内容。

第二，N\_I 实现 U\_S，主承担项是 SourceDrive。

SourceDrive 给出：𝒫\_I 处在源动驱动关系中，并由它自身承担源动的续行；源动一侧位于组织之内，续行经 𝒫\_I 分向，分向域就是它的正式方向；组织之外没有另选方向的通路。

逐项对照：意向具有源动驱动，源动属于它本身（u11），由“源动一侧位于组织之内、由组织自身承担续行”给出，SourceDrive 本身就是组织的结构，不是外来接入；源动的续行由意向域中的这一组织承担，是源动不竭之核（u12），是联合实现：“续行由这一组织承担、经 𝒫\_I 分向”由 SourceDrive 给出，“位于意向域”由 P\_I 中的 InIntentDomain(𝒫\_I) 给出。U\_S 没有剩余内容。

第三，N\_I 实现 U\_G，主承担项是 GateCorrespondence。

GateCorrespondence 给出：各概率维与欲门之间是一一对应，每一对对应都是合法通达。

逐项对照：方向是欲的方向、去之所向（u13、u14），由“每一维通向其对应的欲门”给出；欲门对应概率的方向维（u16）、一一对应（u17），由对应的双射给出；各去处的开合之所在于意向域（u15），是联合实现：各去处的开合之所，即各维所对应的欲门，由 GateCorrespondence 给出；它们所属的方向组织位于意向域，由 P\_I 中的 InIntentDomain(𝒫\_I) 给出。U\_G 没有剩余内容。

第四，N\_I 实现 U\_T，主承担项是 TuneInterface。

TuneInterface 给出：每一个欲门之后都有合法的后继接口，其职责属于调谐使役，即《式篇第四》的统摄关系（理场使役调谐、TunePriority），而不是效应输出。

逐项对照：经调谐场连接经验（u18）、意图场能使役调谐（u19）、调谐线使意向能调谐各经验（u20），由“每一个欲门之后都有调谐使役接口”给出；经验的并用与切换由意图使役（u21），是联合实现：“欲门之后能使役调谐”由 TuneInterface 给出，“经验在不同欲门之后并用或切换”所需的多个欲门及其与各维的对应由 GateCorrespondence 给出；过欲门后使役调谐律破持经验场（u22），由调谐使役接口属于统摄关系给出。U\_T 没有剩余内容。

综合以上四点，N\_I ⇒ U\_P ∧ U\_S ∧ U\_G ∧ U\_T。四项各自单独不推出相应的整类职责；推出全部职责的是同锚的 N\_I。□

八、意向必然定理

1\. 定理三　意向必然定理

&nbsp;&nbsp;&nbsp;&nbsp;N\_I ⇒ Intent\_{F,t}

证明

假设 N\_I = 1。由定理二，U\_P、U\_S、U\_G、U\_T 的全部内容在 𝒫\_I、C\_I、𝔯\_I、𝒢\_I 上成立。由定理一，在固定语料域上，当前意向资格的取得条件正好是这四类，取消条件集合为空，并且不存在承担第五项资格职责或取消职责的不可约合取。因此，当前意向资格的全部语义条件都已取得，而且没有独立的取消条件生效。按第三节语料域申明，Intent\_{F,t} = 1。□

这里得到的不是“与意向相似的结构”。四项结构完整实现了由固定语料独立分析得到的全部当前资格职责；证明并不依赖于把 Intent 定义为 N\_I。

2\. 反充分世界

令

&nbsp;&nbsp;&nbsp;&nbsp;W\_I^- := { w ∣ N\_I(w) = 1 ∧ Intent(w) = 0 }

在固定语料域与意向资格工作域内，

&nbsp;&nbsp;&nbsp;&nbsp;W\_I^- = ∅

证明：设 w ∈ W\_I^-。Intent(w) = 0，按语料域申明，或者某一取得条件不成立，或者某一取消条件生效。前者与定理二矛盾：N\_I(w) = 1 已经实现全部取得条件。后者与定理一矛盾：取消条件集合为空，也不存在承担取消职责的不可约合取。所以 W\_I^- 为空。□

W\_I^- = ∅ 是在冻结语义域和工作域内的结论，不是对一切可能理论的绝对断言。它说明了必然的来由：不是因为 Intent 被定义成 N\_I，而是因为全部当前资格职责已经由 N\_I 完整实现，并且没有独立的取消项，所以在该工作域内不存在 N\_I 全齐而意向不成立的合法世界。

3\. 一致性回测

《意向一般式》必要方向的四项，与定理一得到的四类职责一一对应：P\_I 对应 U\_P，SourceDrive 对应 U\_S，GateCorrespondence 对应 U\_G，TuneInterface 对应 U\_T。该篇第八、九步所得的“没有第五项独立资格、没有独立取消条件”，与本篇定理一的取得侧穷尽、取消侧为空一致。必要方向与充分方向从两个方向得到了同一组职责。这一回测不参与定理三的证明。

4\. 双向闭合

《意向一般式》：Intent\_{F,t} ⇒ N\_I，Status = Established。

定理三：N\_I ⇒ Intent\_{F,t}，Status = Established。

两者合并，得到：

&nbsp;&nbsp;&nbsp;&nbsp;Intent\_{F,t} ⇔ N\_I

双向式 Status = Established。

意向资格于是有了完整的结构刻画：意向是意向域中具有源动驱动的概率化律生态，各维通向对应的欲门，欲门之后能使役调谐。按构成看，它是律生态；按各方向之间的关系看，它是概率；按与被破持之律的关系看，它是理；按它承担源动续行这一特殊的生态身份看，称为意向。这是同一组织的四种看法，不是四样东西相加。

九、边界例

1\. 零率维

假设 V\_I = {v\_1, v\_2, v\_3}，v\_3 当前的率为零；三维都取得正式律承担，共同续行，组织承担相对生成；源动驱动、概率维与欲门的对应、门后调谐接口都成立。那么 N\_I = 1，由定理三得 Intent = 1。v\_3 仍是正式方向，它对应的欲门仍在一一对应之中。

&nbsp;&nbsp;&nbsp;&nbsp;ρ(v\_i) = 0 ⇏ ¬Intent

需要区分两种情况：只有一维时，P\_I 中的多维不成立；有两维以上而某一维当前率为零时，意向照样成立。

2\. 静置

假设四项结构全部成立，而此刻没有源动脉冲，没有欲门切换，没有调谐，也没有显化。那么 N\_I = 1，Intent = 1。源动驱动判的是组织是否自身承担源动的续行，不是此刻有没有一次脉冲；调谐接口判的是门后有没有使役调谐的接口，不是此刻是否正在调谐。

3\. 低等沉积场

假设一个低等沉积场，四项结构全部成立，但没有显性回路，没有清楚的起心动念体验，显化清晰度极低。那么 N\_I = 1，Intent = 1。显化与体验属于后果，不属于资格；没有意向就不会有显性，但没有显性仍可以有意向。

4\. 新内容与新方向

假设系统第一次出现一个具体目标，例如第一次想去一座从未去过的城市，而这一目标由已经取得律承担的既有方向承载。那么 V\_I 不变，N\_I = 1 不受影响，Intent = 1。新的具体内容可以即时出现。

假设出现一条从未取得律承担的全新独立去向。它不是 V\_I 的成员，最多是新径候选、未成律的裸候选或一次实际探索；只有经过“新径 → 沉积 → 取得律承担 → 进入概率组织”，才成为新的概率维。它的出现不改变既有 V\_I 上的 N\_I，也不构成取消条件；它不能作为正式维进入一一对应。

5\. 确定性路由

假设环境与律生态在某一时刻都已固定，源动每次都沿同一维续行。判断的关键是：在容纳环境扰动变化的生成制度中，是否仍有两个以上由律承担的方向，并且相对生成由组织自身承担。如果是，并且其余三项结构成立，那么 N\_I = 1，Intent = 1；单次续行的确定性不取消资格。如果整个生成制度被冻结到只剩一维，P\_I 中的多维不成立，N\_I = 0，定理三不适用。这是第一项结构的失败，不需要另外增加“非确定性”资格。

&nbsp;&nbsp;&nbsp;&nbsp;Determinism ⇏ ¬Intent

十、形式层推论与条件账本

1\. 形式层推论

定理三以结构事实 N\_I 为出发点，不经过《意向数理式》的形式回读，所以主定理不继承 H\_LawRead。形式入口所继承的 H\_LawRead，只来自 N\_PQualRead\_I^M 经 N\_P 回读到 Probability 的路径，不扩张到 SourceDrive、GateCorrespondence、TuneInterface 的直接结构回读。

如果以形式读数为出发点：

&nbsp;&nbsp;&nbsp;&nbsp;IntentCoreCert^M = 1 ⇒ N\_I = 1　［《意向数理式》定理 5；H\_LawRead 只沿 Probability 的回读路径传播］  
&nbsp;&nbsp;&nbsp;&nbsp;N\_I ⇒ Intent\_{F,t}　［定理三，没有附加条件］

合并后得到形式推论：

&nbsp;&nbsp;&nbsp;&nbsp;IntentCoreCert^M = 1 ⇒ Intent\_{F,t} = 1　［Probability 回读路径中实际使用的 Law-bearing 见证所适用的 H\_LawRead 的合取］

IntentCoreCert^M = 1 不是主定理的前件。它是进入主定理的形式入口，不是充分性的证明来源。IntentCoreCert^M = ⊥ 既不回读为 N\_I = 0，也不回读为 Intent = 0。

2\. 条件账本

H\_new = ∅。

主定理 N\_I ⇒ Intent 不调用《意向一般式》的必要方向。

定理二第一部分调用的是《概率必然式》定理一与《律必然式》定理二的语义闭合，不调用《概率一般式》《律一般式》的必要方向，不继承 H2、H3^red、C0、C2、H1 至 H3。

《意向普遍不变量式》的 H\_PL、H\_SD、H\_GP、H\_TI 不进入本篇。那四座桥回答的是怎样从更弱的跨实现职责取得四项结构；本篇以四项结构为前件。

语料域的限定（Q1 至 Q13、P1 至 P5、I1 至 I9、T1 至 T4）与意向资格工作域的限定，是证明域的限定，不是 H。

主定理 Status = Established。

双向式 Status = Established。

形式层推论 Status = Conditional，条件为 Probability 回读路径中实际使用的 Law-bearing 见证所适用的 H\_LawRead。

十一、击穿

直接击穿主定理的情形是：

&nbsp;&nbsp;&nbsp;&nbsp;N\_I = 1 ∧ Intent = 0

按发生的层次分为四类。任何一类出现，都必须重新审查：

击穿一　语料域遗漏：固定语料之外存在承担当前意向资格的语句，或者语料修订后新增了这类语句，而这些语句的原子不能归入 U\_P、U\_S、U\_G、U\_T 或 U\_O。

击穿二　第五资格反例：存在一个有语料依据的单个原子或不可约合取 X，在取得条件全部成立时仍能单独取消资格，并且既不能归入四项结构，也不属于下游任务。

击穿三　结构实现失败：N\_I = 1，但 U\_P、U\_S、U\_G、U\_T 中至少有一类的某项内容实际上没有实现，说明第七节的对应有误。

击穿四　反充分世界：四类职责都已实际实现，仍然有一个独立因素使 Intent = 0，而且这一因素生效时并不表现为四项结构中任一项的退出。

以下情形不构成击穿：

IntentCoreCert^M = ⊥：这只是形式材料不足。

某一维当前率为零，或者某一维当前没有兑现：零率不导致该维退出。

概率值不可读：这是表示问题。

当前没有显化，没有“我想……”的体验，没有外部行为：这些属于后果。

当前没有源动脉冲、没有欲门切换、没有调谐：这些属于作用。

没有默想回路或思考回路参与：这属于起始方式。

意向后来失去稳定：属于稳定式的范围。

意向无法从某一初态到达：属于可达式的范围。

一条从未取得律承担的新去向出现：它不是正式维，不进入 N\_I。

十二、接口

《意向作用一般式》《意向作用数理式》《意向作用必然式》：以意向资格为前提，研究意向的当前作用；u30 至 u34 所述的作用归入这三篇。

《意向欲门切换一般式》《意向欲门切换数理式》《意向欲门切换必然式》：研究从一个欲门切到另一个欲门的事件结构；u48 至 u50 所述切换与显化的关系由这三篇承接。

《意向动力一般式》《意向动力数理式》《意向动力必然式》：u35 至 u37 所述的等待、状态与抑制归入这三篇。

《意向反演式》：由可观察材料反推意向资格时，必须经过 N\_I 与定理三；行为、体验或显化的缺失，不能用来推出意向资格不成立。

《意向判定式》：判定的对象是 N\_I 的四项结构；判得 N\_I = 1 的，经定理三就可以得到 Intent。如果 N\_I = 1 是由形式读数 IntentCoreCert^M = 1 判得，所得 Intent 携带 Probability 回读路径中实际使用的 Law-bearing 见证所适用的 H\_LawRead（十之 1）。

《意向极限式》：由定理三的逆否，意向资格退出时，四项结构中至少有一项退出；反过来，某一项退出必然导致资格退出，依据的是《意向一般式》的必要方向。零率、读数为 ⊥、静置都不构成资格边界。

《意向源式》：u38 至 u42 所述的生成与形成归入这一篇；新径怎样经沉积、取得律承担而进入概率组织，也由这一篇承接。

《意向运行基底构造式》：以 N\_I 的可运行见证作为构造目标。

《意向可达式》：以 N\_I 成立的组织作为目标状态，研究它的可达性。

《意向稳定式》：研究意向资格在时间上的保持。

《意向普遍不变量式》：该篇把“具有这些职责是否足以成为意向”交本篇；本篇以四项结构为前件给出回答，不调用该篇的四座对象层桥。
