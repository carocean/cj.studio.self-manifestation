# 意向作用数理式

一、目的

为意向作用的必要结构建立形式系统，使任一已经取得意向资格的申报实例，在当前作用申报单元 ξ\_t 内，四项作用职责及其共同见证都可以形式求值，并得到成立（1）、不成立（0）或材料不足（⊥）的确定读数。其中第二项职责在“当前发生已经成立而职责兑现失败”这一支上取得的 0，在结构层上的否定强度携带反向表示条件 H\_PAct-Rep；其余各层的 0 不携带。

所形式化的结构是：

&nbsp;&nbsp;&nbsp;&nbsp;IntentAct\_{F,t}(ξ\_t) ⇒ N\_IAct  
&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct := ∃w\_I \[ A1(w\_I) ∧ A2(w\_I) ∧ A3(w\_I) ∧ A4(w\_I) \]

A1 是源动职责当前发生，A2 是概率职责当前兑现，A3 是对应欲门当前通过，A4 是调谐使役当前兑现；四项按 R1 ≺ R2 ≺ R3 ≺ R4 逐层递进，并由同一个见证共同承担。

形式目标为：

&nbsp;&nbsp;&nbsp;&nbsp;S\_IAct ↦ M\_IAct

即：给出四项当前职责的形式判据，在同一见证上逐层求值，保持递进关系；给出候选见证的枚举、负读出所需的覆盖、求解程序与三值回读规则。

二、核心论题

给定已经成立的意向资格及其申报实例，以及当前作用申报单元 ξ\_t，怎样从现实事件记录、当前实现登记、实际来源链、正式方向与欲门的职责身份、门后调谐职责登记，以及上游的当前率承担证书中，求得“存在一个见证，在其上四项当前职责都成立”的形式真值，并严格区分结构失败 0 与形式材料不足 ⊥？

M\_IAct 须精确表达：

（1）当前与资格的区分。资格读数只说结构在不在，作用读数说这一次是否真的发生。SourceDrive^M = 1 不是源动当前在行，GateCorrespondence^M = 1 不是方向当前过了门，TuneInterface^M = 1 不是当前在使役调谐。作用的每一项都必须读现实当前的事件、实现和路径段。

（2）四项当前职责。源动职责在本次事件中由意向自身的源动职责实现承担，并实际进入 𝒫\_I；概率组织在同一事件中作为概率承担相对生成；由此取得当前职责的正式方向，沿正式对应实际进入其欲门；同一条链过门以后实际进入门后的调谐使役职责。

（3）递进与共同见证。后一项只在前一项已经取得的同一条链上求值；四项不得拆成四个独立的存在式，也不得从不同的事件、组织、方向、欲门或调谐链拼接。共同见证是对见证的良构要求，不是第五项职责。

（4）失败与不足的区分。没有找到见证，不等于见证不存在；负读出必须有覆盖。申报本身失格，只能要求重新申报，不能读成意向作用的结构失败。第二项的形式失败要回读为结构失败，还需要上游职责兑现的反向表示。

须在形式上区分下列几组对象：

&nbsp;&nbsp;&nbsp;&nbsp;资格读数 ≠ 当前作用读数  
&nbsp;&nbsp;&nbsp;&nbsp;当前过门 ≠ 欲门切换  
&nbsp;&nbsp;&nbsp;&nbsp;当前调谐使役 ≠ 调谐结果、经验改变、显化  
&nbsp;&nbsp;&nbsp;&nbsp;外部诱发 ≠ 外部完整承担  
&nbsp;&nbsp;&nbsp;&nbsp;第二项职责兑现 ≠ 概率作用本身  
&nbsp;&nbsp;&nbsp;&nbsp;结构见证 ≠ 形式见证

本系统表示的是意向作用的必要结构，不证明它的充分方向。可以区分和计数的，是事件、实现、路径段、方向、欲门、调谐职责与见证；多个完整见证可以同时存在。

2\. 定义序列

作用的求值对象，是已经取得意向资格的申报实例在一个当前作用单元内的现实运行。所以申报实例由资格实例加上作用申报单元构成；与作用有关的身份，例如哪一个事件、哪一组实现、哪一条路径段，都要在求解以前冻结，看到运行结果以后不得改写。

定义 1（作用求解实例）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;χ\_IAct := (χ\_I, ξ\_t, Γ\_IAct)

χ\_I 是已经建立的意向资格申报实例；ξ\_t 是《意向作用一般式》的当前完整作用申报单元，不是零宽瞬点；Γ\_IAct 是求解协议与身份冻结登记，至少冻结：当前事件身份协议，当前意向组织实现的身份，源动职责类、正式方向职责族、欲门职责类与门后调谐职责登记的版本，路径段的身份规则，候选枚举协议，覆盖协议，申报边界规则。Γ\_IAct 是求解协议，不是作用职责，不是本体谓词。

进入条件：Intent\_{F,t} = 1。本系统不重新求意向资格；若意向资格由上游形式读数取得，其回读条件保持上游原来的归属。

一般式中的见证，说的是同一次作用的六个方面：同一个 𝒫\_I，同一次现实续行，同一个概率职责的兑现，同一条实际方向，该方向对应的同一个欲门，从这个欲门接出的同一条调谐使役链。形式层把它展开为一个元组，把每一个方面落到可以读取的事件、实现与路径段上。

定义 2（结构见证）\[表\]　《意向作用一般式》的见证 w\_I 在结构层记为 w\_I^S。

定义 3（形式见证）\[表\]

&nbsp;&nbsp;&nbsp;&nbsp;w\_I^M := (e\_t, Π\_t^I, Z\_src, Z\_ρ, v\_i, \[G\_i\], Z\_G, q\_i, Z\_T)

e\_t 是当前现实续行事件；Π\_t^I 是本次作用中意向组织的当前实现包，其概率组织部分记为 Π\_t^𝒫，与《概率作用数理式》的当前组织实现包同一；Z\_src 是源动职责到 𝒫\_I 的实际当前续行子段；Z\_ρ 是 𝒫\_I 当前承担相对生成的实际生成子段；v\_i 是本次现实生成链中取得当前职责的正式方向维；\[G\_i\] 是 v\_i 正式对应的欲门职责类，按欲门职责商类 𝒢̄\_I 计，不以单个物理节点计；Z\_G 是 v\_i 到 \[G\_i\] 的实际当前通过子段；q\_i 是 \[G\_i\] 之后合法的调谐使役职责实现；Z\_T 是 \[G\_i\] 到 q\_i 的实际当前进入子段。

形式见证与结构见证的对应记为集合值映射 𝔉\_IAct：w\_I^M ∈ 𝔉\_IAct(w\_I^S) 表示 w\_I^M 是 w\_I^S 的一个合法形式登记。同一结构见证可以有多个合法形式登记，例如实现的登记粒度不同；不得由形式登记的个数推断作用的次数。下文的 w 在形式层均指形式见证。

A1 读的是源动职责此刻是否真的在行。资格层的 SourceDrive^M 只说 𝒫\_I 处在源动驱动之中，不说此刻有续行，所以不能用它代替 A1。A1 要读四件事：这是不是现实当前的事件；本次承担源动的，是不是意向自身的源动职责实现；这段续行是否真的进入了 𝒫\_I；以上是否与资格锚是同一套对象。

定义 4（现实当前事件）\[S\]　CurrentEvent\_I^M(e\_t; t, ξ\_t)：取 1，e\_t 是 ξ\_t 所申报的现实当前运行事件，不是资格复走、历史重演或离线再入的记录；取 0，事件记录完整，且 e\_t 明确不属于现实当前运行；其余取 ⊥。

定义 5（当前源动职责实现）\[S\]　CurrentSrcRoleReal^M(e\_t, \[S\_I\]\_src, Π\_t^I)：取 1，有合法的当前实现登记表明，本次 e\_t 中承担源动职责的实现属于正式源动职责类 \[S\_I\]\_src，并属于 Π\_t^I 所代表的同一意向组织；取 0，当前实现登记与职责身份的覆盖完整，且本次承担者确定不属于 \[S\_I\]\_src，或者是组织之外的完整承担机制；其余取 ⊥。

定义 6（源动实际进入）\[S\]　ActualSrcEnter^M(Z\_src; e\_t, \[S\_I\]\_src, 𝒫\_I)：取 1，Z\_src 是 e\_t 的现实当前路径段，由 \[S\_I\]\_src 的当前实现实际承担，并进入同一 𝒫\_I 的当前相对生成组织；取 0，路径记录覆盖完整，且这段续行明确没有进入 𝒫\_I，或者由外部的完整选择器绕过 𝒫\_I 直接决定了后继；其余取 ⊥。

定义 7（源动—资格锚绑定）\[辅\]　SrcAnchorBind^M(\[S\_I\]\_src, 𝒫\_I, Π\_t^I, K\_I^M)：取 1，四者引用同一个冻结的意向资格锚与当前实现身份；取 0，身份资料完整，且确定跨锚；其余取 ⊥。

定义 8（A1 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;A1^M(w) := CurrentEvent\_I^M ∧₃ CurrentSrcRoleReal^M ∧₃ ActualSrcEnter^M ∧₃ SrcAnchorBind^M

外界可以触发、扰动或改变场态，从而引起意向自身的源动续行；本系统不要求最外部的原因属于系统内部，只要求本次源动到方向的续行由意向自身的职责承担。所以外部触发经 \[S\_I\]\_src 进入 𝒫\_I，A1^M 可以取 1；外部选择器绕过 \[S\_I\]\_src 与 𝒫\_I 直接决定欲门，A1^M 不得取 1。外部原因不等于外部完整承担。

一个候选见证上 SrcAnchorBind^M = 0，说明这一候选的源动承担不属于本申报锚上的意向组织；它使这一候选失败，不使申报失格。申报实例本身跨锚、跨版本，属于定义 29 的 DeclarationZero。

A2 读的是概率组织在这一次续行中是否作为概率承担了相对生成。这一职责的形式判据，《概率作用数理式》已经建立；本系统不另建第二套，只把它嵌入同一个见证。A2 不是概率作用本身：本系统不以概率作用的总读数代替 A2，A2 只是对同一见证上的当前职责兑现的读取。

定义 9（A2 读数）\[S\]　记 w\_ρ := (e\_t, Π\_t^𝒫, Z\_ρ)。

&nbsp;&nbsp;&nbsp;&nbsp;A2^M(w) := ProbabilityDutyConformance^M(w\_ρ)，当 CurrentProbabilityOccurrence^M(w\_ρ) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;A2^M(w) := 0，当 CurrentProbabilityOccurrence^M(w\_ρ) = 0  
&nbsp;&nbsp;&nbsp;&nbsp;A2^M(w) := ⊥，当 CurrentProbabilityOccurrence^M(w\_ρ) = ⊥

《概率作用数理式》规定，职责兑现只在当前发生已经成立的见证上求值，所以 A2^M 先读 w\_ρ 上的当前发生。Π\_t^𝒫 必须是 Π\_t^I 中的同一个概率组织实现，不得另取；Z\_ρ 必须属于同一个 e\_t；职责兑现只调用现实当前运行评价 ν\_t^cur 上的当前率承担证书 κ\_ρ，不调用率域聚合的率承担读数。ProbabilityDutyConformance^M = 0 须以 RateCertCover^M(w\_ρ) = 1 为前提，否则记 ⊥。

A2^M 因此有两种不同的 0。一种是当前发生取 0：在本次事件中，概率组织的当前实现没有实际承担这一生成子段；这对应上游的第一层负读出。另一种是当前发生取 1 而职责兑现取 0：概率组织的实现确实承担了这段生成，却没有取得作为概率承担相对生成的证书；这对应上游的第二层负读出。两种 0 的结构回读强度不同（七之 3）。

A3 读的是本次取得当前职责的方向，是否真的进入了它的欲门。资格层上概率维与欲门的对应只给出合法通达，不给出当前的实际通过。A3 要读四件事：本次哪一个正式方向取得了当前后继职责；它正式对应哪一个欲门职责类；有没有一段现实路径从这一方向进入这个欲门；这一方向是否就是 A2 那一次职责兑现中形成的方向。

定义 10（当前正式方向实现）\[S\]　DirCurrentRealize^M(v\_i; e\_t, Z\_ρ, Π\_t^I)：取 1，v\_i 是 V\_I 中的正式方向，并且在 Z\_ρ 所属的本次现实生成链中取得了当前后继职责；取 0，方向候选的覆盖完整，且 v\_i 没有在本次链中取得现实职责，或者只是结果标签、外部标签、历史登记；其余取 ⊥。

定义 11（正式维—欲门对应）\[承\]　CorrGateRead^M(v\_i, \[G\_i\]) := CorrRead\_I^M(v\_i, \[G\_i\])，即《意向数理式》已经冻结的正式对应读数，按欲门职责类求值，不以物理节点身份替代。

定义 12（实际过门路径段）\[S\]　ActualGatePassSeg^M(Z\_G; e\_t, v\_i, \[G\_i\])：取 1，Z\_G 是 e\_t 的实际当前后继段，从现实承担的正式方向 v\_i 进入其欲门职责类 \[G\_i\]；取 0，路径覆盖完整，且方向进入的是普通内部状态、一般输出、非对应的欲门，或者没有进入任何欲门；其余取 ⊥。

定义 13（方向—欲门同链绑定）\[辅\]　DirGateChainBind^M(Z\_ρ, v\_i, Z\_G, \[G\_i\], e\_t)：取 1，Z\_G 是 Z\_ρ 在同一 e\_t 上的合法现实后继，v\_i 是 A2 那一次职责兑现中实际形成并承担的正式方向，\[G\_i\] 是它的正式对应欲门；取 0，身份链完整，且确定发生了跨事件、跨方向、跨门或外部插接；其余取 ⊥。

定义 14（A3 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;A3^M(w) := DirCurrentRealize^M ∧₃ CorrGateRead^M ∧₃ ActualGatePassSeg^M ∧₃ DirGateChainBind^M

A3^M = 1 只说本次作用经过了对应的欲门，不说门位发生了变化：A3^M = 1 不推出欲门切换。

A4 读的是过门以后是否真的进入了调谐使役。资格层的 TuneInterface^M 只说门后有合法的调谐接口，不说此刻在使役。A4 要读四件事：门后的这个职责是不是合法的调谐使役；它此刻有没有合法的当前实现；有没有一段现实路径从这个欲门进入它；这段路径是否接在 A3 的同一个欲门之后。

定义 15（欲门后合法调谐职责）\[承\]　PostGateTuneRoleRead^M(\[G\_i\], q\_i)，即《意向数理式》的定义。

定义 16（当前调谐职责实现）\[S\]　CurrentTuneRoleReal^M(q\_i; e\_t, Π\_t^I)：取 1，本次现实事件中 q\_i 有合法的当前实现，且这一实现属于冻结的门后调谐职责登记；取 0，当前实现的覆盖完整，且 q\_i 没有现实承担这一职责；其余取 ⊥。

定义 17（实际调谐进入路径段）\[S\]　ActualTuneEntrySeg^M(Z\_T; e\_t, \[G\_i\], q\_i)：取 1，Z\_T 是本次现实链从 \[G\_i\] 进入 q\_i 的实际当前路径段；取 0，门后路径覆盖完整，且没有进入调谐使役职责，或者直接绕到了效应或其他非调谐的职责；其余取 ⊥。

定义 18（欲门—调谐同链绑定）\[辅\]　GateTuneChainBind^M(Z\_G, \[G\_i\], Z\_T, q\_i, e\_t)：取 1，Z\_T 是 A3 的同一个 \[G\_i\] 的现实后继，不来自另一事件、另一欲门或另一次独立调用；取 0，身份链完整，且确定跨事件、跨门或拼接；其余取 ⊥。

定义 19（A4 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;A4^M(w) := PostGateTuneRoleRead^M ∧₃ CurrentTuneRoleReal^M ∧₃ ActualTuneEntrySeg^M ∧₃ GateTuneChainBind^M

A4^M = 1 只说本次作用确实进入了门后的调谐使役，不说调谐已经完成、经验已经改变、已经显化、欲门已经切换、理之作用已经完成，也不说作用的结果成功。

四项各自的读数还不够：四个 1 如果分别取自不同的事件、方向、欲门或调谐链，拼在一起并不描述同一次作用。共同见证把一般式的同一性要求落到形式见证的各个分量上。它检查的是一个候选见证是否良构，不是第五项职责。

定义 20（作用锚键）\[辅\]　K\_IAct^M := (K\_I^M, e\_t, Π\_t^I, v\_i, \[G\_i\], q\_i)。

定义 21（作用链段键）\[辅\]　Λ\_IAct^M := (Z\_src, Z\_ρ, Z\_G, Z\_T)。

定义 22（共同见证绑定）\[表\]　SameIActBind^M(w)：取 1，当且仅当下列各项同时成立：A1 至 A4 全部引用同一个 K\_I^M；全部引用同一个现实当前事件 e\_t；Π\_t^I 的概率组织实现与 A2 所调用的 Π\_t^𝒫 同一；Z\_src 的后继进入同一个 𝒫\_I；Z\_ρ 属于同一条当前生成链；A2 的实际方向就是 A3 的 v\_i；A3 的 \[G\_i\] 就是 A4 的欲门；q\_i 是这个 \[G\_i\] 的合法后继调谐职责；链段的顺序与连接合法，Z\_src ⇝ Z\_ρ ⇝ Z\_G ⇝ Z\_T；没有跨事件、跨组织、跨方向、跨欲门或跨调谐链的拼接。取 0，身份资料完整，且上述某一项确定不成立；其余取 ⊥。

SameIActBind^M = 0 的含义是：这一组形式片段不是一个合法的共同见证。它不是第五项职责取 0。

关系性质：事件身份同一、实现包同一、方向同一、欲门职责类同一、调谐职责同一，都是身份等同，按等价关系处理（自反、对称、传递）。链段之间的后继关系 ⇝ 是异型的有向关系，不申报自反、对称或传递，不是偏序。𝔉\_IAct 是集合值对应，不申报单值、单射、满射或唯一性，不申报自反、对称、传递。DirGateChainBind^M、GateTuneChainBind^M、SrcAnchorBind^M 是异型三值谓词，不申报自反、对称或传递。候选集、覆盖证书是集合或谓词，不是二元关系。

（定义 23 至 30 是由上述对象组成的关系式与读数，列于四。）

四、方程

本系统没有动力方程；它的关系都是静力关系，即读数之间的组成关系。

1\. 递进求值

一般式规定：后一层只在前面各层已经成立的同一条作用链上求值。所以形式层不能把四项无条件地同时求值，而要按递进顺序逐层求：A2 只在 A1 已经取得当前事件与源动进入之后，才有合法的求值对象；A3 只在 A2 的现实方向已经取得之后求值；A4 只在 A3 的现实欲门已经取得之后求值。上一层为 ⊥ 时，下一层没有合法的求值对象，不能越过这个 ⊥ 去下层寻找 0。

定义 23（逐见证递进读数）\[辅\]

&nbsp;&nbsp;&nbsp;&nbsp;Q1(w) := A1^M(w)  
&nbsp;&nbsp;&nbsp;&nbsp;Q2(w) := 0，当 Q1(w) = 0；⊥，当 Q1(w) = ⊥；A2^M(w)，当 Q1(w) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;Q3(w) := 0，当 Q2(w) = 0；⊥，当 Q2(w) = ⊥；A3^M(w)，当 Q2(w) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;Q4(w) := 0，当 Q3(w) = 0；⊥，当 Q3(w) = ⊥；A4^M(w)，当 Q3(w) = 1

累计阶段的形式表示为 R\_k^M(w) := Q\_k(w)，k = 1, 2, 3, 4。

定义 24（逐见证完整作用读数）\[辅\]

&nbsp;&nbsp;&nbsp;&nbsp;Q\_IAct(w) := SameIActBind^M(w) ∧₃ Q4(w)

SameIActBind^M 是见证的守卫，不是第五层职责。

2\. 候选与覆盖

正读数只需要一个合法的共同见证。负读数不同：没有找到见证，不等于见证不存在；要签 0，必须证明所需的候选都已经枚举完。覆盖按递进的层次分开冻结，只在准备签出相应层的失败时使用。

定义 25（候选见证域）\[辅\]　Ŵ\_IAct：按 Γ\_IAct，从现实事件、当前实现、来源链、方向、欲门与调谐职责登记中枚举的形式见证候选集。带帽的集合只是枚举域，不天然等于全部合法见证。

覆盖证书分层如下：

EventCover^M：当前申报单元内与申报锚相关的现实当前事件都已覆盖。  
SrcRoleCover^M(e)：事件 e 中有资格承担正式源动职责的当前实现都已覆盖。  
SrcSegCover^M(e, s)：源动职责到 𝒫\_I 的相关当前路径段都已覆盖。  
PRealCover^M(e\_t)：事件 e\_t 中 𝒫\_I 的全部合法当前组织实现包都已覆盖，即上游定义 3.14 的 PRealCover^M。  
PGenSegCover^M(e\_t, Π\_t^𝒫)：Π\_t^𝒫 在 e\_t 中实际承担的全部生成子段都已覆盖，即上游定义 3.14 的 SegCover^M。  
以上两项服务于 A2 当前发生子层的负读出。  
PActCertCover^M(w)：A2 所需的当前率承担证书候选都已覆盖，即上游 RateCertCover^M(w\_ρ) = 1；它只服务于 A2 职责兑现子层的负读出。它只说明形式证书候选都已枚举，不说明一切结构层的职责兑现方式都能被这一证书体系表示；后者正是 H\_PAct-Rep 的内容。  
DirRealCover^M(w)：本次现实生成链上的正式方向候选都已覆盖。  
GateSegCover^M(w, v\_i)：方向到欲门的现实当前后继段都已覆盖。  
TuneRoleCover^M(w, \[G\_i\])：这个欲门之后的合法调谐职责候选都已覆盖。  
TuneSegCover^M(w, \[G\_i\], q\_i)：欲门到调谐职责的现实当前路径段都已覆盖。

定义 26（负读出覆盖）\[辅\]　NegComplete\_IAct^M = 1，当且仅当：对各候选的失败层以及这些层之前所有必须求值的候选层，所需的覆盖证书都已闭合，并且候选枚举没有遗漏可能形成正见证的形式对象。NegComplete\_IAct^M 不是本体条件，不进入 N\_IAct；正读数一旦出现即可签 1，不需要它。

3\. 总读数

定义 27（总读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{N\_IAct}^M := ∃₃ w ∈ Ŵ\_IAct · Q\_IAct(w)

分段地说：取 1，至少有一个候选 w 使 Q\_IAct(w) = 1；取 0，NegComplete\_IAct^M = 1，所有候选都有 Q\_IAct(w) = 0，且这些 0 中没有 DeclarationZero；其余取 ⊥，包括存在未决的候选、覆盖未闭、上游的形式可解性条件未满足、申报失格、身份不可判等情形。总读数只由形式材料、覆盖、身份与申报的合法性决定；H\_PAct-Rep、H\_LawRead 等回读条件是否关闭，不改变总读数，只影响它回读为结构判词时的强度（七之 3、七之 7）。

4\. 零型与失败层

一个 0 可以来自两种完全不同的原因。一种是作用的某一层在结构上确实没有发生；一种是申报本身不合格，例如版本错了、锚跨了、协议在看到运行以后被改了。后者说明的是这次申报不能用，不说明作用没有发生。

定义 28（StructuralZero）\[辅\]　决定性的 0 来自实际职责层的失败：A1、A2、A3 或 A4 在结构上失败，或者所有候选共同见证都被合法的结构反证排除。

定义 29（DeclarationZero）\[辅\]　决定性的形式 0 只来自申报或协议的失格，例如：χ\_I 与当前运行对象的身份不一致；欲门职责表的版本错误；Γ\_IAct 在观察运行以后被改写；ξ\_t 申报单元不合法；使用了不属于 K\_I^M 的 𝒫；身份锚跨版本；作用候选域由不合法的事后删选产生。DeclarationZero 不回读为 N\_IAct = 0，最终退为 ⊥（DeclarationInvalid）。

定义 30（失败层）\[辅\]　Read\_{N\_IAct}^M = 0 时，每一个候选都在某一层取得 0：Q1 = 0 记在 A1；Q1 = 1 而 Q2 = 0 记在 A2；Q2 = 1 而 Q3 = 0 记在 A3；Q3 = 1 而 Q4 = 0 记在 A4；SameIActBind^M = 0 而 Q4 不为 0 的，记在 Bind。最后一种包括 Q4 = 1 与 Q4 = ⊥ 两种情形：由定义 24，SameIActBind^M = 0 时 Q\_IAct = 0，这一候选已确定不是合法的共同见证，不必等待各层读出。失败层签名 FailLayer\_IAct^M ⊆ {A1, A2, A3, A4, Bind} 是全部候选的失败层的集合；读数为 1 或 ⊥ 时，FailLayer\_IAct^M = ∅。A2 ∈ FailLayer\_IAct^M 时，另记子失败签名 FailSub\_A2^M ∈ {PCurrent, PDuty}：记在 A2 的候选都是 CurrentProbabilityOccurrence^M(w\_ρ) = 0，记 PCurrent；其中至少有一个候选是 CurrentProbabilityOccurrence^M(w\_ρ) = 1 而 ProbabilityDutyConformance^M(w\_ρ) = 0，记 PDuty。只要有进入职责兑现子层而失败的候选，就记 PDuty，这是保守的取法。Bind 不是第五项职责，只表示四层都已取得而同链绑定不成立。FailLayer 与 FailSub\_A2 都不是职责，只是负读出的诊断签名。

这些关系的性质如下。

命题 1（递进包含）。R4^M(w) = 1 ⇒ R3^M(w) = 1 ⇒ R2^M(w) = 1 ⇒ R1^M(w) = 1；并且 A\_{k+1}^M 只在 R\_k^M(w) = 1 的见证上求值。证明：由定义 23，Q\_{k+1}(w) = 1 只在 Q\_k(w) = 1 时可能。□

命题 2（量词不可拆分）。(∃₃w A1^M(w)) ∧₃ (∃₃w A2^M(w)) ∧₃ (∃₃w A3^M(w)) ∧₃ (∃₃w A4^M(w)) = 1 不推出 Read\_{N\_IAct}^M = 1。证明：取四个事件 e1 至 e4，分别只在其上使 A1^M、A2^M、A3^M、A4^M 取 1；任何把它们拼成一个候选的 w 都有 SameIActBind^M(w) = 0，故 Q\_IAct(w) = 0。□

命题 3（静置与复走）。资格齐全而当前没有现实源动续行，或者见证的事件是复走或再入，都不能取得 Read\_{N\_IAct}^M = 1。证明：前者没有 CurrentSrcRoleReal^M = 1 的候选；后者 CurrentEvent\_I^M = 0；两种情形 Q1 都不为 1。若 EventCover^M 等覆盖完整，读数为 0，FailLayer = {A1}。□

命题 4（外部完整选择器）。外部机制直接决定方向或欲门，申报组织只执行结果，没有正式源动职责到 𝒫\_I 的当前承担链，则不能取得 Read\_{N\_IAct}^M = 1。证明：CurrentSrcRoleReal^M 或 ActualSrcEnter^M 不为 1，或者任何拼接候选的 SameIActBind^M = 0。外部刺激触发而由 \[S\_I\]\_src 承担续行时，A1^M 可以取 1，不因存在外因而取 0。□

命题 5（单律独行）。A1^M = 1 而续行只由一条固定的成员律决定，概率组织没有承担相对生成，则 A2^M = 0（在 PActCertCover^M = 1 时），这一候选记在 A2。证明：由《概率作用数理式》命题 4.3，ProbabilityDutyConformance^M(w\_ρ) = 0；这里当前发生已经成立，FailSub\_A2 = PDuty。这一形式 0 的结构回读携 H\_PAct-Rep（七之 3）。□

命题 6（错误欲门与门后效应）。A2 的实际方向为 v\_a，现实路径段进入 \[G\_b\]（b ≠ a），则 CorrGateRead^M 或 DirGateChainBind^M 为 0，A3^M = 0。R3^M = 1 而门后直接进入效应一侧，则 ActualTuneEntrySeg^M = 0，A4^M = 0，不因“门后有活动”而签 1。□

命题 7（跨方向与跨门拼接）。A2 的实际方向为 v\_a 而 A3 取 v\_b 的欲门，则 DirGateChainBind^M = 0 或 SameIActBind^M = 0；A3 经过 \[G\_a\] 而 A4 取 \[G\_b\] 后的 q\_b，则 GateTuneChainBind^M = 0。□

命题 8（结果、显化与切换不进入读数）。A4^M = 1 而调谐随后被其他机制抵消、经验没有改变，或者没有显性回路参与，或者两个连续作用都走 v\_a → \[G\_a\] → q\_a 而没有欲门切换，每一个作用单元仍可取得 Read\_{N\_IAct}^M = 1。证明：定义 8 至 24 中没有一项读取调谐结果、经验改变、显化或上一个欲门。□

命题 9（多见证与零率维）。同一 ξ\_t 内存在两个合法的完整见证，Read\_{N\_IAct}^M = 1；某一正式维当前率为零，另一维形成完整作用链，Read\_{N\_IAct}^M = 1。本系统不要求唯一的方向或唯一的完整见证，零率维不退出 V\_I。证明：定义 27 是存在读数，不计正见证的个数；V\_I 取自资格实例，不随当前率值增删。□

命题 10（缺证据不写 0）。已知结果到达某个门，而来源链或 Z\_G 不可取得，则 A3^M = ⊥，不由结果状态反推过门；已知 q\_i 活跃，而不能证明它由本次 \[G\_i\] 进入，则 A4^M = ⊥，不由共时活跃反推同链使役；没有找到完整见证，而 GateSegCover^M 或 TuneSegCover^M 未闭，则 Read\_{N\_IAct}^M = ⊥。□

命题 11（申报失格）。作用链看似完整，而欲门职责表的版本与资格锚的版本不一致，则读数为 ⊥（DeclarationInvalid），不签 N\_IAct = 0。□

五、运行与求解

本系统表示当前作用的结构，不随时间演化；“运行”指对一个作用求解实例 χ\_IAct 求值。

1\. 求解次序

（1）校验 χ\_IAct、进入条件与 Γ\_IAct。申报失格时，返回 ⊥（DeclarationInvalid）。  
（2）枚举 ξ\_t 内相关的现实当前事件 e\_t，判 EventCover^M。  
（3）对每一个 e\_t 读取 Π\_t^I，校验它与 K\_I^M 同锚。  
（4）枚举正式源动职责的当前实现与 Z\_src，求 A1^M。  
（5）对 Q1 = 1 的候选，标识 ν\_t^cur，读取 κ\_ρ，求 A2^M。  
（6）对 Q2 = 1 的候选，读取本次现实生成中的正式方向 v\_i 与其对应的 \[G\_i\]，枚举 Z\_G，求 A3^M。  
（7）对 Q3 = 1 的候选，读取 \[G\_i\] 之后合法的 q\_i，枚举 Z\_T，求 A4^M。  
（8）对候选的完整链求 SameIActBind^M，得 Q\_IAct(w)。  
（9）任一 Q\_IAct(w) = 1，读数为 1，枚举可以停止。  
（10）没有正见证时，按失败层检查相应的覆盖：覆盖未闭，返回相应的 ⊥；候选的 0 中含 DeclarationZero，返回 ⊥（DeclarationInvalid）；否则签 0，并给出 FailLayer 与 FailSub\_A2。签 0 以后，按七之 3 由失败层集合确定结构判词：集合不含 A2，或含 A2 而 FailSub\_A2 = PCurrent，结构负判不携 H\_PAct-Rep；集合含 A2 且 FailSub\_A2 = PDuty 而 H\_PAct-Rep 未关闭时，形式读数仍为 0，结构判词为 ⊥（PActRepOpen）。

2\. ⊥ 的原因

形式读数取 ⊥ 时必须附原因，分为：DeclarationInvalid，申报、版本或锚失格；EventOpen，当前现实事件记录不完整；SourceRoleOpen，当前源动职责实现不可判；SourcePathOpen，源动进入 𝒫\_I 的来源链不完整；ProbabilityCertOpen，A2 的当前率承担证书不可求；DirectionOpen，当前正式方向不可判；GateIdentityOpen，正式方向与欲门职责的对应身份不可判；GatePathOpen，当前过门路径的覆盖未闭；TuneRoleOpen，门后调谐职责的身份或当前实现不可判；TunePathOpen，欲门到调谐职责的当前路径覆盖未闭；SameBindOpen，同一事件、方向、欲门、调谐链的身份绑定不可判。

另有两个原因不属于形式读数，而属于由形式读数回读得到的结构判词：PActRepOpen，形式读数为 0、失败层集合含 A2 且 FailSub\_A2 = PDuty，而 H\_PAct-Rep 未关闭，结构判词不能签 N\_IAct = 0；LawReadOpen，形式读数为 1，而正向回读实际使用的 Law-bearing 见证的 H\_LawRead 未关闭，结构判词不能无条件签 N\_IAct = 1。

这些原因都是求解诊断，不是本体条件。

3\. 可解性

以下是形式表示与求解的条件，记为 IA-M1 至 IA-M12。它们不是意向作用的本体条件，也不是 H。任一条件缺失，只使依赖它的项退为 ⊥，不自动判为结构 0。

IA-M1 求解实例可识别：χ\_IAct 的各项可以有效引用；χ\_I 是已经成立的意向资格实例；Γ\_IAct 在求解以前冻结。  
IA-M2 现实当前事件可读：运行基底能给出 ξ\_t 内的现实当前事件记录，并区分当前运行、历史复走、离线再入与资格复走。  
IA-M3 当前意向实现包可读：当前的 Π\_t^I、其中的 Π\_t^𝒫、资格锚 K\_I^M 与运行实例的身份可以取得。  
IA-M4 源动职责当前实现可判：\[S\_I\]\_src 的职责身份与当前承担的实现可判，系统边界规则冻结，能区分外部诱发与外部完整承担。  
IA-M5 来源链可追踪：Z\_src、Z\_ρ、Z\_G、Z\_T 的现实来源链、前后继关系与承担者可以读取。  
IA-M6 当前概率评价可标识：ν\_t^cur 可以合法标识，不以历史复走的评价替代当前评价。  
IA-M7 概率职责的上游证书可取：《概率作用数理式》所需的 κ\_ρ、MinSuff\_ρ、GenIn、EvalRateBind、CurrentRateRealize 在当前评价上可求，并满足其上游的可解性条件。  
IA-M8 正式方向可判：V\_I 冻结；本次现实链中哪一个正式方向取得当前后继职责可判；不以最终结果标签替代方向职责。  
IA-M9 欲门职责身份可判：欲门职责商类 𝒢̄\_I、正式对应与 GateRoleID 可判；不以单个物理节点替代欲门职责。  
IA-M10 调谐职责身份可判：门后 q\_i 的调谐职责资格、当前实现与 PostGateTuneRoleRead^M 可判；不以任意门后变化替代调谐使役。  
IA-M11 同链身份可判：事件、实现、路径段、方向、欲门、调谐职责的身份同一与前后继绑定可判，能检测跨事件、跨链的拼接。  
IA-M12 覆盖可判：各层覆盖证书都能按所需的失败层判定。

在 Γ\_IAct 冻结、所涉候选域都有限可枚举、IA-M1 至 IA-M12 成立的条件下，每一步都在有限步内完成，Read\_{N\_IAct}^M 有确定的三值读数，并在取 ⊥ 时附原因。不满足这一条件的申报实例，不因此取 0，其读数保持为 ⊥。

4\. 解的地位

Read\_{N\_IAct}^M = 1 是形式解，表示存在一个共同见证，在其上四项当前职责都成立。Read\_{N\_IAct}^M = 0 表示在完整覆盖下没有这样的形式见证；其结构层的否定强度按失败层区分（七之 3）。Read\_{N\_IAct}^M = ⊥ 表示材料不足，不得读作 N\_IAct 不成立，更不得读作意向作用不成立。

六、耦合关系

与《意向作用一般式》：只形式化 N\_IAct、A1 至 A4、R1 至 R4 与共同见证纪律，逐项对应见对应表。本系统不新增第五项职责；共同见证由同一个形式见证与 SameIActBind^M 表达。

与《意向数理式》：资格实例 χ\_I、资格锚 K\_I^M、正式方向族、源动职责类、欲门职责商类、概率维与欲门的对应、门后调谐职责的读数都沿用上游，不另建第二套意向资格系统。资格读数与作用读数严格分开：SourceDrive^M、GateCorrespondence^M、TuneInterface^M 不作为 A1^M、A3^M、A4^M 使用。

与《概率作用数理式》：当前事件、当前组织实现包、实际生成子段、当前发生、现实当前运行评价、当前率承担证书、职责兑现及其覆盖全部沿用上游，不另建第二套概率职责系统。A2^M 只调用同一见证上的当前发生与职责兑现，不调用概率作用的总读数，也不调用率域聚合的率承担读数。

与《概率数理式》《律数理式》：当前率承担证书与 Law-bearing 资格的形式来源沿用上游；具体律见证的回读条件 H\_LawRead 随该见证传播。

与场系统和运行基底：现实事件记录、当前运行实例、实际来源链、路径段与当前评价标识，都须来自场系统或运行基底。本系统不另建物理生成系统。

七、回读规则

1\. 正向回读

定理 1（A1）。w ∈ 𝔉\_IAct(w^S) ∧ A1^M(w) = 1 ⇒ A1(w^S) = 1。证明：CurrentEvent\_I^M 给出现实当前的事件；CurrentSrcRoleReal^M 给出本次承担源动的是意向自身的源动职责实现；ActualSrcEnter^M 给出这段续行实际进入 𝒫\_I；SrcAnchorBind^M 给出它们属于同一资格锚。各项都是结构分量的直接表示，不另立回读桥，不新增 H。□

定理 2（A2）。w ∈ 𝔉\_IAct(w^S) ∧ A2^M(w) = 1 ⇒ A2(w^S) = 1。证明：A2^M(w) = 1 要求 CurrentProbabilityOccurrence^M(w\_ρ) = 1 且 ProbabilityDutyConformance^M(w\_ρ) = 1；由《概率作用数理式》的正向回读（7.1）、（7.2）与定理 7.1，在同一事件、同一实现包、同一生成子段上，𝒫\_I 的合法当前实现以当前承重状态实际进入各方向之间相对生成的形成。这一回读不携 H\_PAct-Rep；所用 Law-bearing 资格若由形式读数即时取得，按实际见证逐项承继 H\_LawRead(W\_i)，不建立统一的新 H。□

定理 3（A3）。w ∈ 𝔉\_IAct(w^S) ∧ A3^M(w) = 1 ⇒ A3(w^S) = 1。证明：DirCurrentRealize^M 给出本次取得当前职责的正式方向；CorrGateRead^M 给出它正式对应的欲门职责类；ActualGatePassSeg^M 给出现实的过门路径段；DirGateChainBind^M 给出这一方向正是 A2 那一次职责兑现中形成的方向。合为：由 A2 形成的方向续行沿正式对应实际进入其欲门。不新增 H。□

定理 4（A4）。w ∈ 𝔉\_IAct(w^S) ∧ A4^M(w) = 1 ⇒ A4(w^S) = 1。证明：PostGateTuneRoleRead^M 给出门后职责是合法的调谐使役；CurrentTuneRoleReal^M 给出它此刻有合法的当前实现；ActualTuneEntrySeg^M 给出从欲门进入它的现实路径段；GateTuneChainBind^M 给出这段路径接在 A3 的同一欲门之后。合为：同一条作用链过门以后实际进入调谐使役。A4^M = 1 只回读 CurrentTuneCommand = 1，不回读调谐成功、经验改变、显化、欲门切换、理之作用完成或效应成功。不新增 H。□

定理 5（共同见证）。SameIActBind^M(w) = 1 回读为：A1 至 A4 在结构层属于同一次合法的现实作用链，即一般式的 B\_same^IAct。它不回读为第五项职责，不携 H。证明：定义 22 的各项逐一对应一般式共同见证的六个方面与链段的连接。□

定理 6（N\_IAct 正向形式解定理）。Read\_{N\_IAct}^M = 1 ⇒ N\_IAct = 1。证明：存在 w 使 Q\_IAct(w) = 1，即 SameIActBind^M(w) = 1 且 Q4(w) = 1；由定义 23，A1^M 至 A4^M 在 w 上都为 1；取 w^S 使 w ∈ 𝔉\_IAct(w^S)，由定理 1 至 5，四项在同一结构见证上成立。条件：只沿 A2 实际使用的 Law-bearing 形式见证传播适用的 H\_LawRead；若 Law 资格已是对象层的既成事实，则无此条件。本定理不调用 H\_PAct-Rep。□

Read\_{N\_IAct}^M = 1 回读到 N\_IAct = 1 为止；N\_IAct ⇒ IntentAct 属于《意向作用必然式》。

2\. 反向表示

负向回读要成立，须先有反向表示：结构层存在一个四项都成立的见证时，形式层能取得相应的正见证。否则“形式候选已查完而没有正见证”推不出“结构层没有这样的见证”。

A1、A3、A4 的各项读数，都是对事件、路径段与职责身份的直接表示：在 IA-M1 至 IA-M5、IA-M8 至 IA-M12 成立时，结构层的源动当前发生、当前过门与调谐使役当前兑现，都有相应的合法形式登记，并在覆盖完整时进入候选域。形式材料不足时退为 ⊥，不以弱的代理量反推结构，所以这三项不需要另立表示条件。共同见证绑定同样是对事件、实现、路径段与职责身份的直接表示：结构层一条同链的完整作用，其形式登记在 IA-M11 成立、覆盖完整时以 SameIActBind^M = 1 进入候选域。

A2 的当前发生子层也是直接表示：由《概率作用数理式》定理 7.2，在其可解性条件 PA-M1 至 PA-M5、PA-M9 下，结构层的当前概率发生有合法形式登记，并在 EventCover^M、PRealCover^M、PGenSegCover^M 为 1 时进入候选域，不携 H。

A2 的职责兑现子层不同。它需要的是：结构层在同一见证上职责兑现成立时，现实当前评价上存在一张满足上游证书定义、并对这个形式见证满足同一性条件的证书。这正是《概率作用数理式》的 H\_PAct-Rep；本系统承继它，不关闭它。

3\. 负向回读

Read\_{N\_IAct}^M = 0 时，各候选可以在不同的层上失败，失败层签名 FailLayer\_IAct^M 是这些层的集合（定义 30）。从形式 0 回读结构判词 N\_IAct = 0，须对集合中的每一层都满足该层的回读条件：

A1 ∈ FailLayer：EventCover^M、SrcRoleCover^M、SrcSegCover^M 及相关身份覆盖闭合。不携新 H。

A2 ∈ FailLayer，且 FailSub\_A2 = PCurrent：上述各项与 PRealCover^M、PGenSegCover^M 闭合。不携 H\_PAct-Rep，不携新 H。

A2 ∈ FailLayer，且 FailSub\_A2 = PDuty：上述各项与 PActCertCover^M 都闭合，并且 H\_PAct-Rep 关闭。H\_PAct-Rep 未关闭时，形式读数仍为 0，但不得签结构零，结构判词为 ⊥（PActRepOpen），更不得进一步签 IntentAct = 0。

A3 ∈ FailLayer：DirRealCover^M、GateSegCover^M 与对应身份覆盖闭合。不携新 H。

A4 ∈ FailLayer：TuneRoleCover^M、TuneSegCover^M 与门后身份覆盖闭合。不携新 H。

Bind ∈ FailLayer：A1 至 A4 各层的覆盖都闭合，同链身份可判。共同见证绑定是对事件、实现、路径段与职责身份的直接表示，结构层若有一条同链的完整作用，它的形式登记在覆盖完整时必然以 SameIActBind^M = 1 进入候选域；所以不携新 H。

集合中各层的条件都满足时，N\_IAct = 0：结构层不存在一个四项都成立、并属于同一条作用链的见证。所携条件是集合中各层所携条件的合取；只要集合含 A2 且 FailSub\_A2 = PDuty，就携 H\_PAct-Rep。

由《意向作用一般式》的必要方向 IntentAct ⇒ N\_IAct 取逆否，N\_IAct = 0 ⇒ IntentAct = 0。这一箭头不另增条件；经 A2 职责兑现子层取得者，仍携 H\_PAct-Rep。N\_IAct = 0 不推出 Intent = 0：意向作用不成立，意向资格仍可以成立。

4\. 未决与零型

Read\_{N\_IAct}^M = ⊥ 既不推出作用成立，也不推出作用不成立：

&nbsp;&nbsp;&nbsp;&nbsp;没有找到见证 ≠ 0，　⊥ ≠ 0，　Read = ⊥ ⇏ N\_IAct = 0

DeclarationZero 不回读为 N\_IAct = 0，只退为 ⊥（DeclarationInvalid）。

5\. 禁止回读

不得：Read\_{N\_IAct}^M = 1 ⇒ IntentAct = 1；这一方向须经《意向作用必然式》。  
不得：SourceDrive^M = 1 ⇒ A1，GateCorrespondence^M = 1 ⇒ A3，TuneInterface^M = 1 ⇒ A4。  
不得：A3^M = 1 ⇒ 欲门切换。  
不得：A4^M = 1 ⇒ 调谐成功、经验改变、显化或效应成功。  
不得：候选域为空 ⇒ Read = 0，除非 NegComplete\_IAct^M = 1。  
不得：由结果状态反推过门，由共时活跃反推同链使役。

6\. 纯形式辅助量

以下不回读为意向作用的新增本体组成：Γ\_IAct；SrcAnchorBind^M、DirGateChainBind^M、GateTuneChainBind^M；K\_IAct^M、Λ\_IAct^M；Q1 至 Q4、Q\_IAct；Ŵ\_IAct、各覆盖证书与 NegComplete\_IAct^M；StructuralZero、DeclarationZero 的标记；FailLayer\_IAct^M 与 FailSub\_A2^M；⊥ 所附的原因；候选的枚举次序与编号。w\_I^M、Π\_t^I 与 SameIActBind^M 标为 \[表\]：它们是一般式已有对象的形式登记，回读为一般式的见证、当前实现与共同见证纪律，不是新的实体。

7\. 条件

&nbsp;&nbsp;&nbsp;&nbsp;H\_new = ∅

本系统不新立 H\_SrcAct-Rep、H\_GatePass-Rep、H\_TuneCmd-Rep：A1、A3、A4 都采用对事件、路径段与职责身份的直接形式表示，形式材料不足时退为 ⊥。

承继的开放条件：

&nbsp;&nbsp;&nbsp;&nbsp;H\_inherit^open = { H\_PAct-Rep }

来源：《概率作用数理式》。它只承重 A2 ∈ FailLayer 且 FailSub\_A2 = PDuty 这一支的负向结构回读，以及由此传导到 N\_IAct = 0、IntentAct = 0 的负向结论；不承重形式系统本身、A1 至 A4 的正向回读、定理 6、A2 当前发生子层的负向回读，以及 A1、A3、A4 层的负向结构回读。

H\_LawRead：只在 A2 正向回读实际使用某一 Law-bearing 形式见证时，按见证逐项传播；不设统一的新 H。

IA-M1 至 IA-M12 是形式可解性条件，影响 1、0、⊥ 的取得，不改变结构真值，不是 H。

状态：形式系统 Established，不以任何未决 H 为前提；A2 的正向回读与定理 6 为 Conditional，条件为所用见证适用的 H\_LawRead（A1、A3、A4 与共同见证的正向回读 Established）；A1、A3、A4、Bind 层与 A2 当前发生子层的负向回读 Established；A2 职责兑现子层的负向回读 Conditional，条件为 H\_PAct-Rep。

8\. 击穿方式

K-IAM1：Read\_{N\_IAct}^M = 1，而结构层 N\_IAct = 0。  
K-IAM2：A1^M = 1，而结构层没有源动职责当前发生。  
K-IAM3：A2^M = 1，而结构层没有概率职责当前兑现。  
K-IAM4：A3^M = 1，而结构层没有对应欲门当前通过。  
K-IAM5：A4^M = 1，而结构层没有调谐使役当前兑现。
