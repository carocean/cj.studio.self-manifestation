# 意向作用必然式

一、目的

证明：意向已经成立时，在当前作用申报单元 ξ\_t 内，只要以下四项当前职责在同一个现实见证上全部兑现，一次完整的意向作用就成立，不需要再满足第五项独立的作用条件。

四项当前职责是：

第一，源动职责当前发生：本次现实续行中，意向自身的源动职责实际发生，并进入 𝒫\_I。

第二，概率职责当前兑现：在同一次续行中，𝒫\_I 作为概率组织，实际承担各正式方向之间相对生成的形成。

第三，对应欲门当前通过：由此形成的方向续行，沿正式对应实际进入该方向的欲门。

第四，调谐使役当前兑现：同一条作用链过门以后，实际进入该欲门的调谐使役接口。

用式子表示为：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct ⇒ IntentAct\_{F,t}(ξ\_t)

&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct := ∃w\_I \[ A1(w\_I) ∧ A2(w\_I) ∧ A3(w\_I) ∧ A4(w\_I) \]

工作域为 Intent\_{F,t} = 1。

“不需要再满足第五项独立的作用条件”具体是指：欲门是否发生了切换，有没有显化，有没有意识到，调谐是否成功，经验最终是否改变，有没有外部行为或效应，有没有形成注意，有没有默想或思考回路参与，这次路线是否确定，某些正式维当前率是否为零，是否由外界刺激诱发，同一单元内是否另有完整的作用链，都不影响结论。

二、上游输入、证明路线与对象映射

1\. 上游输入

《意向作用一般式》：N\_IAct、A1 至 A4、R1 ≺ R2 ≺ R3 ≺ R4、共同见证纪律 B\_same^IAct、当前完整作用单元的含义；必要方向 IntentAct ⇒ N\_IAct，Status 为 Established；作用语料的冻结范围 U\_IAct^src。本篇使用该篇的作用核与语料范围，不使用该篇关于第五项作用职责与独立取消条件的结论。

《意向作用数理式》：作用形式系统 M\_IAct、总读数 Read\_{N\_IAct}^M 与正向回读 Read\_{N\_IAct}^M = 1 ⇒ N\_IAct = 1（携所用见证适用的 H\_LawRead）。它只作为本篇的形式入口，不作主证明的前件。

《意向必然式》：Intent ⇔ N\_I，Status 为 Established；对语义原子的分类，其中 u30 至 u34 归作用，u48 至 u51 归后果。

《意向一般式》：语义原子全集 u1 至 u52 与各原子的拆分（附录四）。

2\. 证明路线

证明不采用“《意向作用一般式》已经检查过没有第五项作用职责、没有独立取消条件，所以四项齐全就足以成立意向作用”的路线。那两项检查在该篇中服务于必要方向，本篇不把它们作为前提，只在第八节作一致性回测。本篇在同一作用语料范围上独立地重新执行充分性程序。

证明路线为：

&nbsp;&nbsp;&nbsp;&nbsp;冻结作用语义域 → 原子分类 → 不可约合取审查 → 作用语义闭合 → N\_IAct 完整实现作用语义 → IntentAct

与此对应的三条定理是：先在冻结的作用语义域上取得当前作用的全部正面语义，并证明不存在第五项作用职责与独立的取消条件（定理一）；再证明 N\_IAct 在同一见证上完整实现这些语义（定理二）；最后得出意向作用必然定理（定理三）。

3\. 对象与算子映射

对象层：

Intent\_{F,t}：已经成立的意向资格，本篇的工作域，不重新证明。  
ξ\_t：当前完整作用申报单元，不是零宽瞬点，取自《意向作用一般式》。  
IntentAct\_{F,t}(ξ\_t)：在当前申报单元 ξ\_t 内，一次完整的意向作用成立；本篇的目标谓词。  
A1 = CurrentSourceOccurrence，A2 = IntentProbabilityDuty，A3 = CurrentGatePass，A4 = CurrentTuneCommand；R1 至 R4；B\_same^IAct；N\_IAct：均取自《意向作用一般式》，本篇不重写。

元语言对象：

U\_IAct^+：本篇独立取得的正面作用语义的集合。  
U\_IAct^O：本篇独立取得的、不决定每一次作用真值的其余语义的集合。

这些都是元语言名称，不是本体谓词，不是场量，不进入 N\_IAct；出现的地方都可以直接展开为第五节列出的语义原子。证明使用的是展开后的语料条件，不是名称本身。

形式层，只作入口：

Read\_{N\_IAct}^M、A1^M 至 A4^M、SameIActBind^M、Q\_IAct：取自《意向作用数理式》。

映射到此完整；没有列入的对象不承重。

三、冻结作用语义域

本篇的作用语义域冻结为：

&nbsp;&nbsp;&nbsp;&nbsp;U\_IAct^src = { u30, u31, u32, u33, u34, u48, u49, u50, u51 }

原子的编号与拆分沿用《意向一般式》附录四，出处如下。页码为《自显论》v0.7.1 的 PDF 页序。

u30　经验可以并用，也可以切换。出自 Q3：“各有其经验可以并用，亦可切换，使之者，意图也。”（第 53 页）  
u31　静中动念必于意向域发动，意向施动于初。出自 Q12：“其必于意向域发之，故必有‘意向’施动之以初，称之为静中动念。”（第 87 页）  
u32　偏向是起心动念，择欲门而使役调谐，必先决而后使之。出自 Q13：“偏向者，起心动念，择欲门而使役调谐，必先决而后使之。”（第 126 页）  
u33　源动驱动的概率在穿过众多律生态的各方向上能归一而行。出自 P1：“概率如受源动驱动，则表现为对律生态的破持，生成各向的律续行熟路，由于其对律施以破持，故源动驱动的概率是理，它使在穿过众多律生态中各方向上，能归一而行，即能行一。”（《概率组式》B5）  
u34　注意，是紧张意向所调之处。出自 T3（第 76 页）。  
u48　切换欲门的过程本身没有自显性。  
u49　切换到某个欲门以后，欲门后的组织中有显性回路参与，才发生显化。  
u50　意向作用发生在意识到之前。  
以上三项出自 I9：“切换欲门的过程本身没有自显性，而是切换到某欲门后，欲门后的组织中有显性回路的参与才发生了显化作用……所以意向作用发生在意识到之前。”  
u51　意向效应线使意向能调动各效应。出自 T1：意图场的五总线中，有意向调谐线，使意向能调谐各经验；有意向效应线，使意向能调动各效应。（第 55 页）

《意向必然式》已把 u30 至 u34 归为作用，把 u48 至 u51 归为后果。其余原子回答的是意向资格、关系、称名、位置、工作域、动力、来源、表示、本体边界或实现，不回答一次作用是否成立；它们中属于资格的部分，回答的是工作域 Intent = 1 本身的内容，不进入作用真值的判定。

语料域申明：当前 IntentAct 的真值，由冻结作用语义域所给出的当前作用语义决定：在工作域 Intent = 1 内，正面取得的作用语义全部实现、且没有取消条件生效时，IntentAct = 1。这是冻结语义域的含义，不是另加的前件。关于一次完整意向作用的全部语义结论，只在 U\_IAct^src 上取得。若母本语料修订，或新增直接决定当前 IntentAct 真值的语句，按第十一节击穿一复审。这一限定是证明域的限定，不是 H。

四、分类规则

1\. 分类

每一个原子按它在“本次完整作用是否成立”这一问题上的职责，归入下列一类。

正面作用语义 U\_IAct^+：一次完整作用成立，凭的是哪些当前的事。按所回答的问题，本篇在语料中读出三个承重点：

U\_Init　发起：意向是否施动于初。  
U\_ChooseCommand　决、择、使：是否先决出方向、择定欲门，然后使役调谐。  
U\_ProbRun　源动经由概率而行：源动驱动的概率是否在诸方向上归一而行。

三个承重点不与 A1 至 A4 一一对应；它们是从语料中独立读出的，承重点的个数由语料决定，不为了与四项职责数目一致而凑数。

取消侧：在正面作用语义全部实现时，能够单独使 IntentAct = 0 的原子。

其余语义 U\_IAct^O：能力或功能的范围、作用的一类对象、作用的后果与边界。它们各有理论意义，但不承担“本次完整作用是否成立”的普遍取得职责。

2\. 分类判准

（a）问题判准。看该原子回答的是“本次作用凭什么成立”，还是“作用能做什么”“作用作用于什么”“作用之后发生什么”。

（b）时相判准。看该原子说的是本次作用之内的事，还是作用之后的后果、作用一般具有的能力。

（c）删除判准。假设该原子在本次作用中不出现，其余原子不变。如果语料中没有语句因此否认本次作用成立，那么它不属于正面作用语义。本判准只用于复核按（a）已归入 U\_IAct^O 的原子。

（d）取消侧审查。如果某个原子在形式上像否定，需要专门审查：假设正面作用语义全部实现，它能否单独使 IntentAct = 0。如果它要生效就必然使某项正面语义失效，它就不是独立的取消条件。

3\. 不可约合取审查

单个原子分类以后，仍须检查冻结语料所授权的不可约合取。两个单独都不决定作用真值的原子，合在一起有可能产生新的效力，所以不能由“各部分都不是作用条件”推出“合取也不是作用条件”。如果有人主张某个合取承担新的作用取得职责或取消职责，就必须在冻结语料中找到明确授权这一组合承担该职责的依据；这种授权可以出现在同一句内，也可以由跨句的因果、条件、指代、总结或回指关系形成。

一个合取如果要成为第五项作用职责，还必须满足：在正面作用语义全部实现、四项作用职责同见证成立时，它不成立就使 IntentAct = 0，而这一取消并不表现为四项中任何一项的退出。

五、原子逐项分类

1\. 正面作用语义

u31　意向施动于初。U\_Init。Q12 说静中动念“必有‘意向’施动之以初”：从静到动，必须有意向自身的施动。它回答的是本次作用凭什么开始。

u32　先决而后使。U\_ChooseCommand。Q13 说偏向“择欲门而使役调谐，必先决而后使之”：先决出方向，择定欲门，然后使役调谐，并且有先后。它回答的是本次作用由哪几件事组成、按什么次序。

u33　源动驱动的概率在诸方向上归一而行。U\_ProbRun。P1 的这一分量说的是：源动经由概率组织，在诸方向之间归一而行，而不是一条律自己走。它回答的是本次作用的行是谁在行、怎样行。

2\. 其余语义

u30　经验可以并用，也可以切换。U\_IAct^O。它说的是作用能做什么，不是每一次作用都必须并用或切换。删除判准：一次作用只调一个经验、不发生切换，语料中没有语句因此否认它是意向作用。

u34　注意，是紧张意向所调之处。U\_IAct^O。它说的是作用的一类对象：紧张意向所调之处叫作注意。不是每一次作用都调到注意上。

u48　切换欲门的过程本身没有自显性。U\_IAct^O，边界。

u49　切换以后，欲门后的组织中有显性回路参与，才发生显化。U\_IAct^O，后果。

u50　意向作用发生在意识到之前。U\_IAct^O，边界。

u51　意向效应线使意向能调动各效应。U\_IAct^O，作用之后的能力。

3\. 取消侧审查

在形式上像否定或像限制的原子有 u48、u49、u50。

u48“没有自显性”：它否定的是切换过程的自显，不否定作用。假设正面作用语义全部实现而没有任何自显，语料中没有语句因此使 IntentAct = 0；相反，它说明作用本来就可以没有自显。

u49“才发生显化”：它规定的是显化的条件，即显性回路参与。它说显化晚于作用、依赖门后的显性回路，不说作用依赖显化。假设正面作用语义全部实现而没有显性回路参与，显化不发生，作用照样成立。

u50“发生在意识到之前”：它直接排除把意识到当作作用的条件。假设正面作用语义全部实现而尚未意识到，语料明说作用已经发生。

三者都不能在正面作用语义全部实现时单独使 IntentAct = 0。

&nbsp;&nbsp;&nbsp;&nbsp;U\_IAct^O = { u30, u34, u48, u49, u50, u51 }  
&nbsp;&nbsp;&nbsp;&nbsp;取消侧：空集

六、作用语义闭合

1\. 定理一　意向当前作用语义闭合定理

在冻结作用语义域 U\_IAct^src 上：当前完整意向作用的正面语义正好是 u31、u32、u33；其余原子不决定每一次作用的真值；取消侧为空；并且冻结语料中不存在承担第五项作用职责或取消职责的不可约合取。即：

&nbsp;&nbsp;&nbsp;&nbsp;U\_IAct^+ = { u31, u32, u33 }，　U\_IAct^O = { u30, u34, u48, u49, u50, u51 }  
&nbsp;&nbsp;&nbsp;&nbsp;FifthIndependentActDuty\_I = ∅，　IndependentCancel\_IAct = ∅

证明

第一，正面语义已经穷尽。U\_IAct^src 是有限集合，九个原子都已按第四节的判准归类。归入正面的只有 u31、u32、u33；其余六个按判准（a）（b）归入能力、对象、边界或后果，并经判准（c）复核。

第二，单原子不承担第五项职责。u31 由“施动于初”承担发起；u32 承担决、择、使及其次序；u33 承担源动经由概率而行。u30 是能力范围，u34 是作用对象的一类，u48、u50 是边界，u49 是显化后果，u51 是作用之后的能力；它们都不是每一次作用的普遍取得条件。

第三，取消侧为空。u48、u49、u50 已按判准（d）逐项审查，都不能在正面语义全部实现时单独使 IntentAct = 0。以下候选也都不是独立的取消条件：

没有欲门切换：同一欲门上连续两次完整作用都合法，u30 只说可以切换。  
没有显化：由 u48、u49，作用可以先于显化，显化是门后显性回路参与的后果。  
没有意识到：由 u50，作用发生在意识到之前。  
没有外部行为、没有效应输出：行为与效应在调谐使役之后；u51 说的是作用之后的能力。  
调谐没有成功、经验最终没有改变、后续结果被抵消：u32 说的是“使役调谐”，使役已经发出即已兑现，结果属于其后。  
没有形成注意：由 u34，注意只是作用的一类对象。  
没有默想、内观、回顾或思考回路参与：这些是高级重入的一种起始方式；u31 只要求意向自身施动，源动可以直接触发作用。  
这次路线是确定性的：u33 说的是在诸方向之间归一而行，单次续行落在哪一维不取消“经由概率而行”。  
某些正式维当前率为零：零率维不退出正式方向，不影响另一维上的完整作用。  
外界刺激诱发：u31 要求施动属于意向自身；外界可以触发，承担施动的仍是意向自身的源动职责。  
休眠域对意向域的抑制：这一项不在冻结作用语义域内（u37，动力），但它最容易被读成取消条件，所以一并审查。抑制若使源动续行不能发生，或使门后的调谐使役不能发生，那是 u31 或 u32 没有实现，属于正面语义的缺失；正面语义全部实现时，语料中没有语句规定抑制仍使作用不成立。  
同一单元内另有完整的作用链：语料中没有语句要求一次只有一条作用链。

第四，不存在承担第五项职责或取消职责的不可约合取。这里审查的不是“同一句中同时出现的多个原子”，而是冻结语料是否在两个以上原子之间给出了联合授权，即把这些原子的共同成立本身作为取得或取消本次作用的依据。

先审查同句授权。

Q13 把“偏向”“起心动念”“择欲门”“使役调谐”“先决而后使”写在一句里，全部属于 u32，句子说明的是同一次作用的组成与次序，没有另加条件。

I9 把 u48、u49、u50 写在一句里，全部属于 U\_IAct^O。句子的结论是“意向作用发生在意识到之前”，它恰好排除了把显化或意识到加为作用条件的读法，没有授权这些后果的组合承担作用职责。

Q3 把 u30“可以并用，亦可切换”与资格原子 u21“使之者，意图也”写在一句里。u21 回答经验的并用与切换由谁使役，属于意向资格，回答的是工作域本身的内容；u30 说的是作用能做什么。句子没有规定“当前正在并用或切换”才是作用。

T1 把 u51“效应线”与资格原子 u20“调谐线”并列。并列不是授权：T1 只是列举意图场的总线，没有规定一次作用必须同时调谐与调动效应。

P1 把 u33 与资格原子 u1、关系原子 u23、形成原子 u40 写在一句里。句中“由于其对律施以破持，故……是理”说明的是“是理”的来由，“生成各向的律续行熟路”的结果分量是资格；它们都没有被赋予“本次作用是否成立”的新增语义。

再审查核心原子之间与核心原子同其余原子的合取。u31 ∧ u32、u31 ∧ u33、u32 ∧ u33、u31 ∧ u32 ∧ u33：只是三个承重点的组合，语料没有在它们之上另加职责。u32 ∧ u34：描述作用调到注意上的一类实例；u32 ∧ u49：描述作用之后发生显化的一类实例；它们都不是普遍的作用条件。U\_IAct^O 内部的合取，例如 u30 ∧ u34、u48 ∧ u49 ∧ u50：冻结语料没有授权这些组合本身决定作用的真值。

再审查跨句授权。Q12 的“施动之以初”与 Q13 的“起心动念”相互对照，都说本次作用由意向自身发起；Q13 的“择欲门而使役调谐”与资格层上概率维与欲门的对应、门后调谐接口相互对照，前者是当前的兑现，后者是结构；P1 的“归一而行”与 I5、I6 的“系统不读率值”“有路径、有律使之走此路”相互限定，说明归一而行由组织承担，不是读出率值再选择；T4 的“起心动念始发于默想回路”与 Q12 相互对照，前者说的是一种起始方式，后者说的是普遍的施动。这些跨句关系都只用于澄清单项语义、说明起始方式或后果，没有任何跨句关系把两个以上原本不决定作用真值的原子的共同成立，另外授权为第五项作用职责或独立的取消条件。

真正能阻断作用的情形，都通过使某项正面语义失效而生效：源动没有施动，u31 不实现；单律独行而概率组织没有承担相对生成，u33 不实现；方向没有进入对应的欲门，或者到门而止没有使役调谐，u32 不实现。这些是正面语义的缺失，不是独立的取消条件。

综合以上四点，定理一得证。□

这一结论是本篇在冻结作用语义域上独立取得的，不引用《意向作用一般式》的同名检查结果。

七、职责实现

1\. 定理二　意向作用职责实现定理

&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct ⇒ u31 ∧ u32 ∧ u33

具体为：

&nbsp;&nbsp;&nbsp;&nbsp;A1 ⇒ u31  
&nbsp;&nbsp;&nbsp;&nbsp;A2 ∧ A3 ∧ A4 ⇒ u32  
&nbsp;&nbsp;&nbsp;&nbsp;A1 ∧ A2 ⇒ u33

三条都在同一个见证 w\_I 上读取。u32 与 u33 是跨职责的联合实现：它们的完整含义需要两项或三项职责在同一条作用链上共同落成，不能伪造成“每一项职责单独实现一个完整的语义原子”。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;A1    A2    A3    A4  
&nbsp;&nbsp;&nbsp;&nbsp;u31     ✓  
&nbsp;&nbsp;&nbsp;&nbsp;u32           ✓     ✓     ✓  
&nbsp;&nbsp;&nbsp;&nbsp;u33     ✓     ✓

证明

第一，A1 ⇒ u31。A1 给出：本次现实续行中，意向自身的源动职责实际发生，并进入 𝒫\_I。这就是“意向施动于初”：从静到动，有一次属于意向自身的施动。外界可以触发，但承担这次施动的是意向自身的源动职责，所以 u31 的“意向”施动得到实现。

第二，A2 ∧ A3 ∧ A4 ⇒ u32。u32 有三个环节和一个次序。“先决”：A2 给出，在同一次续行中，概率组织作为概率承担了各正式方向之间相对生成的形成，从而决出了这一次的方向。“择欲门”：A3 给出，由 A2 形成的方向续行沿正式对应实际进入该方向的欲门。“使役调谐”：A4 给出，同一条链过门以后实际进入门后的调谐使役。“先决而后使之”：由 R2 ≺ R3 ≺ R4，后一层只在前面各层已经成立的同一条链上取得，A4 的使役接在 A3 的同一欲门之后，A3 的方向正是 A2 那一次决出的方向。这里的先后是同一次作用之内的语义次序，不是一般的因果律。三项缺一，u32 都不完整：只有 A2，方向决出了而没有择门；只有 A2、A3，择了门而没有使役。

第三，A1 ∧ A2 ⇒ u33。u33 说的是“源动驱动的概率”在诸方向上“归一而行”。A1 给出源动驱动在本次的现实发生；A2 给出概率组织在同一次续行中承担诸方向之间相对生成的形成，这一次续行由此在诸方向之间走出，即归一而行。这里的“归一而行”是当前相对生成的执行表现，不要求最终只落到某一维，也不排除同一单元内另有作用链。只有 A2 而没有 A1，概率在行，却不是源动驱动；只有 A1 而没有 A2，源动在行，却是单律独行，不是经由概率而行。所以 u33 必须由二者在同一见证上共同实现。

第四，同一见证。N\_IAct 的前件是 ∃w\_I \[ A1(w\_I) ∧ A2(w\_I) ∧ A3(w\_I) ∧ A4(w\_I) \]，而不是 (∃w A1) ∧ (∃w A2) ∧ (∃w A3) ∧ (∃w A4)。共同见证 B\_same^IAct 保证四项属于同一个 𝒫\_I、同一次现实续行、同一个概率职责的兑现、同一条实际方向、该方向对应的同一个欲门、从这个欲门接出的同一条调谐使役链。所以上面三条实现都发生在同一次作用中：意向自己发起，概率自己承担方向的形成，方向实际进入对应的欲门，同一条链实际进入调谐使役。这证明的不是“四件事曾分别发生”，而是一次作用。

综合以上四点，N\_IAct ⇒ u31 ∧ u32 ∧ u33，即 N\_IAct 完整实现 U\_IAct^+。□

2\. 完整作用单元不是第五项条件

不另立“作用单元已经完整”作为第五项前件。《意向作用一般式》已经把一次完整作用的闭合放在 R4 = A1 ∧ A2 ∧ A3 ∧ A4 与共同见证之中：R1、R2、R3 是同一次完整作用的职责前缀，到 A4 闭合。若再另立一项“完整”，就会重复计算 R4 与共同见证已经实现的内容。

八、意向作用必然定理

1\. 定理三　意向作用必然定理

&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct ⇒ IntentAct\_{F,t}(ξ\_t)

证明

设 Intent\_{F,t} = 1，并设 N\_IAct = 1。由定理二，冻结作用语义域中的全部正面作用语义 u31、u32、u33，在同一次现实作用中完整实现。由定理一，在冻结作用语义域上，正面作用语义正好是这三项，没有第五项作用职责，没有独立的取消条件，也不存在承担第五项职责或取消职责的不可约合取。因此，当前完整意向作用的全部正面语义已经取得，而且没有独立的因素取消它。按第三节语料域申明，IntentAct\_{F,t}(ξ\_t) = 1。□

这里得到的不是“与意向作用相似的结构”。四项当前职责在同一见证上完整实现了由冻结语料独立分析得到的全部正面作用语义；证明并不依赖于把 IntentAct 定义为 N\_IAct。

2\. 反充分世界

令

&nbsp;&nbsp;&nbsp;&nbsp;W\_IAct^- := { w ∣ N\_IAct(w) = 1 ∧ IntentAct(w) = 0 }

在冻结作用语义域与工作域 Intent = 1 内，

&nbsp;&nbsp;&nbsp;&nbsp;W\_IAct^- = ∅

证明：设 w ∈ W\_IAct^-。IntentAct(w) = 0，按语料域申明，或者某一项正面作用语义没有实现，或者某一取消条件生效。前者与定理二矛盾：N\_IAct(w) = 1 已经在同一见证上实现 u31、u32、u33。后者与定理一矛盾：取消条件集合为空，也不存在承担取消职责的不可约合取。所以 W\_IAct^- 为空。□

W\_IAct^- = ∅ 是在冻结作用语义域与工作域内的结论，不是对一切可能理论的绝对断言。它说明必然的来由：不是因为意向作用被定义成四项职责，而是因为全部正面作用语义已经由四项职责在同一见证上完整实现，并且没有独立的取消项。

3\. 一致性回测

《意向作用一般式》在其冻结作用语义域上检查过，没有第五项普遍作用职责，也没有独立的取消条件。这与本篇定理一的结论一致。必要方向与充分方向在同一语义域上得到了相容的结果。这一回测不参与定理三的证明。

4\. 双向闭合

《意向作用一般式》：IntentAct\_{F,t}(ξ\_t) ⇒ N\_IAct，Status = Established。

定理三：N\_IAct ⇒ IntentAct\_{F,t}(ξ\_t)，Status = Established。

两者合并，得到：

&nbsp;&nbsp;&nbsp;&nbsp;IntentAct\_{F,t}(ξ\_t) ⇔ N\_IAct

双向式 Status = Established。这不是定义上的同一，而是两个方向分别由两篇独立证明以后的合成。

意向作用于是有了完整的结构刻画：一次完整的意向作用，就是意向自身的源动此刻确实在行，概率此刻确实作为概率在行，方向此刻确实进入对应的欲门，过门以后确实使役了调谐，而且这四层是同一次作用。

九、边界例

1\. 同一欲门上连续作用

假设同一欲门 G\_a 上先后有两次完整作用，每一次都有 A1 至 A4 在同一见证上成立。两次 IntentAct 都成立；没有发生欲门切换，不取消任何一次。

2\. 无显化、无意识到

假设 A1 至 A4 在同一见证上成立，欲门后没有显性回路参与，系统尚未意识到。IntentAct = 1。意向作用发生在意识到之前；显化是门后显性回路参与的后果。

3\. 调谐失败、经验未变、无行为

假设 A4 已经兑现，调谐随后被其他机制抵消，经验最终没有改变，也没有外部行为或效应输出。IntentAct = 1。使役已经兑现，作用的当前职责已经闭合；结果属于其后。

4\. 无注意、无默想

假设这一次调谐的对象不是注意，起始也没有默想、内观、回顾或思考回路参与，而是源动直接触发。A1 至 A4 成立时，IntentAct = 1。

5\. 外部诱发与外部完整承担

假设外界刺激触发，意向自身的源动职责承担续行，其后 A2 至 A4 同链成立。IntentAct = 1：外部诱发不等于外部承担。

假设外部选择器直接决定方向或欲门，申报组织只执行结果。这时 A1 或 A2 不成立，不落入定理三的前件，也不构成反充分世界。

6\. 前件不满足的情形

单律独行，A1 成立而 A2 不成立；方向不进对应欲门，A3 = 0；到门而止，A4 = 0；四项分属不同的事件，或者四类事实各自存在而共同见证不成立，N\_IAct = 0。这些都不落入定理三的前件，不构成反充分世界。

7\. 多条完整作用链与零率维

假设同一单元内有两条合法的完整作用链，IntentAct = 1，不要求唯一。作用链、方向、欲门都可以区分和计数；作用链的条数不是意向的计数。

假设某一正式维当前率为零，另一维形成完整作用链，IntentAct = 1。零率维不退出正式方向。

8\. 确定性单次落定

假设当前环境下每一次都落到同一方向，而资格层仍是合法的多方向概率组织，A1 至 A4 成立。IntentAct = 1。单次续行落在哪一维，不取消经由概率而行。

9\. 附带后果

假设 A1 至 A4 成立，同时发生了显化、行为与效应。IntentAct = 1；后果的出现不改变作用的成立，也不改变它的强度。

十、形式层推论与条件账本

1\. 形式层推论

定理三以对象层的 N\_IAct 为出发点，不经过《意向作用数理式》的形式回读，所以主定理不继承 H\_LawRead。

如果以形式读数为出发点：

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{N\_IAct}^M = 1 ⇒ N\_IAct = 1　［《意向作用数理式》定理 6；只沿 A2 正向回读实际使用的 Law-bearing 见证传播 H\_LawRead(W\_i)］  
&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct ⇒ IntentAct\_{F,t}(ξ\_t)　［定理三，没有附加条件］

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{N\_IAct}^M = 1 ⇒ IntentAct\_{F,t}(ξ\_t) = 1　［所用 Law-bearing 见证适用的 H\_LawRead(W\_i) 的合取］

2\. 条件账本

十一、击穿

直接击穿主定理的情形是：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct = 1 ∧ IntentAct = 0

按发生的层次分为以下几类。任何一类出现，都必须重新审查：

击穿一　语义域遗漏：冻结作用语义域之外，存在已属当前理论、且直接决定 IntentAct 真值的语句，不能归入 U\_IAct^+ 或 U\_IAct^O。

击穿二　第五职责反例：存在一个有冻结语料依据的单原子或不可约合取，在 A1 至 A4 同见证成立时，仍是 IntentAct 的普遍额外取得条件。

击穿三　实现映射失败：N\_IAct = 1，而 u31、u32、u33 中至少有一项实际上没有实现，说明第七节的映射有误。

击穿四　反充分世界：存在合法的 w，N\_IAct(w) = 1 而 IntentAct(w) = 0。

击穿五　独立取消反例：存在 X，A1 至 A4 与共同见证全部保持，X 仍独立使 IntentAct = 0，而且 X 有冻结语料的授权。

以下错误写法也击穿本篇：把 N\_IAct 拆成四个独立的存在式，允许跨事件拼接；把 u32 完全归给 A2、A3、A4 中的任一单项，丢掉“先决、择门、使役”的联合含义；把 u33 完全归给 A2，丢掉 A1 对“源动驱动”的承担；把欲门切换、显化、意识到、调谐成功、经验改变、行为或效应升格为 IntentAct 的普遍取得条件；以 Read\_{N\_IAct}^M = 1 直接充当主证明的前件，而不经《意向作用数理式》回读到对象层的 N\_IAct；把 H\_PAct-Rep 加入本篇的主充分方向；把作用链的条数当作意向的计数；另立“作用单元完整”为第五项职责或独立的充分前件。

以下情形不构成击穿：

Read\_{N\_IAct}^M = ⊥：这只是形式材料不足。

没有欲门切换、没有显化、没有意识到、没有外部行为、调谐结果被抵消、没有形成注意、没有默想：这些不属于作用的取得条件。

某些正式维当前率为零，单次路线确定，外界刺激参与诱发，同一单元内有多条完整作用链：这些都不取消作用。

满足 A1 至 A4 中的一部分而 N\_IAct 不成立的世界：它们不落入主定理的前件。

十二、接口

《意向作用一般式》：本篇使用其 N\_IAct、A1 至 A4、R1 至 R4、共同见证纪律、当前完整作用单元的含义与作用语义的冻结范围；其必要方向与其中的闭合检查只作一致性回测，不承重主证明。两篇合成 IntentAct ⇔ N\_IAct。

《意向作用数理式》：Read\_{N\_IAct}^M 与正向回读只作形式入口；经该篇定理 6 与本篇定理三，Read\_{N\_IAct}^M = 1 ⇒ IntentAct = 1，携所用见证的 H\_LawRead(W\_i)。
