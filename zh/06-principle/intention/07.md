# 意向欲门切换一般式

本篇试论一个总命题：

意向已经成立，并且在它的一个切换比较序列上确实发生了意向欲门切换，这一事实一定意味着：这一序列的前态中，有一次现实的过门，经过的是欲门职责类 \[G\_a\]；后态中，意向自身的源动续行现实发生，概率组织在同一次续行中承担了诸方向之间的相对生成，由此形成的方向进入欲门职责类 \[G\_b\]；\[G\_a\] 在这一序列的后态中退出了过门承担；并且这一退出与 \[G\_b\] 的取得同属后态那一次续行所承担的门交接，不是由另一独立机制单独承担的。

这引出的问题是：

意向已经成立时，什么时候才能说意向的欲门发生了切换？过了一个门，算不算切换？前后过了两个门，算不算？门态被外部改到另一个门，算不算意向的切换？旧门恰好退出、新门恰好由意向取得，又算什么？

需要预先说明本篇对这一问的回答程度。本篇只证必要方向，即意向欲门切换发生，就必然有某种结构；不证这种结构足以使意向欲门切换发生，充分方向由《意向欲门切换必然式》承担。本篇不重新证明意向资格与意向作用；切换怎样开始、进行、竞争、失败、恢复与持续，只留接口，交意向动力三篇。

我们要在本篇，在不断追问下找到证明应当走向何处，并推导意向欲门切换的一般式。

我们的目标是：

说明意向欲门切换与一般的门位切换、与当前过门、与并用、与外部强制换门的区别；得到意向欲门切换的最小必要结构，并使其中各项互不吸收；说明前后两端为什么必须属于同一比较序列，而这一绑定又为什么不是另一项职责；并给出最小性论证、两种诱发机制、边界与击穿路径。

先给出结果。

意向欲门切换必要结构式

在 Intent\_{F,t} = 1 的工作域内：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]

其中：

S1　前门真实通过（PriorGatePass）：前态见证 w\_a 上，有一次现实合法的过门，经过正式欲门职责类 \[G\_a\]；在序列 σ 上，Pass\_σ^-(\[G\_a\]) = 1。

S2　意向自身当前过后门（IntentDrivenCurrentGatePass）：后态见证 w\_b 上，A1(w\_b) ∧ A2(w\_b) ∧ A3(w\_b, \[G\_b\])，即意向自身的源动续行现实发生并进入 𝒫\_I，概率组织在同一次续行中承担诸方向之间的相对生成，由此形成的正式方向沿正式对应进入 \[G\_b\]；在序列 σ 上，Pass\_σ^+(\[G\_b\]) = 1。

S3　前门退出（PriorGateExit）：Pass\_σ^+(\[G\_a\]) = 0，即 \[G\_a\] 在 σ 的后态中不再承担过门。这只是这一序列上的局部退出，不是全系统失活。

S4　交接承担（HandoffBear）：HandoffBear(w\_b; σ, \[G\_a\]) = 1，即 σ 后态中 \[G\_a\] 的承担状态与 \[G\_b\] 的取得，同属 w\_b 上的同一次现实门承担事件；\[G\_a\] 的后态承担状态不由另一独立机制单独承担。

B\_same^IGS 是共绑定纪律：前后两端同锚、有序、属于同一比较序列、不跨资格组织拼接。它是见证的良构绑定，不是第五项职责。

门职责身份不同不是一项独立职责，而是推论：S2 ∧ S3 ⇒ \[G\_a\] ≠ \[G\_b\]。

N\_IGS(σ) 是固定比较序列 σ 上的必要核：S1 至 S4 与 B\_same^IGS 中出现的 σ，都是前件中的同一条 σ，不再重新量化。若要说至少有一条比较序列具有必要核，另记 N\_IGS := ∃σ N\_IGS(σ)；主定理与各篇的接口都用 N\_IGS(σ)。

上式在篇首只作结果预告，不作后文推导的前提。

一句话

意向的欲门切换，不是过了一个门，也不是看见门从一个变成了另一个：它是在同一条序列上，前态走过一个门，后态由意向自身的源动经由概率走进另一个门，而旧门的退出与新门的取得同属这一次续行所承担的门交接。

摘要

本篇回答：意向已经成立时，意向欲门切换发生，最低必须有什么结构。

先分开两件事。一般的门位切换，只说门从一个变成了另一个，它可以由外部强制、普通门控或其他机制造成；意向欲门切换是其中由意向自身做出的那一类。本篇研究的是后者。

从当前过门出发追问。只有当前通过某一欲门，可能是第一次进入，没有“从哪里切来”，所以要求前态有一次真实的过门。有了前门，后门却是外部选择器或普通门控直接改出来的，意向自身的源动与概率并没有承担后门的续行，这不是意向的切换，所以要求后门由意向自身的源动、概率与方向在同一见证上取得。后门由意向自身取得，而旧门在后态仍承担过门，这是同门继续或并用新增，门没有被换掉，所以要求旧门在这一序列的后态中退出；前后两门的职责身份不同由此推出，不必另立。旧门退出、新门也由意向自身取得，但旧门的退出恰好由另一外部机制单独承担，两件事只是巧合，所以要求旧门的后态承担状态与新门的取得同属后态的同一次现实门承担事件。前后两端必须属于同一比较序列，不能从不同组织、不同序列拼接；这一绑定是良构纪律，不是第五项职责。

四项各有一个只缺它的世界，互不吸收，都不能删除。门后的调谐使役、显化、意识到、调谐结果、行为与效应，都不进入必要核。切换的诱发有两种机制，源动直接切换与显式重入诱发切换，二者都汇入同一条意向自身的源动、概率与方向链。在本篇的冻结语义域上，没有第五项独立职责，也没有独立的取消条件。本篇只证必要方向，不携带新增 H。

引

我们说“我原来在看，后来转去听”。这里有两件不同的事：一件是此刻有一个欲门被通过，另一件是门从“看”换到了“听”。前一件，《意向作用一般式》已经作为意向作用的第三层讨论过：方向进入它对应的欲门。后一件才是本篇的问题。

母书说：“各有其经验可以并用，亦可切换，使之者，意图也。”经验可以同时并用，也可以前后切换，二者都由意图使役。所以，切换必须与并用分得开；并且，本篇所说的切换要由意向自身来使，不能是别的什么替它换了门。母书又说，切换欲门的过程本身没有自显性，切换到某个欲门以后，欲门之后的组织中有显性回路参与，才发生显化。所以切换在显化之前，也在意识到之前。

由此产生的问题是：过了一个门是不是切换？前后过了两个门是不是切换？门态被外部改到另一个门，是不是意向的切换？旧门恰好退出、新门恰好由意向取得，又是什么？

本篇不讨论意向资格与意向作用本身是否成立，不建立切换怎样开始、竞争、失败、恢复与持续的动力过程，也不讨论怎样从外部观测判定切换。这些问题分属本组式其他各篇。

先行之辨

一、工作域与对象

本篇的工作域是 Intent\_{F,t} = 1：研究的是已经成立的意向内部，前后现实过门之间的门承担改变。σ 是一次欲门切换的比较序列，即被申报比较的前后过门关系；它不是一个抽象的宿体、槽位或实体。前后两端的见证分别记为 w\_a、w\_b。Pass\_σ^-(\[G\])、Pass\_σ^+(\[G\]) 分别读 σ 的前态、后态是否由欲门职责类 \[G\] 承担过门。

本篇不要求入口处已有完整的意向作用。完整的意向作用需要门后的调谐使役（A4），而欲门切换属于过门这一层的门位变化；《意向作用一般式》已把当前过门交给欲门切换三篇；到门而止不是完整的意向作用，但“门已经实际通过”这一事实仍然成立。

二、门位切换与意向欲门切换

《意向作用一般式》已经说明：门的状态可以被外部强制、普通门控或其他机制改变，而没有走意向的职责链，所以 IntentAct ⇏ GateSwitch，GateSwitch ⇏ IntentAct。那里的 GateSwitch 是一般的门位切换事实：σ 上门从一个职责类变成了另一个，不问是谁做的。

本篇研究的不是这一般的事实，而是其中由意向自身做出的那一类，记为 IntentGateSwitch\_F(σ)。二者的关系是：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch ⇒ GateSwitch，　GateSwitch ⇏ IntentGateSwitch

外部强制换门的世界是 GateSwitch = 1、IntentGateSwitch = 0。《意向作用一般式》的判定在本篇完整保留；本篇的主定理只对 IntentGateSwitch 说话。

三、当前过门与欲门切换

当前过门（CurrentGatePass）只说此刻真实通过某一欲门，不说门位发生了变化。上一次作用 v\_a ⇝ G\_a，这一次作用仍是 v\_a ⇝ G\_a，两次都过了门，却没有切换。所以：

&nbsp;&nbsp;&nbsp;&nbsp;CurrentGatePass ≠ IntentGateSwitch

四、欲门按职责计

欲门按职责身份计，不按物理节点计。一个欲门职责可以由多个物理节点共同承担，一个物理载体也可以在不同状态下承担不同的欲门职责。所以判断前后两门是否不同，比较的是欲门职责类 \[G\]，不是物理节点。

五、并用与切换

经验可以并用，也可以切换。两个不同的欲门同时或先后被通过，可能是两条作用链的并用，也可能是新门的新增，也可能是同一序列上的切换。只看到两个不同的门，不足以说发生了切换。

六、外部诱发与外部强制

外界条件可以触发、扰动或改变场态，从而诱发意向自身的续行改向；这是合法的。外部选择器或普通门控直接把门态改到另一个门，意向自身的源动与概率并没有承担这次后门的续行，这是外部强制：它可以是一般的门位切换，但不是意向欲门切换。外部诱发不等于外部承担。

七、切换与显化、意识

切换欲门的过程本身没有自显性；切换到某个欲门以后，门后的组织中有显性回路参与，才发生显化；意向作用发生在意识到之前。所以切换可以已经发生，而还没有显化、还没有被意识到。

八、语料

本篇的冻结语义域为：

&nbsp;&nbsp;&nbsp;&nbsp;U\_IGS^src = { u21, u30, u48, u49, u50 }

原子的编号与拆分沿用《意向一般式》附录四。页码为《自显论》v0.7.1 的 PDF 页序。

u21　让经验并用或切换的是意图。u30　经验可以并用，也可以切换。二者出自 Q3：“各有其经验可以并用，亦可切换，使之者，意图也。”（第 53 页）  
u48　切换欲门的过程本身没有自显性。u49　切换到某个欲门以后，欲门后的组织中有显性回路参与，才发生显化。u50　意向作用发生在意识到之前。三者出自 I9：“切换欲门的过程本身没有自显性，而是切换到某欲门后，欲门后的组织中有显性回路的参与才发生了显化作用……所以意向作用发生在意识到之前。”

u21 在《意向一般式》中属于资格。进入欲门切换这一专门任务以后，它约束的是这一次切换的归属：经验的并用与切换，使之者须归于意向自身。所以它不能只由工作域 Intent = 1 代替，而要落实到这一次切换的当前结构上。

语义域申明：本篇关于意向欲门切换最低必要结构的结论，只在上述冻结语义与上游已封版的结构上取得。若母本以后新增直接决定意向欲门切换真值的语句，本篇须复审。这一限定是证明域的限定，不是 H。

九、上游承继

本篇承继《意向一般式》：概率维与欲门的区分 v\_i ≠ G\_i、v\_i ⇝ G\_i；欲门是方向在结构上的门位，欲门之后才是调谐一侧。

本篇承继《意向数理式》：欲门按职责身份计，GateRoleID 与欲门职责商类；同一物理载体可在不同状态承担不同的欲门职责，多个物理实现可共同承担同一欲门职责。

本篇承继《意向作用一般式》：A1（源动职责当前发生）、A2（概率职责当前兑现）、A3（对应欲门当前通过）、A4（调谐使役当前兑现）；当前过门不等于欲门切换；IntentAct ⇏ GateSwitch，GateSwitch ⇏ IntentAct；欲门切换三篇接收当前过门，研究上一门是什么、当前门是否不同，是否发生了一次欲门切换；门从 G\_a 到 G\_b 怎样开始、完成、竞争、失败、恢复与持续，只留形式接口，交意向动力三篇。

本篇承继《意向作用数理式》与《意向作用必然式》：A3 的形式表示不推出欲门切换；多条完整作用链可以同时存在；同门连续作用合法；没有欲门切换不取消意向作用；u48 至 u50 不属于作用的取得条件，u30 与 u48 的专门意义由欲门切换三篇承接。

论证流

我们采用不断追问的方式，一步一步来，因此会形成论证流，需要大家从上往下看。

一、过了一个门，是否已经是切换

先从最弱的情形问起。此刻有一次现实的过门，经过欲门 \[G\_b\]。

W-GS1　当前通过 \[G\_b\]，此前在这一序列上没有任何过门；\[G\_b\] 是第一次被通过。

W-GS1 中有过门，却没有“从哪里切来”。切换说的是门从一个变成另一个；只有一个门，谈不上换。所以只有当前过门，不能说发生了切换。缺的是：这一序列的前态中有一次真实的过门。由此取得第一项：

&nbsp;&nbsp;&nbsp;&nbsp;S1 := PriorGatePass：前态见证 w\_a 上，有一次现实合法的过门，经过正式欲门职责类 \[G\_a\]；Pass\_σ^-(\[G\_a\]) = 1。

S1 要求的是现实的过门，不是历史标签、观察者的标注或静态的可达关系。它不要求前态有完整的意向作用，不要求前态的 A4，也不要求前门在整个系统中唯一。

S1 也不要求追溯证明 \[G\_a\] 当初是由意向自身的源动与概率取得的。S1 的任务只是给这一次切换提供真实的前态参照；“这一次切换由谁做”由后态承担（第二、四步）。如果强制追溯旧门的历史来源，就会排除一种合法的情形：\[G\_a\] 已经是同一意向门体系中的真实前态，随后意向自身的新续行确实从这一前态改向 \[G\_b\]。母书没有要求旧门的历史来源与这一次切换的当前来源相同。

二、有前门、后门另有一门，是否已经是切换

保持 S1：前态通过 \[G\_a\]。后态也有一次现实的过门，经过 \[G\_b\]。

W-GS2　同一意向资格组织中，前态通过 \[G\_a\]；随后外部完整选择器或普通强制门控直接把门态改到 \[G\_b\]，旧门随之退出，组织只是执行了这一结果；意向自身的源动没有在后态续行，概率组织也没有在后态承担诸方向之间的相对生成。

W-GS2 中，门确实从 \[G\_a\] 变到了 \[G\_b\]，这是一次一般的门位切换。但母书说并用与切换“使之者，意图也”：意向的切换要由意向来使。W-GS2 的后门是外部替意向选定的，不是意向自身走进去的。这与《意向作用一般式》的判定一致：外部选择器直接决定落到哪一个欲门，跳过意向自身的源动续行和概率承担，不是意向在作用。所以 W-GS2 至多是 GateSwitch = 1，而 IntentGateSwitch = 0。

还要注意，只要求“后态有一次过门”也不够：过门这一层本身只说方向进入了门，不说这一次续行是不是意向自身的源动经由概率形成的。缺的是：后门由意向自身的源动续行、概率承担与方向在同一见证上取得。由此取得第二项：

&nbsp;&nbsp;&nbsp;&nbsp;S2 := IntentDrivenCurrentGatePass：后态见证 w\_b 上，A1(w\_b) ∧ A2(w\_b) ∧ A3(w\_b, \[G\_b\])；Pass\_σ^+(\[G\_b\]) = 1。

即：意向自身的源动职责在后态续行中现实发生并进入 𝒫\_I；同一次续行中，𝒫\_I 作为概率组织现实承担诸正式方向之间的相对生成；由此形成的正式方向沿正式对应进入 \[G\_b\]。w\_b 属于 σ 的后态由共绑定保证（第五步），所以这一次过门就是 σ 后态的过门。

S2 比普通的当前过门强：只有后门的过门不足，后门必须是意向自身经源动、概率、方向这一条链现实取得的。外界刺激可以诱发 S2，只要后态的实际承担仍由 A1、A2、A3 完成。S2 不要求 A4，不要求调谐成功，不要求显化或意识到。

前后两端在这里不对称：S1 不追溯前门的来源，S2 要求后门由意向自身取得。理由已在第一步说明：前门只是参照，后门承担的是“这一次切换由谁做”。

三、有前门、后门由意向自身取得，是否已经是切换

保持 S1、S2：前态通过 \[G\_a\]，后态由意向自身的 A1、A2、A3 走进 \[G\_b\]。

W-GS3　前态通过 \[G\_a\]，后态由意向自身的续行再次走进 \[G\_a\]，即 \[G\_b\] 与 \[G\_a\] 是同一职责类。

W-GS3 是同门继续，或者同一欲门的重复通过。

W-GS3-B　前态通过 \[G\_a\]；后态中意向自身新取得了 \[G\_b\] 的过门，而 \[G\_a\] 在这一序列的后态中仍承担过门。

W-GS3-B 是并用或新增：新门加了进来，旧门并没有让出。

两个世界的共同之处是：旧门在这一序列的后态中仍承担过门。门没有被换掉，谈不上切换。缺的是：旧门在后态退出。由此取得第三项：

&nbsp;&nbsp;&nbsp;&nbsp;S3 := PriorGateExit：Pass\_σ^+(\[G\_a\]) = 0。

S3 只要求 \[G\_a\] 从这一序列的后态承担中退出，不要求 \[G\_a\] 在整个系统、在其他并用链或其他职责中全局失活。

推论：前后两门的职责身份不同。

&nbsp;&nbsp;&nbsp;&nbsp;S2 ∧ S3 ⇒ \[G\_a\] ≠ \[G\_b\]

因为 S2 给出 Pass\_σ^+(\[G\_b\]) = 1，S3 给出 Pass\_σ^+(\[G\_a\]) = 0；若 \[G\_a\] 与 \[G\_b\] 是同一职责类，同一职责在同一后态上既承担又不承担，矛盾。所以门职责身份不同不是一项额外职责，而是换门结构自身推出的结果。

比较的是欲门职责类，不是物理节点。所以：同一欲门职责前后由不同的物理节点实现，前后仍是同一职责类，它在后态仍承担过门，S3 不成立，不是切换；同一物理载体前态承担 \[G\_a\]、后态承担 \[G\_b\]，职责类不同，可以是切换。

四、旧门退出、新门由意向自身取得，是否已经是切换

保持 S1、S2、S3：前态通过 \[G\_a\]，\[G\_a\] 在后态退出，后态由意向自身的 A1、A2、A3 走进 \[G\_b\]。

W-GS4　意向自身走向 \[G\_b\] 的同时，\[G\_a\] 在这一序列上的退出，恰好由另一个外部机制单独承担，与意向这一次续行不属同一事件。两件事只是在时间上巧合。

W-GS4 中，旧门确实退出了，新门也确实由意向自身取得了，但旧门的退出与新门的取得不是同一件事：旧门的让出由另一机制承担，不属于意向这一次续行所承担的事件。这不是意向从 \[G\_a\] 切到 \[G\_b\]，只是意向在旧门恰好空出时走进了新门。

所以 W-GS4 不是意向欲门切换。缺的是：旧门的后态承担状态与新门的取得，同属后态的同一次现实门承担事件。由此取得第四项：

&nbsp;&nbsp;&nbsp;&nbsp;S4 := HandoffBear：HandoffBear(w\_b; σ, \[G\_a\]) = 1，即 σ 后态中 \[G\_a\] 的承担状态与 \[G\_b\] 的取得，同属 w\_b 上的同一次现实门承担事件；\[G\_a\] 的后态承担状态不由另一独立机制单独承担。

S4 读的只是一种归属关系，它不重复其他各项的内容：

S4 不说前态有没有经过 \[G\_a\]，那是 S1；  
S4 不说旧门是否已经退出，那是 S3；  
S4 不说 w\_b 上这一事件是不是意向自身的续行、是否经源动与概率进入 \[G\_b\]，那是 S2；  
S4 只说：σ 后态中旧门的承担状态与新门的取得，是不是 w\_b 上同一次门承担事件的两面。

所以 S4 不用“替代”“切换”作定义词，也不是“已经发生切换”的改名，不循环。

这一归属是现实承担的归属，不是反事实的因果依赖。它不断言“没有 w\_b 上这一事件，\[G\_a\] 就不会退出”，只断言：在现实后态中，旧门的承担状态与新门的取得属于同一次门承担事件，而不是分别由互不相干的机制承担。上游已建立的是同链、同见证、非外部完整承担这一类归属纪律，S4 只用这一类纪律，不新增因果语义。

四项合起来，才说出了意向欲门切换的完整意思：S3 与 S4 合起来，旧门的退出与新门的取得同属 w\_b 上的同一次门承担事件；S2 说这一事件正是意向自身的源动经由概率进入 \[G\_b\] 的续行。于是旧门的退出与新门的取得，都由意向自身的同一次续行承担。

五、前后两端能否从不同的序列拼接

S1 至 S4 都已取得。问：前后两端是否可以取自不相干的地方？

W-拼　w\_a 属于作用序列甲，w\_b 属于作用序列乙，甲、乙彼此独立；甚至在全局上看见旧门某处退出、新门某处进入。或者，w\_a 属于资格组织 X，w\_b 属于资格组织 Y。

W-拼 中各项可能分别为真，但这些事实不是同一次切换的事实。所以前后两端必须绑定在同一比较序列上。记这一绑定为 B\_same^IGS，它的最低内容是：

B1 同锚：w\_a 与 w\_b 锚定于同一意向资格锚 K\_I。  
B2 有序：在事前冻结的协议下，w\_a 真实地先于 w\_b；不能把两个共时无序的事件任意排出先后。  
B3 序列归属：前后两端按事件谱系、控制谱系、作用记录或其他事前冻结的身份资料，判为同一门变化序列 σ 的前后状态；不能以“最后看见门不同”反过来定义同一序列。  
B4 不跨资格组织：不能把组织 X 的 \[G\_a\] 与组织 Y 的 \[G\_b\] 拼成一次切换。

判断依据的协议记为 Γ\_IGS，在比较以前冻结：什么算同一资格锚，GateRoleID，什么算前事件、后事件，什么算同一门变化序列，怎样区分独立的并用支路与同一序列的前后状态。看完结果以后，这些都不得改动。

B\_same^IGS 回答的是：这些事实是不是同一次申报事件的事实。它不回答“意向欲门切换还需要一种什么职责”。所以它是见证的良构绑定纪律，与意向作用中的共同见证、意向资格中的共锚同类，不是第五项职责。它也不创造“切换槽位”之类的持久实体，只规定两个现实的作用单元能否被放进同一个 σ 中比较。

六、四项能否删除

四项各有一个只缺它、其余三项都成立的世界：

删去 S1：W-GS1。后态由意向自身走进 \[G\_b\]，S2 成立；σ 上本没有 \[G\_a\] 的承担，S3、S4 只是空洞地成立，没有任何退出需要另行承担；但前态没有过门，没有“从哪里切来”。缺 S1 的世界只能是这种空洞的样子，这正说明 S1 承担的是“有前态可切”这一独立内容，不被其余三项给出。

删去 S2：W-GS2。前态通过 \[G\_a\]，\[G\_a\] 在后态退出，而且这一退出与 \[G\_b\] 的取得同属 w\_b 上那一次外部执行所承担的事件，S1、S3、S4 都成立；但后门是外部强制改出来的，意向自身没有 A1、A2、A3 的现实承担。这是一般的门位切换，不是意向欲门切换。

删去 S3：W-GS3。前态通过 \[G\_a\]，后态由意向自身的续行再次走进 \[G\_a\]，\[G\_a\] 的后态承担状态正由这一次续行承担，S1、S2、S4 都成立；但旧门没有退出，是同门继续。W-GS3-B 同样缺 S3：旧门在后态仍承担，是并用或新增；它的旧门多由自己的链继续承担，往往同时缺 S4，所以只作补充例，只缺 S3 的反例以 W-GS3 为准。

删去 S4：W-GS4。S1、S2、S3 都成立，但旧门的退出由另一外部机制单独承担，与意向这一次续行只是巧合。

删去 B\_same^IGS：各项事实可以从不同的资格锚、不同的作用序列拼接，失去事件的同一性（W-拼）。B\_same^IGS 不能删，但它是良构纪律，不是第五项职责。

每一项都有一个只缺它的反例，所以没有哪一项被其他项吸收，四项都不能删。前后两门职责不同已作为推论取得，不再单独计数。

七、门后的调谐使役、显化与意识是否进入必要核

问：意向欲门切换是否要求后态那一次作用已经进入门后的调谐使役？

W-GS5　后门 \[G\_b\] 已经由意向自身真实通过，S1 至 S4 与 B\_same^IGS 都成立；但这一次作用随后止于门处，没有进入门后的调谐使役，A4(w\_b) = 0。

W-GS5 中，门已经换了。母书说“切换到某欲门以后，欲门后的组织中有显性回路的参与才发生了显化”：“切到欲门”在门后发生什么之前就已经成立。《意向作用一般式》也允许 A3 = 1 而 A4 = 0：这是到门而止的合法作用前缀，不是完整的意向作用，但过门已经成立。所以 W-GS5 是意向欲门切换，只是这一次作用不完整。A4 不进入 N\_IGS(σ)：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch ⇏ A4

同理，切换过程本身没有自显性，作用发生在意识到之前：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch ⇏ Manifestation，IntentGateSwitch ⇏ Awareness，IntentGateSwitch ⇏ TuneSuccess，IntentGateSwitch ⇏ ExperienceChanged，IntentGateSwitch ⇏ 行为或效应

八、并用、局部切换与物理实现

同门继续：前态 \[G\_a\]，后态仍 \[G\_a\]，S3 = 0，不是切换。

并用或新增：原有 w\_a 通过 \[G\_a\]，另有 w\_b 通过 \[G\_b\]。若二者在同一 σ 上而 \[G\_a\] 在后态仍承担，S3 = 0；若 \[G\_b\] 属于另一独立序列，B\_same^IGS = 0。即使 \[G\_a\] ≠ \[G\_b\]，也不是切换。

局部切换：在某一合法的 σ 中，前态 Pass\_σ^-(\[G\_a\]) = 1，后态 Pass\_σ^+(\[G\_a\]) = 0、Pass\_σ^+(\[G\_b\]) = 1，后门由意向自身取得，旧门的退出与新门的取得同属这一次续行所承担的门交接；同时系统别处仍有 \[G\_a\] 的另一条合法作用链。这仍是 σ 上的意向欲门切换：

&nbsp;&nbsp;&nbsp;&nbsp;局部切换 ≠ 旧门全局失活

全局门改变：若所有相关支路上 \[G\_a\] 都退出，只剩 \[G\_b\]，这是意向欲门切换的一种特殊的强情形，不是一般的必要条件。

物理重实现：前后物理节点从 g\_1 换成 g\_2，而 GateRoleID 相同，旧门的职责在后态仍承担，S3 = 0，不是切换。同一物理载体前态承担 \[G\_a\]、后态承担 \[G\_b\]，职责类不同；其余各项成立时，可以是切换。

九、有没有第五项职责，有没有独立的取消条件

保持 S1 至 S4 与 B\_same^IGS 成立。问：冻结语义域中是否还有不能归入这四项与绑定的第五项必要职责？

u21 与 u30 同属 Q3。二者合起来给出两层要求：一是并用与切换必须分得开；二是这一次门改变必须由意向自身来使，不能只因为 Intent = 1 而门态变了就归给意向。第一层由 S3 与 B\_same^IGS 承担；第二层由 S2 的同见证 A1、A2、A3 与 S4 的交接承担共同实现。Q3 没有另外要求显化、意识、门后的调谐使役、唯一的门、概率值的比较或旧门的全局消失。

u48、u49、u50 同属 I9。它们的逻辑方向是分层：切换过程与显化不同；到门以后，门后的显性回路参与才可发生显化；作用发生在意识到之前。这组合取的作用是把切换与显化、意识分开，不是给切换加条件。

u30 与 u48 至 u50 的跨组合：“可并用、可切换”加上“切换本身不显”，只说明切换是一种可由意向产生、与显化分层的门变化，没有新的取得职责。

与上游“概率维与欲门的对应”的组合：欲门职责类与正式方向一一对应，保证 S1、S2 中的过门是正式的门事件；它不额外要求比较概率数值、当前最大率、当前唯一方向或唯一的过门。

与 A4 的组合：A3 与 A4 合起来是完整意向作用的后两层，但意向欲门切换的真值不需要它；加入 A4 会错误排除换门后止于门处的世界（W-GS5）。

所以，在冻结语义域 U\_IGS^src 与现行上游边界内：

&nbsp;&nbsp;&nbsp;&nbsp;FifthIndependentIGSDuty\_I = ∅

再问：S1 至 S4 与 B\_same^IGS 都成立时，是否还有独立的因素能单独使切换不成立？逐项审查：没有 A4、调谐没有成功、经验没有改变、没有显化、没有意识到、没有行为或效应，都不取消；外界刺激参与诱发，只要后门仍由意向自身的 A1、A2、A3 取得、旧门的退出仍与新门的取得同属这一次续行所承担的门交接，不取消；系统中另有并用链、旧门在其他链上仍活动，不取消这一 σ 上的局部切换；前后之间有时间空档，母书没有要求无缝切换，只要序列绑定仍然合法，不取消；前后有一段短暂重叠，只要最终后态中 S3 成立，重叠本身不取消，具体的竞争过程交意向动力各篇；概率值读不出，这是表示问题，不取消；旧门的率值没有降为零，过门的事实与概率率值不是同一对象，不取消；新门不是“最大率”的门，系统中没有读取最大值的选择者，不取消。所以，在冻结语义域内：

&nbsp;&nbsp;&nbsp;&nbsp;IndependentCancel\_IGS = ∅

这两项检查只是一般式的闭合检查，说明必要结构在冻结语义域中没有遗漏。它们不证明 N\_IGS(σ) ⇒ IntentGateSwitch\_F(σ)；充分方向必须由《意向欲门切换必然式》独立证明。

十、总式与主定理

意向欲门切换必要核：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]

σ 是固定的比较序列，S1 至 S4 与 B\_same^IGS 都在这同一条 σ 上读取。其中 S1 = PriorGatePass，S2 = IntentDrivenCurrentGatePass，S3 = PriorGateExit，S4 = HandoffBear；B\_same^IGS 是共绑定纪律，不计作第五项职责。门职责身份不同是推论 S2 ∧ S3 ⇒ \[G\_a\] ≠ \[G\_b\]，不计作职责。

主定理（意向欲门切换必要结构定理）。在本篇的冻结语义域内，设 Intent\_{F,t} = 1。如果在比较序列 σ 上发生了意向欲门切换，那么：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)

证明。设 IntentGateSwitch\_F(σ) = 1。

切换说的是门从一个变成另一个；W-GS1 表明没有前态过门就没有“从哪里切来”（第一步）。所以前态见证 w\_a 上有一次现实的过门，经过 \[G\_a\]，即 S1 成立。

由 Q3 的“使之者，意图也”，意向欲门切换由意向来使；W-GS2 表明外部强制改出的后门只是一般的门位切换，不是意向的切换（第二步）。所以后态见证 w\_b 上，意向自身的源动续行、概率承担与方向进入 \[G\_b\] 同见证成立，即 S2 成立。

由 Q3 的“可以并用，亦可切换”，切换与并用分得开；W-GS3 与 W-GS3-B 表明，旧门在后态仍承担过门，是同门继续或并用新增，门没有被换掉（第三步）。所以 \[G\_a\] 在 σ 的后态中退出，即 S3 成立。

再由 Q3 的“使之者，意图也”，切换作为一件事由意向来使，旧门的让出也在这件事之内；W-GS4 表明旧门的退出若由另一外部机制单独承担，新门的取得与它只是巧合（第四步）。所以 σ 后态中 \[G\_a\] 的承担状态与 \[G\_b\] 的取得同属 w\_b 上的同一次现实门承担事件，即 S4 成立。

由 W-拼，前后两端必须同锚、有序、属于同一序列、不跨资格组织（第五步）。所以 B\_same^IGS 成立。

合起来，在前件所固定的同一比较序列 σ 上，存在 w\_a、w\_b、\[G\_a\]、\[G\_b\]，使 S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS 成立，即 N\_IGS(σ)。

删除检验见第六步；门后调谐使役、显化与意识的排除见第七步；第五项职责与取消条件的检查见第九步。证毕。

本定理是必要方向，不证明其逆命题 N\_IGS(σ) ⇒ IntentGateSwitch\_F(σ)。本篇也不以定义 IntentGateSwitch\_F(σ) := N\_IGS(σ) 取得定理。本定理不对一般的 GateSwitch 说话：外部强制换门可以是 GateSwitch = 1，而 N\_IGS(σ) 不成立，这与本定理不冲突。

两种切换诱发机制

意向欲门切换可以由两种机制诱发。它们不是两套切换的定义，也不新增职责；二者的差别在 A1 之前，即诱发来源一侧，进入必要核以后共享同一组 S2、S3 与 S4。

直接源动切换。当前的场态、既成的沉积关系或合法的环境扰动，改变了意向概率组织现实承担的相对生成。随后，意向自身的新源动续行现实发生（A1）；同一个概率化律生态承担新的相对生成（A2）；现实方向进入新的对应欲门 \[G\_b\]（A3）；旧门在这一序列后态的退出与新门的取得同属这一次内部续行所承担的门交接（S3、S4）。环境扰动可以诱发，但不能充当外部选择器直接指定 \[G\_b\]；只要方向与门仍由意向自身的链承担，就是意向的切换。

显式重入诱发切换。默想、思考、内观、回顾，或者已经显化的经验，经合法回路返回，改变意向当前的动力状态。随后仍必须：新的源动续行发生在意向自身（A1）；仍经过同一个概率化律生态重新形成相对生成（A2）；进入新的正式对应欲门 \[G\_b\]（A3）；旧门的退出与新门的取得同属这一次内部续行所承担的门交接（S3、S4）。显式重入只是诱发或调制的前件，不是一个观察者读出概率值以后手工选定 \[G\_b\]；它不得绕过 A1、A2 直接指定后门。

有没有默想、思考回路参与，不决定切换是否成立，只决定这一次切换怎样被诱发。重入怎样启动一次切换、切换怎样进行，属于意向动力三篇。

击穿论证

K-GS1：存在合法的意向欲门切换，但不存在前态的真实过门。

K-GS2：存在合法的意向欲门切换，但后门不是由意向自身在同一见证上的 A1、A2、A3 取得的。最小反例形态：后门由外部完整选择器直接指定，而这一情形仍应判为意向欲门切换，而不只是一般的门位切换。

K-GS5：存在合法的意向欲门切换，却无法在任何事前冻结、不含待证结论的 Γ\_IGS 下，把前后两端绑定为同一切换序列。这说明现行绑定结构过强或不完备。

K-GS6：两条独立的合法作用链分别通过 \[G\_a\]、\[G\_b\]，系统仍因门不同而判为意向欲门切换。这说明 S3 或 B\_same^IGS 没有排除并用。

K-GS7：把 A4、调谐成功、经验改变、显化、意识到中的任何一项作为意向欲门切换的必要条件。

K-GS8：只因物理节点改变就判为切换，或者同一物理载体换了 GateRoleID 却拒绝判为切换。

K-GS9：要求 \[G\_a\] 在整个系统中完全失活，从而把这一 σ 上已经换门、别处仍合法使用 \[G\_a\] 的世界判为失败。

K-GS10：要求读取率值、最大率、率值交叉或阈值，才承认切换。这违反意向不读取概率的上游纪律。

K-GS11：冻结语义域中出现有直接语料授权的独立必要职责 X：S1 至 S4 与 B\_same^IGS 全部成立时，X 不成立就使切换不成立，并且 X 不能归入现有四项、绑定、后果、动力或实现。

K-GS12：S1 至 S4 与 B\_same^IGS 全部成立，仍存在冻结语料授权的独立因素 X 使切换不成立。

K-GS13：能证明四项中某一项被其他项完全吸收，即不存在只缺它而其余三项都成立的世界，则四项的最小性被击穿。

下列情况不构成本篇的击穿：外部强制换门是 GateSwitch 而不是 IntentGateSwitch；换门以后作用止于门处；没有显化；没有意识到；没有调谐结果或行为；旧门在别处仍被使用；前后之间有时间空档；切换中有短暂重叠；读不出概率值；物理节点更换而职责不变时不判为切换；在同一固定比较序列 σ 上满足 N\_IGS(σ)，却没有 IntentGateSwitch\_F(σ) 的世界，这属于充分方向，由《意向欲门切换必然式》处理。

※※※

结语

本篇从当前过门出发，一路追问：过了一个门为什么还不是切换，门是外部改出来的为什么不是意向的切换，后门由意向取得而旧门在后态仍承担为什么不是，旧门恰好退出而新门由意向取得为什么仍不是，前后两端为什么不能拼接。每一步只处理上一步留下的缺口，四项结构随问题链逐步取得承重地位，各有只缺它的反例，并且落在同一条比较序列上；前后两门职责不同，由后门过门与旧门退出一起推出。

本篇结论压成两句话：

意向的欲门切换，是在同一条序列上，前态走过一个门，后态由意向自身的源动经由概率走进另一个门，而旧门的退出与新门的取得同属这一次续行所承担的门交接。

意向欲门切换不等于当前过门，不等于看见门变了，不等于并用，也不等于外部强制换门；它不要求门后已经使役调谐，不要求显化与意识，也不要求旧门在全系统消失。

三、分工

本篇回答 IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)。

《意向欲门切换数理式》：形式化本篇，入口为 χ\_IGS^M；至少形式化前后作用单元、GateRoleID、前门过门、意向自身的后门过门、前门退出、交接承担、门职责差异推论、共绑定、事件排序、覆盖、三值读数、并用排除、申报失格、绑定未决与前后过门的覆盖。形式化的对象是 N\_IGS(σ)。它不证明 N\_IGS(σ) ⇒ IntentGateSwitch\_F(σ)。
