# 意向欲门切换数理式

一、目的

为意向欲门切换的必要结构建立形式系统，使任一已经取得意向资格的申报实例，在一条固定申报的切换比较序列 σ 上，前门真实通过、意向自身当前过后门、前门退出、交接承担四项及其共绑定都可以形式求值，并得到成立（1）、不成立（0）或材料不足（⊥）的确定读数。其中，后门一项内部的概率职责兑现子层在“当前发生已经成立而职责兑现失败”这一支上取得的 0，在结构层上的否定强度携带反向表示条件 H\_PAct-Rep；其余各项的 0 不携带。

所形式化的结构是：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)  
&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]

S1 是前门真实通过，Pass\_σ^-(\[G\_a\]) = 1；S2 是意向自身当前过后门，A1(w\_b) ∧ A2(w\_b) ∧ A3(w\_b, \[G\_b\])，并且这一次过门属于 σ 的后态；S3 是前门退出，Pass\_σ^+(\[G\_a\]) = 0；S4 是交接承担，σ 后态中 \[G\_a\] 的承担状态与 \[G\_b\] 的取得同属 w\_b 上的同一次现实门承担事件；B\_same^IGS 是前后两端的共绑定纪律，不是第五项职责。四项互不吸收，并列成立；前后两门职责不同是推论，不是分量。

形式目标为：

&nbsp;&nbsp;&nbsp;&nbsp;S\_IGS ↦ M\_IGS

即：给出四项与共绑定的形式判据，在同一候选见证上并列求值；后门一项内部沿用意向作用的前三层递进；给出候选见证的枚举、负读出所需的覆盖、求解程序与三值回读规则。

二、核心论题

给定已经成立的意向资格及其申报实例，以及一条在求解以前冻结的比较序列 σ，怎样从前后评价域内的现实过门记录、后态意向作用前三层的候选前缀登记、后态各欲门职责类的承担状态记录、现实事件的身份键，以及前后两端的锚、顺序与序列身份资料中，求得“存在一个候选见证，在其上四项与共绑定都成立”的形式真值，并严格区分结构失败 0 与形式材料不足 ⊥？

M\_IGS 须精确表达：

（1）切换与过门的区分。A3^M = 1 只说本次作用经过了对应的欲门，不说门位发生了变化；GateRoleID 不同、旧门不在、新门取得，任一单项都不是切换。切换的读数只能由四项与共绑定合起来给出。

（2）四项各读各的对象。S1 只读前态一次现实合法的过门，不追溯它的源动与概率来源；S2 读后态由意向自身的源动、概率与方向取得的过门，并且这一过门落在 σ 的后态；S3 只读旧门在 σ 后态的承担状态；S4 只读后态记录的事件归属，不读谁的续行，不读旧门是否已经退出。四项各有独立的求值对象，所以在顶层并列求值，不排成递进。

（3）退出与没看见的区分。旧门退出必须在后态门承担的覆盖闭合以后才能读出；在后态没有找到旧门的记录，不等于旧门已经退出。

（4）事件归属与时间相邻的区分。S4 只用事前冻结的现实事件身份键判断后态两组相关记录是否都属于同一次事件；时间相邻、状态相关、结果相同都不能代替事件身份；S4 不作反事实、干预或因果测试。

（5）局部归属与跨前后绑定的区分。S4 是后态内部的事件归属；B\_same^IGS 是前态与后态之间的同锚、有序、同序列、同组织绑定。二者分别求值，不得合并。

（6）失败与不足的区分。没有找到正见证，不等于正见证不存在；负读出必须有覆盖。申报本身失格，只能要求重新申报，不能读成切换的结构失败。

须在形式上区分下列几组对象：

&nbsp;&nbsp;&nbsp;&nbsp;当前过门 ≠ 欲门切换  
&nbsp;&nbsp;&nbsp;&nbsp;一般的门位切换 ≠ 意向欲门切换  
&nbsp;&nbsp;&nbsp;&nbsp;旧门没被看见 ≠ 旧门已经退出  
&nbsp;&nbsp;&nbsp;&nbsp;时间相邻 ≠ 同一事件  
&nbsp;&nbsp;&nbsp;&nbsp;后态事件归属 ≠ 前后序列绑定  
&nbsp;&nbsp;&nbsp;&nbsp;结构见证 ≠ 形式见证

本系统表示的是意向欲门切换的必要结构，不证明它的充分方向。可以区分和计数的，是比较序列、事件、记录、路径段、欲门职责类与见证；同一条 σ 上可以有多个候选见证，不要求唯一的后门或唯一的切换候选。

2\. 定义序列

切换的求值对象，是已经取得意向资格的申报实例在一条比较序列上的前后两段现实运行。所以申报实例由资格实例加上比较序列构成；与切换有关的身份，例如哪一段算前态、哪一段算后态、哪些记录属于同一事件、哪些前后记录属于同一序列，都要在求解以前冻结，看到门的前后状态以后不得改写。

定义 1（切换求解实例）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;χ\_IGS^M := (χ\_I, σ^M, Γ\_IGS)

χ\_I 是已经建立的意向资格申报实例，其中含沉积场 F、资格锚 K\_I^M、正式方向族 V\_I、欲门职责商类 𝒢̄\_I 与 GateRoleID；σ^M 是被申报比较的一条切换序列（定义 2）；Γ\_IGS 是求解协议与身份冻结登记，至少冻结：资格锚与运行实例的身份协议，前后评价域的划分与顺序，GateRoleID 的版本，现实事件身份键的方案与允许使用的身份资料，序列归属的身份资料，候选枚举协议，覆盖协议，申报边界规则。Γ\_IGS 是求解协议，不是切换职责，不是本体谓词。

进入条件：Intent\_{F,t} = 1。本系统不重新求意向资格；若意向资格由上游形式读数取得，其回读条件保持上游原来的归属。

定义 2（比较序列登记）\[表\]

&nbsp;&nbsp;&nbsp;&nbsp;σ^M := (D\_σ^-, D\_σ^+, ≺\_σ)

D\_σ^- 是 σ 的前态评价域，D\_σ^+ 是 σ 的后态评价域，≺\_σ 是在 Γ\_IGS 中冻结的先后关系，D\_σ^- ≺\_σ D\_σ^+。≺\_σ 只说前态评价域整体先于后态评价域，不要求相邻，不要求无间隙；两者之间可以有空档，也可以有一段过渡。过渡段不属于 D\_σ^+，所以过渡中旧门与新门的短暂并存不进入 S3 的读数；后态评价域从哪里起算，由 Γ\_IGS 事前冻结，不得在看到门的状态以后移动。σ^M 不是宿体、槽位或实体，只是被申报比较的前后过门关系的登记。

一般式的必要核在固定 σ 上写作 N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ … \]，全局闭包另记 N\_IGS := ∃σ N\_IGS(σ)。一般式的证明对前件给定的那一条 σ 逐项取得 S1 至 B\_same^IGS，并以 B3 要求前后两端属于这同一条 σ。所以在一条固定申报的 σ 上，形式化的对象写为：

定义 3（固定序列的必要核）\[表\]

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]

一般式的 N\_IGS 即 ∃σ N\_IGS(σ)；一般式的主定理在固定 σ 上读为 IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)。对一条 σ 取得 N\_IGS(σ) = 0，只说这一条 σ 上没有必要核，不说其他比较序列上没有。

一般式中的见证，说的是同一次切换的四个方面：前态的一次现实过门，后态的一次意向作用前三层，前后两门的职责类，后态那一次现实事件。形式层把它展开为一个元组，把每一个方面落到可以读取的事件、记录、路径段与身份键上。

定义 4（结构见证）\[表\]　《意向欲门切换一般式》的见证组 (w\_a, w\_b, \[G\_a\], \[G\_b\]) 在结构层记为 w\_IGS^S。

定义 5（形式见证）\[表\]

&nbsp;&nbsp;&nbsp;&nbsp;w\_IGS^M := (w\_a^M, w\_b^M, \[G\_a\], \[G\_b\], κ\_b, Λ\_IGS^M)  
&nbsp;&nbsp;&nbsp;&nbsp;w\_a^M := (e\_a, Z\_a)  
&nbsp;&nbsp;&nbsp;&nbsp;w\_b^M := (e\_b, Π\_b^I, Z\_src, Z\_ρ, v\_b, Z\_G)

w\_a^M 是前态候选登记：e\_a 是前态评价域中被登记的一次事件，Z\_a 是这一事件中被登记的过门路径段。它只服务于 S1，不带源动、概率或方向的分量。w\_b^M 是后态候选前缀登记：e\_b、Π\_b^I、Z\_src、Z\_ρ、v\_b、Z\_G 与《意向作用数理式》形式见证 w\_I^M 的 e\_t、Π\_t^I、Z\_src、Z\_ρ、v\_i、Z\_G 同型，只取到过门一层，不含门后调谐职责 q\_i 与调谐进入段 Z\_T，也不以任何含 q\_i、Z\_T 的完整作用见证为前提。

两种登记都是候选登记，不是已经成立的见证。候选的生成在各项判定之前，不能由 S1 或 S2 的成立反过来定义候选。登记的各分量可以是合法的实际段，可以是明确不匹配的实际段，也可以缺失或未决：例如外部完整选择器直接把门态改到 \[G\_b\] 的世界里，后态登记有 e\_b 与进入 \[G\_b\] 的实际过门段 Z\_G，而 Z\_src 缺失或 Z\_ρ 不属于 𝒫\_I 的生成；这样的登记照样进入候选域，在 S2 上取得 0（记录完整时）或 ⊥（记录不完整时），而不是在枚举阶段消失。A1、A2、A3 各层失败的登记同样进入候选域。v\_b 为正式方向时，它的正式对应欲门记为 \[G\_b\]；v\_b 缺失时，\[G\_b\] 取 Z\_G 实际进入的欲门职责类。\[G\_a\]、\[G\_b\] 是前后两门的欲门职责类，按 𝒢̄\_I 计，不以单个物理节点计。κ\_b 是 e\_b 的现实事件身份键（定义 17）。Λ\_IGS^M 是比较键（定义 23）。

形式见证与结构见证的对应记为集合值映射 𝔉\_IGS：w\_IGS^M ∈ 𝔉\_IGS(w\_IGS^S) 表示 w\_IGS^M 是 w\_IGS^S 的一个合法形式登记。同一结构见证可以有多个合法形式登记，例如记录的登记粒度不同；不得由形式登记的个数推断切换的次数。下文的 w 在形式层均指形式见证。

S1 读的是前态有没有一次现实合法的过门，经过 \[G\_a\]。一般式规定 S1 不追溯前门当初是由什么取得的，所以 S1 不能用《意向作用数理式》的 A3^M 来读：A3^M 已经把过门绑定在 A2 那一次职责兑现形成的方向上，用它读前门，会把一般式允许的合法前态判为 ⊥ 或 0。S1 只读四件事：这是不是前态评价域中的现实事件；\[G\_a\] 是不是正式的欲门职责类；这一事件中有没有一段现实路径进入 \[G\_a\]；这一过门是否属于 σ 的前态。

定义 6（前态现实事件）\[S\]　PriorEventReal^M(e\_a; σ)：取 1，e\_a 是现实运行事件，不是历史标签、观察者的标注、静态的可达关系或离线重演的记录；它是否属于 σ 的前态，由定义 9 读取；取 0，前态事件记录完整，且 e\_a 明确不属于现实运行；其余取 ⊥。

定义 7（前门职责类登记）\[承\]　PriorGateRoleRead^M(\[G\_a\])：\[G\_a\] ∈ 𝒢̄\_I，按冻结的 GateRoleID 求值，即《意向数理式》的欲门职责商类登记。

定义 8（前态实际过门）\[S\]　ActualPriorGatePass^M(Z\_a; e\_a, \[G\_a\])：取 1，Z\_a 是 e\_a 中的现实路径段，实际进入欲门职责类 \[G\_a\]，即由承担 \[G\_a\] 的某一物理实现现实地通过；取 0，e\_a 的过门候选与路径段覆盖完整，且确定没有进入 \[G\_a\]；其余取 ⊥。这一读数不读 Z\_a 之前的源动段与生成段，不问进入 \[G\_a\] 的方向是由谁形成的。

定义 9（前态序列绑定）\[辅\]　PriorPassSeqBind^M(e\_a, Z\_a; σ)：取 1，按 Γ\_IGS 冻结的身份资料，Z\_a 这一次过门属于 σ 的前态评价域 D\_σ^-；取 0，身份资料完整，且确定不属于；其余取 ⊥。不得以“后来看见门不同”反过来认定它属于 σ 的前态。

定义 10（S1 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;S1^M(w) := PriorEventReal^M ∧₃ PriorGateRoleRead^M ∧₃ ActualPriorGatePass^M ∧₃ PriorPassSeqBind^M

S1^M 不要求前态有完整的意向作用，不要求前态的 A1、A2 或 A4，也不要求前门在整个系统中唯一。

S2 读的是后门是不是由意向自身经源动、概率与方向这一条链现实取得的，并且这一过门落在 σ 的后态。前一部分《意向作用数理式》已经给出形式判据，本系统不另建第二套，只取它的前三层，并把它绑定到 σ 的后态上。

定义 11（后态前三层递进读数）\[辅\]

&nbsp;&nbsp;&nbsp;&nbsp;Q1^≤3(w\_b) := A1^M(w\_b)  
&nbsp;&nbsp;&nbsp;&nbsp;Q2^≤3(w\_b) := 0，当 Q1^≤3(w\_b) = 0；⊥，当 Q1^≤3(w\_b) = ⊥；A2^M(w\_b)，当 Q1^≤3(w\_b) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;Q3^≤3(w\_b) := 0，当 Q2^≤3(w\_b) = 0；⊥，当 Q2^≤3(w\_b) = ⊥；A3^M(w\_b)，当 Q2^≤3(w\_b) = 1

这里的 A1^M、A2^M、A3^M 就是《意向作用数理式》定义 8、9、14 的读数，直接在后态候选前缀 w\_b^M 上求值：这三项读数在该篇中各自只读本层的分量，即事件、实现包、Z\_src、Z\_ρ、v\_b、\[G\_b\] 与 Z\_G，不读 q\_i、Z\_T，所以不需要先有一个含门后分量的完整作用见证。该篇定义 4 读取现实当前事件时所需的作用申报单元 ξ\_t，在这里取 D\_σ^+ 中包含 e\_b 的申报单元，由 Γ\_IGS 事前冻结。递进的形式与该篇定义 23 的前三层相同，递进纪律原样承继：A2^M 只在 A1^M = 1 的同一见证上求值，A3^M 只在 A2^M = 1 的同一见证上求值；上一层为 ⊥ 时，不越过这个 ⊥ 去下层寻找 0。A2^M 的两种 0 也原样承继：当前发生取 0 记 PCurrent，当前发生取 1 而职责兑现取 0 记 PDuty。

定义 12（前三层同链绑定）\[表\]　SameIActBind\_≤3^M(w\_b)：取 1，当且仅当下列各项同时成立：A1^M、A2^M、A3^M 全部引用同一个 K\_I^M；全部引用同一个现实事件 e\_b；Π\_b^I 的概率组织实现与 A2^M 所调用的概率组织实现同一；Z\_src 的后继进入同一个 𝒫\_I；Z\_ρ 属于同一条当前生成链；A2 的实际方向就是 A3 的 v\_b；链段的顺序与连接合法，Z\_src ⇝ Z\_ρ ⇝ Z\_G；没有跨事件、跨组织、跨方向或跨欲门的拼接。取 0，身份资料完整，且上述某一项确定不成立；其余取 ⊥。它是《意向作用数理式》定义 22 在前三层上的部分，不含 q\_i、Z\_T、门后调谐职责登记与 A4。

定义 13（后态序列绑定）\[辅\]　PostPassSeqBind^M(e\_b, Z\_G; σ)：取 1，按 Γ\_IGS 冻结的身份资料，Z\_G 这一次进入 \[G\_b\] 的过门属于 σ 的后态评价域 D\_σ^+；取 0，身份资料完整，且确定不属于；其余取 ⊥。

定义 14（S2 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;S2^M(w) := Q3^≤3(w\_b) ∧₃ SameIActBind\_≤3^M(w\_b) ∧₃ PostPassSeqBind^M(e\_b, Z\_G; σ)

S2^M = 1 给出：后态见证上 A1、A2、A3 在同一条链上成立，并且这一次过门就是 σ 后态中 \[G\_b\] 的过门，即 Pass\_σ^+(\[G\_b\]) = 1。外界刺激经正式源动职责进入 𝒫\_I 而诱发这一续行，S2^M 可以取 1；外部完整选择器绕过源动职责与 𝒫\_I 直接把门态改到 \[G\_b\]，由《意向作用数理式》命题 4，A1^M 或同链绑定不为 1，S2^M 不得取 1。S2^M 不读门后调谐，不读显化与意识。

S3 读的是旧门在 σ 后态中是否还承担过门。这里最要防的，是把“没看见”当作“已退出”。所以先定义后态门承担的读数，再由它取否定。

定义 15（后态门承担读数）\[S\]　PostGateBearRead^M(σ, \[G\]) ：取 1，D\_σ^+ 中有现实记录明确表明，σ 的后态由欲门职责类 \[G\] 承担过门，即由承担 \[G\] 的某一物理实现现实地通过，且这一记录按 Γ\_IGS 属于 σ 的后态；取 0，PostGateStateCover^M(σ, \[G\]) = 1，即 D\_σ^+ 中承担 \[G\] 的全部物理实现、共同承担节点及其过门记录都已覆盖，并且确定 σ 的后态中 \[G\] 不承担过门；其余取 ⊥，包括后态记录不完整、共同承担节点覆盖不全、GateRoleID 未决、后态边界未决等情形。

定义 16（S3 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;S3^M(w) := ¬₃ PostGateBearRead^M(σ, \[G\_a\])

即：S3^M = 1 当且仅当后态承担覆盖闭合且确定 \[G\_a\] 不承担；S3^M = 0 当且仅当有现实记录明确表明 \[G\_a\] 在 σ 后态仍承担；其余为 ⊥。取 0 不需要覆盖闭合：一份属于 σ 后态的承担记录，已经是旧门仍在的正证据。取 1 必须覆盖闭合：

&nbsp;&nbsp;&nbsp;&nbsp;未找到 \[G\_a\] 的后态记录 ≠ \[G\_a\] 已退出

S3^M 只读 σ 的后态，不读系统别处、其他并用链或其他职责中的 \[G\_a\]；S3^M = 1 不是旧门的全局失活。

S4 读的是后态两组记录的事件归属：决定旧门在后态承担状态的全部记录，和表明新门在后态取得的全部记录，是否都属于 w\_b 上的同一次现实事件。一个欲门职责可以由多个物理实现共同承担，所以旧门的后态状态、新门的取得都可能由几份记录共同决定；S4 必须读全部这些记录，不能只挑一份。一般式规定 S4 不说这一事件是不是意向自身的续行，也不说旧门是否已经退出；所以形式层的 S4 不读 A1^M、A2^M，也不以 S3^M = 1 为前件，只读事件身份键。

定义 17（事件身份键）\[辅\]　EventKey^M(r)：对每一份现实门承担记录或门状态记录 r，按 Γ\_IGS 事前冻结的事件身份方案读取它所属的现实事件的键，例如运行编号、分支编号、实际更新编号、事务或事件编号、同期事件谱系。取得键须依据冻结方案允许的身份资料；不得因为“门看起来换了”而事后造出相同的键；时间相邻、状态相关、结果相同都不是身份资料。读不出键时取 ⊥。κ\_b := EventKey^M(e\_b)。

定义 18（后态新门取得记录族）\[S\]　ℛ\_new^M(σ, \[G\_b\])：D\_σ^+ 中表明 \[G\_b\] 被取得、即 σ 的后态由 \[G\_b\] 承担过门的全部现实记录，包括承担 \[G\_b\] 的各物理实现与共同承担节点的记录；其事件键集合记为 K\_new^M := { EventKey^M(r) \| r ∈ ℛ\_new^M }。这一记录族按 σ 的后态读取，不经由 S2^M 取得：在外部强制改门的世界里，新门的取得记录照样存在，只是它的事件不是意向自身的续行。

定义 19（后态旧门承担状态记录族）\[S\]　ℛ\_old^M(σ, \[G\_a\])：D\_σ^+ 中决定 \[G\_a\] 在 σ 后态承担状态的全部现实记录，无论这一状态是仍承担还是不再承担，包括承担 \[G\_a\] 的各物理实现与共同承担节点的记录；其事件键集合记为 K\_old^M := { EventKey^M(r) \| r ∈ ℛ\_old^M }。读的是“承担状态”的记录，不预设 S3 = 1：同门继续时，它们是 \[G\_a\] 仍承担的记录；旧门退出时，它们是 \[G\_a\] 不再承担的记录。

旧门状态空域读数 OldStateDomainEmpty^M(σ, \[G\_a\])：取 1，σ 的前后评价域中承担 \[G\_a\] 的全部物理实现与记录都已覆盖，并确认 \[G\_a\] 在 σ 上没有任何承担，也没有任何承担状态的改变，因而没有需要归属的旧门状态事件；取 0，σ 上确有 \[G\_a\] 的承担或承担状态的改变，旧门状态必须由 ℛ\_old^M 中的记录归属；其余取 ⊥，即不知道是确实为空还是材料缺失。它是纯形式辅助读数，只服务于 S4^M 的空洞分支。

&nbsp;&nbsp;&nbsp;&nbsp;旧门状态域确认为空 ≠ 旧门状态的归属材料缺失

前者是一般式所说的“没有任何退出需要另行承担”；后者只能是 ⊥。前态确有 \[G\_a\] 的过门时，OldStateDomainEmpty^M = 0，旧门的后态状态必须有记录并逐份归属，不能借空洞分支签出 1。

覆盖 HandoffAttributionCover^M(σ, \[G\_a\], \[G\_b\])：ℛ\_old^M 与 ℛ\_new^M 都已完整枚举，其中每一份记录的事件身份键都已读出，并且 OldStateDomainEmpty^M 已取得 1 或 0。“没看到另有机制”不能代替这一覆盖。

定义 20（S4 读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;S4^M(w) := 1，当 HandoffAttributionCover^M = 1，ℛ\_new^M ≠ ∅，K\_new^M = {κ\_b}，并且下列两支之一成立：  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;实质归属支：ℛ\_old^M ≠ ∅，且 K\_old^M = {κ\_b}；  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;空洞归属支：OldStateDomainEmpty^M = 1  
&nbsp;&nbsp;&nbsp;&nbsp;S4^M(w) := 0，当存在 r ∈ ℛ\_old^M ∪ ℛ\_new^M，r 属于 σ 的后态，EventKey^M(r) 可读且 EventKey^M(r) ≠ κ\_b  
&nbsp;&nbsp;&nbsp;&nbsp;S4^M(w) := ⊥，其余

实质归属支等价于全称式：∀r ∈ ℛ\_old^M ∪ ℛ\_new^M，EventKey^M(r) = κ\_b。它要求覆盖闭合，因为一般式的 S4 含“\[G\_a\] 的后态承担状态不由另一独立机制单独承担”这一全称内容：只有全部相关记录都已覆盖、并且每一份都属于 κ\_b，才能说旧门的状态与新门的取得同属 w\_b 上的同一次事件，没有另一事件参与承担。新门的取得记录在两支中都必须存在：没有任何记录表明新门的取得，就没有可以归属的材料。

空洞归属支对应一般式删去 S1 的那个世界：σ 上本没有 \[G\_a\] 的承担，后态由 w\_b 取得 \[G\_b\]，旧门一侧没有任何需要归属的事件，S4 空洞地成立。这一支只在 OldStateDomainEmpty^M = 1 时开放；旧门状态的记录族为空而空域未经确认，读数为 ⊥，不签 1。

各种情形的读数如下：σ 上没有旧门需要交接，新门取得全部属于 κ\_b，S4^M = 1；有旧门状态，旧门状态与新门取得的全部记录都属于 κ\_b，S4^M = 1；有一份相关记录属于另一事件，S4^M = 0；不知道旧门状态域是否为空，或者有记录的事件键读不出，S4^M = ⊥。

取 0 不需要覆盖闭合：只要有一份属于 σ 后态的相关记录明确属于另一事件，旧门的状态或新门的取得就已有另一事件参与承担，S4 已经不成立；这与 S3^M 取 0 的道理相同。典型情形是旧门状态的记录属于另一独立事件；也包括全部记录同属另一事件 κ ≠ κ\_b，这时这一候选的 w\_b 不是承担这次交接的事件。若运行基底根本不提供事件身份键，S4^M 只能取 ⊥；不得为了可判而另立表示条件。

S4^M 与 S2^M、S3^M 的独立性在形式层保持如下：同门继续时，\[G\_a\] 仍承担的全部记录与 \[G\_b\] = \[G\_a\] 的取得记录可以都属于 κ\_b，S4^M = 1 而 S3^M = 0；外部强制改门时，旧门退出与新门取得的全部记录都属于那一次外部执行的事件，S4^M = 1 而 S2^M = 0；巧合退出时，旧门状态的记录族中有一份属于另一事件，S4^M = 0 而 S2^M = S3^M = 1。

四项各自的读数还不够：四个 1 如果分别取自不同的锚、不同的序列，拼在一起并不描述同一次切换。共绑定把一般式的 B1 至 B4 落到前后两端的身份资料上。它检查的是一个候选见证是否良构，不是第五项职责。

定义 21（共绑定的四个方面）\[辅\]  
AnchorBind\_IGS^M(w)：取 1，w\_a^M 与 w\_b^M 锚定于同一个 K\_I^M；取 0，身份资料完整，且确定跨锚；其余取 ⊥。  
OrderBind\_IGS^M(w)：取 1，按 ≺\_σ，e\_a 所在的前态真实先于 e\_b 所在的后态；取 0，顺序资料完整，且确定 e\_a 不先于 e\_b，或者二者共时无序而被任意排出了先后；其余取 ⊥。  
SequenceBind\_IGS^M(w)：取 1，按 Γ\_IGS 允许的事件谱系、控制谱系、作用记录或其他冻结的身份资料，w\_a^M 与 w\_b^M 是同一条门变化序列 σ 的前后状态；取 0，身份资料完整，且确定二者分属不同的序列，例如分属两条独立的作用链；其余取 ⊥。不得以“前后门不同”反过来认定同一序列。  
OrganizationBind\_IGS^M(w)：取 1，前后两端属于同一资格组织；取 0，身份资料完整，且确定跨资格组织；其余取 ⊥。

定义 22（共绑定）\[表\]

&nbsp;&nbsp;&nbsp;&nbsp;SameIGSBind^M(w) := AnchorBind\_IGS^M ∧₃ OrderBind\_IGS^M ∧₃ SequenceBind\_IGS^M ∧₃ OrganizationBind\_IGS^M

SameIGSBind^M = 0 的含义是：这一组形式片段不是同一次切换的前后两端。它不是第五项职责取 0。SameIGSBind^M 与 S4^M 分别求值：前者绑定前态与后态，后者只看后态内部两组相关记录的事件归属；二者互不推出。SameIGSBind^M 也与 SameIActBind\_≤3^M 不同：后者只绑定后态一端内部的前三层。

定义 23（切换比较键）\[辅\]　Λ\_IGS^M := (K\_I^M, σ^M, e\_a, e\_b, \[G\_a\], \[G\_b\], κ\_b)。它只用于登记与比较，不新增本体对象。

关系性质：事件身份同一、事件键相等、资格锚同一、欲门职责类同一、序列身份同一，都是身份等同，按等价关系处理（自反、对称、传递）。≺\_σ 是前后评价域之间的严格先后，申报为反自反、反对称、传递，但只在 σ 的前后两个评价域之间使用，不申报为全序。链段之间的后继关系 ⇝ 是异型的有向关系，不申报自反、对称或传递，不是偏序。𝔉\_IGS 是集合值对应，不申报单值、单射、满射或唯一性，不申报自反、对称、传递。PriorPassSeqBind^M、PostPassSeqBind^M 与共绑定的四个方面，都是异型三值谓词，不申报自反、对称或传递。候选集、覆盖证书是集合或谓词，不是二元关系。

四、方程

本系统没有动力方程；它的关系都是静力关系，即读数之间的组成关系。切换怎样开始、经过多久、中间怎样竞争，不在本系统中表示。

1\. 并列求值

《意向作用数理式》的四项是累计阶段，后一项只在前一项取得的同一条链上才有求值对象，所以那里逐层递进。本系统的四项不同：S1 的对象是前态的过门记录，S2 的对象是后态的作用链，S3 的对象是后态旧门的承担记录，S4 的对象是后态两组相关记录族的事件键。任何一项的求值对象都不由另一项的取值产生；一般式也已给出四项各有只缺它的反例。所以顶层四项并列求值，不排成递进；若把它们排成递进，某一项本可独立判 0 或 1，却会被前一项的 ⊥ 非法遮蔽。只有 S2 内部沿用意向作用前三层的递进。

定义 24（逐见证并列读数）\[辅\]

&nbsp;&nbsp;&nbsp;&nbsp;Q\_IGS(w) := S1^M(w) ∧₃ S2^M(w) ∧₃ S3^M(w) ∧₃ S4^M(w) ∧₃ SameIGSBind^M(w)

SameIGSBind^M 是见证的守卫，不是第五项职责。前后两门职责类不同不进入 Q\_IGS，它是推论（命题 1）。

2\. 候选与覆盖

正读数只需要一个合法的候选见证。负读数不同：没有找到见证，不等于见证不存在；要签 0，必须证明所需的候选都已经枚举完。

定义 25（候选见证域）\[辅\]　Ŵ\_IGS(σ)：按 Γ\_IGS，从 σ 的前后评价域、GateRoleID 登记、现实事件记录与事件身份记录中，枚举前态候选登记与后态候选前缀登记，并组成形式见证候选集。带帽的集合只是枚举域，不天然等于全部合法见证。枚举纪律：不得先用 S1 至 S4 或共绑定为 1 来过滤候选，否则负例会在枚举阶段被静默删掉；同门继续、并用新增、外部强制、巧合退出、跨序列拼接，以及后态 A1、A2、A3 各层失败的候选，都必须能进入候选域并取得各自的读数；不要求正见证唯一。

覆盖证书分层如下：

S1：PriorEventCover^M，D\_σ^- 中与申报锚相关的现实事件都已覆盖；PriorGatePassCover^M(e\_a)，e\_a 中的过门候选与路径段都已覆盖；PriorSeqBindCover^M，前态过门的序列身份资料完整。

S2：直接承继《意向作用数理式》的 EventCover^M、SrcRoleCover^M、SrcSegCover^M、PRealCover^M、PGenSegCover^M、PActCertCover^M、DirRealCover^M、GateSegCover^M 及对应身份覆盖，限于后态评价域；另有 PrefixBindCover\_≤3^M，前三层同链的身份资料完整；PostSeqBindCover^M，后态过门的序列身份资料完整。

S3：PostGateStateCover^M(σ, \[G\])，定义 15。

S4：HandoffAttributionCover^M(σ, \[G\_a\], \[G\_b\])，定义 19 之后；其中含 ℛ\_old^M、ℛ\_new^M 两族记录的完整枚举、每一份记录事件身份键的读出与旧门状态空域的判定。它只服务于 S4^M 取 1；取 0 由一份属于另一事件的相关记录即可给出。

共绑定：AnchorCover^M、OrderCover^M、SequenceIdentityCover^M、OrganizationCover^M，分别为锚、顺序、序列身份与组织身份的资料完整。

候选：CandidatePairCover\_IGS^M，σ 上可能组成候选见证的前态候选登记、后态候选前缀登记与职责类组合都已枚举。

这些都是形式可解性与覆盖的条件，不是 H，也不是意向欲门切换的对象层条件。

定义 26（负读出覆盖）\[辅\]　NegComplete\_IGS^M = 1，当且仅当：CandidatePairCover\_IGS^M = 1，并且每一个候选都至少有一条反证路径（定义 30）可用：该路径需要覆盖的，覆盖已经闭合；S3、S4 由正证据取得的 0 不需要覆盖。NegComplete\_IGS^M 不是本体条件，不进入 N\_IGS(σ)；正读数一旦出现即可签 1，不需要它。

3\. 总读数

定义 27（总读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{N\_IGS(σ)}^M := ∃₃ w ∈ Ŵ\_IGS(σ) · Q\_IGS(w)

分段地说：取 1，至少有一个候选 w 使 Q\_IGS(w) = 1；取 0，NegComplete\_IGS^M = 1，所有候选都有 Q\_IGS(w) = 0，且这些 0 中没有 DeclarationZero；其余取 ⊥，包括存在未决的候选、覆盖未闭、上游的形式可解性条件未满足、申报失格、身份不可判等情形。总读数只由形式材料、覆盖、身份与申报的合法性决定；H\_PAct-Rep、H\_LawRead 等回读条件是否关闭，不改变总读数，只影响它回读为结构判词时的强度（七之 3、七之 7）。

4\. 零型与失败项

定义 28（StructuralZero）\[辅\]　决定性的 0 来自实际结构的失败：前态确实没有合法过门；后态的作用前三层在结构上失败，或者前三层同链不成立，或者后门确定不属于 σ 的后态；旧门在 σ 后态确定仍承担；后态相关记录族中确有一份属于 w\_b 以外的事件；前后两端确定跨锚、无序、跨序列或跨组织。

定义 29（DeclarationZero）\[辅\]　决定性的形式 0 只来自申报或协议的失格，例如：σ^M 的前后评价域写反或互相包含；Γ\_IGS 在观察门的状态以后被改写；事件身份键的方案没有事前冻结；GateRoleID 的版本与资格锚的版本不一致；资格锚跨版本；候选域由不合法的事后删选产生。DeclarationZero 不回读为 N\_IGS(σ) = 0，最终退为 ⊥（DeclarationInvalid）。

定义 30（失败项与反证路径）\[辅\]　Read\_{N\_IGS(σ)}^M = 0 时，每一个候选 w 都有 Q\_IGS(w) = 0。记 Fail\_IGS^M(w) ⊆ {S1, S2, S3, S4, Bind} 为 w 上取 0 的项的集合，Bind 指 SameIGSBind^M = 0；由于顶层并列，一个候选可以同时在几项上取 0。S2 ∈ Fail\_IGS^M(w) 时，另记子失败签名 FailSub\_S2^M(w) ⊆ {A1, A2-PCurrent, A2-PDuty, A3, PrefixBind, PostSeqBind}：Q3^≤3 的 0 按《意向作用数理式》定义 30 在前三层上的取法记在 A1、A2-PCurrent、A2-PDuty 或 A3；SameIActBind\_≤3^M = 0 记 PrefixBind；PostPassSeqBind^M = 0 记 PostSeqBind。反证路径 RefuteRoute(w) 是 Fail\_IGS^M(w) 中被选来签出这一候选之 0 的一项（取 S2 时并选定一个子失败）；所选路径须满足该项的覆盖与回读条件（七之 3）。全部候选所选路径的项组成失败层签名 FailLayer\_IGS^M；读数为 1 或 ⊥ 时，FailLayer\_IGS^M = ∅。Bind 不是第五项职责，只表示前后两端不是同一次切换的两端。Fail、FailSub、RefuteRoute 与 FailLayer 都不是职责，只是负读出的诊断签名。

一个候选只要有一项在结构上确定为 0，合取就已为 0；所以负判只需要每个候选至少一条有效的反证路径，不要求把这一候选在其他项上的读数也都求到闭合。这一点与《意向作用数理式》的逐层递进不同：那里每个候选只有一个失败层；这里并列求值，同一候选可以有几条反证路径，择一可用者即可。

这些关系的性质如下。

命题 1（门职责差异）。S2^M(w) = 1 ∧ S3^M(w) = 1 ⇒ GateRoleID(\[G\_a\]) ≠ GateRoleID(\[G\_b\])。证明：S2^M = 1 给出一份属于 σ 后态的现实过门记录，表明 \[G\_b\] 在 σ 后态承担过门；若 \[G\_a\] 与 \[G\_b\] 是同一职责类，这份记录就是 \[G\_a\] 在 σ 后态仍承担的记录，由定义 15，PostGateBearRead^M(σ, \[G\_a\]) = 1，于是 S3^M = 0，矛盾。□ 这一推论用于一致性审查，不是 N\_IGS(σ) 的分量。

命题 2（量词不可拆分）。(∃₃w S1^M(w)) ∧₃ (∃₃w S2^M(w)) ∧₃ (∃₃w S3^M(w)) ∧₃ (∃₃w S4^M(w)) = 1 不推出 Read\_{N\_IGS(σ)}^M = 1。证明：取作用序列甲上的前态过门使 S1^M 取 1，取与甲独立的作用序列乙上的后态作用链使 S2^M、S3^M、S4^M 取 1；任何把二者拼成一个候选的 w 都有 SequenceBind\_IGS^M(w) = 0，故 Q\_IGS(w) = 0。□

命题 3（同门继续）。后态由意向自身的续行再次走进 \[G\_a\]，并且这一记录属于 σ 后态，则 PostGateBearRead^M(σ, \[G\_a\]) = 1，S3^M = 0，Q\_IGS = 0；此时 S1^M、S2^M、S4^M 可以都为 1。□

命题 4（并用与新增）。后态中意向自身新取得 \[G\_b\]，而 \[G\_a\] 在 σ 后态仍有属于 σ 的承担记录，则 S3^M = 0；若 \[G\_a\] 的继续承担属于与 w\_a 无关的另一条序列，则 SequenceBind\_IGS^M = 0。两种情形 Q\_IGS = 0，即使 \[G\_a\] ≠ \[G\_b\]。□

命题 5（外部强制改门）。前态通过 \[G\_a\]，外部完整选择器或普通强制门控直接把门态改到 \[G\_b\]，旧门随之退出，组织只是执行了这一结果，则 S2^M 不为 1：由《意向作用数理式》命题 4，后态候选的 A1^M 或同链绑定不为 1。此时 S1^M、S3^M、S4^M 可以都为 1，这是一般的门位切换可以成立而意向欲门切换的必要核不成立的标准形式。□

命题 6（巧合退出）。后态由意向自身取得 \[G\_b\]，S1^M = S2^M = S3^M = 1，而 \[G\_a\] 的后态状态记录族中有一份属于另一独立事件，EventKey^M(r) ≠ κ\_b，则 S4^M = 0，Q\_IGS = 0。旧门由几个物理实现共同承担，其中一份记录属于 κ\_b、另一份属于另一事件时，同样 S4^M = 0：不得只挑属于 κ\_b 的那一份记录签出 1。□

命题 7（事件归属未知）。状态上已知旧门在后态不再承担、新门已经取得，但读不出旧门状态记录的事件键，则 S4^M = ⊥；该候选若没有其他决定性的 0，Q\_IGS = ⊥，不由时间相邻或结果一致把它补成 1。□

命题 8（局部切换）。σ 上旧门退出、新门由意向自身取得且同属 κ\_b，而系统别处仍有另一条合法作用链通过 \[G\_a\]，只要那一条链的记录不属于 σ 的后态，PostGateBearRead^M(σ, \[G\_a\]) 不因它取 1，S3^M 不受影响。本系统不要求旧门的全局失活。□

命题 9（门后、显化与意识不进入读数）。后门已由意向自身取得、四项与共绑定都为 1，而这一次作用随后止于门处，A4^M = 0，或者没有显化、没有被意识到、没有调谐结果或行为，Read\_{N\_IGS(σ)}^M 仍可取 1。证明：定义 6 至 24 中没有一项读取 q\_i、Z\_T、A4^M、调谐结果、经验改变、显化或意识。□

命题 10（多候选与不读率值）。同一 σ 上存在几个合法的候选见证，Read\_{N\_IGS(σ)}^M = 1；本系统不要求唯一的后门或唯一的切换候选。新门不是当前率最大的方向所对应的门，或者旧门方向的率值没有降为零，都不影响读数：定义 6 至 24 中没有一项读取率值、最大率、率值交叉或阈值。□

命题 11（缺证据不写退出）。后态没有找到 \[G\_a\] 的承担记录，而 PostGateStateCover^M(σ, \[G\_a\]) 未闭，则 S3^M = ⊥，不签 1；没有看到另有机制改变旧门状态，而 HandoffAttributionCover^M 未闭，则 S4^M = ⊥，不签 1；没有找到正见证，而 CandidatePairCover\_IGS^M 未闭，则 Read\_{N\_IGS(σ)}^M = ⊥。□

命题 12（诱发来源不进入读数）。默想、思考或已显化的经验经合法回路返回，诱发了后态的续行改向，本系统不读这一诱发来源；只要后态的源动续行、概率承担与过门仍由意向自身的链承担，S2^M 可以取 1。若所谓重入直接指定了后门，绕过了源动职责与 𝒫\_I，则 A1^M 或同链绑定不为 1，S2^M 不得取 1。直接源动切换与显式重入诱发切换在形式层读同一组 S2^M、S3^M、S4^M。□

命题 13（申报失格）。切换链看似完整，而后态评价域的起点是在看到门的状态以后才确定的，或者事件身份键的方案没有事前冻结，则读数为 ⊥（DeclarationInvalid），不签 N\_IGS(σ) = 0。□

五、运行与求解

本系统表示一条比较序列上切换的必要结构，不随时间演化；“运行”指对一个切换求解实例 χ\_IGS^M 求值。

1\. 求解次序

（1）校验 χ\_IGS^M、进入条件与 Γ\_IGS；校验 σ^M 的前后评价域与 ≺\_σ。申报失格时，返回 ⊥（DeclarationInvalid）。  
（2）枚举 D\_σ^- 中的现实事件与过门路径段，对每一个候选的 (e\_a, Z\_a, \[G\_a\]) 求 S1^M。  
（3）枚举 D\_σ^+ 中的后态候选前缀登记 w\_b^M，包括 A1、A2、A3 可能失败与外部强制改门的登记，按定义 11 递进求 Q3^≤3，求 SameIActBind\_≤3^M 与 PostPassSeqBind^M，得 S2^M。  
（4）对每一个候选的 \[G\_a\]，读取 σ 后态中承担 \[G\_a\] 的记录，判 PostGateStateCover^M，求 S3^M。  
（5）枚举 σ 后态中 \[G\_b\] 的取得记录族 ℛ\_new^M 与 \[G\_a\] 的承担状态记录族 ℛ\_old^M，按冻结方案读取每一份记录的事件键与 κ\_b；有一份可读的键不等于 κ\_b，S4^M 即为 0；否则判 OldStateDomainEmpty^M 与 HandoffAttributionCover^M，求 S4^M。  
（6）对前后两端求共绑定的四个方面，得 SameIGSBind^M。  
（7）对每一个候选求 Q\_IGS(w)。各项之间没有求值次序的依赖，可以按任意次序求；某一项已为 0 时，这一候选已为 0，其余项可以不再求。  
（8）任一 Q\_IGS(w) = 1，读数为 1，枚举可以停止。  
（9）没有正见证时，判 CandidatePairCover\_IGS^M，并为每一个候选选一条反证路径，检查该路径所需的覆盖：任一候选没有可用的反证路径，返回相应的 ⊥；候选的 0 中含 DeclarationZero，返回 ⊥（DeclarationInvalid）；否则签 0，并给出 FailLayer\_IGS^M 与所选路径的 FailSub\_S2^M。签 0 以后，按七之 3 由所选路径确定结构判词：若某个候选唯一可用的反证路径是 S2 的 A2-PDuty 子失败，而 H\_PAct-Rep 未关闭，形式读数仍为 0，结构判词为 ⊥（PActRepOpen）。

2\. ⊥ 的原因

形式读数取 ⊥ 时必须附原因，分为：DeclarationInvalid，申报、版本、锚或序列登记失格；PriorEventOpen，前态现实事件记录不完整；PriorPassOpen，前态过门路径的覆盖未闭；PriorSeqOpen，前态过门的序列身份不可判；PostActOpen，后态作用前三层的某一层不可判，原因细分沿用《意向作用数理式》五之 2 的 EventOpen、SourceRoleOpen、SourcePathOpen、ProbabilityCertOpen、DirectionOpen、GateIdentityOpen、GatePathOpen；PrefixBindOpen，前三层同链身份不可判；PostSeqOpen，后态过门的序列身份不可判；GateStateOpen，后态门承担的覆盖未闭；EventKeyOpen，事件身份键读不出或其覆盖未闭；OldDomainOpen，旧门状态空域不可判，不知道是确实为空还是材料缺失；BindOpen，前后两端的锚、顺序、序列或组织身份不可判；CandidateOpen，候选组合的枚举未闭。

另有两个原因不属于形式读数，而属于由形式读数回读得到的结构判词：PActRepOpen，形式读数为 0，而某个候选唯一可用的反证路径是 A2-PDuty，且 H\_PAct-Rep 未关闭，结构判词不能签 N\_IGS(σ) = 0；LawReadOpen，形式读数为 1，而正向回读实际使用的 Law-bearing 见证的 H\_LawRead 未关闭，结构判词不能无条件签 N\_IGS(σ) = 1。

这些原因都是求解诊断，不是本体条件。

3\. 可解性

以下是形式表示与求解的条件，记为 IGS-M1 至 IGS-M10。它们不是意向欲门切换的本体条件，也不是 H。任一条件缺失，只使依赖它的项退为 ⊥，不自动判为结构 0。

IGS-M1 求解实例可识别：χ\_IGS^M 的各项可以有效引用；χ\_I 是已经成立的意向资格实例；Γ\_IGS 在求解以前冻结。  
IGS-M2 比较序列可登记：σ 的前后评价域与先后关系可以在求解以前冻结，后态评价域的起点不随门的状态移动。  
IGS-M3 前态过门可读：运行基底能给出 D\_σ^- 中的现实事件与过门路径段，并区分现实运行、历史标签与离线重演。  
IGS-M4 后态作用前三层可求：《意向作用数理式》的 IA-M1 至 IA-M9、IA-M11、IA-M12 在后态评价域上成立。  
IGS-M5 欲门职责身份可判：𝒢̄\_I 与 GateRoleID 可判；能把各物理实现与共同承担节点归到职责类；不以单个物理节点替代欲门职责。  
IGS-M6 后态门承担可读：σ 后态中各相关职责类的承担记录可以读取，承担 \[G\] 的全部物理实现与共同承担节点可以覆盖；门承担状态的改变，包括某一职责类不再承担过门，也有现实记录。运行基底若只记录过门、不记录退出，前门确有过门时 ℛ\_old^M 恒为空，S4^M 不能取 1。  
IGS-M7 事件身份键可读：运行基底提供事前冻结方案下的现实事件身份键，后态的门承担记录与门状态记录都能读出它所属事件的键。  
IGS-M8 序列身份可判：前后两端的事件谱系、控制谱系或作用记录可以读取，能区分同一序列的前后状态与独立的并用支路。  
IGS-M9 锚、顺序与组织身份可判：前后两端的资格锚、先后与资格组织可判，能检测跨锚、共时无序与跨组织的拼接。  
IGS-M10 覆盖可判：各项覆盖证书与候选组合的覆盖都能判定。

在 Γ\_IGS 冻结、所涉候选域都有限可枚举、IGS-M1 至 IGS-M10 成立的条件下，每一步都在有限步内完成，Read\_{N\_IGS(σ)}^M 有确定的三值读数，并在取 ⊥ 时附原因。不满足这一条件的申报实例，不因此取 0，其读数保持为 ⊥。

4\. 解的地位

Read\_{N\_IGS(σ)}^M = 1 是形式解，表示在 σ 上存在一个候选见证，四项与共绑定都成立。Read\_{N\_IGS(σ)}^M = 0 表示在完整覆盖下 σ 上没有这样的形式见证；其结构层的否定强度按所选的反证路径区分（七之 3）。Read\_{N\_IGS(σ)}^M = ⊥ 表示材料不足，不得读作 N\_IGS(σ) 不成立，更不得读作意向欲门切换不成立。

六、耦合关系

与《意向欲门切换一般式》：只形式化 N\_IGS(σ)、S1 至 S4、B\_same^IGS 与推论 \[G\_a\] ≠ \[G\_b\]，逐项对应见对应表。本系统不新增第五项职责；共绑定由同一个形式见证与 SameIGSBind^M 表达。一般式中 IntentGateSwitch 与 GateSwitch 的层级在本系统中保持：外部强制改门的候选可以使旧门退出、新门取得，却不能取得 Q\_IGS = 1（命题 5）。

与《意向作用数理式》：S2^M 直接调用该篇的 A1^M、A2^M、A3^M、定义 23 的递进、定义 22 中前三层的同链要求、覆盖证书与 H\_PAct-Rep、H\_LawRead 的传播纪律，不另建第二套意向作用的形式系统。A3^M 只用于 S2，不用于 S1；A4^M 与门后调谐的任何对象都不进入本系统。

与《意向数理式》：资格实例 χ\_I、资格锚 K\_I^M、正式方向族、欲门职责商类与 GateRoleID 都沿用上游。前后两门按职责类比较，不按物理节点比较。

与《概率作用数理式》《概率数理式》《律数理式》：只经由 A2^M 间接调用，当前发生、职责兑现、当前率承担证书与 Law-bearing 资格的形式来源都沿用上游；本系统自身不读率值。

与场系统和运行基底：前后评价域内的现实事件记录、过门路径段、后态门承担记录、事件身份键与序列身份资料，都须来自场系统或运行基底。本系统不另建物理生成系统。

七、回读规则

1\. 正向回读

定理 1（S1）。w ∈ 𝔉\_IGS(w^S) ∧ S1^M(w) = 1 ⇒ S1(w^S) = 1。证明：PriorEventReal^M 给出前态的现实事件；PriorGateRoleRead^M 给出 \[G\_a\] 是正式欲门职责类；ActualPriorGatePass^M 给出这一事件中实际进入 \[G\_a\] 的现实路径段；PriorPassSeqBind^M 给出这一过门属于 σ 的前态。合为 Pass\_σ^-(\[G\_a\]) = 1。各项都是结构分量的直接表示，不另立回读桥，不新增 H。□

定理 2（S2）。w ∈ 𝔉\_IGS(w^S) ∧ S2^M(w) = 1 ⇒ S2(w^S) = 1。证明：Q3^≤3(w\_b) = 1 给出 A1^M、A2^M、A3^M 在 w\_b^M 上都为 1，由《意向作用数理式》定理 1 至 3 得 A1(w\_b)、A2(w\_b)、A3(w\_b, \[G\_b\]) 在结构层成立：这三条定理的证明各自只用本层的读数分量，不用 q\_i、Z\_T，所以对后态候选前缀同样适用；SameIActBind\_≤3^M = 1 给出三者属于同一条现实作用链的前三层，这是该篇定理 5 在前三层上的部分，同为直接表示；PostPassSeqBind^M = 1 给出这一次过门属于 σ 的后态，即 Pass\_σ^+(\[G\_b\]) = 1。条件：A2 的正向回读不携 H\_PAct-Rep；所用 Law-bearing 资格若由形式读数即时取得，按实际见证逐项承继 H\_LawRead(W\_i)。不新增 H。□

定理 3（S3）。w ∈ 𝔉\_IGS(w^S) ∧ S3^M(w) = 1 ⇒ S3(w^S) = 1。证明：S3^M = 1 即 PostGateBearRead^M(σ, \[G\_a\]) = 0，由定义 15，这要求 σ 后态中承担 \[G\_a\] 的全部物理实现、共同承担节点及其记录都已覆盖，并确定 \[G\_a\] 不承担过门；这是 Pass\_σ^+(\[G\_a\]) = 0 的直接表示。不新增 H。□

定理 4（S4）。w ∈ 𝔉\_IGS(w^S) ∧ S4^M(w) = 1 ⇒ S4(w^S) = 1。证明：HandoffAttributionCover^M = 1 给出决定 \[G\_a\] 后态承担状态的全部记录 ℛ\_old^M、表明 \[G\_b\] 取得的全部记录 ℛ\_new^M 与旧门状态空域都已覆盖，且 ℛ\_new^M 非空、K\_new^M = {κ\_b}。实质归属支中，ℛ\_old^M 非空且 K\_old^M = {κ\_b}，给出旧门状态与新门取得的每一份记录都属于 w\_b 上的同一次现实事件，没有另一事件参与承担；空洞归属支中，OldStateDomainEmpty^M = 1 给出 σ 上没有任何需要归属的旧门状态事件，新门的取得全部属于 w\_b 上的事件，一般式的 S4 空洞地成立。两支都是一般式 HandoffBear(w\_b; σ, \[G\_a\]) = 1 的直接表示：读的是现实承担的归属，不是反事实依赖。不新增 H。□

定理 5（共绑定）。SameIGSBind^M(w) = 1 回读为：前后两端同锚、有序、属于同一比较序列、不跨资格组织，即一般式的 B\_same^IGS。它不回读为第五项职责，不携 H。证明：定义 21 的四个方面逐一对应一般式的 B1 至 B4。□

定理 6（N\_IGS(σ) 正向形式解定理）。Read\_{N\_IGS(σ)}^M = 1 ⇒ N\_IGS(σ) = 1。证明：存在 w 使 Q\_IGS(w) = 1，即 S1^M、S2^M、S3^M、S4^M 与 SameIGSBind^M 在 w 上都为 1；取 w^S 使 w ∈ 𝔉\_IGS(w^S)，由定理 1 至 5，四项与共绑定在同一结构见证组上成立。条件：只沿 S2 中 A2 实际使用的 Law-bearing 形式见证传播适用的 H\_LawRead；若 Law 资格已是对象层的既成事实，则无此条件。本定理不调用 H\_PAct-Rep，也不调用 H\_GP、H\_TI、H\_PL、H\_SD。□

Read\_{N\_IGS(σ)}^M = 1 回读到 N\_IGS(σ) = 1 为止；N\_IGS(σ) ⇒ IntentGateSwitch\_F(σ) 属于《意向欲门切换必然式》。

2\. 反向表示

负向回读要成立，须先有反向表示：结构层存在一个四项与共绑定都成立的见证组时，形式层能取得相应的正见证。否则“形式候选已查完而没有正见证”推不出“结构层没有这样的见证组”。

S1、S3、S4 与共绑定的各项读数，都是对事件、路径段、门承担记录、事件身份键与身份资料的直接表示：在 IGS-M1 至 IGS-M3、IGS-M5 至 IGS-M10 成立时，结构层前态的现实过门、后态旧门的承担状态、后态两组相关记录的事件归属与前后两端的绑定，都有相应的合法形式登记，并在覆盖完整时进入候选域。形式材料不足时退为 ⊥，不以弱的代理量反推结构，所以这几项不需要另立表示条件。

S2 中，A1、A2 的当前发生子层、A3、前三层同链与后态序列绑定，都沿用《意向作用数理式》七之 2 的直接表示，不携 H。A2 的职责兑现子层需要《概率作用数理式》的 H\_PAct-Rep；本系统承继它，不关闭它。

3\. 负向回读

Read\_{N\_IGS(σ)}^M = 0 时，每一个候选都有一条所选的反证路径（定义 30）。从形式 0 回读结构判词 N\_IGS(σ) = 0，须对每一个候选所选的路径满足该路径的回读条件：

路径 S1：PriorEventCover^M、PriorGatePassCover^M、PriorSeqBindCover^M 中该失败所需的覆盖闭合。不携新 H。

路径 S2，子失败 A1：《意向作用数理式》的 EventCover^M、SrcRoleCover^M、SrcSegCover^M 及相关身份覆盖在后态评价域上闭合。不携新 H。

路径 S2，子失败 A2-PCurrent：上述各项与 PRealCover^M、PGenSegCover^M 闭合。不携 H\_PAct-Rep，不携新 H。

路径 S2，子失败 A2-PDuty：上述各项与 PActCertCover^M 都闭合，并且 H\_PAct-Rep 关闭。H\_PAct-Rep 未关闭时，这一路径不能签结构零；若同一候选另有可用的路径，例如 S3 或 S4 的结构 0，可以改选；若没有，结构判词为 ⊥（PActRepOpen）。

路径 S2，子失败 A3：DirRealCover^M、GateSegCover^M 与对应身份覆盖闭合。不携新 H。

路径 S2，子失败 PrefixBind 或 PostSeqBind：前三层同链或后态序列的身份覆盖闭合。不携新 H。

路径 S3：一份属于 σ 后态的 \[G\_a\] 承担记录已经明确。不携新 H。

路径 S4：一份属于 σ 后态的相关记录，其事件身份键可读且不等于 κ\_b。不携新 H。

路径 Bind：相应的锚、顺序、序列或组织身份覆盖闭合。不携新 H。

每一个候选所选的路径都满足条件时，N\_IGS(σ) = 0：在 σ 上，结构层不存在一个四项与共绑定都成立的见证组。所携条件是各候选所选路径所携条件的合取；只有所选路径中含 A2-PDuty 时，才携 H\_PAct-Rep。不得因为某一候选未选用的 A2-PDuty 分支上 H\_PAct-Rep 未关闭，就否认它已经由另一条无条件路径取得的结构 0。

由《意向欲门切换一般式》的必要方向 IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ) 取逆否，N\_IGS(σ) = 0 ⇒ IntentGateSwitch\_F(σ) = 0。这一箭头不另增条件；经 A2-PDuty 路径取得者，仍携 H\_PAct-Rep。这一结论只否定这一条 σ 上的意向欲门切换：它不推出其他比较序列上没有意向欲门切换，不推出这一条 σ 上没有一般的门位切换，也不推出意向作用或意向资格不成立。

4\. 未决与零型

Read\_{N\_IGS(σ)}^M = ⊥ 既不推出切换成立，也不推出切换不成立：

&nbsp;&nbsp;&nbsp;&nbsp;没有找到见证 ≠ 0，　⊥ ≠ 0，　Read = ⊥ ⇏ N\_IGS(σ) = 0

DeclarationZero 不回读为 N\_IGS(σ) = 0，只退为 ⊥（DeclarationInvalid）。

5\. 禁止回读

不得：Read\_{N\_IGS(σ)}^M = 1 ⇒ IntentGateSwitch\_F(σ) = 1；这一方向须经《意向欲门切换必然式》。  
不得：A3^M = 1 ⇒ 欲门切换；GateRoleID(\[G\_a\]) ≠ GateRoleID(\[G\_b\]) ⇒ 欲门切换；S1^M、S2^M、S3^M 都为 1 而 S4^M 或共绑定未闭 ⇒ 欲门切换。  
不得：未找到 \[G\_a\] 的后态记录 ⇒ S3 = 1；未看到另有机制 ⇒ S4 = 1。  
不得：时间相邻、状态相关或结果一致 ⇒ 同一事件。  
不得：物理节点改变 ⇒ 欲门职责改变。  
不得：S3^M = 1 ⇒ 旧门全局失活。  
不得：S4^M = 1 ⇒ S2 = 1 或 S3 = 1；SameIGSBind^M = 1 ⇒ S4 = 1；S4^M = 1 ⇒ SameIGSBind = 1。  
不得：候选域为空 ⇒ Read = 0，除非 CandidatePairCover\_IGS^M = 1 且申报合法。  
不得：一条 σ 上 Read = 0 ⇒ 其他比较序列上没有切换。  
不得：以 A4、调谐成功、经验改变、显化、意识或行为结果作为 Read = 1 的条件；以率值、最大率、率值交叉或阈值判切换。

6\. 纯形式辅助量

以下不回读为意向欲门切换的新增本体组成：Γ\_IGS；PriorPassSeqBind^M、PostPassSeqBind^M；EventKey^M 与各事件键；OldStateDomainEmpty^M；共绑定的四个方面；Λ\_IGS^M；Q\_IGS；Ŵ\_IGS(σ)、各覆盖证书与 NegComplete\_IGS^M；StructuralZero、DeclarationZero 的标记；Fail\_IGS^M、FailSub\_S2^M、RefuteRoute 与 FailLayer\_IGS^M；⊥ 所附的原因；候选的枚举次序与编号。σ^M、N\_IGS(σ)、w\_IGS^M、SameIActBind\_≤3^M 与 SameIGSBind^M 标为 \[表\]：它们是一般式已有对象的形式登记，回读为一般式的比较序列、必要核、见证组、后门一端的同链要求与共绑定纪律，不是新的实体。

7\. 条件

&nbsp;&nbsp;&nbsp;&nbsp;H\_new = ∅

本系统不新立 H\_PriorGateRep、H\_GateExitRep、H\_HandoffRep、H\_SeqRep：S1、S3、S4 与共绑定都采用对事件、路径段、门承担记录、事件身份键与身份资料的直接形式表示，形式材料不足时退为 ⊥。

承继的开放条件：

&nbsp;&nbsp;&nbsp;&nbsp;H\_inherit^open = { H\_PAct-Rep }

来源：《概率作用数理式》，经《意向作用数理式》承继。它只承重所选反证路径为 S2 的 A2-PDuty 这一支的负向结构回读，以及由此传导到 N\_IGS(σ) = 0、IntentGateSwitch\_F(σ) = 0 的负向结论；不承重形式系统本身、各项的正向回读、定理 6、A2 当前发生子层的负向回读，以及 S1、S3、S4、共绑定与 S2 其余子失败的负向结构回读。

本系统不承继 H\_GP、H\_TI、H\_PL、H\_SD：所有回读都不走这些桥的跨实现或形式推导路径。IGS-M1 至 IGS-M10 是形式可解性条件，影响 1、0、⊥ 的取得，不改变结构真值，不是 H。

状态：形式系统 Established，不以任何未决 H 为前提；S1、S3、S4 与共绑定的正向回读 Established；S2 的正向回读与定理 6 为 Conditional，条件为所用见证适用的 H\_LawRead；S1、S3、S4、共绑定与 S2 的 A1、A2-PCurrent、A3、PrefixBind、PostSeqBind 路径的负向回读 Established；S2 的 A2-PDuty 路径的负向回读 Conditional，条件为 H\_PAct-Rep。

8\. 击穿方式

K-IGSM1：Read\_{N\_IGS(σ)}^M = 1，而结构层 N\_IGS(σ) = 0。  
K-IGSM2：S1^M = 1，而结构层前态没有经过 \[G\_a\] 的现实过门。  
K-IGSM3：S1^M 要求前门的源动或概率来源，从而把一般式允许的合法前态判为 0 或 ⊥。  
K-IGSM4：S2^M = 1，而结构层后态见证上没有同链的 A1、A2、A3，或者这一过门不属于 σ 的后态。  
K-IGSM5：S2^M 读入 A4 或门后调谐的材料。  
K-IGSM6：覆盖未闭，仅因没有看见旧门的后态记录便签 S3^M = 1。  
K-IGSM7：S3^M = 1，而结构层旧门在 σ 后态仍承担过门。  
K-IGSM8：S4^M = 1，而旧门的后态状态与新门的取得实际属于不同的现实事件，或者有另一事件参与承担其中任一方；例如只读了共同承担的若干记录中属于 κ\_b 的那一份；或者前态确有 \[G\_a\] 的承担，而旧门状态的归属材料缺失时经空洞分支签出 1。  
K-IGSM9：S4^M 的定义使用反事实、干预或因果测试，或者以“旧门已退出”“后态事件是意向自身的续行”作前件，从而吸收 S3 或 S2。  
K-IGSM10：SameIGSBind^M 与 S4^M 合并，使后态内部的事件归属与跨前后的序列身份不能区分。  
K-IGSM11：两条独立作用链分别通过 \[G\_a\]、\[G\_b\]，系统因前后门不同而签出正见证。  
K-IGSM12：外部强制改门的候选取得 Q\_IGS = 1；或者巧合退出的候选（S1^M = S2^M = S3^M = 1，S4^M = 0）取得 Q\_IGS = 1。  
K-IGSM13：DeclarationZero 被回读为 N\_IGS(σ) = 0；或者候选覆盖未闭仍签 Read = 0。  
K-IGSM14：H\_PAct-Rep 未关闭时，以 A2-PDuty 为唯一路径的候选仍被回读为结构 0；或者正向 Read = 1 被错误地挂上 H\_PAct-Rep。  
K-IGSM15：一条 σ 上的 0 被读成全场不存在意向欲门切换。  
K-IGSM16：顶层四项被排成递进，使某一项本可独立判出的 0 或 1 被前一项的 ⊥ 遮蔽；或者多个合法候选被强行压成唯一见证，从而误删并用、竞争或多候选的世界。  
此外：展示形式系统内部的矛盾；展示对应表遗漏了承重符号；展示定义序列中某个关系的实际性质与所申明的不符。

八、接口

上承：《意向欲门切换一般式》的 IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)、S1 至 S4、B\_same^IGS 与 B1 至 B4、门职责差异推论、四项的独立性、IntentGateSwitch 与 GateSwitch 的层级、门后调谐与显化意识的排除、两种诱发机制；《意向作用数理式》的 A1^M、A2^M、A3^M、定义 22 与 23、候选与覆盖纪律、零型、H\_PAct-Rep 与 H\_LawRead 的传播；《意向数理式》的 χ\_I、K\_I^M、正式方向族、欲门职责商类、GateRoleID 与三值纪律；场系统与运行基底的现实事件记录、过门路径段、门承担记录、事件身份键与序列身份资料。

下交：《意向欲门切换必然式》接收 N\_IGS(σ) 与 Read\_{N\_IGS(σ)}^M 的正向形式证书，独立证明 N\_IGS(σ) ⇒ IntentGateSwitch\_F(σ)，不把 Read = 1 直接当作主证明的前件；《意向动力一般式》《意向动力数理式》《意向动力必然式》接收前后作用单元、切换候选、失败项与事件身份键，研究切换的开始、进行、竞争、失败、恢复与持续，本系统不建立这些过程的状态机；《意向判定式》接收三值读数、FailLayer 与 FailSub\_S2、所选反证路径、覆盖证书、⊥ 的原因与条件传播；《意向运行基底构造式》须提供前态过门记录、后态作用前三层的现实链、GateRoleID、后态门承担记录与门承担状态改变的记录、事件身份键、前后序列身份与各项覆盖接口，缺少任一项，运行基底不能声称完整实现 M\_IGS；没有事件身份键时，S4^M 只能取 ⊥。

并用与竞争：本系统不规定一条 σ 上只有一个后门候选，也不要求正见证唯一；只要存在一个 w 使 Q\_IGS(w) = 1，即可正判 N\_IGS(σ)。多个候选同时存在时，它们之间是并用、竞争还是先后的几次切换，不在本系统中本体化，交意向动力各篇。
