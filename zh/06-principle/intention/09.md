# 意向欲门切换必然式

一、目的

证明：意向已经成立时，在一条固定的比较序列 σ 上，只要以下四项与前后两端的共绑定全部成立，σ 上就发生了一次意向欲门切换，不需要再满足第五项独立的切换条件。

四项是：

第一，前门真实通过：σ 的前态中，有一次现实合法的过门，经过欲门职责类 \[G\_a\]。

第二，意向自身当前过后门：σ 的后态中，意向自身的源动续行现实发生并进入 𝒫\_I，概率组织在同一次续行中承担诸方向之间的相对生成，由此形成的方向沿正式对应进入欲门职责类 \[G\_b\]。

第三，前门退出：\[G\_a\] 在 σ 的后态中不再承担过门。

第四，交接承担：σ 后态中 \[G\_a\] 的承担状态与 \[G\_b\] 的取得，同属后态那一次现实门承担事件；\[G\_a\] 的后态承担状态不由另一独立机制单独承担。

共绑定：前后两端同锚、有序、属于同一条 σ、不跨资格组织。

用式子表示为：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) ⇒ IntentGateSwitch\_F(σ)

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]

工作域为 Intent\_{F,t} = 1。

“不需要再满足第五项独立的切换条件”具体是指：切换以后作用有没有进入门后的调谐使役，有没有显化，有没有意识到，调谐是否成功，经验最终是否改变，有没有行为或效应，旧门在系统别处是否仍在活动，前后之间有没有时间空档，过渡中有没有短暂重叠，新门是否对应当前率最大的方向，旧方向的率值是否降到零，切换是不是由外界刺激或显式重入诱发的，同一条 σ 上是否另有候选，系统中是否另有合法的作用链，都不影响结论。

二、上游输入、证明路线与对象映射

1\. 上游输入

《意向欲门切换一般式》：N\_IGS(σ)、S1 至 S4、B\_same^IGS 及其 B1 至 B4、推论 S2 ∧ S3 ⇒ \[G\_a\] ≠ \[G\_b\]、IntentGateSwitch 与一般的门位切换 GateSwitch 的层级；必要方向 IntentGateSwitch\_F(σ) ⇒ N\_IGS(σ)，Status 为 Established；切换语料的冻结范围 U\_IGS^src。本篇使用该篇的必要核与语料范围，不使用该篇关于第五项职责与独立取消条件的结论。

《意向欲门切换数理式》：切换形式系统 M\_IGS、总读数 Read\_{N\_IGS(σ)}^M 与正向回读 Read\_{N\_IGS(σ)}^M = 1 ⇒ N\_IGS(σ) = 1（携所用见证适用的 H\_LawRead）。它只作为本篇的形式入口，不作主证明的前件。

《意向作用一般式》：A1、A2、A3 的含义；GateSwitch 是一般的门位切换事实，门的状态可以被外部强制、普通门控或其他机制改变而不走意向的职责链，所以 IntentAct ⇏ GateSwitch，GateSwitch ⇏ IntentAct。

《意向作用必然式》《意向必然式》：语义原子的既有分类。

《意向一般式》：语义原子全集 u1 至 u52 与各原子的拆分（附录四）。

2\. 证明路线

证明不采用“《意向欲门切换一般式》已经检查过没有第五项职责、没有独立取消条件，所以四项齐全就足以成立意向欲门切换”的路线。那两项检查在该篇中服务于必要方向，本篇不把它们作为前提，只在第八节作一致性回测。本篇在同一切换语料范围上独立地重新执行充分性程序。

证明路线为：

&nbsp;&nbsp;&nbsp;&nbsp;冻结切换语义域 → 原子分类 → 不可约合取审查 → 切换语义闭合 → N\_IGS(σ) 完整实现切换语义 → IntentGateSwitch\_F(σ)

与此对应的三条定理是：先在冻结的切换语义域上取得一次意向欲门切换的全部正面语义，并证明不存在第五项职责与独立的取消条件（定理一）；再证明 N\_IGS(σ) 在同一条 σ、同一组见证上完整实现这些语义（定理二）；最后得出意向欲门切换必然定理（定理三）。

3\. 对象与算子映射

对象层：

Intent\_{F,t}：已经成立的意向资格，本篇的工作域，不重新证明。  
σ：一条在比较以前冻结的切换比较序列，即被申报比较的前后过门关系；不是宿体、槽位或实体。  
IntentGateSwitch\_F(σ)：σ 上发生了一次意向欲门切换；本篇的目标谓词。  
GateSwitch\_F(σ)：σ 上发生了一次一般的门位切换，不问由谁做出；IntentGateSwitch ⇒ GateSwitch，GateSwitch ⇏ IntentGateSwitch。  
S1 = PriorGatePass，S2 = IntentDrivenCurrentGatePass，S3 = PriorGateExit，S4 = HandoffBear；B\_same^IGS；N\_IGS(σ)：均取自《意向欲门切换一般式》，本篇不重写。  
A1、A2、A3：取自《意向作用一般式》。

元语言对象：

U\_IGS^src：本篇的冻结切换语义域。  
U\_IGS^+：本篇独立取得的正面切换语义的集合。  
U\_IGS^O：本篇独立取得的、不决定每一次切换真值的其余语义的集合。  
FifthIndependentIGSDuty\_I：第五项普遍切换职责的集合。  
IndependentCancel\_IGS：独立取消条件的集合。  
W\_IGS^-：反充分世界的集合。

这些都是元语言名称，不是本体谓词，不是场量，不进入 N\_IGS(σ)；出现的地方都可以直接展开为第五节列出的语义原子。证明使用的是展开后的语料条件，不是名称本身。

形式层，只作入口：

Read\_{N\_IGS(σ)}^M、S1^M 至 S4^M、SameIGSBind^M、Q\_IGS、OldStateDomainEmpty^M：取自《意向欲门切换数理式》。

映射到此完整；没有列入的对象不承重。

三、冻结切换语义域

本篇的切换语义域冻结为：

&nbsp;&nbsp;&nbsp;&nbsp;U\_IGS^src = { u21, u30, u48, u49, u50 }

原子的编号与拆分沿用《意向一般式》附录四，出处如下。页码为《自显论》v0.7.1 的 PDF 页序。

u21　让经验并用或切换的是意图。u30　经验可以并用，也可以切换。二者出自 Q3：“各有其经验可以并用，亦可切换，使之者，意图也。”（第 53 页）  
u48　切换欲门的过程本身没有自显性。  
u49　切换到某个欲门以后，欲门后的组织中有显性回路参与，才发生显化。  
u50　意向作用发生在意识到之前。  
以上三项出自 I9：“切换欲门的过程本身没有自显性，而是切换到某欲门后，欲门后的组织中有显性回路的参与才发生了显化作用……所以意向作用发生在意识到之前。”

同一个原子在不同的问题下可以承担不同的职责。《意向必然式》问的是意向资格是否成立，u21 在那里回答的是结构上经验的并用与切换由谁使役，归于资格；《意向作用必然式》问的是一次完整作用是否成立，u30 在那里回答的是作用能做什么，归于其余语义。本篇问的是 σ 上是否发生了一次意向欲门切换：u30 在这里回答的是“这一次是切换还是并用”，u21 回答的是“这一次切换由谁来使”，二者都直接决定这一次切换的真值。这不改变上游的分类，只是同一原子对本篇问题的回答。其余原子回答的是意向资格、关系、称名、位置、工作域、作用、动力、来源、表示、本体边界、后果或实现，不回答一次切换是否成立。

语料域申明：σ 上 IntentGateSwitch 的真值，由冻结切换语义域所给出的切换语义决定：在工作域 Intent = 1 内，正面取得的切换语义全部实现、且没有取消条件生效时，IntentGateSwitch\_F(σ) = 1。这是冻结语义域的含义，不是另加的前件。关于意向欲门切换的全部语义结论，只在 U\_IGS^src 上取得。若母本语料修订，或新增直接决定一次意向欲门切换真值的语句，按第十一节击穿一复审。这一限定是证明域的限定，不是 H。

四、分类规则

1\. 分类

每一个原子按它在“σ 上这一次意向欲门切换是否成立”这一问题上的职责，归入下列一类。

正面切换语义 U\_IGS^+：σ 上一次意向欲门切换成立，凭的是哪些事。按所回答的问题，本篇在语料中读出两个承重点：

U\_Switch　真实切换：σ 上是否真的发生了门从一个职责类到另一个职责类的切换，而不是第一次过门、同门继续、并用、新增，或者从不同序列拼出的两个门。  
U\_IntentBear　意向来使：这一次切换的“使之者”是否是意向自身，而不是外部完整选择器替意向定了后门，也不是意向只取得了新门而旧门恰由另一机制退出。

两个承重点不与 S1 至 S4 一一对应；它们是从语料中独立读出的，承重点的个数由语料决定，不为了与四项结构的数目一致而凑数。

取消侧：在正面切换语义全部实现时，能够单独使 IntentGateSwitch = 0 的原子。

其余语义 U\_IGS^O：切换的边界、切换之后的后果、切换与意识的时相关系。它们各有理论意义，但不承担“这一次切换是否成立”的普遍取得职责。

2\. 分类判准

（a）问题判准。看该原子回答的是“这一次切换凭什么成立”，还是“切换有没有自显”“切换以后发生什么”“切换与意识谁先谁后”。

（b）时相判准。看该原子说的是切换本身之内的事，还是切换之后的后果。

（c）删除判准。假设该原子所说的事在这一次切换中不出现，其余原子不变。如果语料中没有语句因此否认这一次切换成立，那么它不属于正面切换语义。本判准只用于复核按（a）已归入 U\_IGS^O 的原子。

（d）取消侧审查。如果某个原子在形式上像否定或像限制，需要专门审查：假设正面切换语义全部实现，它能否单独使 IntentGateSwitch = 0。如果它要生效就必然使某项正面语义失效，它就不是独立的取消条件。

3\. 不可约合取审查

单个原子分类以后，仍须检查冻结语料所授权的不可约合取。两个单独都不决定切换真值的原子，合在一起有可能产生新的效力，所以不能由“各部分都不是切换条件”推出“合取也不是切换条件”。如果有人主张某个合取承担新的取得职责或取消职责，就必须在冻结语料中找到明确授权这一组合承担该职责的依据；这种授权可以出现在同一句内，也可以由跨句的因果、条件、指代、总结或回指关系形成。

一个合取如果要成为第五项职责，还必须满足：在正面切换语义全部实现、四项与共绑定同时成立时，它不成立就使 IntentGateSwitch = 0，而这一取消并不表现为四项中任何一项或共绑定的退出。

五、原子逐项分类

1\. 正面切换语义

u30　经验可以并用，也可以切换。U\_Switch。Q3 把“并用”与“切换”并列为经验被调用的两种不同方式：并用是几个经验同时被调用，切换是从一个转到另一个。所以说一次切换，必须是从一个门转到另一个门，而且不能是并用：旧门还在承担，新门只是加了进来，那是并用或新增，不是切换。“切换”一词本身还排除了只有一个门的情形和前后同一个门的情形：没有从哪里切来，或者前后是同一个，都谈不上从一个转到另一个。它回答的是这一次是不是切换。

u21　让经验并用或切换的是意图。U\_IntentBear。Q3 说“使之者，意图也”：切换由意图来使。落到这一次切换上，它要求这一次门的改变由意向自身来使，旧门的让出与新门的取得都属于意向这一次的作为；外部替意向改了门，或者意向只走进了新门而旧门是别的机制退出的，都不是“意图使之”。它回答的是这一次切换由谁来使。

2\. 其余语义

u48　切换欲门的过程本身没有自显性。U\_IGS^O，边界。它说切换过程不带自显，不是说切换要有什么。

u49　切换到某个欲门以后，欲门后的组织中有显性回路参与，才发生显化。U\_IGS^O，后果。它规定的是显化的条件：切换到门以后，还要有门后的显性回路参与。句中“切换到某欲门”同时说明了切换的对象是欲门，并且到了门，切换就已经完成，这一点用于澄清 U\_Switch 的对象与完成点，不另外承担取得职责。

u50　意向作用发生在意识到之前。U\_IGS^O，时相边界。

3\. 取消侧审查

在形式上像否定或像限制的原子有 u48、u49、u50。

u48“没有自显性”：它否定的是切换过程的自显，不否定切换。假设正面切换语义全部实现而没有任何自显，语料中没有语句因此使 IntentGateSwitch = 0；相反，它说明切换本来就可以没有自显。

u49“才发生显化”：它规定的是显化的条件，不是切换的条件。它说显化晚于切换、依赖门后的显性回路，不说切换依赖显化。假设正面切换语义全部实现而门后没有显性回路参与，显化不发生，切换照样已经发生。

u50“发生在意识到之前”：I9 由“切换过程没有自显”“到门以后才显化”用“所以”推出这一句；切换是作用在欲门这一层的变化，同在意识到之前。它排除把意识到当作切换的条件。假设正面切换语义全部实现而尚未意识到，语料明说作用已经发生，切换也已经发生。

三者都不能在正面切换语义全部实现时单独使 IntentGateSwitch = 0。

4\. 分类汇总

&nbsp;&nbsp;&nbsp;&nbsp;U\_IGS^+ = { u21, u30 }  
&nbsp;&nbsp;&nbsp;&nbsp;U\_IGS^O = { u48, u49, u50 }  
&nbsp;&nbsp;&nbsp;&nbsp;取消侧：空集

&nbsp;&nbsp;&nbsp;&nbsp;U\_IGS^src = U\_IGS^+ ⊎ U\_IGS^O

六、切换语义闭合

1\. 定理一　意向欲门切换语义闭合定理

在冻结切换语义域 U\_IGS^src 上：σ 上一次意向欲门切换的正面语义正好是 u30 所给的真实切换与 u21 所给的意向来使；其余原子不决定每一次切换的真值；取消侧为空；并且冻结语料中不存在承担第五项职责或取消职责的不可约合取。即：

&nbsp;&nbsp;&nbsp;&nbsp;U\_IGS^+ = { u21, u30 }，　U\_IGS^O = { u48, u49, u50 }  
&nbsp;&nbsp;&nbsp;&nbsp;FifthIndependentIGSDuty\_I = ∅，　IndependentCancel\_IGS = ∅

证明

第一，正面语义已经穷尽。U\_IGS^src 是有限集合，五个原子都已按第四节的判准归类。归入正面的只有 u30、u21；其余三个按判准（a）（b）归入边界、后果或时相关系，并经判准（c）复核：一次切换没有自显，没有在切换以后发生显化，或者尚未被意识到，语料中都没有语句因此否认切换已经发生。

第二，单原子不承担第五项职责。u30 承担“是切换而不是并用、不是第一次过门、不是同门继续”；u21 承担“由意向自身来使”。u48 是切换过程的边界，u49 是切换以后显化的条件，u50 是作用与意识的时相关系；它们都不是每一次切换的普遍取得条件。

第三，取消侧为空。u48、u49、u50 已按判准（d）逐项审查。以下候选也都不是独立的取消条件：

切换以后止于门处，没有进入门后的调谐使役：由 u49，“切换到某欲门”在门后发生什么之前就已经成立。  
没有显化：由 u48、u49，切换可以先于显化，显化是门后显性回路参与的后果。  
没有意识到：由 u50，作用发生在意识到之前。  
调谐没有成功、经验最终没有改变、没有行为或效应：这些都在门后，属于切换以后的事。  
旧门在系统别处、其他并用链或其他职责中仍在活动：u30 区分并用与切换，是就同一次被比较的门变化而言；别处的并用不使这一次的切换变成并用。  
前后之间有时间空档：语料没有要求切换必须无缝。  
过渡阶段有短暂的重叠：u30 区分的是切换的结果是从一个转到另一个，还是两个同时被调用；过渡中短暂并存，只要后态旧门已经让出，结果仍是切换。  
新门不是当前率最大的方向所对应的门，旧方向的率值没有降到零：语料没有以率值决定切换；意向不读取概率，率值不是切换的条件。  
外界刺激参与诱发：u21 要求“使之者”是意向；外界可以诱发，承担这一次切换的仍可以是意向自身。  
默想、思考、内观、回顾或已显化的经验经合法回路返回，诱发了这一次切换：这是诱发的来源，不是承担者；只要随后的源动、概率与过门仍由意向自身承担，u21 照样实现。  
同一条 σ 上另有候选，系统中另有合法的作用链：语料没有要求一次只有一个候选或一条链。

第四，不存在承担第五项职责或取消职责的不可约合取。这里审查的不是“同一句中同时出现的多个原子”，而是冻结语料是否在两个以上原子之间给出了联合授权，即把这些原子的共同成立本身作为取得或取消这一次切换的依据。

先审查同句授权。

Q3 把 u30“可以并用，亦可切换”与 u21“使之者，意图也”写在一句里。合起来说的是：经验的并用与切换都由意图来使。落到一次切换上，就是“这一次是切换”与“这一次由意向来使”两件事，正是 U\_Switch 与 U\_IntentBear；句子没有在二者之外另加第三件事，例如切换必须同时伴随并用、必须有某种结果，或者必须在某个时刻完成。

I9 把 u48、u49、u50 写在一句里，全部属于 U\_IGS^O。句子的结论是“意向作用发生在意识到之前”，它恰好排除了把显化或意识到加为条件的读法，没有授权这些边界与后果的组合承担切换的取得职责或取消职责。

再审查正面原子与其余原子之间的合取。u21 ∧ u48、u21 ∧ u49、u21 ∧ u50：“意图使之”与“切换无自显”“切换以后才显化”“作用先于意识”放在一起，只说意向来使的切换可以无自显、可以先于显化与意识，不产生第三种取得职责。u30 ∧ u48、u30 ∧ u49、u30 ∧ u50：“是切换而不是并用”与这些边界放在一起，只说切换是一种与显化分层的门的变化，不产生新的切换条件。u48 ∧ u49、u49 ∧ u50、u48 ∧ u49 ∧ u50：冻结语料没有授权这些组合本身决定切换的真值。

再审查跨句授权。Q3 与 I9 的关系是：Q3 说切换由意图来使，I9 说切换的过程没有自显、到门以后才有显化、作用先于意识。I9 中的“切换到某欲门”承接 Q3 的“切换”，说明切换的对象是欲门、到门即完成，只用于澄清 U\_Switch 的对象与完成点；没有任何跨句关系把两个以上原本不决定切换真值的原子的共同成立，另外授权为第五项职责或独立的取消条件。

真正能阻断意向欲门切换的情形，都通过使某项正面语义失效而生效：只有一个门、前后同门、旧门仍在承担而新门只是加入、前后取自不同的序列，u30 不实现；后门由外部替意向选定，或者旧门的退出由另一机制单独承担，u21 不实现。这些是正面语义的缺失，不是独立的取消条件。

综合以上四点，定理一得证。□

这一结论是本篇在冻结切换语义域上独立取得的，不引用《意向欲门切换一般式》的同名检查结果。

七、语义实现

1\. 定理二　意向欲门切换语义实现定理

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) ⇒ u30 ∧ u21

具体为：

&nbsp;&nbsp;&nbsp;&nbsp;S1 ∧ S2 ∧ S3 ∧ B\_same^IGS ⇒ u30  
&nbsp;&nbsp;&nbsp;&nbsp;S2 ∧ S4 ∧ B\_same^IGS ⇒ u21

两条都在同一条 σ、同一组见证 (w\_a, w\_b, \[G\_a\], \[G\_b\]) 上读取。两条都是跨项的联合实现：一次真实切换的完整含义，需要前门、后门、旧门的退出与同一序列共同落成；意向来使的完整含义，需要后门由意向自身取得、旧门的让出与新门的取得同属 w\_b 上那一次续行所对应的现实门交接，并且前后属于同一条序列。不能伪造成“每一项单独实现一个完整的语义原子”。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;S1    S2    S3    S4    B\_same  
&nbsp;&nbsp;&nbsp;&nbsp;u30       ✓     ✓     ✓           ✓  
&nbsp;&nbsp;&nbsp;&nbsp;u21             ✓           ✓     ✓

证明

第一，S1 ∧ S2 ∧ S3 ∧ B\_same^IGS ⇒ u30。

S1 给出：σ 的前态中有一次现实合法的过门，经过 \[G\_a\]，Pass\_σ^-(\[G\_a\]) = 1。所以有“从哪里切来”，不是第一次过门。

S2 给出：σ 的后态中有一次现实的过门，经过 \[G\_b\]，Pass\_σ^+(\[G\_b\]) = 1。所以有“切到哪里”。

S3 给出：\[G\_a\] 在 σ 的后态中不再承担过门，Pass\_σ^+(\[G\_a\]) = 0。所以旧门让出了，新门不是在旧门仍在时加进来的；这排除了并用与新增。

由 S2 ∧ S3，\[G\_a\] ≠ \[G\_b\]：若二者是同一职责类，同一职责在同一后态上既承担又不承担，矛盾。所以前后是两个不同的门，不是同门继续；比较的是职责类，物理节点更换而职责不变的情形也已排除。

B\_same^IGS 给出：前后两端同锚、有序、属于同一条 σ、不跨资格组织。所以前态与后态是同一次门变化的前后，不是从两条独立的作用链或两个组织拼出来的。

合起来：在同一条 σ 上，门从 \[G\_a\] 转到了另一个职责类 \[G\_b\]，旧门让出，新门承担，前后属于同一次门变化。这就是 u30 所说的切换，而不是并用；由此也得到一般的门位切换：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) ⇒ GateSwitch\_F(σ)

这一步没有用到 S4。一般的门位切换不问是谁做的，S4 的承重在下一步。

第二，S2 ∧ S4 ∧ B\_same^IGS ⇒ u21。

S2 给出：后态见证 w\_b 上，A1(w\_b) ∧ A2(w\_b) ∧ A3(w\_b, \[G\_b\])。也就是说，w\_b 上的那一次续行是意向自身的源动职责现实发生并进入 𝒫\_I，概率组织在同一次续行中承担了诸方向之间的相对生成，由此形成的方向沿正式对应进入 \[G\_b\]。新门不是外部完整选择器替意向选定的，而是意向自身经源动、概率、方向这一条链走进去的。

但只有 S2 还不够。意向可以自己走进 \[G\_b\]，而 \[G\_a\] 恰好由另一个机制退出；这时新门是意向取得的，旧门的让出却不在意向这一次续行的门交接之内，两件事只是凑在一起，不能说这一次切换是“意图使之”。

S4 给出：σ 后态中 \[G\_a\] 的承担状态与 \[G\_b\] 的取得，同属 w\_b 上的同一次现实门承担事件，\[G\_a\] 的后态承担状态不由另一独立机制单独承担。S4 中 w\_b 上的那一次事件，就是 S2 中 w\_b 上的那一次续行：二者由同一个后态见证 w\_b 指认，S2 读这一次续行的内部链，S4 读这一次事件承担了什么。所以旧门的让出与新门的取得，同属由 S2 所识别的那一次意向自身续行上的现实门交接。

B\_same^IGS 给出：这一后态的交接与 S1 的前态属于同一条 σ、同一资格组织，不是从别处拼来的。

合起来：这一次门从 \[G\_a\] 到 \[G\_b\] 的改变，其中旧门的让出与新门的取得，同属 w\_b 上这一次意向自身续行所对应的现实门交接。这就是 u21 所说的“使之者，意图也”落到这一次切换上的含义。

S2 与 S4 在这里缺一不可。S2 只能说明新门由意向自身取得，不能说明整次切换由意向承担；S4 只能说明旧门的状态与新门的取得属于同一次事件，不能说明这一次事件是意向自身的续行。二者在同一 w\_b 上联合，才把“意图使之”落实为这一次切换的现实承担。

第三，同一序列与同一见证。N\_IGS(σ) 的前件是 ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]，σ 由主命题固定，而不是 (∃ S1) ∧ (∃ S2) ∧ (∃ S3) ∧ (∃ S4)。所以上面两条实现都发生在同一条 σ 的同一次门变化中：门真的从一个切到了另一个，并且这一次切换由意向自身来使。这证明的不是“几件事曾分别发生”，而是一次意向欲门切换。

综合以上三点，N\_IGS(σ) ⇒ u30 ∧ u21，即 N\_IGS(σ) 完整实现 U\_IGS^+。□

2\. S4 的空洞情形不承重主定理

《意向欲门切换一般式》为了说明 S1 不被其余各项吸收，允许一种世界：σ 上本没有 \[G\_a\] 的承担，S3、S4 只是空洞地成立。《意向欲门切换数理式》相应地设了 S4 的空洞归属支，只在旧门状态域确认为空时开放。

3\. 门职责不同不是第五项条件

不另立“前后两门职责不同”作为第五项前件。它已由 S2 ∧ S3 推出，并在第一条实现中承重；若再另立一项，就会重复计算 S2 与 S3 已经实现的内容。同样，不另立“切换已经完整”作为前件：到门即完成（u49），切换的闭合已经在 S2 的过门、S3 的旧门让出与 S4 的交接归属之中。

九、边界例

以下各例都以固定的 σ 为准。

1\. 第一次过门

后态由意向自身走进 \[G\_b\]，σ 的前态没有任何过门。S1 不成立，N\_IGS(σ) = 0，不落入定理三的前件，不构成反充分世界。

2\. 同门继续

前态通过 \[G\_a\]，后态由意向自身的续行再次走进 \[G\_a\]。S3 不成立，N\_IGS(σ) = 0，不构成反充分世界。

3\. 并用与新增

后态中意向自身新取得 \[G\_b\]，而 \[G\_a\] 在 σ 的后态仍承担过门；或者 \[G\_b\] 属于与前态无关的另一条序列。S3 或 B\_same^IGS 不成立，N\_IGS(σ) = 0，不构成反充分世界。

4\. 外部强制改门

前态通过 \[G\_a\]，外部完整选择器或普通强制门控直接把门态改到 \[G\_b\]，旧门随之退出。这时 GateSwitch\_F(σ) 可以成立，S1、S3、S4 都可以成立，但 S2 不成立，N\_IGS(σ) = 0，IntentGateSwitch\_F(σ) = 0。这是一般的门位切换，不落入定理三的前件，也不构成反充分世界。

5\. 巧合退出

后态由意向自身取得 \[G\_b\]，\[G\_a\] 在 σ 后态确实退出，但旧门的后态状态由另一独立事件承担。S1、S2、S3 成立，S4 不成立，N\_IGS(σ) = 0，不构成反充分世界。

6\. 跨序列与跨组织拼接

前态取自作用序列甲，后态取自与之独立的作用序列乙；或者前后分属两个资格组织。B\_same^IGS 不成立，N\_IGS(σ) = 0，不构成反充分世界。

7\. 物理重实现

前后的物理节点不同，而 GateRoleID 相同。旧门的职责在后态仍承担，S3 不成立，N\_IGS(σ) = 0；这不是职责的切换。同一物理载体前态承担 \[G\_a\]、后态承担 \[G\_b\]，其余各项成立时，N\_IGS(σ) = 1，IntentGateSwitch\_F(σ) = 1。

8\. 到门而止

N\_IGS(σ) = 1，而后态那一次作用随后止于门处，没有进入门后的调谐使役。IntentGateSwitch\_F(σ) = 1：到门切换即完成，作用不完整不取消切换。

9\. 无显化、无意识到、无结果

N\_IGS(σ) = 1，门后没有显性回路参与，系统尚未意识到，调谐没有成功，经验没有改变，没有行为或效应。IntentGateSwitch\_F(σ) = 1。

10\. 旧门在别处仍活动

N\_IGS(σ) = 1，系统别处另有一条合法作用链仍通过 \[G\_a\]，它不属于 σ 的后态。IntentGateSwitch\_F(σ) = 1：这是 σ 上的局部切换，不要求旧门全局失活。

11\. 时间空档与短暂重叠

N\_IGS(σ) = 1，前后之间有一段空档，或者过渡中旧门与新门短暂并存，但后态评价中旧门已经让出。IntentGateSwitch\_F(σ) = 1。

12\. 外界诱发、直接源动与显式重入

外界刺激改变了场态，诱发意向自身的新源动续行改向；或者没有外部扰动，由当前场态与既成的沉积关系直接引起源动续行改向；或者默想、思考或已显化的经验经合法回路返回，改变了意向当前的动力状态，随后新的源动仍经同一个概率化律生态改向。只要 S2 的 A1、A2、A3 在 w\_b 上成立，并且 S4 的交接同属 w\_b 上这一次续行所对应的现实门交接，N\_IGS(σ) = 1，IntentGateSwitch\_F(σ) = 1。若所谓重入绕过源动与概率直接指定了后门，S2 不成立，不落入前件。

13\. 多候选与率值

同一条 σ 上有几个候选，其中一个满足 N\_IGS(σ)；新门不是当前率最大的方向所对应的门；旧方向的率值没有降到零。IntentGateSwitch\_F(σ) = 1。不要求唯一候选，不以率值判切换。

14\. 附带后果

N\_IGS(σ) = 1，同时切换以后发生了显化、行为与效应。IntentGateSwitch\_F(σ) = 1；后果的出现不改变切换的成立。

主定理不继承 H\_PAct-Rep。它只承重《意向欲门切换数理式》中 S2 的 A2-PDuty 反证路径的负向结构回读，以及由此传导到 N\_IGS(σ) = 0、IntentGateSwitch\_F(σ) = 0 的负向结论；本篇主定理直接以对象层的 N\_IGS(σ) = 1 为前件，不经过任何负向回读。形式入口走的是正向回读，同样不调用 H\_PAct-Rep。

主定理不继承 H\_LawRead：主定理不从形式读数开始。

主定理不继承 H\_PL、H\_SD、H\_GP、H\_TI：那四座桥回答的是怎样从更弱的跨实现职责取得意向资格的结构；本篇的工作域已经给定 Intent = 1，必要核直接给定 S1 至 S4 与共绑定。

冻结切换语义域、工作域 Intent = 1 与固定的比较序列 σ，是证明域、工作域与比较协议的限定，不是 H。

主定理 Status = Established。

双向式 Status = Established。

形式层推论 Status = Conditional，条件为所用 Law-bearing 见证适用的 H\_LawRead(W\_i)。

十一、击穿

直接击穿主定理的情形是：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) = 1 ∧ IntentGateSwitch\_F(σ) = 0

按发生的层次分为以下几类。任何一类出现，都必须重新审查：

击穿一　语义域遗漏：冻结切换语义域之外，存在已属当前理论、且直接决定一次意向欲门切换真值的语句，不能归入 U\_IGS^+ 或 U\_IGS^O。

击穿二　第五职责反例：存在一个有冻结语料依据的单原子或不可约合取，在四项与共绑定同时成立时，仍是 IntentGateSwitch 的普遍额外取得条件。

击穿三　实现映射失败：N\_IGS(σ) = 1，而 GateSwitch\_F(σ) = 0，或者这一次切换的现实承担不归于意向自身，说明第七节的映射有误。

击穿四　反充分世界：存在合法的 w，N\_IGS(σ, w) = 1 而 IntentGateSwitch\_F(σ, w) = 0。

击穿五　独立取消反例：存在 X，四项与共绑定全部保持，X 仍独立使 IntentGateSwitch\_F(σ) = 0，而且 X 有冻结语料的授权。

以下错误写法也击穿本篇：把 IntentGateSwitch 定义为 N\_IGS(σ)；以《意向欲门切换一般式》的“没有第五项职责、没有独立取消条件”作为主证明的前提；以 Read\_{N\_IGS(σ)}^M = 1 直接充当主证明的前件，而不经《意向欲门切换数理式》回读到对象层的 N\_IGS(σ)；把 H\_PAct-Rep 加入本篇的主充分方向；由 Intent = 1 与 GateSwitch\_F(σ) = 1 直接推出 IntentGateSwitch\_F(σ) = 1，绕过 S2 与 S4；把 u21 完全归给 S2，丢掉 S4 对“旧门的让出与新门的取得同属这一次门交接”的承担；把 u30 完全归给 S3，丢掉 S1、S2 与共绑定对“从哪里切到哪里、同一次门变化”的承担；在主证明中让 S4 的空洞情形承重，忽略 S1 已经给出真实的前门；把“前后两门职责不同”或“切换已经完整”另立为第五项前件；把门后的调谐使役、调谐成功、显化、意识到、经验改变、行为或效应加入充分前件；把最大率、率值交叉、阈值或旧方向率值归零加入充分前件；要求旧门全局失活；要求切换无空档或无过渡重叠；把外界诱发或显式重入本身判为外部承担，即使 S2 与 S4 都由意向自身承担；要求一条 σ 上只有唯一的候选；把切换候选的个数当作意向的计数；由一条 σ 上的结论推出其他比较序列上的结论。

以下情形不构成击穿：

Read\_{N\_IGS(σ)}^M = ⊥：这只是形式材料不足。

外部强制改门是 GateSwitch 而不是 IntentGateSwitch：它的 S2 不成立，不落入前件。

切换以后止于门处，没有显化、没有意识到、没有调谐结果或行为：这些不属于切换的取得条件。

旧门在别处仍被使用，前后之间有空档，过渡中短暂重叠，新门非最大率，外界或重入参与诱发，同一条 σ 上有多个候选：这些都不取消切换。

满足四项与共绑定中的一部分而 N\_IGS(σ) 不成立的世界：它们不落入主定理的前件。

十二、接口

《意向欲门切换一般式》：本篇使用其 N\_IGS(σ)、S1 至 S4、B\_same^IGS、门职责差异推论、IntentGateSwitch 与 GateSwitch 的层级与切换语义的冻结范围；其必要方向与其中的闭合检查只作一致性回测，不承重主证明。两篇合成 IntentGateSwitch\_F(σ) ⇔ N\_IGS(σ)。

《意向欲门切换数理式》：Read\_{N\_IGS(σ)}^M 与正向回读只作形式入口；经该篇定理 6 与本篇定理三，Read\_{N\_IGS(σ)}^M = 1 ⇒ IntentGateSwitch\_F(σ) = 1，携所用见证的 H\_LawRead(W\_i)。

《意向作用一般式》《意向作用必然式》：本篇的 S2 调用其 A1、A2、A3；意向作用的闭合 IntentAct ⇔ N\_IAct 不进入本篇的前件，切换不要求一次完整的意向作用。

《意向动力一般式》《意向动力数理式》《意向动力必然式》：接收 IntentGateSwitch\_F(σ) ⇔ N\_IGS(σ) 的对象层闭合，研究切换怎样开始、进行、竞争、失败、恢复与持续，以及直接源动与显式重入两种诱发怎样启动一次切换。

《意向判定式》：可把 N\_IGS(σ) 作为 IntentGateSwitch\_F(σ) 的对象层判定核心；形式正入口经《意向欲门切换数理式》与本篇得到 IntentGateSwitch\_F(σ) = 1，携所用见证的 H\_LawRead。

《意向运行基底构造式》：若运行基底真实构造出对象层 N\_IGS(σ) = 1 的合法见证组，由本篇可判 IntentGateSwitch\_F(σ) = 1；形式数据入口仍须遵守《意向欲门切换数理式》的回读条件与可解性条件。
