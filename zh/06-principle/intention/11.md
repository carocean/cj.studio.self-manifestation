# 意向动力数理式

一、目的

为意向动力的必要结构建立形式系统，使任一已经取得意向资格的申报实例，在一段事前申报的真实运行轨迹 γ 上，合法动力段的六项、源动发生动力、载体动力、意向概率动力三处，以及由三处运行出来的作用投影、类型化的增强与减弱、欲门切换的调用，都可以形式求值，并得到成立（1）、不成立（0）或材料不足（⊥）的确定读数。其中概率一处的 0 在结构层上的否定强度，携带《概率动力一般式》必要方向的条件与上游失败路径所携的反向表示条件；载体一处与资格整段保持一项的 0，按上游实际的负向路径承继条件；其余各项的 0 不携带条件。

所形式化的结构是：

&nbsp;&nbsp;&nbsp;&nbsp;IntentDyn\_F^γ(K\_I) ⇒ N\_IDyn^γ  
&nbsp;&nbsp;&nbsp;&nbsp;N\_IDyn^γ := LegalIntentDynSegment\_F^γ(K\_I; Γ\_IDyn) ∧ DynActual\_I^γ  
&nbsp;&nbsp;&nbsp;&nbsp;DynActual\_I^γ := SourceOccurrenceDyn\_I^γ ∨ CarrierDyn\_I^γ ∨ IntentProbDyn\_I^γ

合法动力段由六项组成：L1 真实轨迹，L2 合法运行，L3 同锚，L4 资格整段保持，L5 同轨取证，L6 协议冻结。三处互不吸收，以析取出现。作用的开始、继续、停止、重启，方向型与载体型的增强与减弱，是三处在运行中的投影；欲门切换是调用源动当前发生与概率职责当前兑现的门层事件，它在跨时上是否构成三处中的动力，须由 γ 上相应的跨时子段另行判定。这些都不是另外的轴。

形式目标为：

&nbsp;&nbsp;&nbsp;&nbsp;S\_IDyn ↦ M\_IDyn

即：给出合法动力段六项与三处的形式判据，在同一真实运行上求值；源动一处读评价单元内的现实源动续行，并以真实的起始、续行与停止记录分辨其跨时类型，不以单元的端态代替跨时事实；载体一处与概率一处调用律动力与概率动力的已有形式系统；给出各运行投影的形式判据；给出候选的枚举、负读出所需的覆盖、求解程序与三值回读规则。

二、核心论题

给定已经成立的意向资格及其申报实例，以及一段在求解以前冻结了评价点、评价单元、连续粒度与比较协议的真实运行轨迹 γ，怎样从运行实例与分支的记录、状态更新与来源历史、各评价单元内的现实事件与源动职责实现、正式方向承担律的程度读数、同一 𝒫\_I 的概率动力读数、各时间窗的意向作用读数，以及比较序列上的欲门切换读数中，求得“γ 是同一意向的合法动力段，并且三处至少有一处在 γ 上真实地动”的形式真值，并严格区分结构失败 0 与形式材料不足 ⊥？

M\_IDyn 须精确表达：

（1）三处的区分。源动一处只读意向自身源动职责的现实续行及其起、续、止，不读概率职责是否兑现；载体一处只读正式方向承担律在其方向职责上的程度动力，不读成员律的起、续、止；概率一处只读同一 𝒫\_I 的概率动力，不读场中别的概率组织。三处各有只取 1 的世界，所以在顶层以析取合成，不排成递进。

（2）跨时与端态的区分。三处读的都是真实子段上的事，不以两个端点或两个单元的读数代替。两个相邻单元各有源动发生，不推出源动跨两单元持续，其间可以真实地停发又再起；一个单元有发生、下一个单元没有找到发生，也不推出停止。持续、开始与停止，都由真实续行子段与事前冻结的连续粒度判定，停止与开始还须相应时间窗的负覆盖。载体一处与概率一处沿用上游对相邻评价点的逐步比较与段内实际行使的纪律。

（3）存在与分类的区分。一处动力是否发生，与它属于开始、继续还是停止，是两个问题。一段落在 γ 内的真实非零源动续行，足以确定源动在 γ 上有跨时的动；它在某一时刻属于开始、继续还是停止，须有相应的跨时证据。分类未决，不洗掉已经确定的发生；发生已经确定，也不凭端态补写未证的分类。

（4）投影与轴的区分。作用投影、类型化的增强与减弱、切换的调用都在三处的读数之旁求值，只报告，不反过来决定三处的读数，也不进入必要核的读数。

（5）类型与总量的区分。增强与减弱只有方向型与载体型两类，各落在已封的对象上；若申报了合成剖面，只能作乘积偏序，混合升降为不可比，某一必需坐标在对象上没有可比较的关系时记不适用，不与材料不足混同；本系统不输出任何意向总强度。

（6）失败与不足的区分。没有找到正证据，不等于正证据不存在；负读出必须有覆盖。申报本身失格，只能要求重新申报，不能读成意向动力的结构失败。拿来的概率证据属于另一对象，只说明这份证据不能用，不说明本申报的 𝒫\_I 没有概率动力；三处的承重证据取自不同的运行或资格锚而被共同采用，这一组拼接材料不能取得同一意向的动力证书，但也不说明 γ 上没有意向动力。证据身份的错配只能使证书失败，不能制造对象层的否定。

须在形式上区分下列几组对象：

&nbsp;&nbsp;&nbsp;&nbsp;端态读数 ≠ 子段中的实际发生  
&nbsp;&nbsp;&nbsp;&nbsp;单元中曾有发生 ≠ 跨单元持续  
&nbsp;&nbsp;&nbsp;&nbsp;源动发生 ≠ 概率作用  
&nbsp;&nbsp;&nbsp;&nbsp;成员律的作用动力 ≠ 方向承担律的程度动力  
&nbsp;&nbsp;&nbsp;&nbsp;场中的概率动力 ≠ 同一 𝒫\_I 的概率动力  
&nbsp;&nbsp;&nbsp;&nbsp;外来证据不合用 ≠ 本对象没有动力  
&nbsp;&nbsp;&nbsp;&nbsp;相对生成关系的变化 ≠ 率值的变化  
&nbsp;&nbsp;&nbsp;&nbsp;方向型增强 ≠ 载体型增强  
&nbsp;&nbsp;&nbsp;&nbsp;当前切换事件 ≠ 跨时动力的分类  
&nbsp;&nbsp;&nbsp;&nbsp;读出 ≠ 写入

本系统表示的是意向动力的必要结构，不证明它的充分方向。可以区分和计数的，是运行、子段、评价点、评价单元、时间窗、事件、源动职责实现、承担律、评价与比较坐标；本系统不计算意向的强度。

2\. 定义序列

动力的求值对象，是已经取得意向资格的申报实例在一段真实运行上的变化。所以在求解以前冻结的，是对象与职责的身份、候选域、读法、评价点、评价单元、连续粒度、比较规约与归属规则；看到运行结果以后不得改写。本来就是动力所要读的运行状态，不在冻结之列：正式方向的身份体系可以冻结，某一方向在某一时刻由哪一条律实际承担，可以依法变化；候选载体域可以冻结，实际的承担状态不能冻结；Rel\_ρ 的表示协议可以冻结，Rel\_ρ 本身不能冻结。

定义 1（动力求解实例）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;χ\_IDyn^M := (χ\_I, γ, Γ\_IDyn)

χ\_I 是已经建立的意向资格申报实例，其中含沉积场 F、资格锚 K\_I^M、𝒫\_I、C\_I、𝔯\_I、正式方向族 V\_I、源动职责类 \[S\_I\]\_src、欲门职责商类 𝒢̄\_I；γ 是被申报的真实运行轨迹段；Γ\_IDyn 是事前冻结的协议，至少冻结：资格锚与资格组织的身份；\[S\_I\]\_src 与 SrcRoleID 的版本；正式方向职责的身份体系与 GateRoleID 的版本；载体候选域的发现规则及其 BearDim 读取规则；评价点 T\_γ、评价单元的划分与连续粒度 δ\_src、δ\_act；场的运行协议与许可的操作；同证据键的方案；每一载体候选的程度规约；概率一处所用的 Γ\_PDyn^I；方向比较实例；若申报合成剖面，则其坐标集与坐标的定义域规则；作用与切换投影的绑定规则；覆盖协议；申报边界。Γ\_IDyn 不冻结运行中实际的承担状态、程度、Rel\_ρ、正式维的当前组织、共同绑定、率承担组织、作用状态或门的承担状态。Γ\_IDyn 是求解协议，不是动力职责，不是本体谓词。χ\_IDyn^M 是一般式动力申报 χ\_IDyn = (F, K\_I, γ, Γ\_IDyn) 的形式登记。

进入条件：在 γ 的起点，Intent\_{F,t\_0} = 1。本系统不重新求意向资格的成立；资格在整段上是否保持，由 L4 求值。

定义 2（运行数据包）\[辅\]

&nbsp;&nbsp;&nbsp;&nbsp;Ω\_IDyn^γ := (RunID, BranchID, χ\_IDyn^M, T\_γ, {I\_k}, U\_γ, {S\_k}, ℰ\_γ, ℋ\_γ)

RunID 是实际运行实例的标识，BranchID 是实际历史分支的标识，ℰ\_γ 是实际事件记录，ℋ\_γ 是状态更新、操作、来源与协议冻结的历史，S\_k 是评价点 t\_k 的正式状态快照。这些输入由场系统与运行基底提供，本系统不另建物理运行系统。Ω\_IDyn^γ 只是求解输入的组织形式，不是新的本体。

定义 3（评价点、评价单元与连续粒度）\[辅\]　T\_γ := (t\_0, …, t\_n)，n ≥ 1，是事前冻结的评价点；I\_k 是真实运行中连接 t\_k 与 t\_{k+1} 的实际子段。U\_γ := (u\_1, …, u\_m)，m ≥ 1，是事前冻结的评价单元序列：每一个 u\_j 都是 γ 内一段非零宽的实际子段，各单元按时间先后排列，互不重叠，合起来无间隙地覆盖 γ。评价单元是源动发生与覆盖的读取粒度，不是连续的定义：两个相邻单元各有发生，不表示发生跨两单元持续。δ\_src \> 0 与 δ\_act \> 0 是事前冻结的连续粒度，即一般式“连续的粒度由 Γ\_IDyn 冻结”的形式登记：同一职责的两次现实续行之间的间隙短于这一粒度，算连续发生；一段长度不小于这一粒度的间隙，若经负覆盖确认其中没有发生，算停发。时间窗指 γ 内长度不小于相应连续粒度的实际子段；Γ\_IDyn 规定，每一个评价单元与每一个这样的时间窗，都是《意向作用数理式》意义下的合法作用申报单元。

定义 4（同证据键与同证据绑定）\[辅\]　每一份承重记录 r 都携带它的同证据键

&nbsp;&nbsp;&nbsp;&nbsp;K^IDyn(r) := (K\_I^M, RunID, BranchID, γ, Γ\_IDyn 版本, 所属子段、单元或时间窗)

SameIDynBind^M(x) 对一个读数 x 实际采用的全部承重记录求值：取 1，这些记录的键与申报的 K\_I、RunID、BranchID、γ、Γ\_IDyn 一致，并彼此一致；身份材料完整，且 x 的某一份必要承重记录明确来自另一资格锚、另一运行、另一分支、另一申报段或另一协议版本，取 ⊥（EvidenceSplice）；身份本身不可判，取 ⊥（EvidenceKeyOpen）。本读数不取 0：确认一份记录是外来的，只确定它不能证明本对象，不确定本对象没有相应的事实。数据包中与当前求值无关、未被采用为承重的外来记录，不进入 x 的承重记录集，忽略即可；各处的候选只从携带本申报键的记录中枚举。下文凡说“绑定”，都指对相应读数所用记录的 SameIDynBind^M。凡以 ∧₃ 与绑定读数合取的读数，包括 SrcOcc^M 的候选项、Q^Car 与各投影的见证，绑定不为 1 时，该读数取 ⊥，不因其余分量为 0 而取 0：拿错的或身份不明的材料，不作正证据，也不作负证据。

合法动力段把一般式的 L1 至 L6 落到运行记录、更新历史、资格读数与协议历史上。

定义 5（L1，真实轨迹）\[S\]　Read\_{ActualTrajectory}^M：取 1，可以核实 γ 的全部子段属于同一 RunID 与同一 BranchID，各 I\_k 真实存在，Begin(I\_k) = t\_k，End(I\_k) = t\_{k+1}，相邻子段在实际历史上连续接合，即存在真实运行轨迹 τ 使 γ = τ\|\_{\[t\_0, t\_n\]}；取 0，申报的 γ 本身有明确的跨运行、跨分支、复走或快照拼接；其余取 ⊥，例如运行或分支的记录不可取得。

定义 6（L2，合法运行）\[S\]　Read\_{AdmissibleIntentRun}^M：对每一子段取得真实的更新证书，含操作、来源链、协议引用与权威状态的写入历史。取 1，γ 内全部承重状态的更新都属于 Γ\_IDyn 许可的场运行或运行操作，并有可追踪的来源链，且没有绕过场的运行、直接写入并成为权威底层状态的下列对象：源动发生，律的程度，相对生成关系，正式维、共同绑定或率承担组织，作用、切换或反持，以及任何动力标签；取 0，有明确的非法直写、标签注入或越过底层机制的状态篡改；其余取 ⊥，例如来源链或写入历史不可取得。被动产生的事件日志、审计记录、读出缓存与派生证书可以存在，只要它们只记录已经发生的运行，不成为驱动底层状态的来源。环境扰动经场的合法接口进入，有可追踪的来源链，属于合法运行。不得因为“没有发现非法操作”签 1。

定义 7（L3，同锚）\[S\]　Read\_{FixedIntentAnchor}^M：取 1，在全部评价点上 F、K\_I^M、𝒫\_I、C\_I、𝔯\_I、\[S\_I\]\_src、正式方向职责的身份体系与欲门职责的身份体系，都是同一资格锚的引用；取 0，资格锚、概率组织、源动职责、正式方向职责体系或欲门职责体系的引用有跨组织的更换；其余取 ⊥。正式方向的当前承担者、承担律的程度、Rel\_ρ、正式维的当前组织、共同绑定、率承担组织、作用状态与门的承担状态都不列入同锚：它们正是允许依法变化、并被动力所读取的状态。

定义 8（L4，资格整段保持）\[S\]　Read\_{IntentQualWholeSegment}^M：取 1，在全部评价点 t\_k 上 IntentCoreCert^M = 1，并且资格变化事件的记录覆盖整段 γ（QualEventCover^M = 1），其中没有资格退出或重新形成的事件；取 0，某一评价点上 IntentCoreCert^M = 0，或者有资格退出、重新形成的现实记录；其余取 ⊥。某一评价点读不出资格，只取 ⊥，不取 0；不得只检查 t\_0 与 t\_n。资格变化事件的记录是本项能从离散评价点推到“全部场态上保持”的根据，没有它，本项不能取 1。

定义 9（L5，同轨取证）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{SameIDynEvidenceRun}^M := ∧₃ SameIDynBind^M(x)

x 遍历本次求值实际采用的全部承重证据组，包括合法段其余五项与三处的读数所用的证据。全部同轨取 1；有被实际采用的跨锚、跨运行、跨分支或跨申报段的承重材料，取 ⊥（EvidenceSplice）；身份不可判取 ⊥（EvidenceKeyOpen）。本项不取 0。这正是一般式 W-ID6 的形式表示：从不同处取来、拼在一起的材料，不能取得同一意向动力的证书；它不是“γ 上没有意向动力”的证明。须以同轨材料重新求值。本项是证据的身份守卫，不是第四处动力。

定义 10（L6，协议冻结）\[S\]　Read\_{FrozenIDynProtocol}^M：取 1，Γ\_IDyn 的冻结时间早于一切承重评价，全程版本一致；没有事后增删评价点、评价单元或时间窗，没有事后改变单元的划分与连续粒度；没有事后改写载体候选域的发现规则、职责身份规则、程度规约、Γ\_PDyn^I、方向比较集、剖面坐标、覆盖规则或归属规则；求值所用的索引与申报的索引相同；取 0，有明确的事后修改、对不利评价点的删选、候选域的事后扩大或缩小、职责身份的重新指定或比较规则的改变；其余取 ⊥，例如修改历史不可审计。这里冻结的是怎样识别、比较、枚举与归属，不是不许运行状态变化：依法发生的承担者更替、正式维结构的变化、Rel\_ρ 的变化、共同绑定与率承担组织的变化，都不构成本项为 0。某一评价点或单元读不出结果，只使相应读数为 ⊥，不得把它从索引中删去。

定义 11（合法动力段）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{LegalIDynSeg}^M := Read\_{ActualTrajectory}^M ∧₃ Read\_{AdmissibleIntentRun}^M ∧₃ Read\_{FixedIntentAnchor}^M ∧₃ Read\_{IntentQualWholeSegment}^M ∧₃ Read\_{SameIDynEvidenceRun}^M ∧₃ Read\_{FrozenIDynProtocol}^M

六项一一对应一般式的 L1 至 L6。读不出来只产生 ⊥，不得改写为轨迹非法。

源动一处读的是：在 γ 上，意向自身的源动职责有没有现实地续行并进入 𝒫\_I，以及这一续行在什么时刻开始、在哪些子段上持续、在什么时刻停止。单元内的读数直接调用《意向作用数理式》A1 一层的四项读数，不读 A2：源动在发而概率没有兑现，读数照样为 1。

定义 12（单元源动发生读数与正发生区间）\[S、辅\]　对每一个 u ∈ U\_γ，按 Γ\_IDyn 枚举源动候选 o := (e, Π^I, Z\_src)：e 是 u 内的一次现实事件，Π^I 是这一事件中意向组织的当前实现包，Z\_src 是这一事件中源动职责到 𝒫\_I 的实际非零续行子段；候选集记为 SrcCand(u)。记

&nbsp;&nbsp;&nbsp;&nbsp;A1src^M(o) := CurrentEvent\_I^M ∧₃ CurrentSrcRoleReal^M ∧₃ ActualSrcEnter^M ∧₃ SrcAnchorBind^M

四项即《意向作用数理式》定义 4 至 7，以 u 作为作用申报单元求值。

&nbsp;&nbsp;&nbsp;&nbsp;SrcOcc^M(u) := ∃₃ o ∈ SrcCand(u) · \[ A1src^M(o) ∧₃ SameIDynBind^M(o) \]

取 0 须有覆盖 Cov^Src(u) = 1，即 EventCover^M、SrcRoleCover^M、SrcSegCover^M 在 u 上闭合；覆盖未闭而没有找到正候选，取 ⊥。SrcOcc^M(u) = 1 说的是：u 中有一段属于 \[S\_I\]\_src、实际进入同一 𝒫\_I 的现实非零续行。它不说这段续行相对于前后是开始、继续还是停止。外界刺激经 \[S\_I\]\_src 进入 𝒫\_I 而引起的续行，可以取 1；外部完整选择器绕过 \[S\_I\]\_src 与 𝒫\_I 直接决定后继，A1src^M 不为 1；源动职责实现现实地发生而没有进入 𝒫\_I，这一候选不为 1。

正发生区间 Occ\_src 是 γ 内全部满足 A1src^M(o) = 1 且绑定为 1 的候选的 Z\_src 之并。对 γ 内的一个实际子段 J，确认无发生 NoSrc^M(J) := 1，当 J 所及各单元的 Cov^Src 闭合，且没有正候选的 Z\_src 与 J 相交；J 与某一正候选的 Z\_src 相交时为 0；其余为 ⊥。

定义 13（源动的持续、停止与开始）\[S\]

持续：对 γ 内的实际子段 J，SrcCont^M(J) := 1，当 J 内有一列按时间排列、绑定为 1 的正源动续行，J 的起点到第一段续行、最后一段续行到 J 的终点、以及任意相邻两段续行之间的间隙，都严格短于 δ\_src。续行可以是一段跨越 J 的连续续行，也可以是一串脉冲式的连续发生；两者都进入持续。持续是正证据，不需要负覆盖；J 内若有一段长度不小于 δ\_src、经负覆盖确认无源动发生的间隙，则不构成持续。  
停止：对 γ 内的时刻 τ，SrcStop^M(τ) := 1，当某一正续行在 τ 结束，且 \[τ, τ + δ\_src\] 在 γ 内，NoSrc^M(\[τ, τ + δ\_src\]) = 1。  
开始：SrcStart^M(τ) := 1，当某一正续行在 τ 开始，且 \[τ − δ\_src, τ\] 在 γ 内，NoSrc^M(\[τ − δ\_src, τ\]) = 1。

停止与开始所需的时间窗确认无发生为 0（窗内有正续行）时，相应读数为 0；为 ⊥ 时，相应读数为 ⊥；时间窗越出 γ 时，相应读数不在本申报内求值。一对相邻单元之间，按这些读数报告其间的开始、持续、停止或停止后再起；两单元各有发生而其间有确认的停发与再起，报告停止与开始，不报告持续。所需的跨时记录不足时，分类为 ⊥（SourceTransitionOpen），不洗掉已经确定的发生。不得以相邻单元的 SrcOcc^M 取值直接定义开始、持续或停止。

定义 14（源动发生动力）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{SourceOccurrenceDyn}^{M,γ} := ∃₃ u ∈ U\_γ · SrcOcc^M(u)

取 0，当且仅当全部单元的 SrcOcc^M(u) = 0，且覆盖 Cov^Src\_γ := ∧₃\_u Cov^Src(u) 闭合。这一读数由单元内落在 γ 中的真实非零源动续行承担：一段这样的续行，或者在 γ 内开始，或者在 γ 内停止，或者在它与 γ 相交的子段上持续，三者必居其一（七之 1 定理 2）；定义 13 只是对跨时类型的进一步分类，不是这一读数的前提。

定义 15（源动停后再起）\[S\]　SrcRestart^M := 1，当存在时刻 τ\_1 \< τ\_2，γ 内 τ\_1 以前有正续行，SrcStop^M(τ\_1) = 1，SrcStart^M(τ\_2) = 1，所用记录的绑定都为 1，且 Read\_{IntentQualWholeSegment}^M = 1；SrcRestart^M := 0，当整段相关记录与覆盖完整，并确定不存在这样的序列；其余取 ⊥。中间的停发未经确认，不签再起。停后再起的末段是一次开始，开始不必是再起。停后再起不另加入定义 14 的读数。

载体一处读的是：𝒫\_I 的某一正式方向的承担律，在承担这一方向职责的同一实现上，有没有程度的升、降或迁移。程度的读取与比较全部调用律动力的已有形式系统，本系统只做三件事：按事前冻结的规则确定载体候选；把程度规约中的职责对应冻结为这一方向职责；检查承担关系在比较的两端都保持。

定义 16（载体候选域与程度规约）\[表\]　对每一个正式方向职责 v\_i，按 Γ\_IDyn 冻结的发现规则，确定可能合法承担 v\_i 的候选律，组成候选登记

&nbsp;&nbsp;&nbsp;&nbsp;κ\_{ij}^car := (K\_I^M, 𝒫\_I, v\_i, L\_{ij}, Γ\_D^{ij})

Γ\_D^{ij} 是《律分级式》比较规约 Γ\_D 的一份冻结实例，其中第三项“同职责与同评价单元的对应规则”固定为 L\_{ij} 在实际承担 v\_i 正式方向职责时的程度读取，第九项“跨状态时的承载对应”固定为同一承担实现的职责连续，其余各项按《律分级式》冻结。这只是在上游既有的职责化读取制度中选定一个职责，不新造按方向裁切的律，也不新造程度。冻结的是候选律的身份、方向职责的身份与读取规则；某一候选在某一评价点是否实际承担 v\_i，不冻结，所以合法的承担者更替不违反 Γ\_IDyn。候选登记的全体记为 𝒦^car。CarRegCover^M = 1 表示按冻结的发现规则，可能合法承担 V\_I 正式方向职责的候选都已登记；运行中出现一个合法的新承担实现，而它在发现规则可识别的范围内，即按规则进入登记；不能确认候选域完整时，载体一处不能签 0。

定义 17（承担保持）\[辅\]　BearHold\_{ij,k}^M := BearDim^M(L\_{ij}, v\_i; t\_k) ∧₃ BearDim^M(L\_{ij}, v\_i; t\_{k+1})。BearDim^M 是《概率数理式》的正式维承担读数。承担在一端不成立时，这一步不是 L\_{ij} 作为 v\_i 同一载体的程度步；承担者的更替若改变了 𝒫\_I 的正式维组织，由概率一处读取。

定义 18（载体步读数）\[表、辅\]　SameCarrierDynBind\_{ij,k}^M：取 1，这一步所用的程度读数、承担读数与比较都属于同一 K\_I^M、同一 𝒫\_I、同一 v\_i、同一 L\_{ij}、同一 Γ\_D^{ij}，并且 SameIDynBind^M 为 1；身份材料完整，且这一步实际采用的承重记录明确属于另一锚、另一方向、另一律、另一规约或另一运行，取 ⊥（CarrierBindMismatch）；其余取 ⊥。本读数不取 0：拿错的载体证据不得作为载体动力的正证据，也不得作为负证据。它是一般式 SameCarrierDynBind\_I 的形式登记。StepDeg\_{ij,k} 是《律动力数理式》在 Γ\_D^{ij} 之下对 L\_{ij} 在 t\_k 与 t\_{k+1} 的程度剖面的比较结果，取升、降、等阶、迁移或 ⊥\_D 之一。记

&nbsp;&nbsp;&nbsp;&nbsp;ChangeDeg\_{ij,k} := 1，当 StepDeg\_{ij,k} ∈ {升, 降, 迁移}；0，当 StepDeg\_{ij,k} = 等阶；⊥，当 StepDeg\_{ij,k} = ⊥\_D

&nbsp;&nbsp;&nbsp;&nbsp;Q\_{ij,k}^Car := BearHold\_{ij,k}^M ∧₃ ChangeDeg\_{ij,k} ∧₃ SameCarrierDynBind\_{ij,k}^M

迁移是确定的比较结果，不是未决：两侧的剖面都确定不能覆盖对方，它是一种实际的程度动力。程度读不出，只取 ⊥，不取降。

定义 19（载体动力）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{CarrierDyn}^{M,γ} := ∃₃ κ\_{ij}^car ∈ 𝒦^car, k · Q\_{ij,k}^Car

概率一处读的是：意向域中那个正式的概率组织 𝒫\_I，在 γ 上有没有概率组式已封的概率动力。全部读数调用《概率动力数理式》，本系统只确认被读的正是 K\_I 中的同一个 𝒫\_I。

定义 21（意向概率动力）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{IntentProbDyn}^{M,γ} := Read\_{N\_PDyn}^M(χ̄\_PDyn^I; γ)，当 SameIntentProbDynBind^M = 1  
&nbsp;&nbsp;&nbsp;&nbsp;Read\_{IntentProbDyn}^{M,γ} := ⊥（ProbBindMismatch），当 SameIntentProbDynBind^M = 0

&nbsp;&nbsp;&nbsp;&nbsp;IAct^M(J) := Read\_{N\_IAct}^M(χ\_I, J, Γ\_IAct^J)

Γ\_IAct^J 是 Γ\_IDyn 为时间窗 J 冻结的作用求解协议，其候选只取携带本申报同证据键的记录。完整作用正区间 Occ\_act 是 γ 内全部满足 Q\_IAct(w) = 1 且绑定为 1 的完整作用见证的现实事件所占时间之并；确认无完整作用 NoAct^M(J) := 1，当 IAct^M(J) = 0；与 Occ\_act 相交时为 0；其余为 ⊥。

前缀绑定 SameIActBind\_≤2^M(w) 是《意向欲门切换数理式》定义 12 中只涉及 A1、A2 的部分：同一 K\_I^M，同一现实事件，Π^I 的概率组织实现与 A2 所调用的实现同一，Z\_src 的后继进入同一 𝒫\_I，Z\_ρ 属于同一条当前生成链。到达层 Reach^M(J) 是 J 内各候选沿同一候选、带前缀绑定的递进所能取得 1 的最高层：

&nbsp;&nbsp;&nbsp;&nbsp;第 1 层：Q1(w) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;第 2 层：Q2(w) = 1 且 SameIActBind\_≤2^M(w) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;第 3 层：Q3(w) = 1 且 SameIActBind\_≤3^M(w) = 1  
&nbsp;&nbsp;&nbsp;&nbsp;第 4 层：Q\_IAct(w) = 1

没有候选达到第 1 层，记 0。不得把不同候选分别取得的层拼成更高的层。高一层的覆盖对全部候选都已闭合时，Reach^M(J) 才确定，否则为 ⊥。由定义，Reach^M(J) = 4 当且仅当 J 内有同链的完整作用见证；所以 NoAct^M(J) = 1 时，Reach^M(J) ≤ 3。

定义 23（作用投影）\[S、辅\]

开始：ActStart^M(τ) := 1，当某一完整作用正区间在 τ 开始，\[τ − δ\_act, τ\] 在 γ 内，且 NoAct^M(\[τ − δ\_act, τ\]) = 1，所用见证的绑定为 1。即：同一 K\_I；这一现实链上有意向自身源动的现实发生，它可以是新开始的，也可以是此前已在持续的；同链上 𝒫\_I 的概率职责当前兑现；方向实际进入对应欲门；同链实际进入门后调谐职责；同链绑定成立；此前一个连续粒度内没有同一申报的完整作用，此后有；完整作用见证由 A1 的同链承担取得，外部完整选择器直接写入过门或门后调谐不能取得这一见证。  
继续：ActCont^M(J) := 1，当 J 内有一列按时间排列、绑定为 1 的完整作用正见证，每一见证各自在同一现实链上闭合 A1 至 A4，J 的起点到第一次、最后一次到 J 的终点、以及任意相邻两次完整作用之间的间隙，都严格短于 δ\_act。这要求源动的续行、概率职责的兑现、过门与门后使役在同链上按冻结的粒度持续兑现，不要求完整作用在物理时间上无缝占满 J。J 内若有一段长度不小于 δ\_act、经负覆盖确认无完整作用的间隙，则不构成继续。  
停止：ActStop^M(τ) := 1，当某一完整作用正区间在 τ 结束，\[τ, τ + δ\_act\] 在 γ 内，且 NoAct^M(\[τ, τ + δ\_act\]) = 1。

所需时间窗的读数为 ⊥ 时，相应投影为 ⊥（ActTransitionOpen）。时间窗或单元的作用端态之差不定义开始、继续或停止：两端都有完整作用而其间有确认的停止与开始，读出停止与开始，不读继续。

停止的层位不读停止以后时间窗内全部候选的最高到达层，只读与刚刚停止的那条作用续行相接的后继候选。记 W\_τ^- 为在 τ 终止的完整作用见证；\[τ, τ + δ\_act\] 内的一个候选是它的后继候选，当这一候选与 W\_τ^- 同锚、其源动职责实现与 W\_τ^- 的源动续行在 δ\_src 之内相接、其概率组织实现与 W\_τ^- 的同一，即按 Γ\_IDyn 冻结的续行身份规则属于同一条作用续行。限制在后继候选上的到达层记为 Reach\_τ^-，它沿用定义 22 的分层与前缀绑定：没有后继候选、且这一时间窗内源动的覆盖闭合，记 0。与终止链无续行对应的新候选，不参加这一次层位的判定。停止的层位 StopLayer^M(τ) 按 Reach\_τ^- 读取：0 为源动层，源动不再发生；1 为概率层，源动在而概率职责不再兑现；2 为门层，源动与概率职责在而当前过门断开；3 为调谐层，过门在而门后调谐使役不再进入。Reach\_τ^- 为 ⊥ 时层位为 ⊥（StopLayerOpen）。层位是停止的分辨，不是四种动力。

开始的概率一侧 ProbSide^M(τ) 调用同一 𝒫\_I、同一 γ 上《概率动力数理式》已经建立的概率作用动力读数及其真实子段证书，即定义 3.11 的作用评价单元读数、步读数 StepAct\_k 与来源绑定，本系统不另立概率作用的连续判据。若上游证书表明概率作用在 τ 以前未在行，而在 τ 所属的起始单元上真实开始，记为概率作用开始；若上游证书表明概率作用已在 τ 以前的真实子段上续行至 τ，记为概率作用续行，例如完整作用此前停在门层或调谐层；上游的跨时读数不可判时，记 ⊥（ProbSideOpen）。单独的 Read\_{N\_PAct}^M = 1 只说明当前有概率作用的见证，不说明它此前一直在行。完整作用的见证在 τ 有 A2 = 1，即其 w\_ρ 上当前发生与职责兑现两层都为 1，这是一次当前概率作用的见证，所以开始时概率作用必定在行：此前未在行，是概率作用之开始；此前已在行，是它的续行。ProbSide 只报告是哪一种，不是开始的条件。

作用的重启 IActRestart^M := 1，当存在 τ\_1 \< τ\_2，τ\_1 以前有完整作用，ActStop^M(τ\_1) = 1，ActStart^M(τ\_2) = 1，且 Read\_{IntentQualWholeSegment}^M = 1；整段相关记录与覆盖完整而确定不存在这样的序列时取 0；其余取 ⊥。新的开始可以伴随概率作用之开始，也可以在概率作用一直续行、门层或调谐层重新闭合时取得。重启的末段是一次开始，开始不必是重启。

方向型的增强与减弱只落在 𝒫\_I 的相对生成关系上。上游 weight 表示的相对生成关系是正比例等价类 \[w(ν)\]\_ρ；两个方向之间的相对地位，用在这一等价类上不变的量来读。

定义 24（方向比较实例与相对份额）\[辅\]　方向比较实例

&nbsp;&nbsp;&nbsp;&nbsp;χ\_Dir^i := (K\_I^M, 𝒫\_I, \[v\_i\], CmpSet\_i, EvalSet\_i, Γ\_Dir)

\[v\_i\] 是正式方向职责类；CmpSet\_i ⊆ V\_I ∖ {v\_i} 是事前冻结的比较集；EvalSet\_i ⊆ Eval(r\_P) 是事前冻结的评价集；Γ\_Dir 承继上游 Rel\_ρ 的表示与比较协议。在 weight 模式下，对 j ∈ CmpSet\_i、ν ∈ EvalSet\_i 与评价点 t\_k，取 \[w\_k(ν)\]\_ρ 的任一代表 w\_k(ν)，定义

&nbsp;&nbsp;&nbsp;&nbsp;s\_{ij}^k(ν) := w\_{k,i}(ν) / ( w\_{k,i}(ν) + w\_{k,j}(ν) )，当 w\_{k,i}(ν) + w\_{k,j}(ν) \> 0

它对代表的正比例缩放不变，所以是相对生成关系本身的读数，不是数值的读数。两维在某一端都为零时，或者比较集中的某一方向在某一端不属于当时的正式维族时，这一对在这一评价上没有相对地位，不进入方向型比较；它的变化照样由概率一处的率关系动力读取。struct 模式下，只有上游的 struct 表示对这一对方向给出了相对生成的先后比较时才可比；没有合法的跨模式桥时，比较为 ⊥。

定义 25（方向型读数）\[S\]　对相邻评价点 t\_k、t\_{k+1}，在两端都有相对地位的全部 (j, ν) 上取 Δ\_{ij}(ν) := sgn( s\_{ij}^{k+1}(ν) − s\_{ij}^k(ν) )：

&nbsp;&nbsp;&nbsp;&nbsp;升：全部 Δ ≥ 0，至少一个 Δ \> 0  
&nbsp;&nbsp;&nbsp;&nbsp;降：全部 Δ ≤ 0，至少一个 Δ \< 0  
&nbsp;&nbsp;&nbsp;&nbsp;等：全部 Δ = 0  
&nbsp;&nbsp;&nbsp;&nbsp;不可比：既有 Δ \> 0，又有 Δ \< 0  
&nbsp;&nbsp;&nbsp;&nbsp;不适用：全部 (j, ν) 都在某一端没有相对地位，或者 \[v\_i\] 自身在某一端不属于当时的正式维族  
&nbsp;&nbsp;&nbsp;&nbsp;⊥：按申报本应比较的某一坐标，因材料、表示或覆盖不足而不能判，或者 Cov^Rel\_k 未闭

定义 27（类型化剖面）\[辅\]　若 Γ\_IDyn 申报了合成剖面，其坐标集 J\_Π := J\_D ∪ J\_C 须事前冻结：J\_D 中每一坐标是一份方向比较实例，J\_C 中每一坐标是一份载体候选登记。申报的坐标都是必需坐标，运行以后不得因结果不利而删除。剖面在相邻评价点之间的比较 ≻\_Π 先判适用：某一必需坐标在这一步为不适用，或者某一载体坐标在这一步不满足承担保持，而 Γ\_IDyn 没有在运行以前规定这种情形下该坐标不属于本次剖面的定义域，则这一步的剖面比较为剖面不适用。剖面不适用表示这份申报剖面在这一步没有完整的共同比较域，不是材料不足。适用时按乘积偏序：

&nbsp;&nbsp;&nbsp;&nbsp;升：全部坐标为升或等，至少一个为升  
&nbsp;&nbsp;&nbsp;&nbsp;降：全部坐标为降或等，至少一个为降  
&nbsp;&nbsp;&nbsp;&nbsp;等：全部坐标为等  
&nbsp;&nbsp;&nbsp;&nbsp;不可比：有坐标为不可比或迁移，或者既有坐标为升，又有坐标为降  
&nbsp;&nbsp;&nbsp;&nbsp;⊥：不属于以上情形，且有坐标为 ⊥

不得以加权和、平均值、最大值或归一化后的总分代替这一比较；剖面的比较结果只说申报坐标集上的类型化变化，不说意向整个变强或变弱。本系统不输出任何意向总强度。

否则 SwitchCall^M(σ) = ⊥。本系统不重定义 S1 至 S4 与共绑定，只调用《意向欲门切换数理式》的总读数并报告。

四、方程

本系统表示意向动力的必要结构，而动力本身是跨时的；但本系统的关系都是读数之间的组成关系，不是演化方程。场怎样从一个状态运行到下一个状态，由场系统与运行基底给出，本系统只读它的记录。

1\. 析取合成

三处各有只缺它的世界，一处的求值对象也不由另一处的取值产生：源动一处读评价单元内的源动续行，载体一处读承担律的程度剖面，概率一处读同一 𝒫\_I 的概率动力。所以三处并列求值，以三值析取合成；若排成递进，一处本可独立判出的 1 会被前一处的 ⊥ 遮蔽。

定义 29（动力实际性）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{DynActual\_I}^{M,γ} := Read\_{SourceOccurrenceDyn}^{M,γ} ∨₃ Read\_{CarrierDyn}^{M,γ} ∨₃ Read\_{IntentProbDyn}^{M,γ}

任一处明确为 1，即为 1，其他处的 ⊥ 不洗掉它；三处都在各自正确的对象、正确的绑定与完整覆盖下为 0，才为 0；其余为 ⊥。概率一处为 ⊥（ProbBindMismatch）时，不能以外来证据的 0 参加“三处都为 0”。

定义 30（总读数）\[S\]

&nbsp;&nbsp;&nbsp;&nbsp;Read\_{N\_IDyn^γ}^M := Read\_{LegalIDynSeg}^M ∧₃ Read\_{DynActual\_I}^{M,γ}

分段地说：取 1，合法动力段六项都为 1，且三处至少一处为 1；取 0，合法动力段有一项在结构上为 0，或者三处在正确对象与完整覆盖下都为 0，且这些 0 中没有 DeclarationZero；其余取 ⊥。合法动力段为 ⊥ 而动力实际性已确定为 0 时，总读数为 0；它的结构回读只走“三处都为 0”这一条路径，不借未决的合法段材料补充任何结论。

作用投影、方向型与载体型读数、类型化剖面与切换的调用都不进入定义 29、30。它们与三处的关系由下面的命题给出，只用于一致性审查与报告。

2\. 覆盖与零型

定义 31（覆盖证书）\[辅\]　覆盖按层分开冻结，只在准备签出相应的 0 时使用：

合法段：Cov^traj，运行、分支与相邻子段的记录完整；Cov^upd，更新操作、来源链与权威状态的写入历史完整；Cov^anchor，各评价点的锚与身份体系引用完整；QualEventCover^M，资格变化事件的记录覆盖整段；Cov^prot，协议版本、修改历史与索引完整。

作用投影：各时间窗按《意向作用数理式》的覆盖；到达层另需高一层的覆盖对全部候选闭合。  
方向型读数：Cov^Rel\_k，相关评价上的率关系比较完整。剖面：坐标定义域、适用性与各坐标读数的覆盖分别可判。

这些都是形式可解性与覆盖的条件，不是 H，也不是意向动力的对象层条件。

定义 31 之后：NegComplete\_IDyn^M = 1，当且仅当每一条被用来签 0 的失败路径都有它所需的覆盖。它不是本体条件，不进入 N\_IDyn^γ；正读数一旦出现即可签 1，不需要它。

定义 32（StructuralZero）\[辅\]　决定性的结构 0 来自实际结构的失败：申报的 γ 本身确有跨运行、跨分支或快照的拼接；γ 内确有非法直写；资格锚或职责身份体系确有跨组织的更换；资格确在 γ 内退出或重新形成；一份合法申报确在看到结果以后被改写；或者三处在正确对象与完整覆盖下都确定没有动力。依法发生的承担者更替、Rel\_ρ 的变化、正式维组织、共同绑定与率承担组织的变化都不是结构 0：它们可能正是被读的动力。外来记录、被采用的跨轨拼证与概率、载体证据的错配都不是结构 0，只使相应读数为 ⊥：证据身份的错配只能使证书失败，不能制造对象层的否定。

定义 33（DeclarationZero）\[辅\]　决定性的形式 0 只来自申报的失格，例如：γ 不是可识别的轨迹引用；T\_γ 的评价点顺序非法；U\_γ 的单元重叠或留有间隙；连续粒度未申报或不为正；Γ\_IDyn 的冻结时间晚于承重评价；SrcRoleID、GateRoleID 或职责身份体系的版本与资格锚的初始申报不一致；方向比较集包含被比较的方向本身；候选域的发现规则在申报时即不良构。DeclarationZero 不回读为 N\_IDyn^γ = 0，最终退为 ⊥（DeclarationInvalid），即要求重新申报。申报的失格与 L6 的取 0 不同：前者是申报本身不能用，后者是一份合法申报在运行中被事后改写。

定义 34（失败签名与反证路径）\[辅\]　Read\_{N\_IDyn^γ}^M = 0 时，记 FailBranch^M 为取得结构 0 的部分：若合法动力段为 0，记其中取 0 的项，取自 {L1, L2, L3, L4, L6}；若动力实际性为 0，记 {Src, Car, Prob}，并在 Prob 下记上游《概率动力数理式》的失败支与失败路径。只有正确对象上的概率负读，才可进入 Prob 的结构失败路径。反证路径 RefuteRoute 是被选来签出这一 0 的部分：合法段中任一取 0 的项即足以签出；动力实际性须三处同时为 0。所选路径须满足其覆盖与回读条件（七之 3）。FailBranch 与 RefuteRoute 都不是职责，只是负读出的诊断签名。

3\. 性质

命题 1（正证据优先）。若某一单元 SrcOcc^M(u) = 1，或某一载体步 Q\_{ij,k}^Car = 1，或 Read\_{IntentProbDyn}^{M,γ} = 1，则 Read\_{DynActual\_I}^{M,γ} = 1，不论其他单元、其他步或其他处是否为 ⊥。证明：由 ∃₃ 与 ∨₃ 的定义，一个 1 决定结果。□

命题 2（源动发生与源动发生动力）。Read\_{SourceOccurrenceDyn}^{M,γ} = 1 当且仅当存在单元 u，其中有属于 \[S\_I\]\_src、实际进入同一 𝒫\_I、绑定为 1 的现实非零源动续行；Read\_{SourceOccurrenceDyn}^{M,γ} = 0 当且仅当全部单元的覆盖闭合而都没有这样的续行。证明：由定义 12、14。□ 这是一般式“源动在 γ 上没有发生，因而也没有发生的开始、持续、停止或再起”在形式层的表示。本命题只判源动发生动力是否存在，不判某一时刻属于开始、持续还是停止。

命题 3（存在与分类分离）。两个相邻单元的 SrcOcc^M 都为 1，不推出两单元之间的持续；前一单元为 1、后一单元为 0，也不推出停止。持续须有间隙都短于 δ\_src 的真实续行覆盖；停止与开始须相应时间窗确认无发生。两单元各有发生而其间有一段不短于 δ\_src、经负覆盖确认无发生的间隙，读出停止与再起。后态的源动记录缺失时，确认无发生为 ⊥，不签停止。分类为 ⊥ 不洗掉已经由 SrcOcc^M 确定的源动发生动力。证明：由定义 12、13、15。□

命题 4（源动独行）。源动职责现实地续行并进入 𝒫\_I，而 𝒫\_I 在这些续行上没有兑现相对生成，概率作用没有起、续、止，相对生成关系与组织结构不变，承担律的程度各步等阶，则 Read\_{SourceOccurrenceDyn}^{M,γ} = 1，Read\_{CarrierDyn}^{M,γ} = 0，Read\_{IntentProbDyn}^{M,γ} = 0（在各自覆盖闭合、归属绑定为 1 时），Read\_{DynActual\_I}^{M,γ} = 1。证明：SrcOcc^M 只读 A1 一层，不读 A2；上游三支各步为 0；载体各步 ChangeDeg = 0。□

命题 5（载体独行与概率独行）。源动在 γ 上没有续行，𝒫\_I 无概率动力，某一候选载体某一步在承担保持下程度上升，则三处读数为 0、1、0，动力实际性为 1。源动在 γ 上没有续行，全部候选载体各步等阶或不在承担，𝒫\_I 的相对生成关系、共同绑定、率承担组织或正式维结构真实变化，则读数为 0、0、1，动力实际性为 1。证明：由定义 14、19、21。□

命题 6（承担者更替）。某一步上 v\_i 的实际承担由 L\_{ij} 换为 L\_{ij′}，则两个候选在这一步都不满足承担保持，Q^Car 都为 0；这一更替本身不签任何一条律的载体动力，若它改变了 𝒫\_I 的正式维承担登记，由概率一处的 DimStructDyn 读取。这一更替不使 L3 或 L6 为 0。证明：由定义 7、10、16、17、18。□

命题 7（正比例缩放）。若在全部相关评价上，w\_{k+1}(ν) = a(ν)·w\_k(ν)，a(ν) \> 0，则全部 Δ\_{ij}(ν) = 0，DirStep\_{i,k} = 等，不签方向型增强或减弱；上游同时有 SameRel\_k^M = 1，率关系动力不签出。证明：s\_{ij} 对正比例缩放不变。□

命题 8（两类互不推出）。L\_{ij} 的程度上升而 Rel\_ρ 在正比例意义下不变，则 CarrierStrengthen\_{ij,k}^M = 1，DirectionStrengthen\_{i,k}^M = 0；\[v\_i\] 相对比较集严格上升而 L\_{ij} 等阶，则 DirectionStrengthen\_{i,k}^M = 1，CarrierStrengthen\_{ij,k}^M = 0。证明：两类读数分别只读 StepDeg 与 s\_{ij}，二者互不为对方的分量。□

命题 9（方向型读数与概率一处）。若 DirStep\_{i,k} ∈ {升, 降, 不可比}，则至少有一个 (j, ν) 使 \[w\_{k+1}(ν)\]\_ρ ≠ \[w\_k(ν)\]\_ρ，于是上游 SameRel\_k^M = 0；在上游合法段、资格接触与绑定都为 1 时，Q\_k^Rate = 1，Read\_{IntentProbDyn}^{M,γ} = 1。证明：某一 s\_{ij} 改变，两端的权重就不成正比例。□

命题 10（作用投影与源动一处）。若 ActStart^M(τ) = 1、ActCont^M(J) = 1 或 ActStop^M(τ) = 1，则 Read\_{SourceOccurrenceDyn}^{M,γ} = 1。证明：三种投影都要求 γ 内有绑定为 1 的完整作用见证；见证有 Q1 = 1，即 A1 一层四项为 1，其 (e\_t, Π\_t^I, Z\_src) 是某一单元的源动正候选，于是该单元 SrcOcc^M = 1。□ 这是一般式主定理二“开始、继续、停止、重启时，源动发生动力或意向概率动力成立”在形式层的落点。本命题由定义 23 的真实机制给出，不由时间窗端态之差给出。门层与调谐层的停止，源动在停止以后仍在续行，这一续行同样使源动一处为 1。

命题 11（作用开始的两种概率一侧）。ActStart^M(τ) = 1 时，τ 处的完整作用见证有 A2 = 1，所以概率作用在 τ 在行；若上游证书表明此前概率作用未在行，ProbSide^M(τ) 为概率作用开始；若此前已在行，例如完整作用此前停在门层或调谐层，ProbSide^M(τ) 为概率作用续行，开始照样成立。源动一侧同样可以是新开始，也可以是此前已在持续。证明：由定义 22、23。□

命题 12（门层与调谐层停止）。ActStop^M(τ) = 1，Reach\_τ^- = 2，则停止层位为门层：停止以后的时间窗内，终止链的后继候选中有同一候选、带前缀绑定的 A1、A2 为 1，而没有后继候选取得第 3 层，于是这条作用续行的源动与概率职责的兑现仍在，当前过门断开；Reach\_τ^- 为 3 时为调谐层。停止以后新来的、与终止链无续行对应的候选，不改变这一层位。完整作用停止不等于三处的动力停止。证明：由定义 22、23。□

命题 13（切换的调用与跨时动力）。SwitchCall^M(σ) = 1 本身不给出任何跨时类型，也不推出 Read\_{IntentProbDyn}^{M,γ} = 1：切换读数所含的后态 A2 只是一次当前职责兑现，概率一处读的是上游对相邻评价点的作用动力、率关系与组织结构的比较。当 σ 落在 γ 内并且绑定为 1 时，后态 A1 的现实事件是某一单元的源动正候选，该单元的 SrcOcc^M = 1，于是源动一处为 1：这是由落在 γ 内的真实源动续行判定的，不是由切换的结构推出的；这一续行在后态属于开始、持续还是停止，仍须定义 13 的跨时证据，切换读数不提供。□

命题 14（证据拼接）。源动一处的承重证据取自运行甲，载体一处的承重证据取自运行乙，并试图共同承重同一 χ\_IDyn^M，而申报的 γ 属于运行甲，则载体各步 SameCarrierDynBind^M = ⊥（CarrierBindMismatch），Read\_{SameIDynEvidenceRun}^M = ⊥（EvidenceSplice）；拼接的材料不能共同进入有效证书，错配的一处既不取得正读，也不取得关于正确对象的负读，所以这一证据包不能使 Read\_{N\_IDyn^γ}^M = 1。以同轨材料重新求值以前，不由此推出 N\_IDyn^γ = 0。证明：由定义 4、9、18。□

命题 15（资格中途退出）。t\_0 与 t\_n 上 IntentCoreCert^M = 1，而 γ 内有资格退出又重新形成的现实记录，则 Read\_{IntentQualWholeSegment}^M = 0，Read\_{N\_IDyn^γ}^M = 0；不得把前后两段当作同一意向的一段动力。资格变化事件的记录不全时，本项为 ⊥，不为 1。资格退出的结构判定属于《意向判定式》。□

命题 16（直写不作正证据）。γ 内有直接写入源动发生、程度、相对生成关系、作用或切换状态并使之成为权威底层状态的记录，则 Read\_{AdmissibleIntentRun}^M = 0，Read\_{N\_IDyn^γ}^M = 0；写入的状态与标签不作为任何一处的正证据。被动的日志、审计记录与派生证书不属于这种直写，只要它们不驱动底层状态。□

命题 17（混合剖面与剖面不适用）。剖面坐标中一个方向为升，另一个载体为降，则 ≻\_Π 的比较为不可比；某一必需方向坐标为不适用而没有事前的定义域规定，则为剖面不适用。本系统不输出“意向整个变强”或“意向整个变弱”。□

命题 18（资格接触）。Read\_{IntentQualWholeSegment}^M = 1 时，在全部评价点上 IntentCoreCert^M = 1，其中 𝒫\_I 的概率资格读数为 1，所以上游的 Contact\_k^M = 1。证明：IntentCoreCert^M 含《意向数理式》的 N\_PQualRead\_I^M，即 𝒫\_I 的 Read\_{N\_P}^M。□ 所以在意向资格整段保持的工作域内，概率一处不会因上游的资格接触而失去对象。

命题 19（申报失格与合法更替）。评价单元的划分或连续粒度在看到源动发生以后才确定，则 Read\_{FrozenIDynProtocol}^M = 0；单元的申报本身重叠或留有间隙，则为 DeclarationZero，读数为 ⊥（DeclarationInvalid），不签 N\_IDyn^γ = 0。合法运行中实际承担者的变化，不属于申报失格，也不使 L6 为 0。□

五、运行与求解

“运行”指对一个动力求解实例 χ\_IDyn^M 求值。本系统读运行记录，不驱动运行。

1\. 求解次序

（1）校验 χ\_IDyn^M、进入条件与 Γ\_IDyn；校验 T\_γ、U\_γ 与连续粒度的申报。申报失格时，返回 ⊥（DeclarationInvalid）。  
（2）重建 RunID、BranchID 与全部 I\_k，求 Read\_{ActualTrajectory}^M。  
（3）读取更新日志、来源链与权威状态的写入历史，求 Read\_{AdmissibleIntentRun}^M。  
（4）核各评价点的资格锚与职责身份体系，求 Read\_{FixedIntentAnchor}^M；运行状态的依法变化不在此列。  
（5）在各评价点求 IntentCoreCert^M，读取资格变化事件的记录，求 Read\_{IntentQualWholeSegment}^M。  
（6）核同证据键：未被采用的外来记录忽略；被采用为承重的外来记录使 L5 为 ⊥（EvidenceSplice），须以同轨材料重新求值。求 Read\_{SameIDynEvidenceRun}^M。  
（7）审核协议与索引的冻结历史，求 Read\_{FrozenIDynProtocol}^M。  
（8）合成 Read\_{LegalIDynSeg}^M。若为 0，总读数为 0，可以停止；若为 ⊥，继续求动力实际性。  
（9）源动一处：对每一单元枚举 SrcCand(u)，求 A1src^M 与绑定，得 SrcOcc^M(u)；聚合 Read\_{SourceOccurrenceDyn}^{M,γ}。另从正发生区间与确认无发生，求持续、停止、开始与 SrcRestart^M，作为分类报告。不得从相邻单元的 SrcOcc^M 取值直接定义跨时类型。  
（10）载体一处：按发现规则建立 𝒦^car，判 CarRegCover^M；对每一候选的每一步求 BearHold，在 Γ\_D^{ij} 之下调用 StepDeg，求绑定与 Q^Car；聚合 Read\_{CarrierDyn}^{M,γ}。  
（11）概率一处：核 SameIntentProbDynBind^M；为 1 时以 χ̄\_PDyn^I 与 γ 调用《概率动力数理式》的求解次序，得 Read\_{IntentProbDyn}^{M,γ}；为 0 时剔除外来证据，对正确对象重新求值，仍不能取得正确对象的材料时返回 ⊥（ProbBindMismatch）。  
（12）合成 Read\_{DynActual\_I}^{M,γ} 与 Read\_{N\_IDyn^γ}^M。任一处取得 1，动力实际性即可签 1，其余处可以停止；绑定须在求各单元、各步的读数以前即时核过。  
（13）另行求作用投影：求完整作用正区间与各相关时间窗的 NoAct^M、Reach^M，求开始、继续、停止、停止层位、ProbSide 与 IActRestart^M。时间窗端态只作一致性检查。  
（14）另行求方向型读数与载体型读数；若申报了合成剖面，先判适用，再求 ≻\_Π 的比较。  
（15）对落在 γ 内的比较序列求 SwitchCall^M(σ)。  
（16）没有正读数时，为签 0 检查所选反证路径的覆盖：覆盖未闭，返回相应的 ⊥；只有 DeclarationZero，返回 ⊥（DeclarationInvalid）；否则签 0，并给出 FailBranch^M。签 0 以后，按七之 3 确定结构判词。  
（17）输出总读数、所附原因、所用路径、三处读数、各投影的报告与条件传播记录。

第（13）至（15）步只是投影的报告，不反过来决定第（9）至（12）步的读数。

2\. ⊥ 的原因

形式读数取 ⊥ 时必须附原因，分为：DeclarationInvalid，申报、版本、单元划分或连续粒度失格；TrajectoryOpen，运行或分支的记录不完整；UpdateOpen，更新操作、来源链或写入历史不完整；AnchorOpen，锚或职责身份体系的引用不可判；QualificationOpen，某一评价点的资格读数为 ⊥，或资格变化事件的记录不全；EvidenceKeyOpen，同证据键不可判；EvidenceSplice，被采用的承重材料中有确认的外来记录；ProtocolOpen，协议或索引的修改历史不可审计；SourceOpen，源动一处有单元不可判，细分沿用《意向作用数理式》的 EventOpen、SourceRoleOpen、SourcePathOpen；CarrierRegistryOpen，载体候选域的覆盖未闭；BearDimOpen，承担读数不可判；DegreeOpen，程度读数或比较为 ⊥\_D；CarrierBindMismatch，载体一步采用的承重记录属于别的锚、方向、律、规约或运行；ProbabilityDynOpen，上游概率动力读数为 ⊥，细分沿用上游的原因；ProbBindOpen，意向概率动力的归属不可判；ProbBindMismatch，所取得的概率动力证据属于别的对象，而正确对象的材料尚未取得；ReaderImplementationInvalid，读出不干涉的检验不成立（五之 3 IDyn-M14）。

投影的报告另有原因：SourceTransitionOpen，源动的跨时分类所需记录不足；ActOpen，时间窗作用读数为 ⊥；ActTransitionOpen，完整作用的跨时分类所需记录不足；StopLayerOpen，到达层不可判；ProbSideOpen，开始前的概率作用状态不可判；DirectionOpen，方向型比较不可判；ProfileOpen，剖面比较为 ⊥；SwitchOpen，切换读数为 ⊥ 或序列不在 γ 内。它们不影响总读数。不适用与剖面不适用不是 ⊥ 的原因，是确定的结果。

另有几个原因不属于形式读数，而属于由形式读数回读得到的结构判词：PDynNegOpen，形式读数为 0，而概率一处的 0 在回读时所需的条件未关闭；CarrierNegOpen，载体一处的 0 在回读时所需的上游负向条件未关闭；QualExitOpen，所选路径是 L4 的 0，而资格在 γ 内退出的结构判定尚未由上游负向路径闭合；LawReadOpen，形式读数为 1，而正向回读实际使用的 Law-bearing 见证的 H\_LawRead 未关闭。

这些原因都是求解诊断，不是本体条件。不得把所有的 ⊥ 统称为材料不足。

3\. 可解性

以下是形式表示与求解的条件，记为 IDyn-M1 至 IDyn-M14。它们不是意向动力的本体条件，也不是 H。

IDyn-M1 求解实例可识别：χ\_IDyn^M 的各项可以有效引用；χ\_I 是已经成立的意向资格实例；Γ\_IDyn 在求解以前冻结。  
IDyn-M2 实际运行可追踪：RunID、BranchID 与全部相邻子段可以重建，并区分现实运行、复走与离线重演。  
IDyn-M3 更新可审计：状态更新的操作、来源链与权威状态的写入历史可以读取，并与被动日志分开。  
IDyn-M4 资格可逐点读取：各评价点的 IntentCoreCert^M 可求，资格变化事件有现实记录。  
IDyn-M5 同证据键可读：全部承重记录携带可比较的同证据键。  
IDyn-M6 协议可审计：Γ\_IDyn 的版本、冻结时间与修改历史可以读取。  
IDyn-M7 评价单元与连续粒度合法：U\_γ 可以事前冻结为无重叠、无间隙的划分；δ\_src、δ\_act 事前冻结；每一评价单元与每一时间窗都是合法的作用申报单元。

IDyn-M1 至 IDyn-M13 中某一条件缺失，只使依赖它的项退为 ⊥，不自动判为结构 0。IDyn-M14 不成立时，读出参与了它所读对象的生成，这一形式实现整体失格，返回 ⊥（ReaderImplementationInvalid）；不得用这种实现签 1 或 0；它也不是对象层的结构 0。

在 Γ\_IDyn 冻结、所涉候选域都有限可枚举、IDyn-M1 至 IDyn-M14 成立的条件下，每一步都在有限步内完成，Read\_{N\_IDyn^γ}^M 有确定的三值读数，并在取 ⊥ 时附原因。不满足这一条件的申报实例，不因此取 0，其读数保持为 ⊥。

4\. 解的地位

Read\_{N\_IDyn^γ}^M = 1 是形式解，表示 γ 是同一意向的合法动力段，并且三处至少一处有动力的形式证书。Read\_{N\_IDyn^γ}^M = 0 表示合法段有一项在结构上失败，或者三处在正确对象与完整覆盖下都没有动力；其结构层的否定强度按所选的反证路径区分（七之 3）。Read\_{N\_IDyn^γ}^M = ⊥ 表示形式上不能决定 N\_IDyn^γ，不得读作 N\_IDyn^γ 不成立，更不得读作意向没有动力。剖面不适用只说申报剖面在某一步没有完整的共同比较域，不影响总读数。

六、耦合关系

与《意向动力一般式》：只形式化 N\_IDyn^γ、合法段 L1 至 L6、三处、三处的归属绑定与各运行投影，逐项对应见对应表。作用的开始按该篇第六步：可以伴随概率作用之开始，也可以在概率作用已经在行、门层或调谐层重新闭合时取得。本系统不新增第四处，不新增总强度，不把作用投影、类型化的增强与减弱、切换的调用或门后的理之行立为轴。门后的理之行在本系统中只作输出与反馈：它若真实发生，经场的改路、留迹与沉积，再经合法的反馈或重入改变以后的源动续行、承担律的程度或 𝒫\_I 的状态，这些改变由三处在以后的段上读取；本系统不读当前反持，不以调谐结果、经验改变、显化或行为输出作任何读数的条件。

与《意向作用数理式》：源动一处直接调用该篇 A1 一层的四项读数与覆盖，不读 A2；作用投影调用该篇的总读数、递进读数与同链绑定。该篇的读数是一个申报单元内的当前读数，跨时的开始、继续与停止由本系统以真实子段与连续粒度另行判定。本系统不另建第二套作用系统。

与《意向欲门切换数理式》：调用该篇的总读数，并借用其定义 12 的前三层同链绑定作到达层；不重定义 S1 至 S4 与共绑定。

与《意向数理式》：资格实例、资格锚、源动职责类、正式方向职责体系、欲门职责商类与资格读数都沿用上游。

与《概率动力数理式》《概率数理式》《概率作用数理式》：概率一处调用 N\_PDyn 的全部形式系统，不另造第二套概率动力，只对正确的 𝒫\_I 调用；方向型读数只读上游的 Rel\_ρ 表示，不读率值的大小；承担读数沿用 BearDim^M；开始的概率一侧调用概率作用动力的单元读数、步读数与来源绑定，不另立概率作用的连续判据。

与《律动力数理式》《律分级式》：载体一处与载体型读数调用程度剖面、比较规约与逐步比较，不重建程度，不重建程度动力，不取成员律的作用动力；候选载体域可以冻结，实际的承担状态依法变化。

与场系统和运行基底：运行实例、分支、子段、事件、源动续行的起止记录、更新与写入历史、协议历史、资格变化记录与同证据键都须来自场系统或运行基底。本系统不另建物理运行系统，也不驱动运行。

七、回读规则

1\. 正向回读

定理 1（合法动力段）。Read\_{LegalIDynSeg}^M = 1 ⇒ LegalIntentDynSegment\_F^γ(K\_I; Γ\_IDyn) = 1。证明：L1 由运行与分支的记录给出 γ 是真实运行轨迹的一段；L2 由更新证书与写入历史给出段内权威状态都由场的许可运行产生，没有段外写入；L3 由锚与身份体系的引用给出资格锚不更换，它不要求承担状态与概率组织的内部结构静止；L4 中，各评价点 IntentCoreCert^M = 1，由《意向数理式》定理 5 得 N\_I，由《意向必然式》的充分方向得 Intent，资格变化事件的覆盖给出其间没有退出与重新形成，合为资格在 γ 的全部场态上保持；L5 由同证据键给出所用证据取自同一 γ、同一运行；L6 由协议历史给出识别、比较与归属的协议事前冻结。条件：L4 只沿 IntentCoreCert^M 实际使用的 Law-bearing 见证传播适用的 H\_LawRead；其余各项是直接表示，不携 H。□

定理 2（源动发生动力）。Read\_{SourceOccurrenceDyn}^{M,γ} = 1 ⇒ SourceOccurrenceDyn\_I^γ = 1。证明：存在单元 u 使 SrcOcc^M(u) = 1。由《意向作用数理式》定理 1 的各项直接表示，u 内有属于 \[S\_I\]\_src 的现实源动续行，沿真实非零子段 Z\_src 实际进入同一 𝒫\_I，并与 K\_I 同锚；绑定给出它属于同一 γ、同一运行。Z\_src 是 γ 内的非零续行：它的起点或者在 γ 内，这是一次开始；或者在 γ 起点以前，于是它在与 γ 相交的子段上持续；它的终点同样或者在 γ 内，这是一次停止，或者在 γ 终点以后。所以这一源动职责在 γ 上必有跨时的开始、持续或停止之一。若要确定是哪一种，须用定义 13 的跨时证据；本定理不靠分类取得动力的存在。不携 H。□

定理 3（载体动力）。Read\_{CarrierDyn}^{M,γ} = 1 ⇒ CarrierDyn\_I^γ = 1。证明：存在候选登记 κ\_{ij}^car 与一步 k 使 Q\_{ij,k}^Car = 1。BearHold\_{ij,k}^M = 1 按《概率数理式》的正向回读给出 BearDim(L\_{ij}, v\_i, K\_I) 在这一步两端成立；StepDeg\_{ij,k} 为升、降或迁移，按《律动力数理式》的正向回读给出 L\_{ij} 在 Γ\_D^{ij} 之下发生程度动力，而 Γ\_D^{ij} 的职责对应固定为 v\_i 的正式方向承担，跨状态的承载对应固定为同一实现；SameCarrierDynBind\_{ij,k}^M = 1 给出同一 γ、同一运行、同一 K\_I。合为一般式的 CarrierDyn\_I^γ。条件：承担读数与程度读数所用的 Law-bearing 见证，按见证传播 H\_LawRead；程度读数的其余条件按《律动力数理式》原样承继，本系统不另立。候选域的冻结不表示承担状态的冻结。□

定理 4（意向概率动力）。Read\_{IntentProbDyn}^{M,γ} = 1 ⇒ IntentProbDyn\_I^γ = 1。证明：由定义 21，此时 SameIntentProbDynBind^M = 1 且 Read\_{N\_PDyn}^M = 1。由《概率动力数理式》的正向回读（7.1）得 N\_PDyn = 1，条件只沿实际正读路径传播；由《概率动力必然式》的充分方向得 ProbabilityDyn^γ(𝒫\_I; C\_I, 𝔯\_I) = 1，这一方向不携 H；归属绑定给出动力的对象正是 K\_I 中同一个 𝒫\_I，同一正式方向职责体系、同一欲门职责体系、同一 γ。合为一般式的 IntentProbDyn\_I^γ。不新增 H。□ 这里调用的是概率组式已封的充分方向，不是本组式的《意向动力必然式》。

定理 5（动力实际性）。Read\_{DynActual\_I}^{M,γ} = 1 ⇒ DynActual\_I^γ = 1。证明：由定义 29 与定理 2 至 4。□

定理 6（N\_IDyn 正向形式解定理）。Read\_{N\_IDyn^γ}^M = 1 ⇒ N\_IDyn^γ = 1。证明：由定理 1 与定理 5。条件：只沿实际使用的正读路径传播 H\_LawRead 等上游的正向条件；本定理不调用 H\_PAct-Rep、H\_ρRep^-、H^-\_M，不调用《概率动力一般式》必要方向的条件，也不调用 H\_GP、H\_TI、H\_PL、H\_SD。□

Read\_{N\_IDyn^γ}^M = 1 回读到 N\_IDyn^γ = 1 为止；N\_IDyn^γ ⇒ IntentDyn\_F^γ(K\_I) 属于《意向动力必然式》。

投影的正向回读如下，除作用投影、载体型与切换的调用下文注明所携条件外，均为直接表示。作用投影：ActStart^M、ActCont^M、ActStop^M 为 1，回读为一般式第六步的开始、继续与停止由定义 23 的真实机制成立，完整作用正见证按《意向作用数理式》定理 6 随所用见证传播 H\_LawRead；其中 NoAct^M = 1 的时间窗，按《意向作用数理式》七之 3 的失败层承继条件，含 A2 职责兑现子层者携 H\_PAct-Rep；ProbSide 为概率作用开始或续行，分别回读为第六步开始中“概率作用之开始真实成立”与“概率作用的当前续行保持成立”两种情形；停止层位回读为停止的层位分辨。源动的开始、持续、停止与停后再起，回读为一般式源动发生动力中的相应类型，不携 H。方向型：DirStep\_{i,k} 为升或降，回读为 Rel\_ρ 的真实变化使 \[v\_i\] 相对冻结比较集取得严格更高或更低的相对生成关系，即一般式的方向型增强或减弱；这一读数只用正比例等价类上不变的量，不由数值差回读。载体型：CarStep\_{ij,k} 为升、降或迁移，回读为一般式的载体型增强、减弱或迁移，条件同定理 3。剖面的比较只回读为申报坐标集上各类型读数的组合，不回读为任何总强度。切换的调用回读为《意向欲门切换数理式》定理 6 的结论，条件随之承继。

2\. 反向表示

负向回读要成立，须先有反向表示：结构层确有某一处动力时，形式层能取得相应的正证据。否则“候选已查完而没有正证据”推不出“结构层没有这一处动力”。

合法段的 L1、L2、L3、L6 都是对运行记录、更新与写入历史、锚与身份体系引用、协议历史的直接表示：在 IDyn-M2 至 IDyn-M6 成立时，结构层的拼接、直写、换锚与事后改写都有现实记录，并在覆盖完整时被读出。L5 不取 0，不设负向的反向表示。L4 不同：资格在 γ 内退出这一结构事实，形式层以 IntentCoreCert^M = 0 或资格退出的记录读出，而《意向数理式》七之 3 规定，它的形式零回读为结构零，须按失败路径承继负向表示条件，其完整的结构判定属于《意向判定式》。

源动一处的存在读数是直接表示：结构层在 γ 上有属于 \[S\_I\]\_src 的现实源动续行进入 𝒫\_I，它落在某一个评价单元内；由《意向作用数理式》七之 2，A1 一层的四项都是直接表示，在 IDyn-M8 成立、覆盖完整时，这一续行以 SrcOcc^M(u) = 1 进入读数。所以源动一处的存在读数不携表示条件。跨时分类只在所需记录可判时输出确定类型，记录不足只退为 ⊥。

载体一处：承担读数的反向表示按《概率数理式》的负端条件 H^-\_M 逐见证承继；程度读数的反向表示按《律动力数理式》与《律分级式》原样承继。本系统不新立表示条件。

概率一处：反向表示完全沿用《概率动力数理式》七之 2：ActDyn 支承继 H\_PAct-Rep，RateBearingStructDyn 支承继 H\_ρRep^-，其余直接表示。证据的错配不是反向表示的路径。本系统不新立统一的反向桥。

3\. 负向回读

Read\_{N\_IDyn^γ}^M = 0 时，按所选的反证路径回读结构判词 N\_IDyn^γ = 0：

路径 L1、L2、L3、L6：相应的覆盖 Cov^traj、Cov^upd、Cov^anchor、Cov^prot 闭合，且有明确的拼接、直写、换锚或事后改写。不携 H。

路径 L4：形式读数为 0，回读为“资格在 γ 内退出或重新形成”，须按《意向数理式》七之 3 承继该失败路径的负向表示条件，并由《意向判定式》的负判路径闭合；这些条件未闭合时，结构判词为 ⊥（QualExitOpen）。L4 的 0 还有一层含义：γ 不在一般式主定理的工作域之内。所以即使结构判词成立，它也只说这一申报段不是同一意向的合法动力段，应按资格退出的边界分段重新申报，不回读为意向在 γ 上没有动力。

路径“三处都为 0”：三处须同时满足各自的条件。  
源动一处：Cov^Src\_γ 闭合，全部单元的 SrcOcc^M(u) = 0。这回读为 γ 上没有属于 \[S\_I\]\_src 并进入 𝒫\_I 的现实源动续行，因而没有源动发生动力；它不要求先给不存在的续行分类。不携 H。  
载体一处：CarRegCover^M 闭合，每一候选的每一步都有 Q\_{ij,k}^Car = 0，并且这些 0 所用的承担读数与程度读数满足上游的负向回读条件；条件未闭合时，结构判词为 ⊥（CarrierNegOpen）。这一回读以 T\_γ 的分辨率为限：相邻评价点之间若有升而复降，本次评价读不到，那是分辨率的限度，不是结论被推翻；须更细的事前申报评价点另行暴露。  
概率一处：须 SameIntentProbDynBind^M = 1 且 Read\_{N\_PDyn}^M = 0。先按《概率动力数理式》七之 3 回读 N\_PDyn = 0，沿实际失败路径承继 H\_PAct-Rep、H\_ρRep^- 或 H^-\_M；再由《概率动力一般式》必要方向 ProbabilityDyn^η ⇒ N\_PDyn 取逆否，得 ProbabilityDyn^γ(𝒫\_I) = 0，这一步携该必要方向的条件 H2 ∧ H3^red。所需条件未闭合时，结构判词为 ⊥（PDynNegOpen）。概率证据的错配只得 ⊥（ProbBindMismatch），不进入这一路径。分辨率的限度同载体一处。

每一条所选路径都满足条件时，N\_IDyn^γ = 0。所携条件是所选路径所携条件的合取：只有所选路径经由概率一处时，才携 H2 ∧ H3^red 与上游的失败路径条件；只有所选路径经由载体一处时，才携载体的上游负向条件；只有所选路径是 L4 时，才需要资格负判的闭合。不得因为某一条未选用的路径上条件未闭合，就否认另一条无条件路径已经取得的结构 0。

由《意向动力一般式》的必要方向 IntentDyn\_F^γ(K\_I) ⇒ N\_IDyn^γ 取逆否，在主定理的工作域内，N\_IDyn^γ = 0 ⇒ IntentDyn\_F^γ(K\_I) = 0。这一箭头不另增条件；所携条件仍是所选路径的条件。经由 L4 路径取得的 0 不走这一箭头：L4 的 0 使 γ 落在主定理的工作域之外。这一结论只否定这一申报段上的意向动力：它不推出别的段上没有意向动力，不推出意向作用或意向资格不成立，也不推出场中没有别的动力。

4\. 未决与零型

Read\_{N\_IDyn^γ}^M = ⊥ 既不推出意向动力成立，也不推出意向动力不成立：

&nbsp;&nbsp;&nbsp;&nbsp;没有找到正证据 ≠ 0，　⊥ ≠ 0，　Read = ⊥ ⇏ N\_IDyn^γ = 0  
&nbsp;&nbsp;&nbsp;&nbsp;ProbBindMismatch ⇏ IntentProbDyn = 0，　CarrierBindMismatch ⇏ CarrierDyn = 0，　EvidenceSplice ⇏ N\_IDyn^γ = 0  
&nbsp;&nbsp;&nbsp;&nbsp;剖面不适用 ≠ ⊥，　剖面不适用 ⇏ IntentDyn = 0

DeclarationZero 不回读为 N\_IDyn^γ = 0，只退为 ⊥（DeclarationInvalid）。ReaderImplementationInvalid 既不回读为 1，也不回读为 0。

5\. 禁止回读

不得：Read\_{N\_IDyn^γ}^M = 1 ⇒ IntentDyn\_F^γ(K\_I) = 1；这一方向须经《意向动力必然式》。  
不得：以相邻单元的 SrcOcc^M 取值定义源动的开始、持续或停止；两个相邻单元都有发生 ⇒ 持续；后态记录缺失 ⇒ 停止。  
不得：以时间窗或单元的作用端态之差定义作用的开始、继续或停止；把不同候选取得的层拼成到达层。  
不得：程度读不出 ⇒ 减弱；Rel\_ρ 的表示缺失 ⇒ 方向型减弱；迁移 ⇒ 升或降。  
不得：成员律的起、续、止 ⇒ 载体动力；场中任一概率动力 ⇒ 意向概率动力；外来证据的 0 ⇒ 本对象没有动力。  
不得：合法的承担者更替或正式维结构的变化 ⇒ L3 或 L6 为 0。

K-IDM1：Read\_{N\_IDyn^γ}^M = 1，而结构层 N\_IDyn^γ = 0。
