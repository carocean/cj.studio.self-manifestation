自显论 · 理篇 · 意向组式第十三 v1.0

# 意向反演式

一、目的

在事前冻结的合法观测协议 Π 下，给定实际观测 y，确定：由 y 最多能够知道一段申报轨迹 γ 上意向有没有动力；最多能够知道合法动力段 L1 至 L6 与源动、承担律、概率组织三处的哪些部分；什么时候已经证明不可辨明，什么时候只是前像没有查全，什么时候只是候选自身的动力分类没有关闭，什么时候候选的整段 γ 不能合法调用双向闭合来签值。

观测不把内部系统还原为一个答案，只把可能的内部系统缩成一个前像。意向动力能否由此识出，不在于结果有多像意向在动，而在于这个前像中还能不能同时容纳有意向动力与没有意向动力的合法候选。

本篇不重新定义 IntentDyn\_F^γ(K\_I)、N\_IDyn^γ、LegalIntentDynSegment\_F^γ(K\_I; Γ\_IDyn)、SourceOccurrenceDyn\_I^γ、CarrierDyn\_I^γ 与 IntentProbDyn\_I^γ，不新增第四处动力，不重建《意向动力数理式》的形式系统，不回答怎样检查一个现实实例是否有意向动力。

1\. 上游冻结结论

《意向动力一般式》：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IDyn^γ := LegalIntentDynSegment\_F^γ(K\_I; Γ\_IDyn) ∧ DynActual\_I^γ  
&nbsp;&nbsp;&nbsp;&nbsp;DynActual\_I^γ := SourceOccurrenceDyn\_I^γ ∨ CarrierDyn\_I^γ ∨ IntentProbDyn\_I^γ

合法段的六项是：L1 γ 是沉积场一条真实运行轨迹的一段；L2 段内状态都由场的合法运行产生，没有段外写入；L3 资格锚不更换；L4 意向资格在 γ 的全部场态上保持成立；L5 三处的证据取自同一 γ、同一运行；L6 识别、比较与归属的协议在看到结果以前冻结。必要方向 IntentDyn\_F^γ(K\_I) ⇒ N\_IDyn^γ，Status = Established。

《意向动力必然式》：充分方向 N\_IDyn^γ ⇒ IntentDyn\_F^γ(K\_I)，Status = Established，不携 H。两篇合成，在共同工作域内：

&nbsp;&nbsp;&nbsp;&nbsp;IntentDyn\_F^γ(K\_I) ⇔ N\_IDyn^γ

基础工作域是：

&nbsp;&nbsp;&nbsp;&nbsp;W\_IDyn := Intent\_{F,t\_0} = 1

即 γ 的起点意向成立。资格在整段上的保持是 LegalIntentDynSegment 的结构分量 L4，不并入基础工作域，也不另作工作域的假设。由此：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IDyn^γ = 1 ⇒ IntentDyn\_F^γ(K\_I) = 1，不携 H；  
&nbsp;&nbsp;&nbsp;&nbsp;N\_IDyn^γ = 0 ⇒ IntentDyn\_F^γ(K\_I) = 0，这一步是必要方向的逆否，不另增条件；N\_IDyn^γ = 0 本身若由《意向动力数理式》的负向回读取得，携所选反证路径的条件。

逆否一步另受 L4 纪律的限制，见下。

《意向动力数理式》：三值形式系统与正向回读 Read\_{N\_IDyn^γ}^M = 1 ⇒ N\_IDyn^γ = 1；负向回读按所选反证路径（该篇七之 3）。该篇同时封闭以下纪律，本篇全部保持：

&nbsp;&nbsp;&nbsp;&nbsp;EvidenceSplice ⇏ N\_IDyn^γ = 0  
&nbsp;&nbsp;&nbsp;&nbsp;CarrierBindMismatch ⇏ CarrierDyn\_I^γ = 0  
&nbsp;&nbsp;&nbsp;&nbsp;ProbBindMismatch ⇏ IntentProbDyn\_I^γ = 0  
&nbsp;&nbsp;&nbsp;&nbsp;L5 只取 1 或 ⊥，不取 0

L4 的 0 表示资格在 γ 内退出或重新形成：它可以回读为这一申报段不是同一意向的合法动力段，即 N\_IDyn^γ = 0；但这一申报段由此落出工作域（《意向动力数理式》七之 3，《意向动力必然式》接口），不回读为 IntentDyn\_F^γ(K\_I) = 0，应按资格退出的边界重新分段。所以 L4 = 0 时，整段 γ 不再使用 N\_IDyn^γ = 0 ⇒ IntentDyn\_F^γ(K\_I) = 0 的逆否链。这是 L4 的特例纪律，不是把 L4 并入基础工作域。

本篇因此要把整段 γ 作为同一意向的一段动力来反演时，除基础工作域外，还要求 L4 = 1 已经签出；这一要求是反演任务的整段适用条件，不是 IntentDyn 的新条件。

2\. 三个认识层次

本篇区分关于意向动力的三个层次：

真值层：意向在 γ 上有没有动力。  
位置层：三处中哪几处在动。  
细节层：某一处内部具体怎样动，例如源动是开始、持续、停止还是停后再起，哪一条承担律在升、降或迁移，概率组织是关系在变还是结构在变，有没有中间复原。

本篇证明：三个层次之间不存在一般的自上而下推出，真值可识别不推出位置可识别，位置可识别不推出细节可识别；自下而上的推出，须下层所识别的信息足以确定上层目标。

二、观测协议、前向映射与反演准入

1\. 观测协议

&nbsp;&nbsp;&nbsp;&nbsp;Π = (D\_Π, Y\_Π, H\_Π, Prot\_Π)

D\_Π：合法候选内部系统的域。每个成员 X 是一份完整规定的候选内部世界，至少包括：沉积场 F，申报轨迹 γ，资格锚 K\_I，比较与归属协议 Γ\_IDyn，意向资格在 γ 上的历史，运行与分支的身份，内部更新与写入的历史，源动职责 \[S\_I\]\_src 的现实历史，承担律及其程度的历史，正式概率组织 𝒫\_I 及其概率动力的历史，以及与之相关的作用、切换、调谐、门后输出、显化与效应。候选是完整的内部世界，不是零散的解释片段。

Y\_Π：协议允许取得的观测空间。可以包括外部行为、场外输出、已显化的结果、效应序列、合法可读的场侧投影、时间序列、合法干预以后的响应，以及上游已经建立的其他观测接口。这里不预先规定哪一种观测天然更有分辨力。

H\_Π：D\_Π → Y\_Π，前向映射：给定候选内部世界 X，协议下会得到的观测 H\_Π(X)。

Prot\_Π：事前冻结的观测协议，规定观测的对象、申报窗、时间窗、采样、分辨率、允许的干预、观测通道、记录格式与候选域的版本。

实际观测：y ∈ Y\_Π。

2\. 前向映射的来源

H\_Π 必须由已经成立的式给出：由场系统、已封版的形式系统、已经建立的合法外部接口，以及以后由《意向运行基底构造式》给出的运行基底接口，说明候选内部世界 X 在 Prot\_Π 之下会产生什么观测。H\_Π 的来源须逐项写明。

不得以“有意向动力就会表现出某种行为”这样的假定充当前向映射，再用它反演意向动力。凭空假定一个由意向动力到观测的统一总映射，不构成合法的前向映射。

3\. 反演准入

&nbsp;&nbsp;&nbsp;&nbsp;AdmIInv(Π) := DomainFrozen ∧ ObsSetFrozen ∧ ForwardMapEstablished ∧ NoInternalAnswerLeak ∧ NoTargetPreselection ∧ SameDeclaredWindow

DomainFrozen：D\_Π 在观测以前冻结；看见结果以后，不删除不利的候选，不重切候选域。

ObsSetFrozen：Y\_Π 与 Prot\_Π 在观测以前冻结；看见结果以后，不追加只对某一解释有利的观测。

ForwardMapEstablished：H\_Π 按本节第 2 条有已成立的来源。

NoInternalAnswerLeak：y 不直接含有待反演的答案，也不直接含有签出这些答案的内部判词与证书。包括：IntentDyn\_F^γ(K\_I)、N\_IDyn^γ；Read\_{N\_IDyn^γ}^M、Read\_{LegalIDynSeg}^M、Read\_{SourceOccurrenceDyn}^{M,γ}、Read\_{CarrierDyn}^{M,γ}、Read\_{IntentProbDyn}^{M,γ}；L1 至 L6 的正式判词；SameIDynBind^M、SameCarrierDynBind^M、SameIntentProbDynBind^M；上游直接签出三处动力真值的形式证书。由合法可读的场侧投影经已成立的前向关系分离出这些答案，是识别，不是泄漏；泄漏是把答案本身或签出答案的判词放进 y。这些东西一旦进入观测端，反演就被换成了判定。

NoTargetPreselection：D\_Π 不是预先只保留有意向动力的候选而得，不是用与 IntentDyn 等价的内部判词筛选而得，也不是预先认定“这里一定是源动在动”或“这里一定是概率组织在动”而只保留相应位置的候选。

SameDeclaredWindow：D\_Π 中所有候选取同一申报窗：同一申报对象、同一起止评价点、同一申报的 Γ\_IDyn。Γ\_IDyn 在某一候选内部是否事前冻结，是该候选的 L6，不是准入。不得让正候选取整段而负候选取局部，也不得让一个候选以资格退出点以前为对象、另一个以退出点以后为对象。申报窗不同的候选不属于同一反演问题。

y 中含有别的运行、别的分支或别的锚的材料时，分三种情形：

协议本来不许这些材料进入，看见结果以后又混进来：ObsSetFrozen 不成立，协议失格，反演不进入。

协议事前合法地申报了对其他运行、其他对象的观测：这些材料仍是 y 的一部分，由 H\_Π 说明它们怎样由候选世界产生；它们不承担当前 γ 的内部归属，对当前目标可能没有分离力，但不使协议失格。

把这些材料当作当前 γ 自身的证据：这是证据拼接或目标绑定错误，不使前像中任何候选得到 0；若它进入候选的分类，该候选的相应标签为 ⊥（EvidenceSplice、CarrierBindMismatch 或 ProbBindMismatch）。

三种情形都不是 IntentDyn\_F^γ(K\_I) = 0，也不是 N\_IDyn^γ = 0。

AdmIInv 是反演的准入，不是新的意向动力本体条件，不计入 H。AdmIInv(Π) = 0 时，不进入反演。

三、候选标签与整段适用

候选标签描述候选内部世界的理论分类，用来刻画前像；它不是观测，不进入 y，与 NoInternalAnswerLeak 不冲突。标签记录的是当前上游理论是否已经合法签出该候选的相应真值；⊥ 表示真值当前没有被理论链关闭，不表示意向动力在本体上有第三个真值。

1\. 整段适用标签

&nbsp;&nbsp;&nbsp;&nbsp;Dom(X) ∈ {In, Out, ⊥}

Dom 不是意向动力的真值，也不是新的工作域定义；它记录的是：对候选 X，能否把整段 γ 作为同一意向的一段动力，合法调用双向闭合来签值。

In：X 在基础工作域 W\_IDyn 内，并且已有合法的上游结论签出 L4(X) = 1，即资格在 γ 的全部场态上保持。由对象层给定时不携 H；由《意向动力数理式》定理 1 的 L4 正读取得时，沿所用 Law-bearing 见证携 H\_LawRead。

Out：已有合法的上游结论签出下列两种失败之一，并附原因：

&nbsp;&nbsp;&nbsp;&nbsp;Reason\_Out ∈ { StartDomainFail, QualExit }

StartDomainFail：γ 的起点意向不成立，X 不在基础工作域 W\_IDyn 内，这一组式的意向动力问题在这一段上根本不提出。由《意向判定式》的资格负判（经《意向一般式》必要方向的逆否）取得，携其条件。

QualExit：起点意向成立，而 L4(X) = 0，资格在 γ 内退出或重新形成。经《意向动力数理式》的 L4 路径取得，须承继《意向数理式》七之 3 的负向表示条件，并由《意向判定式》的负判路径闭合。

两者都进入 Out，但来源不同，不得互相替代：前者是基础工作域不成立，后者是基础工作域成立而合法段的 L4 分量失败。

⊥：当前没有合法的上游结论签出上述 In 或 Out。附开放原因：

&nbsp;&nbsp;&nbsp;&nbsp;Reason\_DomOpen ∈ { StartDomainOpen, QualExitOpen }

StartDomainOpen：当前尚未合法签出 Intent\_{F,t\_0} = 1 或其否定，候选是否进入基础工作域 W\_IDyn 未闭合。后续的资格材料无论多么丰富，在起点关闭以前，这都不是资格退出是否发生的问题。

QualExitOpen：已经签出 Intent\_{F,t\_0} = 1，但 L4 是否在 γ 全段保持尚未合法关闭，或 L4 负路径所需的条件尚未闭合。

2\. 动力真值标签

&nbsp;&nbsp;&nbsp;&nbsp;Class\_IDyn(X) ∈ {1, 0, ⊥, OutDom}

Class\_IDyn(X) = 1：已有合法的上游结论签出 IntentDyn\_F^γ(K\_I; X) = 1。当前的充分来源是 N\_IDyn^γ(X) = 1 ⇒ IntentDyn\_F^γ(K\_I; X) = 1（《意向动力必然式》），不携 H。N\_IDyn^γ(X) = 1 由对象层给定时，标签不携 H；由形式读数经《意向动力数理式》定理 6 取得时，携所用正读路径的条件。N\_IDyn^γ = 1 含 L4 = 1，而 L4 = 1 含起点意向成立，所以 Class\_IDyn(X) = 1 蕴涵 Dom(X) = In。

Class\_IDyn(X) = 0：Dom(X) = In，并且已有合法的上游结论经 L4 以外的路径签出 N\_IDyn^γ(X) = 0，再经必要方向的逆否得到 IntentDyn\_F^γ(K\_I; X) = 0。所携条件按所选路径：路径 L1、L2、L3、L6 不携 H；三处都为 0 的路径中，源动一处不携 H，载体一处携上游的载体负向条件，概率一处携 H2 ∧ H3^red 与 H\_PAct-Rep、H\_ρRep^-、H^-\_M 中实际失败路径所用者。逆否一步不另增条件；另携 Dom(X) = In 所用的条件。

Class\_IDyn(X) = OutDom：Dom(X) = Out，附 Out 的原因。

Class\_IDyn(X) = ⊥：其他情形。⊥ 附子原因：Dom(X) = ⊥ 时，按 Dom 的开放原因附 StartDomainOpen 或 QualExitOpen；Dom(X) = In 而动力真值未闭合时为 DynClassOpen，其中来自证据拼接或证据错配的，另附 EvidenceSplice、CarrierBindMismatch 或 ProbBindMismatch。

由 L2 等路径已经签出 N\_IDyn^γ(X) = 0，而 Dom(X) = ⊥ 时，Class\_IDyn(X) = ⊥，按 Dom 的开放原因附 StartDomainOpen 或 QualExitOpen，不为 0：起点意向未确定时，候选是否在基础工作域内未定；L4 实际为 0 时，整段不再使用逆否链；所以 Dom 未确定时不得取逆否。

Class\_IDyn 是合法上游签出的状态，不限定只能由 N\_IDyn^γ 取得；以后若有其他已成立的式签出意向动力真值，按其来源及所携条件进入。

正标签与负标签所携条件不对称：由对象层经充分方向取得的正标签不携 H，负标签按所选路径可能携条件。这一不对称来自上游证明的现状，不是意向动力本体的正负不对称。

3\. OutDom 不并入 0，也不是第三个真值

&nbsp;&nbsp;&nbsp;&nbsp;OutDom ≠ IntentDyn = 0  
&nbsp;&nbsp;&nbsp;&nbsp;OutDom ≠ IntentDyn 的第三个真值

IntentDyn\_F^γ(K\_I) 在对象层仍是二值性质。OutDom 是反演任务的适用状态：当前理论不能对这一整段 γ 合法调用双向闭合来给它签值。StartDomainFail 时，这一段不在基础工作域内；QualExit 时，按 L4 纪律，整段不再使用逆否链，正确的处理是按资格边界重新分段，对新的 γ\_1、γ\_2 分别申报。把 OutDom 候选当作普通负候选，违反《意向动力数理式》与《意向动力必然式》已经封闭的 L4 纪律。

重新分段产生的是新的反演问题：新的申报窗及其协议须按 AdmIInv 重新申报与冻结；分段边界只能由资格边界的合法判定给出，不能按 y 的哪一部分对某一解释有利来切。

4\. 分量标签

对 φ ∈ {N, L1, …, L6, Src, Car, Prob}：

&nbsp;&nbsp;&nbsp;&nbsp;Class\_φ(X) ∈ {1, 0, ⊥}，三处另可取 OutDom

Class\_N：1 经 N\_IDyn^γ(X) = 1；0 经任一闭合的负向路径，包括 L4 路径。资格在 γ 内退出的候选，其 N\_IDyn^γ = 0 是正确的结构判词：它只说这一申报段不是合法动力段，不推到 IntentDyn。所以 OutDom 候选可以有 Class\_N = 0，而 Class\_IDyn = OutDom。

Class\_{Li}：1 经《意向动力数理式》定理 1 的各项正读，L4 沿见证携 H\_LawRead，其余不携 H；0 经相应的负向路径，L1、L2、L3、L6 不携 H，L4 携 L4 路径的条件。Class\_L5 只取 1 或 ⊥：当前材料不能证明同轨，不是对象层 L5 = 0；证据拼接只得 ⊥（EvidenceSplice）。

三处 Class\_Src、Class\_Car、Class\_Prob：本篇把三处作为同一意向整段动力的位置来反演，所以只在 Dom(X) = In 时签 1 或 0；Dom(X) = Out 时记 OutDom；Dom(X) = ⊥ 时为 ⊥，并沿 Dom 的开放原因附 StartDomainOpen 或 QualExitOpen。Class\_Src 的 1 与 0 都不携 H。Class\_Car 的 1 沿见证携 H\_LawRead，0 携上游的载体负向条件；CarrierBindMismatch 只得 ⊥。Class\_Prob 的 1 携所用正读路径的条件，不新增 H，0 携 H2 ∧ H3^red 与实际失败路径的条件；ProbBindMismatch 只得 ⊥。

四、反演问题陈述

1\. 前像与观测等价

&nbsp;&nbsp;&nbsp;&nbsp;E\_Π(y) := H\_Π^{-1}(y) = { X ∈ D\_Π \| H\_Π(X) = y }  
&nbsp;&nbsp;&nbsp;&nbsp;X\_a ∼\_Π X\_b ⇔ H\_Π(X\_a) = H\_Π(X\_b)

∼\_Π 是 D\_Π 上的等价关系。E\_Π(y) 非空时，是实际观测所对应的等价类。

2\. 反演性质族

&nbsp;&nbsp;&nbsp;&nbsp;Φ\_IDyn = { φ\_I, φ\_N, φ\_L1, …, φ\_L6, φ\_Src, φ\_Car, φ\_Prob }

φ\_I(X) := IntentDyn\_F^γ(K\_I; X)，对象层二值性质。  
φ\_N(X) := N\_IDyn^γ(X)。  
φ\_Li(X) := Li(X)，i = 1, …, 6。  
φ\_Src(X) := SourceOccurrenceDyn\_I^γ(X)，φ\_Car(X) := CarrierDyn\_I^γ(X)，φ\_Prob(X) := IntentProbDyn\_I^γ(X)。

位置：对 Dom(X) = In 的候选，

&nbsp;&nbsp;&nbsp;&nbsp;Site(X) := { s ∈ {Src, Car, Prob} \| φ\_s(X) = 1 }

φ\_Site(X) := Site(X)。DynActual\_I^γ(X) = 1 当且仅当 Site(X) ≠ ∅；在合法段成立时，N\_IDyn^γ(X) = 1 当且仅当 Site(X) ≠ ∅。

这些都是候选的对象层真值，不因反演而变为三值，也不因整段适用失败而取得第三个值。实际求解时不直接访问这些真值，而以第三节的标签记录当前理论是否已经合法签出它们；Dom(X) = Out 的候选，其 φ\_I 与三处的整段值当前理论不签，标签记 OutDom。

由此，对 φ\_I 与三处，前像中有 OutDom 候选时，即使其他成员的值都已签出，也不能确认这些性质在 E\_Π(y) 上恒定：OutDom 候选的值没有合法来源。所以 IdentAt\_Π(φ\_I; y) 不能在这样的前像上取得。

3\. 不进入反演核的对象

作用的开始、继续、停止、重启，方向型与载体型的增强与减弱，欲门切换，门后的反持与理之行，显化、调谐结果与行为效应，都不是 N\_IDyn^γ 的分量。它们是作用投影、类型化读数、邻接的门层事件、输出或后果，可以作为附报进入反演，但不进入反演核，也不得因反演而升格为意向动力的条件。

4\. 问题

由 y 求前像 E\_Π(y) 的界：由 y 最多能够知道候选内部世界的什么，以及关于 Φ\_IDyn 中每一性质最多能够知道什么。

前像不是最可能的解释，不是拟合最好的解释，不是心理上最合理的解释，也不是最简单的解释。这里不引入贝叶斯先验与后验，不给前像成员赋可信度，不以统计拟合优度代替结构可识别性。

5\. 前像覆盖

实际求解时，前像以枚举候选集 Ê\_Π(y) ⊆ E\_Π(y) 给出。前像覆盖证书：

&nbsp;&nbsp;&nbsp;&nbsp;InvCover\_Π(y) ∈ {1, 0, ⊥}

1：已证明 Ê\_Π(y) = E\_Π(y)，合法候选已经查全。  
0：已证明 Ê\_Π(y) ⊊ E\_Π(y)，已知至少还有一个合法候选没有被当前枚举包含。  
⊥：既不能证明覆盖完整，也没有取得明确的遗漏见证。

InvCover\_Π(y) ≠ 1 时，前像覆盖未闭。

五、可识别性与上界

1\. 定理一　性质可识别因子化定理

对内部性质 φ：D\_Π → Z，定义 Ident\_Π(φ)：存在函数 g\_φ：Im(H\_Π) → Z，使对所有 X ∈ D\_Π，φ(X) = g\_φ(H\_Π(X))。其中 Im(H\_Π) = H\_Π(D\_Π)。则：

&nbsp;&nbsp;&nbsp;&nbsp;Ident\_Π(φ) ⇔ \[ ∀X\_a, X\_b ∈ D\_Π：X\_a ∼\_Π X\_b ⇒ φ(X\_a) = φ(X\_b) \] ⇔ ∃g\_φ：Im(H\_Π) → Z，φ = g\_φ ∘ H\_Π

局部形式：定义 IdentAt\_Π(φ; y)：存在 z ∈ Z，使对所有 X ∈ E\_Π(y)，φ(X) = z。则

&nbsp;&nbsp;&nbsp;&nbsp;IdentAt\_Π(φ; y) ⇔ φ 在 E\_Π(y) 上恒定

记 NonIdent\_φ^Π(y) := ¬IdentAt\_Π(φ; y)；对 φ\_I 记作 NonIdent\_I^Π(y)。

证明：由左推中：若 φ = g\_φ ∘ H\_Π，且 H\_Π(X\_a) = H\_Π(X\_b)，则 φ(X\_a) = g\_φ(H\_Π(X\_a)) = g\_φ(H\_Π(X\_b)) = φ(X\_b)。由中推右：若 φ 在每个等价类上恒定，对 Im(H\_Π) 中的每一个 y′，取 E\_Π(y′) 中任一成员 X，令 g\_φ(y′) := φ(X)；由恒定性，这一定义与所取成员无关，于是对任意 X，φ(X) = g\_φ(H\_Π(X))。右即左的定义。局部形式同理，只在 E\_Π(y) 上论证。□

数据量多不自动意味着可识别。可识别的真正条件是：目标性质不区分任何观测协议无法区分的两个合法候选。

2\. 定理二　观测等价上界定理

在 AdmIInv(Π) = 1 下，给定 y = H\_Π(X)，只使用 y 的反演对候选内部世界的最细合法分辨率是 E\_Π(y)；任何只依赖 y 的合法反演输出，都不能进一步区分同一前像中的成员。

证明：只依赖 y 的反演输出是 y 的函数 K(y)。设 X\_a, X\_b ∈ E\_Π(y)，而 K 声称能够区分二者，即对 X\_a 输出 K\_a、对 X\_b 输出 K\_b，且 K\_a ≠ K\_b。但 H\_Π(X\_a) = H\_Π(X\_b) = y，二者给 K 的输入相同，K(y) 只能取一个值。矛盾。□

记 KnowMax\_Π(y) := E\_Π(y)。KnowMax 只是反演上界的形式名称，不是新的本体谓词。

3\. 命题一　协议加细

设 Π′ 与 Π 有同一候选域，且存在函数 f 使 H\_Π = f ∘ H\_Π′，称 Π′ 加细 Π。则对任意 y′ ∈ Im(H\_Π′)，E\_Π′(y′) ⊆ E\_Π(f(y′))；对任意 φ，Ident\_Π(φ) ⇒ Ident\_Π′(φ)，反之不成立。

证明：H\_Π′(X) = y′ 推出 H\_Π(X) = f(y′)，得包含关系。若 φ = g ∘ H\_Π，则 φ = (g ∘ f) ∘ H\_Π′。反向的不成立，只需一对在 Π′ 下分开、在 Π 下等价而 φ 值不同的候选。□

所以：更强的协议后来能够分离，不推出原协议本来可识别；原协议之下的不可识别，也不推出在一切协议之下不可识别。

4\. 命题二　同型重复不增加分离

设在 Π 上追加观测分量 h，得 H\_Π^h(X) := (H\_Π(X), h(X))。若 X\_a ∼\_Π X\_b 且 h(X\_a) = h(X\_b)，则 X\_a ∼\_{Π^h} X\_b。

证明：直接由定义。□

所以：追加的材料只有在它对某一对原先等价的候选取值不同时，才增加分离能力。重复采集完全同型、对这一对候选输出相同的数据，不能消除它们之间的观测等价。真正的协议增强须增加新的通道、新的时序、新的干预、更高的分辨率，或新的合法前向分离量。

六、动力真值、动力位置与动力细节

1\. 定理三　意向动力真值可识别定理

设 AdmIInv(Π) = 1。

（1）若 E\_Π(y) 非空，且它的所有成员都有 Class\_IDyn = 1，则 IdentAt\_Π(φ\_I; y)，值为 1；若所有成员都有 Class\_IDyn = 0，则 IdentAt\_Π(φ\_I; y)，值为 0。

（2）若存在 X\_1, X\_0 ∈ E\_Π(y)，使 Class\_IDyn(X\_1) = 1，Class\_IDyn(X\_0) = 0，则 NonIdent\_I^Π(y) = 1；任何只使用该协议观测的反演，都不得在这个 y 上签出 IntentDyn = 1 或 IntentDyn = 0。

证明：（1）由标签的含义，所有成员的 φ\_I 取同一值，由定理一的局部形式得 IdentAt。（2）由标签的含义，φ\_I(X\_1) = 1，φ\_I(X\_0) = 0，φ\_I 在 E\_Π(y) 上不恒定，由定理一得 NonIdent\_I^Π(y) = 1。再由定理二，只依赖 y 的输出对 X\_1 与 X\_0 相同：签 1 则对 X\_0 为错，签 0 则对 X\_1 为错；二者都在合法前像之中，协议不能排除任何一个。□

（1）讲的是前像本身。实际求解只能看到枚举集 Ê\_Π(y)，所以（1）进入对外读出时，还须覆盖闭合，见第八节。（2）只要已经找到两个异标签的合法成员即成立，不以覆盖闭合为前提。

（2）是已经证明的不可辨识，不是当前枚举不足。只要追加的材料仍属于同一个不增加分离能力的观测协议，或者扩展后的协议仍使这一对候选观测等价，增加这类数据就不能消除这一不可辨识；若新观测引入了新的合法分离量，那已经是更强协议之下的另一次反演。

条件传播：定理三自身不新增、也不继承 H，它以标签已经成立为前提。具体应用中，结论携所用标签的条件：（1）的值为 1 时携各正标签的条件，值为 0 时携各负标签的条件；（2）的结论携 X\_1 的正标签与 X\_0 的负标签的条件。

2\. 命题三　组成可识别推出真值可识别

若 E\_Π(y) 的所有成员都有 Dom = In，且 φ\_L1、…、φ\_L6、φ\_Src、φ\_Car、φ\_Prob 在 y 上都可识别，则 φ\_N 与 φ\_I 在 y 上都可识别。

证明：φ\_N 是这九个分量的函数：N = (L1 ∧ … ∧ L6) ∧ (Src ∨ Car ∨ Prob)。各分量在 E\_Π(y) 上恒定，φ\_N 也恒定。在 Dom = In 的候选上，由双向式 φ\_I = φ\_N，所以 φ\_I 恒定。□

在全部成员 Dom = In 的前像上，φ\_N 与 φ\_I 的反演同值，标签条件也相同，因为逆否一步不另增条件。前像中有 Dom = Out 的成员时，二者分开：这样的成员可以有 Class\_N = 0，而 Class\_IDyn = OutDom。

3\. 定理四　动力位置不可由动力真值推出

&nbsp;&nbsp;&nbsp;&nbsp;IdentAt\_Π(φ\_I; y) ⇏ IdentAt\_Π(φ\_Src; y) ∧ IdentAt\_Π(φ\_Car; y) ∧ IdentAt\_Π(φ\_Prob; y)

这是协议相对的结构模板，不申报新的运行实现，也不断言某种具体的运行已经存在。模板条件是：AdmIInv(Π) = 1，并且 D\_Π 中确有下述候选。

二候选模板：设 X\_S, X\_C ∈ D\_Π，Dom 都为 In，L1 至 L6 的标签都为 1；Class\_Src(X\_S) = 1；Class\_Src(X\_C) = 0，Class\_Car(X\_C) = 1。由《意向动力必然式》，Class\_IDyn(X\_S) = Class\_IDyn(X\_C) = 1。若 H\_Π(X\_S) = H\_Π(X\_C) = y，且 E\_Π(y) 的成员都有 Class\_IDyn = 1，例如 E\_Π(y) = {X\_S, X\_C}，则 IdentAt\_Π(φ\_I; y) 成立，值为 1；而 φ\_Src(X\_S) = 1，φ\_Src(X\_C) = 0，由定理一，NonIdent\_Src^Π(y) = 1。

源动一处的负标签不携 H，所以二候选模板的结论在正标签取自对象层时不携 H。

三候选模板：再设 X\_P ∈ D\_Π，Dom 为 In，L1 至 L6 的标签都为 1，Class\_Src(X\_P) = 0，Class\_Car(X\_P) = 0，Class\_Prob(X\_P) = 1；并令 Class\_Car(X\_S) = Class\_Prob(X\_S) = 0，Class\_Prob(X\_C) = 0。若三者同属 E\_Π(y)，且 E\_Π(y) 的成员都有 Class\_IDyn = 1，则 φ\_I 在 y 上可识别而三处都不可识别。这里载体与概率两处的负标签各携其条件，三候选模板的结论随之携带。

所以，由 IdentAt\_Π(φ\_I; y) 推出三处可识别，不能作为反演的一般规则：凡是 D\_Π 含有这样的候选的协议，这一推断都在相应的 y 上失败。□

知道意向在动，不等于知道哪里在动。

4\. 位置的反演：单处、多处与位置混合

位置可识别，即 IdentAt\_Π(φ\_Site; y)，等价于三处都可识别。位置可识别时，按 Site 的值分为：

单处：Site 恒为只含一处的集合，只有一处在动。  
多处：Site 恒为含两处或三处的集合，同一候选中本来就有两处或三处同时在动。  
无处：Site 恒为空集；此时若合法段可识别为 1，则由命题三，φ\_I 可识别为 0。

位置不可识别而有两个已找到的成员 Site 值不同，为位置混合：多个观测等价的候选分别把这一 y 解释为不同的动力位置。

多处与位置混合不得混写。前者是同一候选里本来就有几处在动，是关于内部世界的确定知识；后者是不同候选分别给出不同位置，是协议的不可辨识。位置混合时，不得凭最可能、最合理或最简单的解释强选一处。

5\. 命题四　位置可识别不推出细节可识别

对任一细节性质 φ\_Det，例如源动在 γ 上是开始、持续、停止还是停后再起，哪一条 L\_ij 在升、降或迁移，概率动力是相对生成关系的变化还是正式维、共同绑定、率承担组织的变化，有没有中间复原，作用投影与类型化的增强、减弱：由定理一，IdentAt\_Π(φ\_Det; y) 当且仅当 φ\_Det 在 E\_Π(y) 上恒定。Site 在 E\_Π(y) 上恒定，不使 φ\_Det 恒定；只要 D\_Π 含有两个位置相同、细节不同、观测等价的候选，位置可识别而细节不可识别。□

例如两个候选都只有源动一处在动，一个的源动续行在 γ 内开始，另一个的在 γ 起点以前已在续行；若协议看不见 γ 起点以前的源动历史，二者可以观测等价。

三层之间不存在一般的自上而下推出。自下而上的推出须下层所识别的信息足以确定上层目标：所识别的细节属于已经闭合的候选对象，并足以确定三处各自的真值时，位置可识别；合法段与位置都可识别，且前像成员都有 Dom = In 时，真值可识别（命题三）。不是任一细节可识别就自动推出位置可识别。自上而下：

&nbsp;&nbsp;&nbsp;&nbsp;知道在动 ⇏ 知道哪里在动 ⇏ 知道怎样动

七、外部结果、干预与协议增强

1\. 定理五　外部结果不可普遍反推意向动力

若存在 X\_1, X\_0 ∈ D\_Π，使 Class\_IDyn(X\_1) = 1，Class\_IDyn(X\_0) = 0，H\_Π(X\_1) = H\_Π(X\_0) = y，则 NonIdent\_I^Π(y) = 1。

这是定理三（2）在外部结果上的应用。以下两个模板是协议相对的结构模板，模板条件同第六节第 3 条：AdmIInv(Π) = 1，并且 D\_Π 中确有相应的候选。

模板一　段外写入：给定 X\_1，协议 Π\_out 只记录场外的行为、显化、效应与调谐结果。构造 X\_0：资格整段保持，Dom 为 In；外部输出与 X\_1 相同，但意向自身状态在 γ 上的变化由段外的过程直接写入，而不是由场的合法运行产生。于是 L2(X\_0) = 0，经 L2 路径 N\_IDyn^γ(X\_0) = 0，再经逆否 Class\_IDyn(X\_0) = 0，不携 H。若 Π\_out 看不见内部写入路径，H\_{Π\_out}(X\_0) = H\_{Π\_out}(X\_1)。这一模板的结论在正标签取自对象层时不携 H。

模板二　外部机制代偿：给定 X\_1，构造 X\_0：合法段成立，资格整段保持，意向自身的三处都不动；同一外部行为、显化或效应由外部装置、不属于 K\_I 的另一概率组织、不承担 𝒫\_I 任何正式方向的律结构、环境机制或非意向的场过程产生。于是 Class\_Src(X\_0) = 0 不携 H；Class\_Car(X\_0) = 0 携上游的载体负向条件；Class\_Prob(X\_0) = 0 携 H2 ∧ H3^red 与实际失败路径的条件；Class\_IDyn(X\_0) = 0 携这些条件。若协议只记录这些外部结果，二者观测等价。这一模板中“X\_0 没有意向动力”的判断携上述条件。

所以：在只记录外部结果的协议下，只要模板条件满足，就存在这样的 y：

&nbsp;&nbsp;&nbsp;&nbsp;AdmIInv(Π\_out) = 1 ⊢ ObservedOutcome ⇏ IntentDyn

行为、显化、效应、调谐结果、外部动作与粗粒度输出，都不能只凭本身普遍反推意向动力，除非已成立的前向关系把异真值的候选分开。□

这一结论是协议相对的。不得写“行为永远不能反推意向动力”，也不得写“意向动力不可观察”；只能写：在协议 Π 下，若前像中有异真值的合法候选，该协议在这一观测上不能识别意向动力。

2\. 不得作的推断

不得写 NoObservedOutput ⇒ IntentDyn = 0。意向动力不以完整作用、欲门切换、显化、调谐成功、行为或效应为取得条件（《意向动力必然式》），没有观测到输出比没有输出更弱。

不得写 OutputChange ⇒ 某一处在动，也不得凭经验心理的直觉建立刺激与动力的对应：某种刺激一定引起源动，某种行为一定代表概率动力，某种注意变化一定代表载体动力，某种显化一定意味着意向动力。这些对应都须由已成立的前向关系给出。

不得写 Read^Inv = ⊥ ⇒ IntentDyn = 0，也不得写 NonIdent\_I^Π(y) = 1 ⇒ IntentDyn = 0：不可识别是认识的边界，不是对象的否定。

3\. 干预与分离

干预可以进入观测协议，但只能条件开放。不得写 Intervention ⇒ Identification。

设协议 Π 含一族在 Prot\_Π 中事前申报的合法干预 u，每一干预有前向映射 H\_{Π,u}。定义：

&nbsp;&nbsp;&nbsp;&nbsp;Sep\_Π(X\_a, X\_b) = 1 ⇔ ∃u ∈ Π：H\_{Π,u}(X\_a) ≠ H\_{Π,u}(X\_b)

由定理一，φ 在 Π 下普遍可识别，至少要求：对任意 φ(X\_a) ≠ φ(X\_b) 的两个候选，Sep\_Π(X\_a, X\_b) = 1。

有辨识力的是合法干预加上已成立的差异前向响应：干预 u 合法；H\_{Π,u} 有已成立的来源；异值候选对 u 的响应在协议下确实不同；实际响应落在其中一类。仅凭“干预以后系统变了”，不能推出意向有动力，也不能推出是哪一处在动。

干预只能经场的合法接口进入。干预若直接写入意向的源动、承担律或概率组织的状态，在被干预的候选中构成段外写入，L2 不成立，这一段不再是合法动力段；这样的干预改变了被反演的对象，不是对原对象的分离。

4\. 协议增强

由命题一与命题二：原协议下的 Mix 在更强协议下被分开，是另一个协议下的另一次反演，不推出原协议本来可识别；同型数据的重复不是协议增强。

八、反演状态与对外读出

1\. 内部反演状态

&nbsp;&nbsp;&nbsp;&nbsp;InvState\_I^Π(y) ∈ { I^+, I^-, Mix, DomOpen, InvOpen, ClassOpen }

依次判定：

Mix：已知前像中至少有一个 Class\_IDyn = 1 的候选和一个 Class\_IDyn = 0 的候选。由定理三（2），已证不可辨识。Mix 不以覆盖闭合为前提：只要已找到两个异标签的合法成员即成立。

DomOpen：不属于 Mix，并且或者已知前像中有 Class\_IDyn = OutDom 的候选，或者 InvCover\_Π(y) = 1 而前像中有 Dom = ⊥ 的候选。前一种只要已找到 OutDom 成员即成立，不以覆盖闭合为前提。

InvOpen：不属于以上两种，且 InvCover\_Π(y) ≠ 1，即前像没有证明查全。

ClassOpen：不属于以上三种，InvCover\_Π(y) = 1，但至少有一个候选 Class\_IDyn = ⊥；这时这些候选都有 Dom = In，是动力真值本身未闭合。

I^+：InvCover\_Π(y) = 1，E\_Π(y) 非空，且所有 X ∈ E\_Π(y) 都有 Class\_IDyn = 1。

I^-：InvCover\_Π(y) = 1，E\_Π(y) 非空，且所有 X ∈ E\_Π(y) 都有 Class\_IDyn = 0。

若 InvCover\_Π(y) = 1 而 E\_Π(y) = ∅，则观测 y 不在前向映射的像中，说明前向映射或协议有误，属于 AdmIInv 层面的问题，不进入上述六种状态。

六种状态两两不相交，并覆盖 AdmIInv(Π) = 1、y 在前向映射的像中时的全部情形：不属于 Mix、DomOpen、InvOpen 时，覆盖已闭，前像中没有 OutDom、没有 Dom = ⊥，标签都在 {1, 0, ⊥} 中且 1 与 0 不同时出现，于是落入 ClassOpen、I^+、I^- 之一。

Mix 与 OutDom 成员同时出现时，状态记为 Mix，并附报 OutDom 见证：Dom = In 的那一对异标签候选在 Π 下观测等价，这一不可辨识不因关闭 L4 或重新分段而消失。

2\. 对外三值读出

&nbsp;&nbsp;&nbsp;&nbsp;Read^Inv\_{IDyn,Π}(y) ∈ {1, 0, ⊥}

&nbsp;&nbsp;&nbsp;&nbsp;I^+ → 1  
&nbsp;&nbsp;&nbsp;&nbsp;I^- → 0  
&nbsp;&nbsp;&nbsp;&nbsp;Mix、DomOpen、InvOpen、ClassOpen → ⊥

⊥ 必须附原因：

&nbsp;&nbsp;&nbsp;&nbsp;Reason\_⊥ ∈ { NonIdentifiable, WorkDomainOpen, InverseCoverageOpen, CandidateClassificationOpen }

分别对应 Mix、DomOpen、InvOpen、ClassOpen。CandidateClassificationOpen 另附子原因 DynClassOpen、EvidenceSplice、CarrierBindMismatch 或 ProbBindMismatch。WorkDomainOpen 另附子原因：

&nbsp;&nbsp;&nbsp;&nbsp;Reason\_WorkDomainOpen ∈ { StartDomainOpen, StartDomainFail, QualExitOpen, QualExit }

前两者关于基础工作域，后两者关于 L4。四类原因不得混写，各自的子原因也不得互相替代。

DomOpen 中，若覆盖已闭而所有成员都是 OutDom，则“整段不能合法调用双向闭合”本身已被识别；整段的 IntentDyn 读出仍为 ⊥，原因为 WorkDomainOpen，不为 0。若这些 OutDom 候选全部由 QualExit 取得，L4 的分量可以读出为 0（第九节）；若其中有 StartDomainFail 候选，不能仅由 OutDom 推出 L4 = 0，L4 仍按其自身的分量反演结果申报。这一申报段随后按相应原因处理：起点失败时，基础工作域没有进入；资格中途退出时，按资格边界重新分段。

读出的条件：

Read = 1：前像中所有候选的正标签按其来源携带条件；由对象层 N\_IDyn^γ = 1 经《意向动力必然式》取得的正标签不携 H，读出随之不携 H。

Read = 0：前像中所有候选的负标签按所选路径携带条件；读出携它们的合取。只有路径经由概率一处时，才携 H2 ∧ H3^red 与概率的失败路径条件；只有路径经由载体一处时，才携载体的负向条件；路径 L1、L2、L3、L6 与源动一处不携 H；另携各候选 Dom = In 所用的条件。

⊥ 且原因为 NonIdentifiable：这一判断依赖其中正标签候选的 Class\_IDyn = 1 与负标签候选的 Class\_IDyn = 0，携这两个标签的条件。

⊥ 且原因为 WorkDomainOpen、由已找到的 OutDom 成员给出：这一判断依赖该成员 Out 标签的取得，携其所用路径的条件。

全部读出都以 AdmIInv(Π) = 1 为准入；H\_Π 的来源所携的条件，随来源承继。

3\. 定理六　负读出覆盖定理

&nbsp;&nbsp;&nbsp;&nbsp;NoPositiveWitness ⇏ NegativeIdentification

即“没有找到 Class\_IDyn = 1 的候选”不等于“所有候选都是 Class\_IDyn = 0”。

Read^Inv\_{IDyn,Π}(y) = 0 当且仅当：InvCover\_Π(y) = 1，E\_Π(y) 非空，所有候选都取得 Class\_IDyn = 0。由此前像中不含 OutDom，不含 ⊥，所用负标签的条件都已登记。

证明：由第 1 条与第 2 条的定义，Read = 0 当且仅当状态为 I^-，而 I^- 要求覆盖闭合、前像非空、所有候选负标签。若覆盖未闭，前像中可能有未枚举的 Class\_IDyn = 1 候选或 OutDom 候选，此时签 0 可能为错，故只能签 ⊥，除已落入 Mix 或 DomOpen 外，原因为 InverseCoverageOpen；若已找到 OutDom 成员，状态为 DomOpen，也不签 0。□

同理，签出 1 也须覆盖闭合：未枚举的成员可能是负标签，从而实际状态是 Mix；也可能是 OutDom，从而实际状态是 DomOpen。

4\. 定理七　工作域分裂定理

若同一前像中已知有 Class\_IDyn = OutDom 的候选 X\_out，则当前观测 y 不能取得整段 γ 的确定 IntentDyn 反演读出：任何只使用该协议观测的反演，都不得对整段 γ 签出 IntentDyn = 1 或 IntentDyn = 0。特别地，若前像中同时有可以对整段合法签值的候选 X\_in（Dom(X\_in) = In）与 X\_out，须先分离起点资格或 L4、确定资格边界或重新分段。

证明：由定理二，只依赖 y 的输出对 X\_out 与前像中其他成员相同，所以整段读出若签确定值，就同时是对 X\_out 的签值。签 0 就是把 X\_out 记为 IntentDyn = 0：QualExit 时违反 L4 的 0 不回读为 IntentDyn = 0 的纪律，StartDomainFail 时这一问题在这一段上不提出。签 1 对 X\_out 没有合法来源：它的 L4 不成立，N\_IDyn^γ 不能为 1，充分方向不适用；当前理论对它的整段 IntentDyn 不签值。两种签值都没有合法依据。□

这一定理不是由 φ\_I 在前像上不恒定推出的：OutDom 不是 IntentDyn 的第三个真值，而是反演任务的适用状态。它说的是整段读出没有合法来源，不是证明了异真值。X\_in 的标签可以是 1、0 或 ⊥：分裂只依赖 X\_in 可以对整段合法签值、X\_out 不可以，不依赖 X\_in 的动力真值是否已经闭合。所以工作域分裂不是普通的 Mix：OutDom ≠ 0。它的消除方式不是增加同型数据，而是增强协议对资格历史的分离，关闭起点资格或 L4，或按资格边界重新分段（第三节第 3 条）。

条件传播：定理七自身不携 H；应用中携 X\_out 的 Out 标签所用路径的条件，以及 X\_in 的 Dom = In 所用正读的条件。

九、分量反演与反演剖面

1\. 统一的分量状态

对 φ ∈ {N, L1, …, L6, Src, Car, Prob, Site}，按第八节同一判定次序定义：

&nbsp;&nbsp;&nbsp;&nbsp;InvState\_φ^Π(y) ∈ { All1, All0, Mix, DomOpen, InvOpen, ClassOpen }

以 Class\_φ 代替 Class\_IDyn。DomOpen 只用于三处与 Site：它们在 Dom = Out 的候选上记 OutDom，在 Dom = ⊥ 的候选上为 ⊥，沿 Dom 的开放原因附 StartDomainOpen 或 QualExitOpen。φ\_N 与 L1 至 L6 不设 DomOpen：它们问的是这一申报段本身，在 Dom = Out 的候选上同样可以签值。

Site 的标签在三处标签都已闭合时取 Site(X)，否则为 ⊥；它的 All1、All0 改为“确定为某一集合”，Mix 为两个已找到的成员 Site 值不同。

对外读出 Read^Inv\_{φ,Π}(y) 同第八节：确定值输出该值，其余输出 ⊥ 并附原因；条件沿所用标签传播。不为每一分量另立一套三值系统。

2\. 各分量的要点

φ\_N：OutDom 候选可以有 Class\_N = 0。所以在全部成员都是 OutDom、覆盖已闭、L4 路径都已闭合时，φ\_N 可以读出 0，而 φ\_I 读出 ⊥（WorkDomainOpen）。前像成员全部 Dom = In 时，φ\_N 与 φ\_I 的读出相同。

L1、L2、L3、L6：负标签不携 H，但它们问的是真实轨迹、段外写入、换锚与协议改写，这些多在内部，协议看不见运行身份、写入路径、锚引用或协议历史时，常为 Mix。外部行为连续，不等于内部真实轨迹连续，也不等于资格锚连续；外部记录看不出协议版本的变化，不等于协议事前冻结。

L4：协议不能分离“资格一直保持”与“中途退出以后又重新形成”时，L4 为 Mix；此时整段 IntentDyn 的状态由第八节决定为 DomOpen 或 Mix，不把后一类候选记为 IntentDyn = 0。

L5：Class\_L5 只取 1 或 ⊥，所以 L5 的分量读出只有 1 或 ⊥，不出现 All0，也不出现 Mix。当前材料不能证明同轨，不是对象层 L5 = 0；EvidenceSplice 只说明这份证据包不能合法证明当前申报对象，不说明当前申报对象没有意向动力，应重新取得同轨材料。

Src：1 与 0 都不携 H。Car、Prob：0 各携其上游负向条件；CarrierBindMismatch 与 ProbBindMismatch 只得 ⊥，说明当前拿来的材料不属于正确的对象，不说明正确的对象上没有动力。

Site：按第六节第 4 条区分单处、多处、无处与位置混合。

3\. 反演剖面

&nbsp;&nbsp;&nbsp;&nbsp;InvProfile\_IDyn^Π(y) := ( InvState\_I, InvState\_N, InvState\_L1, …, InvState\_L6, InvState\_Src, InvState\_Car, InvState\_Prob, InvState\_Site )

每一位置给出确定 1、确定 0（Site 给出确定的集合）、Mix、DomOpen、InvOpen 或 ClassOpen，并附所携条件。作用投影、类型化读数、切换与细节性质，可以作为附报列在剖面之外。

剖面回答的不是“它到底有没有意向动力”，而是“对它的意向动力结构，当前协议之下知道到了哪一层”。剖面的各位置不合成总分，不互相投票，也不以一个位置的确定值填补另一个位置的 ⊥；位置之间只有第六节所证的推出关系。

十、残余申报

以下残余必须显式申报，不得默不申报：

NonIdentifiable（Mix）：前像中同时有有意向动力与没有意向动力的合法候选。已证明不可辨识，是结构性的。要消除它，只能换用能够分离它们的协议（第七节第 3、4 条），不能靠增加不提高分离能力的同类数据，也不能靠对同一候选再作一次同样的判定。

InverseCoverageOpen（InvOpen）：前像没有证明查全。这是枚举上的残余，补全枚举或证明覆盖以后可以消除。

CandidateClassificationOpen（ClassOpen）：前像已查全，但有 Dom = In 的候选，其动力真值上游尚未关闭；包括证据拼接与证据错配造成的未闭合。这是候选分类上的残余，由《意向判定式》关闭候选的动力分类，或对候选重新取得同轨、同对象的材料以后，可以消除。

WorkDomainOpen（DomOpen）：前像中有 OutDom 候选（起点意向不成立，或资格在 γ 内退出或重新形成），或者在覆盖已闭时仍有候选的整段适用尚未确定（起点意向尚未关闭，或 L4 的整段保持尚未关闭）。这是整段适用上的残余：当前申报段不能作为整体合法调用双向闭合。要消除它，须增强对资格历史的观测，由《意向判定式》关闭 L4 或起点资格，或按资格边界重新分段。

四者性质不同：第一种是结构性的，第二种是枚举上的，第三种是候选分类上的，第四种是整段适用上的。

&nbsp;&nbsp;&nbsp;&nbsp;Mix ≠ InvOpen ≠ ClassOpen ≠ DomOpen

不得统称为“信息不足”。DomOpen 不并入 Mix，因为 OutDom 不是 0；ClassOpen 不并入 InvOpen，因为前像已经查全。

各分量的读出为 ⊥ 时，同样按这四类中适用的原因申报；φ\_N 与 L1 至 L6 不设 DomOpen，不申报 WorkDomainOpen。

十一、条件账本

&nbsp;&nbsp;&nbsp;&nbsp;H\_new = ∅

定理一、定理二、定理六、命题一至命题四：纯反演结构，Status = Established，不继承任何 H。

定理三、定理四、定理五、定理七：作为反演定理，不因自身证明而继承 H，它们以候选标签已经成立为前提。具体应用中，条件沿所用标签传播：

正标签：由对象层 N\_IDyn^γ = 1 经《意向动力必然式》取得，不携 H；由形式读数经《意向动力数理式》定理 6 取得，携所用正读路径的条件，即实际使用的 Law-bearing 见证适用的 H\_LawRead 与上游正读路径的条件。

负标签：路径 L1、L2、L3、L6 与源动一处的零，不携 H；载体一处的零，携上游的载体负向条件（承担读数按见证的 H^-\_M，程度读数按《律动力数理式》与《律分级式》的负向条件）；概率一处的零，携《概率动力一般式》必要方向的 H2 ∧ H3^red，以及 H\_PAct-Rep、H\_ρRep^-、H^-\_M 中实际失败路径所用者。由 N\_IDyn^γ = 0 到 IntentDyn = 0 的逆否，不另增条件。

整段适用标签：Dom = In 沿 L4 正读所用见证携 H\_LawRead；Dom = Out 原因为 QualExit 时，携 L4 路径的条件，即《意向数理式》七之 3 的负向表示条件与《意向判定式》负判路径的闭合；原因为 StartDomainFail 时，携所用资格负判的条件。

模板的结论：定理四的二候选模板与定理五的模板一，在正标签取自对象层时不携 H；定理四的三候选模板与定理五的模板二，携载体与概率两处负标签的条件。

条件不沿“反演式”这一名称整体传播。

AdmIInv 与其中的 ForwardMapEstablished，是反演协议的准入条件，不是本体桥，不计入 H；H\_Π 的来源所携的条件，随来源承继。

本篇不承继 H\_GP、H\_TI、H\_PL、H\_SD：所有反演都不走这些桥的跨实现路径。

状态：反演的一般结构 Established；具体某一次反演读出 Conditional，条件为所用标签与 H\_Π 来源所携条件的合取，所用标签都不携条件时为 Established。

十二、击穿

K-IInv1　上界击穿：同一前像中的两个候选，被只依赖 y 的合法方法区分。击穿定理二。

K-IInv2　前像中已有 Class\_IDyn = 1 与 Class\_IDyn = 0 的候选，却签出确定的 1 或 0。击穿定理三。

K-IInv3　InvCover\_Π(y) ≠ 1 时签出确定的 1 或 0。击穿定理六。

K-IInv4　把“没有找到正候选”写成负识别。击穿定理六。

K-IInv5　把 IntentDyn、N\_IDyn^γ、三处的正式判词、L1 至 L6 的正式判词、绑定读数或内部形式证书直接放进外部观测。这不是主定理被击穿，而是 AdmIInv(Π) = 0，反演没有进入；若仍据此签出反演结论，击穿本篇。

K-IInv6　看见结果以后重新切候选域、改协议、追加有利的观测，或按 y 中对某一解释有利的部分重新分段。

K-IInv7　由行为、显化、效应或调谐成功直接推出意向动力，而没有已成立的前向分离。击穿定理五。

K-IInv8　由动力真值可识别，宣称三处位置也可识别。击穿定理四。

K-IInv9　同一前像中有不同位置的解释，却以最可能、最合理或最简单为由强选一处；或把位置混合写成多处同时在动，或把多处同时在动写成位置混合。

K-IInv10　以贝叶斯后验、置信度或拟合优度代替结构可识别性。

K-IInv11　把 EvidenceSplice 记成 N\_IDyn^γ = 0 或 IntentDyn = 0。

K-IInv12　把 CarrierBindMismatch 或 ProbBindMismatch 记成相应一处的 0。

K-IInv13　把资格在 γ 内退出或重新形成的候选，或起点意向不成立的候选，直接记为 IntentDyn = 0，而不是 OutDom；或把 StartDomainFail 与 QualExit、StartDomainOpen 与 QualExitOpen 互相替代。

K-IInv14　把 Mix、InvOpen、ClassOpen、DomOpen 混成同一种“资料不足”。

K-IInv15　由更强协议后来能够分离，反推原协议本来可识别。击穿命题一。

K-IInv16　把“在协议 Π 下不可识别”升级为“在一切协议下不可识别”或“意向动力不存在”。

K-IInv17　把动力位置、作用投影、增强与减弱、欲门切换、显化或调谐结果升格为意向动力的额外条件，或升格为 N\_IDyn^γ 的第四分量。

K-IInv18　让 OutDom 候选作为普通负候选与正候选一起构成 Mix。

K-IInv19　不同候选取不同的申报窗，却被当作同一反演问题。

K-IInv20　把干预本身当作内部动力身份的证据，而没有已成立的差异前向响应；或把直接写入意向内部状态的干预当作对原对象的合法分离。

局部不可辨识结论的击穿：宣称某一具体协议不能识别意向动力或某一分量，但该协议实际有已成立的合法分离量，能够区分前像中所有异值候选。击穿第六、七节中相应的模板结论。

不构成击穿：读出为 ⊥；标签所携的上游条件尚未关闭；原来的 Mix 在更强协议下被分离，那是另一个协议下的另一次反演；重新分段以后的新申报段得到与原整段不同的读出，那是不同的反演问题；前像中同时有几处在动的候选被识别为多处。

十三、接口

1\. 与《意向判定式》的边界

《意向反演式》：输入既有的合法观测协议、前向映射与观测结果，回答“这些观测最多允许知道什么”。

《意向判定式》：建立或调用合法的内部接口、证书、覆盖与上游判词，回答“怎样检查一个现实实例在 γ 上有没有意向动力，怎样签出 1、0 或 ⊥”。

所以这里不把 Read\_{N\_IDyn^γ}^M、L1 至 L6 的判词、绑定读数或 N\_IDyn^γ 本身当作普通外部观测，否则就把反演写成了判定。候选标签由上游给出，这里只读取，不判定。

反演读出为 ⊥ 时所附的原因交该篇区分：ClassOpen 可以由候选的动力判定关闭；DomOpen 可以由起点资格与 L4 的判定、资格边界的确定部分关闭；Mix 不会因为对同一候选再跑一次同样的判定而消失，除非增加了真正有分离力的新接口，那已经是新的协议。

2\. 上承

《意向动力一般式》：N\_IDyn^γ、合法段 L1 至 L6、三处及其归属绑定，必要方向。

《意向动力数理式》：三值形式系统、正向回读、负向回读的路径与条件、证据拼接与错配的纪律、L4 的特例纪律。

《意向动力必然式》：充分方向与双向式；基础工作域 Intent\_{F,t\_0} = 1。

《意向一般式》《意向必然式》《意向数理式》：意向资格及其负向表示条件，用于 Dom 标签。

场系统与已封版的形式系统：前向映射 H\_Π 的来源。

《概率反演式》：反演的一般结构与本篇同型；本篇不以该篇对概率资格的反演结论作为前提。

3\. 下交

《意向判定式》：承接 ClassOpen 与 DomOpen 中可由判定关闭的部分，包括起点资格与 L4 的判定，以及资格边界的确定。

《意向极限式》：本篇的不可识别是观测协议相对的识别边界；资格与动力在什么极限上真正失效或退出，由该篇研究。反演不可识别不等于本体不存在。

《意向运行基底构造式》：须给出 H\_Π 可以合法依据的实际接口：哪些内部状态可观测，哪些外部输出由什么内部结构产生，哪些干预合法，哪些干预能够分离候选。

《意向可达式》《意向稳定式》：动力目标的可达与动力在扰动下的保持，这里不作推断。

4\. 不做的事
