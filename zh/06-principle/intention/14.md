自显论 · 理篇 · 意向组式第十四 v1.0

# 意向判定式

一、目的

对事前冻结的现实申报实例，在合法可操作的判定协议下，调用前十三篇已经封闭的形式系统、回读规则与对象层闭合，对意向组式当前已经闭合的四类对象分别给出最终判词，并证明：判 1 时对象一定成立，判 0 时对象一定不成立（各携所用路径的条件）；对象的工作域没有进入时判 OutDom，不判 0；不能保证正确时一律判 ⊥，并写明原因。

四类对象与四个判词是：

&nbsp;&nbsp;&nbsp;&nbsp;Det\_I(χ\_I) ∈ {1, 0, ⊥}：申报的资格实例上，意向是否成立；  
&nbsp;&nbsp;&nbsp;&nbsp;Det\_IAct(χ\_IAct) ∈ {1, 0, ⊥, OutDom}：申报的当前作用单元上，是否发生了一次完整的意向作用；  
&nbsp;&nbsp;&nbsp;&nbsp;Det\_IGS(χ\_IGS) ∈ {1, 0, ⊥, OutDom}：申报的比较序列 σ 上，是否发生了一次意向欲门切换；  
&nbsp;&nbsp;&nbsp;&nbsp;Det\_IDyn(χ\_IDyn) ∈ {1, 0, ⊥, OutDom}：申报的轨迹段 γ 上，意向是否有动力。

合称组级判定族：

&nbsp;&nbsp;&nbsp;&nbsp;𝔇\_I^Π := ( Det\_I, Det\_IAct, Det\_IGS, Det\_IDyn )

四个判词回答四个不同的问题，不合成一个总判词，不互相表决，也不互相填补。

本篇不重新定义 Intent、IntentAct、IntentGateSwitch 与 IntentDyn，不新增任何对象的组成项，不重建各数理式的形式系统，不新立 H。

1\. 上游冻结结论

意向资格：

&nbsp;&nbsp;&nbsp;&nbsp;N\_I := P\_I ∧ SourceDrive\_{F,t}(𝒫\_I) ∧ GateCorrespondence\_{F,t}(𝒫\_I; 𝒢\_I) ∧ TuneInterface\_{F,t}(𝒢\_I)，P\_I := InIntentDomain\_{F,t}(𝒫\_I) ∧ Probability\_{F,t}(𝒫\_I; C\_I, 𝔯\_I)

《意向一般式》：Intent\_{F,t} ⇒ N\_I，Status = Established，不携 H。《意向必然式》：N\_I ⇒ Intent\_{F,t}，Status = Established，不携 H。形式入口：IntentCoreCert^M = 1 ⇒ N\_I = 1（《意向数理式》定理 5），条件只沿 Probability 回读路径中实际使用的 Law-bearing 见证传播 H\_LawRead。《意向数理式》七之 3：IntentCoreCert^M = 0 只来自合格锚上的形式零；Probability 一侧的形式零按上游实际失败路径携条件；本组式新增原子的负向表示完备性没有证明，它们的形式零不回读为结构零；由结构零经 Intent ⇒ N\_I 取逆否所得的结论，属于本篇。

意向作用：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IAct := ∃w\_I \[ A1(w\_I) ∧ A2(w\_I) ∧ A3(w\_I) ∧ A4(w\_I) \]

在工作域 Intent\_{F,t} = 1 内，IntentAct ⇔ N\_IAct，Status = Established（《意向作用一般式》《意向作用必然式》）。形式入口与负向回读见《意向作用数理式》七之 1、七之 3：只有失败层含 A2 且 FailSub\_A2 = PDuty 的一支携 H\_PAct-Rep。

意向欲门切换：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]

在工作域 Intent\_{F,t} = 1 内，对每一条固定的 σ，IntentGateSwitch\_F(σ) ⇔ N\_IGS(σ)，Status = Established（《意向欲门切换一般式》《意向欲门切换必然式》）。形式入口与负向回读见《意向欲门切换数理式》七之 1、七之 3：只有所选反证路径为 S2 的 A2-PDuty 一支携 H\_PAct-Rep。

意向动力：

&nbsp;&nbsp;&nbsp;&nbsp;N\_IDyn^γ := LegalIntentDynSegment\_F^γ(K\_I; Γ\_IDyn) ∧ ( SourceOccurrenceDyn\_I^γ ∨ CarrierDyn\_I^γ ∨ IntentProbDyn\_I^γ )

基础工作域 W\_IDyn := Intent\_{F,t\_0} = 1；资格在整段上的保持是合法段的分量 L4，不并入基础工作域。IntentDyn\_F^γ(K\_I) ⇔ N\_IDyn^γ，Status = Established（《意向动力一般式》《意向动力必然式》）。形式入口、负向回读的路径与条件、L5 只取 1 或 ⊥、证据拼接与错配不形成结构零，见《意向动力数理式》七之 1 至七之 4；L4 的 0 使这一申报段落出工作域，不回读为 IntentDyn = 0，其资格负判由本篇闭合。

《意向反演式》：反演残余 Mix、InvOpen、ClassOpen、DomOpen；整段适用标签与 StartDomainFail、QualExit、StartDomainOpen、QualExitOpen 的区分。

《概率判定式》：𝒫\_I 的概率判词 Det\_P(χ\_P) ∈ {1, 0, ⊥}；Det\_P = 0 ⇒ Probability = 0，携 H2 ∧ H3^red，并随失败路径携 H^-\_M 或 H\_ρRep^-。

2\. 与《意向反演式》的边界

《意向反演式》回答：给定既有观测，最多可以知道什么；它禁止把内部判词与证书作为观测。本篇回答：为判定一份现实实例，应调用哪些合法内部接口，怎样签出正式判词。这里读取的形式证书、覆盖证书与上游判词是合法操作接口，不是待判定的对象本身；Intent、IntentAct、IntentGateSwitch、IntentDyn 与各结构核仍不作输入。

二、判定实例、判定协议与证据分层

1\. 判定实例

&nbsp;&nbsp;&nbsp;&nbsp;χ\_IJudge := ( χ\_I, χ\_IAct, χ\_IGS, χ\_IDyn )

各子实例沿用上游的求解实例，不重建：

χ\_I := (F, t, χ\_P, 𝒢\_I^raw, Σ\_I^src, 𝒯\_I^tune, Γ\_I)，《意向数理式》定义 1；资格锚 K\_I^M 由它给出。  
χ\_IAct := (χ\_I, ξ\_t, Γ\_IAct)，《意向作用数理式》定义 1。  
χ\_IGS := (χ\_I, σ^M, Γ\_IGS)，《意向欲门切换数理式》定义 1。  
χ\_IDyn := (χ\_I, γ, Γ\_IDyn)，《意向动力数理式》定义 1；其中的 χ\_I 取 γ 的起点 t\_0，各评价点 t\_k 上的资格实例与它同锚。

只对申报了的子实例求值。各上层子实例所引用的资格实例须与本次申报的资格锚 K\_I^M 同锚，并在各自的时点上调用 Det\_I；引用别的锚，是申报失格。

这些都是申报对象，不是已经取得资格的对象。它们须在判定以前冻结，判定过程中不得为通过检查而增删、缩域、换锚、换窗或重报。

2\. 判定协议

&nbsp;&nbsp;&nbsp;&nbsp;Π\_IJudge := ( Freeze^inst, VersionSet, DeclRules, CoverRules, BindRules, FailRules )

Freeze^inst：判定对象、申报窗、候选身份与资格锚在判定以前冻结。  
VersionSet：所调用的各上游形式系统与职责身份体系的版本冻结。  
DeclRules：各子实例的申报合格规则，沿用各数理式的申报零定义。  
CoverRules：各负向路径签 0 所需的覆盖，沿用各数理式的覆盖证书。  
BindRules：同锚、同链、同序列、同运行、同载体、同概率组织的绑定规则，沿用各数理式。  
FailRules：允许采用的结构反证路径，沿用各数理式；本篇只加一条：意向动力的负判不采用 L4 路径。

各子判定仍调用自己的专属协议 Γ\_I、Γ\_IAct、Γ\_IGS、Γ\_IDyn。本篇不覆盖这些协议，只确认它们已经合法冻结、版本一致，并统一最终判词的签出规则。

3\. 证据分层

判定读取的接口按服务的对象分为四层：

&nbsp;&nbsp;&nbsp;&nbsp;Y\_det = ( Y\_I, Y\_IAct, Y\_IGS, Y\_IDyn ) 与 Y\_cov

Y\_I：IntentCoreCert^M 及其四项读数、锚资格、𝒫\_I 的概率读数与零型，以及《概率判定式》的 Det\_P。  
Y\_IAct：当前事件、当前实现、四段来源链、职责身份、同链绑定与 FailLayer、FailSub\_A2。  
Y\_IGS：前后评价域的现实事件、过门路径段、后态门承担记录、事件身份键、序列身份与 FailLayer、FailSub\_S2。  
Y\_IDyn：运行与分支的记录、更新与写入历史、各评价点的资格读数与资格变化记录、同证据键、协议历史、源动续行、载体登记与程度、概率动力，以及 FailBranch 与 RefuteRoute。  
Y\_cov：各层的覆盖证书与负读出的完整性，即 NegComplete\_IAct^M、NegComplete\_IGS^M、NegComplete\_IDyn^M 等。

Y\_cov 不是任何对象的组成项，只决定判定方法有没有资格签出 1 或 0。

各层的前向来源由已成立的式给出：Y\_I 来自《意向数理式》《概率数理式》与《概率判定式》；Y\_IAct 来自《意向作用数理式》的定义与 IA-M1 至 IA-M12；Y\_IGS 来自《意向欲门切换数理式》的定义与 IGS-M1 至 IGS-M10；Y\_IDyn 来自《意向动力数理式》的定义与 IDyn-M1 至 IDyn-M14。

不得以行为、显化、效应、调谐结果、经验频率或率值作为任何判词的输入：《意向反演式》已经证明，这类外部结果不能普遍识别意向动力；它们也都不是资格、作用或切换的条件。

三、组级判定纪律

1\. 四值判词

1：对象正式成立。  
0：对象正式不成立。  
⊥：当前实例不能合法签出 1 或 0。  
OutDom：对象的工作域没有进入，当前申报问题不在这一对象上提出。

四值两两不同。⊥ 与 OutDom 都不是对象的第三个真值：对象在对象层仍是二值的；⊥ 说的是判定没有完成，OutDom 说的是这一问题对当前实例不适用。OutDom 不并入 0，也不并入 ⊥：并入 0 会把工作域的失败写成对象的否定，并入 ⊥ 会丢掉“工作域已经确定没有进入”这一已经取得的知识。

Det\_I 不用 OutDom：它判的就是资格本身。资格的工作域是自显场中的意向资格工作域；申报的 F 不是这样的场，是申报失格，判 ⊥（DeclarationInvalid）。

2\. 六条总纪律

J1　形式读数不是最终判词。Read^M = 1 不等于判 1，还须完成对象层回读并关闭所用路径的条件；Read^M = 0 不等于判 0，还须取得合法的结构零并关闭所选路径的条件。

J2　申报零不是结构零。凡 0 只来自申报的失格，一律判 ⊥（DeclarationInvalid），要求重新申报。

J3　没有找到正证据不是负判。NoPositiveWitness ⇏ Det = 0。

J4　覆盖未闭不签 0。凡签 0 所需的候选域与覆盖未闭，一律判 ⊥。

J5　证据错配不制造对象的 0。EvidenceSplice、CarrierBindMismatch、ProbBindMismatch，以及各层对同链、同序列、同锚的身份错配，只使相应读数或判词为 ⊥。

J6　条件只沿实际路径传播。判哪一条路径，就携哪一条路径的条件；不把各对象、各路径的条件机械合取。

3\. 零型

&nbsp;&nbsp;&nbsp;&nbsp;ZeroType ∈ { StructuralZero, DeclarationZero }

StructuralZero\_T：对目标 T，决定性的 0 来自上游允许的结构失败路径，候选覆盖完整，绑定正确，所选路径的负向表示条件关闭，可以合法回读为结构核 N\_T = 0。DeclarationZero\_T：决定性的 0 只来自申报的失格。

不另立证据零：证据拼接与错配都是 ⊥，不是一种 0。

4\. 依赖结构

Det\_I 是另外三个判词共同的入口：作用、切换与动力都在 Intent = 1 的工作域内定义。三者之间没有前后级：

&nbsp;&nbsp;&nbsp;&nbsp;IntentGateSwitch 的判定不要求 IntentAct = 1：S2 只调用作用的 A1、A2、A3；  
&nbsp;&nbsp;&nbsp;&nbsp;IntentDyn 的判定不要求 IntentAct = 1，也不要求 IntentGateSwitch = 1：完整作用与欲门切换都不是动力的取得条件；  
&nbsp;&nbsp;&nbsp;&nbsp;IntentAct 的判定不要求任何切换或动力。

所以判定的依赖图是由 Intent 向下分出三支，不是 Intent → IntentAct → IntentGateSwitch → IntentDyn 的链。意向动力的入口另有整段适用的要求（第七节）。

四、意向资格判定

1\. 正判

Det\_I(χ\_I) = 1，当且仅当：IntentCoreCert^M(K\_I^M) = 1，且 Probability 回读路径中实际使用的各 Law-bearing 见证的 H\_LawRead 已关闭。

2\. 负判

《意向数理式》七之 3 规定，本组式新增原子（InIntentDomain、SourceDrive、GateCorrespondence、TuneInterface 各自的原子读数）的形式零不回读为结构零。所以当前唯一可以取得资格结构零的路径，是 P\_I 中的概率一侧：

Det\_I(χ\_I) = 0，当且仅当：AnchorQual\_I^M = 1；χ\_P 是 K\_I^M 所申报的 𝒫\_I 的概率求解实例；并且《概率判定式》对 χ\_P 签出 Det\_P(χ\_P) = 0。

Det\_P = 0 的定义已经要求 Read\_{N\_P}^M = 0 为结构零、失败路径所需的 H^-\_M 或 H\_ρRep^- 已关闭、H2 ∧ H3^red 已关闭；这些条件随之进入 Det\_I = 0。

Det\_I = 0 是相对于申报锚 K\_I^M 与时点 t 的判词：它说这一锚在 t 上不承载意向，不说场中别处没有意向。

3\. 未决

其余情形 Det\_I = ⊥，并附原因：

DeclarationInvalid：申报失格，包括锚失格（AnchorQual\_I^M = 0）与概率读数的申报零。  
AnchorOpen：锚资格不可判。  
IntentCoverOpen：某一原子读数的覆盖未闭或材料不足。  
ProbabilityOpen：𝒫\_I 的概率判词为 ⊥，附《概率判定式》的原因，如 OntologyBridgeOpen、UpstreamLawOpen、RateRepOpen。  
IntentAtomRepOpen：IntentCoreCert^M = 0，而形式零只来自本组式新增原子；它们的负向表示没有证明，不能签结构零。  
LawReadOpen：IntentCoreCert^M = 1，而所用见证的 H\_LawRead 未关闭。

4\. 资格判定是三支的入口

作用、切换与动力子实例在各自时点上所引用的资格实例记为 χ\_I。

&nbsp;&nbsp;&nbsp;&nbsp;Det\_I(χ\_I) = 0　⇒　Det\_IAct = OutDom、Det\_IGS = OutDom，原因 IntentDomainFail  
&nbsp;&nbsp;&nbsp;&nbsp;Det\_I(χ\_I) = ⊥　⇒　Det\_IAct = ⊥、Det\_IGS = ⊥，原因 IntentDomainOpen

意向动力的入口按第七节另判：起点资格的失败与未决分别记 StartDomainFail 与 StartDomainOpen，即 IntentDomainFail 与 IntentDomainOpen 在 γ 的起点上的名称。

各上层子实例先校验自身的申报：申报失格时判 ⊥（DeclarationInvalid），不进入入口判定；申报合格以后，才按上述入口规则调用 Det\_I。这与第七节第 7 条动力的判定次序一致。

IntentDomainFail 不说 IntentAct = 0 或 IntentGateSwitch = 0：这些对象在这一申报锚上没有工作域，问题不在其上提出。

五、意向作用判定

入口：Det\_I(χ\_I) = 1。Det\_I(χ\_I) = 0 时判 OutDom（IntentDomainFail）；Det\_I(χ\_I) = ⊥ 时判 ⊥（IntentDomainOpen）。

1\. 正判

Det\_IAct(χ\_IAct) = 1，当且仅当：Det\_I(χ\_I) = 1；Read\_{N\_IAct}^M = 1；A2 正向回读实际使用的各 Law-bearing 见证的 H\_LawRead 已关闭。

2\. 负判

Det\_IAct(χ\_IAct) = 0，当且仅当：Det\_I(χ\_I) = 1；Read\_{N\_IAct}^M = 0，且这一 0 是结构零；FailLayer\_IAct^M 中每一层都满足《意向作用数理式》七之 3 的回读条件，即该层与之前各层所需的覆盖闭合；失败层集合含 A2 且 FailSub\_A2 = PDuty 时，H\_PAct-Rep 已关闭。

3\. 未决

其余情形 Det\_IAct = ⊥，原因沿用《意向作用数理式》五之 2：DeclarationInvalid、EventOpen、SourceRoleOpen、SourcePathOpen、ProbabilityCertOpen、DirectionOpen、GateIdentityOpen、GatePathOpen、TuneRoleOpen、TunePathOpen、SameBindOpen；结构判词层的 PActRepOpen 与 LawReadOpen；入口的 IntentDomainOpen。

4\. 局部性

Det\_IAct = 0 只否定这一申报单元 ξ\_t 上的完整意向作用：它不推出 Intent = 0，不推出别的单元上没有作用，也不推出这一单元上没有意向动力或切换。A3^M = 1 不推出欲门切换；A4^M = 1 不推出调谐成功、经验改变、显化或效应成功。

六、意向欲门切换判定

入口：Det\_I(χ\_I) = 1。Det\_I(χ\_I) = 0 时判 OutDom（IntentDomainFail）；Det\_I(χ\_I) = ⊥ 时判 ⊥（IntentDomainOpen）。入口不要求 Det\_IAct = 1。

1\. 正判

Det\_IGS(χ\_IGS) = 1，当且仅当：Det\_I(χ\_I) = 1；Read\_{N\_IGS(σ)}^M = 1；S2 中 A2 正向回读实际使用的各 Law-bearing 见证的 H\_LawRead 已关闭。

2\. 负判

Det\_IGS(χ\_IGS) = 0，当且仅当：Det\_I(χ\_I) = 1；Read\_{N\_IGS(σ)}^M = 0，且这一 0 是结构零；CandidatePairCover\_IGS^M = 1；每一个候选都有一条所选的反证路径满足《意向欲门切换数理式》七之 3 的回读条件；所选路径为 S2 的 A2-PDuty 时，H\_PAct-Rep 已关闭。

某一候选的 A2-PDuty 路径因 H\_PAct-Rep 未关闭而不可用时，可以改选它的其他可用路径，例如 S3 或 S4 的结构 0；不得因为未选用的 A2-PDuty 分支上条件未关闭，就否认另一条无条件路径已经取得的结构 0。

3\. 未决

其余情形 Det\_IGS = ⊥，原因沿用《意向欲门切换数理式》五之 2：DeclarationInvalid、PriorEventOpen、PriorPassOpen、PriorSeqOpen、PostActOpen（细分沿用作用的原因）、PrefixBindOpen、PostSeqOpen、GateStateOpen、EventKeyOpen、OldDomainOpen、BindOpen、CandidateOpen；结构判词层的 PActRepOpen 与 LawReadOpen；入口的 IntentDomainOpen。

4\. 局部性

Det\_IGS = 0 只否定这一条 σ 上的意向欲门切换：它不推出其他比较序列上没有意向欲门切换，不推出这一条 σ 上没有一般的门位切换，也不推出作用或资格不成立。Det\_IGS = 1 不推出完整意向作用：切换只调用作用的前三层。

七、意向动力判定

1\. 第一关：起点资格

调用 Det\_I(χ\_I)，χ\_I 取 γ 的起点 t\_0。

&nbsp;&nbsp;&nbsp;&nbsp;Det\_I(χ\_I) = 0　⇒　Det\_IDyn = OutDom（StartDomainFail）  
&nbsp;&nbsp;&nbsp;&nbsp;Det\_I(χ\_I) = ⊥　⇒　Det\_IDyn = ⊥（StartDomainOpen）

起点资格不成立时，基础工作域 W\_IDyn 没有进入，本组式的动力问题在这一段上不提出；不签 IntentDyn = 0。

2\. 第二关：整段资格保持

起点资格判 1 以后，判 L4：

&nbsp;&nbsp;&nbsp;&nbsp;L4Det ∈ {1, 0, ⊥}

L4Det = 1，当且仅当：Read\_{IntentQualWholeSegment}^M = 1，即全部评价点 t\_k 上 IntentCoreCert^M = 1，资格变化事件的记录覆盖整段（QualEventCover^M = 1）且其中没有退出或重新形成的事件；并且各评价点资格读数所用 Law-bearing 见证的 H\_LawRead 已关闭。等价地说，全部评价点上 Det\_I = 1，并且资格变化的记录覆盖整段而没有退出事件。

第二条不要求在某一离散评价点上先取得 Det\_I = 0，例如退出与重新形成都发生在相邻评价点之间时，只能由事件记录读出。但两条承担同一种回读条件：资格失败落在哪一项上，就携哪一项的负向表示条件。在当前上游状态下，本组式新增原子没有负向表示，资格变化记录所示的失败若落在这些项上，这条路径同样不能闭合；记录不显示失败落在哪一项上时，条件无从确定，也不能闭合。这两种情形都退为 ⊥（QualExitOpen）。概率一侧的失败按《概率判定式》携条件。

L4Det = ⊥：其余情形（QualExitOpen）。

签 L4Det = 0 只需要一条闭合的负路径，不需要全部评价点的资格读数，也不需要资格变化记录的整段覆盖：后两者是签 L4Det = 1 的要求。资格退出以后是否又重新形成、重新形成的事件身份是否可分离，不影响 L4Det = 0；它们只用于确定重新分段的边界，作为报告输出。

&nbsp;&nbsp;&nbsp;&nbsp;Det\_IDyn = OutDom（QualExit）

此时可以签出结构判词 L4 = 0 与 N\_IDyn^γ = 0，作为报告项；不签 IntentDyn = 0。这一申报段应按资格边界重新分段，对新的申报段重新判定。

八、判据有效性

1\. 定理一　正判有效定理

2\. 定理二　负判有效定理

&nbsp;&nbsp;&nbsp;&nbsp;Det\_T = 0 ⇒ T = 0

条件按目标与所选路径：

Det\_IGS = 0：所选路径含 S2 的 A2-PDuty 时携 H\_PAct-Rep；否则不携 H。  
Det\_IDyn = 0：路径 L1、L2、L3、L6 不携 H；路径 DynActual 携载体一处的上游负向条件与概率一处的 H2 ∧ H3^red 及实际失败路径的条件。

3\. 定理三　OutDom 正确性定理

（1）Det\_IAct = OutDom 或 Det\_IGS = OutDom（IntentDomainFail），蕴含 χ\_I 上 Intent = 0，作用或切换的工作域没有进入。所携条件同 Det\_I = 0。

（2）Det\_IDyn = OutDom（StartDomainFail），蕴含 Intent\_{F,t\_0} = 0，基础工作域 W\_IDyn 没有进入。所携条件同 Det\_I = 0。

（4）以上各种 OutDom 都不推出相应对象为 0。

证明：（1）（2）由入口规则与定理二（A）。（3）由第七节第 2 条：起点判 1，由定理一（A）Intent\_{F,t\_0} = 1；L4Det = 0 经 QualPointFail 时，给出 γ 内一个评价点 t\_k，在同锚、同运行上 Det\_I = 0，由定理二（A）Intent\_{F,t\_k} = 0，资格在 γ 的这一场态上不成立，L4 = 0；经 QualExitEvent 时，形式读数 Read\_{IntentQualWholeSegment}^M = 0 来自同轨同锚的现实退出记录，所示失败路径的回读条件已关闭，由《意向动力数理式》七之 3 的 L4 路径，回读为资格在 γ 内退出或重新形成，L4 = 0。（4）作用、切换在 Intent = 0 的锚上没有工作域，必要方向与充分方向都不在其上适用；L4 = 0 时，按《意向动力数理式》七之 3 与《意向动力必然式》接口，这一申报段落出工作域，不取逆否。所以都没有合法的路径推出对象为 0。□

4\. 定理四　未决保护定理

&nbsp;&nbsp;&nbsp;&nbsp;Det\_T = ⊥ ⇏ T = 0，　Det\_T = ⊥ ⇏ T = 1

对四个目标统一成立，包括：申报零；证据拼接与错配；覆盖未闭；负向表示条件或本体桥未关闭；候选身份、锚、序列或运行身份不可判；上游 Law、Probability 或概率动力的判词为 ⊥；读出实现失格。

证明：由各判词的定义，⊥ 只在既没有取得正判所需的全部条件、也没有取得负判所需的全部条件时签出；它不经过任何回读路径，所以不传递任何对象层的结论。□

5\. 定理五　判词独立定理

四个判词之间，除入口关系以外，没有相互推出：

&nbsp;&nbsp;&nbsp;&nbsp;Det\_IAct = 0 ⇏ Det\_I = 0；Det\_IGS = 0 ⇏ Det\_IAct = 0；Det\_IDyn = 0 ⇏ Det\_IAct = 0 或 Det\_IGS = 0；  
&nbsp;&nbsp;&nbsp;&nbsp;Det\_IGS = 1 ⇏ Det\_IAct = 1；Det\_IDyn = 1 ⇏ Det\_IAct = 1 或 Det\_IGS = 1。

证明：上游已经证明各对象只在 Intent = 1 的工作域内相互独立：作用的不成立不取消资格（《意向作用数理式》七之 3）；切换只调用作用的前三层，不要求完整作用（《意向欲门切换必然式》接口）；完整作用与欲门切换都不是意向动力的取得条件（《意向动力必然式》第一节）；一条 σ 上的结论不推出别的序列。所以上游容许对象之间取这些不相推出的组合。判词只在取确定值 1 或 0 时与相应对象的真值一致（定理一、二）；若由一个判词推出另一个判词的确定值，在对象取上述组合的实例上，被推出的判词将与它的对象真值不一致，违反定理一或定理二。所以各判词只能按自己的定义分别求值。判词与对象真值相等，只在第十节各自的完全判定域中成立。□

所以四个判词可以任意组合，例如 Det\_I = 1、Det\_IAct = 0、Det\_IGS = 1、Det\_IDyn = 1。不得多数表决，不得以一个判词的确定值填补另一个判词的 ⊥。

九、误判界

本篇不引入统计误判率。判定纪律是：不能保证正确时退到 ⊥。

正判域：由定理一，凡签 1，对象一定成立，条件已写进定义。

负判域：由定理二，凡签 0，对象一定不成立，所选路径的条件已写进定义。

工作域：由定理三，凡签 OutDom，工作域一定没有进入，且对象没有被否定。

不能两全之处，按上游所申报的现状：

意向资格的负判只有概率一侧一条路径。它依赖 H2 ∧ H3^red，并随路径依赖 H^-\_M 或 H\_ρRep^-；《概率判定式》申报这些条件尚未关闭。在它们关闭以前，Det\_I = 0 不能签出，退为 ⊥（ProbabilityOpen，附 OntologyBridgeOpen 等）。本组式新增原子的形式零，退为 ⊥（IntentAtomRepOpen）。

由此，IntentDomainFail 与 StartDomainFail 依赖 Det\_I = 0，QualExit 的两条负路径承担与 Det\_I = 0 相同的资格负向回读条件，三者都随之退为 ⊥：在上游条件关闭以前，判定器取不到 OutDom，只给出 IntentDomainOpen、StartDomainOpen 或 QualExitOpen。

作用与切换：经 A2-PDuty 的负判依赖 H\_PAct-Rep；该条件尚未关闭时退为 ⊥（PActRepOpen）。其余失败层与路径的负判不携 H，可以签出。

动力：路径 L1、L2、L3、L6 不携 H，可以签出；路径 DynActual 依赖载体一处的上游负向条件与概率一处的 H2 ∧ H3^red 等，在它们关闭以前退为 ⊥（CarrierNegOpen 或 PDynNegOpen）。L5 不取 0，承重证据跨轨的实例只能判 ⊥（EvidenceSplice）。

以上“可以签出”都以入口资格判 1 为前提，即入口资格读数所用见证的 H\_LawRead 已关闭。

所以当前判定器在负方向与工作域方向上的覆盖范围小于正方向：它不会误判，但会有较多的 ⊥。这是显式申报的误判界，不是判定器的错误。真正的判定边界是可判域，不是统计置信区间。

十、完全判定

完全判定域按目标分别定义，不立一个统一的总域，不强迫四个对象同时二值可判。意向资格当前没有完全判定域；申报了作用、切换、动力中几个目标全判时，才要求相应各域的交，各域都已含资格判 1 的入口。

1\. 意向资格

意向资格当前不建立完全判定定理。Intent = 1 ⇒ Det\_I = 1 需要四项结构的反向表示：结构成立时形式读数一定取 1；Intent = 0 ⇒ Det\_I = 0 需要失败项的形式零可以回读。概率一侧的两者由《概率判定式》在其条件下给出；本组式新增原子的两者都没有在《意向数理式》中证明。这一缺口属于《意向数理式》的反向表示，在该篇升版时补；本篇不为求完全判定而新立 H。

在这一缺口之下，Det\_I 仍是可靠的：签 1、签 0 都正确；只是有些实例只能判 ⊥。

2\. 定理六　作用完全判定定理

设 FullDetDom\_IAct：Det\_I(χ\_I) = 1；IA-M1 至 IA-M12 成立；所涉候选域有限可枚举；各层覆盖证书都可判且闭合；申报合格。则在 H\_LawRead 与 H\_PAct-Rep 都关闭时：

&nbsp;&nbsp;&nbsp;&nbsp;IntentAct = 1 ⇒ Det\_IAct = 1，　IntentAct = 0 ⇒ Det\_IAct = 0

即 Det\_IAct = IntentAct。

证明：IntentAct = 1。由必要方向，N\_IAct = 1，存在结构见证使 A1 至 A4 同链成立。由《意向作用数理式》七之 2，A1、A3、A4、同链绑定与 A2 的当前发生子层是直接表示，A2 的职责兑现子层在 H\_PAct-Rep 下有表示；所以这一见证的形式登记在覆盖完整时进入候选域并取得 Q\_IAct = 1，Read\_{N\_IAct}^M = 1；H\_LawRead 关闭，Det\_IAct = 1。IntentAct = 0。由充分方向的逆否，N\_IAct = 0；由《意向作用数理式》定理 6 的逆否，Read ≠ 1；在这一域中读数不为 ⊥，申报合格，所以 Read = 0 为结构零；各失败层的覆盖闭合，含 A2-PDuty 时 H\_PAct-Rep 关闭，所以 Det\_IAct = 0。□

3\. 定理七　切换完全判定定理

设 FullDetDom\_IGS：Det\_I(χ\_I) = 1；IGS-M1 至 IGS-M10 成立；所涉候选域有限可枚举；CandidatePairCover\_IGS^M 与各项覆盖都可判且闭合；申报合格。则在 H\_LawRead 与 H\_PAct-Rep 都关闭时，对这一条 σ：

&nbsp;&nbsp;&nbsp;&nbsp;Det\_IGS = IntentGateSwitch\_F(σ)

证明：与定理六同型。正方向用《意向欲门切换数理式》七之 2：S1、S3、S4、共绑定与 S2 除 A2 职责兑现以外的部分都是直接表示，A2 的职责兑现在 H\_PAct-Rep 下有表示。负方向由充分方向的逆否得 N\_IGS(σ) = 0，读数为结构零；每一个候选都至少有一项取得结构 0，并有覆盖闭合的反证路径；若某一候选只有 A2-PDuty 可选，H\_PAct-Rep 关闭，路径可用。所以 Det\_IGS = 0。□

结论只对这一条 σ 成立。

4\. 定理八　动力完全判定定理

设 FullDetDom\_IDyn：Dom = In 已经签出；IDyn-M1 至 IDyn-M14 成立；所涉候选域有限可枚举；各层覆盖都可判且闭合；承重材料全部取自同一运行，同证据键可读，没有被采用的外来记录，因而 L5 的读数为 1；载体与概率的证据都取自正确的对象；申报合格。则在 H\_LawRead、载体一处的上游表示条件（承担读数按见证的 H^-\_M，程度读数按《律动力数理式》《律分级式》的条件）、H\_PAct-Rep、H\_ρRep^-、H2 ∧ H3^red 都关闭时：

&nbsp;&nbsp;&nbsp;&nbsp;Det\_IDyn = IntentDyn\_F^γ(K\_I)

在二值的动力域上成立。OutDom 不进入这一等式。

证明：IntentDyn = 1。由必要方向，N\_IDyn^γ = 1。L1、L2、L3、L6 是直接表示，结构成立且覆盖闭合时形式读数为 1；L4 由 Dom = In 为 1；L5 由域的规定为 1。三处至少一处结构成立：源动一处是直接表示；载体一处与概率一处在上述反向表示条件下取得形式 1。所以 Read\_{N\_IDyn^γ}^M = 1，条件关闭，Det\_IDyn = 1。IntentDyn = 0。由充分方向的逆否，N\_IDyn^γ = 0；由《意向动力数理式》定理 6 的逆否，Read ≠ 1；域中读数不为 ⊥，申报合格，Read = 0 为结构零。L4 = 1、L5 = 1，所以失败在 L1、L2、L3、L6 之一，或三处都为 0；该路径的覆盖闭合，载体与概率的负向条件关闭，路径可用。所以 Det\_IDyn = 0。□

完全判定域不是所有物理世界。L5 没有负向表示：承重证据跨轨的实例不在 FullDetDom\_IDyn 中，只能判 ⊥（EvidenceSplice）。本篇不为把这类实例拉进二值判定而新立 L5 的负向表示条件。

测试 1　资格正例。四项读数都为 1，锚合格，H\_LawRead 关闭。Det\_I = 1。

十五、接口

1\. 上承

《意向一般式》《意向必然式》《意向数理式》：意向资格的双向闭合、形式入口、零型、锚资格与负向回读的边界。  
《意向作用一般式》《意向作用必然式》《意向作用数理式》：作用的双向闭合、三值读数、失败层、覆盖、⊥ 原因与 H\_PAct-Rep 的传播。  
《意向欲门切换一般式》《意向欲门切换必然式》《意向欲门切换数理式》：切换的双向闭合、并列求值、反证路径、覆盖、⊥ 原因与条件传播。

场系统与运行基底：各判定接口的现实来源。

2\. 与《意向反演式》的衔接

本篇对一份现实实例调用合法内部接口签出判词，可以关闭反演中的 ClassOpen：候选的对象真值经本篇判 1 或 0 后，其标签随之闭合。DomOpen 中，由起点资格与 L4 的判定关闭可以关闭的部分，结果为 In、StartDomainFail 或 QualExit。InvOpen 是另一个问题：直接判定一份实例，并不补全原反演协议下的前像枚举。Mix 不由本篇消除：两个合法候选在外部协议下观测等价，这是协议的结构性不可识别；对同一实例再跑一次判定，不会使原协议增加分离能力。

3\. 下交

《意向极限式》：接收 StartDomainFail、QualExit、资格失败时点与重新分段的边界，研究资格与各对象在什么极限上真正退出。

《意向可达式》：可用本篇的判词认证目标状态是否真正到达。  
《意向源式》：可调用 Det\_I 等判词确定首次成立的历史端点；负端的判词按原路径携条件。  
《意向稳定式》：可把本篇的判词作为窗级的状态签名；稳定本身不在本篇判定。
