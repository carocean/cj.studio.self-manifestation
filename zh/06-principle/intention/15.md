# 意向极限式

在意向组式已经闭合的四类对象上，沿事先声明的合法比较方向作极限审查，确定三件事：通常被当作“意向在起作用”的那些外围属性，退到极端时对象是否仍然成立；每一类对象真正不可越过的边界在哪里；越过以后，是哪一个对象退出，退化成什么。

结论是：当前率为零的方向、当前没有源动脉冲、没有显化、没有完整作用、没有切换、两端状态相同、动力位置迁移，这些端点都与相应对象相容；意向资格的边界恰由四项资格结构刻画，意向作用、意向欲门切换的边界恰由各自的结构核刻画；意向动力的边界分为两种，一种是对象内部的退出，一种是整段适用的退出，后者不是动力的否定。意向资格是另外三类对象共同的工作域，它的边界是三者共同的域界，三者各自的边界都不是它的边界。在当前封版的语义域内，这些边界的进入与退出都不携 H。意向的极限不变量不是行为、显化或效果，而是各对象的结构核。

一、基本设定

1\. 上游冻结结论

意向资格：

&nbsp;&nbsp;&nbsp;&nbsp;N\_I := P\_I ∧ SourceDrive ∧ GateCorrespondence ∧ TuneInterface，P\_I := InIntentDomain ∧ Probability

《意向一般式》：Intent ⇒ N\_I；《意向必然式》：N\_I ⇒ Intent。两向 Status 都为 Established，都不携 H。所以

&nbsp;&nbsp;&nbsp;&nbsp;Intent ⇔ N\_I

进入与退出都不携 H。这与《概率极限式》不同：那里退出方向携 H2 ∧ H3^red。但 P\_I 中的 Probability 本身的退出，若要进一步定位到概率资格的三项结构上，仍承继《概率极限式》的条件（第五节定理三）。

意向作用：在工作域 Intent = 1 内，IntentAct ⇔ N\_IAct，N\_IAct := ∃w\_I \[ A1 ∧ A2 ∧ A3 ∧ A4 \]，四项在同一条作用链上递进成立；两向都不携 H（《意向作用一般式》《意向作用必然式》）。

意向欲门切换：在工作域 Intent = 1 内，对每一条固定的比较序列 σ，IntentGateSwitch\_F(σ) ⇔ N\_IGS(σ)，N\_IGS(σ) := ∃w\_a, w\_b, \[G\_a\], \[G\_b\] \[ S1 ∧ S2 ∧ S3 ∧ S4 ∧ B\_same^IGS \]，四项并列，共绑定是守卫；两向都不携 H（《意向欲门切换一般式》《意向欲门切换必然式》）。

意向动力：基础工作域 W\_IDyn := Intent\_{F,t\_0} = 1；IntentDyn\_F^γ(K\_I) ⇔ N\_IDyn^γ，N\_IDyn^γ := (L1 ∧ … ∧ L6) ∧ (Src ∨ Car ∨ Prob)；两向都不携 H（《意向动力一般式》《意向动力必然式》）。L4 的 0 使这一申报段落出工作域，不回读为 IntentDyn = 0，应按资格边界重新分段（《意向动力数理式》七之 3，《意向动力必然式》接口）。

《意向反演式》：观测协议下的不可识别是协议相对的，不是对象的否定。

《意向判定式》：四个判词 Det\_I、Det\_IAct、Det\_IGS、Det\_IDyn；StartDomainFail、QualExit、资格失败的评价点或退出事件与重新分段的边界，下交本篇；判词的 ⊥ 不是对象的第三个真值；当前上游条件下，Det\_I = 0 与 OutDom 都取不到。

《概率极限式》：单维零率、零各向异性、完全确定、数值不可读为相容端点；部分覆盖为开放软区间；整个率域上的零覆盖与 N\_P = 1 不相容；在 H2 ∧ H3^red 下，概率资格的硬界恰由 D、B、R 刻画，越界退化为 Deg\_D、Deg\_B、Deg\_R。

2\. 冻结语义域

记 Σ\_I^cur 为当前封版的《自显论》与意向组式所冻结的语义域：资格、作用、切换与动力各自的冻结语料与必要核。它是证明域的限定，不是本体谓词、场量、第五项资格或 H。以下所说的“硬界”“恰由”“精确”，都只相对于 Σ\_I^cur。若以后出现新的独立职责，并满足上游的重开条件，上游与本篇一并受控升版。

3\. 极限比较协议

&nbsp;&nbsp;&nbsp;&nbsp;Π\_ILim := ( Σ\_I^cur, T, A, Ord\_A, E\_A, Fix\_A )

T：本次审查的目标，T ∈ { Intent, IntentAct, IntentGateSwitch, IntentDyn }。每次只申报一个目标。

A：比较轴。可以是目标结构核的某一项、目标的合法辅助量、外围的结果或强度，或实现资源的量。每一项极限结论都须事先声明比较哪一个轴；不得同时移动几个轴，再把结果归给其中一个。

Ord\_A：该轴的退化方向，例如某一维的当前率下降到零、显化的清晰度下降到零、某一处的动力退到不动。方向在看到结果以前冻结。

E\_A：所申报的端点或边界，须区分四种：端点相容、端点只能逼近、开放软区间、越过对象的边界。

Fix\_A：比较中须固定的身份与协议。同一目标种类；同一 Σ\_I^cur；同一资格锚规则与对象身份规则；作用比较固定当前作用单元的申报规则，切换比较固定 σ，动力比较固定申报窗与 Γ\_IDyn；分辨协议不变；申报轴以外的结构不变。比较族由不同候选组成时，须事先冻结比较族协议，各成员的锚、单元、序列或申报段各在检验前冻结。不得看见结果以后换锚、换候选域、重切申报段，不得跨协议、跨工作域拼成一条极限序列，不得把不同对象的端点混为一个边界。

4\. 极限方向与极限条件

极限方向：沿 Ord\_A，把比较轴推向其退化端。

极限条件：比较族 {χ\_α} 的每一成员都满足 Fix\_A，都在 Σ\_I^cur 的语义之下，并且都由合法候选、合法实例或合法表示组成。

5\. 比较不是动力，也不是稳定、可达或来源

&nbsp;&nbsp;&nbsp;&nbsp;{χ\_α} ≠ χ(t\_0) → χ(t\_1) → …　　LimitComparison ≠ IntentDyn

比较的是一族合法候选，不是同一系统怎样从一个状态变到另一个状态。把源动的脉冲逐步减到零可以是一条比较轴，但不说明哪一个现实系统真的经历了这样的下降；“门承担趋近消失”可以是一条比较轴，但不说明现实中发生了一次切换；资格边界不是动力中的一次资格退出事件。

本篇不研究保持多久、扰动后是否恢复、首次失效与复归、迟滞或稳定宽度，这些属于《意向稳定式》；不研究从给定初态能否实际走到某一端点，这属于《意向可达式》；不研究边界两侧的结构从哪段历史第一次形成，这属于《意向源式》。

6\. 端点相容的含义

“端点相容”（EndpointCompatible）指：目标结构核的各项定义中，没有任何一项排除该端点，所以处在该端点、并且结构核成立的合法候选，由充分方向一定是目标对象。它不断言某一具体物理实现已经存在，实现的构造属于《意向运行基底构造式》；它也不断言从任何初态都能走到该端点，那是《意向可达式》的问题。本篇不用“端点可达”这个词，以免与《意向可达式》的路径可达相混。

“端点只能逼近”（ApproachableEndpoint）指：存在任意接近端点、并且结构核成立的合法候选，而端点本身与结构核不相容。这是存在性结论，须有真实的见证。

“开放软区间”（OpenSoftRange）指：某一非端点的退化范围与结构核相容，不构成边界；但尚未证明存在结构核成立的候选一直逼近端点。

二、不可避免性论证

为什么极限审查必然落到各对象的结构核上，而不是落到行为、显化、效果或强度上？

第一，软极限侧。各对象的结构核是该对象在工作域内的充分核。任何比较族，只要每一成员都在工作域内并保持结构核成立，就每一成员都保持对象成立，无论比较轴走到哪里。这一侧不携 H。

第二，硬界穷尽侧。各对象的必要方向在当前封版状态下都不携 H，所以在工作域内，对象成立就意味着结构核成立；任何从对象内部走到对象外部的比较，都必然使结构核的至少一项由 1 变 0。一个外围属性要成为对象的边界，只能通过破坏结构核的某一项来实现。

第三，因此任何比较轴只有两种可能：它的退化端与结构核相容，这时它是软极限，对象保持；或者它的退化端迫使结构核的某一项失败，这时它越过硬界，而越界的原因是那一项结构，不是该轴本身。

第四，作用、切换与动力还有第三种可能：比较使工作域本身失去，即资格退出，或者对动力而言，起点资格不成立、资格在申报段内不保持。这时对象不是变为 0，而是它的问题不在这一实例上提出。

这一分叉在 Σ\_I^cur 内不可避免，并且对四类对象都不携 H。

三、核心定义

1\. 软极限

某一不属于目标结构核的属性，其退化端或趋近退化端的每一值与结构核相容，称为软极限，分为 EndpointCompatible、ApproachableEndpoint 与 OpenSoftRange（第一节第 6 条）。

2\. 硬界与域界

硬界（HardBoundary\_T）：在 T 的工作域保持时，使 T 由 1 退出为 0 的结构边界。

域界（DomainBoundary\_T）：使 T 的工作域失去的边界。越过域界，T 的问题在这一实例上不提出，记 OutDom；它不是 T = 0。

四类对象的边界分别称为：意向资格的资格边界 QualificationBoundary\_I；意向作用的作用边界 ActionBoundary；意向欲门切换的切换边界 SwitchBoundary；意向动力的动力边界 DynBoundary，后者再分为动力内部边界 DynInternalBoundary 与动力适用边界 DynApplicabilityBoundary。“资格边界”只用于意向资格；作用、切换与动力的边界不称为资格边界。组级总称为对象边界 ObjectBoundary。

3\. 边界值与边界取得

比较轴有冻结的顺序时，记比较族中对象成立的那些轴值为

&nbsp;&nbsp;&nbsp;&nbsp;A^+ := { A(χ\_α) ∣ T(χ\_α) = 1 }

沿 Ord\_A 取 A^+ 的下确界或上确界 b，只给出边界的位置：

&nbsp;&nbsp;&nbsp;&nbsp;BoundaryValue\_T(A) := b

它不给出 b 处的对象值。边界是否实际取得另记：

&nbsp;&nbsp;&nbsp;&nbsp;BoundaryAttained\_T(A; b) ∈ { 1, 0, ⊥ }

1：比较族中有轴值为 b 的合法候选，并且它的对象值与失败结构已经确定；0：已证明比较族中没有轴值为 b 的合法候选；⊥：其余情形。

候选系统的空间上没有定义拓扑，也没有定义边界算子；这里的边界值只是比较轴上的序值，硬界指结构核的退出条件，不是拓扑边界。

4\. 失败签名与越界退化类

越过硬界的候选，记其失败签名 FailSig\_T 为结构核中不成立的项的集合。可以同时有几项失败；不强求唯一的责任项。越界退化类以失败签名中的项命名：Deg\_X 表示 X ∈ FailSig\_T。各类之间可以并存；按失败签名的集合划分，越界区被不重叠、不遗漏地划分，意向动力一侧以第四节第 2 条的限定为准。

意向资格：FailSig\_I ⊆ { P, S, G, T }，依次指 P\_I、SourceDrive、GateCorrespondence、TuneInterface。P ∈ FailSig\_I 时另附子型：Deg\_P,Dom，InIntentDomain 不成立；Deg\_P,Prob，Probability 不成立。子型只是附报，不是第五项资格。

意向作用：N\_IAct 是对作用见证的存在量化，四项在同一见证上递进成立。N\_IAct = 0 即每一个可能的见证都在某处失败；每一见证的失败记在它第一个不成立的层上；各层的材料都能分别找到，却不存在一个合法的共同见证使四项在同一链上成立的，记在 Bind。FailSig\_IAct ⊆ { A1, A2, A3, A4, Bind } 是全部见证失败位置的集合。Bind 不是 A1 至 A4 之外的第五项结构职责：同链由同一个见证 w\_I 承担，Bind 只表示共同见证无法成立，是 N\_IAct 这一存在量化的一种失败方式，不是新增的合取项。

意向欲门切换：顶层四项并列，一个见证组可以同时在几项上失败。FailSig\_IGS ⊆ { S1, S2, S3, S4, Bind } 是全部见证组失败项的集合，Bind 指共绑定 B\_same^IGS 不成立。共绑定在 N\_IGS(σ) 中是见证组的守卫，不是第五项职责（《意向欲门切换一般式》）。

意向动力：动力内部的失败签名 FailSig\_IDyn ⊆ { L1, L2, L3, L6, DynActual }，DynActual 指三处都不动；动力适用边界另记 { StartDomainFail, QualExit }。L4 不进入内部失败签名。L5 当前没有已建立的对象层负向刻画，本篇不申报 L5 型的退化类，也不宣称它在对象层不构成边界（第五节定理六）。

FailSig 与各退化类都是极限分类的标签，不是新的本体谓词。

5\. 本体边界与形式可判边界

本篇的边界都在对象层：对象在结构核失败处退出。《意向判定式》能否在某一实例上签出这一退出，是另一问题。判定器因表示缺口、条件未关闭或材料不足而只能判 ⊥ 的地方，记为形式可判边界 FormalDecidabilityBoundary\_T，只作附报：

&nbsp;&nbsp;&nbsp;&nbsp;FormalDecidabilityBoundary\_T ≠ OnticBoundary\_T

同样，《意向反演式》的 Mix、InvOpen、ClassOpen、DomOpen 是观测协议相对的识别边界，不是对象的边界。

四、结构刻画

1\. 四个成立区

在 Σ\_I^cur 内：

&nbsp;&nbsp;&nbsp;&nbsp;{ Intent = 1 } = { N\_I = 1 }  
&nbsp;&nbsp;&nbsp;&nbsp;在 Intent = 1 的实例中：{ IntentAct = 1 } = { N\_IAct = 1 }  
&nbsp;&nbsp;&nbsp;&nbsp;在 Intent = 1 的实例中，对固定的 σ：{ IntentGateSwitch\_F(σ) = 1 } = { N\_IGS(σ) = 1 }  
&nbsp;&nbsp;&nbsp;&nbsp;在 Intent\_{F,t\_0} = 1 且 L4 = 1 的申报段中：{ IntentDyn = 1 } = { N\_IDyn^γ = 1 }

前三式由各自的双向闭合直接得到。第四式：在 W\_IDyn 内、L4 = 1 时，双向式 IntentDyn ⇔ N\_IDyn^γ 成立；限于 L4 = 1 的申报段，是因为 L4 = 0 的申报段按 L4 的特例纪律不再作为同一意向的一段动力提出问题。

2\. 越界区的划分

意向资格的越界区 { N\_I = 0 } 由 FailSig\_I 的非空子集划分。作用、切换的越界区（在 Intent = 1 内）分别由 FailSig\_IAct、FailSig\_IGS 的非空子集划分。动力在 W\_IDyn 内、L4 = 1 时，越界区中 L5 成立的部分由 FailSig\_IDyn 的非空子集划分；L5 不成立的候选是否独立存在、退化成什么，当前开放（第五节定理六）。这些划分两两不相交，并覆盖相应的越界区，动力一侧为其中 L5 成立的部分。

3\. 域界的嵌套

意向资格是作用、切换与动力共同的工作域：

&nbsp;&nbsp;&nbsp;&nbsp;Intent = 0　⇒　IntentAct、IntentGateSwitch 在该锚上为 OutDom  
&nbsp;&nbsp;&nbsp;&nbsp;Intent\_{F,t\_0} = 0　⇒　IntentDyn 在以 t\_0 为起点的申报段上为 OutDom（StartDomainFail）

动力另有自己的适用边界：

&nbsp;&nbsp;&nbsp;&nbsp;Intent\_{F,t\_0} = 1 而 L4 = 0　⇒　IntentDyn 在该申报段上为 OutDom（QualExit）

作用、切换与动力各自的硬界，都在资格成立的范围之内；它们都不是资格边界。

五、主结论

1\. 定理一　结构保持定理

在 Π\_ILim 下，若比较族的每一成员都在 T 的工作域内，并且 T 的结构核成立，则无论比较轴逼近哪一个合法退化端，每一成员都有 T = 1。对意向动力，工作域指 W\_IDyn，且结构核含 L4。

证明：各对象的充分方向（《意向必然式》《意向作用必然式》《意向欲门切换必然式》《意向动力必然式》），逐成员适用。□

不携 H。这只是充分方向的极限式读法，不新增本体。

2\. 定理二　软极限定理

在 Π\_ILim 下，以下端点与相应对象相容（EndpointCompatible）。

意向资格：

（1）某一正式维当前率为零。V\_I 取自资格实例，不随当前率值增删，当前率为 0 的方向仍属于 V\_I（《意向数理式》七之 4）；单维零率与 N\_P = 1 相容（《概率极限式》定理一）。P\_I、SourceDrive、GateCorrespondence、TuneInterface 都不要求每一维的当前率为正。

（2）当前没有源动脉冲。SourceDrive 是 𝒫\_I 处在源动驱动关系中并承担源动续行的资格，不是当前有脉冲（《意向数理式》定理 2 与七之 4）。

（3）当前没有显化、没有调谐正在进行。TuneInterface 是每一欲门职责类都有合法的门后调谐接口，不是当前正在调谐（《意向数理式》定理 4）；当前没有显化，不取消 N\_I（同上七之 4）。

（4）当前没有完整作用、没有欲门切换、申报段上没有动力。N\_I 的四项都是资格结构，不含当前事件；作用、切换与动力都在资格成立以后才提出。

（5）零各向异性、完全确定、数值不可读。它们与 Probability 相容（《概率极限式》定理一），经 P\_I 进入，不触及另外三项。部分覆盖为开放软区间，承继该篇的结论与开放问题。

意向作用（在 Intent = 1 内，A1 至 A4 同链成立）：

（6）调谐之后被其他机制抵消、经验没有改变、没有显性回路参与、没有显化。A4 是同一链过门以后实际进入调谐使役，不是调谐成功、经验改变或显化（《意向作用一般式》，形式层见《意向作用数理式》命题 8）。

（7）连续两个作用走同一方向与同一欲门，没有欲门切换。作用不要求切换（同上）。

（8）某一正式维当前率为零而另一维形成完整作用链；同一单元内有几个完整见证。作用不要求每一维兑现，也不要求唯一的见证（《意向作用数理式》命题 9）。

（9）外部刺激触发，而续行由意向自身的源动职责承担。A1 问的是承担者，不问诱发来自哪里（《意向作用数理式》命题 4）。

意向欲门切换（在 Intent = 1 内，固定 σ 上 S1 至 S4 与共绑定成立）：

（10）后态没有 A4，没有一次完整的意向作用。S2 只调用作用的 A1、A2、A3（《意向欲门切换必然式》接口）。

（11）切换以后没有显化、没有行为或经验的改变。四项与共绑定都不含这些结果。

（12）在另一条比较序列上又回到旧门。这一条 σ 上的结论不涉及别的序列。

意向动力（在 W\_IDyn 内，L1 至 L6 成立）：

（13）只有一处在动。动力实际性是三处的析取（《意向动力一般式》）。

（14）两端状态相同而中间变过。三处的对象层定义都读真实的跨时变化，不读端态之差（《意向动力必然式》边界例）。

（15）完整作用停止而源动仍在续行；没有欲门切换；没有显化、调谐成功、行为或效应。这些都不是动力的取得条件（《意向动力必然式》第一节）。

（16）诱发来自外界刺激或显式重入，而变化落在意向自身的源动、承担律或组织上；休眠域的压制加重。诱发来源不是动的承担者；压制作用于意向域，意向域因此而变，正是意向在动（《意向动力必然式》边界例）。

（17）动力位置迁移：比较族中各成员的位置不同，例如由只有源动在动到只有载体在动，而每一成员都至少有一处在动。由（13），每一成员都有动力实际性。

证明：每一条都是逐项检查结构核的定义，没有一项排除所列端点；处在该端点而结构核成立的候选，由定理一是目标对象。□

所以上述属性都不是当前各对象的硬界。当前没有已经证明的 ApproachableEndpoint；除（5）承继的部分覆盖以外，本篇不申报新的开放软区间。

不携 H。

3\. 定理三　硬界定理

在 Σ\_I^cur 内：

（1）意向资格：Intent ⇔ N\_I。资格边界恰由 P\_I、SourceDrive、GateCorrespondence、TuneInterface 四项刻画；进入与退出都不携 H。

（2）意向作用：在 Intent = 1 内，IntentAct ⇔ N\_IAct。作用边界恰由 A1 至 A4 的共同见证结构刻画：退化表现为某一层失败，或共同见证无法在同一链上成立；不携 H。

（3）意向欲门切换：在 Intent = 1 内，对固定的 σ，IntentGateSwitch\_F(σ) ⇔ N\_IGS(σ)。切换边界恰由 S1 至 S4 与共绑定刻画，不携 H。

（4）意向动力：在 W\_IDyn 内、L4 = 1 时，IntentDyn ⇔ N\_IDyn^γ，不携 H。在当前已经建立了对象层负向刻画的范围内，动力内部的硬界由 L1、L2、L3、L6 与动力实际性的失败刻画；动力实际性的边界是三处同时不动，不是任何一处单独不动。L5 当前没有合法的对象层负判路径：本篇不由 L5 的形式未决或证据拼接建立动力的硬界，也不申报 L5 型的退化类；是否存在独立的对象层 L5 失败边界，上游没有证明，这里保持开放。

证明：各对象的必要方向与充分方向都已封版，Status 为 Established，都不携 H；合起来，成立区与结构核成立的区域重合（第四节第 1 条），所以对象的进入与退出都由结构核刻画。（4）中 L5 的处理见定理六。□

把边界进一步定位到上游组式的结构项时，承继上游的条件：资格边界落在 Probability 一侧时，若要进一步定位到概率资格的 D、B、R，退出方向携 H2 ∧ H3^red（《概率极限式》定理二）；动力边界落在概率一处时，若要进一步定位到概率动力必要核的各项，退出方向携《概率动力一般式》必要方向的 H2 ∧ H3^red。这些条件只随进一步的定位传播，不进入定理三本身：定理三以 Probability、IntentProbDyn 等对象层事实为边界项。

本体边界不因当前的判定能力而改变。例如 SourceDrive 在对象层不成立时，由《意向一般式》取逆否，Intent = 0；《意向判定式》当前不能由 SourceDrive 的形式零签出 Det\_I = 0，只说明这一边界在当前形式表示中不可判定，不说明它不是资格边界。

4\. 定理四　越界退化定理

在 Σ\_I^cur 内，对意向资格、意向作用、意向欲门切换，越过硬界的每一个候选都不是相应对象，并且其失败签名确定它属于下列退化类中的一类或几类。对意向动力，本定理只覆盖当前已经建立了对象层负向刻画的内部硬界，即在 W\_IDyn 内、L4 = 1、L5 = 1 的范围内，由 L1、L2、L3、L6 或动力实际性的失败取得的越界。

意向资格：

Deg\_P,Dom　位置退化：𝒫\_I 不在意向域中，例如位于欲门之后；它可以是正式的概率组织，却不是意向的组织。  
Deg\_P,Prob　概率退化：申报的组织不是正式的概率组织；在 H2 ∧ H3^red 下，按《概率极限式》进一步退化为维基塌缩、共同绑定解体或相对生成承担失效。  
Deg\_S　源动退化：组织不处在源动驱动关系中，或不承担源动的续行，例如由外部推动的概率组织。它可以仍是概率组织，却不是意向。  
Deg\_G　对应退化：正式维与欲门职责类之间失去双射，例如两个方向合于一个欲门职责类、一个正式维对应两个欲门职责类、存在没有方向对应的正式欲门职责类，或对应不是合法通达。  
Deg\_T　接口退化：某一欲门职责类之后没有合法的调谐接口，只有效应输出或一般的状态变化。

意向作用（资格保持）：

Deg\_A1　没有当前源动发生：资格齐全而静置，或者见证的事件是复走、再入，或者续行由外部完整承担。  
Deg\_A2　概率职责没有当前兑现：概率组织当前没有发生，或者发生了而没有承担各方向之间相对生成的形成，例如续行只由一条固定的成员律决定。  
Deg\_A3　方向没有进入对应的欲门：进入了别的欲门，或者没有过门。  
Deg\_A4　过门以后没有进入调谐使役，只进入效应一侧。  
Deg\_Bind　四层不在同一条作用链上：来自不同的事件、方向、欲门或调谐链的拼接。

意向欲门切换（资格保持，固定 σ）：

Deg\_S1　前态没有现实的合法过门。  
Deg\_S2　后态的过门不是意向驱动的：没有正式源动到 𝒫\_I 的当前承担链，例如外部强制换门；或者前三层不同链，或者后门不属于 σ 的后态。  
Deg\_S3　旧门在后态仍然承担，例如同门继续、并用新增。  
Deg\_S4　旧门的退出与新门的取得不属于同一次现实门承担事件，例如巧合退出、另有机制承担旧门的退出。  
Deg\_Bind　前后两端跨锚、无序、跨序列或跨组织。

意向动力（W\_IDyn 内，L4 = 1）：

Deg\_L1　申报段不是真实运行轨迹的一段，而是快照的拼接。  
Deg\_L2　段内有段外写入的状态或读数。  
Deg\_L3　资格锚在段内更换，跨意向组织或跨运行拼接。  
Deg\_L6　一份合法申报在看到结果以后被改写。  
Deg\_DynActual　三处都不动：场中只有别处在动，例如一条不承担 𝒫\_I 任何正式方向的律在变、另一个不属于 K\_I 的概率组织在变；或者同一外部结果由外部机制产生而意向自身没有一处在动。

证明：前三类由第四节第 2 条直接得到失败签名非空；动力一侧在上述限定的范围内同理。由定理三，它们都不是相应对象。各类的退化结果，由相应结构项的定义与上游对该项的删职检查、边界例给出。□

这里不宣称这些类在未来一切可能理论中绝对穷尽。

5\. 定理五　域界嵌套与优先定理

（1）资格是共同域界。比较族中某一成员 Intent = 0 时，该成员上的 IntentAct、IntentGateSwitch 为 OutDom；以该成员的时点为起点的申报段上，IntentDyn 为 OutDom（StartDomainFail）。这不是这些对象为 0。

（2）反向不成立：IntentAct = 0、IntentGateSwitch\_F(σ) = 0、IntentDyn = 0 都不推出 Intent = 0。

（3）域界优先：比较轴同时触及资格与上层对象的结构项时，若某一成员上资格已经不成立，该成员对上层对象的结论是 OutDom，不是上层对象的内部退出。所以对上层对象作极限审查，须先判资格边界是否先于其内部边界被越过。

证明：（1）作用、切换、动力都在资格成立的工作域内定义，它们的必要方向与充分方向都只在其中适用；资格不成立时，没有合法的路径给出这些对象的值。（2）作用不成立而资格成立的实例、切换不成立而资格成立的实例、动力不成立而资格成立的实例，都在上游的边界例中存在：例如资格齐全而静置（Deg\_A1），外部强制换门（Deg\_S2），段外写入（Deg\_L2）。（3）由（1）。□

6\. 定理六　动力边界两类三支定理

意向动力的边界分为两类三支，彼此不同：动力内部边界一类，即下面（1）；动力适用边界一类，DynApplicabilityBoundary，分为起点与整段两支，即下面（2）（3）。

（1）动力内部边界：在 W\_IDyn 内、L4 = 1 时，由 L1、L2、L3、L6 或动力实际性的失败越过，结果是 IntentDyn = 0（定理三（4））。

（2）动力适用边界之一，起点：Intent\_{F,t\_0} = 0，基础工作域没有进入，结果是 OutDom（StartDomainFail）。

（3）动力适用边界之二，整段：Intent\_{F,t\_0} = 1 而 L4 = 0，资格在申报段内退出或重新形成，结果是 OutDom（QualExit）。这时可以说这一申报段不是合法动力段，即 N\_IDyn^γ = 0；但不说 IntentDyn = 0。

另外，关于 L5。L5 是合法段的必要内容（《意向动力一般式》），对象层上 L5 = 0 推出 N\_IDyn^γ = 0。但上游只建立了形式层的纪律：L5 只取 1 或 ⊥，不设负向的反向表示，证据包取自别的运行只得 ⊥（EvidenceSplice），不是对象层的 L5 = 0（《意向动力数理式》《意向反演式》）。上游没有给出对象层 L5 失败的独立刻画。所以本篇只确定

&nbsp;&nbsp;&nbsp;&nbsp;EvidenceSplice ≠ OnticBoundary\_IDyn，　L5 读数为 ⊥ ≠ 动力退出

并且：L5 的独立对象层负边界，当前未建立。本篇既不由形式层的未决建立这一边界，也不宣称它不存在。

证明：（1）由定理三（4）。（2）由第四节第 3 条。（3）由《意向动力数理式》七之 3 与《意向动力必然式》接口：L4 的 0 使这一申报段落出工作域，不取逆否；N\_IDyn^γ = 0 由 L4 = 0 与合法段的定义得到。L5 一段：证据拼接与 L5 的未决只在形式层，不经过任何回读路径到达对象层的 L5 = 0（《意向动力数理式》七之 4），所以不能成为对象的边界。□

7\. 定理七　边界取得定理

只知 BoundaryValue\_T(A) = b，不得写 T(b) = 1 或 T(b) = 0，也不得读取 b 处的失败签名或退化类。只有 BoundaryAttained\_T(A; b) = 1，才可以从 b 处的候选读取它的对象值、失败签名与退化类。

证明：A^+ 的下确界或上确界只由对象成立的轴值决定；b 本身可以属于 A^+，也可以不属于，比较族中甚至可以没有轴值为 b 的候选。两种情形都与同一个 b 相容。□

8\. 命题　多轴不归责

比较族中同时有几个轴变化，例如 SourceDrive 与 GateCorrespondence 同时退化，最后对象退出，只能说这条复合路径越过了对象的边界，不能说其中某一轴的极限就在这一点；除非另有单轴的比较族或理论上的分离。

&nbsp;&nbsp;&nbsp;&nbsp;MultiAxisCross ⇏ SingleAxisBoundaryIdentification

9\. 命题　边界的轴相对性

同一对象沿不同的合法比较轴，可以有不同的边界。资格可以沿 Probability 一侧、SourceDrive、GateCorrespondence 或 TuneInterface 分别越界。所以不存在一个全局唯一的“意向极限”：边界值记为 b\_T(A; Π\_ILim)，相对于目标、比较轴、方向与协议。

10\. 命题　进入与退出

在 Σ\_I^cur 内，四类对象的进入与退出都由同一结构核刻画，并且都不携 H（定理三），这一点与概率资格的进入不携 H、退出携 H2 ∧ H3^red 不同。但边界是否取得、从哪一侧取得，随比较方向而定：沿 1 → 0 方向与沿 0 → 1 方向，可以一侧取得、另一侧不取得；不预设两侧都取得。

11\. 命题　重新形成不是原段复入

申报段 γ 内资格 1 → 0 → 1，原段已经越过动力适用边界（QualExit）。其后的重新形成不是原来那一段的意向动力回到边界之内，而是须按资格边界重新分段，对新的申报段重新冻结与申报：

&nbsp;&nbsp;&nbsp;&nbsp;Reformation ≠ SameSegmentReentry

L4 由 0 再回到 1，不构成原段的动力的进入。对重新形成的组织是否与原来的组织“同一”，本篇不作结论；它的保持与复归属于《意向稳定式》，它的形成属于《意向源式》。

六、当前边界的精确性

这里不宣称唯一性。候选系统空间上没有拓扑，“硬界”指结构核的退出条件，不是拓扑边界。

在 Σ\_I^cur 内：

&nbsp;&nbsp;&nbsp;&nbsp;N\_I = 1 的候选全部是意向，N\_I = 0 的候选全部不是意向；  
&nbsp;&nbsp;&nbsp;&nbsp;资格成立时，作用、切换在其结构核成立处成立，不成立处不成立；  
&nbsp;&nbsp;&nbsp;&nbsp;W\_IDyn 内、L4 = 1 时，动力在其结构核成立处成立，不成立处不成立；  
&nbsp;&nbsp;&nbsp;&nbsp;各对象的退出恰由失败签名所列的结构项刻画；

这些都不携 H。越界退化各类与结构核的各项相对应，并按失败签名穷尽越界区（第四节第 2 条），动力一侧以 L5 成立的部分为限；这里不宣称它们在未来理论中的绝对穷尽。

八、解读（不属于形式结构）

以下只是对前述结论的说明，不参与证明，不承重。

通常会以为，意向在的时候，一定有点什么正在发生：一个念头冒出来，一次行动，一点被感觉到的东西。按这里的结论，这些都可以退到零而意向仍在：没有脉冲、没有显化、没有行动、没有切换，甚至这一段上什么都没有动，意向资格照样成立。一次作用也可以没有任何看得见的后果；一次切换可以没有完成一次完整的作用；一段动力可以首尾相同，可以只有一处在动，也可以从这一处移到那一处。

意向消失的地方只有四处：组织不在意向域中或不是正式的概率组织；它不再承担源动；方向与欲门的对应散了；欲门之后没有调谐的接口。作用、切换与动力各有自己消失的地方，但它们都在意向之内；意向一旦不在，它们不是变成“没有”，而是不再被问起。

所以意向的极限不在它的效果上，而在它的结构上。

九、最终结论

1\. 总式

在 Π\_ILim 与 Σ\_I^cur 下：

软极限：定理二所列端点都与相应对象相容；动力的单处失去、位置迁移、两端相同都不是动力的退出。Status = Established，不携 H。当前没有已证明的可逼近端点；部分覆盖承继《概率极限式》的开放软区间。

硬界：四类对象的边界恰由各自的结构核刻画，进入与退出都不携 H。动力内部的失败项，以当前已建立对象层负向刻画的范围为限；L5 的独立对象层负边界当前未建立，保持开放。进一步定位到上游结构项时，承继上游的条件。

越界退化：资格 Deg\_P,Dom、Deg\_P,Prob、Deg\_S、Deg\_G、Deg\_T；作用 Deg\_A1 至 Deg\_A4、Deg\_Bind；切换 Deg\_S1 至 Deg\_S4、Deg\_Bind；动力内部 Deg\_L1、Deg\_L2、Deg\_L3、Deg\_L6、Deg\_DynActual，限于 L5 成立的范围，不申报 L5 型。

域界：资格是作用、切换与动力共同的域界；动力另有起点与整段两种适用边界。越过域界为 OutDom，不为 0。

2\. 条件账本

&nbsp;&nbsp;&nbsp;&nbsp;H\_new = ∅

定理一至定理七与各命题都在对象层，只调用各对象已封版的必要方向与充分方向，这些方向都不携 H；Status = Established。

进一步定位的条件：资格边界定位到概率资格的 D、B、R 时，退出方向携 H2 ∧ H3^red；动力边界定位到概率动力必要核的各项时，退出方向携《概率动力一般式》的 H2 ∧ H3^red。这些条件只随进一步的定位传播。

现实检测的条件：若以《意向判定式》的判词或各数理式的形式读数作为边界见证的输入，例如以 Det\_I = 0、OutDom（StartDomainFail）或 OutDom（QualExit）证明边界已在某一实例上实际取得，则须承继该篇实际路径上的条件，包括 H\_LawRead、H2 ∧ H3^red、H^-\_M、H\_ρRep^-、H\_PAct-Rep 中实际所用者。对象层的极限定理与现实的边界检测，条件账本分列，不互相传染。

Σ\_I^cur、Π\_ILim、比较族协议与 BoundaryAttained 都是证明域与比较方法的限定，不是 H。

本篇不承继 H\_GP、H\_TI、H\_PL、H\_SD。

3\. 禁止推论

不得：没有观测到输出、没有显化、没有行为 ⇒ 资格边界。  
不得：当前率为零 ⇒ 该方向不属于 V\_I，或意向不成立。  
不得：当前没有源动脉冲 ⇒ SourceDrive 不成立。  
不得：IntentAct = 0、IntentGateSwitch = 0 或 IntentDyn = 0 ⇒ 资格边界。  
不得：Intent = 0 ⇒ IntentAct = 0、IntentGateSwitch = 0 或 IntentDyn = 0。  
不得：没有完整作用 ⇒ 没有意向欲门切换。  
不得：Src = 0、Car = 0 或 Prob = 0 单独 ⇒ IntentDyn = 0。  
不得：动力位置迁移 ⇒ 动力退出；两端差为零 ⇒ 没有动力。  
不得：L4 = 0 ⇒ IntentDyn = 0。  
不得：EvidenceSplice、L5 读数为 ⊥ ⇒ 动力的边界。  
不得：Det\_T = ⊥、形式可判边界或反演的不可识别 ⇒ 对象的边界。  
不得：BoundaryValue = b ⇒ T(b) = 0 或 T(b) = 1。  
不得：ApproachableEndpoint ⇒ EndpointCompatible；EndpointCompatible ⇒ 从给定初态可达。  
不得：多轴同时变化 ⇒ 其中某一轴的边界。  
不得：资格重新形成 ⇒ 原申报段的动力回到边界之内。  
不得：把 Σ\_I^cur 内的边界写成未来理论永恒唯一的本体边界。

4\. 击穿方式

极限式的击穿是：极限条件已经成立，而所断言的极限性质没有出现。

K-ILim1　软端误界：宣称某一端点与结构核相容，却能证明结构核的某一项排除该端点。  
K-ILim2　外围误界：把不属于结构核、也不是工作域条件、也没有已成立的桥推出结构项失败的轴，写成对象的硬界。  
K-ILim3　硬界内反例：在工作域内存在对象成立而结构核不成立。  
K-ILim4　硬界外反例：在工作域内存在结构核成立而对象不成立；这同时直接击穿相应的必然式。  
K-ILim5　退化分类错误：宣称某候选属于某一退化类，而该结构项事实上成立；或者按失败签名的划分出现重叠或遗漏。  
K-ILim6　比较协议污染：极限族须经换锚、换单元、换 σ、重切申报段、换候选域、改分辨协议或跨协议拼接才取得极限结果。  
K-ILim7　动力偷渡：把比较族写成同一系统的真实时间演化，并据此断言形成原因、保持或恢复。  
K-ILim8　把可逼近端点写成相容端点；或把相容端点写成路径可达。  
K-ILim9　由边界值直接读取端点的对象值或失败签名。  
K-ILim10　多轴变化，把退出责任归给其中一轴。  
K-ILim11　把判定的 ⊥、形式可判边界或反演的不可识别当作对象的边界。  
K-ILim12　把作用、切换或动力的内部边界写成资格边界。  
K-ILim13　资格退出以后，把作用、切换或动力写成 0，而不是 OutDom。  
K-ILim14　L4 = 0 被写成 IntentDyn = 0；起点资格不成立被写成 IntentDyn = 0。  
K-ILim15　证据拼接或 L5 的未决被升格为动力的对象边界；或者反过来，把 L5 当前没有负向刻画写成 L5 在对象层不构成边界。  
K-ILim16　单处失去、位置迁移或两端相同被写成动力的退出。  
K-ILim17　资格的重新形成被当成原申报段回到边界之内。  
K-ILim18　极限式研究保持、恢复、稳定时间、路径可达或首次形成。  
K-ILim19　为取得完整边界而新增 H、新增资格项或新增对象的组成项。  
K-ILim20　绝对唯一性越权：把 Σ\_I^cur 内的精确边界写成未来理论永恒唯一的本体边界。

5\. 回归测试

以下只作回归检验，不作一般证明。

测试 1　Probability 一侧越界。SourceDrive、GateCorrespondence、TuneInterface 保持，申报组织不再是正式概率组织。Intent = 0，Deg\_P,Prob；进一步定位到 D、B、R 时携 H2 ∧ H3^red。作用、切换为 OutDom；以此为起点的动力为 OutDom（StartDomainFail）。  
测试 2　SourceDrive 越界。Probability 仍成立，组织由外部推动，不承担源动续行。对象层 Intent = 0，Deg\_S，不携 H；当前 Det\_I = ⊥（IntentAtomRepOpen）。本体边界成立，形式可判边界另报。  
测试 3　无显化。显化退到零，四项资格成立。Intent = 1，不是资格边界。  
测试 4　某一维当前率为零。四项资格成立。Intent = 1。  
测试 5　作用 A4 越界。资格保持，A1 至 A3 同链成立，过门以后只进入效应一侧。IntentAct = 0，Deg\_A4；Intent 不退出。  
测试 6　切换而无完整作用。资格保持，S1 至 S4 与共绑定成立，后态没有 A4。IntentGateSwitch\_F(σ) = 1；A4 不成立不是切换边界。  
测试 7　外部强制换门。旧门退出、新门取得，没有正式源动到 𝒫\_I 的承担链。IntentGateSwitch\_F(σ) = 0，Deg\_S2；资格不退出。  
测试 8　源动一处消失。合法段保持，源动由动到不动，载体仍在动。IntentDyn = 1。  
测试 9　三处全失。合法段保持，三处都不动。IntentDyn = 0，Deg\_DynActual。  
测试 10　段外写入。起点资格与 L4 成立，段内有段外写入。IntentDyn = 0，Deg\_L2。  
测试 11　资格在段内退出。起点资格成立，γ 内资格退出。L4 = 0，N\_IDyn^γ = 0，IntentDyn 为 OutDom（QualExit），不为 0。  
测试 12　证据跨轨。被采用的承重证据来自别的运行。Det\_IDyn = ⊥（EvidenceSplice）；这不是动力的对象边界，对象层的动力情形另行确定。  
测试 13　两端相同。中间三处之一真实地动，终点回到起点状态。IntentDyn = 1。  
测试 14　位置迁移。比较族由只有源动在动的成员到只有概率组织在动的成员，每一成员合法段成立。每一成员 IntentDyn = 1。  
测试 15　只知下确界。已知对象成立的轴值集合的下确界为 b，未证明 b 被取得。只报告 BoundaryValue = b，BoundaryAttained = ⊥；不报告 b 处的对象值。  
测试 16　资格退出后重新形成。申报段内资格 1 → 0 → 1。原段为 OutDom（QualExit）；后段须重新申报，不写成原段动力的恢复。  
测试 17　双轴同变。比较族中 SourceDrive 与 GateCorrespondence 同时退化，资格退出。只报告复合路径越过资格边界，FailSig\_I 为 S、G 中实际不成立的项组成的非空集合；不把边界归给其中一轴。

十、接口

上承

《意向一般式》《意向必然式》《意向数理式》：N\_I 的四项、双向闭合、结构侧对应（当前率为零、没有脉冲、没有显化不取消资格）、本组式新增原子的负向表示边界。  
《意向作用一般式》《意向作用必然式》《意向作用数理式》：N\_IAct、递进与同链、双向闭合、边界命题。  
《意向欲门切换一般式》《意向欲门切换必然式》《意向欲门切换数理式》：N\_IGS(σ)、并列与共绑定、双向闭合、S2 只调用前三层。  
《意向动力一般式》《意向动力必然式》《意向动力数理式》：N\_IDyn^γ、合法段、三处及其归属绑定、双向闭合、边界例、L4 的特例纪律、L5 只取 1 或 ⊥。  
《意向反演式》：识别边界的协议相对性。  
《意向判定式》：StartDomainFail、QualExit、资格失败的评价点或退出事件、重新分段的边界，作为现实实例中边界已经取得的见证；判词的条件随见证传播。  
《概率极限式》：概率资格的软极限、硬界与越界退化，经 P\_I 进入。

与《意向判定式》的衔接

本篇不重复判定。该篇的 StartDomainFail 说明：在这一实例的起点，资格边界已经越过；QualExit 说明：在同一申报段内，资格边界被实际越过，原段的动力适用域结束。本篇进一步回答：这是哪一项结构的边界，属于哪一类退化，是对象内部的退出还是工作域的退出，边界是否实际取得。在当前上游条件下，该篇取不到 Det\_I = 0 与 OutDom，所以现实实例中资格边界的取得见证暂时都只能报为未决；这不影响本篇对象层的边界结论。

下交

《意向运行基底构造式》：本篇给出需要能够实例化与检验的软极限族、四类硬界、三处的耗尽、L4 的适用边界；相容端点的具体实现，以及是否存在可逼近端点，由该篇构造；L5 的开放项另见下条。  
《意向可达式》：接收本篇的端点与边界，研究从给定初态是否有有限的合法路径实际到达；本篇的“端点相容”不是该篇的“可达”。  
《意向源式》：边界两侧的结构从哪段历史第一次形成，本篇不回答。  
《意向稳定式》：本篇给出对象在哪里退出；该篇回答在许可的变化轨迹上是否保持、何时首次失效、能否恢复，以及重新形成的组织与原组织的关系。  
《意向数理式》升版：补本组式新增原子的反向表示以后，资格边界的现实检测可以扩展到 SourceDrive、GateCorrespondence、TuneInterface 与位置一侧。  
L5 的开放项，分层交出：有没有对象层上 L5 独立失败的世界，交《意向运行基底构造式》或其他合法的构造与反例去探查；若发现这样的世界，先由《意向动力一般式》补它在对象层的失败刻画，再由《意向动力数理式》补相应的负向表示与回读，两篇随之受控升版，本篇的动力内部边界与退化分类一并升版；若构造层始终只发现证据错配，而没有独立的对象层 L5 失败，不因此升版。构造式只承担检验，不替代对象层的定义。

不做的事

不把意向定义为行为、显化、效果或强度；不新增资格项或任何对象的组成项；不把判定的未决或反演的不可识别写成对象的边界；不证明动力变化、跨时稳定、来源或可达；不重新作实例判定；不宣称各结构核是未来理论永恒唯一的本体核。
