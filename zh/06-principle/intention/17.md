自显论 · 理篇 · 意向组式第十七 v1.0

# 意向可达式

## 第一节　目的、进入条件与唯一待证命题

### 1.1 目的

《意向运行基底构造式》已经给出一族可运行的沉积场系统：已有合法意向结构的场中，源动、作用、欲门切换、调谐与跨时动力实际运行，资格、作用、切换与动力的读数都从同一份统一运行证书上的真实历史取得。构造已经给出。

剩下的是可达问题：从一个事前申报的初态出发，只用事前冻结的许可输入与系统自身的合法动力，是否存在一条有限的合法真实历史，使上游已经定义的某一类意向目标在这条历史中实际成立；如果不存在，凭什么说不存在；如果暂时既找不到路径、也证不出不存在，应当怎样记录。

以下只回答这一问题：不重新定义意向、意向作用、意向欲门切换或意向动力，不重新证明资格的成立条件，不把可达写进意向资格的组成，不新增任何动力引擎。四类目标的含义、工作域与回读条件，全部沿用已封版的上游。

### 1.2 进入条件

（一）构造已经给出：《意向运行基底构造式》v1.0 及其参考模型 v14.5（附录 C 列出十个源码的 SHA-256）。

（二）初态界定清晰：第二节申报。

（三）许可输入集界定清晰：第三节申报，并在路径构造以前冻结。

（四）目标属于四类之一，其上游定义、入口与工作域已经封版：意向资格（《意向一般式》《意向数理式》《意向必然式》）、当前作用（《意向作用一般式》《意向作用数理式》《意向作用必然式》）、欲门切换（《意向欲门切换一般式》《意向欲门切换数理式》《意向欲门切换必然式》）、意向动力（《意向动力一般式》《意向动力数理式》《意向动力必然式》），判词与入口分流按《意向判定式》。

### 1.3 与相邻式文的分工

《意向运行基底构造式》回答“已有意向能否在场中实际运行”，这里回答“从给定初态能不能合法地走到”。《意向源式》回答意向结构首次形成的来源条件；《意向稳定式》回答成立以后的保持、失效与恢复；《意向生成基底构造式》（第二十一篇）在基础沉积场中构造意向资格首次成立的完整历史。这里所用的初态都建立在已安置的意向专用结构之上，所以这里的资格可达只是“已安置结构上的资格重新成立”，不是意向的首次生成。

可达不等于意向资格、当前作用或意向动力本身；不等于稳定、保持或恢复；不等于可控；不等于一切合法历史都保证到达。

### 1.4 唯一待证命题

给定冻结的任务规格，目标可达当且仅当存在一条从初态出发、每一步只用许可输入并落在合法后继之内的有限真实历史，以及这条历史上的一份见证，使上游定义的目标在该见证上实际成立；有效的形式命中证书足以签出可达，由封闭的后继域、覆盖目标全部命中方式的必要条件与不变量组成的负证书足以签出不可达，两者都没有取得时只能记为未决。

## 第二节　任务规格、初态与目标

### 2.1 冻结任务规格

&nbsp;&nbsp;&nbsp;&nbsp;Ξ\_R = (Spec, X\_0, U^adm, 𝒯, G, Π)

Spec 是《意向运行基底构造式》的参考运行规格 Spec\_IB^ref；X\_0 是初态；U^adm 是许可输入集；𝒯 ∈ {I, IAct, IGS, IDyn} 是目标类型；G 是该类型下的具体目标；Π 是核验协议，包括目标监视器、历史绑定规则、比较序列规则与申报段规则。Ξ\_R 在整条历史上不变，是冻结的任务规格，不是动态状态。

### 2.2 状态与随机实现

在本篇的许可集之内，唯一的随机分支是组织事件的选维（没有给定路径的场脉冲另有随机续行，它不在本篇的许可集之内）：概率组织按当时的相对生成关系 Rel 选取一个正式维，选中维 d 的概率就是 Rel(d)。场层脉冲沿给定路径执行，不含随机分支。

这里申报的状态 X 是场、概率层与意向侧的全部状态量，不含随机源本身；随机源只决定从同一状态出发实际取得哪一个合法后继。所以同一 X\_0 可以有多条实现：参考模型以流号 s 为随机源设种子，不同流号给出同一初态上的不同实现。初态的形成过程只沿给定路径施加脉冲，不抽取任何随机源，所以任何流号下的初态都相同；附录 A 对流号 0 至 5 逐量核对了这一点：流号 0 至 5 的初态，在各边的沉积量、重复记录、门槛、可用性与屏蔽，各节点的沉积，运行与沉积计数，场日志、路径动力与程度记录，概率层的绑定、生成闸与载体接线，以及意向侧的门承担、会话与事件计数上完全相同，只有随机源不同。

除历史记录以外，状态 X 不含的量只有两类：随机源，以及运行身份标识（取自对象地址，每次构造不同）。这两类量都不影响许可输入下的后继：运行身份只进入记录的身份核对，不进入任何动力更新；场层与概率层自带的随机源在许可输入下不被抽取：许可输入中的场层脉冲都带给定路径，场层只在没有给定路径时才抽取随机续行（fldb\_work.py 第 61 至 69 行），概率层自身的随机事件不在许可集内；附录 A 的 x0 命令在一段许可输入序列前后核对了这两个随机源的状态不变；意向侧的随机源只用于选维。职责登记、对应关系、调谐候选登记、载体候选登记与各协议在不同流号下也完全相同。所以在许可输入之下，后继只由 X、输入与选维抽样决定。

事件记录与证书条目属于历史，不属于状态；它们由许可输入产生，读出器与回读都从历史上取材料，所以历史的同一性由证书保证，不由状态保证。

随机实现指选维所用的一列均匀抽样值；参考模型以流号设种子，只是给出随机实现的一种方式。在选维核的均匀抽样理想化之下，支撑内的任一抽样序列都是一个随机实现。随机源的状态记入统一运行证书的全状态摘要，所以在一条历史的中途改写随机源是绕过合法操作的写入，会使证书断链；随机实现只能在初态处选定。

### 2.3 四类目标

各类目标都以上游对象的实际成立为准，记作 ActualTarget\_G(w)，w 是某一条历史上的见证。

资格目标 G\_I（状态目标）：历史上某一评价点 t 处 Intent\_{F,t} = 1。见证是证书上的一个点。

作用目标 G\_IAct（事件目标）：历史上某一现实事件 w，其开始处 Intent = 1，且 IntentAct(w) = 1。开始处资格不为 1 的事件，按《意向判定式》对作用判词作入口分流（OutDom 或 ⊥），它既不是命中，也不是作用目标的失败。

切换目标 G\_IGS^{→\[G\_b\]}（序列目标）：比较序列规则 σ 事前冻结为“证书上的每一个组织事件与紧邻的前一个组织事件相比”；历史上某一对相邻组织事件 (w\_a, w\_b)，两端开始处 Intent = 1，IntentGateSwitch\_F(σ) = 1，且后态之门属于职责类 \[G\_b\]。

动力目标 G\_IDyn（段目标）：历史上某一申报段 γ，起点资格为 1，IntentDyn\_F^γ(K\_I) = 1，即合法动力段六项都成立且三处至少一处有动力。

事件、序列与段目标的时间窗口取初态登记点之后的证书历史：见证所用的事件都必须是这段历史中的事件，前态事件也不例外。本篇各初态在登记点以前没有任何事件（门承担状态为空），所以没有被这一窗口遗漏的前态事件。

四类目标各自继承其上游的入口与工作域，不相互填补，也不合成一个总的意向可达判词。

### 2.4 初态申报

参考初态 X\_0：《意向运行基底构造式》参考构造在统一运行证书建立以前的状态，资格形式读数为 1（IntentCoreCert^M = 1），两个正式维都在 V 中，Rel = (A: 0.51829, X: 0.48171)，尚无任何事件，门承担状态为空。

源动侵蚀初态 X\_0^er：在 X\_0 上以构造层的形成脉冲只刷新其余各边与两维、不刷新源动段，直到源动段失去成律（同《意向运行基底构造式》V6 的退出段）。此时形式读数 SourceDrive^M = 0、Probability = 1、IntentCoreCert^M = 0。SourceDrive 属于本组式新增的原子，它的形式零不回读为结构零，所以对象层的资格判词在这里为 ⊥（IntentAtomRepOpen），不是 0；本篇对 X\_0^er 只使用这一形式读数。

零率初态 X\_0^z：在 X\_0 上以生成闸把维 A 的生成关到 0。此时 Rel(A) = 0，V 仍为 {A, X}，Probability = 1，资格形式读数 IntentCoreCert^M = 1，这是《意向运行基底构造式》V11 的零率端点。

三个初态都在统一运行证书建立以前申报，证书以一次零步的 IdleStep 作起点登记，这一登记前后的全状态摘要相同，不改变任何状态，不计入路径。就本篇申报的各个实例而言，目标在初态处都没有命中：X\_0 与 X\_0^z 上尚无任何事件；X\_0^er 上资格形式读数为 0。这只是对这些实例的申报，不是对目标的一般要求：一般的资格目标，若初态的资格形式读数已为 1，即在零步处形式命中（H = 0，见 4.2 与 3.5）；状态目标与事件目标的时间制度不同，事件目标至少要有一次事件。

初态的资格与目标的可达是两件事：

&nbsp;&nbsp;&nbsp;&nbsp;¬R\_Ξ(X\_0, G) ⇏ ¬Intent(X\_0)，　IntentCoreCert^M(X\_0) ≠ 1 ⇏ ¬Reach\_Ξ^M(X\_0, G\_I)

前者在 X\_0^z 上出现：初态的资格形式读数为 1（对象层 Intent(X\_0^z) = 1 按 11.2 中 G\_I 的回读条件），而切换进入 \[G\_A\] 不可达（第八节），所以前者的对象层见证随 G\_I 的回读条件为 Conditional，形式层见证（IntentCoreCert^M(X\_0^z) = 1 而 Reach\_Ξ^M = 0）无条件；后者在 X\_0^er 上出现：初态的资格形式读数为 0，而资格目标在形式层可达（第六节）。第二条是形式层的分离；它的对象层形式（Intent(X\_0) = 0 ⇏ ¬R\_Ξ(X\_0, G\_I)）还须对象层资格负判，而本组式新增原子的负向回读未关闭，所以这里只在形式层申报。

## 第三节　许可输入、系统动力与合法后继

### 3.1 许可输入

U^adm 是统一运行证书合法操作集的子集，由 Ξ\_R 在路径构造以前一次冻结。扩大它须另行申报，并重新走可达论证。本篇实际用到的许可集：

&nbsp;&nbsp;&nbsp;&nbsp;U\_ev = {OrgEvent}  
&nbsp;&nbsp;&nbsp;&nbsp;U\_neg = {OrgEvent, SourceOnlyEvent, IdleStep}  
&nbsp;&nbsp;&nbsp;&nbsp;U\_neg⁺ = U\_neg ∪ {GenGate(A, 1.0)}

OrgEvent 是一次完整组织事件：自源动节点起，经概率组织选维，沿该维的载体、过门段与门后段走完。施加 OrgEvent 是输入；选中哪一维、事件是否构成作用、是否构成切换，都是系统按 Spec 运行以后的事实，不是可以从外部按下的结果。

### 3.2 系统动力

下列由 Spec 自动发生，不是外部操作，不计入 U^adm：场的衰减与沉积、成律判定、概率组织的正式维、相对生成关系与共同绑定的计算、组织事件中的选维、门承担记录的更新、统一运行证书的记录。

### 3.3 合法后继

定义集合值映射 F\_R(X, u)：在冻结的 Spec 与输入 u 下，系统动力以正概率产生的一步后继的集合。OrgEvent 至多有两个后继，分别对应选中 A 与选中 X，概率为当时的 Rel(A) 与 Rel(X)；Rel 为 0 的维不在后继之内。其余许可输入只有一个后继。

参考模型有数值终点：同一维连续承担数十次组织事件以后，承担律入口的指数权重溢出，操作中途失败。这是参考程序的数值表示能力到达边界，不是沉积场动力的终止：

&nbsp;&nbsp;&nbsp;&nbsp;参考程序数值终止 ≠ 沉积场动力本体终止

为此区分两个后继关系。F\_R 是 Spec 意义下的后继关系。F\_R^ref 是参考程序的可执行语义 S\_ref 给出的后继关系：输入在 X 上完成时，F\_R^ref(X, u) 是程序以正概率产生的完成状态的集合；输入在 X 上中途失败时，按模型约定 C\_num 取 F\_R^ref(X, u) = ∅。C\_num 只是对参考程序的约定，不是对场的断言。参考工作域 W\_ref 是在 S\_ref 下由已完成的合法操作所到达的全部状态。

在数值终点以前，F\_R^ref 与参考规格的后继一致；本篇的一切历史都由已完成的操作组成。第五节的定理对任一具有本节形式的后继关系成立；用于参考实例时，后继关系取 F\_R^ref。凡用到 C\_num 的结论（第七节命中概率的精确值、锁定概率与保证到达不成立，8.3 的穷尽型尾段证书），都只对 S\_ref 成立，不推广到沉积场本身；对 C\_num 不敏感的结论（第六节的显式路径、8.1 的不变量型负证书、第七节命中概率的下界）在任何与 S\_ref 在数值终点以前一致、保持选维规则、路线、写入范围与生成闸乘子的语义扩展中同样成立，各处另行写明。

### 3.4 禁用操作

路径禁止使用：绕过合法操作直接写场、概率层或意向侧的任何状态量；指定选维；外部换门；修改职责登记、对应关系、调谐候选登记或载体候选登记；修改协议、比较序列规则、申报段规则或目标；中途改写随机源；中途扩大许可集。

第七节为了计算精确的核概率而逐一取出 F\_R^ref(X, u) 中的每个后继，这是对后继集合的分析，不是路径上的操作，不进入任何正路径。

### 3.5 历史合法性

历史合法由两部分组成，二者必须同时成立，这条历史才能用于可达证明。其一是操作合法：输入与后继是否合法，由冻结的 Spec、U^adm 与后继关系决定。其二是记录合法：运行记录是否满足证明所需的条件，由统一运行证书决定。即一条历史 γ = (X\_0, u\_0, X\_1, …, u\_{H−1}, X\_H) 合法，当且仅当对一切 k \< H 有 u\_k ∈ U^adm、X\_{k+1} ∈ F\_R(X\_k, u\_k)，并且统一运行证书在从初态登记点到 X\_H 的一段上读出

&nbsp;&nbsp;&nbsp;&nbsp;Legal\_R(γ) := L1 ∧ L2 ∧ L3 ∧ L5 ∧ L6 = 1

L1 至 L3、L5、L6 是《意向动力数理式》的合法段各项：轨迹同运行、同分支、计数不倒退，状态写入闭合于合法操作，职责身份不变，承重证据同轨，协议冻结。它们是对运行记录的证明条件，不等同于一切物理操作的合法性；操作本身是否合法，仍由前一部分决定。L4（整段资格保持）不是历史合法性的条件：资格目标的历史必然跨越资格的变化；L4 只作为意向动力目标自身的组成出现。

长度为 0 的历史 (X\_0) 不含任何操作，没有写入需要证书闭合，约定 Legal\_R((X\_0)) = 1。统一运行证书在零宽申报上读出 ⊥，那是申报段的读出规则，不改变这一约定；零步历史只用于资格目标在初态处的命中。

## 第四节　可达命题、命中证书与判词

### 4.1 对象层可达

&nbsp;&nbsp;&nbsp;&nbsp;R\_Ξ(X\_0, G) ⟺ ∃γ ∈ ℋ\_Ξ(X\_0) ∃w ⪯ γ : ActualTarget\_G(w)

ℋ\_Ξ(X\_0) 是从 X\_0 出发的有限合法历史的集合，w ⪯ γ 表示见证属于这条历史。

### 4.2 形式命中证书

CertHit\_G(w) = 1，当且仅当：w 属于一条 Legal\_R = 1 的历史；对作用、切换与动力目标，w 的入口资格（作用事件的开始处、切换两端事件的开始处、动力申报段的起点）取形式读数 1；目标的形式读数在 w 上取 1，并且该读数所需的形式可解性条件都成立。资格目标没有另外的入口：它的形式读数本身就是资格读数，见证可以是初态登记点，即允许零步命中（H = 0）；本篇的资格实例取资格形式读数为 0 的初态，所以没有零步命中；实例中命中在第 1 步（6.3）。四类目标的形式读数为：

&nbsp;&nbsp;&nbsp;&nbsp;G\_I：IntentCoreCert^M = 1（《意向数理式》）  
&nbsp;&nbsp;&nbsp;&nbsp;G\_IAct：Read\_{N\_IAct}^M(w) = 1，IA-M1 至 IA-M12 都成立（《意向作用数理式》）  
&nbsp;&nbsp;&nbsp;&nbsp;G\_IGS：Read\_{N\_IGS(σ)}^M(w\_a, w\_b) = 1，IGS-M1 至 IGS-M10 都成立（《意向欲门切换数理式》）  
&nbsp;&nbsp;&nbsp;&nbsp;G\_IDyn：Read\_{N\_IDyn^γ}^M = 1，IDyn-M1 至 IDyn-M14 都成立，合法段六项都为 1（《意向动力数理式》）

形式命中与对象层成立之间有两个方向，须分别登记，不能用“监视器正确”一句话代替：

&nbsp;&nbsp;&nbsp;&nbsp;无误报：CertHit\_G(w) = 1 ⇒ ActualTarget\_G(w)  
&nbsp;&nbsp;&nbsp;&nbsp;无漏报：ActualTarget\_G(w) ⇒ MonitorHit\_G(w)

无误报由上游的正向回读与必然式的充分方向给出，条件按上游原归属承继（第十一节的条件表）。无漏报要求监视器读到历史上的全部合法事件与全部状态写入，并且结构层的目标在形式层有相应的正见证；后者就是上游负向回读所要求的反向表示。只有无漏报与完整的合法后继覆盖同时成立，才能从“监视器没有命中”推出对象层不可达。

形式层可达定义为：

&nbsp;&nbsp;&nbsp;&nbsp;Reach\_Ξ^M(X\_0, G) = 1 ⟺ ∃γ ∈ ℋ\_Ξ(X\_0) ∃w ⪯ γ : CertHit\_G(w) = 1

### 4.3 三种量词

实例可达：R\_Ξ(X\_0, G)。

初态域内可达：对申报的初态域 D，∀X\_0 ∈ D 有 R\_Ξ(X\_0, G)。

保证到达：从 X\_0 出发的每一条极大合法历史都命中 G。第七节在 S\_ref 与许可集 U\_ev 之下只考察截断于首次命中的历史；这些历史都在 40 步以内命中，或锁定以后沿唯一后继链在数值终点处结束，所以都是有限的。首次命中以后的延续不在考察之内。含 IdleStep 或 SourceOnlyEvent 的许可集可以有无限长的历史。

保证到达蕴涵实例可达，反之不然；初态域内可达蕴涵其中每一实例可达，反之不然。可达不等于可控：许可集中没有任何输入能指定选维，同一输入序列在不同随机实现下走向不同的后继。

### 4.4 可达判词

&nbsp;&nbsp;&nbsp;&nbsp;Det\_R^𝒯(Ξ\_R) ∈ {1, 0, ⊥, OutDom}

OutDom：X\_0 不在 Ξ\_R 申报的工作域之内（例如处在数值终点之外），或 𝒯 不属于四类目标。它在证据判定以前独立分流。

⊥（DeclarationInvalid）：Ξ\_R 或其登记不是在运行以前冻结的，或者中途改动了许可集、比较序列规则、申报段规则或目标。这沿用上游“申报失格只退为 ⊥”的纪律。

1：取得一条合法历史与其上的 CertHit\_G = 1，并且 11.2 中该目标正向回读所需的条件已经关闭。按《意向判定式》“判 1 时对象一定成立”的纪律，这些条件未关闭时 Det\_R = ⊥（LawReadOpen），形式层可达 Reach\_Ξ^M = 1 另行登记。

0：取得一份负证书（第五节定理二）。

⊥：两者都没有取得。有限步内没有命中、有限次实现没有命中，都只能记 ⊥。

四类目标各有自己的 Det\_R^𝒯，不合成为一个总判词。

## 第五节　可达定理

定理一（正向路径可靠性）　设冻结任务规格 Ξ\_R，且：（一）X\_0 在申报的工作域内；（二）存在有限历史 γ，对一切 k \< H 有 u\_k ∈ U^adm 且 X\_{k+1} ∈ F\_R(X\_k, u\_k)；（三）Legal\_R(γ) = 1；（四）存在 w ⪯ γ 使 CertHit\_G(w) = 1。则

（甲）形式层可达成立：Reach\_Ξ^M(X\_0, G) = 1；

（乙）在目标类型所对应的正向回读条件成立时（第十一节条件表），对象层可达成立：R\_Ξ(X\_0, G) = 1。

证明。（甲）由（二）（三），γ 是从 X\_0 出发的有限合法历史；由（四），γ 上有一份形式命中证书；按第四节的定义，形式层可达成立。（乙）CertHit\_G(w) = 1 中的形式读数，经上游正向回读得到 N\_I、N\_IAct、N\_IGS(σ) 或 N\_IDyn^γ 在 w 上成立，再由各自的必然式的充分方向得到 Intent、IntentAct、IntentGateSwitch\_F(σ) 或 IntentDyn\_F^γ(K\_I) 在 w 上成立；入口资格的形式读数同样经《意向数理式》与《意向必然式》回读。于是 ActualTarget\_G(w) 在 γ 上成立，R\_Ξ(X\_0, G) = 1。该结论随所用回读条件条件化，不因（甲）无条件而无条件。□

定理二（封闭域负向充分性）　设冻结任务规格 Ξ\_R 与状态集 D，且：

（一）X\_0 ∈ D，X\_0 在申报的工作域内；D 是所用后继关系之下的状态集；

（二）封闭：对一切 X ∈ D 与 u ∈ U^adm，F\_R(X, u) ⊆ D；

（三）必要条件：按目标类型给出一项必要条件，它覆盖目标的每一种合法命中方式，包括零步方式。  
　　状态目标：给出状态谓词 Nec\_G^st，使 ActualTarget\_G 在某一评价点成立时，该点的状态满足 Nec\_G^st；  
　　事件、序列与段目标：给出一步谓词 Nec\_G^step，使 ActualTarget\_G(w) 成立时，w 在 2.3 的时间窗口内所用的历史中必有一步满足 Nec\_G^step；  
　　必要条件不成立的负向回读是直接表示或已经 Established，并且这一负向回读所需的覆盖条件在该历史的记录上成立；

（四）不变量：状态目标，D 中没有任何状态满足 Nec\_G^st（X\_0 包括在内）；事件、序列与段目标，从 D 中任一状态出发、经任一许可输入的一步，都不满足 Nec\_G^step。

则 R\_Ξ(X\_0, G) = 0。

证明。先证一切从 X\_0 出发的有限合法历史都在 D 中：长度为 0 的历史只有 X\_0 ∈ D；若长度为 k 的合法历史全在 D 中，由（二），其任一合法延长的下一状态仍在 D 中。

状态目标：一切合法历史上的一切评价点，包括零步历史的初态登记点，其状态都在 D 中；由（四），没有一点满足 Nec\_G^st；由（三），没有一点使 ActualTarget\_G 成立。

事件、序列与段目标：这类见证至少要有一次事件，零步历史不含事件，所以没有零步命中；长度至少为 1 的合法历史，每一步都从 D 中的状态出发、经许可输入，由（四）都不满足 Nec\_G^step；由 2.3，见证所用的事件都在初态登记点之后的这段历史中，所以由（三），其中没有任何见证使 ActualTarget\_G 成立。

两种情形都不存在命中的历史，R\_Ξ(X\_0, G) = 0。□

推论一（尾段形式）　设 G 是由相邻事件对组成的序列目标（如 2.3 的切换目标），h 是从 X\_0 出发、末态为 X\_L 的合法历史前缀，状态集 D 含 X\_L 且对 U^adm 封闭（定理二（二））；一步谓词 Nec\_G^step 系于后态事件：ActualTarget\_G(w\_a, w\_b) 成立时，产生后态事件 w\_b 的那一步满足 Nec\_G^step；从 D 中任一状态出发、经任一许可输入的一步，都不满足 Nec\_G^step（定理二（四））；并且对 h 的每一合法延长，由 h 的最后一个事件与 X\_L 之后的第一个事件组成的那一对（跨越 X\_L 的一对）都不构成命中。则 h 的任一合法延长，在 X\_L 之后都没有命中。

证明。由封闭性，X\_L 之后的一切状态都在 D 中。在 X\_L 之后完成的见证是一对相邻事件：若两个事件都在 X\_L 之后，产生后态事件的那一步从 D 中的状态出发，不满足 Nec\_G^step，而命中要求这一步满足它，所以不构成命中；否则它就是跨越 X\_L 的那一对，由前提不构成命中。□

推论一只说 X\_L 以后的事，不说包含 X\_L 的整条历史从未命中，也不改变初态处的可达判词。

定理二的结论是对象层的不可达，不经过监视器；若改用监视器给出负判，须另证无漏报（4.2）与后继覆盖完整，二者缺一，监视器没有命中只能记 ⊥。

定理三（许可集单调与受限域不外推）　设 Ξ\_R 与 Ξ\_R′ 只在许可集上不同，U^adm ⊆ U^adm′。则 R\_Ξ(X\_0, G) = 1 ⇒ R\_Ξ′(X\_0, G) = 1；而 R\_Ξ(X\_0, G) = 0 不推出 R\_Ξ′(X\_0, G) = 0（后一句的实例见证在形式层无条件，在对象层按 11.2 的回读条件，见证明）。

证明。正向：Ξ\_R 中的合法历史每一步的输入都在 U^adm′ 中，后继映射不变，历史合法性的各项只依赖历史本身，所以它也是 Ξ\_R′ 中的合法历史，见证不变。反向不成立：第八节给出 X\_0^z 上 Reach^M = 0 且 Det\_R = 0（U\_neg），而 Reach^M = 1（U\_neg⁺）的实例；定理二的封闭条件（二）对新增的 GenGate 不成立。这一反例在形式层无条件成立（两侧都是形式读数）；在对象层，R\_Ξ = 0 一侧由定理二 Established，R\_Ξ′ = 1 一侧按 11.2 的回读条件。□

定理三也适用于工作域：在受限工作域上证得的不可达，至多推出该受限域内不可达；除非另有等价覆盖的证明，不能推出更大工作域内不可达。

定理四（只读监视器的保守扩展）　设监视器只读统一运行证书的记录与事件记录，不调用任何合法操作，也不写任何状态量。则在同一初态、同一许可输入序列与同一随机实现下，带监视器与不带监视器的两条历史，其全状态摘要逐步相同。

证明。统一运行证书是被动的，不更新场或概率层的状态（《意向运行基底构造式》第三节第 3 条）；读出层不改变运行层与概率层的任何后续状态（同篇第三节第 1 条 U8）；读出器不进入场的因果更新（该篇定理一（6），V46、V47）。监视器只是这些读出器与记录的组合，不调用合法操作，所以它不改变任何一步的状态与随机源；两条历史的输入与随机实现相同，于是逐步相同。附录 A 的差分运行核对了 40 步之后两侧的全状态摘要相同、逐步的选维相同。□

保守性只保证监视器没有反向改写原系统，不保证它的识别正确：一个漏读事件、或把不同历史的记录拼在一起的监视器，同样是保守的，却会漏报或误报（第十节）。

定理五（有限秩可达）　分两种版本。

（甲）状态版，只用于状态目标，即 ActualTarget 只依赖当前状态的目标（资格目标）。设申报的状态域 D 含于工作域，存在函数 ρ: D → ℕ，满足：（一）ρ(X) = 0 时 X 处 ActualTarget\_G 成立；（二）对一切 X ∈ D 且 ρ(X) \> 0，存在 u ∈ U^adm 与 X′ ∈ F\_R(X, u)，使 X′ ∈ D、ρ(X′) \< ρ(X)，且这一步不破坏 Legal\_R。则对一切 X ∈ D 有 R\_Ξ(X, G) = 1，并且存在长度不超过 ρ(X) 的命中历史。

（乙）前缀版，用于历史事件目标（作用、切换与动力目标）。这类目标的见证要用到事件记录与先前的事件，同一状态可以由不同的历史到达，只在状态上定秩不足以保证命中。所以秩定义在合法历史前缀上：设 𝒟 是一族从 X\_0 出发的有限合法历史前缀，对 𝒟 中的前缀 h（其末态记作 last(h)），存在函数 ρ: 𝒟 → ℕ，满足：（一）ρ(h) = 0 时，存在 u ∈ U^adm 与 X′ ∈ F\_R(last(h), u)，使延长的前缀 h·(u, X′) 合法，并在其上有使 ActualTarget\_G 成立的见证；（二）ρ(h) \> 0 时，存在 u 与 X′ ∈ F\_R(last(h), u)，使 h·(u, X′) ∈ 𝒟、合法且 ρ(h·(u, X′)) \< ρ(h)。则对一切 h ∈ 𝒟，存在 h 的合法延长命中目标，延长的步数不超过 ρ(h) + 1；特别地，若空前缀 (X\_0) ∈ 𝒟，则 R\_Ξ(X\_0, G) = 1。见证所用的一切历史材料都在所给的前缀与其延长之内，不默许别的历史提供前件。

前缀版也可以写在监视扩展状态 (X, m) 上：m 是只读监视器对已发生历史的记录（例如前一事件的门承担与入口资格）。由定理四，加入 m 不改变原系统的后继；只要 m 记下了目标见证所需的全部历史材料，(X, m) 上的秩即等价于前缀上的秩。

证明。（甲）自 X 起反复按（二）取后继，每次仍在 D 内，ρ 在自然数上严格下降，至多 ρ(X) 步到达 ρ = 0 的状态，由（一）它已命中。（乙）同理，在前缀上反复延长，至多 ρ(h) 步到达 ρ = 0 的前缀，再由（一）延长一步得到命中；每一步都用许可输入、落在合法后继之内且保持合法，所得前缀是合法历史，见证属于它。□

若把（一）中的 ActualTarget\_G 换成 CertHit\_G = 1，定理五的结论相应为 Reach\_Ξ^M = 1，对象层随定理一（乙）的回读条件。

定理五的量词是“每一状态（或每一前缀）存在一个下降后继”，推出的只是存在一条路径，不推出一切合法历史都到达，也不推出任何概率结论。ρ 只是证明工具，不是意向的新本体，不进入任何回读。本篇没有为参考实例构造 ρ。

引理一（正概率与存在）　设：（一）输入策略 π 事前固定，它是从合法历史前缀到许可输入的映射（许可集只含一个输入时 π 唯一）；（二）每一前缀 h 在 π(h) 下的后继有限；（三）每一个后继的概率为正，且在每一个有后继的前缀上，后继概率之和为 1；（四）终止前缀是 π(h) 在 last(h) 上没有后继的前缀，极大历史是在终止前缀处结束、或在首次命中处截断的历史；（五）极大历史的长度有统一上界；（六）“命中”指形式命中证书 CertHit\_G = 1，由监视器按第四节的定义求取，且监视器对这一形式命中的识别正确（不漏读事件、不跨历史拼接）。则从 X\_0 出发命中 G 的概率 P\_π(hit) 是命中历史各步后继概率之积的和，并且：P\_π(hit) \> 0 当且仅当在策略 π 下存在命中的合法历史；P\_π(hit) = 1 当且仅当在策略 π 下每一条极大历史都命中。

证明。由（二）（五），在策略 π 下的全部极大历史构成一棵有限树；由（三），每一条极大历史的概率是各步后继概率之积，都为正，且全部极大历史的概率之和为 1（对树的深度归纳：每一内部结点的子结点概率之和为 1）。命中历史在首次命中处截断，是这棵树的一部分叶。所以 P\_π(hit) \> 0 当且仅当有命中的叶；P\_π(hit) = 1 当且仅当不命中的叶概率和为 0，又每一片叶的概率为正，故当且仅当没有不命中的叶。□

引理一的结论在形式层：概率为一不解释为一般沉积场中的必然到达，概率为正也只经第十一节的回读条件才成为对象层的可达。引理一是一般命题。它对第七节参考核的适用，须逐条核验其前提，由第七节 7.2 给出；第七节的 P(命中) 即策略 π ≡ OrgEvent 下的 P\_π(hit)；它的概率以均匀抽样的理想化为前提，是对选维核的计算，不是对自然系统的统计估计。

引理二（证书合法性的保持）　设长度至少为 1 的历史 γ 从初态登记点开始，随机实现在登记点以前选定，此后的每一步都是 U^adm 中的一个输入、经统一运行证书的合法操作接口执行并已完成，其间没有任何别的写入；U^adm 中的输入都不写职责登记、对应关系、调谐候选登记、载体候选登记与各协议对象。则 Legal\_R(γ) = 1。

证明。逐项对照《意向运行基底构造式》第三节第 3 条对 L1 至 L6 的读出规则。L1：终点在起点之后；起点的实际状态就是登记点那一条记录之后的状态；各条记录取自同一对象，运行与分支身份不变；运行计数与沉积计数只由脉冲与衰减增加，不减少。L2：每一步都经合法操作接口执行，接口在操作前后各记一次全状态摘要；两步之间没有别的写入（随机实现已在登记点以前选定，此后不再改写），所以相邻记录首尾相接，段末状态与最后一条记录相接；每一条记录的操作都在合法操作集内，两份权威日志只由这些操作追加，审计通过。L3：职责身份快照由职责登记、对应关系与候选登记组成，U^adm 中的输入都不写它们，所以各点相同。L5：段内的承重证据就是这些操作自身产生的事件，同运行、同分支、同锚、同协议，带证据键，并由同一段证书登记。L6：协议快照由各协议对象及其历史组成，U^adm 中的输入都不写它们，冻结状态不变。□

长度为 0 的历史按 3.5 的约定合法。引理二只说历史的记录合法；操作合法（3.5 的第一部分）另由 U^adm 与后继关系保证。

形式层保证到达（4.3）是对一切输入策略说的；许可集只含一个输入时，它与引理一中“策略 π 下每一条极大历史都命中”一致。

## 第六节　显式路径

以下各实例都在第二节申报的初态与第三节冻结的许可集上取得，每一步只用许可输入，全部经统一运行证书执行。数值见附录 A。

下文“参考判定器输出 1”中的参考判定器，是《意向运行基底构造式》的判定矩阵，它不携 H\_LawRead，读数为 1 即输出 1，所以这个 1 只等于形式读数为 1。各实例的可达结论都是形式层 Reach\_Ξ^M = 1；回读所需的 H\_LawRead 尚未关闭，按 4.4，Det\_R^𝒯 = ⊥（LawReadOpen）。

### 6.1 作用目标

### 6.2 切换目标

## 第七节　有限支撑上的精确核分析

### 7.1 分析对象

初态 X\_0，许可集 U\_ev，目标 G\_IGS^{→\[G\_A\]}，后继关系 F\_R^ref。每一步只有一个许可输入，后继至多两个（选 A 或选 X），概率为当时的 Rel。逐一取出每一个后继，得到从 X\_0 出发的全部后继历史，直到下列两种情形之一：命中；或者只剩一个维在 V 中（锁定）。树上的每一步都是一次已完成的 OrgEvent，不含任何别的写入。在选维核的均匀抽样理想化之下（2.2），树上的每一条历史，都对应一条“随机实现在初态登记点以前选定（依次给出使该选维串成立的抽样值）、此后只用 OrgEvent、全部经统一运行证书执行”的历史；统一运行证书是被动的，这条历史的状态与树上逐一取出的后继相同。U\_ev 中的 OrgEvent 不写职责登记、对应关系、候选登记与协议对象，所以由引理二，树上的全部历史都满足 Legal\_R = 1：300 条命中历史都是合法的命中历史，13 条锁定历史到数值终点以前的每一个完成步也都合法。

锁定以后，Rel 只在一个维上为正，后继唯一。脚本沿这条唯一的后继链逐结点核验，直到数值终点：每一结点 Rel 只在该维上为 1，缺失的维始终没有重新进入 V。这一核验是对唯一后继链的穷尽，不是抽样。链上没有切换进入 \[G\_A\]，理由见 8.3：链上 V 只含一维，由选维规则（intent\_on\_fldb\_rnd\_v14.py 第 472 至 478 行）每一事件都选该维，路线与门由此确定。

### 7.2 引理一前提的逐条核验

（一）策略：U\_ev 只含 OrgEvent，策略唯一，没有其他许可输入可以在 OrgEvent 失败时另产生后继。

（二）（三）有限分支、正概率与归一：全部 312 个内部结点上 V 都恰为 {A, X}，Rel(A) 与 Rel(X) 都为正（最小为 5.2 × 10^-9），两者之和与 1 的偏差不超过 2.3 × 10^-16，内部结点处资格形式读数都为 1；叶数 313 恰为内部结点数加一，即每一内部结点恰有两个子结点，没有漏取的后继。

（四）终止：命中叶在首次命中处截断。锁定状态在引理一的意义上还不是终止前缀，它的历史沿唯一后继链延长：链上每一结点 V 只含一个维，Rel 在该维上为 1，后继唯一、概率为 1（13 条链共 769 个结点逐一核验）；链在 S\_ref 中终止于数值终点（按 C\_num 无后继）。所以引理一所说的树，是 313 片叶各自沿锁定链延长后的树，叶数与各叶概率不变。

（五）长度上界：命中历史不超过 40 步；锁定链在锁定后 55 至 72 步终止。

（六）监视器：命中由切换监视器按 4.2 求取，它读取每一组织事件与紧邻前一组织事件的开始处资格与 IGS-M1 至 IGS-M10，前态事件都取自同一棵树的同一条历史。

以上核验由附录 B 脚本的 tree 命令逐结点完成，结果载于附录 A，复现器重跑时一并核对。

## 第八节　负证书

### 8.1 不变量型负证书

初态 X\_0^z，许可集 U\_neg，目标 G\_IGS^{→\[G\_A\]}。

取 D = {X : gen\_gate(A) = 0，\[G\_A\] 的承担节点登记为 {gA}，载体接线与职责登记同 X\_0^z}，X 取遍所用语义的全部状态，不以 W\_ref 为限。

封闭（定理二（二））：生成闸的值只由 GenGate 操作写入（probability\_on\_fldb\_rnd.py 第 45 行），GenGate 不在 U\_neg 中；职责登记与载体接线只由登记改变与 CarrierLink 写入，都不在 U\_neg 中。所以 U\_neg 中的每一输入的每一后继仍在 D 中。

必要条件（定理二（三），序列目标）：任何进入 \[G\_A\] 的意向欲门切换，其后态事件都须实际经过 \[G\_A\] 的承担节点的过门段（S2 中的 A3，与 S4 的新门取得）。在参考规格中 \[G\_A\] 的承担节点只有 gA，进入 gA 的边只有 c → gA，所以 Nec\_G^step 是“这一步的实际路线经过 c → gA”。实际路线记入场日志与事件记录，A3 一层的负向回读在《意向作用数理式》与《意向欲门切换数理式》中都是 Established；它所需的方向实现覆盖与过门段覆盖，由统一运行证书的闭合链（L2 = 1）与完整的事件路线记录给出。

不变量（定理二（四），序列目标的一步谓词）：在 D 中，A 的生成权重为其各现行载体的 exp(κ/T) 之最大值乘以 max(0, gen\_gate(A))，等于 0（probability\_on\_fldb\_rnd\_v2.py 第 69 行），Rel(A) = 0；选维只在 Rel 为正的维中进行（intent\_on\_fldb\_rnd\_v14.py 第 472 至 478 行），所以 OrgEvent 只能选 X，路线为 sI → a1 → m2 → x → gX → tX；SourceOnlyEvent 的路线为 sI → a1；IdleStep 不产生路线。三者都不经过 c → gA。门承担状态只在 OrgGateEvent、ExternalGateEvent 与组织或外部路线事件中写入（intent\_on\_fldb\_rnd\_v14.py 第 435、458、491 行），其中只有 OrgEvent 在 U\_neg 内，而它只能选 X；运行层的脉冲操作 Pulse 也不在 U\_neg 内。所以不存在取得 \[G\_A\] 承担的替代路线。

切换目标是序列目标，至少要有两次事件，没有零步命中；初态登记点以前没有事件（2.3）。由定理二，R\_Ξ(X\_0^z, G\_IGS^{→\[G\_A\]}) = 0，Det\_R = 0。形式层同样不可达：由同一不变量，U\_neg 下任一合法历史的事件记录中都没有经过 c → gA 的路线，后态事件对 \[G\_A\] 的 A3^M 从不为 1，所以没有 CertHit，Reach\_Ξ^M(X\_0^z, G\_IGS^{→\[G\_A\]}) = 0；这一步直接读事件记录，不经回读。这一证明对 C\_num 不敏感：封闭性与不变量只涉及完成操作的写入范围、选维规则与生成闸乘子（gen\_gate = 0 ⇒ 该维权重为 0）；在 S\_ref 中，中途失败的操作没有后继，空集含于 D，在不发生失败的语义扩展中，完成的操作同样落在 D 内。所以它对 F\_R^ref 成立，也对任何保持选维规则、路线、写入范围与生成闸乘子的语义扩展成立；它不推广为对沉积场本身的断言。

附录 A 另在 50 个实现上各以 60 步随机选取 U\_neg 中的输入作演示：共 969 个组织事件，没有一个选中 A，没有一次命中，生成闸、Rel(A) 与门承担状态的不变量没有一次被破坏，每一条历史都合法。这一演示不承担证明，证明是上面的不变量。

同一初态与许可集上，作用目标在形式层可达（对象层按 11.2 的条件）：第一个组织事件选中 X，即构成完整作用。初态资格形式读数为 1、作用目标可达，而切换进入 \[G\_A\] 不可达：可达的否定不是资格的否定，四类目标也互不填补。

### 8.2 扩大许可集

同一初态 X\_0^z，许可集改为 U\_neg⁺。流号 1 的实现：第 1 步 GenGate(A, 1.0)，其后选维依次为 A、X、X、A，第 5 步命中切换进入 \[G\_A\]，切换读数为 1、参考判定器输出 1，这一段上 L1 至 L6 都为 1。所以形式层 Reach\_Ξ⁺^M(X\_0^z, G\_IGS^{→\[G\_A\]}) = 1；对象层 R\_Ξ⁺ = 1 按 11.2 中 G\_IGS 的回读条件，Conditional；Det\_R^{IGS} = ⊥（LawReadOpen）。

这是定理三的实例：U\_neg 上的负证书不能外推到 U\_neg⁺。若在 U\_neg⁺ 上仍以 8.1 的 D 签不可达，定理二的封闭条件对 GenGate 不成立：这正是“合法后继漏枚举而签不可达”的错误。

### 8.3 穷尽型尾段证书

本小节不是对某一申报初态的负证书：X\_L 不是第二节申报的初态，这里不签任何 R\_Ξ = 0 或 Det\_R = 0，只给出经过 X\_L 的历史在其后的结论。

第七节的每一个锁定状态 X\_L，在许可集 U\_ev 与后继关系 F\_R^ref 之下，后继唯一，后继链有限并按 C\_num 终止于数值终点。链上每一事件的路线与门由选维规则确定（7.1），不必逐步取证。这里的时间窗口仍从 X\_0 的登记点开始：所论的是从 X\_0 出发、经过 X\_L 的历史，在 X\_L 之后有没有命中，包括跨越 X\_L 的相邻事件对。取 D 为这条链上的全部状态，它对 U\_ev 封闭；切换目标是序列目标，没有零步命中；链上每一步都不满足相应的一步谓词（锁定于 X 时，取 Nec\_G^step 为“路线经过 c → gA”，链上路线都不经过；锁定于 A 时，取“后态事件的门不同于前态事件的门”，在参考规格中每一职责类只有一个承担节点，这一谓词不成立即 S3 不成立；链上相邻两事件的门都是 gA，S3 一层的负向回读在《意向欲门切换数理式》中是 Established）。两个谓词都系于后态事件：“路线经过 c → gA”说的是后态事件的路线，S3 说的是后态事件与其前态的门是否不同。锁定以后后继唯一，跨越 X\_L 的一对也唯一；链上第一个事件的前态，是锁定以前历史中的最后一个事件，这一对也不构成命中：锁定于 X 时，X\_L 之后的第一个事件经过 gX，不进入 \[G\_A\]，无论前态的门是什么；锁定于 A 时，前态的门也是 gA：第七节的枚举中，每一个 X 事件之后紧接的 A 事件都由切换监视器判为命中，历史在那里截断（附录 A 的 tree 命令：这样的相邻对共 300 个，全部命中），所以不命中的历史都形如 A^a X^b；枚举中锁定于 A 的叶只有一片，选维串为 A^12，锁定于 X 的 12 片都以 X 结尾，每片锁定叶的最后一个事件的门都与锁定维的门相同（附录 A 的 lock\_leaves\_detail）。所以锁定于 A 时，前态与后态的门都是 gA。由推论一，在 F\_R^ref 之下，经过 X\_L 的历史在 X\_L 之后没有命中。这一结论依赖 C\_num，只对参考程序的可执行语义 S\_ref 成立；数值终点以外、以及沉积场本身，不作主张。

## 第十节　分离命题与反例

以下反例都在参考规格中实际取得（附录 A），它们各自击穿一种常见的误判。

反例一（跨历史拼接）：前态事件取自一条运行中进入 \[G\_X\] 的组织事件，后态事件取自另一条运行中进入 \[G\_A\] 的组织事件。前态事件序号小于后态，而两者运行身份不同，IGS-M8 与 IGS-M10 不成立，切换读数为 ⊥，监视器不命中。找到的两段材料各自真实，却不构成同一历史上的命中。

反例二（假目标）：前态是进入 \[G\_X\] 的组织事件，后态是外部换门事件，把门承担改为 gA（外部换门不在本篇任何许可集内，这里只用来构造反例）。以门占用作目标的监视器命中；而意向欲门切换的读数为 ⊥（IGS-M4），切换判词不为 1。这里的切换读数先核 IGS-M1 至 IGS-M10，条件不全即为 ⊥；《意向运行基底构造式》V20 对外部换门直接取 S1 至 S4 的读数，S2 为 0，记切换为 0。两处都不为 1。门占用不是意向欲门切换：CertHit 必须对目标本身无误报。

反例三（合法后继漏枚举）：8.2。在 U\_neg⁺ 上沿用 U\_neg 的封闭集 D 签不可达，漏掉了 GenGate 的后继。

反例四（监视器漏报）：流号 6 的实现选维为 X、X、X、X、A、X。只比较第 1 个事件之后与第 6 个事件之后门承担的监视器报告“没有变化”；逐事件的监视器读到两次切换，其中一次进入 \[G\_A\]。端态比较的监视器是保守的，却漏报了段内的切换。这也是上游“不以单元的端态代替跨时事实”的实例。

反例五（有限步内未命中而宣称不可达）：流号 0 在 83 步内没有命中；若据此宣称从 X\_0 不可达，就错了：P(命中) = 0.497，流号 1 在第 4 步命中，精确树中命中历史长达 40 步。没有完备的负证书，有限步内的未命中只能记 ⊥。流号 0 后来经过锁定状态，在 S\_ref 中经过它的历史在其后不再命中（8.3），但这是对锁定以后的历史的结论，不是对 X\_0 的结论。

反例六（零率误判）：X\_0^z 上 Rel(A) = 0，在 U\_neg 上切换进入 \[G\_A\] 不可达，在 U\_neg⁺ 上可达。零率是状态的性质，不是可达集的性质；“零率方向永不可达”只在不含恢复其生成的许可集上，并且须有封闭域证明，才成立。

反例七（工作域混淆）：6.3 中的第一个事件，作用形式读数为 1，而其开始处资格形式读数为 0、资格判词为 ⊥。把它计为作用目标的命中，就是混淆了目标读数与目标的入口。

反例八（结构相容而无路径）：X\_0^z 上 GateCorrespondence = 1，A ↔ \[G\_A\] 的对应与通达都成立，进入 \[G\_A\] 的切换在结构上相容；而在 U\_neg 上它不可达。结构相容不等于存在实际到达的路径。

反例九（预装结构冒充内生生成）：6.3 的资格目标自资格形式读数为 0 的初态可达，而这是已安置结构上的重新成律。把它写成“意向由沉积场自行生成”，越过了本篇的构造起点。

由此得到下列分离：

&nbsp;&nbsp;&nbsp;&nbsp;可达 ≠ 资格、作用或动力本身；可达 ≠ 稳定；可达 ≠ 可控；可达 ≠ 保证到达；  
&nbsp;&nbsp;&nbsp;&nbsp;一次运行未命中 ≠ 不可达；零率 ≠ 永不可达；资格形式读数为 0 的初态 ≠ 必然不可达；  
&nbsp;&nbsp;&nbsp;&nbsp;结构相容 ≠ 可达；形式命中 ≠ 对象层成立（须回读条件）；监视器保守 ≠ 监视器正确。

## 第十二节　击穿

按可达式的规范，击穿有两类。

其一，证明一切许可路径都到达不了：对第二节申报的初态与第三节冻结的许可集，证明某一被签为形式层可达（Reach\_Ξ^M = 1）的目标，在一切合法历史与一切有限步数上都没有见证。

其二，展示所给路径包含不许可的操作：指出第六节或第八节 8.2 的某一步使用了 3.4 节的禁用操作，或使用了 U^adm 以外的输入，或某一后继不属于 F\_R^ref(X\_k, u\_k)，或该段的 Legal\_R 不为 1。

另有针对以上陈述的击穿：展示第六至第八节的路径与计算在所申报的模型、初态、许可集与流号下不能复现；展示 8.1 的不变量在 U\_neg 下被某一后继破坏，或存在不经过 c → gA 而进入 \[G\_A\] 的承担节点；展示第七节的后继枚举遗漏了某一正概率后继，或锁定链上缺失的维重新进入 V；展示某一对象层结论越过了 11.2 的回读条件；对定理五，展示 ρ 不取自然数、某一 ρ \> 0 的状态（或前缀）没有下降后继、下降后继跑出 D（或 𝒟），或 ρ = 0 而不命中；对引理二，展示某一满足其前提的历史 Legal\_R 不为 1，或 U\_ev、U\_neg、U\_neg⁺ 中的某一输入写了职责登记、候选登记或协议对象。

不构成击穿：一般统一步数界未立；实例的秩函数未构造；某些实现在数值终点以前没有命中（属于 ⊥ 或已由第七节给出概率）；数值终点以外的行为；结构相容而不可达（已作为反例写明）。

## 第十三节　接口

上承

《意向运行基底构造式》：运行规格、统一运行证书、合法操作集、资格、作用、切换与动力的读出接口；本篇不改动该篇的任何代码与判据。  
《意向一般式》《意向数理式》《意向必然式》：资格的结构、形式读数、正向回读与充分方向。  
《意向作用一般式》《意向作用数理式》《意向作用必然式》，《意向欲门切换一般式》《意向欲门切换数理式》《意向欲门切换必然式》，《意向动力一般式》《意向动力数理式》《意向动力必然式》：各目标的定义、可解性条件、正负回读与其条件。  
《意向判定式》：入口分流与三值判词的纪律；本篇的可达判词 Det\_R 沿用这一纪律，不改动该篇的四个判词。  
《意向极限式》：零率端点、资格硬界与 L4 的适用边界。

下交

《意向源式》：本篇的资格可达只是已安置结构上的重新成律，交付“重新成律的路径与其可达条件”作为实例；结构首次形成的来源条件不在此承担。  
《意向稳定式》：交付锁定现象：同一维越用越深，另一维离开 V，资格形式读数随之降为 0（对象层退出以 H2 ∧ H3^red 为条件，并随概率的失败路径携 H^-\_M 或 H\_ρRep^-）；锁定状态是可达的，经过锁定状态的历史在其后不再发生进入 \[G\_A\] 的切换（在参考程序的可执行语义中）。保持、失效与恢复的研究归该篇。  
《意向生成基底构造式》（第二十一篇）：交付可达的正负证书制度与历史合法性 Legal\_R；从基础沉积场到资格首次成立的可达，归该篇构造。

不涉及：外部输出模型与分离候选内部结构的干预（《意向反演式》所需），不在本篇承担。
