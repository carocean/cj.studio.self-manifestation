自显论 · 理篇 · 意向组式第十八 v1.0

# 意向源式

一份冻结的候选，在申报的历史窗中首次取得意向资格。这一次首次成立，由哪一段实际历史承担形成？若有多段历史都能合法承担，最多能确定到什么程度？承担形成的历史，又在多大程度上是场自身的形成，而不是边界上已经给定的东西？

结论是：意向资格的来源，不是终点上四项结构同时成立，不是最后闭合的那一项，不是时间上在先的事件，也不是任一反事实必要条件；它是一段实际历史，对这份冻结候选的首次资格闭合承担了真实的形成，并且同时通过实际生成链与合法反事实最小充分性的认证。来源可以不唯一；没有找到来源，不等于没有来源。来源经认证以后还要另问出处：四项的形成是否在场内经沉积取得，边界上是否已经预置了意向特异的职责指定，形成所用的输入是否已经点名了承担者。只有三问都过，才可以在该边界之内说“意向资格由场内形成”；初态没有意向资格，不等于初态没有预装意向。

## 第一节　对象申报

### 1.1 式种与唯一任务

源式，附式，独立成篇。按《法篇》第四编第四章源式规范：证明一个已经成立的结构由什么实际过程生成，而不是由什么给定。

这里只研究意向资格首次成立的来源，并区分来源的出处与边界。初态已有资格时追溯当前组织怎样形成，不另立一类问题：评价点集的第一个点不晚于候选的登记点（1.4），这一追溯就是在更长的窗上问同一个首次成立；更早的历史不可得、第一个点上已经为 1 时，按 1.5 Genesis\_I 为 ⊥，来源随之为 ⊥。资格退出以后的重新形成，按《意向极限式》须对新的申报段重新冻结与申报；这一重新形成的来源问题由《意向极限式》交到这里：对重新申报的候选，在它自己的评价点集上问首次成立与来源（1.5）。不研究：当前是否有意向资格；意向此刻怎样作用、怎样切换、怎样有动力；资格以后的保持、失效与复归；从给定初态能否到达资格；怎样构造在基础沉积场中首次生成意向的可执行系统；重新形成的组织与原组织是否同一；跨宿主迁移或复制的身份连续性。

五种闭合在这里分开：

&nbsp;&nbsp;&nbsp;&nbsp;资格闭合　　　四项结构在评价点上成立　　　　　　　　　可签意向资格（《意向一般式》《意向必然式》）  
&nbsp;&nbsp;&nbsp;&nbsp;运行闭合　　　已有结构在场中实际运作　　　　　　　　　可签已有意向的运行（《意向运行基底构造式》）  
&nbsp;&nbsp;&nbsp;&nbsp;路径闭合　　　从给定初态有合法路径到达　　　　　　　　可签指定任务下的可达（《意向可达式》）  
&nbsp;&nbsp;&nbsp;&nbsp;来源闭合　　　首次成立由认证的实际历史承担　　　　　　可签给定协议下的来源（本篇第四节）  
&nbsp;&nbsp;&nbsp;&nbsp;场内形成闭合　来源经认证，边界无意向特异预装，四项都在场内形成且不由输入点名　可签给定边界内的场内形成（本篇第六节）

前一种闭合不推出后一种。

### 1.2 上游冻结结构

&nbsp;&nbsp;&nbsp;&nbsp;N\_I := P\_I ∧ SD ∧ GC ∧ TI

SD、GC、TI 分别记 SourceDrive(𝒫\_I)、GateCorrespondence(𝒫\_I; 𝒢\_I)、TuneInterface(𝒢\_I)；P\_I := InIntentDomain(𝒫\_I) ∧ Probability(𝒫\_I; C\_I, 𝔯\_I)。四项落在同一意向组织与同一资格锚上。

《意向一般式》：Intent ⇒ N\_I，Status = Established。《意向必然式》：N\_I ⇒ Intent，Status = Established。所以对象层 Intent ⇔ N\_I，两个方向都不携 H。

形式层：《意向数理式》给出 IntentCoreCert^M 及各项的形式读数；形式读数为 1 回读对象层，按所用 Law-bearing 见证承继 H\_LawRead；形式读数为 0 回读对象层，按《意向判定式》，概率一侧的负读携 H2 ∧ H3^red 与相应失败路径的 H^-\_M 或 H\_ρRep^-，本组式新增原子的形式零不回读为结构零（IntentAtomRepOpen）。这些是上游的回读条件，不是这里新增的 H。

### 1.3 跨时候选与承担者指定

源式不能把某一单独时刻冻结为候选的身份。记跨时冻结声明：

&nbsp;&nbsp;&nbsp;&nbsp;χ̄\_I = (F, 𝒫\_I, C\_I, 𝔯\_I, V\_I, Anc\_I, Duty\_I, Rec\_I)

F 是场；𝒫\_I、C\_I、𝔯\_I、V\_I 是概率组织、续行位、率域与正式维，概率层的载体候选登记属于 𝒫\_I 的冻结声明；Anc\_I 是资格锚；Duty\_I 是职责的种类与身份：源动职责、欲门职责的身份集合、调谐职责的身份集合、意向域职责。Duty\_I 只给职责的身份，不点名承担者，也不给维与门职责的配对；Rec\_I 是申报记录：登记点与申报序号。评价点 t 的候选实例为 χ\_I(t) = (χ̄\_I, t)。

哪一条边承担源动、哪一维对应哪一个门职责（维与门职责的配对）、哪一个门节点承担门职责、哪一条门后边承担哪一门职责之后的调谐、哪一概率组织被申报为位于意向域，这些承担者指定记作 Des\_I。维与门职责的配对是 GC 的承担内容，只属于 Des\_I。意向域职责是身份，属于 Duty\_I；把某一概率组织申报为它的承担者，是指定，属于 Des\_I。Des\_I 属于系统状态，不属于候选声明：它或者在初态中已经给定，或者由窗内的历史事项取得。在窗内取得的指定是历史事项，和其他事项一样接受削减、重放与形成审查（3.6）。

在一次来源协议中，χ̄\_I 全部事前冻结。删除历史以后，不得增删 V\_I，不得换锚、换续行位、换率域，不得改职责的身份，不得重新申报另一份候选。

### 1.4 来源协议

&nbsp;&nbsp;&nbsp;&nbsp;Π\_I^src = (χ̄\_I, X\_0, H\_obs, Bg^Π, Ops^Π, Wd^Π, Dyn^Π, Judge\_I^Π, Judge\_N^Π, T\_Π, Gran^Π)

χ̄\_I：冻结的跨时候选声明。  
X\_0：来源窗的申报初态，即边界状态，包括其中已有的承担者指定。  
H\_obs：实际观察到的有序有限历史。  
Bg^Π：冻结背景，在窗内不变的条件。  
Ops^Π：允许的历史削减操作，事前冻结。  
Wd^Π：撤回操作，事前冻结，只用于判定形成性承重（3.6（四））；它不是削减操作，不进入 ⪯\_Π，由它得到的重放不进入削减域与来源候选域。  
Dyn^Π：合法的场动力与运行基底动力。  
Judge\_I^Π：意向资格的三值判词，Judge\_I^Π(t) ∈ {1, 0, ⊥}，对象层取《意向判定式》的 Det\_I，或在结构事实已经取得时取 Intent\_t 本身（1.7），形式层取 IntentCoreCert^M。  
Judge\_N^Π：资格核的分项读数，Judge\_N^Π(t) = (P\_I, SD, GC, TI)\_t。  
T\_Π：事前冻结的有限评价点集。候选的登记点是 χ̄\_I 首次冻结与申报的评价点；T\_Π 的第一个点就是 X\_0 所在的点，它不晚于登记点。“首次”只相对于这一点集定义，不得看见结果以后增删评价点，不得把第一个点移到登记点以后。  
Gran^Π：历史事项的冻结切分粒度。

X\_0 与 Bg^Π 合起来称为边界 B\_S。边界之内的东西不属于来源候选，只能另行审查（第六节）。

### 1.5 首次资格事件

&nbsp;&nbsp;&nbsp;&nbsp;Genesis\_I^Π(χ̄\_I, τ) ∈ {1, 0, ⊥}

1：τ 不是 T\_Π 的第一个点，Judge\_I^Π(τ) = 1，且对 T\_Π 中一切 t \< τ，Judge\_I^Π(t) = 0。  
0：Judge\_I^Π(τ) = 0；或存在 t \< τ 使 Judge\_I^Π(t) = 1。更早存在确定的 1，足以否定“首次”，即使其他更早的点为 ⊥。  
⊥：其余情形，例如 τ 点不可判；τ 点为 1 而此前有评价点为 ⊥，且没有更早的确定的 1；或 τ 是 T\_Π 的第一个点而已为 1（没有更早的 0 可比）。

T\_Π 的第一个点不晚于候选的登记点，所以对原候选而言，资格退出以后的再次成立，在更早的 1 已经确定取得时（形式层；或对象层以结构事实作判词、或所用见证的 H\_LawRead 已关闭）Genesis\_I = 0；对象层用 Det\_I 而更早的 1 为 ⊥（LawReadOpen）时，Genesis\_I = ⊥。按《意向极限式》“重新形成不是原段复入”（亦见《意向运行基底构造式》V52），原段越过资格边界以后，重新形成的段须重新冻结与申报为新的候选 χ̄\_I′：它的申报记录 Rec\_I′ 不同于 Rec\_I，登记点在原段退出以后、重新形成以前；对 χ̄\_I′，在它自己的评价点集上，重新形成可以是首次资格事件，它的来源按第四节认证。χ̄\_I′ 与 χ̄\_I 是否同一，这里不作结论（同《意向极限式》）。这样的重新形成发生在已经安置并指定过的结构上，按第六节它至多落入 Boundary，不是从基础沉积场中的首次生成。

### 1.6 首次事件的两层

Genesis\_I 由判词取得；以对象层的结构事实作判词时，见 1.7。对象层用 Det\_I：τ 点的 1 须所用见证的 H\_LawRead 已关闭，否则为 ⊥（LawReadOpen）；此前各点的 0 须按《意向判定式》的负读路径取得，概率一侧携 H2 ∧ H3^red 与 H^-\_M 或 H\_ρRep^-，本组式新增原子的形式零为 ⊥（IntentAtomRepOpen）。形式层用 IntentCoreCert^M，记 Genesis\_I^{Π,M}。两层分别登记，不混用；第七节的实例只在形式层签出 Genesis\_I^{Π,M} = 1，对象层 Genesis\_I = ⊥。

分流的原则：Genesis\_I 无定义或为 0 时记 OutDom；Genesis\_I 为 1 或 ⊥ 而来源判定域没有闭合时记 ⊥。所以候选未冻结、评价点集未冻结、τ 不在 T\_Π 中，来源判词记 OutDom，在证据判定以前分流；Genesis\_I(τ) = 0 时，τ 不是首次资格事件，对它问来源没有对象，同样记 OutDom；Genesis\_I(τ) = ⊥ 时，来源记 ⊥；Genesis\_I 为 1 或 ⊥，而粒度未冻结、削减域无限或削减关系不构成有限偏序时，来源判定域不闭合，来源记 ⊥。

### 1.7 首次成核

若以对象层的结构事实作判词（Judge\_I(t) = Intent\_t），τ 不是 T\_Π 的第一个点，T\_Π 中一切 t \< τ 有 N\_{I,t} = 0，且 N\_{I,τ} = 1，则 Genesis\_I^Π(χ̄\_I, τ) = 1，τ 是这份候选在点集上首次取得意向资格的评价点。

证明。由《意向必然式》，N\_{I,τ} = 1 ⇒ Intent\_τ = 1；由《意向一般式》的必要方向取逆否，N\_{I,t} = 0 ⇒ Intent\_t = 0。两个方向都不携 H，代入 1.5 的 1 分支即得。□

Status = Established。它只说首次成立的时点，不说这一次由什么形成；来源另由第四节认证。实例中四项的结构事实是由形式读数取得的，回读对象层须按 1.2 的条件，其中新增原子的形式零不回读，所以第七节的实例只能停在形式层。

## 第二节　默认来源的排除

以下是容易被当作来源、但不能作为来源的对象。各项都是定义层的不推出；来源由第四节的 IGenesisSource 认证，它的第二、三项以历史为自变量，终态、时间次序、相关与反事实必要性都不能单独满足它。

W-I1　终态资格倒推：Intent\_τ = 1 ⇏ 𝔖^Π\_{I,src} ≠ ∅。  
W-I2　终态资格核倒推：N\_{I,τ} = 1 ⇏ 来源已认证。资格证书不是来源证书（定理二）。  
W-I3　最后闭合项冒充全部来源：τ 处最后由 0 变为 1 的是 X ⇏ 来源只形成 X（定理三）。  
W-I4　单项形成冒充意向来源：某一项在窗内形成 ⇏ 意向资格的来源已认证。首次事件要求同一候选在 τ 处四项都成立（定理三、定理五）。  
W-I5　时间先后、同步、相关、预测：h 先于 τ ⇏ h 承担来源；Corr(h, Genesis\_I) ⇏ h 承担来源。  
W-I6　环境奖惩冒充来源（u41）：发生过奖惩 ⇏ 来源。奖惩须真实进入实际生成链，并在最小充分性中承重（5.4）。  
W-I7　触发冒充形成（u42）：默想、回顾、思考回路发动已成意向的一次活动，是该次活动的起始来源，不是资格的形成来源。资格已经确定为 1 的窗内，Genesis\_I = 0（第七节 7.7）。  
W-I8　破持冒充来源（u40）：发生过破持 ⇏ 意向资格形成。破持可以只产生律生态的另一种安排（5.4）。  
W-I9　背景使能：反事实必要 ⇏ 来源。不在 H\_obs 中的条件，删去以后系统不能成立资格，也不因此成为来源（第七节 7.8）。  
W-I10　非法删除：删去 h 以后不能合法重放（Replayable = 0）⇏ h 是必要来源。  
W-I11　外部安装冒充场内形成：ExternalInstall\_I = 1 ⇏ FieldBorn\_I = 1。外部安装可以是来源，但不因此是场内形成。  
W-I12　初态无资格冒充未预装：Intent(X\_0) = 0 ⇏ NoPreinstalledIntent(B\_S)（定理八）。  
W-I13　运行冒充来源：已安置结构在场中实际运行 ⇏ 这些结构在边界之后首次形成。  
W-I14　恢复冒充首次形成：对原候选，资格退出以后的再次成立不是首次（更早的 1 确定时 Genesis\_I = 0，否则为 ⊥，1.5）；重新形成须按重新申报的候选另问首次与来源，且在已安置结构上至多是 Boundary（1.5，第七节 7.7）。  
W-I15　可达冒充来源：R\_Ξ(X\_0, G\_I) = 1 ⇏ 来源已认证；来源已认证 ⇏ 另一冻结任务下可达（定理十）。  
W-I16　外部输入冒充外部完成：形成中存在外部输入 ⇏ 不是场内形成；合法的外部诱发、场内完成形成，不排除场内形成（6.2；一般结构上的形式层实例见第七节 7.5 的 P\_I）。  
W-I17　概率冒充意向：Probability = 1 ⇏ Intent；普通概率组织没有源动驱动、欲门对应与调谐接口，不是意向（第七节 7.9）。  
W-I18　下层结构冒充上层资格：重复沉积 ⇏ 律；多条律并存 ⇏ 概率；源动驱动的概率组织 ⇏ 意向（缺欲门对应或调谐接口）；方向连到门 ⇏ 完整的意向（缺门后使役调谐的接口）。依据见 5.5。

由此四条区分：

&nbsp;&nbsp;&nbsp;&nbsp;最后闭合 ≠ 来源，结构必要 ≠ 来源，终态资格 ≠ 来源，反事实必要 ≠ 来源

依据分别是定理三、定理四、定理二、3.6 的实际生成链要求。

## 第三节　发生过程刻画

### 3.1 历史表示

实际历史写作有序有限对象：

&nbsp;&nbsp;&nbsp;&nbsp;H\_obs = (e\_1, e\_2, …, e\_n)，n \< ∞

不得写成无序集合。每一发生事项至少保留时间次序、实际发生内容、所作用的对象与它的路线。属于场内形成过程的，另保留执行、痕迹、沉积、成形，以及与终点四项承担之间的连接；属于外部安装过程的，保留外部编辑事项、编辑对象与编辑前后的状态。不存在的字段不得为了格式完整而虚造。

### 3.2 削减域

协议相对的削减记作 H′ ⪯\_Π H：存在一列由 Ops^Π 允许的有限操作，把 H 削减为 H′。每项操作只能删除已有事项，或削弱已有事项的作用；不改变它的原时间位置；执行与结果可以审查。删除事项时，它所占的时间位置以同样时长的空位保留。

削减不得改 X\_0（包括其中的承担者指定）、χ̄\_I、Bg^Π、Dyn^Π、判词或资格核的定义，不得加入新事件，不得改变剩余事件的顺序，不得偷补终态，不得事后重切 Gran^Π。严格削减记作 H′ ≺\_Π H。要求 ⪯\_Π 在申报的削减域上构成冻结的有限偏序；不满足时来源判定域不闭合（1.6）。下文的最小性相对于这一偏序。

### 3.3 有限性与来源候选域

这里要求 \|H\_obs\| \< ∞，且削减域 ℛ\_Π(H\_obs) = { H′ \| H′ ⪯\_Π H\_obs } 有限。连续的削弱强度、无限细的粒度或无限下降链，未经冻结离散化的，ReductionDomainFinite 或 GranFrozen 不成立，SrcDetDom 不闭合，来源记 ⊥（4.4、4.5）。来源候选历史域：

&nbsp;&nbsp;&nbsp;&nbsp;𝓗^Π\_src := ℛ\_Π(H\_obs) ∖ { H\_∅ }

H\_obs 只取到 τ 为止，τ 以后的事项不进入来源候选。来源候选只能由实际历史经允许的削减取得；不得把实际历史中没有发生的替代过程或另一条可能历史当作本次首次成立的来源候选。H\_∅ 只作 4.3 的空历史控制。

### 3.4 合法重放

&nbsp;&nbsp;&nbsp;&nbsp;Replayable\_I^Π(H) ∈ {1, 0, ⊥}

1：存在遵守完整冻结协议的合法重放：同一 X\_0、同一 χ̄\_I、同一背景、同一合法动力、同一判词与评价协议；只对未保留的事项作允许的删除或削弱，然后让系统依法演化。  
0：只有通过换候选、改动 X\_0 或背景（包括边界上的承担者指定）、换动力、改判词、加未申报事件或偷补终态，才能完成所谓重放。  
⊥：当前无法确定重放是否合法。

&nbsp;&nbsp;&nbsp;&nbsp;Replayable = 0 ≠ 反事实失败，不能删 ≠ 删了不成

### 3.5 来源充分性

只在 Replayable\_I^Π(H) = 1 以后求：

&nbsp;&nbsp;&nbsp;&nbsp;Suff\_I^Π(H; χ̄\_I, τ) ∈ {1, 0, ⊥}

1：合法重放到 τ，N\_{I,τ}^{Replay(H)} = 1，即同一候选在 τ 处四项都成立；由《意向必然式》，Intent\_τ = 1。  
0：合法重放完成，τ 处明确 N\_{I,τ} = 0。  
⊥：合法重放成立，τ 处的读数不足以判 N\_I。

反事实重放中不要求资格恰在 τ 首次成立，它可以更早成立：这里研究的是来源，不是精确定时。形式层以 IntentCoreCert^M 取 Suff\_I^M；它的 1 回读对象层按 H\_LawRead，它的 0 回读对象层按 1.2 的负读条件。

### 3.6 实际意向生成链

来源不能只有反事实充分性，还须有实际的形成；形成的东西与终点资格所用的东西必须是同一个；并且这一形成本身必须承担这段历史的充分性，不能只是随同发生、又被终点读到的副产物。

保序子历史 H\_g ⊑\_ord H\_s：由 H\_s 中若干事项按原次序抽取。形成见证 g = (H\_g, s\_g)，s\_g 是这些事项所形成的一个结构，或几个结构的并（复合见证，见（四））。

H\_g 取 s\_g 在窗内最后一次由 0 变为 1 的那次转变的确切写入事项，即实际历史中到这次转变为止、路线经过 s\_g 承担边的那些事项，按事件逐一列出，不按原子扩大；一个结构的写入事项可以分属几个原子（例如两维的率关系同时依两维的载体），这时 H\_g 取它们的并。原子只用来判断见证是否落在某一候选之内，以及报告事件级承担。下文的“此前”指 H\_g 的第一个写入事项之前（参考实例中，窗内在此以前没有别的事项写入这些变量，所以取值与 X\_0 处相同）。

（一）状态变化的种类。s\_g 在窗内由 0 变为 1，可以是几种不同的事实，按它所依的状态变量分类，在形成判定中的地位各不相同：

结构生成：承担 s\_g 的沉积变量（承担边的沉积量与重复记录、绑定沉积；不含节点沉积与路径动力）在此前为空，由 H\_g 事项的痕迹建立，转变发生在 H\_g 的一个写入事项上，并且这一事项没有改动承担边的开关与拓扑，也没有改写承担者指定。节点沉积为几个结构共用，载体路径的路径动力有非空的初值，二者不参与这一判别。它可以承担当次的形成，也是结构的首次来源。  
阈值越过：承担 s\_g 的上述沉积变量此前已有、但不足以使 s\_g 成立，转变发生在 H\_g 的一个写入事项上，这一事项没有改动开关、拓扑与指定，它的痕迹使这些变量越过成立条件（例如成槽所需的重复记录重新落入窗口）。它可以承担当次的形成，即资格所依结构状态的取得；结构的更早来源在此前的历史中，须另行登记，不由这一次承担。  
重新启用：s\_g 的成立只因可用性、遮蔽或门槛一类开关被改动，沉积变量没有因 H\_g 而改变。它不承担形成，只能作为触发或恢复的证据。  
指定改变：s\_g 的成立只因承担者指定被改写。它不是场内形成；若改写是申报的外部编辑事项，可以是外部安装的形成连接，否则是未申报写入。  
读出改变：判词、读出定义或协议被改动。这是协议失格，不是任何形成。  
其他或混合：不属于以上各类的转变，例如转变不发生在任何写入事项上、也不是开关改动或指定改写所致（只因竞争边或别的结构变化而转变），转变所在的写入事项同时改动了开关、拓扑或指定，或同一转变上同时有开关改动与指定改写。种类记 ⊥，不承担形成。  
判别只看与这次转变相关的改动：转变所在的事项前后，承担边的可用性、遮蔽、门槛与拓扑是否改动，承担者指定是否改写。

只有结构生成与阈值越过可以承担形成。形成在实际历史 H\_obs 上判定，不在削减历史的重放上判定：s\_g 在窗内最后一次由 0 变为 1 的那一事项属于 H\_g，此后到 τ 一直为 1，这一变化属于上面两种之一，并且 H\_g 的事项实际经过承担 s\_g 的边。已经存在、只被维持的结构，不算这一段历史的形成。

反例：一次事项只把某条已经成槽、被遮蔽的边重新开放，s\_g 由 0 变为 1，事项也经过这条边，终点读到它；按上面的分类，这是重新启用，不是形成。

（二）两条形成路径，对每一 g 取值于 {1, 0, ⊥}：

FieldFormationLink\_I(g)：1，H\_g 中的事项都是申报的合法输入，经 Dyn^Π 的执行、痕迹、沉积、成形，以结构生成或阈值越过的方式在场内形成了 s\_g，窗内没有未申报的写入改动 s\_g 或承担者指定，全过程可以审查；0，所需接口完整可读，而明确没有这样的形成连接；⊥，存在不可读、不可审之处，或变化的种类不能判别。

ExternalInstallLink\_I(g)：1，H\_g 中有申报的、可以审查的外部编辑事项，真实生成了 s\_g；0，所需接口完整可读，而明确没有这样的安装连接；⊥，存在不可读、不可审之处。

&nbsp;&nbsp;&nbsp;&nbsp;ActualFormation(g) := FieldFormationLink\_I(g) ∨₃ ExternalInstallLink\_I(g)

这一析取只在这里的形式定义内穷尽形成路径，不宣称在本体上一切意向形成方式都被穷尽。相关、同步、预测、旁观、纯背景使能、重新启用与终态代理，都不满足任一路径。

（三）终点绑定，对每一 g 与每一 X ∈ {P\_I, SD, GC, TI} 取值于 {1, 0, ⊥}：

EndBind\_X(g)：1，s\_g 正式进入 τ 处这份冻结候选的 X 项承担，即 X 的读出在 τ 处为 1，并且读到的承担者之中有 s\_g；0，绑定接口完整可读，而明确没有进入；⊥，绑定关系不可判。

&nbsp;&nbsp;&nbsp;&nbsp;EndBind\_I(g) := EndBind\_P\_I(g) ∨₃ EndBind\_SD(g) ∨₃ EndBind\_GC(g) ∨₃ EndBind\_TI(g)

终点绑定相对于冻结的 χ̄\_I：s\_g 必须进入同一候选、同一资格锚之下某一项的承担。形成在另一个组织、另一条运行或另一资格锚上的结构，EndBind\_I = 0。

（四）形成性承重。撤回操作 Wd^Π(g, s\_g)：合法重放 H\_s 时，只在 H\_g 的每一事项（按事件逐一，不含同一原子中 H\_g 以外的事项）执行以后，撤回该事项在 s\_g 承担边上的沉积增量与重复记录、绑定增量，以及（s\_g 是律承担或率关系时）相应各维路径动力的改动，保留该事项自身的一个衰减步，该事项的其他作用与时间位置都保留。节点沉积为所有经过该节点的结构共用，不撤回。撤回的变量若也承担别的结构，撤回就同时取消了那些结构，判定的实际是它们的并，须作为复合见证登记。Wd^Π 的合法性在协议中事前申报；不能合法执行时 FormBear 记 ⊥。

&nbsp;&nbsp;&nbsp;&nbsp;FormBear(g; H\_s) ∈ {1, 0, ⊥}

先看候选自身：Replayable(H\_s) ≠ 1 或 Suff(H\_s) = ⊥ 时，FormBear = ⊥；Replayable(H\_s) = 1 且 Suff(H\_s) = 0 时，FormBear = 0。只有 Replayable(H\_s) = 1 且 Suff(H\_s) = 1 时，才继续：  
0：在 H\_s 的合法重放中，s\_g 不由 H\_g 的事项形成，或在 τ 处不成立。  
否则作带 Wd^Π(g, s\_g) 的合法重放：  
⊥：撤回不可合法执行；或撤回重放中 s\_g 仍由 H\_g 的事项形成（撤回没有取消这次形成）；或撤回重放的读数不可判。  
1：撤回已经取消 H\_g 对 s\_g 的形成，并且在 τ 处明确 N\_I = 0。  
0：撤回已经取消 H\_g 对 s\_g 的形成（s\_g 不成立，或改由 H\_g 以外的事项形成），而在 τ 处明确 N\_I = 1，即这次形成不承担这段历史的充分性。

FormBear 把实际形成与反事实承重绑在同一个结构上：它问的不是“删去某一事项是否不再充分”，而是“只取消这一结构的形成、该事项的其余作用都保留，是否不再充分”。所以，一个事项因别的作用而在反事实上必要、只顺带形成了一条冗余结构时，那条结构的 FormBear = 0。几条结构互为冗余、各自单独撤回都不破坏充分性时，单一结构的见证都为 0，须再审查它们的并。复合见证只在极小时使用：撤回它的并破坏充分性，而撤回它的任一真子并都不破坏；所以含有单独承重成员的并不是复合见证，副产物不能借并入一个承重结构而取得承重。极小性按可以单独撤回的变量集来判：几个结构共用撤回变量、不能分开撤回时，它们整体作为一个成员单位；有真子并的读数为 ⊥ 时，极小性不能判定，这一复合见证记 ⊥。复合见证的 ActualFormation 取各成员 ActualFormation 的 ∧₃；EndBind\_X(g) = 1 要求某一成员进入 X 的承担。出处轴上，FieldBorn 要求全体成员都是场内形成，ExternalInstall 要求全体成员都是外部安装，成员出处不同时两者都不签 1，来源核心不受影响。“枚举完整”包括极小复合见证。

实际意向生成链：

&nbsp;&nbsp;&nbsp;&nbsp;ActualIGenesisLink^Π(H\_s; χ̄\_I, τ) := ∃₃ g，H\_g ⊑\_ord H\_s：\[ ActualFormation(g) ∧₃ EndBind\_I(g) ∧₃ FormBear(g; H\_s) \]

形成、绑定与承重必须落在同一个见证 g 上：不能一边拿事项 A 的形成，一边拿另一事项或既存结构 B 的终点绑定，也不能拿 C 的反事实必要代替 A 的形成承重。Suff(H\_s) = 0 的候选，FormBear = 0，ActualIGenesisLink = 0，MinSuff 也为 0；Replayable(H\_s) ≠ 1 或 Suff(H\_s) = ⊥ 的候选，一切见证的 FormBear 都为 ⊥；这时，只要有一个见证的 ActualFormation 与 EndBind 都不为 0，它的三项合取就为 ⊥，ActualIGenesisLink 不签 0；MinSuff 按 3.7 为 ⊥。

三值规则：∨₃ 有 1 即 1，无 1 而有 ⊥ 即 ⊥，全 0 才为 0；∧₃ 有 0 即 0，无 0 而有 ⊥ 即 ⊥，全 1 才为 1；∃₃ 有 1 即 1，无 1 而有 ⊥ 即 ⊥，全 0 才为 0，并且“全 0”要求 H\_s 中的形成见证已经枚举完整，否则为 ⊥。

### 3.7 最小充分来源历史

&nbsp;&nbsp;&nbsp;&nbsp;MinSuff\_I^Π(H\_s; χ̄\_I, τ) ∈ {1, 0, ⊥}

先判候选自身：Replayable(H\_s) ∈ {0, ⊥} 时为 ⊥；Replayable(H\_s) = 1 且 Suff(H\_s) = 0 时为 0；Suff(H\_s) = ⊥ 时为 ⊥。只有 Replayable(H\_s) = 1 且 Suff(H\_s) = 1 时，才审查一切 H′ ≺\_Π H\_s：

0：存在 H′ ≺\_Π H\_s，Replayable(H′) = 1 且 Suff(H′) = 1。确定反例优先。  
1：没有上述反例，并且一切严格削减都有 Replayable(H′) = 1 且 Suff(H′) = 0。  
⊥：没有确定的充分严格削减，但至少有一个严格削减 Replayable = 0 或 ⊥，或合法重放以后 Suff = ⊥。

不得：不能合法删除 ⇒ 必要来源。

MinSuff = 1 证明的是：在一切严格削减都可以合法重放、并取得确定读数的削减域中，H\_s 是极小的。只要有一份严格削减不能合法重放或读数不可判，即使其余合法削减都已证明不充分，MinSuff 也只记 ⊥。这是保守的判法：它不是一般反事实意义上的极小性。削减的准入与重放的合法性是两件事：Ops^Π 事前冻结，可以事前排除已知会破坏协议的操作；已经准入、而 Replayable ≠ 1 的削减，使 MinSuff 停在 ⊥，事后不得剔除。

## 第四节　来源定理

### 4.1 来源核心

&nbsp;&nbsp;&nbsp;&nbsp;IGenesisSource^Π(H\_s; χ̄\_I, τ) := Genesis\_I^Π ∧₃ ActualIGenesisLink^Π ∧₃ MinSuff\_I^Π

三项各守一事：Genesis\_I 守首次资格事件；ActualIGenesisLink 守实际形成链及其形成性承重；MinSuff\_I 守整段历史的合法反事实承重与非冗余。只有实际链而没有反事实承重，不够；只有反事实必要而没有实际形成链，也不够。三值传播按 ∧₃。材料不足不写成“不是来源”。

### 4.2 来源解族

&nbsp;&nbsp;&nbsp;&nbsp;𝔖^Π\_{I,src} := { H\_s ∈ 𝓗^Π\_src \| IGenesisSource^Π(H\_s) = 1 }

来源解族可以有多个成员，不默认唯一。来源有多解时，报告整个可认证的解族。

### 4.3 空历史控制

H\_∅：不保留任何申报来源事项，其余协议项不变。

SourceDomainIncomplete\_I^Π：1，Replayable(H\_∅) = 1 且 Suff(H\_∅) = 1：不保留任何来源事项，终点仍然充分，说明申报的历史事项没有穷尽这一次资格形成的可区分承重来源；来源可能在边界、背景、冻结动力的自主演化或申报粒度之外，须进一步追溯，此时 Source\_I = ⊥，不写成 Source\_I = 0，也不据此断定有某一段被遗漏的历史；0，Replayable(H\_∅) = 1 且 Suff(H\_∅) = 0；⊥，空历史不能合法重放或其 Suff 不可判。空历史不进入解族。

### 4.4 来源可判域

&nbsp;&nbsp;&nbsp;&nbsp;SrcDetDom\_I^Π := GenesisResolved ∧ DomainExhaustive ∧ ReductionDomainFinite ∧ ReplayCoverage ∧ ActualLinkCoverage ∧ EmptyControlClosed ∧ GranFrozen

GenesisResolved：Genesis\_I 已判为 1。DomainExhaustive：来源候选域已完整申报并穷尽。ReductionDomainFinite：3.3 的有限性成立。ReplayCoverage：对一切有形成与终点绑定见证的候选，MinSuff 已判为 0 或 1。ActualLinkCoverage：一切候选的 ActualIGenesisLink 已判为 1 或 0。EmptyControlClosed：SourceDomainIncomplete = 0。GranFrozen：粒度已冻结。

它只是来源判定工作的完整域，不是意向本体，不是第五项资格，不是 H。

### 4.5 来源整体状态

SourceExistence\_I^Π ∈ {1, 0, ⊥}：1，𝔖^Π\_{I,src} ≠ ∅；0，SrcDetDom = 1 且 𝔖^Π\_{I,src} = ∅；⊥，其余情形。

Source\_I^Π(χ̄\_I, τ) ∈ {1, 0, ⊥}：1，SrcDetDom = 1 且 𝔖^Π\_{I,src} ≠ ∅；0，SrcDetDom = 1 且 𝔖^Π\_{I,src} = ∅；⊥，其余情形，包括 Genesis\_I = ⊥、来源候选域不完整、空历史已充分、关键重放非法或不可判、实际生成链不可审、粒度不足、来源集尚未穷尽。Genesis\_I = 0 的情形已在 1.6 分流为 OutDom。

可以同时有 SourceExistence = 1 与 Source = ⊥：已经知道至少有一条真实来源，但来源域尚未穷尽。

&nbsp;&nbsp;&nbsp;&nbsp;没有找到来源 ≠ 没有来源

来源主张的负证书有三类：来源结构断裂（这里的 Source\_I = 0），边界预装（6.6），封闭域不可能（6.7）。

Source\_I = 0 是“来源结构断裂”的负证书：在完整闭合的判定域内，没有一段候选历史同时承担实际形成与最小充分。它只对申报的协议成立；对某一粒度、某一边界签 0，不推出更细的粒度、更早或更大的边界也为 0。

### 4.6 定理一（意向来源认证定理）

设 H\_s ∈ 𝓗^Π\_src。若 Genesis\_I^Π(χ̄\_I, τ) = 1、ActualIGenesisLink^Π(H\_s) = 1、MinSuff\_I^Π(H\_s) = 1，则 IGenesisSource^Π(H\_s) = 1，H\_s ∈ 𝔖^Π\_{I,src}，并且：

合法重放 H\_s 到 τ，N\_{I,τ} = 1，从而 Intent\_τ = 1；  
H\_s 中有真实形成的一个结构或一个极小结构组进入 τ 处同一候选的至少一项承担，并且只取消它的形成，H\_s 就不再充分；  
H\_s 的任何合法严格削减都不再充分。

证明。由 4.1 的三值合取，三项为 1 则 IGenesisSource = 1；又 H\_s ∈ 𝓗^Π\_src，故 H\_s ∈ 𝔖^Π\_{I,src}。由 3.7，MinSuff = 1 只在 Replayable(H\_s) = 1 且 Suff(H\_s) = 1 时取得；由 3.5，重放终点 N\_{I,τ} = 1，由《意向必然式》Intent\_τ = 1。由 ActualIGenesisLink = 1 与 3.6，有同一见证上的真实形成、终点绑定与形成性承重。由 MinSuff = 1 的定义，一切严格削减 Suff = 0。□

Status = Established，不携 H。形式层的同一定理以 Genesis\_I^{Π,M}、Suff\_I^M 代入，结论为形式层的来源认证；回读对象层按 1.6 与 3.5 的条件。

推论一（来源主张须有认证）　宣称某段历史是首次资格的来源，须给出 4.1 的三项；某一项证据不足、而没有一项确定为 0 时，只能记 ⊥，不能记 1；某一项确定为 0 时，按三值合取记 0。没有来源证书，只否定“来源已被证明”，不否定对象实际上有来源。

证明。IGenesisSource 是三项的 ∧₃：有一项为 0 则为 0；无 0 而有 ⊥ 则为 ⊥；只有三项都为 1 才为 1；不为 1 的候选不入解族。后一句由 4.5：Source = 0 须 SrcDetDom = 1。□

推论二（伴随形成不足）　H\_s 最小充分，且 H\_s 中有形成见证 ActualFormation = 1、EndBind\_I = 1，不推出 IGenesisSource(H\_s) = 1。

证明。有限抽象协议模型（形式模型）：H\_obs = (a)；τ 不是 T\_Π 的第一个点，τ 以前 N\_I = 0，Genesis\_I(τ) = 1；a 改变了资格所需的一项控制状态，同时顺带形成一条冗余的源动承担边，终点读到这条边；Suff((a)) = 1，Suff(H\_∅) = 0，所以 MinSuff((a)) = 1；只撤回这条边的痕迹，重放仍然充分，FormBear = 0。于是 ActualIGenesisLink((a)) = 0，解族为空，Source = 0；若不计形成性承重，同一模型会签出来源（附录 A 的 abstract，byproduct）。再加一个事项 b，它形成 TI 并承重、两事项缺一不可：解族为 {(a, b)}，承担谱为 0001；不计承重时会记为 0101，把副产物记成源动一项的来源（附录 A 的 abstract，byproduct\_with\_b）。□

Status = Established，逻辑层；抽象模型不断言对应的物理实例已经存在。

### 4.7 定理二（终态来源不足定理）

&nbsp;&nbsp;&nbsp;&nbsp;Intent\_τ = 1 ⇏ 𝔖^Π\_{I,src} ≠ ∅；N\_{I,τ} = 1 ⇏ 𝔖^Π\_{I,src} ≠ ∅

证明。IGenesisSource 的第二、三项以历史为自变量，需要实际形成链与合法重放的证据；终点的资格读数与资格核读数不含这些证据。构造一个有限的抽象协议模型（形式模型，不断言物理实例已经存在）：X\_0 处 N\_I = 0；H\_obs = (h\_0)；ℛ\_Π = { H\_∅, (h\_0) }；τ 处 Judge\_I = 1、N\_{I,τ} = 1，更早的点都为 0，Genesis\_I(τ) = 1。h\_0 的唯一形成见证 g\_0 = ((h\_0), s\_0)，所需接口完整可读，FieldFormationLink(g\_0) = ExternalInstallLink(g\_0) = 0，所以 ActualIGenesisLink((h\_0)) = 0，IGenesisSource((h\_0)) = 0，𝔖 = ∅，而 Intent\_τ = 1、N\_{I,τ} = 1。若空历史的合法重放在 τ 处也充分，则 SourceDomainIncomplete = 1，Source\_I = ⊥，不是“没有来源”。两种情形的求值见附录 A 的 abstract 命令（terminal、terminal\_empty\_sufficient）。□

Status = Established。

由定理二：已安置结构在场中实际运行，只给出终态与运行的证据，不给出来源证书（W-I13）。

### 4.8 定理三（单项形成与最后闭合不足定理）

（一）某一项在窗内真实形成，不推出意向资格的来源已认证。  
（二）τ 处最后闭合的是 X，不推出来源的承担谱只在 X 一项为 1。

证明。（一）IGenesisSource 的第一项要求 Genesis\_I(τ) = 1，即同一候选在 τ 处四项都成立；某一项的真实形成只给出 ActualFormation 与该项的 EndBind，不给出其余三项。有限抽象模型（形式模型）：X\_0 处四项都为 0，H\_obs = (h\_SD)，h\_SD 在场内形成并绑定 SD，其余三项在窗内始终为 0；N\_I 在 T\_Π 上从不为 1，没有首次资格事件，来源记 OutDom（附录 A 的 abstract，single\_item）。参考模型的形式层实例见第七节 7.8：四项分别在四个场中形成。  
（二）构造一个有限的抽象协议模型（形式模型）：X\_0 处四项都为 0；H\_obs = (h\_P, h\_SD, h\_GC, h\_TI)，依次发生，TI 最后闭合；τ 不是 T\_Π 的第一个点，τ 以前各点 N\_I = 0，τ 处 N\_I = 1，Genesis\_I(τ) = 1；削减域为全部子序列，都可以合法重放；Suff(H\_obs) = 1，一切严格削减 Suff = 0；g\_X = ((h\_X), s\_X)，FieldFormationLink(g\_X) = 1，EndBind\_X(g\_X) = 1，撤回 s\_X 的痕迹以后重放不充分，FormBear(g\_X; H\_obs) = 1（模型申报）。于是 IGenesisSource(H\_obs) = 1，承担谱为 1111，不是 0001（附录 A 的 abstract，last\_closure）。□

Status = Established，定义层结论。

### 4.9 定理四（资格核组成来源不足定理）

对任意 X ∈ {P\_I, SD, GC, TI}：X 是 N\_I 的组成项，不推出 X 的形成史属于本次首次资格的来源。

证明。来源只在来源窗内、并经最小充分认证的历史中取得。抽象模型：X\_0 处 P\_I = SD = GC = 1、TI = 0；H\_obs = (h\_TI)；τ 不是 T\_Π 的第一个点，τ 以前各点 TI = 0 从而 N\_I = 0，τ 处 N\_I = 1，Genesis\_I(τ) = 1；H\_∅ 与 (h\_TI) 都可以合法重放，Suff(H\_∅) = 0，Suff((h\_TI)) = 1；g\_TI 形成并绑定 TI，撤回它的痕迹以后不充分，FormBear = 1（模型申报）。于是 𝔖 = { (h\_TI) }，承担谱 0001（附录 A 的 abstract，component）；P\_I、SD、GC 在终点仍是 N\_I 的组成项，它们的形成史不在任何 H\_s 中。X 取其他三项时，交换项名同理。

参考模型在形式层给出一个窗内的实例（第七节 7.4）：P\_I 的结构在窗内真实形成（第 4、5 轮），并且进入 τ 处 P\_I 的承担，但形成它的那一段历史不在唯一的认证来源中；τ 处 P\_I 的承担由后一段历史在反事实上承重，那一段历史只维持、不形成，所以认证来源的承担谱在 P\_I 一项为 0。□

Status = Established，不携 H。第七节 7.4 中含 pA1 或 pX1 的充分候选，也给出“只有实际链而没有反事实承重，不够”的实例。

### 4.10 定理五（共锚绑定定理）

四项各有真实形成的见证，不推出存在这份候选的来源：

&nbsp;&nbsp;&nbsp;&nbsp;∧\_X \[ ∃ g\_X：ActualFormation(g\_X) = 1 且 s\_{g\_X} 在某一候选的 X 项承担中 \] ⇏ 𝔖^Π\_{I,src} ≠ ∅

除非四项的形成进入同一份冻结候选、同一资格锚之下的承担，并且该候选在 τ 处有首次资格事件。

证明。EndBind\_X 相对于冻结的 χ̄\_I：形成在另一组织、另一条运行或另一资格锚上的结构，对这份候选 EndBind = 0（3.6）。所以四个见证分属四个候选时，它们对任何一份候选至多提供一项的终点绑定；每一份候选是否有来源，只取决于它自己的历史。有限抽象模型（形式模型）：四次运行，各自的候选在窗内只形成自己的一项，其余三项始终为 0；每一份候选的 N\_I 都不为 1，都没有首次资格事件，解族都为空（附录 A 的 abstract，four\_runs）。前件成立而结论不成立。参考模型在形式层的实例：四项分别在四个场中形成，每一项在各自的场中读为 1，四个场中意向资格都不成立，跨运行的终点绑定为 0（第七节 7.8）。□

Status = Established。四项来源不得跨组织拼接，这一点与《意向一般式》四项落在同一组织上的要求一致。

### 4.11 事件级来源承担

对历史原子 h（按 Gran^Π），记“来源族完整”为 SrcDetDom = 1 且 𝔖 已完整枚举：

PossibleSourceCarrier\_I(h)：1，已找到含 h 的 H\_s ∈ 𝔖；0，来源族完整，且没有 H\_s 含 h；⊥，其余情形。  
NecessarySourceCarrier\_I(h)：1，来源族完整且非空，所有 H\_s 都含 h；0，已有 H\_s ∈ 𝔖 不含 h；⊥，其余情形。来源族为空时，不借空集的全称把任意 h 判为必要来源。  
RedundantSourceCarrier\_I(h)：1，已找到含 h 的 H\_A ∈ 𝔖，又找到不含 h 的 H\_B ∈ 𝔖；0，来源族完整，且 h 不属于任何 H\_s，或属于所有 H\_s；⊥，其余情形。  
NonSourceCarrier\_I(h)：1，来源族完整，且 h 不属于任何 H\_s；0，已找到含 h 的 H\_s；⊥，其余情形。

这些承担读数都只相对于冻结的候选、粒度、削减关系与已完整枚举的解族。NecessarySourceCarrier(h) = 1 只说在这一协议下每一份认证来源都含 h；它不说 h 的每一作用都形成意向，也不说一切可能的发生历史都必须含 h。

## 第五节　不能唯一确定之处与来源分类

### 5.1 定理六（来源非唯一性定理）

&nbsp;&nbsp;&nbsp;&nbsp;Source\_I = 1 ⇏ 来源唯一

证明。MinSuff 是相对于偏序 ⪯\_Π 的极小性，偏序集中的极小元不必唯一；IGenesisSource 的定义中也没有唯一性条款。抽象模型（形式模型）：H\_obs = (h\_A, h\_B)；ℛ\_Π = { H\_∅, (h\_A), (h\_B), (h\_A, h\_B) }；Genesis\_I(τ) = 1；各元素都可以合法重放，Suff(H\_∅) = 0，Suff((h\_A)) = Suff((h\_B)) = Suff((h\_A, h\_B)) = 1；(h\_A)、(h\_B) 各有形成见证，ActualFormation = 1，EndBind\_SD = 1，在 (h\_A)、(h\_B) 中撤回它的痕迹以后不充分，FormBear = 1（模型申报）；(h\_A, h\_B) 中各见证的 FormBear 不影响结论，因为 MinSuff((h\_A, h\_B)) = 0。于是 MinSuff((h\_A)) = MinSuff((h\_B)) = 1，MinSuff((h\_A, h\_B)) = 0；空历史不充分；判定域闭合。所以 𝔖 = { (h\_A), (h\_B) }，Source\_I = 1，而来源有两条，没有一条是必要来源（附录 A 的 abstract，non\_unique）。□

Status = Established。

### 5.2 定理七（形成顺序非唯一定理）

资格合取本身不决定四项的历史形成顺序：

&nbsp;&nbsp;&nbsp;&nbsp;N\_{I,τ} = 1 ⇏ t(P\_I) \< t(SD) \< t(GC) \< t(TI)，也不推出其他任一固定的全序

其中 t(X) 是 X 在窗内首次读为 1 的评价点。

证明。N\_I 是同一评价点上的合取，只规定四项在 τ 处共同成立，不含四项过去何时成立的任何条款；由合取推不出时间次序。参考模型在形式层给出三条合法历史，都取得资格而顺序不同（附录 A 的 order）：参考构造中 P\_I 先于其余三项（第 5 轮与第 86 轮）；两维的概率形成脉冲与五类场脉冲每轮一起施加时，四项同在第 6 轮成立；先单独施加 20 轮五类场脉冲、再每轮一起施加两维的概率形成脉冲与五类场脉冲时，TI 在第 5 轮、SD 与 GC 在第 6 轮、P\_I 在第 26 轮成立。□

Status = Established，限于“资格合取本身不推出唯一顺序”。它不证明一切顺序在物理上都可实现；若要主张某一顺序约束，须由另行给出的动力关系证明。

### 5.3 必须申报的不确定处

来源解族可以有多个成员；事件级的必要来源，正判须来源族完整且非空，负判由一个不含该原子的认证来源直接取得；SrcDetDom 未闭合时，NonSourceCarrier = 1 与 Source = 0 都不能签出；空历史已充分时，来源域不完整，Source = ⊥；削减域无限或粒度未冻结时，SrcDetDom 不闭合，来源记 ⊥。

### 5.4 来源分类：四条正交轴

不得把源动、环境奖惩、默想回路、破持、外部安装写成同层互斥的来源型。分类沿四条正交轴进行。

轴一　来源出处：FieldBorn\_I 与 ExternalInstall\_I。

&nbsp;&nbsp;&nbsp;&nbsp;FieldBorn\_I(H\_s) = 1：存在 g，H\_g ⊑\_ord H\_s，FieldFormationLink\_I(g) = 1、EndBind\_I(g) = 1 且 FormBear(g; H\_s) = 1；= 0：H\_s 中的形成见证已经枚举完整，没有这样的 g；= ⊥：其余情形。  
&nbsp;&nbsp;&nbsp;&nbsp;ExternalInstall\_I(H\_s) = 1：存在 g，H\_g ⊑\_ord H\_s，ExternalInstallLink\_I(g) = 1、EndBind\_I(g) = 1 且 FormBear(g; H\_s) = 1；0 与 ⊥ 同上。

二者不预设互斥。ExternalInstall ⇏ ¬Source；ExternalInstall ⇏ FieldBorn。外部安装不解释为意向可以脱离沉积场存在；它说的是：候选所需的合法沉积结构，可以通过外部安装历史在当前来源窗中首次取得。

轴二　边界：Internal、Boundary、Directed、Unresolved，见第六节。

语料归属：u38（“意向由此而生”）落为来源闭合，即首次资格事件与 IGenesisSource 的认证（第一、四节）；u39（“意图之沉积，沉于意图场”）落为轴一的 FieldBorn（形成经场内的痕迹与沉积取得）与第六节的场内形成判据（意向特异性在边界之后由场内沉积取得）；u40、u41、u42 见轴三。

轴三　形成机制标签。按认证的来源链附加，多标签，不互斥，不穷尽；必须由认证的来源链支持，不能只凭语料中出现某一词就贴标签。

&nbsp;&nbsp;&nbsp;&nbsp;SourceDriveSource：源动驱动的历史真实形成了终点所用的结构，并进入最小充分来源（u40 的“概率受源动驱动”）。  
&nbsp;&nbsp;&nbsp;&nbsp;PrincipleSource：认证来源中有按《理组式》签出的理关系（目标律与候选理的实际持势关系成立，满足关系域、职责所限与持向、反持条件），并且这一关系实际进入了方向竞争、欲门分化或既有职责改写的形成见证（u40 的“破持”）。多方向概率组织不推出任意两方向之间都有理关系；发生过破持，不推出意向必然形成。  
&nbsp;&nbsp;&nbsp;&nbsp;RewardSedimentSource：最小充分的实际来源历史真实包含“试行 → 环境的时间性奖惩 → 沉积分化 → 律续行成形”，并进入终点资格承担（u41）。环境反馈须指明它经何种合法接口进入沉积场，以及引起了什么实际的沉积变化。  
&nbsp;&nbsp;&nbsp;&nbsp;MentationSource：默想、回顾或思考回路实际改变了形成结构，使此前不成立的资格成立，并进入最小充分来源（u42）。回路只在已成意向之内发动一次活动的，属于该次活动的起始，不贴这一标签（W-I7）。  
&nbsp;&nbsp;&nbsp;&nbsp;律、概率、理三者的关系：律承担与概率组织提供基本的发生结构，理刻画其中符合《理组式》判据的破持关系；三者与源动、欲门、调谐接口共同进入来源审查，不能相互替代，也不成为第五项资格。

轴四　资格承担谱：

&nbsp;&nbsp;&nbsp;&nbsp;Σ\_I(H\_s) = (σ\_P\_I, σ\_SD, σ\_GC, σ\_TI)，σ\_X ∈ {1, 0, ⊥}

σ\_X = 1：存在同一形成见证 g，H\_g ⊑\_ord H\_s，ActualFormation(g) = 1、EndBind\_X(g) = 1 且 FormBear(g; H\_s) = 1。σ\_X = 0：H\_s 中与 X 相关的形成见证域已经完整审查，并明确不存在这样的 g。σ\_X = ⊥：其余情形。认证来源至少有一项 σ\_X 为 1。σ\_X 只从同一见证上的实际终点绑定读取，不得用“删除某一事件是否使 X = 0”来定义，以免联合效应与循环。MinSuff 在 N\_I 的层面判断，Σ\_I 是附属读数。σ\_X = 0 不是说 X 不在终点成立，而是说 X 在 τ 处的承担不是由这一来源形成的。

三种来源模式只作候选描述，不作穷尽分类：逐步形成（四项在窗内依次形成）；已有结构重组（承重结构在窗前已分别存在，窗内只形成把它们绑到同一候选的那一项）；混合（部分承继、部分窗内形成）。模式说的是结构在哪里形成；Σ\_I 说的是认证来源承担了哪些项，两者不等同：四项都在窗内形成，认证来源的承担谱仍可以小于 1111（第七节 7.4）。《喑显组式》第四篇《喑显源式》（式篇第二十三）的 Pre、Onset、Mixed 之分只作一致性参照，不作意向来源的定理。

### 5.5 四项的形成读数

EndBind\_X 与 σ\_X 只按各项的上游判据读取，这里不另立判据：

P\_I：《意向必然式》把“新径怎样经沉积、取得律承担而进入概率组织”交这里承接。这里的做法是：新径的沉积、律承担的取得、绑定与率关系的取得，各作为 P\_I 承担结构的形成见证，按 3.6 审查实际形成与终点绑定；律与概率的资格按《律组式》《概率组式》的原判据（D、B、R）签出；概率组织自身的来源认证（PGenesisSource）仍属《概率源式》。意向域位置按《意向一般式》。重复使用不推出律，沉积痕迹不推出律（《律组式》的律资格要求成形与稳定持有）；多条律并存不推出概率（《概率组式》的资格要求共同续行绑定与率承担）；算法归一出来的数值不是概率组织；概率组织成立不推出意向。  
SD：源动承担按《意向一般式》的 SourceDrive 判据。源动驱动一份普通的概率分配组织，不推出欲门对应。该篇已证“四项不能删除（删除 P\_I 一处携带 H2 ∧ H3^red），也不能两两合并”，SD 与 GC 互不推出以此为据。  
GC：维与欲门的对应按 GC 的判据。方向连到门，不推出它承担源动续行；所以 SD 与 GC 互不推出。  
TI：每一欲门之后由门层使役的调谐接口，按 TuneInterface 的判据；下面两条不推出，都据这一判据对“由门层使役的接口职责”的要求。门后有路径，不推出门后有调谐结构；门后有并存的调谐结构，不推出它取得了由门层使役的接口职责。

## 第六节　边界与场内形成

### 6.1 意向特异预装

对每一 X ∈ {P\_I, SD, GC, TI}，在边界 B\_S = (X\_0, Bg^Π) 上读：

&nbsp;&nbsp;&nbsp;&nbsp;Spec\_X(B\_S) ∈ {1, 0, ⊥}

1：X\_0 处这份候选的 X 项已经成立；或者 X\_0 处的承担者指定 Des\_I 已经为 X 点名了承担者（对 P\_I，是某一概率组织已被申报为位于意向域）；或者 X\_0 处已有为 X 的职责安置、在一般介质之外的结构。0：边界审查完整，三者都没有。⊥：其余情形。Spec\_X 只看 X\_0：边界上已有的指定或安置，即使在窗内被改写，也使 Spec\_X = 1。

一般介质 M\_gen 在协议中事前申报：边界上不为任何意向职责而设的节点与边，以及其上的一般律与概率结构和概率层的接线状态（如载体接线、生成闸）。一般介质以外、作为 X 的承担者而安置的节点与边，即使尚无沉积，也是意向特异的安置。

&nbsp;&nbsp;&nbsp;&nbsp;NoPreinstalledIntent(B\_S) := ∧₃\_X ¬Spec\_X(B\_S)

一般介质、事前冻结的观测协议（判词、评价点集、粒度、候选的职责身份），不算意向特异预装，可以在边界上存在。“已有结构重组”的模式，只有在窗前的承重结构都属于一般介质、X\_0 处没有为四项给定的指定与安置时，才与无预装相容；否则它至多落入 Boundary。算作预装的，是边界上已经成立的项、已经给定的承担者指定，以及一般介质之外的意向特异安置。

读出器若依赖事前给定的承担者指定，Spec\_X 对相应各项必为 1：这样的系统，包括《意向运行基底构造式》的参考模型，在这里至多落入 Boundary。从场的结构中读出承担者、使指定本身成为窗内形成的读出接口，属于第二十一篇的构造。

### 6.2 读数依赖与输入点名

Dep\_X：X 的读出在 τ 处所依赖的全部状态项，按 X 的读出定义逐变量列出，包括承担结构的状态变量、承担者指定与读出器的覆盖开关。读出器另读冻结声明 χ̄\_I 的组成项（锚、职责身份、正式维、概率组织的身份与载体候选登记）；它们按 1.3 冻结，作为冻结声明项整体计入，不逐项列出，也不作扰动。读出器的覆盖开关属于协议，也归入冻结声明项，但它们在 Dep\_X 中逐项列出，并参与下面的扰动探查。

列出的完整性另作审查。申报一份状态清单，它包含系统的全部状态变量：图的拓扑，各边的沉积与重复记录、可用性、遮蔽与门槛，各节点的沉积，载体路径的路径动力，绑定、生成闸与载体接线，承担者指定（包括源动登记与概率组织的绑定关系、事件组装所用的承担者属性；跨运行比较时，运行身份规范化为“是否绑定冻结的概率组织”，不删去这一关系），读出器的覆盖开关，各层的随机源，时钟，场日志、程度记录与各层的事件与操作记录，门承担状态与源动会话状态。在 τ 处对清单中的每一变量单独施加一种扰动，记下 X 的读数因之改变的变量。DepComplete\_X：1，这些变量全部在 Dep\_X 之内；0，有不在 Dep\_X 之内的；⊥，状态清单本身不完整或扰动不可执行。这一探查有两个限度，随结论一并登记：只在联合扰动下才起作用的依赖查不出来；每一变量只扰动到一个固定取值（例如沉积置零、可用性关闭），变量本来就处在这一取值时，探查对它是空的（例如没有沉积的竞争边，只在加上沉积时才显出的依赖）。所以 DepComplete\_X = 1 的强度是“读出定义的列出，加上这一单变量探查没有发现遗漏”。

对 Dep\_X 的每一项 d，分五类：  
冻结声明项：χ̄\_I 与协议的组成项（资格锚、职责身份、正式维、概率载体候选等），按定义在窗内不变；  
边界一般项：不是冻结声明项，从 X\_0 到 τ 的一切评价点上取值不变，属于一般介质，或者始终未给定（例如始终为空的指定、始终没有沉积的结构）；  
边界特异项：不是冻结声明项，从 X\_0 到 τ 的一切评价点上取值不变，不属于一般介质，并且在 X\_0 处已经给定，例如承担者指定与一般介质之外已有承担的安置；  
窗内形成项：取值在窗内有变，是某一结构 s 的承担变量，s 在 τ 处成立，并且 s 最后一次由 0 变为 1 有 3.6 意义上的形成见证（结构生成或阈值越过）；  
未解释项：其余一切，包括取值有变而 τ 处不成立、没有形成见证或不可读。  
先分出冻结声明项；其余按“取值是否在窗内有变”分两支，不变的一支按“是否不属于一般介质且在 X\_0 处已经给定”分为特异项与一般项，有变的一支按是否满足窗内形成项的条件分为形成项与未解释项。所以这一分类穷尽而且互斥。

NoPrivWrite：窗内一切状态改变都来自 H\_obs 的事项经 Dyn^Π 的执行，没有未申报的写入。

路线的决定来源：形成事项经过承担结构的那一段路线，由谁决定。分四种：  
输入指定：输入本身给定了这段路线（例如给定路线的脉冲），或经一个事前固定、可以审查的映射由输入唯一确定这段路线；  
指定决定：路线由系统按承担者指定构造（例如事件按登记的源动承担者、门与调谐承担者组装路线），承担者的区别来自指定；  
场内选路：路线由场自身的续行在竞争中选出，申报的可审查记录显示没有输入或指定决定这段路线；  
材料不足：决定这段路线的机制不能审查，例如可能存在未申报的查表或间接映射。  
对形成见证 g，SelfRouted(g) ∈ {1, 0, ⊥}：1，场内选路；0，输入指定或指定决定；⊥，材料不足。SelfRouted 按终点承担来定审查范围：凡在 τ 处进入 SD、GC、TI 承担的结构，以及承担意向域位置的结构，都要审查，因为问题是意向承担者的区别由谁取得；只有 P\_I 中一般的律与概率结构沿哪条路线形成，是概率组织自身来源的问题，交《概率源式》。审查范围不按边界身份定：在无预装的边界上，SD、GC、TI 的承担者正是一般介质上未被指定的结构，它们照样受审查。路线经过承担边，不单独说明承担者由外部点名；没有给定路线，也不单独说明承担者由场选出，两者都要审查实际的决定来源。合法的外部诱发不等于外部替系统完成形成：输入可以存在，问题在于承担者的区别由谁取得。

### 6.3 各项的窗内形成与分类

&nbsp;&nbsp;&nbsp;&nbsp;FormInternal\_X ∈ {1, 0, ⊥}

1：Dep\_X 已按读出定义列出，DepComplete\_X = 1；NoPrivWrite = 1；Dep\_X 中没有未解释项；X 在 X\_0 处不成立时，至少有一个窗内形成项；每一窗内形成项的形成见证都 FieldFormationLink = 1、ExternalInstallLink = 0，其中进入 SD、GC、TI 承担或承担意向域位置的结构 SelfRouted = 1。  
0：NoPrivWrite = 0（窗内有未申报的写入）；或有一个窗内形成项的见证明确 FieldFormationLink = 0 或 ExternalInstallLink = 1；或有一个进入 SD、GC、TI 承担或承担意向域位置的结构，其形成路线明确是输入指定或指定决定。  
⊥：其余情形，包括 DepComplete\_X ≠ 1、有未解释项、X 由 0 变为 1 而找不到窗内形成项、路线的决定来源材料不足。不能审查的部分降为 ⊥，不签 1。

FormInternal\_X 审查 X 在窗内的实际形成，不论形成见证是否在 H\_s 之内：H\_s 只说明哪一段历史最小充分，场内形成要问四项的意向特异性实际从哪里来。边界特异项不在 FormInternal\_X 中审查，由 Spec\_X 审查。

&nbsp;&nbsp;&nbsp;&nbsp;InternalSource\_I^{B\_S}(H\_s) := IGenesisSource(H\_s) ∧₃ NoPreinstalledIntent(B\_S) ∧₃ ∧₃\_X FormInternal\_X

分类只对 IGenesisSource(H\_s) ≠ 0 的 H\_s 作出；IGenesisSource(H\_s) = 0、或来源记 OutDom 时，不分类。  
Internal（场内形成）：上式为 1。  
Boundary（边界预装）：IGenesisSource(H\_s) = 1，NoPreinstalledIntent = 0。  
Directed（输入点名、外部安装或未申报写入）：IGenesisSource(H\_s) = 1，NoPreinstalledIntent = 1，而某一 FormInternal\_X = 0。  
Unresolved（未决）：其余情形，包括 IGenesisSource(H\_s) = ⊥。  
它们是来源证明的状态，不是意向本身的几种真值。

### 6.4 定理八（预装分离定理）

（一）Intent(X\_0) = 0 ⇏ NoPreinstalledIntent(B\_S)。  
（二）IGenesisSource(H\_s) = 1 ∧ FieldBorn\_I(H\_s) = 1 ⇏ InternalSource\_I^{B\_S}(H\_s) = 1。

证明。（一）Spec\_X 的 1 分支除“X 已经成立”以外，还有“承担者已被指定”；四项都不成立、而四项的承担者都已指定的边界，Intent(X\_0) = 0 而 NoPreinstalledIntent = 0。  
（二）有限抽象协议模型（形式模型）：X\_0 处四项都为 0；H\_obs = (h\_P, h\_SD, h\_GC, h\_TI)，各事项在场内形成并绑定一项；τ 不是 T\_Π 的第一个点，τ 以前各点 N\_I = 0，Genesis\_I(τ) = 1；削减域为全部子序列，都可以合法重放，Suff(H\_obs) = 1，一切严格削减 Suff = 0；边界上只有 SD 的承担者已经指定（Spec\_SD = 1），其余三项的 Spec 为 0；四项的窗内形成见证都是场内形成、承重（FormBear = 1，模型申报），FormInternal 都为 1。于是 𝔖 = { H\_obs }，Source = 1，FieldBorn = 1，NoPreinstalledIntent = 0，InternalSource = 0（附录 A 的 abstract，preinstalled）。□

Status = Established。参考模型在形式层同时给出（一）（二）两条的实例（第七节 7.5）：初态的资格形式读数为 0，四项的承担者都已指定；来源在形式层经认证、FieldBorn = 1，而分类为 Boundary。《意向可达式》的源动侵蚀初态在形式层也满足（一）：资格形式读数为 0，意向专用结构与指定都在。由（一），初态的预装审查不能由初态没有资格代替（W-I12）；由（二），沉积确实在场内发生，不足以说明意向特异性来自场内。

### 6.5 定理九（场内形成判据）

若 IGenesisSource^Π(H\_s) = 1，NoPreinstalledIntent(B\_S) = 1，且对每一 X ∈ {P\_I, SD, GC, TI}，FormInternal\_X = 1，则在边界 B\_S 之内：

（一）首次资格由 H\_s 承担形成，H\_s 最小充分；  
（二）四项在边界上都不成立，都没有指定的承担者，也没有一般介质之外为它们安置的结构；  
（三）每一项在 τ 处的读数，只依赖冻结声明项、边界一般项与窗内形成项；窗内形成项都由合法输入经场内的执行、痕迹与沉积，以结构生成或阈值越过的方式取得，没有外部编辑与未申报写入，意向特异承担者的区别由场内选路取得，不由输入指定或承担者指定决定。

（二）与（三）合起来，记作“这份候选首次资格的意向特异性在 B\_S 之内由场内形成取得”。

证明。（一）由定理一。（二）由 NoPreinstalledIntent = 1：对每一 X，Spec\_X = 0，即 X 在 X\_0 处不成立，Des\_I 在边界上没有为 X 点名承担者，也没有一般介质之外为 X 的职责安置的结构。（三）FormInternal\_X = 1 要求 Dep\_X 已列出、DepComplete\_X = 1、没有未解释项；由（二），Spec\_X = 0，X\_0 处没有为 X 给定的指定或一般介质之外的安置，所以 Dep\_X 中没有边界特异项（边界特异项按定义在 X\_0 处已经给定）；由 6.2 的分类穷尽，Dep\_X 的每一项是冻结声明项、边界一般项或窗内形成项。X 在 X\_0 处不成立而在 τ 处成立（Genesis\_I(τ) = 1），FormInternal\_X = 1 又要求至少有一个窗内形成项，并且每一窗内形成项的见证都是合法的场内形成（结构生成或阈值越过）、无外部编辑，进入 SD、GC、TI 承担或承担意向域位置的结构 SelfRouted = 1；NoPrivWrite = 1 排除了未申报写入。□

Status = Established。这是判据层的定理：（一）由定理一，（二）是 Spec\_X = 0 的展开，（三）是 FormInternal\_X 与 Spec\_X = 0 的合取；其中唯一不由单一定义直接读出的一步，是 6.2 分类的穷尽性。它的作用是把“场内形成”这一主张拆成可以逐项核查的读数：IGenesisSource 由重放与形成记录取得，NoPreinstalledIntent 由边界审查取得，FormInternal 由读出定义、形成记录、写入审计与输入记录取得。（三）中“只依赖”的强度与 DepComplete\_X 相同：读出定义的列出，加上单变量探查没有发现遗漏；只在联合扰动下起作用、或只在别的扰动取值下显出的依赖，不在这一强度之内。定理九只在申报的边界与协议之内成立；它不推出更早的边界、别的场或自然系统中的意向资格都在场内形成。在一般场中怎样取得 Dep\_X 的完整列出与 NoPrivWrite，是第八节 O-S2 的开放义务；定理九以它们为前件，不承担它们的取得。

### 6.6 预装负证书

Spec\_X(B\_S) = 1 确定成立时，分三层表述：  
边界无预装的主张：签 0，即 NoPreinstalledIntent(B\_S) = 0；  
已认证来源的场内形成分类：不能签 Internal，InternalSource\_I^{B\_S} = 0，即否定“关键意向特异性在该边界以后首次形成”这一具体主张；  
来源本身是否存在：仍按第四节独立判定。预装事实不使某段历史成为来源，也不使来源不存在。  
它不否定在更早、更大的边界上存在场内形成。

### 6.7 封闭域负证书

给定 X\_0、Dyn^Π 与一个申报的输入类 U（一切所论历史只用 U 中的输入）。若存在状态集 D ∋ X\_0，它在 U 与 Dyn^Π 之下的一切合法后继中封闭，并且有某一项 X 与某一承担结构 s，X 的读出为 1 须以 s 成立为必要条件，而 s 在 D 的每一状态上都确定不成立，并且 s 不成立时 X 的读出确定为 0，从而 X 在 D 上恒为 0，则：从 X\_0 出发、只用 U 的一切历史上都没有首次资格事件。于是，“这份候选的首次资格在 U 之内、从 X\_0 起发生”这一主张签 0；对这类历史提来源问题，没有首次事件可问，记 OutDom。

这是《意向可达式》定理二意义上的不可达负证书，用在来源主张上。它只对申报的 U 与 Dyn^Π 成立；扩大输入类以后不外推。X 恒为 0 若由形式读数取得，回读对象层按 1.2 的负读条件；本组式新增原子的形式零不回读，此时负证书停在形式层。

### 6.8 定理十（来源与可达分离定理）

&nbsp;&nbsp;&nbsp;&nbsp;R\_Ξ(X\_0, G\_I) = 1 ⇏ 𝔖^Π\_{I,src} ≠ ∅，且 Source\_I^Π = 1 ⇏ R\_Ξ′(X\_0, G\_I) = 1，InternalSource\_I^{B\_S} = 1 ⇏ R\_Ξ′(X\_0, G\_I) = 1

前者对与来源协议同一初态的可达任务成立；后者对同一初态、而许可集不同的可达任务 Ξ′ 成立。

证明。可达问的是从 X\_0 出发是否存在一条合法路径；来源问的是实际发生的那一段历史。前者：实际历史可以根本没有走到资格，这时没有首次资格事件，来源记 OutDom（1.6），解族为空，而另一条合法路径照样到达。后者：Source = 1 只说实际历史在协议的输入之下承担了首次成立；换成更窄的许可集 U′ 以后，那段历史中的事项可以不在 U′ 中，而从 X\_0 只用 U′ 可以根本无法到达。参考模型在同一初态上给出两者的形式层实例（第七节 7.9）：只施加概率形成脉冲的实际历史没有首次资格事件，解族为空，而施加五类场脉冲的参考构造是一条到达资格的合法路径；参考构造的来源在形式层经认证，而只许可概率形成脉冲的任务有封闭域负证书，形式层不可达。对场内形成的来源，有限抽象模型（形式模型）：定理八（二）的模型改为四项的 Spec 都为 0，于是 InternalSource = 1；可达任务 Ξ′ 的许可集为空，系统在没有输入时不变，从 X\_0 只能到达 X\_0 本身，那里 N\_I = 0，R\_Ξ′ = 0（附录 A 的 abstract，internal\_vs\_reach）。□

Status = Established。

### 6.9 来源条件与构造的分离

这里给出的是来源的认证制度与判据；它们不证明某一可执行系统已经满足全部前件。在基础沉积场中给出具体初态、实际运行接口、形成步骤、统一证书与终点资格见证，并使定理九的各前件都为 1，是《意向生成基底构造式》（第二十一篇）的任务。来源条件已经明确，不推出首次生成的构造已经实现。

&nbsp;&nbsp;&nbsp;&nbsp;𝔖^M = { H\* }，Source\_I^M = 1

### 7.5 边界审查与分类

以下是形式层的审查与分类（附录 A 的 classify）。一般介质 M\_gen 申报为参考模型的介质节点与边（含回路边）。初态四项的形式读数都为 0，资格形式读数为 0。边界上：

&nbsp;&nbsp;&nbsp;&nbsp;P\_I：意向域位置已申报  
&nbsp;&nbsp;&nbsp;&nbsp;SD：源动承担者指定为 sI→a1；节点 sI 与边 sI→a1 在一般介质之外安置  
&nbsp;&nbsp;&nbsp;&nbsp;GC：维与门职责的对应、门职责的承担者已指定，承担边 c→gA、x→gX 在一般介质之外安置  
&nbsp;&nbsp;&nbsp;&nbsp;TI：两门之后的调谐承担者指定为 gA→tA、gX→tX，这两条边在一般介质之外安置

四项的 Spec\_X 都为 1，NoPreinstalledIntent = 0。各项的窗内形成：窗内只执行 H\_obs 的脉冲与模型自身的衰减步，没有其他写入，NoPrivWrite = 1；另逐事件核对，承担者指定与概率层的载体登记、载体接线、生成闸都没有改动；H\_obs 中没有外部编辑类事项，ExternalInstallLink 都为 0；读数依赖：对状态清单的每一变量单独扰动，P\_I 的读数对 23 个变量敏感，SD、GC、TI 各对 6、10、8 个变量敏感（SD 的 6 个中含源动登记与冻结概率组织的绑定关系；各项的敏感变量见附录 A），全部在按读出定义列出的 Dep\_X 之内，DepComplete\_X 都为 1，强度见 6.2；路径动力在单变量扰动下没有显出依赖，它按读出定义列入 Dep\_P\_I；时钟、记录、随机源、门承担状态与会话状态都没有显出依赖。窗内改变的变量都是某一窗内形成结构的承担变量（路径动力归于该维的律承担），没有未解释项；各类变量的个数见附录 A。路线的决定来源：P\_I 的承担结构（两维的律承担、绑定与率关系）在一般介质上，由概率形成脉冲在第 4、5 轮形成，路线经维到路径的固定映射由输入确定；它们不进入 SD、GC、TI 的承担，按 6.2 不审查 SelfRouted，FormInternal\_P\_I = 1，这是“外部输入诱发、场内完成形成”在一般结构上的形式层实例（P\_I 的意向特异部分即意向域位置，已由 Spec\_P\_I = 1 计入）。SD、GC、TI 的承担边由给定路线的场脉冲在第 86 轮形成，脉冲的终点正是被指定的承担者，输入指定，SelfRouted = 0，三项的 FormInternal 都为 0。FieldBorn = 1，ExternalInstall = 0，InternalSource = 0，分类为 Boundary。

所以参考构造是一段“已安置结构上的场内沉积形成”：沉积与成律确实在场内发生，而哪一条边承担哪一项职责、概率组织位于意向域，在边界上已经给定，形成后三项所用的路线也由输入给定。脚本对路线决定来源的判别，只覆盖参考模型中显式的给定路线，与事件组装代码中写定的入口路线（7.7；后者依读源码申报，脚本只核对路线以 sI 起头）；其他决定机制在这里没有出现，出现时按 6.2 记为材料不足。它不是意向从基础沉积场中的首次生成；那一构造交第二十一篇。

### 7.6 形成顺序

同一模型上三条合法历史（附录 A 的 order）：参考构造中，P\_I 在第 5 轮、其余三项在第 86 轮成立；两维的概率形成脉冲与五类场脉冲每轮一起施加时，四项同在第 6 轮成立；先单独施加 20 轮五类场脉冲、再每轮一起施加时，TI 在第 5 轮、SD 与 GC 在第 6 轮、P\_I 在第 26 轮成立。三条历史都取得资格，并且自首次为 1 起到最后一轮一直为 1；四项的成立顺序各不相同（定理七）。

### 7.7 不是首次形成的情形

这两个实例中，构造完成时回路边的开启（与参考构造相同）记为 H\_obs 中的一个事项，背景 Bg^Π 不变。

触发（u42）：评价点集的第一个点是候选的登记点，包含参考构造的 101 个点；构造完成以后开启一次源动会话，再施加一次组织事件，各取一个评价点。资格在第 86 轮首次为 1，会话与事件之后的两点都为 1；取事件之后的点为 τ，Genesis\_I^{Π,M}(τ) = 0。源动会话与组织事件是已成意向之内一次活动的起始，不是资格的形成。

恢复与重新形成：原候选从登记点起算，第 86 轮资格首次为 1；构造完成以后，只刷新其余各边与两维、不刷新源动段，直到源动段失去成律，资格形式读数为 0；再施加一次组织事件，它的路线经过源动段，资格形式读数回到 1。对原候选，这一点 Genesis\_I^{Π,M} = 0：更早的 1 在点集之内；只截去原候选的早段历史、仍用原候选，违反 1.4 的评价点集纪律。按 1.5，在侵蚀以后重新申报候选 χ̄\_I′：申报记录为“登记于侵蚀以后，第 2 次申报”，与 χ̄\_I 的声明摘要不同（职责身份的名称沿用）。它的评价点集为侵蚀后与事件后两点，读数 0、1，对 χ̄\_I′ 的形式层首次读数 Genesis\_I^{Π,M} = 1；背景为回路边可用；粒度为这一事件本身；削减把事件换成同样时长的空位（一个沉积时步的衰减与该事件自身的一步绑定衰减）。削减域为空历史与这一事件，空历史不充分，事件充分；事件把 sI→a1 由不成槽变为成槽，并进入 SD 的承担，形成连接为 1；只撤回这一事件在 sI→a1 上的痕迹，事件后的资格读数不再为 1，FormBear = 1。变化的种类是阈值越过：事件以前这条边仍有沉积（约 2.99），窗口内只剩一条重复记录，来自第 100 轮的 sd，不再成槽；事件补上第二条记录，使它重新成槽。所以这一事件承担的是当次的重新成形；这条边的结构首次生成在第 86 轮，事件以前所剩的沉积与记录来自原候选构造段的 sd（第 81 至 100 轮），不由这一事件承担。所以 χ̄\_I′ 的来源在形式层经认证，解族只含这一事件，承担谱 0100。路线的决定来源是输入指定：按模型源码（intent\_on\_fldb\_rnd\_v14.py 第 482 行），组织事件的路线以写定的入口 sI 起头，再接该维的载体路径与指定的门、调谐承担者；sI→a1 这一段由事件组装代码固定，是由输入种类经事前固定的映射确定的路线（这一判断来自读源码，是申报；附录 A 的读数只核对路线以 sI 起头），SelfRouted = 0；边界上的承担者指定与安置都在，分类为 Boundary。这正是《意向可达式》资格目标的那条路径：对原候选，它是可达的、不是首次形成；对重新申报的候选，它是已安置结构上的重新形成。

### 7.8 反例实例

非法删除：把边界上的源动承担者指定改掉再重放，改动的是 X\_0，Replayable = 0；强行重放所得的 τ 处读数为 0，但这不是反事实失败，也不使该指定成为必要来源。

背景使能：分别去掉五条安置边之一，从同样的历史重放（沿被去掉的边的脉冲换成空位），τ 处资格形式读数都为 0。这一比较换了 X\_0，在来源协议之内它同样是 Replayable = 0，不进入最小充分的判定；它只用来说明 W-I9：这些边在反事实上必要，但它们在 X\_0 中，不在 H\_obs 中，不进入来源候选域；它们是一般介质之外的意向特异安置（6.1、7.5），不是来源。

跨组织拼接：在四个独立的场中各只施加一项所需的脉冲（概率形成脉冲；sd；gA 与 gX；tA 与 tX），截至第 86 轮，四个场中各自那一项读为 1，意向资格都为 0，四个场的首次资格事件都不成立；四个场的运行身份互不相同，在 SD 场中形成的源动承担边，不在 P\_I 场那份候选的承担者之中，终点绑定为 0（定理五）。

### 7.9 封闭域与可达

封闭域（附录 A 的 closed\_domain）：从同一 X\_0 出发，输入类只含两维的概率形成脉冲（任意次序）。概率形成脉冲只沿该维固定的载体路径施加（probability\_on\_fldb\_rnd.py 第 126 至 132 行），两条载体路径 a1→m1→c、a1→m2→x 不含任何意向专用边；场只在被经过的边上写入沉积，衰减不使沉积增加（fldb\_work.py 第 20 至 33 行、第 61 至 76 行；FLDB 对脉冲方法的重写在第 342 至 359 行，除调用上述脉冲以外只更新路径动力与程度记录，不写沉积）；所以 D = { 意向专用边的沉积都为零的状态 } 含 X\_0，并对这一输入类封闭。SD 的读出为 1，须以 sI→a1 已沉积成槽为必要条件（intent\_on\_fldb\_rnd\_v14.py 第 70 至 74 行的 edge\_structural，由第 78 行与第 91 行的源动读出调用，第 106 至 112 行取合取）；在 D 上 sI→a1 没有沉积，SD 恒为 0。附录 A 以本地伪随机次序施加 100 轮作核对：意向专用边的沉积始终为零，SD 与资格的形式读数始终为 0，概率资格在其间成立；这也是“概率组织成立而没有源动驱动，不是意向”的形式层实例。于是这一输入类之内没有首次资格事件（6.7）。SD 的零是本组式新增原子的形式零，这一负证书停在形式层。同一输入类下，按脚本本地种子 0 的次序，参考程序在第 180 轮越过数值终点（附录 A 的 numeric\_failure\_first\_round，同《意向可达式》的 C\_num）；这不影响上述不变量论证。

来源与可达（附录 A 的 reach\_vs\_source）：同一 X\_0 上，只施加概率形成脉冲的实际历史（截至第 86 轮共 172 个事件）没有首次资格事件，来源记 OutDom，解族为空；而施加五类场脉冲的参考构造是到达资格的一条合法路径，形式层可达。反过来，参考构造的来源在形式层经认证（7.4），而只许可概率形成脉冲的可达任务有上述封闭域负证书，形式层不可达（定理十）。

## 第十节　击穿方式

K-ISRC1　正来源反例：已签 IGenesisSource(H\_s) = 1，但合法重放 H\_s 到 τ 时 N\_I = 0。  
K-ISRC2　隐藏外部依赖：宣称实际生成链已经完整，实际还依赖未申报的外部历史或变量。  
K-ISRC3　实际链伪连：所签的来源历史只是相关、使能、同步或旁观，并没有真实进入终点四项的形成。  
K-ISRC4　最小性反例：已判 MinSuff(H\_s) = 1，却发现合法严格削减 H′ ≺\_Π H\_s 仍 Suff(H′) = 1。  
K-ISRC5　必要来源反例：已判 NecessarySourceCarrier(h) = 1，却发现另一份合法最小充分来源不含 h。  
K-ISRC6　来源域误闭合：已判 Source = 0 或 NonSourceCarrier = 1，后来发现空历史充分或遗漏了合法来源候选。  
K-ISRC7　跨组织拼接：所签来源的形成见证进入了另一组织、另一运行或另一资格锚的承担。  
K-ISRC8　预装漏审：已签 InternalSource = 1，却发现某一项的职责指定在边界上已经给定，或某一项的形成事项由输入点名承担者、或经外部编辑取得。  
K-ISRC9　上游未成立：某项被签为窗内形成并进入终点承担，但该项的上游判据在 τ 处实际不成立。  
K-ISRC10　源式与稳定式、动力式偷换：把已成意向以后四项的变化、失效、恢复或迁移写成首次来源。  
K-ISRC11　非法形成：所签的形成见证使用了 Dyn^Π 以外的动力、申报输入以外的输入，或窗内有未申报的写入改动了承担结构或承担者指定。  
K-ISRC12　封闭域误签：已签封闭域负证书，却发现 D 在申报的输入类下有离开 D 的合法后继，或所用的承担结构并不是 X 为 1 的必要条件。  
K-ISRC13　唯一来源反例：已在闭合的判定域内签出单元素解族（如第七节 7.4，相对于冻结的粒度与削减域），却发现另一份合法最小充分来源。  
K-ISRC14　形成承重误签：已签 FormBear(g; H\_s) = 1，却发现只撤回 s\_g 的痕迹以后 H\_s 仍然充分；或所签的形成见证实际只是另一必要事项的副产物。  
K-ISRC15　变化种类误判：所签的形成实际是重新启用、指定改变或读出改变，不是结构生成或阈值越过；或把阈值越过记成了结构的首次来源。  
K-ISRC16　依赖漏列：已签 FormInternal\_X = 1，却发现 X 的读出依赖一个不在 Dep\_X 中、且在窗内改变过的状态变量；或路线实际由未申报的映射决定。

按《法篇》，只有在宣称必要来源或唯一来源时，“目标结构在该过程缺席时仍然发生”才构成击穿；这里对 NecessarySourceCarrier 的判定（K-ISRC5）与在闭合判定域内签出的唯一来源（K-ISRC13）承担这一击穿。一般命题层面不宣称唯一来源（定理六）。

    subs = [S - frozenset(x) for k in range(1, len(S) + 1) for x in itertools.combinations(sorted(S), k)]

    if all(R[T]['replayable'] is True and R[T]['suff'] is False for T in subs): return True
    return None

def probe(I):
    """Single-variable dependency probe at tau: perturb each inventory variable alone, record which readings change."""
    base = qual(I); hits = {it: [] for it in ITEMS}
    for name, _, pert in inventory(I):
        J = copy.deepcopy(I)
        try:
            pert(J); q = qual(J)
        except Exception:
            q = {it: '⊥' for it in ITEMS}
        for it in ITEMS:
            if q[it] != base[it]: hits[it].append(name)
    return hits

def struct_edges(s):
    if s.startswith('law_') or s.startswith('bind_'): return list(DIMS_R[s[-1]])
    if s == 'rate_R': return [e for r in DIMS_R.values() for e in r]
    _, a, b = s.split('_'); return [(a, b)]

def carrier_vars(s):
    """All state variables that carry a structure (used to classify Dep_X): sediment of its carrier edges, deposits of
    their end nodes, binding, and the path dynamics of a dimension's carrier path."""
    es = struct_edges(s); v = [('sed',) + e for e in es] + [('d', n) for n in sorted({n for e in es for n in e})]
    if s.startswith('bind_'): v = [('bind', s[-1])]
    if s.startswith('law_'): v += [('pathdyn', s[-1])]
    if s == 'rate_R': v += [('pathdyn', k) for k in sorted(DIMS_R)]
    return v

def withdraw_vars(s):
    """Wd withdraws the variables on the structure's carrier edges (sediment and repetition records), binding and the
    dimension's path dynamics; node deposits, shared by every structure through a node, are not withdrawn."""
    return [v for v in carrier_vars(s) if v[0] != 'd']

def generation_vars(s):
    """Variables that decide generation versus threshold crossing: carrier-edge sediment and repetition records,
    binding.  Node deposits (shared) and path dynamics (initialised non-empty) do not take part."""
    return [v for v in carrier_vars(s) if v[0] in ('sed', 'bind')]

def _sed_empty(x): return x[0] == 0.0 and not x[1]

def formation_events():
    """Last 0 -> 1 transition of each structure in the actual history; writers (atoms whose events traced its carrier
    edges up to the transition); the kind of change at the transition (section 3.6 (一))."""
    w = window(); evs = w['evs']; st_tau = evs[-1]['st']; st0 = w['X0']['structures']; v0 = w['X0']['vars']; out = {}
    for s in st_tau:
        if st_tau[s] is not True: out[s] = None; continue
        seq = [st0[s]] + [e['st'][s] for e in evs]
        ups = [i for i in range(1, len(seq)) if seq[i] is True and seq[i - 1] is not True]
        if not ups: out[s] = None; continue
        j = ups[-1] - 1; e = dict(evs[j]); es = struct_edges(s)
        wev = [x for x in evs[:j + 1] if x['route'] and set(es) & set(zip(x['route'], x['route'][1:]))]
        writers = sorted({x['atom'] for x in wev}); writer_events = tuple(x['idx'] for x in wev)
        pre = v0 if j == 0 else evs[j - 1]['vars']; post = evs[j]['vars']
        switch = any(pre[(k,) + x] != post[(k,) + x] for x in es for k in ('Avail', 'mask', 'th', 'topo'))
        desig = not evs[j]['designations_unchanged']
        writer_at = e['atom'] in writers and bool(e['route']) and bool(set(es) & set(zip(e['route'], e['route'][1:])))
        # "before": before the first writer event (in this window no other event writes these variables, so X0)
        first_w = min(i for i, x in enumerate(evs[:j + 1]) if x['idx'] in writer_events) if writers else j
        before = v0 if first_w == 0 else evs[first_w - 1]['vars']
        empty0 = all(_sed_empty(before[v]) for v in generation_vars(s))
        if writer_at and (switch or desig): ctype = 'mixed'
        elif switch and desig: ctype = 'mixed'
        elif switch: ctype = 'enabling'
        elif desig: ctype = 'designation'
        elif not writer_at: ctype = 'other'
        else: ctype = 'generation' if empty0 else 'threshold_crossing'
        e['change_type'] = ctype; e['writers'] = writers; e['writer_events'] = writer_events
        out[s] = e
    return out

FORMATION_TYPES = ('generation', 'threshold_crossing')   # change types that can carry a formation (section 3.6)
EVENT_KINDS = {'p': 'formation pulse', 's': 'field pulse', 'g': 'field pulse', 't': 'field pulse'}
def external_edit_events(H):
    """Events of H_obs whose kind is a declared external edit (registry or state write): none of the kinds used."""
    return sum(1 for ev in H if EVENT_KINDS.get(ev[0][0]) not in ('formation pulse', 'field pulse'))

def no_priv_write():
    """NoPrivWrite holds by construction (the window only calls the model's pulses and decay steps); checked per event:
    the designations and the generic probability-layer items are never changed."""
    w = window()
    return all(e['designations_unchanged'] and e['prob_generic'] == w['X0']['prob_generic'] for e in w['evs'])

def _snap(I, vs):
    b = {}
    for v in vs:
        if v[0] == 'sed': e = v[1:]; b[v] = (I.F.g[e], copy.copy(I.F.rep[e]))
        elif v[0] == 'bind': b[v] = (I.P.bind[v[1]], list(I.P.bind_rep[v[1]]))
        elif v[0] == 'pathdyn': b[v] = list(I.F.pathdyn[v[1]])
    return b

def _withdraw(I, b):
    """Wd for the reference instance: withdraw the event's traces on the listed variables, keep its own decay step."""
    for v, x in b.items():
        if v[0] == 'sed':
            e = v[1:]; I.F.g[e] = max(0.0, x[0] - I.F.lam_g); I.F.rep[e] = x[1]
            while I.F.rep[e] and I.F.t_sed - I.F.rep[e][0] > I.F.W: I.F.rep[e].popleft()
            I.F.Om[e] = I.F._omega(e)
        elif v[0] == 'bind': I.P.bind[v[1]] = max(0.0, x[0] - I.P.bind_decay); I.P.bind_rep[v[1]] = x[1]
        elif v[0] == 'pathdyn': I.F.pathdyn[v[1]] = x

def replay_wd(H, keep, wev, sset):
    """Replay the kept events; after each event whose index is in `wev` (the witness's exact events H_g), apply Wd to
    the structures in `sset`.  Returns the three-valued reading of N_I at tau and, for each structure of sset, its
    reading at tau and the index of the event of its last 0 -> 1 transition in this replay."""
    I = blank(); vs = sorted({v for s in sset for v in withdraw_vars(s)}); wev = set(wev)
    prev = {x: structures(I)[x] for x in sset}; last = {x: None for x in sset}
    for i, ev in enumerate(H):
        k = ev[0] in keep
        if k and i in wev:
            b = _snap(I, vs); do_event(I, ev, True); _withdraw(I, b)
        else:
            do_event(I, ev, k)
        if k:
            st = structures(I)
            for x in sset:
                if st[x] is True and prev[x] is not True: last[x] = i
                prev[x] = st[x]
    return qual(I)['Intent'], {x: dict(at_tau=prev[x], last_up_event=last[x]) for x in sset}

def replay_formed(S):
    """In the plain replay of S: for each structure, the index of the event of its last 0 -> 1 transition and its reading at tau."""
    key = ('rf', S)
    if key in _C: return _C[key]
    _, _, evs = run_points(window()['H'], keep=set(S), record_events=True)
    st0 = window()['X0']['structures']; out = {}
    for s in st0:
        seq = [st0[s]] + [e['st'][s] for e in evs]
        ups = [i for i in range(1, len(seq)) if seq[i] is True and seq[i - 1] is not True]
        out[s] = dict(at_tau=seq[-1], last_up_event=(evs[ups[-1] - 1]['idx'] if ups else None))
    _C[key] = out; return out

def form_bear(S, wev, sset):
    """FormBear(g; H_s), three-valued (section 3.6 (四)); g is given by its exact events wev (indices into H_obs) and
    its structures sset.  The withdrawal must actually cancel g's formation: if a structure of g is still formed by an
    event of g in the withdrawal replay, the reading is ⊥."""
    key = ('fb', S, tuple(sorted(wev)), tuple(sorted(sset)))
    if key in _C: return _C[key]
    R = reduction()
    if R[S]['replayable'] is not True or R[S]['suff'] is None: v = None
    elif R[S]['suff'] is False: v = False
    else:
        rf = replay_formed(S)
        same = all(rf[s]['at_tau'] is True and rf[s]['last_up_event'] in set(wev) for s in sset)
        if not same: v = False
        else:
            r, wst = replay_wd(window()['H'], set(S), wev, sset)
            if any(x['at_tau'] is True and x['last_up_event'] in set(wev) for x in wst.values()): v = None
            elif r is None: v = None
            else: v = (r is False)
    _C[key] = v; return v

def witnesses_of(S):
    """Formation witnesses available in S: one per structure; H_g is the exact writer events up to the transition (all
    of whose atoms must lie in S); the atom set is used only for candidate membership and carrier reports."""
    w = window(); fe = formation_events(); q_tau = w['pts'][w['tau']]; dep = w['X0']['dep']; out = []
    for s, e in fe.items():
        if e is None or e['change_type'] not in FORMATION_TYPES: continue
        if not set(e['writers']) <= set(S): continue
        eb = {it: (q_tau[it] is True and s in dep[it]['structures']) for it in ITEMS}
        if any(eb.values()): out.append(dict(atoms=tuple(e['writers']), events=tuple(e['writer_events']), structures=(s,), EndBind=eb))
    return out

def bearing_witnesses(S):
    """Single-structure witnesses with FormBear, and minimal composite witnesses (unions of the exact events and
    structures of non-bearing single witnesses) whose withdrawal breaks sufficiency while that of every proper sub-union
    does not (section 3.6 (四)).  A union with a proper sub-union read ⊥ cannot be shown minimal and is recorded as ⊥."""
    key = ('bw', S)
    if key in _C: return _C[key]
    ws = witnesses_of(S)
    for x in ws: x['bear'] = form_bear(S, x['events'], x['structures'])
    tested = []
    if reduction()[S]['suff'] is True:
        nb = [i for i, x in enumerate(ws) if x['bear'] is False]
        found = []; bot = []; base = list(ws)
        for k in range(2, len(nb) + 1):
            for comb in itertools.combinations(nb, k):
                if any(f < set(comb) for f in found): continue
                xs = [base[i] for i in comb]
                atoms = tuple(sorted({a for x in xs for a in x['atoms']})); evx = tuple(sorted({i for x in xs for i in x['events']}))
                ss = tuple(sorted({t for x in xs for t in x['structures']}))
                b = form_bear(S, evx, ss)
                if b is True and any(f < set(comb) for f in bot): b = None
                tested.append(dict(structures=ss, events=len(evx), bear=t3(b)))
                if b is True: found.append(set(comb))
                if b is None: bot.append(set(comb))
                if b is not False:
                    ws.append(dict(atoms=atoms, events=evx, structures=ss, EndBind={it: any(x['EndBind'][it] for x in xs) for it in ITEMS},
                                   bear=b, composite=True))
    _C[key] = ws; _C[('ct', S)] = tested; return ws

def numeric_horizon(max_rounds=400, seed=0):
    """Round at which the reference program first fails numerically (OverflowError) under the same input class."""

    return None

def abstract_eval(atoms, suff, witnesses, genesis=True, spec=None):
    """atoms: H_obs; suff: frozenset -> bool; witnesses: list of (atom set, field 0/1, endbind {item:0/1});
    genesis: the three-valued first-qualification event at tau; spec: {item: 0/1} at the boundary.
    Every history is replayable.  With genesis not 1 the core is not 1 for any candidate."""
    dom = [frozenset(S) for k in range(len(atoms) + 1) for S in itertools.combinations(atoms, k)]
    R = {S: dict(replayable=True, suff=suff(S)) for S in dom}
    W = [(x + (1,)) if len(x) == 3 else x for x in witnesses]     # (atoms, field, endbind, bear)
    def link(S, bearing=True):
        # bear is the declared FormBear in a sufficient candidate; in an insufficient candidate FormBear = 0 (section 3.6)
        ws = [bool(f) and any(eb.values()) and ((bool(b) and R[S]['suff'] is True) or not bearing) for g, f, eb, b in W if set(g) <= S]
        return or3(*ws) if ws else False
    cands = [S for S in dom if S]
    fam = [S for S in cands if and3(genesis, link(S), minsuff(S, R)) is True]
    sdd = genesis and R[frozenset()]['suff'] is False and all(minsuff(S, R) is not None for S in cands if link(S))
    out = dict(family=[sorted(S) for S in fam], Genesis=t3(genesis),
               Source='OutDom' if genesis is False else 1 if (sdd and fam) else 0 if sdd else '⊥',
               empty_sufficient=t3(R[frozenset()]['suff']),
               spectrum={'+'.join(sorted(S)): ''.join(str(int(any(set(g) <= S and f and b and eb.get(it) for g, f, eb, b in W))) for it in ITEMS) for S in fam})
    fam_nb = [S for S in cands if and3(genesis, link(S, False), minsuff(S, R)) is True]
    if fam_nb != fam or any(len(x) == 4 for x in witnesses):
        out['without_bearing_rule'] = dict(family=[sorted(S) for S in fam_nb],
            spectrum={'+'.join(sorted(S)): ''.join(str(int(any(set(g) <= S and f and eb.get(it) for g, f, eb, b in W))) for it in ITEMS) for S in fam_nb})
    if spec is not None:
        # FormInternal_X from the witnesses: X is 0 at X0 (Spec_X = 0 and not held), so it needs a window formation
        fi = {it: (1 if any(f and eb.get(it) for g, f, eb, b in W) else '⊥') for it in ITEMS}
        no_pre = all(spec[it] == 0 for it in ITEMS)
        fb = any(f and b and any(eb.values()) for S in fam for g, f, eb, b in W if set(g) <= S)
        out.update(FieldBorn=int(fb), NoPreinstalledIntent=int(no_pre), FormInternal=fi,
                   InternalSource=int(bool(fam) and no_pre and all(fi[it] == 1 for it in ITEMS)))
    return out

    out['single_item'] = abstract_eval(['hS'], lambda S: False, [(('hS',), 1, {it: int(it == 'SourceDrive') for it in ITEMS})],
                                       genesis=False)
    # four items formed in four runs, each run's candidate has only its own item: no candidate has a first event
    out['four_runs'] = {it: abstract_eval(['h'], lambda S: False, [(('h',), 1, {x: int(x == it) for x in ITEMS})], genesis=False)['family']
                        for it in ITEMS}
    return out

            order=cmd_order, closed_domain=cmd_closed_domain, reach_vs_source=cmd_reach_vs_source, trigger=cmd_trigger,
            recovery=cmd_recovery, illegal_delete=cmd_illegal_delete, background=cmd_background, splice=cmd_splice,

def _round(x):
    if isinstance(x, float): return float('%.12g' % x)
    if isinstance(x, dict): return {str(k): _round(v) for k, v in x.items()}
    if isinstance(x, (list, tuple)): return [_round(v) for v in x]
