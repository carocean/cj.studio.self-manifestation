# 意向稳定式

意向资格已经成立。在许可的变化与合法的后继轨迹中，它保持下来了吗？什么时候第一次真正失效？失效以后能不能复归？复归回来的，又是什么在保持？

结论是：意向的稳定，不是某一组实现始终不变，也不是作用、脉冲或欲门切换一直在发生。判一份稳定主张以前，必须先说明要保持的是哪一个身份：原来申报的那一段资格，同一组被指定的承担者上的资格，还是事前冻结的候选承担者中有某一个始终合格，或每一时刻都有某一个合格。原段一旦退出就不能复入，退出以后的再次成立要重新申报为新段；同一承担者上的复归，必须后置于一次实际取得的首次失效，在申报期限内回到资格并持续到观察窗末，且经过验证长度；“每一时刻都有某个承担者合格”不推出“有某个承担者每一时刻都合格”。内部见证可以全部更换而承担者与资格不变；分量各自稳定，合取不必稳定；单条轨迹、声明的轨迹族与全部合法轨迹三个层级的强度不同，不得互相冒充。复归回来的组织与原组织在本体上是否同一，本篇不能证明，只给出可审查的分层关系。

## 第一节　对象申报

### 1.1 式种与唯一任务

稳定式，附式，独立成篇。按《法篇》第四编第十五章稳定式规范：对象是已经成立的资格；先冻结身份层、许可变化域、观察协议与轨迹，再判保持、实际失效与复归；固定对象的保持与存在层的保持分开；复归后置于首次实际失效；边界须实际取得；单轨迹、轨迹族与全部合法轨迹的量词不得偷换。

进入条件按该章逐项落实：被稳定的资格已有闭合定义，并在入口上成立（1.2、1.3）；稳定对象的身份层级已经声明（1.6）；许可变化域预先声明（1.3、1.4），变化后的资格由上游的四项同锚核在每一评价点上重算，不沿用变化以前的读数（1.2、3.2）；动态复归所用的合法后继动力取《意向运行基底构造式》的场动力与运行基底动力，时间域与观察协议由本篇 1.3、3.1 申报；声明全部合法轨迹上的保证时，合法轨迹全集按 5.11 界定，不可判的轨迹不删去。

唯一任务：已经成立的意向资格，在事前冻结的许可变化域与合法后继轨迹中，以什么身份、在什么量词层级上保持、实际失效与复归。分为六问：

（一）原申报段能否在观察窗内保持；  
（二）同一组指定承担者上的资格，失效以后能否在申报期限内复归并经过验证；  
（三）事前冻结的候选承担者中，是否有某一个在整个窗内保持（∃e∀t）；  
（四）候选承担者中，是否每一时刻都有某一个合格（∀t∃e），断档以后能否复归；  
（五）内部见证的更替，是否改变上述各层的判词；  
（六）上述主张在单轨迹、声明轨迹族、全部合法轨迹三个层级上分别达到什么强度。

不研究：意向资格是否成立（《意向一般式》《意向必然式》《意向判定式》）；资格的硬边界在哪里（《意向极限式》）；从给定初态能否到达（《意向可达式》）；资格首次成立由什么历史形成，包括重新申报的新段的形成（《意向源式》）；已有结构怎样在场中运行（《意向运行基底构造式》）；意向怎样从基础沉积场中生成（第二十一篇）；意向此刻怎样作用、怎样切换欲门、有无动力（作用、欲门切换、动力各篇）。不新增第五项资格，不新增本体 H，不改写上游任何定义。

六种闭合在这里分开：

&nbsp;&nbsp;&nbsp;&nbsp;资格闭合　　　四项结构在评价点上成立　　　　　　　　　可签当时的意向资格  
&nbsp;&nbsp;&nbsp;&nbsp;运行闭合　　　已有结构在场中实际运作　　　　　　　　　可签已有意向的运行  
&nbsp;&nbsp;&nbsp;&nbsp;路径闭合　　　从给定初态有合法路径到达　　　　　　　　可签指定任务下的可达  
&nbsp;&nbsp;&nbsp;&nbsp;来源闭合　　　首次成立由认证的实际历史承担　　　　　　可签给定协议下的来源  
&nbsp;&nbsp;&nbsp;&nbsp;保持闭合　　　冻结身份层上逐点都为 1　　　　　　　　　可签该层、该窗、该轨迹上的保持  
&nbsp;&nbsp;&nbsp;&nbsp;复归闭合　　　实际首次失效之后，在期限内回到 1 并持续到窗末，经过验证长度　　可签该层、该协议下的复归

前一种闭合不推出后一种；保持与复归都只对所申报的身份层、观察协议与轨迹成立。

### 1.2 上游冻结结构

&nbsp;&nbsp;&nbsp;&nbsp;N\_I := P\_I ∧ SD ∧ GC ∧ TI

SD、GC、TI 分别记 SourceDrive(𝒫\_I)、GateCorrespondence(𝒫\_I; 𝒢\_I)、TuneInterface(𝒢\_I)；P\_I := InIntentDomain(𝒫\_I) ∧ Probability(𝒫\_I; C\_I, 𝔯\_I)。四项落在同一意向组织与同一资格锚上。《意向一般式》：Intent ⇒ N\_I；《意向必然式》：N\_I ⇒ Intent；两个方向都 Established，不携 H。

形式层：《意向数理式》给出 IntentCoreCert^M 及各项的形式读数。形式读数为 1 回读对象层，按所用 Law-bearing 见证承继 H\_LawRead；形式读数为 0 回读对象层，按《意向判定式》，概率一侧的负读携 H2 ∧ H3^red 与相应失败路径的 H^-\_M 或 H\_ρRep^-，本组式新增原子的形式零不回读为结构零（IntentAtomRepOpen）。这些是上游的回读条件，不是这里新增的 H。

资格不是作用。资格读的是已经沉积成立的职责结构，不是当前是否发生脉冲、源动会话是否开启、意向侧某一条边当前是否可以穿越。《意向运行基底构造式》的资格读出器按此设计：当前的停发、意向侧五条边的可用性设置属于发生与作用，不抹去已经成立的结构资格。运行层的可用性关闭可以切断概率组织的载体，使资格退出（该篇 V4）；那是资格的变化，不是发生的变化。所以本篇的一切资格读数都调用上游的四项同锚核，不用作用次数、脉冲频率、切换是否发生代替（第七节 7.2）。

### 1.3 稳定实例

一次稳定考察以一个冻结的稳定实例为对象：

&nbsp;&nbsp;&nbsp;&nbsp;Σ\_I^st = (χ̄\_I, X\_st, 𝒞\_I, Elig\_I, Δ\_I, Dyn, Judge, H)

χ̄\_I：原申报段的跨时冻结声明，同《意向源式》1.3：χ̄\_I = (F, 𝒫\_I, C\_I, 𝔯\_I, V\_I, Anc\_I, Duty\_I, Rec\_I)，Rec\_I 是申报记录（登记点与申报序号）。

X\_st：入口状态。对原段，入口就是登记点；对退出以后重新申报的新段，登记点在再成立以前（1.6），入口取登记以后首次读为 1 的评价点。入口上所用判词须给出资格 1。入口资格不是 1 时，稳定问题不成立：入口为 0 记 OutDom，入口为 ⊥ 记 ⊥。

𝒞\_I：事前冻结的候选承担者域。每一个成员 e 是一个宿主（一个场及其上的运行基底）连同它的承担者指定 Des\_e（哪一条边承担源动、哪一维对应哪一个门职责、哪一个门节点承担门职责、哪一条门后边承担调谐、哪一概率组织申报为位于意向域，同《意向源式》1.3 的 Des\_I）。原段的承担者记 e\_0 ∈ 𝒞\_I。𝒞\_I 另带一个申报 DomClosed\_I ∈ {1, 0}：为 1 时，候选域作为负判的论域已经闭合；为 0 时，存在层只能正判。

Elig\_I：同任务候选标记，事前由各成员的冻结申报计算，不在失效以后改动（1.5）。

Δ\_I：许可变化类。只许可运行基底合法控制集中的操作与申报的扰动操作；不许可写入资格读数或其派生标签，不许可改动 χ̄\_I、Des\_e、𝒞\_I、Elig\_I 与 H。

Dyn：《意向运行基底构造式》的场动力与运行基底动力。

Judge：资格判词。形式层取 IntentCoreCert^M，记 Q^M；对象层取《意向判定式》的 Det\_I，记 Q；以对象层的结构事实为判词时取 Intent\_t 本身（N\_I ⇔ Intent，两个方向都 Established）。

H = (Pts, c, T\_obs, T\_rec, h)：观察协议。Pts 是评价点规则；c 是时钟，把每一评价点映到一个时刻；T\_obs 是观察窗；T\_rec 是恢复期限；h 是验证长度。五项都事前冻结。

### 1.4 冻结纪律

χ̄\_I、各 Des\_e、𝒞\_I（包括 DomClosed\_I）、Elig\_I、Δ\_I 与 H 都在稳定考察开始以前冻结，不得在失效以后修改。改动其中任一项以后成立的东西，不属于原稳定实例的保持或复归，而是另一个稳定实例。尤其不得在看到断档以后把新出现的承担者补进 𝒞\_I，再宣称“从未断档”；不得在看到失效以后放宽 T\_rec 或缩短 h，再宣称“已复归”；不得把另一任务的承担者改记为同一任务。

承担者指定在窗内被改写，比照《意向源式》3.6 属于指定改变：它不是场内的保持或复归，承担者已经换了申报身份，读数随之离开该承担者的稳定考察，按 1.7 记 OutDom。

### 1.5 同任务候选标记

Elig\_I(e) ∈ {1, 0}：e 的冻结申报中的职责身份（源动、欲门与调谐职责的身份）、Des\_e 中维与门职责的配对、正式维与方向域，与原段的冻结申报及 Des\_{e\_0} 逐项相同，为 1；否则为 0。它在考察开始以前对 𝒞\_I 的每一成员算出，此后不变。

Elig\_I 是比较协议，不是第五项资格，也不是身份认证。它只说“按冻结的职责比较，e 被申报为承担同一任务的候选”；不说 e 与 e\_0 是同一组织，不说 e 从 e\_0 处承接了什么，不说两者之间有任何因果或登记上的交接。所以在 Elig\_I 之上只能定义存在层的读数（第四节 4.6）；任何关于“承接”的主张，都须另有交接证书，这在本篇没有构造（O-ST3）。

### 1.6 四个身份层

意向的稳定必须先说明保持的是哪一个身份。四层如下（后三层之间的蕴含见定理三）：

见证层：承担结构当时所依的内部见证，例如承担边上的重复记录、某几次具体的事件。见证可以逐一更换。

原段层：原申报段 S\_0 = (χ̄\_I, e\_0)，自入口起（对 S\_0 即登记点），到资格首次确定为 0 为止。资格 1 → 0 时原段越过资格边界（QualExit），按《意向极限式》第五节命题 11“重新形成不是原段复入”（经《意向源式》1.5 用于资格段），原段不复入；此后再成立的资格属于重新申报的新段 S′，S′ 的申报记录 Rec′ 不同于 Rec\_I，登记点在原段退出以后、再成立以前（《意向源式》1.5）。

固定承担者层：同一个 e，即同一宿主上同一组冻结指定 Des\_e。它可以跨段：原段退出以后，同一组指定承担者上资格再成立，属于这一层的复归问题；是否复归，按 4.2 的七项判定。这里的“同一”是申报记录的同一：宿主与 Des\_e 在窗内没有改写。它不是被复归的组织与原组织在本体上同一的证明（第六节）。

存在层：𝒞\_I 中 Elig\_I = 1 的承担者。分两种量词：某一个承担者在整个窗内都合格（∃e∀t），或每一时刻都有某一个承担者合格（∀t∃e）。

见证层的更替不是承担者的更替；固定承担者的复归不是原段的复入；存在层的不断档不是同一承担者的持续。

### 1.7 三值、两层与工作域

每一评价点上的资格读数取 1、0、⊥。失效只收确定的 0；⊥ 既不算失效，也不算保持。

形式层与对象层分别登记。形式层的 0 不自动成为对象层的 0：对象层的负读须按 1.2 的条件取得，本组式新增原子的形式零记 ⊥（IntentAtomRepOpen）；形式层的 1 回读对象层须所用见证的 H\_LawRead 已关闭，否则记 ⊥（LawReadOpen）。

OutDom 与 0、⊥ 都不同。下列情形记 OutDom，不记失稳：入口资格为 0；稳定实例的冻结项被改动；程序在操作中途数值失败，后继不存在（同《意向可达式》：一切历史都由已完成的操作组成，操作中途失败不产生后继）。

## 第二节　默认稳定主张的排除

以下是容易被当作稳定、失效或复归的说法，都是不成立的推出；有的由定义直接得到，有的由定理或参考实例确立，依据见所注各处。

W-S1　发生冒充资格：源动停发、意向侧的可用性关闭、一段时间没有脉冲 ⇏ 资格退出（1.2，第七节 7.2；无脉冲见 7.4 γ\_idle 第 1 至 10 轮）。运行层对概率载体的可用性关闭可以使资格退出（1.2），不在此列。  
W-S2　运行冒充保持：组织事件持续发生 ⇏ 资格保持（第七节 7.4）。  
W-S3　端点抽样冒充保持：Q(t\_0) = Q(t\_end) = 1 ⇏ Keep = 1（定理七，第七节 7.5）。  
W-S4　粗粒度抽样冒充逐点保持：每轮末都有承担者合格 ⇏ 每一评价点都有承担者合格（定理七，第七节 7.7）。  
W-S5　原段复入：1 → 0 → 1 ⇏ 原段保持，也 ⇏ 原段复归（4.4，定理八）。  
W-S6　瞬时再成立冒充复归：失效以后某一点读到 1 ⇏ Recover = 1（定理五，第七节 7.5）。  
W-S7　期限重置：后来又失效一次，从后一次失效起算期限 ⇏ 合法的复归判定（定理五，第七节 7.8）。  
W-S8　下确界冒充首次实际失效：inf Fail ⇏ 实际失效点（3.3）。  
W-S9　不断档冒充同一承担者持续：∀t∃e ⇏ ∃e∀t（定理四，第七节 7.7）。  
W-S10　跨任务拼接：不同任务的承担者轮流合格 ⇏ 该任务不断档（定理九，第七节 7.7）。  
W-S11　见证更替冒充承担者更替，或承担者不变冒充见证不变（定理十，第七节 7.3）。  
W-S12　分量各自稳定冒充合取稳定：Stable(SD) ∧ Stable(GC) ⇏ Stable(Q)（定理六，第七节 7.8）。  
W-S13　单轨迹或轨迹族冒充保证：一条或几条轨迹稳定 ⇏ 全部合法轨迹稳定（定理十一，第七节 7.9）。  
W-S14　资格边界冒充稳定边界（定理十二，第七节 7.10）。  
W-S15　形式零冒充对象零：Q^M = 0 ⇏ Q = 0（1.7，第七节 7.11）。  
W-S16　记录同一冒充本体同一：同一宿主、同一组指定、同一运行身份、同一任务名 ⇏ 复归的组织与原组织同一（第六节）。  
W-S17　数值终点冒充失效：程序在操作中途数值失败 ⇏ Q = 0（1.7）。  
W-S18　事后改动冻结项以后仍称原实例（1.4）。  
W-S19　高概率不变冒充稳定：多数轨迹或大概率下保持 ⇏ 稳定；稳定按所声明的量词层级逐条轨迹判定（定理十一）。  
W-S20　原见证移出冒充失稳：入口处的见证全部移出 ⇏ 资格失稳；须检查同层的替代见证（定理十，第七节 7.3）。  
W-S21　未覆盖的窗冒充保持：轨迹没有覆盖观察窗，以缺失部分使“一切评价点都为 1”空真 ⇏ Keep = 1（定理七）。  
W-S22　局部结果冒充稳定：极限边界、可达路径或必然后果中的局部结果 ⇏ 稳定式的结论（第十一节）。

## 第三节　评价点、即时读数与首次实际失效

### 3.1 评价点与时钟

Pts：评价点的冻结规则。参考实例取：入口一点，以及每一个许可操作完成以后一点；几个宿主同时考察时，各宿主在同一轮内按申报的次序执行，每一操作以后对全部宿主读数。c(t)：评价点 t 所在的轮次，入口为第 0 轮。期限与验证长度都以轮计。

在参考运行基底中，系统状态只在操作中改变；操作以后读数，覆盖了两次操作之间存在的全部状态。操作内部的中间状态不是本协议粒度下的系统状态。对连续时间的主张须另有段内事件记录与覆盖证书；本篇对连续时间不作主张（O-ST5）。

### 3.2 各层的即时读数

固定承担者层：Q\_e(t) 为宿主 e 在 Des\_e 之下、在评价点 t 的资格读数（形式层 Q\_e^M(t)，对象层 Q\_e(t)）。

原段层：Q\_{S\_0}(t) := Q\_{e\_0}(t)，只在原段存续的点上有定义，即从入口（1.3）到资格首次确定为 0 的点为止。

存在层：

&nbsp;&nbsp;&nbsp;&nbsp;Q\_∃(t) := ∨₃ { Q\_e(t) : e ∈ 𝒞\_I, Elig\_I(e) = 1 }

三值析取：至少一个为 1 取 1；全部为 0 且 DomClosed\_I = 1 取 0；其余取 ⊥。DomClosed\_I = 0 时，“已检索的承担者都为 0”不给出 0，只给出 ⊥。

见证层：W\_e(t) 为 e 的各承担结构在 t 所依的内部见证集合。参考实例取各指定承担边上的重复记录；两维的绑定记录另行计数，不计入 W\_e。

### 3.3 失效时集与首次实际失效

对一条读数序列 Q(·)：

&nbsp;&nbsp;&nbsp;&nbsp;Fail(Q) := { t ∈ Pts ∩ T\_obs : Q(t) = 0 }

只收确定的 0。

FirstFail(Q) = b：b ∈ Fail(Q)，且一切 t \< b 有 Q(t) = 1。若在第一个确定的 0 以前有 ⊥，FirstFail = ⊥：不能排除更早的失效。若 Fail(Q) 非空而其下确界不属于 Fail(Q)（例如连续时间中 Fail = (3, 4\]，3 处读数不为 0），下确界未实际取得，不是实际失效点，FirstFail = ⊥。这里的 ⊥ 表示首次实际失效没有取得、复归无从签出，读数全部确定时也如此；Recover 按 4.2 记 ⊥，窗末为 0 时记 0。若 Fail(Q) 为空且全部为 1，记 FirstFail = none；若 Fail(Q) 为空而有 ⊥，FirstFail = ⊥。

在有限的离散评价点集上，确定的 0 中最早的一个总是实际取得的；“首次失效”的困难只在它以前的 ⊥ 与连续时间的下确界两处。

## 第四节　保持、复归与稳定

### 4.1 保持

&nbsp;&nbsp;&nbsp;&nbsp;Keep(Q) := ∧₃ { Q(t) : t ∈ Pts ∩ T\_obs }

三值合取：任何一点为 0 取 0；全部为 1 取 1；其余取 ⊥。保持要求逐点，不要求逐轮或只看两端。

### 4.2 复归

Recover(Q) 取 1，须同时满足：

（一）入口为 1；  
（二）首次实际失效取得：FirstFail(Q) = b，b 是评价点；  
（三）存在复归点 t\_r \> b，自 t\_r 起到观察窗的最后一点，各点都为 1；  
（四）期限自 b 起算：c(t\_r) − c(b) ≤ T\_rec，不因 b 以后的再次失效而重置；  
（五）t\_r 取满足（三）的最早一点；  
（六）验证长度：c(t\_end) − c(t\_r) ≥ h；  
（七）b 与 t\_r 都在同一冻结实例、同一 H 之下取得。

入口为 1 时，Recover(Q) 取 0：FirstFail(Q) = none（全程逐点为 1，无可复归）；或窗的最后一点为 0（没有持续到窗末的复归）；或 FirstFail(Q) = b 取得，而即使把 b 以后的 ⊥ 都当作 1，最早可能的复归点也已超出期限。

入口不为 1 时不立复归问题（1.3）。入口为 1 时，Recover(Q) 取 ⊥：其余情形，例如 FirstFail = ⊥ 而窗末不为 0；复归点在期限之内而验证长度在窗内观察不到（条件（六）在窗内不能满足时视为验证未完成，记 ⊥，不记 0）；窗末为 ⊥。

### 4.3 稳定

&nbsp;&nbsp;&nbsp;&nbsp;Stable(Q) := Keep(Q) ∨₃ Recover(Q)

入口不为 1 时不立稳定问题（1.3）。Stable = 1 须由确定的 1 支撑：全程逐点为 1，或有实际首次失效并完成复归的全部条件；Stable = 0 须由确定的失效，以及期限条件或窗末条件的确定不满足支撑；其余为 ⊥。

### 4.4 原段的稳定

&nbsp;&nbsp;&nbsp;&nbsp;Stable\_{S\_0} := Keep(Q\_{S\_0})

原段没有复归项。理由：原段在首次确定为 0 的点越过资格边界，按《意向极限式》不复入；1 → 0 → 1 中后一个 1 属于重新申报的新段 S′。所以原段层只有保持：Keep(Q\_{S\_0}) = 1 时原段在窗内保持；有确定的 0 时原段在该点退出，Stable\_{S\_0} = 0，无论其后是否再成立。

新段 S′ 的资格首次成立，在 S′ 的评价点集上可以是《意向源式》意义下的首次资格事件（Genesis 按该篇 1.5 判定）；它由什么历史形成，是来源问题，交该篇。S′ 另立稳定实例：入口取 S′ 首次读为 1 的点（1.3），自此有它自己的原段层保持问题。

### 4.5 固定承担者层的稳定

&nbsp;&nbsp;&nbsp;&nbsp;Keep\_fix(e) := Keep(Q\_e)，Recover\_fix(e) := Recover(Q\_e)，Stable\_fix(e) := Stable(Q\_e)

固定承担者层允许跨段复归：同一宿主、同一组冻结指定上，资格首次失效以后在期限内持续回到 1。它说的是“这组被指定的承担者上，资格回来了”，不说“原来那一段回来了”，也不说“回来的是同一组织”。

### 4.6 存在层的稳定

&nbsp;&nbsp;&nbsp;&nbsp;Keep\_∃∀ := ∨₃ { Keep(Q\_e) : e ∈ 𝒞\_I, Elig\_I(e) = 1 }（三值析取同 3.2）  
&nbsp;&nbsp;&nbsp;&nbsp;Keep\_∀∃ := Keep(Q\_∃)，Recover\_∀∃ := Recover(Q\_∃)，Stable\_∀∃ := Stable(Q\_∃)

Keep\_∃∀ 的 0 与 Q\_∃ 的 0 都要求 DomClosed\_I = 1。Recover\_∀∃ = 1 只说：冻结候选中“有某一个合格”这件事断档以后，在期限内持续回到 1。它不说断档前后的承担者之间有承接，也不说任何承担者复归了。

### 4.7 见证层

&nbsp;&nbsp;&nbsp;&nbsp;WitnessSame\_e(t\_0, t) := \[W\_e(t) ∩ W\_e(t\_0) ≠ ∅\]

它只用来审查见证的更替，不进入资格读数，也不是一层稳定量：资格读的是结构是否成立，不读结构依哪一批见证成立。见证全部更换而 Q\_e 逐点为 1，Keep\_fix(e) = 1。

## 第五节　定理

### 5.1 定理一（即时层间蕴含）

在原段存续的点上，Q\_{S\_0}(t) = Q\_{e\_0}(t)；对任一 e ∈ 𝒞\_I，若 Elig\_I(e) = 1，则 Q\_e(t) = 1 ⇒ Q\_∃(t) = 1。

证明。前一式由 3.2 的定义。后一式：三值析取中有一项为 1，析取取 1。□

Status = Established。反向不成立：Q\_∃(t) = 1 而 Q\_{e\_0}(t) = 0，第七节 7.7 的接力实例在 e\_1 失效以后的各点即是。

### 5.2 定理二（动态稳定单调定理）

设两条读数序列 Q\_1、Q\_2 在同一轨迹、同一 H 之下，并在共同可判域中（观察窗内每一点两者都取 1 或 0），入口都为 1，且逐点有 Q\_1(t) = 1 ⇒ Q\_2(t) = 1。则 Keep(Q\_1) = 1 ⇒ Keep(Q\_2) = 1，Stable(Q\_1) = 1 ⇒ Stable(Q\_2) = 1。

证明。Keep 的一式由逐点蕴含直接得到。Stable：若 Q\_1 属 Keep，同上。若 Q\_1 属 Recover，由逐点蕴含得 Fail(Q\_2) ⊆ Fail(Q\_1)。若 Fail(Q\_2) 为空，Q\_2 逐点为 1，属 Keep。若非空，记 b\_1、b\_2 为两者的首次失效；由包含得 b\_2 ≥ b\_1。取 Q\_1 的复归点 t\_r：自 t\_r 起 Q\_1 逐点为 1，所以 Q\_2 自 t\_r 起逐点为 1；Q\_2 的复归点 t\_r′ ≤ t\_r，又 t\_r′ \> b\_2（b\_2 处 Q\_2 为 0）。于是 c(t\_r′) − c(b\_2) ≤ c(t\_r) − c(b\_1) ≤ T\_rec；c(t\_end) − c(t\_r′) ≥ c(t\_end) − c(t\_r) ≥ h。七项都满足，Q\_2 属 Recover。□

Status = Established。前件须显式：同一轨迹、同一 H、共同可判域。有 ⊥ 的点上逐点蕴含无从核验，定理不适用。

### 5.3 定理三（稳定链）

由定理一与定理二：

&nbsp;&nbsp;&nbsp;&nbsp;Keep\_{S\_0} = 1 ⇒ Keep\_fix(e\_0) = 1 ⇒ Keep\_∃∀ = 1 ⇒ Keep\_∀∃ = 1  
&nbsp;&nbsp;&nbsp;&nbsp;Stable\_{S\_0} = 1 ⇒ Stable\_fix(e\_0) = 1 ⇒ Stable\_∀∃ = 1

前提：e\_0 ∈ 𝒞\_I，Elig\_I(e\_0) = 1，各层在共同可判域中。

证明。Keep\_{S\_0} = 1 时原段在整个窗内存续，Q\_{S\_0} 与 Q\_{e\_0} 逐点相同，得第一步；Keep(Q\_{e\_0}) = 1 是 Keep\_∃∀ 的析取项之一，得第二步；Keep\_∃∀ = 1 时有 e 逐点为 1，由定理一 Q\_∃ 逐点为 1，得第三步。稳定链：Stable\_{S\_0} = Keep\_{S\_0}（4.4），由上一式得 Keep\_fix(e\_0) = 1，从而 Stable\_fix(e\_0) = 1；Q\_{e\_0} 逐点蕴含 Q\_∃（定理一），由定理二得 Stable\_∀∃ = 1。□

Status = Established。Keep 链的第一步两向等价（Keep(Q\_{S\_0}) = 1 当且仅当 Q\_{e\_0} 在整个窗内逐点为 1）；其余各步的反向一般不成立，各有参考实例（第七节）：

其一，固定承担者复归而原段已退出：7.5 的侵蚀复归轨迹，Stable\_fix(e\_0) = 1，Stable\_{S\_0} = 0。  
其二，存在层保持而原承担者失效：7.7 的替代实例，Keep\_∃∀ = 1（由 e\_2），Keep\_fix(e\_0) = 0，Stable\_fix(e\_0) = 0（e\_0 即 e\_1），Stable\_∀∃ = 1。  
其三，每时都有承担者而没有一个全程合格：7.7 的接力实例，Keep\_∀∃ = 1，Keep\_∃∀ = 0（定理四）。

### 5.4 定理四（量词不交换）

&nbsp;&nbsp;&nbsp;&nbsp;∃e ∈ 𝒞\_I ∀t ∈ Pts ∩ T\_obs：Q\_e(t) = 1　⇒　∀t ∈ Pts ∩ T\_obs ∃e ∈ 𝒞\_I：Q\_e(t) = 1

其中 e 只取 Elig\_I(e) = 1 的成员。

反向不成立。

证明。正向：取同一个 e 作每一时刻的见证。反向：第七节 7.7 的接力实例，e\_1 在第 14 轮失效，e\_2 自第 10 轮起合格，每一评价点都有承担者合格，而没有一个承担者在整个窗内合格（e\_2 在入口处不合格）。□

Status = Established；反向的否定以参考实例确立。一句话：同一承担者持续蕴含不断档，不断档不蕴含同一承担者持续。

### 5.5 定理五（复归的必要条件）

Recover(Q) = 1 ⇒ Fail(Q) ≠ ∅，FirstFail(Q) 实际取得，且存在 t\_r，自 t\_r 到窗末逐点为 1，c(t\_r) − c(FirstFail) ≤ T\_rec，c(t\_end) − c(t\_r) ≥ h。

证明。由 4.2 的定义逐项读出。□

Status = Established。由此三个推论：

（一）没有失效就没有复归：全程为 1 的序列 Recover = 0，Stable = Keep = 1。  
（二）瞬时再成立不是复归：失效以后读到的 1，若其后在窗内再次为 0，就不是持续到窗末的复归；7.5 的瞬时实例，第 6 轮的组织事件以后资格回到 1，第 10 轮之内再次为 0，Recover = 0。  
（三）期限不重置：期限从首次实际失效起算；后来再次失效，不得从后一次失效起算。7.8 的异步实例中，资格首次失效在第 4 轮，持续复归自第 16 轮起，期限 3 轮下 Recover = 0；若从第 14 轮的再次失效起算，会误判为 1。

### 5.6 定理六（异步复归不可合取）

一般地

&nbsp;&nbsp;&nbsp;&nbsp;Stable(Q\_1) ∧ Stable(Q\_2) ⇏ Stable(Q\_1 ∧ Q\_2)

证明。第七节 7.8：SD 第 4 轮失效、第 6 轮复归，Stable(SD) = 1；GC 第 14 轮失效、第 16 轮复归，Stable(GC) = 1；SD ∧ GC 首次失效在第 4 轮，自第 16 轮起才持续为 1，c = 12 \> T\_rec = 3，Stable(SD ∧ GC) = 0。同期 P\_I、TI 逐点为 1，所以资格序列与 SD ∧ GC 逐点相同，Stable(Q^M) = 0。□

Status = Established，以参考实例确立的否定结论。推论：不能凭四项各自稳定认证资格稳定；须直接判资格序列。

### 5.7 定理七（逐点覆盖）

Keep 只由覆盖整个观察窗的评价点取得。任一真子集上的读数全为 1，不给出 Keep = 1。

证明。Keep 是对 Pts ∩ T\_obs 的合取；未覆盖的点可以为 0。第七节 7.5：侵蚀复归轨迹的入口与窗末都为 1，而第 4、5 轮为 0；第七节 7.7 的短接缝实例：每一轮末都有承担者合格，而第 14 轮之内 e\_1 失效在先、e\_2 合格在后，其间的评价点上没有承担者合格，Keep\_∀∃ = 0。□

Status = Established。评价点规则 Pts 是协议的一部分：逐操作的评价点在参考运行基底中覆盖了全部系统状态（3.1）；轮末抽样不覆盖。

### 5.8 定理八（原段不复入）

在原段层，若 Fail(Q\_{S\_0}) ≠ ∅，则 Stable\_{S\_0} = 0，无论其后资格是否再成立；其后的资格属于重新申报的新段。

证明。由 4.4，Stable\_{S\_0} = Keep(Q\_{S\_0})；Fail 非空即有确定的 0，Keep = 0。原段在该点越过资格边界，按《意向极限式》第五节命题 11（经《意向源式》1.5 用于资格段），Reformation ≠ SameSegmentReentry。□

Status = Established。第七节 7.6：原段在第 4 轮退出；新段登记于第 5 轮，申报记录不同，第 6 轮首次读为 1。同一组指定承担者上的固定层复归为 1，与原段的退出并存。

### 5.9 定理九（任务不拼接）

存在层只在 Elig\_I = 1 的承担者上取析取。若把 Elig\_I(e) = 0 的承担者计入，可以把断档写成不断档。

证明。第七节 7.7 的错配实例：e\_3 在整个窗内合格，但它的职责身份申报不同，Elig\_I(e\_3) = 0。按冻结的 Elig\_I，Stable\_∀∃ = 0；若不分任务，读数变成 Keep = 1。□

Status = Established。不分任务的读数不是这一任务的读数；在失效以后改记 Elig\_I，按 1.4 离开原实例。

### 5.10 定理十（见证更替与承担者保持分离）

Keep\_fix(e) = 1 与 WitnessSame\_e(t\_0, t\_end) = 0 相容。

证明。第七节 7.3：30 轮的维持运行中，五条指定承担边上入口处的重复记录到第 4 或第 5 轮全部移出窗口，窗末一条也不剩，WitnessSame\_e(t\_0, t\_end) = 0；同期各承担边逐点成槽，指定未变，资格逐点为 1。□

Status = Established。推论：保持不是某一批见证始终在场；固定承担者层的保持可以由不断更新的见证承担。反过来，见证在场也不推出资格：成槽要求承担边的沉积越过阈值，且窗口内至少有两条重复记录；成槽读的是窗口内重复记录的条数，不读记录的身份，见证在场是成槽的必要成分而不充分。

### 5.11 定理十一（三个量词层级）

单轨迹：Stable\_γ 只关于一条合法轨迹。

合法轨迹集：TrajLegal(X\_st, Δ, H) 是自 X\_st 起、每一步取 Δ 中的许可操作及其全部可能后继（模型以随机源选维时，每一个权重为正的选维各是一个后继）、在观察窗内的轨迹集。

声明轨迹族：先冻结一个非空族 𝒢 ⊆ TrajLegal，FamilyStable(𝒢) := ∧₃ { Stable\_γ : γ ∈ 𝒢 }。族中有一条为 0 即为 0；无 0 而有不可判的轨迹即为 ⊥。

全部合法轨迹：GuaranteedStable(Δ, H) := ∧₃ { Stable\_γ : γ ∈ TrajLegal(X\_st, Δ, H) }；GuaranteedKeep(Δ, H) := ∧₃ { Keep\_γ : γ ∈ TrajLegal(X\_st, Δ, H) }，它为 1 推出 GuaranteedStable = 1。不得删去合法而不可判的轨迹；TrajLegal 中含数值终点前截止的轨迹（1.7 的 OutDom）时，保证层不取 1：另有确定失稳的合法轨迹时取 0，否则记 ⊥。

&nbsp;&nbsp;&nbsp;&nbsp;Stable\_γ = 1 ⇏ FamilyStable(𝒢) = 1 ⇏ GuaranteedStable = 1

证明。第七节 7.9：族 F1 的五条轨迹都稳定，FamilyStable(F1) = 1；把一条空转轨迹加入，FamilyStable = 0。同一 X\_st 在含空转的许可类下有一条确定失稳的合法轨迹，GuaranteedStable = 0；在只含“维持轮，或维持轮加一次组织事件”的有限许可类、6 轮的窗内，连同组织事件的每一个选维后继，729 条轨迹全部枚举、逐点为 1，GuaranteedKeep = 1。正判须对全部合法轨迹逐一取得（有限类可枚举）或有符号证明；负判只需一条确定失稳的合法轨迹。□

Status = Established。有限样本全部通过，只给族层的判词；对不能枚举的许可类，保证层的正判记 ⊥（O-ST4）。

### 5.12 定理十二（资格边界与稳定边界不可比）

对一条事前申报的全序扰动轴 q，记 η\_q 为“自 X\_st 起施加扰动 q、再施加申报的后续操作”的轨迹，Q(η\_q) 为扰动结束点上的资格读数，Stable(η\_q; H\_q) 为整条轨迹的稳定；H\_q 与 H 只在观察窗上不同（观察窗随 q 事前申报，其余各项不变）。资格边界 q^∂\_Q := min{ q : Q(η\_q) = 0 }（这是沿本轴的读数，不改写《意向极限式》的边界值 b\_T），稳定边界 q^∂\_St := min{ q : Stable(η\_q; H\_q) = 0 }，都须实际取得。由第三、四节的定义推不出两者之间的一般顺序：q^∂\_Q \< q^∂\_St 在参考构造上取得；q^∂\_St \< q^∂\_Q 只在有限抽象协议模型上取得。

证明。一个方向：第七节 7.10，q 为窗首空转的轮数，其后为 30 个维持轮；T\_rec、h 与评价点规则不变，观察窗为 q + 30 轮。q = 11 处资格已为 0，而其后第 14 轮复归、期限之内，Stable = 1；q^∂\_Q = 11 \< q^∂\_St = 12。另一方向：有限抽象协议模型的三点轴 q = 0、1、2（附录 A 的 abstract，axis\_stability\_before\_qualification；取 T\_rec = 2、h = 2，各 q 的窗长相同）：q = 1 处扰动结束时资格为 1，其后进入不可复归的失效，Stable = 0；q = 2 处资格为 0（η\_1 与 η\_2 是同一序列，差别只在扰动结束点的位置；这是协议层的形式模型，没有动力学内容）。两条边界都求出：q^∂\_St = 1 \< q^∂\_Q = 2。□

Status = Established；前一方向是参考实例，后一方向是抽象模型（形式模型，不宣称对应的物理实例已经存在）；稳定判值关于扰动轴的单调性未立（O-ST6）。推论：不得无条件签 q^∂\_Q ≤ q^∂\_St，也不得签其反向。迟滞宽度只在同一轴上正向的退出边界与反向的入界边界都实际取得以后，取两者之差；它与恢复期限 T\_rec 不是同一个量。

### 5.13 推论一（形式层稳定不是对象层稳定）

形式层 Stable^M = 1 回读对象层，须所用各点的 1 都按 H\_LawRead 回读、所用的 0 都按 1.2 的负读条件回读；本组式新增原子的形式零记 ⊥。入口点的回读条件未关闭时，对象层入口为 ⊥，按 1.3 稳定问题记 ⊥，Keep、FirstFail、Recover 与 Stable 都记 ⊥。入口已关闭、其他点未关闭时，这些点在对象层记 ⊥，按第三、四节的三值规则代入：Keep、Recover 与 Stable 的 1 不能由这些点签出，在它们之后的 0 不能取为首次实际失效；已按 1.2 取得的对象层 0 仍给出 Keep = 0。

证明。对象层的各量由对象层逐点读数按第三、四节的同一定义求出；逐点读数为 ⊥ 时，Keep 的 1、FirstFail 的取得与 Recover 的 1 都不能签出，失效时集只收确定的 0；逐点读数为确定的 0 时，按 4.1 照常取 0。□

Status = Established（判据层），回读条件的关闭见 O-ST2。第七节 7.11：参考实例的形式 1 回读为 LawReadOpen；SD 一侧的形式 0（γ\_rec）判定器给 ⊥（IntentAtomRepOpen），概率一侧的形式 0（γ\_idle）判定器给 ⊥（ProbabilityOpen），后者回读须携 H2 ∧ H3^red 与失败路径的条件。各实例对象层的入口都为 ⊥，首次实际失效与复归都记 ⊥。

## 第六节　重新形成的组织与原组织

《意向极限式》把“重新形成的组织与原组织的关系”交到这里。本篇的回答是分层的：

&nbsp;&nbsp;&nbsp;&nbsp;同一原段　　　　　不成立：原段在首次确定为 0 处退出，不复入（定理八）  
&nbsp;&nbsp;&nbsp;&nbsp;同一组指定承担者　可审查：宿主与 Des\_e 在窗内是否被改写（固定承担者层，4.5）  
&nbsp;&nbsp;&nbsp;&nbsp;同一任务　　　　　可审查：Elig\_I 按冻结的职责比较给出（1.5），是比较协议  
&nbsp;&nbsp;&nbsp;&nbsp;同一组织（本体）　未证

前三层都是申报记录与比较协议上的关系。第四层要求跨段的承担者身份认证：在退出与再成立之间，承担结构的物理载体是否连续，承担的沉积是否延续而不是重新取得，以及什么样的延续足以说“同一组织”。上游没有这样的充分定理：《意向普遍不变量式》的职责不变量是取得同一角色的实现之间的不变量，不推出物理承担者的同一；《意向源式》对重新申报的候选与原候选是否同一不作结论。所以本篇只签前三层，第四层记未证（O-ST1）。

需要补建的接口，规格如下（规格不是构造）：

（一）退出区间内承担载体的连续性证书：退出点与再成立点之间，指定承担边的拓扑、存在与沉积变量没有被删除重建；  
（二）沉积延续的分解：再成立时所依的沉积中，哪一部分来自退出以前，哪一部分由再成立的事件取得（《意向源式》3.6（一）的阈值越过判别可作一项输入，实例见该篇 7.7）；  
（三）同一性的判据本身：在何种延续之下称组织同一，须由身份各篇给出，不得由稳定式自定。

在这三项建成以前，“复归了同一意向组织”不是一个可签的判词；能签的是“同一组指定承担者上资格复归”。

## 第七节　参考实例

实例取《意向运行基底构造式》v1.0 的参考构造，模型 v14.5，源码未修改。稳定侧协议由附录 B 的脚本执行。全部读数在形式层；对象层按 1.7 与推论一。

### 7.1 稳定实例的申报

宿主：参考构造（80 轮两维概率形成脉冲，再 20 轮概率形成脉冲与沿五条意向边的场脉冲），构造完成以后开启回路边，得 X\_st。X\_st 处四项与资格的形式读数都为 1。原段的冻结声明摘要、任务比较的摘要与指定承担边见附录 A 的 setup。

许可变化类 Δ：一轮维持 = 两维各一次概率形成脉冲，加沿五条意向边各一次场脉冲；侵蚀轮 = 维持轮中省去若干条意向边（一条至全部五条）的场脉冲；维持轮或侵蚀轮之后可以有一次模型自身的组织事件；空转轮 = 一次沉积衰减步；另有模型的外部事件、源动会话的开关与可用性设置。不写入任何资格读数、承担者指定或冻结声明。

H：评价点为入口与每一操作以后（3.1）；时钟以轮计；T\_rec = 3 轮，h = 10 轮；观察窗除另注外为 30 轮。

本节的 Δ 即 1.3 的 Δ\_I。

工作域：只连续施加维持轮，参考程序在第 90 轮首次数值溢出；每 4 轮加一次组织事件时在第 73 轮（附录 A 的 setup）。本节各轨迹的运行都没有出现数值溢出。

随机源：组织事件的选维取自模型自身的随机源（种子 0），按当时各维的权重抽取。单轨迹与轨迹族的实例都是种子 0 下的一种实现；保证层的枚举把每一个权重为正的选维都作为后继（7.9）。

### 7.2 资格与发生分离

经运行基底的合法审计账本，依次施加 SourceStart、SourceStop，并把源动边 sI→a1 的可用性设为 0：源动会话关闭，源动边当前不可穿越，四项与资格的形式读数仍都为 1，账本的状态摘要链闭合（附录 A 的 separation）。资格读的是已成立的结构，停发与意向侧的可用性属于发生（W-S1）。

### 7.3 保持与见证更替

γ\_keep：30 轮维持，每 4 轮加一次组织事件（共 7 次），218 个评价点，四项与资格逐点为 1：Keep\_fix(e\_0) = 1，Keep\_{S\_0} = 1，Stable = 1。

同一轨迹上，五条指定承担边入口处的重复记录，sI→a1、c→gA、x→gX 到第 4 轮，gA→tA、gX→tX 到第 5 轮，入口处的记录全部移出窗口，窗末一条不剩；各承担边逐点成槽，承担者指定未变（附录 A 的 witness）。这是定理十的实例。两维的绑定记录在这 30 轮中没有移出，本实例不据此对绑定见证的更替作主张。

### 7.4 实际失效

γ\_idle：30 个空转轮。第 1 至 10 轮资格为 1，第 11 轮首次确定为 0，此时 P\_I 为 0，其余三项为 1。首次实际失效在第 11 轮取得；此后各评价点都为 0，Keep = 0，Recover = 0，Stable = 0。失效是沉积衰减的结果，没有写入资格标签。

γ\_run：15 轮，每轮两维概率形成脉冲与一次组织事件，不施加场脉冲（省去全部五条场脉冲的侵蚀轮加一次组织事件）。组织事件全部选维 X；第 7 轮资格首次为 0，此时 GC 为 0，其余三项为 1；窗末 c→gA 不成槽，Stable = 0。组织持续运行并不保持资格：运行沿一个维反复进行，另一门的承担边没有被使用，窗末已不成槽（W-S2）。这与《意向可达式》交来的锁定现象同属运行偏于一维而另一侧承担结构失效，但失效的项不同，不据此对锁定作新的主张。

### 7.5 侵蚀与复归

侵蚀：维持轮中省去沿 sI→a1 的场脉冲。

γ\_rec：第 1 至 4 轮侵蚀，第 5 轮起恢复维持。第 4 轮的 pX 操作以后资格首次确定为 0，此时 SD 为 0，其余三项为 1；第 6 轮起持续为 1。c(t\_r) − c(b) = 2 ≤ 3，验证长度 24 ≥ 10，Recover\_fix(e\_0) = 1，Stable\_fix(e\_0) = 1；原段 Stable\_{S\_0} = 0。

γ\_late：第 1 至 8 轮侵蚀，第 9 轮起恢复维持。首次失效同在第 4 轮，第 10 轮起持续为 1，c = 6 \> 3，Recover = 0，Stable = 0。同样回到 1 并持续到窗末，超出期限就不算复归。

γ\_trans：始终侵蚀，第 5、6 轮各施加一次组织事件。第 4 轮失效；第 6 轮的组织事件以后资格回到 1，到第 9 轮末仍为 1；第 10 轮之内再次为 0，此后各轮末都为 0。组织事件使资格一度回到 1，但侵蚀继续，没有持续到窗末。Recover = 0，Stable = 0（定理五（二））。

端点：γ\_rec 的入口与窗末都为 1，只看两端会签出保持；逐点求值得 Keep = 0（定理七）。

### 7.6 原段与新段

在 γ\_rec 上：原段 S\_0 在第 4 轮退出，Keep\_{S\_0} = 0，不复入。新段 S′ 登记于第 5 轮，申报记录为“登记于退出以后，第 2 次申报”，声明摘要与原段不同；S′ 在第 6 轮首次读为 1，形式层首次资格事件为 1，自此到窗末保持。S′ 与 S\_0 的指定承担边相同，任务比较摘要相同；固定承担者层的形式复归为 1；跨段的承担者身份证书为 ⊥（第六节）。S′ 的这一次成立由什么历史形成，属于《意向源式》：该篇 7.7 的同类实例判为已安置结构上的阈值越过，分类 Boundary。

另一条再成立的路径：空转 20 轮（第 11 轮首次失效）以后，每轮施加模型的外部事件 A、X 各一次，第 22 轮资格再为 1，此后到第 26 轮保持（观察窗 26 轮；附录 A 的 idle\_requal）。同一实际历史，在 T\_rec = 3、h = 3 下 Recover = 0，在 T\_rec = 12、h = 3 下 Recover = 1。复归判词相对于冻结的 H，不是轨迹自身的性质；H 须事前冻结（1.4）。

### 7.7 存在层：接力、替代、接缝与错配

宿主 e\_1、e\_2、e\_3 是三个独立的场，各带参考构造。e\_1 是原段的承担者 e\_0；Elig\_I 以 e\_1 的冻结申报为比较基准。错配取 𝒞\_I = {e\_1, e\_2, e\_3}，其余各例取 {e\_1, e\_2}，DomClosed\_I = 1（申报）；Elig\_I 由冻结的职责申报算出。各宿主每轮按 e\_1、e\_2、e\_3 的次序执行，每一操作以后对全部宿主读数。

e\_1：第 1 至 10 轮维持，第 11 轮起侵蚀源动边，第 14 轮首次失效，此后不复归。e\_2（替代实例除外）：在窗前先侵蚀 10 轮，入口资格为 0，按申报的轮次恢复维持。

接力（e\_2 自第 9 轮起维持）：e\_2 第 10 轮起合格。每一评价点都有承担者合格，Keep\_∀∃ = 1；e\_1 在第 14 轮失效，e\_2 入口不合格，Keep\_∃∀ = 0。e\_2 的固定承担者层没有稳定问题（入口为 0，OutDom）。这是定理四的实例。

替代（e\_2 取 X\_st，全程维持）：Keep\_∃∀ = 1（由 e\_2），Keep\_fix(e\_1) = 0，Stable\_fix(e\_1) = 0。所保持的是“冻结候选中有某一个全程合格”，不是 e\_1 的复归。

短接缝（e\_2 自第 13 轮起维持）：e\_2 第 14 轮合格。第 14 轮之内 e\_1 失效在先、e\_2 合格在后，其间的评价点上没有承担者合格：Keep\_∀∃ = 0，Recover\_∀∃ = 1（断档与复归同在第 14 轮，期限之内），Stable\_∀∃ = 1。只用轮末读数会签出 Keep\_∀∃ = 1（定理七）。

迟接缝（e\_2 自第 17 轮起维持）：e\_2 第 18 轮合格。存在层第 14 轮首次失效，第 18 轮起持续为 1，c = 4 \> 3，Stable\_∀∃ = 0。

错配：在迟接缝上加入 e\_3，它全程维持、全程合格，但欲门与调谐的职责身份按另一任务申报，Elig\_I(e\_3) = 0。按冻结的 Elig\_I，Stable\_∀∃ = 0；不分任务的读数为 Keep\_∀∃ = 1（定理九）。

对照（e1\_kept）：e\_1 全程维持，e\_2 自第 9 轮起维持；Keep\_∃∀ = 1（由 e\_1），Keep\_∀∃ = 1。

这些实例只在存在层签判词：e\_2 在 e\_1 失效前后合格，不说明 e\_2 承接了 e\_1 的任何东西；两者是不同的场。

### 7.8 异步复归

第 1 至 4 轮侵蚀源动边，第 11 至 14 轮侵蚀 c→gA，其余轮次维持。SD：第 4 轮失效，第 6 轮复归，Stable(SD) = 1；GC：第 14 轮失效，第 16 轮复归，Stable(GC) = 1。SD ∧ GC 与资格逐点相同（P\_I、TI 逐点为 1）。资格：第 4 轮首次失效，第 6 轮之内回到 1，第 14 轮之内再次为 0，第 16 轮之内回到 1 并持续到窗末（轮末读数见附录 A 的 Intent\_round\_end）；期限从第 4 轮起算，c = 12 \> 3，Stable(Q^M) = 0。这是定理六与定理五（三）的实例。

### 7.9 轨迹族与保证

族 F1：30 轮维持，每 k 轮加一次组织事件，k = 1、2、3、4、5；五条轨迹都 Keep = 1、Stable = 1，FamilyStable(F1) = 1。F1 加上 γ\_idle：FamilyStable = 0。

有限许可类 Δ′：每轮是维持轮，或维持轮加一次组织事件；组织事件的每一个权重为正的选维（A 与 X）各是一个后继；6 轮的窗。729 条轨迹深度优先全部枚举，每一评价点资格都为 1，没有不可判的点：GuaranteedKeep(Δ′, 6 轮) = 1。这是在可枚举的有限类上的保证，不外推到更长的窗或更大的许可类。参考模型中，除组织事件的选维外，各许可操作都沿写定的路径执行，不取随机源（模型的场脉冲在给定路径时不调用续行选择；附录 B 对每一操作都给出路径），所以选维是唯一的分支来源。

许可类 Δ（含空转轮）：γ\_idle 是 Δ 中一条确定失稳的合法轨迹，GuaranteedStable(Δ, H) = 0（窗 30 轮）。

### 7.10 资格边界与稳定边界

扰动轴 q：窗首施加 q 个空转轮，其后 30 个维持轮；T\_rec、h 与评价点规则不变，观察窗为 q + 30 轮。q = 0 至 10：扰动以后资格为 1，全程不失效，Stable = 1。q = 11：扰动以后资格为 0（第 11 轮首次失效），第 14 轮起持续为 1，c = 3 ≤ 3，Stable = 1。q = 12 至 16：首次失效仍在第 11 轮，复归在第 q + 3 轮，c ≥ 4，Stable = 0。两条边界都实际取得：q^∂\_Q = 11，q^∂\_St = 12；q = 11 处资格已失而稳定仍成立（定理十二的一个方向）。

### 7.11 对象层

γ\_rec 的 207 个评价点中，形式读数为 1 的 193 点，参考判定器给 1（PositiveCore），回读对象层为 ⊥（LawReadOpen）；形式读数为 0 的 14 点，判定器给 ⊥（IntentAtomRepOpen），对象层为 ⊥。对象层的入口读数为 ⊥，稳定问题记 ⊥，首次实际失效记 ⊥。参考实例的全部稳定判词停在形式层。

### 7.12 有限抽象协议模型

附录 A 的 abstract 给出三值序列上的协议求值，是形式模型，不是场运行：无脉冲而逐点为 1 时保持；空隙使保持为 0；期限内复归、超期、验证长度观察不到（⊥）、首次失效以前有 ⊥（FirstFail = ⊥）、无失效不是复归、再次失效不重置期限；两承担者接力的 ∀∃ = 1 与 ∃∀ = 0；候选域未闭合时已检索的全部为 0 只给 ⊥；连续时间中 Fail = (3, 4\]（窗为 \[0, 6\]，4 以后读数为 1）的下确界 3 未取得，FirstFail 与 Recover 都为 ⊥；稳定边界先于资格边界的三点轴。其中候选域未闭合与连续时间下确界两项是按 3.2、3.3 写出的申报值，脚本只实现 DomClosed\_I = 1 的析取；其余各项是对三值序列的求值。

## 第八节　开放义务

O-ST1　跨段的承担者身份认证：第六节的三项接口未建；“复归了同一组织”未证。  
O-ST2　对象层回读：形式 1 的 H\_LawRead（入口与各点）、概率一侧负读的 H2 ∧ H3^red 与失败路径条件、本组式新增原子的负向表示，都须按《意向判定式》逐项关闭；入口的 H\_LawRead 关闭以前，对象层的入口、失效与复归都为 ⊥；入口关闭以后，未关闭的点按推论一处理。  
O-ST3　任务交接证书：存在层的不断档之上，若要说后一承担者承接了前一承担者的任务，须有交接的登记与因果证书；本篇只签存在层，不签承接。  
O-ST4　一般场、一般许可类上的保证：本篇只在参考构造与可枚举的有限类上签出保证；一般的许可类须有符号证明或完备的负证书。  
O-ST5　连续时间覆盖：操作内部的中间状态与连续时间中的首次失效，须有段内事件记录与覆盖证书。  
O-ST6　稳定边界的单调性：本篇没有稳定判值关于扰动轴单调的定理，迟滞宽度只能在正反两个边界都实际取得以后报告。  
O-ST7　意向从基础沉积场中生成以后的稳定：交第二十一篇在其可执行构造上逐层取得。  
O-ST8　意向动力的稳定：动力判词（L4 等）在许可变化下的保持、替代与复归，须在动力各篇的判词之上按本篇的四层与三量词层级另行建立；本篇只判资格。  
O-ST9　锁定现象的稳定判读：《意向可达式》交来的锁定状态（同一维越用越深，另一维离开 V，资格形式读数降为 0），其首次实际失效、能否在申报期限内复归，须在冻结的许可类与 H 之下按第三、四节判读；本篇只在 7.4 给出 GC 一侧运行偏于一维的对照，未对锁定轨迹本身取得判词。

## 第九节　状态与禁止推论

### 9.1 状态

def org_successors(I):
    """All successors of an organisation event: one per dimension with Rel > 0 (the model draws the dimension from its
    random source with these weights); each branch consumes the same single draw and then runs the event on that dimension."""
    rel = dict(I.P.Rel()); out = []

def cmd_guarantee(horizon=6):
    """Finite admissible class Δ': each round is a maintenance round, optionally followed by an organisation event;
    every successor of every organisation event (each dimension with Rel > 0) is a separate branch; all trajectories
    enumerated depth-first.  Class Δ adds idle rounds: one legal trajectory (30 idle rounds) is a determinate unstable
    witness."""
    n = [0]; leaves = []; nonone = [0]; branch_dims = set()
    def dfs(I, depth, path, kp):
        if depth == horizon:
            n[0] += 1; leaves.append(kp); return
        J = copy.deepcopy(I); k = kp
        for op in MP():
            do(J, op); x = qual(J)['Intent']; k = and3(k, x)
            if x is None: nonone[0] += 1
        dfs(J, depth + 1, path + 'm', k)
        for d, K in org_successors(J):
            branch_dims.add(d); x = qual(K)['Intent']
            if x is None: nonone[0] += 1
            dfs(K, depth + 1, path + d, and3(k, x))
    I = X_st(); dfs(I, 0, '', qual(I)['Intent'])
    gk = and3(*leaves)
    pts = run({'e0': X_st()}, [{'e0': IDLE} for _ in range(30)])
    w = stats(series(pts, 'e0'), rounds_of(pts), T_REC, HOLD)
    return dict(finite_class=dict(horizon_rounds=horizon, trajectories=n[0], organisation_event_dimensions=sorted(branch_dims),
                                  undecided_points=nonone[0], GuaranteedKeep=t3(gk)),
                class_with_idle=dict(witness='30 idle rounds', witness_Stable=w['Stable'], GuaranteedStable=0 if w['Stable'] == 0 else '⊥'))
