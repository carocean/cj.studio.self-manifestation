# 意向普遍不变量式

## 第一节　目的、式种与唯一任务

一、式种

本篇是不变量式，附式。

《法篇》现行版本尚未收录“不变量式”一章，本篇采用以下暂行规范：在一个对象、资格、职责或关系已经取得合法定义以后，研究它在事先冻结的一族合法实现替换或表示变化下，什么必须保持，什么可以改变，保持发生在哪个抽象层级，以及不同实现依据什么判为承担同一职责。它的典型问题是“实现可换，什么不能换”，不重新回答“对象成立最少要有什么”；后者属于一般式。

二、唯一任务

本篇的唯一任务是：为《意向一般式》的四项必要核，提供一条不同于母书直接语义判断的跨实现结构支撑。

这一支撑分三层：先在不预设《自显论》本体的理论中立层，确定系统定向所不能逃掉的职责；再证明这些职责进入沉积场以后，在律侧现有条件下取得律与概率的结构；最后建立它们进入自显场以后通向《意向一般式》四项结构的四座表示桥，并明确其中已经独立闭合与仍待条件关闭的部分。

本篇不重新证明《意向一般式》，不改变它的任何结论，也不证明具有这些职责就足以成为意向；后者属于《意向必然式》。

三、结果预告

第一层，理论中立层：

&nbsp;&nbsp;&nbsp;&nbsp;MultiDirectionalTask(C, V) ∧ SysDirClaim(X; C, V) 经审查成立 ⇒ SysBear(X) ∧ DirPersist(X)

即凡申报“这些不同方向属于系统自身”且申报经审查成立的实现，都必须具有系统方向承担（SysBear）与方向区分存续（DirPersist）两项职责；在任务保持的不同实现之间，这两项职责都必须重新成立。

第二层，沉积场表示层：在沉积场中，系统方向承担特化为率的承担，正式方向由律承担，并取得 Probability。这一层继承《律组式》的桥接条件。

第三层，自显场表示层：在自显场中，以独立于《意向一般式》的上游场结构为据，经四座各自登记条件的表示桥，并在共锚绑定之下，这些职责与 Probability 落成

&nbsp;&nbsp;&nbsp;&nbsp;P\_I ∧ SourceDrive ∧ GateCorrespondence ∧ TuneInterface

即《意向一般式》的四项结构。

一句话：普遍的是职责；在 H2 ∧ H\_3^red 下且四座自显场表示桥闭合时，四项构成这些职责在自显场中的完整实现。

这一预告不作为后文推导的前提。

## 第二节　中立任务入口与系统归属申报

一、意向不可计数

意向是一，不可数：意向就是意向本身。本篇只说“意向”。职责、结构、节点、方向、实现都可以区分和计数，但对它们的计数不是对意向的计数。

二、任务入口

一个候选系统 X 进入本篇，先申报一个任务实例：

&nbsp;&nbsp;&nbsp;&nbsp;χ\_UI = (X, B\_X, C, V, Γ\_task)

其中 X 是被申报的系统，B\_X 是事先冻结的系统边界，C 是一个续行问题，V = {v₁, …, v\_n} 是 C 的后继类，Γ\_task 是事先冻结的任务比较协议。

入口只规定三件事：

（一）对象层：本篇研究的是系统级的定向资格，不是一次单独的事件。这一条只区分资格与发生，不规定资格怎样实现，也不由此推出任何复走支撑。

（二）多向问题：

&nbsp;&nbsp;&nbsp;&nbsp;MultiDirectionalTask(C, V)：\|V\| ≥ 2

即同一个续行问题有至少两个可以区分的后继类。这里只规定有不同的去向，不规定它们由律承担、组成概率、由谁承担相对生成，也不规定有无欲门。

（三）系统归属申报：

&nbsp;&nbsp;&nbsp;&nbsp;SysDirClaim(X; C, V)

即申报：C 上的方向差异属于系统 X 的定向角色，而不是研究者、描述协议或边界之外机制的角色。

SysDirClaim 在入口只是一项待审查的申报，不是已经成立的结构事实，也不由本篇要比较的职责来定义。它是否成立，由第四、五节的因果归属审查决定。

三、比较层级

本篇比较的是职责，不是物理结构、拓扑或行为结果。职责说明某种东西在系统中做什么、与其余职责处于什么关系，不说明由什么做、在哪里做。同一个物理结构可以承担多项职责，多个物理结构可以共同承担一项职责：

&nbsp;&nbsp;&nbsp;&nbsp;Duty ≠ Module

四、两个问题分开

“意向是什么”由《意向一般式》回答；本篇只回答“哪些职责在实现更换下不能逃，以及它们在《自显论》中为什么落成那四项”。

五、工作域

Ω\_Sed 是沉积场，即《律组式》的工作域。Ω\_SM 是《自显论》描述的自显场：意图场中有意向域与欲门，欲门之后有调谐一侧。工作域的这一描述不规定概率组织的位置，也不规定方向与欲门怎样对应；这些由第九节的表示桥处理。Ω\_SM 包含于 Ω\_Sed。

六、上游承继

《意向一般式》：承继其意向必要核

&nbsp;&nbsp;&nbsp;&nbsp;N\_I = P\_I ∧ SourceDrive ∧ GateCorrespondence ∧ TuneInterface，　P\_I = InIntentDomain(𝒫\_I) ∧ Probability(𝒫\_I; C\_I, 𝔯\_I)

及其登记的语料。N\_I 只在第九节作为表示目标，不进入入口，也不作为第一、二层的前提。

《律组式》：承继 CarrierNonInstant、Established、DynamicRole、StableReplay、ΩSupport，以及《律必然式》的充分方向 ∃R\[Established ∧ Govern\] ⇒ Law（Govern ≡ DynamicRole ∧ ΩSupport），该方向不携带 H；并承继其登记的桥接条件：H1 关系承载实现与沉积状态之桥，H2 稳定复走与 ΩSupport 之桥，H3 冗余动力职责的客观真值之桥，用于冗余、协同与多重承担的情形；本篇记 H\_3^red := (RedRole ⇒ H3)，没有冗余、协同或多重承担时它自动成立。

《概率组式》：承继 MultiLawDimension、CommonContinuationBind、DomainRelativeRateBearing，以及《概率必然式》的充分方向 N\_P ⇒ Probability，该方向不携带 H；并承继其纪律：结果承担不等于率承担；物理上的共处不等于职责上的归属；概率维是已经沉积的路径，不是可能路径。

《式篇第四》：其关系分类把“界门关系：Gate、Pass 及其调谐控制关系”与“统摄关系：理场使役调谐关系、TunePriority 赋权关系”分列；TunePriority 定义为“意向场经欲门对回路之调谐资源分配权重与参数更新贡献之赋值”。

## 第三节　任务保持比较协议与重实现族

一、任务保持关系

两个实现 X、X′ 之间的任务保持关系 X ∼\_task X′，只要求以下各项相同：

T1　任务身份：同一个续行问题 C，或事先冻结的任务同构 ψ\_C：C ≅ C′。  
T2　方向类别签名：V 与 V′ 之间有事先冻结的角色对应 ψ\_V：V ↔ V′。它只是任务类别的对应，不规定内部怎样产生方向。  
T3　系统边界规则：内部与外部的划界规则保持；不允许为了把选择器算作“系统自身”而事后移动边界。  
T4　合法接口签名：正常输入、输出与环境交互接口的任务意义保持。  
T5　比较协议：Γ\_task 在比较之前固定，不在看完两个实现以后改变“什么叫同一任务”。

二、允许变化的东西

T6　内部实现自由：允许任意改变材料、节点数、拓扑、集中或分布、连续或离散、时间尺度、模块划分、算法、中介链，以及生物或人工载体。

三、协议中不含待证内容

任务保持关系的定义中不含 SysBear，也不含 DirPersist。一个实现是否与另一个任务保持，只看 T1 至 T5，不看两项职责在其中是否成立。

四、比较的方式

本篇不主张“有意向的实现经任何合法重实现以后仍有意向”。一个合法重实现完全可能把定向资格做坏。本篇比较的是两个分别通过归属审查的实现：

&nbsp;&nbsp;&nbsp;&nbsp;X ∼\_task X′，　SysDirClaim(X) 与 SysDirClaim(X′) 分别经审查成立

然后问：哪些职责在两端都不可缺。

## 第四节　系统方向承担的取得与反例

一、审查什么

SysDirClaim(X; C, V) 申报方向差异属于 X。审查的问题是：这一申报在对象一侧有没有根据。如果方向差异以及当前续行为什么落向某一类，在对象一侧找不到 X 的因果责任，申报就失败。

二、四个失败世界

W1，标签：方向“差异”只是观察者的标签、名称或读出方式；改变标签，系统的方向关系毫无改变。申报所说的差异不在对象一侧。

W2，惰性中继：改变 X 内部组织的合法状态，V 中各方向的可达关系、相对生成、排序、可用性以及实际所落方向都不改变；方向全由别处决定，X 只是传递。

W3，外部完全承担：边界之外有一个机制 M\_out，在 X 只被动执行的情况下，完整承担 V 中各方向之间的全部生成责任。《概率组式》对外部选择器已有同型裁定：结果的执行可以由 X 完成，率的承担却不在 X。

W4，物理共处：X 内部确有某个结构影响了方向，但它不属于这一方向任务的合法职责组织，只是物理上位于边界之内的旁支。《概率组式》已有纪律：物理上的共处不等于职责上的归属。

四个世界中，申报 SysDirClaim 都在对象一侧落空。

三、系统方向承担

由此，申报要成立，X 必须具有系统方向承担：

&nbsp;&nbsp;&nbsp;&nbsp;SysBear\_X(C, V) = 1

当且仅当存在 X 边界内部的合法因果组织 R\_X，使：

SB1　系统侧有效：在冻结的合法外部接口条件下，改变 R\_X 的合法状态，能够改变 V 中各方向的可达关系、相对生成关系、方向排序、方向可用性或实际所落方向中的至少一项。  
SB2　非标签：只改变观察者的标签、名称或读出方式，而不改变 X 的因果组织，不改变系统的方向关系。  
SB3　非外部完全承担：不存在边界之外的机制，在 X 只被动执行的情况下，完整承担各方向之间的全部生成责任。  
SB4　职责归属而非物理共处：R\_X 属于这一方向任务的合法职责组织，而不只是物理上位于 X 之内。

定理一（系统方向承担定理）。如果 SysDirClaim(X; C, V) 经审查成立，那么 SysBear\_X(C, V) = 1。

证明。SB1 至 SB4 分别是 W2、W1、W3、W4 所缺的东西；四者任何一项不成立，申报就落入相应的失败世界，在对象一侧落空。证毕。

四、系统方向承担推不出内源发动

设世界 W5：外部输入 E\_t 到达 X，X 内有一个已经形成的复杂方向组织 R\_X，E\_t → R\_X → v\_i。不同的 R\_X 状态确实改变方向；方向差异不是标签；外部输入没有直接指定某一 v\_i；所以方向生成的责任确实有一部分属于 X，SysBear = 1。但是，没有当前的外部输入时，X 从不自行发动这一次续行：事件的启动全部来自外部，X 只负责在事件被触发以后决定“往哪里”。所以：

&nbsp;&nbsp;&nbsp;&nbsp;SysBear ⇏ EndoDrive

系统方向承担真正给出的，只是系统方向生成责任：对“为什么是这个方向而不是另一个”的解释，不能完全移出 X。系统可以被外部事件启动，而在内部承担方向的生成。更强的源动一侧的发动职责，不在理论中立层取得。

## 第五节　方向区分存续的取得、独立性与反例

一、失败世界

W6，交接前合流：上游阶段，X 确实自己形成了两个不同的方向 v\_a ≠ v\_b，SysBear = 1；但两条方向在产生任何不同后继以前完全合流，v\_a → h，v\_b → h，从 h 起没有任何物理或因果的差别。后来即使出现不同的输出，也只能由 h 之后的新因素重新产生，不能归属于原来的 v\_a、v\_b。这时申报“后继差异属于 X 的这两个方向”落空。

二、方向区分存续

由此，申报要成立，还需要：

&nbsp;&nbsp;&nbsp;&nbsp;DirPersist\_X(C, V) = 1

即：如果 v\_i ≠ v\_j 是 X 自身承担的两个不同方向角色，那么从方向差异形成以后，到这两个方向第一次取得不同的后继责任以前，这一差异不能在 X 的因果组织中彻底消失。形式地说：如果两条合法运行在某时刻 t\_c 之前已经完全进入同一个因果等价类，State\_i(t\_c) ∼\_C State\_j(t\_c)（∼\_C 指二者对此后的一切合法因果作用都不可区分），并且从 t\_c 起不存在任何方向特有的合法因果差异，而后来仍申报后继差异由原来的 v\_i、v\_j 承担，那么归属失败。

一句话：方向差异必须存续到它真正兑现不同后继责任的地方。

这不要求离散的门、单个节点、一次跳变、同一拓扑或明确的模块边界；连续场、分布系统、状态编码都可以满足。

定理二（方向区分存续定理）。如果 SysDirClaim(X; C, V) 经审查成立，那么 DirPersist\_X(C, V) = 1。

证明。DirPersist 不成立，申报就落入 W6。证毕。

三、两项独立

SysBear 不推出 DirPersist：W6 中 SysBear = 1 而 DirPersist = 0。

DirPersist 不推出 SysBear：设 W7，边界之外的选择器把两个不同的标签一直保持到两个执行器，M\_out → v\_a → out\_a，M\_out → v\_b → out\_b；方向的区别一直保持，DirPersist = 1，而全部方向责任在系统之外，SysBear = 0。

所以两项不能合并。

四、离散交接不是中立不变量

设 W8，连续动力系统：方向 v\_a、v\_b 不经过任何离散的门，也没有可以自然切出的“第一次交接节点”；在连续的状态流中，方向差异逐渐扩张，x\_a(t) ≠ x\_b(t)，最后分别产生不同的后继。它保持了方向身份，DirPersist = 1，却不存在一个 v\_i → G\_i 的离散交接。所以离散交接不是理论中立的不变量；真正不可逃的是方向区分的存续。

## 第六节　系统定向职责不变量定理

定理三（系统定向职责不变量定理）。设 X ∼\_task X′，并且 SysDirClaim(X) 与 SysDirClaim(X′) 分别经审查成立。那么：

&nbsp;&nbsp;&nbsp;&nbsp;SysBear(X) = SysBear(X′) = 1，　DirPersist(X) = DirPersist(X′) = 1

即同一系统定向角色的不同合法实现，可以更换承载，却不能丢掉系统方向承担与方向区分存续。

证明。由 X ∼\_task X′，两端属于事先冻结的同一任务比较类；这一关系只负责说明二者可以比较，它本身不保证任何待证职责保持。由假设，X 与 X′ 的 SysDirClaim 分别独立通过第四、五节的审查。所以由定理一、定理二，分别有 SysBear(X) = DirPersist(X) = 1 与 SysBear(X′) = DirPersist(X′) = 1。因此，在一切仍然独立取得同一系统定向角色资格的任务等价实现中，两项职责都不可缺，而承担它们的物理实现可以不同。证毕。

任务保持关系负责“可比”，归属审查负责“两端各自具有职责”；不是任务保持关系推出职责保持。

这里的不变量是取得角色资格的实现之间的不变量，不是沿一条变换轨迹自动保真的不变量：凡仍然取得同一系统定向角色的实现，虽然物理实现不同，这两项职责都必须重新成立。这与稳定式研究已成资格在许可变化下能否保持、复归，是不同的任务。

不进入理论中立层的职责：

EndoDrive 不进入：W5 表明系统方向承担推不出内源发动。

IntMod 不进入：一个系统可以把方向直接交给行为控制；仅凭它没有内部调谐，不能在理论中立层断定它不承担系统定向角色。

离散交接不进入：W8 表明连续实现可以保持方向身份而没有离散交接。

复走支撑不进入：在中立层，一次从未重复过的具体方向内容，不能仅凭没有再次发生就被排除；复走支撑只在沉积场层恢复。

## 第七节　可变实现项与非不变量

以下都不是理论中立的不变量，它们随实现改变：物理材料；节点数量；拓扑；模块划分；集中或分布承担；连续或离散编码；时间尺度；算法；中介链长度；生物或人工载体；是否有离散的门；门是否为单个节点；概率是否以数值形式存在、是否可读；具体的调谐算法；动力环这一种环形拓扑。

内源发动、内部调制与离散交接，在理论中立层也不是不变量；它们在自显场中，经第九节带条件的表示桥，才取得更强的地位。

## 第八节　沉积场表示：律与概率

设 X ∈ Ω\_Sed。进入沉积场以后，恢复《自显论》的沉积场纪律。

一、正式方向角色必须由律承担

在沉积场中，一个方向要成为当前的正式方向角色，不能只是裸候选、新径或一次偶发；《概率组式》规定，概率维是已经沉积的路径，不是可能路径。一条新径只有经过“实际发生 → 沉积 → 取得律承担 → 进入概率组织”，才成为正式方向维。

需要区分两种“新”。新的具体目标或内容可以第一次出现，并由既有的、已由律承担的方向组织承载，例如第一次想去一座从未去过的城市；新的独立方向职责维，必须先取得律承担。新内容可以即时出现，新正式方向维不能无资格地即时出现。

二、律的取得路线

本篇固定采用以下路线，不与其他路线混用。

在沉积场中，正式方向维是已经沉积的路径，所以承担它的结构 R 直接具有“当前沉积承载组织”的语义，Established 由此直接读取，不经过“关系承载实现 → 沉积状态”的 H1。DynamicRole 由正式方向角色本身给出：一个正式方向角色，如果不真实进入它所申报的后继关系的生成，就不是当前的正式方向承担；所以 R 真实进入这一后继生成。这里不依靠 SB1 的宽泛析取，因为 SB1 所列的某些改变，例如可用性的门控，只是上游条件，不等于承载真实进入后来的生成。ΩSupport 需要由 StableReplay 取得。正式方向维在所声称的适用范围内能稳定复走：《概率组式》登记的语料说，各方向是在路径上受奖惩而沉积成的“律续行熟路”，熟路就是相近条件再次到来时能够再次承担的路径；由 StableReplay 到 ΩSupport，需要《律组式》登记的 H2，以及 H\_3^red。在这些条件下，调用《律必然式》的充分方向，各正式方向由律承担，即 MultiLawDimension。

三、由系统方向承担特化为率承担

SysBear 是上位职责，它只要求 X 内部的组织能改变方向的可达关系、相对生成、排序、可用性或实际落向中的至少一项。进入概率问题时，它还不够。

设世界 W9：多条由律承担的方向共同回答同一个续行问题；X 的方向组织 D 能决定哪些方向可达，SysBear 因而成立；但在可达的方向之间，相对生成由另一个机制 M 承担，M 或在边界之外，或在边界之内却不属于 D。

在沉积场中，多条由律承担的正式方向已经共同回答同一个续行问题，“为什么本次续行落向这一类而不是那一类”，答的正是各方向之间的相对生成：按《概率组式》，同一续行位上各维之间的相对生成关系，就是续行在各维之间怎样生成的关系，数值率只是它的一种表示。W9 中，D 只设定了可去之处，在可去之处之间作出区分的是 M。所以申报“方向差异属于 D 所在系统的定向角色”，在“落向哪一类”这一核心上落空：系统只提供了菜单，定向在 M。《概率组式》对此的裁定相同：结果的执行、局部活动、同一物理系统中的旁支，都不能代替概率组织自身对相对生成的承担。

由此，在沉积场中，SysDirClaim 经审查成立，还要求 SysBear 的率承担特化：

&nbsp;&nbsp;&nbsp;&nbsp;SysRateBear(D; C)：在 C 的各正式方向之间，相对生成关系由方向组织 D 自身承担

SysRateBear 包含于 SysBear，但不等于 SysBear；它是 SysBear 进入概率问题以后的职责特化，在沉积场中由 W9 独立取得。

四、概率的取得

C 由任务入口冻结，各正式方向共同回答它，即 CommonContinuationBind。于是

&nbsp;&nbsp;&nbsp;&nbsp;MultiLawDimension ∧ CommonContinuationBind ∧ SysRateBear ⇒ N\_P

其中 SysRateBear 就是 DomainRelativeRateBearing 的内容。调用《概率必然式》的充分方向 N\_P ⇒ Probability，得 Probability。

DirPersist 在这一层保证：各概率维之间的区分，一直存续到它们取得不同后继责任的地方，各维不会在中途合一。

定理四（沉积场表示定理）。设 X ∈ Ω\_Sed，SysDirClaim(X) 经审查成立。在 H2 ∧ H\_3^red 之下，X 的正式方向由律承担，其方向组织承担率的相对生成，并取得 Probability。

本篇不新增这些条件，它们是《律组式》现有的登记；Probability 的充分方向本身不携带 H。

## 第九节　自显场表示：四项必要核

设 X ∈ Ω\_SM。下面用独立于《意向一般式》的上游场结构，逐座建立四座表示桥。每座桥只用比目标结构更弱的独立前件；凡独立前件不足以闭合的，显式登记为 H。《意向一般式》的语料只在本节末作一致性回测，不作证明前件。

所用的独立上游结构：

SMGateBoundary　《式篇第四》的关系分类：界门关系是 Gate、Pass 及其调谐控制关系。它只说 Gate、Pass 属于这一类控制边界，不说方向与门一一对应。  
SMTuningStructure　《式篇第四》的关系分类：统摄关系是理场使役调谐关系、TunePriority 赋权关系；TunePriority 定义为“意向场经欲门对回路之调谐资源分配权重与参数更新贡献之赋值”，所引外篇九的通路为“意向域动力环 → 欲门 → 使役调谐”。它说明自显场中存在合法的“经欲门使役调谐”结构，不说每一个欲门之后都有调谐接口。  
SMSourceStructure　《喑显组式》所承继的《微核论》《意图场》结构：A/B、动力环、主动因等结构给出“当前内源发出”与“B 侧作用”，意图场给出 B 侧作用与后向使役；动力环只是其中一种实现。它说明自显场存在内源一侧，不说意向方向组织的全部欲门续行都由它发出。

《概率组式》登记的“源动驱动的概率，生在意图场”是位置语句，“欲门对应概率的方向维”是母本关系语句；二者不是独立的结构定理，本节不以它们作证明前件，只作回测。

一、P\_I

由定理四，X 的方向组织取得 Probability。要得到 P\_I，还要证明这份组织位于意向域，而不是其他场域中的概率组织。独立上游结构没有给出这一定位。登记：

&nbsp;&nbsp;&nbsp;&nbsp;H\_PL（意向域概率定位桥）：在自显场中，承担当前意向定向职责并取得正式 Probability 的方向组织，属于意向域一侧，而不是其他场域的概率组织。

于是：

&nbsp;&nbsp;&nbsp;&nbsp;Probability ∧ IntentDirectionalRole ∧ H\_PL ⇒ InIntentDomain，从而 P\_I

其中 IntentDirectionalRole 指这份组织承担的是 SysDirClaim 所申报的定向角色。P\_I 在逻辑上不依赖 SourceDrive，所以不携带 H\_SD；它携带 H\_PL 与定理四的条件。

二、SourceDrive

由定理四，X 的方向组织承担率的相对生成（SysRateBear）。由 SMSourceStructure，当前内源发出的一侧已有独立的结构根据；由 SMTuningStructure，它在现行自显场实现中的合法通路，可以经意向域动力环、欲门而到使役调谐。

但理论中立层的 W5 表明，系统方向承担推不出内源发动；要排除“由外部启动、只在内部定向”的续行也经意向方向组织通向欲门，需要一个全称：意向方向组织的全部欲门续行，都由内源一侧发出。独立上游结构没有给出这一全称。登记：

&nbsp;&nbsp;&nbsp;&nbsp;H\_SD（源动完备发出桥）：在自显场中，属于意向方向组织的欲门续行，其发出都出自意向域的内源一侧。

于是：

&nbsp;&nbsp;&nbsp;&nbsp;SysRateBear ∧ SMSourceStructure ∧ H\_SD ⇒ SourceDrive

即这份组织本身处在源动驱动之中，并承担源动在各方向上的续行。源动写成意向组织自身所处的驱动，不写成组织之外、事后接入的对象。

三、GateCorrespondence

由 DirPersist，方向区分存续到它取得不同后继责任的地方；由 SMGateBoundary，Gate、Pass 属于自显场中的界门关系。

但 SMGateBoundary 只说 Gate、Pass 属于界门关系，没有说方向第一次取得后继责任的地方就是界门；而且 DirPersist 允许一个方向由多个物理组件共同承担，允许多个方向共享通路、以状态区分，也允许一个方向同时进入两个从不产生新独立选择的协同门角色。所以还需要两点前提：方向第一次取得后继责任的边界是界门，界门按方向职责划分。独立上游结构没有给出这两点。登记：

&nbsp;&nbsp;&nbsp;&nbsp;H\_GP（界门分割桥）：在自显场中，方向取得后继责任的第一次正式控制边界是界门，并且界门按方向职责划分；一个界门职责类对应且只对应一个方向职责类，界门角色不新增方向，也不合并已有方向。

于是：

&nbsp;&nbsp;&nbsp;&nbsp;DirPersist ∧ SMGateBoundary ∧ H\_GP ⇒ GateCorrespondence

对应在职责类的层面成立：∀ 方向职责类 \[v\_i\]\_D，∃! 界门职责类 \[G\_i\]\_D；∀ \[G\_i\]\_D，∃! \[v\_i\]\_D。不要求单个物理节点。

四、TuneInterface

由 GateCorrespondence，每一个方向职责类都有它的界门职责类。由 SMTuningStructure，自显场中存在合法的经欲门使役调谐结构。

但入口规定 V 是后继类，只保证每个方向不是没有后继的标签，不保证它的后继必须是调谐接口；理论上可能出现 Gate\_i → Effect\_i，绕过调谐一侧，直接承担后继。要排除它，需要一个全称：当前意向欲门的合法后继职责，都进入调谐一侧。独立上游结构没有给出这一全称。登记：

&nbsp;&nbsp;&nbsp;&nbsp;H\_TI（欲门—调谐完备桥）：在自显场中，每一个正式欲门的合法后继职责，都由调谐一侧承担，不绕过调谐一侧直接承担完整的意向后继职责。

于是：

&nbsp;&nbsp;&nbsp;&nbsp;GateCorrespondence ∧ SMTuningStructure ∧ H\_TI ⇒ TuneInterface

这一桥不断言一切可能的意向都有内部调谐，只说明在自显场中，欲门之后的合法后继落在调谐一侧。

五、共锚绑定

以上四座桥分别证明四项结构。如果允许四项分别取自不同的东西，就会出现拼证：组织 A 满足 P\_I，组织 B 满足 SourceDrive，方向族 C 满足 GateCorrespondence，欲门链 D 满足 TuneInterface；四项各自为真，却不构成同一个必要核。《概率组式》对同型问题已有纪律：同一 Probability 的各维必须同绑于同一续行位、生成域与组织，多项职责必须在同一见证上成立。

所以四项合取时，必须满足共锚绑定：

&nbsp;&nbsp;&nbsp;&nbsp;CoAnchor\_I(K\_I)：K\_I = (χ\_UI, 𝒫\_I, C\_I, \[V\]\_D, \[𝒢\]\_D)

即四座桥所调用的 Probability、SysRateBear、DirPersist、方向职责类、界门职责类与调谐接口，都锚定于同一个任务实例 χ\_UI、同一个正式方向组织 𝒫\_I、同一个续行位 C\_I，以及与之对应的同一个方向职责族 \[V\]\_D 和同一个界门职责族 \[𝒢\]\_D；不得跨组织、跨续行位、跨方向族、跨欲门链拼接四项。

共锚绑定是良构的绑定纪律，不是第五项职责，也不新增 H。它锚定的是组织、续行位和职责族，这些都可以区分和计数；它不对意向本身计数。

六、定理

定理五（意向普遍表示定理）。设 X ∈ Ω\_SM，SysDirClaim(X) 经审查成立。那么：

&nbsp;&nbsp;&nbsp;&nbsp;Probability ∧ IntentDirectionalRole ∧ H\_PL ⇒ P\_I  
&nbsp;&nbsp;&nbsp;&nbsp;SysRateBear ∧ SMSourceStructure ∧ H\_SD ⇒ SourceDrive  
&nbsp;&nbsp;&nbsp;&nbsp;DirPersist ∧ SMGateBoundary ∧ H\_GP ⇒ GateCorrespondence  
&nbsp;&nbsp;&nbsp;&nbsp;GateCorrespondence ∧ SMTuningStructure ∧ H\_TI ⇒ TuneInterface

合起来，在定理四的条件 H2 ∧ H\_3^red 与 H\_PL ∧ H\_SD ∧ H\_GP ∧ H\_TI 之下：

&nbsp;&nbsp;&nbsp;&nbsp;∃K\_I \[ CoAnchor\_I(K\_I) ∧ P\_I(K\_I) ∧ SourceDrive(K\_I) ∧ GateCorrespondence(K\_I) ∧ TuneInterface(K\_I) \]

即四项在同一套锚上共同成立。四座桥各自携带自己的条件，彼此不串联；只有 TuneInterface 以 GateCorrespondence 为前件，因而同时依赖 H\_GP。

七、与《意向一般式》的一致性回测

《意向一般式》登记的语料与四座桥一致：I7（概率在意向域，不在欲门之后；概率维通向欲门，是一一对应）支持 H\_PL 与 H\_GP；I6、I8（源动到欲门之间有路径、有律；意向是具有源动驱动的概率组织）支持 H\_SD；Q5、I2（意向域连接经验，中经调谐场，使役调谐；过欲门后使役调谐律破持经验场）支持 H\_TI；Q4、Q6 与意向域、源动之核的结构一致。《概率组式》登记的“源动驱动的概率生在意图场”“欲门对应概率的方向维”也与之一致。

这些语料在《意向一般式》的体系内支持四座桥，但不能替本篇独立闭合它们；所以四座桥在本篇登记为 H。

推论一。《意向一般式》的四项，不是任意挑出的四个部件：真正跨实现普遍的是系统方向承担与方向区分存续；进入沉积场，前者特化为率的承担，方向由律承担并组成概率；进入自显场，受界门与统摄的关系分类、内源一侧的结构约束，它们落到四项结构的位置上。本篇把这一落成逐座拆为四座桥：每座桥中，哪部分已有独立的跨实现根据，哪部分仍依赖自显场特有的前提，都已分开登记。

推论二。意向域、欲门、调谐场是自显场的实现名称；其他实现可以没有同名的结构，却不能没有系统方向承担与方向区分存续。

## 第十节　分层击穿

击穿分三层登记。表示层的桥断裂，不使理论中立层失效。

一、击穿理论中立层

K-Inv1：存在 X ∼\_task X′，两端的 SysDirClaim 都经审查成立，而 SysBear 或 DirPersist 在一端不成立。  
K-Inv2：存在申报经审查成立、却不满足 SB1 至 SB4 中某一项的合法实现。  
K-Inv3：存在申报经审查成立、方向差异在兑现后继责任以前已彻底消失的合法实现。  
K-Inv4：SysBear 与 DirPersist 可以相互推出，从而两项可以合并。  
K-Inv5：任务保持关系的定义实际依赖两项职责，从而定理三循环。  
K-Inv6：某一结论依赖未申报的实现条件，例如材料、节点数、神经实现、离散时间、数值概率、唯一承载、单门单节点。

二、只击穿沉积场表示层

K-Inv7：H2 或 H\_3^red 不成立，使正式方向的律承担不能取得；或者 W9 的裁定不成立，即在沉积场中 SysBear 不需要特化为率的承担。这只使定理四及定理五中依赖它的项失效，不击穿定理三。

三、只击穿自显场表示层

K-Inv8：SMGateBoundary、SMTuningStructure、SMSourceStructure 中某一项被证明与上游原文不符，或不足以承担所用的桥；H\_PL、H\_SD、H\_GP、H\_TI 中某一项被证明不成立；或者存在 X ∈ Ω\_SM，相应职责与 Probability 都成立，而 P\_I、SourceDrive、GateCorrespondence、TuneInterface 中某一项不成立。这只击穿定理五中的相应项，不击穿定理三。

K-Inv9：跨锚拼证。四项分别可以在不同的方向组织、不同的续行位、不同的方向族或不同的欲门—调谐链中取得，却不存在一套共同的锚使四项共同成立；如果仍判定 N\_I 成立，定理五被击穿。

下列情况不构成击穿：两种实现使用不同的材料；一种集中，另一种分布；一个方向由多个节点共同承担；多个方向共享同一条物理通路而职责状态可以区分；欲门职责没有唯一的节点；概率的率值不可读；某一维当前的率为零；当前没有实际的源动脉冲；当前的意向没有显化或没有转为行为；外界刺激诱发了意向；理论中立层中存在不具有内源发动或内部调制的系统定向实现；一个合法重实现把定向资格做坏，使申报不再成立。

## 第十一节　条件账与强度

一、条件账

第一层（定理一、二、三）：不携带 H。依赖任务入口、任务保持关系与归属审查，这些是工作域与比较协议，不是 H。

第二层（定理四）：采用由沉积场正式方向资格直接读取 Established 的路线，不经 H1；继承《律组式》登记的 H2 与 H\_3^red；SysRateBear 由 W9 在沉积场中独立取得，不携带 H；调用的《律必然式》《概率必然式》充分方向本身不携带 H。

第三层（定理五）：P\_I 携带 H\_PL 与第二层的条件；SourceDrive 携带 H\_SD，并因所用的 SysRateBear 而继承第二层的条件；GateCorrespondence 携带 H\_GP；TuneInterface 携带 H\_TI，并因以 GateCorrespondence 为前件而同时依赖 H\_GP。

&nbsp;&nbsp;&nbsp;&nbsp;H\_new = { H\_PL, H\_SD, H\_GP, H\_TI }

四项都是本篇新增的桥接条件：它们在《意向一般式》中由其语料直接给出，本篇要求由独立的上游场结构闭合，目前尚未闭合。如果以后能从场篇独立闭合其中某几项，逐项关闭，不必整篇重研。

共锚绑定 CoAnchor\_I 是良构纪律，不携带 H。第三层的总条件，是取得四项合取 N\_I 时的联合条件；单项结论只传播自身实际证明路径上的条件：P\_I 为 H2 ∧ H\_3^red ∧ H\_PL；SourceDrive 为 H2 ∧ H\_3^red ∧ H\_SD，因为它所用的 SysRateBear 是在由律承担的正式方向上取得的；GateCorrespondence 为 H\_GP；TuneInterface 为 H\_GP ∧ H\_TI。

状态：第一层（定理一、二、三）为 Established；第二层（定理四）为 Conditional，条件为 H2 ∧ H\_3^red；第三层（定理五）为 Conditional，条件为 H2 ∧ H\_3^red ∧ H\_PL ∧ H\_SD ∧ H\_GP ∧ H\_TI。

二、强度

本篇证明的是语义层面的职责不变量与表示，不提供可执行的跨实现判定算法。第一层不断言任何系统都有律、概率、意图场、欲门或调谐场；第二、三层只在沉积场、自显场的工作域内成立。

本篇不得用理论中立层的宽松概念反向削弱《意向一般式》：中立层不要求历史复走，但在《自显论》中，新径候选不等于正式方向维，Intent ⇒ P\_I 不改。

三、完成条件

一、入口没有预埋待比较的职责，也不引用《意向一般式》的四项结构。二、任务保持关系的定义不含两项职责。三、两项职责由归属审查独立取得，并证明相互独立。四、不进入中立层的职责都有明确的理由或反例。五、非不变量显式列出。六、沉积场表示逐项核对，固定律的取得路线，并以 W9 独立取得率承担的特化。七、自显场表示由独立上游结构逐座建立四座桥，每座桥只用比目标结构更弱的独立前件，《意向一般式》的语料只作回测；未闭合的桥登记为 H\_PL、H\_SD、H\_GP、H\_TI。八、四座桥取得四项合取时，必须通过共锚绑定 CoAnchor\_I；绑定不增加第五项职责，但必须写在总定理之内。九、击穿按三层登记。

## 第十二节　《法篇》制度接口及组内分工

一、组内分工

上承：《意向一般式》的 N\_I 只作第九节的表示目标，其语料只作一致性回测；《喑显组式》所承继的《微核论》《意图场》结构；《律组式》《概率组式》的充分方向与纪律；《式篇第四》的关系分类与 TunePriority 定义。

下交：任务保持关系、归属审查与 SB1 至 SB4、SysRateBear、DirPersist 的数理表示，交《意向数理式》；H\_PL、H\_SD、H\_GP、H\_TI 的对象层独立闭合，交相应场篇、结构篇或后续专门承担该桥的本体式文；《意向数理式》只承接这些桥的形式表示、操作判据与回读，不承担其本体真值的证明；具有这些职责是否足以成为意向，交《意向必然式》；一次源动实际走哪一维、欲门一次切换怎样发生、意向何时实际作用、怎样起续止、首次怎样形成、怎样保持恢复、现实系统是否已有意向、何时显化，分别交本组式相应各篇。

本篇不改变《意向一般式》的任何结论；它补充的是：四项结构如何由跨实现职责进入自显场以后逐层取得，以及这一表示当前还依赖哪些尚未独立关闭的桥。

二、《法篇》制度接口

现行《法篇》规定附式十五种、分为五组，并把“五组是否穷尽未来一切依附任务”列为法篇第四-H1，持续回测；同时把“不变量”列为候选附式的优先观察对象，并规定新附式必须同时通过六项检验：有独立的待证任务，不能被现有式种自然吸收，有独立的推导程序，有独立的完成条件，有独立的击穿方式，能跨多个对象复用。

本篇的任务是比较任务保持的不同实现之间什么职责不能逃，推导程序是“入口冻结 → 比较协议 → 归属审查 → 两端分别成立 → 分层表示”，击穿方式与完成条件见第十、十一节；它与一般式（必要构成）、数理式（精确表示）、必然式（充分方向）、稳定式（已成资格在许可变化下的保持与复归）、构造式（造出满足者）各不相同。跨对象方面，《概率组式》中实现更替不等于正式概率组织的改变，《理组式》中同一职责可以经过长中介链、换载体或分布式共同承担，二者都出现同型任务，这些只作回测。

本篇的不变量任务及六项检验已经闭合，因此本篇构成法篇第四-H1“五组穷尽性”的实证反例，并触发《法篇》后续升版：附式由五组升为六组，新增第六组“不变量组”，附式由十五种升为十六种，新增第十六附式“不变量式”，主式仍为五种。在《法篇》完成升版以前，现行《法篇》文本仍保持十五附式、五组的版本事实。
