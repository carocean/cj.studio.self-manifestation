# 理生成可达式

## 第一节　目的与进入条件

### 1.1　目的

《理运行基底构造式》已经构造出可运行的理基底：同一规格的合法实例中，多律由弱态形成，一条律以使自身成律的同一职责取得对另一条律的理资格并当前行，场动力本身改路、留迹、沉积，一条初始不成立的候选律最终由同一通用律判取得资格。构造已经给出。

剩下的是可达问题：从一个申报的初态出发，只用事前冻结的许可输入与系统自身的合法动力，是否存在一条有限合法路径，使候选律的形式解集由空变为非空；并且该路径中是否存在具有理与理之行来源资格的实际反持生成历史。

以下只回答这一问题：不重新构造理基底，不重新定义 Law、Principle、Act，不重新研究理成立必须具有什么。

### 1.2　进入条件

　　（一）构造已经给出：《理运行基底构造式》v1.0 与其正式构造模型 v4.12。  
　　（二）初态界定清晰：第二节申报。  
　　（三）许可输入集界定清晰：第三节申报，并在路径构造以前冻结。

### 1.3　与相邻式文的分工

第七篇回答"满足者长什么样"，此处回答"从给定初态能不能走到"。律层的资格判据由律组式承担，理与理之行的判据由理组式前六篇承担；以下只在既有判据之上作路径论证。理的稳定、边界、分级与生成的概率结构，各归其式，不在此涉及。

## 第二节　任务规格、初态与目标

### 2.1　冻结任务规格

　　Ξ\_GR = (Spec, P, A, d\*, N, I\_N, U^adm)，

其中 Spec 为已构造的合法运行规格，P 为已成理的承载律，A 为 P 所针对的目标律，d\* 为使 P 成理的同一职责，N 为预先冻结的候选律身份，I\_N 为其入口域，U^adm 为许可输入集。

Ξ\_GR 在整条路径上不变。它是冻结的任务规格，不是动态状态；动态状态只用 F\_t 表示当前场状态，不另设复合状态结构。

### 2.2　目标集

　　G\_N = { F \| 𝒮(F, N, I\_N) ≠ ∅ }。

这是候选律 N 已取得至少一个合法形式见证的身份级目标。固定见证的版本

　　G\_{N,R} = { F \| R ∈ 𝒮(F, N, I\_N) }

只作为更强的子任务出现：第六节的实例路径实际命中的是 G\_{N,R\_N}，而 G\_{N,R\_N} ⊆ G\_N，故亦命中 G\_N。一般定理只要求解集非空，不固定任何预选的 R；实例恰好给出一个 R，是实例事实，不是定理的要求。

### 2.3　初态申报

形式层初态条件：

　　𝒮(F₀, N, I\_N) = ∅，即 F₀ ∉ G\_N。

这是所要跨越的起点。不以"Law(N)=0"作为唯一的初态条件——解集非空与律层回读是两层，混用即层次漂移。

理来源侧的初态条件：

　　Law(P) = 1，Law(A) = 1，Principle(P; A, J) = 1，且 d\* 为使之成立的同一固定职责。

此处的 Principle 按上游带关系域 J；本式所论的关系上下文取 j ∈ J，路径全程不换 j，亦不换 J。

不要求初态 Act = 1。行是路径运行中的当前事实，不是初态的申报项。

## 第三节　许可输入与合法支持后继

### 3.1　许可输入

　　u\_k ∈ U^adm。

U^adm 由 Ξ\_GR 在路径构造以前一次冻结，其内容随任务规格申报，不由本式一般地规定；凡定理中出现 U^adm 者，指该次申报所冻结的那一个集合。扩大它即须另行申报并重新走可达论证。

在所用的运行实例中，U^adm 只含一种输入：

　　u\* = ( {s, hR}, {dR} )，

即正常入流与已冻结的同一职责的激活。

须分清两件事：激活 d\* 是输入；Act(d\*)=1 是系统按 Spec 运行之后的事实。行不是可以从外部按下的按钮，路径不得把它当作操作。

### 3.2　系统动力

下列由 Spec 自动发生，不是外部操作，不计入 U^adm：场压与流、积深、满度、阻抗、阻断、调谐、分支竞争、实际执行、迹、沉积、复走、Ω、衰减。

### 3.3　合法支持后继

定义集合值映射

　　F\_GR(F, u)

为在冻结的任务规格与输入 u 下，仅由 Spec 已声明的正常系统动力所能产生的合法一步后继集合。

它必须是集合值：参考实现的分支竞争含随机选择，一步之后可能落在若干合法状态之一。随机分支属于系统支持，不属于外部可控动作；不得把它写成可指定的操作。

F\_GR 只由 Spec 的动力与所给输入决定：3.4 所列的禁用操作不在 Spec 的正常动力之内，故经它们所得的后继本就不属于任何 F\_GR(F, u)，不必另作排除——禁用清单是对路径构造者的约束，不是对后继集的削减。

### 3.4　禁用操作

正路径禁止使用：分支强制；外部门控；外部编辑；直接写深；直接写复走；直接设定律资格；中途改拓扑；中途换职责；中途换理资格绑定；中途换候选律；运行中修改律判据或阈值；中途扩大许可输入集。

门控、编辑与分支强制只允许出现在对照实验中，不得进入正可达论证。

## 第四节　有限合法路径与理源支持可达

### 4.1　路径

　　Γ = ( F₀, u₀, F₁, …, u\_{H−1}, F\_H )。

Γ 合法，当且仅当对一切 k \< H：

　　u\_k ∈ U^adm，且 F\_{k+1} ∈ F\_GR(F\_k, u\_k)。

### 4.2　理源支持可达

先定义无来源限制的支持可达：

　　SuppReach\_GR(F₀, N) = 1　⟺　存在有限合法路径 Γ: F₀ ⇝ F\_H 使 F\_H ∈ G\_N。

再定义其带来源限制的子类：

　　SuppReach^PrinAct\_GR(F₀, N) = 1

表示：存在有限合法路径 Γ: F₀ ⇝ F\_H，使 F\_H ∈ G\_N，并且路径中存在具有理与理之行来源资格的实际反持生成历史——即至少一次 Act(P; A, d\*) = 1，且同一实验中 d\* 所兑现的反持经正常场动力进入终态某个合法见证的实际执行、迹与沉积历史。

"PrinAct"只标记这条路径的来源类别，不是新的本体谓词。全部构成项——同一 d\*、Principle、Act、实际执行、迹、沉积——均取自上游，不在此新造。

来源型的限定：所签的 PrinAct 取直接型——至少一个进入终态合法见证的实际执行、迹与沉积事件，与合法的 Act 发生于同一实验。另有一种可设想的间接型：行先改变场态，其后承载律静置，由已改变的场态在无行的后续实验中继续改路、沉积并最终使 N 成立。该跨实验的启动—完成型不在本版所签范围内，也不因本版而被排除；对它的一般判定未立。

## 第五节　理来源限定

来源资格与物理动力必须分开。

来源资格指：产生该反持的职责，是承载律取得律资格时所绑定的同一职责，且该职责在当前实验中已取得理资格并实际登记为行。它由上游的判据给出，是一项身份事实。

生成动力指：该反持进入目标所持自由度之后，经阻断、调谐、竞争、执行、迹与沉积所产生的场变化。它由 Spec 的动力给出，是一项动力事实。

二者不等同，须分三层。其一，理资格不蕴含行：Principle 成立而当前未触发、或目标本拍不在承担时，不登记为行。其二，行一旦成立，则同一职责的当前反持已经实际兑现——这是上游 Act 自身的内容，不是一个空标记——但它仍不蕴含某一指定的后继必被选择、留迹、沉积并最终使 N 成立：分支竞争是场的事，不由行的身份决定。其三，反过来，同型的反持及其后续场动力也不蕴含理与理之行的来源身份，第十节的非绑定职责对照即为反例。

以下不主张理的身份提供任何额外的力。Act 不是第二种资格，也不是可以独立于其所兑现的反持而改变物理的标记。

## 第六节　路径构造：显式合法路径

### 6.1　协议

取第七篇所构造的规格与其冻结初态。每一步只施加 u\*，即每一实验调用正常入流与同一职责的激活，其余全部交由系统动力；不使用任何第 3.4 节所列的禁用操作。

### 6.2　显式路径（种子 0）

初态：A、P\_R、P\_D、Q、B 各为律，N 不是律，且 𝒮(F₀, N, I\_N) = ∅——律判在读一项失败，无见证。

自 F₀ 起逐步施加 u\*：

　　第 1—4 实验：P\_R 的同一职责 dR 的理资格自初态起即成立并保持，每一实验登记为行，其反持进入 A 所持自由度的阻抗，结果量下降，阻断累积，旧路开放度下调、旁路上调；分支仍走旧路。  
　　第 5 实验：分支竞争首次实际走旁路 m→x，该边留迹、沉积、登记复走，其后继路径随之执行。  
　　第 6—14 实验：旁路反复被实际执行，深与复走累积。  
　　第 15 实验：复走数达 11、Ω 为 1、深超过阈值，N 的路径全部具备深、复走与 Ω，同一通用律判判得

　　　　𝒮(F₁₅, N, I\_N) ∋ R\_N = { s→m, m→x, x→n, n→d }，

故 F₁₅ ∈ G\_N，H = 15。

全程 Law(A)=1、Law(P\_R)=1、Principle(dR)=1，且每一实验 Act(dR)=1（15/15）。终态见证中的各边均具有其自身的实际执行与沉积历史；自 F₀ 出发的这条生成路径所新增并闭合的关键承担在旁路 m→x——见证中的其余各边在 F₀ 上已是成熟结构。旁路 m→x 在 F₀ 上并非零深：其深为 0.02167、复走为零，远不足以取得资格；自 F₀ 以后，使它由该浅态推进至终态资格所需的全部新增实际执行、复走与沉积（复走 0→11，深 0.02167→1.04569），发生于 dR 当前兑现反持之后的生成路径中。

该路径的每一步只用 u\*，每一后继都属 F\_GR(F\_k, u\*)，故 Γ 合法；终态命中 G\_N；路径含合法来源资格的反持生成历史。于是

　　SuppReach^PrinAct\_GR(F₀, N) = 1

在该实例上成立。

### 6.3　路径的复现范围

同一协议在 200 个种子上全部到达 G\_N。到达以前逐实验检查：Law(A) 不失 200/200，Law(P\_R) 不失 200/200，Principle(dR) 不失 200/200，每一实验登记为行者 200/200。到达步数见第八节。

## 第七节　有限秩可达性论证

第六节给出一条显式路径，这已足以支撑第九节的定理。以下另给一条一般的可达性充分条件，用于本式所构造的实例以外的情形；它不是第九节的证明依据，本式也未对第六节的实例构造其秩函数。

定理 7.1　有限秩支持可达定理

设 D 为申报的状态域，D ⊆ 合法状态且对（二）所取的后继封闭，存在函数 ρ: D → ℕ，满足：

　　（一）ρ(F) = 0 ⇒ F ∈ G\_N；  
　　（二）对一切 F ∈ D 且 ρ(F) \> 0，存在 u ∈ U^adm 与至少一个 F′ ∈ F\_GR(F, u)，使 F′ ∈ D 且 ρ(F′) \< ρ(F)。

则对一切 F ∈ D，存在一条有限合法支持路径由 F 到达 G\_N，即 SuppReach\_GR(F, N) = 1。

证明。自 F 出发反复按（二）取后继：每次所取者仍在 D 内，故（二）可继续施用；ρ 取值于自然数且每次严格下降，故至多 ρ(F) 步之后不能再下降，此时该状态的 ρ 只能为 0，于是由（一）落入 G\_N。所得序列的每一步都用许可输入且落在合法后继集内，故为合法路径。证毕。

自然数上的严格下降每步至少减一，故该下降路径的长度满足 H ≤ ρ(F)。

本定理的量词是"对每个 F 存在一个下降后继"，所推出的因而只是"存在一条路径"。它不推出"一切合法路径都到达"，也不推出任何概率结论。

ρ 只是证明工具，不是理或律的新本体；它不进入任何回读。

取得 SuppReach^PrinAct 还须另一步：所构造的下降路径须独立核验满足第四节的来源条件——路径中确有 Act(P;A,d\*)=1，且其所兑现的反持进入终态见证的实际执行与沉积历史。秩的下降本身不保证来源资格。

## 第八节　代价与步数的界

分三层，不得混用。

实例长度。种子 0 的显式路径 H = 15。这是严格的实例事实。

经验界。同一协议在 200 个种子上到达步数的分布为 {12:1, 13:13, 14:72, 15:98, 16:16}，故 12 ≤ H ≤ 16 在该 200 个种子的集合上成立。这是经验界，不是理论上界。

理论界。在定理 7.1 的条件成立处，下降路径满足 H ≤ ρ(F₀)。但本式并未为第六节的运行实例构造具体的 ρ 与 D，也未核验其两项条件；第六节的 H = 15 由实际路径直接给出，不由定理 7.1 导出。对一般的沉积场、一般的候选律与一般的初态，未给出统一的秩函数，也未给出统一的实验步数上界。

　　实例的秩函数：未构造。  
　　一般统一步数界：未立。

其余实例量同属实例事实，不得升格为理论常数：首次实际改路发生在第 5 实验；终态见证中旁路的复走数为 11；深为 1.0457；Ω 为 1。

## 第九节　可达定理

定理 9.1　理源有限支持可达定理

设冻结任务规格 Ξ\_GR，且：

　　（一）𝒮(F₀, N, I\_N) = ∅；  
　　（二）存在有限路径 Γ = (F₀, u₀, …, u\_{H−1}, F\_H)，对一切 k \< H 有 u\_k ∈ U^adm 且 F\_{k+1} ∈ F\_GR(F\_k, u\_k)；  
　　（三）路径中至少存在一次 Act(P; A, d\*) = 1；  
　　（四）在同一实验中，d\* 所兑现的反持经正常场动力进入终态某个合法见证的实际执行、迹与沉积历史；  
　　（五）𝒮(F\_H, N, I\_N) ≠ ∅。

则

　　（甲）SuppReach^PrinAct\_GR(F₀, N) = 1；  
　　（乙）在《律数理式》的正端回读条件束 H⁺\_M 成立时，进一步有 Law\_{F\_H}(N, I\_N) = 1。

证明。（甲）：（二）与（五）给出一条有限合法支持路径命中 G\_N；（三）（四）给出该路径的来源限定——路径中存在具备理与理之行来源资格的实际反持生成历史，且该历史进入终态见证。故由第 4.2 节的定义得 SuppReach^PrinAct\_GR(F₀, N) = 1。（一）另保证初态不在 G\_N，故此处取得的不是目标内的续行，而是 𝒮: ∅ → ≠∅ 的真实生成跨越。

（乙）：由（五）得 𝒮(F\_H, N, I\_N) ≠ ∅；在 H⁺\_M 成立时，《律数理式》的正端回读给出 ∃R\[ Established\_{F\_H}(R) ∧ Govern\_{F\_H}(N; R, I\_N) \]；再由《律必然式》的充分向、在其工作域与承继前件成立时，得 Law\_{F\_H}(N, I\_N) = 1。该结论随 H⁺\_M 与该充分向的前件条件化，不因（甲）无条件而无条件。证毕。

第六节的显式路径逐项满足（一）至（五），故定理的前件在该实例上非空。

### 9.2　向律层的条件化回读

定理 9.1 直接证明的跨越只是形式解集由空变为非空：

　　𝒮: ∅ → ≠∅。

律层的结论须经上游回读，不得直接等同：

　　在《律数理式》的正端回读条件束 H⁺\_M 成立时，𝒮(F\_H, N, I\_N) ≠ ∅ 给出 ∃R\[ Established\_{F\_H}(R) ∧ Govern\_{F\_H}(N; R, I\_N) \]；  
　　再由《律必然式》的充分向，得 Law\_{F\_H}(N, I\_N) = 1。

这两步的条件按原归属承继，不在此升级。凡引用本式结论而要用到律层者，须连同 H⁺\_M 与充分向的前件一并承继。反向亦有纪律：𝒮(F, N, I\_N) = ∅ 不得直接读为 Law(N) = 0；负端另有其条件束，归律边界式。

### 9.3　随机核下的路径概率

参考实现的分支竞争由随机核给出。若一条有限路径每一步都满足 K(F\_{k+1} \| F\_k, u\_k) \> 0，则

　　P\_K(Γ) = ∏\_{k\<H} K(F\_{k+1} \| F\_k, u\_k) \> 0。

第六节的路径确由该核实际生成，故其每一步的转移概率为正，于是该路径的概率严格为正。其中第 5 实验的分支概率已实测为 0.889660228101722（附录 A）；其余各步未逐一记录数值，只由"该路径为该核实际抽样所生成"这一事实保证为正。

不得据此写成概率为一，不得写成几乎必然到达，不得写成一切轨迹到达，也不得由 200 个种子的全数成功推出任何概率等式。

## 第十节　来源与边界

本节的实验只用于划界，不参与第九节的证明。

### 10.1　局部同随机反事实

在首次到达 G\_N 之前取一个实验，固定同一前态、同一普通入流、同一随机状态，唯一的干预差异是是否激活同一职责：30 个种子全部满足——正支登记为行、实际走旁路且该边沉积为正，负支不走旁路、该边沉积为零。种子 0 在第 5 实验：正支该分支的选择概率 0.889660228101722、该边沉积 0.08731367897583661；负支该分支概率 2.770821959531943e-29、沉积 0。同一次随机抽样因此在两支产生不同的实际续行。

这说明 d\* 当前兑现的反持实际改变了分支竞争，并产生了终态见证所用的沉积历史。它不说明"行"这一身份本身提供了额外的力。

### 10.2　整路径同随机配对

自同一初态出发，正轨每一实验施加 u\*，负轨施加同样的普通入流而不激活任何职责。共同随机流由外部主随机源强制：每一实验开始前，由主源为两轨注入同一实验随机流。模型只在分支竞争处抽样，故逐实验注入使两轨在该实验内的随机流相同；不依赖「起点同种子即全程同流」这一未经证明的假设。抽样次数经计数器逐实验比对，两轨不等的实验数为 0。30 个种子全部满足：在正轨首次到达 G\_N 的同一时刻，负轨未到达；负轨旁路的实际执行累计次数为 0，复走为零，Ω 为零。

这说明在同一初态、同一普通入流与同一逐实验随机实现下，唯一干预差异为是否激活 d\*；在这一配对条件下，d\* 所兑现的反持对该有限生成路径具有动力承重性。它不说明没有该职责时 N 在一切未来永不可达。

### 10.3　同效非同一职责

另有一条职责与 d\* 同承载、同目标、同所限边、同增益、同终端，物理效应相同，唯一差别是它不是承载律取得律资格时所绑定的那一条。于是它的理资格与行均为零，而 d\* 的均为一。

长程对照按与 10.2 同一的共同随机纪律进行：同一初态、同一普通入流、逐实验由主源注入同一随机流、同一职责参数，唯一差异为职责身份；各运行 60 个实验，两轨抽样次数不等的实验数为 0。两者到达时刻逐种子相同（30/30 相同，分布同为 {13:1, 14:9, 15:17, 16:3}），该非绑定职责同样 30/30 到达 G\_N。

故此处明确：

　　动力等价 ⇏ 来源资格等价。

不得写"只有理才能生成 N"，不得写"理的身份提供额外的力"，不得写"非绑定职责不能生成 N"，不得写"行本身独立于其所兑现的反持而改变物理"。上列对照已分别排除这四种写法。

### 10.4　外部机制对照

门控、外部编辑与非绑定职责均可到达同一候选 N 的目标集 G\_N：各 30/30 到达，而行的历史为零。

故终态的

　　𝒮(F, N, I\_N) ≠ ∅

本身不证明 N 由理生成；即使在 H⁺\_M 与律充分向的前件成立而进一步回读为 Law(N) = 1，律身份本身仍不携带其生成来源的证明。资格结果不能反推生成谱系。来源须从完整的路径历史取得：Law(P) → Principle(P; A) → Act(P; A) → 实际执行 → 迹 → 沉积 → 终态见证。

### 10.5　不进入一般定理者

实例中候选律的后段由另一条已成之律提供成熟支撑。该角色只属实例，不得写成理生新律的一般必要条件；一般定理只要求终态解集非空，终态见证的已有支撑来自何处不在此固定。

### 10.6　负判

以下只正式证明正可达。若要签

　　Reach = 0，

须证明对一切许可路径与一切有限步数都不命中 G\_N。第七篇所载的若干消融在 60 个实验内未到达，只说明在该申报协议与该时域内未到达，不足以升格为全局不可达。凡未穷尽路径空间者，一律记为未定。

## 第十一节　强度申报

达到可达强度：初态已申报；许可输入集在路径构造以前冻结；合法后继制度明确；给出了完整的有限合法路径；可给出的界已给出、不能给出的已申报。

所签：

　　SuppReach^PrinAct\_GR(F₀, N) = 1，在第二节所申报的初态、第三节所冻结的许可输入与第六节所给的路径上成立；  
　　所给路径在申报的随机核下概率严格为正。

不签：任何可控可达；任何概率为一或几乎必然的结论；"理一旦行必生成新律"；"理是新律的唯一生成机制"；"行的身份是额外的场力"；一般统一步数界；跨实验间接来源型（行先改变场态、其后由无行的实验完成生成）的普遍可达资格。

## 第十二节　击穿

按可达式规范，击穿有两类。

其一，证明一切许可路径都到达不了：对第二节所申报的初态与第三节所冻结的许可输入，证明对一切合法路径与一切有限步数都有 F\_H ∉ G\_N。

其二，展示所给路径包含不许可的操作：指出第六节的路径在某一步使用了 3.4 节所列的禁用操作，或使用了 U^adm 之外的输入，或某一后继不属于 F\_GR(F\_k, u\_k)。

另有三类针对以上陈述的击穿：展示第六节的路径在所声明的模型版本、种子与参数下不能复现；展示第九节的回读越过 H⁺\_M 而直接断言律层结论；或对定理 7.1 展示下列之一：所声称的 ρ 不取值于自然数；某个 ρ\>0 的状态不存在满足条件（二）的后继；所取后继并未严格降秩；下降后继跑出申报域 D；ρ=0 而该状态不在 G\_N 内。秩在自然数上严格下降必然有限终止，这一步本身不可击穿。

以下不构成击穿：一般统一步数界未立（已申报）；某些消融协议在 60 个实验内未到达（属未定，非不可达）；非绑定职责、门控与编辑同样到达 G\_N（已作为边界写明）；生物实现上的差异。

"""Reachability-side verification protocols for the reach form (rebuilt from the engine's public API).
Commands: path0 | dist200 | gr1 | gr2 | dx | nolaw"""
import json,sys,copy,random
from collections import Counter,defaultdict
import full_dynamics_sediment_field_v4_12 as M

U_ADM=({"s","hR"},{"dR"})   # the only admissible input used on the positive path

class CountingRandom(random.Random):
    """random.Random that counts how many draws an episode consumes, so that a
    'same random stream' claim can be verified rather than assumed."""
    def __init__(self,seed=None):
        super().__init__(seed); self.draws=0
    def random(self):
        self.draws+=1
        return super().random()

def _inject(engines,episode_seed):
    """Give every engine the identical random stream for the coming episode.
    The engine draws at exactly one place (the junction softmax), so re-seeding
    per episode makes the streams identical regardless of how many draws each
    trajectory happens to consume."""
    out=[]
    for f in engines:
        f.rng=CountingRandom(episode_seed); out.append(f.rng)
    return out

def path0(seed=0):
    f=M.build_model(seed); M.train_initial(f)
    out={"S_F0_empty":not f.law_check("N")[0],"fail_at_F0":f.law_check_detail("N")[1]}
    H=None; firstmx=None; acts=0
    for k in range(60):
        l=f.run_episode(*U_ADM)
        if firstmx is None and ("m","x") in l.executed: firstmx=k+1
        acts+=int("dR" in l.act_duties)
        if H is None and f.law_check("N")[0]:
            st=f.edges[("m","x")]
            out.update(H=k+1,first_mx=firstmx,acts_before_H=acts,rep=len(st.rep),omega=st.omega,g=st.g,
                       witness=[list(e) for e in f.law_check_detail("N")[2]])
            break
    return out

def dist200(n=200):
    """Arrival distribution, plus per-episode (not just terminal) checks that
    A, P_R and Principle(dR) never lapse before arrival, and that dR acts every episode."""
    c=Counter(); keep=Counter()
    for seed in range(n):
        f=M.build_model(seed); M.train_initial(f)
        allA=allP=allPr=allAct=True
        for k in range(60):
            l=f.run_episode(*U_ADM)
            allA&=f.law_check("A")[0]; allP&=f.law_check("P_R")[0]
            allPr&=f.principle_check("dR"); allAct&=("dR" in l.act_duties)
            if f.law_check("N")[0]: c[k+1]+=1; break
        keep["A_all_episodes"]+=int(allA); keep["P_R_all_episodes"]+=int(allP)
        keep["principle_all_episodes"]+=int(allPr); keep["act_every_episode"]+=int(allAct)
    return {"firstN":dict(sorted(c.items())),"kept":dict(keep)}

def gr1(n=30):
    """Local counterfactual: identical prior state, identical ordinary inflow, identical
    random state; the sole intervention difference is whether the bound duty is activated.
    Checks execution AND sediment on both branches."""
    ok=0; ex=None
    for seed in range(n):
        f=M.build_model(seed); M.train_initial(f)
        for k in range(60):
            st=f.rng.getstate(); snap=copy.deepcopy(f)
            lp=f.run_episode(*U_ADM)
            g=copy.deepcopy(snap); g.rng.setstate(st)
            ln=g.run_episode({"s","hR"},set())
            e=("m","x")
            plus_sed=lp.sedimented.get(e,0.0); minus_sed=ln.sedimented.get(e,0.0)
            if (e in lp.executed and e not in ln.executed and "dR" in lp.act_duties
                    and plus_sed>0 and minus_sed==0):
                ok+=1
                if seed==0:
                    ex={"episode":k+1,
                        "p_with":dict(lp.candidates.get("m",[])).get(e),
                        "p_without":dict(ln.candidates.get("m",[])).get(e),
                        "sed_with":plus_sed,"sed_without":minus_sed}
                break
            if f.law_check("N")[0]: break
    return {"gr1_ok":ok,"seed0":ex}

def gr2(n=30):
    """Whole-path pairing under a common random stream: before every episode both
    trajectories are injected with the identical episode stream from one master source,
    so the claim of a shared stream is enforced rather than assumed. Draw counts of the
    two trajectories are recorded so that any divergence would be visible."""
    r=defaultdict(int); mismatched=0
    for seed in range(n):
        base=M.build_model(seed); M.train_initial(base)
        pos=copy.deepcopy(base); neg=copy.deepcopy(base)
        master=random.Random(seed+555)
        neg_exec=0
        for k in range(60):
            rp,rn=_inject([pos,neg],master.random())
            pos.run_episode(*U_ADM)
            ln=neg.run_episode({"s","hR"},set())
            neg_exec+=int(("m","x") in ln.executed)
            if rp.draws!=rn.draws: mismatched+=1
            if pos.law_check("N")[0]:
                r["pos_N"]+=1; r["neg_N"]+=int(neg.law_check("N")[0])
                r["neg_mx_exec_total"]+=neg_exec
                r["neg_rep_zero"]+=int(len(neg.edges[("m","x")].rep)==0)
                r["neg_omega_zero"]+=int(neg.edges[("m","x")].omega==0)
                break
    r["episodes_with_unequal_draw_counts"]=mismatched
    return dict(r)

def dx(n=30):
    """Long-run contrast between the bound duty and a physically identical non-bound duty,
    under the same common-random-stream discipline as gr2: identical initial state,
    identical ordinary inflow, identical per-episode random stream, identical duty
    parameters; the sole difference is duty identity."""
    a=Counter(); b=Counter(); same=0; mismatched=0
    for seed in range(n):
        base=M.build_model(seed); M.train_initial(base)
        f1=copy.deepcopy(base); f2=copy.deepcopy(base)
        master=random.Random(seed+999)
        t1=t2=None
        for k in range(60):
            r1,r2=_inject([f1,f2],master.random())
            f1.run_episode({"s","hR"},{"dR"}); f2.run_episode({"s","hR"},{"dX"})
            if r1.draws!=r2.draws: mismatched+=1
            if t1 is None and f1.law_check("N")[0]: t1=k+1
            if t2 is None and f2.law_check("N")[0]: t2=k+1
        a[t1]+=1; b[t2]+=1; same+=int(t1==t2)
    return {"dR_T":dict(sorted(a.items())),"dX_T":dict(sorted(b.items())),"same_T":same,
            "episodes_with_unequal_draw_counts":mismatched}

def nolaw(n=30):
    """Gate / Edit / non-bound duty: no Principle, no Act, yet N still forms."""
    r=defaultdict(int)
    for seed in range(n):
        base=M.build_model(seed); M.train_initial(base)
        for nm,args in (("gate",(set(),{"external_gate":{"A":1.0}})),
                        ("edit",(set(),{"external_edit":{"A":0.8}})),
                        ("dX",({"dX"},{}))):
            f=copy.deepcopy(base); acts=0
            for _ in range(60):
                l=f.run_episode({"s","hR"} if nm=="dX" else {"s"},args[0],**args[1]); acts+=len(l.act_duties)
            r[nm+"_N"]+=int(f.law_check("N")[0]); r[nm+"_acts"]+=acts
    return dict(r)

if __name__=="__main__":
    print(json.dumps({"path0":path0,"dist200":dist200,"gr1":gr1,"gr2":gr2,"dx":dx,"nolaw":nolaw}[sys.argv[1]]()))
