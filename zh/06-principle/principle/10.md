自显论·理篇·理组式第十 v1.0

# 理边界式

## 第一节　基本设定

### 1.1　唯一不可约任务

固定同一个候选理 P、目标律 A、两者的 Law 适用域 I\_P 与 I\_A、预先申报的关系域 J，以及 P 与 A 的 Law 身份之后，只回答一个问题：

　　Principle\_F,t(P; A, J) 何时真正由成立跨到不成立，或由不成立跨回成立？

并须特别回答：一个具体的反持实现、一个承载解、一个 Bind 家族、一个 Anti 自由度、一项原有职责，或一次行的失效，什么时候只是某一份证书退出，什么时候才足以使 Principle 本身退出。

不研究理如何生成，不研究行的持续与终止，不研究稳定宽度、保持时长、恢复、迟滞、重入轨迹与概率，不研究理的分级。

### 1.2　式种与依附

式种为极限式，属边界辨析附式。它在主式已经给出结构之后，辨明该结构成立的边界。

依附下列已封版的式：《理一般式》v1.0、《理数理式》v1.0、《理必然式》v1.0；并承继《律边界式》已经成熟的边界纪律——比较规约先于比较冻结、边界须实际取得、上下确界与取得点分离、端点非对称。不修改上游任何定义，不新增本体谓词，不新增 H。

主式被击穿或撤销，本式结论随之失效或转为待定。

### 1.3　极限方向与极限条件

极限方向：每一次边界比较以前，由 Γ 预先申报一条单向比较路径及其合法变化规则。出界实例沿该路径发生 Principle 由 1 到 0 的跨越，入界实例发生 0 到 1 的跨越。比较方向不等于时间，也不要求所有底层支撑分量逐项同向单调——理的边界恰恰可能出现某一职责退出而另一职责进入、最终共同覆盖关系发生跨越的情形。若采用支撑递减或递增作为特定的比较序，须由 Γ 事先定义该序。

极限条件：沿所申报的方向走到某一处，使得在 A 仍为律的前提下，维持 Principle 资格的合法方式由有到无（出界），或由无到有（入界）。

所要辨明的，就是这一处的位置、它的结构形态，以及越过它以后的退化结果。极限式只回答到哪里失效或到哪里取得，不承担保持、替代与复归。

### 1.4　比较对象与比较规约 Γ

边界比较开始以前，下列各项一次冻结：

　　P；A；I\_P；I\_A；J；P 与 A 的 Law 身份；Rel(P) 与 Rel(A) 中用于识别同一比较对象的身份内容；哪些场状态量允许变化；比较方向；比较分辨率；承载对应规则。

换 P、换 A、缩小 J、改写用于识别身份的 Rel 内容之后重新成立者，不叫原 Principle 恢复或继续，那是另一个比较对象。

J 不得在出现失败以后缩为

　　J⁻ = { j ∈ J \| RelPass(j) = 1 }

再宣称原理仍然成立。

### 1.5　两种不同的边界须先分开

其一，Principle 资格边界。只有比较的两端都仍满足 Principle 工作域时，才定义

　　Cross^Q\_Γ(X⁻, X⁺) ⇔ Dom\_Principle(X⁻) ∧ Dom\_Principle(X⁺) ∧ Principle(X⁻) ≠ Principle(X⁺)，

其中工作域一次闭合定义为上游共同工作域条件的合取：

　　Dom\_Principle(X) ⇔ Law\_X(A, I\_A) = 1 ∧ P ≠ A ∧ I\_P ≠ ∅ ∧ J ≠ ∅。

四项之外不另加条件，也不留待补口。再加上相邻性

　　Adjacent\_Γ(X⁻, X⁺)，

才叫已定位的资格边界：

　　Boundary^Q\_Γ ⇔ Adjacent\_Γ ∧ Cross^Q\_Γ。

按跨越方向再分两类，二者不可混写：

　　Boundary⁻\_Γ ⇔ Adjacent\_Γ ∧ Dom\_Principle(X⁻) ∧ Dom\_Principle(X⁺) ∧ Principle(X⁻) = 1 ∧ Principle(X⁺) = 0（出界）；  
　　Boundary⁺\_Γ ⇔ Adjacent\_Γ ∧ Dom\_Principle(X⁻) ∧ Dom\_Principle(X⁺) ∧ Principle(X⁻) = 0 ∧ Principle(X⁺) = 1（入界）。

此二式与第七节所用者完全一致，两处不得有别。

其二，目标侧定义域退出。若 Law(A) 由 1 变 0，不得直接写成普通的 Principle = 0，记为 OUT\_A。这是目标关系对象退出 Principle 的工作域。《理必然式》已把"A 后来失去 Law"列为 Principle 关系的时间边界，而不是当前资格全部保持时的独立取消项。

因此本式使用四个标记：

　　1：工作域内 Principle 成立；  
　　0：工作域内 Principle 明确不成立；  
　　OUT\_A：A 已退出目标 Law 工作域；  
　　⊥：形式输入、证据或求值不足。

这四个标记分属三层：1 与 0 是工作域中 Principle 的本体真值；OUT\_A 是定义域退出标签；⊥ 是未定标签。OUT\_A 与 ⊥ 都不是 Principle 的第三种本体真值。

### 1.6　结构层核心闭合

在 A 仍属于工作域时，严格承继：

　　必要向：Principle(P; A, J) ⇒ Law(P, I\_P) ∧ CounterHoldRole(P; A, J)，Status = Conditional；  
　　充分向：Law(P, I\_P) ∧ CounterHoldRole(P; A, J) ⇒ Principle(P; A, J)，Status = Established；  
　　双向闭合：Conditional。

不得因充分向为 Established 就把必要向或双向闭合升格。

## 第二节　不可避免性论证

### 2.1　为何出界只能由两大顶层结构承担

在冻结的 M1—M12 语义域内、A 仍为律、P 与 A 与 J 的身份不变、上游必要向的前件成立时，Principle 的内部资格出界只能由下列之一承担：

　　B\_P⁻：Law(P, I\_P) 由 1 变 0；  
　　B\_CH⁻：CounterHoldRole(P; A, J) 由 1 变 0。

入界方向对应两项，且允许二者同时发生变化：

　　B\_P⁺：Law(P, I\_P) 由 0 变 1；  
　　B\_CH⁺：CounterHoldRole(P; A, J) 由 0 变 1。

两个方向的义务须分清，不得把认证条件与责任穷尽混为一谈。

　　认证：对已经认证左端 Principle = 1 的候选出界对，右端只要 Law(P) 与 CounterHoldRole 中至少一项确定失败，即足以认证负端，于是该对为 Boundary⁻。对已经认证左端 Principle = 0 的候选入界对，右端须两项同时成立，才由充分向认证正端。  
　　责任：对一次已经发生的出界，其顶层责任必落入 B\_P⁻ 与 B\_CH⁻ 至少一项；这是穷尽，不是定义。

不对称由此而来：出界的认证只需右端一项失败，入界的认证须右端两项齐备。

不存在第三个独立取消项 X，使

　　Law(P) = 1 ∧ CounterHoldRole = 1 ∧ X = 1 ∧ Principle = 0。

理由直接承继《理必然式》三项已证结论：其一，在冻结母本域内，Principle 的当前成理资格穷尽为 Q\_a—Q\_d；其二，独立取消项为空；其三，主充分定理给出 Law(P) ∧ CounterHoldRole ⇒ Principle。三者合起来即：两项顶层结构同时保持时，Principle 不可能为 0，故任何使 Principle 出界的合法变化，必落在这两项之一上。

这一穷尽是当前冻结母本域内的穷尽。若未来母本或上游理论新增合法的独立取消条件，本式须同步复审；不得写成跨一切未来理论的绝对穷尽。

### 2.2　为何单点失效不可避免地不足

Principle 的反持关系一侧由 CounterHoldRole 承担（另一侧是 Law(P)，见 2.1），而 CounterHoldRole 在形式层由"存在同一职责覆盖整个 J"刻画。存在量词意味着：任何一个具体的见证——一个承载解、一个 Bind 家族、一个 Anti 自由度、一份完整证书、乃至一项职责——退出以后，只要还有另一个合法见证补位，量词仍然满足。故单点失效不足以构成边界，这不是审慎，而是量词结构本身的后果。

### 2.3　为何行的失效不可避免地不属于资格边界

上游第四至第六篇已严格区分"成理资格"与"当前正在行"。Principle = 1 而 Act = 0 完全合法。故当前没有输入、目标本拍不在承担、职责本拍没有实际兑现、当前作用停止，都不能成为 Principle 资格退出的条件。

### 2.4　为何形式层不可避免地不能直接抬为本体层

形式层的判定建立在《理数理式》的表示条件与其调用的律侧前件之上。形式证书集为空，说明的是在该形式表示域内没有可用的证书；把它直接读成本体上的 Principle = 0，等于把表示条件默认为恒真。故形式层的结论抬到本体层时，必须连同 M1—M8 与所调用的律侧表示前件一并承继。

## 第三节　核心定义

本节所定义的四项均为纯形式辅助对象，不是本体对象，不承担 Principle 的定义职能；它们只用于在形式可判域中刻画反持资格的存亡。

### 3.1　形式证书集

定义纯形式辅助对象

　　𝒲^M\_CH(X)：状态 X 上形式反持关系证书的集合。

名称只指向 CounterHoldRole^M，不指向 Principle：它刻画的是形式反持资格，不是本体的理资格。Principle 的本体资格仍由 Law(P) 与 CounterHoldRole 两项承担，形式对象向本体的回读须经《理数理式》M1—M8 与其承继前件。一份证书 C 由下列各项构成，此列举即为闭合定义，不留待补：

　　固定职责 d；  
　　对每个 j ∈ J：固定的合法承载解 R\_j ∈ 𝒮(F, P, I\_P)；该 R\_j 所对应的 Bind 家族 ℱ\_{B,j}；该 j 的联合评价规格；该 j 内 Type-sensitive 的 Sat 与 RelPass 证书；  
　　职责所限的类型；  
　　RoleNonDegenerate 证书；  
　　A 的持有自由度与持向；  
　　Anti 证书；  
　　整个 J 的覆盖结果。

各项均取自《理数理式》已有的证书分量，本式不增不减；若上游升版而分量有变，本式随之复审。

按最终封版的《理数理式》，量词层级为：跨整个 J 固定的是同一个职责 d；不同的 j 可以使用各自不同的合法 R\_j；不同的 j 可以使用各自 R\_j 所对应的 ℱ\_{B,j}；但同一个 j 内不得在不同评价之间更换 R\_j 或 Bind 家族来拼接资格。

不得写成"同一个 Bind 家族必须覆盖整个 J"。

### 3.2　职责覆盖集合

定义纯形式辅助集

　　𝒟\_X(j) = { d ∈ Duties(Rel(P)) \| 存在合法的 R\_j 与其对应的 ℱ\_{B,j}，使 RelPass\_d(P; A, j) = 1 }。

其中 RelPass\_d(P; A, j) = 1 指完整的 RelPass 确定成立，即存在合法承载解与其对应的 Bind 家族，并满足该 j 内全部 Type-sensitive 的 Sat 要求；不是一个裸布尔标签。

须注意 𝒟\_X(j) 只收录 RelPass 确定为 1 的职责：RelPass 为 0 与为 ⊥ 者同样不在其中。故由 𝒟\_X(j) = ∅ 不能直接读出"该上下文上所有职责都确定失败"，只有在 Dec\_CH(X) = 1 时二者才同义。

### 3.3　整体可判前件

定义纯形式辅助谓词

　　Dec\_CH(X) = 1，

表示在状态 X 上：对每个 j ∈ J 与每个 d ∈ Duties(Rel(P))，RelPass\_d(j) 均已落为 0 或 1，无一为 ⊥。于是每个 𝒟\_X(j) 都是确定的集合，其为空即等于该上下文上所有职责确定失败；整体 CounterHoldRole^M 也只取 0 或 1。

这一要求是逐项全称的，不是"取够用的一部分即可"：只要有一个 RelPass\_d(j) 未决，就可能恰是它使交集非空，故 Dec\_CH(X) = 0。

Dec\_CH 不是本体谓词，只是三值制度下的可判性记账。凡由"证书集为空"推出"CounterHoldRole^M = 0"者，一律须先有 Dec\_CH(X) = 1；否则只能推出"CounterHoldRole^M ∈ {0, ⊥}"。

### 3.4　比较规约下的记账对应

对比较规约 Γ 定义纯记账对应 τ\_Γ，用以跟踪左端证书的各个组件在右端是否仍有合法对应。τ\_Γ 只是辅助记账，不新增本体，也不预设任何结构保持。

它只在定理 4.5 的叙述中出现，用以分辨"旧证书退出"与"证书集灭绝"两件事；本式的各项主结论都不以 τ\_Γ 为前提，删去它不影响任何定理的成立。

## 第四节　结构刻画

### 4.1　形式证书集与形式反持资格

定理 4.1　形式证书刻画定理

　　𝒲^M\_CH(X) ≠ ∅ ⇔ CounterHoldRole^M\_X(P; A, J) = 1。

证明。由《理数理式》，CounterHoldRole^M = 1 当且仅当存在固定职责 d，使对每个 j ∈ J 存在合法 R\_j 与其对应的 ℱ\_{B,j}，令 RelPass\_d(j) = 1。把这一存在性见证的各分量按 3.1 逐项登记，即得一份完整证书，故左端非空。反之，一份完整证书按定义即给出这样的 d 与各 j 的 R\_j、ℱ\_{B,j} 与 RelPass 证书，故 CounterHoldRole^M = 1。证毕。

本定理所签的是正值状态的等价，不签其否定状态的补等价：由它不得简单取否而得 𝒲^M\_CH = ∅ ⇔ CounterHoldRole^M = 0。原因是《理数理式》允许 RelPass 与整体 CounterHoldRole^M 取 ⊥，而证书集为空只说明没有已经取得的正证书，它同时兼容 CounterHoldRole^M = 0 与 CounterHoldRole^M = ⊥。故须另加可判前件，见 3.3 与定理 4.2′。

本定理在形式层为 Established。由它回读本体的 CounterHoldRole 时，须保留《理数理式》M1—M8 与其调用的律侧表示前件；形式层不得无条件抬为本体层。

### 4.2　覆盖集合的交集表示

定理 4.2　交集表示定理

　　CounterHoldRole^M\_X(P; A, J) = 1 ⇔ ⋂\_{j ∈ J} 𝒟\_X(j) ≠ ∅。

证明。这是既有定义 ∃d ∀j RelPass\_d(j) = 1 的集合改写：d 属于每个 𝒟\_X(j) 当且仅当它在每个 j 上都有合法的 R\_j 与 ℱ\_{B,j} 使 RelPass 成立。证毕。

与定理 4.1 同理，本定理所签的也是正值状态的等价：由它不得取否而得"交集为空 ⇔ CounterHoldRole^M = 0"。按 3.2，𝒟\_X(j) 只收录 RelPass 确定为 1 的职责，故交集为空同样兼容 CounterHoldRole^M = 0 与 ⊥。

定理 4.2′　可判域中的灭绝等价

若 Dec\_CH(X) = 1，则

　　𝒲^M\_CH(X) = ∅ ⇔ ⋂\_{j ∈ J} 𝒟\_X(j) = ∅ ⇔ CounterHoldRole^M\_X = 0。

证明。Dec\_CH = 1 时每个 RelPass\_d(j) 都取 0 或 1，故 CounterHoldRole^M 亦只取 0 或 1。此时由定理 4.1 与 4.2，非空与取 1 等价，故为空与取 0 等价。证毕。

若 Dec\_CH(X) ≠ 1，则由 𝒲^M\_CH(X) = ∅ 只能得 CounterHoldRole^M\_X ∈ {0, ⊥}，不得写成 = 0。

须强调量词顺序：∀j ∃d\_j 不能替代 ∃d ∀j。前者允许不同上下文各用不同职责，后者要求同一职责覆盖全域。

### 4.3　关系资格灭绝的两个且仅两个形式类型

定理 4.3　二分定理

在 Dec\_CH(X) = 1，即所有 𝒟\_X(j) 均可判时，

　　⋂\_{j ∈ J} 𝒟\_X(j) = ∅

当且仅当下列之一成立：

　　局部灭绝：∃ j ∈ J，𝒟\_X(j) = ∅；  
　　全域一致性断裂：∀ j ∈ J，𝒟\_X(j) ≠ ∅，且 ⋂\_{j ∈ J} 𝒟\_X(j) = ∅。

两者互斥且穷尽。

证明。设交集为空。若某个 𝒟\_X(j) 为空，即第一类。若所有 𝒟\_X(j) 均非空而交集仍空，即第二类。二者按"是否存在空的局部集合"划分，互斥；又已穷尽交集为空的全部情形。反之，第一类显然使交集为空；第二类由其定义直接给出交集为空。证毕。

第一类表示：至少有一个关系上下文上，没有任何职责的 RelPass 取 1。第二类表示：每个上下文上都有职责的 RelPass 取 1，但不存在同一个职责在所有上下文上都取 1——即局部处处有反持，整体仍无覆盖。两类的表述均在 Dec\_CH = 1 之下，故"没有取 1"与"取 0"同义，不含未决。

### 4.4　全域一致性断裂的最小形式模式

取 J = { j₁, j₂ } 与两项职责 d₁、d₂，并在本模式中冻结

　　Duties(Rel(P)) = { d₁, d₂ }。

这一冻结不可省。若 Rel(P) 中另有职责 d₃ 而它在 j₁ 与 j₂ 上都通过，则交集并不为空，模式失效。故若职责集合不止两项，须预先申报其余每一项在至少一个 j 上明确为 0，使它们不进入交集见证；否则下列各集合只是候选职责的局部切片，不是完整的 𝒟(j)。

左端 X⁻：在 j₁ 上 d₁ 通过、d₂ 不通过；在 j₂ 上 d₁ 通过、d₂ 通过。在上述冻结下，𝒟(j) 即由这两项职责的真值完整给出：

　　𝒟⁻(j₁) = { d₁ }，𝒟⁻(j₂) = { d₁, d₂ }，交集为 { d₁ }，

故 CounterHoldRole^M = 1。

右端 X⁺：在 j₁ 上 d₁ 通过、d₂ 不通过；在 j₂ 上 d₁ 不通过、d₂ 通过。于是

　　𝒟⁺(j₁) = { d₁ }，𝒟⁺(j₂) = { d₂ }，各局部集合均非空，交集为空，

故 CounterHoldRole^M = 0。

表中每一个"通过"都须解释为完整的 RelPass 成立，即存在合法 R\_j 与其对应的 Bind 家族并满足全部 Type-sensitive 的 Sat，不是裸布尔标签。

在上述冻结下，两端的每一格真值都已给定，故

　　Dec\_CH(X⁻) = Dec\_CH(X⁺) = 1。

于是由定理 4.2′ 直接得

　　CounterHoldRole^M(X⁻) = 1，CounterHoldRole^M(X⁺) = 0，

本模式与定理 4.2′、4.3 由此完全闭合，读者不需自行补前件。

强度申明：以上是量词结构的可满足模式，不是已构造的运行实例。它证明的是：在 ∀j ∃d\_j 仍为真时，∃d ∀j 仍可以失败——这由《理数理式》原有要求（固定职责须覆盖整个 J、禁止职责漂移）直接边界化而来。本式不签"该四格真值在某个具体沉积场中可同时实现"这一实例可达性；要签它，须另行构造满足联合评价、AHold、Anti、Bind 与 Law(P) 全部条件的合法实例，那是构造式或可达式的任务。按《法篇》，后级实例化未做不自动否定形式结论。

### 4.5　单证书退出不足

定理 4.4　单证书退出不足定理

设 C ∈ 𝒲^M\_CH(X⁻) 而 C ∉ 𝒲^M\_CH(X⁺)。若右端仍有某个 C′ ∈ 𝒲^M\_CH(X⁺)，则 CounterHoldRole^M(X⁺) = 1。

证明。由定理 4.1，右端证书集非空即给出 CounterHoldRole^M(X⁺) = 1。证毕。

故下列各项本身都不足以推出 Principle 的边界，不得自动升级：某一个 R\_j 退出；某一个 Bind 家族失效；某一个 Anti 自由度消失；某一份完整的旧证书退出。只有当其退出造成证书集灭绝，或与其它退出共同导致 CounterHoldRole 失效时，才升级为边界责任。

同理，旧职责 d₁ 失效也不自动等于 Principle 的边界。职责 d 不是 Principle(P; A, J) 的跨时外部身份；只要右端存在另一职责 d₂，且 d₂ 自己完整覆盖整个固定的 J，同一个 Principle 资格可以继续成立。

不要把"资格判定时 d 必须在整个 J 上固定"误写成"不同时间永远必须是同一个 d"。

### 4.6　证书灭绝分解

定理 4.5　证书灭绝分解定理

　　𝒲^{M,+}\_CH = ∅ 当且仅当：左端的全部旧证书在右端均已退出，且右端没有任何新的完整证书补位。

本定理只刻画证书集为空这一形式事实；由它进一步读出 CounterHoldRole^M = 0，须另有 Dec\_CH(X⁺) = 1（定理 4.2′）。

证明。右端证书集为空，则其中既无旧证书的合法对应，也无新证书，故两个条件都成立。反之，若旧证书全退而又无新证书补位，则右端不存在任何完整证书，集合为空。证毕。

旧证书全部退出只说明原见证退出；只有"旧证书全退且无替代证书"才得到证书集灭绝。τ\_Γ 在此只承担记账，不承担任何结构保持的假定。

### 4.7　固定证书边界与证书灭绝边界

沿同一条预先申报的单向 Γ 比较路径，且边界值实际取得。本节只比较形式证书集本身的两个边界，不涉 CounterHoldRole^M 的取值，故不需 Dec\_CH 前件；若要由 q^∂\_𝒲 处进一步读出 CounterHoldRole^M = 0，则须在该处另有 Dec\_CH = 1。设

　　q^∂\_fix(C)：固定的完整形式证书 C 第一次失格的已取得边界；  
　　q^∂\_𝒲：整个 𝒲^M\_CH 第一次变空的已取得边界。

定理 4.6　边界顺序定理

　　q^∂\_fix(C) ≤ q^∂\_𝒲。

若在固定证书失效之后、证书集最终灭绝之前，存在一个严格后继的比较态由替代证书继续承担，则

　　q^∂\_fix(C) \< q^∂\_𝒲。

证明。证书集在 C 仍然合格时必然非空，故其变空的边界不早于 C 失格的边界，得不等式。若在二者之间存在一个严格后继的比较态，其上仍有替代证书承担，则该态处证书集非空而 C 已失格，故严格不等式成立。证毕。

不能仅因同一边界点上存在瞬时的替代就签严格小于。未证明实际取得的上下确界只能报告数值界，不得据以读取边界点上的 Principle 真值、失败责任，或哪一项资格先行断裂。

### 4.8　端点非对称

定理 4.7　端点非对称定理

认证一次具体的 Principle 资格边界，不要求先在整个 Γ 域上证明 Principle ⇔ Law(P) ∧ CounterHoldRole。

出界方向，左端为 1、右端为 0 时：左端的正资格可直接证明 Law(A) = 1、Law(P) = 1、CounterHoldRole = 1，再由《理必然式》的 Established 充分向得 Principle(X⁻) = 1；右端的负资格证明 Law(A) = 1，且 Law(P) = 0 或 CounterHoldRole = 0，再由《理一般式》必要向的逆否得 Principle(X⁺) = 0。负端须保留《理一般式》的 Conditional 前件。

入界方向，左端为 0、右端为 1 时，两端的义务对调：左端证明 Law(A) = 1，且 Law(P) = 0 或 CounterHoldRole = 0，由必要向的逆否得 Principle(X⁻) = 0，保留《理一般式》的 Conditional 前件；右端证明 Law(A) = 1、Law(P) = 1、CounterHoldRole = 1，由充分向得 Principle(X⁺) = 1。故入界的负端义务在左、正端义务在右。

故三项状态分列：结构正端充分为 Established；结构负端必要逆否为 Conditional；形式层若经 CounterHoldRole^M 回读为 Conditional。不得把这些状态抹平。

### 4.9　形式层三值纪律

形式层允许 1、0、⊥ 三值。若某个必要的形式输入不可判而没有确定的失败，传播 ⊥。若已有定义能够独立明确地得到 0，则即使其它形式输入不可判，也按上游三值规则处理这一确定性失败，不得无条件升级为 ⊥。

最要紧的两条：CounterHoldRole^M = ⊥ 绝不能读成 CounterHoldRole = 0；形式输入不足也绝不能读成"现实中没有理"。

## 第五节　主结论

### 5.1　边界内的性质

按点态表达。对任一合法比较态 X，只要 Law(A) = 1、Law(P) = 1、CounterHoldRole = 1，则由《理必然式》的充分向得 Principle(X) = 1，与该态当前是否正在行无关。

某一份证书在 X 退出而 X 上仍存在另一份完整证书，只说明该比较态尚未越过资格边界；它不签任何关于整段路径的保持结论。保持时长、替代的可得性与复归，一律归《理稳定式》。

### 5.2　边界的位置

定理 5.1　Principle 资格边界顶层穷尽定理

在固定的工作域与冻结的 M1—M12 语义域中，A 仍为律时：

　　出界（Boundary⁻）只能由下列之一承担：B\_P⁻，即 P 的 Law 资格退出；或 B\_CH⁻，即 CounterHoldRole 退出。不存在第三个独立取消项。  
　　入界（Boundary⁺）须先有候选入界前件：两端 Dom\_Principle 成立、相邻，且左端 Principle = 0 已经认证。在此前件下，Boundary⁺ 当且仅当右端 Law(P) = 1 与 CounterHoldRole = 1 同时成立，即左端所缺的那一项或两项在右端同时补齐。缺此前件时，右端两项齐备只说明右端 Principle = 1，可能只是 1 到 1，不构成入界。

证明见 2.1。本定理是当前冻结母本域内的穷尽结论，不是跨一切未来理论的绝对穷尽。

定理 5.2　形式反持证书灭绝定理

在 Dec\_CH(X) = 1 时，CounterHoldRole^M = 0 由"同一职责覆盖整个 J"的完整证书集为空刻画（定理 4.2′）；证书集为空进一步分为局部灭绝与全域一致性断裂两类，二者互斥且穷尽（定理 4.3）。Dec\_CH(X) ≠ 1 时，证书集为空只给出 CounterHoldRole^M ∈ {0, ⊥}，不进入本定理。

定理 5.3　边界端点非对称定理

见定理 4.7。

附加定理：单证书退出不足（定理 4.4）；固定证书边界不晚于证书灭绝边界（定理 4.6）；全域一致性断裂的最小形式模式（4.4 节所给）；目标侧退出边界（5.4）。

### 5.3　越界的退化结果

越出界以后，在 A 仍为律的前提下，Principle 在工作域内为 0。两项责任允许同时发生，故分三种读法：

　　B\_P⁻ 发生而 B\_CH⁻ 不发生：右端 P 已不再具有 Law 资格，原来的反持关系失去其律侧承担者；此时反持资格是否仍有形式意义，按相应工作域另行处理。  
　　B\_P⁻ 不发生而 B\_CH⁻ 发生：P 仍为律，但已不再具有对 A 的反持资格——没有任何以同一职责覆盖整个 J 的合法见证。此时 P 与 A 仍可同场共存、仍可互有作用，只是那些作用不再构成理。  
　　两项同时发生：不得强行指定唯一责任。这与第六节"不宣称承担边界的具体部件唯一"一致。

退化不可逆向读取：Principle 在右端为 0，不改变它在左端曾经成立这一事实。

入界方向的对应结果是：越入界以后，在 A 仍为律的前提下，Principle 在工作域内为 1；这同样不追溯改变它在左端曾经不成立这一事实。

### 5.4　目标侧退出

若 Law(A) 由 1 变 0，记为 OUT\_A。它不能倒改 A 失律以前已经成立的 Principle。

不要把"P 成功打掉了 A"写成 P 从来就不是理；恰恰可能是理的实际后果最终消灭了自己的目标关系对象。

### 5.5　边界责任树

在 A 仍在工作域内时，本体层的 Principle 出界最终只允许两大顶级责任：一为 P 失律；二为 CounterHoldRole 失效。入界的责任树是它的对偶：左端所缺的一项或两项在右端补齐。

在形式可表示域中且 Dec\_CH = 1 时，第二项的形式对应 B\_CH^{M,−} 进一步诊断为局部灭绝或全域一致性断裂；由该形式诊断回到本体责任，须另行声明《理数理式》的表示前件。Dec\_CH ≠ 1 时只能记为未决，不得挂责任。再向下才可诊断导致 RelPass 或证书失效的具体部件，例如：交出型或结果型的职责所限；RoleNonDegenerate；AHold；Anti；Ω 与 Bind；R\_j 无合法形式解；JointProj；Sat；联合评价域失败。

下层某一项失效不得直接跳级宣布 Principle 的边界，必须先确认替代证书是否仍然存在。

## 第六节　唯一性

本式在下列两处宣称唯一，并各自给出证明。

其一，顶层退出结构的唯一性：在 2.1 所述前件下，使 Principle 出界的顶层结构只有 B\_P 与 B\_CH 两类，无第三类。证明见 2.1，其依据是《理必然式》的资格穷尽、独立取消项为空与主充分定理三者合取。

其二，形式灭绝类型的唯一二分：在 Dec\_CH(X) = 1 时，证书集为空的类型只有局部灭绝与全域一致性断裂两类，互斥且穷尽。证明见定理 4.3。Dec\_CH ≠ 1 时不作二分，交集与证书集的状态本身即未决。

除这两处以外，本式不宣称任何唯一性。特别地，不宣称边界位置唯一——沿不同的比较路径可以到达不同的边界点；也不宣称承担边界的具体部件唯一。

## 第七节　最简表达

边界的定义与边界的原因是两件事，不得写成同一个双条件。

其一，边界定义。仍以第一节的真值跨越为准：

　　Boundary⁻\_Γ ⇔ Adjacent\_Γ ∧ Dom\_Principle(X⁻) ∧ Dom\_Principle(X⁺) ∧ Principle(X⁻) = 1 ∧ Principle(X⁺) = 0；  
　　Boundary⁺\_Γ ⇔ Adjacent\_Γ ∧ Dom\_Principle(X⁻) ∧ Dom\_Principle(X⁺) ∧ Principle(X⁻) = 0 ∧ Principle(X⁺) = 1。

其二，结构责任压缩。它只是单向蕴含，不可反向读：

　　Boundary⁻\_Γ ⇒ B\_P⁻ ∨ B\_CH⁻，在《理一般式》必要向的 Conditional 前件下成立；  
　　Boundary⁺\_Γ ⇒ Law(P)(X⁺) = 1 ∧ CounterHoldRole(X⁺) = 1。

反向不成立。取左端 Law(P) = 1 而 CounterHoldRole = 0，则左端 Principle 本已为 0；右端 Law(P) 由 1 落到 0，B\_P⁻ 发生且两态相邻，但这是 Principle 由 0 到 0，并非 Boundary⁻。入界一侧同理：左端两项本已同时成立时，右端条件全满足而 Principle 由 1 到 1，亦非 Boundary⁺。

入界的反向只在下列条件下可用：左端 Principle = 0 已经合法认证、两端 Dom\_Principle 成立且相邻，此时由右端两项同时成立经《理必然式》的充分向得 Principle(X⁺) = 1，于是 Boundary⁺ 成立。

其三，形式层的边界标签。为免层级混写，先定义

　　B\_CH^{M,−}：CounterHoldRole^M 由 1 变 0；  
　　B\_CH^{M,+}：CounterHoldRole^M 由 0 变 1。

它们是形式层标签，不是本体层的 B\_CH^±。在相邻两端 Dec\_CH 均为 1 时：

　　B\_CH^{M,−} ⇔ ⋂\_{j ∈ J} 𝒟(j) 由非空变为空 ⇔ LocalExtinction ∨ GlobalConsistencyBreak；  
　　B\_CH^{M,+} ⇔ 该交集由空变为非空。

此二式在该前件下为 Established。

其四，跨层回读。只有在《理数理式》M1—M8 及其全部承继表示前件于相邻两端均成立时，B\_CH^{M,±} 才可回读为本体层的 B\_CH^±；该回读的 Status = Conditional。不得把上面两个形式等价直接写成本体层 B\_CH^± 的等价式。

若 Law(A) 由 1 变 0，则不属上列各式，记为 OUT\_A。

以上只是前述各定理的压缩记法，其中每一项的成立条件与状态见强度总表。

## 第八节　解读

本节为解读，不属于形式结构，不承担证明义务。

理的边界不在某一次反持消失的地方。一条律对另一条律的反持资格，是一份可以由许多不同见证轮流承担的资格：这次由这个承载解承担，下次由另一个；这次经这条 Anti 自由度，下次经另一条；甚至这一段由这项职责承担，另一段由另一项职责承担——只要还有同一项职责能把整个预先申报的关系域覆盖下来。资格的消失，是这类承担方式全部用尽。

这段话说的是失去。取得的一侧是它的对偶：要让理重新成立，不是补上某一份见证就够，而是候选理自身重新成为律，并且重新有一项职责能把整个关系域覆盖下来——两件事都要齐。

因此有两种很不一样的"没有了"。一种是某一条具体的路断了，而别的路还在；这时候理还在。另一种是每一段路单独看都还通，却再也找不到一条能够从头走到尾的同一条路；这时候理已经不在了。后一种就是全域一致性断裂——它是本式最值得注意的形态，因为局部看上去处处正常。还要加一句：说"再也找不到"，前提是每一段都已经查清；若有某一段还没查清，那就既不能说找得到，也不能说找不到。

还有一种"没有了"根本不属于这里：目标律自己退出了。那时不是理失去了资格，而是它所针对的那份持势已经不复存在。理甚至可能正是促成这一退出的原因之一。

最后一句可以这样压缩：理的边界，不是某一个反持实现消失的地方，而是在目标仍为律的前提下，候选理自身失去律资格，或最后一份能够以同一职责覆盖整个关系域的反持资格彻底消失的地方；若目标律本身退出，则进入另一类目标定义域边界。

## 第九节　最终结论

在冻结的比较规约 Γ 与冻结的 M1—M12 语义域内：

　　A 仍为律时，Principle 的出界由 B\_P⁻ 与 B\_CH⁻ 两类且仅两类承担；入界则要求右端两项同时成立；  
　　在形式可判域中，即 Dec\_CH = 1 时，B\_CH⁻ 由完整证书集为空刻画，并二分为局部灭绝与全域一致性断裂；证书集为空而 Dec\_CH ≠ 1 者，只能得 CounterHoldRole^M ∈ {0, ⊥}；  
　　单一见证、单一承载解、单一 Bind 家族、单一 Anti 自由度、单一职责或单一完整证书的退出，本身不足以推出 Principle 边界；只有当其退出造成最后一份完整资格证书灭绝，或与其它退出共同导致 CounterHoldRole 失效时，才升级为边界责任；  
　　固定证书的失格边界不晚于证书集的灭绝边界；  
　　行的失效不属于资格边界；  
　　A 失律记为 OUT\_A，属另一类边界，且不倒改此前成立的 Principle。

## 第十二节　击穿方式与拦截项

### 12.1　直接击穿条件

按极限式规范，击穿即展示一个极限条件成立而所断言性质不出现的情形。下列各项针对主结论，可实际构造。

　　K-B1　构造合法情形，其中 A 仍成律、P 仍成律、CounterHoldRole 仍成立，而 Principle = 0。若成立，则直接击穿顶层穷尽（定理 5.1 出界部分），并同时击穿《理必然式》主充分定理的 K-PB1。  
　　K-B2　构造合法情形，其中 A 仍为律而 Principle 由 1 变 0，且右端 Law(P) = 1 与 CounterHoldRole = 1 仍同时成立。击穿责任压缩 Boundary⁻ ⇒ B\_P⁻ ∨ B\_CH⁻。  
　　K-B3　构造合法情形，其中两端相邻、Dom 均成立、左端 Principle = 0 已认证，右端 Law(P) = 1 且 CounterHoldRole = 1，而 Principle(X⁺) 仍为 0。击穿入界的充分向认证。  
　　K-B4　在 Dec\_CH = 1 的状态上构造：证书集为空而 CounterHoldRole^M ≠ 0，或证书集非空而 CounterHoldRole^M ≠ 1。击穿定理 4.1 或 4.2′。  
　　K-B5　在 Dec\_CH = 1 的状态上构造：交集为空而既非局部灭绝亦非全域一致性断裂，或两类同时成立。击穿二分定理 4.3。  
　　K-B6　构造合法比较路径，其中固定证书的失格边界严格晚于证书集的灭绝边界，且两处边界均实际取得。击穿边界顺序定理 4.6。

定理 4.4 的内容是"右端存在完整证书则 CounterHoldRole^M(X⁺) = 1"，其击穿已由 K-B4 覆盖，不另列。须注意：右端存在替代证书而 Principle 仍然出界，是完全合法的情形——例如同一跨越中 Law(P) 由 1 落到 0；这不击穿 4.4，因为 4.4 从未证明"有替代证书则 Principle 不会出界"。

### 12.2　禁止读法与审稿拦截项

下列各项不是对主结论的反例，而是违规写法或越界使用。审稿时据以拦截；出现即判该处不合规，不构成理论击穿。

　　R-B1　换 P、换 A、缩小 J 或改写身份内容以后，仍冒充同一个 Principle 边界。  
　　R-B2　把 ∀j ∃d\_j 偷换成 ∃d ∀j。  
　　R-B3　把 A 失律直接写成普通的 Principle = 0，混淆 OUT\_A。  
　　R-B4　在表示与回读前件不足时，把 CounterHoldRole^M = 0 直接抬为本体的 Principle = 0。  
　　R-B5　把 ⊥ 冒充为 0；或在 Dec\_CH ≠ 1 时由证书集为空写出 CounterHoldRole^M = 0。  
　　R-B6　把行的停止冒充为 Principle 的边界。  
　　R-B7　把某一个 Anti、承载解、Bind 家族或职责的单点失效，直接冒充主边界。  
　　R-B8　只有上下确界而无实际取得，却读取边界点上的真值或责任。  
　　R-B9　进入保持、恢复、迟滞等稳定任务。  
　　R-B10　把 4.4 的最小形式模式读作已构造的运行实例。  
　　R-B11　把出界公式直接当作双向边界的等价式使用。  
　　R-B12　把形式边界标签 B\_CH^{M,±} 直接当作本体层 B\_CH^± 使用，未声明《理数理式》的表示前件。  
　　R-B13　把责任压缩的单向蕴含反向读，即由 B\_P⁻ 或 B\_CH⁻ 发生直接断定该相邻对为 Boundary⁻，而未先认证左端 Principle = 1。

## 第十三节　接口
