# 理稳定式

## 第一节　目的、式种与唯一不可约任务

### 1.1　式种定位

本式为稳定式，属附式。它在主式已经给出结构、边界式已经辨明即时资格边界之后，回答一份已经成立的理关系在许可变化与合法后继轨迹中如何保持、失效与复归。

### 1.2　唯一不可约任务

固定同一个目标律 A、同一个候选理身份 P₀、同一个预先申报的关系域 J，以及同一个稳定协议之后，只回答一个问题：Principle 已经成立以后，在许可的状态变化与合法后继轨迹中，它以什么身份、在什么量词层级上保持下来？

这一问题分六项：

　　同一份反持证书能否继续承担；  
　　原职责退出以后，能否由同一职责的新证书替代；  
　　原职责退出以后，同一个 P₀ 是否仍可由其它职责保持 Principle；  
　　P₀ 退出以后，针对同一个 A 是否仍有其它候选理接替；  
　　已经失效的各层资格能否在规定期限内复归；  
　　上述主张在单轨迹、声明轨迹族、全部合法未来三个量词层级上分别达到什么强度。

不重新证明什么是理，不重新证明 Principle、CounterHoldRole 与 Act，不研究理如何生成新律，不研究意向性，不研究理的强弱分级。

### 1.3　依附

依附已封版的《理一般式》v1.0、《理数理式》v1.0、《理必然式》v1.0 与《理边界式》v1.0；承继《律稳定式》已经成熟的稳定纪律——固定对象与存在层分立、恢复后置于首次实际失效、边界须实际取得、单轨迹与轨迹族与全部合法轨迹的量词不得偷换。不修改上游任何定义，不新增本体谓词，不新增 H。

主式被击穿或撤销，本式结论随之失效或转为待定。

## 第二节　稳定实例与冻结身份

### 2.1　稳定实例

一次稳定考察以一个冻结的稳定实例为对象：

　　Σ\_P = ( F\_t, A, I\_A, P₀, I\_{P₀}, J, C₀, d₀, Π, Δ, τ, H )。

其中 F\_t 为初始沉积场；A 为固定目标律身份，I\_A 为其 Law 适用域；P₀ 为原始候选理身份，I\_{P₀} 为其 Law 适用域；J 为 P₀ 相对于 A 的预先申报关系域；C₀ 为初始的完整形式反持证书；d₀ 为 C₀ 所使用的固定职责；Π 为预先冻结的候选理身份族，且 P₀ ∈ Π——其含义见 2.2；Δ 为许可状态摄动类；τ 为证书组件的跨态身份对应规则，见 2.3；H = (T\_obs, T\_rec, h) 为动态稳定协议。

### 2.2　冻结纪律

A、P₀、J、Rel 中用于判定同一身份与同一职责的内容，以及候选族 Π，都不得在失稳以后事后修改。改变其中任何一项之后重新成立者，不属于原稳定实例的恢复，而是另一个稳定实例。

Π 不是一个裸的名称集合。对每一个成员，其 Law 身份、预先申报的 Law 适用域，以及用于识别同一候选的 Rel 身份内容，都随 Π 一次冻结。形式上可写

　　Π = { ( P\_α, I\_{P\_α}, IdRel(P\_α) ) }\_α，

正文中仍简称其成员为 P。

由此，对 Π 中任一候选修改其 Law 适用域或用于身份识别的 Rel 内容，即视为更换候选，不得计为原 Π 内的接替，也不得计为理的不断档。这与对 P₀ 的冻结纪律一致：若只冻结名称而不冻结判定身份，"同一个候选接替"就没有跨时的对象可指。

Π 尤须事前冻结：事后把新出现的候选理补进 Π，再宣称"理从未断档"，是把结论塞进前提。

### 2.3　证书的跨态身份

C₀ 内含各 j 的承载解 R\_j、Bind 家族成员、Anti 见证等组件。场状态一变，这些对象可能迁移、改写或失去对应，故"还是不是同一份 C₀"须有规则，否则固定证书层既可被读成字面对象分毫不变，也可被读成随便找一份同型证书。

为此在 Σ\_P 中一并冻结一个跨态身份对应规则 τ：它把 C₀ 的每一个组件映到摄动态或后继态上的对应对象，只作身份记账，不预设任何结构保持。τ 与《理边界式》的 τ\_Γ 同类，是纯形式辅助对象，不新增本体。

τ 须与 Δ 一同事前申报，不得在失稳以后改写其对应方式。τ 若对某一组件不给出对应，则该组件在该态上视为无对应。

## 第三节　许可摄动、目标工作域与判定域

### 3.1　许可摄动

摄动是一个映射

　　η: F\_t ↦ F\_t^η。

许可摄动类记为 Δ^adm。允许变化的是场状态，以及由场状态合法导出的实际承担实现：各 j 的承载解 R\_j；Bind 家族中的实际成员；Anti 自由度；沉积、阻抗、可用性与竞争结构；P 的 Law 承载实现；某一职责当前是否还能覆盖整个 J。

不得借摄动改动下列各项：A 的身份；P₀ 的身份；J；I\_A 与 I\_{P₀}；Rel(P₀) 中用于判定同一职责的内容；候选族 Π。改动它们即离开原稳定实例。

合法而不可判的摄动不得从摄动类中删去，也不得直接判为 0；它按三值制度进入 ⊥。

### 3.2　目标工作域先行判定

理的稳定与律的稳定有一处根本不同：目标 A 自身可能退出 Law。故对任一轨迹 γ，先判 Law\_s(A, I\_A)。定义

　　DomA\_γ(H) = 1 ⇔ 对一切 s ∈ J\_obs，Law\_s(A, I\_A) = 1。

若存在实际时刻 s\_o 使 Law\_{s\_o}(A, I\_A) = 0，则该轨迹标记为 OUT\_A。若没有已知的 0 而存在不可判，则为 ⊥。

三者互不相同：

　　OUT\_A ≠ 0，OUT\_A ≠ ⊥。

OUT\_A 表示目标关系对象退出了 Principle 的稳定工作域，不是 Principle 的普通失稳。

轨迹层可以使用 OUT\_A 标签。轨迹族与保证层不另设四值稳定量，而是另立目标域保证这一条独立的轴，见第十节。

### 3.3　判定域

各稳定任务所需的判定域分别申报：本体层需要 Law 与 Principle 的可判性；形式层需要《理数理式》的表示条件与其调用的律侧前件；跨层回读另需该式 M1—M8。判定域不足处一律记 ⊥，不得填 0。

## 第四节　四层即时稳定资格

理的稳定必须先说明保持的是哪一个身份。下列四层自低而高，各自定义即时资格。

### 4.1　固定证书层

以 τ(C₀) 记 C₀ 各组件在 X 上的对应物。定义三值资格：

　　Q\_C(X) = 1，当 τ(C₀) 在 X 上仍构成一份完整合法证书，即其各组件均有合法对应且逐项满足《理边界式》3.1 所冻结的完整证书要求；  
　　Q\_C(X) = 0，当存在决定性失败：某一必要组件在 X 上无对应，或其对应物确定不满足相应要求；  
　　Q\_C(X) = ⊥，当没有决定性失败，而至少一项必要的证书分量未决。

保持的是同一份完整形式反持证书，"同一份"依 τ 判定。

### 4.2　固定职责层

定义三值资格：

　　Q\_d(X) = 1，当对一切 j ∈ J 有 RelPass\_{d₀}(j) = 1，即 d₀ ∈ ⋂\_{j ∈ J} 𝒟\_X(j)；  
　　Q\_d(X) = 0，当存在 j ∈ J 使 RelPass\_{d₀}(j) = 0；  
　　Q\_d(X) = ⊥，当无 0 而至少一项 RelPass\_{d₀}(j) 为 ⊥。

允许 R\_j、Bind 家族成员、Anti 自由度等逐一替换，但职责必须仍是同一个 d₀。

须注意 d₀ ∉ ⋂\_j 𝒟\_X(j) 不等于 Q\_d(X) = 0：按《理边界式》3.2，𝒟 只收录 RelPass 确定为 1 者，故"不属于"兼容 0 与 ⊥ 两种情形。

### 4.3　固定理身份层

以下两层为本体层，其三值按本体判定域给出：判定域不足者为 ⊥。

　　Q\_P(X) = 1 ⇔ Principle\_X(P₀; A, J) = 1；  
　　Q\_P(X) = 0 ⇔ Principle\_X(P₀; A, J) = 0；  
　　Q\_P(X) = ⊥，当该态上 Principle 的判定域不足。

保持的是同一个候选理的理资格，职责可以更换。

### 4.4　候选族存在层

　　Q\_Π(X) = 1 ⇔ 存在 P ∈ Π 使 Principle\_X(P; A, J) = 1。

保持的只是"针对同一个 A 始终有某个理存在"。其三值制度为：至少一项确定为 1 则 Q\_Π = 1；全部冻结候选都确定为 0 则 Q\_Π = 0；没有 1 而仍有 ⊥ 则 Q\_Π = ⊥。

不得把"目前没有找到某个 P"写成 0。

### 4.5　形式反持层

另记形式层资格

　　Q\_{CH^M}(X) := CounterHoldRole^M\_X(P₀; A, J)，

其三值直接承继《理数理式》：取 1、0 或 ⊥。它属形式层，不是本体资格。

四层与本层的三值制度由此闭合：第六节的失效时集只收 Q\_ℓ(s) 确定为 0 者，⊥ 既不入 Fail，也不充当保持。

## 第五节　五态替代结构

### 5.1　判定次序

五态不得由证书层向上推。必须先判本体的 Principle，再以形式层细分其承担方式。

五态在下列子域内定义：A 仍在工作域内；Π 已冻结；所需的本体与形式判断全部可决，即 Principle(P₀)、各候选的 Principle、Q\_C 与 Q\_d 均取 1 或 0；表示前件足以支持相关的形式诊断。

子域之外不勉强归态：某一资格未决者记 ⊥，目标退出者记 OUT\_A，二者都不占五态中的任何一格。

### 5.2　五态

　　S1　原证书态：Principle(P₀) = 1 且 Q\_C = 1。  
　　S2　同职责替代态：Principle(P₀) = 1，Q\_C = 0，而 Q\_d = 1。  
　　S3　同理异职责态：Principle(P₀) = 1，而 Q\_d = 0。形式诊断可以进一步说明存在其它职责承担，但不得无条件由形式量推出 Principle。  
　　S4　异理接替态：Principle(P₀) = 0，而存在 P₁ ∈ Π \\ { P₀ } 使 Principle(P₁) = 1。  
　　S5　理空缺态：对一切 P ∈ Π，Principle(P) = 0。

五态一律以第四节所定义的三值资格 Q\_C、Q\_d 表述，不用"C₀ ∈ 𝒲^M\_CH"这类字面写法：摄动之后的对应物由 τ 给出，未必是字面意义上的原对象。

### 5.3　互斥穷尽

在上述共同可决子域中，S1 至 S5 互斥且穷尽。

证明。先按 Principle(P₀) 的取值二分。取 1 的一支：先按 Q\_C 的取值二分，Q\_C = 1 即 S1；Q\_C = 0 者再按 Q\_d 的取值二分，Q\_d = 1 即 S2，Q\_d = 0 即 S3。这里用到即时链 Q\_C ⇒ Q\_d（第六节），故 S1 中必有 Q\_d = 1，与 S3 不重叠。取 0 的一支：按 Π 中是否另有候选成立二分为 S4 与 S5。在共同可决子域中各资格均取 1 或 0，无 ⊥，故各步划分互斥且穷尽。证毕。

OUT\_A 与 ⊥ 不属于五态。

### 5.4　证书残留不改判

即使 Q\_C = 1，即旧证书经 τ 仍有完整的合法对应，只要 Law(P₀) 已经退出而 Principle(P₀) = 0，该态即进入 S4 或 S5，不得因证书残留归入 S1。形式证书的存在不是本体资格的证明。

## 第六节　动态协议、保持、恢复与稳定

### 6.1　形式层即时链

上游已经给出：一份完整证书蕴含其所用职责覆盖整个 J，而后者蕴含形式反持资格成立。以第四节的三值资格表述，即时层有

　　Q\_C ⇒ Q\_d ⇒ Q\_{CH^M}，　Status = Established。

此处一律用 Q\_C，不用"C₀ ∈ 𝒲^M\_CH"作跨态前件：摄动后的对应物由 τ 给出。

反向一般不成立：原证书退出而同职责的另一证书补位；d₀ 退出而另一职责补位。

### 6.2　本体层与跨层桥

记本体结构辅助式

　　Q\_P^str(X) = Law\_X(P₀, I\_{P₀}) ∧ CounterHoldRole\_X(P₀; A, J)。

它只是既有两项条件的合取，不是新增本体谓词。由《理必然式》的充分向，

　　Q\_P^str = 1 ⇒ Principle(P₀; A, J) = 1，　Status = Established。

形式层不得直接写 CounterHoldRole^M ⇒ Principle。只有在《理数理式》M1—M8 及其全部承继表示前件成立时，才有 CounterHoldRole^M ⇒ CounterHoldRole，再与 Law(P₀) 合取进入 Principle。故形式层到本体层的稳定桥一律标 Conditional。

### 6.3　协议与三个量

冻结 H = (T\_obs, T\_rec, h)。对任一身份层 ℓ ∈ { C, d, CH^M, P, Π } 取其资格函数 Q\_ℓ(s)。失效时集为

　　Fail^ℓ\_γ(H) = { s ∈ J\_obs \| Q\_ℓ(s) = 0 }。

只收确定为 0 者：Q\_ℓ(s) = ⊥ 的时刻不入失效时集，也不因此算作成立。

若非空，记 b\_ℓ = inf Fail^ℓ\_γ(H)。下确界不是实际失效点，这一点须始终保留。

保持：

　　Keep^ℓ\_γ = 1 ⇔ 对一切 s ∈ J\_obs，Q\_ℓ(s) = 1。

恢复：Recover^ℓ\_γ = 1 须同时满足七项——失效时集非空；b\_ℓ \< t\_r；恢复期限自首次失效边界起算，不因后续失效而重置；存在实际失败点 s\_f 满足 b\_ℓ ≤ s\_f \< t\_r；Dur(b\_ℓ, t\_r) ≤ T\_rec；自 t\_r 起持续成立至观察窗结束；恢复之后至少具有验证长度 h。

稳定：

　　Stable^ℓ\_γ ⇔ Keep^ℓ\_γ ∨ Recover^ℓ\_γ。

三值如何落位须写明，不得含糊。若观察窗内存在时刻使 Q\_ℓ(s) = ⊥，则该时刻既不入失效时集，也不满足保持的逐时要求；此时 Keep 与 Recover 都不得判为 1，而稳定量记 ⊥——除非在该轨迹上已有确定的失效并已完成恢复的全部七项，且未决时段不影响这七项中的任何一项，此时仍可判 Recover = 1。

简言之：Stable^ℓ\_γ = 1 须由确定的 1 值支撑；Stable^ℓ\_γ = 0 须由确定的失效与恢复条件的确定不满足支撑；其余情形为 ⊥。判定域不足者亦为 ⊥。若 A 退出工作域，该轨迹报告 OUT\_A，而不是 Stable = 0。

## 第七节　动态稳定单调定理与两条稳定链

### 7.1　单调定理

定理 7.1　动态稳定单调定理

设在同一条轨迹、同一个 H、共同的动态可判域中，对一切 s 有 Q₁(s) = 1 ⇒ Q₂(s) = 1，则

　　Stable\_H(Q₁) ⇒ Stable\_H(Q₂)。

证明。分两种情形。

其一，Q₁ 属 Keep。则对一切 s 有 Q₁(s) = 1，由逐时蕴含得 Q₂(s) = 1，故 Q₂ 亦属 Keep，稳定成立。

其二，Q₁ 属 Recover。由逐时蕴含得 Fail(Q₂) ⊆ Fail(Q₁)。若 Fail(Q₂) 为空，则 Q₂ 属 Keep，稳定成立。若非空，则由包含关系得 b₂ ≥ b₁。取 Q₁ 的恢复时刻 t\_r：自 t\_r 起 Q₁ 恒为 1，故 Q₂ 自 t\_r 起亦恒为 1，于是 Q₂ 在 t\_r 之后无失效，其恢复时刻不晚于 t\_r。又 Fail(Q₂) 非空且含于 Fail(Q₁)，故存在实际失败点；由 b₂ ≥ b₁ 得 Dur(b₂, t\_r) ≤ Dur(b₁, t\_r) ≤ T\_rec；验证长度 h 由 t\_r 之后的恒为 1 保证。七项俱备，故 Q₂ 属 Recover。证毕。

Status = Established。前件须显式：同一轨迹、同一 H、共同动态可判域。三者缺一则定理不适用。

共同动态可判域在此指：观察窗内每一时刻 Q₁(s) 与 Q₂(s) 均取 1 或 0，无一为 ⊥。若某时刻二者之一未决，则逐时蕴含无从核验，Fail 的包含关系也不再成立，定理不适用。

### 7.2　两条稳定链

由定理 7.1 与 6.1 的即时链，得形式层稳定链

　　Stable\_C ⇒ Stable\_d ⇒ Stable\_{CH^M}，　Status = Established。

由 P₀ ∈ Π 得即时蕴含 Q\_P ⇒ Q\_Π：Q\_P = 1 时 P₀ 自身即为 Q\_Π 的存在见证。再由定理 7.1 得本体层稳定链

　　Stable\_P(P₀) ⇒ Stable\_Π，　Status = Established。

### 7.3　三个反向反例

三条反向一般都不成立，各给最小反例。

其一，证书替代。设整个观察窗内 d₀ 始终覆盖 J，而在某时刻 C₀ 退出、由同职责的另一份完整证书 C₁ 承担，且 C₀ 在恢复期限内未复归。则 Stable\_d = 1 而 Stable\_C = 0。

其二，职责替代。设整个观察窗内 CounterHoldRole^M 始终为 1，而在某时刻 d₀ 退出交集、由另一职责 d₁ 覆盖 J，且 d₀ 在恢复期限内未复归。则 Stable\_{CH^M} = 1 而 Stable\_d = 0。

其三，理身份替代。设 P₀ 在某时刻退出而 P₁ ∈ Π 即时接替并持续成立，且 P₀ 在恢复期限内未复归。则 Stable\_Π = 1 而 Stable\_P(P₀) = 0。

第三例尤须记明：这不是 P₀ 的恢复，也不是"同一个理保持"；所保持的只是理的存在没有断档。

## 第八节　跨形式—本体桥与异步恢复不可合取

### 8.1　跨层桥

不得写 Stable\_{CH^M} ⇒ Stable\_P。

条件化版本：若在整个观察区间内 Law\_s(P₀, I\_{P₀}) = 1，且《理数理式》M1—M8 及其全部承继表示前件逐时成立，则

　　Stable\_{CH^M} ⇒ Stable\_P(P₀)，　Status = Conditional。

若要使用形式与本体的双向等价，须另行完整承继《理一般式》的必要向与《理数理式》的反向表示条件，不得默认为无条件。

### 8.2　异步恢复不可合取

定理 8.1　异步恢复不可合取定理

一般地

　　Stable(Q₁) ∧ Stable(Q₂) ⇏ Stable(Q₁ ∧ Q₂)。

反例。取 T\_rec = 2。设 Law(P₀) 于 t = 1 失效、t = 2 恢复；CounterHoldRole 于 t = 9 失效、t = 10 恢复。二者各自满足恢复条件，故分别稳定。但合取式 Q\_P^str = Law(P₀) ∧ CounterHoldRole 首次失效在 t = 1，而两项共同成立要到 t = 10，故 Dur(1, 10) = 9 \> T\_rec = 2，恢复条件不满足。于是

　　Stable\_Law ∧ Stable\_CH ⇏ Stable\_{Q\_P^str}。

Status：以反例确立的否定结论，Established。

本定理到此为止，不再多走一步。由 Q\_P^str 失稳读出 Principle 失稳，须用《理一般式》必要向的逆否及其动态回读前件，而那一方向是 Conditional；故不在此签 Stable\_Law ∧ Stable\_CH ⇏ Stable\_P。

推论：不能凭 Law(P₀) 与 CounterHoldRole 各自稳定就认证 Principle 的稳定。若要由联合结构进一步读取 Principle 的稳定，仍须按上游的必要与充分接口及其各自 Status 处理。最稳妥的办法是直接判 Principle，或直接判其合法联合资格并保留跨层前件。

## 第九节　量词不交换

定理 9.1　理持续与理不断档

　　存在 P ∈ Π 使对一切 s ∈ J\_obs 有 Principle\_s(P) = 1  
　　⇒ 对一切 s ∈ J\_obs 存在 P ∈ Π 使 Principle\_s(P) = 1。

反向不成立。

证明。正向：取见证 P，对每个 s 以同一个 P 作为存在见证即可。反向反例：设 Π = { P₁, P₂ }，观察窗前半段只有 P₁ 成立、后半段只有 P₂ 成立。则每个时刻都有某个候选成立，而没有任何一个候选在整个窗内始终成立。证毕。

一句话：同一理持续蕴含理不断档；理不断档不蕴含同一理持续。

证书层与职责层有对应的量词不交换：

　　存在 C 使对一切 s 成立 ⇒ 对一切 s 存在 C 成立，反向不成立；  
　　存在 d 使对一切 s 成立 ⇒ 对一切 s 存在 d 成立，反向不成立。

两处的反例同型：前半窗由一份证书或一项职责承担，后半窗由另一份承担。

## 第十节　轨迹稳定、轨迹族稳定与保证稳定

三个量词层级须分开，不得互相冒充。

### 10.1　单轨迹

Stable^ℓ\_γ 只关于一条具体的合法轨迹，其取值按 6.3 的三值制度给出。

该轨迹若在观察窗内目标退出，则按 3.2 报告 OUT\_A，不另给稳定值；若判定域不足，则报告 ⊥。一条轨迹的结论不得推广到族或保证层，见 10.2 与 10.3。

### 10.2　声明轨迹族

先冻结一个非空族 𝒢^ℓ ⊆ TrajDec\_ℓ。与保证层一样，族层也分目标域与稳定两轴，次序不可颠倒。

先判目标域：

　　FamilyDom\_A = 1 ⇔ 对一切 γ ∈ 𝒢^ℓ 有 DomA\_γ = 1。

若族中含有目标退出的轨迹，则 FamilyDom\_A = 0；若无已知的退出而存在不可判，则为 ⊥。这类轨迹既不记为 Stable = 0，也不记为 ⊥，更不得从族中删去。

只有在 FamilyDom\_A = 1 之后，才判

　　FamilyStable\_ℓ = 1 ⇔ 对一切 γ ∈ 𝒢^ℓ 有 Stable^ℓ\_γ = 1。

族中存在一条稳定为 0 的轨迹，则 FamilyStable = 0。族为空，或无法确认其属于相应的可判轨迹集，则为 ⊥。

### 10.3　全部合法未来保证

先定义合法轨迹集 TrajLegal(F\_t^η, H)。定义它时不得删去不可判轨迹，也不得删去 OUT\_A 轨迹。

先判目标域保证：

　　GuaranteedDom\_A = 1 ⇔ 全部合法轨迹在整个观察窗内 A 都保持 Law。

只有在 GuaranteedDom\_A = 1 之后，才判 GuaranteedStable\_ℓ。若存在合法而不可判的在域轨迹，则 GuaranteedStable = ⊥。

不得以一条可恢复的轨迹冒充 FamilyStable，也不得以 FamilyStable 冒充 GuaranteedStable。

## 第十一节　稳定边界、替代区与迟滞

### 11.1　恢复层级

Recover\_C、Recover\_d、Recover\_P、Recover\_Π 分别定义，不得互相冒充。

例如 P₀ 失效而 P₁ 立即接替、其后 P₀ 回归：此时可以有 Recover\_P(P₀) = 1，但候选族从未空缺，故根本不存在 Π 层的恢复事件。低层发生恢复时，高层可能从未失效。

### 11.2　稳定边界与资格边界不可混

《理边界式》的资格边界回答的是：当前资格在哪一个 q 上发生 1 与 0 的跨越。本式的稳定边界回答的是：自摄动态 q 出发按协议 H 运行，什么时候不再满足保持或恢复。

两者一般不可比较，两个方向各有反模型。

其一，资格已失而稳定仍成立。设在某摄动参数上当前资格为 0，但该失效落在恢复期限之内、随后按协议复归并满足验证长度。则该处资格边界已被越过，而 Stable = 1。

其二，资格仍成立而稳定已失。设在某摄动参数上当前资格为 1，但其合法后继在观察窗内进入不可恢复的失效。则该处资格尚未越界，而 Stable = 0。

两个方向合起来说明：两类边界之间没有一般的顺序。故不得无条件签 q^∂\_资格 ≤ q^∂\_稳定，也不得签其反向。除非另有稳定判值关于 q 的单调前件，而本式没有该定理。

### 11.3　稳定边界顺序

对同一条预先申报的全序摄动轴 q，且相应失败参数集非空、下确界存在：

　　形式层：q^∂\_C ≤ q^∂\_d ≤ q^∂\_{CH^M}，Status = Established；  
　　本体层：q^∂\_P ≤ q^∂\_Π，Status = Established。

中间一段一般不可比：q^∂\_{CH^M} 与 q^∂\_P 之间没有无条件的顺序，两个方向各有反情形。其一，Law(P₀) 先于形式反持资格退出：此时 P₀ 的理资格先失稳，而形式层仍稳定，故 q^∂\_P \< q^∂\_{CH^M}。其二，形式反持资格先退出而 Law(P₀) 始终保持，且表示前件全程成立：此时形式层先失稳，本体层随之，故 q^∂\_{CH^M} ≤ q^∂\_P。两个方向都可能，故无一般顺序。

若在整个比较域内 Law(P₀) 保持，且形式与本体的表示前件全程成立，则可条件地连接。

若某一层的失败集为空，不得写成正无穷，而应报告

　　NoExitOnΓ，

即在所申报的 Γ 范围内没有取得该层的退出。

### 11.4　稳定替代区与严格不等

本节所谈的是稳定边界，故替代区须按稳定量定义，不得用即时资格的替代事实直接推出稳定边界的严格不等。

定义稳定替代区：

　　Sub^St\_C = { q \| Stable\_C(q) = 0 且 Stable\_d(q) = 1 }；  
　　Sub^St\_d = { q \| Stable\_d(q) = 0 且 Stable\_P(q) = 1 }；  
　　Sub^St\_P = { q \| Stable\_P(q) = 0 且 Stable\_Π(q) = 1 }。

它们表示在该摄动参数上，低层身份按协议 H 已经不再稳定，而高层身份仍然稳定。

须强调：区非空不足以推出下确界严格不等。完全可能在某个 q 上 Q\_C = 0 而 Q\_d = 1，两层最终却都稳定为 0，且两个稳定失败集的下确界相同。

要签

　　q^∂\_{C,St} \< q^∂\_{d,St}，

须另有下列条件全部成立：两层的首次稳定失败点均实际取得；在低层的稳定失败点之后、高层的稳定失败点之前，存在严格后继的比较态落在 Sub^St\_C 内；或者预先申报稳定失败在 q 轴上的单调性。其余两处同理。

以即时资格的替代事实——C₀ 已退出而 d₀ 仍覆盖 J，或 d₀ 已退出而 P₀ 仍为理，或 P₀ 已退出而 P₁ 成立——所能得到的，只是《理边界式》意义下资格边界的严格顺序，不是本式的稳定边界顺序。二者不得混用。

### 11.5　迟滞

迟滞必须逐身份层定义，不得泛称"理的迟滞"。分别有 Hys\_C、Hys\_d、Hys\_P、Hys\_Π。

判迟滞以前须冻结：同一 q 轴；同一身份对象；同一 A、J、Π；同一分辨率；同一协议 H；正向与反向路径预先声明。只有正向的退出边界与反向的入界边界均实际取得以后，才可判迟滞。

标量轴下可写 Hys\_ℓ = \| q\*\_{ℓ,out} − q\*\_{ℓ,in} \|。一般偏序或路径情形只能报告两个边界不重合，不定义宽度。

恢复时间 T\_rec 与迟滞宽度不是同一个量，禁止混写。

## 第十二节　最简表达与主结论

### 12.1　最简表达

在稳定实例 Σ\_P 冻结、A 在工作域内、所需判定域充分的前提下：

　　Stable^ℓ\_γ ⇔ Keep^ℓ\_γ ∨ Recover^ℓ\_γ，　ℓ ∈ { C, d, CH^M, P, Π }；  
　　Stable\_C ⇒ Stable\_d ⇒ Stable\_{CH^M}；  
　　Stable\_P ⇒ Stable\_Π；  
　　Stable\_{CH^M} ⇒ Stable\_P：仅在 Law(P₀) 全程保持且表示前件逐时成立时，Conditional。

上列三条稳定链的反向一律不成立，反例见 7.3。另有两条不得写入最简表达：分量各自稳定不蕴含其合取稳定（定理 8.1）；理不断档不蕴含同一理持续（定理 9.1）。

最简表达只在所声明的前件下成立；离开该前件，各量按 6.3 的三值制度取 ⊥，不得默认为 0。

### 12.2　主结论

理的稳定不是某一个反持实现始终不变。判一份稳定主张以前，必须先说明所要求保持的是哪一个身份：同一份证书、同一项职责、同一个理，还是只要求针对同一个目标律始终有某个理存在。

低层的承担可以替换而高层的资格保持；但一旦 P₀ 被另一个 P 接替，所保持的已不是同一个 Principle，而只是理的存在没有断档。

目标律自身退出时，报告 OUT\_A，那不是失稳。
