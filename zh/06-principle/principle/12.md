自显论·理篇·理组式第十二 v1.0

# 理分级式

## 第一节　式种、唯一任务与进入条件

### 1.1　式种

本式为分级式，采用多维偏序型。它不建立单一总等级，也不给出任何加权总分；它建立的是一套多维偏序的分级制度，并把不可比较、不可通约与未决三者严格分开。

### 1.2　唯一任务

对已经成立的 Principle，在不改变其资格、不引入其它对象的前提下，建立其反持之度的合法分级制度，并明确：分级维度；各维等级值域；各维序方向；各维非退化；各维非冗余；各维与联合比较的偏序性质；不可比较条件；不可通约条件；未决条件；投影规则；以及禁止任意总分与单一总等级。

### 1.3　进入条件

本式只对 Principle\_F,t(P; A, J) = 1 的对象分级。

Principle = 0 者不称"零级理"，它只是没有进入本式的分级对象域。Principle = ⊥ 者，其进入资格未决，本式不给等级。

本式所分的既不是宿主 P 的整体，也不是 P 的全部职责，而是：使 P 相对于 A 取得 Principle 身份的同一固定职责所形成的反持结构。

任何等级关系都不得反向变成 Principle 的资格条件。弱反持仍然是合法的 Principle：等级低不等于资格差，更不等于没有资格。

### 1.4　依附

依附已封版的《理一般式》v1.0、《理数理式》v1.0、《理必然式》v1.0，并使用其既有术语：Law、Principle、CounterHoldRole、DeliveryLimit、ResultLimit、DeliveryAnti、ResultAnti、Type、Read、J、A 持向预序、Att、Rest。不修改上游任何定义，不新增本体谓词，不新增 H。

主式被击穿或撤销，本式结论随之失效或转为待定。

## 第二节　明确排除项

下列各项本式不研究，也不得充当分级维度：行是否正在发生；行的强弱；净效应；竞争胜负；稳定性；理是否生成新律；触发概率与倾向；P 作为 Law 的深与熟；工程资源、能耗与效率。

竞争强弱尤须排除。局部竞争胜负可以不传递——甲胜乙、乙胜丙而丙胜甲的情形并不违反任何上游结构——而不传递的关系按《法篇》不得称为分级。把竞争塞进分级维度，等于用一个非偏序的关系冒充偏序。

## 第三节　固定分级维度

正式维度固定为两个：

　　𝒟\_G = { D, R }，

其中 D 为交出反持维，R 为结果反持维。二者分别对应上游的 DeliveryAnti 与 ResultAnti。

不得因某个对象只有交出型或只有结果型而临时删去维度。某一合法评价单位上某维不适用者，该维在该单位上取 NA，而不是把维度删掉。删维会使两个对象的剖面长度不同，比较无从进行，也会让"不适用"悄悄变成"没有反持"。附录的参考实现为此在剖面长度不等时直接报错，而不是静默截断——静默截断等于默许了一次被本节禁止的输入。

## 第四节　比较规约 Γ\_G

一次分级任务必须事前冻结完整的比较规约 Γ\_G，至少包含：共同目标律 A；完整或投影的比较范围；共同关系域；合法等级评价单位集合；固定的 D 与 R 两维；A 侧共同规范空间；规范化见证规则；Rest 锚点规则；合法结果底域；A 持向结构的保持规则；投影身份；分辨率及必要的读取规则。

不得在看到比较结果之后缩小比较域、改变评价单位或更换规约来制造排名。

若原任务是完整比较，则事后所取的最大共同可比子域只能形成投影比较，不得冒充完整比较。这一条与第十三节的投影规则配套。

## 第五节　合法等级评价单位

等级评价单位不写死为某种固定三元组。正式定义为

　　u ∈ 𝒰\_{Γ\_G}，

其中 𝒰\_{Γ\_G} 是由原 Type 与 Read 语义诱导出的合法等级评价单位集合。

要求如下：单成员型可以使用单成员评价单位；集合型保持原集合评价边界；测度型不得把资格测度比例自动升级为等级分值；时序型与持续型保持原窗口、时间展开与量词单位；分级式不得重新拆解上游的 Type 与 Read。

一句话：Type 与 Read 决定什么是合法的等级评价单位，不决定如何把各单位加总成总分。加总本身在本式是被禁止的，见第十一节 11.2。

## 第六节　规范化域

统一使用三值谓词

　　Dom\_Γ(P) ∈ { 1, 0, ⊥ }。

Dom\_Γ(P) = 1 当且仅当存在一份合法规范化见证 N^Γ\_P，使 P 相对于 A 的候选反持结构能够无损地进入 Γ\_G 的共同规范 A 空间。

合法规范化见证必须满足七项：承重的 A 侧对象同一；定义域合法；事前冻结；不制造也不消灭 Anti；多份允许的规范化见证不得给出不同的等级结论；D 维需要承重 A 序上的序嵌入与统一的 Rest 锚点；R 维需要共同合法结果底域上的结构同构，并保持与 A 持向相关的结构。

若明确违反必要条件，则 Dom\_Γ(P) = 0，记为当前规约域退出 OUT\_Γ。若没有明确失败而必要条件不足，则 Dom\_Γ(P) = ⊥。

进入资格逐候选判定。一次比较中可能出现 Dom\_Γ(P) = 1 而 Dom\_Γ(Q) = 0：此时并非"这一对未决"，而是这一份规约下根本无法完整比较这一对。只有两方都为 1，才可在当前 Γ\_G 下进入第十一至十三节的比较；任一方为 0，则当前规约不足以承担这次完整比较；任一方为 ⊥，则进入资格未决。

须记明：OUT\_Γ 不等于不可通约。前者说的是这一份规约不行，后者说的是任何允许的规约都不行，见第十二节。

## 第七节　A 侧规范化

### 7.1　禁止逐对搭桥

不得采用"P 与 Q 一座桥、Q 与 R 另一座桥"的逐对搭桥方式。所有进入同一个 Γ\_G 的候选，必须规范化进入同一个预先冻结的 A 侧规范空间。

理由是传递性。若每一对各用各的桥，甲不弱于乙、乙不弱于丙，并不能得出甲不弱于丙——两次比较所用的规范空间根本不是同一个。共同空间是传递性的前提，不是形式上的讲究。

### 7.2　D 维的规范化要求

要求映射

　　φ\_{P,u}: X^P\_{A,u}/∼\_P → C\_u

在承重域上为序嵌入，即

　　x ≼\_P y ⟺ φ\_{P,u}(x) ≼^C\_u φ\_{P,u}(y)。

并要求统一的 Rest 锚点

　　φ\_{P,u}(\[Y^P\_rest\]) = c^0\_u。

原始的 Rest 不必相等，但其规范身份必须对齐到同一个 c^0\_u；否则各人从各自的起点量，所得的位序不可比。

不得凭纯粹的序同构人为制造"距离"。规范空间必须来自 A 已有的共同物理、状态、结果或自由度上的有序结构，或已经证明结构同一的规范商空间；不得为了排名随手造一条数轴。

### 7.3　R 维的规范化要求

R 维的规范化必须保证四项：P 与 Q 的完整合法结果底域被同构到同一个 D^C\_u；A 持向序保持；Att、终端类、无界共尾等承担 ResultAnti 的结构保持；不得因为原始底域较小而伪造"限制更严"。

最后一项尤须当心：把一个本来就窄的底域直接当作"限制严"，是用定义域的差别冒充限制的差别。

## 第八节　D 维等级

D 维所分的是交出反持位序，不称为统一的"反持深度"。

在规范空间中，若交出型反持成立，则

　　d^Γ\_P(u) = φ\_{P,u}(\[Y\_P\])，

且

　　d^Γ\_P(u) ≺\_C c^0\_u，

即交出后的规范位置严格逆于 Rest 锚点——这正是 DeliveryAnti 成立的规范化表述。

局部等级序定义为

　　d^Γ\_P(u) ≽\_D d^Γ\_Q(u)　⟺　d^Γ\_P(u) ≼\_C d^Γ\_Q(u)。

方向解释：在共同规范序上位置越逆于 A 的持向，其交出反持位序越高。故等级序与规范序方向相反，这不是笔误，而是这一方向解释的直接写法。此处不涉任何距离：位序是序上的位置，越逆指的是在序中更靠反持一侧，不是量出的远近。

不得引入未经上游支持的数值距离。

附录的参考实现以整数位序表示规范序中的位置，并约定位序越小者在共同规范序中越逆于 Rest 锚点，故 D 维的支配与位序大小相反。这只是实现约定，与本节的定义 ≽\_D ⟺ ≼\_C 完全一致。

## 第九节　R 维等级

R 维所分的是结果限制的严度。它不称为"结果反持距离"或"方向深度"；也不宜称为位序——位序是 D 维的说法，指共同规范 A 序中的位置，而 R 维的等级不落在任何一条序上，它就是限制集本身，其高低由反包含给出。

对已经成立 ResultAnti 的合法结果限制集，在规范共同结果底域中取

　　S^C\_P, S^C\_Q ⊆ D^C\_u，

定义

　　S^C\_P ≽\_R S^C\_Q　⟺　S^C\_P ⊆ S^C\_Q。

即留给 A 的合法结果越少，限制越严，等级越高。

若两个 ResultAnti 集合互不包含，则在 R 维不可比较——即使直觉上某一集合"离终端更远"。直觉上的远近在这里没有形式地位：底域上没有本式承认的距离，只有包含关系。

这一点是 R 维与 D 维的实质差别：D 维的正值落在共同规范 A 序中，该序在承重域上可以是链；而 R 维的正值是结果限制集，其上的反包含只是偏序，互不包含的两个正等级本身就不可比。故不得把 R 维压成一条位序链——那会把一个偏序悄悄变成全序，使互不可比的情形永不出现。附录的参考实现为此把两维的正值分作两种数据类型，并单独核验了 R 维内部的互不可比实例。

## 第十节　局部状态字母表与等级剖面

### 10.1　局部状态

局部求值必须严格区分四种状态：

　　NA：该固定维在该合法评价单位上不适用；  
　　0：该维可评价，但明确没有形成该型 Anti；  
　　v⁺：取得真实的正反持等级；  
　　⊥：本应可评价，而承重事实不足。

四者须严格区分，两两不可互代：NA、0、v⁺、⊥ 各有其义，尤须记住 NA ≠ 0，且二者都不等于 ⊥。

并且

　　NA, 0, v⁺ ∈ V\_G，　而　⊥ ∉ V\_G。

⊥ 是求值状态，不是等级值。

比较规则：NA 只与 NA 比较；真实正值高于明确的 0。

NA 与非 NA 之间的错配是确定失败，不是未决。二者的等级值都已经确定，只是在偏序中没有关系：v⁺ 不高于 NA，NA 也不高于 v⁺，两个方向都不通过。未决只属于 ⊥，即承重事实不足的情形。故一个坐标上一方为 NA、另一方为 v⁺ 或 0 时，两个方向的支配判定各得 0，最终关系为互不可比，而不是 ⊥\_G。

不得把 NA 折叠为 0——那会把"不适用"伪造成"零反持"，从而制造出虚假的严格支配，见第十五节 K-G1。

### 10.2　等级剖面

正式等级值是完整剖面：

　　G^Γ\_D(P) = ( g^P\_D(u) )\_{u ∈ 𝒰\_Γ}，  
　　G^Γ\_R(P) = ( g^P\_R(u) )\_{u ∈ 𝒰\_Γ}。

整个 Principle 的等级剖面为

　　G^Γ(P) = ( G^Γ\_D(P), G^Γ\_R(P) )。

每一个 u 不是独立的维度：正式维度只有 D 与 R，u 只是剖面的索引。

## 第十一节　偏序性质与联合比较

### 11.1　各维偏序

D 剖面的比较采用点态支配：G\_D(P) ≽\_D G\_D(Q) 当且仅当在所有合法评价单位上 D 的局部值都不弱于。R 维同理。

定理 11.1　各维偏序

≽\_D 与 ≽\_R 在等级值空间上自反、传递、反对称。

本定理在等级值空间 V\_G 上陈述，即各坐标取 NA、0 或 v⁺；⊥ 不是等级值，不进入本定理的论域（第十节）。

证明。自反：每个坐标上局部值与自身比较均通过——NA 与 NA 通过，0 与 0 通过，正值与自身在各自的序中通过。传递：设 P 在每一坐标不弱于 Q、Q 在每一坐标不弱于 R。逐坐标看，正值之间的传递分两维各自承担——D 维正值之间的传递来自共同规范 A 序 ≼\_C 的传递，R 维正值之间的传递来自集合包含 ⊆ 的传递；两者都是偏序，故各自传递。再看混合：正值高于 0，0 不高于正值，故正值与 0 的混合情形亦传递；NA 的情形须单独看：若某坐标上 P 与 Q 之一为 NA 而另一为非 NA，则该坐标的比较已经失败，前提"P 在每一坐标不弱于 Q"不成立，无从谈传递；故在前提成立的前提下，P 与 Q 在该坐标必同为 NA 或同为非 NA，Q 与 R 亦然，于是三者在该坐标上要么同为 NA、要么都不是 NA。同为 NA 时传递显然；都不是 NA 时归入上述正值与 0 的情形。于是以 0 与 NA 扩张之后，逐坐标的传递仍然保持。故每一坐标上 P 不弱于 R。反对称：若两向都通过，则每一坐标上双向不弱于。D 维正值处由 ≼\_C 的反对称得相等，R 维正值处由集合的双向包含得相等，0 与 NA 处直接相等。故局部值逐坐标相等，两剖面相同。证毕。

须注意：反对称只给出等级剖面相同，不能推出 P = Q。Principle 的身份层不由等级决定。故定义等级等价

　　P ∼\_G Q　⟺　G(P) = G(Q)，

商掉等级等价以后才得到真正的偏序。

### 11.2　联合偏序

定义

　　G(P) ≽\_G G(Q)　⟺　G\_D(P) ≽\_D G\_D(Q) 且 G\_R(P) ≽\_R G\_R(Q)。

严格支配要求总体不弱且至少一维严格。

定理 11.2　乘积序

≽\_G 在等级值空间上自反、传递、反对称。

证明。两个分量各自自反、传递、反对称（定理 11.1），乘积序逐分量继承这三条。证毕。

不得定义 Score(P) = w\_D·D + w\_R·R 或任何其它加权总分，也不得宣称单一的总体等级号。允许的结论只有一句：P 在完整分级域上支配 Q。

## 第十二节　方向性判定、最终等级关系与三种否定

### 12.1　方向性三值判定

不写单一的比较黑箱。先分别判定方向性支配

　　Dir^Γ\_G(P, Q) ∈ { 1, 0, ⊥ }　与　Dir^Γ\_G(Q, P)。

记号须与第六节的规约进入资格 Dom\_Γ(P) 区分：后者判的是单个候选能否进入共同规范空间，前者判的是两个候选之间某一方向的支配。二者含义全然不同，不用同一个名字。

单方向规则：若存在任一确定坐标使"P 不弱于 Q"失败，则 Dir(P, Q) = 0；若所有坐标均确定通过，则为 1；若无确定失败而仍有一个或多个坐标未决，则为 ⊥。

此处的"确定通过"包括两方同为 NA 的坐标：那是一个已定的通过，不是未决，也不是失败。而一方为 NA、另一方为非 NA 者，按第十节是确定失败。

否证优先：0 优先于 ⊥。已有确定失败时，未知坐标不得把方向性判定重新抬回 ⊥。这一条不是符号洁癖——没有它，只要在任意一个坐标上制造未决，就能把已经确定的失败洗成未决，见第十五节 K-G2。

### 12.2　最终等级关系

由两个方向的判定 Dir(P, Q) 与 Dir(Q, P) 组合：

　　(1, 0) ⇒ P ≻ Q；  
　　(0, 1) ⇒ Q ≻ P；  
　　(1, 1) ⇒ P ∼\_G Q；  
　　(0, 0) ⇒ P ∥\_G Q；  
　　其它未闭合的组合 ⇒ ⊥\_G。

其中 P ∥\_G Q 表示双方已经进入同一合法完整分级域，而两个方向都被确定否证。

### 12.3　三种否定严格区分

　　∥\_G ≠ 不可通约 ≠ ⊥\_G。

∥\_G 指共同分级域内双方互不支配；不可通约指不存在一份允许的完整共同规约；⊥\_G 指本应能判而当前事实不足。

不得写"不能比较时记为 ⊥"这类混合表述：它把三件不同的事压成一件。

### 12.4　不可通约

当前某一个 Γ\_G 失败，不得直接推出不可通约。

对同一个事前申报的比较范围 S，定义允许规约类 Adm(S)。只有

　　不存在 Γ′ ∈ Adm(S) 使 P 与 Q 可共同完整进入，

才称不可通约。

这一判断要求对 Adm(S) 作穷尽考察。仅仅"手头没有找到别的规约"不足以断定不可通约；未完成穷尽者只能停在 OUT\_Γ。附录的参考实现按此设计：只有在传入 Adm(S) 的穷尽枚举结果时，才允许给出不可通约的结论。

两点须记明：找到一个非空的共同子域不等于已经通约；若原任务是完整比较，新规约仍须覆盖同一个完整比较对象。

## 第十三节　完整比较与投影比较

设完整规约的承重域为 𝒰\_Γ。完整比较必须覆盖全部 𝒰\_Γ。

若只能在 U′ ⊊ 𝒰\_Γ 上比较，则结论必须写作

　　P ≽\_{Γ\|U′} Q，

其读法只有一句：P 在投影子域 U′ 上不弱于 Q。不得升格为 P ≽\_Γ Q。

若某个投影从一开始就是独立申报的局部比较任务，则该投影域本身即为那个局部任务的完整域，其结论在该任务内是完整结论。

禁止事后截取有利子域。

## 第十四节　非退化与非冗余

本节的四项主张不以"存在某些等级剖面"为前提。凡等级组合，都须在一个满足上游 Principle 条件的合法模型中实际取得见证；否则便有隐藏耦合的可能——D 与 R 都来自同一固定职责，理论上不能事先排除只有某些 (D, R) 配对可实现。而非冗余所要否证的恰是这种函数依赖，故不可把"任意组合可实现"当作前提，那会使证明循环。

为此申报一个合法最小共同模型 M\_G，其完整构造见附录 B。此处只引用它所提供的三个已成立的 Principle 及其等级剖面。

### 14.1　最小模型所提供的见证

在 M\_G 的单一评价单位 u 上，共同规范 A 序中固定 Rest 锚点 c₀ 并取两点 d₁ ≺\_C d₂ ≺\_C c₀；共同规范结果底域为 D^C\_u = { 0, 1, 2 }，A 的持向终端为 Att = { 2 }。取两个结果限制集

　　S₁ = { 0 }，S₂ = { 0, 1 }，

二者均为 D^C\_u 的真子集且都排除了 Att，故各自的 ResultAnti 成立，都是真实的正 R 等级；且 S₁ ⊊ S₂。

须注意限制集不得等于整个底域：允许 A 的全部合法结果，就没有形成任何结果限制，那样的集合不能充当 ResultAnti 的正见证。

M\_G 中实际取得三个已成立的 Principle：

　　候选　　Dom\_Γ　　D(u)　　R(u)　　所用固定职责  
　　P₁　　　1　　　　 d₁　　　S₁　　　d\*₁₁  
　　P₂　　　1　　　　 d₂　　　S₁　　　d\*₂₁  
　　P₃　　　1　　　　 d₁　　　S₂　　　d\*₁₂

三者各自的 Law(P)、CounterHoldRole 与 J 覆盖均在 M\_G 中成立，其 DeliveryAnti 由 d\_i ≺\_C c₀ 给出，其 ResultAnti 由相应限制集给出。它们不是假设存在的剖面，而是该模型中有见证的三个对象。

### 14.2　D 维非退化

见证 W-ND-D：P₁ 与 P₂。二者的 R 维取值同为 S₁，D 维取值分别为 d₁ 与 d₂，且均为真实正等级。由第八节的等级序 ≽\_D ⟺ ≼\_C，d₁ ≺\_C d₂ 给出 P₁ 在 D 维严格高于 P₂——d₁ 在共同规范序中位置更逆于 Rest 锚点，故其交出反持位序更高。故 D 维至少取得两个不同的真实正等级，非退化成立。

不得用 NA 与 0 的不同来冒充非退化：那两者都不是真实正等级。

### 14.3　R 维非退化

见证 W-ND-R：P₁ 与 P₃。二者的 D 维取值同为 d₁，R 维取值分别为 S₁ 与 S₂，且均为真实正等级。由第九节的定义，S₁ ⊊ S₂ 给出 P₁ 在 R 维严格高于 P₃。故 R 维至少取得两个不同的真实正等级，非退化成立。

### 14.4　D 不由 R 决定

见证 W-NR-D：P₁ 与 P₂。二者的 R 剖面完全相同，而 D 剖面不同。若 D 是 R 的函数，则 R 剖面相同者其 D 剖面必相同，与此矛盾。故 D 不由 R 决定。

### 14.5　R 不由 D 决定

见证 W-NR-R：P₁ 与 P₃。二者的 D 剖面完全相同，而 R 剖面不同。若 R 是 D 的函数，则 D 剖面相同者其 R 剖面必相同，与此矛盾。故 R 不由 D 决定。

### 14.6　合起来

三个对象同时承担两维的非退化与非冗余：P₁ 与 P₂ 给出 D 维的两个不同正等级并固定 R，P₁ 与 P₃ 给出 R 维的两个不同正等级并固定 D。故 D 与 R 各自独立承重，缺一不可，也不能互相替代。

这三个对象的等级剖面已在附录的参考实现中作为测试项核验，见 A.3 的第十四项。

## 第十五节　误判界

K-G1　NA 折零。错误做法是把 NA 映为 0。后果是把"不适用"伪造成"零反持"，从而制造出虚假的严格支配。附录中的错误实现 A 就是它，实测显示同一案例由正确的 P ∥ Q 变为 P ≻ Q。

K-G2　未决向上传播。错误做法是只要存在 ⊥ 就把总体判为 ⊥。后果是掩盖已经确定的双向否证。正确做法是方向性判定采用确定失败优先。附录中的错误实现 B 就是它，实测显示同一案例由 P ∥ Q 变为 ⊥\_G。

K-G3　投影冒充完整支配。错误做法是只取有利子域或单维胜出，就宣称完整支配。

K-G4　OUT\_Γ 冒充不可通约。错误做法是由当前规约失败直接断定不可通约，而未检查允许规约类中是否另有可行者。

K-G5　任意规范化映射制造等级。若允许普通的单调映射压平原有的严格序，或多份合法映射给出不同的等级结论，则不得择优使用。必须满足序嵌入或结构同构，且等级结论不变；否则该规约的求值未决或无效。

须分清两种情形。其一，某个映射根本不满足序嵌入——例如把若干不同的正等级一律压成同一个值——那它自始就不是允许的规范化，应在分级以前被拒绝，而不是拿它与别的映射比结论。附录的参考实现为此提供了序嵌入检验，实测显示压平映射不通过该检验。其二，两份都通过基础结构条件的规范化给出不同的等级结论——此时按第六节所列七项中的第五项，即多份允许的规范化见证不得给出不同的等级结论，该规约的等级求值未决。

## 第十六节　结论

其一，Principle 的反持之度具有两个固定的等级维：D 与 R。

其二，各维内部形成偏序。

其三，完整等级剖面采用乘积支配。

其四，两项理之间可以等级等价、可以严格支配、也可以互不可比。

其五，不存在共同的合法完整规约时，二者不可通约。

其六，信息不足时保持未决。

其七，不建立任意总分、权重或全序。

理不能被排成一条从低到高的统一等级。它们只能在预先冻结的共同规约中，沿两个固定的维度各自比较：各坐标均同向不弱且至少一处严格时，才有严格支配；任一方向被不同坐标或维内的局部偏序关系分别否证时，则只是互不可比。

须记明后一种否证不止一种来路：可以是两维方向相反，也可以是同一维的不同评价单位上各有胜负，还可以是 R 维内部两个限制集互不包含——集合的反包含本就只是偏序，不必借助另一维即可产生互不可比。

"""Minimal reference implementation for the grading protocol of the Principle grading form.

It carries no ontological proof. It only checks, on a finite reference model, that the
decision protocol, the partial-order axioms and the declared misjudgement bounds behave
as the text states.

Every integer rank below denotes a position in a common finite reference order obtained
AFTER a legal A-side normalisation has been performed. A rank is not a theory-defined
physical distance and not a universal scalar strength.
"""
from enum import Enum
from itertools import product


class Local(Enum):
    """Local state alphabet on one legal grading evaluation unit."""
    NA = "NA"              # the fixed dimension does not apply on this unit
    ZERO = "ZERO"          # evaluable, but no Anti of that type is formed
    POSITIVE = "POSITIVE"  # a genuine positive counter-hold grade is taken
    UNKNOWN = "UNKNOWN"    # should be evaluable, but the bearing facts are insufficient


class GammaState(Enum):
    IN_GAMMA = "IN_GAMMA"
    OUT_GAMMA = "OUT_GAMMA"
    UNKNOWN_GAMMA = "UNKNOWN_GAMMA"


class Cell:
    """One coordinate of a grade profile: a local state plus, when POSITIVE, a payload.

    The two fixed dimensions carry DIFFERENT kinds of positive value, and the reference
    implementation keeps them apart on purpose:

      D positive — a position in the common normalised A-order, held as an integer rank.
                   The rank follows the common A-order ≼_C: a SMALLER rank means a
                   position more counter to the Rest anchor, hence a HIGHER D grade.
                   D-grade dominance therefore reverses the rank order, exactly as the
                   text defines it: d_P ≽_D d_Q iff d_P ≼_C d_Q. The rank is a position
                   in a finite reference order obtained after a legal A-side
                   normalisation; it is not a physical distance.
      R positive — the legal result restriction set itself, held as a frozenset of the
                   results still allowed to A inside the common normalised result base.
                   Its order is reverse inclusion, which is only a partial order: two
                   restriction sets that neither contains the other are incomparable.

    Collapsing R onto a rank chain would silently turn a partial order into a total one
    and would never exhibit the incomparable case, so it is not done here.
    """
    def __init__(self, state, rank=None, allowed=None):
        self.state = state
        self.rank = rank            # D positive only
        self.allowed = allowed      # R positive only
        if state is Local.POSITIVE and rank is None and allowed is None:
            raise ValueError("POSITIVE requires either a D rank or an R restriction set")

    def __repr__(self):
        if self.state is not Local.POSITIVE:
            return self.state.value
        return f"D({self.rank})" if self.rank is not None else f"R({set(self.allowed)})"

    def __eq__(self, o):
        return (isinstance(o, Cell) and self.state is o.state
                and self.rank == o.rank and self.allowed == o.allowed)


NA, UNK = Cell(Local.NA), Cell(Local.UNKNOWN)
ZERO = Cell(Local.ZERO)


def POS(r):
    """A D-dimension positive grade: a position in the common normalised A-order.

    Smaller r is further counter to the Rest anchor, hence a higher D grade.
    """
    return Cell(Local.POSITIVE, rank=r)


def RPOS(allowed):
    """An R-dimension positive grade: the set of results still allowed to A.

    Fewer allowed results means a stricter restriction, hence a higher R grade.
    """
    return Cell(Local.POSITIVE, allowed=frozenset(allowed))


def d_positive_ge(a, b):
    """D positive against D positive.

    a is not weaker than b exactly when a sits no further from the counter side in the
    common normalised A-order, i.e. a ≼_C b. With smaller ranks lying more counter to
    the Rest anchor, this reads a.rank <= b.rank.
    """
    return a.rank <= b.rank


def r_positive_ge(a, b):
    """R positive against R positive: reverse inclusion.

    a is not weaker than b exactly when a allows no more than b does. When neither set
    contains the other, both directions return False and the two grades are incomparable.
    """
    return a.allowed <= b.allowed


def cell_ge(a, b):
    """Three-valued 'a is not weaker than b' on one coordinate of one dimension.

    Returns True / False / None, where None means undecided.
    NA compares only with NA. A genuine positive outranks an explicit zero. NA is never
    folded into zero. Note that an NA-versus-anything-else mismatch is a DECIDED failure,
    not an undecided one: both sides carry a settled grade value, they simply stand in no
    order relation, so neither direction passes. Undecidedness belongs to UNKNOWN alone.
    """
    if a.state is Local.UNKNOWN or b.state is Local.UNKNOWN:
        return None
    if a.state is Local.NA or b.state is Local.NA:
        return a.state is Local.NA and b.state is Local.NA
    if a.state is Local.POSITIVE and b.state is Local.POSITIVE:
        if (a.rank is None) != (b.rank is None):
            raise ValueError("cannot compare a D grade with an R grade on one coordinate")
        return d_positive_ge(a, b) if a.rank is not None else r_positive_ge(a, b)
    if a.state is Local.POSITIVE and b.state is Local.ZERO:
        return True
    if a.state is Local.ZERO and b.state is Local.POSITIVE:
        return False
    return True                      # ZERO vs ZERO


def profile_dom(pp, qq):
    """Directional three-valued dominance of one profile over another.

    Refutation first: one decided failure fixes the answer at 0, and later undecided
    coordinates may not lift it back to undecided.
    """
    if len(pp) != len(qq):
        raise ValueError("profiles must share the same declared grading domain")
    undecided = False
    for a, b in zip(pp, qq):
        r = cell_ge(a, b)
        if r is False:
            return 0
        if r is None:
            undecided = True
    return None if undecided else 1


def dom(P, Q):
    """Dominance over the full D/R profile pair. Same refutation-first discipline."""
    dD = profile_dom(P["D"], Q["D"])
    dR = profile_dom(P["R"], Q["R"])
    if dD == 0 or dR == 0:
        return 0
    if dD == 1 and dR == 1:
        return 1
    return None


def compare(P, Q):
    """Final grade relation from the two directional judgements."""
    a, b = dom(P, Q), dom(Q, P)
    if (a, b) == (1, 0): return "P≻Q"
    if (a, b) == (0, 1): return "Q≻P"
    if (a, b) == (1, 1): return "P~Q"
    if (a, b) == (0, 0): return "P∥Q"
    return "⊥_G"


def verdict(P, Q, gamma_P, gamma_Q, adm_exhaustive=None):
    """Separates current-regulation failure from incommensurability.

    Regulation entry is per candidate, as the text defines it: Dom_Γ(P) and Dom_Γ(Q) are
    judged separately, and only when BOTH are IN_GAMMA may the pair be compared under the
    current Γ. If either is OUT, the pair simply cannot be compared completely under this Γ.

    adm_exhaustive, when given, must be an exhaustive enumeration of the admissible
    regulation class Adm(S) over the same declared comparison range, each entry being the
    pair of entry states this regulation yields. Only such an exhaustive enumeration can
    support the verdict 'incommensurable'. When it is None, the caller has not established
    exhaustiveness and the verdict stops at OUT_Γ.
    """
    if GammaState.UNKNOWN_GAMMA in (gamma_P, gamma_Q):
        return "⊥_Γ"
    if gamma_P is GammaState.IN_GAMMA and gamma_Q is GammaState.IN_GAMMA:
        return compare(P, Q)
    if adm_exhaustive is None:
        return "OUT_Γ"
    if any(gp is GammaState.IN_GAMMA and gq is GammaState.IN_GAMMA
           for gp, gq in adm_exhaustive):
        return "OUT_Γ"
    return "incommensurable"


def is_order_embedding(phi, domain, le_src, le_dst):
    """Checks that phi is an order embedding, i.e. x ≼ y iff phi(x) ≼ phi(y).

    A normalisation that is merely monotone, and flattens a strict order, fails this and
    is therefore not an admissible normalisation at all — see the misjudgement bound on
    manufacturing grades by arbitrary mappings.
    """
    return all(le_src(x, y) == le_dst(phi(x), phi(y))
               for x in domain for y in domain)

B.1　模型设定

取单一合法等级评价单位 u。共同规范 A 空间为一条有限链，其中固定 Rest 锚点 c₀，并取两点 d₁ ≺\_C d₂ ≺\_C c₀；按第八节的等级序，d₁ 的 D 维等级高于 d₂。

B.2　三个候选

候选 P₁、P₂、P₃ 各以一项固定职责取得 Principle。须先说明这一项职责的身份：d\*₁₁、d\*₂₁、d\*₁₂ 分别就是 P₁、P₂、P₃ 取得其 Law 资格所凭的那一项已成固定职责，不是另选的职责。以下的 DeliveryLimit、ResultLimit、DeliveryAnti、ResultAnti 与 CounterHoldRole 一律由该同一项职责承担，全程不换。

这一绑定不可省。上游所要求的不是"P 有一个 Law，同时另有一个职责反持 A"，而是使 P 取得 Law 资格的同一项已成职责承担对 A 的反持。若 Law 所凭的职责与承担反持的职责不是同一项，所得的便不是 Principle。
