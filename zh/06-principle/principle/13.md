自显论·理篇·理组式第十三 v1.0

# 理源式

## 第一节　目的、式种与进入条件

### 1.1　式种

本式为源式，附式，独立成篇。它不问理是什么，也不问理何时成立、何时越界、是否稳定、强弱几何；它只问一件事：一项已经发生的理，是怎么发生的。

### 1.2　唯一不可约任务

给定一项由不成立首次转为成立的 Principle，辨明其发生所由，建立合法的来源承担与来源识别条件，并判明其中是否存在这样一种来源——使 P 成律的同一项已成职责，在合法的沉积场历史中取得原先没有的反持角色，从而使理生于律。

本式须回答七问：Principle 已经成立，能否仅凭终态反推它如何发生；什么历史有资格称为真实的发生来源；来源冗余、多路、联合承担时如何处理；无法合法重放时为什么不能判"没有来源"；什么条件下可以说一项 Principle 真正具有律生理来源；一般来源与律生理来源是什么包含关系；哪些情况下来源不能唯一确定。

本式不回答：Principle 是什么；其资格的必要与充分条件；其边界何时跨越；是否稳定；强弱与分级；是否正在行；理如何生成新律；如何从有限观测反演真实来源；来源的概率；以及任何具体运行基底的构造。

### 1.3　依附

依附已封版的《理一般式》v1.0、《理数理式》v1.0、《理必然式》v1.0、《理边界式》v1.0、《理运行基底构造式》v1.0、《理分级式》v1.0。不修改上游任何定义，不新增本体谓词，不新增 H。式内所设的协议谓词只服务于来源判断，不进入本体。

尤须保持上游的同一职责要求：Principle 必须由使 P 取得 Law 资格的同一项已成职责承担 CounterHoldRole。下列写法在本式中一概不成立——"P 有一个 Law，另有一项职责去反 A，所以 P 成理"。那是职责偷换，不是理。

所谓场内生成，一律依附已有的沉积场与合法运行基底动力，不另造抽象宿主。

### 1.4　进入条件

本式的对象不是任意一项已成立的 Principle，而是一次首次发生事件。冻结

　　Genesis\_τ(P; A, J)，

其成立要求

　　Principle\_{τ⁻}(P; A, J) = 0　且　Principle\_τ(P; A, J) = 1，

其中 τ 是所申报历史范围内 Principle 的首次成立边界。本式不重新证明边界式，只引用这一首次由 0 到 1 的事件作为来源研究的对象。

若所论的是 1 → 0 → 1 的再次成立，那属于复归或重入，不在本式主命题的首次创生之列。本式的来源判据同样可以用于复归来源，但复归不得写成首次创生。

## 第二节　为什么终态不能说明来源

理的成立是一个结果。结果相同，来路可以完全不同。若允许由终态反推来源，那么凡是 Principle 成立处都可以宣称律生理，而这一宣称将不承担任何历史。

故本节先排除六类默认伪来源。它们都不是因为"证据不足"而被排除，而是因为它们在形式上根本不是来源承担。

E1　终态反推。不得由 Principle\_τ = 1 推出 LawBorn。终态相同可以来自不同历史，见第十三节 W-S1 所给的两条轨迹。

E2　时间先后。不得由"d\\\* 先变化、Principle 后成立"推出 d\\\* 是来源。先后是时序关系，不是承担关系。

E3　同步相关。不得由"d\\\* 与 Principle 同时变化"推出来源。相关、同步与可预测都不能代替发生承担。

E4　纯 A 侧变化冒充律生理。若 P 与 d\\\* 本身没有形成新的反持角色，只因 A 的持向发生变化而使原职责现在相对于 A 成为 Anti，那么这可以是 Principle 的发生来源，但不能自动称为 LawBorn。

E5　换职责。若使 P 成律的职责与承担反持的职责不是同一项，即 d\_Law ≠ d\_Anti，则不得称为"使 P 成律的同一职责生成为理"。

E6　观察发现冒充生成。若 CounterHoldRole 早已成立，只是后来才被测出，那是识别史，不是发生史。

六者合起来给出本式的基本立场：来源不是从结果读出来的，而是由历史承担出来的。

## 第三节　来源协议与候选历史单元

### 3.1　来源协议

一次来源考察必须事前冻结来源协议 Π\_src，至少包含：初态；P、A、J 与 d\\\* 的身份规则；候选来源历史单元族 ℋ^Π；允许的外部输入；宿主与沉积场的动力规则；允许的冻结、遮蔽与移除操作；以及最终统一使用原 Principle 判据求值这一条。

候选历史单元族须在看到来源结果之前冻结。事后改变粒度以制造"最小来源"，等于先看答案再画题。

并须冻结其有限性：

　　\| ℋ^Π \| \< ∞。

这一条不是技术上的便利，而是第五节最小性得以成立的前提。在有限族上，只要某个非空集合充分而空集不充分，沿真子集下降必在有限步内停住，故必存在包含极小的充分子集，𝒮\_src^Π 的非空性有保证。若允许无限族，则可以构造这样的情形：每一个充分集都还有一个仍然充分的真子集，于是没有任何集合是最小的，𝒮\_src^Π 为空——而那并不是"没有来源"，只是来源是无极小元的分布式承担。本式不判这一类，也不得把它误读成来源为零。

故本式所判定的，是一次冻结的有限来源协议。连续的或无界的历史，必须先依协议切分为有限多个合法来源单元，然后才能进入本式。

### 3.2　禁止事项

不得改初态；不得改 Principle 或 Law 的判据；不得直接补偿其它状态以维持原轨迹；不得在删除一个历史单元之后人工修补其后果；不得直接写入 Principle = 1；不得为获得所需结果而事后重切历史单元。

### 3.3　协议相对性

来源结论默认写成协议相对的形式：

　　Source^Π，　LawBorn^Π。

若多份允许的来源协议给出不同的来源结论，只能报告协议相对的结果。只有当结论在整个允许协议类中保持不变时，才可提升为协议无关的结论。

## 第四节　合法重放

### 4.1　三值语义

对候选历史子集 K ⊆ ℋ^Π 定义

　　Replayable\_Π(K) ∈ { 1, 0, ⊥ }。

定义域包含空集。空集在本式中有明确而单一的角色：它是背景控制，不是来源候选。Replayable\_Π(∅) 问的是"不保留任何已申报的来源单元"这一背景控制运行本身是否合法；Suff\_Π(∅) 问的是冻结背景本身是否已足以得到 Principle。两者都须可求——否则第五节判定单元素集的最小性时，其唯一的真子集正是空集，最小性将无从判起。

层次由此清楚：Replayable 与 Suff 对一切 K ⊆ ℋ^Π 定义，空集在内；而 𝒮\_src^Π 只收非空的 K。

Replayable\_Π(K) = 1：存在符合 Π\_src 的合法重放——同初态、同身份规则、同允许输入、同动力规律；对未被选入 K 的来源单元只使用协议允许的冻结或遮蔽；此后让系统自行演化。

Replayable\_Π(K) = 0：这样的反事实重放本身不合法。例如只有通过换宿主、改身份、改动力律或改资格判据才能完成。

Replayable\_Π(K) = ⊥：理论上应当可判，而现有事实不足以确认该重放是否合法。

### 4.2　不可重放不是不是来源

这一条须单独写明：

　　不能合法重放　≠　反事实失败　≠　不是来源。

Replayable = 0 说的是这一协议无法回答该反事实，不是说被删的历史不承担来源。一段历史可能不可干预、不可逆、无法合法删除，而它恰恰是真实的来源。把不可重放读成来源为零，是本式最要防的一种误判。

## 第五节　充分来源与可认证最小来源

### 5.1　充分性

只有在 Replayable\_Π(K) = 1 之后，才可求

　　Suff\_Π(K) ∈ { 1, 0, ⊥ }。

若在该合法重放中起点处 Principle = 0，而到实际首次成立时刻 τ 时 Principle = 1，则 Suff\_Π(K) = 1。

此处不要求反事实中的 Principle 也恰好在 τ 第一次成立：移除某个抑制因素之后，它可能更早成立。本式所研究的是资格的发生来源，不是发生时刻的全部定时原因。

### 5.2　可认证最小性

定义 Minimal\_Π(K) ∈ { 1, 0, ⊥ }。

若 Suff\_Π(K) = 1，且对一切真子集 K′ ⊊ K 都已有 Replayable\_Π(K′) = 1 与 Suff\_Π(K′) = 0，则 Minimal\_Π(K) = 1。

若存在某个关键真子集其 Replayable 为 0 或 ⊥，则不得宣布 K 最小，只能记 Minimal\_Π(K) = ⊥。

不得默认只检查单元素删除就够。除非另有明确的单调性或闭包条件，定义层必须遍历所有真子集。

### 5.3　最小充分来源集族

定义

　　𝒮\_src^Π = { K \| K ≠ ∅ ∧ Suff\_Π(K) = 1 ∧ Minimal\_Π(K) = 1 }。

非空要求不可省。若空集已经足够——即 Suff\_Π(∅) = 1，冻结的背景动力本身就令 Principle 成立——那说明所申报的候选来源单元族没有捕获真正的发生承担，或者来源落在冻结的背景条件之中。

由此须同时守住两件事，二者不可互相吞并：

其一，空集仍然不得进入 𝒮\_src^Π。一个没有任何承担者的来源，不是来源。

其二，事件层的来源也不得因此判为 0。恰恰相反，Suff\_Π(∅) = 1 本身就证明当前候选来源域不完备——不能一面说真正的来源可能藏在冻结背景里，一面又说候选域已经穷尽、所以没有来源。此时应当把承重的背景重新拆入 ℋ^Π，再行判定。

故立一条纪律：

　　Suff\_Π(∅) = 1　⇒　Source^Π = ⊥。

没有被候选域捕获，不等于没有来源。这与第四节"不可重放不是不是来源"是同一条纪律的两种形态：前者说协议的删除能力有限，后者说协议的切分能力有限，两者都不构成来源为零的证据。附录的参考实现为此从单元素起枚举，并另设测试核验背景充分时 𝒮\_src^Π 为空而事件层来源与来源承担均停在未决。

这是真正可认证的最小充分来源集族。本式此后所说的"来源"，一律以它为准。

其非空性由 3.1 的有限性保证：若存在非空的充分集而空集不充分，则在有限族上沿真子集下降必在有限步内停住，所停之处即为最小充分来源集。故在本式的工作域内，"𝒮\_src^Π = ∅"只能来自真正的无来源或穷尽性不足，不会来自极小元的缺失。

### 5.4　事件级来源

定义

　　Source^Π(H; P, A, J) = 1　⟺　𝒮\_src^Π ≠ ∅。

其三值边界为：若相关的候选来源域与合法重放均已穷尽，而 𝒮\_src^Π = ∅，则 Source^Π = 0；若穷尽性不足、或关键重放非法或未决、或 Suff\_Π(∅) = 1，则 Source^Π = ⊥。

第三种情形须特别记明：Suff\_Π(∅) = 1 直接否定了穷尽性这一前提，故它不落入 0 的那一支，而落入 ⊥。

这一谓词是第九节两条定理的落脚点，不可只靠 𝒮\_src^Π 的非空性口头带过。

## 第六节　冗余、必要与多路来源

### 6.1　来源承担

对历史单元 h：若存在 K ∈ 𝒮\_src^Π 使 h ∈ K，则 SourceCarrier\_Π(h) = 1。

若要判 SourceCarrier\_Π(h) = 0，必须已经穷尽相关的候选来源域、相关的合法重放与所有可认证最小充分来源集，并确认 h 不属于其中任何一个。否则一律保持 ⊥。

一句话：没有找到来源证书，不等于不是来源。

### 6.2　必要来源

附带定义：NecessarySource\_Π(h) = 1 当且仅当来源族已完整识别，且

　　h ∈ ⋂\_{K ∈ 𝒮\_src^Π} K。

"已完整识别"这一前提不可省。若有关键重放非法，或背景本身已足够，则可能还有未被触及的最小充分来源集，而其中某一个未必含 h。此时不得由已找到的那一部分断言必要性，只能记 ⊥。附录的参考实现为此在这两种情形下先行返回未决，并有测试核验。

它只是来源的一种附带分类，不是本式的主命题。

### 6.3　冗余来源

设 𝒮\_src^Π = { { h₁ }, { h₂ } }。此时删去 h₁ 之后 h₂ 仍足以生成 Principle，删去 h₂ 之后 h₁ 亦然。

于是"单删之后 Principle 仍然成立"不能推出"h 不是来源"。这一点在附录的参考实现中有实测：两个单元各自构成一个最小充分来源集，二者都是来源承担者，而没有一个是必要来源。

据此区分三类：

　　必要来源——属于所有最小充分来源集；  
　　冗余但真实的来源——属于至少一个，但不是所有；  
　　非来源伴生项——不属于任何一个已完整识别的最小充分来源集。

第三类的判定尤须谨慎：它要求"已完整识别"，否则只能停在 ⊥。

## 第七节　律生理的同职责发生条件

一般的 Principle 来源允许多种承担：P 侧变化、A 侧变化、联合变化，乃至外部直接写入。LawBorn 只是其中一种，其最小结构固定为下列七项；它确实是一般来源的真子类，这一点由第九节的两条定理证明，此处先不预支。

G1　先成律。存在 t₀ \< τ 使 Law\_{t₀}(P) = 1。

G2　同一成律职责。存在 d\\\*，它就是 P 在 t₀ 取得 Law 资格所凭的那一项职责。

G3　职责身份承继。d\\\*\_{t₀} ≡ d\\\*\_τ。允许职责的状态、作用关系与角色发生变化，不允许身份被偷换。

G4　Law 资格在发生端仍成立。Law\_τ(P) = 1，且发生端的 Law 资格仍由同一 d\\\* 承担。此处不强写整个 \[t₀, τ\] 全程 Law = 1——那是未经证明的加强。最低要求只锁三点：起点成律、终点仍成律、同一 d\\\* 两端承担。

G5　反持关系资格新生。在来源起点 CounterHoldRole\_{t₀}(d\\\*; P, A, J) = 0，而在发生端 CounterHoldRole\_τ(d\\\*; P, A, J) = 1。

G5 只判这一关系资格由 0 变为 1，不判这次变化由 P 侧、A 侧还是联合侧造成。来源归属完全由 G6 承担。故纯 A 侧的发生完全可能满足 G5——A 的持向变了，同一职责相对于 A 就成了 Anti——而它仍然不是 LawBorn，因为 G6 不成立。

G6　同一职责的角色形成历史是真实的来源承担。存在 K ∈ 𝒮\_src^Π，使该同一 d\\\* 的角色形成历史 h\_{d\\\*} ∈ K。

此处的 h\_{d\\\*} 指的是：在 Π\_src 所冻结的候选单元族中，那些承担 d\\\* 自身由无反持关系资格到有反持关系资格这一转变的历史单元。它必须是同一个 d\\\* 的历史，不是 P 的别的职责的历史，也不是 A 侧的历史。

G7　该角色形成不得靠直接资格写入制造。h\_{d\\\*} 必须由许可的沉积场或运行基底动力形成——此处的许可动力即 Π\_src 第五项所冻结的宿主与沉积场动力规则，依附《理运行基底构造式》，本式不另造。不得以 CounterHoldRole := 1、Principle := 1、DeliveryAnti := 1、ResultAnti := 1 之类的直接写入充当 LawBorn 的生成机制。

G5 与 G6 的分工须看清：G5 只说这一关系资格是新生的，G6 才说这段新生背后有同一职责自身的角色形成历史，并且该历史确实承担了来源。资格新生不等于来源承担——这正是第二节 E3 所排除的同步相关在结构层的对应物。

## 第八节　律生理来源定理

定理 8.1　律生理来源定理

设对首次事件 Genesis\_τ(P; A, J)，存在职责 d\\\* 与来源历史 H，使 G1 至 G7 全部成立。则

　　LawBornSource^Π(H; P, A, J) = 1。

证明分两条链，最后合取。

结构链。由 G4 得 Law\_τ(P) = 1；由 G5 得 CounterHoldRole\_τ(d\\\*; P, A, J) = 1；由 G2 与 G3，此处的 d\\\* 正是使 P 取得 Law 资格的同一项职责，两端身份一致。于是引用已封版《理必然式》的充分向

　　Law\_τ(P) ∧ CounterHoldRole\_τ(d\\\*; P, A, J) ⇒ Principle\_τ(P; A, J)，

得 Principle\_τ = 1。

这一步的作用须说清，以免被读成多余。Principle\_τ = 1 本由第一节的进入条件给出，无须在此重证；结构链真正确立的是它的承担方式——τ 处的这一份 Principle 由 Law\_τ(P) 与同一 d\\\* 的 CounterHoldRole\_τ 两项承担，而不是由别的职责或别的路径承担。没有这一步，G6 所指的 h\_{d\\\*} 就可能是一段与 τ 处实际承担无关的历史。

至于 τ 的首次性，同样由进入条件给出——Genesis\_τ 已冻结 τ 为首次成立边界。此处不由 G5 去推"τ 以前尚无反持关系资格"：G5 只给 t₀ 与 τ 两个时点的取值，推不出整个开区间。

来源链。由 G6，该同一 d\\\* 的角色形成历史 h\_{d\\\*} 属于某个已认证的最小充分来源集 K ∈ 𝒮\_src^Π。按第五节，K 的充分性由合法重放给出，其最小性由对所有真子集的检验给出。故 h\_{d\\\*} 不是同步伴生项，而是真实的来源承担。又由 G7，这段历史由许可动力形成，不是直接资格写入。

两条链合取，即得 LawBornSource^Π = 1。证毕。

须记明：结构链只保证 Principle 在 τ 成立，来源链只保证那段历史承担来源；缺任何一条，所得都不是 LawBorn。不得把角色新生直接等同于来源承担，也不得把资格成立直接等同于来源判定。

## 第九节　一般来源与律生理来源的边界

定理 9.1　包含关系

　　LawBornSource^Π ⇒ Source^Π。

证明。由 G6，存在 K ∈ 𝒮\_src^Π 含 h\_{d\\\*}，故 𝒮\_src^Π 非空，按第五节即 Source^Π 成立。证毕。

定理 9.2　反向不成立

　　Source^Π ⇏ LawBornSource^Π。

以两类反例证明。

其一，纯 A 侧变化。P 与 d\\\* 自身不形成任何新结构，A 的持向发生变化，使原职责相对于 A 成为 Anti，Principle 由 0 变 1。该历史构成合法的最小充分来源集，故 Source^Π = 1。此时 G5 甚至可能成立——反持关系资格确实由 0 变 1。真正失败的是 G6：不存在 K ∈ 𝒮\_src^Π 使同一 d\\\* 自身的角色形成历史 h\_{d\\\*} ∈ K，因为根本没有这样一段历史承担来源。故 LawBorn 不成立。这一情形在附录中单独实测。

其二，外部直接写入。资格结构被直接写入而成立，Principle 由 0 变 1，该写入历史同样构成最小充分来源集，故 Source^Π = 1；但由 G7，直接写入不得充当 LawBorn 的生成机制。

二者在附录的参考实现中均有实测，各自 Source = 1 而 LawBorn = 0。

推论 9.3

　　Genesis\_τ ⇏ LawBornSource^Π。

一项理发生了，不等于它由律生。

## 第十节　纯律生、协同律生与其它来源型

以下四个标签只是来源归属的附带分类，不构成分级，不再向下扩展。

PureLawBorn：存在一个最小充分来源集，其成员全部是 G6 所指的 h\_{d\\\*}，即同一 d\\\* 自身的场内角色形成历史。

CoLawBorn：存在一个最小充分来源集，其中含 h\_{d\\\*} 作为真实不可删的来源成员，而该集合并不止于 h\_{d\\\*}——还须与 A 侧变化、合法输入或其它联合历史共同承担。

ASource：存在纯 A 侧即足够的来源路径。

DirectWriteSource：存在以直接写资格结构为承担的最小充分来源路径。

前两者都是 LawBorn 的子类型，故

　　PureLawBorn ⇒ LawBorn，　CoLawBorn ⇒ LawBorn。

G1 至 G7 中任何一项不成立时，这两个标签一并关闭，不得只因某条来源集的形状合适就贴上。附录的参考实现为此在两个标签的判定前先查 LawBorn。

四者不要求互斥。同一个 Genesis 事件完全可以既有 LawBorn = 1，又有 ASource = 1——那意味着它有两条独立足够的来路。来源允许多归属。

须强调：Pure 与 Co 不是强弱之别，只是承担结构之别。把它们读成等级，等于把本式与《理分级式》混为一谈。

## 第十一节　来源非唯一性与协议相对性

来源的非唯一性至少有四种，须显式申报。

U1　多个最小充分来源集。𝒮\_src^Π 可以含多个 K，它们彼此独立足够。

U2　多种来源归属可以同时成立。LawBorn、ASource、DirectWriteSource 之间不必互斥。

U3　PureLawBorn 与 CoLawBorn 可以由不同的来源路径同时成立：一条最小充分来源集全由 h\_{d\\\*} 构成，另一条则须联合承担，二者并存并不矛盾。不强迫单标签。

U4　协议相对性。不同的允许协议可能因历史切分或合法重放的定义不同而给出不同的来源分解。

故来源结论默认写作 Source^Π 与 LawBorn^Π，不得悄悄提升为绝对的来源结论。只有在允许协议类中证明了结论不变性，才可去掉上标。

## 第十二节　三值判定与 0 与 ⊥ 的边界

这是本式必须写清的核心之一。

### 12.1　何时可判 LawBorn = 1

G1 至 G5 的结构条件全部成立——先成律、同一成律职责、职责身份承继、发生端 Law 仍由该职责承担、反持关系资格由 0 变 1；并且至少存在一条已认证的最小充分来源路径，其中该同一 d\\\* 自身的角色形成历史 h\_{d\\\*} 是真实的来源承担（G6），且不是直接资格写入（G7）。

七项缺一，即不得判 1。

### 12.2　何时可判 LawBorn = 0

只有两种情形。

其一，结构性排除：G1 至 G5 中任一项确定不成立——先成律不成立；或使 P 成律的职责与承担反持者确定不是同一项；或职责身份未承继；或发生端的 Law 已不由该职责承担；或反持关系资格并非由 0 变 1。此外，在该协议下根本不存在合法的同职责来源可能者，亦属此支。

其二，穷尽性排除：来源候选域已冻结且足够完整；所有相关的合法重放已穷尽；所有可认证的最小充分来源集已求出；而其中没有任何一个包含同一成律职责自身的角色形成历史 h\_{d\\\*} 作为来源承担。

此支另有一项前提须写明：Suff\_Π(∅) = 0。若背景本身已足够，则候选域的完备性已被否定，穷尽性无从谈起，此时只能记 ⊥，见 5.3。

### 12.3　其余一律为 ⊥

三条纪律须并列写明，它们各自堵住一种把协议的局限读成场中事实的做法：

　　Replayable = 0 ⇏ LawBorn = 0——删不动不等于不承担；  
　　Suff\_Π(∅) = 1 ⇏ Source = 0——没被候选域捕获不等于不存在；  
　　没有找到来源证书 ⇏ 不是来源——未穷尽不等于已否证。

不可干预、不可逆、无法合法删除、切分不当、尚未查全，都不是"无来源"的证据。

## 第十三节　对照情形

以下五种情形用于划界，各自在附录的参考实现中有实测。

W-S1　终态相同而来源不同。历史一：同一职责在场内形成 CounterHoldRole。历史二：外部直接写入。二者最终都得 Principle = 1。故终态不能唯一反推来源。实测：前者 LawBorn = 1，后者 LawBorn = 0。

W-S2　纯 A 侧发生。P 与 d\\\* 不形成新角色，A 的持向变化，最终 Principle = 1。故 Genesis ⇏ LawBorn。实测：Source = 1，ASource = 1，LawBorn = 0。

W-S3　冗余双源。K₁ = { h₁ } 与 K₂ = { h₂ } 两条独立足够。故单删的必要性不是来源判据。实测：𝒮\_src 含两个单元素集，两个单元都是来源承担者，而没有一个是必要来源。

W-S4　不可合法重放。真实历史可能有来源，但删除候选历史会破坏身份或合法动力规则。故不可重放 ⇏ 非来源。实测：Replayable = 0，而 Suff 与 SourceCarrier 均停在 ⊥，不随之降为 0。

W-S5　换职责。d₁ 使 P 成律，其后由 d₂ 去反 A。故 d\_Law ≠ d\_Anti 不能构成"同一成律职责生理"的正例。实测：Source = 1，LawBorn = 0。

## 第十四节　误判界

K-SRC1　在已满足 Genesis 的进入条件且 G1 至 G7 全部成立时，本式仍不能得到所宣称的 LawBorn。

K-SRC2　来源定理依赖了一个未申报的外部条件。

K-SRC3　合法重放证明被认定的 h\_{d\\\*} 实际不承担所宣称的来源作用。

K-SRC4　纯 A 侧、直接写入或换职责的历史被误判为 LawBorn。

K-SRC5　冗余的真实来源因"单删仍成立"而被错误判为非来源。

K-SRC6　不可合法重放被直接解释成来源为 0。

关于击穿的一点纪律：只有当本式宣称某过程是"必要来源"或"唯一来源"时，"过程缺席而目标仍发生"才构成击穿。本式既然允许替代来源，就不得以替代路径的存在来错误击穿。

## 第十五节　完成条件、接口与结论

### 15.1　完成条件

　　CPL-SRC1　对象限定为首次 Principle 由 0 到 1，不重新定义 Principle。  
　　CPL-SRC2　排除终态反推、时间先后、同步相关、纯 A 侧、换职责、观察发现六类伪来源。  
　　CPL-SRC3　冻结 Π\_src 与候选历史单元族，并冻结该族的有限性，使最小充分来源集的存在性有保证。  
　　CPL-SRC4　建立 Replayable、Suff、Minimal 的三值语义，并明确非法重放不等于非来源。  
　　CPL-SRC5　支持多路、冗余与分布式的最小充分来源集；空集不得进入 𝒮\_src^Π。  
　　CPL-SRC5b　事件级 Source^Π 已正式定义并给出三值边界；空集充分时判未决而非 0。  
　　CPL-SRC5c　Replayable 与 Suff 的定义域含空集，空集作背景控制；𝒮\_src^Π 只收非空集。  
　　CPL-SRC6　证明 G1 至 G7 蕴含 LawBornSource^Π。  
　　CPL-SRC7　证明 LawBornSource^Π 蕴含 Source^Π，并以反例证明反向不成立。  
　　CPL-SRC8　来源的多解、多归属与协议相对性均已显式申报。  
　　CPL-SRC9　不承担运行基底、可达、边界、稳定、分级、理生新律与有限观测反演等下游任务。

### 15.2　接口

向《理运行基底构造式》：本式所说的场内角色形成，一律依附其已构造的运行基底动力；本式不另造宿主。

向《理边界式》：本式引用其首次跨越作为对象，不重新判定边界。

向《理稳定式》与《理分级式》：来源不判稳定，也不判强弱；反之亦然。

向理生新律与观测反演等下游任务：本式只给发生来源的判据，不给由有限观测反演真实来源的方法，也不给来源的概率。

### 15.3　结论

一项 Principle 的成立事实，并不唯一决定其发生来源。

真实的来源必须由合法来源协议下的发生历史承担，而不能由终态、相关或时间先后反推。

一项发生可以具有多个最小充分来源集；来源可以冗余、可以分布、可以多归属。

不可合法重放，只意味着当前协议无法回答该反事实，不意味着那段历史不是来源。

所谓律生理，不是 Principle 资格的另一种定义，而是一项来源性质：使 P 成律的同一项已成职责，在保持其 Law 身份承担的同时，经合法的沉积场历史取得原先没有的 CounterHoldRole，并且这段角色形成历史 h\_{d\\\*} 真实地属于至少一条已认证的最小充分来源路径，而不是由直接资格写入制造。

因此

　　LawBornSource^Π ⇒ Source^Π，  
　　Source^Π ⇏ LawBornSource^Π，  
　　Principle = 1 ⇏ LawBornSource^Π = 1。

理成立了，不等于理由律生；理由律生，是一件须由历史承担的事。

~~~python
"""Minimal finite model for the source certificates of the Principle-origin form.

It carries no ontological proof. On a finite reference model it only checks that the
source-certificate system behaves as the text states: redundant sources, several minimal
sufficient source sets, the separation of illegal replay from non-source, the pure and
cooperative law-born types, and the two directions between Source and LawBorn.

Every history unit below is an opaque token. The model never writes Principle directly;
it evaluates the frozen Principle criterion on whatever the replay produces.
"""
from itertools import combinations
from enum import Enum


class Tri(Enum):
    TRUE = 1
    FALSE = 0
    UNDEC = "⊥"

    def __repr__(self):
        return {1: "1", 0: "0", "⊥": "⊥"}[self.value]


class Scenario:
    """One frozen source protocol Π_src over one Genesis event.

    units          — the frozen candidate history-unit family ℋ^Π, required to be finite:
                     over a finite family, a non-empty sufficient set always contains a
                     minimal sufficient one, so 𝒮_src^Π cannot be empty for the wrong
                     reason. Continuous or unbounded histories must first be cut into
                     finitely many legal source units by the protocol.
    law_at         — for each unit, whether it carries Law(P) at the source origin.
    role_units     — units that are role-formation history of the SAME duty d* that
                     carries Law(P); these are the only candidates for a law-born path.
    direct_write   — units that obtain the qualification by writing it in rather than by
                     admissible field dynamics; such a unit can be a Source but never
                     grounds LawBorn.
    a_side         — units that are purely A-side changes; likewise never LawBorn.
    unreplayable   — subsets whose removal cannot be legally replayed at all.
    holds          — the frozen Principle criterion, evaluated on the surviving units.
    Besides the history data, three structural inputs are carried explicitly so that the
    law-born test encodes G1–G7 rather than only the source-certificate part:
    duty_persists (G3), law_at_tau (G4) and role_novel (G5). They are supplied by the
    upstream forms; the model does not derive them.
    """
    def __init__(self, units, holds, role_units=frozenset(), direct_write=frozenset(),
                 a_side=frozenset(), unreplayable=(), prior_law=True, same_duty=True,
                 duty_persists=True, law_at_tau=True, role_novel=True):
        self.units = frozenset(units)
        self.holds = holds
        self.role_units = frozenset(role_units)
        self.direct_write = frozenset(direct_write)
        self.a_side = frozenset(a_side)
        self.unreplayable = {frozenset(s) for s in unreplayable}
        self.prior_law = prior_law            # G1 Law holds at the source origin
        self.same_duty = same_duty            # G2 that Law is carried by d*
        self.duty_persists = duty_persists    # G3 the duty identity is carried through
        self.law_at_tau = law_at_tau          # G4 Law still holds at τ, borne by the same d*
        self.role_novel = role_novel          # G5 CounterHoldRole goes 0 → 1

    # ---- replay ---------------------------------------------------------------
    def replayable(self, K):
        """Whether removing everything outside K admits a legal replay.

        Defined for EVERY K ⊆ ℋ^Π, the empty set included: Replayable(∅) asks whether the
        background control run — no declared source unit retained — is itself legal. The
        empty set is a control input, not a source candidate; only 𝒮_src^Π excludes it.

        An illegal replay is a fact about the protocol, not about the field: it says the
        counterfactual cannot be run here, never that the removed history is no source.
        """
        return Tri.FALSE if frozenset(K) in self.unreplayable else Tri.TRUE

    def suff(self, K):
        """Source sufficiency of K: the replayed run still reaches Principle = 1.

        Also defined for the empty set, where it asks whether the frozen background alone
        already yields Principle = 1. Only asked after the replay is legal; an illegal
        replay leaves this undecided.
        """
        if self.replayable(K) is not Tri.TRUE:
            return Tri.UNDEC
        return Tri.TRUE if self.holds(frozenset(K)) else Tri.FALSE

    def minimal(self, K):
        """Certifiable minimality: every proper subset is legally replayable and insufficient.

        If some proper subset cannot be legally replayed, minimality is undecided — it is
        not declared, and it is not denied. Single-element deletion is never enough.
        """
        K = frozenset(K)
        if self.suff(K) is not Tri.TRUE:
            return Tri.FALSE if self.suff(K) is Tri.FALSE else Tri.UNDEC
        undecided = False
        for r in range(len(K)):
            for sub in combinations(sorted(K), r):
                sub = frozenset(sub)
                if self.replayable(sub) is not Tri.TRUE:
                    undecided = True
                    continue
                if self.suff(sub) is Tri.TRUE:
                    return Tri.FALSE
        return Tri.UNDEC if undecided else Tri.TRUE

    def empty_suffices(self):
        """Whether the frozen background control alone already yields Principle = 1.

        If it does, the declared candidate family has failed to capture the bearing
        history, or the source lies inside the frozen background conditions. Two things
        follow, and they must not be confused:

          the empty set still never enters 𝒮_src^Π — a source with no carrier is no source;
          but the event-level verdict cannot be 0 either, because the very fact that the
          background suffices shows the candidate domain is incomplete. Exhaustion has not
          been established, so Source^Π stays undecided and the protocol must be rebuilt
          with the bearing background split back into ℋ^Π.

        Not captured by the candidate domain is not the same as no source at all.
        """
        return self.holds(frozenset())

    def minimal_sets(self):
        """𝒮_src^Π: all certifiable minimal sufficient source sets. Non-empty only."""
        out = []
        for r in range(1, len(self.units) + 1):
            for K in combinations(sorted(self.units), r):
                K = frozenset(K)
                if self.suff(K) is Tri.TRUE and self.minimal(K) is Tri.TRUE:
                    out.append(K)
        return out

    # ---- source carriage ------------------------------------------------------
    def source_carrier(self, h):
        """Whether h belongs to some certifiable minimal sufficient source set.

        A negative verdict requires the candidate domain to be exhausted; where some
        relevant replay is illegal, the verdict stays undecided rather than 0.
        """
        sets = self.minimal_sets()
        if any(h in K for K in sets):
            return Tri.TRUE
        if self.empty_suffices() or self.unreplayable:
            return Tri.UNDEC          # exhaustion not established
        return Tri.FALSE

    def necessary_source(self, h):
        """h lies in every certifiable minimal sufficient source set. A side label only.

        The text requires the source family to be COMPLETELY identified first. Where some
        relevant replay is illegal, or the background alone suffices, further minimal sets
        may exist that were never reachable, and one of them might omit h. In that case the
        label stays undecided rather than claiming necessity from a partial family.
        """
        sets = self.minimal_sets()
        if not sets:
            return Tri.UNDEC
        if self.empty_suffices() or self.unreplayable:
            return Tri.UNDEC          # family not completely identified
        return Tri.TRUE if all(h in K for K in sets) else Tri.FALSE

    # ---- source types ---------------------------------------------------------
    def is_source(self):
        """Source^Π at the event level: 𝒮_src^Π is non-empty.

        0 requires the candidate domain and the relevant replays to be exhausted; where
        exhaustion is not established, the verdict stays undecided rather than 0.
        """
        if self.minimal_sets():
            return Tri.TRUE
        if self.empty_suffices():
            return Tri.UNDEC      # candidate domain incomplete, not an absence of source
        return Tri.UNDEC if self.unreplayable else Tri.FALSE

    def law_born(self):
        """LawBorn: G1–G7.

        G1–G5 are the structural conditions supplied above: prior Law, the same duty
        carrying it, that duty's identity carried through, Law still standing at τ borne by
        the same duty, and the counter-hold relation going 0 → 1. G6 requires that duty's
        own role-formation history to sit inside some certifiable minimal sufficient source
        set; G7 requires that history not to be a direct qualification write.

        Note G5 only records that the relation changed from 0 to 1; it says nothing about
        which side caused the change. Attribution is G6's job, which is exactly why a pure
        A-side genesis can satisfy G5 and still fail LawBorn.
        """
        if not (self.prior_law and self.same_duty and self.duty_persists
                and self.law_at_tau and self.role_novel):
            return Tri.FALSE
        sets = self.minimal_sets()
        if not sets:
            return Tri.UNDEC if (self.empty_suffices() or self.unreplayable) else Tri.FALSE
        ok = any(any(h in self.role_units and h not in self.direct_write for h in K)
                 for K in sets)
        if ok:
            return Tri.TRUE
        return Tri.UNDEC if (self.empty_suffices() or self.unreplayable) else Tri.FALSE

    def pure_law_born(self):
        """Some minimal sufficient set whose whole bearing source is that duty's own history.

        PureLawBorn ⇒ LawBorn, so the structural conditions are checked first.
        """
        if self.law_born() is not Tri.TRUE:
            return Tri.FALSE
        return Tri.TRUE if any(K and K <= self.role_units and not (K & self.direct_write)
                               for K in self.minimal_sets()) else Tri.FALSE

    def co_law_born(self):
        """Some minimal sufficient set where the duty's history is an undeletable member
        but must be carried together with A-side or other legal history.

        CoLawBorn ⇒ LawBorn, so the structural conditions are checked first.
        """
        if self.law_born() is not Tri.TRUE:
            return Tri.FALSE
        for K in self.minimal_sets():
            if (K & self.role_units) and not (K <= self.role_units):
                return Tri.TRUE
        return Tri.FALSE

    def a_source(self):
        """Some minimal sufficient set lying wholly on the A side."""
        return Tri.TRUE if any(K and K <= self.a_side for K in self.minimal_sets()) else Tri.FALSE

    def direct_write_source(self):
        """Some minimal sufficient set lying wholly in direct qualification writes."""
        return Tri.TRUE if any(K and K <= self.direct_write
                               for K in self.minimal_sets()) else Tri.FALSE
~~~
