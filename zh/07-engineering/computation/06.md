# 生成计算数理式

## 第一节　目的

### 1.1　结构来源

《生成计算一般式》v1.0（下称第五篇）对承担一步任务 τ\_Φ 的计算宿载 P 及其上一段运行 σ 证明了生成计算的必要结构。在任务侧条件、工作域与生成计算的六条规定 G1—G6 之下：

　　（一）GenComp(P, σ) ⇒ ∃π ∃r \[LegalPart(π) ∧ RunOf(r, P) ∧ N₆(σ, π, r)\]  
　　（二）H2 ∧ GenComp(P, σ) ⇒ ∃π ∃r \[LegalPart(π) ∧ RunOf(r, P) ∧ N₇(σ, π, r)\]

其中 N₆ ≔ Step ∧ Carry ∧ Sed ∧ ¬Intr ∧ Hold ∧ Multi，N₇ ≔ N₆ ∧ Gov；Step 中 Ex 两款以计算执行一般式-H3 为条件，Sed（i）的持久场态一款以《律一般式》v2.5 C0 为条件，Sed（ii）对部署耦合一类以生成计算一般式-H3 为条件；各项的判定携生成计算一般式-H1、计算执行一般式-H1—H3 与计算承担一般式-H1—H3。由其逆否得非生成计算条件：

　　（一′）∀π ∀r \[LegalPart(π) ∧ RunOf(r, P) ⇒ ¬N₆(σ, π, r)\] ⇒ ¬GenComp(P, σ)  
　　（二′）在 H2 下，∀π ∀r \[LegalPart(π) ∧ RunOf(r, P) ⇒ ¬N₇(σ, π, r)\] ⇒ ¬GenComp(P, σ)

七项以自然语言与附录形式陈述给出：步划分由执行界出；动力条件 D 属于 x′ 的某一极小 μ-充分组；D 是合格沉积场的持久场态，有以 D 为作用对象的沉积模式，σ 中 D 的每一改变合于场协议；接续处无边界外的求值；承接分量与 D 在接续处由宿载持有；输出载体与下一步状态载体之间只存只传，承接投影不被改写；各步属同一运行。第五篇以生成计算一般式-H1（扩展状态与步划分的认定、个体化、划分变换下的保持、分界）与生成计算一般式-H2（生成核与 AdmVar 的刻画、ActualHold 向 D ∈ ActArg^μ 的推出、复合 D 的分解、可比性条件）登记了这些项在具体宿载上何时成立所需的形式判据，并以本篇为 H1 各款与 H2 中（a）（b3）（c）（d）形式层的验证文本；H2（b1）（b2）不在本篇证明之列（8.2）。

### 1.2　形式化的对象

记第五篇所立的结构为 S\_Gen。形式系统 M\_Gen 是 S\_Gen 在《计算数理式》v1.0（下称第四篇）的带端口离散局部动力模型之上的形式表示：

　　S\_Gen ⟼ M\_Gen

M\_Gen 以第四篇的宿载模型 𝔐\_P 为底，加上扩展状态的申报、状态载体与输出载体、沉积场及其协议、生成核与合法反事实族，在同一模型上给出三层谓词：

　　原子层　七项 Step、Carry、Sed、¬Intr、Hold、Multi、Gov 在给定步划分 π 与运行 r 上的形式像；  
　　候选层　W₆(π, r)、W₇(π, r)：七项在同一 (π, r) 上的合取；  
　　总判层　V₆、V₇：对申报的候选族取存在。

一切谓词取值于 {1, 0, ⊥}。形式像取 1 只表示该必要结构在所申报模型下成立，由此推不出 GenComp；取 0 只表示在所申报模型下该必要结构的形式像不成立；读到上游结构命题须经第七节的回读规则，并携第八节所列条件。形式判定相对于申报模型成立；模型与实际宿载之间的充分对应，不由这些条件保证。

## 第二节　核心论题

论题一（七项在宿载原语上的判定）　第五篇七项中凡涉及"由谁持有""由谁求值""是否只存只传""是否合于协议""是否同一运行"者，都可以写成第四篇已定义的原语——事件、端口读取、实际链接、实际作用源、末次写入——之上的有限条件。Step 直接调用第四篇的 N\_exec；Multi 所需的"σ 整段属于同一运行"在第四篇字面下没有对象（第四篇的运行个体不跨过锚后的第一次读出，命题 7.21），本篇在第四篇的实例过程图上作过程运行扩展 r^σ，明列为扩展（定义 3.3（2）、生成计算数理式-H6）；Carry、¬Intr、Hold、Sed（iii）由权威载体谱系、边界外事件的求值职责（第四篇定义 3.18）、只存只传的复制路径与协议操作记录给出；Sed（i）（ii）是上游场资格，在 M\_Gen 中作为带来源的输入。

论题二（Gov 的枢纽组刻画）　在有限读入变量集上，D 属于某一极小 μ-充分组，当且仅当存在不含 D 的变量集 C，固定 C 时生成核的合法纤维直径超过申报分辨度，再固定 D 即不超过（定理 7.1）。由此第五篇 H2（b）"ActualHold 推出 D ∈ ActArg^μ"在形式层上改写为一个枢纽组存在命题 Rep\_ε；改写不是证明，Rep\_ε 即第五篇 H2（b）本身，其语义层仍待证。

论题三（申报完整性）　第五篇的任务侧条件要求扩展状态的完整变量域先于 σ 申报，即时量不跨步承接。这一条件在个例上的检验是 DeclEq：从本步启动前切口出发，把未申报的宿载状态换为模板值，比较两种运行的事件发生、时段、写值与读入来源。DeclEq 只取 1 或 ⊥。Step 的形式像取为执行与申报完整性的合取，于是未申报的跨步带入状态在本步重写之前被读入、且其值不同于模板值时，Step 不取确定的 1（引理 7.7）。

论题四（三值总判及其可靠性）　V\_j 对候选族取强 Kleene 存在。V\_j = 1 只认证所申报模型中存在七项（或六项）必要结构的形式见证；V\_j = 0 须候选族的覆盖已经认证，或候选族含由形式合法划分有限生成的候选族 Cand\_gen，且每一候选都有确定的失败分量；候选族为空而其覆盖未经证明者，V\_j 记 ⊥。由 V\_j = 0 读到 ¬GenComp，须经第五篇（一′）（二′），并携定理 7.15 的前提（1）—（5）：第五篇总定理的前提（含任务侧条件与工作域）、第五篇总定理所携的条件、反向表示条件、候选覆盖条件，j = 7 时另有第五篇 H2；候选族含 Cand\_gen 时，候选覆盖条件由命题 7.27 转为所列反向表示各款，这些条款都未证。

四条论题建立在同一申报模型上：论题一给出原子，论题三修饰其中的 Step，论题二刻画其中的 Gov，论题四把原子合成为总判。

## 第三节　基础对象与定义序列

定义按申报层、步与运行层、原语层、七项层、申报完整性层、总判层的依赖次序给出。每条定义末注其所对应的 S\_Gen 结构项；标〔S〕者为 S\_Gen 结构项的形式表示，标〔辅〕者为纯形式辅助对象，在 S\_Gen 中没有对应物，不单独回读（7.1）。凡出自第四篇的对象，记号与含义不变。

### 3.1　申报层

定义 3.1〔S〕（生成申报模型）　生成申报模型  
　　𝔐\_Gen = (𝔐\_P, 𝔇, τ\_Φ, Σ\_s, Car, F, Prot\_F, Pers(F), Op, K, Q, AdmVar, ε\_role, σ, t\_end, Tmpl, ℙ^σ)  
由下列各项组成，除 σ 与 ℙ^σ 外都先于并独立于 σ 申报：  
　（1）𝔐\_P 与 𝔇：第四篇定义 3.1 的宿载模型与申报项（边界 B、入口、读出及读出条件 R\_out、交付协议族、运转条件、启动部分 S）。  
　（2）τ\_Φ：一步任务，运算对象 (x, D, u)，结果 (x′, D′)，以函数（或核）在其运算对象域 Dom\_τ 上的外延为身份（第四篇定义 3.5）。  
　（3）Σ\_s：扩展状态的划分。s = (x, D)，x = (x\_carry, x\_input, x\_inst)：承接分量、输入位、即时量；D 为复合量，变量域 Dom(D) 含 F 的全部持久分量及随之更新的派生量；c 为外生控制构型，不属 x，不属 D。各宿载状态分量归入 x\_carry、x\_input、x\_inst、D、c 中的哪一类，按申报协议逐接续处给出。  
　（4）Car：各步的状态载体 In\_k、输出载体 Out\_k、末态载体 Fin，按分量申报，连同只存只传的复制谱系。分量 v 在时刻 t 的权威载体 Auth(v, t) 是按 Car 的谱系在 t 时承载 v 的权威内容的保持元件。  
　（5）F、Prot\_F、Pers(F)：沉积场、场协议（沉积、退浅、冻结、解冻、角色屏蔽等模式与操作）、持久场态集合。  
　（6）Op：协议操作记录。每一条记录 o 给出时刻、模式、操作类型、读取来源、写入目标（D 的权威载体）与协议所要求的写入值；Op 列出 σ 中 Prot\_F 在申报模式下应当执行的一切 D 更新。  
　（7）K、Q：第 k 步的生成核 K\_k(x′ \| x, D, u; c) 与联合核 Q\_k(x′, D′ \| x, D, u; c)（第四节式(4.2)）。  
　（8）AdmVar：《律数理式》v1.5 定义 3.9′ 的合法反事实族，取于 K\_k 实际读取的输入集 A\_k 上；ε\_role ∈ \[0, 1)：申报分辨度，差异量取全变差 TV。  
　（9）σ = \[s₁, t\_end\]：被谈论的一段实际过程，t\_end 为其申报终点。第四篇定义 3.15 中运行个体的截止时刻在本篇记作 t\_end^{Comp}，与 t\_end 不同。  
　（10）Tmpl：模板表，对每一不属于保留集（定义 3.12（D7-T））的宿载保持元件给出模板值，缺省为其复位值。  
　（11）ℙ^σ：σ 上的过程级外生律〔辅〕，供定义 3.7′ 使用（其支撑定合法对象域，其分布定 QDep）。槽位格 Z^σ 与外生实现空间 Ω^σ 见定义 3.7′（1）。ℙ^σ 由下列两项组成：  
　　（a）U 在 σ 上的联合律 ℙ^{Env,σ}(dU)。U 只实现一次，σ 内各次交付共用。  
　　（b）条件核族 κ\_ζ(dξ\_ζ \| U, h\_ζ)，槽位 ζ ∈ Z^σ 按时间先后取。h\_ζ 为 ζ 之前的运行历史，由运算对象、协议规则与许可执行、U 与此前各槽位的随机成分经式(4.1) 确定。依 h\_ζ 有交付者，核以当时选定的协议 π\_ζ 为下标；无交付者，取占位值 ∅\_ζ 上的单点律。  
　　ℙ^σ\_{d,ρ,ς}(dU, dξ) := ℙ^{Env,σ}(dU) ∏\_{ζ 按时序} κ\_ζ(dξ\_ζ \| U, h\_ζ)。支撑有限（第四篇 (W2)），h\_ζ 是此前各量的确定函数，故此律由（a）（b）唯一确定。  
　　机制相容（本篇新增的限制）：  
　　（c1）对每一有交付的 ζ 与每一可达的 (U, h\_ζ)，κ\_ζ(dξ\_ζ \| U, h\_ζ) = ℙ^{π\_ζ,Env}(dξ \| U\_ζ)。U\_ζ 为该次交付所涉的 U 分量，右端为第四篇对 π\_ζ 申报的联合律在给定 U 下的条件律。由（c1），给定 U\_ζ 与所选协议 π\_ζ，ξ\_ζ 的条件律不再依历史的其余部分；跨次交付随机成分之间的相关，只能经共用的 U 或经历史对协议选择的影响表达，须如此申报。  
　　（c2）对每一在某一合法运算对象、协议规则与许可执行下可达的协议 π 与其所在槽位 ζ，ℙ^{Env,σ}\|\_{U\_ζ} = ℙ^{π,Env}\|\_U。这是协议选择之前的无条件边缘律。同一槽位可达的不同协议申报了不同 U 边缘律者，（c2）不能成立。（c2）成立时两边 U 的支撑相同，（c1）右端在过程级可达的每一 U\_ζ 上都有定义。  
　　（a）（b）未申报，或申报而不合（c1）（c2）者，ℙ^σ 无效。ℙ^σ 无效时，凡依赖该律或其支撑的对象——定义 3.7′ 的合法对象域、可采族、正常运行族 ℱ\_ω、对照运行、见证域 𝒬^σ 与结果分布——都不取得确定的正常资格；依赖这些对象的 VInc^σ、CondF^σ、QDep^σ 及段判据记 ⊥\_M，按 3.6 节的优先序传播（照第四篇式(4.2)"只有边缘律者 μ 记 ⊥\_M"）。不依该律的运行原语与结构判据——r^σ、RunOf、▷^σ、NC、CS 及七项中不经段判据的各款——不受影响。条件独立是常见特例，也须写成申报。  
　　机制相容不是第四篇联合律的等价刻画。协议依历史、从而依 U 动态选取时，"选中 π\_ζ"这一事件下 U\_ζ 的条件律一般不等于 ℙ^{π\_ζ,Env}\|\_U。例：U 均匀二值，U = 0 时选 π₀，U = 1 时选 π₁；选中 π₀ 时 U 的条件律是 0 上的单点律。因此，选择事件条件下的联合律一般不等于第四篇的申报。选择事件与 U\_ζ 独立时（例如协议只依 σ 起点的对象 d 而定，不依其后经 U 或此前随机成分演化的状态），（c1）（c2）给出该次交付 (ξ, U) 的联合律与第四篇的申报相等；协议依交付时的宿载状态而定者，该状态可以依 U，不在此列。  
对应：第五篇任务侧条件（其六）与附录"一、基本对象与类型"。Op 的记录格式、Tmpl、Auth 的谱系取法、ℙ^σ 及其机制相容是形式约定〔辅〕。

### 3.2　步与运行层

定义 3.2〔S〕（覆盖、接续处与合法可个体化）　π = ((s\_k, e\_k))\_{k=1..n} 是 σ 的步划分，s\_k、e\_k 是实例过程图中的事件，In\_{n+1} ≔ Fin。事件 e 的时间区间 I(e) 为第四篇定义 3.2 的极大驱动区间，记 t⁻(e) := min I(e)，t⁺(e) := max I(e)。步界取点值：  
　　τ⁻\_k := t⁻(s\_k)，τ⁺\_k := t⁺(e\_k)；步段 \[τ⁻\_k, τ⁺\_k\]；接续处 J\_k := (τ⁺\_k, τ⁻\_{k+1})（k \< n），末段 J\_n := (τ⁺\_n, t\_end\]。  
　　Cover(σ, π) :⇔ σ = \[s₁, t\_end\] = ⋃\_{k=1}^{n} (\[τ⁻\_k, τ⁺\_k\] ∪ J\_k)，各部分内部两两不交，端点可以重合；并且（I）I(s\_k) ⊆ \[τ⁻\_k, τ⁺\_k\] 且 I(e\_k) ⊆ \[τ⁻\_k, τ⁺\_k\]（k = 1, …, n）；（Id）不同步的启写事件两两不同。  
公共端点上的事件按身份归属：e\_k 为第 k 步的读出事件，s\_{k+1} 为第 k+1 步的启动事件，同一事件只属一步（（Id）；同一步的启动与读出可为同一事件）。（I）把这一归属读作启写事件的整个区间都在本步段内；同一步内 s\_k 与 e\_k 的区间可以重叠，Cover 不约束一步之内事件的先后，后者由 Step 判定。  
持续事件的步界取"启动事件之始至读出事件之终"并要求（I），这是本篇对持续事件的读法，第五篇没有规定，也没有反面规定；它与第五篇 Cover 的对应列入生成计算数理式-H2-Step 的持续事件步界款（8.3）。事件都是瞬时的（t⁻ = t⁺）时，（I）自动成立，本定义即第五篇 Cover 的字面。定义 3.7、3.8 中的"e\_k 时""s\_{k+1} 时"与区间 \[e\_k, s\_{k+1}\]，分别读作 τ⁺\_k 时、τ⁻\_{k+1} 时与 \[τ⁺\_k, τ⁻\_{k+1}\]；定义 3.12 中读出事件 e\_k 的时刻 t\_out 读作 τ⁺\_k；定义 3.7′ 中"与 e\_k 认同的事件之时"读作该事件的 t⁺。这些点值只定数值读取的时刻；端点事件归属哪一步，仍按上文的身份归属，接续区间两端的步内事件不计入接续处内部的改写（定义 3.8）。  
　　LegalPart(π) :⇔ Cover(σ, π) ∧ ∀k：s\_k 的事件属 P 的控制或申报协议（Prot\_F 的操作或 𝔇 中的交付协议），e\_k 为第 k 步结果写入或锁存于 Out\_k 的事件。  
LegalPart 只约束段覆盖与启写事件，不推出各步是一次执行。末段取左开右闭：第五篇"e\_n = t\_end 时末段为空"即此读法；取开区间者，凡 τ⁺\_n \< t\_end 都不覆盖 t\_end。  
对应：第五篇附录"一"中的 Cover、J\_k 与"二"中的 LegalPart；持续事件的步界读法为形式约定〔辅〕。

定义 3.3〔S〕（执行、运行与候选族）  
　（1）步段 \[s\_k, e\_k\] 上的一次执行由第四篇个例层判定：取以 s\_k 的启动部分为锚的运行个体 r\_k（第四篇定义 3.15），N\_exec(r\_k) 按第四篇定义 3.20 求值。执行界出的步划分 π\_Exec 以 σ 中 N\_exec 取 1 的各运行个体的启动与读出为步界；它是 σ 的步划分，须这些运行个体的区间内部两两不交，且后一启动不早于前一读出（第五篇的工作域，端点重合者按定义 3.2 归属）。交叠者不落入工作域，π\_Exec 不构成步划分（流水线交叠执行，8.2 H1（b））。  
　（2）过程运行个体 r^σ（扩展，不属第四篇定义 3.15）。第四篇的运行个体都截至其读出条件在锚后的首次到达；当多步 σ 含同一申报下锚后首次读出之后的实际结点时，第四篇没有一个运行个体能同时容纳整段 σ（命题 7.21）。故 Multi 所需的运行由下列各款在同一 𝔐\_P 与同一实例过程图上给出：  
　　（E1）结点：实例过程图中区间与 \[s₁, t\_end\] 相交的一切事件与保持区间，各取其在 \[s₁, t\_end^σ\] 上的区段。结点 v 在区间 J 上的区段 v\|\_J 是同一结点限于 I(v) ∩ J 的部分（I(v) ∩ J ≠ ∅ 时）；跨 s₁ 或跨 t\_end^σ 的结点只含其区间内的区段。  
　　（E2）截止：t\_end^σ := min(t\_end, 中止之时)。σ 内各步的读出不截止 r^σ。

### 3.3　原语层

定义 3.4〔辅〕（读取、持有、链接、照搬、来源）　以下各项都由第四篇的宿载模型、事件与动力（第四篇式(4.1)）求得，不作为判定器的输入：

　　条件读取 CRd(i, t)：G\_i 在时步 t 求值时经条件端取用的保持元件之集；部件自身状态经自反馈进入 G\_i 者计入。由式(4.1)，E\_i(t) = G\_i(·) 在每一时步求值，故不论 E\_i(t) 取 1 还是 0，CRd(i, t) 在每一时步都有定义；只在 i 的使能端处在使能范围之外的时步，G\_i 不取用条件端，CRd(i, t) = ∅。

一切谓词取值于 {1, 0, ⊥}；⊥ 按来源分四层 ⊥\_M、⊥\_D、⊥\_J、⊥\_C，联结取强 Kleene，条件分款与信息序都承继第四篇 3.7（第四篇以 ⊑ 记信息序；本篇的 ⊑ 只记定义 3.3（2）的区段包含，信息序不另用记号）。第三节各定义的分款按下列次序适用：有确定失败见证者取 0，不因其余数据不全改记 ⊥；无 0 款而有 ⊥ 款适用者取 ⊥，数款同时适用时按 ⊥\_D、⊥\_C、⊥\_J、⊥\_M 的次序取第一个；各款都不适用者取 1。以":⇔"给出而未另列分款的谓词（Cover、LegalPart、RunOf、NoImp\_k、StartSrc、Link\_I 等），右端按强 Kleene 求值；右端有确定值者取该值；右端所需的事件、端口、值或归属在模型中不全者记 ⊥\_M，申报不足以确定者记 ⊥\_D，这两种情形都不记 0。有限族上的存在取：有一项为 1 者为 1；族的覆盖已认证且各项都为 0 者为 0；其余为 ⊥。总判 V\_j 另有以生成候选族给出形式穷尽的 0 款，按定义 3.13。凡作为输入的证书（cert\_FQ、cert\_SD、AdmVar 的覆盖证书、CovCert），须附来源标识、所依申报版本与覆盖范围；来源缺失或证据冲突者记 ⊥\_M。

### 3.7　总判层

定义 3.13〔S/辅〕（候选判值与总判）  
　　W₆(π, r) := Step(σ, π) ∧ Carry(σ, π) ∧ Sed(σ) ∧ ¬Intr(σ, π, r) ∧ Hold(σ, π) ∧ Multi(σ, π, r)

对应：W₆、W₇ 是第五篇 N₆、N₇ 在同一 (π, r) 上的形式像〔S〕；Cand、CovCert 与 V\_j 的存在判值是〔辅〕。

## 第四节　方程

式(4.1)　局部动力  
承继第四篇式(4.1)：E\_i(t) = G\_i(c\_i(t), en\_i(t), U\_i(t))；E\_i(t) = 1 时 X\_i(t⁺) = F\_i(x\_i(t), U\_i(t))，否则 X\_i(t⁺) = H\_i(X\_i(t), U\_i(t); Δ)，Δ 为第四篇的时步长，与式(4.3) 的 Δ\_k(C) 无关。M\_Gen 的一切谓词都是这一动力与申报项的函数；DeclEq 的模板运行是同一动力在 ℋ\_k 上换取初值后的运行。

式(4.2)　步核  
　Q\_k(x′, D′ \| x, D, u; c) ≥ 0，Σ\_{x′, D′} Q\_k(x′, D′ \| x, D, u; c) = 1，  
　K\_k(x′ \| x, D, u; c) = Σ\_{D′} Q\_k(x′, D′ \| x, D, u; c)（连续域取积分）。  
在 𝔐\_P 上，Q\_k 是第四篇式(4.2) 对第 k 步的读出取 (x′, D′) 投影所得的结果分布，K\_k 是其 x′ 边缘；确定型任务 Q\_k = δ\_{Φ(x, D, u; c)}。Φ 的申报不显含 c 者，c 只作为该步模式的固定条件，不成为 D 以外的承担自变量。D′ 的实际写入与 Prot\_F 的权威执行另由式(4.4) 与 Sed（iii）对应；由 K\_k 或 Q\_k 的支撑推不出 Sed（iii）。

式(4.3)　μ-充分与承担自变量  
　Var\_k(C) = {v ∈ AdmVar\_k：v\|\_C = ν\_k\|\_C}，Δ\_k(C) = sup\_{v, w ∈ Var\_k(C)} TV(K\_k(· \| v), K\_k(· \| w))，  
　Suf\_k(C) :⇔ Δ\_k(C) ≤ ε\_role，ActArg^μ\_k = ⋃{C：C 是极小的 Suf\_k 集}。  
单调性：C ⊆ C′ ⇒ Var\_k(C′) ⊆ Var\_k(C) ⇒ Δ\_k(C′) ≤ Δ\_k(C)，故 Suf\_k 对包含向上封闭；A\_k 有限时极小 Suf\_k 集存在（A\_k 本身满足 Suf\_k：Var\_k(A\_k) = {ν\_k}，ν\_k ∈ AdmVar\_k）。

式(4.4)　协议更新  
对 o ∈ Op（m(o) 为 o 所记的模式），D 在 o 之后的取值 = Prot\_F^{m(o)}(o)(D 在 o 之前的取值)；G\_k := J\_k 内各 o 依时序的复合。Sed（iii）要求 Op 与 Auth(D, ·) 上的写入事件一一对应且值合于此式；Hold（b）以 G\_k 联系 e\_k 时 Out\_k 所持的内容与 s\_{k+1} 时 In\_{k+1} 所持的内容。

式(4.5)　候选判值与总判  
　W₆ = Step ∧ Carry ∧ Sed ∧ ¬Intr ∧ Hold ∧ Multi，W₇ = W₆ ∧ Gov（¬Intr、Multi 在 r^σ 上），  
　V\_j = ⋁\_{(π, r) ∈ Cand} W\_j(π, r)（存在按 3.6 节，族的覆盖由 CovCert 认定，或由 Cand ⊇ Cand\_gen 给出形式穷尽，定义 3.13）。

式(4.1)(4.2) 给出动力与核；式(4.3) 在核上给出 Gov；式(4.4) 在协议记录上给出 Sed（iii）与 Hold（b）的值条件；式(4.5) 把原子合成为总判。

M\_Gen 以第四篇的 M\_Comp 为底层，不重定义其对象。耦合项三处：Step\_k 的 N\_exec 分量（第四篇定义 3.20，经 SolveExec 求得）；Multi 与 ¬Intr 所用的过程运行个体 r^σ，是在第四篇实例过程图上的扩展（定义 3.3（2）），其中止、拼接与撤去语义照第四篇定义 3.15、3.16，锚类型、截止款、可达款与区段读法不承继；¬Intr 的段判据（第四篇定义 3.18，以 τ\_Φ 的结果函数分量或 Prot\_F 的更新函数代替 f），在 r^σ 上按定义 3.7′ 取过程级形式。M\_Gen 的原语（定义 3.4）除 E6 三项外都由第四篇的原语导出，不改其含义。凡调用第四篇谓词的结论，连同该谓词在第四篇 8.2 所携的条件（计算数理式-H1 锚指派、计算数理式-H4 冻结撤去所得的驱动为第三篇意义的实际原因等）一并承继。

### 6.2　与《律数理式》v1.5

AdmVar、μ-充分与 ActArg^μ 取自其定义 3.9′、3.10′；在有限读入变量集上，定义 3.11 与该定义一致：候选集为生成核实际读取的输入集，μ-充分以合法联合赋值之间生成分布的全变差比较，承担自变量为某一极小 μ-充分组的成员。确定型任务下，由其定理 3.10′.1，ActArg^μ 与确定型 ActArg 相同。《律数理式》的正向回读与反向表示（H\_ReadD、H\_RepD 等）关于律的 DynamicRole，不是 Gov 的回读桥；两者之间没有耦合项。

### 6.3　与《场数理式》v2.6 及上游场论

F、Pers(F) 取自场篇；场协议的许可操作取自《律运行基底构造式》v1.2（Mode\_exo、Mode\_endo、Freeze、Thaw、IdleStep、do(Mask)、do(Avail)），其中 Mask 与 Avail 属外生控制 c。cert\_FQ 的来源是 FieldQualified(F) 的上游成立式（《沉积场论》v1.2、《最小沉积场构造式》v1.2）在所申报场规格上的适用。

### 6.4　与《律动力数理式》v1.0

其 3.7 的实际路线投影给出 Path(σ)；4.3 的沉积写入闸门规定只有实际经过者进入沉积。在沉积开启的模式下，Op 中的 D 更新记录以 4.3 的闸门为准；被计算评价而未实际经过的假想分支不入 Op，也不入 W\_D。

### 6.5　与《概率数理式》v1.0（概率组式第二）

AdmVar\_k 的覆盖证书移用其 M11 的 Sound\_Adm 与 Cover\_Adm。上游二者定义在率承担的诊断变化族 AdmVar\_ρ(ν) 上，以保持 C、Γ\_r、V\_P、{D\_i}、g\_C 与冻结的生成图式为条件；本篇的读法是移用，不是原样承继：以 AdmVar\_k 代 AdmVar\_ρ(ν)，以 K\_k 的读入集 A\_k 代 A\_ρ^gen(ν)，保持对象改为申报的扩展状态划分 Σ\_s、场协议 Prot\_F 与申报模式、该步的生成核 K\_k 与外生控制构型 c。Sound\_Adm = 1 指 AdmVar\_k 中每一联合取值都由场协议许可并保持上列对象；Cover\_Adm = 1 指在上列对象保持不变时，场协议所许可、能改变 A\_k 中某一读入取值的合法联合变化都被 AdmVar\_k 收入，或由 ε\_role 下等价的代表覆盖。二者都为 1 时，定义 3.11 的极小组可以给出确定值；任一项不可判或为 0 时，依赖它的 Gov 记 ⊥，不记 0（与上游"为 0 或不可判时记 ⊥"同向）。这一移用是否忠实，随生成计算数理式-H1-Gov、H2-Gov 承继。

### 7.2　Gov 的枢纽组刻画

定理 7.1（枢纽组）　设第 k 步的读入变量集 A\_k 有限，D ∈ A\_k，ν\_k ∈ AdmVar\_k，ε\_role ∈ \[0, 1)。则  
　　D ∈ ActArg^μ\_k(x′\_k) ⇔ ∃C ⊆ A\_k ∖ {D}：Δ\_k(C) \> ε\_role ∧ Δ\_k(C ∪ {D}) ≤ ε\_role。  
证明：（⇒）设 D 属于极小 μ-充分组 M。取 C = M ∖ {D}。M 极小，故其真子集 C 不是 μ-充分的，Δ\_k(C) \> ε\_role；C ∪ {D} = M 是 μ-充分的，Δ\_k(C ∪ {D}) ≤ ε\_role。（⇐）设 C 如右端。C ∪ {D} 是 μ-充分的；A\_k 有限，其 μ-充分子集中有基数最小者 M ⊆ C ∪ {D}，M 是极小 μ-充分组。若 D ∉ M，则 M ⊆ C；由式(4.3) 的单调性，Δ\_k(C) ≤ Δ\_k(M) ≤ ε\_role，与 Δ\_k(C) \> ε\_role 矛盾。故 D ∈ M，D ∈ ActArg^μ\_k(x′\_k)。∎  
A\_k 无限时本定理不主张；极小组的存在或可求性不能保证者，Gov 记 ⊥\_C（定义 3.11）。

推论 7.2（可比性）　若存在 v, w ∈ AdmVar\_k，二者在 A\_k ∖ {D} 上都与 ν\_k 一致，且 TV(K\_k(· \| v), K\_k(· \| w)) \> ε\_role，则 D ∈ ActArg^μ\_k(x′\_k)。  
证明：取 C = A\_k ∖ {D}。v, w ∈ Var\_k(C)，故 Δ\_k(C) \> ε\_role；C ∪ {D} = A\_k，Var\_k(A\_k) = {ν\_k}，Δ\_k(A\_k) = 0 ≤ ε\_role。由定理 7.1 得结论。∎  
这是第五篇可比性引理的形式像：反事实只变 D，其余读入与 c 固定于该步实际之值。

命题 7.3（第五篇 H2（b）的形式层）　记  
　　Rep\_ε :⇔ 对 σ 中每一步 k，若 D 在 x′\_k 的生成上具有 ActualHold 所说的职责，则存在 C ⊆ A\_k ∖ {D} 使 Δ\_k(C) \> ε\_role 且 Δ\_k(C ∪ {D}) ≤ ε\_role。  
在 A\_k 有限，且 Gov 的正向回读与反向表示条件（生成计算数理式-H1-Gov、H2-Gov）成立时，第五篇 H2（b）"ActualHold 在 x′ 的生成上推出 D ∈ ActArg^μ(x′)"与 Rep\_ε 等价。  
证明：在所设回读条件下，第五篇的 D ∈ ActArg^μ(x′\_k) 与定义 3.11 的同名谓词同值；由定理 7.1，后者等价于枢纽组存在。代入 H2（b）的后件即得。∎  
Rep\_ε 的前件含 ActualHold，后者在《律必然式》v1.3 中是中间职责名称，不承担脱离律的职责体系的独立真值；Rep\_ε 即第五篇 H2（b）本身的枢纽组改写，其真值与 H2（b）相同，命题 7.3 不证明它。命题 7.3 给出的是：一旦 H2（b）在某一宿载上得到判定，其判定对象是一个可在有限申报模型上检验的枢纽组存在命题。按第五篇第四节的分段，Rep\_ε 的前件到后件经（b1）（b2）得职责申报下的枢纽组，再经（b3）转为本步申报（K\_k、AdmVar\_k、ε\_role）下的枢纽组；命题 7.30 的 C 即两级共用的枢纽组，推论 7.2 是不经职责申报的一条路线（7.9）。故 Rep\_ε 的真值至少依赖（b1）（b2），在命题 7.30 或推论 7.2 的条件不成立处还依赖（b3）。

例 7.4（正分辨度下的弱作用）　A\_k = {D}，D ∈ {0, 1}，ν\_k(D) = 1，AdmVar\_k = {0, 1}，K\_k(x′ = 1 \| D = d) = 1/2 + d/20，ε\_role = 1/10。Δ\_k(∅) = 1/20 ≤ ε\_role，空集是 μ-充分的，ActArg^μ\_k = ∅，D ∉ ActArg^μ\_k，Gov = 0。D 被读入且改变 x′ 的分布，而在分辨度 1/10 下不承担。由此，"D 被读入并改变生成分布 ⇒ D ∈ ActArg^μ"在 ε\_role \> 0 时不成立。这一例是否构成 ActualHold 意义下的反例，取决于申报分辨度是否忠实于上游职责（Rep\_ε），不由本例判定。

### 7.3　抽象生成核的良定

定理 7.6　设宿载微态集 𝔐 有限，α：𝔐 → 𝒮 为到申报类型状态的读出，微态上一步的输出核为 κ(· \| m)。  
　（1）抽象核 K(· \| s) := κ(· \| m)（α(m) = s）在 α 之像上良定，当且仅当对每一 s，α⁻¹(s) 中各微态的输出核相同。  
　（2）若要求 n 步输出的分布由抽象状态决定，充分条件是：对每一 s，α⁻¹(s) 中各微态的联合核 (α(m′), y) 相同，且微态动力是马尔可夫的、控制历史已冻结。只要求输出核相同，不足以保证两步以上的分布由抽象状态决定。  
证明：（1）K 是 𝒮 上的映射，当且仅当它在每一纤维上取单一值。（2）充分性：联合核在纤维上相同，则 (α(m\_{t+1}), y\_t) 的条件分布只依 α(m\_t)；由马尔可夫性逐步复合，n 步输出分布只依 α(m₀)。不足性的例子：𝔐 = {a, b, a′, b′}，α(a) = α(b) = s，α(a′) = s₁，α(b′) = s₂；a、b 一步输出都为 0，分别转移到 a′、b′；a′ 输出 0，b′ 输出 1。一步输出核在纤维 {a, b} 上相同，两步输出的分布却随纤维中的微态而变。∎  
定理 7.6 给出 K\_k 在类型状态上可以作为单值核使用的条件；它不证明某一宿载满足这些条件。

### 7.4　申报完整性与 Step

引理 7.7（写前读）　设 𝔐\_P 满足 (WG1) 并通过 5.5 的核查（含第四篇 5.5 的（i）（ii）），动力确定，各部件的 G、F、H 不依赖模型之外的隐藏状态；Ret\_k、Tmpl 已申报，合法赋值域已全部枚举。对第 k 步：  
　（i）若对每一合法赋值 ω，在 ω 下的实际运行中，每一 h ∈ ℋ\_k 或切口处实际值等于 Tmpl(h)，或在 \[t\_S, t\_out\] 内不出现于任何读取事实与使能来源，或在 \[t\_S, t\_out\] 内首次出现于某一读取事实 Rd(i, t) 或使能来源 ERd(i, t)（定义 3.4（1））之前已被本运行内的事件重写，则 DeclEq\_k = 1。  
　（ii）若存在合法赋值 ω 与 h ∈ ℋ\_k，h 的切口处实际值不等于 Tmpl(h)，并且在 ω 下的实际运行中、在本运行内对它的任何重写之前，h 已出现于某一读取事实 Rd(i, t)，t ∈ \[t\_S, t\_out\]（条件读取不要求 E\_i(t) = 1），则 DeclEq\_k = ⊥（差异见证，⊥\_D）。  
证明：固定合法赋值 ω，以下所说的两次运行都在 ω 下。记 Ξ := {h ∈ ℋ\_k：切口处实际值 ≠ Tmpl(h)}，Ret\_k 的元件不在其中。对时刻 t，记 Υ\_t 为 Ξ 中在实际运行内、t 之前尚未被事件重写的元件之集；在（i）的证明中，"出现于"兼指读取事实与使能来源；记 Diff\_t 为 t 时两次运行中内容不同的保持元件之集。状态的改变分两支：E\_i(t) = 1 者，h\_i 的内容由 F\_i 写入（事件写入）；E\_i(t) = 0 者，h\_i 按 H\_i 演化，H\_i 只依 h\_i 自身的状态与外生取值（第四篇式(4.1)；定义 3.4（1）末段），两次运行取同一外生实现。H\_i 不必为恒等。  
（i）对 t 归纳，归纳假设为：至 t 前两次运行四轴相同；Diff\_t ⊆ Υ\_t；Υ\_t 的元件此前都未出现于任何读取事实。t 为切口时 Diff = Ξ = Υ，假设成立。由（i）的条件对所固定的 ω 成立，Υ\_t 与 ⋃\_i \[Rd(i, t) ∪ ERd(i, t)\] 不交，Diff\_t 亦然。于是：每一 G\_i 在 t 的条件自变量（CRd(i, t)）与使能自变量（ERd(i, t)）在两次运行中取同一值，外生取值相同，E\_i(t) 相同；E\_i(t) = 1 者，F\_i 的内容自变量（FRd(i, t)）取同一值，写入内容相同，h\_i 的后继两边同值；E\_i(t) = 0 者，h\_i ∉ Diff\_t 时后继两边同值，h\_i ∈ Diff\_t 时后继或仍不同，或经 H\_i 合为同值。故 Diff\_{t+1} 含于 Diff\_t 中 t 时未被写入的元件之集，从而含于 Υ\_{t+1}：H 的演化能消去差异，不能产生差异；只有事件写入使元件离开 Υ。t 时被读取的元件 j 不在 Υ\_t 中：j 若在本运行内已被重写，两次运行中的来源是同一事件（事件相同，按第四篇定义 3.2 认同）；j 若未被重写，则 j ∉ Ξ，来源都是切口持有值且切口处取值相同。第（d）轴相同。归纳推进至 t\_out，四轴全同。（i）的条件对每一 ω 成立，ω 任取，故对每一 ω 四轴全同，DeclEq\_k = 1。  
（ii）取（ii）所给的 ω，在其下的实际运行中取最早的时刻 t\*，使某一 h ∈ Υ\_{t\*} 出现于某一 Rd(i, t\*)；（ii）的条件保证 t\* 存在。若 t\* 之前两次运行的四轴已有差异（例如 Υ 的某一元件经使能来源改变了某一部件的事件），此 ω 下四轴不全同，DeclEq\_k = ⊥，结论已得。否则至 t\* 前两次运行四轴相同，事件相同，h 在两次运行中都未被重写。t\* 时该读取在两次运行中的来源都是 h 的切口持有值（其间 H\_h 的演化不改变来源，定义 3.4（6）），切口处的取值一为实际值、一为 Tmpl(h)，二者不同；按 D7-d，第（d）轴有差异，不论 H\_h 是否已使读取时刻的内容相同。此 ω 下四轴不全同，按定义 3.12 DeclEq\_k = ⊥。∎  
（i）的条件是对全部合法赋值的全称条件，与定义 3.12 中"对每一合法赋值 ω 四轴都相同"对齐；（ii）只需一个 ω。只在实际所取的赋值上满足"先重写后读取"不足以得 1：例如未申报的 h 切口实际值 1、模板值 0，申报输入 x ∈ {0, 1}，第一拍 x = 0 时 h 被写成 0，第二拍 y 读取 h；实际赋值 x = 0 下 h 先重写后读取，而在合法赋值 x = 1 下 h 未被重写即被读取，两次读取的来源是取值不同的切口持有值，由（ii）DeclEq\_k = ⊥。在不涉使能来源时，（i）（ii）的条件互为否定。另有一种情形两款都不适用：某一 h ∈ Ξ 在重写之前只经使能来源被取用、不出现于读取事实。此时 DeclEq\_k 按定义 3.12 直接计算：两种切口值使某一部件的使能端处于范围内外之别、从而改变事件者，第（a）轴有差异，取 ⊥；二者都在使能范围之内或都在其外、事件不变者，D7-d 不比较使能来源，可以取 1。例：未申报的电源门控寄存器 PG 切口实际值 1、复位值 0，PG 经使能端门控功能单元 FU；模板运行中 FU 不能写入，事件不同，DeclEq\_k = ⊥，而 PG 不出现于任何读取事实。  
（ii）只给出 DeclEq\_k = ⊥，从而 Step\_k ∈ {0, ⊥}；它不推出 Step\_k = 0，也不推出 N\_exec(r\_k) = 0。引理 7.7（ii）对一切在重写前被读取、值不同于模板的未申报状态都给出 ⊥，不论该状态是否承载跨步内容；与执行无关的辅助状态也会使 DeclEq\_k = ⊥。这一严格性使 DeclEq 不出假 1，代价是 Step 的反向表示（生成计算数理式-H2-Step）不能由定义推出，较弱的可靠判据列为未解问题（8.4（3））。  
切口差异在读取前经 H 合流的情形属于这一严格性。例：未申报元件 h 的切口实际值 1、模板值 0，E\_h = 0 且 H\_h(h) = 0，下一时步 y 经 F\_y 读取 h；读取时两次运行中 h 的内容都是 0，写入相同，但两次读取的来源分别是取值 1 与取值 0 的切口持有值，按 D7-d 第（d）轴有差异，DeclEq\_k = ⊥。这里 h 的切口内容没有进入本步，⊥ 是保守的，不是假 1，也不是否定；它与上段所说的辅助状态同属 8.4（3）的较弱判据所要处理的情形。若改按读取时刻的内容比较第（d）轴，这一情形可得 1；那是另一判据，其无假 1 性须另证（8.4（3））。

### 7.7　语义对应

命题 7.19（同一运行条件）　记  
　　SameRun(σ, π, r) := RunOf(r, P) ∧ ⋀\_k \[Seg\_k ⊑ r\] ∧ \[W\_D ⊑ r\] ∧ ⋀\_k \[J\_k ⊑ r\]，r 取 r^σ，  
其中 W\_D 与 J\_k 分别指 σ 内写入 Auth(D, ·) 的事件结点之集与区间与 J\_k 相交的结点在 J\_k 上的区段之集。即各步执行、σ 内 D 的一切权威写入与各接续处的承接都属于 P 的同一实例上的同一过程运行 r^σ。若 W₆(π, r^σ) = 1，则 SameRun(σ, π, r^σ)，且各接续处 x\_carry 与 D 的权威载体都在 B 内。  
证明：Multi = 1 给出 RunOf(r^σ, P) 与 Seg\_k ⊑ r^σ。RunOf 给出 r^σ ∈ Run^ok^σ，且 σ 的全部结点（实例过程图中区间与 σ 相交的结点在 \[s₁, t\_end\] 上的区段）都属 r^σ（E7）。W\_D 的事件在 σ 内（定义 3.10（iii）），J\_k ⊆ σ，故 W\_D ⊑ r^σ，J\_k ⊑ r^σ；后者包括 x\_carry 与 D 的权威载体在 J\_k 内的保持区间与迁移事件。r^σ ∈ Run^ok^σ 保证这些结点之间没有中止，且其拼接边都在 B 内。Carry = 1 给出各 Owner\_P = 1，即 J\_k 内权威载体在 B 内。∎  
由此，计算执行、场态变换与历史承接属于同一运行，是 W₆ = 1 的推论，其形式条件即 SameRun。两种情形使 W₆ ≠ 1：（1）影子计算——对场态作对应运算而结果没有落到权威载体（例 7.13：Sed^{(iii)} = 0）；（2）跨实例拼证——执行见证与场态见证取自不同实例：场态写入不在本实例的 Auth(D, ·) 上，Op 的记录在 W\_D 中没有对应写入，Sed^{(iii)} = 0；或 σ 不整段属于本实例上的一次运行，RunOf = 0。

### 7.8　过程运行与生成候选族

命题 7.21（第四篇字面下没有跨两次读出的运行个体）　设宿载按第四篇申报为 𝔐\_P，启动部分 S ≠ ∅，读出条件为 𝔇 的 R\_out。则以该申报构造的第四篇定义 3.15 的任一运行个体，其结点不跨过 R\_out 在锚后的首次到达。故当多步 σ 含 𝔐\_P 下锚后首次读出之后的实际结点时，以 𝔐\_P 构造的第四篇运行个体没有一个能同时容纳整段 σ。

引理 7.23（步段包含）　设 π 满足 Cover，且每一 e\_k 是实例过程图中实际存在的事件结点。则 Seg\_k ⊑ r^σ ⇔ t⁺(e\_k) ≤ t\_end^σ。  
证明：（⇐）由 Cover，s₁ ≤ τ⁻\_k；又 τ⁺\_k = t⁺(e\_k) ≤ t\_end^σ，故 \[τ⁻\_k, τ⁺\_k\] ⊆ \[s₁, t\_end^σ\]。Seg\_k 的任一区段 v\|\_{\[τ⁻\_k, τ⁺\_k\]} 非空，v 的区间与 \[s₁, t\_end^σ\] 相交，v\|\_{\[s₁, t\_end^σ\]} 是 r^σ 的结点区段（E1），且包含之。（⇒）设 t⁺(e\_k) \> t\_end^σ。由 Cover 的（I），I(e\_k) ⊆ \[τ⁻\_k, τ⁺\_k\]，e\_k 的步段区段是整个 e\_k，含时刻 t⁺(e\_k)；r^σ 中 e\_k 的区段为 e\_k\|\_{\[s₁, t\_end^σ\]}，不含 t⁺(e\_k)。故 Seg\_k ⊑ r^σ 不成立。∎  
中止恰在 t⁺(e\_k) 时，t\_end^σ = t⁺(e\_k)，右端成立（E3：中止时刻所在的区段属 r^σ）。e\_k 无实际事件结点与之对应者，LegalPart 中"e\_k 为第 k 步结果写入或锁存于 Out\_k 的事件"一款不成立或不可判，π ∉ Π\_gen′ 或 LegalPart = ⊥（命题 7.25）；后者 Multi 依强 Kleene 取 ⊥。

引理 7.24（Cover 的点值刻画）　设 π 的启写事件取自实例过程图。则  
　　Cover(σ, π) ⇔ τ⁻\_1 = s₁ ∧ τ⁻\_1 ≤ τ⁺\_1 ≤ τ⁻\_2 ≤ τ⁺\_2 ≤ … ≤ τ⁺\_n ≤ t\_end ∧ 各步满足（I）∧（Id）。  
证明：点值部分。（⇐）\[τ⁻\_1, τ⁺\_1\]、J\_1 = (τ⁺\_1, τ⁻\_2)、…、\[τ⁻\_n, τ⁺\_n\]、J\_n = (τ⁺\_n, t\_end\] 依次首尾相接，其并为 \[s₁, t\_end\]；闭段之间只在 τ⁺\_k = τ⁻\_{k+1} 处共端点，开段 J\_k 与他段不交。（⇒）若某 τ⁺\_k \< τ⁻\_k，\[τ⁻\_k, τ⁺\_k\] 不成区间；若某 τ⁻\_{k+1} \< τ⁺\_k，则第 k 与第 k+1 步段的内部相交；若 τ⁺\_n \> t\_end，并超出 σ；若 τ⁻\_1 ≠ s₁，σ 的起点不被覆盖或并超出 σ。（I）（Id）是定义 3.2 中与点值部分独立的合取项。∎  
Cover 只依时刻、区间与事件身份，三者在模型中确定，故 Cover ∈ {0, 1}，不取 ⊥。事件都是瞬时的时，（I）自动成立，本引理即以事件时刻写出的 Cover 刻画。

命题 7.25（形式合法划分的有限穷尽）　设 (WG1)。候选划分取统一的类型域：n ≥ 1 步，各步启写事件取自 σ 内与 t\_end 之后的有限事件集 E\_σ。LegalPart 按定义 3.2，其 Cover 含（I）与身份互异（Id）。则：  
　（1）Π\_gen′ ⊆ Π\_pre′，二者都有限：由（Id），不同步的启动事件两两不同，n ≤ \|E\_σ\|，\|Π\_pre′\| ≤ Σ\_{n ≤ \|E\_σ\|} \|E\_σ\|^{2n}。  
　（2）对上述类型域中的任一 π：LegalPart(π) ≠ 0 ⇔ π ∈ Π\_gen′。  
　（3）Π\_gen′ 可由下列算法有限步算出：自 σ 的起点递归，第 k 层在未用事件中取 s 与 e：s 满足"属 P 的控制或申报协议"不取 0，t⁻(s) ≥ τ⁺\_{k−1}（k = 1 时 t⁻(s) = s₁）；e 满足"为第 k 步结果写入或锁存于 Out\_k 的事件"不取 0，t⁻(e) ≥ t⁻(s)、t⁺(s) ≤ t⁺(e)（即（I）），t⁺(e) ≤ t\_end。每取得一对即记入 Π\_gen′ 并进入下一层。Out\_k 按步申报，写出资格随步号而异。  
证明：（2）（⇒）LegalPart ≠ 0 时 Cover ≠ 0，即 Cover = 1，由引理 7.24 点值次序、（I）与（Id）成立；各启写归属不为 0（强 Kleene 合取有 0 则为 0）。故 π ∈ Π\_pre′ 且属 Π\_gen′。（⇐）π ∈ Π\_gen′ 时由引理 7.24 Cover = 1，各归属不为 0，强 Kleene 合取不为 0。（1）由身份互异与 E\_σ 有限；（3）由（1）与引理 7.24 的逐层检验。∎  
LegalPart = ⊥ 的划分保留在 Π\_gen′ 中，其后续判值依 3.6 节照常取 ⊥。本命题只在形式定义之内成立；第五篇意义的合法划分是否落入 Π\_gen′，由 H2-Step 的 LegalPart 款与持续事件步界款承担（8.3）。

引理 7.26（候选运行的作用路径）　固定申报模型与 (σ, π)。Step、Carry、Sed、Hold、Gov 的自变量不含候选运行 r（Step 所用的 r\_k 是由 π 的启动点定的启动锚个体，不是候选运行）；Multi 经 RunOf 与 Seg\_k ⊑ r 依赖 r，StartSrc 不依 r；¬Intr 经 ▷^σ 与定义 3.7′ 依赖 r。故 W\_j(π, r) 对 r 的依赖只经 Multi 与 ¬Intr。  
证明：逐条读定义 3.5—3.11 与 3.7′ 的自变量。∎

命题 7.27（生成候选族的条件覆盖）　设 Cand ⊇ Cand\_gen。若第五篇意义的 (π\*, r\*) 满足 LegalPart(π\*) ∧ RunOf(r\*, P) ∧ N\_j(σ, π\*, r\*)，且下列条件成立：  
　（a）H2-Step，含 LegalPart 款与持续事件步界款；  
　（b）生成计算数理式-H6 的反向一侧，与 H2-Multi 其余各款；  
　（c）H2-¬Intr，含过程运行款；  
　（d）H2-Carry、H2-Sed、H2-Hold，j = 7 时另加 H2-Gov；  
则 (π\*, r^σ) ∈ Cand\_gen 且 W\_j(π\*, r^σ) = 1。  
证明：由（a），形式 LegalPart(π\*) = 1，Step(σ, π\*) = 1；由命题 7.25（2），π\* ∈ Π\_gen′，故 (π\*, r^σ) ∈ Cand\_gen。由（b），Multi(σ, π\*, r^σ) = 1。第五篇的 ¬Intr(σ, π\*) 是 N\_j 的合取项，由（c），¬Intr(σ, π\*, r^σ) = 1。由（d），Carry、Sed、Hold（与 Gov）在 (σ, π\*) 上取 1；由引理 7.26，它们不依 r。各项合取，W\_j(π\*, r^σ) = 1。∎  
强度：（a）—（d）都是未证的反向表示条件。本命题是条件定理：只在这些条件确定成立时，W\_j(π\*, r^σ) = 1 才由它推出；它不主张求解程序在某一具体模型上能输出该值——定义 3.7′ 在申报不足、条件支撑或对照运行不能唯一确定、非容差类无判定程序之处取 ⊥。不依这些条件的候选覆盖（H3 的无条件形式）未证。对不含 Cand\_gen 的申报 Cand，H3 照旧作定理 7.15 的独立前提。

命题 7.28（类型补全的极值）　在定义 3.7′（5）中，对每一 d，μ(G\_d) 在 Comp\_type(μ̃^d) 上的下确界与上确界分别为 L\_d^{min} 与 L\_d^{max}，且都可达。  
证明：Comp\_type 中各含 ↑ 原子的质量独立分配于其可补值上；μ(G\_d) 是已知合格质量 L\_d 加上各原子分配到合格值上的质量，对分配是线性的。线性函数在乘积单纯形上的极值在顶点取得，即每一原子整质量取某一补值：取不合格补值可行者计入下界时取 0，否则（只可合格）取全质量，得 L\_d^{min}；取合格补值可行者计入上界时取全质量，得 L\_d^{max}。支撑有限，极值可达。∎  
不同 d 是不同的运行，其 ↑ 原子各自补全，没有跨对象约束，故容差类的整族判据逐对象取极值。本命题只给出 Comp\_type 的内部极值，不给出与物理可能补全的对应。

### 7.9　承担资格的分辨度窗口与申报间转移

第五篇 H2（b）所需的一向分三段（第五篇第四节，记（b1）（b2）（b3））：（b1）ActualHold 推出 DynamicRole（第五篇 G2 的读法问题）；（b2）DynamicRole 推出职责级形式判据，即职责所在生成节点上 D 的某一分量在职责的申报 (A, AdmVar^r, ν, K^r, ε^r) 下属 ActArg^{μ,r}（《律数理式》H\_RepD）；（b3）由职责的申报转到本步的申报 (A, AdmVar\_k, ν, K\_k, ε\_k)。（b3）是两组申报之间的数学问题，由命题 7.30 与推论 7.2 给出条件；（b1）（b2）未证，仍是第五篇 H2（b）的待证部分。由分量到复合 D 一步用命题 7.5′ 的（⇐）向，不需（Q0）。

命题 7.29（分辨度窗口）　设 A 有限，D ∈ A，ν ∈ AdmVar。则 D ∈ ActArg^μ(ε) ⇔ ε ∈ ⋃\_{C ⊆ A∖{D}} \[Δ(C ∪ {D}), Δ(C))。  
证明：对固定的 C，定理 7.1 的右端即 Δ(C ∪ {D}) ≤ ε \< Δ(C)；对 C 取并。∎  
本命题是定理 7.1 的等价改写，不是新的充分条件；它把 D 取得承担资格的分辨度范围写成有限个半开区间之并，可直接计算。例 7.4 中 D 的窗口为 \[0, 1/20)。

命题 7.30（申报间转移）　设两组申报有同一有限候选集 A（D 为复合时按命题 7.5′ 的（Q2）展开对齐）与同一实际点 ν ∈ AdmVar\_k ∩ AdmVar^r；存在确定映射 g，使在两族共有的点上 K\_k(· \| v) = g#K^r(· \| v)（本步输出 x′\_k = g(y)，y 为职责所在节点；g 为恒等时二者同一节点）。设职责级有 C ⊆ A ∖ {D}，Δ^r(C) \> ε^r ≥ Δ^r(C ∪ {D})。若  
　（S1）Var\_k(C ∪ {D}) ⊆ Var^r(C ∪ {D})，且 ε\_k ≥ ε^r；  
　（S2）存在 v, w ∈ Var^r(C) ∩ Var\_k(C)，TV(g#K^r(· \| v), g#K^r(· \| w)) \> ε\_k；  
则 D ∈ ActArg^μ\_k(x′\_k)。  
证明：由（S1），Var\_k(C ∪ {D}) 的点都在职责族中，其本步核是职责核经 g 的推前；全变差对确定映射不增，故 Δ\_k(C ∪ {D}) ≤ Δ^r(C ∪ {D}) ≤ ε^r ≤ ε\_k。由（S2），Δ\_k(C) \> ε\_k。由定理 7.1，D ∈ ActArg^μ\_k(x′\_k)。∎  
（S1）是两组申报之间的关系，可在有限域上逐点核验。（S2）即枢纽组 C 的下界在本步申报下仍由一对共有的合法状态见证，是结论之一半在见证对上的形式，可核验而不独立于结论。另一条路线是推论 7.2：本步合法族中有只在 D 上不同、在 A ∖ {D} 上与 ν 一致、核差超过 ε\_k 的一对状态，D 即属 ActArg^μ\_k(x′\_k)，不需（S1），也不依职责的申报。推论 7.2 只说"本步族中有这样的见证对时 D 取得本步资格"，不证明 ActualHold 必然带来这样的见证对，后者仍经（b1）（b2）。以下反例分别表明，撤去相应保障后，转移不再普遍成立（它们不证明这些条件是一切转移定理的必要条件）：（S2）不成立者见例 7.4（职责分辨度 0 下属，本步 ε = 1/10 下不属）；（S1）的族包含不成立者见例 7.5（2）；（S1）的分辨度关系不成立者见命题 7.31；节点映射把差异抹去者，如 D 两值使 y 取两个单点、x′ = g(y) 把二者合并，职责节点上属而本步不属——此时 D 不进入 x′ 的生成，不是 H2（b）的反例，只说明节点对应不可省。

命题 7.31（承担资格对分辨度不单调）　存在有限模型与 ε₁ \< ε₂，使 D ∈ ActArg^μ(ε₂) 而 D ∉ ActArg^μ(ε₁)；也存在 D ∈ ActArg^μ(ε₁) 而 D ∉ ActArg^μ(ε₂) 者。  
证明：后者即例 7.4（ε₁ = 0，ε₂ = 1/10）。前者：A = {D, Z}，AdmVar = {(1, 0), (0, 1), (0, 0)}（坐标为 (D, Z)），ν = (0, 1)，K(· \| 1, 0) = (1, 0, 0)，K(· \| 0, 1) = (6/13, 5/13, 2/13)，K(· \| 0, 0) = (4/7, 3/7, 0)。Var({D}) = {(0, 1), (0, 0)}，Δ({D}) = 2/13；Var({Z}) = {ν}，Δ({Z}) = 0；Δ(∅) = TV(K(· \| 1, 0), K(· \| 0, 1)) = 7/13。ε₂ = 1/5 时 {D}、{Z} 都是极小 μ-充分组，D ∈ ActArg^μ；ε₁ = 0 时 {D} 不充分，只有 {Z} 是极小 μ-充分组，D ∉ ActArg^μ。∎  
前一例中 Z = 1 借联合约束唯一确定状态，精确分辨度下 Z 独自充分，D 被挤出。由此，本步申报的分辨度较职责的分辨度粗或细，都可能失去资格；命题 7.30 以族包含配合 ε\_k ≥ ε^r，推论 7.2 不依二者的大小关系，都不以单一阈值关系代替逐项核验。

### 8.5　击穿方式

下列任一情形构成对 M\_Gen 的击穿：同一求解输入下某一谓词取两个值；某一形式谓词在第五篇的标准正例 GS1—GS10、运行分类、推论二的成对构造或其他正例、负例、边界情形上给出与原文字面归类相反的确定值（0 或 1，不是 ⊥），且不是依携条件的形式约定而得；DeclEq 取 0；V\_j 在某一候选取 ⊥、或 Cand 为空、CovCert 未取 1 且 Π\_gen′ ≠ ∅ 时取 0；S\_Gen 的某一承重结构项在对应表中没有对应；某一关系的实际性质与 3.8 节所列不符；模型缺少结构而谓词取 0；第七节某一定理、引理或命题在所列前提下有反例。取值 ⊥、模型不如实刻画宿载、证书来源有误、同一结构的另一种物理实现，都不构成对 M\_Gen 的击穿。击穿的最小形态是一个有限生成申报模型（部件、端口、G、F、H、外生取值、S、Σ\_s、Car、Op、Tmpl、AdmVar 与 K），按定义逐步算出与上游相反的确定值，或指出证明的缺步。

## 附录 A　例 7.9 的十项构造

以下各项都在例 7.8 的宿载 𝔅 上加入未申报部件，其余部件与申报不变；读取类别按定义 3.4（1）。所加各部件（Q、BAD、Z、PROD、T、A、B、K、PR、MD、KEY、VAL、VLD）的保持律 H 都为恒等：不写入时状态不变，只经事件改变；它们都没有使能端。  
　写法约定：各项另加步计数部件 NS：条 GO，内 NS；G = \[GO = 1\]；F = NS + 1；初值 0；H 为恒等；NS 申报为步序器的一部分，属保留集 Ret\_k（定义 3.12（D7-T）），不入 ℋ\_k。下文凡称某部件"在第 j 步写 v"者，该部件为：条 GO、NS，内为 v 中出现的元件；G = \[GO = 1 ∧ NS = j − 1\]；F = v。这一写入与 TX、TW 同拍（启动后一个时步），在 NS 增一之前求值，故只在第 j 步发生一次。各加入部件的初值都等于其模板值；未列模板值者取复位值 0。读取部件（BAD、PROD、PR）与 TX 的改写按各项所列。  
　（1）门控辅助寄存器：Q 在第 1 步由 GO 选通写 1，模板值 5；BAD：条 Q、X，G = \[Q = 1 ∧ X = 2\]，F = 1；TX 另加内容端 BAD 并加上其值。第 2 步中每一时步 Q ∈ CRd(BAD, t)（条件读取，定义 3.4（1）），实际值 1。另一变体把触发值 1 改为 7，BAD 在实际运行中从不触发，E\_BAD(t) = 0，没有 BAD 的事件，也就没有事件读取；但 Q ∈ CRd(BAD, t) 在每一时步仍成立。  
　（2）门控承担求值：初态 W = 2。Z 在第 1 步写 \[((W + 1)·M) mod 3 = 0\] = 1，模板值 0；PROD：条 PH、Z，内 W、M，G = \[PH = 5 ∧ Z = 0\]，F = (W·M) mod 3；TX 改为 F = (X + PROD + U) mod 3。第 2 步启动拍 Z ∈ CRd(PROD, t)，实际值 1；模板运行中 PROD 写入，实际运行中不写。  
　（3）整表预算：T 在第 1 步写 Σ\_{w=0}^{2} ((w·M) mod 3)·3^w = 21，模板值 99；TX 在 T \< 99 且 W ≤ 2 时以 T 的第 W 个三进制位代替 W·M。第 2 步 T ∈ FRd(TX, t)，实际值 21。在 W ∈ {0, 1, 2} 上，查表所得与 W·M 相同，两次运行的写入内容相同；差异只在读入来源。  
　（4）前步预算乘积项：Z 在第 1 步写 ((W + 1)·M) mod 3 = 1，模板值 9；TX 在 Z \< 9 时以 Z 代替 W·M。第 2 步 Z ∈ FRd(TX, t)，实际值 1。  
　（5）双寄存器联合预算：A、B 在第 1 步各写 ((W + 1)·M) mod 3 = 1，模板值各 9；TX 在 A = B \< 9 时以 A 代替 W·M。第 2 步 A、B ∈ FRd(TX, t)，实际值各 1。  
　（6）启动拍读前步预算：K 在第 1 步写 ((W + 1)·M) mod 3 = 1，模板值 9；PR：条 PH，内 K、W、M，G = \[PH = 5\]（与启动同拍），F = K（K \< 9 时）或 (W·M) mod 3；TX 改为 F = (X + PR + U) mod 3。第 2 步启动拍 K ∈ FRd(PR, t)，实际值 1。切口取在启动部分最早事件之前，故启动拍的这一读取在比较区间内。  
　（7）跨两锚的数据：MD 在第 1 步写 W mod 2 = 0，模板值 0；B 在第 2 步由 GO 选通写 MD，模板值 5；TX 在 B = 1 时加 1。第 2 步中 MD 被 B 的 F 读取，实际值 0 等于模板值；B 在被 TX 读取的同一时步才被重写，所读为切口值 5，等于模板值；这两处不产生差异。第 3 步 B ∈ FRd(TX, t)，实际值 0。B = 0 与 B = 5 都不触发加 1，两次运行的写入内容相同；差异只在读入来源。
