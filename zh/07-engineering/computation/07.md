自显论·工篇·计算组式第七 v1.1

# 计算分层一般式

本篇试论一个总命题：

计算宿载 P 上的一段计算 σ，若使历史成为动力，它的必要结构最少分为几层？若它进而使律在 P 所承载的系统中续行，又最少分为几层？

计算承担一般式给出了宿载承担一项任务最少须有什么，计算执行一般式给出了一次执行最少须有什么，生成计算一般式给出了一段生成计算最少须有的六项，并在该篇-H2 下另有势支配，合为七项。生成计算一般式以 G1—G6 界定生成计算，其中 G6 规定："计算作用于场的结构、关系与动力条件，处在驱动层；目标律由场的动力生成，计算对它没有直接的结果贡献。"层位在那里是规定，不是结论。

本组式对计算的初始规定说：计算驱动沉积场动力，沉积场动力生成律与理，这就是分层（初始规定七）；又说：计算对律不作直接的结果贡献，二者之间隔着动力层（初始规定五后款）。本篇与第五篇的根本不同在于：第五篇把层位当作规定之一，本篇把它当作待证的结论。本篇只给出生成的职责，不给出层，也不预先给出层的判别关系；先追问这些职责最少逼出怎样的结构，结构闭合之后，再按初始规定的生成层级检验：每一级取得了什么资格，这一资格能否由下一级承担，从而是否分层、分几层。

须预先说明对这一问的回答程度。首版。进入证明时的初始问题是：只凭承担与执行、生成职责的规定 E1—E5、上游场与律的已立结果与非退化条件，σ 所承担的职责是否已经成立。追问中实际生成的子问题及其地位如下（"已证"均指必要方向，并限于工作域 𝒲）：  
其一，只凭当前已知，历史是否已成为动力——未成立；κ（比较投影之外、进入执行的跨步因素）必要，为 E2、E3 的实施展开（第二节）。  
其二，有 κ 后是否成立——未成立；κ 中承担差异的部分须按实际经过更新，为 E4 的实施展开（第三节）。  
其三，有按经过更新者后，差异的形成是否已归责于执行——器件环境沉积是 E3（ii）的退化见证：缺（ii），计算宿载之外的动力也会被算作承担；W（同一见证链上 σ 内的沉积更新由执行驱动）由 E3（ii）推出，为其实施展开，携计算执行一般式-H3（第四节）。  
其四，有 W 后，承担 E2 的历史是否已进入后继——由 E2 与 κ 的定义直接得出：Rd（所沉积者在见证链上被后续执行读入）必要，为 E2、κ 的实施展开，不计新项，判定携生成计算一般式-H2（第五节）。  
其五，不涉对象时是否闭合——闭合；所得结构整合为固定变换关系的执行 S 与满足可沉积性、段内由执行驱动更新、为执行读入的历史条件 D，二者构成渠定流、流改渠的反作用循环；段内无更新时，D 的资格由段首场态的场资格承担，携本篇-H1（第六节）。  
其六，转入律：保持此前所得，律是否已在续行——未成立：律写在规则里是失宿律；场中有合格沉积而续行由程序规则规定，沉积也不承担律；G\_loc 必要：律的承担者在 P 的沉积场持久场态的组织中，其相关状态经执行进入续行（只含位置与读入，不含律资格与贡献归责），携律组式 H\_G、E5\_run、E5\_car 与初始限定 E5\_host（第七节）。  
其七，S、D 与 G\_loc 俱在，律是否已成立——未成立：一次强冲的新沟在场内、被读入，却没有稳定复走；O（律之持：R 的已成组织取得 Established ∧ Govern）必要；O 是律对象资格，Φ(L) 另须 σ 对 L 续行的非虚设贡献（本篇-H2）；计算实施的事实不能替代 O 所需的场承担（不可替代引理）（第八节）。  
其八，两重反作用如何安放——第一重是动力层的本义；第二重，律以持势反作用于动力，由宿载实际实现、经动力承担，不作为另设机制的依据；动力可以停留于简单运转而不生律，要跃迁到律这一级，须压缩到在申报窗口内表现出稳定复走（Ω\_W = 1），并经充分向（携 SC\_Hold）取得律资格（第九节）。  
其九，拟增项是否须另立——检验十项，九项不须另立；理、概率、意向各自的特有职责，未答（U3）（第十节）。  
其十，所得结构是否分层、分几层——以初始规定的生成层级为计层单位，按新资格、可停留、不可由下级认证、任务所需与生成资格的层级性五条检验：D 是 S 之上的一级，O 是 D 之上的一级；隔级不可越过。规则状态、纯定位、已成而有当前支配却无稳定复走者、单独的稳定复走，都不另成一级。最少层数分四项申报：全称必要——Φ(∅) 要求 S、D，Φ(L) 要求 S、D、O；限定上界——在工作域 𝔇 内，每升一级须完整取得一项此前未获资格的申报生成关系，𝔇 只申报两项，故至多三级；可满足性——Φ(∅) 有合格实例，Φ(L) 的实例携 H\_cert 与本篇-H2，并携计算执行一般式-H3、生成计算一般式-H1、H2 与本篇-H1（证书（v））；于是在总定理（一）（二）所列条件下，MinLayers\_𝔇(Φ(∅)) = 2，H\_cert ∧ 本篇-H2 ⇒ MinLayers\_𝔇(Φ(L)) = 3（第十一节）。  
总结论：必要方向，限于 𝔇。不涉对象时最少两层：宿载层、动力层，携计算执行一般式-H3、生成计算一般式-H1、H2 与本篇-H1。律续行时最少三层——宿载层、动力层、对象层，另携律组式 H\_G、E5 的承载申报与初始限定 E5\_host，并携 H\_cert 与本篇-H2；精确的两层、三层依第十一节的计层约定。这是申报生成资格链的最低层数，不是任一具体计算系统的功能层位数。对象层不要求另有独立的物理机制，允许由宿载经动力实现；它是动力的已成组织取得律资格的那一级。

我们要在本篇，在不断追问下找到证明应当走向何处，并推导计算分层的一般式。

我们的目标是：

不以层位为前提，从生成职责逼出最小必要结构，在结构闭合后按初始规定的生成层级与各级资格检验其中的分层，逼出限定工作域内的最少层数及其条件、最小性与击穿方式；由此把规则计算放回生成计算的宿载层，把算出来、跑出来与生成出来分开，并说明计算为什么不能直接取得律。

并满足：

Layer(X, Y)：Y 是 X 之上的一级——Y 有新资格；X 可停留而不取得它；只凭 X 的已有资格不能认证它；它为申报任务所需；且它的资格具有以 X 类生成为合法依托的来源，或这种来源下满足上游移植与保持条件的合法承接，使该组织能承担资格取得以前未获资格的申报生成关系（不要求新增执行机制，不要求在本段计算内重新生成，也不要求由当前 P 亲自生成）；  
NoSubst(S, D, O)：计算实施的事实不能替代动力层对律的场承担；  
S（宿载层）：τ 在 P 上的合法执行，τ 是固定的变换关系，规定怎样变；承担生成职责的实施中，τ 含沉积律这类反作用规则，但这不是一切 S 成立的条件；它不预先指定会生成哪条律；  
D（动力层）：P 中被执行读入的沉积场持久场态 D\_P；其承担历史差异见证的部分 κ\_sed 满足可沉积性，在同一见证链上段内由 S 驱动沉积（W）、为 S 读入（Rd）——沉积约束流变，流变改写沉积，渠定流、流改渠；  
O（对象层）：P 的沉积场中律的承担组织 R 已成并取得 Govern——在律的关系 Rel(L) 与适用域 I 上真实支配后继，并在申报窗口内具稳定复走历史资格（Ω\_W = 1）（律组式：必要向 Law ⇒ ∃R\[Established ∧ Govern\]，携 H\_G；充分向 ∃R\[Established ∧ Govern\] ⇒ Law，据《律必然式》v1.4，携 SC\_Hold）；律由本段续行时，R 的相关状态经执行进入续行；取得资格的律又以持势反作用于后续动力。

层以初始规定的生成层级计，对公式拆分、变量命名、机制合并保持不变；这里的层数是申报生成资格链的最低层数，不是一个系统全部功能层位的个数。

即：一段计算若使历史成为动力，它至少有两层——固定的规则在宿载上执行；历史在规则下刻成沉积，沉积反过来定下流的去向，流又改写沉积。它若进而使律在其宿载所承载的系统中续行，至少有三层：动力之上，须有已成、在申报窗口内表现出稳定复走（Ω\_W = 1）并支配后继的组织，经充分向（携 SC\_Hold）取得律的资格。动力可以停留于简单的运转而不生律；只有压缩到能生成稳定，才进入律这一级。律的作用由宿载实际实现、经动力承担，这不妨碍它是生成层级中的上一级。

一句话

宿载定下怎样变，动力在渠与流的往返中刻下历史，律是动力压缩到稳定而成的那一级；计算够得着动力，够不着律的资格。

摘要

生成计算一般式已经说明：一段生成计算必有逐步执行、势支配、势居沉积、接续不侵入、宿持、改后承接与同一运行七项（其中势支配携生成计算一般式-H2）。但它以 G6 规定计算处在驱动层，层位本身没有被证明。于是问题推进一步：撤去层位规定，只留下"历史成为动力"与"律在续行"这两项职责，结构是否仍然分层？分几层？

纯函数程序（算出来）没有跨步因素，两处当前相同则后继必同，故须有比较投影之外、进入执行的跨步因素。逐帧模拟球碰墙弹开（跑出来）有跨步状态，却是规则的状态，不因经过而深、不因少用而浅，故承担差异者须按实际经过沉积。存储器件自身的物理迹应按经过深浅，却不是这段执行驱动的，由此须把 E3 的归责落实到段内的沉积更新上：承担见证的沉积更新须由执行驱动（W）。承担差异的历史须进入后来，由 E2 与跨步因素的定义，所沉积者须为后续执行读入（Rd）。到此，不涉对象的职责闭合：固定变换关系的执行 S，与满足可沉积性、为执行读入、段内由执行改写的历史条件 D——沉积定下流的去向，流又改写沉积。这一往一返是动力层的本义；规则计算也可以有反馈与状态更新，但反馈本身不构成沉积动力。

转入律。律写在规则里得到的是失宿律，故律的承担者须在场内的沉积中，并经执行读入（G\_loc）；而一次强冲的新沟在场内、被读入，却不成律，故还须已成并取得 Govern（O）。计算实施的事实——规则的内容、轨迹的复现——不能替代律所需的场承担。

分层按生成层级与资格检验。宿载与动力之间：固定的规则承担不了历史，算出来与跑出来是有宿载而无动力的完整计算。动力与律之间：一次强冲留下的新沟已入场、真实支配下一步，却没有稳定复走——动力在，律未成，动力停在简单运转；上游判定核在稳定复走一环落判。反之，经反复经过压缩到在申报窗口内表现出稳定复走的组织，取得律资格（条件化，携 H\_cert；上游正例；被读沉积相同而不成律的强冲场，在再入中经动力层自身的反作用被判定核由 FAIL 判为 PASS，升为律携 H\_cert）。律的资格不能由未取得它的动力组织承担；场中有合格沉积而续行由程序规则规定时，沉积也不承担律。故在总定理（一）（二）所列条件下，不涉对象时最少两层；律续行时最少三层：每升一级须完整取得一项此前未获资格的申报生成关系，而本篇只申报"历史成为动力"与"律成立"两项，故在本篇工作域内也至多三级；律续行的可满足性在上游回读前件与本篇归责条件下由运行基底的正例给出。律的持势反作用由宿载实际实现、经动力承担，这一点不改变它在生成层级中的位置。这里得到的是申报生成资格链的最低层数，不是任一计算系统的功能层位数。

本文的核心结论是：计算驱动动力，动力生成律，这是初始规定所说的分层；它在撤去层位规定之后，由生成职责逼出、由各级资格不可替代检验成立。初始规定五后款所说计算对律不作直接的结果贡献、二者之间隔着动力层，由此在限定工作域内得到条件化的定理表述（推论二）；该款本身仍是初始规定，只供读回。

引言

说一台机器"算出了律"，可以指几件不同的事：它按规则给出了律的结果；它按规则一步步模拟了律的过程；它让一个场的动力运转，律从这动力中长出并持住。初始规定称这三者为算出来、跑出来与生成出来。

对"计算与律隔着几层"，有三种读法，各自给出不同的层数。

第一种：计算直接给出律。层只有一层，律是计算的产物。这是算力迷信的读法；初始规定否认它：不能说计算直接算出了 GPT 中的问答律（初始规定七）。

第二种：动力不过是程序的状态。一段程序带着跨步的变量走下去，所谓历史条件只是规则计算的状态，并入宿载；计算之上只有律。层有两层：计算与律。

第三种：律不过是动力。初始规定也说，对象本质上也是动力，不去识出，它仍是动力变换（初始规定十二）；若有动力就有律，或律的作用既然经由动力实现就与动力同级，对象并入动力。层有两层：计算与动力。

计算的初始规定是：计算驱动沉积场动力，沉积场动力生成律与理，这就是分层（初始规定七）。它也说了两重反作用：水流过之后又反蚀渠网，这就是动力层的生成（初始规定九）；一部分持势被判准为律，对象以其持、择、偏、破等作用反过来作用于动力（初始规定十）。四种读法在输出上可以完全一样：一个规则程序可以逐帧复现律的全部轨迹，一个训练中的网络也可以。所以问题不能靠看输出回答。

于是问题不再是：计算能不能复现律？

也不再只是：计算处在哪一层？

而是更早的一问：只给出生成的职责，不给出层，逼出的结构会不会塌缩成两层，乃至一层？

※ ※ ※

先行之辨

一、层。本篇所说的层，是生成层级：下一级驱动、生成上一级，上一级取得下一级所没有的资格，并反过来制约下一级（初始规定五前款、七、九、十）。计层单位是初始规定所说的生成层级与反作用关系：层以各级所取得的生成资格区分，不按计算表示中的位置（变换关系、自变量）计，不按物理机制、变量、计算核或存储的数量计，也不按逻辑原子或任务条款的个数计；层位对逻辑公式的拆分方式、变量命名、执行机制的合并保持不变。同一程序、同一存储、同一载体可以兼有几级。上一级不必有下一级所没有的另一种执行反馈方式：对象层与动力层可以在一段合法比较中有相同的实际流变，其区别在资格。生成箭头表示承接，不表示下一级必然生成上一级。层也不指因果上彼此独立的过程：上一级的作用由宿载实际实现、经下一级承担；层的区分不以上一级另有执行机制或在因果上独立于下一级为条件。  
这里不规定层的判别关系，也不规定层数。层是否成立、有几层，在论证流闭合之后检验（第十一节）。

二、宿载、宿载层与规则计算。初始规定：宿载规则就是信号与宿载介质的迹应关系，动力条件是每一次迹应发生、产生变换时的当前条件（初始规定十五）；生成计算包含规则计算，规则计算发生在生成计算的宿载层（初始规定十六）。宿载 P 是承载计算的系统；宿载层一词指 P 上固定的变换关系及其执行，不是硬件。规则计算按初始规定是规则变换：每一执行节点是固定的规则。生成计算的宿载层所执行的，是宿载的基本规则（迹应关系、沉积律），其中含有反作用规则——经过则深、少用则浅；规则写在宿载里，宿载按这些规则能够自动生成动力层（初始规定十二）。它不是一项模拟外部对象规则的任务，也不预先指定会生成哪条律。计算本身就有状态：由输入经状态、变换、再到状态，依次进行直至输出（初始规定一）；规则计算的状态——球的位置与速度、计数器、缓存——属于计算本身。

三、动力条件与动力规则。规则写在宿载里，固定；动力条件是历史在规则下刻出来的，随流而变。神经可塑性中，经常流经之处变深、少流经之处变浅（初始规定十一），这是规则，当前各连接的深浅是动力条件。两者可以在同一程序、同一存储中实现，在职责上不是一回事。

四、对象层与识出。初始规定说，对象本质上也是动力，只是逐渐形成了对象形式，我们在这一层识出对象，不去识出，它仍是动力变换（初始规定十二）；又说一部分持势被判准为律（初始规定十）。这里有两件事：对象形式在场中形成；观者识出、判准它。本篇的 O 只指前者——律在场中的已成组织及其支配，按律组式取 Established ∧ Govern，这是场的事实，不以识出为条件；识出、判准属他组式。对象形式由动力压缩到稳定而成（初始规定十二：动力层由此逐渐压缩输入、产生对象）。

五、生成职责与生成计算。本篇的职责 Φ 不是第五篇的 GenComp：Φ 不含 G6，也不含 G1—G5 中的结构内容，只含初始规定对生成的规定（论证流第一节 E1—E5）。第五篇各项的判据可以引用，其总定理以 G6 为前件，不在本篇作前提。

六、续行与形成；训练与势引。总命题问的是续行：一段计算在承担职责期间最少须有什么。律怎样从无到有地长出属形成，其最小结构列为未答（U6）；第九节的跃迁见证用于层级区分。训练中按误差调权重是势引，不是沉积场的基本规则（《自显场势引一般式》）：它从外部改变流径，使一些区变深、一些变浅，沉积场的规则不变。

"宿载层""动力层""对象层"三个名称在第十一节检验之后才作为层的名称使用；此前只称 S、D、O。

计算的初始规定。本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。下文简称"初始规定"，引用时标出序号：  
　初始规定一：计算的本质是由输入经状态、变换、再到状态，依次进行直至输出的过程；计算限于由设备驱动的数学运算。  
　初始规定二：只有描述而无承载者的律，称为失宿律；场动力与律的运动必然需要驱动，这一驱动就是承载它的系统 P，记作 L 宿于 P。  
　初始规定三：规则变换的每一个执行节点都是一条逻辑规则；规则计算生成失宿律，例如电脑游戏用规则模拟球碰墙后弹开。  
　初始规定四：在动力变换中，历史成为动力；在历史之外对动力施加外力干预，是另一种情形。  
　初始规定五：（前款）计算处在驱动层；生成计算先驱动生成场动力，这一级称为动力层，再由场动力生成律、意象等上层对象，这一级称为对象层。（后款）计算对律不作直接的结果贡献，二者之间隔着动力层。后款即本篇所证结论在规定层的说法，列此只供读回，不作任何证明的前件。  
　初始规定六：人脑的驱动是营养，其动力条件与计算无关，人脑的运作却同样产生律与理；跳过宿载层、直接用计算模拟律，得到的必定是结果计算。  
　初始规定七：计算驱动沉积场动力，沉积场动力生成律与理，这就是分层；因此不能说计算直接算出了 GPT 中的问答律；沉积场不必依赖计算才能实现。其中"这就是分层"一语即本篇所证结论在规定层的说法，只供读回；本式只取本条所说的生成关系作计层单位。  
　初始规定八：区分算出来、跑出来、生成出来三者；生成出来是计算驱动宿载，律从宿载中长出。  
　初始规定九：以挖渠为例，水流过之后又反蚀渠网，后续水流就这样持续与渠网交互，这一过程表现为渠网的动力，这就是动力层的生成。  
　初始规定十：在动力层之上，一部分持势被判准为律；动力的变化生成对象，对象以其持、择、偏、破等作用反过来作用于动力，使后续的流只能沿某种趋势走；这些运动都真实地来自宿载，若宿载是计算设备，就来自计算。  
　初始规定十一：宿载的计算只能定下动力层的计算规则，例如神经可塑性：脉冲经常流经之处变深、更易通过，少流经之处变浅、不易通过。  
　初始规定十二：生成计算把规则写在宿载里，宿载按这些规则能够自动生成动力层；动力层由此逐渐压缩输入、产生对象；对象本质上也是动力，只是逐渐形成了对象形式，我们在这一层识出对象，不去识出，它仍是动力变换。  
　初始规定十三：训练中按误差调整权重的规则不是沉积场的基本规则，而是训练的规则；这种训练称为势引。  
　初始规定十四：不经由信号流、在历史之外直接改渠或改写权重，是侵入。  
　初始规定十五：宿载的基本规则固定写在宿载里，动力条件是历史在规则之下刻出来的；在计算宿载中，动力在信号流经过、通过规则真正进行计算变换时发生，在非计算宿载中，动力在信号流过宿载介质、与介质中的物质发生交互迹应时发生；宿载规则就是信号与宿载介质的迹应关系，动力条件是每一次迹应发生、产生变换时的当前条件。  
　初始规定十六：生成计算包含规则计算；规则计算发生在生成计算的宿载层。

其五，任务侧条件。P 所持状态的完整读法先于 σ 申报：哪些分量列入 π\_cmp，哪些是跨步承接的状态，各分量的更新方式，按第五篇扩展状态的划分申报（携生成计算一般式-H1）。π\_cmp 在 σ 之前由申报任务与合法观测范围固定，包括 τ、本步输入、外生控制构型 c、申报的当前结构读出；不得为证明某一因素而事后选择。P 所持而未列入 π\_cmp 的普通缓存、计数器所产生的"相同投影、不同后继"，若不满足 E4，不构成 E2 的合格见证。外生控制构型 c（运行模式、Mask、Avail）只经申报协议的许可干预改变，不属 σ 的执行。τ 含随机抽样时，比较协议同时固定随机源：两处在同一抽样源下比较实际执行，或比较同一条件下的后继分布；随机源的状态不作为跨步因素计入，也不得用来制造或掩盖差异。E5 的"非虚设因果贡献"按本篇-H2 的口径审查，不以 but-for 为最低判据；完整归责协议未关闭。

其六，非退化条件：存在 P 执行 τ 而 E2—E4 不成立的情形（纯函数程序）；存在 E1—E4 成立而对申报的 L 而言 E5 不成立的情形（一次强冲，见第八节）。二者不含待证结构的任何分量。

其七，工作域 𝒲：单宿载 P 内的计算实施、沉积动力与至多一条律的续行；承继以上所列上游条件。不含：理、概率、意向的特有职责（其律侧部分作推论，U3）；对象种类的完备（U4）；跨宿载的分布式承载（U5）；形成（U6）。本篇一切结论限于 𝒲。  
层数的陈述另限于 𝔇：𝒲 连同本篇所申报的两项生成关系——Rel0，历史成为动力，即 Φ(∅)；RelL，申报律 L 作为对象在 P 所承载的系统中成立——对象资格 RelL^obj ≔ Law\_P(L)：L 在以 P 的沉积场为场的系统中按律组式成律；其结构刻画分两向登记：Law\_P(L) ⇒ ∃R\[Established\_P(R) ∧ Govern\_P(R, L)\]（必要向，携 H\_G）；∃R\[Established\_P(R) ∧ Govern\_P(R, L)\] ⇒ Law\_P(L)（充分向，携 SC\_Hold 及上游申报论域）；合成双向式只在 H\_G ∧ SC\_Hold 下成立，两向条件各自保留；其中 R、Established、Govern 各按上游原文，不预置本篇的 D\_P。律对象资格按上游场 F、时刻 t、关系 Rel(L) 与适用域 I 认证，不以 D\_P 为前提。律在系统中成立与律由本段 σ 实际续行不可互换：后者还含运行域的匹配与任务归责。律的承担者在 P 的沉积场中（第七节引理一）、其相关状态被本段执行读入（第七节引理二），是要证明的，不写进 RelL^obj 的定义。另记任务资格 RelL^task ≔ RelL^obj ∧ Ct(σ, L)，Ct 为 σ 对 L 续行的非虚设贡献（本篇-H2）；Φ(L) ⇒ RelL^task ⇒ RelL^obj。层级计数针对生成资格，所用的是 RelL^obj；Ct 是任务归责，不是生成资格，不计层。E1—E5 之外的职责、上游原子之下更细的分解、许可候选结构中更细的分级（U2），不在 𝔇 内。

其八，相邻各式：第八《生成计算必然式》在其规则类与工作域内处理 Φ(∅) 一侧的充分性（Φ(L) 一侧组内尚未成立），第九《计算越层误置消解式》、第十《计算复现失真源式》、第十一《计算判定式》、第十二《计算与非计算宿载区分式》、第十三《生成计算干预区分式》引用本篇结论；它们的结论不进入本篇前提。

二

只凭这些，Φ(∅) 已经成立了吗？

取一个纯函数程序（初始规定所说的"算出来"）：P 执行 τ，每一次执行只读本步输入与 π\_cmp 所列的当前结构读出，给出结果，不持任何跨步变量。σ 中的变换都是 P 对 τ 的执行，E1 成立。

它不承担 Φ(∅)：两处 π\_cmp 相同，后继必同；任何合法的历史变动都不在后续变换上留下差异，与 E2 相违。当前已知拦不住它：承担与执行只说 P 在算、算的是 τ，不说历史是否进入。

由 E2，须有一个因素：不在 π\_cmp 之中，随合法历史取值不同，作为自变量进入 σ 中某一后续变换；由 E3，它由 P 所持，进入的是 σ 的执行。

定义一：跨步因素  
κ 指 P 所持、不在 π\_cmp 之中、随合法历史取值不同、作为自变量进入 σ 中某一后续执行的因素。

其必要性：对任一满足 E2 的 σ，由 E1 与任务的外延身份，τ 在 Θ 内固定；两处 π\_cmp 相同、随机源按比较协议固定（第一节其五），而某一后续变换（或其分布）不同，变换之差只能来自 π\_cmp 之外的自变量；由 E3，这一自变量由 P 所持，所进入的是 P 的执行。故 κ 必有。"进入执行"在执行归责上承计算执行一般式的 Ex，携该式-H3；π\_cmp 与完整状态的读法须按第一节其五先于 σ 锁定。  
登记：κ 是 E2、E3 在固定 τ 之下的实施展开，不计新项。由此另得一条后文要用的事实（记为 FixedNoHist）：固定的 τ 作用于 π\_cmp 相同、且 κ 相同的状态，给出相同的后继分布，在共用随机源下给出相同的实际后继——固定的变换关系自身不承担历史差异。

三

κ 已经得到。有 κ，历史已经成为动力了吗？

取电脑游戏中的球碰墙弹开（初始规定所说的"跑出来"）：π\_cmp 申报的当前结构读出是球的位置；速度作为 κ 跨帧承接，不在 π\_cmp 中。两处位置相同、来路不同的球，下一帧去向不同，E2 成立；差异由 P 所持的速度承担，在 P 的执行之内，E3 成立。

它不承担 Φ(∅)：承担差异的速度由规则直接改写，不因经过而深，不因少用而浅，不分来源；它是计算本身的状态，与 E4 相违。κ 拦不住它：κ 只问有无跨步因素，不问这一因素以什么方式随历史而变。

由 E4，κ 中承担差异的那部分，其历史依赖满足可沉积性：经过则有迹，反复则迹深，少用则迹淡；按写入闸门，只有实际经过者入沉积。记 κ 中历史依赖满足可沉积性的部分为 κ\_sed，其按经过而成记为 Pass；E4 要求承担 E2 见证的那部分落在 κ\_sed 之中。κ\_sed 是就 E2 的跨历史比较界定的：它的成员须随合法历史取值不同。另记 Sed\_P 为 P 中取得场资格的沉积场的持久场态，不论其在某一次比较中是否取值不同；由本篇-H1，κ\_sed ⊆ Sed\_P。P 中可以有几套沉积组织，各自承担不同的见证（第七节）。

登记：这是 E4 在 κ 上的实施展开，不计新项。它给下一问提供对象：按经过而变的，是谁使它变？另登记一项：κ 中不承担 E4 的部分是规则计算的状态，属计算本身（先行之辨二）。

四

κ\_sed 已经得到。它按经过而变，是这段执行使它变的吗？

取一块存储器件，它自身有物理迹应：电流经过越多电导越大，久不经过则回落。这一物理过程不在 τ 的申报实施之内，只作为器件的环境性质存在；τ 的执行不驱动它，它的发生不依本次启动而定。P 照常执行 τ，τ 读取这些单元，器件的漂移使后继随历史而不同。E2 成立；差异在 P 内，不是边界外写入；差异按经过深浅，E4 成立。

它不承担 Φ(∅)：差异由器件的物理变化产生，不由 σ 的执行产生，Φ 不能归责于 σ，E3 不成立。这正是初始规定所分的两种动力：在计算宿载中，动力在通过规则真正进行计算变换时发生（初始规定十五）；在非计算宿载中，动力在信号与介质的物质交互中发生。器件的漂移是后一种，即便它发生在计算设备里。本例的地位是 E3（ii）的退化见证：它在 P 之内、在运行之中，满足 E3（i）的"非边界外、非运行外"与当前执行贡献，κ\_sed 也照常按经过而变；若职责只有 E3（i），它就会被算作承担 Φ(∅)。E3（ii）——见证所依历史条件的段内形成须是计算宿载的动力（初始规定十五）——正是排除它的那一款。下面由 E3（ii）推出 W，不在 E3 之外另立新要求。

W（段内沉积由执行驱动）：对 E2 的一条见证链 χ，σ 内 χ 上的 κ\_sed 更新事件都由 σ 中某一次执行驱动——本次启动是该更新的实际原因之一（计算执行一般式 Ex，携该式-H3）。W 约束的是申报执行所承担的那条见证链上、在 σ 内发生的沉积更新，不是 P 中一切状态更新，不是一切见证链上的更新，也不是见证所依历史条件在 σ 以前的形成。被合法申报为 τ 实施组成部分、由本次执行驱动的物理状态转移，属执行驱动；不在申报实施之内、不依本次启动而发生的器件物理变化，不属——这类变化若承担 χ 的段内形成，仍在 W 的审查范围之内，并使 W 不成立。σ 内没有这样的更新事件时（冻结运行、只读部署），W 平凡成立。

其必要性：E2 是存在命题；E3（ii）要求，见证所依的历史条件若在 σ 内形成或改变，这一形成由执行驱动。若某条见证链上有 σ 内不由执行驱动的 κ\_sed 更新，这条见证的段内形成就是介质自身的物理变化（本例）或边界外、运行外的改变，不满足 E3（ii）；它可以仍有 σ 的当前执行贡献（E3（i））——执行确实读取了这一差异——但这不补足（ii）。由 Ex，一个变化归责于执行，当且仅当本次启动是它本次演化的实际原因之一。故满足 E3 的 Φ(∅) 至少有一条见证链，其 σ 内的 κ\_sed 更新都由执行驱动：W 必有。这一推导用的是 E3（ii）对段内形成的约束，不是把 Ex 对当前演化的归责推广到沉积历史的全部事件：σ 以前的自主形成不受 W 约束。  
混合模式不被排除：σ 执行期间，P 中某些场态分量可以自主变化，执行照常读取并支配后继；只要另有一条完全归责于执行的见证链，Φ(∅) 照常成立。自主变化不计入 σ 的沉积成果；若 E2 的见证只能由它承担，E3 不成立。

实现形式不限：数字写入、合法申报的物理实施，都可满足 W；区分落在归责上，不落在物理形态上。κ\_sed 的段首取值如何得来——训练、移入、写入——不在 W 之内（移植条款）。W 不要求 τ 的外延含沉积律。须注意：W 平凡成立只说明段内没有不归于执行的更新，不说明段内发生了沉积，也不认证 κ\_sed 的场资格；后者见第六节。

登记：W 是 E3（ii）在见证链沉积更新上的实施展开，判据承继计算执行一般式 Ex，不计新项。本节的所得是：器件环境沉积见证了 E3（ii）的必要，W 把（ii）落到同一见证链 χ 上 σ 内的沉积更新事件本身。

五

W 已经得到。承担 E2 的历史，进入了后来吗？

这一问由已有所得直接回答。E2 要求两处在 π\_cmp 下相同而后续实际变换有因果差异；κ 的定义要求承担差异的因素作为自变量进入后续执行；κ\_sed ⊆ κ 是其中承担差异者。故见证所依的沉积必须被后续执行读入。这是 E2、κ 在 κ\_sed 上的实施展开，不逼出新的独立条件。

一个说明性的例子：沉积律照开启模式执行，更新由执行驱动，但写入 P 内的一份副本，承担后续变换的执行仍从原位置读取。它不承担 Φ(∅)：沉积下的历史不进入任何后续变换。它说明单有写入不足；但它不是保留此前全部所得的情形——被读入的原位置不随历史而变，被沉积的副本不进入执行，κ 本身在这段历史上就不成立。

Rd（执行读入沉积）：在 χ 上，κ\_sed 的取值被后续执行作为自变量读入。W 与 Rd 由同一条见证链 χ 承担：WR ≔ ∃χ\[E2(χ) ∧ E3(χ) ∧ E4(χ) ∧ W(χ) ∧ Rd(χ)\]，下文 W ∧ Rd 皆指 WR。只要求见证链上的读入，不推广到一切沉积更新；不要求每一次沉积即时被读；容许延迟、阶段性的承接；冻结段中无更新而 Rd 在。Rd 只说被读，不说所读者具有合格的场资格。

其必要性：对任一满足 E2 的 σ，见证所需的历史差异须进入某一后续变换；若它不被任何后续执行读入，它就不进入任何后续变换，与 E2 矛盾。故 Rd 必有。Rd 的判定承第五篇 Hold、Carry 与 Gov 的判据，Gov 携生成计算一般式-H2。  
登记：Rd 是 E2 见证链的实施展开，不计新项。

六

κ、κ\_sed、W、Rd 已经得到。Φ(∅) 闭合了吗？

逐项全称必要性已在各节给出：κ 由 E2 与 E3，Pass 由 E4，W 由 E3（ii）与执行归责，Rd 由 E2 与 κ。逐项反例：去 κ 是算出来，去 Pass 是跑出来，去 W 是器件环境沉积；Rd 不另以独立反例逼出，它是 E2、κ 的实施展开，写入而不被读的副本只作说明（第五节）。

段内无更新者另须一问：冻结运行、只读部署中，W 平凡成立，Rd 只认证被读，那么 E4 所要求的可沉积性由什么承担？段内没有任何沉积事件可资认证，E4 只能由 κ\_sed 段首场态所属载体的场资格承担：它是一个取得完整场资格的沉积场的持久场态，在申报的冻结或只读模式下被读入（第五篇 GS2—GS4 的冻结、移入、写入初值三类，按上游冻结运行与移植条款承继）。由"满足 E4 的历史依赖"认定为"合格场的持久场态"，或反之，是本篇-H1 的内容。H1 因此是 Φ(∅) 在段内无更新情形下的承重条件，不是附带条件：H1 不成立时，冻结段、只读段能否纳入 D，悬而未决。

在此条件下，E2、E3、E4 各款的未闭合处都已关上，E1 由承继给出。不再有由 E1—E4 打开、尚未关上的约束。闭合，停止逼项。

所得结构可以整合为两种承担。由 E1 与外延身份，τ 在 Θ 内固定，这是承继；第三至五节使 κ\_sed 成为满足可沉积性、段内由执行驱动更新、为执行读入的自变量。于是：

S：τ 在 P 上的执行，τ 是固定的变换关系，规定怎样变；κ 中不承担 E4 的规则状态随之在内。  
D：分三个对象。D\_P ≔ Sed\_P 中被 σ 的执行作为自变量读入的部分——P 中合格沉积动力的总体承担域；成员只须属 Sed\_P 并被执行读入，不须满足某一条见证链上的 W，各成员可以有不同的形成时期、续行模式与见证职责。D\_E2 ≔ 见证链 χ 上的 κ\_sed，由 Pass ∧ WR 认证（段内无更新时 Pass 由 H1 承担）；由 κ\_sed ⊆ Sed\_P（H1）与 Rd，D\_E2 ⊆ D\_P。Φ(∅) 要求 D\_E2 非空，使历史差异进入后续变换。律的承担者 R 在 Sed\_P 中（第七节引理一），其被本段读入的相关状态 Q ⊆ D\_P（引理二），另按律资格与 σ 的实际作用认证。D 是资格种类，D\_E2 与 Q 所在部分是它的实例；W ∧ Rd 是申报见证链的认证要求，不分配给 D\_P 的全部成员。

这正是初始规定所分的宿载规则与动力条件。κ\_sed 的取值不是 τ 的配置常量；可塑的低阶规则可以是 κ\_sed 的分量，由固定的高阶 τ 规定其更新；S 与 D 可以在同一程序、同一存储中实现。登记：这是整合，由承继与前四节所得直接得出，不计新项。S、D 是否构成层，此处不问，留到第十一节。  
这两种承担合成动力层的本义：Rd 是渠定流——沉积作为自变量被读入，定下后继的流向；W 与 Pass 是流改渠——实际经过者经执行沉积，改写此后被读的取值。普通程序也可以有反馈、状态更新乃至自修改；区别不在有没有反馈，而在历史是否取得可沉积性、更新是否合法归责于执行（第三、四节）。须分清两件事：D 已取得由反作用循环形成的动力条件——它经合法历史在渠与流的往返中生成，当前仍约束流变；与本段正在完成一轮反作用更新。前者是 D 的资格，任一满足 Φ(∅) 的 σ 都须有；后者只在开启段发生。冻结段与移植段中 W 平凡成立，本段并不"流改渠"，D 的资格由段首场态承担（本篇-H1）。

七

转入 Ob 含律 L。保持第二至六节的全部所得，Φ(L) 已经成立了吗？

取一个规则模拟：τ 直接规定 L 的续行，球碰墙即弹开的规则写在程序里，L 的全部轨迹完全复现；P 中另有一段 D 回路，κ\_sed 照常沉积、照常读入，E1—E4 成立，但这段回路不进入 L 的续行。L 作为律不成立：按 C0（律入沉积）与查表条款，只存在于场外的规定不成律；这里得到的是初始规定所说规则计算所生成的失宿律（初始规定三）。与 E5 相违。  
S、D 拦不住它：它们只问历史是否成为动力，不问律的支配结构在哪里。这一例只击穿"规则执行足以给出律"，是弱非蕴含：它不推出"有规则执行则场中绝无律"，因为同一宿载可以另有真实的沉积结构；D 回路只保证 Φ(∅)，不使 L 取得资格。

更强的一例是场中本有合格沉积，续行却由规则规定。取上游运行基底 F\_LB 的 LB1 场（a1→m1、m1→c 的 g = 9.759，阈状态 S\_e = 1，Ω = 1.0；a1、a2、m1、m2、c、x 是 F\_LB 的结构位，结构位 c 不是外生控制构型 c），场态原样不动、不屏蔽，只把执行程序换成 τ\_C：τ\_C 在 a1 一律取 a1→m1、在 m1 一律取 m1→c，这两处不读任何场量，其余位置与 F\_LB 的续行核相同。同一实例以自身执行运行 100 次（a1、a2 交替，共用随机源），路线与正例逐步相同；同一实例交判定，对 L = a1 ⇒ c 落在 DynamicRole：m1 处没有任何场态是作用自变量。不依赖判定器的论证：τ\_C 在 a1、m1 的变换不含任何场量，对场态的一切取值续行分布不变，故对任何场内组织 R，DynamicRole(R, L) 不成立，由律组式必要向，L 不成律（携 H\_G）。同一系统中另一关系 a2 ⇒ x 仍判成律（附录 B 条目 A-3）。场中的合格沉积在，律却不由它承担——承担 a1 ⇒ c 轨迹的是 τ\_C 中的规则（C0、查表条款）。  
判定器的适用域须注明：《律判定式》参考判定核按 F\_LB 原续行核的公式计算续行分布，其判定域是以原续行核执行的 F\_LB；审查 τ 已改写的系统，续行分布须取被审系统实际执行的变换核。按这一读法计算，上例在 DynamicRole 处落判，与上段论证一致；上段的否定结论不依赖任何判定器（两种判定器的版本与适用范围见附录 B 条目 A-0，判定结果见 A-3）。

由 E5\_run，L 在 σ 中续行，L 在 P 承载的系统中成律，即 Law\_P(L)；由律组式必要向，有 R 满足 Established\_P(R) ∧ Govern\_P(R, L)（携 H\_G），R 与这两项资格都按上游原文，不含本篇的任何结构。这里只问这个 R 在 P 中处于何处、怎样与本段计算相接。须分开两件事：律在系统中成立（对象资格），与律由本段 σ 实际续行（还含运行域的匹配与任务归责）。前者不推出后者：L 可以在 P 的场中成律，而 σ 只执行别的关系、从不运行 Rel(L)，这时 σ 不读入 R。故分两座桥。

（1）场内承载。按上游 Established 的定义，R 是场 F 的当前沉积承载组织，不是只由当前输入即时维持的响应状态；由 C0 与查表条款，它不是只存在于场外、写在 τ 中的规则内容；由 E5\_car，F 是 P 的沉积场。

引理一（场内承载桥）　在 H\_G、C0、查表条款与 E5\_car 下：Law\_P(L) ⇒ ∃R ⊆ Org(Sed\_P)：Established\_P(R) ∧ Govern\_P(R, L)，R 是同一关系 Rel(L)、同一适用域 I 上认证的上游律承担者。  
证明：由律组式必要向取得 R；由（1），R ⊆ Org(Sed\_P)。推导不调用 D\_P，也不调用 Ct。∎

（2）本段作用。E5\_run 说 σ 在 Rel(L) 与 I 上包含 L 的实际续行事件，且在该事件的时刻 L 成律；E5\_host 说这些续行中，律的承担者所起的动力作用是计算宿载中的动力——若宿载是计算设备，运动就来自计算（初始规定十），动力在通过规则真正进行计算变换时发生（初始规定十五）——即承担者的作用经 P 对 τ 的执行进入后继，不经介质对后继的直接物质交互。E5\_host 只约束承担者对续行事件的作用途径；R 的场态在两次执行之间可以有自主变化，变化后的取值照常被读入。

定义（作用绑定）　ActBind(σ, e, L, R\_t, Q\_t) 指：e 是 σ 内申报目标 L 在 Rel(L)、I 上的合法实际续行事件，时刻为 t；R\_t 是该时刻、该关系、该适用域上经上游认证的律承担者（Established\_P ∧ Govern\_P）；∅ ≠ Q\_t ⊆ R\_t 是 R\_t 中对 Rel(L) 后继生成承担非平凡动力作用的相关状态（DynamicRole 所指），不是 R\_t 中任意被读取的字段；Q\_t 的作用经 P 对 τ 的合法实际执行链进入 e 的后继生成——执行链可以含中间状态与多个执行节点，不要求 Q\_t 是生成 e 的那一次执行的直接自变量。对象、关系、时刻与承担者在全过程中保持同一。ActBind 是对象资格与本段计算之间的作用绑定，不是新的律资格，不构成新层。

引理二（本段作用承接桥）　在引理一的前件下，E1 ∧ E5\_run ∧ E5\_host ⇒ 对 σ 中 L 的每一实际续行事件 e（时刻 t），∃R\_t, Q\_t：ActBind(σ, e, L, R\_t, Q\_t)，R\_t ⊆ Org(Sed\_P)，且 Q\_t 被执行链上的某次执行读入，Q\_t ⊆ D\_P。  
证明：由 E5\_run，e 的时刻 t 在 σ 内，且 L 在 t 成律——不只是 σ 以前某一时刻曾经成律。由引理一，在同一 t、同一 Rel(L)、同一 I 上取承担者 R\_t ⊆ Org(Sed\_P)，满足 Established\_P ∧ Govern\_P。Govern 含 DynamicRole：Rel(L) 的后继生成对 R\_t 的相关状态 Q\_t 有非平凡动力作用，Q\_t 非空。由 E1，σ 内的生成都是 P 对 τ 的执行；由 E5\_host，Q\_t 对 e 的动力作用经计算执行实现，不经独立于执行的介质作用。由第二节 FixedNoHist，τ 固定时每一次执行的后继分布只是其自变量的函数（随机源按比较协议固定）；故 Q\_t 经执行到达 e 的作用，只能沿一条数据依赖或因果依赖途径传递：其起点是某次以 Q\_t 为自变量的执行 r₁，其后可经中间状态与若干执行节点，终于生成 e 的执行。若没有任何执行以 Q\_t 为自变量，Q\_t 经执行对 e 无任何作用——与 E5\_host 与 DynamicRole 的合取相违（作用须有，且须经执行）。故有执行读入 Q\_t：ActBind 成立。Q\_t 属 Sed\_P 的场态，按 D\_P 的定义 Q\_t ⊆ D\_P。∎  
时刻：冻结续行中，场态在 σ 内逐位保持，段首的认证经保持性及于各事件时刻；开启续行中，须在事件时刻重新认证或证明资格持续保持，不得由段首认证直接推广到全段。律在 σ 内可以跨时改变其承担组织：不同事件时刻的 R\_t 可以不同，不假设整个 σ 只有一个不变的 R。  
所携：H\_G；E1；E5\_run、E5\_host、E5\_car；FixedNoHist；"进入执行即作为自变量被读入"承计算执行一般式 Ex，携该式-H3；读入的判定承生成计算一般式-H2。证明不用单一 but-for：冗余承担时删除 Q\_t 后结果可以不变，但只要 Q\_t 有经执行的作用，执行链的起点就须读入它。这一推出依赖 E5\_host 这一前提；E5\_host 本身是初始限定，不是由此证得的。

G\_loc（律的场内承担位置）：G\_loc(σ, L, R, Q) 当且仅当（a）R 是候选场内组织，R ⊆ Org(Sed\_P)，不在 τ 的规则之中；（b）∅ ≠ Q ⊆ R 是候选相关状态；（c）Q 在申报目标关系 Rel(L) 的实际续行中进入计算执行的数据依赖路径，Q ⊆ D\_P。G\_loc 不把"已经具有非平凡动力作用"写入定义，不含 Established、Govern、Ct：G\_loc ⇏ DynamicRole，G\_loc ⇏ Established，G\_loc ⇏ ΩSupport。ActBind 才把上游 DynamicRole 的真实作用资格与本段执行路径结合；ActBind ⇒ G\_loc，反之不成立。一次强冲中 G\_loc 成立而律资格不成立（第八节）。不要求 R 与 E2 的见证同一，不要求 R 属 κ\_sed，不要求 R 的全部分量被读。由引理一、二，Φ(L) ⇒ ∃e, R, Q：ActBind(σ, e, L, R, Q)，从而 G\_loc(σ, L, R, Q)。

R 不必落在承担 E2 见证的 D\_E2 中。同一宿载可以有两套沉积回路：A 回路承担 E2 的历史差异，B 回路形成 R\_B 并对申报的 L 取得资格，由同一个 τ 的执行读入。此时 D\_E2 在 A，Q 在 B，二者都是 D\_P 的部分；引理一、二对 B 回路成立——包括 B 处于冻结续行、在 A 的比较族中不取值不同的情形——证明中没有用到 R 与 E2 见证的同一，也没有要求 B 满足 A 的见证链上的 W。层按资格种类计，A、B 同属 D。

（3）贡献路径。σ 对 L 的贡献（Ct，按本篇-H2 审查）由 E5 归于 σ；由 Ex，σ 的贡献只能经其执行。须分开三件事：当前读入——由引理二，σ 的执行在 L 的续行中读入 Q；历史形成来源——R 的段首取值与资格可来自 Θ 之前（移植条款），不在 W 之内；段内更新归责——σ 内 R 的场态可以有执行驱动的更新，也可以有自主变化，自主变化不计入 σ 的贡献，也不算作 σ 的沉积成果。

CtPath（贡献路径）：σ 对申报目标律 L 的非虚设贡献，经 Exe(σ) 中实际承担该贡献的合法执行子链实现。执行子链可以包括沉积状态的读入、当前位置与信号流的推进、中间状态转移、固定变换关系的实施，以及由执行驱动的相关状态更新；这些状态不必全部属于律承担组织 R。与 L 的续行无关的执行事件，不因处于同一 σ 内而计为对 L 的贡献；R 在执行之间发生的自主变化，也不归为 σ 的执行贡献。  
引理二另外保证：在 E5\_run、E5\_car、E5\_host 及相应上游条件下，目标律承担者 R\_t 的相关状态 Q\_t 经合法执行依赖链进入相应续行事件——这是目标律作用在计算宿载中的承接路径。CtPath 记录这一承接与 σ 的实际贡献路径；贡献是否非虚设，仍由 Ct 按本篇-H2 认证。ActBind 不替代 Ct，CtPath 不反向赋予对象资格。律的资格承担者仍须按上游认证为沉积场组织 R：计算执行可以直接参与目标律的当前续行，执行事实却不能直接代替沉积组织取得律资格。由 E5 与 Ex，并承引理二，在上述意义下 Φ(L) ⇒ CtPath。CtPath 属任务归责，不计生成层级。  
较强的写法——"σ 对 L 的贡献只经读入 R 或执行驱动的 R 的更新"——不成立，不采用：执行推进 L 链上的信号（如 F\_LB 中脉冲的当前位置 q）是对续行的真实贡献，所改的状态不在 R 中。

G\_loc 与 ActBind 的必要性即引理一、二，对 𝒲 内任一满足 Φ(L) 的情形成立；CtPath 的必要性即（3）。所携：H\_G、E5（run、host、car，host 为初始限定）、FixedNoHist、生成计算一般式-H2（读入的判定）、计算执行一般式-H3。反例不可省：去 G\_loc，回到规则模拟；场中有合格沉积而续行由规则规定者（τ\_C）同样落在这里——在 τ\_C 中 R1 在场内（引理一的位置成立），但 m1 处的续行不读任何场量，R1 的状态不进入任何执行的数据依赖路径，G\_loc 的（c）与 ActBind 都不成立，DynamicRole 也不成立。σ 对律续行的非虚设贡献属 E5 本身，按上游冗余因果职责的口径，不要求 but-for（本篇-H2）。

八

G\_loc 已经得到。S、D 与 G\_loc 俱在，律已经成立了吗？

取上游参考实现在运行基底 F\_LB 上的一次强冲案例（《律运行基底构造式》LB2；《律数理式》定理 4.13；《律判定式》附录 B 五案例之一），逐项写成一段计算：  
P：执行 F\_LB 更新程序的计算设备；τ：F\_LB 的更新程序，Decay → Continuation → Trace → Sediment，在 Θ 内固定（E1）。  
σ 与申报运行窗：自强冲脉冲交付的一步起，至申报的检查步止；窗内为开启模式。  
E2：取合法历史变动"无此强冲"与"有此强冲"，两处在 π\_cmp（τ、本步输入、c、申报的当前结构读出）下相同；强冲之后，续行核值 κ\_LB 读取 g，新沟所在边上的续行概率不同，后续变换有差异。  
E3：差异由 P 所持的 g、d、rep 承担，强冲经申报入口交付，Sediment 由程序计算，无边界外代算或运行外写入。  
E4：Sediment 按 α·p、β·p 写入所经路线，Decay 退浅，同源同迹——满足可沉积性，Pass 成立。  
W：新沟的写入由强冲那一步的执行驱动。  
Rd：后续各步的 Continuation 以 Mask·g 读入新沟所在边的 g。  
G\_loc：申报 L 为这道新沟所承担的关系 a1 ⇒ c（c 为结构位），R1 = {a1→m1, m1→c}。R1 在 P 所持的 g 中，不在规则里（a）；Q 为 R1 两条边的 g 值，即 a1 ⇒ c 的后继对之有依赖的相关状态（b）；Q 在自 a1 的续行中经 Continuation 被读入、进入 a1 ⇒ c 所涉的后继生成（c）。另记 CtPath 一侧的事实：R1 的写入由强冲那一步的执行驱动——这只是执行写入的事实，不意味着已取得律的任务资格。  
上游实测（LB2：新场单次 p = 20 沿 a1→m1→c，随即冻结）：a1→m1、m1→c 的 g = 5.0 ≥ θ，复走 1，Ω = 0；冻结探测 P̂\_2000(c\|a1) 基线 1.000，do(Mask\_{R1} = 0) 后 0.537，对照屏蔽后 1.000，g、rep、Ω 逐位不变。上游前阶读出：Established^inst = 1，DynamicRole^inst = 1，ΩSupport^pre = 0（《律运行基底构造式》LB2 的实例读出，不等于《律数理式》的形式谓词）；形式层由《律数理式》定理 4.13 与《律判定式》判定核给出：判定核在 ΩSupport(ΩOK) 处落判。  
故 S、D、G\_loc 俱在，E1—E4 成立，而对申报的 L，E5 不成立。

GS9 也可用作同类情形，但只能在如下限定下：申报 L 为训练所要生成的目标新律，GS9 是"尚未生成这一目标新律的训练早期段"，并须对这一 L 逐项核实其在申报运行窗内不成立。它不是"尚无任何律成立"的证据：初值或既有组织可能已在别的关系、别的适用域上成律。

G\_loc 拦不住它：G\_loc 只问 R 在哪里、怎样与计算相接，不问 R 是否已成、是否在适用域上稳定复走并支配后继。

由 E5 与律组式必要向，逼出：

定义二：律之持（对象资格）  
O\_P(L) 指：O\_P(L) ≔ Law\_P(L)——律对象资格，即 RelL^obj，按律组式原文认证，不预置位置。其结构刻画按上游分两向：O\_P(L) ⇒ ∃R\[Established\_P(R) ∧ Govern\_P(R, L)\]（必要向，携 H\_G）；∃R\[Established\_P(R) ∧ Govern\_P(R, L)\] ⇒ O\_P(L)（充分向，《律必然式》v1.4，携 SC\_Hold）；本篇不经定义取得充分向。O\_σ(L) 指：∃e, t, R, Q：O\_P(L, t) ∧ ActBind(σ, e, L, R, Q)——目标律对象资格与本段实际续行作用绑定的合取，不重新定义 Established、Govern 或 ΩSupport，不是律组式之外的新律资格；凡谈"由 σ 承担的目标律对象"用 O\_σ，凡只谈"P 的系统中已有的律资格"用 O\_P。两者中，Govern ⇔ DynamicRole ∧ ΩSupport，各按上游原文（第一节其三）——其中包括一次强冲所未取得的稳定复走资格。

O\_P 是律对象资格，不是 Φ(L) 本身：Φ(L) 的 E5 另须 σ 对 L 的续行有非虚设的因果贡献（记 Ct，按本篇-H2 审查）。O\_P 成立不推出 Φ(L)；"取得律对象资格"与"由申报的 σ 承担律的续行任务"分开申报。计层用 O\_P；Ct、E5\_host、ActBind 都不计层。  
O\_P 的内容按上游原文读，不另加判据；Established、DynamicRole、ΩSupport 各按上游分别认证，互不推出，也不由 G\_loc 推出：G\_loc 只给位置，不含 Established 所需的完整关系承载（CarrierRealizes），也不含 DynamicRole 所需的非平凡动力依赖。DynamicRole 说的是：R 的相关状态真实进入 Rel(L) 所涉的后继生成，不是纯记录、纯相关、伴生迹或闲置结构；它不要求 R 是唯一原因，其他结构可以同时影响 L 的后继，多律可以共同作用。ΩSupport 说的是：对 I 中每一类实际适用覆盖的再入条件，都有入口可接达承担 Rel(L) 的结构，且其承担段满足申报窗口 W 内的稳定复走历史资格 Ω\_W = 1；这里不是单次复走事件，也不直接保证当前或未来仍可复走；历史资格与 Established、DynamicRole 共同承接为母本「持之势」的当前资格，另携 SC\_Hold。主书"律者，持之势也"（《内篇第九·经验场》）、"律者，复也，深也"（内篇），在上游即由这两项承担。

接受最强的合并对手：Q\_L = q\_L(H\_F, Rel(L), I)，O 由场的完整历史及其关系确定。下文不需要否认这一点。

全称必要性：对 𝒲 内任一满足 Φ(L) 的情形，由律组式必要向，必有 Established ∧ Govern 的 R（O\_P）；由第七节引理一、二，在每一续行事件的时刻，同一关系上的承担者 R\_t 在 Sed\_P 中，其相关状态 Q\_t 经执行链进入续行（O\_σ）。故 O\_P、O\_σ 必有。这些都是必要条件：Established、DynamicRole、ΩSupport 齐备，仍须按律组式完整认证，才说 O\_P 成立；G\_loc 是 Φ(L) 的本段位置条件，不是 O\_P 的必要条件。反例不可省：去 O\_P，回到一次强冲世界，S、D、G\_loc 俱在而对申报的 L，E5 不成立。

O\_P 成立之后还须回答一问，因为 E5 说驱动由 σ 承担：σ 的计算实施能不能代替场的承担，直接使 O\_P 成立？

不可替代引理　在 𝒲 内，在 H\_G、C0、查表条款与 E5\_car 下（经引理一），计算实施的事实不能替代 O\_P 所需的场承担与资格：凡 O\_P 成立，其承担者是 Sed\_P 中满足 Established ∧ Govern 的 R；τ 的规则内容、κ 中的规则状态、执行的事件与轨迹，本身都不是 Established、DynamicRole 或 ΩSupport 的承担者。凡声称由计算直接取得对象资格者，须经上游规定的场承担关系认证。引理证明的是资格承担不可替代，不否认执行对当前续行的因果作用：计算执行可以直接参与目标律的当前续行（Ct、CtPath），执行事实却不能直接代替沉积组织取得律资格。  
证明：由引理一（第七节（1）），R 是场的沉积承载组织，R ⊆ Org(Sed\_P)；τ 是固定的变换关系，按 C0 与查表条款，写在 τ 中的规则只存在于场外，不是沉积承载组织；κ 中的规则状态不满足 Pass（第三节），不属场的沉积承载状态，不是 R 的承担者；执行事件与轨迹是生成的过程与结果，不是生成所读的组织。O\_P 的三个分量都是 R 的资格（定义二），故其承担者不在上述任何一项中。∎

限定命题（路径）　另在 Θ 内、τ 固定、不计交付输入与外生控制构型的干预时：执行事实对 Established(R)、ΩSupport(R, I) 的改变只经执行驱动的 R 的场态更新——按 Ex 对每一实际更新事件逐一归责，不由见证链上的 W 认证；R 的场态在 Θ 内的其他改变来源是 E3 所排除者与不归于执行的自主变化。执行对 DynamicRole(R) 的实现只经执行链——其起点读入 R 的相关状态（引理二）；τ 固定，执行能读到的 R 只是 D\_P 中的部分。  
这一命题的强度到此为止。改变 τ 或更新协议是另一项任务的申报；交付输入、外生控制构型的许可干预（如角色屏蔽）可以影响律的续行而不经本段的沉积；D\_P 的段首场态来自 Θ 之前，按移植条款可使 O\_P 在段首即成立。这些影响最终仍须落实在 D\_P 的组织及其被读入上，不构成对不可替代引理的反例，但不在限定命题的路径之内。

第七、八节的递推次序：规则模拟逼出 G\_loc——律的承担者须在场内；一次强冲逼出 O——承担者在场内、被读入，还不等于成律。前者是"在不在"，后者是"成没成"。

边界，不构成失败：预装状态与移入的沉积，按移植条款可成律，G\_loc 与 O\_P 照常（GS3、GS4）；部署耦合下的场实现，携生成计算一般式-H3。

闭合，停止逼项。

九

O 已经得到，生成一侧在 E1—E5 上闭合。初始规定对生成不只说"驱动""生成"，也说"反作用"，而且是两重：  
其一，动力层自身：水流过之后又反蚀渠网，后续水流就这样持续与渠网交互，这一过程表现为渠网的动力，这就是动力层的生成（初始规定九）。  
其二，对象：动力的变化生成对象，对象以其持、择、偏、破等作用反过来作用于动力，使后续的流只能沿某种趋势走；这些运动都真实地来自宿载（初始规定十）。  
现在问：两重反作用在已逼出的结构中各在何处，是否打开新项；生成层级由什么区分。本工作域只含律，对象的反作用只检"持"；择、偏、破属理、概率、意向，在 U3。

第一重是动力层的本义。第五、六节所得的 Rd 是渠定流——沉积作为自变量被执行读入，定下后继的流向；W 与 Pass 是流改渠——实际经过者经执行沉积，改写此后被读的取值。二者合成一往一返：反作用后的势比之前变了，后续的流又与之交互。规则计算可以有反馈、状态更新乃至自修改，但反馈本身不构成沉积动力：跑出来有状态与反馈，它的状态却不因经过而深、不因少用而浅；只有在合格的可沉积性与执行归责下，历史经过才成为后续的动力条件。若宿载的规则中写有反作用规则（经过则深、少用则浅），这套规则就成了生成计算的驱动基底；而反作用的具体内容由实际经过形成，不由规则预先穷尽（第三节 E4、第四节 W）。第一重不能由宿载规则的一般执行替代：固定的 τ 对相同自变量给出相同后继（第二节）。它不打开新项——它就是 D。

第二重——律以持势反作用于动力——由宿载实际实现、经动力承担。按上游，律的支配是 R 的相关状态真实进入 Rel(L) 所涉后继生成（DynamicRole），其稳定复走是对每一类适用条件都能再入承担（ΩSupport）。在计算宿载中，这一作用经执行链实现（第七节引理二，依 E5\_host），被约束的流又按写入闸门刻深 R——仍是渠与流的往返。在上游运行基底 F\_LB 上可作如下核验（同深核验，附录 B 条目 A-1）：续行核只读局部的沉积深浅；一道被读沉积与已成律相同而不成律的强冲沟，在共用随机源下对后续流施加同样的约束（100 次交替再入中，a1 的 50 次续行两侧都走 a1→m1→c，窗口末的 g 与 Ω 读数相同；竞争扰动 30 次时两侧选边概率、命中数与末时刻的律侧前阶读出（Established^inst、ΩSupport^pre）逐项相同，60 次及以上两侧同样翻转，g 只在第三位小数相差 0.001）。这说明律的作用由宿载实际实现、经动力承担，正合初始规定：这些运动都真实地来自宿载（初始规定十）。  
它不说明律与动力同级。层级不按作用由什么机制实现区分（先行之辨一），而按所取得的资格区分。初始规定：在动力层之上，一部分持势被判准为律（初始规定十）——持势是动力层的事，被判准为律的，是其中压缩到稳定的那些。

于是分出动力层可以停留之处与跃迁之处。  
停留：一次强冲进入场，经实际经过留下明显新沟，新沟已入场、真实支配下一段后继（Established = 1，DynamicRole = 1），而不具稳定复走历史资格（Ω = 0，按现行上游即 Ω\_W = 0）；上游判定核在 ΩSupport 一环落判，对申报的 a1 ⇒ c 不成律（《律数理式》定理 4.13，《律运行基底构造式》LB2；第八节已写成计算）。动力在，持势在，律未成——动力层停在简单运转，没有生成对象。上游明言"一次强冲不自动形成 Ω"（《律一般式》C3）。  
跃迁：同一规则下，经反复经过，组织压缩到对每一类适用条件都在申报窗口内表现出稳定复走（Ω\_W = 1），取得 Established ∧ Govern，经《律必然式》充分向（携 SC\_Hold）进入律这一级。上游正例 LB1 场经判定核签出 R1 ∈ 𝒮，经回读与充分向条件化成律（第十一节证书）。形成轨迹的独立复核（开启模式，a1、a2 交替再入，共用随机源，判定核逐次判定；附录 B 条目 A-2）：LB2 强冲场（单次 p = 20）t₀ 判 FAIL @ ΩSupport(ΩOK)，自 a1 第 1 次再入后仍不成律，第 2 次再入后判 PASS（rep = 3，Ω = 0.5）；一个被读沉积与 LB1 匹配而不成律的强冲场 B，t₀ 与第 1、2 次再入后不成律，第 3 次再入后判 PASS。两例的次数不同，都只是本参数与本协议下的历史结果，不是普遍阈值；判定核 PASS 只是 R1 ∈ 𝒮，升为 Law 携 H\_cert。须分清其中两种反作用：取得资格以前，强冲沟已制约当前流变、又经流变改写自身——这是动力层的反作用，不需要先成为律；取得 Established ∧ Govern 以后，其持势才作为已成律的对象作用被认证。对象由动力层的反作用生成，不是先有对象反作用才有对象。  
故：动力成立 ⇏ 律成立；律成立 ⇒ 存在已成、支配后继且具稳定复走历史资格的沉积组织。前者由停留之例，后者由引理一与律组式必要向。跃迁的条件，按上游即 Established ∧ Govern——初始规定所说动力层逐渐压缩输入、产生对象（初始规定十二）在上游的落实。

本节不打开新项：第一重反作用即 D；第二重由宿载经 D 实现，其所属层级由资格判定，留第十一节。

十

κ、Pass、W、Rd、G\_loc、O\_P 已经得到，两重反作用已安放。还须另立什么吗？

一、κ 中的规则状态另立一项职责：它可以承担 E2 的差异（跑出来），却不取得可沉积性，不使组织能承担"历史成为动力"；删去它，Φ 的任一款不因此失败；它是计算本身的状态，在 S 之内。不须另立；它不另成一级，见第十一节。  
二、W、Rd 各立一项职责：它们是 S 与 D 之间的驱动与读入，是 S、D 的承接关系本身，不另有作用职责；W 是 E3（ii）的实施展开，Rd 是 E2、κ 的实施展开；写入而不被读的副本是 Φ(∅) 的失败情形，连 κ 也不成立，不是某一职责的合法完整情形。不须另立。  
三、每一步都改写 D：冻结推理中 D 不变而历史照常成为动力（GS2；第六节 H1 条件）。不须另立。  
四、D 由本段形成：移入的沉积、手工写入的初值（GS3、GS4；移植条款）。不须另立。  
五、每段都生成新律：Φ(∅) 闭合不需要律；Φ(L) 只要求 L 续行，不要求在本段形成。不须另立。  
六、S 与 D 分在不同模块、不同存储：先行之辨一、三；层位不以模块计。不须另立。  
七、O 被识出或被判准：先行之辨四；O 指场的事实，识出另属他组式。不须另立。  
八、O 在因果上独立于场的完整历史：G\_loc、O\_P 与不可替代引理的证明都不用到它。不须另立。  
九、训练另立一项职责：训练是势引，从外部改变流径；它使 D 的轨迹如此，不在 S、D、O 之外另承担 Φ 的一款。不须另立。  
十、理、概率、意向的特有职责：理的反持、概率的分布、意向的取向，是否另成一项职责，本篇未答（U3）。它们的律侧部分不打开新约束（推论四）。  
以上九项不须另立，第十项未答，不进入总式。拟增项检查只说明所检验者不打开新约束，不单独证明不存在其他必要职责；层数的上界见第十一节。

回到同一任务：σ 若承担 Φ(∅)，必有固定变换关系的执行，与满足可沉积性、段内由这一执行驱动更新、为这一执行读入的历史条件。σ 若承担 Φ(L)，律的承担者必是 P 的沉积场中的已成组织并取得 Govern，其相关状态经执行进入续行（它不必与承担 E2 见证的那部分同一）；计算实施的事实不能替代这一承担。第二至八节的失败情形都已排除，拟增项无一打开新的约束，余下一项列为未答；原问题在 𝒲 内、必要方向上闭合。闭合指不再有已知的未闭合处，不是充分性（U1）。

十一

结构已经闭合，两重反作用已安放。现在回到总命题：分层吗？分几层？

计层单位按先行之辨一：初始规定所说的生成层级与反作用关系（初始规定五前款、七、九、十）。层以生成资格区分，对逻辑公式的拆分、变量命名、执行机制的合并保持不变。按原子个数计层、按任务条款的个数计层、按函数位置或物理机制的个数计层，都不取：一个程序从没有缓存变成有缓存，或从没有速度变量变成有速度变量，不意味着它生成了新的动力层；把 Established 拆成三个更细的条件，也不意味着对象层多出两级。

对下一级候选 X 与上一级候选 Y，Y 是 X 之上的一级，当且仅当以下五条各有独立见证：  
（一）新资格：Y 有 X 所没有的资格；  
（二）可停留：存在合法的完整情形，X 成立而 Y 不成立——X 可以停留，不必生成 Y；  
（三）不可由下级认证：只凭 X 的已有资格不能认证 Y；认证取上游已立的判据与见证，须有独立的退化见证，不得仅由 Y 的定义推出；  
（四）任务所需：这一资格为申报任务所必需；  
（五）生成资格的层级性：Y 的资格具有以 X 类生成为合法依托的来源——由 X 类的合法生成历史及其组织取得，或属于这种来源下、满足上游移植与保持条件的合法承接；不要求 Y 在所考察的 σ 中形成，也不要求由当前这个 P 曾经亲自生成；预装的资格仍按上游条件判定，不因预装而自动合格。该资格使组织能够承担此前尚未取得资格的申报生成关系——"此前"指资格取得以前的生成层级状态，不必是本段计算的前一时刻；这一变化可以是稳定持势、适用覆盖或其他上游已认证的对象资格，不要求新增执行机制。  
第（五）条保证上级的资格确有合法的生成来源，而不是任意规定的名称——若只有（三），任何人为规定的资格都会"不可由下级认证"；它也规定了什么算一次升级：完整取得一项新的申报生成关系，中间资格不算。这一计数口径的来源是初始规定对层的规定，不是为得出某一层数而加的排他条件：初始规定以生成了什么来命名层——生成计算先驱动生成场动力，这一级称为动力层，再由场动力生成律、意象等上层对象，这一级称为对象层（初始规定五前款）；对象层的成员是被判准为律等对象者，在动力层之上，一部分持势被判准为律（初始规定十）；对象本质上也是动力（初始规定十二），未被判准为律的持势留在动力层。依此，一个层由其生成物的完整资格种类界定：取得了律的完整资格者在对象层，具有部分律资格而未取得完整资格者（如有当前支配而无稳定复走的持势）仍在动力层；中间资格不另成层。这是依初始规定所作的计数约定，在 𝔇 内使用；它不由 E1—E5 单独推出，故由它得到的上界称为申报资格层级计数定理，不扩张为生成结构的绝对最少层数定理。它不要求 Y 有 X 所没有的另一种执行反馈方式：第九节已见，成律与未成律的组织可以在一段合法比较中有相同的实际流变。另检隔级：隔一级的下级的事实，不能替代 X 对 Y 的承担（不可越过）。  
本节一切判断只用必要方向：某一资格的已证必要条件缺一项者，不能取得该资格；必要条件齐备者，仍须经完整认证——对 Rel0 是 E1—E4 的任务认证，对 RelL 是律组式的完整认证。

候选：闭合结构中的 S、D、O。κ、Pass、W、Rd 是 D 的必要条件与承接关系，G\_loc 是 Φ(L) 在本段的执行位置条件（第七节），不是 RelL^obj 的必要条件，不是候选层级。

先检 S 与 D。  
（一）新资格：D 所具的是 Rel0 所需的可沉积动力资格——在承担 E2 差异的 κ\_sed 上 Pass ∧ W ∧ Rd，渠定流、流改渠所形成的动力条件。  
（二）可停留：算出来（无 κ）与跑出来（有规则状态而无 Pass）是合法完整的计算，S 成立，D 不成立——宿载可以只执行规则，不生成动力。一个把正确轨迹的取值写成程序常量的查表程序，常量不随历史而异，也只有 S。  
（三）不可由下级认证：固定的 τ 对相同自变量给出相同后继，不承担历史差异（第二节）；规则状态可以承担差异，却不满足可沉积性（第三节）。独立退化见证：跑出来——跨步因素、执行更新、执行读入俱在，可沉积性失败。若令规则状态满足可沉积性、段内由执行驱动更新、为执行读入，它就已取得 D 的资格。  
（四）任务所需：Rel0 ⇒ κ ∧ Pass ∧ WR（第二至六节）。  
（五）生成资格的层级性：分资格形成、资格承接与当前实现三件事。资格形成——D 类资格的合法来源是执行写入（W）、实际经过在执行中刻成沉积（Pass）的历史，所依场历史合法（E3），即以 S 类生成为依托；资格承接——冻结、移入的 D 由段首场态承接，携本篇-H1，不要求本段重新形成，也不称本段完成了流改渠；当前实现——σ 的执行读入承担见证的沉积（Rd）。D 使组织能承担 Rel0；S 不能。认证不按变量名：跑出来的速度是跨步变量，却不取得可沉积性；一个只挂沉积之名、不按经过深浅的变量不取得它（第五篇 Sed（i）的同名算子例）。  
D 是 S 之上的一级。（不可越过在两级之间无所施。）

再检 D 与 O。  
（一）新资格：O 所具的是 RelL^obj 所需的律对象资格 Established ∧ Govern，按律组式完整认证，不以 Ω 的数值单独代替 Govern。  
（二）可停留：一次强冲世界（第八、九节），D 与 G\_loc 完整成立，Established = 1，DynamicRole = 1，ΩSupport 不成立，对申报的 L 不成律——动力可以停留于简单运转。  
（三）不可由下级认证：同一强冲世界中 D 的资格全部成立，上游判定核仍在 ΩSupport 一环落判。认证取上游已立的判据与见证（律组式：必要向 Law ⇒ ∃R\[Established ∧ Govern\]，携 H\_G，充分向携 SC\_Hold；《律数理式》定理 4.13；《律判定式》判定核），不由 O 的定义推出：强冲沟是独立构造、经上游机器判定的退化见证。  
（四）任务所需：RelL^obj ⇒ Established ∧ DynamicRole ∧ ΩSupport（律组式必要向，携 H\_G），且由引理一 R ⊆ Org(Sed\_P)；Φ(L) 另由引理二给出 G\_loc（第七、八节）。  
（五）生成资格的层级性：O 的资格有合法的场内生成来源——承担者须是场的当前沉积承载组织（C0、Established），只存在于场外的查表关系不成立（查表条款）。Φ(L) 说的是 L 在 σ 中续行，不要求 R 在 σ 中生成：冻结续行中，已取得的资格由当前场态继续承担；移入、预装的 R，其历史来源与资格承接按上游移植条款确认（第八节边界）。合法形成来源的实例见证：同一更新规则下，强冲场在再入中经动力层自身的反作用被判定核由 FAIL 判为 PASS（第九节，LB2 第 2 次、B 第 3 次再入，非普遍阈值，PASS 升为 Law 携 H\_cert）；这一见证用于层级区分，形成的一般最小结构仍属 U6。所改变的是该组织对申报关系 L 所能合法承担的资格：由当前支配到稳定持势。不要求新的执行机制：Ω 不进入运行律，律的作用由宿载经动力实现（第九节），不因此并入 D。  
不可越过：S 的事实不能替代 D 对 O 的承担——不可替代引理（第八节）；见证为规则模拟、查表程序（场中无已沉积的 R1；附录 B 条目 A-4）与同一执行模型的旁路系统 τ\_C（第七节：场中 R1 有合格沉积，续行由规则规定，L 不成律；附录 B 条目 A-3）。  
O 是 D 之上的一级。

判据的来源与非循环性。两次检验的判据逐项来源如下，均不由"先定义 Y 为上一级"推出"Y 是上一级"：  
S → D。（1）资格内容：Rel0 = Φ(∅) 由 E1—E4 给出，其必要项 κ、Pass、W、Rd 由第二至六节逐轮逼出或展开；资格内容不来自层的定义。（2）下级停留的完整合法见证：纯函数程序与规则状态程序（跑出来）都是合法完整的计算，S 成立而 D 不成立（附录 B 条目 A-5）；查表程序同（A-4）。（3）不可由下级认证：跑出来具有跨步因素、执行更新与执行读入，可沉积性仍失败——这是独立构造的事实，不由 D 的定义推出。（4）合法形成或承接：开启运行中执行写入、读入（F\_LB 的形成段与强冲段）；冻结、移植段由段首场态承接，携本篇-H1。（5）性质：（1）至（4）都是生成事实或上游与本篇的必要性结论；把 S、D 记为"两级"而不是更多，依赖第（五）条的计层约定。

不另成级的候选，逐项按五条：  
规则状态（跑出来）：不使组织能承担 Rel0（可沉积性失败），不满足（五）；属 S。  
不由执行驱动的沉积动力（器件环境漂移，第四节）：不由 S 的实际生成取得，不满足（五）；它在计算宿载的生成链之外。  
纯定位 G\_loc：是 Φ(L) 的本段位置条件，只表示 P 的沉积场中某一组织被指定为 L 的候选承担者，不含新增资格，不是候选层级。凡还要求 Established、DynamicRole 等新增资格者，按下一项检验，不因名为定位而合层。  
已成且有当前支配而无稳定复走（一次强冲）：组织有真实动力作用，但不具完整律资格，不使组织能承担 RelL；不满足（五）；属 D。  
单独的稳定复走（场中 R1 已建立、Ω \> 0 而不被读入，τ\_C 一例）：Govern 须 DynamicRole ∧ ΩSupport，不使组织能承担 RelL；不满足（五），不独立成级。  
对象的反作用：经宿载和动力实现，不另为一级；也不因经动力实现而把 O 并入 D——O 的区别在资格，不在机制。

最少层数。分四项申报。  
（甲）全称必要（下界）：  
　Φ(∅)：S、D 为任一满足 Φ(∅) 的合法结构所必有（第二至六节），且 D 是 S 之上的一级，故满足 Φ(∅) 者至少有两级。携计算执行一般式-H3、生成计算一般式-H1、H2、本篇-H1。  
　Φ(L)：S、D、O 为任一满足 Φ(L) 的合法结构所必有（第二至八节；缺 O 则律不续行，一次强冲世界），且 D 是 S 之上的一级、O 是 D 之上的一级，故满足 Φ(L) 者至少有三级。另携 H\_G、E5（run、car）、初始限定 E5\_host 与本篇-H2（同总定理（二））。  
（乙）申报资格层级计数定理（限定上界）：在第十一节的生成资格层级判据及仅含 Rel0、RelL 的工作域 𝔇 内，任一合法结构在这两项申报关系上取得的申报生成资格级数至多三。  
　证：由（五），每升一级须使组织能承担一项此前未获资格、并已完整取得的申报生成关系；中间资格不算。𝔇 中申报生成关系只有 Rel0、RelL 两项，故 Layers\_𝔇 ≤ 1 + 2 = 3。同一项关系不能由两级先后取得：Rel0 只有经 E1—E4 的完整任务认证才取得动力生成资格，κ、Pass、W、Rd 是其已证的必要承担条件——缺少任一项者不能取得该资格，全部齐备者仍须通过任务认证；故 S 与 D 之间缺项的资格都不能取得 Rel0。RelL 同理，以律组式的完整对象资格为准：Established、DynamicRole、ΩSupport 是 RelL^obj 的必要资格分量，各按上游在同一关系、适用域与认证时刻上判定；缺失任一分量，不能取得该律对象资格；各分量的必要条件齐备，也不得代替完整认证。故 D 与 O 之间缺项的资格都不能取得 RelL。O 之上，𝔇 中没有第三项申报关系。∎  
　G\_loc 不属于 RelL^obj 的定义，也不是其一般必要条件。它是申报任务 Φ(L) 在 E5\_run、E5\_car、E5\_host 下由第七节两座承接桥推出的本段执行位置条件：律已在 P 中成立而 σ 不运行目标关系时，RelL^obj 可以成立，G\_loc 可以不成立——这不影响律的对象资格，也不满足本段申报的 Φ(L)。故对象资格的完整取得与本段任务的执行归责分别认证：D 与 O 之间尚未取得完整 RelL^obj 的中间资格不另计为申报生成层级；本段执行位置与贡献路径也不因另有判据而增设层级。O 的计层依据仍为上游 Established ∧ Govern，任务接口另以 G\_loc、ActBind、CtPath 与 Ct 承担。  
　这一证明计的是申报生成关系的个数，不计原子：把 Established 拆成更细的条件、给变量改名、合并执行机制，上界不变。它只用必要方向。它的力量来自（五）——每一新增层级须完整取得一项尚未取得的申报生成关系，同一关系的中间资格不单独成级——与 𝔇 只含两项申报关系的限定：它是这一判据与工作域下的计层定理。由它推不出，具有同一计算任务与律对象的系统在更一般的生成分解下不可能另有一级；它也不是"自然界或一切计算系统至多三级"，不是对一切潜在生成层级的排他上界。  
（丙）可满足性：Φ(∅) 在 𝒲 内可满足——F\_LB 的开启运行（第八节的强冲段；其 E4 由《最小沉积场构造式》对 F\_min 的 C1—C7 构造与 F\_LB 的保持性给出实例认证）。Φ(L) 在 𝒲 内的可满足性携 H\_cert 与本篇-H2，另携下文证书（v）所列组内条件（计算执行一般式-H3、生成计算一般式-H1、H2 与本篇-H1）——F\_LB 正例（下文证书）：律对象资格按上游承继，条件化成立，σ 的非虚设贡献由本例的实例证书给出；本篇-H2 是一般归责协议的条件，实例是否满足按证书申报，不以条件符号代替认证。  
（丁）最少层数：携总定理（一）的条件（Φ(L) 部分另携（二）的条件），并以（丙）的存在实例为条件：MinLayers\_𝔇(Φ(∅)) = 2；H\_cert ∧ 本篇-H2 ⇒ MinLayers\_𝔇(Φ(L)) = 3。MinLayers\_𝔇 是所有合格实例上申报生成资格级数的最低值，不断言每一满足 Φ(∅) 的实例都恰有两级：某一满足 Φ(∅) 的实例同时已有律，不推翻其最小值为 2；具体系统具有 Rel0、RelL 之外的生成资格时，Layers\_𝔇 不计。MinLayers\_𝔇 不是未经限定的"计算生成结构的绝对最少层数"；实际生成过程中是否另有更细的必要分级，属 U2。不携 H\_cert 时能说的是：在（甲）所列条件下（含本篇-H2），凡满足 Φ(L) 者至少有三级、在 𝔇 内至多三级，而 Φ(L) 在 𝒲 内的可满足性未经无条件认证。  
界限：这是申报生成资格链的最低层数，不是证明任一具体计算系统只有两个或三个功能层位。  
可证明的是五项：S 的已有资格不足以认证 D；D 的已有资格不足以认证 O；S 的执行事实不能替代 O 的场内承担；两次资格跃迁各有合法退化见证；在 𝔇 的计层规则下只有 Rel0、RelL 两项可计的完整申报生成关系。  
强度分级。三种强度分开陈述：其一，两次不可合并的资格跃迁（S → D，D → O）——由生成事实、独立退化见证与上游判据给出的必要性论证，携所列 H；其二，在 𝔇 内恰为三级——依第（五）条的计层约定与上界证明，有条件成立，正向实例携 H\_cert 与本篇-H2，另携证书（v）所列组内条件；其三，完全不依赖计层选择的绝对最少三级——未证。三者不混称。  
自此，S、D、O 分别称宿载层、动力层、对象层。

对象层的正向形成见证——完整证书。动力组织跃迁到律这一级的正例，按上游已签出的结论承继出示。取上游运行基底 F\_LB 的正例：LB1 场（外生交替 120 脉冲，a1→m1→c 与 a2→m2→x 各 60 次）形成后，在冻结模式下运行。申报 L = L\_{0.9}：a1 ⇒ c，职责 J = (Ante：p = 1 入 a1；Anchor：m1→c；Read：经 c 的路径测度 ≥ 0.9)，I = {a1}，R1 = {a1→m1, m1→c}。分五栏出示：  
（i）计算承担与执行。P 为执行 F\_LB 参考实现的计算设备；τ 为 F\_LB 的更新程序，Θ 内固定；σ 为冻结运行段，每一次内生脉冲是 P 对 τ 的一次执行，Ini、Run、Out 由程序的启动、运转与写出给出（承计算承担一般式、计算执行一般式，携其 H）。E1 成立。  
（ii）E2—E4 与见证链。先冻结比较投影。π\_cmp 的成分在 σ 之前按任务侧的申报规则确定：第五篇扩展状态划分把"当前结构与关系"与"动力条件"分开申报，上游《律运行基底构造式》§3.4 把 F\_LB 的量分为即时量（上游记作 τ、κ、q，即当前迹应 τ\_LB、续行核值 κ\_LB 与脉冲当前所在位 q）、持久沉积量（d、g、rep）、派生量（阈状态 S\_e、Γ、Ω）、外生控制量与时钟。据此，π\_cmp 只含：τ（Spec\_LB 的更新程序与 §5.2 参数，含 θ）；本步输入（入口位与 p）；外生控制构型（Mask、Avail、SED）；申报的当前结构读出（脉冲当前所在位 q）。持久沉积量 d、g、rep 及其函数 S\_e、Γ、Ω 是申报的跨步历史条件，不入 π\_cmp。S\_e 进入续行核，但它是 τ 在一步之内由 g 与 θ 算出的量，不是当前结构读出；π\_cmp 中没有任何一项能唯一确定 g。  
再给一对完整合法比较状态。取上游构造式自检所用的一对实例 H₁、H₂：同一初态 fresh(8)，同一规格与参数；H₁ 作 30 轮"a1 沿 a1→m1、a2 沿 a2→m2"的交替外生脉冲，H₂ 作 30 轮配对相反的"a1 沿 a1→m2、a2 沿 a2→m1"；二者都由 Prot\_LB 产生，属 Inst(Spec\_LB)。比较时刻取二者历史之后、下一脉冲 p = 1 入 a1 之前：τ、本步输入、c、q 全同，π\_cmp(H₁) = π\_cmp(H₂)；且各结构位的 d 在退浅次序抖动之内相同（自检 same\_d）。而 H₁ 在 a1 处 P(m1) \> 0.9，H₂ 在 a1 处 P(m1) \< 0.1（自检 diff\_g）——π\_cmp 相同、连 d 也相同，后继有差异，差异只能由 g 承担。E2 成立，见证状态完整、合法、可复跑。  
E2 说的是"后续实际变换有因果差异"。以共用随机源比较实际执行：在 a1 处以同一均匀抽样 ξ 选边（ξ \< P(m1) 取 m1），H₁ 在 ξ \< 0.9 时取 m1，H₂ 在 ξ ≥ 0.1 时取 m2，于是在 ξ ∈ \[0.1, 0.9\]、测度至少 0.8 的抽样上，二者实际所走之边不同。差异在实际执行上见证，不只在分布上；第五篇推论二亦以相同随机源作比较。

十三、推论

推论一（宿载层是规则变换）　分两层陈述。普遍性：承担 Φ(∅) 的任一 σ 含 S，S 是固定的 τ 在 P 上的执行，每一执行节点是固定的规则，按初始规定属规则变换（初始规定三）。特定性：在承担 Φ(∅) 的 σ 中，D 的合法来源是执行写入、按经过刻成的沉积（第十一节 S → D（五））；承担这一写入的规则——迹应关系、沉积律等宿载基本规则——是 τ 的组成部分，或经合法承接的 D 由带有这类规则的执行形成。故生成计算包含规则计算，规则计算发生在生成计算的宿载层（初始规定十六）。这里的规则计算指宿载基本规则的执行，不意味着生成计算同时承担一项模拟外部对象规则的任务。  
证明：普遍性由总定理（一）与 E1：S 成立，τ 在 Θ 内固定。特定性由第三、四节（Pass、W）与第十一节 S → D（五）；"τ 在 Θ 内固定"一项单独推不出 τ 是宿载的基本沉积规则。∎  
算出来与跑出来是 S 单独成立的规则计算，其 τ 是对象规则；生成计算的宿载层也是规则计算，其 τ 是宿载的基本规则。二者同为规则变换，所执行的规则不同。

推论二（计算实施不能越过沉积场承担直接取得律资格）　在 𝒲 内、Φ(L) 下，携总定理（二）的条件（经不可替代引理用 H\_G 与引理一的前件，经引理二用 E5\_run、E5\_host、计算执行一般式-H3 与生成计算一般式-H2，经 CtPath 用本篇-H2），计算实施不能越过实际沉积场的承担直接取得律资格：律资格的承担者是 Sed\_P 中的 R，其相关状态 Q 经执行链进入续行（引理二）；当前续行可由实际贡献的执行子链参与（CtPath），包括 R 之外的信号与状态；律资格由场组织承担。在资格的意义上，计算对律没有直接的结果贡献——此即初始规定五后款在资格意义上的条件化读回——宿载的计算定下的是动力层的规则；这不否认执行对当前续行的直接因果参与（Ct）。交付输入与外生控制构型的许可干预可以影响律的续行，见下文边界。  
证明：由不可替代引理、引理二与 CtPath。∎  
本推论不涵盖外生控制构型的许可干预、交付输入的影响与任务的重新申报；它们对律的续行的影响另判。运行外直接写入 Sed\_P 违 E3（侵入），改的仍是动力层，其后果归第十《计算复现失真源式》。

推论三（轨迹相同而律资格不同，可检验）　在以下资格前件下，可以构造一对合法过程，在相同初态、相同交付与相同随机源下，L 的对象轨迹逐步相同，一者 L 取得律资格，一者没有：  
甲：一个实现了合格场的网络在冻结模式下运行（GS2）；L 在其中的律资格经《律判定式》判定核独立签出——例如上游参考实现的正例在冻结运行下 PASS。不得仅凭"已训练""冻结权重"或"轨迹正确"认定甲的律资格。  
乙：把甲的冻结权重写成 τ₂ 的规则常量，τ₂ 的规则构造为与甲的续行核相同的变换（第五篇推论二第（4）对）。乙是合法的规则程序；支配 L 轨迹的结构写在 τ₂ 的规则中，按 Established 的查表条款与 C0 不是场的沉积承载组织，L 在乙中无律资格。这一认定只及于目标 L，不及于乙中别处是否另有已成结构。  
甲、乙每一步读入的结构、输入与随机源相同，续行核相同，故 L 的对象轨迹相同。若要乙满足 Φ(∅)，可另加一段与 L 的续行无关的 D 回路；它只保证另有一份实际动力，不使 L 取得资格。  
证明：轨迹相同由第五篇推论二第（4）对的证明；甲的律资格由前件，乙的无资格由不可替代引理。∎  
由此，轨迹或续行核相同，不推出在目标系统中具有相同的律资格；只看对象轨迹，不能判定律是否宿于 P。  
同型而更强的一例在同一执行模型中给出（第七节 τ\_C）：场态与甲逐项相同、合格沉积未屏蔽，只把 a1、m1 两处的续行交给程序规则，100 次路线与甲逐步相同，L 不成律，同一系统中另一关系 a2 ⇒ x 仍成律。

推论四（理、概率、意向的律侧）　理的 Law(P)、概率各维之律、意向经其取向至概率之律，凡为律者，总定理（二）对它们成立，各携其组式的必要向条件（概率一侧，《概率一般式》v1.1 必要向现为 H2 ∧ H3^red ∧ SC\_Hold）。各类特有职责是否另成职责，未答（U3）。

推论五（三种"出来"）　算出来：S，且无 κ；跑出来：S 连同规则状态，无 D；生成出来：S 与 D，律续行时连同 O\_P 与 O\_σ。三者的差别在结构，不在步数，也不在输出。初始规定所说律从宿载中长出（初始规定八）含形成一义；以上给出的是续行时的结构，形成的最小结构属 U6。

推论六（层级跃迁）　在 𝒲 内，就本式申报的律对象资格：动力层可以停留于简单运转而无对象生成；动力层的组织取得律对象资格，当且仅当按上游取得 Established ∧ Govern（充分向据《律必然式》，携其条件，即 v1.4 的 SC\_Hold，判定核 PASS 读作律资格时另携 Ω\_e 补检，二者并入 H\_cert；必要向据律组式，携 H\_G；完整承继律组式的适用前提）——即初始规定所说动力压缩而产生对象。这一刻画只及于律；理、概率、意向等其他对象的形成不由它解决（U3、U4）。同一宿载规则下，有的历史停留（一次强冲），有的跃迁（上游正例；第九节中 LB2 强冲场在第 2 次、匹配强冲场 B 在第 3 次再入后判定核判 PASS——都不是普遍阈值，PASS 升为 Law 携 H\_cert）。  
证明：由第九节、第十一节与律组式双向刻画。∎  
由此，宿载规则不预先决定会生成哪条律；计算所能定下的，是动力层的规则。

十四、最小性与承重

承重来源逐项扣除：  
κ：E2、E3 在固定 τ 下的直接展开；执行归责承继 Ex。不计新。  
Pass：E4 与写入闸门；段内无更新时由本篇-H1。不计新。  
W：E3（ii）的实施展开，判据承继 Ex。计新的只有一处归责定位：仅 E3（i）不足以排除器件环境沉积，E3（ii）负责排除，W 把它落到同一见证链上 σ 内的沉积更新事件本身。  
Rd：E2、κ 在 κ\_sed 上的直接展开，判据承继第五篇；不以独立反例逼出。不计新。  
S、D 的整合与反作用循环：由承继与上述各项直接得出；把 Rd 与 W、Pass 认作渠定流、流改渠的一往一返，是初始规定中水流过之后又反蚀渠网（初始规定九）一说的读回。不计新。  
G\_loc：C0、查表条款承继律组式；E5 是前件。计新的是两座桥：引理一把上游律承担者放进 P 的沉积场（Established 的定义、C0、E5\_car），不用 D\_P、Ct；引理二由 E5\_run、E5\_host 与 DynamicRole、FixedNoHist 推出本段执行读入承担者的相关状态 Q，不用 but-for，不另列 H——它分开了"律在系统中成立"与"律由本段续行"。另：A、B 两回路的分离（L 的承担者不必与 E2 的见证同一）；CtPath 只取可证的弱形式。  
O\_P：内容全部承继律组式，不计新。  
不可替代引理：计新。引理一、二只给出 O\_P 的承担者的位置与本段读入；引理给出的是计算实施的各类事实都不是 O\_P 的承担者。  
层的检验（第十一节）：计新的是把三者合为生成层级——以初始规定的生成层级为计层单位，S、D 之间与 D、O 之间各以新资格、可停留、不可由下级认证、任务所需、生成资格的层级性检验，隔级以不可越过检验；D、O 之间的可停留与不可由下级认证，见证承继上游（一次强冲、判定核），本篇所作的是把它们放进计算侧的层级。限定上界的证明计新：每升一级须完整取得一项新的申报生成关系，𝔇 只申报两项。  
承重归属：κ、Pass、W、Rd 的大部分内容是前件与承继的展开；O 的资格完全取自律组式；本篇的增量在关系——生成层级在撤去层位规定之后由生成职责逼出，各级资格不可替代，计算越不过动力取得律。

独立退化：去掉一项、其余按原义保持，各留下一种不承担 Φ 而被算作承担的情形——去 κ 为算出来，去 Pass 为跑出来，去 W 为器件环境沉积，去 G\_loc 为带闲置 D 回路的规则模拟或 τ\_C，去 O\_P 为一次强冲世界。

不可合并：S 与 D，D 与 O，各由第十一节（二）（三）（五）——下级可以停留，停留者当不了上级，上级的资格由下级的生成取得；S 与 O，由不可替代引理。

最小性的含义：κ、Pass、G\_loc、O\_P 各由一个保持此前各项而不承担 Φ 的情形逼出，W 是 E3（ii）在沉积更新上的实施定位（器件环境沉积为其边界例），Rd 由 E2 与 κ 直接展开；去掉 κ、Pass、W、G\_loc、O\_P 中任一项，留下被算作承担的不承担者；相邻两级的资格有合法生成来源且不可由下级认证，故 Φ(∅) 不少于两级、Φ(L) 不少于三级；在 𝔇 内，每升一级须完整取得一项新的申报生成关系，故至多三级；可满足性另行申报（Φ(L) 携 H\_cert 与本篇-H2，另携总定理（四）所列组内条件）。这是 𝔇 内的限定结果。逐项删除导致失败，不等于一切更弱的替代结构都不能成功：以 Ψ 记本篇所得必要结构的合取，任取不恒真的条件 X，Ψ ∨ X 也是必要条件且更弱，故最小性只能相对于一族许可候选结构——以宿载层与场的事实为分量、能排除第二至八节各失败情形者——提出，其中是否另有更弱或更细的分级，未答（U2）。

击穿论证

击穿方式：在总定理的前提、E1—E5、任务侧条件、𝒲 与相应 H 保持时，展示：Φ(∅) 成立而 κ、Pass、W、Rd 之一不成立；或 S 中未取得 D 资格的组织承担了历史差异；或展示律在 P 承载的系统中由 σ 驱动续行，而其支配结构不在 P 的沉积场 Sed\_P 中，或 σ 在 L 的续行中不读入其任何相关状态；或 D 蕴含 O——任何动力都已是律；或未取得律资格的动力组织承担了律资格（击穿上游判定）；或计算实施的某一事实本身承担了 Established、DynamicRole 或 ΩSupport。对最少层数：证明 S、D 或 D、O 可以合为一级；或在 𝔇 内给出一个满足第十一节五条、却不完整取得任何新申报生成关系的上一级；或给出缺 Rel0、RelL 某一已证必要条件而仍取得该关系的组织。  
不构成击穿：律的作用由宿载经动力实现、不要求另有独立执行机制（第九节的同深核验）——层级不按机制计。

反例一：器件的物理迹应。  
同一块会随电流漂移的存储器件，在两种申报下归类不同：作为器件的环境性质，段内的更新不由执行驱动，W 不成立，归非计算宿载的动力（第四节）；被合法申报为 τ 的实施组成部分并由本次执行驱动，W 成立。区分落在归责上，与初始规定的两种宿载动力之分相合，不是击穿。若律的承担者对续行的作用经前一种漂移而不经执行，律在这一部分上宿于介质而不宿于计算，E5\_host 不成立（第七节（2））。

反例二：只部署推理的宿载。  
宿载中不实现任何沉积算子，只以训练所得的 κ\_sed 运行，沉积在另一系统中发生。σ 内无沉积更新，W 平凡成立；Rd 成立。其 κ\_sed 是否满足可沉积性须由本篇-H1 与生成计算一般式-H3 判定；在判定之前，相应结论为 ⊥，不为 0。既不被总式排除，也不构成击穿。

反例三：预装状态与移入的沉积。  
Sed\_P 的段首场态来自别处，O\_P 在段首即可成立。这在限定命题所列的边界之内，不是计算对 O\_P 的替代。G\_loc 与 O\_P 照常。不是击穿。

反例四：角色屏蔽与交付输入。  
经外生控制构型的许可干预屏蔽 R，或改变交付的输入，L 的续行随之改变而 Sed\_P 未在本段沉积。这在推论二与限定命题的排除范围之内；承担者仍是 Sed\_P 中的 R。不是击穿。

反例五：训练。  
外部的误差与优化器决定了 D 往哪里沉积。按初始规定，这是势引，不是沉积场的基本规则；段内的沉积更新仍由执行驱动。不是击穿，也不另立一层。

反例六：脑。  
脑中有动力，有律理，而其驱动是营养，其动力条件与计算无关（初始规定六）。它不满足 E1，不在 𝒲 之内；它说明动力与律可以没有计算的宿载层，是边界，不是击穿。

反例七：同一程序兼任 S 与 D，同一载体兼有 D 与 O。  
层不以模块、载体或机制计（先行之辨一）。不是击穿。

反例八：统一场变换核与"同深不同律"。  
一个核同时实现沉积、承接与已成律的支配；被读沉积相同而一成律一不成律的两场，后续流变在第九节同深核验的读数上相同（a1 的续行逐次相同，窗口末沉积读数相同；附录 B 条目 A-1）。这说明律的作用由宿载经动力实现，不说明律与动力同级：不成律者没有稳定复走，上游判它不成律，它是停留在动力层的持势。不是击穿。

反例九："计算算出了问答律"。  
把语言模型中的问答律说成计算的直接产物。按推论二与不可替代引理，这是越层的误读，不是对总式的反例；其消解属第九《计算越层误置消解式》。训练可以经梯度等方法改变权重、影响行为；但从"权重调到某值"或"输出合乎目标"，推不出相应问答律已以沉积场资格成立。

因此：有状态不等于有动力，有动力不等于有律；规则能复现律的轨迹，替代不了律所需的场；动力要压缩到稳定才进入律这一级；计算与律之间，必须隔着一个由计算驱动、渠流往返、律在其中取得资格的动力层。

缺口申报

结语

撤去层位规定，只留下"历史成为动力"与"律在续行"，逼出的结构闭合之后仍然分层：宿载执行写定的规则，其中有反作用规则，却不写定会长出什么；动力在渠与流的往返中刻下历史，规则替它刻不出；律是动力压缩到稳定而成的那一级，动力可以停留而不到这一级，计算越不过动力取得它。律的作用由宿载实际实现、经动力承担，这不改变它在生成中的位置。本篇所得是申报生成资格链的最低层数——不涉对象两层，律续行三层——不是说任一计算系统只有两个或三个功能层位。

本篇结论压成三句话：

宿载层解决"按什么变"，  
动力层解决"历史怎样在渠与流的往返中推它走"，  
对象层解决"推出来的什么已经稳定持住，又怎样约束此后的流"。

再压成最简一句：

没有宿载层，就没有承担生成职责的计算；没有动力层，算得再多也只是规则在走；没有压缩到稳定，历史在推，律还没有成；而计算不经动力层，够不着律的资格。

附：计算分层一般式·形式化

本附录给出计算分层一般式的形式对象与形式陈述，使正文的结构、命题与定理在形式层面可以逐项核对。

一、基本对象与类型

P：计算宿载，边界、入口、读出、交付协议、申报时期 Θ 按计算承担一般式申报。  
τ：P 在 Θ 内承担的任务，以函数（或核）外延为身份。  
σ ⊆ Θ：P 上一段实际过程；Exe(σ)：σ 中 P 对 τ 的各次执行。  
Decl：P 所持状态的完整读法（分量划分、π\_cmp、跨步承接、更新方式），先于 σ 申报（生成计算一般式-H1）。  
π\_cmp：申报比较投影，含 τ、本步输入、外生控制构型 c、申报的当前结构读出，先于 σ 固定。  
c：外生控制构型，只经申报协议的许可干预改变，不属 Exe(σ)；u：交付输入。  
Ob ∈ {∅, {L}}：申报对象集；Rel(L)、I：律的关系与适用域。  
𝒲：工作域——单宿载 P 内的计算实施、沉积动力与至多一条律的续行。  
HistVar：合法历史条件变动族（可含合法反事实）。  
Ex(e, r)：事件 e 由执行 r 驱动（计算执行一般式 Ex，携该式-H3）；ImplDecl(e)：e 为被合法申报为 τ 实施组成部分的物理状态转移。  
Witness(σ)：E2 的见证链。  
Sed\_P：P 中取得场资格的沉积场的持久场态；D\_P：Sed\_P 中被执行读入的部分；R ⊆ Org(Sed\_P)：律 L 的承担者；Q ⊆ R：其被本段读入的相关状态（Q ⊆ D\_P）；ActBind：作用绑定；O\_P、O\_σ：上游律对象资格、其与本段位置的合取。  
FieldQual(κ\_sed)：κ\_sed 为取得完整场资格的沉积场的持久场态（本篇-H1 所对应者）。

二、规定

E1(σ) ⟺ P 在 Θ 内承担 τ ∧ σ 中的变换 ⊆ Exe(σ)。  
E2(σ) ⟺ ∃ h₁, h₂ ∈ HistVar，∃ s₁, s₂：π\_cmp(s₁) = π\_cmp(s₂) ∧ σ 中某一后续实际变换在 h₁、h₂ 下不同。  
以下 χ ∈ Witness(σ) 为一条见证链：一对合法历史 h₁、h₂ 及其在 π\_cmp 下相同的两处，连同承担其后续差异的状态分量与 σ 内的相关事件。  
E2(χ) ⟺ χ 上 π\_cmp(s₁) = π\_cmp(s₂)，且 σ 中某一后续实际变换在 h₁、h₂ 下不同（随机源按比较协议固定）。  
E3(χ) ⟺（i）χ 的差异由 P 所持者承担，非边界外代算、非运行外写入，并经 Exe(σ) 进入后继 ∧（ii）χ 所依的历史条件在 σ 内的形成或改变事件均为合法申报的实施并由 Exe(σ) 驱动（ImplDecl ∧ Ex）；σ 以前的形成不在（ii）之内。（ii）只约束 χ，不约束 P 中其他场态的自主变化。  
E4(χ) ⟺ 承担 χ 差异的历史依赖满足可沉积性。  
E5(σ, L) ⟺ E5\_run ∧ E5\_car ∧ E5\_host ∧ Ct：E5\_run——σ 含 L 在 Rel(L)、I 上的实际续行事件，L 在其时刻成律；E5\_car——L 的支配结构申报在 P 的承载范围内；E5\_host——这些事件中承担者的动力作用经 Exe(σ) 进入后继（计算宿载中的动力），不约束承担者场态在执行之间的自主变化；Ct——σ 对 L 的续行有非虚设因果贡献（H2）。  
Φ(∅) ≔ E1 ∧ ∃χ ∈ Witness(σ)：E2(χ) ∧ E3(χ) ∧ E4(χ)（共同见证）；Φ(L) ≔ Φ(∅) ∧ E5。

三、各项的形式陈述

κ：P 所持、∉ π\_cmp、随 HistVar 取值不同、作为自变量进入 Exe(σ) 中某一执行的因素；κ\_sed ⊆ κ：κ 中历史依赖满足可沉积性的部分；对 Φ(∅) 所取的 χ，E4(χ) ⇒ χ 上承担差异者 ⊆ κ\_sed（不要求一切见证链如此）。Sed\_P：P 中取得场资格的沉积场的持久场态（不要求在某一比较中取值不同）；κ\_sed ⊆ Sed\_P（本篇-H1）。  
FixedNoHist：τ 固定 ⇒ 对相同的自变量给出相同的后继分布，在比较协议固定的共用随机源下给出相同的实际后继；历史差异只能由自变量承担。  
Pass(κ\_sed) ⟺ κ\_sed 的历史依赖满足可沉积性：段内有更新时，更新依实际经过（写入闸门）；段内无更新时，FieldQual(κ\_sed)（本篇-H1）。  
W(χ) ⟺ ∀ e ∈ Upd\_σ(κ\_sed) ∩ χ，∃ r ∈ Exe(σ)：ImplDecl(e) ∧ Ex(e, r)。其中 Upd\_σ(κ\_sed) ∩ χ 收集同一 E2 见证链上、在 σ 内实际发生并承担该见证历史条件形成或改变的全部相关更新事件，不因其尚未取得执行归责而从待审集合中剔除。每一事件须同时满足合法实施申报 ImplDecl(e) 与执行驱动 Ex(e, r)，方通过 W。未被申报为 τ 实施组成部分的器件自主物理变化，若承担 χ 的段内历史形成或改变，仍进入待审集合，并因不满足相应条件而使 W 失败；χ 之外的自主变化不受 W 约束。若该集合为空，W 平凡成立；这不认证段首场态的完整场资格，后者仍按本篇-H1 处理。  
Rd(χ) ⟺ ∀ 承担 χ 的 κ\_sed 取值 v，∃ 后续 r ∈ Exe(σ)：v 为 r 的自变量（只及见证链；容许延迟；判定按第五篇 Hold、Carry、Gov，携生成计算一般式-H2）；Rd 不认证场资格。  
WR(σ) ⟺ ∃ χ ∈ Witness(σ)：E2(χ) ∧ E3(χ) ∧ E4(χ) ∧ Pass(χ) ∧ W(χ) ∧ Rd(χ)（同一 χ）。对 Φ(∅) 所取的 χ：E3(χ)（ii）⇒ W(χ)；E2(χ) ⇒ Rd(χ)；E4(χ) ⇒ Pass(χ)。故 Φ(∅) ⇒ WR。  
S(σ) ≔ Exe(σ) 连同 τ；κ \\ κ\_sed 属 S。  
D\_P ≔ {v ∈ Sed\_P：∃ r ∈ Exe(σ)，v 为 r 的自变量}（总体承担域，成员不须满足某一见证链上的 W）；D\_E2 ≔ WR 所取 χ 上的 κ\_sed，D\_E2 ⊆ D\_P；律承担者 R ⊆ Org(Sed\_P)（引理一），其相关状态 Q ⊆ D\_P（引理二），按 O\_P 与 ActBind 另认证。D 为资格种类，D\_E2 与 Q 所在部分为其实例。  
G\_loc(σ, L, R, Q) ⟺ R ⊆ Org(Sed\_P)（候选场内组织，不在 τ 的规则中；C0、查表条款，携 H\_G）∧ ∅ ≠ Q ⊆ R（候选相关状态）∧ Q 在 Rel(L) 的实际续行中进入 Exe(σ) 的数据依赖路径——执行链上某次执行以 Q 为自变量，Q ⊆ D\_P（判定携生成计算一般式-H2）；不把非平凡动力作用写入定义。不含 Established、Govern、Ct；G\_loc ⇏ Established，G\_loc ⇏ DynamicRole，G\_loc ⇏ ΩSupport。  
ActBind(σ, e, L, R\_t, Q\_t) ⟺ e 为 σ 内 L 在 Rel(L)、I 上的合法实际续行事件，时刻 t ∧ R\_t 为 t 时同一关系、同一适用域上认证的律承担者（Established\_P ∧ Govern\_P）∧ ∅ ≠ Q\_t ⊆ R\_t 为 DynamicRole 所指、承担非平凡动力作用的相关状态 ∧ Q\_t 的作用经 Exe(σ) 的合法实际执行链（可含中间状态与多个执行节点）进入 e 的后继；对象、关系、时刻、承担者同一。ActBind ⇒ G\_loc；G\_loc ⇏ ActBind。  
CtPath(σ, L) ⟺ ∃γ ⊆ Exe(σ)：LegalExecPath(γ) ∧ ActualContribution(γ, L) ∧ ∃e, t, R\_t, Q\_t：ActBind(σ, e, L, R\_t, Q\_t)。γ 为实际贡献子链，不要求等于 Exe(σ) 的全部节点，所涉状态不限于 R（R 的自主变化不计入 σ）；ActualContribution 不引入新的因果资格判据，引用本篇-H2 的归责协议；ActBind 的 Q 读入路径与 γ 不必逐节点重合，若要把两者绑定为同一贡献链，须依 H2 认证，不能由 ActBind 单独推出。属任务归责，不计层。  
递推：Φ(∅) ∧ ¬G\_loc ⇒ ¬Φ(L)（规则模拟、τ\_C）；Φ(∅) ∧ G\_loc ⇏ Law(L)（一次强冲）⇒ 逼出 O\_P。

四、层的检验（闭合之后）

计层单位：初始规定所说的生成层级与反作用关系；Layers 对公式拆分、变量命名、执行机制合并不变。  
候选：闭合结构中的 S、D、O；κ、Pass、W、Rd 为 D 的必要条件与承接关系，G\_loc 为 Φ(L) 的本段执行位置条件，不为候选，也不是 RelL^obj 的必要条件。  
Qual(Y)：Y 所具的资格——Qual(D)：Rel0 所需的可沉积动力资格（Pass ∧ W ∧ Rd 在承担 E2 差异的 κ\_sed 上，渠定流、流改渠）；Qual(O)：RelL 所需的律对象资格 Established ∧ Govern（律组式完整认证）。  
NewQual(X, Y) ⟺ Qual(Y) 不是 X 已有的资格。  
NEnt(X, Y) ⟺ ∃ 合法完整情形 c：X(c) ∧ ¬Y(c)。（下级可停留。）  
NoCert(X, Y) ⟺ 只凭 X 的已有资格不能认证 Qual(Y)，且有独立的退化见证（不由 Y 的定义推出）。  
Need(Y) ⟺ Qual(Y) 为申报任务所必需。  
GenLevel(X, Y) ⟺ Qual(Y) 具有以 X 类生成为合法依托的来源，或这种来源下满足上游移植与保持条件的合法承接（σ 内不必重新生成，不要求由当前 P 亲自生成；预装按上游条件判定），并使该组织能承担一项资格取得以前未获资格、完整取得的申报生成关系；不要求新增执行机制。  
NoSubst(X, Y, Z) ⟺ X 的事实不是 Y 对 Z 之承担的替代承担者。

"""F_LB = Augment(F_min).
Inherited from Canonical F* v1.2 (最小沉积场构造式 v0.9): node depth d, relation sediment g (saturating),
Trace / Sediment / Decay / Continuation, Mode_exo / Mode_endo, softmax solver.
Added (law-base layer): pulse strength p, threshold θ, S, derived groove set Γ, replay window & Ω,
Freeze^inst (SED=OFF), Avail (availability), RoleReadMask (targeted role intervention), dual clock t_run / t_sed, IdleStep (decay only), Established^inst(R)."""
import math, random, copy
from collections import defaultdict, deque

class FLB:
    def __init__(self, nodes, medium, alpha=0.05, beta=0.25, g_max=20.0, lam_d=0.01, lam_g=0.01,
                 theta=1.0, W=30, n_omega=3, kappa0=0.05, w_g=1.0, w_d=0.02, s_weak=0.4, T=0.15, seed=0):
        self.nodes=nodes; self.E=list(medium); self.out=defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        # inherited persistent state
        self.d={n:0.0 for n in nodes}; self.g={e:0.0 for e in self.E}
        # added persistent state
        self.rep={e:deque() for e in self.E}; self.Om={e:0.0 for e in self.E}
        self.th={e:theta for e in self.E}; self.Avail={e:1 for e in self.E}
        self.alpha,self.beta,self.g_max,self.lam_d,self.lam_g=alpha,beta,g_max,lam_d,lam_g
        self.W,self.n_omega,self.k0,self.w_g,self.w_d,self.s_weak,self.T=W,n_omega,kappa0,w_g,w_d,s_weak,T
        self.t_run=0; self.t_sed=0; self.SED=True; self.rng=random.Random(seed); self.log=[]; self.macro=None
        self.mask={e:1 for e in self.E}   # RoleReadMask: exogenous control quantity (not sediment, not decayed, persists until re-intervened)
    # ---------- inherited operators
    def Decay(self):
        """one sediment-clock step: t_sed advances; depths decay; replay windows (on t_sed) expire."""
        self.t_sed+=1
        for n in self.nodes: self.d[n]=max(0.0,self.d[n]-self.lam_d)
        for e in self.E:
            self.g[e]=max(0.0,self.g[e]-self.lam_g)
            while self.rep[e] and self.t_sed-self.rep[e][0]>self.W: self.rep[e].popleft()
            self.Om[e]=self._omega(e)
    def Trace(self,e,p): return {'e':e,'p':p}
    def Sediment(self,tau):
        e,p=tau['e'],tau['p']
        self.d[e[0]]+=self.alpha*p; self.d[e[1]]+=self.alpha*p
        self.g[e]=min(self.g_max,self.g[e]+self.beta*p*(1-self.g[e]/self.g_max))
        self.rep[e].append(self.t_sed); self.Om[e]=self._omega(e)
    def kappa(self,e):
        if not self.Avail[e]: return -1e9
        return self.k0+self.w_g*self.mask[e]*self.g[e]*(1.0 if self.S(e) else self.s_weak)+self.w_d*self.d[e[1]]
    def Continuation(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        if not cand: return None
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]
        r=self.rng.random()*sum(ws)
        for e,w in zip(cand,ws):
            r-=w
            if r<=0: return e
        return cand[-1]
    def probs(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return {e[1]:w/z for e,w in zip(cand,ws)}
    # ---------- added layer
    def S(self,e): return self.g[e]>=self.th[e]
    def Deposited(self,e): return self.g[e]>0
    def Groove(self,e): return self.S(e) and len(self.rep[e])>=2
    def Gamma(self): return {e for e in self.E if self.Groove(e)}
    def _omega(self,e):
        n=len(self.rep[e]); return 0.0 if (n<self.n_omega or not self.S(e)) else min(1.0,n/(2*self.n_omega))
    def Freeze(self): self.SED=False
    def Thaw(self): self.SED=True
    def SetAvail(self,e,v): self.Avail[e]=v
    def IdleStep(self,n=1):
        for _ in range(n): self.Decay()          # t_sed advances only
    def SetMask(self,e,v): self.mask[e]=v          # targeted role intervention (structure untouched)
    # ---------- pulse
    def pulse(self,entry,p=1.0,path=None,maxhop=6):
        self.t_run+=1
        if self.SED: self.Decay()                 # t_sed advances only when sediment law is on
        q=entry; route=[q]; inst=[]
        for h in range(maxhop):
            if path is not None:
                if h>=len(path)-1: break
                e=(path[h],path[h+1])
            else:
                e=self.Continuation(q)
                if e is None: break
            if not self.Deposited(e): inst.append(e)
            if self.SED: self.Sediment(self.Trace(e,p))
            q=e[1]; route.append(q)
            if not self.out[q]: break
        self.log.append((self.t_run,entry,tuple(route),self.macro))
        return route,inst
    # ---------- law-side readouts
    # duty = dict(ante=entry node, anchor=edge whose head state is the relation's antecedent, read=target node)
    def _closure(self,start,edges):
        adj=defaultdict(list)
        for (i,j) in edges: adj[i].append(j)
        seen={start}; st=[start]
        while st:
            x=st.pop()
            for y in adj[x]:
                if y not in seen: seen.add(y); st.append(y)
        return seen
    def CarrierRealizes_inst(self,R,duty):
        """R alone (restricted) carries Ante ⇝ Anchor.tail —Anchor→ Anchor.head ⇝ Read, all on deposited edges of R;
        the anchor edge itself must be traversed (it is deposited and on the path)."""
        a=duty['anchor']
        if a not in R or not self.Deposited(a): return False
        dep=[e for e in R if self.Deposited(e)]
        return a[0] in self._closure(duty['ante'],dep) and duty['read'] in self._closure(a[1],dep)
    def Established_inst(self,R,duty):
        """R ⊆ E ∧ ∀e∈R Deposited ∧ CarrierRealizes_inst. CarrierNonInstant is a type invariant here:
        g is persistent state, so Deposited(e) ⇒ not flow-only."""
        return set(R)<=set(self.E) and all(self.Deposited(e) for e in R) and self.CarrierRealizes_inst(R,duty)
    def MediumReach_inst(self,entry,Q):
        """medium access only: entry reaches the head of some Avail=1 edge in Q via Avail=1 edges. Does not require Q deposited."""
        seen=self._closure(entry,[e for e in self.E if self.Avail[e]])
        return any(self.Avail[e] and e[0] in seen for e in Q)
    def RolePath_inst(self,R,duty):
        """a deposited, mask-open path inside R from the anchor state to Read."""
        a=duty['anchor']
        if a not in R or not (self.Deposited(a) and self.mask[a]): return False
        open_edges=[e for e in R if self.Deposited(e) and self.mask[e]]
        return a[0] in self._closure(duty['ante'],open_edges) and duty['read'] in self._closure(a[1],open_edges)

import math, copy, itertools

MAXHOP=6

# ---------- kernel & exact path measure ----------
def kernel(F,q,avail=None,mask=None):
    """K_y at position q: distribution over out-edges, from state only (exact)."""
    avail=avail or F.Avail; mask=mask or F.mask
    cand=[e for e in F.out[q] if avail[e]]
    if not cand: return {}
    ks=[]
    for e in cand:
        k=F.k0+F.w_g*mask[e]*F.g[e]*(1.0 if F.S(e) else F.s_weak)+F.w_d*F.d[e[1]]
        ks.append(k/F.T)
    m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
    return {e:w/z for e,w in zip(cand,ws)}

def eval_paths(F,entry,edges_allowed=None,maxhop=MAXHOP):
    """Exhaustive Eval(Ctx): all routes with exact μ. edges_allowed=None → all; else restrict (κ_P)."""
    out=[]
    def rec(q,route,prob,hops):
        K=kernel(F,q)
        if edges_allowed is not None:
            K={e:p for e,p in K.items() if e in edges_allowed}
            z=sum(K.values())
            if z==0: out.append((tuple(route),prob,'dead')); return
            K={e:p/z for e,p in K.items()}   # 受限评价：P 外结构不可用，核在 P 内重归一
        if not K or hops>=maxhop: out.append((tuple(route),prob,'end')); return
        for e,p in K.items(): rec(e[1],route+[e[1]],prob*p,hops+1)
    rec(entry,[entry],1.0,0)
    return out

def mu_read(F,entry,target,edges_allowed=None):
    return sum(p for r,p,_ in eval_paths(F,entry,edges_allowed) if target in r)

# ---------- ActArg^μ at a choice node (weighted duty) ----------
def actargs_at(F,q,eps=0.01):
    """minimal μ-sufficient groups over per-edge state fixings at position q.
    AdmVar: each out-edge's g varies over its admissible domain. The implementation evaluates
    endpoint grids {0,g_max} (S recomputed): single-free-variable sufficiency is exact, while
    multi-variable positive sufficiency is conditional on PR2-valid (paper §4 PR2, §7.1);
    negative verdicts from grid counterexamples are unconditionally sound."""
    cand=[e for e in F.out[q] if F.Avail[e]]
    def dist(gvals):
        ks=[]
        for e in cand:
            g=gvals[e]; S=1.0 if g>=F.th[e] else 0.0
            k=F.k0+F.w_g*F.mask[e]*g*(1.0 if S else F.s_weak)+F.w_d*F.d[e[1]]
            ks.append(k/F.T)
        m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return [w/z for w in ws]
    def tv(p,qq): return 0.5*sum(abs(a-b) for a,b in zip(p,qq))
    base={e:F.g[e] for e in cand}
    def sufficient(C):
        freevars=[e for e in cand if e not in C]
        if not freevars: return True
        grids=[[0.0,F.g_max] for _ in freevars]
        dists=[]
        for combo in itertools.product(*grids):
            gv=dict(base); gv.update({e:v for e,v in zip(freevars,combo)})
            for e in C: gv[e]=base[e]
            dists.append(dist(gv))
        return max(tv(a,b) for a in dists for b in dists)<=eps
    minimal=[]
    for r in range(len(cand)+1):
        for C in itertools.combinations(cand,r):
            if sufficient(set(C)) and not any(set(M)<=set(C) for M in minimal):
                minimal.append(C)
    return set(u for M in minimal for u in M), minimal

def _judge_P(F,L,P,R,pi0,eps):
    """evaluate CR/CNI/Dyn/ΩSupport on one implementation P ⊆ R (canonical witness Π_P: W=ResEval(κ_P), PR1).
    Returns (depth_reached, detail). Depth order: CR=1, CNI=2, Dyn=3, ΩSupport=4 (all-pass)."""
    ante,anchor,read=L['ante'],L['anchor'],L['read']; d={}
    m_res=mu_read(F,ante,read,edges_allowed=set(P))
    d['P']=[f"{e[0]}→{e[1]}" for e in sorted(P)]
    d['CR']=dict(anchor_in_P=anchor in P,mu_restricted=round(m_res,4),pi0=pi0)
    if not (anchor in P and m_res>=pi0): return 0,d
    # CNI by reduction lemma: frozen ⇒ Estab={g>0}; witnesses under PR1 have Q(Π)⊆P⊆R⊆Estab (CC);
    # Bear∩Inst=∅ automatic since P has no g=0 edge. Assert the lemma's premises:
    assert all(F.g[e]>0 for e in P), "CNI reduction premise violated"
    d['CNI']=dict(by_reduction_lemma=True,Q_subset_Estab=True)
    # Dyn on Π_P
    aa,minimal=actargs_at(F,anchor[0],eps)
    adj=defaultdict(list)
    for (i,j) in P:
        if F.g[(i,j)]>0 and F.mask[(i,j)]: adj[i].append(j)
    seen={anchor[1]}; st=[anchor[1]]
    while st:
        x=st.pop()
        for y2 in adj[x]:
            if y2 not in seen: seen.add(y2); st.append(y2)
    rolepath=(anchor in aa) and (read in seen or read==anchor[1])
    d['Dyn']=dict(ActArg_at_anchor_tail=[f"{e[0]}→{e[1]}" for e in sorted(aa)],minimal_groups=[[f"{e[0]}→{e[1]}" for e in M] for M in minimal],anchor_in_ActArg=anchor in aa,rolepath=rolepath)
    if not rolepath: return 2,d
    # ΩSupport on Π_P
    seenA=F._closure(ante,[e for e in F.E if F.Avail[e]])
    reach=any(F.Avail[e] and e[0] in seenA for e in P)
    bear=[e for e in P if e==anchor or (anchor[1]==e[0] or e[0] in seen)]
    omega_ok=all(F.Om[e]>0 for e in bear)
    d['ΩSupport']=dict(Reach=reach,Bear=[f"{e[0]}→{e[1]}" for e in bear],Omega={f"{e[0]}→{e[1]}":round(F.Om[e],2) for e in bear})
    if not reach: return 3,dict(d,fail='Reach')

def judge(F,L,R,I,pi0=0.9,eps=0.01,verbose=True):
    """Decision domain: single-duty, single-entry I={Ante}, measure-type candidate;
    the input F_LB state is converted to a Freeze^inst snapshot before judging.
    Existential over implementations: R passes iff ∃P ⊆ R (anchor ∈ P) whose canonical witness Π_P
    passes CR∧CNI∧Dyn∧ΩSupport; Bind then follows by the collapse lemma (frozen: RoleCtx=ReplayCtx,
    same Π_P bears ΩWit and ρ_P ∈ RoleReal via its Dyn check). fail_at = deepest level reached over all P."""
    T={}

    # runtime guard below checks single entry I={Ante}; F is frozen into a Freeze^inst snapshot before judging

        return None,T

    cc = len(R)>0 and all(e in F.E for e in R) and all(F.g[e]>0 for e in R)

def kernel(F,q,avail=None,mask=None):
    """K_y at position q from the instance's ACTUAL τ kernel F.kappa (same function as Continuation uses)."""
    if avail is not None or mask is not None:

def actargs_at(F,q,eps=0.01):
    """same AdmVar / grid / minimality as upstream; distribution under each g-assignment from F.kappa."""

        for e in cand: G.g[e]=saved[e]
