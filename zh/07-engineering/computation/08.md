自显论·工篇·计算组式第八 v1.0

# 生成计算必然式

一、目的

计算分层一般式已经说明：一段计算若使历史成为动力（职责 Φ(∅)），它必有两种承担——固定变换关系在宿载上的执行 S，与满足可沉积性、段内由执行驱动更新、为执行读入的历史条件 D；D 是 S 之上的一级。那是必要方向：先假定历史已成为动力，再问最少须有什么。生成计算一般式与计算分层一般式都把另一方向列为未答：在什么条件下，历史不能不成为动力。

本组式对计算的初始规定给出的正是这一方向的说法：生成计算把规则写在宿载里，宿载按这些规则能够自动生成动力层（初始规定六）；宿载只需写下信号与介质的迹应关系，给出一个初始的沉积场网络，此后由信号流在历史中不断改变它（初始规定六）。本篇证明：宿载规则满足一组可从规则本身读出的性质，连同初态、复入许可、合法承接与无侵入等条件时，必有合法运行使动力层在宿载中生成；凡实际包含一次分支经过、其后的实际复入，迹差留存到读入且读入集未受别的改动的运行段，动力层在其中不能不生成——历史在这段计算内成为后续变换的条件，并经渠定流、流改渠完成一次反作用往返；而规则中无须写入任何对象规则。

回答程度。首版。所得结论及其地位如下："已证"指在第三节申报模型内给出完整证明。生成的必然性分两层陈述：存在一段合法运行使生成发生（定理一甲），与凡实际包含见证构型的运行段之内生成必然发生（定理一乙）。  
其一，生成见证的存在性（定理一甲）与运行段内的生成必然性（定理一乙）：已证，携计算执行一般式-H3。  
其二，自主续行中的见证构型（定理二）：已证，另附源入口与关系读入或隔离二者之一；满足留存的每一次经过都成为条件（定理三）：已证，只在定理二（a）关系读入（连同源入口）下成立，不及于隔离情形；二者携计算执行一般式-H3；去掉关系读入与隔离时存在抵消反模型。  
其三，无须对象规则（定理四）：已证。  
其四，初始势不定命（定理五）：已证，结论是存在改写起始偏向的合法外生历史；无退浅且初态饱和时锁定，作为边界给出。  
其五，确定读入下的改路（定理六）：已证，规则类另立为 𝔗\_det，另附 Fgt\*、RT₁(o)、NL(x) 与条件组 C\_pre（C₂ 的 𝔗 换为 𝔗\_det，C₆ 由 RT₁(o) 代）；携计算执行一般式-H3。  
其六，动力层成立（定理七）：由定理一乙与计算分层一般式总定理（一）合成，条件化。  
其七，与生成计算一般式七项的对应（定理八）：条件化，并给出差异非零与差异可辨之间的界限。  
未答：连续向量介质上的对应结论；一般介质上自主续行见证的存在性；动力变换的复杂程度；对象层在动力中的形成；一般 Luce 型核下全变差的下界。

初始规定。本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。引用时标出序号：  
　初始规定一：规则变换的每一个执行节点都是一条逻辑规则：它是程序所表达的那条律在这一节点上的规则，规定为了形成这条律下一步怎样走。  
　初始规定二：在动力变换中，历史成为动力；在历史之外对动力施加外力干预，是另一种情形，即侵入。  
　初始规定三：以挖渠为例，水流过之后又反蚀渠网，后续水流就这样持续与渠网交互，这就是动力层的生成。  
　初始规定四：在动力层之上，一部分持势被判准为律；对象以其持、择、偏、破等作用反过来作用于动力；这些运动都真实地来自宿载，若宿载是计算设备，就来自计算。  
　初始规定五：宿载的计算只能定下动力层的计算规则，例如神经可塑性：脉冲经常流经之处变深、更易通过，少流经之处变浅、不易通过。  
　初始规定六：生成计算把规则写在宿载里，宿载按这些规则能够自动生成动力层；动力类型包括反蚀与改路、退浅等。宿载规则只需判断信号流经某处沉积结构（如某条沟线与端壑）在时间窗口内的计数：计数变大则易通过，变小则不易通过；宿载给出一个初始的沉积场网络，此后由信号流在历史中不断改变它。宿载只是规定并捕捉基本规则的变化，让信号流不断作用于场，产生动力层的复杂变换。  
　初始规定七：训练中按误差调整权重的规则不是沉积场的基本规则，而是训练的规则；这种训练称为势引；势引不改变宿载规则。  
　初始规定八：不经由信号流、在历史之外直接改渠或改写权重，是侵入。  
　初始规定九：在计算宿载中，动力在信号流经过、通过规则真正进行计算变换时发生；宿载规则就是信号与宿载介质的迹应关系，动力条件是每一次迹应发生、产生变换时的当前条件。  
　初始规定十：生成计算包含规则计算；规则计算发生在生成计算的宿载层。  
　初始规定十一：初始沉积场并非没有势的作用，它是不均匀的。

工作域 𝒲₇：单宿载 P；介质为有限个结构位与其间允许的局部迁转（有限简单有向图：同一对结构位之间至多一条同向的迁转）；信号以脉冲方式进入，一次脉冲是 P 对一步任务 τ\_Φ 的一次执行；随机续行一律在分布层或共用随机源下陈述。连续向量介质、多宿载、对象层（律、理、概率、意向）的形成在 𝒲₇ 之外。本篇一切结论限于 𝒲₇。

二、核心命题

宿载规则若只规定信号与介质的迹应关系——实际经过者留迹，反复经过则迹深，少用则迹淡，迹深者易过，且这些规定对一切结构位一致——那么：

其一，只要宿载承担并执行这条规则，持有一个由合法承接取得的初始场，信号被许可再次进入某一分支位，沉积开启而没有侵入，在初始场上一次经过所留的迹差留得过一个沉积钟步，就存在一段合法运行，历史在其中成为后续变换的条件，所形成的迹经执行被读入，并改变其后的去向与写入。

其二，任一段运行，只要实际包含分支位上的一次经过与其后在该位的一次实际读入，其间所留之迹未被抹平，该位的读入集不受别的改动，则在这段运行之内，历史不能不成为后续变换的条件，所形成的迹不能不改变其后的去向与写入。

规则中无须、也不含任何以对象为自变量的条款。初始场的不均匀给出起始的势，而在退浅之下不决定此后的动力条件。

形式：C\_pre ⇒ ∃σ ∈ Run\_legal：C₃(σ) ∧ C\_run(σ) ∧ Γ(σ) ∧ R₁(σ) ∧ R₂(σ)；C₁ ∧ C₂ ∧ C₄ ∧ C₈ ∧ C\_run(σ) ∧ Γ(σ) ⇒ R₁(σ) ∧ R₂(σ)；τ\_Φ ∈ 𝔗 ⇒ R₃（第四节给出各项；第五节逐一证明）。其一、其二与前两式限于 𝒲₇，携计算执行一般式-H3（E3（ii）与 W 的执行归责）。

### 3.3　迹应规则类 𝔗

一次脉冲（τ\_Φ 的一次执行）：SED = 1 时先对一切迹状态作一次 Idle；其后逐跳续行——在位 q，按 K\_q 取一条可用出边（外生经历时取 route 所给之边），SED = 1 时对该边及其两端位作一次 Pass\_p，q 移至该边末端；无可用出边或达到跳数上限 H 时止。这一次序承 F\_min 第十节"先退浅，再处理当前事件"（Decay → Continuation → Trace → Sediment）与 F\_LB 的脉冲程序。

τ\_Φ ∈ 𝔗，当且仅当下列五条成立：  
　TR1（写入闸门）开启沉积时，一次脉冲中 D 的改变只有：每一迹状态先作一次 Idle；其后每一次实际经过 e，对 m\_e 与 n\_{tail(e)}、n\_{head(e)} 各作一次 Pass\_p。关闭沉积时 D 不变。依据：初始规定六（判断信号流经沉积结构的计数）；《律动力数理式》v1.0 写入闸门 4.3（只有实际经过者入沉积）。  
　TR2（迹深）记读数支配序 m ⪰ m′ :⇔ 对一切 k ≥ 0，ρ(Idle^k m) ≥ ρ(Idle^k m′)。Idle 与 Pass\_p 保持 ⪰；Pass\_p(m) ⪰ m；零迹 o 是 ⪯ 的最小元，且 Idle(o) = o；在未饱和状态集 𝕄° 上 ρ(Pass\_p m) \> ρ(m)。位迹同。依据：初始规定五（经常流经之处变深）、初始规定六（计数变大）。  
　TR3（退浅）ρ(Idle m) ≤ ρ(m)。依据：初始规定五（少流经之处变浅）、初始规定六（计数变小）。  
　TR4（局部一致）Idle、Pass、S、φ 对一切边、一切位是同一函数，不以结构位、关系或入口的名字为自变量；τ\_Φ 是确定的，随机只在续行抽样中，由申报随机源给出。依据：初始规定六（宿载只是规定并捕捉基本规则的变化）、初始规定九（宿载规则就是信号与宿载介质的迹应关系）。  
　TR5（读入耦合）S 关于第一自变量严格增、关于第二自变量不减；φ 严格增且取正值（Luce 型续行核，softmax、幂次归一与线性归一都在其内）。依据：初始规定五（深者更易通过、浅者不易通过）、初始规定六（计数变大则易通过、变小则不易通过）、初始规定九（动力条件）。

D 中不进入得分的其余持久量（如 F\_LB 的复走窗口记录与 Ω）也只经 Idle、Pass 改变；TR2、TR3 只对进入得分的迹分量立论。  
五条都是规则自身的性质，在任何一次运行之前就能从 τ\_Φ 的申报中读出。实例：F\_min 满足 TR1—TR5；F\_LB 在强度 p ≤ g\_max/β 时满足 TR1—TR5（其得分 κ\_e = κ₀ + w\_g·Mask\_e·g\_e·(1 或 s\_weak) + w\_d·d\_{head(e)} 关于 g\_e 分段线性严格增、阈处上跳；p ≤ g\_max/β 时其 Pass 关于 g 保序，p 更大时不保序，TR2 不成立；本篇所引 F\_LB 实例都在此范围内）；以时间窗口内的经过次数为读数的规则（初始规定六）满足 TR1—TR5。

可沉积性与 𝔗 的逐款对应。《沉积场论》v1.2 定可沉积性为"与之作用能应之以迹，反复则迹深，少用则迹淡，同源则同迹，异源则异迹"（引文转引自《最小沉积场构造式》v1.2 第三节）。逐款：  
　\| 可沉积性 \| 𝔗 中的对应 \|  
　\| 与之作用能应之以迹 \| TR1：实际经过者作 Pass；TR2：Pass\_p(m) ⪰ m，未饱和时读数严格增 \|  
　\| 反复则迹深 \| TR2：Pass 保序且严格增，n + 1 次经过支配 n 次经过，未饱和处严格 \|  
　\| 少用则迹淡 \| TR3：Idle 不增读数；未经过者只受 Idle \|  
　\| 同源则同迹 \| TR4：同一经过序列给出同一迹 \|  
　\| 异源则异迹 \| TR1：经过哪一条边，就在哪一条边的边迹上作 Pass，未经过的边只受 Idle \|  
由此，τ\_Φ ∈ 𝔗 时，凡由 Idle、Pass 给出历史依赖的迹分量，其历史依赖满足可沉积性。  
"同源则同迹，异源则异迹"的读法：同一作用（经过）在同一处留下同一迹，不同的作用在各自所及之处留下各自的迹；这是逐次作用、逐个分量的性质。它不是"任意两段不同的历史必定留下不同的完整场态"这一全局单射：后者与同一定义中的"少用则迹淡"不相容——两段不同的旧历史在退浅到零迹之后留下相同的场态。主书原文"断其能使同源之流同，异源之流异"（《自显论》v0.7.1 外篇第六《电磁》，择材段）亦就每一来源之流而言。本篇的见证只用到所选两段历史在读入分量上的差异，由 Γ5 与引理 1 证明，不依赖全局单射。

### 3.4　留存与遗忘

留存　分两种时基。以经过前一刻的状态 m̂ 为基准：RT^pre\_k(m̂) :⇔ ρ(Idle^k Pass\_p m̂) \> ρ(Idle^k m̂)——在 m̂ 上经过一次与不经过，再隔 k 个沉积钟步，读数仍严格不同。以脉冲开始前的状态 m 为基准（脉冲的第一跳，其前只有本脉冲开始时的一次 Idle）：RT\_k(m) :⇔ RT^pre\_k(Idle m)，即 ρ(Idle^k Pass\_p Idle m) \> ρ(Idle^{k+1} m)。二者都同时排除饱和（Pass 不再增）与抹平（退浅到零迹）；凡经过不在脉冲第一跳、或其前状态已受过本脉冲的 Idle 者，只能用 RT^pre。  
读数支配序 ⪰ 自反、传递（由其定义中的 ≥ 逐 k 成立而得）。  
遗忘　Fgt：对一切 m，ρ(Idle^n m) 在有限步内达到 ρ(o) 或趋于 ρ(o)；位迹同。定理五、六所用的是由此加强的得分遗忘 Fgt\*（5.6）。

四、动力律、条件组与见证构型

### 4.1　动力律

条件组之下系统按 3.3 的一次脉冲演化：先退浅，再逐跳续行并沉积。续行核 K\_v 读取当前的边迹与末端位迹；被经过者的迹经 Pass 加深，未经过者经 Idle 变浅。来源：F\_min 第十节的统一时间更新与第十一节的续行求解器，F\_LB 的 Sediment、Decay、κ 与脉冲程序；在 𝔗 上的一般形式由 TR1—TR5 给出。

### 4.2　条件组：模型级前件 C\_pre 与运行级条件 C\_run(σ)

下列 C₁—C₈ 是模型级的前件：只陈述规则、介质、初态、申报与许可，不提及任何一段运行。凡涉及运行段 σ 的条款，单列为运行级条件 C₁(σ)、C₃(σ)、C₇(σ)、C₈(σ)，σ 由各定理的量词给出。  
　C₁（承担）P 在申报时期 Θ 内承担 τ\_Φ。来源：计算承担一般式 v1.0、计算执行一般式 v1.0。  
　C₂（规则）τ\_Φ ∈ 𝔗；Idle 与 Pass 是被合法申报的实施组成部分（ImplDecl），由 P 执行。来源：初始规定六（规则写在宿载里）、初始规定九（宿载规则就是信号与宿载介质的迹应关系）；3.3。  
　C₃（初态与合法承接）申报的段首场态 D₀ 由合法承接取得：新场、预装、移入、写入初值均可；D₀ 可以任意不均匀。来源：初始规定十一；《律一般式》v2.5 Established 的移植条款；《律动力一般式》v1.0 定义一的合法轨迹段（初态不限）。  
　C₄（分支与读开）存在结构位 x 与两条可用出边 e₁ ≠ e₂（e\_i = (x, y\_i)），申报构型下 Mask\_{e₁} = Mask\_{e₂} = 1。来源：介质申报与 c 的申报。  
　C₅（复入与外生经历的许可）x ∈ Ent；自合法初态 D₀ 起，申报交付协议许可由向 x 的交付 (x, p) 与单跳外生经历 (x, p, (x, y\_i))（i = 1, 2）任意组成的有限序列，在同一合法运行中、于 C₄ 的读开构型与 C₇ 的执行配置之下依次实现。许可指这些交付的组合可在同一运行中联合实现，不是分别各自许可。来源：初始规定六（由信号流在历史中不断改变场）；F\_min、F\_LB 的 Mode\_exo 与许可协议 Prot\_LB。  
　C₆（初态留存）D₀ 上 RT₁(m⁰\_{e₁}) 或 RT₁(m⁰\_{e₂}) 成立：初态在这两条边上不全饱和，一次沉积留得过一个沉积钟步。来源：3.4。  
　C₇（开启与无侵入的许可）申报协议许可在 SED = 1 下运行，且许可的运行中没有必须执行的边界外代算，也没有必须作用于 A(x) 边迹与末端位迹的 Idle、Pass 之外的协议操作。来源：初始规定二、七、八；生成计算一般式 ¬Intr。  
　C₈（比较投影）比较投影 π\_cmp = (τ\_Φ, 本步输入, c, q) 与完整状态读法先于一切运行申报。来源：计算分层一般式第一节其五。  
C\_pre := C₁ ∧ … ∧ C₈。  
运行级条件，对一段运行 σ：  
　C₁(σ)　σ ⊆ Θ，σ 中的变换由 P 的执行完成。  
　C₃(σ)　σ 自 D₀ 开始。  
　C₇(σ)　σ 中 SED = 1；生成计算一般式的 ¬Intr 在 σ 上成立；A(x) 的边迹与末端位迹在 σ 内除 Idle、Pass 外不受其他协议操作（训练规则的写入、裸改、冻结切换、屏蔽或可用性的改变）。  
　C₈(σ)　σ 是同一合法运行（生成计算一般式 Hold、Multi）。  
C\_run(σ) := C₁(σ) ∧ C₇(σ) ∧ C₈(σ)；Run\_legal 为申报协议下的合法运行之集。  
条件组的各项是规则自身的性质（C₂ 与 3.3、3.4）、初态的性质（C₃、C₆）、任务侧的申报和许可（C₁、C₄、C₅、C₇、C₈）与运行级的事实（C\_run(σ)、C₃(σ)）。C₅、C₇ 只陈述协议许可什么，不陈述任一运行段实际发生了什么；运行段内实际发生的事件由 C\_run(σ) 与 4.3 的见证构型陈述。

### 4.3　见证构型 Γ(σ)（运行段内的事件）

对一段运行 σ，Γ(σ) 指存在下列五项：  
　Γ1（实际经过）σ 在某次脉冲 t₁ 的某一跳于 x 实际经过 e₁ = (x, y₁)；记此前的历史为 h⁻，实际历史为 h₁。  
　Γ2（合法替代）在 h⁻ 之后、以 e₂ = (x, y₂) 代替 t₁ 该跳的历史 h₂ 属申报的合法历史族：e₁ 来自外生经历时，h₂ 以许可的外生经历 (x, p, (x, y₂)) 代之；e₁ 来自续行抽样时，e₂ 在该处的续行概率为正。h₂ 此后的交付、外生控制操作与随机数与 h₁ 共用。  
　Γ3（实际复入）σ 在其后的脉冲 t₂ 于 x 实际执行一次续行读入；记 k 为 t₁ 该跳的 Pass 与 t₂ 的读入之间沉积钟的步数。比较同构：h₁、h₂ 在 t₂ 的比较点有相同的 τ\_Φ、本步输入 u、外生控制构型 c = (SED, Mask, Avail)、当前位 q = x、可用出边集 A(x) 及其申报次序；其 c 在 A(x) 上保持 C₄ 的读开构型。两史的场态 D 不要求相同。  
　Γ4（读入集隔离）自 t₁ 该跳之后至 t₂ 的读入之前：（i）A(x) 各边的边迹在 h₁、h₂ 中都只受 Idle；（ii）S 读位迹时，比较时 n\_{y₁} 在 h₁ 中 ⪰ 在 h₂ 中，n\_{y₂} 在 h₁ 中 ⪯ 在 h₂ 中，A(x) 其余各边末端的位迹两史相同。  
　Γ5（留存到读入）RT^pre\_k(m̂\_{e₁}) 或 RT^pre\_k(m̂\_{e₂}) 成立，m̂ 为 t₁ 该跳经过前一刻（本脉冲开始时的 Idle 与此前各跳都已作用之后）A(x) 的边迹，两史在此刻相同；k 取 Γ3 所定之数。  
Γ(σ) 中没有一项陈述历史差异已经进入后继，也没有一项陈述沉积已被读入：Γ1、Γ3 是两个执行事件的发生，Γ2 是反事实的合法性，Γ4、Γ5 是两事件之间读入集的演化与留存。TR5 是规则对场态的函数依赖，执行读入沉积（Rd）是这一依赖在 Γ 所给的那条见证链上的实际发生，由下文证明。

### 4.4　结果 R

对一段运行 σ：  
　R₁(σ)（段内生成）Φ(∅)(σ) 成立，且存在见证链 χ，χ 所依的历史条件在 σ 内形成：σ 内 χ 上的沉积更新事件集非空，其中每一事件满足 ImplDecl 与执行驱动（W(χ) 非平凡成立）。  
　R₂(σ)（反作用往返）χ 上在 σ 内形成的迹被 σ 内的后续执行读入，使读入处的续行核改变，并在共用随机源的一个正测度抽样集上改变实际出边，从而改变其后写入的位置：流改渠，渠定流，再改渠（初始规定三所说水流过之后又反蚀渠网）。  
　R₃（无对象规则）τ\_Φ 不含对象规则（定义见 5.5）。  
Φ(∅)、E1—E4、W、Rd、共同见证 χ 按计算分层一般式第一节其四、第四、五节与"附：计算分层一般式·形式化"第二、三节原义使用。

### 5.1　两条引理

引理 1（迹差留存）　设 C₂、C₇(σ)，两段历史 h₁、h₂ 满足 Γ1—Γ5。则比较时：  
　ρ(m\_{e₁}) 在 h₁ 中不小于在 h₂ 中，ρ(m\_{e₂}) 在 h₁ 中不大于在 h₂ 中，至少一者严格；  
　S 读位迹时，ρ\_d(n\_{y₁}) 在 h₁ 中不小于在 h₂ 中，ρ\_d(n\_{y₂}) 在 h₁ 中不大于在 h₂ 中；  
　A(x) 的其余各边及其末端，进入得分的读数两史相同。  
证明　两史在 t₁ 该跳之前相同（Γ2），该跳经过前一刻的边迹为 m̂。由 TR1，该跳在 h₁ 中对 m\_{e₁} 作一次 Pass，在 h₂ 中对 m\_{e₂} 作一次 Pass。由 Γ4（i），此后至比较，两史中 A(x) 的边迹只受 Idle，共 k 次。于是 h₁ 中 m\_{e₁} 成为 Idle^k Pass\_p m̂\_{e₁}，h₂ 中成为 Idle^k m̂\_{e₁}；由 TR2，Pass\_p m̂ ⪰ m̂，Idle 保持 ⪰，故前者读数不小于后者，RT^pre\_k(m̂\_{e₁}) 时严格。m\_{e₂} 对称。A(x) 其余各边在两史中所受算子相同，由 TR4 的确定性取值相同。位迹各款由 Γ4（ii） 与 ⪰ 的定义（取 k = 0）直接得出。由 Γ5，至少一者严格。∎

引理 2（比值核）　设 TR5。若自 h₂ 到 h₁，s\_{e₁} 不减、s\_{e₂} 不增、至少一者严格，A(x) 其余各边的得分不变，则 K\_x(e₁)/K\_x(e₂) 严格增大；从而 K\_x 改变，且在按固定出边次序的逆分布抽样下，两分布给出不同实际出边的随机数集测度为正。  
证明　K\_x(e₁)/K\_x(e₂) = φ(s\_{e₁})/φ(s\_{e₂})，φ 严格增且为正，故该比值严格增大，两分布不同。两分布不同，则其累积分布在某处不同，逆分布抽样在其间给出不同的出边，该区间长度为正。∎

### 5.2　定理一（生成必然定理）

定理一乙（运行段内的生成必然性）　设 C₁、C₂、C₄、C₈ 与 C\_run(σ)，σ 满足 Γ(σ)。则 R₁(σ) 与 R₂(σ) 成立。携计算执行一般式-H3。

证明　E1：由 C₁ 与 C₁(σ)。  
　E2：由 Γ3 的比较同构，两处比较状态的 τ\_Φ、本步输入、c、q 相同，A(x) 及其次序相同；π\_cmp 先于运行申报（C₈）；故两处的 π\_cmp 相同，且两处的续行核在同一出边集上比较。由引理 1，ρ(m\_{e₁}) 在 h₁ 中不小、ρ(m\_{e₂}) 不大、至少一者严格，末端位迹同向，其余读入不变。由 TR5 与 Γ3（c 保持 C₄ 的读开构型，Mask\_{e₁} = Mask\_{e₂} = 1），s\_{e₁} 不减、s\_{e₂} 不增、至少一者严格。由引理 2，K\_x 不同；共用随机源下，t₂ 处的实际后继在正测度的抽样上不同。  
　E3：（i）差异由 A(x) 的边迹与末端位迹承担，它们属 P 所持的 D，经续行核这一执行进入后继；没有边界外代算（C₇(σ)）。（ii）见证所依的历史条件——t₁ 该跳的 Pass——在 σ 内形成，是被合法申报的实施（C₂），t₁ 脉冲的启动是该更新本次演化的实际原因之一（计算执行一般式 Ex，携该式-H3）；A(x) 的读入集在 σ 内除 Idle、Pass 外不受其他改变（C₇(σ)）。  
　E4：承担差异的分量，其历史依赖由 Idle、Pass 给出，按 3.3 的逐款对应满足可沉积性。这里段内有沉积更新，E4 由更新本身认证，不依赖段首场态的场资格。  
　W(χ)：χ 上 σ 内的沉积更新事件，是 t₁ 该跳的 Pass 与其后的各次 Idle 及 Γ4（ii）所涉的末端写入，全部是申报实施并由执行驱动（C₂、C₇(σ)）；Pass 事件存在，W 非平凡。  
　Rd(χ)：t₂ 处 ρ(m\_{e\_i}) 作为 S 的自变量进入 K\_x（TR5），这次读入是 σ 内实际发生的执行（Γ3）。  
　E2、E3、E4、W、Rd 都在 Γ 所给的同一条见证链上认证。故 Φ(∅)(σ) 成立，R₁(σ) 成立。  
　R₂(σ)：由引理 2，取随机数于两分布的差异区间，t₂ 处 h₁、h₂ 经过不同的出边；由 TR1，其后的 Pass 写在不同的边上。χ 上形成的迹在 σ 内被读入，改变了实际所经，又改变了下一次写入。∎  
结论的读法：K\_x 不同是确定的；"改变实际出边"是共用随机源下的路径差异——两史给出不同出边的抽样集测度为正，不是说 σ 中实际实现的那一次抽样必定落在其中。单次观测看不到出边的差异，不否定 R₂(σ)。

定理一甲（生成见证的存在性）　设 C\_pre。则存在 σ ∈ Run\_legal，满足 C₃(σ)、C\_run(σ) 与 Γ(σ)，从而 R₁(σ) 与 R₂(σ) 成立。携计算执行一般式-H3。

证明　自 D₀ 起构造 σ：第一次脉冲为外生经历 (x, p, (x, y₁))，第二次脉冲向 x 交付 (x, p)。这一序列在同一合法运行中的联合实现为 C₅ 所许可；σ 由 P 执行（C₁、C₂），SED = 1 且不作任何别的协议操作（C₇ 许可之），整段为同一运行——故 σ ∈ Run\_legal，C₃(σ)、C\_run(σ) 成立。逐项验 Γ：Γ1 为第一次脉冲的单跳；Γ2 的替代为许可的外生经历 (x, p, (x, y₂))，其后交付共用；Γ3 为第二次脉冲在 x 的续行读入，k = 1；两史都以 (x, p) 处于 x，二者都不改变 c，c 保持 C₄ 的读开构型，A(x) 及其次序是介质申报所给，故比较同构成立；Γ4（i）两脉冲之间 A(x) 的边迹只受第二次脉冲开始时的一次 Idle；Γ4（ii）单跳外生经历只写 n\_x 与所经边的末端，故 n\_{y₁} 在 h₁ 中多受一次 Pass、n\_{y₂} 在 h₂ 中多受一次 Pass，其余末端两史相同，由 TR2 得所需的 ⪰；Γ5：该跳是第一次脉冲的第一跳，经过前一刻的边迹为 Idle m⁰，RT^pre\_1(Idle m⁰) 即 RT₁(m⁰)，即 C₆。由定理一乙即得。∎

强度　定理一甲断言生成见证的存在：在条件组下可以构造出使生成发生的合法运行，不断言每一合法运行都使生成发生。定理一乙断言运行段内的必然：凡实际包含见证构型的运行段，生成在其中不能不发生。二者所给差异都是非零，不断言大于任何给定的分辨度（见 5.9）。实例：F\_LB 新场上 TV = 0.312，F\_min 新场上 TV = 0.041；在 TR1—TR5 的随机实例 4000 例中，C₆ 成立的 3517 例得分差的变化全部为正，反作用往返可检的 3262 例全部成立（附录 B 条目 B-1、B-2，均为定理一甲的构造运行）。

### 5.3　定理二（自主续行中的见证构型）

设 C₁、C₂、C₄、C₈ 与 C\_run(σ)；x 为源入口（没有入边）；σ 在 t₁ 有一次向 x 的交付，其第一跳由续行抽样取 e₁，并在其后的 t₂ 有下一次向 x 的交付；RT\_k(m\_{e₁}) 或 RT\_k(m\_{e₂}) 成立（m 为 t₁ 脉冲开始前的边迹，k 为该跳的 Pass 至 t₂ 读入之间沉积钟的步数；x 是源，该跳是 t₁ 的第一跳，故 RT\_k(m) 即 RT^pre\_k(Idle m)）；并满足下列之一：  
　（a）关系读入：S 与第二自变量无关；  
　（b）隔离 Iso(x)：在跳数上限 H 内，自 A(x) 任一末端出发的路线不到达 x，也不到达 A(x) 的其他末端，且 t₂ 是紧接 t₁ 的下一次脉冲。  
则 Γ(σ) 成立，从而 R₁(σ)、R₂(σ) 成立，见证由 P 自身的续行抽样形成。携计算执行一般式-H3。

证明　Γ1、Γ3 为所设的两次交付；比较同构：h₂ 与 h₁ 共用交付与外生控制操作，C₇(σ) 下 A(x) 的 c 在 σ 内不变，t₂ 两史都以同一交付处于 x，A(x) 及其次序由介质申报给出；Γ2：e₂ 的续行概率为正（φ \> 0），其后各跳与交付共用。Γ4（i）：x 是源，A(x) 的边只在 x 脉冲的第一跳被经过，而 t₁ 与 t₂ 之间没有 x 脉冲，故两史中 A(x) 的边迹只受 Idle。Γ4（ii）：（a）下末端位迹不进入得分，此款不用；（b）下逐一写出两史对各末端位迹的算子序列。记 n̂ 为 t₁ 该跳经过前一刻的位迹（两史相同）。t₁ 该跳之后至 t₂ 读入之前，只有 t₁ 脉冲的其余各跳与 t₂ 脉冲开始时的一次 Idle（t₂ 紧接 t₁）。h₁ 中：n\_{y₁} 先作为 e₁ 的末端受一次 Pass，其后 t₁ 的路线自 y₁ 出发，可能多次以 y₁ 为起点或末端再受 Pass，但这些都是 Pass，中间没有 Idle；由 Iso(x)，这条路线不到达 y₂ 与 A(x) 的其他末端。于是 h₁ 中 n\_{y₁} = Idle Pass^j n̂\_{y₁}（j ≥ 1），n\_{y₂} = Idle n̂\_{y₂}，其余末端 = Idle n̂。h₂ 对称：n\_{y₂} = Idle Pass^{j′} n̂\_{y₂}（j′ ≥ 1），n\_{y₁} = Idle n̂\_{y₁}，其余末端 = Idle n̂。由 TR2，Pass(n) ⪰ n，⪰ 传递，故 Pass^j n̂ ⪰ n̂；Idle 保持 ⪰。所以 n\_{y₁} 在 h₁ 中 ⪰ 在 h₂ 中，n\_{y₂} 在 h₁ 中 ⪯ 在 h₂ 中，其余末端两史相同，即 Γ4（ii）。Γ5：该跳经过前一刻的边迹为 Idle m，RT\_k(m) 即 RT^pre\_k(Idle m)。由定理一乙即得。∎  
存在形式：设 C\_pre、x 为源入口、（a）或（b）。自 D₀ 起由 C₅ 向 x 连续交付两次，第一次第一跳取 e₁ 有正概率，SED = 1、不作别的协议操作（C₇）；取 k = 1，Γ5 即 RT₁(m⁰)，由 C₆。故存在 σ ∈ Run\_legal，满足 C₃(σ)、C\_run(σ) 与 Γ(σ)，见证由 P 自身续行给出。

抵消反模型　条件（a）（b）在这一证明中承重。介质取 x→y₁、x→y₂、y₂→y₁、y₁→w、w→y₁、y₁→z（z 无出边），跳数上限 H = 6；h₁ 的路线为 x, y₁, z（止于 z），h₂ 的路线为 x, y₂, y₁, w, y₁, w, y₁（止于跳数上限），二者在任一取正值的续行核下都是正概率的完整轨迹；边迹每次经过加 0.25，位迹每次加 1，无退浅，S = κ₀ + g + w\_d·d。比较时 n\_{y₁} 在 h₁、h₂ 中为 2、5，n\_{y₂} 为 0、2，Γ4（ii）不成立；s\_{e₁} − s\_{e₂} 在 h₁ 中为 0.25 + 2w\_d，在 h₂ 中为 −0.25 + 3w\_d；w\_d = 0.5 时二者相等，两史在 x 的续行分布完全相同，这一对历史不见证 E2；w\_d = 0.02 时 TV = 0.654（附录 B 条目 B-6）。同一系统中由外生经历仍可按定理一甲取得见证。

### 5.4　定理三（满足留存的每一次经过都成为条件）

在定理二（a）的条件下，σ 内 x 处的每一次实际经过 e，凡其后在 σ 内实际有下一次 x 复入、且 RT\_k(m\_e) 或 RT\_k(m\_{e′}) 成立者（m 为该次脉冲开始前的边迹，e′ 为 A(x) 中另一条出边，申报构型下 Mask\_e = Mask\_{e′} = 1，k 为该次经过至下一次复入读入之间沉积钟的步数），与其合法反事实 e′ 相比，下一次复入时 K\_x 不同。携计算执行一般式-H3。

证明　对每一次这样的经过，取 t₁ 为该次、t₂ 为下一次 x 复入，由定理二（a）的证明，Γ(σ) 以 (e, e′) 成立；由引理 1、2 即得。∎

在这些条件下，动力层不是一次性地生成：每一次满足留存、其后又有复入的经过，都成为其后续行的条件。实例：随机运行中可判定的 8799 次检查全部成立；F\_LB（不满足（a）（b））上 199 次检查也全部给出非零差异（附录 B 条目 B-4）。

### 5.5　定理四（无须对象规则）

定义（对象规则）　τ\_Φ 中的一个条款，其作用式以某一结构位、关系或入口的名字——而不是其场态——为自变量，规定或偏置该处的续行或沉积。初始规定一所说规则变换的执行节点规定为了形成这条律下一步怎样走，正是这样的条款。例：在 a1 一律取 m1（计算分层一般式第七节的 τ\_C）；对某一边的得分附加常数；只对某一边写入。

定理四　τ\_Φ ∈ 𝔗 时，τ\_Φ 不含对象规则；定理一甲、一乙、二、三对 𝔗 的每一成员成立。故动力层的生成无须写入任何对象规则。

证明　TR4 规定 Idle、Pass、S、φ 对一切位置是同一函数，不以位置的名字为自变量；对象规则按定义以位置的名字为自变量，与 TR4 相违。定理一甲至三的证明只用 TR1—TR5、条件组与见证构型。∎

推论 4.1（等变）　τ\_Φ ∈ 𝔗 与介质的任一改名交换：改名后的介质、初态与历史给出改名后的场态与续行分布。实例：随机 500 例一致规则失配 0；含对象条款的规则 500 例中失配 480（附录 B 条目 B-5）。  
推论 4.2（方向由历史给出）　设介质有自同构 ψ，固定 x 而交换 e₁、e₂，D₀、交付与控制构型都在 ψ 下不变或随之变换。则由推论 4.1，同一规则下历史 h 与其像 ψ(h) 给出互换的续行概率：K\_x^{ψ(h)}(e₁) = K\_x^{h}(e₂)，K\_x^{ψ(h)}(e₂) = K\_x^{h}(e₁)；若 h 形成严格偏向（K\_x^h(e₁) ≠ K\_x^h(e₂)），ψ(h) 形成反向的严格偏向；h 无偏向时 ψ(h) 亦无偏向。实例：F\_LB 的介质以 (m1 m2)(c x) 为自同构（此处 c、x 是 F\_LB 介质中结构位的名字，分支位为 a1）；新场经 20 次 a1→m1→c 后 P(m1 \| a1) ≈ 1.000，经其像历史后 P(m1 \| a1) ≈ 3.2×10⁻¹³（附录 B 条目 B-5）。动力条件偏向哪一边，由历史给出，规则只给出偏向如何随历史形成。  
推论 4.3（把对象写进介质）　若介质在 x 只留一条可用出边，x 处 K\_x 是单点分布，任何历史都不改变它，E2 不能在 x 得到见证。以外生控制构型只留对象的路线可用，在被限定的位上同此：这些位上没有可由历史改变的续行。  
推论 4.4（完全决定续行的对象规则在其所在处取代动力）　若 τ\_Φ 在 x 含对象规则，且该规则完全决定 x 处的续行——对一切合法可比的场态 D、D′，K\_x(D) = K\_x(D′)（如"在 x 一律取 e₁"）——则任何历史都不改变 K\_x，E2 不能在 x 得到见证。这与计算分层一般式第七节的结论（τ\_C 下该处 DynamicRole 不成立）是同一事实的两面：完全决定续行的对象规则所在之处，律的承担与动力的生成一并让位于规则。只作偏置的对象规则（如对某一边的得分附加常数，其余仍读边迹）不取消该处的动力读入：历史照样改变续行，只是偏向的一部分由规则预先写定；这样的 τ\_Φ 不属 𝔗，定理一甲至三对它的前件不成立，其结论是否成立须另证。

### 5.6　定理五（初始势不定命）

得分遗忘 Fgt\*：对任一边迹 m 与位迹 n，S(ρ(Idle^j m), ρ\_d(Idle^j n)) 在 j → ∞ 时趋于 S(ρ(o), ρ\_d(o))（3.4 的 Fgt 加上 S 的联合连续即可推出；有限步达到零迹者自然满足）。

分支位无自环 NL(x)：A(x) 的每一条出边的末端都不是 x。定理五、六用它保证：反复经过一条出边时，其余出边的边迹与末端位迹只受 Idle——经过 e₂ 时 x 作为起点受 Pass，若某条出边的末端就是 x，其得分仍会经 n\_x 被持续加深。

定理五　设 τ\_Φ ∈ 𝔗、Fgt\*、RT₁(o)（零迹上的一次沉积留得过一个沉积钟步）、NL(x)，以及 C₁、C₂、C₄、C₅、C₇；e₁、e₂ 为 C₄ 所给的两条读开出边。则对任一满足 C₃、且 C₅ 对其成立的初态 D₀（可任意不均匀），存在自 D₀ 开始、满足 C\_run 的合法外生历史——反复向 x 交付外生经历 (x, p, (x, y₂))——使有限次之后 K\_x(e₂) \> K\_x(e₁)。

证明　这段历史的每次脉冲只有单跳 x→y₂，由 TR1 只写 m\_{e₂}、n\_x、n\_{y₂}；由 NL(x)，y₁ ≠ x，又 y₁ ≠ y₂（简单图），故 e₁ 与 y₁ 只受 Idle，由 Fgt\*，s\_{e₁} 趋于 S(ρ(o), ρ\_d(o))。e₂ 每次受 Idle 后再受 Pass：由 TR2（o 最小，算子保序），每次之后 m\_{e₂} ⪰ Pass\_p Idle o，比较时 ρ(m\_{e₂}) ≥ ρ(Idle Pass\_p Idle o)。记 δ := ρ(Idle Pass\_p Idle o) − ρ(o)，由 RT₁(o) 与 Idle(o) = o，δ \> 0。y₂ 的位迹 ⪰ 零迹。由 Mask\_{e₂} = 1 与 TR5，s\_{e₂} ≥ S(ρ(o) + δ, ρ\_d(o)) \> S(ρ(o), ρ\_d(o))。故有限次后 s\_{e₂} \> s\_{e₁}，由 TR5，K\_x(e₂)/K\_x(e₁) = φ(s\_{e₂})/φ(s\_{e₁}) \> 1。∎

定理五断言的是改写起始偏向的合法外生历史存在；它不断言自主运行必定改写。

命题 5.1（锁定）　Idle 为恒等、e₁ 的初态读数已达可达的上确界而 Pass 只能渐近、不能达到、S 不读位迹时，任何历史都不能使 K\_x(e₂) \> K\_x(e₁)：初态在此锁定。证明：e₁ 的读数始终是上确界，e₂ 的读数始终不大于它，S 关于第一自变量增、不读位迹，s\_{e₂} ≤ s\_{e₁}，故 K\_x(e₂) ≤ K\_x(e₁)。∎  
实例：退浅为线性截底、指数、时间窗口三族，强偏初态分别在第 104、47、26 次被改写；无退浅且初态饱和者 5000 次内不改写；无退浅而无容量上限者在第 61 次改写——锁定须同时有"无退浅"与"饱和"（附录 B 条目 B-7）。

初始场的不均匀给出起始的势（初始规定十一）。在"少用则迹淡"之下，它不决定此后的动力条件；退浅缺席而初态已饱和时，初态成为不可由历史改写的规定。可沉积性中"少用则迹淡"一款，在充分方向上承担的正是这一点。  
推论 5.2　在定理五的条件下，比较时刻的动力条件随初态与历史二者而变。

### 5.7　定理六（确定读入下的改路）

规则类 𝔗\_det：TR1—TR4 不变；TR5 换为 TR5′——S 关于第一自变量严格增、关于第二自变量不减，续行取得分最大的可用出边，同分时按介质申报中 A(v) 的固定次序取首位。这一次序是介质申报的一部分，结构位改名时随之搬运；在此约定下推论 4.1 对 𝔗\_det 同样成立，次序本身不以名字规定续行，不构成对象规则。

定理六　设 τ\_Φ ∈ 𝔗\_det、Fgt\*、RT₁(o)、NL(x)，以及 C\_pre（其中 C₂ 的 𝔗 换为 𝔗\_det，C₆ 由 RT₁(o) 代）。则存在 n，使"向 x 交付 n 次外生经历 (x, p, (x, y₁))，再向 x 交付 (x, p)"与"以 (x, p, (x, y₂)) 代替前 n 次"的两段合法历史，在最后一次交付处 x 的实际出边不同；E2 由此得到见证，两段运行都可取为满足 C₃(σ)、C\_run(σ) 的合法运行，前一段满足 R₁，携计算执行一般式-H3。

证明　n 充分大时，第一段历史中：每次脉冲只写 m\_{e₁}、n\_x、n\_{y₁}；由 NL(x) 与简单图，A(x) 其他各边的末端既不是 x 也不是 y₁，故这些边与其末端只受 Idle，由 Fgt\*，其得分趋于 S(ρ(o), ρ\_d(o))；s\_{e₁} ≥ S(ρ(o) + δ, ρ\_d(o))（δ 同定理五的证明，由 RT₁(o) 为正），严格大于该极限。故有限次后 s\_{e₁} 严格大于 A(x) 中其他各边的得分，最大者为 e₁；第二段历史中同理，最大者为 e₂。两段历史都不改变 c（C₇），在最后一次交付处 τ\_Φ、本步输入、c、q 与 A(x) 及其次序相同，π\_cmp 相同，实际出边不同，E2 成立；E3、E4、W、Rd 同定理一乙。∎

随机读入下，一次经过之差即成为条件；确定读入下，一次经过之差不一定改变去向，须积累到改路。初始规定六所列反蚀与改路即后一种。实例：确定读入的随机实例 600 例中只有 137 例一次即改路；留存成立的 490 例中 489 例在 600 次内改路，其余一例为慢退浅（退浅率 0.001、第三出边初态深），至迟在第 750 次改路（第 700 次时尚未改路；附录 B 条目 B-8）。

### 5.8　定理七（动力层成立）

凡满足 R₁ 的运行段 σ（定理一乙、一甲、二所给者，以及定理六的运行段），Φ(∅)(σ) 成立；由计算分层一般式总定理（一），S 与 D（此处 S、D 为计算分层一般式的宿载层与动力层，S 不是 3.2 的得分函数）在 P 上成立，D 是 S 之上的一级：Layer(S, D)。所携：计算执行一般式-H3、生成计算一般式-H1、H2、计算分层一般式-H1。其中计算分层一般式-H1 在这里只承担见证分量归入 P 的沉积场持久场态（D\_E2 ⊆ D\_P），E4 已由段内更新认证。

初始规定六所说宿载按规则能够自动生成动力层，在 𝒲₇ 内由计算分层一般式的必要方向与本篇的充分方向合成为条件化的结论：职责 Φ(∅) 必有宿载层与动力层；迹应规则类连同条件组，必有合法运行使 Φ(∅) 成立，凡包含见证构型的运行段必使 Φ(∅) 成立。条件组不是 Φ(∅) 的必要条件：冻结部署与只读部署可以满足 Φ(∅)，其 D 的资格由段首场态承担（计算分层一般式第六节），它们不满足 C₇(σ) 的开启。

### 5.9　定理八（与生成计算一般式七项的对应）

在定理一乙的比较步（t₂ 的读入）上，两份比较状态都是合法可达状态，u、c 相同，当前位都是 x；设二者的非场部分 x\_s 也相同（比较读入是 t₂ 的第一跳时即如此），则二者只在 D 上不同。若申报分辨度 ε\_role 小于两分布的全变差 TV，且这两份状态属于申报的合法反事实族 AdmVar（其覆盖按生成计算数理式定义 3.11 取证书），则依生成计算数理式定义 3.11（Var\_k(C) 为 AdmVar\_k 中与当前取值 ν\_k 在 C 上一致者之集，Δ\_k(C) 为其中任两者生成核全变差的上确界，Δ\_k(C) ≤ ε\_role 即 C 为 μ-充分，D 属某一极小 μ-充分组即 D ∈ ActArg^μ）：取 ν\_k 为实际历史 h₁ 的比较状态；对任何不含 D 的输入组 C，h₂ 的比较状态与 ν\_k 在 C 上一致（二者只在 D 上不同），同属 Var\_k(C)，故 Δ\_k(C) ≥ TV \> ε\_role，C 不是 μ-充分的；全部输入集 A\_k 上 Var\_k(A\_k) = {ν\_k}，Δ\_k(A\_k) = 0，是 μ-充分的；输入集有限，故极小 μ-充分组存在，且都含 D，D ∈ ActArg^μ，该步 Gov 成立。这一推出与生成计算一般式的可比性论证相同，不经生成计算一般式-H2。

命题 8.1（全变差下界）　续行核为两出边 softmax 时，记 z = (s\_{e₁} − s\_{e₂})/T，ℓ(z) := 1/(1 + e^{−z})（逻辑斯蒂函数），则 TV ≥ \|z\_{h₁} − z\_{h₂}\|·min ℓ(z)(1 − ℓ(z))，最小值取于 z\_{h₁}、z\_{h₂} 之间。证明：TV = \|ℓ(z\_{h₁}) − ℓ(z\_{h₂})\|，由中值定理。∎  
差异非零与差异可辨　E2 只要求差异非零；Gov 在申报分辨度上成立，另须 TV \> ε\_role。初态在 e₁ 上偏得越深，一次经过之差给出的 TV 越小：F\_LB 中 a1→m1 的初态 g = 0、1、2、4、8 时，TV 依次为 0.312、0.122、3.1×10⁻⁶、4.9×10⁻¹²、6.1×10⁻²⁴（附录 B 条目 B-3）。历史成为条件是必然的，成为在给定分辨度上可辨的条件则另有量的前提。

七项中由条件组与见证构型直接给出的是：Gov（该步，另需比较状态 x\_s 相同、ε\_role \< TV 与 AdmVar 证书）、¬Intr（C₇(σ)）、Sed（ii）（C₂：沉积模式由 P 实现）、A(x) 读入集上的 Sed（iii）（C₇(σ)）。Step、Carry、Hold、Multi 是运行结构项，按生成计算一般式与生成计算数理式的定义逐项判定；Sed（i）须上游的场资格证书（F\_min、F\_LB 有构造证书）。故：定理一乙的前提 ∧ 两份比较状态的 x\_s 相同 ∧ 场资格证书 ∧ Step ∧ Carry ∧ Hold ∧ Multi ∧ σ 内 D 的写入全对应协议记录 ∧ ε\_role \< TV ∧ AdmVar 证书 ⇒ 七项在 σ 上成立。这回答七项在何种附加条件下成立的前件一侧；以 G6 为规定的生成计算 GenComp 不在其内。

### 6.2　边界情形

冻结部署、只读部署：满足 Φ(∅) 而不满足 C₇(σ) 的开启，D 的资格由段首场态承担（计算分层一般式-H1）；这是 Φ(∅) 的另一来源，不是本篇定理的反例。  
预装与移入的初态：C₃ 容许之；定理一的见证在 σ 内另行形成，与初态的来源无关。  
训练：训练规则的写入不在 𝔗 的 Pass 之内（初始规定七）。它写在 A(x) 读入集之外时，定理一照常成立；写在其上时，C₇(σ) 不成立。  
LMS 滤波与储备池计算：LMS 的权重按实际误差更新，同一输入的重复经过可使更新趋于零或反号，不满足 TR1、TR2；储备池的内部权重是规则配置，不受迹应写入。二者不在 𝔗 之内，定理一的前件不成立，其结论不及于二者；若其权重所承担的历史依赖不满足可沉积性，按计算分层一般式的必要方向，Φ(∅) 不能以之为见证。  
连续向量介质：在 𝒲₇ 之外。

### 6.3　缺口申报

本篇无新增缺口。定理一至六只用条件组、见证构型、TR1—TR5（定理六为 𝔗\_det）与承继项；E4 的依据是 3.3 的逐款对应，由可沉积性五款与 TR 的条文逐一核对，不依赖待验物理桥。  
承继条件，按原编号：计算执行一般式-H3（E3（ii）与 W 的执行归责；定理一甲、一乙、二、三、六）；生成计算一般式-H1、H2 与计算分层一般式-H1（定理七）；生成计算一般式 Sed（i）的场资格证书与生成计算数理式中 AdmVar 的覆盖证书（定理八）。条件闭包：引用定理一至三、六者，携计算执行一般式-H3；引用定理七者，另携生成计算一般式-H1、H2 与计算分层一般式-H1；引用定理八者，另携比较状态 x\_s 相同、场资格证书、运行结构项、AdmVar 证书与 ε\_role \< TV。引用定理一乙者，须连同见证构型 Γ(σ) 一并引用；引用定理一甲者，只得到存在性。  
申报模型：结论在 𝔐\_Gen 的申报模型内成立。某一实际宿载是否实现了所申报的 τ\_Φ，按计算数理式与生成计算数理式的申报制度判定。  
未答（不支撑总式与定理）：U1 连续向量介质（权重网络与符号矢量流）上的对应规则类与充分条件；U2 一般介质上自主续行见证的存在性（已知个别见证对可被抵消，5.3）；U3 动力变换的复杂程度（初始规定六所说信号流不断作用于场而产生的动力层的复杂变换）；U4 对象层在动力中的形成；U5 一般 Luce 型核下全变差的下界。

### 6.4　击穿方式

在 𝒲₇ 内：构造满足 C\_pre 的系统，而不存在满足 C₃(σ)、C\_run(σ)、Γ(σ)、R₁(σ)、R₂(σ) 的合法运行（击穿定理一甲）；或构造满足 C₁、C₂、C₄、C₈、C\_run(σ) 与 Γ(σ) 的运行段 σ，而 R₁(σ) 或 R₂(σ) 不成立（击穿定理一乙）；或指出 TR1—TR5 中某一条在 F\_min、F\_LB 上实际不成立，而本篇据之作了实例断言；或证明某一 TR 条款实质上以对象的名字为自变量；或在定理二、三、五、六的条件下构造相应结论不成立的系统。在 𝒲₇ 之外的系统、只满足许可而未包含见证构型的运行段、只说明条件组不必要的系统（如冻结部署），都是边界情形，不构成击穿。

"""F_LB = Augment(F_min).
Inherited from Canonical F* v1.2 (最小沉积场构造式 v0.9): node depth d, relation sediment g (saturating),
Trace / Sediment / Decay / Continuation, Mode_exo / Mode_endo, softmax solver.
Added (law-base layer): pulse strength p, threshold θ, S, derived groove set Γ, replay window & Ω,
Freeze^inst (SED=OFF), Avail (availability), RoleReadMask (targeted role intervention), dual clock t_run / t_sed, IdleStep (decay only), Established^inst(R)."""
import math, random, copy
from collections import defaultdict, deque

class FLB:
    def __init__(self, nodes, medium, alpha=0.05, beta=0.25, g_max=20.0, lam_d=0.01, lam_g=0.01,
                 theta=1.0, W=30, n_omega=3, kappa0=0.05, w_g=1.0, w_d=0.02, s_weak=0.4, T=0.15, seed=0):
        self.nodes=nodes; self.E=list(medium); self.out=defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        # inherited persistent state
        self.d={n:0.0 for n in nodes}; self.g={e:0.0 for e in self.E}
        # added persistent state
        self.rep={e:deque() for e in self.E}; self.Om={e:0.0 for e in self.E}
        self.th={e:theta for e in self.E}; self.Avail={e:1 for e in self.E}
        self.alpha,self.beta,self.g_max,self.lam_d,self.lam_g=alpha,beta,g_max,lam_d,lam_g
        self.W,self.n_omega,self.k0,self.w_g,self.w_d,self.s_weak,self.T=W,n_omega,kappa0,w_g,w_d,s_weak,T
        self.t_run=0; self.t_sed=0; self.SED=True; self.rng=random.Random(seed); self.log=[]; self.macro=None
        self.mask={e:1 for e in self.E}   # RoleReadMask: exogenous control quantity (not sediment, not decayed, persists until re-intervened)
    # ---------- inherited operators
    def Decay(self):
        """one sediment-clock step: t_sed advances; depths decay; replay windows (on t_sed) expire."""
        self.t_sed+=1
        for n in self.nodes: self.d[n]=max(0.0,self.d[n]-self.lam_d)
        for e in self.E:
            self.g[e]=max(0.0,self.g[e]-self.lam_g)
            while self.rep[e] and self.t_sed-self.rep[e][0]>self.W: self.rep[e].popleft()
            self.Om[e]=self._omega(e)
    def Trace(self,e,p): return {'e':e,'p':p}
    def Sediment(self,tau):
        e,p=tau['e'],tau['p']
        self.d[e[0]]+=self.alpha*p; self.d[e[1]]+=self.alpha*p
        self.g[e]=min(self.g_max,self.g[e]+self.beta*p*(1-self.g[e]/self.g_max))
        self.rep[e].append(self.t_sed); self.Om[e]=self._omega(e)
    def kappa(self,e):
        if not self.Avail[e]: return -1e9
        return self.k0+self.w_g*self.mask[e]*self.g[e]*(1.0 if self.S(e) else self.s_weak)+self.w_d*self.d[e[1]]
    def Continuation(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        if not cand: return None
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]
        r=self.rng.random()*sum(ws)
        for e,w in zip(cand,ws):
            r-=w
            if r<=0: return e
        return cand[-1]
    def probs(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return {e[1]:w/z for e,w in zip(cand,ws)}
    # ---------- added layer
    def S(self,e): return self.g[e]>=self.th[e]
    def Deposited(self,e): return self.g[e]>0
    def Groove(self,e): return self.S(e) and len(self.rep[e])>=2
    def Gamma(self): return {e for e in self.E if self.Groove(e)}
    def _omega(self,e):
        n=len(self.rep[e]); return 0.0 if (n<self.n_omega or not self.S(e)) else min(1.0,n/(2*self.n_omega))
    def Freeze(self): self.SED=False
    def Thaw(self): self.SED=True
    def SetAvail(self,e,v): self.Avail[e]=v
    def IdleStep(self,n=1):
        for _ in range(n): self.Decay()          # t_sed advances only
    def SetMask(self,e,v): self.mask[e]=v          # targeted role intervention (structure untouched)
    # ---------- pulse
    def pulse(self,entry,p=1.0,path=None,maxhop=6):
        self.t_run+=1
        if self.SED: self.Decay()                 # t_sed advances only when sediment law is on
        q=entry; route=[q]; inst=[]
        for h in range(maxhop):
            if path is not None:
                if h>=len(path)-1: break
                e=(path[h],path[h+1])
            else:
                e=self.Continuation(q)
                if e is None: break
            if not self.Deposited(e): inst.append(e)
            if self.SED: self.Sediment(self.Trace(e,p))
            q=e[1]; route.append(q)
            if not self.out[q]: break
        self.log.append((self.t_run,entry,tuple(route),self.macro))
        return route,inst
    # ---------- law-side readouts
    # duty = dict(ante=entry node, anchor=edge whose head state is the relation's antecedent, read=target node)
    def _closure(self,start,edges):
        adj=defaultdict(list)
        for (i,j) in edges: adj[i].append(j)
        seen={start}; st=[start]
        while st:
            x=st.pop()
            for y in adj[x]:
                if y not in seen: seen.add(y); st.append(y)
        return seen
    def CarrierRealizes_inst(self,R,duty):
        """R alone (restricted) carries Ante ⇝ Anchor.tail —Anchor→ Anchor.head ⇝ Read, all on deposited edges of R;
        the anchor edge itself must be traversed (it is deposited and on the path)."""
        a=duty['anchor']
        if a not in R or not self.Deposited(a): return False
        dep=[e for e in R if self.Deposited(e)]
        return a[0] in self._closure(duty['ante'],dep) and duty['read'] in self._closure(a[1],dep)
    def Established_inst(self,R,duty):
        """R ⊆ E ∧ ∀e∈R Deposited ∧ CarrierRealizes_inst. CarrierNonInstant is a type invariant here:
        g is persistent state, so Deposited(e) ⇒ not flow-only."""
        return set(R)<=set(self.E) and all(self.Deposited(e) for e in R) and self.CarrierRealizes_inst(R,duty)
    def MediumReach_inst(self,entry,Q):
        """medium access only: entry reaches the head of some Avail=1 edge in Q via Avail=1 edges. Does not require Q deposited."""
        seen=self._closure(entry,[e for e in self.E if self.Avail[e]])
        return any(self.Avail[e] and e[0] in seen for e in Q)
    def RolePath_inst(self,R,duty):
        """a deposited, mask-open path inside R from the anchor state to Read."""
        a=duty['anchor']
        if a not in R or not (self.Deposited(a) and self.mask[a]): return False
        open_edges=[e for e in R if self.Deposited(e) and self.mask[e]]
        return a[0] in self._closure(duty['ante'],open_edges) and duty['read'] in self._closure(a[1],open_edges)

def OmegaSupport_pre(F,entry,Q):
    """pre-stage interface for this construct only: MediumReach_inst(I,Q) ∧ ∃e∈Q Ω_e>0. Not the formal ΩSupport^M."""
    return F.MediumReach_inst(entry,Q) and any(F.Om[e]>0 for e in Q)
def DynamicRole_inst(F,R,duty,control_R=None,n=2000,delta=0.15):
    """RolePath_inst(R,d)=1 and do(Mask_R=0) changes P̂(Read|Ante) by >delta while a control mask on control_R does not;
    g,rep,Ω unchanged under both masks."""
    if not F.RolePath_inst(R,duty): return False,{}
    base=hit_prob(F,duty['ante'],duty['read'],n)
    L=copy.deepcopy(F)
    for e in R: L.SetMask(e,0)
    pm=hit_prob(L,duty['ante'],duty['read'],n)
    inv=(L.g==F.g and L.Om==F.Om and {e:len(L.rep[e]) for e in L.E}=={e:len(F.rep[e]) for e in F.E})
    pc=None
    if control_R:
        C=copy.deepcopy(F)
        for e in control_R: C.SetMask(e,0)
        pc=hit_prob(C,duty['ante'],duty['read'],n)
    ok=inv and (base-pm)>delta and (pc is None or abs(base-pc)<=delta)
    return ok,dict(P_hat_base=base,P_hat_Rmask=pm,P_hat_ctrlmask=pc,invariants=inv)
def hit_prob(F,entry,target,n=2000):
    G=copy.deepcopy(F); G.Freeze(); c=0
    for _ in range(n): c+= target in G.pulse(entry)[0]
    return c/n

def corr_M(F,a,b):
    """macro-event co-occurrence: Corr_M = #{k: a,b both in M_k} / #{k: a or b in M_k}."""
    ev=defaultdict(lambda:[False,False])
    for _,_,r,m in F.log:
        if m is None: continue
        if a in r: ev[m][0]=True
        if b in r: ev[m][1]=True
    both=sum(1 for x,y in ev.values() if x and y); either=sum(1 for x,y in ev.values() if x or y)
    return both/either if either else 0.0

"""rulelib.py — 迹应规则类 𝔗 的参照实现（第八《生成计算必然式》参考实现）。

规则只由三类算子给出，全部对一切边（位）一致，不以结构位的名字为自变量（TR3）：
  Idle  ：每个沉积钟步对一切迹状态作用一次（退浅，TR2）；
  Pass  ：被实际经过的边（及其两端位）作用一次（写入闸门与迹深，TR1）；
  score ：位置 x 的每一可用出边 e 的得分 s_e = k0 + w_g*h(ρ(m_e)) + w_d*ρ_d(m_head(e))，
          h 严格增；续行核把得分变成出边上的分布（TR4）。
迹状态族（trace family）：
  'linfloor'  g ← max(0, g−λ)；经过 g ← min(G, g+β p (1−g/G))          （F_LB / F_min 形式）
  'exp'       g ← γ g；        经过 g ← g + β p                         （指数退浅、无容量）
  'window'    状态为时间戳表；退浅＝时钟前进并丢弃窗口外记录；经过＝追加；ρ＝窗口内计数（以时间窗口内的经过次数为读数）
  'clamp'     g ← max(0, g−λ)；经过 g ← min(G, g+B)                      （可达容量的硬截断；崩坏条件 K3 用）
续行核（kernel）：'softmax'（温度 T）、'luce'（s^a 归一，s>0）、'linnorm'（s/Σs，s>0）。
共用随机源：续行按出边的固定次序做逆分布抽样，ξ ~ U[0,1)；两条历史用同一 ξ 序列即为共用随机源下的比较。
本文件只是参照实现；它不承担任何定理的证明。
"""
import math, random, copy
from collections import defaultdict

class Trace:
    def __init__(self, fam, **kw):
        self.fam = fam; self.kw = kw
    def init(self, v=0.0):
        if self.fam == 'window':
            return {'t': 0, 'ts': [0] * int(round(v))}      # v 次"段首之前"的经过（合法承接的初值）
        return float(v)
    def idle(self, m):
        k = self.kw
        if self.fam in ('linfloor', 'clamp'): return max(0.0, m - k['lam'])
        if self.fam == 'exp': return k['gam'] * m
        if self.fam == 'window':
            t = m['t'] + 1; return {'t': t, 'ts': [s for s in m['ts'] if t - s < k['W']]}
        if self.fam in ('none', 'schedule', 'overwrite'): return m
        raise ValueError(self.fam)
    def passed(self, m, p):
        k = self.kw
        if self.fam == 'linfloor':
            G = k['G']; return min(G, m + k['beta'] * p * (1 - m / G))
        if self.fam == 'clamp': return min(k['G'], m + k['B'] * p)
        if self.fam == 'exp': return m + k['beta'] * p
        if self.fam == 'window': return {'t': m['t'], 'ts': m['ts'] + [m['t']]}
        if self.fam == 'none': return m
        if self.fam == 'schedule': return m                  # 崩坏条件 K1：经过不写
        if self.fam == 'overwrite': return 1.0               # 崩坏条件 K11：规则状态（不随反复而深）
        raise ValueError(self.fam)
    def rho(self, m):
        if self.fam == 'window': return float(len(m['ts']))
        return float(m)

class Rule:
    """τ_Φ 的一个实例：迹族（边、位）＋得分＋续行核。全部参数对一切位置一致。"""
    def __init__(self, tr_g, tr_d, k0=0.05, w_g=1.0, w_d=0.0, h='id', theta=None, s_weak=0.4,
                 kernel='softmax', T=0.15, a=2.0, sched_delta=0.0, obj_clause=None):
        self.tr_g, self.tr_d = tr_g, tr_d
        self.k0, self.w_g, self.w_d, self.h, self.theta, self.s_weak = k0, w_g, w_d, h, theta, s_weak
        self.kernel, self.T, self.a = kernel, T, a
        self.sched_delta = sched_delta           # K1：按时间表给一切边加同量（与经过无关）
        self.obj_clause = obj_clause             # K10：对象规则条款 {位置名: 规定的出边}（违反 TR3）
    def hfun(self, r):
        if self.h == 'id': return r
        if self.h == 'thr':                       # F_LB 式：阈下以 s_weak 计，阈上全计；严格增（含阈处上跳）
            return r * (1.0 if r >= self.theta else self.s_weak)
        raise ValueError(self.h)
    def score(self, F, e):
        if not F.avail[e]: return None
        return self.k0 + self.w_g * F.mask[e] * self.hfun(self.tr_g.rho(F.g[e])) + self.w_d * self.tr_d.rho(F.d[e[1]])
    def probs(self, F, x):
        cand = [e for e in F.out[x] if F.avail[e]]
        if not cand: return []
        if self.obj_clause and x in self.obj_clause:          # 对象规则：不读场态
            return [(e, 1.0 if e == self.obj_clause[x] else 0.0) for e in cand]
        s = [self.score(F, e) for e in cand]
        if self.kernel == 'softmax':
            m = max(s); w = [math.exp((v - m) / self.T) for v in s]
        elif self.kernel == 'luce':
            w = [max(v, 1e-12) ** self.a for v in s]
        elif self.kernel == 'linnorm':
            w = [max(v, 1e-12) for v in s]
        else: raise ValueError(self.kernel)
        z = sum(w); return [(e, wi / z) for e, wi in zip(cand, w)]

class Field:
    """宿载上的介质与持久场态 D = (g, d)；外生控制构型 c = (SED, mask, avail)。"""
    def __init__(self, nodes, edges, rule, g0=None, d0=None):
        self.nodes = list(nodes); self.E = list(edges); self.rule = rule
        self.out = defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        self.g = {e: rule.tr_g.init((g0 or {}).get(e, 0.0)) for e in self.E}
        self.d = {n: rule.tr_d.init((d0 or {}).get(n, 0.0)) for n in self.nodes}
        self.mask = {e: 1 for e in self.E}; self.avail = {e: 1 for e in self.E}
        self.SED = True; self.t_sed = 0; self.writes = []   # writes：D 的写入记录（来源标注，供 E3/W 的核对）
    def decay(self):
        self.t_sed += 1
        for e in self.E: self.g[e] = self.rule.tr_g.idle(self.g[e])
        for n in self.nodes: self.d[n] = self.rule.tr_d.idle(self.d[n])
        if self.rule.sched_delta:
            for e in self.E: self.g[e] = self.g[e] + self.rule.sched_delta if not isinstance(self.g[e], dict) else self.g[e]
    def deposit(self, e, p, src='exec'):
        self.g[e] = self.rule.tr_g.passed(self.g[e], p)
        self.d[e[0]] = self.rule.tr_d.passed(self.d[e[0]], p)
        self.d[e[1]] = self.rule.tr_d.passed(self.d[e[1]], p)
        self.writes.append((self.t_sed, e, src))
    def choose(self, x, xi):
        pr = self.rule.probs(self, x)
        if not pr: return None
        c = 0.0
        for e, w in pr:
            c += w
            if xi < c: return e
        return pr[-1][0]
    def pulse(self, entry, p=1.0, route=None, xis=None, maxhop=6, first=None):
        """一次脉冲＝τ_Φ 的一次执行：先退浅（开启沉积时），再逐跳续行并沉积。
        route：外生经历（Mode_exo），给定所经结构位序列；xis：本脉冲各跳的共用随机数；
        first：自主续行中第一跳的合法反事实取值（须为正概率出边）。"""
        if self.SED: self.decay()
        q = entry; path = [q]; xis = list(xis or [])
        for h in range(maxhop):
            if route is not None:
                if h >= len(route) - 1: break
                e = (route[h], route[h + 1])
            else:
                if h == 0 and first is not None:
                    pr = dict(self.rule.probs(self, q)); assert pr.get(first, 0) > 0, 'counterfactual must be a legal draw'
                    e = first
                else:
                    xi = xis[h] if h < len(xis) else 0.5
                    e = self.choose(q, xi)
                    if e is None: break
            if self.SED: self.deposit(e, p)
            q = e[1]; path.append(q)
            if not self.out[q]: break
        return path

def tv(p1, p2):
    a = dict(p1); b = dict(p2); keys = set(a) | set(b)
    return 0.5 * sum(abs(a.get(k, 0) - b.get(k, 0)) for k in keys)

def diff_measure(p1, p2):
    """共用随机源（固定次序的逆分布抽样）下两分布给出不同实际出边的 ξ 测度。"""

        out = []; c = 0.0

        return out
    A, B = cuts(p1), cuts(p2); m = 0.0
    for a0, a1, ea in A:
        for b0, b1, eb in B:
            if ea != eb: m += max(0.0, min(a1, b1) - max(a0, b0))
    return m

def gap_change(rule, A, B, x, e1, e2):
    """比值核（softmax、luce、linnorm）下，P(e1)/P(e2) 是得分的严格单调函数；分布不同的充分判据：
    softmax 用得分差的变化，luce、linnorm 用对数得分差的变化。返回该变化量（> 0 即两分布不同，与浮点下溢无关）。"""
    sA1, sA2, sB1, sB2 = rule.score(A, e1), rule.score(A, e2), rule.score(B, e1), rule.score(B, e2)
    if rule.kernel == 'softmax': return (sA1 - sA2) - (sB1 - sB2)
    return (math.log(sA1) - math.log(sA2)) - (math.log(sB1) - math.log(sB2))

def test_T2(N=300, steps=120, seed=31):
    """预期（T2，每次经过都成为条件）：x 为源入口、ReadRel 时，在一段自主运行中，x 处的每一次实际经过 e，
    与其合法反事实 e′（正概率的另一出边）相比，在下一次 x 复入时续行分布不同——只要 RT_k 在 e 或 e′ 上成立
    （k 为两次 x 脉冲之间的沉积钟步数）。中间各脉冲的输入与随机数共用。违反数应为 0。"""
    rng = random.Random(seed); res = dict(runs=0, checks=0, pred=0, viol=0)
    for r in range(N):
        rule = rand_rule(rng, read_rel=True); nodes, E = rand_medium(rng, source_x=True); g0, d0 = rand_init(rng, rule, E, nodes)
        entries = ['x'] + [n for n in nodes[1:] if Field(nodes, E, rule).out[n]][:2]
        sched = [rng.choice(entries) for _ in range(steps)]; X = [[rng.random() for _ in range(6)] for _ in range(steps)]
        F = Field(nodes, E, rule, g0, d0); res['runs'] += 1
        for i, ent in enumerate(sched):
            if ent == 'x':
                nxt = next((j for j in range(i + 1, steps) if sched[j] == 'x'), None)
                if nxt is not None:
                    pr = [e for e, w in rule.probs(F, 'x') if w > 0]
                    # 实际经过：
                    A = copy.deepcopy(F); pa = A.pulse('x', 1.0, xis=X[i]); e = (pa[0], pa[1])
                    alts = [a for a in pr if a != e]
                    if alts:
                        ep = rng.choice(alts); B = copy.deepcopy(F); B.pulse('x', 1.0, xis=X[i], first=ep)
                        for j in range(i + 1, nxt):
                            A.pulse(sched[j], 1.0, xis=X[j]); B.pulse(sched[j], 1.0, xis=X[j])
                        A.decay(); B.decay(); t = tv(rule.probs(A, 'x'), rule.probs(B, 'x'))
                        gc = gap_change(rule, A, B, 'x', e, ep)
                        k = nxt - i
                        pred = rt_pred(rule, F.g[e], k) or rt_pred(rule, F.g[ep], k)
                        res['checks'] += 1
                        if pred:
                            res['pred'] += 1
                            if not gc > 0: res['viol'] += 1
                            if not t > 0: res['float_underflow'] = res.get('float_underflow', 0) + 1
            F.pulse(ent, 1.0, xis=X[i])
    return res

class ArgmaxRule(Rule):
    def probs(self, F, x):
        cand = [e for e in F.out[x] if F.avail[e]]
        if not cand: return []
        s = [self.score(F, e) for e in cand]; m = max(s); i = s.index(m)
        return [(e, 1.0 if j == i else 0.0) for j, e in enumerate(cand)]

def test_internal(N=1500, seed=81):
    """预期：入口 a 只有一条出边 a→x 时，外生历史 (a,x,y1) 与 (a,x,y2) 之后，下一脉冲自 a 到达 x 时，x 处得分差变化 > 0（RT₁ 成立者），违反数 0。"""

def test_tv_bound(N=20000, seed=91):
    """预期：两出边 softmax，TV = |σ(z_A) − σ(z_B)| ≥ |z_A − z_B| · min_{z∈[z_B,z_A]} σ(z)(1−σ(z))，违反数 0（中值定理）。"""
    rng = random.Random(seed); bad = 0
    sig = lambda z: 1 / (1 + math.exp(-z))
    for _ in range(N):
        zA, zB = rng.uniform(-30, 30), rng.uniform(-30, 30)
        lo, hi = min(zA, zB), max(zA, zB)
        m = min(sig(lo) * (1 - sig(lo)), sig(hi) * (1 - sig(hi)))   # σ(1−σ) 在区间上的最小值取于端点（单峰）
        if abs(sig(zA) - sig(zB)) + 1e-15 < (hi - lo) * m: bad += 1
    return dict(n=N, violations=bad)
