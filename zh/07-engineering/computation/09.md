自显论·工篇·计算组式第九 v1.1

# 计算越层误置消解式

总命题

"计算直接算出了律""算力决定对象""步步都是规则，所以不是生成""动力不过是程序状态""有动力就有律"——这五种说法有同一个形式：以计算一侧可以得到的事实（规则、步数、算力、输出、程序变量、执行中的更新），判定上一层的资格。它们在结构层面不成立。它们由同一结构过程压出：每一种说法都依据一条在计算一侧为真的局部事实；层可以在下一级停留，而停留与不停留在计算一侧看不出区别，这条局部事实于是被推广成上一层的资格判断，越过了层。按层读开之后，初始规定中看似相反的几组说法同时成立。

消解范围。消解一件事，保留一件事，不裁定一件事：  
消解：由计算侧可得的事实推出（或否定）动力层、对象层资格的推理。  
保留：计算在实现层处处在场——计算宿载中的一切变换都由计算执行；宿载层处处是规则；算力是沉积形成的资源；动力条件存于设备之中；动力可以生成律。  
不裁定：具体的现实系统（某一语言模型、某一个脑）实际取得了何种资格。

一句话

计算宿载里的一切都由计算做出，律却不由计算承担：律由计算驱动的沉积场承担。把"做出"读成"承担"，就越了层。

一、目的、回答程度与工作域

计算分层一般式已经说明：在其工作域 𝒲 内，承担"历史成为动力"的一段计算必有宿载层 S 与动力层 D，承担一条律的续行另有对象层 O；计算实施的事实不能替代律所需的场承担与资格（不可替代引理），宿载层是规则变换（推论一），计算实施不能越过沉积场的承担直接取得律资格（推论二），动力层可以停留而无律（推论六）。生成计算必然式已经说明：宿载规则属迹应规则类 𝔗 时，规则中不含对象规则（定理四），在条件组之下存在使动力层生成的合法运行（定理一甲）。生成计算一般式已经说明：输出轨迹相同而归类不同的成对过程存在（推论二）；步数多、参数在变、对历史敏感，都不使一段计算成为生成计算（该篇击穿论证节末，反例一至七后的结论）。

在这些结果之上，下面的问题仍然开放：流行的几种越层说法为什么不成立，它们从哪里来，初始规定中几组看似相反的说法怎样同时成立，以及消解之后还剩下什么。

回答程度。首版。所得结论及其地位如下（"已证"指在工作域内给出完整证明，所携条件逐项注明）：  
其一，效果层不可区分（引理一）：已证。律的判定在完整的计算侧可得量上不定（判词一 PASS 一 FAIL；PASS 升为律资格携计算分层一般式-H\_cert，FAIL 经正式必要项失败的核查（2.3）读作律资格为假，携律组式 H\_G）；"历史成为动力"在去掉规则文本的计算侧可得量上不定（成立一侧携计算执行一般式-H3）。  
其二，来源（定理一）：已证。判定函数的界限按上述两个信息范围分别陈述；五种误置各依据一条为真的局部事实，其跨层推广在所指系统上不成立，各有证明根据；推广的形成分两个方向，都由层的可停留性给出。所携：（一）（a）携计算分层一般式-H\_cert，以律资格为判定对象者另携 H\_G，（b）携计算执行一般式-H3；（二）各行携所引结果的条件——W1 行携 H\_G、E5\_car，W3 行携计算执行一般式-H3，W5 行携计算分层一般式推论六的条件与 H\_G。  
其三，消解（定理二）：已证。承担侧携律组式 H\_G 与计算分层一般式 E5\_car；实现侧中"律的作用经执行实现"一款依 E5\_host（初始限定）；（乙）生成侧携计算执行一般式-H3；（戊）携计算分层一般式推论六的条件，其中跃迁实例的判词成立升为律资格携计算分层一般式-H\_cert，停留侧经正式必要项失败的核查（2.3）取逆否读出律不成立，携 H\_G。  
其四，制造只能经 D（推论 2.1，携 H\_G、E5\_car）、算力的地位（推论 2.2）：已证。  
以上"已证"都相对于工作域 𝒲₈、初始规定与所承继的条件，不涉及对现实系统的验证。  
未答：计算侧可得量连同规则文本能否判定"历史成为动力"；算力与沉积形成之间的定量关系；律在不计算的宿载中成立的认证实例；具体现实系统的资格。

初始规定。本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。引用时标出序号：  
　初始规定一：只有描述而无承载者的律，称为失宿律；场动力与律的运动必然需要驱动，这一驱动就是承载它的系统 P。  
　初始规定二：规则变换的每一个执行节点都是一条逻辑规则；规则计算生成失宿律，例如电脑游戏用规则模拟球碰墙后弹开。  
　初始规定三：计算处在驱动层；计算对律不作直接的结果贡献，二者之间隔着动力层。  
　初始规定四：人脑的驱动是营养，其动力条件与计算无关，人脑的运作却同样产生律与理；跳过宿载层、直接用计算模拟律，得到的必定是结果计算。  
　初始规定五：计算驱动沉积场动力，沉积场动力生成律与理，这就是分层；因此不能说计算直接算出了 GPT 中的问答律。  
　初始规定六：区分算出来、跑出来、生成出来三者。  
　初始规定七：动力的变化生成对象，对象又反过来作用于动力；这些运动都真实地来自宿载，若宿载是计算设备，就来自计算。  
　初始规定八：宿载的计算只能定下动力层的计算规则；这也是人工神经网络只能调整权重，而不能直接控制或制造问答律的原因。  
　初始规定九：训练中按误差调整权重的规则不是沉积场的基本规则，而是训练的规则；这种训练称为势引。  
　初始规定十：不经由信号流、在历史之外直接改渠或改写权重，是侵入。  
　初始规定十一：生成计算包含规则计算；规则计算发生在生成计算的宿载层。  
　初始规定十二：规则计算即使在设备上逐节点执行了很多步，也不会因为步数增加就自动成为生成计算。  
　初始规定十三：对 GPT 的算力迷信，源于不明白计算的本质与层级。  
　初始规定十四：结果计算也称规则计算；生成计算与结果计算的区别，在于其变换是动力变换还是规则变换。  
主书所涉两处：《智能判》（外篇第十四）："其算力用于生成沉积场，而非用于得其符流之律，其律之得，唯在沉积"；《GPT 的真正解》（杂篇第五）：算力制度属势引结构。

工作域 𝒲₈：计算分层一般式的工作域 𝒲（单宿载 P 内的计算实施、沉积动力与至多一条律的续行），连同其所携条件；凡以 𝔗、TR1—TR5、对象规则的定义与生成计算必然式的条件组、见证构型为前件者——"历史成为动力"的存在陈述、定理二（甲）承担侧中 τ ∈ 𝔗 一款与 W1 分支、（乙）生成侧、（丙）资源侧、定义四中的"规则种类"与一致性见证——另限生成计算必然式的工作域 𝒲₇。脑等不计算的宿载不满足 E1，在 𝒲₈ 之外，只作边界例。本篇一切结论限于 𝒲₈。

承继（按原状态引用，不重证）：计算分层一般式 v1.1 的 S、D、O，Φ(∅) 与 E1—E4（E1 即该篇的 E1(σ)，其中的承担与执行规定由计算承担一般式、计算执行一般式给出），不可替代引理，推论一、六，第三节，第十一节的层检验（（二）可停留、（三）不可由下级认证），反例三，计算分层一般式附录 B 条目 A-1 至 A-5；Φ(L) 与推论二只作背景，不承重；生成计算必然式 v1.0 的 𝔗（TR1—TR5）、条件组与见证构型 Γ(σ)、对象规则的定义、定理一甲、定理一乙、定理四、推论 4.4；生成计算一般式 v1.0 的 G3、推论一、推论二与击穿论证节末的结论（反例一至七之后）；计算执行一般式的执行归责；律组式的 Law、Established、Govern、ΩSupport 与判定核（ΩSupport 中的 Ω 按现行上游读作申报窗口内稳定复走历史资格 Ω\_W = 1；判定核读 Ω\_e，PASS 读作 Law 时另携补检，见下）。所携条件按原编号：律组式 H\_G；计算分层一般式 E5\_car、E5\_host（初始限定）、H1 与 H\_cert（所取为其上游待验条件与判定域限定部分；计算分层一般式 v1.1 起，其中含《律必然式》v1.4 充分向所携 SC\_Hold 与《律运行基底构造式》v1.3 K13 所要求的 Ω\_e 补检，本篇按名称随之）；计算执行一般式-H3。本篇不以 Φ(L) 承重，不携计算分层一般式-H2。

二、误置陈述

### 2.1　五种误置

W1　计算直接算出了律。其变体：可以用计算直接制造或控制问答律。  
W2　算力决定对象：算力越大，律越多、越强。  
W3　步步都是规则，所以不是生成。其逆：步数足够多，就成了生成。  
W4　动力不过是程序状态：动力条件存于程序变量、由程序更新，所以就是规则计算的状态。  
W5　有动力就有律：场在执行中被刻写，律就已经成立。

### 2.2　初始规定中的五组表面对立

（甲）这些运动都真实地来自宿载，若宿载是计算设备，就来自计算（初始规定七）——不能说计算直接算出了 GPT 中的问答律（初始规定五）；计算对律不作直接的结果贡献（初始规定三）。  
（乙）每一个执行节点都是一条逻辑规则（初始规定二）、生成计算包含规则计算（初始规定十一）——生成计算与规则计算的区别在于变换是动力变换还是规则变换（初始规定十四）。  
（丙）"其算力用于生成沉积场"（《智能判》）——对算力的迷信（初始规定十三）。  
（丁）计算"保持被动力条件改后的结构与关系"，动力条件的载体在宿载 P 中（生成计算一般式 G3）——承担历史的动力条件须满足可沉积性，规则状态不保证这一点（计算分层一般式第三节）。  
（戊）动力的变化生成对象（初始规定七）——动力层可以停留而无律（计算分层一般式推论六）。  
每一组中两侧都出自已成立的文本；若两侧说的是同一主词、同一谓词，二者矛盾。

### 2.3　陈述所用的概念

层、资格与判据全取自承继：Φ(∅) 由 E1—E4 定义；Law(L) 在比较时刻的真值按律组式判定核取得（判词为成立者升为 Law(L)，携计算分层一般式-H\_cert。负向读取纪律：机器 FAIL 首先表示所审候选未通过该判定任务；只有经适用的负向回读，或独立核查，确认不存在满足正式必要资格的承担组织，才能在 H\_G 下由律一般式必要向的逆否取得 ¬Law(L)；Ω\_e = 0 不直接推出 Ω\_W = 0；这一负向推理不经充分向，故不追加 SC\_Hold）；律资格的承担者按不可替代引理：O\_P ≔ Law\_P(L)（计算分层一般式 v1.1），由律组式必要向（携 H\_G）得 Sed\_P 中满足 Established ∧ Govern 的组织 R。另立三个对已成立对象的读法与计量：

定义一（计算侧可得量）　对 𝒲₈ 中的运行段 σ，Λ(σ) = (Λ\_rule, Λ\_op, Λ\_io, Λ\_ex)：Λ\_rule 是 τ 的规则文本（结构位改名意义下）；Λ\_op 是 P 在 σ 中的算子调用类型序列——τ 所申报的各算子（续行核求值、续行抽样、沉积 Pass、退浅 Idle 等）每调用一次记一项，算子内部的指令不再细分（由此得到步数）；Λ\_io 是交付序列与输出轨迹；Λ\_ex 是执行事实——每一执行节点是否为固定规则（记 RuleFixed）、跨步量存放在何处、沉积更新事件有无及其次数。Λ 不含 D 的内容，也不含场的历史。去掉 Λ\_rule 的部分记 Λ⁻。  
定义二（算力）　对任一申报的非负计价 w（给每一算子类型一个非负数），c\_w(σ) = 对 Λ\_op(σ) 中各项的 w 求和。两段运行的算子调用类型序列逐项相同，则在一切这样的计价下算力相同。  
定义三（越层判断）　以 Λ 的某些分量为自变量，对上一层的资格 Q 给出判断。Q 取下列之一：Φ(∅)；承担跨步差异的分量是否满足可沉积性（E4）；比较时刻的 Law(L)；L 成律时律资格的承担者。每一误置由两部分组成：所据的局部事实 F——取自 Λ，在其所述范围内为真；与由 F 推出 Q 的跨层推广。  
　W1　F：σ 中合于 L 的表现由 P 执行 τ 直接产生（Λ\_io、Λ\_ex）。推广：L 的律资格由计算侧——τ 的规则内容或执行的事件——承担。  
　W2　F：存在一个正计价 w 与一段增长历史，其中 c\_w 增加与律由不成立转为成立相伴（对某一 w 的局部同现）。推广：Law(L) 由 c\_w 决定，或为 c\_w 的增函数。  
　W3　F：每一执行节点是固定规则（RuleFixed）。推广：Φ(∅) 不成立。其逆　F：执行步数很多。推广：Φ(∅) 成立。  
　W4　F：跨步量存于程序变量，由固定规则逐步更新（Λ\_ex）。推广：它不满足可沉积性，只是规则状态。  
　W5　F：执行中有沉积更新，场态实际被刻写（Λ\_ex）。推广：Law(L) 成立。

三、来源定位

### 3.1　引理一（效果层不可区分）

（i）律的判定在完整的计算侧可得量上不定：存在 𝒲₈ 中自同一时刻 t₀ 开始的两段运行 σ、σ′，Λ(σ) = Λ(σ′)——同一规则文本、算子调用类型序列逐项相同、同一交付与同一输出——而在比较时刻 t₀，律组式判定核对 L 的判词在 σ 中为成立、在 σ′ 中为不成立。判词为成立者升为 Law(L)，携计算分层一般式-H\_cert；判词为不成立者，按 2.3 的负向读取纪律，由证明中「对象层失败依据」所列核查，在 H\_G 下取必要向逆否得 Law(L) 为假。  
（ii）Φ(∅) 在 Λ⁻ 上不定：存在 σ、σ′，Λ⁻(σ) = Λ⁻(σ′)，而 Φ(∅) 在 σ 中成立、在 σ′ 中不成立。成立一侧携计算执行一般式-H3。  
（iii）由（i），对按算子类型计价的任一 w，律的判定不是 c\_w 的函数。

证明　（i）分两层：计算侧可得量的相同是数学推导，判词的一真一假是实例认证。  
　数学推导。取 A 为 F\_LB 上的已成律之场；取 B\* 为与 A 的边迹 g、位迹 d、掩码、阈值、可用性逐项相同，而复走记录清空、Ω 为零的场。B\* 由写入初值取得，是合法承接（生成计算一般式推论一；计算分层一般式反例三）。两场在 t₀ 只在复走记录与 Ω 上不同，这两项不在 Λ 中。二者执行同一规则 F\_LB，以同一交付（a1、a2 交替，强度 1）与同一随机源运行。F\_LB 的续行核只读 g、d、掩码与可用性，不读复走记录与 Ω（计算分层一般式附录 B 条目 A-1 所核源码事实）；沉积与退浅对 g、d 的改写也不读复走记录与 Ω。按步归纳：每一步开始时两场被读入的量相同，同一随机数给出同一续行，沉积与退浅给出同一 g、d，输出相同。  
　完整 Λ 的各分量逐项相同。Λ\_rule：同一规则。Λ\_op：F\_LB 的一次脉冲依次调用退浅一次、在每一经过位调用续行核与抽样、对每一经过边调用沉积一次；哪一算子被调用、调用几次，只由当前位置、可用出边与所抽续行决定。复走记录与 Ω 的维护在沉积与退浅两算子之内无条件进行——沉积每次追加一条记录并重算 Ω，退浅每次移出到期记录并重算 Ω——不决定任何算子是否被调用及调用几次；续行已逐步相同，故调用类型序列逐项相同。Λ\_io：交付与输出相同。Λ\_ex：每一执行节点是同一固定规则，跨步量存放于同一处，沉积调用次数相同。故 Λ(σ) = Λ(σ′)，对任意长的段都成立。  
　算子之内的指令量并不全同：退浅中移出到期复走记录的次数，A 多于 B\*（附录 B 条目 B-2：100 次脉冲中 200 对 138），差额以 A 在 t₀ 所存的记录条数为界。这一差别是 D 中复走记录的维护，Λ 按算子调用计，不及于此；以算子内部指令计价的算力能否判定律的判词，引理不作断言（ρ9）。

四、消解条件

定义四（层标读法）　凡关于计算的陈述，标明它说的是下列哪一种：  
　实现——某一事件由 P 执行；  
　规则种类——τ 是宿载的基本规则，还是含对象规则（生成计算必然式第五节的定义）；  
　资源——c\_w；  
　载体——D 存于 P 的存储；  
　资格——Q 是否成立、由何者承担。  
资格只按其所在层的判据判定：Φ(∅) 按 E1—E4 与见证构型；Law(L) 按律组式的 Established ∧ Govern 与判定核。

消解条件即：陈述按层标读法分开，资格按本层判据判定。

（甲）实现侧：在 𝒲₈ 内，σ 中的一切变换由 P 对 τ 的执行完成（E1）；律对续行的作用经计算执行实现（E5\_host，初始限定）。全称。

一致性见证：F\_LB 已成律之场的开启运行，在同一系统中同时有——一切变换由 P 执行；每一执行节点是宿载的迹应规则（F\_LB 在强度 p ≤ g\_max/β 时属 𝔗，不含对象规则）；D 存于 P 的存储；判定核判 L = a1 ⇒ c 成立（升为 Law 携 H\_cert），其承担者为 Sed\_P 中的 R1 = {a1→m1, m1→c}（计算分层一般式附录 B 条目 A-1、A-2；本篇附录 B 条目 B-1）。（甲）两侧、（乙）规则侧、（丁）两侧、（戊）生成侧在这一系统中同真。其余各侧是存在陈述，由各自的成对系统见证。

不可重构：五组两侧的主词各不相同——实现者与承担者，宿载的基本规则与对象规则，资源与决定量，载体与资格，动力与律。每一侧的全称陈述不提及另一侧的主词。在层标读法下，不存在同主词、同谓词而真值相反的一对陈述，表面对立无从重构。∎

推论 2.1（制造只能经 D）　在 𝒲₈ 内（携 H\_G、E5\_car），使 L 在 P 中取得律组式意义上的律资格的一切途径，都经过 D。工作域之外的宿载与生成路径不在此列：  
　（i）把 L 写进 τ，成为完全决定该处续行的对象规则：该处没有动力读入（生成计算必然式推论 4.4），L 在该处不取得律资格（计算分层一般式附录 B 条目 A-3：判定落于 DynamicRole；A-4：落于 CC）。所得是失宿律。  
　（ii）训练按误差调整权重：这是势引（初始规定九），所改的是 D；L 的资格仍由 D 中的组织取得。  
　（iii）写入权重：作为段首初值，是合法承接，可以使 L 在段首即有律资格（生成计算一般式推论一；计算分层一般式反例三）；在运行之中写入，是侵入（初始规定十）。二者写的都是 D。  
证明：由不可替代引理，凡 L 成律，其承担者在 Sed\_P 中，故取得律资格的途径都经过 D。（i）至（iii）是从计算一侧着手的三类做法，各自的结果由所引给出：写进规则者不取得资格，其余两类改的是 D。∎  
初始规定所说人工神经网络只能调整权重，而不能直接控制或制造问答律（初始规定八），即此推论：能做的只有改 D，资格仍由 D 承担。

推论 2.2（算力的地位）　算力是宿载层上按计价得到的资源计量。段内沉积调用以执行为前提，在计价对沉积算子有正下界时受算力约束；算力不决定律资格，对律资格的影响不单调，任意大的算力也不足以使规则模拟取得律资格。  
证明：由定理二（丙）。∎  
《智能判》所说"其算力用于生成沉积场，而非用于得其符流之律，其律之得，唯在沉积"，即资源侧与决定量侧的分开。

总结

　律的判定不是 Λ 的函数（PASS 升为 Law 携 H\_cert，FAIL 经正式必要项失败的核查读作 Law 为假，携 H\_G）；Φ(∅) 不是 Λ⁻ 的函数（携计算执行一般式-H3）　　（引理一）  
　以 Λ 判律、以 Λ⁻ 判 Φ(∅) 的函数在某一信息类上必错；五种误置各依据一条为真的局部事实，其跨层推广越过可停留的层而不成立，分下读上与上读下两向　　（定理一，（一）（a）携 H\_cert，（b）携计算执行一般式-H3；（二）各行携所引结果的条件）  
　消解条件下：实现在 S，资格在 D 与 O；规则在宿载层，生成看规则种类与运行事件；算力是资源计量而非决定量；D 存于设备，其资格由可沉积性判定，不由存放方式判定；动力可以生律而不必生律　　（定理二，承担侧携 H\_G、E5\_car，实现侧一款依 E5\_host，（乙）生成侧携计算执行一般式-H3，（戊）携计算分层一般式推论六的条件，生律一侧的判词成立升为 Law 携 H\_cert）  
　使 L 取得律资格的途径都经过 D　　（推论 2.1，携 H\_G、E5\_car）

计算宿载里发生的一切都是计算做出的；律却由计算所驱动的沉积场取得并承担。规则写在宿载里，历史写在场里，律在场中长成。把计算做出的事实当作律的资格，便越过了动力层；把宿载层处处是规则当作没有生成，便看不见动力层。两种误读出自同一处：层可以停在下一级，而计算一侧看不出它停在哪里。

"""F_LB = Augment(F_min).
Inherited from Canonical F* v1.2 (最小沉积场构造式 v0.9): node depth d, relation sediment g (saturating),
Trace / Sediment / Decay / Continuation, Mode_exo / Mode_endo, softmax solver.
Added (law-base layer): pulse strength p, threshold θ, S, derived groove set Γ, replay window & Ω,
Freeze^inst (SED=OFF), Avail (availability), RoleReadMask (targeted role intervention), dual clock t_run / t_sed, IdleStep (decay only), Established^inst(R)."""
import math, random, copy
from collections import defaultdict, deque

class FLB:
    def __init__(self, nodes, medium, alpha=0.05, beta=0.25, g_max=20.0, lam_d=0.01, lam_g=0.01,
                 theta=1.0, W=30, n_omega=3, kappa0=0.05, w_g=1.0, w_d=0.02, s_weak=0.4, T=0.15, seed=0):
        self.nodes=nodes; self.E=list(medium); self.out=defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        # inherited persistent state
        self.d={n:0.0 for n in nodes}; self.g={e:0.0 for e in self.E}
        # added persistent state
        self.rep={e:deque() for e in self.E}; self.Om={e:0.0 for e in self.E}
        self.th={e:theta for e in self.E}; self.Avail={e:1 for e in self.E}
        self.alpha,self.beta,self.g_max,self.lam_d,self.lam_g=alpha,beta,g_max,lam_d,lam_g
        self.W,self.n_omega,self.k0,self.w_g,self.w_d,self.s_weak,self.T=W,n_omega,kappa0,w_g,w_d,s_weak,T
        self.t_run=0; self.t_sed=0; self.SED=True; self.rng=random.Random(seed); self.log=[]; self.macro=None
        self.mask={e:1 for e in self.E}   # RoleReadMask: exogenous control quantity (not sediment, not decayed, persists until re-intervened)
    # ---------- inherited operators
    def Decay(self):
        """one sediment-clock step: t_sed advances; depths decay; replay windows (on t_sed) expire."""
        self.t_sed+=1
        for n in self.nodes: self.d[n]=max(0.0,self.d[n]-self.lam_d)
        for e in self.E:
            self.g[e]=max(0.0,self.g[e]-self.lam_g)
            while self.rep[e] and self.t_sed-self.rep[e][0]>self.W: self.rep[e].popleft()
            self.Om[e]=self._omega(e)
    def Trace(self,e,p): return {'e':e,'p':p}
    def Sediment(self,tau):
        e,p=tau['e'],tau['p']
        self.d[e[0]]+=self.alpha*p; self.d[e[1]]+=self.alpha*p
        self.g[e]=min(self.g_max,self.g[e]+self.beta*p*(1-self.g[e]/self.g_max))
        self.rep[e].append(self.t_sed); self.Om[e]=self._omega(e)
    def kappa(self,e):
        if not self.Avail[e]: return -1e9
        return self.k0+self.w_g*self.mask[e]*self.g[e]*(1.0 if self.S(e) else self.s_weak)+self.w_d*self.d[e[1]]
    def Continuation(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        if not cand: return None
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]
        r=self.rng.random()*sum(ws)
        for e,w in zip(cand,ws):
            r-=w
            if r<=0: return e
        return cand[-1]
    def probs(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return {e[1]:w/z for e,w in zip(cand,ws)}
    # ---------- added layer
    def S(self,e): return self.g[e]>=self.th[e]
    def Deposited(self,e): return self.g[e]>0
    def Groove(self,e): return self.S(e) and len(self.rep[e])>=2
    def Gamma(self): return {e for e in self.E if self.Groove(e)}
    def _omega(self,e):
        n=len(self.rep[e]); return 0.0 if (n<self.n_omega or not self.S(e)) else min(1.0,n/(2*self.n_omega))
    def Freeze(self): self.SED=False
    def Thaw(self): self.SED=True
    def SetAvail(self,e,v): self.Avail[e]=v
    def IdleStep(self,n=1):
        for _ in range(n): self.Decay()          # t_sed advances only
    def SetMask(self,e,v): self.mask[e]=v          # targeted role intervention (structure untouched)
    # ---------- pulse
    def pulse(self,entry,p=1.0,path=None,maxhop=6):
        self.t_run+=1
        if self.SED: self.Decay()                 # t_sed advances only when sediment law is on
        q=entry; route=[q]; inst=[]
        for h in range(maxhop):
            if path is not None:
                if h>=len(path)-1: break
                e=(path[h],path[h+1])
            else:
                e=self.Continuation(q)
                if e is None: break
            if not self.Deposited(e): inst.append(e)
            if self.SED: self.Sediment(self.Trace(e,p))
            q=e[1]; route.append(q)
            if not self.out[q]: break
        self.log.append((self.t_run,entry,tuple(route),self.macro))
        return route,inst
    # ---------- law-side readouts
    # duty = dict(ante=entry node, anchor=edge whose head state is the relation's antecedent, read=target node)
    def _closure(self,start,edges):
        adj=defaultdict(list)
        for (i,j) in edges: adj[i].append(j)
        seen={start}; st=[start]
        while st:
            x=st.pop()
            for y in adj[x]:
                if y not in seen: seen.add(y); st.append(y)
        return seen
    def CarrierRealizes_inst(self,R,duty):
        """R alone (restricted) carries Ante ⇝ Anchor.tail —Anchor→ Anchor.head ⇝ Read, all on deposited edges of R;
        the anchor edge itself must be traversed (it is deposited and on the path)."""
        a=duty['anchor']
        if a not in R or not self.Deposited(a): return False
        dep=[e for e in R if self.Deposited(e)]
        return a[0] in self._closure(duty['ante'],dep) and duty['read'] in self._closure(a[1],dep)
    def Established_inst(self,R,duty):
        """R ⊆ E ∧ ∀e∈R Deposited ∧ CarrierRealizes_inst. CarrierNonInstant is a type invariant here:
        g is persistent state, so Deposited(e) ⇒ not flow-only."""
        return set(R)<=set(self.E) and all(self.Deposited(e) for e in R) and self.CarrierRealizes_inst(R,duty)
    def MediumReach_inst(self,entry,Q):
        """medium access only: entry reaches the head of some Avail=1 edge in Q via Avail=1 edges. Does not require Q deposited."""
        seen=self._closure(entry,[e for e in self.E if self.Avail[e]])
        return any(self.Avail[e] and e[0] in seen for e in Q)
    def RolePath_inst(self,R,duty):
        """a deposited, mask-open path inside R from the anchor state to Read."""
        a=duty['anchor']
        if a not in R or not (self.Deposited(a) and self.mask[a]): return False
        open_edges=[e for e in R if self.Deposited(e) and self.mask[e]]
        return a[0] in self._closure(duty['ante'],open_edges) and duty['read'] in self._closure(a[1],open_edges)

def OmegaSupport_pre(F,entry,Q):
    """pre-stage interface for this construct only: MediumReach_inst(I,Q) ∧ ∃e∈Q Ω_e>0. Not the formal ΩSupport^M."""
    return F.MediumReach_inst(entry,Q) and any(F.Om[e]>0 for e in Q)
def DynamicRole_inst(F,R,duty,control_R=None,n=2000,delta=0.15):
    """RolePath_inst(R,d)=1 and do(Mask_R=0) changes P̂(Read|Ante) by >delta while a control mask on control_R does not;
    g,rep,Ω unchanged under both masks."""
    if not F.RolePath_inst(R,duty): return False,{}
    base=hit_prob(F,duty['ante'],duty['read'],n)
    L=copy.deepcopy(F)
    for e in R: L.SetMask(e,0)
    pm=hit_prob(L,duty['ante'],duty['read'],n)
    inv=(L.g==F.g and L.Om==F.Om and {e:len(L.rep[e]) for e in L.E}=={e:len(F.rep[e]) for e in F.E})
    pc=None
    if control_R:
        C=copy.deepcopy(F)
        for e in control_R: C.SetMask(e,0)
        pc=hit_prob(C,duty['ante'],duty['read'],n)
    ok=inv and (base-pm)>delta and (pc is None or abs(base-pc)<=delta)
    return ok,dict(P_hat_base=base,P_hat_Rmask=pm,P_hat_ctrlmask=pc,invariants=inv)
def hit_prob(F,entry,target,n=2000):
    G=copy.deepcopy(F); G.Freeze(); c=0
    for _ in range(n): c+= target in G.pulse(entry)[0]
    return c/n

def corr_M(F,a,b):
    """macro-event co-occurrence: Corr_M = #{k: a,b both in M_k} / #{k: a or b in M_k}."""
    ev=defaultdict(lambda:[False,False])
    for _,_,r,m in F.log:
        if m is None: continue
        if a in r: ev[m][0]=True
        if b in r: ev[m][1]=True
    both=sum(1 for x,y in ev.values() if x and y); either=sum(1 for x,y in ev.values() if x or y)
    return both/either if either else 0.0

def kernel(F,q,avail=None,mask=None):

    out=[]

            K={e:p for e,p in K.items() if e in edges_allowed}
            z=sum(K.values())

        if not K or hops>=maxhop: out.append((tuple(route),prob,'end')); return
        for e,p in K.items(): rec(e[1],route+[e[1]],prob*p,hops+1)
    rec(entry,[entry],1.0,0)
    return out

    endpoint grids {0,g_max} (S recomputed): single-free-variable sufficiency is exact, while
    multi-variable positive sufficiency is conditional on PR2-valid (paper §4 PR2, §7.1);
