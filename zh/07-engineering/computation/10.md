# 计算复现失真源式

总命题

一次复现中出现的失真，不由计算本身给出，也不由算力的多少给出。它由复现构造中可申报的实际过程压出：把源系统的动力写成宿载中的规则，在源系统的历史改变其动力之处不随而失真；把差异写进宿载的场态或交付——侵入与提纯——差异经宿载自身的生成回路留存、读入、改路、再写入而传开。三类过程都可以出现而不压出失真；同一失真可以有几份合法来源，只看宿载一侧在评价点上的逐点记录辨不出是哪一份。

一句话

失真不是计算的产物，是复现中被写进去的规则或差异，在宿载的生成里不随或随而偏的结果。

一、目的、回答程度与工作域

计算分层一般式已经说明：律资格由宿载 P 的沉积场中的组织承担，计算实施的事实替代不了这一承担（不可替代引理）。生成计算必然式已经说明：在其工作域 𝒲₇ 内，宿载规则属迹应规则类 𝔗、满足见证构型（含读入集隔离）与 C₇(σ) 时，一次经过所留的迹差留存到读入，便改变续行核，在共同随机源的正测度抽样上改变实际出边，从而改变其后的写入（引理 1、2；反作用往返 R₂ 是其定理一乙的结论，携计算执行一般式-H3）；完全决定续行的对象规则在其所在处取代动力读入（推论 4.4）。计算越层误置消解式已经说明：资格不由计算侧可得量决定（引理一）；跳过宿载层的规则模拟所得是失宿律，运行中写入权重是侵入（推论 2.1（iii）后一款；该推论携律组式 H\_G、计算分层一般式 E5\_car）。律源式已经说明：一次资格首次发生的来源，按冻结的来源协议，由实际发生链与最小充分两项共同认证，可以有多解。

在这些结果之上，复现失真——侵入（初始规定一、三）在后续复杂的复现中是否造成失真（本式不取为前提，由定理三、四推出）；提取有出入时，就难以在 P 中准确复现，从而失真（初始规定四）；数字信号经过观者提纯（初始规定五）——仍待回答：一次复现中失真首次发生时，它由哪一段实际过程压出；规则提取、提纯、侵入三类过程各以什么链进入 P 的变换；一个失真能否有几份合法来源，来源能否唯一确定。

回答程度。首版。所得结论及其地位如下（"已证"均相对于工作域 𝒲₉、初始规定与所承继的条件）：  
其一，计算本身、算力不是来源（定理一）：已证，前提是忠实移植存在；源系统不能在宿载中表示时，相应结论记为不可判。  
其二，提取的发生链"不随"（定理二）：已证；（b）的存在性一款经生成计算必然式定理一甲，携计算执行一般式-H3，限其工作域 𝒲₇。  
其三，侵入与提纯的发生链"随而偏"（定理三）：已证，要求宿载规则属 𝔗、介质为有限简单有向图；所用生成计算必然式引理 2 与 TR1、TR2、TR5 不经其定理一甲、一乙，不携计算执行一般式-H3。  
其四，三类过程都不必然压出失真（定理四）：已证。

未答：初始规定五所说必然失真、反差必然越来越大的强读法；同条所说主要调整的是动力条件，其中"主要"一词；三类之外的来源类型；源系统不能在宿载中表示时提纯本身的来源地位。

初始规定。本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。引用时标出序号。其中初始规定五所说必然失真、反差必然越来越大以及主要调整的是动力条件，其强读法都不作为本式任何证明的前提，登记为残余 ρ1、ρ3；后一项本式只给出结构读法（定理三）：  
　初始规定一：在动力变换中，历史成为动力；在历史之外对动力施加外力干预，是另一种情形，即侵入。  
　初始规定二：跳过宿载层、直接用计算模拟律，得到的必定是结果计算。  
　初始规定三：不经由信号流、在历史之外直接改渠或改写权重，是侵入。  
　初始规定四：跳过宿载层直接模拟律时，一旦从 A 中提取的结构、关系与变换规则（步骤节点）有出入，就难以在 P 中准确复现，从而失真；这就是模拟与复现的区别，也是结果计算与生成计算的差别，即在 P 中靠设置变换规则模拟律，与在宿载中由动力长出律的差别。  
　初始规定五：模拟信号携带的因应簇是广泛的，数字信号则经过观者提纯，因此律在复现环境中必然失真，并且在律运行多步之后，P 与 A 之间的反差必然越来越大；这主要取决于动力条件以及结构、关系在 A、P 中的差别。因此需要在 P 中反复调整，以对齐 A 中 L 的发生，主要调整的是动力条件。

工作域 𝒲₉：源系统 A 与宿载 P 都以申报模型出现；P 是计算宿载；涉及发生链"随而偏"的结论要求 P 的宿载规则属 𝔗（生成计算必然式第三节）；律目标的陈述限于计算分层一般式的工作域。现实源系统与现实宿载是否满足申报模型，属外部验证。本篇一切结论限于 𝒲₉。

二、对象申报

### 2.1　复现申报

ℛ = (A, P, κ, Bg)：A 为源系统的申报模型，其规则 τ\_A、场态 D^A；P 为计算宿载，其规则 τ\_P、场态 D^P；κ 为两者结构位与目标的对应；Bg 为冻结背景——共同交付序列、共同随机源（两侧各持同一种子的随机源）、P 的执行。

### 2.2　失真目标与读数

失真目标 χ\_D = (T, κ, ε, T\_Π)，事前冻结：T 取律目标——候选 L 在 A、P 中由律组式判定核给出的判词——或续行目标——冻结结构位集 X\_T 上的续行分布；ε 为分辨度；T\_Π 为有限评价点集。  
失真读数 Dist\_t ∈ {1, 0, ⊥}（t ∈ T\_Π）：律目标，两侧判词一为成立、一为不成立时为 1，相同时为 0，任一侧不可判时为 ⊥；续行目标，max\_{x∈X\_T} TV(K^A\_x(t), K^P\_x(t)) \> ε 时为 1，否则为 0。律目标中判词为成立者升为律资格，携计算分层一般式-H\_cert（所取为其上游待验条件与《律判定式》判定域限定部分）；失真在判词层陈述。判词为不成立者只记为该侧判词，本篇不由它读出律资格为假（计算越层误置消解式 v1.1 2.3 负向读取纪律：机器 FAIL 只表示所审候选未通过判定任务，¬Law 须另经正式必要资格失败的核查）。P 的续行核被提取单元改写时，P 一侧的判词由计算分层一般式附录 B 条目 A-3 的扩展判定核给出（实施忠实扩展：按被审实例实际执行的续行核求有效自变量），续行核未改写的实例仍由原判定核判定（附录 A，exp9.py 函数 judge）；扩展判定核的适用依据随计算分层一般式-H\_cert 的判定域限定承继。

### 2.3　首次失真

Genesis\_Dist^Π\_{t\*} ∈ {1, 0, ⊥}（t\* ∈ T\_Π 为所论的评价时刻）：Dist\_{t\*} = 1 且对一切 t ∈ T\_Π、t \< t\* 有 Dist\_t = 0 时为 1；Dist\_{t\*} = 0，或有更早的 t 使 Dist\_t = 1 时为 0；其余为 ⊥。取值规则与律源式 3.5 相同，以 Dist 代判词。

### 2.4　来源协议与构造历史

来源协议按律源式 3.2 冻结，其中历史 H\_obs 是复现构造单元的有序有限列。单元分三类：  
　提取单元——把一条完全决定续行的对象规则写入 τ\_P 的某一结构位 x，所写为从 A 提取所得之值；  
　提纯单元——以申报的编码 π 处理交接场态（由 A 移交 P 时 D^P 的段首场态，在第一次脉冲之前）或某一交付的某一分量；  
　侵入单元——在运行之中，即某一次脉冲之后（含第一次脉冲之后、首个评价点之前），对 D^P 作 Idle、Pass 之外的申报写入。  
单元类别由本协议事前冻结，按单元的作用对象与时位判定，不由构造者对同一操作另行指名：第一次脉冲之前对段首场态的改动不是侵入单元：申报了编码 π 者为提纯单元；未申报编码 π 而使段首场态与 D^A 不同者，不是本协议的单元，也不是背景，含这类改动的构造不在本协议的适用范围之内（许可的削减删不去这一改动，删去全部单元也得不到 H\_∅），本篇对它不给来源解（须先把该改动申报为编码 π，按提纯单元处理；另见第七节边界情形"移植与预装"）；第一次脉冲之后对 D^P 的写入为侵入单元；把一条对象规则写入 τ\_P 者为提取单元；三类互不相交。这里的类别是复现来源协议中的单元类型，判的是相对于源系统 A 的复现差异由哪一类单元放入，不判所得场态的资格是否合法取得——后者按计算越层误置消解式推论 2.1（iii）。  
许可的削减：删去提取单元，该结构位复原为 τ\_A；删去提纯单元，复原为恒等编码；删去侵入单元，不作该写入。交付、随机源与 P 的执行属背景，不是单元。削减域有限，各削减的重放语义明确（律源式第五、六节）。

### 2.5　空历史控制

H\_∅ 取忠实移植：τ\_P = τ\_A；D^P 的段首值由合法承接取自 D^A（生成计算一般式推论一）；无写入。SuffDist(H\_∅) 与 SourceDomainIncomplete 按律源式 3.4 求值。

三、默认来源的排除

W-D1　终态倒推。首次失真的时刻与读数不决定来源解族：相同的首次失真可以出自不同的单元（定理五）。  
W-D2　计算本身、数字设备本身。由定理一，在忠实移植存在时排除。  
W-D3　算力、精度。失真的有无不是 P 的算力的函数（定理一（iii））；编码精度不定来源资格——同一编码方式的三种格距，一不失真、一延迟失真、一即时失真（附录 B 条目 C-4）。  
W-D4　时间先后、相关。按律源式 W-S2、W-S3：先于首次失真或与之共现，不推出承担。  
W-D5　背景使能。交付、随机源、P 的执行缺了则无运行，但它们是背景，不是单元，不入来源（律源式 W-S7）。  
W-D6　非法删除。Replayable = 0 ⇏ 必要承担（律源式 W-S6）。

定理一（空历史控制：计算本身不是来源）　设忠实移植存在。  
（i）忠实移植下，两侧在每一评价点上的读数相同；SuffDist(H\_∅) = 0，SourceDomainIncomplete = 0。  
（ii）P 的执行、算力与数字表示在 H\_∅ 与背景中全部在场，它们不是构造单元，不入任何来源解；背景本身不充分。  
（iii）在至首次失真为止的运行段上，失真的有无不是 P 的算力（按计算越层误置消解式定义二）的函数。  
证明　（i）按步归纳：τ\_P = τ\_A，段首场态相同；每一步两侧的状态、交付与随机数相同，同一确定规则给出同一续行与同一写入，故读数相同，Dist\_t = 0。（ii）由（i）与定义：背景之下无单元时不出现失真。（iii）取只含一个侵入单元的构造：写入发生在 P 的执行之外，至首次失真之前 P 的算子调用序列与忠实移植相同（附录 B 条目 C-3：写入后紧接的评价点即失真），而一有失真一无。∎  
限制　源系统 A 若不能在 P 中表示，忠实移植不存在，Replayable(H\_∅) = 0，SourceDomainIncomplete = ⊥：在这一协议下，提纯本身是不是来源不可判。初始规定所说的模拟源与数字宿载属于这一情形，初始规定五的强读法不因定理一得证或被否证。  
实例：F\_LB 已成律之场的忠实移植，120 个评价点两种目标都无失真（附录 B 条目 C-1）。

四、发生过程刻画

### 4.1　两种模式

两支实际失真链对应两种模式。不随：P 在 A 有动力读入之处以规则代之，A 的历史改变 A 的续行，P 不随。随而偏：差异被写进 P 所读的场态或交付，P 以自身的生成回路承接它，随之偏离。二者不预设互斥：同一次复现可以两支都成立。  
链的读数。ExtLink 在律目标上读作：提取单元所写的对象规则在场，且 x 处续行的有效自变量集为空；在续行目标上读作：K^P\_x 不随场态取值而变，而在评价点上 K^A\_x 偏离提取值超过 ε。DevLink 读作：单元所放的差异在实际运行中被某一实际续行的得分或某一评价点的目标读数取用，或落在律的承担分量上而使该资格分量不成立（此处「资格分量不成立」按判定核所读的判定分量读取，复走支撑一项读 Ω\_e，属判词层读数，不直接读作正式资格分量（Ω\_W）不成立）。两支都在实际运行的状态上读取，不以"删去它则不失真"代替（律源式 7.5）。

### 4.2　提取：不随

定理二（提取源）　设提取单元在结构位 x 写入完全决定续行的对象规则，P 在 x 的续行核恒为 K̂。  
（a）律目标：设 x 是 L 的申报职责中锚边的起点——按律组式判定核的 DynamicRole 一项，P 中任一候选组织 R 要取得 Govern(R, L)，锚边都须在 x 处是续行的有效自变量，这一要求只涉及 x 处的续行核，与候选组织是哪一个无关——且 A 在首个评价点判 L 成立。则 Dist 在首个评价点为 1，与 K̂ 是否等于 A 的续行无关。  
（b）续行目标，设 x ∈ X\_T 被提取覆盖，记 TV\_x(t) = TV(K^A\_x(t), K̂)。对 t ∈ T\_Π：TV\_x(t) \> ε ⇒ Dist\_t = 1；当 X\_T = {x}，或在该评价点其余各位 z ∈ X\_T 的读数都不超过 ε 时，Dist\_t = 1 当且仅当 TV\_x(t) \> ε。提取准确（K̂ = K^A\_x(t\_e)，t\_e 为提取时刻）且其余各位在首次失真之前的评价点上读数都不超过 ε 时，首次失真在 T\_Π 中 TV\_x 首次超过 ε 的评价点——不是连续历史上首次越过阈值的时刻。提取有出入（TV\_x(t\_e) \> ε）且 t\_e ∈ T\_Π 时，Dist\_{t\_e} = 1；t\_e ∉ T\_Π 时，只能说提取时已有超过 ε 的局部分布差异，首次失真仍须在其后的评价点上读出。  
存在性：设 A 属生成计算必然式的工作域 𝒲₇，且其在 t\_e 的场态满足该篇的 C\_pre（以之为段首场态 D₀，分支位取 x），则自 t\_e 起存在两段可比的合法历史，在复入处给出不同的 K^A\_x（定理一甲，携计算执行一般式-H3），故其中至少一段使 K^A\_x 偏离 K̂；偏离是否超过 ε，依实例而定。这两段历史的交付按生成计算必然式的构造取得，不必是复现申报中的共同交付；对申报的交付序列，K^A\_x 是否偏离，亦依实例而定。  
（c）在（a）或（b）给出失真时，只含这一个单元的构造中，它是唯一的来源：首次失真成立，ExtLink 按上述读数成立，删去它即为空历史而不充分。  
证明　（a）由生成计算必然式推论 4.4，x 处的续行不读场态，x 处没有场态分量是续行的有效自变量，锚边不是有效自变量。这一事实只由 x 处的续行核决定，故对 P 中一切候选组织 R，DynamicRole 都不成立，Govern(R, L) 都不成立；律资格是对候选组织的存在量化（Law\_P(L) ⇒ ∃R\[Established(R) ∧ Govern(R, L)\]，必要向，携 H\_G），故 L 在 P 中不成律，判词为不成立，而 A 判成立。替代组织由此一并排除：任何绕过 x 的组织都不满足锚边在 x 处的要求（计算分层一般式附录 B 条目 A-3：τ\_C 在锚边起点 m1 处有效自变量为空，判定落于 DynamicRole）。（b）P 在 x 的续行核恒为 K̂，故 x 处的读数为 TV\_x(t)；Dist\_t 是 X\_T 上各位读数的最大者超过 ε，故 TV\_x(t) \> ε 时 Dist\_t = 1，其余各位都不超过 ε 时二者等价。存在性：两段历史都以 t\_e 的场态为段首，K̂ 是一个固定分布，两段的 K^A\_x 互不相同，不能都等于 K̂。（c）删去它即得 H\_∅，由定理一（i）不充分；由前提它本身充分。实际失真链即 ExtLink。∎  
实例：τ\_C（a1 一律取 m1、m1 一律取 c）装入 A 的场态；L = a1 ⇒ c 的申报锚边为 m1→c，其起点 m1 在 τ\_C 所覆盖之处。律目标在首个评价点失真；续行目标在 A 经连续外生经历 a1→m2→x 转向之后，于第 73 个评价点首次失真；另取一份事前冻结的协议：交付只取前 20 次 a1、a2 交替，T\_Π 为其 20 个评价点，其余同 C-2；其运行按因果是 C-2 运行的前缀，C-2 第 0—19 点的记录即其运行记录——在这些评价点上 A 在 a1、m1 的续行与提取值之差不超过分辨度，续行目标无失真（附录 B 条目 C-2）。这不是对 C-2 协议的 T\_Π 作事后截断。  
读回：初始规定四所说提取有出入时难以准确复现，是（b）后一款；同条所说模拟与复现的区别，是（a）与（b）前一款——即使提取准确，A 的历史改变 A 的动力之后，规则不随。

### 4.3　侵入与提纯：随而偏

定理三（侵入源与提纯源）　设 τ\_P ∈ 𝔗（介质为有限简单有向图），共同交付与共同随机源，一个侵入或提纯单元在时刻 t\_w（提纯取段首）使 D^P 的迹分量 ζ 与 A 的不同，此外两侧相同。  
（a）设 x 至少有两条可用出边且都读开；ζ 是其中一条出边 e 的边迹，或是 e 的末端位迹而得分 S 关于位迹严格增；差异留存到 x 的下一次续行读入（读入时两侧 ζ 的读数仍不同），且至该读入为止两侧只在 ζ 上不同。则在两侧只在 ζ 上不同的任一状态上 K^P\_x ≠ K^A\_x，该次读入即在这样的状态上进行。续行目标：若某一评价点上两侧只在 ζ 上不同，则 ζ 为边迹时该评价点上只有 x 的续行可能不同，Dist = 1 当且仅当 x ∈ X\_T 且该处全变差大于 ε；ζ 为位迹时，X\_T 中凡有出边以该位为末端者都可能不同，Dist 按定义取各位读数的最大。两侧分叉之后的评价点不在此款之内。  
（b）在（a）的情形下，共同随机源的正测度抽样集上两侧在 x 的实际出边不同。在这样的抽样上，分叉之步两侧所经的两条出边中，至少有一条在此前两侧的边迹相同；该边只在一侧受 Pass，未饱和时其迹此后两侧不同——至少一个单元未曾写入、此前两侧相同的分量变为不同。本款不断言差异分量的数目单调增加，也不断言失真幅度扩大。  
（c）设存在时刻 t′：在 t′ 之前，该差异不改变任何实际续行的得分，也不改变任何评价点的目标读数（续行目标在 X\_T 上的分布、律目标的判词）；在 t′ 时两侧状态重新相同（例如差异已被退浅抹平）。则只含该单元的构造在全部评价点上 Dist\_t = 0，SuffDist = 0。只知差异在某一次读入之前被抹平，只能得出该次读入不失真的局部结论。本款与生成计算必然式 6.1 中撤去 Γ5 的"抹平"世界相应。  
（d）若 ζ 承担律（复走记录、Ω 等）而不被续行核读入，律目标可以失真而续行目标不变。  
证明　（a）简单图中 x 的两条不同出边末端不同，故 ζ 只进入 e 的得分 s\_e，不进入 x 其余出边的得分。由 TR5（边迹）或所设的严格增（位迹），s\_e 在两侧不同，其余得分相同；续行核为 Luce 型，K\_x(e)/K\_x(e′) = φ(s\_e)/φ(s\_{e′})，φ 严格增，故对另一条可用出边 e′ 这一比值在两侧不同，续行核不同（生成计算必然式引理 2 的同一论证，差异来自单元的写入而非一次经过）。只有一条可用出边时续行核恒为单点分布，故须至少两条。续行目标的两种情形：边迹只在其出发位被读入；位迹在一切以该位为末端的出边处被读入。（b）由生成计算必然式引理 2，两分布不同，逆分布抽样在正测度区间上给出不同出边 e\_A ≠ e\_P。两侧此前只在 ζ 上不同，ζ 至多是 e\_A、e\_P 之一的边迹（ζ 为位迹时二者的边迹都相同），故二者之中至少一条边迹在两侧相同；由 TR1 它只在一侧受 Pass，由 TR2 未饱和时读数严格增，故此后两侧不同，而单元未写过它。（c）t′ 之前，两侧在每一实际续行处的得分相同，同一随机数给出同一续行与同一写入，两侧只在 ζ 上不同而目标读数不变，Dist\_t = 0；t′ 起两侧状态相同，按定理一（i）的归纳，此后 Dist\_t = 0。（d）判定核取复走记录与 Ω，续行核不取（计算越层误置消解式引理一（i）的源码事实）。∎  
实例：侵入 +15 写在 g(a1→m2)：写入后的评价点续行目标即失真，场态差异分量由 1 增至 8，第 35 点律目标失真（P 在 a1 改走 m2，R1 失去复走）；侵入 +0.005 写在零迹上，下一步退浅前已归零，无失真；清空复走记录，律目标失真而续行目标不失真。提纯：段首 g 按格距 0.001 舍入，无失真；格距 2.0，段首无失真，第 74 点续行目标首次失真（段首 g(a1→m1) 由 9.759 舍入为 10.0，约 0.24 的差异留存，A 的历史把 a1 推近两边相持时越过分辨度）；格距 20，段首即失真；交接时丢弃复走记录，律目标失真、续行目标不失真（附录 B 条目 C-3、C-4）。  
读回：侵入（初始规定一、三）在后续复杂的复现中是否造成失真，本式不取为前提，而由定理三、四给出——差异留存到 x 的读入且满足（a）所设条件时，x 处续行核改变，在正测度抽样上改路，在这样的抽样上、所经之边未饱和时，至少一个未写入的分量随之不同（（a）（b）），差异由此经 P 自身的生成回路留存、读入、改路、再写入而传开（不断言差异分量单调增加或失真幅度扩大），是否读为失真按冻结的失真目标判；差异在改变任何实际续行的得分或任何评价点的目标读数之前被抹平、两侧状态重新相同时，由（c）只含该单元的构造全程不压出失真；差异落在承担律而不被续行核读入的分量上时，由（d）律目标可以失真而续行目标不变。三类过程都不必然压出失真，见定理四。初始规定五所说主要调整的是动力条件，其结构读法是：随而偏一类的失真由 P 的动力条件承接与传播；"主要"一词不由本定理得证。

### 4.4　类型不必然

定理四（类型不必然）　对申报的失真目标，三类单元各有出现而不压出失真的实例，也各有压出失真的实例。来源资格属于一次运行中的单元，不属于单元的类型；不存在"某一类过程必然造成失真"的结论。  
证明　不压出失真的实例：提取准确而 A 此后在该处的续行与提取值之差不超过分辨度，续行目标不失真（定理二（b）；4.2 实例所述只取前 20 次交替交付的协议，其运行记录即附录 B 条目 C-2 第 0—19 点；同一构造在律目标上即时失真，见定理二（a））；侵入未留存到读入（定理三（c）；C-3 的 +0.005）；提纯低于分辨度（C-4 格距 0.001）。压出失真的实例见定理二、三。∎

五、来源定理

定理五（终态来源不足）　不存在只由首次失真的时刻与读数决定来源解族的函数：存在两份构造，首次失真的时刻与读数相同，来源解分属不同类型的单元。  
证明　构造甲含提纯单元"交接时丢弃复走记录"（第一次脉冲之前，编码 π 删去段首场态的复走记录、Ω 置零）；构造乙含侵入单元"第一次脉冲之后、首个评价点之前删去复走记录中段首承接的条目，按规则重算 Ω"（运行之中的写入）。两单元按 2.4 冻结的时位分属两类，不靠指名区分。逐项认证（附录 B 条目 C-5（i）、C-6）：  
　首次失真：二者都在首个评价点，律目标 A 判成立、P 判不成立（落于 ΩSupport），Genesis\_Dist = 1。  
　实际失真链：二者都是 DevLink（d）——首个评价点上 P 的复走记录只剩第一次脉冲所写的条目，各边 Ω 为零，复走支撑的前置读数为假；续行核在 a1、m1 的有效自变量与忠实移植相同，未受影响。  
　最小充分：删去单元即为空历史，忠实移植不失真（定理一）；单元本身充分。  
故构造甲的来源解为 {提纯单元}，构造乙的为 {侵入单元}，首次失真的时刻与读数相同而来源类型不同。∎

定理六（宿载一侧不可辨源）　存在两份构造，P 在评价点集 T\_Π 上的逐点运行记录——路线、算子调用、判词、续行分布——完全相同，失真相同，而来源解分属提纯单元与侵入单元。故来源不是 P 一侧在 T\_Π 上的逐点可观察量的函数；仅凭这些逐点记录不能认证来源，要区分这两份构造，须取得这些记录之外能够区分二者的信息，例如构造与时位信息。  
证明　定理五的两份构造在 P 一侧逐点相同（附录 B 条目 C-5（i）：T\_Π 全部 120 个评价点上，P 的路线、判词、各位续行分布与完整场态逐点相同；构造乙的写入发生在 P 的执行之外，不是 P 的算子调用，路线相同则各次脉冲的算子调用类型序列相同）。两份构造在第一次脉冲之前的段首场态不同，第一次脉冲中退浅移出到期复走记录的条数也不同（算子内部指令粒度，同计算越层误置消解式 ρ9），二者都不在 T\_Π 的逐点记录之内；正因时位不同，二者按协议可分。由于两份构造的这些逐点记录相同而来源不同，任何能分开二者的判别都须用到这些记录之外的信息。∎  
说明　本篇依事前冻结的来源协议（2.4；认证三项见 2.6），读取构造的申报及实施记录，以确定单元类别并认证来源；这是本篇协议采用的一种认证路径，不由定理六证出其为唯一必需的途径。上述段首场态是由构造在第一次脉冲之前确定的 P 一侧状态，同样在 T\_Π 的逐点记录之外，也足以分开本定理所给的这一对构造。  
这与计算越层误置消解式引理一同型：那里资格不由计算侧可得量决定，这里来源不由失真结果与宿载一侧在评价点上的逐点记录决定。

定理七（多源保留与双链）　𝔖^Π\_dist 可以有不止一员而无必要承担者；反事实上充分而不在实际链上的单元，不入来源解族。  
证明　其一，律目标，单元 {提取 τ\_C，提纯：丢弃复走记录} 同时在场（附录 B 条目 C-5（ii）、C-6）。首次失真：首个评价点。实际失真链：在实际运行的 P 上，a1、m1 处续行的有效自变量集为空（ExtLink），复走支撑的前置读数为假（DevLink（d））——两项判定分量的读数都为假：Dyn 一项由有效自变量集为空直接给出；复走支撑一项是机器前置读数（读 Ω\_e），不直接读作正式 ΩSupport（Ω\_W）不成立；判定核报告的失败点是 Dyn，那是它的检查次序，不改变两项读数都为假的事实。本定理在判词层陈述，不据此签出 P 一侧律资格为假。最小充分：各单独充分，空历史不充分。故解族为 {提取}、{提纯}，NecessarySourceCarrier 对二者都为 0。  
其二，续行目标，单元 {提取 τ\_C，侵入 +15（第 9 次脉冲后写 g(a1→m2)），侵入 +0.005} 同时在场。首次失真在第 73 个评价点（C-6）。{侵入 +15} 单独重放时充分（第 9 点即失真），MinSuff = 1；但在实际运行中，a1 处的续行由对象规则决定，所写的 g(a1→m2) 不进入任何实际续行的得分，也不进入 X\_T 上的目标读数，ActualDistLink = 0，故不入解族（律源式 9.3：只有反事实承重而无实际生成）。{侵入 +0.005} 单独不充分。{提取} 的 ExtLink 成立、单独充分。故实际解族为 {提取} 一员。∎

六、来源不能唯一确定处

　其一，解族的基数。不主张 \|𝔖^Π\_dist\| = 1，也不给出使其为一的条件（定理七）。  
　其二，同一失真可以出自不同类型的单元（定理五）。  
　其三，只看宿载一侧在 T\_Π 上的逐点记录辨不出来源（定理六）；两份构造在段首场态与算子内部指令粒度上可分，这是二者按协议时位分属两类的应有之义。本篇按协议读取申报及实施记录认证来源，不主张这是唯一途径。  
　其四，协议相对。来源解系于协议的冻结。交付作背景时，提取在续行目标上的失真以提取单元为唯一来源；若把改变 A 动力的那段外生经历申报为单元，而删去那段经历后 A 在该处的续行与提取值之差始终不超过分辨度、续行目标不失真，则它与提取单元须共同承担。删去那段经历的重放本篇未作运行：附录 B 条目 C-2 只给出其前 20 个评价点（交替交付）上续行目标无失真，其余各点未载，故这里只作条件陈述。不主张来源在任意协议下一致。  
　其五，⊥ 的分布。取 ⊥ 者其是否属解族未定；其范围由重放的合法性、判词的可判性、发生链的可审查性与协议的粒度共同决定。源系统不能在宿载中表示时，空历史控制本身为 ⊥（定理一的限制）。  
　其六，背景与单元的界线。何者应划为背景、何者应划为单元，不给判准（律源式 11.4 其四）。

缺口：本篇无新增 H。承继条件按原编号：律源式 H-SRC1（判词接口）、H-SRC2（实际生成链可审查，在本篇读作 4.1 所列 ExtLink、DevLink 两支的接口可读）、H-SRC3（削减协议可执行）——全篇的来源协议；律组式 v1.4 的 H\_G、计算分层一般式-H\_cert（所取为其上游待验条件与《律判定式》判定域限定部分，v1.1 起含 SC\_Hold 与 Ω\_e 补检）——律目标的判词升为律资格时；计算执行一般式-H3——定理二（b）的存在性一款（经生成计算必然式定理一甲，限其工作域 𝒲₇）。定理三所用生成计算必然式引理 2 与 TR1、TR2、TR5 不携计算执行一般式-H3。

七、击穿方式与边界情形

击穿方式：  
　（1）对一份构造宣称 DistSource = 1 或 MinSuff = 1，而按同一冻结协议重放后并未出现合法的首次失真（律源式 K-SRC1 的同型）；  
　（2）所称的实际失真链依赖一项未申报的写入、编辑或背景改变（K-SRC2 的同型）；  
　（3）经干预证实所申报的单元并不承担所称的失真链，例如删去提取单元后续行目标仍以同样方式失真；  
　（4）在定理一的前提下给出忠实移植而读数不同的情形；在定理二的前提下给出 P 在 x 的续行核恒为 K̂ 而 Dist 与 TV(K^A\_x, K̂) \> ε 不一致的情形；在定理三（a）的前提下给出读入处续行核相同的情形；  
　（5）对正文所宣称的必要承担或唯一来源给出反例——本篇不作这两种宣称。  
不构成击穿：来源有多解（定理七）；某削减不可执行而得 ⊥（第六节其五）；源系统不能表示时空历史控制为 ⊥（定理一的限制）；三类之外的来源造成的失真（ρ4）。

边界情形：  
　移植与预装：合法承接的场态不是提纯单元；只在申报了编码 π 时才有提纯单元。  
　训练：势引改的是 D；训练若作为构造的一部分，其在运行之中的写入按申报归为侵入单元或背景；在第一次脉冲之前完成的训练所得属段首场态，按 2.4 的时位规则归类（不是侵入单元）；二者都须事前冻结。  
　冻结运行的宿载：D^P 不再沉积，此时 P 不属 𝔗 的开启运行，定理三的（b）不适用；定理二对冻结宿载同样成立。

总结

　忠实移植下无失真；计算本身、算力不是来源（源系统可在宿载中表示时）　　（定理一）  
　提取：律目标即时失真；续行目标在 x 处的读数为 TV(K^A\_x, K̂)，源系统的续行偏离提取值超过分辨度即失真——不随　　（定理二；（b）的存在性一款携计算执行一般式-H3，限 𝒲₇）  
　侵入、提纯：差异留存到读入（至少两条可用出边）则改变续行，正测度上改路，至少一个未写入的分量随之不同；差异在改变任何实际续行的得分或任何评价点的目标读数之前被抹平、两侧状态重新相同，则不压出失真——随而偏　　（定理三，要求 τ\_P ∈ 𝔗）  
　三类过程都不必然压出失真；来源按次认证　　（定理四）  
　终态不定来源；只看宿载一侧在评价点上的逐点记录辨不出来源；来源可以多解；反事实充分而不在实际链上者不是来源　　（定理五至七）

复现中的失真有其来处。把源系统的动力抄成规则，规则就停在抄下的那一刻，源系统的历史继续改变它的动力，复现便落在后面；把差异写进宿载的场里，宿载用它自己的生成去承接这份差异，差异便随着读入与写入走到别处。计算在两种情形里都照常运行，算力也都在，它们不是失真的来处。

"""F_LB = Augment(F_min).
Inherited from Canonical F* v1.2 (最小沉积场构造式 v0.9): node depth d, relation sediment g (saturating),
Trace / Sediment / Decay / Continuation, Mode_exo / Mode_endo, softmax solver.
Added (law-base layer): pulse strength p, threshold θ, S, derived groove set Γ, replay window & Ω,
Freeze^inst (SED=OFF), Avail (availability), RoleReadMask (targeted role intervention), dual clock t_run / t_sed, IdleStep (decay only), Established^inst(R)."""
import math, random, copy
from collections import defaultdict, deque

class FLB:
    def __init__(self, nodes, medium, alpha=0.05, beta=0.25, g_max=20.0, lam_d=0.01, lam_g=0.01,
                 theta=1.0, W=30, n_omega=3, kappa0=0.05, w_g=1.0, w_d=0.02, s_weak=0.4, T=0.15, seed=0):
        self.nodes=nodes; self.E=list(medium); self.out=defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        # inherited persistent state
        self.d={n:0.0 for n in nodes}; self.g={e:0.0 for e in self.E}
        # added persistent state
        self.rep={e:deque() for e in self.E}; self.Om={e:0.0 for e in self.E}
        self.th={e:theta for e in self.E}; self.Avail={e:1 for e in self.E}
        self.alpha,self.beta,self.g_max,self.lam_d,self.lam_g=alpha,beta,g_max,lam_d,lam_g
        self.W,self.n_omega,self.k0,self.w_g,self.w_d,self.s_weak,self.T=W,n_omega,kappa0,w_g,w_d,s_weak,T
        self.t_run=0; self.t_sed=0; self.SED=True; self.rng=random.Random(seed); self.log=[]; self.macro=None
        self.mask={e:1 for e in self.E}   # RoleReadMask: exogenous control quantity (not sediment, not decayed, persists until re-intervened)
    # ---------- inherited operators
    def Decay(self):
        """one sediment-clock step: t_sed advances; depths decay; replay windows (on t_sed) expire."""
        self.t_sed+=1
        for n in self.nodes: self.d[n]=max(0.0,self.d[n]-self.lam_d)
        for e in self.E:
            self.g[e]=max(0.0,self.g[e]-self.lam_g)
            while self.rep[e] and self.t_sed-self.rep[e][0]>self.W: self.rep[e].popleft()
            self.Om[e]=self._omega(e)
    def Trace(self,e,p): return {'e':e,'p':p}
    def Sediment(self,tau):
        e,p=tau['e'],tau['p']
        self.d[e[0]]+=self.alpha*p; self.d[e[1]]+=self.alpha*p
        self.g[e]=min(self.g_max,self.g[e]+self.beta*p*(1-self.g[e]/self.g_max))
        self.rep[e].append(self.t_sed); self.Om[e]=self._omega(e)
    def kappa(self,e):
        if not self.Avail[e]: return -1e9
        return self.k0+self.w_g*self.mask[e]*self.g[e]*(1.0 if self.S(e) else self.s_weak)+self.w_d*self.d[e[1]]
    def Continuation(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        if not cand: return None
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]
        r=self.rng.random()*sum(ws)
        for e,w in zip(cand,ws):
            r-=w
            if r<=0: return e
        return cand[-1]
    def probs(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return {e[1]:w/z for e,w in zip(cand,ws)}
    # ---------- added layer
    def S(self,e): return self.g[e]>=self.th[e]
    def Deposited(self,e): return self.g[e]>0
    def Groove(self,e): return self.S(e) and len(self.rep[e])>=2
    def Gamma(self): return {e for e in self.E if self.Groove(e)}
    def _omega(self,e):
        n=len(self.rep[e]); return 0.0 if (n<self.n_omega or not self.S(e)) else min(1.0,n/(2*self.n_omega))
    def Freeze(self): self.SED=False
    def Thaw(self): self.SED=True
    def SetAvail(self,e,v): self.Avail[e]=v
    def IdleStep(self,n=1):
        for _ in range(n): self.Decay()          # t_sed advances only
    def SetMask(self,e,v): self.mask[e]=v          # targeted role intervention (structure untouched)
    # ---------- pulse
    def pulse(self,entry,p=1.0,path=None,maxhop=6):
        self.t_run+=1
        if self.SED: self.Decay()                 # t_sed advances only when sediment law is on
        q=entry; route=[q]; inst=[]
        for h in range(maxhop):
            if path is not None:
                if h>=len(path)-1: break
                e=(path[h],path[h+1])
            else:
                e=self.Continuation(q)
                if e is None: break
            if not self.Deposited(e): inst.append(e)
            if self.SED: self.Sediment(self.Trace(e,p))
            q=e[1]; route.append(q)
            if not self.out[q]: break
        self.log.append((self.t_run,entry,tuple(route),self.macro))
        return route,inst
    # ---------- law-side readouts
    # duty = dict(ante=entry node, anchor=edge whose head state is the relation's antecedent, read=target node)
    def _closure(self,start,edges):
        adj=defaultdict(list)
        for (i,j) in edges: adj[i].append(j)
        seen={start}; st=[start]
        while st:
            x=st.pop()
            for y in adj[x]:
                if y not in seen: seen.add(y); st.append(y)
        return seen
    def CarrierRealizes_inst(self,R,duty):
        """R alone (restricted) carries Ante ⇝ Anchor.tail —Anchor→ Anchor.head ⇝ Read, all on deposited edges of R;
        the anchor edge itself must be traversed (it is deposited and on the path)."""
        a=duty['anchor']
        if a not in R or not self.Deposited(a): return False
        dep=[e for e in R if self.Deposited(e)]
        return a[0] in self._closure(duty['ante'],dep) and duty['read'] in self._closure(a[1],dep)
    def Established_inst(self,R,duty):
        """R ⊆ E ∧ ∀e∈R Deposited ∧ CarrierRealizes_inst. CarrierNonInstant is a type invariant here:
        g is persistent state, so Deposited(e) ⇒ not flow-only."""
        return set(R)<=set(self.E) and all(self.Deposited(e) for e in R) and self.CarrierRealizes_inst(R,duty)
    def MediumReach_inst(self,entry,Q):
        """medium access only: entry reaches the head of some Avail=1 edge in Q via Avail=1 edges. Does not require Q deposited."""
        seen=self._closure(entry,[e for e in self.E if self.Avail[e]])
        return any(self.Avail[e] and e[0] in seen for e in Q)
    def RolePath_inst(self,R,duty):
        """a deposited, mask-open path inside R from the anchor state to Read."""
        a=duty['anchor']
        if a not in R or not (self.Deposited(a) and self.mask[a]): return False
        open_edges=[e for e in R if self.Deposited(e) and self.mask[e]]
        return a[0] in self._closure(duty['ante'],open_edges) and duty['read'] in self._closure(a[1],open_edges)

def OmegaSupport_pre(F,entry,Q):
    """pre-stage interface for this construct only: MediumReach_inst(I,Q) ∧ ∃e∈Q Ω_e>0. Not the formal ΩSupport^M."""
    return F.MediumReach_inst(entry,Q) and any(F.Om[e]>0 for e in Q)
def DynamicRole_inst(F,R,duty,control_R=None,n=2000,delta=0.15):
    """RolePath_inst(R,d)=1 and do(Mask_R=0) changes P̂(Read|Ante) by >delta while a control mask on control_R does not;
    g,rep,Ω unchanged under both masks."""
    if not F.RolePath_inst(R,duty): return False,{}
    base=hit_prob(F,duty['ante'],duty['read'],n)
    L=copy.deepcopy(F)
    for e in R: L.SetMask(e,0)
    pm=hit_prob(L,duty['ante'],duty['read'],n)
    inv=(L.g==F.g and L.Om==F.Om and {e:len(L.rep[e]) for e in L.E}=={e:len(F.rep[e]) for e in F.E})
    pc=None
    if control_R:
        C=copy.deepcopy(F)
        for e in control_R: C.SetMask(e,0)
        pc=hit_prob(C,duty['ante'],duty['read'],n)
    ok=inv and (base-pm)>delta and (pc is None or abs(base-pc)<=delta)
    return ok,dict(P_hat_base=base,P_hat_Rmask=pm,P_hat_ctrlmask=pc,invariants=inv)
def hit_prob(F,entry,target,n=2000):
    G=copy.deepcopy(F); G.Freeze(); c=0
    for _ in range(n): c+= target in G.pulse(entry)[0]
    return c/n

def corr_M(F,a,b):
    """macro-event co-occurrence: Corr_M = #{k: a,b both in M_k} / #{k: a or b in M_k}."""
    ev=defaultdict(lambda:[False,False])
    for _,_,r,m in F.log:
        if m is None: continue

"""ljudge.py — 《律判定式》参考实现 v1.0
P := R ∈ 𝒮(F_LB, L, I)，按律数理式 v1.2 在 F_LB(flb.py v1.0) 冻结快照上精确判定。

不用蒙特卡洛；所有概率为 softmax 精确值的有限乘积与求和。
候选 L 均为权重型：EvalMode = measure，ε_role = 0.01，Read: μ(路径含 Read 位 | Ante) ≥ π₀ = 0.9。
"""
import math, copy, itertools
from collections import defaultdict
import sys; sys.path.insert(0,'.')

MAXHOP=6

# ---------- kernel & exact path measure ----------
def kernel(F,q,avail=None,mask=None):
    """K_y at position q: distribution over out-edges, from state only (exact)."""
    avail=avail or F.Avail; mask=mask or F.mask
    cand=[e for e in F.out[q] if avail[e]]
    if not cand: return {}
    ks=[]
    for e in cand:
        k=F.k0+F.w_g*mask[e]*F.g[e]*(1.0 if F.S(e) else F.s_weak)+F.w_d*F.d[e[1]]
        ks.append(k/F.T)
    m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
    return {e:w/z for e,w in zip(cand,ws)}

def eval_paths(F,entry,edges_allowed=None,maxhop=MAXHOP):
    """Exhaustive Eval(Ctx): all routes with exact μ. edges_allowed=None → all; else restrict (κ_P)."""
    out=[]
    def rec(q,route,prob,hops):
        K=kernel(F,q)
        if edges_allowed is not None:
            K={e:p for e,p in K.items() if e in edges_allowed}
            z=sum(K.values())
            if z==0: out.append((tuple(route),prob,'dead')); return
            K={e:p/z for e,p in K.items()}   # 受限评价：P 外结构不可用，核在 P 内重归一
        if not K or hops>=maxhop: out.append((tuple(route),prob,'end')); return
        for e,p in K.items(): rec(e[1],route+[e[1]],prob*p,hops+1)
    rec(entry,[entry],1.0,0)
    return out

def mu_read(F,entry,target,edges_allowed=None):
    return sum(p for r,p,_ in eval_paths(F,entry,edges_allowed) if target in r)

# ---------- ActArg^μ at a choice node (weighted duty) ----------
def actargs_at(F,q,eps=0.01):
    """minimal μ-sufficient groups over per-edge state fixings at position q.
    AdmVar: each out-edge's g varies over its admissible domain. The implementation evaluates
    endpoint grids {0,g_max} (S recomputed): single-free-variable sufficiency is exact, while
    multi-variable positive sufficiency is conditional on PR2-valid (paper §4 PR2, §7.1);
    negative verdicts from grid counterexamples are unconditionally sound."""
    cand=[e for e in F.out[q] if F.Avail[e]]
    def dist(gvals):
        ks=[]
        for e in cand:
            g=gvals[e]; S=1.0 if g>=F.th[e] else 0.0
            k=F.k0+F.w_g*F.mask[e]*g*(1.0 if S else F.s_weak)+F.w_d*F.d[e[1]]
            ks.append(k/F.T)
        m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return [w/z for w in ws]
    def tv(p,qq): return 0.5*sum(abs(a-b) for a,b in zip(p,qq))
    base={e:F.g[e] for e in cand}
    def sufficient(C):
        freevars=[e for e in cand if e not in C]
        if not freevars: return True
        grids=[[0.0,F.g_max] for _ in freevars]
        dists=[]
        for combo in itertools.product(*grids):
            gv=dict(base); gv.update({e:v for e,v in zip(freevars,combo)})
            for e in C: gv[e]=base[e]
            dists.append(dist(gv))
        return max(tv(a,b) for a in dists for b in dists)<=eps
    minimal=[]
    for r in range(len(cand)+1):
        for C in itertools.combinations(cand,r):
            if sufficient(set(C)) and not any(set(M)<=set(C) for M in minimal):
                minimal.append(C)
    return set(u for M in minimal for u in M), minimal

# ---------- the judging pipeline ----------
def _judge_P(F,L,P,R,pi0,eps):
    """evaluate CR/CNI/Dyn/ΩSupport on one implementation P ⊆ R (canonical witness Π_P: W=ResEval(κ_P), PR1).
    Returns (depth_reached, detail). Depth order: CR=1, CNI=2, Dyn=3, ΩSupport=4 (all-pass)."""
    ante,anchor,read=L['ante'],L['anchor'],L['read']; d={}
    m_res=mu_read(F,ante,read,edges_allowed=set(P))
    d['P']=[f"{e[0]}→{e[1]}" for e in sorted(P)]
    d['CR']=dict(anchor_in_P=anchor in P,mu_restricted=round(m_res,4),pi0=pi0)
    if not (anchor in P and m_res>=pi0): return 0,d
    # CNI by reduction lemma: frozen ⇒ Estab={g>0}; witnesses under PR1 have Q(Π)⊆P⊆R⊆Estab (CC);
    # Bear∩Inst=∅ automatic since P has no g=0 edge. Assert the lemma's premises:
    assert all(F.g[e]>0 for e in P), "CNI reduction premise violated"
    d['CNI']=dict(by_reduction_lemma=True,Q_subset_Estab=True)
    # Dyn on Π_P
    aa,minimal=actargs_at(F,anchor[0],eps)
    adj=defaultdict(list)
    for (i,j) in P:
        if F.g[(i,j)]>0 and F.mask[(i,j)]: adj[i].append(j)
    seen={anchor[1]}; st=[anchor[1]]
    while st:
        x=st.pop()
        for y2 in adj[x]:
            if y2 not in seen: seen.add(y2); st.append(y2)
    rolepath=(anchor in aa) and (read in seen or read==anchor[1])
    d['Dyn']=dict(ActArg_at_anchor_tail=[f"{e[0]}→{e[1]}" for e in sorted(aa)],minimal_groups=[[f"{e[0]}→{e[1]}" for e in M] for M in minimal],anchor_in_ActArg=anchor in aa,rolepath=rolepath)
    if not rolepath: return 2,d
    # ΩSupport on Π_P
    seenA=F._closure(ante,[e for e in F.E if F.Avail[e]])
    reach=any(F.Avail[e] and e[0] in seenA for e in P)
    bear=[e for e in P if e==anchor or (anchor[1]==e[0] or e[0] in seen)]
    omega_ok=all(F.Om[e]>0 for e in bear)
    d['ΩSupport']=dict(Reach=reach,Bear=[f"{e[0]}→{e[1]}" for e in bear],Omega={f"{e[0]}→{e[1]}":round(F.Om[e],2) for e in bear})
    if not reach: return 3,dict(d,fail='Reach')
    if not omega_ok: return 3,dict(d,fail='ΩOK')
    return 4,d

def judge(F,L,R,I,pi0=0.9,eps=0.01,verbose=True):
    """Decision domain: single-duty, single-entry I={Ante}, measure-type candidate;
    the input F_LB state is converted to a Freeze^inst snapshot before judging.
    Existential over implementations: R passes iff ∃P ⊆ R (anchor ∈ P) whose canonical witness Π_P
    passes CR∧CNI∧Dyn∧ΩSupport; Bind then follows by the collapse lemma (frozen: RoleCtx=ReplayCtx,
    same Π_P bears ΩWit and ρ_P ∈ RoleReal via its Dyn check). fail_at = deepest level reached over all P."""
    T={}
    # interface domain: duty structure admits single-duty measure-type candidates only;
    # runtime guard below checks single entry I={Ante}; F is frozen into a Freeze^inst snapshot before judging
    if list(I)!=[L['ante']]:
        T['fail_at']='⊥(判定域外: 本篇只判单职责、单入口 I={Ante} 之权重型候选)'
        if verbose: print(T['fail_at'])
        return None,T
    F=copy.deepcopy(F); F.Freeze()
    T['Y']={e:(round(F.g[e],2),int(F.S(e)),round(F.Om[e],2),F.Avail[e],F.mask[e]) for e in F.E if F.g[e]>0 or e in R}
    cc = len(R)>0 and all(e in F.E for e in R) and all(F.g[e]>0 for e in R)
    T['CC']=cc
    if not cc: return _out('CC',T,verbose)
    anchor=L['anchor']
    best=(-1,None)
    for r in range(1,len(R)+1):
        for Pt in itertools.combinations(R,r):
            if anchor not in Pt: continue
            depth,detail=_judge_P(F,L,set(Pt),R,pi0,eps)
            if depth>best[0]: best=(depth,detail)
            if depth==4: break
        if best[0]==4: break
    depth,detail=best
    for k in ('P','CR','CNI','Dyn','ΩSupport'):
        if detail and k in detail: T[k]=detail[k]
    if depth==4:
        T['Bind']=dict(by_collapse_lemma=True,value=True)
        T['verdict']='R ∈ 𝒮'
        return _out(None,T,verbose)
    fail=['CR','CNI','Dyn',('ΩSupport(Reach)' if detail and detail.get('fail')=='Reach' else 'ΩSupport(ΩOK)')][depth if depth<3 else 3]
    return _out(fail,T,verbose)

def _out(fail,T,verbose):

def source_family(units, A, key, N=120):
    """对一切非空子集求 Suff，再求最小充分子集族（对一切真子集量化）。"""
