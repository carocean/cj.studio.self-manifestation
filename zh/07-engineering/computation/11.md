# 计算判定式

一、目的

本篇为判定式（附式，反演辨识组）。用途：对事前冻结的判定实例，在合法可操作的判定协议下，调用第二至十篇已闭合的定义、必要向、形式系统与回读规则，判定承担、执行、相对目标的规则计算、生成计算四类性质在实例上成立与否；并证明：判 0 时该性质一定不成立（在判定域内，携所申报的条件）；不能保证正确时判 ⊥，并写明原因。在当前上游状态下四判词的值域为 {0, ⊥}（定理三）。

四类性质与四个判词是：

　　Det\_Bear(χ) ∈ {1, 0, ⊥}：申报的任务 τ 上，P 是否承担 τ；  
　　Det\_Exec(χ) ∈ {1, 0, ⊥}：申报的时段 T 内，P 是否执行 τ；  
　　Det\_RuleComp\_L(χ) ∈ {1, 0, ⊥}：相对申报目标 L，P 在 T 内的执行是否为规则计算；  
　　Det\_Gen(χ) ∈ {1, 0, ⊥}：申报的运行段 σ 是否为生成计算。

四个判词回答四个不同的问题，不合成一个"是否计算"的总判，不互相表决，也不互相填补。

四类性质都取上游定义与形式系统，组成项不增不减；条件账本中无新增 H（7.2）；判据不以任何律、理、概率、意向的资格为输入。

判定域申明：判定实例以申报模型出现，申报先于被判运行冻结。现实宿载与其申报模型、规则文本是否相符，属实例化与外部连接，作为判定域条件 Dom（4.2）申报。

判定前提：  
（一）四类性质的定义：承担、执行、生成计算分别由第二、三、五篇的前件或规定给出；相对目标的规则计算由执行与第八篇的对象规则定义合取给出，对象规则有两种读法（3.1）。  
（二）观测集：3.3。  
（三）前向关系：承担、执行、生成计算由各自的必要向给出，对象规则由规则文本读出（3.4）；三类原性质的充分向，第二篇未答，第三、五篇为 U1。  
"计算型宿载"在上游没有闭合定义（第二篇："承担是宿载对一项任务的结构资格，不是计算的标志"；第三篇："执行是承担的一次行使，不是计算的标志"；初始规定六只列举脑与计算设备两种），不是这里的被判性质；天然过程与可设定物质上的承担、执行判词见 7.5。

初始规定。本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。引用时标出序号：  
　初始规定一：规则变换的每一个执行节点都是一条逻辑规则：它是程序所表达的那条律在这一节点上的规则，规定为了形成这条律下一步怎样走。  
　初始规定二：跳过宿载层、直接用计算模拟律，得到的必定是结果计算。  
　初始规定三：生成计算包含规则计算；规则计算发生在生成计算的宿载层。  
　初始规定四：规则计算即使在设备上逐节点执行了很多步，也不会因为步数增加就自动成为生成计算。  
　初始规定五：结果计算也称规则计算；生成计算与结果计算的区别，在于其变换是动力变换还是规则变换。  
　初始规定六：相对于非计算的 P，目前已知的计算的 P 有两种：一是脑，仅限于它行使计算能力之时，但不能误解为计算驱动生成了脑的动力；二是计算设备。  
　初始规定七：在 P 中靠设置变换规则模拟律，与在宿载中由动力长出律，这一差别就是计算机程序与 GPT 中前馈网络（FFN）的差别。

三、性质与观测集申报

### 3.1　性质

　Bear(P, τ)：第二篇意义的承担。  
　Exec(P, τ, T)：第三篇意义的执行，以承担为前件。  
　GenComp(P, σ)：第五篇意义的生成计算。  
　RuleComp\_L(P, τ, T)：相对申报目标 L 的规则计算，

　　RuleComp\_L(P, τ, T) :⟺ Exec(P, τ, T) ∧ Obj\_L(R\_P)

　R\_P：P 在 T 内执行 τ 时所执行的规则文本（Y\_impl，随 Δ 冻结）。T 内换用规则文本者，按规则文本不变的子时段分别判定。任务以 f 在定义域上的外延为身份，算法与配置不参与任务身份（第二篇推论一），故对象规则是所执行规则的性质，不是任务的性质；第七篇推论一所说"其 τ 是对象规则"、第八篇所说"τ\_Φ 中的一个条款"，指的都是被执行的规则。  
　Obj\_L(R\_P)：R\_P 在 L 的申报结构位、关系或入口上含对象规则条款。对象规则按第八篇 5.5 定义："τ\_Φ 中的一个条款，其作用式以某一结构位、关系或入口的名字——而不是其场态——为自变量，规定或偏置该处的续行或沉积"。合取由上游条文给出：第七篇推论一，"算出来与跑出来是 S 单独成立的规则计算，其 τ 是对象规则；生成计算的宿载层也是规则计算，其 τ 是宿载的基本规则"；第九篇定理二（乙），"执行的是宿载的迹应规则还是对象规则，可从规则文本读出"。初始规定三所说宿载层的规则计算是后一种，在每一生成计算中都成立；RuleComp\_L 是前一种，相对目标 L 而言。

　上游条文对 Obj\_L 有两种读法，在只作偏置的条款上分开：  
　　Obj\_L^含：R\_P 在 L 上有对象规则条款，含只作偏置者（第八篇 5.5 定义）；  
　　Obj\_L^全：R\_P 在 L 上有完全决定该处续行的对象规则——该条款以名字为自变量，且使对一切合法可比的场态 D、D′，K\_x(D) = K\_x(D′)（第八篇推论 4.4；第七篇推论一"其 τ 是对象规则"）。  
　推论 4.4 末段指明只作偏置的条款"不取消该处的动力读入"，故两读不同。两读并判（4.7），两读同值处判词与读法无关。

　Φ(∅)（第七篇的生成职责）不是被判性质：它与 GenComp 之间只有第八篇定理八的条件化对应。

### 3.2　判定实例

χ = (P, Δ, T, σ)。P 为申报边界内的宿载；T 为时段；σ 为 P 的一段运行；Δ 为合法申报：任务 τ 或一步任务 τ\_Φ、读法、交付协议（含随机成分与未指定选择）、运转条件 Env 与评估制度 R\_B（第二篇：在 Env 下、外部不代算）、启动部分、使能条件、申报时期 Θ；生成一侧另有沉积场 F 及其协议、扩展状态的划分 Σ\_s、步划分候选；规则一侧另有目标 L 及其申报结构位、关系、入口。Δ 先于被判运行冻结，判定中不得增删、缩域、换域或重报。

### 3.3　观测集

Y = (Y\_decl, Y\_impl, Y\_run, Y\_cov)

　Y\_decl：Δ 及其申报时间。  
　Y\_impl：端口模型与交付、读出的实施；规则文本及其条款（每一条款的作用式以名字还是以场态为自变量，效果是写定还是偏置）；状态分量的归类；各分量的更新规则；沉积模式及其作用对象；写入通道；耦合申报。  
　Y\_run：运行事件记录；交付全族与未指定选择、随机成分的穷举；撤去启动的反事实；改名重放。  
　Y\_cov：模型充分性（第四篇 5.5）；规则文本读出的一致性核对；候选覆盖证书（第六篇 CovCert；证书只记录覆盖，覆盖为真所须的条件见 C9）。Y\_cov 只决定判定方法能否签出，不是任何一类的组成项。

不得以对象层轨迹、输出序列或经验频率作判据。依据：第二篇推论三（携 PP），单段运行的有限观测轨迹不足以判定承担；第九篇引理一与定理一（一），只取计算侧可得量的判断在某一类实例上必错；第十篇定理六，来源不由宿载一侧在评价点上的逐点记录决定，认证来源须另取这些记录之外的构造与时位信息（本篇取 Y\_decl、Y\_impl、Y\_run）。三对实例给出同型的对照（附录 B 条目 E-2）：一台加法器与一台按槽位放出录下之和的录放器，在观测交付序列上输出相同，前者承担判 ⊥、后者判 0；一台正常的计算器与一台第二次运行时运算部分停摆、显示保留上次之值的计算器，输入与显示序列相同，前者执行判 ⊥、后者给出条件化负读数 0；F\_LB 与在 a1、m1 写定续行的 τ\_C，在同一场态与同一随机源下 100 次路线相同，前者相对目标的规则计算判 0、后者判 ⊥。

四、判据构造

### 4.1　判词与纪律

Det\_X(χ) = (v, Code, Cond, H, Read)，X ∈ {Bear, Exec, RuleComp\_L, Gen}，v ∈ {1, 0, ⊥}：Code 为路径或原因码；Cond 为所用的判定域条件；H 为路径所携的上游条件；Read 为结构读数与条件化负读数。

判定纪律六条：形式读数不是最终判词；申报失格不是结构零；没有找到正证据不是负判；覆盖未闭不签 0；证据错配不制造 0；条件只沿实际路径传播。

### 4.2　判定域与条件

判定域 Dom 由判定方法层的条件组成：  
　Dom1　Δ 合法，且先于被判运行冻结（申报时间、版本可查）；  
　Dom2　申报模型如实：模型充分性五项通过（第四篇 5.5），申报的状态归类、启动部分、运行个体与宿载相符，运行事件记录覆盖 T 内的全部运行个体；  
　Dom3　规则文本读出如实：Y\_impl 中的条款表与宿载执行的规则相符；  
　Dom4　判定协议 Π\_CJ（4.4）得到遵守。  
Dom 的各条不是 H，不是任何一类的组成项。Dom2 把生成计算一般式-H1 的（a）款（扩展状态、变量域与步划分的唯一认定；其（b）款——流水线交叠执行与连续自由运行何时纳入工作域——不在此列，见 4.8 的进入条件）、计算执行一般式-H1（启动与使能的认定）、H2（同一运行的认定）所要回答的事取为申报相符的条件，这些 H 不因此关闭；Dom2 也不由第四篇 5.5 的核查推出——核查通过只使谓词可以输出，不推出宿载中没有未建模的结构。

路径所携的上游条件 H 分两类：  
　蕴含条件：所用必要向本身所携的条件。Ex 路径携计算执行一般式-H3（a）（b），其反事实一支只在 C5 的条件（含不过定）下取；Gov 路径携生成计算一般式-H2，并携逐候选读数与覆盖为真所须的条件（C9、4.8 G-戊）；部署耦合下的 Sed（ii）携生成计算一般式-H3；G-丁第 3 项中 D ∉ Pers(F) 与配置常量两款，经第五篇 Sed（i）的持久场态一款，携《律一般式》v2.5 C0（上游状态为待核承继，按下文终判规则与未关闭的 H 同样处理）。  
　认定条件：在实例上认定失败项所须的形式判据。读法的划型携计算承担一般式-H1，读法与交付代算携 H2，外部代算携 H3；失败项是冻结申报、实施或运行记录对相应条款的直接否定时不携（引理一及其后注）。

终判规则：路径给出 0 而所携 H 全部关闭者，终判 0；所携 H 有未关闭者，终判 ⊥，原因 ⊥\_HOpen，Read 中报出条件化负读数 0 及所携 H。当前上游的计算承担一般式-H1—H3（待验）、计算执行一般式-H1—H3（待证）、生成计算一般式-H1—H3（待证）都未关闭。

引理一（申报读出的代算）　若冻结的实施把交付或读出定义为对 f 的求值（交付函数输出 f(d)，或读法把状态读作 f 施于某量之值），则 Leg₂ 不成立；若冻结的申报写明交付之后边界外的过程对 f 求值、结果依赖这份工作，则 Prod 不成立。二者都不携计算承担一般式-H2、H3。  
证明：第二篇以"交付无须求 f 的值、读出无须施加 f"界定 Leg₂，以"交付与交付之后的外部过程都不代算"界定 Prod 中的产出，代算即"宿载之外的环节执行了对 f 的求值或其一部分，并且结果是否合格依赖于这份工作"。前提给出的正是这些条款的否定，失败由条款本身得出。H2、H3 是这些条款的形式判据，用以在未直接写明之处——编码部分分担 f、外部作用是否求值——作出认定；任何一份合格的判据在条款被直接否定之处都须给出同一结论。□  
第二篇第十一节对"读法内含答案的导线""代算黑箱"的归类即这一情形。

### 5.4　未决保护

### 5.6　判词独立

定理六（判词独立）　除定理一的入口关系外，判词之间不相推出：同一类宿载上可以 Det\_RuleComp\_L = 0 而 Det\_Gen = ⊥，可以 Det\_RuleComp\_L = ⊥ 而 Det\_Gen = 0，也可以二者都为 ⊥。

推论　同一宿载可以在 L 的结构位上含对象规则而在另一处有生成结构；规则计算与生成计算的判词须分别给出，不由其中一个推出另一个。

六、误判界申报

不引入统计误判率。判定纪律是：不能保证正确时退到 ⊥。

负判域：由定理二，在 Dom 内终判 0 的误判为零；条件化负读数 0 在所携 H 成立时误判为零。

正判域：为空（定理三）。

不能两全之处：  
（一）正向判定域为空。上游所给的必要方向不推出四类成立（承担的充分向第二篇未答，执行、生成计算为第三、五篇 U1，相对目标的规则计算以执行为合取项）。标准正例 S1—S13、GS1—GS10 是情形描述，没有给出由可观测证据到类别成立的充分判据，并以承担为前件（第三篇推论三："总式不推出它是执行"；第五篇："标准正例只用作适用域与过强条件的检验锚"）；它们在判定中只作回归锚。  
（二）负向不完全。定理五的子域之外，¬X 的实例可以判 ⊥。可以点名者：模型充分性不过（⊥\_M）或无合法申报（⊥\_D）的实例；第三篇 U2 两项（归类未定）；编码部分分担 f 的读法（⊥\_H2）；Ex 路径的负判（⊥\_HOpen，携计算执行一般式-H3（a）（b））；过定的运行（⊥\_Cov，C5）；不在第五篇工作域内或读不出工作域的 σ（⊥\_Cov，4.8）；依赖步划分的生成计算失败（⊥\_Cov）；Gov 一支（携生成计算一般式-H2、生成计算数理式-H2-Gov 与覆盖为真的条件）；部署耦合（⊥\_H3）。  
（三）协议失效所致的误判。申报模型与宿载不符（Dom2 失效）：第四篇 5.5 的核查通过不推出宿载中没有未建模的结构，未建模的通道可以使 B4、B5 的 0 出错。规则文本与执行不符（Dom3 失效）：改名重放只能在失配时揭出，对称的命名条款可以使 R2 的 0 出错。撤去启动的反事实在第四篇定理 7.4 的条件之外与第三篇不同值（例 7.5′）；过定下二者即使同值，也不与第三篇的驱动重合；这两种情形 C5 都不取此路径，过定因申报模型或事件记录不全而未被读出者，属 Dom2 失效。覆盖证书或 Cand ⊇ Cand\_gen 只给出形式覆盖（C9），覆盖为真所须的条件随 G-戊、G-己 携带，未关闭时这两条路径终判 ⊥\_HOpen。判定中改动申报（C1 失效），判词作废。这些失效击穿的是相应的判定域条件，不击穿判定定理。  
（四）读法未定处。只作偏置的对象规则上 Obj\_L 的两读不同，Det\_RuleComp\_L 判 ⊥\_Reading，两读之值并列于 Read。

真正的判定边界是可判域与所携条件，不是统计置信区间。

七、判定定理

### 7.1　判定定理

定理七（判定定理）　在判定域 Dom 内：  
（i）四判词签出的 0 都正确（定理二）；  
（ii）四判词的值域为 {0, ⊥}（定理三）；  
（iii）由 ⊥ 不许推出任一方向的结论（定理四（i））；  
（iv）定理五所列子域上，负向完全；  
（v）携 H 的路径给出条件化负读数 0，所携 H 关闭时，相应判词升为 0，判词定义不变。  
各判词的路径与所携条件按第四节分列，不跨判词合取。

"""F_LB = Augment(F_min).
Inherited from Canonical F* v1.2 (最小沉积场构造式 v0.9): node depth d, relation sediment g (saturating),
Trace / Sediment / Decay / Continuation, Mode_exo / Mode_endo, softmax solver.
Added (law-base layer): pulse strength p, threshold θ, S, derived groove set Γ, replay window & Ω,
Freeze^inst (SED=OFF), Avail (availability), RoleReadMask (targeted role intervention), dual clock t_run / t_sed, IdleStep (decay only), Established^inst(R)."""
import math, random, copy
from collections import defaultdict, deque

class FLB:
    def __init__(self, nodes, medium, alpha=0.05, beta=0.25, g_max=20.0, lam_d=0.01, lam_g=0.01,
                 theta=1.0, W=30, n_omega=3, kappa0=0.05, w_g=1.0, w_d=0.02, s_weak=0.4, T=0.15, seed=0):
        self.nodes=nodes; self.E=list(medium); self.out=defaultdict(list)
        for e in self.E: self.out[e[0]].append(e)
        # inherited persistent state
        self.d={n:0.0 for n in nodes}; self.g={e:0.0 for e in self.E}
        # added persistent state
        self.rep={e:deque() for e in self.E}; self.Om={e:0.0 for e in self.E}
        self.th={e:theta for e in self.E}; self.Avail={e:1 for e in self.E}
        self.alpha,self.beta,self.g_max,self.lam_d,self.lam_g=alpha,beta,g_max,lam_d,lam_g
        self.W,self.n_omega,self.k0,self.w_g,self.w_d,self.s_weak,self.T=W,n_omega,kappa0,w_g,w_d,s_weak,T
        self.t_run=0; self.t_sed=0; self.SED=True; self.rng=random.Random(seed); self.log=[]; self.macro=None
        self.mask={e:1 for e in self.E}   # RoleReadMask: exogenous control quantity (not sediment, not decayed, persists until re-intervened)
    # ---------- inherited operators
    def Decay(self):
        """one sediment-clock step: t_sed advances; depths decay; replay windows (on t_sed) expire."""
        self.t_sed+=1
        for n in self.nodes: self.d[n]=max(0.0,self.d[n]-self.lam_d)
        for e in self.E:
            self.g[e]=max(0.0,self.g[e]-self.lam_g)
            while self.rep[e] and self.t_sed-self.rep[e][0]>self.W: self.rep[e].popleft()
            self.Om[e]=self._omega(e)
    def Trace(self,e,p): return {'e':e,'p':p}
    def Sediment(self,tau):
        e,p=tau['e'],tau['p']
        self.d[e[0]]+=self.alpha*p; self.d[e[1]]+=self.alpha*p
        self.g[e]=min(self.g_max,self.g[e]+self.beta*p*(1-self.g[e]/self.g_max))
        self.rep[e].append(self.t_sed); self.Om[e]=self._omega(e)
    def kappa(self,e):
        if not self.Avail[e]: return -1e9
        return self.k0+self.w_g*self.mask[e]*self.g[e]*(1.0 if self.S(e) else self.s_weak)+self.w_d*self.d[e[1]]
    def Continuation(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        if not cand: return None
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]
        r=self.rng.random()*sum(ws)
        for e,w in zip(cand,ws):
            r-=w
            if r<=0: return e
        return cand[-1]
    def probs(self,q):
        cand=[e for e in self.out[q] if self.Avail[e]]
        ks=[self.kappa(e)/self.T for e in cand]; m=max(ks); ws=[math.exp(k-m) for k in ks]; z=sum(ws)
        return {e[1]:w/z for e,w in zip(cand,ws)}
    # ---------- added layer
    def S(self,e): return self.g[e]>=self.th[e]
    def Deposited(self,e): return self.g[e]>0
    def Groove(self,e): return self.S(e) and len(self.rep[e])>=2
    def Gamma(self): return {e for e in self.E if self.Groove(e)}
    def _omega(self,e):
        n=len(self.rep[e]); return 0.0 if (n<self.n_omega or not self.S(e)) else min(1.0,n/(2*self.n_omega))
    def Freeze(self): self.SED=False
    def Thaw(self): self.SED=True
    def SetAvail(self,e,v): self.Avail[e]=v
    def IdleStep(self,n=1):
        for _ in range(n): self.Decay()          # t_sed advances only
    def SetMask(self,e,v): self.mask[e]=v          # targeted role intervention (structure untouched)
    # ---------- pulse
    def pulse(self,entry,p=1.0,path=None,maxhop=6):
        self.t_run+=1
        if self.SED: self.Decay()                 # t_sed advances only when sediment law is on
        q=entry; route=[q]; inst=[]
        for h in range(maxhop):
            if path is not None:
                if h>=len(path)-1: break
                e=(path[h],path[h+1])
            else:
                e=self.Continuation(q)
                if e is None: break
            if not self.Deposited(e): inst.append(e)
            if self.SED: self.Sediment(self.Trace(e,p))
            q=e[1]; route.append(q)
            if not self.out[q]: break
        self.log.append((self.t_run,entry,tuple(route),self.macro))
        return route,inst
    # ---------- law-side readouts
    # duty = dict(ante=entry node, anchor=edge whose head state is the relation's antecedent, read=target node)
    def _closure(self,start,edges):
        adj=defaultdict(list)
        for (i,j) in edges: adj[i].append(j)
        seen={start}; st=[start]
        while st:
            x=st.pop()
            for y in adj[x]:
                if y not in seen: seen.add(y); st.append(y)
        return seen
    def CarrierRealizes_inst(self,R,duty):
        """R alone (restricted) carries Ante ⇝ Anchor.tail —Anchor→ Anchor.head ⇝ Read, all on deposited edges of R;
        the anchor edge itself must be traversed (it is deposited and on the path)."""
        a=duty['anchor']
        if a not in R or not self.Deposited(a): return False
        dep=[e for e in R if self.Deposited(e)]
        return a[0] in self._closure(duty['ante'],dep) and duty['read'] in self._closure(a[1],dep)
    def Established_inst(self,R,duty):
        """R ⊆ E ∧ ∀e∈R Deposited ∧ CarrierRealizes_inst. CarrierNonInstant is a type invariant here:
        g is persistent state, so Deposited(e) ⇒ not flow-only."""
        return set(R)<=set(self.E) and all(self.Deposited(e) for e in R) and self.CarrierRealizes_inst(R,duty)
    def MediumReach_inst(self,entry,Q):
        """medium access only: entry reaches the head of some Avail=1 edge in Q via Avail=1 edges. Does not require Q deposited."""
        seen=self._closure(entry,[e for e in self.E if self.Avail[e]])
        return any(self.Avail[e] and e[0] in seen for e in Q)
    def RolePath_inst(self,R,duty):
        """a deposited, mask-open path inside R from the anchor state to Read."""
        a=duty['anchor']
        if a not in R or not (self.Deposited(a) and self.mask[a]): return False
        open_edges=[e for e in R if self.Deposited(e) and self.mask[e]]
        return a[0] in self._closure(duty['ante'],open_edges) and duty['read'] in self._closure(a[1],open_edges)

def DynamicRole_inst(F,R,duty,control_R=None,n=2000,delta=0.15):
    """RolePath_inst(R,d)=1 and do(Mask_R=0) changes P̂(Read|Ante) by >delta while a control mask on control_R does not;
    g,rep,Ω unchanged under both masks."""
    if not F.RolePath_inst(R,duty): return False,{}
    base=hit_prob(F,duty['ante'],duty['read'],n)
    L=copy.deepcopy(F)
    for e in R: L.SetMask(e,0)
    pm=hit_prob(L,duty['ante'],duty['read'],n)

        for e in control_R: C.SetMask(e,0)
        pc=hit_prob(C,duty['ante'],duty['read'],n)
    ok=inv and (base-pm)>delta and (pc is None or abs(base-pc)<=delta)
    return ok,dict(P_hat_base=base,P_hat_Rmask=pm,P_hat_ctrlmask=pc,invariants=inv)
def hit_prob(F,entry,target,n=2000):
    G=copy.deepcopy(F); G.Freeze(); c=0
    for _ in range(n): c+= target in G.pulse(entry)[0]
    return c/n

def corr_M(F,a,b):
    """macro-event co-occurrence: Corr_M = #{k: a,b both in M_k} / #{k: a or b in M_k}."""
    ev=defaultdict(lambda:[False,False])
    for _,_,r,m in F.log:
        if m is None: continue
        if a in r: ev[m][0]=True
        if b in r: ev[m][1]=True
    both=sum(1 for x,y in ev.values() if x and y); either=sum(1 for x,y in ev.values() if x or y)
    return both/either if either else 0.0

def events(model, inputs, remove_start=None):
    """model: 'normal' | 'stalled'（第二次启动时加法逻辑不求值，显示保留上次之值）| 'static'（静置存储：交付即放置、原位读取）"""
    log = []; disp = None
    for k, inp in enumerate(inputs):
        started = (k != remove_start)
        if model == 'static':
            log.append(('place', k, inp)); log.append(('read', k, inp)); continue
        if started: log.append(('start', k))
        if started and not (model == 'stalled' and k == 1):
            s = inp[0] + inp[1]; log.append(('eval', k, s)); log.append(('write', k, s)); disp = s
        log.append(('read', k, disp))
    return log
def det_exec(model, inputs, T_runs, bear, enabling_awake=False, run_asleep=False, u2=False):
    if bear['v'] == 0: return V(0, '入口：Det_Bear = 0（执行以承担为前件，第三篇）', bear['Cond'], bear.get('H', []))
    if enabling_awake and run_asleep: return V(0, '使能条件不成立：申报使能含清醒，运行记录有睡眠证据（第三篇第十三节）')
    fails = []
    for k in T_runs:
        act = events(model, inputs)
        if model == 'static':
            fails.append((k, 'Ex_α：变换部分为空（第三篇例：承担而不能执行）')); continue
        if not any(e[0] == 'start' and e[1] == k for e in act): fails.append((k, 'Ini')); continue
        if not any(e[0] == 'read' and e[1] == k for e in act): fails.append((k, 'Out')); continue
        cf = events(model, inputs, remove_start=k)
        w_act = [e for e in act if e[0] in ('eval', 'write') and e[1] == k]; w_cf = [e for e in cf if e[0] in ('eval', 'write') and e[1] == k]
        if not w_act or w_act == w_cf: fails.append((k, 'Ex：撤去本次启动，读出所依事件不变（第四篇定理 7.4 的条件下）'))
    if len(fails) == len(T_runs):
        exf = any(('Ex：' in f[1]) or ('Ex_α' in f[1]) for f in fails)
        cond = ['判定域：第四篇定理 7.4 的条件'] if any('Ex：' in f[1] for f in fails) else []
        return V(0, 'T 内每一运行都直接失败：%s' % fails, cond, ['计算执行一般式-H3（a）（b）'] if exf else [])
    if u2: return V('⊥', '⊥_U2：第三篇 U2 未定情形')
    return V('⊥', '⊥_Suff：执行的充分向未答（第三篇 U1）', structure='Ini、En、¬Sub、Ex、Out 在案')
