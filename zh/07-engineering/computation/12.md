# 计算与非计算宿载区分式

## 第一节　唯一任务与式种

### 1.1 唯一任务

计算宿载与非计算宿载，是不是只是同一类宿载的两种说法？

要证明的不是二者的定义写法不同，而是：存在一个合法、可以执行的共同观测规范 q，满足 C 的合格宿载接入它只能读出 1，满足 N 的合格宿载接入它只能读出 0，两侧的读出集合不相交。这里的读出是对申报模型全部许可结果的理论读出；按一次实际运行给出的实际读出，在模型符合实物的条件下与它一致（9.6）。

　　Out\_C(q) ∩ Out\_N(q) = ∅

两类宿载中的变换，都是信号与介质的迹应。二者的差别在于迹应关系从哪里来：计算宿载的迹应关系由数学表达式设定，非计算宿载的迹应关系就是介质中物质与信号的交互本身。本篇证明：这个差别可以由一项观测读出来，而第七节所列的那些只看承担、产出、介质和记录的被动观测，都不足以普遍地读出它。

这里的"计算宿载"与"非计算宿载"，指第四、五节的两个候选 C、N。C 刻画的是迹应关系可以按数学表达式重新设定的宿载；N 刻画的是没有这种设定通路、表达式只作描述的宿载。它们由初始规定读出（2.3），但本篇没有证明初始规定所说的一切计算宿载都满足 C、一切非计算宿载都满足 N：只能实现一个任务、重设就得重新制造的硬连线器件，就不在 C 的可观测范围之内（12.3（7）（8））。所以总定理是对这两个候选的区分，不是对一切宿载的分类。

### 1.2 区分什么，为什么要区分

初始规定把律在宿载中的复现分为两条路：在计算宿载中，动力在信号流经过、通过规则真正进行计算变换时发生；在非计算宿载中，动力在信号流过宿载介质、与介质中的物质发生交互迹应时发生（初始规定五）。两条路都通向动力层：这些运动都真实地来自宿载，若宿载是计算设备，就来自计算；若是非计算物质，就来自这些物质（初始规定三）；沉积场不一定要靠计算才能实现（初始规定二）。

所以本篇区分的，是动力在宿载层的两种实施来源，以第四、五节的两个候选 C、N 刻画（二者能否完整代表这两种来源，见 12.3（8））。它不是给设备分类，也不认为哪一种来源更接近真实的动力。动力层和对象层的资格由它们自己的成立条件取得，不由宿载属于哪一类决定；这一层次关系由《计算分层一般式》的层分立与不可越过、《计算越层误置消解式》的越层误置消解给出，本篇在 10.2、10.9 和第十四节引用。本篇的定理不以非计算宿载上已经形成动力层为前提。

### 1.3 式种

区分式，附式，独立成篇（《法篇》第一 v2.2 第四编第十二章）。区分式的用途是证明存在一个观测，能把两个候选结构分开；进入条件是两个候选的定义已经分别闭合、两个候选的前向映射都已经给出（本篇的前向映射在共同观测规范之下写出，两侧的读出集合由它给出，见 8.5）；标准写法是候选对申报、区分观测构造、区分有效性证明、区分定理、接口；完成条件是区分观测已经明确写出，有效性证明已经完成。

区分式只回答有没有一个观测能把两者分开；对任意一个宿载给出"计算"或"非计算"的判词，是判定式的任务，由《计算判定式》的后续研究承担，组内尚未成立（12.3（1））。第七节定理一是区分观测的阻力论证：它在被动观测集 𝒴₀ 上对其中每一项观测成立，借 7.1 的一对见证说明这些观测不足以普遍地分开两个候选，区分观测须越出 𝒴₀。它不独立承担完成条件，不研究观测集扩张的界，也不对 𝒴₀ 之外的观测作结论；一般观测集上的效果层不可区分研究属原规划，组内尚未成立。

### 1.4 结果

下面是本篇结果的缩写，正式陈述与证明见第七、九节。

定理一：在承担判词、接受判词、介质是否连续、迹应元件的材料、表达式记录及其申报主张、是否为求值而设置这六项被动观测上，存在一个计算宿载和一个非计算宿载，它们的产出完全相同。

定理二至四：在共同前件 K0（3.3）、申报完备（W1）、运转条件冻结（W2）、交付到宿载的信号保持不变（Y5）、比较的两轮的运行初态由同一初始化协议取得（Y6）以及 𝒴^adm 其余各项条件下，对表达式记录做一次重设——改写记录、重新运行设定程序、按冻结的协议看产出符合哪一个表达式——满足 C 的宿载（τ′ ∈ 𝒯）必然读出 1，满足 N 的宿载必然读出 0。判词对申报模型中的全部许可结果作出，不对某一次抽样运行作出。所以存在共同观测规范 q，使 Out\_C(q) = {1}，Out\_N(q) = {0}，二者不相交。

推论二：对 𝒴^adm 中的观测，在实际产出落在申报模型许可结果集合之内的条件下（W3），对冻结的测试交付做一次实际干预，按实际产出给出的判词与上面的理论判词一致：满足 C 的宿载读出 1，满足 N 的宿载读出 0。W3 是申报的连接条件，不由有限次实验证明；一次实际观测本身不能认证一个未知宿载的稳健资格。

一句话：两类宿载都是信号与介质的迹应；在两个候选 C、N 与工作域 𝒴^adm（含 W1、W2，连同共同前件 K0；C 一侧另需 τ′ ∈ 𝒯）之内，改写表达式后宿载跟着改变的属 C，迹应关系由表达式设定；改写表达式后宿载不变的属 N，迹应关系是物质自身的交互。两个候选能否代表两类宿载，没有证明（12.3（8））。

### 2.2 初始规定

本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。引用时标出序号：

　初始规定一：计算的本质是由输入经状态、变换、再到状态，依次进行直至输出的过程；计算限于由设备驱动的数学运算。  
　初始规定二：计算驱动沉积场动力，沉积场动力生成律与理，这就是分层；沉积场不必依赖计算才能实现。  
　初始规定三：动力层与对象层的运动都真实地来自宿载：若宿载是计算设备，就来自计算；若是非计算物质，就来自这些物质。  
　初始规定四：不经由信号流、在历史之外直接改渠或改写权重，是侵入。  
　初始规定五：动力的发生分两种：在计算宿载中，动力在信号流经过、通过规则真正进行计算变换时发生（前一款）；在非计算宿载中，动力在信号流过宿载介质、与介质中的物质发生交互迹应时发生（后一款）。宿载规则就是信号与宿载介质的迹应关系。  
　初始规定六：相对于非计算的 P，目前已知的计算的 P 有两种：一是脑，仅限于它行使计算能力之时，但不能误解为计算驱动生成了脑的动力；二是计算设备。  
　初始规定七：复现也可以不经计算：例如用同类物质与环境复现旋涡；复现所用的不一定是同类物质与环境，不同类的也必定有复现成功的例子。  
　初始规定八：计算、思考、推理本质上是同一件事，都是由输入经状态、变换、状态直至输出，即律在宿载中的运行；不同之处在于，计算限定于数学运算设备，其余则是由其他物质驱动的动力场。  
　初始规定九：人工神经网络模拟的是信号流与介质之间的迹应作用，不过是把它数学化为规则，交由计算设备处理；生成计算的宿载在本质上仍是信号流与介质如何发生迹应。  
　初始规定十：形式与数学规定结构、关系、变换的成立与证明：从具体材料（现象）中提取结构、关系与变换，以求在别的材料中也能复现，或经去噪后逼近复现。

### 2.3 从初始规定读出的两件事

第一，共同基础。初始规定五与初始规定九说明：计算宿载与非计算宿载中的变换，都是信号与宿载介质的迹应。

第二，差别在哪里。计算宿载把现象数学化为规则，由设备按规则变换（初始规定一：计算限于由设备驱动的数学运算；初始规定八：计算限定于数学运算设备；初始规定九：数学化为规则，交由计算设备处理）；非计算宿载的变换是信号与介质中物质的交互，由物质的动力驱动（初始规定五后一款；初始规定八：由其他物质驱动的动力场）。初始规定十给出数学表达式与现象之间的两个方向：从现象提取表达式；用表达式在别的材料中复现。

所以，在初始规定中，计算与非计算的区分落在迹应关系的来由上：迹应关系是不是由数学表达式设定的。第四、五节的两个候选就是这两种情形。

### 2.4 工作域之外

宿载之上的动力层、对象层是不是计算；律、理、概率、意向在宿载中的资格；一次复现是否失真；任意一个宿载属于哪一类；某一事件上计算是否成立——这些都在工作域之外，本篇的定理对它们不作断言。

## 第三节　记号与共同前件

### 3.1 宿载系统

　　𝒮 =（P, m, Env, Π, ℛ, 𝒫）

P：宿载。  
m：介质的组成与排布，包括 P 内部从输入端口到读出之间的一切组成部分；它是宿载的配置。  
s₀：一次测试运行开始时介质的运行状态，例如电容上的初始电荷。它与配置 m 不同：设定程序改变的是配置，运行初态由申报的初始化协议在每次运行开始时取得。  
Env：申报的运转条件（第二篇）。  
Π：申报的交付与读法协议（对应第二篇 Prov、Leg 中的交付与读法）。本篇的 Π 不是第二篇任务中的接受协议 Π；接受协议在本篇记作 Acc\_τ（3.4）。交付指按 Π 送到 P 输入端口的物理信号；从测试交付到这个信号的对应，记为交付映射 Δ\_Π。  
ℛ：申报边界内的表达式记录，也就是以任何形式载有数学表达式的记录：程序文本、接线表、电路设计、指令、笔记。  
𝒫：申报边界内以 ℛ 中的记录为输入的程序；每个程序注明它的作用对象——作用于 m，或者只作用于交付。

### 3.2 宿载规则

k\_P：P 的宿载规则，也就是信号与宿载介质的迹应关系（初始规定五）。

### 3.3 共同前件 K0

在 Π、Env 给定时，P 对一次交付 u 的许可结果集合 𝓜(m, s₀, u)，由配置 m、运行初态 s₀ 和这次交付决定；𝓜 非空；交付之后，结果不经申报边界之外的代算。宿载的结果有随机性时，结果在 𝓜 上的分布也由这三者决定。一次实际运行得到的结果，是 𝓜 中的一个元素。

依据：初始规定五、九——两类宿载中的变换都是信号与介质的迹应，也就是介质在运转条件下对信号的作用。"交付之后没有外部代算"一款与第二篇 Prod 中不代算一款同义，本篇把它作为申报条件取用，不由承担推出：本篇的观测包只要求稳健接受（Y3），不要求承担。K0 是本篇申报模型的共同前件，对两个候选同样取用；它不成立时，失效的是前件（第十三节）。

### 3.4 任务与接受

任务 τ 采用第二篇的定义；ext(τ) 是 f 在 D 上的外延（第二篇推论一）。对一组有限的测试交付 D\_test = (u₁, …, u\_k)，结果族 μ = (y₁, …, y\_k) 是在每一次交付上各取一个结果组成的序列；Acc\_τ(μ) ∈ {1, 0} 是 τ 的接受协议对这一整组结果给出的判词。

许可结果族集合：𝓜(𝒮; D\_test) = 𝓜(m, s₀, u₁) × … × 𝓜(m, s₀, u\_k)，即在每一次交付上从许可结果集合中任取一个结果所能组成的全部结果族。

稳健接受：Acc\*\_τ(𝒮; D\_test) = 1，当且仅当 𝓜(𝒮; D\_test) 中的每一个结果族都满足 Acc\_τ；否则为 0。

这里区分三个层次：结果分布、许可结果族、实际抽样结果。本篇的判词都在许可结果族这一层作出——稳健接受对全部许可结果族成立，所以无论一次实际运行抽到哪一个结果，这一结果都被接受。有限次实际运行恰好被接受，不等于稳健接受，不能代替它。

## 第四节　候选一：计算宿载

### 4.1 定义

　　C(𝒮; τ, 𝒯) ≔ C1 ∧ C2 ∧ C3

C1（数学化的规则）𝒯 是一组任务，τ ∈ 𝒯；每个成员都与 τ 共用 Π 的交付与读法类型；成员的外延两两不同；每个成员都以表达式记录的形式给出。

C2（设定入口）𝒫 中有这样的程序：它读取 𝒯 中成员的记录，在交付之前作用于 m。这些程序合起来记为 Set。

C3（按规则变换）对 𝒯 中的每一个 τ′：用 τ′ 的记录运行 Set 之后，在 Env 与 Π 下，从申报的初始化协议取得的运行初态开始，P 稳健接受 τ′，即 Acc\*\_τ′ = 1：全部许可结果族都满足 Acc\_τ′。一次或有限次运行恰好被接受，不满足 C3。

### 4.2 读法

表达式在宿载规则之前，并经过设定入口决定宿载规则：

　　表达式 → m → k\_P

C1 取自初始规定十与初始规定一：规则是从现象中提取的数学结构、关系、变换，宿载做的是数学运算。C2、C3 取自初始规定五所说通过规则真正进行计算变换、初始规定八所说计算限定于数学运算设备、初始规定九所说数学化为规则并交由计算设备处理："由设备按规则变换"落到宿载系统上，就是有一个以规则为输入、决定介质的入口，而且按它设定之后，宿载的产出符合这个规则。Set 以记录为输入，所以对 𝒯 的每一个成员都可以执行。

### 4.3 设定入口的几种形态

可编程设备：Set 是装载程序；程序存在存储器里时，记录同时就在 m 中，装载就是设定。  
模拟运算装置：Set 是按接线表接线、选取元件。  
硬连线器件：只能实现一个任务、改变任务必须重新制造的硬连线器件，不一定满足 C2。如果申报的宿载系统包含按表达式记录配置介质的制造或设置程序，而且这个程序符合 C2，它可以满足 C 的定义；如果申报的是已经制成、没有这类设定入口的单一器件，它不属于 C。无论哪一种情形，它的任务族只有一个成员，都不满足 8.4 中 C 一侧的可读条件 τ′ ∈ 𝒯，本篇的重设观测不覆盖它（12.3（7））。它是不是初始规定意义上的计算宿载，留在 12.3（8）。能在同一器件上按记录改接的，属于上一条模拟运算装置一类。  
行使计算能力时的脑（初始规定六）：Set 是读取或学会运算规则；𝒯 是它能按着运算的那些规则。心算的人读进指令，使自己的运算按指令设定；指令改写之后，他的结果跟着符合新的表达式。脑自身的离子与递质动力不经过表达式设定，属于第五节那一侧。这与初始规定六（脑仅在行使计算能力时是计算的 P）相符。

### 4.4 候选在宿载层定义

两个候选都按宿载规则 k\_P 的来由定义，不按宿载之上有没有目标动力过程来定义。如果把候选定为"通过计算执行驱动目标动力过程的宿载"和"通过物质交互驱动目标动力过程的宿载"，那么要判断一个宿载属于哪个候选，就得先判断它上面有没有目标动力过程、由谁驱动，候选就用到了动力层的资格（与 6.3 不符）；而且承担数学任务、却不生成动力层的计算设备，会落在两个候选之外，可是初始规定把计算设备列为计算的 P（初始规定六），并没有以它生成动力为条件。初始规定五所说的两种动力来源，差别正在宿载规则的来由上；动力层从这里往上接（初始规定三），不必写进定义。

## 第五节　候选二：非计算宿载

### 5.1 定义

　　N(𝒮) ≔ N1 ∧ N2

N1（物质迹应）k\_P 是介质中物质与信号的交互，由 m 在 Env 下给出（初始规定五后一款）。

N2（没有设定入口）𝒫 中没有作用于 m 的程序；ℛ 中如果有表达式记录，也只是对 P 的描述——从 P 的现象中提取，或者是关于 P 写下的（初始规定十的提取方向），它不在 m 中决定 k\_P 的那部分里。读取记录、只作用于交付的程序可以有，但它送到 P 输入端口的信号不随记录内容而改变（例如只做记录、计时、触发）。

### 5.2 读法

现象在表达式之前：

　　k\_P → 表达式（如果有）

从表达式到 k\_P 没有通路。初始规定五后一款、初始规定八所说由其他物质驱动的动力场，以及初始规定七用同类物质与环境做的复现，都属于这一类：变换由物质自身的动力给出。

## 第六节　两个候选各自闭合

### 6.1 各自读什么

C 读 ℛ、𝒫、Set 的作用对象，以及按 Set 设定之后的许可结果族。N 读 𝒫 的作用对象，以及 ℛ 中记录的地位。

### 6.2 各自有确定的真值

在申报已经冻结的 𝒮 与 𝒯 上，C 的三款、N 的两款都有确定的真值。

### 6.3 各自不用到的东西

两个候选都不用到"计算型宿载"这个名称，不用到对方，不用到动力层、对象层的任何资格，也不用到任何律、理、概率、意向的读数。

### 6.4 所以候选闭合

由 6.1 至 6.3，两个候选的定义已经分别闭合。

### 6.5 定义上互斥，不等于可以观测地分开

C2 要求 𝒫 中有作用于 m 的程序，N2 排除了这种程序，所以二者在定义上互斥。可是两个互斥的定义，仍然可以在一切被动观测上产出相同（第七节定理一）。能不能通过观测把它们分开，需要另外证明。

### 6.6 二者没有高下

二者是迹应关系的两种来由，也是动力的两种实施来源。从区分推不出哪一种更根本、更强或更真实。

## 第七节　阻力：被动观测分不开两者

### 7.1 见证对

W\_C：一个运算放大器反馈网络，反馈元件由接线程序按表达式记录选取：记录为积分时接入电容 C₀，记录为比例时接入电阻 R₀。交付是电流 I(t)，幅度与时间窗按申报；读出是输出电压。ℛ 中有接线表和任务表达式；𝒫 中有按表达式选取并接入反馈元件的接线程序，它作用于 m。

　　𝒯 = { τ\_int, τ\_prop }，　τ\_int ：V(T) = (1/C₀)·∫₀ᵀ I dt，　τ\_prop ：V(T) = R₀·I(T)

两个任务的算子不同——一个是积分，一个是比例——不只是同一个算子的参数不同。

W\_N：一只电容量为 C₀ 的裸电容，没有经过按表达式的选取，由电流源充电，用电压表读它的端电压。ℛ 中有一份笔记"V = (1/C₀)·∫ I dt"，是对它充电现象的描述；𝒫 只包括连接、交付与读数，不作用于电容。

两者的申报初始化协议 ι 相同：每次交付开始前，把反馈网络或读出端中接入的、承担产出的储能元件放电到 0 V。在 W\_N 与积分配置的 W\_C 中，这个元件是电容 C₀；比例配置的 W\_C 中，反馈元件是电阻 R₀，没有承担产出的储能状态，ι 对它不起作用，运行初态由比例配置本身确定。两者的申报运转条件取为有界误差模型：漏电使积分输出的相对误差不超过 10⁻³，失调与读出噪声之和的绝对值不超过 0.005 V。两者的申报都在测试运行之前冻结（《计算判定式》Dom1、C2），两者的申报模型都取为通过该式 C3 所引的模型充分性核查（第四篇 5.5）；7.3（ii）的承担判词在这一判定域条件下作出。

W\_C 满足 C（对 τ\_int 与 𝒯）：C1 由 𝒯 的写法给出；C2 由接线程序给出；C3 由反馈网络在申报运转条件下的输出给出——反馈元件是电容 C₀ 时，输出 (1/C₀)·∫ I dt；是电阻 R₀ 时，输出 R₀·I(T)。

W\_N 满足 N：端电压由电介质的极化与电荷积累给出（N1）；𝒫 不作用于电容，笔记只是描述（N2）。

### 7.2 被动观测集 𝒴₀

（i）在 τ\_int 的冻结协议下的稳健接受判词 Acc\*\_τint；  
（ii）《计算判定式》对 τ\_int 的承担判词 Det\_Bear；  
（iii）介质是不是连续的；  
（iv）承担积分的迹应元件是什么材料；  
（v）有没有表达式记录、记录的内容，以及附带的申报主张；  
（vi）装置是不是为了求 f 而设置的。

### 7.3 定理一（被动观测分不开）

对 𝒴₀ 中的每一项观测，W\_C 与 W\_N 的产出相同。所以 𝒴₀ 中没有一项观测能把 C 与 N 分开。

证明。  
（i）在申报运转条件下，两者的全部许可输出都在容差之内给出 V(T) = (1/C₀)·∫ I dt（误差界见 9.2），Acc\*\_τint = 1。  
（ii）两者的交付都不包含对 f 的求值；读法都是对电压的固定判读，读出时不施加 f；入口可达；常值读法、录放、交付时直接送出结果这几种情形都没有出现。《计算判定式》的否定判据 B1—B6 都不触发；读法是对电压的直接判读，不涉及编码分担，不落入 ⊥\_H2；两者都在判定域之内（7.1），不落入 ⊥\_D、⊥\_M；承担的充分方向在第二篇没有回答，所以在判定域内，两者的承担判词都是 ⊥\_Suff。  
（iii）两者的介质都是连续的。  
（iv）两者承担积分的元件都是电容的电介质。  
（v）两者的 ℛ 中都有 τ\_int 的表达式。如果 W\_N 一侧另外附上"𝒯 可以设定"的申报主张，那么只读记录和主张，它的产出与 W\_C 相同；主张是否属实，只读是看不出来的。  
（vi）两者都是为了得到 ∫ I dt 而设置的。初始规定七用同类物质与环境做的复现，也同样是有意设置的。  
六项都相同。证毕。

### 7.4 读回

第二篇说"承担是宿载对一项任务的结构资格，不是计算的标志"，其中"不是计算的标志"一半，在同一个任务上由一对见证得到例示：两者在承担一侧的被动观测相同（7.3（ii）），而一为计算宿载、一为非计算宿载。连续与离散不是分界：连续的反馈网络是计算宿载。材料不是分界：同一种电介质在两边都在承担积分。能不能写出表达式不是分界：裸电容的充电完全可以用表达式描述。是否有意设置也不是分界。

初始规定六给出另一组同介质的情形：行使计算能力时的脑，与脑自身的离子动力，介质是相同的。

定理一说明：所列的被动观测不足以成为两个候选的普遍区分器——在这一对见证上它们分不开二者。它不说明这些观测在任何一对特定的宿载上都分不开。

## 第八节　重设观测

### 8.1 共同观测规范与观测包

　　q =（τ, τ′, Π, Env, ι, D\_test, Acc\_τ, Acc\_τ′）

q 是共同观测规范：ι 是申报的初始化协议，其余各项如前。q 不含宿载，对两个候选同样适用。把一个宿载系统接入规范 q，得到一份观测包：

　　Y =（𝒮, q）

两个候选比较的是：在同一个 q 下，分别接入满足 C 与满足 N 的合格宿载，各自能读出什么（8.5）。

### 8.2 操作 I(τ → τ′)

把 ℛ 中 τ 的每一份记录改写为 τ′ 的记录；把 𝒫 中读取这些记录、作用于 m 的每一个程序按申报重新运行；只作用于交付的程序不重新运行，Π 冻结；除此之外，不对 m、Π、Env 做任何操作。然后按 Π 对 D\_test 中的各次交付运行 P。操作之后宿载的许可结果族集合记为 𝓜′(D\_test)；一次实际运行得到其中的一个结果族 μ′。

### 8.3 读出

　　Read(Y) = 1　　如果操作之后 Acc\*\_τ′ = 1  
　　Read(Y) = 0　　如果操作之后 Acc\*\_τ = 1  
　　Read(Y) = ⊥　　如果两者都不成立

由 8.4 的 Y2 与 𝓜′ 非空（K0），前两款不会同时成立，所以 Read 只取一个值。

Read 是理论读出：它对操作之后的全部许可结果族判定，不对某一次运行判定，承担定理二至四的证明。

实际读出：按 8.2 实际运行一次，得到结果族 μ′，

　　Read\_obs(Y) = 1　　如果 Acc\_τ′(μ′) = 1  
　　Read\_obs(Y) = 0　　如果 Acc\_τ(μ′) = 1  
　　Read\_obs(Y) = ⊥　　如果两者都不成立

由 Y2，前两款不会同时成立。

两种读出职责不同。Read 要求知道申报模型的全部许可结果，由申报模型及其证书（例如误差上界）给出；Read\_obs 只要求实际交付与读数。μ′ 恰好满足某一个接受协议，不足以确定 Read：有限次读数不能认证全部许可结果——一个输出机制永远落在接受域内，另一个只以极小概率落到接受域外，有限次测试可以给出完全相同的记录。二者之间的连接由 W3 承担（8.4），连接命题是推论二（9.6）。

### 8.4 有效工作域 𝒴^adm

Y1　τ、τ′ 是第二篇意义上的任务，共用 Π 的交付与读法类型，ext(τ) ≠ ext(τ′)；读法冻结，不随 τ′ 改动。  
Y2　接受互斥：D\_test 上没有一个结果族同时满足 Acc\_τ 和 Acc\_τ′。例如，在每一次交付上两个函数之差大于两倍容差。  
Y3（稳健基线接受）施加操作之前，P 稳健接受 τ：对 D\_test，宿载在申报模型中全部许可结果族都满足 Acc\_τ（Acc\*\_τ = 1）。不得以有限次实际运行恰好被接受代替这一条件。  
Y4　操作只有 8.2 所列的那些。  
Y5　交付冻结：对 D\_test 中的每一次交付，操作前后送到 P 输入端口的物理信号相同，也就是交付映射 Δ\_Π 不因记录的改写而改变。  
Y6　运行初态同一：操作前后的比较运行中，每一次测试交付开始时，与申报产出有关的介质运行状态都由同一个冻结的初始化协议取得：配置不变时，两次运行的初态相同；配置被设定程序改变时，初态是同一协议作用于新配置的结果。初始化协议不读取表达式记录、不替宿载求值，也不撤销或替代设定程序对配置所做的改变：它只决定运行初态 s₀，不触及配置 m。  
W1（申报完备）𝒮 的申报边界包含一切以表达式记录为输入、在 m 中设定 k\_P 的程序。  
W2（运转条件冻结）操作前后 Env 与 Π 不变。  
W3（模型符合实物）操作前后，宿载每一次实际运行的产出都属于申报模型给出的许可结果集合 𝓜(m, s₀, u)。W3 只用于实际读出 Read\_obs，不属于 𝒴^adm 的条件，定理二至四不用到它。它是申报的连接条件，不能由有限次实验自动证明。

候选一侧的可读条件：对 C，τ′ ∈ 𝒯；对 N，不另加条件。

W1、W2、W3 与《计算判定式》的判定域条件是同一类：申报模型与现实宿载是否相符，属于实例化与外部连接。W1 或 W2 不成立时，产出可以与候选不符；W3 不成立时，实际读出可以与理论读出不符；这时失效的是工作域条件。

### 8.5 前向映射与读出集合

　　F\_C：定义在 {(𝒮, q) ∈ 𝒴^adm：𝒮 满足 C（对 τ 与 𝒯），τ′ ∈ 𝒯} 上，取值 Read(𝒮, q)。  
　　F\_N：定义在 {(𝒮, q) ∈ 𝒴^adm：𝒮 满足 N} 上，取值 Read(𝒮, q)。

固定共同规范 q，两个候选的读出集合是：

　　Out\_C(q) = { F\_C(𝒮, q)：(𝒮, q) 在 F\_C 的定义域中 }  
　　Out\_N(q) = { F\_N(𝒮, q)：(𝒮, q) 在 F\_N 的定义域中 }

C 与 N 互斥（6.5），同一个 𝒮 不能同时满足二者，所以 F\_C 与 F\_N 的定义域不相交。区分要比较的不是两个函数在同一个宿载上的值，而是同一个冻结规范 q 下两侧的读出集合。读出集合是否非空不能从写法假定，要由合格实例给出（9.2）。

### 8.6 观测可以执行

可以执行的是实际读出 Read\_obs：改写记录；按申报重新运行程序；按冻结的协议交付与读数；按冻结的接受协议给出判词。这些在申报的实现环境中都能做，不读任何观测不到的量，也不读"计算型宿载"的标签。

理论读出 Read 不由这些操作单独取得：稳健接受是对申报模型的判定，由申报模型给出的许可结果集合决定，例如由误差上界证明全部许可输出都落在容差之内（9.2）。实际读出在 W3 下与理论读出一致（推论二）；W3 是否成立，与《计算判定式》中申报模型与现实宿载是否相符一样，属于判定域条件。

### 8.7 观测读的是当下的干预

操作做的是：现在改写记录，现在重新运行现有的程序，现在看结果是否跟着改变。它不读介质过去是怎样形成的。W1 要求的是申报边界包含现有的设定入口。

### 8.8 观测不预先假定归属

操作 I 对一切宿载系统都用同一个定义：改写申报边界内的全部表达式记录，重新运行申报边界内读取这些记录的全部程序。它的定义里没有按候选归属而分的情形，也不按归属挑选记录或程序；读出只依据冻结的接受协议。归属只出现在定理二的证明里，用来推出两侧的产出。

与归属有关的只有 W1：如果申报边界漏报了设定入口，满足 C 的宿载会读出 0。W1 要求的是申报边界完备，不是申报者对归属的声明。下面几种情形说明各项条件的作用（附录 B 记录了它们在模型上的运行）：  
　甲　在非计算宿载的申报中，加入一个读取表达式记录、作用于介质、但不按表达式设定迹应关系的程序（例如读到记录就给电容加热，而加热不改变产出）。这个系统不满足 N2，也不满足 C3，不在两个候选之内；读出为 0，定理对它不作断言。  
　乙　满足 C 的宿载漏报了设定入口：W1 不成立，读出为 0。这正是 W1 所排除的情形。  
　丙　申报的 𝒯 中有一个成员实际上实现不了：C3 不成立，这个系统不满足 C，不在 C 一侧的可读条件之内。  
　丁　在裸电容之前加一个读取表达式记录的转换程序：记录为积分时原样交付；记录改为比例后，把输入换成另一条电流波形，使电容的输出满足比例任务。电容和它的迹应关系都没有变，读出却会是 1。如果这个转换程序在 P 之外，它改变了送到 P 输入端口的信号，Y5 不成立，这份观测不在 𝒴^adm 之内；如果它在 P 之内，它就是按记录作用于 m 的程序，系统不满足 N2，在 C3 成立时满足 C。两种情形都不构成定理二的反例。  
　戊　裸电容在操作之后的那一轮从另一个初始电压开始：没有设定程序，交付信号相同，运转条件相同，电容和它的迹应关系都没有变，可是输出不再符合原任务，读出不是 0。这时两轮的运行初态不同，Y6 不成立，这份观测不在 𝒴^adm 之内。它不说明电容变成了计算宿载，只说明比较的两轮必须从同一运行初态开始。  
　己　一个满足 N 的随机器件：在同一配置、初态、交付与运转条件下，每次运行独立地输出 0 或 1，概率各半；τ 只接受 0，τ′ 只接受 1。第一轮实际输出 0，第二轮实际输出 1，如果按实际结果读，会读出 1。可是这个器件的许可结果集合是 {0, 1}，其中有不被 Acc\_τ 接受的结果，稳健 Y3 不成立，这份观测不在 𝒴^adm 之内；操作之后许可结果集合仍是 {0, 1}，按 8.3 读出 ⊥。两轮的结果分布相同，不等于两轮的实际结果相同，所以判词必须对全部许可结果作出，不能对一次抽样作出。  
Y5 只比较操作前后送到输入端口的信号是否相同，Y6 只比较两轮运行初态是否由同一协议取得，二者都不涉及宿载属于哪一类，对两个候选同样适用。满足 C 的宿载，其 Set 作用于配置 m，不改变送到输入端口的信号，也不受初始化协议撤销，所以 Y5、Y6 都不排除它。

## 第九节　区分有效性

### 9.1 定理二（有效性）

对 𝒴^adm 中的任一 Y：  
　如果 𝒮 满足 C（τ′ ∈ 𝒯），那么 Read(Y) = 1；  
　如果 𝒮 满足 N，那么 Read(Y) = 0。

证明。

C 一侧。由 Y4，操作重新运行 𝒫 中读取记录、作用于 m 的全部程序，也就是 Set（C2），这时它的输入已经改为 τ′ 的记录；Set 在交付之前作用于 m。由 W2，Env 与 Π 不变。由 Y6，测试运行从初始化协议取得的运行初态开始。由 C3，此后 P 稳健接受 τ′：操作之后的全部许可结果族都满足 Acc\_τ′，Acc\*\_τ′ = 1。所以 Read(Y) = 1。

N 一侧。由 N2，𝒫 中没有作用于 m 的程序；由 W1，申报边界之外也没有以表达式记录为输入、设定 k\_P 的程序。由 Y4，操作除了改写记录、重新运行 𝒫 中的程序以外，不触及 m。改写记录本身不改变 m 中决定 k\_P 的组成与排布，因为按 N2，记录不在那一部分里。所以 m 不变。由 Y5，送到 P 输入端口的信号也不变。由 Y6，运行初态 s₀ 也相同。由 K0 与 W2，每一次交付的许可结果集合不变，𝓜(m, s₀, u) 在操作前后相同；结果有随机性时，分布也不变。所以 𝓜′(D\_test) = 𝓜(D\_test)。由 Y3，𝓜(D\_test) 中每一个结果族都满足 Acc\_τ，所以 𝓜′(D\_test) 中每一个结果族都满足 Acc\_τ，Acc\*\_τ = 1。所以 Read(Y) = 0。

两侧推出的都是对全部许可结果族的接受，不是对某一次运行结果的预言；由于实际运行得到的结果族属于许可结果族集合，它也必然被相应的接受协议接受。证毕。

### 9.2 定理三（实例）

取 7.1 的 W\_C、W\_N，C₀ = 1 mF，R₀ = 250 Ω，T = 1 s；τ = τ\_int，τ′ = τ\_prop；D\_test 取任意一组有限个恒定电流交付 I(t) ≡ iⱼ，每一个都满足 0.2 mA ≤ \|iⱼ\| ≤ 1 mA，下面的证明对每一种取法都成立；任务 τ 的接受协议 Acc\_τ 是：在每一次交付上，输出与 τ 的函数值之差都不超过容差 0.05 V；误差按 7.1 的有界模型。

在每一次这样的交付上，τ\_int 给出 i·T/C₀ = 1000·i（伏，i 以安为单位），τ\_prop 给出 R₀·i = 250·i，二者之差为 750·\|i\| ≥ 0.15 V（i 取各 iⱼ）。按有界误差模型，宿载在一次交付上的许可输出集合，是它所实现的那个函数值周围的一个区间：每一个许可输出与这个函数值之差都不超过 \|V\|·10⁻³ + 0.005 ≤ 0.001 + 0.005 = 0.006 V。

核对工作域。Y1：两个任务共用"电流入、电压出"的交付与读法类型，外延不同。Y2：每一次交付上两个函数之差至少 0.15 V，大于两倍容差 0.1 V。Y3：两者在操作前都实现 τ\_int，全部许可输出与 τ\_int 之差都不超过 0.006 V \< 0.05 V，所以全部许可结果族都满足 Acc\_τint，稳健 Y3 成立。Y4、W1、W2：按 7.1 的申报。K0：两者的许可结果集合按 7.1 的有界误差模型由配置、运行初态与交付决定，对每一交付非空（误差模型对每一交付给出许可输出），交付之后只经电压表直接判读，不经申报边界之外的代算。Y5：两者的交付都直接接到输入端口，操作不改变交付。Y6：两者每次交付前都按同一协议 ι 取得运行初态（7.1）——积分配置中电容放电到 0 V；W\_C 切换到比例配置后，ι 对电阻不起作用，比较的各次运行仍由同一协议取得初态。τ\_prop ∈ 𝒯（W\_C 一侧的可读条件）。所以两份观测都在 𝒴^adm 之内。

接受与拒绝都对全部许可结果作出，不依赖误差在某一次运行中的具体取值：实现某一函数的宿载，每一个许可输出与这个函数相差不超过 0.006 V，所以全部许可结果族被这个函数的接受协议接受；每一个许可输出与另一函数相差至少 0.15 − 0.006 = 0.144 V \> 0.05 V，所以全部许可结果族被另一函数的接受协议拒绝。这一误差上界就是稳健接受的证书。

由定理二：

　　Read(Y; W\_C) = 1，　Read(Y; W\_N) = 0

证毕。

### 9.3 定理四（区分）

由定理二，对任一共同规范 q，F\_C 的定义域上读出都是 1，F\_N 的定义域上读出都是 0：

　　Out\_C(q) ⊆ {1}，　Out\_N(q) ⊆ {0}

取 9.2 的规范 q₀ =（τ\_int, τ\_prop, Π, Env, ι, D\_test, Acc\_τint, Acc\_τprop），其中 ι 是 7.1 的初始化协议。由定理三，W\_C、W\_N 分别是两侧在 q₀ 下的合格实例，两个读出集合都非空。所以

　　Out\_C(q₀) = {1}，　Out\_N(q₀) = {0}，　Out\_C(q₀) ∩ Out\_N(q₀) = ∅

而且，在同一个规范 q₀ 下，"这个宿载满足 C"和"这个宿载满足 N"预言不相交的读出，做一次重设观测就能在两者之间作出选择。证毕。

### 9.4 反检查：产出确实由从表达式到宿载规则的通路引起

甲　W\_C 只改写记录、不重新运行 Set：m 不变，全部许可结果族仍然满足 Acc\_τint，Read = 0。所以 W\_C 一侧的 1 来自 Set 这条通路，不是装置固有的常量。

乙　给 W\_N 加入"按表达式选取并接入反馈元件"的程序：重设之后，全部许可结果族满足 Acc\_τprop，Read = 1。这时 𝒮 满足 C（对 𝒯），不满足 N——同一种电容经过按表达式的接入，成了被组织起来的运算元件。所以 W\_N 一侧的 0 来自这条通路的缺席。

### 9.5 推论一（同一介质可以属于两边）

同一种介质，可以在一个宿载系统中满足 C，在另一个宿载系统中满足 N；满足哪一个，由宿载系统中有没有从表达式到宿载规则的通路决定。

证明。由 9.4 乙：同一种电容在 W\_N 中满足 N，加入设定程序后满足 C。证毕。

初始规定六（脑仅在行使计算能力时是计算的 P）、第七篇的器件漂移例（同一器件在两种申报下的两种归类，击穿论证反例一）、第八篇 C₂ 的实施申报条件，都与这条推论相符：分界在宿载系统的组织，不在材料。

### 9.6 推论二（实际读出）

对 𝒴^adm 中的任一 Y，若 W3 成立：  
　如果 𝒮 满足 C（τ′ ∈ 𝒯），那么 Read\_obs(Y) = 1；  
　如果 𝒮 满足 N，那么 Read\_obs(Y) = 0。

证明。C 一侧：由定理二，Read(Y) = 1，即操作之后全部许可结果族都满足 Acc\_τ′（C3）。由 W3，实际结果族 μ′ 属于许可结果族集合，所以 Acc\_τ′(μ′) = 1。由 Y2，μ′ 不同时满足 Acc\_τ，所以 Read\_obs(Y) = 1。N 一侧：由定理二，Read(Y) = 0，即操作之后全部许可结果族都满足 Acc\_τ（Y3 与 K0）。由 W3，Acc\_τ(μ′) = 1；由 Y2，Acc\_τ′(μ′) = 0，所以 Read\_obs(Y) = 0。证毕。

所以本篇有两项职责不同的成果：定理二至四在数学上证明两个候选在共同规范下的读出集合不相交；推论二证明，对模型符合实物（W3）的实例，一次实际干预就能正确读出这一区别。推论二不说明一次实际观测能认证一个未知宿载的稳健资格：W3 是前提，不是结论。

在 9.2 的实例中，许可输出与函数值相差不超过 0.006 V，两函数之差至少 0.15 V，容差 0.05 V；只要 W3 成立，实际产出就落在互斥的接受域中的一个里。

## 第十节　不能由本篇推出的结论

10.1 不能由区分推出高下。Read = 1 只说明宿载规则由表达式设定。

10.2 不能由宿载层推出上层。C 只针对宿载规则 k\_P。计算宿载上的动力层、对象层由动力驱动；规则计算发生在生成计算的宿载层，这是《计算分层一般式》的初始规定十六，在该式工作域内（承担 Φ(∅) 的 σ）由其推论一承担；本式不另立前提。

10.3 不能由 N 推出不能承担数学任务。W\_N 承担积分任务，稳健接受判词为 1（定理一（i））。

10.4 不能由"可以用数学描述"推出 C（定理一（v））。

10.5 不能由"有意设置"推出 C（定理一（vi））。

10.6 不能由"连续"推出 N，也不能由"离散"推出 C（定理一（iii））。

10.7 不能由本篇推出"凡是能分开两者的观测，都必须干预表达式记录"。定理一只对 𝒴₀ 成立。

10.8 不能由 Read 推出某一事件上计算是否成立。Read 刻画的是宿载系统中迹应关系的来由，不是《计算一般式》中 Compₙ 在某一事件上的真值；事件层 Dₙ 的实例判据属于判定问题，由《计算判定式》的后续研究承担，组内尚未成立（该式 v1.0 的判词不含 Dₙ）。

10.9 不能由候选归属推出动力层能不能生成，也不能推出动力与对象资格的高下。两类宿载是动力的两种来源（初始规定三、五），沉积场不一定要靠计算才能实现（初始规定二）；动力层与对象层的资格由它们自己的成立条件取得（《计算分层一般式》《计算越层误置消解式》）。

10.10 不能由一次或有限次实际观测推出稳健资格。Read\_obs 与 Read 一致以 W3 为前提（推论二）；有限次读数相同，不说明两个宿载的许可结果集合相同。

## 第十一节　最小性

区分式不证明构成项不可删。这里的最小性是区分观测的最小性：要证 Out\_C(q) ∩ Out\_N(q) = ∅，一个共同规范、一个 τ′、两侧各一个合格实例就够了。不需要穷尽 𝒯，不需要对一切宿载给出判词，也不需要反向构造。

### 12.3 未答

（1）对任意一个宿载给出"计算"或"非计算"的判词。  
（2）混合宿载：一部分迹应关系由表达式设定，一部分不由表达式设定。  
（3）只按表达式选定参数、用同类物质复现某一现象的宿载（例如按方程选定流体黏度的水槽）：对相应的参数族满足 C；它与初始规定七所说用同类物质与环境复现之间是什么关系，没有回答。如果这类复现应当属于非计算，那么 C1 必须要求 𝒯 的成员在算子上不同。定理一至四的见证对在算子上不同，不受这个问题答案的影响。  
（4）W1 与 W3 的核验方法；特别是，对一个未知宿载，怎样由实际观测取得它符合申报模型的证书。  
（5）"凡是能分开两者的观测，都必须干预表达式记录"这句话是真是假。  
（6）非计算宿载上动力层的实例。本篇的定理不以它为前提。  
（7）只能实现一个任务、重设就得重新制造的硬连线器件：可能满足 C 的定义，取决于它的申报系统是否包含 C2 所要求的设定入口；无论是否满足，𝒯 只含一项，本篇的重设观测不覆盖它。  
（8）初始规定所说的计算宿载是否都满足 C、非计算宿载是否都满足 N。本篇只区分 C 与 N 这两个候选，二者能否完整代表初始规定的两类宿载，没有证明。

其中（1）（2）（4）是升为判定所需的研究，由《计算判定式》的后续研究承担，组内尚未成立（1.3、第十四节）。

## 第十三节　击穿方式

击穿定理二：在 𝒴^adm 中有一份观测，𝒮 满足 C、τ′ ∈ 𝒯，而 Read ≠ 1；或者 𝒮 满足 N，而 Read ≠ 0。

击穿定理一：𝒴₀ 中有一项观测，在 W\_C 与 W\_N 上产出不同。

击穿闭合：两个候选的定义用到了"计算型宿载"这个名称、用到了对方，或者用到了动力层、对象层的资格。

击穿观测不预先假定归属：给出一个申报边界完备（W1 成立）的宿载系统，在它上面，操作 I 必须按它的归属来定义才能执行。

击穿推论二：在 𝒴^adm 中有一份观测，W3 成立，𝒮 满足 C 而 Read\_obs ≠ 1，或者满足 N 而 Read\_obs ≠ 0。

## 第十四节　接口

~~~python
# distinguish_ref.py —— 计算与非计算宿载区分式：重设观测的参考实现（模型层定义演示，不是物理实验）
# 误差模型有界：漏电按每步 1e-5 衰减，读出噪声在 ±0.005 V 内均匀取值。
# 计算一侧按表达式记录改换反馈元件（积分 ↔ 比例），任务族在算子上不同；参数族（增益 2 的积分）作对照。
# 另含两项反检查、四项申报检查（含随记录改变交付信号的转换程序）、Y5 交付冻结核对，
# 以及运行初态核对（Y6）：初始化协议 ι 在每次交付开始时把反馈网络中接入的储能元件放电到 v0；
# 积分配置中是电容，比例配置中反馈元件是电阻，没有承担产出的储能状态，ι 对它不起作用，程序不使用 v0。
# 读出分两层：Read_robust 对申报模型的全部许可结果判定（无噪声输出 ± NOISE 的区间），对应正文的理论读出 Read；
# Read_obs 对本次实际运行的产出判定，对应正文的实际读出；W3 核对实际产出是否落在申报的许可结果集合之内。
# 另含随机二值器件的检查（8.8 己）：许可结果集合为 {0, 1}，稳健 Y3 不成立。
import random, json
C0, R0 = 1e-3, 250.0          # 法、欧
T, dt = 1.0, 0.01
EPS = 0.05                    # 接受容差（伏）
NOISE = 0.005                 # 读出噪声界（伏）

def deliveries(rng, n=40):    # D_test：只取 |(1/C0)∫I dt| ≥ 0.2 V 的交付（Y2 所需）
    out = []
    while len(out) < n:
        base = rng.uniform(-1e-3, 1e-3)
        I = [base + rng.uniform(-2e-4, 2e-4) for _ in range(int(T/dt))]
        if abs(sum(I)*dt/C0) >= 0.2: out.append(I)
    return out

TASKS = {   # 表达式记录 → 任务：读法共用"电流入、电压出"
    'int':  lambda I: sum(I)*dt/C0,          # τ_int：V(T) = (1/C0)∫I dt
    'prop': lambda I: R0*I[-1],              # τ_prop：V(T) = R0·I(T)
    'int2': lambda I: 2*sum(I)*dt/C0,        # 参数族对照：增益 2 的积分
}

class Host:
    def __init__(self, name, procs, rng, tx=None):
        self.name, self.procs, self.rng, self.tx = name, procs, rng, tx
        self.records = {'expr': 'int'}       # 边界内的表达式记录
        self.element = ('C', C0)             # 介质配置：反馈元件（裸电容即自身）
        self.v0 = 0.0                        # 运行初态：积分配置中每次交付开始时的电容电压（初始化协议 ι）
    def delivered(self, I):                  # 送到 P 输入端口的实际信号
        return self.tx(self, I) if self.tx else I
    def run(self, I):                        # 一次实际运行：无噪声输出加有界噪声
        return self.det(I) + self.rng.uniform(-NOISE, NOISE)
    def det(self, I):                        # 介质自身的迹应：电容积分或电阻比例（含漏电），不含噪声
        J = self.delivered(I)
        kind, val = self.element
        if kind == 'C':
            v = self.v0                      # ι 取得的运行初态
            for i in J:
                v += i*dt/val; v *= (1 - 1e-5)
        else:
            v = val*J[-1]                    # 比例配置：没有承担产出的储能状态，不用 v0
        return v
    def intervene(self, new_expr, rerun=True):
        for k in self.records: self.records[k] = new_expr   # 改写边界内全部表达式记录
        if rerun:
            for p in self.procs: p(self)                     # 重跑读这些记录的全部申报程序

def set_by_expr(h):            # 设定入口：按表达式记录选择并接入反馈元件
    e = h.records['expr']
    h.element = {'int': ('C', C0), 'prop': ('R', R0), 'int2': ('C', C0/2)}[e]
def heat_only(h):              # 作用于介质、但不按表达式设定迹应关系的程序（加热，产出不变）
    pass
def record_tx(h, I):           # 申报边界之外、随记录改变交付信号的转换程序（8.8 丁）
    if h.records['expr'] == 'prop':
        return [R0*I[-1]*C0/T]*len(I)        # 换成使电容输出等于 R0·I(T) 的恒流
    return I

def random_binary():            # 8.8 己：满足 N 的随机器件，每次运行独立输出 0 或 1
    M = {0, 1}                              # 许可结果集合，操作前后相同；τ 接受 0，τ′ 接受 1
    acc_t, acc_t2 = (lambda y: y == 0), (lambda y: y == 1)
    return {'Y3_robust': all(acc_t(y) for y in M),               # 稳健基线接受是否成立
            'Y3_if_first_run_gives_0': acc_t(0),                  # 只看一次恰好输出 0 的运行
            'sample_read_can_be_1': any(acc_t2(y) for y in M),     # 第二轮实际输出可能被 τ′ 接受
            'Read_robust_after': 1 if all(acc_t2(y) for y in M) else 0 if all(acc_t(y) for y in M) else '⊥'}

def run_all(seed):
    rng = random.Random(seed)
    D = deliveries(rng)
    def acc_robust(task, host):              # 稳健接受：许可结果区间 [det − NOISE, det + NOISE] 全部在容差内
        return all(abs(host.det(I) - TASKS[task](I)) + NOISE <= EPS for I in D)
    def rej_robust(task, host):              # 稳健拒绝：许可结果区间全部在容差外
        return all(abs(host.det(I) - TASKS[task](I)) - NOISE > EPS for I in D)
    def O(host, t, t2, rerun=True, v0_after=None):
        before = [host.delivered(I) for I in D]
        s0_before = host.v0
        if not acc_robust(t, host): return {'Read': 'not-admissible'}
        host.intervene(t2, rerun)
        if v0_after is not None: host.v0 = v0_after                  # 违反 Y6 的对照：第二轮从另一初态开始
        y5 = all(host.delivered(I) == b for I, b in zip(D, before))   # Y5：交付到 P 输入端口的信号不变
        y6 = host.v0 == s0_before                                     # Y6：运行初态由同一初始化协议取得
        ys = [host.run(I) for I in D]                                 # 实际运行：每次交付一次
        w3 = all(abs(y - host.det(I)) <= NOISE for y, I in zip(ys, D))  # W3：实际产出在许可结果集合之内
        a = all(abs(y - TASKS[t](I)) <= EPS for y, I in zip(ys, D))
        b = all(abs(y - TASKS[t2](I)) <= EPS for y, I in zip(ys, D))
        ra, rb = acc_robust(t, host), acc_robust(t2, host)
        return {'Read_robust': 1 if rb else 0 if ra else '⊥',
                'Read_obs': 1 if (b and not a) else 0 if (a and not b) else '⊥',
                'W3': w3,
                'robust_reject_other': rej_robust(t, host) if rb else rej_robust(t2, host) if ra else None,
                'Y5': y5, 'Y6': y6}
    WC = lambda: Host('运放反馈网络', [set_by_expr], rng)
    WN = lambda: Host('裸电容', [], rng)
    res = {}
    res['Y2_min_gap'] = {k: round(min(abs(TASKS['int'](I)-TASKS[k](I)) for I in D), 4) for k in ('prop','int2')}
    res['Y2_holds'] = {k: v > 2*EPS for k, v in res['Y2_min_gap'].items()}
    res['max_leak_error'] = round(max(abs(sum(I)*dt/C0) * (1 - (1-1e-5)**len(I)) for I in D), 6)
    res['Y0_Acc_int'] = {'W_C': acc_robust('int', WC()), 'W_N': acc_robust('int', WN())}
    res['O_WC_int_to_prop'] = O(WC(), 'int', 'prop')
    res['O_WN_int_to_prop'] = O(WN(), 'int', 'prop')
    res['O_WC_int_to_int2'] = O(WC(), 'int', 'int2')
    res['O_WN_int_to_int2'] = O(WN(), 'int', 'int2')
    res['check_A_WC_no_rerun'] = O(WC(), 'int', 'prop', rerun=False)
    h = WN(); h.procs = [set_by_expr]; res['check_B_WN_plus_set'] = O(h, 'int', 'prop')
    h = WN(); h.procs = [heat_only]; res['adv1_N_with_nonsetting_proc'] = O(h, 'int', 'prop')
    h = WC(); h.procs = []; res['adv2_C_with_undeclared_set'] = O(h, 'int', 'prop')
    h = Host('裸电容加交付转换', [], rng, tx=record_tx); res['adv3_N_with_record_dependent_delivery'] = O(h, 'int', 'prop')
    res['adv4_N_with_different_initial_charge'] = O(WN(), 'int', 'prop', v0_after=0.3)
    res['adv5_N_random_binary'] = random_binary()
    return res

main = run_all(7)
keys = ['O_WC_int_to_prop', 'O_WN_int_to_prop', 'check_A_WC_no_rerun', 'check_B_WN_plus_set',
        'adv1_N_with_nonsetting_proc', 'adv2_C_with_undeclared_set', 'adv3_N_with_record_dependent_delivery',
        'adv4_N_with_different_initial_charge', 'adv5_N_random_binary']
other = [run_all(s) for s in range(1, 21)]
main['seeds_1_to_20_same_reads'] = all(all(r[k] == main[k] for k in keys) for r in other)
print(json.dumps(main, ensure_ascii=False, indent=1))
~~~
