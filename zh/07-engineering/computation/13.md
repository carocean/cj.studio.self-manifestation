自显论·工篇·计算组式第十三 v1.0

# 生成计算干预区分式

## 第一节　唯一任务与式种

### 1.1 唯一任务

一段计算中，历史条件在运行段之内由执行驱动形成并被后继读入，与历史条件在段内不随实际经过而变——这两种段内动力职责，能不能由一项合法的交付干预分开？这项干预能分开什么，分不开什么？

要证明的不是两种职责的定义写法不同，而是：

存在共同观测规范 q，使满足段内形成的合格系统接入它读出 1，满足段内不形成的合格系统接入它读出 0：

　　Out\_G(q) ∩ Out\_R(q) = ∅

同时给出这项区分观测的分辨边界：交付干预的读出只由续行核读到的自变量决定，因此它不能普遍判定《生成计算一般式》七项资格的整体；对其中五个结构分项，本篇分别构造逐步同效、读出相同、而该项一成立一不成立的系统对。分辨边界属于区分观测的适用范围（1.3），不是与上式并列的第二项主任务。

### 1.2 区分什么，为什么要区分

初始规定说，在动力变换中历史成为动力（初始规定一）；生成计算把规则写在宿载里，宿载按这些规则能够自动生成动力层，宿载给出一个初始的沉积场网络，此后由信号流在历史中不断改变它（初始规定二）。《生成计算必然式》在工作域 𝒲₇ 内、条件组 C₁、C₂、C₄、C₈ 与运行级条件 C\_run(σ) 下证明：凡运行段实际包含见证构型 Γ(σ)——其中有分支位上的一次经过、其后的实际复入、所留之迹留存到读入且读入集未受别的改动——历史在这段运行之内不能不成为后续变换的条件（定理一乙）；在确定续行的规则类 𝔗\_det 与 Fgt\*、RT₁(o)、NL(x)、C\_pre 下，存在只在前 n 次外生经历上不同的两段合法历史，在复入处改路（定理六）。两项都携计算执行一般式-H3。

这是生成一侧的结论。它没有回答：从外面看，怎样知道一个系统的后继确实由段内形成的历史条件承担，而不是由预先给定的表、时间表或冻结的初值承担？两类系统在平常的交付下可以给出完全相同的输出。

《生成计算一般式》已经给出两条限制。推论一（来源无关）：在同一合格场规格之下，动力条件的段首取值由实际续行形成、由别的实例移入、由手工写入或由初始化给定，不改变 Sed 的真值。所以要区分的不是历史从哪里来。推论二：存在逐步续行相同、而七项中某一项一成立一不成立的过程对，这样的项是 Hold、¬Intr、Carry、Sed 与 Multi。所以只看输出，不能判定七项中的这五项。

本篇在这两条限制之内工作：区分的对象是段内的动力职责——历史条件是否在运行段之内由执行驱动更新、并被后继读入（《计算分层一般式》的 W 与 Rd，《生成计算必然式》定理一乙的段内生成结论）；同时给出这项区分的分辨边界。

### 1.3 式种

区分式，附式，独立成篇（《法篇》第一 v2.2 第四编第十二章）。区分式的用途是证明存在一个观测，能把两个候选结构分开；进入条件是两个候选的定义已经分别闭合、两个候选的前向映射都已经给出（本篇的前向映射在共同观测规范之下写出，两侧的读出集合由它给出，见 7.6）；标准写法是候选对申报、区分观测构造、区分有效性证明、区分定理、接口；完成条件是区分观测已经明确写出，有效性证明已经完成。本篇另在第十节给出这项观测的分辨边界，它是区分观测适用范围的组成部分。分辨边界不独立承担完成条件：本篇的完成条件仍是区分观测已经写出、有效性证明已经完成；第十节的定理四、定理五与推论二是陈述这一边界的边界定理，作用与判定式的误判界、不可区分式的观测集扩张的界相类，它们的击穿属于边界陈述的击穿（第十三节）。定理四对 𝒴^adm 中的全体观测成立；定理五与推论二的观测集是本篇的交付干预族，即 𝒴^adm 中以本篇冻结的交付协议与前缀族 𝓗\_n(x) 为前缀族的规范，在这一族上对全体规范成立；三者陈述这项区分观测适用范围的界，不独立承担完成条件。交付干预族之外的观测、一般观测集上的不可区分结论与观测集扩张的界，属原规划的《效果层不可区分式》，组内尚未成立（第十四节）。

区分式只回答有没有一个观测能把两者分开；对任意一个系统判定它是否为生成计算，是判定式的任务。

### 1.4 结果

下面是本篇结果的缩写，正式陈述与证明见第九、十节。

引理一（桥接）：确定续行下，续行核的全部自变量在两段历史上相同，测试处的去向就相同；段内不形成的系统，两段只在所经之边上不同的前缀历史给出相同的自变量。

定理一至三：在 𝒲₇ 内，以"n 次经由第一条出边"与"n 次经由第二条出边"两段合法外生前缀为干预，比较其后同一次测试交付的去向。段内不形成的系统，对一切 n 读出 0；段内形成的系统，在《生成计算必然式》定理六的前提下（引用定理六，携计算执行一般式-H3，12.1），存在可在观测之前由申报算出的 n 使它读出 1。在三结构位实例上，改路的 n 恰为 n ≥ 4；在该规范下 Out\_G = {1}，Out\_R = {0}，二者不相交。

定理四：读出为 1 推出两段历史上续行核的自变量不同；反过来不成立。读出为 0 时，自变量可能没有改变，也可能已经改变而尚未改路。

定理五：在以最小沉积场构造的场算子实现的实例上，对沉积资格的第（一）、（三）款、无侵入、自持与同一运行五项，各有一对系统，在本篇冻结的交付协议与前缀族上、相同段首状态与外生控制及同一确定续行规则下，逐步读入相同、读出相同，而该项一成立一不成立。各项按《生成计算一般式》执行界出的步划分（一次脉冲为一步）与所申报的运行判定，携 12.1 所列条件；同一运行一项另携计算执行一般式-H1、H2。

一句话：在候选 G、R 与工作域（𝒲₇、Z1—Z4、W1′）之内，把前缀中 n 次合法外生经历换到另一条出边（n 由申报算出），看测试处改不改路：改路的属段内形成并被读入，不改路的属段内不形成（G 一侧携计算执行一般式-H3，12.1）；读出 0 不说明续行自变量没有改变。在本篇冻结的交付协议与前缀族上，这项读出看不出更新由谁算、存在哪里、是否在同一次运行中、载体有没有场资格（各项判定携 12.1 所列条件）。

### 2.2 初始规定

本式以下列关于计算的规定为前提：它们是本式采用的初始规定，不在本式中证明，也不因被援引而成为已证定理。引用时标出序号：

　初始规定一：在动力变换中，历史成为动力；在历史之外对动力施加外力干预，是另一种情形，即侵入。  
　初始规定二：生成计算把规则写在宿载里，宿载按这些规则能够自动生成动力层；动力类型包括反蚀与改路、退浅等。宿载规则只需判断信号流经某处沉积结构（如某条沟线与端壑）在时间窗口内的计数：计数变大则易通过，变小则不易通过；宿载给出一个初始的沉积场网络，此后由信号流在历史中不断改变它。  
　初始规定三：不经由信号流、在历史之外直接改渠或改写权重，是侵入。  
　初始规定四：在计算宿载中，动力在信号流经过、通过规则真正进行计算变换时发生；宿载规则就是信号与宿载介质的迹应关系，动力条件是每一次迹应发生、产生变换时的当前条件。  
　初始规定五：生成计算包含规则计算；规则计算发生在生成计算的宿载层。

### 2.3 从初始规定读出的两件事

第一，生成发生在信号流经过的过程中。初始规定四说动力条件是每一次迹应发生、产生变换时的当前条件，初始规定二说信号流在历史中不断改变场。所以要看的是运行段之内：信号经过时迹被更新，后来的续行读到更新后的迹。

第二，干预必须经由信号流。初始规定三把不经由信号流、在历史之外直接改渠或改写权重定为侵入。所以区分用的干预只能改变交付，不能直接写场态。

### 2.4 工作域

单宿载；介质为有限简单有向图；信号以脉冲方式进入；结论在申报模型内陈述（《生成计算必然式》𝒲₇）。连续向量介质、多宿载、无外生经历的自主续行、对象层（律、理、概率、意向）的形成，以及对任意一个系统判定它是否为生成计算，都在工作域之外。

## 第三节　记号与共同前件

### 3.1 宿载系统

　　𝒮 =（P, 𝔾, τ\_Φ, D₀, ι, c, Prot, 𝓡）

P：宿载及其申报边界。𝔾 =（Ξ, E）：介质，有限简单有向图。τ\_Φ：一步任务，一次脉冲是它的一次执行。D：场态，含各边的边迹 m\_e 与各位的位迹 n\_v，读数取非负有理数，零迹记 o。D₀：申报的段首场态。ι：初始化协议，把 D 置为 D₀、把脉冲序号置零。本篇说同一系统"运行两次"（7.3、Z1、Z2），指两遍观测过程，每一遍由 ι 开始；一遍之中通常只有一次运行，接力系统的一遍含两次运行（10.3）。c =（SED, Mask, Avail）：外生控制构型——沉积开关、读取掩码、可用性。Prot：交付与场协议。交付协议在每一次交付到达时发出一次脉冲的启动，同时经入口给定当前位；它在 P 的任何一次运行中都这样工作，不以该运行是否经 ι 开始为条件。场协议可以在两次脉冲之间的接续处排定许可的协议操作 IdleStep——只退浅，作用于 D，不是一步变换；是否排定随实施申报，本篇只在定理五第三对的两个系统中排定。排定了接续处操作时，申报的交付时序使每一次交付在接续处操作完成之后到达；交付协议在到达时发出启动。Prot 中开始一次运行的协议只有 ι，没有恢复、迁移或接力一类使运行续行的协议。𝓡：读入申报——续行核在每一位读取哪些量，这些量在段内按什么方程更新，由谁求值，保存在何处。

分支位 x 为源入口，A(x) = (e₁, e₂) 为其两条可用出边及申报次序，e\_i = (x, y\_i)。

### 3.2 续行核的全部自变量

在 x 处一次续行，续行核读取：读入载体 B(x) 的取值（得分所读的量）、当前非场状态（当前位）、外生控制中的 Mask 与 Avail、本次交付 u、A(x) 及其申报次序。这些合起来记为 Arg。沉积开关 SED 只决定场是否更新，不进入续行核，不在 Arg 之内。

### 3.3 确定续行

续行取得分最大的可用出边，同分时按 A(x) 的申报次序取首位（《生成计算必然式》TR5′）。确定续行下，x 处的去向是 Arg 的函数。

### 3.4 共同前件 K0

τ\_Φ 在一次脉冲中的场更新与续行，只由 D、c、交付与 τ\_Φ 的申报给出；接续处排定的协议操作只由 Prot 的申报给出；ι 在每一遍观测开始时执行，不在运行段之内写 D。

依据：初始规定四（宿载规则即信号与介质的迹应关系）；《生成计算必然式》3.3 的一次脉冲次序（先退浅，再续行，再沉积）；《生成计算必然式》C₃ 许可预装、移入、写入初值作为段首场态。K0 对两个候选同样成立。

## 第四节　候选一：段内形成

### 4.1 定义

　　G(𝒮; σ) ≔ G1 ∧ G2 ∧ G3

G1（规则类）τ\_Φ ∈ 𝔗\_det；退浅 Idle 与经过 Pass 由 P 执行（《生成计算必然式》C₂）。  
G2（读入载体即沉积载体）B(x) 是 D 中 A(x) 的边迹与末端位迹；续行核每次在 x 续行时读取它们的当前值。  
G3（段内开启）σ 中 SED = 1；B(x) 在 σ 内只经各次脉冲之内的 Idle、Pass 改变，接续处没有作用于 B(x) 的协议操作（强于《生成计算必然式》C₇(σ)）。

### 4.2 读法

信号经过时，被经过的边与其两端的迹按 Pass 加深，其余的迹按 Idle 变浅；下一次在 x 续行时，续行核读到的就是这些更新后的迹。这正是《计算分层一般式》的 W（段内由执行驱动的沉积更新）与 Rd（所沉积者被后续执行读入）在 x 处的实现。G 不要求历史从本实例形成：G 的定义不涉及 D₀ 的来源，D₀ 可以是新场、预装、移入或写入的初值（《生成计算必然式》C₃ 许可预装、移入与写入初值；《生成计算一般式》推论一在同一合格场规格之下给出同向的结论：段首取值的来源不改变 Sed 的真值）。G 也不要求七项中的其余各项：步间外部保管、接力的系统仍可满足 G（定理五）。

## 第五节　候选二：段内不形成

### 5.1 定义

　　R(𝒮; σ) ≔ R1 ∧ R2

R1（确定续行）x 处的续行是 Arg 的确定函数。  
R2（自变量不随所经）Arg 的每一项在 σ 内的取值序列，其更新方程不以 σ 中实际所经之边（包括外生经历所给之边）为自变量；可以依赖 D₀、ι、外生控制的申报演化、脉冲序号与交付时序。这里的"自变量"按依赖闭包理解：若 Arg 的某一项依赖某一中间量，该中间量的更新方程也不得以实际所经之边为自变量，依此直到申报的全部量。

### 5.2 实例

以下各例都由申报判定，不依赖任何运行：  
　冻结运行：SED = 0，D 在段内恒为 D₀，续行核读 D；  
　影子副本：SED = 1，续行核读段首值，Idle、Pass 写到另一载体；  
　时间表：续行核读取按脉冲序号给定的量；  
　路径表：续行核读取按脉冲序号编址的表项作为读入值，得分与求解器照共同规范；  
　读入归零：续行核读入的 B(x) 在申报中恒取零迹值，得分与求解器照共同规范（屏蔽由读入申报实施，不经 Mask）；  
　规则常量：D 的值写在 τ\_Φ 的规则配置之中，SED = 0。

### 5.3 读法

R 不是"非生成计算"。冻结运行在 R 中，而它与《生成计算一般式》的标准正例 GS2（训练后在同一系统中以冻结模式推理）同型，不被该式的总式排除。R 刻画的只是：运行段之内的实际经过不进入 x 处后来的读入。

## 第六节　两个候选各自闭合

### 6.1 各自读什么

G 读 τ\_Φ 的规则类、B(x) 的载体申报与 σ 内的协议操作。R 读续行是否确定、Arg 各项更新方程的自变量表及其依赖闭包。都可在申报上逐项核对。

### 6.2 各自有确定的真值

在申报已经冻结的 𝒮 上，G 的三款、R 的两款都有确定的真值。

### 6.3 各自不用到的东西

两个候选都不用到对方，不用到"生成计算"的判词，不用到七项中任何一项的判词，也不用到任何交付干预的读出。

### 6.4 所以候选闭合

由 6.1 至 6.3，两个候选的定义已经分别闭合。

### 6.5 定义上互斥，不等于可以观测地分开

G3 要求 B(x) 在 σ 内随 Pass 改变，而 Pass 作用于实际所经之边；R2 排除以实际所经为自变量的更新。二者在定义上互斥。两者能不能由观测分开，需要另外证明。

### 6.6 不完全覆盖

B(x) 随所经而变、但规则不属 𝔗\_det 的系统（例如经过即覆写、按误差更新），以及经过与时间表混合更新的系统，在两个候选之外，本篇的定理对它们不作断言。接续处另有作用于 B(x) 的协议操作的系统（如定理五第三对的两个系统）也在两个候选之外。

## 第七节　交付干预观测

### 7.1 前缀族与测试交付

𝓗\_n(x)：n 次向 x 的外生经历组成的前缀，时序相同。取

　　h⁰ = n 次 (x, p, e₁)，　h¹ = n 次 (x, p, e₂)，　u\_test = (x, p)

外生经历是由交付给出该跳之边的合法交付（《生成计算必然式》C₅）；干预就是把前缀 h⁰ 换成 h¹。

### 7.2 共同观测规范

　　q =（𝔾, A(x) 的申报次序, x, D₀, ι, Mask, Avail, Idle, Pass, S, 续行求解器, n, h⁰, h¹, u\_test, 读出规定）

q 冻结介质、场更新规则 Idle 与 Pass、得分函数与求解器、前缀、测试交付、读法、可比初态与外生控制中的 Mask、Avail。q 不含宿载自身的实施申报：沉积开关 SED、读入申报 𝓡（续行核实际读取哪些量）、求值者与保存位置、运行身份、D 的值所在载体的类别。其中 SED 由各候选申报：G 含 SED = 1，冻结运行与规则常量含 SED = 0，其余 R 的实例含 SED = 1。把一个宿载系统接入 q，得到一份观测包 Y =（𝒮, q）。

### 7.3 操作与读出

同一系统运行两次，各自先由 ι 置回 D₀，一次走 h⁰ + u\_test，一次走 h¹ + u\_test。记 Route\_𝒮(h) 为 u\_test 处 x 的实际出边，

　　Read(Y) = 1　　如果 Route\_𝒮(h⁰) ≠ Route\_𝒮(h¹)  
　　Read(Y) = 0　　如果 Route\_𝒮(h⁰) = Route\_𝒮(h¹)

确定续行下没有随机性，申报模型给出的理论读出与实际运行给出的读出相同。对现实宿载，两者一致以实物符合申报模型为前提（7.5 的 W3′）。

### 7.4 有效工作域 𝒴^adm

Z1　同一系统的两次运行，τ\_Φ、𝔾、c（含该系统申报的 SED）、Prot 相同；Mask、Avail 取 q 所给之值，在 A(x) 上保持两条出边都可读、可用。  
Z2　两次运行都由同一冻结的 ι 从同一 D₀ 开始。ι 作用在运行段之前，不在段内写 D。  
Z3　h⁰、h¹ 属申报的合法交付族；干预只替换交付，不在交付之外写 D（初始规定三）。  
Z4　u\_test 相同。  
W1′（申报完备）Arg 各项的载体、更新方程、求值者与保存位置全部在申报之内。

### 7.5 连接条件

W3′（模型符合实物）对现实宿载，每次实际运行的去向与申报模型给出的去向相同。W3′ 只用于把本篇的读出用在现实宿载上，不是定理一至五的条件；它与《计算判定式》中申报模型与现实宿载是否相符同属判定域条件，不能由有限次运行证明。

### 7.6 前向映射与读出集合

　　F\_G：定义在 {Y ∈ 𝒴^adm：𝒮 满足 G} 上，取值 Read(Y)。  
　　F\_R：定义在 {Y ∈ 𝒴^adm：𝒮 满足 R} 上，取值 Read(Y)。

固定 q，两个候选的读出集合是

　　Out\_G(q) = { F\_G(𝒮, q)：(𝒮, q) 在 F\_G 的定义域中 }  
　　Out\_R(q) = { F\_R(𝒮, q)：(𝒮, q) 在 F\_R 的定义域中 }

G 与 R 互斥，同一个 𝒮 不能同时属于两者。比较的是同一冻结规范 q 下两侧的读出集合；读出集合是否非空，不从写法假定，由合格实例给出（9.3、9.4）。

### 7.7 观测可以执行

需要做的只是：按 ι 置初值，按前缀交付，交付一次测试，记下 x 处的去向。这些在申报的实现环境中都能做，不读任何观测不到的量，也不读候选的名称。

### 7.8 观测不预先假定归属

操作对一切系统用同一个定义：同样的前缀、同样的测试交付、同样的读出。定义里没有按候选而分的情形。归属只出现在定理一的证明里。

### 7.9 几种情形

　甲　两次运行的 D₀ 不同：冻结运行也会读出 1。违反 Z2，不在 𝒴^adm 之内。  
　乙　在两次运行之间改变 Mask 或 Avail：R 也会读出 1。违反 Z1。  
　丙　不经交付、直接把迹写入 D：违反 Z3（初始规定三的侵入）。  
　丁　续行核另读一个记下外生经历所经之边的寄存器：R2 不成立，不在 R 之内。  
　戊　漏报读入载体：可能被误归 G 或 R。违反 W1′。  
　己　规则带随机续行而两次运行独立抽样：即使冻结运行，两次去向也可能不同。以上读出以确定续行为前提；随机续行下的读出列为未答，须在共用随机源或核层读出下另行陈述（12.3（4））。

## 第八节　桥接引理

### 8.1 引理一（桥接）

设确定续行，Y ∈ 𝒴^adm。  
（1）若 Arg 在 h⁰、h¹ 后的 u\_test 处相同，则 Route\_𝒮(h⁰) = Route\_𝒮(h¹)。  
（2）若 𝒮 满足 R，则 Arg 在 h⁰、h¹ 后的 u\_test 处相同，从而 Read(Y) = 0。  
（3）若 𝒮 满足 G，且《生成计算必然式》定理六的前提在 𝒮 的申报上成立，则集合 N\_sw(𝒮) ≔ {n：Route\_𝒮(h⁰) ≠ Route\_𝒮(h¹)} 非空。  
（4）若一对 G、R 另满足基线同效 Route\_G(h⁰) = Route\_R(h⁰)，则对 n ∈ N\_sw(G)：

　　Route\_G(h¹) ≠ Route\_G(h⁰) = Route\_R(h⁰) = Route\_R(h¹)

证明。  
（1）确定续行下，得分由 B(x) 的读入值与 Mask 给出，可用出边由 Avail 与 A(x) 给出，同分次序由 A(x) 的申报次序给出，在哪一位续行由当前位与交付给出。全部自变量相同，去向相同。  
（2）h⁰、h¹ 时序相同、脉冲序号相同，只在外生经历所给之边上不同。由 R2，Arg 的每一项及其依赖闭包中的每一中间量，更新方程都不以所经之边为自变量；由 Z1、Z2、Z4，二者自同一 D₀、同一外生控制、同一交付时序与同一 u\_test 演化。故 Arg 相同；由（1），Read(Y) = 0。  
（3）h⁰、h¹ 正是《生成计算必然式》定理六的两段合法历史："向 x 交付 n 次外生经历 (x, p, (x, y₁))，再向 x 交付 (x, p)"与"以 (x, p, (x, y₂)) 代替前 n 次"。定理六断言存在 n 使最后一次交付处 x 的实际出边不同。  
（4）由（3），Route\_G(h¹) ≠ Route\_G(h⁰)；由基线同效，Route\_G(h⁰) = Route\_R(h⁰)；由（2），Route\_R(h⁰) = Route\_R(h¹)。证毕。

### 8.2 两种区分

Read 是同一系统两次运行的自比较，定理一至三只用它。（4）是一对系统在同一干预历史 h¹ 上去向不同，须另加基线同效；它说明"平常同效、干预后分离"的情形确实存在（9.5）。两种区分各自陈述，不互相代替。

### 8.3 n 的取定

（3）只断言 N\_sw(𝒮) 非空。要在观测之前取定 q 的 n，用下面的程序：输入为 𝒮 的全部申报（介质与次序、Idle、Pass、得分函数与同分规则、D₀、ι、c、前缀族、u\_test、读出规定），不含任何观测结果；对 n = 1, 2, … 在申报模型上分别算 h⁰ + u\_test 与 h¹ + u\_test 的去向，取首个不同者为 n\*。定理六的前提逐项从申报读出（TR1—TR4、TR5′ 读规则规格，Fgt\* 读 Idle 的形式，RT₁(o) 在零迹上计算，NL(x) 读介质，C\_pre 读申报与许可）；前提成立时 N\_sw 非空，程序在有限步内停止。先对申报取摘要，再算 n\*，二者一并记录，然后才进行观测运行：n 由申报决定，不是看了读出再选。q 的 n 只须属于 N\_sw(𝒮)，不要求 N\_sw 对 n 单调。

## 第九节　区分有效性

### 9.1 定理一（有效性）

对 𝒴^adm 中的观测：  
（一）若 𝒮 满足 R，则对一切 n，Read(𝒮, q) = 0；  
（二）若 𝒮 满足 G，且《生成计算必然式》定理六的前提在 𝒮 的申报上成立，则存在 n ∈ N\_sw(𝒮)，可在观测之前由申报算出，使 Read(𝒮, q\_n) = 1。

证明。（一）即引理一（2）。（二）由引理一（3）与 8.3。证毕。

### 9.2 量词的读法

（一）对一切 q、一切 R 成立。（二）对每一个合格的 G，存在使它读出 1 的规范；不断言同一个 q 对一切 G 都使其读出 1——那需要只依赖申报参数的统一界（12.3（3））。所以定理一给出的是：对每一个合格的 G，存在规范 q，使 G 读 1，而每一个接入同一 q 的 R 都读 0。

### 9.3 定理二（实例一：三结构位介质）

申报：Ξ = {x, y₁, y₂}，e₁ = (x, y₁)，e₂ = (x, y₂)，A(x) 次序 (e₁, e₂)，x 为源入口，y₁、y₂ 无出边。D 含边迹 m\_{e₁}、m\_{e₂} 与位迹 n\_x、n\_{y₁}、n\_{y₂}。一次脉冲：SED = 1 时先对五个迹各作一次 Idle，再在 x 续行一跳（外生经历取所给之边），SED = 1 时对所经边的边迹及其起点、终点位迹各作一次 Pass。Idle(v) = max(v − 1/100, 0)，Pass(v) = min(v + 1/4, 10)，边迹与位迹用同一对函数，状态域为 \[0, 10\]。得分 S(m\_e, n\_{head(e)}) = m\_e，s\_e = Mask\_e·S；确定续行，同分取 e₁。D₀：(m\_{e₁}, m\_{e₂}) = (1, 0)，(n\_x, n\_{y₁}, n\_{y₂}) = (0, 0, 0)；Mask、Avail 全为 1。

定理六的前提逐项成立：  
TR1：开启沉积时 D 的改变只有每一迹一次 Idle 与每次实际经过 e 对 m\_e、n\_x、n\_{head(e)} 各一次 Pass；关闭时 D 不变——由脉冲申报。  
TR2：Idle、Pass 都单调不减；读数即值，读数支配序即值的大小序，故二者保持支配序；Pass(v) ≥ v；o = 0 是最小元，Idle(0) = 0；v \< 10 时 Pass(v) \> v。  
TR3：Idle(v) ≤ v。  
TR4：Idle、Pass、S 对一切边、位是同一函数，不以名字为自变量；续行确定。  
TR5′：S 关于 m 严格增，关于 n 不减（不读）；取最大，同分按申报次序。  
Fgt\*：Idle 在有限步内把任一读数降到 0，S(0, ·) 是极限。  
RT₁(o)：Idle(Pass(Idle(0))) = 1/4 − 1/100 = 6/25 \> 0。  
NL(x)：y₁、y₂ ≠ x；图是简单的。  
C\_pre：P 承担 τ\_Φ 由申报模型给出（C₁）；Idle、Pass 由 P 执行（C₂）；D₀ 是预装的合法段首场态（C₃）；x 有两条读开出边（C₄）；外生经历与交付在同一运行中联合许可（C₅）；C₆ 由 RT₁(o) 代；SED = 1、无别的协议操作、无边界外代算（C₇）；比较投影先于运行申报（C₈）。G 的沉积由 P 自身实现，不属部署耦合一类。

定理二　对上述系统 𝒮₁（满足 G），N\_sw(𝒮₁) = {n ≥ 4}。

证明。得分不读位迹，只需看边迹。h¹ 下，e₁ 从不被经过，到 u\_test 读入时已作 n + 1 次 Idle：m\_{e₁} = 1 − (n + 1)/100（n ≤ 99）。e₂ 每次脉冲先作 Idle 再作 Pass，未到上限时每次净增 1/4 − 1/100 = 6/25（第一次自 0 起为 1/4），到 u\_test 读入时再作一次 Idle：m\_{e₂} = 6n/25（n ≤ 41）。u\_test 取 e₂ 当且仅当 6n/25 \> 1 − (n + 1)/100，即 25n \> 99，即 n ≥ 4。n ≥ 42 时 m\_{e₂} 不小于 n = 41 时的值 246/25 \> 9，而 m\_{e₁} ≤ 1，仍取 e₂。h⁰ 下 e₂ 从不被经过，m\_{e₂} = 0 ≤ m\_{e₁}，取 e₁。故 n ≥ 4 时两段历史去向不同，n = 1、2、3 时相同。证毕。

由 8.3 的程序得 n\* = 4。

### 9.4 定理三（区分）

取 q₀ 为 9.3 的规范，n = 4。由定理二，𝒮₁ 读出 1。下面六个系统与 𝒮₁ 共享 q₀，各自满足 R：冻结运行（SED = 0）、影子副本、时间表（续行核读段首值按脉冲序号退浅所得之量）、路径表（表项使 e₁ 得分最高）、读入归零、规则常量（SED = 0）。由定理一（一），它们都读出 0。所以

　　Out\_G(q₀) = {1}，　Out\_R(q₀) = {0}，　Out\_G(q₀) ∩ Out\_R(q₀) = ∅

q₀ 冻结了介质、D₀、Idle、Pass、S 与续行求解器，满足 G 的系统接入 q₀ 时，G2、G3 规定它读场、开启沉积，其读出由定理二确定为 1，故 Out\_G(q₀) = {1}；满足 R 的系统由定理一（一）读出 0，故 Out\_R(q₀) = {0}。两个读出集合都由已构造并核对的实例取得非空；这一结论只对 q₀ 断言，不推及每一个规范。证毕。

### 9.5 推论一（平常同效，干预后分离）

在 q₀ 下，h⁰ 上 𝒮₁ 与上述六个 R 实例逐跳轨迹相同，u\_test 处都取 e₁；h¹ 上 𝒮₁ 取 e₂，六个 R 实例取 e₁。

证明。h⁰ 下各系统前缀各跳由外生经历给定，相同；u\_test 处 𝒮₁ 的 m\_{e₁} ≥ m\_{e₂} = 0，取 e₁；各 R 实例的读入在 h⁰、h¹ 后相同（引理一（2）），且都给出 e₁（冻结、影子、时间表、路径表读到的 e₁ 得分不小于 e₂，读入归零时同分取 e₁）。由引理一（4）。证毕。

### 9.6 反检查：读出 1 来自段内的更新与读入

甲　𝒮₁ 关闭沉积（SED = 0）：成为冻结运行，读出 0。读出 1 来自段内的 Pass，不是介质固有的偏向。  
乙　𝒮₁ 保留沉积、但续行核改读段首值（影子副本）：读出 0。读出 1 来自 Rd——更新后的迹被读入，不只是迹被更新。

## 第十节　分辨边界

### 10.1 定理四（读出只依赖自变量）

对 𝒴^adm 中的观测，Read(Y) 只由续行规则与 Arg 在 h⁰、h¹ 后 u\_test 处的两份取值决定：两个系统在这两处的 Arg 分别相同，读出就相同。由此，Read = 1 推出两段历史上的 Arg 不同；反过来不成立。

证明。前一句由引理一（1）对两个系统分别适用。Read = 1 时两处去向不同，由引理一（1）的逆否，Arg 不同。反向不成立的实例：定理二的 𝒮₁ 在 n = 1、2、3 时，h¹ 后 m\_{e₂} = 6n/25 \> 0 = h⁰ 后的 m\_{e₂}，Arg 不同，而两处都取 e₁，Read = 0。证毕。

所以：读出 1 见证续行自变量的差异已经形成可观察的改路；读出 0 既可能是自变量没有改变，也可能是已经改变而尚未改路，读出 0 不判定自变量是否改变。

### 10.2 实例二：最小沉积场的场算子

申报：Ξ = {A, B, C, D}，E = {(A, C), (A, D), (B, C), (B, D)}，x = A，A(x) 次序 ((A, C), (A, D))。场算子取律组式第四《最小沉积场构造式》v1.2 的 Canonical F\*：退浅 Decay 对 d、g 各减 0.0015 并截底于 0；一次经过 (i, j) 使 d\_i、d\_j 各加 0.015，g\_{ij} 加 0.030·(1 − g\_{ij}/1.20)；续行得分 κ = 0.10 + 0.55·g\_{xj} + 0.05·d\_j。续行求解器取得分最大者，同分取申报次序首位（《最小沉积场构造式》第二十节把 softmax 与温度列为实现项）。D₀ 全为 0。

在此实例上，h¹ 一次经过 (A, D) 后，u\_test 处 κ\_{AD} = 0.10 + 0.55·(0.030 − 0.0015) + 0.05·(0.015 − 0.0015) \> 0.10 = κ\_{AC}，h⁰ 下 κ\_{AC} ≥ κ\_{AD}，故开启运行 N\_sw = {n ≥ 1}。

实例二中 x 的两条出边都止于没有出边的位，一次脉冲恰含一跳。前缀 n 次与测试一次，共 n + 1 次脉冲，即 τ\_Φ 的 n + 1 次执行；σ 共 n + 1 步。

实例二的场协议 Prot\_F 是 Canonical F\* 的两种模式（外生经历与内生续行），另加《生成计算一般式》所列上游许可协议中的 IdleStep（《律运行基底构造式》v1.2）：它只作一次 Decay，不产生脉冲。IdleStep 只用 F\* 已有的 Decay 算子，10.3 对 C1—C7 的逐项证明不受影响。

### 10.3 七项中五项的模型层判定

（甲）组成

实例二的各系统由彼此独立的组成构造。宿载 P 及其场态载体（场的持久场态）、当前位寄存器、影子载体、规则配置载体（构造后只读，不参与任何更新），以及 P 的交付协议，在申报边界之内；求值者 Q、外部存储与启动者在边界之外。每一次运行是一个独立的运行对象，记录它由谁启动，结束后不再执行任何一步。五对系统的结构差别由这些组成的实际操作给出，而不是由名称给出：  
　规则常量：续行核实际读取的是规则配置载体，不是场态载体；  
　影子副本：续行核读取场态载体，开启模式要求的 Idle、Pass 实际写入影子载体，场态载体在段内不变；  
　接续处外算：前者是开启运行，Prot 在每一接续处另排定一次 IdleStep，由 P 执行；后者排定相同，而每次 IdleStep 由 Q 收到场值的副本、按同一退浅律算出新值，再写回场态载体；  
　外部存储：每一接续处，场态载体移出 P，由外部存储持有，再原样交还 P；  
　接力：前一次运行在前缀最后一次脉冲读出后结束；启动者在同一宿载上另行启动一次运行，不经 ι，状态原位留在 P 的载体上，测试脉冲属于后一次运行。启动者只发出运行的启动，不读写 D 与承接分量。

接力系统的一遍观测含两次运行（3.1）。启动者不写 D，也不替换交付，Z1—Z4 按观测过程核对仍成立。

（乙）判定所取的段、步划分与运行

σ 自第一次脉冲的启动起，至测试脉冲的读出止，末段为空。按 3.1 与 𝒲₇，一次脉冲是 τ\_Φ 的一次执行。七项按《生成计算一般式》附形式化第二节执行界出的步划分 π 判定：s\_k 是交付协议发出的第 k 次脉冲的启动，e\_k 是该次脉冲出口位的锁存。一次脉冲之内依次是：SED = 1 时的 Idle，在 x 续行一跳，SED = 1 时的 Pass，脉冲序号加一，出口位锁存。这些都在第 k 步之内。

接续处 J\_k = (e\_k, s\_{k+1})（k = 1, …, n）内只有下列操作：  
　接续处外算一对的两系统：排定的 IdleStep；  
　外部存储一系统：场态的移出与交还；  
　接力一系统：J\_n 内前一运行的结束与后一运行的启动。  
其余实施的接续处为空。这些操作都发生在一次执行读出之后、下一次执行启动之前，不在任何一次执行之内。第 k+1 次交付的到达即 s\_{k+1}，它同时经入口给定当前位。

所以 π 覆盖 σ，没有不归属的操作。每一 s\_k 由申报协议发出，不是观察者划定的时刻。每一 e\_k 是该步结果锁存于输出载体的事件；D′ 由 Pass 写在 Pass 的写入对象上，锁存时已在其上。所以 π 合法可个体化。这一划分由执行区间与 3.1 申报的先后给出。《生成计算必然式》3.2 许可把一次脉冲或其中每一跳申报为一步；实例二中一次脉冲恰为一跳，两种申报给出同一划分。

状态载体与输出载体按分量申报。D 一侧，In\_k 是续行核读取的对象，Out\_k 是 Pass 写入的对象（SED = 0 时与 In\_k 相同，未写）；x 一侧是当前位寄存器与脉冲序号所在之处。分量归类：D 是全部边迹与位迹；当前位在接续处申报为输入位，由第 k+1 次交付在 s\_{k+1} 处给定；脉冲序号属承接分量；c 是外生控制量；得分与当前有效关系是即时量。各系统的运行身份由运行对象给出。

（丙）各项的判定依据

按《生成计算一般式》附形式化第三节，相对于（乙）的 σ、π 与运行，以上述实际操作为依据逐项判定：  
　Step：每一步由交付协议启动，由 P 在该次脉冲之内完成 Idle（SED = 1 时）、读入、续行、Pass（SED = 1 时）与锁存；步内没有边界外环节对本步结果 (x′, D′) 求值；一步的全部操作属于同一次运行。由《生成计算一般式》引理一，Ini、Run、Out 在每一步上成立；接力一系统按运行分段适用引理一，第 1 至 n 步在前一运行中、第 n+1 步在后一运行中各自满足引理的假设。  
　¬Intr：在每一 J\_k 内，没有边界外过程对 D 或承接分量求值、而第 k+1 步的读入依赖其结果；  
　Carry：每一 J\_k 内，D 与承接分量由 P 持有；  
　Sed（i）：D 是场的持久场态，不是 τ\_Φ 规则中的配置常量；  
　Sed（iii）：每一次改变都是协议操作，申报模式要求的更新都落在状态载体上；  
　Multi：σ 整段属于同一次运行，段内没有另行启动的运行，至少两步。  
另核 Hold：（a）每步写出 D 之处即下一步读取之处，当前位寄存器与脉冲序号原位；（b）第 k+1 步起始的 D 与脉冲序号，是第 k 步写出之值经接续处内操作所得；（c）接续处内脉冲序号不被改写。

以上判定都相对于（乙）的 π 与申报的分量归类。按《生成计算一般式》，各项判定携该式-H1（全项）、计算执行一般式-H1—H3 与计算承担一般式-H1—H3（12.1）。其中：Step 的 Ex 两款携计算执行一般式-H3，其具体判定另携计算执行一般式-H1；¬Intr、Carry、Hold 依申报的分量归类（生成计算一般式-H1（a））；在本实例上，接续处与步内的分界由申报的执行区间与 3.1 申报的先后给出（《生成计算一般式》"接续处的协议操作不是一步变换"），执行区间起止事件的认定携计算执行一般式-H1，生成计算一般式-H1（d）在这里没有被另行用作判据，但仍随各项判定承继；Multi 依"终止后另行启动的运行与原运行之别"，携计算执行一般式-H1、H2。

Sed（i）要求 D 属于合格场。实例二的结构位、持久状态 (d, g) 与 Trace、Sediment、Decay 三个场算子与 Canonical F\* 相同，只把续行求解器由 softmax 换为取最大。求解器替换是否保留《最小沉积场构造式》C1—C7，不从"求解器是实现项"直接推出，下面逐项证明：  
　C1（作用进入）、C2（迹应形成）、C3（跨时沉积）、C6（退浅）：只涉及 Trace、Sediment、Decay 与持久状态，不涉及续行求解器，与 Canonical F\* 逐字相同，照原证成立。  
　C4（关系组织）：取两段历史，H₁ 反复经历 (A, C) 与 (B, D)，H₂ 反复经历 (B, C) 与 (A, D)，使 C、D 两位在两段历史中于相同时刻被经过；则续行所读的末端位迹 d\_C、d\_D 两史相同，而 H₁ 中 g\_{AC} \> 0 = g\_{AD}，H₂ 中相反。κ 关于 g 严格增，取最大下 H₁ 自 A 取 C、自 B 取 D，H₂ 自 A 取 D、自 B 取 C；擦除 g、只留 d 时两史自 A、自 B 的去向相同。关系配对由 g 承担。  
　C5（历史参与后来）：H₂ 之后自 A 取 D；保持 d、g 不变而令 κ 不读 d、g（w\_g = w\_d = 0）时，两出边同分，取申报次序首位 C。已形成的沉积经续行被实际读取。  
　C7（当前流变）：A、B 各有两条可用出边，取最大总给出一条，场内存在实际迁转 q\_t → q\_{t+1}。  
所以实例二在取最大下满足 C1—C7，Sed（i）对它的场态载体成立。附录 A 对这七项另作运行核对（键 Fmin\_argmax\_C1\_C7）。

（3）¬Intr 一对。  
　Q 的操作在接续处。排定的 IdleStep 发生在第 k 次脉冲出口位的锁存 e\_k 之后、第 k+1 次交付到达 s\_{k+1} 之前，不属于任何一次脉冲，也就不在 τ\_Φ 的任何一次执行之内。两系统每一次脉冲之内的 Idle 都由 P 执行。  
　¬Intr 不成立。Q 收到 D 的副本，按退浅律算出新值，这是对 D 的求值，不只是保存或传递。写回后，s\_{k+1} 处的 D 正是 Q 写回的值，第 k+1 步的读入依赖这份工作。n ≥ 1 时至少有 J\_1，所以 ¬Intr 在 π 上不成立。  
　Step 不因此不成立。每一步的结果 (x′, D′) 都由 P 在该次脉冲之内算出：x′ 由续行（或按交付所给之边）得出，D′ 是 P 对 D 作 Idle、Pass 所得。Q 不参与任何一步之内的求值，¬Sub 成立；每一步的启动、运转与读出都由 P 在同一运行中完成。这正是《生成计算一般式》第六节所举的情形——"每一个接续处，协议排定的退浅由一台申报边界之外的主机代为求值"，而"Step 成立"——也是该式推论二（2）。该式把"外部主机算出本步的 D′ 写回"归 Step 的 ¬Sub，与此不同。  
　其余各项成立：  
　　Carry——Q 只取副本、不保管，D 与承接分量在接续处始终由 P 持有；  
　　Sed（iii）——IdleStep 是该式所列的许可协议操作（只退浅，作用于 D），Q 写回的值与退浅律给出的值相同，每一次改变都是协议操作，申报模式要求的更新都落在场态载体上；  
　　Sed（i）——D 在场的持久场态上；  
　　Hold——Out\_k 与 In\_{k+1} 是同一场态载体与同一寄存器，（a）成立；s\_{k+1} 处的 D 是 e\_k 处写出的 D 经接续处 IdleStep 所得，（b）成立；接续处脉冲序号不被改写，当前位按交付取得，（c）成立；  
　　Multi——整段属于一次运行。  
前者的各项同理成立，接续处的 IdleStep 由 P 执行。

（4）Carry 一对。外部存储的移出与交还发生在 e\_k 之后、s\_{k+1} 之前，在 J\_k 内。  
　J\_k 内 D 不由 P 持有，Carry 不成立。  
　外部存储只存不算，不对 D 求值，¬Intr 成立。  
　场态载体原样交还，Out\_k 与 In\_{k+1} 经只存只传相连，交还时的值与移出时相同，Hold 成立。  
　步内没有外部环节，Step 成立。其余各项同开启运行。

（5）Multi 一对。  
　前一运行怎样结束。前缀第 n 次脉冲的出口位锁存 e\_n 之后，前一运行 r₁ 结束，此后不再执行任何一步。  
　后一运行怎样启动。J\_n 内，边界外的启动者在同一宿载上启动运行 r₂。它不由 r₁ 的动力发出，也不由申报协议发出：Prot 中开始运行的协议只有 ι，而 r₂ 不经 ι。测试脉冲的启动 s\_{n+1} 由交付协议在 r₂ 中发出。  
　状态怎样承接。D、当前位寄存器与脉冲序号都原位留在 P 的载体上，r₂ 的第一次脉冲就在原载体上读写，不经复制。Out\_n 与 In\_{n+1} 是同一位置；s\_{n+1} 处的 D 与脉冲序号就是 e\_n 处写出的值。  
　其余各项成立：  
　　Carry、Hold（a）（b）（c）——由上一款；  
　　¬Intr——启动者不对 D 或承接分量求值；  
　　Sed 两款——D 的改变都是协议操作；  
　　Step——每一步的操作属于同一次运行（第 1 至 n 步属 r₁，第 n+1 步属 r₂），每一 s\_k 由交付协议发出。  
　Multi 不成立。σ 的前 n 步属 r₁，第 n+1 步属 r₂，σ 不整段属于一次运行。  
　为什么不是合法恢复或热迁移。《计算执行一般式》规定：虚拟机热迁移、在另一台机器上由检查点恢复，源主机、目标主机与传输通道都在申报边界之内且传输不代算时，是同一实例上的同一运行。《生成计算一般式》把同一实例上由检查点恢复后续训列为同一运行的续行（GS8），把"接力（未申报为恢复协议）"列为 Multi 不成立。本对没有迁移，也没有传输。就宿载上的物理过程说，同一宿载上不经传输的原位再启动，与边界之内的恢复没有差别；二者之分由是否申报为恢复协议给出。本对的 Prot 没有恢复协议，r₂ 的启动由边界外的启动者发出，不由 Prot 或 r₁ 的动力发出，所以它是"未申报为恢复协议"的接力。  
　条件。这一区分的一般判据属计算执行一般式-H1（使能间隔中由同一实例续行，与中断后的复位重推之分，含检查点恢复）与 H2（同一运行的判据，含检查点恢复与重新运行之分），二者都待证；《生成计算一般式》也规定"接力与恢复之分由计算执行一般式-H2 判定"。所以本对"后者只在 Multi 上不成立"携执行-H1、H2。若这两项条件的判据把这种接力认作原运行的续行，本对的见证随之失效。

## 第十三节　击穿方式

击穿定理一：在 𝒴^adm 中有一份观测，𝒮 满足 R 而 Read = 1；或 𝒮 满足 G 与定理六的前提，而对一切 n，Read = 0。

击穿定理二：指出实例一的申报中某一条前提不成立，或 N\_sw(𝒮₁) ≠ {n ≥ 4}。

击穿定理三：在 q₀ 下有满足 G 的系统读出 0，或满足 R 的系统读出 1。

以下击穿定理四、击穿定理五是对分辨边界陈述的击穿（1.3）。

击穿定理四：两个系统在 h⁰、h¹ 后 u\_test 处的 Arg 分别相同，而读出不同。

击穿定理五：指出某一对的两系统在某一前缀、某一步上 Arg 不同；或 10.3（乙）的步划分不是合法可个体化的；或在该划分与所申报的运行上，所列之项的判定与《生成计算一般式》的定义不合。

击穿闭合：两个候选的定义用到了对方、用到了七项或生成计算的判词，或用到了交付干预的读出。

击穿观测不预先假定归属：给出一个申报完备（W1′ 成立）的系统，在它上面，操作必须按它的归属来定义才能执行。

def partition(ex):
    """执行记录是否构成执行界出的合法可个体化步划分：σ 起于第一次脉冲的启动，止于测试脉冲的读出（末段为空）。"""

    order = [(r['part'], r['k']) for r in R]
    expect, i = [], 0
    for k in range(1, K + 1):                                     # 记录须依次为 S_1、J_1、S_2、…、J_{K-1}、S_K
        while i < len(order) and order[i] == ('S', k): i += 1; expect.append(('S', k))
        if k < K:
            while i < len(order) and order[i] == ('J', k): i += 1; expect.append(('J', k))
    cover = (expect == order)
    steps = {k: [r for r in R if r['part'] == 'S' and r['k'] == k] for k in range(1, K + 1)}

    end_ok = all(st and st[-1]['op'] == 'end' and st[-1]['obj'] == 'Position' for st in steps.values())
