自显论·工篇·场具化组式第二 v1.0

# 场具化数理式

第一节  
目的

### 1.1 这套系统要解决什么问题

《场具化一般式》已经证明：一个申报宿载实例若在其历史窗上活动具化为沉积场，必存在一个迹应集合 T，使迹应集合职责、组织参与职责与历史动力职责同时成立。三项职责说的是机制事实：哪一个机制过程以 T 的组织为条件，哪一个过程对 T 的组织施加了有效作用，这一作用是否由 T 已留下的迹应经实际物质途径参与决定，过程的载体在对象域之内还是之外。  
要在一个具体的宿载模型上表示、运行并求解这三项职责，最直接的做法是记录状态轨迹。这一做法不够。两个分项 +a 与 −a 相抵时，轨迹与静置无异，而一般式承认相抵的作用为作用；一个按固定日程施加的写入与一个由迹应决定强度的写入，可以给出逐点相同的轨迹，而前者不出自迹应。资格不是状态轨迹的函数。  
本系统给出一套保留机制见证的形式语言：每一步转移连同参与其中的机制事件、各事件的分项、载体归属、作用对象与来源路径一并记录，三项职责在这些见证上以三值求值。系统分两层：关系层 R 容纳多值、非线性与不可拆分的联合机制；有限可分层 F 在可分机制的有限子域上给出数值递推与可执行求解。F 经保见证嵌入 J 进入 R。宿载机制到三项职责的形式对应，由本系统的对应表、嵌入与回读规则承担。

### 1.2 所形式化的结构

所形式化的结构是《场具化一般式》第五节的正式总式：  
　　S\_Fld：Fld(χ) ⇒ ∃T \[ TraceSet(χ, T) ∧ Part(χ, T) ∧ HDyn(χ, T) \]  
连同该篇第三节的承担关系、组织条件、作用与过程识别规则、活动具化规定，以及收束轮引理。本系统为它建立形式系统：  
　　S\_Fld ⟼ M\_Fld  
式种为数理式，主式，独立成篇，首版。按《法篇》第一第三编第二章定种。进入条件：结构 S\_Fld 已由证明主式《场具化一般式》成立，各分量已有稳定术语。

### 1.3 边界

M\_Fld 的求值以申报的证据为输入，输出三值读数。读数 1 在第八节所列回读前件成立时读回一般式的三项职责；回读前件本身——迹应的形成与留存、迹应集合的跨时同一、机制的个别化与载体归属、组织条件与来源路径的物质真实——由宿载侧的认证给出，不由本系统的运行产生。  
F 层只覆盖有限结构位、有限离散历史窗、常数、线性与双线性三类数值律的可分机制。R 层的有限显式部分可完整枚举；隐式、无限或连续的关系不在可解域内。一般式中「不可拆分的联合作用在净变化为零时的作用判据」尚无结论，本系统对此保持未定值。

第二节  
核心论题

### 2.1 中心内容

本系统要精确表达的中心内容是：沉积场的具化资格是机制见证的函数，不是状态轨迹的函数。  
由此有三条要求。其一，表示须携带机制事件及其分项、载体归属、作用对象与来源路径，不得压缩为净状态转移（第十节定理一）。其二，不同层之间的对应须逐事件保持这些见证，资格才得保持（定理二）。其三，凡读不出的返回第三值；未定不等于假，证据细化只能使读数由未定变为确定，不翻转已定的读数（定理四）。

### 2.2 自上游承继而来的结构

《场具化一般式》已经确立下列内容，本系统按其原样承继：  
　　申报宿载实例　χ = (P, L, B, W)  
　　活动具化规定　定义各成分在 W 内承担，迹应可早于 W 形成而在 W 内留存  
　　TraceSet(χ, T)　T 非空，元素在 Ξ\_B 上，每一元素满足 q（结构位承受并留下的有效改变，在 W 内留存），且满足 r（T 的形成史中有信号留下的迹应；其余元素可由场内续行造成）  
　　Part(χ, T)　存在 W 内实际发生、机制载体在 B 内的过程 π，Cond(π, Org(T))  
　　HDyn(χ, T)　存在 W 内实际发生的过程 ρ，Act(ρ, Org(T)) ∧ HistCond(ρ, T)  
　　Cond　过程的实际进行（含发生条件与作用位置、方向或强度）以同一 T 的组织状态（含既往状态）为条件，可经实际物质途径传递  
　　Act　过程以物质方式对 Org(T) 实际施加在 L 上有效的作用；诸作用可相抵；具合法逐过程分解时以分项不为零且有效为精确判据  
　　HistCond　过程对 Org(T) 的作用（发生、时刻、位置、强度或方向）由 T 已留下的迹应经实际物质途径参与决定  
　　过程识别规则　过程以机制过程为单位；仅在不存在合法逐过程分解时以联合过程为单位  
　　收束轮引理　HistCond(ρ, T) ⇒ Cond(ρ, Org(T))  
信号是从 B 之外实际作用于 B 所属介质的作用，经由哪一通道不论。

### 2.3 工作输入

　　𝕀\_Fld = ( χ, T, 𝔐, ν, Γ )  
各项的含义：  
　　χ　　申报宿载实例，含申报分辨率  
　　T　　申报的迹应集合（有限结构位集）  
　　𝔐　　宿载模型：R 层为有类型转移关系与机制事件，F 层为结构位、脉冲、可分机制与数值律  
　　ν　　证据赋值：各证据原子在三值域上的值  
　　Γ　　求值约定：证据路径图的闭合约定、路径枚举上限、分辨率阈

### 2.4 两层与嵌入

R 层回答「怎样表示」：一切合法个别化的机制事件与转移，包括多值与不可拆分者。F 层回答「怎样运行与求解」：有限可分机制的数值递推与资格求值。J 回答「怎样耦合」：F 的每条运行进入 R，见证逐事件保持。

第三节  
基础对象与定义序列

### 3.1 对象的三类来源

第一类，上游的本体对象。本系统只调用，不重新定义：  
　　χ、P、L、B、W、Ξ\_B、T、Org(T)、Fld、TraceSet、Part、HDyn、Cond、Act、HistCond、信号、机制过程、联合过程  
第二类，已有的形式对象。从《场数理式》承继，不重新构造：  
　　结构位、迹应、沉积度 δ、方程 2 的积深项 Dτ 与退浅项 Eλ  
第三类，本篇新设的形式对象。下面逐条定义。凡标为纯形式辅助对象者，不是场量，不是本体谓词，不进入宿载的运行律；其完整清单见 8.6。

### 3.2 定义序列

以下逐条编号。凡含关系的条目，其性质在第七节逐项申明。  
D1　三值证据域  
　　𝔻 = { 1, 0, ⊥ }  
1 表示已认证成立，0 表示已认证不成立，⊥ 表示未定。合取与析取取强 Kleene 规则：合取中有 0 则为 0，否则有 ⊥ 则为 ⊥，否则为 1；析取对偶。⊥ 不等于 0。  
D2　申报集合与时窗  
T 是有限结构位集，T ⊆ Ξ\_B。F 层的历史窗为整数区间 W = { t₀, t₀ + 1, …, t₁ }；W 之前的形成史在 F 中以入口拍 t₀ − 1 表示。  
D3　组织状态  
O\_t 为时刻 t 的有类型组织状态，可为标量、向量或一般状态。O\_t 不等同于 T：T 是元素集合，O\_t 是这些元素的深度、分布与关系在时刻 t 的取值。  
D4　机制事件  
一个机制事件 e 是一个合法个别化的机制过程在一拍内的实际运行，按一般式的过程识别规则个别化。它携带：标识 id(e)、时刻 t(e)、载体归属 car(e) ∈ { B, 界外 }、作用对象 tgt(e)。存在合法逐过程分解时，不得把可分解的事件并为一个复合事件。  
D5　R 转移关系与合法历史  
　　K\_t ⊆ O\_t × E\_t × O\_{t+1}  
E\_t 为时刻 t 的机制事件集合。合法历史为 h = ( o₀, e₀, o₁, …, e\_{n−1}, o\_n )，逐步满足 ( o\_k, e\_k, o\_{k+1} ) ∈ K\_k。K\_t 不必是函数，不必处处有定义；一个前态可有多个后继。  
D6　事件见证  
　　ω = ( id, t, car, tgt, c, a, κ, η )  
c 为分项（可分时），a、κ、η ∈ 𝔻 依次为该事件的 Act、Cond、HistCond 证据值。  
D7　见证步与见证历史  
　　RStep = ( t, o\_before, o\_after, Ω\_t, Π\_t )  
　　RPath = ( X, Trace, Ident, ( RStep\_k )\_k, T )  
Ω\_t 为该拍事件见证的有限集合，Π\_t 为该拍脉冲贡献的有限集合，X 为结构位集。Trace 为迹应集合职责的证据值，Ident 为 T 的跨时同一证据值（η\_T）。RPath 是 R 层唯一的转移与资格类型。  
D8　R 层资格求值  
　　Part\_R = ⋁ { κ(ω) : ω 属 W 内各步，car(ω) = B }  
　　HDyn\_R = ⋁ { \[tgt(ω) ∈ T\] ∧ a(ω) ∧ η(ω) : ω 属 W 内各步 }  
　　Q\_R = Trace ∧ Ident ∧ Part\_R ∧ HDyn\_R  
⋁ 与 ∧ 取 D1 的强 Kleene 规则；空析取为 0。\[·\] 为 0、1 指示。  
D9　不可分联合事件  
　　j = ( id, car, o\_b, After(j), φ, κ, η, tgt )  
After(j) 为有限后继集合，φ ∈ 𝔻 为物理作用证据。设实际实现的转移为 ( o\_b, o\_a )，o\_a ∈ After(j)，则  
　　Act(j, o\_a) = φ　　　　　若 o\_a ≠ o\_b  
　　Act(j, o\_a) = 0　　　　　若 o\_a = o\_b 且 φ = 0  
　　Act(j, o\_a) = ⊥　　　　　若 o\_a = o\_b 且 φ ≠ 0  
最后一行承继一般式的未答范围：不可拆分的联合过程净变化为零时，作用资格不由本系统签定。Act 按实际实现的转移求值，不按事件的全部可选后继求值。联合事件经适配写为事件见证（ω 的 a 取 Act(j, o\_a)，κ、η 取申报值，tgt 取 tgt(j)），由 D8 求值。  
D10　F 层状态  
I 为有限结构位集，I ⊆ Ξ\_B。状态 s\_t : I → ℚ\_{≥0}；深度不截零，更新值为负者越出定义域（D20）。F 的全部数值取有理数并精确运算：申报的数值按其十进制表示取精确有理数。ε ≥ 0 为申报分辨率在 F 中的阈值：绝对值不超过 ε 的改变不是有效改变。  
D11　脉冲  
　　p = ( id, t, tgt, a\_p, ext, cert )  
a\_p ≥ 0 为积深量，ext 标明来自界外（信号）还是场内。cert 是该脉冲是否实际发生的认证：1 为发生，0 为不发生，⊥ 为发生未定。F 是对一个已给定的实际事件历程求值，只接受 cert ∈ { 1, 0 }；cert = ⊥ 的脉冲会改变后态而不知是否发生，不属 F 的单轨迹定义域，在 R 中以发生、不发生两条实现分支表示，各分支分别求资格（5.2）。ext 是已决定的归属；发生未定不得读作界外归属未定。F 中脉冲只表示积深；界外作用所致的退浅以界外载体的机制表示。  
D12　可分机制  
　　m = ( id, t, tgt, car, law, R(m), k, b, cert\_eff, cert\_read )  
分项按数值律由前态计算：  
　　常数律　c\_m = b  
　　线性律　c\_m = b + k · Σ\_{j ∈ R(m)} s\_t(j)  
　　双线性律　c\_m = b + k · s\_t(j₁) · s\_t(j₂)，R(m) = ( j₁, j₂ )  
R(m) 为读取位。机制一律读取拍前状态 s\_t。cert\_eff、cert\_read ∈ 𝔻 分别为作用认证与读取认证；cert\_eff 决定数值轨迹，在 F 中须已决定（D20）。  
D13　证据路径图  
结点为状态结点 (i, t)（时刻 t）与事件结点 id（时刻 t + ½）；边 ( u, v ) 携带认证值 cert(u, v) ∈ 𝔻，并要求 time(u) \< time(v)。闭合约定 Γ\_closed ∈ { 闭合, 开放 }。  
D14　路径状态  
对起点集 S 与事件 e：  
　　Path(S, e) = 1　　若只经认证值为 1 的边可由 S 达 e  
　　Path(S, e) = ⊥　　若否，而经认证值不为 0 的边可由 S 达 e  
　　Path(S, e) = 0　　若以上皆否且 Γ\_closed = 闭合  
　　Path(S, e) = ⊥　　若以上皆否且 Γ\_closed = 开放  
图上可达只是来源路径的形式见证；物质途径的真实是回读前件。  
D15　函数支持  
　　Supp\_act(m, s\_t)：数值律对其有非零偏导的读取位  
　　　　常数律为空；线性律在 k ≠ 0 时为 R(m)，否则为空；双线性律在 k ≠ 0 时为 { j₁ : s\_t(j₂) ≠ 0 } ∪ { j₂ : s\_t(j₁) ≠ 0 }  
　　Supp\_cond(m, s\_t) = Supp\_act(m, s\_t) ∪ ( R(m)，若 m 为线性律且 \|c\_m\| ≤ ε )  
「非零」取数学意义：k 与伙伴读数是否精确为零，与申报分辨率 ε 无关。ε 只判改变量是否有效（D10），不判函数依赖是否存在：系数再小，只要不为零，强度仍由读取位参与决定。后一项承认纯读取过程：分项不是有效改变（\|c\_m\| ≤ ε）而以读取位为条件运行的过程（如扫描读出）。分项为有效改变者，不论正负，都不是纯读取；纯读取能否承担参与，另须读取认证（D18）与回读前件。  
D16　形成记录与界外成因  
　　有效界外改变：作用于结构位 i 的界外作用，其改变量的绝对值大于 ε。界外作用指 ext = 界外的脉冲（改变量 a\_p），以及载体在界外的机制（改变量 c\_m）。  
　　Form(i)：使结构位 i 成为留迹元素的事件记录。已认证有效脉冲计入；已认证有效机制分项使 s\_t(i) ≤ ε \< s\_t(i) + c\_m 者计入，载体在 B 内者为场内续行形成，在界外者为信号形成。  
　　Mark(i)：结构位 i 上已认证的有效界外改变，不论元素新旧、改变正负。  
Form 与 Mark 职责不同。Form 承担 q 中「元素已形成」与 D17 中「形成早于读取」，只记新元素的产生；Mark 承担 r 中「信号留下的迹应」，记一切由界外作用留下的有效改变，含对已存在元素的加深与退浅。同一事件可同时入二者：界外脉冲产生新元素时，既入 Form，又入 Mark。  
D17　可用位  
　　Avail\_x(m, t) = { i ∈ Supp\_x(m, s\_t) ∩ T : s\_t(i) \> ε，且 Form(i) 中有早于 t 的记录 }，x ∈ { act, cond }  
D18　F 层事件原子  
　　Act\_F(m) = \[ \|c\_m\| \> ε \] ∧ cert\_eff  
　　Cond\_F(m) = \[ Avail\_cond(m, t) ≠ ∅ \] ∧ cert\_read  
　　HistCond\_F(m) = \[ Avail\_act(m, t) ≠ ∅ \] ∧ cert\_read ∧ Path( { (i, t) : i ∈ Avail\_act(m, t) }, m )  
HistCond\_F 不含 Act\_F；HDyn 是二者的合取（D19）。路径标签不能代替函数支持：Supp\_act 为空时 HistCond\_F = 0，无论链接如何申报。  
F 中机制的时刻、对象与读取位是申报给定的，数值律只表达作用强度对读取位的依赖。故 HistCond\_F 只编码「强度由迹应参与决定」一种，Cond\_F 只编码强度依赖与纯读取两种；作用的发生、时刻或位置由迹应参与决定者，F 不编码，须在 R 层以事件见证的 κ、η 表示。  
D19　F 层资格  
　　Src = \[ ∃ i ∈ T，Mark(i) ≠ ∅ \]，在已决定的事件历程上求值  
　　Ret = \[ ∀ i ∈ T，s\_{t₁+1}(i) \> ε 且 Form(i) ≠ ∅ \]  
　　Trace\_F = Src ∧ Ret ∧ Ident ∧ HistEv  
　　Part\_F = ⋁ { Cond\_F(m) : t(m) ∈ W，car(m) = B }  
　　HDyn\_F = ⋁ { \[tgt(m) ∈ T\] ∧ Act\_F(m) ∧ HistCond\_F(m) : t(m) ∈ W }  
　　Q\_F = Trace\_F ∧ Part\_F ∧ HDyn\_F  
Src 只由「对 T 的有效界外改变」确定：作用于 T 外的界外作用，或改变量不超过 ε 的界外作用，都不进入 Src。F 中脉冲的发生已决定（D11、D20），故 Src 只取 0、1；发生未定的情形属 R 的分支，在每一分支上分别求 Src。  
Ident 为 T 的跨时同一证据，HistEv 为形成史记录本身的证据，二者皆为申报的三值原子。  
D20　F 层定义域  
F 的一次运行要求：结构位与事件标识互异；事件时刻在 \[t₀ − 1, t₁\] 内；数值律、读取位与参数合法且有限；证据路径图的边按时间前向；各拍的精确更新值不小于零；cert\_eff ≠ ⊥；每一脉冲的发生认证 cert ∈ { 1, 0 }。不设容差：更新值小于零即越出定义域。作用未定的机制、发生未定的脉冲都不能决定数值轨迹，属 R 层；F 对它们拒绝运行，而不返回 Q = 0 或 Q = ⊥。数值输入可为整数、有理数或十进制小数，后者按其十进制表示取精确有理数。  
D21　保见证嵌入  
　　J：F 的一次运行 ⟼ RPath  
对 W 内每拍，J 取该拍的前态、后态、每一机制的见证 ω = ( id, t, car, tgt, c\_m, Act\_F, Cond\_F, HistCond\_F ) 与每一已认证有效脉冲的贡献；Trace 取 Trace\_F，Ident 取 Ident，T 不变。  
D22　状态轨迹投影  
　　π(h) = ( o₀, o₁, …, o\_n )；在 F 中为 ( s\_{t₀}, …, s\_{t₁+1} )  
π 丢弃事件、分项、载体、对象与路径，只留状态序列。

第四节  
方程与判据

### 4.1 R 层的关系演化

　　o\_{t+1} ∈ K\_t( o\_t, e\_t )  
W 上的合法历史集合记为 ℋ\_W。资格按每一条完整历史求值；「某一条历史成立」不替代「每一条历史成立」。

### 4.2 F 层的数值递推

　　s\_{t+1}(i) = s\_t(i) + Σ\_{p : tgt(p) = i, cert(p) = 1, a\_p \> ε} a\_p + Σ\_{m : tgt(m) = i, Act\_F(m) = 1} c\_m  
分项一律由前态 s\_t 计算。同一结构位上不同机制的分项可以相抵。更新不截零：右端为负的输入越出定义域（D20），右端为零者合法。

### 4.3 判据方程

R 层：D8。F 层：D18、D19。二者的资格式同形：  
　　Q = Trace ∧ Part ∧ HDyn，Part 只计 B 内载体，HDyn 只计作用对象属 T 者，HistCond 不含 Act

### 4.4 三值求值的形状

三项职责的读数都是有限个原子的强 Kleene 合取、析取复合。原子分两类：一类由数值律与形成记录确定（\[\|c\_m\| \> ε\]、Supp、Form、Mark、Ret），只取 0、1；一类是申报的证据（cert\_read、路径边认证、Ident、HistEv），可取 ⊥。作用认证 cert\_eff 与脉冲发生认证 cert 决定数值轨迹，在 F 中须已决定（D20）。

第五节  
运行与求解

### 5.1 F 层求解器

输入 𝕀\_Fld 的 F 部分，自 t₀ − 1 至 t₁ 逐拍执行：  
　　第一步　核验 D20，不合即拒绝；含发生未定的脉冲或作用未定的机制者拒绝，转 R 层  
　　第二步　登记该拍已认证发生且有效的脉冲及其形成记录与界外成因；认证不发生的脉冲不计  
　　第三步　对该拍每一机制，由前态计算 c\_m，求 Act\_F、Cond\_F、HistCond\_F  
　　第四步　Act\_F = 1 者计入分项，并登记新元素的形成与界外成因  
　　第五步　按 4.2 更新状态  
　　第六步　对 t ∈ W，记录前态、后态、分项与事件原子  
　　第七步　窗末按 D19 求 Trace\_F、Part\_F、HDyn\_F、Q\_F  
每拍的证据路径判定是有限图上的可达性，求解器在有限步内终止。

### 5.2 R 层枚举

输入初态与逐拍显式有限的联合事件集合。逐拍对每条合法前缀追加其全部合法后继，得 ℋ\_W；对每条完整历史，以 D9 按实际实现的转移求事件的 Act，经适配由 D8 求资格。设枚举上限，触及上限即报截断，不签「全部枚举」。  
发生未定的脉冲在 R 中表示为两条实现分支：发生一支与不发生一支。若其余事件都可分且已决定，每一分支就是 F 的一次合法运行，其在 J 下的像即该分支的见证历史；两分支各自求 Trace、Part、HDyn、Q。R 的分支只是形式上可能的历史，不认证哪一支是实际发生的物质历史。

### 5.3 三值传播

0 与 ⊥ 不得压平：缺证据返回 ⊥；闭合图上无路径返回 0，开放图上无路径返回 ⊥；不可拆分联合事件的净零转移在作用证据不为 0 时返回 ⊥。  
证据原子未定与事件是否发生未定是两种问题。前者不改变数值轨迹，按强 Kleene 规则传播；后者改变数值轨迹，不在 F 的单轨迹运行中处理，而由 R 枚举各实现分支，每一分支有确定的轨迹并分别求资格。不得把各分支的状态拼成一个数值状态，再以 ⊥ 掩盖分支的差别。

### 5.4 可解性

F 层：在 D20 的定义域内，每次运行有唯一的数值轨迹与唯一的资格读数（第十节命题一）。R 层：有限显式的部分可完整求解，代价可随窗长指数增长（定理三）；隐式、无限或连续的转移关系不提供通用求解程序。

第六节  
耦合关系

### 6.1 与《场数理式》

对应：结构位 ↔ I 的元素；沉积度 δ ↔ s；迹应 ↔ Form 与 Mark 所记的有效改变。  
《场数理式》方程 2 为 δ\_{t+1}(x) = δ\_t(x) + Dτ\_t(x) − Eλ\_t(x)。在同一层级、同一时标、各分项有合法机制归属时，F 的分项按机制职责归入方程 2，不按正负号归入：  
　　Dτ ↔ 脉冲及迹应、续行所致的积深分项  
　　Eλ ↔ 场质退浅类机制的分项  
　　R\_ext、R\_other ↔ 方程 2 中无对应项的分项，如界外作用所致的退浅  
于是 F 的记账可写为  
　　s\_{t+1} = s\_t + Dτ\_t − Eλ\_t + R\_ext(t) + R\_other(t)  
这是 F 一侧的对应记账，不改动《场数理式》方程 2。机制归属无法认定的分项记为未定，不强行归入。R 层的不可拆分联合事件不拆为方程 2 的分项。

### 6.2 与《最小沉积场构造式》的 Canonical F\*

F\* 的单步更新可作为 R 层的有限显式转移申报，其 Sediment 写入与退浅分项可作为事件见证。F\* 中由续行势决定后继的选择不属 F 的三类数值律，F\* 不在 F 中直接求值。

### 6.3 与《沉积场判定式》

判定式的操作谓词是宿载侧证据的候选来源，对应如下：  
　　Tr^静、Tr^撤（留存差异）　　↔　Ret 与 q 的留存证据  
　　Hist（历史留存差异）　　　　↔　Form、Mark、HistEv 的形成史证据  
　　Act\_𝓟（协议内活动参与见证）　↔　Part 中 cert\_read 的参与证据  
　　Dep（依赖效应历史改变）　　　↔　HistCond 中函数支持与读取认证的候选证据  
这些对应只给出证据的去向。判定式的谓词何时足以认证上述原子，由判定式自身的桥接判定；在桥接成立之前，取自判定式的值不升格为本系统原子的已认证值。由定理一，仅以实际历史状态轨迹为输入的判据不能判定 Act 与 HistCond；判定式的干预、反事实比较与协议见证，正是状态轨迹之外的信息来源。

### 6.4 与《场具化一般式》

逐项对应见第九节。M\_Fld 不新增本体条件：D8、D18、D19 的每一合取项都回指一般式的一项承担条件。

第七节  
关系性质

### 7.1 R 转移关系 K\_t（D5）

K\_t 是 O\_t × E\_t × O\_{t+1} 上的三元异型关系。自反、对称、反对称、传递四性对三元异型关系无定义，不适用。固定一个事件后投影所得的状态二元关系，四性都不普遍成立。

### 7.2 Cond、Act、HistCond（作为过程与迹应集合之间的关系）

三者都是机制过程集合与迹应集合（或其组织状态）之间的异型二元关系。同域四性不适用。不得假定对称或传递。

### 7.3 时间先后 \<（D13）

结点时刻上的严格先后：非自反、非对称、反对称（空真）、传递。

### 7.4 认证可达 ⇝⁺（D14，长度不少于一）

只经认证值为 1 的边、长度不少于一的可达：由 7.3，边按时间前向，故非自反、非对称、反对称（空真）、传递（路径拼接）。只经认证值不为 0 的边的可达同具此四性，但它只给出 ⊥，不是已认证可达。

### 7.5 零长度可达 ⇝\*

允许长度为零的可达：自反、反对称、传递，不对称。HistCond 的求值只用 ⇝⁺，不以零长度可达为来源证据。

### 7.6 跨时同一证据 Ident（η\_T）

Ident 是关于申报的 T 的三值原子，不是集合之间的二元关系；四性不适用。本系统不把它当作等价关系使用，不由数值相等推出跨时同一。

### 7.7 信息序 ⪯（D1）

⊥ ⪯ 0，⊥ ⪯ 1，且每一值 ⪯ 自身：自反、反对称、传递；不是全序（0 与 1 不可比）。

### 7.8 真值序 ≤（D1）

0 ≤ ⊥ ≤ 1：自反、反对称、传递，是全序。真值序与信息序语义不同，不得互代。

### 7.9 嵌入 J（D21）

J 是从 F 运行到 RPath 的映射，不是同域二元关系；四性不适用。J 不是满射（定理二（三））；其可逆性未证。

第十节  
形式实现定理  
本节诸结论的证明都是初等的：构造反例、按构造验证、对步数归纳、对公式结构归纳。它们的作用是确定这一形式系统的表示要求、层间耦合与可解范围，不是高阻力的数学定理。  
命题一（F 层的唯一性）  
在 D20 的定义域内，F 的每次运行有唯一的数值轨迹与唯一的资格读数。  
证明。各拍的分项是前态的单值函数，脉冲贡献由输入给定，事件原子由前态、输入与有限图可达性确定；对拍数归纳，轨迹与读数唯一。∎  
此命题只是数值递推的良定，不是物理机制唯一性的主张。  
定理一（机制见证不可压缩）  
存在合法见证历史 h、h′，π(h) = π(h′) 而 Act\_W(h) ≠ Act\_W(h′)；也存在合法见证历史 g、g′，π(g) = π(g′) 而 HistCond\_W(g) ≠ HistCond\_W(g′)；两组历史的 Q 值也不同。故不存在以 π 为唯一输入的函数，能在全部合法历史上正确给出 Act\_W、HistCond\_W 或 Q。  
证明。Act：取同一申报实例与 T，初态 s = 1。h 在 W 内无机制事件；h′ 在同一拍有两个合法个别化的机制事件，分项 +a 与 −a，a \> ε，前者以 T 为读取条件且出自迹应。则 π(h) = π(h′) = (1, 1)，h 的 Act 与 Part 为 0，h′ 的 Act、Part、HDyn 为 1。  
HistCond：取同一申报实例与 T，W 之前已形成并留存，s = 1，W 内另有一纯读取过程承担 Part。g 中唯一写入机制为常数律 c = 0.2；g′ 中为线性律 c = 0.2 · s，并有已认证的证据路径。两者在 s = 1 处都给出 +0.2，π(g) = π(g′) = (1, 1.2)。g 中 Supp\_act 为空，HistCond = 0，Q = 0；g′ 中 HistCond = 1，Q = 1。  
若有函数 f 以 π 为唯一输入而处处正确，则 f 在同一输入上须取两个不同值，矛盾。∎  
二例都在一般式允许的范围之内：相抵的作用为作用；作用是否出自迹应，与它在某一状态处的取值无关。本定理说的是形式表示的要求：表示须携带机制见证。它不是关于观测可区分性的结论；后者涉及干预与协议，属判定任务。  
定理二（保见证嵌入与资格保持）  
对 D20 定义域内的每一 F 运行 F：  
（一）Trace、Part、HDyn、Q 在 F 与 J(F) 上逐项相等；  
（二）J(F) 的每一步上，每一结构位的后态等于前态加该步作用认证为 1 的事件分项与已认证脉冲贡献之和；  
（三）J 不是满射：存在 RPath 不是任何 F 运行的像。  
证明。（一）由 D21，J(F) 的每一事件见证逐字段取自 F 的同一事件：载体、对象、分项、Act\_F、Cond\_F、HistCond\_F；Trace 与 T 不变。D8 与 D19 的资格式在相同的见证集合上取相同的析取与合取，强 Kleene 运算对相同输入给出相同值；Q\_R 中的 Ident 已含于 Trace\_F，强 Kleene 合取幂等，不改变读数。（二）由 4.2 逐拍成立：4.2 不含截零，后态即前态加该拍已认证有效的分项与脉冲贡献；右端为负者不在定义域内。F 在有理数上精确运算，此等式逐位精确成立，程序以相等关系核验。（三）F 的定义域内作用证据不取 ⊥（D20），故 J 的像中每一事件见证的 a ∈ { 0, 1 }；而含一个净零不可拆分联合事件的 RPath 有 a = ⊥（D9），不在像中。∎  
由定理一，若 J 把一步的见证压缩为净状态转移，（一）不能普遍成立。  
定理三（有限显式 R 的全历史求解）  
设 W 有 n 拍；每拍对每一合法前态可有效列出全部有限后继；状态相等可判定；枚举不触及上限。则 5.2 的枚举输出的历史集合恰为 ℋ\_W。若每拍任一前态的合法后继数至多为 b，则 \|ℋ\_W\| ≤ bⁿ；显式输出全部历史所需的时间与空间不少于输出总长度。  
证明。对拍数归纳。零拍时只有初始历史。设枚举恰列出全部长度为 k 的合法历史；它对每条历史追加全部且仅追加合法后继，故恰得全部长度为 k + 1 的合法历史。逐拍至多乘 b，得 bⁿ。∎  
本定理不给出多值关系的多项式全枚举，也不覆盖隐式、无限或连续的转移关系。  
定理四（三值证据细化下的单调）  
固定 F 的结构（结构位、T、W、脉冲及其认证、机制及其数值律与作用认证、证据路径图的边集与闭合约定）。设两个证据赋值 ν ⪯ ν′，即读取认证、路径边认证、Ident、HistEv 中每一原子在 ν 下为 ⊥ 或与 ν′ 同值。则 Trace、Part、HDyn、Q 的读数满足 Eval\_ν ⪯ Eval\_ν′；R 层对事件见证的 a、κ、η 与 Trace、Ident 同样成立。  
证明。数值轨迹只依赖结构，不依赖上列原子（D12、4.2），故 Supp、Form、Mark、Ret 与 \[\|c\_m\| \> ε\] 在 ν、ν′ 下相同。D14 的路径状态对边认证单调：ν 下取 1 者在 ν′ 下仍取 1；ν 下取 0 者（闭合图上无非零路径）在 ν′ 下仍无非零路径。资格式是原子的强 Kleene 合取、析取复合，而强 Kleene 合取、析取对信息序单调；对公式结构归纳即得。∎  
脉冲认证与作用认证的改变会改变数值轨迹，不属证据细化；改变 T、机制律或换用别的历史，也不属证据细化。  
定理五（条件回读）  
在 8.2 的回读前件下，对申报的 T：Q = 1 当且仅当 T 在 χ 上满足 TraceSet、Part、HDyn。  
证明。逐项对应。Src 与 Mark 对应 r：Mark 记录界外作用留在 T 的结构位上的改变，包括界外脉冲与界外载体机制的分项（前件（一）（三））。Ret 与 Form 对应 q（前件（一）（二）（六））。Part\_F 只计 B 内载体、以 T 上可用位为条件的过程，对应 Part（前件（三）（四）（六））。HDyn\_F 只计作用对象属 T、作用有效、且函数支持与证据路径出自 T 已留迹应的过程，对应 Act ∧ HistCond（前件（四）（五）（六））；R 层的 HDyn\_R 在事件见证上取同一对应。各合取项一一对应，W 级存在量词在两侧取同一见证集合。∎  
推论一（读回沉积场成立）  
在 8.2 的前件下，Q = 1 时由一般式推论一得 Fld(χ)。这一方向是定义性对应，不提供物质认证。  
推论二（对应表完备）  
一般式总式及其展开的每一承重项，在第九节都有对应；本系统新设对象均为形式对象，不新增本体条件。

第十一节  
反例与边界见证  
下列构造都在第二节的工作输入之内，逐一对应附录 B 的检验组。

### 11.1 一般式的反例链

　　无信号留迹：Trace = 0（B1）  
　　P₂ 型：留迹而 W 内无参与过程：Trace = 1，Part = 0，Q = 0（B1）  
　　P₃ 型：纯读取过程承担参与，无作用：Part = 1，HDyn = 0（B1）  
　　P₄ 型：界外常数律写入；或线性律而 k = 0，并申报已认证链接：Act = 1，HistCond = 0，Q = 0（B1）

### 11.2 一般式的见证

　　χ₀ 型：信号入场 α、读出回写 β·s、退浅 −λ·s 三分项；W 前一拍入口信号使 s = α/(λ − β)；W 内每拍净变化为零，三分项各不为零，Q = 1（B2）  
　　χ\_e 型：B 内纯读取过程承担 Part，界外机制写入出自迹应，Q = 1；去掉 B 内参与过程则 Part = 0（B3）  
　　W 级存在：参与与作用分处不同拍，Q = 1（B4）

### 11.3 对象与成因

　　作用对象不在 T 内的过程不计入 HDyn（B5）  
　　场内续行形成的元素计入 T；仅由场内续行形成而无界外成因的 T 不满足 r（B5）  
　　界外载体机制形成的元素、以及对已存在元素的界外加深，都计为界外成因（B6）  
　　更新值为负的输入越出定义域，恰降到零者合法；发生未定的脉冲越出 F，其发生、不发生两分支各有确定轨迹并分别求资格；认证不发生的脉冲不计贡献、不登记形成与成因；分项为有效负改变者不是纯读取；系数小于 ε 而不为零的线性律仍取得函数支持；有理数输入精确进入运算（B15）

### 11.4 联合事件与三值

　　作用对象必填；对象不在 T 内的联合事件不计入 HDyn；净零转移的 Act 为 ⊥；分支按实际实现的转移求值（B7）  
　　路径边未定、开放图无路径、跨时同一未定，Q = ⊥；闭合图无路径，HDyn = 0（B8）

### 11.5 回归

定理二另有多机制、相抵、界外载体与多位的随机回归（B16）；11.1 至 11.4 中承重的边界构造另作集中回归（B17）。

第十二节  
击穿  
下列各条，任一成立即击穿本系统。前四条针对表示与回读，后四条针对层级与类型。  
K1　对应遗漏。一般式的某一承重项在第九节没有对应。  
K2　回读冲突。在 8.2 的前件下，Q 的读数与 T 在 χ 上三项职责的实际成立情况不符。  
K3　压缩见证。一个只以状态轨迹为输入的求值，在全部合法历史上正确给出 Act 或 HistCond（与定理一相悖）。  
K4　嵌入失守。存在 D20 定义域内的 F 运行，其在 J 下的资格读数或逐步加和与 F 不同（与定理二相悖）。  
K5　判据错置。函数支持为空而 HistCond 取 1；或偏导不为零而以分辨率阈判为无支持；或作用对象不在 T 内而计入 HDyn；或界外载体过程留下的改变不计为界外成因。

~~~python
"""场具化数理式 v1.0 附录 A：F 层（有限可分层）求值器。
形式模拟，不是物质因果认证。
"""
from dataclasses import dataclass
from math import isfinite
from collections import defaultdict
from fractions import Fraction
Tri = bool | None
def exact(v):
    """输入数值按其十进制表示取精确有理数；F 层全部运算在有理数上精确进行。"""
    return Fraction(repr(v)) if isinstance(v, float) else Fraction(v)
def tri_and(*xs):
    if False in xs:return False
    if None in xs:return None
    return True
def tri_or(xs):
    xs=list(xs)
    if True in xs:return True
    if None in xs:return None
    return False
@dataclass(frozen=True)
class Pulse:
    name:str; step:int; target:str; amount:float; external:bool=True; certified:Tri=True
@dataclass(frozen=True)
class Process:
    name:str; step:int; target:str; carrier_inside:bool; law:str
    reads:tuple[str,...]=(); coefficient:float=0.; bias:float=0.
    certified_effect:Tri=True; certified_read:Tri=True
    # rule: constant, linear (sum of read sites), bilinear (two sites)
@dataclass(frozen=True)
class Link:
    source:str; target:str; certified:Tri=True
@dataclass(frozen=True)
class Spec:
    sites:tuple[str,...]; initial:tuple[float,...]; window:tuple[int,...]
    pulses:tuple[Pulse,...]; processes:tuple[Process,...]
    links:tuple[Link,...]=(); identity:Tri=True; trace_history:Tri=True
    closed_graph:bool=True; epsilon:float=1e-9
    declared_T:tuple[str,...]|None=None

def _num(v, nonneg=False):
    # 合法数值：整数、有理数（Fraction）或有限的十进制浮点数
    if isinstance(v, bool) or not isinstance(v, (int, float, Fraction)): return False
    if isinstance(v, float) and not isfinite(v): return False
    return (not nonneg) or v >= 0
def check(x):
    if not x.sites or len(set(x.sites))!=len(x.sites):raise ValueError('sites')
    if x.declared_T is None or not x.declared_T or len(set(x.declared_T))!=len(x.declared_T) or any(s not in x.sites for s in x.declared_T):raise ValueError('declared T')
    if not x.window or tuple(range(x.window[0],x.window[-1]+1))!=x.window:raise ValueError('window')
    if len(x.initial)!=len(x.sites) or not all(_num(z,True) for z in x.initial):raise ValueError('initial')
    if not _num(x.epsilon,True):raise ValueError('epsilon')
    if x.identity not in (True,False,None) or x.trace_history not in (True,False,None):raise ValueError('identity')
    names=set()
    for e in (*x.pulses,*x.processes):
        if not e.name or e.name in names:raise ValueError('event id')
        names.add(e.name)
        if e.step<x.window[0]-1 or e.step>x.window[-1]:raise ValueError('event time')
        if e.target not in x.sites:raise ValueError('target')
        if isinstance(e,Pulse):
            if not _num(e.amount,True):raise ValueError('pulse amount')
            # certified 在 F 中是脉冲「是否实际发生」的认证：1 发生，0 不发生；⊥ 不属 F 单轨迹定义域，须在 R 中按分支枚举
            if e.certified is None:raise ValueError('F_UNDECIDED_PULSE: enumerate occurrence branches in R')
            if e.certified not in (True,False):raise ValueError('pulse evidence')
        else:
            if e.law not in ('constant','linear','bilinear'):raise ValueError('law')
            if any(s not in x.sites for s in e.reads):raise ValueError('read sites')
            if e.law=='bilinear' and len(e.reads)!=2:raise ValueError('bilinear arity')
            if e.law=='linear' and not e.reads:raise ValueError('linear reads')
            if e.law=='constant' and e.reads:raise ValueError('constant reads')
            if not _num(e.coefficient) or not _num(e.bias):raise ValueError('params')
            # D20：作用认证须已决定；作用未定的机制不属 F 定义域（零分项亦然）
            if e.certified_effect not in (True,False):raise ValueError('undecided mechanism effect')
            if e.certified_read not in (True,False,None):raise ValueError('evidence')
    # All trace nodes are snapshots at integer t; process nodes at integer t+0.5.
    # Strict temporal order prevents fabricated same-step read-after-write.
    times={f'state:{s}:{t}':float(t) for s in x.sites for t in range(x.window[0],x.window[-1]+2)}
    times.update({e.name:float(e.step)+0.5 for e in (*x.pulses,*x.processes)})
    for link in x.links:
        if link.source not in times or link.target not in times:raise ValueError('link endpoint')
        if times[link.source]>=times[link.target]:raise ValueError('noncausal link')
        if link.certified not in (True,False,None):raise ValueError('link evidence')
    return times
def path_status(links,starts,target,closed=True):
    adjacency=defaultdict(list)
    for l in links:adjacency[l.source].append(l)
    def reachable(allow):
        seen=set(starts);queue=list(starts)
        while queue:
            u=queue.pop()
            for l in adjacency[u]:
                if allow(l.certified) and l.target not in seen:
                    seen.add(l.target);queue.append(l.target)
        return target in seen
    if reachable(lambda w:w is True):return True
    if reachable(lambda w:w is not False):return None
    return False if closed else None
def run(x):
    check(x)
    eps=exact(x.epsilon)
    state={s:exact(v) for s,v in zip(x.sites,x.initial)}
    # For each site, certified external history must be identified as event, not inferred from nonzero state.
    formation=defaultdict(list); history_snapshots=defaultdict(list)
    signal_marks=defaultdict(list)  # 界外成因：已认证、有效的界外作用分项（脉冲或界外载体过程）在该位留下的改变
    part=[];hdyn=[];reports=[]
    for t in range(x.window[0]-1,x.window[-1]+1):
        before=dict(state); contributions=defaultdict(list);events=[]
        # Pulse first as an event, but processes read the prior snapshot, not pulse-modified value.
        for p in x.pulses:
            if p.step!=t:continue
            # 只计已认证发生且有效的脉冲；确认不发生者不计贡献、不登记形成与成因
            a=exact(p.amount)
            if p.certified is True and a>eps:
                contributions[p.target].append((p.name,a))
                formation[p.target].append((p.name,t,p.external))
                if p.external:signal_marks[p.target].append((p.name,t))
        for m in x.processes:
            if m.step!=t:continue
            k=exact(m.coefficient); b=exact(m.bias)
            if m.law=='constant':value=b
            elif m.law=='linear':value=b+k*sum(before[s] for s in m.reads)
            else:value=b+k*before[m.reads[0]]*before[m.reads[1]]
            is_action=tri_and(abs(value)>eps,m.certified_effect)
            # Declared reads do not establish a genuine dependence: compute the law's support.
            support=()
            # 组织条件的支持：数值律依赖读取位，或纯读取过程（分项为零）；读取认证另作合取，未定不预先截为假
            # 函数支持按数学上的非零偏导判定（系数与伙伴读数精确不为零），不与有效改变阈值 ε 混用
            if m.law=='linear' and (k!=0 or abs(value)<=eps): support=m.reads
            elif m.law=='bilinear' and k!=0:
                support=tuple(s for i,s in enumerate(m.reads) if before[m.reads[1-i]]!=0)
            # For every element in the declared T, historical formation must precede the read.
            active_T=set(x.declared_T)
            available=[s for s in support if s in active_T and before[s]>eps and any(a[1]<t for a in formation[s])]
            is_cond=tri_and(bool(available),m.certified_read)
            # No automatic path from a read-site to an act. Explicit event links are required.
            old_nodes=[f'state:{s}:{t}' for s in available]
            route=path_status(x.links,old_nodes,m.name,x.closed_graph) if old_nodes else False
            # Action provenance must be supported by a nonzero functional dependence,
            # not merely a certified read that has no effect on the action.
            action_support=()
            if m.law=='linear' and k!=0:action_support=m.reads
            elif m.law=='bilinear' and k!=0:
                action_support=tuple(s for i,s in enumerate(m.reads) if before[m.reads[1-i]]!=0)
            action_available=[s for s in action_support if s in active_T and before[s]>eps and any(a[1]<t for a in formation[s])]
            action_nodes=[f'state:{s}:{t}' for s in action_available]
            action_route=path_status(x.links,action_nodes,m.name,x.closed_graph) if action_nodes else False
            is_hist=tri_and(bool(action_available),m.certified_read,action_route)
            if is_action is True:
                contributions[m.target].append((m.name,value))
                # 新元素的形成：B 内载体者为场内续行形成，界外载体者为信号形成
                if value>eps and before[m.target]<=eps:
                    formation[m.target].append((m.name,t,not m.carrier_inside))
                # 界外载体过程的有效分项，不论新旧元素、不论正负，都是信号留下的改变
                if not m.carrier_inside:
                    signal_marks[m.target].append((m.name,t))
            elif is_action is None: # 防御性检查：作用认证未定已由 check() 排除于定义域之外
                raise ValueError('unresolved effect cannot determine numeric trajectory')
            if t in x.window:
                if m.carrier_inside:part.append(is_cond)
                hdyn.append(tri_and(m.target in active_T,is_action,is_hist))
            events.append({'id':m.name,'delta':value,'act':is_action,'cond':is_cond,'histcond':is_hist,'route':route})
        for s in x.sites:
            new=before[s]+sum(v for _,v in contributions[s])
            # 深度不得为负：精确更新值小于零者越出定义域，不截零、不设容差
            if new < 0:raise ValueError('negative trace depth')
            state[s]=new
            if state[s]>eps and formation[s]:history_snapshots[s].append(t+1)
        if t in x.window:reports.append({'step':t,'before':before,'after':dict(state),'contributions':dict(contributions),'events':events})
    ts=x.declared_T
    eligible=all(state[s]>eps and formation[s] for s in ts)
    sources={origin for site in ts for origin,t in signal_marks[site]}
    trace=tri_and(bool(sources),eligible,x.identity,x.trace_history)
    pw=tri_or(part); hw=tri_or(hdyn)
    return {'trace':trace,'part':pw,'hdyn':hw,'Q':tri_and(trace,pw,hw),'reports':reports,'physical_certificate':False}
~~~

A.2　embedding\_verified.py　R 层统一类型、资格求值与保见证嵌入 J（D6—D8，D21）

~~~python
"""场具化数理式 v1.0 附录 A：R 层统一类型（EventWitness／RStep／RPath）、资格求值与 F→R 保见证嵌入 J。
保留事件见证，不认证物理因果。
"""
from dataclasses import dataclass
from field_final import run, Spec
def t_and(*xs):
    if False in xs:return False
    if None in xs:return None
    return True
@dataclass(frozen=True)
class EventWitness:
    event_id: str
    step: int
    carrier_inside: bool
    target: str
    contribution: float
    act: bool|None
    cond: bool|None
    histcond: bool|None
    source: str='F_mechanism'
@dataclass(frozen=True)
class RStep:
    time: int
    before: tuple[float,...]
    after: tuple[float,...]
    witnesses: tuple[EventWitness,...]
    pulse_contributions: tuple[tuple[str,str,float],...]
@dataclass(frozen=True)
class RPath:
    sites: tuple[str,...]
    trace: bool|None
    identity: bool|None
    steps: tuple[RStep,...]
    declared_T: tuple[str,...]
def tri_or(xs):
    xs=tuple(xs)
    if True in xs:return True
    if None in xs:return None
    return False
def evaluate_rpath(path:RPath):
    ev=[w for s in path.steps for w in s.witnesses]
    part=tri_or(w.cond for w in ev if w.carrier_inside)
    active=set(path.declared_T)
    hdyn=tri_or(t_and(w.target in active,w.act,w.histcond) for w in ev)
    return {'trace':path.trace,'part':part,'hdyn':hdyn,'Q':t_and(path.trace,path.identity,part,hdyn)}
def embed_f(spec:Spec):
    f=run(spec)
    processes={p.name:p for p in spec.processes}
    pulses={p.name:p for p in spec.pulses}
    rows=[]
    for row in f['reports']:
        t=row['step']
        contribution_map={eid:(target,value) for target,contrib in row['contributions'].items() for eid,value in contrib}
        witnesses=[]
        for event in row['events']:
            m=processes[event['id']]
            witnesses.append(EventWitness(m.name,t,m.carrier_inside,m.target,event['delta'],event['act'],event['cond'],event['histcond']))
        pcon=tuple((name,target,val) for name,(target,val) in contribution_map.items() if name in pulses)
        rows.append(RStep(t,tuple(row['before'][s] for s in spec.sites),tuple(row['after'][s] for s in spec.sites),tuple(witnesses),pcon))
    path=RPath(spec.sites,f['trace'],spec.identity,tuple(rows),spec.declared_T)
    q=evaluate_rpath(path)
    # F trace already includes identity; R separate identity conjunct is idempotent.
    assert {k:f[k] for k in ('trace','part','hdyn','Q')}==q,(f,q)
    for s in path.steps:
        for i,site in enumerate(path.sites):
            expected=s.before[i]+sum(w.contribution for w in s.witnesses if w.target==site and w.act is True)+sum(val for _,target,val in s.pulse_contributions if target==site)
            assert expected==s.after[i],(s,site,expected)  # 有理数精确运算下的等式
    return f,path,q
~~~

A.3　relational\_extension.py　R 层不可分联合事件、有限显式枚举与适配（D9，第五节 5.2）

~~~python
"""场具化数理式 v1.0 附录 A：R 层不可分联合事件的有限显式关系求解与适配。
不由申报的转移关系推断物理因果。

@dataclass(frozen=True)
class JointEvent:

    carrier_inside: bool
    before: tuple
    after_options: tuple[tuple,...]
    physical_effect: bool|None
    organized_read: bool|None
    trace_causal_path: bool|None
    target: str  # 作用对象（必填）
    # net change 0 need independent effect witness; no invented decomposition
    def act(self,after=None):
        # Neither state inequality nor an uncertified flag proves a physical Act.
        # Nonseparable net-zero remains unresolved in the sealed upstream text.
        if after is None: return None # a branched event alone is not a realized transition
        if after not in self.after_options: raise ValueError("unrealized transition")
        if self.before == after:
            return False if self.physical_effect is False else None
        return self.physical_effect
    def histcond(self):
        return self.trace_causal_path
    def cond(self):
        return self.organized_read

def t_and(*args):
    if False in args:return False
    if None in args:return None
    return True

def solve_relational(initial, stages, max_paths=100000):
    """Finite set-valued successor relation: all paths, not an arbitrarily chosen unique path."""
    paths=[(initial,)]
    for stage in stages:
        nxt=[]
        for p in paths:
            for ev in stage:
                if p[-1]!=ev.before: continue
                for end in ev.after_options:
                    nxt.append(p+(end,))
                    if len(nxt)>max_paths:raise OverflowError('path cap, no completeness claim')
        paths=nxt
    return tuple(paths)

def window_quality(trace_status, events, identity_status, declared_T):
    """Requires explicit true/false/unknown declarations; these are not material certification."""
    def t_or(xs):
        xs=list(xs)
        if True in xs:return True
        if None in xs:return None
        return False
    events=tuple((e,e.after_options[0] if len(e.after_options)==1 else None) if isinstance(e,JointEvent) else e for e in events)
    # JointEvent is an adapter to the shared witnessed R transition semantics.
    # The event is indivisible; a net-zero joint effect remains unknown.
    witness_rows=tuple(EventWitness(e.name,i,e.carrier_inside,e.target,0.0 if after==e.before else 1.0,e.act(after),e.cond(),e.histcond(),'joint') for i,(e,after) in enumerate(events))
    canonical=RPath(tuple(declared_T),trace_status,identity_status,(RStep(0,(0.,),(0.,),witness_rows,()),),tuple(declared_T))
    return evaluate_rpath(canonical)

def qualify_paths(initial,stages,trace_status,identity_status,declared_T):
    # Models may branch; qualify each complete history, do not existentially select a good history
    paths=[((initial,),())]
    for stage in stages:
        nxt=[]
        for states,events in paths:
            for event in stage:
                if event.before!=states[-1]:continue
                for after in event.after_options:
                    nxt.append((states+(after,),events+((event,after),)))
        paths=nxt
    return tuple((states,window_quality(trace_status,events,identity_status,declared_T)) for states,events in paths)
~~~
