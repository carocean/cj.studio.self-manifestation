# 场具化不可区分式

一、目的  
《沉积场判定式》给出由观测判定沉积场诸职责的判据，并以定理四、定理五申报了第一层判据的判定极限：在共同冻结的操作配置下，剖面相同的实例在第一层判词上无法分开。那里只给出若干对见证与逐实例孪生，用作误判界。其后的不可区分问题是：对一族闭合申报的观测集，就职责分项 q、r、Part、Act、HistCond、HDyn，以及申报 T 的 Q(T) 与 Fld = ∃T Q(T)，证明在观测集内全体观测之下哪些项可以确定、哪些项存在对全体观测不可区分的异资格候选，并给出使之可区分的观测集扩张，或扩张所须越出的范围。  
各定理的结论对所申报的观测集内全体观测成立；附录的有限核验用于找反例与核对构造，不构成证明。  
式种：不可区分式（《法篇》第四组反演辨识附式第十三章）。

二、上游输入  
《沉积场本体定义》定义正文。  
《场具化一般式》v1.0：三项职责（迹应集合职责、组织参与职责、历史动力职责）及其承担关系；过程识别规则；不可拆分联合净零之作用为未答范围。  
《场具化数理式》v1.0：D1 三值域；D9 不可拆分联合事件；D10—D20 的 F 层（有理数精确运算，ε 为申报分辨率，只入账有效项，D15 函数支持，D16 Form 与 Mark，D17 可用位，D18 事件原子，D19 资格，D20 定义域）；4.2 递推；定理一；14.2（观测协议下的不可区分不能由数理式定理一代替）。本篇附录 A.1 即数理式附录 A.1 的 F 层求值器，二者逐字相同。

三、候选与观测集申报

### 3.1　候选族

确定性族 𝔉：F 类候选 M 由下列各项组成。  
　（一）有限位集 I，分为界内 I\_B 与界外 I\_out；初态 s\_{t₀−1}: I → ℚ\_{≥0}；申报 T 是 I\_B 的非空子集；分辨率 ε ≥ 0；窗 W = {t₀, …, t₁}，入口拍 t₀ − 1。  
　（二）字母表 U，含静置 rest；合法历史集合 𝓗，由有限监控自动机给出；实际史 h\_act ∈ 𝓗，有记录。  
　（三）脉冲：拍、字母、对象位、幅度 a ≥ 0、界外或场内的来源标记。  
　（四）过程：拍、门控（无门控，或只在某一字母下运行）、对象位、载体（B 内或界外）、数值律（常数律、读取位之和的线性律、两读取位之积的双线性律）、读取位、系数 k 与偏置 b。  
　（五）各认证取 1；Ident、HistEv 取 1（POS、REC 已申报）；证据边取规范边，即每一过程的读取位指向该过程。  
净转移 Φ\_t(s, u) 按数理式 4.2：只入账有效项（脉冲幅度大于 ε，过程分项绝对值大于 ε）；分项读拍前状态；更新值为负即越出定义域。职责按数理式 D16—D19 在实际史上求值。  
随机族 𝔉^ω：在 𝔉 之上，脉冲幅度与过程参数可依当拍新息 ω\_t 取值；ω\_t 逐拍独立同分布。除申报状态外不另设隐藏记忆；跨拍相关须作扩张状态申报，扩张后即属本族（判定式 3.3）。实际记录为 h\_act 及实际实现下的界内轨迹；实际新息序列 ω\* 不可读。  
R 层联合事件：数理式 D9 的不可拆分联合事件，以其形式证据变量 φ 记录作用证据。

### 3.2　接口、完整协议状态与比较规则

候选 M 的接口 𝔦(M) 包括：界内读数坐标与 act；U 与监控自动机 𝓜；t₀、t₁、ε、T、h\_act；撤供是否申报；可设定的位及其取值域；在 MOD 分支，模块标号集。  
完整协议状态：拍号；各拷贝的监控态；各拷贝的完整状态，含界外分量与钳定所得的混合态；合法性标记，越域后进入显式吸收态并读出「不合法」。凡可判定性结论都以完整协议状态计。  
比较规则：  
　（一）两候选只在 𝔦 相同时比较，一切操作配置 C\_op 以同一参数施于两侧。  
　（二）𝔦 不同者称申报可区分，不属以下各定理的论域。  
　（三）接口相同而某一操作在一侧合法、另一侧不合法时，实验读出「不合法」；合法操作域的差异是读数。  
　（四）界外分量、过程分解、载体与来源标记、模块内部的数值律都不是读数。

### 3.3　实验与观测集

实验：有限、可自适应的操作序列，作用于 k 份耦合拷贝；每拍对各拷贝各选一个操作；同拍共享外生扰动；拷贝 1 至 k − 1 每步把界外分量覆写为拷贝 0 的值（孪生钳定）；读数为各拷贝的界内分量与 act，包含共同操作前的初始读数；实验的产出是读数序列的联合分布。  
观测集：  
　𝒴₁：k ≤ 2；操作为 U 的字母（含静置与探测）、已申报的撤供、Dep 已申报的设定。这是判定式第一层所用的全部观测，判定式第一层的一切判词都是其读数的泛函。  
　𝒴₁^(k)：同 𝒴₁，拷贝数 k。  
　𝒴₁+LOC：另加任意拍、任意位的局部设定（合法值）。  
　𝒴₁+MOD：另加任意拍、任意模块子集的敲除，两侧共同标号。  
　𝒴₂\_obs：𝒴₁+LOC+MOD，另加申报 OUT-f 的读取过程的输出。  
　𝒴\_L：R 层模型上，读数为 L 层全部状态分量，干预为输入、局部设定与以过程为单位（联合事件为不可拆分单元）的敲除的一切实验。  
𝒴₁+LOC 与 𝒴₁+MOD 互不包含：LOC 能到达不可达状态而 MOD 不能，MOD 能读出单个模块的入账项而 LOC 不能。  
闭包与前件 FIN：观测集 𝒴 在拍 t 的闭包 R\_t 是 𝒴 内一切实验中各拷贝在拍 t 的完整状态之集，含任意合法基线史与对照史、钳定混合态与已申报设定。FIN 指 R\_t 有限。有限字母、有限窗、有限设定域、有限扰动值集下 FIN 成立。  
可判定性结论的适用范围：有限、显式、有理的域，即有限 U、有限窗或有限完整协议状态、有限扰动值集、有理参数。任意局部设定给出无限的操作字母，对此只作数学陈述，不附算法。

### 3.4　观测与申报

𝒴₂\_obs 不读载体与来源标记。判定式在第二层另用实例协议的申报：INV-a、INV-c、PE 等，记为 𝒴\_decl。以申报限制候选族，即取观测类与申报族 C 之交，这与增加观测是两种不同的作用；𝒴₂\_obs 不等同于判定式的完整判定输入 𝒴₂\_obs + 𝒴\_decl。

### 3.5　随机族的关系、随机类与量词形式

观测等价 ≈obs：接口相同，观测集内一切实验的读数联合分布相同。本篇一切类与确定性结论都相对于 ≈obs。  
路径等价 ≈path：同一状态表示与同一扰动耦合下，逐 ω 的完整轨迹相同。≈path 蕴含 ≈obs；反之不成立（定理一（二）的奇偶候选二拷贝观测等价，而同一 ω 下轨迹不同）。≈path 只作构造孪生的工具。  
随机资格读法：职责在实际实现 (h\_act, ω\*) 上按数理式 F 的单轨迹读法求值。  
随机类：C(M, 记录) = {(M′, ω′)：M′ ≈obs M，ω′ 是 M′ 沿 h\_act 给出所记录界内轨迹的一个实现}，职责在 (M′, ω′) 上求值。不可读的 ω 对应不作为观测。  
两种量词形式：  
　锚定形式「∀ω\* ∃M′」：先固定实际实现，再构造并冻结孪生；冻结后，孪生对一切实验保持全部读数分布。  
　一致形式「∃M′ ∀ω\*」：同一孪生在一切满足条件的实现上改变职责。  
锚定形式是存在性结论，不是可由不可读的 ω\* 执行的识别算法。  
确定、两值：对观测集 𝒴 与职责项 X，若某一类内一切成员的 X 相同，称 X 在该类内确定；若类内有 X 取 1 与取 0 的成员，称该类两值。两值由一对对全体观测不可区分的异资格候选（孪生）证实。

四、产出同一性  
引理一（结构恒等）  
两候选接口相同，并在观测集的操作所能到达的状态上满足：逐 t、u、ω 的结构映射相同；撤供、设定、敲除映射与读数相同；合法性相同；扰动分布相同；初态（或初始分布）相同。则对任意拷贝数 k，该观测集内一切实验的读数联合分布相同。  
证明：按已读历史归纳。设对一切长为 n 的读数历史，两侧在该历史上的扩展概率相同，并且按该历史条件化后，拷贝联合状态的分布相同。下一操作是已读历史的函数，两侧取同一操作；联合状态经同一核与共享扰动转移；故长为 n + 1 的扩展概率与条件联合状态分布仍相同。∎  
引理一是同一状态表示下的充分条件；观测等价的候选可以有不同的隐藏表示，引理一不是其必要条件。  
定理一（观测框架）  
（一）确定性有限候选，k ≥ 2：k 拷贝实验区分两候选，当且仅当某个基线加一份对照的二拷贝实验区分它们。不可区分可由完整协议状态上的乘积搜索判定：有限窗时为按拍分层的图，从入口拍起计的区分实验长度不超过 \|W\| + 1（若从入口后起计，则不超过 \|W\|）；齐次、无限时程时，最短区分长度小于 \|𝓜\|²·\|S\|²·\|S′\|²，S、S′ 为含界外分量的完整状态集。  
证明：对照拷贝 j 的读数只依赖基线轨迹与 j 自身的操作，故 k 拷贝读数不同，则基线读数或某一对照的读数不同，相应的二拷贝实验即区分。乘积状态为（拍号，两侧监控态，两候选各自的基线态与对照态），可达者有限，广度搜索在有限步内或找到读数不同之态，或穷尽。∎  
（二）随机候选：对每个 k ≥ 1，存在两候选，在一切至多 k 拷贝实验上读数联合分布相同，而 k + 1 拷贝实验可区分。  
证明：单拍扰动取 k + 1 个独立公平位。字母 a₁…a\_k 读出前 k 位；字母 c 在候选 A 中读出前 k 位的奇偶，在候选 B 中读出第 k + 1 位。奇偶与前 k 位中任意 k − 1 位的联合是 k 维均匀分布，故至多 k 份读数（重复选同一字母时是重复坐标）的联合分布两侧相同；全部 k + 1 份读数的联合分布在 A 中满足奇偶约束，在 B 中不满足。多拍时状态无记忆，联合分布逐拍相乘；自适应情形按引理一的方式归纳。∎  
故随机情形下 𝒴₁^(k) 严格弱于 𝒴₁^(k+1)。本篇取 k ≤ 2 为 𝒴₁，与判定式的孪生协议一致；凡经引理一证得的不可区分，对任意 k 成立。  
引理二（死区分解）  
设 Z ⊂ ℚ 有限，z\* ∈ Z，ε \> 0，F: Z → ℚ 且 F(z\*) = 0。则 F 是有限个 θ(z) = (b + k z)·\[\|b + k z\| \> ε\] 之和，且每项满足 \|b + k z\*\| ≤ ε，即在 z\* 处无效。  
证明：记 z\_min、z\_max 为 Z 的最小、最大元。  
　右侧单项：取 U \> z\* 与 0 \< κ \< 2ε/(U − z\_min)。P⁺ = κ(z − U) + ε 与 P⁻ = −κ(z − U) − ε 在 Z 上恰于 z \> U 处有效（另一侧的再激活点 U − 2ε/κ 小于 z\_min），在 z\* 处取值落在 \[−ε, ε\]。  
　同阈值的 P⁺(κ₁) 与 P⁻(κ₂) 之和为 (κ₁ − κ₂)(z − U)·\[z \> U\]：±ε 台阶相消，余下斜坡；斜率受上界限制，以若干份重复得任意有理斜率。  
　同一间隙内两阈值 U \< U′ 的斜坡之差，在间隙右侧各点为常数 U′ − U，在左侧为 0，即纯台阶。阈值取在相邻有理点之间。  
　逐间隙取台阶，高度为 F 的相邻差，得 z\* 右侧的 F；左侧以在 z \< L 处有效的镜像单项同法得之。  
　Z 为单点或 F 恒为 0 时取空和；只有一侧时只作该侧的构造。∎

五、不可区分定理

### 5.1　确定性族的 𝒴₁ 等价类

记号：s\_t 为候选在实际史上拍 t 的拍前完整态，π\_B s\_t 为其界内读数；A(T) 指存在 t ∈ W、y ∈ T 使 s\_t(y) \> ε；越阈（x）指记录内某拍 s(x) ≤ ε 而窗末 s(x) \> ε；D\_t(y) 为拍 t 在 y 上的观测净增量。记 Y\_t(T) = { y ∈ T : s\_t(y) \> ε，且 Form(y) 中有早于 t 的记录 }，简写 Y\_t。Y\_t 是给定候选的可用位集；在定理五（一）的前件下，其形成部分可由观测恢复。Y\_t^det 指由可观测的越阈形成认证的可用位子集。数值律在完整态 s\_t 上求值；只有界内分量直接可读。  
定理二（族 𝔉，𝒴₁ 等价类内的职责确定性）  
　q(x)：窗末 s(x) ≤ ε 时确定为 0；越阈（x）时确定为 1；记录内恒大于 ε 时两值。  
　r（T 非空）：恒两值。  
　Part：¬A(T) 时确定为 0；否则两值。  
　HDyn：¬A(T) 时确定为 0；否则两值（ε \> 0 时需 FIN）。  
　Act（W 内作用于 T）：某拍某 y 有 D\_t(y) \< 0 或 0 \< D\_t(y) ≤ ε 时确定为 1；否则两值（ε \> 0 时需 FIN）。  
　Q(T)：某 x ∈ T 窗末 s(x) ≤ ε，或 ¬A(T) 时，确定为 0；否则两值；永不确定为 1。  
　Fld：不存在位 x 同时满足「窗末 s(x) \> ε」与「W 内某拍 s(x) \> ε」时，确定为 0；否则两值；永不确定为 1。  
确定方向的证明：  
　q：Ret 不成立则 q = 0。越阈那一拍的净增量为正；只有有效项入账，故有一项 c \> ε，且 s ≥ 0，于是该项入 Form（判定式定理五（三））。  
　Part、HDyn：¬A(T) 时 W 内无可用位，Avail 为空，Cond 与 HistCond 都为 0。  
　Act：脉冲幅度非负，故净减少必出自某个有效的负分项；有效脉冲幅度都大于 ε，其和或为 0、或大于 ε，故 0 \< D ≤ ε 也必含有效过程分项。二者都是作用于 T 的有效过程。  
　Q、Fld：Q(T) = 1 要求 T 中各位窗末大于 ε 且某位在 W 内可用，故须有一位兼具两者。  
两值方向的孪生构造：以下各构造保持 Φ 在所述状态集上逐点相同（含越域点上的原始值，故合法性也相同），由引理一，在 𝒴₁ 全体观测上不可区分。  
　r → 0：一切脉冲改为场内，一切过程载体改为 B 内。  
　r → 1：同拍加界外常数律 +a 与界内常数律 −a（a \> ε），作用于 T 中一位。  
　形成登记：入口拍加实际字母下的场内脉冲 +a，与同字母门控的界内常数律 −a，作用于 y。  
　q → 1：施形成登记。  
　q → 0（记录内恒大于 ε）：x 上的有效脉冲改为同字母门控、同幅度的界内常数律；x 恒大于 ε，故没有过程越阈形成。  
　Part → 1：施形成登记，再在可用拍加读 y 的纯读取过程（k = b = 0）。  
　Part → 0：W 内过程载体全改为界外。  
　HDyn → 1：施形成登记，再加 +k·y 与 −k·y（\|k·s\_t(y)\| \> ε）；两项绝对值处处相同，有效性同起同落。  
　Q、Fld → 0：r → 0 同时使一切 T 的 Src = 0。  
　Fld → 1：取 T = {x}，叠加形成登记、r → 1、纯读取与 ±k·x；各构造互不干扰。  
　以上各构造在一切状态上恒等，任意 ε。  
　HDyn → 0：  
　　ε = 0：重心化。每个作用于 T 的窗内过程 τ 换为常数律 τ(s\_t) 与同型律 τ − τ(s\_t)。后者在实际态上为 0，因而无效；常数律无函数支持，HistCond 为 0。ε = 0 时零项不改和，Φ 为多项式恒等；实际态上各项取值不变，故形成、成因与作用不变。  
　　ε \> 0（FIN）：只换在实际态有效、作用于 T 的窗内过程 τ = b + k·m(s)，m 为读取位之和或之积。拍 t 上记 Z = m(R\_t)、z\* = m(s\_t)，F(z) = τ(z)·\[\|τ(z)\| \> ε\] − τ(z\*)。τ 换为实际字母门控的常数律 τ(s\_t)，加引理二给出的同律型、同读取位、实际字母门控的死区项；原过程不门控时，在其他字母下各加一份门控副本。于是 R\_t 上逐字母、逐点的 Φ 相同。  
　Act → 0（各拍各 D = 0 或 D \> ε）：  
　　ε = 0：各项改为平移项；不门控部分的常数改由其他字母门控的常数律给出；实际字母下的净增量 D 改由场内脉冲给出。脉冲不计作用。  
　　ε \> 0（FIN）：有效项按上法换为死区项，常数部分与实际字母下的有效脉冲并为一个场内脉冲 D；D \> ε，该脉冲有效；D = 0 时不设。∎

### 5.2　随机族

定理三（族 𝔉^ω）  
（一）一致形式：存在单一冻结孪生，逐 ω 结构映射恒等，在每一条满足相应条件的实现上改变职责。  
　r → 0/1、Part → 0、q → 0/1、Q 与 Fld → 0：定理二的构造本不依赖实现，参数依 ω 者随同变换。  
　Part → 1、HDyn → 1（全 T 全拍构造）：对 T 中每一位 y 登记形成；对每一窗拍 t、每一 y，加界内 +1·y 与 −1·y。参数与实现无关；两项绝对值处处相同，逐 ω、逐状态净转移恒等。任一满足 A(T) 的实现，某 y 在某窗拍大于 ε，该对项在该处有效、读取可用位 y、载体在 B 内，故 Part = HDyn = 1。  
　Q(T) → 1：在上述构造上，再对 T 中每一位加 t₀ 的界外 +a 与界内 −a。凡 T 各位窗末大于 ε 且 A(T) 的实现，Q(T) = 1。  
　Fld → 1：对全部界内位施同一构造（含 r 对）。每一实现中，任取窗末大于 ε 且窗内某拍大于 ε 的位 x，令 T = {x}，则 Q(T) = 1。T 依实现而取，孪生是同一个。  
　这些构造增加过程，只用于不读模块分解的观测集，不用于 MOD 分支。  
（二）锚定形式：  
　HDyn → 0：对每一实际实现 ω\*，存在先于实验冻结的孪生，保持全部实验分布，且在 (h\_act, ω\*) 上 HDyn = 0。ε = 0：对每一待替换模块，常数取该模块在实际拍前完整态及实际新息下的律值 C = τ\_{ω\*\_t}(s\_t)，平移项的参数逐 ω 取 b\_ω − C，逐 ω 多项式恒等。ε \> 0：要求 FIN 与有限扰动值集 Ω；参数依当拍新息分段，ω\_t = ω\*\_t 时取以实际拍前态为锚的死区分解，其余 ω 下保留原律；闭包取一切 ω 序列、基线与对照史下的状态。  
　Act → 0：允许实现域是窗内每拍、每一 T 位的实际净增量 D = 0 或 D \> ε（ε = 0 时即 D ≥ 0）。  
　　在此域内，ε = 0 时用重心化，无需另加前件；ε \> 0 时另要求 FIN 与有限 Ω（闭包含全部允许实验、已申报设定、共享扰动与钳定态）。在这些前件下，对每一实际实现 ω\*，存在先于实验冻结的孪生，保持全部实验分布，且在 (h\_act, ω\*) 上 Act = 0。构造：在 ω\*\_t 下，各有效 T 项换为实际态上无效的项（ε = 0 为平移项，ε \> 0 为死区项），其实际态取值与原有效脉冲总量并为一个场内脉冲 D；其余 ω 下保留原律与原有效脉冲总量；原过程不门控时，其他字母下保留完整副本。  
　　FIN 与有限 Ω 是本构造的工作域条件，不断言为一切零向孪生存在的必要条件。ε \> 0 而 FIN 不成立时（如已申报设定域含无限的合法值），本构造不覆盖：此时可能出现定理四的朝向跳变而使 Act 确定为 1（实例 B6），也可能另有零向孪生；无其他判据时记为本构造未覆盖。  
　　在此域外（某拍某 T 位 D \< 0，或 0 \< D ≤ ε）：Act 在记录类中确定为 1，不存在零向孪生；此结论不依赖 FIN。  
　锚定构造不具一致性：同一锚定孪生在非锚定实现上 HDyn 可仍为 1。这只说明该构造不一致，不证明一致孪生不存在。  
（三）确定方向只用实际记录。记录中的界内轨迹在随机类 C(M, 记录) 的每一成员上相同，故定理二的各确定条件对类内一切 (M′, ω′) 成立；两值结论由 ≈path 孪生给出，这些孪生属于 ≈obs 类。∎

### 5.3　LOC 分支

推论一（ε = 0 时 LOC 不增加可确定性）  
ε = 0 时，在 𝒴₁+LOC 内，定理二的确定条件与两值情形逐项不变；定理三的锚定形式同样成立。  
证明：ε = 0 时定理二、定理三的全部孪生都是 Φ 在全体状态上的恒等，局部设定不能分开；确定方向在更细的等价类上仍成立。∎  
ε \> 0 时，q、r、Part、Q、Fld 各行的孪生仍是全状态恒等，结论不变；HDyn 与 Act 的零向孪生只在闭包上相等，LOC 可以使之确定（定理四）。Act 的零向在一切情形下只在其允许实现域内陈述。  
定理四（ε \> 0 时 LOC 的增益；族 𝔉）  
前件：LOC 设定域含所论切片上某开邻域内的一切合法值；该邻域内各步合法；y′ 属 Y\_t^det，即 s\_t(y′) \> ε 且拍 t 之前有可观测的越阈形成；每一模型的过程数有限。  
陈述：取 t ∈ W、实际字母 u、y ∈ T。沿 y′ 切片（s\_t 中把 y′ 设为 v），记 g(v) 为 y 上的增量。若存在 p ≠ s\_t(y′)，g(p) 等于背向 s\_t(y′) 一侧的极限，而朝向 s\_t(y′) 一侧的极限不等于 g(p)，则同类全体成员 HDyn = 1、Act = 1。  
证明：在任一成员中，g 是拍 t、字母 u 下作用于 y 的各有效项之和。不读 y′ 的项与脉冲沿切片为常数；双线性律的伙伴在切片上固定。读 y′ 的项为 θ\_j = w\_j·\[\|w\_j\| \> ε\]，w\_j 对 v 仿射，或为 b + k v²。在 v ≥ 0 上，w\_j 的无效集是闭区间，有效集是其补，各分支向远离该区间的方向延伸到底。g 的间断只在各项有效集的边界上；在边界点 p，该项取 0，有效一侧的极限模为 ε。朝向一侧的极限与 g(p) 之差，等于以 p 为边界、有效侧朝向 s\_t(y′) 的各项极限之和；差不为 0，故至少有一项 θ\_j 以 p 为边界、朝向 s\_t(y′) 一侧有效。该有效分支延伸到底，含 s\_t(y′)。故 θ\_j 在实际态有效，对象 y ∈ T，并沿切片依赖 y′：线性律 k ≠ 0 且 y′ 在读取位中；双线性律的伙伴在 s\_t 非零；y′·y′ 律中 s\_t(y′) \> ε ≥ 0。三种情形下 y′ 都在作用支持内；y′ 可用，越阈在每一成员中都给出形成记录，规范证据边存在。故 HistCond = 1，HDyn = 1，Act = 1。∎  
本定理只是充分条件。实例：附录 B.6。故 ε \> 0 时 LOC 严格增加可确定性。

### 5.4　MOD 分支

闭包 R\_t^MOD：𝒴₁+MOD 一切实验中两侧在拍 t 的完整状态之集，实验含任意合法基线史与对照史、两侧各拍任意敲除子集、钳定混合态。只在以实际史为基线的切片上拟合不足以支撑全观测等价（实例 B1）。  
引理三（脉冲总量归约）  
记 P\_t(u, y) 为拍 t、字母 u 下对象位 y 上的有效脉冲总量（先逐项截阈，再求和）。  
（一）记 π\_B 为界内读数投影。若在拍 t、字母 u 下某一闭包态上该步与全模块敲除合法，则 π\_B(Φ\_t^{−全}(s, u) − s) = π\_B P\_t(u, ·)，故每一界内位的有效脉冲总量由读数决定。逐模块入账同样只恢复可读投影：π\_B(Φ\_t(s, u) − Φ\_t^{−m}(s, u)) = π\_B ĉ\_m(s, u)。界外位的脉冲总量与作用于界外位的模块一般不能由读数恢复（实例 B7）。  
（二）形成记录在 (t, y) 上由有效脉冲入账，当且仅当 P\_t(u\_t, y) \> 0（有效幅度都大于 ε，其和为正当且仅当至少一项有效）；入账的净增量只含总量。故形成记录的有无与拍号、可用位、q、Part、HistCond、HDyn、Act 都只依赖总量。  
（三）唯一依赖脉冲分解的是来源标记（r），它不是读数；本引理不把来源认定为相同。∎  
定理五（族 𝔉，𝒴₁+MOD）  
（零）同表示替换引理（充分条件）：设 M′ 与 M 有同一完整状态表示及同一初态（有初始分布时要求分布相同），并满足：接口与模块标号相同；各拍、各字母、各对象位的有效脉冲总量相同；对一切 t、一切 s ∈ R\_t^MOD、一切字母 u，每一模块的原始入账向量 ĉ\_m(s, u)（按阈值截取后的律值，含门控与对象的效果，不论该点上的步或敲除是否合法）相同。则 M′ 与 M 在 𝒴₁+MOD 内不可区分，载体与来源标记可任意。  
证明：对任一敲除集 K，Φ\_t^{−K}(s, u) = s + P\_t(u, ·) + Σ\_{m∉K} ĉ\_m(s, u)，在 R\_t^MOD 上两侧逐项相等，因而合法性也相等。按拍归纳，两侧到达同一闭包，各实验读数相同（引理一）。各模块的条件互不牵连，可同时替换任意多个模块。∎  
本条件要求完整坐标相同；不能放宽为只要求界内一步更新相同，因为隐藏更新可以反馈。  
（一）形成记录可恢复：设任一拍任一模块子集的敲除合法，则形成记录（有无与拍号）与 q 在类内确定。证明：敲除该拍全部模块，余下的界内增量为有效脉冲总量，为正当且仅当有有效脉冲；单敲 m 得入账项 ĉ\_m(s\_t, u\_t)，越阈形成当且仅当 ĉ\_m \> ε 且 s\_t ≤ ε。∎  
（二）（甲）前件：t ∈ W；m 在实际字母下运行，实际态上有效且对象位属于 T；Y\_t 的形成记录在观测类内可恢复（例如满足（一）的前件）；s 取自以 h\_act 为基线、基线不敲除的二拷贝实验中，对照侧在拍 t 的完整状态（界外已钳定为实际值）；原步及单敲 m 的可读投影存在，m 的实际入账和两态入账差可读。陈述：若 s 在 Y\_t 以外与 s\_t 相同，而 ĉ\_m(s) ≠ ĉ\_m(s\_t)，则 HistCond(m) = 1，HDyn 确定为 1。证明：论证在每一成员自己的状态上进行。同一实验中，实际态与对照态在每一成员中都只在 Y\_t 上不同，而可读入账之差由观测决定，故每一成员的律都在两态上取值不同，从而读取某一 y′ ∈ Y\_t。线性律 k ≠ 0，支持即读取位。双线性律 k·j₁·j₂：若 j₂ 在 s\_t 上为 0，则 j₂ ∉ Y\_t，于是 j₂(s) = 0，两态取值相同，矛盾；故伙伴在 s\_t 上非零，j₁ 在支持内且可用。ε \> 0 时入账项不同即律值不同，论证不变。由前件，m 的实际非零入账及其 T 内对象由读数共同固定，因此每一成员均有 Act(m) = 1；与 HistCond(m) = 1 合取，得到 HDyn = 1。∎  
（乙）若 ĉ\_m 在 R\_t^MOD 上为常数，m 可换为同值常数律，HistCond(m) = 0（由（零））。  
（丙）判定。前件：FIN-MOD，即 R\_t^MOD 有限（无 LOC 时，有限字母、有限窗、有限敲除集下自动成立）；全读前件，即 R\_t^MOD 上一切步、单模块敲除与该拍全模块敲除合法。  
　同表示子族 C\_rep(M)：与 M 有同一完整状态表示、同一界外初值、同一界外动力（作用于界外位的过程，以及界外位上的有效脉冲总量）的候选。这是候选族的限制，来源为申报（界外分量申报属实，属 𝒴\_decl），不是观测所得；界内脉冲的分解不在限制之内。  
　在 C\_rep(M) 内：界外初值与界外动力由申报相同；界内读数由观测决定，按拍归纳各成员在同一实验中到达同一完整状态，即同一闭包；全读前件下，作用于界内位的各模块入账与界内脉冲总量在同一坐标上可读而相同（引理三（一））。于是完整入账向量与完整脉冲总量都相同：界内部分来自读数，界外部分来自申报。初始界内读数在观测类内相同，界外初值又由 C\_rep 固定，故完整初态相同。因而观测类 ∩ C\_rep(M) 等于 C\_rep 内满足（零）的全部候选，必要与充分两向成立。HDyn、Part 只依赖脉冲总量与模块律（引理三（二）），各模块的同值律可行性是 (b, k) 上的有理线性问题（律值对 (b, k) 线性；实际态给出一个等式，b 可消去，化为 k 的区间可行性），判定精确：  
　　某一实际态有效的 T 模块不存在无可用支持的同值律，则确定为 1；  
　　一切实际态有效的 T 模块都不存在有可用支持的同值律，则确定为 0；  
　　其余两值，两个孪生由（零）同时替换得到。  
　全观测等价类：观测等价的候选可有不同的隐藏表示（实例 B2），故（零）不是必要条件。全类上可签的结论：（甲）成立时确定为 1；C\_rep 内给出的两个孪生属于全类，故两值；窗内无可用位或实际态上无有效 T 模块时确定为 0（二者由观测决定）。其余情形称全类未定，不输出判值。  
　全读前件不成立时，只用可读点的判定是松弛问题：确定方向仍然成立，两值须另以越域点上原始入账项相同的严格见证验证。  
（三）载体与来源：r → 0、Part → 0 只改标记，由（零）不可区分。r 在 MOD 下确定为 0，当且仅当实际史上 T 无有效脉冲与有效模块分项；否则把一项标记改为界外即得 r = 1，不增删模块。

### 5.5　来源与载体；受限族

定理六（族 𝔉）  
在 𝒴₁、𝒴₁+LOC、𝒴₁+MOD、𝒴₂\_obs 的任一观测集内，任意拷贝数下，r、Part、Q(T)、Fld 的值 1 从不确定。  
证明：r → 0 与 Part → 0 只改脉冲来源与过程载体的标记；数值律、门控、标号、读取位都不变，故 Φ、撤供、设定、敲除映射与一切读数逐项相同（引理一）。Q、Fld 含 r 为合取项。∎  
此结论相对于本篇所定义的观测集，它们都不读载体与来源标记。要使这些项可确定，有两条途径：增加载体或来源的直接认证读数，这在本篇所定义的观测集之外；或以 𝒴\_decl 中的申报协议限制候选族。二者之外是否别无途径、认证是否只能靠申报，未证。  
命题一（PE 族，𝒴₁）  
在 PE 族中（无输入门控的过程，无界外载体过程，脉冲只作用于申报入口位且都是信号，静置不带脉冲），若 \[t₀ − 1, t₁\] 内每拍的「实际前缀加静置」都属 𝓗，则 r 确定。  
证明：Φ\_t(s, u) − Φ\_t(s, rest) 恰为 u 下的有效脉冲之和，在实际态上可读。∎  
若某拍在一切合法史中只许实际字母，则不门控的常数律与脉冲在该拍不可分，r 可两值。PE 只约束信号的入场方式，不给出 Part、HDyn 的认证。  
命题二（INV-a 而无 INV-c，𝒴₁ 与 𝒴₁+LOC）  
子族界定：INV-a 只认证清单所列过程的载体、对象与是否运行，不认证数值律；无 INV-c，清单外过程允许存在；所论观测集不读模块分解，过程标号不冻结。在此子族中，r、Part、HDyn 的确定性与族 𝔉 中相同。  
证明：把清单内过程的数值律移到一个新增的清单外过程上，载体任取；清单内过程改为常数 0 的运行过程。Φ 恒等，而各项职责可取定理二的两值孪生。∎  
INV-a 与 INV-c 是两件事。  
命题三（INV-a ∧ INV-c，𝒴₁+MOD）  
记 C\_ac 为满足 INV-a ∧ INV-c 的候选族。前件：模块即全部过程；载体如申报；满足 FIN-MOD 与全读前件。  
　Part：在 C\_rep ∩ C\_ac 内精确（类刻画用定理五（零）与引理三）。判定由组织条件支持（数理式 D15）的同值律可行性给出：某一 B 内窗内运行模块不存在无可用组织条件支持的同值律，则确定为 1；一切此类模块都不存在有可用组织条件支持的同值律，则确定为 0；否则两值，孪生由（零）替换得到，载体不变。全类上与定理五（丙）同法分层：只签（甲）型的确定为 1（实际态有效的 B 内模块满足（甲），其作用支持即组织条件支持）、由孪生证实的两值，以及窗内无可用位时的确定为 0。  
　r：某一界外载体模块在实际史上对 T 有非零入账，则确定为 1；T 上无有效脉冲且无界外模块有效，则确定为 0；否则两值，因为脉冲来源不受 INV-a 约束。  
　HDyn：同定理五。  
命题四（INV-a ∧ INV-c，𝒴₂\_obs）  
在一切状态上入账恒为 0 的界内纯读取模块，其读取位在 𝒴₂\_obs 内不可见：敲除与设定都不改读数。若 Part 只能由此类模块承担而 Y\_t 非空，则 Part 两值：改该模块的读取位即得孪生。这是判定式 ⊥\_Sub 的不可区分含义；有效模块的支持由判定式定理六（二甲）确定。申报 OUT-f 而观测集含其输出时，读取位可读，此不可区分消失。

### 5.6　不可拆分联合净零

命题五（形式证据变量不能由 𝒴\_L 恢复）  
对象：R 层模型对，转移关系与一切联合事件的后继集相同，只在某一联合事件 j 的形式证据变量 φ（数理式 D9）上一侧取 1、一侧取 0。允许干预：输入、局部设定、以 j 为不可拆分单元的敲除。允许读数：L 层全部状态分量。  
结论：𝒴\_L 内一切实验的读数联合分布相同，故所申报的形式证据变量 φ 不能由 𝒴\_L 恢复。  
证明：φ 不进入任何转移、干预映射或读数，由引理一。∎  
本命题是关于形式证据变量的陈述，不是关于对象层物理作用事实的陈述。要主张「实际作用为真」与「实际作用为假」的两个合法宿载在 𝒴\_L 内不可区分，须分别给出满足上游语义的两个机制见证及全部干预映射，并证明二者都是合法候选；这一命题未证（U4）。数理式 D9 对联合净零保留未定，赋值的自由不替上游决定实际作用。区分须超出所定义的 𝒴\_L；由此不推出须超出 L 层。「不存在区分观测」与「尚未定义可实施的额外读数」是两种不同状态。

### 5.7　Hist 参照史

设 Hist\_ρ 为以 ρ 替换被检段的参照史所给的 Hist（静读，孪生钳定）。本节 q ∈ ℕ₀ 为延后拍数，r ∈ \[0,1) 为 TV 判别阈值，区别于职责记号 q(x) 与来源记号 r(T)。  
定理七（参照史的等价类）  
（一）固定实际史与比较块后，参照只经各 q 下的 TV 距离作用于 Hist；故 ρ 与 ρ′ 在一切 r ∈ \[0, 1) 与 q 上同判，当且仅当二者的 TV 距离向量相同。这是按距离函数取商：不同的边缘分布可以有相同的距离（附录 B.11（四）例一）。确定性情形：比较块为全部界内位、每拍钳定、尾段为同一动力时，钳定后比较块上状态相同的拍构成上闭集；比较块缩小时不得沿用此结论。  
（二）PE 族中，无脉冲字母的净转移与静置相同，故一切无有效脉冲的参照与静置参照同类。  
（三）PE 不成立（允许输入门控的界内过程）时，静置不是特优参照：存在无脉冲参照与静置给出相反的 Hist。  
（四）含有效脉冲的参照可使被检段无信号而 Hist = 1。故判定式引理十二只对静置参照或与之同类的参照认证 r。  
（五）有限窗、有限 q 集合时可精确计算：传播二拷贝联合分布（共享扰动、钳定），取比较块边缘，逐 q 求有理 TV，参照按距离向量取商。  
（六）Hist 商丢失形成来源：两参照到达同一状态，一经信号脉冲、一经场内门控过程，距离向量相同而形成事件不同（附录 B.11（四）例二）。故 Hist 相等推不出事件来源相同，与判定式引理七的冗余形成相合。  
证明：（一）记 d\_ρ(q) 为固定实际史与参照史在延后 q 拍时的比较块边缘 TV 距离。Hist\_ρ(r,q) = 1 当且仅当 d\_ρ(q) \> r。距离向量相同则逐阈值同判；若某 q 的两距离 d \< d′，取 d ≤ r \< d′（可取 r \< 1），两判值不同，故逆向也成立。不同边缘可同距离，例如相对于 δ₀，δ₁ 与 δ₂ 的 TV 都为 1。确定性全界内状态并合且界外已钳定相同后，两份完整状态相同；共同的尾段动力使相同状态保持，故并合拍集上闭。  
（二）PE 下脉冲之外的过程不受输入门控，无有效脉冲字母与静置给出相同更新；按拍归纳，参照读数分布及其距离相同。  
（三）取一个初态为 0 的界内位 x，被检拍实际字母 a 给信号脉冲 1，字母 b 给场内门控常数律 1，静置无改变。以 b 为参照时两侧都到 1，q=0 时 Hist=0；以静置为参照时两侧为 1 与 0，Hist=1（任取 r\<1）。此模型不满足 PE 的无门控条件。  
（四）取只有 a 携信号脉冲 1、静置无改变的 PE 模型，实际被检拍静置，参照用 a。实际段无信号，但末态 0 与 1 的 TV 为 1，故 q=0、r\<1 时 Hist=1。  
（五）有限显式有理核在完整二拷贝状态上作推送，按共享扰动求联合概率，完成钳定后取边缘；所有概率及 TV 为有理数，可逐 q 精确比较。  
（六）在（三）的模型中，实际史取 a，两个参照分别取 a 与 b；两参照都到 1，共同静置尾段保持相同状态，故所有距离均相同。前者有信号形成事件，后者只有场内形成事件，来源不同而 Hist 商相同。∎

### 5.8　随机二拷贝等价的判定

定理八（有限有理域上 ≈obs 的判定）  
前件：有限扰动值集，有理概率；有限字母；有限窗，或完整协议状态有限；结构核已冻结。  
陈述：两候选在 𝒴₁（二拷贝、共享扰动、钳定）内是否观测等价可判定。本定理只判 ≈obs，不判 ≈path。  
完整协议：先比初始读数；操作含字母与已申报的设定，撤供作为已申报的操作字母；合法史由监控自动机给出，非前缀封闭时以接受态界定合法完整史，实验只取可在剩余拍内延伸为接受史的前缀；同拍运行的各拷贝须能在同一剩余长度上共同接受，不能只检查每一拷贝各自存在某个接受长度；越域进入吸收态并读出「不合法」。  
证明：（1）各候选的二拷贝过程是有限受控概率机，状态为完整协议状态；每一共同操作 a 与联合读数 o 给出有理矩阵 K\_(a,o)。（2）两候选取块对角矩阵，初始行向量 α = (α\_M, α\_M′)，泛函 f(v) = v·(1, −1)ᵀ。（3）带读数的操作词 w 的概率差为 f(α K\_w)。（4）由 α 出发右乘各 K\_(a,o) 生成有理线性张成空间，维数不超过两候选状态数之和，闭包有限步完成。（5）观测等价当且仅当张成空间的每一基向量 v 都满足 f(v) = 0；若某向量 f ≠ 0，其生成词即区分见证。（6）固定操作词上全读数分布相同，再按已读历史归纳（引理一），推广到自适应策略。∎  
不适用于无限状态或任意实数黑箱核。

六、观测集扩张的界  
　拷贝数：随机情形下 𝒴₁^(k) 严格弱于 𝒴₁^(k+1)（定理一（二））；确定性情形下二拷贝已足（定理一（一））。  
　LOC：ε = 0 时不增加任何职责项的可确定性（推论一）；ε \> 0 时可使 HDyn、Act 确定（定理四，充分条件）。  
　MOD：在定理五（一）的合法性前件下，形成记录与 q 可确定；在 FIN-MOD 与全读前件下，C\_rep 内实际有效 T 模块的同值律支持可行性及由其承担的 HDyn 可精确判定，在全类上只签（甲）型确定、孪生证实的两值及所列确定为 0 的情形；其余为全类未定（定理五（二））。载体与来源标记本身仍不可见（定理五（三））。  
　𝒴₂\_obs：r、Part、Q、Fld 的值 1 仍不确定（定理六）；纯读取模块的读取位不可见，申报 OUT-f 并读其输出后可见（命题四）。  
　申报限制：PE 使 r 在 𝒴₁ 内可确定（命题一）；INV-a 单独不改变 𝒴₁ 中的结论（命题二）；INV-a ∧ INV-c 在 MOD、FIN-MOD 与全读前件下使 Part 在 C\_rep ∩ C\_ac 内可判定，全观测类仍按命题三分层，未覆盖情形保持未定。这些是限制候选族，不是扩张观测集。  
　联合净零：区分形式证据变量须超出所定义的 𝒴\_L（命题五）。

七、边界实例

A.3　lawfit.py　同值律可行性的有理线性判定：模块入账在闭包上的拟合、有无可用支持的同值律（定理五（丙），命题三）

~~~python
"""定理五（丙）与命题三的判定程序：MOD 分支中模块级 HistCond 与组织条件支持的确定性。
给定模块在拍 t 的闭包 R_t 上的入账项 ĉ(s)、实际态 s_t、可用位集 Y_t，
逐律型（常数；读取位集 J 上的线性律 b + k·Σ_J s；位对 (i, j) 上的双线性律 b + k·s_i·s_j）求 (b, k)：
　ĉ(s) ≠ 0 处 b + k·g(s) = ĉ(s)；ĉ(s) = 0 处 |b + k·g(s)| ≤ ε；k 分 > 0、< 0、= 0 三种。
律值对 (b, k) 线性，故每一律型、每一符号是一个精确的有理线性可行性问题（两个变量，逐对约束化为 k 的区间）。
返回：是否存在「实际态有效且有可用支持」的同值律，是否存在「无可用支持」的同值律，以及见证。
"""
import itertools
from fractions import Fraction as Fr
def shapes(sites):
    yield ('constant', ())
    for r in range(1, len(sites) + 1):
        for J in itertools.combinations(sites, r): yield ('linear', J)
    for i, j in itertools.combinations_with_replacement(sites, 2): yield ('bilinear', (i, j))
def gval(shape, s):
    law, rd = shape
    if law == 'constant': return Fr(0)
    if law == 'linear': return sum(s[j] for j in rd)
    return s[rd[0]] * s[rd[1]]
def _interval_ok(lo, hi, sign):
    """k ∈ [lo, hi]（None 为无界）且 k 符号为 sign（+1 严格正，−1 严格负，0 为零）是否可行；返回一个可行 k 或 None。"""
    if sign == 0:
        return Fr(0) if (lo is None or lo <= 0) and (hi is None or hi >= 0) else None
    if sign > 0:
        l = lo if lo is not None and lo > 0 else None
        if hi is not None and hi <= 0: return None
        if l is None: return (hi / 2) if hi is not None else Fr(1)
        if hi is not None and l > hi: return None
        return l
    l = hi if hi is not None and hi < 0 else None
    if lo is not None and lo >= 0: return None
    if l is None: return (lo / 2) if lo is not None else Fr(-1)
    if lo is not None and l < lo: return None
    return l
def fit(pts, eps, sign):
    """pts: [(g, ĉ)]。求 (b, k)，k 的符号为 sign。返回 (b, k) 或 None。"""
    E = [(g, c) for g, c in pts if c != 0]; I = [g for g, c in pts if c == 0]
    def check(b, k):
        return all(b + k * g == c for g, c in E) and all(abs(b + k * g) <= eps for g in I)
    gs = sorted({g for g, _ in E})
    if sign == 0:
        if len({c for _, c in E}) > 1: return None
        b = E[0][1] if E else Fr(0)
        return (b, Fr(0)) if check(b, Fr(0)) else None
    if len(gs) >= 2:
        (g1, c1), (g2, c2) = [next((g, c) for g, c in E if g == gs[0]), next((g, c) for g, c in E if g == gs[1])]
        k = (c2 - c1) / (g2 - g1); b = c1 - k * g1
        return (b, k) if (k > 0 if sign > 0 else k < 0) and check(b, k) else None
    if len(gs) == 1:

        if len({c for g, c in E}) > 1: return None
        c0 = E[0][1]; lo = hi = None
        for g in I:
            d = g - g0                     # |c0 + k·d| ≤ ε
            if d == 0:
                if abs(c0) > eps: return None
                continue
            a, bnd = (-eps - c0) / d, (eps - c0) / d
            l, h = min(a, bnd), max(a, bnd)
            lo = l if lo is None else max(lo, l); hi = h if hi is None else min(hi, h)
        if lo is not None and hi is not None and lo > hi: return None
        k = _interval_ok(lo, hi, sign)
        return None if k is None else (c0 - k * g0, k)
    # 无等式：|b + k g| ≤ ε 对一切 g；取 b = 0、|k| 足够小
    rng = (max(I) - min(I)) if I else Fr(0)
    mx = max((abs(g) for g in I), default=Fr(0))
    k = Fr(sign) * (eps / (mx + 1)) if mx else Fr(sign)
    return (Fr(0), k) if check(Fr(0), k) else None
def has_avail_support(shape, k, st, Y):
    law, rd = shape
    if k == 0 or law == 'constant': return False
    if law == 'linear': return any(j in Y for j in rd)
    i, j = rd
    return (i in Y and st[j] != 0) or (j in Y and st[i] != 0)
def decide(sites, data, st, Y, eps):
    """data: [(s, ĉ(s))]，含实际态 st。返回 (存在有可用支持的同值律, 存在无可用支持的同值律, 见证们)。"""
    sup = nosup = None
    for shp in shapes(sites):
        pts = [(gval(shp, s), c) for s, c in data]
        for sign in (1, -1, 0):
            w = fit(pts, eps, sign)
            if w is None: continue
            if has_avail_support(shp, w[1], st, Y): sup = sup or (shp, w)
            else: nosup = nosup or (shp, w)
    return sup, nosup
def has_avail_cond(shape, b, k, st, Y, eps):
    """组织条件支持（数理式 D15）：作用支持，另加线性律在实际态 |c| ≤ ε 时的读取位（纯读取）。"""
    law, rd = shape
    if has_avail_support(shape, k, st, Y): return True
    if law == 'linear' and abs(b + k * gval(shape, st)) <= eps: return any(j in Y for j in rd)
    return False
def decide_cond(sites, data, st, Y, eps):
    """返回 (存在有可用组织条件支持的同值律, 存在无可用组织条件支持的同值律)。用于载体已认证族中的 Part。"""
    yes = no = None

        pts = [(gval(shp, s), c) for s, c in data]
        for sign in (1, -1, 0):
            w = fit(pts, eps, sign)
            if w is None: continue
            # 纯读取分支：线性律 k 可取 0 以外的值，也可取使实际态 |c| ≤ ε 的值；fit 只给一个见证，另试实际态无效的见证
            if has_avail_cond(shp, w[0], w[1], st, Y, eps): yes = yes or (shp, w)
            else: no = no or (shp, w)
        if shp[0] == 'linear' and yes is None:
            g0 = gval(shp, st); c0 = dict((gval(shp, s), c) for s, c in data).get(g0)
            # 实际态入账为 0 时，读取位含可用位的线性律只须同值：已由上面各符号的见证覆盖其一；补试 k = 0、b = 0
            w = fit(pts, eps, 0)
            if w is not None and any(j in Y for j in shp[1]) and abs(w[0]) <= eps: yes = (shp, w)
    return yes, no
~~~

A.6　deadzone.py　死区分解：有限集上任意目标函数分解为在锚点无效的有效项之和（引理二）

~~~python
"""引理二（死区分解）：有限集 Z ⊂ ℚ、z* ∈ Z、ε > 0，任一 F: Z → ℚ 且 F(z*) = 0，
可写成有限个 θ(z) = (b + k z)·[|b + k z| > ε] 之和，且每项 |b + k z*| ≤ ε（在 z* 处无效）。
构造：z* 右侧各间隙以两个阈值处的斜坡之差得纯台阶，斜坡由同阈值的一对单项（±ε 台阶相消）给出；左侧镜像。
"""
from fractions import Fraction as Fr
def _theta(b, k, z, eps):
    v = b + k * z
    return v if abs(v) > eps else Fr(0)
def _ramp_right(U, lam, zmin, eps):
    """λ·(z − U)·[z > U]，各项在 z ≤ U 的有限集点上无效（左尾不再激活要求斜率 < 2ε/(U − zmin)）。"""
    if lam == 0: return []
    B = 2 * eps / (U - zmin)
    N = int(abs(lam) / (B / 2)) + 1
    k2 = B / 2; k1 = k2 + lam / N
    assert 0 < k1 < B and 0 < k2 < B
    return [(eps - k1 * U, k1), (k2 * U - eps, -k2)] * N     # P+(U,k1)：k1(z−U)+ε；P−(U,k2)：−k2(z−U)−ε
def _ramp_left(L, lam, zmax, eps):
    """λ·(L − z)·[z < L]。"""
    if lam == 0: return []
    B = 2 * eps / (zmax - L)
    N = int(abs(lam) / (B / 2)) + 1
    k2 = B / 2; k1 = k2 + lam / N
    assert 0 < k1 < B and 0 < k2 < B
    return [(k1 * L + eps, -k1), (-k2 * L - eps, k2)] * N    # Q+：k1(L−z)+ε；Q−：−k2(L−z)−ε
def decompose(Z, zs, F, eps):
    Z = sorted(set(Z)); assert zs in Z and F[zs] == 0 and eps > 0
    zmin, zmax = Z[0], Z[-1]; terms = []
    right = [z for z in Z if z > zs]; left = [z for z in Z if z < zs][::-1]
    prev, fprev = zs, Fr(0)
    for z in right:
        H = F[z] - fprev
        if H:
            U, U2 = prev + (z - prev) / 3, prev + 2 * (z - prev) / 3
            lam = H / (U2 - U)
            terms += _ramp_right(U, lam, zmin, eps) + _ramp_right(U2, -lam, zmin, eps)
        prev, fprev = z, F[z]
    prev, fprev = zs, Fr(0)
    for z in left:
        G = F[z] - fprev
        if G:
            L, L2 = prev - (prev - z) / 3, prev - 2 * (prev - z) / 3
            lam = G / (L - L2)
            terms += _ramp_left(L, lam, zmax, eps) + _ramp_left(L2, -lam, zmax, eps)
        prev, fprev = z, F[z]
    for b, k in terms: assert abs(b + k * zs) <= eps
    for z in Z: assert sum((_theta(b, k, z, eps) for b, k in terms), Fr(0)) == F[z], z
    return terms
~~~

~~~python
def run_k(m, seqs):

def product_search(m1, m2):
~~~

~~~python
    dm = sm.inst(w); tr = dm.traj(h)
    for i, t in enumerate(dm.beats):
        if t in dm.W:
            for y in dm.T:
                if tr[i][y] > dm.eps: return t, y, tr[i][y]
    return None
def f_part1(sm, h, w):
    """单锚点构造（按某一实现选位与拍），作对照：它不具一致性。"""
    t, y, v = avail(sm, h, w); s2 = f_form(sm, h, y)
    return sm_with(s2, procs=s2.base.procs + (M('rd', t, y, True, 'linear', (y,), Fr(0), Fr(0)),))
def f_hdyn1(sm, h, w):
    t, y, v = avail(sm, h, w); k = 2 * (sm.base.eps + 1) / v; s2 = f_form(sm, h, y)
    return sm_with(s2, procs=s2.base.procs + (M('h+', t, y, True, 'linear', (y,), k, Fr(0)), M('h-', t, y, True, 'linear', (y,), -k, Fr(0))))
def u_pos(sm, h, sites=None, rpair=False):
    """一致形式的正向构造（全 T 全拍）：对 sites（缺省为 T）中每一位 y，入口拍登记形成；
    对每一窗拍 t、每一 y，加界内 +1·y 与 −1·y。参数与实现无关；±项同起同落，逐 ω、逐状态净转移恒等。
    任一实现只要某 y 在某窗拍大于 ε，该对项在该处有效，读取可用位 y，给出 Part 与 HDyn。
    rpair：另在每一 y 上于 t₀ 加界外 +a 与界内 −a 常数律，给出 r。"""
    sites = tuple(sites or sm.base.T); s2 = sm; a = sm.base.eps + 1
    for y in sites: s2 = f_form(s2, h, y)
    add = []
    for t in sm.base.W:
        for y in sites:
            add += [M(f'u+{y}{t}', t, y, True, 'linear', (y,), Fr(1), Fr(0)), M(f'u-{y}{t}', t, y, True, 'linear', (y,), Fr(-1), Fr(0))]
    if rpair:
        for y in sites:
            add += [M(f'r+{y}', sm.base.t0, y, False, 'constant', (), Fr(0), a), M(f'r-{y}', sm.base.t0, y, True, 'constant', (), Fr(0), -a)]
    return sm_with(s2, procs=s2.base.procs + tuple(add))
def f_q0(sm, h, x):
    keep, add = [], []
    for p in sm.base.pulses:
        if p.target == x: add.append(M(f'g{p.name}', p.beat, x, True, 'constant', (), Fr(0), p.amount, p.letter))
        else: keep.append(p)
    return sm_with(sm, pulses=tuple(keep), procs=sm.base.procs + tuple(add))

def a_hdyn0_eps0(sm, h, w):
    dm = sm.inst(w); st = dict(zip(dm.beats, dm.traj(h))); au = dict(zip(dm.beats, h)); wb = dict(zip(dm.beats, w)); new = []
    for q in sm.base.procs:
        if q.beat in dm.W and q.target in dm.T and (q.gate is None or q.gate == au[q.beat]) and q.law != 'constant':
            qi = replace(q, b=pick(q.b, wb[q.beat]), k=pick(q.k, wb[q.beat])); C = value(qi, st[q.beat])
            bsh = {o: pick(q.b, o) - C for o in sm.Omega}
            new += [replace(q, name=q.name + '·c', law='constant', reads=(), k=Fr(0), b=C), replace(q, name=q.name + '·δ', b=bsh)]
        else: new.append(q)
    return sm_with(sm, procs=tuple(new))
def reach_s(sm, t, letters):
    i = sm.base.beats.index(t); out = []
    for w in itertools.product(sm.Omega, repeat=len(sm.base.beats)):
        dm = sm.inst(w)
        for pb in itertools.product(letters, repeat=i):
            for pc in itertools.product(letters, repeat=i):
                b = dict(dm.init); c = dict(dm.init); ok = True
                for tt, ub, uc in zip(dm.beats[:i], pb, pc):
                    try: nb = dm.step(tt, b, ub); nc = dm.step(tt, c, uc)
                    except Illegal: ok = False; break
                    for o in sm.out: nc[o] = nb[o]
                    b, c = nb, nc
                if ok: out += [b, c]
    return list({tuple(sorted(s.items())): s for s in out}.values())
def a_hdyn0_eps(sm, h, w, letters=LET):
    dm = sm.inst(w); st = dict(zip(dm.beats, dm.traj(h))); au = dict(zip(dm.beats, h)); wb = dict(zip(dm.beats, w)); eps = sm.base.eps
    procs = list(sm.base.procs)
    for t in dm.W:
        u, ws = au[t], wb[t]; R = reach_s(sm, t, letters) + [st[t]]
        for q in sm.base.procs:
            if not (q.beat == t and q.target in dm.T and (q.gate is None or q.gate == u) and q.law != 'constant'): continue
            qi = replace(q, b=pick(q.b, ws), k=pick(q.k, ws))
            if qi.k == 0 or abs(value(qi, st[t])) <= eps: continue
            fun = lambda s: sum(s[j] for j in q.reads) if q.law == 'linear' else s[q.reads[0]] * s[q.reads[1]]
            c = value(qi, st[t]); Z = {fun(s) for s in R}; zs = fun(st[t])
            F = {z: ((qi.b + qi.k * z) if abs(qi.b + qi.k * z) > eps else Fr(0)) - c for z in Z}
            terms = decompose(Z, zs, F, eps)
            procs.remove(q)
            zero_at = lambda spec, val: {o: (val if o == ws else pick(spec, o)) for o in sm.Omega}
            if q.gate is None: procs += [replace(q, name=f'{q.name}@{v}', gate=v) for v in letters if v != u]
            procs.append(replace(q, name=q.name + '·o', gate=u, b=zero_at(q.b, Fr(0)), k=zero_at(q.k, Fr(0))))          # 非实际新息下保留原律
            procs.append(M(q.name + '·c', t, q.target, q.inside, 'constant', (), Fr(0), {o: (c if o == ws else Fr(0)) for o in sm.Omega}, u))
            procs += [replace(q, name=f'{q.name}#{j}', gate=u, b={o: (bb if o == ws else Fr(0)) for o in sm.Omega},
                              k={o: (kk if o == ws else Fr(0)) for o in sm.Omega}) for j, (bb, kk) in enumerate(terms)]
    return sm_with(sm, procs=tuple(procs))

def act_domain_ok(sm, h, w):
    """Act → 0 的允许实现域：窗内每拍、每一 T 位的实际净增量 D = 0 或 D > ε。否则 Act 在记录类中确定为 1。"""
    dm = sm.inst(w); tr = dm.traj(h); eps = sm.base.eps
    for i, t in enumerate(dm.beats):
        if t in dm.W:
            for y in dm.T:
                D = tr[i + 1][y] - tr[i][y]
                if D < 0 or (0 < D <= eps): return False
    return True
def a_act0(sm, h, w, letters=LET):
    """锚定形式的 Act → 0（只在允许实现域内调用）。拍 t、实际新息 ω*_t、实际字母 u 下：
    作用于 T 的窗内各过程，在 ω*_t 下换为实际态上无效的项（ε = 0：平移项；ε > 0：死区项），其实际态取值并入一个场内脉冲；
    其余 ω 下保留原律；原过程不门控时，其他字母下保留完整副本。原脉冲在 ω*_t 下并入 D，其余 ω 下保留原幅度。"""
    assert act_domain_ok(sm, h, w)
    dm = sm.inst(w); st = dict(zip(dm.beats, dm.traj(h))); au = dict(zip(dm.beats, h)); wb = dict(zip(dm.beats, w)); eps = sm.base.eps
    procs = list(sm.base.procs); pulses = list(sm.base.pulses)
    zero_at = lambda spec, ws, val: {o: (val if o == ws else pick(spec, o)) for o in sm.Omega}
    for t in dm.W:
        u, ws = au[t], wb[t]; R = reach_s(sm, t, letters) + [st[t]]
        K = defaultdict(Fr)
        for q in sm.base.procs:
            if not (q.beat == t and q.target in dm.T and (q.gate is None or q.gate == u)): continue
            qi = replace(q, b=pick(q.b, ws), k=pick(q.k, ws)); c = value(qi, st[t])
            if abs(c) <= eps: continue                       # 实际态无效的项本不计作用，保留
            procs.remove(q)
            if q.gate is None: procs += [replace(q, name=f'{q.name}@{v}', gate=v) for v in letters if v != u]
            procs.append(replace(q, name=q.name + '·o', gate=u, b=zero_at(q.b, ws, Fr(0)), k=zero_at(q.k, ws, Fr(0))))
            K[q.target] += c
            if q.law != 'constant' and qi.k != 0:
                fun = lambda s_, q=q: sum(s_[j] for j in q.reads) if q.law == 'linear' else s_[q.reads[0]] * s_[q.reads[1]]
                if eps == 0:
                    procs.append(replace(q, name=q.name + '·δ', gate=u, b={o: (qi.b - c if o == ws else Fr(0)) for o in sm.Omega},
                                         k={o: (qi.k if o == ws else Fr(0)) for o in sm.Omega}))
                else:
                    Z = {fun(s_) for s_ in R}; zs = fun(st[t])
                    F = {z: ((qi.b + qi.k * z) if abs(qi.b + qi.k * z) > eps else Fr(0)) - c for z in Z}
                    for j, (bb, kk) in enumerate(decompose(Z, zs, F, eps)):
                        procs.append(replace(q, name=f'{q.name}#{j}', gate=u, b={o: (bb if o == ws else Fr(0)) for o in sm.Omega},
                                             k={o: (kk if o == ws else Fr(0)) for o in sm.Omega}))
        for y in dm.T:
            old = [p for p in sm.base.pulses if p.beat == t and p.letter == u and p.target == y]
            A = sum((pick(p.amount, ws) for p in old if pick(p.amount, ws) > eps), Fr(0))
            D = A + K[y]
            assert D == st[t + 1][y] - st[t][y] if (t + 1) in st else True
            pulses = [p for p in pulses if p not in old]
            amt = {o: (D if o == ws else sum((pick(p.amount, o) for p in old if pick(p.amount, o) > eps), Fr(0))) for o in sm.Omega}
            if any(amt.values()): pulses.append(P(f'D{t}{y}', t, u, y, amt, False))
    return sm_with(sm, procs=tuple(procs), pulses=tuple(pulses))
def part_act(n):
    """Act → 0 锚定形式：允许域内构造并核验；允许域外核对 Act 在记录上为 1（确定，无零向孪生）。另含净减少实例与小正增量实例。"""
    rng = random.Random(71); stat = defaultdict(int); bad = []
    for trial in range(n):
        eps = rng.choice((Fr(0), Fr(1, 4)))
        sm = rand_s(rng, eps)
        h = ('a',) + tuple(rng.choice(LET) for _ in range(2))
        ws = list(itertools.product(sm.Omega, repeat=3))
        try:
            for w in ws: sm.inst(w).traj(h)
        except Illegal: continue
        w0 = ws[rng.randrange(len(ws))]
        d = sm.inst(w0).duties(h)
        if not d['Act']: continue
        if act_domain_ok(sm, h, w0):
            tw = a_act0(sm, h, w0)
            if all_laws(tw, LET) != all_laws(sm, LET): bad.append(('Act', '分布不同')); continue
            e = tw.inst(w0).duties(h)
            if e['Act'] or not tw.inst(w0).crosscheck(h)[0]: bad.append(('Act', '职责')); continue
            stat[f'允许域内：锚定 Act → 0（ε = {eps}）'] += 1
        else:
            stat[f'允许域外（某拍 D < 0 或 0 < D ≤ ε）：Act 在记录上为 1，不构造零向孪生（ε = {eps}）'] += 1
    # 实例 B5：入口脉冲 1，下一拍 −x/2，净增量 −1/2
    D1 = SModel(Model(('x',), ('x',), {'x': Fr(0)}, 0, 0, Fr(0), (P('s', -1, 'a', 'x', Fr(1), True),),
                      (M('decay', 0, 'x', True, 'linear', ('x',), Fr(-1, 2), Fr(0)),)), frozenset(), (0,))
    h1 = ('a', 'rest'); assert not act_domain_ok(D1, h1, (0, 0)) and D1.inst((0, 0)).duties(h1)['Act']
    # 小正增量：ε = 1/4，入口脉冲 1，下一拍 +x/8，净增量 1/8 ∈ (0, ε]
    D2 = SModel(Model(('x',), ('x',), {'x': Fr(0)}, 0, 0, Fr(1, 4), (P('s', -1, 'a', 'x', Fr(1), True),),
                      (M('g', 0, 'x', True, 'constant', (), Fr(0), {0: Fr(1, 8)}),)), frozenset(), (0,))
    # 常数 1/8 本身不大于 ε，不入账；改用 +x/2 与 −3x/8 两项：各自有效，和为 1/8
    D2 = SModel(Model(('x',), ('x',), {'x': Fr(0)}, 0, 0, Fr(1, 4), (P('s', -1, 'a', 'x', Fr(1), True),),
                      (M('g1', 0, 'x', True, 'linear', ('x',), Fr(1, 2), Fr(0)), M('g2', 0, 'x', True, 'linear', ('x',), Fr(-3, 8), Fr(0)))), frozenset(), (0,))
    tr2 = D2.inst((0, 0)).traj(h1); assert tr2[-1]['x'] - tr2[-2]['x'] == Fr(1, 8)
    assert not act_domain_ok(D2, h1, (0, 0)) and D2.inst((0, 0)).duties(h1)['Act']
    # 允许域正例：D = 0（+x/2 与 −x/2）与 D > ε（+x）
    for name, procs in (('D = 0', (M('g1', 0, 'x', True, 'linear', ('x',), Fr(1, 2), Fr(0)), M('g2', 0, 'x', True, 'linear', ('x',), Fr(-1, 2), Fr(0)))),
                        ('D > ε', (M('g', 0, 'x', True, 'linear', ('x',), Fr(1), Fr(0)),))):
        sm3 = SModel(Model(('x',), ('x',), {'x': Fr(0)}, 0, 0, Fr(1, 4), (P('s', -1, 'a', 'x', {0: Fr(1), 1: Fr(2)}, True),), procs), frozenset(), (0, 1))
        for w in itertools.product((0, 1), repeat=2):
            assert act_domain_ok(sm3, h1, w) and sm3.inst(w).duties(h1)['Act']
            tw = a_act0(sm3, h1, w)
            assert all_laws(tw, LET) == all_laws(sm3, LET) and not tw.inst(w).duties(h1)['Act']
        stat[f'允许域正例 {name}（两种随机前态，逐一锚定）'] += 1
    stat['允许域外实例：净减少 −1/2、小正增量 1/8（ε = 1/4），Act 均确定为 1'] += 1
    for k in sorted(stat): print(f'  {k}：{stat[k]} 例')
    print('  违例', len(bad)); [print('  ', b) for b in bad[:5]]
    return not bad
def part1_2(n):

        if avail(sm, h, w0):
            if d['HDyn']:
                tw = a_hdyn0_eps0(sm, h, w0) if eps == 0 else a_hdyn0_eps(sm, h, w0)
                name = '锚定 HDyn→0（ε=0）' if eps == 0 else '锚定 HDyn→0（ε>0）'
                check(name, tw, [w0], lambda e: not e['HDyn'])
                others = [w for w in ws if w != w0 and sm.inst(w).duties(h)['HDyn'] and tw.inst(w).duties(h)['HDyn']]
                if others: tally['当前锚定构造在非锚定实现上 HDyn 仍为 1（只说明该构造不具一致性，不证明一致孪生不存在）'] += 1
        for x in sm.base.T:
            if all(s[x] > eps for s in tr):

                check('冻结 q→0', f_q0(sm, h, x), ok_ws, lambda e, x=x: not e['q'][x])
            if tr[-1][x] > eps:
                ok_ws = [w for w in ws if sm.inst(w).traj(h)[-1][x] > eps]
                check('冻结 q→1', f_form(sm, h, x), ok_ws, lambda e, x=x: e['q'][x])
    for k in sorted(tally): print(f'  {k}：{tally[k]} 例')
    print('  违例', len(bad)); [print('  ', b) for b in bad[:8]]
    return not bad
# ---------- 定理八：二拷贝受控概率机的线性张成判定 ----------
def inst_beat(sm, t, o):
    return sm.inst(tuple(o if tt == t else sm.Omega[0] for tt in sm.base.beats))
def push(sm, state, op):
    """state = (拍号, 基线态, 对照态) 或 'END'。返回 {读数: {新状态: 概率}}。"""
    out = defaultdict(lambda: defaultdict(Fr))
    if state == 'END' or state[0] > sm.base.t1:
        out['—']['END'] += 1; return out
    t, b, c = state; b, c = dict(b), dict(c); pr = Fr(1, len(sm.Omega))
    for o in sm.Omega:
        dm = inst_beat(sm, t, o)
        try: nb = dm.step(t, b, op[0]); nc = dm.step(t, c, op[1])
        except Illegal: out['不合法']['END'] += pr; continue
        for x in sm.out: nc[x] = nb[x]
        rd = (tuple(nb[x] for x in dm.sites if x not in sm.out), tuple(nc[x] for x in dm.sites if x not in sm.out))
        out[rd][(t + 1, tuple(sorted(nb.items())), tuple(sorted(nc.items())))] += pr
    return out
def equivalent(sm1, sm2, letters):
    ops = list(itertools.product(letters, repeat=2))
    s0 = lambda sm: (sm.base.t0 - 1, tuple(sorted(sm.base.init.items())), tuple(sorted(sm.base.init.items())))
    start = {(0, s0(sm1)): Fr(1), (1, s0(sm2)): Fr(1)}
    basis = []                                        # 已约化的基：[(主元, 向量)]
    def reduce(v):
        v = dict(v)
        for piv, bv in basis:
            if piv in v and v[piv] != 0:
                f = v[piv] / bv[piv]
                for k, x in bv.items(): v[k] = v.get(k, Fr(0)) - f * x
                v = {k: x for k, x in v.items() if x != 0}
        return v
    def func(v): return sum(x for (side, _), x in v.items() if side == 0) - sum(x for (side, _), x in v.items() if side == 1)
    queue = [(start, ())]
    while queue:
        v, word = queue.pop()
        r = reduce(v)
        if not r: continue
        piv = next(iter(r)); basis.append((piv, r))
        if func(v) != 0: return False, word
        for op in ops:
            grouped = defaultdict(dict)
            for (side, st), x in v.items():
                smx = sm1 if side == 0 else sm2

def joint_can_finish(mon, qb, qc, steps):

    OPS_G[0] = ops
    B = len(sm1.base.beats)
    rd0 = lambda sm: tuple(sm.base.init[x] for x in sm.base.sites if x not in sm.out)
    if rd0(sm1) != rd0(sm2): return False, ('初始读数',)
    start = {}
    for side, sm in ((0, sm1), (1, sm2)):
        st = (sm.base.t0 - 1, mon[2], mon[2], tuple(sorted(sm.base.init.items())), tuple(sorted(sm.base.init.items())))
        start[(side, st)] = Fr(1)
    basis = []
    def reduce(v):
        v = dict(v)
        for piv, bv in basis:
            if piv in v and v[piv] != 0:
                f = v[piv] / bv[piv]
                for k, x in bv.items(): v[k] = v.get(k, Fr(0)) - f * x
                v = {k: x for k, x in v.items() if x != 0}
        return v
    def func(v): return sum(x for (sd, _), x in v.items() if sd == 0) - sum(x for (sd, _), x in v.items() if sd == 1)
    queue = [(start, ())]
    while queue:
        v, word = queue.pop()
        r = reduce(v)
        if not r: continue
        basis.append((next(iter(r)), r))
        if func(v) != 0: return False, word
        for ob in ops:
            for oc in ops:
                grouped = defaultdict(dict)
                for (side, st), x in v.items():

                    if t > sm.base.t1 or nqb is None or nqc is None: continue
                    rem = sm.base.t1 - t
                    if not joint_can_finish(mon, nqb, nqc, rem): continue
                    pr = Fr(1, len(sm.Omega))
                    for o in sm.Omega:
                        dm = inst_beat(sm, t, o)
                        try: nb = apply_op(dm, t, dict(b), ob); nc = apply_op(dm, t, dict(c), oc)
                        except Illegal: grouped['不合法'][(side, 'END')] = grouped['不合法'].get((side, 'END'), Fr(0)) + x * pr; continue
                        for z in sm.out: nc[z] = nb[z]
                        rd = (tuple(nb[z] for z in dm.sites if z not in sm.out), tuple(nc[z] for z in dm.sites if z not in sm.out))
                        key = (side, (t + 1, nqb, nqc, tuple(sorted(nb.items())), tuple(sorted(nc.items()))))
                        grouped[rd][key] = grouped[rd].get(key, Fr(0)) + x * pr

def brute_full(sm1, sm2, ops, mon):

    if rd0(sm1) != rd0(sm2): return False

        for o in seq:
            q = mon[1].get((q, o))
            if q is None: return False
        return q in mon[3]
    seqs = [x for n in range(B + 1) for x in itertools.product(ops, repeat=n) if accepted(x)]
    def law(sm, hb, hc):
        ws = list(itertools.product(sm.Omega, repeat=len(hb))); pr = Fr(1, len(ws)); out = Counter()

            dm = sm.inst(w); b = dict(dm.init); c = dict(dm.init); rd = []

                try: nb = apply_op(dm, t, b, ob); nc = apply_op(dm, t, c, oc)

        return out
~~~
