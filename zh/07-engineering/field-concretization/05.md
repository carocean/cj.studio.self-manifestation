自显论·工篇·场具化组式第五 v1.0

# 场具化可达式

一、式种申报  
本篇是可达式（成立证明附式）。唯一任务：在固定的可达工作上下文中，自申报初态出发，只用申报的许可操作、只经同一谱系的合法后继，判明已达构造强度的沉积场目标能否到达；能到达者给出路径与步数或预算的界，不能到达者给出不可达见证。  
本篇的结论分四组。  
　1．资格目标的信息结构：沉积场资格不是原始状态的函数（定理一）；在申报模型类内，资格由窗起点状态、形成与标记记录、窗内输入决定（引理一）。  
　2．有限判定与路径界：物理可达集有限时，资格可达可判定，最短路径长不超过 (2\|I\| + 1)N − 1 + w（定理二）；反事实级目标在钳定闭包有限时有相应的结点界（推论一）。  
　3．形成路径：资格路径须含有效界外改变（引理二）；《场具化一般式》见证 χ₀ 与《沉积场判定式》实例甲的形成路径、最少拍数与不可达见证（定理三、命题二）；势型代表例的入口阶段（命题三）。  
　4．受控排序：在局部可交换族的限定族中，每拍幅度受限与累计预算受限两种制度下的反序可达与锁定障碍（定理四）。  
另有：许可集扩张的申报规则（命题四）、可达而不可证（推论二）、抹迹界（引理三）、随机分支的申报（第十一节）。  
强度定位：可达在法篇第二编第五章的强度顺序中位于构造之后、实现之前。可达结论不兼含构造结论；「存在一条许可路径」不等于稳定式的保持，也不等于必然式的全称到达；可达不等于物质实现。  
理论增量与阻力：资格目标依赖形成与标记记录及反事实史对，不能写成原始状态集上的可达；「系统 × 记录」的乘积构造本身是已有的形式方法，本篇的增量在于沉积场资格所需的具体记录、其充分性与量词保持，以及记录单调所给的线性路径界。受控排序部分在指定模型与操作制度下给出显式不变集与预算界，不是一般最优控制理论。初等结论作引理、推论或申报规则，不作主定理。

二、前提

### 2.1　先行事实

　F1　沉积场是信号在介质中留下的迹应集合，以及这一集合在历史动力作用下变换的组织方式及其活动（《沉积场本体定义》）。  
　F2　《场具化一般式》v1.0：三项职责 TraceSet、Part、HDyn，第七节界内自反馈型；第六节的见证 χ₀ 与「三项职责可同时实现」的构造见证（Canonical F\*，《最小沉积场构造式》v1.3）。  
　F3　《场具化数理式》v1.0：D1 三值与强 Kleene 规则；D10—D20 的 F 层；4.2 数值递推；5.1 求解器；定理一（同一申报实例与 T、相同状态轨迹，两史的机制事件不同而 Act、HistCond 与资格读数不同）。  
　F4　《沉积场判定式》v1.0：3.1 判定实例与合法史 𝓗；3.3 钳定；3.4 第一层谓词与第二层职责；3.5 观测集；4.2 实例协议；定理四（固定操作配置下的剖面不变）；7.5 实例甲。  
　F5　《场具化不可区分式》v1.0：观测集阶梯；定理六（载体与来源标记在所定义的观测集内不可见）。  
　F6　《势型分级式》v1.0：局部可交换族、域引理、入口脉冲与一拍流映射、T4（易位定理：严格反序须先合后分，约束静置流段）。

### 2.2　构造进入条件

可达式的进入条件是目标已达构造强度（法篇第四编第九章）。本篇的目标对象只取以下已有构造：  
　（一）χ₀（《场具化一般式》第六节），显式给出并逐项核对；  
　（二）判定式实例甲（χ\_ext、χ\_in、χ\_frz），模型显式，判词逐项求值；  
　（三）《势型分级式》6.3—6.4 的局部族代表例，状态、净律与 Tr^静 见证显式给出；  
　（四）定理一、定理二、推论一、命题四、推论二所用的有限模型，在本篇正文或附录 A 中显式给出，逐项求值。  
以其他对象为目标者，须先登记「目标已达构造强度」为开放前件，只作条件可达陈述；可达制度不反向代证构造强度。Canonical F\* 的续行为随机，列于第十一节，不进入主定理。

### 2.3　范围的分界

　（一）目标的构造属构造式；  
　（二）到达后的保持、退出与复归属稳定式；  
　（三）一切或几乎一切轨迹的必然到达属必然式；  
　（四）在真实资源与材料下的落成属实现式；  
　（五）可达结论不构成任何物质宿载的资格认证；模拟可达不等于物质宿载已获资格。

三、可达工作上下文与许可操作申报  
定义一（可达工作上下文 𝒞\_reach）。可达判断须固定以下各项：  
　模型实例与表示层（F 层、R 层，或连续模型经一拍流映射进入的拍式读法）；  
　初态及初始记录（缺省为空；非空者须申报为合法前史的记录）；  
　许可集 Π；  
　合法史制度（全部有限词，或申报的监控自动机所识别的语言）；  
　禁止操作；  
　谱系（同一申报宿载实例）；  
　时间域（有限、最终、渐近）；  
　控制者信息（开环输入词、完全状态反馈、仅凭观测历史的策略）。  
改变其中任何一项，须重新判可达。  
定义二（许可集阶梯）。  
　Π₀：申报字母表，即信号脉冲与静置；  
　Π₁ = Π₀ ∪ {撤供}；  
　Π₂ = Π₁ ∪ {LOC（申报设定域）}；  
　Π₃ = Π₂ ∪ {MOD}。  
工程许可集为 Π₀、Π₁；Π₂、Π₃ 只用于讨论扩张效应。改变输入幅度的上界是另行申报的控制制度，不是原许可集。许可与禁止按作用途径区分：许可的是经申报入口施加信号、由宿载自身响应形成的改变；禁止的是绕过该机制直接覆盖内部状态，包括直接写入或覆盖迹应与沉积状态、直接设置资格变量或标签、复制覆盖、重初始化或替换宿载、隐藏控制器。每一具体模型须写明申报入口位与入口作用途径。  
定义三（字母门控 F 模型类 𝔐\_GF）。判定式机制转移模型的有限确定子类：每一字母决定本拍的脉冲表与过程表。合法性前件：  
　位名非空互异；ε、初态、脉冲幅度为非负有理数；  
　字母表有限且含静置；同一字母内过程标号互异；  
　过程律属数理式 D12 三类，线性律读取位非空，双线性律恰两位，常数律无读取位；读取位与作用对象属位集；  
　cert\_eff = 1；cert\_read 与直接路径边认证取值于 {1, 0, ⊥}；Γ\_closed = 闭合；Ident、HistEv 申报为 1；  
　窗长 w ≥ 1。  
不合法者拒绝，不进入求值；后态出现负值者越出定义域。形成与标记的登记严格按数理式 D16：已认证有效脉冲一律计入 Form；有效正分项使拍前深度不大于 ε 的位成为留迹元素；界外脉冲与界外载体过程的有效分项计入 Mark。本篇求值器与《场具化数理式》附录 A.1 的上游求值器在可直接比较的范围内逐项相同（附录 B.1）。  
定义四（窗读法 RD）。对 𝔐\_GF 的输入史 h 与窗长 w，取以下 F 运行：W 为 h 的末 w 拍；W 之前各拍为形成史，其按 D16 登记的 Form、Mark 记录在 F 中以入口拍记录表示（数理式 D2）；W 的起点状态为形成史的末态。对每个非空 T ⊆ I 得三值读数 Q\_F(h, T)，定义资格读数  
　　Fld\_RD(h) = ⋁^K\_{∅ ≠ T ⊆ I} Q\_F(h, T)，  
其中 ⋁^K 为强 Kleene 析取（数理式 D1）：有一项为 1 则为 1，全为 0 才为 0，其余为 ⊥。资格正判目标是 Fld\_RD(h) = 1，正判可达指 ∃h ∈ 𝓗 \[Fld\_RD(h) = 1\]；正判目标等价于 ∃T \[Q\_F(h, T) = 1\]，但这一等价不重新定义三值读数 Fld\_RD，不存在 Q\_F = 1 的史可能是 Fld\_RD = ⊥（尚未认证），不读作 0。下文简记 Fld 均指 Fld\_RD；物质层回读仍携上游认证前件。界内自反馈型另要求存在 B 内过程，使 \[tgt ∈ T\] ∧ Act ∧ HistCond，且 HistCond 所经途径在 B 内（一般式第七节）；在 𝔐\_GF 的直接证据边下，途径由 T 内读取位直达该 B 内过程，此条随之成立。RD 只用于 𝔐\_GF 的实际形成史，不把一般 R 层历史的来源路径压为位集摘要。  
定义五（目标阶梯）。  
　状态目标：到达申报的状态、排序、份额区域或状态势向。宿载势型是固定净律与申报域的结构性质，不是轨迹到达的状态，不作状态目标；研究势型改变须另申报参数或动力律的改变。  
　资格目标：RD 下资格读数 Fld\_RD = 1（正判），或界内自反馈型的三值读数为 1。  
　可证资格目标：资格目标在申报观测集内可由认证读数判 1。

四、资格目标的信息结构  
定理一（原始状态不足）。存在 𝔐\_GF 中的模型 M\_B1、初态与两条许可史，二者同谱系、逐拍状态轨迹相同、终态相同，而 RD 下 Fld 一为 1、一为 0。因此资格目标不可表为原始状态集或原始轨迹集上的可达。  
证明。M\_B1：位 x、o，ε = 0；字母 w 为界外脉冲 +1 → x；字母 b 为 B 内门控常数律过程 +1 → x；字母 c 运行 B 内线性律过程 opt（读 x，分项 1 − x/2，作用于 x）与 B 内纯读取过程 rd（读 x，作用于 o，分项 0）；初态 (0, 0)，初始记录为空。史 (w, c) 与 (b, c)，W 为末 1 拍。两史第一拍后都有 x = 1 且 Form(x) ≠ ∅；第二拍 opt 读已形成的 x，分项 1/2 有效，两史窗末态都是 (3/2, 0)。前者 Mark(x) ≠ ∅，T = {x} 时 Src = Ret = 1，rd 承担 Part，opt 承担 HDyn，Q\_F = 1；后者 Mark = ∅，对一切 T 有 Src = 0，Fld = 0（附录 B.2）。∎  
与《场具化数理式》定理一的关系：该定理在同一申报实例上以不同的机制事件给出同轨迹异资格；这里机制由字母门控，模型与初态固定，两史只差输入词，是可达语境下两条许可史之间的直接见证。本定理的结论限于「原始」状态与轨迹不足；加入记录后，资格目标可化为扩展状态上的目标（引理一）。  
命题一（信息分级）。在固定模型、参数与操作配置下，资格判词按所需信息分为三级：  
　（1）状态级：Wr 是当前状态连同既定模型与操作配置 C\_op 的函数。在可达语境下以到达态为新申报起点所问的 Tr^静，即该点的 Wr。  
　（2）记录级：RD 下的 Q\_F、Fld 与界内自反馈型，所需信息为窗起点状态、按 D16 登记的形成与标记位集、窗内事件原子、申报原子（cert\_read、路径边、Ident、HistEv）。  
　（3）反事实级：Hist^静、Hist^撤 与历史式 Act\_𝓟^h，所需信息为实际侧与参照侧（被检段以静置替换）的成对状态及判定式 3.3 的值钳定。参照侧是认证用的计算分支，不在宿载上执行。  
本命题是分类说明，不是「最少信息」的普遍不可约性定理。  
引理一（RD 的充分性）。在 𝔐\_GF（直接证据边子类）中，RD 下各 T 的 Q\_F、Fld 与界内自反馈型，都是 (s\_{n−w}, Form\_\<, Mark\_\<, 窗词) 的函数；其中 Form\_\<、Mark\_\< 是形成史按 D16 登记的形成位集与标记位集。  
证明。数理式 5.1 的求解器逐拍只读：拍前状态；早于当拍的形成记录（决定可用位 D17）；标记记录（决定 Src）；申报原子。入口记录的作用只有三处：使相应位「此前已形成」，使 Src 取值，使 Ret 中 Form ≠ ∅ 成立。Form、Mark 按 D16 只增不减。对窗内拍数归纳，各拍的事件原子相同，故窗末各 T 的 Q\_F 相同。Fld\_RD 对有限个非空 T 取强 Kleene 析取（定义四），三值语义与上游相同；正判 Fld\_RD = 1 当且仅当某个 T 的 Q\_F = 1，量词 ∃T 不丢失。∎

五、有限判定与路径界  
定理二（有限确定模型上的资格可达）。设 M ∈ 𝔐\_GF，合法史为全部有限词，初始记录为空，自 s₀ 经申报字母可达的物理状态有限，共 N 个。  
　（1）增广结点 (s, Form, Mark) 自 (s₀, ∅, ∅) 的可达集有限，结点数不超过 N·4^{\|I\|}。增广后的结点数可以超过 N。  
　（2）RD 下「存在许可史使 Fld = 1（或界内自反馈型 = 1）」可判定。  
　（3）若存在，则最短满足史长不超过 (2\|I\| + 1)N − 1 + w。  
　（4）计数：增广结点不超过 N·4^{\|I\|}；每一结点枚举 \|U\|^w 个窗词；每一窗的求值为 O(2^{\|I\|}·w·\|事件\|) 次单位代价有理运算。这是运算计数，不是位复杂度界。  
证明。（1）物理后继只依赖物理状态与字母，记录位集各取 2^{\|I\|} 种。（2）由引理一，资格是增广结点与窗词的函数；在有限增广图上广度搜索，再对每一结点枚举有限个窗词，搜索完全且可靠。（3）Form、Mark 只增，最短路径上 (Form, Mark) 至多改变 2\|I\| 次；在记录不变的段内，物理状态若重复，则增广结点重复，截去回路得更短路径，故每段至多 N − 1 步；形成段不超过 (2\|I\| + 1)(N − 1) + 2\|I\| = (2\|I\| + 1)N − 1，再加窗长 w。∎  
本界不覆盖带一般历史监控语言的模型；非空初始记录须作为搜索初结点另行带入，本篇程序只实现空初始记录。  
有限核验（附录 B.1、B.2）：本篇求值器与上游求值器在「入口拍 1 拍 + W」的史上（此时 RD 与上游 F 运行同义）对每个非空 T 比较 Q：400 个随机模型、29979 条史、64107 个 (史, T) 对逐项相同，覆盖初态为正的位上的有效脉冲、正负有效分项、形成早于读取、纯读取、零系数、认证为 0 或 ⊥、越出定义域的史（3630 条）。一般形成史的压缩由引理一的证明承担，不由有限比较代替。增广搜索对照：300 个有界随机模型中，109 个正例的最短长度与按长度递增的暴力枚举一致（最短长度最大 4）；191 个负例由（2）判不可达，暴力只核至长度 5；形成段最长距离与 N 之比最大为 2.00，说明结点界不能以 N 代替。该对照与搜索共用求值器，只校验搜索逻辑。  
推论一（反事实级目标的结点与路径界）。适用子类：确定性模型；原动力自 s₀ 的可达集有限（N 个状态），且参照侧钳定闭包有限（界内取值集 I′ 有限）；转移可算；合法史为全部有限词；被检段为单一位置；q 固定。则 Hist^静 目标的成对结点（阶段，实际态，参照态）在被检位置之前不超过 N，之后由（实际态，参照侧界内值）决定，不超过 N·\|I′\|，其中 I′ 是钳定后参照侧的界内取值集，不是原动力可达集的投影；最短满足史长不超过 N + N·\|I′\| − 1，另加 q 拍静置尾段。若申报正则合法史，须把两侧监控态与阶段并入结点并乘相应因子，这一情形不在本推论内（U3）。  
证明。被检位置前两侧输入相同，状态相同；之后参照侧的界外分量每步被覆写为实际侧的值，故参照态由实际态与参照侧界内值决定。最短路径不重复结点。∎  
界限见证（附录 B.3）：M5 的原动力可达状态只有 N = 2 个，而实际史 w·a^j 下参照侧依次为 (0, 1)、(2, 1)、(4, 1)、…，钳定闭包无限；故 N 有限不能代替闭包有限。M1（判定式定理一 (a2) 的见证模型）在「实际字母对静置」的协议下成对结点 5 个，参照侧进入原动力不可达的混合态 (0, 1)；此数属本推论的限制协议，与判定式上游 Tr 史对搜索的结点数不是同一算法量。M\_H 的最短 Hist^静 = 1 工程史为 (a)，与暴力枚举一致。工程上只执行实际史；参照侧在模型模式中是计算分支，在实测模式中须以复制品或可复位宿载实现（判定式 3.2）。

六、形成路径  
引理二（信号必经）。在 RD 下且初始记录为空时，Fld = 1 的任一许可史必含一次作用于某 T 位的有效界外改变（界外脉冲或界外载体过程的有效分项）。  
证明。Fld = 1 ⇒ 存在 T 使 Src = 1 ⇒ 某 i ∈ T 有 Mark(i) ≠ ∅（数理式 D19、D16）。∎  
若初始记录申报为带 Mark 的合法前史，本引理不适用。

八、受控排序  
限定族：《势型分级式》局部可交换族 β = 1，n = 2，ẋᵢ = (I·sᵢ)^α − λxᵢ；入口脉冲只施于次位 x₂；一拍为脉冲后接时长 Δ 的静置流。记 M₁ = max(x₁(0), I^α/λ)，ρ₀ = x₂/x₁ \< 1。目标是严格反序 x₂ \> x₁。T4、T5 只约束静置流段；含脉冲跳变的受控路径，跳变段另算。各结论是充分界或障碍，不是精确临界值或最优控制。  
定理四（限定族的排序可达与锁定障碍）。  
　（a）每拍幅度受限，α ≤ 1：任意 η \> 0 都可达严格反序，拍数不超过 ⌊(1 − ρ₀)M₁/η⌋ + 1。  
　（b）每拍幅度受限，α \> 1：取 A、b 满足 (L1) I^α b^{α−1}/A^α ≤ λ/2，(L2) A ≤ (I^α/λ)(A/(A + b))^α，b \< A，并令 η ≤ b(1 − e^{−λΔ/2})。则 V = {x₁ ≥ A，x₂ ≤ b·e^{−λΔ/2}} 在拍映射下不变，自 V 不可反序。A = I^α/(2λ) 时，取足够小的 b 即满足各条件。  
　（c）通用充分条件：若 η \> M(1 − e^{−λΔ})，M = max(x₁(0), I^α/λ)，则自 X 内任一初态可达反序。  
　（d）累计预算受限，α \< 1：任意 B \> 0 都可达反序。  
　（e）累计预算受限，α = 1：B \< (1 − ρ₀)s₁(0)S\_min/(1 + (1 − ρ₀)s₁(0)) 时不可达反序，其中 S\_min = min(S₀, I/λ)。  
　（f）累计预算受限，α \> 1：记剩余预算为 r，集合 {x₁ ≥ A，x₂ + r ≤ b}（A、b 满足 (L1)(L2) 与 b \< A）在静置与脉冲下都不变，自其中不可反序。  
证明。  
（a）每次脉冲使 ρ = x₂/x₁ 增加 η/x₁ ≥ η/M₁：脉冲不改 x₁，静置流下 x₁ ≤ M₁（域引理 (i)）。流段在 ρ \< 1 时不使 ρ 减小：份额差式 ṡ₁ = s₁s₂I^α(s₁^{α−1} − s₂^{α−1})/S 表明 α = 1 时份额不变、α \< 1 时 s₁ 下降。n 次脉冲后 ρ ≥ ρ₀ + nη/M₁，n = ⌊(1 − ρ₀)M₁/η⌋ + 1 时严格大于 1。α \< 1 的流不跨并列线（对称性与唯一性），反序发生在跳变段，与 T4 相容；跨过并列后，正域流的唯一性保持严格排序。  
（b）(L2) 使 x₁ = A 时 ẋ₁ ≥ 0，故 {x₁ ≥ A} 正向不变；S ≥ x₁ ≥ A，x₂ ≤ b 时 ẋ₂ ≤ x₂(I^α x₂^{α−1}/A^α − λ) ≤ −(λ/2)x₂，故静置段 x₂ 下降且末值不超过入段值乘 e^{−λΔ/2}；脉冲后 x₂ ≤ b·e^{−λΔ/2} + η ≤ b。全程 x₂ ≤ b \< A ≤ x₁。  
（c）取 y\_k 为第 k 次脉冲刚施完时的 x₂。静置段写入非负，x₂ 至多以 e^{−λΔ} 衰减，故 y\_{k+1} ≥ e^{−λΔ}y\_k + η，y\_k ≥ η(1 − e^{−kλΔ})/(1 − e^{−λΔ})，其极限 η/(1 − e^{−λΔ}) \> M ≥ x₁。故反序至迟发生于第 k 拍，k 为满足 η(1 − e^{−kλΔ})/(1 − e^{−λΔ}) \> M 的最小正整数，即 k \> −ln(1 − M(1 − e^{−λΔ})/η)/(λΔ)。反序在脉冲后检测。  
（d）静置时 s₁ 单调；状态有正下界与上界，紧性排除非并列的极限，故 s₁ → 1/2，ρ → 1。待 1 − ρ \< B/M₁ 后施一次幅度 B 的脉冲，ρ 增加 B/x₁ ≥ B/M₁，反序。等待拍数依 s₁ 趋 1/2 的速率而定，其界未决（第十五节 U1）。  
（e）α = 1 时流不改份额，Ṡ = I − λS，脉冲只增大 S，故 S ≥ S\_min；脉冲使 s₁ 乘以 S/(S + η) ≥ 1 − η/S\_min，故 s₁ ≥ s₁(0)(1 − B/S\_min)，x₁ ≥ s₁(0)(S\_min − B)。流不改 ρ，第 k 次脉冲使 ρ 增加 ηₖ/x₁ ≤ ηₖ/(s₁(0)(S\_min − B))，故全程 ρ ≤ ρ₀ + B/(s₁(0)(S\_min − B))。所给 B 等价于 B \< (1 − ρ₀)s₁(0)(S\_min − B)，使右端小于 1，故 ρ 始终小于 1，不可反序。  
（f）静置使 x₂ 下降、r 不变；幅度 η 的脉冲使 x₂ 增加 η、r 减少 η。故 x₂ + r ≤ b 保持，从而 x₂ ≤ b，(L1)(L2) 的估计成立，x₁ ≥ A \> b ≥ x₂。本证明覆盖一切施用策略。∎  
数值对照（附录 B.6，I = λ = 1，Δ = 1/2）：(a) 12 组反序拍数均在界内；(b) 40 个 V 内初态各 60 拍，V 保持；(c)—(f) 均相符。数值只作对照。  
本定理表明：平型（α = 1）与减型（α \< 1）在每拍幅度受限下同为任意小幅可达，在累计预算下不同；涨型（α \> 1）在两种预算下都有障碍。势型不单独决定排序可达性，预算类型、作用位置、拍长与当前状态都进入结论。结论限于本节限定族；一般 Φ 与黏菌两管模型未证。涨型锁定的定性内容在递增收益文献中已有（Arthur 1989），本定理的内容是本节模型与操作制度下的显式不变集与预算界。

十、抹迹界  
引理三（抹迹的有限时间界）。  
　（1）连续时间、λ \> 0、写入 w ≥ 0：x(t) ≥ x(0)e^{−λt}，正迹在有限时间内不归零。  
　（2）w ≡ 0、ε \> 0、x₀ \> ε：t\* = ln(x₀/ε)/λ。非严格目标 x ≤ ε 的拍数为 ⌈t\*/Δ⌉；严格目标 x \< ε 的拍数为 ⌊t\*/Δ⌋ + 1，t\*/Δ 为整数时比非严格目标多一拍（每拍因子 1/2、x₀ = 1、ε = 1/8 时分别为 3 拍与 4 拍）。附注（前件之外）：x₀ ≤ ε 时非严格目标为 0 拍；x₀ = ε 且 w ≡ 0 时严格目标恰需一拍。  
　（3）共同前件 λ \> 0、Δ \> 0、ε \> 0、0 ≤ w ≤ w̄，按初态分为互斥三支：  
　　已在阈下——x₀ ≤ ε 时，非严格目标的最短时间与拍数为 0；本句不主张此后保持在阈下。  
　　保证可达——x₀ \> ε 且 w̄/λ \< ε 时，t\* = ln((x₀ − w̄/λ)/(ε − w̄/λ))/λ \> 0（分子分母都为正，且分子大于分母），对一切这样的 w，t ≥ t\* 时 x(t) ≤ ε，拍数可取 ⌈t\*/Δ⌉。  
　　存在坏写入——x₀ \> ε 且 w̄/λ ≥ ε 时，取 w ≡ w̄：x₀ \> w̄/λ 时 x(t) \> w̄/λ ≥ ε，ε \< x₀ ≤ w̄/λ 时 x(t) ≥ x₀ \> ε，x ≤ ε 都有限不可达，不能保证有限到达。  
　（4）F 层线性退浅 c = −κs（有效当且仅当 κs \> ε）：在 ε \> 0、0 \< κ \< 1、s₀ \> ε/κ 下，s 停滞于 ((1 − κ)ε/κ, ε/κ\]；0 \< κ ≤ 1/2 时停滞值大于 ε，单凭此退浅不能把迹应抹至 ε 以下。退化情形：ε = 0、0 \< κ \< 1、s₀ \> 0 时无有限停滞，s\_n = (1 − κ)ⁿs₀；κ = 1 时，s₀ \> ε 一步到 0，s₀ ≤ ε 保持原值；κ = 0 时不退浅，区间公式不适用。  
　（5）固定量截零退浅 max{0, d − λ\_d}（Canonical F\* 所用，非 F 层比例退浅）：无写入时 ⌈d/λ\_d⌉ 拍内到 0。  
证明。（1）比较原理。（2）（3）由 ẋ = w − λx 的显式解与比较原理；严格目标的取整按 t\*/Δ 是否为整数分列。（4）末次有效步前 s \> ε/κ，之后 s' = (1 − κ)s \> (1 − κ)ε/κ；κ ≤ 1/2 时 (1 − κ)/κ ≥ 1。（5）直接计算。∎  
本引理只供向稳定式的接口，不承担复归的保证。数值例见附录 B.6。

十一、随机分支（申报，不签结论）  
随机族中资格目标的可判定性未决；外部方法的边界如下：  
　开环输入词：概率自动机的严格阈值空语言问题不可判定（Paz 1971；Rote, Probabilistic Finite Automaton Emptiness is Undecidable, 2024）。  
　仅凭观测历史的策略：无穷时域规划与部分可观测的相关问题不可判定（Madani, Hanks, Condon, AAAI 1999, 541—548）。  
　完全状态反馈：有限马尔可夫决策过程的最大到达概率可由线性规划求得，并由无记忆确定策略达到（Kwiatkowska, Parker, Automated Verification and Strategy Synthesis for Probabilistic Systems, 2013, 3.1）；这是对完全可观测的增广过程而言，投回原物理状态后策略可能需要记忆。  
　有限时限：开环词按逐词枚举，代价 \|U\|^H 另乘概率传播；状态反馈按含剩余时限的状态作动态规划；观测策略按策略树计算。

~~~python
"""场具化可达式：字母门控 F 模型、窗读法、增广可达搜索与暴力对照（精确有理运算，三值强 Kleene）
模型类 𝔐_GF（字母门控 F 模型）：有限位集 I、分辨率 ε；字母表 U（含静置 'rest'）；
每个字母 u 给出本拍的脉冲表 [(tgt, a_p, ext)] 与过程表 [Proc]；过程按《场具化数理式》D12 的三类数值律，
读取拍前状态；cert_eff = 1；cert_read、路径边认证由过程申报（直接边：读取位 → 过程，Γ_closed = 闭合）；
Ident、HistEv 申报为 1。一条输入史 h 的窗读法（本篇读法 RD）：W 取 h 的末 w 拍，W 之前的全部拍为形成史，
其 Form、Mark 记录在 F 中以入口拍的记录表示（数理式 D2），W 起点状态为形成史末态。
"""
from fractions import Fraction as Fr
from itertools import combinations, product
from collections import deque
ONE, ZERO, BOT = 1, 0, None

def k_and(*xs):
    if any(x == 0 for x in xs):
        return 0
    if any(x is None for x in xs):
        return None
    return 1

def k_or(*xs):
    if any(x == 1 for x in xs):
        return 1
    if any(x is None for x in xs):
        return None
    return 0

class Proc:
    def __init__(self, pid, tgt, car, law, R=(), k=0, b=0, cert_read=1, cert_path=1):
        self.pid, self.tgt, self.car, self.law = pid, tgt, car, law
        self.R, self.k, self.b = tuple(R), Fr(k), Fr(b)
        self.cert_read, self.cert_path = cert_read, cert_path
    def value(self, s):
        if self.law == 'const':
            return self.b
        if self.law == 'lin':
            return self.b + self.k * sum(s[j] for j in self.R)
        j1, j2 = self.R
        return self.b + self.k * s[j1] * s[j2]
    def supp_act(self, s):
        if self.law == 'const' or self.k == 0:
            return set()
        if self.law == 'lin':
            return set(self.R)
        j1, j2 = self.R
        out = set()
        if s[j2] != 0:
            out.add(j1)
        if s[j1] != 0:
            out.add(j2)
        return out
    def supp_cond(self, s, eps):
        sa = self.supp_act(s)
        if self.law == 'lin' and abs(self.value(s)) <= eps:
            sa |= set(self.R)
        return sa

class GF:
    """字母门控 F 模型。letters: {u: (pulses, procs)}；pulses = [(tgt, a, ext)]，ext ∈ {'out','in'}。"""
    def __init__(self, I, eps, letters, s0):
        """合法性前件（定义三）：位名非空互异；ε、初态、脉冲幅度为非负有理数（整数或 Fraction，不收浮点）；
        字母表有限且含 'rest'；过程标号在同一字母内互异；律 ∈ {const, lin, bilin}，lin 读取位非空，bilin 恰两位，
        const 无读取位；读取位与作用对象属位集；cert_read、cert_path ∈ {1, 0, None}；脉冲 ext ∈ {'out','in'}。
        不合法者抛出 ValueError，不进入求值。"""
        def rat(v, nonneg=False):
            if isinstance(v, bool) or not isinstance(v, (int, Fr)):
                raise ValueError('数值须为整数或 Fraction')
            if nonneg and v < 0:
                raise ValueError('须非负')
            return Fr(v)
        I = tuple(I)
        if not I or len(set(I)) != len(I) or any(not i for i in I):
            raise ValueError('位集')
        if 'rest' not in letters:
            raise ValueError('字母表须含 rest')
        for u, (pulses, procs) in letters.items():
            for (tgt, a, ext) in pulses:
                if tgt not in I or ext not in ('out', 'in'):
                    raise ValueError('脉冲')
                rat(a, True)
            ids = [p.pid for p in procs]
            if len(set(ids)) != len(ids):
                raise ValueError('过程标号重复')
            for p in procs:
                if p.tgt not in I or any(j not in I for j in p.R) or p.car not in ('B', 'out'):
                    raise ValueError('过程对象或读取位')
                if p.law not in ('const', 'lin', 'bilin') or (p.law == 'lin' and not p.R) or \
                   (p.law == 'bilin' and len(p.R) != 2) or (p.law == 'const' and p.R):
                    raise ValueError('律与读取位')
                if p.cert_read not in (1, 0, None) or p.cert_path not in (1, 0, None):
                    raise ValueError('认证值')
        if len(s0) != len(I):
            raise ValueError('初态长度')
        self.I, self.eps, self.letters = I, rat(eps, True), letters
        self.s0 = tuple(rat(x, True) for x in s0)
    def idx(self, i):
        return self.I.index(i)
    def step(self, s, u):
        """一拍（数理式 4.2、5.1）：返回 (后态, 新形成位集, 新标记位集, 过程事件表)；越出定义域返回 None。"""
        eps = self.eps
        pulses, procs = self.letters[u]
        d = {i: Fr(0) for i in self.I}
        sd = dict(zip(self.I, s))
        formed, marked, events = set(), set(), []
        for (tgt, a, ext) in pulses:
            a = Fr(a)
            if a > eps:                      # 有效脉冲：一律计入 Form（D16；与上游 field_final.py 第 123—126 行同），不论拍前深度
                formed.add(tgt)
                if ext == 'out':
                    marked.add(tgt)
                d[tgt] += a
        for p in procs:
            c = p.value(sd)
            act = 1 if abs(c) > eps else 0
            events.append((p, c, act))
            if act:
                if c > eps and sd[p.tgt] <= eps:   # 有效正分项使空位成为留迹元素（D16；上游第 161 行）
                    formed.add(p.tgt)
                if p.car == 'out':
                    marked.add(p.tgt)        # 界外载体机制的有效改变入 Mark
                d[p.tgt] += c
        s2 = tuple(sd[i] + d[i] for i in self.I)
        if any(x < 0 for x in s2):
            return None
        return s2, formed, marked, events

def window_eval(M, s_start, F_rec, M_rec, word):
    """窗读法：入口记录 F_rec、M_rec（位集），W = word。返回 dict：每个非空 T 的 Q 及 Fld、界内自反馈型。"""
    eps = M.eps
    s = s_start
    Form = set(F_rec)           # 「早于 t」的形成记录（入口拍记录早于 W 内一切拍）
    Mark = set(M_rec)
    ev_log = []                 # (avail_cond 全集, avail_act 全集, p, c, act)，T 相关部分事后按 T 截取
    for u in word:
        r = M.step(s, u)
        if r is None:
            return None
        s2, formed, marked, events = r
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev_log.append((ac, aa, p, act))
        Form |= formed
        Mark |= marked
        s = s2
    end = dict(zip(M.I, s))
    out = {}
    fld, selfref = 0, 0
    for n in range(1, len(M.I) + 1):
        for T in combinations(M.I, n):
            T = set(T)
            src = 1 if any(i in Mark for i in T) else 0
            ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
            trace = k_and(src, ret, 1, 1)   # Ident、HistEv 申报为 1
            part = k_or(*[k_and(1 if (ac & T) else 0, p.cert_read)
                          for (ac, aa, p, act) in ev_log if p.car == 'B']) if ev_log else 0
            hd_terms, sr_terms = [], []
            for (ac, aa, p, act) in ev_log:
                hc = k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0)
                hd_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
                if p.car == 'B':
                    sr_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
            hdyn = k_or(*hd_terms) if hd_terms else 0
            q = k_and(trace, part, hdyn)
            out[frozenset(T)] = q
            fld = k_or(fld, q)
            sr = k_and(q, k_or(*sr_terms) if sr_terms else 0)
            selfref = k_or(selfref, sr)
    return {'Q': out, 'Fld': fld, 'self': selfref, 'end': s}

def run_prefix(M, h):
    """形成史：自 s0 施加 h，返回 (末态, Form 位集, Mark 位集)。"""
    s, F, Mk = M.s0, set(), set()
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F |= fo
        Mk |= ma
    return s, frozenset(F), frozenset(Mk)

def fld_of_history(M, h, w):
    """输入史 h 的窗读法资格（W = 末 w 拍，w ≥ 1）。"""
    if w < 1:
        raise ValueError('w ≥ 1')
    if len(h) < w:
        return None
    pre = run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    return window_eval(M, s, F, Mk, h[len(h) - w:])

def physical_reach(M, letters=None):
    letters = letters or list(M.letters)
    seen, dq = {M.s0}, deque([M.s0])
    while dq:
        s = dq.popleft()
        for u in letters:
            r = M.step(s, u)
            if r and r[0] not in seen:
                seen.add(r[0])
                dq.append(r[0])
    return seen

def augmented_search(M, w, target='Fld', letters=None):
    """增广搜索：结点 (s, Form, Mark)；对每个结点枚举长 w 的窗词。返回最短满足史及结点统计。"""
    letters = letters or list(M.letters)
    start = (M.s0, frozenset(), frozenset())
    dist, par = {start: 0}, {start: None}
    dq = deque([start])
    while dq:
        node = dq.popleft()
        s, F, Mk = node
        for u in letters:
            r = M.step(s, u)
            if r is None:
                continue
            s2, fo, ma, _ = r
            nxt = (s2, F | fo, Mk | ma)
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                par[nxt] = (node, u)
                dq.append(nxt)
    best = None
    for node in sorted(dist, key=lambda n: dist[n]):
        if best is not None and dist[node] + w >= best[0]:
            break
        s, F, Mk = node
        for word in product(letters, repeat=w):
            e = window_eval(M, s, F, Mk, word)
            if e is not None and e[target] == 1:
                path, n = [], node
                while par[n] is not None:
                    n, u = par[n]
                    path.append(u)
                h = tuple(reversed(path)) + word
                if best is None or len(h) < best[0]:
                    best = (len(h), h)
                break
    N = len(physical_reach(M, letters))
    return {'best': best, 'nodes': len(dist), 'N': N,
            'max_prefix_dist': max(dist.values()), 'bound_prefix': (2 * len(M.I) + 1) * N - 1}

def brute_min(M, w, Lmax, target='Fld', letters=None):
    letters = letters or list(M.letters)
    for L in range(w, Lmax + 1):
        for h in product(letters, repeat=L):
            e = fld_of_history(M, h, w)
            if e is not None and e[target] == 1:
                return L, h
    return None
~~~

~~~python
"""场具化数理式 v1.0 附录 A：F 层（有限可分层）求值器。
形式模拟，不是物质因果认证。
"""
from dataclasses import dataclass
from math import isfinite
from collections import defaultdict
from fractions import Fraction
Tri = bool | None
def exact(v):
    """输入数值按其十进制表示取精确有理数；F 层全部运算在有理数上精确进行。"""
    return Fraction(repr(v)) if isinstance(v, float) else Fraction(v)
def tri_and(*xs):
    if False in xs:return False
    if None in xs:return None
    return True
def tri_or(xs):
    xs=list(xs)
    if True in xs:return True
    if None in xs:return None
    return False
@dataclass(frozen=True)
class Pulse:
    name:str; step:int; target:str; amount:float; external:bool=True; certified:Tri=True
@dataclass(frozen=True)
class Process:
    name:str; step:int; target:str; carrier_inside:bool; law:str
    reads:tuple[str,...]=(); coefficient:float=0.; bias:float=0.
    certified_effect:Tri=True; certified_read:Tri=True
    # rule: constant, linear (sum of read sites), bilinear (two sites)
@dataclass(frozen=True)
class Link:
    source:str; target:str; certified:Tri=True
@dataclass(frozen=True)
class Spec:
    sites:tuple[str,...]; initial:tuple[float,...]; window:tuple[int,...]
    pulses:tuple[Pulse,...]; processes:tuple[Process,...]
    links:tuple[Link,...]=(); identity:Tri=True; trace_history:Tri=True
    closed_graph:bool=True; epsilon:float=1e-9
    declared_T:tuple[str,...]|None=None

def _num(v, nonneg=False):
    # 合法数值：整数、有理数（Fraction）或有限的十进制浮点数
    if isinstance(v, bool) or not isinstance(v, (int, float, Fraction)): return False
    if isinstance(v, float) and not isfinite(v): return False
    return (not nonneg) or v >= 0
def check(x):
    if not x.sites or len(set(x.sites))!=len(x.sites):raise ValueError('sites')
    if x.declared_T is None or not x.declared_T or len(set(x.declared_T))!=len(x.declared_T) or any(s not in x.sites for s in x.declared_T):raise ValueError('declared T')
    if not x.window or tuple(range(x.window[0],x.window[-1]+1))!=x.window:raise ValueError('window')
    if len(x.initial)!=len(x.sites) or not all(_num(z,True) for z in x.initial):raise ValueError('initial')
    if not _num(x.epsilon,True):raise ValueError('epsilon')
    if x.identity not in (True,False,None) or x.trace_history not in (True,False,None):raise ValueError('identity')
    names=set()
    for e in (*x.pulses,*x.processes):
        if not e.name or e.name in names:raise ValueError('event id')
        names.add(e.name)
        if e.step<x.window[0]-1 or e.step>x.window[-1]:raise ValueError('event time')
        if e.target not in x.sites:raise ValueError('target')
        if isinstance(e,Pulse):
            if not _num(e.amount,True):raise ValueError('pulse amount')
            # certified 在 F 中是脉冲「是否实际发生」的认证：1 发生，0 不发生；⊥ 不属 F 单轨迹定义域，须在 R 中按分支枚举
            if e.certified is None:raise ValueError('F_UNDECIDED_PULSE: enumerate occurrence branches in R')
            if e.certified not in (True,False):raise ValueError('pulse evidence')
        else:
            if e.law not in ('constant','linear','bilinear'):raise ValueError('law')
            if any(s not in x.sites for s in e.reads):raise ValueError('read sites')
            if e.law=='bilinear' and len(e.reads)!=2:raise ValueError('bilinear arity')
            if e.law=='linear' and not e.reads:raise ValueError('linear reads')
            if e.law=='constant' and e.reads:raise ValueError('constant reads')
            if not _num(e.coefficient) or not _num(e.bias):raise ValueError('params')
            # D20：作用认证须已决定；作用未定的机制不属 F 定义域（零分项亦然）
            if e.certified_effect not in (True,False):raise ValueError('undecided mechanism effect')
            if e.certified_read not in (True,False,None):raise ValueError('evidence')
    # All trace nodes are snapshots at integer t; process nodes at integer t+0.5.
    # Strict temporal order prevents fabricated same-step read-after-write.
    times={f'state:{s}:{t}':float(t) for s in x.sites for t in range(x.window[0],x.window[-1]+2)}
    times.update({e.name:float(e.step)+0.5 for e in (*x.pulses,*x.processes)})
    for link in x.links:
        if link.source not in times or link.target not in times:raise ValueError('link endpoint')
        if times[link.source]>=times[link.target]:raise ValueError('noncausal link')
        if link.certified not in (True,False,None):raise ValueError('link evidence')
    return times
def path_status(links,starts,target,closed=True):
    adjacency=defaultdict(list)
    for l in links:adjacency[l.source].append(l)
    def reachable(allow):
        seen=set(starts);queue=list(starts)
        while queue:
            u=queue.pop()
            for l in adjacency[u]:
                if allow(l.certified) and l.target not in seen:
                    seen.add(l.target);queue.append(l.target)
        return target in seen
    if reachable(lambda w:w is True):return True
    if reachable(lambda w:w is not False):return None
    return False if closed else None
def run(x):
    check(x)
    eps=exact(x.epsilon)
    state={s:exact(v) for s,v in zip(x.sites,x.initial)}
    # For each site, certified external history must be identified as event, not inferred from nonzero state.
    formation=defaultdict(list); history_snapshots=defaultdict(list)
    signal_marks=defaultdict(list)  # 界外成因：已认证、有效的界外作用分项（脉冲或界外载体过程）在该位留下的改变
    part=[];hdyn=[];reports=[]
    for t in range(x.window[0]-1,x.window[-1]+1):
        before=dict(state); contributions=defaultdict(list);events=[]
        # Pulse first as an event, but processes read the prior snapshot, not pulse-modified value.
        for p in x.pulses:
            if p.step!=t:continue
            # 只计已认证发生且有效的脉冲；确认不发生者不计贡献、不登记形成与成因
            a=exact(p.amount)
            if p.certified is True and a>eps:
                contributions[p.target].append((p.name,a))
                formation[p.target].append((p.name,t,p.external))
                if p.external:signal_marks[p.target].append((p.name,t))
        for m in x.processes:
            if m.step!=t:continue
            k=exact(m.coefficient); b=exact(m.bias)
            if m.law=='constant':value=b
            elif m.law=='linear':value=b+k*sum(before[s] for s in m.reads)
            else:value=b+k*before[m.reads[0]]*before[m.reads[1]]
            is_action=tri_and(abs(value)>eps,m.certified_effect)
            # Declared reads do not establish a genuine dependence: compute the law's support.
            support=()
            # 组织条件的支持：数值律依赖读取位，或纯读取过程（分项为零）；读取认证另作合取，未定不预先截为假
            # 函数支持按数学上的非零偏导判定（系数与伙伴读数精确不为零），不与有效改变阈值 ε 混用
            if m.law=='linear' and (k!=0 or abs(value)<=eps): support=m.reads
            elif m.law=='bilinear' and k!=0:
                support=tuple(s for i,s in enumerate(m.reads) if before[m.reads[1-i]]!=0)
            # For every element in the declared T, historical formation must precede the read.
            active_T=set(x.declared_T)
            available=[s for s in support if s in active_T and before[s]>eps and any(a[1]<t for a in formation[s])]
            is_cond=tri_and(bool(available),m.certified_read)
            # No automatic path from a read-site to an act. Explicit event links are required.
            old_nodes=[f'state:{s}:{t}' for s in available]
            route=path_status(x.links,old_nodes,m.name,x.closed_graph) if old_nodes else False
            # Action provenance must be supported by a nonzero functional dependence,
            # not merely a certified read that has no effect on the action.
            action_support=()
            if m.law=='linear' and k!=0:action_support=m.reads
            elif m.law=='bilinear' and k!=0:
                action_support=tuple(s for i,s in enumerate(m.reads) if before[m.reads[1-i]]!=0)
            action_available=[s for s in action_support if s in active_T and before[s]>eps and any(a[1]<t for a in formation[s])]
            action_nodes=[f'state:{s}:{t}' for s in action_available]
            action_route=path_status(x.links,action_nodes,m.name,x.closed_graph) if action_nodes else False
            is_hist=tri_and(bool(action_available),m.certified_read,action_route)
            if is_action is True:
                contributions[m.target].append((m.name,value))
                # 新元素的形成：B 内载体者为场内续行形成，界外载体者为信号形成
                if value>eps and before[m.target]<=eps:
                    formation[m.target].append((m.name,t,not m.carrier_inside))
                # 界外载体过程的有效分项，不论新旧元素、不论正负，都是信号留下的改变
                if not m.carrier_inside:
                    signal_marks[m.target].append((m.name,t))
            elif is_action is None: # 防御性检查：作用认证未定已由 check() 排除于定义域之外
                raise ValueError('unresolved effect cannot determine numeric trajectory')
            if t in x.window:
                if m.carrier_inside:part.append(is_cond)
                hdyn.append(tri_and(m.target in active_T,is_action,is_hist))
            events.append({'id':m.name,'delta':value,'act':is_action,'cond':is_cond,'histcond':is_hist,'route':route})
        for s in x.sites:
            new=before[s]+sum(v for _,v in contributions[s])
            # 深度不得为负：精确更新值小于零者越出定义域，不截零、不设容差
            if new < 0:raise ValueError('negative trace depth')
            state[s]=new
            if state[s]>eps and formation[s]:history_snapshots[s].append(t+1)
        if t in x.window:reports.append({'step':t,'before':before,'after':dict(state),'contributions':dict(contributions),'events':events})
    ts=x.declared_T
    eligible=all(state[s]>eps and formation[s] for s in ts)
    sources={origin for site in ts for origin,t in signal_marks[site]}
    trace=tri_and(bool(sources),eligible,x.identity,x.trace_history)
    pw=tri_or(part); hw=tri_or(hdyn)
    return {'trace':trace,'part':pw,'hdyn':hw,'Q':tri_and(trace,pw,hw),'reports':reports,'physical_certificate':False}
~~~

~~~python
def upstream_Q(M, h, w, T):
    pulses, procs, links = [], [], []
    for t, u in enumerate(h):
        pl, pr = M.letters[u]
        for k, (tgt, a, ext) in enumerate(pl):
            pulses.append(up.Pulse(f'p{k}{u}@{t}', t, tgt, a, ext == 'out'))
        for p in pr:
            name = f'{p.pid}@{t}'
            procs.append(up.Process(name, t, p.tgt, p.car == 'B', LAW[p.law], p.R, p.k, p.b, True, TRI[p.cert_read]))
            if t >= 1:
                for j in p.R:
                    links.append(up.Link(f'state:{j}:{t}', name, TRI[p.cert_path]))
    spec = up.Spec(sites=M.I, initial=M.s0, window=tuple(range(1, w + 1)), pulses=tuple(pulses),
                   processes=tuple(procs), links=tuple(links), epsilon=M.eps, declared_T=tuple(T))
    try:
        return up.run(spec)['Q']
    except ValueError as e:
        if 'negative' in str(e):
            return 'illegal'
        raise

def ours_Q(M, h, w, T):
    e = fld_of_history(M, h, w)

def compare(M, h, w):
    n = 0

        for T in combinations(M.I, k):
            a, b = ours_Q(M, h, w, T), upstream_Q(M, h, w, T)
            assert a == b, (M.I, M.s0, h, w, T, a, b)
            n += 1
    return n
~~~

~~~python
def nstar_exact(ub):
    """最少 n 使 ū(1 − ρⁿ) ≥ 1（全有理倍增＋二分，不经浮点）；ū ≤ 1 返回 None。
    0 < ρ < 1、ū > 1 时倍增在有限步内找到满足点；reached 对 n 单调，二分返回首个满足点。"""
    if ub <= 1:
        return None
    def reached(n):
        return ub * (1 - rho ** n) >= 1
    lo, hi = 0, 1
    while not reached(hi):
        lo, hi = hi, 2 * hi
    while hi - lo > 1:
        mid = (lo + hi) // 2
        if reached(mid):
            hi = mid
        else:
            lo = mid
    return hi
~~~

A.7　ladder\_cert.py　许可集阶梯的有限例证与可达而不可证的见证对（命题四，推论二）

~~~python
"""命题四（R 层转移／操作模型，含上限、截零与吸收态，不属线性 F 子类）：许可集阶梯 Π₀ ⊆ Π₁ ⊆ Π₂ ⊆ Π₃ 的可达集——弱包含（一般）、一个模型同时见证三级严格包含、两个等号见证；
推论二：可达而在 Y₁（及 Y₂ 的 MOD、LOC 读数）内不可证的见证对，区分该对须载体／来源申报。"""
from collections import deque
from fractions import Fraction as Fr
from reach_core import GF, Proc, fld_of_history

def reach(s0, ops):
    seen, dq = {s0}, deque([s0])
    while dq:
        s = dq.popleft()
        for f in ops:
            n = f(s)
            if n is not None and n not in seen:
                seen.add(n); dq.append(n)
    return seen

# ---------- M4：状态 (x, z, y)。x 迹应位（上限 2；x = 3 为吸收值），z 随 x 由过程 pz 同步，y 供给位（供给在时恒为 1）
def w(s, ko=False):          # 字母 w：界外脉冲 +1 于 x（x < 2），同拍过程 pz 使 z 加 1（上限 2）；供给维持 y = 1
    x, z, y = s
    if x >= 2:
        return (x, z, 1) if x != 3 else s
    return (x + 1, z if ko else min(2, z + 1), 1)
def rest(s, ko=False):       # 静置：退浅过程 pd 使 x、z 各减 1（不低于 0）；x = 3 不变
    x, z, y = s
    if x == 3:
        return s
    return (max(0, x - 1), z if ko else max(0, z - 1), 1)
def cut(s):                  # 撤供：y ← 0，其余不变（申报的撤供转移律）
    x, z, y = s
    return (x, z, 0)
def loc3(s):                 # LOC：只设定 x，申报设定域 {3}
    x, z, y = s
    return (3, z, y)
~~~

~~~python
"""定理四（限定族）：局部族 β = 1、n = 2，入口脉冲只施于次位（x₂），一拍 = 脉冲后接时长 Δ 的静置流；
核对：(a) α ≤ 1 每拍幅度 η > 0 皆可反序且拍数 ≤ ⌊(1 − ρ₀)M₁/η⌋ + 1；(b) α > 1 锁定集 V 不变；(c) 通用充分条件；
(d)(e)(f) 累计预算下三种情形。数值只作对照，证明见正文第八节。
引理三：抹迹界——连续时间纯衰减、写入有上界、F 层分辨率截取下的线性退浅停滞。"""
import math
from fractions import Fraction as Fr
I, LAM = 1.0, 1.0

def F(x, al):
    S = x[0] + x[1]
    return [(I * x[0] / S) ** al - LAM * x[0], (I * x[1] / S) ** al - LAM * x[1]]

def flow(x, al, T, h=1e-3):
    n = max(1, round(T / h)); h = T / n
    for _ in range(n):
        k1 = F(x, al)
        k2 = F([x[i] + h / 2 * k1[i] for i in range(2)], al)
        k3 = F([x[i] + h / 2 * k2[i] for i in range(2)], al)
        k4 = F([x[i] + h * k3[i] for i in range(2)], al)
        x = [x[i] + h / 6 * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]) for i in range(2)]
    return x

def beats_to_reverse(x, al, eta, D, nmax):
    for n in range(1, nmax + 1):
        x = [x[0], x[1] + eta]
        if x[1] > x[0]:
            return n
        x = flow(x, al, D)
        if x[1] > x[0]:
            return n
    return None

D = 0.5
print('定理四数值对照（局部族 β = 1，I = λ = 1，Δ = 0.5，脉冲只施于 x₂）')
for al in (0.5, 1.0):
    for x0 in ([1.0, 0.2], [0.9, 0.05], [3.0, 0.5]):
        for eta in (0.05, 0.01):
            M1 = max(x0[0], I ** al / LAM); rho0 = x0[1] / x0[0]
            bound = math.floor((1 - rho0) * M1 / eta) + 1

            assert n is not None and n <= bound, (al, x0, eta, n, bound)
            print(f'  (a) α = {al}，x₀ = {x0}，η = {eta}：反序于第 {n} 拍，界 ⌊(1 − ρ₀)M₁/η⌋ + 1 = {bound}')

      f'V = {{x₁ ≥ A，x₂ ≤ b·e^(−λΔ/2)}}')
import random
rng = random.Random(1)
worst = 0
for trial in range(40):
    x = [A + rng.random() * 0.8, rng.random() * b * math.exp(-LAM * D / 2)]
    for n in range(60):
        x = [x[0], x[1] + eta_lock]
        assert x[1] <= b + 1e-9 and x[0] >= A - 1e-9
        x = flow(x, al, D)
        assert x[0] >= A - 1e-6 and x[1] <= b * math.exp(-LAM * D / 2) + 1e-6
        worst = max(worst, x[1] / x[0])

for al in (0.5, 1.0, 1.5):

    assert n is not None
    print(f'  (c) α = {al}：η = 1.05·M(1 − e^(−λΔ)) = {eta:.4f} 时第 {n} 拍反序（通用充分条件）')

for B in (0.05, 0.01):

    while 1 - x[1] / x[0] >= B / M1:

    x = [x[0], x[1] + B]
    assert x[1] > x[0]
~~~
