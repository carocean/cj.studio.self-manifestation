自显论·工篇·场具化组式第六 v1.0

# 场具化构造式

一、式种申报  
本篇是构造式（第三组成立证明附式）。唯一任务：在流网沉积与生物神经网络两族中，各给出一个申报的物理机制模型及其形式编码的显式构造；在机制模型上逐项验证场具化的三项职责；逐项验证机制模型与形式编码之间的对应义务；给出构造域，并对失效作分解；两族在同一条件组、同一验证表下并列，再给出人工神经网络与生物构造的逐项对应。  
本篇的结论分五组。  
　1．条件组：物理机制模型申报（量纲、平衡律与收支、局域性、能量账、参数与适用域），三项职责与五项承担内容，机制模型与形式编码之间的八类对应义务，两族并列比较（第三节）。  
　2．构造：编译规则 J 把申报的机制模型编译为字母门控 F 模型；族甲为恒压头两通道流网，族戊为一个前神经元经两个突触驱动两个后神经元的发放率网络（第四节）。  
　3．构造定理：投影省略引理（引理一）；两族的构造定理（定理一）；单位闭式构造域（命题一）；状态忠实的精确条件与证书的充分条件（命题二）；无驱动留存域（命题三）；正负分项的分担（命题四）；失效判词分列（第六节）。  
　4．并列比较：两族编译为同一参数化编码，职责读数全等，而物理申报、收支、能量与途径逐项不同；形式编码相同不等于物理构造可用（命题五）；人工神经网络在在线学习与冻结推理两种运行方式下的对应（命题六）（第七节）。  
　5．强度、击穿、未决与接口（第八至十二节）。  
强度定位：  
　所达强度为构造强度：在申报的机制模型内显式造出满足条件组的对象。可达（由许可操作从给定初态到达）与实现（真实材料落成）不在此强度内，物质资格亦不在其内。  
　所论对象分为三个：申报的物理机制模型 χ；承载其结构位的形式编码 M；真实宿载。对真实宿载只给条件接口：还须另有证据证明真实系统保存八类对应事实。「真实系统服从同一状态方程」不足以兑现这一接口。  
　「不同宿载的承担原理相同」作为一般结论未证；所证为两个申报构造之间的逐项结论。  
理论增量：上游已有抽象模型 χ₀、Canonical F\*、《势型分级式》6.3 的机制见证模板与两管模型，以及《沉积场判定式》7.5（三）的人工网络最小代表模型；这些都没有带量纲与收支的物理申报，也没有把机制与编码之间的对应义务逐项验证。本篇的增量是：  
　带量纲、逐拍核验收支与能量账的两族物理机制构造，其中生物神经网络的物理机制层构造在组式中首次给出；  
　认证值由申报的途径链推出，而不按申报取 1；  
　状态忠实的精确条件，及数理式 F 层分辨率语义对物理构造的约束（命题二）；  
　投影编码与省略过程的资格保持（引理一）；  
　两族结构位编码的结构类同构，及形式层与物理层的四层分列（命题五）。  
各证明是初等的（逐项代入、归纳、强 Kleene 合取）。

### 2.2　模型与求值

编码层是 𝔐\_GF 与 RD，求值器是 reach\_core.py（附录 A.8，与可达式附录 A.1 逐字相同）。  
　有效改变：脉冲幅度 a \> ε，或过程分项 \|c\| \> ε；只有有效改变计入状态。  
　形成登记：有效脉冲登记形成；有效正分项作用于拍前 s ≤ ε 的位也登记形成。标记登记：界外脉冲与界外载体的有效过程登记标记。  
　资格：Q(T) = TraceSet(T) ∧ Part(T) ∧ HDyn(T)，强 Kleene 合取；求值器另报界内自反馈读数。  
　求值器把 Ident 与 HistEv 申报为 1；本篇以第三节 C-丙（7）的结构性申报检查作为其模型内依据。  
机制层是第四节申报的 χ\_甲、χ\_戊：状态带量纲，数值为申报单位制下的有理数；每拍按申报的本构前件计算，收支（族甲为载液与结构物质，族戊为受体）与能量账逐拍核验。

### 2.3　进入条件

　（一）条件组闭合：第三节 C-甲、C-乙、C-丙、C-丁逐项有来源。  
　（二）相容：物理机制申报与三项职责、对应义务能否共存，上游没有证明。本篇与构造并行关闭相容：同一构造物同时取得条件组全部条款，即构造性相容见证。  
　（三）需要回答「满足者长什么样」：神经网络与流网、河道、黏菌等宿载的承担原理是否都能落到同一套职责与构造条件上，须有带物理申报的显式实例。

三、条件组申报  
C-甲　物理机制模型申报（两族各自填写；可核验条款由程序逐拍检查）  
　P1　量纲与状态：结构位带量纲；结构量与导通量（或突触电导）的关系作为本构前件申报。  
　P2　平衡律与收支：每个守恒量逐拍列出入口、出口、转换、外部注入的入口位、来源与去向。  
　P3　局域性：耦合只经申报的物理连接；准静态消元申报时标条件。  
　P4　能量账：供给功率 = 储能变化率 + 耗散，耗散 ≥ 0；「无供给不增结构量」不作要求，也不归因于热力学第二定律。  
　P5　参数：量纲一致，参数取物理上可解释的取值域；本构前件申报适用域并逐拍检查。  
　本构前件独立申报，现象学律申报其假设地位；构造由完整前件导出，不宣称由 P1—P5 唯一推出。  
　新增条款的判据：更新式每一分项可追溯到一条申报的平衡律与一条申报的本构前件，并对应一个带量纲的物理量；与 Canonical F\* 和《势型分级式》6.3 模板逐项对照，列出新增条款（7.5）。  
C-乙　三项职责：在申报实例、迹应集合 T、窗 W、分辨率 ε 上，TraceSet（Src、Ret）、Part、HDyn（Act ∧ HistCond）逐项成立；正负有效分项同等检查；核定界内自反馈型。五项承担内容——迹应、形成与留存、组织参与、历史动力、实际作用途径——逐族写出（5.2）。  
C-丙　机制模型 χ 与编码 M 的对应义务  
　（1）过程（投影覆盖义务）：机制模型的全部过程在 χ 中列全；其中改变被编码结构位的过程，其每个有效分项都编译为 M 的过程分项；作用于不编码状态的过程可以省略，但须满足引理一的前件 K1—K4 与申报完整性条件 K5，并由引理一保证省略不改变所签的资格。编码中某字母下两系数 b、k 都为 0 的过程不出现（恒零过程省略；生成只由系数决定，不论是哪个物理量为 0）；系数非零而在某状态取值为 0 的过程保留。  
　（2）状态：完整机制状态 X 由结构位与不编码状态（族甲的疏松库存、族戊的受体池）组成；M 的位只取投影 π(X)，即结构位（超基线量）以申报单位计的无量纲数。  
　（3）记录：形成事件编译为 M 的脉冲，不以状态代替记录；触发载体在 B\_phys 外者记界外（Mark）。这是对本篇两个形成事件的申报：它们被粗粒化为宏观有效的界外脉冲，即信号自界外作用于介质并在一拍内完成该结构改变。它不是一般编译定理：内生过程不因有界外远因就记为界外改变。  
　（4）载体：过程载体在 B\_phys 内者记界内。  
　（5）途径：cert\_read、cert\_path 由申报的途径链推出——读取位载体为链首；每段是申报的物理连接；每个结点在 B\_phys 内；链缺失记未知，与申报矛盾记 0。  
　（6）时间：途径链结点时刻自 t 起严格前向，止于 t + 1/2（数理式 D13 的作用事件时刻）。  
　（7）同一与历史事件：每个位绑定唯一载体且跨字母不变；形成事件在 χ 的字母申报中有记录。这是结构性申报检查，是求值器把 Ident、HistEv 申报为 1 的模型内依据；它不检验跨时同一或历史事件的物理认证，后者属真实宿载接口。  
　（8）分辨率相容：沿所论输入史，每个非零脉冲幅度与过程分项 \|c\| \> ε。这是 M 的状态与 π(X) 逐拍相同的充分条件（命题二）；本篇的构造证书以它为签发条件。不满足时证书不签，但不等于不能回读。  
C-丁　并列比较：五项承担内容两族逐项并列，写明共同结构与差异；人工神经网络逐项标明对应、由程序宿载申报代替、在所述运行方式下不成立；只签两个申报构造之间的结论。

四、构造程序

### 4.1　编译 J（附录 A.1）

J(χ) → (M, 编译记录)：按 C-丙（1）—（7）逐项生成 M 的位集、ε、初态、脉冲、过程（律为线性律：值 = b(u) + k(u)·Σ读取位）、载体标记与认证值。b、k 由申报物理量相乘得出，程序断言 k 无量纲、b 与结构位同量纲。认证值不手工填写，全部由途径链与物理连接推出。  
分辨率相容检查 fidelity(M, h)：逐拍检查 C-丙（8），返回首个不相容的脉冲或分项。  
投影与省略前件检查 coverage(χ)：χ 另列不编码状态与被省略过程（名、作用对象、读取量）；程序逐条检查 K1—K5（引理一）。这是对本篇两个申报的结构性辅助检查，不是任意模型的语义认证器：K2 与「过程列全」的依据是两族的显式系数式、逐拍物理更新与过程清单（4.2、4.3）。

### 4.2　族甲：恒压头两通道流网 χ\_甲（附录 A.2）

物理边界 B\_phys = {inlet, outlet, bed1, bed2, flow1, flow2, loose1, loose2}：上游水池入口、下游出口、两条通道的壁与通道内载液、各通道的疏松物库存（脱落的结构物质暂存处）。  
物理连接：inlet→flowᵢ，flowᵢ→outlet；bedᵢ→flowᵢ（壁上结构决定导通）；flowᵢ→bedᵢ（剪切与输运作用于壁）；bedᵢ→bedᵢ（壁的局部过程）；bedᵢ→looseᵢ（脱落入库）；looseᵢ→flowᵢ（库存由载液带出）。  
量纲：压强 P = M L⁻¹ T⁻²；水力导通 G = L⁴ T M⁻¹（Q = gΔP）；结构量 A = L²；时间 T。单位制 P\_u、G\_u、A\_u、Δt，长度单位 L\_u = G\_u P\_u Δt / A\_u（程序断言其量纲为 L）。  
量与解释：Qᵢ 为载液体积流量；载液携带的结构物质为稀相（体积分数 c ≪ 1），其体积不计入 Q；zᵢ 为通道 i 壁上的超基线结构物质截面积，即单位长度的结构体积，是迹应；结构体积与载液体积不相互转换；导通随 z 增大是现象学前件 C1。  
结构位：zᵢ，绑定载体 bedᵢ，初态 0。完整机制状态 X = (z₁, z₂, L₁, L₂)，Lᵢ 为疏松库存（体积）。  
本构前件（现象学，申报其假设地位）：  
　C1　导通与结构的线性化：gᵢ = g₀ + κzᵢ，适用域 0 ≤ zᵢ ≤ z\_max；  
　C2　恒压头流量：Qᵢ = gᵢΔP（准静态：水力弛豫时间 ≪ Δt ≪ 结构弛豫时间 1/γ）；  
　C3　通量增结构：每拍写入 dzᵢ = φcQᵢΔt/ℓ，φ ∈ \[0, 1\] 为携带物中转为结构的分数；  
　C4　结构弛豫：每拍 −γzᵢΔt，脱落的结构物质拍末进入本通道库存 Lᵢ；  
　C4′　库存输出：每拍由载液带出 min(Lᵢ, eQᵢΔt)，用拍首库存，e 为载液对疏松物的输运容量（体积分数）；零流量拍不输出；  
　C5　外部投放：界外投放点 dump 把体积 V 的结构物质加入通道 1，z₁ 增 V/ℓ。  
驱动字母：flow（ΔP = 1 P\_u）；seed（ΔP = 0，伴随外部投放 V/ℓ = 2 A\_u）；rest（ΔP = 0）。  
参数：g₀ = 1 G\_u，κ = 1 G\_u/A\_u，c = 1/5，φ = 1/2，ℓ = 1 L\_u，γ = 1/10 Δt⁻¹，e = 1/5，ε = 1/1000 A\_u，z\_max = 10 A\_u。  
收支（逐拍，程序独立重算）：  
　载液：各通道载液库存不变（不可压、满管）；入口结点总流量与出口结点总流量分别计算并核对相等。  
　结构物质：入口携带 cQᵢΔt；写入为 φ 乘入口携带，不超过入口携带；脱落 γzᵢΔtℓ 入库；库存输出不超过拍首库存，也不超过 eQᵢΔt；出口携带 = 入口携带 − 写入 + 库存输出；零流量拍库存输出与出口携带都为 0。  
　全局：结构物质库存 Σzᵢℓ + ΣLᵢ 的变化（由状态差算出）= 入口携带 + 外部投放 − 出口携带（由两端结点算出），逐拍精确相等。  
能量账：本模型取理想化——结构物质的自由能变化，以及写入、脱落、库存输运的附加耗散，都取 0；外部投放所做的功在 B\_phys 外，不入本账。这是模型假设，不是推论。在此假设下水力账即全部能量账：供给功率 ΔP·ΣQᵢ = 黏性耗散 ΣQᵢ²/gᵢ（由 C2 与泊肃叶耗散推出），水力储能变化为 0。零流量拍两边都为 0，而结构仍可脱落；这在所取理想化中是允许的；它对真实材料是否成立，未证。  
途径链：writeᵢ：bedᵢ(t) → flowᵢ(t + 1/4) → bedᵢ(t + 1/2)；relaxᵢ：bedᵢ(t) → bedᵢ(t + 1/2)。  
被省略过程：intakeᵢ（弛豫脱落物入库，relaxᵢ 在库存一侧的分项，对象 Lᵢ）；exportᵢ（库存输出，对象 Lᵢ，读取 Lᵢ，并经 Qᵢ = (g₀ + κzᵢ)ΔP 读取 zᵢ）。库存输出读取库存，但库存不反馈到结构位的更新：写入与弛豫的系数、发生与途径都不读 L。编码只取 π(X) = (z₁, z₂)。省略的是编码分量，不是删除真实收支；库存侧分项与写入、弛豫之间的物质耦合按申报保留，这些侧分项不作为可以独立敲除的物理机制申报。  
读法：黏菌管道读法中，z 为管壁结构物质截面增量，结构物质由原生质流输送，C3 的收支方向即此。河道读法中，下切使过水断面增大而床面物质输出到流体，收支方向与 C3 相反；编码不变，物质收支须按相反方向另行申报和核验，这一核验未决（U2）。

### 4.3　族戊：生物神经网络发放率模型 χ\_戊（附录 A.3）

物理边界 B\_phys = {pre, syn1, syn2, N1, N2}：前神经元、两个突触、两个后神经元。  
物理连接：pre→synᵢ（递质释放）；synᵢ→Nᵢ（突触传递）；Nᵢ→synᵢ（反传动作电位到达突触）；synᵢ→synᵢ（突触局部过程）。

本构前件（现象学，申报其假设地位）：  
　N1　线性发放率：yᵢ = βwᵢx（x 为前神经元发放率；膜时间常数 ≪ Δt；适用域 yᵢ ≤ y\_max）；

六、构造定理  
引理一（投影省略引理）【所比较的史须在各模型共同的合法域内】  
　设 χ 的完整状态 X = (z, Y)，z 为被编码的结构位，Y 为不编码状态；M = J(χ) 只含作用于 z 的过程；χ 另有被省略过程，其作用对象都在 Y 中。设：  
　　K1　被省略过程不作用于结构位；  
　　K2　被编码过程只读结构位，其系数、发生与途径认证只由字母决定，不读 Y；  
　　K3　形成事件只作用于结构位，被省略过程不产生结构位的脉冲；  
　　K4　被编码过程全部界内，认证值为 1。  
　设 M⁺ 为在 M 上加入被省略过程（作为作用于 Y 的过程，认证值任意）所得的机制层编码，Y 的初值任意合法；M⁺ 按数理式 D15—D18 的同一语义求值，被省略过程的律可以越出 D12（如 exportᵢ 的 min 律），只要求其作用对象、函数支持与有效性有定义（min 律在分支交界点的支持按本篇所用语义申报）。M⁺ 是本篇机制层的辅助语义，不是对求值器的扩展；求值器不执行 M⁺，本引理的结论由下列证明给出，不由程序运行给出。则对同一输入史、同一窗与任一 T ⊆ z：  
　（i）M⁺ 与 M 的 z 轨迹相同，z 位的 Form、Mark 相同；  
　（ii）Src(T)、Ret(T)、HDyn(T) 在两者上相同；  
　（iii）Q\_{M⁺}(T) = Q\_M(T)，界内自反馈读数相同。  
证明：（i）由 K2，z 的每拍增量只依赖拍前 z 与字母；由 K1，被省略过程不改变 z；由 K3，z 位的形成与标记只来自形成事件与被编码过程，二者在 M、M⁺ 中相同；归纳即得。（ii）Src、Ret 只依赖 z 位的 Mark、Form 与末态，由（i）相同。HDyn(T) 要求作用对象属于 T ⊆ z；由 K1，被省略过程的对象不在 z 中，不是 HDyn(T) 的承担者，故承担者集合及其判值相同。（iii）Q = Src ∧ Ret ∧ Part ∧ HDyn。被省略过程可能以 z 为组织条件（例如 exportᵢ 经 Qᵢ 读取 zᵢ），使 Part\_{M⁺}(T) 可能大于 Part\_M(T)。但由 K4，任一 HDyn(T) 承担者在界内，且 Supp\_act ⊆ Supp\_cond，故 HDyn(T) = 1 蕴含 Part\_M(T) = 1；HDyn(T) = 0 时两者 Q 都为 0；认证值为 1 时 HDyn 不取未知。故两者 Q 相同；界内自反馈读数同理，其承担项也要求作用对象属于 T。∎  
　适用：两族的 K1—K4 与申报完整性条件 K5（不编码状态与被省略过程互相列全）由 coverage 检查为真（附录 B.1）。族甲 Y = (L₁, L₂)，被省略过程 intakeᵢ、exportᵢ；族戊 Y = (R₁, R₂)，被省略过程 poolᵢ。  
　限度：引理只对 T ⊆ 结构位成立，不对含库存或受体池的候选 T 作结论，也不说明机制模型的全部职责原子（如以库存为对象的作用）与编码相同。Y 的合法性（库存、池非负）是物理构造证书的条件，不由引理给出。  
定理一（构造定理）  
　设 χ 为 χ\_甲 或 χ\_戊（本构前件 C1—C5、C4′ 或 N1—N5，参数、单位制与能量账的申报如第四节），M = J(χ)。则：  
　（i）M ∈ 𝔐\_GF，位集 {z1, z2}，ε = 1/1000，全部认证值由途径链推出为 1；  
　（ii）在输入史 H1—H4 上，χ 的收支、能量账与本构适用域逐拍成立，C-丙（8）成立，M 的状态与 π(X) 逐拍相同，投影省略前件 K1—K5 成立；  
　（iii）RD 读数：H1、H4 上 Q{z1} = 1、Fld = 1、界内自反馈 = 1；对照史 H2 上全部为 0；H3 上 Q{z1} = 1、Fld = 1、界内自反馈 = 1【有限核验】；  
　（iv）由引理一，对任一 T ⊆ {z1, z2}，含被省略过程的机制层读数与 M 的读数相同，故（iii）的读数是 χ 在这些 T 上的读数。  
　故 Constructed(χ, M) = 1：同一构造物同时满足 C-甲、C-乙、C-丙，这是构造性相容见证。所签强度为「结构位状态投影相同」与「指定 T 与史上的资格可回读」，不签「完整机制模型与全部过程一一编码」。  
证明：（i）由 J 的定义与 4.4 的系数计算。（ii）族甲由 C3—C5、C4′ 逐拍计算 5.1 所列各量，载液与结构物质两本账以两端结点与状态差独立重算核对；能量账由 C2 与泊肃叶耗散 Qᵢ²/gᵢ = ΔPQᵢ 得供给 = 耗散；族戊由 N2—N5 逐拍计算受体池，能量账按申报记账；适用域与相容条件由 5.1 所列轨迹逐拍检查（附录 B.1）。（iii）H1 由命题一的闭式在 a = 2、b = 1/10、k = 1/10、γ = 1/10、ε = 1/1000 处代入：z = 2，z′ = 21/10，写入分项 3/10。H4 窗内只有弛豫，按同一推导：γz = 1/5 \> ε，z′ = 9/5 \> ε。H2 中 z₁、z₂ 无形成记录，Src = 0。H3 的窗长 3 拍不在命题一范围内，只作程序核验。（iv）由引理一与（ii）中 K1—K4 成立。∎  
命题一（单位闭式构造域）  
　单位模型：形成脉冲 a，随后静置 m 拍（弛豫 −γz），再驱动一拍（写入 b + kz，弛豫 −γz），W 取末一拍，T = {z1}。过程按 J 的规则生成：b = k = 0 的写入与 γ = 0 的弛豫不出现，系数非零而在该状态取值为 0 的过程保留；全部认证值为 1，全部过程在界内。设分辨率相容。则 Q{z1} = 1 当且仅当  
　　a \> ε，z := a(1 − γ)^m \> ε，z′ := z + b + kz − γz \> ε，且 \[k ≠ 0 ∧ \|b + kz\| \> ε\] 或 \[γ ≠ 0 ∧ γz \> ε\]；  
　任一拍结构量为负则越域。  
证明：Src = \[a \> ε\]，有效界外脉冲入 Mark。Ret = \[z′ \> ε ∧ z1 ∈ Form\]，Form 由脉冲给出。对线性律，k ≠ 0 时 Supp\_act = {z1}，经可用性过滤（z \> ε，z1 ∈ Form）得 HistCond；Act 为 \|c\| \> ε。Part：任一 HDyn 承担者都在界内，且 Supp\_act ⊆ Supp\_cond，故它以同一可用位 z1 为条件，HDyn = 1 蕴含 Part = 1。其他过程（例如系数非零而在本态取值为 0 的过程，其条件支持含 z1）可能单独使 Part = 1，但 Q 还要求 HDyn，HDyn = 0 时不能补成 Q = 1。故 Q = Src ∧ Ret ∧ HDyn，即上列条件。∎  
　有限核验：a ∈ {0, 1/200, 1/5, 2}，γ ∈ {0, 1/10, 1/2, 1, 3/2}，b ∈ {0, 1/10}，k ∈ {0, 1/10, −1/2}，m ∈ {0, 1, 3}，ε = 1/100；分辨率相容的 230 组上闭式与求值器一致，其中含状态零值过程 a = 1/5、b = 1/10、k = −1/2、m = 0、γ = 0（b + kz = 0，过程存在、条件支持含 z1、Act = 0，Q{z1} = 0，与闭式一致）（附录 B.2 第三部分）。  
命题二（状态忠实的精确条件；分辨率相容为充分条件）  
　设 M = J(χ)，χ 作用于结构位的每个分项都全额计入状态。沿输入史 h：  
　（i）M 的状态轨迹与投影 π(X) 的轨迹逐拍相同，当且仅当每拍每个位上被 M 丢弃的分项（0 \< \|c\| ≤ ε 的脉冲幅度与过程分项）之和为 0；  
　（ii）特别地，分辨率相容蕴含轨迹相同。若某拍的拍前状态在两层相同，且该拍某位被丢弃分项之和非零，则该拍更新后两态不同；该位恰有一个非零被丢弃分项，或所有被丢弃分项同号时，此条件成立。特别地，若 t 为被丢弃分项之和首次在某位非零之拍，则两层在拍 t 更新后首次分叉。分叉之后，后续被丢弃分项可能抵消已有差值，使两态重新相等；重新相等不表示整条轨迹始终一致。  
证明：求值器只把 \|c\| \> ε 的分项计入状态（有效脉冲同）。设前一拍两态相同；本拍某位上，χ 的增量减去 M 的增量，恰为该位被丢弃分项之和。（i）由此逐拍归纳。（ii）相容时无被丢弃分项。拍前两态相同时，该拍更新后某位的差恰为该位被丢弃分项之和，只有一个或同号时其和非零；首次非零之拍以前各拍和都为 0，由（i）拍前两态相同，故该拍首次分叉。∎ 例：ε = 1/100，初态 1，两拍依次只有常数分项 +1/200 与 −1/200，编码轨迹 1, 1, 1，机制轨迹 1, 201/200, 1：第 1 拍首次分叉，第 2 拍重新相等。  
　分项相消时（同一位、同一拍有 +1/200 与 −1/200，ε = 1/100），分辨率不相容而轨迹相同（附录 B.2 第五部分）。故 C-丙（8）是可检查的充分条件，不是轨迹相同的必要条件。  
　推论：分辨率相容不成立时，不能仅凭此检查保证回读，本篇的构造证书不签；若逐项另证状态以及相关资格原子与对应义务仍一致，可另行回读。例：有效弛豫 −1/5 加两个相消的亚阈分项 +1/200、−1/200（ε = 1/100），相容检查不通过，而机制与编码末态同为 9/5，亚阈分项在两层都不有效，形式资格为 1（附录 B.2 第五部分）。  
　实际不忠实的见证（只就所列史而言）：族甲取 ε = 1/100 时，H3 第 5 拍 relax₂ = −1/100 被丢弃，编码与机制分叉，读数为 1 但不读回；ε = 1/1000、形成后静置 120 拍，编码态 z₁ 冻结在约 9.28 × 10⁻³，机制模型为 2·(9/10)^120 ≈ 6.46 × 10⁻⁶。亚分辨率分项被丢弃，使编码中出现机制模型没有的留存。  
　三种情形分开：充分条件成立，证书可签；充分条件不成立而未另证，证书不签；已见分叉，实际不忠实。  
命题三（无驱动留存域）  
　在第四节申报的参数下，史「形成 + 静置 m 拍 + 驱动一拍」分辨率相容当且仅当 m ≤ 50，此时 Q{z1} = 1。  
证明：最小非零分项为末段弛豫 −γz₁，z₁ = 2·(9/10)^m；相容 ⇔ (1/10)·2·(9/10)^m \> 1/1000 ⇔ m ≤ 50。m ≤ 50 时代入命题一，四个条件都成立。∎ 程序核验 m = 0—79：最大相容 m = 50，m = 51 起首个不相容分项为 relax₁，约 −9.28 × 10⁻⁴（附录 B.2 第二部分）。  
命题四（正负分项的分担与零驱动窗）  
　族甲 H1：完整模型、只写入（γ = 0）、只弛豫（κ = 0，写入不读迹应）三种情形 Q{z1} = 1；κ = 0、γ = 0 时为 0。零驱动窗 H4 中只有弛豫，Q{z1} = 1；脱落物入疏松库存，收支闭合（附录 B.1、B.2 第一部分）。  
　读法：组织参与与历史动力可由正分项承担，也可由负分项承担，零来流不排除资格。只隔离写入（γ = 0）即见证经载液闭合的途径单独足够。  
失效判词分列（附录 B.2 第四、五部分，B.3 第四部分）  
　越出合法域：γΔt = 3/2，结构量被减为负，回放越域，不作 0。  
　证书未取得：本构适用域或收支核验不通过，例 φ = 3/2（写入超过来料），构造证书不发，不给 Q 值。  
　物理合法而资源不足：族戊受体池初值 10 时，编码与形式读数和初值 40 相同（Fld = 1），但形成时池不足 20，物理核验不通过，构造证书不发。  
　固定 T 的 Q = 0：对照史无形成，T = {z1} 无 Mark；同史 Fld = 0。  
　证据不足：途径链未申报，认证值未知，Q 为未知。  
　证书范围外：分辨率不相容而未另证，本篇证书不签，不等于不能回读。  
　实际不忠实：已见编码与机制分叉，读数不读回。  
　其他 T 仍可能成立：H1 中 Q{z2} = 0，而 Q{z1} = Q{z1, z2} = 1。  
　改参数的口径：在同一申报下改变整组参数后全史重跑；形成事件（投放或配对刺激）与窗内写入系数分属不同前件，κ 或 φ 取 0 不消灭形成史。

七、并列比较

### 7.1　结构位编码的同构

命题五（结构位编码的同构与读数全等）  
　（i）在字母 seed ↔ pair、flow ↔ drive 与过程 write ↔ hebb、relax ↔ decay 的改名下，第四节申报参数下的 J(χ\_甲) 与 J(χ\_戊) 逐项相同（位集、ε、初态、脉冲、律、系数、载体标记、认证值）。因此对一切输入史与窗，两族的 Q(T)（一切 T ⊆ {z1, z2}）、Fld、界内自反馈读数相同。  
　（ii）结构类：在恒零过程省略的统一生成规则下，对一切申报参数，J(χ\_甲) 与 J(χ\_戊) 都等于同一参数化编码 M(a, b, k, γ, ε)——两位；形成字母一个界外脉冲（幅度 a）入 z1；驱动字母每位一个写入过程（线性律，读本位，系数 b、k），b = k = 0 时省略；各字母每位一个弛豫过程（线性律，读本位，系数 −γ），γ = 0 时省略；全部界内，认证值由途径链推出为 1。对应关系为：族甲 a = V/ℓ，b = φcΔPg₀Δt/ℓ，k = φcΔPκΔt/ℓ；族戊 a = Δw，b = ηxβw₀xΔt，k = ηxβxΔt；γ 两族同名。  
证明：系数由各自申报的物理量相乘得出；由 J 的规则与两族申报的过程表逐项对照即得（ii），在申报参数下数值相同即得（i）的编码相同；求值器是 M 的函数，与位名、字母名、过程名的改名无关。∎  
　有限核验：长度 1—4 的全部输入史与窗共 426 组，读数逐一相同；族甲 7 组、族戊 6 组物理参数的编译结果都等于 M(a, b, k, γ, ε)，含驱动为 0、φ 或 η 为 0、κ = 0、γ = 0 等退化点；ΔP = 0、γ = 0 与 φ = 0、γ = 0 两组参数五元组同为 (2, 0, 0, 0, 1/1000)，编译为同一编码（附录 B.3 第一、三部分）。  
　四层分列：五元组决定的是形式编码与形式读数，不决定物理构造是否可用。四层分开——（甲）完整形式编码同构；（乙）职责读数相同；（丙）物理模型合法、资源与收支可行；（丁）编码与机制的对应成立。（甲）蕴含（乙），不蕴含（丙）（丁）。构造域 = 各族物理合法域 ∩ 资源与收支域 ∩ 对应义务域 ∩ 指定目标的形式判值条件；最后一项在命题一的前件与史形状下由同一闭式给出，前三项两族分别核验。例：族戊受体池初值 10 与 40 编码相同、形式 Fld 都为 1，前者物理核验不通过、无构造证书（附录 B.3 第四部分）。  
　读法：共同的 M 是两族结构位的形式编码，不是完整物质模型的同构；族甲的库存、族戊的受体池及其过程都不入编码。两族在结构位编码的结构类与职责读数上共同，且各自在物理层取得构造证书；这是「共同属于沉积场」在本篇范围内的逐项依据。同一 M 对应两个不同的机制模型，说明形式读数本身不区分宿载，与《场具化不可区分式》相容；两族的区别与各自的验证负担全部在 C-甲 与 C-丙。

### 7.2　机制层逐项差异（附录 B.3 第二部分）

　结构位量纲：族甲 L²（截面积）；族戊为电导。  
　形成：族甲为外部物质进入；族戊界外只给触发，物质取自界内受体池。  
　写入物质来源：族甲为载液携带物（H1 驱动拍入口携带 3/5 中取 3/10）；族戊为受体池（20 → 19）。  
　负分项去向：族甲脱落物入通道疏松库存，有流时由载液带出，为开放收支；族戊受体还池，为界内闭合收支。  
　能量账：族甲在申报的理想化（结构自由能与附加耗散取 0）下，水力账由泊肃叶耗散律推出供给 = 耗散；族戊为现象学代谢账，「耗散 = 供给」是假设的实现。  
　驱动：族甲为恒压头边界条件；族戊为前神经元发放率输入。  
　途径链：族甲为壁 → 通道载液 → 壁；族戊为突触 → 后神经元 → 反传至突触。  
　时标前件：族甲为水力弛豫 ≪ Δt ≪ 1/γ；族戊为膜时间常数 ≪ Δt ≪ 可塑性时间。

### 7.3　人工神经网络的逐项对应

命题六（附录 B.4）  
　所构造的是生物神经网络（族戊）；人工神经网络（数字硬件上的程序）属程序宿载层，与之只有逐项对应，没有物理机制构造。  
　已有先例：《沉积场判定式》7.5（三）实例甲已给出 MLP 候选的最小代表模型——单权重线性单元、平方损失、在线梯度 Δw = η(2 − w)、前向读出：训练实例 χ\_in（优化器纳入边界）Fld = 1、界内自反馈型为 1；优化器载体在界外的 χ\_ext 亦 Fld = 1，界内自反馈型判词不同；冻结部署 χ\_frz 的 Part = 1、HDyn = 0（模型模式；该篇另列各观测条件下的判词）。在线与冻结的这一差别承该先例。  
　与判定式实例甲的不同：本节的更新律为 Hebb 型写入 b + kw（读本位，b、k 由前后活动给出），而非朝目标的梯度；形成为训练样本的界外写入脉冲；途径链显式列出存储—总线—运算—总线—存储，认证值由链推出；冻结情形另建模持续保存的输出寄存器 o。本节的作用是与族戊逐项对照。  
　职责结构对应（不是完整递推编码相同）：权重 ↔ 突触电导（迹应）；训练样本写入 ↔ 配对刺激（界外触发，编码为界外脉冲）；在线学习的权重更新 ↔ Hebb 写入；前向计算 ↔ 突触传递与发放。本节示例只有一个权重、没有衰减项，与族戊的两位、带衰减的编码不同。  
　由程序宿载申报代替：载体为存储单元、总线、运算单元（B\_phys = {mem1, memo, bus, alu}）；量纲与物质收支由程序量与存储位代替；能量账为电源供给全部转为热，属现象学申报。  
　按运行方式分列：  
　　在线学习：Q{w1} = 1，Fld = 1，界内自反馈 = 1；  
　　训练后冻结推理：窗内无过程作用于权重。不建模前向过程时窗内无事件；建模前向过程（读 w1、写输出寄存器 o）时，w1 是组织条件，但作用对象 o ∉ T = {w1}，HDyn({w1}) = 0，Q{w1} = 0；  
　　持续保存的输出寄存器 o 若列入 T，Q{o, w1} = 1；o 的形成全在窗内运行、内容由权重决定，是否算迹应列为未决（U5）。  
　读法：在所列 T = {w1}、过程表、边界与窗下，冻结推理的人工网络，权重是迹应并参与组织，但推理期间没有作用于迹应的历史动力；它与在线学习的人工网络、与生物网络的差别在历史动力这一项。含持续输出寄存器的更大 T 已有形式正例，故不得读成冻结网络整体不是沉积场。

### 7.5　与《势型分级式》6.3—6.4、Canonical F\* 的对照

　《势型分级式》6.3—6.4：

八、强度申报  
　所签强度：两个申报的物理机制模型及其结构位编码的显式构造；在第四节参数与 H1—H4 上的构造证书；命题一、三的构造域；命题二的忠实条件；引理一的资格保持；命题五的结构类同构与四层分列；命题六所列模型、T、过程表、边界与窗下的读数。  
　不在所签强度内：  
　　可达与实现；  
　　任何真实流网、河道、黏菌或神经组织的物质资格（物质判词仍为 ⊥）；  
　　完整机制模型与全部过程一一编码；  
　　含库存或受体池的候选 T；  
　　「不同宿载承担原理相同」的一般定理；  
　　现象学本构前件、族甲能量理想化与族戊代谢账作为物理定律；  
　　河道读法的收支；  
　　竞争型构造；  
　　冻结推理的人工网络整体不是沉积场。  
　证据层级：数学证明与有限核验分列；所用本构关系作为申报的现象学前件，不作实验规律的新认证。

九、最终表达  
在流网沉积与生物神经网络两族中，各有一个带量纲、收支闭合、能量账申报完整的物理机制模型，其结构位经编译规则 J 编为字母门控 F 模型：认证值由申报的途径链推出，形成事件编为界外脉冲，作用于不编码状态的过程按投影省略引理省略。在申报参数与所列输入史上，两族的机制状态投影与编码状态逐拍相同，迹应 z₁ 承担三项职责，Fld = 1、属界内自反馈型；无形成的对照史全部为 0。两族的结构位编码属同一参数化类 M(a, b, k, γ, ε)，职责读数全等，而物质来源、收支、能量账、驱动与途径逐项不同；形式编码相同不蕴含物理构造可用。编码忠实的精确条件是每拍每位被丢弃分项之和为 0；分辨率相容是其可检查的充分条件，也是本篇构造证书的签发条件。人工神经网络在线学习时与生物构造在职责结构上对应；训练后冻结推理时，在所列 T 上缺历史动力。

~~~python
  途径链缺失记 None（未知），与申报矛盾记 0。
"""
from fractions import Fraction as F
from reach_core import GF, Proc
BASE = ('M', 'L', 'T', 'I')

class Dim:
    def __init__(self, **e):
        self.e = tuple(F(e.get(b, 0)) for b in BASE)
    def __mul__(self, o):
        d = Dim(); d.e = tuple(a + b for a, b in zip(self.e, o.e)); return d
    def __truediv__(self, o):
        d = Dim(); d.e = tuple(a - b for a, b in zip(self.e, o.e)); return d
    def __pow__(self, n):
        d = Dim(); d.e = tuple(a * n for a in self.e); return d
    def __eq__(self, o):
        return self.e == o.e
    def __repr__(self):
        s = ' '.join(f'{b}^{x}' for b, x in zip(BASE, self.e) if x)
        return s or '1'

ONE = Dim()

class Qty:
    """带量纲的申报量：数值以申报单位制计（有理数），dim 为量纲。"""
    def __init__(self, v, dim):
        self.v, self.dim = F(v), dim
    def __mul__(self, o):
        return Qty(self.v * o.v, self.dim * o.dim)
    def __truediv__(self, o):
        return Qty(self.v / o.v, self.dim / o.dim)
    def __add__(self, o):
        assert self.dim == o.dim, ('量纲不一致', self.dim, o.dim)
        return Qty(self.v + o.v, self.dim)
    def __sub__(self, o):
        assert self.dim == o.dim, ('量纲不一致', self.dim, o.dim)
        return Qty(self.v - o.v, self.dim)

def dimensionless(q, unit):
    """把以 unit 计的量化为无量纲数：要求 q.dim == unit.dim。"""
    assert q.dim == unit.dim, ('量纲不一致', q.dim, unit.dim)
    return q.v / unit.v

class Process:
    """申报的物理过程：value = b(u) + k(u)·Σ 读取位。b、k 为该字母下的 Qty，须与结构量单位相容。
    chain：途径链 [(载体, 时刻偏移)]，自读取位的载体起，至过程载体止；None 表示途径未申报。"""
    def __init__(self, pid, tgt, carrier, reads, coef, chain):
        self.pid, self.tgt, self.carrier, self.reads = pid, tgt, carrier, tuple(reads)
        self.coef, self.chain = coef, chain     # coef(u) -> (b: Qty|None, k: Qty|None)，(None, None) 表示该拍无此过程

class Model:
    """χ_model：B_phys（载体集）、links（物理连接，有向）、positions {位: (载体, 单位 Qty)}（被编码的结构位）、
    letters {u: [(位, Qty 幅度, 触发载体)]}（形成事件）、processes [Process]（作用于结构位的过程，全部编码）、
    eps（Qty，结构量单位）、extra（不编码的机制状态名）、omitted [(过程名, 作用对象, 读取量, 说明)]（不编码的过程）。
    完整机制状态 X = (结构位, extra)；编码只取投影 π(X) = 结构位 / 申报单位。"""
    def __init__(self, name, B_phys, links, positions, letters, processes, eps, s0, extra=(), omitted=()):
        self.name, self.B, self.links = name, set(B_phys), set(links)
        self.pos, self.letters, self.procs, self.eps, self.s0 = positions, letters, processes, eps, s0
        self.extra, self.omitted = tuple(extra), list(omitted)

def coverage(model):
    """投影编码的覆盖与省略前件（引理一的 K1—K4 与申报完整性 K5），逐条返回真值：
    K1 改变结构位的过程全部在 procs 中（被省略过程的作用对象都不是结构位）；
    K2 被编码过程的系数只由字母决定（Process.coef 只接受字母），读取量都是结构位（不读不编码的状态）；
    K3 形成事件只作用于结构位；被省略过程不产生结构位的脉冲、形成或标记（其对象不在结构位中）；
    K4 被编码过程全部界内且途径认证可由链推出为 1（HDyn 承担者在界内，HDyn ⇒ Part）；
    K5 不编码的状态与被省略过程在申报中列全（extra 与 omitted 的对象互相覆盖）。"""
    pos = set(model.pos)
    k1 = all(o[1] not in pos for o in model.omitted) and all(p.tgt in pos for p in model.procs)
    k2 = all(set(p.reads) <= pos for p in model.procs) and \
        all(p.coef.__code__.co_argcount == 1 for p in model.procs)
    k3 = all(i in pos for evs in model.letters.values() for (i, _, _) in evs)
    k4 = all(p.carrier in model.B and cert_of(model, p)[:2] == (1, 1) for p in model.procs)
    k5 = {o[1] for o in model.omitted} == set(model.extra)        # 每个不编码状态都有过程申报，反之亦然
    return dict(K1=k1, K2=k2, K3=k3, K4=k4, K5=k5)

def cert_of(model, p):
    """由途径申报推出 (cert_read, cert_path, 理由)。"""
    if p.chain is None:
        return None, None, '途径未申报'
    nodes = [c for c, _ in p.chain]
    times = [t for _, t in p.chain]
    rd = 1 if all(model.pos[j][0] == nodes[0] for j in p.reads) else 0
    ok_links = all((a, b) in model.links for a, b in zip(nodes, nodes[1:]))
    ok_B = all(c in model.B for c in nodes)
    ok_t = times[0] == 0 and times[-1] == F(1, 2) and all(a < b for a, b in zip(times, times[1:])) \
        if len(times) > 1 else times == [F(1, 2)]
    ok_end = nodes[-1] == p.carrier
    path = 1 if (ok_links and ok_B and ok_t and ok_end) else 0
    why = dict(读取位载体=rd, 连接=ok_links, 界内=ok_B, 时序=ok_t, 止于过程载体=ok_end)
    return rd, path, why

def compile_model(model):
    """J(χ_model) → (GF, 编译记录)。"""
    I = tuple(model.pos)
    unit = {i: model.pos[i][1] for i in I}
    rec = {'Ident': {i: model.pos[i][0] for i in I}, 'cert': {}, 'pulses': {}, 'procs': {}}
    letters = {}
    for u, events in model.letters.items():
        pulses = []
        for (i, amt, trig) in events:
            a = dimensionless(amt, unit[i])
            ext = 'in' if trig in model.B else 'out'
            pulses.append((i, a, ext))
            rec['pulses'][(u, i)] = (a, ext, trig)
        procs = []
        for p in model.procs:
            b, k = p.coef(u)
            if b is None and k is None:
                continue
            bv = dimensionless(b, unit[p.tgt]) if b is not None else F(0)
            kv = F(0)
            if k is not None:
                assert k.dim == ONE, ('k 须无量纲（位单位相同）', p.pid, k.dim)
                kv = k.v * unit[p.reads[0]].v / unit[p.tgt].v
            if bv == 0 and kv == 0:
                continue                      # 恒零过程省略（生成只由系数决定）
            rd, path, why = cert_of(model, p)
            rec['cert'][p.pid] = (rd, path, why)
            car = 'B' if p.carrier in model.B else 'out'
            procs.append(Proc(f'{p.pid}@{u}', p.tgt, car, 'lin', R=p.reads, k=kv, b=bv,
                              cert_read=rd, cert_path=path))
            rec['procs'][(u, p.pid)] = (bv, kv, car)
        letters[u] = (pulses, procs)
    eps = dimensionless(model.eps, unit[I[0]])
    s0 = tuple(dimensionless(model.s0[i], unit[i]) for i in I)
    return GF(I, eps, letters, s0), rec

def fmt(x):
    return str(x) if not isinstance(x, (set, frozenset)) else '{' + ','.join(sorted(x)) + '}'

def fidelity(M, hist):
    """分辨率相容检查：沿 hist 每拍每个脉冲幅度与过程分项 c 须为 0 或 |c| > ε，否则 F 编码丢弃该分项而与机制模型分叉。
    返回 None（相容）或 (拍号, 过程, c)。"""
    s = M.s0
    for t, u in enumerate(hist, 1):
        sd = dict(zip(M.I, s))
        for (tgt, a, ext) in M.letters[u][0]:
            if a != 0 and abs(a) <= M.eps:
                return t, f'脉冲→{tgt}', a
        for p in M.letters[u][1]:
            c = p.value(sd)
            if c != 0 and abs(c) <= M.eps:
                return t, p.pid, c
        r = M.step(s, u)
        if r is None:
            return t, '越域', None
        s = r[0]
    return None
~~~

A.2　fam\_flow.py　族甲：恒压头两通道流网的机制模型申报与逐拍物理核验（第四节 4.2）

~~~python
"""族甲：恒压头两通道流网（河道下切、黏菌管道增粗的共同抽象）的物理机制模型申报 χ_甲。
本构前件（现象学，申报其假设地位）：
  C1 导通–结构线性化：g_i = g0 + κ·z_i（z_i 为超基线截面积，适用域 0 ≤ z_i ≤ z_max）；
  C2 恒压头流量：Q_i = g_i·ΔP（准静态，水力弛豫时间 ≪ Δt）；
  C3 通量增结构：每拍写入 dz_i = φ·c·Q_i·Δt/ℓ（φ 为携带物质中转为结构的分数，0 ≤ φ ≤ 1）；
  C4 结构弛豫：每拍 −γ·z_i·Δt，脱落的结构物质进入本通道的疏松物库存 L_i（载体 loose_i，在 B_phys 内）；
  C4′ 库存输出：每拍由流体带出 min(L_i, e·Q_i·Δt)（e 为载液对疏松物的输运容量，体积分数）；
      用拍首库存，零流量拍不输出；本拍脱落物拍末入库；
  C5 外部投放：界外来源（投放点）把体积 V 的结构物质加到通道 1，z_1 增 V/ℓ。
量与解释：Q 为载液体积流量；携带的结构物质为稀相（体积分数 c ≪ 1），其体积不计入 Q；z 为壁结构物质截面积
  （单位长度结构体积），结构体积与载液体积不相互转换；导通随 z 增大是申报的现象学前件 C1。
能量账（理想化，申报）：结构物质的自由能变化与写入、脱落、库存输运的附加耗散取 0；外部投放所做的功在 B_phys 外，
  不入本账。在此理想化下，水力账 供给 ΔP·ΣQ = 黏性耗散 ΣQ²/g（储能变化 0）即全部能量账。
完整机制状态 X = (z_1, z_2, L_1, L_2)。库存输出过程读取 L_i（与经 Q_i 读取 z_i），作用于 L_i；脱落入库是弛豫在库存一侧的
  对应分项。库存不反馈到结构位的更新（写入与弛豫的系数、发生与途径都不读 L）。编码 M 只取投影 π(X) = (z_1, z_2)，
  库存及其过程按投影省略引理省略（引理一），不作「全部物理过程一一编码」。
时间：状态 t → 分流 t+1/4 → 写入事件 t+1/2 → 状态 t+1（数理式 D13）。
"""
from fractions import Fraction as F
from ctor_core import Dim, Qty, ONE, Process, Model
Pd = Dim(M=1, L=-1, T=-2)                  # 压强
Gd = Dim(L=4, T=1, M=-1)                   # 水力导通（Q = g·ΔP）
Ad = Dim(L=2)
Td = Dim(T=1)
Ld = Dim(L=1)
P_u, G_u, A_u, dt = Qty(1, Pd), Qty(1, Gd), Qty(1, Ad), Qty(1, Td)
L_u = G_u * P_u * dt / A_u                 # 单位制自洽：A_u·L_u = g_u·P_u·Δt
assert L_u.dim == Ld and L_u.v == 1

def params(**over):
    p = dict(g0=Qty(1, Gd), kappa=Qty(1, Gd / Ad), c=Qty(F(1, 5), ONE), phi=Qty(F(1, 2), ONE),
             ell=Qty(1, Ld), gamma=Qty(F(1, 10), Td ** -1), dP_flow=Qty(1, Pd), seed=Qty(2, Ad),
             eps=Qty(F(1, 1000), Ad), z_max=Qty(10, Ad), e=Qty(F(1, 5), ONE))
    p.update(over)
    return p

def model(p=None, chains=True):
    p = p or params()
    dP = {'flow': p['dP_flow'], 'seed': Qty(0, Pd), 'rest': Qty(0, Pd)}
    alpha = p['phi'] * p['c'] / p['ell']                      # 量纲 L^-1
    def write_coef(u):
        return alpha * dP[u] * p['g0'] * dt, alpha * dP[u] * p['kappa'] * dt
    def relax_coef(u):
        return None, Qty(-1, ONE) * p['gamma'] * dt
    procs = []
    for i in (1, 2):
        b, f = f'bed{i}', f'flow{i}'
        procs.append(Process(f'write{i}', f'z{i}', b, (f'z{i}',), write_coef,
                             [(b, F(0)), (f, F(1, 4)), (b, F(1, 2))] if chains else None))
        procs.append(Process(f'relax{i}', f'z{i}', b, (f'z{i}',), relax_coef,
                             [(b, F(0)), (b, F(1, 2))] if chains else None))
    B = {'inlet', 'outlet', 'bed1', 'bed2', 'flow1', 'flow2', 'loose1', 'loose2'}
    links = {('inlet', 'flow1'), ('inlet', 'flow2'), ('flow1', 'outlet'), ('flow2', 'outlet'),
             ('bed1', 'loose1'), ('bed2', 'loose2'), ('loose1', 'flow1'), ('loose2', 'flow2'),
             ('bed1', 'flow1'), ('flow1', 'bed1'), ('bed2', 'flow2'), ('flow2', 'bed2'),
             ('bed1', 'bed1'), ('bed2', 'bed2')}
    letters = {'seed': [('z1', p['seed'], 'dump')], 'flow': [], 'rest': []}
    pos = {'z1': ('bed1', A_u), 'z2': ('bed2', A_u)}
    omitted = [(f'intake{i}', f'L{i}', (f'z{i}',), '弛豫脱落物入库（relax 的库存侧分项）') for i in (1, 2)] + \
              [(f'export{i}', f'L{i}', (f'L{i}', f'z{i}'), '库存由载液带出 min(L, eQΔt)，Q 经 g 读 z') for i in (1, 2)]
    return Model('族甲·恒压头两通道流网', B, links, pos, letters, procs, p['eps'],
                 {'z1': Qty(0, Ad), 'z2': Qty(0, Ad)}, extra=('L1', 'L2'), omitted=omitted), dP, alpha

def physics(hist, p=None, L0=0):
    """在 χ_甲 上直接按申报物理量逐拍计算，独立重算三本账；返回 z 轨迹（以 A_u 计）与核验记录。
    流体：各通道载液库存不变（不可压、满管），入流 = 出流；入口总量与出口总量分别由两端结点重算。
    结构物质：每通道 结构体积 zℓ 与疏松库存 L；边界通量 = 入口携带 + 外部投放 − 出口携带；
      逐拍核验 Δ(Σzℓ + ΣL) = 边界通量（库存量由状态差算出，边界通量由两端结点算出）。"""
    p = p or params()
    M, dP, alpha = model(p)
    V3 = Ld ** 3
    z = {1: Qty(0, Ad), 2: Qty(0, Ad)}
    L = {1: Qty(L0, V3), 2: Qty(L0, V3)}
    traj, log = [(z[1].v, z[2].v)], []
    for u in hist:
        g = {i: p['g0'] + p['kappa'] * z[i] for i in (1, 2)}
        Q = {i: g[i] * dP[u] for i in (1, 2)}                          # 载液流量 L^3/T
        load_in = {i: p['c'] * Q[i] * dt for i in (1, 2)}               # 入口携带结构物质体积
        dep = {i: p['phi'] * load_in[i] for i in (1, 2)}                # 转为结构
        ero = {i: p['gamma'] * dt * z[i] * p['ell'] for i in (1, 2)}    # 脱落入库存
        cap = {i: p['e'] * Q[i] * dt for i in (1, 2)}
        exp_ = {i: L[i] if L[i].v <= cap[i].v else cap[i] for i in (1, 2)}   # 库存输出（拍首库存）
        inj = {1: p['seed'] * p['ell'] if u == 'seed' else Qty(0, V3), 2: Qty(0, V3)}
        carry_out = {i: load_in[i] - dep[i] + exp_[i] for i in (1, 2)}  # 出口携带
        znew = {i: z[i] + (dep[i] - ero[i] + inj[i]) / p['ell'] for i in (1, 2)}
        Lnew = {i: L[i] - exp_[i] + ero[i] for i in (1, 2)}
        for i in (1, 2):
            assert dep[i].v <= load_in[i].v and exp_[i].v <= L[i].v and exp_[i].v <= cap[i].v
            assert Lnew[i].v >= 0 and carry_out[i].v >= 0
            assert g[i].v > 0 and 0 <= znew[i].v <= p['z_max'].v        # 本构适用域
            if Q[i].v == 0:
                assert exp_[i].v == 0 and carry_out[i].v == 0           # 零流量拍不输运
        # 流体：入口结点与出口结点分别重算
        q_in = sum((g[i] * dP[u] for i in (1, 2)), Qty(0, Dim(L=3, T=-1)))
        q_out = sum((Q[i] for i in (1, 2)), Qty(0, Dim(L=3, T=-1)))
        assert q_in.v == q_out.v
        # 结构物质：库存差（状态）= 边界通量（两端结点）
        inv0 = sum((z[i] * p['ell'] + L[i] for i in (1, 2)), Qty(0, V3))
        inv1 = sum((znew[i] * p['ell'] + Lnew[i] for i in (1, 2)), Qty(0, V3))
        bnd = sum((load_in[i] + inj[i] - carry_out[i] for i in (1, 2)), Qty(0, V3))
        assert (inv1 - inv0).v == bnd.v
        # 能量账（理想化见模块说明）：供给功率 = 黏性耗散，储能变化 0
        supply = dP[u] * (Q[1] + Q[2])
        diss = sum(((Q[i] * Q[i] / g[i]) for i in (1, 2)), Qty(0, supply.dim))
        assert supply.dim == diss.dim and supply.v == diss.v and diss.v >= 0
        log.append(dict(u=u, Q=(Q[1].v, Q[2].v), dep=(dep[1].v, dep[2].v), ero=(ero[1].v, ero[2].v),
                        exp=(exp_[1].v, exp_[2].v), L=(Lnew[1].v, Lnew[2].v), inj=inj[1].v,
                        carry_out=(carry_out[1].v, carry_out[2].v), supply=supply.v))
        z, L = znew, Lnew
        traj.append((z[1].v, z[2].v))
    return traj, log
~~~

A.3　fam\_neuro.py　族戊：生物神经网络发放率模型的机制模型申报与逐拍物理核验（第四节 4.3）

~~~python
"""族戊：生物神经网络发放率模型（一个前神经元经两个突触驱动两个后神经元）的物理机制模型申报 χ_戊。
本构前件（现象学，申报其假设地位）：
  N1 线性发放率：y_i = β·w_i·x（x 为前神经元发放率，适用域 y_i ≤ y_max；膜时间常数 ≪ Δt）；
  N2 Hebb 型可塑性：每拍写入 dz_i = η·x·y_i·Δt（前后共同活动；后神经元反传动作电位到达突触）；
  N3 权重衰减：每拍 −γ·z_i·Δt（受体内吞回到树突受体池）；
  N4 外部配对刺激：界外电极的配对刺激诱导突触 1 增强 Δw（受体取自后神经元 1 的受体池）；
  N5 受体收支：w = 受体数 × 单受体电导 g₁；写入从池中取受体，衰减把受体还池；池非负。
z_i = w_i − w0 为超基线突触电导（迹应）。时间：状态 t → 突触传递与发放 t+1/4 → 写入事件 t+1/2 → 状态 t+1。
"""
from fractions import Fraction as F
from ctor_core import Dim, Qty, ONE, Process, Model
Sd = Dim(M=-1, L=-2, T=3, I=2)             # 电导（西门子）
Hz = Dim(T=-1)
Td = Dim(T=1)
Ed = Dim(M=1, L=2, T=-2)                   # 能量
Wd = Ed / Td                               # 功率
S_u, x_u, dt = Qty(1, Sd), Qty(1, Hz), Qty(1, Td)

def params(**over):
    p = dict(w0=Qty(1, Sd), beta=Qty(1, Sd ** -1), eta=Qty(F(1, 10), Sd * Td),
             gamma=Qty(F(1, 10), Td ** -1), x_drive=Qty(1, Hz), seed=Qty(2, Sd),
             eps=Qty(F(1, 1000), Sd), g1=Qty(F(1, 10), Sd), pool0=40, y_max=Qty(100, Hz),
             e_spk=Qty(1, Ed), e_syn=Qty(1, Ed / Sd), e_pl=Qty(1, Ed / Sd))
    p.update(over)
    return p

def model(p=None, chains=True):
    p = p or params()
    x = {'drive': p['x_drive'], 'pair': Qty(0, Hz), 'rest': Qty(0, Hz)}
    def write_coef(u):
        return (p['eta'] * x[u] * (p['beta'] * p['w0'] * x[u]) * dt,
                p['eta'] * x[u] * p['beta'] * x[u] * dt)
    def relax_coef(u):

def physics(hist, p=None):
    p = p or params()
    M, x = model(p)
    z = {1: Qty(0, Sd), 2: Qty(0, Sd)}
    pool = {1: F(p['pool0']), 2: F(p['pool0'])}
    traj, log = [(z[1].v, z[2].v)], []
    for u in hist:
        w = {i: p['w0'] + z[i] for i in (1, 2)}
        y = {i: p['beta'] * w[i] * x[u] for i in (1, 2)}                 # Hz
        heb = {i: p['eta'] * x[u] * y[i] * dt for i in (1, 2)}            # 电导增量
        dec = {i: p['gamma'] * dt * z[i] for i in (1, 2)}
        ind = {1: p['seed'] if u == 'pair' else Qty(0, Sd), 2: Qty(0, Sd)}
        znew = {i: z[i] + heb[i] - dec[i] + ind[i] for i in (1, 2)}
        for i in (1, 2):
            take = (heb[i] + ind[i] - dec[i]) / p['g1']                    # 受体数净取用（无量纲）
            assert take.dim == ONE
            pool[i] -= take.v
            assert pool[i] >= 0 and y[i].v <= p['y_max'].v and znew[i].v >= 0 and w[i].v > 0
        # 代谢能量账（现象学）：供给 = 发放耗能 + 突触传递耗能 + 可塑性耗能；全部耗散，化学储能变化取 0
        # e_spk：每次发放耗能（能量）；e_syn：每次前突触发放、每单位突触电导的传递耗能；e_pl：每单位电导改变的可塑性耗能
        dw_abs = {i: Qty(abs((heb[i] - dec[i] + ind[i]).v), Sd) for i in (1, 2)}
        supply = (p['e_spk'] * (y[1] + y[2]) + p['e_syn'] * x[u] * (w[1] + w[2]) +
                  p['e_pl'] * (dw_abs[1] + dw_abs[2]) / dt)
        diss = supply
        assert supply.dim == Wd and diss.v >= 0
        log.append(dict(u=u, y=(y[1].v, y[2].v), heb=(heb[1].v, heb[2].v), dec=(dec[1].v, dec[2].v),
                        ind=ind[1].v, pool=(pool[1], pool[2]), supply=supply.v))
        z = znew
        traj.append((z[1].v, z[2].v))
    return traj, log
~~~

A.8　reach\_core.py　《场具化可达式》v1.0 附录 A.1 的字母门控 F 模型与窗读法求值器，与该篇附录 A.1 逐字相同

~~~python
"""场具化可达式：字母门控 F 模型、窗读法、增广可达搜索与暴力对照（精确有理运算，三值强 Kleene）
模型类 𝔐_GF（字母门控 F 模型）：有限位集 I、分辨率 ε；字母表 U（含静置 'rest'）；
每个字母 u 给出本拍的脉冲表 [(tgt, a_p, ext)] 与过程表 [Proc]；过程按《场具化数理式》D12 的三类数值律，
读取拍前状态；cert_eff = 1；cert_read、路径边认证由过程申报（直接边：读取位 → 过程，Γ_closed = 闭合）；
Ident、HistEv 申报为 1。一条输入史 h 的窗读法（本篇读法 RD）：W 取 h 的末 w 拍，W 之前的全部拍为形成史，
其 Form、Mark 记录在 F 中以入口拍的记录表示（数理式 D2），W 起点状态为形成史末态。
"""
from fractions import Fraction as Fr
from itertools import combinations, product
from collections import deque
ONE, ZERO, BOT = 1, 0, None

def k_and(*xs):
    if any(x == 0 for x in xs):
        return 0
    if any(x is None for x in xs):
        return None
    return 1

def k_or(*xs):
    if any(x == 1 for x in xs):
        return 1
    if any(x is None for x in xs):
        return None
    return 0

class Proc:
    def __init__(self, pid, tgt, car, law, R=(), k=0, b=0, cert_read=1, cert_path=1):
        self.pid, self.tgt, self.car, self.law = pid, tgt, car, law
        self.R, self.k, self.b = tuple(R), Fr(k), Fr(b)
        self.cert_read, self.cert_path = cert_read, cert_path
    def value(self, s):
        if self.law == 'const':
            return self.b
        if self.law == 'lin':
            return self.b + self.k * sum(s[j] for j in self.R)
        j1, j2 = self.R
        return self.b + self.k * s[j1] * s[j2]
    def supp_act(self, s):
        if self.law == 'const' or self.k == 0:
            return set()
        if self.law == 'lin':
            return set(self.R)
        j1, j2 = self.R
        out = set()
        if s[j2] != 0:
            out.add(j1)
        if s[j1] != 0:
            out.add(j2)
        return out
    def supp_cond(self, s, eps):
        sa = self.supp_act(s)
        if self.law == 'lin' and abs(self.value(s)) <= eps:
            sa |= set(self.R)
        return sa

class GF:
    """字母门控 F 模型。letters: {u: (pulses, procs)}；pulses = [(tgt, a, ext)]，ext ∈ {'out','in'}。"""
    def __init__(self, I, eps, letters, s0):
        """合法性前件（定义三）：位名非空互异；ε、初态、脉冲幅度为非负有理数（整数或 Fraction，不收浮点）；
        字母表有限且含 'rest'；过程标号在同一字母内互异；律 ∈ {const, lin, bilin}，lin 读取位非空，bilin 恰两位，
        const 无读取位；读取位与作用对象属位集；cert_read、cert_path ∈ {1, 0, None}；脉冲 ext ∈ {'out','in'}。
        不合法者抛出 ValueError，不进入求值。"""
        def rat(v, nonneg=False):
            if isinstance(v, bool) or not isinstance(v, (int, Fr)):
                raise ValueError('数值须为整数或 Fraction')
            if nonneg and v < 0:
                raise ValueError('须非负')
            return Fr(v)
        I = tuple(I)
        if not I or len(set(I)) != len(I) or any(not i for i in I):
            raise ValueError('位集')
        if 'rest' not in letters:
            raise ValueError('字母表须含 rest')
        for u, (pulses, procs) in letters.items():
            for (tgt, a, ext) in pulses:
                if tgt not in I or ext not in ('out', 'in'):
                    raise ValueError('脉冲')
                rat(a, True)
            ids = [p.pid for p in procs]
            if len(set(ids)) != len(ids):
                raise ValueError('过程标号重复')
            for p in procs:
                if p.tgt not in I or any(j not in I for j in p.R) or p.car not in ('B', 'out'):
                    raise ValueError('过程对象或读取位')
                if p.law not in ('const', 'lin', 'bilin') or (p.law == 'lin' and not p.R) or \
                   (p.law == 'bilin' and len(p.R) != 2) or (p.law == 'const' and p.R):
                    raise ValueError('律与读取位')
                if p.cert_read not in (1, 0, None) or p.cert_path not in (1, 0, None):
                    raise ValueError('认证值')
        if len(s0) != len(I):
            raise ValueError('初态长度')
        self.I, self.eps, self.letters = I, rat(eps, True), letters
        self.s0 = tuple(rat(x, True) for x in s0)
    def idx(self, i):
        return self.I.index(i)
    def step(self, s, u):
        """一拍（数理式 4.2、5.1）：返回 (后态, 新形成位集, 新标记位集, 过程事件表)；越出定义域返回 None。"""
        eps = self.eps
        pulses, procs = self.letters[u]
        d = {i: Fr(0) for i in self.I}
        sd = dict(zip(self.I, s))
        formed, marked, events = set(), set(), []
        for (tgt, a, ext) in pulses:
            a = Fr(a)
            if a > eps:                      # 有效脉冲：一律计入 Form（D16；与上游 field_final.py 第 123—126 行同），不论拍前深度
                formed.add(tgt)
                if ext == 'out':
                    marked.add(tgt)
                d[tgt] += a
        for p in procs:
            c = p.value(sd)
            act = 1 if abs(c) > eps else 0
            events.append((p, c, act))
            if act:
                if c > eps and sd[p.tgt] <= eps:   # 有效正分项使空位成为留迹元素（D16；上游第 161 行）
                    formed.add(p.tgt)
                if p.car == 'out':
                    marked.add(p.tgt)        # 界外载体机制的有效改变入 Mark
                d[p.tgt] += c
        s2 = tuple(sd[i] + d[i] for i in self.I)
        if any(x < 0 for x in s2):
            return None
        return s2, formed, marked, events

def window_eval(M, s_start, F_rec, M_rec, word):
    """窗读法：入口记录 F_rec、M_rec（位集），W = word。返回 dict：每个非空 T 的 Q 及 Fld、界内自反馈型。"""
    eps = M.eps
    s = s_start
    Form = set(F_rec)           # 「早于 t」的形成记录（入口拍记录早于 W 内一切拍）
    Mark = set(M_rec)
    ev_log = []                 # (avail_cond 全集, avail_act 全集, p, c, act)，T 相关部分事后按 T 截取
    for u in word:
        r = M.step(s, u)
        if r is None:
            return None
        s2, formed, marked, events = r
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev_log.append((ac, aa, p, act))
        Form |= formed
        Mark |= marked
        s = s2
    end = dict(zip(M.I, s))
    out = {}
    fld, selfref = 0, 0
    for n in range(1, len(M.I) + 1):
        for T in combinations(M.I, n):
            T = set(T)
            src = 1 if any(i in Mark for i in T) else 0
            ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
            trace = k_and(src, ret, 1, 1)   # Ident、HistEv 申报为 1
            part = k_or(*[k_and(1 if (ac & T) else 0, p.cert_read)
                          for (ac, aa, p, act) in ev_log if p.car == 'B']) if ev_log else 0
            hd_terms, sr_terms = [], []
            for (ac, aa, p, act) in ev_log:
                hc = k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0)
                hd_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
                if p.car == 'B':
                    sr_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
            hdyn = k_or(*hd_terms) if hd_terms else 0
            q = k_and(trace, part, hdyn)
            out[frozenset(T)] = q
            fld = k_or(fld, q)
            sr = k_and(q, k_or(*sr_terms) if sr_terms else 0)
            selfref = k_or(selfref, sr)
    return {'Q': out, 'Fld': fld, 'self': selfref, 'end': s}

def run_prefix(M, h):
    """形成史：自 s0 施加 h，返回 (末态, Form 位集, Mark 位集)。"""
    s, F, Mk = M.s0, set(), set()
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F |= fo
        Mk |= ma
    return s, frozenset(F), frozenset(Mk)

def fld_of_history(M, h, w):
    """输入史 h 的窗读法资格（W = 末 w 拍，w ≥ 1）。"""
    if w < 1:
        raise ValueError('w ≥ 1')
    if len(h) < w:
        return None
    pre = run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    return window_eval(M, s, F, Mk, h[len(h) - w:])

def physical_reach(M, letters=None):
    letters = letters or list(M.letters)
    seen, dq = {M.s0}, deque([M.s0])
    while dq:
        s = dq.popleft()
        for u in letters:
            r = M.step(s, u)
            if r and r[0] not in seen:
                seen.add(r[0])
                dq.append(r[0])
    return seen

def augmented_search(M, w, target='Fld', letters=None):
    """增广搜索：结点 (s, Form, Mark)；对每个结点枚举长 w 的窗词。返回最短满足史及结点统计。"""
    letters = letters or list(M.letters)
    start = (M.s0, frozenset(), frozenset())
    dist, par = {start: 0}, {start: None}
    dq = deque([start])
    while dq:
        node = dq.popleft()
        s, F, Mk = node
        for u in letters:
            r = M.step(s, u)
            if r is None:
                continue
            s2, fo, ma, _ = r
            nxt = (s2, F | fo, Mk | ma)
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                par[nxt] = (node, u)
                dq.append(nxt)
    best = None
    for node in sorted(dist, key=lambda n: dist[n]):
        if best is not None and dist[node] + w >= best[0]:
            break
        s, F, Mk = node
        for word in product(letters, repeat=w):
            e = window_eval(M, s, F, Mk, word)
            if e is not None and e[target] == 1:
                path, n = [], node
                while par[n] is not None:
                    n, u = par[n]
                    path.append(u)
                h = tuple(reversed(path)) + word
                if best is None or len(h) < best[0]:
                    best = (len(h), h)
                break
    N = len(physical_reach(M, letters))
    return {'best': best, 'nodes': len(dist), 'N': N,
            'max_prefix_dist': max(dist.values()), 'bound_prefix': (2 * len(M.I) + 1) * N - 1}

def brute_min(M, w, Lmax, target='Fld', letters=None):
    letters = letters or list(M.letters)
    for L in range(w, Lmax + 1):
        for h in product(letters, repeat=L):
            e = fld_of_history(M, h, w)
            if e is not None and e[target] == 1:
                return L, h
    return None
~~~
