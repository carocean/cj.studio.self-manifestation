自显论·工篇·场具化组式第七 v1.0

# 场具化实现式

一、式种申报  
本篇是实现式（成立证明附式）。唯一任务：对《场具化可达式》已证可达的沉积场目标，在显式申报的真实约束组下给出实现方案，逐项核验约束，给出实现记录与实现定理，并申报未落成的部分。  
本篇的结论分四组。  
　1．算法层实现：χ₀ 与判定式实例甲以程序为宿载。宿载的状态变量就是结构位，过程函数就是机制过程，入口函数就是信号入口。定理一给出两条模拟关系：精确宿载与原模型逐拍相等；binary64 宿载与申报的舍入运算图逐拍相等。实现记录一给出 7 条有限输入的执行记录，并在程序上实施 SEP、MOD、LOC、IMP、OUT-f 诸协议。  
　2．有限精度下的资格保持：经单一数值入口（定义四）之后，若区间后端能决定资格判定树的全部比较，则 binary64 实现与精确模型走同一分支，判词相同（定理二）；区间安全求值只给出正确判词或「数值未知」，从不错判（定理三）。  
　3．数制边界：等号点不满足正裕度（命题一）；binary64 比例衰减的终局依运算图与次正规策略而不同（引理一）；完整 F 模型可以因此翻转资格，而单个原子翻转不必翻转资格（命题二）。  
　4．候选部分：物质层的需求与认证追溯矩阵（第九节）、替代与对照操作、候选宿载状态（第十节）。这一部分不是实现定理的前提，不构成物质实现证书。  
强度定位：在法篇第二编第五章的强度顺序「相容 ≺ 构造 ≺ 可达 ≺ 实现」中，本篇取实现。  
本篇的实现限于算法层：以程序为宿载的有限执行，在所申报的平台、数制与预算之下落成。它不是物质宿载的实现，也不是对任何生物或物理系统的资格认证。  
理论增量：本篇回答一个上游各篇都不承担的问题——在什么真实约束下、以什么证据，可达目标被实现而不只被模拟。回答由四部分组成：  
　（甲）算法层对象身份与两条模拟关系；  
　（乙）真实约束组下的执行记录与协议实施；  
　（丙）上游完整三值资格判定树在有限精度下的保持条件与安全求值契约；  
　（丁）数制边界：等号点、运算图、次正规策略。  
区间包含、精确谓词与舍入分析的方法本身是已有方法。本篇的增量在于把上游判定树逐个原子纳入，隔离非数值原子，并给出沉积场资格在这些数制下的具体保持与失效条件。

### 2.3　三类证据并列

实现证据有三类，三类并列，不作递进：  
　（一）算法层实现：程序本身是宿载，被实现的是算法层对象。这是本篇第四至八节的对象。  
　（二）物质过程的计算模拟：程序模拟某个物质系统。它是算法层对象的实现，不是该物质系统的实现。第十节所引文献属此类，只作对照。  
　（三）物质宿载实现：物质系统承担结构位、过程与入口。现无此类记录。  
三类不能互相代替。第（一）类的成立不推出第（三）类，第（二）类的结果不推及被模拟的组织。

### 2.4　范围的分界

　（一）可达与构造分属可达式与构造式，此处承用，不重证；  
　（二）到达后的保持、退出与复归属稳定式；  
　（三）实现结论不构成任何物质宿载的资格认证；  
　（四）一切输入的最坏时间界与表示无关的资源下界未证；  
　（五）一般随机 Hist 协议与无限窗不在所论模型类内。

三、真实约束组  
定义一（真实约束组 𝒦）。本篇的实现在下列约束下落成并核验：  
　平台：Linux 6.18 x86\_64，glibc 2.39；Python 3.13.17；只用 Python 标准库。  
　数制：  
　　exact——Python Fraction，分子分母按展开形式保存；  
　　binary64——IEEE 754 双精度，默认最近舍入（偶数优先），sys.float\_info.mant\_dig = 53、rounds = 1，保留次正规数；  
　　区间——以有限 binary64 端点包住精确值的区间（定义五）。  
　　冲零模式（次正规结果置 0）只以程序模拟，不是本平台的运行模式。  
　数值入口：全部申报数值经定义四的单一入口规范化。  
　资源预算（每条实现记录）：墙钟时间 ≤ 5 秒，峰值内存 ≤ 8 MiB，运算次数由程序计数器计数。  
　测量范围：  
　　计时（time.perf\_counter）与峰值内存（tracemalloc）只覆盖宿载构造与逐拍执行；规格转写、上游求值、区间求值与交叉核对不在其内；  
　　tracemalloc 计 Python 分配的峰值，不是进程总驻留内存；  
　　运算计数器只计宿载数值律中的加与乘，不计 Fraction 约分、比较、转换、日志与认证求值。  
　　故资源预算只签「所列输入的宿载执行」，不签实现加认证的全流程或整机总资源。  
　量词：时间与内存预算只对第六节所列 7 条有限输入成立；对一切输入的成立与最坏时间界未证。  
　代码身份：附录 A 的 6 个程序及附录 B 所列 SHA-256。其中 A.5 field\_final.py 与《场具化数理式》附录 A.1 逐字相同，A.6 reach\_core.py 与《场具化可达式》附录 A.1 逐字相同。

四、实现方案  
定义二（宿载程序）。宿载程序是一个状态机（附录 A.2 的 Host），由位名表、过程表与入口脉冲表给定：  
　每个过程登记标号、载体（B 内或界外）、作用位、数值律（常数或线性）、读取位、系数 k、偏置 b 与运行条件（依本拍字母）；  
　每个入口脉冲登记标号、作用位、幅度与是否界外。  
每拍 beat(u) 依次执行：  
　读拍前状态；  
　对本拍字母的入口脉冲按 a \> ε 登记有效；  
　对本拍运行的每一过程按数值律由拍前状态计算分项 c，按 \|c\| \> ε 登记有效；  
　有效分项按发生次序（先脉冲，后过程）逐项加到拍前值上；  
　后态为负即越出定义域。  
执行日志逐拍记录拍前态、拍后态，以及实际发生的每一脉冲与过程的标号、载体、作用位、读取位、数值律、分项与是否有效。  
程序内不存放任何判词。判词由执行日志转写为上游 F 运行规格后，交上游求值器计算。  
对象身份（代码元素 → 模型元素）：  
　χ₀（附录 A.2 Chi0Host）：  
　　state\["x"\] → 结构位 x（沉积度 δ）；  
　　入口字母 u1、u5 → 界外信号脉冲 α·u（u = 1、5），与《场具化可达式》附录 A.6 的 F 层编码 chi0\_gf 相同；  
　　procs\["wb"\] → B 内读出回写，线性律 β·δ，读 x，每拍运行；  
　　procs\["dec"\] → B 内退浅，线性律 −λ·δ，读 x，每拍运行；  
　　readout() → 活动读出 a\_t = δ。  
　　截顶 δ\_max 不编码。程序逐拍断言后态 ≤ δ\_max，故只在不触顶区域运行，此时原模型与编码逐拍相同。  
　实例甲（附录 A.2 LinUnitHost），与《场具化可达式》附录 A.6 inst 的编码相同：  
　　state\["w"\] → 结构位 w；  
　　pulses\["init"\] → 入口拍的界外初始化脉冲 +1；  
　　procs\["fwd"\] → B 内纯读取，线性律，系数 0、偏置 0，读 w，每拍运行；  
　　procs\["opt"\] → 优化器，线性律 Δw = (2 − w)/4（k = −1/4，b = 1/2），只在字母 a 下运行；载体按 χ\_ext（界外）或 χ\_in（B 内）申报；  
　　readout\_fwd() → OUT-f：fwd 的读出等于 w。  
　　宿载不强制 𝓗\_甲；合法史由外部输入制度保证。  
协议的实施：  
　beat(u, knock=…) → MOD：撤去本拍的指定过程或脉冲；  
　beat(u, loc=…) → LOC：本拍前只设定指定结构位。  
数制：同一宿载以 exact 或 binary64 运行（附录 A.2 的 Num）。参数为申报的有理数；binary64 运行时取其最近双精度数。

五、模拟关系  
定义三（申报的舍入运算图）。宿载以 binary64 运行时，其运算图如下：  
　参数与初态由有理申报值取最近双精度数；  
　线性律分项为 fl(b + fl(k · s))，其中 s 为读取位之和，按读取位次序以 fl 逐次累加；  
　有效分项按发生次序逐项加到拍前值上：fl(fl(pre + t₁) + t₂)…；  
　有效阈与越域比较直接在双精度值上进行。

定理一（模拟关系）。  
　(a)　精确模拟。宿载以 exact 运行，在声明的合法域内（χ₀ 不触顶；实例甲的史属 𝓗\_甲），程序第 t 拍的拍前态、各过程分项、有效登记与拍后态，与《场具化数理式》4.2 对同一事件序列的有理递推逐项相等。  
　(b)　舍入运算图模拟。宿载以 binary64 运行时，其逐拍状态与定义三的运算图逐拍逐位相等。  
　(b) 不声称 binary64 状态等于原模型的精确状态。binary64 实现是否保持原模型的资格，由定理二的充分条件给出，或由具体原子与判词的逐条比对给出。  
证明。  
　(a)　定义二的逐拍步骤正是 4.2 与 5.1 第二至五步：读拍前状态；按 a \> ε 登记入口脉冲；按数值律由拍前状态计算各分项，按 \|c\| \> ε 登记；有效项相加更新；后态为负即越出定义域。χ₀ 在所列区域内截顶不触发（程序逐拍断言）。精确数制下运算无舍入，加法与次序无关。对拍数归纳即得。  
　(b)　宿载代码与定义三逐项对应：Num.c 取最近双精度数；value 先以 fl 累加读取位，再计算 fl(k·s)，再计算 fl(b + ·)；beat 先脉冲后过程，逐项加到拍前值上。对拍数归纳即得。∎  
见证（附录 B.1）：χ₀ 史 (u1, rest, rest)，精确宿载 x = 8/25；binary64 宿载 x = 0.32000000000000006，按上游十进制读法也不等于 8/25。两条关系必须分开签署。

七、有限精度下的资格保持

### 7.1　判定树的原子

上游求值器 field\_final.run 的资格判定树由下列原子组成。  
　状态相关的数值比较：  
　　有效脉冲 a \> ε；  
　　有效分项 \|c\| \> ε；  
　　线性律纯读取条件 \|c\| ≤ ε；  
　　双线性伙伴读数 ≠ 0（精确非零，不以 ε 替代）；  
　　可用位 s(i) \> ε；  
　　过程形成 c \> ε 且 s(tgt) ≤ ε；  
　　越出定义域 s′ \< 0；  
　　窗末留存 s(i) \> ε。  
　参数检查：系数 k ≠ 0，以申报的有理参数精确判定，不经运行数制。  
　非数值原子：certified\_effect、certified\_read、路径边认证、Ident、HistEv、形成先后（拍号）。原样传入，不由数值裕度改变。  
原子经强 Kleene 规则组合为 TraceSet、Part、HDyn 与 Q。附录 A.1 的通用求值器 feval 按此原子表复写上游判定树，数值运算与比较交给数制后端。  
定义四（单一数值入口与有效规格）。上游 field\_final.exact 的读数政策是：float 依其十进制表示 repr 取有理数（0.1 读作 1/10），整数与 Fraction 原样。  
feval.normalize 在上游合法性检查之后，按同一政策把全部申报数值（初态、ε、脉冲幅度、过程系数与偏置）一次规范化为有理数，所得规格称为有效规格。  
精确、binary64、区间三种后端都只对有效规格运算；binary64 与区间再由有理值转换。规范化是幂等的。  
故精确后端与上游是同一有效模型，精确回退回到上游模型。  
若以 float 的二进制展开值读入，则与上游不是同一模型：k = 0.1、b = 0.2、ε = 0.3 的单过程模型，分项按十进制读法恰等于阈值，上游判 0；按二进制展开值读入则分项大于阈值，判 1。附录 B.2 (3) 核对，规范化后两者都判 0，与其 Fraction 写法相同。  
核验（附录 B.2 (1)(3)）：精确后端与上游 field\_final.run 在 6000 个随机模型上 Q 逐个相同（越出定义域 294 个）；在 3000 个混合数值入口模型（各数值以 1/2 概率改为 float 申报）上逐个相同（越出定义域 122 个）。  
这是有限对照，只覆盖其生成器的数值域；全域同义由定义四的构造给出。  
定义五（区间后端与安全求值）。区间 \[lo, hi\] 以有限双精度端点包住精确值：  
　参数与初态由有理数 r 转换：记 f 为 r 的最近双精度数；f = r 时取单点 \[f, f\]，否则以 f 和 f 在 r 一侧的相邻浮点数为两端点，故区间同时包住 r 与 f；  
　加法取端点和、乘法取四个端点积的最小与最大值，再各向外移到相邻浮点数（math.nextafter）；与精确零的加乘不外移；  
　比较：区间整体满足或整体不满足时给出答案，否则不能决定；  
　申报值转换溢出、端点运算或外移后出现非有限值时，不能决定。  
安全求值 safe\_run 对合法申报只有三种结局：  
　（1）决定：全部比较由区间决定，且全部端点有限，输出 Q；  
　（2）⊥（数值未知）：有比较不能决定，或数值在有限端点下不可表示；  
　（3）报错：上游 check 拒绝的非法申报，或越出定义域。非法与数值不可表示分开报告。  
定理二（保持定理）。设有限确定 F 规格经定义四规范化为有效规格。binary64 实现指附录 A.1 的 binary64 后端：参数与初态取最近双精度数，常数律取 b，线性律取 fl(b + fl(k·s))（s 为读取位按次序的 fl 累加），双线性律取 fl(b + fl(fl(k·s₁)·s₂))，有效分项按发生次序逐项加到拍前值上；对线性律即定义三的运算图。若区间后端在全部比较上都能决定，则：  
　(a)　区间后端的 Q 等于精确 Q；  
　(b)　上述 binary64 实现中，判定树的每一分支都与精确实现相同，故 Q 相同；且该实现不溢出。  
证明。  
　包含不变量：每拍每个状态与中间量的精确值落在其区间内。参数与初态的转换同时包住有理值及其最近双精度数（定义五）。端点运算的精确结果 r 与其最近舍入 fl(r) 之间没有别的浮点数，故 fl(r) 向外的相邻浮点数在 r 之外，这一点在二进位边界与次正规区同样成立。加法的端点和、乘法四个端点积的极值经此外移，即包住精确结果的全部可能值；与精确零的加乘结果精确，不需外移。  
　binary64 值的包含：binary64 实现的同一中间量也落在同一区间内。参数与初态由定义五包住；操作数在区间内时，其精确结果介于端点运算的精确极值之间；舍入单调，故 binary64 结果介于端点舍入值之间，在外移后的区间内。端点有限，故 binary64 值有限，不溢出。  
　分支相同：区间能决定的比较，对区间内一切值给出同一答案，故精确值与 binary64 值走同一分支。参数检查以有理参数精确判定，非数值原子原样传入，两种实现相同。  
　对拍数与判定树的层次归纳，经强 Kleene 组合，得 Q 相同。∎  
范围：有限确定 F 规格、有限窗、所述三种后端与默认最近舍入。不涉及一般随机 Hist，不引入容差改变上游阈值。  
核验（附录 B.2 (2)(3)）：  
　6000 个随机模型中，区间决定 3515 个，全部与精确相同；在区间全部可决定的模型上，binary64 判词都与精确相同。binary64 与精确判词不同的 4 个模型，区间都返回 ⊥。  
　3000 个混合数值入口模型中，区间决定 1751 个，全部正确，binary64 判词都与精确相同。  
定理三（安全求值）。在定义五的契约下，安全求值只返回与精确 Q 相同的判词或 ⊥，从不错判。⊥ 时以精确数制回退，可得精确判词，代价是精确实现的资源。  
证明。结局（1）由定理二 (a) 给出。转换、运算与外移之后都核验端点有限，故结局（1）中不出现非有限端点。结局（2）不给判词。∎  
核验（附录 B.2 (4)）：初态 10^400（转换溢出）、初态 2·MAX（转换溢出）、初态 MAX 加脉冲 +1（外移溢出）都返回 ⊥；精确回退对 10^400 得 Q = 0；端点加法的外移溢出与端点乘法溢出都判为不能决定。  
保守性：区间算术不计相关性。有相抵过程时，例如 χ₀ 的 +β·δ 与 −λ·δ，包络宽度逐拍约放大 1 + β + λ 倍，中心只乘 1 + β − λ，相对宽度逐拍约放大 (1 + β + λ)/(1 + β − λ) = 7/4 倍，长窗上返回 ⊥（实现记录一 (6)）。这是安全的未知，不是负判。安全性不等于可决定性；精确回退不自带统一的资源预算。

八、数制边界  
命题一（等号点）。ε = 3/10，单过程线性律，读取位 x = 1，系数 1/10、偏置 2/10：分项精确等于 3/10，不大于阈值，无效；binary64 计算 0.2 + 0.1 得 0.30000000000000004，有效。精确 Q = 0，binary64 Q = 1，区间返回 ⊥（附录 B.2 (5)）。  
等号点不满足正裕度，只能精确回退或返回 ⊥。上游的严格不等式不以容差改写。  
引理一（binary64 比例衰减的终局，依运算图与次正规策略）。乘法图系数 a ∈ (0, 1) 与加法图系数 k ∈ (−1, 0) 各是被存储的浮点参数，分别申报；一般 fl(a − 1) 未必等于 a − 1，两图的对照只在所列 a、k 精确满足 k = a − 1 时作出。记 N = 2^(−1022)（最小正规数），q = 2^(−1074)（次正规间距）；默认最近偶数舍入。  
　(a)　乘法图 x ← fl(a·x)，保留次正规数，次正规区中状态为 m·q，即 m ↦ round(a·m)：a ≤ 1/2 时有限步到 0；a \> 1/2 时永不为 0，停在正整数不动点。  
　(b)　加法图 x ← fl(x + fl(k·x))（F 层线性退浅的运算图），保留次正规数，即 m ↦ m + round(k·m)：k \< −1/2 时有限步到 0；k ≥ −1/2 时停在正整数不动点。  
　(c)　两图在 a = 1/2（k = −1/2）处不同：乘法图归零，加法图停在 q。  
　(d)　正规区严格下降：乘法图 0 \< a ≤ 1 − 2^(−52) 时，对一切正规 x 有 fl(a·x) \< x；加法图 −1 \< k ≤ −2^(−52) 时，对一切正规 x 有 0 ≤ fl(x + fl(k·x)) \< x。于是在这些系数范围内，(a)(b) 的分类对一切正起点成立。  
　(e)　冲零模式（先舍入、后冲零：每次运算先按最近偶数舍入，再把所得次正规结果置 0），自正规起点，系数取 (d) 的范围：乘法图有限步归零；加法图的正规不动点集恰为  
　　S\_k = {正规浮点数 x：\|RN(k·x)\| \< N} = {正规浮点数 x：\|k\|·x \< N − q/2}，  
　　轨道有限步后或归零，或停在 S\_k 内的正规值，二者都发生，依起点而定。  
证明。  
　(a)　次正规区中 a·m·q 的最近舍入为 round(a·m)·q。a \> 1/2 时 a·m \> 1/2，舍入不小于 1；又 a \< 1，故 round(a·m) ≤ m，不增，停于正整数不动点。a ≤ 1/2 时：m = 1 得 round(a) = 0（a = 1/2 为平局，偶数舍入为 0）；m ≥ 2 时 round(a·m) ≤ round(m/2) ≤ m − 1，严格下降，故有限步到 0。  
　(b)　fl(k·m·q) = round(k·m)·q，与 m·q 相加精确，故 m′ = m + round(k·m)。k \> −1 时 round(k·m) ≥ −m，故 m′ ≥ 0。k \< −1/2 时：m = 1 得 round(k) = −1，即到 0；m ≥ 2 时 m′ ≤ m + k·m + 1/2 \< m，严格下降。k ≥ −1/2 时：m = 1 的减量 round(k) = −0，m′ = 1；m ≥ 2 时 m′ ≥ m(1 + k) − 1/2 ≥ 1/2，故 m′ ≥ 1，又 m′ ≤ m，停于正整数不动点。  
　(c)　由 (a)(b)。  
　(d)　记 g 为 x 与其下方相邻浮点数的间距。x 不是 2 的幂时 g \< 2^(−52)·x；x = 2^e（e \> −1022）时 g = 2^(−53)·x；x = N 时 g = q = 2^(−52)·x。故恒有 g ≤ 2^(−52)·x，且 x − g 是浮点数。  
　　乘法图：a·x ≤ x − 2^(−52)·x ≤ x − g，舍入单调，故 fl(a·x) ≤ x − g \< x。  
　　加法图：\|k·x\| ≥ 2^(−52)·x ≥ g，g 是浮点数，舍入单调且对称，故 c = fl(k·x) ≤ −g，x + c ≤ x − g，fl(x + c) ≤ x − g \< x。又 k·x \> −x，故 c ≥ fl(−x) = −x，x + c ≥ 0。  
　　正规数有限，故自任一正规起点，轨道有限步进入次正规区或 0，此后按 (a)(b)。由正规区不会直接到 0 的两种情形：乘法图 a \> 1/2 时 a·x \> x/2 ≥ N/2，舍入单调，fl(a·x) ≥ fl(N/2) = N/2 \> 0；加法图 k ≥ −1/2 时 k·x ≥ −x/2，c ≥ fl(−x/2) ≥ −x/2 − q/2（x ≥ 2N 时 x/2 是正规数，精确；N ≤ x \< 2N 时 x/2 落在次正规区，舍入误差不超过 q/2），故 x + c ≥ x/2 − q/2 ≥ N/2 − q/2 \> q/2，fl(x + c) ≥ q \> 0。  
　(e)　乘法图：轨道按 (d) 严格下降，首个落入次正规区的结果置 0。  
　　加法图，等价：N 下方相邻的浮点数为 N − q，尾数为奇，二者的中点为 N − q/2。故 RN(v) \< N 当且仅当 v \< N − q/2；v = N − q/2 为平局，偶数舍入到 N，不属 S\_k。  
　　S\_k 内的点都停滞：RN(k·x) 为次正规数或零，被置 0，x + 0 = x。  
　　S\_k 外的点都不停滞：\|RN(k·x)\| ≥ N，分项为正规数，不被置 0；又 \|k\|·x ≥ 2^(−52)·x ≥ g，按 (d) 的论证 fl(x + c) ≤ x − g \< x，冲零只能使其变为 0，仍小于 x。  
　　故轨道在 S\_k 外严格下降，有限步后或落入次正规区而置 0，或进入 S\_k 而停滞。∎  
系数条件不能去掉：乘法图 a = 1 − 2^(−53)（区间 (1 − 2^(−52), 1) 内唯一的浮点数）自 N 一步不变，因为 a·N 恰为平局，偶数舍入回到 N；加法图 k = −2^(−60) 自 1.0 一步不变，停在正规区。  
核验（附录 B.2 (6)(7)）：  
　(a)(b)：两图各 8 个系数与 6 个次正规起点（系数 0.999999 只核 5 个小起点）逐一相符；自 1.0 起，乘法图乘 0.5 于第 1075 次更新得 0，乘 0.75 于第 2586 次更新后停在 2q。

A.1　feval.py　通用数制 F 层求值器：单一数值入口、精确／binary64／区间三后端与安全求值（定义三、定义四、定义五，定理二、定理三）

~~~python
"""场具化实现式：通用数制 F 层求值器。
按《场具化数理式》附录 A.1 的上游求值器 field_final.run 的判定树逐项复写，数值运算与比较交给数制后端：
  Exact    ：有理精确运算（与上游同义）；
  Float64  ：IEEE 754 binary64、默认最近舍入（Python float），参数先舍入为最近的双精度数；
  Interval ：以双精度端点包住精确值的区间运算，每次运算后向外各移一个 ulp（math.nextafter），
             比较不能由区间决定、申报值超出有限范围或端点（含外移后）非有限时抛出 Undecided——安全求值只返回与精确值相同的判词或 ⊥。
判定树中的每一个状态相关比较都经后端：有效改变阈、精确非零（双线性伙伴读数）、纯读取条件、可用位、
形成登记、越出定义域、窗末留存。系数 k ≠ 0 的检查以申报的有理参数精确判定（参数不是运行状态）。
认证常量（cert_read、路径边、Ident、HistEv）不是数值，原样传入，不由数值裕度改变。"""
import math
from dataclasses import replace
from fractions import Fraction
from collections import defaultdict
import field_final as up

def normalize(x):
    """单一数值入口：按上游 field_final.exact 的政策（float 依其十进制表示 repr 取有理数，整数与 Fraction 原样）
    把全部申报数值——初态、阈值、脉冲幅度、过程系数与偏置——规范化为同一份有理有效规格。
    各后端（精确、binary64、区间）都只对这份规格运算；binary64 与区间再由有理值转换。"""
    E = up.exact
    return replace(x, initial=tuple(E(v) for v in x.initial), epsilon=E(x.epsilon),
                   pulses=tuple(replace(p, amount=E(p.amount)) for p in x.pulses),
                   processes=tuple(replace(m, coefficient=E(m.coefficient), bias=E(m.bias)) for m in x.processes))

class Undecided(Exception):
    pass

class Exact:
    name = 'exact'
    conv = staticmethod(lambda x: Fraction(x))
    add = staticmethod(lambda a, b: a + b)
    mul = staticmethod(lambda a, b: a * b)
    neg = staticmethod(lambda a: -a)
    gt = staticmethod(lambda a, b: a > b)        # a > b
    nonzero = staticmethod(lambda a: a != 0)
    absv = staticmethod(abs)

class Float64:
    name = 'binary64'
    conv = staticmethod(lambda x: float(Fraction(x)))
    add = staticmethod(lambda a, b: a + b)
    mul = staticmethod(lambda a, b: a * b)
    neg = staticmethod(lambda a: -a)
    gt = staticmethod(lambda a, b: a > b)
    nonzero = staticmethod(lambda a: a != 0)
    absv = staticmethod(abs)

def _fin(x):
    if not math.isfinite(x):                    # 端点溢出或非数：安全地返回未知，不作判词
        raise Undecided('区间端点非有限（数值不可在 binary64 有限端点下表示）')
    return x

def _down(x):                                   # 外移前后都核验：运算结果与外移结果都须有限
    return _fin(math.nextafter(_fin(x), -math.inf))

def _up(x):
    return _fin(math.nextafter(_fin(x), math.inf))

class Interval:
    """区间 (lo, hi)，lo ≤ 精确值 ≤ hi。最近舍入误差不超过半个 ulp，故每次运算后向外移一个 ulp 足以包住精确值。"""
    name = 'interval'
    @staticmethod
    def conv(x):
        x = Fraction(x)
        try:
            f = float(x)
        except OverflowError:                   # 合法的精确申报值超出 binary64 有限范围：数值不可表示，返回未知
            raise Undecided('申报数值超出 binary64 有限范围')
        _fin(f)
        lo = f if Fraction(f) <= x else _down(f)
        hi = f if Fraction(f) >= x else _up(f)
        return (lo, hi)
    @staticmethod
    def add(a, b):
        if a == (0.0, 0.0):            # 与精确零相加是精确的，不必外移
            return b
        if b == (0.0, 0.0):
            return a
        return (_down(a[0] + b[0]), _up(a[1] + b[1]))
    @staticmethod
    def mul(a, b):
        if a == (0.0, 0.0) or b == (0.0, 0.0):   # 与精确零相乘得精确零
            return (0.0, 0.0)
        ps = [a[0] * b[0], a[0] * b[1], a[1] * b[0], a[1] * b[1]]
        return (_down(min(ps)), _up(max(ps)))
    @staticmethod
    def neg(a):
        return (-a[1], -a[0])
    @staticmethod
    def gt(a, b):
        if a[0] > b[1]:
            return True
        if a[1] <= b[0]:
            return False
        raise Undecided('比较 a > b 不能由区间决定')
    @staticmethod
    def nonzero(a):
        if a[0] > 0 or a[1] < 0:
            return True
        if a[0] == 0 and a[1] == 0:
            return False
        raise Undecided('非零检查不能由区间决定')
    @staticmethod
    def absv(a):
        if a[0] >= 0:
            return a
        if a[1] <= 0:
            return (-a[1], -a[0])
        return (0.0, max(-a[0], a[1]))

def run(x, B=Exact, trace=None):
    """与 field_final.run 同一判定树；B 为数制后端。trace（列表）可收集逐拍原子，供实现记录核对。"""
    up.check(x)                     # 非法申报：抛 ValueError，不吞为未知
    x = normalize(x)                # 单一数值入口（与上游同一有效模型）
    eps = B.conv(x.epsilon)
    zero = B.conv(0)
    state = {s: B.conv(v) for s, v in zip(x.sites, x.initial)}
    formation = defaultdict(list)
    signal_marks = defaultdict(list)
    part, hdyn = [], []
    active_T = set(x.declared_T)
    for t in range(x.window[0] - 1, x.window[-1] + 1):
        before = dict(state)
        contributions = defaultdict(list)
        for p in x.pulses:
            if p.step != t:
                continue
            a = B.conv(p.amount)
            if p.certified is True and B.gt(a, eps):
                contributions[p.target].append((p.name, a))
                formation[p.target].append((p.name, t, p.external))
                if p.external:
                    signal_marks[p.target].append((p.name, t))
                if trace is not None:
                    trace.append(('pulse', t, p.name, 'effective'))
        for m in x.processes:
            if m.step != t:
                continue
            k, b = Fraction(m.coefficient), Fraction(m.bias)
            kB, bB = B.conv(k), B.conv(b)
            if m.law == 'constant':
                value = bB
            elif m.law == 'linear':
                acc = zero
                for s in m.reads:
                    acc = B.add(acc, before[s])
                value = B.add(bB, B.mul(kB, acc))
            else:
                value = B.add(bB, B.mul(B.mul(kB, before[m.reads[0]]), before[m.reads[1]]))
            eff = B.gt(B.absv(value), eps)
            is_action = up.tri_and(eff, m.certified_effect)
            support = ()
            if m.law == 'linear' and (k != 0 or not eff):
                support = m.reads
            elif m.law == 'bilinear' and k != 0:
                support = tuple(s for i, s in enumerate(m.reads) if B.nonzero(before[m.reads[1 - i]]))
            available = [s for s in support if s in active_T and B.gt(before[s], eps)
                         and any(a[1] < t for a in formation[s])]
            is_cond = up.tri_and(bool(available), m.certified_read)
            action_support = ()
            if m.law == 'linear' and k != 0:
                action_support = m.reads
            elif m.law == 'bilinear' and k != 0:
                action_support = tuple(s for i, s in enumerate(m.reads) if B.nonzero(before[m.reads[1 - i]]))
            action_available = [s for s in action_support if s in active_T and B.gt(before[s], eps)
                                and any(a[1] < t for a in formation[s])]
            action_nodes = [f'state:{s}:{t}' for s in action_available]
            action_route = up.path_status(x.links, action_nodes, m.name, x.closed_graph) if action_nodes else False
            is_hist = up.tri_and(bool(action_available), m.certified_read, action_route)
            if is_action is True:
                contributions[m.target].append((m.name, value))
                if B.gt(value, eps) and not B.gt(before[m.target], eps):
                    formation[m.target].append((m.name, t, not m.carrier_inside))
                if not m.carrier_inside:
                    signal_marks[m.target].append((m.name, t))
            if t in x.window:
                if m.carrier_inside:
                    part.append(is_cond)
                hdyn.append(up.tri_and(m.target in active_T, is_action, is_hist))
            if trace is not None:
                trace.append(('proc', t, m.name, bool(is_action), is_cond, is_hist))
        for s in x.sites:
            new = before[s]
            for _, v in contributions[s]:
                new = B.add(new, v)
            if B.gt(zero, new):
                raise ValueError('negative trace depth')
            state[s] = new
        if trace is not None:
            trace.append(('post', t, dict(state)))
    ts = x.declared_T
    eligible = all(B.gt(state[s], eps) and formation[s] for s in ts)
    sources = {o for site in ts for o, _ in signal_marks[site]}
    trace_v = up.tri_and(bool(sources), eligible, x.identity, x.trace_history)
    pw, hw = up.tri_or(part), up.tri_or(hdyn)
    return {'trace': trace_v, 'part': pw, 'hdyn': hw, 'Q': up.tri_and(trace_v, pw, hw), 'state': state}

def safe_run(x):
    """安全求值：区间后端。
    返回 decided=True 时，全部比较由区间决定且全部端点有限，Q 与精确值相同；
    比较不能决定、申报值超出 binary64 有限范围、或端点运算／外移溢出时返回 Q = '⊥'（数值未知），可以精确回退；
    非法申报（上游 check 拒绝）与越出定义域照常抛 ValueError，不吞为未知。"""
    try:
        r = run(x, Interval)
    except Undecided as e:
        return {'Q': '⊥', 'decided': False, 'why': str(e)}
    assert all(math.isfinite(e) for v in r['state'].values() for e in v)
    return {'Q': r['Q'], 'decided': True}
~~~

~~~python
"""场具化实现式 E1：算法层宿载程序。
被实现的是算法层对象本身（不是某物理系统的模拟）：程序的状态变量即结构位，程序中各过程函数即机制过程，
入口函数即信号入口。每拍按《场具化数理式》4.2 读拍前状态、计算各分项、按有效阈登记并更新；执行日志逐拍记录
实际发生的脉冲与过程（标号、载体、作用对象、读取位、数值律、分项、是否有效）。程序不存放任何判词。
判词由执行日志转写为上游 F 运行规格后，交上游求值器 field_final.run 计算（精确数制），或按宿载自身数制的
同一判定树计算（feval，binary64）。数制：'exact'（Fraction）或 'binary64'（Python float）。"""
from fractions import Fraction
import field_final as up

class Num:
    def __init__(self, kind):
        assert kind in ('exact', 'binary64')
        self.kind, self.ops = kind, 0
    def c(self, x):
        return Fraction(x) if self.kind == 'exact' else float(Fraction(x))
    def add(self, a, b):
        self.ops += 1
        return a + b
    def mul(self, a, b):
        self.ops += 1
        return a * b

class Host:
    """通用宿载程序框架：sites、procs（标号 → (载体在 B 内?, 作用对象, 律, 读取位, k, b, 运行条件)）、入口脉冲表。"""
    sites = ()
    procs = {}
    pulses = {}          # 字母 → [(标号, 作用对象, 幅度, 界外?)]
    eps = Fraction(0)
    def __init__(self, kind, init):
        self.N = Num(kind)
        self.state = {s: self.N.c(v) for s, v in zip(self.sites, init)}
        self.log = []
        self.t = 0
    def value(self, pid, pre):
        inside, tgt, law, reads, k, b, cond = self.procs[pid]
        k, b = self.N.c(k), self.N.c(b)
        if law == 'constant':
            return b
        acc = self.N.c(0)
        for s in reads:
            acc = self.N.add(acc, pre[s])
        return self.N.add(b, self.N.mul(k, acc))
    def beat(self, letter, knock=(), loc=None):
        """一拍。knock：本拍撤去的过程或脉冲标号（MOD 的实施）；loc：本拍前把某位设定为某值（LOC 的实施）。"""
        if loc:
            for s, v in loc.items():
                self.state[s] = self.N.c(v)
        pre = dict(self.state)
        eps = self.N.c(self.eps)
        ev = {'t': self.t, 'letter': letter, 'pre': pre, 'pulses': [], 'procs': []}
        terms = {s: [] for s in self.sites}      # 本拍有效分项，按发生次序（先脉冲、后过程）
        for (pid, tgt, amt, ext) in self.pulses.get(letter, []):
            if pid in knock:
                continue
            a = self.N.c(amt)
            eff = a > eps
            ev['pulses'].append((pid, tgt, amt, ext, eff))
            if eff:
                terms[tgt].append(a)
        for pid, (inside, tgt, law, reads, k, b, cond) in self.procs.items():
            if not cond(letter) or pid in knock:
                continue
            c = self.value(pid, pre)
            eff = abs(c) > eps
            ev['procs'].append((pid, inside, tgt, law, reads, k, b, c, eff))
            if eff:
                terms[tgt].append(c)
        for s in self.sites:                     # 逐项加到拍前值上（与 4.2 及 feval 的运算图相同：((pre + t1) + t2) + …）
            new = pre[s]
            for v in terms[s]:
                new = self.N.add(new, v)
            self.state[s] = new
            if self.state[s] < 0:
                raise ValueError('negative trace depth')
        ev['post'] = dict(self.state)
        self.log.append(ev)
        self.t += 1
        return ev
    def to_spec(self, w, T, links_cert=True):
        """把执行日志转写为上游 F 运行规格：入口拍 = 日志中 W 之前最后一拍；W = 末 w 拍。
        只用于形成史为 1 拍（日志长 w + 1）的情形，此时与上游 F 运行同义。"""
        assert len(self.log) == w + 1
        pulses, procs, links = [], [], []
        for ev in self.log:
            t = ev['t']
            for (pid, tgt, amt, ext, eff) in ev['pulses']:
                pulses.append(up.Pulse(f'{pid}@{t}', t, tgt, Fraction(amt), ext))
            for (pid, inside, tgt, law, reads, k, b, c, eff) in ev['procs']:
                name = f'{pid}@{t}'
                procs.append(up.Process(name, t, tgt, inside, law, tuple(reads), Fraction(k), Fraction(b), True, True))
                if t >= 1:
                    for r in reads:
                        links.append(up.Link(f'state:{r}:{t}', name, links_cert))
        init = tuple(Fraction(self.log[0]['pre'][s]) for s in self.sites)
        return up.Spec(sites=self.sites, initial=init, window=tuple(range(1, w + 1)), pulses=tuple(pulses),
                       processes=tuple(procs), links=tuple(links), epsilon=self.eps, declared_T=tuple(T))

class Chi0Host(Host):
    """χ₀（《场具化一般式》第六节）：δ' = min{δ_max, δ + α·u + β·δ − λ·δ}，α = 1/2、β = 1/10、λ = 3/10、δ_max = 3、ε = 0。
    入口：字母 u1（u = 1）、u5（u = 5）施加界外脉冲 α·u（与《场具化可达式》附录 A.6 chi0_gf 的 F 层编码相同，不含截顶）；B 内过程：读出回写 wb（β·δ）、退浅 dec（−λ·δ），每拍运行。"""
    sites = ('x',)
    alpha, beta, lam, dmax = Fraction(1, 2), Fraction(1, 10), Fraction(3, 10), Fraction(3)
    procs = {'wb': (True, 'x', 'linear', ('x',), Fraction(1, 10), 0, lambda u: True),
             'dec': (True, 'x', 'linear', ('x',), Fraction(-3, 10), 0, lambda u: True)}
    pulses = {'u1': [('sig', 'x', Fraction(1, 2), True)], 'u5': [('sig', 'x', Fraction(5, 2), True)]}
    eps = Fraction(0)
    def beat(self, letter, **kw):
        ev = super().beat(letter, **kw)
        assert ev['post']['x'] <= self.N.c(self.dmax), '本记录只在不触顶的区域运行（截顶未触发）'
        return ev
    def readout(self):
        """活动读出 a_t = δ（读出以 δ 为条件）。"""
        return self.state['x']

class LinUnitHost(Host):
    """判定式实例甲（7.5、附录 A.7）：位 w，ε = 1/100；init：入口界外初始化脉冲 +1；
    fwd：B 内纯读取（作用于 w，系数 0、偏置 0，每拍运行）；opt：训练输入 a 下 Δw = (2 − w)/4，载体按申报（χ_ext 界外、χ_in 在 B 内）。"""

        super().__init__(kind, (0,))
    def readout_fwd(self):
        """OUT-f：fwd 的读出等于所读位 w 的值。"""
        return self.state['w']
~~~

~~~python
    opt = rc.Proc('opt', 'w', car_opt, 'lin', R=('w',), k=Fr(-1, 4), b=Fr(1, 2))
    return rc.GF(I=('w',), eps=Fr(1, 100),
                 letters={'rest': ([], [fwd]), 'init': ([('w', 1, 'out')], [fwd]), 'a': ([], [opt, fwd])}, s0=(0,))

def record(obj, hist, kind='exact'):

    h = make(obj, kind)
    for u in hist:
        h.beat(u)
    dt = time.perf_counter() - t0; peak = tracemalloc.get_traced_memory()[1]; tracemalloc.stop()

        assert {k: Fr(v) for k, v in ev['pre'].items()} == r['before']
~~~

A.4　e2\_precision.py　有限精度下的资格保持与数制边界（第七节核验，定理二、定理三，命题一、引理一、命题二、命题三）

~~~python
"""E2：有限精度实现下资格判定树的保持（有限确定 F 子类、有限窗、binary64 默认最近舍入）。
（1）通用求值器精确后端与上游 field_final.run 的逐项比对（第七节核验）；
（2）随机模型上：精确、binary64、区间安全求值三者对照——区间求值从不给出与精确不同的判词；binary64 可以翻转（定理二、定理三）；
（3）混合数值入口：float 申报按上游十进制读法规范化（定义四）；

def rand_spec(rng, w=None):
    sites = ('x', 'y')[:rng.choice([1, 2])]
    w = w or rng.choice([1, 2, 3])
    window = tuple(range(1, w + 1))
    vals = [Fr(0), Fr(1, 10), Fr(2, 10), Fr(3, 10), Fr(1, 2), Fr(1), Fr(2)]
    pulses, procs, links = [], [], []
    n = 0
    for t in range(0, w + 1):
        for s in sites:
            if rng.random() < 0.3:
                pulses.append(up.Pulse(f'p{n}', t, s, rng.choice(vals[1:]), rng.random() < 0.7)); n += 1
            if rng.random() < 0.6:
                law = rng.choice(['constant', 'linear', 'linear', 'bilinear'])
                reads = () if law == 'constant' else ((rng.choice(sites),) if law == 'linear' else (rng.choice(sites), rng.choice(sites)))
                k = rng.choice([Fr(0), Fr(1, 10), Fr(-1, 2), Fr(1), Fr(1, 3)])
                b = rng.choice([Fr(0), Fr(1, 10), Fr(2, 10), Fr(-1, 10), Fr(3, 10)])
                name = f'm{n}'; n += 1
                procs.append(up.Process(name, t, s, rng.random() < 0.7, law, reads, k, b, True, rng.choice([True, True, None, False])))
                if t >= 1:
                    for r in reads:
                        links.append(up.Link(f'state:{r}:{t}', name, rng.choice([True, True, None, False])))
    T = tuple(rng.sample(sites, rng.choice([1, len(sites)])))
    return up.Spec(sites=sites, initial=tuple(rng.choice(vals) for _ in sites), window=window, pulses=tuple(pulses),

def sub_orbit(a, m0, graph='mul', ftz=False, limit=10 ** 6):
    """自 m0·q 出发（q = 2^(−1074)）。graph = 'mul'：x ← a·x；graph = 'add'：x ← x + k·x，k = a − 1（F 层线性退浅的运算图）。"""
    k = a - 1.0
    assert Fr(k) == Fr(a) - 1                    # 存储参数：加法系数 k = fl(a − 1) 在所列 a 上精确等于 a − 1
    m = m0
    for i in range(limit):
        xq = m * Q
        if graph == 'mul':
            x = a * xq
        else:
            d = k * xq
            if ftz and 0 < abs(d) < sys.float_info.min:
                d = -0.0
            x = xq + d
        if ftz and 0 < abs(x) < sys.float_info.min:
            x = 0.0
        m2 = round(x / Q)
        if m2 == m:
            return ('stall', m, i)
        if m2 == 0:
            return ('zero', 0, i + 1)
        m = m2
    return ('?', m, limit)

# 冲零下次正规状态不可达，故自正规起点检验。系数 k 为被存储的浮点参数。

    return 0.0 if 0 < abs(v) < MINN else v
def ftz_step(x, k, graph):
    return ftzf((1.0 + k) * x) if graph == 'mul' else ftzf(x + ftzf(k * x))

    return abs(Fr(k)) * Fr(x) < Fr(MINN) - Fr(QQ) / 2

        if y == x:
            return ('stall', x, i)
        if y == 0.0:
            return ('zero', 0.0, i + 1)
        x = y
    return ('?', x, limit)
~~~

A.6　reach\_core.py　《场具化可达式》v1.0 附录 A.1 的字母门控 F 模型与窗读法求值器，与该篇附录 A.1 逐字相同

~~~python
"""场具化可达式：字母门控 F 模型、窗读法、增广可达搜索与暴力对照（精确有理运算，三值强 Kleene）

每个字母 u 给出本拍的脉冲表 [(tgt, a_p, ext)] 与过程表 [Proc]；过程按《场具化数理式》D12 的三类数值律，

其 Form、Mark 记录在 F 中以入口拍的记录表示（数理式 D2），W 起点状态为形成史末态。

from fractions import Fraction as Fr
from itertools import combinations, product
from collections import deque
ONE, ZERO, BOT = 1, 0, None

def k_and(*xs):
    if any(x == 0 for x in xs):

    return 1

    if any(x == 1 for x in xs):

class Proc:
    def __init__(self, pid, tgt, car, law, R=(), k=0, b=0, cert_read=1, cert_path=1):
        self.pid, self.tgt, self.car, self.law = pid, tgt, car, law
        self.R, self.k, self.b = tuple(R), Fr(k), Fr(b)
        self.cert_read, self.cert_path = cert_read, cert_path
    def value(self, s):
        if self.law == 'const':
            return self.b
        if self.law == 'lin':
            return self.b + self.k * sum(s[j] for j in self.R)
        j1, j2 = self.R
        return self.b + self.k * s[j1] * s[j2]
    def supp_act(self, s):
        if self.law == 'const' or self.k == 0:
            return set()
        if self.law == 'lin':
            return set(self.R)
        j1, j2 = self.R
        out = set()
        if s[j2] != 0:
            out.add(j1)
        if s[j1] != 0:
            out.add(j2)
        return out
    def supp_cond(self, s, eps):
        sa = self.supp_act(s)
        if self.law == 'lin' and abs(self.value(s)) <= eps:
            sa |= set(self.R)
        return sa

class GF:
    """字母门控 F 模型。letters: {u: (pulses, procs)}；pulses = [(tgt, a, ext)]，ext ∈ {'out','in'}。"""
    def __init__(self, I, eps, letters, s0):
        """合法性前件（定义三）：位名非空互异；ε、初态、脉冲幅度为非负有理数（整数或 Fraction，不收浮点）；
        字母表有限且含 'rest'；过程标号在同一字母内互异；律 ∈ {const, lin, bilin}，lin 读取位非空，bilin 恰两位，
        const 无读取位；读取位与作用对象属位集；cert_read、cert_path ∈ {1, 0, None}；脉冲 ext ∈ {'out','in'}。
        不合法者抛出 ValueError，不进入求值。"""
        def rat(v, nonneg=False):
            if isinstance(v, bool) or not isinstance(v, (int, Fr)):
                raise ValueError('数值须为整数或 Fraction')
            if nonneg and v < 0:
                raise ValueError('须非负')
            return Fr(v)
        I = tuple(I)
        if not I or len(set(I)) != len(I) or any(not i for i in I):
            raise ValueError('位集')
        if 'rest' not in letters:
            raise ValueError('字母表须含 rest')
        for u, (pulses, procs) in letters.items():
            for (tgt, a, ext) in pulses:
                if tgt not in I or ext not in ('out', 'in'):
                    raise ValueError('脉冲')
                rat(a, True)
            ids = [p.pid for p in procs]
            if len(set(ids)) != len(ids):
                raise ValueError('过程标号重复')
            for p in procs:
                if p.tgt not in I or any(j not in I for j in p.R) or p.car not in ('B', 'out'):
                    raise ValueError('过程对象或读取位')
                if p.law not in ('const', 'lin', 'bilin') or (p.law == 'lin' and not p.R) or \
                   (p.law == 'bilin' and len(p.R) != 2) or (p.law == 'const' and p.R):
                    raise ValueError('律与读取位')
                if p.cert_read not in (1, 0, None) or p.cert_path not in (1, 0, None):

        eps = self.eps

                    formed.add(p.tgt)

def window_eval(M, s_start, F_rec, M_rec, word):
    """窗读法：入口记录 F_rec、M_rec（位集），W = word。返回 dict：每个非空 T 的 Q 及 Fld、界内自反馈型。"""
    eps = M.eps
    s = s_start
    Form = set(F_rec)           # 「早于 t」的形成记录（入口拍记录早于 W 内一切拍）
    Mark = set(M_rec)
    ev_log = []                 # (avail_cond 全集, avail_act 全集, p, c, act)，T 相关部分事后按 T 截取
    for u in word:
        r = M.step(s, u)
        if r is None:
            return None
        s2, formed, marked, events = r
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev_log.append((ac, aa, p, act))
        Form |= formed
        Mark |= marked
        s = s2
    end = dict(zip(M.I, s))
    out = {}
    fld, selfref = 0, 0
    for n in range(1, len(M.I) + 1):
        for T in combinations(M.I, n):
            T = set(T)
            src = 1 if any(i in Mark for i in T) else 0
            ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
            trace = k_and(src, ret, 1, 1)   # Ident、HistEv 申报为 1
            part = k_or(*[k_and(1 if (ac & T) else 0, p.cert_read)
                          for (ac, aa, p, act) in ev_log if p.car == 'B']) if ev_log else 0
            hd_terms, sr_terms = [], []
            for (ac, aa, p, act) in ev_log:
                hc = k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0)
                hd_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
                if p.car == 'B':
                    sr_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
            hdyn = k_or(*hd_terms) if hd_terms else 0
            q = k_and(trace, part, hdyn)
            out[frozenset(T)] = q
            fld = k_or(fld, q)
            sr = k_and(q, k_or(*sr_terms) if sr_terms else 0)
            selfref = k_or(selfref, sr)
    return {'Q': out, 'Fld': fld, 'self': selfref, 'end': s}

def run_prefix(M, h):
    """形成史：自 s0 施加 h，返回 (末态, Form 位集, Mark 位集)。"""
    s, F, Mk = M.s0, set(), set()
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F |= fo
        Mk |= ma
    return s, frozenset(F), frozenset(Mk)

def fld_of_history(M, h, w):
    """输入史 h 的窗读法资格（W = 末 w 拍，w ≥ 1）。"""
    if w < 1:
        raise ValueError('w ≥ 1')
    if len(h) < w:
        return None
    pre = run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    return window_eval(M, s, F, Mk, h[len(h) - w:])

def physical_reach(M, letters=None):
    letters = letters or list(M.letters)
    seen, dq = {M.s0}, deque([M.s0])
    while dq:
        s = dq.popleft()
        for u in letters:
            r = M.step(s, u)
            if r and r[0] not in seen:
                seen.add(r[0])
                dq.append(r[0])
    return seen

                continue
            s2, fo, ma, _ = r
            nxt = (s2, F | fo, Mk | ma)
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                par[nxt] = (node, u)
                dq.append(nxt)
    best = None
    for node in sorted(dist, key=lambda n: dist[n]):
        if best is not None and dist[node] + w >= best[0]:
            break
        s, F, Mk = node
        for word in product(letters, repeat=w):
            e = window_eval(M, s, F, Mk, word)
            if e is not None and e[target] == 1:
                path, n = [], node
                while par[n] is not None:
                    n, u = par[n]
                    path.append(u)
                h = tuple(reversed(path)) + word
                if best is None or len(h) < best[0]:
                    best = (len(h), h)
                break
    N = len(physical_reach(M, letters))
    return {'best': best, 'nodes': len(dist), 'N': N,
            'max_prefix_dist': max(dist.values()), 'bound_prefix': (2 * len(M.I) + 1) * N - 1}

def brute_min(M, w, Lmax, target='Fld', letters=None):
    letters = letters or list(M.letters)
    for L in range(w, Lmax + 1):
        for h in product(letters, repeat=L):
            e = fld_of_history(M, h, w)
            if e is not None and e[target] == 1:
                return L, h
    return None
~~~
