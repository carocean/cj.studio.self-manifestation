自显论·工篇·场具化组式第八 v1.0

# 场具化动力源式

一、式种申报  
本篇是源式（第二组来源转变附式）。唯一任务：在字母门控 F 模型与窗读法中，冻结模型、机制、实际史、评价点与目标作用之后，刻画本次承担历史动力的那一作用事件，其「出自迹应」的部分——所读位的可用性、双线性伙伴的精确非零、作用的有效性——由实际史中哪些事件激活并贡献；在回放干预下，这些事件的充分、必要与替代关系如何；来源不唯一时，理论最多能确定到什么程度。  
责任范围：本次历史动力作用。来源对象不含资格整体的首次形成，也不含动力律、耦合或过程表本身的生成。  
本篇的结论分五组。  
　1．默认来源的排除：目标作用只经拍前状态与拍前形成记录依赖过去（定理一）；常数律与零系数过程不承担历史动力（推论一）；过程表是否单独决定本次历史动力，取决于 Φ\_e 在申报史族上是否恒定，一般不成立，三条通道各有见证（推论二）；形成记录一般不是状态的函数（命题一）。  
　2．发生过程：实际祖先图有限，回溯止于三类根，节点数有显式上界（定理二）。  
　3．来源定理：非负族中形成记录按位由状态与有效脉冲决定（定理三）；非负族中三个目标层都对保留事件单调，必要事件由单删检验精确判定，最小充分集都含于实际祖先，实际祖先与冻结背景不交时，删去候选域中的全部祖先则目标失效（定理四）；族外的若干失效现象（命题二）；双线性伙伴只须精确非零，不要求已形成或阈上，可以来自初态，也可以由历史形成（定理五）；资格的信号条件与作用的来源分账（命题三）。  
　4．不能唯一确定之处：过定、替代形成兼抢先、联合充分、越域缺口、合法未定、层间分账、冗余祖先七类，及各类下可确定的集合（命题四）。  
　5．实例：χ₀ 的无截顶 F 变体与原 χ₀ 的桥接域（命题五）；判定式实例甲（命题六）。  
强度定位：  
　所签的「来源」是冻结背景下的反事实保留集结构与实际祖先限制：充分、必要、祖先包含。它不是实际形成责任的分摊，也不是对象的首次存在或首次可达。  
　各结论都在形式模型内，不构成任何物质宿载的来源认证。  
理论增量：上游各篇证明了沉积场资格的成立、判定、可达、实现与保持，都把历史动力作为读数，没有一篇追溯它由哪些实际事件压出。本篇的增量落在沉积场特有的三处结构上：  
　形成登记带来的回放替代形成；  
　精确非零与阈值有效性的混合；  
　负改变造成的越域与非单调。  
非负族中越域与非单调被排除，形成登记的抢先仍会出现，但被约束在实际祖先之内（命题四（1）、定理四（v））；来源结构可以精确刻画。族外只能以有限合法掩码表给出。各证明是初等的（单调性、归纳、闭包）。

三、对象申报  
定义一（目标与评价点）。冻结 M ∈ 𝔐\_GF、窗长 w ≥ 1、实际史 h；评价点集 E(h) = {t：w ≤ t ≤ \|h\|}，取 t\* ∈ E(h)；承担集 ∅ ≠ T ⊆ I；目标事件 e 为第 b 拍（b 为 h 中的拍序，t\* − w \< b ≤ t\*，即该拍属 t\* 的窗）的过程实例 p。记拍前状态 s = s\_{b−1}、拍前形成记录 Fo = Form\_{b−1}。三个目标层：  
　O₁（主线，固定作用事件）：HD\_e(T) = τ ∧ η ∧ H。  
　　τ = \[p 的作用对象 ∈ T\]；  
　　η = \[\|c\_p(s)\| \> ε\]；  
　　H = α ∧ κ，α = \[∃i ∈ Supp\_act,p(s) ∩ T：s\_i \> ε 且 i ∈ Fo\]，κ = cert\_read ∧ cert\_path；α 为 0 时 H = 0；  
　　合取按强 Kleene。  
　这是 D18、D19 的 \[tgt ∈ T\] ∧ Act\_F ∧ HistCond\_F 在 𝔐\_GF 中的写法：𝔐\_GF 中 cert\_eff = 1，故 Act\_F = η；证据路径为读取位到过程的直接边，其路径状态即 cert\_path；α 即 Avail\_act ≠ ∅（D17）。  
　O₂（并列）：同一 t\* 上的 HDyn(T)，即窗内各过程事件 HD 项的析取。  
　O₃（并列）：同一 t\* 上的 Fld\_RD。  
目标作用消失而另一作用接替时，对 O₁ 判不保持，对 O₂、O₃ 可判保持；三者分账，不互代。回放中改找更晚的评价点或另一承担集，不属本协议。  
定义二（三值首次性）。Genesis(h, t) = Fld\_RD(h≤t) ∧ ⋀\_{t′∈E(h), t′\<t} ¬Fld\_RD(h≤t′)（强 Kleene）。  
　当前 1 且更早评价点全为 0：认证的首次成立；  
　当前为 0，或更早有 1：Genesis = 0；  
　其余情形（当前 1 而更早有 ⊥ 无 1；当前 ⊥ 而更早无 1）：首次性未定。  
首次性只作限定词：Genesis = 1 时来源结论可加注「首次形成情形」，否则不签首次性。首个正读数不称首次成立。  
定义三（来源协议 Π\_src）。  
　（1）冻结项：M（含字母表、过程表、数值律、系数、认证原子）、w、h、t\*、目标层与其参数 (T, b, p)。  
　（2）事件个别化：一个事件是「第 t 拍的第 k 个脉冲实例」(t, pulse, k)，或「第 t 拍的过程实例 pid」(t, proc, pid)。实际中无效的实例也是事件。  
　（3）干预：删除指定拍的个别事件，即在该拍改用一个只少了这些事件的字母；同拍其余事件与其他各拍不变。该字母名须新鲜，原字母一概不被覆写；过程标号与拍标号不变。  
　（4）重算：回放自 s₀ 起，保留事件的分项、有效性、支持、形成与标记一律依回放前态重算。不重算的「冻结数值」干预不属此处的干预类（U6）。  
　（5）候选域与背景：事前冻结有限候选事件域 C，只取第 t\* 拍及以前的事件；C 之外的事件为背景，在一切回放中保留；目标事件不入 C。来源结论都相对于 (C, 背景)。  
　（5′）评价范围：三个目标层都在 t\* 读取（O₁ 取第 b 拍，t\* − w \< b ≤ t\*）。回放自 s₀ 运行到第 t\* 拍为止；t\* 之后的拍不属比较对象，不入回放，其合法性不影响判词。  
　（6）合法域三分：对保留集 K ⊆ C（删去 C∖K）回放至 t\*，  
　　越出定义域：记「不合法」，排除出比较，不作 0，不作必要来源的证据；  
　　合法而目标判词为 ⊥：记「合法未定」；  
　　合法而判词为 0 或 1。  
定义四（集合语义）。对目标层 O：  
　充分保留集族 𝒮 = {K ⊆ C：回放合法且 O(K) = 1}；最小充分集族 𝒦\_min 为 𝒮 的极小元；  
　合法删除必要事件：𝒮 非空，x ∈ C，存在删去 x 的合法回放，且 𝒮 的每个成员都含 x；全体记作 N（𝒮 为空时 N = ∅，不作空真的必要）；  
　实际祖先事件集 A：第五节实际祖先图中的有效脉冲实例与有效机制实例。  
四者分别定义，一般互不相等。𝒮、𝒦\_min、N 是冻结背景下的反事实保留集语义，不是实际形成责任；A 是实际史上的谱系，也不是责任。  
定义五（非负族）。𝔐\_GF⁺：𝔐\_GF 中一切过程的 k ≥ 0、b ≥ 0（常数律 b ≥ 0；双线性同）；初态为任意非负有理数；脉冲幅度在 𝔐\_GF 中本已非负。𝔐\_GF⁺₀：𝔐\_GF⁺ 中 s₀ 各分量 ≤ ε 的子族。

四、默认来源的排除  
定理一（因子化）。冻结 M 与第 b 拍字母时，O₁ 是 (s\_{b−1}, Form\_{b−1}, T) 的函数 Φ\_e，写法即定义一的式子。过去只经拍前状态与拍前形成记录进入。  
证明：  
　由 D15、D17、D18 与 4.2，O₁ 的每个因子只读第 b 拍的过程表、拍前状态与早于该拍的形成记录。  
　RD 的窗读不改变这一点：窗内各拍的形成记录由入口记录与窗内更早拍的形成并成（可达式引理一）。  
　回放时同式对回放的拍前状态与记录成立。∎  
有限核验：随机一般模型（含负系数、阈上初态、⊥ 认证）中，同一模型内到达同一（拍前状态, 拍前记录, 字母, 过程, T）的 O₁ 读数无冲突；O₁ 按事件式单独计算，另把自算的 Q(T) 与求值器的 Q(T) 逐项对拍（附录 B.1 (1)）。O₁ 与 Q(T) 不是同一判词（命题三（甲）中 O₁ = 1 而 Fld = 0）。  
内部评价点（t\* \< \|h\|）的读数与回放范围见附录 B.1 (5)。  
推论一（恒定律不承担）。常数律实例，以及 k = 0 的线性、双线性实例，作用支持为空，故 α ≡ 0、O₁ ≡ 0：它们不承担任何 T 的 HDyn。HDyn 的承担者必为 k ≠ 0 的线性或双线性实例。  
常数律实例仍可作承担者的祖先：「不承担」与「不作来源」不同。核验见附录 B.1 (2)。  
推论二（默认来源排除的判据）。设 𝓗 为申报的一族实际史，它们在第 b 拍有同一字母。过程表单独足以确定本次 HDyn，当且仅当 Φ\_e 在 {(s\_{b−1}(h), Form\_{b−1}(h))：h ∈ 𝓗} 上取常值。  
证明：由定理一即得。∎  
三条通道各有不由过程表决定的见证（附录 B.1 (3-a)—(3-c)）：  
　可用性（记录）通道：ε = 1/10，s₀ = 1/2（阈上、记录为空），use 读 x：O₁ = 0；  
　作用支持通道：sx·sy·bl 与 sx·rest·bl 上，bl 对 T = {x} 的 O₁ 为 1、0；  
　有效性通道：实例甲第 12、13 个 a 拍上 opt 的 O₁ 为 1、0，第 13 拍 w 已形成且阈上，分项 ≤ ε。  
故默认读法在 𝔐\_GF 上一般不成立。排除只到这一步：字母表、数值律、系数与认证原子始终是给定机制，一切给定条件并不因此排除。  
命题一（记录通道独立于状态）。𝔐\_GF 中形成记录一般不是状态的函数。  
见证（附录 B.2 (2-iii′)）：s₀ = 1 \> ε。史 rest·use 与 sx·drain·use 在 use 拍前状态同为 x = 1，形成记录为 ∅ 与 {x}，O₁ 为 0 与 1。  
所以「历史部分」不能归结为当前状态：形成记录携带了状态之外的历史。该见证同时用了阈上初态与负偏置，不用以隔离任一前件。

五、发生过程刻画：实际祖先图  
定义六（实际祖先图）。对实际史 h 与目标事件 e：  
　数值节点 (i, t)：位 i 在第 t 拍之前的值（1 ≤ t ≤ \|h\|）。其输入为初态边界节点 E0(i)，以及第 t 拍前以 i 为对象的全部有效事件。  
　初态边界节点 E0(i)：s₀ 的每一分量都设，零值也设。作截断边界，不称已解释其来源。  
　事件节点：  
　　有效脉冲实例，无输入；  
　　有效机制实例，输入为其读取位在该拍之前的数值节点（状态依赖输入），以及 b ≠ 0 时一个带标号的偏置输入节点 offset(t, pid)。常数律实例只有偏置输入。  
　偏置输入只是谱系表示，不改变过程身份，也不改变删除粒度（删除仍以整个过程实例为单位）。b 的数值属机制参数，offset(t, pid) 记该实例本拍的实际执行。  
　回溯自 (i, b)（i ∈ R\_e）出发。  
　根分两类：  
　　贡献根：非零 E0 节点、有效脉冲实例、偏置输入；  
　　零值边界：读到零值的 E0 节点，只记语法依赖，不认证形成责任。  
　事件来源、数值输入、认证原子、机制参数四本账分开记录。  
定理二（祖先图有限、根的覆盖与节点数上界）。对有限实际史，实际祖先图有限，每条回溯止于三类根之一：初态边界节点、有效脉冲实例、偏置输入。节点总数 ≤ \|I\|·(\|h\| + 1) + E + B ≤ \|I\|·(\|h\| + 1) + 2E，其中 E 为 h 中的事件实例数，B 为 h 中 b ≠ 0 的过程实例数。  
证明：  
　数值节点的输入止于 E0 节点与以该位为对象的有效事件。脉冲无输入。机制实例的输入止于更早时刻的数值节点与偏置输入。  
　对 t 归纳，每条回溯严格向前，止于 E0 节点、脉冲或偏置输入。故非空图必有根。  
　计数：数值节点 ≤ \|I\|·\|h\|；初态边界节点 ≤ \|I\|；事件节点 ≤ E；偏置输入节点 ≤ B（每个实例至多一个），B ≤ E。∎  
有限核验见附录 B.1 (4)、(4′)。(4′) 为 12 个常数律祖先之例：节点 26 个，上界 28。  
根的覆盖不等于来源已闭合；贡献根不是已认证形成责任的同义词。

六、来源定理  
定理三（非负族的形成记录）。在 𝔐\_GF⁺ 中，任一合法史的任一时刻，按位成立：  
　（甲）s₀,i ≤ ε 的位：i ∈ Form ⇔ s\_i \> ε；  
　（乙）s₀,i \> ε 的位：i ∈ Form ⇔ 此前有以 i 为对象的有效脉冲。  
全局形式（𝔐\_GF⁺₀）：i ∈ Form ⇔ s\_i \> ε。  
证明：  
　𝔐\_GF⁺ 中一切有效改变非负，状态单调不减、恒非负。登记形成只有两种途径：有效脉冲；有效正分项作用于拍前 s\_i ≤ ε 的位。  
　（甲 ⇒）两种途径之后都有 s\_i \> ε，状态不减，故此后恒 s\_i \> ε。  
　（甲 ⇐）若某时 s\_i \> ε，取 i 的第一次有效改变：施加时拍前 s\_i = s₀,i ≤ ε。若为脉冲，登记形成；若为过程分项，c \> ε 作用于 s\_i ≤ ε，也登记形成。  
　（乙）s\_i ≥ s₀,i \> ε 恒成立，过程途径永不可用；故形成恰由有效脉冲登记。∎  
推论：𝔐\_GF⁺ 中形成记录由状态与有效脉冲的历史决定；𝔐\_GF⁺₀ 中由状态单独决定，记录通道塌缩进状态。  
边界（附录 B.2 (2-iii)）：ε = 0、s₀ = 1、只有 rest 时 s \> ε 而 Form = ∅，全局形式失效，按位形式（乙）成立。  
有限核验见附录 B.2 (1) b。  
定理四（非负族的单调来源结构）。设 M ∈ 𝔐\_GF⁺，按定义三冻结 (h, w, t\*, e, T, C, 背景)，实际上 O₁ = 1。则：  
　（i）一切回放合法；  
　（ii）K ⊆ K′ ⇒ 逐拍 s^K ≤ s^{K′}（分量序），且 Form^K ⊆ Form^{K′}；  
　（iii）O₁ 对 K 单调（真值序 0 \< ⊥ \< 1）；𝒮 向上封闭；  
　（iii′）O₂ 与 O₃ 也对 K 单调；  
　（iv）N = {x ∈ C：O₁(C∖{x}) ≠ 1} = ∩𝒦\_min：实际史之外只需 \|C\| 次单删回放。O₂、O₃ 在实际上为 1 时，其必要事件同样由单删检验精确判定；  
　（v）非祖先候选无关：对任一 K 与 X ⊆ C∖A，O₁(K) = O₁(K ∪ X)。因而 𝒦\_min 的每一成员都含于 A；  
　（vi）若 A 与背景不交，则删去全部候选后 O₁ = 0：候选域中的实际祖先全体联合必要。A 与背景相交时不签此条（背景中的祖先在一切回放中保留）。  
证明：  
　（i）删除只去掉事件，被编辑的模型仍属 𝔐\_GF⁺，状态恒非负。  
　（ii）对拍数归纳。在第 t 拍，K-回放中出现的事件都出现在 K′-回放中。  
　　两边都出现的事件：脉冲增量相同；过程分项 b + kΣs\_j 或 b + k·s\_j·s\_l 在非负状态上对 s 单调不减；增量 c·\[c \> ε\] 对 c 单调不减。只在 K′ 中出现的事件增量非负。故 s^K\_t ≤ s^{K′}\_t。  
　　形成记录的包含由定理三按位得到：（甲）类位由状态单调；（乙）类位只由有效脉冲登记，K-回放中的脉冲都出现在 K′-回放中。  
　（iii）τ、κ 是常量。η = \[c\_e(s) \> ε\] 单调。α ⇔ ∃i ∈ Supp\_act(s) ∩ T：s\_i \> ε 且 i ∈ Fo，两个条件都对 K 单调。线性律的 Supp\_act 在 k ≠ 0 时恒为 R；双线性律 j₁ ∈ Supp\_act ⇔ s\_{j₂} ≠ 0 ⇔ s\_{j₂} \> 0，单调。强 Kleene 合取单调。  
　（iii′）O₂ 是窗内各事件 HD 项的析取，出现的事件随 K 增大而增多，每项按（iii）单调。O₃ = ⋁\_T（Src ∧ Ret ∧ Part ∧ HDyn），逐项单调：  
　　Src：标记由有效界外脉冲与界外载体的有效过程登记，有效性单调；  
　　Ret：窗末 s\_i \> ε 且已形成，由（ii）单调；  
　　Part：界内过程的 Supp\_cond 在 𝔐\_GF⁺ 中，对常数律为空，对线性律是常量（k ≠ 0 时为 R；k = 0 时 \|b\| ≤ ε 则为 R，否则为空），对双线性律等于 Supp\_act；可用性单调；  
　　HDyn：同 O₂。  
　（iv）𝒮 向上封闭且 C ∈ 𝒮。若 C∖{x} ∈ 𝒮，它是不含 x 的充分集；反之，若某个 K ∈ 𝒮 不含 x，则 K ⊆ C∖{x}，故 C∖{x} ∈ 𝒮。删去 x 的回放都合法。  
　（v）对祖先节点 (i, t) 按 t 归纳：s^K\_i(t) = s₀,i + 第 t 拍前以 i 为对象的回放增量之和。  
　　以 i 为对象、实际有效的事件都在 A 中（祖先闭包）。实际无效的事件：脉冲 a ≤ ε，增量恒为 0；过程在回放中有 c^K ≤ c^C ≤ ε（由（ii），s^K ≤ s^C = 实际），仍无效。  
　　祖先事件的分项只读其读取位在更早时刻的值，这些也是祖先节点。故祖先节点的回放值只依赖 K ∩ A。  
　　祖先节点处的形成：（甲）类位由回放值决定；（乙）类位由此前以 i 为对象的有效脉冲决定，它们都在 A 中。  
　　O₁ 只读 (i, b)（i ∈ R\_e）的值与形成，都是祖先节点。  
　　若 K 极小充分，则 O₁(K ∩ A) = O₁(K) = 1，由极小性 K = K ∩ A。  
　（vi）由（v），删去全部候选时 R\_e 各位只剩初态而无任何祖先事件：（甲）类位值 s₀,i ≤ ε；（乙）类位没有有效脉冲，未形成。故 α = 0。∎  
有限核验见附录 B.2 (1)：随机 𝔐\_GF⁺ 实例，含阈上初态与非空背景，(i)—(vi) 与 O₂、O₃ 的单调和单删全部成立。

命题二（族外的若干失效现象）。定理四的前件只作充分条件，不宣称逐一必要。下列见证每次只去掉一个前件，其余前件与实际 O₁ = 1 保持，击穿定理四的某一条（附录 B.2 (2-i)、(2-ii)、(2-iv)）：

定理五（伙伴的精确非零通道）。设 e 为双线性实例，R = (j₁, j₂)，j₁ ≠ j₂，j₁ ∈ T，j₂ ∉ T。则  
　α ⇔ k ≠ 0 且 s\_{j₁} \> ε 且 j₁ ∈ Fo 且 s\_{j₂} ≠ 0。  
k = 0 时作用支持为空，α = 0（与推论一相容）。  
证明：由 D15，双线性作用支持先受 k ≠ 0 限制；k ≠ 0 时 j₁ ∈ Supp\_act ⇔ s\_{j₂} ≠ 0。代入 α 的定义即得。∎  
伙伴条件只要求精确非零：不要求形成，不要求阈上，不要求属于 T。所以伙伴对本次作用的贡献记在数值输入账，不以迹应为条件：它可以只来自初态边界而无任何历史事件，也可以由历史形成（如 sx·sy·bl 中伙伴 y 已形成且阈上）。这只就当前 T 而言，不断言 j₂ 不可能是其他承担集中的迹应。  
另一状态事实（与 k 的前件无关）：在 𝔐\_GF⁺ 且 s₀,j₂ = 0 时，伙伴非零 ⇔ 伙伴已形成。理由：有效增量都 \> ε，故 s \> 0 ⇔ s \> ε，再由定理三（甲）。此时伙伴必由历史压出。  
见证（附录 B.3 (1)）：ε = 1/10，s₀ = (0, 1/20)，sx·bl，bl = 4xy 作用于 x。(O₁, O₂, Fld) = (1, 1, 1)；y = 1/20 ≤ ε，从未形成，贡献根含 y 的非零初态边界。同一模型 y₀ = 0 时 O₁ = 0。  
边界网格与随机核验见附录 B.3 (1′)、(2)。  
这是同一给定双线性律下伙伴位的历史激活，不是动力律、耦合或过程表由沉积生成。  
命题三（资格信号条件与作用来源的分离）。（附录 B.3 (3)）  
　（甲）承担作用可以完全无信号而成立：bias·use 上 (O₁, O₂, Fld) = (1, 1, 0)。

七、来源不能唯一确定处的申报  
命题四（多解分类与可确定程度）。在有限史与有限候选域上，2^\|C\| 次回放给出精确的 𝒮、𝒦\_min、N 与不合法保留集。这是计算，不是新的全称定理。𝔐\_GF⁺ 中 N 只需实际史之外的 \|C\| 次单删回放（定理四（iv）），三个目标层都如此。  
分类与见证（附录 B.4）：  
　（1）过定（𝔐\_GF⁺ 内）：seed·bias·use，𝒦\_min = {{seed}, {bias}}，N = ∅，A = C。删去 seed 后 bias 在回放中登记形成，这是形成登记的抢先；bias 在实际中已有效。  
　（2）替代形成兼抢先（族外）：seed·alt·use。seed 使 alt 在实际中无效；删去 seed 后 alt 形成 y。  
　（3）联合充分（𝔐\_GF⁺ 内）：n 个幅度 1/2 的脉冲，ε = 1/10，2 ≤ m ≤ n，use 系数 k 取在 k(m − 1)/2 ≤ ε \< km/2（m ≥ 2 时该区间非空）。则 𝒦\_min 为全部 m 元子集，共 C(n, m) 个；2 ≤ m \< n 时 N = ∅，m = n 时 𝒦\_min = {C}、N = C。  
　　证明：y 等于保留脉冲数的一半，use 有效当且仅当保留数 ≥ m。m \< n 时每个脉冲都有不含它的 m 元子集；m = n 时唯一的充分集是 C。∎  
　　取 n ≥ 4、m = ⌊n/2⌋（故 2 ≤ m \< n），𝒦\_min 的成员数按 C(n, ⌊n/2⌋) 指数增长：精确列出全部最小充分集一般不是多项式规模，而 N 可以。  
　（4）越域比较缺口：seed·seed·drain·use 的全删回放越域，合法保留集上另算。  
　（5）合法未定：读取认证为 ⊥ 时保留表只有 0 与 ⊥，无充分集，不签必要。「删去则为 0」不推出「保留则为 1」。  
　（6）作用层与资格层分账：实例甲 init·a·a 上 O₁ 的 N = ∅，Fld 的 N = {init}。𝔐\_GF⁺ 中两层各自单删精确，所得集合也一般不同：sig·bias·use（T = {x, y}）上 O₁ 的 N = {bias}，Fld 的 N = {sig, bias}。  
　（7）冗余祖先：实际祖先不进入任何最小充分集。  
可确定程度：  
　𝒮、𝒦\_min、N、A 与不合法保留集各自精确可算，一般互不相等；理论能确定的是这几个集合，不能确定「哪一个是那个来源」。  
　𝔐\_GF⁺ 中可以额外确定 ∪𝒦\_min ⊆ A 与 N = ∩𝒦\_min。  
　族外不能把 𝒦\_min 的成员直接称作实际来源：（2）中 alt 实际增量为 0，却构成反事实最小充分集 {alt}。  
观测不可见（申报，未计算）：承接不可区分式定理六，只说明所定义观测集内的可识别边界，不证明同一完整模型中存在多种实际生成责任。

八、实例  
命题五（χ₀ 的无截顶 F 变体 χ₀^F；原 χ₀ 的桥接域）。  
　对象：  
　　χ₀^F 即可达式附录 A.6 的 χ₀ F 层编码（不含截顶）：ε = 0；u1 为界外脉冲 x + 1/2 及过程 wb（x/10）、dec（−3x/10）；rest 为过程 wb、dec。  
　　原 χ₀：δ′ = min{δ\_max, δ + αu + βδ − λδ}，α = 1/2、β = 1/10、λ = 3/10、δ\_max = 3。截顶不是 F 编码中的过程，不作可干预事件。  
　协议：实际史 u1·rest^n（n ≥ 1），w = 1，t\* = \|h\|；O₁ 为末拍 wb 对 T = {x}；C 为其余全部事件，背景为空。  
　　删除按 F 编码的过程实例进行。在原 χ₀ 上，删除 wb、dec 实例读作删去该拍原律中的 βδ、λδ 项，删除脉冲读作该拍 u = 0。  
　（i）χ₀^F，一切 n ≥ 1：  
　　一切回放合法；  
　　O₁ 与 Fld 的 𝒦\_min 都是 {{u1 脉冲}}，N = {u1 脉冲}；  
　　Genesis 在第 2 评价点为 1（认证的首次成立）。  
　（ii）原 χ₀，1 ≤ n ≤ 18：比较域内一切保留集的回放，截顶前的值逐拍 ≤ (1/2)(11/10)^n \< 3，故与 χ₀^F 逐拍相同；（i）的结论对原 χ₀ 原样成立。  
　（iii）原 χ₀，n ≥ 19：保留脉冲与全部 wb、删去全部 dec 时，χ₀^F 的末态为 (1/2)(11/10)^n，n = 19 时首次超过 3；原 χ₀ 在该拍被截到 3，此后自 3 起递推，n ≥ 20 时末拍截顶前值为 33/10。两者分离，桥接失效。原 χ₀ 在此范围的来源结论不签。  
证明：  
　（i）第 1 拍拍前 x = 0，过程分项为 0。此后每拍乘以 1、11/10、7/10 或 4/5 之一（视 wb、dec 的保留而定），因子都为正。故 x \> 0 当且仅当保留脉冲，回放恒合法。  
　　形成只由脉冲登记。O₁ = \[x 拍前 \> 0 且已形成 且 x/10 \> 0\] = \[保留脉冲\]。Fld 同理，Src 只由脉冲的标记给出。  
　　Fld(u1) = 0：第 1 拍可用位为空，Part 为 0。Fld(u1·rest) = 1。  
　（ii）脉冲至多在第 1 拍给 1/2，此后每拍因子 ≤ 11/10。故第 t 拍截顶前的值 ≤ (1/2)(11/10)^{t−1}，全程 ≤ (1/2)(11/10)^n。n = 18 时约 2.780 \< 3。截顶从未起作用，原律与 F 编码逐拍相同（可达式 A.6 的桥接判据）。  
　（iii）该保留集下 χ₀^F 第 t 拍的值恰为 (1/2)(11/10)^{t−1}；原 χ₀ 在首次超过 3 之前与之相同。n = 19 时末拍截顶前值约 3.058 \> 3，原 χ₀ 截为 3；n ≥ 20 时原 χ₀ 末拍截顶前值为 3·(11/10) = 33/10，不再是等比值。∎  
有限核验（附录 B.5）：n = 1…5 的全部保留集，每个同时按原律逐拍对拍；6 ≤ n ≤ 18 的随机保留集逐拍对拍；n ≤ 19 的极值上界与 n = 19 的触顶；n = 18、19、20、25 时两套递推的末拍截顶前值。

命题六（实例甲）。

十、最终表达  
在模型、机制、实际史、评价点、目标作用、候选域与背景事前冻结的条件下：

　非负族中，形成记录按位由状态与有效脉冲决定；三个目标层都对保留事件单调，必要事件由单删检验精确判定，最小充分集都在实际祖先之内；实际祖先与冻结背景不交时，删去候选域中的全部祖先则目标失效。负改变下替代形成、越域与非单调都会出现。

A.1　src\_core.py　来源协议的实现：拍内个别删除与回放、三个目标层的求值、三值首次性、保留集表与集合语义、实际祖先图（定义一至四、六）

~~~python
"""场具化动力源式：来源协议 Π_src 的参照实现（只用标准库；精确有理运算；三值强 Kleene）。
仅调用 reach_core（《场具化可达式》附录 A.1），不修改上游规则。
  edited     拍内个别删除（脉冲实例或过程实例），新字母名真正新鲜，逐拍核对掩码外保留；
  evaluate   评价点 t* 上的 (O1, O2, Fld)：O1 固定作用事件的 HDyn 项；O2 固定 T 的 HDyn；Fld 存在层；
             回放只运行到 t*，越域返回 ILLEGAL；
             每次求值把自算 Q(T) 与 reach_core 的 Q(T) 对拍；
  genesis    三值首次性（冻结评价点集 E(h) = {w, …, |h|}）；
  table      有限掩码表（保留集 K ⊆ C → (O1, O2, Fld) 或 ILLEGAL）；
  summarize  最小充分集族、合法删除必要事件、不合法掩码；
  ancestors  实际祖先（贡献根 / 零值边界 / 中间事件），ancestor_events 折成事件标识；
  ancestor_nodes  祖先图的全部节点（数值节点、初态边界节点、事件节点、偏置输入节点），供节点数上界核验。
"""
from fractions import Fraction as F
from hashlib import sha256
from itertools import combinations
from pathlib import Path
from reach_core import GF, Proc, k_and, k_or, fld_of_history, run_prefix, window_eval
ILLEGAL = 'illegal'

def P(pid, tgt, reads, k, b=0, car='B', cert=1, law='lin'):
    return Proc(pid, tgt, car, law, R=reads, k=F(k), b=F(b), cert_read=cert)

# ---------- 干预：拍内个别删除 ----------
def edited(M, h, deleted):
    """deleted: 事件集合 {(beat, 'pulse', k) | (beat, 'proc', pid)}，beat 自 1 起。
    返回 (M', h')：对被删事件所在拍另立一个只少了这些事件的字母；同拍其余事件保留。
    新字母名经检查不在原字母表及已分配名中（真正新鲜），原字母一概不被覆写；
    过程标号与拍标号不变。返回前逐拍核对：掩码外事件全部保留，掩码内事件全部缺席。"""
    letters = dict(M.letters)
    h2 = []
    for t, u in enumerate(h, 1):
        dp = {k for (b, kind, k) in deleted if b == t and kind == 'pulse'}
        dq = {k for (b, kind, k) in deleted if b == t and kind == 'proc'}
        if not dp and not dq:
            h2.append(u)
            continue
        pulses, procs = M.letters[u]
        n = 0
        while ('del', t, n) in letters:
            n += 1
        nu = ('del', t, n)                  # 非字符串元组名，另经 in 检查，必不与已有字母重名
        letters[nu] = ([x for k, x in enumerate(pulses) if k not in dp],
                       [p for p in procs if p.pid not in dq])
        h2.append(nu)
    M2, h2 = GF(M.I, M.eps, letters, M.s0), tuple(h2)
    for t, (u, u2) in enumerate(zip(h, h2), 1):   # 掩码外事件保留核对
        (p1, q1), (p2, q2) = M.letters[u], M2.letters[u2]
        keep_p = [x for k, x in enumerate(p1) if (t, 'pulse', k) not in deleted]
        keep_q = [p for p in q1 if (t, 'proc', p.pid) not in deleted]
        assert p2 == keep_p and q2 == keep_q, ('掩码外事件未保留', t)
    return M2, h2

def events_of(M, h):
    out = []
    for t, u in enumerate(h, 1):
        pulses, procs = M.letters[u]
        out += [(t, 'pulse', k) for k in range(len(pulses))]
        out += [(t, 'proc', p.pid) for p in procs]
    return out

# ---------- 求值：事件级 HDyn 项与 Q 对拍 ----------
def trace_run(M, h):
    """返回逐拍 (拍前态 dict, 拍前 Form, events) 与末态记录；越域返回 None。"""
    s, Form, Mark, rows = M.s0, set(), set(), []
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s2, fo, ma, ev = r
        rows.append((dict(zip(M.I, s)), set(Form), ev))
        Form |= fo
        Mark |= ma
        s = s2
    return rows, dict(zip(M.I, s)), Form, Mark

def hd_term(M, row, p, act, T):
    sd, Form, _ = row
    aa = {i for i in p.supp_act(sd) if sd[i] > M.eps and i in Form}
    hc = k_and(1 if aa & T else 0, p.cert_read, p.cert_path if aa & T else 0)
    return k_and(1 if p.tgt in T else 0, act, hc)

def evaluate(M, h, w, T, beat, pid, tstar=None):
    """返回评价点 t*（缺省 |h|）上的 (O1, O2, Fld)；回放越域返回 ILLEGAL。
    O1：第 beat 拍过程 pid 的 HDyn 项（该过程实例缺席记 0），要求 t* − w < beat ≤ t*。
    回放只运行到 t*：t* 之后的拍不属比较对象，不入回放，其合法性不影响判词（定义三）。"""
    tstar = len(h) if tstar is None else tstar
    assert w <= tstar <= len(h) and tstar - w < beat <= tstar, ('评价点或目标拍越界', tstar, beat)
    h = tuple(h[:tstar])
    T = set(T)
    tr = trace_run(M, h)
    if tr is None:
        return ILLEGAL
    rows, end, Form, Mark = tr
    n = len(h)
    win = range(n - w, n)
    o1 = 0
    for (p, c, act) in rows[beat - 1][2]:
        if p.pid == pid:
            o1 = hd_term(M, rows[beat - 1], p, act, T)
    o2 = k_or(*[hd_term(M, rows[t], p, act, T) for t in win for (p, c, act) in rows[t][2]] or [0])
    # 对拍：自算 Q(T) = Trace ∧ Part ∧ HDyn，与 reach_core 一致
    src = 1 if T & Mark else 0
    ret = 1 if all(end[i] > M.eps and i in Form for i in T) else 0
    part = k_or(*[k_and(1 if ({i for i in p.supp_cond(rows[t][0], M.eps)
                               if rows[t][0][i] > M.eps and i in rows[t][1]} & T) else 0, p.cert_read)
                  for t in win for (p, c, act) in rows[t][2] if p.car == 'B'] or [0])
    q = k_and(src, ret, part, o2)
    r = fld_of_history(M, h, w)
    assert r is not None and r['Q'][frozenset(T)] == q, ('对拍失败', h, T)
    return o1, o2, r['Fld']

# ---------- G：三值首次性 ----------
def k_not(x):
    return None if x is None else 1 - x

def genesis(M, h, w):
    reads = [fld_of_history(M, h[:t], w)['Fld'] for t in range(w, len(h) + 1)]
    g = [k_and(reads[j], *[k_not(x) for x in reads[:j]]) if j else reads[0] for j in range(len(reads))]
    return reads, g

# ---------- K：有限掩码表 ----------
def mask_table(M, h, w, T, beat, pid, cand, idx=0):
    """cand：候选事件域（其余事件为冻结背景，始终保留）。对每个保留集 K ⊆ cand 回放。"""
    rows = []
    for n in range(len(cand) + 1):
        for K in combinations(cand, n):
            M2, h2 = edited(M, h, set(cand) - set(K))
            v = evaluate(M2, h2, w, T, beat, pid)
            rows.append((frozenset(K), v if v == ILLEGAL else v[idx]))
    legal = [(K, v) for K, v in rows if v != ILLEGAL]
    suff = [K for K, v in legal if v == 1]
    minimal = sorted([sorted(K) for K in suff if not any(S < K for S in suff)])
    # 合法删除意义下必要：合法且目标为 1 的保留集都含 e；且至少有一个删去 e 的合法回放（否则不签必要）
    nec = sorted(e for e in cand if all(e in K for K in suff)
                 and any(e not in K for K, v in legal) and suff)
    return rows, minimal, nec

def ancestors(M, h, beat, reads):
    """实际祖先（只作谱系表示，不作责任）。
    节点：位 i 在拍 t 之前的数值 (i, t)；拍 t 的有效事件（脉冲实例、机制实例）。
    (i, t) 的输入 = 初态边界节点 E0(i)（零值也列入）+ 拍 t 之前以 i 为对象的全部有效事件。
    机制实例的输入 = 其读取位的拍前数值（状态依赖输入）+ 偏置输入 ('offset', t, pid)（当 b ≠ 0；常数律即只有偏置输入）。
    偏置输入只是谱系表示中带标号的输入，不改变过程身份，也不改变删除粒度（删除仍以整个过程实例为单位）。
    返回 (贡献根, 零值边界, 中间事件)：
      贡献根 = 非零初态边界、有效脉冲实例、执行实例的非零偏置输入；
      零值边界 = 读到零值的初态边界节点，只记语法依赖，不认证形成责任。
    由构造，任一 (i, t) 的回溯止于 E0 节点、脉冲或偏置输入，故中间事件非空时根（两类合计）必非空。"""
    tr = trace_run(M, h)
    rows = tr[0]
    seen, roots, zeros, mids = set(), set(), set(), set()
    def pos(i, t):                       # 拍 t 之前（拍前）位 i 的数值来源
        if (i, t) in seen:
            return
        seen.add((i, t))
        if M.s0[M.idx(i)] != 0:
            roots.add(('E0', i))
        else:
            zeros.add(('E0', i, 0))
        for t2 in range(1, t):
            pulses, _ = M.letters[h[t2 - 1]]
            for k, (tgt, a, ext) in enumerate(pulses):
                if tgt == i and F(a) > M.eps:
                    roots.add(('pulse-' + ext, t2, k))
            for (p, c, act) in rows[t2 - 1][2]:
                if p.tgt == i and act:
                    mids.add(('mech-' + ('ext' if p.car == 'out' else 'in') + '/' + p.law, t2, p.pid))
                    if p.b != 0:
                        roots.add(('offset', t2, p.pid))
                    for j in p.R:
                        pos(j, t2)
    for i in reads:
        pos(i, beat)
    assert not mids or roots or zeros, '非空图无根'
    return sorted(roots, key=str), sorted(zeros, key=str), sorted(mids, key=str)



def ancestor_events(M, h, beat, reads):
    """实际祖先中的事件标识集合：脉冲 (t,'pulse',k)；机制实例 (t,'proc',pid)（偏置输入归于其实例）。"""
    roots, zeros, mids = ancestors(M, h, beat, reads)
    out = set()
    for r in roots:
        if r[0].startswith('pulse'):
            out.add((r[1], 'pulse', r[2]))
        elif r[0] == 'offset':
            out.add((r[1], 'proc', r[2]))
    for m in mids:
        out.add((m[1], 'proc', m[2]))
    return out

def table(M, h, w, T, beat, pid, cand, tstar=None):
    """保留集 K ⊆ cand → 评价点 t*（缺省 |h|）上的 evaluate 结果（三元组或 ILLEGAL）。
    cand 之外为冻结背景；cand 只取第 t* 拍及以前的事件。"""
    tstar = len(h) if tstar is None else tstar
    assert all(e[0] <= tstar for e in cand), '候选事件须在评价点及以前'
    out = {}
    for n in range(len(cand) + 1):
        for K in combinations(cand, n):
            M2, h2 = edited(M, h, set(cand) - set(K))
            out[frozenset(K)] = evaluate(M2, h2, w, T, beat, pid, tstar)
    return out

def summarize(tab, cand, idx=0):
    """返回 (最小充分集族, 合法删除必要事件, 不合法保留集个数)；idx = 0/1/2 取 O1/O2/Fld。"""
    legal = {K: v[idx] for K, v in tab.items() if v != ILLEGAL}
    suff = [K for K, v in legal.items() if v == 1]
    minimal = sorted(sorted(K) for K in suff if not any(S < K for S in suff))
    nec = sorted(e for e in cand if suff and all(e in K for K in suff) and any(e not in K for K in legal))
    return minimal, nec, len(tab) - len(legal)

def ancestor_nodes(M, h, beat, reads):
    """祖先图全部节点，按类型返回 dict：
    'num'   数值节点 (i, t)，1 ≤ t ≤ |h|，表示位 i 在第 t 拍之前的值；
    'E0'    初态边界节点 E0(i)（零值也列入）；
    'event' 事件节点：有效脉冲 (t,'pulse',k)、有效机制实例 (t,'proc',pid)；
    'offset' 偏置输入节点 ('offset', t, pid)（b ≠ 0 的有效机制实例各一个）。"""
    rows = trace_run(M, h)[0]
    num, E0, ev, off = set(), set(), set(), set()
    def pos(i, t):
        if (i, t) in num:
            return
        num.add((i, t))
        E0.add(i)
        for t2 in range(1, t):
            pulses, _ = M.letters[h[t2 - 1]]
            for k, (tgt, a, ext) in enumerate(pulses):
                if tgt == i and F(a) > M.eps:
                    ev.add((t2, 'pulse', k))
            for (p, c, act) in rows[t2 - 1][2]:
                if p.tgt == i and act:
                    ev.add((t2, 'proc', p.pid))
                    if p.b != 0:
                        off.add(('offset', t2, p.pid))
                    for j in p.R:
                        pos(j, t2)
    for i in reads:
        pos(i, beat)
    return {'num': num, 'E0': E0, 'event': ev, 'offset': off}
~~~

A.2　s1\_factor.py　因子化与三通道、恒定律不承担、实际祖先图的根覆盖与节点数上界（定理一、二，推论一、二）

~~~python
"""因子化与三通道（定理一、推论一、推论二）；实际祖先图的有限性、根的覆盖与节点数上界（定理二）。
（1）随机一般 𝔐_GF 实例（含负系数、正初态）：对每个窗内过程事件，O1 只依赖 (拍前状态, 拍前 Form, 本拍字母, pid, T)——
     把出现过的键与读数登记成表，不同史到达同一键时读数必相同；同时每次求值 Q(T) 与 reach_core 对拍。
~~~

~~~python
    """定理三（按位）：逐拍核对。"""
    tr = trace_run(M, h)
    if tr is None:
        return None
    rows, end, Form, Mark = tr
    states = [(r[0], r[1]) for r in rows] + [(end, Form)]
    pulsed = [set()]
    for u in h:
        pulsed.append(pulsed[-1] | {tgt for (tgt, a, ext) in M.letters[u][0] if F(a) > M.eps})
    for t, (s, Fo) in enumerate(states):
        for i in M.I:
            want = (s[i] > M.eps) if M.s0[M.idx(i)] <= M.eps else (i in pulsed[t])
            if (i in Fo) != want:
                return False
    return True

        for K in combinations(cand, n):

                    return False
            if not (all(r[1][i] <= r2[1][i] for i in M.I) and r[2] <= r2[2]):
                return False
    return True
~~~

A.7　reach\_core.py　《场具化可达式》v1.0 附录 A.1 的字母门控 F 模型与窗读法求值器，与该篇附录 A.1 逐字相同

~~~python
"""场具化可达式：字母门控 F 模型、窗读法、增广可达搜索与暴力对照（精确有理运算，三值强 Kleene）
模型类 𝔐_GF（字母门控 F 模型）：有限位集 I、分辨率 ε；字母表 U（含静置 'rest'）；
每个字母 u 给出本拍的脉冲表 [(tgt, a_p, ext)] 与过程表 [Proc]；过程按《场具化数理式》D12 的三类数值律，
读取拍前状态；cert_eff = 1；cert_read、路径边认证由过程申报（直接边：读取位 → 过程，Γ_closed = 闭合）；
Ident、HistEv 申报为 1。一条输入史 h 的窗读法（本篇读法 RD）：W 取 h 的末 w 拍，W 之前的全部拍为形成史，
其 Form、Mark 记录在 F 中以入口拍的记录表示（数理式 D2），W 起点状态为形成史末态。
"""
from fractions import Fraction as Fr
from itertools import combinations, product
from collections import deque
ONE, ZERO, BOT = 1, 0, None

def k_and(*xs):
    if any(x == 0 for x in xs):
        return 0
    if any(x is None for x in xs):
        return None
    return 1

def k_or(*xs):
    if any(x == 1 for x in xs):
        return 1
    if any(x is None for x in xs):
        return None
    return 0

class Proc:
    def __init__(self, pid, tgt, car, law, R=(), k=0, b=0, cert_read=1, cert_path=1):
        self.pid, self.tgt, self.car, self.law = pid, tgt, car, law
        self.R, self.k, self.b = tuple(R), Fr(k), Fr(b)
        self.cert_read, self.cert_path = cert_read, cert_path
    def value(self, s):
        if self.law == 'const':
            return self.b
        if self.law == 'lin':
            return self.b + self.k * sum(s[j] for j in self.R)
        j1, j2 = self.R
        return self.b + self.k * s[j1] * s[j2]
    def supp_act(self, s):
        if self.law == 'const' or self.k == 0:
            return set()
        if self.law == 'lin':
            return set(self.R)
        j1, j2 = self.R
        out = set()
        if s[j2] != 0:
            out.add(j1)
        if s[j1] != 0:
            out.add(j2)
        return out
    def supp_cond(self, s, eps):
        sa = self.supp_act(s)
        if self.law == 'lin' and abs(self.value(s)) <= eps:
            sa |= set(self.R)
        return sa

class GF:
    """字母门控 F 模型。letters: {u: (pulses, procs)}；pulses = [(tgt, a, ext)]，ext ∈ {'out','in'}。"""
    def __init__(self, I, eps, letters, s0):
        """合法性前件（定义三）：位名非空互异；ε、初态、脉冲幅度为非负有理数（整数或 Fraction，不收浮点）；
        字母表有限且含 'rest'；过程标号在同一字母内互异；律 ∈ {const, lin, bilin}，lin 读取位非空，bilin 恰两位，
        const 无读取位；读取位与作用对象属位集；cert_read、cert_path ∈ {1, 0, None}；脉冲 ext ∈ {'out','in'}。
        不合法者抛出 ValueError，不进入求值。"""
        def rat(v, nonneg=False):
            if isinstance(v, bool) or not isinstance(v, (int, Fr)):
                raise ValueError('数值须为整数或 Fraction')
            if nonneg and v < 0:
                raise ValueError('须非负')
            return Fr(v)
        I = tuple(I)
        if not I or len(set(I)) != len(I) or any(not i for i in I):
            raise ValueError('位集')
        if 'rest' not in letters:
            raise ValueError('字母表须含 rest')
        for u, (pulses, procs) in letters.items():
            for (tgt, a, ext) in pulses:
                if tgt not in I or ext not in ('out', 'in'):
                    raise ValueError('脉冲')
                rat(a, True)
            ids = [p.pid for p in procs]
            if len(set(ids)) != len(ids):
                raise ValueError('过程标号重复')
            for p in procs:
                if p.tgt not in I or any(j not in I for j in p.R) or p.car not in ('B', 'out'):
                    raise ValueError('过程对象或读取位')
                if p.law not in ('const', 'lin', 'bilin') or (p.law == 'lin' and not p.R) or \
                   (p.law == 'bilin' and len(p.R) != 2) or (p.law == 'const' and p.R):
                    raise ValueError('律与读取位')
                if p.cert_read not in (1, 0, None) or p.cert_path not in (1, 0, None):
                    raise ValueError('认证值')
        if len(s0) != len(I):
            raise ValueError('初态长度')
        self.I, self.eps, self.letters = I, rat(eps, True), letters
        self.s0 = tuple(rat(x, True) for x in s0)
    def idx(self, i):
        return self.I.index(i)
    def step(self, s, u):
        """一拍（数理式 4.2、5.1）：返回 (后态, 新形成位集, 新标记位集, 过程事件表)；越出定义域返回 None。"""
        eps = self.eps
        pulses, procs = self.letters[u]
        d = {i: Fr(0) for i in self.I}
        sd = dict(zip(self.I, s))
        formed, marked, events = set(), set(), []
        for (tgt, a, ext) in pulses:
            a = Fr(a)
            if a > eps:                      # 有效脉冲：一律计入 Form（D16；与上游 field_final.py 第 123—126 行同），不论拍前深度
                formed.add(tgt)
                if ext == 'out':
                    marked.add(tgt)
                d[tgt] += a
        for p in procs:
            c = p.value(sd)
            act = 1 if abs(c) > eps else 0
            events.append((p, c, act))
            if act:
                if c > eps and sd[p.tgt] <= eps:   # 有效正分项使空位成为留迹元素（D16；上游第 161 行）
                    formed.add(p.tgt)
                if p.car == 'out':
                    marked.add(p.tgt)        # 界外载体机制的有效改变入 Mark
                d[p.tgt] += c
        s2 = tuple(sd[i] + d[i] for i in self.I)
        if any(x < 0 for x in s2):
            return None
        return s2, formed, marked, events

def window_eval(M, s_start, F_rec, M_rec, word):
    """窗读法：入口记录 F_rec、M_rec（位集），W = word。返回 dict：每个非空 T 的 Q 及 Fld、界内自反馈型。"""
    eps = M.eps
    s = s_start
    Form = set(F_rec)           # 「早于 t」的形成记录（入口拍记录早于 W 内一切拍）
    Mark = set(M_rec)
    ev_log = []                 # (avail_cond 全集, avail_act 全集, p, c, act)，T 相关部分事后按 T 截取
    for u in word:
        r = M.step(s, u)
        if r is None:
            return None
        s2, formed, marked, events = r
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev_log.append((ac, aa, p, act))
        Form |= formed
        Mark |= marked
        s = s2
    end = dict(zip(M.I, s))
    out = {}
    fld, selfref = 0, 0
    for n in range(1, len(M.I) + 1):
        for T in combinations(M.I, n):
            T = set(T)
            src = 1 if any(i in Mark for i in T) else 0
            ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
            trace = k_and(src, ret, 1, 1)   # Ident、HistEv 申报为 1
            part = k_or(*[k_and(1 if (ac & T) else 0, p.cert_read)
                          for (ac, aa, p, act) in ev_log if p.car == 'B']) if ev_log else 0
            hd_terms, sr_terms = [], []
            for (ac, aa, p, act) in ev_log:
                hc = k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0)
                hd_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
                if p.car == 'B':
                    sr_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
            hdyn = k_or(*hd_terms) if hd_terms else 0
            q = k_and(trace, part, hdyn)
            out[frozenset(T)] = q
            fld = k_or(fld, q)
            sr = k_and(q, k_or(*sr_terms) if sr_terms else 0)
            selfref = k_or(selfref, sr)
    return {'Q': out, 'Fld': fld, 'self': selfref, 'end': s}

def run_prefix(M, h):
    """形成史：自 s0 施加 h，返回 (末态, Form 位集, Mark 位集)。"""
    s, F, Mk = M.s0, set(), set()
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F |= fo
        Mk |= ma
    return s, frozenset(F), frozenset(Mk)

def fld_of_history(M, h, w):
    """输入史 h 的窗读法资格（W = 末 w 拍，w ≥ 1）。"""
    if w < 1:
        raise ValueError('w ≥ 1')
    if len(h) < w:
        return None
    pre = run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    return window_eval(M, s, F, Mk, h[len(h) - w:])

def physical_reach(M, letters=None):
    letters = letters or list(M.letters)
    seen, dq = {M.s0}, deque([M.s0])
    while dq:
        s = dq.popleft()
        for u in letters:
            r = M.step(s, u)
            if r and r[0] not in seen:
                seen.add(r[0])
                dq.append(r[0])
    return seen

def augmented_search(M, w, target='Fld', letters=None):
    """增广搜索：结点 (s, Form, Mark)；对每个结点枚举长 w 的窗词。返回最短满足史及结点统计。"""
    letters = letters or list(M.letters)
    start = (M.s0, frozenset(), frozenset())
    dist, par = {start: 0}, {start: None}
    dq = deque([start])
    while dq:
        node = dq.popleft()
        s, F, Mk = node
        for u in letters:
            r = M.step(s, u)
            if r is None:
                continue
            s2, fo, ma, _ = r
            nxt = (s2, F | fo, Mk | ma)
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                par[nxt] = (node, u)
                dq.append(nxt)
    best = None
    for node in sorted(dist, key=lambda n: dist[n]):
        if best is not None and dist[node] + w >= best[0]:
            break
        s, F, Mk = node
        for word in product(letters, repeat=w):
            e = window_eval(M, s, F, Mk, word)
            if e is not None and e[target] == 1:
                path, n = [], node
                while par[n] is not None:
                    n, u = par[n]
                    path.append(u)
                h = tuple(reversed(path)) + word
                if best is None or len(h) < best[0]:
                    best = (len(h), h)
                break
    N = len(physical_reach(M, letters))
    return {'best': best, 'nodes': len(dist), 'N': N,
            'max_prefix_dist': max(dist.values()), 'bound_prefix': (2 * len(M.I) + 1) * N - 1}

def brute_min(M, w, Lmax, target='Fld', letters=None):
    letters = letters or list(M.letters)
    for L in range(w, Lmax + 1):
        for h in product(letters, repeat=L):
            e = fld_of_history(M, h, w)
            if e is not None and e[target] == 1:
                return L, h
    return None
~~~
