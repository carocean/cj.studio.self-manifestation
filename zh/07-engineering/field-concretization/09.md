自显论·工篇·场具化组式第九 v1.0

# 势型分级式

一、型别申报  
本篇是分级式中的单轴分层型。判据轴是一个量：迹应对的对向符号  
　σᵢⱼ(x) = sgn\[(sᵢ − sⱼ)(rᵢ − rⱼ)\]，并列（sᵢ = sⱼ）而 rᵢ ≠ rⱼ 时取 +。  
份额与相对增长同序为 +（分），反序为 −（合），相对增长相等为 0（中）。宿载按 σ 在申报域 R 上的取号集 Σ(χ) = {σᵢⱼ(x) : x ∈ R, i ≠ j} 分级。  
　1．四级由取号集定义：{0}；含 + 且 ⊆ {0, +}；含 − 且 ⊆ {0, −}；同含 + 与 −。这是同一个量的符号支集，不是两种判据的拼合。  
　2．四级互斥、完备、各级非空；层级之间不设全序。涨、平、减三名是符号标记，不构成分级之序。  
　3．势型是（宿载，申报层级，族 Φ，申报域 B\_dyn，平稳来流）的性质，不是介质单独的性质；B\_dyn 按第五节取定。  
　4．所分级的是势向，即活动份额格局是否继续收束、摊散或不变；宿载有无势不由此分级判定（H3）。  
记号：净更新律记 Ψ（自治常微分方程 ẋ = Ψ(x)），与《场具化数理式》的 F 层（带脉冲、过程分项、载体与来源的有限可分数值模型）区分。宿载的物理边界记 B\_phys（一般式 χ = (P, L, B, W) 中的 B），状态的正向不变域记 B\_dyn；途径「在界内」指在 B\_phys 内，不指在 B\_dyn 内。黏菌模型中 Dᵢ 是传导度（适应变量）。  
理论增量与阻力：T1、T3、T4、T6 是初等论证；T5 是加权切比雪夫和不等式与 Schur–Ostrowski 条件的组合。本篇的核心是易位定理（T4，严格反序的必要条件）与集中度单调（T5）；另有并列引理及其推论（固定份额映射的数学向量场类中，含合格并列点的定号型无内点，其全体无处稠密）、受限闭合粗粒化下势型可变（T6 (c)）、最大域进入条件的域引理与各级代表例，以及申报域规则。全部结论携带条件 H1—H4。

二、前提

### 2.1　先行事实

　F1　沉积场是信号在介质中留下的迹应集合，以及这一集合在历史动力作用下变换的组织方式及其活动（《沉积场本体定义》）。  
　F2　历史动力形成势，势的实行，就是活动，活动与势组织（指集合的组织）就是变换，其因势而变换，如水就低（作用语前提，不参与后续证明）。  
　F3　《场数理式》v2.7（场篇第一）定义 3、9、11，方程 2、3a、4，定律 20。

### 2.2　条件（携带，不作已成立前件）

　H1　《沉积场判定式》v1.0 第一层的 Tr^静（3.4（一））与钳定（3.3）。继承其资格边界：Tr^静 是能力谓词，不直接认证任何证据原子（4.4（一））；Tr^静 = 1 是操作化证据，不升格为迹应集合职责 TraceSet 或留存 Ret。  
　H2　活动份额 s 是组织方式的操作化读数，不是组织方式的定义。组织方式与活动在本体定义中并列；当前分配相同不保证后继历史相同，故以下结论只关于这一读数的轨迹。  
　H3　势按工篇第一定义三，指已有的压缩倾向，不改读。势向是独立检验：格局不再收束时势仍可存在。  
　H4　地势作为候选，称「既定势差」，与历史续行所成之势区分；两者都进入势向的计算。既定势差是否为定义三意义上的势，留待上游。

### 2.3　原语

份额映射 s: B\_dyn → Δ°ₙ₋₁，Δ°ₙ₋₁ = {s : sᵢ \> 0，Σsᵢ = 1}（归一化份额，故 Σvᵢ = 0），净更新律 Ψ，份额速度 v = Ds·Ψ（只取期望更新律所定部分），相对增长 rᵢ = vᵢ/sᵢ。状态 x 含调谐变量：凡改变当前得流顺序的内部量都列入状态。族 Φ = {1, …, n}，n ≥ 2，同承一股共享来流；来流平稳，即与历史、时刻都无关。

### 2.4　上游承继

申报实例 χ = (P, L, B\_phys, W) 须在 W 上满足《场具化一般式》v1.0 的三项职责 TraceSet、Part、HDyn（同一 T），且属其第七节界内自反馈型：份额分配所依的读出以诸迹应的组织状态为条件（Part）；迹应的写入与退浅由 B\_phys 内机制执行，其强度经 B\_phys 内物质途径由已留下的迹应参与决定（HDyn；Act 与 HistCond 属同一过程，途径全在 B\_phys 内）。界内自反馈型是比沉积场资格更强的类型，不是一切沉积场的必要条件。HistCond 沿用该篇的三层区分：结构承继定义符号与图示；「经实际物质途径参与决定」为该篇的承担读法；「在 W 内」为该篇的工作域规定。  
平稳共享来流 I 在本篇的模型中申报为固定外部供给（《沉积场判定式》3.1（四）：供给日程固定，与信号史无关）；迹应来源 r 由实际形成史中的入口信号承担证明。这一申报只关于本篇模型中的供给与信号，上游的信号定义不因此改变——《场具化一般式》v1.0 与《场具化数理式》v1.0 都界定信号为「从 B 之外实际作用于 B 所属介质的作用，经由哪一通道不论」，系数写法与标记本身不决定其物质身份——其他实例中持续来流作为信号的可能也不因此排除；作其他申报的实例须另给相应见证。  
势型是 Ψ 在 R 上的结构性质，不随 W 而变；把势型归于实例 χ，须 χ 在其 W 上满足本节前两段。

### 2.5　归属的判定途径

　（一）模型模式：在带机制见证的申报模型上按上游定义核对，即申报实际形成史、T、非空 W、分辨率、信号来源、窗内留存、载体与过程分项，以及同一过程的 Act 与 HistCond（6.3 的机制见证）。净更新律 Ψ 单独不认证三项职责：《场具化数理式》已证资格不是净状态轨迹的函数；下文净律反例在本篇的连续模型类内给出同一 Ψ、同一份额轨迹而 HDyn 不同的两候选。  
　（二）实测或物质宿载：三项职责由《沉积场判定式》4.6、4.7 判定；界内自反馈型由其 4.8 判定——正判须 Act 与 HistCond 已由 4.6 认证且外钳 LOC 下有响应（引理十三）；判 0 须 INV-c、EF4 与 B\_phys 内每一运行过程原子的已判定值；外钳 LOC 下无响应不判 0。未取得 4.8 判 1 者，势型不归于该物质实例，只作模型实例报告；这不推出该物质实例不满足资格。  
　（三）证据级：《场具化不可区分式》定理二对其确定性 F 类候选族、观测集 𝒴₁ 证明：Part 在 A(T)（W 内某拍 T 有位大于 ε）时两值；HDyn 在 A(T) 时两值，ε \> 0 时需 FIN（𝒴₁ 含已申报的 Dep 设定，FIN 须另核，不能凭未加 LOC 推定）；随机族另见该篇定理三。该篇定理六：载体与来源标记在其所定义、不读这些标记的观测集内不可见，须由认证读数或申报协议承担；这是相对于所申报观测集与标签自由的族而言，不是一切认证观测下的普遍不可知。连续时间份额模型不认作该族成员；由这些上游反模型只得：单凭轨迹不能无条件提供通用资格认证；不由此推出每一连续模型类内 Part、HDyn 恒为两值。  
　（四）净律反例：状态 (g₁, g₂, z)，g₁, g₂ \> 0，净律 Ψ = (0, 0, 1 − z)，份额 sᵢ = gᵢ/(g₁ + g₂)。两候选在窗前都由外部信号脉冲形成并留下 g₁、g₂，窗内有相同的份额读取过程，TraceSet 与 Part 可同时固定。候选甲在 W 内没有作用于 T = {g₁, g₂} 的过程，HDyn = 0；候选乙另申报两个界内过程 +g₁ 与 −g₁，各自有效且以已有的 g₁ 为条件，HDyn = 1，途径全在 B\_phys 内。两候选的 Ψ 与全部份额轨迹相同。两过程构成一般式允许的合法相抵机制，区别于以任意代数拆项充当机制。

### 2.6　进入条件

　（一）份额映射：s 在含 B\_dyn 的开集上 C¹，sᵢ \> 0。  
　（二）Lipschitz 开域与预紧：存在开集 U ⊂ ℝᴺ 包含 B\_dyn，Ψ 在 U 上局部 Lipschitz（解正反两向唯一，流对初值连续依赖）；B\_dyn 正向不变，且自 B\_dyn 出发的每条正向轨道在 U 中预紧（闭包是 U 的紧子集）。U 可以含 B\_dyn 的边界点；预紧的拓扑空间是 U，轨道的极限点须在 U 内。  
　（三）份额定态集 A₀：B\_dyn 中 ω-极限集里、整条轨道上 v ≡ 0 的点之集。R = (B\_dyn \\ A₀) ∩ {sᵢ \> 0 ∀i}，R ≠ ∅，份额全正的部分正向不变。份额在有限时间内降为 0 者，按时窗分段，族改为较小的族。  
　（四）族 Φ 的诸迹应满足 Tr^静 = 1（H1），作为操作化证据，不代替 2.4 的三项职责。  
　（五）带阈的读出（如 κ = max(g − θ, 0)）在阈处不可微，可在有限时间内使份额为 0，须分段申报，各段分别满足本节条件。族 Φ 在申报时窗内固定。  
　（六）来流不平稳、界外改写份额者，不入本级。  
　（七）用于 T8 推论二′ 的模型类，另加一致预紧：自 B\_dyn 的每个紧子集出发的正向轨道之并在 U 中预紧。

三、先行事实的固定  
被分级的结构：申报层级上，诸迹应同承一股平稳共享来流，活动按份额分配，迹应随活动加深退浅，份额随之改变。活动份额 s 是组织方式的操作化读数（H2），不以 s 作为组织方式本身。

四、分级判据与各级定义

### 4.1　迹应对的势向（任一对 i ≠ j）

　分：(sᵢ − sⱼ)(rᵢ − rⱼ) \> 0；或 sᵢ = sⱼ 而 rᵢ ≠ rⱼ（并列被拉开）。  
　合：(sᵢ − sⱼ)(rᵢ − rⱼ) \< 0。  
　中：rᵢ = rⱼ。

### 4.2　状态势向

涨为无合且有分；减为无分且有合；平为一切对皆中；混为既有分又有合。

### 4.3　宿载势型（在 R 上）

　涨型：取号集含 +、不含 −；R 上处处无合，且有分。  
　平型：取号集为 {0}；R 上处处一切对为中。  
　减型：取号集含 −、不含 +；R 上处处无分，且有合。  
　不定型：取号集同含 + 与 −；R 上兼有分对与合对。只指申报域上势向异号，不指随机性，也不指动力规律不确定。

### 4.4　层级差异是结构差异

四型的区别由正负对向符号在申报域上的出现结构给出：无正负、仅正、仅负、正负兼有，分别对应平、涨、减、不定。T3—T5 给出各型保证的动力后果：平型份额冻结（T3）；涨型与减型的优超序方向分别不降与不升（T5）；同一对的严格反序只可能出现在不定型（T4 推论），但并非每个不定型都发生严格反序。这些后果是由势型推出的单向结论，不单独构成势型的充分判据；例如，优超序在全域不降并不推出涨型。涨与减之分是 σ 的符号之分，不是相关程度之分。

五、申报域的规则  
击穿尝试：同一宿载取不同的合法正向不变域，可得不同势型。例：黏菌模型 I 型 m = 2、两管不等长 L = (1, 1.05)，取 B\_dyn 为开正象限判为不定型（6.4（三））；取 B\_dyn = {q₁ \> q₂}（qᵢ = (Dᵢ/Lᵢ)/Σⱼ(Dⱼ/Lⱼ)）则判为涨型：该域内 r₁ − r₂ = (D₁/L₁² − D₂/L₂²)/K²（K = ΣDⱼ/Lⱼ），由 D₁/L₁ \> D₂/L₂ 与 L₁ \< L₂ 得其为正，处处为分，且并列线上 r₁ − r₂ \> 0，此域正向不变。  
规则：  
　1．主读法：B\_dyn 须在判型之前申报，取申报层级上全部可容许状态的内部 X（由状态变量及其物理取值范围确定，不论是否由申报历史抵达），如两管取开正象限、局部族取开正卦限，并须满足 2.6（二）的 Lipschitz 开域与预紧条件。主读法的进入条件对每个代表例须单独证明（域引理），不能以某个有界小域的正向不变性代替。全篇各实例一律以主读法定型。  
　2．为得到定号型而缩小 B\_dyn，属禁止写法（E2）。  
　3．盆限势型：因物理理由只关心某一吸引盆者，申报为盆限势型，同时报出最大域上的势型；盆限势型不得升格为宿载的势型。  
　4．可达势型：对自 s₀ 经申报历史实际可达的状态集判型，只作附加报告，不替代主读法。  
按此规则，上例的势型为不定型。  
关于 A₀ 的约定：去掉份额定态集是约定。A₀ 中 v = 0，只向取号集加入 0：对非平的类型，加入或删去全中点不改变分类；对全中的模型，它决定 R 是否非空，须单独申报。只去份额定态，不去闭轨与极限环：份额往复振荡的宿载留在 R 内，判为不定型。份额为 0 的面视为较小的族，另行判型。  
主读法与观测：主读法以 X 上全部可容许状态的 Ψ 定型。模型模式下 Ψ 已申报，判型无此问题。实测时，在不附加已认证结构约束的任意模型类中，只覆盖严格子域的读数通常不决定主读法势型；全域合法设定并取得相应份额速度读数，是一种理想化的充分信息途径（《场具化不可区分式》𝒴₁+LOC 意义下的局部设定），但不是唯一途径：模型若已认证属于某一参数族，已知函数形式、参数认证与少数状态上的增长率差可经解析单调性定型；连续律在稠密可观测域上的一致读数也可带来全域信息。有设定能力不等于已完成全域认证；有限样本只证明观测到的势向存在（E5）。

六、定理与证明

### 6.1　T0（R 正向不变）

在 2.6 的进入条件下，R 正向不变。  
证明：记 Ψ 的流为 Fl\_t。只需证：若 x ∈ B\_dyn、t \> 0、Fl\_t(x) = y ∈ A₀，则 x ∈ A₀。y ∈ A₀ ⊆ ω(z)（某 z ∈ B\_dyn），故有 tₙ → ∞ 使 Fl\_{tₙ}(z) → y。Ψ 在 U 上局部 Lipschitz，y ∈ U 且 Fl\_{−t}(y) = x 有定义，Fl\_{−t} 在 y 的邻域上连续，故 Fl\_{tₙ−t}(z) = Fl\_{−t}(Fl\_{tₙ}(z)) → x，即 x ∈ ω(z)。x 与 y 在同一条整轨道上，而 y 的整条轨道上 v ≡ 0，故 x 亦然，x ∈ A₀。由此 B\_dyn \\ A₀ 正向不变；与份额全正部分的正向不变取交，R 正向不变。∎

### 6.2　T1（互斥与完备）

T1a：四种取号条件两两不交。∎  
T1b：R ≠ ∅ 时 Σ(χ) 非空，且 Σ ⊆ {−, 0, +}，按是否含 +、是否含 − 恰落入四者之一。n ≥ 2 与 R ≠ ∅ 不可省；R ≠ ∅ 保证平型不是空真成立。∎

### 6.3　域引理与见证

域引理（β = 1 型份额律的最大域进入条件）  
设状态 x ∈ X = (0, ∞)ⁿ，n ≥ 2，正权 L₁, …, Lₙ，份额 qᵢ(x) = (xᵢ/Lᵢ)/Σⱼ(xⱼ/Lⱼ)，净律 Ψᵢ(x) = φᵢ(qᵢ(x)) − λxᵢ（λ \> 0），每个 φᵢ: \[0, 1\] → \[0, φ̄\] 连续、严格增、φᵢ(0) = 0，在 (0, 1\] 上 C¹ 且 φᵢ′ \> 0 于 (0, 1)。则：  
　(i) X 正向不变，xᵢ(t) ≤ max(xᵢ(0), φ̄/λ)；总量 S = Σxᵢ 满足 S(t) ≥ min(S(0), m/λ)，m = minᵢ φᵢ(1/n) \> 0。两界对初态在紧集上一致。  
　(ii) 若每个 φᵢ 在 \[0, 1\] 上 Lipschitz，令 U = {x ∈ ℝⁿ : xᵢ \> −η ∀i, Σⱼ max(xⱼ, 0) \> 0}（η \> 0），以 max(xⱼ, 0) 代替 xⱼ 定义 qᵢ（于是 qᵢ ∈ \[0, 1\]），则 Ψ 在 U 上局部 Lipschitz，U ⊃ X；自 X 的紧子集 K 出发的轨道之并落在 {xᵢ ≥ 0, xᵢ ≤ 上界, S ≥ min(min\_K S, m/λ)} 内，这是 U 的紧子集，故在 U 中一致预紧（极限点可在 X 的边界上，但在 U 内）。  
　(iii) 若每个 φᵢ 在 0 附近满足 φᵢ(q) ≥ κq^γ（0 \< γ \< 1，κ \> 0），则自 X 的紧子集 K 出发的轨道一致地满足 xᵢ(t) ≥ min(min\_K xᵢ, cᵢ) \> 0；轨道之并在 X 中预紧，取 U = X，Ψ 在 X 上局部 Lipschitz。  
　(iv) 在 (ii) 或 (iii) 下，份额映射 q 在 X 的邻域内 C¹；份额全正部分即 X，正向不变；A₀ 由 X 中的份额定态组成；除全中模型外 R ≠ ∅。  
证明：(i) xᵢ = 0 处 Ψᵢ = 0，且 Ψᵢ ≥ −λxᵢ 给出 xᵢ(t) ≥ xᵢ(0)e^{−λt}，故 X 正向不变；Ψᵢ ≤ φ̄ − λxᵢ 给出上界；因 Σqᵢ = 1，必有某 qᵢ ≥ 1/n，故 Ṡ = Σφᵢ(qᵢ) − λS ≥ m − λS，给出下界。(ii) 在 U 的每点附近分母 Σmax(xⱼ, 0)/Lⱼ 有正下界，qᵢ 局部 Lipschitz，φᵢ ∘ qᵢ 是 Lipschitz 函数的复合；所述紧集由 (i) 得到。(iii) 在 \[δ, 1\] 上 φᵢ(q)/q^γ 有正的最小值，与 0 附近的 κ 取小，得 \[0, 1\] 上的正下界 κ\*：φᵢ(q) ≥ κ\*q^γ。由 (i)，S ≤ S̄，qᵢ ≥ L\_min xᵢ/(Lᵢ S̄)，故 Ψᵢ ≥ κ′xᵢ^γ − λxᵢ，κ′ = κ\*(L\_min/(Lᵢ S̄))^γ；取 cᵢ = (κ′/λ)^{1/(1−γ)}，xᵢ \< cᵢ 时 Ψᵢ \> 0，故 xᵢ 不低于 min(xᵢ(0), cᵢ)。(iv) 直接。∎  
适用：局部族取 β = 1，φ(q) = (Iq)^α，α ≥ 1 属 (ii)，0 \< α \< 1 属 (iii)（γ = α）。黏菌模型 I 型 f = q^m（λ = 1）：m ≥ 1 属 (ii)，m \< 1 属 (iii)。II 型 f = 31q³/(1 + 30q³) 属 (ii)；构造例 f(q) = q^{0.2}e^{2.5q}/e^{2.5} 属 (iii)（γ = 0.2）；不等长 L = (1, 1.05)、m = 2 属 (ii)。T6 (c) 粗系统的写入律 (Iq)^α 与 2^{1−α}(Iq)^α 属 (ii)。  
排除：局部族 β ≠ 1 的参数不在本引理内，只签符号公式，不签全部进入条件。例：α = 3、β = 1/2、I = λ = 1、初态 (0.1, 1)，αβ \> 1，份额 s₁ 单调趋 0，轨道趋边界点 (0, 1)；而 Ψ₂(h, 1) = (1 + √h)^{−3} − 1，\|Ψ₂(h, 1) − Ψ₂(0, 1)\|/h ≈ 3/√h → ∞，不存在含 (0, 1) 的局部 Lipschitz 延拓，故不满足主读法的进入条件（数值对照见附录 B.5）。  
机制见证（模型模式，关系层）  
对域引理型的每个代表例，申报：  
　物理边界 B\_phys：介质（单元或管网）；结构位 x₁, …, xₙ 在界内；T = {1, …, n}；分辨率 ε = 0，非零分项即有效。  
　实际形成史：入口拍 t₀ − 1 由外部信号脉冲把每个 xᵢ 自 0 形成为 aᵢ \> 0（入 Form 与 Mark）；实际初态 a ∈ X。  
　窗 W = \[t₀, t₁\]，t₁ \> t₀；来流 I 申报为固定外部供给，迹应来源由入口信号见证（2.4）。  
　过程（载体都在 B\_phys 内）：对每个 i，写入过程 wᵢ，对象 xᵢ，律 φᵢ(qᵢ(x))，读取一切 xⱼ；退浅过程 dᵢ，对象 xᵢ，律 −λxᵢ，读取 xᵢ。证据边取规范边；POS、REC 申报，Ident、HistEv 取 1。  
核对：Act(wᵢ)：X 上 φᵢ(qᵢ) \> 0。HistCond(wᵢ)：∂(φᵢ ∘ qᵢ)/∂xᵢ = φᵢ′(qᵢ)·qᵢ(1 − qᵢ)/xᵢ ≠ 0（n ≥ 2、正状态使 0 \< qᵢ \< 1），读取位 xᵢ 大于 ε 且形成早于 W，可用位非空；同一过程 wᵢ 兼有 Act 与 HistCond，对象属于 T，故 HDyn = 1。Part：wᵢ 的组织条件支持含可用位，载体在 B\_phys 内，Part = 1。TraceSet：Src 由入口信号脉冲在 T 上留下 Mark；Ret 由 X 的正向不变给出 xᵢ(t₁⁺) \> 0 = ε 且 Form 非空；故 TraceSet = 1。界内：wᵢ 的 HistCond 经 B\_phys 内的读取，无界外分量，途径全在 B\_phys 内。本模板是带机制的申报模型，不由 Ψ 推出（2.5（四））；Tr^静 只作能力谓词另列。  
拍式读法：进入 R 层时，以时长 Δ 的流映射为一拍转移，W 取拍 t₀, …, t₁，入口拍为 t₀ − 1；各过程一拍的分项取该拍内的积分，写入为 ∫φᵢ(qᵢ(x(τ)))dτ，退浅为 ∫−λxᵢ(τ)dτ，二者之和即一拍增量。这一按过程的拍内积分是申报的分解（ε = 0 下不影响各判断）。X 上 φᵢ(qᵢ) \> 0、λxᵢ \> 0，故对任意 Δ \> 0 各分项非零。X 内 Ψ 为 C¹，流对拍首状态 C¹；Δ → 0 时，在实际轨道于有限窗 W 内扫过的紧集上，写入分项除以 Δ 对拍首状态的偏导一致收敛于 ∂(φᵢ ∘ qᵢ)/∂xᵢ，后者在该紧集上连续且远离 0；故存在一个 Δ₀ \> 0，Δ ∈ (0, Δ₀) 时写入分项对 xᵢ 的依赖不为零，上述核对在拍式读法下同样成立。Tr^静 见证取同一 Δ，该见证对任意 Δ \> 0 都成立。连续转移不在 R 层可解域内，本篇以解析核对代替求解。  
Tr^静 见证（模型模式；同一固定供给下的入口状态脉冲）  
背景供给 I = I₀ 在一切字母、两侧及静置尾段相同，判型净律 Ψ 不变。入口信号字母 w：在拍首自 B\_phys 外向申报入口位施加状态脉冲 P\_w(x) = x + η，η ∈ \[0, ∞)ⁿ 为固定的非零向量（与形成史中的入口信号同型）；静置 P\_rest(x) = x。以静置流 Fl\_t（Ψ 的流）定义一拍转移 Π\_u(x) = Fl\_Δ(P\_u(x))，Δ \> 0 固定。P\_u 保持 X，静置流保持 X（域引理 (i)），故一切有限词合法，𝓗 取全部有限序列。取共同起点 a = s₀ ∈ X（判定式 3.1（二）的申报起点），见证对 ((w), (rest)) 只在 1 个位置上不同，故对任何申报 k ≥ 1、H\_max ≥ 1 都合格，q 为任意有限非负整数，0 ≤ r \< 1；模型确定、无界外分量，钳定为恒等（《沉积场判定式》3.3）。经 q 拍静置后（q 为判定式的静置窗参数，r 为其分辨阈，与份额 qᵢ、相对增长 rᵢ 无关），两侧状态为 Fl\_{(q+1)Δ}(a + η) 与 Fl\_{(q+1)Δ}(a)。初态不同；若两态相同，由局部反向唯一性沿两轨道延续回 0 时刻，得 a + η = a，矛盾；故两态不同。两侧都是点分布，界内联合分布的总变差为 1 \> r，Tr^静 = 1。Tr^静 比较的是界内全部状态的联合分布，本见证不把联合差异当作每个坐标的边缘差异；若需逐结构位见证，按申报读数块逐项给入口与测量。本构造对 6.4 全部代表例与 T6 (c) 的粗系统都适用，不需要 φᵢ 关于 I 的延拓，不改变固定供给的申报。这是模型模式下的解析判值，连续状态模型不在《沉积场判定式》附录判定程序的支持域内（数值对照见附录 B.5）。

### 6.4　T2（各级非空）

以下各代表例满足 2.6 的全部进入条件（域引理），并附 6.3 的机制见证与 Tr^静 见证。  
（一）局部可交换族（涨、平、减）  
读出 κ = g^β（β \> 0），sᵢ = κ(gᵢ)/Z，Z = Σκ；写入 ġᵢ = (I sᵢ)^α − λgᵢ。令 c = α − 1/β，则  
　rᵢ − rⱼ = βI^α Z^{−1/β}(sᵢ^c − sⱼ^c)。  
证明：令 uᵢ = gᵢ^β，u̇ᵢ/uᵢ = βġᵢ/gᵢ = β\[I^α sᵢ^α gᵢ^{−1} − λ\]；代入 gᵢ = (sᵢZ)^{1/β} 得 u̇ᵢ/uᵢ = βI^αZ^{−1/β}sᵢ^c − βλ；rᵢ = u̇ᵢ/uᵢ − Σₖsₖu̇ₖ/uₖ，相减即得。∎  
公式对一切 α, β \> 0 成立。对非并列对 sᵢ ≠ sⱼ，αβ \> 1 时为分，αβ \< 1 时为合；αβ = 1 时所有对皆中。对并列对 sᵢ = sⱼ，任意这些参数下均为中（涨型宿载中出现平状态是宿载定义所允许的）。以下分列点态对向、状态势向与全域宿载类型三个层次。全部进入条件只对 β = 1 签：α \> 1 涨型，α = 1 平型，0 \< α \< 1 减型；代表取 α = 1.5、1、0.5。三种情形下 R 都含非均匀内部状态：c ≠ 0 时 A₀ 在内部只含均匀平衡点；c = 0 时 A₀ 是曲面 {Σg = I/λ}，其外仍有 R。机制见证按模板（φ(q) = (Iq)^α）。  
（二）黏菌两管等长（Tero 等 2007 的模型）  
Ḋᵢ = f(Qᵢ) − Dᵢ，Dᵢ 为传导度，Qᵢ = sᵢ = Dᵢ/S，S = D₁ + D₂。则 r₁ − r₂ = \[h(s₁) − h(s₂)\]/S，h(q) = f(q)/q。  
证明：rᵢ = Ḋᵢ/Dᵢ − Ṡ/S，故 r₁ − r₂ = f(s₁)/D₁ − f(s₂)/D₂ = \[h(s₁) − h(s₂)\]/S。∎  
I 型 f = q^m（一切 m \> 0 都在域引理内）：m \> 1 涨型，m = 1 平型，m \< 1 减型。这与 Tero 等（2007）的报告一致：m \> 1 只存一管、视初值；m = 1 等长时线段上处处平衡；m \< 1 两管俱存。机制见证按模板：适应过程 f(Qᵢ) 与退浅过程 −Dᵢ，载体在管网内，流量分配 Qᵢ 以传导度为条件。  
（三）不定型（解析点值，均在域引理内）  
　II 型 f = 31q³/(1 + 30q³)，两管等长、a = 30（本篇自算；Tero 原文的 II 型两管分析取 L₂ = 1.1）：h = 31q²/(1 + 30q³)，h(0.55) − h(0.45) = −0.116，h(0.95) − h(0.05) = +0.970：份额近半时合、近极时分（双稳）。见证点处 r₁ ≠ r₂，故 v ≠ 0，不属 A₀，在 R 内。  
　构造例 f(q) = q^{0.2}e^{2.5q}/e^{2.5}：h ∝ q^{−0.8}e^{2.5q}；以未归一化的 q^{−0.8}e^{2.5q} 计，h(0.55) − h(0.45) = +0.546，h(0.95) − h(0.05) = −1.247（归一化 h 为此值乘 e^{−2.5}，符号不变）：近半时分、近极时合（居间取衡）。  
　I 型 m = 2、两管不等长 L = (1, 1.05)：qᵢ = (Dᵢ/Lᵢ)/Σ。并列线 {D₁/L₁ = D₂/L₂} 上 r₁ − r₂ = f(1/2)(1/D₁ − 1/D₂) ≠ 0（D₁ ≠ D₂），且 q₁ − q₂ 在并列线两侧变号（横截），由 T8 为不定型。∎ 轨迹上可发生严格易位：初态 D = (0.5, 0.54) 时 q₁ 初为 0.493，终而管 1 独存（数值示例见附录 B.5，不作证明；不定型的判定只依 T8）。

### 6.5　T3（平型等价于份额沿轨迹不变）

若一切 rᵢ 相等为 ρ，则 0 = Σvᵢ = Σsᵢrᵢ = ρ，故 v ≡ 0；反之 v ≡ 0 则 r ≡ 0。∎（定义展开。）

### 6.6　T4（严格易位须先合后分）

设 Λ = log(sᵢ/sⱼ)，Λ′ = rᵢ − rⱼ。若沿 R 内一条轨迹 Λ(t\_a) \> 0 \> Λ(t\_b)，则存在 t\_a \< t₁ \< t₂ \< t\_b，该对在 t₁ 为合、在 t₂ 为分。  
证明：零点集 N₀ = {τ ∈ \[t\_a, t\_b\] : Λ(τ) = 0} 由介值定理非空，由连续性为闭集，故 t₋ = min N₀、t₊ = max N₀ 都取到，Λ(t₋) = Λ(t₊) = 0，t₋ ≤ t₊。在 \[t\_a, t₋\] 上由中值定理得 t₁ ∈ (t\_a, t₋)，Λ′(t₁) = −Λ(t\_a)/(t₋ − t\_a) \< 0，且 Λ(t₁) \> 0，即合。在 \[t₊, t\_b\] 上得 t₂ ∈ (t₊, t\_b)，Λ′(t₂) \< 0 且 Λ(t₂) \< 0，即 sᵢ \< sⱼ 而 rᵢ \< rⱼ，为分。t₁ \< t₋ ≤ t₊ \< t₂。∎  
推论（只签严格反序）：  
　涨型：Λ \> 0 时 Λ′ ≥ 0，Λ 不能降到 0，已有的严格次序保持；并列可被拉开，拉开方向不受限。  
　减型：Λ \> 0 时 Λ′ ≤ 0，严格次序可在有限时刻合为并列，但不能越过 0（否则由 T4 须有分，而减型无分）。  
　两型都不发生同一对的严格反序。主导易位指严格排序反转；并列的拆分与合并另计。严格的主导易位只能发生在不定型。  
　弱次序（含并列关系）不必保持。光滑例：ẋ = 1 − x，x ∈ (−1, 1)，s₁ = 1/2 + e(x)/10，s₂ = 1 − s₁。取 e(x) = exp(−1/x²)（x \> 0），否则 0：x ≤ 0 时并列，x \> 0 时 s₁ \> s₂ 且为分，全部状态只有涨或平，为涨型，轨迹自 x = −1/2 到正 x 时并列被拉开。取 e(x) = exp(−1/x²)（x \< 0），否则 0：只有减或平，严格次序在有限时刻合为并列。取 B\_dyn = (−1, 1)、U = ℝ，两例满足 2.6（一）—（三）的数学进入条件；它们只说明次序边界，不是宿载实例，不带机制见证与 Tr^静 见证；ω-极限点 x = 1 不在 B\_dyn 内，不影响这两段暂态。

### 6.7　T5（集中度单调）

设 Γ 定义在含单纯形内部的对称开凸集（ℝⁿ 中）上，对称、C¹、Schur 凸。涨型中，沿 R 内轨迹 Γ(s) 不减；减型中不增。  
证明：dΓ/dt = Σᵢ ∂ᵢΓ·sᵢrᵢ。对一切 i, j 有 (rᵢ − rⱼ)(∂ᵢΓ − ∂ⱼΓ) ≥ 0：sᵢ \> sⱼ 时，无合给出 rᵢ ≥ rⱼ，Schur–Ostrowski 条件给出 ∂ᵢΓ ≥ ∂ⱼΓ；sᵢ = sⱼ 时，对称给出 ∂ᵢΓ = ∂ⱼΓ。因 Σsᵢrᵢ = Σvᵢ = 0，dΓ/dt = ½Σᵢⱼsᵢsⱼ(rᵢ − rⱼ)(∂ᵢΓ − ∂ⱼΓ) ≥ 0（以 s 为权的切比雪夫和不等式）。减型反号。∎  
优超序：对任一光滑凸函数 ϑ，Σϑ(sᵢ) 是对称 C¹ Schur 凸函数，沿涨型轨迹不减；对连续凸 ϑ，在有限轨迹段所处的单纯形紧子域上以光滑凸函数一致逼近，由 Hardy–Littlewood–Pólya 刻画，s(t₂) 优超 s(t₁)（t₂ \> t₁）。减型反之。

### 6.8　T6（不变性及其限度）

（a）势型只依赖份额轨迹，在状态的微分同胚重编码下不变：共轭动力与复合份额映射保持 Ds·Ψ 及其符号。  
（b）状态势向在份额合并下不保证保持：6.4（一）的涨型（α = 1.5、β = 1，c = 1/2）在 s = (0.4, 0.3, 0.3) 处，由 rᵢ − rⱼ ∝ sᵢ^c − sⱼ^c 得 r₁ \> r₂ = r₃，为涨；把迹应 2、3 的份额合并，合并份额的相对增长 r₂₃ = (v₂ + v₃)/(s₂ + s₃) = r₂ \< r₁，而 s₁ = 0.4 \< s₂₃ = 0.6，读数 (0.4, 0.6) 处为合，即减（数值对照见附录 B.2）。这只是读数层的结论，不冒充粗动力闭合。  
（c）受限闭合粗粒化下势型可变。构造顺序：完整细系统，限制到正向不变子系统，合并成闭合粗系统。可交换族中 g₂ = g₃ 蕴含 ġ₂ = ġ₃（置换对称），子空间 {g₂ = g₃} 正向不变，其上合并是严格的：粗宿载以 (g₁, G)，G = g₂ + g₃ 为状态，s₁ = κ(g₁)/(κ(g₁) + 2κ(G/2))，ġ₁ = (I s₁)^α − λg₁，Ġ = 2(I(1 − s₁)/2)^α − λG，动力由粗状态自身决定。β = 1、α = 1.5 时，s₁ = g₁/S，s₂₃ = G/S，r₁ − r₂₃ = (I^α/S)\[s₁^{α−1} − 2^{1−α}s₂₃^{α−1}\]，其符号即 s₁ − s₂₃/2 的符号：s₁ \> 1/2 时为分，1/3 \< s₁ \< 1/2 时为合，s₁ \< 1/3 时为分。故细宿载为涨型，粗宿载为不定型（数值核对见附录 B.3）。本款的结论是：存在一个涨型细宿载及其正向不变子系统，使该子系统的份额合并形成闭合粗动力而为不定型；整个三维细宿载是否存在同一个闭合的二维粗动力，不在此结论之内。粗系统满足域引理 (ii)；其实例资格按机制见证模板另行申报（写入律 (Iq)^α 与 2^{1−α}(Iq)^α），Tr^静 见证同 6.3。  
故势型相对于族的划分；把一个宿载的势型推到它的粗粒化上，须另证。

### 6.9　T7（平型的余维）

（a）在 6.4（一）的 (α, β) 参数平面内，平型（就符号公式而言）是 αβ = 1 一条光滑曲线，余维 1。  
（b）固定开集 O 与 O 上的 C¹ 份额映射 s，设 O 内某点 x₀ 处 Ds(x₀) ≠ 0。则 O 上 C¹ 向量场所成线性空间 𝒱 中，约束子空间 𝒱₀ = {Ψ ∈ 𝒱 : Ds·Ψ = 0 于 O} 的代数余维为无穷。  
证明（b）：取向量 w 使 Ds(x₀)w ≠ 0；由 Ds 连续，有以 x₀ 为心的球 B₀ ⊂ O，其上 Ds(x)w ≠ 0。在 B₀ 内取可数个两两不交的小球 Bₖ 及其上的 C¹ 紧支非负截断函数（凸起函数）χₖ，χₖ 在 Bₖ 内某点为正，令 Ψₖ = χₖw。对任意有限组不全为零的系数 cₖ，Σcₖ Ψₖ 在某个 cₖ ≠ 0 的 Bₖ 内满足 Ds·(Σcₖ Ψₖ) = cₖχₖ Ds·w ≠ 0，故不属 𝒱₀。于是 {Ψₖ} 模 𝒱₀ 线性无关，商空间无穷维。∎  
限定：前件 Ds ≠ 0 不可省。常份额映射（Ds ≡ 0）下任何 Ψ 都给 v = 0，平型构成整个类，余维为 0；常份额不等于无历史动力（H2）。（b）的对象是固定的 O 与 s；「在随 Ψ 而变的 R 上恒为 0」不作为一个固定子空间。「无内点」（T8 推论二′）不等于「无穷余维」。

### 6.10　T8（并列引理）及推论

T8：设 x 是 R 的内点，sᵢ(x) = sⱼ(x)，x 的任一邻域内 sᵢ − sⱼ 都取正负两号，且 rᵢ(x) ≠ rⱼ(x)。则 x 的邻域内该对同时出现分与合，宿载为不定型。  
证明：s 为 C¹、Ψ 连续，故 v = Ds·Ψ 与 rᵢ − rⱼ 在 x 的邻域内连续；于是有 x 的邻域 N ⊂ R（x 为 R 的内点）使 rᵢ − rⱼ 在 N 内与 rᵢ(x) − rⱼ(x) 同号且不为 0。在 N 内分别取 sᵢ − sⱼ 与之同号、异号的点，即得分与合。∎  
推论一：涨型、减型与平型中，R 内部满足「任一邻域取两号」的并列点上必有 rᵢ = rⱼ。  
推论二：任何全域定号的势型，都要求 R 内部这类并列点满足 rᵢ = rⱼ。  
推论二′（无内点；固定份额映射的数学向量场类）  
　模型类 𝔉：给定申报层级、开状态域 X = B\_dyn、C¹ 份额映射 s、开集 U ⊃ X，𝔉 为 U 上满足 2.6 数学进入条件（Ψ 局部 Lipschitz 且在 X 附近 C¹、X 正向不变、份额全正部分正向不变、一致预紧、R ≠ ∅）的自治向量场之集；拓扑取紧支 C¹ 拓扑，即 Ψ 的邻域基为 {Ψ + Θ : Θ ∈ C¹\_c(U), ‖Θ‖\_{C¹} \< δ} ∩ 𝔉（δ \> 0）。𝔉 是数学向量场类，其成员不带 Tr、TraceSet、载体分解与 W 的资格；其结论不传给可实现的机制模型子族；向这类子族的传递以另立的可容许扰动假设及其逐项证明为前提。  
　合格并列点：x₀ ∈ R 内部，sᵢ(x₀) = sⱼ(x₀)，且 D(sᵢ − sⱼ)(x₀) ≠ 0。  
　命题：设 Ψ ∈ 𝔉 为定号型，且 R 内部含合格并列点 x₀。则 Ψ 的任一紧支 C¹ 邻域内有 Ψ′ ∈ 𝔉 为不定型；不定型在 𝔉 中是开集。故含合格并列点的定号型在 𝔉 中无内点。  
　证明（i）：由推论一，x₀ 处 rᵢ = rⱼ，即 D(sᵢ − sⱼ)(x₀)·Ψ(x₀) = 0。取闭球 K₀ ∋ x₀，K₀ 在 X 内且与 X 的边界、与份额非全正的集相离，在 K₀ 内 D(sᵢ − sⱼ) ≠ 0；取 C¹ 函数 Θ，支撑于 K₀，使 D(sᵢ − sⱼ)(x₀)·Θ(x₀) ≠ 0。令 Ψ′ = Ψ + εΘ，ε ≠ 0 充分小。逐项核对 Ψ′ ∈ 𝔉：局部 Lipschitz 与 C¹ 显然；X 与份额全正部分都是开集且在 Ψ 下正向不变，Ψ′ 在其边界的邻域内等于 Ψ，Ψ′-轨道若离开，必先在该邻域内沿一段 Ψ-轨道到达边界，与 Ψ 下的正向不变矛盾；一致预紧：Ψ′-轨道在 K₀ 外的各段都是自 K₀ 或自初始紧集出发的 Ψ-轨道段，其并含于 Ψ 下自这两个紧集出发的轨道之并与 K₀ 之并，由 Ψ 的一致预紧，在 U 中预紧。x₀ 处 v′ᵢ − v′ⱼ = εD(sᵢ − sⱼ)(x₀)·Θ(x₀) ≠ 0，故 r′ᵢ(x₀) ≠ r′ⱼ(x₀)，v′(x₀) ≠ 0；由 v′ 连续，x₀ 的某邻域内 v′ ≠ 0，该邻域与 A₀′ 不交，x₀ 是 R′ 的内点，R′ ≠ ∅，且仍是合格并列点（s 未变）。由 T8，Ψ′ 为不定型。  
　证明（ii）：不定型 Ψ 在 R 中有点 x₊、x₋ 分别带某对的 σ = +、σ = −（严格）；这些点上 r 的某个差不为 0，故 v ≠ 0。r 的各差在固定点处随 Ψ(x) 的点值连续，紧支 C¹ 小扰动 Ψ′ ∈ 𝔉 保持这些严格符号与 v′(x±) ≠ 0；v′(x±) ≠ 0 使 x± 不属 A₀′，又在 X 内、份额全正，故 x± ∈ R′，Ψ′ 仍为不定型。∎  
　限定：在可交换参数族这类结构化子类中，定号型可以是开的。按第五节申报盆限势型而 R 避开并列集时，涨型可以稳健。  
推论四（无处稠密）：记 S 为 𝔉 中含合格并列点的定号型之集，O 为 𝔉 中的不定型之集。则 S 在 𝔉 中无处稠密。  
证明：由推论二′，O 是开集，S ∩ O = ∅，且 S ⊆ cl(O)。于是 cl(S) ⊆ 𝔉 \\ O（O 开），又 cl(S) ⊆ cl(O)，故 cl(S) ⊆ cl(O) \\ O = ∂O。开集的边界没有内点，故 int(cl(S)) = ∅。∎ 证明不用 Baire 定理；结论不含不定型在整个 𝔉 中稠密，结论只就集合 S 而言，不涉及没有合格并列点的其他定号型。  
　关于既定势差（与推论二′ 分开，不享有同等证明资格）：既定势差（介质参数不等，H4）可能破坏并列处的增长率相等条件，从而产生不定型；是否发生，取决于该势差实际进入更新律的方式。黏菌两管不等长是一个发生的实例（6.4（三）），不构成「有地势的宿载一般为不定型」的证明。  
推论三（并列规则不另造类型）：并列规则「sᵢ = sⱼ 而 rᵢ ≠ rⱼ 计为分」在 R 的内点处不改变宿载判型。  
证明：设 x 为 R 的内点，sᵢ(x) = sⱼ(x)，rᵢ(x) ≠ rⱼ(x)。则 vᵢ(x) − vⱼ(x) = sᵢ(x)(rᵢ(x) − rⱼ(x)) ≠ 0，即 D(sᵢ − sⱼ)(x)·Ψ(x) ≠ 0，沿过 x 的流线 sᵢ − sⱼ 在 x 处严格单调变号，x 的任一邻域内取正负两号；由 T8，x 的邻域内已有严格的分与合，宿载为不定型，与是否把 x 本身计为分无关。若 rᵢ(x) = rⱼ(x)，规则不触发。∎ 并列规则只在 R 的边界上可能起作用。

七、最终表达  
在 H1—H4 与申报（宿载，层级，Φ，B\_dyn，平稳来流）下，B\_dyn 按第五节取最大域，势型由对向符号 σ 在 R 上的取号集定，四级互斥、完备、非空（6.4 的代表例满足全部进入条件并附机制见证）：  
　涨型（只有 + 与 0）：已有严格次序保持，并列可被拉开；优超序上不降。  
　平型（只有 0）：活动份额零变换，即组织方式的这一读数不变；不推出组织方式本身不变（H2）。  
　减型（只有 − 与 0）：严格次序不反转、可合为并列；优超序上不升。  
　不定型（兼有 + 与 −）：严格的主导易位只能在此发生。  
涨、平、减三型要求并列处增长率相等（T8 推论二）；在固定份额映射的数学向量场类 𝔉 中，R 内部含合格并列点的定号型无内点，且其全体无处稠密（推论二′、推论四）。既定势差可能使宿载落入不定型，视其进入更新律的方式而定。

八、具化实例（实例化责任，不承载第六、七节结论的成立；携带 H1—H4）  
　涨型候选：新生神经肌肉接头的突触淘汰，多轴突共占一个接头，竞争后只留一条（Turney 与 Lichtman 2012，PLoS Biology，DOI 10.1371/journal.pbio.1001352；Robinson 2012 的综述性简介，PLoS Biology，DOI 10.1371/journal.pbio.1001354）。有张力：原文报告领地份额往复翻转，结局不能由相对份额确定预言，即有严格易位。按 T4 推论，若易位属系统漂移，应判不定型；若归于涨落（E1）或界外改写（如激光切除），方可判涨。须申报；平稳输入、漂移分离与沉积场资格都未认证。  
　平型：不签（E5、E7）。突触缩放（Turrigiano 等 1998，Nature，DOI 10.1038/36103，报告比例缩放）只能算状态势向「平」的近似观测；活动阻断改变了来流，不满足来流平稳。  
　减型候选：黏菌模型 I 型 m \< 1（模型实例；Tero、Kobayashi、Nakagaki 2007，Journal of Theoretical Biology 244: 553—564，DOI 10.1016/j.jtbi.2006.07.015）。实物实例未定。  
　不定型候选：黏菌两管不等长（模型实例；Tero 原文给出模型与结局，m = 1 不等长时只存短者，判为不定型是本篇计算）；河道改道（未有一手文献依据，不作已认证例）。  
物质实例的归属：上列实物候选都未取得《沉积场判定式》4.8 的界内自反馈型判 1（多头绒泡菌在判定式实例乙中，Tr^静 与各职责现判 ⊥\_Obs/⊥\_Prof，缺 MOD、LOC 等取证条件，未作 4.8 判词）；在取得之前，其势型只作候选登记，不归于该物质实例，也不判其不满足资格（2.5）。  
计算机：判定边界有两种读法，乙读指边界只含存储，甲读指边界含程序。若取乙读，存储单元间不存在由状态决定的共享来流分配，组织之变来自界外程序，出自迹应的动力途径经过界外，不属一般式第七节界内自反馈型（同该篇见证 χ\_e 的情形），不入本级。《沉积场判定式》实例甲给出同型的算法层判值：χ\_ext 中 B\_phys 内唯一运行过程的 Act\_F = 0，在 INV-c 与 EF4 下界内自反馈型判 0，未申报 INV-c 判 ⊥；χ\_in 判 1。若取甲读，须按程序的分配律另判。

九、误判界  
　E1　涨落之势：分级对象是漂移读法（期望更新律），不是整个随机实际过程；涨落之势不计入势向，须另报。  
　E2　申报域：按第五节取最大可容许域（主读法），并在含 X 的 Lipschitz 开域 U 中满足预紧；缩小 B\_dyn 以得定号型属禁止写法；盆限势型与可达势型只作附加报告，须另注。  
　E3　既定势差（地势）：计入势向的计算（H4）；可能破坏并列处增长率相等而产生不定型，视其进入更新律的方式而定；不据此判定它是否为定义三意义上的势。  
　E4　侧向项：计入；势向按份额判，不论势源。  
　E5　实测：有限实测只签势向的存在；不签平型与势型全称；定型依赖模型，申报为实例化责任；全域设定只是一种取证途径，不是唯一途径。  
　E6　族的粗细：势型相对于申报划分；闭合粗粒化下势型可变（T6 (c)）。  
　E7　涨、平、减三型的限制：平型在 6.4（一）的参数平面内（就符号公式而言）余维 1；固定 O 与 Ds ≠ 0 的 s 下约束子空间代数余维无穷，Ds ≡ 0 时余维 0（T7）；三型都要求并列处增长率相等，实例须申报其来源；数学向量场类 𝔉 中含合格并列点的定号型无内点，其全体无处稠密（T8 推论二′、推论四），「无内点」「无处稠密」都不等于「无穷余维」。  
　E8　带阈宿载：阈处分段申报，族改变须重报；各段分别满足进入条件。  
　E9　进入条件的证据级：净律 Ψ 与份额轨迹不单独认证三项职责与界内条件（2.5（四）；《场具化不可区分式》定理二、六按原文带族、A(T)、FIN 与观测集）；物质实例须取得《沉积场判定式》4.6—4.8 的判词，未取得者势型不归于该实例，也不判其不满足资格。

十三、解读（不属形式结构）  
　作者古文 812「抑二助一为之势平……抑八助三势为减……抑七助四势乃涨」：势带符号，涨、平、减三名取此。812 的「势平」是抑助相当的状态，本篇平型是处处势平的宿载。  
　平型（T3）：迹应照常加深退浅而活动份额不变，是本体定义所含「零变换」在这一读数上的非平凡实例（β = 1、α = 1）；组织方式本身是否零变换，不由 T3 判定（H2）。  
　作者古文 810 列的是趋衡方式：「上下振荡以渐衡，或增大至极以衡，或减弱至极以衡，或至其间以衡」。涨型的优超方向即增大至极，减型即趋均（只指集中度变化的方向，T5 只给单调性，不签轨迹必至极端吸引子）；「至其间以衡」与「振荡以渐衡」都落在不定型。

A.1　shi\_type.py　数值采样判型器：局部可交换族、黏菌两管模型的采样判型，II 型与构造例的解析点值，证据强度对照（6.4，第四节）

~~~python
"""势型分级 · 数值采样判型器（连续时间模型的数值示例；不是全称判定程序）
证据强度：
  · state_dir 以浮点计算，用两项容差：相对增长差 |r_i − r_j| ≤ TOL（1e-10）按「中」计；份额差 |s_i − s_j| ≤ 1e-14 按并列计；容差内的非零差被计为中，
    故「平」只表示容差内未见非零号，不是精确平型。精确的平型与全称分类只来自解析证明（正文 6.4、6.9）。
  · host_type 汇总有限样本：空样本返回「未定（无样本）」，不返回平型；「未见反号」不等于全域定号。
  · local() 在 [0.05, 5]^n 内均匀取样 M 点；不计算份额定态集 A₀（取样点落入其中的概率为零；此为取样约定，不作证明）。
  · tero() 在网格 [0.01, 1]² 上取样，剔除 |F| < 1e-9 的点；这是取样规则，不是一般 A₀ 的计算，网格也不是可达域的证明。
状态势向（对每一对 (i,j)，s_i,s_j > 0）：
  分：(s_i−s_j)(r_i−r_j) > 0，或 s_i = s_j 而 r_i ≠ r_j；合：(s_i−s_j)(r_i−r_j) < 0；中：r_i = r_j（数值上 |r_i−r_j| ≤ TOL）
  涨 = 无合且有分；减 = 无分且有合；平 = 全中；混 = 有分有合
样本势型：涨型 / 减型 / 平型（容差内）/ 不定型 / 未定（无样本）"""
import numpy as np, itertools
TOL = 1e-10
def state_dir(s, v):
    r = v / s; div = conv = False
    for i, j in itertools.combinations(range(len(s)), 2):
        dr = r[i] - r[j]
        if abs(dr) <= TOL: continue
        ds = s[i] - s[j]
        if abs(ds) <= 1e-14 or ds * dr > 0: div = True
        else: conv = True
    return '平' if not (div or conv) else '混' if (div and conv) else '涨' if div else '减'
def host_type(dirs):
    if not dirs: return '未定（无样本）'
    S = set(dirs) - {'平'}
    if not S: return '平型（容差内）'
    if S == {'涨'}: return '涨型'
    if S == {'减'}: return '减型'
    return '不定型'
# 两管黏菌（Tero 等 2007）：D' = f(Q) − D，D 为传导度（适应变量），Q = (D/L)/Σ(D/L)；网格取样，剔除 |F| < 1e-9 的点
def tero(f, N=120, L=(1.0, 1.0)):
    dirs = []
    for D1 in np.linspace(0.01, 1.0, N):
        for D2 in np.linspace(0.01, 1.0, N):
            k = np.array([D1 / L[0], D2 / L[1]]); s = k / k.sum()
            F = np.array([f(s[0]) - D1, f(s[1]) - D2])
            if np.abs(F).max() < 1e-9: continue          # 取样规则：剔除近零速度点（不是一般 A₀ 的计算）
            dk = F / np.array(L); v = (dk * k.sum() - k * dk.sum()) / k.sum() ** 2
            dirs.append(state_dir(s, v))
    return host_type(dirs)
# 局部可交换族：读出 g^β，写入 (I s)^α，退浅 0.1 g；n = 3；在 [0.05, 5]^n 内均匀取样
def local(a, b, n=3, M=3000, seed=1):
    rng = np.random.default_rng(seed); dirs = []
    for _ in range(M):
        g = rng.uniform(0.05, 5, n); k = g ** b; s = k / k.sum()
        F = s ** a - 0.1 * g
        dk = b * g ** (b - 1) * F; v = (dk * k.sum() - k * dk.sum()) / k.sum() ** 2
        dirs.append(state_dir(s, v))
    return host_type(dirs)
if __name__ == '__main__':
    print('以下为数值采样判型（浮点、容差 1e-10、有限样本），只作示例，不作全称结论；全称分类见正文的解析证明')
    print('— 局部可交换族（n=3）—')
    for a, b in [(1.5, 1), (1, 1), (0.5, 1), (1.5, 2 / 3), (2, 0.5), (1, 1.5), (1, 0.7)]:
        print(f'α={a:.2f} β={b:.2f} αβ={a*b:.2f} → {local(a, b)}')
    print('— 黏菌两管等长 —')
    cases = {'I 型 m=2': lambda q: q ** 2, 'I 型 m=1': lambda q: q, 'I 型 m=0.5': lambda q: q ** 0.5,
             'II 型 m=3 a=30（双稳）': lambda q: 31 * q ** 3 / (1 + 30 * q ** 3),
             '构造 f=q^0.2·e^{2.5q}（居间取衡）': lambda q: q ** 0.2 * np.exp(2.5 * q) / np.exp(2.5)}
    for k, f in cases.items(): print(f'{k:34s} → {tero(f)}')
    print(f'{"I 型 m=2，两管不等长 L=(1,1.05)":34s} → {tero(lambda q: q ** 2, L=(1, 1.05))}')
    h2 = lambda q: 31 * q ** 2 / (1 + 30 * q ** 3); hc = lambda q: q ** -0.8 * np.exp(2.5 * q)
    print('6.4（三）解析点值（构造例为未归一化 h）：II 型 a=30：h(.55)-h(.45)=%+.3f，h(.95)-h(.05)=%+.3f；构造例：s=.55 处 %+.3f，s=.95 处 %+.3f'
          % (h2(.55) - h2(.45), h2(.95) - h2(.05), hc(.55) - hc(.45), hc(.95) - hc(.05)))
    # 并列对：不可交换两迹应在 s=(0.5,0.5) 处速度 ±0.1875
    print('并列分离判向：', state_dir(np.array([.5, .5]), np.array([.1875, -.1875])))
    print('— 证据强度对照 —')
    s, v = np.array([.6, .4]), np.array([1e-12, -1e-12])
    ex = np.sign((s[0] - s[1]) * (v[0] / s[0] - v[1] / s[1]))
    print(f'极小非零速度 v=(1e-12,-1e-12)、s=(.6,.4)：精确符号 {ex:+.0f}（涨），state_dir 判「{state_dir(s, v)}」（容差内计为中）')
    print(f'αβ = 1 + 1e-12（α=1+1e-12, β=1）：解析判涨型；采样判「{local(1 + 1e-12, 1, M=100)}」')
    print(f'空样本：host_type([]) = 「{host_type([])}」')
~~~

A.3　t6\_coarse.py　受限闭合粗粒化的闭合性核对与粗系统样本势型（6.8（c））

~~~python
"""正文 6.8（c）数值核对（闭合性为浮点比对；粗宿载判型为有限网格取样，解析判号见正文 6.8（c））：在可交换不变子空间 {g2 = g3} 上的严格合并（闭合的粗粒宿载）
细宿载：n=3，读出 g^β（β=1），写入 (I s)^α（α=1.5），退浅 λg —— 涨型（正文 6.4（一））。
粗宿载：状态 (g1, G)，G = g2 + g3，约束 g2 = g3 = G/2（可交换性使该子空间不变，故动力闭合）：
  s1 = κ(g1)/(κ(g1)+2κ(G/2))，s23 = 1 − s1
  ġ1 = (I s1)^α − λ g1，Ġ = 2 (I s23/2)^α − λ G
"""
import numpy as np
from shi_type import state_dir, host_type
a, b, I, lam = 1.5, 1.0, 1.0, 0.1
k = lambda g: g ** b
def coarse_v(g1, G):
    s1 = k(g1) / (k(g1) + 2 * k(G / 2)); s = np.array([s1, 1 - s1])
    F1 = (I * s1) ** a - lam * g1; FG = 2 * (I * (1 - s1) / 2) ** a - lam * G
    # 份额速度：s1 = k(g1)/(k(g1)+2k(G/2))，对 (g1,G) 求导
    K = k(g1) + 2 * k(G / 2); dk1 = b * g1 ** (b - 1); dkG = b * (G / 2) ** (b - 1)  # d k(G/2)/dG = dkG/2，乘 2 得 dkG
    ds1 = (dk1 * F1 * K - k(g1) * (dk1 * F1 + dkG * FG)) / K ** 2
    return s, np.array([ds1, -ds1])
# 闭合性核对：细宿载在 g2=g3 上的 s1 速度 与 粗宿载给出的一致
def fine_v(g):
    kk = k(g); s = kk / kk.sum(); F = (I * s) ** a - lam * g
    dk = b * g ** (b - 1) * F; return s, (dk * kk.sum() - kk * dk.sum()) / kk.sum() ** 2
err = 0
for g1 in np.linspace(0.2, 9, 15):
    for G in np.linspace(0.2, 9, 15):
        s, v = coarse_v(g1, G); sf, vf = fine_v(np.array([g1, G / 2, G / 2]))
        err = max(err, abs(v[0] - vf[0]))
print(f'闭合性：粗宿载与细宿载在不变子空间上 s1 速度最大差 = {err:.2e}')
dirs = []
for g1 in np.linspace(0.05, 10, 120):
    for G in np.linspace(0.05, 10, 120):
        s, v = coarse_v(g1, G)
        if np.abs(v).max() < 1e-12: continue
        dirs.append(state_dir(s, v))
print('粗宿载样本势型（网格取样）：', host_type(dirs), ' 状态势向出现：', sorted(set(dirs)))
s, v = coarse_v(4.0, 6.0); print('粗宿载在 s=(0.4,0.6) 处势向：', state_dir(s, v))
s, v = coarse_v(7.0, 3.0); print('粗宿载在 s=(0.7,0.3) 处势向：', state_dir(s, v))
~~~

A.4　tero\_types.py　黏菌两管模型的两管数值对照（6.4（二）（三））

~~~python
"""势型分级 · 黏菌两管等长模型（Tero 等 2007）的两管数值对照
D_i' = f(Q_i) − D_i，D 为传导度（适应变量），Q_i = D_i/(D_1+D_2)（等长、I0=1）；活动份额 s = Q。
P(x) = Σ s_i v_i，v = Ds·F。两管时 v₂ = −v₁，P = (s₁ − s₂)v₁，而 r₁ − r₂ = v₁/(s₁s₂)，故在非并列处（s₁ ≠ s₂）sgn P = σ₁₂；并列处 P = 0 而并列规则可能取 σ = +（本程序网格去掉 D₁ = D₂）：P 只是两管情形下对向符号的等价写法，
不是一般 n 维的判据，不用于一般族判型。取样：网格 [0.02, 1]²（去掉 D₁ = D₂），浮点容差 1e-12；有限样本，只作数值对照，不作全称结论。"""
import numpy as np
def P_profile(f, Dmax=1.0, N=160):
    vals = []
    for D1 in np.linspace(0.02, Dmax, N):
        for D2 in np.linspace(0.02, Dmax, N):
            if abs(D1 - D2) < 1e-9: continue
            S = D1 + D2; s1, s2 = D1 / S, D2 / S
            F1, F2 = f(s1) - D1, f(s2) - D2
            ds1 = (F1 * S - D1 * (F1 + F2)) / S ** 2; ds2 = -ds1
            vals.append(s1 * ds1 + s2 * ds2)
    v = np.array(vals); tol = 1e-12
    pos, neg = (v > tol).any(), (v < -tol).any()
    return ('涨型' if pos and not neg else '减型' if neg and not pos else '平型（容差内）' if not pos and not neg else '不定型'), v.min(), v.max()
cases = {
 'I 型 m=2': lambda q: q ** 2,
 'I 型 m=1': lambda q: q,
 'I 型 m=0.5': lambda q: q ** 0.5,
}
for a in (0.5, 10, 30, 60, 200):
    cases[f'II 型 m=3, a={a}'] = (lambda a: lambda q: (1 + a) * q ** 3 / (1 + a * q ** 3))(a)
print('两管数值对照（网格取样、浮点容差 1e-12；只作示例，不作全称结论）')
for k, f in cases.items():
    t, lo, hi = P_profile(f)
    print(f'{k:20s} → {t}   P ∈ [{lo:+.4f}, {hi:+.4f}]')
~~~

A.5　domain\_T2.py　域引理的数值对照、排除例与同一固定供给下的入口脉冲见证（6.3，6.4）

~~~python
"""T2 代表例的最大域进入条件：数值对照（RK4 积分、有限初态；只作对照，证明见正文 6.3 的域引理）
各代表例在主读法 X = 开正卦限上取样初态，积分到 t = 60，报告：总量 S 的上下界、最小分量的走向、
以及最小分量趋 0 时 F 在边界附近是否可 Lipschitz 延拓（以差商估计）。另以 α=3、β=1/2 作排除对照，
以同一固定供给下的入口状态脉冲（P_w(x) = x + η，再施同一静置流）核对两条只差一个脉冲的史在静置后状态不同。"""
import numpy as np
def rk4(F, x, T=60.0, h=1e-2):
    steps = max(1, round(T / h)); h = T / steps          # 步数取整后按实际步长积分，终点恰为 T
    xs = [x.copy()]
    for _ in range(steps):
        k1 = F(x); k2 = F(x + h / 2 * k1); k3 = F(x + h / 2 * k2); k4 = F(x + h * k3)
        x = x + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4); xs.append(x.copy())
    return np.array(xs)
def local(alpha, beta, I=1.0, lam=1.0):
    def F(g):
        k = np.maximum(g, 0) ** beta; s = k / k.sum()
        return (I * s) ** alpha - lam * g
    return F
def tero(f, L=(1.0, 1.0)):
    L = np.array(L)
    def F(D):
        k = np.maximum(D, 0) / L; s = k / k.sum()
        return f(s) - D
    return F
inits = [np.array(x) for x in ([0.1, 1.0], [1.0, 0.1], [0.5, 0.52], [3.0, 0.02], [0.02, 3.0])]
cases = [
    ('局部族 β=1, α=1.5（涨）', local(1.5, 1.0), 'ext'),
    ('局部族 β=1, α=1（平）', local(1.0, 1.0), 'int'),
    ('局部族 β=1, α=0.5（减）', local(0.5, 1.0), 'int'),
    ('Tero I 型 m=2（涨）', tero(lambda q: q ** 2), 'ext'),
    ('Tero I 型 m=1（平）', tero(lambda q: q), 'int'),
    ('Tero I 型 m=0.5（减）', tero(lambda q: q ** 0.5), 'int'),
    ('Tero II 型 a=30（不定）', tero(lambda q: 31 * q ** 3 / (1 + 30 * q ** 3)), 'ext'),
    ('构造例 q^0.2·e^{2.5q}（不定）', tero(lambda q: q ** 0.2 * np.exp(2.5 * q) / np.exp(2.5)), 'int'),
    ('Tero I 型 m=2，L=(1,1.05)（不定）', tero(lambda q: q ** 2, L=(1, 1.05)), 'ext'),
]
print('数值对照（RK4，h=0.01，t∈[0,60]，5 个初态）；证明见正文 6.3 域引理')
for name, F, mode in cases:
    Smin = Smax = None; mins = []
    for x0 in inits:
        X = rk4(F, x0); S = X.sum(axis=1)
        Smin = S[100:].min() if Smin is None else min(Smin, S[100:].min())
        Smax = S.max() if Smax is None else max(Smax, S.max())
        mins.append(X[-1].min())
    tail = '最小分量趋 0（极限在开卦限边界，须在含边界的开域上 Lipschitz 延拓）' if min(mins) < 1e-6 else \
           f'最小分量保持正下界（末值最小 {min(mins):.3g}），轨道在开卦限内预紧'
    assert (mode == 'ext') == (min(mins) < 1e-6), name
    print(f'  {name}：t≥1 时 S ∈ [{Smin:.3f}, {Smax:.3f}]；{tail}')
# 边界延拓：β=1 时 s 对 g 光滑；α>1 时 s^α 在 s=0 处 C¹；以差商核对
for name, F in [('局部族 β=1, α=1.5', local(1.5, 1.0)), ('Tero II 型 a=30', tero(lambda q: 31 * q ** 3 / (1 + 30 * q ** 3)))]:
    r = [abs(F(np.array([h, 1.0]))[1] - F(np.array([0.0, 1.0]))[1]) / h for h in (1e-4, 1e-8, 1e-12)]
    print(f'  {name}：边界点 (0,1) 处差商 |F₂(h,1) − F₂(0,1)|/h = ' + ', '.join(f'{x:.4g}' for x in r) + '（有界）')
F = local(3.0, 0.5)
r = [abs(F(np.array([h, 1.0]))[1] - F(np.array([0.0, 1.0]))[1]) / h for h in (1e-4, 1e-8, 1e-12)]
X = rk4(F, np.array([0.1, 1.0]), T=40)
print(f'  排除对照 α=3, β=1/2：轨道末态 {X[-1][0]:.3g}, {X[-1][1]:.7f}（趋边界 (0,1)）；差商 ' + ', '.join(f'{x:.4g}' for x in r) + '（发散，无 Lipschitz 延拓）')
# 脉冲见证（同一固定供给 I0 = 1）：检验字母 w 为入口状态脉冲 P_w(x) = x + η，静置为恒等；一拍 = 脉冲后接时长 Δ 的同一静置流
def coarse_F(g):  # T6 (c) 粗系统：状态 (g1, G)，写入律 (I q1)^α 与 2^{1-α}(I q2)^α
    k = np.maximum(g, 0); q = k / k.sum()
    return np.array([q[0] ** 1.5, 2 ** -0.5 * q[1] ** 1.5]) - g
eta = np.array([0.1, 0.1]); a0 = np.array([0.4, 0.7]); Dt = 0.01
for name, F in [(n, f) for n, f, _ in cases] + [('T6 (c) 粗系统', coarse_F)]:
    gap = np.abs(rk4(F, a0 + eta, T=Dt + 5.0)[-1] - rk4(F, a0, T=Dt + 5.0)[-1]).max()
~~~
