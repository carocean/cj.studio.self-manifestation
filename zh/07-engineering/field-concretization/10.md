自显论·工篇·场具化组式第十 v1.0

# 场具化稳定式

一、式种申报  
本篇是稳定式（第五组保持稳定附式）。唯一任务：已经成立的沉积场资格，在事前冻结的许可变化域与合法后继轨迹中，以什么身份、在什么量词层级上保持、实际失效与复归。  
本篇的结论分五组。  
　1．即时读数：在字母门控 F 模型中，存在层的资格读数由唯一的最大承担集决定（定理一），失效责任可在这一集合上逐分量读出（推论一）。  
　2．替代：资格在每一时刻成立，不推出同一迹应集合全程承担（命题一）；承担历史动力的过程被替换，不推出资格失效（命题二）。  
　3．观察窗与保证：窗长加长时资格读数不降（定理二）；判定一切合法后继上的保持，必须保存窗起点的状态与记录（命题三、定理三），在有限情形可三值判定（定理四）。  
　4．恢复：复归的两类阻断——信号必经（定理五）与静止点阻断（定理六）；判定式实例甲在持续训练下退出且不可复归（推论三）。  
　5．边界与量词：回放比较下的有限分段（定理七）及其不能外推到无限时域（命题六）；固定层与轨迹量词的判定与分离（推论四、命题七、命题八）。  
强度定位：稳定式所证是已立资格在变化中的保持，不是对象的首次存在、首次可达或首次发生。本篇的结论都在形式模型内，不认证任何物质宿载的稳定。  
理论增量：上游各篇分别证明了沉积场资格的成立、判定、可达与实现，资格在时窗推移与合法后继下能否保持、退出后能否复归，没有一篇承担。本篇的增量落在资格的具体信息结构上：  
　存在层化归于单个最大承担集；  
　复归须按失效责任分为两类阻断；  
　滑动窗资格的监控必须保存窗起点，不能只看末态。  
各定理的证明是初等的（单调性、归纳、多项式根的有限性、图搜索）。三值代数、安全性乘积构造与根的有限性都是已有方法，不作方法新颖性主张。

### 2.2　进入条件

法篇第四编第十五章的进入条件在本篇的落实：  
　（一）被稳定的资格 Q 已有闭合定义：Fld\_RD 与各 Q\_F(h, T)（F6）。  
　（二）Q 在入口上已成立：稳定实例的入口史 h₀ 满足 Fld\_RD(h₀) = 1。χ₀ 与实例甲的入口取可达式已证的到达点；另申报的实例在文中直接求值入口。  
　（三）稳定对象的身份层已经声明（定义三）。  
　（四）许可变化域已预先声明，变化后的重算规则已经成立（定义一、二）。  
　（五）合法后继动力、时间域与观察协议由 𝔐\_GF 的拍式递推（数理式 4.2）与定义一、四给出。  
　（六）声明全部合法未来上的保证稳定时，评价域在定义一、二、七中界定。

### 2.3　范围之外

　（一）资格的成立、判定、可达与实现，分别由一般式、判定式、可达式、实现式承担；  
　（二）运行中途改变参数或状态的在线变化（超出 𝔐\_GF 的字母门控形式）不在许可变化域内（U2）；  
　（三）固定层的恢复、含恢复的稳定判定算法、随机族与连续时间模型，未有结论（U1、U3、U4）；  
　（四）以下结论不认证任何物质宿载的保持、退出或复归（U5）。

三、稳定对象与原资格  
定义一（稳定实例与许可变化域）。稳定实例 Σ = (M, w, h₀, 𝓛)：  
　M ∈ 𝔐\_GF（固定位集 I、分辨率 ε、字母表与初态 s₀）；  
　w ≥ 1 为窗长；  
　h₀ 为入口史，\|h₀\| ≥ w，Fld\_RD(h₀) = 1；  
　𝓛 为合法后继，两种制度：  
　　字母制度：字母集 U′（可以为空集，此时只有空延伸，即入口本身），U′ 上的每个有限词都是评价点；  
　　正则制度：自动机 (Q, q₀, δ, F)，δ 为部分转移函数，F ⊆ Q 为接受态。  
　　　q₀ 是读入空延伸词时的状态，不读入 h₀。  
　　　延伸词 v 可执行，指 δ 沿 v 处处有定义，且每一前缀都不越出定义域。  
　　　v 是评价点，当且仅当 v 可执行且 δ(q₀, v) ∈ F。非接受前缀照常推进物理状态，但不作评价点。  
　　前缀封闭制度是 F = Q 的特例：每个可执行前缀都是评价点。接受语义与前缀封闭语义不同，不得混称。  
许可变化域就是按 𝓛 的延伸，模型、ε 与 w 都不变。改变其中任一项即另一实例，不称原实例保持或恢复。  
定义二（评价点、重算与实际失效）。评价点是 h = h₀·v，v 按定义一属被评价的延伸词。  
　重算规则：每一评价点按 RD 对实际史 h 重算全部 T 与三值读数 Fld(h) := Fld\_RD(h)，不沿用此前的读数。  
　入口保留 h₀ 的全部 Form、Mark 记录与末窗，不重置为空记录。  
　实际失效：评价点上 Fld(h) = 0。  
　⊥ 不是实际失效。越出定义域的延伸不可执行，不是评价点，也不再延伸。  
定义三（身份层）。  
　固定层：事前指定非空 T₀ ⊆ I，读数 a(h) = Q\_F(h, T₀)。固定层的稳定任务另要求入口上 Q\_F(h₀, T₀) = 1。不合格的 T₀ 仍可作即时读数分类（引理一），但不称已立资格的保持。Fld(h₀) = 1 只保证某个 T 合格，不保证所指定的 T₀ 合格。  
　存在层：读数 b(h) = Fld(h)。  
　内部见证层：承担 HDyn 的过程事件。𝔐\_GF 只保证同一字母内过程标号互异，跨字母的过程标识须另行申报。  
　Ident、HistEv 在 𝔐\_GF 中申报为 1，坐标集合 T 的形式保持不证明物质迹应的连续同一。  
定义四（稳定协议、失效时集与恢复）。  
　稳定协议 𝒫 在观察之前冻结，与稳定实例一并申报：  
　　所判身份层；  
　　评价域与入口；  
　　恢复期限 D 与持续验证长度 L（可为「不申报」）；  
　　计时规则：以评价点序号计；期限自首次实际失效起算，其后再次失效不重置；持续验证自复归点起连续计数，含复归点。  
　每份恢复结论引用同一份 𝒫。对不同的 (D, L) 作参数化查询是允许的，但查询结果不是预申报协议下的结论。  
　存在层：沿一条合法轨迹 ν（延伸序列），失效时集 F(ν) = {t : Fld\_t = 0}。  
　　首次实际失效 τ\_f = min F(ν)（F(ν) 非空时）；  
　　复归点 τ\_r \> τ\_f，Fld\_{τ\_r} = 1；  
　　恢复成立，当且仅当 τ\_r − τ\_f ≤ D，且自 τ\_r 起连续 L 个评价点 Fld = 1；𝒫 未申报的项（D 或 L）不作要求，此时的结论只说明已申报的那几项。  
　　只有 Fld 再次为 1 而无先行实际失效，不构成恢复。  
　固定层：以 Q\_F(·, T₀) 代替 Fld，逐字照上定义 F、τ\_f、τ\_r，不以存在层的时刻代替。失效与恢复的结论只签存在层。

四、即时读数：最大承担集与失效分解  
定义五（最大承担集）。评价点 h 上，R(h) = {i ∈ I : 窗末 s\_i \> ε，且 i ∈ Form(h)}，Form(h) 为全史形成记录。  
定理一（最大承担集）。对 𝔐\_GF 的任一评价点 h：  
　(a)　R(h) = ∅ 时 Fld(h) = 0；R(h) ≠ ∅ 时 Fld(h) = Q\_F(h, R(h))。  
　(b)　对 T ⊆ T′ ⊆ R(h)，Q\_F(h, T) ≤ Q\_F(h, T′)（真值序）；T ⊄ R(h) 时 Q\_F(h, T) = 0。  
证明。  
　Ret\_T = 1 当且仅当 T ⊆ R(h)。  
　Src\_T = \[T ∩ Mark ≠ ∅\]，随 T 增大而不减。  
　Part\_T 是对窗内 B 内事件的强 Kleene 析取，各项 \[ac ∩ T ≠ ∅\] ∧ cert\_read 随 T 不减（ac 为该事件可用的条件支持位）。  
　HDyn\_T 是对窗内事件的析取，各项 \[tgt ∈ T\] ∧ act ∧ (\[aa ∩ T ≠ ∅\] ∧ cert\_read ∧ cert\_path) 随 T 不减（aa 为可用的作用支持位）。  
　强 Kleene 的合取与析取在真值序下单调，故 (b) 成立。  
　Fld 是对一切非空 T 的析取：T ⊄ R(h) 者为 0，T ⊆ R(h) 者不超过 Q\_F(h, R(h))。故 (a) 成立。∎  
核验（附录 B.1 (1)）：随机合法模型 8798 个评价点（含 ⊥ 认证），Fld 都等于 Q\_F(h, R(h))。  
推论一（失效分解）。Fld(h) = 0 当且仅当以下四者之一成立：  
　R(h) = ∅（留存坍缩）；  
　Src(R(h)) = 0；  
　Part(R(h)) = 0；  
　HDyn(R(h)) = 0。  
Fld(h) = ⊥ 当且仅当 R(h) ≠ ∅，且这四个分量无 0 而有 ⊥。  
故存在层的失效责任只须在唯一的集合 R(h) 上读出。下文的失效点分别属于不同责任：  
　χ₀ 变体的首次失效（第七节实例）：R = {x}，Part = 1，HDyn = 0；  
　命题四的失效点：R = {x}，Part = HDyn = 0；  
　定理五后例的失效点：R = ∅。  
引理一（两层读数配对）。a(h) ≤ b(h)。故 (a, b) 只能是以下六种：  
　(1, 1)：两层均保持；  
　(0, 1)：固定层确定退出，存在层由替代保持；  
　(0, 0)：存在层确定坍缩；  
　(⊥, 1)：存在层确定保持，固定层未知；  
　(0, ⊥)：固定层确定退出，存在层未知；  
　(⊥, ⊥)：两层未知。  
固定层保持蕴涵存在层保持，逆不成立（命题一）。  
证明。Fld 是含 Q\_F(h, T₀) 的强 Kleene 析取。∎  
分类保存二元读数，不把 (⊥, 1) 读作存在层不成立。核验（附录 B.1 (2)）：随机模型中六种配对都出现，未见其他配对。

五、替代关系：对象替代与内部见证替代  
推论二（固定层的最大候选）。沿一组评价点 E，∃T ∀h ∈ E \[Q\_F(h, T) = 1\] 成立，当且仅当  
　R\_E := ⋂\_{h∈E} R(h) ≠ ∅，且 ∀h ∈ E \[Q\_F(h, R\_E) = 1\]。  
证明。由定理一 (b)，任一合格 T 须含于每个 R(h)，故 T ⊆ R\_E，且 Q\_F(h, T) ≤ Q\_F(h, R\_E)。∎  
I 有限，交集在有限步内稳定，故对无限轨迹同样适用。  
命题一（对象替代：每一时刻有承担者，而无全程承担者）。  
　模型：I = {x, y}，ε = 0，w = 2。  
　　X：界外脉冲 x +1；B 内过程 ky，读 y，作用于 y，分项 −y。  
　　Y：界外脉冲 y +1；B 内过程 kx，读 x，作用于 x，分项 −x。  
　入口 X·Y·X，后继 (Y·X)^∞。  
　结论：每个评价点 Fld = 1；R 在 {x} 与 {y} 之间交替，交集为空；三个非空 T 都在某一评价点不合格。故 ∀t∃T 成立，∃T∀t 不成立。  
证明。自入口起，状态在 (1, 0) 与 (0, 1) 之间交替，记录与状态周期为 2。  
　以 X 结束的评价点，窗 \[Y, X\] 中，kx 读拍前 x = 1，x 已形成，分项 −1 有效，作用于 x；故 Q({x}) 的 Src、Ret、Part、HDyn 均为 1。  
　以 Y 结束者对称。  
　R 交替，由推论二，没有固定 T。∎  
核验（附录 B.1 (3)）：41 个评价点。  
命题二（内部见证替代）。  
　模型：I = {x}，ε = 0，w = 1。  
　　seed：界外脉冲 +1；  
　　A：B 内过程 p，读 x，作用于 x，分项 x/2；  
　　B：B 内过程 q，读 x，作用于 x，分项 −x/4。  
　入口 seed·A，后继 (B·A)^∞。  
　结论：T = {x} 全程合格，承担 HDyn 的过程在 p、q 之间交替。原见证 p 在 q 拍的窗内不出现，而资格不失。  
证明。x 恒正；每拍的唯一过程读 x、作用于 x，分项非零。∎  
原见证退出不等于失稳：须检查同层的替代见证。

六、动态轨迹、观察窗与可判域  
定理二（窗长单调）。对固定史 h 与 1 ≤ w \< \|h\|，Fld(h, w) ≤ Fld(h, w + 1)（真值序）。故窗长的正判区可以为空；若存在正判窗长，正判区是 {1, …, \|h\|} 内的上尾。  
证明。  
　Src、Ret 只依全史的 Mark、Form 与窗末状态，与 w 无关。  
　窗内拍 j 的事件项只依赖两样东西：拍前状态；拍前的形成记录。后者是入口拍记录与窗内此前形成之并，恰为 j 之前的全部形成，与窗起点无关。  
　故 w 与 w + 1 共有的事件项相同，较长的窗只多出若干析取项。强 Kleene 析取单调。∎  
见证（附录 B.3 (4)）：实例甲 χ\_in，史 (init, aⁿ)，正判窗长为 w ≥ n − 11（n = 13、20、40）——窗须覆盖最后一个 opt 有效的拍。  
定义六（窗起点监控结点）。评价点 h 的结点 ν(h) = (Z(h), buf(h))：  
　Z(h) = (s, Form, Mark) 是 h 的前 \|h\| − w 拍运行所得的窗起点状态与记录；  
　buf(h) 为末 w 个字母。  
推进一拍 u：以 buf 的首字母更新 Z（记录按数理式 D16 累积），删去首字母，附加 u。  
命题三（末态监控不充分）。  
　模型：I = {x}，ε = 0，w = 1。  
　　small：界外脉冲 +1/2；  
　　large：界外脉冲 +1；  
　　c：B 内过程，读 x，作用于 x，分项 1 − x。  
　史 small·c 与 large·c 的末态 x = 1、累计 Form 与 Mark、末窗字母全同，而 Fld 分别为 1 与 0。  
　二者的窗起点状态不同（1/2 与 1）：前者 c 的分项为 1/2，有效；后者为 0，无效，HDyn = 0。  
故「末态 + 累计记录 + 末窗字母」不能决定资格。  
定理三（窗起点监控）。  
　(a)　Fld(h) 只依 ν(h)：它等于以 Z(h) 为窗起点、以 buf(h) 为窗内词的窗读数（可达式定义四与引理一）。  
　(b)　ν(h·u) 由 ν(h) 与 u 决定（定义六的推进）。  
　(c)　故 h 的一切延伸上的读数只依 ν(h)。  
　(d)　计数：设 N 为入口窗起点状态在全部字母下（含入口末窗中的字母）的物理可达状态数，d = \|I\|，A 为合法后继字母与入口末窗字母之并的字母数。则可执行的监控结点数 K ≤ N·4^d·A^w。正则制度再乘自动机状态数 \|Q\|。越出定义域的转移截停，不计入 K。  
证明。  
　(a)　RD 的定义。  
　(b)　Z(h·u) 是前 \|h\| + 1 − w 拍的运行结果，即 Z(h) 再走 buf(h) 的首字母，记录按 D16 累积；buf 的更新显然。  
　(c)　对延伸长度归纳。  
　(d)　Form、Mark ⊆ I，各至多 2^d 种。∎  
命题三表明，(Z\_t, buf) 不能代替 (Z\_{t−w}, buf)。  
核验（附录 B.4 (2)）：随机有限模型 387 例（含 ⊥ 认证）中：  
　深度 ≤ 5 的监控标签集与逐史求值的枚举逐例相同；  
　首个 0 与首个 ⊥ 标签的最短词长相同；  
　K 都不超过 N·4^d·A^w。  
定义七（保持层级与三值保证读数）。  
　单轨迹保持：一条轨迹的一切评价点 Fld = 1。  
　声明轨迹族保持：族内一切轨迹保持。  
　保证保持：𝓛 的一切评价点 Fld = 1。  
　三值保证读数 G(Σ)：存在评价点读 0，则 G = 0；无 0 而有 ⊥，则 G = ⊥；全部为 1，则 G = 1。  
　G = ⊥ 不认证保持，也不证明实际失效；未知轨迹留在量词域内，不删去。  
　评价域：定义一、二所申报的全部评价点。在前缀封闭制度下，无限合法轨迹的评价点集是其各有限前缀之并；可执行图无死端时，两种评价域给出同一 G。有死端时，死端前缀上的评价点照样计入，死端本身不读作失效。  
　空评价域：正则制度可以没有任何可执行的接受结点（例如 F = ∅）。此时 G = 1 只是空域上的逻辑真，单列为空评价域，不作经评价的保持记录。  
定理四（三值保证读数的判定）。可执行乘积图（监控结点 × 自动机状态）有限时，G(Σ) 由广度优先遍历全部可达乘积结点求得，标签只在被评价的结点上读取（字母制度为全部结点；正则制度为状态属 F 的结点）：  
　有被评价的 0 标签，则 G = 0；  
　否则有被评价的 ⊥ 标签，则 G = ⊥；  
　否则 G = 1；被评价结点数为 0 时，单列为空评价域。  
越出定义域的转移截停。首个被评价的 0（或 ⊥）标签，其最短延伸词长不超过 K − 1。  
证明。由定理三 (c)，评价点的标签集等于被评价的可达乘积结点的标签集；非接受结点照常展开，只不读标签。广度优先给出最短路径，最短路径无回路。∎  
见证（附录 B.4 (3)(6)(7)）：  
　命题一的模型在交替的前缀封闭制度下 G = 1（3 个结点）；在全字母表下 G = 0，最短反例为 rest。  
　一个过程的读取认证为 ⊥ 的翻转模型：G = ⊥。  
　接受语义与前缀封闭语义：  
　　入口 seed·b（seed 为界外脉冲 +1；b 为 B 内翻转过程，读 x，作用于 x，分项 3/2 − 2x；a 无事件），延伸语言 (ab)\*。  
　　按接受语义只评价 (ab)ⁿ：x 在 1/2 与 1 之间交替，末拍 b 的分项绝对值恒为 1/2，G = 1。  
　　按其前缀闭包评价：非接受前缀 a 上 Fld = 0，G = 0。  
　其他边界：  
　　接受终点为 ⊥ 时 G = ⊥；  
　　含越出定义域分支时截停，G = 1；  
　　只接受 ab 时空延伸不作评价点；  
　　显式空字母集只有空延伸，G = 1；  
　　F = ∅ 时为空评价域。  
范围：本定理判的是全程保持。含恢复的稳定（保持或恢复）的判定须另定义恢复计时与验证长度的监控，尚无此结果（U1）；评价点上曾出现 0，不否定恢复。

七、恢复  
命题四（无新信号的复归）。  
　模型：I = {x}，ε = 1，w = 1。  
　　seed：界外脉冲 +4；  
　　a：B 内过程 p，读 x，作用于 x，分项 x/2；  
　　rest：无事件。  
　史 seed·a、seed·a·rest、seed·a·rest·a 的 Fld 依次为 1、0、1（x = 6、6、9）。  
　失效点上 R = {x}，Src = Ret = 1，Part = HDyn = 0：窗内没有过程，旧迹应仍在。  
　失效后没有任何界外改变，旧 Mark 保留，资格却复归。阈下（x ≤ 1）不存在有效正分项，也不能阻止这种复归。  
定理五（信号必经）。设 τ 为轨迹上一个实际失效点，Mark\_τ 为其全史标记集，并满足：  
　(i)　τ 处每个 i ∈ Mark\_τ，其窗末 s\_i ≤ ε；  
　(ii)　在一切无信号后继中，每个 i ∈ Mark\_τ 的状态保持 ≤ ε。  
无信号后继指各拍都不含有效界外改变的合法后继：没有幅度大于 ε 的界外脉冲，也没有有效的界外载体过程分项。这是按拍判定的；不以 Mark 集合是否增大判定——对已标记位再施界外脉冲，Mark 不增大，仍是信号。  
则在一切无信号后继的评价点上 Fld = 0。故复归必经新的有效界外改变。这一条件是复归的必要条件，不是充分条件。  
证明。Mark 只由有效界外脉冲与有效界外载体分项登记（数理式 D16），故无信号后继中 Mark 恒为 Mark\_τ。对任一非空 T：  
　若 T ∩ Mark\_τ = ∅，则 Src = 0；  
　否则取 i ∈ T ∩ Mark\_τ，由 (ii) 得 s\_i ≤ ε，故 Ret = 0。  
两种情形 Q\_F = 0，故 Fld = 0。∎  
可检查的充分条件：每个可施的非信号字母，对 Mark\_τ 中处于阈下的位，其有效脉冲与有效分项之和不使其越过 ε。  
例（附录 B.2 (4)）：  
　模型：I = {x}，ε = 1/10，w = 1。  
　　sig：界外脉冲 +1；  
　　g：B 内过程，读 x，作用于 x，分项 x；  
　　d：B 内过程，读 x，作用于 x，分项 −x；  
　　inp：场内脉冲 +1。  
　入口 sig·g；施 d 后 x = 0，首次实际失效（R = ∅）。  
　非信号字母 rest、d、g 都保持 x ≤ ε。长度 ≤ 6 的全部非信号后继共 1093 条，Fld 全为 0。  
　经 sig·g 复归：sig 打在已标记位上，Mark 不增大，仍是信号。  
　前件 (ii) 不能去掉：允许 inp 时，inp·g 使 Fld = 1，而 Mark 仍只是旧的 {x}，这是无新界外改变的复归。  
定理六（静止点阻断）。设轨迹在 σ 时处于状态 s\*，且对 σ 之后合法的每个字母 u，u 的每个脉冲幅度 ≤ ε，u 的每个过程在 s\* 上 \|c\| ≤ ε。则：  
　(a)　此后状态恒为 s\*；  
　(b)　窗完全落在 σ 之后的一切评价点上 Fld = 0。  
证明。  
　(a)　没有有效分项，对拍数归纳。  
　(b)　窗内事件的 act 全为 0，HDyn 的每一项含因子 0，故 HDyn = 0。于是 Q\_F = 0 对一切 T 成立，不论认证是否为 ⊥。∎  
推论三（实例甲在持续训练下的退出与不可复归）。

　结论：第 13 个 a 拍首次实际失效；此后在 a、rest 的一切后继上 Fld = 0，永不复归。  
证明。

核验（附录 B.2 (2)）：失效后长度 ≤ 8 的全部合法后继 511 条，Fld 全为 0。  
资格退出的责任是学习收敛——优化器的作用降到分辨率以下，HDyn = 0；迹应并未消失，Ret 仍成立。  
命题五（χ₀ 在不触顶后继上的处处保持）。

八、稳定边界  
定义八（回放比较的参数区）。对申报的单参数族 {M\_θ}、固定史 h 与窗长 w，每个 θ 自原始 s₀ 独立运行。  
　正判区为 {θ : Fld = 1}，零判区为 {θ : Fld = 0}，未定区为 {θ : Fld = ⊥}。  
　这是参数族之间的比较，不描述运行中途的变化，不称保持、失效或复归；参数区的边界不是动态的实际失效事件。  
定理七（单参数多项式族的有限分段）。  
　设：固定有限史 h 与窗长 w，参数 θ 只取有理值，θ ∈ J ∩ ℚ（J 为区间）。以下离散数据在 θ 上固定：  
　　位集 I、字母表、各字母的脉冲表与过程表；  
　　律类型、读取位、作用对象、载体、脉冲的界外或场内标志；  
　　全部认证原子（cert\_read、cert\_path）。  
　只有初态、脉冲幅度、过程系数与偏置、ε 随 θ 变化，且都是 θ 的有理系数多项式。  
　记实代数合法域 J\_alg = {θ ∈ J : 非负性等合法前件成立，且 h 全程不越出定义域}，原模型的合法参数域 J\* = J\_alg ∩ ℚ。不合法或越域的参数点不作读数，也不并入 ⊥。  
　结论：实轴 J 可分为有限个点与开区间（胞）；每个胞与 J\* 之交若非空，其上 Fld(θ) 与一切 Q\_F(θ, T) 为常值。  
证明。逐拍归纳。在比较结果确定的每一分支上，状态分量与分项都是 θ 的多项式。每次比较是某多项式的符号判定：  
　x − ε、c − ε、−c − ε、s − ε、ε − s（有效、可用、形成）；  
　双线性伙伴读数的精确非零；  
　后态的非负性。  
　分支有限，各分支涉及的多项式也有限。离散数据与认证原子固定，故三值组合只随这些比较的结果变化。  
　取其中不恒为零者在 J 内的全部根，连同 J\_alg 的符号条件所涉多项式的根，得有限个胞。同一胞内每个多项式的符号不变，故胞中的合法有理参数走同一分支，读数相同。根处若为有理数，直接重算。  
　J\_alg 是有限个点与区间之并；J\* = J\_alg ∩ ℚ 一般不是，故结论按胞与 J\* 之交陈述。∎  
推广：数值数据为有理函数，且分母在 J 上不为零时，各分支上的状态与分项仍是有理函数；比较 f/g \> 0 等价于 f·g \> 0（乘以非零分母的平方保号），再取有限根集。  
前件不能放宽：  
　离散数据不固定时：数值全为常数，而 cert\_read(θ) 在可数个区间上取 1、其余取 0，则 Fld 恰等于 cert\_read(θ)，正判区有无限多段；  
　参数依赖不受多项式限制时：系数 k(θ) 在可数个区间上取 1、其余取 0，同样有无限多段。  
端点：断点上的读数须直接重算，不能只凭各原子是严格不等式来判断。  
参数区的见证（ε = θ 的族，是定理七的一次特例；附录 B.3 (1)(3)）。  
　方法：以记录比较对象的阈值代替 ε 运行原求值器，得所经的全部比较值，逐个求断点，并在断点上重算。  
　χ₀，史 (u1, restⁿ)，w = 1，θ ∈ \[0, 1\]：  
　　n = 5：正判区 \[0, 1029/25000)，零判区 \[1029/25000, 1\]；  
　　n = 12、30：同形，断点依次为 2107392/244140625、约 1.55e−4。  
　　正判区的上确界不属正判区；零判区的下确界取得。原因是各原子为严格不等式，θ = θ\_n 处分项恰不大于阈值。  
　正判区不必是区间：  
　　模型：I = {x, y}，ε = θ，零初态，w = 1；字母 a 含界外脉冲 x +1、y +1，以及两个 B 内过程——p0 读 y、作用于 y、系数 −1/4，p1 读 x、作用于 y、系数 −1/2。  
　　史 a·a·a·a 上，θ ∈ \[0, 2\] 的读数依次为：\[0, 13/64) → 1；\[13/64, 15/64) → 0；\[15/64, 1) → 1；\[1, 2\] → 0。  
命题六（有限时域的正裕度不保证无限时域的正裕度）。χ₀ 取 ε = θ，沿 (u1, rest, rest, …)。一切评价点 Fld = 1，当且仅当 θ = 0。  
证明。  
　θ = 0：由命题五。  
　θ \> 0：静置下 δ 不增。wb 有效蕴含 dec 有效（3δ/10 \> δ/10），故只要有过程有效，δ 至少每拍乘 4/5。有限步后 (3/10)δ ≤ θ，两过程都无效，进入静止点，由定理六此后 Fld = 0。∎  
每个有限 n 上，正判区是 \[0, θ\_n)，θ\_n 递减趋于 0（对任一 θ \> 0，n 充分大时 θ ∉ \[0, θ\_n)）；无限时域的正判区只有 {0}。  
范围：{0} 本身仍是有限分段，故本例不说明无限时域不具有限分段。它说明的是：各有限时域都有正裕度 θ\_n \> 0，不推出无限时域有统一的正裕度。定理七只签有限史。

九、层级量词检查  
时间量词与轨迹量词须同时核对。以下三个命题依次蕴涵，逆向都不成立：  
　同一 T 对全部轨迹全程合格（∃T ∀ν ∀t）；  
　每条轨迹各有一个全程合格的固定 T（∀ν ∃T ∀t）；  
　每条轨迹每一时刻有某 T 合格（∀ν ∀t ∃T）。  
命题七说明第二条不推出第一条，命题一说明第三条不推出第二条。  
推论四（固定层的全轨迹量词）。可执行乘积图有限时，「存在一个 T，在入口上合格，且在全部被评价的可达乘积结点上合格」可以判定：  
　取候选 T\_E = R(h₀) ∩ ⋂{R(ν) : ν 为被评价的可达乘积结点}；  
　读数为 T\_E 在入口与全部被评价结点上 Q\_F 的强 Kleene 合取（T\_E = ∅ 时为 0）。  
　读数为 1，当且仅当这样的 T 存在；读数为 0 时，一切 T 都在某一结点读 0；读数为 ⊥ 时，不认证也不否定。  
证明。由推论二与定理一 (b)，任一合格 T ⊆ T\_E，且在每一结点上 Q\_F(T) ≤ Q\_F(T\_E)。∎  
两点要求：  
　求交与检查只取被评价的结点；非接受结点照常展开，不筛除路径。  
　入口无论 q₀ 是否接受，都计入候选条件。所判的是原入口已合格的承担者是否保持，不能用一个入口不合格、后来才合格的 T 冒充原承担者。若只签评价域 E 上的数学存在命题，须另标，它不是固定层的稳定任务。  
见证（附录 B.4 (4)(7)）：  
　入口 seed·A、合法字母 A、B 的模型（seed 为界外脉冲 x +1、y +1；A 翻转 x 并撤除 y，B 翻转 x）：5 个结点，T\_E = {x}，读数 1。  
　(ab)\* 接受语义下 T\_E = {x}，读数 1；其前缀闭包下读数 0。  
　只接受 ab 时读数 1；接受终点为 ⊥ 时读数 ⊥。  
　非接受中间点的 R 更小：入口 seed·B、延伸 (a·B)\*，中间点 R = {x}。接受语义下 T\_E = {x, y}，读数 1；前缀闭包下候选缩为 {x}。  
命题七（轨迹量词分离：每条轨迹各有固定承担者，而无共同承担者）。  
　模型：I = {x, y}，ε = 0，w = 1。  
　　seed：界外脉冲 x +1、y +1；  
　　C：两个 B 内翻转过程，各读本位、作用于本位，分项 3/2 − 2·本位值；  
　　A：翻转 x，撤除 y（分项 −y）；  
　　B：翻转 y，撤除 x。  
　入口 seed·C；合法史为前缀封闭制度：首拍择定 A 或 B，此后不变。  
　结论：A 轨迹上 T = {x} 全程合格，B 轨迹上 T = {y} 全程合格；而全部可达评价结点连同入口的最大承担集之交为空，故没有 T 对全部轨迹全程合格。  
证明。翻转使所翻之位在 {1/2, 1} 之间往返，分项的绝对值为 1/2 \> 0。结论由推论二对两条轨迹分别取交，再对全部被评价结点连同入口取交得出。∎  
核验（附录 B.4 (5)）：7 个可达评价结点。  
命题八（∀ν∃T∀t 的判定）。  
　设：前缀封闭制度；可执行监控图有限，其中每个可达结点都有可执行后继（无死端）；轨迹指自入口起的无限可执行路径。  
　在结点上附加已违反集合 V ⊆ 𝒫⁺(I)：初始 V₀ = {T : Q\_F(h₀, T) ≠ 1}（入口本身是评价点，Fld(h₀) = 1 不保证每个 T 在入口合格）；沿边并入新评价点上 Q\_F ≠ 1 的 T。  
　则「存在轨迹使每个 T 都被违反」，当且仅当可以到达某个 V = 𝒫⁺(I) 的乘积结点。  
证明。  
　（⇐）有限路径到达 V = 𝒫⁺(I) 的结点。由无死端，把这一有限前缀延伸为无限轨迹；V 只增不减，故该轨迹上每个 T 都在某一评价点不合格。  
　（⇒）某无限轨迹上没有固定 T 全程合格，即每个 T 都有首次违反的评价点。T 只有有限个，取这些首次违反时刻的最大值，则该有限前缀末端的乘积结点已有 V = 𝒫⁺(I)。∎  
乘积结点数至多为 K·2^(2^d − 1)，K 为可执行监控图的结点数。入口违反不能漏记：可构造这样的模型——入口上只有 {x} 合格、{x, y} 不合格，此后 {x, y} 永远合格、{x} 随后退出。含入口时全部候选被违反，忽略入口则误留 {x, y}。

十、替代与观测、数制（接口）  
　替代与观测：存在层保持而固定层退出时，替代是否可观测，依具体替代对与观测集分别而定。命题一的两位交替在状态轨迹上可见；载体与来源标记的替代，按不可区分式定理六，在其所定义的观测集内不可见。不由定理六推出一切替代都不可见。  
　数制：长时程下须分开三件事——精确模型的资格退出、binary64 宿载的退出、认证算法变为 ⊥。实现式命题二给出 binary64 宿载先于精确模型退出的见证。实现式的保持定理是有限执行上的条件性结论，不量化到无限未来；长时程稳定性的数制申报须写明舍入与次正规策略。

十二、最终表达  
在稳定实例 Σ 与稳定协议 𝒫 事前冻结的条件下：

~~~python
"""场具化稳定式：滑动窗资格的轨迹求值、最大承担集、窗起点监控与三值保证判定（精确有理运算）。

稳定实例：模型 M、窗长 w、入口史 h0（|h0| ≥ w，Fld_RD(h0) = 1）、合法后继（字母集或确定有限自动机）。
评价点：入口史的各合法延伸 h0·v（v 为有限合法词），读数 Fld_RD(h0·v)，W 为末 w 拍。
越出定义域的延伸不是评价点，单列登记，不读作失效。"""
from fractions import Fraction as Fr
from collections import deque
from itertools import combinations
import reach_core as rc
ORDER = {0: 0, None: 1, 1: 2}          # 真值序 0 < ⊥ < 1

def window_record(M, h, w):
    """返回 (窗起点 Z = (s, Form, Mark), 窗末态, 全史 Form, 全史 Mark)；越出定义域返回 None。"""
    pre = rc.run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    z = (s, F, Mk)
    F2, M2 = set(F), set(Mk)
    for u in h[len(h) - w:]:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F2 |= fo
        M2 |= ma
    return z, s, frozenset(F2), frozenset(M2)

def canon(M, h, w):
    """最大承担集 R = {i : 窗末 s_i > ε 且 i ∈ Form}（定理一）。"""
    rec = window_record(M, h, w)
    if rec is None:
        return None
    _, s, F, _ = rec
    return frozenset(i for i, v in zip(M.I, s) if v > M.eps and i in F)

def evaluate(M, h, w):
    """评价点的完整读数：Fld、各 T 的 Q、最大承担集 R。越出定义域返回 None。"""
    e = rc.fld_of_history(M, h, w)
    if e is None:
        return None
    return {'Fld': e['Fld'], 'Q': e['Q'], 'R': canon(M, h, w), 'end': e['end']}

def components(M, h, w, T):
    """单个 T 的四个分量（Src、Ret、Part、HDyn），供失效分解；与 reach_core.window_eval 逐项相同。"""
    rec = window_record(M, h, w)
    (s0, F0, M0), _, _, _ = rec
    eps = M.eps
    s, Form, Mark, ev = s0, set(F0), set(M0), []
    for u in h[len(h) - w:]:
        s2, fo, ma, events = M.step(s, u)
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev.append((ac, aa, p, act))
        Form |= fo
        Mark |= ma
        s = s2
    end = dict(zip(M.I, s))
    T = set(T)
    src = 1 if T & Mark else 0
    ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
    part = rc.k_or(*[rc.k_and(1 if (ac & T) else 0, p.cert_read) for (ac, aa, p, act) in ev if p.car == 'B']) if ev else 0
    hd = [rc.k_and(1 if p.tgt in T else 0, act, rc.k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0))
          for (ac, aa, p, act) in ev]
    hdyn = rc.k_or(*hd) if hd else 0
    return {'Src': src, 'Ret': ret, 'Part': part, 'HDyn': hdyn}

# ---------- 窗起点监控（定义六、定理三）
def monitor_init(M, h0, w):
    """自入口史初始化：结点 = (窗起点 Z, 末 w 个字母)。入口保留 h0 的全部记录，不重置为空记录。"""
    rec = window_record(M, h0, w)
    if rec is None:
        raise ValueError('入口史越出定义域')
    (s, F, Mk), _, _, _ = rec
    return (s, frozenset(F), frozenset(Mk), tuple(h0[len(h0) - w:]))

def monitor_step(M, node, u):
    """推进一拍：以窗首字母更新窗起点 Z，删去窗首、附加新字母。"""
    s, F, Mk, buf = node
    r = M.step(s, buf[0])
    s2, fo, ma, _ = r
    return (s2, F | frozenset(fo), Mk | frozenset(ma), buf[1:] + (u,))

def monitor_label(M, node):
    """结点标签：Fld ∈ {1, 0, ⊥}；窗内越出定义域返回 'dead'（不是评价点）。"""
    s, F, Mk, buf = node
    e = rc.window_eval(M, s, F, Mk, buf)
    return 'dead' if e is None else e['Fld']

def guarantee(M, h0, w, letters=None, dfa=None, cap=200000, stop_on_zero=False):
    """全部被申报评价点上的三值保证读数（定理四）。
    letters：合法字母集（缺省为全部字母）。
    dfa：(q0, δ, F) 申报延伸词 v 的正则制度——q0 是读入空延伸词时的自动机状态（不读 h0），δ(q, u) 返回后继状态或 None
         （不可行），F 为接受态集合；缺省 F 时取全部状态（前缀封闭制度：每个可行前缀都是评价点）。
         评价点恰为 h0·v，v 被接受；非接受前缀照常推进物理状态与监控结点，但不作评价点。
    stop_on_zero：首次见被评价的 0 标签即停（读数 0 已确定；广度优先，所给反例词最短；此时 K 只是已展开的结点数）。
    返回 dict：verdict（1：全部评价点为 1；0：存在评价点为 0；⊥：无 0 而有 ⊥），K（可达且可执行的乘积结点数，
    越出定义域的结点不计入），first0 / firstB（最短的被评价 0 / ⊥ 延伸词），dead（越出定义域而截停的转移数），finite，
    evaluated（被评价的结点数）；evaluated = 0 时 verdict = 1 只是空评价域上的逻辑真，vacuous 标为 True，不是经评价的保持记录。"""
    letters = list(M.letters if letters is None else letters)   # None 为缺省（全部字母）；显式空集照常保留
    if dfa:
        q0, delta = dfa[0], dfa[1]
        acc = dfa[2] if len(dfa) > 2 and dfa[2] is not None else None
    else:
        q0, delta, acc = None, None, None
    accepted = (lambda q: True) if acc is None else (lambda q: q in acc)
    start = (monitor_init(M, h0, w), q0)
    seen = {start: ()}
    dq = deque([start])
    first = {0: None, None: None}
    dead = 0
    evaluated = 0
    lab0 = monitor_label(M, start[0])
    if accepted(q0):
        evaluated += 1
        if lab0 in (0, None):
            first[lab0] = ()
    while dq:
        node, q = dq.popleft()
        for u in letters:
            q2 = q
            if delta:
                q2 = delta(q, u)
                if q2 is None:
                    continue
            n2 = (monitor_step(M, node, u), q2)
            if n2 in seen:
                continue
            lab = monitor_label(M, n2[0])
            if lab == 'dead':
                dead += 1
                continue                        # 越出定义域：不可执行，不是评价点，也不再延伸
            seen[n2] = seen[(node, q)] + (u,)
            if accepted(q2):
                evaluated += 1
            if accepted(q2) and lab in (0, None) and first[lab] is None:
                first[lab] = seen[n2]
                if lab == 0 and stop_on_zero:
                    return {'verdict': 0, 'K': len(seen), 'finite': None, 'first0': first[0], 'firstB': first[None], 'dead': dead,
                            'evaluated': evaluated, 'vacuous': False}
            dq.append(n2)
            if len(seen) > cap:
                return {'verdict': '未闭合', 'K': len(seen), 'finite': False, 'first0': first[0], 'firstB': first[None], 'dead': dead,
                        'evaluated': evaluated, 'vacuous': None}
    v = 0 if first[0] is not None else (None if first[None] is not None else 1)
    return {'verdict': v, 'K': len(seen), 'finite': True, 'first0': first[0], 'firstB': first[None], 'dead': dead,
            'evaluated': evaluated, 'vacuous': evaluated == 0}

def node_R_Q(M, node):
    """监控结点上的最大承担集 R 与全部 Q（定理一、定理三 (a)）。"""
    s, F, Mk, buf = node
    e = rc.window_eval(M, s, F, Mk, buf)
    Ftot, ss = set(F), s
    for u in buf:
        ss, fo, _, _ = M.step(ss, u)
        Ftot |= fo
    end = dict(zip(M.I, e['end']))
    return frozenset(i for i in M.I if end[i] > M.eps and i in Ftot), e['Q']

def fixed_layer(M, h0, w, letters=None, dfa=None, cap=200000):
    """固定层全轨迹量词（推论四）：是否有一个 T，在入口上合格且在全部被评价的可达乘积结点上合格。
    非接受结点照常展开，只在求交与检查 Q 时筛去；入口无论 q0 是否接受都计入候选条件（原承担者须在入口已合格）。
    返回 T（候选 = R(入口) ∩ 各被评价结点 R 之交）、verdict（候选在入口与全部被评价结点上 Q 的强 Kleene 合取；候选为空时为 0）、
    evaluated（被评价结点数）、K。由定理一 (b)，verdict = 1 当且仅当存在这样的 T；verdict = 0 时一切 T 都在某结点读 0。"""
    letters = list(M.letters if letters is None else letters)
    if dfa:
        q0, delta = dfa[0], dfa[1]
        acc = dfa[2] if len(dfa) > 2 and dfa[2] is not None else None
    else:
        q0, delta, acc = None, None, None
    accepted = (lambda q: True) if acc is None else (lambda q: q in acc)
    start = (monitor_init(M, h0, w), q0)
    seen, dq = {start}, deque([start])
    Rs, Qs = [], []
    R0, Q0 = node_R_Q(M, start[0])
    Rs.append(R0); Qs.append(Q0)                       # 入口：候选条件
    evaluated = 1 if accepted(q0) else 0
    while dq:
        node, q = dq.popleft()
        for u in letters:
            q2 = q
            if delta:
                q2 = delta(q, u)
                if q2 is None:
                    continue
            n2 = (monitor_step(M, node, u), q2)
            if n2 in seen or monitor_label(M, n2[0]) == 'dead':
                continue
            seen.add(n2); dq.append(n2)
            if accepted(q2):
                R, Q = node_R_Q(M, n2[0])
                Rs.append(R); Qs.append(Q); evaluated += 1
            if len(seen) > cap:
                raise RuntimeError('乘积图未在 cap 内闭合')
    T = frozenset.intersection(*Rs)
    v = rc.k_and(*[Q[T] for Q in Qs]) if T else 0
    return {'T': T, 'verdict': v, 'evaluated': evaluated, 'K': len(seen)}

def brute_labels(M, h0, w, letters, L):
    """暴力对照：长度 ≤ L 的全部合法延伸逐一求值（越出定义域者剔除并停止延伸）；返回标签集合与各标签的最短词。"""
    out, first = set(), {}
    level = [()]
    for n in range(L + 1):
        nxt = []
        for v in level:
            e = rc.fld_of_history(M, h0 + v, w)
            if e is None:
                continue
            f = e['Fld']
~~~

A.4　s4\_boundary.py　回放比较下的参数区、边界取得与窗长参数（定理二、七，命题六）

~~~python
"""S4：回放比较语义下的参数分区与边界取得（固定有限史）。
参数取分辨率 ε = θ（申报的单参数族：初态、脉冲幅度与系数都不随 θ 变，只有阈值随 θ 变；这是定理七所论多项式族的一次特例）。
θ 的每一个取值都是一份独立的合法 𝔐_GF 模型，自原始 s₀ 重新运行；这里比较的是参数族，不是动态的保持或失效。
方法：以记录比较对象的阈值类 Thr 代替 ε 运行原求值器，得到该点所经的全部比较值；在不含比较值的开区间内分支不变，
故读数不变（定理七的证明骨架）。逐个求出断点并在断点上直接重算。
（1）χ₀ 的 ε 参数族，史 (u1, rest^n)，n = 5、12、30：正判区、零判区与断点的取得。
（2）无限时域：对每个 n 正判区为 [0, θ_n)，θ_n 递减趋于 0；全部 n 上都为 1 的参数只有 θ = 0（命题六）。
（3）正判区不必是区间：随机模型中出现读数沿 θ 为 1、0、1 的参数族（显式给出一例）。
（4）窗长 w 为离散参数，按定理二单调；实例甲 (init, a^n) 上正判的最小窗长。"""
import random
from fractions import Fraction as Fr
import reach_core as rc
from stab_core import evaluate

class Thr:
    """阈值 θ：与之比较的每一个有理数都记入 seen。"""
    def __init__(self, v):
        self.v, self.seen = Fr(v), set()
    def _r(self, x):
        self.seen.add(Fr(x))
        return Fr(x)
    def __lt__(self, x): return self.v < self._r(x)      # x > θ
    def __gt__(self, x): return self.v > self._r(x)      # x < θ
    def __le__(self, x): return self.v <= self._r(x)     # x ≥ θ
    def __ge__(self, x): return self.v >= self._r(x)     # x ≤ θ

def fld_at(M, h, w, theta):
    t = Thr(theta)
    M.eps = t
    e = rc.fld_of_history(M, h, w)
    return (None if e is None else e['Fld']), t.seen

def cells(M, h, w, hi):
    """[0, hi] 的分区：[(左, 右, 是否点, Fld)]。"""
    out, p = [], Fr(0)
    f, _ = fld_at(M, h, w, p)
    out.append((p, p, True, f))
    while p < hi:
        q = p + Fr(1, 2) ** 10 if p + Fr(1, 2) ** 10 < hi else (p + hi) / 2
        while True:
            fq, V = fld_at(M, h, w, q)
            b = min([v for v in V if v > p] + [hi])
            if q < b:
                break
            q = (p + b) / 2
        out.append((p, b, False, fq))
        fb, _ = fld_at(M, h, w, b)
        out.append((b, b, True, fb))
        p = b
    return out

def merged(cs):
    """合并相邻同值的胞，给出正判区（读数 1）的区间表示。"""
    segs = []
    for (l, r, pt, f) in cs:
        if segs and segs[-1][3] == f:
            segs[-1] = (segs[-1][0], r, segs[-1][2], f, segs[-1][4], pt)
        else:
            segs.append((l, r, pt, f, pt, pt))
    return segs

def fmt(segs):
    s = []
    for (l, r, lpt, f, lclosed, rclosed) in segs:
        if l == r:
            s.append(f'{{{l}}}→{f}')
        else:
            s.append(f'{"[" if lclosed else "("}{l}, {r}{"]" if rclosed else ")"}→{f}')
    return '；'.join(s)

al, be, la = Fr(1, 2), Fr(1, 10), Fr(3, 10)
procs = [rc.Proc('wb', 'x', 'B', 'lin', R=('x',), k=be), rc.Proc('dec', 'x', 'B', 'lin', R=('x',), k=-la)]
C = rc.GF(I=('x',), eps=0, letters={'rest': ([], procs), 'u1': ([('x', al, 'out')], procs)}, s0=(0,))

    assert len(pos) == 1 and pos[0][0] == 0 and pos[0][5] is False
    thetas.append(pos[0][1])
    print(f'（1）χ₀，史 (u1, rest^{n})，w = 1，θ ∈ [0, 1]：{fmt(segs)}')
~~~

~~~python
    return seen
~~~

A.6　reach\_core.py　《场具化可达式》v1.0 附录 A.1 的字母门控 F 模型与窗读法求值器，与该篇附录 A.1 逐字相同

~~~python
"""场具化可达式：字母门控 F 模型、窗读法、增广可达搜索与暴力对照（精确有理运算，三值强 Kleene）
模型类 𝔐_GF（字母门控 F 模型）：有限位集 I、分辨率 ε；字母表 U（含静置 'rest'）；
每个字母 u 给出本拍的脉冲表 [(tgt, a_p, ext)] 与过程表 [Proc]；过程按《场具化数理式》D12 的三类数值律，
读取拍前状态；cert_eff = 1；cert_read、路径边认证由过程申报（直接边：读取位 → 过程，Γ_closed = 闭合）；
Ident、HistEv 申报为 1。一条输入史 h 的窗读法（本篇读法 RD）：W 取 h 的末 w 拍，W 之前的全部拍为形成史，
其 Form、Mark 记录在 F 中以入口拍的记录表示（数理式 D2），W 起点状态为形成史末态。
"""
from fractions import Fraction as Fr
from itertools import combinations, product
from collections import deque
ONE, ZERO, BOT = 1, 0, None

def k_and(*xs):
    if any(x == 0 for x in xs):
        return 0
    if any(x is None for x in xs):
        return None
    return 1

def k_or(*xs):
    if any(x == 1 for x in xs):
        return 1
    if any(x is None for x in xs):
        return None
    return 0

class Proc:
    def __init__(self, pid, tgt, car, law, R=(), k=0, b=0, cert_read=1, cert_path=1):
        self.pid, self.tgt, self.car, self.law = pid, tgt, car, law
        self.R, self.k, self.b = tuple(R), Fr(k), Fr(b)
        self.cert_read, self.cert_path = cert_read, cert_path
    def value(self, s):
        if self.law == 'const':
            return self.b
        if self.law == 'lin':
            return self.b + self.k * sum(s[j] for j in self.R)
        j1, j2 = self.R
        return self.b + self.k * s[j1] * s[j2]
    def supp_act(self, s):
        if self.law == 'const' or self.k == 0:
            return set()
        if self.law == 'lin':
            return set(self.R)
        j1, j2 = self.R
        out = set()
        if s[j2] != 0:
            out.add(j1)
        if s[j1] != 0:
            out.add(j2)
        return out
    def supp_cond(self, s, eps):
        sa = self.supp_act(s)
        if self.law == 'lin' and abs(self.value(s)) <= eps:
            sa |= set(self.R)
        return sa

class GF:
    """字母门控 F 模型。letters: {u: (pulses, procs)}；pulses = [(tgt, a, ext)]，ext ∈ {'out','in'}。"""
    def __init__(self, I, eps, letters, s0):
        """合法性前件（定义三）：位名非空互异；ε、初态、脉冲幅度为非负有理数（整数或 Fraction，不收浮点）；
        字母表有限且含 'rest'；过程标号在同一字母内互异；律 ∈ {const, lin, bilin}，lin 读取位非空，bilin 恰两位，
        const 无读取位；读取位与作用对象属位集；cert_read、cert_path ∈ {1, 0, None}；脉冲 ext ∈ {'out','in'}。
        不合法者抛出 ValueError，不进入求值。"""
        def rat(v, nonneg=False):
            if isinstance(v, bool) or not isinstance(v, (int, Fr)):
                raise ValueError('数值须为整数或 Fraction')
            if nonneg and v < 0:
                raise ValueError('须非负')
            return Fr(v)
        I = tuple(I)
        if not I or len(set(I)) != len(I) or any(not i for i in I):
            raise ValueError('位集')
        if 'rest' not in letters:
            raise ValueError('字母表须含 rest')
        for u, (pulses, procs) in letters.items():
            for (tgt, a, ext) in pulses:
                if tgt not in I or ext not in ('out', 'in'):
                    raise ValueError('脉冲')
                rat(a, True)
            ids = [p.pid for p in procs]
            if len(set(ids)) != len(ids):
                raise ValueError('过程标号重复')
            for p in procs:
                if p.tgt not in I or any(j not in I for j in p.R) or p.car not in ('B', 'out'):
                    raise ValueError('过程对象或读取位')
                if p.law not in ('const', 'lin', 'bilin') or (p.law == 'lin' and not p.R) or \
                   (p.law == 'bilin' and len(p.R) != 2) or (p.law == 'const' and p.R):
                    raise ValueError('律与读取位')
                if p.cert_read not in (1, 0, None) or p.cert_path not in (1, 0, None):
                    raise ValueError('认证值')
        if len(s0) != len(I):
            raise ValueError('初态长度')
        self.I, self.eps, self.letters = I, rat(eps, True), letters
        self.s0 = tuple(rat(x, True) for x in s0)
    def idx(self, i):
        return self.I.index(i)
    def step(self, s, u):
        """一拍（数理式 4.2、5.1）：返回 (后态, 新形成位集, 新标记位集, 过程事件表)；越出定义域返回 None。"""
        eps = self.eps
        pulses, procs = self.letters[u]
        d = {i: Fr(0) for i in self.I}
        sd = dict(zip(self.I, s))
        formed, marked, events = set(), set(), []
        for (tgt, a, ext) in pulses:
            a = Fr(a)
            if a > eps:                      # 有效脉冲：一律计入 Form（D16；与上游 field_final.py 第 123—126 行同），不论拍前深度
                formed.add(tgt)
                if ext == 'out':
                    marked.add(tgt)
                d[tgt] += a
        for p in procs:
            c = p.value(sd)
            act = 1 if abs(c) > eps else 0
            events.append((p, c, act))
            if act:
                if c > eps and sd[p.tgt] <= eps:   # 有效正分项使空位成为留迹元素（D16；上游第 161 行）
                    formed.add(p.tgt)
                if p.car == 'out':
                    marked.add(p.tgt)        # 界外载体机制的有效改变入 Mark
                d[p.tgt] += c
        s2 = tuple(sd[i] + d[i] for i in self.I)
        if any(x < 0 for x in s2):
            return None
        return s2, formed, marked, events

def window_eval(M, s_start, F_rec, M_rec, word):
    """窗读法：入口记录 F_rec、M_rec（位集），W = word。返回 dict：每个非空 T 的 Q 及 Fld、界内自反馈型。"""
    eps = M.eps
    s = s_start
    Form = set(F_rec)           # 「早于 t」的形成记录（入口拍记录早于 W 内一切拍）
    Mark = set(M_rec)
    ev_log = []                 # (avail_cond 全集, avail_act 全集, p, c, act)，T 相关部分事后按 T 截取
    for u in word:
        r = M.step(s, u)
        if r is None:
            return None
        s2, formed, marked, events = r
        sd = dict(zip(M.I, s))
        for (p, c, act) in events:
            ac = {i for i in p.supp_cond(sd, eps) if sd[i] > eps and i in Form}
            aa = {i for i in p.supp_act(sd) if sd[i] > eps and i in Form}
            ev_log.append((ac, aa, p, act))
        Form |= formed
        Mark |= marked
        s = s2
    end = dict(zip(M.I, s))
    out = {}
    fld, selfref = 0, 0
    for n in range(1, len(M.I) + 1):
        for T in combinations(M.I, n):
            T = set(T)
            src = 1 if any(i in Mark for i in T) else 0
            ret = 1 if all(end[i] > eps and i in Form for i in T) else 0
            trace = k_and(src, ret, 1, 1)   # Ident、HistEv 申报为 1
            part = k_or(*[k_and(1 if (ac & T) else 0, p.cert_read)
                          for (ac, aa, p, act) in ev_log if p.car == 'B']) if ev_log else 0
            hd_terms, sr_terms = [], []
            for (ac, aa, p, act) in ev_log:
                hc = k_and(1 if (aa & T) else 0, p.cert_read, p.cert_path if (aa & T) else 0)
                hd_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
                if p.car == 'B':
                    sr_terms.append(k_and(1 if p.tgt in T else 0, act, hc))
            hdyn = k_or(*hd_terms) if hd_terms else 0
            q = k_and(trace, part, hdyn)
            out[frozenset(T)] = q
            fld = k_or(fld, q)
            sr = k_and(q, k_or(*sr_terms) if sr_terms else 0)
            selfref = k_or(selfref, sr)
    return {'Q': out, 'Fld': fld, 'self': selfref, 'end': s}

def run_prefix(M, h):
    """形成史：自 s0 施加 h，返回 (末态, Form 位集, Mark 位集)。"""
    s, F, Mk = M.s0, set(), set()
    for u in h:
        r = M.step(s, u)
        if r is None:
            return None
        s, fo, ma, _ = r
        F |= fo
        Mk |= ma
    return s, frozenset(F), frozenset(Mk)

def fld_of_history(M, h, w):
    """输入史 h 的窗读法资格（W = 末 w 拍，w ≥ 1）。"""
    if w < 1:
        raise ValueError('w ≥ 1')
    if len(h) < w:
        return None
    pre = run_prefix(M, h[:len(h) - w])
    if pre is None:
        return None
    s, F, Mk = pre
    return window_eval(M, s, F, Mk, h[len(h) - w:])

def physical_reach(M, letters=None):
    letters = letters or list(M.letters)
    seen, dq = {M.s0}, deque([M.s0])
    while dq:
        s = dq.popleft()
        for u in letters:
            r = M.step(s, u)
            if r and r[0] not in seen:
                seen.add(r[0])
                dq.append(r[0])
    return seen

def augmented_search(M, w, target='Fld', letters=None):
    """增广搜索：结点 (s, Form, Mark)；对每个结点枚举长 w 的窗词。返回最短满足史及结点统计。"""
    letters = letters or list(M.letters)
    start = (M.s0, frozenset(), frozenset())
    dist, par = {start: 0}, {start: None}
    dq = deque([start])
    while dq:
        node = dq.popleft()
        s, F, Mk = node
        for u in letters:
            r = M.step(s, u)
            if r is None:
                continue
            s2, fo, ma, _ = r
            nxt = (s2, F | fo, Mk | ma)
            if nxt not in dist:
                dist[nxt] = dist[node] + 1
                par[nxt] = (node, u)
                dq.append(nxt)
    best = None
    for node in sorted(dist, key=lambda n: dist[n]):
        if best is not None and dist[node] + w >= best[0]:
            break
        s, F, Mk = node
        for word in product(letters, repeat=w):
            e = window_eval(M, s, F, Mk, word)
            if e is not None and e[target] == 1:
                path, n = [], node
                while par[n] is not None:
                    n, u = par[n]
                    path.append(u)
                h = tuple(reversed(path)) + word
                if best is None or len(h) < best[0]:
                    best = (len(h), h)
                break
    N = len(physical_reach(M, letters))
    return {'best': best, 'nodes': len(dist), 'N': N,
            'max_prefix_dist': max(dist.values()), 'bound_prefix': (2 * len(M.I) + 1) * N - 1}

def brute_min(M, w, Lmax, target='Fld', letters=None):
    letters = letters or list(M.letters)
    for L in range(w, Lmax + 1):
        for h in product(letters, repeat=L):
            e = fld_of_history(M, h, w)
            if e is not None and e[target] == 1:
                return L, h
    return None
~~~
