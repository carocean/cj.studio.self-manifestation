自显论·工篇·场具化组式第十七 v1.0

# 具化场识别判定式

一、目的

### 1.1　用途与中心问题

本篇为判定式（附式，反演辨识组；主书《自显论》v0.7.8 法篇判定式一章）。用途：面对一个具体宿载，从其机制证据（分子机制、电生理、成像、形态测量、连接组、群体实验与已发表模型）出发，判定：（一）哪些改变是迹应、哪些是当时的活动、活动残留与背景结构；（二）迹应深浅由什么量承担，并检出「先选的数」；（三）在申报设定族与时间框架下，哪些承担构成同一组织；（四）识别所得能否进入〔封三〕〔封十一〕〔封十三〕，三篇不覆盖处以有证明的补充判据桥接；（五）按〔封一〕总式报告该实例是否成立为沉积场，并分报可选台账。  
中心问题：第三、十一、十三篇从已申报的结构位、状态变量、过程清单与观测协议出发；本篇处理这些申报怎样从具体对象获得依据——为什么选这些改变作为迹应，为什么这些承担组成同一集合，已有集合怎样参与活动、活动又怎样作用回这个集合——并检验识别所得能否进入已有判据。  
职责判定以上游判词为准；判定结论不含物质认证。没有现成实验时，判定结论限于机制、条件结论与可击穿预测；预测不登记为现实认证，不预设候选必然通过，也不把未定当作负判。

### 1.2　分工

　〔封三〕｜起点：冻结的申报 Δ（F 类律与观测协议）｜输出：职责判词，F 类上两向，实测只判 1 或 ⊥  
　〔封十一〕｜起点：申报的事件门控类成员｜输出：相对声明干预域的两向判定  
　〔封十三〕｜起点：申报的不完美实验台与对象类｜输出：职责原子的可靠判 1 与不可认证界  
　本篇｜起点：对象及其机制证据｜输出：迹应、深度、组织与区间的识别判词；向三篇的路由；三篇不覆盖处的补充判据；实例的成立条件与台账  
第十八篇《迹应集合变换数理式》承担集合变换的表示、运行与推导；势作为组织方式的倾向层由第十八篇表述。涉及势时按同一口径：势是集合组织在申报背景、残留与输入类下形成的活动倾向，具体活动是在实际信号下的实行。

　1．识别：钳定自留存三分；已观测下界与完整自留存分开，完整须尾部证据，有限记录只给下界（定义 2′、定理 17-1、引理 17-1′）；深度相对申报探针与写入条件签署，序唯一，先选的数可检出（定义 3′、定理 17-2、推论 17-2a）；周期写入只击穿所申报的 K1/K3 组合（定理 17-3）；探针序冲突（引理 17-3′）；候选筛查与元素证书分签，越过基态的反向单列（定义 4′）；组织超图在申报联合设定族上精确枚举，采样只报见证与覆盖缺口，分量唯一只对给定超图（定义 5′、定理 17-4′、引理 17-4′）。

二、上游输入

### 2.1　本体原文

《沉积场本体定义》v2.0：「沉积场是：信号在介质中留下的迹应集合，以及这一集合在历史动力作用下变换的组织方式及其活动。」「因此，自显论是研究：信号在介质中的迹应，及迹应集合变换的一门理论。它考察一个具化场，首先要找出其迹应是什么，再研究其集合在历史动力作用下的变换。」说明：「单个迹应（元素）只有加深、退浅两种基本变化性质；不变是零变化，退浅的极限是迹应现象不发生。」「迹应集合由动力组织起来，其变换建立在元素加深、退浅的基础上，表现为路径、交叠、边沁、局部退浅等动力现象，以及整体、子集及其相互干预的组织变换。」  
迹应的界定（《沉积场本体结构示意图》v0.4.1，2026年10月28日）：「「迹应」取主书场数理式定义 3 原义：结构位 x 在时刻 t 所承受并留下的有效改变。据此：承载处 = 结构位 x（定义 4）；迹应 = 该处留下的有效改变；迹应的深浅对应沉积度 δ(x)（定义 9）。」《场数理式》v2.7 定义 3：「迹应不是观察者命名的因果关系。迹应是场中真实发生的物理改变。」定义 9：「沉积度由宿载机制承担，不必是几何深度」。  
读法：「历史动力形成势，势的实行，就是活动，活动与势组织（指集合的组织）就是变换，其因势而变换，如水就低。」（《势型分级式》v1.0 第2.1节 F2。）其中「组织」指迹应集合的组织方式：连接、路径、交叠、子集、相互约束及由此形成的势。  
《沉积场本体结构示意图》v0.4：横轴为历史 H；Tᵢ 为当前迹应集合；Sᵢ 自上入 Tᵢ；Dᵢ 为信号与当前集合共同作用产生的动力，带动力类型集合；D′ᵢ 为动力再作用，直接接到下一时刻的迹应集合 Tᵢ₊₁。

### 2.2　《沉积场定义》v1.1（2026年10月28日）中与本篇识别直接相关者

「其既有迹应集合能够参与决定后续动力在介质中的去向，并在后续动力与外部信号的再作用下，继续能够改变自身的迹应及其组织。其迹应具有可沉积性：在相应作用条件下能够因反复经受而加深，因退浅作用而减弱，直至迹应现象不再发生。」该定义的要点：承重点为动力去向与可沉积性；「去向」包括实际趋入、续行、分流与受阻；可沉积性不写成无条件规律；退浅机制不限定为自然退浅；不以预期分类反推定义（晒热的石头通常不符合；沙滩脚印不能一概排除；里程表数位不符合，整个物质装置另论）。检验一：「二者没有本体区别；区别在于所处的动力区间……流经凹处的水，是把它冲深，还是把它淤平？」「判定是区间依赖的。」  
地位：现行本体定义为《沉积场本体定义》v2.0（2.1）。v1.1 的「可沉积性」「区间依赖」只用于可选台账（定义 7′、8′）与对照栏（8.6），主判词保留〔封一〕总式的语义，不以 v1.1 改写总式或本体。

### 2.3　具化场研究流程（七步）

具化场研究流程是《场具化组式总图》的必载内容：给定一个具化场，先找它的迹应，再研究迹应集合怎样变换。第一步找迹应（什么信号作用于它的什么介质，留下了什么改变，改变由什么承担、怎样留存，分清留存的改变与当时发生的活动）；第二步研究单个迹应（怎样加深、怎样退浅、什么时候不变，深浅在宿载中由什么量承担）；第三步研究集合的组织（边界与子集）；第四至六步研究势、活动与再作用；第七步整理证据、条件推导和可击穿预测，再调用已有判据判断。  
本篇承担第一步、第二步中「深浅由什么量承担」、第三步中「集合的边界与子集」、第六步中「接牢已有迹应参与决定作用、作用进一步改变集合的实际过程」的判定侧，以及第七步。第四至六步的表达、运行与求解归第十八篇《迹应集合变换数理式》；两者的对应见接口（第十一节）。

三、性质与观测集申报

### 3.1　识别对象与识别申报底本

识别对象：一个宿载 H（物理对象及其层级 L），连同申报的区间 R（作用条件：流量与含沙、温度、刺激间隔、驱动方式等）与历史窗 W。  
识别申报底本 Δ\_id 只含对象侧事实与观测，不含预先选定的迹应、深度或集合：  
　（一）候选载体清单 𝒞：介质中可能承受改变的物理量，各带身份标签、物理描述与量度方法（例：每个受体分子上的甲基化位点；每个 KC→MBON 突触的传递效能；每个管段的内径；每一床面网格的高程）。清单不完备时，凡依赖完备性的负判改判 ⊥（〔封三〕EF1 同义）。  
　（二）信号类 𝒮：自 B 之外实际作用于介质的作用（〔封一〕第三节），含静置。  
　（三）观测：见 3.2。  
　（四）分辨率 ε（可逐实例申报），以及（若已测）各载体的自留存记录。  
　（五）区间 R 的申报与可达史类 𝓗\_R（所论作用条件下合法的信号史与驱动史）。  
　（六）设定族 𝔖：可施行的合法设定（单位设定、联合设定及其取值），注明哪些能同时施行、施于何时；组织判词只对 𝔖 与所注时间框架签署（定理 17-4′）。  
　（七）写入条件 𝒲：K3 所针对的形成写入（施何信号、其余过程如何钳定），事前申报。  
识别的输出 Out\_id（第四节）才包含 T、深度度量、元素身份、组织分量与区间判词；它们是判出来的，不是申报进去的。这是识别判定与〔封三〕3.1 的起点差别。

### 3.2　观测集 Y\_id

O1　撤供留存记录：对载体 k，在信号史 h 后撤去信号、并钳定其余载体（或在其余载体已知不变的制备中），记录 k 相对无迹基态的偏离随时间的序列 u\_k(t)；注明尾部证据（定义 2′）；无尾部证据时只报已观测下界。  
O2　探针响应：对探针信号 p ∈ 𝒮 与活动读出分量 j，在载体处于不同状态（由历史产生，或由设定产生）时的读数 Φ\_j(w; p)。  
O3　机制图：载体、活动变量与过程之间的读取与写入关系，每条边带出处标签：【事实】（有直接测量或干预）、【已发表模型】、【机制假设】。  
O4　干预：设定（LOC 型，含 Q/E 替换、光遗传驱动、机械设定）、敲除或律改写（含谱系型缺失株，〔封十三〕C-1、C-2）、阻断（途径阻断）、钳定（活动钳定、流量钳定）。  
O5　跨记录材料：不同动物组、不同菌株、不同论文中的记录，各带协议与时程。  
O6　区间读数：作用条件（流速、含沙量、刺激间隔、温度）与相应的冲淤或加深退浅读数。

### 3.3　定义序列

定义 1（无迹基态、参照史与取向深度）【表示选择】  
载体 k 的无迹基态 w⁰\_k：介质在无任何信号史时该载体所处的状态（静止介质为常值；有漂移的介质为同一非信号驱动下的参照轨迹 w\_k(h\_ref; t)，h\_ref 为把实际史中的信号段换为静置所得的参照史，承〔封三〕Hist 的参照史）。取向深度 δ\_x := o\_x·(w\_x − w⁰\_x)，o\_x 为申报元素取向（压抑型、加粗型等）。δ\_x \> ε 为该取向上的迹应候选；δ\_x \< −ε 为越过基态的另一型候选，单列，不计入原取向。信号形成位：实际史与参照史在窗末的载体差超过 ε 的位，给出〔封一〕r 的识别侧见证；由场内续行形成而不经信号的元素深度以 w⁰ 计。  
定义 2′（自留存与三分；完整与下界）  
对载体 k，在钳定其余载体的条件下施合法写入，令 u\_k(t) 为此后静置中的偏离序列；自留存步数 τ\_k := 最后一个 \|u\_k(t)\| \> ε 的 t 加一（在全部静置域上取；无越阈为 0）。  
已观测下界：有限记录 u\_k(0), …, u\_k(t\_end) 上，τ\_k^obs := 记录中最后一个 \|u\_k(t)\| \> ε 的 t 加一。恒有 τ\_k ≥ τ\_k^obs；记录末点不越阈不给上界，因为越阈可以中断后再现（反例 X11）。越阈中断再现时，末次越阈与连续留存分报。  
完整自留存：τ\_k = τ\_k^obs 须有尾部证据，三种之一：（甲）记录已覆盖余下的全部静置域；（乙）记录末态已进入正向不变的阈下集——静置映射把该集映入自身，且集内 \|u\| ≤ ε；（丙）经证明的包络——\|u\_k(t\_end + s)\| ≤ C·λ^s 对一切 s ≥ 0 成立，0 ≤ λ \< 1，C ≤ ε。无尾部证据时只记「下界」，不论末点是否越阈。  
三分：给定申报 τ\_act \< τ\_W。背景——在 𝓗\_R 的一切合法史下不被写入；迹应载体——可被写入且 τ\_k ≥ τ\_W，下界 τ\_k^obs ≥ τ\_W 已足以正判；活动——可被写入且 τ\_k ≤ τ\_act；活动残留——τ\_act \< τ\_k \< τ\_W。后两类须完整自留存（上界）；只有下界而 τ\_k^obs \< τ\_W 时判 ⊥\_Tail，不签活动、残留或非迹应。四类相对申报的 τ\_act、τ\_W 互斥且穷尽；判词至多停在 ⊥\_Tail。要点是「钳定其余载体」：随迹应而变的活动读数（Part）不是自身的留存（引理 17-1′）。  
定义 3′（深度可承担；相对申报探针与写入条件）  
设 k 为迹应载体（其身份可由自留存下界 ≥ τ\_W 给出，K1—K3 不用完整自留存），Ω\_k 为 k 的可达载体值之集（其余载体在无迹基态），p 为申报探针，j 为申报读出分量，参与效应 e\_{p,j}(w) := \|Φ\_j(w; p) − Φ\_j(w⁰; p)\|。δ: Ω\_k → ℚ≥0 为可承担深度，当且仅当：  
　K1（留存承担）：δ 只是 k 的留存载体值的函数；δ(w⁰) = 0，w ≠ w⁰ 时 δ(w) \> 0；  
　K2（参与分级，相对固定的 p、j）：δ(w) \< δ(w′) ⇔ e(w) \< e(w′)，δ(w) = δ(w′) ⇔ e(w) = e(w′)；  
　K3（重复不擦，只对申报写入条件 𝒲）：δ(W\_s(w)) ≥ δ(w) 对一切 w ∈ Ω\_k。  
参与深度 δ\* := e\_{p,j}。若某非基态 w 有 e(w) = 0，该元素对探针 p 隐，须换探针或申报探针类。一组 (K1, K3) 的失败只击穿该载体在 𝒲 下的申报。依据：本体说明「单个迹应只有加深、退浅……退浅的极限是迹应现象不发生」；《场数理式》定义 9「沉积度由宿载机制承担」；《沉积场定义》v1.1「因反复经受而加深」【表示选择】。  
定义 4′（迹应候选与元素证书）  
候选筛查：窗末取向深度 \> ε（正向）与 \< −ε（反向）的位分列。元素证书：候选另须（一）自留存达到 τ\_W（下界 τ\_k^obs ≥ τ\_W 即可；下界不足 τ\_W 而无尾部证据时 ⊥\_Tail）；（二）K1—K3 在申报 p、j、𝒲 下通过；（三）在探针类序冲突时已按引理 17-3′ 拆分。筛查不等于证书。  
定义 5′（组织超图；精确枚举与有界采样）  
在元素集 E 上作超图 H\_org：共同参与超边——使活动分量 j 有效改变的极小设定子集（单位依赖的各位并为一条超边，只有联合设定显出的依赖取该联合子集）；历史条件超边——使作用于 x 的过程的总分项（按未钳定机制重算）有效改变的极小设定子集 U，连同 x。精确判词：在申报设定族 𝔖 全体（含联合设定）上枚举，分支为连通分量。有界采样：只在已施行子集上求，输出见证超边与覆盖缺口（未被任何已测子集共同覆盖的位对；被覆盖也不等于该位对的关系已识别），不输出分支。每条超边注明探针与时刻；跨时刻或跨不能同时施行的设定连成的链须注明。对象集合：在 𝔖 与时间框架下的一个分量；子组织为申报边界条件（其余位钳于申报值）后取分量子集所得的另一判定实例。连通是等价关系；分量唯一只对给定超图。  
定义 6′（有效差异证书：〔封一〕HistCond 的一条充分证书）  
〔封一〕HistCond(ρ, T) 的定义不变：ρ 在 W 内对 Org(T) 的作用（发生、时刻、位置、强度或方向）由 T 已留下的迹应经实际物质途径参与决定。本定义只给其「强度」一款的一条充分取证规则，是正判入口，不是等价定义。  
有效差异见证：过程 ρ 于 W 内拍 t、状态 σ\_t 对 x ∈ T 的作用，连同一个合法对照 σ′，满足  
　（甲）同拍同过程：Act 与差异取于同一拍 t、同一过程 ρ、同一目标 x；  
　（乙）承担位：σ′ 只改动 U ⊆ T，且 U 中每一位在拍 t 的拍前态中取向深度 \> ε、并有早于拍 t 的形成与留存证据（T 的窗末成员身份不独自给出这一证据）；  
　（丙）有效差异：按未钳定机制重算（活动随设定重算），总分项差 Δ\_tot := c\_{ρ,x}(σ′) − c\_{ρ,x}(σ\_t) 满足 \|Δ\_tot\| \> ε；  
　（丁）途径与认证：σ\_t 与 σ′ 之间的依赖经所申报的实际机制途径（模型模式由模型结构给出；实测须〔封三〕IMP 或其对应物），且 ρ 的作用认证成立（同拍分项 \|c\_{ρ,x}(σ\_t)\| \> ε，按申报分辨率语义）。  
判值三分（对每一拍、过程、目标与申报设定族）：  
　有效差异已获证——某合法对照满足（甲）至（丁）；  
　函数支持已立——某合法对照使 Δ\_tot ≠ 0 而无一越过 ε，或按〔封二〕D15—D18 在已认证路径上有非零函数支持；  
　有效差异未获证——其余。  
后两值不是 HistCond 的否定。两支分报：沿申报次序「先换活动、后改直读」，A := c(σ\_t 的直读, y(σ′)) − c(σ\_t 的直读, y(σ\_t))，D := c(σ′ 的直读, y(σ′)) − c(σ\_t 的直读, y(σ′))，A + D = Δ\_tot。这是沿该次序的望远镜恒等式；直读与活动有交互时另一次序的分项不同（反例 X8），分项不是唯一的责任分摊。混合状态（σ\_t 的直读配 σ′ 的活动）可施性未立时，A、D 只属模型账。两支各自有效不推出（丙）（反例 X1）；可核验的消差裕度：\|A\| \> \|D\| + ε 或 \|D\| \> \|A\| + ε 时（丙）成立；两支同号时 \|Δ\_tot\| = \|A\| + \|D\|。  
注 6′-1（历史条件的规范注）  
定义 6′ 的有效差异证书只证明申报对照下的一种历史条件。第二篇 D15—D18 按已认证路径与非零函数支持表达强度依赖；未取得有效差异证书不能据此否定该依赖，也不裁定其它参与方式。第二篇 F 层结论可按其原前件回读。  
定义 7′（主判词与可选台账）  
主判词：〔封一〕正式总式 Fld(χ) 的原定义，HDyn 与 HistCond 取〔封一〕原义。识别侧取证：HistCond 的正判由定义 6′ 的有效差异已获证给出，或由〔封三〕〔封十一〕〔封十三〕的上游证书给出。  
⊥\_HC 的范围：⊥\_HC 限于当前候选见证的识别证据不足——它只说所考察的候选见证（该 T、该拍、该过程、该目标与所申报的对照族）上只有「函数支持已立」或「有效差异未获证」。已有别的合格过程（另一拍、另一过程或另一 T 上的有效差异见证）或上游证书时，Fld 依〔封一〕原式求值：同一 T 上 TraceSet、Part、HDyn 合取，诸 T 之间与诸过程之间析取；某一候选的失败不覆盖别处已得的判值。只有在一切已考察的候选见证都停在上述两值、又无上游证书时，HDyn 与 Fld 才记 ⊥（未定），不记 0。记 0 须另有覆盖所申报读法（发生、时刻、位置、强度、方向）的完整否定证明，如模型过程清单完备而窗内无一过程对 T 有有效分项，或模型律逐项检视无任何依赖。定义 6′ 的失败不改写为总式的失败。  
可选台账（各自记账，互不推出，不改主判词）：  
　SED\_W(T)：W 内实际发生的某拍，某过程在 x ∈ T 上的取向分项 \> ε，且同一合法对照上 Δ\_tot 有效、A 支有效；  
　SED\_R(T)：同上，而状态取自区间 R 的申报可达集；  
　SED⁺\_R(T)：另要求把整个 T 按申报倍数设浅时该取向分项严格变小；  
　净加深 ND(T; P)：自申报状态施协议 P 后，T 中某位取向深度之增 \> ε；  
　周期累积 CA(T; P)：周期映射良定（定义 8′）且实际深度在加深侧。  
Fld^sed := Fld ∧ SED\_R 是可选的加强型判词，不作「是沉积场」的通用门槛；升为门槛须有它与冻结定义的对应证明及其在有效退浅、直读、饱和与负反馈各边界上的表现，并按主书的变更程序处理。本体原句同时承认加深、退浅与零变化，《沉积场定义》v1.1 亦排除「每次重复必然加深」的读法。  
定义 8′（周期映射：良定、吸引域、三种阈分报）  
F\_P：深度 ↦ 协议 P 一周期后的深度，只在良定时使用：同一深度的一切申报可达辅助状态一周期后给出同一深度；否则以 (深度, 辅助状态) 增广。冲刷侧 D⁺ := {δ : F(δ) \> δ}，淤积侧 D⁻ := {δ : F(δ) \< δ}，不动点集 Fix。吸引域 B(p) := {δ : lim F^n(δ) = p}（按极限的原像），端点逐个写明，可有单点吸引域。三种量分报：逐拍未取格零点、带格周期阈值、饱和点。  
定义 9′（连续类支持）  
连续类宿载：ẋ = Σ\_m F\_m(x, u)，F\_m 在申报盒上 Lipschitz；过程 m 对目标坐标的速率分项 f\_m。有限差异支持：f\_m(s′) ≠ f\_m(s)（s′ = s + δe\_i）。微分支持：f\_m 在开线段 (s, s′) 上关于 x\_i 可微时，某内点偏导非零；在含 s 的申报状态盒 Ω\_i 上有符号定性前件 SD\_i（偏导恒正、恒负或恒零）时，读到 s 处偏导非零。普通严格单调不推出实际点偏导非零。候选读法 HC^c：W 内某时刻某可用位 i ∈ T 上微分支持成立、m 的积分分项有效、速率律是所申报的实际物质机制（IMP-c）；它是否为〔封一〕HistCond 在连续类上的承担读法，属〔封十三〕U13-19 与〔封十一〕U9 的上游读法问题，在上游解决前不采纳。  
定义 10′（跨记录链）  
目标实例 χ\* 中：T、作用于 x ∈ T 的写入过程 ρ、T 外中间活动变量 y。记录 R₁ 认证链一：T 的两态 T₁、T₂ 下 y 取值 y₁、y₂。记录 R₂ 认证链二：在律区间 I 上，经 y 的写入贡献 G(y) 的律（或其单调性类）。接合条件：  
　C1　结点同一：R₁、R₂、χ\* 中 y 为同一物理变量（同一细胞类型或分子种类、同一读出映射，或差一已申报的严格单调变换），ρ 与 x 为同一过程与同一目标类；  
　C2　中介忠实：R₂ 中 y 的改变经再现生理 y 的通道取得，不同时改动写入的其他论元（偏差界按〔封十三〕丙b 申报）；  
　C3′　律区间：G 在 I 上严格增或严格减（不要求导数符号），且目标两态的 y₁、y₂ ∈ I（I 为记录二已证的律区间）；  
　C4′　态对应：写入时刻目标两态与 R₁ 的两态对应（计入退浅、饱和与中介残留）；  
　C5　割集或同号：χ\* 中 T 影响 c 的一切途径都经 y，或其余途径对两态差的贡献与经 y 者同号；  
　C6　实际作用：目标实际总分项 c\_{ρ,x}(σ) = G(y₁) + B 的认证区间与 \[−ε, ε\] 不交，其中 B 为一切其余分项（旁路）之和：或证明 B ≡ 0（「G 即完整分项」：该拍该位无其余分项、夹限等后处理未生效），或给出 B 在实际态上的申报界。C5 只约束两态差，不保证旁路在实际态上不冲掉 G（反例 X10）。  
记录的认证纪律、抽样单元与误差按〔封十三〕；参数迁移按其 M2-1、M2-2 的 μ、τ 条件。  
定义 11（出处标签与三层登记）  
每一判词携带所用证据边出处标签之最弱者（【事实】强于【已发表模型】强于【机制假设】）与所耗前件；含【机制假设】边的链只给条件结论（B 栏）。

### 3.4　前向关系

载体的写入与读出按〔封一〕第三节的过程识别与分项判据；有逐过程分解时，分项取原机制值（不先取格），ε 只用于判有效；F 类与事件门控类分别取〔封二〕4.2 与〔封十一〕引理 R1；连续类取常微分方程的流。真实宿载上「申报模型如实」属〔封三〕Dom4。

四、判据构造

### 4.1　判词格式与原因码

### 5.1　三分

定理 17-1（自留存分类与稳健窗）  
前提：钳定其余载体时，各载体的自衰减满足 \|u\_k(t)\| = \|u\_k(0)\|·λ\_k^t，λ\_k ∈ \[0, 1)，合法写入幅度 \|u\_k(0)\| ∈ \[a, A\]，0 \< ε \< a ≤ A。称 k 在窗长 t「必留存」若 a·λ\_k^t \> ε，「必不留存」若 A·λ\_k^t ≤ ε。  
（一）对每一 k，必留存之 t 为 {0, …, t\_s(k)}，必不留存之 t 为 {t\_f(k), t\_f(k)+1, …}，t\_s(k) \< t\_f(k)。  
（二）设载体分为快组 F（λ\_k ≤ λ\_f）与慢组 S（λ\_k ≥ λ\_s），λ\_f \< λ\_s。令 t\_lo := min{t : A·λ\_f^t ≤ ε}，t\_hi := max{t : a·λ\_s^t \> ε}。若 t\_lo ≤ t\_hi，则对一切 τ\_W ∈ \[t\_lo, t\_hi\]，S 中每一载体必留存、F 中每一载体必不留存：分类在该区间内不随窗长改变（稳健窗）。  
（三）分类随窗长改变：载体集非空时，t = 0 的必留存集合是全体，t ≥ max\_k t\_f(k) 的必留存集合为空；故在整个窗长域内必留存集合必变化。（二）的稳健窗为空时（无谱隙），判词须携带申报的 τ\_W，无申报判 ⊥\_Sep。  
（四）在给定候选窗域中区分两载体 k、k′：若实际临界拍 t\_s(k) \< t\_s(k′)（t\_s(k) = max{t : a·λ\_k^t \> ε}，直接计算），则对一切 t ∈ (t\_s(k), t\_s(k′)\]，k′ 必留存而 k 不必留存；候选窗域与该区间相交时可在其中区分。仅 λ\_k \< λ\_k′ 不推出 t\_s(k) \< t\_s(k′)：a = 1、ε = 1/2、λ = 2/5 与 49/100 时 t\_s 都为 0（附录 B.2 R1f）。  
证明：λ^t 关于 t 单调不增。（一）a·λ^t \> ε 的 t 构成前段，A·λ^t ≤ ε 的 t 构成后段；a ≤ A 故前段末点小于后段首点。（二）λ\_k ≤ λ\_f ⇒ A·λ\_k^t ≤ A·λ\_f^t ≤ ε（t ≥ t\_lo）；λ\_k ≥ λ\_s ⇒ a·λ\_k^t ≥ a·λ\_s^t \> ε（t ≤ t\_hi）。（三）a \> ε 故 a·λ\_k^0 = a \> ε，t = 0 时一切载体必留存；λ\_k \< 1 故 A·λ\_k^t → 0，t\_f(k) 有限，t ≥ max\_k t\_f(k)（有限个载体）时一切载体必不留存，两窗长下的必留存集合一为全体、一为空。（四）由（一），t ≤ t\_s(k′) 时 k′ 必留存，t \> t\_s(k) 时 k 不必留存；区间 (t\_s(k), t\_s(k′)\] 非空当且仅当 t\_s(k) \< t\_s(k′)。∎  
推广：自衰减不必是几何的；只要快组有单调上包络、慢组有单调下包络，证明不变。  
尾部证据：本定理的前提（几何自衰减）本身是定义 2′（丙）型的包络；由此所判的「必不留存」是完整判词。实例上只有有限记录时，须另给定义 2′ 的尾部证据才把记录读作完整，否则只用下界。  
两向性：精确钳定记录且有尾部证据时 J1 两向（定义即计算）；有读数误差 r 时，以 a·λ^t − r \> ε 判必留存、A·λ^t + r ≤ ε 判必不留存，其余 ⊥，判 1 单向可靠（同〔封十三〕13-A 的裕度结构）。  
核验：附录 B.2 R1c（λ = 1/2 与 31/32，幅度 \[1/10, 1\]，ε = 1/100，稳健窗 \[7, 72\]）；R1d（λ = 1/10 … 9/10 无谱隙，t = 2、4、8、16 四种分类互不相同）；R1d′（同一族 t = 0 时必留存 9 个、t = 44 时 0 个）；R1a（大肠杆菌代理模型：甲基化已观测下界 39 拍；尾部证据为阈下集 \|u\| ≤ 40/4096 在静置映射下正向不变，逐格核过，故完整 39 拍；活动 0 拍）；R1b（果蝇模型：γ1 位完整 29 拍，尾部证据同型；α3 位只得下界 ≥ 300 拍——τ\_W ≤ 29 时 γ1 是迹应，τ\_W \> 29 时是活动残留，区间依赖于时间窗；α3 在 τ\_W ≤ 300 时由下界正判为迹应载体）。  
引理 17-1′（随迹应而变的活动不因此成为迹应）  
设活动分量 y\_j = Φ\_j(d, s) 是拍内由迹应载体 d 与当前信号 s 决定的量。则钳定 d 时 y\_j 的自留存为 0；不钳定时，撤供后 y\_j 相对无迹史的偏离等于 Φ\_j(d, rest) − Φ\_j(d⁰, rest)，即 d 的参与效应，可以长期不为零。  
证明：钳定 d 时，撤供当拍 y\_j = Φ\_j(d, rest) 即与历史无关；不钳定时偏离式直接代入。∎  
意义：只用「撤供后是否仍偏离」判迹应，会把 CheA 活性、MBON 放电这类随迹应而变的活动误判为迹应；定义 2′ 的钳定是必需的。实物上的钳定：修饰态固定株（大肠杆菌 cheR cheB 背景，Sourjik 与 Berg 2002）、光遗传或药理钳定、流量钳定。有限记录无尾部证据时只得下界，末点越阈与否都一样（定义 2′、反例 X11；附录 B.2 R1b：γ1 位有尾部证据，完整 29 拍；α3 位只得下界 ≥ 300 拍）。  
核验：附录 B.2 R8a（大肠杆菌代理模型适应于引诱剂后撤除，A 由基态 1/2 升到 0.638——这是留存甲基化的读出，A 自身自留存为 0）。

### 5.2　深度

定理 17-2（深度序唯一；相对固定探针）  
设 δ₁、δ₂ 都在 Ω\_k 上对同一探针 p、读出 j 满足 K1、K2。则存在唯一的严格增 φ，φ(0) = 0，使 δ₂ = φ∘δ₁。  
证明：定义 φ(δ₁(w)) := δ₂(w)。良定：δ₁(w) = δ₁(w′) ⇒ e(w) = e(w′) ⇒ δ₂(w) = δ₂(w′)；严格增：δ₁(w) \< δ₁(w′) ⇒ e(w) \< e(w′) ⇒ δ₂(w) \< δ₂(w′)；φ(0) = 0 由 K1；唯一由定义式。∎ 换探针时两深度可以不同序（引理 17-3′）。  
推论 17-2a（先选数的检出）：设候选数 q 已满足 K1 且在 𝒲 下满足 K3。则 q 是相对 (p, j) 的可承担深度，当且仅当 q 与 e\_{p,j} 的序关系处处相同——严格反序、q 等而 e 异、q 异而 e 等三种冲突都不许。有一对冲突，q 就不是该探针下的深度。K1 或 K3 未过时不用本推论。核验：附录 B.2 R2a（甲基化超出量与参与效应序关系全同）；R2b（候选 \|M − 6\| 有严格反序 256 对、等号错配 16 对）。  
推论 17-2b：在 φ 下不变的陈述（每步是加深、退浅还是零变化；同元素两态谁深；是否熄灭）是对象事实；增量大小、比率、线性增长律只是所选度量的事实，须注明度量。  
定理 17-3（周期写入与申报的 K1/K3）  
若 𝒲 下的形成写入 W\_s 在 Ω\_k 中有经过基态的周期轨道 w⁰ → W\_s(w⁰) → … → W\_s^n(w⁰) = w⁰（n ≥ 2，W\_s(w⁰) ≠ w⁰），则不存在同时满足 K1 与（相对 𝒲 的）K3 的深度。  
证明：K3 沿轨道给 0 = δ(w⁰) ≤ δ(W\_s(w⁰)) ≤ … ≤ δ(W\_s^n(w⁰)) = 0，故 δ(W\_s(w⁰)) = 0，与 K1 矛盾。∎  
限定：只击穿「该载体、在 𝒲 下」的 K1/K3 组合；有留存的周期宿载可在别的载体（磨损、振子参数）或别的写入条件下有可承担深度。里程表数位轮在「只施走一格」的 𝒲 下不能作该取向元素（附录 B.2 R2c）；计数寄存器在满量程以下满足 K3，回零处不满足（R2d）。  
引理 17-3′（探针序冲突与拆分）  
若探针 p、p′ 下存在 w, w′ ∈ Ω\_k 使 e\_p(w) \< e\_p(w′) 而 e\_{p′}(w) \> e\_{p′}(w′)，则不存在对两探针都满足 K2 的深度。证明：K2 对 p 要求 δ(w) \< δ(w′)，对 p′ 要求相反。∎ 只给拆分的必要条件；只相对所列两探针（附录 B.2 R2e）。

### 5.4　历史条件与主判词

定理 17-5′（有效差异证书下的历史动力；同拍资格；两支）  
（一）若存在定义 6′ 的有效差异见证（同拍 t、同一过程 ρ、目标 x ∈ T、对照只改 t 时已留下的迹应位 U，Δ\_tot 越阈，途径与作用认证成立），则 Act(ρ, Org(T)) ∧ HistCond(ρ, T) 于拍 t 成立，从而 HDyn(χ, T)。  
（二）若另有 TraceSet(χ, T) 与 ρ 的载体在 B 内，则 Fld(χ)。

引理 17-5a（参照差分消去）  
深度按参照轨迹计时，与状态无关的分项在实际史与参照史中相同，在深度变化中相消；非信号驱动下深度的变化只由依状态的分项承担。它不推出该分项经活动中介：直读本位的有效加深同样形成实际变换。证明：Δδ\_x = Σ\_ρ \[c\_{ρ,x}(σ, u) − c\_{ρ,x}(σ\_ref, u)\]，与状态无关的项两侧相等。∎

### 5.5　周期映射

定理 17-6′（周期映射：良定、单调收敛、吸引域）

（二）F(δ₀) \< δ₀ 时迭代单调不增，收敛到 ≤ δ₀ 的最大不动点。  
（三）吸引域 B(p) 是含 p 的凸集；端点逐点由（一）（二）决定；F 为恒等时每点自成单点吸引域。  
证明：（一）F(δ₀) ≥ δ₀ 与单调性给 F^{n+1}(δ₀) ≥ F^n(δ₀)；p 为 ≥ δ₀ 的不动点时 F^n(δ₀) ≤ p ⇒ F^{n+1}(δ₀) ≤ F(p) = p；有限链上序列终于常值 q，F(q) = q，δ₀ ≤ q ≤ p，取 p 最小得 q = p；闭区间上极限 L 存在，连续性给 F(L) = L，同理 L = p。（二）对称。（三）δ₁ \< δ \< δ₂、δ₁, δ₂ ∈ B(p) 时 F^n(δ₁) ≤ F^n(δ) ≤ F^n(δ₂)，极限夹于 p。∎ 核验：附录 B.2 R0，X6。

### 5.6　连续类

定理 17-7′（连续类短拍敲除证书）  
前提：ẋ = F(x) = Σ\_m F\_m(x)，F 与 F − F\_m 在含相关轨迹段的凸集 K 上 Lipschitz，常数（最大范数）L、L′，上确界 M、M′。拍长 h；全流 φ\_h，去掉 m 的流 φ\_h^{−m}；敲除差 Δ\_m^h(s) := (φ\_h(s) − φ\_h^{−m}(s))\_t；设定 s′ = s + δe\_i，响应 R := Δ\_m^h(s′) − Δ\_m^h(s)。  
（一）一阶界：\|R − h(f\_m(s′) − f\_m(s))\| ≤ h²(LM + L′M′)。证明：对 Lipschitz 场 G（常数 L\_G、上确界 M\_G）及其流 ψ，ψ\_h(s) − s − hG(s) = ∫\_0^h (G(ψ\_τ(s)) − G(s))dτ，被积式 ≤ L\_G·\|ψ\_τ(s) − s\| ≤ L\_G M\_G τ，积分得 ≤ L\_G M\_G h²/2；故 Δ\_m^h(s) = h f\_m(s) + E₁(s) − E₂(s)，\|E₁\| ≤ LMh²/2、\|E₂\| ≤ L′M′h²/2，相减得界。∎  
（二）精确式一般不成立（反例 X5：附录 B.2 R0 以有理上下界核得 R ≈ 0.648721 \> 1/2，且 \|R − h\| ≤ 5/4 = 一阶界）。精确式的一个充分前件：目标坐标上其余过程的速率不依目标坐标及受 m 影响的坐标（三角结构），且配对流中其余目标速率之差的积分为零；f\_m 沿不漂移的迹应为常值时 R = h(f\_m(s′) − f\_m(s))（R6b）。  
（三）误差分开预算：四个原始流读数各 ≤ r\_φ；两个敲除差各 ≤ 2r\_φ；最终响应读数误差 ≤ 4r\_φ；模型误差 ≤ h²(LM + L′M′)。判 1 规则 \|R\_obs\| \> h²(LM + L′M′) + 4r\_φ ⇒ f\_m(s′) ≠ f\_m(s)（有限差异支持，可靠；附录 B.2 R6a：随机 3000 例模型误差越界 0，判 1 者无一有限差异为 0）。  
（四）微分支持：开线段 (s, s′) 上可微 ⇒ 某内点偏导非零；另有 SD\_i 于含 s 的 Ω\_i ⇒ s 处偏导非零。Lipschitz 不给可微。  
（五）极限完备：记 K := LM + L′M′。f\_m(s′) ≠ f\_m(s) 时：K = 0 且读数误差为零，对一切 h 判 1；K \> 0 时，读数误差足够小即存在 h 使判 1。有限差异为 0 时不求阈（R6c，不作除法）。  
（六）读回：即使读到偏导，仍须窗内分项有效、i 为可用位与途径（IMP-c）；HC^c 维持候选读法；读回 HistCond 时按定义 6′ 另取有效差异，或按注 6′-1 只记函数支持。

E17-1　三分：钳定不完全（其余载体在钳定中漂移）使活动的自留存被高估。界：漂移幅度 η 下，自留存判据以 a·λ^t − η \> ε 判必留存才可靠；未报 η 判 ⊥\_Clamp。  
E17-2　三分：窗长取在稳健窗外，同一载体在两份报告中分属不同类。界：定理 17-1（二）的窗端点；窗外判词须携带 τ\_W。  
E17-3　深度：探针类过窄，隐位被判为基态（K2 失败未察）。界：只对所申报的探针类成立；换探针显出者另判。  
E17-4　深度：多状态载体未拆分，深度在不同探针下反序。界：引理 17-3′ 的冲突检验覆盖所测探针；未测探针下的冲突不在界内。  
E17-5　集合：边认证不足而把一个组织判为两个（误分）。实测不作分离判词，故此误判只在模型模式出现，且由过程与活动清单不完备承担（击穿的是清单申报）。  
E17-6　集合：子组织的边界条件未申报，把对象的一部分当作整体。界：子组织是另一判定实例，判词不推及整体。  
E17-7　SED：可达史类申报过窄而漏报加深状态（误排）；过宽而包含不可达状态（误收）。界：判词携带 𝓗\_R；SED\_W 只用实际发生的状态。  
E17-8　SED：两支不可分（无活动钳定）时把直读加深误作活动中介加深。界：判 ⊥\_Br，不判 1。  
E17-9　连续类：Lipschitz 常数或上确界低报。界：定理 17-7′ 只在所报常数为真时可靠；常数申报不属实击穿的是申报。  
E17-10　跨记录链：C1—C5 的申报不属实（光遗传驱动不等于生理放电；范围未覆盖）。界：判词只到 B 栏条件结论，携带 C1—C5。  
E17-11　区间：有限格上的不动点由取格产生（数值伪不动点）。界：程序中的取格是申报模型的一部分，结论对该模型精确；对连续模型以解析阈值为准（如 δ\_c = 1/3）。  
E17-12　有限记录无尾部证据而写成完整自留存，末点越阈或不越阈皆然（X11）；或由下界签活动、残留或非迹应。界：只记下界；下界 ≥ τ\_W 可正判迹应载体，下界 \< τ\_W 判 ⊥\_Tail（定义 2′）。

　未钳定的撤供偏离与随迹应而变的活动不读作迹应；自留存下界不读作完整自留存；有限记录末点不越阈不读作完整自留存；下界不读作活动、活动残留或非迹应。  
　单支变化不读作总差；某一次序的两支分项不读作唯一责任分摊；混合状态未可施时两支不读作物质事实。  
　候选不读作元素；反向候选不计入原取向。

### 8.0　读法

每例三段：识别 → 进入已有判据或补充途径 → 判断。判断三栏分立：A 栏为申报模型（附录 A.2，本篇构造的最小模型，参数为构造值）的模型模式判词，先报主判词（〔封一〕Fld，取值 1／0／⊥），再报可选台账；B 栏为真实宿载的条件结论与条件预测，逐项列实证前件；C 栏为实证认证。跨记录链逐项给出 C1—C6 的出处、同一对象与两态、时序与效应预算；证据层分开写。模型只承担「判据能否用于对象」的检验，不承担对象事实。真实大肠杆菌、果蝇、管网与河床的判断都随各自的实证前件；程序核验只在 A 栏，不升级为物质认证。

### 8.1　大肠杆菌趋化（非神经；甲基化是迹应，CheA 活性是活动，受体簇是组织）

（一）识别  
信号：胞外配体浓度改变（MeAsp 或天冬氨酸对 Tar，丝氨酸对 Tsr），自 B（细胞）之外作用于受体的配体结合域（Sourjik 与 Berg 2002）。  
介质与载体：化学感受受体阵列（Tar、Tsr 与 CheA、CheW 成簇）；载体为每一受体分子上的可甲基化谷氨酸位点。  
留下的改变：位点甲基化。【事实】加入引诱剂后甲基化在数分钟内升至新水平，增幅随刺激增大，引诱剂在场时维持，移除后迅速回落（Goy、Springer 与 Adler 1977，摘要）；修饰态固定株的剂量—响应随修饰态单调移动，Tar 分量 K\_D 自 38 µM（EEEE）至 440 µM（QEQQ）（Sourjik 与 Berg 2002）。  
三分（J1）：CheA 活性为活动——修饰态钳定（cheR cheB 背景）时活性随配体阶跃在溶液交换时间内响应（交换 90% \< 4 s，CheY-P 半衰期约零点几秒，Sourjik 与 Berg 2002，【事实】）；甲基化为迹应载体——自弛豫 τ\_a 约 29 s（22 °C）、11 s（32 °C）（Shimizu、Tu 与 Berg 2010，由 FRET 动力学经模型推得，【已发表模型】）；CheB 的磷酸化态为活动残留（Clausznitzer 等 2010）；受体与酶的表达量、簇几何为背景。引诱剂持续时甲基化的维持是「保持」（CheR 与 CheB 分项相抵，有作用承担，〔封一〕第三节），不是活动。代理模型：甲基化自留存完整 39 拍（尾部证据为正向不变阈下集）、活性 0 拍（附录 B.2 R1a）；撤除响应 A = 0.638 \> 1/2（R8a），是留存甲基化的读出。  
深度（J2）：相对探针「配体阶跃下的活性偏移」与写入条件「同一引诱剂阶跃的重复」签署。在已发表 MWC 模型的位点权重差下（Shimizu、Tu 与 Berg 2010：E 修饰效应约为 Q 的 2.5 倍，【已发表模型】），与自由能偏移同序的是按位点权重加权的甲基化；未加权的位点个数可与之等号错配（推论 17-2a 的适用情形）。代理模型同序（附录 B.2 R2a）。退浅：去甲基化回到适应基线，撤除响应消失即迹应现象不发生；去酰胺（Q → E）是另一类不可逆改变，属背景。  
组织（J4）：同簇受体共享一个活性，簇间经 CheY-P 池共同参与（【已发表模型】【机制假设】）；代理模型在全部联合设定上枚举，Tar、Tsr 两类修饰位为一个分量；适应串扰——设定 Tar 位改变 Tsr 位 CheR 的总分项，只经活动（附录 B.2 R8c）。元素物理同一：同一受体分子上的同一位点，W 内周转可忽略（【不足：观察不足】，持存未直接标记）。  
再作用：CheR 偏好失活受体、CheB-P 偏好激活受体，修饰速率依活性；又依可修饰位点数（直读）（Shimizu、Tu 与 Berg 2010；Meir 等 2010；Clausznitzer 等 2010）。代理模型 CheR@mTar，T 设回基态：沿「先活动后直读」次序 A = 0.002544、D = 0.022512 同号，总差 0.025056 \> ε = 1/1000，有效差异已获证（附录 B.2 R8b）。

三分（J1）：同一载体（管径）上叠着活动与迹应：周期收缩约 1—2 min（Marbach 等 2023）是活动成分，收缩周期平均的管径是迹应成分；按定理 17-1 以谱分解区分（快模式为蠕动振荡，慢模式为适应时间 t\_adapt 约 10—100 min，Marbach 等 2023），窗长取在二者之间。胞质流、压力、剪切是活动；感受剪切的时滞（1—3 min）是活动残留；软化剂（Kramar 与 Alim 2021 的机制假设）是被平流输运的活动或残留。基线随收缩漂移，深度须以参照轨迹（无刺激的同一网络或假刺激对照）计，否则 ⊥\_Ref（定义 1）。  
深度（J2）：参与效应为管段在探针泵送下所载流量相对参照的改变；其余网络固定时，单管流量可写为 Q\_x = V\_eq/(1/g\_x + R\_net)（V\_eq、R\_net 为其余网络对该管两端的等效驱动与等效阻力），R\_net 有限时关于本管导率 g\_x 严格增，K2 成立。K3：近处重复刺激使管径增大至上限（半径 5—70 µm，Marbach 等 2023）。退浅极限：管段消失（Marbach 等 2023）——熄灭伴随载体消失与拓扑改变，与突触效能回到基线而突触仍在不同。  
集合（J4）：Kirchhoff 守恒使连通网络中一切管段的流量同依各管导率，故一个变形体的管网是一个组织分量（附录 B.2 R3d：正向候选 02、13、23 一个分量；变细的 01 为反向候选，单列）。元素身份：管段因邻管消失而并为长管（Marbach 等 2023），按引理 17-4′ 以全窗共同细分为表示单元，并合是组织（路径）的改变；管段物质的同一另须连续成像依据。  
活动与再作用：势为网络对泵送与刺激的流量分配，单管所受之势由其余网络的等效阻力 R\_net 与局部压力承担（Marbach 等 2023，【已发表模型】）；再作用为剪切驱动的管径适应，带 1—3 min 时滞；一管消失经 R\_net 改变使邻管失稳（雪崩）。  
（二）进入已有判据或补充途径  
〔封三〕实例乙：判 ⊥\_Obs／⊥\_Prof，律不属 F 类（U9）；直接应用，照登记。  
〔封十一〕：连续类，类外（其 8.2-02a）。

### 8.4　滩面凹痕与河床（非神经；区间依赖）

（一）识别  
信号：踩踏（脚印）或一次冲刷事件；河床：来水来沙事件（自 B 外）。介质与载体：床面沉积物；载体为床面网格的高程相对参照面（无此信号史时的周围滩面或参照地形）。迹应：凹陷深度；河床上的河道地形，特别是已废弃而未充填的河道（Reitz、Jerolmack 与 Swenson 2010，摘要；Martin 与 Edmonds 2022 的模型：废弃河道既可排斥也可吸引流动）。【事实】改道前河道内淤积达阈值 h\* ≈ 0.3 h\_c（Ganti 等 2016）。  
三分：水流、悬沙为活动（秒至分钟）；床面高程为迹应（潮次至年）；谱隙大。深度：参与效应为凹陷在探针水流下所汇的额外流量，关于深度单调（模型 q = q0(1 + κδ)），K2 成立；K3：重复踩踏使之加深。集合：同一排水范围内的凹陷经分流共同参与，为一个分量；扇面上的河道经分汊处的流量分配共同参与（〔封十六〕Φ15）。  
活动与再作用：水汇入凹处（参与），流经凹处的水冲深或淤平它（再作用），符号由区间决定（《沉积场定义》v1.1 检验一）。  
（二）进入已有判据或补充途径  
〔封三〕：律不属 F 类；〔封十一〕：连续输运加阈值改道，合同外（其 8.2-12）；〔封十三〕：无实例级条款。缺口：区间依赖与可沉积性在上游无原子。补充：定义 7′ 的可选台账与定理 17-6′（周期映射）。  
（三）判断  
A 栏（附录 B.2 R4）：冲刷区间、混合区间（单脚印与双脚印）、淤积区间的凹痕，Fld 都为 1（有效差异分别由冲刷或淤积分项经汇流承担）。  
可选台账：冲刷区间与混合区间双脚印：SED\_W = SED\_R = SED⁺ = 1、净加深 = 1；混合区间单脚印（1/4）：SED 0、净加深 0；淤积区间：SED 0、净加深 0。  
三种阈分报（附录 B.2 R5）：逐拍未取格零点 δ = 1/3；带格周期阈值 171/512 ≈ 0.333984；饱和点 4；测试链上 B(0) 上端 5/16、B(4) 下端 11/32。周期映射良定（R5e）。  
B 栏【条件结论】：在申报含沙量 c 与起冲流量 q\_c 下，凹痕的 Fld 由迹应所汇流量对它的冲淤承担，各区间都可成立；周期累积台账为 1 当且仅当实际深度处于该区间周期映射的加深侧。真实滩面与河床的这一判断随含沙量、流量、参照面与床面测量的实证前件。  
C 栏：⊥。  
【预测】  
　PR-1（水槽：深度阈）：在受控片流与含沙量下预刻分级深度的凹陷，存在临界深度 δ\_c：浅于者淤平、深于者冲深成沟；δ\_c 随含沙量增大而增大、随流强增大而减小；纯淤积条件（高含沙、低流速）下无深度能加深。击穿：淤积条件下浅凹加深，或混合条件下无阈值结构。  
　PR-2（扇面植入与擦除，承 Reitz、Jerolmack 与 Swenson 2010）：冲刷捕获区间中植入深于 δ\_c 的河道使其重占概率上升，充填废弃河道使之下降；淤积愈合区间中植入河道在重占前即被填平。击穿：两区间中植入与充填的效应同号。  
　PR-3（单调性）：孤立凹陷在重复潮次下深度序列单调（不振荡）；观测到振荡则单元约化不成立，须以相邻凹陷的多元素映射研究。  
　注：PR-1 的「临界深度」指周期映射加深侧的下界，报告时注明是逐拍零点还是周期阈值（定义 8′）。  
三层登记：理论条件——周期映射与台账的区间结论；可检验预测——PR-1 至 PR-3；现实未定——扇面重占统计（Reitz、Jerolmack 与 Swenson 2010 与 Ganti 等 2016 的结论有冲突）、愈合方式的实测。

~~~python
"""《具化场识别判定式》v1.0 附录程序：核心库。
只用 Python 标准库；数值一律 fractions.Fraction。宿载模型的接口：X（位）、lo/hi（夹限）、ground（无迹基态）、
orient（申报取向）、init、grid（取格）、act(w, s)（活动）、comps(w, y, s)（分项列表 (过程, 位, 值)）。
  branches          两支分报：A 支（只换活动）、D 支（活动换后再改直读），A + D = 总差（按未钳定机制重算）。
  branches_rev      另一次序的望远镜分解（先改直读，再换活动）。
  hc_total          差异读法：存在合法设定使总分项差 > ε（不限可用位；只作对照）。
  avail_at          拍前态中已越阈的承担位（定义 6′(乙) 的数值部分）。
  hc_status         有效差异证书的三种判值：有效差异已获证／函数支持已立／有效差异未获证。
  hdyn_cert         同拍、同一过程上的 Act 与有效差异（定义 6′、定义 7′ 的模型模式）。
  sed               活动中介正分项（可选加强台账）；plus 为 SED⁺。
  net_deep          实际净加深（另一台账）。
  trace_candidates  迹应候选筛查（取向深度 > ε 与 < −ε 分列；不是元素证书）。
  retention         自留存：已观测下界与完整判词分开；完整须显式尾部证据（定义 2′）。
  triage            按下界、完整与否和申报 τ_act、τ_W 给三分判词；只有下界且不足 τ_W 时判 ⊥_Tail。
  org_graph_exact   在申报的全部联合设定上精确枚举（含超边）。
  org_graph_sample  有界采样：只报见证边与覆盖缺口。
  basins            有限链上映射的吸引域（按「极限等于该不动点」的原像）。
"""
from fractions import Fraction as Fr
from itertools import combinations
import math
ZERO = Fr(0)
FRACS = (Fr(0), Fr(1, 2), Fr(2))

def floor_grid(x, G):
    return Fr(math.floor(x * G), G)

class Host:
    name = 'host'
    grid = None
    def step(self, w, s):
        y = self.act(w, s)
        new = dict(w)
        for (_p, x, c) in self.comps(w, y, s):
            new[x] = new[x] + c
        for x in self.X:
            v = min(self.hi[x], max(self.lo[x], new[x]))
            if self.grid is not None:
                v = floor_grid(v, self.grid)
            new[x] = v
        return new

def run(host, w0, hist):
    out, w = [dict(w0)], dict(w0)
    for s in hist:
        w = host.step(w, s)
        out.append(w)
    return out

def ref_hist(host, hist):
    return ['rest' for _ in hist]

def depth(host, w, x):
    """取向深度（带号）：正值为申报取向上的迹应，负值为越过基态的另一型。"""
    return host.orient[x] * (w[x] - host.ground[x])

def trace_candidates(host, hist, eps):
    """候选筛查（不是元素证书）。返回 (轨迹, 参照轨迹, 正向候选, 反向候选, 信号形成位)。"""
    S = run(host, host.init, hist)
    R = run(host, host.init, ref_hist(host, hist))
    w, wr = S[-1], R[-1]
    pos = [x for x in host.X if depth(host, w, x) > eps]
    neg = [x for x in host.X if depth(host, w, x) < -eps]
    sig = [x for x in host.X if abs(w[x] - wr[x]) > eps]
    return S, R, pos, neg, sig

def retention(seq, eps, tail=None):
    """自留存（定义 2′）。返回 (下界, 判别)；下界 = 记录中最后一个 |u| > eps 的 t 加一（无越阈为 0）。
    判别为 '完整' 当且仅当给出并核过尾部证据，否则为 '下界'——记录末点越阈与否都一样：
    末点不越阈不排除此后静置中再越阈。tail 取以下之一：
      ('覆盖',)                记录已覆盖余下的全部静置域（申报，函数不代证）；
      ('不变集', step, band)   band 为阈下集的全部点（|u| ≤ eps），step 为静置一步映射；
                               须记录末点在 band 中且 step(band) ⊆ band（逐点精确核）；
      ('包络', C, lam)         已证 |u(t_end + s)| ≤ C·lam^s（s ≥ 0），0 ≤ lam < 1；须 C ≤ eps。"""
    last = 0
    for t, v in enumerate(seq):
        if abs(v) > eps:
            last = t + 1
    if tail is None or not seq:
        return last, '下界'
    kind = tail[0]
    ok = False
    if kind == '覆盖':
        ok = True
    elif kind == '不变集':
        step, band = tail[1], set(tail[2])
        ok = (seq[-1] in band and all(abs(u) <= eps for u in band)
              and all(step(u) in band for u in band))
    elif kind == '包络':
        C, lam = tail[1], tail[2]
        ok = 0 <= lam < 1 and C <= eps and abs(seq[-1]) <= C
    return last, ('完整' if ok else '下界')

def triage(lb, status, tau_act, tau_W):
    """可被写入的载体的三分判词（定义 2′）：下界 ≥ τ_W 即迹应载体；活动与活动残留须完整自留存；
    只有下界而下界 < τ_W 时判 ⊥_Tail（不签活动、残留或非迹应）。"""
    if lb >= tau_W:
        return '迹应载体'
    if status != '完整':
        return '⊥_Tail'
    return '活动' if lb <= tau_act else '活动残留'

def setv(host, w, vals):
    v = dict(w)
    for x, val in vals.items():
        v[x] = min(host.hi[x], max(host.lo[x], val))
    return v

def setT(host, w, T, frac=Fr(0)):
    return setv(host, w, {x: host.ground[x] + frac * (w[x] - host.ground[x]) for x in T})

def comp_of(host, w, y, s, proc, x):
    tot = ZERO
    for (p, xx, c) in host.comps(w, y, s):
        if p == proc and xx == x:
            tot += c
    return tot

def total_comp(host, w, s, proc, x):
    return comp_of(host, w, host.act(w, s), s, proc, x)

def branches(host, w, w2, s, proc, x):
    """两支分报（对照 w2 为合法设定后的状态）。A = c(w 直读, y(w2)) − c(w 直读, y(w))；
    D = c(w2 直读, y(w2)) − c(w 直读, y(w2))；A + D = 总差 = c(w2) − c(w)（按未钳定机制重算）。"""
    y, y2 = host.act(w, s), host.act(w2, s)
    c0 = comp_of(host, w, y, s, proc, x)
    cA = comp_of(host, w, y2, s, proc, x)
    c2 = comp_of(host, w2, y2, s, proc, x)
    return cA - c0, c2 - cA, c2 - c0

def settings(host, w, T, fracs=FRACS, joint=True):
    """申报的合法设定族：T 的每一非空子集（joint=True）或单位与全体（joint=False）乘以深度倍数。"""
    T = list(T)
    subs = []
    if joint:
        for k in range(1, len(T) + 1):
            subs += [list(c) for c in combinations(T, k)]
    else:
        subs = [[x] for x in T] + ([T] if len(T) > 1 else [])
    out = []
    for U in subs:
        for f in fracs:
            w2 = setT(host, w, U, f)
            if w2 != w:
                out.append((tuple(U), f, w2))
    return out

def hc_total(host, w, s, proc, x, T, eps, fracs=FRACS, joint=True):
    """历史条件的差异读法：存在合法设定使总分项差 > eps。返回 (U, f, A, D, 总差) 或 None。"""
    for (U, f, w2) in settings(host, w, T, fracs, joint):
        A, D, tot = branches(host, w, w2, s, proc, x)
        if abs(tot) > eps:
            return (U, f, A, D, tot)
    return None

def part(host, w, T, probes, eps, fracs=FRACS):
    for s in probes:
        y0 = host.act(w, s)
        for (U, f, w2) in settings(host, w, T, fracs, joint=False):
            y1 = host.act(w2, s)
            for j in y0:
                if abs(y0[j] - y1[j]) > eps:
                    return (s, j, y0[j], y1[j])
    return None

def hdyn(host, states, sigs, T, eps, fracs=FRACS):
    """对照用：窗内某拍过程 p 对 x ∈ T 的分项有效，且总分项差在 T 的某合法设定下有效（不限可用位）。"""
    for k, s in enumerate(sigs):
        w = states[k]
        y = host.act(w, s)
        seen = set()
        for (p, x, c) in host.comps(w, y, s):
            if x not in T or (p, x) in seen:
                continue
            seen.add((p, x))
            c = comp_of(host, w, y, s, p, x)
            if abs(c) <= eps:
                continue
            h = hc_total(host, w, s, p, x, T, eps, fracs)
            if h:
                return (k, s, p, x, c) + h
    return None

def sed(host, reach, T, eps, plus=False, fracs=FRACS):
    """活动中介正分项（可选加强台账）：(甲) 取向分项 > eps；(乙) 同一设定上总差有效且 A 支有效。
    plus：另要求把整个 T 按各 frac < 1 设浅都使取向分项严格变小（自增强台账；不是对一切子集的全称）。"""
    for (w, s) in reach:
        y = host.act(w, s)
        for (p, x, c) in host.comps(w, y, s):
            if x not in T:
                continue
            c = comp_of(host, w, y, s, p, x)
            if host.orient[x] * c <= eps:
                continue
            ok = False
            for (U, f, w2) in settings(host, w, T, fracs):
                A, D, tot = branches(host, w, w2, s, p, x)
                if abs(tot) > eps and abs(A) > eps:
                    ok = True
                    break
            if not ok:
                continue
            if not plus:
                return (s, p, x, c)
            good = True
            for f_ in [f_ for f_ in fracs if f_ < 1]:
                w2 = setT(host, w, T, f_)
                if not host.orient[x] * total_comp(host, w2, s, p, x) < host.orient[x] * c:
                    good = False
                    break
            if good:
                return (s, p, x, c)
    return None

def net_deep(host, w, protocol, T, eps):
    """实际净加深：施协议后 T 中某位取向深度之增 > eps。返回 [(x, 前, 后)]。"""
    w2 = dict(w)
    for s in protocol:
        w2 = host.step(w2, s)
    return [(x, depth(host, w, x), depth(host, w2, x)) for x in T if depth(host, w2, x) - depth(host, w, x) > eps]

def reach_pairs(host, hists):
    out = []
    for h in hists:
        S = run(host, host.init, h)
        for k, s in enumerate(h):
            out.append((S[k], s))
    return out

class UF:
    def __init__(self, items):
        self.p = {i: i for i in items}
    def f(self, i):
        while self.p[i] != i:
            self.p[i] = self.p[self.p[i]]
            i = self.p[i]
        return i
    def u(self, a, b):
        ra, rb = self.f(a), self.f(b)
        if ra != rb:
            self.p[rb] = ra

def _act_dep(host, w, w2, s, eps):
    y0, y1 = host.act(w, s), host.act(w2, s)
    return [j for j in y0 if abs(y0[j] - y1[j]) > eps]

def org_graph_exact(host, w, E, probes, eps, fracs=FRACS):
    """精确枚举：在 E 的全部非空子集 × 深度倍数（申报的联合设定族）上求依赖。
    共同参与超边：使活动分量 j 改变的极小子集 U（|U| ≥ 2 时为超边，|U| = 1 时并入同一 j 的单位依赖群）。
    历史条件超边：使作用于 x 的总分项改变的极小子集 U，连同 x。返回 (超边列表, 分支)。"""
    E = list(E)
    hyper = set()
    for s in probes:
        y0 = host.act(w, s)
        changed = {}
        for (U, f, w2) in settings(host, w, E, fracs, joint=True):
            for j in _act_dep(host, w, w2, s, eps):
                changed.setdefault(('act', j), set()).add(U)
            for (p, x, c) in host.comps(w, y0, s):
                if x not in E:
                    continue
                tot = total_comp(host, w2, s, p, x) - comp_of(host, w, y0, s, p, x)
                if abs(tot) > eps:
                    changed.setdefault(('w', p, x), set()).add(U)
        for key, Us in changed.items():
            mins = [U for U in Us if not any(set(V) < set(U) for V in Us)]
            if key[0] == 'act':
                singles = sorted({U[0] for U in mins if len(U) == 1})
                if len(singles) >= 2:
                    hyper.add(('共同参与', key[1], tuple(singles)))
                for U in mins:
                    if len(U) >= 2:
                        hyper.add(('共同参与', key[1], tuple(sorted(U))))
            else:
                x = key[2]
                for U in mins:
                    nodes = tuple(sorted(set(U) | {x}))
                    if len(nodes) >= 2:
                        hyper.add(('历史条件', key[1] + '@' + x, nodes))
    uf = UF(E)
    for (_k, _n, nodes) in hyper:
        for a in nodes[1:]:
            uf.u(nodes[0], a)
    comps = {}
    for i in E:
        comps.setdefault(uf.f(i), []).append(i)
    return sorted(hyper), sorted([sorted(v) for v in comps.values()])

def org_graph_sample(host, w, E, probes, eps, tested, fracs=FRACS):
    """有界采样：只在 tested（子集列表）上设定。返回 (见证超边, 覆盖缺口：未被任何已测子集共同覆盖的位对；被覆盖也不等于已识别)。"""
    hyper = set()
    for s in probes:
        y0 = host.act(w, s)
        for U in tested:
            for f in fracs:
                w2 = setT(host, w, U, f)
                if w2 == w:
                    continue
                for j in _act_dep(host, w, w2, s, eps):
                    hyper.add(('共同参与', j, tuple(sorted(U))))
                for (p, x, c) in host.comps(w, y0, s):
                    if x in E and abs(total_comp(host, w2, s, p, x) - comp_of(host, w, y0, s, p, x)) > eps:
                        hyper.add(('历史条件', p + '@' + x, tuple(sorted(set(U) | {x}))))
    covered = set()
    for U in tested:
        for a in U:
            for b in U:
                covered.add((a, b))
    unknown = [(a, b) for a, b in combinations(sorted(E), 2) if (a, b) not in covered]
    return sorted(hyper), unknown

def basins(F, chain):
    """有限全序链 chain 上的映射 F（dict）。返回 {不动点: [其吸引域（极限等于该点的原像）]}。"""
    out = {}
    for d in chain:
        x, seen = d, set()
        while F[x] != x:
            if x in seen:
                x = None
                break
            seen.add(x)
            x = F[x]
        out.setdefault(x, []).append(d)
    return out

def order_rel(a1, a2):
    return (a1 > a2) - (a1 < a2)

def order_conflicts(pairs):
    """返回 q 与 e 的序关系不一致的点对（含等号错配两个方向）。"""
    bad = []
    for i in range(len(pairs)):
        for j in range(i + 1, len(pairs)):
            (q1, e1), (q2, e2) = pairs[i], pairs[j]
            if order_rel(q1, q2) != order_rel(e1, e2):
                bad.append((pairs[i], pairs[j]))
    return bad

def fstr(x):
    if isinstance(x, Fr):

    return str(x)

def avail_at(host, states, k, T, eps, k_form=None):
    """拍 k 的可用承担位：拍 k 的拍前态 states[k] 中取向深度 > eps 的 T 中位。
    states[k] 是此前各拍写入的结果，故其越阈意味着在拍 k 之前已留下；若越阈始自 states[0]（起点即越阈），
    其形成须另有记录（〔封三〕ENT 的对应物），本函数不代证；程序在此只验数值上的「已留下」。
    T 的窗末成员身份不用于此判断。"""
    return [x for x in T if depth(host, states[k], x) > eps]

def hc_status(host, w, s, proc, x, U_av, eps, fracs=FRACS):
    """历史条件在一拍一过程上的三种判值（只改可用位 U_av 的合法设定族，含联合设定）：
    '有效差异已获证'：某设定使总分项差 > eps；'函数支持已立'：某设定使总分项差 ≠ 0 而无一 > eps；
    '有效差异未获证'：所测设定族内总分项差恒为 0（这只是有限设定族内的读数，不是完整否定）。"""
    best = None
    nonzero = False
    for (U, f, w2) in settings(host, w, U_av, fracs, joint=True):
        A, D, tot = branches(host, w, w2, s, proc, x)
        if abs(tot) > eps:
            return '有效差异已获证', (U, f, A, D, tot)
        if tot != 0:
            nonzero = True
            best = (U, f, A, D, tot)
    if nonzero:
        return '函数支持已立', best
    return '有效差异未获证', None

def hdyn_cert(host, states, sigs, T, eps, fracs=FRACS):
    """同拍、同一过程上的 Act 与历史差异：Act = 该拍该过程在 x ∈ T 上的总分项 |c| > eps；
    设定只改该拍的可用承担位（avail_at）。返回 (判值, 见证)；判值 ∈ {'1', '函数支持已立', '未获证'}。
    本函数只验模型的结构依赖与数值差（模型模式）；实际物质途径与作用认证另由申报承担。"""
    status = '未获证'
    wit = None
    for k, s in enumerate(sigs):
        w = states[k]
        Uav = avail_at(host, states, k, T, eps)
        if not Uav:
            continue
        y = host.act(w, s)
        seen = set()
        for (p, x, _c) in host.comps(w, y, s):
            if x not in T or (p, x) in seen:
                continue
            seen.add((p, x))
            c = comp_of(host, w, y, s, p, x)
            if abs(c) <= eps:
                continue
            st, wt = hc_status(host, w, s, p, x, Uav, eps, fracs)
            if st == '有效差异已获证':
                return '1', (k, s, p, x, c, Uav) + wt
            if st == '函数支持已立' and status == '未获证':
                status, wit = '函数支持已立', (k, s, p, x, c, Uav) + wt
    return status, wit

def branches_rev(host, w, w2, s, proc, x):
    """另一申报次序的望远镜分解：先改直读（活动保持原值），再换活动。返回 (D″, A″, 总差)。"""
    y, y2 = host.act(w, s), host.act(w2, s)
    c0 = comp_of(host, w, y, s, proc, x)
    cD = comp_of(host, w2, y, s, proc, x)
    c2 = comp_of(host, w2, y2, s, proc, x)
    return cD - c0, c2 - cD, c2 - c0
~~~

~~~python
def solve(A, b):
    """有理高斯消元。"""
    n = len(A)
    M = [list(A[i]) + [b[i]] for i in range(n)]
    for c in range(n):
        piv = next(r for r in range(c, n) if M[r][c] != 0)
        M[c], M[piv] = M[piv], M[c]
        pv = M[c][c]
        M[c] = [v / pv for v in M[c]]
        for r in range(n):
            if r != c and M[r][c] != 0:
                fct = M[r][c]
                M[r] = [M[r][k] - fct * M[c][k] for k in range(n + 1)]
    return [M[i][n] for i in range(n)]

class Ecoli(Host):
    """活性代理 A = M²/(M² + K²·Rt·Rs)，M = mTar + mTsr，R(L) = ((1+L)/(1+L/50))²。
    分项：CheR_i = h·kR·(1 − A)·(4 − m_i)/4（加深），CheB_i = −h·kB·A·m_i/4（退浅）。
    无迹基态 m = 2、2（A = 1/2，静置下不动）。kR = 0 为 cheR 缺失变体。"""
    def __init__(self, kR=F(1), kB=F(1), h=F(1, 4), K=F(4), grid=4096):
        self.name = 'Ecoli' if kR != 0 else 'Ecoli_cheR-'
        self.X = ['mTar', 'mTsr']
        self.lo = {x: F(0) for x in self.X}
        self.hi = {x: F(4) for x in self.X}
        self.orient = {x: 1 for x in self.X}
        self.kR, self.kB, self.h, self.K, self.grid = kR, kB, h, K, grid
        if kR != 0:
            g = {'mTar': F(2), 'mTsr': F(2)}
        else:
            g = {'mTar': F(0), 'mTsr': F(0)}
        self.ground = dict(g)
        self.init = dict(g)
        self.signals = ['rest', 'Ltar', 'Ltsr', 'Ltar3']
    @staticmethod
    def R(L):
        return ((1 + L) / (1 + L / 50)) ** 2
    def lig(self, s):
        return {'rest': (F(0), F(0)), 'Ltar': (F(1), F(0)), 'Ltsr': (F(0), F(1)),
                'Ltar3': (F(3), F(0))}[s]
    def act(self, w, s):
        Lt, Ls = self.lig(s)
        M = w['mTar'] + w['mTsr']
        A = M * M / (M * M + self.K ** 2 * self.R(Lt) * self.R(Ls))
        return {'A': A}
    def comps(self, w, y, s):
        A = y['A']
        out = []
        for x in self.X:
            out.append(('CheR', x, self.h * self.kR * (1 - A) * (4 - w[x]) / 4))
            out.append(('CheB', x, -self.h * self.kB * A * w[x] / 4))
        return out

class Fly(Host):
    """KC 0..3；K(A) = {0,1}，K(B) = {2,3}（overlap=True 时 K(B) = {1,2}）。
    γ1 位 g_i、α3 位 a_i 的深度 = 压抑比例 ∈ [0,1]。
    活动：MBON_g = Σ_{K(s)} (1 − g_i)；DAN_g = 电击 + fb·(|K(s)| − MBON_g)（fb 只在变体 gfb）；
          PPL1_a3 = 电击 + (−a + b·Σ_{K(s)} g_i)（有气味时）；MBON_a3 = Σ_{K(s)} (1 − a_i)。
    分项：Wg_i = η_g·DAN_g（KC 激活时），Rg_i = −ρ_g·g_i（每拍），Wa_i = η_a·PPL1_a3（KC 激活时，带符号）。
    变体：full（γ1 ∪ α3）、gonly（只 γ1，前馈）、gfb（只 γ1，加 MBON-γ1pedc → PPL1-γ1pedc 去抑制）。"""
    def __init__(self, variant='full', overlap=False, grid=4096):
        self.name = 'Fly_' + variant + ('_ov' if overlap else '')
        self.variant = variant
        self.KA = [0, 1]
        self.KB = [1, 2] if overlap else [2, 3]
        self.X = ['g0', 'g1', 'g2', 'g3']
        if variant == 'full':
            self.X += ['a0', 'a1', 'a2', 'a3']
        self.lo = {x: F(0) for x in self.X}
        self.hi = {x: F(1) for x in self.X}
        self.orient = {x: 1 for x in self.X}
        self.ground = {x: F(0) for x in self.X}
        self.init = dict(self.ground)
        self.grid = grid
        self.eta_g, self.rho_g, self.eta_a = F(1, 2), F(1, 8), F(1, 4)
        self.a, self.b, self.fb = F(1, 2), F(1), F(1, 2)
        self.signals = ['rest', 'A+', 'B+', 'A', 'B']
    def K(self, s):
        if s.startswith('A'):
            return self.KA
        if s.startswith('B'):
            return self.KB
        return []
    def act(self, w, s):
        K = self.K(s)
        shock = F(1) if s.endswith('+') else F(0)
        odor = len(K) > 0
        mg = sum((1 - w['g%d' % i] for i in K), F(0))
        dang = shock
        if self.variant == 'gfb' and odor:
            dang = shock + self.fb * (len(K) - mg)
        y = {'MBON_g': mg, 'DAN_g': dang}
        if self.variant == 'full':
            p = shock + ((-self.a + self.b * sum((w['g%d' % i] for i in K), F(0))) if odor else F(0))
            y['PPL1_a3'] = p
            y['MBON_a3'] = sum((1 - w['a%d' % i] for i in K), F(0))
        return y
    def comps(self, w, y, s):
        K = self.K(s)
        out = []
        for i in range(4):
            g = 'g%d' % i
            if i in K:
                out.append(('Wg', g, self.eta_g * y['DAN_g']))
            out.append(('Rg', g, -self.rho_g * w[g]))
            if self.variant == 'full' and i in K:
                out.append(('Wa', 'a%d' % i, self.eta_a * y['PPL1_a3']))
        return out

class Physarum(Host):
    """结点 0（泵送入口，注入 1）、1、2、3（汇，压力 0）；管 01、02、13、23、12，长度 1、2、2、1、1。
    流量 Q_e = (D_e/ℓ_e)(p_u − p_v)。信号 N1：结点 1 另注入 1/2（营养刺激），汇点吸收全部。
    分项：grow_e = h·κ·Q²/(q0² + Q²)（活动中介），decay_e = −h·γ·D_e（直读本位）。
    无迹基态：自 D ≡ 1 起静置 400 拍所得的取格状态（运行时计算并核对静置不动）。"""

        self.X = [e[0] for e in self.E]

        self.hi = {x: F(4) for x in self.X}
        self.orient = {x: 1 for x in self.X}

        self.h, self.kap, self.q0, self.gam = F(1, 8), F(2), F(1, 2), F(1)

        w = {x: F(1) for x in self.X}
        for _ in range(400):
            w = self.step(w, 'rest')

        self.init = dict(w)
    def act(self, w, s):

        for (e, u, v, ln) in self.E:

                        L[a][b_] -= c
~~~

~~~python
"""《具化场识别判定式》v1.0 附录程序：识别与桥接的专门核验。
  window_geo        三分识别的稳健窗（定理 17-1）：几何自衰减模式的留存分类端点。
  digit_wheel       周期写入的载体（数位轮）：沿形成写入的轨道回到无迹基态（定理 17-3）。
  probe_orders      两探针诱导的深度序冲突（引理 17-3′）。
  cert_continuous   连续类短拍敲除—设定响应及其一阶误差界；cert_short 加读数预算（定理 17-7′）。
  exp_bracket       e^h − 1 的有理上下界（X5）。
  chain_eval        跨记录链接合的反例求值；chain_certificate 为单调律类的链证书（定理 17-8′）。
  cycle_map         周期映射；cyclemap_welldef 为周期映射良定检验（定理 17-6′）。

from fractions import Fraction as Fr

# ---------- 定理 17-1：几何自衰减的稳健窗 ----------
def first_below(A, lam, eps):
    """最小 t ≥ 0 使 A·lam^t ≤ eps。"""
    t, v = 0, A
    while v > eps:
        t += 1
        v = v * lam
    return t

def last_above(a, lam, eps, cap=100000):
    """最大 t ≥ 0 使 a·lam^t > eps（a > eps 时）；a ≤ eps 返回 -1。"""
    if a <= eps:
        return -1
    t, v = 0, a
    while v * lam > eps and t < cap:
        t += 1
        v = v * lam
    return t

def window_geo(lams, a, A, eps):
    """各模式自衰减率 lams，写入幅度 ∈ [a, A]。对每一窗长 t 求「必留存」与「必不留存」的模式集；
    返回 (稳健窗 [t_lo, t_hi]（分类与快慢二分一致的 t 之集的端点）, 逐 t 分类表的摘要)。
    必留存：a·lam^t > eps；必不留存：A·lam^t ≤ eps；其余为「依幅度」。"""
    return {k: (first_below(A, l, eps), last_above(a, l, eps)) for k, l in lams.items()}

# ---------- 定理 17-3：数位轮 ----------
def digit_wheel(n=10):
    """数位轮：载体态 0..n−1，形成写入（走一格）w(k) = (k + 1) mod n。返回自基态 0 出发的轨道。"""
    orb, k = [0], 0
    while True:
        k = (k + 1) % n
        if k == 0:
            break
        orb.append(k)
    return orb

def k3_possible_on_orbit(orb, n):
    """在轨道上是否存在满足 K1（基态深度 0、其余 > 0）与 K3（形成写入不减深度）的深度函数。
    轨道末点写入回到基态：K3 要求 δ(0) ≥ δ(末点) > 0，与 K1 矛盾。返回 (可能?, 矛盾点)。"""
    last = orb[-1]
    if (last + 1) % n == orb[0]:
        return False, (last, orb[0])
    return True, None

# ---------- 引理 17-3′：两探针的序冲突 ----------
def probe_orders(states, e1, e2):
    """返回 e1 与 e2 诱导的序相冲突的一对状态（无冲突返回 None）。"""
    for u in states:
        for v in states:
            if e1(u) < e1(v) and e2(u) > e2(v):
                return (u, v)
    return None

# ---------- 定理 17-7′：连续类短拍证书（多项式系统，敲除差的精确积分） ----------
def pint(coefs, y0, c, h):
    """∫_0^h P(y0 + c s) ds，P 为多项式（系数自低到高）。精确。"""
    # 展开 P(y0 + c s) 为 s 的多项式
    from math import comb
    deg = len(coefs) - 1
    sc = [F(0)] * (deg + 1)
    for k, a in enumerate(coefs):
        for j in range(k + 1):
            sc[j] += a * comb(k, j) * (y0 ** (k - j)) * (c ** j)
    return sum((sc[j] * h ** (j + 1) / (j + 1) for j in range(deg + 1)), F(0))

def pval(coefs, y):
    return sum((a * y ** k for k, a in enumerate(coefs)), F(0))

def pder(coefs):
    return [k * coefs[k] for k in range(1, len(coefs))]

def sup_abs_quad(coefs, lo, hi):
    """二次及以下多项式在 [lo, hi] 上 |P| 的上确界（端点与顶点）。"""
    cands = [lo, hi]
    if len(coefs) == 3 and coefs[2] != 0:
        v = -coefs[1] / (2 * coefs[2])
        if lo <= v <= hi:
            cands.append(v)
    return max(abs(pval(coefs, t)) for t in cands)

def cert_continuous(fm, g, c, y0, delta, h):
    """系统 y' = c，x' = f_m(y) + g(y)；f_m、g 为二次及以下多项式。过程 m 读迹应 y、作用于 x。
    敲除差 Δ_m^h(y0) = x_full(h) − x_{−m}(h) = ∫_0^h f_m(y0 + c s) ds（精确）。
    设定响应 R = Δ_m^h(y0 + δ) − Δ_m^h(y0)。
    误差界 B = h²·(L·M + L'·M')：L、M 为全系统场在凸包盒上的 Lipschitz 常数（最大范数）与场的上确界，
    L'、M' 为敲除系统的。返回 dict。"""
    lo = min(y0, y0 + delta, y0 + c * h, y0 + delta + c * h)
    hi = max(y0, y0 + delta, y0 + c * h, y0 + delta + c * h)
    full = [a + b for a, b in zip(fm + [F(0)] * (3 - len(fm)), g + [F(0)] * (3 - len(g)))]
    gg = g + [F(0)] * (3 - len(g))
    L = sup_abs_quad(pder(full) + [F(0)], lo, hi)
    M = max(abs(c), sup_abs_quad(full, lo, hi))
    L2 = sup_abs_quad(pder(gg) + [F(0)], lo, hi)
    M2 = max(abs(c), sup_abs_quad(gg, lo, hi))
    B = h * h * (L * M + L2 * M2)
    D0 = pint(fm, y0, c, h)
    D1 = pint(fm, y0 + delta, c, h)
    R = D1 - D0
    lin = h * (pval(fm, y0 + delta) - pval(fm, y0))
    return {'R': R, 'lin': lin, 'B': B, 'err': abs(R - lin), 'fires': abs(R) > B,
            'fdiff': pval(fm, y0 + delta) - pval(fm, y0)}

# ---------- 定理 17-8′：跨记录链接合的反例求值 ----------

def cycle_map(host, d, cycle):
    w = {'d': d}
    for s in cycle:
        w = host.step(w, s)
    return w['d']

def cert_short(fm, g, c, y0, delta, h, r_phi=F(0)):
    """定理 17-7′：误差分报。
    模型误差（流的一阶展开）：E_mod = h²(LM + L′M′)；读数误差：四个原始流读数各 ≤ r_phi，
    两个敲除差各 ≤ 2 r_phi，最终响应 ≤ 4 r_phi。判 1 规则：|R_obs| > E_mod + 4 r_phi（先签有限差异 f(s′) ≠ f(s)）。
    完备性阈：E_mod 的系数 K = LM + L′M′；K = 0 时对一切 h 完备（不作除法）。"""
    r = cert_continuous(fm, g, c, y0, delta, h)
    K = r['B'] / (h * h)
    r['K'] = K
    r['bud_read'] = 4 * r_phi
    r['fires_read'] = abs(r['R']) > r['B'] + 4 * r_phi
    if r['fdiff'] == 0:
        r['h_complete'] = None
    elif K == 0:
        r['h_complete'] = 'all'
    else:
        r['h_complete'] = abs(r['fdiff']) / (2 * K)
    return r

def exp_bracket(h, N=12):
    """e^h − 1 的有理上下界（0 < h ≤ 1/2）：部分和与余项 ≤ 2·h^{N+1}/(N+1)!。"""
    from math import factorial
    s = sum((h ** k / factorial(k) for k in range(1, N + 1)), F(0))
    return s, s + 2 * h ** (N + 1) / factorial(N + 1)

def cyclemap_welldef(host, states_by_depth, cycle, key):
    """周期映射良定检验：同一深度 key(w) 的若干可达状态经一周期后的深度是否相同。"""
    outs = {}
    for w in states_by_depth:
        w2 = dict(w)
        for s in cycle:
            w2 = host.step(w2, s)
        outs.setdefault(key(w), set()).add(key(w2))
    return {k: v for k, v in outs.items() if len(v) > 1}

# ---------- 定理 17-8′：链式非零、越阈差异、实际作用分别证明 ----------
def chain_certificate(y1m, y2m, r1, grid_meas, r2, zeta, eps, full_component=False, bypass=None):
    """单调律类（写入关于中介单调不减）证书，三项分签。
    非零：存在格点 a < b，y2m + r1 ≤ a、b ≤ y1m − r1，使 (ĝ(b) − r2 − ζ) − (ĝ(a) + r2 + ζ) > 0；
    越阈：同一下界 > eps（有效差异已获证）；
    实际作用：目标实际总分项 c(T1) 的认证区间。G(y1) ∈ [ĝ(b) − r2 − ζ, ĝ(b′) + r2 + ζ]，b′ 为 ≥ y1m + r1 的最小格点；
      full_component=True 时申报「G 即完整分项」（须另证：该拍该位无其它分项、无夹限生效）；
      bypass = (下界, 上界) 时总分项区间为 G 区间加旁路区间；二者皆无时实际作用判 ⊥_Act。
      区间下端 > eps 或上端 < −eps 时 Act 已获证（负号即有效退浅，同样是作用）。
    记录一两态区间重叠、或两态区间之间格点不足时提前返回，差异与实际作用都记 ⊥：对充分程序是保守的；
    本函数不穷尽一切可独立认证实际作用的输入，独立取得的 Act 证书另行申报。"""
    lo1, hi1, hi2 = y1m - r1, y1m + r1, y2m + r1
    out = {'nonzero': False, 'over_eps': False, 'margin': None, 'act': '⊥', 'act_ok': False, 'interval': None}
    if hi2 >= lo1:
        out['v'], out['why'] = '⊥', '⊥_Chain(C3′)：记录一两态区间重叠'
        return out
    pts = sorted(u for u in grid_meas if hi2 <= u <= lo1)
    if len(pts) < 2:
        out['v'], out['why'] = '⊥', '⊥_Chain(C3′)：两态区间之间无足够格点'
        return out
    a, b = pts[0], pts[-1]

        hi_t = (g_hi + bypass[1]) if g_hi is not None else None
    else:

        return out
    out['interval'] = (lo_t, hi_t)
    if lo_t > eps:

    elif hi_t is not None and hi_t < -eps:
        out['act'], out['act_ok'] = '已获证（负向，有效退浅）', True
    else:
        out['act'] = '⊥_Act：认证区间与 [−ε, ε] 相交'
~~~
