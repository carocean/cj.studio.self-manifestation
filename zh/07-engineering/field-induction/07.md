自显论·工篇·势引组式第七 v1.0

# 误差驱动调宿数理式

## 第一节　目的

### 1.1　结构来源

《调宿一般式》v1.0 给出一次调宿的必要结构：

　　Retune(κ) ⇒ 六组职责（F := B′）∧ Rewrite(a, B′) ∧ Bear\_R(a, Φ\_𝓘; W)

其中六组职责来自《势引一般式》v1.0：起点组织 Org₀、目标规格 GoalRep 及其所指 Target、W 内净势差、施作作用于场 Eff、承担 Bear、目标条件 GoalCond。《势引一般式》还规定目标规格、读数靶与内容资格三者分开；承担只须参与，W 内存在一个承担时刻即可，「所依赖的部分」取结构依赖（附定义 1：固定同一个其余部分 r，存在合法的 c₁、c₂ 使读数不同）。《自显场势引造场一般式》v1.0 论证流七规定：直接写权重的优化施作是调宿，是造场中势引事件的一种实现，不是续行累积的实现。《计算组式》第十节规定宿载层与动力层分立，训练须分别核验更新、留存与后续读入。

这些结论以自然语言给出。在一个具体的训练闭环上——前向计算、损失、反向传播、优化器、参数写回——它们各落在哪一处、何时成立，需要可以逐项计算的形式系统。

### 1.2　形式化的对象

记上述各篇对以误差驱动的调宿所立的结构为 S\_EDR。本式为它建立形式系统：

　　S\_EDR ⟼ M\_EDR

式种为数理式，主式，首版。进入条件：S\_EDR 的承重结构已由《调宿一般式》《势引一般式》《自显场势引造场一般式》成立；被调场 B′ 的场具化资格、机制与宿载归属从这些式承继，不由 M\_EDR 的任何形式值授予。误差驱动的各工程量（损失、梯度、优化器状态）作为实现类的模型规格或纯形式辅助量进入定义序列，逐项回读到已成立的结构项，不作新的结构项。

### 1.3　申报范围

本式首版的实现类 𝒞\_EDR：  
\- 被调场是有限计算图上的前馈网络，节点运算取自 {in, mul, sq, add}，前向是参数与输入的多项式；  
\- 损失为平方损失；  
\- 求导为按链式法则展开的反向传播；  
\- 优化器为动量法（动量系数 β ∈ \[0, 1)，β = 0 即纯梯度下降；学习率 η 为非负有理数，η = 0 在域内）；  
\- 数据为有限数据集，采样为申报的确定性采样表，小批量大小为 1；  
\- 比较在固定采样表下进行。  
𝒞\_EDR 不含其他损失、自适应优化器、批平均、随机采样的分布比较、非多项式激活、自监督与强化学习；这些实现类上的形式系统未建立。

## 第二节　核心论题

论题一（一步训练的分报）　一步训练中，输入进入被调场并由场自身规则做前向计算，是输入与场的运行，不是本例施作的直写部分；标签、损失、反向传播与优化器的计算在被调场之外，不落在被调场上；只有参数写回是对被调场物理层的直接变换。分类按对被调场的实际实施层与途径，不按施作者是谁、在内在外。机制分报不排除输入作为一次施作的一部分；它只规定输入不是直写。

论题二（保留机制见证）　轨迹不足以判定承担：一次写回与另一次写回可以给出相同的末态，一次被覆写的写回在终点不留痕迹，一次只被读入而不影响写入值的变量与承担无关。故 M\_EDR 记录每一原子事件的执行途径、读写、实际改变与来源，承担与目标条件在这些见证上以三值求值。

论题三（回读有方向）　M\_EDR 的形式值为 1，在第七节所列桥接条件下读回为相应必要项成立；形式值为 0，只有在该项已证反向覆盖时才读回为不成立，否则只报形式值。必要项的合取不推出一次调宿已经成立，损失下降不推出目标所指的内容已经具有资格。

## 第三节　基础对象与定义序列

定义按依赖次序给出；每条定义末注其对应的结构项（对应表见第七节）。

定义 3.1（申报模型）　𝔐 = (V, λ, Dom, Φ, deg\_Φ, Ports, F\_M, X\_ext, fid)。V 为状态变量集；λ(v) ∈ {θ, r, ext}：θ 为被调场的物理层（参数），r 为被调场的普通运行状态（输入、节点值），ext 为被调场之外的变量（施作者与目标承担者的状态）。Dom(v) 为取值域：有限值域，或谓词值域附一个有限的有序替代值序列。Φ 为读数，申报其读数层级 L 与所代表的输入类 𝓘；Φ 只读 θ 层，是数学读出，不向场注入信号，不是事件。deg\_Φ(v) 为 Φ 对 v 的多项式次数上界，取非负整数或不申报。Ports 为施作端口：直写端口（可写的 θ 变量）与输入端口。F\_M 为被调场自身基本规则的分项表（前向分项）。X\_ext 为界外过程分项表，每个分项只写 ext 层；它不是 F\_M 的一部分。fid 为被调场的注册标识，在模型构建时固定。〔对应：被调场 B′ 及其工作域申报〕

定义 3.2（计算图）　𝒢 = (P, N, out)。P 为参数（θ 层的叶）；N 为拓扑序的节点，每个节点 n 有运算 op(n) ∈ {in, mul, sq, add} 与参数序列 args(n)：in 读输入 x；mul(a, b) = a·b；sq(a) = a²；add(a, b) = a + b；同一变量可在一个节点的两个位置出现。out 为输出节点。对每个变量 v，Ch(v) 为以 v 为参数之一的不同子节点之集，每个子节点只计一次。〔对应：被调场的组织与接入〕

定义 3.3（事件与契约）　事件 ε = (id, kind, reads, writes, fn, deg, part, src)，其中 kind ∈ {In, Run, Rw}：In 为输入进入，Run 为运行（场自身前向分项，或界外过程分项），Rw 为直写；src 指明执行途径——Run 须引用 F\_M 或 X\_ext 中的分项，In、Rw 须经相应端口。id 取自事件标识域 𝔈（定义 3.7），在一次运行内唯一；writes 可含一个或多个变量，只含一个者称单输出事件；deg 为 fn 对各读入变量的多项式次数，可省。fn 在写前状态上求值。契约：读入变量已申报且有值；fn 的实际输出键等于 writes；实际写入的层与 kind 相容（In、Run 写 r 或 ext，Rw 写 θ）；写入值在值域内；写集不出所引分项或端口。任一不合，该次运行定义域无效。〔对应：施作、输入与场的运行的分报〕

定义 3.4（相位）　每个原子事件占一个子相位 (k, i)，k 为训练步，i 为步内次序；入口为 (0, 0)。相位按字典序严格递增。子相位 τ 的快照 σ\_τ 是 τ 处事件写入后的全部状态值，入口快照为初值；每个快照附同一时刻的来源映射 anc\_τ。〔对应：W 及其内的时刻〕

定义 3.5（实际改变）　事件 ε 对变量 x 的写入值异于写前值，称 ε 实际改变了 x。〔对应：「施作留下的改变」〕

定义 3.6（三值依赖）　对函数 f、自变量赋值 args 与变量 v：把 v 换为其值域中的替代值、其余变量保持 args 中的值，若 f 改变，dep(f, args, v) = 1；若检验完备而 f 不变，dep = 0；否则 dep = ⊥。完备只有两种情形：v 为有限值域且已全枚举；或 f 对 v 申报了次数上界 d，且已检验 d 个彼此不同、均异于当前值的合法替代值（替代值先按精确有理数规范化、剔除不合法与等于当前值者、保序去重，再计数）。  
这是固定实际背景的局部依赖：其余部分固定为当时的实际赋值，而不是遍历一切合法的其余部分。dep = 1 给出一个实际背景上的差异，实际背景是合法背景之一，故它是《势引一般式》附定义 1 所称结构依赖的见证；dep = 0 只说在这一背景上无差异，不排除在另一合法背景上有差异，不是结构依赖不存在的证明。〔对应：「所依赖的部分」取结构依赖——单向，见 7.1〕

定义 3.7（来源）　来源域 𝔖 = 𝔈 ⊎ 𝔄 为事件标识域 𝔈 与持有锚标识域 𝔄 的不交并；来源的匹配按类型与同一标识，不同类型的来源在任何情形下不相等。以字符串实现时，持有锚标识带保留前缀，事件标识不得带此前缀，否则该次运行定义域无效。每个变量 x 带来源映射 anc(x)：𝔖 的有限子集 → {确定, 未决}。  
(a) 事件 ε 实际改变 x 时，anc(x) = {ε: 确定}，并入：对 dep = 1 的读入变量 u，并入 anc(u)；对 dep = ⊥ 者，把 anc(u) 的各项以「未决」并入；dep = 0 者不并入。确定优先于未决。依赖与来源都按写前快照取。  
(b) 直写事件对 x 的写入值与写前值相同：不生成来源，anc(x) 不变。  
(c) In 或 Run 事件对 x 的写入值与写前值相同、但由本次读入重新决定：不把该事件记为来源，anc(x) 重定为按 (a) 由读入变量并入的结果（不含该事件自身）；写入目标变量 g 者（不论途径）除外，按 (b)。  
多输出事件对每个输出变量分别按 (a)—(c) 求来源；(a) 与 (c) 所并入的都是读入变量在本事件之前的来源（写前快照），不是本事件中兄弟输出刚生成的来源；各输出的来源求出后统一提交。一个输出的来源不并入另一个输出。  
〔对应：施作经实际途径参与；承担链〕

定义 3.8（目标声明、目标指向登记与目标来源）  
(a) 目标指向登记 𝒯 是一张表：TargetDecl(g) = (被调场 φ′，关系模板)。本式首例的关系模板为 B′ 在输入类 𝓘 上的输入—输出关系 y = g·x。  
(b) 目标声明 GoalDecl = (角色 Xg，目标变量 g，被调场 φ)。  
(c) 运行入口：一次带 GoalDecl 的训练运行，要求 𝒯 中有 TargetDecl(g)，且 φ = φ′ = fid；缺登记或任一不等，该次运行定义域无效。  
(d) 目标来源登记，两类：入口的持有锚——Xg 在入口已持有 g，其标识属 𝔄；其角色与变量须与 GoalDecl 一致，g 须已申报为 ext 层并在入口可用，否则定义域无效；持有锚不是事件，不是物理改变。窗内的目标写入事件——src 为目标设定分项、part 为 Xg、写集恰为 {g}、实际改变了 g；其标识属 𝔈。一次合法运行可以没有任何目标来源登记。  
〔对应：GoalRep(Xg, g)、Target(g, B′)〕

定义 3.9（训练量）　g：目标规格；y\*：监督材料（标签）；ℓ：当前误差读数；ε：读数靶，申报为阈值 ℓ ≤ ε；δ\_v：反向误差（伴随）；q\_p：梯度；v\_p：动量（优化器状态，ext 层）；stop：监视标志。目标规格、监督材料、当前误差读数、读数靶、对象层内容资格五者不互换。〔对应：《势引一般式》对目标规格、读数靶、内容资格的区分〕

定义 3.10（形式谓词）　对施作 a（以 part 标记）、时窗 W 与事件种类子集 K ⊆ {In, Run, Rw}。a 的事件指 part 为 a、相位在 W 内的事件；承担时刻 τ 取 W 内的快照相位；W 之前的事件只以其来源出现在来源映射中。第七节各例的 W 取整个运行。  
\- Rewrite^f(a)：a 中存在实际改变 θ 变量的 Rw 事件。  
\- BearAt\_K(a, τ)：三值——存在 v，dep(Φ, σ\_τ, v) = 1，且 anc\_τ(v) 中有 a 的、kind ∈ K、有实际改变的事件且标为确定，则 1；对 τ 时一切 v，或 dep = 0，或 anc\_τ(v) 中无此类事件，则 0；否则 ⊥。  
\- Bear\_K(a; W)：对 τ ∈ W 按强 Kleene 析取：某一 τ 为 1 则 1；一切 τ 为 0 则 0；否则 ⊥。Bear^f = Bear\_{In, Run, Rw}，Bear\_R^f = Bear\_{Rw}。  
\- GoalCond^f(a)（在合法运行内）：未登记任何目标来源，⊥；a 的某个实际改变 θ 的 Rw 事件写入后，被写变量的来源中含已登记的目标来源（按类型与标识匹配）且为确定，1；只含未决者，⊥；其余，0。  
\- Eff^f(a)：a 的某个事件实际改变了被调场的 θ 层。  
\- Org₀^f：入口时 θ 层变量已接入且非空，计算图已申报。  
\- ΔΦ^f\_W：Φ(σ\_{W 末}) − Φ(σ\_{W 入口})，是一个量；进入三值表的是谓词 ΔΦ^f\_W ≠ 0。  
\- Target^f(g)（登记查询，不是运行）：𝒯 中无 TargetDecl(g)，⊥；有且其被调场为 fid，1；有而其被调场异于 fid，0。  
〔对应：第七节〕

关系与性质（逐项申明域与方向）：  
\- ≺\_𝕋（子相位之间）：严格全序——非自反、传递、完全。  
\- 版本：同一参数每次实际改变产生一个新版本，入口值为初版本。Pred(ν, ν′)：ν 是 ν′ 的直接前驱版本（同一参数，ν 在前）。作为 ν′ ↦ ν 的对应，它是定义在非初版本上的函数（每个非初版本恰有一个前驱，初版本无前驱）；非自反；一般不传递（同一参数有三个以上版本时 Pred(ν₁, ν₂) ∧ Pred(ν₂, ν₃) 而非 Pred(ν₁, ν₃)）。  
\- ≺\_ver（Pred 的传递闭包，ν 在前）：严格偏序——非自反、传递、反对称；对同一参数为全序，不同参数之间不可比。  
\- Src(e, e′)（e′ 为有实际改变的事件，e 属于 e′ 某一实际改变的变量在写入后的来源）：在有实际改变的事件上自反（e′ 在自己的写入来源中）。  
\- AncEv⁺(e, e′) :⇔ Src(e, e′) ∧ e ≠ e′（事件之间）：非自反；先行（e 的相位早于 e′，因来源只来自已执行的事件）；反对称（由先行）。传递性只在中间事件为单输出时成立，见命题 5.4；对一般多输出事件，事件投影不保证传递（7.3 有例）。确定性：在命题 5.4 的条件下，确定与确定合成为确定；含未决者为未决。  
\- 持有锚不是事件，不入 AncEv⁺；锚与变量之间另记 HoldAnc（异型关系，不讨论自反、对称）。  
\- 同 part（事件之间）：等价关系。Rewrite^f、Bear\_R^f、GoalCond^f 都绑定在 part 上。

## 第四节　方程

对 𝒢 与第 k 步，记 x\_k 为本步输入。

（采样）　idx\_k = π(k, s)，π 为申报的确定性采样表，s 为种子；x\_k = D\[idx\_k\]，D 为有限数据集。  
（前向）　按拓扑序，val(n) = op(n)(val(args(n)))，in 节点取 x\_k；y\_k = val(out)。  
（标签）　y\*\_k = g·x\_k。  
（观测）　ℓ\_k = (y\_k − y\*\_k)²/2。  
（伴随）　δ\_out = y\_k − y\*\_k；对其余节点与参数按逆拓扑序

　　δ\_v = Σ\_{c ∈ Ch(v)} δ\_c · ∂c/∂v，

其中 ∂mul(a, b)/∂a = b，∂sq(a)/∂a = 2a，∂add(a, b)/∂a = 1，同一变量在一个节点的两个位置出现者对所有出现位置求和（∂mul(w, w)/∂w = 2w，∂add(w, w)/∂w = 2）。Ch(v) 为空者 δ\_v = 0。  
（梯度）　q\_p = δ\_p，p ∈ P。  
（动量）　v\_p ← β·v\_p + q\_p。  
（写回）　p ← p − η·v\_p。  
（监视）　stop = 1 当 ℓ\_k ≤ ε，否则 0。  
（读数）　Φ(θ) = 𝒢 在读出探针 x = 1 处的输出值。读出探针代表输入类 𝓘：Φ 在 x = 1 处作独立的数学读出，不经过训练采样，也不产生运行事件；探针值可与训练样本相同。deg\_Φ(p) 由图递推：in 为 0，参数 p 为 1、其他参数为 0，mul 两参数次数相加，sq 加倍，add 取大。前向事件对读入变量的次数：mul(a, b) 中 a = b 时为 2、否则各 1；sq 为 2；add 为 1（重复亦 1）。

桥接条件（申报）：所选损失 ℓ(y, y\*) = (y − y\*)²/2 决定伴随起点 δ\_out = y − y\*；梯度由前向值与伴随规则算出，不读 ℓ 的标量；ℓ 的标量只经监视进入。这只是本实现类的申报；若某实现以 ℓ 调度学习率或停止训练，须登记相应的读取事件。  
动量与零梯度：参数改变量为 −η·(β·v\_old + q)。q = 0 时，参数改变量为 −η·β·v\_old：若 η ≠ 0，参数保持当且仅当 β·v\_old = 0；若 η = 0，参数保持。

## 第五节　运行与求解

### 5.1　运行次序

第 k 步的子相位依次为：采样（界外）、输入（In）、前向（F\_M，按拓扑序每节点一事件）、标签、观测、伴随（界外，按逆拓扑序每变量一事件）、动量（界外，每参数一事件）、写回（Rw，每参数一事件）、监视（界外）。目标若在窗内设定，其写入事件位于 (0, 1)。按此次序生成的每个事件都是单输出事件。

### 5.2　有限可执行域与受信任前提

有限可执行域：变量、节点、参数、数据、步数有限；值取有理数；每个事件的 fn 为有理多项式（监视为有限分支）。受信任前提：各函数在其值域上全定义；申报的次数上界属实；kind 与 src 的申报符合实际执行途径；W 内施作 a 对被调场的一切实际落点都已登记为事件（申报完整）。这四项不由求解程序认证；它们失实时，求值结论随之失效。

### 5.3　结果三类

（一）定义域无效：模型、声明或事件不合定义 3.1、3.3、3.7、3.8 的契约——包括事件标识与持有锚标识同型，带 GoalDecl 的运行缺 TargetDecl 或三方被调场不一致，持有锚与 GoalDecl 不绑定。  
（二）未决 ⊥（合法运行之内）：依赖检验不完备；或运行中未登记任何目标来源，此时 GoalCond^f = ⊥。  
（三）已认证的 1 或 0。  
登记查询 Target^f(g) 不是运行，另有三值：未登记 ⊥，被调场一致 1，被调场不一致 0。

定理 5.1（有限终止）　在有限可执行域内，对任一申报模型与有限步数，运行、来源更新与第三节各形式谓词的求值在有限步内终止，并对每一谓词返回 {1, 0, ⊥} 之一或定义域无效。  
证明：事件数有限；每个事件的执行、契约检查与对每个读入变量的依赖检验只涉及有限个替代值；来源映射的合并是有限集合运算；谓词在有限个快照与有限个变量上枚举。∎  
本定理对多输出事件同样成立；它不认证登记的真实性，也不认证被调场的场具化资格。

定理 5.2（伴随正确）　对 𝒢 中任一节点或参数 v，第四节的伴随 δ\_v 等于 ℓ 对 v 的偏导数（在本步前向值处，其余节点视为 v 的函数）。  
证明：对逆拓扑序归纳。δ\_out = ∂ℓ/∂y 由平方损失直接求得。设对 v 的一切子节点 c 已有 δ\_c = ∂ℓ/∂c。ℓ 经 v 影响的只有 Ch(v) 中的节点，由多元链式法则 ∂ℓ/∂v = Σ\_{c ∈ Ch(v)} (∂ℓ/∂c)(∂c/∂v)；其中每个子节点只出现一次，∂c/∂v 是 c 对 v 的全偏导，已对 v 在 c 中的全部出现位置求和。Ch(v) 为空时 ℓ 不经 v，偏导为 0，与 δ\_v = 0 一致。故 δ\_v = ∂ℓ/∂v。∎  
本定理不保证损失单调下降。

定理 5.3（重定只改来源）　定义 3.7(c) 不改变任何状态值与读数轨迹；它与定义 3.7(b) 的差别只在 In、Run 的同值写入处的来源。  
证明：(c) 只在写入值与写前值相同时作用，只改 anc(x)，不改 x 的值；事件函数不读来源，Φ 只读 θ 层，不读来源；由相位归纳，各快照的状态值与 Φ 不变。∎  
因此，Bear^f 与 GoalCond^f 依赖来源的定义，在 (c) 生效之处可与不作重定的规则取值不同；本式的回读一律按定义 3.7。实际改变、Rewrite^f 不受 (c) 影响。重定的必要性（对本式的见证语义）：目标值为 0 时标签恒为 0，与标签的初值相同；若不重定，目标对其后计算的作用在此中断。

命题 5.4（单输出条件下的事件传递）　在一次合法运行中，若 e′ 为单输出事件，则 AncEv⁺(e, e′) ∧ AncEv⁺(e′, e″) ⇒ AncEv⁺(e, e″)；若前两者均为确定，后者亦为确定。§5.1 的运行中每个事件都是单输出，故其上 AncEv⁺ 是严格偏序。  
证明：设 e′ 唯一的输出为 x′，写入后来源为 A′ = anc(x′)，e ∈ A′。由定义 3.7，e′ 作为来源只在 A′ 中被生成；此后的来源集或由 (b) 保持，或由 (a)、(c) 把若干读入变量的来源集整集并入（dep = 1 者保留各项状态，dep = ⊥ 者各项改为未决）而得。对相位归纳，得两条不变式：其一，凡含 e′ 的来源集都含 A′ 的全部元素；其二，凡 e′ 为确定的来源集，A′ 中为确定的元素在其中也为确定——因为 e′ 为确定，必来自某个 dep = 1 并入的、e′ 已为确定的来源集，由归纳假设，该集中 A′ 的确定元素仍为确定，而合并时确定优先。由 AncEv⁺(e′, e″)，e″ 某一输出的来源含 e′，由不变式一亦含 e，且 e ≠ e″（e 先于 e′，e′ 先于 e″）；两者均为确定时，由不变式二，e 在其中为确定。单输出用于保证 A′ 唯一：e′ 只在一个来源集中生成。∎  
若 e′ 有多个输出，e′ 在各输出的来源集中分别生成，各集的其余元素可以不同；e 在一个输出的来源中、e″ 只读另一个输出时，e 不必在 e″ 的来源中（7.3 有例）。

## 第六节　耦合

6.1　与《调宿一般式》　M\_EDR 的形式谓词是调宿一般式各结构项在 𝒞\_EDR 上的形式像，对应、方向与强度见第七节。

6.2　与《计算组式》　本式使用的对应：前向事件对应计算组式所称实际事件——节点在驱动通路下被写入，一次前向是一次运行；参数写回是宿载层的变换，与动力层分立。本式未建立的对应：读法合法性、交付与承担全族量词的映射。

6.3　与《势引数理式》v1.0　申报模型、事件契约、相位、实际改变、三值依赖、来源映射与承担求值，是势引数理式见证语言的受限形式：事件种类限于 In、Run、Rw，没有动态层与场自身写回，计算图的连接集固定、不含断接。其定义与定理在第三至五节内自足。界外过程分项表 X\_ext（定义 3.1）与 In、Run 同值写入的来源重定（定义 3.7(c)）在势引数理式中分别为其定义 3.1 的 X\_ext 与定义 3.6(c)，规定相同；GoalCond^f 是其 P6\_Π 取 Π = {Rw} × {θ} 的读法；时窗的取法同其定义 3.9。计算图（定义 3.2）与训练量（定义 3.9）是 𝒞\_EDR 的专有结构。

### 7.2　回读规则

规则一　形式值 1 在对应表所列桥接条件下作肯定读回。形式值 0 表示本形式谓词在申报域内为假。只有已证「结构项成立必使形式值不为 0」（反向覆盖）时，才能以形式值 0 排除该结构项；本式中有此保证的只有对应表标「可排除」的两项。若被排除的是调宿的必要项，且工作域前提满足，才可排除相应调宿候选。未获反向覆盖保证的 0，只报形式值，不作上游否定。⊥ 表示未决，不读作不成立。定义域无效另列，不是形式值。  
规则二　各必要项的形式值同为 1，不读作一次调宿已经成立；Retune 不由本式的形式值认定。  
规则三　损失下降、达到读数靶，不读作目标所指的内容已具资格，也不读作 GoalCond 成立；GoalCond 只由第三节的目标来源与来源映射读出。  
规则四　写回值等于写前值时，该直写不生成新来源，既有来源保持。若施作 a 无实际改变的直写，则 Rewrite^f(a) = 0；这不删除先前或其他机制产生的来源。对动量法，是否有实际改写按写回量 η·v\_p 判断：零梯度时还须结合 η 与 β·v\_old（第四节）。

### 7.3　回读示例

以下各例的读数都在读出探针 x = 1 处取（第四节），与训练数据 D 分开；未另说明者，D = {0 ↦ 1, 1 ↦ 2}，π(k, 0) = k mod 2，Xg 在入口持有 g = 2，β = 0，初动量为 0，ε = 1/2。

两层线性网络：P = {w1, w2}，h = w1·x，y = w2·h；η = 1/8；入口 w1 = 1、w2 = 1/2。第 1 步：x = 2，h = 2，y = 1，y\* = 4，ℓ = 9/2，δ\_y = −3，δ\_h = w2·δ\_y = −3/2，q1 = δ\_h·x = −3，q2 = δ\_y·h = −6；写回 w1 = 11/8，w2 = 5/4；Φ 由 1/2 到 55/32。读回：Rewrite^f = 1；Bear\_R^f = 1，见证为第 1 步写回 w1 的子相位与变量 w1；GoalCond^f = 1，见证为同一写回事件，命中持有锚；ℓ 的标量不在 q1 的来源中。第 2 步起 stop = 1（ℓ = 81/2048）。  
三参数网络：数据、采样、g、β、ε 与零初动量同上。h = w1·x，s = h²，y = w2·s + w3·x；入口 w1 = 1、w2 = w3 = 1/2；η = 1/32。第 1 步：x = 2，h = 2，s = 4，y = 3，y\* = 4，ℓ = 1/2，δ\_y = −1，δ\_s = w2·δ\_y = −1/2，δ\_h = δ\_s·2h = −2，q\_{w1} = δ\_h·x = −4，q\_{w2} = δ\_y·s = −4，q\_{w3} = δ\_y·x = −2；写回 w1 = 9/8，w2 = 5/8，w3 = 9/16。读数次数 deg\_Φ：w1 为 2，w2、w3 为 1。Bear\_R^f = 1，GoalCond^f = 1。  
零更新：两层网络，入口 w1 = 1、w2 = 2，β = 0，初动量为 0，取第 1 步。在 D 上 y = y\*，δ 全为 0，写回值等于写前值：Rewrite^f = 0，Bear\_R^f = 0，GoalCond^f = 0。按对应表，Rewrite^f = 0 可排除本步 Rewrite(a, B′)；Bear\_R^f = 0、GoalCond^f = 0 只报形式值。  
零梯度而有动量：同一网络与入口，β = 1/2，入口 v\_{w1} = 2、v\_{w2} = 0，η = 1/8，第 1 步。q1 = q2 = 0，v\_{w1} = 1，w1 由 1 写为 7/8：Rewrite^f = 1。零梯度不推出无写回。同一入口而 η = 0：v\_{w1} 仍更新为 1，w1 保持为 1，Rewrite^f = 0。  
只写不被读取的参数：另设 u ∈ θ，入口 u = 1，不入前向、不入 Φ（deg\_Φ(u) = 0）。主更新由另一施作 b 执行；施作 a 只对 u 作衰减 u ← (9/10)·u。Rewrite^f(a) = 1，Bear\_R^f(a) = 0，Bear\_R^f(b) = 1。这与《调宿一般式》论证流二「直写落空」同型。此处 0 来自 deg\_Φ(u) = 0：Φ 在任何背景上都不读 u。  
局部背景上的 0：Φ = w1·w2 + w3，入口 (w1, w2, w3) = (1, 0, 0)；施作 a 把 w1 写为 2，另一施作 b 把 w3 写为 1。全窗 w2 = 0，ΔΦ^f\_W = 1，Bear\_R^f(a) = 0。但在另一合法背景 w2 = 1、w3 = 0 上，w1 = 1、2 的读数分别为 1、2：结构依赖存在。此 0 只报形式值，不推出 a 对读数无结构依赖，也不推出无上游承担链。本例只示回读方向，不签其中任何对象具有场具化资格或调宿资格。  
重复位置：y = mul(w, w)、add(w, w)、sq(w)，w = 1，x = 2，g = 2：δ\_w 分别为 −6、−4、−6，与 (y − y\*)·∂y/∂w 一致。  
多输出事件：e1 直写 w1 := 2（入口 w1 = 1）；e2 经一个界外分项同时写 d\_{w1} := w1、d\_{w2} := 1；e3 只读 d\_{w2}，写 v\_{w2} := 2·d\_{w2}。AncEv⁺(e1, e2)（经 d\_{w1}），AncEv⁺(e2, e3)（经 d\_{w2}），而 e1 不在 e3 的来源中。中间事件 e2 为多输出，命题 5.4 的条件不满足。§5.1 的运行中无此情形。  
多输出事件中的同值输出：两层网络，入口 w1 = 1、w2 = 2，d\_{w1} = 0、y\* = 0，Xg 在入口持有 g = 2。一个界外事件按写前状态同时写 d\_{w1} := g、y\* := d\_{w1}，得 d\_{w1} = 2（实际改变），y\* = 0（与写前值相同，按 3.7(c) 重定）。y\* 读的是写前的 d\_{w1}，其来源为空，故 y\* 重定后的来源为空，不含本事件，也不含目标来源；其后直写 w1 := y\*，w1 由 1 改为 0，GoalCond^f = 0：目标只经 d\_{w1} 的新值传递，而 y\* 读的不是这个新值。  
目标来源与登记：入口 g = 0、窗内设定 g := 2，与入口持有 g = 2，GoalCond^f 均为 1，参数轨迹相同。三方一致而未登记任何目标来源的运行，GoalCond^f = ⊥。带 GoalDecl 的运行缺 TargetDecl，或其被调场与 GoalDecl、fid 不一致，定义域无效；持有锚贴在参数上，定义域无效；以持有锚标识命名事件，定义域无效。登记查询 Target^f(g)：未登记 ⊥，一致 1，不一致 0。
