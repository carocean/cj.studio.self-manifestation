自显论·工篇·势引组式第十 v1.0

# 调宿收束必然式

## 第一节　目的

### 1.1　问题

《误差驱动调宿数理式》v1.0 给出误差驱动调宿的形式系统 M\_EDR：前向、标签、损失、伴随、梯度、动量与写回逐事件进行，监视只记录损失是否达到读数靶。它回答一次写回是否发生、由谁承担，不回答训练何时算是到位。到位须同时满足两件独立的事：被调场的输出已经实现目标关系，并且按原协议继续执行不再改写参数。前者没有后者，参数仍被改写——改写是否离开对齐，另看改写的方向；后者没有前者，只是停止改写。由此问：在什么条件下，一次误差驱动调宿必然收束到这样的状态？

### 1.2　命题形式

　　C ⇒ R

C 为第二节的首证子类 𝒦₀ 的各项条件；R 为：参数与动量收敛，极限态是调宿平衡（定义 2.2），且极限点由初态在未触子空间上的分量与目标的插值点唯一确定。

### 1.3　强度

结论是充分条件，在 M\_EDR 的实现类、首证子类 𝒦₀ 与第六节 H 组下成立。所证是极限态的性质；原轨迹是否在有限步内到达，另由定理 2 刻画。收束不读作调宿的发生资格，低损失不读作内容资格；结论不推及生物学习与一般非凸网络。

## 第二节　核心命题

### 2.1　五项区分

对一次 M\_EDR 运行、申报输入类 𝓘（取采样表所覆盖的数据集 D）与目标关系 y = g·x，区分五项：  
(a) 外部停机：运行被外部终止。M\_EDR 的 stop 是监视标志，第四节方程中没有停训联锁；(a) 与其余各项没有逻辑联系。  
(b) 一次零更新：某一步的写回量 η·v\_p 对一切参数为零。  
(c) 协议止调：状态 (θ, v, 相位) 下按申报采样协议继续执行，此后每一步写回量都为零。状态取完整的优化器状态（参数 θ 与动量 v）与采样相位。  
(d) 达标：损失 ℓ ≤ ε。  
(e) 对齐：被调场在 𝓘 的每个输入上实现目标关系，即 θ 下的输出等于 g·x。不取容差。

### 2.2　调宿平衡

定义 2.2　状态 (θ, v, 相位) 满足 (e) 且满足 (c)，称为调宿平衡。

调宿平衡是调宿的收束终点；调谐的收束终点为调谐平衡（亦称经验平衡），二者统称内容对齐平衡。调宿平衡的两个分量是独立的要求。对齐时梯度为 0，下一步写回量为 η·β·v：η·β·v ≠ 0 时仍写回；写回落在未触子空间时，申报输入上的对齐仍保持。例：y = (w₁ + w₂)·x，g = 2，θ = (1, 1)，v = (1, −1)，η = β = 1/2：下一步 θ = (3/4, 5/4)，参数改变，各申报输入上的输出仍为 2x；同一入口取 β = 0，下一步参数保持、动量归零。只有止调而不对齐（如 η = 0），参数不动而输出未达目标。动量为零不是调宿平衡的必要项。

### 2.3　首证子类 𝒦₀

K1　参数线性：y = θ·φ(x)，φ 由计算图确定；  
K2　β = 0，初动量为 0；  
K3　采样表周期覆盖 D；  
K4　目标可实现：存在 θ\* 使 θ\*·φ(x) = g·x 对一切 x ∈ D；  
K5　步长条件：0 \< η‖φ(x)‖² \< 2 对一切 x ∈ D；  
K6　φ(x) ≠ 0 对一切 x ∈ D。

K1、K3、K5 是场具化组式第二十（4.4）定理 20-2 的原前提；K2 中 β = 0 使 M\_EDR 的写回与 20-2 的写入规则对应，初动量为 0 是选定的条件；K4 是 20-2 的「目标一致」。K5 已蕴含 K6（η‖φ(x)‖² \> 0 推出 φ(x) ≠ 0）；K6 单列，以标明它在由零写回反推对齐时的用途。

### 2.4　核心命题

　　𝒦₀ ⇒ lim θ\_k = θ∞ 存在 ∧ θ∞ = P\_{V⊥}θ₀ + θ\*\_V ∧ v\_k → 0 ∧ 状态 (θ∞, 0, 任一相位) 为调宿平衡

V = span{φ(x) : x ∈ D}；P\_{V⊥}θ₀ 为 θ₀ 在 V⊥ 上的分量；θ\*\_V 为 V 中使 θ·φ(x) = g·x 对一切 x ∈ D 成立的唯一点。

## 第四节　动力

### 4.1　方程

第 k 步按 M\_EDR 第四节：采样 x\_k，前向得 y\_k，标签 y\*\_k = g·x\_k，伴随与梯度 q\_k，动量 v\_k = β·v\_{k−1} + q\_k，写回 θ\_k = θ\_{k−1} − η·v\_k。K1、K2 下合为

　　θ\_k = θ\_{k−1} + η·φ(x\_k)·(g·x\_k − θ\_{k−1}·φ(x\_k))，　v\_k = q\_k。

这正是定理 20-2 的写入 Δθ = η·s·(t − θᵀs)，s = φ(x\_k)，t = g·x\_k。例：y = w₁·x + w₂·x²，D = {1, 2}，按上式递推的前六步与 M\_EDR 的逐事件运行逐值相同。

### 4.2　延拓

有限窗的 M\_EDR 运行按同一递推延拓为 k = 1, 2, …。参数序列取值于 ℚⁿ，极限在其实闭包 ℝⁿ 中取；β \> 0 时取于参数与动量之积。延拓只用于极限陈述；有限步陈述仍在 M\_EDR 之内。

## 第五节　定理群

命题 1（对齐与零写回的正向）　对任一计算图：对齐 ∧ η·β·v = 0 ⇒ 该状态按协议继续执行，每一步写回为零；θ 保持，对齐保持，采样相位按协议推进。特别地，β = 0 或 v = 0 时成立。  
证明：θ 对齐时每个采样输入上 δ\_out = 0；由伴随递推各 δ\_p = 0，故 q = 0。下一步动量为 β·v，写回量为 η·β·v = 0，θ 保持，对齐保持。此后：η = 0 时写回恒为 0；η \> 0 时 β·v = 0，动量变为 0，以后各步 q = 0、v = 0，写回为 0。∎

命题 2（零写回的逆向）　设 K1、K2、K3、K6 与 η \> 0。状态按协议继续执行一个完整采样周期，每一步写回为零 ⇒ 对齐。  
证明：K2 下 v = q；写回为零且 η \> 0 给每步 q = 0，参数在周期内不变。K1 下 q = (θ·φ(x) − g·x)·φ(x)，由 K6 得 θ·φ(x) = g·x；K3 使之对一切 x ∈ D 成立。∎  
缺 K1 时逆向不成立：y = w²·x，w = 0，g = 1，x = 2，残差为 −2，梯度 2w·x·δ\_out = 0，零写回而不对齐。

命题 3（蕴含图）　(c) ⇒ (b)；调宿平衡 ⇒ (c)，⇒ (e)；(e) ⇒ (d)（当步 ℓ = 0 ≤ ε）。以下各方向不成立：  
\- (c) ⇏ (e)：η = 0 时每步零写回，参数停在不对齐处。  
\- (b) ⇏ (c)：y = w₁·x + w₂·x²，g = 1，入口 (2, −1)，η = 1/32，首样本 x = 1：第 1 步残差为 0、零写回；第 2 步 x = 2，残差为 −2，写回非零。  
\- (d) ⇏ (e)：y = w·x，w = 3/2，g = 2，x = 1，ε = 1/2：ℓ = 1/8 ≤ ε 而不对齐。  
\- (e) ⇏ (c)（β \> 0）：y = w·x，w = g = 2，入口动量 2，β = 1/2，η = 1/8：已对齐而第 1 步写回非零。  
\- 「极限态继续执行零写回」⇏「原轨迹某步起零写回」：y = w·x，x = 1，g = 1，θ₀ = 0，η = 1/2：θ\_k = 1 − 2⁻ᵏ，每一步都写回，极限 1 是固定点。  
证明：前三条由定义与命题 1；反例逐例按第四节方程求值。∎

定理 1（收束到调宿平衡）　在 𝒦₀ 中，θ\_k 收敛到 θ∞（V = ℝⁿ 的满秩支与 V 为真子空间的缺秩支同此），且  
(i) θ∞ 在 D 上对齐；  
(ii) θ∞ 在 V⊥ 上的分量等于 θ₀ 的该分量，在 V 上的分量为 θ\*\_V；  
(iii) v\_k = q\_k → 0；状态 (θ∞, 0, 任一相位) 为调宿平衡。  
证明：由 4.1，运行即定理 20-2 的周期写入，其前提由 K1、K2、K3、K5 给出。满秩支（V = ℝⁿ）：由 20-2（一），一周期映射是压缩，周期截面极限唯一，目标一致（K4）时为插值解。缺秩支（V 为真子空间）：由 20-2（二），V⊥ 分量逐拍不变，V 上分量几何收敛；各写入只沿 φ(x) ∈ V 改变参数，限于 V 时各特征张满 V，按 20-2（一）在 V 上的读法，周期截面在 V 上收敛到插值解 θ\*\_V。两支中，插值点在每一相位的残差为 0，是每一相位写入的不动点；每一相位的截面极限由前一相位极限经连续的有限步映射得到，故各相位截面同点，逐步轨迹 θ\_k 本身收敛到 θ∞ = P\_{V⊥}θ₀ + θ\*\_V。(i)(ii) 由此。  
(iii) K2 下 v\_k = q\_k，动量并不恒为 0：y = w·x，w₀ = 1，g = 2，x = 1，η = 1 时首步 v = −1、w₁ = 2。采样表有限周期，θ\_k → θ∞，θ∞ 在每一相位的残差为 0，q 对 θ 连续，故 q\_k → 0，v\_k → 0。v = 0 是插值极限态的合法动量分量；由命题 1，(θ∞, 0) 在任一相位继续执行每步零写回且对齐，即调宿平衡。采样周期大于 1 时，采样相位周期循环而不收敛，按各相位截面表述：每一相位的截面子列都收敛到 (θ∞, 0, 该相位)。∎  
例：y = w₁·x + w₂·x²，D = {1, 2}，g = 2，η = 1/16：η‖φ‖² 为 1/8 与 5/4；一周期映射的迹 49/64、行列式 −7/32，谱半径小于 1；插值点 (2, 0) 是周期映射的不动点。y = w₁·x + w₂·x（φ(x) = (x, x)），入口 (1, −1)：w₁ − w₂ 恒为 2，w₁ + w₂ → g；入口 (3, −3) 时 w₁ − w₂ 恒为 6——极限依初态在 V⊥ 上的分量而异。θ₀ = 0、g = 1、x = 1、η = 1/2：v\_k = −2^{−(k−1)} → 0。

定理 2（有限步到达与渐近收束之分）　在 𝒦₀ 中，原轨迹自某步起每步零写回，当且仅当自某步起 θ\_k 已对齐。单模式（D 只含一个输入，φ = φ(x)）下，θ\_k − θ∞ = (1 − η‖φ‖²)ᵏ·(θ₀ − θ∞)\_V，故有限步到达当且仅当 η‖φ‖² = 1 或 (θ₀ − θ∞)\_V = 0。  
证明：「已对齐 ⇒ 此后零写回」：K2 下 β = 0，θ\_k 对齐时下一步 q = 0、v = q = 0，写回为零，对齐保持，逐步递推（即命题 1 取 β = 0）。首次到达对齐的那一步留下的动量 v\_k = q\_k 可以非零，下一步才归零；参数到达、此后零写回与动量归零之间可有一步索引差。按定义 2.2，首个对齐态 (θ\_k, v\_k, 相位) 已满足继续执行不写回，即已是调宿平衡。「某步起零写回 ⇒ 已对齐」由命题 2，用 K1、K3、K6。单模式的式子由递推直接计算。∎  
例：θ₀ = 0、g = 1、x = 1：η = 1/2 时 θ\_k = 1 − 2⁻ᵏ，从不到达；η = 1 时一步到达，此后零写回。y = w·x、x = 1、g = 2、w₀ = 1、η = 1：第 1 步后 (w, v) = (2, −1)，第 2 步后 (2, 0)，第 2 步零写回；第 1 步后的状态已是调宿平衡。

定理 3（不可实现目标：周期截面而不止调）　设 K1、K2、K3、K5 成立而 K4 不成立。各相位的周期截面收敛；各相位截面不全同点，在截面上每一周期都有写回，不止调，也不对齐。  
证明：满秩支由 20-2（一）（原强度：只称周期截面收敛）。缺秩支先由 20-2（二）保留 V⊥ 分量，再限于 V：各特征在 V 上张满，按满秩支在 V 上的一周期压缩，周期截面收敛；每一相位的截面极限由连续的有限步映射取得。若各相位截面同点 θ̄，则 θ̄ 是每一相位写入的共同不动点；K5 下 η \> 0、φ(x) ≠ 0，不动点要求该相位残差为 0，故 θ̄ 在 D 上对齐，与 K4 不成立矛盾。故截面不全同点，某一相位的写入把一个截面点映到另一个，写回非零；不可实现即 D 上不存在对齐的 θ。∎  
例（满秩）：y = w·x²，标签 g·x，g = 2，D = {1, 2}，η = 1/16：x = 1 一步之后的截面为 17/16，x = 2 一步之后为 1；轨迹逼近截面，截面上逐步写回。  
例（缺秩）：y = (w₁ + w₂)·x²，标签 2x，D = {1, 2}，η = 1/32，入口 (1, 0)，V = span{(1, 1)}：参数和在两相位之后分别为 17/16 与 1，参数差保持为 1，每步写回。  
定理 20-2 的外标边界：同一特征、交替标签 0 与 1（η = 1/2，入口 2/3）给截面 {1/3, 2/3}。这是 20-2 意义下的不一致外标，不是固定 g 的 M\_EDR 标签，同属 20-2（一）「只称周期截面收敛」。

H 组：  
H1　延拓按同一递推，只用于极限陈述；  
H2　采样表周期覆盖 D（K3 的协议形式）；  
H3　目标可实现（K4）；  
H4　对齐不取容差；取容差者另行申报，定理 1(iii) 随之改写。

## 第七节　总结公式

　　𝒦₀ ⇒ lim θ\_k = θ∞ = P\_{V⊥}θ₀ + θ\*\_V ∧ v\_k → 0 ∧ (θ∞, 0, 任一相位) 为调宿平衡

即：极限态在任一相位继续执行，每步零写回且对齐。这是极限态的性质，不是原轨迹在某步到达；原轨迹何时有限步到达由定理 2 刻画；目标不可实现时只得周期截面（定理 3）。

## 第八节　接口

输入：《误差驱动调宿数理式》v1.0 的 M\_EDR（定义 3.1—3.4、3.9，第四节方程，1.3 参数域）；场具化组式第二十（4.4）定理 20-2，在其原前提下按原强度承接；《调宿一般式》v1.0 的调宿结构。方法参照：同篇定理 20-7（证明在 4.4，11.4 为其三层接口）。

输出：五项区分与调宿平衡的定义；命题 1—3；定理 1—3；边界表与 H 组。  
——向调宿平衡判定式：交付定义 2.1、2.2 与蕴含图；由观测判定是否达到调宿平衡的判据另立。  
——向调宿观测反演式：收束态的可观测部分作为接口登记，不互为前提。  
——向势引作用必然式：每一步是否满足作用条件按该式判定；收束过程允许零写回与固定点，逐步非零改写不作一般前提。  
——向维护律工可达式：调宿平衡作为可达目标。

未答：非零动量下的收束条件；两层线性网与一般非凸模型的收束；容差对齐下的调宿平衡；脉冲网络上的等价更新与收束。
