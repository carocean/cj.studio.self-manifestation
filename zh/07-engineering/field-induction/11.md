# 调宿观测反演式

## 第一节　观测集与前向映射申报

### 1.1　问题

一次误差驱动调宿在运行中留下可观测的痕迹：每步的输出与损失，可能还有梯度、写回量或参数坐标。由这些观测，最多能知道调宿的什么，必然不能知道什么？目标的数值、参数的初态、目标的登记来源、施作的承担、对象层的内容资格，各在哪种观测下可辨、在哪种观测下必然不可辨？

### 1.2　前向映射

前向映射 H 取《误差驱动调宿数理式》v1.0 的 M\_EDR：第四节逐事件方程（采样、前向、标签、损失、伴随、梯度、动量、写回、监视），定义 3.7 的来源，定义 3.8 的目标声明与目标来源登记，定义 3.10 的 Rewrite^f、Bear\_R^f、GoalCond^f。前向域 𝒟：

\- 实现类为严格 𝒞\_EDR（有限计算图，op ∈ {in, mul, sq, add}）；  
\- 值域（定义 3.1）：参数、目标 g、节点值、标签、损失、伴随、梯度与动量的谓词值域均为全体有理数，即数值槽位对一切有理候选及其轨迹开放；采样索引与监视标志按原规则取有限值域；  
\- β = 0，初动量为 0；  
\- 数据 D = {0 ↦ 1, 1 ↦ 2}，采样表 π(k, s) = (k + s) mod 2，种子 s 已知；输入 x ∈ {1, 2}，均非零；  
\- 观测时窗为第 1—K 步；运行窗另含入口与相位 (0, 1)。

### 1.3　观测协议

各协议分别定义，不合并：  
O1　每步输出 y\_k 与损失 ℓ\_k（写回前）；  
O2-梯度　O1 加每步梯度 q\_k（各参数坐标）；  
O2-更新　O1 加每步写回量 η·v\_k；  
O3　O1 加每步末的参数坐标；含入口坐标者记 O3⁰；  
O末　只读窗末的参数坐标，不含 O1。  
组合协议取观测字段之并。若两次运行在各组成协议下的观测都相同，在组合协议下也相同。  
对照：x = 1、θ = 0、η = 0，g = 1 与 g = −1 两次运行，O1、O2-更新、O3 的观测相同；梯度为 −1 与 1，O2-梯度可分。

### 1.4　已知与隐藏

逐待识别量事前申报：

\| θ₀ \| 已知，y = w₂·(w₁·x) \| 隐藏 \| 已知 \| 已知 \| 已知 \|

## 第二节　反演问题陈述

以运行 h 为前像，H\_O(h) 为协议 O 下的观测序列，Z(h) 为待识别量。对观测值 y，前像集 H\_O⁻¹(y) 取 𝒟 内与其余已知量相符、在 O 下给出 y 的运行。Z 在 y 上可辨，当且仅当 Z(H\_O⁻¹(y)) 为单点。

量词分两种，读出时逐格标明：  
——逐观测值：对给定的 y，Z(H\_O⁻¹(y)) 单点记 1，至少两值记 0；  
——协议全域：所列条件下一切 y 单点，记「全域 1」；存在一个 y 使 Z(H\_O⁻¹(y)) 至少两值，记「全域 0」，并给出见证。  
⊥ 为未决：既未证单点，也未构造异值前像。

1 与 0 只对可实现的观测值（前像集非空）给出；前像集为空的观测值另报为超域或与申报不相容。「全域」的范围是该格所列条件下、冻结的已知配置（1.4）所生成的运行族。

可辨以纤维单点证明；不可辨以纤维中异值两点的具体构造证明，构造须是 𝒟 中的合法运行。代数对称（目标的反射、参数的交换与变号）只保证方程与观测相同；在 𝒟 的开放有理值域中，对称变体的入口与其后各步写入都是有理数，因而是合法运行。若另申报更窄的值域，纤维取解析纤维与合法运行的交集，点数与读出按交集重算；单点结论（可辨方向）在更窄的域中保持，因为它只要求实际观测来自合法运行。例：y = w·x，x = 1，η = 0，w₀ = 1/2，K = 1，g 的合法域申报为 {0, 2}：g = 2 给 O1 = (1/2, 9/8)；代数反射给 −1，不在合法域内；另一合法值 0 的观测不同；故该纤维为 {2}。

## 第三节　可识别性分析

### 3.1　目标数值 g

设定：y = w·x，θ₀ 已知，g 隐藏。平方损失下每步 \|y\_k − g·x\_k\| = √(2ℓ\_k)，x\_k ≠ 0 时 g ∈ {(y\_k ± √(2ℓ\_k))/x\_k}。逐步候选的交集是必要条件；唯一性另须核前向一致。例：θ₀ = 1/2，η = 1/8，g = 2，s = 0：第 1 步（x = 2）候选 {−1, 2}，第 2 步（x = 1）候选 {1/2, 2}，交集 {2}。

定理 1（g 的可辨界）　在 𝒟 中：  
(a) O2-梯度：任一步 g 可辨：q\_k = (θ\_{k−1}·x\_k − g·x\_k)·x\_k，g = θ\_{k−1} − q\_k/x\_k²，θ\_{k−1} 由已知量与此前观测递推。  
(b) O1，K = 1 或 η = 0：纤维为 {g, 2θ₀ − g}（𝒟 的开放有理值域中二者都合法）。逐观测值：ℓ₁ = 0（即 g = θ₀）时单点，否则两点；协议全域 0。  
(c) O1，K ≥ 2 且 η \> 0：g 可辨。  
(d) O2-更新、O3：η \> 0 时第 1 步可辨；η = 0 时写回量恒为 0、坐标恒为 θ₀，观测等同 O1，纤维同 (b)。  
证明：(a) 由伴随与梯度方程直接解出。(b) η = 0 时 θ\_k ≡ θ₀，y\_k = θ₀·x\_k 与 g 无关，ℓ\_k = (θ₀ − g)²·x\_k²/2 只依赖 \|θ₀ − g\|，故 g 与 2θ₀ − g 的观测逐步相同；K = 1 时第 1 步观测同理只依赖 \|θ₀ − g\|。(c) θ₁ = θ₀ − η·(θ₀ − g)·x₁²，对 g 的系数 η·x₁² ≠ 0，y₂ = θ₁·x₂ 唯一定 g。(d) 写回量为 η·q₁，坐标为 θ₁，η \> 0 时各唯一定 g。∎  
目标的登记身份与数值 g 分开：本节只识别数值；登记身份见 3.3。

### 3.2　参数初态 θ₀

设定：y = w₂·(w₁·x)，g 已知，θ₀ = (w₁, w₂) 隐藏。记 P = w₁w₂，S = w₁² + w₂²，δ₁ = (P − g)·x₁，c = η·δ₁·x₁。第 1 步写回 θ₁ = (w₁ − c·w₂, w₂ − c·w₁)，其乘积 P₁ = (1 + c²)·P − c·S。

定理 2（θ₀ 的观测等价类）　在 𝒟 中：  
(a) O1，K = 1，或 η = 0，或 δ₁ = 0：纤维为乘积等值集 {w₁w₂ = P}；P ≠ 0 时为双曲线，P = 0 时为两坐标轴之并。  
(b) O1，K ≥ 2、η \> 0、δ₁ ≠ 0：纤维恰为轨道 {±(w₁, w₂), ±(w₂, w₁)}。点数：θ₀ = (0, 0) 时 1；w₁ = w₂ ≠ 0 或 w₁ = −w₂ ≠ 0 时 2；其余 4。点数可由观测判定：P、S 已读出，w₁ = ±w₂ 当且仅当 S = ±2P。  
(c) O2-梯度：δ₁ ≠ 0 时单点（q₁ = δ₁·x₁·(w₂, w₁)）；δ₁ = 0 时同 (a)。  
(d) O2-更新：η \> 0 且 δ₁ ≠ 0 时单点；否则同 O1。  
(e) O3：θ₁ = \[\[1, −c\], \[−c, 1\]\]·θ₀，c 由 O1 的 P = y₁/x₁ 已知。c² ≠ 1 时可逆，单点（含 c = 0：θ₁ = θ₀ 直接读出）。c = −1 时 θ₁ 只给和 A = w₁ + w₂，与 P 解 t² − A·t + P = 0，判别式 (w₁ − w₂)²：w₁ = w₂ 时重根单点，否则两点 {(w₁, w₂), (w₂, w₁)}。c = +1 时 θ₁ 只给差 B = w₁ − w₂，由 w₂² + B·w₂ − P = 0，判别式 (w₁ + w₂)²：w₁ = −w₂ 时重根单点，否则两点 {(w₁, w₂), (−w₂, −w₁)}。两种情形此后的观测由 θ₁ 决定，不再增加信息。O3⁰ 单点。  
证明：(a) η = 0 时 θ 不变，y\_k = P·x\_k；K = 1 时第 1 步观测只依赖 P；δ₁ = 0 时 q₁ = 0，β = 0 下 θ 不变、此后 δ\_k = 0，观测只依赖 P。(b) 上界：y₁ 定 P；c ≠ 0 时 y₂ 定 P₁，进而定 S = ((1 + c²)·P − P₁)/c；P、S 定 {w₁, w₂} 至交换与联合变号（w₁ ± w₂ = ±√(S ± 2P)）。下界：前向只依赖 P；写回 w₁ ← w₁ − η·δ·x·w₂、w₂ ← w₂ − η·δ·x·w₁ 在交换下对称、在联合变号下等变，故轨道各点逐步观测相同；轨道各点及其轨迹都是有理值，在 𝒟 中合法。(a) 的乘积等值集中的有理点同理合法。点数按交换与变号的不动点计。(c)(d) 由梯度与写回量直接解出。(e) 由 θ₁ 的线性式与 P 的二次式直接得出。∎  
例（g = 2，s = 0，x₁ = 2）：K = 2、η = 1/8 时，入口 (0, 0) 的纤维为单点（残差非零，c = −1，P = S = 0 唯一定初态），(1, 1) 为 {(1, 1), (−1, −1)}，(1, 1/2) 为 {±(1, 1/2), ±(1/2, 1)}。O3 在 η = 1/4、入口 (1, 1) 时 c = −1，重根单点；η = 1/6、入口 (1, 1/2) 时 c = −1，两点 {(1, 1/2), (1/2, 1)}。g = −2、s = 1、x₁ = 1、η = 1 时 c = +1：入口 (1, −1) 单点，入口 (2, −1/2) 两点 {(2, −1/2), (1/2, −2)}。  
重标度：(1, 1/2) 与 (2, 1/4) 给出相同的前向函数，第 1 步 y 相同；第 1 步梯度为 (−3, −6) 与 (−3/2, −12)，第 2 步 y 为 55/32 与 245/64。两层重标度保持前向函数，不保持多步轨迹或梯度。

### 3.3　来源结构

对照：同一 y = w₂·(w₁·x)，θ₀ = (1, 1/2)，η = 1/8，K = 2，g 的数值同为 2，目标登记方式三种——  
　入口持有锚：入口 g = 2，Xg 持有 g；  
　运行窗内设定：入口 g = 0，目标设定事件在运行窗的 (0, 1) 处写 g := 2，位于第 1 步首个样本观测之前；  
　未登记：入口 g = 2，无持有锚、无设定事件。  
三者都是 M\_EDR 的合法目标入口（定义 3.8），都通过运行入口的登记契约；前向域不扩大。GoalCond 在整个运行窗上计算，观测窗为第 1—K 步。

探针覆盖的冻结 𝒟\_π：在 𝒟 上再把探针规格与其覆盖列为已知——从 g 到参数写回的事件链（标签、损失、伴随、动量、写回与前向）上，每个事件的每个读入变量，按定义 3.6 规范化（剔除不合法与等于当前值者、保序去重）之后的合法替代值数不少于该事件对它申报的次数，且所申报的次数上界属实；有限值域变量全枚举。在 𝒟 的开放有理值域中，以 19 个有理点 {k/7 : −9 ≤ k ≤ 9} 为替代序列、各事件申报次数不超过 2，即满足这一覆盖：每个读入变量规范化后至少有 18 个合法替代值。探针列表可见本身不保证覆盖。

定理 3（GoalCond 形式输出的不可辨）　目标登记方式隐藏、g 的数值已知时：  
(a) 一般域，存在性：对 O1、O2-梯度、O2-更新、O3 及其任一组合，存在观测值 y\*，其纤维含 GoalCond 形式输出为 1 与为 ⊥ 的运行；协议全域 0。  
(b) 𝒟\_π，逐观测值：任一由 𝒟\_π 中运行实现的观测值 y，其纤维同时含持有锚变体与未登记变体；前者的 GoalCond 形式输出为确定值 1 或 0，后者为 ⊥。故在每一个这样的 y 上，GoalCond 形式输出至少两值。输出 0 有两种情形：无实际改写；有实际改写而其来源未确定命中目标登记。  
(c) 覆盖条件不满足时不作逐观测值陈述，持有锚也可给 ⊥。例一：y = w·x，同一实际写回，把 g 的替代序列置空。例二：保留同一 19 点列表，而 g 的谓词值域申报为 g ≥ 2（在 𝒟 之外），y = w·x、w₀ = 1、g = 2、x = 1、η = 1，实际写回到 2；列表点都低于 2，规范化后目标读取没有合法替代值。两例中持有锚与未登记两支的数值观测相同，GoalCond 均为 ⊥；目标设定变体也不能靠登记的改变补足这一缺失。此时只有 (a)。  
(d) 定理所说的是 GoalCond 形式输出不可由观测识别。⊥ 是「目标条件未决」的形式值，不是否定；定理不断言上游目标条件在一支成立、在另一支不成立。  
证明：(a) 取上述对照，三种运行自第 1 步起逐事件方程相同（目标设定事件在 (0, 1)，g 的数值在第 1 步之前三者相同），各协议的观测字段逐一相同；GoalCond^f 查目标来源登记：持有锚与运行窗内设定为 1，未登记为 ⊥。y\* 取其共同观测值。  
(b) 任取 𝒟\_π 中的运行 h，构造另两种登记变体，观测同 (a)。未登记时无目标来源登记，GoalCond^f = ⊥。持有锚时，由 𝒟\_π 的覆盖条件，事件链上每个依赖检验规范化后的合法替代值数不少于申报的次数，依定义 3.6 每个检验完备，返回 1 或 0；来源标记因而都是确定的，GoalCond^f 为 1 或 0。监视事件只写 stop，stop 不被任何事件读取，不进入参数来源。∎  
分开陈述：持有锚与运行窗内设定的来源配置不同（锚与事件），GoalCond 输出相同（都为 1）——来源配置不同不等于谓词取值不同。数值 g 在定理 1 的条件下可辨，登记身份不可辨：数值可辨不推出目标来源可辨。

### 3.4　承担 Bear\_R

命题 4（纯末态：η = 1 的配置）　已知配置 𝒦\_末¹：y = w·x、g = 2、s = 1（x = 1）、η = 1、K = 1，入口 w₀ 隐藏；读数 Φ(w) = w，deg\_Φ(w) = 1，w 的申报替代序列为 19 个有理点 {k/7 : −9 ≤ k ≤ 9}——任一可实现末态的 w 规范化后至少有 18 个合法替代值，读数依赖检验至少实际入检一个异于当前 w 的合法值。在 𝒦\_末¹ 下，O末 不辨 Bear\_R^f（全域 0）。  
证明：w₀ = 1 时一步写回到 2，Bear\_R^f = 1；w₀ = 2 时已对齐，零写回，Bear\_R^f = 0。O末 同为 2。∎  
两次运行的 O1 不同，故这一对不构成 O1 或 O3 的见证。读回：按《误差驱动调宿数理式》7.1，Bear\_R^f = 1 在 B1—B4 下单向读回为承担结构项，0 只报形式值；故在这一见证纤维（窗末 w = 2）上，O末 不能认证承担，也不由此推出承担不成立。

命题 5（纯末态：η = 1/2 的配置）　已知配置 𝒦\_末^{1/2}：同 𝒦\_末¹ 而 η = 1/2。在 𝒦\_末^{1/2} 下，O末 唯一定 w₀，且 Bear\_R^f 可辨（全域 1）。  
证明：w₁ = w₀ − (1/2)(w₀ − 2) = 1 + w₀/2，对一切有理 w₀ 可逆。Φ(w) = w 严格依赖 w，且按所冻结的探针，任一快照上依赖检验入检一个异于当前值的合法值，故 dep(Φ, w) = 1；写回有实际改变当且仅当 w₀ ≠ 2。故 Bear\_R^f = 1 当且仅当 w₀ ≠ 2，即 w₁ ≠ 2；w₁ = 2 时 Bear\_R^f = 0。例：窗末 w₁ = 1 唯一反演出 w₀ = 0，Bear\_R^f = 1，在桥接条件下可读回承担。∎

读数探针是两命题的前件：保持其余设定、只把 w 的替代序列置空（合法域仍为全体有理数），η = 1 与 η = 1/2 时末态分别为 2 与 3/2，各有实际写回，而 Bear\_R^f 由 1 变为 ⊥；同一末态因此不能唯一确定形式承担。空探针不满足两份配置的前件；初态的数值反演 w₀ = 2(w₁ − 1) 不受影响。

两个命题属于两份不同的已知配置，各自的全域量词只及本配置所生成的运行族。在更广的配置族上可陈述的是：存在一种已知配置及其中的观测值，使 O末 不辨 Bear\_R^f。其余纯末态配置未证，记 ⊥。全程观测（O1—O3）下 Bear\_R^f 的可辨性未决。

### 3.5　对象层内容资格

𝒟 中没有资格函数及其合法变化的映射：M\_EDR 的目标指向登记只申报被调场的输入—输出关系（定义 3.8(a)），训练量与内容资格不互换（定义 3.9）。故在 O1—O3 与 O末 下，此观测协议没有建立资格读回；内容资格的可辨性未决，不作不可辨陈述。建立资格映射后，按第二节的纤维检验。

## 第四节　上界与下界

上界由第三节的单点陈述给出，下界由异值前像的构造给出。三值读出逐格绑定待识别量、协议与条件；全域量词以冻结的已知配置（1.4）与该格所列条件所生成的运行族为范围，值域为 𝒟 的开放有理值域；更窄的值域按第二节取交集重算：

\| 待识别量（条件） \| O1 \| O2-梯度 \| O2-更新 \| O3 \|

## 第五节　残余申报

### 5.1　不得作的推断

\- 低损失不推出对齐，更不推出内容资格：y = w·x，w = 3/2，g = 2，x = 1，ℓ = 1/8 ≤ 1/2 而不对齐。  
\- 末态不推出承担：O末 同为 2，Bear\_R^f 为 1 与 0（命题 4）。  
\- 梯度可辨数值不推出目标来源可辨：梯度定数值 g（定理 1(a)），不定登记身份（定理 3：梯度相同，GoalCond 1 与 ⊥）。  
\- 统计相关不推出可识别：可辨只以纤维判定，不以观测与待识别量的相关判定。

### 5.2　残余

未决：β \> 0 与非零初动量；一般参数线性模型上 O1 对 g 的可辨条件；多层与非线性图上 θ₀ 的纤维；全程观测下 Bear\_R 的可辨性；带噪观测；内容资格映射。

### 5.3　H 组与击穿

H1　前向域 𝒟 与已知量逐项事前申报；  
H2　β = 0，初动量为 0；  
H3　x\_k ≠ 0；  
H4　观测为精确有理值，无噪声。  
击穿：  
——对「全域 1」与逐观测值的 1：在该观测值上给出 𝒟 中合法、观测相同而待识别量异值的前像；  
——对精确纤维的陈述（如轨道点数）：给出纤维之外的合法前像，或证明所列某点不合法或观测不同；  
——对逐观测值的 0 与「全域 0」（存在性陈述）：所给见证失效（不合法、观测不同或值不异），只要求换证；存在性被反证，须证明该观测值上（全域 0 则为该配置下一切观测值上）不存在异值的合法前像。找到纤维之外的合法前像不击穿已证的逐观测值 0；单个可辨的观测值不击穿全域 0。
