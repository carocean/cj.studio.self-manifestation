自显论·工篇·势引组式第十三 v1.0

# 调宿平衡判定式

## 第一节　性质与观测集申报

### 1.1　问题

《调宿收束必然式》v1.0 定义了调宿平衡：被调场在申报输入上实现目标关系（对齐），且按协议继续执行不再写回（协议止调）。它证明在一定条件下训练的极限态是调宿平衡，却没有回答：在训练的某一时刻，凭观测能否判定当前状态已是调宿平衡？损失为零、一次不写回、优化器不再动，都不等于调宿平衡；对齐与止调又各须何种观测？

### 1.2　前向关系与被判对象

前向关系取《误差驱动调宿数理式》v1.0 的 M\_EDR 第四节（采样、前向、标签、损失、伴随、梯度、动量、写回、监视）；实现类为 M\_EDR 合法的计算图。M\_EDR 的 stop 只是监视标志（定义 3.9），不是停训联锁；外部或另行申报的停训联锁不在被判对象之内。  
被判对象逐项冻结：时点 t\*；状态 (θ\*, v\*, 相位)；此后的协议——周期采样表（周期 P，一个周期覆盖数据集 D）、学习率 η、动量系数 β、目标数值 g；D 中各输入非零。冻结的是被判对象；观察者能看到什么，按下列各协议另行列明。

### 1.3　性质

(e) 对齐：θ\* 在 D 的每个输入上输出等于 g·x。  
(c) 协议止调：自 t\* 起按协议继续执行，每一步写回量为零。  
Bal 调宿平衡：(e) ∧ (c)（《调宿收束必然式》定义 2.2）。  
(d) 达标：某一步的 ℓ ≤ ε，以所申报的当步损失 ℓ 与读数靶 ε 单列，不参与上三者。

### 1.4　观测集

被动观测：自 t\* 起按协议实际执行的窗内观测，不改动运行，沿原轨迹，各步对应的参数一般不同。协议沿用《调宿观测反演式》v1.0：O1 为每步输出 y\_k 与写回前损失 ℓ\_k；O2-更新为 O1 加每步写回量 η·v\_k；O2-梯度为 O1 加每步梯度 q\_k。另记两个投影：纯写回投影 π\_u（只含每步写回量）与纯梯度投影 π\_q（只含每步梯度）。各判据所需的最少字段与窗长逐项申报（第二节）。  
已知量：采样表与 t\* 的相位（从而各步输入 x\_k）、η、β 按各判据申报；g 是否已知亦逐项申报。  
主动探针 A：在冻结的 θ\* 上，对 D 的每个输入作一次数学读出（前向输出或残差）；不写回，不改动 θ、v 与相位；它不是 O1—O2。  
观测为精确有理值。

## 第三节　判据有效性

引理 1（止调的判别）　对 M\_EDR 合法的计算图：(c) ⇔ η = 0 ∨ (β·v\* = 0 ∧ ∀x ∈ D：q(θ\*, x) = 0)。  
证明：⇐：η = 0 时写回恒为零；否则 β·v\* = 0 且 θ\* 处各输入梯度为零，第 1 步 v = β·v\* + q = 0，写回为零、θ 不变，归纳得此后恒为零。⇒：设 η \> 0 且 (c)。第 1 步写回为零给 v₁ = β·v\* + q(θ\*, x₁) = 0，θ 不变；此后第 k 步写回为零给 v\_k = β·0 + q(θ\*, x\_k) = 0，故 θ\* 处第 2 步起出现的每个输入的梯度为零；周期覆盖使之及于 D 全体（含 x₁），从而 q(θ\*, x₁) = 0，β·v\* = 0。∎

引理 2（平衡的等价式）　Bal ⇔ (e) ∧ η·β·v\* = 0。  
证明：(e) 使 θ\* 处各残差为零，由伴随递推各梯度为零；代入引理 1，(c) ⇔ η = 0 ∨ β·v\* = 0。∎

定理 1（J\_bal）　对 M\_EDR 合法的计算图，J\_bal = 1 ⇔ Bal。  
证明：⇒：写回全为零，θ 在窗内保持 θ\*；各步 ℓ = 0 即 θ\* 在该步输入上残差为零，窗长 P 覆盖 D，得 (e)。第 1 步残差为零使 q₁ = 0，写回量 η·(β·v\* + 0) = 0，即 η·β·v\* = 0；由引理 2 得 Bal。⇐：Bal 下各步残差、梯度与写回都为零。∎

定理 2（J\_c、J\_c′、J\_c^β0）　对 M\_EDR 合法的计算图：(i) J\_c = 1 ⇔ (c)；(ii) η 已知时 J\_c′ = 1 ⇔ (c)；(iii) β = 0 已知时 J\_c^β0 = 1 ⇔ (c)。  
证明：(i) ⇐ 平凡。⇒：η = 0 时 (c) 成立。η \> 0 时，第 1 步写回为零给 v₁ = 0、θ 不变；第 2 至 P + 1 步写回为零给 θ\* 处这 P 个相继输入（覆盖 D）的梯度为零；由引理 1 得 (c)。(ii) 窗内有非零写回时 (c) 不成立，判 0 正确。η = 0 时 (c) 成立，判 1 正确。窗内写回全为零且 η \> 0 时，θ 保持 θ\*，第 1 步 v₁ = β·v\* + q₁ = 0，第 2 至 P 步给其余输入梯度为零；故 (c) ⇔ q₁ = 0 ⇔ β·v\* = 0（引理 1）。  
(iii) 已知 β = 0 时 J\_c^β0 = 1 ⇔ (c)：窗内有非零写回时 (c) 不成立；全为零且 η = 0 时 (c) 成立；全为零且 η \> 0 时，β = 0 给 v = q，写回为零即这一周期各输入的梯度为零，θ 保持 θ\*，由引理 1（β·v\* = 0）得 (c)。∎

定理 3（对齐判据）　(i) J\_e = 1 ⇔ (e)。(ii) J\_e′ 的 1 与 0 都有效。(iii) 参数线性图上 J\_e^lin = 1 ⇔ (e)。  
证明：(i) 由定义。(ii) 判 0 的那一步之前写回全为零，θ 仍为 θ\*，ℓ\_k ≠ 0 即 θ\* 在 x\_k 上残差非零；判 1 时 θ 全窗为 θ\*，各输入残差为零。(iii) ℓ₁ ≠ 0 即 θ\* 在 x₁ 上残差非零，不对齐；ℓ₁ = 0 时 y₁ = g·x₁，x₁ ≠ 0 给 g。第 k 步的参数为 θ\* − Σ\_{j\<k} 写回量\_j，参数线性给 θ\*·φ(x\_k) = y\_k + (Σ\_{j\<k} 写回量\_j)·φ(x\_k)；窗长 P 覆盖 D。∎

例（检验）：  
\- 损失为零而不对齐：y = w₁x + w₂x²，g = 0，x 按 1、2 循环，η = 1，β = 1/2，入口 θ = (1, −1)、v = (−2, 0)。两步损失均为 0，写回量为 (−1, 0)、(−1/2, 0)；θ\* 在 x = 2 上的输出为 −2，不对齐。J\_bal = 0，J\_e′ = ⊥，J\_e^lin = 0。  
\- 达标不判对齐：同一图，θ = (3/2, 0)，g = 2，η = 0，ε = 1/2：两步 ℓ = 1/8、1/2，均 ≤ ε，而不对齐；J\_bal = 0。  
\- 优化器不动不判平衡：η = 0 时 (c) 恒成立，Bal 取决于 (e)。

## 第四节　误判界

定理 4（纯写回投影的不可辨）　在一般申报域（η、β 不作为已知量限制）上，只用纯写回投影 π\_u、窗 P 时，存在两个状态，窗内写回量相同而 (c) 的真值不同。故该投影、该窗长下，没有判据能在申报域上处处完整判定 (c)；保守判据可在有非零写回时给 0，在写回全零且与见证同纤维时给 ⊥。  
证明：y = w₁x + w₂x²，g = 0，η = 1，β = 1/2，P = 2（先 x = 1，后 x = 2）。状态一 θ = (−1, 1/2)、v = (1, 1)：第 1 步梯度 (−1/2, −1/2) 与 β·v 相抵，写回为零；第 2 步 x = 2 处残差为零，写回为零；第 3 步回到 x = 1，写回非零。状态二 θ = (0, 0)、v = (0, 0)：平衡，写回恒为零。两者窗 P 内纯写回投影同为零。∎  
这一不可辨只属 π\_u：在完整的 O2-更新（含 O1）下两者首步 (y, ℓ) 为 (−1/2, 1/8) 与 (0, 0)，可分。已知量改变结论：η = 0 已知时 (c) 恒成立；β = 0 已知时 J\_c^β0 在窗 P 上完全（定理 2(iii)）。单样本周期（P = 1）的动量抵消同型：y = w·x，x = 1，g = 0，η = 1，β = 1/2，w₀ = 1，v₀ = −2：首个周期写回为零，下一周期写回非零。

误判界：J\_bal、J\_c、J\_c′、J\_e、J\_e^lin 在申报域内（M\_EDR 合法图、精确观测、协议冻结、周期采样覆盖 D）误判为零。J\_e′ 的 ⊥ 只出现于窗内有非零写回的状态；非参数线性图上这一 ⊥ 区是否必要，未证——主动探针 J\_e 给出完全判据。域外（采样非周期或不覆盖 D、观测带噪、协议在窗内改变、另行申报的停训联锁）判 ⊥。

## 第五节　判定定理

定理 5（判定定理）　在申报域内：  
(i) J\_bal 对 Bal 两向有效（定理 1），是调宿平衡的直接完全判据；  
(ii) J\_c 对 (c) 两向有效，J\_c′ 在 η 已知时、J\_c^β0 在 β = 0 已知时亦然；一般申报域上纯写回投影、窗 P 时有不可辨对（定理 2、4）；  
(iii) J\_e 对 (e) 两向有效；参数线性图上被动的 J\_e^lin 亦然；J\_e′ 的 1、0 有效（定理 3）；  
(iv) 分量判词的强 Kleene 合取 J\_e ∧ J\_c 是 Bal 的保守判据：分量判词可靠，合取的肯定与否定可靠；不由两分量的 ⊥ 推出联合不可辨。  
(v) 达标 (d)、一次零更新、监视标志与优化器停止，均不作 Bal 的判据。

## 第六节　接口

输入：《误差驱动调宿数理式》v1.0（第四节，定义 3.9）；《调宿收束必然式》v1.0（定义 2.1、2.2，命题 1—3）；《调宿观测反演式》v1.0（观测协议 O1、O2）。

输出：引理 1、2；判据 J\_bal、J\_c、J\_c′、J\_e、J\_e′、J\_e^lin 与其有效性；误判界；判定定理。  
——向调宿收束极限式：J\_bal(t\*) = 0 只排除被判时刻 t\*；要读出某一有限区间内处处未达平衡，须对区间内每个被判状态判定，或另有区间证明。例：y = w·x，x = 1，g = 0，w = 1，η = 1，β = 0：入口未平衡（写回量 1），更新一次即平衡（此后写回、损失为零）。  
——向维护律工可达式：J\_bal 作可达验收判据时，只在申报域与观测覆盖内读回。  
——向势引作用方式判定式：实施标记为直写的落点只是候选；进入本判定域，另核 M\_EDR 协议、周期采样与观测准入。

未答：非参数线性图上被动对齐判据的 ⊥ 是否必要；带噪观测与容差对齐；非周期采样。
