自显论·工篇·势引组式第十五 v1.0

# 势引律工构造式

## 第一节　条件组申报

### 1.1　问题

场具化组式第二十给出宿载层改变到动力层改变的一条可截取、可预测、可复算的对应，并把「势引律工如何截取目标场跨层的变律、在自身场内生成势引律、据之反复调控」登记为势引组式的任务。满足这一描述的对象长什么样？要求显式构造：被引场、律工、它们之间的端口与运行，并逐项验证。

### 1.2　条件组

对被引场 F、律工 G、目标规格 g、读数 Φ 与输入类 𝓘：  
C1 被引场 F：申报的具化场，场具化资格分两证——规则级机制见证（《势引数理式》v1.0 定义 3.10 的 P10）与某一实际窗中迹应、组织参与、历史动力的实际承担。  
C2 律工 G：另一申报的具化场，变量与 F 不交，经申报端口相接；其规则级与实际窗资格同样分证。  
C3 截取跨层变律：G 经申报端口取得 F 的宿载层改变 δ 与读数改变 ΔΦ 之间的对应（场具化组式第二十 11.3 的读出映射），并以自身迹应留存。逐项冻结：所截取的对应、观测与输入、适用域、读数纤维的界；区分真实截取与只记样本——留存的对应须对形成期未出现的案例给出正确预言。  
C4 势引律的资格：G 中一条律候选 L，其承载组织 R 由 G 的写入律经信号史形成，并经读值链决定 G 对 F 施作的写值。资格分档：正式成律须在同一承载组织上满足律组式《律数理式》的判据，经其回读条件得 Established ∧ Govern，再经《律必然式》的充分向得律；未满足者交律候选的构造并明示。  
C5 据之反复调控：G 依 L 对 F 在不交的时窗至少施作两次；每次分三项交付——实施途径（《势引作用方式判定式》v1.0 的实施标记）、六组必要项的形式读回（《势引数理式》定义 3.9 P1—P7 与 7.1、7.2）、事件资格（上游登记其肯定向为未答，本式不签）。  
C6 历史承担：在相同的外部目标与后续输入下，不同的合法形成史给出不同的承载组织，施作的写值随之改变；依协议检验所形成的组织时施作随之改变；形成与在用的读入证据分存；「由 G 内形成」按场具化组式第十八 D18-2、D18-3 的来源与留存核对；固定日程不满足以上各项。  
C7 维护配置：G 在 F 的维护窗中施作；冻结所用的比较（场具化组式第二十定理 20-8 的比较甲或比较乙）、保护读数、窗与输入族，单独验证，不因名称继承。

## 第二节　构造程序

### 2.1　被引场 F

变量：宿载层 w0、w1；运行层输入 x0、x1，膜驱动 u，读出 y；目标 g——界外变量，由目标持有者持有，目标声明指向 F，不属 F 的宿载层与运行层。场自身规则：膜驱动 u := w0·x0 + w1·x1；沉积（STDP 型）：x1 = 1 且 u ≥ 1 时 w1 增 1/8；读出 y := w0 + p·w1。读数 Φ = w0 + p·w1。端口：直写端口 {w0, w1}，输入端口 {x0, x1}。取 p = 2。

### 2.2　律工 G

变量：宿载层 c、C；运行层：读入的读数 yG、读入的目标 gG、命令 cmd、命令副本 dlt、读入的读数差 obs。场自身规则：计划 cmd := (gG − yG)/C；副本 dlt := cmd；沉积一（归一化最小均方）：c += (obs − c·dlt)/dlt；沉积二：C := c。输入端口 {yG、gG、obs}：分别读入 F 的读数、F 的目标、施作前后的读数差。  
触发条件：读数差读入、副本、沉积一、沉积二只在本窗命令 cmd ≠ 0 且读数差观测到达时执行；cmd = 0 的窗不执行这四项（无除零）。C 的入口值为 1，沉积一只在 dlt ≠ 0 时执行且 obs = p·dlt，故 c、C 在已签运行中保持非零（p = 2 时为 1、2；p = 3 时为 1、3），计划中的除法有定义。

### 2.3　入口（完整初态）

\| 变量 \| 入口值 \| 归属 \|  
\| w0、w1 \| 1/2、1/2 \| F 宿载层 \|  
\| x0、x1、u、y \| 0、0、0、0 \| F 运行层 \|  
\| g \| 2 \| 界外（目标持有者），指向 F \|  
\| c、C \| 1、1 \| G 宿载层（起点取得） \|  
\| yG、gG、cmd、obs \| 0、0、0、0 \| G 运行层 \|  
\| dlt \| 1 \| G 运行层（非零初值） \|

### 2.4　联合运行

一张全局事件表依相位次序执行；每个事件同时记入 F 与 G 各自的形式模型，在对方模型中以申报的界外分项出现，两侧数值逐事件同步。跨场传输都是实际事件：G 的输入端口读 F 的 y、g 与读数差；G 的计划读 C 出令；F 的直写端口事件（施作者 G）读命令写 w1。  
　W1（第 20 拍）：F 读出 → G 读入 y、g → G 计划（C = 1）→ G 经 F 的直写端口写 w1 += cmd → F 读出 →（若 cmd ≠ 0 且读数差观测到达）G 读入读数差、记命令副本、沉积 c、C。  
　第 25、26 拍：F 正常运行（输入 (1, 1)，沉积使读数漂移）。  
　W2（第 30 拍）、第 35、36 拍、W3（第 40 拍）：同 W1 的事件序列，计划读形成后的 C。  
G 的形成数据取自它在 W1 的实际施作后果；不用探针写入，不用检验置权。

## 第三节　逐项验证

C1　规则级 P10 = 1（申报路线：膜驱动、沉积、读出、目标设定、界外分项、输入端口、直写端口，穷尽）：迹应版本为第 25 拍沉积写出的 w1（来源含输入事件），读入事件为第 26 拍膜驱动（实际改变 u），后继写入为第 26 拍沉积写出的 w1。机制未申报时 ⊥。实际窗：同一运行中第 25、26 拍给出版本路径 w1（第 25 拍）—写值→ u（第 26 拍）—写值→ w1（第 26 拍）。

C2　规则级 P10 = 1（申报路线：计划、副本、两项沉积、界外分项、输入端口，穷尽）：迹应版本为 W1 沉积一写出的 c（来源含 G 的输入事件），读入事件为沉积二（实际改变 C），路径 c —写值→ C。实际窗：W1 的形成；基线（入口 C）为 1，形成值为 2，分辨 ε\_L = 0，留存自 W1 末至 W3 末。

C3　截取  
(a) 对应：w1 方向的读数斜率，ΔΦ = p·δ；作用结论只限 w1 方向的仿射读数斜率。  
(b) 观测与输入：G 只经输入端口读 F 的读数、目标与读数差；形成数据是 G 自身施作的命令副本与施作前后的读数差。  
(c) 适用域：读出模式 (1, p)；F 的状态任意；δ 非零有理。  
(d) 纤维：G 只读 Φ 的差；w0 方向的对应不在截取内。  
形成时刻：W1 的观测（δ = 1/2，ΔΦ = 1）是首个有效观测，沉积一把 c 由 1 改为 2；W2、W3 的观测 (−1/2, −1)、(−1/4, −1/2) 使沉积一执行而 c 不变，是用后验证。  
区分条件：对形成期未出现的 δ ∈ {3/2, −2, 1/3}，G 的预言 C·δ = 3、−4、2/3 与真值全等；只记所见样本的查表在三例上无预言。另一被引场 p = 3：入口读数 1/2 + 3/2 = 2 已等于目标，W1 的命令为 0，按触发条件不作读数差读入及其后的副本与沉积（目标与读数的读入照常）；第 25、26 拍的漂移使 W2 命令非零，G 于 W2 形成 C = 3；三例预言 9/2、−6、1 全等。

C4　势引律的资格  
律候选 L：「以 C 所存的斜率，把读数偏差换算为对 w1 的写入量」；承载组织 R = {c, C}。  
已证：R 由 G 的写入律经输入史形成（来源含输入事件，入口值 1 与形成值 2 不同）；R 在 W2、W3 施作时现行且留存；施作写值经读值链依赖 R——G 中 W2 的计划读入 W1 末形成的 C 版本，命令的来源含该版本；F 中 W2、W3 所写 w1 版本的来源含该 C 版本、c 版本与目标持有锚；以检验干预复位 R，施作随之改变（C6(b)）。  
未证：律组式《律数理式》定义 3.34—3.47 在 G 上的正式求值；《律判定式》向非运行基底场的桥接；同一承载组织的正式证书与回读条件。《律必然式》的充分向带承接条件 SC\_Hold，该条件在律组式中登记为语义承接条件、待证，不在本构造域内闭合。  
结论：本式交律候选的构造，未取得正式成律。

C6　历史承担  
(a) 同一 F、同一目标与后续输入，两条合法历史：H1（W1 后 G 读入读数差并沉积）：W2 前 C = 2，三次施作写后 (w1, 读数) = (1, 5/2)、(3/4, 2)、(3/4, 2)。H0（W1 后 G 的读数差输入缺席）：W2 前 C = 1，写后 (1, 5/2)、(1/4, 1)、(3/4, 2)（G 在 W2 读入读数差后形成）。W2 的写值随所形成的组织改变。  
(b) 检验干预：H1 下 W2 前把 C 复位为入口值 1，W2 写后 (1/4, 1)，与 H0 的 W2 相同。检验干预只作验证。  
(c) 形成证据：W1 的读数差读入、命令副本、沉积一、沉积二；在用证据：W2、W3 的计划读 C，施作读命令。  
(d) 与 D18-3 对应：来源——c、C 由 G 的写入律经输入写入，未由界外直接写值（F 上的施作仍在观测因果链上：读数差来自 G 在 F 上的施作后果）；留存——C 自 W1 末至 W3 末；层级——G 的宿载层。  
(e) 固定日程：两条历史各自照常执行 G 的读入与沉积，只在施作端以同一日程 (1/2, −1/2, −1/4) 写入。W2 入口 C：H1 为 2，H0 为 1；W2 的写入与读数在两史相同（(3/4, 2)），律工在两史下的 W2 写入为 (3/4, 2) 与 (1/4, 1)。历史承担的结论落在 W2。（H0 的 W2 中 G 的命令副本与实际写量不同，其后的沉积不作对实际写量的再估计；W3 只作固定执行的记录。）  
跨场移植对照：把 p = 3 所形成的 C = 3 置入 p = 2 的 G 且不再形成，W1 写后 w1 = 2/3、读数 11/6，不对齐。

C7　维护配置（比较甲）  
协议：从每次施作的实际改前、改后快照分叉，两臂保持同一实际残留（膜驱动 u 分别为 0、13/8、11/8），各执行四拍输入 (1, 0)。保护读数为膜驱动 u。结果：三对两臂的四拍膜驱动都是 1/2、1/2、1/2、1/2，全同（输入 (1, 0) 下 w1 对膜驱动无实际贡献，定理 20-8（甲））。保护读数的输入族 (1, 0) 与势差读数的输入族 (1, p) 不交；各调控窗内 F 无输入事件。放电读数与比较乙不签。  
许可操作：G 的输入端口读入；G 的场自身规则；G 经 F 的直写端口对 w1 的写入；F 的场自身规则与输入。检验干预（只作验证）：C 复位、跨场移植、固定日程。

## 第四节　构造定理

定理（势引律工的显式构造）　第二节的被引场 F、律工 G 与联合运行满足：C1、C2（规则级与实际窗分证）；C3（w1 方向读数斜率的截取，隔离案例全等）；C5（两次据律候选的调控，三项分交）；C6（形成史检验、检验干预、来源与留存核对，固定日程对照）；C7（比较甲）。C4 只到律候选。  
证明：第三节逐项给出形式值、版本来源与运行读数。∎

## 第五节　强度申报

\- 只取构造强度：不证律工唯一、最小或一般。  
\- 正式成律未取得：《律数理式》判据在 G 上的正式求值、向非运行基底场的桥接、同一承载组织的正式证书均未作；《律必然式》充分向的 SC\_Hold 不在本构造域内闭合。  
\- 每次调控只交必要结构的读回，不签事件资格。  
\- 不证调宿平衡可达，不证替代训练或权重空间编程，不签生物睡眠与梦。  
\- 截取只限 w1 方向的仿射读数斜率；维护配置只签比较甲于所申报的输入族、窗与膜驱动。  
H15-1　F、G 的机制路线申报穷尽属实。  
H15-2　F 的读出映射在 w1 方向线性（申报模型给出）。

## 第六节　接口

输入：《势引数理式》v1.0（定义 3.1—3.10，P1—P7、P10，7.1、7.2）；《势引一般式》《调宿一般式》v1.0 的必要结构；《势引作用方式判定式》v1.0 的实施标记；场具化组式第十八 D18-2、D18-3，第二十 11.3—11.6、定理 20-8；律组式《律数理式》《律判定式》《律必然式》。

输出：律工的显式构造与逐项验证；构造定理。  
——向维护律工可达式：许可操作集 {G 的输入端口读入、G 的场自身规则（含触发条件）、G 经 F 的直写端口对 w1 的写入、F 的场自身规则与输入}；初态取 2.3 的完整入口表；维护窗条件（窗内 F 无输入；保护输入族下被写位对保护读数无实际贡献）。结论限第二节的联合协议。  
——向训练替代区分式、权重空间编程区分式：律工的显式构造与固定日程对照。  
——向脉冲网络调宿成律可达式：律工实施教学这一路线。  
——律组式：正式求值、桥接与 SC\_Hold 为上游接口。
