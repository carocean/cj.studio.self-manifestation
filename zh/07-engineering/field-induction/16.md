自显论·工篇·势引组式第十六 v1.0

# 调宿收束极限式

## 第一节　基本设定

### 1.1　问题

《调宿收束必然式》v1.0 在首证子类 𝒦₀ 中证明：参数线性、无动量、周期覆盖、目标可实现、步长适当时，误差驱动调宿收束到调宿平衡；单模式下有限步到达当且仅当步长与特征的乘积为 1 或初误差在可调子空间上为零；目标不可实现时只得周期截面。它没有回答：步数趋于无穷、步长与动量系数趋于边界、目标不可实现时，收束还必然呈现什么——何时在有限时间内到达、何种参数下收束、越界之后如何退化、不可达时极限落在何处。

### 1.2　实现类与冻结项

实现类：《误差驱动调宿数理式》v1.0 的 M\_EDR 中参数线性的计算图，y = θ·φ(x)（K1）；采样表周期 P、周期内次序 x\_(1), …, x\_(P) 覆盖数据集 D（K3）；φ(x) ≠ 0（K6）。冻结项：P 与周期内次序、起始相位、步长 η \> 0、动量系数 β ∈ \[0, 1)、初参数 θ₀、初动量 v₀、目标 g。  
记号：V = span{φ(x) : x ∈ D}；β = 0 时第 j 步的参数误差映射 A\_j = I − η φ\_j φ\_jᵀ（在 V⊥ 上为恒等，保持 V）；前缀 B\_0 = I，B\_k = A\_(k) ⋯ A\_(1)；一周期映射 M = B\_P；H = Σ\_j φ\_j φ\_jᵀ（按周期内重复计）。目标可实现（K4）时取 θ\*\_V ∈ V 为插值点，误差 e = θ − (P\_{V⊥}θ₀ + θ\*\_V)，对齐 ⇔ P\_V e = 0。分支：β = 0 且目标可实现时用上述齐次参数映射；β = 0 且目标不可实现时用参数的仿射周期映射 θ ↦ Mθ + c（命题 5）；β \> 0 时用扩展状态 (θ, v)，一周期映射为各相位一步映射之积（只在 P = 1 时为同一步映射的幂），本式所证的带动量收束域只取单模式（命题 4）。

### 1.3　极限方向与次序

(A) 固定全部冻结项，步数 k → ∞；  
(B) 步长 η、动量系数 β 趋于收束域的边界——作为 (A) 的结论随参数变化的刻画，不作参数与步数的联合极限；  
(C) β = 0 且目标不可实现时，先 k → ∞ 取长时周期截面，再取 η → 0⁺；联合极限不签。

### 1.4　三种首次时刻

k\_e：首次对齐；k\_c：自该时刻起按协议继续执行每步写回为零（协议止调）；k\_bal：首次为调宿平衡——按《调宿平衡判定式》v1.0 引理 2 以「对齐且 η·β·v = 0」判定，v 取全部写回坐标，含 V⊥ 分量。

## 第二节　不可避免性

在参数线性实现类中，梯度只沿 φ(x) 改变参数，V⊥ 上不受梯度作用。三种情形的轨迹各由一个线性或仿射的周期映射决定：β = 0 且目标可实现时，参数误差为 e\_{mP+j} = B\_j M^m e₀；β = 0 且目标不可实现时，参数的周期截面由仿射映射 θ ↦ Mθ + c 决定；β \> 0 时，轨迹由扩展状态 (θ, v) 的一周期映射（各相位一步映射之积）决定，V⊥ 上的动量另按 β 衰减——此时参数本身没有不依赖初动量的周期映射（例：常值特征、标签 (1, 2)、η = β = 1/2、θ₀ = 0，初动量 0 与 1 的周期末参数分别为 3/2 与 5/4）。收束的性质因而由相应映射的谱与 Jordan 结构、初态在各广义特征方向上的实际激发、以及仿射项的投影决定，不可回避。第三、四节据此逐方向给出必然呈现的性质。

## 第三节　核心定义与结构刻画

定义 3.1　稳定子空间 E\_s：M\|\_V 中 \|λ\| \< 1 的广义特征子空间之和。实际激发谱半径 ρ\_ex：初误差在其上有非零分量的广义特征子空间中最大的 \|λ\|。  
定义 3.2　收束参数域：全初态收束的 (η, β) 集合；指定初态收束条件：对给定初态收束到对齐点的条件。二者分写。

命题 1（止调与平衡同一时刻）　设 η \> 0、K1、K3、K6，任意 β ∈ \[0, 1)。对任一状态，协议止调 ⇔ 调宿平衡；故 k\_c = k\_bal，且 k\_e ≤ k\_bal，可严格小于。  
证明：《调宿平衡判定式》v1.0 引理 1：止调 ⇔ η = 0 ∨ (β·v = 0 ∧ ∀x ∈ D：q(θ, x) = 0)。η \> 0；K1 下 q(θ, x) = (θ·φ(x) − g·x)·φ(x)，K6 下其为零当且仅当残差为零；故止调 ⇔ 对齐 ∧ β·v = 0 ⇔ 对齐 ∧ η·β·v = 0。∎  
例：y = w·x，x = 1，g = 0，η = β = 1/2，(w₀, v₀) = (1, 2)：(w, v) 依次为 (1, 2)、(0, 2)、(−1/2, 1)、(−1/2, 0)；第 1 步对齐，第 2 步离开对齐，此后不在有限步成为调宿平衡（命题 4(iii)）。  
β = 0、目标可实现时三者相同：k\_e = k\_c = k\_bal（《调宿收束必然式》定理 2）。

命题 2（无动量的有限到达）　设 β = 0、K1、K3、K4。  
(i) 在第 k 步对齐 ⇔ B\_k·e₀,V = 0；k\_e = min{k : B\_k e₀,V = 0}，首次到达的相位由前缀决定，整周期映射的零空间不足以单独决定。  
(ii) 限制到 V 的前缀 B\_k\|\_V 的零空间随 k 不减；全部前缀零空间之并等于 ker (M\|\_V)^d，d = dim V。  
(iii) det(M\|\_V) = Π\_j (1 − η‖φ\_j‖²)，故 M\|\_V 奇异 ⇔ 某一 j 有 η‖φ\_j‖² = 1。若一切 η‖φ\_j‖² ≠ 1，有限步到达 ⇔ 入口已对齐；否则有限步到达的初误差恰为子空间 ker (M\|\_V)^d，它为真子空间当且仅当 M\|\_V 非幂零；M\|\_V 幂零时一切初误差在至多 d 个周期内消失。  
证明：(i) e\_k = B\_k e₀。(ii) B\_{k+1} = A\_(k+1)B\_k，故 ker B\_k\|\_V ⊆ ker B\_{k+1}\|\_V；周期内 ker B\_{mP+j} ⊆ ker B\_{(m+1)P} = ker M^{m+1}；幂的零空间链一旦不增即永不增，至多增 d 次。(iii) A\_j\|\_V 在 φ\_j 方向的特征值为 1 − η‖φ\_j‖²，其余为 1，故 det(A\_j\|\_V) = 1 − η‖φ\_j‖²。∎  
例（目标 g = 0，插值点 θ\*\_V = 0）：φ = e₁、3e₂（两输入、周期两步）。η = 1/9 时第 2 步零化 e₂ 分量：θ₀ = (0, 5) 于第 2 步到达，θ₀ = (1, 5) 永不到达。η = 1/10 时各前缀可逆，只有入口已对齐者到达。φ = (1, 1)、(1, −1)，η = 1/2：M\|\_V = 0，一切初态在一周期内到达。  
「一般不在有限步到达」的意义即 (iii)：例外初态是一个子空间，不以概率表述。

## 第四节　主结论：边界内外与越界退化

命题 3（无动量的收束边界）　设 β = 0、K1、K3、K4。  
(i) 指定初态：θ\_k 收束到对齐点 ⇔ e₀,V ∈ E\_s。  
(ii) 全初态：收束参数域为 {η \> 0 : ρ(M\_η\|\_V) \< 1}；《调宿收束必然式》的 K5 是其中的充分区间。该域不必是区间。  
(iii) 截面与全序列分写：  
　(a) 相位 0 截面误差趋于零，则各前缀 e\_{mP+j} = B\_j e\_{mP} 趋于零，全序列收束到对齐点。  
　(b) 相位 0 截面收敛到 e\* ≠ 0（初误差在 λ = 1 的半单分量非零、其余在 E\_s 中）时，相位 j 的截面收敛到 B\_j e\*；各相位极限不能全同——若 B\_j e\* = e\* 对一切 j，则 φ\_j·e\* = 0 对一切 j，e\* ∈ V⊥，与 e\* ∈ V、e\* ≠ 0 矛盾。故各相位截面收敛、全序列不收敛、永不对齐。  
　(c) 其他单位模态：λ = −1 的分量非零时截面在该模态上二周期振荡；\|λ\| = 1、λ ≠ 1 的半单模态（M 是对称矩阵之积，可有复特征值）分量非零时截面在该模态上有界而不收敛；单位模态上的非平凡 Jordan 块按其次数作多项式增长。混合初态按模态叠加。  
　(d) \|λ\| \> 1 的分量被激发时发散；未激发时不影响。  
　(e) 速率：ρ\_ex \> 0 时 ‖e\_{mP}‖ ≤ c·(1 + m)^{s−1}·ρ\_ex^m（m ≥ 0），s 为 \|λ\| = ρ\_ex 的被激发 Jordan 块的最大阶数；ρ\_ex = 0（只激发零根）时 e\_{mP} 在至多 s 个周期内为零，s 为被激发零根块的最大阶数；初误差为零时恒为零。全初态的最坏速率在 ρ(M\|\_V) \> 0 时为 c·(1 + m)^{s₀−1}·ρ(M\|\_V)^m，s₀ 为 \|λ\| = ρ(M\|\_V) 的最大 Jordan 块阶数；ρ(M\|\_V) = 0 时沿用幂零情形。  
证明：e\_{mP} = M^m e₀,V；各项由 M\|\_V 的 Jordan 分解与 e\_{mP+j} = B\_j e\_{mP} 得出。(ii) 全初态收束 ⇔ 一切 e 有 M^m e → 0 ⇔ ρ \< 1。∎  
非区间例：y = w·x，D = {1, 3}，周期 (1, 3)：一周期因子 f(η) = (1 − η)(1 − 9η)；\|f\| \< 1 ⇔ η ∈ (0, (5 − √7)/9) ∪ ((5 + √7)/9, 10/9)。η = 1/10：f = 9/100，收束；η = 1/2：f = −7/4，发散；η = 1：f = 0，第 1 步到达；η = 10/9：f = 1，周期内 w 在 3 与 17/9 间往复——相位 0 截面误差恒为 1，相位 1 截面误差恒为 −1/9，全序列不收敛；η = 6/5：f = 49/25，发散。  
未激发的不稳定分量：φ = e₁、3e₂，η = 1/2，e₂ 方向因子 −7/2：θ₀ = (3, 0) 收束，θ₀ = (3, 1) 发散。模态叠加：φ = e₁、(1/2)e₂，η = 2，因子 −1 与 1/2：截面 (1, 1)、(−1, 1/2)、(1, 1/4)、…。

命题 4（单模式带动量）　设 D 只含一个输入（P = 1），s = ‖φ‖² \> 0，η \> 0，β ∈ \[0, 1)，K4。  
(i) 取 e 为参数误差在 φ 方向的分量、v 为动量在 φ 方向的分量，一步映射 N = \[\[1 − ηs, −ηβ\], \[s, β\]\]（v′ = βv + s·e，e′ = e − η·v′）。全初态收束 ⇔ 0 \< ηs \< 2(1 + β)。  
(ii) 收束时 e\_k、v\_k → 0；V⊥ 上 v⊥\_k = β^k v₀⊥，θ⊥ 的极限为 P\_{V⊥}θ₀ − η·β·v₀⊥/(1 − β)；极限态为调宿平衡。β \> 0 且 v₀⊥ ≠ 0 时极限点不再是 P\_{V⊥}θ₀ + θ\*\_V；β = 0 时 V⊥ 无位移（v⊥ 第一步即为零）。  
(iii) β \> 0 时 k\_bal 有限 ⇔ 入口已是调宿平衡（e₀ = 0 且全部写回坐标上 v₀ = 0）。  
(iv) β \> 0 时，k\_e 的例外初态为可数条过原点直线之并（每个 k 一条，可以重合）。β = 0 时按命题 2：ηs = 1 时一切入口一步对齐，ηs ≠ 1 时只有入口已对齐者到达。  
(v) 边界与越界：  
　ηs = 2(1 + β)：特征根 −1 与 −β。入口只有 −1 模态时精确二周期；只有 −β 模态时收束；两模态均有投影时趋于该二周期。只有激发 −1 模态才有非零二周期极限。  
　ηs \> 2(1 + β)：β \> 0 时两实根皆负、乘积 β，一根绝对值大于 1、一根小于 1；β = 0 时两根为 0 与 1 − ηs。入口激发不稳定根时发散，入口在稳定特征向量上时收束。  
　ηs ↓ 0⁺：两根趋于 1 与 β，收束变慢，仍在收束域内。η = 0 不在本式域内。  
证明：(i) 特征多项式 z² − (1 + β − ηs)z + β，Jury 条件。(ii) V⊥ 上无梯度，累积位移 −η Σ\_{k≥1} β^k v₀⊥。(iii) det N = β ≠ 0，(e\_k, v\_k) = 0 ⇒ (e₀, v₀) = 0；v⊥\_k = β^k v₀⊥。(iv) β \> 0 时 N 可逆，每个 k 的条件是一个非平凡线性方程。(v) 边界时多项式为 (z + 1)(z + β)；越界时根之和 1 + β − ηs \< 0、积 β，判别式为正。∎  
例：η = 1、β = 1/2、v₀⊥ = 2：θ⊥ 依次为 −1、−3/2、−7/4、…，极限 −2，有限步内不成为调宿平衡。边界 s = 1、η = 3、β = 1/2：入口 (1, −2/3) 精确二周期；入口 (1, −1) 依次为 (−1/2, 1/2)、(1/4, −1/4)、…，收束；入口 (1, 0) 趋于 (±3, ∓2) 的二周期。越界 η = 15/4（根 −1/4、−2）：入口 (1, −4/3) 按 −1/4 收束，入口 (1, 0) 发散。β = 0、ηs = 3：入口 (1, 0) 依次为 1、−2、4、−8、16。

命题 5（不可达：目标不可实现）  
(i) 在《调宿平衡判定式》的判定域内，任一时刻不对齐，故调宿平衡在全部时刻不成立，该式的平衡判据在整段运行上恒判否。只用对齐不成立。  
(ii) 设 η \> 0、K1、K3、K6，任意 β：任一时刻协议止调不成立（由命题 1）。缺 K6 时不成立：y = w·(x + x²)，D = {−1, 1}，目标 y = x，w = 1/2：两点残差 1、0，梯度都为 0，入口动量为 0 时止调而永不对齐；η = 0 亦止调。这两例在扩大的工作域上，不涉《调宿收束必然式》保留 K5 的定理 3。  
(iii) 设 β = 0、K1、K3、K6。η 充分小（取在 K5 区间内）时一周期映射在 V 上严格收缩，各相位周期截面收敛；η → 0⁺（取在 k → ∞ 之后）时，各相位截面极限同趋于 P\_{V⊥}θ₀ + θ\_LS，θ\_LS = H⁺·Σ\_j g·x\_j·φ\_j 为周期内样本按重复次数加权的最小二乘解。  
证明：K5 下各 A\_j\|\_V 非扩张，一周期映射在 V 上严格收缩（《调宿收束必然式》定理 3 所承场具化组式第二十定理 20-2）；由 M\_η\|\_V = I − ηH\|\_V + O(η²) 与 H\|\_V 可逆，‖(I − M\_η\|\_V)⁻¹‖ = O(1/η)；又 c\_η = O(η)，故截面不动点一致有界；截面不动点满足 (I − M\_η)θ̄ = c\_η，c\_η = η Σ\_j g x\_j φ\_j + O(η²)，除以 η 并令 η → 0⁺ 得 Hθ̄\_V = Σ\_j g x\_j φ\_j；每步改变量为 η 乘有界量，各相位截面之差为 O(η)；V⊥ 分量不动。∎  
例：常值特征 φ ≡ 1，目标 g·x，g = 1，D = {1, 2}。周期 (1, 2)：截面不动点 (3 − η)/(2 − η)，η = 1/2、1/10、1/100、1/1000 时为 5/3、29/19、299/199、2999/1999，趋于 3/2；周期 (1, 1, 2)：371/271、39701/29701、3997001/2997001，趋于 4/3。  
(iv) 仿射项与单位根（β = 0）：周期截面满足 e\_{m+1} = M e\_m + c。若 M\|\_V 在 λ = 1 上半单，且 c 在该特征子空间上的投影（沿 M 的其余不变子空间）非零，则截面每周期累加该投影，线性漂移。一般情形以增广矩阵 \[\[M, c\], \[0, 1\]\] 检查：初态实际激发其单位根 1 的二阶块的广义方向时，该分量线性增长；其余模态按各自性质判。  
例：φ ≡ 1，周期标签 (1, 2)，η = 2：两步因子都是 −1，M = 1，截面映射 w ↦ w + 2，截面 0、2、4、6、8，周期内 0、2、2、0、4、…。  
越界发散：同一采样，η = 3：两步因子都是 −2，M = 4，截面映射 w ↦ 4w，不动点 0；w₀ = 1 时截面 1、4、16、64、256，发散；w₀ = 0 时停在不动点（不对齐）。

## 第五节　唯一性

命题 5(iii) 的 θ\_LS 在 V 中唯一（H\|\_V 可逆）；命题 4(ii) 的极限点由入口唯一确定。不宣称其他唯一性。

## 第六节　解读（不属形式结构）

收束不只是「到或不到」。同一个可实现的目标，在步长落入两个分离区间之一时收束，落在中间时发散，落在边界时可能永远绕着对齐点走。带动量时，参数可以先一步到位又被惯性带离；在收束条件下，入口不是平衡的，平衡只在极限中取得。目标不可实现时，只要步长不为零、特征不为零，训练不会止调，也不会对齐。无动量时：小步长（K5）下截面趋于一个由步长与采样表决定的周期，并在步长趋零时逼近加权最小二乘解；若周期映射的线性部分具有半单单位根 1，而仿射项在其上的投影非零，该分量一圈一圈地漂走（仿射映射本身为恒等时截面不动）；步长越界时截面可以发散。

## 第七节　最终结论与未答

在 M\_EDR 的参数线性实现类与周期采样下：  
　η \> 0、K6、周期覆盖下止调与平衡同时刻（命题 1）；β = 0 时无动量有限到达的初态恰为一个子空间（命题 2）；β = 0 时收束参数域由一周期映射的谱半径给出且可不连通，截面收敛不保证全序列收敛（命题 3）；单模式、β ∈ \[0, 1) 的收束区间、边界二周期与越界的激发依赖，0 \< β \< 1 时非平衡入口不在有限步成为平衡（命题 4）；目标不可实现时平衡全程不成立，η \> 0 与 K6 下止调全程不成立，β = 0 且 K5 下小步长截面趋于加权最小二乘解，β = 0 时周期映射线性部分的半单单位根 1 上仿射项的投影非零则该分量线性漂移（命题 5）。  
本式不承担保持与复归。  
未答：多模式周期采样带动量的收束边界与有限到达；\|λ\| = 1 的高阶 Jordan 块是否可实现；仿射项与高阶单位 Jordan 块并存的情形；β \> 0 的不可达截面与小步长极限；两层网、一般非凸、脉冲网络与容差对齐。
