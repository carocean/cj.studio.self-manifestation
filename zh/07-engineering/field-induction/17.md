自显论·工篇·势引组式第十七 v1.0

# 内容对齐结构必然式

## 第一节　目的

内容对齐使被调场在申报输入上实现目标。调宿变换宿载层，调谐变换动态层。要问的是：在冻结的内容任务、冻结的结构类与申报条件下，内容对齐是否必然把场的结构变换为与内容目标相应的特定结构——调宿是否必然变换迹应集合的结构，调谐是否必然变换动态层的结构。「发生了状态改变」不算结构变换；结构须以组织语言事前定义，并证明它与目标相应、实际承担读数。

## 第二节　核心命题

### 2.1　一般命题与本式所证

一般命题（开放）：  
　(调宿) 调宿必然把迹应集合的结构变换为与内容目标相应的特定结构；  
　(调谐) 调谐所变换的结构只落在动态层，不必然长出迹应集合结构，但必然把动态层的结构变换为与内容目标相应的特定结构。  
本式所证：在两个申报宿主与任务上，这两条命题的条件形式——调宿分两条路径（直写为起点而迹应由场自身写入律形成；直写改变既有迹应的沉积度），调谐取物理层固定；各自的完整前件与结论见第七节。一般命题在其他宿主与任务上保持开放。

### 2.2　迹应资格与迹应组织

两件事分开核：  
(a) 资格（场具化组式第十八 D18-3）：位 x 的每个资格区间由一次形成开始——由场自身写入律在输入下生成、且偏离基线的版本，即该区间的形成版本。区间内的改写（含直写）只改变沉积度，并在来源中留下界外成因的成分（D18-2）；回到基线即终止该区间；终止后只经直写再升起不恢复资格，须新的形成。当前身份读当前区间的形成版本。基线取入口值，分辨 ε\_L = 0。成员：当前资格区间延续至被判时刻，且当前深度版本之后实际执行的拍数不少于留存窗 L = 2。  
(b) 组织（D18-4）：带标签组织描述含成员、连接与各迹应的沉积度。沉积度由宿载机制承担（场篇第一《场数理式》沉积度 δ，方程 2 的积深与退浅）；深浅影响通行（方程 3a、定律 5；外篇第三「沉积度愈深，其阈值愈小」「深者先得其流」；内篇第六「反复而迹深，少用则迹淡」）。同一批迹应、同一张连接网，某条迹应变深或变浅，迹应集合的组织即改变。直写落在一条既有迹应的沉积度上，即以直写方式直接改变迹应组织（施作方式与必要项层面；完整的调宿事件资格另判）；「有界外直写」不推出「既有迹应组织未变」。

### 2.3　非平凡性的要求

结构类以组织关系的有限布尔式定义，事前冻结，对所用关系的取值等价饱和；每个关系类含合法对齐见证（目标相应）；所用关系在对齐态上实际承担读数（破坏即失配）；入口不在结构类中；存在发生了改变而不在结构类中的状态；结构类不等于对齐集。

## 第四节　动力

### 4.1　脉冲宿主 𝔐\_I

输入 s ∈ D = {A = (1, 0), B = (0, 1), AB = (1, 1)}。中间神经元 z\_I(s) = \[a\_A s\_A + a\_B s\_B ≥ 1\]；输出 z(s) = \[m\_A w\_A s\_A + m\_B w\_B s\_B − m\_u u z\_I(s) ≥ 1\]。w、a 为兴奋连接，u 为中间神经元到输出的抑制连接，权值非负（H17-1）；m ∈ {0, 1} 支撑在 w\_A、w\_B、u 上。任务：z(A) = z(B) = 1，z(AB) = 0。  
运行：每拍依次为输入（s\_A、s\_B 与教学信号 t）、中间神经元、膜驱动 v = m\_A w\_A s\_A + m\_B w\_B s\_B − m\_u u z\_I、放电 z = \[v ≥ 1\]、兴奋沉积 w\_X += t·s\_X/2、募集沉积 a\_X += t·s\_X/4、抑制沉积 u += κ·z\_I·z（κ 为律层可塑系数）。端口：输入、直写、门控；机制路线申报穷尽。读数：Φ\_z = z(AB)（状态层探针），Φ\_v = m\_A w\_A + m\_B w\_B − m\_u u·\[a\_A + a\_B ≥ 1\]（AB 下的膜驱动，运行层标量读数）。形成史：A、A、B、B（t = 1）；入口留存段：A、B、A、B（t = 0）。  
规则级 P10 = 1：迹应版本为第 1 拍兴奋沉积写出的 w\_A（来源含输入事件），后继版本为第 2 拍写出的 w\_A，路径 w\_A —写值→ w\_A；第 2 拍膜驱动读入首版并实际改变 v。各例的实际窗取自其自身运行的形成段。

### 4.2　线性宿主 𝔐\_L

y(s) = w1 s\_A + w2 s\_B + w3 s\_A s\_B（参数线性）。宿主写入律：w\_i += e·k\_i·(t − y)·φ\_i(s)，φ = (s\_A, s\_B, s\_A s\_B)，t 为目标输入，e ∈ {0, 1} 为教学使能输入；每拍执行输入、读出与写入，e = 0 时写入同值。k 为律层可塑系数。任务同上（A、B 输出 1，AB 输出 0）。读数：任务读数为三个输出与损失 ℓ = ½Σ(y − 目标)²；势读数在运行前申报，取 Φ\_L = y(AB) 或 Φ\_A = y(A)。

## 第五节　定理群

### 5.1　脉冲宿主的结构类

关系词汇 𝓡：r₁ = z\_I(A)，r₂ = z\_I(B)，r₃ = z\_I(AB)，r₄ = \[m\_u u \> 0\]，r₅ = \[m\_A w\_A \> 0\]，r₆ = \[m\_B w\_B \> 0\]。推导规则：兴奋驱动对输入集单调，任务读出非单调，故须有一条只在 AB 上被募集的有效负向通路，两条兴奋通路有效。  
数值结构类 S\_c^数：门全开时 𝓡 = (0, 0, 1, 1, 1, 1)（只读数值与门）。  
粗结构类 S\_c：{w\_A, w\_B, a\_A, a\_B, u} 都是成员，且属于 S\_c^数；即在扩充词汇 𝓡⁺ = 𝓡 ∪ {mem(x)} 上定义。  
深浅关系 D\_T：{w\_A, w\_B, u} 都是成员，且 δ\_u \> δ\_wA + δ\_wB − 1。  
动态层结构类 𝒮^m：𝓡 在门控有效权上取 (0, 0, 1, 1, 1, 1)。宿载组织结构类 𝒮\_θ：𝓡 在 θ 上取该值，不问成员来源。

定理 1（对齐刻画）　记 w̃ = m·w、ũ = m\_u u。对齐 ⇔ w̃\_A ≥ 1，w̃\_B ≥ 1，a\_A \< 1，a\_B \< 1，a\_A + a\_B ≥ 1，ũ \> w̃\_A + w̃\_B − 1。  
证明：若 z\_I(AB) = 0，则 z\_I(A) = z\_I(B) = 0，z(AB) = \[w̃\_A + w̃\_B ≥ 1\]，而 z(A) = 1 给 w̃\_A ≥ 1，矛盾；故 z\_I(AB) = 1，a\_A + a\_B ≥ 1，且 ũ \> w̃\_A + w̃\_B − 1。若 z\_I(A) = 1，z(A) = 1 给 ũ ≤ w̃\_A − 1；而 z(B) = 1 给 w̃\_B ≥ 1，于是 ũ \> w̃\_A，矛盾；故 a\_A \< 1、w̃\_A ≥ 1，B 同理。反向代入。∎  
推论：对齐 ⇒ 𝓡 = (0, 0, 1, 1, 1, 1) 且 ũ \> w̃\_A + w̃\_B − 1。后一数值关系在全模型中只是必要条件（θ = (1/2, 1, 1/2, 1/2, 2) 满足而不对齐）；在 w̃\_A ≥ 1、w̃\_B ≥ 1、a\_A \< 1、a\_B \< 1、a\_A + a\_B ≥ 1 已成立的截面上与对齐等价。

定理 2（非平凡与承担）  
(a) 分层饱和：S\_c^数 由 𝓡 的取值定义，对 𝓡 等价饱和；S\_c 由 𝓡⁺ 的取值定义，对 𝓡⁺ 等价饱和。两条运行史在 W 末可有相同的读出权与募集权（𝓡 同值）而 S\_c 不同——例五与例二即是，差别只在 u 是否为成员。  
(b) 状态层：入口 (1, 1, 1/2, 1/2, 0) 不在 S\_c^数 中；只改 w\_A := 2 的状态不在 S\_c^数 中；S\_c^数 中有不对齐者（u = 1/2）；D\_T 的数值关系中有不对齐者（上例）。成员层：例一入口不在 S\_c 中（u 不是成员）；例二 W 入口在 S\_c 中而不对齐（含留存的非对齐见证）；例二 W 末与留存末在 S\_c 中且对齐（成员类的合法对齐见证）。线性宿主的 D^L 数值等式在例六入口已真，不要求每个子谓词在入口为假。  
(c) 调宿、调谐两路都有合法对齐见证（5.3）。  
(d) S\_c^数 只有一个 𝓡 关系类，含对齐见证；成员类 S\_c 的见证见 (b)。无对齐见证的关系类不得并入（「对齐集并上一个孤立类」不通过）。  
(e) 承担（对一切满足定理 1 的非负有理 θ）：u := 0 → z(AB) = 1，AB 失配；a\_A := 1 → z(A) = 0（因 u \> w\_A），A 失配；a\_A := a\_B := 0 → AB 失配；w\_A := 0 → A 失配。  
证明：(e) 逐项代入定理 1 的条件。∎

定理 3（必写）  
(Q1) 无冗余时：自 (1, 1, 1/2, 1/2, 0) 每个对齐态都改变 u；自 (1, 1, 0, 0, 2) 每个对齐态都改变 a\_A、a\_B。  
(Q2) 冗余扩展（申报：k 个中间神经元，募集权 a\_{j,A}、a\_{j,B} ≥ 0，抑制权 u\_j ≥ 0，各连接可门控）：对齐 ⇒ Σ\_{j ∈ J₀} ũ\_j \> 1，J₀ 为只在 AB 上被募集的单元。  
证明：记 S\_s = Σ\_j ũ\_j z\_j(s)。z(A) = 1 给 S\_A ≤ w̃\_A − 1，z(B) = 1 给 S\_B ≤ w̃\_B − 1，z(AB) = 0 给 S\_AB \> w̃\_A + w̃\_B − 1。募集对输入集单调，故 S\_AB ≤ Σ\_{J₀} ũ\_j + S\_A + S\_B，合并得 Σ\_{J₀} ũ\_j \> 1。∎  
整组承担：把 J₀ 全组的抑制置零，A、B 不变，AB 膜驱动 ≥ w̃\_A + w̃\_B − (S\_A + S\_B) ≥ 2，AB 放电，失配；单个单元的消融不必失配（u₁ = u₂ = 2 时删任一条仍对齐）。承担签在合计关系与整组干预上。  
事前冻结的候选位族 K = {u\_j, m\_uj, a\_{j,A}, a\_{j,B}} 与终态谓词「j ∈ J₀」。入口一切 ũ\_j = 0 时，每条合法对齐史都改变某个 u\_j 或其门，且该单元在终态满足终态谓词。一般入口：合计关系只依赖 K；入口不满足而终态满足时，K 中必有改变，可以只是募集权（例：w = (1, 1)，u₁ = 2，u₂ = 0，募集权都为 1/4；只把第一单元的募集权提到 1/2 即对齐）。

定理 4（调谐支的存在前提）　固定 θ，存在对齐门态 ⇔ θ 在门全开时对齐；对齐门态唯一为全开。  
证明：门只把有效权置零；对齐要求 w̃\_A、w̃\_B ≥ 1 与 ũ \> 0。∎

定理 5（路径一：直写为起点，后继由场自身写入律形成迹应）　设入口 {w\_A, w\_B, a\_A, a\_B} 为成员，u 在基线。若一段运行达到对齐，终态 u 有由场自身写入律在输入下开始并延续的资格区间，u 与其余成员的当前深度版本已留存，其余成员在该段内保持资格，则终态 S\_c 与 D\_T 成立。  
证明：由定理 1 推论得 𝓡 取值与数值关系；资格与留存由前件给出。∎

定理 6（路径二：直写改变既有迹应的沉积度）  
(i) 若入口 δ\_u ≤ δ\_wA + δ\_wB − 1，任一达到对齐的运行终态满足 δ\_u \> δ\_wA + δ\_wB − 1。  
(ii) 若 u、w\_A、w\_B 的资格区间自入口延续至终态，这三条迹应身份连续；若入口与终态三者都是含留存的成员，则 (i) 的翻转是同一组成员迹应之间深浅关系 D\_T 的翻转——迹应集合组织改变，成员与身份不变。签整个迹应集成员不变须另核其余成员的进出；有回到基线后的重建时另判。  
(iii) 若 (ii) 的改变由施作者直写既有迹应的沉积度承担，则是以直写方式直接改变迹应组织（施作方式与必要项层面；不签完整调宿事件）。  
证明：(i) 由定理 1 推论。(ii) 资格区间延续即身份不变（2.2(a)），直写只改沉积度。(iii) 由 (ii) 与直写的来源。∎

### 5.2　线性宿主的结构类

定理 L1　对齐 ⇔ (w1, w2, w3) = (1, 1, −2)。  
证明：y(A) = w1 = 1，y(B) = w2 = 1，y(AB) = w1 + w2 + w3 = 0，消元得 w3 = −2；反向代入。∎  
推导规则：兴奋特征的贡献对输入集单调，任务读出非单调，故共现迹应为负且其深度抵消两兴奋迹应之合。粗结构 S\_c^L：w1 \> 0、w2 \> 0、w3 \< 0；深浅关系 D^L：−w3 = w1 + w2。对齐 ⇒ S\_c^L ∧ D^L（数值读法；成员读法另须三位都是含留存的成员）。非平凡：S\_c^L、D^L 各含不对齐者（如 (1/2, 1/2, −1/2)、(2, 2, −4)）；承担：对齐态 w3 := 0 使 AB 输出 2，w1 := 0 使 A 输出 0。

定理 L2（路径一的闭式递推）　入口 θ = 0，可塑系数 k = (1/3, 1/3, 1/3)，A、B、AB 循环教学。第 n 个周期末 θ = (x\_n, x\_n, −2x\_n)，x\_n = 1 − (8/9)^n。  
证明：入口满足 w1 = w2 = x、w3 = −2x（x = 0）。A、B 两步给 w1 = w2 = x̂ = x + (1 − x)/3；AB 步输出 2x̂ − 2x，三位各减 (2x̂ − 2x)/3，得 w1 = w2 = x + (1 − x)/9，w3 = −2(x + (1 − x)/9)。∎  
推论：θ\_n → (1, 1, −2)；极限态对齐，下一周期零写回。这是递推的数学极限，不是已发生的留存。

### 5.3　运行证据（同一运行逐例）

各例的运行依次为形成段、入口留存段、施作窗 W（第 20—23 拍，AB 输入 t = 0）与留存窗（第 30—35 拍，A、B、AB 各两次）。W 的必要项按 W 入口相位读回；目标声明与指向经运行入口的登记一致性校验；边界为申报项（施作者在场外）；事件资格不签。状态层的对齐见证与调宿、调谐事件资格分写。

例一（调宿·路径一：直写可塑系数，抑制迹应由场自身写入律形成）　入口 κ = 0、u = 0，形成与留存后成员为 w\_A、w\_B、a\_A、a\_B；S\_c、D\_T 假。W：施作者直写 κ := g/2 = 1/2（读目标）。逐拍：第 20 拍 AB 放电、u = 1/2（S\_c 值成立）；第 21 拍 u = 1；第 22 拍 u = 3/2（D\_T 值与状态对齐成立）；第 23 拍 AB 首次实际不放电。含留存的 S\_c、D\_T 于第 30 拍末成立（第 24—29 拍不执行）。u 的资格区间始于第 20 拍的抑制沉积，来源含输入事件与可塑系数的直写版本。必要项：净势差 ΔΦ\_v = −3/2；实际改变、直写、Org₀（第 13 拍末）、Rewrite、Bear\_R、目标条件均为 1。

例二（调宿·路径二：直写加深既有浅抑制迹应）　入口 κ = 1/2；形成段后一次 AB 输入使抑制沉积把 u 由 0 写为 1/2，四拍留存。W 入口：成员 w\_A、w\_B、a\_A、a\_B、u；沉积度 w = (1, 1)、a = (1/2, 1/2)、u = 1/2；S\_c 真，D\_T 假；AB 膜驱动 3/2、放电；不对齐。W：施作者直写 u := w\_A + w\_B − 1 + g = 2。W 末与留存末：成员不变；u 的资格区间仍是第 5 拍形成的那一个（身份不变），当前深度版本为直写版本，沉积度 1/2 → 2；D\_T 真；AB 膜驱动 0、不放电；A、B 照常放电；对齐。含留存的 S\_c 在第 20、21 拍为假（u 刚改写、未留存）、第 22 拍起为真；资格区间口径的 S\_c 始终为真——变的是深浅关系。必要项：净势差 ΔΦ\_v = −3/2；直写、Org₀（第 13 拍末）、Rewrite、Bear\_R、目标条件均为 1。

例三（对照：只经输入与场自身沉积，不是调宿）　入口 κ = 1/2，无施作者事件；AB 输入下抑制沉积形成 u，时序同例一；施作者的实际改变与目标条件为 0。

例四（调谐）　入口 κ = 1/2、m\_u = 0；门关时 AB 放电，抑制沉积把 u 写到 2（成员）。W 入口：S\_c、D\_T 已真，𝒮^m 假，不对齐。W：施作者门控 m\_u := g = 1。W 内宿载层无改变；𝒮^m 由假变真；对齐。必要项：门控、Bear\_G、目标条件为 1，ΔΦ\_v = −2。

例五（边界对照：直写一个无形成记录的位）　入口 u 的数值为 0，W 中直写 u := 2（u 的数值 0 → 2；u 不是迹应，这一数值不是迹应的沉积度）。W 入口、W 末、留存末三处：成员都是 w\_A、w\_B、a\_A、a\_B，沉积度与募集 K(s) = (0, 0, 1) 不变，限制到迹应成员的有效子集都是 A：{w\_A}、B：{w\_B}、AB：{w\_A, w\_B, 中间神经元募集}；S\_c、D\_T 皆假；对齐。u 无形成记录，不是迹应。只证得宿载组织改变；未获完整调宿资格前不作本式命题的反例。

资格连续性：一条迹应形成后被直写回基线，再被直写升起，其资格区间于回到基线时终止，不恢复；其后若经场自身写入律重新形成，新的资格区间绑定新的形成版本，当前身份读新的一个。

例六（线性·路径一）　入口 θ = 0；W = 施作者直写 k := (1/3, 1/3, 1/3) 起至第 10 个教学周期末。首次写入的可塑系数来源逐坐标：A 拍写 w1 只以 k1 为正承担；B 拍写 w2 只以 k2 为正承担；AB 拍写 w3 以 k1、k2、k3 为正承担。第 1 周期末 S\_c^L 数值成立；D^L 数值等式自入口（0 = 0）即成立，不作由假变真的关系。任务损失由 1 降到 (8/9)^20；去掉直写的对照损失保持 1。势读数 Φ\_L = y(AB) 在 W 两端都为 0，净势差必要项在此读数下不满足；运行前申报 Φ\_A = y(A) 时，同一施作与输入下 ΔΦ\_A,W = 1 − (8/9)^10，直写、Bear\_R、目标条件为 1。施作期间 w3 每周期改写，不满足留存；停止施作（e = 0）四拍后三位都是含留存的成员，S\_c^L 与 D^L 成员读法为真，完整目标未精确对齐；精确对齐只在定理 L2 的极限中。  
必写（K = {w3}，承担依据为 w3 := 0 使 AB 失配）：有限史——由入口取得 S\_c^L 须 w3 由 0 变负（本史第 1 周期末 w3 = −2/9）；极限——精确任务终点须 w3 = −2。

例七（线性·路径二）　入口 k = (1, 1, 0)，A、B 教学各一次形成 w1 = w2 = 1；环境把可塑系数设为 (0, 0, 1/4)（律层，非施作者）；一次 AB 教学形成 w3 = −1/2；四拍留存。W 入口：三位都是成员，S\_c^L 真、D^L 假，AB 输出 3/2，不对齐。W：施作者直写 w3 := −(w1 + w2)·g = −2。W 末与留存末：w3 的身份仍是 AB 教学形成的那一版，沉积度 1/2 → 2，D^L 真，对齐。必要项：净势差 ΔΦ\_L,W = −3/2；直写、Org₀、Rewrite、Bear\_R、目标条件为 1。  
Q2（K = {w3}，承担依据为 w3 := 0 使 AB 失配）：每条由入口 (1, 1, −1/2) 达到对齐的合法有限史都把 w3 由 −1/2 改到 −2（唯一对齐点）；本史于 W 内由直写完成。

## 第六节　边界情形与结构崩坏条件

\- 直写一个无形成记录的位：宿载组织改变，迹应组织不变（例五）。  
\- 只经输入与场自身沉积：结构同样长出，但不是调宿（例三）。  
\- 冗余实现：公共必改坐标可为空，只签合计关系与候选位族的必命中（定理 3）。  
\- 调谐支：θ 门全开不对齐时无对齐见证（定理 4）；调谐后场自身写入律可能据改变的活动写入宿载层，这是场自身沉积，不是调谐落点，也不是必然结果。  
\- 资格不连续（回到基线）时，不由旧形成版本延续身份。  
\- 线性宿主只有唯一对齐点，D^L 在该宿主中即 AB 分量的对齐条件。  
\- 反例条款：对本式所证的条件命题，击穿为第七节某一式的前件全部成立而结论不成立的运行。对 2.1 的一般命题（开放），若某实例确属调宿并达到对齐，而迹应集合的成员、所申报的组织关系与既有迹应的沉积度都没有改变，即作为该命题在该工作域内的反例。  
H17-1　连接符号由申报给出，权值非负（脉冲宿主）。  
H17-2　调谐支：θ 在门全开时对齐。  
H17-3　留存窗 L = 2 拍、ε\_L = 0、基线取入口值。

## 第七节　总结公式

在所申报的两个宿主、任务与 H17-1、H17-3 下（H17-2 只用于调谐）：  
　调宿·路径一（脉冲）：入口 u 在基线、{w\_A, w\_B, a\_A, a\_B} 为成员 ∧ 施作者直写可塑系数 ∧ 终态 u 有由场自身写入律在输入下开始并延续的资格区间 ∧ u 与其余成员的当前深度版本已留存、其余成员在该段内保持资格 ∧ 对齐 ⇒ S\_c ∧ D\_T（成员读法）。〔定理 5；例一于留存窗读出〕  
　调宿·路径一（线性）：入口 θ = 0 ∧ 施作者直写可塑系数 k = (1/3, 1/3, 1/3) ∧ 按 A、B、AB 次序与任务标签至少教学一个完整周期 ∧ 其后 e = 0 并留存至少两拍 ⇒ S\_c^L ∧ D^L（成员读法）；精确对齐只在极限中（定理 L2）。其他可塑系数或次序不在本式内（例：只直写 k1 = 1/3、k2 = k3 = 0，同一输入与留存，末态 (2/9, 0, 0)，S\_c^L 不成立）。〔例六〕  
　调宿·路径二：入口深浅关系为假（D\_T 或 D^L）∧ 施作者直写既有迹应的沉积度 ∧ 相关迹应的资格区间自入口延续至终态 ∧ 入口与终态它们都是含留存的成员 ∧ 对齐 ⇒ 深浅关系由假变真，相关迹应（u、w\_A、w\_B，或 w1、w2、w3）的成员与身份不变；迹应集全体成员的保持按定理 6(ii) 另核（例二、例七已核）。〔定理 6；例二、例七〕  
　调谐：θ 固定 ∧ H17-2 ∧ 入口 𝒮^m 为假 ∧ 门控 ∧ 对齐 ⇒ 𝒮^m 由假变真，宿载层的数值与连接保持；不设入口为假时，只得终态属于 𝒮^m。若另有入口时相关迹应已是含留存的成员（其当前深度版本已留存），则迹应集合的成员与组织在该段内保持（例四即是）；否则成员资格可因留存期满而变化（例：门关时刚把 u 加深的一拍之后随即开门，u 在开门后才满足留存，成员集变化），此时不签迹应组织保持。〔定理 4；例四〕  
以上为模型内的条件结论；「施作者直写」「门控」只指施作方式，必要结构只作形式读回，不签调宿、调谐的事件资格。

## 第八节　接口

输入：《势引数理式》v1.0（定义 3.1—3.10）；《调宿一般式》《调谐一般式》v1.0 的必要结构；《误差驱动调宿数理式》v1.0；《调谐条件相容式》v1.0（相容模型参照）；场具化组式第十八 D18-2、D18-3、D18-4、D18-11、D18-12；场篇第一《场数理式》沉积度与方程 2、3a、定律 5。

输出：两宿主上的结构类、定理 1—6 与 L1、L2、七个运行例。  
——向一般化结构源式：结构候选「AB 专属抑制通路及其深浅关系」（线性宿主为负的共现迹应及其深浅关系），附合计承担依据；一般化结构的身份与可复用域不在本式。

未答：其他宿主与任务；容差对齐；调宿、调谐事件资格的肯定向。
