自显论·工篇·势引组式第十八 v1.0

# 维护律工可达式

## 第一节　初态与许可操作申报

### 1.1　问题

《势引律工构造式》给出了律工 G 与被引场 F 的显式构造：G 经输入端口读入 F 的读数与目标，以自身沉积留存 F 在被写位方向上的读数斜率，并据之经直写端口改写 F。构造中已发生对齐；问题是：从给定初态，经许可的操作，能否到达被引场的调宿平衡？路径如何，用几步？在哪些协议下到不了？

### 1.2　初态

取《势引律工构造式》2.3 的完整入口表：F 的宿载层 w0 = w1 = 1/2；运行层 x0 = x1 = u = y = 0；界外目标 g = 2，由目标持有者持有，指向 F；G 的宿载层 c = C = 1（起点取得）；G 的运行层 yG = gG = cmd = obs = 0，dlt = 1。被引场的读出为 y := w0 + p·w1，读数 Φ = w0 + p·w1，主宿主取 p = 2。

### 1.3　许可操作

许可操作集 𝒪：G 的输入端口读入；G 的场自身规则（计划、副本、两项沉积），含触发条件——读数差读入、副本与两项沉积只在本窗命令 cmd ≠ 0 且读数差观测到达时执行；G 经 F 的直写端口对 w1 的写入；F 的场自身规则（膜驱动、沉积、读出）与输入。𝒪 不含对 w0 的任何写入：G 只写 w1，F 的沉积也只写 w1。  
联合协议：调控窗 W\_n 依次位于第 20、30、40……拍，窗内事件依次为——F 读出 → G 读入 y 与 g → G 计划 cmd := (gG − yG)/C → G 经直写端口写 w1 += cmd → F 读出 →（触发时）G 读入读数差 obs、记副本 dlt := cmd、沉积 c := c + (obs − c·dlt)/dlt、沉积 C := c。窗内 F 无输入。联合协议只规定窗内；相邻两窗之间的宿主输入由所申报的路径（2.1）或续行协议（1.4）规定。拍号为日历标号：W\_n 位于第 10n + 10 拍；只有路径或续行中实际执行的拍计入拍数，未执行的标号不计。  
另申报三类变动，都不扩张 𝒪：  
　(i) 受限协议 R\_obs：G 的读数差观测不到达，触发条件不满足，C 保持入口值；R\_obs 是 𝒪 的子集。  
　(ii) 宿主与入口族〔族〕：宿主 F\_p（p ∈ ℚ），入口 w0、w1、g 为任意有理数，c = C ≠ 0，其余同 1.2；是初态的申报扩张，用于定理 2 与第四节的例。  
　(iii) 初态变体：只用于第四节的因子示例，不进入可达定理。  
步数以调控窗计（W1 为第 1 窗），另报拍数。

### 1.4　续行协议与调宿平衡

拟签平衡的窗之后，按冻结的续行协议继续执行：窗内事件与次序如 1.3；目标 g 固定；相邻两窗之间的宿主输入族冻结为下列之一：  
　K0（空窗）：窗间无输入事件，F 不执行场规则拍。  
　Kp（保护输入）：窗间两拍输入 (1, 0)。逐拍膜驱动 u := w0，沉积条件 x1 = 1 不满足，w1 不变，读数不变。  
　Km（主运行续行）：窗间两拍输入 (1, 1)，即律工构造的主运行在 W1 与 W2、W2 与 W3 之间所执行的输入。w0 + w1 ≥ 1 的拍上沉积使 w1 增 1/8，读数增 p/8。  
三者都在 𝒪 与维护窗条件（窗内 F 无输入）之内。  
判定截面：入口状态（其后第一窗为 W1）或某窗末状态（其后第一窗为按 K 执行窗间拍之后的下一窗）。对齐目标集 A = {Φ = g}。对续行 K，平衡集 B\_K：判定截面 σ，Φ(σ) = g，且自 σ 按 K 继续执行，此后每一窗 G 的命令为零、F 上无施作改写。因 cmd = (g − Φ\_入)/C，「此后每窗 cmd = 0」等价于「此后每窗入口 Φ = g」，故 B\_K ⊆ A。B\_K 依续行协议而定：不同的 K 对同一状态可给出不同判定。  
桥接：《调宿收束必然式》定义 2.2 以「对齐且协议止调」定义调宿平衡。在 F–G 系统上，对齐对应 Φ = g；协议止调对应「按申报续行继续执行，施作端此后零写回」。与该定义的原设定相比有三处差别：其一，写回者是另一场 G，F 自身的沉积不是写回却能移动 Φ，故 B\_K 以「此后每窗入口 Φ = g」同时承担零写回与对齐保持；其二，续行须显式申报；其三，本系统无动量，首个属 B\_K 的窗末即为平衡。《调宿平衡判定式》的判据 J\_bal 以 M\_EDR 合法计算图为判定域，F–G 联合系统不在其中；本式取模型内判据 J\_K——逐窗核对「入口 Φ = g、cmd = 0、施作不改 w1」，并以归纳证明此后保持。  
三种结论分立：(i) 首次对齐——某判定截面属 A；(ii) 调宿平衡——某判定截面属 B\_K；(iii) 扰动后再校正——各窗末重新属 A 而不属 B\_K。

## 第二节　路径构造

### 2.1　主路径

主路径：自 1.2 的初态执行 W1；W1 后先执行第 25、26 拍（输入 (1, 1)）；再执行 W2；W2 后按续行 K0、Kp 或 Km 分支。实际执行的拍为第 20 拍（W1）、第 25、26 拍、第 30 拍（W2）。逐窗：  
　W1：Φ\_入 = 1/2 + 2·(1/2) = 3/2，cmd = (2 − 3/2)/1 = 1/2，w1 = 1，Φ = 5/2；触发执行，obs = 1，dlt = 1/2，c := 1 + (1 − 1·1/2)/(1/2) = 2，C = 2——首个有效观测形成斜率。  
　第 25、26 拍：u = 1/2 + 1 ≥ 1，x1 = 1，沉积使 w1 = 9/8、5/4，Φ = 3。  
　W2：cmd = (2 − 3)/2 = −1/2，w1 = 3/4，Φ = 2；触发执行，obs = −1，dlt = −1/2，c := 2 + (−1 − 2·(−1/2))/(−1/2) = 2，C 不变。  
　W2 后按 K0 或 Kp：各窗入口 Φ = 2，cmd = 0，直写同值，触发条件不满足，C 与宿载层不变。按 Km：各窗入口 Φ = 5/2，cmd = −1/4，窗末再对齐（4.2 命题 3）。  
K0、Kp 续行八窗：各窗 (Φ入, cmd, Φ出, C) 自第 3 窗起恒为 (2, 0, 2, 2)；续行内无宿主沉积改变 w1，G 的读数差读入与沉积不执行。若在 W2 后先按 Km 执行第 35、36 拍与 W3（cmd = −1/4）而后转入 K0 或 Kp，则第 3 窗末起属 B\_K。  
对照：W1 后不执行第 25、26 拍而直接按 K0 续行，W2 的命令为 −1/4（不是 −1/2），W2 末同样对齐并属 B\_K0——这是 2.2 学习支的情形；主路径的逐窗数值依赖于 W1 与 W2 之间实际执行的两拍。

### 2.2　学习支

在〔族〕上，自入口起即按 K0 或 Kp 续行（窗间无漂移）。记 e₀ = w0 + p·w1 − g。e₀ ≠ 0 时，W1 的命令 cmd = −e₀/C 非零；窗内只有施作改变 Φ，且读出在 w1 方向线性，故 obs = p·cmd，沉积给 c := c + (obs − c·dlt)/dlt = obs/dlt = p，与 c 的入口值无关；C := p。W1 末误差 e₁ = (1 − p/C入口)·e₀；若 e₁ ≠ 0，W2 的命令 −e₁/p 使误差归零，沉积 c := obs/dlt = p 不变。入口因子 1 − p/C入口 只作用于 W1，不移入其后各窗。

## 第三节　代价与步数的界

定理 1（主路径）　自 1.2 的初态（p = 2），按 2.1 的主路径（W1、第 25—26 拍、W2），W2 末首次属 A，且 W2 末 ∈ B\_K0 ∩ B\_Kp。首次对齐与平衡都在第 2 窗末取得，实际执行的拍为第 20、25、26、30 拍。  
证明：对齐由 2.1 的逐窗计算给出，此前各窗末 Φ = 5/2。平衡：设某窗末 Φ = 2、C = 2、w0 = 1/2、w1 = 3/4。K0 下窗间无事件；Kp 下两拍 u := 1/2 \< 1 且 x1 = 0，沉积不写，w1 不变。下一窗入口 Φ = 2，cmd = 0，直写同值，触发条件不满足，C 不变，窗末宿载层与 C 同上一窗末。对窗数归纳，此后每窗 cmd = 0、入口 Φ = 2。∎

定理 2（学习支的步数界）〔族〕　设 p ≠ 0，入口 w0、w1、g 任意有理，c = C ≠ 0，自入口起按 K ∈ {K0, Kp} 续行。则：e₀ = 0 时入口截面即属 B\_K（其后第一窗为 W1）；e₀ ≠ 0 时 W1 形成 C = p，且 W1 末（若 C入口 = p）或 W2 末属 B\_K。A 与 B\_K 都在 ≤ 2 窗内取得。  
证明：e₀ = 0 时入口截面属 A；其后第一窗为 W1，每窗 cmd = 0，触发条件不满足，状态的宿载部分不变，故入口截面属 B\_K。e₀ ≠ 0 时由 2.2。保持由定理 1 的归纳：K0、Kp 窗间不改 w1，且与 w 的取值无关（Kp 的沉积条件 x1 = 1 恒不满足）。∎  
有理网格（p 取八值，w0、w1 各取四值，g 取三值，C 取四值，K 取两支，共 3072 例）上逐例成立：全部在 ≤ 2 窗内属 B\_K，其后八窗零写回且对齐；结论由证明承担。

常斜率支的步数　R\_obs 下 C 固定为入口值，误差递推 e\_n = (1 − p/C)·e\_{n−1}。全初误差收束至零 ⇔ \|1 − p/C\| \< 1；e₀ = 0 时任何因子下恒为零；e₀ ≠ 0 时，因子为 0 则一窗到达，0 \< \|1 − p/C\| \< 1 只有极限收束而任何有限窗都不到达，因子 −1 振荡，因子 1（p = 0）停滞，\|1 − p/C\| \> 1 发散。故有限步界只在因子为 0 时可给。例（初态变体 p = 2、C = 3/2，因子 −1/3，e₀ = −1/2）：e\_n = (−1/3)ⁿ·(−1/2) 恒非零而趋于零，与《调宿收束极限式》命题 1、2 的有限到达与极限收束之分一致。

## 第四节　可达定理与不可达边界

### 4.1　可达定理

可达定理　(a) 对 A：自 1.2 的初态按 2.1 的主路径（W1、第 25—26 拍、W2），A 在第 2 窗末首次取得；在〔族〕中（p ≠ 0，入口任意，C ≠ 0，K0 或 Kp 自入口起），A 在 ≤ 2 窗内取得。  
(b) 对 B：自 1.2 的初态按同一主路径，W2 后取 K0 或 Kp，B\_K0、B\_Kp 在第 2 窗末取得；在〔族〕中，在 ≤ 2 窗内取得。  
证明：定理 1、2。∎

### 4.2　不可达

可达集与 A、B 分判：  
\| 协议（入口） \| 可达集 ∩ A \| 可达集 ∩ B \|  
\| 主路径，W2 后 K0 或 Kp（1.2） \| 非空（W2 末起） \| 非空（W2 末 ∈ B\_K0 ∩ B\_Kp） \|  
\| 主路径（W1 与 W2 之间及其后都按 Km）（1.2） \| 非空（W2 末起每窗末） \| 对 B\_Km 为空（命题 3） \|  
\| R\_obs + K0（1.2，p = 2） \| 空（命题 1） \| 空 \|  
\| 宿主 F\_0，g ≠ w0〔族〕 \| 空（命题 2） \| 空 \|  
\| 宿主 F\_0，g = w0〔族〕 \| 非空（入口截面） \| 非空（入口截面属 B\_K0、B\_Kp） \|

命题 1（受限协议对 A 不可达）　R\_obs + K0 下，自 1.2 的初态，可达集的读数像为 {3/2, 5/2}，不含 g = 2。  
证明：C ≡ 1，因子 1 − 2/1 = −1，e₀ = −1/2，e\_n = (−1)ⁿ·e₀ ≠ 0；读数在 3/2 与 5/2 之间交替。∎  
同一协议下，p = 3 的宿主自 1.2 的入口读数已为 2（e₀ = 0），因子虽为 −2 而各窗恒对齐。

命题 2（读数不依赖被写位）　宿主 F\_0（p = 0）上，自任一入口，可达集的读数像为 {w0入口}；g ≠ w0入口 时 A 不可达。  
证明：Φ = w0，而 𝒪 不写 w0。∎  
g ≠ w0 时分两支：读数差观测到达，W1 的第一次沉积给 c := obs/dlt = 0，越出 G 宿载变量的非零类型，该沉积事件不合法，运行在 W1 中止；R\_obs 下每窗命令 (g − w0)/C 非零而读数不变，永不止调。两支的不可达都由 Φ ≡ w0 独立承担。g = w0 时入口截面已对齐，每窗命令为零，触发条件不满足，入口截面属 B\_K0 与 B\_Kp。

命题 3（对 B\_Km 不可达，对 A 可达）　自 1.2 的初态，W1 与 W2 之间及 W2 之后都按 Km（即主路径后接 Km），各窗末自 W2 起都属 A，而没有任何可达状态属 B\_Km。  
证明：𝒪 不写 w0，故 w0 ≡ 1/2；对齐即 w1 = (2 − 1/2)/2 = 3/4。Km 的下一拍 u = 5/4 ≥ 1、x1 = 1，沉积必写，第二拍 u = 11/8 亦然，下一窗入口 Φ = 5/2，cmd = −1/4 ≠ 0，窗末再对齐。故对齐态都不属 B\_Km，在 w0 = 1/2 的许可截面上 B\_Km 为空。∎  
区别见证：W2 末状态 (w0, w1, C) = (1/2, 3/4, 2)，Φ = 2，属 A；在 K0、Kp 下其后各窗 cmd = 0，属 B\_K0 与 B\_Kp；在 Km 下其后各窗 cmd = −1/4，不属 B\_Km。律工构造主运行中 W3 的再次施作即这一情形——一次零命令或一次对齐都不足以签平衡。  
不可达以许可操作可达集与 A、B 的相交为判，不以读数纤维判：w1 可任意有理写且 p ≠ 0 时，一切有理目标都有代数原像，而协议能否到达另须路径。以上为具体受限协议与宿主上的不可达，不穷尽全许可域的一切不可达原因。

## 第五节　强度申报

\- 证路径存在，及〔族〕中 K0、Kp 下的收束与步数界；Km（对 B）、R\_obs（对 A）与 p = 0 且 g ≠ w0（对 A）各有不可达结论，定理 2 不推出申报族之外。  
\- 调宿平衡在本系统上取 1.4 的桥接定义与模型内判据 J\_K；J\_bal 不在其判定域内调用。  
\- 律工的律资格保持《势引律工构造式》的律候选档：正式成律未取得，《律必然式》充分向的 SC\_Hold 未闭合。  
\- 不签调宿、调谐的事件资格；不签生物睡眠。  
H18-1　《势引律工构造式》的机制路线申报穷尽属实。  
H18-2　F 的读出在 w1 方向线性（申报模型给出）。

输入：《势引律工构造式》v1.0（2.3 入口、联合运行、许可操作、维护窗条件）；《调宿收束必然式》v1.0（定义 2.1、2.2，定理 2）；《调宿平衡判定式》v1.0（J\_bal 及其判定域）；《调宿收束极限式》v1.0（命题 1、2）；《势引数理式》v1.0。

输出：联合协议上的可达定理（A 与 B 分签）、学习支的步数界、常斜率支的收束条件、三条不可达命题与区别见证。
