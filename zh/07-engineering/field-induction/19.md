自显论·工篇·势引组式第十九 v1.0

# 脉冲网络调谐构造式

## 第一节　条件组申报

### 1.1　问题

《调谐条件相容式》给出了调谐前件的共存模型：一个最小脉冲网络中，场内中间神经元的放电经抑制通道关闭突触前门，传输实际读取门态。共存不是构造。问题是：在脉冲网络的一个参数族上，满足调谐诸条件的回路长什么样？要求显式给出由场内控制活动使役、经抑与去抑改变既有连接通透性的调谐回路，给出构造程序，并在其一般性范围内逐项验证。

### 1.2　条件组

对被调场 N、施作 I、窗 W、读数 Φ 与目标规格：  
C1 被调场：申报的脉冲网络，场具化资格分两证——规则级机制见证（《势引数理式》v1.0 定义 3.10 的 P10）与某一实际窗中的迹应、组织参与与历史动力。  
C2 调谐落点：(a) 每个调谐窗中，施作落在门控既有连接的通透性上（门控端口，m 层支撑在既有连接上），传输实际读取 m；(b) 两向存在：抑（关门）与去抑（开门）各在独立的调谐窗中有实例。  
C3 场内使役者的证据档：(i) 场内控制规则档——场内神经元的放电经申报控制链驱动门控；(ii) 律候选档——须有场内形成（来源含输入、非起点取得）、留存、施作写值对承载组织的依赖；(iii) 正式律档——同一承载组织上的律组式正式判据与回读，经《律必然式》充分向；(iv) 意向路线——须有其上游资格与承接。各档分立证据上限。  
C4 控制来源与承担：「目标版本 → 场内控制活动 → 门控事件 → 实际传输（读取 m）」的链；在保持输入与目标不变时干预控制输出，门控随之改变。控制来源的证明与作用方式分类（《势引作用方式判定式》的 L2）分开。  
C5 必要结构：《调谐一般式》的 Org₀、GoalRep、Target、ΔΦ、Eff、Bear、GoalCond、Gate、Bear\_G 逐项读回（形式读回；事件资格不签）。  
C6 一般性：在申报参数族上，候选域与成功域事前冻结，成功域内构造成立，失败支逐类给出。  
C7 物理层：取《调谐条件相容式》H14-0 的加强读法——调谐窗内无 θ 实际改变。

## 第二节　构造程序

### 2.1　参数族 𝒩

数值域：一切量取有理数，精确运算。既有连接 i = 0, …, n−1（n ≥ 1 有限）：权 w\_i ≥ 0（宿载层），突触前门 m\_i ∈ {0, 1}（m 层，支撑在 w\_i 上），突触前输入 zpre\_i；一个突触后神经元（膜驱动 u、放电 z）；门控子集 G\_sel；读数 Φ = Σ a\_i·m\_i·w\_i（a\_i 为申报的读出系数）；入口门态 m⁰；目标值 g ∈ {0} ∪ 𝒢，g = 0 为基线；𝒢 为互异非零有理数的有限集，各项按标签升序处理。拓扑限于此前馈族（单个突触后神经元、突触前门）。  
目标规格：对每个 g ∈ 𝒢，给目标读数 Φ\*\_g，或直接给目标门态 m^g ∈ {0, 1}^n 且 m^g\_i = m⁰\_i（i ∉ G\_sel）——未选的门不受控，其目标态须等于入口态；直接给门态时，诱导目标读数取 Φ\*\_g := Φ(m^g)。

### 2.2　构造步骤

第 0 步（目标门态与规格检查）：给 Φ\*\_g 时在 {0, 1}^{G\_sel}（未选门取入口态）上求 Φ(m) = Φ\*\_g，取改变门数最少者（字典序最先）；无解则停止，不出回路——目标不可满足。直接给 m^g 时先查长度、取值与未选门约束，不合即报目标在所选门集合上不可满足。记抑集 C\_g = {i ∈ G\_sel：m⁰\_i = 1，m^g\_i = 0}，去抑集 O\_g = {i ∈ G\_sel：m⁰\_i = 0，m^g\_i = 1}，改变门集 S\_g = C\_g ∪ O\_g。  
第 1 步（控制神经元）：每个 g ∈ 𝒢 设场内神经元 K\_g：u\_K := q\_g·ctx\_g + d\_g，z\_K := \[u\_K ≥ 1\]。上下文 ctx\_g := \[g = 该值\]，由输入端口事件读目标写入；d\_g 为教学驱动（输入）。  
第 2 步（紧张性抑制元）：对 i ∈ G\_sel 设 T\_i：u\_T := tonic\_i·(1 − Σ\_{g：i∈O\_g} z\_K,g) + Σ\_{g：i∈C\_g} z\_K,g，z\_T := \[u\_T ≥ 1\]，tonic\_i = 1 − m⁰\_i。  
第 3 步（门控与传输）：门控端口事件（施作 I）m\_i := 1 − z\_T,i；膜驱动 u\_pre := u/2 + Σ m\_i·w\_i·zpre\_i（传输实际读取 m）；放电 z := \[u\_pre ≥ 1\]，放电后 u := 0（z = 1）或 u := u\_pre（z = 0）。  
第 4 步（控制耦合的场内形成）：赫布沉积 q\_g := min(1, q\_g + ½·ctx\_g·\[u\_K,g ≥ 1\])，入口 q\_g = 0。  
入口：u = z = 0；q\_g = ctx\_g = d\_g = u\_K,g = z\_K,g = 0；u\_T,i = z\_T,i = tonic\_i；m = m⁰。  
变量与层：θ = {w\_i, q\_g}；m = {m\_i}；运行层 u、z、zpre\_i、ctx\_g、d\_g、u\_K、z\_K、u\_T、z\_T；目标 g 为界外。场规则分项：控制、赫布沉积、紧张性、膜驱动、放电、目标设定（界外）；端口：门控 {m\_i：i ∈ G\_sel}，输入 {zpre\_i、ctx\_g、d\_g}；机制路线申报穷尽。

### 2.3　运行协议与相位

对每个 g ∈ 𝒢 依次：教学窗 T\_g（目标设定事件置 g；两拍 d\_g = 1、输入全 0）、置 g = 0 一拍；其后对每个 g：调谐窗 W\_g（目标设定事件置 g；两拍输入全 1）、复位窗 R\_g（g = 0，一拍）。  
每拍内事件依次为输入、上下文、各 g（按标签升序）的控制与赫布、各 i ∈ G\_sel 的紧张性抑制元、各门控、膜驱动、放电，相位 (k, 1), …, (k, ℓ)，ℓ = 4 + 2\|𝒢\| + 2\|G\_sel\|，末事件为放电；目标设定事件相位为 (k, 0)。窗界：T\_g = \[(k, 0), (k+1, ℓ)\]，W\_g = \[(k, 1), (k+1, ℓ)\]，R\_g = \[(k, 1), (k, ℓ)\]，k 为该窗首拍；窗尾即窗内最后一拍的放电事件。下一拍的目标设定事件 (k′, 0) 晚于窗内各拍，恒在窗外；教学窗内第 j 个目标（从 0 计）第二拍的赫布事件相位为 (k+1, 4 + 2j) ≤ (k+1, ℓ)，恒在窗内。

## 第三节　逐项验证（主实例）

主实例：n = 3，w = (1, 1/2, 1)，a = (1, 1, 1)，G\_sel = {0, 1, 2}，m⁰ = (1, 1, 0)，Φ⁰ = 3/2；Φ\*\_1 = 1/2 → m¹ = (0, 1, 0)，C\_1 = {0}（抑）；Φ\*\_2 = 5/2 → m² = (1, 1, 1)，O\_2 = {2}（去抑）。

C1　规则级 P10 = 1（申报路线穷尽；教学协议 T1 重放）：迹应版本 q1\|1（第 1 拍赫布沉积，来源含输入事件），读入事件为第 2 拍控制神经元（实际改变 u\_K），后继版本 q1\|2；路径 q1\|1 —写值→ u\_K1\|2 —写值→ q1\|2。机制未申报时 ⊥。实际窗为同一运行的教学窗 T1：教学窗共两次实际赫布写入，第二次在第二拍，路径同上。

C2　(a) 门控端口可写 {m0, m1, m2}，支撑 m\_i → w\_i；调谐窗内各拍传输对 m0、m1、m2 的依赖都为 1。W1 内只有门 0 改变（m0：1 → 0），W2 内只有门 2 改变（m2：0 → 1）。(b) 抑在 W1、去抑在 W2，两向各在独立窗中有实例。两窗的实施途径（窗内有实际改变的施作事件种类）都是门控。复位窗中目标回到 0，门回到紧张性状态（m0 复开、m2 复关）：门态由控制活动维持，不留存。

C3　证据档  
(i) 场内控制规则档：q\_g 预置为 1、无教学窗时，W1、W2 的 Gate\_W、Bear\_G,W、GoalCond 为 1，ΔΦ\_W = −1、+1。预置映射只到此档。  
(ii) 律候选档：形成——q1 由 0 经 1/2 到 1（教学窗 T1 两次赫布沉积），q2 同（T2）；起点不具该耦合，首版本来源含输入事件。留存——教学窗末至运行末 q 无实际改变。依赖——W1 门控所写 m0 版本的来源含 q1 的两版本、目标版本与上下文版本；W2 同。检验干预——调谐前把 q 复位为 0，W1、W2 无门态改变。律候选 L\_g：「在目标上下文 g 下发动控制」，承载组织 R\_g = {q\_g}。场内形成的只有上下文到控制神经元的耦合 q\_g；控制神经元到紧张性抑制元的接线（C\_g、O\_g）由构造程序给出。  
(iii) 正式律档：未取得。《律数理式》判据在本场的正式求值、向非运行基底场的桥接与同一承载的正式证书未作；《律必然式》充分向的 SC\_Hold 未闭合。  
(iv) 意向路线：开放。

C4　控制链（版本路径）：W1 中，目标版本 → 上下文 ctx1 → 控制神经元 z\_K1 → 紧张性抑制元 z\_T0 → 门 m0，同拍传输读入 m0（依赖 1）；W2 中同链经 ctx2、z\_K2、z\_T2 到 m2。干预：输入、目标与教学不变，阻断控制神经元对紧张性抑制元的输出——控制神经元在 W1、W2 照常放电，门态不变，Gate\_W = 0，ΔΦ\_W = 0。控制来源由链与干预证；作用方式分类（门控）另读。

C5　必要结构（W 入口为目标设定事件相位）：  
\| 项 \| W1（抑） \| W2（去抑） \|  
\| Org₀（入口） \| 1 \| 1 \|  
\| GoalRep／Target \| 指向 N \| 指向 N \|  
\| ΔΦ\_W \| −1（3/2 → 1/2） \| +1（3/2 → 5/2） \|  
\| Eff\_W(I)、Gate\_W(I) \| 1、1 \| 1、1 \|  
\| Bear\_W(I)、Bear\_G,W(I) \| 1、1 \| 1、1 \|  
\| GoalCond（Π = {门控} × {m}） \| 1 \| 1 \|  
\| W 内 θ 实际改变 \| 无 \| 无 \|  
W 末 Φ = Φ\*\_g。

C7　w\_i 无沉积分项；q\_g 在调谐窗中的赫布执行而同值（已饱和于 1）。调谐窗内无 θ 实际改变。

### 3.1　与共存模型的关系

特例 n = 1、w = 3/2、a = 1、m⁰ = 1、关门：Φ 由 3/2 到 0，C5 各项为 1，W 内无 θ 改变——复现共存模型的门控结论。差别：共存模型由中间神经元放电直接写 m（m := 1 − z\_I），本构造经控制神经元与紧张性抑制元两级，使抑与去抑由同一程序给出；共存模型在 w 上有 STDP（LTD 取 m·zpre），本族 w 无沉积分项；共存模型的控制映射为预置，本构造的上下文耦合 q\_g 由场内形成。冲突候选点重核：K1——抑制落在门控端口，传输实际读取 m；K2——控制神经元与紧张性抑制元是场的运行，施作落点是门控事件；K3——目标经输入、控制神经元、紧张性抑制元的写值链进入 m；K4——本族 w 无沉积分项，q\_g 在 W 内同值，H14-2 不需；K5——Bear\_G 经支撑 w\_i ≠ 0 与 a\_i ≠ 0；K6——教学窗与调谐窗属同一运行、同一场。

## 第四节　一般性

### 4.1　候选域与成功域

候选域：G\_sel ≠ ∅；S\_g ≠ ∅（选中门有非零实际变化）；∀i ∈ S\_g：w\_i ≠ 0（可作用支撑），a\_i ≠ 0（读数对该门的依赖为 1，即 a\_i·w\_i ≠ 0）。  
成功域：候选域中同窗联合门变换的净差 ΔΦ = Σ\_{i∈S\_g} a\_i·w\_i·(m^g\_i − m⁰\_i) ≠ 0，且目标可满足（Φ(m^g) = Φ\*\_g）。

定理 1（成功域内的构造）　对 𝒩 中成功域内任一实例与每个 g ∈ 𝒢，第二节的构造程序可执行，且：  
(i) C1：规则级 P10 与实际教学窗 T\_g 成立；  
(ii) C2(a)：在 W\_g 中 S\_g 的门按 m^g 改变，其余门不变，传输对每个改变门的依赖为 1；  
(iii) C3(ii) 的形成、留存与复位对照：q\_g 由 0 经 1/2 到 1（来源含输入），其后不变；调谐前把 q\_g 复位为 0 则 W\_g 中门不变；  
(iv) C4：W\_g 的门控所写 m\_i 的来源经 z\_T、z\_K、ctx 到目标设定事件；保持输入与目标、阻断控制神经元对紧张性抑制元的输出，则 u\_T,i = tonic\_i，门不变；  
(v) C5：Org₀、GoalRep／Target、Eff\_W、Gate\_W、Bear\_W、Bear\_G,W、GoalCond（Π = {门控} × {m}）为 1，ΔΦ\_W ≠ 0，Φ 末 = Φ\*\_g；  
(vi) C7：W\_g 内无 θ 实际改变。  
证明：教学：入口 q\_g = 0；第一拍 u\_K = d\_g = 1，赫布读 ctx\_g = 1 与 u\_K ≥ 1，q\_g := 1/2（来源含输入事件）；第二拍 u\_K = 1/2 + 1 读入 q\_g\|1 而实际改变，q\_g := 1。这与 w、a、G\_sel、m⁰ 无关，故迹应版本 q\_g\|1、读入事件 K\_g（第二拍）、后继版本 q\_g\|2 对每个实例、每个 g 齐备，二者都在 T\_g 内（2.3）。留存：赫布 q := min(1, q + …) 不减，饱和后同值。复位对照：q\_g = 0 时 W\_g 中 u\_K,g = 0，z\_K,g = 0，各 u\_T,i = tonic\_i，门不变。调谐：W\_g 中 ctx\_g = 1、d\_g = 0，u\_K,g = 1，z\_K,g = 1；其余 g′ 的 ctx 与 d 为 0，z\_K,g′ = 0。i ∈ C\_g：tonic\_i = 0，u\_T = 1，m\_i = 0；i ∈ O\_g：tonic\_i = 1，u\_T = 0，m\_i = 1；其余 i ∈ G\_sel：u\_T = tonic\_i，m\_i = m⁰\_i。故 ΔΦ\_W = Φ(m^g) − Φ(m⁰) ≠ 0，Φ 末 = Φ\*\_g。传输：i ∈ S\_g 时 w\_i ≠ 0，W\_g 中 zpre\_i = 1，膜驱动对 m\_i 的依赖为 1。干预：阻断 K→T 时 u\_T,i 不读 z\_K，等于 tonic\_i，m\_i = m⁰\_i。Org₀：入口接入的 θ 非空。GoalRep／Target：模型的目标声明与目标指向登记一致，指向 N。Bear\_W：由 Bear\_G,W。Bear\_G：对 i ∈ S\_g，Φ 对 m\_i 的依赖在有限值域 {0, 1} 上完备检验为 1，m\_i 的来源含该门控事件。GoalCond：m\_i 的来源经 z\_T、z\_K、ctx 到目标设定事件，逐步依赖为 1。θ：w\_i 无沉积分项，q\_g 已饱和。∎  
C3 中按同一规则推及全族的是形成、留存、依赖与复位对照；律候选 L\_g 的档位上限与预置对照（C3(i)）以主实例为证。  
有理网格（n = 2，w\_i ∈ {0, 1/2, 1}，a\_i ∈ {−1, 0, 1}，G\_sel ⊆ {0, 1}，m⁰ 与 m¹ 全枚举，共 2916 例，每例为构造程序的完整运行）上逐例成立：成功域 624 例的形式值 (Eff\_W, Gate\_W, Bear\_G,W, ΔΦ\_W ≠ 0, GoalCond\_W, 目标达成) 全为 1；全部实例的规则级 P10 与实际教学窗为 1；窗界全部合格。另以 n = 31（稀疏 G\_sel = {3, 17, 30}，三目标，含同窗抑去抑）、n = 12（G\_sel 全选，读出系数混号，四目标）与 \|𝒢\| = 8 的实例逐窗、逐目标成立。

### 4.2　失败支

\| 类 \| 形式值 (Eff\_W, Gate\_W, Bear\_G,W, ΔΦ\_W ≠ 0, GoalCond\_W) \| 失败的必要项 \|  
\| 空门控子集（G\_sel = ∅） \| (0, 0, 0, 0, 0) \| Eff、Gate、Bear\_G、ΔΦ、GoalCond \|  
\| 门态无实际变化（S\_g = ∅） \| (0, 0, 0, 0, 0) \| 同上 \|  
\| 零权连接（S\_g 含 w\_i = 0） \| 缺陷门全为零权时 (1, 1, 0, 0, 1) \| 该门的单门 Bear\_G 为 0，对 ΔΦ 贡献为零 \|  
\| 读数不依赖（S\_g 含 a\_i = 0） \| 缺陷门全为不依赖时 (1, 1, 0, 0, 1) \| 同上 \|  
\| 联合净差取消（候选域内） \| (1, 1, 1, 0, 1) \| ΔΦ \|  
零权与不依赖的缺陷定位在门一级：缺陷门自身实际改变（Eff、Gate 由它满足），其单门 Bear\_G 为 0；同一窗另有有效门时，整例的 Bear\_G 与 ΔΦ 可由有效门满足。  
净差取消：异向——w = (1, 1)，a = (1, 1)，m：(1, 0) → (0, 1)，两门都实际改变、各自读数依赖为 1，Bear\_G = 1，而 ΔΦ\_W = 0；同向——w = (1, 1)，a = (1, −1)，两门同关，ΔΦ\_W = 0。单门依赖与单门承担不能代替同窗净差。  
目标不可满足：w = (1, 1/2)，a = (1, 1)，m⁰ = (1, 1)，Φ\* = 2；可达读数 {0, 1/2, 1, 3/2}，第 0 步无解，构造停止。对照：按 Φ = 1 的门态执行，Eff、Gate、Bear\_G、GoalCond 为 1，ΔΦ\_W = −1/2，读数不达 2——目标不可满足与必要项的成败相互独立。直接给 m^g 而未选门的目标态异于入口态时，第 0 步报目标不可满足。

## 第五节　构造定理

定理（脉冲网络调谐回路的显式构造）　第二节的构造程序在 𝒩 的成功域内给出满足 C1、C2(a)、C4、C5、C6、C7 的调谐回路，C3 到律候选档；C2(b) 的两向存在由主实例的 W1（抑）与 W2（去抑）给出。成功域内的单个实例不必两向兼有：例如 n = 1、w = a = 1、G\_sel = {0}、m⁰ = (1)、唯一目标直接给 m^g = (0)，调谐窗中只有抑，门的重新打开只在复位窗中发生。

## 第六节　q\_g 候选结构的来源

### 6.1　对象与来源协议

对象：χ\_g = (L\_g, I\_g, Rel(L\_g), Γ\_cand)，L\_g 为「在目标上下文 g 下发动控制」，承载组织 R\_g = {q\_g}。强度为律候选档（C3(ii)）；本节结论是候选结构的来源，不是正式 Law 首次成律的来源。  
候选判定 Γ\_cand，在每一评价点 t 求值：  
　(a) 场内形成——q\_g ≠ 0，且 q\_g 当前版本的来源含输入端口事件；  
　(b) 作用——自 t 的冻结快照（宿载层 w、q 保留，门与运行层回到入口值）起，目标设定 g，两拍输入全 1，C\_g ∪ O\_g 中有门态改变；  
　(c) 依赖——同一检验运行而 q\_g := 0，无门态改变。  
　Judge\_t = (a) ∧ (b) ∧ (c)，在每一评价点二值有定义。  
Γ\_cand 与 C3(ii) 的对应：形成对应 (a)；留存为首次之后各评价点 Judge 逐点为 1；依赖对应 (b)(c)——C3(ii) 在原运行上以「调谐前把 q 复位为 0」检验，(b)(c) 是同一干预在冻结快照上的作法。检验运行取冻结快照，是因为门态由控制活动维持、不留存（C2）：在调谐窗或复位窗中途读门，读到的是当下的控制活动，不是承载组织。限度：检验运行只核 C\_g ∪ O\_g 的门有改变，门态等于目标门态与传输读数由 C2、C5 在原运行上另证；冻结快照是诊断协议，不是原运行的续行。  
来源协议 Π\_src：  
　X\_0：2.2 的入口（q = 0，门 m⁰）。  
　Dyn^Π：第二节的场规则——控制、赫布沉积、紧张性、门控、膜驱动、放电（含放电后复位）。目标设定事件属外部历史，不属 Dyn^Π。  
　H\_obs：第三节主实例的同一运行——T1、复位拍、T2、复位拍、W1、R1、W2、R2，共 12 拍（教学窗及其后的两复位拍前突触输入全 0；调谐窗与 R1、R2 前突触输入全 1）；按同一历史驱动重放，与 2.3 运行协议所生成的运行逐事件核对，176 个事件的编号、种类、实际改变与写值全同。  
　历史项（可删）：每拍的目标设定事件 G\_k（若有）、上下文输入分量 ctx\_k、教学驱动 d\_k、非零前突触输入 zp\_k。  
　削减语义（削减单位均为整拍）：删 G\_k，该拍不发生目标设定事件——目标是持续的寄存量，沿前值；删 ctx\_k，该拍上下文组全体（各 g 的上下文分量）取 0，只此一拍，其余拍不变；删 d\_k，该拍教学驱动向量（各 g 的分量）取 0；删 zp\_k，该拍前突触输入向量取全 0。  
　背景干预（不属历史削减，单列）：全程阻断控制神经元对紧张性抑制元的输出；协议所取的组合是历史与 (b)(c) 的检验运行同施阻断。  
　评价点集 T\_Π：入口与每拍末，共 13 点；粒度 Gran^Π：上述历史项。  
以上各项事前冻结；事后不改粒度、可删项、判定与评价点集。

### 6.2　默认来源的排除

(i) 构造给出：q\_g 入口预置为 1 而删去全部历史项，(a) 在各点都不成立，Judge 全 0——作用与依赖在，却不是场内形成，只到 C3(i) 的控制规则档。  
(ii) 接线：背景干预（历史与检验运行同施阻断）下两目标 Judge 全 0，而 q\_g 的形成写入与原运行逐项相同（q\_g 末值 1）。若只阻断历史而检验运行不阻断，形成的 q\_g 仍足以在检验运行中触发门控，Judge 与原史同时取得（g = 1 于 T1 第二拍末，g = 2 于 T2 第二拍末）——两种组合判词不同，正说明接线在作用侧必要而不进入形成。反事实必要不等于来源承担（《律源式》第四条边界），不计来源。  
(iii) 形成期的门控活动：教学窗中门也实际改变，但不在 q\_g 末版本的来源链上；q\_g 的来源链只含目标设定、输入、控制神经元运行与赫布沉积事件，不含门控事件与 m 层变量。  
(iv) 另一目标的教学：见 6.4，不承重。

### 6.3　发生过程

同一教学窗中，目标设定使上下文 ctx\_g = 1，两拍上下文与教学驱动 d\_g 配对。第一拍 u\_K = d\_g = 1，赫布读 ctx\_g = 1 与 u\_K ≥ 1，q\_g := 1/2；第二拍 u\_K = q\_g\|1·ctx\_g + d\_g = 3/2，读入 q\_g\|1，q\_g := 1。q\_g = 1/2 时 u\_K = 1/2 \< 1，(b) 不成立；两次沉积都承重。

### 6.4　来源定理（候选档）

H\_obs 上的 Judge：g = 1，入口与 T1 第一拍末为 0，T1 第二拍末首次为 1，从首次点至末点均为 1；g = 2，入口至 T2 第一拍末为 0，T2 第二拍末首次为 1，从首次点至末点均为 1。原运行中，W1 门控所写 m0 版本的来源含 q1 的两版本，W2 门控所写 m2 版本的来源含 q2 的两版本。  
定理（q\_g 候选结构的来源）　在 Π\_src 下：  
　(一) χ\_g 首次取得候选资格于 T\_g 第二拍末，其后留存至末点；  
　(二) 固定首次评价点 τ，在 τ 前历史项的全部削减中（g = 1 为 5 项、32 个保留集；g = 2 为 12 项、4096 个保留集），使 τ 处 Judge = 1 且此前全为 0 的充分保留集，g = 1 只有全集一个，g = 2 有 128 个；极小充分保留集各唯一，为 T\_g 窗内的目标设定、两拍上下文与两拍教学驱动；  
　(三) 其外各项不承重：g = 2 单删 T1 段各项或复位拍的目标设定，首次仍在 T2 第二拍末；  
　(四) 空历史控制：删去全部申报历史项（目标设定、上下文、教学驱动、前突触输入），Dyn^Π 照常，两候选在原首次点为 0，且在 13 个评价点上全为 0，q 末值 0；依空历史的定义，SourceDomainIncomplete^Π = 0。该值依本协议的候选档、初态、固定背景与粒度求得，不表示一切可替代或遗漏的历史因素都已枚举。  
证明：(一) 由 6.3 与逐点求值；(二)(三) 由对 τ 前历史项全部子集的逐一求值；(四) 由同一求值。背景干预单列于 6.2(ii)，不计来源。∎

### 6.5　不能唯一确定处

唯一性只对申报的 H\_obs、历史项粒度与 Γ\_cand 成立；更细粒度（拍内事件、控制神经元运行）的来源分配未判。别的历史可得同一候选：两教学拍之间插一拍目标 0，并在第二次教学拍前重新设定目标 g，则两次配对沉积照常（g = 1：q1 写入 1/2、1，第 3 拍末首次取得；g = 2 同型，第 6 拍末首次取得）；若只插目标 0 而不恢复，第二次教学拍上下文为 0，q 停在 1/2，不取得。教学三拍时第三拍写入同值、不承重，首次仍在第二拍末。这些属于另外的历史，不作同一历史的多解；6.4 的唯一性只属于原冻结历史。正式律档未取得；正式 Law 的首次成律来源，待资格取得后按《律源式》另求。
