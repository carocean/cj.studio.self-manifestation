自显论·工篇·势引组式第二十一 v1.0

# 训练替代区分式

## 第一节　候选对申报

### 1.1　问题

《势引律工构造式》给出的律工 G 经直写端口改写被引场 F，使其读数达到目标并在续行中维护；同一目标也可由追加训练达到——在 F 上设场自身的训练规则，由教学输入驱动。在同一宿主、同一达标判据与同一允许后续历史下，是否存在可执行的观测，把「律工替代训练」与「追加训练」分开？

### 1.2　共同宿主

F⁺：《势引律工构造式》的 F（p = 2；宿载层 w0、w1；运行层 x0、x1、u、y；界外目标 g = 2）加训练分项与教学输入端口。训练分项（沉积，写 w1）：w1 += η·e·(g′ − y)，η = 1/2，y 读同窗内刚执行的读出；教学输入 g′、e 经输入端口进入。机制路线申报穷尽：膜驱动、宿主沉积、训练、读出、目标设定、输入端口、直写端口。入口取《势引律工构造式》2.3 的完整入口表，另 g′ = e = 0。

### 1.3　候选

H\_L（律工替代）：F⁺ 与律工 G 联合执行。窗内依次为：F 读出（相位 1）→ G 读入 y、g（3、4）→ 计划（5）→ G 经直写端口写 w1（6）→ F 读出（7）→（cmd ≠ 0 且读数差观测到达时）G 读入读数差、记副本、两项沉积（8—11）→ 教学输入 (g′, e) := (g, 0)（12）→ 训练分项（13）→ 教学输入 e := 0（14）。H\_L 中 e ≡ 0，训练分项执行而写入增量为零，不改 w1。  
H\_T（追加训练）：F⁺ 单独执行。调控窗位置同 H\_L，窗内：F 读出 → 教学输入 g′ := g、e := e\_on → 训练分项 → F 读出 → 教学输入 e := 0。e\_on 在教学期为 1，在撤教期为 0。  
两臂窗位依次为第 20、30、40……拍；窗间续行同取 K0（窗间无输入）、Kp（窗间两拍输入 (1, 0)）或 Km（窗间两拍输入 (1, 1)）。

### 1.4　共同达标判据

判定截面 σ（入口状态或窗末状态，同《维护律工可达式》1.4）。Ach\_K(σ)：Φ(σ) = g，且自 σ 按续行 K 与该臂的窗协议继续执行，此后每窗该臂的有效修正量——w1 的实际改变量，来自 G 的直写或训练分项——为零。  
H\_L 的有效修正量即 G 的直写量，Ach\_K 读回为《维护律工可达式》的平衡集 B\_K。H\_T 在教学期的有效修正量为 η·(g − y)，Φ = g 时为零。撤教后停止写入不单独构成达标：Ach\_K 在教学期的窗协议下判定。律候选的资格另列——只 H\_L 在 G 中有律候选（《势引律工构造式》C4），不进入 Ach\_K；正式成律不签。

### 1.5　允许的后续历史

自两臂各自首次属 Ach\_K 的截面起进入撤教期：H\_T 的 e\_on = 0；H\_L 的 G 保留其许可操作。律工的校正权即其施作权，是 H\_L 作为被比较对象的结构，不是两臂历史的差别。检验干预：撤教后第一个调控窗的 F 读出之前（该窗相位 (k, 0)），直写 w1 += δ，δ ∈ Δ\_δ = {±1/8, ±1/4, ±1/2}；此后按 K0 或 Kp 续行，无教学。首证域：K ∈ {K0, Kp}，δ ∈ Δ\_δ，且 H\_L 第 1 窗的读数差观测到达（首次有效观测；G 由此形成 C = p）。读数差观测不到达的 H\_L 臂——第 1、2 窗末读数为 5/2、3/2，C 保持 1，不按所申报时序进入达标与撤教比较——列在首证域之外，判未判。

## 第二节　前向映射

### 2.1　达标

H\_T：第 1 窗 y = 3/2，w1 += (1/2)·(1/2) = 1/4，Φ = 1/2 + 2·(3/4) = 2；其后各窗 y = 2，修正量为零。第 1 窗末首次属 Ach\_K（K0、Kp）。  
H\_L：第 1 窗 cmd = (2 − 3/2)/1 = 1/2，Φ = 5/2；读数差观测到达，G 形成 C = 2；第 2 窗 cmd = (2 − 5/2)/2 = −1/4，Φ = 2；其后修正量为零。第 2 窗末首次属 Ach\_K，即 B\_K（《维护律工可达式》定理 2 的情形）。  
两臂在 K0、Kp 下各执行六窗，逐窗如上；H\_L 的全部事件中训练分项无实际改变。

### 2.2　扰动窗

扰动窗入口 Φ\_入 = g + p·δ。  
H\_L：C = p = 2，cmd = (g − Φ\_入)/C = −δ，窗末 Φ = g；读数差观测到达，沉积给 c := obs/dlt = p，C 不变。  
H\_T：e = 0，训练分项的写入增量为零；K0 无窗间事件，Kp 下 x1 = 0，宿主沉积条件不满足；窗末 Φ = g + p·δ。  
证明：H\_L 由《维护律工可达式》2.2——窗内只有施作改变 Φ，读出在 w1 方向线性；H\_T 由训练分项的式与 e = 0。∎

### 2.3　续行 Km

记 x 为窗末 w1（w0 = 1/2）。宿主单拍 h(x) = x + (1/8)·\[x ≥ 1/2\]（膜驱动 1/2 + x ≥ 1 ⟺ x ≥ 1/2）；相邻两窗之间执行 h∘h；扰动窗的入口为 h(h(x)) + δ。H\_T 教学期 x := x + η·(g − (1/2 + 2x))，撤教期窗内不写；H\_L 窗内 x := x + (g − Φ\_入)/C，触发时 C := obs/cmd = p。两臂自同一入口，H\_T 教学一窗后撤教，扰动施于第 2 窗前；H\_L 执行两窗后扰动施于第 3 窗前。  
逐窗：H\_L 各窗末 Φ = 5/2、2、2、2、2、2（W2 末读数为 2，但在 Km 下此后每窗命令非零，不属 Ach\_Km）；H\_T 扰动窗入口 w1 = h(h(3/4)) + δ = 1 + δ，窗末 Φ = 5/2 + 2δ，其后 w1 ≥ 1/2 时每窗增 1/2。在 Km 下两臂都不属 Ach\_Km。

## 第三节　区分观测构造

区分观测 𝒪\_a：扰动后首个调控窗末的读数 Φ。  
判读：Φ = g 判 H\_L；Φ ≠ g 判 H\_T。  
可执行性：𝒪\_a 只读 F 的读出，在扰动后的第一个完整调控窗末取值；扰动由检验干预在申报相位施加。  
未判：δ = 0（两臂窗末都为 g）；扰动后未完成调控窗；两臂不自所冻结的达标截面开始。

## 第四节　区分有效性

命题 1（首证域）　K ∈ {K0, Kp}，δ ∈ Δ\_δ 时，H\_L 的 𝒪\_a = g，H\_T 的 𝒪\_a = g + p·δ ≠ g。  
证明：2.2 与 pδ ≠ 0。∎  
逐例：两臂在 K0、Kp 下对六个 δ 各执行；H\_L 窗末都为 2；H\_T 窗末为 9/4、7/4、5/2、3/2、3、1（δ = 1/8、−1/8、1/4、−1/4、1/2、−1/2）；判读全部正确。δ = 0 时两臂窗末都为 2。

命题 2（续行 Km 的个例）　在 2.3 的入口与相位下，𝒪\_a 的两臂值为 2 与 5/2 + 2δ；二者相等当且仅当 δ = −1/4。故 Km 上 δ ∈ {±1/8, 1/4, ±1/2} 时两臂分开，δ = −1/4 时宿主沉积的 +1/4 与扰动相抵，两臂同为 2。  
证明：2.3 的递推。∎  
δ = −1/2 时 H\_T 扰动后 w1 = 1/2，恰在宿主沉积阈值上，窗末 3/2，其后每窗续升。Km 上的分离是逐 δ 的个例，不构成区分定理。

## 第五节　区分定理

区分定理　在共同宿主 F⁺、入口（《势引律工构造式》2.3）、H\_L 第 1 窗读数差观测到达、共同达标判据 Ach\_K（K ∈ {K0, Kp}）、撤教期与一次扰动 δ ∈ Δ\_δ 的允许后续历史下，观测 𝒪\_a 把律工替代 H\_L 与追加训练 H\_T 分开：H\_L 的扰动后首窗末读数为 g，H\_T 为 g + p·δ。  
证明：命题 1。∎

### 5.1　成本口径（单列，不承担区分）

自入口至首次属 Ach\_K0：H\_T——窗数 1，w1 实际写入事件 1，F⁺ 的教学端口事件 2；H\_L——窗数 2，w1 实际写入事件 2，G 的输入端口事件 6，另有 F⁺ 的教学端口事件 4（每窗 2，e 恒为 0）。两类端口事件分列；只报两臂各自取值，不作优劣结论。

### 5.2　机制记录（不承担区分）

δ = 1/4、K0 下 w1 的实际写入：H\_T 为训练分项一次、检验扰动一次；H\_L 为 G 的直写三次、检验扰动一次。H\_T 的规则级 P10 = 1，见证协议为教学一窗后接两拍输入 (1, 1)（训练分项写出的 w1 版本 → 膜驱动 → 宿主沉积写出的后继版本）；这是不同于首证续行的辅助协议。载体干预（复位 C）在 H\_L 中改变施作（《势引律工构造式》C6），H\_T 无对应载体。这些记录只说明两臂的写入途径，不以候选名称或事件标签判分。

## 第六节　强度申报

\- 只签所申报候选对、首证域与观测 𝒪\_a；续行 Km 只签递推与逐 δ 个例。  
\- 不签律工优于训练；成本只报数。  
\- 律工的律资格保持律候选档，正式成律未取得；不签生物学习。  
H21-1　共同宿主 F⁺ 与律工 G 的机制路线申报穷尽属实。  
H21-2　训练分项的读入相位、η 与教学使能的开关时点如 1.2、1.3 所申报。
