自显论·工篇·势引组式第二十二 v1.0

# 权重空间编程区分式

## 第一节　候选对申报

### 1.1　问题

改写被引场权重的，可以是一个按规则计算写入量的计算过程，也可以是律工——一个以自身沉积留存被引场读数斜率的具化场。二者可以给出相同的末态，甚至相同的逐窗写入。依可查的机制与历史，而不只看末态，能否把它们分开？在哪一层观测上分开？

### 1.2　共同协议

宿主 F\_p：《势引律工构造式》的被引场，读出 y := w0 + p·w1，入口 w = (1/2, 1/2)；目标 g。窗内次序：F 读出 → 写入者读入 y、g → 计划 → 经直写端口写 w1 → F 读出 →（触发：本窗命令 cmd ≠ 0 且读数差观测到达）写入者读入读数差并更新。窗间续行 K0（无输入）。观察至第 2 个调控窗末。

### 1.3　候选

H\_P⁰（固定参数规则）：计算过程 R⁰，写入量 (g − y)/p̂，p̂ = 2 固定；不读入观测；部署到其他宿主时携带 p̂ = 2。  
H\_P¹（随观测更新的规则）：计算过程 R¹，p̂ 初值 1；触发时 p̂ := obs/cmd；写入量 (g − y)/p̂；部署到其他宿主时以初值新启。  
H\_L（律工）：《势引律工构造式》的 G，宿载层 c、C 入口为 1，触发时沉积 c := c + (obs − c·dlt)/dlt、C := c；写入量 (g − y)/C；部署到其他宿主时以入口值新启。  
机制申报：R 的申报边界为一个计算过程，其变量都在运行层——p̂ 为运行层寄存器，由计算分项写入；分项为计划、副本、更新与界外分项，机制路线穷尽申报。G 的 c、C 在宿载层，由沉积写入。

### 1.4　观测族

嵌套：𝒪\_end ⊂ 𝒪\_beh ⊂ 𝒪\_mech。  
𝒪\_end：第 2 窗末的 (w0, w1, Φ)。  
𝒪\_beh：逐窗 F 的读数与对 F 的写入投影（拍、相位、位置、数值）；不含写入者的内部状态与来源标签。  
𝒪\_mech：另加写入者的机制申报、规则级 P10（《势引数理式》定义 3.10）、实际版本路径与来源记录。  
首证域：p = 3，g = 3（入口误差 −1），无漂移，首个有效观测到达，观察两窗。

## 第二节　区分观测构造

### 2.1　前向映射（首证域）

H\_P⁰：第 1 窗 y = 2，写 1/2，Φ = 7/2；第 2 窗写 −1/4，Φ = 11/4。误差逐窗乘 1 − 3/2 = −1/2：−1 → 1/2 → −1/4。  
H\_P¹：第 1 窗写 1（p̂ = 1），Φ = 5；触发，p̂ := 3；第 2 窗写 −2/3，Φ = 3。  
H\_L：第 1 窗写 1（C = 1），Φ = 5；触发，c := obs/dlt = 3，C = 3；第 2 窗写 −2/3，Φ = 3。  
第 2 窗末 (w0, w1, Φ)：H\_P⁰ 为 (1/2, 3/4, 11/4)；H\_P¹、H\_L 为 (1/2, 5/6, 3)。

### 2.2　各对的区分观测

H\_P⁰ 对 H\_L、H\_P⁰ 对 H\_P¹：𝒪\_end 中第 2 窗末的读数 Φ（11/4 对 3）。  
H\_P¹ 对 H\_L：𝒪\_mech 中写入者的规则级 P10 与承载层级（第三节）。

## 第三节　区分有效性

命题 1（固定参数规则）　首证域中 H\_P⁰ 的第 2 窗末误差为 −1/4，H\_P¹ 与 H\_L 为 0。  
证明：2.1。∎

命题 2（逐窗耦合）　设宿主读出系数 p 为非零有理数，R¹ 的 p̂ 与 G 的 C 入口相同且非零，窗间无漂移，两臂的读数差观测同时到达，观察至共同的停止截面。则在共同协议下，每窗二者的命令、对 F 的写入与 F 的读数相同，且触发后 p̂ = C = p。  
证明：对窗数归纳。设窗入口 F 的状态相同且 p̂ = C。命令 (g − y)/p̂ = (g − y)/C 相同，写入与读数随之相同。cmd ≠ 0 且读数差观测到达时二者都触发：obs = p·cmd 相同；R¹ 给 p̂ := obs/cmd = p；G 给 c := c + (obs − c·cmd)/cmd = obs/cmd = p，C := p。cmd = 0 或观测不到达时二者都不更新。p̂、C 始终为非零有理数，计划中的除法有定义。∎  
停步界：若 p = 0，则在首次满足命令非零且两臂读数差观测到达的窗，两臂的更新给 p̂ := 0 与 c := 0，越出各自的非零类型，合法的共同前缀止于该更新之前；无触发则无此类停步（如 p = 0、g = 1/2 时入口已对齐，两臂命令为零，估计保持 1）。例：p = 0、g = 3 在第 1 窗触发。  
推论：在首证域中，H\_P¹ 与 H\_L 在 𝒪\_end、𝒪\_beh 上不可区分。命题 2 的非零推广域上，另以读出系数 −1、1/2、1、2、3、5/2，目标 0、2、3、−1，w1 入口 0、1/2、1 执行三窗（比首证域多观察一窗），七十二例的 𝒪\_beh 投影逐窗相同；其中入口已对齐的三例两者全程不写，列为未判。结论只对所冻结的 H\_P¹ 成立，不推及任意自适应程序。

命题 3（机制层的条件性分离）　在 1.3 的机制申报下：G 的规则级 P10 = 1——迹应版本 c（第一次沉积一）读入沉积二并实际改变 C，路径 c —写值→ C；R¹ 的规则级 P10 = 0——机制申报穷尽，且无机制路线写宿载层。R¹ 的机制未申报时 P10 为 ⊥。  
证明：按《势引数理式》定义 3.10 在同一窗协议上重放。G 的第 1 窗事件：  
\| 事件 \| 种类 \| 读入 \| 实际改变 \| 写后版本来源中的输入事件 \|  
\| 读入 y、读入 g \| 输入 \| y；g \| yG；gG \| 各自 \|  
\| 计划 \| 运行 \| gG、yG、C \| cmd \| 读入 y、读入 g \|  
\| 读入读数差 \| 输入 \| y、yG \| obs \| 读入 y、读入 g、读入读数差 \|  
\| 沉积一 \| 沉积 \| c、obs、dlt \| c（1 → 3） \| 读入 y、读入 g、读入读数差 \|  
\| 沉积二 \| 沉积 \| C、c \| C（1 → 3） \| 同上 \|  
迹应版本：沉积一写出的 c，来源含输入事件，由场自身沉积写入（宿载层）；组织参与：沉积二读入该版本并实际改变 C；历史动力：C 的新版本依赖 c 的版本，路径 c —写值→ C。三项齐备，P10 = 1。R¹ 的机制申报穷尽而无机制路线写宿载层，没有迹应版本，P10 = 0；机制未申报时为 ⊥。∎  
首证域的实际版本：G 中写入 C 的事件为沉积，来源含输入事件；R¹ 中写入 p̂ 的事件为计算分项，来源亦含输入事件。分离不落在来源上，而落在承载层级与 P10：G 的承载组织是宿载层迹应，R¹ 的是运行层寄存器。  
未判：日志欠缺；R 的 p̂ 若改申报为宿载层沉积，则二者的 P10 可能相同，机制分离须重审（P10 相同不确定完整申报与版本日志相同）；域外实现。⊥ 不作反证。

## 第四节　区分定理

区分定理　在首证域与共同协议下，各对候选在嵌套观测族中最早可区分的一档为：  
\| 候选对 \| 最早可区分档 \| 前档 \|  
\| H\_P⁰ 对 H\_L \| 𝒪\_end \| 无 \|  
\| H\_P⁰ 对 H\_P¹ \| 𝒪\_end \| 无 \|  
\| H\_P¹ 对 H\_L \| 𝒪\_mech（在 1.3 的机制申报下） \| 𝒪\_end、𝒪\_beh 不足 \|  
证明：命题 1、2、3。∎  
首证域之外：宿主 p = 2、g = 2 时，H\_P⁰（p̂ = p）与 H\_L 的第 2 窗末同为 (1/2, 3/4, 2)——在更宽的宿主域上，固定参数规则与律工的末态可以交叠；这不改变首证域的结论。

## 第五节　强度申报

\- 只签首证域、共同协议与所冻结的三档候选；H\_P¹ 与 H\_L 的行为同一只签冻结对手。  
\- 机制层的分离以 1.3 的机制申报与证据访问为条件，读回强度按《势引数理式》7.1、7.2；⊥ 不作反证。  
\- 不签律工优于编程；不签生物。  
H22-1　R 与 G 的机制路线申报穷尽属实。  
H22-2　F\_p 的读出在 w1 方向线性（申报模型给出）。

## 第六节　接口

输入：《势引律工构造式》v1.0（G、联合运行、触发条件）；《维护律工可达式》v1.0（学习支）；《势引数理式》v1.0（定义 3.10，7.1、7.2）；场具化组式第十八 D18-2、D18-3。

输出：三档候选的前向映射、逐窗耦合命题、机制层的条件性分离、分档区分定理。  
——向训练替代区分式：机制层记录的读法。  
——向不可区分式：𝒪\_beh 上 H\_P¹ 与 H\_L 不可区分，扩张至 𝒪\_mech 时在机制申报下可区分。
