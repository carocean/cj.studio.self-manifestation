自显论·工篇·势引组式第二十三 v1.0

# 一般化结构稳定式

## 第一节　稳定对象与原资格

### 1.1　问题

《一般化结构源式》立起了合取抑制迹应结构 Σ\_mem(τ)，并给出它的来源。已经成立的这一结构，在声明的变化中能否保持？失效后能否在合法动力下复归？复归的是同一条迹应，还是另一条迹应替代？各结论在哪一量词层级成立？

### 1.2　宿主与资格

宿主 𝔐\_I 与工作域 D\_mem（门恒开）、迹应资格与成员判法、关系模板 R1—R4、D 与对象 Σ\_mem(τ) = Σ(τ) ∧ mem(u)，都取自《一般化结构源式》第一节。记阈 θ = w\_A + w\_B − 1，间隙 d = u − θ；D 即 d \> 0。

### 1.3　初态与对象层级

首证域：τ = (1, 1, 0)，初态 σ₀ 取《一般化结构源式》S1 的终态——w = (1, 1)，a = (1/2, 1/2)，u = 3/2，κ = 1/2，u 的资格区间始于第 1 拍的抑制沉积，含留存成员；θ = 1，d = 1/2。  
第二域：τ = (1, 0, 0)，初态取《一般化结构源式》1.5 所列承担位全为成员之史的终态——w = (1, 1/2)，a = (1/2, 1/2)，u = 1，κ = 1/2；θ = 1/2，d = 1/2。(0, 1, 0) 为其改名像（《一般化结构源式》命题 1）。单正任务的结论分别给出，不由双正任务外推。  
记 u₀ 为初态的 u。原资格 Q = Σ\_mem(τ)；另报 Q ∧ 对齐（Σ\_mem 不含对齐）。  
对象层级：固定对象层——u 的当前资格区间的形成版本与 σ₀ 相同，且 Q 成立；存在层——Q 成立，允许新形成的区间承担。

## 第二节　许可变化域与资格重算

### 2.1　许可变化域

Δ1：A、B、AB 的任意有限序列，教学信号 t = 0。  
Δ2：同上，t ∈ {0, 1}。  
Δ3：一次施作者直写 u := c，c ∈ D\_c = {k/8：k = 0, 1, …, 24}，施于两拍之间（下一拍输入之前），其后不再直写，按 Δ1 续行。与当前值相同的写入不产生事件、不改版本。  
Δ4：一次施作者直写 κ := κ′，κ′ ∈ {0, 1/4, 1/2, 1}，其后按 Δ1 续行；复合 Δ43：先 Δ4 后 Δ3，各一次。  
门控变化不在许可变化域内。判定截面：每次直写之后与每拍之末。

### 2.2　资格重算

逐截面按《一般化结构源式》1.2、1.3 的规则重算：区间内的异值直写产生新的深度版本，留存计时自该版本重起；回到基线终止区间；不在区间内的直写不开区间。固定对象层以形成版本判同一。

## 第三节　即时保持层级与替代关系

### 3.1　三种边界

(i) 深浅边界：直写 u := c 后，D 失效 ⟺ c ≤ θ。D\_c 上失效集的最大元为 θ（双正 1，单正 1/2），在该点取得——D 为严格不等式；在连续值域上上确界同为 θ 且取得。  
(ii) 即时资格边界：c ≠ u₀ 的一切 c（含 c \> θ）是异值写入，使 mem(u) 在直写后的截面与其后第一拍末不成立，Q 即时失效；无后续写入时，第二拍末即恢复留存。c = u₀ 是同值写入，不产生事件，Q 直接保持（两域都如此：双正 c = 3/2，单正 c = 1）。  
(iii) 恢复后的边界：见第四节命题 2。

### 3.2　替代

c = 0 使 u 回到基线，终止原区间；其后由新形成的区间承担时，只是存在层的替代，不是原迹应的恢复——c = 0 后的复归都伴随形成版本的改变；存在层的复归只在合法地形成了新区间并满足留存时签。0 \< c 且 c ≠ u₀ 的直写只在同一区间内更替深度版本，是内部见证的更替，不是对象替代。

## 第四节　动态轨迹、观察窗与恢复

### 4.1　轨迹与可判域

合法后继动力为 𝔐\_I 的拍规则；观察协议为 2.1 的判定截面；所列有限序列全部可判。

### 4.2　保持

引理（零写入）　在门恒开、权非负且 a\_A + a\_B ≥ 1 的状态上（两域初态及其在 2.1 下的可达状态都满足：募集权只增不减），自 d \> 0 的截面执行 t = 0 的拍，不产生任何实际写入。  
证明：AB 拍上 z\_I = 1（a\_A + a\_B ≥ 1，募集权只增不减），膜驱动 w\_A + w\_B − u = 1 − d \< 1，不放电，无抑制沉积。单输入 X 若被募集，膜驱动 w\_X − u ≤ w\_A + w\_B − u \< 1（权非负），不放电；未被募集则无抑制沉积。t = 0 时兴奋与募集沉积为零。∎  
命题 1（Δ1 下的保证稳定）　自 σ₀（两域）按任意 t = 0 序列，每个截面上固定对象层的 Q ∧ 对齐成立。  
证明：σ₀ 的 d = 1/2 \> 0；由引理，宿载状态、区间与版本都不变，留存计时只增。∎  
长度不超过 8 的全部 t = 0 序列（每域 9840 条）逐截面成立。

### 4.3　深度扰动后的恢复

命题 2（按拍序的复归条件）　自 σ₀ 直写 u := c（c ≠ u₀）后按 t = 0 序列续行，κ 为当时的可塑系数。  
(a) c \> θ：D 保持，原区间延续；固定对象层的 Q ∧ 对齐在直写后第 2 拍末首次复归，与输入无关。  
(b) 0 \< c ≤ θ、κ \> 0：记 m\* 为使 c + m\*·κ \> θ 的最小正整数。固定对象层复归，当且仅当序列中第 m\* 个 AB 拍存在且其后至少再执行两拍；首个复归截面为该 AB 拍后的第二拍末。  
(c) c = 0、κ \> 0：原区间终止；以 c = 0 计 m\*，同 (b) 的条件下只在存在层复归（新区间），固定对象层不复归。  
(d) κ = 0 且 c ≤ θ：不复归——c \> 0 时深度无从补足，c = 0 时不能形成新区间。  
证明：AB 拍上 z(AB) = \[d ≤ 0\]，故 u ≤ θ 时每个 AB 拍使 u 增 κ，u \> θ 后不再改变；A、B 拍不改 u：本支为 t = 0，募集权保持入口值 1/2，单输入不被募集，无抑制沉积。使 u 越过 θ 的那一拍是最后一次实际写入，其后两拍满足留存；复归前每个截面或 D 不成立，或 mem 不成立。c = 0 时原区间已终止，其后首个改变 u 的抑制沉积开启新区间。∎  
两域、κ′ 不写或取 0、1/4、1，c 取 D\_c 中异于 u₀ 的值，长度不超过 7 的全部 t = 0 续行上，按拍序条件的判定与逐截面的实际复归逐例一致；κ′ = 0 时不复归的 c 恰为 0 与 (0, θ\] ∩ D\_c。

### 4.4　计时与持续验证

两种计时分列：首次实际失效（直写截面）起的总计时不重置；留存计时自最后一次实际深度写入起，遇新的深度写入即重置。u 越过阈之前可有多次实际写入——如 c = 1/4，续行 A、AB、B、AB、A、B：两个 AB 拍各写一次，各重置留存，第 6 拍末复归。首个复归截面是由序列确定的停止时点，不是统一的拍数期限；本式不声明统一的恢复期限。  
持续验证（两拍）：复归截面上 d \> 0，由引理，其后任意 t = 0 续行逐截面保持该截面的 Q 与对齐状态。有限轨迹在复归后不足两拍者，只签首次复归；复归后至少覆盖两拍 t = 0 者，签持续复归；复归后继续教学者不援用此保证——如复归后一拍 A(t = 1)，D 即失效。

### 4.5　教学续行

命题 3（间隙不变量与教学失效）　自两域初态（d = 1/2，κ = 1/2），沿任一 t ∈ {0, 1} 序列，每个截面 d ≤ 1/2；且每个教学拍末 d ≤ 0，已失效截面上的教学拍亦然。  
证明：每拍抑制沉积的增量至多 κ = 1/2。t = 0 的拍：d \> 0 时由引理无写入；d ≤ 0 时 u 至多增 1/2，故 d ≤ 1/2。t = 1 的单输入 X 拍：θ 增 1/2；若 X 被募集且放电则 u 同增 1/2——此时单输入驱动不超过 AB，拍首已有 d ≤ 0，拍末 d ≤ 0；否则 d 减 1/2，由 d ≤ 1/2 得拍末 d ≤ 0。t = 1 的 AB 拍：θ 增 1，u 至多增 1/2，拍末 d ≤ 0。∎  
长度不超过 5 的全部 t ∈ {0, 1} 序列（每域 9330 条、44790 个截面）：d ≤ 1/2 处处成立；22395 个教学拍末 D 全部失效。  
全轨迹保证界：不存在有限拍数的全称失效界——同长度的 t = 0 序列全部保持（命题 1）。  
失效后的复归，Q 与 Q ∧ 对齐分报：长度不超过 5 的序列中，末截面固定对象层 Q 复归的，双正、单正各 171 条；其中 Q ∧ 对齐复归的，双正 171 条、单正 81 条。单正域中，正输入 A 的 w\_A ≥ 1 由入口与兴奋沉积的单调性保证，AB 由 D 压住；Q 成立时，对齐当且仅当负单输入 B 满足 w\_B \< 1 或 a\_B ≥ 1（a\_B ≥ 1 时 B 被募集，由 D 与 w\_A ≥ 1 而被抑制）。该判据在 Q 成立的全部截面上与实际对齐逐一相符。例：单正域 B(t = 1)、AB、A、A——第 4 拍末 Q 复归，而 w\_B = 1、a\_B = 3/4，B 未被募集却放电，不对齐。  
不可恢复：正输入 X 的 a\_X ≥ 1 使 R2 永久失效（募集权只增不减）。

### 4.6　律层扰动

Δ4 的直写不改 u 与区间，Q 不变；只改变其后命题 2 中的 m\* 与 (d)。Δ43：κ′ = 0 时，c ≤ θ 不复归（c = 0 亦不能形成新区间）；c \> θ 且 c ≠ u₀ 的异值直写经两拍留存复归，固定对象层的 Q 与 Q ∧ 对齐都复归，并可按 Δ1 持续验证；同值写入不发生失效；κ′ ≠ 0 时代入实际 κ′ 按命题 2 计算。单正任务以其阈与初态分别计算。

## 第五节　稳定边界与层级量词

边界：D 失效集的上确界为 θ 且取得；即时资格失效集为 D\_c 中异于 u₀ 的全部值，c = u₀ 保持；复归由命题 2 给出；Δ2 中最早可能的失效在绝对第 1 拍（首拍即教学），给定轨迹的首次失效是该轨迹第一个教学拍的实际拍号（教学可以延后），全轨迹保证界不存在。  
量词：  
\- Δ1：对全部合法轨迹的全部截面，同一迹应 u 承担 Q ∧ 对齐（∃x∀t 形）。  
\- Δ3（κ \> 0）：c = u₀ 时保持；异值写入时存在复归轨迹；满足命题 2 拍序条件的轨迹族上首次复归，其后覆盖两拍 t = 0 者持续复归；对全部合法轨迹不成立（如全 A 续行，c ≤ θ 时不复归）。c = 0 时只有存在层复归：复归后在认证续行的每个截面有合格迹应，不是固定对象层的 ∃x∀t，也不涵盖复归前的失效段。  
\- Δ2：对全部轨迹的全部教学拍，拍末 D 失效；复归分报 Q 与 Q ∧ 对齐，无统一期限。  
\- Δ43（κ′ = 0）：c ≤ θ 不复归；c \> θ 且 c ≠ u₀ 经两拍复归；c = u₀ 保持。

## 第六节　稳定定理与强度申报

稳定定理　在 𝔐\_I、D\_mem、两域初态与 2.1 的许可变化域内：  
(i) Δ1 下固定对象保证稳定（命题 1）；  
(ii) Δ3 下同值写入保持；异值的深度扰动即时使资格失效，按命题 2 的拍序条件复归；c = 0 只有存在层的替代复归（新区间合法形成并满足留存时）；  
(iii) Δ2 下每个教学拍末 D 失效（命题 3），失效后的复归分报 Q 与 Q ∧ 对齐，单正域另需负单输入判据，正输入 a\_X ≥ 1 时不可恢复；  
(iv) 复归后的持续限 t = 0 续行（零写入引理），不声明统一恢复期限；  
(v) Δ4、Δ43 按 4.6。  
证明：第三、四节。∎  
强度：  
\- 限申报宿主、两任务、两域初态与 2.1 的许可变化域；不签其他宿主、三输入以上、门控变化与其他初态。  
\- 有限序列的逐例核对只作见证，全称结论由命题 1—3 的证明承担。  
H23-1　宿主的机制路线申报穷尽属实；权值非负。  
H23-2　留存窗 2 拍、基线取入口值（同《一般化结构源式》H20-2）。

## 第七节　接口

输入：《一般化结构源式》v1.0（宿主、D\_mem、资格判法、Σ\_mem、身份判据、命题 1、S1 与 1.5 的历史）；《内容对齐结构必然式》v1.0（迹应资格）。

输出：Δ1 的保证稳定、深度扰动的拍序复归条件、教学失效的间隙不变量、固定对象层与存在层的分判、稳定定理。  
——向起势诸式：自两域初态（或满足零写入引理前件、d \> 0 的状态），结构在 t = 0 续行中保持；深度扰动与教学后的复归条件；以此结构作起势的路线仍为待研接口。  
——向一般化结构源式：固定对象层与存在层的使用。
