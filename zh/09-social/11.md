自显论·社篇第十一 v1.0

# 国家结构

本篇试论一个总命题：

社篇第十论证了权力场的生成：在续行位有限、候选续行存在差异的社会场中，PowerPos 差异系统性趋向扩大，权力结构趋向形成，δ(Power) 系统性趋向积深。本篇处理权力场积深到某一阈值之后发生的结构性跃迁——国家生成：当 δ(Power) 超过制度化阈值，且续行位分配规则本身也发生沉积（δ(Rule\_SlotAllocation) \> θ\_rule），社会场中出现一种全新的结构——规则的规则；国家不是权力场本身，而是权力场的制度性沉积，是续行位分配规则本身被固化为稳定结构的状态。

我们要找到：国家生成的动力条件，以及国家与权力场的关系、国家的制度连续性、国家失稳条件的判定方程。

先给出结果。

国家生成的核心条件：

StateGenesis(F\_S) = 1 ⟺ δ(Power) \> θ\_state ∧ δ(Rule\_SlotAllocation) \> θ\_rule

一句话

国家出现的标志不是有人统治，  
而是连统治如何进行都已被规则化——  
国家是权力场的制度性沉积，不是权力场本身；  
PowerCore 可以换手，国家仍然存续，  
直到规则结构本身崩溃。

1\. 目的

社篇第十给出了权力场的生成条件和积深机制。但权力场的存在并不等于国家的存在——历史上存在大量有高度集中权力场但没有国家结构的社会形态：军阀割据、部落酋长统治、黑帮组织。这些形态都有高 PowerPos 的核心场，但没有国家。

它们缺少的不是权力，而是：续行位分配规则本身的沉积——即”统治如何进行”这一问题的规则化、制度化、可传递化。

国家的出现意味着两件事同时发生：其一，某个 PowerCore 的 δ(Power) 超过了让权力结构稳定运转所需的最低深度；其二，围绕这个权力结构形成的续行位分配规则本身也积深为一套稳定结构——不再依赖特定的 PowerCore 成员个体，而是依赖规则本身的续行惯性。

这是一个结构性跃迁，不是量变。国家出现之前，权力是”谁的”；国家出现之后，权力是”什么规则的”。

本篇解释为什么国家会出现（生成条件）；为什么国家比权力场更稳定（制度连续性）；以及国家在什么条件下会失稳（Legitimation Core 与 Enforcement Core 分离），为社篇第十二革命的扰动条件提供结构性入口。

1\. 核心命题

自显论的立场是：

国家（State）是权力场积深超过制度化阈值后，续行位分配规则本身发生沉积所产生的制度性结构——不是某个 PowerCore 的延伸，而是 PowerCore 长期占据续行位后将”如何分配续行位”这一规则本身固化为新的沉积结构；国家的稳定性来自 δ(Rule\_SlotAllocation) 的深度，不来自当前 PowerCore 的强度。

这个定义有三个关键含义：

其一，国家生成需要双重沉积。单纯的 δ(Power) 高不足以产生国家——军阀、黑帮、部落酋长可以有极高的 δ(Power)，但若没有 δ(Rule\_SlotAllocation) \> θ\_rule（规则本身的沉积），则只是”强权”而非”国家”。国家的标志是：规则的规则出现，即续行位如何分配的规则本身成为沉积对象。

其二，PowerCore 换手不等于国家替换。由于国家的稳定性来自 δ(Rule\_SlotAllocation)，而非当前 PowerCore 的强度，PowerCore 的替换（选举、政变、王朝更替）只要没有触及规则结构本身，国家就保持连续。美国总统更替、法国历次政党轮替，以及历史上诸多王朝的嬗替，都是 PowerCore 换手；其中部分规则结构（如制度框架、司法体系、行政惯例）保持了连续性，另一部分规则结构（如法统来源、权力授权方式）则发生了替换——这正是为什么历史学家对”某某朝代是否构成同一国家”存在争议：他们争的恰好是规则结构的哪些部分连续、哪些替换。

其三，国家失稳的根本原因是规则结构崩溃，不是权力减弱。当 Legitimation Core 与 Enforcement Core 发生结构性分离，且 δ(Rule\_SlotAllocation) 的衰减速率超过其积深速率时，规则结构开始失去对 PowerCore 换手的承载能力，国家进入失稳状态——这是革命的结构性前提之一。

1\. 算子映射

本篇在社篇第十算子基础上引入以下新定义：

续行位分配规则：Rule\_SlotAllocation(F\_S)，表示社会场中关于”如何分配续行位”的稳定规则结构。Rule\_SlotAllocation 是元层级的结构——它不直接分配续行位，而是规定分配续行位的程序、权限和合法性来源。注：Rule\_SlotAllocation 最初来源于 PowerCore 的重复续行——PowerCore 长期占据续行位，其占据方式逐渐被社会场识别、接受并固化为规则；但当 δ(Rule\_SlotAllocation) 超过 θ\_rule 后，规则结构获得相对独立的续行能力，不再完全依赖当前 PowerCore 的存在——规则本身成为新的沉积结构，反过来约束 PowerCore 的行为范围。这是”Power 创造规则、规则反过来约束 Power”的动力转折点。

规则沉积深度：δ(Rule\_SlotAllocation)，表示续行位分配规则在社会场中的历史沉积深度。δ(Rule\_SlotAllocation) 越高，规则越难被替换，国家的制度连续性越强。

国家生成条件：StateGenesis(F\_S) = 1，表示社会场中国家结构已经出现，成立条件为：

StateGenesis(F\_S) = 1 ⟺ δ(Power) \> θ\_state ∧ δ(Rule\_SlotAllocation) \> θ\_rule

即：权力场深度超过制度化阈值，且续行位分配规则本身的沉积深度超过规则稳定化阈值。注：此处默认 Rule\_SlotAllocation 具有最低执行能力——若规则存在但不可执行（如名义宪法、架空法律），则只构成名义制度，不构成完整国家结构；名义制度对应 δ(Rule\_SlotAllocation) 虽超过 θ\_rule 但执行渗透率极低的状态，国家形式成立但实质功能缺失。

国家强度：K\_State(F\_S)，表示国家结构抵抗替换和崩溃的能力。

K\_State ∝ δ(Rule\_SlotAllocation) · Ω(Rule\_SlotAllocation) · PowerCoreCpl

即：规则结构越深、越完整、权力-共核耦合越强，国家强度越高。

国家替换阈值：T\_replace(State)，表示触发国家结构真正替换所需的最低扰动强度。T\_replace(State) ∝ K\_State ∝ δ(Rule\_SlotAllocation) · Ω(Rule\_SlotAllocation)。注：T\_replace(State) 通常远高于 T\_replace(Power)——替换 PowerCore 远比替换国家结构容易。

国家裂解度：Frag(State)，表示国家内部的结构性裂解程度，由 Legitimation Core 与 Enforcement Core 的分离程度决定：

Frag(State) ∝ Δ(LegitimationCore, EnforcementCore) = \|PowerPos(Legitimation) − PowerPos(Enforcement)\|

注：Frag(State) 由 Δ 定义，而 Δ 的动力来源是两类：其一，社篇第九的社会场裂解（Frag(F\_S) ↑）差异性侵蚀 Legitimation Core 与 Enforcement Core 的支撑基础；其二，外部扰动对两核的差异性冲击（如经济危机削弱 Enforcement Core、意识形态危机削弱 Legitimation Core）。Frag(State) 不是自发产生的，而是社会场裂解与外部扰动在国家层面的传导结果。

国家残留：δ\_res^S，表示旧国家结构被替换后在社会场中的制度性残留，约束新国家结构的生长方向。

1\. 动力方程

规则结构积深方程：

dδ(Rule\_SlotAllocation)/dt ∝ PowerPos\_mean · FlowShare(Power) · φ\_{F\_S} · LegitimacyOverlap − Decay(Rule)

其中 LegitimacyOverlap := FamOverlap(PowerCore, Core\_S)，表示 PowerCore 与社会共核 Core\_S 的熟径重合度——即 PowerCore 的续行优先能力中有多少来自其与共识结构的深度嵌入。注：LegitimacyOverlap 与 PowerCoreCpl 的区别：PowerCoreCpl 是 PowerCore 与 Core\_S 之间的总体耦合强度（包含结构性联结的所有维度），LegitimacyOverlap 是其中专指共识重合部分的子量（FamOverlap 分量）。两者方向一致但粒度不同；本篇用 LegitimacyOverlap 作为规则结构积深方程的驱动项，强调共识嵌入对规则合法性的直接贡献。Decay(Rule) ∝ Frag(State) · (1 − Recompression\_S) 为规则结构衰减项。

注：规则结构的积深依赖 PowerCore 的续行位占据，但同时需要 LegitimacyOverlap 足够高——纯粹的力场压制型权力（低 PowerCoreCpl）可以维持高 δ(Power)，但无法产生高 δ(Rule\_SlotAllocation)，因为没有共识基础支撑规则的合法性。这解释了为什么军阀统治无法稳定演化为国家，而需要额外的共识整合过程。

国家连续性方程：

PowerCore 替换 ⇒ State 连续，当且仅当 δ(Power) ≥ θ\_state ∧ δ(Rule\_SlotAllocation) 在替换过程中未降至 θ\_rule 以下

即：只要规则结构的沉积深度维持在阈值以上，PowerCore 的换手（选举、政变、改朝换代）就不触发国家替换。国家的连续性是规则结构的连续性，不是 PowerCore 的连续性。

国家失稳方程：

Frag(State) ↑ ⟺ Δ(LegitimationCore, EnforcementCore) ↑

dδ(Rule\_SlotAllocation)/dt \< 0 当且仅当 Decay(Rule) \> PowerPos\_mean · FlowShare · φ · LegitimacyOverlap

State 失稳趋向 ⟺ dδ(Rule\_SlotAllocation)/dt \< 0 且 δ(Rule\_SlotAllocation) 趋向 θ\_rule（竞争性规则结构崛起的动力见社篇第十二）

1\. 国家的三种结构形态

国家在社会场中表现为三种可观测的制度形态，取决于 LegitimacyOverlap 与 δ(Rule\_SlotAllocation) 的组合：

形态一：共识深嵌型国家（高 LegitimacyOverlap，高 δ(Rule\_SlotAllocation)）。规则结构深度嵌入社会共核，续行位分配规则被社会场绝大多数个体场视为理所当然。可观测现象：PowerCore 换手不引发合法性危机；国家规则被主动遵守而非仅被强制执行；个体场将国家规则内化为自身熟径结构（FamOverlap(f\_i, Rule) 高）。例：成熟民主国家、传统王朝稳定期、古典城邦。

形态二：强制维持型国家（低 LegitimacyOverlap，高 K\_{Power}/K\_{F\_S}）。规则结构缺乏共识基础，国家依赖 Enforcement Core 的强制压制维持续行位分配。可观测现象：高维持成本（大规模监控、强制机构、维稳支出）；规则遵守率高但内化率低；PowerCore 换手容易引发短期失稳。例：殖民地政权、占领军政府、部分威权国家。

形态三：规则竞争型国家（多个竞争性规则结构，Frag(State) 高）。国家内部存在多个相互竞争的续行位分配规则体系，各自支撑不同的 PowerCore 候选，无一形成统合。可观测现象：宪法危机频发；法律体系内部冲突；执行机构与立法机构相互抵制；不同地区适用事实上不同的规则。例：联邦制危机期、宪政转型期、内战前夕的制度分裂。

1\. 定理

定理一：国家生成趋向定理

在满足 StateGenesis = 0（国家尚未出现）但 δ(Power) \> θ\_state 的社会场中，若 LegitimacyOverlap 持续为正且 PowerPos\_mean · FlowShare · φ · LegitimacyOverlap \> Decay(Rule)，则 δ(Rule\_SlotAllocation) 系统性趋向升高，社会场系统性趋向满足 StateGenesis = 1。

证明要点：由规则结构积深方程，当正向项大于衰减项时 δ(Rule\_SlotAllocation) 趋增；由 LegitimacyOverlap \> 0，PowerCore 的续行流优势可以转化为规则结构的沉积动力；续行位分配规则一旦开始沉积，其 Familiar Route 效应（规则被反复遵守 → 规则加深 → 更多个体场习惯遵守规则 → 规则进一步沉积）形成正反馈；故在权力足够深且共识基础存在的条件下，国家生成系统性趋向发生。∎

定理二：国家连续性定理

在已生成（StateGenesis = 1）的国家中，在权力场最低续行能力未丧失（δ(Power) ≥ θ\_state）的前提下，PowerCore 的替换不触发 State 替换，当且仅当替换过程中 δ(Rule\_SlotAllocation) 维持在 θ\_rule 以上；国家的历史连续性是规则结构的连续性，而非 PowerCore 的连续性。

证明要点：由 StateGenesis 的双条件定义，State 的成立仅依赖 δ(Power) \> θ\_state ∧ δ(Rule\_SlotAllocation) \> θ\_rule；PowerCore 替换只改变当前占据续行位的场，不直接改变规则结构的沉积深度；只要 δ(Rule\_SlotAllocation) ≥ θ\_rule 在替换过程中保持，StateGenesis = 1 持续成立；故 PowerCore 替换 ≠ State 替换，除非替换过程同时触发规则结构崩溃。∎

定理三：国家失稳趋向定理

在已生成（StateGenesis = 1）的国家中，若 Frag(State) 持续上升且 Decay(Rule) \> PowerPos\_mean · FlowShare · φ · LegitimacyOverlap，则 δ(Rule\_SlotAllocation) 系统性趋向下降，国家系统性趋向失稳。当 δ(Rule\_SlotAllocation) 趋降至 θ\_rule 以下时，StateGenesis 趋向归零，国家进入替换前状态。竞争性规则结构如何崛起并夺取统合地位，属于革命扰动动力学的范畴，在社篇第十二展开。

证明要点：由 dδ(Rule)/dt ∝ PowerPos · FlowShare · φ · LegitimacyOverlap − Decay(Rule)，当 Decay 超过积深项时 δ 趋降；由 Frag(State) ∝ Δ(LegitimationCore, EnforcementCore)，Legitimation Core 与 Enforcement Core 的分离使 Decay(Rule) 升高、LegitimacyOverlap 降低，双重加速 δ 下降；由 StateGenesis 双条件，δ(Rule) \< θ\_rule 触发 StateGenesis = 0；故 Frag(State) 持续上升在纠偏不足的条件下系统性趋向国家失稳。∎

1\. 击穿条件

反例一（无共识基础的持久强权）：某些历史形态下（某些帝国晚期、占领军政权），δ(Power) 极高但 LegitimacyOverlap 持续低，国家始终处于强制维持型而无法演化为共识深嵌型。此时 δ(Rule\_SlotAllocation) 依赖强制维持，一旦 Enforcement Core 削弱，规则结构快速崩溃。此为形态二的边界，不推翻定理一（定理一要求 LegitimacyOverlap 持续为正，此处条件不满足）。

反例二（外部强 Shock 保持规则连续性）：即使 PowerCore 发生剧烈替换（革命），若新 PowerCore 主动继承旧规则结构的部分框架（如继承宪法、保留司法体系），δ(Rule\_SlotAllocation) 可能不降至 θ\_rule 以下，国家在形式上保持连续性。法国大革命后的部分制度继承、日本明治维新的制度移植符合此模式。此为边界条件，支持定理二，不推翻它。

反例三（双重失稳同时触发）：在某些历史情形下，(a) 内部裂解和 (b) 竞争性规则崛起同时发生，形成协同失稳——旧规则结构在内外双重压力下快速崩溃，新国家结构在高 φ\_{F\_S} 条件下快速重建。历史上帝国崩溃后的快速国家重建（如一战后的欧洲国家系统重构）符合此模式。此为击穿条件，支持定理三，不推翻它。

1\. 总式

国家结构动力一般式：

δ(Power) \> θ\_state ∧ LegitimacyOverlap \> 0 ∧ 积深项 \> Decay(Rule) ⇒ δ(Rule\_SlotAllocation) ↑ ⇒ 系统性趋向 StateGenesis = 1（国家生成趋向定理）

StateGenesis = 1 ∧ PowerCore 替换 ∧ δ(Rule\_SlotAllocation) ≥ θ\_rule ⇒ State 连续（国家连续性定理）

Δ(LegitimationCore, EnforcementCore) ↑ ∧ Decay(Rule) \> 积深项 ⇒ δ(Rule\_SlotAllocation) ↓ ⇒ StateInstability ↑（国家失稳趋向定理）

δ(Rule\_SlotAllocation) \< θ\_rule ⇒ StateGenesis = 0（国家结构不再成立；竞争性规则结构的崛起动力见社篇第十二）

δ\_res^S 约束新国家结构的生长方向——旧制度残留使完全清零的国家替换不存在

当 Legitimation Core 与 Enforcement Core 的分离程度 Δ 持续上升时，Frag(State) ↑，规则结构开始失去对 PowerCore 换手的承载能力。这是国家失稳的动力起点，也是革命条件的结构性入口。当 Δ(LegitimationCore, EnforcementCore) 超过临界值，且社会场的共识崩溃（社篇第九）与权力场动荡（社篇第十）同时作用于国家结构时，革命所需的扰动条件趋向成熟。此即后篇所论。
