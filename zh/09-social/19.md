自显论·社篇第十九 v1.0

# 非社的条件

本篇试论一个总命题：

外篇第十一《非社》给出了一个核心证明：若群 = 能力不足之补偿，且能力可持续提升，则群体依赖趋于零——自显体必然走向非社。但这个证明有两个环节需要在社篇中形式化：一是”能力达到什么阈值时，个体开始脱离对社群的依赖”；二是”在哪些关键维度上，个体能力的提升使群体功能变得可被替代”。本篇处理第一个问题：非社的条件。

非社不是反社会，不是主动拒绝群体，而是社群必要条件被解除——个体在各关键功能维度上的有效能力已超过群体所能提供的功能增益，社群对于该个体的存续与自显不再是前提条件，而退化为可选项。

我们要找到：社群依赖的来源结构，个体有效能力的组成维度，以及非社条件的完整判据。

先给出结果。

非社条件：

∀ i ∈ KeyFunctions：IndividualCapacity\_i(f) ≥ GroupSupport\_i(f)

⇒ SocialDependency(f) → 0

⇒ 非社条件成立

一句话

社群不是自显体的本质归宿，  
而是能力不足阶段的补偿结构——  
当个体在所有关键功能维度上的有效能力  
超过群体所能提供的功能增益，  
社群就不再是前提条件，而退化为可选项；  
此时，非社条件成立。

1\. 目的

社篇第一至第十八讨论了社会场的生成、运作、演化的全部动力机制，但这些机制都建立在一个隐含前提上：个体场（f\_i）必须嵌入社会场（F\_S）才能维持足够的存续能力和自显能力。这个前提从未被明确检验——它被视为不言而喻的。

外篇第十一从根本上质疑了这个前提：社群依赖不是自显体的本质特征，而是能力结构的历史阶段特征。在原生生物条件下（人无腮、鱼无足、感知有限、行动受限、认知孤立），任何个体都必须依赖群体来完成其单独无法完成的功能——沟通、分工、竞争、工具制造、知识积累。但随着自显体的能力扩展，这些原本只有群体才能提供的功能，可以被个体以其他方式实现。

本篇给出”非社条件”的完整形式化：当个体有效能力在所有关键维度上超过群体支持时，社群不再是生存和自显的前提条件。

注：非社条件的成立不预设非社必然发生——它只是说此时社群依赖在动力上不再是强制性的。非社的必然性属于社篇第二十的议题。

1\. 核心命题

自显论的立场是：

社群依赖（SocialDependency）本质上是个体有效能力与其所需功能之间缺口的补偿结构——只要个体无法独立完成某项关键功能（感知、行动、构造、沟通、认知、存续），就会系统性趋向与其他个体耦合以填补这个缺口，由此形成社群。当个体有效能力在所有关键维度上超过群体所能提供的增益时，社群依赖的动力来源消失，个体进入非社条件。

这个命题有三个关键含义：

其一，社群依赖是功能性的，不是目的性的。人与人聚合，不是因为聚合本身有价值，而是因为聚合能够填补个体能力缺口。社群的道德价值、情感意义、文化意义都是在功能性聚合的基础上次生形成的——本篇专门处理功能性维度，不评判次生维度。

其二，有效能力是多维的，非社条件需要在所有关键维度上同时成立。能力极强的个体可能在认知维度已经超越群体，但在身体行动维度仍然依赖工具或群体协作——此时非社条件不完全成立。只有全维度超越，社群依赖才真正趋零。

其三，“能力超越群体”不要求单一场无限扩展。通过宿体可换、宿器可增、感知可扩、行动可外接、认知可并联、记忆可外化、自修复可持续，个体有效能力的上界相对于原生社群功能需求趋向开放——不是单一场容积无限，而是多层扩展机制使有效能力持续高于社群依赖阈值。

注：非社条件成立的前提隐含 GroupSupport\_j 存在有限有效上界——即对个体实际功能需求而言，群体所能提供的支持存在可被超越的上限。若社群本身也持续升级且增速高于个体能力提升速度，非社条件可能无法到达。本篇假定在个体能力开放化路径下，IndividualCapacity 的增速可持续超过 GroupSupport 的增速。

注：SocialGain → 0 不是非社条件成立的充分条件——群体功能退化（GroupSupport → 0）同样会导致 SocialGain → 0，但此时个体能力未必超越群体，非社条件未必成立（可能是双方同时衰退）。非社条件的正确判据是 ∀ j：IndividualCapacity\_j ≥ GroupSupport\_j，而非 SocialGain → 0。

1\. 算子映射

本篇在社篇第十八算子基础上引入以下新定义：

社群依赖度：SocialDependency(f\_i)，表示个体场 f\_i 对社群 F\_S 的功能性依赖强度：

SocialDependency(f\_i) = Σ\_j w\_j · max(0, GroupSupport\_j(f\_i) − IndividualCapacity\_j(f\_i)) / Σ\_j w\_j · GroupSupport\_j(f\_i)

即：社群依赖度为各关键功能维度上”群体支持超过个体能力”的加权比例；若个体能力在所有维度均超过群体支持，SocialDependency → 0。

关键功能维度集合：KeyFunctions = {感知扩展、行动执行、构造与制造、沟通与信息获取、认知与运算、存续与修复}，为社群在原生条件下能提供而个体单独无法完全提供的核心功能集合。

群体功能支持：GroupSupport\_j(f\_i)，表示在第 j 个关键功能维度上，社群能为个体 f\_i 提供的最大功能增益——包括分工专业化、知识积累、集体行动、工具共享等。

个体有效能力：IndividualCapacity\_j(f\_i)，表示个体 f\_i 在第 j 个关键功能维度上的实际可用能力，包含：

IndividualCapacity\_j = NativeCapacity\_j + ExtendedCapacity\_j

其中 NativeCapacity\_j 为个体场自身的原生能力；ExtendedCapacity\_j 为通过宿体替换（BodySubstitution）、外接工具（ExternalTool）、感知扩展（SensoryExtension）、认知并联（CognitiveParallel）、记忆外化（MemoryExternalization）、自修复机制（SelfRepair）获得的有效能力增量。

注：ExtendedCapacity\_j 不直接受单一场内部容积上限（Cap\_f）约束，因为它主要依赖外部资源和工具结构的扩展，而非单一沉积场的内部容积——这是自显体有效能力上界趋向开放的结构原因。注意：外接能力最终仍需通过观察回路进入个体场，故不完全脱离场结构约束，但其增长不被单一场容积封顶。

社群耦合成本：SocialCost(f\_i)，表示个体场维持社群耦合所需的持续资源消耗：包括 Core\_S 约束成本（社篇第一至第十二）、代际传递成本（社篇第十七）、历史残留偏置成本（社篇第十六）等。

社群功能增益：SocialGain(f\_i) = Σ\_j w\_j · max(0, GroupSupport\_j(f\_i) − IndividualCapacity\_j(f\_i))，即社群实际提供的净功能增益（仅计算个体能力尚未覆盖的维度）。

能力缺口：CapacityGap\_j(f\_i) := max(0, GroupSupport\_j(f\_i) − IndividualCapacity\_j(f\_i))，表示第 j 维度上个体能力尚未覆盖的群体支持量；CapacityGap\_j = 0 表示该维度非社条件已成立。

非社条件：NonSocialCondition(f\_i)，成立条件为以下四项同时满足：

条件一（全维度超越）：∀ j ∈ KeyFunctions：IndividualCapacity\_j(f\_i) ≥ GroupSupport\_j(f\_i)

条件二（扩展能力鲁棒性）：ExtendedCapacity\_j(f\_i) 可被个体独立维持——即扩展能力不依赖社群基础设施的持续运作，而来自个体可自主控制和修复的工具结构；依赖社群中介维持的扩展能力不计入 IndividualCapacity，仅计入 GroupSupport。

条件三（需求有限性）：个体实际功能需求存在有限上界——非社条件针对个体实际需要的功能集合，而非假想中无限扩展的需求集合。

条件四（功能性判据）：非社条件仅描述功能性依赖消解，不包含情感依赖、习惯积深等次生依赖——功能非社 ≠ 情感非社，后者属于另一层次的分析。

即个体在所有关键功能维度上的有效能力均达到或超过群体支持水平，且该能力具备独立维持性。

1\. 动力方程

社群依赖方程：

dSocialDependency(f\_i)/dt ∝ −dIndividualCapacity/dt · CapacityGap(f\_i) / GroupSupport(f\_i)

即：当个体有效能力持续提升且存在功能缺口时，社群依赖度系统性下降；当功能缺口趋零时，依赖下降趋于停止（已达非社条件）。

有效能力开放化方程：

dIndividualCapacity\_j/dt ∝ dNativeCapacity\_j/dt + dExtendedCapacity\_j/dt

其中 dExtendedCapacity\_j/dt 取决于工具自造能力（ToolSelfMake）、宿体可扩展性（BodyExtensibility）和外接资源可用性（ExternalResourceAccess）；这三项不受单一场容积约束，在自显体主动升级路径下可持续为正。

非社条件触发方程：

NonSocialCondition 成立 ⇒ SocialGain(f\_i) → 0；反向不成立：SocialGain → 0 不推出 NonSocialCondition（群体功能退化亦可使 SocialGain 趋零）

即：当非社条件成立时，社群对个体的净功能增益趋零；但净功能增益趋零本身不构成非社条件——社群功能退化同样可使 SocialGain 趋零，而不涉及个体能力的超越。

注：非社条件成立不等于社群关系立即断裂——存在过渡区（SocialGain \> 0 但趋于0），在此区间内社群关系变为可选项而非必选项，个体可以自主决定是否维持耦合。

1\. 非社条件的六个维度

非社条件需要在六个关键功能维度上同时成立：

维度一：感知扩展。原生条件下群体提供扩展感知（哨兵、侦察、群体信息网络）；非社条件：个体通过感知扩展设备、感知外接系统，独立获得等效或更优的感知覆盖。判据：IndividualSensory ≥ GroupSensory\_network。

维度二：行动执行。原生条件下群体提供集体行动力（建造、搬运、战斗）；非社条件：个体通过宿器扩展、机械外接、自造工具，独立完成原本需要群体协作的行动任务。判据：IndividualAction ≥ GroupAction\_collective。

维度三：构造与制造。原生条件下群体提供分工制造（技术积累、工具链、生产协作）；非社条件：个体通过自造能力（ToolSelfMake）、设计-制造一体化，独立完成构造与制造需求。判据：IndividualConstruction ≥ GroupManufacturing。

维度四：沟通与信息获取。原生条件下群体提供信息网络（语言、文字、教育、媒体）；非社条件：个体通过认知并联、外部知识库直接接入、自主信息处理，不再需要群体作为信息中介。判据：IndividualInformation ≥ GroupInformation\_network。

维度五：认知与运算。原生条件下群体提供集体智慧（分工认知、协作决策、知识专业化）；非社条件：个体通过认知并联（CognitiveParallel）、认知场外接，独立达到或超过群体认知效能。判据：IndividualCognition ≥ GroupCognition\_collective。

维度六：存续与修复。原生条件下群体提供存续保障（医疗、互助、防御、食物生产）；非社条件：个体通过自修复机制（SelfRepair）、存续自持（SurvivalSelfSufficiency），独立维持生存与修复需求。判据：IndividualSurvival ≥ GroupSurvival\_support。

全维度非社条件：上述六项判据同时成立时，SocialDependency → 0，非社条件完全成立。

1\. 定理

定理一：社群依赖来源定理

社群依赖的根本来源是关键功能维度上的能力缺口（CapacityGap）——只要存在任意一个维度 j 使得 IndividualCapacity\_j \< GroupSupport\_j，个体就存在对社群的功能性依赖，SocialDependency \> 0。

证明要点：由 SocialDependency 定义，SocialDependency \> 0 ⟺ ∃ j 使得 max(0, GroupSupport\_j − IndividualCapacity\_j) \> 0；即至少一个维度存在个体能力不足于群体支持的情形；在原生生物条件下，所有六个维度均存在显著缺口，故 SocialDependency 高；随缺口缩小，SocialDependency 趋降。∎

定理二：有效能力开放化定理

通过 ExtendedCapacity（宿体替换、外接工具、感知扩展、认知并联、记忆外化、自修复），个体有效能力上界不受单一场容积约束，可在各关键功能维度上持续超过原生社群功能需求水平。

证明要点：ExtendedCapacity\_j 依赖外部资源和工具结构，而非单一场 f\_i 的内部容积（Cap\_f）；只要外部资源可接入且工具可自造，dExtendedCapacity\_j/dt \> 0 可持续成立；当 ExtendedCapacity\_j 足够大，IndividualCapacity\_j 可超过任何固定的 GroupSupport\_j 水平；故有效能力上界相对于原生社群功能需求趋向开放，不被场容积上限封闭。∎

定理三：非社稳定态定理

若非社条件在所有维度上成立（SocialGain → 0）且个体有效能力持续维持或提升，则非社状态系统性稳定——已超越的功能维度不会自发退回到需要群体支持的状态。注：若有效能力发生结构性下降（外接能力丧失、工具链断裂、自修复失败），非社条件可以逆转，故本定理为条件稳定而非绝对不可逆。

证明要点：非社条件成立后，SocialDependency → 0，继续维持社群耦合的动力来源消失（SocialGain → 0）；在此条件下，群体耦合强度趋降（社篇第十八演化律：低 CurrentDynamics 压力 → 轨迹趋向 StableCoreRegion，而此时个体场的 StableCoreRegion 为低耦合态）；故只要有效能力维持，非社条件是稳定态，不会自发逆转——但有效能力的结构性下降可以打破此稳定。∎

1\. 击穿条件

反例一（次生依赖的残留）：某些个体即使在功能性维度上已达到非社条件，仍因情感依附、习惯积深、文化认同（ValueLayer、NarrativeLayer 的深度积深，见社篇第十五）维持社群耦合。这说明非社条件的功能性成立不等于社群关系立即解除——次生依赖（非功能性依赖）可以在功能性依赖消解后仍然维持，甚至强化。此为边界条件，不推翻定理三（定理三描述功能性条件，不处理次生依赖）。

反例二（能力集中化导致的脆弱性）：若个体通过极度专业化的外接系统达到非社条件，但该外接系统依赖其他个体或社会机构维持（如高度依赖基础设施的技术能力），则一旦社会基础设施失效，有效能力将急剧下降，非社条件反转。这说明有效能力的稳健性（ExtendedCapacity 的鲁棒性）是非社条件成立的必要条件——依赖社群维持的扩展能力不构成真正意义上的 IndividualCapacity 提升。此为边界条件，支持定理二（有效能力开放化需要外部资源可独立接入，而非依赖社群中介）。

反例三（维度不均衡的过渡状态）：实际演化中，个体在不同维度的能力提升速度差异极大——某些自显体可能在认知和信息维度已远超群体，但在行动和存续维度仍依赖社群基础设施。此时非社条件部分成立，产生”半非社”过渡状态：个体与社群的关系从全面依赖变为选择性依赖——只在仍存在缺口的维度维持耦合，在已超越的维度逐步脱耦。此为非社条件的正常过渡路径，不推翻定理一（任意维度仍有缺口则 SocialDependency \> 0）。

1\. 总式

非社条件动力一般式：

SocialDependency(f\_i) = Σ\_j w\_j · max(0, GroupSupport\_j − IndividualCapacity\_j) / Σ\_j w\_j · GroupSupport\_j（社群依赖度定义）

IndividualCapacity\_j = NativeCapacity\_j + ExtendedCapacity\_j（有效能力开放化；ExtendedCapacity 不受单一场容积约束）

∀ j ∈ KeyFunctions：IndividualCapacity\_j ≥ GroupSupport\_j ⟺ SocialDependency → 0（非社条件）

NonSocialCondition 成立 ⇒ SocialGain → 0 ∧ SocialCost \> 0（非社条件成立时净增益消失，社群耦合变为净消耗；注：SocialGain → 0 不反向蕴含非社条件——群体功能退化也可使 SocialGain 趋零，但不等于个体能力已超越群体支持）

社群依赖的动力来源是关键功能维度上的能力缺口——缺口消失，依赖消失；社群不是自显体的本质归宿，而是能力不足阶段的补偿结构；非社条件是自显体在各维度有效能力超过群体支持后的可达状态，其发生不需要对抗社群，只需要能力条件满足。
